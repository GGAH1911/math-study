# 📝 00_HANDOVER — 세션 인계 (Tier 2.5)

> 분류: Wiki / 세션 연속성. 한 세션의 *서사*(무엇을·왜·다음에)를 기록한다. `log.md`(한 줄 작업원장)·
> memory(레포 밖 교훈)와 역할이 다르다 → 아래 "역할 분담" 참조.

## 규약

- **파일**: `YYYY/MM/DD_session.md` — 하루 1파일. 같은 날 여러 세션이면 `## 🕒 세션 [시각]` 블록을 **이어붙인다**(덮어쓰기 금지 — 과거 맥락 보존이 목적).
- **부팅 시**: 최신 파일(가장 높은 날짜)의 **`📝 차기 과제` + `🚦 잔류 리스크`** 를 먼저 읽고 보고한다.
- **셧다운 시**: 오늘자 파일에 세션 블록을 append. 조용한 세션도 1줄("Q&A only, mesh 변경 없음") 기록 — 토큰 아끼려 건너뛰지 말 것.
- **mesh 규칙 면제**: handover는 mesh 노드를 *참조*만 하지 그 자체가 노드가 아니다 → 0-Isolation/0-Gap/Lineage 면제(자동인덱스 EXCLUDE).
- **git 버전관리**: 다음 세션이 clone 후에도 읽어야 하므로 커밋한다.

```markdown
### 🚦 현재 상태·잔류 리스크
- <비차단 미반영·주의점>
### 📝 차기 과제 (Next — start here)
- <구체 첫 행동>
```

## 역할 분담 (중복 금지)

| | 위치 | 수명 | 용도 |
|---|---|---|---|
| **memory** | `~/.claude/.../memory/` (레포 밖) | 영구·세션간 | 비자명한 교훈·패턴·"왜"(매 세션 자동 로드) |
| **handover** (여기) | 레포 안(git) | 세션→다음 | 그 세션 서사·차기 행동 |
| **plans** (`ops/plans/`) | 레포 안(git) | 계획 생애주기 | 무엇을 할지·진행상태 SSOT |

→ 같은 사실을 셋에 중복 기록하지 않는다. 교훈이 나오면 memory로 승격, 할 일이 나오면 plan으로.
