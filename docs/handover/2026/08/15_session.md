는 DB mastery·진행도·추천·산출물 2개를 쓰는 **대시보드**였다. 남은 5개 중 **3개는 페이지 전용
API 가 필요**하고, 그건 "목록을 클라이언트로 던지는" 것과 다른 종류의 일이다.
