# 🤖 Android 출시 체크리스트 — math-study

> 분류: Operations / Release. **부동산포렌식 프로젝트가 2026-08-11~12 에 실제로 겪은 것**을
> math-study 관점으로 옮긴 것이다. 원본 런북은 그쪽 레포에 있고, 여기엔 **우리에게 적용되는 것과
> 우리는 안 겪어도 되는 것**을 갈라 적는다. 회의 모드 산출물 — 실행은 앱 프로젝트 착수 후.

## 🎁 우리가 공짜로 얻는 것 (남이 먼저 밟아준 지뢰)

### ① targetSdk 36 — 처음부터 이 값으로 시작한다
포렌식은 targetSdk 34 로 만들었다가 **업로드 자체가 막혔다.** 빌드는 성공하는데
**Play Console 업로드에서 막힌다 — 가장 늦게 드러나는 자리다.**

| 시점 | 신규 앱 제출에 필요한 target |
|---|---|
| 2025-08-31~ | API 35 |
| **2026-08-31~** | **API 36** (연장 신청 시 2026-11-01) |

우리는 그 이후에 낸다 → **36 확정.**

### ② Capacitor 8 로 시작한다 (가장 큰 절감)
targetSdk 는 **Capacitor 메이저 버전에 강하게 묶여 있다.** 숫자만 올리면 깨진다.
포렌식은 Capacitor 6(기본 SDK 34)에서 시작해 **6 → 8 메이저 두 단계 승급**을 해야 했다.

SDK 36 = Capacitor 8 기본값. 함께 가는 값:
```
minSdkVersion 24 · compileSdkVersion 36 · targetSdkVersion 36
Java 21 권장(17+) · AGP 8.13.0 · Gradle wrapper 8.14.3
```
→ **우리는 처음부터 8 로 시작하므로 승급 작업이 없다.**

★파생 규칙: **결제 플러그인은 Capacitor 버전을 확정한 뒤 고른다.** 플러그인이 Cap 버전을
가리므로, 6 에 붙였다가 8 로 올리면 두 번 일한다(포렌식이 이 순서 문제를 겪었다).

### ③ minSdk 24 — Android 5.x 가 빠진다
점유율 극소라 실질 영향 없음. 학생 기기는 더 신형이라 우리는 더 안전하다.

### ④ 서명 키 — 처음부터 바르게
포렌식은 **비밀번호가 `build.gradle` 에 평문**으로 있었고 그 파일이 git 추적 대상이라
배포 직전에 키를 교체해야 했다(배포 후엔 교체 불가 — 서명이 바뀌면 기존 사용자가
업데이트를 못 받는다).

우리는 처음부터:
- 키 4096-bit, 유효기간 30년+
- 비밀번호는 **`keystore.properties`(gitignore)** 또는 환경변수. **소스에 절대 안 넣는다**
- 둘 다 없으면 **빌드가 멈추게** 한다 — 서명 없는 산출물을 조용히 내지 않는다
- `.gitignore` 패턴은 `release.keystore*` · `keystore.properties*` (뒤에 접미사 붙은 백업본까지 잡히게)

★**비밀번호는 문서·이메일에 적지 않는다.** 리포는 원격에 푸시되고 메일은 오래 남는다.

### ⑤ Play App Signing — 걱정을 덜 해도 된다
"키를 잃으면 앱을 영원히 업데이트 못 한다"가 통설인데, **지금 콘솔은 앱 생성 시
Play 앱 서명 약관 동의가 필수**라 자동으로 켜진다. 그러면 우리 키는 **업로드 키**가 되고
**분실 시 재발급**받을 수 있다.
→ 백업은 여전히 하되, **"마지막 방어선"은 아니다.** 과도한 백업 의식에 시간 쓰지 않는다.

## 📋 우리가 따로 해야 하는 것

### 스토어 자산
| 항목 | 규격 |
|---|---|
| 피처 이미지 | 1024×500 |
| 앱 아이콘 | (런북 6-2 참조) |
| 짧은 설명 | 80자 이내 |
| 전체 설명 | 4000자 이내 |
| 스크린샷 | 직접 캡처 — **필기 화면이 핵심 셀링 포인트** |

★스크린샷은 우리 제품의 차별점(**손풀이 + AI 튜터**)이 한눈에 보이게 잡는다.

### 빌드 파이프라인
포렌식은 **맥북(Tailscale rsync) → Android Studio** 였다가 **서버에서 스튜디오 없이 빌드**로
옮겼다. 우리도 tme 에서 CLI 빌드가 가능한지 먼저 보고, 안 되면 맥북 경유.
★산출물 디렉터리에 **옛 것과 새 것이 같은 이름으로 섞이는 함정**이 있었다 — 빌드 전 정리.

### 실기기 확인
`bundletool` 로 AAB → APKS → 설치. 포렌식은 Galaxy S20+ 로 확인했다.
**우리는 S펜 되는 갤럭시 탭으로 해야 한다** — 필기가 코어라 폰 확인만으로는 부족하다.

### 내부 테스트 트랙
**공개 스토어 페이지를 만들지 않는다**(포렌식 실측). 안심하고 먼저 올려서 파이프라인을 검증한다.

## ⚠️ math-study 고유 — 포렌식엔 없던 것

포렌식 런북에 **없는** 항목들이다. 우리가 처음 겪는다.

1. **인앱결제(구독)** — 포렌식은 결제가 M7-B 로 남아 있었다. 우리는 출시 필수.
   → 구독관리 서비스 + 상품 등록 + 구매 복원 + 정기결제 심사 항목
2. **가이드라인 4.2(최소 기능)** — WebView 셸이라 **오프라인 콘텐츠·펜 입력·인앱결제**가 방어 논거
3. **만 14세 미만 법정대리인 동의** — 중1~중3 콘텐츠가 있어 실제로 온다
4. **손풀이 이미지의 국외 이전 고지** — 해외 LLM API 로 나간다
5. **데이터 안전 섹션(Data safety)** — Play Console 필수 신고. 수집 항목·국외 이전·삭제 요청 경로
6. **앱 내 회원탈퇴** — 이미 구현돼 있으니 노출만
7. **필기 지연** — 포렌식엔 없는 요구. 실기기(S펜)에서 기준선 확인 필요
