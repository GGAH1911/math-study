# 필기 캔버스 (InkCanvas) — 전체 스펙 & 로드맵

> 작성 2026-06-27 · 구현 `web/src/components/InkCanvas.tsx` · 통합 문제/개념 페이지
> 비전: 단순 필기가 아니라 **맥락 인지 튜터와 연결된 수학 학습 표면**. 굿노트가 못 하는 자리(수학 인지 도형 + 학습 레이어 + 튜터 피드백).

## 핵심 원칙
- **저지연**: `desynchronized` 캔버스 + `getCoalescedEvents`(고주파 중간점) + `getPredictedEvents`(예측 잉크) + 2레이어(확정 base / 진행 overlay) + 압력 굵기 + 팜리젝션. (M1 iPad Pro ProMotion 120Hz에서 무지연 확인.)
- **벡터 스트로크 모델**: 획 = 점(좌표+압력) 배열. ★래스터가 아니라 벡터라 선택·이동·변형·재색·스냅·OCR이 전부 가능. 이게 모든 고급 기능의 토대.
- **웹 우선**: iPad Safari에서 애플펜슬 즉시 작동 → 네이티브 앱 없이 전 기기. 굿노트급 손맛 필수 시에만 네이티브 PencilKit 후속.
- **채점과 분리**: AI 채점(루브릭·단계별·sympy)은 아주 장기. 필기 자체 + 가벼운 튜터 피드백이 우선.

## 영속
- 현재 localStorage(per 문제/개념 storageKey). → 후속 DB 저장(멤버십 재사용, 기기 간 동기화).

## Phase A — 필기 완성도 + 레이어 + 갈무리 (다음)
| # | 항목 | 메모 |
|---|---|---|
| A-필압 | 필압 감지/**무감지** | 수학엔 무감지(균일선) **기본** — 그림 아니면 균일이 학습에 유리 |
| A-점선 | 점선/실선 | `setLineDash` |
| A-종이 | blank / ruled / 격자 + **간격 조절** | 배경 레이어 교체, 격자/ruled 간격 슬라이더 |
| A-지우개 | **획 지우개 + 정밀 지우개** | 획=스트로크 히트테스트로 통째 삭제, 정밀=픽셀(destination-out) |
| **A-레이어** | ★**필기 레이어 on/off (전후 비교)** | 레이어={이름,가시,strokes[]}. 내풀이/정답/첨삭/메모로 나눠 토글 → 학습 비교. **우측 프리뷰 패널**(썸네일·눈토글·추가/삭제, 슬라이드 in/out) |
| **A-갈무리** | ★**올가미·사각 선택 + 일괄 조작** | 이동·크기·회전·삭제·복제·**색변경**·**다른 레이어로 이동** |

**아키텍처 — 레이어 & 갈무리는 한 몸·foundational**:
- 스트로크 모델 `strokes[]` → `layers[].strokes[]`. 나중에 넣으면 리팩터라 **A에서 코어로**.
- 레이어 렌더: 가시 레이어 순서대로 합성(스택형 per-layer 캔버스 권장 — 가시토글=display, 지우개 격리=그 레이어 canvas에 destination-out).
- 갈무리: 올가미=point-in-polygon으로 포함 스트로크 선택 → 어파인 변형(이동·스케일·회전)·색 일괄변경·**레이어 이동**(레이어 기능의 진짜 활용처).

## Phase B — 스냅 + 전체화면 + 튜터 피드백
| # | 항목 | 메모 |
|---|---|---|
| B-전체화면 | **문제 좌측 절반 + 그 위 필기** | 랜드스케이프. 세로면 "가로로 돌려주세요" 오버레이(`matchMedia('(orientation:portrait)')`). 문제 이미지=배경 레이어 |
| B-직선스냅 | 직선 스냅 | 직선 도구 or 그은 뒤 자동 직선화 |

| **B-튜터피드백** | ★**갈무리 → 튜터에게 보내기** | 선택 PNG를 채팅으로 → 튜터가 맥락(문제·개념·**검증 풀이**) + 이미지로 대화형 피드백. 채점 파이프라인 없는 **가벼운 AI 피드백**. 의존=채팅 이미지 첨부 + 튜터 vision(Haiku 4.5 OK) + 손글씨 vision PoC(대화형이라 문턱 낮음). 프로토타입=self-hosted, 프로덕션=LLM API 직결과 함께 |

## Phase C — 도형 시스템 (GeoGebra-lite, 최대 차별점)

### 모델 — 프리셋 = 파라미터 템플릿
- **카테고리**: 도형(삼각형·사각형·원·다각형) / 곡선(함수그래프·포물선·이차곡선·sin/cos) / 선·각(직선·반직선·선분·벡터·각·부채꼴)
- **차원**: 2D / 3D. 2D→3D = **압출**(삼각형→삼각기둥·삼각뿔, 사각형→사각기둥·사각뿔, 원→원뿔·원기둥) + **별도 경로**(구, 정다면체=정사면체·정육면체·정팔면체는 압출 아님)
- **프리셋 = 파라미터**: 직각삼각형(밑변·높이)·정삼각형(한 변)·이등변·직사각형(가로·세로)·정사각형(변)·평행사변형(밑변·높이·기울기)·사다리꼴·마름모·원(반지름)·타원(a·b)·원뿔(밑면반지름·높이)·원기둥(반지름·높이)·구(반지름)…
- → 각 프리셋이 곧 **`InteractiveSpec` 템플릿**(params + geometry). 배치 후 슬라이더로 실시간 조절. 렌더 = 기존 `Geometry.tsx`·`Geometry3D`·`InteractiveSpec` 엔진 재사용.
- **수학 라벨/측정**: 꼭짓점 자동 라벨(A/B/C)·변 길이·직각/각도 표시·눈금. 토글.

### ★UX — 메뉴 트리 함정 회피 (프리셋이라도 직관적으로)
정밀(프리셋·파라미터) ↔ 유려함(스케치)의 긴장. 메뉴 트리(카테고리→2D/3D→프리셋→파라미터)는 탭 지옥 → 다음으로 해결:
1. **★주력 = 스케치 후 스냅**: 대충 그리면 **기하 휴리스틱**(폴리라인 단순화 Douglas-Peucker → 꼭짓점 수·닫힘·원 피팅)으로 도형 인식 → 깔끔한 파라메트릭 도형으로 스냅. 정밀 타입(직각/정)은 그린 각도·변에서 **자동 추론·제안**(고스트 프리뷰 1탭 확정). 카테고리·프리셋이 *그리는 행위에서 추론*됨. (GeoGebra·iOS Notes·Procreate "draw and hold"와 동일 원리. ML 불필요.)
2. **스마트 기본값 + 점진 정밀화**: 2D/3D/프리셋을 한 번에 안 물음 → 즉시 기본 도형 → 핸들·칩으로 다듬기.
3. **직접 조작 핸들 + 슬라이더**: 꼭짓점 드래그(빠른 시각) + 슬라이더(정밀 수치) 둘 다.
4. **시각 프리셋 팔레트(아이콘 썸네일)**: 텍스트 메뉴 아님, 1탭. 스케치-스냅의 보조.
5. **그리는 중 제약 스냅**: 직각·30/45/60·등변에 스냅 + 라이브 각도/길이 라벨.
6. **2D 우선, 3D는 "이 2D를 입체로" 액션** or 별도 모드.
→ **스케치-스냅 주력 + 팔레트 보조.** 프리셋·파라미터는 *내부 모델*로 남고, 사용자는 "그리면 깔끔해진다"를 경험.
