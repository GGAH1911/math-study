# SymPy (Python 기호 계산)

> **site** · 한국 수능 수학 학습 자료
> **URL**: <https://www.sympy.org>


## 요약 (왜 유용한가)

복잡한 식 전개·인수분해·미분·적분을 Python으로 검산하는 도구. D11 표준 검산기.

## 활용법

본인 풀이를 sympy로 검산 — 답이 다르면 어느 단계가 틀렸는지 좁혀나가기. 페이지 채팅창의 튜터에게 "이 풀이 sympy로 검산해줘"라고 요청 가능.
