# 자이스토리 (수학)

> **workbook** · 한국 수능 수학 학습 자료


## 요약 (왜 유용한가)

수능 기출 변형 + 평가원 모의 기출을 단원별로 풍부하게 모은 대표 문제집. 4점 킬러 분석에 강점.

## 활용법

단원 학습 후 기출 양 채우기에 효과적. 풀고 나서 오답을 docs/mistakes/에 정리하면 D6 자동 트리거.
