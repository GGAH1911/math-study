> **site** · 한국 수능 수학 학습 자료
> **URL**: <https://www.ebsi.co.kr>


## 요약 (왜 유용한가)

평가원 연계 EBS 무료 인강 + 기출 자료. 회원가입만 하면 사용 가능.

## 활용법

돈을 안 들이고 시작하는 가장 좋은 곳. 수능특강 / 수능완성 교재 영상이 무료로 제공됨.
