# 마더텅 수학 기출문제집

> **workbook** · 한국 수능 수학 학습 자료


## 요약 (왜 유용한가)

평가원·교육청 기출을 시기별·유형별로 모은 정통 기출집. 해설이 자세함.

## 활용법

단원별 약점 진단 후 같은 유형 묶음 풀이로 굳히기. 해설을 그대로 읽기보다 일부러 가린 채 풀고 비교.
