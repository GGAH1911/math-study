# Desmos 그래픽 계산기

> **site** · 한국 수능 수학 학습 자료
> **URL**: <https://www.desmos.com/calculator>


## 요약 (왜 유용한가)

함수 그래프를 즉시 그려주는 무료 온라인 계산기. 슬라이더로 파라미터 변화 관찰 가능.

## 활용법

"$y=ax^2$에서 $a$를 변화시키면 어떻게 되는가" 같은 직관 다지기. 풀이 검증 + 그래프 개형 확인에 강력.
