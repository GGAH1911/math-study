# GeoGebra (기하·대수 통합)

> **site** · 한국 수능 수학 학습 자료
> **URL**: <https://www.geogebra.org>


## 요약 (왜 유용한가)

기하 작도·대수 통합 무료 도구. 평면·공간 도형을 인터랙티브하게.

## 활용법

도형 단원에서 정리·증명을 직관적으로 확인할 때. 예: 원주각이 정말 일정한지 직접 확인.
