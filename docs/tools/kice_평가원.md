# 한국교육과정평가원 (KICE)

> **site** · 한국 수능 수학 학습 자료
> **URL**: <https://www.kice.re.kr>


## 요약 (왜 유용한가)

수능 출제·관리 공식 기관. 기출 원본 PDF, 정답표, 등급컷 등 공식 자료.

## 활용법

수능·6월·9월 모의평가 직후 원본 PDF 다운로드. 풀이는 사설이 더 친절하지만 원본은 여기.
