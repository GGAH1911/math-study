# EBS 수능특강 (수학)

> **workbook** · 한국 수능 수학 학습 자료
> **URL**: <https://www.ebsi.co.kr>


## 요약 (왜 유용한가)

평가원이 EBS 연계 자료로 지정하는 공식 교재. 수능 직전 마무리에 필수.

## 활용법

6월 모의평가 후 풀기 시작. 연계 출제 가능성이 있어 모든 문제 풀어보는 것을 권장.
