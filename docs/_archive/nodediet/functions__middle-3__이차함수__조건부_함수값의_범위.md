# 조건부 함수값의 범위

정의역에 어떤 조건이 부과된 상태에서 함수의 출력이 취할 수 있는 값의 범위를 구하는 문제입니다. 중3 이차함수의 응용 유형입니다.

## 정의

정의역 $D \subseteq \mathbb{R}$ 위에서 함수 $f$의 함숫값들이 이루는 집합 $f(D) = \{f(x) \mid x \in D\}$이 함수의 **치역**입니다. 조건부 함숫값의 범위는 이 치역을 구간 형태로 명시한 결과입니다.

이차함수에서는 꼭짓점의 위치와 정의역의 양 끝점을 비교해 결정합니다. 정의역이 닫힌구간이면 치역도 닫힌구간으로 표현됩니다.

## 예시

$f(x) = x^2 - 2x$의 정의역이 $-1 \le x \le 3$일 때 함숫값의 범위를 구해 봅니다. 표준형 $f(x) = (x-1)^2 - 1$, 꼭짓점은 $(1, -1)$이고 정의역에 포함됩니다.

끝점 값: $f(-1) = 1 + 2 = 3$, $f(3) = 9 - 6 = 3$. 꼭짓점 값: $f(1) = -1$. 따라서 함숫값의 범위는 $-1 \le f(x) \le 3$입니다.
