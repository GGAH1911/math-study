# 속도함수의 부호변화

## 정확한 진술

위치함수 $s(t)$의 도함수 $v(t) = s'(t)$를 속도함수라 합니다. 속도함수의 부호변화란 $v(t)$의 값이 양수에서 음수로, 또는 음수에서 양수로 바뀌는 현상을 말합니다. 즉, 어떤 시각 $t = a$에서 $v(a) = 0$이고 $t = a$를 기준으로 $v(t)$의 부호가 바뀔 때, "속도함수가 $t = a$에서 부호를 변화시킨다"고 표현합니다.

## 직관 및 기하적 의미

속도는 단순한 크기(속력)가 아닌 방향을 포함한 벡터 개념입니다. 일직선 운동에서 $v(t) > 0$이면 양의 방향(오른쪽, 위쪽 등)으로 움직이고, $v(t) < 0$이면 음의 방향(왼쪽, 아래쪽 등)으로 움직입니다. $v(t) = 0$인 시각은 물체가 순간적으로 멈추는 순간이며, 바로 이때 운동 방향이 바뀝니다. 

그래프 관점에서 $y = s(t)$ 위에서 속도함수의 부호변화는 곡선이 증가에서 감소로(또는 감소에서 증가로) 바뀌는 변곡점을 나타냅니다. $v(t) = 0$인 점은 $s(t)$의 극값을 가지는 위치입니다.

## 한 줄 예

$s(t) = t^3 - 3t$일 때, $v(t) = 3t^2 - 3 = 3(t-1)(t+1)$이므로 $t = -1$과 $t = 1$에서 속도함수가 0이 되며 부호가 변화합니다. ($t < -1$에서 양, $-1 < t < 1$에서 음, $t > 1$에서 양)
