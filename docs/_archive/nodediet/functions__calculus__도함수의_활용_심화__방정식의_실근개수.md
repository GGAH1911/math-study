# 방정식의 실근개수

## 정확한 진술

방정식의 실근개수란, 주어진 방정식 $f(x) = 0$을 만족하는 실수 $x$의 개수입니다. 이는 함수 $y = f(x)$의 그래프가 $x$축과 만나는 점의 개수와 같습니다. 도함수 $f'(x)$를 이용하여 함수의 극값과 개형을 파악하면, $x$축과의 교점 개수를 정확히 판정할 수 있습니다.

## 직관/기하적 의미

방정식 $f(x) = 0$의 실근개수를 판정하려면 함수 $f(x)$의 전체 개형을 알아야 합니다. 먼저 $f'(x) = 0$을 풀어 극값을 갖는 $x$값들을 찾고, 각 구간에서 함수의 증감을 조사합니다. 그 다음 극댓값과 극솟값의 부호를 확인합니다. 

- **극댓값이 양수이고 극솟값이 음수**이면, 함수의 그래프가 $x$축을 정확히 3번 가로지르므로 실근은 3개입니다.
- **극댓값과 극솟값이 같은 부호**이거나 한쪽이 0이면, 실근의 개수가 감소합니다.

3차 함수의 경우 도함수가 2차이므로, 극값을 최대 2개 가질 수 있고, 이를 통해 실근개수가 1개 또는 3개임을 알 수 있습니다.

## 한 줄 예

$f(x) = x^3 - 3x$일 때, $f'(x) = 3x^2 - 3 = 0$에서 $x = \pm 1$이고, $f(1) = -2 < 0$, $f(-1) = 2 > 0$이므로 실근은 3개입니다.
```
import sympy; x = sympy.Symbol('x'); print(sympy.solve(x**3 - 3*x, x))
```
