# 좌표공간의 점

## 정확한 진술

좌표공간(또는 3차원 직교좌표계)의 점은 **세 개의 실수 순서쌍** $(x, y, z)$로 나타냅니다. 이는 두 수직 수축(좌표축) $x$축, $y$축, $z$축이 원점 $O$에서 서로 수직으로 만나는 공간에서, 주어진 점 $P$에 대해:
- $x$좌표: $P$에서 $yz$평면까지의 (부호 있는) 거리
- $y$좌표: $P$에서 $xz$평면까지의 (부호 있는) 거리  
- $z$좌표: $P$에서 $xy$평면까지의 (부호 있는) 거리

로 정의되며, 점 $P$를 $P(x, y, z)$로 표기합니다.

## 직관/기하적 의미

평면좌표 $(x, y)$에서 출발한 것처럼, 좌표공간은 그것을 3차원으로 확장한 것입니다. 수평면(2D)의 격자에서처럼, 공간(3D)에서도 각 축을 따라 이동하면서 점의 위치를 표현할 수 있습니다. 

원점 $O(0, 0, 0)$에서 시작해 $x$축 방향으로 $a$, $y$축 방향으로 $b$, $z$축 방향으로 $c$만큼 이동하면 점 $(a, b, c)$에 도달합니다. 각 좌표의 부호는 축의 양의 방향(음의 방향)을 나타냅니다. 세 축이 만드는 8개의 영역을 **제1~8사분체(octant)**라 부르는데, 제1사분체는 $x > 0, y > 0, z > 0$인 영역입니다.

## 예

점 $P(2, 3, 1)$은 원점에서 $x$축 방향으로 2, $y$축 방향으로 3, $z$축 방향으로 1만큼 떨어진 곳에 있습니다. 

**축 위의 점들**: $x$축 위의 점은 $(a, 0, 0)$ 형태이고, $y$축 위는 $(0, b, 0)$, $z$축 위는 $(0, 0, c)$ 형태입니다. 예를 들어 $(3, 0, 0)$은 $x$축 위의 점, $(0, -2, 0)$은 $y$축의 음의 방향에 있는 점입니다.

**좌표평면 위의 점들**: $xy$평면(수평면) 위의 점은 $(a, b, 0)$ 형태이므로, 평면좌표처럼 다룰 수 있습니다.
