# 상용로그

## 정확한 진술

상용로그(common logarithm)는 밑이 10인 로그를 뜻합니다. $x > 0$일 때, 상용로그는 다음과 같이 정의됩니다:

$$\log_{10} x = \log x$$

(보통 밑 10을 생략하고 $\log x$로만 표기합니다.)

상용로그는 $10^y = x$를 만족하는 $y$의 값입니다. 예를 들어 $\log 1000 = 3$인 이유는 $10^3 = 1000$이기 때문입니다.

## 직관과 실용성

상용로그는 밑이 10이므로 우리의 십진법 숫자 체계와 완벽하게 맞아떨어집니다. 어떤 양수 $x$의 상용로그 $\log x$는 "$x$를 10의 몇 제곱으로 나타낼 수 있는가"라는 질문에 답합니다.

이는 실용적으로 매우 중요합니다. 예를 들어:
- 음향의 크기(데시벨), pH 척도(산성/염기성), 지진 규모(리히터 척도)는 모두 상용로그로 정의됩니다.
- 큰 수를 다룰 때 곱셈을 덧셈으로 바꿀 수 있어 계산을 단순화합니다.
- 어떤 수가 몇 자리 수인지 빠르게 파악할 수 있습니다. ($x$가 $n$자리 수면 $\lfloor \log x \rfloor = n-1$)

## 기본 성질과 예

$\log 10 = 1$, $\log 100 = 2$, $\log 0.1 = -1$

더 일반적으로, $\log x = a + b$ (단, $0 \le b < 1$)로 나타낼 때:
- 정수 부분 $a$: $x$가 $(10^a, 10^{a+1}]$ 사이에 있음을 의미
- 소수 부분 $b$: 자릿수 사이의 정확한 위치를 나타냄

**예:** $\log 250 \approx 2.398$ ⟹ $250$은 3자리 수 (검증: $10^{2.398} \approx 250$)
