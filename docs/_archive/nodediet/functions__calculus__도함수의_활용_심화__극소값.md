# 극소값

## 정확한 진술

함수 $f$가 $x = a$를 포함하는 어떤 열린 구간에서 정의될 때, 그 구간의 모든 $x$에 대하여 $f(x) \geq f(a)$가 성립하면 $f(a)$를 **극솟값**이라 하고, $x = a$를 **극소점**이라 합니다. 

도함수를 이용한 판정법: $f'(a) = 0$이고, $x = a$의 좌측에서 $f'(x) < 0$ (감소), 우측에서 $f'(x) > 0$ (증가)이면 $f(a)$는 극솟값입니다. 즉, 도함수가 음에서 양으로 변할 때입니다.

## 직관 및 기하적 의미

극솟값은 그래프 위의 "골짜기"에 해당합니다. 함수가 감소하다가 어느 지점에서 멈춘 후 다시 증가하는 지점이 극소점이고, 그 점의 함수값이 극솟값입니다. 

주의할 점은 극솟값이 **함수의 최솟값(절댓값)과 다르다**는 것입니다. 극소는 "주변에서" 가장 작은 값이지만, 극솟값보다 작은 함수값이 다른 곳에 존재할 수 있습니다. 예를 들어 3차 함수는 극소점을 2개 가질 수 있으며, 그 두 극솟값은 서로 다를 수 있습니다.

## 한 줄 예

$f(x) = x^3 - 3x$일 때, $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 $x = -1$에서 도함수가 음에서 양으로 변하고, 극솟값은 $f(-1) = (-1)^3 - 3(-1) = 2$입니다.

```python
# 검산: f(x) = x³ - 3x의 임계점과 극솟값 확인
# f'(-1) = 0이고 x < -1에서 f' > 0, x > -1에서 f' < 0이므로 극소
```

극댓값과 대비하여 암기하면, 도함수 부호 변화(음→양)만으로 극소를 판정할 수 있습니다.
