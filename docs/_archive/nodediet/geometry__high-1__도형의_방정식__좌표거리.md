# 좌표거리

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음 공식으로 정의합니다.

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

3차원 공간의 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 위 공식을 확장하여:

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

## 직관 및 기하적 의미

좌표거리 공식은 피타고라스 정리에서 비롯됩니다. 두 점 $A$에서 $B$로 가기 위해 가로로 $|x_2 - x_1|$, 세로로 $|y_2 - y_1|$만큼 이동한다고 생각하면, 이들이 직각삼각형의 두 직각변이 되고 선분 $AB$가 빗변이 됩니다. 따라서 빗변의 길이는 피타고라스 정리에 의해 위 공식으로 계산됩니다. 이처럼 좌표를 사용하여 기하학적 거리를 대수적으로 나타낼 수 있다는 점이 해석기하학의 강력함입니다.

## 계산 예제

두 점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리를 구하면:

$$d(A, B) = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

검증: `from math import sqrt; sqrt((4-1)**2 + (6-2)**2)` → 5.0

원점 $O(0, 0)$에서 점 $P(3, 4)$까지의 거리는 $d(O, P) = \sqrt{9 + 16} = 5$입니다.
