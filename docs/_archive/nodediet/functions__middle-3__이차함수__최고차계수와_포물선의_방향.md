# 최고차계수와 포물선의 방향

## 정확한 진술

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)에서 최고차계수 $a$의 부호는 포물선의 열림 방향을 결정합니다.

- $a > 0$이면 포물선은 **위로 열림** (아래로 볼록)
- $a < 0$이면 포물선은 **아래로 열림** (위로 볼록)

## 직관·기하적 의미

최고차계수 $a$는 $x$값이 커질수록 $x^2$항이 얼마나 빠르게 증가하는지를 제어합니다. 

$a > 0$인 경우, $|x|$가 커질수록 $ax^2$는 양수로 빠르게 증가합니다. 따라서 그래프는 꼭짓점을 최솟값으로 하며 양쪽으로 위로 올라갑니다. 반대로 $a < 0$인 경우, $|x|$가 커질수록 $ax^2$는 음수로 빠르게 감소하므로 꼭짓점이 최댓값이 되고 양쪽으로 아래로 내려갑니다.

**함수의 극값과의 연결:** $a > 0$이면 **최솟값 존재** (아래로 유계), $a < 0$이면 **최댓값 존재** (위로 유계)

## 한 줄 예

$y = 2x^2 - 4x + 1$은 $a = 2 > 0$이므로 위로 열린 포물선입니다.

**검증:** $x = 0$일 때 $y = 1$, $x = 1$일 때 $y = 2 - 4 + 1 = -1$, $x = 2$일 때 $y = 8 - 8 + 1 = 1$로, 꼭짓점(최솟값)을 지나 양쪽으로 상승하는 모양입니다. (`sympy.solve(diff(2*x**2 - 4*x + 1, x), x)` → $x = 1$이 최솟값 위치)
