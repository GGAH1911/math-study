# 정수해 조건

방정식 또는 부등식의 해 중 정수($\ldots, -2, -1, 0, 1, 2, \ldots$)인 것에 관한 조건을 다루는 문제 유형입니다. 고1 방정식과 부등식 단원에서 매개변수 결정 문제에 자주 등장합니다.

## 정의

부등식의 정수해의 개수는 실수 해집합 안에 들어 있는 정수의 개수입니다. 매개변수를 포함한 부등식 $f(x; k) \le 0$의 정수해의 개수에 대한 조건은 보통 다음 형태로 나타납니다.
- 정수해가 정확히 $m$개: 해집합의 양 끝점이 어떤 두 정수 사이에 놓여 있어야 함.
- 정수해가 무한히 많음: 해집합이 한쪽으로 무한히 뻗어 있어야 함.

## 예시

부등식 $|x - 3| \le k$의 정수해의 개수가 정확히 $5$개가 되는 자연수 $k$를 구해 봅니다. 해집합은 $3 - k \le x \le 3 + k$이고, 정수해는 $3 - k, \ldots, 3 + k$로 모두 $2k + 1$개입니다. $2k + 1 = 5$에서 $k = 2$입니다.

또한 부등식 $x^2 - 5x + k \le 0$이 정수해를 가지지 않으려면, 좌변의 판별식 $25 - 4k < 0$이어야 하므로 $k > \dfrac{25}{4}$, 즉 $k \ge 7$인 정수 $k$이면 충분합니다.
