# 도함수 관계식

## 정확한 진술

**도함수 관계식**이란 원함수 $f(x)$와 그 도함수 $f'(x)$ 사이에 성립하는 함수방정식입니다. 즉, $f(x)$와 $f'(x)$를 연결하는 조건식으로서, 

$$f'(x) = g(x)$$

형태이거나 혹은 

$$f(x) = f'(x) + h(x)$$

같이 두 함수가 만족해야 할 관계를 나타냅니다. 특히 고등학교에서는 원함수와 도함수가 특정한 조건을 동시에 만족할 때, 그 함수를 유일하게 결정하는 방정식을 다룹니다.

## 직관 및 기하적 의미

도함수는 함수의 **변화 속도**입니다. 도함수 관계식은 "함수가 어떻게 변하는가"를 기술하므로, 이를 통해 함수의 형태를 역으로 파악할 수 있습니다. 예를 들어 "$f'(x) = 2x$라면 $f(x)$는 어떤 함수일까?"라는 질문은 바로 도함수 관계식을 풀어 원함수를 찾는 과정입니다. 

또한 $f(x) = f'(x)$와 같은 관계식은 "함수 자체의 값이 그 변화 속도와 같다"는 특별한 성질을 나타내며, 이는 지수함수 $f(x) = Ce^x$처럼 성장이 극도로 빠른 함수의 특징입니다.

## 한 줄 예

$f'(x) = 3x^2 + 2$이고 $f(0) = 1$일 때, 도함수 관계식과 초기조건으로부터 $f(x) = x^3 + 2x + 1$을 결정할 수 있습니다.

(검증: `sympy.diff(x**3 + 2*x + 1, x)` → $3x^2 + 2$)
