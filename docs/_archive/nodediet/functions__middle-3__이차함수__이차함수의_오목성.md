# 이차함수의 오목성

## 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)에서 **오목성**은 이차항의 계수 $a$의 부호로 결정됩니다. $a > 0$이면 함수는 **아래로 볼록**(아래로 오목, 아래로 凹), $a < 0$이면 **위로 볼록**(위로 오목, 위로 凸)입니다.

## 직관과 기하적 의미

이차함수의 그래프는 항상 포물선 모양입니다. **아래로 볼록**일 때는 그릇처럼 아래로 펼쳐져 있으며, 꼭짓점에서 최솟값을 가집니다. 반대로 **위로 볼록**일 때는 뒤집은 그릇 모양으로 위로 솟아있으며, 꼭짓점에서 최댓값을 가집니다.

더 정확히는, 곡선 위의 임의의 두 점 $(x_1, f(x_1))$과 $(x_2, f(x_2))$를 잇는 현(割線)을 생각할 때:
- **아래로 볼록**: 현이 곡선 위쪽에 있습니다. 즉, 두 점 사이의 임의의 점 $x$에 대해 $f(x) \leq \frac{f(x_1) + f(x_2)}{2}$입니다 (위로 볼록한 경우와 부등호 방향이 반대).
- **위로 볼록**: 현이 곡선 아래쪽에 있습니다.

이 성질은 **이차함수의 볼록성**(convexity)과 일맥상통합니다.

## 한 줄 예

$f(x) = x^2$는 $a = 1 > 0$이므로 아래로 볼록하고, $g(x) = -2x^2 + 4x - 1$은 $a = -2 < 0$이므로 위로 볼록합니다.
