# 근의 활용

다항식의 근(영점)을 이용해 식의 값을 구하거나, 인수분해·나머지 정리 등에 적용하는 풀이 전략입니다. 고1 다항식 단원의 응용 개념입니다.

## 정의

다항식 $f(x)$의 근 $\alpha$는 $f(\alpha) = 0$을 만족시키는 값입니다. 이때 인수정리에 의해 $f(x)$는 $(x - \alpha)$를 인수로 가집니다. 따라서 $\alpha$가 근이라는 사실로부터 미지의 계수 또는 식의 값 사이의 관계식을 얻을 수 있습니다.

## 예시

$f(x) = x^3 - 2x^2 + ax + 6$이 $x = 1$을 근으로 가질 때 $a$를 구해 봅니다. $f(1) = 1 - 2 + a + 6 = 0$이므로 $a = -5$입니다.

또한 $f(x) = x^2 - 3x + 1$의 두 근을 $\alpha, \beta$라 하면 근과 계수의 관계로부터 $\alpha + \beta = 3$, $\alpha\beta = 1$이고, $\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = 9 - 2 = 7$입니다.
