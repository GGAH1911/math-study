# 그래프의 교점 개수

## 정확한 진술

두 함수 $f(x)$와 $g(x)$의 그래프가 만나는 점을 **교점**이라 합니다. 교점의 $x$좌표는 방정식 $f(x) = g(x)$의 해입니다. 따라서 **그래프의 교점 개수 = 방정식 $f(x) = g(x)$의 해의 개수**입니다.

## 직관/기하적 의미

그래프의 교점 개수를 구하는 것은 방정식의 해를 대수적으로 푸는 것과 같지만, **도함수의 활용**으로 더 효율적으로 판단할 수 있습니다. 예를 들어 $f(x) - g(x) = 0$의 해의 개수를 구해야 한다면, $h(x) = f(x) - g(x)$로 놓고 $h(x)$의 극값(극대, 극소)을 구한 후 $h(x)$가 $x$축과 만나는 횟수를 세면 됩니다.

**핵심 절차**:
1. $h(x) = f(x) - g(x)$로 정의
2. $h'(x) = 0$을 풀어 극값을 구함
3. 극값에서의 함수값 부호를 조사
4. 극값 사이에서 $h(x) = 0$의 해의 개수 결정

극값에서 함수값이 양수와 음수를 번갈아 가지면, 그 구간에 정확히 하나의 해가 존재합니다(중간값 정리).

## 한 줄 예

$f(x) = x^3 - 3x$와 $g(x) = x$의 교점 개수를 구하면, $h(x) = x^3 - 4x$이고 $h'(x) = 3x^2 - 4 = 0$에서 $x = \pm\frac{2}{\sqrt{3}}$입니다. 극값이 양음을 가지므로 교점은 **3개**입니다. (`sympy.solve(x**3 - 4*x, x)` → $[-2, 0, 2]$에서 확인)
