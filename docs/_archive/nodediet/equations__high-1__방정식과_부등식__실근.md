# 실근

## 정확한 진술

방정식 $f(x) = 0$의 **실근(real root)**은 이 방정식을 참으로 만드는 실수 값입니다. 즉, $x = a$가 실수이고 $f(a) = 0$을 만족할 때, $a$를 이 방정식의 실근이라고 부릅니다.

## 직관과 기하적 의미

그래프 관점에서, 실근은 함수 $y = f(x)$의 그래프가 $x$축과 만나는 점의 $x$좌표입니다. 예를 들어 이차함수 $f(x) = x^2 - 5x + 6$의 그래프를 그리면 $x = 2$와 $x = 3$에서 $x$축을 지나가는데, 이 두 점의 $x$좌표가 바로 실근입니다.

방정식이 실근을 몇 개 가지는지는 판별식으로 판단할 수 있습니다. 이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)에서 판별식 $D = b^2 - 4ac$에 따라:
- $D > 0$이면 서로 다른 두 실근
- $D = 0$이면 중근(하나의 실근)
- $D < 0$이면 실근이 없음 (복소수 범위의 허근만 존재)

## 한 줄 예

이차방정식 $x^2 - 5x + 6 = 0$을 풀면 $(x-2)(x-3) = 0$이므로 실근은 $x = 2, 3$입니다.

`sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`
