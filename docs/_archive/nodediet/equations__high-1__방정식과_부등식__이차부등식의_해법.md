# 이차부등식의 해법

이차식 $ax^2 + bx + c$의 부호를 판단해 부등식의 해를 구하는 절차입니다. 고1 방정식과 부등식 단원의 핵심 풀이 기법입니다.

## 정의

$a > 0$인 이차부등식 $ax^2 + bx + c > 0$의 해법은 판별식 $D = b^2 - 4ac$의 부호에 따라 다음과 같이 결정됩니다.
- $D > 0$: 서로 다른 두 실근 $\alpha < \beta$가 있고 해는 $x < \alpha$ 또는 $x > \beta$.
- $D = 0$: 중근 $\alpha$가 있고 해는 $x \neq \alpha$인 모든 실수.
- $D < 0$: 실근이 없고 해는 모든 실수.

부등호 방향이 $<$이거나 $a < 0$인 경우는 부호를 바꿔 같은 원리로 적용합니다. 풀이 시 좌변을 인수분해하거나 이차함수 그래프의 부호를 이용합니다.

## 예시

$x^2 - 5x + 6 > 0$을 풀어 봅니다. 좌변은 $(x-2)(x-3)$으로 인수분해되고, $a = 1 > 0$이므로 그래프는 아래로 볼록합니다. 따라서 두 근 사이에서는 음수, 바깥에서는 양수가 되므로 해는 $x < 2$ 또는 $x > 3$입니다.

또한 $x^2 - 4x + 5 < 0$은 판별식 $D = 16 - 20 = -4 < 0$이고 $a > 0$이므로 좌변이 항상 양수입니다. 따라서 해가 없습니다.
