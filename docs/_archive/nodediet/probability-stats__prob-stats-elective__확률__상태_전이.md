# 상태 전이

## 정확한 진술

어떤 시스템이 확률적으로 한 상태에서 다른 상태로 변하는 과정을 **상태 전이(state transition)**라고 합니다. 시간 $n$에 시스템이 상태 $i$에 있을 때, 시간 $n+1$에 상태 $j$로 전이할 확률을 **전이 확률** $P_{ij}$라 하면, 다음을 만족합니다:

$$P_{ij} \geq 0, \quad \sum_{j} P_{ij} = 1$$

모든 전이 확률을 정사각 행렬로 배열한 것을 **상태 전이 행렬(transition matrix)** 또는 **확률 행렬**이라 부르며, 각 행의 합은 항상 1입니다.

## 직관과 기하적 의미

상태 전이는 "현재 상태에만 의존하여 다음 상태가 결정되는" 현상입니다. 이를 **마르코프 성질(Markov property)**이라 하며, 과거의 경로나 이력은 미래 확률에 영향을 주지 않습니다. 예를 들어 "내일 날씨는 오늘 날씨에만 의존한다"는 의미입니다. 이 성질을 갖춘 시스템을 **마르코프 연쇄(Markov chain)**라 부르며, 수능 확률과통계와 심화 확률 문제에서 자주 다룹니다. 시간이 지남에 따라 상태 분포가 어떻게 변하는지를 추적하는 것이 핵심입니다.

## 한 줄 예

어떤 지역의 날씨 상태를 "맑음(A)", "흐림(B)" 두 가지로 분류하고, $P_{AA}=0.8$(오늘 맑으면 내일도 맑을 확률 80%), $P_{AB}=0.2$, $P_{BA}=0.3$, $P_{BB}=0.7$로 설정했을 때, 초기에 맑을 확률이 0.5라면 $n$일 후의 각 상태 확률을 계산하는 문제가 전형적인 상태 전이 응용입니다. (검산: `[[0.8, 0.2], [0.3, 0.7]]`의 거듭제곱으로 $n$단계 후 확률 계산)
