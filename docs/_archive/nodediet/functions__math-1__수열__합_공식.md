# 합 공식

## 정확한 진술

수열 $\{a_n\}$의 첫 항부터 제 $n$항까지의 합을 **부분합(partial sum)**이라 하고, 시그마 기호로 다음과 같이 나타냅니다:

$$S_n = a_1 + a_2 + a_3 + \cdots + a_n = \sum_{k=1}^{n} a_k$$

여기서 $S_n$은 수열의 처음 $n$개 항을 모두 더한 값입니다.

## 직관적 의미와 중요성

매달 저금액을 월말에 합계하거나, 시간에 따라 증가하는 인구를 누적 계산하는 등 현실에서 여러 값을 더하는 상황이 자주 등장합니다. 항이 10개, 100개, 1000개일 때마다 일일이 더하는 것은 비효율적입니다. 합 공식은 이러한 누적합을 간결하게 표현하고, 규칙을 찾아 복잡한 계산을 효율적으로 처리하도록 합니다. 특히 항의 개수가 많을수록 합 공식의 가치가 두드러집니다.

## 기본 예제

등차수열 $1, 2, 3, 4, 5$의 처음 5항의 합은:
$$S_5 = 1 + 2 + 3 + 4 + 5 = 15$$

이를 일반화하면 $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$ 공식으로 빠르게 계산할 수 있습니다. $n=5$일 때: $\frac{5 \times 6}{2} = 15$ (검증: `sum(range(1, 6))` → 15).
