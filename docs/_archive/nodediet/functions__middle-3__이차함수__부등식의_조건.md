# 부등식의 조건

## 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)에 대해 부등식 $f(x) > 0$ 또는 $f(x) < 0$이 모든 실수 $x$에서 성립하기 위한 필요충분조건은 다음과 같습니다:
- $f(x) > 0$이 항상 참: $a > 0$이고 판별식 $D = b^2 - 4ac < 0$
- $f(x) < 0$이 항상 참: $a < 0$이고 판별식 $D = b^2 - 4ac < 0$
- $f(x) \geq 0$ 또는 $f(x) \leq 0$이 항상 참: 위의 조건에서 $D \leq 0$ (등호 허용)

## 직관과 기하적 의미

이차함수의 그래프는 포물선입니다. 부등식이 모든 $x$에서 성립하려면 포물선이 $x$축과 만나지 않거나 접해야 합니다. 

$a > 0$이면 포물선이 위로 볼록하므로, 모든 점이 $x$축 위에 있으려면 $D < 0$이어야 합니다. $a < 0$이면 아래로 볼록하므로, 모든 점이 $x$축 아래에 있으려면 역시 $D < 0$이어야 합니다. 판별식이 음수일 때 실근이 없으므로, 포물선이 $x$축과 만나지 않는 것입니다.

## 한 줄 예

$x^2 - 2x + 3 > 0$이 모든 $x$에서 성립하는가? $a=1>0$이고, $D = 4 - 12 = -8 < 0$이므로 성립합니다.

## 응용 예제

$2x^2 - 4x + k > 0$이 모든 실수 $x$에서 성립하는 $k$의 범위를 구해봅시다. $a=2>0$이므로, 조건은 $D = 16 - 8k < 0$입니다. 따라서 $k > 2$입니다. (검산: `sympy.solve(16 - 8*k, k)` → $k = 2$)
