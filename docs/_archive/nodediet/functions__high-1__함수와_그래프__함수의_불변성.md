# 함수의 불변성

## 정확한 진술

함수 $f: X \to Y$에서 정의역에 속하는 같은 원소는 항상 같은 함숫값으로 대응되는 성질을 **함수의 불변성**이라고 합니다. 즉, $x_1 = x_2$이면 $f(x_1) = f(x_2)$가 반드시 성립합니다.

## 직관과 기하적 의미

함수의 불변성은 함수의 **결정성(deterministic nature)**을 나타냅니다. 한 번 함수가 정의되면, 특정 입력값 $x$에 대해 출력값 $f(x)$는 절대 바뀌지 않습니다. 그래프로 보면, 이는 **세로줄 검사(vertical line test)**를 통과한다는 뜻입니다. 정의역의 각 $x$값에서 수직선을 그었을 때 곡선과 정확히 한 점에서만 만나므로, 하나의 $x$에 여러 개의 $y$값이 대응될 수 없습니다.

## 구체적인 예

$f(x) = 2x - 3$ ($x \in \mathbb{R}$)에서:
- $x = 2$일 때 $f(2) = 1$
- 같은 $x = 2$를 다시 대입해도 $f(2) = 1$
- 이 대응관계는 변하지 않습니다.

반대로 $y^2 = x$는 함수가 아닙니다. $x = 4$일 때 $y = 2$ 또는 $y = -2$로 두 개의 값이 대응되기 때문입니다. (`sympy.solve(y**2 - 4, y)` → $[-2, 2]$)

## 중요한 역할

불변성은 함수의 기본 정의를 보장합니다. 이 성질이 없으면 함수를 식으로 계산할 수도, 예측할 수도 없습니다. 수능 문제에서 "다음은 함수인가?"를 판단할 때는 항상 이 불변성을 확인하세요.
