# 기하학적 구조

## 정확한 진술

수렴하는 수열의 **기하학적 구조**란 극한을 가지는 수열이 수렴값 주변에 어떻게 분포하는지를 나타냅니다. 수열 $\{a_n\}$이 $\alpha$로 수렴할 때, 임의의 양수 $\epsilon$에 대해, 충분히 큰 자연수 $N$이 존재하여 $n > N$인 모든 항이 구간 $(\alpha - \epsilon, \alpha + \epsilon)$ 안에 들어옵니다.

## 직관 및 기하적 의미

수직선 위에서 생각해보면, 수렴하는 수열의 항들은 수렴값을 중심으로 점점 더 조밀하게 모여듭니다. 극한값 $\alpha$를 중심으로 한 아무리 작은 구간을 택해도, 처음 몇 항을 제외한 나머지 모든 항이 그 구간 속에 갇혀 있다는 뜻입니다. 이것이 기하학적 구조의 본질이며, 극한의 정의를 "움직임"이 아닌 "공간적 배치"로 이해하게 합니다.

## 예시

수열 $a_n = 1 + \frac{1}{n}$을 생각해봅시다. 이 수열은 1로 수렴합니다:
- $a_1 = 2, a_2 = 1.5, a_3 = 1.33..., a_{10} = 1.1, a_{100} = 1.01, \ldots$

$\epsilon = 0.01$로 설정하면, 구간 $(0.99, 1.01)$ 안에 $a_{100}$부터 모든 항이 들어옵니다. $\epsilon$을 더 줄이면 필요한 $N$만 커질 뿐, 항상 어떤 $N$이 존재합니다.

**계산 예**: $\frac{1}{n} < 0.01 \Rightarrow n > 100$ 이므로 $N=100$
