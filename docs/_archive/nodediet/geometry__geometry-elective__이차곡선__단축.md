# 단축

## 정확한 진술

타원에서 **단축**(minor axis)은 두 주축 중 더 짧은 축을 의미합니다. 중심이 원점이고 표준형이 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b > 0$)인 타원에서, 장축이 $x$축일 때 단축은 $y$축이며, 단축의 길이는 $2b$이고 끝점은 $(0, b)$와 $(0, -b)$입니다. 장축과 단축은 항상 타원의 중심에서 직교합니다.

## 직관/기하적 의미

타원을 바라보면 수평 방향과 수직 방향의 '폭'이 다릅니다. 더 긴 방향을 장축, 더 짧은 방향을 단축이라 부르는데, 이 두 길이의 비율이 타원의 '찌그러진 정도'를 결정합니다. 원에서는 모든 방향의 반지름이 같아서 축을 구분할 필요가 없지만, 타원은 이 두 축을 함께 지정해야 완전하게 결정됩니다. 단축의 끝점들은 타원 위에서 장축의 끝점들까지의 거리가 최소가 되는 점들입니다.

## 한 줄 예

타원 $\frac{x^2}{36} + \frac{y^2}{16} = 1$에서 $a = 6, b = 4$이므로 장축 길이는 $12$, 단축 길이는 $8$이며, 단축의 끝점은 $(0, 4)$와 $(0, -4)$입니다.
