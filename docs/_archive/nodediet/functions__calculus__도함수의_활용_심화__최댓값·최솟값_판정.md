# 최댓값·최솟값 판정

## 정확한 진술

함수 $f(x)$가 $x = c$ 근처에서 미분가능할 때, $f'(c) = 0$ 또는 $f'(x)$가 정의되지 않는 점 $x = c$를 **임계점(critical point)**이라 합니다. 임계점에서 $f(x)$가 극값을 가지는지 판정하는 방법은 다음 두 가지입니다.

**1차 도함수 판정법**: 임계점 $x = c$의 좌우에서 $f'(x)$의 부호 변화를 조사합니다. $f'(x)$가 $x = c$에서 양에서 음으로 바뀌면 극댓값, 음에서 양으로 바뀌면 극솟값입니다. 부호가 바뀌지 않으면 극값이 아닙니다.

**2차 도함수 판정법**: 임계점 $x = c$에서 $f''(c) > 0$이면 극솟값, $f''(c) < 0$이면 극댓값입니다.

## 직관 및 기하적 의미

도함수는 함수의 순간변화율입니다. $f'(x)$의 부호가 바뀐다는 것은 함수가 증가에서 감소로(또는 그 반대로) 전환된다는 뜻이므로, 그 지점에서 봉우리나 골짜기가 생깁니다. 

2차 도함수 판정법은 더 빠릅니다. $f''(c) > 0$은 곡선이 아래로 볼록(위로 오목)이므로 최솟값을 가지고, $f''(c) < 0$은 위로 볼록(아래로 오목)이므로 최댓값을 가진다는 의미입니다.

## 예시

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 0$이므로 임계점은 $x = \pm 1$입니다.

1차 판정법: $x < -1$에서 $f'(x) > 0$, $-1 < x < 1$에서 $f'(x) < 0$이므로 $x = -1$에서 극댓값. $x = 1$ 좌우에서 $f'(x)$가 음에서 양으로 바뀌므로 극솟값입니다.

2차 판정법: $f''(x) = 6x$이므로 $f''(-1) = -6 < 0$ (극댓값), $f''(1) = 6 > 0$ (극솟값).

(검증: `[solve(3*x**2 - 3, x), (x**3 - 3*x).diff(x, 2).subs(x, -1), (x**3 - 3*x).diff(x, 2).subs(x, 1)]`)
