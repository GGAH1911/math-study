# 원소의 합

## 정확한 진술

유한집합 $A = \{a_1, a_2, \ldots, a_n\}$에 대해 **원소의 합**은 집합에 포함된 모든 원소를 더한 값입니다. 기호로는 $\sum_{a \in A} a$ 또는 $a_1 + a_2 + \cdots + a_n$으로 나타냅니다.

더 일반적으로, 조건 $P(x)$를 만족하는 집합의 원소들의 합은 $\sum_{x \in A, P(x)} x$로 표기합니다. 예를 들어 조건부 합 $\sum_{x \in A, x > 0} x$는 양수인 원소들만 더합니다.

## 직관 및 의미

원소의 합은 집합을 단순한 "모임"에서 "수량적 특성을 갖는 대상"으로 변환합니다. 집합은 원래 원소의 순서나 반복을 무시하지만, 합을 구할 때는 각 원소의 크기를 고려하게 됩니다. 이는 확률론(기댓값), 수열, 경우의 수 문제에서 중요합니다.

집합에서의 합은 순서가 없으므로, 덧셈의 교환법칙에 의해 어떤 순서로 더해도 같은 결과를 얻습니다. 따라서 집합의 표현 방식과 관계없이 원소의 합은 유일하게 결정됩니다.

## 한 줄 예

$A = \{2, 5, 8\}$일 때, $\sum_{a \in A} a = 2 + 5 + 8 = 15$ (검증: `sum([2, 5, 8])` = 15)

조건부: $B = \{-3, -1, 0, 2, 4\}$에서 음이 아닌 원소의 합은 $\sum_{b \in B, b \geq 0} b = 0 + 2 + 4 = 6$입니다.
