# 거리 관계식

## 정확한 진술

원뿔곡선(포물선, 타원, 쌍곡선)들은 초점(focus)과 준선(directrix), 또는 여러 초점들로부터의 거리 관계를 만족하는 점들의 자취로 정의됩니다.

**포물선**: 한 초점 $F$로부터의 거리와 준선 $l$로부터의 거리가 항상 같다.
$$|PF| = d(P, l)$$

**타원**: 두 초점 $F_1, F_2$로부터의 거리의 합이 일정하다.
$$|PF_1| + |PF_2| = 2a$$

**쌍곡선**: 두 초점 $F_1, F_2$로부터의 거리의 차의 절댓값이 일정하다.
$$\big||PF_1| - |PF_2|\big| = 2a$$

## 직관/기하적 의미

거리 관계식은 단순한 계산 규칙이 아니라, 곡선의 형태를 결정하는 본질적 조건입니다. 포물선의 경우, 초점에 가까워질수록 준선에서는 멀어져야 한다는 대칭성을 담고 있습니다. 타원은 거리의 합을 고정함으로써 두 초점을 중심으로 균형잡힌 폐곡선이 만들어집니다. 쌍곡선은 거리의 차를 고정함으로써, 한 초점에 가까워질수록 다른 초점에서는 멀어지는 두 개의 갈래진 곡선을 형성합니다. 이 거리 관계식들은 위성 궤도, 건축 설계, 광학 반사 등 실제 현상을 수학적으로 표현하는 데 근본적인 역할을 합니다.

## 한 줄 예

포물선 $y^2 = 4x$에서 초점은 $F(1, 0)$이고 준선은 $x = -1$입니다. 포물선 위의 점 $P(1, 2)$에서 초점까지의 거리는 $\sqrt{(1-1)^2 + (2-0)^2} = 2$이고, 준선까지의 거리도 $1 - (-1) = 2$로 같습니다. (검증: `sympy.sqrt((1-1)**2 + (2-0)**2)` = 2)
