# 각도 계산

## 정확한 진술

각도 계산은 도형의 꼭짓점에서 만나는 두 반직선이 이루는 각의 크기를 구하는 과정입니다. 고등학교 범위에서는 도형의 기본 성질(삼각형의 내각의 합, 사각형의 내각의 합, 원주각과 중심각의 관계 등)을 이용하여 직접 주어지지 않은 각도를 체계적으로 구합니다.

각도는 두 반직선의 상대적 위치를 나타내는 양으로, 일반적으로 $0°$부터 $360°$ 범위에서 측정합니다. 기본 관계식으로는 삼각형의 내각의 합이 $180°$, 사각형의 내각의 합이 $360°$ 등이 있으며, 이들을 기반으로 복합 도형의 각도를 계산합니다.

## 직관과 기하적 의미

각도 계산의 본질은 도형의 구조로부터 논리적으로 미지의 각을 찾아내는 것입니다. 예를 들어 삼각형 ABC에서 두 내각 $\angle A$, $\angle B$를 알면, $\angle C = 180° - \angle A - \angle B$로 자동으로 결정됩니다. 이는 평면의 기하학적 성질이 강하게 제약을 주기 때문입니다.

또한 대응각, 동위각, 엇각 등의 개념(평행선 조건)이나 원에 내접하는 각의 성질도 각도 계산에 자주 쓰입니다. 이들은 모두 도형이 만족해야 하는 **논리적 필연성**을 나타냅니다.

## 한 줄 예

삼각형에서 두 각이 $50°$, $60°$일 때, 남은 각은 $180° - 50° - 60° = 70°$입니다.

(검산: `sympy.solve(x + 50 + 60 - 180, x)` → `[70]`)
