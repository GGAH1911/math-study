# 원에 내접하는 점의 성질

## 정확한 진술

도형의 모든 꼭짓점이 한 원 위에 있을 때, 그 도형이 **원에 내접한다**고 하고, 이 원을 **외접원**이라고 합니다. 예를 들어 삼각형 ABC의 세 꼭짓점 A, B, C가 모두 원 O 위에 있으면, 삼각형 ABC는 원 O에 내접합니다.

특히 원에 내접하는 사각형의 경우, 다음이 성립합니다:
$$\text{대각의 합} = 180°$$

즉, 원에 내접하는 사각형 ABCD에서 $\angle A + \angle C = 180°$, $\angle B + \angle D = 180°$입니다.

## 직관/기하적 의미

원에 내접한다는 것은 모든 꼭짓점이 "같은 원 위에 정렬되어 있다"는 뜻입니다. 이렇게 배치되면 자동으로 특별한 각도 관계가 생깁니다.

같은 호에 대한 원주각들은 모두 같으므로, 한 호를 보는 원주각들은 어디서 보든 동일합니다. 원에 내접하는 사각형에서 대각의 합이 180°인 이유도 여기서 비롯됩니다. 호 AB를 보는 원주각 $\angle ACB$와 호 CD를 보는 원주각 $\angle CAD$를 조합하면, 대각 A와 C의 합이 정확히 반바퀴(180°)를 이루기 때문입니다.

## 한 줄 예

원 위의 네 점 A, B, C, D가 시계 반대 방향으로 배열되어 있을 때, 사각형 ABCD에서 $\angle DAB = 70°$이면 $\angle BCD = 110°$입니다. (대각의 합이 180°이므로)
