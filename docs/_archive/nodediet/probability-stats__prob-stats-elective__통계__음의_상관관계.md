# 음의 상관관계

## 정확한 진술

음의 상관관계(negative correlation)는 두 변수 $X$와 $Y$ 사이의 관계에서 한 변수가 증가할 때 다른 변수가 감소하는 경향을 보이는 것을 의미합니다. 통계적으로는 상관계수 $r$이 음수 값을 가질 때, 즉 $-1 \leq r < 0$일 때 음의 상관관계가 있다고 합니다.

## 직관과 기하적 의미

산점도(scatter plot)에 나타낸 데이터 점들의 분포를 보면, 음의 상관관계가 있는 두 변수는 우상향에서 좌하향으로 향하는 직선 같은 패턴을 이룹니다. $r = -1$에 가까울수록 더 강한 음의 선형 관계를 나타내며, $r = 0$에 가까워질수록 관계가 약해집니다. 예를 들어 $r = -0.9$는 매우 강한 음의 관계이고, $r = -0.3$은 약한 음의 관계입니다.

## 구체적 예시

외부 기온과 난방비의 관계를 생각해봅시다. 일반적으로 기온이 높아질수록(겨울에서 봄으로 변할수록) 난방비는 줄어듭니다. 이는 전형적인 음의 상관관계입니다.

여러 도시의 평균 기온(°C)과 난방비(만원)를 조사한 결과가 다음과 같다면:
- 기온: $[5, 10, 15, 20, 25]$
- 난방비: $[100, 80, 60, 40, 20]$

이 데이터의 상관계수는 $r = -1$이 되어 완벽한 음의 상관관계를 나타냅니다.
```python
# sympy 코드: np.corrcoef([5,10,15,20,25], [100,80,60,40,20])
# 결과: -1.0 (완벽한 음의 상관관계)
```

## 주의점

음의 상관관계가 있다고 해서 반드시 인과관계(원인과 결과)가 있는 것은 아닙니다. 기온과 난방비는 인과관계가 명백하지만, 다른 경우 두 변수가 모두 제3의 변수의 영향을 받을 수 있습니다.
