# 조건 만족 경우의 수

## 정확한 진술

조건을 만족하는 경우의 수는, 주어진 조건(사건)을 충족하는 모든 경우를 세는 것입니다. 일반적으로 "전체 경우의 수 중에서 조건 $C$를 만족하는 경우의 수는 몇 가지인가?"와 같이 표현됩니다. 수학적으로는, 표본공간 $S$의 부분집합 $A$(조건을 만족하는 경우들)의 원소 개수 $|A|$를 구하는 것입니다.

## 직관과 의미

경우의 수는 본질적으로 "집합의 원소 개수 세기"입니다. 조건이 없으면 가능한 모든 경우를 센다면, 조건이 주어지면 그 조건을 만족하는 경우들로만 범위가 좁혀집니다. 예를 들어, "주사위를 던진다"는 전체 경우(표본공간)에서 "6이 나온다"라는 조건을 추가하면, 가능한 경우는 단 1가지로 제한됩니다. 조건은 **표본공간에서 가능한 경우들을 필터링하는 역할**을 합니다.

## 기본 예제

**상황**: 주사위 두 개를 던질 때, 눈의 합이 7인 경우의 수는?

- 전체 경우의 수: $6 \times 6 = 36$가지
- 조건 "$X + Y = 7$"을 만족하는 경우: $(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)$ → **6가지**

검산: `sympy.symbols('x y'); [(x, y) for x in range(1, 7) for y in range(1, 7) if x + y == 7]`

조건이 강할수록(더 제한적일수록) 경우의 수는 작아집니다.
