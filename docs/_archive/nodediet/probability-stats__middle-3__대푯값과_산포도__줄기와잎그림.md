# 줄기와잎그림

## 정확한 진술

줄기와잎그림은 자료를 두 부분으로 나누어 표현하는 통계 그래프입니다. 각 데이터를 **줄기**(stem)와 **잎**(leaf)으로 분리합니다. 예를 들어 23이라는 값은 줄기 2, 잎 3으로 표현됩니다. 줄기는 십의 자리 이상을 나타내고, 잎은 일의 자리를 나타내는 것이 일반적입니다.

줄기와잎그림의 구성 방법:
- 세로축에 줄기를 작은 값부터 큰 값 순서대로 배열
- 각 줄기의 오른쪽에 해당하는 잎들을 작은 값부터 큰 값 순서대로 표시
- 필요시 줄기를 양쪽으로 나누어 표현 가능(뒷잎은 왼쪽, 앞잎은 오른쪽)

## 직관과 활용

줄기와잎그림의 가장 큰 장점은 **원래 데이터를 보존하면서도 분포를 한눈에 파악**할 수 있다는 점입니다. 히스토그램처럼 도수만 보여주는 것이 아니라, 실제 값들을 볼 수 있어 자료의 특성을 더 정확히 이해할 수 있습니다.

또한 중앙값, 사분위수 같은 대푯값을 직접 읽을 수 있습니다. 자료가 어느 구간에 집중되어 있는지, 이상값(아웃라이어)이 있는지도 쉽게 발견할 수 있으므로 탐색적 자료 분석에 매우 유용합니다.

## 한 줄 예

학생 10명의 수학 시험 점수 $64, 68, 71, 73, 75, 78, 81, 82, 88, 92$를 줄기와잎그림으로 나타내면, 줄기 6에 4와 8, 줄기 7에 1, 3, 5, 8, 줄기 8에 1, 2, 8, 줄기 9에 2가 배열됩니다.
