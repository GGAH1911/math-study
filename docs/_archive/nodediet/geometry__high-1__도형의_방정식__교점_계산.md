# 교점 계산

## 정확한 진술

두 도형의 **교점(intersection point)**은 두 도형을 나타내는 방정식을 동시에 만족하는 점입니다. 예를 들어 직선 $y = 2x + 1$과 원 $x^2 + y^2 = 5$의 교점은 두 방정식을 모두 만족하는 점 $(x, y)$입니다. 

교점을 구하려면 두 도형의 방정식을 연립방정식으로 풀어서 해를 찾습니다. 직선과 원의 경우처럼 한 방정식을 다른 방정식에 대입하여 정리하면, 보통 일변수 방정식(1차, 2차 등)으로 축약되고, 이를 풀면 교점의 좌표를 얻습니다.

## 직관/기하적 의미

좌표평면 위에 두 도형을 그렸을 때, 두 그래프가 만나는 점이 바로 교점입니다. 이는 두 도형의 방정식을 동시에 만족하는 유일한 해석입니다. 

- 직선과 원이 만나면 교점은 0개, 1개, 또는 2개입니다(원의 위치에 따라).
- 두 직선이 만나면 보통 1개 교점(평행하지 않은 경우) 또는 무수히 많은 교점(일치하는 경우)을 갖습니다.
- 두 포물선이 만나면 최대 4개 교점을 가질 수 있습니다.

교점의 개수는 연립방정식의 해의 개수로 결정됩니다.

## 한 줄 예

직선 $y = x + 1$과 원 $x^2 + y^2 = 2$의 교점: 첫 번째 식을 두 번째 식에 대입하면 $x^2 + (x+1)^2 = 2$ → $2x^2 + 2x - 1 = 0$ → $x = \frac{-1 \pm \sqrt{3}}{2}$ (sympy: `solve([y - (x + 1), x**2 + y**2 - 2], [x, y])`)
