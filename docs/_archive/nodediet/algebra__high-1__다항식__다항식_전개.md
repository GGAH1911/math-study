# 다항식 전개

## 정확한 진술

다항식 전개(polynomial expansion)란 괄호로 묶인 여러 다항식의 곱을 분배법칙으로 전개하여 하나의 표준 다항식으로 나타내는 과정입니다. 예를 들어 $(x+2)(x+3)$을 전개하면:
$$
(x+2)(x+3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6
$$
이는 분배법칙을 이용해 모든 항들의 곱을 계산하고, 같은 차수의 항들을 모아서(combine like terms) 정리한 결과입니다. 일반적으로 최고차항부터 낮은 차수로 정렬하여 표기합니다.

## 직관 및 의미

다항식 전개는 **복잡한 곱셈 형태를 단순한 합 형태로 변환**하여 다항식의 구조를 명확하게 드러냅니다. 전개된 형태에서는 최고차 계수와 상수항을 한눈에 파악할 수 있고, 근의 공식이나 판별식을 적용하기 위해 $ax^2 + bx + c$ 꼴로 정리할 수 있으며, 미분·적분에서 각 항의 계수를 다루기 훨씬 편합니다.

곱셈 공식—예: $(a+b)^2 = a^2 + 2ab + b^2$, $(a-b)^2 = a^2 - 2ab + b^2$, $(a+b)(a-b) = a^2 - b^2$—은 자주 나타나는 전개 패턴으로, 이들을 암기하면 수능 계산 속도가 크게 빨라집니다. 기하적으로는 직사각형의 넓이를 여러 사각형 조각으로 나누어 계산하는 면적 분배 아이디어와도 맥락이 같습니다.

## 예

$(x+1)(x+2) = x^2 + 2x + x + 2 = x^2 + 3x + 2$

이 계산은 `sympy.expand((x+1)*(x+2))`로도 검증할 수 있습니다. 더 복잡한 식 $(x-2)^3$을 전개하려면 곱셈 공식을 활용하거나 $(x-2)(x-2)(x-2)$로 단계적으로 전개합니다.
