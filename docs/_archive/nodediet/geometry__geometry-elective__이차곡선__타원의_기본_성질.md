# 타원의 기본 성질

## 정확한 진술

**타원**(ellipse)은 평면 위의 두 점(초점, focus)으로부터의 거리의 합이 항상 일정한 점들의 자취입니다. 두 초점을 $F$, $F'$이라 하고, 거리의 합을 $2a$ (단, $a > 0$)라 하면:

$$\{P \mid |PF| + |PF'| = 2a\}$$

두 초점 사이의 거리를 $2c$ (단, $0 < c < a$)라 할 때, 타원의 **표준형 방정식**은:

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0, \, b^2 = a^2 - c^2)$$

여기서 $a$는 장축의 반길이, $b$는 단축의 반길이입니다.

## 직관/기하적 의미

타원은 두 초점을 "중심"처럼 잡아끌어서 원을 늘인 도형입니다. 두 초점이 일치하면 ($c = 0$) 원이 되고, 두 초점이 멀어질수록 타원은 더 길쭉해집니다. 

실생활에서는 행성의 공전 궤도(케플러 법칙)나 음향 거울에서 나타나는데, 한쪽 초점에서 나는 소리가 다른 초점으로 모이는 성질을 이용합니다.

**이심률**(eccentricity) $e = \frac{c}{a}$는 타원의 찌그러진 정도를 나타냅니다. $0 < e < 1$이며, $e$가 0에 가까울수록 원에 가깝고, 1에 가까울수록 더 길쭉해집니다.

## 한 줄 예

초점이 $F(-3, 0)$, $F'(3, 0)$이고 거리의 합이 $2a = 10$인 타원은 $\frac{x^2}{25} + \frac{y^2}{16} = 1$입니다. (왜냐하면 $a=5$, $c=3$, $b^2=25-9=16$)
