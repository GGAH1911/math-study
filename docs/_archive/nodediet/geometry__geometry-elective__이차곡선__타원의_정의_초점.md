# 타원의 정의 초점

## 정확한 진술

두 점 $F_1$, $F_2$(초점)로부터의 거리의 합이 일정한 점 $P$의 자취를 **타원**이라 한다. 즉, $|PF_1| + |PF_2| = 2a$ (단, $2a$는 상수, $2a > |F_1F_2|$)를 만족하는 모든 점 $P$의 집합이다. 

두 초점 사이의 거리를 $2c$라 하면 ($c \geq 0$), 관계식 $a^2 = b^2 + c^2$이 성립한다. 여기서 $a$는 반장축, $b$는 반단축의 길이이다.

## 직관과 기하적 의미

초점이 일직선상에 있을 때, 줄의 양 끝을 두 초점에 고정하고 펜으로 줄을 팽팽하게 당기면서 그린 도형이 타원입니다. 이것이 타원의 가장 직관적인 설명입니다.

거리의 합이 일정하다는 조건은 타원이 닫힌 곡선이며 두 초점에 대해 대칭임을 보장합니다. $2a$가 클수록 타원이 커지고, 두 초점이 멀어질수록(즉, $c$가 클수록) 타원은 더 납작해집니다. 극단적으로 $c = 0$이면 두 초점이 한 점에서 만나 원이 되고, $c \to a$이면 선분에 가까워집니다.

좌표계에서 원점을 중심으로 초점이 $x$축 위에 있다면, 표준형 방정식은 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ (단, $a > b > 0$)입니다.

## 한 줄 예

초점이 $(-3, 0)$, $(3, 0)$이고 거리의 합이 10인 타원: $2a = 10 \Rightarrow a = 5$, $c = 3 \Rightarrow b^2 = 25 - 9 = 16$이므로 방정식은 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$입니다. (검증: `sympy: Ellipse(Point(0,0), 5, 4).foci` → $[Point(-3,0), Point(3,0)]$ ✓)
