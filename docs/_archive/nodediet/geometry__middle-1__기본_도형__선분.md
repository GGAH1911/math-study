# 선분

두 점을 양 끝으로 하는 곧은 도형으로, 직선의 일부분입니다. 중1 기본 도형 단원에서 도형의 가장 기본 구성요소입니다.

## 정의

서로 다른 두 점 $\mathrm{A}, \mathrm{B}$를 양 끝점으로 하고 그 사이를 곧게 잇는 도형을 **선분 $\mathrm{AB}$**라 하고 $\overline{\mathrm{AB}}$로 표기합니다. 이는 두 점 사이의 직선의 일부이며, 양 끝점을 모두 포함합니다.

선분의 길이는 두 점 사이의 거리를 의미하며 양수입니다. 좌표평면 위에서 $\mathrm{A}(x_1, y_1), \mathrm{B}(x_2, y_2)$일 때
$$\overline{\mathrm{AB}} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.$$

선분의 **중점**은 두 끝점에서 같은 거리에 있는 선분 위의 점, 곧 $\dfrac{1}{2}(\mathrm{A} + \mathrm{B})$입니다.

## 예시

두 점 $\mathrm{A}(1, 2), \mathrm{B}(7, 10)$에 대해 선분 $\overline{\mathrm{AB}}$의 길이는
$$\sqrt{36 + 64} = 10.$$
중점은 $\left(\dfrac{1+7}{2}, \dfrac{2+10}{2}\right) = (4, 6)$입니다.
