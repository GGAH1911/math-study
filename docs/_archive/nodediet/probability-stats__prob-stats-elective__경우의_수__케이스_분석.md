# 케이스 분석

## 정확한 진술

**케이스 분석**은 복잡한 경우의 수 문제를 상호배타적(겹치지 않는)인 여러 **경우들로 나누어**, 각 경우의 수를 따로 센 후 모두 더하는 방법입니다. 즉, 전체 집합을 서로 겹치지 않는 부분집합들로 분할한 뒤
$$\text{전체} = \text{경우1} + \text{경우2} + \cdots + \text{경우n}$$
의 형태로 계산합니다.

## 직관과 의미

어떤 상황에서는 모든 경우를 한 번에 세기 어렵습니다. 예를 들어 "A는 반드시 포함되고, B는 포함되지 않으면서..." 같은 조건이 섞여 있을 때가 그렇습니다. 이럴 때 조건의 만족 여부, 특정 원소의 포함 여부, 또는 값의 대소 관계 등을 기준으로 **상황을 나누면**, 각 나뉜 경우는 단순한 곱셈 원리나 조합으로 계산할 수 있습니다. 

중요한 것은:
- 나뉜 경우들이 **서로 겹치지 않아야** 합니다 (상호배타).
- 나뉜 경우들이 **모든 상황을 포함해야** 합니다 (완전성).

이 두 조건이 만족되면 더한 값이 정확한 답입니다.

## 한 줄 예

6명을 일렬로 배열하되, 홀수 번째 자리 3개에 남학생만 오는 경우의 수를 구하려면, "남학생이 모두 다 홀수 번째에 올 수 없을 수도 있다"는 생각에서 케이스를 나눕니다:
- **경우 1**: 남학생 3명이 모두 홀수 자리를 채우는 경우
- **경우 2**: 남학생 2명이 홀수 자리를 채우는 경우  
- **경우 3**: 남학생 1명이 홀수 자리를 채우는 경우

각각을 따로 계산한 후 더하면 됩니다.
