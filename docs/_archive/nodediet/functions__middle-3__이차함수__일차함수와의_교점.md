# 일차함수와의 교점

## 정확한 진술

이차함수와 일차함수의 교점(交點)이란, 두 함수의 그래프가 만나는 점을 말합니다. 이차함수 $y = ax^2 + bx + c$와 일차함수 $y = mx + n$이 만나는 점을 찾으려면, 두 식을 같다고 놓으면 됩니다:

$$ax^2 + bx + c = mx + n$$

이를 정리하면 다음의 이차방정식을 얻습니다:

$$ax^2 + (b-m)x + (c-n) = 0$$

이 방정식의 해가 교점의 $x$좌표이고, 각 $x$ 값을 원래 함수에 대입하면 $y$좌표를 구할 수 있습니다.

## 직관과 기하적 의미

이차함수는 포물선, 일차함수는 직선이므로, 교점은 직선이 포물선과 만나는 지점입니다. 위의 이차방정식의 판별식 $D = (b-m)^2 - 4a(c-n)$에 따라:

- **$D > 0$**: 두 개의 교점 (직선이 포물선을 관통)
- **$D = 0$**: 한 개의 교점 (직선이 포물선에 접함)  
- **$D < 0$**: 교점이 없음 (직선과 포물선이 만나지 않음)

## 한 줄 예

이차함수 $y = x^2 - 3x + 2$와 일차함수 $y = x - 1$의 교점을 구하면: $x^2 - 3x + 2 = x - 1$에서 $x^2 - 4x + 3 = 0$, $(x-1)(x-3) = 0$이므로 $x = 1, 3$. 교점은 $(1, 0)$과 $(3, 2)$입니다. (검증: `sympy.solve(x**2 - 4*x + 3, x)` → `[1, 3]`)
