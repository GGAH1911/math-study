# 직선의 절편

## 정확한 진술

직선이 $x$축과 만나는 점의 $x$좌표를 **$x$절편**, $y$축과 만나는 점의 $y$좌표를 **$y$절편**이라고 합니다. 직선의 방정식이 $ax + by + c = 0$ (단, $a, b \neq 0$)일 때, $x$절편은 $y = 0$을 대입하여 구하고, $y$절편은 $x = 0$을 대입하여 구합니다.

## 직관 및 기하적 의미

직선을 좌표평면에 그렸을 때 절편은 그 직선의 "위치"를 가장 간단하게 표현하는 정보입니다. $x$절편은 직선이 수평축과 만나는 지점, $y$절편은 직선이 수직축과 만나는 지점이므로, 두 값만 알면 직선의 개형을 빠르게 파악할 수 있습니다. 특히 절편 형태의 직선 방정식 $\frac{x}{a} + \frac{y}{b} = 1$ (단, $a, b \neq 0$)은 $x$절편이 $a$, $y$절편이 $b$임을 명시적으로 보여줍니다.

## 한 줄 예

직선 $2x + 3y - 6 = 0$에서 $y = 0$을 대입하면 $x = 3$ ($x$절편), $x = 0$을 대입하면 $y = 2$ ($y$절편)입니다.

## 계산 확인

```
# 직선 2x + 3y - 6 = 0의 절편
# sympy.solve([2*x + 3*0 - 6], x) → [3]
# sympy.solve([2*0 + 3*y - 6], y) → [2]
```
