# 근의개수

## 정확한 진술

**근의 개수**는 주어진 방정식 $f(x) = 0$ (또는 $f(x) = g(x)$)을 만족하는 실근이 몇 개인지를 나타냅니다. 도함수를 이용하여 함수의 극값과 개형을 파악하면, 그래프와 $x$축(또는 다른 곡선)의 교점 개수로부터 근의 개수를 정확하게 판단할 수 있습니다.

## 직관과 기하적 의미

도함수 $f'(x)$는 함수 $f(x)$의 증감을 알려줍니다. $f'(x) = 0$인 점에서 함수는 극값을 가지며, 이를 통해 함수의 대략적인 모양을 그릴 수 있습니다. 방정식 $f(x) = 0$의 근의 개수는 $f(x)$의 그래프가 $x$축과 만나는 점의 개수와 같습니다. 따라서:

- 극댓값이 양수이고 극솟값이 음수이면 근은 3개
- 극댓값과 극솟값이 모두 양수이면 근은 1개 (또는 0개)
- 극댓값이 0이거나 극솟값이 0이면 근은 2개

이렇게 극값을 조사하는 것이 근의 개수를 판정하는 핵심입니다.

## 한 줄 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 극댓값은 $f(-1) = 2$, 극솟값은 $f(1) = -2$입니다. 극댓값과 극솟값이 부호가 반대이므로 $f(x) = 0$은 **근 3개**를 가집니다. (검증: `sympy.solve(x**3 - 3*x, x)`)
