# 공간 좌표계

## 정확한 진술

공간좌표계(또는 3차원 좌표계)는 원점 O를 중심으로 서로 직각을 이루는 세 개의 수직선 x축, y축, z축으로 이루어진 좌표 체계입니다. 공간의 임의의 점 P는 순서쌍 $(x, y, z)$로 유일하게 나타내어지며, 각각 x축, y축, z축 위의 좌표값입니다.

## 직관과 기하적 의미

평면좌표계에서 (x, y) 두 개의 수로 2차원 평면의 점을 결정했듯이, 공간좌표계는 세 개의 수로 3차원 공간의 점을 결정합니다. 세 축은 모두 원점에서 서로 직각으로 만나며, 일반적으로 오른손 좌표계(오른손 손가락을 x축에서 y축 방향으로 구부렸을 때 엄지손가락이 z축 양의 방향)를 사용합니다. 공간의 한 점의 위치를 정확히 지정하려면 이 세 개의 좌표값이 필요합니다.

## 거리 공식

두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 피타고라스 정리를 3차원으로 확장하여:
$$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

## 예제

점 $A(1, 0, 0)$과 $B(4, 4, 12)$ 사이의 거리를 구하면:
$$|AB| = \sqrt{(4-1)^2 + (4-0)^2 + (12-0)^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13$$

검산: `sympy.sqrt((4-1)**2 + (4-0)**2 + (12-0)**2)` → 13
