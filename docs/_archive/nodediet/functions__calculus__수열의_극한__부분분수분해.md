# 부분분수분해

## 정확한 진술

부분분수분해(部分分數分解)는 하나의 유리함수를 여러 개의 더 단순한 유리함수들의 합으로 표현하는 기법입니다. 분자의 차수가 분모의 차수보다 작은 진분수 유리식 $\frac{P(x)}{Q(x)}$에 대해, 분모 $Q(x)$를 일차 및 이차 인수로 인수분해한 뒤, 각 인수에 대응하는 부분분수들의 합으로 나타냅니다. 분모에 $(x-a)$라는 일차 인수가 있으면 $\frac{A}{x-a}$ 형태의 항이 생기고, $(x-a)^2$라는 중근이 있으면 $\frac{A}{x-a} + \frac{B}{(x-a)^2}$ 형태가 되며, $(x^2+bx+c)$ 같은 인수분해 불가능한 이차식이 있으면 $\frac{Bx+C}{x^2+bx+c}$ 형태가 됩니다.

## 직관과 필요성

복잡한 하나의 분수식을 더 간단한 분수들의 합으로 분해하면, 각각을 개별적으로 다룰 수 있다는 가장 큰 장점이 있습니다. 특히 적분에서 $\int \frac{1}{x-a} dx = \ln|x-a| + C$ 같은 기본 공식들을 직접 적용할 수 있어, 처음에는 복잡해 보이는 유리함수의 적분도 체계적으로 풀 수 있습니다. 또한 급수의 합을 구할 때 망원급수(telescoping series) 기법과 결합하면 매우 강력한 도구가 됩니다.

## 간단한 예

$$\frac{5x-7}{(x-1)(x-3)} = \frac{A}{x-1} + \frac{B}{x-3}$$

양변에 $(x-1)(x-3)$을 곱하면 $5x-7 = A(x-3) + B(x-1)$입니다. $x=1$을 대입하면 $A=1$, $x=3$을 대입하면 $B=4$를 얻습니다. 따라서 원래 식은 $\frac{1}{x-1} + \frac{4}{x-3}$로 분해됩니다.
