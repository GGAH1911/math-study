# 중첩식

## 정확한 진술

**중첩식**은 분자 또는 분모, 또는 근호 안에 다시 같은 형태의 식이 포함된 식입니다. 가장 흔한 예는 중첩된 제곱근입니다. 예를 들어 $\sqrt{a + \sqrt{b}}$나 $\sqrt{a - \sqrt{b}}$ 형태처럼, 근호 안의 식 안에 또 다른 근호가 있는 경우를 말합니다. 더 일반적으로는 분수의 분자나 분모가 같은 구조를 반복하는 경우도 포함됩니다.

## 직관과 기하적 의미

중첩식이 자주 나타나는 이유는 **제곱근 형태를 단순화하거나 역함수를 다룰 때** 자연스럽게 생기기 때문입니다. 예를 들어 방정식 $x = \sqrt{2 + x}$를 풀 때, $x$를 대입하면 $x = \sqrt{2 + \sqrt{2 + \sqrt{2 + \cdots}}}$ 형태의 무한 중첩식이 나타납니다. 

기하적으로는 도형의 반복 구조에서도 나타납니다. 또한 삼각함수의 반각 공식이나 특정 기하 계산에서 이 형태가 자연스럽게 유도되며, 이는 측정이 **자기 닮음 구조를 가진** 현상을 다룰 때 핵심입니다.

## 한 줄 예

$\sqrt{5 + \sqrt{24}}$를 간단히 하면 $\sqrt{3} + \sqrt{2}$가 됩니다. (확인: $(\sqrt{3} + \sqrt{2})^2 = 3 + 2\sqrt{6} + 2 = 5 + 2\sqrt{6}$이므로, $\sqrt{5 + 2\sqrt{6}} = \sqrt{3} + \sqrt{2}$)
