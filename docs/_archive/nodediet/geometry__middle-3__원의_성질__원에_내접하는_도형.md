# 원에 내접하는 도형

## 정확한 진술

어떤 도형의 모든 꼭짓점이 한 원 위에 있을 때, 그 도형을 **원에 내접하는 도형**이라고 합니다. 이 원을 **외접원(circumcircle)**이라 하며, 도형이 원에 내접한다는 것은 도형의 외접원이 존재한다는 의미입니다.

특히 다각형의 경우, $n$각형의 모든 꼭짓점이 원 위에 있으면 그 $n$각형을 **원에 내접하는 $n$각형** 또는 **내접 $n$각형**이라 부릅니다.

## 직관/기하적 의미

원에 내접하는 도형은 매우 특별한 성질을 가집니다. 특히 원에 내접하는 사각형은 **대각의 합이 $180°$**라는 중요한 성질을 갖습니다:
$$\angle A + \angle C = 180°, \quad \angle B + \angle D = 180°$$

이 성질은 원에 내접하는 도형이 얼마나 제한적인지를 보여줍니다. 모든 사각형이 원에 내접할 수 있는 것은 아니며, 오직 대각의 합이 $180°$인 사각형만 원에 내접합니다.

또한 원에 내접하는 삼각형은 모든 삼각형을 의미합니다. 왜냐하면 임의의 세 점이 일직선상에 있지 않으면 항상 유일한 외접원이 존재하기 때문입니다.

## 한 줄 예

직각삼각형은 항상 원에 내접하며, 외접원의 지름은 빗변과 같습니다(탈레스 정리). 정사각형이나 정삼각형도 당연히 원에 내접하는 도형입니다.
