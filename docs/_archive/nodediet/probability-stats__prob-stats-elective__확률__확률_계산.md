# 확률 계산

## 정확한 진술

어떤 사건 $A$가 일어날 확률은 다음과 같이 계산합니다:

$$P(A) = \frac{\text{사건 } A\text{가 일어나는 경우의 수}}{\text{표본공간의 전체 경우의 수}}$$

사건 $A$의 경우의 수를 $n(A)$, 표본공간 $S$의 경우의 수를 $n(S)$로 나타내면:

$$P(A) = \frac{n(A)}{n(S)}$$

이 공식은 **표본공간의 모든 경우가 같은 확률로 나타날 때**(근원사건이 동등할 때)만 적용됩니다. 이를 **고전적 확률**이라 부릅니다.

## 직관과 의미

확률 계산의 본질은 **비율**입니다. 동전을 던질 때 앞면이 나올 확률이 $\frac{1}{2}$라는 것은, 동전을 충분히 많이 던지면 전체 시행의 절반 정도에서 앞면이 나타난다는 의미입니다.

분자는 우리가 원하는 결과에 해당하는 경우가 몇 가지인지, 분모는 일어날 수 있는 모든 결과가 몇 가지인지를 세는 것입니다. **정확한 경우의 수 계산이 확률 문제의 핵심**입니다. 이를 위해 곱의 법칙, 조합, 순열 등을 활용합니다.

## 기본 예시

빨간 공 2개, 파란 공 3개가 들어 있는 주머니에서 공을 하나 꺼낼 때 빨간 공이 나올 확률:
- 전체 경우: $n(S) = 2 + 3 = 5$
- 사건(빨간 공): $n(A) = 2$
- 확률: $P(A) = \dfrac{2}{5}$
