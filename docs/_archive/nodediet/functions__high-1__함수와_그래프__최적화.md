# 최적화

## 정의

**최적화(optimization)**는 주어진 조건(제약) 하에서 특정 함수의 최댓값 또는 최솟값을 구하는 과정입니다. 즉, 함수 $f(x)$가 가장 크거나 작아지는 $x$의 값과 그때의 함수값을 찾는 것입니다.

구간 $[a, b]$ 위에서 연속함수의 최댓값과 최솟값은 다음 중 하나에서 나타납니다:
- 구간의 끝점: $x = a, b$
- 극값점: $f'(x) = 0$을 만족하는 점들

## 직관과 기하적 의미

최적화는 현실 문제와 밀접하게 연결되어 있습니다. 기업이 이익을 최대화하려 하거나, 배송 경로의 거리를 최소화하려 하거나, 건축에서 재료를 절약하면서 강도를 최대한 유지하려 할 때 모두 최적화 문제입니다.

함수의 그래프로 보면, 최댓값은 '가장 높은 점', 최솟값은 '가장 낮은 점'입니다. 미분을 통해 도함수가 0인 점들을 찾으면 극값 후보를 얻고, 이들과 끝점을 비교하여 최댓값과 최솟값을 결정합니다.

## 예: 직사각형의 넓이 최대화

둘레가 20인 직사각형 중 넓이가 최대인 것을 찾으세요.

가로를 $x$라 하면 세로는 $10 - x$ (단, $0 < x < 10$)이고, 넓이는:
$$f(x) = x(10-x) = 10x - x^2$$

도함수를 구하면:
$$f'(x) = 10 - 2x = 0 \implies x = 5$$

$f(5) = 25$이 최댓값이므로, **정사각형(한 변 5)일 때 넓이가 최대**입니다.

`sympy.solve(10 - 2*x, x)` → $[5]$
