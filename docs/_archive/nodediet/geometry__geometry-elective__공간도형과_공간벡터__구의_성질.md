# 구의 성질

## 정확한 진술

공간 내 한 점을 중심으로 하여, 그 점으로부터의 거리가 항상 같은 모든 점들의 집합을 **구(sphere)**라고 합니다. 중심을 $O$, 반지름을 $r$ $(r > 0)$이라 하면, 구 위의 임의의 점 $P$는 $\overline{OP} = r$을 만족합니다.

좌표계에서 중심이 $(a, b, c)$이고 반지름이 $r$인 구의 방정식은
$$( x - a )^2 + ( y - b )^2 + ( z - c )^2 = r^2$$
입니다. 특히 중심이 원점인 경우 $x^2 + y^2 + z^2 = r^2$로 간단해집니다.

## 직관과 기하적 의미

구는 평면 위의 원을 3차원으로 확장한 개념입니다. 원이 2차원에서 중심으로부터 같은 거리의 점들이라면, 구는 3차원에서 중심으로부터 같은 거리의 모든 점들을 모은 것입니다.

구의 핵심 성질은 **완전한 대칭성**입니다. 중심을 지나는 어떤 축으로 회전시켜도 모양이 변하지 않으며, 중심을 지나는 모든 평면에 대해 대칭입니다. 따라서 구와 평면의 교선은 항상 원이 됩니다.

구는 주어진 표면적 내에서 최대 부피를 갖는 도형이므로 자연과 공학에서 빈번히 나타납니다.

## 한 줄 예

중심이 $(1, 2, 3)$이고 반지름이 $5$인 구의 방정식은 $(x - 1)^2 + (y - 2)^2 + (z - 3)^2 = 25$이며, 예를 들어 점 $(4, 6, 7)$은 $(4-1)^2 + (6-2)^2 + (7-3)^2 = 9 + 16 + 16 = 41 \neq 25$이므로 이 구 위에 있지 않습니다.
