# 기하학적 관계식

닮음·피타고라스 정리로부터 얻는 변의 길이와 비례 관계식들의 모음입니다. 중2 닮음과 피타고라스 단원의 핵심 도구입니다.

## 정의

- **피타고라스 정리:** 직각삼각형의 빗변의 길이가 $c$, 다른 두 변의 길이가 $a, b$이면
$$a^2 + b^2 = c^2.$$
- **닮음의 변의 길이 비:** 두 도형이 닮음비 $k : 1$이면 대응 변의 길이의 비도 $k : 1$.
- **닮음 삼각형의 넓이의 비:** 닮음비가 $k : 1$이면 넓이의 비는 $k^2 : 1$.
- **직각삼각형의 닮음 관계식:** 빗변에 내린 수선이 빗변을 $p, q$로 나누면 수선의 길이 $h$와의 관계는 $h^2 = pq$이고, 변과의 관계는 $a^2 = pc, b^2 = qc$.

## 예시

직각삼각형에서 두 변이 $3, 4$이면 빗변은 $\sqrt{9 + 16} = 5$입니다.

또한 빗변이 $13$이고 한 변이 $5$인 직각삼각형의 다른 변은 $\sqrt{169 - 25} = 12$입니다.
