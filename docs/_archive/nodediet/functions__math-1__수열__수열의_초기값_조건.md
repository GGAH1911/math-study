# 수열의 초기값 조건

## 정확한 진술

**초기값 조건**(initial condition)은 수열의 첫 번째 항의 값을 명시하는 조건입니다. 점화식으로 정의된 수열 $\{a_n\}$에서 재귀 관계만으로는 모든 항을 결정할 수 없으므로, 반드시 하나 이상의 초기값(예: $a_1$)을 주어야 수열이 유일하게 결정됩니다.

예를 들어, 점화식 $a_{n+1} = 2a_n$만으로는 수열을 정할 수 없지만, "$a_1 = 3$"이라는 초기값 조건을 추가하면 $\{a_n\} = 3, 6, 12, 24, \ldots$로 유일하게 결정됩니다.

## 직관과 역할

점화식은 각 항과 다음 항의 **관계**만 나타내므로, 출발점이 없으면 수열 전체를 생성할 수 없습니다. 초기값 조건은 이 출발점을 제공합니다. 마치 도미노를 쌓을 때 첫 번째 도미노를 정하는 것처럼, 초기값이 정해져야 뒷부분이 연쇄적으로 결정되는 것입니다.

**고차 점화식의 경우**: $a_{n+2} = a_{n+1} + a_n$ (피보나치 수열처럼) 같은 2차 점화식은 초기값 **두 개**가 필요합니다. 일반적으로 $k$차 점화식은 정확히 $k$개의 초기값이 필요합니다.

## 한 줄 예

점화식 $a_{n+1} = a_n + 2$와 초기값 $a_1 = 5$가 주어지면, $a_2 = 7, a_3 = 9, \ldots$이므로 $a_n = 2n + 3$ (Python: `[2*n + 3 for n in range(1, 5)]` → `[5, 7, 9, 11]`).
