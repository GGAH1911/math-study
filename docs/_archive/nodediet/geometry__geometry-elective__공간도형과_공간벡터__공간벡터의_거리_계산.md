# 공간벡터의 거리 계산

## 정확한 진술

좌표평면에서 거리를 피타고라스 정리로 구하듯이, 3차원 공간에서도 두 점 사이의 거리를 정의합니다. 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 다음과 같습니다.

$$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

또는 벡터로 표현하면, 벡터 $\vec{a} = (a_1, a_2, a_3)$의 크기(거리)는

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

이고, 두 벡터 $\vec{a}$, $\vec{b}$의 **거리**는 $|\vec{a} - \vec{b}|$로 정의합니다.

## 직관과 기하적 의미

평면에서 두 점의 거리 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$는 밑변과 높이가 $|x_2-x_1|$, $|y_2-y_1|$인 직각삼각형의 빗변입니다. 공간에서도 같은 논리가 적용되는데, 이번엔 3개의 직각변 $|x_2-x_1|$, $|y_2-y_1|$, $|z_2-z_1|$을 가진 직육면체의 대각선 길이입니다. 피타고라스 정리를 3차원으로 확장한 것이므로, 거리 공식의 세제곱근들이 제곱하여 더해지는 구조를 봅시다.

벡터의 크기는 원점에서 점 $(a_1, a_2, a_3)$까지의 거리이며, 두 벡터의 차이를 거리로 재면 평행이동되지 않은 "벡터 사이의 떨어짐"을 측정하게 됩니다.

## 한 줄 예

$A(1, 2, 3)$과 $B(4, 6, 15)$ 사이의 거리는 $\sqrt{(4-1)^2 + (6-2)^2 + (15-3)^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13$입니다.
