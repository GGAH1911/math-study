# 함수의 기본 개념

두 집합 사이의 대응 규칙 중 "각 입력에 정확히 하나의 출력이 대응되는 것"을 가리키는 개념입니다. 고1 함수와 그래프 단원의 출발점입니다.

## 정의

두 집합 $X, Y$에 대하여 $X$의 각 원소 $x$에 $Y$의 단 하나의 원소 $y$를 대응시키는 규칙 $f$를 **함수**라 하고 $f : X \to Y$로 씁니다.
- $X$를 **정의역**, $Y$를 **공역**, $\{f(x) \mid x \in X\}$를 **치역**이라 합니다.
- 함수가 같다는 것은 정의역과 공역이 같고, 모든 $x$에서 $f(x) = g(x)$가 성립한다는 의미입니다.

## 예시

대응 "각 실수 $x$에 $x^2$을 대응"은 함수이며 $f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2$입니다. 정의역은 $\mathbb{R}$, 공역은 $\mathbb{R}$, 치역은 $[0, \infty)$.

반면 대응 "각 양의 실수 $x$에 $\pm\sqrt{x}$를 대응"은 한 입력에 두 출력이 대응되므로 함수가 아닙니다.
