# 원소

집합을 구성하는 각각의 대상을 가리키는 개념입니다. 고1 집합과 명제 단원의 가장 기본 용어입니다.

## 정의

어떤 집합 $A$를 구성하는 하나하나의 대상을 $A$의 **원소**라 합니다. $a$가 집합 $A$의 원소일 때
$$a \in A$$
로 표기하고 "$a$는 $A$에 속한다"라고 읽습니다. 반대로 속하지 않으면 $a \notin A$.

집합은 그 원소들이 명확히 결정되어야 합니다(원소의 결정성). 같은 원소가 여러 번 나오는 것이나 원소들의 순서는 집합의 정체성과 무관합니다.

## 예시

집합 $A = \{1, 2, 3\}$에 대하여 $1 \in A$, $2 \in A$이지만 $4 \notin A$입니다.

또한 집합 $B = \{x \mid x\text{는 } 10\text{의 양의 약수}\} = \{1, 2, 5, 10\}$이므로 $5 \in B$, $3 \notin B$입니다.
