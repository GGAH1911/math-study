# 구의 성질과 접조건

## 정확한 진술

공간에서 한 점 $C$로부터 일정한 거리 $r$ (단, $r > 0$)에 있는 모든 점들의 집합을 **구(sphere)**라 하고, 점 $C$를 중심, $r$을 반지름이라 합니다.

중심이 점 $C(a, b, c)$이고 반지름이 $r$인 구의 방정식은
$$
(x-a)^2 + (y-b)^2 + (z-c)^2 = r^2
$$
입니다. 특히 원점을 중심으로 하고 반지름이 $r$인 구는 $x^2 + y^2 + z^2 = r^2$으로 나타납니다.

## 직관/기하적 의미

구는 평면에서의 원을 3차원 공간으로 확장한 개념입니다. 중심으로부터 모든 방향으로 같은 거리에 있는 점들의 궤적이므로, 공간에서 가장 대칭성이 높은 도형입니다.

평면 $\pi$와 구의 위치 관계를 판단하는 **접조건**은 중심 $C$에서 평면까지의 최단거리 $d$로 결정됩니다:
- $d > r$: 평면과 구는 만나지 않음
- $d = r$: 평면이 구에 **접함** (접점은 1개)
- $d < r$: 평면이 구를 자름 (교선은 원)

특히 평면이 구에 접할 때, 중심 $C$에서 평면에 내린 수선의 발이 바로 접점입니다.

## 한 줄 예

중심이 $(1, 2, 3)$이고 반지름이 $5$인 구에서, 평면 $x + 2y + 2z = 13$까지의 거리는 $\frac{|1+4+6-13|}{\sqrt{1+4+4}} = \frac{2}{3} < 5$이므로 평면은 구를 자릅니다. (`sympy`: 중심에서 평면까지 거리 계산 → $d = |1(1) + 2(2) + 2(3) - 13|/\sqrt{9} = 2/3$)
