# 등차수열의 정의와 성질

## 정의

**등차수열**(arithmetic sequence)은 인접한 두 항의 차이가 항상 일정한 수열입니다.

수열 $\{a_n\}$이 등차수열이라는 것은 어떤 상수 $d$에 대하여 모든 양의 정수 $n$에서 다음을 만족한다는 뜻입니다:

$$a_{n+1} - a_n = d$$

여기서 $d$를 **공차**(common difference)라고 부릅니다. 첫 항을 $a_1$이라 하면, 등차수열은 $a_1, a_1+d, a_1+2d, a_1+3d, \ldots$ 형태로 전개됩니다.

## 직관과 의미

등차수열은 일정한 간격으로 증가하거나 감소하는 수열입니다. 수직선 위에 나타내면 등차수열의 각 항은 일정한 거리만큼 떨어져 있습니다. 예를 들어 $d > 0$이면 수열이 증가하고, $d < 0$이면 감소하며, $d = 0$이면 모든 항이 같은 상수수열입니다.

**일반항 공식**: $n$번째 항은 다음과 같이 직접 계산할 수 있습니다:
$$a_n = a_1 + (n-1)d$$

이는 첫 항에서 시작하여 공차를 $(n-1)$번 더하는 구조입니다.

## 기본 성질

**등차수열의 합(부분합)**: 첫 $n$개 항의 합 $S_n$은 다음과 같습니다:
$$S_n = \frac{n}{2}(a_1 + a_n) = \frac{n}{2}(2a_1 + (n-1)d)$$

**대칭성**: 등차수열에서 시작과 끝으로부터 같은 거리에 있는 두 항의 합은 항상 같습니다. 즉, $a_1 + a_n = a_2 + a_{n-1} = \cdots$입니다.

## 예시

수열 $2, 5, 8, 11, 14, \ldots$를 생각해봅시다.
- 첫 항: $a_1 = 2$
- 공차: $d = 5 - 2 = 3$
- 10번째 항: $a_{10} = 2 + (10-1) \times 3 = 2 + 27 = 29$
- 처음 10개 항의 합: $S_{10} = \frac{10}{2}(2 + 29) = 5 \times 31 = 155$

(검산: `sympy.solve(symbols('d'); [2, 5, 8])` 또는 직접 계산으로 $d=3$ 확인)
