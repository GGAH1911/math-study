# 조건부 상수 결정

## 정확한 진술

**조건부 상수 결정**이란, 함수식에 포함된 미지의 상수들(계수)을 그 함수가 만족해야 하는 주어진 조건들을 이용하여 구체적으로 구하는 절차입니다.

일반적으로 다항함수 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$는 $(n+1)$개의 계수를 가지므로, 함수를 완전히 결정하려면 $(n+1)$개의 독립적인 조건이 필요합니다. 이 조건들은 다음과 같은 형태입니다:
- **점의 조건**: 함수가 특정 점 $(p, q)$를 지남 → $f(p) = q$
- **극값 조건**: $x = p$에서 극값을 가짐 → $f'(p) = 0$
- **기울기 조건**: 특정 점에서의 미분값이 $m$ → $f'(p) = m$
- **특수값 조건**: $f(a) = b$, $f'(c) = d$ 등 여러 식

## 직관 및 기하적 의미

그래프는 수많은 점들로 이루어져 있지만, 그 모양을 결정하는 것은 계수뿐입니다. 주어진 조건들은 "이 함수의 그래프가 만족해야 할 기하학적 제약"을 수식으로 표현한 것입니다. 조건부 상수 결정은 이 제약들을 모두 만족하는 유일한 함수를 찾는 과정—즉, 연립방정식을 세우고 푸는 것입니다.

예를 들어, 이차함수가 세 점을 지난다는 조건 3개는 이차함수의 3개 계수를 모두 결정하기에 충분하며, 그 결과로 유일한 이차함수가 정해집니다.

## 한 줄 예

이차함수 $f(x) = ax^2 + bx + c$가 점 $(0, 1)$, $(1, 0)$, $(2, 3)$을 지날 때: 각 점을 대입하면 $c = 1$, $a + b + 1 = 0$, $4a + 2b + 1 = 3$ 이 되고, 연립방정식을 풀어 $a = 1, b = -2, c = 1$을 결정합니다. (sympy.solve([a+b+1, 4*a+2*b-2], [a,b]))
