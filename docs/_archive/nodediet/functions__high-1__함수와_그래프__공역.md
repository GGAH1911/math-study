# 공역

함숫값들이 속할 수 있는 집합을 가리키는 개념으로, 함수의 정의에 함께 명시되는 구성요소입니다. 고1 함수와 그래프 단원의 기본 용어입니다.

## 정의

함수 $f : X \to Y$에서 정의역 $X$는 입력값들의 집합, **공역** $Y$는 출력값이 속할 수 있는 집합입니다. 한편 실제 함숫값들의 집합 $f(X) = \{f(x) \mid x \in X\}$를 **치역**이라 하며 항상 $f(X) \subseteq Y$가 성립합니다.

공역은 함수의 정의에 의해 미리 지정되는 반면 치역은 함수의 작용에 의해 결정됩니다. 일반적으로 공역과 치역은 같지 않을 수 있습니다.

## 예시

함수 $f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2$을 봅니다. 공역은 $\mathbb{R}$ 전체이지만 치역은 $[0, \infty)$로 공역의 진부분집합입니다.

같은 대응이라도 공역을 $[0, \infty)$로 잡으면 함수 $g : \mathbb{R} \to [0, \infty)$, $g(x) = x^2$이 되어 공역과 치역이 일치하는 함수가 됩니다.
