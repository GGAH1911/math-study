# 두 직선의 교점

## 정확한 진술

두 직선 $L_1: a_1x + b_1y + c_1 = 0$과 $L_2: a_2x + b_2y + c_2 = 0$이 있을 때, **두 직선의 교점**은 두 방정식을 동시에 만족하는 점 $(x_0, y_0)$입니다. 즉, 다음 연립방정식의 해입니다:

$$\begin{cases} a_1x + b_1y + c_1 = 0 \\ a_2x + b_2y + c_2 = 0 \end{cases}$$

이 연립방정식이 유일한 해를 가지려면 두 직선이 평행하지 않아야 하므로, 계수의 비가 같지 않아야 합니다: $\dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2}$ (단, 분모가 0이 아닐 때).

## 직관·기하적 의미

좌표평면에 그려진 두 직선이 만나는 점이 바로 교점입니다. 두 직선이 일반적인 위치에 있으면 정확히 한 점에서 만나고, 이 점의 좌표를 구하는 것은 두 직선을 나타내는 일차방정식들을 동시에 풀이하는 것과 같습니다. 교점의 $x$좌표와 $y$좌표는 각 직선 위의 점이 만족해야 할 조건을 모두 충족합니다.

## 예시

직선 $2x + y = 5$와 직선 $x - y = 1$의 교점을 구해봅시다.

$$\begin{cases} 2x + y = 5 \\ x - y = 1 \end{cases}$$

두 식을 더하면 $3x = 6$이므로 $x = 2$. 이를 첫 번째 식에 대입하면 $4 + y = 5$에서 $y = 1$. 따라서 교점은 $(2, 1)$입니다.

검증: `sympy.solve([2*x + y - 5, x - y - 1], [x, y])`는 $\{x: 2, y: 1\}$을 반환합니다.
