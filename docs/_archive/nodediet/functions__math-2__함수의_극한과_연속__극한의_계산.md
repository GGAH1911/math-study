# 극한의 계산

## 정확한 진술

함수 $f(x)$에서 $x$가 어떤 값 $a$에 가까워질 때, $f(x)$가 수렴하는 값을 **극한값**이라 하며 $\lim_{x \to a} f(x) = L$로 나타냅니다. **극한의 계산**은 이 극한값 $L$을 구하는 과정과 방법들을 의미합니다. 극한값이 존재한다는 것은, $x$가 $a$에 얼마나 가까워지든 $f(x)$가 어떤 한 값 $L$에 임의로 가까워진다는 뜻입니다.

## 직관과 의미

극한의 계산은 함수의 **연속적인 행동**을 파악하는 도구입니다. 실제로 계산할 때는 $x = a$를 직접 대입하거나, 0으로 나누는 꼴 $\frac{0}{0}$을 피하기 위해 인수분해, 유리화, 함수의 성질 등을 활용합니다. 기하학적으로는 그래프 위에서 어떤 점에 가까워질 때 함수값이 어디로 수렴하는지를 보는 것입니다. 극한 계산이 중요한 이유는 함수의 미분·적분 정의가 모두 극한에 기반하기 때문입니다.

## 한 줄 예

$\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$는 $x = 2$를 대입하면 $\frac{0}{0}$이지만, 분자를 인수분해하면 $\frac{(x+2)(x-2)}{x-2} = x + 2$이고, 따라서 극한값은 $\lim_{x \to 2} (x + 2) = 4$입니다. (검증: `sympy.limit((x**2 - 4)/(x - 2), x, 2)`)
