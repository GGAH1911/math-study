# 두 점의 만남 조건

## 정확한 진술
$t$를 매개변수로 하여 주어진 두 점의 위치가 매개변수 함수로 표현될 때, 어떤 시각 $t = t_0$에서 두 점의 모든 좌표가 일치하면 두 점이 **만난다**고 정의합니다. 평면에서는
$$P(t_0) = (x_1(t_0), y_1(t_0)), \quad Q(t_0) = (x_2(t_0), y_2(t_0))$$
일 때 $x_1(t_0) = x_2(t_0)$이고 $y_1(t_0) = y_2(t_0)$를 동시에 만족해야 합니다. 직선(일차원)에서는 두 점이 같은 위치 함수값을 가질 때, 즉 $s_1(t_0) = s_2(t_0)$일 때 만난다고 합니다.

## 직관/기하적 의미
두 점이 각각의 궤적을 따라 시간에 따라 이동할 때, 어떤 순간에 정확히 같은 위치에 도달하는 경우를 두 점의 만남이라고 합니다. 두 곡선이 단순히 교차하는 것이 아니라, **같은 시각에** 두 점이 교점에 있어야 만나는 것입니다. 이는 정적분을 이용해 위치를 정의한 문제에서 자주 등장합니다. 예를 들어 속도를 적분하여 위치를 구할 때, 두 점의 위치 함수가 같아지는 순간이 바로 두 점의 만남입니다. 수능 기출에서는 종종 두 점이 "처음으로 만나는 순간" 또는 "다시 만나는 순간"을 찾는 문제로 출제됩니다.

## 한 줄 예
점 P가 시간 $t$에서 위치 $f(t) = t^2 - 3t$에, 점 Q가 위치 $g(t) = 2t$에 있다면, $f(t) = g(t)$, 즉 $t^2 - 5t = 0$을 풀어 $t = 0$ 또는 $t = 5$에서 만납니다. (`sympy.solve(t**2 - 5*t, t)` → `[0, 5]`)
