# 지수 방정식

## 정확한 진술

지수 방정식이란 지수에 미지수를 포함하는 방정식입니다. 일반적으로 $a^{f(x)} = b$ 형태이거나, 양변에 모두 지수식이 나타나는 $a^{f(x)} = a^{g(x)}$ 형태로 나타납니다. 여기서 $a$는 1이 아닌 양수(밑)이고, $f(x)$, $g(x)$는 $x$를 포함한 식입니다.

## 직관과 구조

지수 방정식의 핵심은 **밑이 같으면 지수가 같다**는 원리입니다. 예를 들어 $2^3 = 2^{x}$라는 식이 있다면, 8 = $2^x$이므로 지수 3과 $x$가 반드시 같아야 합니다. 이것이 지수 방정식을 푸는 가장 기본적인 전략입니다.

더 복잡한 경우, $2^x = 8$처럼 우변을 같은 밑의 거듭제곱 형태로 만들 수 있습니다. 8을 $2^3$으로 바꾸면 $2^x = 2^3$이 되어 $x = 3$을 얻습니다. 만약 밑으로 통일할 수 없다면, 양변에 로그를 취하는 방법을 사용합니다. 예를 들어 $2^x = 5$일 때, $x = \log_2 5$가 해입니다.

지수 함수는 밑이 1이 아닌 양수일 때 일대일 대응(일반적으로 전사 함수는 아니지만 정의역과 치역 내에서 역함수가 존재)이기 때문에, 두 지수값이 같다는 것은 지수 자체가 같다는 뜻입니다.

## 한 줄 예

$3^{x-1} = 27$에서 $27 = 3^3$이므로, $3^{x-1} = 3^3$이 되어 $x - 1 = 3$, 따라서 $x = 4$입니다.
