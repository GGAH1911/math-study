# 도함수 조건의 활용

## 정확한 진술

함수 $f(x)$가 $x = a$를 포함하는 구간에서 미분가능할 때, **도함수의 부호 변화**로부터 함수의 극값과 단조성을 판정할 수 있다. 구체적으로:

- $x = a$ 좌측에서 $f'(x) > 0$이고 우측에서 $f'(x) < 0$이면, $f(x)$는 $x = a$에서 **극대**
- $x = a$ 좌측에서 $f'(x) < 0$이고 우측에서 $f'(x) > 0$이면, $x = a$에서 **극소**
- 구간 $(a, b)$에서 $f'(x) > 0$이면 $f(x)$는 $(a, b)$에서 **증가**
- 구간 $(a, b)$에서 $f'(x) < 0$이면 $f(x)$는 $(a, b)$에서 **감소**

## 직관/기하적 의미

도함수는 그 점에서 접선의 기울기이다. 기울기가 양수일 때는 함수가 올라가고, 음수일 때는 내려간다. 기울기가 부호를 바꾸는 지점, 즉 $f'(x) = 0$인 점이 극값의 후보가 된다. 이는 함수의 "방향성"을 도함수가 제어한다는 의미이며, 도함수 조건을 확인하면 함수의 전체 개형을 알 수 있다.

## 한 줄 예

$f(x) = x^3 - 3x$일 때, $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 $x = -1$에서 극대, $x = 1$에서 극소이다. (검산: `sympy.diff(x**3 - 3*x, x)` → $3x^2 - 3$)
