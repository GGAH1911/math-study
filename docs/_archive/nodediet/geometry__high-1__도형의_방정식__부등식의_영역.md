# 부등식의 영역

좌표평면에서 부등식을 만족하는 점들의 집합을 가리키는 영역입니다. 고1 도형의 방정식 단원에서 직선·원·이차곡선의 위치 관계를 시각적으로 다루는 도구입니다.

## 정의

좌표평면에서 부등식 $f(x, y) > 0$의 해집합은 곡선 $f(x, y) = 0$로 나누어진 평면의 영역 중 부등식이 성립하는 쪽 영역입니다.

- **직선 부등식 $ax + by + c > 0$:** 직선 $ax + by + c = 0$의 한쪽 반평면.
- **원 부등식 $(x - a)^2 + (y - b)^2 < r^2$:** 중심 $(a, b)$, 반지름 $r$인 원의 내부.
- **부등식의 연립:** 각 부등식의 영역의 공통부분(교집합).

영역을 그릴 때 등호가 포함되면 경계선을 실선, 포함되지 않으면 점선으로 표시합니다.

## 예시

연립부등식 $\begin{cases} x + y \le 4 \\ x \ge 0 \\ y \ge 0 \end{cases}$의 영역은 좌표평면의 제1사분면에서 직선 $x + y = 4$ 이하의 부분입니다. 이는 꼭짓점이 $(0, 0), (4, 0), (0, 4)$인 직각삼각형 내부와 그 경계입니다.
