# 극소 판정

## 정확한 진술

함수 $f(x)$가 점 $x = a$에서 **극솟값**을 가지는지를 판정하는 방법을 **극소 판정**이라 합니다.

**1차 도함수 판정법:** $f'(a) = 0$이고, $x = a$의 좌측에서 $f'(x) < 0$, 우측에서 $f'(x) > 0$이면 $f(x)$는 $x = a$에서 극솟값을 가집니다.

**2차 도함수 판정법:** $f'(a) = 0$이고 $f''(a) > 0$이면 $f(x)$는 $x = a$에서 극솟값을 가집니다.

## 직관/기하적 의미

1차 판정법으로 생각해봅시다. $f'(x) < 0$이면 함수가 감소하고, $f'(x) > 0$이면 함수가 증가합니다. 따라서 $x = a$를 기준으로 왼쪽에서는 내려가다가 오른쪽에서 올라간다면, $x = a$는 그래프 위의 가장 낮은 지점—즉 극솟값—입니다.

2차 판정법은 더 간결합니다. $f''(a) > 0$은 $x = a$ 근처에서 함수의 그래프가 아래로 볼록하다는 의미이므로, $f'(a) = 0$인 순간 접선이 수평인 지점은 자동으로 극솟값입니다.

## 계산 예시

$f(x) = x^2 - 4x + 3$을 살펴봅시다.

- $f'(x) = 2x - 4$이므로 $f'(x) = 0$에서 $x = 2$
- $f''(x) = 2 > 0$이므로 2차 판정법에 의해 $x = 2$에서 극솟값
- 극솟값은 $f(2) = 4 - 8 + 3 = -1$

(검산: `sympy.solve(2*x - 4, x)` → $x = 2$)
