# 여사건의 확률

## 정확한 진술

어떤 사건 $A$에 대해, 사건 $A$가 **일어나지 않는 경우**를 사건 $A$의 **여사건**이라 하며, $A^c$ 또는 $\overline{A}$로 표기합니다. 여사건의 확률은 다음과 같습니다:

$$P(A^c) = 1 - P(A)$$

이는 전체 확률이 1이고, 사건 $A$와 여사건 $A^c$가 서로 배반(겹치지 않음)이며 합쳐지면 전체 표본공간이 되기 때문입니다.

## 직관과 의미

표본공간의 모든 경우의 수를 100%라고 생각하면, 사건 $A$가 일어날 확률이 $P(A)$이면, $A$가 일어나지 않을 확률은 자동으로 $1 - P(A)$입니다. 여사건은 "그 외 모든 경우"를 의미하므로, 여사건의 확률을 계산할 때 복잡한 경우의 수를 일일이 세는 대신 전체에서 빼는 방식을 자주 사용합니다. 특히 "**적어도 하나**" 같은 조건에서 매우 유용합니다. 예를 들어 "적어도 하나의 동전이 앞면일 확률"은 직접 계산하기보다 "모두 뒷면일 확률을 1에서 빼는" 것이 훨씬 간단합니다.

## 한 줄 예

주사위를 한 번 던질 때, 6이 나올 확률은 $\frac{1}{6}$이므로, 6이 나오지 않을 확률(여사건)은 $P(\text{6 아님}) = 1 - \frac{1}{6} = \frac{5}{6}$입니다.

**검산**: $\{1,2,3,4,5\}$는 5개이고 전체 6개이므로 직접 계산해도 $\frac{5}{6}$입니다. ✓
