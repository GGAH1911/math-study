# 블록 배열

## 요약
블록 배열은 주어진 물체들을 일정한 규칙이나 조건에 따라 묶음(블록)으로 처리하여 전체의 순서를 결정하는 배열 방식입니다.

## 본문
블록 배열은 서로 다른 물체들을 특정 기준에 따라 하나의 묶음으로 간주하여, 묶음 자체를 하나의 단위로 취급하여 나열하는 방법입니다. 이 방식은 개별 물체의 순서보다 물체들이 이루는 집단(블록)의 구성과 그 집단들이 나열되는 순서가 중요할 때 사용됩니다. 먼저 조건에 맞는 물체들을 하나의 블록으로 묶은 뒤, 전체 개수를 계산할 때는 묶인 블록과 남은 물체들을 모두 개별 단위로 보고 나열합니다. 마지막으로 각 블록 내부에서 물체들이 서로 자리를 바꾸는 경우의 수를 곱하여 최종적인 배열의 수를 구합니다.

### 직관과 기하적 의미
물체들이 서로 붙어 있어야 한다는 조건이 있다면, 이들을 하나의 커다란 상자에 담아 움직이는 것과 같습니다. 상자 안의 물체들은 상자 안에서 자유롭게 움직일 수 있지만, 상자 밖에서는 하나의 덩어리로 인식됩니다. 이는 복잡한 배열 문제를 단순화하여 전체적인 구조를 먼저 파악하게 해줍니다.

### 기본 성질
1. 묶음으로 처리할 대상의 개수를 하나의 단위로 계산한다.
2. 묶음 외부의 나머지 물체들과 묶음의 개수를 합산하여 전체 나열 수를 구한다.
3. 각 묶음 내부에서 물체들이 배열되는 경우의 수를 반드시 곱해주어야 한다.

## 학습 체크
- 묶음으로 지정된 물체들이 서로 다른 종류인가, 아니면 같은 종류인가?
- 묶음 내부의 물체들이 자리를 바꿀 수 있는 조건인가?
- 묶음이 아닌 나머지 물체들의 개수는 총 몇 개인가?

## 관련 개념
- **경우의 수** 고1: 블록 배열은 전체 경우의 수를 구하는 여러 가지 전략 중 하나로, 복잡한 조건을 단순한 단위로 치환하여 계산하는 원리를 제공합니다.
