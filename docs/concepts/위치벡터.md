### 정확한 진술

좌표평면에서 원점 $O$를 기준으로 점 $P$까지의 벡터를 점 $P$의 **위치벡터**라고 합니다. 점 $P$의 좌표가 $(x, y)$일 때, 위치벡터는 $\overrightarrow{OP} = (x, y)$로 나타냅니다.

더 일반적으로, 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$가 있을 때, 벡터 $\overrightarrow{AB}$는 점 $A$의 위치벡터를 $\vec{a}$, 점 $B$의 위치벡터를 $\vec{b}$라 하면 다음이 성립합니다:

$$\overrightarrow{AB} = \vec{b} - \vec{a} = (x_2 - x_1, y_2 - y_1)$$

### 직관과 기하적 의미

위치벡터는 **원점을 기준으로 평면상의 위치를 나타내는 화살표**입니다. 어떤 점이 평면 어디에 있는지를 벡터로 표현함으로써, 점의 좌표와 벡터를 같은 언어로 다룰 수 있게 됩니다.

이것이 중요한 이유는 벡터의 덧셈, 뺄셈, 스칼라배 연산을 기하학적으로 해석할 수 있기 때문입니다. 예를 들어 $\vec{a} + \vec{b}$는 위치벡터 $\vec{a}$와 $\vec{b}$를 더한 결과 위치를 나타내므로, 선분의 내분점, 외분점, 무게중심 같은 기하학적 성질을 벡터 계산으로 구할 수 있습니다.

### 예시

점 $A(1, 2)$와 점 $B(4, 6)$이 있을 때:
- 점 $A$의 위치벡터: $\vec{a} = (1, 2)$
- 점 $B$의 위치벡터: $\vec{b} = (4, 6)$
- 벡터 $\overrightarrow{AB} = \vec{b} - \vec{a} = (3, 4)$

선분 $AB$의 중점 $M$의 위치벡터는 $\frac{\vec{a} + \vec{b}}{2} = (2.5, 4)$입니다. (검증: `(1+4)/2, (2+6)/2 = 2.5, 4` ✓)
