# 귀납법 증명 예제

> **예제** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
$1+2+...+n=n(n+1)/2$ 증명

## 본문 (학습 시 채워짐)

### 문제

수학적 귀납법을 이용하여 모든 양의 정수 $n$에 대해 다음이 성립함을 증명하시오:
$$1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}$$

### 단계별 풀이

**단계 1: 기저 단계($n=1$) 확인**

$n=1$일 때 좌변은 $1$이고 우변은 $\frac{1 \cdot 2}{2} = 1$이므로 등식이 성립합니다. (귀납법은 항상 가장 작은 경우부터 시작해서 신뢰성을 확보합니다.)

**단계 2: 귀납 가정 설정**

$n=k$일 때 등식이 참이라고 가정합니다:
$$1 + 2 + \cdots + k = \frac{k(k+1)}{2}$$

(이 가정이 우리가 $n=k+1$까지 확장할 발판이 됩니다.)

**단계 3: 귀납 단계 증명($n=k+1$일 때)**

$n=k+1$일 때를 보겠습니다:
$$1 + 2 + \cdots + k + (k+1) = \frac{k(k+1)}{2} + (k+1)$$

(귀납 가정을 이용해 앞의 $k$항 합을 공식으로 대체합니다.)

우변을 정리하면:
$$\frac{k(k+1)}{2} + (k+1) = (k+1)\left(\frac{k}{2} + 1\right) = (k+1) \cdot \frac{k+2}{2} = \frac{(k+1)(k+2)}{2}$$

(공통인수 $(k+1)$으로 묶고, 분수를 통분하여 구하려는 형태로 만들었습니다.)

이는 $n=k+1$을 대입한 공식과 일치합니다. (따라서 $n=k$가 참이면 $n=k+1$도 참입니다.)

### 답

기저 단계와 귀납 단계가 모두 성립하므로, 수학적 귀납법에 의해 모든 양의 정수 $n$에 대해 $1+2+\cdots+n=\frac{n(n+1)}{2}$가 증명됩니다.

### 변형/주의

몇 가지 $n$ 값으로 검증해보면 확신이 생깁니다: $n=2$일 때 $1+2=3=\frac{2 \cdot 3}{2}$ ✓, $n=3$일 때 $1+2+3=6=\frac{3 \cdot 4}{2}$ ✓ (sympy 검증: `sum(range(1, n+1)) == n*(n+1)//2`). 

이 공식은 첫째항과 마지막항이 같은 등차수열 합 $S=\frac{n(\text{첫째항}+\text{마지막항})}{2}$의 특수한 경우입니다. 귀납법은 일반항이 복잡한 수열의 합이나 부등식 증명에 특히 강력하므로, 단순히 패턴으로 외우지 말고 증명 논리 자체를 습득하세요.
