### 정확한 진술

시간 $t$에 대한 물체의 위치를 $s(t)$라 할 때, **속도는 위치의 도함수**이고 **위치는 속도의 정적분**입니다. 즉,

$$v(t) = \frac{ds}{dt}$$

**역으로, 속도 함수 $v(t)$가 주어졌을 때 위치는**

$$s(t) = s_0 + \int_0^t v(u) \, du$$

여기서 $s_0$는 $t=0$일 때의 초기 위치입니다.

### 직관·기하적 의미

도함수는 변화의 순간 변화율을 나타내므로, $\frac{ds}{dt}$는 "시간이 아주 작은 구간에서 위치가 얼마나 빠르게 변하는가"를 의미합니다. 이것이 바로 **속도**입니다.

반대로 정적분 $\int_0^t v(u) \, du$는 속도의 그래프 아래 넓이인데, 이는 시간 구간 $[0, t]$에서 물체가 얼마나 많이 움직였는지(변위)를 나타냅니다. 따라서 초기 위치에서 이 변위를 더하면 현재 위치 $s(t)$를 얻게 됩니다.

**기하적으로**: 속도 그래프 $v(t)$에서 $x$축과 곡선 사이의 부호를 포함한 넓이가 바로 변위입니다.

### 예시

물체의 속도가 $v(t) = 3t^2$ m/s이고, $t=0$일 때 위치가 $s_0 = 1$ m이라고 하겠습니다.

$t$초일 때의 위치를 구하면:

$$s(t) = 1 + \int_0^t 3u^2 \, du = 1 + \left[ u^3 \right]_0^t = 1 + t^3$$

따라서 $t=2$초일 때 위치는 $s(2) = 1 + 8 = 9$ m입니다.

검증: `sympy.integrate(3*u**2, (u, 0, 2))` → $8$ (변위)이므로 최종 위치 $1 + 8 = 9$ ✓
