### 정확한 진술

삼각함수의 기본형태는 사인과 코사인 함수를 일반화한 다음의 형태이다:

$$y = a\sin(bx + c) + d$$

또는 코사인의 경우:

$$y = a\cos(bx + c) + d$$

여기서 $a, b, c, d$는 실수 상수이고 $b \neq 0$이며, 각 계수는 다음을 나타낸다:
- **$a$**: 진폭(amplitude). 함수의 최댓값과 최솟값이 중심선 $y=d$에서 $|a|$만큼 떨어져 있음
- **$b$**: 주기 계수. 함수의 주기는 $T = \frac{2\pi}{|b|}$
- **$c$**: 위상상수(phase constant). 기본 사인함수가 $x = -\frac{c}{b}$만큼 수평이동
- **$d$**: 수직이동(vertical shift). 함수의 중심축이 $y = d$

### 직관과 기하적 의미

기본형태는 기본 사인함수 $y = \sin x$에 네 가지 변환을 차례로 적용한 결과다:

1. **$bx$ 변환**: $x$축 방향으로 압축(또는 확장). $|b| > 1$이면 압축, $0 < |b| < 1$이면 확장
2. **$c$ 이동**: 위상이동으로 인한 그래프의 좌우 이동
3. **$a$ 배율**: $y$축 방향 확대/축소로 파동의 진폭을 제어
4. **$+d$ 이동**: 전체 그래프가 $d$만큼 위아래로 평행이동

파동, 진동, 교류전류 등 반복되는 현상을 수식으로 나타낼 때 이 형태를 사용한다.

### 한 줄 예

$y = 3\sin(2x - \frac{\pi}{4}) + 2$는 진폭 3, 주기 $\pi$, 오른쪽으로 $\frac{\pi}{8}$만큼 위상이동, 중심축 $y=2$인 함수다.
