### 정확한 진술

주어진 데이터 $x_1, x_2, \ldots, x_n$의 평균을 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$라 할 때, **분산**(variance)은 다음과 같이 정의됩니다.

$$\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

이는 각 데이터가 평균으로부터 떨어진 거리의 제곱을 모두 더한 후 데이터의 개수로 나눈 값입니다. 표본 분산을 구할 때는 분모를 $n-1$로 쓰기도 합니다.

### 직관 및 의미

분산은 데이터가 평균 주위에 얼마나 흩어져 있는지를 재는 척도입니다. 만약 모든 데이터가 평균과 같다면 분산은 0입니다. 데이터들이 평균에서 멀어질수록 분산은 커집니다. 거리를 제곱하는 이유는 음수를 피하고, 큰 편차에 더 큰 가중치를 부여하기 위함입니다. 분산이 작으면 데이터가 "몰려 있다"는 뜻이고, 크면 "흩어져 있다"는 뜻입니다.

### 한 줄 예제

데이터 $\{2, 4, 6\}$의 평균은 $\bar{x}=4$이므로, 분산은 $\sigma^2 = \frac{(2-4)^2 + (4-4)^2 + (6-4)^2}{3} = \frac{4+0+4}{3} = \frac{8}{3}$입니다. (`sympy.var('sigma2'); sigma2 = (4 + 0 + 4) / 3`)
