# 절댓값함수의 성질

## 요약
절댓값함수는 수직선 위에서 원점으로부터의 거리를 나타내며, 그래프가 꺾이는 지점을 기준으로 구간을 나누어 함수를 재정의하여 다룹니다.

## 본문
절댓값함수란 임의의 실수 $x$에 대하여 $x$의 절댓값 $|x|$를 포함하는 함수를 의미합니다. 절댓값의 정의에 따라 $x \ge 0$이면 $|x| = x$이고, $x < 0$이면 $|x| = -x$가 됩니다. 따라서 절댓값 함수를 다룰 때는 절댓값 내부의 식이 $0$이 되는 지점을 기준으로 범위를 나누어 각 구간에서의 함수식을 결정하는 것이 핵심입니다.

### 직관과 기하적 의미
기하학적으로 $|x|$는 수직선 위에서 원점 $0$으로부터 점 $x$까지의 거리를 의미합니다. 거리는 항상 $0$보다 크거나 같아야 하므로, 함수 $y=|x|$의 그래프는 $x$축 아래로 내려가지 않는 $V$자 형태를 띱니다. 함수 $y=|f(x)|$의 경우, 원래 함수 $f(x)$의 그래프에서 $x$축 아래에 있는 부분을 $x$축을 기준으로 대칭 이동시킨 모양이 됩니다.

### 기본 성질
첫째, 모든 실수 $x$에 대하여 $|f(x)| \ge 0$이 성립하므로 함수의 치역은 항상 $0$ 이상입니다. 둘째, $|f(x)| = g(x)$라는 방정식은 $f(x) = g(x)$ 또는 $f(x) = -g(x)$를 만족하는 $x$를 찾는 것과 같습니다. 셋째, 절댓값 기호가 포함된 부등식 $|f(x)| < a$ (단, $a>0$)는 $-a < f(x) < a$로, $|f(x)| > a$는 $f(x) < -a$ 또는 $f(x) > a$로 변형하여 풀 수 있습니다.

## 학습 체크
- 절댓값 내부의 식이 $0$이 되는 지점을 기준으로 구간을 나누었는가?
- 그래프를 그릴 때 $x$축 아래 부분을 위로 꺾어 올렸는가?
- 부등식을 풀 때 절댓값을 벗기는 과정에서 부등호의 방향을 주의하였는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수와 로그함수의 그래프를 $x$축에 대하여 대칭 이동시키면 절댓값 함수와 유사한 형태의 그래프를 얻을 수 있습니다.
