# 삼각함수

> **단원** · 수학1 · 선수: [삼각비](./삼각비.md) / [함수와 그래프](./함수와_그래프.md) · 다음: 없음 (말단 노드 / Phase 1에서 미정의)

## 학습 목표
- 호도법으로 각을 표현하고 단위원에서 정의된 삼각함수를 이해한다
- 삼각함수의 그래프·주기·대칭을 다룬다
- 삼각함수의 덧셈정리·합성 등을 활용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 호도법 (라디안)
- 단위원에서의 $\sin, \cos, \tan$
- 주기, 진폭, 위상

**정리(theorem)**
- $\sin^2\theta+\cos^2\theta=1$
- 주기 $\sin, \cos$은 $2\pi$, $\tan$은 $\pi$
- 사인·코사인 법칙

**예제(example)**
- 삼각함수 그래프 그리기
- 주기·진폭·위상 변형
- 삼각방정식 풀이
