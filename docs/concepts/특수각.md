# 특수각

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
$30°, 45°, 60°$의 삼각비

## 본문 (학습 시 채워짐)

### 정확한 진술

**특수각**은 삼각비의 값을 정확히 알 수 있는 특별한 각도를 말합니다. 고등학교 교육과정에서는 $30°$, $45°$, $60°$를 주로 다룹니다. 각 각의 삼각비는 다음과 같습니다:

| 각도 | $\sin$ | $\cos$ | $\tan$ |
|------|--------|--------|--------|
| $30°$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$ |
| $45°$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $1$ |
| $60°$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $\sqrt{3}$ |

### 직관과 기하적 의미

이 값들은 **특정한 기하 도형**에서 자연스럽게 나타납니다. 

$45°$의 경우, **직각이등변삼각형**(두 직각변의 길이가 같은 직각삼각형)에서 나옵니다. 직각변의 길이를 1이라 하면 빗변은 $\sqrt{1^2 + 1^2} = \sqrt{2}$이므로 $\sin 45° = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$입니다.

$30°$와 $60°$의 경우, **정삼각형**을 반으로 나눈 직각삼각형에서 나옵니다. 한 변의 길이가 2인 정삼각형을 높이로 나누면, 높이는 $\sqrt{3}$이 되어 $30°$의 맞은쪽 변이 1, 인접한 변이 $\sqrt{3}$이므로 $\sin 30° = \dfrac{1}{2}$, $\cos 30° = \dfrac{\sqrt{3}}{2}$입니다.

### 한 줄 예

$\sin 60° = \dfrac{\sqrt{3}}{2}$이므로, 빗변이 4인 직각삼각형에서 $60°$에 대한 맞은쪽 변의 길이는 $4 \times \dfrac{\sqrt{3}}{2} = 2\sqrt{3}$입니다.
