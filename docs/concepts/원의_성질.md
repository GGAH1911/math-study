# 원의 성질

> **단원** · 중3 · 선수: [도형의 성질](./도형의_성질.md) / [평면도형](./평면도형.md) · 다음: [도형의 방정식](./도형의_방정식.md)

## 학습 목표
- 원의 현·접선·원주각의 성질을 활용한다
- 내접·외접 사각형의 성질을 적용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 현, 접선, 원주각, 중심각

**정리(theorem)**
- 원주각은 같은 호에 대해 동일
- 원주각 = 중심각 / 2
- 접선은 접점에서 반지름과 수직

**예제(example)**
- 원주각으로 각도 구하기
- 접선의 길이
- 내접사각형의 대각의 합 $180°$
