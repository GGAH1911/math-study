### 정확한 진술

두 분수 $\frac{a}{b}$와 $\frac{c}{d}$ (단, $b, d \neq 0$)에 대한 사칙계산 규칙은 다음과 같습니다.

**덧셈**: 분모가 같으면 $\frac{a}{b} + \frac{c}{b} = \frac{a+c}{b}$입니다. 분모가 다르면 통분하여 $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$입니다.

**뺄셈**: $\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}$입니다.

**곱셈**: $\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$입니다.

**나눗셈**: $\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc}$ (단, $c \neq 0$)입니다.

### 직관/기하적 의미

분수는 전체를 여러 부분으로 나눈 것 중 일부입니다. 덧셈과 뺄셈은 **같은 기준(분모)에서** 부분들을 모으거나 빼는 것이므로, 통분하여 분모를 맞춘 후 분자끼리만 계산합니다. 곱셈의 $\frac{a}{b} \times \frac{c}{d}$는 "전체의 $\frac{a}{b}$에서, 다시 그것의 $\frac{c}{d}$를 취한다"는 '~의 ~' 의미입니다. 나눗셈은 곱셈의 역연산으로, 나누는 분수를 역수로 바꿔 곱합니다.

### 한 줄 예

$\frac{2}{3} + \frac{1}{6} = \frac{4}{6} + \frac{1}{6} = \frac{5}{6}$, $\frac{2}{3} \times \frac{3}{4} = \frac{6}{12} = \frac{1}{2}$, $\frac{2}{3} \div \frac{4}{5} = \frac{2}{3} \times \frac{5}{4} = \frac{10}{12} = \frac{5}{6}$ (검산: `from fractions import Fraction; Fraction(2,3) + Fraction(1,6)`)
