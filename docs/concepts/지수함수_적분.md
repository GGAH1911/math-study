# 지수함수 적분

지수함수의 부정적분은 미분의 역연산으로 정의한다.

자연상수 $e$를 밑으로 하는 지수함수는 미분해도 자기 자신이 된다는 성질 덕분에, 적분도 같은 형태가 된다.

$$\int e^x \, dx = e^x + C$$

밑이 $a$인 일반 지수함수($a > 0$, $a \neq 1$)는 $a^x = e^{x \ln a}$임을 이용하면,

$$\int a^x \, dx = \frac{a^x}{\ln a} + C$$

지수 안에 일차식이 들어간 형태는 치환적분을 쓰거나 공식을 직접 외워 두면 편하다.

$$\int e^{ax+b} \, dx = \frac{1}{a} e^{ax+b} + C \quad (a \neq 0)$$

이 세 꼴이 지수함수 적분의 기본 틀이며, 정적분에서는 위 부정적분 결과에 구간의 양 끝값을 대입해 뺀다.

## 예시

**예시 1.** $\displaystyle\int_0^1 e^{2x-1} \, dx$ 를 구해 보자.

공식 $\int e^{ax+b} dx = \dfrac{1}{a}e^{ax+b} + C$에 $a=2$, $b=-1$을 적용하면

$$\int_0^1 e^{2x-1} \, dx = \left[ \frac{1}{2} e^{2x-1} \right]_0^1 = \frac{1}{2}e^1 - \frac{1}{2}e^{-1} = \frac{1}{2}\!\left(e - \frac{1}{e}\right)$$

**예시 2.** $\displaystyle\int_0^2 3^x \, dx$ 를 구해 보자.

$\int 3^x dx = \dfrac{3^x}{\ln 3} + C$ 이므로

$$\int_0^2 3^x \, dx = \left[ \frac{3^x}{\ln 3} \right]_0^2 = \frac{3^2}{\ln 3} - \frac{3^0}{\ln 3} = \frac{9-1}{\ln 3} = \frac{8}{\ln 3}$$

## 관련 개념

**선수 개념과의 연결.** 지수함수 적분은 **여러 가지 적분법**의 핵심 소재다. 지수 안에 복잡한 식이 들어오면 **치환적분**으로 $u = g(x)$로 바꿔 기본 꼴로 만들고, 앞에 다항식이 곱해진 형태($x e^x$ 등)는 **부분적분**으로 처리한다.

**인접 개념.** $\dfrac{1}{x}$의 적분인 $\ln x$ 적분과 짝을 이룬다. $e^x$과 $\ln x$는 역함수 관계이므로, 한 쪽의 적분 성질이 다른 쪽 미분 성질과 맞닿아 있다. **정적분의 활용** 단원에서는 이 결과를 곧바로 넓이·부피 계산에 대입하므로, 계산 실수 없이 빠르게 기본 꼴을 인식하는 연습이 중요하다.
