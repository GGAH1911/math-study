# 지수함수 적분

## 요약
지수함수의 적분은 미분의 역연산으로, 밑이 $e$인 경우 자기 자신과 형태가 같고 일반적인 밑 $a$인 경우에는 $\ln a$로 나누어 준다.

## 본문
지수함수의 부정적분은 미분의 역연산으로 정의한다. 자연상수 $e$를 밑으로 하는 지수함수는 미분해도 자기 자신이 된다는 성질 덕분에, 적분 결과 또한 원래의 함수 형태를 유지한다.

$$\int e^x \, dx = e^x + C$$

밑이 $a$인 일반 지수함수($a > 0, a \neq 1$)의 경우에는 $a^x = e^{x \ln a}$라는 관계식을 이용하여 적분할 수 있으며, 결과값에 $\ln a$가 분모에 추가된다.

$$\int a^x \, dx = \frac{a^x}{\ln a} + C$$

지수 부분에 일차식이 포함된 형태인 $e^{ax+b}$를 적분할 때는 치환적분을 활용하거나, 결과값에 지수의 계수인 $a$의 역수를 곱해주는 공식을 사용한다.

$$\int e^{ax+b} \, dx = \frac{1}{a} e^{ax+b} + C \quad (a \neq 0)$$

이 세 가지 형태가 지수함수 적분의 가장 기본적인 틀을 이룬다. 정적분을 계산할 때는 위에서 구한 부정적분 결과에 구간의 양 끝값을 대입하여 차이를 구한다.

### 직관과 기하적 의미
지수함수의 적분은 함수 그래프 아래의 면적을 구하는 과정이다. 밑이 $e$인 지수함수는 변화율이 자기 자신과 같기 때문에, 적분 결과 역시 원래 함수와 동일한 곡선의 형태를 띠게 된다.

### 기본 성질
1. 자연상수 $e$를 밑으로 하는 지수함수의 적분은 자기 자신이다.
2. 밑이 $a$인 지수함수를 적분하면 $\ln a$로 나누어야 한다.
3. 지수 부분에 일차식이 있을 경우, 적분 결과에 해당 일차식 계수의 역수를 곱한다.

## 학습 체크
- 밑이 $e$가 아닌 일반적인 지수함수를 적분할 때 $\ln a$를 곱하는지 나누는지 구분할 수 있는가?
- 지수 부분에 $ax+b$와 같은 일차식이 포함된 경우, 계수 $a$의 역수를 정확히 적용하였는가?
- 정적분 계산 시 구간의 양 끝값을 대입하여 차이를 구하는 과정을 빠뜨리지 않았는가?

## 관련 개념

**선수 개념과의 연결.** 지수함수 적분은 **여러 가지 적분법**의 핵심 소재다. 지수 안에 복잡한 식이 들어오면 **치환적분**으로 $u = g(x)$로 바꿔 기본 꼴로 만들고, 앞에 다항식이 곱해진 형태($x e^x$ 등)는 **부분적분**으로 처리한다.

**인접 개념.** $\tfrac{1}{x}$의 적분인 $\ln x$ 적분과 짝을 이룬다. $e^x$과 $\ln x$는 역함수 관계이므로, 한 쪽의 적분 성질이 다른 쪽 미분 성질과 맞닿아 있다. **정적분의 활용** 단원에서는 이 결과를 곧바로 넓이·부피 계산에 대입하므로, 계산 실수 없이 빠르게 기본 꼴을 인식하는 연습이 중요하다.
