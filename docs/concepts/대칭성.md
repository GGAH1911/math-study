# 대칭성

## 요약
도형이나 함수가 특정 선이나 점, 또는 회전 또는 반사 연산을 통해 원래의 모습과 일치하게 유지되는 성질을 의미합니다.

## 본문
대칭성이란 어떤 대상이 특정 기준에 대하여 변환되었을 때, 변환 전과 후의 모습이 완전히 동일하게 유지되는 성질을 말합니다. 이는 기하학적 도형뿐만 아니라 함수, 수열, 물리적 구조 등 다양한 수학적 대상에서 나타나는 핵심적인 특징입니다.

### 직관과 기하적 의미
도형을 반으로 접었을 때 양쪽이 완벽하게 겹치면 선대칭이라고 하며, 도형을 특정 점을 중심으로 돌렸을 때 처음과 같은 모양이 되면 점대칭이라고 합니다. 이는 대상이 가진 구조적 균형을 시각적으로 보여주며, 복잡한 형태를 단순한 기본 단위로 분해하여 이해할 수 있게 돕는 도구가 됩니다.

### 기본 성질
대칭성은 변환의 결합에 대해 닫혀 있는 경우가 많으며, 이는 대칭군(Group)이라는 수학적 구조를 형성하는 기초가 됩니다. 선대칭의 경우 대칭축을 기준으로 거리가 같은 점들의 집합으로 나타나고, 점대칭의 경우 대칭의 중심으로부터 거리가 같은 점들의 집합으로 나타납니다.

## 학습 체크
- 대칭축이나 대칭의 중심이 존재할 때, 도형의 모든 점이 대칭 이동 후에도 원래 도형의 경계 위에 머무르는가?
- 선대칭과 점대칭이 동시에 나타나는 도형의 경우, 어떤 기하학적 특징을 공유하는가?

## 관련 개념
- **확률**: 확률 분포가 특정 값을 중심으로 대칭을 이루면, 평균과 중앙값이 일치하는 특성을 가집니다.
