# 분자의 유리화

## 요약
분모에 포함된 무리수를 제거하기 위해 분자와 분모에 같은 무리수를 곱하여 분모를 유리수로 만드는 과정입니다.

## 본문
분수의 분모에 무리수가 포함되어 있을 때, 분모를 유리수로 바꾸어 식을 간결하게 만드는 과정을 분자의 유리화라고 합니다. 분모가 $\sqrt{a}$와 같은 형태라면 분자와 분모에 똑같이 $\sqrt{a}$를 곱하여 분모를 $a$라는 유리수로 변환합니다. 만약 분모가 $\sqrt{a} + \sqrt{b}$와 같이 합이나 차의 형태라면, 합차 공식을 이용하기 위해 켤레무리수인 $\sqrt{a} - \sqrt{b}$를 분자와 분모에 각각 곱하여 분모를 $a-b$라는 유리수로 만듭니다. 이러한 과정은 분수식의 형태를 단순화하여 계산을 용이하게 하며, 특히 극한값을 구할 때 식의 수렴 여부를 판단하는 데 매우 중요한 역할을 합니다.

### 직관과 기하적 의미
무리수가 분모에 있으면 수직선 위에서 해당 값의 위치를 정확히 특정하거나 크기를 비교하기가 어렵습니다. 분자의 유리화를 통해 분모를 정수나 유리수로 바꾸면, 전체 분수의 크기를 우리가 익숙한 유리수 체계 내에서 훨씬 직관적으로 파악할 수 있게 됩니다.

### 기본 성질
분자와 분모에 0이 아닌 같은 수를 곱하더라도 분수의 값은 변하지 않는 성질을 이용합니다. 이를 통해 식의 본질적인 값은 유지하면서 표현 방식만 유리수 형태로 변환하는 것이 핵심입니다.

## 학습 체크
- 분모가 $\sqrt{a} + \sqrt{b}$ 형태일 때, 어떤 식을 곱해야 분모를 유리수로 만들 수 있는가?
- 분자의 유리화를 수행한 후, 결과값이 원래의 분수와 동일한 값을 가지는지 확인하였는가?

## 관련 개념
- **수열의 극한**: 극한값을 계산할 때 분모가 0으로 수렴하여 $\tfrac{0}{0}$ 꼴의 부정형이 나타나면, 분자의 유리화를 통해 식을 변형하여 극한값을 구합니다.
