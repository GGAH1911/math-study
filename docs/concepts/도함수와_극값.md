# 도함수와 극값

## 요약
함수의 증감을 결정하는 도함수의 부호 변화를 통해 함수의 극대와 극소를 판별할 수 있습니다.

## 본문
함수 $f(x)$가 어떤 구간의 개구간에서 미분가능할 때, 도함수 $f'(x)$의 부호가 변하는 지점을 통해 함수의 극값을 찾을 수 있습니다. 함수 $f(x)$가 $x=a$ 근처에서 $a$를 포함하는 어떤 구간에서 정의되어 있고, $x=a$에서 함숫값이 $f(a)$이며, $a$의 좌우에서 $f(x)$의 부호가 $a$를 경계로 변할 때 $x=a$에서 극값을 갖는다고 합니다. 구체적으로 $x=a$의 좌측에서 $f'(x) > 0$이고 우측에서 $f'(x) < 0$이면 함수는 $x=a$에서 극대값을 가지며, 반대로 좌측에서 $f'(x) < 0$이고 우측에서 $f'(x) > 0$이면 $x=a$에서 극소값을 가집니다. 이때 $f'(a)=0$인 지점은 극값이 될 수 있는 후보가 되지만, 반드시 극값을 갖는 것은 아닙니다. 예를 들어 $f(x)=x^3$과 같이 $f'(a)=0$임에도 불구하고 부호 변화가 없는 경우를 주의해야 합니다.

### 직관과 기하적 의미
그래프의 관점에서 도함수는 접선의 기울기를 의미합니다. 접선의 기울기가 양수에서 음수로 변한다는 것은 그래프가 상승하다가 하강하기 시작함을 의미하며, 이 변곡점에서 그래프의 꼭대기인 극대점이 형성됩니다. 반대로 기울기가 음수에서 양수로 변하면 골짜기의 바닥인 극소점이 형성됩니다.

### 기본 성질
함수가 미분가능하면 극값인 지점에서의 미분계수는 항상 $0$입니다. 즉, $f(a)$가 극값이라면 $f'(a)=0$을 만족합니다. 하지만 역은 성립하지 않으므로, $f'(a)=0$인 모든 점을 조사하되 부호 변화가 있는지 반드시 확인해야 합니다.

## 학습 체크
- $f'(a)=0$임에도 불구하고 $x=a$에서 극값을 갖지 않는 함수의 사례를 찾을 수 있는가?
- 함수의 증감표를 작성할 때 $f'(x)$의 부호 변화가 어떻게 $f(x)$의 증감과 연결되는지 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수를 통해 함수의 극대, 극소, 증가와 감소를 판별하여 함수의 그래프 개형을 정확하게 그리는 과정으로 확장됩니다.
