### 정확한 진술

평면 위의 두 점 $F$, $F'$까지의 거리의 합이 일정한 점들의 자취를 **타원**(ellipse)이라 합니다. 즉, 
$$|PF| + |PF'| = 2a$$
를 만족하는 모든 점 $P$의 집합입니다. 이때 $F$, $F'$를 **초점**(focus)이라 하고, $2a$는 상수(단, $2a > |FF'|$)입니다.

두 초점을 잇는 선분의 중점을 원점으로 하고, 초점 사이의 거리를 $2c$라 하면, 초점은 $(\pm c, 0)$이고, 표준형은
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0, \, a^2 = b^2 + c^2)$$
입니다.

### 직관/기하적 의미

타원은 "납작한 원"이라고 이해할 수 있습니다. 두 개의 핀을 초점에 꽂고 그 사이에 실 하나를 팽팽하게 펴서 연필을 실에 얹고 그리면 타원이 그려집니다. 이는 '거리의 합 = 일정'이라는 조건을 직관적으로 나타냅니다.

긴 축의 길이는 $2a$ (장축), 짧은 축의 길이는 $2b$ (단축)이고, 원심률 $e = \frac{c}{a}$ ($0 < e < 1$)로 얼마나 찌그러졌는지를 나타냅니다. $e$가 0에 가까울수록 원에 가깝고, 1에 가까울수록 더 납작해집니다.

### 한 줄 예

타원 $\frac{x^2}{25} + \frac{y^2}{16} = 1$에서 $a = 5$, $b = 4$이고, $c = \sqrt{25-16} = 3$이므로 초점은 $(\pm 3, 0)$입니다. `from sympy import *; a, b = 5, 4; c = sqrt(a**2 - b**2); print(c)` → $c = 3$
