# 신뢰도

## 요약
신뢰도는 추정된 구간 안에 실제 모수가 포함될 확률을 나타내는 척도로, 구간의 신뢰 수준을 결정하는 핵심 요소입니다.

## 본문
신뢰도는 표본을 통해 구한 신뢰 구간 내에 모집단의 실제 모수가 포함될 확률을 의미합니다. 통계적 추정에서 우리는 표본을 통해 모수를 추측하며, 이때 단 하나의 값(점추정)보다는 일정한 범위를 지정하는 구간추정을 주로 사용합니다. 신뢰 구간의 크기를 결정하는 신뢰 수준은 보통 $95\%$ 또는 $99\%$와 같은 확률로 표현되며, 이는 동일한 방식으로 구간을 반복하여 무수히 많은 구간을 만들었을 때 그중 실제 모수를 포함하는 구간의 비율이 해당 확률과 같음을 의미합니다.

### 직관과 기하적 의미
신뢰도는 확률의 개념을 구간의 신뢰성에 적용한 것입니다. 예를 들어 $95\%$ 신뢰 구간을 구했다는 것은, 우리가 표본을 추출하여 구간을 만드는 과정을 무한히 반복했을 때, 생성된 구간들 중 $95\%$는 실제 모수를 포함하고 나머지 $5\%$는 포함하지 못한다는 것을 의미합니다. 이는 특정 구간 안에 모수가 있을 확률이 $95\%$라는 의미와 같지만, 이미 결정된 특정 구간에 대해서는 모수가 있거나 없거나 둘 중 하나일 뿐 확률을 논할 수 없다는 점에 주의해야 합니다.

### 기본 성질
신뢰 구간의 길이는 신뢰 수준이 높아질수록 길어지는 경향이 있습니다. 더 높은 확률로 모수를 포함하고 싶다면 구간의 범위를 더 넓게 잡아야 하기 때문입니다. 또한 표본의 크기가 커질수록 표준 오차가 작아지므로 신뢰 구간의 길이는 짧아지며, 이는 추정의 정밀도가 높아짐을 의미합니다.

## 학습 체크
- 신뢰 수준이 $95\%$에서 $99\%$로 증가할 때 신뢰 구간의 길이는 어떻게 변하는가?
- 신뢰 구간이 실제 모수를 포함할 확률과, 특정 구간이 모수를 포함할 확률의 차이를 설명할 수 있는가?

## 관련 개념
- **통계**: 표본 데이터를 바탕으로 모집단의 특성을 추론하는 과정에서 신뢰 구간을 산출하는 핵심 지표로 사용됩니다.
