### 정확한 진술

정수 $a$가 0이 아닌 정수 $b$의 **약수**라는 것은, $b = a \times k$를 만족하는 정수 $k$가 존재한다는 뜻입니다. 이를 기호로 $a \mid b$로 표기하며 "$a$가 $b$를 나눈다" 또는 "$b$는 $a$의 배수"라고 읽습니다. 반대로 $a$가 $b$의 약수가 아니면 $a \nmid b$로 쓰입니다.

### 직관적 의미

약수 판정은 **나눗셈에서 나머지가 0인지 확인하는 것**입니다. 예를 들어 15를 3으로 나누면 나머지가 0이므로, 3은 15의 약수입니다. 다르게 말하면, 15개의 사탕을 3명의 친구에게 나머지 없이 똑같이 나눠줄 수 있다는 뜻입니다. 나눗셈 정리로 표현하면: 정수 $b$와 0이 아닌 정수 $a$에 대해 $b = a \times q + r$ (단, $0 \le r < |a|$)일 때, $a \mid b$ ⟺ $r = 0$입니다.

### 기본 성질

약수 판정의 핵심 성질은 다음과 같습니다.
- $a \mid b$이고 $b \mid c$이면 $a \mid c$ (전이성)
- $a \mid b$이고 $a \mid c$이면 $a \mid (b + c)$와 $a \mid (b - c)$ (합과 차의 약수)
- $a \mid b$이면 모든 정수 $m$에 대해 $a \mid (m \times b)$

### 한 줄 예

$12 = 3 \times 4$이므로 $3 \mid 12$입니다. 하지만 $12 = 5 \times 2 + 2$이므로 $5 \nmid 12$입니다. (검증: `12 % 3 = 0`, `12 % 5 = 2`)
