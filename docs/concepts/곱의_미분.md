# 곱의 미분

> **정리** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$(fg)'=f'g+fg'

## 본문 (학습 시 채워짐)

### 곱의 미분법 (진술과 가정)

두 함수 $f(x)$와 $g(x)$가 어떤 구간에서 미분가능할 때, 곱 $f(x)g(x)$의 도함수는 다음과 같습니다.

$$\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$$

또는 간단히 $(fg)' = f'g + fg'$로 표현합니다. 이 공식은 두 함수의 곱을 미분할 때 각 함수를 번갈아가며 미분하고 더하는 방식입니다.

### 증명 (미분의 정의로부터)

도함수의 정의 $\{f(x)g(x)\}' = \lim_{h \to 0} \frac{f(x+h)g(x+h) - f(x)g(x)}{h}$에서 시작합니다. 분자에 $f(x+h)g(x) - f(x+h)g(x)$를 더하고 빼면:

$$\frac{f(x+h)g(x+h) - f(x+h)g(x) + f(x+h)g(x) - f(x)g(x)}{h}$$

$$= \frac{f(x+h)\{g(x+h) - g(x)\}}{h} + \frac{g(x)\{f(x+h) - f(x)\}}{h}$$

$h \to 0$일 때, 첫 번째 항은 $f(x) \cdot g'(x)$로, 두 번째 항은 $f'(x) \cdot g(x)$로 수렴합니다 ($f$의 연속성 이용). 따라서 $(fg)' = f'g + fg'$입니다.

### 의의와 활용

곱의 미분법은 단순 함수들의 조합으로 이루어진 복잡한 식을 미분할 때 핵심 도구입니다. 예를 들어 $y = x^2 \sin x$를 미분하면 $y' = 2x \sin x + x^2 \cos x$이 됩니다. 나아가 몫의 미분법, 연쇄법칙과 함께 사용되어 고차 다항식, 삼각함수, 지수·로그함수의 곱으로 표현된 함수들을 다루는 데 필수적입니다. 수능과 모의고사에서 함수의 도함수를 구하거나 접선의 기울기, 극값을 구할 때 반복적으로 나타나는 기본 공식입니다.
