### 정확한 진술

구간별함수는 정의역을 여러 개의 구간으로 나누어, 각 구간에서 서로 다른 함수식으로 정의되는 함수입니다. 정의역을 $I_1, I_2, \ldots, I_n$으로 분할할 때, 함수 $f$는 다음과 같이 나타냅니다:

$$f(x) = \begin{cases} f_1(x) & \text{if } x \in I_1 \\ f_2(x) & \text{if } x \in I_2 \\ \vdots \\ f_n(x) & \text{if } x \in I_n \end{cases}$$

여기서 각 $f_i(x)$는 해당 구간에서만 적용되는 함수식입니다.

### 직관과 기하적 의미

그래프 관점에서 구간별함수는 여러 곡선이 이어붙여진 형태입니다. 각 구간의 경계점에서는 함수가 연속일 수도, 불연속(끊김)일 수도 있습니다. 경계점 $x=a$에서 연속이려면 $\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = f(a)$ 를 만족해야 합니다.

구간별함수는 실제 현상을 모델링할 때 자주 나타납니다. 예를 들어 절댓값 함수 $|x|$, 요금 체계, 구간마다 다른 속도로 이동하는 물체의 위치 함수 등이 모두 구간별함수입니다.

### 한 줄 예

$$f(x) = \begin{cases} x^2 & \text{if } x < 0 \\ 2x & \text{if } x \geq 0 \end{cases}$$

는 $x < 0$에서는 이차함수, $x \geq 0$에서는 일차함수로 정의된 구간별함수이며, $x=0$에서 $\lim_{x \to 0^-} f(x) = 0 = f(0)$이고 $\lim_{x \to 0^+} f(x) = 0$이므로 연속입니다.
