# 기댓값

## 요약
어떤 확률 변수가 취할 수 있는 값들에 각각의 확률을 곱하여 모두 더한 값으로, 확률 변수의 평균적인 기대치를 의미합니다.

## 본문
확률 변수 $X$가 가질 수 있는 값들을 $x_1, x_2, \dots, x_n$이라 하고, 각 값이 나타날 확률을 $P(X=x_i)$라고 할 때, 기댓값 $E(X)$는 $\sum_{i=1}^{n} x_i P(X=x_i)$로 정의됩니다. 이는 확률 변수가 시행을 반복했을 때 나타날 것으로 기대되는 평균적인 값을 수학적으로 나타낸 것입니다.

### 직관과 기하적 의미
기댓값은 확률 분포의 '무게 중심'과 같은 역할을 합니다. 확률 변수의 각 값에 확률이라는 무게를 곱하여 합산한 것이므로, 확률 분포의 그래프를 물리적인 막대라고 가정했을 때 그 막대가 평형을 이루는 지점과 같습니다. 따라서 기댓값은 데이터가 어느 방향으로 치우쳐 있는지를 보여주는 척도가 됩니다.

### 기본 성질
기댓값은 선형성을 가지므로, 두 확률 변수의 합의 기댓값은 각 기댓값의 합과 같고($E(X+Y) = E(X) + E(Y)$), 상수가 곱해진 경우 상수를 밖으로 뺄 수 있습니다($E(aX) = aE(X)$). 또한, 서로 독립인 두 확률 변수의 곱의 기댓값은 각 기댓값의 곱과 같습니다($E(XY) = E(X)E(Y)$).

## 학습 체크
- 이산 확률 변수의 경우 모든 가능한 값과 그 확률의 곱을 모두 더했을 때 계산이 완료되는가?
- 기댓값이 확률 변수가 가질 수 있는 값의 범위 내에 항상 존재하는가?
- 확률 변수에 상수를 더하거나 곱했을 때 기댓값에 어떤 변화가 생기는가?

## 관련 개념
- **확률**: 기댓값을 계산하기 위해서는 각 사건이 발생할 가능성을 나타내는 확률 값이 반드시 필요합니다.
- **분산**: 기댓값을 기준으로 데이터가 얼마나 퍼져 있는지를 나타내는 척도로, 기댓값의 제곱의 평균에서 기댓값의 제곱을 빼서 구합니다.
- **평균**: 확률 변수의 경우 기댓값이 곧 평균의 역할을 수행하며, 데이터의 중심 경향성을 나타냅니다.
