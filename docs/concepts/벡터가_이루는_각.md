### 정확한 진술

영벡터가 아닌 두 평면벡터 $\vec{a}$, $\vec{b}$가 이루는 각을 $\theta$라 할 때, $0 \leq \theta \leq \pi$의 범위에서 다음을 만족하는 각입니다:

$$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$$

여기서 $\vec{a} \cdot \vec{b}$는 두 벡터의 내적, $|\vec{a}|$, $|\vec{b}|$는 각각의 크기입니다.

### 직관과 기하적 의미

두 벡터가 이루는 각은 시점을 같게 했을 때 두 벡터 사이의 각도를 뜻합니다. 각 $\theta$의 크기에 따라:
- $\theta = 0$ (또는 $\cos \theta = 1$): 두 벡터가 같은 방향
- $0 < \theta < \frac{\pi}{2}$: 예각으로 대체로 비슷한 방향
- $\theta = \frac{\pi}{2}$ (또는 $\cos \theta = 0$): 수직 (직교)
- $\frac{\pi}{2} < \theta < \pi$: 둔각으로 반대 방향에 가까움
- $\theta = \pi$ (또는 $\cos \theta = -1$): 정반대 방향

내적의 부호와 크기는 두 벡터의 방향 관계를 수량적으로 나타냅니다.

### 계산 예

$\vec{a} = (1, 2)$, $\vec{b} = (2, 1)$일 때 두 벡터가 이루는 각을 구하면:
- $\vec{a} \cdot \vec{b} = 1 \cdot 2 + 2 \cdot 1 = 4$
- $|\vec{a}| = \sqrt{1^2 + 2^2} = \sqrt{5}$, $|\vec{b}| = \sqrt{2^2 + 1^2} = \sqrt{5}$
- $\cos \theta = \frac{4}{5}$ ✓

(검산: `from sympy import acos, sqrt; theta = acos(4/5); print(float(theta))` 약 $0.6435$ rad ≈ $36.87°$)
