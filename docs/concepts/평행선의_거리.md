### 정확한 진술

두 평행선 $ax + by + c_1 = 0$과 $ax + by + c_2 = 0$ 사이의 거리는 다음 공식으로 구합니다:

$$d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}$$

두 직선의 $x$, $y$ 계수가 정확히 같다는 것은 평행하다는 의미입니다. 만약 직선 방정식이 다른 형태라면, 먼저 계수를 맞춰서 정규화한 후 이 공식을 적용합니다.

### 직관/기하적 의미

두 평행선 사이의 거리는 한 직선 위의 임의의 점에서 다른 직선까지 그은 수선의 길이입니다. 평행선은 절대 만나지 않으므로, 이 거리는 일정합니다.

공식의 구조를 보면: 분자 $|c_1 - c_2|$는 두 직선의 위치 차이를, 분모 $\sqrt{a^2 + b^2}$는 직선의 방향을 나타내는 정규화 계수입니다. 이는 점과 직선 사이의 거리 공식 $\frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$과 같은 논리로 유도됩니다. 한 직선 위의 점 $(x_0, y_0)$를 선택하면 $ax_0 + by_0 + c_1 = 0$이므로, 이 점에서 다른 직선까지의 거리가 바로 두 평행선 사이의 거리입니다.

### 한 줄 예

직선 $2x + y - 3 = 0$과 $2x + y + 5 = 0$ 사이의 거리는:

$$d = \frac{|-3 - 5|}{\sqrt{2^2 + 1^2}} = \frac{8}{\sqrt{5}} = \frac{8\sqrt{5}}{5}$$

검증: `sympy.sqrt(64/5)` = $\frac{8\sqrt{5}}{5}$ ✓
