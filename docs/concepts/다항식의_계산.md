# 다항식의 계산

## 요약
다항식의 덧셈, 뺄셈, 곱셈을 통해 식을 단순화하고 계산하는 과정이다.

## 본문
다항식의 계산이란 여러 개의 항으로 이루어진 다항식들 사이에서 덧셈, 뺄셈, 곱셈 연산을 수행하여 하나의 다항식으로 나타내는 과정을 의미한다. 다항식의 덧셈과 뺄셈은 동류항, 즉 문자와 차수가 같은 항들끼리 계수를 계산하여 정리하는 방식으로 이루어진다. 다항식의 곱셈은 분배법칙을 이용하여 각 항을 차례대로 곱한 후, 그 결과들을 모두 더하여 동류항을 정리함으로써 수행한다. 이러한 계산 과정은 복잡한 수식을 단순화하여 함수의 성질을 파악하거나 방정식의 해를 구하는 기초적인 단계가 된다.

### 직관과 기하적 의미
다항식의 덧셈은 서로 다른 도형의 넓이를 합치는 과정과 유사하며, 다항식의 곱셈은 직사각형의 가로와 세로 길이를 곱하여 넓이를 구하는 과정으로 이해할 수 있다. 예를 들어 $(x+a)(x+b)$의 곱셈은 한 변의 길이가 $x+a$이고 다른 한 변의 길이가 $x+b$인 직사각형의 넓이를 구하는 것과 같다.

### 기본 성질
다항식의 계산은 결합법칙과 교환법칙이 성립하여 계산의 순서를 바꾸거나 묶는 순서를 변경해도 결과가 동일하다. 또한, 분배법칙을 통해 괄호를 풀고 식을 전개할 수 있으며, 이는 복잡한 다항식 연산을 효율적으로 수행하게 돕는다.

## 학습 체크
- 동류항을 찾을 때 문자와 차수가 모두 일치하는지 확인하였는가?
- 다항식의 곱셈 시 분배법칙을 사용하여 모든 항이 빠짐없이 곱해졌는가?
- 계산 결과에서 부호 오류가 발생하지 않았는지 검토하였는가?

## 관련 개념
- **다항식**: 계산의 대상이 되는 기본 단위로, 여러 개의 항이 덧셈이나 뺄셈으로 연결된 식이다.
