### 정확한 진술

두 사건 $A$, $B$에 대하여 다음이 성립합니다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

여기서 $A \cup B$는 "$A$ 또는 $B$가 일어나는 사건", $A \cap B$는 "$A$와 $B$가 동시에 일어나는 사건"입니다. 특히 $A$와 $B$가 **서로소**(즉 $A \cap B = \emptyset$)이면 $P(A \cup B) = P(A) + P(B)$입니다.

### 직관 및 의미

공식을 유도하는 방법은 간단합니다. $A \cup B$를 겹치지 않는 영역들로 분할하면 다음과 같습니다.

$$A \cup B = (A - B) \cup (A \cap B) \cup (B - A)$$

이들 영역은 서로 겹치지 않으므로,

$$P(A \cup B) = P(A - B) + P(A \cap B) + P(B - A)$$

한편, $A = (A - B) \cup (A \cap B)$이고 $B = (B - A) \cup (A \cap B)$이므로,

$$P(A) = P(A - B) + P(A \cap B), \quad P(B) = P(B - A) + P(A \cap B)$$

따라서 $P(A) + P(B) = P(A - B) + P(B - A) + 2P(A \cap B)$이고, 이를 정리하면 위 공식을 얻습니다.

### 예제

주사위를 한 번 던질 때, $A$ = "3의 배수가 나올 사건" = $\{3, 6\}$, $B$ = "짝수가 나올 사건" = $\{2, 4, 6\}$이라 하면,

- $P(A) = \frac{2}{6} = \frac{1}{3}$
- $P(B) = \frac{3}{6} = \frac{1}{2}$  
- $A \cap B = \{6\}$이므로 $P(A \cap B) = \frac{1}{6}$

따라서 $P(A \cup B) = \frac{1}{3} + \frac{1}{2} - \frac{1}{6} = \frac{2}{6} + \frac{3}{6} - \frac{1}{6} = \frac{2}{3}$입니다.

(검산: $A \cup B = \{2, 3, 4, 6\}$이므로 $P(A \cup B) = \frac{4}{6} = \frac{2}{3}$ ✓)
