# 수열의 일반항

> **예제** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
주어진 조건에서 $a_n$ 구하기

## 본문 (학습 시 채워짐)

### 문제

첫째항 $a_1 = 2$이고 점화식 $a_{n+1} = a_n + 3n$을 만족하는 수열 $\{a_n\}$의 일반항 $a_n$을 구하세요.

### 풀이

**1단계: 점화식을 망원급수 형태로 변환**

점화식을 다시 정리하면 $a_{n+1} - a_n = 3n$입니다. 이렇게 연속된 항들의 차가 일정한 규칙을 따르는 경우, 망원급수(telescoping series) 기법으로 일반항을 구할 수 있습니다.

**2단계: 망원급수로 전개**

$n \geq 2$일 때 첫째항부터 제$n$항까지의 변화를 추적합니다:
$$a_n - a_1 = (a_2 - a_1) + (a_3 - a_2) + \cdots + (a_n - a_{n-1})$$

점화식을 대입하면:
$$a_n - a_1 = 3 \cdot 1 + 3 \cdot 2 + \cdots + 3(n-1) = 3(1 + 2 + \cdots + (n-1))$$

**3단계: 등차수열의 합 공식 적용**

$$1 + 2 + \cdots + (n-1) = \frac{(n-1)n}{2}$$

따라서:
$$a_n - 2 = 3 \cdot \frac{(n-1)n}{2}$$

**4단계: 정리**

$$a_n = 2 + \frac{3n(n-1)}{2} = \frac{4 + 3n^2 - 3n}{2} = \frac{3n^2 - 3n + 4}{2}$$

### 답

$$a_n = \frac{3n^2 - 3n + 4}{2}$$

### 변형/주의

- **검증**: $n=1$일 때 $a_1 = \frac{3-3+4}{2} = 2$ ✓, $n=2$일 때 점화식으로 $a_2 = 2 + 3(1) = 5$이고 공식으로도 $\frac{12-6+4}{2} = 5$ ✓
- **핵심 패턴**: 점화식이 $a_{n+1} - a_n = f(n)$ 형태면 망원급수로 항상 일반항을 구할 수 있습니다. 합의 범위(1부터 $n-1$까지)를 정확히 설정하는 것이 가장 중요합니다.
- **주의**: $n=1$일 때는 별도로 확인하여 공식이 성립하는지 반드시 검증하세요.
