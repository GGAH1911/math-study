### 정확한 진술

시그마 표기법 $\sum$는 수열의 합을 간단하게 나타내는 기호입니다. 일반적으로 다음과 같이 정의합니다:

$$\sum_{k=1}^{n} a_k = a_1 + a_2 + a_3 + \cdots + a_n$$

여기서:
- $\sum$ (대문자 시그마): 합을 의미하는 기호
- $k$: 더하기의 인덱스(변수)
- $1$: 시작 값
- $n$: 끝 값
- $a_k$: 더할 항들

예를 들어 $\sum_{k=1}^{5} k^2$는 $1^2 + 2^2 + 3^2 + 4^2 + 5^2$를 의미합니다.

### 직관/기하적 의미

수열의 항을 하나씩 모두 더하는 과정을 매번 글로 설명하면 복잡하고 길어집니다. 시그마 표기법은 이 반복 과정을 간결한 기호로 표현해서 수식을 정리된 형태로 만듭니다. 

시그마 아래의 $k=1$은 "첫 번째 항부터 시작"하고, 위의 $n$은 "마지막 $n$번째 항까지"라는 의미입니다. 인덱스 $k$는 $1$에서 $n$까지 하나씩 증가하면서 각 항 $a_k$를 계산하고, 그 모든 값들을 더합니다.

### 한 줄 예

$$\sum_{k=1}^{4} (2k-1) = 1 + 3 + 5 + 7 = 16$$

(검증: `sympy.summation(2*k - 1, (k, 1, 4))` → 16)

시그마 표기법을 사용하면 "첫 4개의 홀수를 모두 더한다"는 뜻을 $\sum_{k=1}^{4} (2k-1)$로 정확하고 간단하게 나타낼 수 있습니다.
