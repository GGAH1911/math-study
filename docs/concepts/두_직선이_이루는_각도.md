### 정확한 진술

두 직선 $y = m_1 x + b_1$과 $y = m_2 x + b_2$가 이루는 예각 (또는 특정 방향의 각)을 $\theta$라 하면, 다음 공식이 성립합니다.

$$\tan \theta = \left| \frac{m_1 - m_2}{1 + m_1 m_2} \right|$$

단, 두 직선이 수직이 아닐 때 성립하며, 절댓값을 붙이면 $0 < \theta < 90°$인 예각을 얻습니다. 절댓값 없이 사용하면 첫 번째 직선에서 두 번째 직선으로 **반시계 방향 회전각**을 구할 수 있습니다.

### 직관과 기하적 의미

기울기는 직선이 $x$축과 이루는 각의 탄젠트값입니다. $m_1 = \tan \alpha_1$, $m_2 = \tan \alpha_2$라 하면, 두 직선 사이의 각 $\theta = \alpha_1 - \alpha_2$이고, 탄젠트 덧셈 공식 $\tan(\alpha - \beta) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}$를 적용하면 위 식을 얻습니다. 

**도함수와의 연결**: 곡선 $y = f(x)$ 위의 점에서 접선의 기울기는 $f'(x)$입니다. 따라서 두 곡선이 한 점에서 만날 때 그들의 접선이 이루는 각도는 $\tan \theta = |f'(x) - g'(x)|/(1 + f'(x)g'(x))|$로 계산됩니다.

### 예시

직선 $y = 2x + 1$과 $y = -x + 3$이 이루는 예각을 구하면, $m_1 = 2$, $m_2 = -1$이므로:

$$\tan \theta = \left| \frac{2 - (-1)}{1 + 2 \cdot (-1)} \right| = \left| \frac{3}{-1} \right| = 3$$

따라서 $\theta = \arctan(3) \approx 71.57°$입니다. (`sympy.atan(3)*180/3.14159`로 확인 가능)
