# 블록묶음

## 정의

**블록묶음(묶음 처리)**은 순열·조합 문제에서 특정 원소들을 하나의 덩어리(블록)로 묶어 먼저 배열한 뒤, 블록 내부의 배열을 별도로 계산하는 기법이다. "A, B, C는 반드시 이웃해야 한다"처럼 인접 조건이 주어질 때, 해당 원소들을 하나의 원소로 취급하여 경우의 수를 구한다. 블록 전체 배열 수 × 블록 내부 배열 수의 곱으로 최종 경우의 수를 산출한다.

## 예시

A, B, C, D, E 다섯 명을 한 줄로 세울 때, A와 B가 반드시 이웃하는 경우의 수를 구하시오.

A, B를 하나의 블록 [AB]로 묶으면 [AB], C, D, E 총 4개를 나열하는 경우의 수: $4! = 24$

블록 내부에서 A, B의 순서: $2! = 2$

따라서 총 경우의 수 $= 24 \times 2 = 48$
