# 블록묶음

## 요약
특정 원소들이 이웃해야 하는 조건이 있을 때, 해당 원소들을 하나의 덩어리로 묶어 전체 배열을 구한 뒤 묶음 내부의 배열을 곱하여 경우의 수를 구하는 방법이다.

## 본문
블록묶음은 순열과 조합 문제에서 특정 원소들이 반드시 서로 이웃해야 한다는 조건이 주어졌을 때 사용하는 기법이다. 이 방법은 조건에 해당하는 원소들을 하나의 커다란 덩어리인 블록으로 간주하여 전체 원소의 개수를 줄여 계산하는 것이 핵심이다. 먼저 조건에 해당하는 원소들을 하나의 단위로 묶어 전체를 나열하는 경우의 수를 구한다. 그 다음, 묶인 블록 내부에서 원소들이 서로 자리를 바꾸는 경우의 수를 별도로 계산하여 두 값을 곱함으로써 최종적인 경우의 수를 산출한다.

### 직관과 기하적 의미
이 개념은 복잡한 제약 조건을 단순화하는 과정이다. 여러 개의 점이 서로 붙어 있어야 한다는 조건을 하나의 긴 막대로 치환하여 생각하면, 전체적인 배열의 구조를 훨씬 쉽게 파악할 수 있다. 즉, 개별 원소의 움직임을 관찰하는 대신 덩어리 단위의 움직임을 먼저 파악하는 방식이다.

### 기본 성질
블록묶음을 적용할 때 최종 결과값은 항상 (전체 덩어리의 배열 수) $\times$ (블록 내부의 배열 수)의 형태를 띤다. 만약 묶어야 할 원소가 $n$개이고 나머지 원소가 $m$개라면, 전체 배열은 $(m+1)!$의 형태를 가지며, 블록 내부의 배열은 $n!$의 형태를 갖게 된다.

## 학습 체크
- 이웃해야 하는 원소들을 하나의 덩어리로 취급했을 때, 전체 원소의 개수는 어떻게 변하는가?
- 블록 내부의 원소들이 서로 자리를 바꾸는 경우의 수를 계산할 때 주의할 점은 무엇인가?
- 특정 원소들이 이웃하지 않아야 하는 조건이 주어졌을 때, 블록묶음을 바로 적용할 수 있는가?
