### 정확한 진술

함수 $f: \mathbb{N} \to \mathbb{R}$의 **치역(치, range)**은 함수가 취하는 모든 함수값의 집합입니다.

$$\text{치역} = \{f(n) \mid n \in \mathbb{N}\}$$

정의역이 자연수로 제한되면, 함수값들도 특정한 집합을 이루게 됩니다. 이 집합이 치역입니다.

### 직관과 기하적 의미

정의역이 모든 실수가 아니라 자연수($1, 2, 3, \ldots$)로 제한되면, 함수는 **특정 점들에서만 값을 가집니다**. 예를 들어 $\sin(n)$ (여기서 $n \in \mathbb{N}$)은 $\sin(1), \sin(2), \sin(3), \ldots$만 취하므로, $[-1, 1]$의 모든 값을 취하는 일반적인 사인함수와 달리 **의도치 않은 점들의 모임**이 됩니다.

이렇게 띄엄띄엄 취해진 함수값들을 모두 모은 것이 치역입니다. 치역은 정의역이 자연수일 때 보통 유한 집합이거나 무한이지만 조밀하지 않은 집합이 됩니다.

### 예

$f(n) = 2\sin\left(\dfrac{n\pi}{6}\right)$ (단, $n = 1, 2, 3, \ldots$)라 하면:
- $f(1) = 2\sin(\pi/6) = 1$
- $f(2) = 2\sin(\pi/3) = \sqrt{3}$
- $f(3) = 2\sin(\pi/2) = 2$
- $f(4) = 2\sin(2\pi/3) = \sqrt{3}$
- $f(5) = 2\sin(5\pi/6) = 1$
- $f(6) = 2\sin(\pi) = 0$

이 함수의 치역은 $\{0, 1, \sqrt{3}, 2, -1, -\sqrt{3}\}$입니다.
