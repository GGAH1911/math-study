# 삼각방정식 풀이

> **예제** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
$\sin x=1/2$의 해

## 본문 (학습 시 채워짐)

### 문제

$0 \le x < 2\pi$ 범위에서 다음 방정식을 풀어라.
$$\sin x = \frac{1}{2}$$

### 단계별 풀이

**1단계: 기준각 찾기**

$\sin x = \frac{1}{2}$를 만족하는 기준각(제1사분면의 예각)을 찾는다. 삼각함수 특수각에서 $\sin \frac{\pi}{6} = \frac{1}{2}$이므로 기준각은 $\alpha = \frac{\pi}{6}$이다.

**2단계: 단위원에서 해의 위치 파악**

사인 값이 양수인 각은 제1, 제2사분면에만 존재한다. 단위원 위에서 $y$좌표가 $\frac{1}{2}$인 점을 찾으면:
- 제1사분면: 기준각 그대로 $x = \frac{\pi}{6}$
- 제2사분면: $\pi$ 에서 기준각을 뺀 $x = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$

**3단계: 범위 내 해 확인**

$0 \le x < 2\pi$ 범위에서 찾은 두 각은 모두 이 범위에 속한다. 제3, 제4사분면에서는 $\sin x < 0$이므로 추가 해는 없다.

### 답

$$x = \frac{\pi}{6} \text{ 또는 } x = \frac{5\pi}{6}$$

일반해 형태로 나타내면: $x = \frac{\pi}{6} + 2n\pi$ 또는 $x = \frac{5\pi}{6} + 2n\pi$ (단, $n$은 정수)

### 변형과 주의

**범위 확장**: $[0, 4\pi)$에서 풀면 주기성에 따라 해가 4개가 된다. $\frac{\pi}{6}, \frac{5\pi}{6}, \frac{13\pi}{6}, \frac{17\pi}{6}$

**대칭성 기억**: 제2사분면의 해는 항상 $\pi - (\text{기준각})$ 형태다. 기준각만 정확히 구하면 음수와 양수 구간의 해를 체계적으로 찾을 수 있다.

**부호 확인**: 각의 사분면과 삼각함수 값의 부호를 먼저 확인해야 한다. 예를 들어 $\sin x = -\frac{1}{2}$이면 제3, 제4사분면에서만 해를 찾는다.
