# 표본합의 분포

모집단에서 크기 $n$인 표본 $X_1, X_2, \ldots, X_n$을 임의추출할 때, 이 표본값들의 합

$$T = X_1 + X_2 + \cdots + X_n$$

을 **표본합**이라 한다. 표본을 어떻게 뽑느냐에 따라 $T$의 값이 달라지므로, $T$는 확률변수이며 그 분포를 **표본합의 분포**라 한다.

모집단의 평균이 $\mu$, 분산이 $\sigma^2$일 때 표본합의 기댓값과 분산은 다음과 같다.

$$E(T) = n\mu, \quad V(T) = n\sigma^2, \quad \sigma(T) = \sqrt{n}\,\sigma$$

모집단이 정규분포 $N(\mu,\,\sigma^2)$을 따르면 표본합도 정확히 정규분포를 따른다.

$$T \sim N(n\mu,\; n\sigma^2)$$

표본의 크기 $n$이 충분히 클 때는 모집단의 분포 형태에 관계없이 중심극한정리에 의해 $T$는 근사적으로 $N(n\mu,\, n\sigma^2)$을 따른다.

## 예시

**예시 1.** 평균이 $3$, 분산이 $4$인 모집단에서 크기 $16$인 표본을 뽑는다. 표본합 $T$의 평균과 표준편차를 구하면

$$E(T) = 16 \times 3 = 48, \quad \sigma(T) = \sqrt{16 \times 4} = \sqrt{64} = 8$$

이다.

**예시 2.** 모집단이 $N(5,\, 9)$를 따를 때 크기 $4$인 표본을 뽑으면

$$T \sim N(4 \times 5,\; 4 \times 9) = N(20,\; 36)$$

이므로 $T$를 표준화하면 $Z = \dfrac{T - 20}{6}$이 표준정규분포를 따른다. 예를 들어 $P(T \leq 26)$을 구하면

$$P\!\left(Z \leq \frac{26-20}{6}\right) = P(Z \leq 1) \approx 0.8413$$

이다.

## 관련 개념

**확률·통계(선수 개념)** — 확률변수의 기댓값과 분산 공식 $E(aX+b) = aE(X)+b$, $V(aX+b) = a^2 V(X)$, 그리고 독립인 확률변수의 합의 분산 $V(X_1 + \cdots + X_n) = V(X_1) + \cdots + V(X_n)$이 표본합의 분산 공식을 이끌어 내는 토대가 된다.

**표본평균의 분포** — 표본합 $T$와 표본평균 $\bar{X}$ 사이에는 $T = n\bar{X}$의 관계가 있으므로 두 분포는 본질적으로 같다. $E(\bar{X}) = \mu$, $V(\bar{X}) = \dfrac{\sigma^2}{n}$임을 알면 $E(T) = n\mu$, $V(T) = n\sigma^2$을 바로 유도할 수 있다.

**정규분포** — 모집단이 정규분포를 따를 때 표본합도 정규분포를 따른다는 사실이 핵심이다. 정규분포의 표준화 $Z = \dfrac{X - m}{s}$를 쓸 줄 알면 표본합에 관한 확률을 정규분포표로 계산할 수 있다.

**중심극한정리** — 모집단의 분포가 알려지지 않거나 정규분포가 아니더라도 $n$이 충분히 크면 표본합이 정규분포에 가까워진다는 정리로, 표본합의 분포가 실제 문제에 폭넓게 적용되는 이유가 된다.
