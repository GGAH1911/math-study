# 조건을 만족하는 값

## 정의

**조건을 만족하는 값** 이란, 주어진 등식·부등식·함수 관계 등의 조건을 동시에 충족하는 미지수의 값 또는 값의 집합을 말한다. 수능에서는 "함수 $f(x)$가 다음 조건을 만족시킬 때 $f(k)$의 값을 구하여라"와 같이 조건을 분석하여 특정 상수나 함수식을 결정하는 형태로 출제된다. 풀이 전략은 조건을 수식으로 번역 → 연립 또는 대입 → 유일한 값 확정 순서를 따른다.

## 예시

$f(x) = ax^2 + b$가 $f(1) = 3$, $f(-1) = 3$, $f(2) = 9$를 만족할 때 $a, b$를 구하여라.

$f(1) = a + b = 3$, $f(2) = 4a + b = 9$. 두 식을 빼면 $3a = 6$이므로 $a = 2$, $b = 1$.

검산: $f(-1) = 2 - 1 + 1 = 3$ ✓ → $a=2,\, b=1$.
