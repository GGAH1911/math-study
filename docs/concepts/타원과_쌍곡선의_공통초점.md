# 타원과 쌍곡선의 공통초점

## 요약
타원과 쌍곡선이 동일한 초점을 가질 때 이를 공통초점이라 하며, 두 곡선 위의 점과 초점 사이의 거리 관계를 이용해 선분의 길이와 넓이를 구하는 것이 핵심이다.

## 본문
타원 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$과 쌍곡선 $\dfrac{x^2}{c^2} - \dfrac{y^2}{d^2} = 1$이 두 초점을 공유할 때, 이 두 초점을 공통초점이라 한다. 타원의 초점 좌표는 $(\pm\sqrt{a^2 - b^2},\, 0)$이고 쌍곡선의 초점 좌표는 $(\pm\sqrt{c^2 + d^2},\, 0)$이므로, 두 곡선이 공통초점을 갖기 위해서는 $\sqrt{a^2 - b^2} = \sqrt{c^2 + d^2}$라는 조건이 성립해야 한다. 수능 및 모의고사에서는 이러한 공통초점을 공유하는 타원과 쌍곡선 위의 점 $P$에서 두 초점까지의 거리 관계식을 연립하여 선분의 길이 또는 도형의 넓이를 구하는 유형이 자주 출제된다.

### 직관과 기하적 의미
두 곡선이 같은 초점을 공유한다는 것은 두 곡선이 초점을 중심으로 하는 대칭 구조를 공유함을 의미한다. 타원은 초점으로부터의 거리의 합이 일정하고, 쌍곡선은 초점으로부터의 거리의 차가 일정하다는 성질을 동시에 활용하여 점 $P$의 위치를 결정할 수 있다.

### 기본 성질
예를 들어 타원 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$의 초점은 $c = \sqrt{25-16} = 3$이므로 $(\pm 3, 0)$이다. 만약 쌍곡선 $\dfrac{x^2}{k^2} - \dfrac{y^2}{d^2} = 1$이 이와 동일한 초점을 갖는다면 $\sqrt{k^2 + d^2} = 3$을 만족해야 한다. 이때 타원 위의 점 $P$에서 두 초점 $F_1, F_2$까지의 거리의 합은 타원의 장축의 길이인 $2a = 2 \times 5 = 10$이 된다.

## 학습 체크
- 타원과 쌍곡선의 초점 좌표 공식에서 부호($+$ 또는 $-$)가 왜 다른지 이해하였는가?
- 공통초점을 가진 두 곡선 위의 점 $P$에 대하여 $PF_1 + PF_2$와 $|PF_1 - PF_2|$의 값을 각각 구할 수 있는가?
