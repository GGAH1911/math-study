# 타원과 쌍곡선의 공통초점

## 정의

타원 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$과 쌍곡선 $\dfrac{x^2}{c^2} - \dfrac{y^2}{d^2} = 1$이 두 초점을 **공유**할 때, 이 두 초점을 **공통초점**이라 한다. 타원의 초점은 $(\pm\sqrt{a^2 - b^2},\, 0)$이고, 쌍곡선의 초점은 $(\pm\sqrt{c^2 + d^2},\, 0)$이므로, 공통초점이 되려면 $\sqrt{a^2 - b^2} = \sqrt{c^2 + d^2}$이어야 한다. 수능에서는 공통초점을 공유하는 타원과 쌍곡선 위의 점 $P$에서 두 초점까지의 거리 관계식을 연립하여 선분 길이 또는 넓이를 구하는 문제가 자주 출제된다.

## 예시

타원 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$ 의 초점: $c = \sqrt{25-16} = 3$ → 초점 $(\pm 3, 0)$.

쌍곡선 $\dfrac{x^2}{9} - \dfrac{y^2}{c'^2} = 1$ 이 동일 초점 $(\pm 3, 0)$을 갖도록 하면, $\sqrt{9 + c'^2} = 3$ → 성립하려면 $c'^2 = 0$ 이 되어 부적합하므로, 초점이 $(\pm 3, 0)$인 쌍곡선은 $\dfrac{x^2}{k^2} - \dfrac{y^2}{9-k^2} = 1\, (k < 3)$ 꼴이다.

타원 위의 점 $P$에서 두 초점 $F_1,F_2$까지의 거리의 합: $PF_1 + PF_2 = 2a = 10$.
