# 로그함수의 미분

## 요약
로그함수의 미분은 자연로그함수 $\ln x$의 도함수가 $\frac{1}{x}$임을 이용하여 복잡한 로그 형태의 함수를 미분하는 방법입니다.

## 본문
함수 $f(x) = \ln x$의 도함수는 $f'(x) = \frac{1}{x}$이다. 즉, 자연로그함수의 변화율은 역수 함수의 형태를 띠며, 이는 로그함수의 그래프에서 접선의 기울기가 $x$의 역수와 같음을 의미한다. 합성함수의 미분법을 적용하면 $\ln |f(x)|$의 미분은 $\frac{f'(x)}{f(x)}$가 된다. 이 원리를 이용하면 밑이 $e$가 아닌 일반적인 로그함수 $\log_a x$도 $\frac{1}{x \ln a}$로 미분할 수 있다.

### 직관과 기하적 의미
로그함수 $y = \ln x$의 그래프를 보면 $x$가 커질수록 기울기가 완만해지는데, 이는 도함수인 $\frac{1}{x}$이 $x$가 증가함에 따라 감소하는 것과 일치한다. 특히 $x=1$에서 접선의 기울기가 $1$이 되는 특징을 가진다.

### 기본 성질
1. $\frac{d}{dx}(\ln x) = \frac{1}{x}$ (단, $x > 0$)
2. $\frac{d}{dx}(\ln |f(x)|) = \frac{f'(x)}{f(x)}$
3. $\frac{d}{dx}(\log_a x) = \frac{1}{x \ln a}$

## 학습 체크
- 자연로그의 미분 결과가 왜 $x$의 역수 형태가 되는지 미분계수의 정의를 통해 설명할 수 있는가?
- 밑이 $e$가 아닌 로그함수를 미분할 때 $\ln a$가 분모에 붙는 이유를 합성함수의 미분법과 연결하여 이해했는가?

## 관련 개념
- **여러가지함수의 미분**: 로그함수의 미분은 지수함수의 미분과 함께 미분법의 핵심을 이루며, 다양한 초월함수의 도함수를 구하는 기초가 된다.
