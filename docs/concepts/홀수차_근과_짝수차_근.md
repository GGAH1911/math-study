# 홀수차 근과 짝수차 근

## 정의

다항함수 $f(x)$에서 $(x - a)^k$이 $f(x)$의 인수일 때, $x = a$를 $f(x)$의 **$k$중근**이라 한다. $k$가 홀수이면 **홀수차 근**, 짝수이면 **짝수차 근**이라 한다. 그래프의 관점에서, 홀수차 근에서는 $y = f(x)$의 그래프가 $x$축을 **가로질러** 지나가고, 짝수차 근에서는 $x$축에 **접하고 되돌아온다** (부호 유지). 이 성질은 수능에서 그래프의 개형을 결정할 때 핵심적으로 활용된다.

## 예시

$f(x) = (x+1)^2(x-2)^3$에서:

- $x = -1$: 2중근(짝수차) → 그래프가 $x$축에 접하고 되돌아감.
- $x = 2$: 3중근(홀수차) → 그래프가 $x$축을 가로지름.

따라서 $x < -1$에서 $f(x) > 0$, $-1 < x < 2$에서 $f(x) > 0$, $x > 2$에서 $f(x) > 0$이 되며 그래프는 $x = -1$에서 접선 형태를 그린 뒤 $x = 2$에서 축을 관통한다.
