# 유리수의 사칙연산

## 요약
유리수의 사칙연산은 분수를 통분하여 계산하거나 분자와 분모를 각각 계산하는 방식으로 수행하며, 나눗셈은 역수의 곱셈으로 변환하여 계산한다.

## 본문
유리수의 사칙연산은 두 유리수를 더하거나, 빼거나, 곱하거나, 나누는 네 가지 계산을 의미한다. 덧셈과 뺄셈은 분모를 통분하여 같게 만든 뒤 분자끼리 계산하며, 두 유리수 $\tfrac{a}{b}$와 $\tfrac{c}{d}$에 대하여 $\tfrac{a}{b} + \tfrac{c}{d} = \tfrac{ad + bc}{bd}$이고 $\tfrac{a}{b} - \tfrac{c}{d} = \tfrac{ad - bc}{bd}$이다. 이때 부호가 포함된 경우에는 양수와 음수의 덧셈 규칙을 함께 적용한다. 곱셈은 분자는 분자끼리, 분모는 분모끼리 곱하여 $\tfrac{a}{b} \times \tfrac{c}{d} = \tfrac{ac}{bd}$로 계산한다. 나눗셈은 나누는 수의 분자와 분모를 뒤집은 역수를 곱하는 것과 같으므로 $\tfrac{a}{b} \div \tfrac{c}{d} = \tfrac{a}{b} \times \tfrac{d}{c} = \tfrac{ad}{bc}$로 계산한다. 단, 어떤 수도 $0$으로 나눌 수 없다.

### 직관과 기하적 의미
유리수의 덧셈과 뺄셈은 수직선 위에서 두 지점 사이의 거리나 위치 변화로 이해할 수 있으며, 통분은 서로 다른 크기의 조각들을 같은 크기로 나누어 비교하거나 합치는 과정과 같다. 곱셈은 한 수의 일정 배만큼 이동하는 크기를 나타내며, 나눗셈은 한 수 안에 다른 수가 몇 번 포함되는지를 찾는 과정으로 해석할 수 있다.

### 기본 성질
덧셈과 곱셈에서는 계산 순서를 바꾸어도 결과가 같은 교환법칙과, 결합법칙이 성립한다. 또한 어떤 수에 $0$을 곱하면 항상 $0$이 되며, 나눗셈의 경우 나누는 수가 $0$이 아닐 때만 정의된다.

## 학습 체크
- 덧셈과 뺄셈을 할 때 분모를 통분한 후 분자 계산 시 부호를 어떻게 처리해야 하는가?
- 나눗셈을 곱셈으로 변환할 때 나누는 수의 분자와 분모를 어떻게 처리해야 하는가?
- 유리수의 곱셈과 나눗셈에서 결과값이 양수인지 음수인지 결정하는 부호 규칙은 무엇인가?

## 관련 개념

**정수와 유리수**는 이 연산의 대상이 되는 수 체계다. 정수는 유리수의 특수한 경우($\tfrac{a}{1}$ 꼴)이므로, 정수의 덧셈·뺄셈·곱셈 규칙이 유리수 연산에 그대로 확장되어 적용된다.

**약수와 배수** 개념은 통분과 약분의 바탕이 된다. 최소공배수를 이용해 통분하고, 최대공약수를 이용해 약분하므로, 사칙연산을 능숙하게 하려면 약수·배수 관계를 잘 파악해야 한다.

**역수**는 나눗셈을 곱셈으로 바꾸는 핵심 개념이다. $\tfrac{a}{b}$의 역수는 $\tfrac{b}{a}$이며, 두 수의 곱은 항상 $1$이 된다. 나눗셈을 역수의 곱셈으로 변환하는 원리를 이해하면 복잡한 분수 계산도 한결 쉬워진다.
