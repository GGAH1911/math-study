# 유리수의 사칙연산

유리수의 사칙연산은 두 유리수를 더하거나, 빼거나, 곱하거나, 나누는 네 가지 계산을 말한다.

**덧셈과 뺄셈**은 분모를 통분하여 같게 만든 뒤 분자끼리 계산한다. 두 유리수 $\dfrac{a}{b}$와 $\dfrac{c}{d}$에 대해

$$\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}, \qquad \frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}$$

이다. 부호가 있는 경우에는 양수·음수의 덧셈 규칙을 함께 적용한다.

**곱셈**은 분자는 분자끼리, 분모는 분모끼리 곱한다.

$$\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$$

**나눗셈**은 나누는 수의 분자와 분모를 뒤집은 역수를 곱하는 것과 같다.

$$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc}$$

단, 어떤 수도 $0$으로 나눌 수 없다.

## 예시

**예시 1 — 덧셈과 뺄셈**

$$\frac{1}{3} + \left(-\frac{3}{4}\right) = \frac{4}{12} + \left(-\frac{9}{12}\right) = \frac{4-9}{12} = -\frac{5}{12}$$

분모 $3$과 $4$의 최소공배수인 $12$로 통분한 뒤, 분자를 부호에 맞게 더한다.

**예시 2 — 곱셈과 나눗셈**

$$\left(-\frac{2}{5}\right) \div \frac{4}{15} = \left(-\frac{2}{5}\right) \times \frac{15}{4} = -\frac{30}{20} = -\frac{3}{2}$$

나눗셈을 역수의 곱셈으로 바꾼 뒤, 분자·분모를 약분하여 정리한다.

## 관련 개념

**정수와 유리수**는 이 연산의 대상이 되는 수 체계다. 정수는 유리수의 특수한 경우($\dfrac{a}{1}$ 꼴)이므로, 정수의 덧셈·뺄셈·곱셈 규칙이 유리수 연산에 그대로 확장되어 적용된다.

**약수와 배수** 개념은 통분과 약분의 바탕이 된다. 최소공배수를 이용해 통분하고, 최대공약수를 이용해 약분하므로, 사칙연산을 능숙하게 하려면 약수·배수 관계를 잘 파악해야 한다.

**역수**는 나눗셈을 곱셈으로 바꾸는 핵심 개념이다. $\dfrac{a}{b}$의 역수는 $\dfrac{b}{a}$이며, 두 수의 곱은 항상 $1$이 된다. 나눗셈을 역수의 곱셈으로 변환하는 원리를 이해하면 복잡한 분수 계산도 한결 쉬워진다.
