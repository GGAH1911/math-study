# 자연수 조건

## 요약
지수와 로그의 밑 조건에서 밑이 양수여야 한다는 제약 조건입니다.

## 본문
지수법칙을 확장하여 실수 범위에서 지수를 정의할 때, 밑은 반드시 $0$이 아닌 양수여야 합니다. 만약 밑이 음수라면 지수가 유리수나 실수로 확장될 때 결과값이 허수가 되거나 정의되지 않는 상황이 발생하여 함수의 연속성과 일관성이 깨지게 됩니다. 따라서 지수함수 $y=a^x$와 로그함수 $y=\log_a x$를 정의할 때, 밑 $a$는 항상 $a>0$인 조건을 만족해야 합니다.

### 직관과 기하적 의미
밑이 음수인 경우, 지수가 정수일 때는 결과가 양수와 음수를 번갈아 가며 나타나지만, 지수가 분수일 경우 허수가 발생하여 그래프가 끊기게 됩니다. 기하학적으로 지수함수가 매끄러운 곡선 형태를 유지하며 연속적인 함수로 존재하기 위해서는 밑이 양수여야만 합니다.

### 기본 성질
밑이 양수일 때 지수함수는 단조 증가 또는 단조 감소의 형태를 띠며, 로그함수는 밑이 $1$이 아닐 때 일대일 대응 관계를 가집니다. 만약 밑이 $1$이라면 $1^x=1$이 되어 상수함수가 되므로, 로그의 정의에서도 밑은 $1$이 아니어야 한다는 조건이 추가됩니다.

## 학습 체크
- 지수함수 $y=a^x$에서 밑 $a$가 $0$이 될 수 없는 이유는 무엇인가?
- 로그의 밑 조건에서 $a>0$ 외에 $a \neq 1$이라는 조건이 필요한 이유는 무엇인가?

## 관련 개념
- **지수와 로그**: 지수함수의 밑 조건은 로그의 밑 조건과 동일하게 적용되며, 로그는 지수의 역연산으로서 지수함수의 밑 조건을 그대로 계승합니다.
