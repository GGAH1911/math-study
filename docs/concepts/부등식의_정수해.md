### 정확한 진술

부등식의 **정수해**란, 주어진 부등식을 만족하면서 동시에 정수인 $x$ 값들의 집합입니다. 즉, 부등식의 해 집합 중에서 정수만 추려낸 것입니다. 예를 들어 $x > -2$의 해는 실수 전체 중 $-2$보다 큰 모든 수이지만, 정수해는 $-1, 0, 1, 2, \ldots$ 뿐입니다.

### 직관/기하적 의미

부등식의 해를 **수직선** 위에서 생각해봅시다. 일차부등식 $ax + b \geq c$는 수직선의 특정 구간 또는 반직선을 나타냅니다. 정수해는 이 구간/반직선 위에 점처럼 흩어져 있는 정수들입니다. 

이것이 중요한 이유는 **현실 문제**에서 "개수"를 세어야 할 때가 많기 때문입니다. "초콜릿을 나눠 먹는데, 한 명에게 3개씩 주면 2개가 남고, 4개씩 주면 부족하다"는 문제에서 초콜릿의 개수는 정수여야 하고, 부등식 조건을 동시에 만족해야 합니다.

### 예

**예시 1**: $-2 < x \leq 4$의 정수해를 구하세요.
- 수직선에서: $-2$는 포함 안 됨(열린 원), $4$는 포함됨(닫힌 원)
- 정수해: $-1, 0, 1, 2, 3, 4$ (총 6개)

**예시 2**: $2x - 5 > 3$의 정수해를 구하세요.
- 부등식을 풀면: $2x > 8$ → $x > 4$
- 정수해: $5, 6, 7, \ldots$ (무한개)

**예시 3**: $0.5x + 1 \leq 3.5$의 정수해를 구하세요.
- 부등식을 풀면: $0.5x \leq 2.5$ → $x \leq 5$
- 정수해: $\ldots, -2, -1, 0, 1, 2, 3, 4, 5$ (음의 무한대까지)

**검증**: `sympy.solve(2*x - 5 > 3, x)` 또는 부등식의 경계를 정수로 확인하여 어떤 정수부터 시작하는지 판단합니다.
