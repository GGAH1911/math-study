# 원과 호의 넓이

## 요약
정적분과 삼각치환법을 이용하여 반지름이 $r$인 원의 넓이와 활꼴의 넓이를 구할 수 있다.

## 본문
반지름이 $r$인 원의 방정식 $x^2 + y^2 = r^2$의 넓이는 정적분을 통해 엄밀하게 계산할 수 있다. 원의 위쪽 반원은 $y = \sqrt{r^2 - x^2}$이고 아래쪽 반원은 $y = -\sqrt{r^2 - x^2}$이므로, 원 전체의 넓이 $S$는 위아래 대칭성을 이용하여 다음과 같이 정의된다.
$$S = 2\int_{-r}^{r} \sqrt{r^2 - x^2}\, dx = \pi r^2$$
또한 원 $x^2 + y^2 = r^2$에서 직선 $x = a$ (단, $-r < a < r$)의 한쪽에 해당하는 활꼴의 넓이 역시 동일한 적분 방식을 적용하여 구할 수 있다. 위아래 대칭을 고려하면 활꼴의 넓이는 다음과 같다.
$$S = 2\int_{a}^{r} \sqrt{r^2 - x^2}\, dx$$
이때 $\sqrt{r^2 - x^2}$ 형태의 피적분함수를 적분하기 위해서는 $x = r\sin\theta$로 치환하는 삼각치환법을 사용한다. 이 과정을 거치면 루트 안의 식이 $r^2\cos^2\theta$로 변하여 제곱근이 제거되며, 이후 반각 공식인 $\cos^2\theta = \dfrac{1+\cos 2\theta}{2}$를 이용하여 적분을 마무리할 수 있다.

### 직관과 기하적 의미
원의 넓이를 구하는 과정은 곡선으로 둘러싸인 영역을 수직으로 잘게 나누어 그 높이를 모두 더하는 과정과 같다. 활꼴의 넓이를 구하는 것은 원의 전체 면적에서 특정 구간을 제외하거나, 특정 구간에 해당하는 부분 면적만을 추출하는 기하학적 의미를 갖는다.

### 기본 성질
- 원의 방정식 $x^2 + y^2 = r^2$은 원점에 중심을 둔 반지름이 $r$인 원을 나타낸다.
- 삼각치환법을 사용할 때 $x = r\sin\theta$로 치환하면 $dx = r\cos\theta\,d\theta$가 된다.
- 적분 계산 과정에서 $\cos^2\theta$를 $\cos 2\theta$를 포함한 식으로 변환하는 것이 핵심이다.

## 학습 체크
- 반지름이 $r$인 원의 넓이를 구할 때 왜 적분 구간을 $-r$에서 $r$까지로 설정하고 $2$를 곱해야 하는가?
- 활꼴의 넓이를 구할 때 $x = r\sin\theta$로 치환하면 적분 구간(범위)은 어떻게 변화하는가?
- $\sqrt{r^2 - x^2}$ 형태의 함수를 적분할 때 삼각치환법을 사용하는 이유는 무엇인가?

## 관련 개념

**정적분의 활용**에서 배우는 두 곡선 사이의 넓이 공식 $\displaystyle\int_a^b\{f(x)-g(x)\}\,dx$의 특수한 경우가 바로 원과 호의 넓이다. 원에서는 $f(x) = \sqrt{r^2-x^2}$과 $g(x) = -\sqrt{r^2-x^2}$을 한꺼번에 처리하거나, 대칭을 이용해 위쪽 절반만 적분한 뒤 두 배로 계산한다.

**평면도형**에서 배운 원의 기본 용어가 적분 구간 설정의 토대가 된다. 호(arc), 현(chord), 활꼴(circular segment), 부채꼴(sector)이 무엇인지 명확히 알아야 어느 영역의 경계를 $x = a$와 $x = b$로 표현할 수 있는지 파악할 수 있다.

**삼각치환**은 이 단원의 핵심 계산 도구다. $\sqrt{r^2 - x^2}$ 꼴이 나오면 $x = r\sin\theta$로 치환하고, 이후 $\cos^2\theta = \dfrac{1+\cos 2\theta}{2}$ 공식으로 마무리하는 흐름을 손에 익혀야 한다.

**부채꼴의 넓이** $\dfrac{1}{2}r^2\theta$를 아는 경우, 활꼴 넓이 = 부채꼴 넓이 − 삼각형 넓이로도 구할 수 있다. 이 기하적 방법과 정적분 결과를 대조하면 계산 실수를 점검하기 좋다. 예시 2에서 반지름 2, 중심각 $\dfrac{\pi}{3}$인 부채꼴 넓이 $\dfrac{2\pi}{3}$에서 삼각형 넓이 $\dfrac{\sqrt{3}}{2}$를 빼면 $\dfrac{2\pi}{3}-\dfrac{\sqrt{3}}{2}$이고, 이것의 두 배가 $\dfrac{4\pi}{3}-\sqrt{3}$으로 적분 결과와 일치함을 확인할 수 있다.
