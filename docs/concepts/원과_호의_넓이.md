# 원과 호의 넓이

반지름이 $r$인 원 $x^2 + y^2 = r^2$의 넓이는 정적분으로 엄밀하게 구할 수 있다. 원의 위쪽 절반이 $y = \sqrt{r^2 - x^2}$이고, 아래쪽이 $y = -\sqrt{r^2 - x^2}$이므로 원 전체의 넓이 $S$는

$$S = 2\int_{-r}^{r} \sqrt{r^2 - x^2}\, dx = \pi r^2$$

이다. 또한 원 $x^2 + y^2 = r^2$에서 직선 $x = a\;(-r < a < r)$의 한쪽에 해당하는 **활꼴**의 넓이도 같은 방식으로 구한다. 위아래 대칭을 이용하면

$$S = 2\int_{a}^{r} \sqrt{r^2 - x^2}\, dx$$

이다. $\sqrt{r^2 - x^2}$ 형태의 피적분함수는 $x = r\sin\theta$로 치환하면 루트 안이 $r^2\cos^2\theta$로 바뀌어 제곱근이 사라지고, 이후 $\cos^2\theta = \dfrac{1+\cos 2\theta}{2}$ 공식으로 계산을 마무리한다.

---

## 예시

**예시 1.** 원 $x^2 + y^2 = 1$의 넓이를 정적분으로 구한다.

$x = \sin\theta$로 치환하면 $dx = \cos\theta\,d\theta$이고, $x$가 $-1$에서 $1$로 바뀔 때 $\theta$는 $-\dfrac{\pi}{2}$에서 $\dfrac{\pi}{2}$로 바뀐다.

$$S = 2\int_{-1}^{1}\sqrt{1-x^2}\,dx = 2\int_{-\pi/2}^{\pi/2}\cos^2\theta\,d\theta = \int_{-\pi/2}^{\pi/2}(1+\cos 2\theta)\,d\theta = \left[\theta + \frac{\sin 2\theta}{2}\right]_{-\pi/2}^{\pi/2} = \pi$$

**예시 2.** 원 $x^2 + y^2 = 4$에서 $x \geq 1$인 활꼴의 넓이를 구한다.

위아래 대칭이므로 $S = 2\displaystyle\int_{1}^{2}\sqrt{4-x^2}\,dx$이다. $x = 2\sin\theta$로 놓으면 $x=1$일 때 $\theta=\dfrac{\pi}{6}$, $x=2$일 때 $\theta=\dfrac{\pi}{2}$이므로

$$S = 2\int_{\pi/6}^{\pi/2}2\cos\theta\cdot 2\cos\theta\,d\theta = 8\int_{\pi/6}^{\pi/2}\cos^2\theta\,d\theta = 4\left[\theta + \frac{\sin 2\theta}{2}\right]_{\pi/6}^{\pi/2}$$

대입하면 $\theta = \dfrac{\pi}{2}$일 때 값은 $\dfrac{\pi}{2}$, $\theta = \dfrac{\pi}{6}$일 때 값은 $\dfrac{\pi}{6}+\dfrac{\sqrt{3}}{4}$이므로

$$S = 4\left(\frac{\pi}{3} - \frac{\sqrt{3}}{4}\right) = \frac{4\pi}{3} - \sqrt{3}$$

## 관련 개념

**정적분의 활용**에서 배우는 두 곡선 사이의 넓이 공식 $\displaystyle\int_a^b\{f(x)-g(x)\}\,dx$의 특수한 경우가 바로 원과 호의 넓이다. 원에서는 $f(x) = \sqrt{r^2-x^2}$과 $g(x) = -\sqrt{r^2-x^2}$을 한꺼번에 처리하거나, 대칭을 이용해 위쪽 절반만 적분한 뒤 두 배로 계산한다.

**평면도형**에서 배운 원의 기본 용어가 적분 구간 설정의 토대가 된다. 호(arc), 현(chord), 활꼴(circular segment), 부채꼴(sector)이 무엇인지 명확히 알아야 어느 영역의 경계를 $x = a$와 $x = b$로 표현할 수 있는지 파악할 수 있다.

**삼각치환**은 이 단원의 핵심 계산 도구다. $\sqrt{r^2 - x^2}$ 꼴이 나오면 $x = r\sin\theta$로 치환하고, 이후 $\cos^2\theta = \dfrac{1+\cos 2\theta}{2}$ 공식으로 마무리하는 흐름을 손에 익혀야 한다.

**부채꼴의 넓이** $\dfrac{1}{2}r^2\theta$를 아는 경우, 활꼴 넓이 = 부채꼴 넓이 − 삼각형 넓이로도 구할 수 있다. 이 기하적 방법과 정적분 결과를 대조하면 계산 실수를 점검하기 좋다. 예시 2에서 반지름 2, 중심각 $\dfrac{\pi}{3}$인 부채꼴 넓이 $\dfrac{2\pi}{3}$에서 삼각형 넓이 $\dfrac{\sqrt{3}}{2}$를 빼면 $\dfrac{2\pi}{3}-\dfrac{\sqrt{3}}{2}$이고, 이것의 두 배가 $\dfrac{4\pi}{3}-\sqrt{3}$으로 적분 결과와 일치함을 확인할 수 있다.
