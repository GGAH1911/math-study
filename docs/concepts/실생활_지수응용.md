# 실생활 지수응용

> **예제** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
복리·반감기

## 본문 (학습 시 채워짐)

### 문제

은행에 100만 원을 연 5% 복리로 정기예금에 넣었습니다. 5년 후 원리금 합계는 얼마입니까? (단, $1.05^5 \approx 1.276$)

### 단계별 풀이

**1단계: 복리 모델 수립**
매년 말의 잔액이 전년도의 1.05배가 되므로, $n$년 후 잔액을 $A_n$이라 하면:
$$A_n = A_0(1 + r)^n$$
여기서 $A_0 = 100$ (만 원), $r = 0.05$ (연 5%), $n = 5$ (년).

**2단계: 지수식에 값 대입**
정의에 맞춰 대입하면:
$$A_5 = 100 \times (1.05)^5$$
주어진 근삿값을 사용해 계산합니다.

**3단계: 계산 수행**
$$A_5 = 100 \times 1.276 = 127.6 \text{ (만 원)}$$
따라서 원리금 합계는 127만 6000원입니다.

**4단계: 의미 확인**
초기금 100만 원에서 5년 동안 이자 27만 6000원을 얻었고, 이는 단리 이자(25만 원)보다 큼을 알 수 있습니다.

### 답

**127만 6000원**

(`sympy.N(100 * 1.05**5)`로 확인하면 127.628...)

### 변형 및 주의

**반감기 응용**: 방사성 물질의 잔량도 같은 구조입니다. 반감기가 $T$일 때 $t$일 후 잔량은 $A(t) = A_0 \left(\frac{1}{2}\right)^{t/T}$. 예를 들어 반감기 8일인 물질 64g은 16일 후 $(64 \times 0.5^{16/8} = 16\text{g})$로 감소합니다.

**주의**: 복리 계산 시 "연"의 의미를 명확히 하세요. 분기별·월별 복리라면 지수의 밑과 지수를 조정해야 합니다. 예를 들어 월 복리면 $A = A_0(1 + r/12)^{12n}$입니다.
