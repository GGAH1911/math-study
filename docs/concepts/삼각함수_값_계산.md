# 삼각함수 값 계산

## 요약
삼각함수의 정의를 바탕으로 특수각의 삼각비와 단위원을 이용하여 $\sin, \cos, \tan$의 값을 구하는 과정입니다.

## 본문
삼각함수의 값은 직각삼각형의 변의 길이의 비 또는 단위원 위의 점의 좌표를 통해 결정됩니다. 반지름의 길이가 $1$인 단위원 위를 움직이는 동경이 $x$축의 양의 방향과 이루는 각을 $\theta$라고 할 때, 점 $(x, y)$의 좌표는 각각 $\cos\theta$와 $\sin\theta$의 값이 됩니다. 이때 $\tan\theta$는 두 좌표의 비율인 $\frac{y}{x}$로 정의됩니다. 각도가 $0^\circ$에서 $90^\circ$ 사이인 경우, 직각삼각형의 밑변, 높이, 빗변의 길이를 이용하여 삼각비의 개념으로 값을 구할 수 있으며, 이를 통해 $30^\circ, 45^\circ, 60^\circ$와 같은 특수각에 대한 값을 암기하거나 유도하여 계산에 활용합니다.

### 직관과 기하적 의미
단위원을 활용하면 각의 크기가 $90^\circ$를 넘어 $360^\circ$ 이상으로 커지더라도 삼각함수의 값을 정의할 수 있습니다. 이는 단순히 삼각형의 변의 길이를 구하는 것을 넘어, 회전 운동을 좌표 평면상의 위치로 변환하여 해석하는 도구가 됩니다.

### 기본 성질
$\sin\theta$와 $\cos\theta$의 값은 항상 $-1$과 $1$ 사이의 값을 가지며, $\tan\theta$는 모든 실수 값을 가질 수 있습니다. 또한, $\tan\theta = \frac{\sin\theta}{\cos\theta}$라는 관계가 성립합니다.

## 학습 체크
- $30^\circ, 45^\circ, 60^\circ$ 각에 대한 $\sin, \cos, \tan$ 값을 표로 나타내어 암기하고 있는가?
- 단위원을 이용하여 각의 사분면에 따른 삼각함수의 부호($+$, $-$)를 판별할 수 있는가?
- $\sin^2\theta + \cos^2\theta = 1$과 같은 기본 항등식을 활용하여 미지의 값을 구할 수 있는가?

## 관련 개념
- **삼각함수**: 삼각함수의 값을 구하는 것은 삼각함수라는 함수 자체의 함숫값을 결정하는 기초적인 과정입니다.
- **삼각비**: 삼각비는 직각삼각형에서의 변의 길이의 비율을 의미하며, 삼각함수의 값이 정의되는 근간이 됩니다.
