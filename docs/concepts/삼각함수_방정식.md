# 삼각함수 방정식

## 요약
삼각함수의 함숫값이 특정 값을 갖도록 하는 미지수 $x$의 값을 찾는 과정으로, 삼각함수의 주기성과 대칭성을 활용하여 일반해를 구하는 것이 핵심입니다.

## 본문
삼각함수 방정식은 $\sin x = a$, $\cos x = a$, $\tan x = a$와 같이 삼각함수의 값이 특정한 상수가 되도록 하는 미지수 $x$의 값을 구하는 방정식을 의미합니다. 이때 $a$의 값에 따라 해의 존재 여부가 결정되는데, $\sin x = a$ 또는 $\cos x = a$의 경우 $-1 \le a \le 1$이어야 해가 존재하며, $\tan x = a$는 모든 실수 $a$에 대해 해가 존재합니다. 삼각함수는 주기함수이므로 하나의 해를 찾으면 주기성을 이용하여 무수히 많은 해를 나타낼 수 있으며, 이를 일반해라고 합니다.

### 직관과 기하적 의미
단위원 위에서 $x$를 동경의 각으로 보았을 때, 삼각함수의 값은 동경과 각 축이 만나는 점의 좌표로 해석할 수 있습니다. 예를 들어 $\sin x = a$는 단위원 위의 점의 $y$좌표가 $a$가 되는 지점들을 찾는 것과 같으며, 이는 원과 직선의 교점을 찾는 기하학적 문제로 직결됩니다.

### 기본 성질
삼각함수 방정식의 해를 구할 때는 함수의 대칭성을 활용하는 것이 가장 효율적입니다. $\sin x = \sin \alpha$의 해는 $x = n\pi + (-1)^n \alpha$ (단, $n$은 정수)로 나타낼 수 있으며, $\cos x = \cos \alpha$의 해는 $x = 2n\pi \pm \alpha$로 나타낼 수 있습니다. $\tan x = \tan \alpha$의 해는 $x = n\pi + \alpha$로 나타납니다.

## 학습 체크
- 주어진 삼각함수의 값이 $-1$과 $1$ 사이의 범위에 있는지 확인하였는가?
- 삼각함수의 대칭성을 이용하여 해의 범위를 제한했을 때 누락된 해가 없는가?
- 일반해를 구할 때 주기성을 고려하여 정수 $n$을 포함한 형태로 정확히 표현하였는가?

## 관련 개념
- **삼각함수**: 방정식의 좌변을 구성하는 함수로서, 주기성과 대칭성을 제공하여 해의 구조를 결정합니다.
- **삼각함수의 그래프**: 방정식의 해를 그래프의 교점의 $x$좌표로 시각화하여 직관적으로 이해할 수 있게 합니다.
- **단위원**: 삼각함수의 값을 좌표로 정의하여 방정식의 해를 기하학적으로 해석하는 도구가 됩니다.
