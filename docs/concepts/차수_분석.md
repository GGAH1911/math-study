### 정확한 진술

차수 분석(order analysis)은 두 수열이나 함수의 극한 상황에서의 상대적 성장률을 비교하는 방법입니다. 주로 다음 두 가지 표기로 정의합니다:

**Big-O 표기**: $f(n) = O(g(n))$ 
$$\Leftrightarrow \exists C > 0, N \in \mathbb{N} \text{ such that } |f(n)| \leq C|g(n)| \text{ for all } n > N$$

**Little-o 표기**: $f(n) = o(g(n))$
$$\Leftrightarrow \lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$$

### 직관/기하적 의미

차수 분석은 **함수의 주도적인 항(dominant term)이 무엇인지 파악**하는 도구입니다. 

$f(n) = O(g(n))$은 "$n$이 충분히 클 때 $f(n)$이 $g(n)$의 상수배 이내로 제어된다"는 뜻입니다. 즉, $g(n)$이 $f(n)$의 '상한'이 됩니다.

$f(n) = o(g(n))$은 더 강한 조건으로, "$f(n)$이 $g(n)$보다 훨씬 느리게 증가한다"는 의미입니다. 예컨대 $n$이 증가할수록 $\frac{f(n)}{g(n)}$의 비율이 0으로 수렴합니다.

실제로 복잡한 식 $2n^3 + 100n^2 + 5n + 3$을 분석할 때, 큰 $n$에 대해 $n^3$항이 지배적이므로 전체 식을 $O(n^3)$으로 평가할 수 있습니다.

### 한 줄 예

$f(n) = 3n^2 + 2n$, $g(n) = n^2$일 때: $f(n) = O(n^2)$ (상수배로 제어) 이고 $2n = o(n^2)$ (더 느리게 증가)

→ `sympy.limit((3*n**2 + 2*n)/n**2, n, oo)` = $3$이므로 $f(n) = O(g(n))$; `sympy.limit(2*n/n**2, n, oo)` = $0$이므로 $2n = o(n^2)$

이 개념은 **알고리즘의 시간복잡도**, **수열의 수렴 속도**, **테일러 전개의 오차항** 분석 등에서 필수적입니다.
