### 정확한 진술

함수 $f: D \to \mathbb{R}$가 정의역 $D$에서 정의되어 있을 때, $D$의 부분집합 $D' \subseteq D$를 새로운 정의역으로 지정하여 함수 $f|_{D'}: D' \to \mathbb{R}$를 만드는 것을 **정의역 제한**(restriction of domain)이라고 합니다. 이때 $D'$를 **제한된 정의역**, 원래의 $f|_{D'}$를 **제한된 함수**라고 부릅니다.

### 직관/기하적 의미

함수는 정의역에서 치역으로 가는 대응 관계입니다. 정의역을 제한한다는 것은 이 대응을 "일부만" 보는 것입니다. 예를 들어 포물선 $y = x^2$는 모든 $x$에 대해 정의되지만, 학생이 $0 \le x \le 3$ 범위의 구간에서만 문제를 풀도록 제한할 수 있습니다. 그래프상으로는 포물선의 일부분만 그리는 것과 같습니다.

이 개념은 다음과 같은 상황에서 중요합니다:
- **최댓값과 최솟값**: 제한된 정의역에서 함수는 서로 다른 최댓값이나 최솟값을 가질 수 있습니다.
- **일대일 대응**: 일부 함수는 정의역 전체에서는 일대일 대응이 아니지만, 정의역을 제한하면 일대일 대응이 될 수 있습니다. 예를 들어 $f(x) = x^2$는 $x \ge 0$ 범위에서만 제한하면 일대일 대응이 됩니다.

### 한 줄 예

$f(x) = x^2$에 대해 정의역을 $[0, 2]$로 제한하면 $f|_{[0,2]}: [0, 2] \to [0, 4]$이고, 이 함수의 최댓값은 $4$ (at $x=2$), 최솟값은 $0$ (at $x=0$)입니다.

```python
# sympy로 검증: 제한된 정의역 [0,2]에서 f(x)=x^2의 최대/최소
import sympy as sp
x = sp.Symbol('x')
f = x**2
print(f"f(0) = {f.subs(x, 0)}, f(2) = {f.subs(x, 2)}")  # 0, 4
```
