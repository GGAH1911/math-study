# 경우 분류

## 요약
어떤 사건이 일어날 수 있는 모든 상황을 서로 겹치지 않고 빠짐없이 나누어 각각의 경우를 구하는 방법입니다.

## 본문
경우의 수를 구할 때 가장 중요한 원칙 중 하나는 중복 없이, 그리고 빠짐없이 사건을 나누는 것입니다. 경우 분류란 전체 사건을 서로 배반인(동시에 일어날 수 없는) 여러 가지 부분 사건으로 나누어 각각의 경우의 수를 구한 뒤, 이를 모두 더하여 전체 경우의 수를 구하는 전략을 의미합니다. 복잡한 조건이 붙은 문제일수록 기준을 명확히 설정하여 사건을 분류하는 것이 문제 해결의 핵심입니다.

### 직관과 기하적 의미
우리가 어떤 복잡한 모양의 도형의 넓이를 구할 때, 이를 다루기 쉬운 삼각형이나 사각형으로 나누어 각각의 넓이를 더하는 과정과 논리적으로 동일합니다. 전체를 한 번에 계산하기 어려울 때, 계산이 용이한 작은 조각들로 쪼개어 각각의 값을 구한 뒤 합치는 과정이 바로 경우 분류의 직관적 의미입니다.

### 기본 성질
경우 분류를 수행할 때는 분류된 각 사건들이 서로 겹치지 않아야 하며, 모든 가능한 상황이 포함되어야 합니다. 만약 분류된 사건들 사이에 중복되는 부분이 있다면 결과값이 실제보다 크게 계산되고, 누락된 부분이 있다면 결과값이 실제보다 작게 계산됩니다. 따라서 분류의 기준이 되는 조건이 명확하고 상호 배타적인지를 확인하는 것이 필수적입니다.

## 학습 체크
- 사건을 분류할 때 기준이 되는 조건이 모든 경우를 포함하고 있는가?
- 분류된 각 경우들이 서로 동시에 일어날 수 없는 독립적인 상황인가?
- 분류된 각 경우의 수를 구한 후 합산하는 과정에서 중복 계산된 것은 없는가?

## 관련 개념
- **경우의 수**: 경우 분류를 통해 나누어진 각 부분 사건의 개수를 모두 합하여 최종적인 전체 경우의 수를 결정합니다.
