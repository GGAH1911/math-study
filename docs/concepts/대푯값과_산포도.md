# 대푯값과 산포도

> **단원** · 중3 · 선수: [확률 중2](./확률_중2.md) / [실수와 그 계산](./실수와_그_계산.md) · 다음: [통계](./통계.md)

## 학습 목표
- 평균·중앙값·최빈값을 구분해 사용한다
- 편차·분산·표준편차의 의미를 이해한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 평균, 중앙값, 최빈값
- 편차, 분산, 표준편차

**정리(theorem)**
- 표준편차 = $\sqrt{\text{분산}}$
- 분산이 클수록 자료가 평균에서 멀리 퍼짐

**예제(example)**
- 평균·분산 계산
- 두 집단 비교
- 도수분포표에서 평균 추정
