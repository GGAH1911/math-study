# 회전체 부피

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
회전축 기준 부피

## 본문 (학습 시 채워짐)

### 정확한 진술

평면곡선 $y = f(x)$ (단, $f(x) \geq 0$)을 $x$축 중심으로 회전시킨 회전체의 부피는 다음과 같이 정의됩니다:

$$V = \int_a^b \pi [f(x)]^2 \, dx$$

여기서 $a \leq x \leq b$는 회전시킬 곡선의 구간이고, $\pi [f(x)]^2$는 위치 $x$에서의 단면(원판)의 넓이입니다. 마찬가지로 $y$축 중심 회전이나 일반적인 수평선 $y = c$를 중심으로 한 회전의 경우도 같은 원리로 확장됩니다.

### 기하적 의미

회전체는 곡선이 축을 중심으로 한 바퀴 도는 과정에서 그려내는 입체도형입니다. 이 입체를 두께 $dx$인 얇은 원판들로 자르면, 위치 $x$에서 각 원판의 반지름은 $f(x)$이므로 넓이는 $\pi [f(x)]^2$입니다. 이 원판들을 구간 $[a,b]$에서 무한히 많이 쌓으면 회전체가 됩니다. 따라서 정적분 $\int_a^b \pi [f(x)]^2 \, dx$는 이 모든 원판의 부피를 합한 것이 됩니다. 이 아이디어는 부정적분(원시함수)을 통해 구체적으로 계산할 수 있습니다.

### 예

$y = x$, $x \in [0, 2]$를 $x$축 중심으로 회전시킨 부피:
$$V = \int_0^2 \pi x^2 \, dx = \pi \left[ \frac{x^3}{3} \right]_0^2 = \frac{8\pi}{3}$$

(`sympy.pi * sympy.integrate(x**2, (x, 0, 2))` → $\frac{8\pi}{3}$)

이 경우 원뿔 모양의 회전체가 만들어집니다.
