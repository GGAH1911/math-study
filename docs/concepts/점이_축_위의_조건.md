### 정확한 진술

3차원 좌표계에서 점 $P(x, y, z)$가 다음 조건을 만족할 때, 각 축 위의 점입니다.

- **$x$축 위**: $y = 0, z = 0$ (점의 형태: $(x, 0, 0)$)
- **$y$축 위**: $x = 0, z = 0$ (점의 형태: $(0, y, 0)$)
- **$z$축 위**: $x = 0, y = 0$ (점의 형태: $(0, 0, z)$)

즉, 점이 어떤 축 위에 있으려면 그 축에 해당하는 좌표만 0이 아닌 값을 가지고, 나머지 두 좌표는 반드시 0이어야 합니다.

### 직관/기하적 의미

축은 3차원 공간에서 1차원의 직선입니다. 축 위의 점이 되려면 한 방향으로만 이동할 수 있고, 다른 모든 방향에서는 제약을 받아야 합니다. 

$x$축 위의 점들을 모두 모으면 $\{(t, 0, 0) : t \in \mathbb{R}\}$이 되는데, 이는 $x$축 방향으로만 자유롭게 움직이고 $yz$-평면에는 모두 0에 고정된 상태입니다. 마찬가지로 $y$축 위의 점은 $xz$-평면 위에서, $z$축 위의 점은 $xy$-평면 위에서 각각 하나의 좌표축이 고정됩니다.

이는 "축"이라는 이름의 의미와도 일치합니다. 회전의 중심이 되는 축처럼, 좌표축은 해당 방향만 변할 수 있는 1차원 구조입니다.

### 한 줄 예

점 $A(5, 0, 0)$은 $x$축 위의 점입니다 ($y = 0, z = 0$ 만족).  
점 $B(0, -3, 0)$은 $y$축 위의 점입니다 ($x = 0, z = 0$ 만족).  
점 $C(0, 0, 7)$은 $z$축 위의 점입니다 ($x = 0, y = 0$ 만족).  
점 $D(2, 1, 0)$은 어느 축 위에도 있지 않습니다 ($x \neq 0, y \neq 0$이므로 축 조건 불만족).
