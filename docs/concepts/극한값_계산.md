# 극한값 계산

## 요약
함수나 수열이 특정 값에 무한히 가까워질 때 도달하고자 하는 목표 값을 구하는 과정입니다.

## 본문
함수 $f(x)$에서 변수 $x$가 어떤 값 $a$에 한없이 가까워질 때, 함수값 $f(x)$가 일정한 값 $L$에 한없이 가까워지면 우리는 $L$을 함수 $f(x)$의 극한값이라 하며, 이를 $\lim_{x \to a} f(x) = L$로 나타냅니다. 이때 $x$는 $a$에 도달하지 않고 $a$에 한없이 가까워지기만 하는 상태를 의미합니다. 극한값 계산은 함수의 연속성을 판단하거나 함수의 변화율을 다루는 미분의 기초가 되는 매우 중요한 과정입니다.

### 직관과 기하적 의미
그래프 상에서 $x$가 $a$를 향해 이동할 때, 함수의 그래프가 $y$축의 어느 높이(값)를 향해 수렴해 가는지를 관찰하는 것과 같습니다. 만약 그래프가 끊어져 있거나 발산하여 하나의 값으로 모이지 않는다면 극한값은 존재하지 않습니다.

### 기본 성질
극한값이 존재할 때, 극한의 선형성을 이용하여 다음과 같은 성질을 적용할 수 있습니다.
1. 두 함수의 극한값이 각각 존재하면, 두 함수의 합, 차, 실수배의 극한값은 각각의 극한값의 합, 차, 실수배와 같습니다.
2. 두 함수의 극한값이 각각 존재하고 하나가 $0$이 아니라면, 두 함수의 극한값의 곱과 몫(분모가 $0$이 아닌 경우)은 각각의 극한값의 곱과 몫과 같습니다.

## 학습 체크
- 함수값이 정의되지 않은 지점에서도 극한값은 존재할 수 있는가?
- 좌극한과 우극한이 서로 다를 때 극한값은 어떻게 정의되는가?
- 분수 형태의 함수에서 분모가 $0$으로 갈 때 극한값은 어떻게 처리하는가?

## 관련 개념
- **수열의 극한**: 변수 $x$ 대신 자연수 $n$을 사용하여 항의 번호가 커짐에 따라 항의 값이 어디로 향하는지를 다룹니다.
