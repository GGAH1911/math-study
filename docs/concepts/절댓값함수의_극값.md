### 정확한 진술
절댓값 함수 $f(x) = |g(x)|$의 극값을 구할 때, 극값의 후보점은 다음과 같다:
1. $g(x) > 0$인 구간에서 $f'(x) = 0$인 점 (이 구간에서 $f(x) = g(x)$)
2. $g(x) = 0$인 점 (함수가 미분 불가능)

각 후보점에서 함숫값을 구해 극댓값과 극솟값을 판정한다. $g(x) = 0$인 점에서는 좌미분과 우미분의 부호를 비교하거나 근처 함숫값과 직접 비교하여 극값 여부를 판단한다.

### 직관/기하적 의미
절댓값 함수 $y = |g(x)|$의 그래프는 $y = g(x)$에서 $y < 0$인 부분을 $x$축에 대해 대칭이동한 것이다. 이로 인해 $g(x) = 0$인 점에서 그래프가 뾰족하게 꺾여 미분 불가능하다. 따라서 절댓값이 없는 함수와 달리 미분 불가능한 점도 극값 후보가 되므로, 반드시 함께 검토해야 한다.

### 한 줄 예
$f(x) = |x^2 - 4x + 3|$에서 $x = 1, 3$은 미분 불가능점이고, $1 < x < 3$ 구간에서 $f(x) = -x^2 + 4x - 3$이므로 $x = 2$에서 극댓값 $f(2) = 1$을 갖는다 (`sympy: abs(2**2 - 4*2 + 3) = 1`).
