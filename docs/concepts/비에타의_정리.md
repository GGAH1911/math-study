### 정확한 진술

$a \neq 0$인 이차방정식 $ax^2 + bx + c = 0$의 두 근을 $\alpha, \beta$라 하면, 다음이 성립합니다.

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이를 **근과 계수의 관계**라고 부르며, 비에타(François Viète)의 공식으로도 알려져 있습니다.

### 직관과 증명의 핵심

이차방정식의 두 근이 $\alpha, \beta$이면 인수분해 형태는 다음과 같습니다.

$$a(x - \alpha)(x - \beta) = 0$$

우변을 전개하면:

$$a\left[x^2 - (\alpha + \beta)x + \alpha\beta\right] = ax^2 - a(\alpha + \beta)x + a\alpha\beta = 0$$

원래 형태 $ax^2 + bx + c = 0$과 계수를 비교하면:
- $x$의 계수: $-a(\alpha + \beta) = b$ → $\alpha + \beta = -\frac{b}{a}$
- 상수항: $a\alpha\beta = c$ → $\alpha\beta = \frac{c}{a}$

따라서 **근의 공식으로 실제 근을 구하지 않아도**, 근의 합과 곱만으로 근의 성질을 파악할 수 있습니다.

### 한 줄 예

방정식 $x^2 - 5x + 6 = 0$에서 근의 합은 $5$, 근의 곱은 $6$입니다. (실제 근은 $x=2, 3$)

*검증: `sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$, 합=$5$, 곱=$6$ ✓*
