# 직선의 기울기

## 요약
직선의 기울기는 직선이 기울어진 정도를 나타내는 값으로, $x$의 변화량에 대한 $y$의 변화량의 비율을 의미합니다.

## 본문
직선의 기울기는 좌표평면 위에서 직선이 얼마나 가파르게 기울어져 있는지를 나타내는 수치입니다. 두 점 $(x_1, y_1)$과 $(x_2, y_2)$를 지나는 직선의 기울기는 $\tfrac{y_2 - y_1}{x_2 - y_1}$ (단, $x_1 \neq x_2$)로 정의하며, 이는 $x$축의 증가량에 대한 $y$축의 증가량의 비율을 의미합니다.

### 직관과 기하적 의미
기울기의 값이 클수록 직선은 $y$축에 가까워지며 가파르게 상승하는 형태를 띠고, 값이 작을수록 $x$축에 가까워지며 완만하게 상승합니다. 만약 기울기가 양수이면 오른쪽 위로 향하는 직선이 되고, 음수이면 오른쪽 아래로 향하는 직선이 됩니다. 기울기가 $0$인 경우 직선은 $x$축과 평행한 수평선이 됩니다.

### 기본 성질
직선의 방정식 $y = ax + b$에서 계수 $a$는 기울기를 나타냅니다. 기울기는 두 점을 선택하더라도 직선 위의 어떤 두 점을 선택하더라도 항상 일정한 값을 유지하는 직선의 고유한 특성입니다.

## 학습 체크
- 두 점의 좌표가 주어졌을 때, $x$의 변화량과 $y$의 변화량을 정확히 계산하여 비율을 구할 수 있는가?
- 기울기의 부호(양수, 음수, $0$)에 따라 직선이 그려지는 방향을 시각적으로 예측할 수 있는가?

## 관련 개념
- **지수와 로그**: 지수함수와 로그함수의 그래프에서 함숫값의 변화율을 분석할 때 미분 개념과 연결되어 기울기의 원리가 확장됩니다.
