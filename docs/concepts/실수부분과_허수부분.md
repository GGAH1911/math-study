### 정확한 진술

복소수는 $z = a + bi$ 형태로 나타낼 수 있습니다. 여기서 $a, b$는 실수이고, $i$는 허수 단위($i^2 = -1$)입니다. 이때 $a$를 **실수부분**(real part), $b$를 **허수부분**(imaginary part)이라 하며, 다음과 같이 표기합니다:

$$\text{Re}(z) = a, \quad \text{Im}(z) = b$$

주의: 허수부분은 $bi$가 아니라 계수인 $b$ 자체입니다. 즉, 허수부분도 실수입니다.

### 직관과 의미

복소수를 **복소평면**(complex plane)에 점으로 표현하면 직관이 명확해집니다. 가로축(실수축)에 실수부분 $a$, 세로축(허수축)에 허수부분 $b$를 나타내면, 복소수 $z = a + bi$는 점 $(a, b)$에 대응됩니다.

예를 들어, $z = 3 + 2i$는 복소평면의 점 $(3, 2)$입니다. 실수부분과 허수부분을 알면:
- 복소수의 위치를 정확히 파악
- 복소수의 크기(절댓값) 계산 가능: $|z| = \sqrt{a^2 + b^2}$
- 두 복소수의 관계 비교 가능

복소수는 좌표 $(a, b)$처럼 두 개의 독립적인 실수 정보를 담고 있으므로, 실수부분과 허수부분을 분리하는 것이 계산과 이해의 핵심입니다.

### 한 줄 예

$z = 5 - 3i$일 때, $\text{Re}(z) = 5$, $\text{Im}(z) = -3$이고, $|z| = \sqrt{5^2 + (-3)^2} = \sqrt{34}$입니다.

(검증: `sympy.re(5 - 3j)` → 5, `sympy.im(5 - 3j)` → -3)
