# 기댓값 분산

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
$E(X), V(X)$

## 본문 (학습 시 채워짐)

### 기댓값의 정의

확률변수 $X$가 $x_1, x_2, \ldots, x_n$의 값을 각각 확률 $p_1, p_2, \ldots, p_n$으로 가질 때, 기댓값(expected value)은 다음과 같이 정의됩니다.

$$E(X) = \sum_{i=1}^{n} x_i p_i$$

기댓값은 확률변수가 평균적으로 어떤 값을 가지는지 나타내는 중심값입니다.

### 분산의 정의

분산(variance)은 확률변수가 기댓값 주위에 얼마나 흩어져 있는지를 나타내는 척도입니다.

$$V(X) = E\left((X - E(X))^2\right) = \sum_{i=1}^{n} (x_i - E(X))^2 p_i$$

분산은 다음 공식으로도 계산할 수 있습니다.

$$V(X) = E(X^2) - (E(X))^2$$

여기서 $E(X^2) = \sum_{i=1}^{n} x_i^2 p_i$입니다.

### 직관적 의미

기댓값은 여러 번 반복할 때 기대할 수 있는 평균값입니다. 분산이 작으면 확률변수의 값들이 기댓값 근처에 모여 있고, 분산이 크면 널리 흩어져 있습니다. 분산의 양의 제곱근인 표준편차 $\sigma(X) = \sqrt{V(X)}$는 분산과 같은 단위로 산포도를 표현하여 실무에서 자주 사용됩니다.

### 기본 예제

주사위를 한 번 던질 때 나오는 눈의 수를 $X$라 하면, 각 값이 $\frac{1}{6}$의 확률을 가지므로:

$$E(X) = 1 \cdot \frac{1}{6} + 2 \cdot \frac{1}{6} + \cdots + 6 \cdot \frac{1}{6} = 3.5$$

분산을 구하려면 먼저 $E(X^2) = \frac{1 + 4 + 9 + 16 + 25 + 36}{6} = 15.17$을 계산한 후:

$$V(X) = 15.17 - 3.5^2 = 2.92$$

`from sympy import Rational; E_X = Rational(7,2); V_X = sum(Rational(1,6) * i**2 for i in range(1,7)) - E_X**2`
