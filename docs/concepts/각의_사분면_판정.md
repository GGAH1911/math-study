### 정확한 진술

각 $\theta$를 표준 위치(시초선이 양의 $x$축)에 놓았을 때, 동경이 지나가는 영역에 따라 각을 다음과 같이 분류합니다:

- **제1사분면**: $0° < \theta < 90°$ (또는 $0 < \theta < \frac{\pi}{2}$)
- **제2사분면**: $90° < \theta < 180°$ (또는 $\frac{\pi}{2} < \theta < \pi$)  
- **제3사분면**: $180° < \theta < 270°$ (또는 $\pi < \theta < \frac{3\pi}{2}$)
- **제4사분면**: $270° < \theta < 360°$ (또는 $\frac{3\pi}{2} < \theta < 2\pi$)

일반각의 경우, 끝각이 위 범위 중 하나에 속하면 해당 사분면에 속합니다. 예를 들어 $450° = 360° + 90°$는 제1사분면 각입니다.

### 직관 및 삼각함수의 부호

단위원 위의 점 $(\cos\theta, \sin\theta)$를 이용하면 각 사분면에서 삼각함수의 부호를 판정할 수 있습니다:

| 사분면 | $\sin\theta$ | $\cos\theta$ | $\tan\theta$ |
|--------|-------------|-------------|-------------|
| 제1 | $+$ | $+$ | $+$ |
| 제2 | $+$ | $-$ | $-$ |
| 제3 | $-$ | $-$ | $+$ |
| 제4 | $-$ | $+$ | $-$ |

이를 구호 **"ASTC"**(All Students Take Calculus, 모든 학생이 미적분을 듣는다)로 기억하면, 제1→제2→제3→제4 사분면에서 차례로 All(모두), Sine, Tangent, Cosine이 양수임을 알 수 있습니다.

### 한 줄 예

$\theta = 150°$일 때 $90° < 150° < 180°$이므로 제2사분면이고, $\sin 150° = \frac{1}{2} > 0$, $\cos 150° = -\frac{\sqrt{3}}{2} < 0$입니다.
