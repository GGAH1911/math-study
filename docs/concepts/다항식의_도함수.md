# 다항식의 도함수

## 요약
다항식의 각 항을 미분하여 새로운 다항식을 얻는 과정으로, 각 항의 지수를 앞으로 내리고 지수에서 1을 뺀 값을 곱하여 계산합니다.

## 본문
다항식 $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$의 도함수 $f'(x)$는 각 항에 대하여 $n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + \dots + a_1$로 정의됩니다. 즉, 다항식의 각 항을 개별적으로 미분하여 더한 결과와 같습니다.

### 직관과 기하적 의미
도함수는 원래 다항식 함수가 나타내는 곡선 위의 임의의 점에서의 접선의 기울기를 나타냅니다. 다항식의 차수가 낮을수록 곡선의 변화 양상이 단순하며, 도함수를 통해 함수의 증가와 감소, 극값의 위치를 파악할 수 있습니다.

### 기본 성질
첫째, 상수항을 미분하면 $0$이 됩니다. 둘째, 두 다항식의 합 또는 차의 도함수는 각각의 도함수의 합 또는 차와 같습니다. 셋째, 상수배를 한 다항식의 도함수는 상수를 미분 결과에 곱한 것과 같습니다.

## 학습 체크
- 다항식의 차수가 $n$인 함수를 미분했을 때 결과물의 차수는 어떻게 변하는가?
- 상수항이 포함된 다항식을 미분할 때 주의해야 할 점은 무엇인가?
- 여러 개의 항으로 이루어진 다항식을 미분할 때 각 항을 따로 계산해도 결과가 같은가?

## 관련 개념
- **미분**: 함수의 변화율을 구하는 연산으로, 다항식의 도함수는 미분의 가장 기초적이고 핵심적인 계산 규칙을 보여줍니다.
