### 정확한 진술

조건부 개수 세기는 전체 집합에서 주어진 조건을 만족하는 원소의 개수를 세는 기법입니다. 어떤 집합 $S$에 대해, 특정한 성질 $P$를 만족하는 원소들만을 골라내어 그 개수를 구하는 것을 의미합니다. 일반적으로 다음과 같이 표현합니다:

$$|\{x \in S : P(x)\text{가 참}\}|$$

### 직관과 실제 활용

조건부 개수 세기는 실생활의 거의 모든 경우의 수 문제에서 나타납니다. 예를 들어, "20명의 학생 중 수학 성적이 80점 이상인 학생의 수", "1부터 100까지의 자연수 중 3의 배수인 수의 개수" 같은 상황이 모두 조건부 개수 세기입니다. 

핵심은 **전체에서 조건을 먼저 명확히 정한 후, 그 조건을 만족하는 경우만 계산**하는 것입니다. 조건이 복잡할 때는 여집합(조건을 만족하지 않는 경우)을 이용하는 여사건 기법이나, 경우를 나누어 계산하는 분할 기법을 함께 사용합니다.

### 한 줄 예

1부터 100까지의 자연수 중 **2의 배수이면서 동시에 3의 배수인 수**의 개수는, 6의 배수 개수와 같으므로 $\lfloor 100/6 \rfloor = 16$입니다. (sympy: `len([n for n in range(1, 101) if n % 2 == 0 and n % 3 == 0])` → 16)

### 주의할 점

조건을 여러 개 동시에 만족해야 할 때는 각 조건이 독립적인지, 포함-배제 원리가 필요한지 확인해야 합니다. 특히 "또는"과 "그리고"의 의미를 정확히 구분하는 것이 중요합니다.
