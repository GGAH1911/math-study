# 지수 변환

지수 변환이란 지수 형태의 식에서 밑이나 지수를 조작하여 식의 형태를 바꾸는 것을 말한다. 핵심은 **지수 법칙**을 이용해 복잡한 지수식을 단순하게 정리하거나, 서로 다른 밑을 통일하는 과정이다.

지수 변환에서 가장 자주 쓰이는 법칙은 다음과 같다.

$$a^m \cdot a^n = a^{m+n}, \quad \frac{a^m}{a^n} = a^{m-n}, \quad (a^m)^n = a^{mn}$$

여기에 더해, 밑을 통일할 때는 한 수를 다른 수의 거듭제곱으로 표현하는 것이 핵심 기술이다. 예를 들어 $4 = 2^2$, $8 = 2^3$처럼 밑을 소수(素數)로 통일하면 비교나 계산이 훨씬 쉬워진다.

---

## 예시

**예시 1.** $4^x$를 밑이 $2$인 식으로 변환한다.

$$4^x = (2^2)^x = 2^{2x}$$

$4 = 2^2$임을 이용해 밑을 $2$로 통일했다. 방정식 $4^x = 8$을 풀 때 우변도 $8 = 2^3$으로 바꾸면 $2^{2x} = 2^3$이 되어 $2x = 3$, 즉 $x = \dfrac{3}{2}$를 쉽게 구할 수 있다.

**예시 2.** $\dfrac{9^x}{3^{x-1}}$을 단순화한다.

$$\frac{9^x}{3^{x-1}} = \frac{(3^2)^x}{3^{x-1}} = \frac{3^{2x}}{3^{x-1}} = 3^{2x-(x-1)} = 3^{x+1}$$

분자와 분모의 밑을 $3$으로 맞춘 뒤, 지수의 나눗셈 법칙 $a^m \div a^n = a^{m-n}$을 적용했다.

---

## 관련 개념

**지수와 로그** 단원에서 지수 변환은 거의 모든 계산의 출발점이다. 지수 변환을 능숙하게 하려면 **지수 법칙**을 먼저 완전히 익혀야 하며, 음의 지수 $a^{-n} = \dfrac{1}{a^n}$과 분수 지수 $a^{\frac{m}{n}} = \sqrt[n]{a^m}$도 변환의 도구로 자주 등장한다.

로그 쪽으로 넘어가면, 지수 변환으로 정리한 식이 **로그 변환**(로그를 이용한 식 변환)의 기초가 된다. $a^x = b$와 $x = \log_a b$는 동치이므로, 지수 변환이 곧 로그 변환의 전 단계다. 나아가 **지수함수**의 그래프 분석이나 **지수방정식·부등식** 풀이에서도 밑을 통일하는 지수 변환이 핵심 기술로 반복된다.
