# 지수 변환

## 요약
지수 법칙을 활용하여 밑을 통일하거나 지수를 조작함으로써 복잡한 지수 형태의 식을 단순한 형태로 바꾸는 과정이다.

## 본문
지수 변환이란 지수 형태의 식에서 밑이나 지수를 조작하여 식의 형태를 바꾸는 것을 말한다. 핵심은 지수 법칙을 이용해 복잡한 지수식을 단순하게 정리하거나, 서로 다른 밑을 통일하는 과정이다. 특히 밑을 통일할 때는 한 수를 다른 수의 거듭제곱으로 표현하는 것이 핵심 기술이다. 예를 들어 $4 = 2^2$, $8 = 2^3$처럼 밑을 소수(素數)로 통일하면 수의 비교나 계산이 훨씬 쉬워진다.

### 직관과 기하적 의미
지수 변환은 서로 다른 단위로 표현된 수들을 동일한 기준(밑)으로 맞추어 비교 가능하게 만드는 과정이다. 이는 복잡하게 얽힌 지수 방정식이나 식을 하나의 밑을 가진 형태로 단순화하여 문제 해결의 실마리를 제공한다.

### 기본 성질
지수 변환에서 가장 자주 쓰이는 법칙은 다음과 같다.
- $a^m \cdot a^n = a^{m+n}$
- $\tfrac{a^m}{a^n} = a^{m-n}$
- $(a^m)^n = a^{mn}$

**예시 1.** $4^x$를 밑이 $2$인 식으로 변환하기
$4^x = (2^2)^x = 2^{2x}$
방정식 $4^x = 8$을 풀 때 우변을 $8 = 2^3$으로 바꾸면 $2^{2x} = 2^3$이 되어 $2x = 3$, 즉 $x = \tfrac{3}{2}$를 쉽게 구할 수 있다.

**예시 2.** $\tfrac{9^x}{3^{x-1}}$을 단순화하기
$\tfrac{9^x}{3^{x-1}} = \tfrac{(3^2)^x}{3^{x-1}} = \tfrac{3^{2x}}{3^{x-1}} = 3^{2x-(x-1)} = 3^{x+1}$
분자와 분모의 밑을 $3$으로 맞춘 뒤, 지수의 나눗셈 법칙을 적용하여 식을 정리한다.

## 학습 체크
- 밑이 서로 다른 지수 방정식에서 밑을 소수로 통일하여 변환할 수 있는가?
- 지수 법칙을 적용하여 분수 형태의 지수식을 하나의 지수 형태로 단순화할 수 있는가?
- 거듭제곱의 거듭제곱 형태를 지수의 곱셈 법칙을 이용해 변환할 수 있는가?

## 관련 개념

**지수와 로그** 단원에서 지수 변환은 거의 모든 계산의 출발점이다. 지수 변환을 능숙하게 하려면 **지수 법칙**을 먼저 완전히 익혀야 하며, 음의 지수 $a^{-n} = \tfrac{1}{a^n}$과 분수 지수 $a^{\tfrac{m}{n}} = \sqrt[n]{a^m}$도 변환의 도구로 자주 등장한다.

로그 쪽으로 넘어가면, 지수 변환으로 정리한 식이 **로그 변환**(로그를 이용한 식 변환)의 기초가 된다. $a^x = b$와 $x = \log_a b$는 동치이므로, 지수 변환이 곧 로그 변환의 전 단계다. 나아가 **지수함수**의 그래프 분석이나 **지수방정식·부등식** 풀이에서도 밑을 통일하는 지수 변환이 핵심 기술로 반복된다.
