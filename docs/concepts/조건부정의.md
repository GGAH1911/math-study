### 정확한 진술

조건부정의란 정의 대상(수열, 함수 등)의 값을 주어진 조건에 따라 다르게 정하는 방식입니다. 예를 들어, 수열 $\{a_n\}$을 다음과 같이 정의할 수 있습니다:

$$a_n = \begin{cases} f(n) & \text{if } P(n) \\ g(n) & \text{if } Q(n) \end{cases}$$

여기서 $P(n)$, $Q(n)$은 항 번호 $n$에 대한 조건(홀짝성, 대소관계 등)이고, $f(n)$, $g(n)$은 각 조건에 해당할 때의 정의 규칙입니다. 함수의 경우도 정의역을 구간으로 나누어 각각 다른 식으로 정의합니다.

### 직관 및 의의

현실 상황에서는 하나의 규칙만으로는 표현할 수 없는 대상들이 많습니다. 예컨대 통신요금은 사용량 구간마다 단가가 다르고, 세금은 소득 구간별로 다르게 계산됩니다. 수학도 마찬가지로, 어떤 수열이나 함수가 서로 다른 조건 아래에서 본질적으로 다른 행동을 할 때 조건부정의를 사용합니다. 이 방식은 복잡한 현상을 **논리적으로 명확하게 기술**할 수 있게 해줍니다.

조건부정의된 수열을 다룰 때는 각 조건 구간에서 성질(수렴, 유계성, 단조성)이 달라질 수 있으므로, 전체 수열의 성질을 판단할 때 **각 경우를 나누어 검토**해야 합니다.

### 예시

$$a_n = \begin{cases} n & \text{if } n \text{은 홀수} \\ n^2 & \text{if } n \text{은 짝수} \end{cases}$$

이 수열의 처음 다섯 항은 $a_1 = 1, a_2 = 4, a_3 = 3, a_4 = 16, a_5 = 5$입니다. 홀수 항은 $a_n = n$으로 증가하고, 짝수 항은 $a_n = n^2$으로 훨씬 빠르게 증가합니다.

```python
# sympy로 처음 5항 확인
a = lambda n: n if n % 2 == 1 else n**2
[a(n) for n in range(1, 6)]
# [1, 4, 3, 16, 5]
```
