# 좌표계

## 요약
수직인 두 축을 기준으로 평면 위의 점의 위치를 숫자의 순서쌍으로 나타내는 체계입니다.

## 본문
좌표계는 공간이나 평면 내의 한 점의 위치를 나타내기 위해 기준이 되는 원점과 방향을 나타내는 축을 설정한 수학적 체계입니다. 가장 대표적인 평면 좌표계인 데카르트 좌표계에서는 서로 수직인 $x$축과 $y$축을 설정하며, 평면 위의 임의의 점은 두 축의 교점으로부터의 거리를 나타내는 순서쌍 $(x, y)$로 유일하게 결정됩니다. 이를 통해 기하학적 도형을 대수적인 방정식으로 변환하여 해석할 수 있는 가교 역할을 수행합니다.

### 직관과 기하적 의미
좌표계는 추상적인 공간에 '주소'를 부여하는 것과 같습니다. 우리가 지도 위에서 특정 위치를 위도와 경도로 찾는 것처럼, 좌표계는 공간의 점에 숫자를 대응시켜 위치를 정량적으로 표현할 수 있게 합니다. 이는 눈에 보이는 도형의 성질을 숫자의 계산을 통해 논리적으로 증명할 수 있게 해주는 도구가 됩니다.

### 기본 성질
좌표계가 성립하기 위해서는 기준이 되는 원점이 존재해야 하며, 축들이 서로 직교해야 합니다. 또한, 좌표계 내의 모든 점은 중복되지 않는 유일한 좌표를 가져야 합니다. 좌표를 통해 두 점 사이의 거리를 계산하거나, 두 직선의 기울기를 구하는 등 도형의 성질을 수식으로 나타낼 수 있습니다.

## 학습 체크
- 좌표평면 위에서 점의 위치를 나타내는 순서쌍의 구성 원리를 이해하고 있는가?
- 원점과 축의 설정이 좌표의 값에 어떤 영향을 미치는지 설명할 수 있는가?

## 관련 개념
- **정적분의 활용**: 좌표평면 위에서 곡선과 축 사이의 넓이를 구할 때, 좌표를 변수로 하는 함수를 적분하여 기하학적 면적을 계산합니다.
