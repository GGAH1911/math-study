### 정확한 진술

함수 $y = f(x)$의 **그래프**는 정의역 내의 모든 실수 $x$에 대하여 좌표평면 위의 점 $(x, f(x))$를 모두 표시했을 때 얻어지는 도형입니다. 즉, 집합으로 나타내면 $\{(x, f(x)) \mid x \in \text{정의역}\}$입니다.

### 직관과 기하적 의미

함수의 그래프는 **입력값과 출력값의 관계를 눈으로 볼 수 있게** 나타낸 것입니다. 어떤 $x$ 값을 선택했을 때 함수값 $f(x)$가 얼마인지를 점 $(x, f(x))$로 표현하고, 이 과정을 모든 $x$에 대해 반복하면 연속된 곡선(또는 직선)이 나타납니다.

예를 들어 선수 개념인 "도형의 방정식"에서처럼, 어떤 조건을 만족하는 점들을 모아서 도형을 만듭니다. 함수의 그래프도 마찬가지로 "조건: $y = f(x)$를 만족하는 점들의 모임"이라고 이해할 수 있습니다. 따라서 그래프의 모양을 보면 함수의 증감, 최댓값·최솟값, 대칭성 등을 한눈에 파악할 수 있습니다.

### 한 줄 예

함수 $f(x) = x^2$의 그래프는 점 $(x, x^2)$들의 모임인데, $(-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)$ 등을 표시하면 아래로 볼록한 포물선이 됩니다.

```
# sympy로 확인: f(x) = x^2의 몇 가지 점
import sympy as sp
x = sp.Symbol('x')
f = x**2
points = [(i, f.subs(x, i)) for i in range(-2, 3)]
# [(-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)]
```
