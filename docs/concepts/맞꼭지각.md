# 맞꼭지각

> **정리** · 중1 · 단원: [기본 도형](/concepts/기본_도형)

## 요약
맞꼭지각은 서로 같다

## 본문 (학습 시 채워짐)

### 진술과 가정

두 직선이 한 점에서 만날 때, 서로 마주보는 두 각을 **맞꼭지각**이라고 합니다. 이때 두 맞꼭지각의 크기는 항상 같습니다. 즉, 두 직선 $l$, $m$이 점 $O$에서 만날 때, $\angle AOB$와 $\angle COD$가 맞꼭지각이면 $\angle AOB = \angle COD$입니다.

### 증명 스케치

두 직선이 만나서 네 개의 각을 만들 때, 인접한 두 각(이웃한 각)을 생각해봅시다. 일직선을 이루므로 이들의 합은 항상 $180°$입니다. $\angle AOB$와 $\angle BOC$를 보면:

$$\angle AOB + \angle BOC = 180°$$

마찬가지로 $\angle BOC$와 $\angle COD$도 일직선을 이루므로:

$$\angle BOC + \angle COD = 180°$$

두 식을 비교하면 $\angle AOB + \angle BOC = \angle BOC + \angle COD$이고, 양변에서 $\angle BOC$를 빼면 $\angle AOB = \angle COD$가 됩니다. 한 점에서 만나는 직선의 구조 자체가 맞꼭지각을 같게 만드는 것입니다.

### 의의와 활용

맞꼭지각 정리는 기하 문제에서 각의 크기를 구할 때 가장 기본이 되는 성질입니다. 교선이 많은 도형에서 여러 각이 얽혀 있을 때, 이 성질을 이용해 같은 각끼리 묶으면 복잡한 관계를 단순화할 수 있습니다. 이후 평행선의 성질, 삼각형의 외각 정리 등 더 복잡한 정리들을 증명할 때도 자주 사용됩니다.
