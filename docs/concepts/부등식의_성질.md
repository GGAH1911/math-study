# 부등식의 성질

> **정리** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
음수를 곱하면 부등호 방향 반전

## 본문 (학습 시 채워짐)

### 진술

두 수의 부등식 양변에 같은 수를 더하거나 빼면 부등호의 방향은 유지되고, 양변에 같은 **양수**를 곱하거나 나누어도 방향이 유지됩니다. 그러나 양변에 같은 **음수**를 곱하거나 나누면 부등호의 방향이 **반전**됩니다.

형식적으로, $a < b$일 때:
- $a + c < b + c$ (덧셈)
- $a - c < b - c$ (뺄셈)
- $c > 0$이면 $ac < bc$ (양수 곱셈)
- $c < 0$이면 $ac > bc$ (음수 곱셈 ⟹ 부등호 반전)

### 증명 스케치

$a < b$라는 것은 $b - a > 0$ (양수)를 의미합니다. 여기에 음수 $c < 0$을 곱하면:

$$c(b - a) < 0 \quad \text{(양수 × 음수 = 음수)}$$

전개하면 $cb - ca < 0$이므로 $ca > cb$, 즉 $ac > bc$입니다. 예를 들어 $3 < 5$에 $-2$를 곱하면 $-6 > -10$이 되는 이치입니다. 음수를 곱하면 수의 상대적 크기 관계가 뒤바뀌기 때문입니다.

### 의의와 응용

이 성질은 일차부등식을 풀 때 핵심입니다. 예를 들어 $-2x < 6$을 풀 때, 양변을 $-2$로 나누면 (음수 나눗셈) $x > -3$이 됩니다. 부등호 방향을 반전시키지 않으면 틀린 답입니다. 이는 방정식을 풀 때 식을 변형해도 등호가 유지되는 것과 다른, 부등식만의 특수한 성질입니다.

검증: $x = -2$를 대입하면 원래식 $-2(-2) = 4 < 6$ ✓, 정답 $-2 > -3$ ✓
