# 집합의 부분집합

## 요약
집합 $A$의 모든 원소가 다른 집합 $B$에 포함될 때, $A$를 $B$의 부분집합이라고 합니다.

## 본문
집합 $A$의 모든 원소가 집합 $B$에 속할 때, 즉 모든 원소 $a \in A$에 대하여 $a \in B$가 성립할 때, 집합 $A$를 집합 $B$의 부분집합이라고 하며 기호로 $A \subset B$ 또는 $A \subseteq B$와 같이 나타냅니다. 이때 집합 $A$를 $B$의 부분집합, 집합 $B$를 $A$의 포함집합이라고 합니다.

### 직관과 기하적 의미
부분집합은 어떤 범주 안에 다른 범주가 완전히 포함되는 관계를 의미합니다. 예를 들어 '사과'라는 집합이 '과일'이라는 집합의 부분집합인 것과 같습니다. 벤 다이어그램을 통해 시각화하면, 집합 $A$를 나타내는 원이 집합 $B$를 나타내는 원 안에 완전히 들어가 있는 모습으로 표현됩니다.

### 기본 성질
모든 집합은 자기 자신을 부분집합으로 가집니다. 즉, $A \subseteq A$입니다. 또한, 공집합 $\emptyset$은 모든 집합의 부분집합입니다. 즉, $\emptyset \subseteq A$가 성립합니다. 만약 집합 $A$와 $B$가 서로의 부분집합이면, 두 집합은 서로 같은 집합입니다.

## 학습 체크
- 어떤 집합 $A$의 부분집합의 개수를 구할 때, 원소의 개수가 $n$개라면 $2^n$개가 되는 원리는 무엇인가?
- 공집합이 왜 모든 집합의 부분집합이 되는지 논리적으로 설명할 수 있는가?

## 관련 개념
- **확률**: 전체 표본 공간을 하나의 집합으로 볼 때, 특정 사건은 표본 공간의 부분집합으로 정의되며 해당 사건이 발생할 확률을 계산하는 기초가 됩니다.
