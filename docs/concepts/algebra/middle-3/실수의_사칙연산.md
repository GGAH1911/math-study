### 정확한 진술

실수 $a, b$에 대하여 다음과 같이 정의합니다:
- **덧셈**: $a + b$는 두 실수를 합친 결과
- **뺄셈**: $a - b = a + (-b)$로, $b$의 덧셈 역원을 더하는 것
- **곱셈**: $a \times b$ (또는 $ab$)는 두 실수의 곱
- **나눗셈**: $a \div b = a \cdot \frac{1}{b}$ (단, $b \neq 0$)로, $b$의 곱셈 역원을 곱하는 것

### 직관과 기하적 의미

수직선 위에서 덧셈은 오른쪽으로 이동하는 것, 뺄셈은 왼쪽으로 이동하는 것으로 생각할 수 있습니다. 예를 들어 $3 + 2$는 3에서 시작해 2만큼 오른쪽으로 가 5에 도달하는 것입니다.

곱셈은 스케일링(배율 조정)으로 해석합니다. $a$를 $b$배 늘리거나 줄이는 것이 $a \times b$입니다. 나눗셈은 곱셈의 역연산으로, $b$로 나눈다는 것은 전체를 $b$등분하는 것을 의미합니다.

### 중요한 성질

실수의 사칙연산은 다음 성질들을 만족합니다:
- **교환법칙**: $a + b = b + a$, $ab = ba$
- **결합법칙**: $(a+b)+c = a+(b+c)$, $(ab)c = a(bc)$
- **분배법칙**: $a(b+c) = ab + ac$
- **항등원소**: $a + 0 = a$, $a \times 1 = a$
- **역원소**: 모든 $a$에 대해 $a + (-a) = 0$이고, $a \neq 0$일 때 $a \times \frac{1}{a} = 1$

### 한 줄 예

$3 + (-2) = 1$, $5 - 8 = -3$, $\frac{6}{2} = 3$, $(-2) \times (-3) = 6$
