# 치환 인수분해

> **예제** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
복잡한 식의 치환

## 본문 (학습 시 채워짐)

### 문제

다음 식을 인수분해하시오.
$$x^4 - 5x^2 + 4$$

### 단계별 풀이

**1단계: 반복되는 부분을 찾기**

이 식을 자세히 보면 $x^2$이 두 번 나타난다. $x^4 = (x^2)^2$이므로, 이는 $x^2$에 대한 이차식으로 볼 수 있다.

**2단계: 치환**

$x^2 = t$로 놓으면 원래 식이 다음과 같이 변환된다.
$$t^2 - 5t + 4$$

이제 $t$에 대한 간단한 이차식이 되었다.

**3단계: 이차식 인수분해**

합이 $-5$, 곱이 $4$인 두 수를 찾으면 $-1$과 $-4$이다.
$$t^2 - 5t + 4 = (t-1)(t-4)$$

**4단계: 원래 변수로 되돌리기**

$t = x^2$를 다시 대입한다.
$$(x^2-1)(x^2-4)$$

**5단계: 최종 인수분해**

$x^2 - 1 = (x-1)(x+1)$이고 $x^2 - 4 = (x-2)(x+2)$이므로:
$$(x-1)(x+1)(x-2)(x+2)$$

검산: `sympy.factor(x**4 - 5*x**2 + 4)` → `(x-2)(x-1)(x+1)(x+2)`

### 답

$$(x-1)(x+1)(x-2)(x+2)$$

또는 순서를 정렬하면 $(x-2)(x-1)(x+1)(x+2)$

### 변형 및 주의

**주의점:**
- 치환 후 반드시 **원래 변수로 되돌리기**를 잊지 말 것
- 인수분해 후 더 이상 인수분해할 수 없는 형태까지 진행할 것

**변형 예시:**
- $(x^2+x)^2 - 8(x^2+x) + 12$: $x^2+x = t$로 놓아 $(t-2)(t-6)$ 후 원래대로 되돌리기
- $x^4 + 2x^2 - 3$: $x^2 = t$로 놓으면 $t^2 + 2t - 3 = (t+3)(t-1)$
