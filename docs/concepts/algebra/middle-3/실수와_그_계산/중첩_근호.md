# 중첩 근호

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
근호 안에 또 다른 근호가 포함된 식을 단순화하여 $\sqrt{p} \pm \sqrt{q}$ 형태의 합 또는 차로 나타내는 과정입니다.

## 본문
근호 안에 다시 근호가 포함된 식을 중첩 근호라고 합니다. 가장 대표적인 형태는 $\sqrt{a + \sqrt{b}}$ 또는 $\sqrt{a - \sqrt{b}}$와 같은 구조를 가집니다. 이러한 복잡한 형태의 식은 적절한 변형을 통해 $\sqrt{p} + \sqrt{q}$와 같이 더 단순한 형태의 근호의 합이나 차로 다시 쓸 수 있습니다.

### 직관과 기하적 의미
중첩 근호를 단순화하는 원리는 곱셈 공식의 역과정을 이용하는 것입니다. $(\sqrt{p} + \sqrt{q})^2 = p + q + 2\sqrt{pq}$라는 식을 활용하면, 주어진 식의 $a$ 부분은 $p + q$에 해당하고, $\sqrt{b}$ 부분은 $2\sqrt{pq}$에 해당함을 알 수 있습니다. 즉, 두 수의 합과 곱을 이용해 원래의 숫자를 찾아내는 과정이며, 이는 이차 방정식의 근와 계수의 관계를 역으로 이용하여 문제를 해결하는 전략과 같습니다.

### 기본 성질
$\sqrt{a + \sqrt{b}}$를 $\sqrt{p} + \sqrt{q}$로 바꾸기 위해서는 다음의 조건을 만족하는 $p, q$를 찾아야 합니다.
1. $p + q = a$
2. $2\sqrt{pq} = \sqrt{b}$ (또는 $4pq = b$)
이때 $p$와 $q$는 $t^2 - at + \tfrac{b}{4} = 0$이라는 이차 방정식의 두 근이 됩니다.

## 학습 체크
- 주어진 중첩 근호의 식이 $\sqrt{p} + \sqrt{q}$ 꼴로 변형될 수 있는지 확인하기 위해 $a$와 $b$의 관계를 파악했는가?
- $2\sqrt{pq}$ 형태를 만들기 위해 근호 안의 숫자를 적절히 분리하였는가?
- 구한 $p, q$의 값을 제곱하여 원래의 식과 일치하는지 검산하였는가?

## 관련 개념
- **식의 계산**: 중첩 근호를 단순화하는 과정은 근호가 포함된 복잡한 식을 다항식의 계산처럼 다루기 쉬운 형태로 변환하는 과정입니다.
