# 무리수 계산

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
유리수가 아닌 실수로서, 소수로 나타냈을 때 끝없이 이어지지만 반복되는 패턴이 없는 무한 비순환소수를 의미합니다.

## 본문
무리수란 두 정수의 비인 분수 $\tfrac{p}{q}$ ($q \neq 0$) 형태로 나타낼 수 없는 실수를 말하며, 즉 유리수가 아닌 모든 실수를 의미합니다.

### 직관과 기하적 의미
유리수를 소수로 변환하면 유한소수나 순환소수가 되지만, 무리수는 소수점 아래의 숫자들이 규칙 없이 무한히 이어지는 무한 비순환소수의 형태를 띱니다. 예를 들어 $\sqrt{2} = 1.414213562373...$와 같이 특정 마디가 반복되지 않는 특징이 있습니다. 수직선 위에서 유리수들이 촘촘하게 놓여 있더라도, 그 사이사이의 미세한 틈새를 메우며 존재하는 수들이 바로 무리수입니다.

### 기본 성질
대표적인 무리수로는 완전제곱수가 아닌 정수의 제곱근인 $\sqrt{2}, \sqrt{3}, \sqrt{5}$ 등이 있으며, 원주율인 $\pi$나 자연로그의 밑 $e$와 같은 특수한 초월수도 포함됩니다. 무리수의 계산에서는 근호 안의 숫자를 최대한 단순하게 만드는 과정과, 분모에 있는 근호를 제거하여 유리수로 바꾸는 분모의 유리화 과정이 매우 중요합니다. 이를 통해 복잡한 무리수 식을 표준적인 형태로 정리하여 사칙연산을 수행할 수 있습니다.

## 학습 체크
- 어떤 수가 유리수인지 무리수인지 판별할 때, 소수의 순환 여부를 확인할 수 있는가?
- 근호 안의 숫자를 소인수분해하여 근호 밖으로 꺼내는 과정을 정확히 수행할 수 있는가?
- 분모에 무리수가 포함된 분수를 유리화하여 식을 정리할 수 있는가?

## 관련 개념
- **식의 계산**: 무리수의 사칙연산과 근호의 성질을 이용하여 복잡한 대수식을 단순화하는 과정과 연결됩니다.
