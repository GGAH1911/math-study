# 동류 무리항의 덧셈

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
제곱근 기호 안의 수가 같은 무리항은 계수끼리 더하여 계산할 수 있습니다.

## 본문
동류 무리항(同類 無理項)이란 제곱근 기호 안의 수가 같은 무리항들을 의미합니다. 예를 들어 $2\sqrt{3}$, $5\sqrt{3}$, $-\sqrt{3}$은 모두 $\sqrt{3}$을 공통적으로 포함하고 있으므로 동류 무리항에 해당합니다. 이러한 동류 무리항의 덧셈은 계수만을 더하는 방식으로 계산하며, 식으로는 $a\sqrt{b} + c\sqrt{b} = (a + c)\sqrt{b}$ (단, $a, c$는 유리수, $b$는 양의 정수)와 같이 나타냅니다. 이는 문자항의 계산 원리인 $2x + 3x = 5x$와 동일한 논리를 따릅니다.

### 직관과 기하적 의미
$\sqrt{3}$을 하나의 단위 길이로 상상해 봅니다. $2\sqrt{3}$은 그 단위가 2개 있는 것이고, $3\sqrt{3}$은 그 단위가 3개 있는 것입니다. 따라서 두 길이를 합치면 해당 단위가 총 5개 있는 $5\sqrt{3}$이 됩니다. 즉, 무리수도 문자 $x$와 마찬가지로 같은 종류의 항이 여러 개 모여 있다면 그 개수(계수)를 합산하여 표현할 수 있습니다.

### 기본 성질
동류 무리항은 계수끼리 더하여 계산할 수 있지만, $\sqrt{2} + \sqrt{3}$과 같이 제곱근 안의 수가 서로 다른 무리항은 더 이상 간단히 계산할 수 없습니다. 각 항이 이미 가장 간단한 형태를 유지하고 있기 때문입니다.

## 관련 개념
