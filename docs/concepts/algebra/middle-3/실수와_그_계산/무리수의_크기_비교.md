# 무리수의 크기 비교

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
두 양의 무리수를 비교할 때는 제곱을 통해 근호 안의 수의 크기를 비교하거나, 공통된 거듭제곱을 이용하여 비교할 수 있습니다.

## 본문
두 양의 무리수 $a, b$에 대하여 $a^2$과 $b^2$의 크기 관계는 $a$와 $b$의 크기 관계와 같습니다. 즉, $a > 0, b > 0$일 때 $a^2 > b^2 \Leftrightarrow a > b$가 성립합니다. 또한 근호 안의 계수가 같은 경우, 양수 $A, B$에 대하여 $\sqrt{A} > \sqrt{B} \Leftrightarrow A > B$가 성립합니다.

### 직관과 기하적 의미
수직선 위에서 양수는 크기가 커질수록 오른쪽에 위치합니다. 제곱 함수 $f(x) = x^2$은 양수 범위에서 값이 커질수록 함숫값도 커지는 순증가 함수이므로, 제곱한 값의 크기 비교는 원래 수의 크기 비교와 일치합니다. 예를 들어 $\sqrt{2} \approx 1.41$과 $\sqrt{3} \approx 1.73$을 비교할 때, 이를 제곱하면 $2 < 3$이 되어 원래의 크기 관계인 $\sqrt{2} < \sqrt{3}$과 동일한 결론을 얻습니다. 이처럼 근호 안의 수가 클수록 그 제곱근도 크다는 성질은 복잡한 무리수의 크기를 비교할 때 제곱을 통해 비교를 단순화하는 강력한 도구가 됩니다.

### 기본 성질
- 양의 무리수 $a, b$에 대하여 $a^2$과 $b^2$의 크기 관계는 $a$와 $b$의 크기 관계와 같다.
- $A, B > 0$일 때, $\sqrt{A} > \sqrt{B} \Leftrightarrow A > B$이다.
- 서로 다른 거듭제곱근을 비교할 때는 양변을 공통된 거듭제곱하여 비교할 수 있다.

## 학습 체크
- 두 양의 무리수를 비교할 때 제곱을 이용하는 방법은 왜 유효한가요?
- $\sqrt{5}$와 $\sqrt[3]{10}$처럼 지수가 다른 무리수를 비교하는 방법은 무엇인가요?
- 근호 안의 수가 클수록 제곱근이 더 크다는 성질은 어떤 조건에서 성립하나요?

## 관련 개념
- **실수와 그 계산**: 무리수의 크기 비교는 실수의 대소 관계를 이해하고, 근호가 포함된 식의 계산을 단순화하는 기초가 됩니다.
