# 실수

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
유리수와 무리수를 모두 포함하여 수직선 위의 모든 점에 대응하는 수의 집합입니다.

## 본문
실수(實數)는 유리수와 무리수를 모두 포함하는 수의 집합으로, 집합 기호로는 $\mathbb{R} = \{$ 유리수 $\} \cup \{$ 무리수 $\}$로 나타냅니다. 정수, 분수, 제곱근, 순환소수, 그리고 비순환소수까지 포함하는 광범위한 수의 체계입니다.

### 직관과 기하적 의미
실수는 수직선 위의 모든 점에 일대일로 대응되는 수입니다. 유리수만으로는 수직선의 빈틈을 모두 채울 수 없지만, $\sqrt{2}$나 $\pi$와 같은 무리수를 추가하면 수직선 위의 모든 점을 빠짐없이 나타낼 수 있습니다. 즉, 실수는 수직선이라는 연속적인 선을 구성하는 모든 수치를 의미합니다.

### 기본 성질
모든 실수는 소수로 표현이 가능합니다. 유리수는 소수점 아래가 유한하거나 일정한 마디가 반복되는 무한순환소수로 나타나며, 무리수는 소수점 아래가 반복되지 않고 영원히 이어지는 무한비순환소수로 나타납니다. 예를 들어 정수 $3$, 분수 $-\tfrac{7}{2}$, 제곱근 $\sqrt{5}$, 원주율 $\pi$는 모두 실수에 해당합니다.
