# 제곱근

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)
## 요약
$\sqrt{a}$ — 제곱하면 $a$가 되는 수

## 본문

### 정확한 진술

음이 아닌 실수 $a$에 대해, $a$의 **제곱근**은 제곱하면 $a$가 되는 모든 수입니다. 즉, $x^2 = a$를 만족하는 $x$를 $a$의 제곱근이라 합니다.

주의할 점은 기호 $\sqrt{a}$의 의미입니다. 예를 들어 16의 제곱근은 4와 −4 두 개지만, **기호 $\sqrt{16}$은 양의 제곱근 4만을 나타냅니다**:
$$\sqrt{a} = x \quad (x \geq 0 \text{이고 } x^2 = a)$$

### 직관과 기하적 의미

제곱근은 "제곱의 역연산"입니다. 한 변의 길이가 $x$인 정사각형의 넓이가 $a$라면, $x = \sqrt{a}$입니다.

예를 들어 넓이가 9인 정사각형의 한 변의 길이는 $\sqrt{9} = 3$입니다. 역으로 생각하면 3을 두 번 곱하면 9가 되니까 당연합니다.

**중요한 제약**: $\sqrt{a}$가 실수로 정의되려면 반드시 $a \geq 0$이어야 합니다. 음수는 어떤 실수를 제곱해도 나올 수 없습니다 ($x^2 \geq 0$ 항상 성립). 따라서 음수의 제곱근은 실수 범위에서 존재하지 않습니다.

### 예

- $\sqrt{25} = 5$ (확인: $5^2 = 25$ ✓)
- $\sqrt{4} = 2$, $\sqrt{100} = 10$
- $\sqrt{2} \approx 1.414\ldots$ (무리수)
- $\sqrt{0} = 0$

검산 코드: `sympy.sqrt(25)` → $5$, `float(sympy.sqrt(2))` → $1.414\ldots$
