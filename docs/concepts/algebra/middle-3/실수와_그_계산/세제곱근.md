# 세제곱근

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
어떤 실수 $a$에 대하여 $x^3 = a$를 만족하는 실수 $x$를 $a$의 세제곱근이라 하며, 모든 실수에 대해 단 하나의 실수 세제곱근이 존재합니다.

## 본문
어떤 실수 $a$에 대하여 $x^3 = a$를 만족하는 실수 $x$를 $a$의 세제곱근이라 합니다. $a$의 세제곱근은 기호 $\sqrt[3]{a}$ 또는 $a^{1/3}$로 나타냅니다. 특히 정확히 하나의 실수 세제곱근이 존재하며, 이를 $a$의 세제곱근의 주값이라 부릅니다.

### 직관과 기하적 의미
제곱근은 음수를 제외하고 정의되며, 양수의 제곱근은 항상 양수와 음수 두 개가 존재합니다. 반면 세제곱근은 모든 실수에 대해 정의되며, 각 실수마다 정확히 하나의 세제곱근만 존재한다는 차이점이 있습니다.

기하학적으로는 정육면체의 부피와 밀접한 관련이 있습니다. 한 변의 길이가 $x$인 정육면체의 부피가 $a$일 때, $x = \sqrt[3]{a}$가 됩니다. 예를 들어 부피가 $8$인 정육면체의 한 변의 길이는 $\sqrt[3]{8} = 2$입니다.

또한 세제곱근은 음수의 영역까지 자연스럽게 확장됩니다. 음수의 세제곱근은 음수로 나타나는데, 예를 들어 $\sqrt[3]{-27} = -3$인 이유는 $(-3)^3 = -27$이기 때문입니다.

### 기본 성질
세제곱근의 기본 계산 예시는 다음과 같습니다. $\sqrt[3]{8} = 2$, $\sqrt[3]{-27} = -3$, $\sqrt[3]{0} = 0$입니다.
일반적으로 $(\sqrt[3]{a})^3 = a$가 성립하며, 곱셈에 대하여 $\sqrt[3]{ab} = \sqrt[3]{a} \cdot \sqrt[3]{b}$의 성질을 가집니다.

## 학습 체크
- $x^3 = a$를 만족하는 실수 $x$가 왜 모든 실수 $a$에 대해 유일하게 존재하는지 설명할 수 있는가?
- $\sqrt[3]{-8}$의 값은 무엇이며, 왜 음수가 나오는지 계산 과정을 통해 설명할 수 있는가?
- 한 변의 길이가 $\sqrt[3]{27}$인 정육면체의 부피는 얼마인가?

## 관련 개념
- **방정식과 부등식**: 세제곱근의 정의를 이용하여 $x^3 = a$ 형태의 삼차방정식의 해를 구하거나, 세제곱근을 포함한 부등식의 범위를 구할 수 있습니다.
