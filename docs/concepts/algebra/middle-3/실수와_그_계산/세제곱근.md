# 세제곱근

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 정확한 진술

어떤 실수 $a$에 대해, $x^3 = a$를 만족하는 실수 $x$를 $a$의 **세제곱근**(cubic root)이라 합니다. $a$의 세제곱근은 기호 $\sqrt[3]{a}$ 또는 $a^{1/3}$로 나타냅니다. 특히 정확히 하나의 실수 세제곱근이 존재하며, 이를 $a$의 **세제곱근의 주값**(principal cube root)이라 부릅니다.

## 직관과 기하적 의미

제곱근은 음수를 제외하고 정의되고, 양수의 제곱근은 항상 두 개(양수 하나, 음수 하나)입니다. 반면 **세제곱근은 모든 실수에 대해 정의되며, 각 실수마다 정확히 하나의 세제곱근만 존재합니다**.

기하학적으로는 정육면체의 부피와 연결됩니다. 한 변의 길이가 $x$인 정육면체의 부피가 $a$일 때, $x = \sqrt[3]{a}$입니다. 예를 들어 부피 8인 정육면체의 한 변의 길이는 $\sqrt[3]{8} = 2$입니다.

또한 중요한 특징은 **음수의 세제곱근도 음수**라는 점입니다. $\sqrt[3]{-27} = -3$이므로, 세제곱근 함수는 음수 영역까지 자연스럽게 확장됩니다. 이는 $(-3)^3 = -27$이기 때문입니다.

## 기본 성질과 한 줄 예

세제곱근의 기본 계산: $\sqrt[3]{8} = 2$, $\sqrt[3]{-27} = -3$, $\sqrt[3]{0} = 0$.

일반적으로 $(\sqrt[3]{a})^3 = a$이고 $\sqrt[3]{ab} = \sqrt[3]{a} \cdot \sqrt[3]{b}$입니다.

(검증: `sympy.cbrt(8), sympy.cbrt(-27)` → `2, -3`)
