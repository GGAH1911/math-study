# 제곱근의 성질

> **정리** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
$\sqrt{a^2}=|a|$이며, 음이 아닌 두 실수 $a, b$에 대하여 $\sqrt{a}\sqrt{b}=\sqrt{ab}$가 성립합니다.

## 본문
모든 실수 $a$에 대하여 $\sqrt{a^2} = |a|$가 성립하며, 음이 아닌 실수 $a, b$에 대하여 $\sqrt{a}\sqrt{b} = \sqrt{ab}$가 성립합니다. 제곱근은 정의상 음이 아닌 제곱근만을 의미하므로 $\sqrt{a} \geq 0$이며, 이는 $a$의 제곱이 $a^2$이 되는 음이 아닌 수를 뜻합니다.

### 증명 스케치
**성질 1의 증명:**
$\sqrt{a^2}$는 제곱했을 때 $a^2$이 되는 음이 아닌 수입니다. $a > 0$이면 $a$가 그 수가 되므로 $\sqrt{a^2} = a = |a|$입니다. $a < 0$이면 $-a$가 그 수가 되므로 $\sqrt{a^2} = -a = |a|$입니다. 따라서 모든 실수 $a$에 대해 성질이 성립합니다. 예시로 $\sqrt{(-3)^2} = \sqrt{9} = 3 = |-3|$이 있습니다.

**성질 2의 증명:**
$\sqrt{a}\sqrt{b}$를 제곱하면 $a \cdot b$가 되고, $\sqrt{ab}$를 제곱해도 $ab$가 됩니다. 두 값 모두 음이 아닌 수이고 제곱이 같으므로 $\sqrt{a}\sqrt{b} = \sqrt{ab}$입니다. 단, 음수의 곱에 대해서는 성질이 성립하지 않으므로 주의해야 합니다.

### 의의와 응용
성질 1은 제곱근의 정의를 음수 범위까지 확장하여 절댓값과의 관계를 보여줍니다. 이는 이차방정식 $x^2 = k$의 해를 $x = \pm\sqrt{k}$로 구하는 근거가 됩니다. 성질 2는 제곱근의 곱셈을 단순화하는 도구로, $\sqrt{12} = \sqrt{4 \cdot 3} = 2\sqrt{3}$과 같이 근호 안의 수를 정리할 때 필수적입니다. 반대로 복잡한 곱셈을 하나의 근호 안으로 모으는 데도 사용됩니다.

## 학습 체크
- $a$가 음수일 때 $\sqrt{a^2}$의 결과가 왜 $a$가 아닌 $-a$로 나오는지 설명할 수 있는가?
- $\sqrt{ab} = \sqrt{a}\sqrt{b}$를 사용할 때 $a$와 $b$의 부호 조건이 왜 중요한지 이해하고 있는가?
