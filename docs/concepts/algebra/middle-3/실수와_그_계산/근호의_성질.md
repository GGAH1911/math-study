# 근호의 성질

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
$a, b$가 음이 아닌 실수일 때, 근호 안의 곱셈과 나눗셈을 분리하거나 합칠 수 있으며, 제곱근의 제곱은 원래 수의 절댓값과 같습니다.

## 본문
$a, b$가 음이 아닌 실수일 때, 다음의 성질이 성립합니다. $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$이며, $b > 0$일 때 $\tfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\tfrac{a}{b}}$입니다. 또한 $(\sqrt{a})^2 = a$이고, $\sqrt{a^2} = |a|$입니다.

### 직관과 기하적 의미
근호의 성질은 제곱근의 정의에서 자연스럽게 유도됩니다. $\sqrt{a}$는 제곱했을 때 $a$가 되는 음이 아닌 수이므로, 두 근호의 곱인 $\sqrt{a} \times \sqrt{b}$를 제곱하면 $a \times b$가 됩니다. 따라서 이 값은 제곱하여 $ab$가 되는 음이 아닌 수인 $\sqrt{ab}$와 같습니다. 나눗셈 역시 동일한 논리를 따릅니다. $\sqrt{a^2} = |a|$인 이유는 제곱근의 결과값이 항상 음이 아닌 수여야 하기 때문입니다. 예를 들어 $a = -3$이면 $\sqrt{(-3)^2} = \sqrt{9} = 3$이 되어 $|-3|$과 일치합니다.

### 기본 성질
- 곱셈 성질: $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ (단, $a, b \geq 0$)
- 나눗셈 성질: $\tfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\tfrac{a}{b}}$ (단, $a \geq 0, b > 0$)
- 제곱근의 제곱: $(\sqrt{a})^2 = a$
- 제곱근의 제곱근: $\sqrt{a^2} = |a|$

## 학습 체크
- $a$나 $b$가 음수일 때 $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$가 성립하지 않는 이유를 설명할 수 있는가?
- $\sqrt{(-5)^2}$의 계산 결과가 왜 $-5$가 아닌 $5$가 되는지 절댓값의 개념을 사용하여 설명할 수 있는가?
- $\sqrt{12} \times \sqrt{3}$을 근호 안의 숫자를 곱하는 방식으로 계산할 수 있는가?

## 관련 개념
- **실수와 그 계산**: 근호의 성질은 실수 범위 내에서 무리수의 곱셈과 나눗셈을 간편하게 계산하는 기초가 됩니다.
