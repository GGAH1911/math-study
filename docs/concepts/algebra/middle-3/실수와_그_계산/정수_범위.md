# 정수 범위

## 정확한 진술

정수(integer)는 양의 정수, 0, 음의 정수를 모두 포함하는 수의 집합입니다. 수학 기호로는 $\mathbb{Z}$로 표기하며, 명시적으로는 $\mathbb{Z} = \{\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\}$입니다. 양의 정수의 집합을 $\mathbb{Z}^+$ 또는 $\mathbb{N}$이라 하고($\mathbb{N} = \{1, 2, 3, \ldots\}$), 음의 정수의 집합을 $\mathbb{Z}^-$이라 합니다($\mathbb{Z}^- = \{-1, -2, -3, \ldots\}$).

## 직관/기하적 의미

수직선 위에서 정수는 0을 중심으로 좌우 대칭이며 1 간격으로 등간격하게 배열된 점들입니다. 정수는 실수의 부분집합이지만, 연속이 아닌 **이산(discrete)** 구조를 가집니다. 정수의 가장 중요한 대수적 성질은 덧셈, 뺄셈, 곱셈에 대해 **닫혀 있다**는 것입니다. 즉, 두 정수의 덧셈, 뺄셈, 곱셈 결과는 항상 정수이지만, 나눗셈은 일반적으로 정수를 만들지 않습니다. 이 성질이 정수론의 핵심이며, 나눗셈 관계를 연구하는 것(나머지, 최대공약수 등)이 수능 수학의 중요 단원입니다.

## 한 줄 예

$-5, 0, 3, 10$은 정수이고, $(-2) + 7 = 5$, $3 \times (-4) = -12$도 정수이지만, $5 \div 2 = 2.5$는 정수가 아닙니다.
