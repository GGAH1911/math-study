# 제곱근 계산

> **예제** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
제곱근 안의 수를 소인수분해하여 제곱수를 밖으로 꺼낸 뒤, 같은 제곱근을 가진 항끼리 계수를 더하여 정리합니다.

## 본문
다음 식을 정리하세요.
$$\sqrt{2} + \sqrt{8}$$

### 단계별 풀이
**1단계: 제곱근 안의 수를 소인수분해**
먼저 각 제곱근을 살펴봅시다. $\sqrt{2}$는 이미 가장 간단한 형태이지만, $\sqrt{8}$은 더 정리할 수 있습니다.
$$8 = 4 \times 2 = 2^2 \times 2$$

**2단계: 제곱인수를 제곱근 밖으로 꺼내기**
$\sqrt{8}$에서 완전제곱수인 4를 찾았습니다. 제곱근의 성질 $\sqrt{a^2 \cdot b} = a\sqrt{b}$ (단, $a \geq 0$)를 이용하면 다음과 같습니다.
$$\sqrt{8} = \sqrt{4 \times 2} = \sqrt{4} \times \sqrt{2} = 2\sqrt{2}$$

**3단계: 같은 제곱근끼리 모으기**
이제 두 항이 모두 $\sqrt{2}$를 인수로 가집니다. 마치 문자항처럼 $\sqrt{2}$의 계수끼리 더하면 됩니다.
$$\sqrt{2} + \sqrt{8} = \sqrt{2} + 2\sqrt{2} = (1 + 2)\sqrt{2} = 3\sqrt{2}$$

### 답과 변형
**답**
$$3\sqrt{2}$$

**변형 예제**
- $\sqrt{3} + \sqrt{12} = \sqrt{3} + 2\sqrt{3} = 3\sqrt{3}$
- $\sqrt{5} + \sqrt{20} = \sqrt{5} + 2\sqrt{5} = 3\sqrt{5}$

**주의사항**
- $\sqrt{2} + \sqrt{8} \neq \sqrt{10}$ 이므로, 제곱근끼리 더할 때 안의 숫자만 더하는 실수를 주의해야 합니다.
- 반드시 제곱근 안을 먼저 정리한 후, 같은 종류의 제곱근끼리 모아야 합니다.
- 뺄셈도 같은 방식으로 계산합니다. 예: $\sqrt{18} - \sqrt{2} = 3\sqrt{2} - \sqrt{2} = 2\sqrt{2}$

## 학습 체크

- 서로 다른 제곱근을 가진 항을 같은 형태의 제곱근으로 통일할 수 있는가?
- 제곱근의 덧셈과 뺄셈에서 안의 숫자만 더하는 오류를 범하지 않는가?
