### 정확한 진술

동류 무리항(同類 無理項)이란 제곱근 기호 안의 수가 같은 무리항들을 말합니다. 예를 들어 $2\sqrt{3}$, $5\sqrt{3}$, $-\sqrt{3}$은 모두 $\sqrt{3}$을 포함하므로 동류 무리항입니다.

**덧셈 규칙:**
동류 무리항끼리는 계수만 더하여 계산합니다.

$$a\sqrt{b} + c\sqrt{b} = (a + c)\sqrt{b}$$

여기서 $a, c$는 유리수, $b$는 양의 정수입니다. 이는 문자항의 동류항 계산 $2x + 3x = 5x$와 정확히 같은 원리입니다.

### 직관/기하적 의미

$\sqrt{3}$을 하나의 단위로 생각하면, $2\sqrt{3}$는 "그 단위 2개", $3\sqrt{3}$은 "그 단위 3개"입니다. 두 길이를 합치면 "그 단위 5개"인 $5\sqrt{3}$이 되는 것입니다. 

문자 $x$에서 $2x + 3x = 5x$로 계산하는 것처럼, 무리수도 같은 것이 여러 개 있으면 그 계수들을 더할 수 있습니다.

### 계산 예시

$$3\sqrt{5} + 2\sqrt{5} - \sqrt{5} = (3 + 2 - 1)\sqrt{5} = 4\sqrt{5}$$

**주의:** $\sqrt{2} + \sqrt{3}$처럼 피제곱수가 다른 무리항은 더할 수 없습니다. 각각의 무리항이 이미 가장 간단한 형태이기 때문입니다.
