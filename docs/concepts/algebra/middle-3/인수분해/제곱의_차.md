# 제곱의 차

> **정의** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/다항식의_곱셈과_인수분해)

## 요약
두 수의 제곱의 차는 두 수의 합과 차의 곱으로 인수분해되는 항등식입니다.

## 본문
두 수 $a$, $b$의 제곱의 차는 다음과 같이 인수분해됩니다: $a^2 - b^2 = (a+b)(a-b)$. 이 항등식은 $a$, $b$가 어떤 실수든 항상 성립하며, 역으로 $(a+b)(a-b)$를 전개하면 $a^2 - b^2$을 얻을 수 있습니다.

### 직관과 기하적 의미
제곱의 차는 인수분해의 가장 기본적인 형태이며, 고등학교 수학 전역에서 핵심 도구로 사용됩니다. 기하학적으로 보면, 한 변의 길이가 $a$인 정사각형에서 한 변의 길이가 $b$인 정사각형을 뺀 도형의 넓이를 나타냅니다. 이 도형을 적절히 재배열하면 가로 길이가 $(a+b)$, 세로 길이가 $(a-b)$인 직사각형이 되는데, 이것이 바로 왜 곱 $(a+b)(a-b)$로 표현되는지를 시각적으로 보여줍니다.

### 기본 성질
이 식은 복잡한 식을 간단히 정리하거나, 분수의 분모를 유리화할 때, 또는 이차방정식을 풀 때 자주 마주치는 중요한 패턴입니다. 예를 들어 $x^2 - 25$와 같은 이차식을 빠르게 인수분해할 때 $x^2 - 5^2 = (x+5)(x-5)$와 같이 활용할 수 있습니다.

## 학습 체크
- $a^2 - b^2$ 형태를 보았을 때 즉각적으로 $(a+b)(a-b)$로 변환할 수 있는가?
- 기하학적 모델에서 정사각형의 넓이 차이가 왜 직사각형의 넓이와 같은지 설명할 수 있는가?
- 분모의 유리화 과정에서 왜 이 항등식을 사용하는지 이해하고 있는가?

## 관련 개념
- **삼각함수**: $\sin^2 x - \cos^2 x = -\cos 2x$와 같은 삼각함수의 항등식을 증명할 때 핵심적인 도구로 사용됩니다.
