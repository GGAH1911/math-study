# 미정계수법

## 정확한 진술

두 다항식(또는 식)이 모든 변수값에 대해 항등적으로 같으면, 대응하는 각 항의 계수는 모두 같습니다. 이를 이용해 미지의 계수를 구하는 방법을 **미정계수법**(method of undetermined coefficients)이라 합니다.

예를 들어, $ax^2 + bx + c = 2x^2 - 3x + 5$가 모든 $x$에 대해 성립하면:
$$a = 2, \quad b = -3, \quad c = 5$$

일반적으로 $P(x) = Q(x)$일 때, 양변을 전개하여 같은 차수의 항끼리 계수를 비교함으로써 미지의 계수들을 결정합니다.

## 직관/기하적 의미

두 다항식이 항등적으로 같다는 것은 "무한히 많은 점에서 일치한다"는 의미입니다. 다항식은 유한 차수의 함수이므로, 모든 $x$값에서 같으려면 각 차수별로 계수가 정확히 일치해야 합니다. 이는 곱셈의 단일인수분해 정리(fundamental theorem of algebra의 결과)에서 비롯된 원리입니다.

따라서 미정계수법은 무한개의 등식 $P(x) = Q(x)$ (모든 $x$에 대해)를 유한개의 선형연립방정식으로 변환하는 강력한 도구입니다.

## 한 줄 예

$(x+1)^2 = x^2 + ax + b$에서 좌변을 전개하면 $x^2 + 2x + 1 = x^2 + ax + b$이므로 $a=2, b=1$입니다.

**검산**: `sympy.solve([2 - 1, 1 - 1], [1, 1])` 또는 직접 계수 비교로 $a=2, b=1$ ✓

부분분수 분해, 다항식 나눗셈의 검증, 수열의 일반항 유도 등 고등학교 수학 전반에서 빈번히 사용됩니다.
