# 인수분해 공식

> **정리** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
$a^2-b^2=(a+b)(a-b)$ 등

## 본문 (학습 시 채워짐)

### 진술

다항식을 인수(다항식)의 곱으로 나타내는 표준 공식들입니다:

**차의 제곱식**
$$a^2 - b^2 = (a+b)(a-b)$$

**완전제곱식**
$$a^2 + 2ab + b^2 = (a+b)^2$$
$$a^2 - 2ab + b^2 = (a-b)^2$$

**합과 차의 세제곱식**
$$a^3 + b^3 = (a+b)(a^2 - ab + b^2)$$
$$a^3 - b^3 = (a-b)(a^2 + ab + b^2)$$

### 유도와 의미

**차의 제곱식**은 전개 $(a+b)(a-b) = a^2 - ab + ab - b^2 = a^2 - b^2$로부터 바로 나옵니다. 기하적으로는 한 변의 길이가 $a$인 정사각형에서 한 변의 길이가 $b$인 정사각형을 뺀 영역의 넓이를 두 가지 방법으로 표현한 것입니다.

**완전제곱식**은 다항식의 제곱을 전개한 형태입니다. $(a+b)^2 = a^2 + 2ab + b^2$를 역으로 읽으면 인수분해됩니다. 핵심은 가운데 항이 $2ab$인지 확인하는 것입니다.

**합의 세제곱식** $a^3 + b^3 = (a+b)(a^2 - ab + b^2)$는 다음과 같이 확인할 수 있습니다:
$$(a+b)(a^2 - ab + b^2) = a^3 - a^2b + ab^2 + a^2b - ab^2 + b^3 = a^3 + b^3$$

마찬가지로 $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$도 전개로 검증됩니다.

### 의의와 응용

이 공식들은 복잡한 다항식을 단순한 인수의 곱으로 바꾸므로, 방정식을 푸는 데 필수적입니다. 예를 들어 $x^2 - 9 = 0$은 $(x+3)(x-3) = 0$으로 인수분해되어 $x = \pm 3$을 얻습니다. 또한 식을 간단히 정리하거나 최대공약수를 구할 때도 유용합니다. 고등학교에서 다루는 인수정리, 나머지정리의 기초가 됩니다.

**검증 예**: `sympy.factor(x**3 + 8)` → $(x+2)(x^2-2x+4)$
