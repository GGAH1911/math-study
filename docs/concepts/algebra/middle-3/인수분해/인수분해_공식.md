# 인수분해 공식

> **정리** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
다항식을 여러 개의 다항식의 곱으로 나타내는 표준적인 공식들입니다.

## 본문
다항식을 인수(다항식)의 곱으로 나타내는 표준 공식들은 다음과 같습니다. 먼저 차의 제곱식은 $a^2 - b^2 = (a+b)(a-b)$입니다. 완전제곱식은 $a^2 + 2ab + b^2 = (a+b)^2$와 $a^2 - 2ab + b^2 = (a-b)^2$로 나타냅니다. 마지막으로 합과 차의 세제곱식은 $a^3 + b^3 = (a+b)(a^2 - ab + b^2)$와 $a^3 - b^3 = (a-b)(a^2 + ab + b^2)$입니다.

### 증명 스케치
차의 제곱식은 $(a+b)(a-b)$를 전개하면 중간 항인 $-ab$와 $+ab$가 상쇄되어 $a^2 - b^2$이 됨을 통해 알 수 있습니다. 완전제곱식은 제곱의 전개 과정을 역으로 적용한 것이며, 이때 가운데 항이 $2ab$ 형태인지 확인하는 것이 중요합니다. 합의 세제곱식은 $(a+b)(a^2 - ab + b^2)$를 전개했을 때 $a^3 - a^2b + ab^2 + a^2b - ab^2 + b^3$이 되어 $a^3 + b^3$이 됨을 통해 검증할 수 있습니다.

### 의의와 응용
이 공식들은 복잡한 다항식을 단순한 인수의 곱으로 변환하여 방정식을 해결하는 데 필수적인 도구입니다. 예를 들어 $x^2 - 9 = 0$을 $(x+3)(x-3) = 0$으로 바꾸면 $x = \pm 3$이라는 해를 쉽게 구할 수 있습니다. 또한 식을 간결하게 정리하거나 최대공약수를 구할 때 유용하며, 향후 고등학교 과정의 인수정리와 나머지정리를 학습하는 데 기초가 됩니다.

## 학습 체크
- 차의 제곱식과 완전제곱식의 형태를 보고 즉각적으로 인수분해할 수 있는가?
- 세제곱식의 인수분해 시 중간 항의 부호가 공식과 일치하는지 확인할 수 있는가?
- 인수분해된 결과를 바탕으로 이차방정식의 해를 구할 수 있는가?

## 관련 개념
- **인수분해**: 다항식을 곱의 형태로 분해하는 과정이며, 위 공식들은 인수분해를 수행하는 핵심적인 방법론입니다.
