# 다항식의 인수분해

## 정확한 진술

**다항식의 인수분해**란 주어진 다항식을 더 낮은 차수의 여러 다항식의 곱으로 나타내는 것입니다. 즉, 다항식 $P(x)$를 $P(x) = Q_1(x) \cdot Q_2(x) \cdots Q_n(x)$ 형태로 표현하는 과정입니다. 여기서 각 $Q_i(x)$를 **인수(factor)**라고 부르며, 보통 더 이상 인수분해될 수 없는 기약 다항식(irreducible polynomial)까지 분해합니다.

## 직관 및 의미

다항식의 인수분해는 수를 소인수분해하는 것처럼, 다항식의 "기본 단위"를 찾는 과정입니다. 예를 들어 $x^2 - 5x + 6 = (x-2)(x-3)$으로 나타내면, 이 다항식이 $x=2$와 $x=3$에서 0이 됨을 쉽게 알 수 있습니다. 즉, 인수분해는 **다항식의 근(영점)을 시각적으로 드러내는** 강력한 도구입니다. 또한 복잡한 식을 간단한 부분으로 나누므로, 방정식 풀이, 부분분수 분해, 극한 계산 등 다양한 상황에서 필수적입니다.

## 예시

$x^2 - 1 = (x-1)(x+1)$는 다항식 $x^2-1$을 1차 인수 두 개의 곱으로 나타낸 것입니다.

$x^3 - x = x(x^2-1) = x(x-1)(x+1)$은 더 진행된 인수분해입니다.

더 복잡한 예: $2x^3 + 3x^2 - 8x - 12$를 인수분해하면 $(x+2)(2x^2-x-6) = (x+2)(2x+3)(x-2)$입니다.
(`sympy.factor(2*x**3 + 3*x**2 - 8*x - 12)` → `(x + 2)(x - 2)(2*x + 3)`)

## 주의

- 실계수 다항식의 경우, 1차 인수와 판별식이 음수인 2차 인수까지만 기약입니다.
- 정수 계수 다항식을 정수 범위에서 인수분해하는 것과, 유리수 범위, 실수 범위, 복소수 범위에서 하는 것은 결과가 다를 수 있습니다.
