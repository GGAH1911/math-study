# 인수

> **정의** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
어떤 식을 곱셈으로 나타낼 때, 그 곱을 이루는 각각의 식을 의미합니다.

## 본문
**인수(factor)**는 어떤 식을 곱셈으로 나타낼 때, 그 곱을 이루는 각각의 식을 말합니다. 수식으로 표현하면, 다항식 $A$를 두 개 이상의 다항식 $B$와 $C$의 곱으로 나타낼 수 있을 때, 즉 $A = B \times C$일 때 $B$와 $C$를 $A$의 인수라고 정의합니다. 예를 들어 정수 $12 = 3 \times 4$일 때 $3$과 $4$는 $12$의 인수이며, 다항식에서도 $x^2 + 5x + 6 = (x+2)(x+3)$이면 $(x+2)$와 $(x+3)$이 $x^2 + 5x + 6$의 인수가 됩니다.

### 직관과 기하적 의미
인수의 개념은 식을 더 작은 조각으로 나누는 과정인 인수분해와 반대되는 개념입니다. 복잡한 식을 인수로 분해하면 식의 구조를 명확히 파악할 수 있고, 식이 $0$이 되는 값을 찾는 과정이나 방정식을 풀 때 매우 유용합니다. 예를 들어 $(x+2)(x+3) = 0$이라는 식을 통해 $x$가 $-2$ 또는 $-3$일 때 식이 $0$이 됨을 쉽게 알 수 있습니다.

### 기본 성질
인수는 곱셈을 통해 원래의 식을 다시 만들어낼 수 있는 구성 요소입니다. $x^2 - 4 = (x-2)(x+2)$라는 식에서 $(x-2)$와 $(x+2)$가 인수라는 것은, 이 두 식을 다시 곱하여 전개했을 때 원래의 식인 $x^2 - 4$를 얻을 수 있음을 의미합니다.

## 학습 체크
- 어떤 식을 두 식의 곱으로 나타냈을 때, 각 식을 인수로 지칭할 수 있는가?
- 주어진 다항식이 인수의 곱으로 표현되었을 때, 각 인수를 정확히 찾아낼 수 있는가?
- 인수를 활용하여 식이 $0$이 되는 $x$의 값을 구할 수 있는가?

## 관련 개념
- **인수분해**: 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 과정으로, 인수를 찾아내는 과정과 같습니다.
