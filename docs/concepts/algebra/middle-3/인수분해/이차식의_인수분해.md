# 이차식의 인수분해

> **정의** · 중3 · 단원: [인수분해](/concepts/인수분해)

## 정확한 진술

이차식의 인수분해란 이차식 $ax^2 + bx + c$ (단, $a \neq 0$)를 일차식들의 곱으로 나타내는 것입니다. 보통 $a(x - \alpha)(x - \beta)$ 형태로 표현되는데, 여기서 $\alpha, \beta$는 이차식의 근(해)입니다. 실수 범위에서는 판별식 $D = b^2 - 4ac \geq 0$일 때만 실근이 존재하므로 일차식의 곱으로 완전히 인수분해됩니다.

## 직관과 의미

이차식의 인수분해는 이차방정식의 근과 깊게 연결되어 있습니다. 이차식이 0이 되는 $x$ 값(근)을 알면, 그 근들로부터 인수분해 형태를 바로 구성할 수 있기 때문입니다. 그래프로 생각하면, $y = ax^2 + bx + c$의 포물선이 $x$축과 만나는 두 점이 바로 근이며, 인수분해는 이 교점들을 대수적으로 표현하는 방법입니다. 인수분해를 통해 이차식의 부호 변화, 최댓값/최솟값, 이차부등식의 해를 쉽게 파악할 수 있습니다.

## 주요 인수분해 형태

**1단계: 근의 공식**
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
두 근을 $\alpha, \beta$라 하면:
$$ax^2 + bx + c = a(x - \alpha)(x - \beta)$$

**2단계: 전개 확인**
$a=1$, $b=5$, $c=6$인 경우:
$$x^2 + 5x + 6 = (x + 2)(x + 3)$$
(근: $x = -2, -3$, 계산: `sympy.solve(x**2 + 5*x + 6, x)` → $[-3, -2]$)

## 한 줄 요약

이차식의 인수분해는 이차식을 근을 이용하여 일차식의 곱으로 나타내는 과정으로, 이차방정식 풀이, 부등식 해석, 함수 분석의 기초입니다.
