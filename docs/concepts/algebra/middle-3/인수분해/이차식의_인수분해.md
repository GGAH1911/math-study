# 이차식의 인수분해

> **정의** · 중3 · 단원: [인수분해](/concepts/인수분해)

## 요약
이차식을 근을 이용하여 일차식들의 곱으로 나타내는 과정으로, 이차방정식과 함수를 분석하는 기초가 됩니다.

## 본문
이차식의 인수분해란 이차식 $ax^2 + bx + c$ ($a \neq 0$)를 일차식들의 곱으로 나타내는 것을 의미합니다. 일반적으로 $a(x - \alpha)(x - \beta)$의 형태로 표현되며, 여기서 $\alpha$와 $\beta$는 해당 이차식이 $0$이 되게 하는 근(해)입니다. 실수 범위 내에서 일차식의 곱으로 완전히 인수분해되기 위해서는 판별식 $D = b^2 - 4ac$가 $0$보다 크거나 같아야 실근이 존재합니다.

### 직관과 기하적 의미
이차식의 인수분해는 이차방정식의 해를 구하는 과정과 직결됩니다. 이차식이 $0$이 되는 $x$ 값을 알면 그 값들을 이용하여 인수분해된 형태를 즉시 구성할 수 있기 때문입니다. 기하학적으로는 이차함수 $y = ax^2 + bx + c$의 그래프인 포물선이 $x$축과 만나는 두 교점의 위치를 대수적으로 표현하는 것과 같습니다. 이를 통해 이차식의 부호 변화나 최댓값, 최솟값, 그리고 이차부등식의 해를 직관적으로 파악할 수 있습니다.

### 기본 성질
이차식의 근을 구하는 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 이용하면 두 근 $\alpha, \beta$를 얻을 수 있으며, 이를 통해 $ax^2 + bx + c = a(x - \alpha)(x - \beta)$라는 관계를 도출할 수 있습니다. 예를 들어 $x^2 + 5x + 6$의 경우, 근이 $-2$와 $-3$이므로 $(x + 2)(x + 3)$으로 인수분해됩니다.
