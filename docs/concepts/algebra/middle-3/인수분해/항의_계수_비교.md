### 정확한 진술

두 다항식 $P(x)$와 $Q(x)$가 모든 $x$ 값에 대해 같을 때, 즉 $P(x) = Q(x)$가 **항등식**일 때, 대응하는 각 항의 계수는 반드시 같습니다. 이를 **항의 계수 비교(comparison of coefficients)**라고 합니다.

예를 들어 $ax^2 + bx + c = dx^2 + ex + f$가 모든 $x$에 대해 성립하면:
- $x^2$의 계수: $a = d$
- $x$의 계수: $b = e$  
- 상수항: $c = f$

### 직관과 의미

항등식은 방정식과 다릅니다. 방정식은 특정 $x$ 값에서만 성립하지만, 항등식은 **모든** $x$에서 성립합니다. 만약 $x^2$의 계수가 다르면 $x$가 충분히 크거나 작을 때 좌변과 우변이 달라집니다. 따라서 모든 $x$에서 같으려면 구조 자체가 같아야 하므로, 각 항의 계수가 반드시 일치해야 합니다.

이 성질은 인수분해를 거꾸로 할 때, 또는 복잡한 식을 정리할 때 강력한 도구입니다. 예를 들어 $(x+1)(x+2) = x^2 + 3x + 2$를 전개한 후 미지수가 있는 식과 비교할 때 사용합니다.

### 한 줄 예

$(x+1)(x+a) = x^2 + 5x + 4$가 항등식이면, 전개하면 $x^2 + (1+a)x + a = x^2 + 5x + 4$이므로 $1+a=5$와 $a=4$에서 $a=4$입니다.

**검증:** `sympy.solve([1+a-5, a-4], a)` → $a=4$ ✓
