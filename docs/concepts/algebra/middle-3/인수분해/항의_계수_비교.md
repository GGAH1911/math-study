# 항의 계수 비교

> **정의** · 중3 · 단원: [인수분해](/concepts/인수분해)

## 요약
두 다항식이 모든 $x$에 대해 같은 항등식일 때, 대응하는 각 항의 계수가 반드시 같다는 성질입니다.

## 본문
두 다항식 $P(x)$와 $Q(x)$가 모든 $x$ 값에 대해 같을 때, 즉 $P(x) = Q(x)$가 항등식일 때, 대응하는 각 항의 계수는 반드시 같습니다. 이를 항등식의 계수 비교라고 합니다. 예를 들어 $ax^2 + bx + c = dx^2 + ex + f$가 모든 $x$에 대해 성립하면, $x^2$의 계수인 $a$와 $d$가 같고, $x$의 계수인 $b$와 $e$가 같으며, 상수항인 $c$와 $f$가 서로 같아야 합니다.

### 직관과 의미
항등식은 방정식과 달리 특정 $x$ 값에서만 성립하는 것이 아니라 모든 $x$에서 성립합니다. 만약 $x^2$의 계수가 서로 다르다면, $x$의 값이 충분히 커지거나 작아질 때 좌변과 우변의 값이 서로 달라지게 됩니다. 따라서 모든 $x$에 대해 식이 성립하려면 식의 구조 자체가 완전히 일치해야 하므로, 각 항의 계수가 반드시 일치해야 합니다. 이 성질은 복잡한 식을 정리하거나 미지수를 구할 때 매우 유용한 도구가 됩니다.

### 기본 성질
- 항등식의 양변에서 차수가 같은 항끼리 비교하여 미지수를 구할 수 있습니다.
- $(x+1)(x+a) = x^2 + 5x + 4$와 같은 식에서 전개된 식의 계수와 비교하여 $a$의 값을 정확히 찾아낼 수 있습니다.

## 학습 체크
- 두 다항식이 항등식일 때, 차수가 다른 항이 존재해도 계수 비교가 가능한가요?
- 방정식과 항등식의 결정적인 차이점은 무엇인가요?

## 관련 개념
- **인수분해**: 항등식의 계수 비교 성질을 거꾸로 이용하면, 전개된 다항식을 다시 곱의 형태로 되돌리는 과정에서 미지수를 찾는 데 활용할 수 있습니다.
