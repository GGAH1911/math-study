# 치환 인수분해

> **예제** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
공통된 부분이 반복되는 복잡한 식을 하나의 문자로 바꾸어 간단하게 만든 후 인수분해하는 방법입니다.

## 본문
다음 식을 인수분해하시오.
$$x^4 - 5x^2 + 4$$

### 단계별 풀이
**1단계: 반복되는 부분 찾기**
식에서 $x^2$이 반복되는 것을 확인할 수 있습니다. $x^4$은 $(x^2)^2$이므로, 이 식은 $x^2$을 기준으로 한 이차식의 형태를 띠고 있습니다.

**2단계: 치환하기**
반복되는 $x^2$을 $t$라는 하나의 문자로 치환합니다. 그러면 식은 $t^2 - 5t + 4$로 단순해집니다.

**3단계: 이차식 인수분해**
치환된 식 $t^2 - 5t + 4$를 인수분해합니다. 곱해서 $4$가 되고 더해서 $-5$가 되는 두 수는 $-1$과 $-4$이므로, 식은 $(t-1)(t-4)$가 됩니다.

**4단계: 원래 변수로 되돌리기**
치환했던 $t$에 다시 원래의 식인 $x^2$을 대입합니다. 식은 $(x^2-1)(x^2-4)$가 됩니다.

**5단계: 최종 인수분해**
결과물에 포함된 식들을 다시 한 번 점검합니다. $x^2-1$은 $(x-1)(x+1)$로, $x^2-4$는 $(x-2)(x+2)$로 각각 합차 공식에 의해 더 분해할 수 있습니다. 따라서 최종 결과는 $(x-1)(x+1)(x-2)(x+2)$입니다.

### 답과 변형
**답**
$$(x-1)(x+1)(x-2)(x+2)$$

**변형 및 주의사항**
- 치환을 마친 후에는 반드시 원래의 문자로 되돌려 놓아야 하며, 인수분해를 끝까지 수행하여 더 이상 분해할 수 없는 형태인지 확인해야 합니다.
- 예시 1: $(x^2+x)^2 - 8(x^2+x) + 12$는 $x^2+x=t$로 치환하여 풉니다.
- 예시 2: $x^4 + 2x^2 - 3$은 $x^2=t$로 치환하여 $t^2 + 2t - 3 = (t+3)(t-1)$로 풉니다.

## 학습 체크
- 식에서 반복되는 공통 부분을 찾아 문자로 바꿀 수 있는가?
- 치환된 식을 인수분해한 후 원래 문자로 다시 대입하였는가?
- 인수분해된 결과가 더 이상 분해되지 않는 완전한 형태인가?

## 관련 개념
- **인수분해**: 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 과정으로, 치환 인수분해는 이 과정을 단순화하는 도구입니다.
