### 정확한 진술

두 개 이상의 수 또는 식에 작용하여 새로운 수 또는 식을 만드는 규칙을 **연산자**(operator)라고 합니다. 수학에서는 보통 기호 $+, -, \times, \div$ 등으로 나타냅니다.

더 엄밀하게, 집합 $A$에서 정의된 연산 $\otimes$이란, $A$의 임의의 두 원소 $a, b$에 대해 $a \otimes b$도 $A$의 원소가 되는 규칙입니다. 예를 들어 정수 집합 $\mathbb{Z}$에서 덧셈은 임의의 정수 $a, b$에 대해 $a + b \in \mathbb{Z}$를 만족합니다.

### 직관과 의미

연산자는 "계산 규칙을 나타내는 기호"입니다. 예를 들어 "$3 + 5$"에서 $+$라는 연산자는 "3과 5를 합쳐서 8을 만드는 규칙"을 지시합니다.

고등학교 과정에서는 기본 연산자 외에도 임의의 연산을 정의할 수 있습니다. 예를 들어 $a * b = a + b + ab$처럼 새로운 기호로 새로운 연산 규칙을 만들 수 있습니다. 이렇게 정의된 연산도 원리는 같습니다: 두 개의 입력을 받아서 정해진 규칙에 따라 정확히 하나의 출력을 만드는 것입니다.

### 한 줄 예

연산 $a * b = a + b + ab$가 정의되었을 때, $2 * 3 = 2 + 3 + (2 \times 3) = 11$입니다.
