# 단항식

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
항이 하나인 식

## 본문 (학습 시 채워짐)

### 정확한 진술

**단항식**은 숫자, 문자, 그리고 그들의 곱으로만 이루어진 식입니다. 더 정확히 말하면, 하나의 **항(term)**으로만 구성되며, 덧셈이나 뺄셈이 없는 식입니다.

단항식의 기본 형태는 $ax^my^n \cdots$ 형태입니다. 여기서 $a$는 상수(계수)이고, $x, y, \ldots$는 문자(변수)이며, $m, n, \ldots$는 음이 아닌 정수(지수)입니다. 모든 문자의 지수의 합을 **차수**라고 합니다.

### 직관과 의미

단항식은 더 복잡한 식을 만드는 기초 단위입니다. 여러 개의 단항식을 더하거나 빼면 **다항식**이 되므로, 단항식을 먼저 이해하는 것이 식의 계산의 첫걸음입니다.

예를 들어, $3x$와 $-2y$는 각각 단항식이지만, 이 둘을 더한 $3x - 2y$는 단항식이 아니라 다항식입니다. 즉, **"항이 정확히 하나"**인지가 단항식을 판단하는 핵심입니다.

### 구체적 예시

**단항식인 것:**
- 숫자만: $5$, $-3$, $0.2$
- 문자만: $x$, $a$, $-b$
- 숫자와 문자의 곱: $2x$, $-5ab$, $\frac{3}{4}xy^2$, $10a^2b^3c$

**단항식이 아닌 것:**
- 덧셈이나 뺄셈이 있는 식: $x + 3$, $2a - b$, $x^2 + 2x + 1$
- 분모에 문자가 있는 식: $\frac{1}{x}$, $\frac{2}{x-1}$ (나눗셈 때문에)
