# 약분

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
분수의 분자와 분모를 공약수로 나누어 더 간단한 형태의 기약분수로 만드는 과정입니다.

## 본문
분수 $\tfrac{a}{b}$의 분자와 분모를 $0$이 아닌 같은 수로 나누어 더 간단한 형태로 나타내는 것을 **약분**이라고 합니다. 분자 $a$와 분모 $b$의 공약수 중 $1$이 아닌 것이 있을 때 이를 이용하여 약분할 수 있으며, 식으로는 $\tfrac{a}{b} = \tfrac{a \div d}{b \div d}$ (단, $d$는 $a$와 $b$의 공약수)로 나타냅니다. 이때 분자와 분모의 최대공약수로 나누면 더 이상 약분할 수 없는 **기약분수** 형태가 됩니다.

### 직관과 기하적 의미
약분은 "같은 크기를 더 간단하게 표현하는 것"입니다. 예를 들어 $\tfrac{6}{8}$은 전체를 $8$등분했을 때 $6$개를 의미하지만, 이를 $\tfrac{3}{4}$로 약분하면 전체를 $4$등분했을 때 $3$개를 의미합니다. 즉, 분수의 크기는 변하지 않으면서 수의 형태만 더 이해하기 쉬운 방식으로 변하는 것입니다.

### 기본 성질
약분은 계산의 편리성을 높여 실수를 줄여주며, 서로 다른 형태의 분수를 하나의 표준적인 형태(기약분수)로 통일할 수 있게 해줍니다. 다만, 분수식이 포함된 경우 약분 후 분모가 $0$이 되는 값을 제외해야 한다는 점에 주의해야 합니다. 예를 들어 $\tfrac{x^2 - 4}{x + 2} = \tfrac{(x-2)(x+2)}{x+2} = x - 2$ (단, $x \neq -2$)와 같이 식을 정리할 때 정의역의 변화를 고려해야 합니다.

## 학습 체크
- 분자와 분모를 나누는 수 $d$는 반드시 $0$이 아닌 공약수여야 합니다.
- 약분을 반복하여 더 이상 나누어지지 않는 기약분수 상태가 되었는지 확인해야 합니다.
- 분수식에서 약분을 할 때는 약분된 후의 분모가 $0$이 되지 않는 조건이 있는지 확인해야 합니다.

## 관련 개념
- **식의 계산**: 분수식의 인수를 약분하여 식을 단순화할 때, 약분되는 항으로 인해 분모가 $0$이 되는 값을 제외해야 하는 점을 유의해야 합니다.
