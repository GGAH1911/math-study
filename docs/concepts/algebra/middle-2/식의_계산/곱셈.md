# 곱셈

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
두 수 또는 식을 결합하여 새로운 값을 산출하는 연산으로, 수의 확대와 기하학적 넓이를 의미합니다.

## 본문
곱셈(multiplication)은 두 수 또는 식을 결합하여 새로운 수 또는 식을 만드는 기본 연산입니다. $a$와 $b$의 곱을 $a \times b$ 또는 $ab$로 나타냅니다. 초등 수준의 반복 덧셈 정의($3 \times 4 = 3+3+3+3$)를 넘어, 고등학교 수학에서는 곱셈을 네 가지 성질로 정의합니다.

### 직관과 기하적 의미
곱셈은 다양한 맥락에서 다르게 해석됩니다. 수의 관점에서는 배수나 비율을 나타내고, 기하학적 관점에서는 넓이 또는 부피를 나타냅니다. 예를 들어, 가로 길이 $a$, 세로 길이 $b$인 직사각형의 넓이는 $ab$입니다. 대수식의 관점에서 $2x$는 미지수 $x$를 2배로 확대한 식이고, $3(x+2)$는 $(x+2)$를 3번 반복한다는 의미입니다. 분배법칙 $3(x+2) = 3x + 6$은 직사각형을 수직선으로 두 부분으로 나눈 후 각 부분의 넓이를 더한 것과 같은 논리입니다.

### 기본 성질
1. 교환법칙: $ab = ba$
2. 결합법칙: $(ab)c = a(bc)$
3. 분배법칙: $a(b+c) = ab + ac$
4. 항등원소: $a \cdot 1 = a$

## 학습 체크
- 곱셈의 네 가지 성질(교환, 결합, 분배, 항등원)을 각각 수식으로 표현할 수 있는가?
- 분배법칙을 이용하여 다항식의 곱셈을 전개하는 과정을 기하학적 넓이 모델로 설명할 수 있는가?
- 음수와 음수의 곱셈 결과가 왜 양수가 되는지 직관적으로 이해하고 있는가?
