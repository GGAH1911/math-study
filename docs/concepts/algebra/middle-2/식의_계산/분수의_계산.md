# 분수의 계산

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
분수의 계산은 분모가 다른 두 분수를 통분하여 더하거나 빼고, 분모와 분자를 각각 곱하거나 역수의 곱으로 나눗셈을 수행하는 과정입니다.

## 본문
두 개의 분수 $\frac{a}{b}$와 $\frac{c}{d}$ (단, $b, d \neq 0$)에 대하여 덧셈과 뺄셈은 분모를 $bd$로 통분하여 $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$, $\frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd}$로 계산합니다. 곱셈은 분모는 분모끼리, 분자는 분자끼리 곱하여 $\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$로 계산하며, 나눗셈은 나누는 분수의 역수를 곱하는 방식으로 $\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{ad}{bc}$ ($c \neq 0$)로 계산합니다. 실무적인 계산 과정에서는 분모를 같게 만드는 통분과 분자와 분모를 공약수로 나누어 크기를 줄이는 약분을 활용하여 식을 단순화합니다.

### 직관과 기하적 의미
분수 $\frac{a}{b}$는 전체를 $b$등분한 것 중 $a$개를 의미합니다. 따라서 분수의 덧셈은 같은 크기의 조각들을 모으는 과정이며, 곱셈은 전체의 일부분을 다시 나누는 과정을 나타냅니다. 예를 들어 $\frac{1}{2} \times \frac{2}{3}$는 전체의 절반을 다시 3등분한 것 중 2개를 취한다는 의미로, 결과적으로 전체의 $\frac{1}{3}$을 나타냅니다.

### 기본 성질
분수의 계산에서는 분모의 최소공배수를 이용한 통분이 핵심적인 역할을 합니다. 예를 들어 $\frac{3}{4} + \frac{1}{6}$을 계산할 때, 분모 4와 6의 최소공배수인 12로 통분하면 $\frac{9}{12} + \frac{2}{12} = \frac{11}{12}$가 됩니다.

## 학습 체크
- 분모가 서로 다른 두 분수를 더하거나 뺄 때 통분이 필요한 이유를 설명할 수 있는가?
- 분수의 나눗셈을 곱셈으로 바꿀 때 나누는 수의 분자와 분모를 어떻게 처리해야 하는가?

## 관련 개념
- **식의 계산**: 분수의 사칙연산은 다항식의 계산과 유사한 원리를 가지며, 복잡한 식을 단순화하는 기초가 됩니다.
