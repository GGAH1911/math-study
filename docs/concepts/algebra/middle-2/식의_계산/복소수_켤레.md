# 복소수 켤레

복소수의 허수부 부호를 바꾼 짝을 가리키는 개념입니다. 복소수의 나눗셈을 유리화하거나, 실계수 다항식의 허근 성질을 다룰 때 사용됩니다.

## 정의

복소수 $z = a + bi$ ($a, b$는 실수)에 대하여 $z$의 **켤레복소수**를 $\overline{z} = a - bi$로 정의합니다. 주요 성질은 다음과 같습니다.
- $z + \overline{z} = 2a$ (실수), $\quad z - \overline{z} = 2bi$ (순허수).
- $z \cdot \overline{z} = a^2 + b^2$ (음이 아닌 실수).
- $\overline{z_1 + z_2} = \overline{z_1} + \overline{z_2},\ \overline{z_1 z_2} = \overline{z_1}\, \overline{z_2}.$

## 예시

$z = 3 - 2i$의 켤레는 $\overline{z} = 3 + 2i$입니다. $z \cdot \overline{z} = (3-2i)(3+2i) = 9 + 4 = 13.$

또한 $\dfrac{1}{2 + i}$를 정리할 때 분모의 켤레 $2 - i$를 곱해 $\dfrac{2 - i}{(2+i)(2-i)} = \dfrac{2 - i}{5}$를 얻습니다.
