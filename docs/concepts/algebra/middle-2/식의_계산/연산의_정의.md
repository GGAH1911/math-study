# 연산의 정의

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
연산은 두 개 이상의 수에 정해진 규칙을 적용하여 새로운 수를 얻는 과정이며, 입력값에 대해 결과값이 유일하게 결정되는 규칙성을 가집니다.

## 본문
연산은 주어진 두 개(또는 그 이상)의 수에 대하여 정해진 규칙에 따라 새로운 수를 얻는 행위를 의미합니다. 특히 두 개의 수 $a, b$로부터 유일한 수 $c$를 대응시키는 규칙을 이항연산이라 부르며, 이는 $a \circ b = c$와 같은 형태로 나타냅니다. 우리가 일상적으로 사용하는 덧셈 $a + b$, 뺄셈 $a - b$, 곱셈 $a \times b$, 나눗셈 $a \div b$는 모두 이항연산의 대표적인 예시입니다.

### 직관과 기하적 의미
연산의 핵심은 규칙성입니다. 두 수가 주어졌을 때, 미리 정해진 규칙에 따라 계산된 결과가 항상 일정하게 유지되어야 합니다. 예를 들어 $2 + 3$은 언제나 $5$이고, $4 \times 5$는 언제나 $20$인 것처럼, 입력된 두 값에 대해 출력되는 결과가 유일하게 결정되는 것이 연산의 본질입니다. 이러한 연산 과정을 통해 우리는 두 값을 결합하여 새로운 값을 생성할 수 있으며, 이는 더 복잡한 수학적 계산과 문제 해결을 수행하기 위한 가장 기초적인 도구가 됩니다.

### 기본 성질
새로운 연산 규칙을 정의할 수도 있습니다. 예를 들어 $a \circ b = a + 2b$라는 규칙을 정의한다면, $3 \circ 4$의 결과는 $3 + 2(4)$가 되어 $11$이라는 유일한 값을 얻게 됩니다. 이처럼 연산은 기존의 사칙연산에 국한되지 않고, 어떤 규칙을 설정하느냐에 따라 무한히 확장될 수 있는 수학적 체계입니다.
