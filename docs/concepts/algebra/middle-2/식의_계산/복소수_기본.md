# 복소수 기본

## 정확한 진술

**복소수**는 다음과 같이 표현되는 수입니다.

$$z = a + bi$$

여기서 $a$, $b$는 실수이고, $i$는 **허수 단위**로 $i^2 = -1$을 만족합니다. $a$를 **실부**(real part), $b$를 **허부**(imaginary part)라고 부르며, 다음과 같이 표기합니다.

$$\text{Re}(z) = a, \quad \text{Im}(z) = b$$

$b = 0$이면 $z = a$로 실수이고, $a = 0, b \neq 0$이면 $z = bi$로 **순허수**(pure imaginary)라고 합니다.

## 직관 및 필요성

실수만으로는 $x^2 = -1$ 같은 방정식이 해를 갖지 못합니다. 복소수 체계는 이 문제를 해결하기 위해 허수 단위 $i$를 도입한 것입니다. 복소수는 단순한 추상 개념이 아니라, 다음 두 가지로 이해할 수 있습니다.

**대수적 관점**: 모든 $n$차 다항식 방정식이 복소수 범위에서 정확히 $n$개의 해를 가지도록 하는 수 체계입니다(대수학의 기본정리).

**기하학적 관점**: 복소수 $a + bi$는 좌표평면의 점 $(a, b)$로 대응되며, 이 평면을 **복소평면**(가로축: 실수축, 세로축: 허수축)이라 합니다. 덕분에 복소수 연산은 벡터 연산과 유사하며, 회전과 같은 기하학적 변환을 자연스럽게 표현할 수 있습니다.

## 기본 예

$z_1 = 3 + 2i$는 복소평면에서 점 $(3, 2)$에 해당하며, $\text{Re}(z_1) = 3$, $\text{Im}(z_1) = 2$입니다. $z_2 = -1 - i$는 점 $(-1, -1)$에 해당합니다. 

간단한 검산 예: $i^2 = -1$, $i^3 = -i$, $i^4 = 1$ (sympy로 확인: `[i**n for n in range(1,5)]`)
