# 복소수 기본

> **정의** · 중2 · 단원: [식의 계산](/concepts/식의_계산)

## 요약
실수와 허수를 결합하여 모든 다항방정식의 해를 포함할 수 있도록 확장한 수 체계입니다.

## 본문
복소수는 $z = a + bi$ (단, $a, b$는 실수, $i^2 = -1$)의 형태로 표현되는 수입니다. 여기서 $a$를 실수 부분이라 하며 $\text{Re}(z) = a$로 표기하고, $b$를 허수 부분이라 하며 $\text{Im}(z) = b$로 표기합니다. 만약 $b = 0$이면 이 수는 실수이며, $a = 0$이고 $b \neq 0$인 경우를 순허수라고 부릅니다.

### 직관과 기하적 의미
실수 범위에서는 $x^2 = -1$과 같은 방정식의 해를 구할 수 없지만, 허수 단위 $i$를 도입한 복소수 체계에서는 모든 $n$차 다항방정식이 $n$개의 해를 갖도록 보장할 수 있습니다. 기하학적으로 복소수 $a + bi$는 좌표평면 위의 점 $(a, b)$에 대응됩니다. 이때 가로축을 실수축, 세로축을 허수축으로 하는 평면을 복소평면이라 하며, 이를 통해 복소수의 연산을 평면 위의 회전이나 이동과 같은 기하학적 변환으로 이해할 수 있습니다.

### 기본 성질
허수 단위 $i$는 거듭제곱할 때마다 일정한 규칙성을 보입니다. $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$과 같이 4를 주기로 값이 반복됩니다. 또한 복소수는 실수와 순허수의 결합으로 이루어져 있어, 실수와 허수가 섞인 형태를 띠게 됩니다.

## 학습 체크
- 복소수 $z = a + bi$에서 $a$와 $b$가 각각 무엇을 의미하는지 구분할 수 있는가?
- 어떤 복소수가 순허수가 되기 위한 조건($a=0, b \neq 0$)을 이해하고 있는가?
- 허수 단위 $i$의 거듭제곱이 어떤 주기로 반복되는지 계산할 수 있는가?

## 관련 개념
- **식의 계산**: 복소수의 정의를 바탕으로 실수 부분과 허수 부분을 분리하여 덧셈, 뺄셈, 곱셈, 나눗셈을 수행합니다.
