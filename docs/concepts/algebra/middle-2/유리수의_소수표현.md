# 유리수의 소수표현

> **정리** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
유리수 = 유한소수 ∨ 순환소수

## 본문 (학습 시 채워짐)

### 유리수의 소수 표현 정리

모든 유리수는 소수로 나타낼 때 정확히 두 가지 중 하나입니다: **유한소수** 또는 **순환소수**. 역으로, 유한소수와 순환소수는 모두 유리수입니다.

### 분모의 소인수분해가 결정한다

기약분수 $\frac{a}{b}$를 소수로 나타냈을 때의 형태는 **분모 $b$의 소인수분해**로 완전히 결정됩니다.

분모를 소인수분해했을 때 $b = 2^m \times 5^n$ 형태(2와 5의 거듭제곱만 있음)이면, 분자와 분모에 적절한 수를 곱해 분모를 10의 거듭제곱으로 만들 수 있습니다. 따라서 **유한소수**가 됩니다.

$$\frac{3}{4} = \frac{3 \times 25}{4 \times 25} = \frac{75}{100} = 0.75$$

반면, 분모에 2나 5 이외의 소인수(3, 7, 11, ...)가 있으면, 분모를 10의 거듭제곱으로 만들 수 없습니다. 나눗셈을 계속하면 나머지가 반복되어 **순환소수**가 됩니다.

$$\frac{1}{3} = 0.\overline{3}, \quad \frac{1}{6} = \frac{1}{2 \times 3} = 0.1\overline{6}$$

### 증명 아이디어

유한소수는 정의상 유리수입니다. 순환소수도 일차방정식으로 유리수임을 보일 수 있습니다. 예를 들어 $x = 0.\overline{3}$이면 $10x = 3.\overline{3}$이므로 $10x - x = 3$, 즉 $x = \frac{1}{3}$입니다. 일반적으로 주기가 $k$인 순환소수는 분모가 $10^k - 1$의 약수 형태가 되어 유리수입니다.

### 의의와 응용

이 정리는 유리수의 본질을 드러냅니다. 모든 유리수는 **소수 표현이 반드시 끝나거나 반복된다**는 뜻이며, 이는 원주율처럼 무한하고 비반복인 소수(무리수)와 근본적으로 다릅니다. 수의 성질 판별, 기약분수와 소수 변환 문제에서 자주 활용됩니다.
