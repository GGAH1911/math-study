# 분수 변환

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
분수와 소수(특히 순환소수) 사이를 상호 변환하여 문제 상황에 따라 가장 편리한 형태로 나타내는 과정입니다.

## 본문
분수 변환은 분수와 소수 사이를 상호 변환하는 과정입니다. 모든 유리수는 분수로도, 소수로도 표현할 수 있으므로, 문제 상황에 따라 더 편리한 형태로 바꾸어 사용하는 것이 중요합니다.

분수를 소수로 바꿀 때는 분자를 분모로 나누어 계산합니다.
$$\frac{a}{b} = a \div b$$

소수를 분수로 바꿀 때는 자릿수 이동 원리를 이용합니다. 특히 순환소수를 분수로 나타낼 때 유용하며, 예를 들어 순환소수 $0.\overline{3}$을 분수로 바꾸는 과정은 다음과 같습니다.
$$x = 0.333\cdots$$
$$10x = 3.333\cdots$$
$$10x - x = 3$$
$$9x = 3 \Rightarrow x = \frac{1}{3}$$

### 직관과 기하적 의미
같은 수를 여러 방식으로 나타낼 수 있다는 것은 유리수의 본질입니다. 분수는 수 사이의 정확한 비율 관계을 드러내고, 소수는 수의 크기를 직관적으로 보여주는 역할을 합니다. 순환소수는 끝없이 반복되는 패턴처럼 보이지만, 사실 항상 분수로 표현할 수 있는 완벽한 구조를 가진 유리수입니다.

### 기본 성질
- 분수 $\rightarrow$ 소수: 분자를 분모로 나누어 소수 표현을 얻습니다.
- 소수 $\rightarrow$ 분수: 순환마디의 길이에 따라 $10, 100, 1000$ 등을 곱하여 소수 부분을 일치시킨 후 뺄셈을 통해 순환마디를 제거합니다.

## 학습 체크
- 분수를 소수로 바꿀 때, 나누어떨어지지 않고 순환마디가 생기는 경우는 어떤 경우인가요?
- 순환소수를 분수로 바꿀 때 왜 $10^n$을 곱하여 자릿수를 맞추어야 하나요?
- $0.\overline{27}$을 분수로 변환하는 과정을 단계별로 설명할 수 있나요?

## 관련 개념
- **유리수와 순환소수**: 모든 순환소수는 분수로 나타낼 수 있으므로, 순환소수는 유리수의 일종입니다.
