# 유리수의 소수표현

> **정리** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
모든 유리수는 소수로 나타낼 때 유한소수 또는 순환소수 중 하나로만 표현됩니다.

## 본문
모든 유리수는 소수로 나타낼 때 정확히 두 가지 중 하나인 유한소수 또는 순환소수로 표현됩니다. 역으로 유한소수와 순환소수는 모두 유리수입니다. 기약분수 $\frac{a}{b}$를 소수로 나타낼 때의 형태는 분모 $b$의 소인수분해 결과에 의해 결정됩니다. 분모를 소인수분해했을 때 $2$와 $5$의 거듭제곱 형태($b = 2^m \times 5^n$)로만 이루어져 있다면, 분자와 분모에 적절한 수를 곱하여 분모를 $10$의 거듭제곱으로 만들 수 있으므로 유한소수가 됩니다. 예를 들어 $\frac{3}{4} = \frac{3 \times 25}{4 \times 25} = \frac{75}{100} = 0.75$와 같습니다. 반면 분모에 $2$나 $5$ 이외의 소인수($3, 7, 11$ 등)가 포함되어 있다면 분모를 $10$의 거듭제곱으로 만들 수 없으며, 나눗셈 과정에서 나머지가 반복되어 순환소수가 됩니다. 예시로 $\frac{1}{3} = 0.\overline{3}$, $\frac{1}{6} = \frac{1}{2 \times 3} = 0.1\overline{6}$이 있습니다.

### 증명 스케치
유한소수는 정의에 의해 유리수이며, 순환소수 또한 일차방정식을 통해 유리수임을 보일 수 있습니다. 예를 들어 $x = 0.\overline{3}$일 때 $10x = 3.\overline{3}$이므로 $10x - x = 3$, 즉 $x = \frac{1}{3}$이 됩니다. 일반적으로 주기가 $k$인 순환소수는 분모가 $10^k - 1$의 약수 형태를 가지므로 유리수입니다.

### 의의와 응용
이 정리는 모든 유리수의 소수 표현이 반드시 끝나거나 반복된다는 본질을 보여주며, 이는 무한히 반복되지 않는 무리수와 구별되는 특징입니다. 수의 성질을 판별하거나 기약분수를 소수로 변환하는 문제에서 핵심적인 근거로 활용됩니다.
