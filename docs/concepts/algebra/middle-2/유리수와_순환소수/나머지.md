# 나머지

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
정수 $a$를 양의 정수 $b$로 나누었을 때, $a = bq + r$ ($0 \le r < b$)를 만족하는 유일한 정수 몫 $q$와 나머지 $r$을 의미한다.

## 본문
정수 $a$와 양의 정수 $b$에 대하여, $a = bq + r$을 만족하는 정수 $q$와 $r$은 유일하게 존재한다. 이때 $q$를 몫이라 하고, $r$을 나머지라고 부른다. 이 식에서 가장 중요한 조건은 나머지의 범위가 $0$ 이상 $b$ 미만($0 \le r < b$)으로 제한된다는 점이다. 이 조건이 있어야만 어떤 두 정수를 나누더라도 나머지가 단 하나로 결정된다.

### 직관과 기하적 의미
나머지는 어떤 수량을 일정한 크기로 묶었을 때, 더 이상 묶을 수 없이 남는 부분을 의미한다. 예를 들어 사탕 17개를 5개씩 봉지에 담는다면, 3개의 봉지(몫)를 만들고 2개의 사탕(나머지)이 남는다. 만약 나머지의 범위가 정해져 있지 않다면, $17 = 5 \times 3 + 2$ 외에도 $17 = 5 \times 2 + 7$처럼 여러 방식으로 표현될 수 있어 결과가 불분명해진다. 따라서 나머지는 항상 나누는 수보다 작은 범위 내에서 유일하게 결정되어야 한다.

### 기본 성질
나머지는 나누는 수 $b$에 의해 그 범위가 결정된다. 만약 나머지가 $0$이라면 그 수는 $b$로 나누어떨어진다고 하며, 이때 몫은 $a \div b$의 결과와 같다. 또한, 나누는 수 $a$가 음수인 경우에도 나머지는 항상 $0$ 이상의 정수로 정의된다.

## 학습 체크
- 나머지가 $0$인 경우를 포함하여, $a = bq + r$에서 $r$의 범위가 왜 $0 \le r < b$여야 하는지 설명할 수 있는가?
- 음수를 양수로 나눌 때, 나머지가 항상 $0$ 이상이 되도록 하는 몫 $q$의 값을 찾을 수 있는가?

## 관련 개념
- **정수와 유리수**: 정수를 정수로 나누었을 때 발생하는 나머지는 유리수의 분수 표현을 이해하는 기초가 되며, 나눗셈의 원리를 구성한다.
