# 순환소수를 분수로

> **예제** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
순환소수를 분수로 바꿀 때는 순환마디의 개수만큼 10의 거듭제곱을 곱하여 소수점 아래의 순환 부분이 일치하도록 만든 뒤, 두 식을 빼서 소수 부분을 없애는 원리를 이용합니다.

## 본문
다음 순환소수를 기약분수로 나타내시오.
(1) $0.\overline{3}$
(2) $0.\overline{12}$

### 단계별 풀이
**예제 (1): $0.\overline{3}$ 변환하기**
먼저 순환소수를 $x$로 놓습니다. $x = 0.333\ldots$라고 두면 계산 과정이 명확해집니다.
순환마디가 1자리이므로 양변에 10을 곱하여 소수점 위치를 이동시킵니다.
$$10x = 3.333\ldots$$
이제 두 식을 빼서 소수 부분의 순환 마디를 제거합니다.
$$10x - x = 3.333\ldots - 0.333\ldots$$
$$9x = 3$$
양변을 9로 나누어 $x$의 값을 구한 뒤 기약분수로 나타냅니다.
$$x = \frac{3}{9} = \frac{1}{3}$$

**예제 (2): $0.\overline{12}$ 변환하기**
마찬가지로 $x = 0.121212\ldots$라고 놓습니다.
순환마디가 2자리이므로 양변에 100을 곱합니다.
$$100x = 12.121212\ldots$$
두 식을 빼서 순환 부분을 없앱니다.
$$100x - x = 12$$
$$99x = 12$$
$x$의 값을 구하고 기약분수로 정리합니다.
$$x = \frac{12}{99} = \frac{4}{33}$$

### 답과 변형
(1) $0.\overline{3} = \tfrac{1}{3}$
(2) $0.\overline{12} = \tfrac{4}{33}$

**일반 규칙**: 순환마디의 숫자가 $n$개라면 $10^n$을 곱하여 식을 만듭니다. 예를 들어 $0.\overline{142857}$처럼 6자리인 경우에는 $10^6$인 1,000,000을 곱해야 합니다.

**섞인 순환의 경우**: $0.1\overline{3}$과 같이 순환하지 않는 부분이 섞여 있다면, 소수점 아래 숫자의 위치를 맞추기 위해 서로 다른 10의 거듭제곱을 곱한 뒤 빼줍니다.

**검산**: 구한 분수를 다시 소수로 바꾸어 원래의 순환소수와 일치하는지 확인합니다. 예) $1 \div 3 = 0.333\ldots$

## 학습 체크
- 순환마디의 개수에 따라 $10$의 몇 배를 곱해야 하는지 정확히 알고 있는가?
- 순환하지 않는 부분이 있는 순환소수를 분수로 바꿀 때 두 식을 어떻게 설정해야 하는지 이해했는가?

## 관련 개념
- **유리수와 순환소수**: 모든 순환소수는 분수 형태로 나타낼 수 있으므로, 순환소수는 유리수의 일종입니다.
