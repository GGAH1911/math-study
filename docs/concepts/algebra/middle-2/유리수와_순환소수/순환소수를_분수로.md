# 순환소수를 분수로

> **예제** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)
## 요약
$0.\overline{3}=1/3$

## 본문

### 문제

다음 순환소수를 기약분수로 나타내시오.  
(1) $0.\overline{3}$  
(2) $0.\overline{12}$

### 단계별 풀이

**예제 (1): $0.\overline{3}$ 변환하기**

첫 번째로 할 일은 순환소수를 $x$로 놓는 것이다. $x = 0.333\ldots$라고 쓰면 뭘 해야 할지 더 명확해진다.

이제 양변에 10을 곱한다. 왜냐하면 순환 부분이 1자리 수이므로, 10배 하면 소수점 위치가 한 칸 움직여서 순환 부분이 정렬되기 때문이다:  
$$10x = 3.333\ldots$$

두 식을 빼면 순환 부분이 사라진다. 이게 핵심이다:  
$$10x - x = 3.333\ldots - 0.333\ldots$$
$$9x = 3$$

양변을 9로 나누면:  
$$x = \frac{3}{9} = \frac{1}{3}$$

**예제 (2): $0.\overline{12}$ 변환하기**

같은 방식을 쓰되, 이번엔 순환 부분이 2자리이므로 100을 곱한다:  
$$x = 0.121212\ldots$$
$$100x = 12.121212\ldots$$
$$100x - x = 12$$
$$99x = 12$$
$$x = \frac{12}{99} = \frac{4}{33}$$

### 답

(1) $0.\overline{3} = \dfrac{1}{3}$  
(2) $0.\overline{12} = \dfrac{4}{33}$

### 변형/주의

**일반 규칙**: 순환 부분이 $n$자리면 $10^n$을 곱한다. 예를 들어 $0.\overline{142857}$ 같은 6자리 순환은 100만을 곱해야 한다.

**섞인 순환의 경우** (예: $0.1\overline{3}$): 비순환 부분을 먼저 정렬해야 한다. 비순환 부분이 1자리, 순환 부분이 1자리면 100을 곱하고 10을 곱한 식을 뺀다.

**검산**: 계산 후 분자를 분모로 나누어 순환소수가 나오는지 확인하면 좋다. 예) $1 \div 3 = 0.333\ldots$ ✓
