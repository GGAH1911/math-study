# 유한소수의 조건

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
기약분수의 분모를 소인수분해했을 때 소인수가 2 또는 5뿐이면 유한소수가 됩니다.

## 본문
유한소수란 소수점 아래의 숫자가 어느 지점에서 끝나서, 그 이후로는 계속 0이 반복되는 소수를 의미합니다. 예를 들어 $0.25, 0.375, 0.6$과 같이 표현이 유한한 범위 내에서 마무리되는 형태를 말합니다. 분수 $\tfrac{a}{b}$를 소수로 나타냈을 때 이것이 유한소수가 되기 위한 조건은 다음과 같습니다. 먼저 분수를 반드시 기약분수 상태로 만든 후, 분모를 소인수분해했을 때 오직 2 또는 5만을 소인수로 가져야 합니다. 즉, 분모가 $2^m \times 5^n$ ($m, n$은 0 이상의 정수)의 형태여야 합니다.

### 직관과 기하적 의미
우리가 사용하는 십진법 체계는 $10 = 2 \times 5$라는 구조를 바탕으로 합니다. 분수를 소수로 변환한다는 것은 분모를 $10, 100, 1000$과 같은 10의 거듭제곱 형태로 만드는 과정과 같습니다. 만약 분모에 2와 5 이외의 다른 소인수(예: 3, 7 등)가 포함되어 있다면, 분자와 분모에 어떤 수를 곱하더라도 분모를 10의 거듭제곱으로 만들 수 없으므로 소수점 아래가 끝없이 이어지는 무한소수가 됩니다.

### 기본 성질
분수를 유한소수로 판정할 때는 반드시 '기약분수' 상태인지 확인해야 합니다. 예를 들어 $\tfrac{6}{12}$는 분모에 3이라는 소인수가 있어 무한소수처럼 보이지만, $\tfrac{1}{2}$로 약분하면 분모가 2뿐이므로 유한소수가 됩니다. 반면 $\tfrac{5}{12}$는 약분해도 분모에 3이 남아있으므로 $0.41666...$과 같이 순환소수가 됩니다.

## 학습 체크
- 분수를 유한소수로 판정하기 전, 반드시 기약분수로 약분했는가?
- 분모를 소인수분해했을 때 2와 5 이외의 소인수가 존재하는가?

## 관련 개념
- **유리수와 순환소수**: 유리수 중 유한소수가 아닌 소수는 소수점 아래 특정 마디가 반복되는 순환소수의 형태로 나타납니다.
