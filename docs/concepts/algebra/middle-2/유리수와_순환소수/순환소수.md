# 순환소수

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
소수점 아래의 특정 부분이 끝없이 반복되는 소수입니다.

## 본문
순환소수란 소수점 아래의 어떤 자리부터 일정한 숫자들의 블록이 끝없이 반복되는 소수입니다. 이때 반복되는 부분을 순환마디라고 하며, 수학적으로는 순환마디 위에 점을 찍어 표기합니다. 예를 들어 $0.\overline{3}$은 3이 계속 반복되는 형태이며, $0.1\overline{6}$은 소수점 아래 두 번째 자리부터 6이 반복되는 형태를 의미합니다.

### 직관과 기하적 의미
모든 유리수를 나눗셈으로 나타내면 유한소수 또는 순환소수가 됩니다. 이는 나눗셈 과정에서 나머지가 반복되기 때문에 발생하는 현상입니다. 나눗셈을 할 때 나올 수 있는 나머지는 나누는 수보다 작은 유한한 개수뿐이므로, 계산을 계속하다 보면 반드시 이전에 나왔던 나머지가 다시 나타나게 됩니다. 같은 나머지가 다시 등장하면 그때부터는 몫의 숫자가 동일한 패턴으로 반복되며 순환마디를 형성하게 됩니다. 따라서 모든 유리수는 반드시 유한소수나 순환소수의 형태로 표현될 수 있습니다.

### 기본 성질
- $\tfrac{1}{3} = 0.\overline{3}$ (순환마디: 3)
- $\tfrac{5}{6} = 0.8\overline{3}$ (순환마디: 3)
- $\tfrac{1}{7} = 0.\overline{142857}$ (순환마디: 142857)

## 관련 개념
- **유리수와 순환소수**: 모든 유리수는 분수 형태로 나타낼 수 있으며, 이를 소수로 변환하면 반드시 유한소수 또는 순환소수가 됩니다.
