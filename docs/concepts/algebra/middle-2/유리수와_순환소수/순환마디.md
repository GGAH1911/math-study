# 순환마디

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)
## 요약
반복되는 부분

## 본문

순환소수를 소수점 아래로 계속 나타낼 때, 어느 지점부터 일정한 숫자들이 계속 반복되는 현상이 나타납니다. 이때 반복되는 부분의 숫자들을 **순환마디**라고 합니다. 예를 들어 $\frac{1}{3} = 0.333\cdots$에서는 숫자 3이 계속 반복되므로 순환마디는 3이고, $\frac{1}{6} = 0.1666\cdots$에서는 소수점 아래 둘째 자리부터 6이 반복되므로 순환마디는 6입니다.

### 직관과 표기법

순환마디는 나눗셈을 할 때 자동으로 나타나는 현상입니다. 분자를 분모로 계속 나누다 보면, 어느 순간 나머지가 이전에 나왔던 값과 같아집니다. 그러면 그 이후의 계산 과정이 정확히 반복되어 같은 숫자들이 계속 나타나게 되는 것이죠. 

순환마디를 표기할 때는 반복되는 부분 위에 점을 찍는 방식을 사용합니다. 예를 들어 $0.\overline{3}$은 3이 계속 반복되는 것을 뜻하고, $0.1\overline{6}$은 소수점 아래 둘째 자리부터 6이 반복되는 것을 뜻합니다.

### 예시

$$\frac{1}{3} = 0.\overline{3} \quad \text{(순환마디: 3)}$$

$$\frac{1}{6} = 0.1\overline{6} \quad \text{(순환마디: 6)}$$

$$\frac{1}{7} = 0.\overline{142857} \quad \text{(순환마디: 142857)}$$

분모가 2나 5의 거듭제곱만으로 이루어진 경우를 제외하면, 기약분수는 항상 순환소수가 되고 고유한 순환마디를 갖습니다. 분모가 작을수록 보통 순환마디의 길이가 짧지만, $\frac{1}{7}$처럼 순환마디가 6자리나 될 수도 있습니다. (확인: `from decimal import Decimal; Decimal(1)/Decimal(7)`)
