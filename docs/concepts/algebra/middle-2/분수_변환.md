### 정확한 진술

분수 변환은 분수와 소수(특히 순환소수) 사이를 상호 변환하는 과정입니다. 모든 유리수는 분수로도, 소수로도 표현할 수 있으므로, 문제 상황에 따라 더 편리한 형태로 바꾸는 것입니다.

**분수 → 소수**: 분자를 분모로 나누어 소수 표현을 얻습니다.
$$\frac{a}{b} = a \div b$$

**소수 → 분수**: 특히 순환소수를 분수로 나타낼 때, 자릿수 이동 원리를 이용합니다. 예를 들어 순환소수 $0.\overline{3} = 0.333\cdots$에 대해 다음과 같이 합니다.
$$x = 0.333\cdots$$
$$10x = 3.333\cdots$$
$$10x - x = 3$$
$$9x = 3 \Rightarrow x = \frac{1}{3}$$

### 직관과 의미

같은 수를 여러 방식으로 나타낼 수 있다는 것은 유리수의 본질입니다. 분수는 정확한 관계(비율)를 드러내고, 소수는 크기를 직관적으로 보여줍니다. 

순환소수는 "끝나지 않는" 패턴처럼 보이지만, 사실 항상 분수로 표현 가능합니다. 이는 어떤 유리수도 패턴을 가진 완벽한 구조를 갖는다는 뜻입니다.

### 한 줄 예

$0.\overline{27} = 0.272727\cdots$를 분수로 바꾸면:
$$100x = 27.272727\cdots, \quad x = 0.272727\cdots \Rightarrow 99x = 27 \Rightarrow x = \frac{27}{99} = \frac{3}{11}$$

검산: `sympy.nsimplify(27/99)` → $\frac{3}{11}$ ✓
