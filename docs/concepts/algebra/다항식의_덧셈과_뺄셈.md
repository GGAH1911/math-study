### 정확한 진술

다항식의 덧셈과 뺄셈은 **동류항**(차수가 같고 같은 문자를 포함한 항)끼리만 계수를 더하거나 빼는 연산입니다.

두 다항식 $P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$과 $Q(x) = b_mx^m + b_{m-1}x^{m-1} + \cdots + b_1x + b_0$에 대해:
- **덧셈** $P(x) + Q(x)$는 각 차수별로 같은 차수 항의 계수를 모두 더하여 얻은 다항식입니다.
- **뺄셈** $P(x) - Q(x)$는 각 차수별로 같은 차수 항의 계수를 모두 빼서 얻은 다항식입니다.

동류항이 아닌 항들(예: $3x^2$와 $5x$)은 어떤 연산에서도 결합되지 않습니다.

### 직관과 기하적 의미

다항식을 차수별 계수의 수열로 생각하면, 덧셈과 뺄셈은 **벡터 연산**과 정확히 같습니다. 예를 들어 $2x^2 + 3x + 1$을 계수 벡터 $(2, 3, 1)$로 표현할 수 있으며, 다른 다항식의 계수 벡터와 더하거나 뺄 때는 대응되는 성분(같은 차수의 항)끼리만 연산합니다. 함수의 관점에서 보면 $[P + Q](x) = P(x) + Q(x)$가 성립하여, 다항식 덧셈은 함숫값의 덧셈과 일치합니다. 이는 다항식의 집합이 덧셈과 뺄셈에 대해 닫혀 있다는 것을 의미합니다.

### 한 줄 예

$$(3x^2 + 2x - 1) + (x^2 - 5x + 4) = 4x^2 - 3x + 3$$

$x^2$ 항: $3 + 1 = 4$, $x$ 항: $2 + (-5) = -3$, 상수항: $-1 + 4 = 3$

뺄셈 예: $(2x^3 - 4x + 5) - (x^3 + 3x^2 - 2x + 1) = x^3 - 3x^2 - 2x + 4$
