### 정확한 진술

두 다항식 $f(x)$와 $g(x)$ ($g(x) \neq 0$)에 대해, 다음을 만족하는 다항식 $q(x)$와 $r(x)$가 유일하게 존재합니다:

$$f(x) = g(x) \cdot q(x) + r(x)$$

여기서 $q(x)$를 **몫**, $r(x)$를 **나머지**라 하며, 나머지의 차수는 제수 $g(x)$의 차수보다 작아야 합니다. (나머지가 0이면 차수가 없음)

### 직관적 의미

정수의 나눗셈 $12 = 5 \times 2 + 2$처럼, 다항식도 나눗셈으로 몫과 나머지를 얻습니다. 다항식 $f(x)$를 $g(x)$로 나눌 때, 결과를 **몫 + 나머지/제수** 형태로 표현할 수 있다는 뜻입니다. 

나머지의 차수가 제수보다 작다는 조건은, 더 이상 나눌 수 없는 상태를 의미합니다. 예를 들어 $x^2 + 1$을 $x + 2$로 나누면, 나머지는 상수(차수 0)가 됩니다. 이 성질이 나눗셈을 유일하게 정의하게 합니다.

### 한 줄 예

$x^2 - 5x + 6$을 $x - 2$로 나누면 몫은 $x - 3$, 나머지는 $0$입니다. (검증: $(x-2)(x-3) + 0 = x^2 - 5x + 6$ ✓)

또 다른 예: $x^3 + 2x + 1$을 $x^2 - 1$로 나누면 몫은 $x$, 나머지는 $3x + 1$입니다. (나머지의 차수 1 < 제수의 차수 2)

**sympy 검증:**  
```python
sympy.div(x**3 + 2*x + 1, x**2 - 1)  # (x, 3x + 1)
```
