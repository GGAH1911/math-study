### 정확한 진술

두 개 이상의 다항식을 곱할 때, **분배법칙**을 이용하여 괄호를 풀어 하나의 다항식으로 나타내는 과정을 **다항식전개**라고 합니다. 예를 들어 $(a+b)(c+d)$를 전개하면 각 항끼리 곱한 후 모두 더하여 $ac+ad+bc+bd$로 나타냅니다. 일반적으로 $n$개의 다항식 $P_1(x), P_2(x), \ldots, P_n(x)$의 곱을 전개하는 것도 같은 원리입니다.

$$\left(\sum a_i x^i\right) \cdot \left(\sum b_j x^j\right) = \sum_i \sum_j a_i b_j x^{i+j}$$

### 직관/기하적 의미

다항식전개는 분배법칙의 자연스러운 확장입니다. 직사각형의 넓이를 여러 부분으로 나누어 계산하는 것처럼, $(a+b)(c+d)$는 변의 길이가 $(a+b)$와 $(c+d)$인 직사각형을 $2 \times 2$개의 작은 직사각형으로 분할하는 것과 같습니다. 각 작은 직사각형의 넓이 $ac, ad, bc, bd$를 모두 더하면 전체 넓이가 됩니다.

다항식전개는 인수분해의 역과정이며, 방정식 풀이, 극한 계산, 미적분 등 고등수학의 기초가 됩니다. 또한 같은 패턴을 반복하는 **곱셈공식** (예: $(a+b)^2 = a^2 + 2ab + b^2$)과 **이항정리** 형태로도 나타납니다.

### 한 줄 예

$(2x+3)(x-1)$을 전개하면 $2x^2 - 2x + 3x - 3 = 2x^2 + x - 3$입니다.  
(`sympy.expand((2*x + 3)*(x - 1))` → `2*x**2 + x - 3`)
