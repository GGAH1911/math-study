# 이차식 인수분해

> **예제** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
$x^2-5x+6$

## 본문 (학습 시 채워짐)

### 문제

$x^2-5x+6$을 인수분해하시오.

### 단계별 풀이

**1단계: 인수분해의 형태 결정**

이차식 $x^2-5x+6$을 $(x+a)(x+b)$ 꼴로 인수분해하려면:
$$(x+a)(x+b) = x^2 + (a+b)x + ab$$

이 전개식과 비교하면:
- $a+b = -5$ (일차항의 계수)
- $ab = 6$ (상수항)

를 만족하는 두 수 $a, b$를 찾아야 합니다.

**2단계: 조건을 만족하는 두 수 찾기**

곱이 $6$이 되는 정수 쌍을 모두 나열합니다:
- $(1, 6)$: 합 = $7$
- $(-1, -6)$: 합 = $-7$
- $(2, 3)$: 합 = $5$
- $(-2, -3)$: 합 = $-5$ ✓

따라서 $a = -2, b = -3$입니다.

**3단계: 인수분해 완성 및 검산**

$$x^2-5x+6 = (x-2)(x-3)$$

검산해봅시다:
$$(x-2)(x-3) = x^2 - 3x - 2x + 6 = x^2 - 5x + 6$$ ✓

### 답

$$x^2-5x+6 = (x-2)(x-3)$$

(검증: `sympy.factor(x**2 - 5*x + 6)` → $(x-2)(x-3)$)

### 변형/주의

- **부호 판단**: 상수항이 양수이고 일차항이 음수일 때, 두 수는 모두 음수입니다. 합이 음수, 곱이 양수 → 둘 다 음수!
- **체계적 탐색**: 곱이 같은 쌍들을 빠짐없이 나열하여 합을 확인하는 습관이 중요합니다.
- **항상 검산**: 전개하여 원래 식으로 돌아오는지 확인하면 실수를 방지할 수 있습니다.
- **다른 예**: $x^2-7x+12 = (x-3)(x-4)$, $x^2+5x+6 = (x+2)(x+3)$ 같은 유형도 같은 방법으로 풉니다.
