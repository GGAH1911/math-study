### 정확한 진술

유한소수(finite decimal)는 소수점 이하 유한 자리에서 끝나는 소수를 의미합니다. 즉, $0.25, 0.375, 0.6$ 처럼 어느 시점부터는 계속 0이 되어 표현이 끝나는 소수입니다. 이를 분수로 나타냈을 때, 다음 조건을 만족합니다:

**유한소수 판정법**: 기약분수 $\dfrac{a}{b}$ (단, $\gcd(a,b)=1$)가 유한소수가 되기 위한 필요충분조건은 분모 $b$를 소인수분해했을 때 $b = 2^m \times 5^n$ (단, $m, n \geq 0$인 정수) 형태가 되는 것입니다.

### 분모가 2와 5의 거듭제곱만인 이유

우리가 사용하는 십진법은 $10 = 2 \times 5$를 기반으로 합니다. 분수 $\dfrac{a}{b}$를 소수로 나타낼 때, 분모를 10의 거듭제곱으로 만들어야 유한소수가 됩니다. 분모가 $2^m \times 5^n$이면, $m$과 $n$ 중 더 큰 수를 $k$라 할 때 분자와 분모에 적절한 2 또는 5를 곱하여 분모를 $10^k = 2^k \times 5^k$로 만들 수 있기 때문입니다. 

예를 들어, $\dfrac{3}{8} = \dfrac{3 \times 125}{8 \times 125} = \dfrac{375}{1000} = 0.375$처럼 유한소수로 표현됩니다.

### 예시와 적용

$\dfrac{3}{8}$: 분모 $8 = 2^3$이므로 유한소수 ✓ → $0.375$

$\dfrac{5}{12}$: 분모 $12 = 2^2 \times 3$이므로 유한소수 아님 ✗ → $0.41666...$

$\dfrac{7}{20}$: 분모 $20 = 2^2 \times 5$이므로 유한소수 ✓ → $0.35$

주의할 점은 분수가 기약분수 형태여야 한다는 것입니다. 예를 들어 $\dfrac{6}{12} = \dfrac{1}{2}$로 약분하면 분모가 2뿐이므로 유한소수입니다.

(검산: `sympy.nsimplify(3/8), sympy.nsimplify(5/12)` 등으로 확인 가능)
