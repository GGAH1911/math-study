### 정확한 진술

$a \geq 0$, $b \geq 0$일 때, 다음 두 성질이 성립합니다:

**곱셈 성질:**
$$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$$

**나눗셈 성질:**
$$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \quad (b > 0)$$

이 성질들은 지수를 이용한 표현 $\sqrt{a} = a^{1/2}$에서 $(a^{1/2})(b^{1/2}) = (ab)^{1/2}$와 $\frac{a^{1/2}}{b^{1/2}} = (a/b)^{1/2}$로 바로 유도됩니다.

### 직관적 의미

근호 안의 곱셈은 "제곱근들의 곱은 근호 안의 수들을 먼저 곱한 후 제곱근을 취한 것과 같다"는 뜻입니다. 넓이로 생각하면, 정사각형 두 개의 넓이를 곱할 때 각 정사각형의 한 변 길이를 곱한 후 다시 제곱근을 취하면 결과 도형의 한 변 길이가 됩니다.

나눗셈도 마찬가지로, 두 제곱근의 비는 근호 안의 수들을 먼저 나눈 후 제곱근을 취한 것과 같습니다. 이를 통해 분모의 근호를 없애는 유리화(분모의 유리화) 계산으로 이어집니다.

### 계산 예시

$$\sqrt{3} \times \sqrt{12} = \sqrt{36} = 6$$

$$\frac{\sqrt{50}}{\sqrt{2}} = \sqrt{\frac{50}{2}} = \sqrt{25} = 5$$

$$\sqrt{2} \times \sqrt{8} = \sqrt{16} = 4$$

이 성질들은 복잡한 근호 식을 간단히 할 때 필수적으로 사용됩니다. 특히 서로 다른 근호 형태를 통일하거나 정수로 만들 때 핵심 도구입니다.

(`sympy.simplify(sympy.sqrt(3) * sympy.sqrt(12))` 실행 결과: 6)
