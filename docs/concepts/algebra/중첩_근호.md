### 정확한 진술

근호 안에 다시 근호가 포함된 식을 **중첩 근호**(nested radical)라고 합니다. 가장 흔한 형태는 $\sqrt{a + \sqrt{b}}$이거나 $\sqrt{a - \sqrt{b}}$입니다. 이러한 식들은 복잡해 보이지만, 많은 경우 $\sqrt{p} + \sqrt{q}$ 같은 더 단순한 형태로 다시 쓸 수 있습니다.

### 직관 및 기하적 의미

중첩 근호를 푸는 핵심은 곱셈 공식입니다. $(\sqrt{p} + \sqrt{q})^2 = p + q + 2\sqrt{pq}$라는 것을 알면, 주어진 식 $a + \sqrt{b}$가 이와 같은 형태인지 확인할 수 있습니다. 즉, $p + q = a$이고 $2\sqrt{pq} = \sqrt{b}$라는 두 조건을 만족하는 $p, q$를 찾으면 됩니다. 이는 결국 이차 방정식을 푸는 것과 같으므로, 근과 계수의 관계를 역으로 이용하는 전략입니다.

### 간단한 예

$\sqrt{5 + 2\sqrt{6}}$을 간단히 합시다. $\sqrt{p} + \sqrt{q}$ 형태라 가정하면:
- $p + q = 5$
- $pq = 6$ (∵ $2\sqrt{pq} = 2\sqrt{6}$에서 $pq = 6$)

따라서 $p, q$는 방정식 $t^2 - 5t + 6 = 0$의 근입니다. 이를 풀면 $(t-2)(t-3) = 0$이므로 $p = 2, q = 3$입니다. 그러므로:

$$\sqrt{5 + 2\sqrt{6}} = \sqrt{2} + \sqrt{3}$$

검산: $(\sqrt{2} + \sqrt{3})^2 = 2 + 3 + 2\sqrt{6} = 5 + 2\sqrt{6}$ ✓
