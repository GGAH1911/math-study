# 사칙연산의 성질

> **정리** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
교환·결합·분배·역원

## 본문 (학습 시 채워짐)

### 진술 및 가정

정수와 유리수의 사칙연산은 다음의 네 가지 성질을 만족합니다.

**교환법칙**: 덧셈과 곱셈은 순서를 바꿔도 결과가 같습니다.
- 덧셈: $a + b = b + a$
- 곱셈: $a \times b = b \times a$

**결합법칙**: 세 수를 연산할 때 어느 두 수를 먼저 계산해도 결과가 같습니다.
- 덧셈: $(a + b) + c = a + (b + c)$
- 곱셈: $(a \times b) \times c = a \times (b \times c)$

**분배법칙**: 곱셈은 덧셈 위에서 분배됩니다.
$$a \times (b + c) = a \times b + a \times c$$

**역원**: 각 수에 대해 그것과 연산했을 때 항등원을 만드는 수가 존재합니다.
- 덧셈 역원: $a + (-a) = 0$ (즉, $-a$는 $a$의 덧셈 역원)
- 곱셈 역원: $a \times \frac{1}{a} = 1$ (단, $a \neq 0$이며, $\frac{1}{a}$는 $a$의 곱셈 역원)

### 간단한 검증 및 의의

이 성질들은 '계산을 편하게' 만들기 위한 기본 규칙입니다. 예를 들어, $25 \times 7 \times 4$를 계산할 때 교환·결합법칙을 이용하여 $(25 \times 4) \times 7 = 100 \times 7 = 700$으로 빠르게 계산할 수 있습니다. 분배법칙은 $5 \times (12 + 8) = 5 \times 12 + 5 \times 8 = 60 + 40 = 100$처럼 복잡한 식을 전개하거나 인수분해할 때 필수입니다.

역원의 개념은 나중에 방정식을 풀 때 핵심이 됩니다. 예를 들어 $x + 3 = 7$을 풀기 위해 양변에 $-3$을 더하는 것은 덧셈 역원을 이용하는 것이고, $2x = 10$을 풀기 위해 양변에 $\frac{1}{2}$를 곱하는 것은 곱셈 역원을 이용하는 것입니다.

### 응용

이 네 가지 성질은 단순히 정수와 유리수에만 적용되지 않습니다. 다항식, 행렬, 함수 등 더 복잡한 대상들도 이 성질들을 만족하면 '잘 정의된' 연산으로 간주합니다. 따라서 중학교에서 익숙해지면 고등학교의 지수법칙, 로그의 성질, 삼각함수 항등식 등으로 자연스럽게 확장됩니다.
