# 나눗셈 정리

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
$f(x)=g(x)q(x)+r(x)$

## 본문 (학습 시 채워짐)

### 정확한 진술

다항식 $f(x)$를 영이 아닌 다항식 $g(x)$로 나눌 때, 다음을 만족하는 다항식 $q(x)$(몫)과 $r(x)$(나머지)가 유일하게 존재합니다.

$$f(x) = g(x) \cdot q(x) + r(x)$$

여기서 $r(x) = 0$ 이거나 $\deg(r) < \deg(g)$ 입니다. 즉, 나머지의 차수는 항상 나누는 다항식의 차수보다 작습니다.

### 직관적 의미

정수의 나눗셈처럼, 다항식도 나눗셈이 가능합니다. 예를 들어 정수 17을 5로 나누면 몫 3과 나머지 2를 얻듯이 ($17 = 5 \times 3 + 2$), 다항식도 같은 원리가 작동합니다. 세로 나눗셈으로 수행하며, 나머지는 항상 나누는 다항식보다 차수가 낮아야 더 이상 나눌 수 없다는 뜻입니다.

이 정리는 다항식의 인수분해, 근과 계수의 관계, 그리고 나중에 배우는 인수정리와 직결됩니다. 특히 나머지가 0이 되면 $g(x)$가 $f(x)$의 인수임을 의미합니다.

### 간단한 예

$f(x) = x^3 + 2x + 1$을 $g(x) = x + 1$로 나누면:

$$x^3 + 2x + 1 = (x+1)(x^2 - x + 3) - 2$$

여기서 몫은 $q(x) = x^2 - x + 3$, 나머지는 $r(x) = -2$ 입니다. 나머지의 차수(0)가 $g(x)$의 차수(1)보다 작으므로 조건을 만족합니다.

(`sympy.div(x**3 + 2*x + 1, x + 1)` → $(x^2 - x + 3, -2)$)
