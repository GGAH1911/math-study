### 정확한 진술

$a, b$가 음이 아닌 실수일 때, **근호의 성질**은 다음을 만족합니다:

$$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$$

$$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \quad (b > 0)$$

$$(\sqrt{a})^2 = a$$

$$\sqrt{a^2} = |a|$$

### 직관과 의미

근호의 성질은 제곱근의 정의에서 자연스럽게 나옵니다. $\sqrt{a}$는 "제곱하면 $a$가 되는 음이 아닌 수"이므로, 두 근호의 곱 $\sqrt{a} \times \sqrt{b}$를 제곱하면 $(\sqrt{a})^2 \times (\sqrt{b})^2 = a \times b$가 됩니다. 따라서 $\sqrt{a} \times \sqrt{b}$는 "제곱하면 $ab$가 되는 음이 아닌 수"이고, 이것이 바로 $\sqrt{ab}$입니다.

마찬가지로 나눗셈도 같은 논리를 따릅니다. $\sqrt{a^2} = |a|$인 이유는 제곱근은 항상 음이 아닌 수이기 때문입니다. 예를 들어 $a = -3$이면 $\sqrt{(-3)^2} = \sqrt{9} = 3 = |-3|$입니다.

### 예제

$\sqrt{12} \times \sqrt{3}$을 계산하면:

$$\sqrt{12} \times \sqrt{3} = \sqrt{12 \times 3} = \sqrt{36} = 6$$

또는 $\sqrt{(-5)^2} = |-5| = 5$, $(\sqrt{7})^2 = 7$이 성질의 응용입니다.

### 주의 사항

$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$는 $a, b \geq 0$일 때만 성립합니다. 음수에 대해서는 성립하지 않습니다. 예를 들어 $\sqrt{-1} \times \sqrt{-1} \neq \sqrt{(-1)(-1)} = 1$입니다 (실수 범위에서).
