### 정확한 진술

지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)와 로그함수 $g(x) = \log_a x$는 **역함수 관계**에 있습니다. 즉, 다음이 성립합니다.

$$a^{\log_a x} = x \quad (x > 0)$$
$$\log_a(a^x) = x \quad (x \in \mathbb{R})$$

이는 "지수"와 "로그"가 서로 정반대의 작용을 하며, 한 함수를 적용한 후 다른 함수를 적용하면 원래 값으로 돌아온다는 의미입니다.

### 직관 및 기하적 의미

**대수적 관점**: 지수는 "곱셈을 덧셈으로 변환"합니다. 지수 법칙 $a^m \cdot a^n = a^{m+n}$에서 보듯, 곱해지는 수들이 지수에서는 더해집니다. 로그는 정반대로 "곱셈을 다시 덧셈으로 표현"합니다 ($\log_a(xy) = \log_a x + \log_a y$).

**그래프 관점**: $y = a^x$ 곡선과 $y = \log_a x$ 곡선은 직선 $y = x$를 기준으로 **완벽하게 대칭**입니다. 지수 곡선 위의 점 $(p, q)$는 로그 곡선 위의 점 $(q, p)$에 대응됩니다.

### 구체적 예

$$2^3 = 8 \quad \Leftrightarrow \quad \log_2 8 = 3$$

지수식 "$2^3 = 8$"을 로그식으로 읽으면 "$\log_2 8 = 3$"이고, 역으로 로그식 "$\log_2 8 = 3$"을 지수식으로 쓰면 "$2^3 = 8$"이 됩니다. 역관계이기 때문입니다.

다른 예시:
- $3^4 = 81$ ⟺ $\log_3 81 = 4$
- $\log_5 x = 2$ ⟺ $5^2 = x$ (즉 $x = 25$)

**검증 코드**: `sympy.log(8, 2)` 실행 시 결과는 `3`
