# 거듭제곱근의 곱셈

### 정확한 진술

$a > 0$, $b > 0$이고 $n$이 2 이상의 자연수일 때, 같은 거듭제곱근의 곱은 다음과 같이 계산합니다:

$$\sqrt[n]{a} \times \sqrt[n]{b} = \sqrt[n]{ab}$$

즉, 거듭제곱근을 먼저 취한 뒤 곱하는 것과 근호 안의 수들을 먼저 곱한 뒤 거듭제곱근을 취하는 것이 같다는 의미입니다.

### 직관/기하적 의미

이 성질은 지수법칙에서 자연스럽게 따라옵니다. 거듭제곱근을 분수 지수로 표현하면:

$$\sqrt[n]{a} = a^{1/n}, \quad \sqrt[n]{b} = b^{1/n}$$

따라서 지수의 곱셈법칙 $x^m \times y^m = (xy)^m$을 적용하면:

$$a^{1/n} \times b^{1/n} = (ab)^{1/n} = \sqrt[n]{ab}$$

근호는 "같은 거듭제곱근"이라는 조건 아래에서만 곱셈이 합쳐집니다. 다른 근호는 이 법칙을 적용할 수 없습니다.

### 계산 예제

**예 1:** $\sqrt[3]{2} \times \sqrt[3]{4} = \sqrt[3]{2 \times 4} = \sqrt[3]{8} = 2$

**예 2:** $\sqrt{6} \times \sqrt{2} = \sqrt{6 \times 2} = \sqrt{12} = 2\sqrt{3}$

(검산: `sympy.simplify(sqrt(6) * sqrt(2))` → $2\sqrt{3}$)

**예 3:** $\sqrt[4]{5} \times \sqrt[4]{20} = \sqrt[4]{100}$

이 규칙은 복잡한 거듭제곱근의 계산을 간단히 할 수 있게 해주며, 근호를 정리하고 분모를 유리화하는 과정에서 자주 사용됩니다.
