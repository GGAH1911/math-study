### 정확한 진술

서로 다른 두 로그 밑을 변환할 수 있는 공식입니다. $a, b, c > 0$이고 $a \neq 1$, $c \neq 1$일 때:

$$\log_a b = \frac{\log_c b}{\log_c a}$$

특히 상용로그($\log_{10}$) 또는 자연로그($\ln$)로 변환하면:

$$\log_a b = \frac{\log b}{\log a} = \frac{\ln b}{\ln a}$$

### 직관 및 의미

계산기나 표에는 보통 상용로그와 자연로그만 있습니다. 로그의 밑 변환 공식은 계산하기 어려운 임의의 밑을 우리가 계산할 수 있는 밑으로 바꿔주는 도구입니다. 예를 들어 $\log_2 1000$을 구해야 할 때, 직접 계산하기는 어렵지만 $\frac{\log 1000}{\log 2}$로 변환하면 계산기로 쉽게 구할 수 있습니다.

### 유도 스케치

정의에서 $\log_a b = x$라고 하면 $a^x = b$입니다. 양변에 로그를 취하면:

$$\log_c(a^x) = \log_c b$$
$$x \log_c a = \log_c b$$
$$x = \frac{\log_c b}{\log_c a}$$

따라서 $\log_a b = \frac{\log_c b}{\log_c a}$입니다.

### 한 줄 예제

$\log_2 8$을 상용로그로 계산하면:
$$\log_2 8 = \frac{\log 8}{\log 2} = \frac{\log 2^3}{\log 2} = \frac{3\log 2}{\log 2} = 3$$

(`from sympy import log; print(log(8, 2))` → 3)

또는 직접 $2^3 = 8$이므로 $\log_2 8 = 3$입니다.
