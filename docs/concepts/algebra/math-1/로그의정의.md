### 정확한 진술

밑 $a$에 대한 $x$의 로그(logarithm)는 다음과 같이 정의합니다.

$a > 0$, $a \neq 1$이고 $x > 0$일 때, 방정식 $a^y = x$를 만족하는 유일한 실수 $y$를 $\log_a x$로 나타냅니다.

즉, **$y = \log_a x \Leftrightarrow a^y = x$** 입니다.

여기서 $a$를 밑(base), $x$를 진수(argument), $y$를 로그값이라 부릅니다.

### 직관과 기하적 의미

로그는 **지수의 역연산**입니다. 지수 함수 $y = a^x$가 "밑 $a$를 $x$번 곱하면 얼마인가?"라고 묻는다면, 로그 함수 $y = \log_a x$는 "밑 $a$를 몇 번 곱해야 $x$가 되는가?"라고 묻습니다.

예를 들어, $2^3 = 8$이므로 역으로 $\log_2 8 = 3$입니다. 즉, "2를 3번 곱해야 8이 된다"는 의미입니다.

기하학적으로는 지수 함수 $y = a^x$의 그래프를 직선 $y = x$에 대해 대칭이동하면 로그 함수 $y = \log_a x$의 그래프를 얻습니다. 이는 두 함수가 서로 역함수 관계임을 보여줍니다.

로그의 정의에서 진수 $x$는 반드시 양수여야 한다는 점이 중요합니다. 음수나 0의 로그는 정의되지 않으므로 로그 함수의 정의역은 항상 양의 실수입니다.

### 한 줄 예

$\log_2 16 = 4$ (왜냐하면 $2^4 = 16$). 고등학교에서는 상용로그 $\log x = \log_{10} x$와 자연로그 $\ln x = \log_e x$를 주로 다룹니다. 검증: `sympy.log(16, 2)` → 4
