### 정확한 진술

$a > 0, a \neq 1$이고 $b > 0$일 때, 임의의 양수 $c \neq 1$에 대하여
$$\log_a b = \frac{\log_c b}{\log_c a}$$
이 성립합니다. 특히 $c = 10$ (상용로그) 또는 $c = e$ (자연로그)를 사용하여 원래 밑 $a$의 로그를 계산할 수 있습니다.

### 직관과 의미

로그의 정의에서 $\log_a b = x$는 "$a$를 몇 번 곱해야 $b$가 되는가"를 의미합니다. 밑변환 공식은 이 질문을 다른 밑 $c$로 다시 표현하는 것입니다.

**유도 스케치**: $\log_a b = x$라 하면 $a^x = b$입니다. 양변에 밑 $c$로 로그를 취하면
$$\log_c(a^x) = \log_c b \implies x \log_c a = \log_c b \implies x = \frac{\log_c b}{\log_c a}$$
따라서 $\log_a b = \frac{\log_c b}{\log_c a}$입니다.

**실용적 의미**: 계산기나 로그표는 보통 상용로그(밑 10)나 자연로그(밑 $e$)만 제공합니다. 밑변환 공식을 사용하면 어떤 밑의 로그도 이들로 표현할 수 있어서, 임의의 밑에 대한 로그값을 계산할 수 있게 됩니다.

### 간단한 예

$\log_2 8$을 구하려면, 밑변환 공식으로 상용로그를 이용하여
$$\log_2 8 = \frac{\log_{10} 8}{\log_{10} 2}$$
로 계산할 수 있습니다. (물론 $2^3 = 8$이므로 답은 3입니다.)

검산: `from sympy import log; log(8, 2)`는 3을 반환합니다.
