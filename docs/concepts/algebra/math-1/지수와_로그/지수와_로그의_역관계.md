# 지수와 로그의 역관계

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
지수함수와 로그함수는 서로 역함수 관계에 있으며, 직선 $y=x$를 기준으로 대칭을 이룹니다.

## 본문
지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)와 로그함수 $g(x) = \log_a x$는 서로 역함수 관계에 있습니다. 이는 지수와 로그가 서로 정반대의 작용을 하여, 한 함수를 적용한 후 다른 함수를 적용하면 원래의 값으로 돌아온다는 것을 의미합니다. 따라서 다음의 성질이 성립합니다. $a^{\log_a x} = x$ ($x > 0$) 및 $\log_a(a^x) = x$ ($x \in \mathbb{R}$).

### 직관과 기하적 의미
대수적 관점에서 지수는 곱셈을 덧셈으로 변환하는 성질을 가집니다. 지수 법칙 $a^m \cdot a^n = a^{m+n}$에서 보듯 곱해지는 수들이 지수에서는 더해지며, 로그는 이와 반대로 곱셈을 다시 덧셈으로 표현합니다($\log_a(xy) = \log_a x + \log_a y$). 기하학적 관점에서 $y = a^x$ 곡선과 $y = \log_a x$ 곡선은 직선 $y = x$를 기준으로 완벽하게 대칭을 이룹니다. 즉, 지수 곡선 위의 점 $(p, q)$는 로그 곡선 위의 점 $(q, p)$에 대응됩니다.

### 기본 성질
지수식과 로그식은 서로 변환이 가능하여 다음과 같은 관계를 가집니다.
- $2^3 = 8 \Leftrightarrow \log_2 8 = 3$
- $3^4 = 81 \Leftrightarrow \log_3 81 = 4$
- $\log_5 x = 2 \Leftrightarrow 5^2 = x$ (즉, $x = 25$)

## 학습 체크
- 지수함수와 로그함수의 그래프가 $y=x$에 대해 대칭임을 이용하여 함숫값을 구할 수 있는가?
- 주어진 지수식을 로그식으로, 또는 로그식을 지수식으로 정확하게 변환할 수 있는가?
- 로그의 밑과 지수의 밑이 같을 때 성립하는 역관계의 성질을 이해하고 있는가?

## 관련 개념
- **지수와 로그**: 지수는 밑을 거듭제곱하여 값을 구하는 연산이며, 로그는 그 결과값으로부터 지수를 찾아내는 역연산입니다.
