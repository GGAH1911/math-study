# 로그값 계산

로그의 정의와 성질을 이용해 구체적인 로그식의 값을 구하는 절차입니다. 수학1 지수와 로그 단원의 기본 계산 기법입니다.

## 정의

$a > 0,\ a \neq 1,\ b > 0,\ c > 0$일 때 다음 로그 성질을 사용합니다.
- 정의: $\log_a b = x \iff a^x = b.$
- 곱·몫: $\log_a (bc) = \log_a b + \log_a c$, $\log_a \dfrac{b}{c} = \log_a b - \log_a c.$
- 거듭제곱: $\log_a b^k = k \log_a b.$
- 밑변환: $\log_a b = \dfrac{\log_c b}{\log_c a}.$

이들을 조합해 미지의 로그식을 알려진 값으로 표현합니다.

## 예시

$\log_2 24 - \log_2 3$의 값을 구해 봅니다. 몫의 성질에 의해
$$\log_2 24 - \log_2 3 = \log_2 \frac{24}{3} = \log_2 8 = 3.$$

또한 $\log_2 3 = a$일 때 $\log_2 18$을 $a$로 나타내면, $18 = 2 \cdot 3^2$이므로
$$\log_2 18 = \log_2 2 + 2\log_2 3 = 1 + 2a.$$
