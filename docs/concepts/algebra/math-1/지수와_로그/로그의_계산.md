# 로그의 계산

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
로그의 성질을 활용하여 복잡한 로그식을 단순화하거나 수치를 계산하는 과정입니다.

## 본문
로그의 계산이란 로그의 성질을 이용하여 복잡한 로그식을 단순화하거나 수치를 구하는 과정입니다. 이 과정은 지수법칙의 원리를 로그의 관점에서 재해석한 것으로, 복잡한 연산을 더 쉬운 연산으로 변환하는 역할을 합니다. 로그 계산을 통해 우리는 곱셈을 덧셈으로, 나눗셈을 뺄셈으로 바꾸어 표현할 수 있으며, 이는 수의 크기를 다루는 데 있어 매우 강력한 도구가 됩니다.

### 직관과 기하적 의미
이 성질들은 모두 지수의 규칙에서 유도됩니다. 지수법칙 $a^m \cdot a^n = a^{m+n}$을 양변에 로그를 취하면 곱의 로그 공식을 얻을 수 있습니다. 따라서 로그 계산은 "지수 언어를 로그 언어로 번역"하는 과정이라 할 수 있습니다. 예를 들어, 곱셈 문제를 덧셈으로 바꾸고, 나눗셈을 뺄셈으로 바꾸는 것처럼 복잡한 계산을 단순하게 만드는 기법입니다.

### 기본 성질
- **곱의 로그**: $\log_a(MN) = \log_a M + \log_a N$ (단, $M, N > 0$)
- **몫의 로그**: $\log_a \frac{M}{N} = \log_a M - \log_a N$
- **거듭제곱의 로그**: $\log_a M^n = n \log_a M$
- **밑의 변환**: $\log_a b = \frac{\log_c b}{\log_c a}$ (단, $c > 0, c \neq 1$)
- **기타 기본 성질**: $\log_a 1 = 0$, $\log_a a = 1$, $a^{\log_a x} = x$

## 학습 체크
- 로그의 성질을 적용할 때 진수 조건($M, N > 0$)을 만족하는지 확인하였는가?
- 밑의 변환 공식을 사용하여 계산하기 편리한 밑으로 변환할 수 있는가?
- 지수법칙과 로그의 성질 사이의 연관성을 이해하고 있는가?

## 관련 개념
- **지수와 로그**: 로그는 지수의 역연산 관계에 있으므로, 지수법칙을 이해하면 로그의 계산 성질을 자연스럽게 유도할 수 있습니다.
