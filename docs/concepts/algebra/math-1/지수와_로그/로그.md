# 로그

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$a^x = b$를 만족하는 $x$를 $\log_a b$라고 정의합니다.

## 본문
$a > 0, a \neq 1, b > 0$일 때, $a^x = b$를 만족하는 수 $x$를 $\log_a b$라고 합니다. 이때 $a$를 밑, $b$를 진수라고 부릅니다. 즉, $\log_a b = x \Leftrightarrow a^x = b$의 관계가 성립합니다. 로그가 정의되기 위해서는 밑 조건($a > 0, a \neq 1$)과 진수 조건($b > 0$)을 반드시 만족해야 하며, 음수나 $0$의 로그는 정의되지 않습니다.

### 직관과 기하적 의미
로그는 지수 방정식에서 지수를 구하기 위한 도구입니다. 예를 들어 $2^x = 8$처럼 암산이 가능한 경우도 있지만, $2^x = 5$와 같이 지수가 정수로 떨어지지 않는 경우 $x = \log_2 5$와 같이 로그를 사용하여 지수를 표현합니다. 즉, 로그는 지수로 숨겨진 값을 찾아내는 역연산입니다. 기하학적으로 볼 때, 지수 함수 $y = a^x$의 그래프 위의 점 $(x, b)$에서 $x$좌표가 바로 $\log_a b$입니다. 따라서 로그 함수 $y = \log_a x$는 지수 함수 $y = a^x$를 직선 $y = x$에 대해 대칭이동한 역함수 관계를 가집니다.

### 기본 성질
로그의 성질을 이해하기 위한 예시는 다음과 같습니다.
- $\log_2 8 = 3$ (∵ $2^3 = 8$)
- $\log_5 25 = 2$ (∵ $5^2 = 25$)
- $\log_3 1 = 0$ (∵ $3^0 = 1$)
- $\log_2 \tfrac{1}{4} = -2$ (∵ $2^{-2} = \tfrac{1}{4}$)

## 학습 체크

- 지수 형태의 방정식을 로그를 이용하여 표현할 수 있는가?
- 지수 함수와 로그 함수의 역함수 관계를 그래프로 이해하고 있는가?

## 관련 개념
- **지수와 로그**: 로그는 지수 방정식의 해를 구하기 위해 도입된 개념으로, 지수와 로그는 서로 역연산 관계에 있습니다.
