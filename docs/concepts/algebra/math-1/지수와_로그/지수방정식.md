### 정확한 진술

지수방정식(exponential equation)은 **미지수가 지수에 포함된 방정식**입니다. 가장 기본적인 형태는 $a^x = b$ (단, $a > 0, a \neq 1, b > 0$)이고, 더 일반적으로는 $a^{f(x)} = a^{g(x)}$ 또는 $a^{f(x)} = c$ 같은 형태를 포함합니다. 여기서 $a$를 밑(base)이라고 부릅니다.

### 직관/기하적 의미

지수방정식을 푼다는 것은 **지수함수가 특정 값을 갖는 입력값(지수)을 찾는 것**입니다. 예를 들어 $2^x = 8$을 풀 때, "2를 몇 번 곱해야 8이 되나?"라고 묻는 것입니다. 좌표평면에서 지수함수 $y = 2^x$의 그래프와 수평선 $y = 8$이 만나는 점의 $x$ 좌표가 바로 해입니다.

$a^x = b$ 형태의 방정식은 양변에 로그를 취하면 쉽게 풀 수 있습니다. $\log_a(a^x) = \log_a b$에서 $x = \log_a b$가 됩니다. 또는 상용로그를 사용하면 $x \log a = \log b$이므로 $x = \frac{\log b}{\log a}$입니다.

### 한 줄 예

$3^x = 81$은 $3^x = 3^4$이므로 $x = 4$이고, $2^{2x-1} = 16$은 $2^{2x-1} = 2^4$에서 $2x - 1 = 4$, 따라서 $x = \frac{5}{2}$입니다.

```python
# sympy로 검증
from sympy import symbols, solve, Eq
x = symbols('x')
solve(Eq(2**(2*x-1), 16), x)  # [5/2]
```
