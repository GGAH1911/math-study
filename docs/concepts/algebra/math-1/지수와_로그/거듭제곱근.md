# 거듭제곱근

## 정확한 진술

$a$가 실수이고 $n$이 2 이상의 자연수일 때, $x^n = a$를 만족하는 실수 $x$를 **$a$의 $n$제곱근**이라고 합니다. 이를 $x = \sqrt[n]{a}$로 나타냅니다. 특히 $n = 2$일 때는 제곱근, $n = 3$일 때는 세제곱근이라고 부릅니다.

## 직관/기하적 의미

거듭제곱근은 거듭제곱의 역연산입니다. 예를 들어 $2^3 = 8$이면, 역으로 "어떤 수를 3번 곱해서 8이 되게 하는 수는?"이라고 물을 때 답이 바로 세제곱근 $\sqrt[3]{8} = 2$입니다. 

$n$이 짝수(예: 제곱근)일 때는 주의가 필요합니다. $x^2 = 4$를 만족하는 실수는 $x = 2$ 또는 $x = -2$ 두 개인데, 우리는 **양수 $x$만을** $\sqrt{4}$로 정의하기로 약속합니다. 즉, $\sqrt[n]{a}$ (여기서 $n$은 짝수, $a > 0$)는 항상 양수입니다.

$n$이 홀수일 때는 음수의 거듭제곱근도 정의할 수 있습니다. 예를 들어 $\sqrt[3]{-8} = -2$입니다. 왜냐하면 $(-2)^3 = -8$이기 때문입니다.

## 한 줄 예

$\sqrt{9} = 3$ (왜냐하면 $3^2 = 9$), $\sqrt[3]{27} = 3$ (왜냐하면 $3^3 = 27$), $\sqrt[4]{16} = 2$ (왜냐하면 $2^4 = 16$).

검증: `sympy.Pow(2, 4), sympy.Pow(3, 3), sympy.Pow(3, 2)` → 각각 16, 27, 9
