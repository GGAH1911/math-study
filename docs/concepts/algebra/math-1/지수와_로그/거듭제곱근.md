# 거듭제곱근

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
실수 $a$에 대하여 $n$제곱을 했을 때 $a$가 되는 실수 $x$를 $a$의 $n$제곱근이라고 하며, 이는 거듭제곱의 역연산 개념입니다.

## 본문
$a$가 실수이고 $n$이 2 이상의 자연수일 때, $x^n = a$를 만족하는 실수 $x$를 $a$의 $n$제곱근이라고 하며, 이를 $x = \sqrt[n]{a}$로 나타냅니다. 특히 $n=2$일 때는 제곱근, $n=3$일 때는 세제곱근이라고 부릅니다.

### 직관과 기하적 의미
거듭제곱근은 거듭제곱의 역연산입니다. 예를 들어 $2^3 = 8$일 때, 어떤 수를 3번 곱해서 8이 되게 하는 수를 찾는 과정이 바로 세제곱근을 구하는 과정이며, $\sqrt[3]{8} = 2$가 그 답이 됩니다.

### 기본 성질
$n$이 짝수일 때(예: 제곱근)는 주의가 필요합니다. $x^2 = 4$를 만족하는 실수는 $x = 2$ 또는 $x = -2$ 두 개이지만, 우리는 양수 $x$만을 $\sqrt{4}$로 정의하기로 약속합니다. 즉, $n$이 짝수이고 $a > 0$인 경우 $\sqrt[n]{a}$는 항상 양수입니다. 반면 $n$이 홀수일 때는 음수의 거듭제곱근도 정의할 수 있습니다. 예를 들어 $(-2)^3 = -8$이므로 $\sqrt[3]{-8} = -2$가 성립합니다.

## 학습 체크
- $n$이 짝수일 때 $a$의 값에 따라 실수인 거듭제곱근의 개수가 어떻게 달라지는가?
- $\sqrt[n]{a}$에서 $n$이 홀수일 때 음수의 거듭제곱근이 존재하는 이유는 무엇인가?

## 관련 개념
- **지수와 로그**: 거듭제곱근은 지수 법칙을 통해 지수가 분수 형태인 지수로 표현될 수 있으며, 로그는 거듭제곱의 관계를 다른 관점에서 설명합니다.
