# 근호의 계산

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$n$제곱근의 정의를 바탕으로 근호 안의 식을 결합하거나 분리하여 계산하는 과정입니다.

## 본문
실수 $a$에 대하여 $x^n = a$를 만족하는 $x$를 $a$의 $n$제곱근이라고 합니다. 이때 $a \geq 0$인 경우, $n$제곱근 중 음이 아닌 것을 주 $n$제곱근이라 하며 $\sqrt[n]{a}$로 표기합니다. 특히 $n=2$일 때는 $\sqrt{a}$로 쓰며 이를 제곱근 또는 루트라고 부릅니다. 근호 계산은 지수법칙의 역연산 성질을 이용하여 근호 안의 식을 단순화하는 과정입니다.

### 직관과 기하적 의미
제곱근 $\sqrt{2}$는 넓이가 2인 정사각형의 한 변의 길이를 의미합니다. 즉, 제곱근은 거듭제곱의 역연산이며, 근호 계산 규칙은 지수법칙을 거꾸로 적용한 것입니다. 예를 들어 $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$는 두 변의 길이를 곱한 값이 넓이가 된다는 기하학적 직관과 연결됩니다. 단, 실수 범위 내에서 근호 안의 값은 항상 0 이상이어야 함을 유의해야 합니다.

### 기본 성질
- $\sqrt[n]{a} \cdot \sqrt[n]{b} = \sqrt[n]{ab}$ (단, $a, b \geq 0$)
- $\frac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\frac{a}{b}}$ (단, $a \geq 0, b > 0$)
- $(\sqrt[n]{a})^n = a$ (단, $a \geq 0$)
- $\sqrt[n]{\sqrt[m]{a}} = \sqrt[nm]{a}$ (단, $a \geq 0$)

## 학습 체크
- 근호 안의 값이 음수가 될 경우 실수 범위에서 정의되지 않는다는 점을 이해하고 있는가?
- 근호 안의 식을 완전제곱식으로 인수분해하여 근호 밖으로 꺼내는 과정을 수행할 수 있는가?

## 관련 개념
- **실수와 그 계산**: 근호 안의 값이 0 이상이어야 실수가 정의된다는 점에서 실수의 범위와 밀접하게 연결됩니다.
