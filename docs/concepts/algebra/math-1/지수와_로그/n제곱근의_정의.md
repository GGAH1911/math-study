# n제곱근의 정의

$n$제곱을 했을 때 주어진 수가 되는 값들을 가리키는 개념으로, 거듭제곱근의 일반화입니다. 수학1 지수와 로그 단원에서 지수 확장의 출발점입니다.

## 정의

실수 $a$와 $2$ 이상의 자연수 $n$에 대하여 $x^n = a$를 만족시키는 $x$를 $a$의 **$n$제곱근**이라 합니다. 복소수 범위에서 $a$의 $n$제곱근은 $n$개 존재합니다.

실수 범위에서는 다음과 같이 결정됩니다.
- $n$이 홀수이면 $a$의 실수 $n$제곱근은 단 하나이며 $\sqrt[n]{a}$로 표기합니다.
- $n$이 짝수이고 $a > 0$이면 실수 $n$제곱근은 $\sqrt[n]{a}$와 $-\sqrt[n]{a}$ 두 개입니다.
- $n$이 짝수이고 $a < 0$이면 실수 $n$제곱근은 존재하지 않습니다.

## 예시

$8$의 세제곱근 중 실수인 것은 $\sqrt[3]{8} = 2$ 하나입니다. 반면 $16$의 네제곱근 중 실수인 것은 $\sqrt[4]{16} = 2$와 $-\sqrt[4]{16} = -2$ 두 개입니다. 또한 $-4$의 제곱근은 실수 범위에는 없습니다.
