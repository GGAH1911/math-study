# 실수의 n제곱근 존재 조건

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
실수 $a$의 $n$제곱근 중 실수가 존재할 조건은 $n$이 홀수이면 모든 실수 $a$에 대해, $n$이 짝수이면 $a \geq 0$일 때만 성립합니다.

## 본문
실수 $a$와 양의 정수 $n$에 대하여, 방정식 $x^n = a$를 만족하는 실수 $x$가 존재할 조건은 $n$의 홀짝 여부에 따라 달라집니다. $n$이 홀수인 경우, $a$의 값에 관계없이 모든 실수 $a$에 대하여 정확히 하나의 실수 $\sqrt[n]{a}$가 존재합니다. 반면 $n$이 짝수인 경우, $a \geq 0$일 때만 음이 아닌 실근 $\sqrt[n]{a}$가 존재하며, $a < 0$일 때는 실수 범위에서 $n$제곱근이 존재하지 않습니다.

### 직관과 기하적 의미
함수 $y = x^n$의 그래프와 수평선 $y = a$의 교점의 $x$좌표를 통해 이해할 수 있습니다. $n$이 홀수일 때 함수 $y = x^n$은 모든 사분면을 지나는 증가함수이므로, 음수 $a$에 대해서도 반드시 하나의 교점이 생깁니다. 예를 들어 $\sqrt[3]{-8} = -2$가 성립하는 이유입니다. 반면 $n$이 짝수일 때 함수 $y = x^n$은 $y$축에 대하여 대칭인 포물선 형태를 띠며 최솟값이 $0$입니다. 따라서 $a < 0$인 수평선과는 만나지 못해 실근이 존재하지 않으며, $a > 0$인 경우에만 두 개의 교점이 생기지만 그중 양수인 값을 주 $n$제곱근으로 정의합니다.

### 기본 성질
- $n$이 홀수이면 $\sqrt[n]{-a} = -\sqrt[n]{a}$가 성립합니다.
- $n$이 짝수이면 $\sqrt[n]{a}$는 $a \geq 0$일 때만 실수로 정의됩니다.
- $\sqrt[4]{-16}$과 같이 $n$이 짝수이면서 $a$가 음수인 경우는 실수 범위에서 정의되지 않습니다.

## 학습 체크
- $n$이 홀수일 때 $a$가 음수라면, $n$제곱근은 양수인가요, 음수인가요?
- $n$이 짝수일 때 $a=0$이면 실근은 몇 개 존재하나요?
- $\sqrt[6]{64}$의 실수인 $n$제곱근은 몇 개인가요?

## 관련 개념
- **지수법칙**: $n$제곱근을 지수 형태인 $\tfrac{1}{n}$제곱으로 나타내어 계산할 수 있습니다.
- **함수의 그래프**: $x^n$의 그래프 개형을 통해 방정식의 실근 개수를 시각적으로 확인할 수 있습니다.
- **삼각함수**: 복소수 범위로 확장될 경우, 드 무아브르 정리를 통해 삼각함수와 연계된 $n$개의 복소수 근을 구할 수 있습니다.
