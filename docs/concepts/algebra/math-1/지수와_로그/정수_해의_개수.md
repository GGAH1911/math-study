# 정수 해의 개수

## 정확한 진술

주어진 방정식이나 부등식을 만족하는 **정수 값** $x$가 총 몇 개 존재하는지를 세는 것입니다. 예를 들어 부등식 $a < x \leq b$를 만족하는 정수 $x$의 개수는 $\lfloor b \rfloor - \lfloor a \rfloor$개입니다. 방정식 $f(x) = g(x)$의 정수 해의 개수는 함수 $y = f(x)$와 $y = g(x)$의 그래프가 만나는 점 중 정수 좌표를 가지는 점의 개수입니다.

## 직관/기하적 의미

수직선 위에 점들을 표시해 보면 직관적으로 이해됩니다. 예를 들어 $-1 < x < 3$을 만족하는 정수는 수직선 상에서 $-1$과 $3$ 사이에 있는 정수 $0, 1, 2$이므로 **3개**입니다. 

함수의 관점에서는 $y = 3^x$와 $y = 27$의 교점에서 $x$좌표가 정수인 경우를 찾습니다. $3^x = 27 = 3^3$이므로 $x = 3$ (정수 해 **1개**). 

부등식 $\log_2 x > 3$의 경우, 이는 $x > 8$과 같으므로 정수 해는 $9, 10, 11, \ldots$ 처럼 무한히 많지만, 보통 **범위가 제한되어** 개수를 세게 됩니다. 예를 들어 $3 < \log_2 x \leq 5$라면 $8 < x \leq 32$이므로 정수 해는 $9, 10, \ldots, 32$로 **24개**입니다.

## 한 줄 예

$2 \leq x < 7$을 만족하는 정수 해: $2, 3, 4, 5, 6$ → **5개** (또는 $7 - 2 = 5$)

검증: `[x for x in range(2, 7)]` → 5개
