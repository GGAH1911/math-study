# 지수 확장

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)
## 요약
자연수 → 정수 → 유리수 → 실수 지수

## 본문

지수의 확장은 자연수 지수에서 정수, 유리수, 실수 지수로 단계적으로 범위를 넓혀가는 과정입니다. 각 단계에서 **지수법칙**이 일관되게 성립하도록 정의를 확장합니다.

- **자연수 지수**: $a^n = a \times a \times \cdots \times a$ (n번 곱함)
- **0 지수**: $a^0 = 1$ (단, $a \neq 0$)
- **음의 정수 지수**: $a^{-n} = \frac{1}{a^n}$ (단, $a \neq 0$)
- **유리수 지수**: $a^{\frac{p}{q}} = \sqrt[q]{a^p}$ (단, $a > 0$, $p, q$는 정수, $q > 0$)
- **실수 지수**: 수렴하는 유리수 수열의 극한으로 정의 ($a^x$, $a > 0$)

### 직관과 연속성

지수 확장의 핵심은 **지수법칙을 보존**하면서도 **"빈틈"을 채우는 것**입니다. 예를 들어 $a^m \times a^n = a^{m+n}$이 음의 정수나 분수 지수에서도 성립하려면, 0 지수는 1이어야 하고 음의 지수는 역수로 정의되어야 합니다.

유리수 지수 $a^{\frac{1}{2}}$는 "$a$를 제곱하면 원래 수가 되는 수," 즉 $\sqrt{a}$입니다. 왜냐하면 $(a^{\frac{1}{2}})^2 = a^{1} = a$이기 때문입니다. 실수 지수는 유리수 근사를 통해 연속적으로 정의되므로, $a^x$ 함수는 **어떤 실수 값에서도 부드럽게** 정의됩니다 ($a > 0$일 때).

### 한 줄 예

$2^3 = 8$, $2^0 = 1$, $2^{-2} = \frac{1}{4}$, $2^{\frac{1}{2}} = \sqrt{2} \approx 1.414$, $2^{\pi} \approx 8.825$ (모두 $2^m \times 2^n = 2^{m+n}$을 만족)

**검산**: `sympy.simplify(2**1.5 - 2**1 * 2**0.5)` → `0`
