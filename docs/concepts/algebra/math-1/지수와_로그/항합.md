# 항합

안녕하세요. 요청을 정확히 파악하기 위해 확인이 필요합니다.

**"항합"이 정확히 어떤 개념인지 확인해 주세요:**

1. **등차수열의 합** 또는 **등비수열의 합**을 다루는 건가요?
2. **급수(series)**의 합을 정의하는 건가요?
3. 아니면 **시그마 기호($\sum$)로 표현되는 합**의 개념을 다루는 건가요?
4. 혹은 다른 특정 수학 개념인가요?

선수 개념이 "지수와 로그"라는 점으로 미루어 등비수열/급수와 관련있어 보이는데, 정확한 의도를 알려주시면 교육과정에 맞는 정확한 정의 페이지를 작성하겠습니다.

또한 **페이지 요약(1줄)**이 비어있는데, 이것도 작성해 주시면 방향을 잡는 데 도움이 될 것 같습니다.
