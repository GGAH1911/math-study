# 밑변환 공식

> **정리** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\log_a b = \tfrac{\log_c b}{\log_c a}$의 형태로 임의의 로그를 다른 밑을 가진 로그의 비로 변환할 수 있다.

## 본문
임의의 양수 $a, b, c$ (단, $a \neq 1, c \neq 1$)에 대하여 $\log_a b = \tfrac{\log_c b}{\log_c a}$가 성립하며, 이를 밑변환 공식이라 한다. 이 공식은 밑이 $a$인 로그를 밑이 $c$인 로그의 비율로 나타내어 계산을 용이하게 만든다. 특히 $c$를 $10$으로 두어 상용로그로 변환하거나, $e$로 두어 자연로그로 변환함으로써 계산기나 로그표를 활용해 값을 구할 수 있게 해준다.

### 증명 스케치
$\log_a b = x$라고 가정하면 로그의 정의에 의해 $a^x = b$이다. 이 식의 양변에 밑이 $c$인 로그를 취하면 $\log_c(a^x) = \log_c b$가 된다. 로그의 성질에 의해 $x \log_c a = \log_c b$로 정리할 수 있으며, 양변을 $\log_c a$로 나누면(단, $\log_c a \neq 0$) $x = \tfrac{\log_c b}{\log_c a}$를 얻는다. 따라서 $\log_a b = \tfrac{\log_c b}{\log_c a}$임이 증명된다.

### 의의와 응용
계산기나 로그표에는 주로 밑이 $10$인 상용로그나 밑이 $e$인 자연로그만 제시되어 있으므로, 임의의 밑을 가진 로그를 계산할 때 이 공식은 필수적이다. 예를 들어 $\log_2 8$을 구하기 위해 $\tfrac{\log_{10} 8}{\log_{10} 2}$로 변환하여 계산할 수 있다. 또한 로그 방정식이나 부등식을 풀 때 서로 다른 밑을 가진 로그들을 하나의 밑으로 통일하여 문제를 해결하는 데 핵심적인 도구로 사용된다.

## 관련 개념
- **지수와 로그**: 로그의 정의인 지수 관계를 바탕으로 하며, 밑변환 공식은 지수 법칙의 확장된 형태로 로그 계산의 범위를 넓혀준다.
