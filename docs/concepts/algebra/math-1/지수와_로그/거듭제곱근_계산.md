# 거듭제곱근 계산

> **예제** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
거듭제곱근 $\sqrt[n]{a}$는 $n$제곱하여 $a$가 되는 수 중 음이 아닌 실수를 의미하며, 지수 법칙을 통해 $a^{1/n}$으로 나타낼 수 있습니다.

## 본문
다음을 계산하고, 지수 형태로 나타내시오.
$$\sqrt[3]{8}$$

### 단계별 풀이
**1단계: 거듭제곱근의 정의 확인**  
$\sqrt[3]{8}$은 8의 세제곱근을 의미하며, 세제곱했을 때 8이 되는 양수 $x$를 찾는 과정입니다. 즉, $x^3 = 8$을 만족하는 $x$를 구하는 것입니다.

**2단계: 어떤 수의 세제곱이 8인지 생각하기**  
$2^3 = 2 \times 2 \times 2 = 8$이므로, $\sqrt[3]{8} = 2$임을 알 수 있습니다.

**3단계: 지수 형태로 표현하기**  
거듭제곱근과 지수의 관계인 $\sqrt[n]{a} = a^{1/n}$을 적용하면 다음과 같습니다.
$$\sqrt[3]{8} = 8^{1/3} = (2^3)^{1/3} = 2^{3 \times 1/3} = 2^1 = 2$$

**4단계: 검산**  
$2^3 = 8$이므로 계산 결과가 올바른지 확인할 수 있습니다.

### 답과 변형
$$\sqrt[3]{8} = 2, \quad 8^{1/3} = 2$$

**다른 거듭제곱근의 예시**  
- $\sqrt[2]{16} = \sqrt{16} = 4$ (제곱근은 보통 $\sqrt{}$로 표기합니다.)
- $\sqrt[4]{16} = 2$ ($2^4 = 16$)
- $\sqrt[5]{32} = 2$ ($2^5 = 32$)

**주의할 점**  
짝수 제곱근은 음수를 포함하지 않으며, 고등학교 과정에서 $\sqrt[n]{a}$는 항상 음이 아닌 실근을 의미합니다. 홀수 제곱근은 음수도 정의될 수 있으나, 일반적인 계산에서는 주 값인 양수를 사용합니다.
