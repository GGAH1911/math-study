# 로그의 성질

> **정리** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
로그의 성질을 이용하면 곱셈을 덧셈으로, 나눗셈을 뺄셈으로 변환하여 복잡한 계산과 지수 방정식을 효율적으로 해결할 수 있습니다.

## 본문
$a > 0, a \neq 1$이고 $x > 0, y > 0$일 때, 다음의 성질이 성립합니다. 첫째, 곱의 로그 성질에 의해 $\log_a(xy) = \log_a x + \log_a y$입니다. 둘째, 나눗셈의 로그 성질에 의해 $\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y$입니다. 셋째, 거듭제곱의 로그 성질에 의해 $\log_a(x^n) = n\log_a x$가 성립하며, 이때 $n$은 실수입니다. 이러한 성질들은 밑이 $10$인 상용로그나 밑이 $e$인 자연로그를 포함한 모든 로그에서 동일하게 적용됩니다.

### 증명 스케치
로그의 정의인 $\log_a x = p \Leftrightarrow a^p = x$를 활용합니다. $\log_a x = p, \log_a y = q$라고 가정하면 $a^p = x, a^q = y$가 됩니다. 이때 두 수의 곱은 $xy = a^p \cdot a^q = a^{p+q}$가 되며, 양변에 로그를 취하면 $\log_a(xy) = p + q = \log_a x + \log_a y$를 얻을 수 있습니다. 나눗셈의 성질은 지수법칙 $\frac{a^p}{a^q} = a^{p-q}$를 통해, 거듭제곱의 성질은 $(a^p)^n = a^{pn}$을 통해 동일한 방식으로 유도됩니다.

### 의의와 응용
로그의 성질은 큰 수의 곱셈을 덧셈으로, 나눗셈을 뺄셈으로 단순화하여 계산의 복잡도를 낮춰줍니다. 이는 $3^x = 50$과 같은 지수 방정식을 풀 때 양변에 로그를 취해 $x = \frac{\log 50}{\log 3}$과 같이 해를 구하는 데 필수적입니다. 또한 pH, 데시벨, 지진의 규모와 같이 지수적으로 변화하는 물리량을 다루는 과학 및 공학 분야에서 매우 중요하게 사용됩니다.

예를 들어 $\log 12$를 계산할 때 $\log(4 \times 3) = \log 4 + \log 3 = 2\log 2 + \log 3$과 같이 분해하여 계산할 수 있습니다.
