# 거듭제곱의 계산

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
거듭제곱은 밑을 지수만큼 반복하여 곱하는 연산으로, 지수의 범위를 정수에서 유리수까지 확장하여 지수법칙을 일관되게 적용할 수 있도록 정의합니다.

## 본문
거듭제곱 $a^n$의 계산은 밑 $a$를 지수 $n$번 곱하는 연산입니다. 여기서 $a$는 밑(base), $n$은 지수(exponent)라 부릅니다. 지수가 양의 정수일 때 $a^n = \underbrace{a \times a \times \cdots \times a}_{n \text{개}}$로 정의하며, 지수가 $0$일 때는 $a^0 = 1$ (단, $a \neq 0$)입니다. 지수가 음의 정수 $-n$일 때는 $a^{-n} = \frac{1}{a^n}$으로 정의하며, 유리수 지수 $\frac{p}{q}$에 대해서는 $a^{\frac{p}{q}} = \sqrt[q]{a^p}$로 정의합니다.

### 직관과 기하적 의미
거듭제곱은 반복되는 곱셈을 간결하게 나타내는 도구입니다. 예를 들어 $2^5 = 32$는 $2$를 다섯 번 곱한다는 의미이며, 지수가 커질수록 값은 기하급수적으로 빠르게 증가합니다. 음수 지수는 역수의 개념을 도입하여 확장한 것이고, 분수 지수는 제곱근의 개념을 거듭제곱의 체계 안으로 통합한 표현입니다. 이러한 일관된 정의 덕분에 모든 실수 범위에서 지수법칙이 성립하게 됩니다.

### 기본 성질
- 지수법칙: $a^m \times a^n = a^{m+n}$
- 음수 지수와 역수: $a^{-n} = \frac{1}{a^n}$
- 분수 지수와 거듭제곱근: $a^{\frac{p}{q}} = \sqrt[q]{a^p}$

## 학습 체크
- 지수가 $0$일 때 결과가 $1$이 되는 이유를 밑이 $0$인 경우와 비교하여 설명할 수 있는가?
- 음수 지수와 분수 지수의 정의가 기존의 정수 지수 정의와 어떻게 일관성을 유지하는가?
- 거듭제곱의 계산 결과가 지수의 변화에 따라 얼마나 급격히 변하는지 이해하고 있는가?

## 관련 개념
- **지수와 로그**: 거듭제곱의 역연산 관계를 통해 로그의 정의를 도출하며, 지수와 로그는 서로 역함수 관계를 가집니다.
