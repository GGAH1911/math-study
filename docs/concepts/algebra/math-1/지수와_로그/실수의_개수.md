### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 **실근의 개수**는 판별식 $D = b^2 - 4ac$의 부호로 결정됩니다.

$$D > 0 \Rightarrow \text{서로 다른 실근 2개}$$
$$D = 0 \Rightarrow \text{중근 1개}$$
$$D < 0 \Rightarrow \text{실근 0개}$$

근의 공식 $x = \frac{-b \pm \sqrt{D}}{2a}$에서 루트 안의 판별식이 근의 개수와 성질을 결정합니다.

### 직관과 기하적 의미

이차방정식 $ax^2 + bx + c = 0$의 해는 이차함수 $y = ax^2 + bx + c$의 그래프가 x축과 만나는 점의 x좌표입니다. 따라서 **실근의 개수 = 포물선과 x축의 교점 개수**입니다.

포물선이 x축을 두 점에서 가로지르면 실근 2개, 한 점에서만 접하면 중근 1개, 만나지 않으면 실근이 없습니다. $a > 0$일 때 포물선은 위로, $a < 0$일 때 아래로 볼록합니다. 판별식은 이 기하적 상황을 대수적으로 판정하는 도구입니다.

### 한 줄 예

방정식 $x^2 - 5x + 6 = 0$에서 $D = 25 - 24 = 1 > 0$이므로 실근 2개입니다. 실제로 $(x - 2)(x - 3) = 0$이므로 $x = 2, 3$입니다. (`sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)
