# 로그 부등식

## 정확한 진술

로그 부등식이란 미지수를 로그의 진수(argument)나 밑(base)으로 포함하는 부등식입니다. 가장 기본적인 형태는 $\log_a x > b$ 또는 $\log_a x < b$ (단, $a > 0, a \neq 1, x > 0$)이며, 일반적으로는 $\log_a f(x) \gtrless \log_a g(x)$ 형태로도 나타납니다. 로그 부등식을 풀 때는 **로그 함수의 증감성**을 이용하여 정의역 조건($f(x) > 0$, $g(x) > 0$ 등)을 반드시 확인한 후 진수의 부등식으로 변환합니다.

## 직관과 기하적 의미

로그 함수 $y = \log_a x$는 밑 $a$의 값에 따라 증감성이 결정됩니다. $a > 1$일 때는 **증가함수**이므로 $\log_a x_1 > \log_a x_2 \Leftrightarrow x_1 > x_2$이지만, $0 < a < 1$일 때는 **감소함수**이므로 $\log_a x_1 > \log_a x_2 \Leftrightarrow x_1 < x_2$가 됩니다. 즉, 부등호의 방향이 **밑의 크기에 따라 반대**가 될 수 있다는 점이 핵심입니다. 이것이 로그 부등식을 풀 때 경우를 나누어야 하는 이유입니다.

## 기본 예시

$\log_2 x > 3$은 밑이 $2 > 1$이므로 증가함수이고, 따라서 $x > 2^3 = 8$입니다(정의역: $x > 0$). 반면 $\log_{1/2} x > 1$은 밑이 $1/2 < 1$이므로 감소함수이고, $x < (1/2)^1 = 1/2$입니다. 정의역 $x > 0$과 함께 고려하면 $0 < x < 1/2$입니다.

**검산:** `sympy.solve(sympy.log(x, 2) > 3, x)` → $x > 8$ ✓
