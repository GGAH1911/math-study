# 로그의 기본 성질

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 정확한 진술

$a > 0, a \neq 1$인 밑 $a$에 대해 다음이 성립합니다:

- $\log_a 1 = 0$
- $\log_a a = 1$
- $\log_a(xy) = \log_a x + \log_a y$ (곱의 로그)
- $\log_a\frac{x}{y} = \log_a x - \log_a y$ (몫의 로그)
- $\log_a x^n = n\log_a x$ (거듭제곱의 로그)

## 직관: 지수법칙에서 나오는 성질

로그는 지수의 역함수입니다. 지수법칙 $a^p \cdot a^q = a^{p+q}$에서 양변에 $\log_a$를 취하면, 곱셈이 덧셈으로 변합니다: $\log_a(xy) = \log_a x + \log_a y$. 

"$y$를 만들려면 $a$를 몇 번 곱해야 하나"는 지수로, "몇 번 곱해야 하는가"는 로그로 나타냅니다. 처음 두 성질 $\log_a 1 = 0$과 $\log_a a = 1$은 로그의 기본: $a^0=1$, $a^1=a$입니다.

## 구체적 예

$\log_2 8 = 3$ (∵ $2^3=8$), $\log_2 4 = 2$ (∵ $2^2=4$)

곱의 성질을 확인하면:
$$\log_2(4 \times 8) = \log_2 4 + \log_2 8 = 2 + 3 = 5$$

검산: $\log_2 32 = 5$ (∵ $2^5=32$) ✓

거듭제곱 성질: $\log_2 4^3 = 3\log_2 4 = 3 \times 2 = 6$, 검산 $\log_2 64 = 6$ ✓
