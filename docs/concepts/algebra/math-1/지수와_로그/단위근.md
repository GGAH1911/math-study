# 단위근

$n$제곱을 했을 때 $1$이 되는 수를 가리키는 개념입니다. 수학1 지수와 로그 단원에서 거듭제곱근의 성질을 다룰 때 등장합니다.

## 정의

$2$ 이상의 자연수 $n$에 대하여 $x^n = 1$을 만족시키는 $x$를 **$n$제곱 단위근**이라 합니다. 실수 범위에서 단위근은 다음과 같이 결정됩니다.
- $n$이 홀수이면 실수 단위근은 $x = 1$ 하나입니다.
- $n$이 짝수이면 실수 단위근은 $x = 1$과 $x = -1$ 두 개입니다.

복소수 범위에서는 단위근이 정확히 $n$개 존재합니다.

## 예시

$x^3 = 1$의 실수해는 $x = 1$ 하나입니다.

반면 $x^4 = 1$의 실수해는 $x = 1$과 $x = -1$ 두 개입니다. $1^4 = 1$, $(-1)^4 = 1$로 확인됩니다.
