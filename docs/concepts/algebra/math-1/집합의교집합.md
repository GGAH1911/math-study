### 정확한 진술

두 집합 $A$, $B$에 대해 **교집합**(intersection)은 $A$와 $B$에 **동시에 속하는 모든 원소**로 이루어진 집합입니다. 기호로는 $A \cap B$로 나타내며, 다음과 같이 정의합니다.

$$A \cap B = \{x \mid x \in A \text{ 그리고 } x \in B\}$$

즉, $x \in A \cap B$ ⟺ ($x \in A$) ∧ ($x \in B$) 입니다.

### 직관과 기하적 의미

교집합은 두 집합의 "**겹치는 부분**"입니다. 벤 다이어그램으로 그려보면, 두 원의 교집합은 원들이 만나는 중앙의 영역에 해당합니다. 

숫자로 생각하면:
- 집합 A: {1, 2, 3, 4}
- 집합 B: {3, 4, 5, 6}
- 교집합 $A \cap B$: {3, 4} ← **두 집합 모두에 있는 원소만**

교집합의 크기는 항상 원래 집합들보다 작거나 같습니다. 특히 두 집합이 공통 원소가 없으면 $A \cap B = \emptyset$ (공집합)입니다.

### 한 줄 예

집합 $A = \{x \mid x \text{는 6의 약수}\}$와 $B = \{x \mid x \text{는 9의 약수}\}$일 때, $A \cap B = \{1, 3\}$입니다.

**검산:** $A = \{1, 2, 3, 6\}$, $B = \{1, 3, 9\}$이므로 공통 원소는 1과 3입니다. (`set([1, 2, 3, 6]) & set([1, 3, 9])` → {1, 3})

### 주의할 점

교집합과 합집합($\cup$)을 헷갈리지 마세요. 합집합은 적어도 한 집합에 속하는 **모든** 원소이고, 교집합은 **모두** 속하는 원소입니다. 위 예에서 $A \cup B = \{1, 2, 3, 6, 9\}$인 반면, $A \cap B = \{1, 3\}$입니다.
