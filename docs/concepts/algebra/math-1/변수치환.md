### 정확한 진술

변수치환(substitution)은 주어진 방정식이나 식에서 새로운 변수를 도입하여 원래 식을 더 간단한 형태로 변환하는 기법입니다. 예를 들어 $t = 2^x$로 놓으면 방정식 $2^{2x} + 2^x - 6 = 0$은 $t^2 + t - 6 = 0$으로 단순화됩니다. 일반적으로 기존 변수를 $y = f(x)$ 형태로 새 변수 $t$나 $u$ 등으로 바꾸어 복잡도를 낮추는 것입니다.

### 직관과 목적

변수치환의 핵심은 **문제의 본질 구조를 드러내기** 입니다. 지수 방정식 $4^x + 8^x = 12$처럼 다양한 지수가 섞여 있으면 풀기 어렵지만, $t = 2^x$로 놓으면 $t^2 + t^3 = 12$로 변환되어 대수적 관점에서 접근할 수 있습니다. 치환이 성공하면 고차 또는 초월 방정식이 저차 대수 방정식으로 축소되므로, 같은 기법(인수분해, 근의 공식 등)으로 풀 수 있습니다. 또한 정적분 $\int \frac{1}{x \ln x} dx$에서 $t = \ln x$로 놓으면 $\int \frac{1}{t} dt = \ln|t| + C = \ln|\ln x| + C$처럼 적분이 가능해집니다.

### 풀이 단계와 한 줄 예

**예:** $\log_2 x + \log_2(2x) = 3$을 풀어봅시다. $t = \log_2 x$로 놓으면 $\log_2(2x) = \log_2 2 + \log_2 x = 1 + t$이므로 방정식은 $t + (1+t) = 3$, 즉 $2t = 2$가 되어 $t = 1$입니다. 따라서 $\log_2 x = 1$에서 $x = 2$를 얻습니다.

**주의:** 치환한 새 변수의 범위를 확인해야 합니다. $t = 2^x$로 놓으면 $t > 0$이므로, 방정식 $t^2 + t - 6 = 0$의 해 중 $t = -3$은 원래 방정식의 해가 될 수 없습니다. 같은 방식으로 $t = \log_2 x$일 때는 $t$는 모든 실수값을 가질 수 있으므로 추가 제약이 없습니다.
