# 공통인수 묶기

> **예제** · 중3 · 단원: [다항식의 곱셈과 인수분해](/concepts/인수분해)

## 요약
$x^2(x-1)+x(x-1)$

## 본문 (학습 시 채워짐)

### 문제

다음 식을 인수분해하시오.
$$x^2(x-1)+x(x-1)$$

### 단계별 풀이

먼저 두 항에 공통으로 나타나는 부분을 찾습니다. $x^2(x-1)$과 $x(x-1)$을 보면, 둘 다 $(x-1)$을 인수로 가지고 있습니다. 이것이 **공통인수**입니다.

공통인수 $(x-1)$로 양쪽 항을 나누면:
- $x^2(x-1) \div (x-1) = x^2$
- $x(x-1) \div (x-1) = x$

따라서 공통인수를 괄호 밖으로 빼내면:
$$(x-1)(x^2 + x)$$

이제 $x^2 + x$ 부분에서 다시 공통인수 $x$를 찾을 수 있습니다:
$$x^2 + x = x(x+1)$$

이를 대입하면 완전히 인수분해됩니다.

### 답

$$x^2(x-1)+x(x-1) = (x-1) \cdot x(x+1) = x(x-1)(x+1)$$

(또는 순서를 바꾼 $(x-1) \cdot x \cdot (x+1)$도 같은 답입니다)

### 변형과 주의

**확인하기**: $(x-1) \cdot x(x+1)$을 전개하면 원래 식으로 돌아옵니다. 전개: $x(x+1)(x-1) = x(x^2-1) = x^3 - x = x^2(x-1) + x(x-1)$ ✓

**중요**: 공통인수를 찾을 때는 **각 항의 모든 인수를 살펴**야 합니다. 계수뿐 아니라 문자와 괄호도 포함됩니다. 이 문제에서 $(x-1)$처럼 괄호 전체가 공통인수가 될 수 있다는 점을 꼭 기억하세요.

**sympy 검증**: `sympy.factor(x**2*(x-1) + x*(x-1))` → `x(x-1)(x+1)` ✓
