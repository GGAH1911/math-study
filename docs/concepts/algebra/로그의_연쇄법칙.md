### 정확한 진술

로그의 연쇄법칙(밑의 변환 공식)은 임의의 밑을 가진 로그를 다른 밑의 로그로 표현할 수 있다는 정리입니다. $a, b, c > 0$이고 $a \neq 1$, $c \neq 1$일 때:

$$\log_a b = \frac{\log_c b}{\log_c a}$$

특히 자연로그나 상용로그(밑이 10)를 이용하면:

$$\log_a b = \frac{\ln b}{\ln a} = \frac{\log b}{\log a}$$

### 직관/기하적 의미

계산기나 교과서에는 보통 밑이 10인 상용로그나 자연로그만 있습니다. 하지만 문제에서는 밑이 2, 3, 7 같은 임의의 수인 로그를 계산해야 할 때가 있습니다. 이때 "연쇄"처럼 같은 중간 밑(예: 10 또는 $e$)으로 변환하면 우리가 아는 로그로 만들 수 있다는 의미입니다.

**역함수 해석**: $\log_a b = x$는 "$a^x = b$를 만족하는 $x$"라는 뜻입니다. 이 관계를 지수 형태로 바꾸고 양변에 $\log_c$를 취하면 이 공식이 자연스럽게 나옵니다.

$$a^x = b \Rightarrow \log_c(a^x) = \log_c b \Rightarrow x \log_c a = \log_c b \Rightarrow x = \frac{\log_c b}{\log_c a}$$

### 한 줄 예

$\log_2 8$을 자연로그로 변환하면 $\log_2 8 = \frac{\ln 8}{\ln 2} = \frac{\ln 2^3}{\ln 2} = \frac{3\ln 2}{\ln 2} = 3$ ✓

더 복잡한 예: $\log_3 5 = \frac{\log 5}{\log 3} \approx \frac{0.699}{0.477} \approx 1.465$ (상용로그 사용)

`sympy.log(5, 3)` 또는 `sympy.log(5) / sympy.log(3)`로 검산 가능합니다.
