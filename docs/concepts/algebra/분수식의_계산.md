### 정확한 진술

분수식이란 분자와 분모가 모두 다항식인 식 $\frac{P(x)}{Q(x)}$ (단, $Q(x) \neq 0$)을 말합니다. 분수식의 계산은 다음 규칙을 따릅니다.

**덧셈과 뺄셈**: 분모가 같을 때는 분자만 더하거나 뺍니다.
$$\frac{A}{B} \pm \frac{C}{B} = \frac{A \pm C}{B}$$

분모가 다를 때는 최소공배수(통분)로 만들어 계산합니다.
$$\frac{A}{B} + \frac{C}{D} = \frac{AD + BC}{BD}$$

**곱셈과 나눗셈**: 분자끼리, 분모끼리 곱합니다.
$$\frac{A}{B} \times \frac{C}{D} = \frac{AC}{BD}$$

나눗셈은 두 번째 분수를 뒤집어 곱합니다.
$$\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \times \frac{D}{C} = \frac{AD}{BC}$$

### 직관적 의미

분수식의 계산은 **분수(숫자)의 계산 규칙과 정확히 같습니다**. 다항식을 하나의 수로 생각하면, 분수식은 '수를 변수로 표현한 분수'일 뿐입니다. 예를 들어 $\frac{3}{5} + \frac{2}{5} = \frac{5}{5}$이듯이, $\frac{x}{x+1} + \frac{1}{x+1} = \frac{x+1}{x+1}$도 같은 원리입니다. 통분할 때도 공통분모를 찾는 방식이 정수의 덧셈과 본질적으로 같습니다.

### 한 줄 예

$\frac{x+2}{x-1} + \frac{2x-1}{x-1} = \frac{3x+1}{x-1}$ (분모가 같으므로 분자끼리 더함)

$\frac{2}{x} - \frac{1}{x+1} = \frac{2(x+1) - x}{x(x+1)} = \frac{x+2}{x(x+1)}$ (공통분모 $x(x+1)$로 통분)

$\frac{x^2-1}{x+2} \times \frac{x+2}{x+1} = \frac{(x^2-1)(x+2)}{(x+2)(x+1)} = \frac{x^2-1}{x+1} = \frac{(x-1)(x+1)}{x+1} = x-1$ (인수분해 후 약분 가능)

(`sympy.simplify((x**2-1)/(x+2) * (x+2)/(x+1))` → $x - 1$)
