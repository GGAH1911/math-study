### 정확한 진술

분수 $\frac{a}{b}$의 분자와 분모를 같은 수(0이 아닌)로 나누어서 더 간단한 형태로 나타내는 것을 **약분**이라고 합니다. 분자 $a$와 분모 $b$의 공약수 중 1이 아닌 것이 있을 때, 이를 이용해 약분할 수 있습니다.

$$\frac{a}{b} = \frac{a \div d}{b \div d}$$

여기서 $d$는 $\gcd(a, b)$의 약수입니다. 분자와 분모의 최대공약수로 나누면 더 이상 약분할 수 없는 **기약분수(irreducible fraction)** 형태가 됩니다.

### 직관과 의미

약분은 "같은 크기를 더 간단하게 표현하는 것"입니다. 예를 들어 $\frac{6}{8}$은 전체를 8등분했을 때 6개를 의미하지만, 이를 $\frac{3}{4}$로 약분하면 전체를 4등분했을 때 3개를 의미합니다. 크기는 같지만 더 이해하기 쉬운 형태입니다.

수학에서 약분의 중요성:
- **계산 편리성**: 더 작은 수로 계산하므로 실수를 줄임
- **표준 형태**: 기약분수로 표현하면 여러 형태를 하나로 통일 가능
- **대수 정리**: 분수식의 인수를 약분할 때 정의역 변화에 주의해야 함

### 예시

$$\frac{12}{18} = \frac{12 \div 6}{18 \div 6} = \frac{2}{3}$$

$\gcd(12, 18) = 6$이므로 최대공약수로 나누면 기약분수가 됩니다.

분수식의 경우: $\frac{x^2 - 4}{x + 2} = \frac{(x-2)(x+2)}{x+2} = x - 2$ (단, $x \neq -2$)

약분 후 분모가 0이 되는 경우를 제외해야 한다는 점을 주의해야 합니다.

**검산**: `from math import gcd; a, b = 12, 18; d = gcd(a, b); print(f"{a}/{b} = {a//d}/{b//d}")` → $\frac{12}{18} = \frac{2}{3}$
