### 정확한 진술

다중근(重根, multiple root)은 다항방정식이 같은 값을 근으로 가질 때, 그 근의 **중복된 횟수**를 나타냅니다. 더 정확히, 다항식 $P(x)$를 인수분해했을 때 $(x-a)^n$ 형태의 인수가 나타나면, $x=a$는 **$n$중근(n-fold root)**입니다.

예를 들어:
- $(x-2)^3(x+1) = 0$에서 $x=2$는 3중근, $x=-1$은 단순근(1중근)
- $x^2 - 4x + 4 = 0$은 $(x-2)^2 = 0$이므로 $x=2$는 2중근

다항식의 **차수**와 **근의 개수**(중복도 포함)는 항상 같습니다. 3차 방정식 $x^3 - x^2 + ax + b = 0$이라면, 근을 중복도까지 세었을 때 반드시 3개입니다.

### 직관/기하적 의미

$y = P(x)$ 그래프에서 단순근은 $x$축과 **한 번 만나거나 지나갑니다**. 반면 짝수 중복도의 근(2중근, 4중근 등)은 $x$축에 **접합니다**—$x$축을 뚫고 지나가지 않습니다. 홀수 중복도의 근(3중근, 5중근 등)은 $x$축과 만나면서 **접선 성질을 유지합니다**.

인수분해 관점에서, $(x-2)^2$는 "곱하기 2번"을 의미하므로, 이 인수가 클수록 그 근 근처에서 함숫값은 0에 가깝게 유지됩니다. 이것이 중근의 **기하적 의미**입니다.

### 한 줄 예

방정식 $x^2 - 6x + 9 = 0$은 $(x-3)^2 = 0$이므로 $x=3$은 **2중근**입니다.

검증 (sympy): `sympy.solve(x**2 - 6*x + 9, x)` → `[3, 3]` (근 3이 두 번 나타남)
