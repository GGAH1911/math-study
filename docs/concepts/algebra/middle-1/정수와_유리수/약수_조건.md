# 약수 조건

## 정확한 진술

정수 $a$, $b$에 대하여, **$b = ka$를 만족하는 정수 $k$가 존재**할 때, "$a$는 $b$를 나눈다" 또는 "$a$는 $b$의 약수"라고 하며, $a \mid b$로 표기합니다.

예를 들어 $6 = 3 \times 2$이므로 $3 \mid 6$입니다.

## 직관과 기하적 의미

약수 조건은 **"정수로 나누어떨어진다"**는 뜻입니다. $a \mid b$라는 것은 $b$를 $a$로 나눴을 때 나머지가 정확히 $0$이라는 의미입니다.

일상적으로는 "같은 크기로 나누기" 상황입니다. 12개의 사탕을 4명이 나눌 때 남는 것이 없으면, 4는 12의 약수입니다. 반대로 5명이 나누면 2개가 남으므로, 5는 12의 약수가 아닙니다.

## 구체적 예

$3 \mid 12$입니다. 왜냐하면 $12 = 3 \times 4$이고, $k = 4$ (정수)이기 때문입니다.

대조적으로, $5 \nmid 12$입니다. 12를 5로 나누면 $12 = 5 \times 2 + 2$로 나머지가 2가 남으므로, 5는 12의 약수가 아닙니다.

12의 모든 약수를 구하면: `sympy.divisors(12)` → $\{1, 2, 3, 4, 6, 12\}$
