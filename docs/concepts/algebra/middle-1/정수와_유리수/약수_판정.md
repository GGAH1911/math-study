# 약수 판정

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$가 $b$의 약수라는 것은 $b$를 $a$로 나누었을 때 나머지가 $0$임을 의미합니다.

## 본문
정수 $a$가 $0$이 아닌 정수 $b$의 약수라는 것은, $b = a \times k$를 만족하는 정수 $k$가 존재한다는 것을 의미합니다. 이를 기호로 $a \mid b$로 표기하며, "$a$가 $b$를 나눈다" 또는 "$b$는 $a$의 배수"라고 읽습니다. 반대로 $a$가 $b$의 약수가 아니면 $a \nmid b$로 표기합니다.

### 직관과 기하적 의미
약수 판정은 나눗셈을 했을 때 나머지가 $0$인지 확인하는 과정입니다. 예를 들어 $15$개의 사탕을 $3$명의 친구에게 나누어 줄 때, 남는 사탕 없이 똑같이 $5$개씩 나누어 줄 수 있다면 $3$은 $15$의 약수입니다. 이를 나눗셈 정리로 표현하면, 정수 $b$와 $0$이 아닌 정수 $a$에 대하여 $b = a \times q + r$ ($0 \le r < |a|$)일 때, 나머지 $r$이 $0$이면 $a \mid b$가 성립합니다.

### 기본 성질
약수 관계는 다음과 같은 수학적 성질을 가집니다.
- $a \mid b$이고 $b \mid c$이면 $a \mid c$가 성립합니다(전이성).
- $a \mid b$이고 $a \mid c$이면 $a \mid (b + c)$와 $a \mid (b - c)$가 성립합니다.
- $a \mid b$이면 모든 정수 $m$에 대하여 $a \mid (m \times b)$가 성립합니다.

## 학습 체크
- $12$를 $5$로 나누었을 때 나머지가 $2$라면, $5$은 $12$의 약수인가?
- $a \mid b$이고 $b \mid c$일 때, $a$가 $c$의 약수임을 증명할 수 있는가?

## 관련 개념
- **정수와 유리수**: 약수와 배수의 개념은 정수의 구조를 이해하고 유리수의 연산을 정의하는 기초가 됩니다.
- **최대공약수**: 두 개 이상의 정수가 공통으로 가지는 약수 중 가장 큰 값을 찾는 과정에서 약수 판정 원리가 사용됩니다.
- **최소공배수**: 두 개 이상의 정수가 공통으로 가지는 배수 중 가장 작은 값을 찾는 개념으로, 약수와 배수의 관계를 통해 이해할 수 있습니다.
