# 수직선

실수를 한 줄의 직선 위의 점에 대응시켜 시각화한 것입니다. 고1 방정식과 부등식 단원에서 해집합을 그림으로 나타낼 때 사용합니다.

## 정의

직선 위에 원점 $O$와 단위 길이를 정하고, 오른쪽을 양의 방향으로 잡습니다. 이때 직선 위의 각 점에 유일한 실수가 대응되고, 모든 실수가 직선 위의 점과 일대일 대응됩니다. 이 직선을 **수직선**이라 합니다. 점 $P$에 대응되는 실수 $a$를 점 $P$의 **좌표**라 하며, $P(a)$로 씁니다.

부등식의 해집합은 수직선 위의 구간(반직선 또는 선분)으로 표현되며, 끝점이 포함되면 색칠한 점, 포함되지 않으면 빈 점으로 그립니다.

## 예시

부등식 $-1 \le x < 3$의 해를 수직선에 나타내면, $-1$에서는 색칠한 점, $3$에서는 빈 점을 찍고 그 사이를 연결한 구간이 됩니다.

또한 두 점 $A(-2)$와 $B(5)$ 사이의 거리는 $|5 - (-2)| = 7$입니다.
