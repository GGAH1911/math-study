# 수직선

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
실수를 직선 위의 점에 일대일로 대응시켜 시각화한 직선을 의미합니다.

## 본문
직선 위에 원점 $O$와 단위 길이를 정하고, 오른쪽을 양의 방향으로 잡은 직선을 **수직선**이라 합니다. 수직선 위의 각 점에는 유일한 실수가 대응되며, 모든 실수는 수직선 위의 점과 일대일로 대응됩니다. 이때 점 $P$에 대응되는 실수 $a$를 점 $P$의 **좌표**라 하며, $P(a)$로 나타냅니다.

### 직관과 기하적 의미
수직선은 추상적인 수의 체계를 시각적인 공간으로 변환하여 보여줍니다. 이를 통해 수의 크기 관계를 직선상의 위치로 직관적으로 파악할 수 있습니다. 특히 방정식이나 부등식의 해집합을 나타낼 때 유용하며, 해의 범위를 선분이나 반직선의 형태로 그림으로 표현할 수 있습니다.

### 기본 성질
부등식의 해를 수직선에 나타낼 때, 경계가 되는 끝점이 포함되면 색칠한 점으로, 포함되지 않으면 빈 점으로 표시하여 구간을 나타냅니다. 또한, 수직선 위의 두 점 $A(a)$와 $B(b)$ 사이의 거리는 두 좌표의 차의 절댓값인 $|b - a|$로 계산할 수 있습니다. 예를 들어, 두 점 $A(-2)$와 $B(5)$ 사이의 거리는 $|5 - (-2)| = 7$입니다.

## 학습 체크
- 수직선 위에서 점 $P(a)$의 좌표를 결정할 때 원점과 단위 길이는 어떤 역할을 하는가?
- 부등식의 해를 수직선에 그릴 때, 경계값이 포함되는 경우와 포함되지 않는 경우를 어떻게 다르게 표시하는가?
- 수직선 위의 두 점 사이의 거리를 구할 때 절댓값을 사용하는 이유는 무엇인가?
