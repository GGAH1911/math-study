# 약수 관계

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$가 $b$를 나누어 나머지가 $0$이 될 때, 이를 $a \mid b$로 나타내며 $a$를 $b$의 약수라고 합니다.

## 본문
정수 $a$와 $b$가 주어졌을 때, 어떤 정수 $q$에 대하여 $b = aq$가 성립하면 $a$가 $b$를 나눈다 또는 $a$는 $b$의 약수라고 정의합니다. 이를 기호로 $a \mid b$로 나타내며, 만약 이러한 정수 $q$가 존재하지 않아 나누어떨어지지 않는 경우에는 $a \nmid b$로 표기합니다.

### 직관과 기하적 의미
$a \mid b$는 $b$를 $a$로 나누었을 때 나머지가 $0$임을 의미합니다. 예를 들어 $3 \mid 12$는 $12 = 3 \times 4$로 나타낼 수 있으므로 참이지만, $3 \mid 13$은 나머지가 $1$이므로 거짓입니다. 이 개념은 정수론의 가장 기초적인 토대로서 최대공약수, 최소공배수, 소수 판정 등을 이해하는 데 필수적입니다.

### 기본 성질
약수 관계는 다음과 같은 수학적 성질을 가집니다.
- 반사성: 모든 정수는 자기 자신을 나눕니다 ($a \mid a$).
- 추이성: $a$가 $b$를 나누고 $b$가 $c$를 나누면, $a$는 $c$를 나눕니다 ($a \mid b$이고 $b \mid c$이면 $a \mid c$).
- 반대칭성: $a$가 $b$를 나누고 $b$가 $a$를 나누면, 두 수는 부호가 같거나 다를 수 있지만 크기는 같습니다 ($a \mid b$이고 $b \mid a$이면 $a = \pm b$).

## 학습 체크
- $a \mid b$일 때 $b$를 $a$로 나눈 몫과 나머지는 각각 무엇인가요?
- $-3 \mid 12$가 성립하는 이유를 $b = aq$의 형태로 설명할 수 있나요?
- $a \mid b$이고 $b \mid c$일 때 $a \mid c$가 성립하는지 확인해 보세요.

## 관련 개념
- **최대공약수**: 두 개 이상의 정수가 공통으로 가지는 약수 중 가장 큰 값을 의미합니다.
- **최소공배수**: 두 개 이상의 정수가 공통으로 가지는 배수 중 가장 작은 값을 의미합니다.
- **소수**: $1$과 자기 자신만을 약수로 가지는 양의 정수를 의미합니다.
