# 배수의 성질

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$가 $b$를 나누어떨어지게 하는 정수 $k$가 존재할 때, $b$를 $a$의 배수라고 합니다.

## 본문
정수 $a, b$에 대하여 어떤 정수 $k$가 존재하여 $b = ka$를 만족하면, $a$는 $b$의 배수이며 $b$는 $a$로 나누어떨어진다고 합니다. 이를 기호로는 $a \mid b$와 같이 나타냅니다.

### 직관과 기하적 의미
배수는 어떤 수를 정수 번 반복하여 더한 결과물입니다. 예를 들어 3의 배수는 $3, 6, 9, \dots$와 같이 3씩 일정하게 증가하는 수들의 집합입니다. 즉, 배수란 어떤 수를 나누었을 때 나머지가 0이 되는, 즉 '나누어떨어지는' 산술적 구조를 의미합니다.

### 기본 성질
배수 관계는 다음과 같은 수학적 성질을 가집니다.
- **반사성**: 모든 자연수 $a$에 대하여 $a$는 자기 자신의 배수입니다 ($a \mid a$).
- **이행성**: $a$가 $b$의 배수이고 $b$가 $c$의 배수이면, $a$는 $c$의 배수입니다 ($a \mid b$이고 $b \mid c$이면 $a \mid c$).
- **선형성**: $a$가 $b$와 $c$의 공통된 배수라면, $b$와 $c$에 임의의 정수를 곱하여 더하거나 뺀 값도 $a$의 배수가 됩니다 ($a \mid b$이고 $a \mid c$이면 $a \mid (mb + nc)$). 이는 복잡한 숫자의 배수 여부를 판단할 때 매우 유용하게 쓰입니다.

## 학습 체크
- $a$가 $b$의 배수일 때, $b$를 $a$로 나누면 나머지는 반드시 무엇인가요?
- $a$가 $b$의 배수이고 $a$가 $c$의 배수일 때, $a$가 $b+c$의 배수인지 확인해 보세요.
- 12가 3의 배수임을 $b = ka$의 형태를 사용하여 증명해 보세요.

## 관련 개념
- **약수**: 어떤 수를 나누어떨어지게 하는 수를 의미하며, 배수와는 역의 관계에 있습니다.
- **최대공약수**: 두 개 이상의 수의 공통된 약수 중 가장 큰 수를 의미합니다.
- **최소공배수**: 두 개 이상의 수의 공통된 배수 중 가장 작은 수를 의미합니다.
