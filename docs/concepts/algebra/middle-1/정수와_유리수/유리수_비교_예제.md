# 유리수 비교 예제

> **예제** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
음수의 크기를 비교할 때는 통분을 통해 분모를 맞춘 후, 절댓값이 작을수록 더 큰 수임을 이용하여 판단합니다.

## 본문
다음 두 유리수를 비교하여 어느 것이 더 큰지 판단하세요.
$$-\frac{3}{4} \text{ 와 } -\frac{2}{3}$$

### 단계별 풀이
**1단계: 음수 비교의 원칙 확인**
음수를 비교할 때는 양수와 달리, 절댓값이 작을수록 더 큰 수입니다. 예를 들어 $-2$는 $-5$보다 크며, 이는 수직선에서 더 오른쪽에 위치함을 의미합니다.

**2단계: 공통분모로 통분하기**
두 분수를 비교하기 위해 4와 3의 최소공배수인 12로 통분합니다.
$$-\frac{3}{4} = -\frac{9}{12}$$
$$-\frac{2}{3} = -\frac{8}{12}$$

**3단계: 분자 비교**
분모가 같으므로 분자인 $-9$와 $-8$을 비교합니다. 음수에서는 절댓값이 작은 $-8$이 더 크므로 $-9 < -8$입니다. 따라서 $-\tfrac{9}{12} < -\tfrac{8}{12}$가 성립합니다.

**4단계: 원래 수로 표현**
$$-\frac{3}{4} < -\frac{2}{3}$$

### 답과 변형
**답:** $-\tfrac{2}{3}$이 더 큽니다.

**변형 및 주의사항**
- **소수 변환:** $-\tfrac{3}{4} = -0.75$이고 $-\tfrac{2}{3} \approx -0.667$입니다. $-0.75$가 $-0.667$보다 왼쪽에 있으므로 더 작습니다.
- **주의할 점:** 양수처럼 절댓값만 보고 비교하면 안 됩니다. $\tfrac{3}{4} > \tfrac{2}{3}$이지만, 음수에서는 부호 때문에 결과가 반대가 됩니다.
- **수직선 활용:** $-\tfrac{2}{3}$이 $-\tfrac{3}{4}$보다 $0$에 더 가깝고 오른쪽에 위치합니다.

## 학습 체크
- 음수 비교 시 절댓값이 큰 수가 더 작은 수임을 이해했는가?
- 분수를 비교하기 위해 통분하는 과정을 정확히 수행할 수 있는가?
- 양수와 음수의 크기 비교 원리가 서로 반대임을 인지하고 있는가?
