# 유리수 비교 예제

> **예제** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
$-3/4$와 $-2/3$ 중 어느 것이 큰가

## 본문 (학습 시 채워짐)

### 문제

다음 두 유리수를 비교하여 어느 것이 더 큰지 판단하세요.

$$-\frac{3}{4} \text{ 와 } -\frac{2}{3}$$

### 단계별 풀이

**1단계: 음수 비교의 원칙 확인**

음수를 비교할 때는 양수와 달리, **절댓값이 작을수록 더 큰 수**입니다. 예를 들어 $-2$는 $-5$보다 크다는 뜻입니다. (수직선에서 더 오른쪽에 있음)

**2단계: 공통분모로 통분하기**

두 분수를 비교하려면 먼저 공통분모로 통분합니다. 4와 3의 최소공배수는 12이므로:

$$-\frac{3}{4} = -\frac{3 \times 3}{4 \times 3} = -\frac{9}{12}$$

$$-\frac{2}{3} = -\frac{2 \times 4}{3 \times 4} = -\frac{8}{12}$$

**3단계: 분자 비교**

분모가 같아졌으므로 분자만 비교합니다:

$$-9 \text{ 와 } -8$$

음수에서는 절댓값이 작을수록 크므로: $-9 < -8$

따라서:
$$-\frac{9}{12} < -\frac{8}{12}$$

**4단계: 원래 수로 표현**

$$-\frac{3}{4} < -\frac{2}{3}$$

### 답

$$-\frac{2}{3}$$이 더 큽니다.

검증: `print(-3/4, -2/3)` → $-0.75 < -0.666...$

### 변형 및 주의

**❶ 소수로도 확인 가능:**
- $-\frac{3}{4} = -0.75$
- $-\frac{2}{3} \approx -0.667$

$-0.75$는 $-0.667$보다 왼쪽에 있으므로 더 작습니다.

**❷ 흔한 실수:**
절댓값만 비교하면 안 됩니다. "$\frac{3}{4} > \frac{2}{3}$이니까 $-\frac{3}{4} > -\frac{2}{3}$"라고 생각하면 틀립니다. 음수는 부호가 있으므로 반대가 됩니다.

**❸ 발전 학습:**
수직선 위에 $-\frac{3}{4}$와 $-\frac{2}{3}$을 표시해보세요. $-\frac{2}{3}$이 0에 더 가깝고 오른쪽에 있을 것입니다.
