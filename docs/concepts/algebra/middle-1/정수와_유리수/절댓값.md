# 절댓값

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
수직선 위에서 원점까지의 거리

## 본문
어떤 수 $a$의 **절댓값**은 다음과 같이 정의됩니다.
$$|a| = \begin{cases} a & \text{if } a \geq 0 \\ -a & \text{if } a < 0 \end{cases}$$
즉, 양수나 $0$이면 그대로 두고, 음수이면 부호를 바꿔서 양수로 만드는 연산입니다.

### 직관과 기하적 의미
수직선 위에 원점($0$)과 어떤 수를 나타내는 점이 있을 때, 절댓값은 그 점에서 원점까지의 거리를 나타냅니다. 거리는 항상 $0$ 이상이므로 절댓값도 항상 음이 아닌 수입니다. 예를 들어, 수직선에서 $3$은 원점의 오른쪽으로 $3$칸 떨어져 있고, $-3$은 원점의 왼쪽으로 $3$칸 떨어져 있으므로 $|3| = 3$, $|-3| = 3$입니다. 이는 두 점이 원점으로부터 같은 거리에 있음을 의미합니다.

### 기본 성질
- $|0| = 0$
- 양수 $a > 0$에 대해 $|a| = a$
- 음수 $a < 0$에 대해 $|a| = -a$
- 모든 수 $a$에 대해 $|-a| = |a|$

## 학습 체크
- 수직선 위에서 두 수 사이의 거리를 구할 때 절댓값을 활용할 수 있는가?
- 음수의 절댓값을 구할 때 부호가 양수로 변하는 원리를 이해하고 있는가?
- $|a| = 5$를 만족하는 $a$의 값을 두 개 찾을 수 있는가?

## 관련 개념
- **정수와 유리수**: 절댓값은 정수와 유리수의 크기를 비교하거나 수의 위치를 파악할 때 기초가 되는 핵심 개념입니다.
