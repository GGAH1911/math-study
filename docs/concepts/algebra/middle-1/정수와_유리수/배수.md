# 배수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
어떤 정수 $a$가 정수 $b$에 어떤 정수 $k$를 곱한 값($a=kb$)으로 나타내어질 때, $a$를 $b$의 배수라고 합니다.

## 본문
정수 $a, b$에 대하여 어떤 정수 $k$가 존재하여 $a = kb$를 만족할 때, $a$를 $b$의 **배수**(multiple)라고 합니다. 이를 기호로 $b \mid a$ (또는 "$b$는 $a$를 나눈다")라고 표기하며, 이때 $b$를 $a$의 약수(divisor) 또는 인수(factor)라고 부릅니다.

### 직관과 기하적 의미
배수는 "나누어떨어진다"는 개념을 수학적으로 정의한 것입니다. $a$가 $b$의 배수라는 것은 $a$를 $b$로 나누었을 때 나머지가 $0$이 된다는 뜻이며, 이는 $a$가 $b$를 특정 정수만큼 반복하여 더한 결과와 같습니다. 예를 들어 $12$는 $3$의 배수인데, 이는 $12$ 안에 $3$이 정확히 $4$번 들어있음을 의미합니다.

### 기본 성질
- $12 = 3 \times 4$이므로 $12$는 $3$의 배수입니다 ($3 \mid 12$).
- $100$ 이하의 $7$의 배수는 $7, 14, 21, \ldots, 98$로 총 $14$개입니다.
- $a = 2b$를 만족하면 $a$는 $b$의 배수이자 동시에 짝수입니다 (단, $b$가 정수일 때).

## 학습 체크
- 어떤 정수 $a$가 $b$의 배수일 때, $a$를 $b$로 나누면 나머지는 반드시 무엇인가요?
- $a = kb$를 만족하는 정수 $k$가 존재한다면, $a$와 $b$ 중 어느 쪽이 배수인가요?

## 관련 개념
- **경우의 수**: 특정 조건을 만족하는 사건의 개수를 셀 때, "3의 배수인 수의 개수"와 같이 배수 개념을 활용하여 조건부 경우의 수를 구합니다.
