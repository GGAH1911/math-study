# 배수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 정확한 진술

정수 $a$, $b$에 대하여, 어떤 정수 $k$가 존재하여 $a = kb$를 만족할 때, $a$를 $b$의 **배수**(multiple)라고 합니다. 이를 기호로 $b \mid a$ (또는 "$b$는 $a$를 나눈다")라고 표기합니다. 이 경우 $b$를 $a$의 약수(divisor) 또는 인수(factor)라고 부릅니다.

## 직관과 의미

배수는 "나누어떨어진다"는 개념을 정확히 정의한 것입니다. $a$가 $b$의 배수라는 것은 $a$를 $b$로 나누었을 때 나머지가 0이 된다는 뜻이며, 다르게 말하면 $a$가 $b$를 어떤 정수 배 한 결과라는 의미입니다. 예를 들어 12는 3의 배수인데, 이는 12를 3으로 나누면 정확히 4번 들어간다는 뜻입니다.

경우의 수에서 배수는 특정 조건을 만족하는 사건의 개수를 세거나, 사건의 확률을 구할 때 중요한 역할을 합니다. "3의 배수인 수의 개수"처럼 조건부 경우의 수를 셀 때 배수 개념을 활용합니다.

## 구체적 예

- $12 = 3 \times 4$이므로 12는 3의 배수입니다 ($3 \mid 12$)
- 100 이하의 7의 배수: $7, 14, 21, \ldots, 98$로 총 14개입니다
- $a = 2b$를 만족하면 $a$는 $b$의 배수이자 동시에 짝수입니다 (단, $b$가 정수일 때)

**검산:**
```python
len([n for n in range(1, 101) if n % 7 == 0])  # 결과: 14
```
