# 정수의 곱셈

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수의 곱셈은 두 수의 부호가 같으면 양수, 다르면 음수가 되는 규칙을 따르며, 음수의 곱은 반대의 반대라는 논리로 이해할 수 있습니다.

## 본문
정수 $a$와 $b$의 곱 $a \times b$ (또는 $ab$)는 다음과 같이 정의됩니다. 우선 $a, b$가 모두 양의 정수일 때는 자연수의 곱셈과 동일하게 계산합니다. 만약 $a$ 또는 $b$ 중 어느 하나라도 $0$이면 곱은 $0$이 됩니다. 두 정수의 부호가 서로 다를 때, 즉 $a > 0, b < 0$이거나 $a < 0, b > 0$인 경우에는 두 수의 절댓값을 곱한 뒤 앞에 음수 부호를 붙여 $-(|a| \times |b|)$로 나타냅니다. 마지막으로 두 정수가 모두 음수인 경우, 즉 $a < 0, b < 0$일 때는 두 수의 절댓값을 곱한 양수 값 $|a| \times |b|$이 결과가 됩니다.

### 직관과 기하적 의미
곱셈은 기본적으로 어떤 수를 여러 번 더하는 반복 덧셈의 의미를 갖습니다. 예를 들어 $3 \times 5$는 $5$를 $3$번 더한 $15$와 같습니다. 음수가 포함된 경우에도 이 논리는 확장됩니다. $3 \times (-5)$는 $-5$를 $3$번 더하는 것이므로 $-15$가 됩니다. $(-3) \times (-5)$의 경우는 '반대의 반대'라는 개념으로 접근할 수 있습니다. $-5$를 $-3$번 더한다는 것은 $-5$를 빼는 동작을 $3$번 반복한다는 의미이므로 결과는 양수인 $15$가 됩니다. 이는 시간과 온도의 관계로도 설명 가능한데, 2시간 전($-2$시간)에 분당 온도가 $3$도씩 떨어지고 있었다면($-3$도), 지금보다 온도가 $6$도 더 높았음을 의미합니다.

### 기본 성질
- $(+) \times (+) = (+)$
- $(+) \times (-) = (-)$
- $(-) \times (+) = (-)$
- $(-) \times (-) = (+)$

## 학습 체크
- 두 정수의 부호가 다를 때 결과의 부호를 결정하는 규칙을 설명할 수 있는가?
- 음수와 음수의 곱이 왜 양수가 되는지 반복 덧셈이나 반대의 개념을 사용하여 설명할 수 있는가?
- $0$이 포함된 곱셈의 결과가 항상 $0$이 되는 이유를 이해하고 있는가?

## 관련 개념
- **정수와 유리수**: 정수의 곱셈은 유리수의 곱셈을 배우기 위한 가장 기초적인 연산 원리가 됩니다.
- **음수의 덧셈**: 음수의 곱셈에서 나타나는 부호의 변화는 음수의 덧셈과 뺄셈의 원리와 밀접하게 연결됩니다.
