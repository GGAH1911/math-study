# 정수의 곱셈

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 정확한 진술

정수 $a$와 $b$의 곱 $a \times b$ (또는 $ab$)는 다음과 같이 정의됩니다.

**경우 1** $a, b$가 모두 양의 정수일 때: $a \times b$는 자연수의 곱셈과 동일합니다.

**경우 2** $a = 0$ 또는 $b = 0$일 때: $a \times b = 0$

**경우 3** $a > 0, b < 0$ (또는 반대)일 때: $a \times b = -(|a| \times |b|)$ (절댓값의 곱에 음수 부호)

**경우 4** $a < 0, b < 0$일 때: $a \times b = |a| \times |b|$ (절댓값의 곱, 양수)

간단히 정리하면, **부호 규칙**은:
- $(+) \times (+) = (+)$
- $(+) \times (-) = (-)$
- $(-) \times (+) = (-)$
- $(-) \times (-) = (+)$

## 직관/기하적 의미

곱셈은 본래 **반복 덧셈**입니다. $3 \times 5 = 5 + 5 + 5 = 15$처럼, "$5$를 3번 더한다"는 뜻입니다.

음수가 포함될 때도 이 논리를 확장합니다. $3 \times (-5)$는 $(-5)$를 3번 더하는 것이므로 $(-5) + (-5) + (-5) = -15$입니다.

그렇다면 $(-3) \times (-5)$는? **"반대의 반대"** 개념으로 생각하면, "$-5$를 $-3$번 더한다"는 것은 "$-5$를 뺀다는 뺄셈을 3번 한다"는 의미이고, 이는 결과적으로 양수가 됩니다: $(-3) \times (-5) = 15$.

온도 변화로도 이해할 수 있습니다. 2시간 전($-2$시간)에 분당 온도가 $-3$도씩 떨어지고 있었다면, 지금보다 온도가 $6$도 더 높았습니다: $(-2) \times (-3) = 6$.

## 한 줄 예

$(-4) \times (-3) = 12$이고, $(-4) \times 3 = -12$입니다. (검증: `(-4) * (-3) = 12, (-4) * 3 = -12`)
