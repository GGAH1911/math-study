# 배수 판정법

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 정확한 진술

어떤 정수 $n$이 주어진 수 $d$의 배수인지 판정하는 방법을 **배수 판정법**이라 합니다. 일반적으로 나눗셈을 수행하지 않고 수의 자릿수나 자릿값의 합, 차 같은 간단한 조건을 확인하여 배수 여부를 판정합니다. 예를 들어:

- $d = 2$: $n$이 2의 배수 $\Leftrightarrow$ $n$의 일의 자리 수가 짝수
- $d = 3$: $n$이 3의 배수 $\Leftrightarrow$ $n$의 각 자릿수의 합이 3의 배수
- $d = 5$: $n$이 5의 배수 $\Leftrightarrow$ $n$의 일의 자리 수가 0 또는 5
- $d = 9$: $n$이 9의 배수 $\Leftrightarrow$ $n$의 각 자릿수의 합이 9의 배수
- $d = 11$: $n$이 11의 배수 $\Leftrightarrow$ 홀수 자리 수의 합과 짝수 자리 수의 합의 차가 11의 배수

## 직관과 원리

배수 판정법의 핵심은 **$10$을 법으로 한 계산**입니다. 수를 $10$진법으로 표현할 때, $10 \equiv 1 \pmod{3}$이고 $10 \equiv 1 \pmod{9}$이므로, 각 자릿수의 합이 원래 수와 같은 나머지를 가집니다. 예를 들어 $n = \overline{a_k a_{k-1} \cdots a_1 a_0}$일 때:

$$n = a_k \cdot 10^k + a_{k-1} \cdot 10^{k-1} + \cdots + a_1 \cdot 10 + a_0$$

3의 배수 판정에서는 $10 \equiv 1 \pmod{3}$이므로 $10^i \equiv 1 \pmod{3}$입니다. 따라서:

$$n \equiv a_k + a_{k-1} + \cdots + a_1 + a_0 \pmod{3}$$

마찬가지로 2의 배수는 $10 \equiv 0 \pmod{2}$를 이용하여 일의 자리만 확인하면 됩니다.

## 한 줄 예

$2457$이 3의 배수인지 판정하려면 각 자릿수를 더합니다: $2 + 4 + 5 + 7 = 18$이고, $1 + 8 = 9$는 3의 배수이므로 $2457 = 3 \times 819$입니다. *(확인: `sympy.divide(2457, 3)` → 몫 819)*
