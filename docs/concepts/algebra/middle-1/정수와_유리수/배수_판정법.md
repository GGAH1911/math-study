# 배수 판정법

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
어떤 정수가 주어진 수의 배수인지 확인하기 위해 나눗셈 대신 자릿수의 특징을 이용하여 빠르게 판정하는 방법입니다.

## 본문
어떤 정수 $n$이 주어진 수 $d$의 배수인지 판정하는 방법을 배수 판정법이라 합니다. 일반적으로 나눗셈을 수행하지 않고 수의 자릿수나 자릿값의 합, 차 같은 간단한 조건을 확인하여 배수 여부를 판정합니다. 주요 판정법은 다음과 같습니다. $d = 2$인 경우 $n$의 일의 자리 수가 짝수이면 배수이고, $d = 5$인 경우 일의 자리 수가 0 또는 5이면 배수입니다. $d = 3$인 경우 각 자릿수의 합이 3의 배수이면 배수이며, $d = 9$인 경우 각 자릿수의 합이 9의 배수이면 배수입니다. 마지막으로 $d = 11$인 경우 홀수 자리 수의 합과 짝수 자리 수의 합의 차가 11의 배수이면 배수입니다.

### 직관과 기하적 의미
배수 판정법의 핵심은 10진법 체계에서 각 자릿값이 갖는 성질을 이용하는 것입니다. 수를 $n = a_k \cdot 10^k + a_{k-1} \cdot 10^{k-1} + \cdots + a_1 \cdot 10 + a_0$로 표현할 때, 3과 9의 경우 $10$을 나누면 나머지가 $1$이므로 $10^i$ 역시 $1$로 나누어떨어집니다. 따라서 전체 수의 나머지는 각 자릿수의 합의 나머지와 같습니다. 반면 2의 경우 $10$이 $2$로 나누어떨어지므로 $10$ 이상의 자릿수는 모두 $2$의 배수가 되어, 일의 자리 수만 확인하면 충분합니다.

### 기본 성질
- 2의 배수 판정: 일의 자리 수가 0, 2, 4, 6, 8 중 하나여야 합니다.
- 3의 배수 판정: 모든 자릿수의 합이 3의 배수여야 합니다.
- 5의 배수 판정: 일의 자리 수가 0 또는 5여야 합니다.
- 9의 배수 판정: 모든 자릿수의 합이 9의 배수여야 합니다.
- 11의 배수 판정: 홀수 번째 자릿수의 합과 짝수 번째 자릿수의 합의 차가 11의 배수여야 합니다.

## 학습 체크
- $2457$이 3의 배수인지 확인하기 위해 각 자릿수의 합을 구하고, 그 합이 3의 배수인지 판정할 수 있는가?
- 11의 배수 판정법에서 홀수 자리와 짝수 자리의 합의 차를 구하는 원리를 이해하고 있는가?

## 관련 개념
- **정수와 유리수**: 배수와 약수의 개념은 정수의 성질을 다루는 가장 기초적인 도구입니다.
- **약수와 배수**: 배수 판정법은 특정 수가 어떤 수의 약수인지 여부를 빠르게 판단하게 해줍니다.
