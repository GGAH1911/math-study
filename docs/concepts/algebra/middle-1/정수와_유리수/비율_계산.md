# 비율 계산

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
두 수 사이의 상대적인 크기 관계를 나타내는 수로, 비례식을 통해 미지수를 구하거나 규모가 다른 대상들을 비교할 때 사용합니다.

## 본문
두 수 $a, b$ ($b \neq 0$)에서 $a$가 $b$의 몇 배인지를 나타내는 수를 **비율**(ratio)이라 하며, $\frac{a}{b}$ 또는 $a : b$로 표현합니다. 비율은 절대적인 양이 아닌 두 수 사이의 상대적인 크기를 나타내는 도구입니다.

### 직관과 기하적 의미
비율은 서로 다른 규모를 가진 대상들을 동일한 기준에서 비교할 수 있게 해줍니다. 예를 들어, 학생 수가 100명인 학교에서 25명이 과학을 선택했다면 비율은 $\frac{25}{100} = \frac{1}{4}$이며, 이는 "4명마다 1명꼴"이라는 의미를 갖습니다. 이러한 특성 덕분에 지도 제작 시의 축척, 화학의 농도, 경제의 할인율, 통계의 확률 등 실생활의 다양한 분야에서 핵심적인 역할을 수행합니다.

### 기본 성질
두 비율이 같을 때 이를 **비례식**(proportion)이라고 하며, $\frac{a}{b} = \frac{c}{d}$ 또는 $a : b = c : d$로 나타냅니다. 비례식의 가장 중요한 성질은 외항의 곱과 내항의 곱이 같다는 것이며, 이를 수식으로 나타내면 $ad = bc$가 됩니다. 이는 양변에 $bd$를 곱하여 유도할 수 있으며, 복잡한 문제에서 미지수를 찾는 유용한 도구가 됩니다.

## 학습 체크
- $a : b = c : d$에서 외항의 곱과 내항의 곱이 일치하는지 확인했는가?
- 비율을 구할 때 분모가 0이 되지 않도록 주의하였는가?
- 실생활 문제에서 주어진 조건이 '몇 명당 몇 명'과 같은 비율의 형태인지 파악하였는가?

## 관련 개념
- **식의 계산**: 비율을 포함한 비례식에서 미지수를 구하기 위해 분수나 정수의 사칙연산을 활용합니다.
