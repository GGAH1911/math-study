# 비율

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
비율은 두 수량 사이의 관계를 나타내는 값으로, 기준량에 대한 비교하는 양의 크기를 상대적인 관점에서 나타낸 것입니다.

## 본문
비율(ratio)은 두 수량 사이의 관계를 나타내는 방법입니다. 일반적으로 $A$와 $B$의 비율은 $\tfrac{A}{B}$ 또는 $A:B$로 표기하며, 분자는 비교하는 양을, 분모는 기준이 되는 양을 나타냅니다. 비율을 백분율로 표현하면 $\tfrac{A}{B} \times 100\%$입니다. 확률과 통계 분야에서는 특정 계급의 도수를 전체 도수로 나눈 값인 상대도수를 비율의 일종으로 정의하여 사용합니다.
$$\text{상대도수} = \frac{\text{해당 계급의 도수}}{\text{전체 도수}}$$

### 직관과 기하적 의미
비율은 수치를 절대적인 크기가 아닌 상대적인 관점에서 비교할 수 있게 해줍니다. 예를 들어, 합격생 수가 단순히 많은 학교가 아니라 전체 수험생 수 대비 합격생의 비율이 높은 학교가 더 우수한 성과를 냈다고 판단할 수 있는 근거가 됩니다. 통계에서 도수를 비율로 변환하면 표본의 크기가 서로 다르더라도 데이터의 분포를 공정하게 비교할 수 있으며, 모든 상대도수의 합이 항상 1(또는 100%)이 되므로 데이터의 구성을 직관적으로 파악하기 용이합니다.

### 기본 성질
어떤 반 40명 중 영어 성적이 우수한 학생이 16명일 때, 우수 학생의 비율은 다음과 같이 계산됩니다.
$$\frac{16}{40} = \frac{2}{5} = 0.4 = 40\%$$
즉, 우수 학생이 전체의 40%를 차지합니다. 반면 다른 반 30명 중 우수 학생이 9명이라면 그 비율은 $\tfrac{9}{30} = 30\%$가 되어, 첫 번째 반의 우수 학생 비율이 상대적으로 더 높음을 알 수 있습니다.

## 학습 체크
- 분자와 분모의 역할이 바뀌었을 때 비율의 값이 어떻게 변하는지 설명할 수 있는가?
- 주어진 도수와 전체 도수를 이용하여 상대도수를 백분율로 변환할 수 있는가?
- 서로 다른 표본 집단의 크기가 다를 때, 왜 절대적인 수치보다 비율을 비교해야 하는지 이해하고 있는가?

## 관련 개념
- **통계**: 특정 계급의 도수를 전체 도수로 나누어 상대도수를 구함으로써, 표본의 크기와 상관없이 데이터의 분포를 비교하는 데 비율을 활용합니다.
