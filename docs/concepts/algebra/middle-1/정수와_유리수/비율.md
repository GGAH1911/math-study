# 비율

## 정확한 진술

비율(ratio)은 두 수량 사이의 관계를 나타내는 방법입니다. 일반적으로 $A$와 $B$의 비율은 $\frac{A}{B}$ 또는 $A:B$로 표기하며, 분자는 부분(또는 비교 대상), 분모는 전체(또는 기준)를 나타냅니다. 비율을 백분율로 표현하면 $\frac{A}{B} \times 100\%$입니다. 확률·통계에서는 특히 상대도수(상대빈도, relative frequency)를 비율로 정의하는데, 이는 특정 계급의 도수를 전체 도수로 나눈 값입니다:

$$\text{상대도수} = \frac{\text{해당 계급의 도수}}{\text{전체 도수}}$$

## 직관 및 실생활 의미

비율은 "크기"를 절대값이 아닌 **상대적 관점**에서 비교할 수 있게 해줍니다. 예를 들어 "학교 A에서 합격생 100명, 학교 B에서 합격생 150명"이라는 정보만으로는 어느 학교가 더 잘했는지 알 수 없지만, 각 학교의 전체 수험생 수로 나누어 비율을 구하면 공정한 비교가 가능합니다. 

통계에서 도수를 비율로 변환하면 표본의 크기와 상관없이 분포를 비교할 수 있습니다. 또한 모든 상대도수의 합은 항상 1(또는 100%)이므로, 데이터의 구성을 직관적으로 파악하기 쉬워집니다.

## 예시

어떤 반 40명의 학생 중 영어 성적이 우수한 학생이 16명일 때, 우수 학생의 비율은:

$$\frac{16}{40} = \frac{2}{5} = 0.4 = 40\%$$

즉, 우수 학생이 전체의 40%를 차지합니다. 다른 반 30명 중 우수 학생 9명의 비율은 $\frac{9}{30} = 30\%$이므로, 첫 번째 반이 상대적으로 우수 학생 비율이 높습니다.
(`sympy.Rational(16, 40)` 결과: $\frac{2}{5}$)
