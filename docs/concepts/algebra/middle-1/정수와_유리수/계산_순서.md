# 계산 순서

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
여러 연산이 섞인 식을 계산할 때, 결과의 일관성을 위해 정해진 우선순위에 따라 계산하는 규칙입니다.

## 본문
여러 연산이 포함된 식을 계산할 때 따르는 규칙을 계산 순서라고 합니다. 계산은 괄호 안의 식을 가장 먼저 계산하고, 그다음 거듭제곱을 계산합니다. 이어서 곱하기와 나누기를 왼쪽에서 오른쪽으로 차례대로 계산한 뒤, 마지막으로 더하기와 빼기를 왼쪽에서 오른쪽으로 차례대로 계산합니다. 이러한 규칙은 식의 결과가 사람마다 다르게 나오는 것을 방지하고, 식의 의미를 유일하게 결정하기 위해 반드시 필요합니다.

### 직관과 기하적 의미
계산 순서가 정해져 있지 않으면 하나의 식에 대해 여러 개의 답이 나올 수 있습니다. 예를 들어 $2 + 3 \times 4$라는 식에서 더하기를 먼저 하면 $20$이 되지만, 곱하기를 먼저 하면 $14$가 됩니다. 수학적 약속을 통해 곱하기를 더하기보다 먼저 계산하기로 정함으로써, 모든 사람이 동일한 결과인 $14$를 얻을 수 있게 됩니다. 즉, 계산 순서는 복잡한 수식을 명확하고 일관되게 해석하기 위한 약속입니다.

### 기본 성질
같은 우선순위를 가진 연산이 나란히 있을 때는 반드시 왼쪽에서 오른쪽 방향으로 계산해야 합니다. 예를 들어 $12 \div 2 \times 3$을 계산할 때, 나누기를 먼저 하고 곱하기를 하는 것이 아니라 왼쪽의 나누기부터 차례대로 수행하여 $6 \times 3 = 18$이라는 결과를 얻어야 합니다.
