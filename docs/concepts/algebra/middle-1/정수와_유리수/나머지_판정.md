# 나머지 판정

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$를 양의 정수 $m$으로 나누었을 때, 몫 $q$와 나머지 $r$이 $a = mq + r$ ($0 \le r < m$)을 만족하며 유일하게 결정되는 성질을 의미합니다.

## 본문
정수 $a$를 양의 정수 $m$으로 나눈 나머지는, $a = mq + r$을 만족하는 정수 $r$입니다. 이때 $q$는 몫이고 $r$은 나머지이며, $0 \le r < m$의 범위를 가집니다. 이러한 분해는 항상 유일하게 존재하며 이를 나눗셈 정리라고 합니다. 나머지 판정은 $a \bmod m = r$이라는 기호로 나타낼 수 있습니다.

### 직관과 기하적 의미
정수들을 $m$으로 나눈 나머지에 따라 분류하면, 정수 전체는 정확히 $m$개의 등가류로 나뉩니다. 예를 들어 $m = 3$인 경우, 나머지가 0인 집합 $\{..., -6, -3, 0, 3, 6, ...\}$, 나머지가 1인 집합 $\{..., -5, -2, 1, 4, 7, ...\}$, 나머지가 2인 집합 $\{..., -4, -1, 2, 5, 8, ...\}$로 구분됩니다. 이러한 구조는 시계처럼 일정한 간격으로 반복되는 주기성을 띠므로, 요일이나 계절처럼 반복되는 현상을 모델링할 때 유용하게 사용됩니다.

### 기본 성질
두 정수가 같은 나머지를 가진다는 것은 $a \equiv b \pmod{m}$로 표기하며, 이는 모듈로 연산의 기초가 됩니다. 또한, 어떤 정수를 $m$으로 나눈 나머지는 항상 0 이상 $m$ 미만의 정수여야 한다는 점이 핵심입니다.

## 학습 체크
- $a = mq + r$에서 $r$의 범위가 왜 $0 \le r < m$이어야 하는지 설명할 수 있는가?
- $47$을 $5$로 나누었을 때의 몫과 나머지를 구하고, 이를 나눗셈 정리 형식으로 쓸 수 있는가?

## 관련 개념
- **수열**: 나머지 판정에서 나타나는 주기적인 패턴은 일정한 규칙을 가지고 반복되는 수열의 형태로 나타날 수 있습니다.
