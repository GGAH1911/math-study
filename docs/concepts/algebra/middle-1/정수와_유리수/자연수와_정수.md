# 자연수와 정수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
자연수, 0, 음의 정수를 모두 포함하는 수의 체계이다.

## 본문
물건의 개수를 나타내는 $1, 2, 3, 4, \ldots$의 수들을 **자연수**라고 하며, 그 집합을 $\mathbb{N}$으로 나타낸다. **정수**는 자연수와 $0$, 그리고 자연수에 마이너스 부호를 붙인 음의 정수 $\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots$를 모두 포함하는 수이며, 그 집합을 $\mathbb{Z}$로 나타낸다. 따라서 모든 자연수는 정수에 포함되지만, 정수가 모두 자연수인 것은 아니다. 즉, $\mathbb{N} \subset \mathbb{Z}$의 관계가 성립한다. 여기서 주의할 점은 $0$은 정수에는 포함되지만 자연수는 아니라는 사실이다.

### 직관과 기하적 의미
수직선 위에서 정수는 $0$을 기준으로 한 칸씩 떨어진 점들로 나타난다. $0$을 기준으로 오른쪽(양수 방향)으로 갈수록 수가 커지고, 왼쪽(음수 방향)으로 갈수록 수가 작아진다. 일상생활에서는 해수면을 기준으로 한 높이 차이, 섭씨 온도의 변화, 통장 잔액과 채무 관계 등을 표현할 때 정수를 사용한다.

### 기본 성질
정수는 양의 정수(자연수), $0$, 음의 정수로 분류할 수 있다. 예를 들어 $5$나 $100$은 양의 정수이며, $-7$은 음의 정수이고, $0$은 양수도 음수도 아닌 중립적인 수이다. 반면 $2.5$와 같이 소수점으로 나타나는 수는 정수에 해당하지 않는다.

## 관련 개념
- **정수와 유리수**: 정수는 유리수의 일부분으로, 분수나 소수 형태를 포함하는 더 넓은 수의 범위를 배운다.
