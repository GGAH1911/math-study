# 자연수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
1부터 시작하여 1씩 증가하는 수들의 모임으로, 사물의 개수를 세는 데 사용되는 가장 기본적인 수입니다.

## 본문
자연수는 1부터 시작하여 1씩 증가하는 수들의 모임입니다. 기호로는 $\mathbb{N}$으로 나타내며, 다음과 같이 정의됩니다.
$$\mathbb{N} = \{1, 2, 3, 4, \ldots\}$$
집합론적으로 자연수는 페아노 공리를 만족하는 최소 집합으로, 1은 자연수이며 모든 자연수 $n$에 대해 $n+1$도 자연수라는 규칙을 통해 구성됩니다.

### 직관과 기하적 의미
자연수는 사물의 개수를 세기 위해 만들어진 가장 기본적인 수입니다. 사과 1개, 학생 2명, 의자 3개처럼 "얼마나 많은가?"를 표현할 때 사용하며, 이러한 특성 때문에 인류 역사에서 가장 먼저 발생한 수 개념이 되었습니다.

### 기본 성질
자연수는 항상 1씩 균일하게 증가하는 규칙성을 가집니다. 수열의 관점에서 보면 첫째 항이 1이고 공차가 1인 등차수열로 이해할 수 있으며, 수열 $(a_n)$에서 $a_n = n$인 경우 각 항은 모두 자연수가 됩니다.

## 학습 체크
- 자연수의 시작 숫자는 무엇이며, 다음 숫자로 넘어가기 위해 어떤 연산이 필요한가요?
- 사물의 개수를 나타낼 때 자연수를 사용하는 이유는 무엇인가요?
- 수열 $a_n = n$에서 각 항이 자연수가 되는 원리는 무엇인가요?

## 관련 개념
- **수열**: 첫째 항이 1이고 공차가 1인 등차수열의 형태로 자연수를 이해할 수 있습니다.
