# 자연수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 정확한 진술

자연수는 **1부터 시작하여 1씩 증가하는 수들의 모임**입니다. 기호로는 $\mathbb{N}$으로 나타내며, 다음과 같이 정의됩니다.

$$\mathbb{N} = \{1, 2, 3, 4, \ldots\}$$

집합론적으로 자연수는 **페아노 공리**(Peano axioms)를 만족하는 최소 집합으로, 다음 성질들을 가집니다:
- 1은 자연수이다.
- 모든 자연수 $n$에 대해, $n + 1$도 자연수이다.
- 이 두 규칙으로만 자연수를 구성한다.

## 직관적 의미

자연수는 **사물의 개수를 세기 위해 만들어진 가장 기본적인 수**입니다. 사과 1개, 학생 2명, 의자 3개처럼 "얼마나 많은가?"를 표현할 때 사용합니다. 이것이 자연수가 인류 역사에서 가장 먼저 발생한 수 개념인 이유입니다.

수열 단원에서 자연수는 **첫째 항이 1이고 공차가 1인 등차수열**로도 이해할 수 있습니다. 수열 $(a_n)$에서 $a_n = n$이면, 이 수열의 각 항 $a_1, a_2, a_3, \ldots$는 모두 자연수이며, 항상 정확히 1씩 균일하게 증가합니다.

## 한 줄 예

$\mathbb{N}$의 처음 여섯 원소는 $1, 2, 3, 4, 5, 6$이고, 모두 자연수입니다. (`[n for n in range(1, 7)]`)
