# 정수의 약수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$를 0이 아닌 정수 $b$로 나누었을 때 나머지가 0이면, $b$를 $a$의 약수라고 하며 $b \mid a$로 나타냅니다.

## 본문
정수 $a$와 0이 아닌 정수 $b$에 대하여, $a = bq$를 만족하는 정수 $q$가 존재할 때 $b$를 $a$의 약수라고 하며, 이를 $b \mid a$로 표기합니다. 이때 $a$는 $b$의 배수가 됩니다. 예를 들어 $12 = 3 \times 4$이므로 $3$은 $12$의 약수입니다.

### 직관과 기하적 의미
약수는 어떤 수를 나누었을 때 나머지가 생기지 않게 하는 수입니다. 나눗셈 정리 $a = bq + r$ ($0 \le r < |b|$)에서 나머지 $r$이 $0$이 되는 상태를 의미합니다.

### 기본 성질
정수 $a$가 0이 아닐 때, $a$의 약수는 유한하며 항상 $\pm 1$과 $\pm a$를 포함합니다. 또한 $a \mid b$이고 $b \mid c$이면 $a \mid c$가 성립하며, $a$가 $b$와 $c$를 각각 나누면 $a$는 이들의 정수 결합인 $mb + nc$도 나눕니다. 음수 또한 약수에 포함되므로, $12$의 약수는 $\pm 1, \pm 2, \pm 3, \pm 4, \pm 6, \pm 12$로 총 12개입니다.

## 학습 체크
- $-2$가 $10$의 약수가 될 수 있는가? (정답: $10 = (-2) \times (-5)$이므로 가능함)
- $3$이 $10$의 약수인가? (정답: 나눗셈 시 나머지가 $1$이므로 불가능함)

## 관련 개념
- **최대공약수**: 두 개 이상의 정수가 공통으로 가지는 약수 중 가장 큰 값을 의미합니다.
- **최소공배수**: 두 개 이상의 정수가 공통으로 가지는 배수 중 가장 작은 값을 의미합니다.
- **소인수분해**: 정수를 소수들의 곱으로 나타내는 과정으로, 약수를 찾는 기초가 됩니다.
- **방정식과 부등식**: 정수의 약수 개념은 방정식의 정수 해를 구하거나 부등식의 범위를 결정할 때 기초가 됩니다.
