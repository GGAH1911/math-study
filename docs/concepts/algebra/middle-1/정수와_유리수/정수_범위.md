# 정수 범위

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수는 양의 정수, $0$, 음의 정수를 모두 포함하는 수의 집합으로, 수직선 위에서 $1$ 간격으로 떨어진 이산적인 점들로 나타납니다.

## 본문
정수(integer)는 양의 정수, $0$, 음의 정수를 모두 포함하는 수의 집합입니다. 수학 기호로는 $\mathbb{Z}$로 표기하며, 명시적으로는 $\mathbb{Z} = \{\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\}$입니다. 양의 정수의 집합을 $\mathbb{Z}^+$ 또는 $\mathbb{N}$이라 하고($\mathbb{N} = \{1, 2, 3, \ldots\}$), 음의 정수의 집합을 $\mathbb{Z}^-$이라 합니다($\mathbb{Z}^- = \{-1, -2, -3, \ldots\}$).

### 직관과 기하적 의미
수직선 위에서 정수는 $0$을 중심으로 좌우 대칭이며 $1$ 간격으로 등간격하게 배열된 점들입니다. 정수는 실수의 부분집합이지만, 연속이 아닌 **이산(discrete)** 구조를 가집니다.

### 기본 성질
정수의 가장 중요한 대수적 성질은 덧셈, 뺄셈, 곱셈에 대해 **닫혀 있다**는 것입니다. 즉, 두 정수의 덧셈, 뺄셈, 곱셈 결과는 항상 정수이지만, 나눗셈은 일반적으로 정수를 만들지 않습니다. 이 성질은 정수론의 핵심이며, 나눗셈 관계를 연구하는 것(나머지, 최대공약수 등)이 수학의 중요한 영역입니다.

## 학습 체크
- $-5, 0, 3, 10$과 같이 정수에 해당하는 수를 구분할 수 있는가?
- 두 정수의 덧셈, 뺄셈, 곱셈 결과가 왜 항상 정수가 되는지 이해하고 있는가?
- $5 \div 2$와 같이 나눗셈의 결과가 정수가 되지 않는 사례를 찾을 수 있는가?

## 관련 개념
- **실수와 그 계산**: 정수는 실수의 부분집합이며, 정수의 사칙연산 성질은 실수의 계산 체계를 이해하는 기초가 됩니다.
