# 백분율 계산

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
백분율은 서로 다른 규모의 수량을 100을 기준으로 통일하여 비교할 수 있게 해주는 척도입니다.

## 본문
백분율(百分率)은 어떤 수량을 전체에 대한 비로 나타낸 후 100을 곱한 값입니다. 전체를 $W$ (전체, whole), 부분을 $P$ (부분, part)라고 할 때, 백분율은 $\frac{P}{W} \times 100\%$로 계산합니다. 만약 백분율값을 $r$이라고 한다면, 부분의 크기는 $P = \frac{r}{100} \times W$라는 식을 통해 구할 수 있습니다.

### 직관과 기하적 의미
백분율은 서로 다른 전체 크기를 가진 두 상황을 동등한 기준인 100으로 변환하여 비교할 수 있게 해줍니다. 예를 들어 A 학교는 150명 중 60명이 합격했고, B 학교는 200명 중 70명이 합격했다고 가정해 봅시다. 단순히 합격자 수만 보면 B 학교가 많아 보이지만, 백분율로 계산하면 A 학교는 40%, B 학교는 35%가 되어 A 학교의 합격률이 더 높다는 사실을 알 수 있습니다. 즉, 백분율은 규모가 다른 집단을 공정하게 비교할 수 있는 통일된 척도 역할을 합니다.

### 기본 성질
백분율 계산은 크게 세 가지 패턴으로 나뉩니다. 첫째, 전체의 일정 비율에 해당하는 부분을 구하는 경우입니다. 둘째, 전체에 대한 특정 부분의 비율이 얼마인지 구하는 경우입니다. 셋째, 어떤 수의 일정 비율이 주어졌을 때 전체 수량을 역산하여 구하는 경우입니다. 이러한 계산 방식은 통계나 확률, 실생활의 다양한 데이터 분석에서 핵심적인 도구로 사용됩니다.

## 학습 체크
- 전체 수량과 부분 수량을 알 때, 백분율을 구하는 식을 세울 수 있는가?
- 백분율로 주어진 값을 바탕으로 실제 부분의 수량을 정확히 계산할 수 있는가?
- 서로 다른 기준을 가진 두 집단을 백분율을 이용해 공정하게 비교할 수 있는가?

## 관련 개념
- **통계**: 데이터를 수집하고 분석할 때, 서로 다른 집단의 특성을 비교하기 위해 백분율을 빈도수 대신 사용합니다.
- **비와 비율**: 백분율은 두 수의 관계를 나타내는 비를 100을 기준으로 나타낸 특수한 형태의 비율입니다.
