# 기약분수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
분자와 분모의 최대공약수가 1인 분수로, 더 이상 약분할 수 없는 가장 간결한 형태의 분수입니다.

## 본문
분수 $\frac{a}{b}$ (단, $b > 0$, $a, b$는 정수)에서 분자 $a$와 분모 $b$의 최대공약수가 1일 때, 이 분수를 **기약분수**라고 합니다. 즉, 공약수가 1뿐인 두 수로 이루어진 분수이므로 더 이상 약분할 수 없습니다. 수식으로는 $\gcd(a, b) = 1 \Leftrightarrow \frac{a}{b}$는 기약분수라고 나타냅니다.

### 직관과 기하적 의미
같은 크기의 분수라도 나타내는 방식은 무한히 많을 수 있습니다. 예를 들어 $\frac{2}{3} = \frac{4}{6} = \frac{6}{9} = \frac{8}{12} = \cdots$와 같이 여러 형태로 표현이 가능합니다. 만약 이러한 분수들을 표준화된 형태로 나타내지 않는다면, 두 분수의 크기가 같은지 판단하기 어렵고 계산 결과를 비교할 때도 매우 복잡해집니다. 기약분수는 각 유리수를 나타내는 표준적인 표현으로서, 분수를 가장 간결하게 나타내어 비교와 연산을 명확하게 만들어주는 역할을 합니다.

### 기본 성질
- $\frac{3}{5}$는 $\gcd(3, 5) = 1$이므로 기약분수입니다.
- $\frac{12}{18}$은 $\gcd(12, 18) = 6$이므로 기약분수가 아닙니다. 분자와 분모를 6으로 나누어 $\frac{2}{3}$으로 약분할 수 있습니다.
- 음수가 포함된 경우에도 분자의 절댓값과 분모의 최대공약수를 기준으로 판단합니다. 예를 들어 $\frac{-7}{11}$은 $\gcd(|-7|, 11) = 1$이므로 기약분수입니다.

## 학습 체크
- 분자와 분모의 최대공약수가 1이라는 조건이 왜 '더 이상 약분할 수 없음'을 의미하는지 설명할 수 있는가?
- 주어진 분수가 기약분수인지 확인하기 위해 어떤 과정을 거쳐야 하는가?
- 음수 분수가 기약분수인지 판단할 때 주의해야 할 점은 무엇인가?

## 관련 개념
- **유리수와 순환소수**: 모든 유리수는 분수로 나타낼 수 있으며, 이를 기약분수로 나타냈을 때 소수로 변환하면 유한소수 또는 순환소수가 됩니다.
