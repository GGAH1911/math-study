# 기약분수

## 정확한 진술

분수 $\frac{a}{b}$ (단, $b > 0$, $a, b$는 정수)에서 분자 $a$와 분모 $b$의 최대공약수가 1일 때, 이 분수를 **기약분수**라고 합니다. 즉, 공약수가 1뿐인 두 수로 이루어진 분수이므로 더 이상 약분할 수 없습니다.

수식으로: $\gcd(a, b) = 1 \Leftrightarrow \frac{a}{b}$는 기약분수

## 왜 기약분수가 필요한가

같은 크기의 분수도 무한히 많은 방식으로 나타낼 수 있습니다. 예를 들어 $\frac{2}{3} = \frac{4}{6} = \frac{6}{9} = \frac{8}{12} = \cdots$ 처럼 말입니다. 만약 표준 형태를 정하지 않으면, 두 분수가 같은지 다른지 판단하기 어렵고, 계산 결과를 비교하기 복잡해집니다. 기약분수는 **각 유리수를 나타내는 표준 표현**으로서, 분수를 간결하게 표현하고 비교와 연산을 명확하게 만듭니다.

## 구체적 예

- $\frac{3}{5}$는 이미 기약분수입니다. $\gcd(3, 5) = 1$이기 때문입니다.
- $\frac{12}{18}$은 기약분수가 아닙니다. $\gcd(12, 18) = 6$이므로, 분자와 분모를 6으로 나누어 $\frac{2}{3}$으로 약분할 수 있습니다.
  - 검증: `from sympy import gcd; gcd(12, 18)` → 6
- 음수를 포함한 경우, $\frac{-7}{11}$도 기약분수입니다. $\gcd(|-7|, 11) = 1$이기 때문입니다.
