# 정수 사칙연산 예제

> **예제** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
부호가 섞인 정수의 +, −, ×, ÷

## 본문 (학습 시 채워짐)

### 문제

다음 계산을 순서대로 하시오.

$$(-8) + 5, \quad (-3) - (-7), \quad (-2) \times (-4), \quad (-12) \div 3$$

### 단계별 풀이

**덧셈: $(-8) + 5$**

부호가 다른 두 수를 더할 때는 절댓값이 큰 수의 부호를 따릅니다. $|-8| = 8 > |5| = 5$이므로 음수 부호를 따르고, 절댓값의 차를 계산합니다.

$$(-8) + 5 = -(8 - 5) = -3$$

**뺄셈: $(-3) - (-7)$**

뺄셈은 빼는 수의 부호를 바꿔서 덧셈으로 만듭니다.

$$(-3) - (-7) = (-3) + 7 = 4$$

**곱셈: $(-2) \times (-4)$**

음수 × 음수 = 양수입니다. 절댓값끼리 곱한 후 양수 부호를 붙입니다.

$$(-2) \times (-4) = +(2 \times 4) = 8$$

**나눗셈: $(-12) \div 3$**

음수 ÷ 양수 = 음수입니다. 절댓값끼리 나눈 후 음수 부호를 붙입니다.

$$(-12) \div 3 = -(12 \div 3) = -4$$

### 답

$$-3, \quad 4, \quad 8, \quad -4$$

### 변형/주의

**핵심 부호 규칙:**
- 같은 부호 × 같은 부호 = 양수 (음수 × 음수도 양수!)
- 다른 부호 × 다른 부호 = 음수
- 나눗셈도 같은 규칙 적용

**자주 하는 실수:** $(-2) \times (-4) = -8$로 잘못 계산하기. **음수 × 음수는 항상 양수**임을 기억하세요. 음수끼리의 곱은 "빚의 빚은 자산"이라고 생각하면 도움이 됩니다.

```python
# sympy로 검증
from sympy import symbols
print((-8) + 5, (-3) - (-7), (-2) * (-4), (-12) / 3)
```
