# 배수 조건

## 정확한 진술

정수 $a$가 정수 $b$의 **배수(multiple)**라는 것은 $a = kb$를 만족하는 정수 $k$가 존재한다는 뜻입니다. 이를 "$b \mid a$" 또는 "$b$가 $a$를 나눈다"고 표현하고, "$a$는 $b$로 나누어떨어진다"고 읽습니다.

수열 맥락에서 **배수 조건**이란 수열 $\{a_n\}$에서 **인덱스 $n$이 특정 수의 배수일 때** 항들이 만족하는 조건을 말합니다. 예를 들어 "$n$이 3의 배수인 항들"이나 "$n$이 2의 배수인 항들"의 성질을 다루는 것입니다.

## 직관과 의미

"배수"는 기준 수를 여러 번 반복한 결과입니다. 3의 배수는 3, 6, 9, 12, ...처럼 3씩 증가하는 규칙적인 수열입니다.

수열에서 배수 조건을 활용하면, 모든 항을 한 번에 살피는 대신 **특정 간격으로 떨어진 항들만** 따로 분석할 수 있습니다. 이는 주기성이나 특정 패턴을 찾을 때 매우 유용합니다.

## 구체적 예

등차수열 $a_n = 2n + 1$ (첫 항부터: 3, 5, 7, 9, 11, 13, ...)을 생각합시다.
- $n$이 **홀수의 배수**인 항: $a_1 = 3, a_3 = 7, a_5 = 11, ...$ (모두 홀수)
- $n$이 **2의 배수**인 항: $a_2 = 5, a_4 = 9, a_6 = 13, ...$ (모두 홀수)

이렇게 배수 조건을 붙이면 부분 수열(subsequence)을 만들 수 있고, 그 부분 수열의 규칙을 분석할 수 있습니다.
