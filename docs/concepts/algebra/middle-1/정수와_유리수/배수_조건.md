# 배수 조건

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
정수 $a$가 정수 $b$의 배수라는 것은 $a = kb$를 만족하는 정수 $k$가 존재함을 의미하며, 수열에서는 인덱스 $n$이 특정 수의 배수일 때 나타나는 항들의 규칙을 다루는 조건을 말합니다.

## 본문
정수 $a$가 정수 $b$의 **배수(multiple)**라는 것은 $a = kb$를 만족하는 정수 $k$가 존재한다는 뜻입니다. 이를 $b \mid a$ 또는 $b$가 $a$를 나눈다라고 표현하며, $a$는 $b$로 나누어떨어진다고 읽습니다. 수열의 맥락에서 **배수 조건**이란 수열 $\{a_n\}$에서 인덱스 $n$이 특정 수의 배수일 때 항들이 만족하는 조건을 의미합니다. 예를 들어 $n$이 3의 배수인 항들이나 $n$이 2의 배수인 항들의 성질을 분석하는 것이 이에 해당합니다.

### 직관과 기하적 의미
배수는 기준이 되는 수를 일정한 간격으로 반복하여 더해나간 결과입니다. 3의 배수는 3, 6, 9, 12와 같이 3씩 일정하게 증가하는 규칙적인 흐름을 보입니다. 수열에서 배수 조건을 활용하면 전체 항을 모두 살피지 않고도 특정 간격으로 떨어진 항들만 따로 추출하여 분석할 수 있어, 수열의 주기성이나 특정한 패턴을 찾아내는 데 매우 유용합니다.

### 기본 성질
배수 조건을 적용하면 원래의 수열에서 특정 규칙을 가진 부분 수열을 만들 수 있습니다. 예를 들어 등차수열 $a_n = 2n + 1$에서 $n$이 2의 배수인 항들($a_2, a_4, a_6, \dots$)만 모으면, 원래 수열의 규칙성을 유지하면서도 새로운 간격을 가진 수열을 형성하게 됩니다.

## 학습 체크
- 정수 $a$가 $b$의 배수일 때, $a$를 $b$로 나누었을 때의 나머지는 얼마인가요?
- 수열 $\{a_n\}$에서 인덱스 $n$이 $k$의 배수일 때, 항들의 간격은 어떻게 변하나요?

## 관련 개념
- **수열**: 인덱스 $n$에 배수 조건을 적용함으로써 전체 수열 중에서 특정 간격의 항들로 이루어진 부분 수열을 추출할 수 있습니다.
