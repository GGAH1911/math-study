# 자연수와 정수

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
0, ±1, ±2 … 의 집합과 그 안의 자연수

## 본문 (학습 시 채워짐)

### 정확한 진술

**자연수**는 물건의 개수를 나타내는 $1, 2, 3, 4, \ldots$의 수들이다. 자연수의 집합을 $\mathbb{N}$으로 나타낸다.

**정수**는 자연수, 0, 그리고 자연수의 음수인 $\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots$를 모두 포함하는 수들이다. 정수의 집합을 $\mathbb{Z}$로 나타낸다.

따라서 모든 자연수는 정수이지만, 정수가 모두 자연수인 것은 아니다. 즉, $\mathbb{N} \subset \mathbb{Z}$이다.

### 직관과 일상적 의미

수직선 위에서 정수는 0을 기준으로 한 칸씩 떨어진 점들이다. 오른쪽(양수)으로 갈수록 수가 커지고, 왼쪽(음수)으로 갈수록 작아진다.

정수는 일상에서 자주 나타난다:
- **높이 차이**: 해수면을 0으로 할 때, 산 위는 양수, 지하는 음수
- **온도**: 섭씨 0도를 기준으로 위는 양수, 아래는 음수
- **잔액**: 통장에 돈이 있으면 양수, 빌린 것은 음수

0은 자연수가 **아니지만** 정수에는 포함된다. 이것이 자연수와 정수의 가장 중요한 차이다.

### 예시

자연수: $5, 100, 1$ (모두 양수)

정수: $-7, 0, 3$ ($-7$은 음수, $0$은 중립, $3$은 양수)

$-1$은 정수이지만 자연수는 아니다. $2.5$는 정수도 자연수도 아니다.
