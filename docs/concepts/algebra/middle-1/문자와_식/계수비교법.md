# 계수비교법

문자 식이 임의의 값에서 항상 같다고 주어졌을 때, 같은 문자의 항끼리 계수를 같게 놓아 미지의 수를 구하는 방법입니다. 중1 문자와 식 단원에서 등식을 정리하는 기본 도구입니다.

## 정의

두 식이 임의의 문자 $x$에 대해 항상 같으려면, 양변의 동류항의 계수와 상수항이 각각 같아야 합니다. 즉,
$$ax + b = cx + d \text{ (모든 } x\text{)} \iff a = c,\ b = d.$$

## 예시

$3x + 5 = ax + b$가 모든 $x$에 대해 성립하도록 하는 $a, b$를 구해 봅니다. 계수와 상수항을 비교하면 $a = 3$, $b = 5$입니다.

또한 $2(x + 1) = ax + b$가 항상 성립하려면, 좌변을 정리한 $2x + 2$와 비교하여 $a = 2$, $b = 2$입니다.
