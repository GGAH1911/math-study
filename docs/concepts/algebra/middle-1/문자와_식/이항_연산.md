# 이항 연산

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
집합의 두 원소를 선택하여 연산했을 때 반드시 그 결과가 다시 해당 집합의 원소가 되는 대응 관계를 의미합니다.

## 본문
공집합이 아닌 집합 $A$에 대하여, $A \times A$에서 $A$로의 함수를 이항 연산이라고 부릅니다. 즉, 집합 $A$의 원소 두 개 $a, b$를 선택하면 반드시 $A$의 원소 $c$가 하나 결정되는 대응 관계를 말하며, 이를 $a \cdot b = c$ 또는 $a + b = c$와 같이 다양한 기호로 나타낼 수 있습니다. 형식적으로는 $\circ : A \times A \to A$인 함수로 정의됩니다.

### 직관과 기하적 의미
이항 연산은 "두 개의 입력에서 하나의 출력"이 나오는 구조를 가집니다. 우리가 일상적으로 사용하는 덧셈 $a + b$나 곱셈 $a \times b$가 바로 실수 집합 $\mathbb{R}$ 위에서 정의된 대표적인 이항 연산입니다. 연산의 결과가 원래의 집합을 벗어나지 않아야 한다는 '닫혀있음'이 가장 중요한 핵심 조건입니다.

### 기본 성질
연산의 결과가 반드시 원래의 집합에 포함되어야 합니다. 예를 들어 정수 집합에서 덧셈은 결과가 항상 정수이므로 닫혀있지만, 나눗셈은 $1 \div 2 = 0.5$와 같이 정수가 아닌 결과가 나올 수 있으므로 정수 집합 위에서 이항 연산이 될 수 없습니다.

## 학습 체크
- 연산의 결과값이 반드시 원래의 집합에 속하는지 확인했는가?
- 두 개의 원소를 넣었을 때 결과값이 유일하게 하나로 결정되는가?

## 관련 개념
- **문자와 식**: 이항 연산을 기호로 나타낼 때 $a, b, c$와 같은 문자를 사용하여 연산의 규칙을 일반화하여 표현합니다.
