# 이항 연산

## 정확한 진술

공집합이 아닌 집합 $A$에 대하여, $A \times A$에서 $A$로의 함수를 **이항 연산**(binary operation)이라고 부릅니다. 즉, 집합 $A$의 원소 두 개 $a, b$를 선택하면 반드시 $A$의 원소 $c$가 하나 결정되는 대응 관계입니다. 이를 $a \cdot b = c$ (또는 $a * b = c$, $a + b = c$ 등)로 나타냅니다.

형식으로는 $\circ : A \times A \to A$인 함수를 이항 연산이라 합니다.

## 직관과 의미

이항 연산은 "두 개의 입력에서 하나의 출력"이라는 기본 구조입니다. 고등학교에서 자주 다루는 덧셈 $a + b$, 곱셈 $a \times b$가 바로 실수 집합 $\mathbb{R}$ 위의 이항 연산입니다. 

**중요한 조건**은 **닫혀있음**(closure)입니다. 집합 $A$의 어떤 두 원소를 선택해서 연산을 하더라도, 그 결과는 반드시 $A$에 속해야 합니다. 예를 들어 정수 집합에서 덧셈은 닫혀있지만 나눗셈은 그렇지 않습니다 ($1 \div 2 = 0.5 \notin \mathbb{Z}$).

## 한 줄 예

실수 집합 $\mathbb{R}$에서 $a \circ b = a + 2b$로 정의하면, 임의의 $a, b \in \mathbb{R}$에 대해 $a + 2b \in \mathbb{R}$이므로 이것은 이항 연산입니다. 예를 들어 $3 \circ 5 = 3 + 2(5) = 13$입니다.
