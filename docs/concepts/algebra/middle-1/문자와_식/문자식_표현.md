# 문자식 표현

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
수, 문자, 연산 기호를 사용하여 수학적 관계나 규칙을 일반화하여 나타내는 식입니다.

## 본문
문자식 표현은 수, 문자, 연산 기호를 사용하여 일반적인 수학적 관계나 규칙을 나타내는 식입니다. 여기서 문자(보통 $x, y, a, b$ 등)는 정해지지 않은 수인 미지수 또는 임의의 수인 변수를 나타냅니다. 예를 들어 $3x + 2$에서 $x$는 특정한 하나의 값이 아니라, 모든 가능한 수를 대표하는 역할을 합니다.

### 직관과 기하적 의미
구체적인 수 대신 문자를 사용하면 일반적인 규칙을 한 번에 표현할 수 있어 매우 효율적입니다. 예를 들어 "어떤 수에 3을 곱한 후 2를 더한다"라는 복잡한 설명을 $3x + 2$라는 식 하나로 간결하게 나타낼 수 있습니다. 또한 이러한 문자식을 더하거나 곱하는 등의 조작을 통해 문제를 체계적으로 해결할 수 있습니다.

도형의 넓이나 둘레 같은 기하학적 양도 문자식으로 표현이 가능합니다. 가로 길이가 $a$, 세로 길이가 $b$인 직사각형의 넓이를 $ab$라고 나타내면, $a$와 $b$가 어떤 값이든 상관없이 그 관계를 한눈에 파악할 수 있어 도형의 성질을 깊이 있게 이해하는 데 도움을 줍니다.

### 기본 성질
문자식은 변수에 어떤 값을 대입하느냐에 따라 결과값이 달라지는 성질을 가집니다. 한 변의 길이가 $a$인 정사각형의 둘레를 $4a$라고 할 때, $a$에 3을 대입하면 둘레는 12가 되고, 5를 대입하면 20이 됩니다. 이처럼 문자식은 다양한 경우의 수를 하나의 식으로 포괄하여 보여줍니다.

## 학습 체크
- 문자 $x$가 특정한 하나의 값이 아닌 변수로서 어떤 역할을 하는지 이해했나요?
- 문자를 사용하여 복잡한 문장 형태의 규칙을 어떻게 간결한 식으로 변환할 수 있나요?
- 도형의 길이나 넓이를 문자로 나타냈을 때 어떤 이점이 있는지 설명할 수 있나요?

## 관련 개념
- **평면도형**: 직사각형이나 정사각형의 둘레와 넓이를 문자식으로 나타냄으로써 도형의 성질을 일반화하여 표현할 수 있습니다.
