# 식의 값 구하기

> **예제** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
문자가 포함된 식의 문자 자리에 주어진 숫자를 대입하여 계산하는 방법입니다.

## 본문
다음 식에 주어진 문자의 값을 대입하여 식의 값을 구하시오.
$$2x + 3 \text{일 때, } x = 5$$

### 단계별 풀이
**1단계: 주어진 식과 문자의 값 확인**
식 $2x + 3$에서 $2x$는 $2$와 $x$의 곱을 의미하며, $x$에 $5$를 대입해야 합니다.

**2단계: $x = 5$를 식에 대입**
$x$ 자리에 $5$를 넣으면 $2 \times 5 + 3$이 됩니다. 이때 문자와 숫자 사이의 곱셈을 명확히 하기 위해 괄호를 사용하여 $2(5) + 3$으로 나타낼 수 있습니다.

**3단계: 연산 순서에 따라 계산**
사칙연산의 순서에 따라 곱셈을 먼저 계산합니다.
$$2 \times 5 = 10$$
그다음 덧셈을 계산하여 최종 값을 구합니다.
$$10 + 3 = 13$$

### 답과 변형
**답**
$$13$$

**변형 및 주의사항**
비슷한 예제로 $3y - 2$에 $y = 4$를 대입하면 $3 \times 4 - 2 = 10$이 됩니다. 학습 시 주의할 점은 문자 앞의 숫자를 더하는 것이 아니라 곱하는 것으로 이해해야 한다는 점입니다. 또한 계산할 때 반드시 곱셈과 나눗셈을 덧셈과 뺄셈보다 먼저 수행해야 하며, 결과값이 음수가 나오는 경우도 있으므로 주의가 필요합니다.

## 학습 체크
- 문자와 숫자 사이의 곱셈 관계를 정확히 이해하고 있는가?
- 대입 후 사칙연산의 우선순위를 지켜 계산하였는가?

## 관련 개념
- **문자와 식**: 문자를 사용하여 수량을 나타내는 식을 세우는 기초가 되며, 식의 값을 구하는 과정은 식의 구조를 이해하는 핵심 단계입니다.
