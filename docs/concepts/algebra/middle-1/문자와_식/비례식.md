# 비례식

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
두 비의 값이 같음을 나타내는 식을 비례식이라 하며, 외항의 곱과 내항의 곱이 같다는 성질을 가집니다.

## 본문
네 수 $a, b, c, d$ (단, $b \neq 0, d \neq 0$)에 대하여 두 비의 값이 같을 때, 즉 $a:b = c:d$를 만족할 때 이를 **비례식**이라고 합니다. 이는 분수 형태인 $\tfrac{a}{b} = \tfrac{c}{d}$로 나타낼 수 있으며, 식의 구성 요소 중 $a$와 $d$를 **외항**, $b$와 $c$를 **내항**이라고 부릅니다.

### 직관과 기하적 의미
비례식은 두 대상의 크기 관계가 일정하게 유지됨을 의미합니다. 예를 들어 지도 축척에서 지도상의 거리와 실제 거리의 비율이 일정하듯, 두 쌍의 양이 동일한 배율로 변화하는 상황을 나타냅니다. 이는 레시피의 재료 비율, 투자 수익률, 닮은 도형의 변의 길이 비 등 일상 속 다양한 상황에서 핵심적인 역할을 합니다.

### 기본 성질
비례식의 가장 중요한 성질은 외항의 곱과 내항의 곱이 같다는 것입니다. 즉, $a:b = c:d$일 때 $ad = bc$가 성립합니다. 이 성질을 이용하면 미지수가 포함된 비례식도 쉽게 해결할 수 있습니다. 예를 들어 $x:3 = 4:6$이라는 식에서 $6x = 12$를 도출하여 $x=2$라는 해를 구할 수 있습니다. 또한 세 수의 비 $a:b:c = 2:3:4$를 $a=2k, b=3k, c=4k$와 같이 상수를 사용하여 표현하는 방식은 복잡한 비례 문제를 해결하는 데 유용합니다.

## 학습 체크
- 비례식에서 외항의 곱과 내항의 곱이 항상 일치하는지 확인했나요?
- 비례식의 각 항이 0이 될 수 없는 조건($b \neq 0, d \neq 0$)을 이해했나요?
- 세 수의 비를 상수를 포함한 식으로 변환하여 문제를 풀 수 있나요?

## 관련 개념
- **방정식과 부등식**: 비례식의 성질을 이용하여 미지수가 포함된 일차방정식을 해결하는 도구로 활용됩니다.
