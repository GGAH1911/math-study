# 동류항

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
문자와 차수가 같은 항

## 본문
동류항(like terms)은 같은 문자가 같은 차수로 나타나는 항을 의미합니다. 즉, 항을 구성하는 문자의 종류가 같고 그 문자의 지수 또한 모두 같아야 합니다. 예를 들어, $2x$와 $5x$, $3x$와 $-7x$는 문자 $x$의 지수가 1로 동일하므로 동류항입니다. 또한 $3x^2$과 $-4x^2$, $2xy$와 $5xy$도 문자와 차수가 일치하므로 동류항에 해당합니다. 반면 $2x$와 $3x^2$은 문자는 $x$로 같지만 차수가 다르기 때문에 동류항이 아닙니다.

### 직관과 기하적 의미
동류항을 구분하는 핵심적인 이유는 동류항끼리만 더하거나 뺄 수 있기 때문입니다. 예를 들어 $3x + 5x$는 같은 종류의 양을 합치는 것과 같아 $8x$로 간단히 계산할 수 있지만, $3x + 2x^2$는 단위 자체가 달라 더 이상 하나로 합칠 수 없습니다. 복잡한 식을 단순하게 정리하기 위해서는 먼저 식 안에서 동류항을 찾아내는 과정이 필수적이며, 이는 방정식을 풀거나 식을 전개하고 인수분해하는 모든 수학적 과정의 가장 기초적인 기술이 됩니다.

### 기본 성질
식을 정리하는 과정은 동류항을 모으는 과정과 같습니다. 식 $2x + 3x^2 - 5x + x^2 + 7$을 예로 들면, 먼저 차수가 같은 항끼리 분류해야 합니다. $x$의 1제곱 항인 $2x$와 $-5x$를 계산하면 $-3x$가 되고, $x$의 2제곱 항인 $3x^2$과 $x^2$을 계산하면 $4x^2$이 됩니다. 마지막으로 상수항인 $7$을 그대로 두면, 최종적으로 정리된 식은 $4x^2 - 3x + 7$이 됩니다. 이처럼 동류항을 이용하면 복잡한 다항식도 매우 간결하게 표현할 수 있습니다.
