# 일차식 연산 규칙

> **정리** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
동류항끼리 계수 가감, 분배법칙

## 본문 (학습 시 채워짐)

### 일차식 연산의 규칙

일차식을 더하고 빼고 곱할 때 따르는 기본 규칙은 두 가지입니다:

1. **동류항 결합 규칙**: 문자와 그 지수가 같은 항(동류항)끼리만 더하고 뺄 수 있습니다. 예를 들어 $3x + 2x = 5x$이지만, $3x + 2y$는 더 이상 간단히 할 수 없습니다.
2. **분배법칙**: 수를 일차식에 곱할 때 각 항에 분배합니다. 즉, $a(b + c) = ab + ac$입니다.

### 유도 및 증명 스케치

동류항을 합칠 수 있는 이유는 수의 기본 성질에서 나옵니다. $x$를 어떤 구체적인 수로 생각하면:
$$3x + 2x = \underbrace{x + x + x}_{\text{3개}} + \underbrace{x + x}_{\text{2개}} = 5x$$

분배법칙도 같은 방식으로 이해할 수 있습니다:
$$2(3x + 4) = (3x + 4) + (3x + 4) = 3x + 3x + 4 + 4 = 6x + 8$$

따라서 $2(3x + 4) = 2 \cdot 3x + 2 \cdot 4$가 성립합니다.

### 의의 및 응용

이 규칙들은 일차방정식과 식의 정리에서 필수입니다:
$$2(x + 3) + 4x - 5 = 2x + 6 + 4x - 5 = 6x + 1$$

분배법칙으로 괄호를 먼저 풀고, 동류항 규칙으로 같은 종류의 항들을 합칩니다. 이 과정을 통해 복잡한 식을 간단히 정리할 수 있고, 방정식을 푸는 기초가 됩니다.

`sympy.expand(2*(x+3) + 4*x - 5)` → $6x + 1$
