# 미지수

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
방정식이나 부등식에서 우리가 구하고자 하는 값을 나타내기 위해 사용하는 문자입니다.

## 본문
미지수(unknown)는 방정식이나 부등식에서 값을 알지 못하는 수를 나타내기 위해 문자로 표기한 것입니다. 보통 $x$, $y$, $a$와 같은 문자를 사용하며, 수학적 문제를 해결할 때 우리가 최종적으로 찾아내야 할 대상이 됩니다. 예를 들어 방정식 $2x + 3 = 7$에서 $x$가 바로 미지수입니다. 미지수는 실수 범위 내에 존재하며, 이 미지수의 구체적인 값을 찾아내는 과정이 곧 방정식을 푸는 과정입니다.

### 직관과 기하적 의미
미지수는 단순히 미스터리한 존재가 아니라, 주어진 조건(방정식)을 만족하는 '아직 발견되지 않은 수'를 의미합니다. 수학은 어떤 조건이 주어졌을 때 그 조건을 만족하는 수가 무엇인지 역으로 추적하여 알아내는 과정입니다. 예를 들어 연립일차방정식 $\begin{cases} x + y = 5 \\ 2x - y = 4 \end{cases}$에서 미지수 $x$와 $y$는 두 식을 동시에 만족해야 합니다. 이를 좌표평면 위에서 해석하면, 두 미지수는 두 직선이 만나는 교점의 좌표 $(3, 2)$에 해당합니다.

### 기본 성질
- 미지수는 특정 방정식 내에서 값을 찾아야 하는 대상입니다.
- 미지수의 개수보다 식의 개수가 적으면 미지수의 값을 하나로 확정할 수 없습니다.
- 방정식 $x^2 - 5x + 6 = 0$의 경우, 미지수 $x$의 값은 $2$ 또는 $3$이 됩니다.

## 학습 체크
- 방정식에서 미지수가 의미하는 바가 무엇인지 설명할 수 있는가?
- 미지수의 개수와 이를 구하기 위해 필요한 방정식의 개수 사이의 관계를 이해하고 있는가?
- 미지수의 값을 구한 후, 원래 식에 대입하여 값이 맞는지 검산할 수 있는가?

## 관련 개념
- **연립일차방정식**: 두 개 이상의 미지수가 포함된 방정식들로, 모든 미지수가 동시에 만족하는 값을 찾는 과정입니다.
