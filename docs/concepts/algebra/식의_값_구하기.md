# 식의 값 구하기

> **예제** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
$2x+3$에 $x=5$ 대입

## 본문 (학습 시 채워짐)

### 문제

다음 식에 주어진 문자의 값을 대입하여 식의 값을 구하시오.

$$2x + 3 \text{일 때, } x = 5$$

### 단계별 풀이

**1단계: 주어진 식과 문자의 값 확인**  
식 $2x + 3$에서 $2x$는 "2 곱하기 $x$"를 의미하고, $x = 5$를 대입해야 합니다.

**2단계: $x = 5$를 식에 대입**  
$x$ 자리에 5를 넣으면:
$$2 \times 5 + 3$$

명확하게 하려면 괄호를 사용할 수 있습니다: $2(5) + 3$

**3단계: 연산 순서에 따라 계산**  
곱셈을 먼저 계산합니다(곱셈과 나눗셈이 덧셈과 뺄셈보다 먼저):
$$2 \times 5 = 10$$

이제 덧셈을 계산합니다:
$$10 + 3 = 13$$

### 답

$$13$$

### 변형/주의

**비슷한 예제:**  
$3y - 2$에 $y = 4$를 대입하면 $3 \times 4 - 2 = 12 - 2 = 10$입니다.

**자주 하는 실수:**  
- $2x$를 "$2 + x$"로 착각하지 않기. 문자 앞의 숫자는 곱하는 것입니다.
- 대입 후 **연산 순서**를 지키기. 곱셈/나눗셈을 먼저, 덧셈/뺄셈을 나중에 계산합니다.
- 음수가 나올 수도 있습니다. 예를 들어 $2x - 10$에 $x = 2$를 대입하면 $4 - 10 = -6$입니다.

**검증:** `2*5 + 3 = 13` ✓
