### 정확한 진술

**밑 변환 공식(change of base formula)**은 한 로그를 다른 밑의 로그로 표현하는 공식입니다.

$$\log_a b = \frac{\log_c b}{\log_c a}$$

단, $a, b > 0$이고 $a \neq 1$, $c > 0$, $c \neq 1$입니다. 특히 상용로그($c = 10$) 또는 자연로그($c = e$)로 변환하면:

$$\log_a b = \frac{\log b}{\log a} = \frac{\ln b}{\ln a}$$

### 직관 및 기하적 의미

로그의 정의 $a^x = b$에서 양변에 밑 $c$의 로그를 취하면:
$$\log_c(a^x) = \log_c b$$
$$x \log_c a = \log_c b$$
$$x = \frac{\log_c b}{\log_c a}$$

즉, $x = \log_a b$이므로 공식이 유도됩니다. 이는 **같은 수량을 다른 단위로 표현하는 것**과 같습니다. 예를 들어 거리를 킬로미터로 재는 것과 마일로 재는 것처럼, 로그도 측정하는 밑의 '크기'에 따라 값이 달라집니다.

### 한 줄 예

$\log_2 32 = \frac{\ln 32}{\ln 2} \approx \frac{3.466}{0.693} = 5$ 
(검산: $2^5 = 32$ ✓, sympy: `log(32, 2)`)

**핵심 활용**: 계산기에 일반적인 $\log_{10}$나 $\ln$만 있을 때 임의의 밑에 대한 로그값을 구할 수 있고, 미분·적분·지수방정식을 풀 때 로그를 자연로그로 통일하여 계산을 단순화합니다.
