# 다중근

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항방정식에서 동일한 값을 근으로 가질 때, 그 근이 나타나는 중복된 횟수를 의미합니다.

## 본문
다중근(重根)은 다항방정식이 같은 값을 근으로 가질 때, 그 근의 중복된 횟수를 나타냅니다. 더 정확히 말하면, 다항식 $P(x)$를 인수분해했을 때 $(x-a)^n$ 형태의 인수가 나타나면, $x=a$는 $n$중근($n$-fold root)이라고 합니다. 예를 들어, $(x-2)^3(x+1) = 0$에서 $x=2$는 3중근이며, $x=-1$은 단순근(1중근)입니다. 또한 $x^2 - 4x + 4 = 0$은 $(x-2)^2 = 0$으로 인수분해되므로 $x=2$는 2중근이 됩니다. 다항식의 차수와 중복도를 포함한 근의 개수는 항상 일치합니다. 예를 들어 3차 방정식 $x^3 - x^2 + ax + b = 0$의 근을 중복도를 포함하여 세면 반드시 3개가 됩니다.

### 직관과 기하적 의미
함수 $y = P(x)$의 그래프에서 단순근은 $x$축과 한 번 만나거나 지나갑니다. 반면 짝수 중복도의 근(2중근, 4중근 등)은 $x$축에 접하며, $x$축을 뚫고 지나가지 않습니다. 홀수 중복도의 근(3중근, 5중근 등)은 $x$축과 만나면서 접선의 성질을 유지하며 지나갑니다. 인수분해 관점에서 인수의 지수가 클수록 해당 근 근처에서 함숫값은 0에 매우 가깝게 유지되는 특성을 보입니다.

### 기본 성질
- 다항식의 차수는 중복도를 포함한 모든 근의 개수와 항상 같습니다.
- 중복도가 짝수인 근은 그래프가 $x$축에 접하며 반대 방향으로 돌아옵니다.
- 중복도가 홀수인 근은 그래프가 $x$축을 뚫고 지나가며 접하는 형태를 보입니다.

## 학습 체크
- 어떤 방정식의 근이 $x=a$일 때, $(x-a)^2$을 인수로 가지는지 어떻게 확인할 수 있는가?
- 그래프가 $x$축에 접할 때, 그 지점의 근은 홀수 중복근인가 짝수 중복근인가?

## 관련 개념
