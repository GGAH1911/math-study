# 인수정리

> **정리** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
$f(a)=0$이면 $(x-a)$는 $f(x)$의 인수이다.

## 본문
다항식 $f(x)$와 실수 $a$에 대하여, $f(a)=0$이라는 조건과 $(x-a)$가 $f(x)$의 인수라는 조건은 서로 동치입니다. 즉, $x=a$가 다항식 $f(x)$의 근이면 $f(x)$는 $(x-a)$를 인수로 가지며, 반대로 $(x-a)$가 $f(x)$의 인수로 존재한다면 $f(a)=0$을 만족합니다. 이를 기호로 나타내면 $f(a)=0 \Leftrightarrow (x-a) \mid f(x)$입니다.

### 증명 스케치
나머지 정리에 의해 다항식 $f(x)$를 $(x-a)$로 나눈 몫을 $q(x)$, 나머지를 $r$이라고 하면 $f(x) = (x-a)q(x) + r$이며, 이때 $r = f(a)$입니다.

먼저 $f(a)=0$인 경우를 살펴보면, $f(x) = (x-a)q(x) + 0$이 되어 $f(x) = (x-a)q(x)$로 나타낼 수 있으므로 $(x-a)$는 $f(x)$의 인수가 됩니다. 반대로 $(x-a)$가 $f(x)$의 인수라면 $f(x) = (x-a)q(x)$로 쓸 수 있고, 양변에 $x=a$를 대입하면 $f(a) = (a-a)q(a) = 0$이 성립합니다.

### 의의와 응용
인수정리는 다항식의 근과 인수를 일대일로 연결해 주는 핵심적인 도구입니다. 특정 값을 대입했을 때 $0$이 되는 값을 찾아내면, 그 값을 이용해 다항식을 간단하게 인수분해할 수 있습니다. 예를 들어 $f(x) = x^2 - 5x + 6$에서 $f(2)=0$임을 알면 $(x-2)$를 인수로 가짐을 알 수 있고, 이를 통해 $f(x) = (x-2)(x-3)$과 같이 인수분해할 수 있습니다. 또한 이 정리를 확장하면 $n$차 다항식은 최대 $n$개의 실근을 가진다는 성질을 도출할 수 있어 다항식의 구조를 파악하는 데 매우 중요합니다.

## 학습 체크

- 주어진 다항식에 적절한 값을 대입하여 인수를 찾아내고 인수분해를 수행할 수 있는가?
