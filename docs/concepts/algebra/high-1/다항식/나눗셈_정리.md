# 나눗셈 정리

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항식 $f(x)$를 $g(x)$로 나눌 때, 몫 $q(x)$와 나머지 $r(x)$는 $f(x) = g(x)q(x) + r(x)$를 만족하며, 이때 나머지의 차수는 나누는 식의 차수보다 작거나 나머지가 $0$이어야 합니다.

## 본문
다항식 $f(x)$를 영이 아닌 다항식 $g(x)$로 나눌 때, 다음을 만족하는 다항식 $q(x)$(몫)와 $r(x)$(나머지)가 유일하게 존재합니다.
$$f(x) = g(x) \cdot q(x) + r(x)$$
이때 $r(x) = 0$ 이거나 $\deg(r) < \deg(g)$ 입니다. 즉, 나머지의 차수는 항상 나누는 다항식의 차수보다 작아야 합니다.

### 직관과 기하적 의미
정수의 나눗셈 원리와 동일하게 다항식에서도 나눗셈이 가능합니다. 정수 $17$을 $5$로 나누어 몫 $3$과 나머지 $2$를 얻는 것($17 = 5 \times 3 + 2$)처럼, 다항식도 세로 나눗셈을 통해 몫과 나머지를 구할 수 있습니다. 여기서 나머지의 차수가 나누는 식보다 낮아야 한다는 조건은, 더 이상 나눗셈을 진행할 수 없는 상태를 의미합니다.

### 기본 성질
이 정리는 다항식의 구조를 파악하는 데 핵심적인 역할을 합니다. 특히 나머지가 $0$이 되는 경우, 나누는 식 $g(x)$는 $f(x)$의 인수가 됩니다. 이는 이후 학습할 인수정리 및 다항식의 인수분해와 직접적으로 연결되는 중요한 성질입니다.

**예시**
$f(x) = x^3 + 2x + 1$을 $g(x) = x + 1$로 나누면 다음과 같습니다.
$$x^3 + 2x + 1 = (x+1)(x^2 - x + 3) - 2$$
여기서 몫 $q(x) = x^2 - x + 3$이며, 나머지 $r(x) = -2$입니다. 나머지의 차수(0)가 나누는 식의 차수(1)보다 작으므로 나눗셈 정리를 만족합니다.

## 학습 체크
- $r(x)=0$이거나 $\deg(r) < \deg(g)$라는 조건을 정확히 이해하고 있는가?
- 주어진 다항식을 직접 나누어 몫과 나머지를 구할 수 있는가?
- 나머지가 $0$일 때 $g(x)$가 $f(x)$의 인수가 된다는 사실을 이용할 수 있는가?

## 관련 개념
- **다항식**: 나눗셈의 대상이 되는 식이며, 나눗셈 정리를 통해 식의 구조를 분해할 수 있습니다.
