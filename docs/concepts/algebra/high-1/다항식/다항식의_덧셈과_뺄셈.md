# 다항식의 덧셈과 뺄셈

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항식의 덧셈과 뺄셈은 차수와 문자가 같은 동류항끼리 계수를 계산하여 수행하는 연산입니다.

## 본문
다항식의 덧셈과 뺄셈은 **동류항**(차수가 같고 같은 문자를 포함한 항)끼리만 계수를 더하거나 빼는 연산입니다. 두 다항식 $P(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$과 $Q(x) = b_mx^m + b_{m-1}x^{m-1} + \cdots + b_1x + b_0$에 대하여, 덧셈 $P(x) + Q(x)$는 각 차수별로 같은 차수 항의 계수를 모두 더하여 얻은 다항식이며, 뺄셈 $P(x) - Q(x)$는 각 차수별로 같은 차수 항의 계수를 모두 빼서 얻은 다항식입니다. 이때 동류항이 아닌 항들(예: $3x^2$와 $5x$)은 어떤 연산에서도 결합되지 않고 그대로 유지됩니다.

예를 들어 $(3x^2 + 2x - 1) + (x^2 - 5x + 4)$를 계산하면, $x^2$ 항은 $3+1=4$, $x$ 항은 $2+(-5)=-3$, 상수항은 $-1+4=3$이 되어 $4x^2 - 3x + 3$이라는 결과를 얻습니다. 뺄셈의 경우 $(2x^3 - 4x + 5) - (x^3 + 3x^2 - 2x + 1)$을 계산하면 $x^3 - 3x^2 - 2x + 4$가 됩니다.

### 직관과 기하적 의미
다항식을 차수별 계수의 수열로 생각하면, 덧셈과 뺄셈은 **벡터 연산**과 정확히 같습니다. 예를 들어 $2x^2 + 3x + 1$을 계수 벡터 $(2, 3, 1)$로 표현할 수 있으며, 다른 다항식의 계수 벡터와 연산할 때 대응되는 성분끼리만 계산합니다. 함수의 관점에서는 $[P + Q](x) = P(x) + Q(x)$가 성립하여 다항식의 덧셈이 함숫값의 덧셈과 일치하며, 이는 다항식의 집합이 연산에 대해 닫혀 있음을 의미합니다.

### 기본 성질
- 덧셈은 교환법칙과 결합법칙이 성립합니다.
- 다항식의 덧셈과 뺄셈 결과는 항상 다항식이 됩니다.

## 학습 체크
- 연산을 수행할 때 차수가 다른 항을 서로 더하거나 빼는 실수를 하지 않았는가?
- 뺄셈을 할 때 뒤에 오는 다항식의 모든 항의 부호를 바꾸어 계산하였는가?

## 관련 개념
- **다항식**: 덧셈과 뺄셈 연산이 이루어지는 대상이며, 항들의 합으로 구성된 식입니다.
