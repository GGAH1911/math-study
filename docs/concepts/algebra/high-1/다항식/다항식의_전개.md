# 다항식의 전개

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 정확한 진술

다항식의 전개는 두 개 이상의 다항식을 곱한 형태를 분배법칙을 이용하여 동류항끼리 모아서 하나의 다항식으로 나타내는 과정입니다. 예를 들어, $(x + 1)(x + 2)$를 전개하면 각 항을 모두 곱한 후 정리하여 $x^2 + 3x + 2$로 나타냅니다. 일반적으로 $n$개의 다항식을 곱한 결과도 다항식이 되며, 최종 형태는 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ (단, $a_i$는 상수) 형태입니다.

## 직관/기하적 의미

다항식의 전개는 복잡한 곱셈 구조를 단순한 합의 형태로 정리하는 것으로, 계산을 효율적으로 만듭니다. 기하적으로는 두 선분의 길이 $(x + a)$와 $(x + b)$를 곱할 때, 만든 직사각형의 넓이를 더 작은 직사각형들로 분할하여 모두 더하는 것과 같습니다. 전개된 형태는 다항식 방정식을 풀거나 인수분해의 역과정으로도 활용되며, 함수의 성질을 분석할 때 각 항의 계수 정보를 직관적으로 파악할 수 있게 합니다.

## 한 줄 예

$(x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6$

분배법칙으로 첫 번째 다항식의 각 항($x, 2$)에 두 번째 다항식 전체를 곱한 후 동류항을 정리합니다. 예: `sympy.expand((x + 2) * (x - 3))`는 $x^2 - x - 6$을 반환합니다.
