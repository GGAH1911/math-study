# 다항식의 전개

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
두 개 이상의 다항식을 곱할 때 분배법칙을 사용하여 동류항을 정리함으로써 하나의 다항식 형태로 나타내는 과정입니다.

## 본문
다항식의 전개는 두 개 이상의 다항식을 곱한 형태를 분배법칙을 이용하여 동류항끼리 모아서 하나의 다항식으로 나타내는 과정입니다. 예를 들어, $(x + 1)(x + 2)$를 전개하면 각 항을 모두 곱한 후 정리하여 $x^2 + 3x + 2$로 나타냅니다. 일반적으로 $n$개의 다항식을 곱한 결과도 다항식이 되며, 최종 형태는 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ (단, $a_i$는 상수) 형태를 띠게 됩니다.

### 직관과 기하적 의미
다항식의 전개는 복잡한 곱셈 구조를 단순한 합의 형태로 정리하여 계산을 효율적으로 만듭니다. 기하적으로는 두 선분의 길이 $(x + a)$와 $(x + b)$를 곱할 때, 만들어지는 직사각형의 넓이를 더 작은 직사각형들의 넓이의 합으로 분할하여 구하는 것과 같습니다. 또한 전개된 형태는 다항식 방정식을 풀거나 인수분해의 역과정으로 활용되며, 함수의 성질을 분석할 때 각 항의 계수 정보를 직관적으로 파악할 수 있게 돕습니다.

### 기본 성질
- 분배법칙을 통해 각 항을 차례대로 곱한 후 동류항을 결합합니다.
- 전개된 결과물은 항상 다항식의 형태를 유지합니다.
- $(x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6$과 같이 계산됩니다.

## 학습 체크
- 분배법칙을 적용할 때 모든 항이 빠짐없이 곱해졌는지 확인했는가?
- 곱셈 결과에서 차수가 같은 항(동류항)끼리 정확히 계산하여 정리했는가?
- 기하학적 모델에서 직사각형의 넓이 합이 전개식의 결과와 일치하는지 이해했는가?

## 관련 개념
- **다항식**: 전개의 대상이 되는 기본 단위이며, 전개 결과물 또한 다항식의 일종입니다.
- **인수분해**: 다항식의 전개와 반대되는 과정으로, 하나의 다항식을 곱의 형태로 분해하는 것입니다.
- **분배법칙**: 다항식의 전개를 수행하기 위해 각 항에 대해 적용해야 하는 핵심 연산 원리입니다.
