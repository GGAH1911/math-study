# 미정계수

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항식의 계수 중 값이 정해지지 않은 문자를 미정계수라 하며, 이를 결정하는 과정을 미정계수법이라 합니다.

## 본문
미정계수(undetermined coefficient)는 다항식이나 등식에서 아직 값이 정해지지 않은 문자 계수를 의미합니다. 주로 $A, B, C$와 같은 대문자나 $a, b, c$와 같은 소문자로 나타내며, 주어진 식의 조건을 만족하도록 이 값들을 찾아내는 과정을 미정계수법이라고 합니다. 예를 들어 $x^3 + 2x^2 - 5x - 6 = (x+1)(x^2 + Ax + B)$와 같은 식에서 $A$와 $B$가 바로 미정계수에 해당합니다.

### 직관과 기하적 의미
미정계수법은 결과물의 형태를 미리 가정하고 빈칸을 채워나가는 역방향 전략입니다. 이는 목표하는 형태를 알고 있을 때, 부족한 정보를 채워 넣는 구성적 사고를 바탕으로 합니다. 즉, 문제의 최종 구조를 먼저 설정한 뒤 세부적인 수치를 결정해 나가는 방식입니다.

### 기본 성질
- **항등식의 성질 활용**: 등식의 양변이 모든 변수에 대해 항상 성립해야 한다는 성질을 이용하여 계수를 비교합니다.
- **계수 비교법**: 식을 전개하여 좌변과 우변의 동차항 계수를 각각 비교함으로써 미정계수의 값을 결정합니다.

## 학습 체크
- 식을 전개했을 때 좌변과 우변의 각 차수의 계수가 일치해야 한다는 점을 이해하고 있는가?
- 미정계수를 설정할 때 식의 구조(인수 형태 등)를 올바르게 가정하였는가?

## 관련 개념
- **인수분해**: 다항식이 특정 인수의 곱으로 나타날 것이라고 예상될 때, 미정계수를 설정하여 각 인수의 계수를 결정하는 방식으로 활용됩니다.
- **항등식**: 양변의 계수가 모두 같아야 한다는 성질을 이용하여 미정계수의 값을 구하는 근거가 됩니다.
