# 계수 비교법

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
두 다항식이 모든 $x$에 대하여 같을 때, 대응하는 동류항의 계수와 상수항이 서로 같음을 이용하여 미지수를 결정하는 방법입니다.

## 본문
두 다항식 $f(x)$와 $g(x)$에 대하여 모든 실수 $x$에서 $f(x) = g(x)$가 성립하면, $f(x)$와 $g(x)$의 같은 차수의 항의 계수와 상수항이 각각 서로 같습니다. 즉, $ax^2 + bx + c = a'x^2 + b'x + c'$가 항등식이라면 $a=a'$, $b=b'$, $c=c'$가 성립합니다. 이 방법은 다항식의 구조를 분석하여 미지수를 결정할 때 매우 유용하며, 고등학교 1학년 수학의 항등식 단원에서 문제를 해결하는 핵심적인 도구로 사용됩니다.

### 직관과 기하적 의미
함수 $y=f(x)$와 $y=g(x)$의 그래프가 모든 $x$ 값에 대해 완전히 일치한다는 것은, 두 식을 구성하는 각 항의 크기가 동일해야 함을 의미합니다. 즉, 그래프가 겹쳐져 있으려면 각 차수의 계수가 일치하여 동일한 곡선(또는 직선)의 형태를 그려야 합니다.

### 기본 성질
항등식의 성질에 따라 좌변과 우변의 차수가 같아야 하며, 각 차수의 계수끼리 비교하여 연립방정식을 세울 수 있습니다. 예를 들어 $a(x+1) + b(x-1) = 3x + 1$과 같은 식에서 좌변을 전개하여 $(a+b)x + (a-b) = 3x + 1$로 정리하면, $x$의 계수인 $a+b=3$과 상수항인 $a-b=1$을 통해 $a=2, b=1$이라는 결과를 얻을 수 있습니다.
