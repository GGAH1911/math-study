# 계수 비교법

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

두 다항식이 항등식으로 같을 때, 동류항의 계수끼리 같다고 놓아 미지수를 결정하는 방법입니다. 고1 다항식 단원에서 항등식 문제 해결의 핵심 도구입니다.

## 정의

두 다항식 $f(x)$와 $g(x)$에 대하여 모든 실수 $x$에서 $f(x) = g(x)$가 성립하면, $f(x)$와 $g(x)$의 같은 차수의 항의 계수와 상수항이 각각 서로 같습니다. 즉,
$$ax^2 + bx + c = a'x^2 + b'x + c' \iff a=a',\ b=b',\ c=c'.$$

## 예시

항등식 $a(x+1) + b(x-1) = 3x + 1$에서 $a, b$를 구해 봅니다. 좌변을 정리하면 $(a+b)x + (a-b) = 3x + 1$이므로 계수를 비교하여 $a+b = 3$, $a-b = 1$. 따라서 $a = 2$, $b = 1$입니다.
