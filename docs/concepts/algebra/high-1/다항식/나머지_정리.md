# 나머지 정리

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항식 $f(x)$를 일차식 $(x-a)$로 나눈 나머지는 복잡한 나눗셈 과정 없이 함수값 $f(a)$를 계산함으로써 간단히 구할 수 있습니다.

## 본문
다항식 $f(x)$를 일차식 $(x-a)$로 나눈 나머지는 $f(a)$입니다. 임의의 다항식 $f(x)$에 대하여 $f(x) = (x-a)Q(x) + r$이라는 등식이 성립하며, 여기서 $Q(x)$는 몫을 나타내는 다항식이고 $r$은 나머지입니다. 이때 나누는 식이 일차식이므로 나머지는 반드시 상수여야 하며, 이 상수가 바로 $f(a)$의 값과 일치하게 됩니다.

### 직관과 기하적 의미
나머지가 왜 $f(a)$가 되는지는 식에 직접 $x=a$를 대입해 보면 명확해집니다. $f(a) = (a-a)Q(a) + r$이 되는데, 이때 $(a-a)$가 $0$이 되므로 $Q(a)$의 값과 상관없이 식은 $f(a) = r$이라는 결론에 도달합니다. 이는 나머지를 구하기 위해 번거로운 다항식의 나눗셈을 수행할 필요 없이, 함수에 특정 값을 대입하는 것만으로도 결과를 얻을 수 있다는 강력한 도구가 됩니다. 기하학적으로는 함수 $y=f(x)$의 그래프에서 $x=a$인 지점의 $y$좌표가 곧 나머지가 됩니다.

### 기본 성질
$f(x) = x^3 - 2x^2 + x - 5$를 $(x-1)$로 나눈 나머지를 구할 때, 직접 나눗셈을 하지 않고도 $f(1) = 1 - 2 + 1 - 5 = -5$임을 통해 나머지가 $-5$임을 즉시 알 수 있습니다.

## 학습 체크
- 나누는 식이 $(x-a)$가 아닌 $(ax+b)$ 형태일 때, $x$에 어떤 값을 대입해야 나머지를 구할 수 있는가?
- 나머지 정리를 이용하여 다항식의 미지수를 결정할 때, 식의 구조를 어떻게 활용할 것인가?

## 관련 개념
- **다항식**: 나머지 정리는 다항식의 나눗셈 원리를 바탕으로 하며, 다항식의 구조를 단순화하여 계산을 돕습니다.
