# 나머지 정리

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 정확한 진술

다항식 $f(x)$를 일차식 $(x-a)$로 나눈 나머지는 $f(a)$이다.

더 정확히 말하면, 임의의 다항식 $f(x)$에 대해 다음 등식이 항상 성립합니다:

$$f(x) = (x-a)Q(x) + r$$

여기서 $Q(x)$는 몫의 다항식이고, $r$은 나머지입니다. $(x-a)$로 나눈 나머지는 $(x-a)$보다 차수가 낮아야 하므로 상수이며, 이 나머지가 정확히 $f(a)$입니다.

## 직관/기하적 의미

나머지가 왜 $f(a)$일까요? 위의 등식 $f(x) = (x-a)Q(x) + r$에 $x=a$를 대입하면:

$$f(a) = (a-a)Q(a) + r = 0 \cdot Q(a) + r = r$$

따라서 $r = f(a)$입니다. 이것은 간단하면서도 강력한 결과로, 나머지를 구하기 위해 복잡한 다항식 나눗셈을 직접 할 필요 없이 함수값 $f(a)$만 계산하면 된다는 뜻입니다.

기하학적으로는 $y=f(x)$의 그래프에서 직선 $x=a$와 만나는 점의 $y$좌표, 즉 $f(a)$가 곧 나머지입니다.

## 한 줄 예

$f(x) = x^3 - 2x^2 + x - 5$를 $(x-1)$로 나눈 나머지는 $f(1) = 1 - 2 + 1 - 5 = -5$입니다.
