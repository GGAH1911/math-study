# 다항정리

## 정확한 진술

$n$개의 변수 $a_1, a_2, \ldots, a_k$에 대해, 다항정리는 다음을 말합니다:

$$\left( a_1 + a_2 + \cdots + a_k \right)^n = \sum_{n_1 + n_2 + \cdots + n_k = n} \frac{n!}{n_1! \, n_2! \, \cdots \, n_k!} \, a_1^{n_1} a_2^{n_2} \cdots a_k^{n_k}$$

여기서 합은 음이 아닌 정수 $n_1, n_2, \ldots, n_k$의 모든 조합에 대해 이루어지고, 계수 $\frac{n!}{n_1! \, n_2! \, \cdots \, n_k!}$는 **다항계수(multinomial coefficient)**라 합니다.

## 직관과 의미

다항정리는 **이항정리의 일반화**입니다. 두 항이 아닌 여러 항을 거듭제곱할 때, 각 항에서 몇 개씩 선택하는 모든 경우의 수를 센 것입니다.

$(a_1 + a_2 + \cdots + a_k)^n$을 전개할 때, $a_1$을 $n_1$번, $a_2$를 $n_2$번, ..., $a_k$를 $n_k$번 선택하는 방법의 개수가 다항계수 $\frac{n!}{n_1! \, n_2! \, \cdots \, n_k!}$입니다. 이는 $n$개의 자리에 같은 종류끼리 구별하지 않는 배열의 개수를 세는 중복순열입니다.

예를 들어, $(x+y+z)^2$를 전개할 때:
- $x$를 2번: 1가지 ($x^2$)
- $x$를 1번, $y$를 1번: $\frac{2!}{1!1!} = 2$가지 (순서 고려)
- 기타 조합들...

## 한 줄 예

$(x+y+z)^2 = x^2 + y^2 + z^2 + 2xy + 2xz + 2yz$
  
`sympy.expand((x + y + z)**2)` 검증 가능.
