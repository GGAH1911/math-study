# 미지상수 결정

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 정확한 진술

다항식에서 **미지상수**(未知常數)란 값이 주어지지 않은 미정 상수입니다. **미지상수 결정**이란 주어진 조건(인수분해 꼴, 특정값, 나머지 등)을 이용하여 이 상수의 정확한 값을 찾는 과정입니다.

예를 들어 "$P(x) = x^2 + ax + b$가 $(x - 1)(x - 2)$로 인수분해된다"는 조건이 있으면, $a$와 $b$는 미지상수이고, 이들 값을 구하는 것이 미지상수 결정입니다.

## 직관 및 기하적 의미

다항식은 자유도를 갖는 식입니다. 예를 들어 2차 다항식 $x^2 + ax + b$는 계수 $a, b$에 따라 무수히 많은 서로 다른 함수를 나타냅니다. 그런데 "근이 1과 2이다"처럼 **제약 조건**이 주어지면, 가능한 다항식의 개수가 확 줄어듭니다. 미지상수 결정은 이런 제약 조건들을 '식'으로 변환해서, 연립방정식을 풀어 상수의 정확한 값을 구하는 기술입니다.

기하학적으로는, 다항식의 그래프가 특정 점을 지나거나 특정 값을 가져야 한다는 조건으로 이해할 수 있습니다.

## 일반적 풀이 전략

**계수 비교법**: $(x - 1)(x - 2) = x^2 - 3x + 2$를 전개하고, $x^2 + ax + b$와 계수를 비교하면 $a = -3, b = 2$.

**대입법**: $P(1) = 0, P(2) = 0$이라는 두 식을 세우고 $a, b$를 구하기.

$$P(1) = 1 + a + b = 0 \implies a + b = -1$$
$$P(2) = 4 + 2a + b = 0 \implies 2a + b = -4$$

두 식을 빼면 $a = -3$, 따라서 $b = 2$.

## 한 줄 예

$f(x) = 2x^2 + px + q$가 $x = 3$과 $x = 1$을 근으로 가질 때, $f(3) = 0$과 $f(1) = 0$을 이용해 미지상수 $p = -8, q = 6$을 결정할 수 있습니다. (검증: `sympy.solve([2*9 + 3*p + q, 2 + p + q], [p, q])`)
