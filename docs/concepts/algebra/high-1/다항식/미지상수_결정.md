# 미지상수 결정

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
주어진 조건(인수, 특정 값, 나머지 등)을 활용하여 다항식에 포함된 알 수 없는 상수 값을 찾아내는 과정입니다.

## 본문
다항식에서 **미지상수**(未知常數)란 값이 확정되지 않은 상수를 의미합니다. **미지상수 결정**이란 다항식이 특정 인수를 갖는다거나, 특정 값을 대입했을 때 어떤 결과가 나온다는 등의 제약 조건을 이용하여 이 상수의 정확한 값을 찾아내는 수학적 과정을 말합니다. 예를 들어 $P(x) = x^2 + ax + b$라는 식이 $(x - 1)(x - 2)$로 인수분해된다는 조건이 주어지면, $a$와 $b$는 미지상수가 되며 이들의 값을 구하는 것이 미지상수 결정의 핵심입니다.

### 직관과 기하적 의미
다항식은 계수의 값에 따라 형태가 변하는 자유도를 가진 식입니다. 2차 다항식 $x^2 + ax + b$를 예로 들면, $a$와 $b$의 값에 따라 무수히 많은 그래프가 그려질 수 있습니다. 하지만 "그래프가 특정 점을 지난다"거나 "특정 근을 가진다"와 같은 제약 조건이 주어지면, 가능한 함수의 형태가 하나로 좁혀지게 됩니다. 즉, 미지상수 결정은 주어진 제약 조건을 방정식으로 변환하여 연립방정식을 푸는 과정이며, 기하학적으로는 다항식의 그래프가 특정 지점을 통과하도록 만드는 계수를 찾는 행위와 같습니다.

### 기본 성질
미지상수를 결정하는 대표적인 전략에는 두 가지가 있습니다. 첫째는 **계수 비교법**입니다. 식을 전개한 후 양변의 각 차수의 계수를 서로 비교하여 상수를 찾는 방식입니다. 둘째는 **대입법**입니다. 주어진 조건(예: $x-1$이 인수인 경우 $P(1)=0$)을 식에 직접 대입하여 미지수가 포함된 방정식을 만들어 푸는 방식입니다.

## 학습 체크

- 문제에서 주어진 조건이 계수 비교법과 대입법 중 어떤 방식에 더 효율적인지 판단할 수 있는가?
