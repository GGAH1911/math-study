# 나머지정리

> **정리** · 고1 · 단원: [다항식](/concepts/다항식)
## 요약
$f(x)\div(x-a)$의 나머지 $=f(a)$

## 본문

### 진술 및 가정

다항식 $f(x)$를 일차식 $(x-a)$로 나눈 나머지는 $f(a)$이다. 즉, $f(x) = (x-a)Q(x) + R$의 형태로 나타낼 때 (여기서 $Q(x)$는 몫, $R$은 나머지), 다음이 성립한다.

$$R = f(a)$$

나머지는 항상 상수이다. 왜냐하면 $(x-a)$가 일차식이므로, 나눗셈을 진행할 때 나머지의 차수는 일차식 차수보다 작아야 하기 때문이다.

### 증명 스케치

나머지 정리는 다항식의 나눗셈 정의에서 직접 따라온다. $f(x)$를 $(x-a)$로 나눈 몫을 $Q(x)$, 나머지를 $R$이라 하면:

$$f(x) = (x-a)Q(x) + R$$

이 식은 모든 $x$ 값에 대해 성립한다. 특별히 $x=a$를 대입하면:

$$f(a) = (a-a)Q(a) + R = 0 \cdot Q(a) + R = R$$

따라서 $R = f(a)$이다. 이것이 바로 나머지 정리의 핵심이다.

### 의의와 응용

나머지 정리의 가장 큰 의미는 **직접 계산 없이 나머지를 빠르게 구할 수 있다**는 것이다. 복잡한 다항식 나눗셈을 할 필요 없이, 단지 $x=a$를 다항식에 대입하면 된다.

예를 들어, $f(x) = 2x^3 + 5x - 7$을 $(x-2)$로 나눈 나머지는 $f(2) = 2(8) + 5(2) - 7 = 16 + 10 - 7 = 19$이다. (`sympy.div(2*x**3 + 5*x - 7, x - 2)` 또는 `f(2)` 계산)

또한 나머지 정리는 인수정리의 기초가 된다. $(x-a)$로 나눈 나머지가 0이면, 즉 $f(a) = 0$이면 $(x-a)$는 $f(x)$의 인수이다. 이를 통해 다항식의 인수 분해와 근의 관계를 체계적으로 이해할 수 있다.
