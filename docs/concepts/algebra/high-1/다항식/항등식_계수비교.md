# 항등식 계수비교

> **예제** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
항등식의 양변에서 각 차수의 계수가 서로 같음을 이용하여 미지수를 결정하는 방법입니다.

## 본문
다음 항등식을 만족하는 상수 $a$, $b$를 구하시오.
$$(x+2)^2 + a(x+1) + b \equiv x^2 + 5x + 7$$

### 단계별 풀이
**1단계: 좌변을 정리한다**
좌변을 전개하여 동류항끼리 모아 정리합니다.
$$(x+2)^2 + a(x+1) + b = x^2 + 4x + 4 + ax + a + b = x^2 + (4+a)x + (4+a+b)$$

**2단계: 양변의 계수를 비교한다**
항등식이 성립하려면 모든 차수의 계수가 일치해야 하므로, 우변 $x^2 + 5x + 7$과 비교합니다.
- $x^2$의 계수: $1 = 1$
- $x$의 계수: $4+a = 5$
- 상수항: $4+a+b = 7$

**3단계: 연립방정식을 풀이한다**
$4+a=5$에서 $a=1$을 얻고, 이를 상수항 식에 대입하면 $4+1+b=7$이 되어 $b=2$를 얻습니다.

### 답과 변형
**답**
$$a = 1, \quad b = 2$$

**다른 접근: 특수값 대입**
항등식은 모든 $x$에 대해 성립하므로 계산이 편리한 값을 대입할 수 있습니다.
- $x = -1$ 대입: $(1)^2 + a(0) + b = 1 - 5 + 7 \Rightarrow 1 + b = 3 \Rightarrow b = 2$
- $x = 0$ 대입: $(2)^2 + a(1) + b = 7 \Rightarrow 4 + a + 2 = 7 \Rightarrow a = 1$

**주의사항**
항등식은 방정식과 달리 모든 $x$에 대해 성립하는 식임을 유의해야 하며, 계수 비교 시에는 반드시 같은 차수끼리 대응시켜야 합니다.
