# 다항식의 근

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
다항식 $f(x)$의 값을 $0$으로 만드는 값 $\alpha$를 근 또는 영점이라고 하며, 이는 방정식 $f(x)=0$의 해와 같습니다.

## 본문
다항식 $f(x)$에 대하여 $f(\alpha) = 0$을 만족하는 값 $\alpha$를 $f(x)$의 **근** 또는 **영점**이라고 정의합니다. 이는 방정식 $f(x) = 0$을 만족하는 해와 동일한 개념이며, 다항식의 성질을 이해하고 인수분해를 수행하는 데 있어 가장 기초가 되는 핵심 개념입니다.

### 직관과 기하적 의미
기하학적으로 다항함수 $y=f(x)$의 그래프를 그렸을 때, 근 $\alpha$는 그래프가 $x$축과 만나는 지점의 $x$좌표를 의미합니다. 즉, 함수값이 $0$이 되어 $x$축과 교차하거나 접하는 지점이 바로 다항식의 근입니다.

### 기본 성질
인수정리에 의해 다항식 $f(x)$이 $\alpha$를 근으로 가지면, 다항식 $f(x)$은 반드시 $(x - \alpha)$를 인수로 가집니다. 이를 수식으로 나타내면 $f(\alpha) = 0 \iff (x - \alpha) \mid f(x)$입니다. 예를 들어 $f(x) = x^2 - 5x + 6$인 경우, $f(x) = (x - 2)(x - 3)$으로 인수분해되므로 $x=2$와 $x=3$이 근이 됩니다. 실제로 $f(2)=0$과 $f(3)=0$이 성립함을 통해 이를 확인할 수 있습니다.

## 학습 체크
- 다항식 $f(x)$의 근이 $\alpha$일 때, $f(x)$가 $(x - \alpha)$를 인수로 가짐을 설명할 수 있는가?
- 주어진 다항식의 근을 구하기 위해 인수분해를 어떻게 활용할 수 있는가?
- 다항식의 근이 그래프의 $x$축과의 관계에서 어떤 의미를 갖는지 이해하였는가?
