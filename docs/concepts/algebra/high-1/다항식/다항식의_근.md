# 다항식의 근

다항식의 값을 $0$으로 만드는 값을 가리키는 개념으로, 방정식 $f(x) = 0$의 해와 같은 의미입니다. 고1 다항식 단원의 출발점이며 인수분해와 직결됩니다.

## 정의

다항식 $f(x)$에 대하여 $f(\alpha) = 0$이 되는 값 $\alpha$를 $f(x)$의 **근** 또는 **영점**이라 합니다. 이때 인수정리에 의해 $f(x)$는 $(x - \alpha)$를 인수로 가집니다:
$$f(\alpha) = 0 \iff (x - \alpha) \mid f(x).$$

## 예시

$f(x) = x^2 - 5x + 6$의 근을 구해 봅니다. $f(x) = (x - 2)(x - 3)$으로 인수분해되므로 근은 $x = 2$ 또는 $x = 3$입니다. 실제로 $f(2) = 0$, $f(3) = 0$임을 확인할 수 있습니다.
