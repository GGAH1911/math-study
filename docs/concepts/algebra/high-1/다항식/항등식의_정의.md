# 항등식의 정의

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

문자에 어떤 값을 대입하더라도 항상 성립하는 등식을 가리키는 개념입니다. 특정한 값에서만 성립하는 방정식과 구별되며, 고1 다항식 단원에서 계수 비교의 기반이 됩니다.

## 정의

미지수 $x$를 포함한 등식이 $x$가 어떤 실수일 때에도 항상 성립할 때, 이 등식을 $x$에 대한 **항등식**이라 합니다. 예를 들어 $(x+1)^2 = x^2 + 2x + 1$은 모든 실수 $x$에 대해 성립하므로 항등식입니다.

두 다항식 $f(x), g(x)$가 항등식 $f(x) = g(x)$를 이룬다는 것은 동류항의 계수가 모두 같다는 것과 동치입니다.

## 예시

등식 $ax^2 + bx + c = 2x^2 - 3x + 5$가 $x$에 대한 항등식이 되려면 계수를 비교하여 $a = 2$, $b = -3$, $c = 5$이어야 합니다.

반면 등식 $x^2 - 3x + 2 = 0$은 $x = 1$이나 $x = 2$일 때만 성립하므로 항등식이 아니라 방정식입니다.
