# 항등식의 정의

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
문자에 어떤 값을 대입하더라도 항상 성립하는 등식을 항등식이라고 합니다.

## 본문
미지수 $x$를 포함한 등식이 $x$가 어떤 실수일 때에도 항상 성립할 때, 이 등식을 $x$에 대한 **항등식**이라 합니다. 이는 특정한 값에서만 성립하는 방정식과 구별되는 개념으로, 고등학교 1학년 다항식 단원에서 계수 비교를 수행하는 핵심적인 기반이 됩니다. 예를 들어 $(x+1)^2 = x^2 + 2x + 1$은 모든 실수 $x$에 대해 항상 성립하므로 항등식의 대표적인 사례입니다. 반면 $x^2 - 3x + 2 = 0$과 같은 식은 $x = 1$ 또는 $x = 2$라는 특정한 값에서만 성립하므로 항등식이 아닌 방정식으로 분류됩니다.

### 직관과 기하적 의미
항등식은 두 식이 근본적으로 동일한 식임을 나타냅니다. 기하학적으로는 두 함수 $y = f(x)$와 $y = g(x)$의 그래프가 완전히 일치하여 모든 $x$ 값에 대해 같은 $y$ 값을 가짐을 의미합니다.

### 기본 성질
두 다항식 $f(x)$와 $g(x)$가 항등식 $f(x) = g(x)$를 이룬다는 것은 두 식의 차인 $f(x) - g(x) = 0$이 모든 $x$에 대해 성립함을 의미하며, 이는 곧 두 다항식의 동류항 계수가 모두 같다는 것과 동치입니다. 예를 들어 등식 $ax^2 + bx + c = 2x^2 - 3x + 5$가 $x$에 대한 항등식이 되려면 계수를 비교하여 $a = 2$, $b = -3$, $c = 5$여야 합니다.

## 학습 체크
- 주어진 등식이 모든 실수에 대해 성립하는 항등식인지, 아니면 특정 값에서만 성립하는 방정식인지 구분할 수 있는가?
- 두 다항식이 항등식일 때, 각 차수의 계수를 비교하여 미지수의 값을 구할 수 있는가?
