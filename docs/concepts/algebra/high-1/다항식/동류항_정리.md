# 동류항 정리

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
문자와 지수가 완전히 일치하는 항들끼리 계수를 계산하여 식을 단순화하는 과정입니다.

## 본문
다항식에서 **동류항**이란 문자의 종류와 각 문자의 지수가 모두 같은 항들을 의미합니다. 즉, 문자의 구성이 완전히 동일하고 계수만 다른 항들이 서로 동류항에 해당합니다. 예를 들어 $2x^2$과 $5x^2$은 동류항이지만, 지수가 서로 다른 $x^2$과 $x^3$은 동류항이 아닙니다. 또한 $xy^2$과 $x^2y$처럼 차수는 같더라도 문자의 지수 구성이 다르면 동류항이 아닙니다.

### 직관과 기하적 의미
동류항을 정리하는 것은 같은 종류의 물건끼리 분류하여 개수를 세는 것과 같습니다. 사과 3개와 오렌지 2개가 있을 때 이를 '사과 3개, 오렌지 2개'라고 말하는 것처럼, 다항식에서도 같은 종류의 항들만 모아서 하나의 항으로 합칠 수 있습니다. 이러한 원리가 없다면 복잡한 다항식의 덧셈과 뺄셈을 수행할 수 없습니다.

### 기본 성질
동류항끼리는 계수만을 더하거나 빼서 하나의 항으로 합칠 수 있으며, 이를 **동류항 정리**라고 합니다. 일반적인 식은 $ax^n + bx^n = (a+b)x^n$의 형태로 나타낼 수 있습니다. 구체적인 예로 $3x^2 + 5x - 2x^2 + 4x + 7$이라는 식이 있다면, $x^2$ 항은 $3x^2 - 2x^2 = x^2$으로, $x$ 항은 $5x + 4x = 9x$로 정리하여 최종적으로 $x^2 + 9x + 7$이라는 간결한 식을 얻을 수 있습니다. 이때 숫자로만 이루어진 상수항들은 항상 서로 동류항입니다.

## 학습 체크
- $xy^2$과 $x^2y$가 왜 동류항이 아닌지 문자의 지수를 중심으로 설명할 수 있는가?
- 다항식의 덧셈과 뺄셈을 할 때, 문자가 포함되지 않은 상수항은 어떻게 처리해야 하는가?

## 관련 개념
- **다항식**: 여러 개의 항이 덧셈이나 뺄셈으로 연결된 식으로, 동류항 정리를 통해 식을 가장 간단한 형태로 만들 수 있습니다.
