# 이차다항식

## 정확한 진술

이차다항식(quadratic polynomial)은 최고차항이 2차인 다항식입니다. 한 변수 $x$에 대한 이차다항식은 다음과 같이 나타냅니다:

$$P(x) = ax^2 + bx + c \quad (a \neq 0)$$

여기서 $a$는 최고차항의 계수(0이 아님), $b$는 1차 계수, $c$는 상수항입니다. $a = 0$이면 1차 이하 다항식이 되므로, 이차다항식이 되려면 반드시 $a \neq 0$이어야 합니다.

## 직관과 기하적 의미

이차다항식의 그래프는 **포물선**입니다. $a > 0$일 때는 아래로 볼록(∪ 모양)하고, $a < 0$일 때는 위로 볼록(∩ 모양)합니다. 계수 $|a|$의 크기는 포물선의 개방도를 결정합니다.

이차다항식은 수능 수학에서 가장 기초가 되는 개념입니다. 근의 공식, 인수분해, 판별식 $D = b^2 - 4ac$ 등을 통해 방정식의 근의 개수와 부호를 결정하고, 부등식을 푸는 데 필수적입니다. 또한 함수의 최댓값·최솟값 문제와 함수의 변환(평행이동, 대칭이동)에서도 자주 등장합니다.

## 예

$f(x) = x^2 - 4x + 3$은 이차다항식입니다. 인수분해하면 $f(x) = (x-1)(x-3)$이고, 방정식 $f(x) = 0$의 근은 $x = 1, 3$입니다. 

검증: `sympy.solve(x**2 - 4*x + 3, x)` 결과 $[1, 3]$
