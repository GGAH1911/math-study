# 3차 방정식

## 정확한 진술

3차 방정식이란 최고차 항이 3차인 다항식 방정식을 말합니다. 일반형은 다음과 같습니다.

$$ax^3 + bx^2 + cx + d = 0 \quad (a \neq 0)$$

여기서 $a, b, c, d$는 실수 계수이고, 특히 $a \neq 0$이어야만 진정한 3차 방정식입니다. 만약 $a = 0$이면 차수가 내려가므로 2차 이하가 됩니다.

## 직관/기하적 의미

3차 방정식의 근은 함수 $f(x) = ax^3 + bx^2 + cx + d$의 그래프와 $x$축의 교점에 해당합니다. 

3차 함수의 그래프는 다음과 같은 특징을 갖습니다:
- 극댓값과 극솟값을 최대 2개까지 가질 수 있습니다.
- 좌끝과 우끝의 부호가 반대입니다 ($a > 0$이면 좌쪽은 음의 무한대에서, 우쪽은 양의 무한대로).
- **이 성질에 의해 3차 방정식은 항상 최소 1개 이상의 실근을 가집니다.**

실근의 개수는 극값의 위치와 크기에 따라:
- 실근 1개 (극값이 모두 같은 부호 또는 존재하지 않음)
- 실근 2개 (극값 중 하나가 0을 지남)  
- 실근 3개 (극값이 $x$축의 양쪽에 위치)

## 한 줄 예

$x^3 - 6x^2 + 11x - 6 = 0$은 3차 방정식이며, 이 방정식의 근은 $x = 1, 2, 3$입니다.
```python
# sympy.solve(x**3 - 6*x**2 + 11*x - 6, x)  →  [1, 2, 3]
```
