# 미정계수법

> **정의** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
두 다항식이 모든 변수값에 대해 항등적으로 같을 때, 대응하는 각 항의 계수를 비교하여 미지의 계수를 결정하는 방법입니다.

## 본문
두 다항식 또는 식이 모든 변수값에 대해 항등적으로 같으면, 대응하는 각 항의 계수는 모두 같습니다. 이를 이용하여 식에 포함된 미지의 계수를 구하는 방법을 미정계수법이라 합니다. 일반적으로 $P(x) = Q(x)$의 형태를 띠는 식에서 양변을 전개한 후, 같은 차수의 항끼리의 계수를 비교함으로써 미지의 계수들을 결정할 수 있습니다. 예를 들어 $ax^2 + bx + c = 2x^2 - 3x + 5$가 모든 $x$에 대해 성립한다면, 각 항의 계수를 비교하여 $a = 2, b = -3, c = 5$임을 바로 알 수 있습니다.

### 직관과 기하적 의미
두 다항식이 항등적으로 같다는 것은 그래프 상에서 두 함수가 무한히 많은 점에서 일치한다는 것을 의미합니다. 다항식은 유한한 차수를 가진 함수이므로, 모든 $x$값에서 값이 같으려면 각 차수별로 계수가 정확히 일치해야만 합니다. 이는 다항식의 성질과 관련이 있으며, 결과적으로 무한히 많은 등식 조건을 유한개의 선형연립방정식으로 변환하여 문제를 해결할 수 있게 해주는 강력한 도구가 됩니다.

### 기본 성질
- 양변의 차수가 같아야 하며, 전개 후 같은 차수의 항을 비교하는 것이 원칙입니다.
- $(x+1)^2 = x^2 + ax + b$와 같은 식에서 좌변을 전개하면 $x^2 + 2x + 1$이 되므로, 계수 비교를 통해 $a=2, b=1$임을 구할 수 있습니다.
- 부분분수 분해, 다항식의 나눗셈 검증, 수열의 일반항 유도 등 수학 전반에서 광범위하게 활용됩니다.

## 학습 체크
- 두 식의 차수가 다를 때 미정계수법을 적용할 수 있는가?
- 식을 전개하지 않고 특정 값을 대입하여 계수를 구하는 방법과 비교했을 때 어떤 장점이 있는가?
- 계수 비교법을 사용할 때 항의 차수를 정확히 매칭시켰는가?

## 관련 개념
- **인수분해**: 다항식을 일차식들의 곱으로 나타내는 과정에서 미지의 계수를 결정하기 위해 미정계수법이 사용됩니다.
- **항등식**: 미정계수법의 전제가 되는 개념으로, 모든 변수에 대해 식이 항상 성립하는 성질을 의미합니다.
- **연립방정식**: 미정계수법을 통해 도출된 계수 비교 식들은 결국 미지수를 구하기 위한 연립방정식의 형태로 나타납니다.
