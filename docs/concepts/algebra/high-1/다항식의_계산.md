### 정확한 진술

다항식의 계산이란 두 개 이상의 다항식에 대해 덧셈, 뺄셈, 곱셈 등의 연산을 수행하는 것입니다. 핵심은 **동류항(같은 차수의 항)끼리만 계산**한다는 것입니다.

**덧셈과 뺄셈**: 동류항끼리 계수를 더하거나 뺍니다.
$$P(x) + Q(x) = (a_n + b_n)x^n + (a_{n-1} + b_{n-1})x^{n-1} + \cdots + (a_0 + b_0)$$

**곱셈**: 분배법칙을 이용해 각 항을 모두 곱한 후 동류항끼리 합칩니다. 예를 들어
$$(ax + b)(cx + d) = acx^2 + (ad + bc)x + bd$$

### 직관 및 의미

다항식의 계산을 이해하는 가장 좋은 방법은 **문자를 수로 생각하기**입니다. 실제로 $x$에 어떤 값을 대입해도 결과가 같아야 하기 때문에, 같은 차수끼리만 조합해야 합니다. 

동류항을 합치는 이유를 구체적으로 보면, $2x + 3x = 5x$와 같이 같은 "단위"(여기서는 $x$)를 모아서 정리하는 것과 같습니다. 다항식도 마찬가지로 $x^2$의 계수끼리, $x$의 계수끼리 모아서 정리합니다.

곱셈은 분배법칙의 확장으로, $(x+1)(x+2) = x^2 + 3x + 2$처럼 모든 항의 쌍을 곱하고 정리하는 과정입니다. 이를 통해 결과도 다항식이 됨을 알 수 있습니다.

### 한 줄 예

$(2x^2 + 3x - 1) + (x^2 - 2x + 4) = 3x^2 + x + 3$ (동류항끼리 계수를 더함)

$(x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6$ (분배법칙으로 전개 후 동류항 정리)

**검산**: `sympy.expand((x + 2)*(x - 3))` → $x^2 - x - 6$
