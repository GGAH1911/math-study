### 정확한 진술

다항식에서 **동류항**(like terms)이란, 같은 문자를 같은 지수로 포함하는 항들입니다. 즉, 문자 부분이 완전히 같고 계수만 다른 항들을 의미합니다.

예를 들어 $2x^2$과 $5x^2$는 동류항이며, $3xy^2$과 $-7xy^2$도 동류항입니다. 반면 $x^2$과 $x^3$은 지수가 다르므로 동류항이 아닙니다.

### 직관적 의미

다항식을 정리하고 계산할 때, 같은 '종류'의 항들만 합칠 수 있습니다. 이는 마치 사과끼리는 더할 수 있지만 사과와 오렌지를 무분별하게 섞을 수 없는 것과 같은 원리입니다. 동류항의 개념 없이는 다항식의 덧셈, 뺄셈, 정리가 불가능합니다.

동류항을 정리하는 것을 **동류항 정리**(combining like terms)라고 하며, 계수들을 더하거나 빼서 하나의 항으로 만듭니다:

$$ax^n + bx^n = (a+b)x^n$$

### 구체적 예시

다항식 $3x^2 + 5x - 2x^2 + 4x + 7$에서:
- $3x^2$과 $-2x^2$는 동류항 → $(3-2)x^2 = x^2$
- $5x$와 $4x$는 동류항 → $(5+4)x = 9x$
- $7$은 상수항

따라서 정리하면 $x^2 + 9x + 7$입니다.

(`sympy.symbols('x'); expr = 3*x**2 + 5*x - 2*x**2 + 4*x + 7; sympy.expand(expr)`)

### 주의점

여러 문자를 포함하는 다항식에서는 **모든 문자의 지수**가 일치해야 동류항입니다. 예를 들어 $xy^2$과 $x^2y$는 모두 2차 항이지만 동류항이 아닙니다. 또한 상수항(숫자만 있는 항)들끼리는 항상 동류항입니다.
