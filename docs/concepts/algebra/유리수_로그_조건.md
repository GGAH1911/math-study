### 정확한 진술

양수 $a$ ($a \neq 1$)에 대해 $\log_a b$가 유리수가 되기 위한 필요충분조건은, 어떤 정수 $p, q$ (단, $q > 0$, $\gcd(p, q) = 1$)가 존재하여 $a^p = b^q$를 만족하는 것입니다.

즉, $\log_a b = \frac{p}{q}$ ⟺ $a^p = b^q$

이 조건이 없으면 로그 값은 무리수가 됩니다.

### 직관: 특별한 관계를 찾기

로그의 정의 $a^x = b$에서 지수 $x$가 정수라면 당연히 유리수(정수)입니다. 그런데 $x$가 분수 $\frac{p}{q}$일 때는 어떨까요? 

$a^{p/q} = b$를 양변에 $q$제곱하면 $a^p = b^q$가 됩니다. 이것은 **밑 $a$와 진수 $b$가 같은 원시근을 공유**한다는 뜻입니다. 예를 들어 $4 = 2^2$, $8 = 2^3$이면 둘 다 2의 거듭제곱이므로 특별한 관계가 있다는 의미입니다.

반대로 $\log_2 3$이 무리수인 이유는 어떤 정수 지수 $p, q$에 대해서도 $2^p = 3^q$를 만족할 수 없기 때문입니다.

### 핵심 예시

**유리수 로그:**
$$\log_4 8 = \frac{3}{2} \quad \text{(∵ } 4^3 = 64 = 8^2 \text{)}$$

**무리수 로그:**
$$\log_2 3 \text{는 무리수} \quad \text{(∵ 어떤 정수 } p, q\text{에 대해서도 } 2^p \neq 3^q \text{)}$$

검증: `sympy.log(8, 4)` = 1.5 (유리수), `sympy.nsimplify(sympy.log(3, 2))` → 무리수 확인
