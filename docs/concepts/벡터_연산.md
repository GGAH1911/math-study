### 정확한 진술

벡터 연산은 두 벡터 또는 벡터와 실수 사이의 기본적인 계산으로, 세 가지로 정의됩니다.

**덧셈**: 두 벡터 $\vec{a}$, $\vec{b}$에 대해 성분별로 더합니다.
$$\vec{a} + \vec{b} = (a_1 + b_1, a_2 + b_2, a_3 + b_3)$$

**뺄셈**: 벡터 $\vec{b}$를 빼는 것은 그 음벡터를 더하는 것과 같습니다.
$$\vec{a} - \vec{b} = (a_1 - b_1, a_2 - b_2, a_3 - b_3)$$

**스칼라곱(스칼라 배수)**: 실수 $k$와 벡터 $\vec{a}$의 곱은 각 성분에 $k$를 곱합니다.
$$k\vec{a} = (ka_1, ka_2, ka_3)$$

### 직관과 기하적 의미

벡터 덧셈은 **평행사변형 법칙**으로 기하학적으로 나타냅니다. $\vec{a}$의 끝점에서 $\vec{b}$의 시작점을 이동시킨 후 그리면, 원점에서 도착점으로의 화살표가 $\vec{a} + \vec{b}$입니다. 물리적으로는 두 힘을 함께 적용한 결과 방향입니다.

벡터 뺄셈 $\vec{a} - \vec{b}$는 $\vec{a}$에서 $\vec{b}$로 가는 변위 벡터를 나타냅니다.

스칼라곱 $k\vec{a}$는 벡터의 크기를 $|k|$배 확대(또는 축소)하고, $k < 0$이면 반대 방향을 향합니다.
