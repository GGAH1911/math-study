# 전확률공식

## 요약
어떤 사건이 일어날 확률을 구하기 위해, 그 사건을 포함하는 서로소인 사건들의 부분집합으로 나누어 각 부분집합에 대한 조건부 확률을 이용해 계산하는 방법입니다.

## 본문
전확률공식은 표본 공간 $S$가 서로 배반인 사건들 $A_1, A_2, \dots, A_n$으로 분할되어 있을 때, 임의의 사건 $B$가 일어날 확률을 각 부분집합에 대한 조건부 확률의 합으로 나타내는 정리입니다. 즉, $P(B) = \sum_{i=1}^{n} P(A_i \cap B) = \sum_{i=1}^{n} P(A_i)P(B|A_i)$로 정의됩니다. 이는 복잡한 사건 $B$의 확률을 직접 구하기 어려울 때, 발생 가능한 여러 경로(사건 $A_i$)를 통해 $B$가 발생하는 확률을 각각 계산하여 모두 더함으로써 전체 확률을 도출하는 유용한 도구입니다.

### 직관과 기하적 의미
전체 영역을 여러 개의 조각으로 나누었을 때, 우리가 찾고자 하는 영역 $B$가 각 조각 위에 얼마나 걸쳐 있는지를 계산하는 것과 같습니다. 각 조각의 면적에 해당 조각 내에서 $B$가 차지하는 비율을 곱한 값들을 모두 더하면, 결국 전체 영역에서 $B$가 차지하는 총 면적이 된다는 논리입니다.

### 기본 성질
전확률공식이 성립하기 위해서는 사건들의 집합 $\{A_1, A_2, \dots, A_n\}$이 표본 공간을 분할해야 합니다. 즉, 모든 $A_i$는 서로 중복되지 않는 배반 사건이어야 하며, 이들의 합집합은 반드시 전체 표본 공간 $S$가 되어야 합니다.

## 학습 체크
- 사건 $B$가 일어날 확률을 구할 때, 사용된 사건들이 서로 중복되지 않는 배반 사건인지 확인하였는가?
- 각 조건부 확률 $P(B|A_i)$를 계산할 때 분모가 되는 $P(A_i)$가 $0$이 아닌지 확인하였는가?

## 관련 개념
- **통계**: 전확률공식은 베이즈 정리의 분모를 계산하는 핵심 과정으로 사용되며, 데이터의 관측 결과로부터 역확률을 추정하는 통계적 추론의 기초가 됩니다.
