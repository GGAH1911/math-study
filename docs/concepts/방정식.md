# 방정식

> **정의** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
미지수의 값에 따라 참/거짓이 갈리는 등식

## 본문 (학습 시 채워짐)

### 정확한 진술

**방정식**은 미지수를 포함하는 등식으로, 미지수의 모든 값에 대해 참인 것이 아니라 특정한 값들에 대해서만 참이 되는 식입니다. 예를 들어 $x + 3 = 7$은 등식이지만, $x = 4$일 때만 참입니다. 방정식을 참으로 만드는 미지수의 값을 **근(根)** 또는 **해(解)**라고 하며, 이 근을 찾는 과정을 **방정식을 푼다**고 합니다.

### 직관과 의미

방정식은 일상적인 상황에서 미지의 값을 찾을 때 사용됩니다. 항등식(모든 $x$ 값에서 참, 예: $2(x+1) = 2x+2$)과 달리, 방정식은 특정 값에서만 성립합니다. 방정식을 풀 때는 등식의 성질을 이용하여 미지수를 한쪽으로 모아냅니다. 핵심은 "이 등식을 만족하는 미지수는 몇인가?"라는 질문에 답하는 것입니다. 이러한 사고 과정은 미지수로 표현된 미지의 상황을 역으로 추리하는 논리적 능력을 키웁니다.

### 예시

$x + 3 = 7$은 방정식입니다. $x = 1$을 대입하면 $1 + 3 = 4 \neq 7$ (거짓), $x = 4$를 대입하면 $4 + 3 = 7$ (참). 따라서 근은 $x = 4$입니다.

다른 예: $2x = 10$ → $x = 5$, $x - 2 = 8$ → $x = 10$

(검증: `sympy.solve(x + 3 - 7, x)` 결과 `[4]`)
