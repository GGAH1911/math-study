# 곡선과 직선 사이의 넓이

## 요약
곡선과 직선으로 둘러싸인 부분의 넓이는 두 함수의 차를 적분하여 구하며, 이때 두 함수의 상하 관계를 고려하여 절댓값을 취하거나 큰 함수에서 작은 함수를 빼서 계산합니다.

## 본문
곡선 $y=f(x)$와 직선 $y=g(x)$가 두 점 $\alpha$와 $\beta$($\alpha < \beta$)에서 만나서 이루는 부분의 넓이는 $\int_{\alpha}^{\beta} |f(x) - g(x)| dx$로 계산합니다. 즉, 구간 내에서 어떤 함수가 더 위에 있는지에 따라 두 식의 차를 구한 뒤 적분하면 됩니다.

### 직관과 기하적 의미
그래프 상에서 곡선과 직선이 만나는 지점은 두 함수의 함숫값이 같아지는 지점입니다. 이 두 지점 사이에서 곡선이 직선보다 위에 있다면 곡선 식에서 직선 식을 뺀 값이 양수가 되어 넓이가 되고, 반대로 직선이 위에 있다면 직선 식에서 곡선 식을 뺀 값이 양수가 되어 넓이가 됩니다. 따라서 절댓값을 사용하여 두 함수 사이의 간격(높이)을 양수로 만든 뒤 이를 구간에 대해 쌓아 올리는 것이 기하학적인 넓이의 의미입니다.

### 기본 성질
두 함수가 만나는 점을 찾는 것이 계산의 첫 단계이며, 구간 내에서 함수의 대소 관계가 변하는 지점이 있다면 구간을 나누어 각각 적분해야 합니다. 만약 $f(x) \ge g(x)$라면 $\int_{\alpha}^{\beta} (f(x) - g(x)) dx$를 계산하고, $f(x) \le g(x)$라면 $\int_{\alpha}^{\beta} (g(x) - f(x)) dx$를 계산합니다.

## 학습 체크
- 두 곡선 또는 곡선과 직선이 만나는 교점의 좌표를 정확히 구하였는가?
- 주어진 구간 내에서 어떤 함수가 더 큰 값을 가지는지 대소 관계를 확인하였는가?
- 넓이를 구할 때 계산 결과가 음수가 나오지는 않았는가?

## 관련 개념
- **정적분의 활용**: 정적분은 함수의 변화량을 나타내지만, 두 함수의 차를 적분하면 기하학적인 넓이를 구할 수 있습니다.
