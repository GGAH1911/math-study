# 미분계수 정의

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
점에서의 순간변화율

## 본문 (학습 시 채워짐)

### 정확한 정의

함수 $f(x)$가 점 $x = a$를 포함하는 열린 구간에서 정의될 때, 점 $a$에서의 **미분계수**는 다음 극한이 존재하면 그 극한값으로 정의합니다.

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

또는 동치적으로

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

이 극한이 존재할 때 $f$는 $x = a$에서 **미분가능**하다고 하며, 극한값 $f'(a)$를 미분계수라 부릅니다.

### 기하적 의미

미분계수 $f'(a)$는 곡선 $y = f(x)$ 위의 점 $(a, f(a))$에서 그은 **접선의 기울기**입니다. 할선(두 점을 지나는 직선)의 기울기 $\frac{f(a+h) - f(a)}{h}$에서 $h \to 0$이 되면, 두 점이 한 점으로 수렴하여 할선이 접선으로 변하기 때문입니다. 다시 말해, 미분계수는 $x = a$ 근처에서 함수값이 **얼마나 빠르게 변하는지**를 나타내는 순간변화율입니다.

### 간단한 예

$f(x) = 2x + 3$일 때, $x = 1$에서의 미분계수를 구하면

$$f'(1) = \lim_{h \to 0} \frac{(2(1+h) + 3) - (2 \cdot 1 + 3)}{h} = \lim_{h \to 0} \frac{2h}{h} = 2$$

직선은 모든 점에서 기울기가 일정하므로 미분계수가 상수입니다. 다항함수 $f(x) = x^2$인 경우 (sympy: `from sympy import *; x, h = symbols('x h'); limit((x+h)**2 - x**2, h, 0) / h` → 결과는 $2x$), $x = 1$에서의 미분계수는 $f'(1) = 2$입니다.
