# 다항식의 곱셈과 인수분해

> **단원** · 중3 · 선수: [식의 계산](./식의_계산.md) / [실수와 그 계산](./실수와_그_계산.md) · 다음: [다항식](./다항식.md) / [이차방정식](./이차방정식.md)

## 학습 목표
- 곱셈공식을 자유롭게 적용한다
- 공통인수·치환·복부호·근의 공식 역추적으로 인수분해한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 인수, 인수분해

**정리(theorem)**
- 곱셈공식 $(a+b)^2$, $(a+b)(a-b)$, $(x+a)(x+b)$
- 인수분해 공식 $a^2-b^2=(a+b)(a-b)$ 등

**예제(example)**
- $x^2-5x+6$ 인수분해
- 치환 인수분해
- 복잡한 다항식 인수분해
