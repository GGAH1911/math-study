# 방정식의 실근 조건

## 요약
방정식의 실근 조건은 방정식의 해가 실수 범위 내에서 존재하는지를 판별하는 조건으로, 함수의 그래프와 $x$축의 교점의 개수 또는 함수의 극값과 함숫값의 부호를 통해 결정된다.

## 본문
방정식 $f(x)=0$의 실근 조건은 함수 $y=f(x)$의 그래프가 $x$축과 만나는 점이 존재하는지를 확인하는 과정이다. 다항함수의 경우, 함수의 연속성과 미분 가능성을 활용하여 실근의 존재 여부를 판단한다. 특히 이차방정식의 경우에는 판별식 $D$를 사용하여 실근의 존재를 판별하지만, 고차방정식이나 초월함수가 포함된 경우에는 함수의 증감과 극값을 분석하는 것이 필수적이다. 실근이 존재하기 위해서는 함수의 최솟값이 $0$ 이하이거나, 함수의 최댓값이 $0$ 이상이어야 하며, 혹은 함수의 함숫값이 서로 다른 부호를 갖는 구간이 존재해야 한다.

### 직관과 기하적 의미
방정식의 실근은 함수 그래프가 $x$축과 만나는 지점의 $x$좌표를 의미한다. 따라서 실근이 존재한다는 것은 그래프가 $x$축을 통과하거나 접한다는 것을 의미하며, 이는 기하학적으로 함수의 최댓값 또는 최솟값이 $0$을 포함하거나, 함숫값의 부호가 바뀌는 구간이 존재함을 뜻한다.

### 기본 성질
함수 $f(x)$가 연속일 때, $f(a) \cdot f(b) \le 0$이면 사잇값 정리에 의해 $f(c)=0$을 만족하는 $c$가 $a$와 $b$ 사이에 적어도 하나 존재한다. 또한, 함수의 극값이 $0$을 포함하는 경우나 함수의 증감 상태에 따라 실근의 개수가 결정된다.

## 학습 체크
- 함수의 극값의 부호와 $x$축의 위치 관계를 통해 실근의 개수를 판별할 수 있는가?
- 사잇값 정리를 이용하여 특정 구간 내에 실근이 존재함을 증명할 수 있는가?
- 이차방정식의 판별식 외에 고차방정식에서 실근 조건을 찾는 논리적 흐름을 이해하고 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증감과 극값을 분석하여 방정식의 실근의 개수를 결정하는 핵심 도구로 사용된다.
