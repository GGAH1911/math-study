# 인수정리

> **정리** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
$f(a)=0$ ↔ $(x-a)$가 $f(x)$의 인수

## 본문 (학습 시 채워짐)

### 정리의 진술

다항식 $f(x)$와 실수 $a$에 대하여, 다음 두 조건이 동치(동등)입니다:
- $f(a) = 0$ (즉, $x=a$가 $f(x)$의 근)
- $(x-a)$가 $f(x)$의 인수 (즉, $f(x) = (x-a)g(x)$를 만족하는 다항식 $g(x)$가 존재)

따라서 **$f(a)=0 \Leftrightarrow (x-a) \mid f(x)$**

### 증명 스케치 (나머지 정리 이용)

나머지 정리에 의해 $f(x)$를 $(x-a)$로 나눈 나머지는 정확히 $f(a)$입니다:
$$f(x) = (x-a)q(x) + f(a)$$

여기서 $q(x)$는 몫 다항식입니다.

**"⇒" 방향**: $f(a) = 0$이면 우변의 나머지가 0이므로 $f(x) = (x-a)q(x)$이고, 따라서 $(x-a)$는 인수입니다.

**"⇐" 방향**: $(x-a)$가 인수이면 $f(x) = (x-a)q(x)$로 나타낼 수 있고, $x=a$를 대입하면 $f(a) = 0 \cdot q(a) = 0$입니다.

### 의의와 활용

인수정리는 **근과 인수를 일대일 대응**시키는 교량 역할을 합니다.

근을 찾으면 인수분해가 되고, 인수분해가 가능하면 근을 알 수 있습니다. 예를 들어 $f(x) = x^2 - 5x + 6$에서 $f(2) = 4 - 10 + 6 = 0$이므로 $(x-2)$는 인수입니다. 따라서 $f(x) = (x-2)(x-3)$으로 인수분해됩니다. (검산: `from sympy import symbols, factor; x = symbols('x'); factor(x**2 - 5*x + 6)`)

또한 이 정리를 반복 적용하면 **$n$차 다항식은 최대 $n$개의 실근을 가진다**는 중요한 성질도 증명됩니다. 이는 다항식의 구조를 이해하는 데 핵심적입니다.
