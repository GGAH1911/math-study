# 정수론

## 정의

**정수론(Number Theory)** 은 정수의 성질을 연구하는 수학의 한 분야이다. 수능 수학에서 정수론과 관련된 핵심 개념은 **약수와 배수, 소인수분해, 최대공약수(GCD)·최소공배수(LCM), 나머지(합동식)** 등이다. 임의의 두 양의 정수 $a, b$에 대해 $a = bq + r$ ($0 \leq r < b$)를 만족하는 유일한 정수 $q$(몫), $r$(나머지)이 존재한다(나눗셈 알고리즘). 두 수의 $\text{GCD} \times \text{LCM} = a \times b$가 성립한다.

## 예시

$12$와 $18$의 GCD와 LCM을 구하여라.

$$12 = 2^2 \times 3, \quad 18 = 2 \times 3^2$$
$$\text{GCD}(12, 18) = 2^1 \times 3^1 = 6$$
$$\text{LCM}(12, 18) = 2^2 \times 3^2 = 36$$

검산: $6 \times 36 = 216 = 12 \times 18$ ✓
