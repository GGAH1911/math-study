# 정수론

## 요약
정수의 성질을 탐구하는 학문으로, 약수와 배수, 소인수분해, 최대공약수와 최소공배수, 나눗셈의 원리 등을 다룬다.

## 본문
정수론(Number Theory)은 정수의 성질을 연구하는 수학의 한 분야이다. 수능 수학에서 정수론과 관련된 핵심 개념은 약수와 배수, 소인수분해, 최대공약수(GCD)·최소공배수(LCM), 나머지(합동식) 등이다. 임의의 두 양의 정수 $a, b$에 대해 $a = bq + r$ ($0 \leq r < b$)를 만족하는 유일한 정수 $q$(몫)와 $r$(나머지)이 존재하는데, 이를 나눗셈 알고리즘이라고 한다. 또한 두 수의 최대공약수와 최소공배수의 곱은 두 수의 곱과 같다는 $\text{GCD} \times \text{LCM} = a \times b$ 성질이 성립한다.

### 직관과 기하적 의미
정수의 나눗셈은 어떤 수를 일정한 크기로 똑같이 나누었을 때 남는 양을 찾는 과정과 같다. 예를 들어 $12$와 $18$의 관계를 살펴보면, 두 수의 공통된 약수 중 가장 큰 값인 $6$은 두 수를 동시에 나누어떨어지게 하는 단위가 되며, 최소공배수인 $36$은 두 수의 배수 중 가장 먼저 만나는 지점이 된다.

### 기본 성질
두 수의 소인수분해를 통해 최대공약수와 최소공배수를 구할 수 있다. $12 = 2^2 \times 3$이고 $18 = 2 \times 3^2$일 때, 각 소인수의 지수 중 가장 작은 값을 택하면 최대공약수 $\text{GCD}(12, 18) = 2^1 \times 3^1 = 6$이 되고, 가장 큰 값을 택하면 최소공배수 $\text{LCM}(12, 18) = 2^2 \times 3^2 = 36$이 된다. 이때 $6 \times 36 = 216$이며, 이는 $12 \times 18 = 216$과 일치하여 두 성질이 유기적으로 연결됨을 보여준다.

## 학습 체크

- 두 수의 최대공약수와 최소공배수의 곱이 두 수의 곱과 일치하는지 검산하였는가?
