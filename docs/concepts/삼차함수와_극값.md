# 삼차함수와 극값

## 요약
삼차함수의 도함수인 이차함수의 부호 변화를 통해 함수의 증가와 감소, 그리고 극대와 극소를 판정한다.

## 본문
삼차함수 $f(x) = ax^3 + bx^2 + cx + d$ ($a \neq 0$)의 극값은 도함수 $f'(x) = 3ax^2 + 2bx + c = 0$을 만족하는 $x$의 값에서 발생한다. 삼차함수가 극값을 갖기 위해서는 이차방정식 $f'(x) = 0$이 서로 다른 두 실근을 가져야 하며, 이때 도함수의 부호가 양에서 음으로, 또는 음에서 양으로 변하는 지점에서 각각 극대와 극소가 결정된다. 만약 $f'(x) = 0$이 중근을 갖거나 허근을 갖는다면, 삼차함수는 단조 증가 또는 단조 감소하며 극값을 갖지 않는다.

### 직관과 기하적 의미
삼차함수의 그래프는 $x$축을 기준으로 굽어지는 형태를 띠는데, 극값은 그래프의 높낮이가 바뀌는 변곡점 근처의 정점이나 저점을 의미한다. 도함수의 그래프인 이차함수가 $x$축을 통과하는 지점이 바로 삼차함수의 그래프가 잠시 멈추거나 방향을 바꾸는 지점이다.

### 기본 성질
삼차함수가 극값을 가질 조건은 판별식 $D = (2b)^2 - 4(3a)(c) > 0$을 만족하는 것이다. 또한, 삼차함수의 극댓값과 극솟값의 차이는 두 극점의 $x$좌표 차이와 도함수의 정적분 값으로 구할 수 있다.

## 학습 체크
- 삼차함수의 도함수가 $x$축과 한 점에서 접할 때, 원래 함수는 극값을 갖는가?
- 삼차함수의 계수 중 최고차항의 부호가 극대와 극소의 위치 관계에 어떤 영향을 주는가?

## 관련 개념
- **도함수의 활용 심화**: 삼차함수의 그래프 개형을 결정하기 위해 도함수의 부호 변화와 이계도함수를 통한 오목과 볼록의 개념을 함께 적용한다.
