# 표

## 정의

확률·통계에서 **표**란 데이터나 사건의 빈도, 확률, 조건부 확률 등의 정보를 행(row)과 열(column)로 정리한 구조이다. 수능에서는 주로 **분할표(이원분류표)**가 사용되며, 두 범주형 변수의 결합 빈도를 나타낸다. 표를 이용해 사건의 확률, 조건부 확률($P(A|B) = \dfrac{P(A \cap B)}{P(B)}$), 독립성 여부를 판단한다. 각 셀의 빈도를 전체 합으로 나누면 상대도수(확률)를 구할 수 있다.

## 예시

어떤 학교 학생 200명을 대상으로 성별·운동 여부를 조사한 결과:

|        | 운동 O | 운동 X | 합계 |
|--------|--------|--------|------|
| 남학생 | 60     | 40     | 100  |
| 여학생 | 50     | 50     | 100  |
| 합계   | 110    | 90     | 200  |

임의로 뽑은 학생이 남학생일 때 운동을 하는 조건부 확률:

$$P(\text{운동 O} \mid \text{남학생}) = \frac{60}{100} = 0.6$$
