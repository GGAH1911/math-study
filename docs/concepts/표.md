# 표

## 요약
데이터나 사건의 빈도 및 확률 정보를 행과 열로 구조화하여 조건부 확률과 독립성을 분석하는 도구이다.

## 본문
확률과 통계에서 표란 데이터나 사건의 빈도, 확률, 조건부 확률 등의 정보를 행(row)과 열(column)로 정리한 구조를 의미한다. 수능 수학에서는 주로 두 범주형 변수의 결합 빈도를 나타내는 분할표(이원분류표)가 핵심적으로 사용된다. 표의 각 셀에 기록된 빈도를 전체 합계로 나누면 상대도수 또는 확률을 구할 수 있으며, 이를 통해 특정 사건이 발생할 확률과 조건부 확률 $P(A|B) = \tfrac{P(A \cap B)}{P(B)}$을 계산할 수 있다. 또한 표에 나타난 수치들 사이의 관계를 분석하여 두 사건이 서로 독립인지 혹은 종속인지를 판단하는 근거로 활용한다.

### 직관과 기하적 의미
표는 복잡하게 얽힌 데이터 간의 관계를 시각적으로 단순화하여 보여준다. 행과 열이 교차하는 지점은 두 가지 조건이 동시에 만족되는 교집합의 크기를 나타내며, 이를 통해 전체 집단 내에서 특정 조건이 차지하는 비중을 직관적으로 파악할 수 있게 한다.

### 기본 성질
표의 가로 합계와 세로 합계의 총합은 항상 전체 표의 총합과 일치해야 한다. 또한, 특정 조건이 주어졌을 때의 확률인 조건부 확률을 구할 때는 분모를 전체 합계가 아닌 해당 조건에 해당하는 행이나 열의 합계로 설정해야 함에 유의해야 한다.

## 학습 체크
- 표의 각 셀에 적힌 빈도를 이용하여 조건부 확률을 구할 때, 분모를 전체 합계로 나누는 오류를 범하지 않았는가?
- 두 사건이 독립인지 확인하기 위해 $P(A \cap B) = P(A)P(B)$ 관계가 성립하는지 표의 수치로 검증할 수 있는가?
