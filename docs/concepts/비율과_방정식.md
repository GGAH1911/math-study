# 비율과 방정식

## 요약
두 양의 비를 방정식의 형태로 변환하여 미지수를 찾아내는 수학적 원리이다.

## 본문
비율과 방정식은 두 양의 비를 방정식으로 표현하여 미지수를 구하는 문제 유형이다. "A : B = m : n"이라는 비의 관계가 주어지면, 이를 분수 형태인 $\tfrac{A}{B} = \tfrac{m}{n}$으로 나타낼 수 있으며, 양변에 분모를 곱하여 $nA = mB$라는 일차방정식을 유도할 수 있다. 이러한 원리는 도형의 넓이비와 길이비, 소금물의 농도, 물체의 속력, 일의 양 등 다양한 실생활 상황에서 발생하는 비율 조건을 방정식으로 변환하여 문제를 해결하는 데 핵심적인 역할을 한다.

### 직관과 기하적 의미
비율은 두 수의 크기를 비교하는 척도이며, 이를 방정식으로 나타내는 것은 두 양 사이의 상대적인 크기 관계를 수식화하는 과정이다. 예를 들어, 두 선분의 길이의 비가 일정하다는 것은 한 선분의 길이가 변함에 따라 다른 선분의 길이도 일정한 비율로 변한다는 것을 의미하며, 이는 기하학적 닮음의 원리와도 직결된다.

### 기본 성질
비의 성질에 따라 외항의 곱은 내항의 곱과 같다($A \times n = B \times m$)는 원리를 이용하면 복잡한 비율 관계를 단순한 일차방정식으로 바꿀 수 있다. 이를 통해 미지수가 포함된 비의 문제도 논리적으로 해결이 가능하다.

**예시**
소금물 A(농도 10%)와 B(농도 25%)를 섞어 농도 16%의 소금물을 만들 때, A와 B의 양의 비를 구하는 과정은 다음과 같다.

A의 양을 $a$, B의 양을 $b$라 하면:
$$\frac{0.10a + 0.25b}{a + b} = 0.16$$
$0.10a + 0.25b = 0.16a + 0.16b$
$0.09b = 0.06a$ $\rightarrow$ $\tfrac{a}{b} = \tfrac{0.09}{0.06} = \tfrac{3}{2}$
따라서 A : B = 3 : 2이다.
