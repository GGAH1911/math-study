# 비율과 방정식

## 정의

**비율과 방정식**은 두 양의 비(ratio)를 방정식으로 표현하여 미지수를 구하는 문제 유형이다. "A : B = m : n"이면 $\frac{A}{B} = \frac{m}{n}$, 즉 $nA = mB$라는 방정식을 세울 수 있다. 도형의 넓이비·길이비·농도·속도·일 등 다양한 실생활 상황에서 비율 조건을 방정식으로 변환하여 풀 수 있다.

## 예시

소금물 A(농도 10%)와 B(농도 25%)를 섞어 농도 16%의 소금물을 만들려 한다. A와 B의 비를 구하시오.

A의 양을 $a$, B의 양을 $b$라 하면:

$$\frac{0.10a + 0.25b}{a + b} = 0.16$$

$0.10a + 0.25b = 0.16a + 0.16b$

$0.09b = 0.06a$ → $\frac{a}{b} = \frac{9}{6} = \frac{3}{2}$

따라서 A : B = 3 : 2.
