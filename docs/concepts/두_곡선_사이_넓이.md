# 두 곡선 사이 넓이

> **예제** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
$\int(f-g)dx$

## 본문 (학습 시 채워짐)

### 문제

두 곡선 $y = x^2$과 $y = 2x$로 둘러싸인 도형의 넓이를 구하시오.

### 단계별 풀이

**교점 찾기**

두 곡선이 만나는 점에서 $y$ 값이 같으므로:
$$x^2 = 2x$$
$$x^2 - 2x = 0$$
$$x(x-2) = 0$$

따라서 $x = 0$ 또는 $x = 2$. 교점은 $(0, 0)$과 $(2, 4)$입니다.

**어느 곡선이 위인지 확인**

$0 < x < 2$ 범위에서 한 점, 예를 들어 $x = 1$을 대입하면:
- $y = x^2$: $y = 1$
- $y = 2x$: $y = 2$

따라서 이 구간에서 $2x > x^2$이므로, 직선이 포물선 위에 있습니다.

**넓이 계산**

두 곡선 사이의 넓이는:
$$\text{넓이} = \int_0^2 (2x - x^2) \, dx$$

부정적분을 구하면:
$$\int (2x - x^2) \, dx = x^2 - \frac{x^3}{3} + C$$

정적분을 계산하면:
$$\left[ x^2 - \frac{x^3}{3} \right]_0^2 = \left(4 - \frac{8}{3}\right) - 0 = \frac{12 - 8}{3} = \frac{4}{3}$$

(검증: `integrate(2*x - x**2, (x, 0, 2))` → $\frac{4}{3}$)

### 답

$$\frac{4}{3}$$

### 변형/주의

- **교점의 개수**: 두 곡선이 두 점 이상에서 만날 수 있습니다. 여러 구간으로 나누어 각각 계산한 후 합하세요.
- **위/아래 판단**: 항상 구간 내 한 점을 대입하여 확인하세요. 그래프를 대충 그리면 실수하기 쉽습니다.
- **절댓값 주의**: 위의 함수에서 아래의 함수를 뺀다는 원칙을 지키면 음수가 나오지 않습니다.
