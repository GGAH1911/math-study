### 정확한 진술

함수 $f(x)$가 **극댓값**을 가진다는 것은, 어떤 점 $x = a$를 포함하는 구간 $(a - \delta, a + \delta)$ 내의 모든 $x$에 대해 $f(x) \leq f(a)$가 성립함을 의미합니다. 마찬가지로 **극솟값**은 같은 조건에서 $f(x) \geq f(a)$가 성립하는 경우입니다. 극댓값과 극솟값을 통틀어 **극값**이라 합니다.

### 도함수와 극값의 관계

극값을 가지는 점에서 중요한 성질이 있습니다. 만약 $f(x)$가 $x = a$에서 극값을 가지고 $f'(a)$가 존재하면, $f'(a) = 0$입니다. 이 점을 **임계점(critical point)**이라 부릅니다.

도함수의 **부호 변화**로 극값의 종류를 판정할 수 있습니다:
- $f'(x)$가 $x = a$ 좌측에서 **양(+)**, 우측에서 **음(−)**으로 변하면 → $f(a)$는 **극댓값**
- $f'(x)$가 $x = a$ 좌측에서 **음(−)**, 우측에서 **양(+)**으로 변하면 → $f(a)$는 **극솟값**

또는 **2차 도함수 판정법**을 사용할 수 있습니다: $f'(a) = 0$일 때, $f''(a) > 0$이면 극솟값, $f''(a) < 0$이면 극댓값입니다.

### 직관 및 의미

그래프 위에서 극댓값은 "봉우리", 극솟값은 "골짜기"처럼 보입니다. 다만 **국소적(local)** 성질이므로, 함수 전체의 최댓값이나 최솟값과는 다릅니다.

### 예제

$f(x) = x^3 - 3x$를 살펴봅시다. $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 임계점은 $x = -1, 1$입니다.

$x < -1$에서 $f'(x) > 0$, $-1 < x < 1$에서 $f'(x) < 0$이므로 $x = -1$에서 극댓값 $f(-1) = 2$를 갖습니다. $x > 1$에서 $f'(x) > 0$이므로 $x = 1$에서 극솟값 $f(1) = -2$를 갖습니다.
