# 계수 조건

## 요약
두 다항식이 항등식으로서 성립하기 위해 각 항의 계수가 만족해야 하는 조건을 의미한다.

## 본문
계수 조건이란 두 다항식이 항등적으로 같거나 특정 등식이 성립하기 위해 각 항의 계수가 만족해야 하는 조건을 말한다. 두 다항식 $f(x) = g(x)$가 $x$에 대한 항등식이라면, 모든 $x$에 대하여 식이 성립해야 하므로 같은 차수의 계수끼리 반드시 일치해야 한다. 이러한 원리를 활용하여 미지의 계수를 결정하거나, 인수분해 및 약수 조건 등을 해결할 때 계수 비교법을 사용한다. 또한 $x$에 특정 값을 대입하여 계수를 구하는 수치 대입법도 계수 조건을 활용하는 대표적인 방법이다.

### 직관과 기하적 의미
두 다항식이 항등식이라는 것은 그래프로 나타냈을 때 두 함수가 모든 실수 구간에서 완전히 겹쳐짐을 의미한다. 즉, 모든 $x$ 값에 대해 함숫값이 동일해야 하므로, 다항식을 전개했을 때 나타나는 각 차수의 계수들이 서로 일치해야 한다는 논리로 이어진다.

### 기본 성질
1. 계수 비교법: 다항식을 전개한 후, 양변의 같은 차수의 계수를 비교하여 미지수를 구한다.
2. 수치 대입법: 항등식의 성질을 이용하여 $x$에 적절한 값을 대입함으로써 계수를 구한다.
3. 항등식의 성립 조건: $f(x) = g(x)$가 항등식이 되려면 모든 차수의 계수가 서로 같아야 한다.

예를 들어, $x^2 + ax + b = (x-1)(x+3) + c$가 항등식일 때, 우변을 전개하면 $x^2 + 2x - 3 + c$가 된다. 이때 계수를 비교하면 $x^1$ 항의 계수로부터 $a = 2$를 얻고, 상수항으로부터 $b = -3 + c$를 얻는다. 또한 $x=0$을 대입하면 $b = -3 + c$가 되고, $x=1$을 대입하면 $1 + a + b = c$가 되어 $c=0, b=-3, a=2$라는 결과를 도출할 수 있다.

## 학습 체크
- 두 다항식이 항등식일 때, 전개된 형태에서 같은 차수의 계수를 비교하는 방법과 특정 값을 대입하는 방법 중 어떤 것이 더 효율적인가?
- 항등식의 성질을 이용하여 미지수가 포함된 계수를 구할 때, 계수 비교법을 사용하기 위해 반드시 선행되어야 할 과정은 무엇인가?
