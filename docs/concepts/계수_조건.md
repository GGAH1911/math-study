# 계수 조건

## 정의

계수 조건이란, 두 다항식이 항등적으로 같거나 특정 등식이 성립하기 위해 각 항의 계수가 만족해야 하는 조건이다. 두 다항식 $f(x) = g(x)$가 $x$에 대한 항등식이면, 같은 차수의 계수끼리 반드시 같아야 한다. 이 원리를 이용하여 미지의 계수를 결정하거나, 인수분해·약수 조건 등을 풀 때 계수 비교법을 사용한다. 또한 $x$에 특정 값을 대입하여 계수를 구하는 수치 대입법도 계수 조건 문제에 자주 활용된다.

## 예시

$x^2 + ax + b = (x-1)(x+3) + c$가 $x$에 대한 항등식일 때, $a$, $b$, $c$의 값을 구한다.

우변을 전개하면: $x^2 + 2x - 3 + c$

계수 비교: $x^1$ 항 $\Rightarrow a = 2$, 상수항 $\Rightarrow b = -3 + c$

$x = 0$ 대입: $b = -3 + c$, $x = 1$ 대입: $1 + a + b = c$ $\Rightarrow c = 0$, $b = -3$, $a = 2$
