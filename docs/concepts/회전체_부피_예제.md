# 회전체 부피 예제

> **예제** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
$y=\sqrt x$ 회전

## 본문 (학습 시 채워짐)

### 문제

$y = \sqrt{x}$ (단, $0 \le x \le 4$)의 그래프를 $x$축 중심으로 회전시킨 회전체의 부피를 구하세요.

### 단계별 풀이

**1단계: 공식 확인**  
$x$축 중심으로 회전시킨 회전체의 부피는 다음 공식을 사용합니다:
$$V = \pi \int_a^b [f(x)]^2 \, dx$$

**2단계: 반지름 함수 결정**  
$x$축 위의 한 점 $x$에서 곡선 $y = \sqrt{x}$까지의 거리(회전축으로부터의 거리)가 반지름입니다.
$$r(x) = \sqrt{x}$$

**3단계: 적분 설정**  
$$V = \pi \int_0^4 (\sqrt{x})^2 \, dx = \pi \int_0^4 x \, dx$$

**4단계: 계산**  
$$\int_0^4 x \, dx = \left[ \frac{x^2}{2} \right]_0^4 = \frac{16}{2} - 0 = 8$$

따라서:
$$V = \pi \cdot 8 = 8\pi$$

검산: `sympy.integrate(sympy.Symbol('x'), (sympy.Symbol('x'), 0, 4))`로 $\int_0^4 x \, dx = 8$ 확인 가능.

### 답

$$V = 8\pi \text{ (단위: 세제곱)}$$

수치로는 약 $25.13$ 입니다.

### 변형/주의

**변형 1**: 같은 함수를 **$y$축 중심**으로 회전하려면 원통각법(원통껍질 방법)을 사용하거나, $x = y^2$로 역함수를 이용해 $V = \pi \int_0^2 (4 - y^4) \, dy$로 계산합니다.

**변형 2**: 적분 구간이 바뀌면 부피도 달라집니다. 예를 들어 $0 \le x \le 1$이면 $V = \pi \cdot \frac{1}{2} = \frac{\pi}{2}$입니다.

**주의**: 반지름은 **함수값 자체**이며, 반드시 제곱 후 적분해야 합니다. 부호나 절댓값도 확인하세요.
