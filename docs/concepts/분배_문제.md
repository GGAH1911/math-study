# 분배 문제

## 요약
서로 다른 $n$개의 물건을 $k$개의 서로 다른 상자에 나누어 담는 방법의 수를 구하는 문제입니다.

## 본문
분배 문제는 주어진 대상들을 특정 기준에 따라 여러 그룹으로 나누거나 상자에 배치하는 모든 가능한 경우를 찾는 과정입니다. 이 과정에서 물건이 서로 구별되는지, 상자가 서로 구별되는지, 그리고 상자가 비어 있어도 되는지 여부에 따라 계산 방식이 결정됩니다. 일반적으로 $n$개의 서로 다른 물건을 $k$개의 서로 같은 상자에 나누어 담는 경우, 이는 집합의 분할과 밀접한 관련이 있으며, 상자가 서로 다르다면 각 물건이 선택할 수 있는 상자의 개수를 고려하여 계산합니다.

### 직관과 기하적 의미
물건을 상자에 담는 행위는 각 물건에 대해 어떤 상자에 들어갈지 '선택'을 부여하는 것과 같습니다. 예를 들어, 물건이 3개이고 상자가 2개라면, 각 물건은 2가지 선택지를 가집니다. 이를 기하학적으로는 격자점의 좌표나 경로의 수로 시각화하여 해석할 수도 있습니다.

### 기본 성질
서로 다른 $n$개의 물건을 서로 다른 $k$개의 상자에 중복을 허용하여 나누어 담는 경우의 수는 $k^n$입니다. 만약 상자가 서로 같다면, 이는 중복 조합이나 집합의 분할 개념을 적용하여 계산해야 하며, 상자가 비어있으면 안 된다는 조건이 붙을 경우 제2종 스털링 수의 개념이 도입됩니다.

## 학습 체크
- 물건과 상자가 각각 구별되는지, 아니면 같은 종류인지 구분하였는가?
- 상자가 비어 있어도 된다는 조건이 포함되어 있는가?
- 중복을 허용하여 선택하는 상황인가, 아니면 한 번씩만 사용하는 상황인가?

## 관련 개념
- **경우의 수**: 분배 문제는 전체 가능한 조합 중 특정 조건을 만족하는 사건의 개수를 구하는 것이므로 경우의 수의 핵심적인 응용 사례입니다.
