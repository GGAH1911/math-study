# 확률의 정의 계산

## 요약
어떤 사건이 일어날 확률은 전체 경우의 수에 대한 해당 사건의 경우의수의 비율로 정의됩니다.

## 본문
어떤 시행에서 발생할 수 있는 모든 결과가 일어날 가능성이 각각 같을 때, 어떤 사건 $A$가 일어날 확률 $P(A)$는 전체 경우의 수를 $n(S)$, 사건 $A$가 일어나는 경우의 수를 $n(A)$라고 할 때 다음과 같이 정의합니다.
$$P(A) = \frac{n(A)}{n(S)}$$
이때 전체 경우의 수 $n(S)$는 반드시 $0$이 아니어야 하며, 모든 경우의 수는 각 사건이 일어날 가능성이 동일하다는 전제 조건이 충족되어야 합니다.

### 직관과 기하적 의미
확률은 전체 영역 중에서 특정 영역이 차지하는 크기나 비율을 의미합니다. 기하학적으로는 선분의 길이, 면적, 또는 부피의 비율로 해석할 수 있으며, 이는 연속적인 공간에서도 동일한 논리로 확장됩니다. 즉, 전체 집합의 크기에 대한 부분 집합의 크기의 비로 이해할 수 있습니다.

### 기본 성질
확률의 값은 항상 $0$ 이상 $1$ 이하의 범위를 가집니다. 즉, $0 \le P(A) \le 1$입니다. 만약 어떤 사건이 일어날 가능성이 전혀 없다면 그 확률은 $0$이며, 반드시 일어나는 사건의 확률은 $1$이 됩니다. 또한, 서로 다른 사건들의 확률을 합산할 때 각 사건이 배반 사건이라면 확률의 합은 각 확률의 합과 같습니다.

## 학습 체크
- 모든 경우의 수가 발생할 가능성이 동일하다는 조건이 주어졌는가?
- 계산된 확률 값이 $0$과 $1$ 사이의 범위에 포함되는가?
- 전체 경우의 수 $n(S)$를 구할 때 중복이나 누락이 없는가?

## 관련 개념
- **확률**: 확률의 정의를 바탕으로 사건의 발생 가능성을 수치화하여 다루는 수학적 체계입니다.
