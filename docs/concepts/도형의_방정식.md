# 도형의 방정식

> **단원** · 고1 · 선수: [좌표평면과 그래프](./좌표평면과_그래프.md) / [이차함수](./이차함수.md) / [원의 성질](./원의_성질.md) · 다음: 없음 (말단 노드 / Phase 1에서 미정의)

## 학습 목표
- 직선·원의 방정식을 좌표평면에서 다룬다
- 점·도형의 이동(평행이동·대칭이동)을 식으로 표현한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 직선의 방정식 $y=mx+n$, $ax+by+c=0$
- 원의 방정식 $(x-a)^2+(y-b)^2=r^2$

**정리(theorem)**
- 두 점 사이의 거리
- 두 직선의 교점·평행·수직 조건
- 원과 직선의 위치관계

**예제(example)**
- 중점·내분점·외분점
- 접선의 방정식
- 평행이동/대칭이동의 식 변환
