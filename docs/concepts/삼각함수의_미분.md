### 정확한 진술

삼각함수의 미분이란 기본 삼각함수들의 도함수를 구하는 것입니다. 다음이 핵심 공식들입니다:

$$\frac{d}{dx}\sin x = \cos x$$

$$\frac{d}{dx}\cos x = -\sin x$$

$$\frac{d}{dx}\tan x = \sec^2 x = \frac{1}{\cos^2 x}$$

이 공식들은 극한의 정의 $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$와 삼각함수의 덧셈 정리, 그리고 $\lim_{h \to 0} \frac{\sin h}{h} = 1$이라는 중요한 극한값으로부터 유도됩니다.

### 직관/기하적 의미

$y = \sin x$ 그래프에서 접선의 기울기를 생각해봅시다. $x$가 $0$ 근처일 때 $\sin x$의 그래프가 가파르고, $x = \frac{\pi}{2}$일 때 평평합니다. 실제로 $x = 0$에서 $(\sin x)' = \cos 0 = 1$ (급한 상승), $x = \frac{\pi}{2}$에서 $(\sin x)' = \cos \frac{\pi}{2} = 0$ (수평)입니다.

같은 방식으로 $\cos x$를 미분하면 $-\sin x$가 되는데, 음수 부호는 $\sin x$와 $\cos x$의 위상 차이를 반영합니다. $\tan x$의 경우, $x$가 $\frac{\pi}{2}$에 가까워질수록 그래프가 수직에 가까워지므로 기울기는 무한대로 증가하며, 이는 $\sec^2 x$가 $x \to \frac{\pi}{2}$일 때 무한대로 발산함을 의미합니다.

### 한 줄 예

$f(x) = \sin x + 2\cos x$이면 $f'(x) = \cos x - 2\sin x$이고, $x = 0$에서 $f'(0) = 1$입니다.
