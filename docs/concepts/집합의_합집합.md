### 정확한 진술

두 집합 $A$와 $B$의 **합집합**(union)은 $A$에 속하거나 $B$에 속하는 모든 원소로 이루어진 집합입니다. 기호로 $A \cup B$로 나타내며, 다음과 같이 정의합니다.

$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$

여기서 "또는"은 수학적 의미의 **포함적 논리합**이므로, $x \in A$이거나 $x \in B$이거나 둘 다인 경우를 모두 포함합니다. 따라서 $A \cap B$의 원소(공통 원소)도 $A \cup B$에 속합니다.

### 직관과 시각적 의미

벤다이어그램으로 나타내면, 합집합 $A \cup B$는 두 원이 칠해진 전체 영역입니다. 합집합에 속하려면 최소한 한 집합에는 속해야 합니다.

합집합의 크기(원소의 개수)는 다음 공식을 만족합니다.

$$|A \cup B| = |A| + |B| - |A \cap B|$$

이는 각 집합의 원소를 더할 때 공통 원소가 중복으로 세어지므로, 그것을 한 번 빼주기 때문입니다. 특히 $A$와 $B$가 서로소(disjoint)인 경우 $|A \cup B| = |A| + |B|$입니다.

### 한 줄 예

$A = \{1, 2, 3\}$, $B = \{3, 4, 5\}$일 때, $A \cup B = \{1, 2, 3, 4, 5\}$입니다.
