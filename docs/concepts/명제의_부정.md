# 명제의 부정

## 요약
어떤 명제의 참과 거짓을 반대로 바꾸는 것을 명제의 부정이라고 합니다.

## 본문
어떤 명제 $p$에 대하여, $p$가 참이면 거짓이 되고 $p$가 거짓이면 참이 되는 명제를 $p$의 부정이라고 하며, 기호로는 $\sim p$ 또는 $\bar{p}$로 나타냅니다. 명제의 부정은 원래 명제의 진리값을 정반대로 뒤집는 연산과 같습니다. 만약 명제 $p$가 참이라면 $\sim p$는 거짓이고, 명제 $p$가 거짓이라면 $\sim p$는 참입니다. 따라서 어떤 명제와 그 부정 중 하나는 반드시 참이고 나머지 하나는 반드시 거짓이 되는 관계를 가집니다.

### 직관과 기하적 의미
명제의 부정은 '아니다'라는 논리를 적용하는 것입니다. 예를 들어, 수직선 위에서 어떤 점 $x$가 $x > 3$이라는 영역에 속한다면, 이 명제의 부정은 $x \le 3$이 되어 해당 영역의 반대편을 가리키게 됩니다. 즉, 전체 집합을 기준으로 원래 명제가 포함하는 영역을 제외한 나머지 모든 영역을 의미하게 됩니다.

### 기본 성질
명제의 부정에 다시 부정을 취하면 원래의 명제와 동일한 진리값을 갖게 됩니다. 즉, $\sim(\sim p)$는 $p$와 같습니다. 또한, 조건 $p(x)$에 대한 명제의 부정은 조건의 범위를 반대로 바꾸어 주는 것입니다. 예를 들어, 모든(all)에 대한 부정은 어떤(some)이 되고, 존재한다(exists)에 대한 부정은 존재하지 않는다(does not exist)가 됩니다.

## 학습 체크
- 명제 $p$가 거짓일 때, 그 부정인 $\sim p$의 참/거짓 여부를 판단할 수 있는가?
- '모든' 또는 '어떤'과 같은 양화사가 포함된 명제를 부정할 때, 조건의 범위를 정확히 반대로 설정하였는가?

## 관련 개념
- **집합과 명제**: 명제의 참과 거짓을 판별하는 과정은 집합의 포함 관계와 밀접하며, 조건의 부정은 해당 조건을 만족하는 집합의 여집합을 구하는 것과 같습니다.
