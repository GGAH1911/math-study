### 정확한 진술

삼각형의 **내각(interior angle)**은 삼각형의 세 꼭짓점에서 이루어지는 각을 말합니다. 삼각형 ABC에서 세 내각을 $\angle A$, $\angle B$, $\angle C$라 하면, 이들의 합은 항상 다음을 만족합니다:

$$\angle A + \angle B + \angle C = 180°$$

삼각형의 **외각(exterior angle)**은 한 변을 연장했을 때 형성되는 각입니다. 예를 들어 변 BC를 점 C 너머로 연장한 직선이 만드는 각을 C의 외각이라 하면, 이는 인접하지 않은 두 내각 $\angle A + \angle B$와 같습니다.

### 직관/기하적 의미

삼각형의 내각의 합이 180°라는 것은 평면 기하학의 가장 기초적인 성질입니다. 한 꼭짓점을 지나는 직선을 그으면, 삼각형의 세 각이 정확히 평각(일직선)을 이룬다는 의미이므로, 삼각형이 "닫힌" 도형임을 나타냅니다.

외각의 성질은 더욱 실용적입니다. 어떤 외각은 그것을 만드는 변에 인접하지 않은 두 내각의 합과 같으므로, 한 각을 모르는 상황에서도 다른 각들의 관계를 파악할 수 있습니다. 이 성질은 각의 크기를 구하는 문제에서 가장 자주 활용됩니다.

### 한 줄 예

$\angle A = 50°$, $\angle B = 70°$인 삼각형 ABC에서 $\angle C = 180° - 50° - 70° = 60°$이며, 점 C의 외각은 $50° + 70° = 120°$입니다.
