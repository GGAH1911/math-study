# 도함수의 조건

## 요약
함수 $f(x)$가 $x=a$에서 미분가능하기 위해서는 해당 지점에서 극한값인 미분계수가 존재해야 하며, 이는 함수가 그 지점에서 연속임을 전제로 합니다.

## 본문
함수 $f(x)$가 $x=a$에서 미분가능하다는 것은 극한값 $\lim_{h \to 0} \tfrac{f(a+h)-f(a)}{h}$가 존재함을 의미한다. 이 극한값이 존재하기 위해서는 좌미분계수 $\lim_{h \to 0^-} \tfrac{f(a+h)-f(a)}{h}$와 우미분계수 $\lim_{h \to 0^+} \tfrac{f(a+h)-f(a)}{h}$가 각각 존재하고 그 값이 서로 같아야 한다. 즉, 함수가 해당 지점에서 매끄럽게 연결되어 있어야 하며, 꺾인 점이나 불연속점이 없어야 한다.

### 직관과 기하적 의미
기하학적으로 미분가능하다는 것은 함수 그래프 위의 점 $(a, f(a))$에서 접선을 유일하게 그릴 수 있음을 의미한다. 만약 그래프가 뾰족한 모양(첨점)을 가지거나 끊어져 있다면, 접선의 기울기를 하나로 정의할 수 없으므로 미분 불가능한 상태가 된다.

### 기본 성질
함수 $f(x)$가 $x=a$에서 미분가능하면, 함수 $f(x)$는 $x=a$에서 반드시 연속이다. 그러나 역은 성립하지 않는다. 즉, 연속이라고 해서 반드시 미분가능한 것은 아니다.

## 학습 체크
- 함수가 연속이지만 미분 불가능한 대표적인 사례(예: 절댓값 함수)를 그래프를 통해 설명할 수 있는가?
- 좌미분계수와 우미분계수의 개념을 이용하여 특정 함수가 특정 지점에서 미분가능한지 판별할 수 있는가?

## 관련 개념
- **이차함수**: 모든 이차함수는 실수 전체의 집합에서 연속이며 매끄러운 곡선을 그리므로, 모든 실수에서 미분가능하다.
