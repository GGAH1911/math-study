# 포함배제 원리

## 요약
여러 집합의 합집합의 원소 개수를 구할 때, 중복 계산된 부분을 더하거나 빼는 방식으로 전체 원소의 개수를 정확히 계산하는 원리입니다.

## 본문
포함배제 원리는 여러 개의 집합이 주어졌을 때, 각 집합의 원소들이 서로 겹치는 부분을 고려하여 합집합의 원소 개수를 구하는 수학적 원리입니다. 두 집합의 경우에는 각 집합의 원소 개수의 합에서 교집합의 원소 개수를 한 번 빼주면 되지만, 집합의 개수가 늘어날수록 계산 과정은 복잡해집니다. 세 개 이상의 집합에 대해서는 각 집합의 원소 개수를 모두 더한 뒤, 두 집합씩 겹치는 부분들을 모두 빼고, 다시 세 집합이 동시에 겹치는 부분을 더하는 방식으로 교차 계산을 반복하여 중복을 제거합니다. 이 원리는 집합의 크기를 구하는 것뿐만 아니라, 특정 조건을 만족하지 않는 경우의 수를 구하는 등 조합론의 다양한 영역에서 핵심적인 도구로 사용됩니다.

### 직관과 기하적 의미
벤 다이어그램을 떠올리면 이해가 쉽습니다. 두 원이 겹쳐 있을 때 두 원의 넓이를 단순히 더하면 겹친 부분만큼 두 번 계산됩니다. 따라서 겹친 부분을 한 번 빼주어야 전체 넓이가 나옵니다. 집합이 많아지면 겹치는 영역이 2개, 3개씩 복잡하게 얽히게 되는데, 포함배제 원리는 이 겹친 영역들을 '더하기'와 '빼기'를 반복하며 정교하게 조정해 나가는 과정입니다.

### 기본 성질
집합 $A_1, A_2, \dots, A_n$에 대하여 합집합의 원소 개수는 다음과 같은 일반식으로 나타낼 수 있습니다.
$$\left| \bigcup_{i=1}^{n} A_i \right| = \sum_{i=1}^{n} |A_i| - \sum_{1 \le i < j \le n} |A_i \cap A_j| + \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k| - \dots + (-1)^{n-1} |A_1 \cap \dots \cap A_n|$$
즉, 홀수 개의 집합이 겹치는 부분은 더하고, 짝수 개의 집합이 겹치는 부분은 빼는 규칙을 따릅니다.

## 학습 체크
- 집합의 개수가 늘어날 때 부호가 왜 $+$, $-$로 번갈아 나타나는지 논리적으로 설명할 수 있는가?
- 전체 집합에서 특정 조건을 만족하는 부분집합의 개수를 구할 때, 여집합의 개념을 어떻게 적용하는가?

## 관련 개념
- **확률**: 포함배제의 원리를 이용하여 여러 사건이 동시에 발생하거나 적어도 하나가 발생할 확률을 계산할 수 있습니다.
