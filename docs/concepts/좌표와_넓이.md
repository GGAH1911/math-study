### 정확한 진술

좌표평면에서 곡선(또는 직선)으로 둘러싸인 영역의 넓이는 곡선을 나타내는 함수와 좌표축(또는 다른 곡선) 사이의 부호 있는 면적으로 정의합니다. 특히 함수 $y = f(x)$의 그래프와 $x$축, 그리고 직선 $x = a$, $x = b$ ($a < b$)로 둘러싸인 영역의 넓이 $S$는
$$S = \int_a^b |f(x)| \, dx$$
로 정의됩니다. 여기서 절댓값은 $f(x)$가 음수인 구간에서도 넓이가 양수가 되도록 보장합니다.

### 직관과 기하적 의미

좌표평면에 함수 그래프를 그리면, 곡선 아래 영역을 수많은 얇은 직사각형으로 나눌 수 있습니다. 각 직사각형의 가로 길이는 $\Delta x$이고 높이는 $|f(x)|$이므로, 모든 직사각형의 넓이를 더하면 전체 영역의 넓이가 됩니다. 이 과정의 극한(구간의 폭을 0으로)이 적분입니다. 이차함수처럼 단순한 함수부터 시작하면, 기하학적 성질(예: 삼각형, 사다리꼴)을 이용해 넓이를 직접 계산할 수 있어 적분의 의미를 이해하기 좋습니다.

### 한 줄 예

이차함수 $f(x) = -x^2 + 4$와 $x$축 사이의 영역($-2 \le x \le 2$)의 넓이는
$$S = \int_{-2}^{2} (4 - x^2) \, dx = \left[4x - \frac{x^3}{3}\right]_{-2}^{2} = \frac{32}{3}$$
입니다. (검증: `sympy.integrate(4 - x**2, (x, -2, 2))`)
