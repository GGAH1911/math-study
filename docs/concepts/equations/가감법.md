# 가감법

> **정리** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
두 식의 가감으로 한 변수 소거

## 본문 (학습 시 채워짐)

### 진술 및 가정

연립일차방정식을 풀 때, 두 식을 더하거나 빼서 미지수 중 하나를 소거하고 다른 하나의 값을 구하는 방법을 **가감법**이라 합니다. 일반적으로 다음 형태의 연립방정식에 적용합니다:

$$\begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases}$$

이 방법이 가능한 이유는 등식의 성질—**같은 식의 양변을 더하면 같은 식이 되고, 한 식에서 다른 식을 빼도 같은 식이 된다**는 원리에 기반합니다.

### 유도 및 원리

$x$의 계수를 같게 만들기 위해 첫 번째 식에 $k$, 두 번째 식에 $m$을 곱한 뒤 두 식을 뺀다고 하면:

$$ka_1 x + kb_1 y = kc_1$$
$$ma_2 x + mb_2 y = mc_2$$

두 식을 빼면:
$$(ka_1 - ma_2)x + (kb_1 - mb_2)y = kc_1 - mc_2$$

$ka_1 = ma_2$가 되도록 $k, m$을 선택하면 $x$가 소거되어 $y$만 남습니다. 이를 푼 후 원래 식에 대입하면 $x$를 구할 수 있습니다.

### 적용 예시 및 의의

다음 연립방정식을 풀어봅시다:
$$\begin{cases} 2x + 3y = 7 \\ 2x - y = 3 \end{cases}$$

$x$의 계수가 이미 같으므로 (2와 2) 두 식을 직접 뺍니다. 첫 번째 식에서 두 번째 식을 빼면:
$$(2x + 3y) - (2x - y) = 7 - 3$$
$$4y = 4, \quad y = 1$$

두 번째 식에 $y=1$을 대입: $2x - 1 = 3$ → $x = 2$. 따라서 $(x, y) = (2, 1)$ (sympy 검증: `sympy.solve([2*x + 3*y - 7, 2*x - y - 3], [x, y])` → `{x: 2, y: 1}`)

가감법은 특히 한 변수의 계수를 쉽게 같게 만들 수 있을 때 **대입법보다 계산이 간단**합니다. 중2에서 연립방정식을 효율적으로 푸는 핵심 도구입니다.
