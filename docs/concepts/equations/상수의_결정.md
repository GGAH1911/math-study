### 정확한 진술

**상수의 결정**은 주어진 조건(예: 점을 지나기, 특정 값 같기)들을 이용하여 다항식이나 함수에 포함된 미지의 상수(계수)들을 구하는 과정입니다. 보통 $f(x) = ax^2 + bx + c$ 형태에서 $a, b, c$ 같은 미지수를 찾는 것입니다. 각 조건 하나가 미지수 하나를 결정하므로, $n$개의 미지수를 정하려면 $n$개의 독립적인 조건이 필요합니다.

### 직관과 의미

어떤 함수를 "완전히" 결정하려면 그 모양을 정해야 합니다. 예를 들어 이차함수 한 개는 3개의 점이 지나간다는 조건이 있어야 비로소 $a, b, c$가 유일하게 정해집니다. 이는 연립일차방정식을 풀어서 얻습니다. 기하학적으로는 여러 조건(그래프의 특정 점, 최솟값, 기울기 등)을 "제약"으로 생각하면, 그 제약이 많을수록 가능한 함수가 하나로 좁혀집니다.

### 한 줄 예

이차함수 $f(x) = ax^2 + bx + c$가 세 점 $(0, 1)$, $(1, 3)$, $(2, 9)$를 지날 때, 조건 $f(0) = 1$, $f(1) = 3$, $f(2) = 9$에서 $c = 1$, $a + b + c = 3$, $4a + 2b + c = 9$를 얻고, 연립하여 $a = 2, b = 0, c = 1$로 결정됩니다.

*검산: `sympy.solve([c - 1, a + b + c - 3, 4*a + 2*b + c - 9], [a, b, c])`*
