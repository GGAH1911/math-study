### 정확한 정의

양의 정수 $N$이 **$n$자리 수**라는 것은 $10^{n-1} \leq N < 10^n$을 만족함을 의미합니다.

더 구체적으로, $N$을 각 자리 수로 표현할 때:
- **$n$자리 수**: 맨 앞자리 $a_1 \in \{1, 2, \ldots, 9\}$이고, 나머지 자리 $a_2, a_3, \ldots, a_n \in \{0, 1, \ldots, 9\}$인 정수
- **범위 조건**: $10^{n-1} \leq N < 10^n$ (부등식 형태)

예를 들어 $N = \overline{a_1 a_2 \cdots a_n}$이면 $N = a_1 \cdot 10^{n-1} + a_2 \cdot 10^{n-2} + \cdots + a_n$입니다.

### 직관과 의미

"자리수 조건"은 미지수가 몇 자리 수인지 제한할 때 쓰는 **부등식 제약**입니다. 

- **한 자리 수**: $1 \leq N \leq 9$ (즉, $N < 10$)
- **두 자리 수**: $10 \leq N \leq 99$ (즉, $10 \leq N < 100$)
- **세 자리 수**: $100 \leq N \leq 999$ (즉, $100 \leq N < 1000$)

일반적으로 **$n$자리 수 조건**은 $10^{n-1} \leq N < 10^n$이라는 **범위 부등식**으로 나타냅니다. 이 조건은 방정식을 풀고 난 뒤, 구한 해가 실제로 문제 상황에 맞는지 **검증**하는 데 핵심적인 역할을 합니다.

### 예시

**두 자리 수 $N = 10a + b$ 조건:**
- 자리수 조건: $10 \leq 10a + b < 100$
- 각 자리 범위: $a \in \{1,2,\ldots,9\}$, $b \in \{0,1,\ldots,9\}$

**세 자리 수 $N = 100a + 10b + c$ 조건:**
- 자리수 조건: $100 \leq 100a + 10b + c < 1000$
- 각 자리 범위: $a \in \{1,2,\ldots,9\}$, $b,c \in \{0,1,\ldots,9\}$

예: 어떤 두 자리 수의 십의 자리와 일의 자리를 더하면 12가 되고, 두 자리 수에서 36을 빼면 일의 자리와 십의 자리가 바뀐다고 하면, $10a + b - 36 = 10b + a$를 풀어 $a - b = 4$를 얻습니다. $a + b = 12$와 함께 풀면 $a=8, b=4$이고, 자리수 조건 $10 \leq N < 100$을 만족하는지 확인하면 $N=84$ ✓

# sympy.solve([a + b - 12, a - b - 4], [a, b])
