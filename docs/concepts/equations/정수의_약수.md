### 정확한 진술

정수 $a$와 0이 아닌 정수 $b$에 대해, $a = bq$ (단, $q$는 정수)를 만족하는 정수 $q$가 존재할 때, "$b$는 $a$의 약수"라고 하고, $b \mid a$로 표기합니다. 동시에 "$a$는 $b$의 배수"라고 부릅니다.

예: $12 = 3 \times 4$이므로 $3 \mid 12$입니다.

### 직관 및 핵심 성질

약수는 "나누어떨어지게 하는 수"입니다. $b \mid a$라는 것은 $a$를 $b$로 나눈 나머지가 정확히 0이라는 뜻입니다. 즉, 나눗셈 정리에서 $a = bq + r$ (단, $0 \le r < |b|$)일 때, $r = 0$이어야 합니다.

정수 $a \neq 0$의 모든 약수는 유한개입니다. 음수도 약수에 포함되므로, 12의 약수는 $\pm 1, \pm 2, \pm 3, \pm 4, \pm 6, \pm 12$이며 총 12개입니다. 항상 $\pm 1$과 $\pm a$는 $a$의 약수입니다 ($1 \mid a$, $a \mid a$이므로).

약수 관계는 다음 성질을 만족합니다:
- $a \mid b$이고 $b \mid c$이면 $a \mid c$ (추이성)
- $a \mid b$이고 $a \mid c$이면 $a \mid (mb + nc)$ (임의의 정수 $m, n$)

### 예시 및 검산

$-2 \mid 10$인가요? $10 = (-2) \times (-5)$이므로 **맞습니다**.

$3 \mid 10$인가요? $10 = 3 \times 3 + 1$이므로 **아닙니다** (나머지가 1).

12의 모든 양의 약수를 찾으려면:
```python
from sympy import divisors
divisors(12)  # [1, 2, 3, 4, 6, 12]
```

약수 개념은 최대공약수, 최소공배수, 소인수분해 등 모든 정수론의 기초를 이룹니다.
