# 이차방정식 인수분해풀이

> **예제** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
곱해서 상수항이 되고 더해서 일차항의 계수가 되는 두 수를 찾아 식을 인수분해한 뒤, 각 인수가 $0$이 되는 값을 구하여 해를 찾습니다.

## 본문
$$x^2-5x+6=0$$

### 단계별 풀이
**1단계: 상수항과 일차항 계수 확인**
이차방정식 $x^2-5x+6=0$에서 상수항은 $6$이고 일차항의 계수는 $-5$입니다. 인수분해를 위해서는 곱했을 때 $6$이 되고, 더했을 때 $-5$가 되는 두 정수를 찾아야 합니다.

**2단계: 두 수 찾기**
곱이 $6$인 정수 쌍 중에서 합이 $-5$가 되는 조합을 찾습니다.
- $1 \times 6 = 6$ (합: $7$)
- $2 \times 3 = 6$ (합: $5$)
- $(-2) \times (-3) = 6$ (합: $-5$)
따라서 구하는 두 수는 $-2$와 $-3$입니다.

**3단계: 인수분해**
찾은 두 수를 이용하여 식을 인수분해하면 다음과 같습니다.
$$x^2 - 5x + 6 = (x - 2)(x - 3) = 0$$

**4단계: 해 구하기**
두 식의 곱이 $0$이 되려면 적어도 하나의 식은 $0$이어야 합니다.
- $x - 2 = 0 \Rightarrow x = 2$
- $x - 3 = 0 \Rightarrow x = 3$

### 답과 변형
**답**
$$x = 2 \text{ 또는 } x = 3$$

**변형 예시**
음수 근을 갖는 $x^2 + 2x - 3 = 0$의 경우, 곱이 $-3$이고 합이 $2$인 두 수 $3$과 $-1$을 찾아 $(x+3)(x-1)=0$으로 인수분해하며, 해는 $x=-3$ 또는 $x=1$이 됩니다.

**주의사항**
부호를 결정할 때 합의 부호를 주의 깊게 살펴야 하며, 정수 범위에서 인수분해가 되지 않는 경우에는 근의 공식을 사용해야 합니다. 인수분해 가능 여부가 불확실할 때는 판별식 $D = b^2 - 4ac$를 통해 확인하는 것이 좋습니다.

## 학습 체크
- 곱해서 상수항이 되고 더해서 일차항 계수가 되는 두 수를 정확히 찾을 수 있는가?
- 인수분해된 식을 바탕으로 각 인수가 $0$이 되는 $x$의 값을 도출할 수 있는가?
- 계수의 부호에 따라 인수분해 결과의 부호를 실수 없이 결정할 수 있는가?

## 관련 개념
- **이차방정식**: 인수분해를 통해 해를 구하는 가장 기본적인 방법 중 하나로, 식을 두 일차식의 곱 형태로 변환하여 해를 찾습니다.
