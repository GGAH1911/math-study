# 양수 조건

## 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)이 모든 실수 $x$에 대해 $f(x) > 0$이 되기 위한 필요충분조건은 다음을 동시에 만족하는 것입니다:
- $a > 0$ (포물선이 위로 볼록)
- 판별식 $D = b^2 - 4ac < 0$ (실근이 없음)

이를 줄여서 "$a > 0$ and $D < 0$"이라 표현합니다.

## 직관과 기하적 의미

이차함수의 그래프는 포물선입니다. 모든 $x$에서 양수라는 것은 포물선이 $x$축과 만나지 않으면서 동시에 $x$축 위쪽에 있다는 뜻입니다.

이를 위해서는 두 가지가 필수입니다. 첫째, $a > 0$이어야 포물선의 "입 모양"이 위로 향합니다. 둘째, 판별식 $D < 0$이어야 포물선이 $x$축과 교점을 갖지 않습니다. 이 두 조건이 모두 성립하면, 포물선은 항상 $x$축 위쪽에 떠 있게 됩니다.

반대로 $a < 0$이면서 $D < 0$인 경우, 포물선은 아래로 볼록하고 $x$축과 만나지 않으므로 항상 음수입니다.

## 한 줄 예

$f(x) = x^2 + 2x + 2$에서 $a = 1 > 0$, $D = 4 - 8 = -4 < 0$이므로 모든 실수 $x$에 대해 $f(x) > 0$입니다. (검증: `sympy.solve(x**2 + 2*x + 2, x)` → 복소수 근만 존재)

반면 $g(x) = x^2 + 2x + 1 = (x+1)^2$는 $D = 0$이므로 $x = -1$에서 $f(-1) = 0$이 되어 양수 조건을 만족하지 않습니다.
