# 이차함수의 영점

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차함수의 영점은 함수값이 $0$이 되게 하는 $x$값으로, 이차방정식의 해와 같으며 그래프가 $x$축과 만나는 지점의 $x$좌표를 의미합니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 영점(zero)은 $f(x) = 0$을 만족하는 $x$값입니다. 이는 곧 이차방정식 $ax^2 + bx + c = 0$의 해를 구하는 과정과 동일합니다. 따라서 이차함수의 영점을 찾는 것은 함수의 그래프가 $x$축과 교차하는 지점을 찾는 것과 같습니다.

### 직관과 기하적 의미
이차함수의 그래프는 포물선 형태를 띠며, 영점은 이 포물선이 $x$축과 만나는 점의 $x$좌표를 나타냅니다. 예를 들어 $a > 0$인 경우 포물선이 아래로 볼록하며, 함수값이 $0$이 되는 지점에서 그래프는 $x$축을 통과하거나 접하게 됩니다. 즉, 영점의 개수는 그래프가 $x$축과 만나는 방식에 따라 결정됩니다.

### 기본 성질
영점의 개수는 판별식 $D = b^2 - 4ac$의 값에 따라 다음과 같이 결정됩니다.
- $D > 0$: 서로 다른 두 실근을 가지며, 영점은 $2$개입니다.
- $D = 0$: 중근을 가지며, 영점은 $1$개입니다.
- $D < 0$: 실근이 존재하지 않으며, 영점은 $0$개입니다.

영점은 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 통해 구할 수 있으며, 식의 인수분해가 가능한 경우 인수분해를 통해 더 간단히 구할 수 있습니다. 예를 들어 $f(x) = x^2 - 5x + 6$의 경우, $x^2 - 5x + 6 = 0$을 인수분해하면 $(x - 2)(x - 3) = 0$이 되어 영점은 $x = 2, 3$이 됩니다.

## 학습 체크
- 판별식의 부호에 따라 $x$축과 만나는 점의 개수가 어떻게 변하는가?
- 이차함수의 영점을 구하는 과정이 이차방정식의 해를 구하는 것과 왜 같은가?

## 관련 개념
- **도함수의 활용 심화**: 영점 근처에서 함수의 부호가 변화하므로, 도함수를 이용해 함수의 증가와 감소를 분석할 때 영점의 위치는 중요한 기준점이 됩니다.
