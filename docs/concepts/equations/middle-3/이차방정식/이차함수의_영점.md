# 이차함수의 영점

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 **영점**(zero)은 $f(x) = 0$을 만족하는 $x$값입니다. 즉, 방정식 $ax^2 + bx + c = 0$의 해를 구하는 것과 같습니다. 영점의 개수는 판별식 $D = b^2 - 4ac$의 값에 따라 결정됩니다:

- $D > 0$: 서로 다른 두 실근 (영점 2개)
- $D = 0$: 중근 (영점 1개)
- $D < 0$: 실근 없음 (영점 0개)

## 직관과 기하적 의미

이차함수의 그래프는 포물선 모양입니다. 영점은 이 포물선이 $x$축과 만나는 점의 $x$좌표를 나타냅니다. 포물선이 $x$축보다 위에 있으면 ($a > 0$일 때) 함수값은 양수이고, $x$축과 만나는 지점에서 함수값이 0이 됩니다. 

선수 개념인 도함수와의 관계를 보면, 영점 근처에서 함수의 부호가 바뀌므로, 도함수를 이용해 함수의 증감을 분석할 때 영점의 위치가 중요한 참고점이 됩니다.

## 한 줄 예와 계산

$f(x) = x^2 - 5x + 6$의 영점을 구하면:

$$x^2 - 5x + 6 = 0$$

인수분해하면 $(x - 2)(x - 3) = 0$이므로 영점은 $x = 2, 3$입니다.

(`sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$)

일반적으로 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$로도 구할 수 있습니다.
