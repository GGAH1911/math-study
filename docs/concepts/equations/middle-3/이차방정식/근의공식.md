# 근의공식

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 정확한 진술
근의공식(quadratic formula)은 이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 해를 구하는 공식입니다:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

여기서 $b^2 - 4ac$를 판별식(discriminant)이라 하며, 보통 $D$ 또는 $\Delta$로 나타냅니다. 근의공식에서 나오는 $\pm$ 기호는 두 개의 근을 의미합니다: $x_1 = \frac{-b + \sqrt{D}}{2a}$와 $x_2 = \frac{-b - \sqrt{D}}{2a}$.

## 직관/기하적 의미
이차방정식은 본질적으로 포물선 $y = ax^2 + bx + c$와 $x$축의 교점의 $x$좌표를 구하는 문제입니다. 근의공식은 이 교점들의 위치를 정확히 계산하는 보편적인 방법입니다.

판별식 $D = b^2 - 4ac$는 근의 개수와 성질을 결정합니다:
- **$D > 0$**: 서로 다른 두 개의 실근(포물선이 $x$축과 두 점에서 만남)
- **$D = 0$**: 중근, 즉 중복도가 2인 하나의 실근(포물선이 $x$축에 접함)
- **$D < 0$**: 실근이 없음, 허근만 존재(포물선이 $x$축과 만나지 않음)

## 한 줄 예
$x^2 - 5x + 6 = 0$을 풀면, $a=1, b=-5, c=6$이므로 $x = \frac{5 \pm \sqrt{25-24}}{2} = \frac{5 \pm 1}{2}$에서 $x = 3$ 또는 $x = 2$입니다. (검증: `sympy.solve(x**2 - 5*x + 6, x)`)
