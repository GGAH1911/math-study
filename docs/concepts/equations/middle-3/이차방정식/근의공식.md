# 근의공식

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 해를 구하는 일반적인 공식입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 해를 구하는 공식인 근의공식은 다음과 같습니다.
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
여기서 $\pm$ 기호는 두 개의 해를 의미하며, 각각 $x = \frac{-b + \sqrt{b^2 - 4ac}}{2a}$와 $x = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$가 됩니다. 이때 루트 안의 식인 $b^2 - 4ac$를 판별식이라 하며, 보통 $D$ 또는 $\Delta$로 표기합니다.

### 직관과 기하적 의미
이차방정식의 해를 구하는 것은 이차함수 $y = ax^2 + bx + c$의 그래프인 포물선이 $x$축과 만나는 점의 $x$좌표를 찾는 것과 같습니다. 즉, 근의공식은 포물선이 $x$축과 교차하는 지점을 수학적으로 정확하게 찾아내는 도구입니다.

### 기본 성질
판별식 $D = b^2 - 4ac$의 값에 따라 근의 성질이 결정됩니다.
- $D > 0$: 서로 다른 두 실근을 가지며, 포물선이 $x$축과 두 점에서 만납니다.
- $D = 0$: 중근을 가지며, 포물선이 $x$축에 접합니다.
- $D < 0$: 실근이 존재하지 않으며, 포물선이 $x$축과 만나지 않습니다.

예를 들어 $x^2 - 5x + 6 = 0$의 경우, $a=1, b=-5, c=6$을 대입하면 $x = \frac{5 \pm \sqrt{25-24}}{2} = \frac{5 \pm 1}{2}$이 되어 $x=3$ 또는 $x=2$라는 해를 얻을 수 있습니다.

- 판별식의 부호에 따라 그래프가 $x$축과 만나는 형태를 예측할 수 있는가?

## 관련 개념
- **이차방정식**: 근의공식은 모든 이차방정식의 해를 구할 수 있는 가장 일반적이고 보편적인 해결 방법입니다.
