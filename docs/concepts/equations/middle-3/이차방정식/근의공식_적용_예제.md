# 근의공식 적용 예제

> **예제** · 중3 · 단원: [이차방정식](/concepts/이차방정식)
## 요약
계수에 분수 포함

## 본문

### 문제
다음 이차방정식을 푸시오.
$$\frac{1}{2}x^2 - \frac{5}{2}x + 2 = 0$$

### 단계별 풀이

**1단계: 분수 제거하기**
계수가 분수일 때는 먼저 양변에 적절한 수를 곱하여 정수 계수로 만드는 것이 계산을 간단히 합니다. 모든 분모의 최소공배수인 2를 양변에 곱합니다.
$$2 \cdot \frac{1}{2}x^2 - 2 \cdot \frac{5}{2}x + 2 \cdot 2 = 0$$
$$x^2 - 5x + 4 = 0$$

**2단계: 근의공식 적용**
정수 계수로 정리된 이차방정식에서 $a=1$, $b=-5$, $c=4$입니다. 근의공식을 적용합니다.
$$x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 1 \cdot 4}}{2 \cdot 1} = \frac{5 \pm \sqrt{25 - 16}}{2} = \frac{5 \pm \sqrt{9}}{2} = \frac{5 \pm 3}{2}$$

**3단계: 근 구하기**
$$x = \frac{5 + 3}{2} = 4 \quad \text{또는} \quad x = \frac{5 - 3}{2} = 1$$

### 답
$$x = 1 \text{ 또는 } x = 4$$

(검증: `sympy.solve(x**2 - 5*x + 4, x)` → [1, 4])

### 변형/주의

**원래 식으로 검산하기**: $x=1$을 원래 방정식에 대입하면 $\frac{1}{2}(1)^2 - \frac{5}{2}(1) + 2 = \frac{1}{2} - \frac{5}{2} + 2 = 0$ ✓

**분수를 그대로 두고 푸는 방법**: 양변에 곱하지 않고 직접 $a = \frac{1}{2}$, $b = -\frac{5}{2}$, $c = 2$를 근의공식에 대입해도 됩니다. 하지만 분자와 분모의 계산이 복잡해져 실수하기 쉬우므로, 정수 계수로 정리한 후 푸는 것을 권장합니다.

**계수가 여러 분수일 때**: 분모가 여럿이면 모든 분모의 최소공배수를 구해 양변에 곱합니다. 예를 들어 분모가 2, 3이면 6을 곱합니다.
