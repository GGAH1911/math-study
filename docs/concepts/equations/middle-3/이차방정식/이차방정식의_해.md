### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 **해(또는 근)**는 이 식을 참으로 만드는 $x$의 값입니다. 이차방정식은 최대 2개의 실근을 가지며, 근의 공식으로 다음과 같이 구합니다:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

판별식 $D = b^2 - 4ac$의 값에 따라 근의 개수가 결정됩니다:
- $D > 0$: 서로 다른 2개의 실근
- $D = 0$: 중근(1개, 중복도 2)
- $D < 0$: 실근 없음(복소수 근 2개)

### 직관/기하적 의미

함수 $y = ax^2 + bx + c$의 그래프는 포물선입니다. **이차방정식의 해는 이 포물선이 $x$축과 만나는 점의 $x$좌표**를 나타냅니다. 예를 들어 포물선이 $x$축과 두 점에서 만나면 서로 다른 2개의 실근이 존재하고, 한 점에서만 접하면 중근을, 만나지 않으면 실근이 없습니다.

비에타의 정리에 의해, 두 근을 $\alpha, \beta$라 하면:
$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이는 근의 합과 곱이 계수로 표현된다는 의미로, 근의 관계식을 세울 때 유용합니다.

### 한 줄 예

$x^2 - 5x + 6 = 0$의 해는 근의 공식으로 $x = \frac{5 \pm \sqrt{25-24}}{2} = \frac{5 \pm 1}{2}$이므로 $x = 3$ 또는 $x = 2$입니다. (검산: `sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$)
