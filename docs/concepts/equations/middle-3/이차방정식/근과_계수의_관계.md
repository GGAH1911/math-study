# 근과 계수의 관계

> **정리** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차방정식의 계수만으로 두 근의 합($-b/a$)과 곱($c/a$)을 즉시 구할 수 있는 성질입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라고 할 때, 두 근의 합은 $\alpha + \beta = -\tfrac{b}{a}$이고 두 근의 곱은 $\alpha\beta = \tfrac{c}{a}$가 성립합니다. 이를 근과 계수의 관계라고 하며, 방정식의 계수만으로 두 근의 합과 곱을 바로 알 수 있게 해주는 유용한 도구입니다.

### 증명 스케치
근의 공식에 의해 두 근은 $\alpha = \tfrac{-b + \sqrt{b^2 - 4ac}}{2a}$, $\beta = \tfrac{-b - \sqrt{b^2 - 4ac}}{2a}$입니다. 두 근을 더하면 분자의 루트 항이 서로 상쇄되어 $\tfrac{-2b}{2a} = -\tfrac{b}{a}$가 됩니다. 두 근을 곱하면 분자의 합차공식을 이용하여 $\tfrac{(-b)^2 - (b^2 - 4ac)}{4a^2} = \tfrac{4ac}{4a^2} = \tfrac{c}{a}$가 유도됩니다. 이 결과는 판별식의 값과 관계없이 항상 성립합니다.

### 의의와 응용
이 관계식은 크게 세 가지 상황에서 활용됩니다. 첫째, 두 근의 합과 곱을 알 때 원래의 이차방정식을 거꾸로 찾아낼 수 있습니다. 둘째, 근을 직접 구하는 복잡한 과정 없이도 근의 성질을 빠르게 판단하여 계산량을 줄여줍니다. 셋째, $\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta$와 같이 두 근 사이의 복잡한 관계식을 유도할 때 필수적으로 사용됩니다.

예를 들어 $x^2 - 3x + 2 = 0$에서 두 근의 합은 $3$, 곱은 $2$입니다. 실제로 이 방정식의 근은 $1$과 $2$이므로 식이 성립함을 확인할 수 있습니다.

## 학습 체크

- 근을 직접 구하지 않고도 $\alpha^2 + \beta^2$과 같은 식의 값을 계산할 수 있는가?
- 주어진 합과 곱을 이용하여 이차방정식을 올바르게 세울 수 있는가?

## 관련 개념
- **이차방정식**: 근과 계수의 관계를 적용하기 위한 기본 대상이며, 계수의 구성에 따라 근의 성질이 결정됩니다.
