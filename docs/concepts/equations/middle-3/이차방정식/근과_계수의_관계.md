# 근과 계수의 관계

> **정리** · 중3 · 단원: [이차방정식](/concepts/이차방정식)
## 요약
$\alpha+\beta=-b/a, \alpha\beta=c/a$

## 본문

### 진술과 가정

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 하면 다음 관계가 성립합니다.

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이를 **근과 계수의 관계**(Vieta's formulas)라고 부릅니다. 이 정리는 방정식의 계수만으로 두 근의 합과 곱을 바로 알 수 있다는 강력한 도구입니다.

### 증명 스케치

근의 공식으로부터 유도할 수 있습니다. 이차방정식 $ax^2 + bx + c = 0$의 두 근은

$$\alpha = \frac{-b + \sqrt{b^2 - 4ac}}{2a}, \quad \beta = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$$

따라서 두 근의 합은
$$\alpha + \beta = \frac{-b + \sqrt{b^2 - 4ac}}{2a} + \frac{-b - \sqrt{b^2 - 4ac}}{2a} = \frac{-2b}{2a} = -\frac{b}{a}$$

두 근의 곱은 합차공식을 이용하여
$$\alpha\beta = \frac{(-b)^2 - (b^2 - 4ac)}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}$$

이 결과는 판별식의 값과 무관하게 항상 성립합니다.

### 의의와 활용

이 관계식은 세 가지 주요 용도를 갖습니다. **첫째**, 근의 합과 곱을 알 때 원래 방정식을 복원할 수 있습니다. **둘째**, 근을 직접 구하지 않고도 근의 성질을 판단할 수 있으므로 계산량을 줄일 수 있습니다. **셋째**, 두 근 사이의 관계식(예: $\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta$)을 유도할 때 필수적입니다.

**예**: $x^2 - 3x + 2 = 0$에서 $\alpha + \beta = 3, \alpha\beta = 2$ (확인: 근은 1, 2) `sympy.symbols('x'); sympy.solve(x**2 - 3*x + 2, x)`
