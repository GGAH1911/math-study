# 완전제곱식 만들기

> **예제** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차항의 계수가 1인 이차방정식에서 일차항 계수의 절반을 제곱한 값을 양변에 더하여 좌변을 완전제곱식 형태로 만드는 방법입니다.

## 본문
다음 이차방정식을 제곱완성으로 풀어라.
$$x^2 + 4x - 5 = 0$$

### 단계별 풀이
**1단계: 상수항을 우변으로 이항**
$$x^2 + 4x = 5$$
상수항을 따로 떼어내어 $x$의 일차항과 이차항만 좌변에 정리합니다.

**2단계: 좌변을 완전제곱식으로 만들기**
일차항의 계수 4의 절반은 2이고, 이를 제곱하면 $2^2 = 4$입니다. 양변에 4를 더합니다.
$$x^2 + 4x + 4 = 5 + 4$$
이렇게 하면 좌변이 $(x + 2)^2$ 형태가 됩니다.

**3단계: 좌변을 인수분해하고 우변을 계산**
$$(x + 2)^2 = 9$$
$x + 2$의 제곱이 9이므로, 양변에 제곱근을 취합니다.

**4단계: 양변에 제곱근을 취하기**
$$x + 2 = \pm 3$$
제곱근은 양수와 음수 두 개이므로 $\pm$ 기호를 붙입니다.

**5단계: $x$ 구하기**
$$x = -2 + 3 = 1 \quad \text{또는} \quad x = -2 - 3 = -5$$

### 답과 변형
$$x = 1, \quad x = -5$$

(검산: $1^2 + 4(1) - 5 = 1 + 4 - 5 = 0$ ✓, $(-5)^2 + 4(-5) - 5 = 25 - 20 - 5 = 0$ ✓)

**주의할 점**
일차항 계수가 홀수인 경우에도 절반의 제곱인 분수 형태를 양변에 더해주면 되며, 이차항의 계수가 1이 아닐 때는 먼저 이차항으로 양변을 나누어 정리한 후 진행합니다. 일차항 계수의 절반을 제곱한 수를 더하는 것이 핵심이며, 이는 근의 공식을 유도하는 기초가 됩니다.

## 학습 체크
- 일차항 계수의 절반을 제곱한 값을 양변에 더할 수 있는가?
- 이차항의 계수가 1이 아닐 때 어떻게 식을 변형해야 하는지 알고 있는가?

## 관련 개념
- **이차방정식**: 완전제곱식을 이용하여 해를 구하는 과정은 이차방정식의 일반적인 풀이 방법 중 하나입니다.
