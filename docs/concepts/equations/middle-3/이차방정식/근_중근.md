# 근 중근

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차방정식의 두 근이 서로 같을 때, 그 값을 중근이라고 합니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)을 만족하는 $x$의 값을 근 또는 해라고 하며, 일반적으로 근의 공식 $x = \tfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$에 의해 두 개의 서로 다른 근을 가집니다. 이때 판별식 $D = b^2 - 4ac$의 값이 $0$이면 근의 공식에서 $\pm$ 부분이 $0$이 되어 $x = \tfrac{-b}{2a}$라는 하나의 값만 나오게 되는데, 이를 두 근이 서로 같다고 하여 중근이라고 부릅니다. 수학적으로는 $(x - \alpha)^2 = 0$과 같이 같은 근이 두 번 나타나는 상태를 의미합니다.

### 직관과 기이적 의미
이차함수 $y = ax^2 + bx + c$의 그래프인 포물선 관점에서 볼 때, 근은 그래프가 $x$축과 만나는 점의 $x$좌표를 의미합니다. 중근을 갖는다는 것은 포물선이 $x$축을 뚫고 지나가는 것이 아니라, $x$축에 접하며 한 점에서만 스치듯 만나는 상태를 뜻합니다.

### 기본 성질
중근을 갖는 이차방정식은 완전제곱식의 형태로 인수분해됩니다. 예를 들어 $x^2 - 6x + 9 = 0$은 판별식이 $0$이므로 $(x-3)^2 = 0$으로 인수분해되며, 중근은 $x=3$입니다. 또한 $x^2 + 2x + 1 = 0$은 $(x+1)^2 = 0$이 되어 중근이 $-1$이 됩니다. 중근을 판정할 때는 판별식을 계산하여 $0$임을 확인한 후, $x = -\tfrac{b}{2a}$를 통해 그 값을 구할 수 있습니다.

## 학습 체크
- 판별식이 $0$일 때 왜 근이 하나로 나타나는지 근의 공식을 통해 설명할 수 있는가?
- 이차함수 그래프가 $x$축과 접하는 상황을 보고 방정식의 중근 여부를 판단할 수 있는가?
- 주어진 이차방정식이 완전제곱식으로 인수분해되는지 확인할 수 있는가?

## 관련 개념
- **이차방정식**: 중근은 이차방정식이 갖는 특수한 형태의 해로서, 방정식의 근의 개수와 성질을 결정하는 핵심 요소입니다.
