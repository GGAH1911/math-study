# 이차방정식의 근과 계수의 관계

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차방정식의 두 근의 합과 곱을 근의 공식 없이 계수만으로 바로 구할 수 있는 관계입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 두 근을 $\alpha, \beta$라고 할 때, 두 근의 합은 $-\frac{b}{a}$이고 두 근의 곱은 $\frac{c}{a}$가 됩니다. 이를 **근과 계수의 관계** 또는 **비에타의 정리**라고 하며, 방정식의 계수만으로도 근들의 합과 곱을 즉각적으로 파악할 수 있게 해줍니다.

### 직관과 기하적 의미
이차방정식의 두 근이 $\alpha, \beta$라면, 이 방정식은 $a(x - \alpha)(x - \beta) = 0$으로 인수분해될 수 있습니다. 이 식을 전개하면 $ax^2 - a(\alpha + \beta)x + a\alpha\beta = 0$이 됩니다. 원래의 방정식 $ax^2 + bx + c = 0$과 각 항의 계수를 비교해 보면, $-a(\alpha + \beta) = b$이므로 $\alpha + \beta = -\frac{b}{a}$가 되고, $a\alpha\beta = c$이므로 $\alpha\beta = \frac{c}{a}$가 유도됩니다. 즉, 근의 공식으로 복잡한 계산을 거쳐 개별 근을 구하지 않더라도, 계수의 비율만으로 근들 사이의 관계를 알 수 있다는 점이 핵심입니다.

### 기본 성질
- 두 근의 합: $\alpha + \beta = -\frac{b}{a}$
- 두 근의 곱: $\alpha\beta = \frac{c}{a}$
- 예시: $x^2 - 5x + 6 = 0$에서 두 근의 합은 $-\frac{-5}{1} = 5$이고, 곱은 $\frac{6}{1} = 6$입니다. 실제 근인 $2$와 $3$을 더하고 곱한 값과 일치함을 확인할 수 있습니다.

## 학습 체크
- 계수 $a$가 $1$이 아닌 경우, 합과 곱을 구할 때 $a$로 나누는 과정을 잊지 않았는가?
- 근의 공식으로 구한 두 근의 합과 곱이 근과 계수의 관계로 구한 값과 일치하는가?
- 이차방정식의 근가 아닌 계수 자체의 성질을 이용해 문제를 해결할 수 있는가?

## 관련 개념
- **수열**: 수열의 각 항이 이차방정식의 근이 되는 경우, 근과 계수의 관계를 통해 수열의 일반항이나 합을 구할 수 있습니다.
- **이차함수**: 이차함수의 그래프가 $x$축과 만나는 두 점의 좌표(절편)의 합과 곱을 근과 계수의 관계를 통해 쉽게 구할 수 있습니다.
