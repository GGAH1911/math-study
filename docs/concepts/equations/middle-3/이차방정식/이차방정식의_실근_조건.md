# 이차방정식의 실근 조건

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
이차방정식의 실근 존재 여부는 판별식 $D = b^2 - 4ac$의 부호에 의해 결정됩니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)이 실근을 갖기 위한 필요충분조건은 판별식 $D = b^2 - 4ac \geq 0$을 만족하는 것입니다. 판별식의 값에 따라 방정식의 해의 상태는 세 가지로 구분됩니다. 우선 $D > 0$인 경우, 근의 공식에 의해 $x = \tfrac{-b \pm \sqrt{D}}{2a}$라는 서로 다른 두 실근을 갖습니다. $D = 0$인 경우에는 $x = -\tfrac{b}{2a}$라는 하나의 실근을 갖는데, 이를 중근이라고 합니다. 마지막으로 $D < 0$인 경우에는 루트 안의 값이 음수가 되어 실근이 존재하지 않으며, 복소수 범위에서만 근을 가집니다.

### 직관과 기하적 의미
이차방정식의 실근은 이차함수 $y = ax^2 + bx + c$의 그래프인 포물선이 $x$축과 만나는 점의 $x$좌표를 의미합니다. 따라서 판별식은 포물선과 $x$축의 교점 개수를 시각적으로 나타냅니다. $D > 0$이면 포물선이 $x$축과 두 점에서 만나고, $D = 0$이면 포물선이 $x$축에 접하며, $D < 0$이면 포물선이 $x$축 위로 떠 있거나 아래로 내려가 있어 만나지 않습니다.

### 기본 성질
- $D > 0$: 서로 다른 두 실근을 가짐
- $D = 0$: 중근(중복도 2인 실근)을 가짐
- $D < 0$: 실근이 존재하지 않음

## 학습 체크
- 판별식 $D$의 값이 0일 때, 왜 이를 '중근'이라고 부르는지 그래프의 접하는 형태와 연결하여 설명할 수 있는가?
- 이차방정식의 계수 $a, b, c$ 중 하나가 미지수일 때, 실근을 갖기 위한 조건으로 $D$를 어떻게 활용하는가?

## 관련 개념
- **이차방정식**: 판별식은 이차방정식의 해의 종류를 판별하여 방정식의 성질을 파악하는 핵심 도구입니다.
