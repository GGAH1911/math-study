# 이차방정식

> **단원** · 중3 · 선수: [인수분해](/concepts/인수분해) / [실수와 그 계산](/concepts/실수와_그_계산) · 다음: [방정식과 부등식](/concepts/방정식과_부등식) / [이차함수](/concepts/이차함수)

## 학습 목표
- $ax^2+bx+c=0$을 인수분해/근의 공식으로 푼다
- 판별식 $D$로 근의 종류를 판단한다
- 근과 계수의 관계를 활용한다

## 다룰 정의 / 정리 / 예제

**정의**
- 이차방정식, 근, 중근

**정리**
- [근의 공식](/concepts/근의_공식) — $x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$
- [판별식](/concepts/판별식) — $D=b^2-4ac$의 부호
- [근과 계수의 관계](/concepts/근과_계수의_관계) — $\alpha+\beta=-b/a$, $\alpha\beta=c/a$

**예제**
- 인수분해로 풀이
- 근의 공식 적용
