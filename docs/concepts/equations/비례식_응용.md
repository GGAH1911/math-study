# 비례식 응용

> **예제** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
$x:6=2:3$ 풀이

## 본문 (학습 시 채워짐)

### 문제

$x:6=2:3$을 만족하는 $x$의 값을 구하세요.

### 단계별 풀이

**1단계: 비례식을 분수 형태로 바꿔 이해하기**

$x:6=2:3$은 "$x$가 $6$과의 비가 $2$와 $3$의 비와 같다"는 뜻입니다. 이를 분수로 쓰면:
$$\frac{x}{6} = \frac{2}{3}$$

**2단계: 양변에 6을 곱해 $x$를 구하기**

분수 형태에서 $x$를 구하기 위해 양변에 6을 곱합니다. (일차방정식 풀이와 동일한 아이디어입니다)
$$x = \frac{2}{3} \times 6 = \frac{2 \times 6}{3} = \frac{12}{3} = 4$$

또는 **외항의 곱 = 내항의 곱** 성질을 바로 적용할 수도 있습니다:
$$x:6 = 2:3 \Rightarrow x \times 3 = 6 \times 2 \Rightarrow 3x = 12 \Rightarrow x = 4$$

**3단계: 검산하기 (선택)**

$x=4$를 원래 식에 대입: $4:6 = 2:3$ → 양변을 간단히 하면 $\frac{2}{3} = \frac{2}{3}$ ✓

### 답

$$x = 4$$

### 변형·주의

- **외항의 곱 = 내항의 곱**: $a:b = c:d$일 때, $ad = bc$입니다. 이 성질을 알면 분수로 바꾸지 않아도 바로 풀 수 있습니다.
- **검산 팁**: 구한 답을 대입해 양변이 정말 같은 비인지 항상 확인하세요.
- **공통 인수로 약분**: $6$과 $3$의 최대공약수가 $3$이므로, $\frac{2 \times 6}{3} = 2 \times 2 = 4$처럼 먼저 약분하면 더 간단합니다.
