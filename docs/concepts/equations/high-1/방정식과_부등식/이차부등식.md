# 이차부등식

## 정확한 진술

이차부등식(quadratic inequality)은 $ax^2 + bx + c > 0$, $ax^2 + bx + c < 0$, $ax^2 + bx + c \geq 0$, $ax^2 + bx + c \leq 0$ 형태의 부등식입니다. 여기서 $a \neq 0$인 상수이고, 이를 만족하는 $x$의 범위를 구하는 것이 목표입니다.

이차부등식의 해를 구하기 위해 먼저 $ax^2 + bx + c = 0$의 근을 구합니다. 이는 인수분해하거나 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 사용합니다. 판별식 $D = b^2 - 4ac$의 값에 따라 실근의 개수가 결정됩니다.

## 직관: 포물선과 x축의 위치 관계

이차함수 $f(x) = ax^2 + bx + c$는 포물선 모양의 그래프를 그립니다. $a > 0$이면 위로 볼록하고, $a < 0$이면 아래로 볼록합니다. 

- $ax^2 + bx + c > 0$의 해는 포물선이 x축 **위에** 있는 x의 범위입니다.
- $ax^2 + bx + c < 0$의 해는 포물선이 x축 **아래에** 있는 x의 범위입니다.

실근 $\alpha, \beta$ ($\alpha < \beta$)가 있을 때, $a > 0$인 경우 $x < \alpha$ 또는 $x > \beta$에서 $f(x) > 0$이고, $\alpha < x < \beta$에서 $f(x) < 0$입니다.

## 기본 예

$x^2 - 5x + 6 > 0$을 풀어봅시다.

먼저 $x^2 - 5x + 6 = 0$의 근을 구합니다: $(x - 2)(x - 3) = 0$이므로 $x = 2$ 또는 $x = 3$입니다.

포물선 $y = x^2 - 5x + 6$는 위로 볼록하고 x축과 $x = 2, 3$에서 만나므로, $x < 2$ 또는 $x > 3$일 때 $y > 0$입니다.

따라서 **해는 $x < 2$ 또는 $x > 3$**입니다. (`sympy.solve(x**2 - 5*x + 6 > 0, x)`)
