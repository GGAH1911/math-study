# 이차부등식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차함수 그래프와 $x$축의 위치 관계를 이용하여 이차식의 부호에 따른 $x$의 범위를 찾는 과정입니다.

## 본문
이차부등식은 $ax^2 + bx + c > 0$, $ax^2 + bx + c < 0$, $ax^2 + bx + c \geq 0$, $ax^2 + bx + c \leq 0$의 형태를 가진 부등식입니다. 여기서 $a \neq 0$인 상수이며, 이 부등식을 만족하는 실수 $x$의 범위를 찾는 것이 핵심입니다. 이차부등식의 해를 구하기 위해서는 먼저 이차방정식 $ax^2 + bx + c = 0$의 근을 구해야 합니다. 이때 인수분해를 이용하거나 근의 공식 $x = \tfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 사용하여 근을 찾을 수 있으며, 판별식 $D = b^2 - 4ac$의 값에 따라 실근의 개수가 결정됩니다.

### 직관과 기하적 의미
이차부등식의 해는 이차함수 $f(x) = ax^2 + bx + c$의 그래프와 $x$축 사이의 위치 관계로 이해할 수 있습니다. 이차함수의 그래프는 포물선 모양을 그리며, $a > 0$이면 아래로 볼록하고 $a < 0$이면 위로 볼록한 형태를 띱니다. $ax^2 + bx + c > 0$의 해는 포물선이 $x$축보다 위쪽에 위치하는 $x$의 범위를 의미하며, $ax^2 + bx + c < 0$의 해는 포물선이 $x$축보다 아래쪽에 위치하는 $x$의 범위를 의미합니다. 예를 들어, $a > 0$이고 두 실근 $\alpha, \beta$ ($\alpha < \beta$)를 가질 때, $x < \alpha$ 또는 $x > \beta$에서 $f(x) > 0$이고, $\alpha < x < \beta$에서 $f(x) < 0$이 됩니다.

### 기본 성질
이차부등식의 해를 구하는 기본 예로 $x^2 - 5x + 6 > 0$을 살펴보겠습니다. 먼저 이차방정식 $x^2 - 5x + 6 = 0$을 인수분해하면 $(x - 2)(x - 3) = 0$이 되어 $x = 2$ 또는 $x = 3$이라는 근을 얻습니다. 그래프 관점에서 보면, 이 함수는 아래로 볼록한 포물선이며 $x$축과 $x=2, 3$에서 만납니다. 따라서 그래프가 $x$축보다 위쪽에 있는 구간은 $x < 2$ 또는 $x > 3$이므로, 최종적인 해는 $x < 2$ 또는 $x > 3$이 됩니다.

## 학습 체크

- 이차항의 계수 $a$의 부호가 그래프의 모양과 부등식의 해에 어떤 영향을 미치나요?
- 판별식 $D$의 값에 따라 부등식의 해가 어떻게 달라지는지 설명할 수 있나요?

## 관련 개념
- **방정식과 부등식**: 이차방정식의 해는 이차부등식의 경계가 되며, 방정식의 근을 기준으로 부등식의 해 구간이 결정됩니다.
