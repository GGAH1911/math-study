# 근과 계수의 관계 활용

> **예제** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차방정식의 두 근의 합과 곱을 이용하여 근에 관한 복잡한 식의 값을 구하는 방법입니다.

## 본문
방정식 $x^2 - 3x + 1 = 0$의 두 근을 $\alpha, \beta$라 할 때, $\alpha^2 + \beta^2$의 값을 구하시오.

### 단계별 풀이
**1단계: 근과 계수의 관계 적용**
주어진 방정식에서 근과 계수의 관계에 의해 $\alpha + \beta = 3$, $\alpha\beta = 1$입니다. 이차방정식 $x^2 + px + q = 0$에서 두 근의 합은 $-p$이고 곱은 $q$이기 때문입니다.

**2단계: 구하는 식을 근의 합과 곱으로 변형**
$\alpha^2 + \beta^2$를 직접 구하기는 어렵지만, 곱셈 공식의 변형을 이용하여 다음과 같이 다시 쓸 수 있습니다.
$$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$$
이 식은 근과 계수의 관계로 이미 알고 있는 값들로만 표현됩니다.

**3단계: 값 대입 및 계산**
$$\alpha^2 + \beta^2 = 3^2 - 2 \cdot 1 = 9 - 2 = 7$$

### 답과 변형
$$\alpha^2 + \beta^2 = 7$$

이 방법은 근의 구체적인 값을 구하지 않고도 식의 값을 구할 수 있다는 점이 핵심입니다. $\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)$ 또는 $\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta}$와 같은 식들도 동일한 원리로 해결할 수 있습니다. 계수가 복잡한 문제일수록 이 방식이 매우 유용합니다.

## 학습 체크
- 근의 합과 곱을 알 때, 이를 이용해 변형된 식의 값을 계산할 수 있는가?
- 근의 값을 직접 구하지 않고도 항등식을 활용하여 문제를 해결할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 이차방정식의 해를 구하는 과정에서 근과 계수의 관계는 가장 기본이 되는 도구입니다.
