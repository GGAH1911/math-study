# 근과 계수의 관계 활용

> **예제** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)
## 요약
근 합·곱 식의 값

## 본문

### 문제

방정식 $x^2 - 3x + 1 = 0$의 두 근을 $\alpha, \beta$라 할 때, $\alpha^2 + \beta^2$의 값을 구하시오.

### 단계별 풀이

**1단계: 근과 계수의 관계 적용**
주어진 방정식에서 근과 계수의 관계에 의해 $\alpha + \beta = 3$, $\alpha\beta = 1$입니다. (방정식 $x^2 + px + q = 0$에서 근의 합은 $-p$, 근의 곱은 $q$이므로)

**2단계: 구하는 식을 근의 합과 곱으로 변형**
$\alpha^2 + \beta^2$를 직접 구하기는 어렵지만, 항등식을 이용하여 다시 쓸 수 있습니다:
$$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$$
우변이 근과 계수의 관계로 알 수 있는 값들로만 표현됩니다.

**3단계: 값 대입 및 계산**
$$\alpha^2 + \beta^2 = 3^2 - 2 \cdot 1 = 9 - 2 = 7$$

### 답

$$\alpha^2 + \beta^2 = 7$$

(검증: `sympy.symbols('x'); sympy.solve(x**2 - 3*x + 1, x)` → 근은 무리수이지만, 근과 계수의 관계만으로 답을 얻음)

### 변형/주의

- **다른 식들도 같은 방법**: $\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)$, $\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta}$ 등도 항등식으로 변형하여 구합니다.
- **핵심**: 근의 구체적인 값을 구하지 않고도 근에 관한 식의 값을 구할 수 있다는 점이 이 방법의 강점입니다. 수능에서는 계수가 복잡한 경우가 많으므로 유용합니다.
