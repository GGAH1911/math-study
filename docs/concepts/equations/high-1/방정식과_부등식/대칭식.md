# 대칭식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 정확한 진술

두 개 이상의 변수를 포함한 식에서, **어떤 두 변수를 서로 바꾸어도 식의 값이 변하지 않을 때**, 그 식을 **대칭식**이라 합니다. 예를 들어 두 변수 $a$, $b$의 식 $f(a, b)$가 $f(a, b) = f(b, a)$를 만족하면 대칭식입니다.

가장 기본적인 대칭식은 **기본 대칭식**으로, 두 변수의 경우 $a + b$와 $ab$, 세 변수의 경우 $a + b + c$, $ab + bc + ca$, $abc$ 등이 있습니다. 모든 대칭식은 기본 대칭식으로 표현할 수 있다는 중요한 성질이 있습니다.

## 직관과 의미

대칭식은 순서가 없는 대상들을 다룰 때 자연스럽게 나타납니다. 예를 들어 "두 수의 합과 곱"은 두 수가 어느 것인지 구분할 필요가 없으므로 대칭식이 됩니다. 이차방정식 $x^2 - (a+b)x + ab = 0$의 두 근이 $a$, $b$일 때, 근의 합과 곱이라는 개념도 순서 무관적이므로 대칭식입니다.

근과 계수의 관계에서 대칭식을 알면, 두 근을 직접 구하지 않고도 근에 대한 식의 값을 구할 수 있습니다. 예를 들어 $a^2 + b^2 = (a+b)^2 - 2ab$는 대칭식을 기본 대칭식으로 표현하는 전형적인 예입니다.

## 한 줄 예

$a^3 + b^3 + c^3 - 3abc$는 $a + b + c$, $ab + bc + ca$, $abc$의 대칭식입니다. (검증: `sympy.factor(a**3 + b**3 + c**3 - 3*a*b*c)` → `(a + b + c)(a**2 + b**2 + c**2 - ab - bc - ca)`)
