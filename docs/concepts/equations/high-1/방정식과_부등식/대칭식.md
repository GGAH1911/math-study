# 대칭식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
두 개 이상의 변수 중 임의의 두 변수를 서로 바꾸어도 식의 값이 변하지 않는 식을 말합니다.

## 본문
두 개 이상의 변수를 포함한 식에서, 어떤 두 변수를 서로 바꾸어도 식의 값이 변하지 않을 때 그 식을 대칭식이라 합니다. 예를 들어 두 변수 $a, b$에 대한 식 $f(a, b)$가 $f(a, b) = f(b, a)$를 만족하면 대칭식입니다.

### 직관과 의미
대칭식은 대상의 순서가 중요하지 않은 상황에서 자연스럽게 나타납니다. 예를 들어 "두 수의 합과 곱"은 두 수 중 어느 것이 무엇인지 구분할 필요가 없으므로 대칭식이 됩니다. 이차방정식 $x^2 - (a+b)x + ab = 0$의 두 근이 $a, b$일 때, 근의 합과 곱이라는 개념 역시 순서와 무관하므로 대칭식에 해당합니다. 이러한 성질을 이용하면 근과 계수의 관계를 통해 두 근을 직접 구하지 않고도 근에 관한 식의 값을 효율적으로 계산할 수 있습니다.

### 기본 성질
가장 기본적인 형태를 기본 대칭식이라고 합니다. 두 변수의 경우 $a + b$와 $ab$가 있으며, 세 변수의 경우 $a + b + c$, $ab + bc + ca$, $abc$ 등이 있습니다. 모든 대칭식은 이러한 기본 대칭식들의 합과 곱의 형태로 표현할 수 있다는 중요한 성질을 가집니다. 예를 들어 $a^2 + b^2 = (a+b)^2 - 2ab$와 같이 복잡한 대칭식을 기본 대칭식으로 변환하여 다룰 수 있습니다.

## 학습 체크
- 변수의 위치를 바꾸었을 때 식의 형태가 유지되는지 확인하였는가?
- 복잡한 대칭식을 기본 대칭식(합, 곱 등)의 조합으로 변환할 수 있는가?
- 근과 계수의 관계를 이용하여 근의 합과 곱을 대칭식의 관점에서 이해하였는가?

## 관련 개념
- **방정식과 부등식**: 이차방정식의 두 근을 변수로 하는 식을 다룰 때, 근의 합과 곱을 이용해 대칭식을 계산함으로써 방정식의 해를 직접 구하지 않고도 식의 값을 구할 수 있습니다.
