# 부등식 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
부등식 조건이란 변수 사이의 관계를 부등호로 나타낸 식이며, 여러 조건이 주어질 때 이를 동시에 만족하는 영역을 찾는 것이 핵심입니다.

## 본문
부등식 조건이란 변수들 사이의 대소 관계를 부등호를 사용하여 나타낸 식을 의미합니다. 예를 들어 $x > 0$, $y \leq 5$, $2x + 3y < 20$과 같은 형태가 이에 해당합니다. 만약 문제에서 여러 개의 부등식 조건이 동시에 주어진다면, 모든 부등식을 한꺼번에 만족하는 변수 값들의 집합을 구해야 하며 이를 해집합 또는 가능 영역이라고 부릅니다.

### 직관과 기하적 의미
부등식 조건은 좌표평면 위에서 특정 영역으로 시각화하여 이해할 수 있습니다. 각 부등식은 평면을 나누는 경계선(직선 등)을 기준으로 한쪽 영역을 나타냅니다. 예를 들어 $x > 0$은 $y$축의 오른쪽 영역을, $y < 5$는 직선 $y = 5$의 아래쪽 영역을 의미하며, $x + y \leq 10$은 직선 $x + y = 10$의 아래쪽 영역을 나타냅니다. 여러 조건이 동시에 주어질 경우, 각 부등식이 나타내는 영역들이 서로 겹치는 교집합 부분이 모든 조건을 만족하는 최종 영역이 됩니다.

### 기본 성질
여러 부등식 조건이 주어졌을 때, 모든 조건을 동시에 만족하는 영역을 찾는 과정은 각 영역의 공통 부분을 찾는 과정과 같습니다. 특히 변수가 정수라는 조건이 추가되면, 해당 영역 내에 포함된 격자점의 개수를 구하는 방식으로 문제를 해결할 수 있습니다.

## 학습 체크
- 여러 부등식이 주어졌을 때, 각 부등식이 나타내는 영역의 공통 부분(교집합)을 정확히 찾았는가?
- 변수가 정수일 경우, 경계선 위에 있는 점을 포함해야 하는지(등호 포함 여부) 확인하였는가?

## 관련 개념
- **경우의 수**: 부등식 조건을 만족하는 영역 내의 정수 좌표(격자점)의 개수를 구함으로써 문제에서 요구하는 경우의 수를 계산할 수 있습니다.
