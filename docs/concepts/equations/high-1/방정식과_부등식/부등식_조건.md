# 부등식 조건

## 정확한 진술

부등식 조건이란 변수들 사이의 관계를 부등호로 나타낸 식입니다. 예를 들어 $x > 0$, $y \leq 5$, $2x + 3y < 20$ 같은 형태입니다. 여러 부등식 조건이 함께 주어질 때, 이들을 **동시에 만족하는** 모든 값의 집합을 **해집합** 또는 **가능 영역**이라 합니다.

## 직관과 기하적 의미

부등식 조건은 좌표평면 위의 영역으로 시각화할 수 있습니다. 각 부등식이 그리는 영역을 이해하면:

- $x > 0$: y축 오른쪽 반평면
- $y < 5$: 직선 $y = 5$ 아래 반평면  
- $x + y \leq 10$: 직선 $x + y = 10$ 아래 영역

여러 조건이 주어질 때, 각 영역이 **겹치는 교집합 부분**이 모든 조건을 동시에 만족합니다. 특히 $x, y$가 정수일 때 이 영역 안의 **격자점 개수**를 세면 경우의 수가 됩니다.

## 한 줄 예

$x > 0, y > 0, x + y \leq 4$ (단, $x, y$는 정수)를 모두 만족하는 $(x, y)$는 $(1,1), (1,2), (1,3), (2,1), (2,2), (3,1)$로 **총 6가지**입니다.
