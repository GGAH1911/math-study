# 중근과 판별식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차방정식의 판별식 $D$가 $0$일 때, 방정식은 하나의 실근인 중근을 가지며 이는 그래프가 $x$축에 접하는 상태를 의미합니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)에서 판별식 $D = b^2 - 4ac$는 방정식의 근의 종류를 결정하는 중요한 지표입니다. 판별식의 값에 따라 $D > 0$이면 서로 다른 두 실근을, $D = 0$이면 중근을, $D < 0$이면 허근을 갖습니다. 여기서 중근이란 $D=0$일 때 근의 공식 $x = \frac{-b \pm \sqrt{D}}{2a}$에서 $\sqrt{D}$가 $0$이 되어 $x = \frac{-b}{2a}$라는 단 하나의 값을 갖게 되는 상황을 말하며, 이는 대수적으로 같은 근이 두 번 반복되어 나타나는 상태를 의미합니다.

### 직관과 기하적 의미
기하학적으로 판별식은 이차함수 $y = ax^2 + bx + c$의 그래프와 $x$축이 만나는 교점의 개수로 해석할 수 있습니다. $D=0$인 경우, 포물선이 $x$축에 접하며 스치듯 지나가므로 교점은 단 하나가 됩니다. 미적분 관점에서 보면, 중근을 갖는 지점 $x = -\frac{b}{2a}$는 함수의 도함수 $f'(x) = 2ax + b$가 $0$이 되는 지점과 일치합니다. 즉, 함수의 극값이 $x$축 위에 놓여 있어 함수의 최댓값 또는 최솟값이 $0$이 되는 상황과 같습니다.

### 기본 성질
이차방정식이 중근을 갖는다는 것은 주어진 식이 $(x - k)^2 = 0$과 같이 완전제곱식의 형태로 인수분해됨을 의미합니다. 예를 들어 $x^2 - 6x + 9 = 0$의 경우, $D = (-6)^2 - 4(1)(9) = 0$이므로 중근 $x = 3$을 갖습니다.

## 학습 체크
- 판별식 $D$의 부호에 따른 실근의 개수와 종류를 구분할 수 있는가?
- 이차함수의 그래프가 $x$축에 접할 때의 대수적 조건과 기하적 의미를 연결할 수 있는가?
- 완전제곱식 형태의 방정식을 보고 중근의 개념을 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 극값이 $x$축과 만나는 지점은 함수의 그래프가 $x$축에 접하는 지점과 같으며, 이때 판별식은 $0$이 됩니다.
