# 중근과 판별식

## 정확한 진술

2차 방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)에서 **판별식** $D$는 다음과 같이 정의됩니다:

$$D = b^2 - 4ac$$

판별식의 값에 따라 근의 개수와 종류가 결정됩니다:
- $D > 0$일 때: 서로 다른 두 실근
- $D = 0$일 때: **중근**(같은 두 실근)
- $D < 0$일 때: 허근(실근 없음)

**중근**은 $D = 0$일 때 나타나는 상황으로, 근의 공식 $x = \frac{-b \pm \sqrt{D}}{2a}$에서 $\sqrt{D} = 0$이 되어 $x = \frac{-b}{2a}$ (단 하나의 값)이 됩니다.

## 직관과 기하적 의미

포물선 $y = ax^2 + bx + c$와 $x$축의 교점 개수로 생각할 수 있습니다. $D = 0$이면 포물선이 $x$축에 접하므로(스치므로) 교점은 1개입니다. 이 접점을 중근이라고 부르는 이유는 **대수적 중복도가 2**이기 때문입니다. 즉, 같은 근이 2번 나타난다는 뜻입니다.

미적분 관점에서는, $D = 0$인 점 $x = -\frac{b}{2a}$에서 도함수 $f'(x) = 2ax + b = 0$도 만족됩니다. 따라서 중근은 함수의 극값(최댓값 또는 최솟값)이 $x$축과 만나는 경우입니다.

## 한 줄 예

$x^2 - 6x + 9 = 0$에서 $D = 36 - 36 = 0$이므로 중근 $x = 3$을 갖습니다.

검산: `sympy.solve(x**2 - 6*x + 9, x)` → $[3, 3]$ 또는 $x=3$ (중복도 2)

일반적으로 $(x - k)^2 = 0$ 형태의 완전제곱식은 항상 $x = k$를 중근으로 가집니다.
