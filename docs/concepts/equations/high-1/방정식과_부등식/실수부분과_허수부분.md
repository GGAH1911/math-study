# 실수부분과 허수부분

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
복소수 $z = a + bi$에서 실수 $a$를 실수부분, 실수 $b$를 허수부분이라 하며, 이는 복소평면 위의 좌표 $(a, b)$로 대응됩니다.

## 본문
복소수는 $z = a + bi$ 형태로 나타낼 수 있습니다. 여기서 $a$와 $b$는 실수이며, $i$는 $i^2 = -1$을 만족하는 허수 단위입니다. 이때 $a$를 **실수부분**(real part), $b$를 **허수부분**(imaginary part)이라고 정의하며, 각각 $\text{Re}(z) = a$, $\text{Im}(z) = b$로 표기합니다. 여기서 주의할 점은 허수부분이 $bi$ 전체가 아니라 $bi$의 계수인 $b$ 자체를 의미한다는 것이며, 따라서 허수부분 또한 실수입니다.

### 직관과 기하적 의미
복소수는 **복소평면**(complex plane) 위에서 하나의 점으로 시각화할 수 있습니다. 가로축을 실수축, 세로축을 허수축으로 설정할 때, 복소수 $z = a + bi$는 좌표 $(a, b)$에 대응됩니다. 예를 들어 $z = 3 + 2i$는 복소평면 위의 점 $(3, 2)$를 나타냅니다. 이러한 기하적 표현을 통해 복소수의 위치를 직관적으로 파악할 수 있으며, 두 복소수 사이의 관계를 비교하는 데 유용합니다.

### 기본 성질
실수부분과 허수부분을 알면 복소수의 크기인 절댓값 $|z|$을 계산할 수 있습니다. 이는 원점으로부터 해당 점까지의 거리와 같으며, $|z| = \sqrt{a^2 + b^2}$로 정의됩니다. 복소수는 두 개의 독립적인 실수 정보를 포함하고 있으므로, 연산 시 실수부분과 허수부분을 분리하여 처리하는 것이 핵심입니다.

예를 들어 $z = 5 - 3i$인 경우, 실수부분은 $5$, 허수부분은 $-3$이며, 절댓값은 $\sqrt{5^2 + (-3)^2} = \sqrt{34}$가 됩니다.

## 학습 체크
- 허수부분을 구할 때 $i$를 포함하여 $bi$로 적지 않도록 주의했는가?
- 복소수 $z = a + bi$를 복소평면 위의 좌표 $(a, b)$로 정확히 변환할 수 있는가?
- 복소수의 절댓값을 구할 때 실수부분과 허수부분의 제곱의 합에 루트를 씌웠는가?

## 관련 개념
- **방정식과 부등식**: 복소수 범위로 확장된 방정식의 해를 구할 때, 실수부분과 허수부분을 분리하여 각 부분의 값이 $0$이 되어야 한다는 조건을 활용합니다.
