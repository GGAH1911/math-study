# 3차 방정식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
최고차항의 차수가 3차인 다항식 방정식으로, 그래프의 형태에 따라 실근의 개수가 결정됩니다.

## 본문
3차 방정식이란 최고차항의 차수가 3차인 다항식으로 이루어진 방정식을 의미합니다. 일반적인 형태는 $ax^3 + bx^2 + cx + d = 0$ ($a \neq 0$)과 같이 나타냅니다. 여기서 $a, b, c, d$는 실수 계수이며, 반드시 $a$가 0이 아니어야만 3차 방정식으로서의 정의를 충족합니다. 만약 $a$가 0이 된다면 차수가 낮아져 2차 이하의 방정식이 됩니다.

### 직관과 기하적 의미
3차 방정식의 해는 함수 $f(x) = ax^3 + bx^2 + cx + d$의 그래프가 $x$축과 만나는 점의 $x$좌표와 같습니다. 3차 함수 그래프는 양 끝의 부호가 서로 반대라는 특징이 있어, 그래프가 반드시 $x$축을 한 번 이상 통과하게 됩니다. 따라서 3차 방정식은 항상 최소한 하나 이상의 실근을 가집니다.

### 기본 성질
실근의 개수는 함수의 극값 위치에 따라 결정됩니다. 극값이 존재하지 않거나 극값의 부호가 같으면 실근은 1개이며, 극값 중 하나가 0이면 실근은 2개(중근 포함)가 됩니다. 극값이 $x$축의 양옆에 위치하면 실근은 3개가 됩니다.

예를 들어 $x^3 - 6x^2 + 11x - 6 = 0$은 3차 방정식이며, 이 방정식의 근은 $x = 1, 2, 3$입니다.

## 학습 체크
- 최고차항의 계수가 0이 될 경우 어떤 변화가 생기는가?
- 3차 방정식이 항상 적어도 하나의 실근을 갖는 이유는 무엇인가?
- 실근이 2개인 경우 그래프는 $x$축과 어떤 관계를 갖는가?

## 관련 개념
- **다항식**: 3차 방정식은 다항식의 항들을 등식으로 연결하여 만든 방정식입니다.
