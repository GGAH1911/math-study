# 4차 방정식

## 정확한 진술

4차 방정식이란 최고차항이 4차인 다항방정식으로, 일반형은 다음과 같습니다.

$$ax^4 + bx^3 + cx^2 + dx + e = 0 \quad (a \neq 0)$$

여기서 $a, b, c, d, e$는 실수(또는 복소수)이며, $a$는 0이 아니어야 4차 방정식입니다.

## 직관과 기하적 의미

4차 함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$의 그래프와 $x$축이 만나는 점의 $x$좌표를 구하는 것이 4차 방정식을 푸는 것입니다. $a > 0$이면 그래프는 양 끝에서 위로 올라가는 모양이고, $a < 0$이면 아래로 내려가는 모양입니다.

4차 방정식은 **최대 4개의 실근**을 가질 수 있습니다. 인수분해 관점에서 보면:
$$a(x - \alpha)(x - \beta)(x - \gamma)(x - \delta) = 0$$
형태로 나타낼 수 있으며, 여기서 $\alpha, \beta, \gamma, \delta$는 근(일부는 중근일 수 있음)입니다.

## 풀이 방법의 분류

고등학교 수학에서 다루는 4차 방정식은 보통 다음 중 하나입니다:

1. **인수분해 가능한 형**: $(x^2 + ax + b)(x^2 + cx + d) = 0$ 꼴
2. **치환으로 2차로 환원**: $x^4 - 5x^2 + 4 = 0$처럼 $y = x^2$로 놓으면 $y^2 - 5y + 4 = 0$이 되는 경우
3. **대칭 방정식**: $x^4 + x^3 + x^2 + x + 1 = 0$ 같은 특수한 형태

## 한 줄 예

$x^4 - 10x^2 + 9 = 0$은 $y = x^2$로 놓으면 $y^2 - 10y + 9 = 0$이 되어 $(y-1)(y-9) = 0$, 즉 $x^2 = 1$ 또는 $x^2 = 9$이므로 $x = \pm 1, \pm 3$입니다. (`sympy.solve(x**4 - 10*x**2 + 9, x)`)
