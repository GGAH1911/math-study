# 삼차방정식의 근과 계수의 관계

## 정확한 진술

삼차방정식 $ax^3 + bx^2 + cx + d = 0$ (단, $a \neq 0$)의 세 근을 $\alpha, \beta, \gamma$라 하면, 다음이 성립합니다:

$$\alpha + \beta + \gamma = -\frac{b}{a}$$
$$\alpha\beta + \beta\gamma + \gamma\alpha = \frac{c}{a}$$
$$\alpha\beta\gamma = -\frac{d}{a}$$

이를 **근과 계수의 관계**라 합니다. 특히 최고차 계수가 1일 때 ($a = 1$), 삼차방정식 $x^3 + px^2 + qx + r = 0$의 근과 계수의 관계는 더욱 간결합니다:
$$\alpha + \beta + \gamma = -p, \quad \alpha\beta + \beta\gamma + \gamma\alpha = q, \quad \alpha\beta\gamma = -r$$

## 직관/기하적 의미

이 관계식은 근의 개별 값을 알지 못해도 근들 사이의 합과 곱의 정보를 계수로부터 직접 읽을 수 있다는 의미입니다. 이항 정리나 다항식 전개를 통해 이해할 수 있습니다. 삼차방정식을 인수분해 형태로 쓰면:

$$a(x-\alpha)(x-\beta)(x-\gamma) = ax^3 + bx^2 + cx + d$$

우변을 전개할 때 $x^2$의 계수는 $-a(\alpha+\beta+\gamma)$가 되므로 첫 번째 관계식이 나오며, $x$의 계수와 상수항에서도 각각 유도됩니다. 따라서 **근들의 대칭적 조합이 정확히 방정식의 계수로 인코딩**되어 있습니다.

## 한 줄 예

방정식 $x^3 - 6x^2 + 11x - 6 = 0$의 세 근이 $1, 2, 3$이면: $1+2+3=6=\frac{b}{-a}$, $1·2+2·3+3·1=11=\frac{c}{a}$, $1·2·3=6=\frac{-d}{a}$ ✓

(`sympy.solve(x**3 - 6*x**2 + 11*x - 6, x)` → `[1, 2, 3]`)
