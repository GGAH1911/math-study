# 삼차방정식의 근과 계수의 관계

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
삼차방정식의 세 근의 합, 두 근의 곱의 합, 세 근의 곱이 방정식의 계수와 일정한 규칙을 가지고 연결되어 있다는 원리입니다.

## 본문
삼차방정식 $ax^3 + bx^2 + cx + d = 0$ ($a \neq 0$)의 세 근을 $\alpha, \beta, \gamma$라고 할 때, 다음의 관계가 성립합니다.
$$\alpha + \beta + \gamma = -\frac{b}{a}$$
$$\alpha\beta + \beta\gamma + \gamma\alpha = \frac{c}{a}$$
$$\alpha\beta\gamma = -\frac{d}{a}$$
특히 최고차항의 계수가 $1$인 $x^3 + px^2 + qx + r = 0$의 경우에는 $\alpha + \beta + \gamma = -p$, $\alpha\beta + \beta\gamma + \gamma\alpha = q$, $\alpha\beta\gamma = -r$로 더욱 간결하게 나타납니다.

### 직관과 기하적 의미
이 관계식은 방정식의 개별 근을 직접 구하지 않더라도, 계수만 보고 근들의 대칭적인 조합(합, 곱 등)을 즉각적으로 파악할 수 있음을 의미합니다. 이는 삼차방정식을 세 일차식의 곱인 $a(x-\alpha)(x-\beta)(x-\gamma) = 0$ 형태로 전개했을 때, 각 차수의 계수가 근들의 조합에 의해 결정된다는 원리에서 비롯됩니다. 즉, 방정식의 계수에는 근들의 정보가 체계적으로 인코딩되어 있습니다.

### 기본 성질
- 근의 개별 값을 몰라도 근들의 합과 곱을 계수로부터 바로 읽어낼 수 있습니다.
- 근들이 어떤 값인지 알지 못해도 근들 사이의 관계식(예: $\alpha^2 + \beta^2 + \gamma^2$)을 계산할 수 있습니다.
- 계수가 실수일 때, 한 근이 허수이면 반드시 그 켤레복소수도 근이 된다는 성질과 결합하여 활용됩니다.

## 학습 체크
- 최고차항의 계수가 $1$이 아닐 때, 계수와 근의 관계를 구할 때 $a$를 나누어 주었는가?
- 근의 합, 두 근의 곱의 합, 세 근의 곱에서 부호($+$, $-$)가 번갈아 나타나는 규칙을 정확히 적용하였는가?
- 근의 합과 곱뿐만 아니라, 근들의 제곱의 합과 같은 변형된 식을 구할 때 근과 계수의 관계를 적절히 활용하였는가?

## 관련 개념
- **다항식**: 삼차방정식은 삼차다항식이 $0$과 같다고 놓은 식이며, 근과 계수의 관계는 다항식의 전개 원리를 바탕으로 합니다.
- **이차방정식**: 이차방정식에서의 근과 계수의 관계가 삼차방정식으로 확장된 형태입니다.
- **인수정리**: 방정식의 근가 $\alpha$이면 $(x-\alpha)$를 인수로 갖는다는 원리는 근과 계수의 관계를 유도하는 기초가 됩니다.
