# 해집합의 포함관계

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
두 방정식 또는 부등식의 해집합 사이의 포함 관계를 통해 해의 일치 여부를 판단할 수 있다.

## 본문
두 방정식(또는 부등식) $P(x) = 0$과 $Q(x) = 0$에 대하여, $P(x) = 0$의 해집합을 $A$, $Q(x) = 0$의 해집합을 $B$라고 할 때, $A \subseteq B$이면 "$P(x) = 0$의 해집합이 $Q(x) = 0$의 해집합에 포함된다"고 하며, $A$는 $B$의 부분집합이라고 표현한다. 만약 $A = B$이면 두 방정식의 해집합이 같다고 한다.

### 직관과 기하적 의미
수직선 위에서 해집합을 점이나 구간으로 나타낼 때, 한 집합이 다른 집합을 완전히 품고 있는 상태를 의미한다. 예를 들어 $x^2 = 4$의 해집합 $\{-2, 2\}$와 $x^2 - 4 = 0$의 해집합 $\{-2, 2\}$는 서로 같으므로 $A = B$이다. 또한 $|x| < 1$의 해집합 $\{x \mid -1 < x < 1\}$은 $|x| < 2$의 해집합 $\{x \mid -2 < x < 2\}$에 완전히 포함되므로 $A \subseteq B$의 관계를 갖는다.

### 기본 성질
두 방정식이 같은 해를 가질 조건은 두 해집합이 서로를 포함하는 상태, 즉 $A = B \Leftrightarrow (A \subseteq B) \text{ and } (B \subseteq A)$임을 확인하는 것이다. 이는 방정식의 동치 관계를 증명할 때 핵심적인 역할을 하며, 함수 단원에서 두 함수의 영점이 같다는 표현도 이와 같은 맥락에서 이해할 수 있다.

## 학습 체크
- $x^2 - 5x + 6 = 0$의 해집합 $\{2, 3\}$이 $(x-2)(x-3)(x-4) = 0$의 해집합 $\{2, 3, 4\}$의 부분집합임을 설명할 수 있는가?
- 두 방정식의 해집합이 같기 위해 필요한 두 가지 포함 관계 조건을 알고 있는가?

## 관련 개념
- **집합과 명제**: 해집합을 집합의 관점에서 정의하고, 포함 관계를 부분집합과 상등의 개념으로 다룬다.
