# 공통근

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
두 개 이상의 방정식이 동시에 만족하는 해를 공통근이라고 합니다.

## 본문
두 개 이상의 방정식이 공통으로 갖는 근을 **공통근**이라 합니다. 즉, 두 방정식 $f(x) = 0$과 $g(x) = 0$이 있을 때, 두 방정식을 동시에 만족하는 값 $\alpha$를 공통근이라 부릅니다. 공통근이 존재한다는 것은 두 곡선 $y = f(x)$와 $y = g(x)$의 그래프가 어떤 점에서 만난다는 의미입니다.

### 직관과 기하적 의미
이차방정식 두 개 $ax^2 + bx + c = 0$과 $dx^2 + ex + f = 0$을 예로 들어봅시다. 각 방정식의 해는 포물선과 $x$축의 교점을 의미합니다. 이때 공통근이 존재한다는 것은 두 포물선이 $x$축 위의 **같은 점에서 만난다**는 뜻입니다.

### 기본 성질
공통근 $\alpha$가 존재하면, $\alpha$를 두 방정식에 모두 대입했을 때 결과값이 $0$이 됩니다. 따라서 두 식의 차인 다항식 $f(x) - g(x)$ 역시 $\alpha$를 근으로 가지게 됩니다. 이러한 성질을 이용하면 두 방정식의 공통근은 두 방정식의 최대공약수와 밀접한 관련이 있음을 알 수 있습니다.

## 학습 체크
- 두 방정식의 차를 구했을 때 나타나는 일차식의 해가 공통근의 후보가 될 수 있음을 이해하고 있는가?
- 공통근이 존재할 때 두 함수의 그래프가 $x$축과 만나는 지점이 일치하는지 확인할 수 있는가?

## 관련 개념
- **이차방정식**: 각 방정식의 해가 그래프와 $x$축의 교점을 의미하므로, 공통근은 두 포물선이 $x$축과 만나는 공통된 지점을 찾는 과정과 같습니다.
