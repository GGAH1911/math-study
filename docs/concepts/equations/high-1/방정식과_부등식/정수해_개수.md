# 정수해 개수

## 정확한 진술

**정수해의 개수**란, 주어진 방정식이나 부등식을 만족하는 정수인 해의 총 개수를 의미합니다. 예를 들어 방정식 $x^2 - 5x + 6 = 0$을 풀면 $x = 2$ 또는 $x = 3$이므로 정수해는 2개입니다. 마찬가지로 부등식 $-2 < x < 5$의 정수해는 $-1, 0, 1, 2, 3, 4$이므로 개수는 6개입니다.

## 직관/기하적 의미

방정식이나 부등식의 **모든 해** 중에서 정수인 것만 세는 작업입니다. 직선이나 곡선과 수직선의 교점을 생각해보면, 실수 해가 무한히 많거나 특정 범위에 퍼져 있을 때도 있는데, 이 중에서 정수인 점들만 찾는 것이 정수해를 구하는 과정입니다.

수능 문제에서는 두 함수가 만나는 점의 개수, 접선이 정수 좌표를 지나는 경우의 수, 또는 정수 조건을 추가로 만족하는 해의 개수 같은 식으로 자주 출제됩니다. 특히 **연립부등식의 정수해 개수**는 이차함수나 절댓값 함수와 결합하여 어려운 문제로 등장합니다.

## 한 줄 예

방정식 $x^2 - 7x + 10 = 0$의 정수해는 $x = 2, 5$이므로 정수해의 개수는 **2개**입니다. (검산: `sympy.solve(x**2 - 7*x + 10, x)`)

부등식 $1 \le x < 10$의 정수해는 $1, 2, 3, \ldots, 9$이므로 정수해의 개수는 **9개**입니다.

## 주의할 점

- 실수 범위에서 해가 존재하더라도 그 중 정수가 없으면 정수해의 개수는 0입니다.
- 부등식에서 경곗값 포함 여부($<$, $\le$, $>$, $\ge$)를 정확히 확인해야 정수해 개수를 올바르게 셀 수 있습니다.
- 연립 조건(예: $x^2 < 9$이고 $x > 0$)이 주어지면 모든 조건을 동시에 만족하는 정수만 세어야 합니다.
