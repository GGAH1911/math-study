# 정수해 개수

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식이나 부등식을 만족하는 해 중에서 정수인 값의 총 개수를 의미합니다.

## 본문
정수해의 개수란 주어진 방정식이나 부등식을 만족하는 해 중에서 정수인 값의 총 개수를 의미합니다. 예를 들어 방정식 $x^2 - 5x + 6 = 0$의 해는 $x = 2$ 또는 $x = 3$이므로 정수해는 2개입니다. 부등식 $-2 < x < 5$의 경우, 이를 만족하는 정수는 $-1, 0, 1, 2, 3, 4$이므로 정수해의 개수는 6개입니다.

### 직관과 기하적 의미
방정식이나 부등식의 모든 실수 해 중에서 정수인 것만 골라내는 작업입니다. 기하학적으로는 그래프가 수직선과 만나는 교점 중 정수 좌표를 갖는 점의 개수를 찾는 것과 같습니다. 수능 등 평가원 시험에서는 두 함수의 교점 개수, 접선이 정수 좌표를 지나는 경우, 또는 절댓값 함수와 결합된 연립부등식의 정수해 개수와 같은 형태로 자주 출제됩니다.

### 기본 성질
- 실수 범위에서 해가 존재하더라도 그중 정수가 하나도 없다면 정수해의 개수는 0입니다.
- 부등식에서는 경곗값을 포함하는지 여부($<$, $\le$, $>$, $\ge$)에 따라 정수해의 개수가 달라지므로 이를 정확히 확인해야 합니다.
- 여러 조건이 동시에 주어지는 연립 조건의 경우, 모든 조건을 동시에 만족하는 정수만을 추출해야 합니다.

## 학습 체크
- 부등식의 경곗값이 정수일 때, 해당 값을 포함하는지($\le, \ge$) 혹은 제외하는지($<, >$)를 정확히 구분하였는가?
- 연립부등식의 경우, 각 부등식의 해를 구한 뒤 공통된 정수 범위가 무엇인지 정확히 찾아냈는가?

## 관련 개념
- **방정식과 부등식**: 정수해는 이들의 해 중에서 특정 조건을 만족하는 부분집합의 크기를 구하는 과정입니다.
