# 무리방정식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 정확한 진술

무리방정식은 **근호 안에 미지수를 포함하는 방정식**입니다. 예를 들어 $\sqrt{x} = 2$, $\sqrt{x+1} + x = 5$ 같은 형태입니다. 더 일반적으로, 방정식에 $\sqrt{f(x)}$, $\sqrt[3]{f(x)}$ 등의 무리식(radical expression)이 나타나는 경우를 무리방정식이라 합니다.

## 직관과 정의의 의미

무리방정식은 **정의역 제한**이 핵심입니다. 짝수 제곱근의 경우 근호 안이 0 이상이어야 하므로, 풀이 과정에서 자동으로 제약 조건이 생깁니다. 또한 양변을 제곱하여 풀 때 **거듭제곱 근사(extraneous solution)** 가 발생할 수 있으므로, 반드시 **검산**해야 합니다. 예를 들어 $\sqrt{x} = -1$은 실근이 없지만, 무심코 양변을 제곱하면 $x = 1$이 나와 혼동하기 쉽습니다.

기하적으로, $y = \sqrt{x}$ 같은 무리함수의 그래프와 직선의 교점을 찾는 문제로 볼 수 있습니다.

## 한 줄 예

$\sqrt{2x - 3} = 1$을 풀면, 정의역 조건 $2x - 3 \geq 0$ 즉 $x \geq \frac{3}{2}$ 후에, 양변을 제곱하여 $2x - 3 = 1$, $x = 2$를 얻고, 이를 원래 식에 대입하면 $\sqrt{1} = 1$ ✓이므로 해는 $x = 2$입니다.

**검증**: `from sympy import symbols, sqrt, solve; x = symbols('x'); solve(sqrt(2*x - 3) - 1, x)`
