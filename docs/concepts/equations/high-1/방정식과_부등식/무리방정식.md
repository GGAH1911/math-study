# 무리방정식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
근호 안에 미지수가 포함된 방정식으로, 풀이 과정에서 정의역 제한과 무연근 발생을 주의해야 합니다.

## 본문
무리방정식은 방정식의 항 중에 $\sqrt{f(x)}$ 또는 $\sqrt[3]{f(x)}$와 같이 근호(radical)를 포함하는 무리식이 나타나는 방정식을 의미합니다. 대표적인 예로는 $\sqrt{x} = 2$ 또는 $\sqrt{x+1} + x = 5$와 같은 형태가 있습니다. 무리방정식을 해결할 때 가장 중요한 원칙은 근호 안의 식이 0 이상이어야 한다는 정의역의 제한 조건을 반드시 고려해야 한다는 점입니다. 특히 양변을 제곱하여 방정식을 풀 경우, 원래 식에서는 성립하지 않는 가짜 해인 무연근이 발생할 수 있으므로 반드시 구한 해를 원래 식에 대입하여 검산하는 과정이 필수적입니다.

### 직관과 기하적 의미
기하학적으로 무리방정식은 무리함수의 그래프와 직선 또는 다른 곡선의 교점을 찾는 문제로 해석할 수 있습니다. 예를 들어 $\sqrt{x}$ 그래프와 직선 $y=2$가 만나는 지점을 찾는 것과 같습니다.

### 기본 성질
짝수 제곱근을 포함하는 경우 근호 안의 식은 항상 0보다 크거나 같아야 한다는 제약 조건이 따릅니다. 또한 양변을 제곱하는 과정에서 차수가 높아지며 원래 식에 존재하지 않던 해가 나타날 수 있으므로 주의가 필요합니다.

## 학습 체크
- 근호 안의 식에 대한 정의역 조건($f(x) \geq 0$)을 먼저 설정하였는가?
- 양변을 제곱하여 얻은 해를 원래의 방정식에 대입하여 무연근 여부를 확인하였는가?

## 관련 개념
- **방정식과 부등식**: 무리방정식은 미지수의 값을 찾는 과정이며, 무리부등식은 근호 안의 조건과 부등식의 방향을 동시에 고려하여 범위를 구하는 과정입니다.
