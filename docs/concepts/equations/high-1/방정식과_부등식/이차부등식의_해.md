# 이차부등식의 해

> **정리** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차부등식의 해는 이차함수 그래프의 모양($a$의 부호)과 $x$축과의 교점 개수(판별식 $D$의 부호)에 의해 결정된다.

## 본문
이차부등식 $ax^2 + bx + c > 0$ 또는 $ax^2 + bx + c < 0$ ($a \neq 0$)의 해를 구하기 위해서는 이차함수 $f(x) = ax^2 + bx + c$의 그래프 특성을 이해해야 한다. 이때 그래프의 방향은 $a$의 부호에 의해 결정되며, $x$축과의 교점 개수는 판별식 $D = b^2 - 4ac$의 부호에 의해 결정된다.

먼저 $D > 0$인 경우, 그래프가 $x$축과 서로 다른 두 점 $\alpha, \beta$ ($\alpha < \beta$)에서 만난다. $a > 0$이면 $f(x) > 0$의 해는 $x < \alpha$ 또는 $x > \beta$이고, $f(x) < 0$의 해는 $\alpha < x < \beta$이다. 반대로 $a < 0$이면 $f(x) > 0$의 해는 $\alpha < x < \beta$이고, $f(x) < 0$의 해는 $x < \alpha$ 또는 $x > \beta$이다.

$D = 0$인 경우, 그래프가 $x$축에 접하며 중근 $\alpha$를 갖는다. $a > 0$이면 $f(x) > 0$의 해는 $x \neq \alpha$인 모든 실수이고, $f(x) < 0$의 해는 없다. $a < 0$이면 $f(x) > 0$의 해는 없고, $f(x) < 0$의 해는 $x \neq \alpha$인 모든 실수이다.

$D < 0$인 경우, 그래프가 $x$축과 만나지 않는다. $a > 0$이면 $f(x) > 0$의 해는 모든 실수이고, $f(x) < 0$의 해는 없다. $a < 0$이면 $f(x) > 0$의 해는 없고, $f(x) < 0$의 해는 모든 실수이다.

### 증명 스케치
이차함수의 그래프를 그려 $x$축보다 위쪽에 있는 부분과 아래쪽에 있는 부분을 시각적으로 확인한다. $a$의 부호로 포물선의 볼록한 방향을 결정하고, 판별식으로 $x$축과의 교점 개수를 확정하여 부등식의 영역을 판별한다.

### 의의와 응용
이 원리는 부등식의 해를 구하는 체계적인 알고리즘을 제공한다. 판별식으로 근의 개수를 파악하고, 근의 공식으로 경계값을 구한 뒤, $a$의 부호에 따라 해의 범위를 결정함으로써 복잡한 부등식도 논리적으로 해결할 수 있다.
