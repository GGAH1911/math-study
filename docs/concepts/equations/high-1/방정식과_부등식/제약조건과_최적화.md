# 제약조건과 최적화

## 정확한 진술

제약조건과 최적화란 여러 일차 부등식이나 등식으로 주어진 제약 조건들 하에서, 목적함수(주로 일차함수)의 최댓값 또는 최솟값을 구하는 문제입니다. 평면에서는 다음과 같이 표현됩니다:

$$\text{제약 조건: } a_1x + b_1y + c_1 \leq 0, \; a_2x + b_2y + c_2 \leq 0, \; \cdots$$
$$\text{목적함수: } z = px + qy + r \; (\text{최대/최소화})$$

## 직관과 기하적 의미

각 부등식 제약은 평면을 두 반평면으로 나누며, 모든 제약을 동시에 만족하는 점들의 집합을 **실행영역(feasible region)**이라고 부릅니다. 이 영역은 보통 다각형 또는 무한 영역의 형태입니다. 목적함수 $z = px + qy + r$은 기울기가 $-\frac{p}{q}$인 직선족을 나타내는데, 이 직선들이 실행영역과 만나면서 $z$가 최대(또는 최소)가 되는 지점을 찾는 것이 목표입니다. **선형계획법의 기본정리**에 따르면, 최적값은 항상 실행영역의 경계(특히 꼭짓점)에서 달성됩니다. 이것이 비효율적으로 보이지만, 실제로는 유한한 수의 꼭짓점만 확인하면 되므로 계산이 효율적입니다.

## 한 줄 예

$x \geq 0, y \geq 0, x+y \leq 4, 2x+y \leq 6$이라는 제약 조건 하에서 $z = 3x + 2y$를 최대화하면, 점 $(2, 2)$에서 최댓값 $10$을 얻습니다.
