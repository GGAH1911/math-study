# 매개변수 범위

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식이나 부등식이 주어진 조건을 만족하도록 만드는 매개변수의 값의 범위를 구하는 것입니다.

## 본문
매개변수 범위는 방정식이나 부등식이 특정한 조건을 만족할 때, 그 조건을 결정하는 매개변수의 값의 범위를 구하는 것을 의미합니다. 예를 들어 이차방정식 $ax^2 + bx + c = 0$에서 계수가 매개변수 $m$으로 주어질 때, "실근을 가진다", "한 근만 양수다", "두 근 사이에 특정값이 있다"와 같은 조건을 만족하는 $m$의 범위를 구하는 과정이 이에 해당합니다.

### 직관과 기하적 의미
방정식이 조건을 만족하려면 판별식, 근과 계수의 관계, 함수값의 부호 등 여러 수학적 관계식을 함께 고려해야 합니다. 판별식 $D = b^2 - 4ac$를 매개변수로 정리하면 실근 존재 조건을 얻고, 이를 풀면 매개변수의 범위가 구간이나 부등식으로 나타납니다. 기하적으로는 이차함수의 그래프가 $x$축, 특정 직선, 또는 다른 곡선과 만나는 조건을 매개변수를 통해 해석하는 것입니다.

### 기본 성질
방정식의 근의 상태에 따라 매개변수의 범위가 결정됩니다. 예를 들어 방정식 $x^2 - (m+1)x + m = 0$이 서로 다른 두 실근을 가지려면 판별식 $(m+1)^2 - 4m > 0$을 만족해야 하며, 이를 정리하면 $(m-1)^2 > 0$이 되어 $m \neq 1$이라는 범위를 얻게 됩니다.

## 학습 체크
- 판별식의 부호가 매개변수의 범위에 어떤 영향을 미치는가?
- 근의 위치 조건(예: 두 근 사이에 특정값이 있음)을 함수값의 부호로 어떻게 변환할 수 있는가?
- 매개변수가 계수로 포함될 때, 그래프의 이동이나 모양 변화가 근의 개수에 어떤 영향을 주는가?

## 관련 개념
- **이차방정식**: 매개변수의 값에 따라 실근의 개수나 근의 위치가 결정되는 가장 대표적인 대상입니다.
