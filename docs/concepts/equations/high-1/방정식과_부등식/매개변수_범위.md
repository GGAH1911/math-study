# 매개변수 범위

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 정확한 진술

매개변수 범위는 방정식이나 부등식이 특정한 조건을 만족할 때, 그 조건을 결정하는 매개변수의 값의 범위를 구하는 것입니다. 예를 들어 이차방정식 $ax^2 + bx + c = 0$에서 계수가 매개변수 $m$으로 주어질 때, "실근을 가진다", "한 근만 양수다", "두 근 사이에 특정값이 있다" 같은 조건을 만족하는 $m$의 범위를 구합니다.

## 직관과 기하적 의미

방정식이 조건을 만족하려면 판별식, 근과 계수의 관계, 함수값의 부호 등 여러 수학적 관계식을 함께 고려해야 합니다. 판별식 $D = b^2 - 4ac$를 매개변수로 정리하면 실근 존재 조건을 얻고, 이를 풀면 매개변수의 범위가 구간이나 부등식으로 나타납니다. 기하적으로는 이차함수의 그래프가 $x$축, 특정 직선, 또는 다른 곡선과 만나는 조건을 매개변수를 통해 해석하는 것입니다.

## 한 줄 예

방정식 $x^2 - (m+1)x + m = 0$이 서로 다른 두 실근을 가지려면 판별식 $(m+1)^2 - 4m > 0$에서 $(m-1)^2 > 0$이므로 $m \neq 1$입니다.
