# 곱셈과 부등식 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
두 실수의 곱의 부호는 두 수의 부호가 같으면 양수, 다르면 음수이며, 부등식에 음수를 곱할 때는 부등호의 방향이 바뀝니다.

## 본문
두 실수 $a, b$에 대하여 곱 $ab$의 부호는 $a$와 $b$의 부호에 따라 다음과 같이 결정됩니다. 우선 $ab > 0$인 경우는 $a > 0$이고 $b > 0$인 경우 또는 $a < 0$이고 $b < 0$인 경우로, 즉 두 수의 부호가 서로 같을 때입니다. 반대로 $ab < 0$인 경우는 $a > 0$이고 $b < 0$인 경우 또는 $a < 0$이고 $b > 0$인 경우로, 두 수의 부호가 서로 다를 때입니다. 마지막으로 $ab = 0$인 경우는 $a = 0$이거나 $b = 0$인 경우입니다. 결과적으로 곱의 부호는 두 수의 부호 조합에 따라 양수, 음수, $0$의 세 가지 결과로 나타납니다.

### 직관과 기하적 의미
수직선 위에서 양수는 오른쪽, 음수는 왼쪽 방향을 의미합니다. 양수와 양수를 곱하면 양의 방향이 유지되어 결과는 양수가 됩니다. 음수와 음수를 곱할 때는 음의 방향이 두 번 뒤집히는 효과가 있어 결과는 다시 양수가 됩니다. 양수와 음수를 곱하면 한쪽 방향만 뒤집히므로 결과는 음수가 됩니다. 이러한 원리는 부등식에서도 동일하게 적용됩니다. 양수를 곱하면 부등호의 방향이 유지되지만, 음수를 곱하면 수직선 상의 위치 관계가 반대로 뒤집히므로 부등호의 방향이 바뀝니다. 예를 들어 $x < 3$에 $-2$를 곱하면 $-2x > -6$이 됩니다.

### 기본 성질
- $ab > 0 \iff (a > 0 \text{ and } b > 0) \text{ or } (a < 0 \text{ and } b < 0)$
- $ab < 0 \iff (a > 0 \text{ and } b < 0) \text{ or } (a < 0 \text{ and } b > 0)$
- $ab = 0 \iff a = 0 \text{ or } b = 0$

## 학습 체크
- 두 수의 부호가 같을 때 곱이 양수가 되는 이유를 수직선 상의 방향 변화로 설명할 수 있는가?
- 부등식의 양변에 음수를 곱했을 때 왜 부등호의 방향이 바뀌어야 하는지 이해하고 있는가?
- $(x-1)(x+2) < 0$과 같이 곱의 부호가 음수인 이차부등식을 풀 때, 두 인수의 부호가 서로 달라야 한다는 조건을 활용할 수 있는가?

## 관련 개념
- **경우의 수**: 두 실수의 부호 조합이 양수, 음수, $0$이라는 세 가지 결과로 나타나는 원리는 가능한 경우를 분류하는 원리와 연결됩니다.
