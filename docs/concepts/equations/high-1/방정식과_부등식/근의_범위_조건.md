# 근의 범위 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차방정식의 두 실근이 특정 구간에 모두 포함되기 위해서는 판별식, 축의 위치, 구간 양 끝점에서의 함수값 부호가 모두 조건을 만족해야 합니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 방정식 $f(x) = 0$의 두 근을 $\alpha, \beta$라 할 때, 두 근이 주어진 열린 구간 $p < x < q$ 안에 모두 포함될 필요충분조건은 다음과 같습니다.

$$\begin{cases}
D = b^2 - 4ac \geq 0 \\
p < \frac{-b}{2a} < q \\
\text{if } a > 0, \text{ then } f(p) > 0 \text{ and } f(q) > 0 \\
\text{if } a < 0, \text{ then } f(p) < 0 \text{ and } f(q) < 0
\end{cases}$$

이 조건들은 이차함수의 그래프가 $x$축과 만나는 지점의 위치를 결정하는 핵심 요소들입니다.

### 직관과 기하적 의미
포물선이 $x$축과 두 점에서 만나려면 먼저 판별식 $D \geq 0$을 만족하여 실근을 가져야 합니다. 그다음 두 근이 구간 $(p, q)$ 사이에 나란히 놓이려면 포물선의 중심축인 $x = -\tfrac{b}{2a}$가 반드시 해당 구간 내에 위치해야 합니다. 마지막으로, 포물선이 구간 밖으로 나가지 않고 구간 안에서만 $x$축과 만나려면 구간의 양 끝점에서의 함숫값이 축의 방향과 같은 부호를 유지해야 합니다. 예를 들어 아래로 볼록한 그래프($a > 0$)라면 양 끝점에서 함숫값이 양수여야 포물선이 $x$축 아래로 내려갔다가 다시 올라오며 구간 내에서 근을 형성합니다.

### 기본 성질
- 판별식 $D$는 근의 존재 여부(실근의 개수)를 결정합니다.
- 축의 위치는 두 근의 평균 위치를 결정하여 근이 구간 내에 있는지 판단하는 기준이 됩니다.
- 구간 양 끝점에서의 함숫값 부호는 근의 위치가 구간의 경계보다 안쪽에 있는지 결정합니다.

## 학습 체크
- 판별식이 $D > 0$임에도 불구하고 축의 위치가 구간 밖에 있다면 근은 어떻게 되는가?
- $a > 0$일 때 $f(p) \leq 0$ 또는 $f(q) \leq 0$인 경우, 근의 위치는 어떻게 변하는가?
- 구간이 닫힌 구간 $[p, q]$로 주어졌을 때, 부등호의 방향은 어떻게 수정되어야 하는가?

## 관련 개념
- **이차함수**: 이차방정식의 근은 이차함수 그래프와 $x$축의 교점의 $x$좌표와 동일한 의미를 가집니다.
- **판별식**: 이차방정식의 근이 실근인지 허근인지, 혹은 중근인지를 판별하는 도구입니다.
- **축의 방정식**: 이차함수의 대칭축은 두 근의 산술 평균과 같으므로 근의 위치를 결정하는 중요한 지표입니다.
