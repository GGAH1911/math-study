# 복소수의 연산

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 정확한 진술

복소수 $z_1 = a+bi$, $z_2 = c+di$ (단, $a,b,c,d \in \mathbb{R}$)의 연산은 다음과 같이 정의합니다:

- **덧셈**: $(a+bi) + (c+di) = (a+c) + (b+d)i$
- **뺄셈**: $(a+bi) - (c+di) = (a-c) + (b-d)i$  
- **곱셈**: $(a+bi)(c+di) = (ac-bd) + (ad+bc)i$ (단, $i^2 = -1$ 이용)
- **나눗셈**: $\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{c^2+d^2}$ (분모의 켤레복소수를 분자·분모에 곱함)

## 직관/기하적 의미

복소평면에서 복소수를 점 $(a,b)$로 볼 때, 덧셈과 뺄셈은 벡터 연산과 동일합니다. 예를 들어 두 점을 더하면 평행사변형의 대각선이 됩니다. 곱셈은 더욱 흥미로운데, 복소수를 극형식 $r e^{i\theta}$로 나타내면 $(r_1 e^{i\theta_1})(r_2 e^{i\theta_2}) = r_1r_2 e^{i(\theta_1+\theta_2)}$이므로, 곱셈은 크기는 곱해지고 편각(회전 각도)은 더해지는 변환입니다. 따라서 복소수의 곱셈은 평면 상의 회전과 확대·축소를 동시에 나타냅니다. 이것이 복소수가 기하학, 물리학, 신호처리에서 회전 변환의 핵심 도구인 이유입니다.

## 한 줄 예

$(1+2i) + (3-i) = 4+i$이고, $(1+i)(2+i) = 1+3i$입니다. (검산: `sympy.expand((1+1j)*(2+1j))` → `(1+3j)`)
