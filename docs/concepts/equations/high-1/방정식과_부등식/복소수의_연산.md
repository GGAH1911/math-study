# 복소수의 연산

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
복소수의 연산은 실수 부분과 허수 부분을 각각 분리하여 계산하며, 기하학적으로는 평면에서의 회전과 확대 및 축소를 의미합니다.

## 본문
복소수 $z_1 = a+bi$, $z_2 = c+di$ (단, $a,b,c,d \in \mathbb{R}$)의 연산은 다음과 같이 정의합니다. 덧셈은 실수 부분과 허수 부분을 각각 더한 $(a+c) + (b+d)i$로 계산하며, 뺄셈은 $(a-c) + (b-d)i$로 계산합니다. 곱셈은 $i^2 = -1$임을 이용하여 $(ac-bd) + (ad+bc)i$로 계산합니다. 나눗셈은 분모의 켤레복소수를 분자와 분모에 각각 곱하여 분모를 실수화함으로써 $\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{c^2+d^2}$와 같이 계산합니다.

### 직관과 기하적 의미
복소평면에서 복소수를 점 $(a,b)$로 볼 때, 덧셈과 뺄셈은 벡터의 연산과 동일한 원리를 가집니다. 예를 들어 두 복소수의 합은 두 벡터를 더했을 때 나타나는 평행사변형의 대각선 위치와 같습니다. 곱셈은 더욱 특별한 의미를 지니는데, 복소수를 극형식 $r e^{i\theta}$로 나타내면 곱셈의 결과는 크기는 두 복소수의 크기의 곱이 되고, 편각은 두 편각의 합이 됩니다. 즉, 복소수의 곱셈은 평면 위에서 도형을 회전시키면서 동시에 확대하거나 축소하는 변환을 의미하며, 이러한 특성 덕분에 복소수는 물리학이나 신호처리 분야에서 회전 변환을 다루는 핵심 도구로 사용됩니다.

### 기본 성질
- $(1+2i) + (3-i) = 4+i$
- $(1+i)(2+i) = 1+3i$

## 학습 체크
- 복소수의 나눗셈을 수행할 때 분모를 실수로 만들기 위해 어떤 과정을 거쳐야 하는가?
- 복소수의 곱셈이 기하학적으로 어떤 변환(회전, 확대, 축소)을 의미하는지 설명할 수 있는가?
