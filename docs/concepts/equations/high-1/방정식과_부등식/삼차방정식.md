# 삼차방정식

## 정확한 진술

삼차방정식은 최고차 항의 차수가 3인 다항방정식입니다. 일반적인 형태는 다음과 같습니다:

$$ax^3 + bx^2 + cx + d = 0 \quad (a \neq 0)$$

여기서 $a, b, c, d$는 실수이고, $a \neq 0$이어야 삼차방정식입니다. 만약 $a = 0$이면 이차 이하의 방정식이 되므로 삼차방정식의 정의에서 벗어납니다.

## 직관과 기하적 의미

삼차방정식 $ax^3 + bx^2 + cx + d = 0$의 해는 삼차함수 $y = ax^3 + bx^2 + cx + d$의 그래프가 $x$축과 만나는 점의 $x$좌표입니다. 

삼차함수의 그래프는 연속이고 부드러운 곡선으로, $x \to -\infty$일 때와 $x \to \infty$일 때 서로 다른 방향으로 진행합니다(최고차 계수의 부호에 따라). 따라서 **삼차방정식은 항상 적어도 하나의 실근을 갖습니다**. 

근의 개수는 상황에 따라 다릅니다:
- **서로 다른 세 개의 실근**: 그래프가 $x$축과 세 점에서 만남
- **중근(중복도 2)과 단순근**: 그래프가 $x$축에 접하고 한 점에서 교차
- **삼중근**: 그래프가 한 점에서 $x$축에 접함 (변곡점에서 접함)

## 한 줄 예

$x^3 - 6x^2 + 11x - 6 = 0$은 삼차방정식이며, 이를 인수분해하면 $(x-1)(x-2)(x-3) = 0$이므로 세 개의 실근 $x = 1, 2, 3$을 갖습니다.

(`sympy.solve(x**3 - 6*x**2 + 11*x - 6, x)` → `[1, 2, 3]`)
