# 삼차방정식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
최고차항의 차수가 3인 다항방정식으로, 그래프의 $x$축 교점의 $x$좌표를 구하는 문제입니다.

## 본문
삼차방정식은 최고차 항의 차수가 3인 다항방정식을 의미하며, 일반적인 형태는 $ax^3 + bx^2 + cx + d = 0$ ($a \neq 0$)입니다. 여기서 $a, b, c, d$는 실수이며, 반드시 $a$가 0이 아니어야 삼차방정식으로서의 정의를 만족합니다. 만약 $a=0$이 되면 차수가 낮아져 이차 이하의 방정식이 됩니다.

### 직관과 기하적 의미
삼차방정식 $ax^3 + bx^2 + cx + d = 0$의 해는 삼차함수 $y = ax^3 + bx^2 + cx + d$의 그래프가 $x$축과 만나는 점의 $x$좌표를 의미합니다. 삼차함수의 그래프는 연속적이고 부드러운 곡선 형태를 띠며, 최고차 계수의 부호에 따라 $x$가 무한히 커지거나 작아질 때 서로 반대 방향으로 진행합니다. 이로 인해 삼차방정식은 항상 적어도 하나의 실근을 갖게 됩니다. 근의 개수는 그래프와 $x$축의 위치 관계에 따라 달라지는데, 서로 다른 세 실근을 갖는 경우, 중근과 단순근을 갖는 경우, 그리고 변곡점에서 접하며 삼중근을 갖는 경우로 나뉩니다.

### 기본 성질
삼차방정식은 실계수 방정식일 때 반드시 하나 이상의 실근을 가집니다. 근의 형태는 그래프가 $x$축과 세 점에서 만날 때 서로 다른 세 실근을 가지며, $x$축에 접하는 지점이 생기면 중근을 포함하게 됩니다. 예를 들어 $x^3 - 6x^2 + 11x - 6 = 0$은 $(x-1)(x-2)(x-3) = 0$으로 인수분해되어 세 실근 $x=1, 2, 3$을 갖는 대표적인 삼차방정식입니다.

## 학습 체크
- 최고차항의 계수가 0이 될 경우 왜 삼차방정식이 될 수 없는가?
- 삼차방정식이 항상 적어도 하나의 실근을 갖는 이유를 함수의 극한과 그래프의 형태를 통해 설명할 수 있는가?
- 그래프가 $x$축과 접하는 상황이 방정식의 근의 개수에 어떤 영향을 미치는가?

## 관련 개념
- **방정식과 부등식**: 방정식은 등호를 사용하여 미지수의 값을 찾는 것이고, 부등식은 부등호를 사용하여 미지수의 범위를 찾는 것이며, 삼차방정식의 해를 통해 삼차부등식의 해를 구할 수 있습니다.
