# 행렬 성분 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
두 행렬이 같으려면 행과 열의 개수가 같은 동일한 크기를 가져야 하며, 대응하는 모든 위치의 성분이 일치해야 합니다.

## 본문
두 행렬이 같다는 것은 두 행렬의 크기가 서로 같고, 대응하는 모든 성분이 일치한다는 것을 의미합니다. 즉, $m \times n$ 행렬 $A = (a_{ij})$와 $B = (b_{ij})$에 대하여, $A = B$가 성립하기 위한 필요충분조건은 모든 $i$와 $j$에 대해 $a_{ij} = b_{ij}$인 것입니다. 만약 두 행렬의 행 또는 열의 개수가 하나라도 다르다면 두 행렬은 결코 같을 수 없으며, 크기가 같더라도 단 하나의 성분이라도 값이 다르면 두 행렬은 서로 다른 행렬로 간주합니다.

### 직관과 기하적 의미
행렬은 수들을 규칙에 따라 배열한 하나의 체계적인 표와 같습니다. 따라서 두 행렬이 같다는 것은 두 표의 구조와 내용이 완벽하게 일치함을 뜻합니다. 예를 들어, 두 개의 성적표를 비교할 때 학생 수와 과목 수가 동일해야 비교가 가능하며, 각 학생의 과목별 점수까지 모두 일치해야 두 성적표가 같다고 말할 수 있는 것과 같은 원리입니다.

### 기본 성질
- 행렬의 크기가 다르면 성분을 비교할 대상 자체가 존재하지 않으므로 같을 수 없습니다.
- 행렬의 크기가 같더라도 대응하는 위치의 성분 중 하나라도 다르면 두 행렬은 다릅니다.

## 학습 체크
- 두 행렬의 크기가 다를 때, 성분이 모두 같다는 조건이 성립할 수 있는가?
- 행렬 $A$와 $B$가 같을 때, 모든 성분 $a_{ij}$와 $b_{ij}$가 일치하는가?

## 관련 개념
- **연립일차방정식**: 행렬의 성분 조건과 행렬의 연산을 이용하여 미지수의 값을 구하는 과정을 행렬의 관점에서 체계적으로 표현할 수 있습니다.
