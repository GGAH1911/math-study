# 근의합

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha$, $\beta$라 할 때, **근의합**은 두 근을 더한 값을 의미합니다. 비에타 공식(근과 계수의 관계)에 의해:

$$\alpha + \beta = -\frac{b}{a}$$

이 관계식은 판별식을 구하거나 근의 공식을 사용하지 않고도 두 근의 합을 계수만으로 즉시 구할 수 있음을 보여줍니다.

## 직관과 기하적 의미

이차함수 $f(x) = ax^2 + bx + c$의 그래프(포물선)에서 두 근 $\alpha$, $\beta$는 $x$축과의 교점입니다. 근의합은 **이 두 교점의 중점을 나타내는 값의 2배**로 이해할 수 있습니다:

$$\text{중점의 } x\text{좌표} = \frac{\alpha + \beta}{2} = -\frac{b}{2a}$$

이것은 포물선의 대칭축과 정확히 일치합니다. 도함수 $f'(x) = 2ax + b = 0$의 해가 대칭축이므로, 근의합은 **도함수가 0이 되는 점**과도 직결되어 있습니다.

## 계산 예

방정식 $x^2 - 5x + 6 = 0$의 근의합: $-(-5)/1 = 5$

실제 근은 2와 3이므로 $2 + 3 = 5$ ✓

```python
from sympy import symbols, solve
x = symbols('x')
solve(x**2 - 5*x + 6, x)  # [2, 3]
```

## 응용: 근과 계수의 관계

근의합과 근의곱을 함께 알면 이차방정식을 복원할 수 있습니다. 두 근의 합이 4, 곱이 3이면:
- $-b/a = 4$ → $b = -4$ (단, $a = 1$)
- $c/a = 3$ → $c = 3$

따라서 방정식은 **$x^2 - 4x + 3 = 0$** 입니다.
