# 치환

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
어떤 변수를 새로운 문자로 바꾸어 복잡한 식을 더 단순한 형태로 변환하여 문제를 해결하는 과정입니다.

## 본문
어떤 변수를 다른 변수(보통 새로운 문자)로 바꾸어 식을 다시 나타내는 과정을 치환이라고 합니다. 형식적으로는 어떤 변수 $u = f(x)$로 정의할 때, 원래 식의 모든 $f(x)$를 $u$로 대체하는 것을 의미합니다. 예를 들어, 주어진 식이나 방정식에서 $x$ 또는 $x^2$ 같은 부분을 $t$로 놓으면, 원래 식이 $t$에 대한 더 간단한 형태로 변환됩니다.

### 직관과 의미
치환은 문제를 다른 관점에서 바라보는 전략입니다. 복잡하거나 고차인 방정식을 저차의 친숙한 형태로 변환하여 풀기 쉽게 만듭니다. 예를 들어, $x^4 - 5x^2 + 6 = 0$은 4차 방정식이라 어렵지만, $x^2 = t$로 놓으면 $t^2 - 5t + 6 = 0$이 되어 2차 방정식으로 축소됩니다. 이 경우 근의 공식을 사용해 $t$ 값을 구한 후, 다시 $x$의 값을 역산하여 원래 문제를 완성할 수 있습니다. 또한 치환은 복잡한 함수나 부등식을 표준적인 형태로 정규화하여, 계산을 체계적으로 만들고 실수를 줄이는 도구로 활용됩니다.

### 예시
$4x^2 + 4x + 1 = 9$를 풀 때, $2x + 1 = t$로 치환하면 $t^2 = 9$가 되어 $t = \pm 3$입니다. 이를 역으로 풀면 $x = 1$ 또는 $x = -2$를 얻습니다.

## 학습 체크
- 치환을 통해 차수를 낮추었을 때, 마지막에 원래 변수의 값을 구하기 위한 역산 과정을 수행하였는가?
- 새로운 문자로 치환할 때, 치환된 문자의 범위(예: $x^2 = t$이면 $t \ge 0$)를 고려하였는가?

## 관련 개념
- **방정식과 부등식**: 치환을 통해 고차 방정식이나 복잡한 부등식을 저차의 친숙한 형태로 변환하여 해를 구할 수 있습니다.
