# 정수해

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식이나 부등식을 만족하는 해 중에서 값이 정수인 해를 의미합니다.

## 본문
방정식 $f(x) = 0$의 정수해란 이 방정식을 만족하는 해가 정수인 경우를 말합니다. 더 일반적으로는 주어진 방정식 또는 부등식을 만족하는 모든 정수를 구하는 것을 의미합니다. 예를 들어, 이차방정식 $x^2 - 5x + 6 = 0$의 해는 $x = 2$ 또는 $x = 3$이며, 두 해가 모두 정수이므로 이 방정식은 정수해를 갖습니다.

### 직관과 기하적 의미
해석학적 관점에서 방정식의 해가 정수라는 것은 해당 식이 매우 정돈된 구조를 가지고 있음을 시사합니다. 대부분의 방정식은 무리수나 복소수 해를 갖는 경우가 많기 때문에, 정수해를 갖는 경우는 수학적으로 특별한 의미를 지닙니다. 기하학적으로는 함수 $y = f(x)$의 그래프가 좌표가 모두 정수인 정수 격자점을 지나는 것을 의미합니다. 앞선 예시의 포물선 $y = x^2 - 5x + 6$은 점 $(2, 0)$과 $(3, 0)$이라는 정수 격자점을 지나며 $x$축과 만납니다.

### 기본 성질
정수해를 찾는 문제는 일반적인 해를 구하는 것보다 조건이 까다롭지만, 정수론적 성질을 이용하면 해의 범위를 제한하거나 특정 값을 찾아내는 데 유용합니다. 부등식의 경우 일반적인 해의 범위 내에 포함되는 정수들을 모두 나열함으로써 정수해를 구할 수 있습니다.

## 학습 체크
- 방정식의 해가 실수 범위에서는 존재하지만 정수 범위에서는 존재하지 않는 경우는 어떤 경우인가요?
- 부등식 $2x + 1 < 8$에서 일반적인 해의 범위와 정수해의 집합은 어떻게 다른가요?

## 관련 개념
- **방정식과 부등식**: 정수해는 방정식이나 부등식을 만족하는 수의 집합 중 정수라는 특정한 조건을 만족하는 원소들을 찾는 과정입니다.
