# 허근의 조건

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 **허근의 조건**은 판별식 $D = b^2 - 4ac < 0$일 때입니다. 이 경우 방정식의 두 근은 모두 실수가 아닌 복소수(허근)이며, $x = \frac{-b \pm \sqrt{D}}{2a} = \frac{-b \pm i\sqrt{|D|}}{2a}$ 형태의 켤레복소수 쌍입니다.

## 직관적 의미

이차함수 $y = ax^2 + bx + c$의 그래프는 포물선입니다. 이 포물선이 $x$축과 만나지 않으면 실근이 없습니다. 판별식 $D < 0$은 정확히 이 상황을 나타냅니다. 즉, $ax^2 + bx + c = 0$을 만족하는 실수 $x$가 존재하지 않는다는 뜻입니다. 

그래픽으로 생각하면, $a > 0$일 때 포물선이 $x$축 위에 떠 있고, $a < 0$일 때 $x$축 아래에 떠 있습니다. 어느 경우든 교점이 없으므로, 방정식을 풀려면 실수 범위를 넘어 복소수 영역으로 확장해야 합니다.

## 한 줄 예

방정식 $x^2 - 2x + 5 = 0$은 $D = 4 - 20 = -16 < 0$이므로 허근을 가지며, 근의 공식으로 $x = \frac{2 \pm 4i}{2} = 1 \pm 2i$입니다.

```python
# 검증: sympy.solve(x**2 - 2*x + 5, x)
# [1 - 2*I, 1 + 2*I]
```

## 핵심 체크리스트

- 판별식이 음수이면 → 허근 존재
- 허근은 항상 켤레복소수 쌍으로 나타남 (복소계수가 아닌 실계수 이차방정식)
- 허근은 방정식을 만족하는 유효한 해이며, 단지 실수가 아닐 뿐
