# 중근과 단순근

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차방정식의 판별식 결과에 따라 근이 중복되어 하나로 나타나는 상태를 중근, 서로 다른 두 실근을 갖는 상태를 단순근이라고 합니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)에서 판별식 $D = b^2 - 4ac$의 값에 따라 근의 형태가 결정됩니다. 판별식 $D = 0$인 경우, 방정식은 하나의 실근을 갖지만 중복된 값을 가지므로 이를 중근이라 하며, 근의 공식에 의해 $x = \dfrac{-b}{2a}$가 됩니다. 이때의 중근도는 2입니다. 반면 판별식 $D > 0$인 경우, 방정식은 서로 다른 두 개의 실근을 가지며 이를 단순근이라 합니다. 근의 공식에 의한 두 근은 $x = \dfrac{-b \pm \sqrt{D}}{2a}$이며, 각 근의 중근도는 1입니다.

### 직관과 기이적 의미
이차함수 $y = ax^2 + bx + c$의 그래프와 $x$축의 위치 관계로 이해할 수 있습니다. 중근을 갖는 경우, 포물선이 $x$축에 접하며 한 점에서만 만나고 다시 반대 방향으로 꺾입니다. 이는 근의 공식에서 동일한 값이 두 번 나타나기 때문입니다. 반면 단순근을 갖는 경우, 포물선이 $x$축을 관통하며 서로 다른 두 점에서 만나게 됩니다.

### 기본 성질
- 중근은 완전제곱식의 형태로 나타나며, 식을 $(x-k)^2 = 0$ 꼴로 인수분해할 수 있습니다.
- 단순근은 서로 다른 두 실수가 방정식의 해가 되며, 각 근은 독립적인 값을 가집니다.

## 학습 체크
- 판별식 $D$의 부호에 따라 그래프가 $x$축과 접하는지, 관통하는지 구분할 수 있는가?
- 중근을 갖는 이차방정식을 완전제곱식 형태로 인수분해할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 이차방정식의 근의 종류(중근, 단순근)는 이차부등식의 해의 범위를 결정하는 핵심적인 기준이 됩니다.
