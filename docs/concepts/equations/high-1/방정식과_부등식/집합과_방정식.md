# 집합과 방정식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식의 해집합은 방정식의 조건을 만족하는 모든 미지수 값들을 모아놓은 집합입니다.

## 본문
방정식 $f(x) = 0$을 만족하는 모든 $x$ 값의 모임을 해집합 또는 근의 집합이라 합니다. 다시 말해, 미지수 $x$에 어떤 값을 대입했을 때 등식이 참이 되게 하는 모든 값들을 집합의 형태로 나타낸 것입니다. 예를 들어 방정식 $x^2 - 5x + 6 = 0$의 경우, 이를 만족하는 $x$의 값은 2와 3이므로 해집합은 $\{2, 3\}$이 됩니다. 만약 방정식이 어떤 근도 갖지 않는다면 해집합은 공집합 $\emptyset$이 되며, 반대로 모든 실수 $x$가 방정식을 만족한다면 해집합은 실수 전체의 집합 $\mathbb{R}$이 됩니다.

### 직관과 기하적 의미
방정식을 푼다는 것은 주어진 조건을 만족하는 모든 값을 찾아내는 과정입니다. 이를 집합의 관점에서 해석하면, 방정식 $f(x) = 0$은 함수 $y = f(x)$의 그래프가 $x$축과 만나는 점들의 $x$좌표를 모으는 것과 같습니다. 좌표평면 위에서 곡선과 $x$축의 교점들이 곧 방정식의 해가 되므로, 그래프를 통해 근의 개수나 대략적인 위치를 직관적으로 파악할 수 있습니다.

### 기본 성질
방정식의 해는 그래프의 교점이라는 기하학적 성질을 가지며, 이는 삼각방정식과 같이 주기성을 가진 함수에서도 원 위의 점이나 정현파 그래프의 특정 높이를 찾는 방식으로 동일하게 적용됩니다.

## 학습 체크
- 방정식의 해집합이 공집합이 되는 경우는 어떤 상황인가요?
- 함수 $y = f(x)$의 그래프와 $x$축의 교점이 방정식의 해와 어떤 관계가 있나요?
- 모든 실수가 방정식의 해가 되는 경우를 집합 기호로 어떻게 표현하나요?

## 관련 개념
- **삼각함수**: 삼각방정식은 삼각함수의 그래프나 단위원을 이용하여 해의 위치를 시각적으로 확인할 수 있습니다.
