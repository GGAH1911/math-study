# 복소수의 절댓값

## 정확한 진술

복소수 $z = a + bi$ (단, $a, b \in \mathbb{R}$)의 **절댓값**(또는 **모듈러스**)은 다음과 같이 정의합니다:

$$|z| = |a + bi| = \sqrt{a^2 + b^2}$$

이는 피타고라스 정리에서 비롯한 식입니다. 복소수 $z = a + bi$에 대해 켤레복소수 $\overline{z} = a - bi$와의 곱을 생각하면:

$$z \cdot \overline{z} = (a + bi)(a - bi) = a^2 + b^2$$

따라서 $|z|^2 = z \cdot \overline{z}$이고, 절댓값은 항상 **음이 아닌 실수**입니다.

## 직관과 기하적 의미

복소평면에서 복소수 $z = a + bi$는 점 $(a, b)$로 표현됩니다. 절댓값 $|z|$는 **원점에서 이 점까지의 거리**입니다. 

예를 들어 $z = 3 + 4i$이면 $|z| = \sqrt{9 + 16} = 5$이므로, 점 $(3, 4)$는 원점으로부터 거리 5입니다. 마찬가지로 $|z_1 - z_2|$는 두 복소수가 나타내는 두 점 사이의 거리를 뜻합니다.

절댓값 1인 복소수들의 집합은 원점 중심, 반지름 1인 원(단위원)을 이루며, 이런 복소수는 $e^{i\theta} = \cos\theta + i\sin\theta$ 꼴로 표현됩니다.

## 한 줄 예와 계산

$z = 1 - 2i$일 때, $|z| = \sqrt{1^2 + (-2)^2} = \sqrt{5}$ 입니다.

```python
# sympy로 검증
import sympy as sp
z = 1 - 2*sp.I
print(abs(z))  # sqrt(5)
```

또 다른 예: $z = -3 + 4i$이면 $|z| = 5$이고, $z = 2i$이면 $|z| = 2$입니다.

절댓값은 곱셈과 나눗셈에서 유용한 성질을 보입니다. **$|z_1 \cdot z_2| = |z_1| \cdot |z_2|$**이고, **$|z_1 / z_2| = |z_1| / |z_2|$** (단, $z_2 \neq 0$)입니다. 이 성질은 복소수 방정식의 해의 거리를 계산하거나 분석할 때 핵심 도구가 됩니다.
