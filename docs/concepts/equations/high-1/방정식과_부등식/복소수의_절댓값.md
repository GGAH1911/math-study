# 복소수의 절댓값

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
복소수의 절댓값은 복소평면에서 원점으로부터 해당 복소수가 나타내는 점까지의 거리를 의미하며, 피타고라스 정리에 의해 정의됩니다.

## 본문
복소수 $z = a + bi$ (단, $a, b \in \mathbb{R}$)의 절댓값(또는 모듈러스)은 $|z| = |a + bi| = \sqrt{a^2 + b^2}$로 정의합니다. 이는 복소수를 좌표평면 위의 점으로 보았을 때 원점으로부터의 거리를 구하는 피타고라스 정리의 원리를 따릅니다. 복소수 $z$와 그 켤레복소수 $\overline{z} = a - bi$를 곱하면 $z \cdot \overline{z} = a^2 + b^2$이 되므로, $|z|^2 = z \cdot \overline{z}$라는 관계가 성립합니다. 따라서 복소수의 절댓값은 항상 음이 아닌 실수 값을 가집니다.

### 직관과 기하적 의미
복소평면에서 복소수 $z = a + bi$는 점 $(a, b)$에 대응됩니다. 이때 $|z|$는 원점 $(0, 0)$에서 점 $(a, b)$까지의 직선 거리를 의미합니다. 예를 들어 $z = 3 + 4i$의 절댓값은 $\sqrt{3^2 + 4^2} = 5$이며, 이는 점 $(3, 4)$가 원점으로부터 5만큼 떨어져 있음을 나타냅니다. 또한 두 복소수의 차의 절댓값인 $|z_1 - z_2|$는 복소평면 위에서 두 점 사이의 거리를 의미합니다. 절댓값이 1인 복소수들은 원점을 중심으로 하고 반지름이 1인 원(단위원) 위에 놓이게 됩니다.

### 기본 성질
복소수의 절댓값은 곱셈과 나눗셈에 대해 다음과 같은 유용한 성질을 가집니다.
- 두 복소수의 곱의 절댓값은 각 절댓값의 곱과 같다: $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$
- 두 복소수의 나눗셈의 절댓값은 각 절댓값의 나눗셈과 같다: $\left| \frac{z_1}{z_2} \right| = \frac{|z_1|}{|z_2|}$ (단, $z_2 \neq 0$)

## 학습 체크
- 복소수 $z = 1 - 2i$의 절댓값을 계산하면 얼마인가요?
- $|z_1 - z_2|$가 나타내는 기하학적 의미는 무엇인가요?
- $|z|^2 = z \cdot \overline{z}$가 성립함을 이용하여 $|z|$를 구하는 과정을 설명할 수 있나요?

## 관련 개념
- **이차방정식**: 복소수를 계수로 갖는 이차방정식의 해를 구할 때, 해의 크기를 비교하거나 해의 위치를 파악하기 위해 절댓값을 활용합니다.
- **켤레복소수**: 복소수의 절댓값을 계산할 때 켤레복소수와의 곱을 이용하면 계산이 매우 간편해집니다.
