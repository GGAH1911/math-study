# 자연수해 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

방정식·부등식의 해 중에서 자연수($1, 2, 3, \ldots$)인 것의 개수나 조건을 다루는 문제 유형입니다. 고1 방정식과 부등식 단원에서 정수해 조건의 특수 경우입니다.

## 정의

자연수 $\mathbb{N} = \{1, 2, 3, \ldots\}$. 어떤 부등식 $f(x) \le k$의 자연수해의 개수를 구하려면, 먼저 실수 범위에서 해집합을 구한 뒤 그 안에 포함된 자연수의 개수를 셉니다.

미지수 $k$를 포함하는 경우, "자연수해가 정확히 $m$개"라는 조건을 만족시키는 $k$의 범위는 보통 부등식의 끝점이 어떤 자연수 사이에 놓이느냐의 조건으로 환원됩니다.

## 예시

부등식 $2x - 1 \le k$의 자연수해가 정확히 $4$개가 되도록 하는 $k$의 범위를 구해 봅니다. 부등식을 정리하면 $x \le \dfrac{k+1}{2}$이므로 자연수해는 $1, 2, \ldots, \left\lfloor \dfrac{k+1}{2} \right\rfloor$입니다. 자연수해가 $\{1, 2, 3, 4\}$이려면
$$4 \le \frac{k+1}{2} < 5 \implies 7 \le k < 9.$$
