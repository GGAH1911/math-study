# 자연수해 조건

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식이나 부등식의 해 중에서 자연수($1, 2, 3, \ldots$)인 조건만을 고려하여 해의 개수나 미지수의 범위를 결정하는 유형입니다.

## 본문
방정식이나 부등식의 해 중에서 자연수 $\mathbb{N} = \{1, 2, 3, \ldots\}$인 것의 개수나 조건을 다루는 유형입니다. 고등학교 1학년 과정의 방정식과 부등식 단원에서 정수해 조건의 특수한 경우로 다루어집니다. 어떤 부등식 $f(x) \le k$의 자연수해의 개수를 구하기 위해서는 먼저 실수 범위에서 해집합을 구한 뒤, 그 범위 안에 포함된 자연수의 개수를 파악해야 합니다. 만약 미지수 $k$가 포함된 문제에서 "자연수해가 정확히 $m$개"라는 조건이 주어진다면, 이는 부등식의 경계값이 어떤 자연수와 자연수 사이에 위치해야 한다는 조건으로 환원하여 해결합니다.

### 직관과 기하적 의미
수직선 위에서 부등식의 해를 나타내는 구간을 생각할 때, 자연수해의 개수는 해당 구간 안에 포함된 점 $\{1, 2, 3, \ldots\}$의 개수와 같습니다. 미지수 $k$의 변화에 따라 구간의 끝점이 이동하며, 이 끝점이 자연수를 지나칠 때마다 자연수해의 개수가 변하게 됩니다.

### 기본 성질
부등식 $2x - 1 \le k$를 예로 들면, 이를 정리하면 $x \le \dfrac{k+1}{2}$이 됩니다. 이때 자연수해가 $\{1, 2, 3, 4\}$로 정확히 $4$개가 되려면, $\dfrac{k+1}{2}$의 값이 $4$보다는 크거나 같아야 하고 $5$보다는 작아야 합니다. 즉, $4 \le \dfrac{k+1}{2} < 5$라는 범위를 통해 $7 \le k < 9$라는 $k$의 범위를 도출할 수 있습니다.

## 학습 체크
- 부등식의 해를 구한 후, 해당 범위에 포함되는 자연수를 빠짐없이 나열할 수 있는가?
- 자연수해의 개수가 변하는 경계 지점이 어떤 자연수 사이의 값인지 파악할 수 있는가?
