# 수직선 해석

부등식의 해, 두 점의 거리, 절댓값 표현 등을 수직선 위의 구간이나 거리로 변환하여 푸는 관점입니다. 고1 방정식과 부등식 단원에서 절댓값 부등식 풀이의 핵심 전략입니다.

## 정의

실수 $a$의 절댓값 $|a|$는 수직선 위에서 점 $a$와 원점 사이의 거리이며, $|a - b|$는 두 점 $a, b$ 사이의 거리입니다. 따라서 부등식은 다음과 같이 해석됩니다.
- $|x - a| < r \iff a - r < x < a + r$ ($a$로부터 거리가 $r$ 미만).
- $|x - a| > r \iff x < a - r$ 또는 $x > a + r.$
- $|x - a| + |x - b|$의 최솟값은 두 점 $a, b$ 사이의 거리 $|a - b|$.

## 예시

부등식 $|x - 2| \le 3$의 해를 구해 봅니다. 수직선에서 점 $2$로부터 거리가 $3$ 이하인 점들의 집합이므로 $-1 \le x \le 5$입니다.

또한 $|x - 1| + |x - 4|$의 최솟값은 두 점 $1, 4$ 사이의 거리인 $3$이며, $1 \le x \le 4$일 때 그 값에 도달합니다.
