# 방정식의 근과 계수의 관계

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
방정식의 계수와 그 방정식의 근들 사이의 합, 곱 등의 관계를 나타내는 공식입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 두 근을 $\alpha, \beta$라 하면 $\alpha + \beta = -\tfrac{b}{a}$, $\alpha\beta = \tfrac{c}{a}$가 성립하며, 삼차방정식 $ax^3 + bx^2 + cx + d = 0$ ($a \neq 0$)의 세 근을 $\alpha, \beta, \gamma$라 하면 $\alpha + \beta + \gamma = -\tfrac{b}{a}$, $\alpha\beta + \beta\gamma + \gamma\alpha = \tfrac{c}{a}$, $\alpha\beta\gamma = -\tfrac{d}{a}$가 성립합니다. 이를 근과 계수의 관계 또는 비에타 공식이라고 합니다.

이 관계는 방정식을 근을 이용한 인수분해 형태인 $a(x-\alpha)(x-\beta) = 0$으로 나타낸 뒤, 이를 전개하여 원래 방정식의 계수와 비교함으로써 유도할 수 있습니다. 삼차 이상의 고차 방정식에서도 동일한 원리가 적용됩니다.

### 직관과 기하적 의미
근의 값을 직접 구하는 복잡한 과정 없이도, 계수만으로 근들의 합이나 곱과 같은 대칭식을 즉각적으로 계산할 수 있게 해줍니다. 이는 문제 해결의 효율성을 극대화하며 대수적 구조를 이해하는 데 도움을 줍니다.

### 기본 성질
방정식의 계수를 알면 근의 합과 곱을 알 수 있고, 이를 응용하여 $\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta$와 같은 근에 관한 식의 값을 구할 수 있습니다. 예를 들어 $2x^2 - 5x + 3 = 0$에서 $\alpha+\beta = \tfrac{5}{2}$, $\alpha\beta = \tfrac{3}{2}$이므로 $\alpha^2 + \beta^2 = \tfrac{13}{4}$임을 바로 알 수 있습니다.

## 학습 체크
- 이차방정식에서 두 근의 합과 곱을 구할 때 부호($-$)를 실수하지 않았는가?
- 삼차방정식에서 세 근의 곱을 구할 때 계수의 부호가 $(-1)^n$ 규칙을 따르는지 확인하였는가?
- 근에 관한 식을 변형할 때 근의 대칭식 형태로 올바르게 변형하였는가?

## 관련 개념
- **이차방정식**: 근과 계수의 관계가 가장 기본적으로 적용되는 대상이며, 근의 공식과 함께 근의 성질을 결정합니다.
- **다항식의 인수분해**: 방정식을 근의 곱 형태로 나타내는 과정에서 근과 계수의 관계가 유도됩니다.
- **도함수의 활용 심화**: 함수의 극값이나 접선의 기울기를 구할 때 방정식의 근의 위치를 파악하는 도구로 활용될 수 있습니다.
