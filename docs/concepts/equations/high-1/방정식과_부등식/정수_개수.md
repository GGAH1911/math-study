### 정확한 진술

**정수의 개수**는 주어진 조건(부등식, 방정식, 함수식 등)을 만족하는 정수가 몇 개인지를 구하는 것입니다. 보통 부등식 범위 $a < x < b$ 또는 $a \leq x \leq b$를 만족하는 정수 해의 개수를 세거나, 함수값이나 식의 조건을 만족하는 정수를 찾는 문제 형태로 나타납니다.

### 직관과 기본 원리

수직선을 그렸을 때, 주어진 조건이 나타내는 영역 내에 있는 **정수 격자점**이 몇 개인지 세는 것입니다. 예를 들어 부등식 $a \leq x \leq b$ (단, $a, b$는 정수)를 만족하는 정수는 $a, a+1, a+2, \ldots, b$이므로 개수는 $b - a + 1$입니다. 

경계 조건이 중요합니다. 부등호가 $\leq, \geq$이면 경계값이 포함되고, $<, >$이면 포함되지 않습니다:
- $a \leq x \leq b$ ⟹ 정수 개수: $b - a + 1$개
- $a < x < b$ ⟹ 정수 개수: $b - a - 1$개

### 예제

**예 1:** $-2 < x < 3$을 만족하는 정수는 $-1, 0, 1, 2$로 4개입니다. 
$$\text{개수} = 3 - (-2) - 1 = 4$$

**예 2:** $1 \leq x \leq 10$을 만족하는 정수는 $1, 2, \ldots, 10$으로 $10 - 1 + 1 = 10$개입니다.

더 복잡한 경우, $f(x) = 0$의 정수 해를 구하거나 여러 부등식의 교집합을 만족하는 정수를 찾기도 합니다. 예를 들어 $x^2 - 5x + 6 = 0$은 $(x-2)(x-3) = 0$이므로 정수 해는 $x=2, 3$으로 2개입니다.

### 풀이 전략

1. 부등식이면 범위를 명확히 파악하고 경계값 포함 여부 확인
2. 방정식이면 인수분해나 근의 공식으로 해를 구하고 정수인지 확인  
3. 여러 조건이 있으면 교집합을 구한 후 개수 세기

정수 개수는 경계와 포함 관계를 정확히 파악하는 것이 핵심입니다.
