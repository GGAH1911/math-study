# 함수의 근과 영점

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
함수 $f(x)$의 근 또는 영점은 함수값이 $0$이 되게 하는 $x$의 값으로, 그래프 상에서는 $x$축과의 교점을 의미합니다.

## 본문
함수 $f(x)$의 근(root) 또는 영점(zero)은 $f(a) = 0$을 만족하는 $x = a$를 의미하며, 이는 함수값이 $0$이 되도록 만드는 독립변수의 값을 뜻합니다. 수학적 맥락에 따라 방정식의 해를 구할 때는 근이라는 용어를 주로 사용하며, 함수 자체의 성질을 다룰 때는 영점이라는 용어를 사용하여 구분하기도 합니다. 예를 들어 이차함수 $f(x) = x^2 - 5x + 6$에서 함수값이 $0$이 되는 지점인 $x = 2$와 $x = 3$이 이 함수의 근이 됩니다.

### 직관과 기하적 의미
함수 $y = f(x)$의 그래프에서 근은 그래프가 $x$축과 만나는 교점의 $x$좌표를 나타냅니다. 그래프가 $x$축을 통과하여 가로지르거나, $x$축에 접하는 지점이 모두 근에 해당합니다.

### 기본 성질
함수의 근은 다음과 같은 수학적 성질을 가집니다.
- **부호의 변화**: 함수가 중근을 갖지 않는 한, 근을 지나는 지점에서 함수의 함숫값은 양수에서 음수로, 또는 음수에서 양수로 부호가 바뀝니다.
- **극값과의 관계**: 도함수 $f'(x)$의 근은 원함수 $f(x)$의 극값이 발생하는 위치를 결정하는 중요한 지표가 됩니다.

## 학습 체크
- 함수 $f(x)$의 근을 구하기 위해 $f(x)=0$이라는 방정식을 세울 수 있는가?
- 그래프를 통해 $x$축과의 교점을 찾아 근을 시각적으로 확인할 수 있는가?

## 관련 개념
- **정적분의 활용**: 적분 구간 내에 함수의 근이 존재할 경우, 근을 기준으로 구간을 나누어 계산해야 함숫값의 부호에 따른 정확한 넓이를 구할 수 있습니다.
