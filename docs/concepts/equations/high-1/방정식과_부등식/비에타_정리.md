# 비에타 정리

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
이차방정식의 두 근의 합과 곱이 계수들의 관계식으로 나타난다는 정리입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음의 관계식이 성립합니다.
$$\alpha + \beta = -\frac{b}{a}, \quad \alpha \beta = \frac{c}{a}$$
이 관계식을 **비에타 정리** 또는 **근과 계수의 관계**라고 부릅니다.

### 직관과 기하적 의미
근의 공식을 통해 얻은 두 근을 직접 더하거나 곱해보면, 복잡한 제곱근 항들이 서로 상쇄되거나 소거되어 계수만으로 이루어진 단순한 식을 얻게 됩니다. 이는 근의 정확한 값을 일일이 구하지 않더라도, 방정식이 가진 근의 합과 곱이라는 핵심 정보를 즉각적으로 추출할 수 있음을 의미합니다. 즉, 방정식의 계수 속에 이미 근들의 대칭적인 정보가 내포되어 있다는 것을 보여줍니다.

### 기본 성질
이 정리는 근을 명시적으로 구하기 어려운 고차방정식이나 복잡한 계산 상황에서 매우 강력한 도구가 됩니다. 두 근의 합과 곱을 알면 이를 이용하여 새로운 방정식을 구성할 수 있고, 두 근의 부호나 대소 관계를 판정하거나, 근의 대칭식(예: $\alpha^2 + \beta^2$)을 효율적으로 계산할 수 있습니다.

## 학습 체크
- 근의 공식을 이용하여 $\alpha + \beta$와 $\alpha\beta$를 유도하는 과정을 설명할 수 있는가?
- 주어진 계수를 바탕으로 두 근의 합과 곱을 정확히 계산할 수 있는가?
- 근과 계수의 관계를 이용하여 근의 대칭식 값을 구할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 방정식의 근의 성질을 파악함으로써 부등식의 해의 범위를 결정하거나 방정식의 해의 존재 여부를 판단하는 기초가 됩니다.
