# 공통해의 범위

## 정확한 진술

두 개 이상의 방정식이나 부등식이 **동시에** 만족하는 미지수 값(들)의 집합을 **공통해의 범위**라고 합니다. 예를 들어 부등식 $x > 1$과 $x < 5$를 동시에 만족하는 $x$는 $1 < x < 5$이고, 이 범위를 공통해의 범위라 부릅니다. 수학적으로는 각 조건의 해집합의 **교집합(intersection)**입니다.

## 직관과 기하적 의미

수직선 위에서 이해하면 가장 명확합니다. 부등식 $A(x)$의 해를 색칠한 구간과 부등식 $B(x)$의 해를 색칠한 구간을 겹쳐놓으면, 둘 다 색칠된 부분이 공통해의 범위입니다. 

예를 들어 $x - 2 > 0$ (즉 $x > 2$)과 $-x + 7 > 0$ (즉 $x < 7$)을 동시에 만족하려면, 수직선에서 $x > 2$인 부분과 $x < 7$인 부분이 겹치는 $2 < x < 7$ 구간이 답이 됩니다. 조건이 많을수록 색칠되는 구간은 더 좁아집니다.

## 간단한 예

부등식 $2x - 3 < 5$와 $x + 1 > 0$의 공통해를 구하면:
- 첫 번째: $2x < 8$ ⟹ $x < 4$
- 두 번째: $x > -1$

두 조건의 교집합은 $-1 < x < 4$입니다.

**검산:** `sympy.solve([(2*x - 3 < 5), (x + 1 > 0)], x)` 로 확인 가능합니다.

## 주의할 점

공통해가 **공집합**일 수도 있습니다. 예를 들어 $x > 5$와 $x < 3$을 동시에 만족하는 $x$는 존재하지 않으므로, 공통해의 범위는 "없음" 또는 $\emptyset$ (공집합)입니다.
