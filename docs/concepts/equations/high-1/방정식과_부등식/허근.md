# 허근

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
허근이란 이차방정식의 판별식이 $0$보다 작을 때 나타나는 실수가 아닌 복소수 근을 의미하며, 항상 서로 켤레복소수 관계를 가집니다.

## 본문
허근이란 실수가 아닌 복소수 형태의 근을 의미합니다. 실수 계수를 갖는 이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)에서 판별식 $D = b^2 - 4ac$가 $0$보다 작으면, 근의 공식에 의해 근은 $x = \tfrac{-b \pm \sqrt{D}}{2a}$의 형태를 띱니다. 이때 루트 안의 값이 음수이므로 $\sqrt{D} = \sqrt{-|D|}i$와 같이 허수 단위 $i$를 포함하게 되며, 결과적으로 $x = \tfrac{-b}{2a} \pm \tfrac{\sqrt{|D|}}{2a}i$라는 두 개의 복소수 근을 얻게 됩니다. 이러한 근들을 허근이라 부르며, 계수가 실수인 방정식에서 두 허근은 항상 실수 부분은 같고 허수 부분의 부호가 반대인 켤레복소수 관계를 형성합니다. 예를 들어 판별식이 $-8$인 경우, 근에는 $\sqrt{8}i = 2\sqrt{2}i$와 같은 허수 성분이 포함됩니다.

### 직관과 기이적 의미
이차함수 $y = ax^2 + bx + c$의 그래프를 통해 허근을 이해할 수 있습니다. 실근이 그래프가 $x$축과 만나는 지점을 의미하는 것과 달리, 판별식 $D < 0$인 경우 포물선은 $x$축과 만나지 않고 떠 있거나 아래에 위치합니다. 즉, 그래프가 $x$축과 교차하지 않으므로 실수 범위 내에서는 해가 존재하지 않으며, 그 해는 실수축을 벗어나 복소평면 상의 공간에 존재하게 됩니다. 이때 두 허근은 복소평면에서 실수축을 기준으로 서로 대칭인 위치에 놓이게 됩니다.

### 기본 성질
- 계수가 실수인 방정식에서 한 허근이 $p + qi$라면, 다른 한 근은 반드시 $p - qi$인 켤레복소수입니다.
- 판별식 $D < 0$인 경우, 방정식은 실수의 범위 내에서는 해가 없다고 말합니다.
