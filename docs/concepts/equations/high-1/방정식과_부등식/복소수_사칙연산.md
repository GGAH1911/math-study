# 복소수 사칙연산

> **예제** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
복소수의 나눗셈은 분모의 켤레복소수를 분자와 분모에 각각 곱하여 분모를 실수로 만들어 계산합니다.

## 본문
다음 복소수 나눗셈을 계산하세요.
$$\frac{1+2i}{3-i}$$

### 단계별 풀이
**1단계: 분모의 켤레복소수 파악하기**
분모 $3-i$의 켤레복소수는 허수부의 부호만 바꾼 $3+i$입니다.

**2단계: 분자와 분모에 켤레복소수 곱하기**
분모를 실수로 만들기 위해 분자와 분모에 $3+i$를 곱합니다.
$$\frac{1+2i}{3-i} \cdot \frac{3+i}{3+i}$$

**3단계: 분자 계산하기**
$(1+2i)(3+i)$를 전개하면 $3 + i + 6i + 2i^2$이 됩니다. 여기서 $i^2 = -1$을 대입하면 $3 + 7i - 2 = 1 + 7i$가 됩니다.

**4단계: 분모 계산하기**
$(3-i)(3+i)$는 합차공식을 이용하여 $9 - i^2 = 9 - (-1) = 10$으로 계산됩니다.

**5단계: 최종 정리**
$$\frac{1+7i}{10} = \frac{1}{10} + \frac{7}{10}i$$

### 답과 변형
$$\frac{1}{10} + \frac{7}{10}i$$
복소수 나눗셈의 핵심은 분모를 켤레복소수로 곱해 실수화하는 것입니다. 만약 분모가 이미 실수라면 켤레를 곱할 필요가 없으며, 계산 과정에서 $i^2 = -1$을 적용할 때 부호 실수가 발생하지 않도록 주의해야 합니다.

## 학습 체크
- 분모의 켤레복소수를 정확히 구할 수 있는가?
- 분자 전개 시 $i^2 = -1$을 빠뜨리지 않고 계산하였는가?
- 계산 결과를 실수부와 허수부의 합 형태로 나타낼 수 있는가?

## 관련 개념
- **방정식과 부등식**: 복소수의 사칙연산은 복소수 계수를 갖는 방정식의 해를 구하는 과정에서 필수적인 기초 연산입니다.
