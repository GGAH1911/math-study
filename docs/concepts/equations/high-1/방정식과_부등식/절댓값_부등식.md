# 절댓값 부등식

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
절댓값 부등식은 수직선 위에서 두 점 사이의 거리를 이용하여 해의 범위를 결정하는 부등식입니다.

## 본문
절댓값 부등식은 절댓값 기호를 포함한 부등식을 의미하며, $|x| < a$, $|x| > a$와 같이 등호를 포함한 형태도 모두 포함합니다. 가장 기본적인 형태인 $|x| < a$ (단, $a > 0$)의 해는 $-a < x < a$이며, $|x| > a$ (단, $a > 0$)의 해는 $x < -a$ 또는 $x > a$가 됩니다. 이를 일반화하여 $|x - b| < a$ (단, $a > 0$)의 해를 구하면 $b - a < x < b + a$가 됩니다.

### 직관과 기하적 의미
절댓값 $|x|$는 수직선 위에서 $x$와 원점 사이의 거리를 나타내며, $|x - b|$는 $x$와 점 $b$ 사이의 거리를 의미합니다. 따라서 $|x - b| < a$는 점 $x$가 점 $b$로부터 거리 $a$ 이내에 있다는 뜻이므로, 수직선상에서 $b$를 중심으로 좌우 $a$만큼의 범위인 열린 구간 $(b-a, b+a)$에 해당합니다. 반대로 $|x - b| > a$는 점 $x$가 점 $b$로부터 거리 $a$보다 멀리 떨어져 있다는 뜻이므로, 해는 $(-\infty, b-a) \cup (b+a, \infty)$가 됩니다.

### 기본 성질
부등식의 형태에 따라 해의 범위가 결정됩니다. 예를 들어 $|x - 2| < 3$의 경우, $x$가 2로부터 거리 3 이내에 있어야 하므로 $-3 < x - 2 < 3$을 풀어 $-1 < x < 5$라는 해를 얻을 수 있습니다. 이처럼 절댓값 부등식은 수직선 위에서의 거리 개념을 통해 해의 범위를 직관적으로 파악할 수 있는 것이 특징입니다.

## 학습 체크
- $|x - b| < a$ 형태의 부등식을 수직선 위의 거리 개념으로 설명할 수 있는가?
- 부등식의 결과가 구간의 형태(합집합 또는 교집합)로 어떻게 나타나는지 이해하고 있는가?

## 관련 개념
- **방정식과 부등식**: 절댓값 부등식의 해는 절댓값을 포함한 방정식의 해를 경계값으로 하여 결정되는 경우가 많으므로 두 개념은 밀접하게 연관됩니다.
