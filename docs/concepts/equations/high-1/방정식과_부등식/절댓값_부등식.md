# 절댓값 부등식

## 정의: 절댓값 부등식

절댓값 부등식은 절댓값 기호를 포함한 부등식입니다. 가장 기본적인 형태는:
- $|x| < a$ (단, $a > 0$): 해는 $-a < x < a$
- $|x| > a$ (단, $a > 0$): 해는 $x < -a$ 또는 $x > a$
- $|x - b| < a$ (단, $a > 0$): 해는 $b - a < x < b + a$

또한 등호를 포함한 $|x| \leq a$, $|x| \geq a$ 등도 절댓값 부등식에 해당합니다.

## 직관: 수직선 위의 거리로 이해하기

절댓값 $|x|$는 수직선 위에서 $x$와 원점 사이의 거리입니다. 마찬가지로 $|x - b|$는 $x$와 점 $b$ 사이의 거리입니다.

따라서 부등식 $|x - b| < a$는 **"점 $x$가 점 $b$로부터 거리 $a$ 이내에 있다"**는 뜻입니다. 이를 수직선에 표현하면 $b$를 중심으로 좌우 $a$만큼의 범위, 즉 열린 구간 $(b-a, b+a)$가 됩니다.

반대로 $|x - b| > a$는 **"점 $x$가 점 $b$로부터 거리 $a$보다 멀리 떨어져 있다"**는 뜻이므로, 해는 $(-\infty, b-a) \cup (b+a, \infty)$가 됩니다.

## 예: 간단한 경우

$|x - 2| < 3$을 풀면, "$x$가 2로부터 거리 3 이내"라는 뜻이므로:
$$-3 < x - 2 < 3$$
$$-1 < x < 5$$

(검증: `sympy.solve(abs(x - 2) < 3, x)` → $-1 < x < 5$)
