# 복소수

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
$a+bi$ ($i^2=-1$) 꼴로 나타내어 실수의 범위를 확장한 수입니다.

## 본문
복소수는 $a+bi$ ($a, b$는 실수, $i$는 허수 단위) 형태의 수입니다. 여기서 허수 단위 $i$는 $i^2 = -1$을 만족하는 수입니다. 복소수 $z = a+bi$에서 $a$를 실부, $b$를 허부라고 하며, 각각 $\text{Re}(z) = a$, $\text{Im}(z) = b$로 나타냅니다.

### 직관과 기하적 의미
실수 범위에서는 $x^2 + 1 = 0$과 같은 방정식의 해를 구할 수 없지만, 복소수를 도입하면 $x = \pm i$라는 해를 가질 수 있습니다. 이는 모든 다항식이 복소수 범위에서 완전히 인수분해될 수 있음을 의미합니다. 기하학적으로 복소수는 복소평면 위의 점 $(a, b)$에 대응됩니다. 이때 가로축은 실수축, 세로축은 허수축으로 정의되며, 이를 통해 복소수는 2차원적 정보를 담는 수로 확장됩니다.

### 기본 성질
두 복소수가 같으려면 실부와 허부가 각각 같아야 합니다. 즉, $a+bi = c+di$이면 $a=c$이고 $b=d$입니다. 대표적인 예로 $3+2i$는 실부가 3, 허부가 2이며, $-5$는 실부가 $-5$, 허부가 0인 복소수입니다. 또한 허부가 0이 아닌 경우를 순허수라고 합니다. 허수 단위 $i$는 $i^1=i, i^2=-1, i^3=-i, i^4=1$과 같이 4를 주기로 반복되는 성질을 가집니다.

## 학습 체크
- 복소수의 실부와 허부를 구분하고, 순허수의 조건을 설명할 수 있는가?
- $i$의 거듭제곱이 갖는 주기성을 이용하여 계산할 수 있는가?
- 두 복소수가 같을 조건을 이용하여 미지수의 값을 구할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 복소수를 도입함으로써 실수 범위에서 해가 없던 이차방정식의 해를 구할 수 있게 됩니다.
