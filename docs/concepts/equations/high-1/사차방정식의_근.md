### 정확한 진술

사차방정식의 **근**은 주어진 사차방정식을 참으로 만드는 수입니다. 사차방정식 $ax^4 + bx^3 + cx^2 + dx + e = 0$ (단, $a \neq 0$)에서, 이 식에 대입했을 때 등식이 성립하는 모든 $x$의 값을 근이라 합니다.

### 직관과 기하적 의미

사차함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$의 그래프와 $x$축의 교점의 $x$좌표가 바로 사차방정식의 근입니다. 사차함수는 최대 4개의 실근을 가질 수 있으며, 다항식의 기본정리에 의해 복소수 범위에서는 **정확히 4개의 근**(중근 포함)을 갖습니다.

사차방정식은 근의 개수와 형태에 따라 여러 경우로 나뉩니다:
- 4개의 서로 다른 실근
- 2개의 실근과 2개의 복소수 켤레근
- 중근을 포함한 경우들

예를 들어 $f(x) = x^4 - 5x^2 + 4$는 $y = x^4 - 5x^2 + 4$의 그래프가 $x$축과 만나는 4개 점의 $x$좌표가 모두 근입니다.

### 구체적 예

방정식 $x^4 - 5x^2 + 4 = 0$의 근을 구하면:

$t = x^2$로 치환하면 $t^2 - 5t + 4 = 0$ → $(t-1)(t-4) = 0$ → $t = 1$ 또는 $t = 4$

따라서 $x^2 = 1$ 또는 $x^2 = 4$에서 $x = \pm 1$ 또는 $x = \pm 2$

이 4개의 값 $-2, -1, 1, 2$가 모두 이 사차방정식의 근입니다. (sympy 검증: `sympy.solve(x**4 - 5*x**2 + 4, x)` → `[-2, -1, 1, 2]`)
