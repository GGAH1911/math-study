# 켤레복소수

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
$\overline{a+bi}=a-bi$

## 본문 (학습 시 채워짐)

### 정확한 진술

복소수 $z = a + bi$ (단, $a, b$는 실수, $i$는 허수단위)에 대해 허수부의 부호를 바꾼 복소수를 **켤레복소수**(conjugate complex number)라 하며, $\overline{z}$ 또는 $z^*$로 나타낸다. 즉,

$$\overline{a+bi} = a - bi$$

### 직관과 기하적 의미

복소평면에서 복소수 $a+bi$는 점 $(a, b)$로 표현되고, 그 켤레복소수 $a-bi$는 점 $(a, -b)$로 나타난다. 두 점은 **실수축(가로축)에 대해 선대칭**이다. 이것이 켤레라는 이름의 유래다. 

켤레복소수는 실계수 이차방정식의 근의 성질과 밀접하다. 실계수 이차방정식 $ax^2 + bx + c = 0$에서 판별식이 음수이면 두 근은 서로 켤레복소수가 된다. 예를 들어 $x^2 + 1 = 0$의 두 근 $i$와 $-i$는 켤레이며, 두 켤레근의 합 $i + (-i) = 0$은 항상 실수이다.

### 기본 성질과 계산

$z$와 $\overline{z}$를 곱하면

$$z \cdot \overline{z} = (a+bi)(a-bi) = a^2 + b^2$$

이는 항상 **음이 아닌 실수**이고, 이를 $|z|^2$이라 부른다. 또한 $\overline{z} = z$ ⟺ $z$는 실수이다.

### 한 줄 예

$\overline{3+4i} = 3 - 4i$이고, $(3+4i)(3-4i) = 9 + 16 = 25$이다. 또한 $\overline{2-5i} = 2+5i$이다.
