# 근 중근

> **정의** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
방정식의 해 / 중복된 해

## 본문 (학습 시 채워짐)

### 근(근)의 정의

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)을 만족하는 $x$의 값을 **근** 또는 **해**라고 부릅니다. 이차방정식은 최대 2개의 근을 가질 수 있습니다. 근의 공식을 사용하면:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

이 식에서 $\pm$ 기호 때문에 일반적으로 2개의 서로 다른 근이 나옵니다.

### 중근의 정의

**중근**은 이차방정식의 두 근이 같을 때의 그 근을 말합니다. 이는 판별식 $D = b^2 - 4ac = 0$일 때 발생합니다. 판별식이 0이면 근의 공식의 $\pm$ 부분이 0이 되므로:

$$x = \frac{-b}{2a}$$

이 하나의 값만 나옵니다. 이를 "중근을 가진다" 또는 "중근이 $x = \frac{-b}{2a}$이다"라고 표현합니다. 수학적으로는 같은 근이 2번 나타나는 것으로 봅니다: $(x - \alpha)^2 = 0$ 형태입니다.

### 기하적 의미

$y = ax^2 + bx + c$의 그래프는 포물선입니다. 근은 이 포물선이 $x$축과 만나는 점의 $x$좌표입니다. 중근을 가질 때는 포물선이 $x$축과 **한 점에서만 접합니다** — 관통하지 않고 스칠(touch)듯이 만날 때입니다.

### 구체적 예

$x^2 - 6x + 9 = 0$은 판별식이 $36 - 36 = 0$이므로 중근을 가집니다. $(x-3)^2 = 0$으로 인수분해되며, 중근은 $x = 3$입니다 (또는 "근 3, 3"이라 표현).

다른 예: $x^2 + 2x + 1 = 0$ → $(x+1)^2 = 0$ → 중근 $-1$ (`sympy.solve(x**2 + 2*x + 1, x)` → `[-1]`)
