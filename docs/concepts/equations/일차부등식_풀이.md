# 일차부등식 풀이

> **예제** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
$2x-3\geq 5$ 풀이

## 본문 (학습 시 채워짐)

### 문제

다음 부등식을 푸시오.
$$2x-3\geq 5$$

### 단계별 풀이

**1단계: 상수항 이항**

부등식의 양변에서 3을 더합니다. (등호/부등호의 성질: 양변에 같은 수를 더해도 부등호 방향은 변하지 않음)

$$2x-3+3\geq 5+3$$
$$2x\geq 8$$

**2단계: 계수로 나누기**

양변을 2로 나눕니다. 2는 양수이므로 부등호 방향이 변하지 않습니다.

$$\frac{2x}{2}\geq \frac{8}{2}$$
$$x\geq 4$$

**3단계: 해집합 표현**

$x$의 범위를 명확하게 나타냅니다: "$x$는 4 이상의 모든 수"

### 답

$$x\geq 4$$

또는 집합 표기로: $\{x | x\geq 4\}$

수직선에 나타내면, 4를 검은색 점(●)으로 표시하고 오른쪽으로 화살표를 그립니다.

### 변형/주의

**부등호 방향 주의** — 음수로 양변을 곱하거나 나누면 부등호 방향이 **반대**로 뒤집힙니다. 예를 들어 $-2x\geq 8$이면 양변을 $-2$로 나누면 $x\leq -4$가 됩니다.

**검산** — $x=4$를 원래 식에 대입: $2(4)-3=5$이므로 $5\geq 5$ ✓. $x=5$를 대입: $2(5)-3=7$이므로 $7\geq 5$ ✓.

**자주하는 실수** — "이항"할 때 부등호 방향을 잘못 바꾸면 안 됩니다. 이항은 부등호 방향을 바꾸지 않습니다. 음수로 곱하거나 나눌 때만 바꿉니다!
