# 선형방정식

## 일차방정식의 정의

일차방정식은 **미지수의 최고차가 1인 방정식**입니다. 일반적으로 일변수 일차방정식은 $ax + b = 0$ (단, $a \neq 0$)의 꼴이며, 정확히 하나의 해 $x = -\frac{b}{a}$를 갖습니다. 여러 미지수를 포함하는 경우, 예를 들어 두 미지수 일차방정식은 $ax + by + c = 0$ (단, $a, b$ 중 적어도 하나는 0이 아님)의 꼴입니다. 핵심은 모든 미지수의 지수가 1이고, 곱셈항(예: $xy$)이 없다는 점입니다.

## 기하학적 의미

일변수 일차방정식 $ax + b = 0$의 해는 **수직선 위의 한 점**입니다. 두 변수 일차방정식 $ax + by + c = 0$의 해의 집합은 **좌표평면상의 직선**입니다—여기서 "선형(linear)"이라는 말의 유래입니다. 예를 들어 $2x + 3y - 6 = 0$은 $(3, 0)$과 $(0, 2)$를 지나는 직선을 나타냅니다. 세 개 이상의 미지수를 가진 일차방정식들의 해는 더 높은 차원의 초평면(hyperplane)을 형성하며, 이것이 연립일차방정식에서 여러 직선이 만나는 교점을 찾는 기하학적 직관과 연결됩니다.

## 예시

**예:** $3x + 5 = 14$는 일차방정식입니다. 
$$3x = 9 \Rightarrow x = 3$$
(검산: sympy.solve(3*x + 5 - 14, x) → [3])

**반례:** $x^2 + 2x + 1 = 0$은 이차방정식이므로 일차방정식이 아닙니다.
