# 일차방정식 속력 문제

> **예제** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
거리, 속력, 시간 사이의 관계를 이용하여 미지수를 구하는 일차방정식의 응용 유형입니다.

## 본문
시속 $60\text{ km}$로 달리는 자동차가 있습니다. 이 자동차가 출발한 지 $3$시간 후에, 같은 출발점에서 시속 $80\text{ km}$로 달리는 또 다른 자동차가 출발했습니다. 두 번째 자동차가 출발한 후 몇 시간이 지났을 때 두 자동차의 거리가 같아질까요?

### 단계별 풀이
**1단계: 미지수 정하기**
두 번째 자동차가 출발한 후 경과 시간을 $x$시간이라고 하겠습니다.

**2단계: 각 자동차가 이동한 거리 표현하기**
- 첫 번째 자동차: 총 $(3 + x)$시간 동안 움직였으므로 거리는 $60(3 + x)\text{ km}$
- 두 번째 자동차: $x$시간 동안 움직였으므로 거리는 $80x\text{ km}$

**3단계: 방정식 세우기**
두 자동차의 거리가 같을 때이므로:
$$60(3 + x) = 80x$$

**4단계: 방정식 풀기**
$$180 + 60x = 80x$$
$$180 = 20x$$
$$x = 9$$

**5단계: 검산**
- 첫 번째 자동차: $60 \times (3 + 9) = 720\text{ km}$
- 두 번째 자동차: $80 \times 9 = 720\text{ km}$

### 답과 변형
**답:** 두 번째 자동차가 출발한 후 **$9$시간** 후에 두 자동차가 만납니다.

**변형 문제:**
- 첫 번째 자동차의 총 주행 시간: $3 + 9 = 12$시간
- 두 자동차의 이동 거리 차이: $0\text{ km}$ (같은 위치에 도달하므로)

**주의할 점:**
- "출발한 지 $3$시간 후"와 같은 시간 차이를 미지수 설정 시 주의해야 합니다.
- 속력의 단위와 시간의 단위를 일치시켜야 합니다.

## 학습 체크
- 두 자동차의 이동 거리가 같다는 조건을 이용해 식을 세울 수 있는가?
- 먼저 출발한 물체의 이동 시간에 기준 시간 차이를 더할 수 있는가?

## 관련 개념
- **일차방정식**: 미지수 $x$를 포함한 등식을 세워 문제를 해결하는 기본 원리로, 거리·속력·시간 문제의 핵심 도구입니다.
