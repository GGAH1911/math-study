# 이항

> **정리** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
항을 반대편으로 옮길 때 부호를 바꾸어 계산을 간편하게 하는 방법입니다.

## 본문
일차방정식 $ax + b = c$ (단, $a \neq 0$)를 풀 때, 한쪽에 있는 항을 반대쪽으로 옮기면서 부호를 바꿀 수 있습니다. 이를 **이항(移項)**이라 합니다. 예를 들어, $2x + 3 = 7$에서 $+3$을 우변으로 옮기면 부호가 바뀌어 $2x = 7 - 3$이 됩니다.

### 증명 스케치
이항은 등식의 성질을 바탕으로 합니다. 등식의 양변에 같은 수를 더하거나 빼도 등식은 성립합니다.
$$2x + 3 = 7$$
양변에서 $3$을 빼면 다음과 같습니다.
$$2x + 3 - 3 = 7 - 3$$
$$2x = 4$$
이 과정을 간단히 줄여서 "$+3$을 우변으로 옮겨 $-3$이 됨"이라고 표현하는 것이 바로 이항입니다. 즉, 이항은 매번 양변에 같은 수를 더하거나 빼는 과정을 생략하여 계산을 빠르게 하기 위한 기법입니다.

### 의의와 응용
이항은 등식의 성질을 체계적으로 적용한 규칙으로, 일차방정식 풀이의 핵심입니다. 좌변의 $+a$는 우변으로 $-a$로, 좌변의 $-a$는 우변으로 $+a$로 이항합니다. 예시로 $3x - 5 = 10$에서 $-5$를 우변으로 이항하면 $3x = 10 + 5 = 15$가 되어 $x = 5$를 구할 수 있습니다. 이 개념은 이후 이차방정식이나 부등식을 해결할 때도 식을 정리하는 기본 원리로 사용됩니다.

## 관련 개념
- **일차방정식**: 이항을 이용하여 미지수 $x$의 값을 구하는 대상이 되는 식입니다.
