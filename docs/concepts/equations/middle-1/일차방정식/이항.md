# 이항

> **정리** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
항을 부호 바꿔 반대편으로

## 본문 (학습 시 채워짐)

### 진술 및 가정

일차방정식 $ax + b = c$ (단, $a \neq 0$)를 풀 때, **한쪽에 있는 항을 반대쪽으로 옮기면서 부호를 바꿀 수 있습니다.** 이를 **이항(移項)**이라 합니다.

예를 들어, $2x + 3 = 7$에서 $+3$을 우변으로 옮기면 부호가 바뀌어 $2x = 7 - 3$이 됩니다.

### 간단한 유도

등식의 양변에 같은 수를 더하거나 빼도 등식은 성립합니다(등식의 성질).

$$2x + 3 = 7$$

양변에서 $3$을 뺍니다:

$$2x + 3 - 3 = 7 - 3$$
$$2x = 4$$

이 과정을 간단히 쓰면, "$+3$을 우변으로 옮겨 $-3$이 됨"이라고 표현합니다. 이것이 **이항**입니다. 이항의 본질은 등식의 성질인데, 계산을 간편하게 하기 위한 기법입니다.

### 의의와 응용

이항은 단순히 항을 옮기는 것이 아니라, 등식의 성질을 체계적으로 적용한 규칙입니다. 매번 양변에서 같은 수를 더하거나 빼는 과정을 명시하지 않고 "항을 옮긴다"는 간단한 규칙으로 일차방정식을 빠르게 풀 수 있습니다.

**이항 규칙:**
- 좌변의 $+a$는 우변으로 $-a$로 이항
- 좌변의 $-a$는 우변으로 $+a$로 이항

예시: $3x - 5 = 10$에서 $-5$를 우변으로 이항하면 $3x = 10 + 5 = 15$, 따라서 $x = 5$

이항은 중학교 일차방정식 풀이의 핵심이며, 이차방정식, 부등식 등 더 복잡한 식을 정리하는 데도 기본이 되는 개념입니다.
