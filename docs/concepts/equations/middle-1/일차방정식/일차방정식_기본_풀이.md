# 일차방정식 기본 풀이

> **예제** · 중1 · 단원: [일차방정식](/concepts/일차방정식)
## 요약
$2x+3=11$ 풀이

## 본문

### 문제

$2x + 3 = 11$을 풀어라.

---

### 풀이 과정

**1단계: 상수항을 이항하기**

등식의 양변에서 같은 수를 빼면 등식은 여전히 성립합니다. 좌변의 3을 없애기 위해 양변에서 3을 뺍니다.

$$2x + 3 - 3 = 11 - 3$$

$$2x = 8$$

**2단계: 미지수 $x$의 계수로 나누기**

$x$ 앞의 계수가 2이므로, 양변을 2로 나눕니다.

$$\frac{2x}{2} = \frac{8}{2}$$

$$x = 4$$

**검산:**
원래 식에 $x = 4$를 대입하면:
$$2 \times 4 + 3 = 8 + 3 = 11 \,\checkmark$$

---

### 답

$$x = 4$$

---

### 주의할 점

**양변에 같은 연산:** 등식을 풀 때는 항상 좌변과 우변에 **같은 연산**을 해야 합니다. 한쪽에만 연산하면 등식이 깨집니다.

**부호 확인:** 항을 이항할 때, 우변으로 넘기면 부호가 바뀝니다. 예를 들어 $+3$은 이항하면 $-3$이 됩니다.

**검산 습관:** 답을 구한 후 원래 식에 대입하여 양변이 같은지 확인하는 것이 중요합니다.

```python
# sympy 검산: sympy.solve(2*x + 3 - 11, x)  # [4]
```
