# 일차방정식 기본 풀이

> **예제** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
등식의 성질을 이용하여 미지수 $x$의 값을 구하는 과정입니다.

## 본문
$2x + 3 = 11$을 풀어라.

### 단계별 풀이
**1단계: 상수항을 이항하기**
등식의 양변에서 같은 수를 빼도 등식은 성립합니다. 좌변의 $3$을 없애기 위해 양변에서 $3$을 뺍니다.
$$2x + 3 - 3 = 11 - 3$$
$$2x = 8$$

**2단계: 미지수 $x$의 계수로 나누기**
$x$ 앞의 계수가 $2$이므로, 양변을 $2$로 나눕니다.
$$\frac{2x}{2} = \frac{8}{2}$$
$$x = 4$$

### 답과 변형
$$x = 4$$

검산을 위해 원래 식에 $x = 4$를 대입하면 $2 \times 4 + 3 = 11$이 되어 식이 성립함을 확인할 수 있습니다.

**주의할 점**
등식을 풀 때는 반드시 좌변과 우변에 같은 연산을 적용해야 합니다. 또한 항을 이항할 때는 부호가 반대로 바뀐다는 점에 유의해야 하며, 구한 답이 맞는지 원래 식에 대입하여 확인하는 습관이 필요합니다.

## 학습 체크
- 등식의 성질을 이용하여 항을 이항할 수 있는가?
- 미지수의 계수로 양변을 나누어 $x$의 값을 구할 수 있는가?
- 구한 답을 원래 식에 대입하여 검산할 수 있는가?

## 관련 개념
- **일차방정식**: 미지수 $x$에 대한 일차식의 형태가 $0$과 같다는 조건으로 나타내어지는 방정식입니다.
