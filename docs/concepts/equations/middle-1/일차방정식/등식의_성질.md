# 등식의 성질

> **정리** · 중1 · 단원: [일차방정식](/concepts/일차방정식)
## 요약
양변에 같은 수를 +, −, ×, ÷

## 본문

### 등식의 성질 진술

$a = b$인 등식이 주어졌을 때, 다음이 모두 참입니다.

- 양변에 같은 수 $c$를 더하면: $a + c = b + c$
- 양변에서 같은 수 $c$를 빼면: $a - c = b - c$
- 양변에 같은 수 $c$를 곱하면: $a \times c = b \times c$
- 양변을 같은 0이 아닌 수 $c$로 나누면: $\displaystyle \frac{a}{c} = \frac{b}{c}$ (단, $c \neq 0$)

이것들을 **등식의 성질**이라고 부르며, 등식의 기본 성질입니다.

### 왜 성립하는가

등식은 양쪽이 정확히 같은 값임을 나타냅니다. 양쪽이 같은 상태에서 **같은 조작**을 가하면 여전히 같은 상태를 유지합니다. 

예를 들어, 저울의 양쪽 접시에 같은 무게의 물건이 올려져 있다고 생각하세요. 양쪽에 똑같이 1kg씩 추가하면 여전히 균형이 맞습니다. 반대로 양쪽에서 똑같이 2kg씩 빼거나, 양쪽 무게에 3을 곱하거나, 양쪽을 2로 나누어도 균형은 깨지지 않습니다. 이것이 등식의 성질입니다.

### 방정식 풀이에서의 활용

$2x + 3 = 11$을 풀 때, 우리는 $x$를 혼자 남기기 위해 등식의 성질을 사용합니다.

- 양변에서 3을 빼면: $2x + 3 - 3 = 11 - 3$ → $2x = 8$
- 양변을 2로 나누면: $\displaystyle \frac{2x}{2} = \frac{8}{2}$ → $x = 4$

등식의 성질이 없다면, 방정식을 풀 수 없습니다. 이 성질을 정확하게 이해하고 사용하는 것이 일차방정식, 이차방정식, 나아가 고등수학의 모든 방정식을 푸는 기초입니다.
