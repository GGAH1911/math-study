# 등식의 성질

> **정리** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
등식의 양변에 같은 수를 더하거나, 빼거나, 곱하거나, $0$이 아닌 같은 수로 나누어도 등식은 성립합니다.

## 본문
$a = b$인 등식이 주어졌을 때, 양변에 같은 수 $c$를 더하면 $a + c = b + c$, 양변에서 같은 수 $c$를 빼면 $a - c = b - c$, 양변에 같은 수 $c$를 곱하면 $a \times c = b \times c$, 그리고 양변을 $0$이 아닌 같은 수 $c$로 나누면 $\displaystyle \tfrac{a}{c} = \tfrac{b}{c}$가 성립합니다. 이러한 성질은 등식의 가장 기본적인 원리입니다.

등식은 양쪽의 값이 정확히 같음을 의미합니다. 이는 마치 양쪽의 무게가 같은 저울과 같습니다. 저울의 양쪽 접시에 똑같은 무게의 물건을 더하거나 빼더라도, 혹은 양쪽 무게에 똑같은 배수를 곱하거나 나누더라도 저울의 수평(균형)은 그대로 유지됩니다. 즉, 양변에 동일한 조작을 가하면 등식의 상태는 변하지 않습니다.

### 증명 스케치
등식은 두 수의 값이 같음을 나타내는 상태입니다. 저울의 양쪽 접시에 놓인 물건의 무게가 같을 때, 양쪽에 같은 무게를 더하거나 빼더라도 균형이 유지된다는 물리적 직관을 통해 그 성립 이유를 이해할 수 있습니다.

### 의의와 응용
이 성질은 방정식을 풀 때 미지수의 값을 구하기 위한 핵심 도구로 사용됩니다. 예를 들어 $2x + 3 = 11$이라는 방정식에서 $x$를 구하기 위해 양변에서 $3$을 빼서 $2x = 8$로 만들고, 다시 양변을 $2$로 나누어 $x = 4$라는 해를 찾아내는 과정이 모두 등식의 성질을 이용한 것입니다. 이 원리는 일차방정식을 넘어 모든 방정식 풀이의 기초가 됩니다.

## 학습 체크
- 양변에 같은 수를 곱하거나 뺄 때 등식이 성립하는 원리를 저울의 원리로 설명할 수 있는가?
- $0$으로 나누는 것이 왜 불가능한지 등식의 성질 관점에서 이해하고 있는가?
- 주어진 방정식에서 미지수를 분리하기 위해 어떤 성질을 적용해야 하는지 판단할 수 있는가?

## 관련 개념
- **일차방정식**: 등식의 성질을 이용하여 미지수 $x$의 값을 구하는 구체적인 계산 과정입니다.
