# 항등식

> **정의** · 중1 · 단원: [일차방정식](/concepts/일차방정식)
## 요약
모든 수에 대해 참인 등식

## 본문

항등식은 **문자에 포함된 모든 값에 대해 항상 참인 등식**입니다. 방정식과의 결정적인 차이는, 항등식은 특정 수 몇 개만 맞는 것이 아니라 어떤 수를 대입해도 양변이 같다는 점입니다.

예를 들어 $2x + x = 3x$는 $x = 1, 2, -5, 0.5$ 등 모든 수에서 성립하므로 항등식입니다. 반면 $x + 2 = 5$는 $x = 3$일 때만 참이므로 조건부 등식(또는 방정식)입니다.

중1에서 다루는 항등식의 예:
- $a + b = b + a$ (덧셈의 교환법칙)
- $a(b + c) = ab + ac$ (분배법칙)
- $(x + 3)^2 = x^2 + 6x + 9$

### 직관/기하적 의미

항등식은 "언제나 참인 수학적 진리"입니다. 일차방정식을 풀 때 사용하는 모든 성질(양변에 같은 수를 더한다, 양변을 같은 수로 나눈다 등)이 항등식 위에서 작동합니다.

예를 들어 $x + 3 = 7$을 풀 때:
- 양변에서 3을 빼면 → $x + 3 - 3 = 7 - 3$
- 이 식이 성립하는 이유는 $a - a = 0$ (항등식)이기 때문입니다
- 따라서 $x = 4$

### 한 줄 예

$3(x + 1) = 3x + 3$은 모든 $x$에 대해 참인 항등식입니다. ($x = 0$일 때: $3 = 3$ ✓, $x = 2$일 때: $9 = 9$ ✓)
