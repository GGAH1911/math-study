# 항등식

> **정의** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
문자에 어떤 값을 대입해도 항상 참이 되는 등식입니다.

## 본문
항등식은 문자에 포함된 모든 값에 대해 항상 참인 등식입니다. 방정식과의 결정적인 차이는, 항등식은 특정 수 몇 개만 맞는 것이 아니라 어떤 수를 대입해도 양변이 같다는 점입니다. 예를 들어 $2x + x = 3x$는 $x = 1, 2, -5, 0.5$ 등 모든 수에서 성립하므로 항등식입니다. 반면 $x + 2 = 5$는 $x = 3$일 때만 참이므로 조건부 등식인 방정식입니다. 중학교 1학년 과정에서 다루는 항등식의 예로는 덧셈의 교환법칙인 $a + b = b + a$, 분배법칙인 $a(b + c) = ab + ac$, 그리고 전개식인 $(x + 3)^2 = x^2 + 6x + 9$ 등이 있습니다.

### 직관과 기하적 의미
항등식은 "언제나 참인 수학적 진리"를 의미합니다. 우리가 일차방정식을 풀 때 사용하는 모든 성질, 즉 양변에 같은 수를 더하거나 같은 수로 나누는 등의 연산이 가능한 근거가 바로 이 항등식의 원리 위에 있습니다. 예를 들어 $x + 3 = 7$이라는 방정식을 풀기 위해 양변에서 3을 빼는 과정($x + 3 - 3 = 7 - 3$)이 성립하는 이유는 $a - a = 0$이라는 항등식이 성립하기 때문입니다. 이를 통해 우리는 $x = 4$라는 결론에 도달할 수 있습니다.

### 기본 성질
항등식은 식의 형태가 다르더라도 양변이 완전히 동일한 값을 나타내야 합니다. $3(x + 1) = 3x + 3$과 같은 식은 $x = 0$일 때 $3 = 3$, $x = 2$일 때 $9 = 9$가 되어 모든 $x$에 대해 참이 됩니다. 즉, 식을 정리했을 때 좌변과 우변이 완전히 일치하면 항등식이라고 할 수 있습니다.

## 학습 체크

- 항등식의 성질을 이용하여 방정식의 풀이 과정을 논리적으로 설명할 수 있는가?

## 관련 개념
- **일차방정식**: 항등식과 달리 특정한 값을 대입했을 때만 참이 되는 등식으로, 항등식의 원리를 이용해 해를 구합니다.
