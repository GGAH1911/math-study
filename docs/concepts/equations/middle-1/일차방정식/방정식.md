# 방정식

> **정의** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
미지수의 값에 따라 참과 거짓이 결정되는 등식입니다.

## 본문
방정식은 미지수를 포함하는 등식 중에서, 미지수의 모든 값에 대해 성립하는 것이 아니라 특정한 값에 대해서만 참이 되는 식을 말합니다. 예를 들어 $x + 3 = 7$이라는 식은 모든 $x$에 대해 성립하는 것이 아니라, $x = 4$라는 특정한 값이 대입될 때만 등식이 성립하게 됩니다. 이처럼 방정식을 참으로 만드는 미지수의 값을 근 또는 해라고 부르며, 이러한 해를 찾아내는 과정을 방정식을 푼다고 합니다.

### 직관과 기하적 의미
방정식은 일상생활에서 알 수 없는 미지의 값을 논리적으로 추론할 때 매우 유용합니다. 모든 $x$ 값에 대해 항상 참이 되는 항등식과 달리, 방정식은 특정 조건에서만 성립한다는 점이 핵심입니다. 방정식을 푸는 과정은 "이 등식을 만족하는 미지수는 무엇인가?"라는 질문에 답하는 과정이며, 이는 주어진 조건으로부터 역으로 미지수의 상태를 추리하는 논리적 사고력을 요구합니다.

### 기본 성질
방정식을 풀기 위해서는 등식의 성질을 활용하여 미지수를 한쪽으로 모으는 과정이 필요합니다. 등식의 양변에 같은 수를 더하거나, 같은 수를 빼거나, 같은 수로 나누어도 등식은 성립한다는 성질을 이용하여 미지수의 값을 분리해낼 수 있습니다.

예를 들어 $x + 3 = 7$에서 양변에 $3$을 빼면 $x = 4$라는 해를 얻을 수 있습니다. 다른 예시로 $2x = 10$의 해는 $x = 5$이며, $x - 2 = 8$의 해는 $x = 10$입니다.

## 학습 체크
- 미지수에 특정 값을 대입했을 때 식이 참인지 거짓인지 판별할 수 있는가?
- 방정식의 해를 구하는 과정이 항등식과 어떻게 다른지 설명할 수 있는가?

## 관련 개념
- **일차방정식**: 미지수의 차수가 1인 방정식을 의미하며, 중학교 과정에서 배우는 가장 기본적인 방정식의 형태입니다.
