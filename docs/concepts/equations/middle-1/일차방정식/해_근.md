# 해 근

> **정의** · 중1 · 단원: [일차방정식](/concepts/일차방정식)

## 요약
방정식을 참이 되게 하는 미지수의 값입니다.

## 본문
방정식의 **해(解)** 또는 **근(根)**이란, 주어진 방정식을 참으로 만드는 미지수의 값입니다. 예를 들어 방정식 $x + 3 = 5$에서 $x = 2$를 대입하면 $2 + 3 = 5$가 되어 식이 성립하므로, $x = 2$가 이 방정식의 해가 됩니다. 용어 "해"와 "근"은 수학적으로 같은 의미로 사용되며, 중학교 과정에서는 "해"라는 용어를 주로 사용하고 고등학교 과정에서는 "근"이라는 표현을 더 자주 사용하는 경향이 있습니다.

일반적으로 방정식 $f(x) = 0$ 또는 $f(x) = g(x)$의 해는 방정식의 양변을 같게 만드는 모든 $x$ 값들을 의미합니다. 일차방정식은 대개 하나의 해를 갖지만, 이차방정식과 같이 차수가 높은 방정식은 여러 개의 해를 가질 수도 있고, 조건에 따라 해가 존재하지 않는 경우도 있습니다.

### 직관과 기하적 의미
방정식을 푼다는 것은 "어떤 $x$ 값을 넣어야 이 식이 참이 될까?"라는 질문에 답을 찾는 과정입니다. 이를 기하학적으로 해석하면, 함수의 그래프가 $x$축과 만나는 점의 $x$ 좌표가 바로 방정식의 해가 됩니다. 예를 들어 일차함수 $y = 2x - 4$의 그래프가 $x$축과 만나는 지점은 $x = 2$이므로, 방정식 $2x - 4 = 0$의 해는 $x = 2$가 됩니다. 즉, 해를 찾는 것은 그래프가 특정 높이에 도달하게 하는 $x$ 값을 찾는 것과 같습니다.

### 기본 성질
방정식의 해를 구한 후에는 반드시 대입을 통해 식이 성립하는지 확인하는 검산 과정이 필요합니다. 예를 들어 $3x - 5 = 10$이라는 방정식에서 $x = 5$를 구했다면, $3(5) - 5 = 10$이 성립함을 확인하여 구한 값이 올바른 해임을 검증할 수 있습니다.

## 학습 체크
- 방정식을 참으로 만드는 미지수의 값을 정확히 설명할 수 있는가?
- 주어진 방정식의 해를 구한 후 대입을 통해 검산할 수 있는가?
- 함수의 그래프와 방정식의 해 사이의 관계를 이해하고 있는가?

## 관련 개념
- **일차방정식**: 미지수의 차수가 1인 방정식으로, 일반적으로 하나의 해를 가집니다.
