# 이차방정식 판별식

> **정리** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
실근/허근 분류

## 본문 (학습 시 채워짐)

### 진술 및 가정

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)에서 판별식을 $D = b^2 - 4ac$로 정의할 때, 다음이 성립한다:

- $D > 0$ ⟹ 서로 다른 두 실근 존재
- $D = 0$ ⟹ 중근(중복도 2인 실근) 존재  
- $D < 0$ ⟹ 실근 없음(서로 다른 두 허근)

### 유도 및 증명 스케치

근의 공식에서 출발한다:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

제곱근 안의 식 $b^2 - 4ac$가 판별식 $D$이다. 근이 실수인지 허수인지는 이 식의 부호에 의해 결정된다:

- $\sqrt{D}$가 실수 ⟺ $D \geq 0$ ⟹ 두 근 모두 실수
- $\sqrt{D}$가 허수 ⟺ $D < 0$ ⟹ 두 근이 허수(켤레복소수)

$D = 0$일 때 $x = \frac{-b}{2a}$로 하나의 값이 되지만, 이를 중복도 2인 중근으로 본다.

### 의의 및 응용

판별식은 방정식의 근을 직접 구하지 않고도 **근의 개수와 성질**을 빠르게 판정하는 도구다. 

**실제 문제 예시:** 
방정식 $x^2 - 5x + 6 = 0$일 때, $D = (-5)^2 - 4(1)(6) = 25 - 24 = 1 > 0$ ⟹ 서로 다른 두 실근을 가짐.  
(`sympy.symbols('x'); sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$)

또한 이차함수 그래프가 $x$축과 만나는지 판정하거나, 부등식 해의 존재성 검토 시에도 필수적이다. 예를 들어 $f(x) > 0$ (모든 $x$)이려면 $a > 0$이면서 $D < 0$이어야 한다.
