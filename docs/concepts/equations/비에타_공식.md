### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 하면, 다음 관계가 성립한다:

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이를 **근과 계수의 관계** 또는 **비에타 공식**(Vieta's formulas)이라고 부른다.

### 왜 이렇게 될까?

근의 공식으로부터 유도할 수 있다. 근의 공식에 의해:

$$\alpha = \frac{-b + \sqrt{b^2 - 4ac}}{2a}, \quad \beta = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$$

두 근을 더하면 제곱근 항이 소거되어:

$$\alpha + \beta = \frac{-2b}{2a} = -\frac{b}{a}$$

두 근의 곱은 $(p+q)(p-q) = p^2 - q^2$ 형태이므로:

$$\alpha\beta = \frac{b^2 - (b^2 - 4ac)}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}$$

### 직관: 계수만으로 근의 정보를 알 수 있다

이차방정식을 인수분해 형태로 쓰면 $a(x - \alpha)(x - \beta) = 0$이고, 이를 전개하면 $ax^2 - a(\alpha + \beta)x + a\alpha\beta = 0$이다. 원래 식 $ax^2 + bx + c = 0$과 비교하면 이 공식이 자연스럽게 나온다. **방정식을 풀지 않아도** 계수 $b, c$만으로 두 근의 합과 곱을 바로 알 수 있다는 뜻이다.

### 한 줄 예

$x^2 - 5x + 6 = 0$에서 근의 합은 $-\frac{(-5)}{1} = 5$, 근의 곱은 $\frac{6}{1} = 6$이고, 실제 근은 2와 3이다. (검증: `sympy.solve(x**2 - 5*x + 6, x)`)
