### 정확한 진술

연립방정식(system of equations)이란 두 개 이상의 방정식을 동시에 만족하는 미지수의 값을 찾는 것입니다. 예를 들어, 두 개의 방정식으로 이루어진 연립방정식은 다음과 같이 표현합니다:

$$\begin{cases} f(x, y) = 0 \\ g(x, y) = 0 \end{cases}$$

이때 **해(solution)**는 두 방정식을 동시에 만족하는 모든 $(x, y)$ 쌍입니다. 연립방정식의 해는:
- **유일해**: 정확히 하나의 해를 가지는 경우
- **부정(무수히 많은 해)**: 무한히 많은 해를 가지는 경우  
- **부정(해가 없음)**: 모순되어 해가 존재하지 않는 경우

중요한 것은 각 방정식을 **동시에** 만족하는 값을 찾아야 한다는 점입니다. 한 방정식의 해가 다른 방정식도 만족하는지 반드시 확인해야 합니다.

### 직관/기하적 의미

좌표평면에서 각 방정식은 특정한 도형으로 나타납니다:
- 일차방정식 $ax + by = c$ → **직선**
- 이차방정식 $x^2 + y^2 = r^2$ → **원**  
- 방정식 $y = ax^2$ → **포물선**

**연립방정식의 해는 이 도형들이 만나는 교점의 좌표입니다.** 따라서 해의 개수는 도형들의 교점 개수와 같습니다:
- 직선과 직선 → 1개(유일해) 또는 무수(겹침) 또는 0개(평행)
- 직선과 원 → 0개, 1개, 또는 2개의 교점  
- 원과 원 → 0개, 1개, 또는 2개의 교점

이렇게 **기하학적으로 생각하면** 연립방정식이 무엇인지, 왜 여러 개의 해를 가질 수 있는지 명확히 이해됩니다.

### 한 줄 예

$x + y = 3$과 $2x - y = 0$을 동시에 만족하는 $(x, y)$를 구하면, 두 직선의 교점 $(1, 2)$가 해입니다.
