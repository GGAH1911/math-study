# 미지수 결정

> **정의** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 정확한 진술

미지수가 $n$개일 때, **독립적인 일차방정식이 정확히 $n$개** 있으면 미지수가 유일하게 결정됩니다. 여기서 "독립적"이란 어떤 방정식도 다른 방정식들의 일차결합으로 나타낼 수 없다는 뜻입니다.

$$\begin{cases} a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = b_1 \\ c_1 x_1 + c_2 x_2 + \cdots + c_n x_n = b_2 \\ \vdots \\ m_1 x_1 + m_2 x_2 + \cdots + m_n x_n = b_n \end{cases}$$

이 연립방정식이 계수행렬의 rank와 확대행렬의 rank가 모두 $n$과 같을 때 해가 유일합니다.

## 직관과 기하적 의미

2차원 평면에서 미지수 2개 $x, y$를 생각하면:
- 방정식 1개 → 직선 1개 (무수히 많은 점)
- 방정식 2개 (독립) → 두 직선의 교점 (1개 점)
- 방정식 3개 (독립) → 해가 없을 수 있음

3차원 공간에서는 평면 3개가 한 점에서 만나야 미지수 3개가 결정됩니다. 미지수 개수 = 독립적인 방정식 개수일 때만 보통의 경우 **유일한 해**를 얻습니다.

## 한 줄 예

$\begin{cases} 2x + 3y = 5 \\ x - y = 1 \end{cases}$ → 미지수 2개, 독립적인 방정식 2개 → $(x, y)$가 유일하게 결정됨 (검산: `from sympy import symbols, solve; x, y = symbols('x y'); solve([2*x + 3*y - 5, x - y - 1], [x, y])` → $x=2, y=\frac{1}{3}$)
