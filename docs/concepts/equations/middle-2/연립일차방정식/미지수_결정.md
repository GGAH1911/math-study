# 미지수 결정

> **정의** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
미지수의 개수와 독립적인 일차방정식의 개수가 일치할 때 미지수는 유일한 값으로 결정됩니다.

## 본문
미지수가 $n$개인 경우, 서로 독립적인 일차방정식이 정확히 $n$개 존재하면 미지수의 값은 유일하게 결정됩니다. 여기서 독립적이라는 것은 어떤 방정식도 다른 방정식들의 일차결합으로 나타낼 수 없음을 의미합니다. 이를 수식으로 나타내면 다음과 같습니다.

$$\begin{cases} a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = b_1 \\ c_1 x_1 + c_2 x_2 + \cdots + c_n x_n = b_2 \\ \vdots \\ m_1 x_1 + m_2 x_2 + \cdots + m_n x_n = b_n \end{cases}$$

이 연립방정식의 해가 유일하기 위해서는 계수행렬의 계수와 확대행렬의 계수가 모두 미지수의 개수인 $n$과 같아야 합니다.

### 직관과 기하적 의미
2차원 평면에서 미지수 2개 $x, y$를 다룰 때, 방정식 1개는 하나의 직선을 의미하며 해는 직선 위의 무수히 많은 점이 됩니다. 반면, 서로 독립적인 방정식 2개가 있으면 두 직선이 만나는 교점이 하나로 결정되어 해가 유일해집니다. 3차원 공간에서는 세 개의 평면이 한 점에서 만날 때 미지수 3개가 결정됩니다. 일반적으로 미지수의 개수와 독립적인 방정식의 개수가 같을 때 유일한 해를 얻을 수 있습니다.

### 기본 성질
- 미지수의 개수보다 독립적인 방정식의 개수가 적으면 해가 무수히 많거나 없을 수 있습니다.
- 미지수의 개수보다 독립적인 방정식의 개수가 많으면 해가 존재하지 않을 수도 있습니다.
- 예시로 $\begin{cases} 2x + 3y = 5 \\ x - y = 1 \end{cases}$와 같이 미지수 2개에 독립적인 방정식 2개가 주어지면 $(x, y) = (2, \frac{1}{3})$과 같이 유일한 해가 결정됩니다.

## 학습 체크
- 미지수가 3개인 방정식을 풀기 위해 필요한 최소한의 독립적인 방정식 개수는 몇 개인가요?
- 두 방정식이 서로 독립적이지 않고 하나의 방정식의 배수라면 해는 어떻게 되나요?

## 관련 개념
- **연립일차방정식**: 여러 개의 일차방정식을 동시에 만족하는 공통된 해를 찾는 과정이며, 미지수 결정의 핵심적인 도구입니다.
