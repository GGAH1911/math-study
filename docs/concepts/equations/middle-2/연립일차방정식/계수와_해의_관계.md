# 계수와 해의 관계

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음이 성립합니다:

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이를 **근과 계수의 관계** 또는 **비에타의 정리(Vieta's formulas)**라고 합니다. 즉, 방정식의 근을 직접 구하지 않아도 계수만으로 두 근의 합과 곱을 알 수 있다는 뜻입니다.

## 직관/기하적 의미

이 관계는 인수분해에서 비롯됩니다. 이차방정식이 두 근 $\alpha, \beta$를 가지면:

$$ax^2 + bx + c = a(x - \alpha)(x - \beta)$$

우변을 전개하면:

$$a(x - \alpha)(x - \beta) = a[x^2 - (\alpha + \beta)x + \alpha\beta]$$

$$= ax^2 - a(\alpha + \beta)x + a\alpha\beta$$

좌변과 비교하면 $b = -a(\alpha + \beta)$, $c = a\alpha\beta$이므로 위의 관계가 얻어집니다. 따라서 근과 계수의 관계는 **인수분해 형태의 전개**에 불과합니다.

## 한 줄 예

$x^2 - 5x + 6 = 0$의 두 근은 $\alpha = 2, \beta = 3$입니다. 계수만으로: $\alpha + \beta = -(-5)/1 = 5$ ✓, $\alpha\beta = 6/1 = 6$ ✓

*검산(sympy):* `solve(x**2 - 5*x + 6, x)` → `[2, 3]`
