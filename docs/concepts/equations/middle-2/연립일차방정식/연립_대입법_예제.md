# 연립 대입법 예제

> **예제** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
$y=2x+1, x+y=4$

## 본문 (학습 시 채워짐)

### 문제

다음 연립일차방정식을 대입법으로 풀어라.
$$\begin{cases} y = 2x + 1 \\ x + y = 4 \end{cases}$$

### 단계별 풀이

**1단계: 한 미지수를 다른 미지수로 표현하기**  
첫 번째 식 $y = 2x + 1$에서 이미 $y$가 $x$로 정리되어 있으므로 이를 그대로 이용합니다. (대입법은 한 문자가 미리 정리되어 있을 때 가장 효율적입니다.)

**2단계: 두 번째 식에 대입하기**  
$y = 2x + 1$을 $x + y = 4$에 대입합니다:
$$x + (2x + 1) = 4$$
(두 식이 같은 해를 공유하므로 $y$ 자리에 $2x + 1$을 넣어도 참입니다.)

**3단계: $x$ 구하기**  
정리하면:
$$3x + 1 = 4$$
$$3x = 3$$
$$x = 1$$

**4단계: $y$ 구하기**  
구한 $x = 1$을 첫 번째 식에 대입합니다:
$$y = 2(1) + 1 = 3$$
($x$의 값이 정해졌으므로 $y$도 유일하게 결정됩니다.)

**5단계: 검산**  
$(x, y) = (1, 3)$을 두 식에 모두 대입해 확인합니다:
- $y = 2x + 1$: $3 = 2(1) + 1 = 3$ ✓
- $x + y = 4$: $1 + 3 = 4$ ✓

### 답

$$x = 1, \, y = 3$$

### 변형/주의

- **언제 대입법을 쓸까?** 한 식이 이미 한 문자에 대해 정리되어 있으면(예: $y = \cdots$) 대입법이 가장 빠릅니다. 반면 두 식이 모두 복잡하게 섞여 있으면 가감법을 고려하세요.
- **검산 필수**: 연립방정식은 두 식을 동시에 만족해야 하므로 반드시 두 식 모두에 넣어 확인하세요.
- **대입할 식을 선택하는 기준**: 계수가 1이거나 정수 해가 나오기 쉬운 식을 선택하면 계산 실수를 줄일 수 있습니다.
