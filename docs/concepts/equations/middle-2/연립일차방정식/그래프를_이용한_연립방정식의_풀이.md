# 그래프를 이용한 연립방정식의 풀이

> **정의** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
두 개 이상의 일차방정식을 좌표평면 위의 직선으로 나타냈을 때, 그 직선들이 만나는 교점의 좌표를 통해 연립방정식의 해를 찾는 방법입니다.

## 본문
두 개 이상의 일차방정식을 동시에 만족하는 미지수의 값을 찾는 연립방정식을 풀 때, 각 방정식을 좌표평면 위의 직선으로 나타내고 그 교점의 좌표를 구하는 풀이 방법입니다.

### 직관과 기하적 의미
각 일차방정식 $ax + by = c$ (단, $a, b$가 동시에 $0$이 아님)는 좌표평면에서 하나의 직선을 나타냅니다. 연립방정식의 해는 모든 방정식을 동시에 만족하는 점이므로, 기하학적으로는 여러 직선이 공통으로 지나는 교점입니다. 그래프를 이용한 방법의 핵심은 복잡한 대수 계산 대신 시각적 표현을 통해 해를 찾는 것입니다.

### 기본 성질
두 직선의 위치 관계에 따라 연립방정식의 해의 개수가 결정됩니다. 두 직선이 한 점에서 만나면 해가 유일하고, 두 직선이 평행하면 교점이 없어 해가 없으며, 두 직선이 일치하면 모든 점이 공통점이 되어 해가 무수히 많습니다. 이를 통해 연립방정식의 해의 존재성과 개수를 즉시 파악할 수 있습니다.

예를 들어, $\begin{cases} x + y = 3 \\ 2x - y = 0 \end{cases}$를 그래프로 풀 때, 첫 번째 식을 $y = -x + 3$으로, 두 번째 식을 $y = 2x$로 정리합니다. 좌표평면에 두 직선을 그리면 점 $(1, 2)$에서 만나므로, 연립방정식의 해는 $x = 1, y = 2$입니다.

## 학습 체크
- 두 직선이 평행할 때와 일치할 때, 각각 연립방정식의 해는 어떻게 나타나는가?
- 주어진 연립방정식의 해를 그래프로 그렸을 때, 교점의 좌표가 방정식의 해와 일치하는가?

## 관련 개념
- **연립일차방정식**: 두 개 이상의 일차방정식이 결합된 형태로, 그래프를 이용한 풀이는 이 방정식의 해를 기하학적으로 해석하는 방법입니다.
