# 그래프를 이용한 연립방정식의 풀이

## 정확한 진술

두 개 이상의 일차방정식을 동시에 만족하는 미지수의 값을 찾는 연립방정식을 풀 때, 각 방정식을 좌표평면 위의 직선으로 나타내고 그 교점의 좌표를 구하는 풀이 방법입니다.

## 직관/기하적 의미

각 일차방정식 $ax + by = c$ (단, $a, b$가 동시에 0이 아님)는 좌표평면에서 하나의 직선을 나타냅니다. 연립방정식의 해는 모든 방정식을 동시에 만족하는 점이므로, 기하학적으로는 여러 직선이 공통으로 지나는 교점입니다.

그래프를 이용한 방법의 핵심은 대수 계산 대신 시각적 표현을 통해 해를 찾는 것입니다. 두 직선이 한 점에서 만나면 해가 유일하고, 두 직선이 평행하면 교점이 없어 해가 없으며, 두 직선이 일치하면 모든 점이 공통점이 되어 해가 무수히 많습니다. 이는 연립방정식의 해의 존재성과 개수를 즉시 파악할 수 있게 해줍니다.

## 한 줄 예

$$\begin{cases} x + y = 3 \\ 2x - y = 0 \end{cases}$$

를 그래프로 풀 때, 첫 번째 식을 $y = -x + 3$으로, 두 번째 식을 $y = 2x$로 정리합니다. 좌표평면에 두 직선을 그으면 점 $(1, 2)$에서 만나므로, 연립방정식의 해는 $x = 1, y = 2$입니다.

(검산: `sympy.solve([Eq(x+y, 3), Eq(2*x-y, 0)], [x, y])` = {x: 1, y: 2})
