# 가감법

> **정리** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
두 식을 더하거나 빼서 미지수 중 하나를 소거하여 해를 구하는 방법입니다.

## 본문
연립일차방정식을 풀 때, 두 식을 더하거나 빼서 미지수 중 하나를 소거하고 다른 하나의 값을 구하는 방법을 가감법이라 합니다. 일반적으로 다음과 같은 형태의 연립방정식에 적용합니다.
$$\begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases}$$
이 방법은 등식의 성질, 즉 같은 식의 양변을 더하면 같은 식이 되고 한 식에서 다른 식을 빼도 같은 식이 된다는 원리에 기반합니다.

$x$의 계수를 같게 만들기 위해 첫 번째 식에 $k$, 두 번째 식에 $m$을 곱한 뒤 두 식을 뺀다고 가정해 봅시다.
$$ka_1 x + kb_1 y = kc_1$$
$$ma_2 x + mb_2 y = mc_2$$
두 식을 빼면 다음과 같습니다.
$$(ka_1 - ma_2)x + (kb_1 - mb_2)y = kc_1 - mc_2$$
이때 $ka_1 = ma_2$가 되도록 $k$와 $m$을 선택하면 $x$가 소거되어 $y$에 관한 일차방정식만 남게 됩니다. 이렇게 구한 $y$의 값을 원래 식에 대입하면 $x$의 값도 구할 수 있습니다.

### 증명 스케치
계수가 서로 다른 경우, 각 식에 적절한 상수를 곱하여 특정 미지수의 계수를 일치시킵니다. 그 후 두 식을 더하거나 빼서 해당 미지수를 제거함으로써 변수가 하나인 방정식으로 변환하여 해를 도출합니다.

### 의의와 응용
가감법은 한 변수의 계수를 쉽게 같게 만들 수 있는 상황에서 대입법보다 계산 과정이 훨씬 간결하고 효율적입니다. 이는 중학교 2학년 과정에서 연립방정식을 해결하는 핵심적인 도구로 활용됩니다.

예를 들어, $\begin{cases} 2x + 3y = 7 \\ 2x - y = 3 \end{cases}$와 같은 식에서 $x$의 계수가 2로 동일하므로 두 식을 바로 빼면 $4y = 4$가 되어 $y=1$을 얻을 수 있습니다. 이를 대입하면 $x=2$가 되어 해 $(x, y) = (2, 1)$을 구할 수 있습니다.

## 학습 체크
- 두 식의 계수를 일치시키기 위해 어떤 수를 곱해야 하는지 계산할 수 있는가?
- 두 식을 더하거나 빼는 과정에서 부호 실수를 하지 않고 정확히 계산할 수 있는가?
- 계수가 복잡한 경우에도 가감법을 사용하여 미지수를 소거할 수 있는가?

## 관련 개념
- **연립일차방정식**: 두 개 이상의 일차방정식이 결합된 형태로, 가감법을 통해 공통된 해를 찾습니다.
