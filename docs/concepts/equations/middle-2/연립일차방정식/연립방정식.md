# 연립방정식

> **정의** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
두 개 이상의 방정식을 함께 쓴 것으로, 모든 방정식을 동시에 만족하는 미지수의 값을 찾는 것입니다.

## 본문
연립방정식은 두 개 이상의 방정식을 한 쌍으로 묶어 나타낸 것입니다. 각 방정식은 동일한 미지수를 포함하고 있으며, 연립방정식의 해란 이 모든 방정식을 동시에 참이 되게 하는 미지수의 값을 의미합니다. 예를 들어 $\begin{cases} x + y = 5 \\ 2x - y = 1 \end{cases}$라는 연립방정식이 있을 때, $x = 2, y = 3$을 대입하면 두 식을 모두 만족하므로 이 값이 연립방정식의 해가 됩니다. 만약 어떤 값이 하나의 방정식은 만족하지만 다른 방정식은 만족하지 않는다면, 그것은 연립방정식의 해가 될 수 없습니다.

### 직관과 기하적 의미
현실 세계의 복합적인 조건을 해결할 때 연립방정식이 사용됩니다. 예를 들어 사과와 귤의 가격을 각각 구해야 하는 상황처럼, 미지수가 두 개라면 이를 해결하기 위해 두 개의 조건(방정식)이 필요합니다. 기하학적으로 좌표평면 위에서 각 일차방정식은 하나의 직선을 나타냅니다. 따라서 연립방정식의 해는 두 직선이 공통으로 가지는 점, 즉 두 직선의 교점의 좌표와 같습니다.

### 기본 성질
연립방정식의 해는 모든 방정식을 동시에 만족해야 한다는 점이 핵심입니다. 위 예시에서 두 직선은 $(2, 3)$이라는 한 점에서 만나며, 이 교점이 곧 연립방정식의 해가 됩니다.

## 학습 체크
- 모든 방정식을 동시에 만족하는 미지수의 값을 찾을 수 있는가?
- 두 직선의 교점이 연립방정식의 해와 같음을 이해하고 있는가?
- 실생활의 복합적인 상황을 연립방정식 모델로 세울 수 있는가?

## 관련 개념
- **연립일차방정식**: 미지수가 2개인 일차방정식 두 개를 묶어 놓은 형태의 연립방정식을 의미합니다.
