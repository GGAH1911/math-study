# 미지의 상수 결정

> **정의** · 중2 · 단원: [연립일차방정식](/concepts/연립일차방정식)

## 요약
연립일차방정식의 해를 식에 대입하여 미지의 상수를 구하거나, 해의 개수에 따른 계수 사이의 비율 관계를 이용하여 상수를 결정하는 방법입니다.

## 본문
연립일차방정식의 해에 대한 조건이 주어졌을 때 식에 포함된 미지의 상수를 결정하는 과정은 중학교 2학년 연립방정식 단원의 대표적인 응용 유형입니다. 연립방정식 $\begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases}$가 주어진 해 $(x_0, y_0)$를 갖는다는 조건이 있다면, 해당 해의 값을 각 방정식의 $x$와 $y$ 자리에 대입하여 미지수가 포함된 새로운 방정식을 유도할 수 있습니다. 이렇게 얻은 방정식을 풀면 미지수 상수의 값을 결정할 수 있습니다.

또한, 해가 하나뿐인지, 무수히 많은지, 혹은 없는지에 대한 조건이 주어질 경우 각 방정식의 계수들 사이의 비율 관계를 활용합니다. 두 직선이 일치하여 해가 무수히 많은 경우에는 $\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} = \tfrac{c_1}{c_2}$의 관계가 성립하며, 해가 없는 경우에는 $\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} \neq \tfrac{c_1}{c_2}$의 관계를 가집니다.

### 직관과 기하적 의미
기하학적으로 연립방정식의 해는 두 직선의 교점을 의미합니다. 미지수가 포함된 상수를 결정한다는 것은, 주어진 특정 점 $(x_0, y_0)$를 반드시 지나도록 직선의 기울기나 절편을 조절하는 것과 같습니다. 해가 무수히 많은 경우는 두 직선이 완전히 겹치는 상태를, 해가 없는 경우는 두 직선이 평행한 상태를 의미합니다.

### 기본 성질
주어진 해가 연립방정식의 모든 식을 동시에 만족해야 한다는 점이 핵심입니다. 따라서 상수를 결정한 후에는 반드시 결정된 값이 두 번째 식에서도 성립하는지 확인하여 해의 일관성을 검토해야 합니다.

## 학습 체크
