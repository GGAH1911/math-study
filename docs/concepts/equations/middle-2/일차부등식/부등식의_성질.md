# 부등식의 성질

> **정리** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
양변에 음수를 곱하거나 나누면 부등호의 방향이 반대로 바뀝니다.

## 본문
두 수의 부등식 양변에 같은 수를 더하거나 빼면 부등호의 방향은 유지됩니다. 또한 양변에 같은 양수를 곱하거나 나누어도 부등호의 방향은 변하지 않습니다. 하지만 양변에 같은 음수를 곱하거나 나누는 경우에는 부등호의 방향이 반전된다는 점에 주의해야 합니다.

형식적으로 $a < b$일 때 다음이 성립합니다.
- $a + c < b + c$ (덧셈)
- $a - c < b - c$ (뺄셈)
- $c > 0$이면 $ac < bc$ (양수 곱셈)
- $c < 0$이면 $ac > bc$ (음수 곱셈)

### 증명 스케치
$a < b$라는 것은 $b - a > 0$인 양수임을 의미합니다. 여기에 음수 $c < 0$를 곱하면 양수와 음수의 곱이므로 $c(b - a) < 0$이 됩니다. 이를 전개하면 $cb - ca < 0$이 되며, 양변에 $-1$을 곱하여 정리하면 $ca > cb$, 즉 $ac > bc$가 됩니다. 예를 들어 $3 < 5$의 양변에 $-2$를 곱하면 $-6 > -10$이 되는 것과 같습니다. 이는 음수를 곱할 때 수의 상대적 크기 관계가 뒤바뀌기 때문입니다.

### 의의와 응용
이 성질은 일차부등식을 풀 때 가장 핵심적인 규칙입니다. 예를 들어 $-2x < 6$이라는 부등식을 풀 때, 양변을 음수인 $-2$로 나누면 부등호 방향이 바뀌어 $x > -3$이라는 결과를 얻게 됩니다. 만약 부등호 방향을 바꾸지 않으면 잘못된 해를 구하게 됩니다. 이는 등식을 유지하며 식을 변형하는 방정식의 풀이와는 다른, 부등식만의 고유하고 특수한 성질입니다.

검증: $x = -2$를 대입하면 원래 식 $-2(-2) = 4 < 6$이 성립하므로, 정답인 $x > -3$은 올바른 결과입니다.

## 학습 체크

- 일차부등식을 풀 때 음수 계수를 처리하는 과정에서 부등호 방향을 정확히 전환하였는가?

## 관련 개념
- **일차부등식**: 부등식의 성질을 이용하여 미지수의 범위를 구하는 과정에서 음수 곱셈/나눗셈 시 부등호 방향을 바꾸는 규칙이 필수적으로 적용됩니다.
