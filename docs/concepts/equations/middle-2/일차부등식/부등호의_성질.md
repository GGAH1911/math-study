# 부등호의 성질

> **정의** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
부등식의 양변에 같은 수를 더하거나 빼거나, 양수를 곱하거나 나누면 부등호의 방향이 유지되지만, 음수를 곱하거나 나누면 부등호의 방향이 반대로 바뀝니다.

## 본문
부등호의 성질은 부등식의 양변에 같은 수를 더하거나 빼기, 곱하기, 나누기 등의 연산을 할 때 부등호의 방향이 어떻게 변하는지를 나타내는 규칙입니다. 이 성질은 부등식을 풀고 검산하는 과정에서 가장 기초가 되는 원리입니다.

### 직관과 기하적 의미
수직선 위에서 $a < b$는 점 $a$가 점 $b$보다 왼쪽에 위치함을 의미합니다. 양변에 같은 수 $c$를 더하면 두 점이 모두 오른쪽으로 $c$만큼 평행 이동하므로 대소 관계는 그대로 유지됩니다. 하지만 음수를 곱하는 연산은 수직선 위에서 원점을 중심으로 점들의 위치를 뒤집는 효과를 가져옵니다. 예를 들어 $2 < 5$의 양변에 $-1$을 곱하면 $-2 > -5$가 되는데, 이는 수직선에서 오른쪽 끝에 있던 값이 음수 영역에서는 왼쪽 끝으로 이동하기 때문입니다.

### 기본 성질
부등식의 성질은 다음과 같이 네 가지로 정리할 수 있습니다.
1. 덧셈과 뺄셈: $a < b$이면 $a + c < b + c$이고 $a - c < b - c$입니다.
2. 양수의 곱셈과 나눗셈: $a < b$이고 $c > 0$이면 $ac < bc$이고 $\tfrac{a}{c} < \tfrac{b}{c}$입니다.
3. 음수의 곱셈과 나눗셈: $a < b$이고 $c < 0$이면 $ac > bc$이고 $\tfrac{a}{c} > \tfrac{b}{c}$입니다.
4. 이행성: $a < b$이고 $b < c$이면 $a < c$입니다.

예를 들어 $3 < 7$에서 양변에 $2$를 더하면 $5 < 9$가 되고, 양변에 $-2$를 곱하면 $-6 > -14$가 되어 부등호의 방향이 바뀜을 확인할 수 있습니다.

## 학습 체크
- 음수를 곱하거나 나눌 때 부등호의 방향을 반대로 바꾸었는가?
- 수직선 상에서 수의 이동과 대소 관계의 변화를 시각적으로 이해하고 있는가?
- 이행성의 성질을 이용하여 복잡한 부등식의 범위를 구할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 방정식은 등호를 사용하여 값이 같음을 나타내지만, 부등식은 부등호를 사용하여 값의 범위를 나타내며 두 개념 모두 수의 대소 관계를 다룹니다.
