# 부등호의 성질

> **정의** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 정확한 진술

부등호의 성질은 부등식의 양변에 같은 수를 더하거나 빼기, 곱하기, 나누기 등의 연산을 할 때 부등호의 방향이 어떻게 변하는지를 나타내는 규칙입니다. 주요 성질은 다음과 같습니다.

**덧셈과 뺄셈**: $a < b$이면 $a + c < b + c$이고 $a - c < b - c$입니다.

**양수의 곱셈과 나눗셈**: $a < b$이고 $c > 0$이면 $ac < bc$이고 $\frac{a}{c} < \frac{b}{c}$입니다.

**음수의 곱셈과 나눗셈**: $a < b$이고 $c < 0$이면 $ac > bc$이고 $\frac{a}{c} > \frac{b}{c}$입니다. (부등호가 바뀜!)

**이행성**: $a < b$이고 $b < c$이면 $a < c$입니다.

## 직관과 기하적 의미

수직선 위에서 $a < b$는 점 $a$가 점 $b$보다 왼쪽에 있다는 뜻입니다. 양변에 같은 수 $c$를 더하면, 두 점이 모두 오른쪽으로 $c$만큼 이동하므로 대소관계는 유지됩니다.

그러나 음수를 곱하면 상황이 달라집니다. 예를 들어 $2 < 5$를 $-1$로 곱하면 $-2 > -5$가 됩니다. 이는 음수를 곱할 때 수직선이 원점을 중심으로 뒤집어지기 때문입니다. 따라서 부등호 방향이 반대가 됩니다.

## 한 줄 예와 검산

$3 < 7$에서 양변에 $2$를 더하면 $5 < 9$ ✓

$3 < 7$에서 양변에 $-2$를 곱하면 $-6 > -14$ ✓

$-4 < -1$을 $3$으로 나누면 $-\frac{4}{3} < -\frac{1}{3}$ ✓

이 성질들을 정확히 이해하면 부등식을 푸는 과정에서 실수를 줄일 수 있습니다. 특히 음수를 곱하거나 나눌 때 부등호를 반드시 뒤집어야 한다는 점이 가장 중요합니다.
