# 해의 범위

> **정의** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
부등식을 참이 되게 하는 모든 수의 집합입니다.

## 본문
일차부등식을 참이 되게 하는 모든 $x$값들의 집합을 **해의 범위**라고 합니다. 예를 들어 부등식 $x + 3 > 5$를 만족하는 $x$는 2보다 큰 모든 수이므로, 해의 범위는 $x > 2$가 됩니다. 이는 단 하나의 값을 갖는 방정식의 해와 달리, 특정 구간에 속하는 수들의 연속적인 집합을 의미합니다.

### 직관과 기하적 의미
부등식의 해의 범위는 수직선 위에 시각적으로 나타낼 수 있습니다. $x > a$ 형태의 해는 수직선에서 $a$의 오른쪽 부분을 나타내며, $a$ 자신은 포함하지 않으므로 흰 동그라미(○)로 표시합니다. 반면 $x \ge a$ 형태의 해는 $a$의 오른쪽 부분을 나타내며, $a$를 포함하므로 검은 동그라미(●)로 표시합니다. $x < a$와 $x \le a$는 각각 $a$의 왼쪽 부분을 나타냅니다. 일차부등식의 해의 범위는 항상 한쪽 방향으로 끝없이 뻗어나가는 반직선 형태를 띱니다.

### 기본 성질
부등식 $3x - 2 \ge 7$을 예로 들어 해의 범위를 구해보면 다음과 같습니다. 먼저 양변에 2를 더하면 $3x \ge 9$이 되고, 양변을 3으로 나누면 $x \ge 3$을 얻습니다. 따라서 해의 범위는 $x \ge 3$이며, 이는 3을 포함하여 3보다 크거나 같은 모든 실수를 의미합니다. 수직선에서는 3의 위치에 검은 동그라미를 찍고 오른쪽으로 화살표를 그려 표현합니다.

## 학습 체크
- 부등식의 해를 수직선 위에 올바른 기호(○, ●)를 사용하여 나타낼 수 있는가?
- 해의 범위가 방정식의 해와 어떻게 다른지 설명할 수 있는가?
- 주어진 일차부등식을 풀어 해의 범위를 정확히 구할 수 있는가?

## 관련 개념
- **일차부등식**: 해의 범위를 구하는 대상이 되는 식이며, 일차부등식을 풀면 그 결과로 해의 범위를 얻게 됩니다.
