# 해의 범위

> **정의** · 중2 · 단원: [일차부등식](/concepts/일차부등식)
## 요약
부등식을 참이 되게 하는 수의 집합

## 본문

### 정의

일차부등식을 참이 되게 하는 모든 $x$값들의 집합을 **해의 범위**라고 합니다. 예를 들어 부등식 $x + 3 > 5$를 만족하는 $x$는 2보다 큰 모든 수이므로, 해의 범위는 $x > 2$입니다.

### 직관과 기하적 의미

부등식의 해의 범위는 **수직선** 위에 시각적으로 나타낼 수 있습니다. 
- $x > a$ 형태의 해는 수직선에서 $a$의 오른쪽 부분을 나타내며, $a$ 자신은 포함하지 않습니다(흰 동그라미 ○).
- $x \ge a$ 형태의 해는 $a$의 오른쪽 부분을 나타내며, $a$는 포함합니다(검은 동그라미 ●).
- $x < a$와 $x \le a$는 각각 $a$의 왼쪽을 나타냅니다.

일차부등식의 해의 범위는 항상 **반직선** 형태입니다. 즉, 한쪽 방향으로 끝없이 뻗어나가는 수들의 집합이며, 양쪽으로 제한되지 않습니다. 이는 방정식의 해(하나의 수)와 완전히 다릅니다.

### 예시

부등식 $3x - 2 \ge 7$을 풀어 해의 범위를 구해봅시다:

$$3x \ge 9$$
$$x \ge 3$$

따라서 해의 범위는 $x \ge 3$입니다. 이는 3을 포함하여 3보다 크거나 같은 모든 실수를 나타내며, 수직선에서 3의 위치에 검은 동그라미를 표시한 후 오른쪽으로 화살표를 그립니다.

(`sympy.solve(3*x - 2 >= 7, x)`)
