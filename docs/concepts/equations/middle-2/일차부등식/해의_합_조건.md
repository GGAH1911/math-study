# 해의 합 조건

## 정확한 진술

두 개 이상의 일차부등식을 동시에 만족하는 모든 $x$의 값들을 찾는 것을 **해의 합 조건을 구한다**고 합니다. 더 정확히는, 주어진 여러 부등식 각각의 해를 먼저 구한 뒤, 그 범위들이 모두 겹치는 부분을 찾는 과정입니다. 이렇게 겹치는 부분을 **공통해** 또는 **교집합**이라 부르며, 이것이 원래 부등식들을 모두 만족하는 $x$의 범위입니다.

## 직관/기하적 의미

수직선을 그려서 생각해 봅시다. 부등식 $x > 1$은 수직선에서 1 오른쪽의 모든 점들을 나타내고, $x < 5$는 5 왼쪽의 모든 점들을 나타냅니다. 두 조건을 **동시에** 만족하려면, 이 두 영역이 겹치는 부분인 $1 < x < 5$ 구간에 있어야 합니다. 각 부등식의 해를 수직선에 색칠한 후, 모든 색이 중복된 부분이 바로 공통해입니다. 만약 두 범위가 전혀 겹치지 않으면 공통해는 존재하지 않습니다.

## 한 줄 예

부등식 $x + 2 > 0$과 $x - 3 < 0$을 동시에 만족하려면, 먼저 각각 $x > -2$, $x < 3$이므로, 공통해는 $-2 < x < 3$입니다.
