# 일차부등식의 풀이

> **정의** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
일차부등식의 풀이는 이항과 동류항 정리를 통해 $x$의 범위를 구하는 과정이며, 음수로 나누거나 곱할 때 부등호의 방향이 바뀐다는 점이 핵심입니다.

## 본문
$ax + b < c$ 형태의 식(부등호는 $<, \le, >, \ge$ 중 하나)을 **일차부등식**이라 하며, 이때 $a \neq 0$이어야 합니다. 일차부등식의 **풀이**는 이 부등식을 만족하는 $x$의 범위를 구하는 과정입니다. 풀이의 원칙은 등식의 성질과 유사하지만 한 가지 중요한 차이가 있습니다. 먼저 미지수 항을 한쪽으로, 상수를 다른 쪽으로 이동시키는 이항을 수행하고, 양변을 정리하여 $ax \circ c$ 형태로 만듭니다. 마지막으로 양변을 $a$로 나눌 때, $a > 0$이면 부등호의 방향을 그대로 유지하지만, $a < 0$이면 부등호의 방향을 반대로 바꾸어야 합니다. 예를 들어 $2x + 3 < 7$을 풀면 $2x < 4$가 되고, 양변을 $2$로 나누어 $x < 2$라는 해를 얻습니다.

### 직관과 기하적 의미
일차부등식의 해는 수직선 위에서 **반직선** 또는 **구간**의 형태로 나타납니다. 예를 들어 $x < 2$의 해는 수직선 위에서 $2$를 기준으로 왼쪽의 모든 점을 의미하며, $x \ge -1$의 해는 $-1$을 포함하여 오른쪽의 모든 점을 의미합니다. 부등호의 방향이 바뀌는 규칙은 음수를 곱하거나 나눌 때 수직선 상에서 대소 관계가 역전되는 성질에서 비롯됩니다.

### 기본 성질
부등식의 양변에 같은 수를 더하거나 빼도 부등호의 방향은 변하지 않습니다. 또한 양변에 양수를 곱하거나 나누어도 부등호 방향은 유지되지만, 음수를 곱하거나 나눌 때는 반드시 부등호의 방향을 반대로 바꾸어야 합니다.

## 학습 체크
- 양변을 음수로 나누었을 때 부등호의 방향을 올바르게 바꾸었는가?
- 해를 구한 후 수직선 위에 해당 범위를 정확히 표시할 수 있는가?

## 관련 개념
- **일차부등식**: $ax + b < c$ 형태의 식을 만족하는 $x$의 범위를 구하는 과정입니다.
