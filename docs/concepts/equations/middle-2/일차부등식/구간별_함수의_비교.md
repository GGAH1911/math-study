### 정확한 진술

구간별 함수(또는 절대값 함수)는 정의역을 몇 개 구간으로 나누어, 각 구간에서 서로 다른 규칙으로 함숫값을 정하는 함수입니다. 예를 들어:

$$f(x) = \begin{cases} -2x + 1 & \text{if } x < 1 \\ x^2 - 1 & \text{if } x \geq 1 \end{cases}$$

구간별 함수의 **비교**란 주어진 $x$ 값에서 여러 함수를 동시에 고려할 때, 어느 함수가 더 큰 값인지 판정하는 과정입니다. 일차부등식 $f(x) > g(x)$ 또는 $f(x) = g(x)$를 각 구간에서 풀어서 전체 그림을 그립니다.

### 직관과 그래프적 의미

구간별 함수는 그래프 위에서 "구간별로 다른 곡선"으로 나타납니다. 비교한다는 것은 두 그래프가 어디서 만나고(교점), 어느 쪽이 위에 있는지(대소)를 파악하는 것입니다.

예를 들어 $f(x) = |x|$는 원점에서 꺾이는 V자 모양입니다:
- $x < 0$일 때: $f(x) = -x$ (우상향)
- $x \geq 0$일 때: $f(x) = x$ (우상향)

$x = 0$에서 두 규칙이 만나고, 전체적으로 "연결된" 그래프가 됩니다.

### 한 줄 예

$f(x) = |x - 2|$와 $g(x) = 1$을 비교할 때, $f(x) = g(x)$인 $x$를 찾으려면 $x - 2 = 1$ (또는 $x - 2 = -1$)을 풀어 $x = 3$ 또는 $x = 1$을 얻고, 그 사이에서 $f(x) < g(x)$임을 알 수 있습니다.

Verify: `from sympy import symbols, Abs, solve; x = symbols('x'); solve(Abs(x - 2) - 1, x)`
