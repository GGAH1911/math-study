# 정수의 개수

## 정확한 진술

주어진 부등식을 만족하는 **정수**가 몇 개 존재하는지 세는 것을 **정수의 개수**라고 합니다. 예를 들어 $-2 < x < 3$을 만족하는 정수는 $-1, 0, 1, 2$로 총 4개입니다.

일반적으로 $a < x < b$ 형태의 부등식에서:
- 경계값이 정수가 아닌 경우, 정수의 개수는 $\lfloor b \rfloor - \lceil a \rceil + 1$
- 경계값이 정수인 경우는 경계 포함 여부(< 또는 $\leq$)에 따라 조정

## 직관 및 기하적 의미

수직선 위에서 부등식을 만족하는 구간을 생각해 보세요. 그 구간 **안에** 몇 개의 정수점이 있는가를 묻는 것입니다. 이는 이산수학과 확률 문제에서 경우의 수를 세거나, 실생활의 "개수" 문제(개를 몇 마리 살 수 있는가, 학생을 몇 명 뽑을 수 있는가)에 직결됩니다.

## 구체적인 예

**예 1:** $-3.5 < x \leq 2.7$을 만족하는 정수는?
- 수직선에 표시하면: $-3, -2, -1, 0, 1, 2$ (총 6개)
- 규칙: 왼쪽 경계 $-3.5$보다 큰 첫 정수는 $-3$, 오른쪽 경계 $2.7$ 이하 최대 정수는 $2$
- 따라서 $-3$부터 $2$까지, 개수 = $2 - (-3) + 1 = 6$

**예 2:** $2x + 1 < 9$를 만족하는 음이 아닌 정수는?
- 정리하면: $2x < 8$ → $x < 4$
- 음이 아닌 정수: $0, 1, 2, 3$ (총 4개)

부등식을 먼저 정리한 후, 구간을 명확히 파악하는 것이 핵심입니다.
