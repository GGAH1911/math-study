# 실생활 응용 부등식

> **예제** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
돈·인원수 모델링

## 본문 (학습 시 채워짐)

### 문제
학교에서 수학 여행을 준비하고 있습니다. 버스를 하루 동안 빌리는 데 500,000원이 들고, 학생 한 명당 입장료와 식사비로 50,000원이 필요합니다. 총 예산이 3,000,000원을 넘지 않을 때, 최대 몇 명의 학생이 참가할 수 있을까요?

### 단계별 풀이

**1단계: 상황을 식으로 나타내기**  
학생 수를 $x$명이라고 합니다. 전체 비용은 버스비와 학생 비용의 합이므로:
$$\text{전체 비용} = 500000 + 50000x \text{ (원)}$$

예산 조건을 부등식으로 나타내면:
$$500000 + 50000x \leq 3000000$$

**2단계: 부등식 풀기**  
양변에서 500,000을 뺍니다:
$$50000x \leq 2500000$$

양변을 50,000으로 나누어 $x$를 구합니다:
$$x \leq 50$$

**3단계: 해 해석하기**  
$x \leq 50$이므로 학생은 최대 50명까지 참가 가능합니다. 검산하면: $500000 + 50000 \times 50 = 3000000$원으로 정확히 예산과 맞습니다.

### 답
최대 **50명**

### 변형 및 주의
- 인원수는 항상 자연수(0보다 큰 정수)이므로, 계산 결과가 정수면 그대로 답입니다.
- 만약 버스 대여비가 600,000원으로 올랐다면? $600000 + 50000x \leq 3000000$에서 $x \leq 48$이 되어 참가 학생 수도 줄어듭니다.
- 버스의 정원이 정해져 있다면(예: 45명), 부등식의 해 50명보다 버스 정원이 더 작으므로, 실제 최댓값은 45명이 됩니다.
