# 실생활 응용 부등식

> **예제** · 중2 · 단원: [일차부등식](/concepts/일차부등식)

## 요약
실생활의 비용이나 인원수 제한 조건을 일차부등식으로 모델링하여 최댓값이나 최솟값을 구하는 방법입니다.

## 본문
학교에서 수학 여행을 준비하고 있습니다. 버스를 하루 동안 빌리는 데 500,000원이 들고, 학생 한 명당 입장료와 식사비로 50,000원이 필요합니다. 총 예산이 3,000,000원을 넘지 않을 때, 최대 몇 명의 학생이 참가할 수 있을까요?

### 단계별 풀이
**1단계: 상황을 식으로 나타내기**
학생 수를 $x$명이라고 하면 전체 비용은 버스비와 학생 1인당 비용의 합인 $500000 + 50000x$원입니다. 예산 조건인 3,000,000원을 넘지 않아야 하므로 부등식은 $500000 + 50000x \leq 3000000$이 됩니다.

**2단계: 부등식 풀기**
양변에서 500,000을 빼면 $50000x \leq 2500000$이 됩니다. 양변을 50,000으로 나누면 $x \leq 50$이라는 결과를 얻습니다.

**3단계: 해 해석하기**
계산 결과 $x \leq 50$이므로 학생은 최대 50명까지 참가할 수 있습니다. 실제로 50명이 참가할 때 비용은 $500000 + 50000 \times 50 = 3000000$원이 되어 예산 범위 내에 들어옵니다.

### 답과 변형
최대 **50명**

실생활 문제에서는 다음과 같은 상황을 주의해야 합니다. 첫째, 인원수는 항상 자연수여야 하므로 계산 결과가 정수가 아닐 경우 조건에 맞는 정수를 찾아야 합니다. 둘째, 버스 대여비가 600,000원으로 인상되면 $x \leq 48$이 되어 참가 인원이 줄어듭니다. 셋째, 만약 버스 정원이 45명으로 제한되어 있다면 부등식의 해인 50명보다 정원이 작으므로 실제 참가 가능한 최대 인원은 45명이 됩니다.

## 학습 체크
- 문제에서 구하고자 하는 미지수를 설정하고 조건에 맞는 부등식을 세울 수 있는가?
- 부등식을 풀 때 계산 결과가 실생활의 조건(자연수 여부 등)과 일치하는지 확인했는가?
- 버스 정원과 같은 추가적인 제한 조건이 있을 때 해를 어떻게 해석해야 하는지 이해하고 있는가?

## 관련 개념
- **일차부등식**: 미지수의 차수가 1인 부등식으로, 실생활의 제한 조건을 수학적 식으로 변환하여 해결하는 기초가 됩니다.
