# 평면과의 교점

## 요약
공간에서 직선과 평면이 만나는 점을 평면과의 교점이라 하며, 직선의 매개변수 표현을 평면의 방정식에 대입하여 구할 수 있다.

## 본문
공간에서 직선(또는 선분)과 평면이 만나는 점을 **평면과의 교점**이라 한다. 직선의 방향벡터 $\vec{d}$와 평면의 법벡터 $\vec{n}$이 수직이 아닌 경우($\vec{d} \cdot \vec{n} \neq 0$), 직선과 평면은 오직 한 점에서 만난다. 직선을 매개변수 $t$로 표현한 후 평면의 방정식에 대입하여 $t$ 값을 구함으로써 교점의 좌표를 얻는다. 수능에서는 주로 공간도형에서 모서리(선분)의 연장과 단면(평면)의 교점을 구하거나, 좌표공간에서 직선과 평면의 방정식을 연립하여 교점을 구하는 문제가 출제된다.

### 직관과 기하적 의미
직선이 평면을 뚫고 지나가는 상황을 상상할 수 있다. 만약 직선이 평면과 평행하다면 교점은 존재하지 않으며, 직선이 평면 속에 포함되어 있다면 교점은 직선 위의 모든 점이 된다. 즉, 방향벡터와 법벡터가 수직인 특수한 경우를 제외하면 직선은 평면과 단 하나의 점에서만 만나게 된다.

### 기본 성질
직선이 점 $(1, 2, 3)$을 지나고 방향벡터 $\vec{d} = (1, -1, 2)$이며, 평면의 방정식이 $2x + y - z = 4$일 때의 계산 과정은 다음과 같다.
1. 직선의 매개변수 표현: $(x, y, z) = (1 + t,\; 2 - t,\; 3 + 2t)$
2. 평면의 방정식에 대입: $2(1+t) + (2-t) - (3+2t) = 4$
3. 식 정리: $2 + 2t + 2 - t - 3 - 2t = 4 \implies 1 - t = 4 \implies t = -3$
4. 교점의 좌표: $(1-3,\; 2+3,\; 3-6) = (-2, 5, -3)$

## 학습 체크
- 직선의 방향벡터와 평면의 법벡터가 수직일 때, 교점의 개수는 어떻게 변하는가?
- 직선의 매개변수 $t$를 구한 후, 이를 다시 직선의 방정식에 대입하여 좌표를 찾는 과정을 숙지하고 있는가?
- 공간도형 문제에서 선분의 연장선이 평면과 만나는 점을 구할 때, 선분의 범위 내에 있는지 확인하는 절차를 알고 있는가?
