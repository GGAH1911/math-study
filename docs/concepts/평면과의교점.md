# 평면과의 교점

## 정의

공간에서 직선(또는 선분)과 평면이 만나는 점을 **평면과의 교점**이라 한다. 직선의 방향벡터 $\vec{d}$와 평면의 법벡터 $\vec{n}$이 수직이 아닌 경우($\vec{d} \cdot \vec{n} \neq 0$), 직선과 평면은 오직 한 점에서 만난다. 직선을 매개변수 $t$로 표현한 후 평면의 방정식에 대입하여 $t$ 값을 구함으로써 교점의 좌표를 얻는다. 수능에서는 주로 공간도형에서 모서리(선분)의 연장과 단면(평면)의 교점을 구하거나, 좌표공간에서 직선과 평면의 방정식을 연립하여 교점을 구하는 문제가 출제된다.

## 예시

직선이 점 $(1, 2, 3)$을 지나고 방향벡터 $\vec{d} = (1, -1, 2)$이며, 평면의 방정식이 $2x + y - z = 4$일 때:

직선의 매개변수 표현: $(x, y, z) = (1 + t,\; 2 - t,\; 3 + 2t)$

평면에 대입:

$$2(1+t) + (2-t) - (3+2t) = 4$$
$$2 + 2t + 2 - t - 3 - 2t = 4 \implies 1 - t = 4 \implies t = -3$$

교점: $(1-3,\; 2+3,\; 3-6) = (-2, 5, -3)$
