### 정확한 진술

영역의 넓이 비율은 두 개 이상의 영역이 이루는 넓이를 상대적으로 비교하는 값입니다. 곡선으로 둘러싸인 영역 $A$와 $B$의 넓이를 각각 $S_A$, $S_B$라 하면, 넓이의 비율은 $\dfrac{S_A}{S_B}$ 또는 $S_A : S_B$로 나타냅니다. 정적분을 이용하여 계산하며, 보통 한 직선이 두 곡선을 나누거나 두 곡선이 만나는 점을 기준으로 영역을 구분합니다.

### 직관과 기하적 의미

두 곡선 $y=f(x)$와 $y=g(x)$ ($f(x) \geq g(x)$)가 $x=a$, $x=b$에서 만날 때, 사이 영역의 넓이는 $\displaystyle\int_a^b \{f(x)-g(x)\} \, dx$입니다. 만약 직선이 이 영역을 두 부분으로 나누면, 각 부분의 넓이를 구한 후 비율을 계산합니다. 넓이의 비율은 "한 도형이 다른 도형의 몇 배인가" 또는 "전체 넓이를 몇 대 몇으로 나누는가"를 직관적으로 보여줍니다.

예를 들어, 포물선과 직선 사이의 영역을 수직선이 나눌 때, 왼쪽 부분과 오른쪽 부분의 넓이 비가 $1:2$라면, 오른쪽이 왼쪽의 2배 크다는 뜻입니다.

### 한 줄 예

$y=x^2$, $y=2x$ ($0 \leq x \leq 2$)로 둘러싸인 영역을 직선 $x=1$이 나눌 때, 왼쪽 부분과 오른쪽 부분의 넓이 비를 구하세요.

왼쪽: $\displaystyle\int_0^1 (2x-x^2) \, dx = \left[x^2 - \frac{x^3}{3}\right]_0^1 = \frac{2}{3}$

오른쪽: $\displaystyle\int_1^2 (2x-x^2) \, dx = \left[x^2 - \frac{x^3}{3}\right]_1^2 = \left(4-\frac{8}{3}\right) - \left(1-\frac{1}{3}\right) = \frac{2}{3}$

따라서 넓이의 비는 $\dfrac{2}{3} : \dfrac{2}{3} = 1:1$입니다.

(`sympy.integrate(2*x - x**2, (x, 0, 1))`, `sympy.integrate(2*x - x**2, (x, 1, 2))`)
