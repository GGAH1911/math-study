# 삼각함수 항등식

## 요약
삼각함수 사이의 관계를 나타내는 등식으로, 피타고라스 정리와 단위원의 성질을 바탕으로 다양한 삼각함수의 값을 유도하는 데 사용됩니다.

## 본문
삼각함수 항등식은 모든 실수 $x$에 대하여 항상 성립하는 삼각함수 사이의 관계식을 의미합니다. 가장 대표적인 형태는 피타고라스 항등식인 $\sin^2 x + \cos^2 x = 1$이며, 이는 단위원 위의 점 $(x, y)$에 대하여 $x = \cos \theta$, $y = \sin \theta$라는 관계에서 유도됩니다. 이 식의 양변을 $\cos^2 x$로 나누면 $\tan^2 x + 1 = \sec^2 x$를 얻을 수 있고, 양변을 $\sin^2 x$로 나누면 $1 + \cot^2 x = \csc^2 x$를 얻을 수 있습니다. 이러한 항등식들은 복잡한 삼각함수 식을 단순화하거나, 한 종류의 삼각함수 값만 주어졌을 때 다른 종류의 값을 결정하는 데 필수적인 도구가 됩니다.

### 직관과 기하적 의미
단위원 위를 움직이는 점의 좌표를 통해 이해할 수 있습니다. 반지름이 $1$인 원 위에서 각 $\theta$에 해당하는 점의 $x$좌표는 $\cos \theta$, $y$좌표는 $\sin \theta$이므로, 원의 방정식 $x^2 + y^2 = 1$에 의해 $\sin^2 \theta + \cos^2 \theta = 1$이 성립합니다. 이는 기하학적으로 삼각형의 높이와 밑변의 제곱의 합이 빗변의 제곱과 같다는 피타고라스 정리의 확장된 형태입니다.

### 기본 성질
모든 실수 범위에서 성립하는 항등식은 함수의 그래프를 변형하거나 미적분을 수행할 때 식을 간결하게 만들어줍니다. 특히 $\tan x$나 $\sec x$가 정의되지 않는 지점에서는 주의가 필요하며, 항등식을 이용해 차수를 낮추거나 함수를 변환함으로써 복잡한 삼각함수 방정식을 쉽게 풀 수 있습니다.

## 학습 체크
- $\sin x$의 값만 알 때 $\cos x$의 값을 구하는 과정에서 부호 결정 시 주의할 점은 무엇인가?
- $\tan^2 x + 1 = \sec^2 x$ 식을 활용하여 $\sec x$를 $\tan x$로 표현할 때의 조건은 무엇인가?

## 관련 개념
- **삼각함수**: 항등식은 삼각함수의 성질을 정의하고 함수 간의 유기적인 관계를 설명하는 기초가 됩니다.
- **피타고라스 정리**: 직각삼각형의 변의 길이 사이의 관계가 삼각함수 항등식의 근본적인 기하학적 토대를 이룹니다.
- **단위원**: 좌표평면 위의 반지름이 $1$인 원은 삼각함수의 정의와 항등식을 시각적으로 증명하는 도구가 됩니다.
