# 삼각비

> **단원** · 중3 · 선수: [닮음과 피타고라스](/concepts/닮음과_피타고라스) · 다음: [삼각함수](/concepts/삼각함수)

## 학습 목표
- 직각삼각형에서 $\sin/\cos/\tan$의 정의를 이해한다
- 특수각($30°, 45°, 60°$)의 삼각비를 외운다
- 삼각비를 이용해 변의 길이/각을 구한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- $\sin\theta, \cos\theta, \tan\theta$ (직각삼각형 정의)

**정리(theorem)**
- 특수각 표
- 피타고라스 정리와의 관계 $\sin^2+\cos^2=1$ (직관)

**예제(example)**
- 특수각 활용 변 구하기
- 실생활(높이·거리) 측정
