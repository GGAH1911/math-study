# 복소수

> **정의** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
$a+bi$ ($i^2=-1$)

## 본문 (학습 시 채워짐)

### 정확한 진술
복소수는 $a+bi$ (단, $a, b$는 실수, $i$는 허수 단위) 형태의 수입니다. 허수 단위 $i$는 $i^2 = -1$을 만족합니다. 복소수 $z = a+bi$에서 $a$를 **실부(real part)**, $b$를 **허부(imaginary part)**라고 부르며, 기호로 $\text{Re}(z) = a$, $\text{Im}(z) = b$로 나타냅니다.

### 직관적 의미와 필요성
실수만으로는 $x^2 + 1 = 0$처럼 해가 없는 방정식들이 존재합니다. 복소수는 이 '불가능'을 극복합니다—위 방정식의 해는 $x = \pm i$입니다. 더 근본적으로, **모든 다항식이 복소수 범위에서 완전히 인수분해됩니다**(대수학의 기본정리). 기하학적으로 복소수는 **복소평면** 위의 점 $(a, b)$에 대응되며, 가로축은 실수축, 세로축은 허수축입니다. 따라서 복소수는 2차원적 정보를 담는 '수'로 확장된 개념입니다.

### 기본 성질과 예시
- $3+2i$: 실부 3, 허부 2
- $-5$: 실부 −5, 허부 0 (실수도 복소수)
- $4i$: 실부 0, 허부 4 (순허수)
- $i$의 거듭제곱: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$, $i^5 = i$ (주기 4)

두 복소수는 실부와 허부가 각각 같을 때만 같습니다. 즉, $a+bi = c+di$ ⟺ $a=c$ 이고 $b=d$ 입니다.
