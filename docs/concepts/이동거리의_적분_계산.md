### 정확한 진술

시간 구간 $[a, b]$에서 속도가 $v(t)$인 물체의 **이동거리**는 다음과 같이 정의합니다:

$$\text{이동거리} = \int_a^b |v(t)| \, dt$$

여기서 $|v(t)|$는 속력(speed)입니다. 속도의 절댓값을 취하므로, 물체가 앞으로 움직이든 뒤로 움직이든 모든 거리를 양수로 합산합니다.

### 직관과 기하적 의미

변위(displacement)와 혼동하기 쉬운데, 둘은 다릅니다:
- **변위**: $\int_a^b v(t) \, dt$ — 시작점에서 끝점까지의 방향이 있는 거리 (음수 가능)
- **이동거리**: $\int_a^b |v(t)| \, dt$ — 실제로 이동한 총 경로의 길이 (항상 음이 아닌 수)

속도가 부호를 바꾸는 구간이 있으면, 그 지점을 기준으로 적분을 나누어 절댓값을 적용합니다. 예를 들어, $v(t) = 0$인 점이 $t = c$ (단, $a < c < b$)이면:

$$\int_a^b |v(t)| \, dt = \int_a^c |v(t)| \, dt + \int_c^b |v(t)| \, dt = -\int_a^c v(t) \, dt + \int_c^b v(t) \, dt$$

(첫 번째 구간에서 $v(t) < 0$이라 가정)

이렇게 계산하면 "뒤로 간 거리"도 양수로 누적되어 실제 이동거리를 얻습니다.

### 한 줄 예

$v(t) = t - 1$ (초당 미터, $0 \le t \le 2$)일 때, $t = 1$에서 속도가 0이 되므로:
$$\text{이동거리} = \int_0^1 (1-t) \, dt + \int_1^2 (t-1) \, dt = \frac{1}{2} + \frac{1}{2} = 1 \text{ (m)}$$

(`sympy.integrate(sympy.Abs(t-1), (t, 0, 2))` → 1.0)
