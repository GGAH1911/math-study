# 무리수

> **정의** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
유리수가 아닌 실수

## 본문 (학습 시 채워짐)

### 정의

무리수는 분수 $\frac{p}{q}$ (단, $p, q$는 정수, $q \neq 0$) 형태로 나타낼 수 없는 실수입니다. 다시 말해, 유리수가 아닌 모든 실수를 무리수라고 합니다.

### 소수 표현의 특징

유리수는 항상 소수로 나타낼 때 유한소수이거나 순환소수가 되는 반면, 무리수는 **비순환무한소수**로 나타납니다. 예를 들어 $\frac{1}{3} = 0.\overline{3} = 0.333\ldots$는 3이 계속 반복되므로 순환소수이고 유리수이지만, $\sqrt{2} = 1.41421356\ldots$는 어떤 패턴이 반복되지 않으므로 무리수입니다.

### 대표적인 무리수 예시

수학에서 자주 다루는 무리수는 제곱근 형태입니다. $\sqrt{2}, \sqrt{3}, \sqrt{5}$ 등 완전제곱수가 아닌 자연수의 제곱근은 모두 무리수입니다. 또한 원의 넓이와 둘레의 관계를 나타내는 $\pi$도 대표적인 무리수입니다.

**중요한 성질**: $\sqrt{4} = 2$는 정수이므로 유리수이지만, $\sqrt{2}$는 무리수라는 점에 주의해야 합니다. 완전제곱수의 제곱근만 유리수가 되고, 나머지는 무리수입니다.

```python
# sympy.sqrt(2) 계산
import sympy
sympy.sqrt(2)  # sqrt(2): 무리수임을 명시적으로 표현
float(sympy.sqrt(2))  # 1.4142135623730951
```
