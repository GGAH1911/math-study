### 정확한 진술

두 집합 $X$, $Y$가 있을 때, $X$의 각 원소 $x$에 대해 $Y$의 원소 $y$가 **정확히 하나** 대응되는 규칙을 **$X$에서 $Y$로의 함수**라고 합니다. 이를 $f : X \to Y$로 나타내고, $x$에 대응되는 $y$를 $f(x)$로 표기합니다. 여기서 $X$를 정의역(domain), $Y$를 치역(codomain)이라 부릅니다.

"정확히 하나"라는 조건이 핵심입니다. 정의역의 모든 원소가 빠짐없이 대응되어야 하고, 하나의 $x$가 여러 개의 $y$로 대응될 수 없습니다.

### 직관/기하적 의미

함수는 **입력과 출력의 관계**를 나타냅니다. 정의역의 각 입력 $x$를 기계에 넣으면 반드시 하나의 출력 $f(x)$가 나온다는 뜻입니다. 예를 들어, 온도계에 특정 물체를 대면 정확히 하나의 온도값이 나오는 것처럼, 함수도 같은 입력에는 항상 같은 출력을 줍니다.

좌표평면에서는 함수의 그래프로 시각화합니다. $y = f(x)$의 그래프는 점 $(x, f(x))$들의 모임이므로, "연직선 검사법(vertical line test)"으로 확인할 수 있습니다. 임의의 수직선이 그래프와 **최대 한 번**만 만나면 함수입니다.

### 한 줄 예

$f(x) = 2x + 1$은 정의역이 모든 실수인 함수이며, 입력 $x = 3$에 대해 정확히 $f(3) = 7$이 출력됩니다.

```python
# sympy로 함숫값 계산 예
f = lambda x: 2*x + 1
print(f(3))  # 출력: 7
```
