### 정확한 진술

전체 경우의 수 중에서 **특정한 조건을 만족하는 경우만 따로 세는 것**을 "조건을 만족하는 경우의 수"라고 합니다. 주어진 문제에서 가능한 모든 결과의 집합을 $U$라 할 때, 어떤 조건 $P$가 있으면, 조건 $P$를 만족하는 경우의 수는 다음과 같이 표현됩니다:

$$\text{(조건 P를 만족하는 경우의 수)} = |\{x \in U \mid P(x) \text{가 참}\}|$$

예를 들어 "1부터 10까지의 자연수 중 **짝수인 경우의 수**"라면, 조건은 "$2$로 나누어떨어진다"이고, 이를 만족하는 원소는 $2, 4, 6, 8, 10$이므로 경우의 수는 $5$입니다.

### 직관/기하적 의미

조건을 만족하는 경우의 수는 **전체에서 필요한 부분만 필터링하는 과정**입니다. 마치 큰 바구니(전체 경우)에서 원하는 색깔의 공(조건을 만족하는 경우)만 꺼내는 것처럼 생각할 수 있습니다.

이를 구하는 방법은 두 가지입니다:
- **직접 세기**: 조건을 만족하는 경우를 하나씩 나열하고 개수를 센다.
- **여사건 이용**: 전체 경우의 수에서 조건을 **만족하지 않는** 경우의 수를 빼기 $\rightarrow$ 때로 더 쉬울 수 있습니다.

예를 들어 "1부터 100까지의 자연수 중 3의 배수가 아닌 경우의 수"는 $(100) - (3\text{의 배수 개수})$로 계산하는 것이 직접 세기보다 간편합니다.

### 한 줄 예

**1부터 20까지의 자연수 중 5의 배수인 경우의 수**: 조건은 "$5$로 나누어떨어진다"이고, 이를 만족하는 수는 $5, 10, 15, 20$이므로 **경우의 수는 4입니다**. (검증: `len([x for x in range(1, 21) if x % 5 == 0])`)
