### 정확한 진술

삼각함수의 방정식은 미지수 $x$를 포함하는 삼각함수 식을 등호로 놓은 식입니다. 예를 들어 $\sin x = a$, $\cos x = b$, $\tan x = c$ 같은 형태이며, 여기서 $a$, $b$, $c$는 주어진 상수입니다. 삼각함수 방정식을 푼다는 것은 조건을 만족하는 모든 $x$ 값(각도 또는 호도각)을 찾는 것입니다.

### 직관/기하적 의미

단위원 위에서 생각하면 의미가 명확합니다. $\sin x = \frac{1}{2}$라는 방정식은 "단위원 위에서 $y$ 좌표가 $\frac{1}{2}$인 점들에 대응되는 각도는 무엇인가?"라는 질문입니다. 

삼각함수는 주기함수이므로, 일반적으로 무한히 많은 해를 갖습니다. $\sin$과 $\cos$는 주기가 $2\pi$이고, $\tan$는 주기가 $\pi$이므로, 해를 구할 때는 이 주기성을 반영하여 **일반해**로 표현합니다. 예를 들어 $\sin x = \frac{\sqrt{3}}{2}$의 해는 $x = \frac{\pi}{3} + 2\pi n$ 또는 $x = \frac{2\pi}{3} + 2\pi n$ (단, $n$은 정수)입니다. 이는 $[0, 2\pi)$ 구간에서의 특수해 $\frac{\pi}{3}$, $\frac{2\pi}{3}$에 $2\pi n$을 더한 것입니다.

### 한 줄 예

$\cos x = \frac{1}{2}$를 풀면: $x = \pm\frac{\pi}{3} + 2\pi n$ (단, $n$은 정수)
