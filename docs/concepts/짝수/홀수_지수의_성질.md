# 홀수 지수의 성질

자연수 $n$이 홀수일 때, 임의의 실수 $a$에 대해 $x^n = a$를 만족하는 실수 $x$는 정확히 하나 존재한다. 이 $x$를 $a$의 $n$제곱근, 즉 $\sqrt[n]{a}$로 나타낸다.

홀수 지수의 가장 중요한 성질은 **부호가 보존된다**는 점이다. $n$이 홀수인 자연수이면, 임의의 실수 $a$에 대해

$$\sqrt[n]{a^n} = a$$

가 성립한다. 음수를 홀수 번 곱하면 결과도 음수이기 때문에, $a$가 음수여도 $n$제곱근이 실수 범위 안에서 유일하게 정해진다. 이는 $n$이 짝수일 때 $\sqrt[n]{a^n} = |a|$가 되는 것과 대비된다.

## 예시

**$n = 3$인 경우.**

$a = -2$이면 $(-2)^3 = -8$이므로

$$\sqrt[3]{(-2)^3} = \sqrt[3]{-8} = -2$$

절댓값이 붙지 않고 원래 값 $-2$가 그대로 나온다.

**식 정리에 적용.**

$\sqrt[5]{(-3)^5}$을 계산하면, $5$는 홀수이므로

$$\sqrt[5]{(-3)^5} = -3$$

만약 $5$ 대신 짝수 지수였다면 $|-3| = 3$이 되었겠지만, 홀수 지수이므로 부호가 살아남는다.

## 관련 개념

**지수와 로그** 단원 전반에서 선수 개념으로 작용한다. 거듭제곱근을 정의하고 계산하는 모든 상황에서 지수가 홀수인지 짝수인지 먼저 확인해야 한다.

- **짝수 지수의 성질**과 쌍을 이룬다. $n$이 짝수이면 $\sqrt[n]{a^n} = |a|$이고, $a < 0$이면 실수 범위에서 $\sqrt[n]{a}$ 자체가 정의되지 않는다. 두 성질을 함께 익혀야 혼동 없이 쓸 수 있다.
- **거듭제곱근의 정의**와 직결된다. $n$제곱근이 실수에서 유일하게 존재할 조건이 바로 홀수 지수의 성질에서 나온다.
- **지수법칙**으로 연결된다. $\left(a^m\right)^{\frac{1}{n}} = a^{\frac{m}{n}}$ 형태로 지수를 유리수로 확장할 때, $n$이 홀수이면 $a < 0$인 경우에도 식이 의미를 가지므로 정의역이 넓어진다.
