# 홀수 지수의 성질

## 요약
$n$이 홀수인 자연수일 때, $\sqrt[n]{a^n} = a$가 성립하며 이는 부호가 보존됨을 의미한다.

## 본문
자연수 $n$이 홀수일 때, 임의의 실수 $a$에 대하여 $x^n = a$를 만족하는 실수 $x$는 정확히 하나 존재한다. 이 $x$를 $a$의 $n$제곱근이라 하며 $\sqrt[n]{a}$로 나타낸다.

### 직관과 기하적 의미
홀수 지수의 가장 핵심적인 특징은 부호가 보존된다는 점이다. 음수를 홀수 번 곱하면 결과도 항상 음수가 되기 때문에, $a$가 음수일지라도 $n$제곱근은 실수 범위 내에서 유일하게 결정된다. 이는 $n$이 짝수일 때 $\sqrt[n]{a^n} = |a|$가 되어 결과가 항상 양수(또는 0)로 나오는 것과 명확히 대비되는 성질이다.

### 기본 성질
$n$이 홀수인 자연수라면 임의의 실수 $a$에 대하여 다음 식이 성립한다.
$$\sqrt[n]{a^n} = a$$
예를 들어 $n=3$이고 $a=-2$인 경우, $(-2)^3 = -8$이므로 $\sqrt[3]{-8} = -2$가 된다. 즉, 홀수 지수에서는 절댓값 기호가 붙지 않고 원래의 부호가 그대로 유지된다. 만약 $\sqrt[5]{(-3)^5}$을 계산한다면, 지수가 홀수이므로 결과는 $-3$이 된다.

## 학습 체크
- $n$이 홀수일 때 $\sqrt[n]{a^n}$의 결과가 $a$의 부호를 어떻게 유지하는가?
- $n$이 짝수일 때의 성질($\sqrt[n]{a^n} = |a|$)과 비교하여 홀수 지수만의 차이점은 무엇인가?

## 관련 개념

**지수와 로그** 단원 전반에서 선수 개념으로 작용한다. 거듭제곱근을 정의하고 계산하는 모든 상황에서 지수가 홀수인지 짝수인지 먼저 확인해야 한다.

- **짝수 지수의 성질**과 쌍을 이룬다. $n$이 짝수이면 $\sqrt[n]{a^n} = |a|$이고, $a < 0$이면 실수 범위에서 $\sqrt[n]{a}$ 자체가 정의되지 않는다. 두 성질을 함께 익혀야 혼동 없이 쓸 수 있다.
- **거듭제곱근의 정의**와 직결된다. $n$제곱근이 실수에서 유일하게 존재할 조건이 바로 홀수 지수의 성질에서 나온다.
- **지수법칙**으로 연결된다. $\left(a^m\right)^{\frac{1}{n}} = a^{\frac{m}{n}}$ 형태로 지수를 유리수로 확장할 때, $n$이 홀수이면 $a < 0$인 경우에도 식이 의미를 가지므로 정의역이 넓어진다.
