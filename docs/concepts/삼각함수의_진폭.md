### 정확한 진술

삼각함수의 **진폭(amplitude)**은 삼각함수 그래프가 중앙값으로부터 얼마나 위아래로 진동하는지를 나타내는 수치입니다. 함수 $y = A\sin(Bx + C) + D$ 또는 $y = A\cos(Bx + C) + D$에서 진폭은 $|A|$입니다. 함수의 최댓값은 $D + |A|$이고 최솟값은 $D - |A|$이므로, 진폭은 다음과 같이도 표현됩니다.

$$\text{진폭} = \frac{\text{최댓값} - \text{최솟값}}{2} = |A|$$

### 직관적·기하적 의미

기본 함수 $y = \sin x$의 진폭은 1입니다. 계수 $A$는 그래프의 '높이'를 결정합니다. $y = 2\sin x$이면 모든 함숫값이 2배로 확대되어 진폭이 2가 되고, 그래프가 위아래로 더 크게 진동합니다. 반대로 $y = 0.5\sin x$는 진폭이 0.5로 줄어들어 더 완만하게 진동합니다. 

$A$가 음수인 경우, 예를 들어 $y = -3\cos x$는 진폭이 $|-3| = 3$이며, 그래프가 위아래로 뒤집혀 있을 뿐 진동의 폭 자체는 같습니다. 중요한 점은 상수항 $D$ (그래프의 연직 평행이동)는 진폭에 영향을 주지 않는다는 것입니다.

### 구체적 예

$y = 3\sin x + 2$의 경우:
- 진폭: $|3| = 3$
- 최댓값: $2 + 3 = 5$
- 최솟값: $2 - 3 = -1$

$y = -\frac{1}{2}\cos(2x) - 1$의 경우:
- 진폭: $\left|-\frac{1}{2}\right| = \frac{1}{2}$
- 최댓값과 최솟값의 범위: $[-1.5, -0.5]$
