# 수심

## 정의

삼각형의 수심(垂心, orthocenter)은 삼각형의 세 꼭짓점에서 각각의 대변에 내린 수선(垂線)이 한 점에서 만나는 점이다. 삼각형 ABC에서 꼭짓점 A에서 BC에 내린 수선의 발을 H_A, B에서 CA에 내린 수선의 발을 H_B, C에서 AB에 내린 수선의 발을 H_C라 하면, 세 수선 AH_A, BH_B, CH_C는 한 점 H에서 만난다. 이 점 H를 삼각형 ABC의 수심이라 한다. 예각삼각형에서는 수심이 삼각형 내부에, 직각삼각형에서는 직각 꼭짓점에, 둔각삼각형에서는 삼각형 외부에 위치한다.

## 예시

직각삼각형 ABC에서 $\angle C = 90°$일 때 수심을 구한다.

꼭짓점 C에서 빗변 AB에 수선을 내리면 발이 삼각형 내부에 놓인다. 그러나 꼭짓점 A에서 대변 BC에 내린 수선은 BC 자체가 $\angle C = 90°$이므로 꼭짓점 C를 지나고, B에서 AC에 내린 수선도 C를 지난다. 따라서 세 수선이 만나는 점, 즉 수심은 꼭짓점 C 자신이다.
