### 정확한 진술

함수 $f: X \to X$에 대해, **반복적 함수 적용**(또는 **함수의 반복 합성**)은 함수를 자신과 계속 합성하는 것입니다. $n$번 반복 적용한 함수를 $f^{(n)}$으로 나타내면:

$$f^{(1)} = f, \quad f^{(2)} = f \circ f, \quad f^{(n)} = \underbrace{f \circ f \circ \cdots \circ f}_{n\text{번}}$$

초기값 $x_0$에서 시작하여 다음과 같이 정의된 수열을 **$f$의 궤도** 또는 **반복 수열**이라 합니다:

$$x_n = f(x_{n-1}) = f^{(n)}(x_0)$$

### 직관 및 기하적 의미

'같은 규칙을 계속 반복해서 적용한다'는 뜻입니다. 고등학교에서 배우는 점화식 $a_{n+1} = f(a_n)$이 바로 이 개념의 구체적 형태입니다.

현실에서는 매우 흔합니다: 매년 일정 비율로 증가하는 인구, 복리 이자 계산, 수치 해석에서 반복 계산으로 어떤 값에 수렴시키기 등. 반복 과정에서 수열이 어떻게 행동하는지—수렴하는지, 발산하는지, 주기적으로 진동하는지—를 분석하는 것은 수열 단원과 미적분의 중요한 주제입니다. 또한 동적 시스템 이론의 출발점입니다.

### 한 줄 예

$f(x) = 2x + 1$, $x_0 = 1$이면: $x_1 = 3, x_2 = 7, x_3 = 15, x_4 = 31, \ldots$
