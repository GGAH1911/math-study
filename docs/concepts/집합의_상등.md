# 집합의 상등

두 집합 $A$와 $B$가 **서로 같다**는 것은, $A$의 모든 원소가 $B$에 속하고 동시에 $B$의 모든 원소가 $A$에 속할 때를 말한다. 이를 $A = B$로 나타낸다.

바꿔 말하면, $A \subseteq B$이고 $B \subseteq A$이면 $A = B$이다. 집합은 원소의 **종류**만으로 결정되므로, 원소를 나열하는 순서나 같은 원소를 반복해서 쓰는 것은 상등 여부에 아무런 영향을 주지 않는다.

## 예시

$A = \{1, 2, 3\}$, $B = \{3, 1, 2\}$이면 두 집합의 원소가 완전히 일치하므로 $A = B$이다. 나열 순서가 달라도 집합으로서는 같다.

$C = \{x \mid x^2 - 3x + 2 = 0\}$, $D = \{1, 2\}$이면, $x^2 - 3x + 2 = (x-1)(x-2) = 0$의 해가 $x = 1$ 또는 $x = 2$이므로 $C = \{1, 2\}$가 되어 $C = D$이다. 조건제시법으로 정의된 집합도 원소만 같으면 상등이다.

## 관련 개념

**집합**은 상등의 기반이 되는 개념이다. 두 집합이 같다는 것을 판단하려면 먼저 각 집합의 원소가 무엇인지 정확히 파악해야 한다.

**부분집합**과는 뗄 수 없는 관계다. $A = B$임을 직접 보이기 어려울 때는 $A \subseteq B$와 $B \subseteq A$를 각각 증명하는 방법을 자주 사용한다. 이 방법은 명제 증명에서도 핵심적으로 쓰인다.

**원소**의 개수가 같다고 해서 반드시 상등인 것은 아니다. $\{1, 2\}$와 $\{1, 3\}$은 원소의 개수가 같지만 $2 \neq 3$이므로 두 집합은 다르다. 원소의 개수가 같은 것과 집합이 같은 것을 혼동하지 않도록 주의해야 한다.
