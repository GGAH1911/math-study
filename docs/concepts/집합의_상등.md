# 집합의 상등

## 요약
두 집합의 모든 원소가 서로 일치할 때, 즉 서로가 서로의 부분집합일 때 두 집합은 상등한다고 한다.

## 본문
두 집합 $A$와 $B$가 서로 같다는 것은 $A$의 모든 원소가 $B$에 속하고 동시에 $B$의 모든 원소가 $A$에 속할 때를 말하며, 이를 $A = B$로 나타낸다. 이는 $A \subseteq B$이고 $B \subseteq A$이면 $A = B$라는 조건과 논리적으로 동일하다. 집합은 원소의 종류에 의해서만 결정되므로, 원소를 나열하는 순서가 다르거나 같은 원소를 중복해서 적더라도 포함된 원소의 구성이 같다면 두 집합은 상등한다.

### 직관과 기하적 의미
집합을 하나의 주머니라고 생각할 때, 두 주머니 안에 들어있는 물건의 종류가 완벽하게 일치한다면 두 주머니는 같은 것으로 간주한다. 물건을 어떤 순서로 꺼내는지, 혹은 같은 물건을 두 번 넣었는지는 주머니의 정체성을 결정하는 데 영향을 주지 않는다.

### 기본 성질
집합의 상등은 원소의 구성이 같음을 의미하므로, 조건제시법으로 표현된 집합이라 할지라도 조건에 의해 결정되는 원소들이 서로 일치한다면 상등 관계가 성립한다. 예를 들어 $A = \{1, 2, 3\}$과 $B = \{3, 1, 2\}$는 순서가 다르지만 $A = B$이다. 또한 $C = \{x \mid x^2 - 3x + 2 = 0\}$과 $D = \{1, 2\}$의 경우, $C$의 원소가 $1$과 $2$이므로 $C = D$가 성립한다.

## 학습 체크
- 두 집합 $A$와 $B$가 상등하기 위해 필요한 두 가지 부분집합 관계는 무엇인가?
- 집합의 원소를 나열하는 순서나 중복 기입이 상등 여부에 영향을 주지 않는 이유는 무엇인가?
- 조건제시법으로 주어진 집합이 다른 집합과 상등함을 확인하기 위해 수행해야 할 과정은 무엇인가?

## 관련 개념

**집합**은 상등의 기반이 되는 개념이다. 두 집합이 같다는 것을 판단하려면 먼저 각 집합의 원소가 무엇인지 정확히 파악해야 한다.

**부분집합**과는 뗄 수 없는 관계다. $A = B$임을 직접 보이기 어려울 때는 $A \subseteq B$와 $B \subseteq A$를 각각 증명하는 방법을 자주 사용한다. 이 방법은 명제 증명에서도 핵심적으로 쓰인다.

**원소**의 개수가 같다고 해서 반드시 상등인 것은 아니다. $\{1, 2\}$와 $\{1, 3\}$은 원소의 개수가 같지만 $2 \neq 3$이므로 두 집합은 다르다. 원소의 개수가 같은 것과 집합이 같은 것을 혼동하지 않도록 주의해야 한다.
