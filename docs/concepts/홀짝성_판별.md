# 홀짝성 판별

홀짝성 판별이란, 확률 문제에서 어떤 수의 합이나 곱이 홀수인지 짝수인지를 빠르게 판단하여 조건을 만족하는 경우의 수를 세는 기법이다. 모든 경우를 일일이 나열하면 시간이 오래 걸리지만, 홀짝성의 규칙을 적용하면 "어떤 조합이 가능한가"를 훨씬 빠르게 분류할 수 있다. 핵심 규칙은 다음과 같다.

- **합의 홀짝성**: 홀수 + 홀수 = 짝수, 짝수 + 짝수 = 짝수, 홀수 + 짝수 = 홀수
- **곱의 홀짝성**: 홀수 × 홀수 = 홀수, 짝수가 하나라도 있으면 곱은 짝수

이 규칙을 이용하면 각각의 원소 값을 알지 않아도 "홀수를 몇 개, 짝수를 몇 개 뽑는지"만 파악해 조건 충족 여부를 결정할 수 있다.

---

## 예시

**예시 1.** 집합 $\{1, 2, 3, 4, 5\}$에서 서로 다른 3개의 수를 뽑을 때, 세 수의 합이 홀수일 확률을 구하여라.

합이 홀수가 되려면 홀수를 홀수 개 포함해야 한다. 집합 안에서 홀수는 $\{1, 3, 5\}$ (3개), 짝수는 $\{2, 4\}$ (2개)이므로 경우를 나누면 다음과 같다.

- 홀수 1개, 짝수 2개: $\binom{3}{1}\binom{2}{2} = 3$
- 홀수 3개, 짝수 0개: $\binom{3}{3}\binom{2}{0} = 1$

전체 경우의 수는 $\binom{5}{3} = 10$이므로, 구하는 확률은

$$P = \frac{3 + 1}{10} = \frac{2}{5}$$

**예시 2.** 주사위 두 개를 동시에 던질 때, 두 눈의 합이 짝수일 확률을 구하여라.

합이 짝수이려면 두 눈이 모두 홀수이거나 모두 짝수여야 한다. 각 주사위에서 홀수가 나올 확률과 짝수가 나올 확률은 모두 $\dfrac{1}{2}$이므로

$$P = \frac{1}{2} \times \frac{1}{2} + \frac{1}{2} \times \frac{1}{2} = \frac{1}{2}$$

## 관련 개념

- **확률**: 홀짝성 판별은 분자(사건의 경우의 수)를 효율적으로 구하기 위해 쓰이며, 확률 계산의 한 도구로 작동한다.
- **홀짝성**: 덧셈·곱셈에 대한 홀짝성 기본 규칙이 이 기법의 근거다. 홀짝성 자체를 먼저 이해한 뒤 확률에 적용해야 한다.
- **조합(순열과 조합)**: 홀짝성으로 경우를 분류한 뒤, 각 범주의 개수는 조합 $\binom{n}{r}$을 이용해 센다. 홀짝성 판별만으로는 개수를 구할 수 없고, 반드시 조합 계산과 함께 쓰인다.
- **여사건의 확률**: 경우에 따라 "홀수인 경우"를 직접 세기보다 "짝수인 경우"를 구한 뒤 $1$에서 빼는 여사건 전략과 결합하면 계산이 더 간단해질 수 있다.
