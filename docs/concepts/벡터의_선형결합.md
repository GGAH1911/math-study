# 벡터의 선형결합

## 요약
두 개 이상의 벡터에 각각 실수를 곱하여 더한 형태를 벡터의 선형결합이라고 합니다.

## 본문
두 벡터 $\vec{a}$와 $\vec{b}$가 있을 때, 임의의 실수 $k, l$에 대하여 $k\vec{a} + l\vec{b}$와 같이 벡터의 실수배를 더한 형태를 벡터의 선형결합이라고 정의합니다. 이는 벡터 공간 내의 원소들을 기본이 되는 벡터들의 합과 실수배를 통해 새롭게 생성해내는 과정을 의미합니다.

### 직관과 기하적 의미
기하학적으로 선형결합은 평행사변형법을 확장한 개념으로 이해할 수 있습니다. 두 벡터 $\vec{a}$와 $\vec{b}$가 평행하지 않을 때, 각 벡터의 길이를 조절(실수배)한 뒤 두 벡터를 이어 붙이면 평면 위의 임의의 점에 도달할 수 있습니다. 즉, 선형결합은 주어진 벡터들을 이용해 평면 위의 새로운 위치를 찾아가는 과정과 같습니다.

### 기본 성질
선형결합은 결합법칙과 분배법칙이 성립하여 계산이 자유롭습니다. 또한, 모든 벡터를 $0$으로 만드는 실수 $k, l$이 $k=0, l=0$뿐이라면, 해당 벡터들은 선형독립이며 이들의 선형결합을 통해 평면 전체를 채울 수 있는 기저가 됩니다.

## 학습 체크
- 주어진 벡터들의 선형결합이 특정 벡터와 일치하도록 하는 실수 $k, l$의 값을 구할 수 있는가?
- 두 벡터가 평행할 때와 평행하지 않을 때, 선형결합으로 만들 수 있는 영역의 차이를 이해하고 있는가?

## 관련 개념
- **평면벡터**: 평면 위의 두 벡터를 이용한 선형결합은 평면 위의 모든 위치 벡터를 표현할 수 있는 도구가 됩니다.
