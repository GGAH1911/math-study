### 정확한 진술

수열 $\{a_n\}$이 실수 $L$로 **수렴한다**는 것은 다음과 같이 정의됩니다:

$$\text{임의의 } \varepsilon > 0\text{에 대해, 어떤 자연수 } N\text{이 존재하여} \newline n > N \Rightarrow |a_n - L| < \varepsilon$$

이를 $\lim_{n \to \infty} a_n = L$ 또는 $a_n \to L$로 표기합니다.

### 직관과 의미

이 정의는 "아무리 작은 오차 범위 $\varepsilon$를 정해도, 충분히 앞으로 나아가면($n > N$) 모든 항이 극한값 $L$ 근처에 갇힌다"는 뜻입니다. 

기하학적으로 보면, $L$ 주변의 폭 $2\varepsilon$인 띠 모양 구간 $(L - \varepsilon, L + \varepsilon)$ 속에 어떤 항부터 이후의 **모든 항**이 들어간다는 의미입니다. 

핵심은:
- $\varepsilon$를 먼저 정하고(아무리 작아도 됨)
- 그에 맞춰 충분히 큰 $N$을 찾을 수 있으면 수렴

이렇게 정의하는 이유는 "대충 가까워진다"가 아닌 **얼마나 정확하게** 가까워지는지를 엄밀하게 표현하기 위함입니다. 고등학교에서는 직관적으로 다루지만, 대학 미적분학부터는 이 정의가 표준입니다.

### 한 줄 예

$a_n = \frac{1}{n}$일 때, $\lim_{n \to \infty} a_n = 0$입니다. 왜냐하면 $\varepsilon = 0.01$이면 $N = 100$으로 잡으면 $n > 100$일 때 $|a_n - 0| = \frac{1}{n} < 0.01$이 성립하기 때문입니다. (일반적으로 $N = \lceil 1/\varepsilon \rceil$로 잡으면 됨)
