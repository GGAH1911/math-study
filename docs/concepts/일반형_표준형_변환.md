# 일반형 표준형 변환

> **예제** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
제곱완성

## 본문 (학습 시 채워짐)

### 문제

다음 이차함수를 표준형으로 나타내고, 꼭짓점의 좌표를 구하세요.

$$y = x^2 - 4x + 3$$

### 단계별 풀이

**1단계: $x$에 대한 항만 묶기**

상수항을 따로 떼어냅니다:
$$y = (x^2 - 4x) + 3$$

**2단계: $x^2 - 4x$를 완전제곱식으로 변형하기**

$x^2 - 4x$를 $(x - p)^2$ 형태로 만들려면, $x$의 계수를 2로 나누고 제곱합니다.

$$x \text{의 계수: } -4 \Rightarrow -4 \div 2 = -2 \Rightarrow (-2)^2 = 4$$

따라서:
$$x^2 - 4x = (x-2)^2 - 4$$

**3단계: 원래 식에 대입**

$$(x-2)^2 - 4$를 대입하면:
$$y = (x-2)^2 - 4 + 3 = (x-2)^2 - 1$$

### 답

**표준형**: $y = (x-2)^2 - 1$

**꼭짓점의 좌표**: $(2, -1)$

(검산: `sympy.expand((x-2)**2 - 1)` → $x^2 - 4x + 3$ ✓)

### 변형/주의

**이차항 계수가 1이 아닌 경우**

$$y = 2x^2 + 8x + 5$$

이차항의 계수 2를 먼저 인수분해합니다:
$$y = 2(x^2 + 4x) + 5$$

괄호 안에서 제곱완성 ($4 \div 2 = 2$, $2^2 = 4$):
$$y = 2[(x+2)^2 - 4] + 5 = 2(x+2)^2 - 8 + 5 = 2(x+2)^2 - 3$$

꼭짓점은 $(-2, -3)$입니다.

**꼭 기억하세요**
- 괄호 안에서 더한 값(예: $-4$)을 빼낼 때는 반드시 바깥 계수(여기선 2)를 곱합니다.
- 표준형 $y = a(x-p)^2 + q$에서 꼭짓점은 항상 $(p, q)$입니다.
