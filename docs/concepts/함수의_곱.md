# 함수의 곱

## 요약
두 함수를 곱하여 얻은 새로운 함수는 각 함수의 함숫값을 곱한 값으로 정의됩니다.

## 본문
두 함수 $f(x)$와 $g(x)$가 각각 정의역 $D$에서 정의될 때, 곱의 함수 $(f \cdot g)(x)$는 모든 $x \in D$에 대하여 $f(x)g(x)$로 정의되는 함수를 의미합니다. 즉, 새로운 함수의 함숫값은 원래 두 함수의 함숫값을 각각 곱한 결과와 같습니다.

### 직관과 기하적 의미
기하학적으로 두 함수의 곱은 두 함수의 그래프가 나타내는 $y$값(높이)을 곱한 새로운 높이를 갖는 그래프를 그리는 과정과 같습니다. 만약 두 함수가 모두 양수라면 곱의 함수는 두 그래프의 높이를 곱한 만큼 커지거나 작아지며, 한 함수가 상수 함수라면 그래프의 높이를 일정 비율로 확대하거나 축소시키는 스케일링(scaling) 효과를 나타내기도 합니다.

### 기본 성질
함수의 곱은 결합법칙과 교환법칙이 성립합니다. 즉, $f(x)g(x) = g(x)f(x)$이며, $(f(x)g(x))h(x) = f(x)(g(x)h(x))$가 성립합니다. 또한, 한 함수가 영함수(모든 $x$에 대해 $0$인 함수)라면 곱의 함수도 영함수가 됩니다.

## 학습 체크
- 두 함수의 곱의 함수가 정의되기 위해 두 함수의 정의역이 어떻게 관계되어야 하는가?
- $f(x)g(x) = 0$일 때, 반드시 $f(x)=0$ 또는 $g(x)=0$이어야 하는가? (정의역 내의 모든 $x$에 대하여)

## 관련 개념
- **함수의 극한과 연속**: 두 함수의 곱의 극한은 각 함수의 극한의 곱과 같으며, 두 함수가 연속이면 곱의 함수도 연속입니다.
