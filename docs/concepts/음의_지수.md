# 음의 지수

## 요약
지수에 음수가 붙으면 해당 수는 역수의 형태가 되어 지수만큼 나누는 연산이 됩니다.

## 본문
지수에 음수가 붙은 형태인 $a^{-n}$은 $a$의 역수인 $\tfrac{1}{a}$을 $n$번 곱한 것과 같습니다. 즉, $a^{-n} = \tfrac{1}{a^n}$ (단, $a \neq 0$)으로 정의합니다. 이는 지수의 연산 규칙을 확장하여, 지수가 양수일 때 곱해지는 과정을 지수가 음수일 때 나누는 과정으로 연결해 줍니다.

### 직관과 기하적 의미
지수가 $1$씩 커질 때마다 값이 $a$배씩 곱해진다면, 지수가 $1$씩 작아질 때는 값이 $\tfrac{1}{a}$배씩 줄어듭니다. 즉, 음의 지수는 곱셈의 반복이 아닌 나눗셈의 반복을 의미하며, 값이 점차 $0$에 가까워지는 감소의 과정을 나타냅니다.

### 기본 성질
1. $a^{-n} = \tfrac{1}{a^n}$
2. $\tfrac{1}{a^n} = a^{-n}$
3. $(a^{-n})^m = a^{-nm}$

## 관련 개념
- **지수와 로그**: 지수가 양수에서 음수로, 그리고 실수 전체로 확장되는 과정에서 로그의 개념이 자연스럽게 등장합니다.
- **분수와 역수**: 음의 지수는 수의 구조를 분수 형태로 변환하므로 역수의 개념과 밀접하게 연결됩니다.
