# 교점의 위치 판단

## 요약
두 그래프가 만나는 점인 교점의 위치를 판단하기 위해 각 함수의 함숫값을 비교하여 대소 관계를 파악한다.

## 본문
두 함수 $y=f(x)$와 $y=g(x)$의 그래프가 만나는 점의 $x$좌표를 구하기 위해서는 방정식 $f(x)=g(x)$의 해를 구해야 한다. 이때 두 함수의 그래프가 만나는 위치를 판단하는 것은 두 함수의 함숫값이 같아지는 지점을 찾는 과정과 같다. 만약 $x$의 범위에 따라 $f(x) > g(x)$이면 $f(x)$의 그래프가 $g(x)$의 그래프보다 위쪽에 위치하며, $f(x) < g(x)$이면 $f(x)$의 그래프가 $g(x)$의 그래프보다 아래쪽에 위치한다. 교점의 위치를 판단할 때는 단순히 방정식의 해를 구하는 것에 그치지 않고, 해를 기준으로 구간을 나누어 각 구간에서 두 함수의 대소 관계가 어떻게 변하는지를 분석하는 것이 중요하다. 특히 지수함수와 로그함수처럼 역함수 관계에 있는 그래프를 비교할 때는 $y=x$와의 교점 유무를 통해 두 그래프의 위치 관계를 효율적으로 파악할 수 있다.

### 직관과 기하적 의미
그래프 상에서 한 함수가 다른 함수보다 위에 있다는 것은 해당 $x$값에서 함수의 높이가 더 높다는 것을 의미하며, 이는 두 함수의 차이인 $h(x)=f(x)-g(x)$의 부호가 양수임을 나타낸다.

### 기본 성질
두 함수의 그래프가 교점에서 만날 때, 그 교점의 $x$좌표는 두 함수를 같다고 놓은 방정식의 실근과 일치한다.

## 학습 체크
- 두 함수의 식을 하나로 합친 $f(x)-g(x)$의 부호를 통해 그래프의 상하 관계를 설명할 수 있는가?
- 역함수 관계에 있는 두 그래프의 교점이 $y=x$ 위에 있는지, 혹은 $y=x$를 기준으로 대칭인 위치에 있는지 판단할 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 두 함수는 서로 역함수 관계이므로, $y=x$와의 교점의 위치를 통해 두 그래프의 상대적인 위치를 쉽게 결정할 수 있다.
