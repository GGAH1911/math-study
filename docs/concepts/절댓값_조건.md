# 절댓값 조건

## 요약
절댓값 조건은 변수의 값이 특정 범위 내에 있을 때, 그 변수의 부호에 따라 식의 형태가 달라지는 조건부 방정식을 의미합니다.

## 본문
절댓값 조건이란 수식 내에 절댓값 기호가 포함되어 있어, 변수의 값에 따라 식의 구조가 변하는 상황을 의미합니다. 일반적으로 변수 $x$에 대한 절댓값 식 $|f(x)| = g(x)$를 해결하기 위해서는 $f(x)$의 부호가 양수인지 음수인지에 따라 식을 두 가지 경우로 나누어 풀어야 합니다. 즉, $f(x) \ge 0$인 구간과 $f(x) < 0$인 구간을 각각 설정하여 조건에 맞는 해를 구하는 과정이 필수적입니다. 이러한 조건 설정은 절댓값 내부의 식이 $0$이 되는 지점을 기준으로 구간을 나누는 것이 핵심입니다.

### 직관과 기하적 의미
기하학적으로 절댓값 $|x - a|$는 수직선 위에서 점 $x$와 점 $a$ 사이의 거리를 의미합니다. 따라서 절댓값 조건이 포함된 부등식이나 방정식은 두 지점 사이의 거리 관계를 다루는 문제로 해석할 수 있습니다. 예를 들어 $|x| < a$는 원점으로부터의 거리가 $a$보다 작은 범위를 의미하며, 이는 수직선 상의 특정 구간을 나타냅니다.

### 기본 성질
절댓값은 항상 $0$보다 크거나 같다는 성질($|a| \ge 0$)을 가집니다. 또한 $|a| = |b|$이면 $a = b$ 또는 $a = -b$라는 성질이 성립하며, 이는 절댓값 조건 문제를 풀 때 부호를 나누어 계산할 수 있는 근거가 됩니다.

## 학습 체크
- 절댓값 내부의 식이 $0$이 되는 값을 기준으로 구간을 나누었는가?
- 각 구간에서 설정한 조건(부호)이 실제 구한 해의 범위와 일치하는가?

## 관련 개념
- **확률**: 확률 변수의 범위가 절댓값 조건에 의해 제한될 때, 특정 구간에 속할 확률을 계산하는 문제로 연결됩니다.
- **함수**: 절댓값이 포함된 함수는 꺾인 그래프의 형태를 띠며, 함수의 연속성과 미분 가능성을 판단하는 중요한 요소가 됩니다.
