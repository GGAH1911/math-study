### 정확한 진술

실수 $a$의 절댓값은 다음과 같이 조건부로 정의된다:

$$|a| = \begin{cases} a & \text{if } a \geq 0 \\ -a & \text{if } a < 0 \end{cases}$$

즉, $a$가 0 이상이면 $a$ 자신이고, $a$가 음수이면 그것의 음수(따라서 양수)이다. 모든 경우에 절댓값의 결과는 항상 $|a| \geq 0$을 만족하는 음이 아닌 수이다.

### 직관 및 기하적 의미

절댓값 $|a|$는 수직선 위에서 수 $a$와 원점(0) 사이의 **거리**를 나타낸다. 거리는 항상 양수이거나 0이므로, 절댓값은 수의 부호를 무시하고 순수한 크기만 나타낸다. 예를 들어 3과 $-3$은 서로 반대 방향이지만 원점으로부터 같은 거리 3에 있으므로 $|3| = |-3| = 3$이다. 이처럼 양수와 음수를 구별하지 않고 크기를 비교할 때, 또는 방정식과 부등식에서 음수 경우를 처리할 때 절댓값의 조건부 정의가 핵심이다.

### 한 줄 예

$|5| = 5$, $|-7| = 7$, $|0| = 0$ (검산: `abs(-7)` → 7)
