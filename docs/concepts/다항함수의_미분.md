# 다항함수의 미분

## 요약
다항함수의 각 항을 개별적으로 미분하여 새로운 다항함수를 얻는 과정으로, 지수를 앞으로 내리고 지수에서 1을 빼는 규칙을 따릅니다.

## 본문
다항함수의 미분은 함수 $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$에 대하여, 각 항의 지수를 앞으로 내려 계수와 곱하고 지수에서 1을 뺀 값을 새로운 계수로 삼아 항을 구성하는 연산입니다. 즉, $f'(x) = n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + \dots + a_1$이 됩니다. 이는 미분계수의 정의인 극한 $\lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$를 다항함수에 적용했을 때 나타나는 결과와 일치하며, 복잡한 극한 계산 없이도 함수의 변화율을 쉽고 빠르게 구할 수 있게 해줍니다.

### 직관과 기하적 의미
다항함수의 미분은 그래프 위의 임의의 점에서의 접선의 기울기를 구하는 과정입니다. 차수가 높은 항일수록 그래프의 곡률이 급격히 변하며, 미분을 통해 얻은 도함수는 원래 함수의 그래프가 어느 지점에서 증가하거나 감소하는지, 그리고 극값을 갖는지 여부를 판단하는 결정적인 지표가 됩니다.

### 기본 성질
첫째, 상수항을 미분하면 $0$이 됩니다. 둘째, 두 다항함수의 합 또는 차를 미분한 것은 각각의 함수를 미분하여 더하거나 뺀 것과 같습니다. 셋째, 상수배가 된 함수를 미분하면 상수는 미분 결과 앞에 그대로 유지됩니다.

## 학습 체크
- $x^n$을 미분할 때 지수 $n$이 $0$인 경우(상수항) 결과가 왜 $0$이 되는지 극한의 정의로 설명할 수 있는가?
- 다항식의 곱셈 형태를 미분할 때 각 항을 따로 미분하여 곱하는 실수를 범하지 않는가?

## 관련 개념
- **미분**: 함수의 특정 지점에서의 순간적인 변화율을 나타내는 연산으로, 다항함수의 미분은 이 연산을 다항식에 적용한 특수한 경우입니다.
- **도함수**: 원래 함수 $f(x)$를 미분하여 얻은 새로운 함수 $f'(x)$를 의미하며, 다항함수의 미분 결과물은 항상 다항함수의 형태를 띱니다.
