### 정의

물체의 속도 함수 $v(t)$의 부호를 조사하여 운동 방향을 판단하는 방법입니다. 어느 시간 구간에서 $v(t) > 0$이면 물체는 정방향(양의 방향)으로 움직이고, $v(t) < 0$이면 역방향(음의 방향)으로 움직입니다.

### 기본 개념

위치 함수 $s(t)$가 주어졌을 때, 속도는 $v(t) = \frac{ds}{dt}$입니다. 속도의 부호가 운동 방향을 직접 결정합니다:

- **$v(t) > 0$인 구간**: 위치가 증가 중 → 정방향(우측 또는 양의 방향)으로 이동
- **$v(t) < 0$인 구간**: 위치가 감소 중 → 역방향(좌측 또는 음의 방향)으로 이동  
- **$v(t) = 0$인 시점**: 운동이 멈춘 순간 → 방향 변환점

$v(t) = 0$이 되는 시점을 찾아 수직선 위에 표시하면, 각 구간에서의 속도 부호를 판단할 수 있습니다. 부호가 바뀌는 지점을 기준으로 운동이 정방향에서 역방향으로(또는 그 반대로) 전환됩니다.

### 기하학적 의미

$v(t)$의 그래프에서:
- $x$축 위쪽(양수): 정방향 운동
- $x$축 아래쪽(음수): 역방향 운동
- $x$축과의 교점: 방향 전환점

### 예시

위치 함수가 $s(t) = t^3 - 3t^2$ (단위: m, $0 \le t \le 4$초)일 때, 속도는 $v(t) = 3t^2 - 6t = 3t(t-2)$입니다. $v(t) = 0$에서 $t = 0, 2$이므로:

- $0 < t < 2$: $v(t) < 0$ → 역방향 운동
- $2 < t \le 4$: $v(t) > 0$ → 정방향 운동

따라서 물체는 처음 2초간 역방향으로 이동한 후, $t=2$초에서 방향을 바꾸어 정방향으로 이동합니다.
