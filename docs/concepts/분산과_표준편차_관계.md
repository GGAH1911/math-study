# 분산과 표준편차 관계

> **정리** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
표준편차 $=\sqrt{\text{분산}}$

## 본문 (학습 시 채워짐)

### 진술과 가정

표준편차는 분산의 양의 제곱근입니다. 즉, 자료의 분산을 $V$라 하면, 표준편차 $\sigma$는 다음을 만족합니다:

$$\sigma = \sqrt{V}$$

여기서 분산 $V$는 각 자료값과 평균의 차이를 제곱한 후 평균낸 값이므로, 자료의 산포도(퍼짐의 정도)를 측정합니다.

### 간단한 유도 스케치

분산을 구하는 과정을 되짚어 봅시다. 평균이 $\bar{x}$인 자료 $x_1, x_2, \ldots, x_n$에 대해:

$$V = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

분산은 편차(평균과의 차이)를 제곱한 값들의 평균이므로, 제곱 단위의 양입니다. 원래 자료의 단위로 돌아가기 위해 제곱근을 취하면 표준편차가 됩니다. 따라서:

$$\sigma = \sqrt{V} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}$$

**예**: 자료가 1, 3, 5, 7, 9일 때, 평균은 5, 분산은 $\frac{(1-5)^2+(3-5)^2+(5-5)^2+(7-5)^2+(9-5)^2}{5} = \frac{40}{5} = 8$이므로, 표준편차는 $\sqrt{8} = 2\sqrt{2}$입니다. (sympy: `sqrt(8)`)

### 의의와 응용

분산은 계산 과정에서 값을 제곱하기 때문에, 원래 자료의 단위와 맞지 않습니다. 표준편차는 제곱근을 취하여 원래 단위로 복원하므로, 산포도를 자료와 같은 단위로 해석할 수 있습니다. 

예를 들어 키의 분산이 25 cm²라면 표준편차는 5 cm로, "키들이 평균으로부터 평균적으로 5 cm 정도 떨어져 있다"고 직관적으로 이해할 수 있습니다. 따라서 수능에서는 산포도를 비교하거나 자료의 특성을 설명할 때 표준편차를 주로 사용합니다.
