# 여러가지 함수의 미분

> **단원** · 미적분 · 선수: [미분](./미분.md) / [여러가지함수의 극한](./여러가지함수의_극한.md)

## 학습 목표
- 지수·로그·삼각함수의 도함수를 구한다
- 몫의 미분법을 활용한다

## 다룰 정의 / 정리 / 예제 (Phase 2 spoke로 분해됨)

**정의(definition)**
- $e^x$의 도함수
- $\ln x$의 도함수
- 삼각함수의 도함수

**정리(theorem)**
- $(e^x)'=e^x$, $(\ln x)'=1/x$
- $(\sin x)'=\cos x$, $(\cos x)'=-\sin x$
- 몫의 미분 $(f/g)'=(f'g-fg')/g^2$

**예제(example)**
- 지수·로그함수 미분
- 삼각함수 미분
- 곱·몫 미분 계산
