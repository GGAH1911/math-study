### 정확한 진술

두 사건 $A$, $B$에 대하여 다음이 성립한다:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

특히 **배반사건** (즉, $A \cap B = \emptyset$)일 때는 교집합 확률이 0이므로:

$$P(A \cup B) = P(A) + P(B)$$

### 직관과 의미

"$A$ 또는 $B$가 일어날 확률"을 구할 때, $P(A)$와 $P(B)$를 단순히 더하면 겹치는 부분(동시에 일어나는 경우)이 두 번 세어진다. 따라서 겹치는 부분 $P(A \cap B)$를 한 번 빼야 정확한 확률을 얻는다. 

벤 다이어그램으로 생각하면, $A$의 영역과 $B$의 영역을 합칠 때 교집합 영역이 중복되므로 한 번 제외하는 것이다. 배반사건이면 겹치는 부분이 없으므로 단순히 더하기만 하면 된다.

### 한 줄 예

주사위를 던져 3의 배수($A$)가 나올 확률은 $1/3$, 홀수($B$)가 나올 확률은 $1/2$이고, 동시에 3의 배수이면서 홀수인 경우(3)의 확률은 $1/6$이므로, "3의 배수 또는 홀수"의 확률은:

$$P(A \cup B) = \frac{1}{3} + \frac{1}{2} - \frac{1}{6} = \frac{2+3-1}{6} = \frac{2}{3}$$

(검증: `from sympy import Rational; print(Rational(1,3) + Rational(1,2) - Rational(1,6))`)
