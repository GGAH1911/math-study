# n제곱근의 정의

## 요약
어떤 수 $a$에 대하여 $x^n = a$를 만족하는 $x$의 값을 $a$의 $n$제곱근이라고 합니다.

## 본문
어떤 수 $a$에 대하여 $x^n = a$를 만족하는 $x$의 값을 $a$의 $n$제곱근이라고 정의합니다. 이때 $n$은 2 이상의 자연수입니다. $n$이 홀수인지 짝수인지, 그리고 $a$의 부호에 따라 $n$제곱근의 개수가 달라지므로 주의가 필요합니다.

### 직관과 기하적 의미
$n$제곱근은 어떤 수를 $n$번 곱했을 때 $a$가 되는 수를 찾는 과정입니다. 기하학적으로는 $n$차원 초입방체의 부피가 $a$일 때, 그 한 변의 길이를 구하는 과정과 유사한 의미를 갖습니다.

### 기본 성질
1. $n$이 홀수일 때: 모든 실수 $a$에 대하여 $a$의 $n$제곱근은 실수로 오직 하나 존재합니다.
2. $n$이 짝수일 때:
   - $a > 0$이면, $a$의 $n$제곱근은 서로 다른 두 실수가 존재합니다.
   - $a = 0$이면, $a$의 $n$제곱근은 $0$ 하나뿐입니다.
   - $a < 0$이면, $a$의 $n$제곱근은 실수 범위에서 존재하지 않습니다.
3. 복소수 범위까지 확장하면, $n$이 홀수일 때 $n$개의, $n$이 짝수일 때 $n$개의 복소수 해가 존재하게 됩니다.

## 학습 체크
- $n$이 짝수일 때 $a < 0$인 경우 왜 실수 범위에서 제곱근이 존재하지 않는가?
- $n$이 홀수일 때 $a$의 부호에 관계없이 항상 하나의 실근을 갖는 이유를 설명할 수 있는가?

## 관련 개념
- **방정식과 부등식**: $x^n = a$라는 방정식의 해를 찾는 과정이 곧 $a$의 $n$제곱근을 구하는 과정과 직결됩니다.
