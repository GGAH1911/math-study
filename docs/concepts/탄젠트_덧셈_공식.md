# 탄젠트 덧셈 공식

두 각 $\alpha$와 $\beta$의 합 또는 차에 대한 탄젠트 값을, 각각의 탄젠트 값만으로 나타내는 공식이다.

$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

$$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$

단, 분모가 $0$이 되는 경우, 즉 $\tan\alpha\tan\beta = 1$인 경우에는 좌변 자체가 정의되지 않으므로 이 공식을 적용할 수 없다.

이 공식은 사인·코사인의 덧셈 공식에서 직접 유도된다. $\tan(\alpha+\beta) = \dfrac{\sin(\alpha+\beta)}{\cos(\alpha+\beta)}$에 각각의 덧셈 공식을 대입한 뒤, 분자·분모를 $\cos\alpha\cos\beta$로 나누면 위의 형태가 나온다.

## 예시

**예 1.** $\tan 75°$의 값을 구해 보자.

$75° = 45° + 30°$이고 $\tan 45° = 1$, $\tan 30° = \dfrac{1}{\sqrt{3}}$이므로,

$$\tan 75° = \frac{1 + \dfrac{1}{\sqrt{3}}}{1 - 1 \cdot \dfrac{1}{\sqrt{3}}} = \frac{\dfrac{\sqrt{3}+1}{\sqrt{3}}}{\dfrac{\sqrt{3}-1}{\sqrt{3}}} = \frac{\sqrt{3}+1}{\sqrt{3}-1} = \frac{(\sqrt{3}+1)^2}{2} = 2+\sqrt{3}$$

**예 2.** $\tan\alpha = 2$, $\tan\beta = \dfrac{1}{3}$일 때 $\tan(\alpha+\beta)$를 구해 보자.

$$\tan(\alpha+\beta) = \frac{2 + \dfrac{1}{3}}{1 - 2 \cdot \dfrac{1}{3}} = \frac{\dfrac{7}{3}}{\dfrac{1}{3}} = 7$$

분모와 분자 모두 $\tan\alpha$, $\tan\beta$의 사칙연산만으로 처리되어, 원래 각의 크기를 몰라도 결과를 바로 얻을 수 있다는 점이 이 공식의 핵심 편리함이다.

## 관련 개념

**삼각함수** — 탄젠트는 사인과 코사인의 비 $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$로 정의된다. 이 정의 자체가 덧셈 공식 유도의 출발점이므로, 삼각함수의 기본 성질을 먼저 익혀야 이 공식의 의미가 온전히 보인다.

**사인·코사인 덧셈 공식** — 탄젠트 덧셈 공식은 독립적인 공식이 아니라, 사인·코사인 덧셈 공식을 탄젠트의 형태로 정리한 결과물이다. 세 공식을 묶어서 기억하면 어느 하나를 잊더라도 나머지에서 복원할 수 있다.

**이중각 공식** — 덧셈 공식에서 $\beta = \alpha$로 놓으면 $\tan 2\alpha = \dfrac{2\tan\alpha}{1-\tan^2\alpha}$가 바로 나온다. 탄젠트 덧셈 공식을 충분히 이해했다면 이중각 공식은 따로 외울 필요 없이 유도해 쓸 수 있다.

**직선의 기울기와 두 직선이 이루는 각** — 좌표평면에서 기울기 $m = \tan\theta$이므로, 두 직선이 이루는 각의 탄젠트를 구할 때 이 공식이 그대로 적용된다. 기하 문제에서 탄젠트 덧셈 공식이 뜻밖에 등장하는 대표적인 맥락이다.
