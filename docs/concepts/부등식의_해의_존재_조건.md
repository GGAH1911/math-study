### 정확한 진술

부등식이 해를 가질 조건은 함수의 치역(또는 범위)과 주어진 상수의 대소 관계로 결정됩니다. 일반적으로:

- 부등식 $f(x) > k$가 해를 가지려면 $\max f(x) > k$이어야 합니다.
- 부등식 $f(x) < k$가 해를 가지려면 $\min f(x) < k$이어야 합니다.
- 부등식 $f(x) \geq k$가 해를 가지려면 $\max f(x) \geq k$이어야 합니다.
- 부등식 $f(x) \leq k$가 해를 가지려면 $\min f(x) \leq k$이어야 합니다.

### 직관과 기하적 의미

부등식 $f(x) > k$를 만족하는 $x$가 존재한다는 것은, 함수 $y = f(x)$의 그래프가 수평선 $y = k$보다 **위에 위치하는 점이 적어도 하나** 있다는 뜻입니다. 따라서 함수의 최댓값이 $k$보다 커야 합니다. 

이차함수 $f(x) = ax^2 + bx + c$ (단, $a < 0$)의 경우, 아래로 볼록한 포물선이므로 최댓값이 존재합니다. 부등식 $f(x) > 0$이 해를 가지려면 꼭짓점의 $y$좌표가 0보다 커야 합니다. 이는 판별식과 이차항 계수의 부호로 판단할 수 있습니다.

### 예시

**이차함수의 경우:**

$f(x) = -x^2 + 4x - 3$에서 부등식 $f(x) > 0$의 해의 존재 조건을 확인해봅시다.

$f(x) = -(x-2)^2 + 1$이므로 최댓값은 1입니다. $1 > 0$이므로 부등식 $f(x) > 0$은 해를 갖습니다. 실제로 $-(x-1)(x-3) > 0$ ⟹ $1 < x < 3$

반대로, 부등식 $f(x) > 5$가 해를 가지는지 판단하려면 최댓값 1과 5를 비교합니다. $1 \not> 5$이므로 해가 **없습니다**.

(`sympy.solve(-x**2 + 4*x - 3 > 0, x)` → $1 < x < 3$)

### 주의사항

판별식이 음수라고 해서 부등식이 해를 갖지 않는 것은 아닙니다. 예를 들어 $x^2 + 1 < 0$은 판별식이 음수이지만, 더 중요한 것은 좌변의 최솟값 1이 0보다 크다는 점이므로 해가 **없습니다**. 반면 $-x^2 - 1 < 0$은 우변이 음수이고 좌변의 최댓값이 $-1 < 0$이므로 **항상 참**입니다.
