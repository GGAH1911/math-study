# 원과 직선 위치관계

> **정리** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
판별식 또는 점-선 거리

## 본문 (학습 시 채워짐)

### 진술 및 가정

원 $(x-a)^2 + (y-b)^2 = r^2$과 직선 $lx + my + n = 0$의 위치 관계는 다음 세 가지 중 하나입니다:
- **만나지 않음** (공통점 0개)
- **한 점에서 만남** (공통점 1개, 접함)
- **두 점에서 만남** (공통점 2개)

이 관계를 판정하는 방법은 **판별식** 또는 **거리**입니다.

### 판별식을 이용한 판정

직선 $y = kx + c$를 원의 방정식에 대입하면:
$$(x-a)^2 + (kx + c - b)^2 = r^2$$

정리하면 $x$에 대한 이차방정식 $Ax^2 + Bx + C = 0$을 얻습니다. 판별식 $D = B^2 - 4AC$에 따라:

- $D > 0$ ⟹ **두 점에서 만남**
- $D = 0$ ⟹ **한 점에서 만남** (접함)
- $D < 0$ ⟹ **만나지 않음**

**예**: 원 $x^2 + y^2 = 5$와 직선 $y = x + 1$을 대입하면 $2x^2 + 2x - 4 = 0$, 판별식 $D = 4 + 32 = 36 > 0$ → 두 점에서 만남

### 거리를 이용한 판정

원의 중심 $(a, b)$에서 직선 $lx + my + n = 0$까지의 거리:
$$d = \frac{|la + mb + n|}{\sqrt{l^2 + m^2}}$$

반지름 $r$과 비교하면:
- $d < r$ ⟹ **두 점에서 만남**
- $d = r$ ⟹ **한 점에서 만남** (접함)
- $d > r$ ⟹ **만나지 않음**

### 의의 및 활용

판별식은 교점의 좌표가 필요할 때, 거리는 위치 관계만 판정하거나 접선을 구할 때 더 효율적입니다. 이 정리는 원뿐 아니라 포물선, 타원, 쌍곡선과 직선의 관계로도 확장되므로 도형의 방정식 단원에서 가장 핵심적인 판정 기준입니다.
