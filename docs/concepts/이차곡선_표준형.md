# 이차곡선 표준형

> **정리** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
포물선 $y^2=4px$, 타원/쌍곡선 표준식

## 본문 (학습 시 채워짐)

### 이차곡선의 표준형 진술

평면에서 주어진 점 $F$(초점)과 직선 $l$(준선)에 대하여, $F$까지의 거리와 $l$까지의 거리의 비가 상수 $e$(이심률)인 점들의 자취를 이차곡선이라 합니다. 이심률 $e$의 값에 따라:

- $e=1$일 때: **포물선** $y^2 = 4px$ (단, $p>0$, 초점 $F(p,0)$, 준선 $x=-p$)
- $0 < e < 1$일 때: **타원** $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ (단, $a > b > 0$)
- $e > 1$일 때: **쌍곡선** $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$

### 포물선 표준형의 유도

초점 $F(p,0)$과 준선 $x=-p$로부터 출발합니다. 포물선의 정의에 따라 점 $P(x,y)$는 $PF = $ (점 $P$에서 준선까지의 거리)를 만족합니다.

$$\sqrt{(x-p)^2 + y^2} = x + p$$

양변을 제곱하고 정리하면:
$$(x-p)^2 + y^2 = (x+p)^2$$
$$y^2 = 4px$$

**타원과 쌍곡선:** 타원의 경우 두 초점까지의 거리의 합이 $2a$로 일정하다는 조건 $PF_1 + PF_2 = 2a$로부터, 쌍곡선의 경우 거리의 차 $|PF_1 - PF_2| = 2a$로부터 각각의 표준형이 유도됩니다. 두 곡선 모두에서 $c$를 중심에서 초점까지의 거리라 하면, 타원은 $c^2 = a^2 - b^2$, 쌍곡선은 $c^2 = a^2 + b^2$의 관계를 따릅니다.

### 표준형의 의의

표준형은 이차곡선의 **기하학적 성질을 대수적으로 표현**하는 최적의 형태입니다. 표준형에서는 초점의 위치, 꼭짓점, 준선, 이심률 등 모든 중요한 요소를 즉시 읽어낼 수 있습니다. 또한 곡선을 평행이동하거나 회전시킬 때도 표준형으로의 변환을 목표로 하므로, 이차곡선 문제 해결의 핵심입니다.
