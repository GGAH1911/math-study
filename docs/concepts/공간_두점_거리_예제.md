# 공간 두점 거리 예제

> **예제** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3D 좌표 계산

## 본문 (학습 시 채워짐)

### 문제
$A(1, -2, 3)$과 $B(4, 2, -1)$ 사이의 거리를 구하시오.

### 단계별 풀이

**1단계: 공간 거리 공식 확인**  
공간에서 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 피타고라스 정리를 3차원으로 확장한 공식입니다.
$$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

**2단계: 각 좌표의 차 계산**  
주어진 점에서 좌표 성분별 차이를 구합니다.
- $x$ 좌표 차이: $4 - 1 = 3$
- $y$ 좌표 차이: $2 - (-2) = 4$
- $z$ 좌표 차이: $-1 - 3 = -4$

**3단계: 제곱하여 더하기**  
각 차이를 제곱한 후 합하는 이유는 음수를 양수로 바꾸고, 거리의 합성을 나타내기 위함입니다.
$$d = \sqrt{3^2 + 4^2 + (-4)^2} = \sqrt{9 + 16 + 16} = \sqrt{41}$$

### 답
$$d = \sqrt{41} \approx 6.40$$

### 변형/주의
- **부호 무관**: $(B-A)$와 $(A-B)$ 중 어느 쪽으로 계산해도 제곱하므로 같은 결과입니다.
- **축 방향 거리**: 한 방향 좌표만 다른 경우, 그 거리가 전체 거리가 됩니다 (예: $A(0,0,0)$과 $B(0,0,5)$이면 $d=5$).
- **검산**: `sympy.sqrt(3**2 + 4**2 + 4**2)` 결과는 $\sqrt{41}$입니다.
