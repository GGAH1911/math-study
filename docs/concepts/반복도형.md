### 정확한 진술

반복도형(또는 반복패턴도형)이란, 초기 도형에서 시작하여 매 단계마다 같은 규칙에 따라 도형의 일부를 변형하거나 추가하기를 무한히 반복할 때 만들어지는 도형입니다. 각 단계 $n$에서 도형의 길이, 넓이, 개수 등이 수열 $\{a_n\}$을 이루며, 무한 반복 후의 극한값 $\lim_{n \to \infty} a_n$으로 도형의 최종 성질을 결정합니다.

### 직관과 기하적 의미

반복도형은 **자기 유사성(self-similarity)**을 갖습니다. 즉, 전체 도형의 일부가 전체와 닮음 관계에 있습니다. 예를 들어 선분을 3등분하여 중간 부분을 정삼각형으로 바꾸는 과정을 무한히 반복하면, 각 단계마다 도형의 둘레는 늘어나지만 넓이는 유한합니다. 

수열의 극한 개념으로 이를 분석합니다. $n$ 단계에서 둘레의 길이를 $L_n$, 넓이를 $S_n$이라 하면, $\lim_{n \to \infty} L_n$과 $\lim_{n \to \infty} S_n$을 구해 최종 도형의 특성을 파악하는 것이 핵심입니다.

### 구체적 예

**코흐 곡선(Koch Curve):** 초기값 선분의 길이를 1이라 할 때, 매 단계마다 각 선분을 3등분하여 중간 부분을 정삼각형으로 교체합니다.
- $n$ 단계 둘레: $L_n = \left(\frac{4}{3}\right)^n$ (무한히 증가)
- 넓이: 유한한 값으로 수렴

(`sympy.limit((4/3)**n, n, oo)` 확인 시 발산)

따라서 "무한히 긴 경계를 가지면서도 유한한 넓이를 갖는 도형"이라는 반직관적 현상을 경험하게 됩니다. 이는 고등학교 급변 모양 도형 문제에서 매우 자주 출제되는 패턴입니다.
