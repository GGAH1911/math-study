### 정확한 진술

함수 $f$가 점 $x = a$에서 **극값**을 가지려면:
1. $f'(a) = 0$ 또는 $f'(a)$가 정의되지 않고,
2. $x = a$의 좌우에서 $f'(x)$의 **부호가 바뀌어야** 합니다.

**극값 판정법**은 이 조건을 확인하는 두 가지 방법입니다:
- **1차 판정법**: 도함수의 부호 변화로 극댓값과 극솟값을 구분
- **2차 판정법**: $f'(a) = 0$일 때, $f''(a)$의 부호로 판정 (계산이 간편)

### 직관과 기하적 의미

극값은 함수의 그래프에서 **봉우리(극대)**나 **계곡(극소)**에 해당합니다. 도함수 $f'(x)$는 순간변화율이므로:
- $f'(x)$가 양 → 음으로 바뀌는 점: 함수가 증가하다가 감소 → **극댓값**
- $f'(x)$가 음 → 양으로 바뀌는 점: 함수가 감소하다가 증가 → **극솟값**

도함수의 부호가 바뀌지 않으면 극값이 아닙니다. 예를 들어 $f'(a) = 0$이지만 양쪽에서 $f'(x) > 0$이면, 그 점은 변곡점일 뿐 극값이 아닙니다.

### 예: $f(x) = x^3 - 3x$

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 $f'(x) = 0$일 때 $x = -1, 1$

- $x < -1$: $f'(x) > 0$ (증가)
- $-1 < x < 1$: $f'(x) < 0$ (감소)  
- $x > 1$: $f'(x) > 0$ (증가)

따라서 $x = -1$에서 **극댓값** $f(-1) = 2$, $x = 1$에서 **극솟값** $f(1) = -2$를 가집니다.

(검산: `sympy.solve(3*x**2 - 3, x)` → `[-1, 1]`)
