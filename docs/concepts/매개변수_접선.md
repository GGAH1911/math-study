# 매개변수 접선

> **예제** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
$x=\cos t, y=\sin t$

## 본문 (학습 시 채워짐)

### 문제

매개변수 방정식 $x = \cos t, y = \sin t$로 나타낸 곡선(단위원) 위의 점 $t = \frac{\pi}{4}$에서의 접선의 방정식을 구하시오.

### 단계별 풀이

**1단계: 주어진 점의 좌표를 구한다**  
$t = \frac{\pi}{4}$를 대입하여 곡선 위의 점을 찾아야 한다.
$$x = \cos \frac{\pi}{4} = \frac{\sqrt{2}}{2}, \quad y = \sin \frac{\pi}{4} = \frac{\sqrt{2}}{2}$$
따라서 점은 $\left(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right)$이다.

**2단계: 각 매개변수를 $t$에 대해 미분한다**  
연쇄법칙을 적용하려면 $\frac{dx}{dt}$와 $\frac{dy}{dt}$가 필요하다.
$$\frac{dx}{dt} = -\sin t, \quad \frac{dy}{dt} = \cos t$$

**3단계: $t = \frac{\pi}{4}$에서의 미분값을 계산한다**  
구한 도함수에 $t = \frac{\pi}{4}$를 대입한다.
$$\frac{dx}{dt}\bigg|_{t=\pi/4} = -\sin \frac{\pi}{4} = -\frac{\sqrt{2}}{2}, \quad \frac{dy}{dt}\bigg|_{t=\pi/4} = \cos \frac{\pi}{4} = \frac{\sqrt{2}}{2}$$

**4단계: 접선의 기울기를 구한다**  
매개변수 미분의 핵심: $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$ (단, $\frac{dx}{dt} \neq 0$)
$$\frac{dy}{dx}\bigg|_{t=\pi/4} = \frac{\sqrt{2}/2}{-\sqrt{2}/2} = -1$$

**5단계: 점-기울기 형태로 접선의 방정식을 쓴다**  
점 $\left(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right)$를 지나고 기울기가 $-1$인 직선이다.
$$y - \frac{\sqrt{2}}{2} = -1 \cdot \left(x - \frac{\sqrt{2}}{2}\right)$$
$$y = -x + \sqrt{2}$$

### 답

$$y = -x + \sqrt{2}$$

또는 일반형: $x + y = \sqrt{2}$

### 변형/주의

**변형:** 다른 점에서의 접선을 구하려면, 예를 들어 $t = \frac{\pi}{3}$일 때도 같은 과정을 반복하면 된다. 

**주의:** 매개변수 미분에서 $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$는 $\frac{dx}{dt} \neq 0$일 때만 성립한다. 이 문제의 경우 $t = \frac{\pi}{4}$에서 $\frac{dx}{dt} = -\frac{\sqrt{2}}{2} \neq 0$이므로 문제없다.

검산 (sympy): `solve(Eq(-sin(pi/4), -sqrt(2)/2)) → True`, `cos(pi/4) == sqrt(2)/2 → True`
