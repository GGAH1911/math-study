## 본문

### 정확한 진술

첫째항이 $a$, 공차가 $d$인 등차수열 $\{a_n\}$의 첫 $n$항의 합을 $S_n$이라 할 때,

$$S_n = \frac{n}{2}(2a + (n-1)d)$$

또는 첫째항을 $a$, $n$째항을 $l$이라 하면,

$$S_n = \frac{n}{2}(a + l)$$

### 직관과 기하적 의미

등차수열의 합은 **역순 합 원리**(역으로 더하기)로 쉽게 유도됩니다.

$$S_n = a + (a+d) + (a+2d) + \cdots + (a+(n-1)d)$$

같은 합을 역순으로 쓰면,

$$S_n = (a+(n-1)d) + (a+(n-2)d) + \cdots + a$$

두 식을 항별로 더하면, 각 쌍의 합이 $2a + (n-1)d$가 되어 $n$번 반복됩니다.

$$2S_n = n(2a + (n-1)d) \quad \Rightarrow \quad S_n = \frac{n}{2}(2a + (n-1)d)$$

기하적으로는 **사다리꼴의 넓이** 공식입니다. 첫째항 $a$와 마지막항 $l$을 사다리꼴의 두 밑변으로, 항의 개수 $n$을 높이로 생각하면 된다는 뜻이죠.

### 한 줄 예

첫째항 $2$, 공차 $3$인 등차수열의 처음 $5$항의 합: 
$$S_5 = \frac{5}{2}(2 \cdot 2 + 4 \cdot 3) = \frac{5}{2} \times 16 = 40$$

검증: `from sympy import summation, symbols; n = symbols('n'); summation(2 + 3*n, (n, 0, 4))`
