### 정확한 진술

방정식 $f(x) = c$ (단, $c$는 상수)의 **실근의 개수를 판정**한다는 것은, 함수 $f(x)$의 극값과 함수값의 범위를 이용하여 주어진 수평선 $y = c$와 곡선 $y = f(x)$가 만나는 점의 개수를 구하는 과정입니다. 특히 다항함수의 경우, 도함수 $f'(x)$를 이용해 극값을 구하고 함수의 개형을 파악하여 판정합니다.

### 직관/기하적 의미

함수 $y = f(x)$의 그래프 위에 수평선 $y = c$를 그었을 때, 두 그래프가 만나는 점의 개수가 곧 방정식의 실근 개수입니다. 도함수를 이용하면:

- $f'(x) = 0$인 점에서 극값(극댓값 또는 극솟값)을 판정
- 극댓값을 $M$, 극솟값을 $m$이라 하면 ($m < M$)
- $c$의 값에 따라 근의 개수가 결정됩니다

**판정 기준** (삼차함수 기준):
$$c > M \text{ 또는 } c < m \Rightarrow \text{근 1개}$$
$$c = M \text{ 또는 } c = m \Rightarrow \text{근 2개}$$
$$m < c < M \Rightarrow \text{근 3개}$$

### 한 줄 예

$f(x) = x^3 - 3x + 1$에서 방정식 $f(x) = 0$의 실근 개수를 판정하려면, 먼저 $f'(x) = 3x^2 - 3 = 0$으로 극값을 구한 후, $x = \pm 1$에서의 함수값을 비교하여 $0$이 극댓값과 극솟값 사이에 있는지 확인합니다. (sympy로 확인: `sympy.solve(3*x**2 - 3, x)` → $x = \pm 1$에서 $f(-1) = 3$, $f(1) = -1$이므로 $-1 < 0 < 3$ → **근 3개**)
