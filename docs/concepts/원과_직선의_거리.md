### 정확한 진술

원의 중심을 $C(x_0, y_0)$, 반지름을 $r$이라 할 때, 직선 $ax + by + c = 0$까지의 거리를 **원과 직선의 거리**라 정의합니다. 이 거리는 원의 중심에서 직선까지의 최단 거리이며, 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미

기하학적으로, 원과 직선의 거리는 원의 중심에서 직선에 내린 수선의 발까지의 거리입니다. 이 거리 $d$와 반지름 $r$을 비교하면 원과 직선의 위치 관계를 판정할 수 있습니다:

- $d > r$: 직선이 원과 만나지 않음 (원의 외부)
- $d = r$: 직선이 원에 접함 (한 점에서 만남)  
- $d < r$: 직선이 원 내부를 지나가며 두 점에서 만남

원의 중심에서 직선까지의 최단 거리는 항상 수선의 길이이므로, 이 거리가 모든 위치 판정의 기초가 됩니다.

### 한 줄 예

원 $(x-1)^2 + (y-2)^2 = 4$ (중심 $(1,2)$, 반지름 $2$)와 직선 $x + 2y - 5 = 0$ 사이의 거리는:

$$d = \frac{|1 + 2(2) - 5|}{\sqrt{1^2 + 2^2}} = \frac{|0|}{\sqrt{5}} = 0$$

원의 중심이 직선 위에 있으므로 $d = 0 < r$이고, 따라서 직선은 원의 중심을 지나 두 점에서 만납니다.
