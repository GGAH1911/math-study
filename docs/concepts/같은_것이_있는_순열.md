### 정확한 진술

같은 것이 있는 순열이란, 원소 중 일부가 구별되지 않을 때 배열하는 경우의 수를 구하는 것입니다. 

전체 $n$개 원소 중에서 같은 종류 $A$가 $p$개, 같은 종류 $B$가 $q$개, ..., 같은 종류 $Z$가 $r$개 있을 때 $(p+q+\cdots+r=n)$, 이들을 모두 배열하는 경우의 수는

$$\frac{n!}{p! \cdot q! \cdot \cdots \cdot r!}$$

입니다.

### 직관과 의미

만약 모든 원소가 서로 다르다면, 순열의 개수는 $n!$입니다. 하지만 같은 것들이 있으면, 그것들을 서로 바꿔도 같은 배열이 됩니다. 예를 들어 '빨, 빨, 파' 세 공을 배열할 때, 두 개의 빨간 공이 구별된다고 생각하면 $3! = 6$가지이지만, 실제로는 빨간 공끼리 바꾸는 $2!$가지가 모두 같으므로 $\frac{3!}{2!} = 3$가지만 다릅니다. 분모의 각 팩토리얼은 같은 종류끼리의 "중복"을 제거하는 역할입니다.

### 한 줄 예

'빨강, 빨강, 파랑, 초록' 4개를 배열하면 $\dfrac{4!}{2!} = 12$가지입니다.

### 계산 확인

```python
import math
math.factorial(4) // math.factorial(2)  # 12
```
