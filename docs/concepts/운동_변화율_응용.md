# 운동 변화율 응용

> **예제** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)

## 요약
속도·가속도·거리

## 본문 (학습 시 채워짐)

### 문제

어떤 물체의 위치(m)가 시간 $t$(초)에 대해 $s(t) = 2t^3 - 15t^2 + 36t$ (단, $0 \le t \le 5$)로 주어집니다. 다음을 구하세요.

1. $t=2$초일 때 속도
2. 물체가 정지하는 시간
3. 가속도가 0인 시간에서의 속도

### 단계별 풀이

**속도 함수 구하기**  
속도는 위치의 시간에 대한 도함수이므로 위치 함수를 미분합니다:
$$v(t) = s'(t) = 6t^2 - 30t + 36$$

**$t=2$초일 때 속도 계산**  
구한 속도 함수에 $t=2$를 대입하면:
$$v(2) = 6(4) - 30(2) + 36 = 24 - 60 + 36 = 0 \text{ m/s}$$
물체가 그 시각에 정지 상태입니다.

**속도가 0인 모든 시간 찾기**  
$v(t) = 0$을 풀기 위해 식을 간단히 합니다:
$$6t^2 - 30t + 36 = 0 \implies t^2 - 5t + 6 = 0 \implies (t-2)(t-3) = 0$$
따라서 $t = 2$초와 $t = 3$초에 정지합니다.

**가속도 함수와 가속도가 0인 시간**  
가속도는 속도의 시간에 대한 도함수입니다:
$$a(t) = v'(t) = 12t - 30$$
$a(t) = 0$일 때: $t = 2.5$초. 이때의 속도는:
$$v(2.5) = 6(2.5)^2 - 30(2.5) + 36 = 37.5 - 75 + 36 = -1.5 \text{ m/s}$$

### 답

1. $v(2) = 0$ m/s
2. 정지 시간: $t=2$초, $t=3$초  
3. 가속도 0일 때의 속도: $v(2.5) = -1.5$ m/s

### 변형 및 주의

- **음의 속도의 해석**: $v(2.5) = -1.5 < 0$은 물체가 역방향(음의 방향)으로 움직인다는 뜻입니다. $t=2$에서 $t=3$ 사이에 운동 방향이 바뀝니다.
- **속도와 속력 구분**: 속도는 방향을 포함한 벡터량(음수 가능)이고, 속력은 크기만 다루는 스칼라량(항상 양수)입니다.
- **물리적 의미**: 가속도가 0인 순간(여기서 $t=2.5$초)은 물체가 속도 변화를 멈추는 순간이지, 정지하는 것이 아닙니다. 실제로 그때 역방향으로 빠르게 움직이고 있습니다.
- **검산**: `sympy.solve(6*t**2 - 30*t + 36, t)` → $[2, 3]$
