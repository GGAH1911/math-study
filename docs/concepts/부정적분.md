# 부정적분

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
$\int f(x)dx=F(x)+C$

## 본문 (학습 시 채워짐)

### 정의

$F(x)$를 미분하면 $f(x)$가 되는 함수를 $f(x)$의 **부정적분** 또는 **원시함수**라 한다. 즉, $F'(x) = f(x)$일 때,

$$\int f(x)\,dx = F(x) + C$$

로 표기한다. 여기서 $C$는 **적분상수**(임의의 상수)이다.

### 적분상수는 왜 붙을까?

$F'(x) = f(x)$이면 $[F(x) + C]' = f(x)$도 성립한다. 상수를 미분하면 0이 되기 때문이다. 따라서 $f(x)$를 미분해서 얻을 수 있는 함수는 무한히 많다. 예를 들어 $(x^2)' = 2x$, $(x^2 + 1)' = 2x$, $(x^2 - 5)' = 2x$이므로, $2x$의 부정적분은 $x^2$, $x^2 + 1$, $x^2 - 5$, ... 모두 다르다. 이 모든 경우를 한 번에 나타내기 위해 $\int 2x\,dx = x^2 + C$로 쓴다.

### 기하학적 의미

$y = f(x)$의 모든 부정적분 $y = F(x) + C$는 **수직 방향으로 평행이동한 곡선들의 모임**이다. 같은 함수를 미분한 것이므로 모든 점에서 기울기가 동일하며, $C$ 값에 따라 상하로 평행이동한다.

### 간단한 예

$\int 4x^3\,dx$를 구하자. $(x^4)' = 4x^3$이므로 답은 $x^4 + C$이다. (`from sympy import *; diff(x**4, x)` → $4x^3$)
