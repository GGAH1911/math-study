# 정적분의 미분

## 요약
함수의 연속성을 전제로 할 때, 정적분으로 정의된 함수를 미분하면 피적분 함수가 됩니다.

## 본문
함수 $f(x)$가 닫힌 구간 $[a, b]$에서 연속일 때, $x$에 대한 함수 $F(x) = \int_{a}^{x} f(t) dt$를 미분하면 $F'(x) = f(x)$가 성립합니다. 이는 미분과 적분이 서로 역연산 관계에 있음을 보여주는 핵심적인 정리입니다. 특히 적분 구간의 상한이 $x$인 함수를 미분하면 피적분 함수에 $x$를 대입한 값과 같아지며, 이는 미적분학의 기본 정리 중 하나로 매우 중요한 의미를 갖습니다.

### 직관과 기하적 의미
정적분 $\int_{a}^{x} f(t) dt$는 구간 $[a, x]$에서 함수 $f(t)$가 만드는 곡선 아래의 넓이를 의미합니다. 여기서 $x$가 아주 미세하게 $\Delta x$만큼 증가할 때, 넓이의 변화량은 밑변의 길이 $\Delta x$와 높이 $f(x)$의 곱에 근사하게 됩니다. 따라서 변화율인 미분값은 높이인 $f(x)$ 그 자체가 됩니다.

### 기본 성질
1. 적분 구간의 상한이 변수 $x$인 함수 $F(x) = \int_{a}^{x} f(t) dt$를 미분하면 $F'(x) = f(x)$입니다.
2. 적분 구간에 $x$에 관한 식 $g(x)$가 포함된 경우, 합성함수의 미분법에 의해 $\tfrac{d}{dx} \int_{a}^{g(x)} f(t) dt = f(g(x)) \cdot g'(x)$가 성립합니다.
3. 적분 구간이 상수인 경우, 즉 $\int_{a}^{b} f(t) dt$와 같이 상수가 되면 미분값은 $0$이 됩니다.

## 학습 체크
- 적분 구간의 상한이 $x$가 아닌 $x^2$과 같은 함수일 때, 미분 시 연쇄 법칙을 올바르게 적용하였는가?
- 피적분 함수 $f(t)$가 해당 구간에서 연속이라는 조건이 왜 필요한지 이해하고 있는가?

## 관련 개념
- **정적분의 활용**: 정적분으로 정의된 함수를 미분하여 함수의 극값이나 그래프의 개형을 파악하는 데 사용됩니다.
