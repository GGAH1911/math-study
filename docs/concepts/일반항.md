### 정확한 진술

수열 $\{a_n\}$에서 **일반항** $a_n$은 $n$번째 항을 $n$에 대한 식으로 나타낸 것입니다. 즉, 임의의 양의 정수 $n$에 대해 항의 값을 결정하는 함수관계식입니다.

예를 들어 수열이 $a_1, a_2, a_3, \ldots$로 주어질 때, 일반항 $a_n$을 알면 수열의 모든 항을 구할 수 있습니다.

### 직관적 의미

수열을 명시하는 방법은 여러 가지입니다. 
- 첫 몇 항을 나열: $2, 4, 6, 8, \ldots$
- 일반항으로 표현: $a_n = 2n$

일반항은 수열을 **단 하나의 식**으로 완전히 결정하는 가장 효율적인 방법입니다. 첫 번째 항부터 100번째 항까지 일일이 쓰지 않고, $a_n = 2n$이라는 한 식만 있으면 어떤 번째 항의 값도 즉시 구할 수 있습니다.

기하적으로는, 일반항 $a_n = f(n)$을 정의역이 양의 정수인 함수로 볼 수 있습니다. 이를 좌표평면에 나타내면 점들 $(1, a_1), (2, a_2), (3, a_3), \ldots$의 배열이 됩니다.

### 핵심 예제

수열 $1, 4, 9, 16, 25, \ldots$는 일반항 $a_n = n^2$으로 나타냅니다.
- $a_1 = 1^2 = 1$
- $a_2 = 2^2 = 4$  
- $a_3 = 3^2 = 9$

```python
# 일반항 a_n = n^2에서 n=10일 때의 항값
a_n = lambda n: n**2
print(a_n(10))  # 100
```

### 중요한 구분

일반항은 **수열 전체를 정의**하므로, 같은 수열이라도 일반항 표현이 유일하지는 않을 수 있습니다. 중요한 것은 각 $n$에 대해 항의 값이 일관되게 결정된다는 점입니다. 고등학교 과정에서는 주로 등차수열, 등비수열, 그리고 점화식으로 정의된 수열의 일반항을 구하는 문제를 다룹니다.
