# 수열

> **단원** · 수학1 · 선수: [함수와 그래프](./함수와_그래프.md) · 다음: 없음 (말단 노드 / Phase 1에서 미정의)

## 학습 목표
- 등차·등비수열의 일반항과 합을 구한다
- 시그마 기호와 수학적 귀납법을 다룬다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 등차수열, 공차
- 등비수열, 공비
- 시그마 $\sum$
- 수학적 귀납법

**정리(theorem)**
- 등차수열의 합 $S_n=\frac{n(a_1+a_n)}{2}$
- 등비수열의 합 (공비 $r\neq 1$)
- 귀납법: 기초단계 + 귀납단계

**예제(example)**
- 일반항 구하기
- 시그마 계산
- 귀납법 증명
