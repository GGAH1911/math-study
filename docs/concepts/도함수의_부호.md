### 정확한 진술

함수 $f(x)$가 어떤 구간에서 미분가능할 때, 그 구간에서:
- $f'(x) > 0$이면 $f(x)$는 그 구간에서 **증가**합니다
- $f'(x) < 0$이면 $f(x)$는 그 구간에서 **감소**합니다
- $f'(x) = 0$인 점을 **극값의 후보**(극댓값/극솟값 또는 변곡점)라 합니다

### 직관과 기하적 의미

도함수 $f'(x)$는 각 점에서 함수의 **순간변화율**을 나타냅니다. $f'(x) > 0$이라는 것은 "$x$가 조금 증가할 때 $f(x)$도 증가한다"는 뜻이고, $f'(x) < 0$이면 $x$가 증가할 때 $f(x)$는 감소합니다.

**그래프 관점에서:**
- $f'(x) > 0$인 구간: 그래프가 **왼쪽 아래에서 오른쪽 위로** 올라갑니다
- $f'(x) < 0$인 구간: 그래프가 **왼쪽 위에서 오른쪽 아래로** 내려갑니다

$f'(x) = 0$인 점은 접선의 기울기가 0, 즉 **접선이 수평**인 지점입니다. 이곳은 극값 또는 변곡점이 될 수 있으므로 더 자세한 검토가 필요합니다.

### 한 줄 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$

- $x < -1$일 때: $f'(x) > 0$ (함수 증가)
- $-1 < x < 1$일 때: $f'(x) < 0$ (함수 감소)  
- $x > 1$일 때: $f'(x) > 0$ (함수 증가)
- $x = -1$에서 극댓값, $x = 1$에서 극솟값

(`sympy.solve(3*x**2 - 3, x)` → $[-1, 1]$)
