# 등식의 항등성

## 요약
변수에 어떤 값을 대입해도 항상 성립하는 등식을 항등식이라 하며, 계수비교법과 수치대입법을 통해 미지의 계수를 구할 수 있다.

## 본문
등식의 항등성이란 어떤 등식이 변수에 어떤 값을 대입하더라도 항상 성립하는 성질을 의미한다. 이처럼 항등성을 갖는 등식을 항등식이라고 한다. 다항식에서 항등성이 중요한 이유는 두 다항식이 항등식을 이룰 때 다음 두 가지 성질이 동시에 성립하기 때문이다. 첫째, 계수비교법에 의해 양변에서 같은 차수의 항의 계수가 서로 같아야 한다. 둘째, 수치대입법에 의해 변수에 어떤 특정한 값을 대입해도 등식이 성립해야 한다. 이 두 성질은 미지의 계수를 결정할 때 매우 강력한 도구가 된다.

**예 1.** 등식 $ax^2 + bx + c = 3x^2 - 5x + 2$ 가 모든 실수 $x$ 에 대해 성립하면, 계수를 비교하여 $a = 3, b = -5, c = 2$ 를 얻는다.

**예 2.** 등식 $(x+1)(x+a) = x^2 + bx + 3$ 이 항등식일 때, 좌변을 전개하면 $x^2 + (a+1)x + a$ 이므로 상수항을 비교하면 $a = 3$, $x$ 의 계수를 비교하면 $b = a + 1 = 4$ 이다. 또는 수치대입법으로 $x = 0$ 을 대입하면 $a = 3$ 을 바로 구할 수 있다.

### 직관과 기하적 의미
항등식은 그래프로 나타냈을 때 두 함수가 나타내는 곡선이 완전히 일치하는 상태와 같다. 즉, $x$ 축 위의 어떤 지점을 선택하더라도 두 함수의 $y$ 값이 항상 같으므로, 두 그래프가 겹쳐져 있는 형태를 띤다.

### 기본 성질
- 계수비교법: 양변의 동차항 계수가 일치함을 이용한다.
- 수치대입법: 변수에 적절한 값을 대입하여 식을 단순화한 뒤 계수를 찾는다.

- 항등식을 풀 때 계수비교법과 수치대입법 중 어떤 방법이 더 효율적인가?

## 관련 개념

- **다항식**: 항등식의 양변은 각각 다항식이므로, 항등성의 판단과 계수 비교는 다항식의 덧셈·전개 연산을 기반으로 한다.
- **항등식**: 등식의 항등성이 성립하는 등식이 바로 항등식이다. 특정 값에서만 성립하는 방정식과 구별하는 것이 핵심이다.
- **미정계수법**: 항등성을 이용해 다항식 안의 미지 계수를 결정하는 대표적인 기법으로, 계수비교법과 수치대입법이 모두 이 개념에서 출발한다.
- **다항식의 나눗셈**: 나머지정리·인수정리에서 등장하는 등식 $f(x) = Q(x) \cdot (x - a) + R$ 도 항등식이며, 여기에 수치대입법을 적용해 나머지 $R$ 을 구한다.
