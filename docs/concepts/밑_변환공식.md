### 정확한 진술

어떤 밑을 가진 로그든 다른 밑의 로그로 나타낼 수 있습니다. **밑 변환공식**은 다음과 같습니다:

$$\log_a b = \frac{\log_c b}{\log_c a}$$

단, $a, b, c > 0$이고 $a \neq 1$, $c \neq 1$입니다. 우변의 로그는 같은 밑 $c$를 가지면 되는데, 보통 자연로그 $\ln$ (밑 $e$) 또는 상용로그 $\log_{10}$ (밑 10)을 선택합니다.

### 직관: 왜 필요한가?

실제로 계산기나 컴퓨터는 특정 밑의 로그만 계산해 줍니다 (보통 $\ln$이나 $\log_{10}$). 따라서 $\log_2 8$이나 $\log_5 125$ 같은 임의의 밑을 가진 로그를 구할 때, 계산 가능한 밑으로 변환해야 합니다. 또한 로그 방정식을 풀 때도, 모든 로그를 같은 밑으로 통일하려면 이 공식이 필수입니다.

### 증명 스케치

$\log_a b = x$라고 하면, 정의에 의해 $a^x = b$입니다. 양변에 $\log_c$를 취하면:

$$\log_c(a^x) = \log_c b$$
$$x \log_c a = \log_c b$$
$$x = \frac{\log_c b}{\log_c a}$$

따라서 $\log_a b = \frac{\log_c b}{\log_c a}$입니다.

### 계산 예

$\log_2 16$을 자연로그로 변환하면:

$$\log_2 16 = \frac{\ln 16}{\ln 2} = \frac{\ln 2^4}{\ln 2} = \frac{4\ln 2}{\ln 2} = 4$$

(검산: `sympy.log(16, 2)` 또는 `sympy.log(16)/sympy.log(2)` → 4)

실제로 로그의 정의에서 $2^4 = 16$이므로 답이 맞습니다.
