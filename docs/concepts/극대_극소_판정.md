# 극대 극소 판정

## 요약
함수의 도함수가 $0$이 되는 지점의 좌우 부호 변화를 통해 함수의 극대와 극소를 판정할 수 있습니다.

## 본문
함수 $f(x)$가 어떤 점 $a$ 근처에서 정의되고 미분 가능할 때, $f'(a)=0$이면서 $a$의 왼쪽에서 $f'(x)$의 부호가 양수에서 음수로 변하면 $f(a)$는 극대이고, 반대로 음수에서 양수로 변하면 $f(a)$는 극소입니다. 만약 $f'(x)$의 부호가 변하지 않는다면 그 점은 극점이 아닙니다.

### 직관과 기하적 의미
함수의 그래프가 위로 볼록하게 꺾이며 정점을 찍을 때는 접선의 기울기가 양수에서 음수로 변하며, 아래로 볼록하게 꺾이며 골짜기를 형성할 때는 기울기가 음수에서 양수로 변합니다. 즉, 도함수의 부호 변화는 함수의 증가와 감소가 바뀌는 지점을 찾는 과정과 같습니다.

### 기본 성질
함수가 미분 가능할 때 극점에서는 반드시 $f'(x)=0$을 만족해야 합니다. 다만, $f'(a)=0$이라고 해서 반드시 극점인 것은 아니며, 반드시 좌우에서의 부호 변화를 확인해야 합니다.

## 학습 체크
- $f'(a)=0$이지만 극점이 아닌 사례(예: $f(x)=x^3$)를 구분할 수 있는가?
- 도함수의 부호가 양수에서 음수로 변할 때 그래프의 개형을 정확히 그릴 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증감과 극값을 이용하여 함수의 그래프 개형을 정밀하게 추론하는 과정으로 연결됩니다.
