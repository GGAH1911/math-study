### 정확한 진술

집합은 **구별되는 객체들을 모아 하나의 대상으로 본 것**입니다. 집합을 이루는 각각의 객체를 **원소**라 하고, 원소 $a$가 집합 $A$에 속하면 $a \in A$로 나타냅니다. 원소가 속하지 않으면 $a \notin A$로 씁니다.

집합은 다음과 같이 표현합니다:
- **원소 나열법**: $A = \{1, 3, 5, 7\}$
- **조건 제시법**: $B = \{x \mid x \text{는 홀수}, 1 \le x \le 10\}$

핵심은 어떤 대상이 집합에 속하는지 속하지 않는지가 명확해야 한다는 점입니다. "큰 수의 모임"은 집합이 아니지만, "10보다 큰 정수의 모임"은 집합입니다.

### 직관/기하적 의미

집합은 **명확한 기준으로 구분되는 것들의 모음**이라고 생각하면 됩니다. 실수 한 줄로 그린 선 위에 점들을 표시한다면, 그 점들의 모임도 집합입니다. 예를 들어 수직선 위에서 $-1$부터 $3$ 사이의 모든 정수를 표시하면, 그것은 $\{-1, 0, 1, 2, 3\}$이라는 집합입니다.

**원소의 개수**에 따라 집합을 분류합니다:
- **유한집합**: 원소가 유한개인 집합 (예: $\{2, 4, 6, 8\}$)
- **무한집합**: 원소가 무한개인 집합 (예: 모든 실수의 집합 $\mathbb{R}$)
- **공집합** $\emptyset$ 또는 $\{\}$: 원소가 없는 집합

### 한 줄 예

$A = \{x \mid x \text{는 소수}, x < 10\}$라 하면 $A = \{2, 3, 5, 7\}$이고, $2 \in A$, $4 \notin A$입니다.
