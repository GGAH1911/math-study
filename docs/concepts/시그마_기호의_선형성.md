### 정확한 진술

시그마 기호의 **선형성**은 다음 두 가지 성질을 의미합니다.

**덧셈의 성질**: 
$$\sum_{i=1}^{n} (a_i + b_i) = \sum_{i=1}^{n} a_i + \sum_{i=1}^{n} b_i$$

**상수배의 성질**: 
$$\sum_{i=1}^{n} c \cdot a_i = c \sum_{i=1}^{n} a_i$$
(단, $c$는 상수)

이 두 성질을 합치면, 일반적으로 
$$\sum_{i=1}^{n} (c_1 a_i + c_2 b_i) = c_1 \sum_{i=1}^{n} a_i + c_2 \sum_{i=1}^{n} b_i$$
가 성립합니다.

### 직관적 의미

덧셈의 성질은 "여러 개를 모두 더한 것 + 여러 개를 모두 더한 것 = 항끼리 더한 것을 모두 더한 것"이라는 당연한 사실입니다. 예를 들어, 1월 판매액 + 2월 판매액 = (1월 A상품 + 1월 B상품) + (2월 A상품 + 2월 B상품) = (1월 A상품 + 2월 A상품) + (1월 B상품 + 2월 B상품)처럼, 합하는 순서를 바꾸어도 같다는 뜻입니다.

상수배의 성질은 "같은 값을 $n$번 더한 결과에 $c$를 곱한 것 = 각 항에 먼저 $c$를 곱하고 모두 더한 것"으로, 분배 법칙의 확장입니다. 이 성질들이 있으므로 복잡한 합을 단순화하거나, 합의 공식을 유도할 때 시그마를 하나씩 분리해서 다룰 수 있습니다.

### 한 줄 예

$\sum_{i=1}^{4} (2i + 3) = 2\sum_{i=1}^{4} i + \sum_{i=1}^{4} 3 = 2 \cdot 10 + 12 = 32$ (검증: $5+7+9+11=32$ ✓)
