# 단측극한

함수 $f(x)$에서 $x$가 어떤 값 $a$에 가까워질 때, 접근하는 방향을 한쪽으로 제한한 극한을 **단측극한**이라 한다.

$x$가 $a$보다 작은 쪽에서 $a$로 가까워질 때의 극한을 **좌극한**이라 하고,

$$\lim_{x \to a^-} f(x)$$

로 나타낸다. 반대로 $x$가 $a$보다 큰 쪽에서 가까워질 때의 극한을 **우극한**이라 하고,

$$\lim_{x \to a^+} f(x)$$

로 나타낸다.

함수 $f(x)$의 $x = a$에서의 극한값이 존재하려면, 좌극한과 우극한이 모두 존재하고 그 값이 서로 같아야 한다. 즉,

$$\lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L$$

이 조건이 하나라도 어긋나면 $x = a$에서의 극한은 존재하지 않는다.

## 예시

**예시 1.** 절댓값이 포함된 함수 $f(x) = \dfrac{|x|}{x}$에서 $x = 0$의 단측극한을 구해 보자.

$x < 0$이면 $|x| = -x$이므로 $f(x) = -1$, 따라서

$$\lim_{x \to 0^-} f(x) = -1$$

$x > 0$이면 $|x| = x$이므로 $f(x) = 1$, 따라서

$$\lim_{x \to 0^+} f(x) = 1$$

좌극한과 우극한이 다르므로 $x = 0$에서 극한값은 존재하지 않는다.

**예시 2.** 가우스 함수 $f(x) = [x]$ ($x$를 넘지 않는 최대 정수)에서 $x = 2$의 단측극한을 구해 보자.

$x$가 2보다 조금 작을 때 $[x] = 1$이므로

$$\lim_{x \to 2^-} [x] = 1$$

$x$가 2보다 조금 클 때 $[x] = 2$이므로

$$\lim_{x \to 2^+} [x] = 2$$

역시 두 값이 달라 $x = 2$에서 극한이 존재하지 않는다. 정수점마다 이런 불연속이 반복된다.

## 관련 개념

**함수의 극한**은 단측극한의 바탕이 되는 개념이다. 양쪽 방향을 동시에 고려하는 일반 극한은 "좌극한 = 우극한"일 때 비로소 정의되므로, 단측극한은 극한 존재 여부를 판단하는 가장 기본 도구다.

**여러 가지 함수의 극한**을 다룰 때 단측극한이 특히 중요하게 쓰인다. 절댓값 함수·가우스 함수·분할 정의 함수처럼 특정 점을 기준으로 식이 달라지는 함수는 일반 극한으로 바로 접근하면 모순이 생길 수 있으므로, 방향을 나눠 단측극한을 먼저 구한 뒤 비교하는 방식으로 분석한다.

**함수의 연속**과도 직결된다. $f(x)$가 $x = a$에서 연속이 되려면 극한값이 존재해야 하고, 그러려면 단측극한이 일치해야 한다. 단측극한이 엇갈리는 점은 반드시 불연속점이 된다.
