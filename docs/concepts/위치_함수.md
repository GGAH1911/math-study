### 정확한 진술

위치 함수(또는 변위 함수)는 시간 $t$에 따른 물체의 위치를 나타내는 함수로, 보통 $s(t)$ 또는 $x(t)$로 표기합니다. 위치 함수의 도함수는 속도 함수 $v(t) = s'(t)$이고, 속도 함수의 도함수는 가속도 함수 $a(t) = v'(t) = s''(t)$입니다.

### 정적분과의 관계

위치 함수와 정적분은 미적분학의 기본정리로 연결됩니다. 속도 함수 $v(t)$를 알 때, 시각 $t_1$에서 $t_2$까지 물체의 **변위**(위치 변화)는:

$$s(t_2) - s(t_1) = \int_{t_1}^{t_2} v(t) \, dt$$

이 식은 역으로 위치 함수를 구하는 데에도 사용됩니다. 속도 함수를 정적분하면 위치 함수(상수항 제외)를 얻을 수 있습니다. 

중요한 점은 **변위**와 **이동 거리**를 구분하는 것입니다. 변위는 최종 위치에서 초기 위치를 뺀 것(음수 가능)이지만, 이동 거리는 항상 양수이며 다음과 같이 구합니다:

$$\text{이동 거리} = \int_{t_1}^{t_2} |v(t)| \, dt$$

### 예제

속도가 $v(t) = 3t - 2$ (m/s)이고 초기 위치 $s(0) = 5$ m일 때, 위치 함수는:

$$s(t) = \int (3t - 2) \, dt = \frac{3t^2}{2} - 2t + C$$

초기조건 $s(0) = 5$를 적용하면 $C = 5$이므로:

$$s(t) = \frac{3t^2}{2} - 2t + 5 \text{ (m)}$$

$t = 2$초일 때 위치: $s(2) = 6 - 4 + 5 = 7$ m

검증: `from sympy import symbols, integrate; t = symbols('t'); v = 3*t - 2; s = integrate(v, t) + 5; s.subs(t, 2)` → `7`
