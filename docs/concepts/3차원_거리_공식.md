# 3차원 거리 공식

## 요약
공간 좌표에서 두 점 사이의 거리는 각 좌표 차이의 제곱 합에 제곱근을 취하여 구하며, 이는 평면 거리 공식의 확장된 형태이다.

## 본문
공간에서 두 점 $\mathrm{A}(x_1,\, y_1,\, z_1)$과 $\mathrm{B}(x_2,\, y_2,\, z_2)$ 사이의 거리는 $\overline{\mathrm{AB}} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$이다. 이 공식은 평면에서의 두 점 사이의 거리 공식을 공간으로 자연스럽게 확장한 것으로, 두 점의 $x$, $y$, $z$ 좌표 차이를 각각 구하여 제곱한 뒤 모두 더하고 그 값에 제곱근을 취하는 방식으로 계산한다. 이때 평면 공식과 비교하여 $z$ 좌표의 차이까지 포함된다는 점이 유일한 차이점이다.

### 직관과 기하적 의미
이 공식은 직육면체의 대각선 길이를 구하는 원리와 같다. 두 점을 대각선의 양 끝점으로 하는 직육면체를 상상했을 때, 각 변의 길이는 각 좌표의 차이와 같다. 특히 원점 $\mathrm{O}(0, 0, 0)$에서 점 $\mathrm{P}(a, b, c)$까지의 거리는 $\overline{\mathrm{OP}} = \sqrt{a^2 + b^2 + c^2}$로 간단히 나타낼 수 있으며, 이는 벡터 $\overrightarrow{\mathrm{OP}}$의 크기와 동일한 의미를 갖는다.

### 기본 성질
두 점 사이의 거리를 구할 때는 좌표의 차이를 제곱하므로, 좌표의 순서가 바뀌어도 결과값은 동일하다. 또한 원점으로부터의 거리를 구할 때는 좌표값 자체를 각각 제곱하여 합산하면 되므로 계산이 매우 간결해진다.

**예시 1.** 두 점 $\mathrm{A}(1, -2, 3)$과 $\mathrm{B}(4, 2, -1)$ 사이의 거리는
$$\overline{\mathrm{AB}} = \sqrt{(4-1)^2 + (2-(-2))^2 + (-1-3)^2} = \sqrt{9 + 16 + 16} = \sqrt{41}$$
이다.

**예시 2.** 점 $\mathrm{P}(2, 1, -2)$에서 원점까지의 거리는
$$\overline{\mathrm{OP}} = \sqrt{2^2 + 1^2 + (-2)^2} = \sqrt{4 + 1 + 4} = \sqrt{9} = 3$$
이다.

## 학습 체크
- 두 점 사이의 거리를 구할 때 $z$ 좌표의 차이를 포함하여 계산하였는가?
- 원점에서의 거리를 구할 때 좌표의 부호와 상관없이 제곱하여 계산하였는가?

## 관련 개념

**공간좌표** 는 공간의 한 점을 $(x, y, z)$의 세 수로 나타내는 체계로, 거리 공식의 출발점이다. 좌표 없이는 두 점을 수식으로 표현할 수 없으므로 반드시 선행되어야 한다.

**공간벡터의 크기** 와 거리 공식은 본질적으로 같은 계산이다. 두 점 $\mathrm{A}$, $\mathrm{B}$를 잇는 벡터 $\overrightarrow{\mathrm{AB}} = (x_2-x_1,\, y_2-y_1,\, z_2-z_1)$의 크기 $|\overrightarrow{\mathrm{AB}}|$가 곧 두 점 사이의 거리이므로, 거리와 벡터의 크기는 서로 같은 개념을 다른 언어로 표현한 것이다.

**구의 방정식** 을 다룰 때도 거리 공식이 핵심 역할을 한다. 중심이 $\mathrm{C}(a, b, c)$이고 반지름이 $r$인 구는 중심에서 거리가 $r$인 점 전체의 집합이므로, 거리 공식을 그대로 적용하면 $(x-a)^2 + (y-b)^2 + (z-c)^2 = r^2$ 가 된다. 거리 공식을 탄탄히 이해하면 구의 방정식도 외울 필요 없이 유도해 낼 수 있다.
