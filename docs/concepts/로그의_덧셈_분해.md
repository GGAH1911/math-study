# 로그의 덧셈 분해

## 요약
밑이 같은 두 로그의 합은 진수의 곱을 취한 하나의 로그로 나타낼 수 있으며, 이는 지수법칙에서 유도되는 성질이다.

## 본문
로그의 덧셈 분해는 두 로그의 합을 하나의 로그로 묶거나, 반대로 하나의 로그를 두 로그의 합으로 나누는 성질이다. 밑이 같은 두 로그에 대해 다음 식이 성립한다.
$$\log_a MN = \log_a M + \log_a N \quad (a > 0,\ a \neq 1,\ M > 0,\ N > 0)$$
이 성질은 지수법칙 $a^p \cdot a^q = a^{p+q}$ 에서 직접 유도된다. $\log_a M = p$, $\log_a N = q$ 로 놓으면 $MN = a^p \cdot a^q = a^{p+q}$ 이고, 양변에 밑이 $a$ 인 로그를 취하면 $\log_a MN = p + q = \log_a M + \log_a N$ 임을 확인할 수 있다. 즉, 진수의 곱셈이 로그의 덧셈으로, 로그의 덧셈이 진수의 곱셈으로 변환된다는 점이 핵심이다.

### 직관과 기하적 의미
지수에서 지수의 덧셈이 밑의 곱셈을 의미하듯, 로그는 지수를 다루는 연산이므로 지수의 덧셈은 진수의 곱셈에 대응한다. 이는 복잡한 곱셈 연산을 단순한 덧셈 연산으로 변환하여 계산의 효율성을 높여주는 역할을 한다.

### 기본 성질
**예 1.** $\log_2 3 + \log_2 4$ 를 간단히 하면
$$\log_2 3 + \log_2 4 = \log_2 (3 \times 4) = \log_2 12$$

**예 2.** $\log_{10} 25 + \log_{10} 4$ 를 계산하면
$$\log_{10} 25 + \log_{10} 4 = \log_{10} (25 \times 4) = \log_{10} 100 = 2$$
두 번째 예시처럼, 겉보기에 구하기 어려운 로그값도 덧셈 분해의 역방향을 적용해 진수를 합쳐 보면 깔끔한 정수로 떨어지는 경우가 많으며, 이는 수능 등 평가원에서 매우 자주 활용되는 전략이다.

## 학습 체크
- 로그의 합을 하나의 로그로 합칠 때, 밑이 서로 다른 두 로그를 바로 더할 수 있는가?
- 로그의 진수 조건($M>0, N>0$)이 로그의 덧셈 분해 과정에서 왜 중요한가?
- 복잡한 로그의 값을 구할 때, 진수를 곱하여 정수로 만드는 역방향 적용법을 숙지하고 있는가?

## 관련 개념

- **로그의 정의** — $\log_a b = c \Leftrightarrow a^c = b$ 라는 기본 정의를 정확히 알아야 덧셈 분해가 왜 성립하는지 이해할 수 있다.
- **지수법칙** — 덧셈 분해의 근거가 되는 $a^p \cdot a^q = a^{p+q}$ 가 선수 지식이다.
- **로그의 뺄셈 분해** — $\log_a \tfrac{M}{N} = \log_a M - \log_a N$ 으로, 덧셈 분해와 쌍을 이루는 성질이다. 나눗셈이 뺄셈으로 바뀐다.
- **로그의 지수 이동** — $\log_a M^n = n \log_a M$ 으로, 덧셈 분해를 반복 적용한 결과와 같다. $\log_a M^3 = \log_a M + \log_a M + \log_a M = 3\log_a M$.
- **상용로그** — 밑이 10인 로그에서 덧셈 분해를 이용하면 진수를 소인수분해한 뒤 $\log_{10} 2$, $\log_{10} 3$ 등의 근삿값을 조합해 복잡한 값을 계산할 수 있다.
