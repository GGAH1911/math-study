# 함수의 개수

## 요약
두 집합 사이에서 원소 하나가 다른 집합의 원소 하나에 대응되는 규칙의 총 개수를 구하는 과정입니다.

## 본문
두 집합 $X$와 $Y$가 있을 때, 집합 $X$의 각 원소가 집합 $Y$의 원소에 단 하나씩 대응되는 규칙을 함수라고 합니다. 이때 집합 $X$의 원소의 개수를 $n$, 집합 $Y$의 원소의 개수를 $m$이라고 하면, 가능한 함수의 총 개수는 $m^n$입니다. 이는 정의역의 각 원소가 선택할 수 있는 공역의 원소의 개수가 $m$개씩이며, 이러한 선택이 정의역의 원소 개수만큼 독립적으로 일어나기 때문입니다.

### 직관과 기하적 의미
함수의 개수를 구하는 것은 정의역의 각 원소에 대해 공역의 원소 중 하나를 화살표로 연결하는 모든 경우의 수를 찾는 것과 같습니다. 만약 정의역의 원소가 $x_1, x_2, \dots, x_n$이라면, $x_1$이 선택할 수 있는 경우 $m$가지, $x_2$가 선택할 수 있는 경우 $m$가지와 같이 곱의 법칙이 적용됩니다.

### 기본 성질
함수의 종류에 따라 개수를 구하는 방식이 달라집니다. 모든 원소가 하나 이상의 공역 원소에 대응되는 '단사함수'의 개수는 $m \ge n$일 때 $P(m, n)$이며, 공역의 모든 원소가 적어도 하나의 정의역 원소와 대응되는 '전사함수'의 개수는 포함-배제의 원리를 이용하여 계산합니다.

## 학습 체크
- 정의역의 원소 개수와 공역의 원소 개수가 같을 때, 일대일 대응의 개수는 왜 $n!$이 되는가?
- 공역의 원소 개수가 정의역의 원소 개수보다 적을 때, 단사함수가 존재할 수 없는 이유는 무엇인가?

## 관련 개념
- **확률**: 함수의 개수를 전체 경우의 수로, 특정 조건을 만족하는 함수의 개수를 사건의 경우의 수로 간주하여 확률을 계산할 수 있습니다.
