### 정확한 진술

포함-배제 원리는 두 개 이상의 집합의 합집합에 속한 원소의 개수를 구하는 원리입니다.

두 개의 유한집합 $A$, $B$에 대해:
$$|A \cup B| = |A| + |B| - |A \cap B|$$

세 개의 집합 $A$, $B$, $C$에 대해:
$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$

일반 규칙: 홀수 개의 집합들의 교집합은 **더하고**, 짝수 개의 집합들의 교집합은 **뺍니다**.

### 직관과 기하적 의미

단순히 $|A| + |B|$라고 하면 $A \cap B$에 속한 원소들이 두 번 세어집니다. 이를 한 번 빼주어야 정확합니다. 세 집합 이상의 경우는 더 복잡한데, 포함-배제 원리는 이러한 중복을 체계적으로 조정합니다. 벤 다이어그램에서 모든 영역을 정확히 한 번씩만 세는 방법이라고 이해하면 됩니다.

### 예제

30 이상 50 이하의 자연수 중에서 2의 배수 **또는** 3의 배수인 수의 개수를 구하세요.

$A$ = 2의 배수 집합 → $|A| = 11$개 (30, 32, 34, ..., 50)  
$B$ = 3의 배수 집합 → $|B| = 7$개 (30, 33, 36, ..., 48)  
$A \cap B$ = 6의 배수 집합 → $|A \cap B| = 3$개 (30, 36, 42, 48 중 범위 내)

포함-배제 원리 적용:
$$|A \cup B| = 11 + 7 - 3 = 15$$

답: **15개**

(검증용: `len([n for n in range(30, 51) if n % 2 == 0 or n % 3 == 0])`)
