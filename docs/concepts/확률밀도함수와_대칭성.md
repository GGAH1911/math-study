# 확률밀도함수와 대칭성

## 요약
확률밀도함수가 특정 구간에 대해 대칭이면, 해당 구간의 확률은 평균을 기준으로 양옆의 구간과 동일합니다.

## 본문
확률변수 $X$의 확률밀도함수를 $f(x)$라고 할 때, 함수 $f(x)$가 $x=a$를 기준으로 대칭이면 즉, 모든 $x$에 대하여 $f(a-x) = f(a+x)$이면, 확률변수 $X$는 평균이 $a$인 분포를 가집니다. 이는 확률밀도함수 그래프의 모양이 $x=a$라는 직선을 축으로 좌우가 거울을 본 듯이 똑같은 형태임을 의미합니다.

### 직관과 기하적 의미
확률밀도함수에서 특정 구간의 확률은 그래프 아래의 면적과 같습니다. 함수가 $x=a$를 기준으로 대칭이라는 것은 $a$를 중심으로 왼쪽으로 $k$만큼 떨어진 구간의 면적과 오른쪽으로 $k$만큼 떨어진 구간의 면적이 항상 같다는 것을 기하학적으로 나타냅니다. 따라서 대칭성을 가진 분포에서는 평균이 곧 중앙값의 역할을 수행하며, 데이터가 평균을 중심으로 균형 있게 분포되어 있음을 시각적으로 확인할 수 있습니다.

### 기본 성질
함수 $f(x)$가 $x=a$에 대해 대칭이면, 임의의 양수 $k$에 대하여 $P(a-k \le X \le a) = P(a \le X \le a+k)$가 성립합니다. 또한, 확률밀도함수의 전체 면적은 $1$이므로, 대칭인 분포에서 평균 $a$를 기준으로 양쪽 구간의 면적을 합하면 $1$이 되어 각각의 면적은 $0.5$가 됩니다.

## 학습 체크
- 확률밀도함수 $f(x)$가 $x=a$에 대해 대칭일 때, $P(X < a)$의 값은 얼마인가?
- 함수 $f(x)$가 $x=a$에 대해 대칭이면 $f(a-x) = f(a+x)$가 성립하는가?

## 관련 개념
- **통계**: 확률밀도함수의 대칭성은 평균, 중앙값, 최빈값이 일치하는 분포의 특성을 이해하는 기초가 됩니다.
