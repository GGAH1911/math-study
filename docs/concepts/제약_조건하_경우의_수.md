# 제약 조건하 경우의 수

특정한 조건이나 제한이 주어진 상황에서 가능한 경우의 수를 세는 방법이다.

아무 조건 없이 모든 경우를 세는 것과 달리, 제약 조건하 경우의 수에서는 **반드시 만족해야 하는 조건** 또는 **허용되지 않는 조건**이 먼저 주어진다. 이때 문제를 푸는 핵심 전략은 두 가지다.

- **조건을 먼저 처리한다.** 제약이 있는 자리나 원소를 먼저 고정하고, 나머지를 자유롭게 배열한다.
- **여사건을 이용한다.** 조건을 직접 만족시키기 어려울 때는 전체 경우에서 조건을 어기는 경우를 빼는 방법이 더 간단할 수 있다.

제약 조건의 형태는 다양하다. 특정 원소가 반드시 포함되거나 포함되지 않아야 하는 경우, 이웃하거나 이웃하지 않아야 하는 경우, 특정 자리에만 올 수 있는 경우 등이 자주 등장한다.

## 예시

**예시 1 — 특정 원소를 고정한 후 나머지 배열**

남학생 3명, 여학생 2명이 일렬로 설 때, 여학생 2명이 반드시 서로 이웃하는 경우의 수를 구하라.

여학생 2명을 한 묶음으로 묶으면 전체를 4개의 단위(묶음 1개 + 남학생 3명)로 볼 수 있다. 이 4단위를 일렬로 세우는 방법은 $4!$가지이고, 묶음 안에서 여학생끼리 자리를 바꾸는 방법은 $2!$가지이므로 구하는 경우의 수는

$$4! \times 2! = 24 \times 2 = 48$$

**예시 2 — 여사건 활용**

1, 2, 3, 4, 5를 한 번씩 사용하여 만든 다섯 자리 수 중 짝수가 적어도 하나 이상인 수의 개수를 구하라.

"적어도 하나"는 여사건으로 접근하면 편리하다. 전체 경우의 수는 $5!= 120$이고, 짝수가 하나도 없는 경우(홀수 1, 3, 5만으로 이루어진 세 자리 자리를 홀수로만 채우는 것은 불가능하므로, 짝수 2·4가 모두 포함되지 않는 경우)는 불가능하다. 대신 홀수만 배열하는 문제로 바꾸면, 홀수 3개(1, 3, 5)와 짝수 2개(2, 4)가 있으므로 짝수가 전혀 없는 다섯 자리 수는 만들 수 없다. 따라서 결국

$$120 - 0 = 120$$

보다 현실적인 여사건 예시로: 5명 중 특정 2명(A, B)이 **모두 포함되지 않는** 경우를 전체에서 빼면

$$\binom{5}{3} - \binom{3}{3} = 10 - 1 = 9$$

## 관련 개념

- **경우의 수**: 제약 조건 없이 모든 경우를 세는 가장 기본 개념이다. 제약 조건하 경우의 수는 여기에 조건이 덧붙여진 형태이므로, 기본 경우의 수 계산이 반드시 선행되어야 한다.
- **조건부 경우의 수**: 어떤 사건이 일어났을 때 다른 사건의 경우의 수를 구하는 개념으로, 제약 조건을 수식으로 표현하는 방식과 직접 연결된다.
- **합의 법칙 · 곱의 법칙**: 제약 조건을 처리한 뒤, 남은 단계들을 순서대로 세거나 경우를 합산할 때 이 두 법칙이 핵심 도구로 쓰인다.
- **여사건**: 조건을 직접 세기 복잡할 때 전체에서 반대 경우를 빼는 전략으로, "적어도 ~인" 또는 "~이 아닌" 꼴의 제약 조건에서 특히 강력하다.
- **순열 · 조합**: 제약 조건이 붙은 배열 문제나 선택 문제는 결국 순열·조합의 틀 안에서 계산되므로, 두 개념과 항상 함께 적용된다.
