# 제약 조건하 경우의 수

## 요약
특정한 조건이나 제한이 주어진 상황에서 반드시 만족해야 하는 조건이나 허용되지 않는 조건을 고려하여 가능한 경우의 수를 구하는 방법이다.

## 본문
특정한 조건이나 제한이 주어진 상황에서 가능한 경우의 수를 세는 방법이다. 아무 조건 없이 모든 경우를 세는 것과 달리, 제약 조건하 경우의 수에서는 반드시 만족해야 하는 조건 또는 허용되지 않는 조건이 먼저 주어진다. 이때 문제를 해결하는 핵심 전략은 두 가지로 요약된다. 첫째는 조건을 먼저 처리하는 것이다. 제약이 있는 자리나 원소를 먼저 고정하여 배치한 후, 나머지 원소들을 자유롭게 배열하는 방식이다. 둘째는 여사건을 이용하는 것이다. 조건을 직접 만족시키는 경우를 구하기 어려울 때는 전체 경우의 수에서 조건을 만족하지 않는 경우를 빼는 방식이 더 효율적일 수 있다. 제약 조건의 형태는 매우 다양하며, 특정 원소가 반드시 포함되거나 포함되지 않아야 하는 경우, 특정 원소들이 서로 이웃하거나 이웃하지 않아야 하는 경우, 혹은 특정 자리에만 특정 원소가 올 수 있는 경우 등이 자주 등장한다.

### 직관과 기하적 의미
제약 조건은 전체 가능한 경우의 수라는 공간 내에서 특정 영역만을 선택하도록 제한하는 역할을 한다. 예를 들어 '이웃한다'는 조건은 여러 원소를 하나의 덩어리로 묶어 공간의 크기를 줄이는 것과 같고, '이웃하지 않는다'는 조건은 원소 사이에 다른 원소를 끼워 넣어 간격을 벌리는 것과 같다.

### 기본 성질
- **조건 우선 처리**: 제약이 있는 대상을 먼저 결정하면 문제의 구조가 단순해진다.
- **여사건 활용**: '적어도 하나'와 같은 표현이 나오면 전체에서 반대되는 경우를 빼는 것이 유리하다.
- **다양한 제약 형태**: 포함/불포함, 이웃/비이웃, 특정 자리 지정 등이 핵심 유형이다.

## 학습 체크
- 제약 조건이 있는 경우, 조건을 먼저 만족시킨 후 나머지 원소를 배열하는 방식이 왜 효율적인가?
- '적어도 하나'라는 표현이 포함된 문제에서 여사건을 적용할 때, 전체 경우에서 빼야 할 '반대되는 경우'는 무엇인가?
- 특정 원소들이 서로 이웃해야 하는 경우, 왜 이들을 하나의 묶음으로 간주하여 계산하는가?

## 관련 개념

- **경우의 수**: 제약 조건 없이 모든 경우를 세는 가장 기본 개념이다. 제약 조건하 경우의 수는 여기에 조건이 덧붙여진 형태이므로, 기본 경우의 수 계산이 반드시 선행되어야 한다.
- **조건부 경우의 수**: 어떤 사건이 일어났을 때 다른 사건의 경우의 수를 구하는 개념으로, 제약 조건을 수식으로 표현하는 방식과 직접 연결된다.
- **합의 법칙 · 곱의 법칙**: 제약 조건을 처리한 뒤, 남은 단계들을 순서대로 세거나 경우를 합산할 때 이 두 법칙이 핵심 도구로 쓰인다.
- **여사건**: 조건을 직접 세기 복잡할 때 전체에서 반대 경우를 빼는 전략으로, "적어도 ~인" 또는 "~이 아닌" 꼴의 제약 조건에서 특히 강력하다.
- **순열 · 조합**: 제약 조건이 붙은 배열 문제나 선택 문제는 결국 순열·조합의 틀 안에서 계산되므로, 두 개념과 항상 함께 적용된다.
