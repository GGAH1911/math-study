# 도수의 합

### 정확한 진술

데이터를 도수분포표로 나타낼 때, 각 구간의 도수를 모두 더한 값을 **도수의 합**이라 합니다. 기호로는:

$$\sum_{i=1}^{k} f_i = f_1 + f_2 + \cdots + f_k$$

여기서 $k$는 구간의 개수이고, $f_i$는 $i$번째 구간의 도수(그 구간에 속하는 데이터의 개수)입니다.

### 직관과 의미

도수의 합은 항상 **전체 데이터의 개수 $n$**과 같습니다. 왜냐하면 도수분포표를 만들 때 모든 데이터를 빠짐없이 각 구간에 배치하기 때문입니다. 따라서 도수의 합은 우리가 수집한 표본의 크기를 나타내는 척도이면서, 동시에 상대도수와 누적도수를 구할 때의 기준이 됩니다. 상대도수 $\frac{f_i}{\sum f_i}$는 각 구간이 전체에서 차지하는 비율을 보여주므로, 도수의 합 없이 통계적 비교와 해석이 불가능합니다. 즉, 도수의 합은 통계에서 **정규화(normalization) 기준**으로 작용하는 핵심 개념입니다.

### 예시

학생 30명의 시험 성적을 10점씩 나눈 도수분포표:
- 50~60점: 도수 5명
- 60~70점: 도수 10명  
- 70~80점: 도수 10명
- 80~90점: 도수 5명

도수의 합은 $5 + 10 + 10 + 5 = 30$이므로 조사 대상이 30명임을 확인할 수 있습니다. 각 구간의 상대도수는 차례로 $\frac{5}{30} = \frac{1}{6}$, $\frac{10}{30} = \frac{1}{3}$, $\frac{10}{30} = \frac{1}{3}$, $\frac{5}{30} = \frac{1}{6}$입니다.
