# 이차방정식 인수분해풀이

> **예제** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
$x^2-5x+6=0$

## 본문 (학습 시 채워짐)

### 문제

다음 이차방정식을 인수분해로 풀어라.
$$x^2-5x+6=0$$

### 단계별 풀이

**1단계: 상수항과 일차항 계수 확인**

이차방정식 $x^2-5x+6=0$에서
- 상수항: $6$
- 일차항 계수: $-5$

인수분해의 핵심은 곱해서 상수항이 되고, 더해서 일차항 계수가 되는 두 수를 찾는 것입니다.

**2단계: 두 수 찾기**

곱이 $6$이고 합이 $-5$인 두 정수를 찾습니다.
- $6 = 1 \times 6 = 2 \times 3$
- 음수를 고려하면: $6 = (-2) \times (-3)$
- $(-2) + (-3) = -5$ ✓

따라서 구하는 두 수는 $-2$와 $-3$입니다.

**3단계: 인수분해**

$$x^2 - 5x + 6 = (x - 2)(x - 3) = 0$$

**4단계: 해 구하기**

$(x-2)(x-3) = 0$이므로
- $x - 2 = 0$ 또는 $x - 3 = 0$
- $x = 2$ 또는 $x = 3$

### 답

$$x = 2 \text{ 또는 } x = 3$$

검증: $x=2$일 때, $4-10+6=0$ ✓  
검증: $x=3$일 때, $9-15+6=0$ ✓

(sympy 검증: `sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)

### 변형 및 주의

**다른 예: 음수 근을 갖는 경우**

$x^2 + 2x - 3 = 0$을 풀면?
- 곱이 $-3$, 합이 $2$인 두 수: $3$과 $-1$
- $(x+3)(x-1) = 0$ → $x = -3$ 또는 $x = 1$

**주의점**
- 부호를 정확히: 합이 음수면 절댓값이 더 큰 수가 음수여야 합니다.
- 모든 이차방정식이 정수 범위에서 인수분해되지는 않습니다. 근의 공식이 필요할 수 있습니다.
- 인수분해가 어려우면 판별식 $D = b^2 - 4ac$로 먼저 정수 근이 존재하는지 확인하세요.
