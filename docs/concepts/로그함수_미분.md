# 로그함수 미분

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$(\ln x)'=1/x$

## 본문 (학습 시 채워짐)

### 정의

자연로그함수 $\ln x$의 도함수는 다음과 같이 정의된다:
$$(\ln x)' = \frac{1}{x} \quad (x > 0)$$

일반 로그함수 $\log_a x$의 도함수는 밑변환 공식을 이용하여:
$$(\log_a x)' = \frac{1}{x \ln a} \quad (x > 0, a > 0, a \neq 1)$$

이는 지수함수와 로그함수의 역함수 관계에서 유도되는 미적분의 핵심 공식이다.

### 기하적 의미

로그함수 $y = \ln x$는 지수함수 $y = e^x$의 역함수다. 역함수의 미분 정리에 의해, 점 $(x, \ln x)$에서의 접선 기울기는 지수함수의 해당 점에서의 기울기의 역수가 된다. 즉, $e^{\ln x} = x$이므로 그 역수는 $\frac{1}{x}$다.

기하학적으로 보면, $x$가 1에 가까울 때 로그함수의 그래프는 가파르고(기울기 ≈ 1), $x$가 증가할수록 완만해진다(기울기 → 0). 이는 로그함수가 천천히 증가하는 성질과 정확히 일치한다.

### 주요 예제

**기본 미분**: $f(x) = \ln x$일 때, $f'(2) = \frac{1}{2}$

**합성함수 미분**: $g(x) = \ln(3x)$이면 체인 룰에 의해
$$g'(x) = \frac{1}{3x} \cdot 3 = \frac{1}{x}$$

**로그 미분법** (지수가 변수인 함수): $y = x^x$를 미분할 때, 양변에 자연로그를 취하면 $\ln y = x \ln x$. 양변을 $x$로 미분하면:
$$\frac{1}{y} \cdot y' = \ln x + 1 \quad \Rightarrow \quad y' = x^x(\ln x + 1)$$

이 기법은 직접 미분이 불가능한 지수함수에서 필수적으로 사용된다.

(`sympy.diff(sympy.ln(x), x)` → `1/x`)
