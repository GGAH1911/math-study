# 삼각함수 미분

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$(\sin x)'=\cos x$ 등

## 본문 (학습 시 채워짐)

### 정확한 진술

삼각함수의 도함수는 다음과 같습니다:
$$(\sin x)' = \cos x, \quad (\cos x)' = -\sin x, \quad (\tan x)' = \sec^2 x$$

이들은 극한의 정의 $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$로부터 유도되며, 특히 $\lim_{h \to 0} \frac{\sin h}{h} = 1$이라는 중요한 극한값이 핵심 역할을 합니다.

### 직관/기하적 의미

$\sin x$의 그래프를 보면, 원점 근처에서는 기울기가 가파르지만 $x = \frac{\pi}{2}$에 가까워질수록 기울기가 완만해집니다. 이 기울기의 변화를 함수로 나타낸 것이 바로 $\cos x$입니다. 더 깊게 말하면, 단위원 위의 점 $(\cos t, \sin t)$를 시간 $t$에 따라 움직일 때 속도 벡터는 $(-\sin t, \cos t)$가 됩니다. 이것이 삼각함수 미분 공식의 기하학적 의미입니다.

### 예

$f(x) = 3\sin x + 2\cos x$일 때 미분하면 $f'(x) = 3\cos x - 2\sin x$입니다.  
검증: `from sympy import *; diff(3*sin(x) + 2*cos(x), x)`
