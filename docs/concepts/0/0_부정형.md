# 0 부정형

## 요약
$\tfrac{0}{0}$ 부정형은 분자와 분모가 동시에 $0$으로 수렴하여 극한값을 즉각 알 수 없는 상태를 의미하며, 약분이나 유리화를 통해 극한값을 결정해야 한다.

## 본문
$x \to a$일 때 분자도 $0$으로, 분모도 $0$으로 수렴하는 극한의 꼴을 $\tfrac{0}{0}$ 부정형이라 한다. 이때 극한값이 $0$이라거나 존재하지 않는다고 단정할 수 없다는 점이 핵심이다. 분자와 분모가 동시에 $0$에 가까워지는 속도의 비율에 따라 극한값이 달라지기 때문에, 겉모습만 보고 결론을 내릴 수 없는 "미정" 상태다. 그래서 부정형이라 부른다. $\tfrac{0}{0}$ 부정형을 만나면 극한값을 구하기 위해 분자·분모를 인수분해하거나 유리화하여 $0$이 되는 공통 인수를 약분해야 한다.

### 직관과 기하적 의미
분자와 분모가 모두 $0$을 향해 달려가고 있지만, 어느 쪽이 더 빠르게 $0$에 도달하느냐에 따라 전체 분수의 값은 결정된다. 분자가 더 빨리 $0$에 도달하면 극한값은 $0$이 되고, 분모가 더 빨리 $0$에 도달하면 극한값은 발산하게 된다. 두 속도가 균형을 이룰 때 비로소 특정한 상숫값으로 수렴하게 된다.

### 기본 성질
$\tfrac{0}{0}$ 꼴의 극한 문제를 해결하는 대표적인 방법은 다음과 같다.
1. **인수분해를 통한 약분**: 다항식 형태인 경우, 분자와 분모를 각각 인수분해하여 $0$을 만드는 공통 인수를 찾아 제거한다.
   - 예시: $\displaystyle\lim_{x \to 2} \tfrac{x^2 - 4}{x - 2} = \lim_{x \to 2} \tfrac{(x+2)(x-2)}{x-2} = \lim_{x \to 2} (x+2) = 4$
2. **유리화를 통한 약분**: 무리식이 포함된 경우, 분자 또는 분모를 유리화하여 식을 변형한 뒤 공통 인수를 제거한다.
   - 예시: $\displaystyle\lim_{x \to 0} \tfrac{\sqrt{x+1} - 1}{x} = \lim_{x \to 0} \tfrac{x}{x(\sqrt{x+1}+1)} = \lim_{x \to 0} \tfrac{1}{\sqrt{x+1}+1} = \tfrac{1}{2}$

## 학습 체크
- $x \to a$일 때 분자와 분모가 모두 $0$으로 수렴한다고 해서 극한값이 반드시 $0$인 것은 아니다.
- $\tfrac{0}{0}$ 꼴의 극한값을 구할 때 가장 먼저 확인해야 할 것은 분자와 분모를 $0$으로 만드는 공통 인수가 무엇인지 찾는 것이다.
- 무리식이 포함된 $\tfrac{0}{0}$ 꼴은 유리화를 통해 분모나 분자의 형태를 변형하는 것이 핵심이다.

## 관련 개념

**부정형**은 $\tfrac{0}{0}$ 부정형을 포함하는 상위 개념이다. 극한에서 값을 바로 결정할 수 없는 꼴을 통틀어 부정형이라 하며, $\tfrac{0}{0}$ 외에 $\tfrac{\infty}{\infty}$ 부정형도 중요하게 다룬다. 두 부정형은 "약분·정리로 해소한다"는 처리 전략을 공유한다.

**함수의 극한**은 $\tfrac{0}{0}$ 부정형이 등장하는 직접적인 맥락이다. 극한의 정의와 성질—특히 "극한값은 $x = a$에서의 함숫값과 무관하다"는 사실—이 있기 때문에, $x \to a$ 근방에서 공통 인수를 약분하는 조작이 정당화된다.

**함수의 연속**과도 연결된다. $x = a$에서 연속인 함수는 직접 대입으로 극한값을 구할 수 있어 부정형이 생기지 않는다. 역으로, $\tfrac{0}{0}$ 부정형이 나타난다는 것은 그 점에서 함수가 정의되지 않거나 연속이 아닐 수 있다는 신호이기도 하다.
