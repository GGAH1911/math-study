# 0 부정형

$x \to a$일 때 분자도 $0$으로, 분모도 $0$으로 수렴하는 극한의 꼴을 **$\dfrac{0}{0}$ 부정형**이라 한다. 이때 극한값이 $0$이라거나 존재하지 않는다고 단정할 수 없다는 점이 핵심이다. 분자와 분모가 동시에 $0$에 가까워지는 속도의 비율에 따라 극한값이 달라지기 때문에, 겉모습만 보고 결론을 내릴 수 없는 "미정" 상태다. 그래서 부정형이라 부른다.

$\dfrac{0}{0}$ 부정형을 만나면 극한값을 구하기 위해 분자·분모를 인수분해하거나 유리화하여 $0$이 되는 공통 인수를 약분해야 한다.

## 예시

**예시 1.** $\displaystyle\lim_{x \to 2} \dfrac{x^2 - 4}{x - 2}$

$x = 2$를 직접 대입하면 분자 $0$, 분모 $0$이 되어 $\dfrac{0}{0}$ 부정형이다. 분자를 인수분해하면

$$\lim_{x \to 2} \dfrac{(x+2)(x-2)}{x-2} = \lim_{x \to 2} (x+2) = 4$$

공통 인수 $(x-2)$를 약분한 뒤 $x \to 2$를 취하면 극한값은 $4$다.

**예시 2.** $\displaystyle\lim_{x \to 0} \dfrac{\sqrt{x+1} - 1}{x}$

$x = 0$을 대입하면 역시 $\dfrac{0}{0}$ 부정형이다. 분자를 유리화하면

$$\lim_{x \to 0} \dfrac{(\sqrt{x+1}-1)(\sqrt{x+1}+1)}{x(\sqrt{x+1}+1)} = \lim_{x \to 0} \dfrac{x}{x(\sqrt{x+1}+1)} = \lim_{x \to 0} \dfrac{1}{\sqrt{x+1}+1} = \dfrac{1}{2}$$

## 관련 개념

**부정형**은 $\dfrac{0}{0}$ 부정형을 포함하는 상위 개념이다. 극한에서 값을 바로 결정할 수 없는 꼴을 통틀어 부정형이라 하며, $\dfrac{0}{0}$ 외에 $\dfrac{\infty}{\infty}$ 부정형도 중요하게 다룬다. 두 부정형은 "약분·정리로 해소한다"는 처리 전략을 공유한다.

**함수의 극한**은 $\dfrac{0}{0}$ 부정형이 등장하는 직접적인 맥락이다. 극한의 정의와 성질—특히 "극한값은 $x = a$에서의 함숫값과 무관하다"는 사실—이 있기 때문에, $x \to a$ 근방에서 공통 인수를 약분하는 조작이 정당화된다.

**함수의 연속**과도 연결된다. $x = a$에서 연속인 함수는 직접 대입으로 극한값을 구할 수 있어 부정형이 생기지 않는다. 역으로, $\dfrac{0}{0}$ 부정형이 나타난다는 것은 그 점에서 함수가 정의되지 않거나 연속이 아닐 수 있다는 신호이기도 하다.
