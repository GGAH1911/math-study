# 확률 (중학)

> **단원** · 중2 · 선수: [유리수와 순환소수](./유리수와_순환소수.md) · 다음: [경우의 수 고1](./경우의_수_고1.md) / [대푯값과 산포도](./대푯값과_산포도.md) / [확률](./확률.md)

## 학습 목표
- 경우의 수를 합·곱의 법칙으로 셀 수 있다
- 확률의 정의 P=경우의 수의 비를 적용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 사건, 경우의 수
- 확률 $P(A)=\frac{n(A)}{n(S)}$

**정리(theorem)**
- 합의 법칙(배반사건)
- 곱의 법칙(독립시행)
- 여사건의 확률 $1-P(A)$

**예제(example)**
- 주사위·동전 경우의 수
- 한 번 뽑기 vs 두 번 뽑기
- 여사건 활용
