### 정확한 진술

순환소수는 일정한 자리 숫자가 무한히 반복되는 소수입니다. 순환소수를 분수로 변환한다는 것은 이러한 소수를 정수의 비율, 즉 **유리수**로 나타내는 것입니다.

순환 부분이 $n$자리이면, 다음 규칙을 따릅니다:
- 순환소수 $0.\overline{a_1a_2\cdots a_n}$ (순환 주기가 $n$) → 분모: 9가 $n$개
- $0.\overline{3} = \frac{3}{9} = \frac{1}{3}$
- $0.\overline{142857} = \frac{142857}{999999} = \frac{1}{7}$

혼합순환소수 $0.b_1\cdots b_m\overline{a_1\cdots a_n}$ (비순환 부분 $m$자리, 순환 부분 $n$자리)의 경우:
$$\text{(전체 숫자)} - \text{(비순환 부분)} \text{ over } 9^n0^m$$

예: $0.1\overline{6} = \frac{16-1}{90} = \frac{15}{90} = \frac{1}{6}$

### 직관/기하적 의미

순환소수가 항상 분수로 표현되는 이유는 **방정식**에 있습니다.

$x = 0.\overline{3} = 0.3333\cdots$라 하면:
$$10x = 3.3333\cdots$$
$$10x - x = 3$$
$$9x = 3 \implies x = \frac{1}{3}$$

순환 주기가 $n$자리면 $10^n$을 곱합니다. 이 방법으로 순환소수는 항상 정수 계수 방정식의 해이므로 유리수가 됩니다. 역으로 모든 유리수는 유한소수이거나 순환소수입니다.

### 한 줄 예

$0.\overline{12} = \frac{12}{99} = \frac{4}{33}$ (검산: `from fractions import Fraction; Fraction(4, 33)` → 약 $0.121212\cdots$)
