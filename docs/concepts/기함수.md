# 기함수

## 정의

함수 $f(x)$가 정의역의 모든 $x$에 대해 $f(-x) = -f(x)$를 만족하면 $f$를 기함수(奇函數, odd function)라 한다. 기함수의 그래프는 원점에 대해 대칭이다. 기함수를 대칭구간 $[-a, a]$에서 적분하면 $\int_{-a}^{a} f(x)\,dx = 0$이 성립하며, 이는 정적분 계산에서 자주 활용된다. 기함수와 우함수(偶函數)의 곱은 기함수가 된다.

## 예시

$f(x) = x^3 - x$가 기함수임을 확인한다.

$f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x)$

따라서 $f(x)$는 기함수이고, $\int_{-2}^{2}(x^3 - x)\,dx = 0$이다.
