# 기함수

## 요약
함수 $f(x)$가 $f(-x) = -f(x)$를 만족할 때 이를 기함수라 하며, 그래프는 원점에 대해 대칭이고 대칭 구간에서의 정적분 값은 $0$이다.

## 본문
함수 $f(x)$가 정의역의 모든 $x$에 대해 $f(-x) = -f(x)$를 만족하면 $f$를 기함수(奇函數, odd function)라 한다. 기함수는 원점을 기준으로 함수값이 부호가 반대로 변하는 성질을 가지며, 이는 대수적 정의뿐만 아니라 기하학적으로도 중요한 특징을 나타낸다.

### 직관과 기하적 의미
기함수의 그래프는 원점에 대하여 대칭인 형태를 띤다. 즉, 그래프 위의 임의의 점 $(x, y)$가 존재한다면, 점 $(-x, -y)$도 반드시 그래프 위에 존재해야 한다. 이러한 대칭성은 함수가 원점을 통과하거나 원점을 중심으로 회전했을 때 원래의 모양을 유지하는 특성을 보여준다.

### 기본 성질
기함수는 정적분 계산에서 매우 유용한 성질을 제공한다. 기함수를 대칭 구간인 $[-a, a]$에서 적분하면 좌우의 넓이와 부호가 상쇄되어 $\int_{-a}^{a} f(x)\,dx = 0$이 성립한다. 또한, 기함수와 우함수(偶函數)를 곱한 함수는 기함수가 된다. 예를 들어 $f(x) = x^3 - x$의 경우, $f(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -f(x)$이므로 기함수이며, 따라서 $\int_{-2}^{2}(x^3 - x)\,dx = 0$이 성립한다.

- 기함수의 그래프가 원점에 대하여 대칭임을 시각적으로 이해하였는가?
- 대칭 구간 $[-a, a]$에서의 정적분 값이 $0$이 되는 원리를 파악하였는가?
