# 시그마의 선형성

## 요약
시그마 기호의 선형성이란 합의 기호가 상수배와 항의 합에 대해 각각 분리되어 적용될 수 있는 성질을 의미합니다.

## 본문
$\sum_{k=1}^{n} c a_k = c \sum_{k=1}^{n} a_k$ (단, $c$는 상수)이며, $\sum_{k=1}^{n} (a_k + b_k) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k$를 만족하는 성질을 말합니다. 이는 수열의 합을 계산할 때 복잡한 식을 단순화하는 데 필수적인 도구입니다.

### 직관과 기하적 의미
시그마는 수열의 항들을 차례대로 더해나가는 연산입니다. 만약 모든 항에 동일한 상수 $c$가 곱해져 있다면, 전체 합을 먼저 구한 뒤 마지막에 $c$를 곱하는 것과 같습니다. 또한, 두 수열의 합에 대한 합은 각 수열의 합을 각각 구하여 더한 것과 결과가 같습니다. 이는 선형 대수학의 선형 변환 개념과 맞닿아 있으며, 연산의 구조적 단순함을 보여줍니다.

### 기본 성질
1. 상수배 성질: $\sum_{k=1}^{n} c a_k = c \sum_{k=1}^{n} a_k$
2. 합의 성질: $\sum_{k=1}^{n} (a_k + b_k) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k$
3. 차의 성질: $\sum_{k=1}^{n} (a_k - b_k) = \sum_{k=1}^{n} a_k - \sum_{k=1}^{n} b_k$

## 학습 체크
- 상수 $c$가 시그마 기호의 인덱스 $k$와 관련이 있는 변수일 때, 이를 시그마 밖으로 꺼낼 수 있는가?
- 두 수열의 합이 아닌, 항의 곱($a_k \cdot b_k$)에 대해 시그마를 분리할 수 있다고 착각하지는 않는가?

## 관련 개념
- **수열**: 시그마 연산의 대상이 되는 항들의 나열이며, 선형성을 적용하여 합을 계산하는 기초가 됩니다.
- **등차수열**: 일반항이 $k$에 대한 일차식 형태이므로, 시그마의 선형성을 이용하여 합의 공식을 유도할 수 있습니다.
- **등비수열**: 일반항이 거듭제곱 형태이지만, 시그마의 성질을 활용하여 합의 공식을 전개할 수 있습니다.
