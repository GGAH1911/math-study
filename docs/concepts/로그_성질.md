### 정확한 진술

로그 성질이란 로그 연산을 단순화하는 기본 규칙들을 말합니다. 주요 성질은 다음과 같습니다:

**곱셈의 성질:** $\log_a(MN) = \log_a M + \log_a N$ (단, $a > 0, a \neq 1, M > 0, N > 0$)

**나눗셈의 성질:** $\log_a \frac{M}{N} = \log_a M - \log_a N$

**거듭제곱의 성질:** $\log_a M^n = n\log_a M$ (단, $n$은 실수)

**밑변환 공식:** $\log_a b = \frac{\log_c b}{\log_c a}$ (새로운 밑 $c$로 변환)

이 성질들은 로그의 정의 $a^x = M \Leftrightarrow x = \log_a M$에서 직접 유도됩니다.

### 직관/기하적 의미

로그 성질의 핵심은 **곱셈을 덧셈으로 변환한다**는 것입니다. 지수 성질 $a^p \cdot a^q = a^{p+q}$를 로그로 나타내면:

$$MN = a^{\log_a M} \cdot a^{\log_a N} = a^{\log_a M + \log_a N}$$

양변에 밑이 $a$인 로그를 취하면 곱셈의 성질이 나옵니다. 즉, 로그 성질은 **지수 법칙의 다른 표현**일 뿐입니다. 이것이 로그가 복잡한 계산(특히 큰 수의 곱셈)을 간단히 하는 이유입니다.

### 한 줄 예

$\log_2 8 + \log_2 4$를 로그 성질로 계산하면: $\log_2(8 \times 4) = \log_2 32 = 5$

(검산: `sympy.log(2**5, 2)` → 5)
