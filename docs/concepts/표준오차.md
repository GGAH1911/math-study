### 정확한 진술

표준오차(standard error, SE)는 표본통계량의 표준편차로, 표본을 이용해 구한 추정값이 모수로부터 평균적으로 얼마나 벗어나는지를 정량화합니다. 모표준편차 $\sigma$와 표본 크기 $n$에 대해 표본평균 $\bar{X}$의 표준오차는:

$$SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}$$

모표준편차를 모르는 실제 상황에서는 표본표준편차 $s$로 추정합니다:

$$SE(\bar{X}) = \frac{s}{\sqrt{n}}$$

### 직관과 의미

같은 모집단에서 표본을 반복 추출하면 각 표본의 평균이 조금씩 다릅니다. 이렇게 얻은 표본평균들의 분포(표본분포)에서 이들이 얼마나 흩어져 있는가를 나타내는 지표가 표준오차입니다:

- **표준오차가 작음** → 표본평균들이 모평균 근처에 모여 있음 → 추정의 신뢰도 높음
- **표준오차가 큼** → 표본평균들이 넓게 흩어짐 → 추정의 신뢰도 낮음

표본 크기가 4배가 되면 표준오차는 $\frac{1}{2}$로 감소합니다($\sqrt{4}=2$이므로).

### 구체적 예시

전국 고등학생의 영어 시험 점수를 조사합니다. 모표준편차가 20점이고 표본 크기가 400명일 때:

$$SE = \frac{20}{\sqrt{400}} = \frac{20}{20} = 1\text{점}$$

이 표본평균은 모평균으로부터 약 1점의 오차를 가질 것으로 예상됩니다. 만약 표본을 100명으로 줄이면 표준오차는 2점이 되어 추정의 불확실성이 높아집니다.

`from sympy import sqrt; SE = 20/sqrt(400); print(float(SE))`
