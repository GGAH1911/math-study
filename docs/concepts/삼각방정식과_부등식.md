### 정확한 진술

**삼각방정식**은 미지수 $x$에 대한 삼각함수를 포함하는 방정식입니다. 즉, $\sin x = a$, $\cos x = b$, $\tan x = c$ 형태 또는 이들의 조합으로 이루어진 식입니다. 주어진 범위 내에서 이 방정식을 만족하는 모든 $x$의 값을 찾는 것을 '삼각방정식을 푼다'고 합니다.

**삼각부등식**은 삼각함수를 포함하는 부등식으로, $\sin x > a$, $\cos x \leq b$, $\tan x < c$ 등의 형태입니다. 부등식을 만족하는 $x$의 범위(또는 해집합)를 구하는 것이 목표입니다.

### 직관 및 기하적 의미

단위원 위의 점 $(\cos\theta, \sin\theta)$를 생각해봅시다. 삼각방정식 $\sin\theta = \frac{1}{2}$는 "단위원 위에서 $y$ 좌표가 $\frac{1}{2}$인 점들을 찾는 것"입니다. 이는 $y = \frac{1}{2}$ 직선이 단위원과 만나는 점들의 각도를 구하는 문제입니다.

삼각부등식 $\sin\theta > \frac{1}{2}$는 "단위원 위에서 $y$ 좌표가 $\frac{1}{2}$보다 큰 호 구간"에 해당합니다. 즉, 기하학적으로는 특정 영역에 속하는 각도들의 집합을 나타냅니다.

삼각함수의 **주기성** 때문에 방정식과 부등식의 해는 일반해로 표현됩니다. 기본 주기 $[0, 2\pi)$에서 해를 구한 후, 주기 $2\pi$를 더해 모든 해를 나타냅니다.

### 한 줄 예

$\sin x = \frac{\sqrt{3}}{2}$ ($0 \leq x < 2\pi$)의 해는 $x = \frac{\pi}{3}, \frac{2\pi}{3}$이고, 일반해는 $x = \frac{\pi}{3} + 2n\pi$ 또는 $x = \frac{2\pi}{3} + 2n\pi$ (단, $n$은 정수)입니다.
