# 다항식 전개

## 요약
다항식의 곱셈을 수행하여 괄호가 없는 형태의 합 또는 차의 형태로 나타내는 과정입니다.

## 본문
다항식의 전개란 두 개 이상의 다항식이 곱해진 형태를 분배법칙을 이용하여 각 항을 곱한 뒤, 동류항끼리 정리하여 합 또는 차의 형태로 나타내는 연산을 의미합니다. 이는 복잡한 곱셈 구조를 단순한 항들의 나열로 변환하여 식을 다루기 쉬운 형태로 만드는 과정입니다.

### 직관과 기하적 의미
다항식의 전개는 도형의 넓이를 구하는 과정으로 이해할 수 있습니다. 예를 들어, $(a+b)(c+d)$의 전개는 가로의 길이가 $a+b$이고 세로의 길이가 $c+d$인 직사각형의 넓이를 구하는 것과 같습니다. 이 직사각형을 네 개의 작은 직사각형으로 나누었을 때, 각 부분의 넓이인 $ac, ad, bc, bd$를 모두 더하면 전체 넓이가 된다는 원리가 전개의 핵심입니다.

### 기본 성질
다항식의 전개에서 가장 기본이 되는 원리는 분배법칙입니다. $A(B+C) = AB + AC$와 같이 괄호 밖의 항을 괄호 안의 각 항에 차례대로 곱해줍니다. 또한, 전개된 결과에서 차수가 같은 항들을 모아 정리하는 과정이 반드시 필요합니다. 곱셈의 순서나 결합 법칙이 성립하므로 전개의 결과는 유일하며, 다항식의 차수는 전개 전 두 다항식의 차수의 합과 같습니다.

## 학습 체크
- 분배법칙을 적용할 때 괄호 안의 모든 항에 빠짐없이 곱해졌는가?
- 전개 후 동류항을 정리하는 과정에서 부호 오류가 발생하지 않았는가?
- 전개된 식의 최고차항의 차수가 원래 식의 차수 합과 일치하는가?

## 관련 개념
- **다항식**: 전개의 대상이 되는 기본 단위로, 여러 개의 항이 덧셈이나 뺄셈으로 연결된 식입니다.
- **곱셈 공식**: 다항식의 전개를 빠르고 효율적으로 수행하기 위해 미리 유도된 특수한 형태의 전개식입니다.
- **인수분해**: 다항식의 전개와 반대되는 과정으로, 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것입니다.
