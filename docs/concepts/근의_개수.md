### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 근의 개수는 **판별식** $D = b^2 - 4ac$의 부호에 의해 다음과 같이 결정됩니다:

- $D > 0$일 때: 서로 다른 **2개의 실근**
- $D = 0$일 때: **중근** (1개, 중복도 2)
- $D < 0$일 때: **실근이 없음** (복소수 범위에서 2개의 허근)

근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \frac{-b \pm \sqrt{D}}{2a}$에서 제곱근 안의 수 $D$가 음수면 실수 범위에서 해가 존재하지 않는다는 사실에서 유래합니다.

### 직관·기하적 의미

이차함수 $y = ax^2 + bx + c$의 그래프는 포물선입니다. 이 포물선이 $x$축과 만나는 점의 개수가 바로 이차방정식의 근의 개수입니다.

- **$D > 0$**: 포물선이 $x$축과 **두 점에서 만남** (두 근은 서로 다름)
- **$D = 0$**: 포물선이 $x$축에 **접함** (꼭짓점이 $x$축 위)
- **$D < 0$**: 포물선이 $x$축과 **만나지 않음** ($a > 0$이면 항상 $y > 0$, $a < 0$이면 항상 $y < 0$)

따라서 판별식은 이차함수의 그래프 위치를 빠르게 파악하는 강력한 도구입니다.

### 한 줄 예

방정식 $x^2 - 5x + 6 = 0$에서 $D = (-5)^2 - 4(1)(6) = 25 - 24 = 1 > 0$이므로 서로 다른 2개의 실근 $x = 2, 3$을 갖습니다. `sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$

반면 $x^2 - 4x + 4 = 0$은 $D = 16 - 16 = 0$이므로 중근 $x = 2$ (중복도 2)를 갖고, $x^2 + x + 1 = 0$은 $D = 1 - 4 = -3 < 0$이므로 실근이 없습니다.
