### 정의: 접선과 도함수

함수 $f(x)$의 그래프 위의 점 $(a, f(a))$에서의 **접선**(tangent line)이란, 그 점을 지나면서 기울기가 $f'(a)$인 직선입니다. 즉, 도함수 $f'(a)$는 점 $x = a$에서의 접선의 기울기입니다. 접선의 방정식은 다음과 같습니다:

$$y - f(a) = f'(a)(x - a)$$

또는 정리하면 $y = f'(a)(x - a) + f(a)$입니다.

### 직관과 기하적 의미

곡선 위의 한 점에서의 접선을 직관적으로 이해하려면, 그 점 근처에서 곡선을 확대해서 봅시다. 충분히 가까이 보면 매끄러운 곡선은 직선처럼 보입니다. 이 "보이는 직선"이 바로 접선입니다. 

도함수 $f'(a)$는 $x = a$ 근처에서 함수가 얼마나 빠르게 변하는지를 나타내는 **변화율**입니다. 기하학적으로는 정확히 그 점에서의 접선의 기울기와 같습니다. 기울기가 양수면 곡선이 올라가고, 음수면 내려가며, 0이면 그 점에서 수평입니다.

### 구체적인 예

$f(x) = x^2$이고 $x = 2$에서의 접선을 구해봅시다.

먼저 도함수는 $f'(x) = 2x$이므로, $x = 2$에서 기울기는 $f'(2) = 4$입니다.

점 $(2, f(2)) = (2, 4)$를 지나고 기울기가 4인 접선의 방정식:

$$y - 4 = 4(x - 2) \quad \Rightarrow \quad y = 4x - 4$$

따라서 접선의 방정식은 $y = 4x - 4$입니다.

```python
# 검산: sympy로 확인
from sympy import symbols, diff
x = symbols('x')
f = x**2
f_prime = diff(f, x)  # f'(x) = 2x
slope_at_2 = f_prime.subs(x, 2)  # f'(2) = 4
```

### 핵심 정리

- **접선의 기울기 = 도함수의 값**: $f'(a)$는 점 $(a, f(a))$에서 곡선에 그은 접선의 기울기
- **미분의 기하학적 의미**: 도함수를 배운다는 것은 곡선의 "순간 기울기"를 구하는 방법을 배운다는 뜻
- **접선의 방정식**: 점 $(a, f(a))$에서의 접선은 $y = f'(a)(x - a) + f(a)$로 바로 구할 수 있습니다
