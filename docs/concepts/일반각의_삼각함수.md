# 일반각의 삼각함수

## 요약
좌표평면 위에서 동경 위의 점의 좌표를 이용하여 모든 실수 각도에 대한 삼각함수의 값을 정의한다.

## 본문
예각삼각형에서 정의한 삼각함수는 $0^\circ$보다 크고 $90^\circ$보다 작은 각도에서만 쓸 수 있지만, 일반각의 삼각함수는 이 범위를 모든 실수 각도로 확장한 것이다. 좌표평면 위에서 원점 $O$를 꼭짓점으로 하고, 시초선을 $x$축의 양의 방향으로 정한다. 각도 $\theta$만큼 회전한 동경 위의 임의의 점을 $\mathrm{P}(x, y)$라 하고, 원점에서 이 점까지의 거리를 $r = \sqrt{x^2 + y^2}\;(r > 0)$이라 하면, 삼각함수를 다음과 같이 정의한다.

$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}\;(x \neq 0)$$

### 직관과 기하적 의미
삼각함수의 값은 동경 위의 점 $\mathrm{P}$의 좌표와 원점 사이의 거리 $r$ 사이의 관계를 나타낸다. 이는 단순히 삼각형의 변의 길이 비를 넘어, 좌표평면 위에서 회전하는 동경의 위치를 나타내는 도구로 확장된다. 따라서 각도가 $90^\circ$를 넘는 둔각이거나, 시계 방향으로 회전하여 음의 각도를 갖더라도 좌표를 통해 삼각함숫값을 명확히 결정할 수 있다.

### 기본 성질
$r$은 항상 양수이므로, $\sin\theta$와 $\cos\theta$의 부호는 점 $\mathrm{P}$가 위치한 사분면에 따라 결정된다. 제1사분면에서는 $\sin, \cos, \tan$ 모두 양수이며, 제2사분면에서는 $\sin\theta$만 양수이다. 제3사분면에서는 $\tan\theta$만 양수이고, 제4사분면에서는 $\cos\theta$만 양수이다.

**예시 1.** $\theta = 150^\circ$일 때, 동경은 제2사분면에 위치한다. 반지름 $r=1$인 단위원과의 교점은 $\mathrm{P}\left(-\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$이므로,
$$\sin 150^\circ = \frac{1/2}{1} = \frac{1}{2}, \quad \cos 150^\circ = \frac{-\sqrt{3}/2}{1} = -\frac{\sqrt{3}}{2}, \quad \tan 150^\circ = \frac{1/2}{-\sqrt{3}/2} = -\frac{1}{\sqrt{3}}$$

**예시 2.** $\theta = -\frac{\pi}{4}$일 때, 교점은 $\mathrm{P}\left(\frac{\sqrt{2}}{2}, -\frac{\sqrt{2}}{2}\right)$이므로,
$$\sin\left(-\frac{\pi}{4}\right) = -\frac{\sqrt{2}}{2}, \quad \cos\left(-\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$$

## 학습 체크
- 동경 위의 점 $\mathrm{P}(x, y)$의 좌표와 원점 사이의 거리 $r$을 이용하여 $\sin\theta, \cos\theta, \tan\theta$를 정의할 수 있는가?
- 각 $\theta$의 위치(사분면)에 따라 $\sin\theta, \cos\theta, \tan\theta$의 부호가 어떻게 결정되는지 설명할 수 있는가?
- 음의 각도나 $90^\circ$를 초과하는 각에 대해서도 좌표를 이용해 삼각함숫값을 구할 수 있는가?

## 관련 개념

**삼각함수 (선수)** — 직각삼각형에서 두 변의 비로 정의한 삼각함수가 출발점이다. 일반각의 삼각함수는 그 정의를 좌표평면 전체로 확장한 것이므로, 직각삼각형 정의와 완전히 호환된다.

**일반각** — 시초선과 동경의 관계로 크기를 정의하는 각의 개념으로, 양의 각·음의 각·$360°$ 이상의 각을 모두 포괄한다. 일반각의 삼각함수는 이 개념 위에서 비로소 의미를 갖는다.

**삼각함수의 주기성** — 동경이 한 바퀴($2\pi$) 돌면 같은 위치로 돌아오므로, $\sin(\theta + 2\pi) = \sin\theta$, $\cos(\theta + 2\pi) = \cos\theta$가 성립한다. 주기성은 일반각 정의에서 자연스럽게 도출된다.

**삼각함수의 그래프** — 일반각에서 정의된 삼각함수를 실수 전체에서 그리면 특유의 파동 모양이 나타난다. 그래프의 형태, 주기, 최댓값·최솟값은 모두 일반각 정의로부터 설명된다.
