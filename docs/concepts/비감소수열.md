### 정확한 진술

수열 $\{a_n\}$이 모든 항에 대해 다음을 만족할 때 **비감소수열**(non-decreasing sequence)이라고 합니다:

$$a_1 \leq a_2 \leq a_3 \leq \cdots \leq a_n$$

다르게 표현하면, 인접한 모든 항에 대해 $a_{n+1} \geq a_n$을 만족합니다.

### 직관과 의의

비감소수열은 오른쪽으로 갈수록 값이 '커지거나 같은 패턴'을 유지합니다. 항이 절대 감소하지 않는다는 뜻이며, 이는 경우의 수와 조합론에서 매우 중요합니다. 특히 **중복조합** 문제를 셀 때 비감소수열이 자연스럽게 등장합니다. 예를 들어, 같은 것 $n$개를 $k$개의 서로 다른 상자에 넣는 경우의 수는 길이 $k$인 비감소수열의 개수와 일대일 대응되며, 이는 $\binom{n+k-1}{k-1}$으로 계산됩니다.

### 예시

수열 $2, 2, 3, 5, 5, 5, 7$은 비감소수열입니다. 각 항이 이전 항 이상의 값을 가지기 때문입니다. 반면 $1, 3, 2, 5$는 $3 > 2$이므로 비감소수열이 아닙니다. 상수수열 $5, 5, 5, 5$도 모든 항이 같으므로 비감소수열입니다 ($\leq$ 포함).
