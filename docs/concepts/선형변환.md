# 선형변환

## 요약
벡터 공간 사이의 구조를 보존하며 벡터를 다른 벡터로 대응시키는 함수입니다.

## 본문
선형변환이란 두 벡터 공간 $V$와 $W$ 사이의 함수 $f: V \to W$ 중에서, 벡터의 덧셈과 스칼라 곱이라는 두 가지 연산 구조를 보존하는 사상을 의미합니다. 즉, 임의의 벡터 $\mathbf{u}, \mathbf{v} \in V$와 임의의 스칼라 $c$에 대하여 $f(\mathbf{u} + \mathbf{v}) = f(\mathbf{u}) + f(\mathbf{v})$와 $f(c\mathbf{u}) = cf(\mathbf{u})$를 동시에 만족해야 합니다. 이러한 성질 덕분에 선형변환은 복잡한 벡터 공간의 변환을 기저(basis) 벡터들의 이동만으로도 완전히 설명할 수 있게 해주는 강력한 도구가 됩니다.

### 직관과 기하적 의미
기하학적으로 선형변환은 공간을 왜곡시키되, 원점($\mathbf{0}$)을 고정시키고 모든 직선을 직선으로 유지하며 격자 구조를 평행하게 유지하는 변환을 의미합니다. 예를 들어, 공간을 회전시키거나, 크기를 확대 또는 축소하거나, 혹은 한 축 방향으로 늘리는 변환 등이 모두 선형변환에 해당합니다. 만약 변환 후 직선이 곡선으로 휘어지거나 원점이 이동한다면 그것은 선형변환이 아닙니다.

### 기본 성질
선형변환은 선형 결합을 보존합니다. 즉, 벡터들의 선형 결합에 함수를 적용한 결과는 각 벡터에 함수를 적용한 후 다시 선형 결합한 결과와 같습니다. 또한, 모든 선형변환은 반드시 원점을 원점으로 보냅니다($f(\mathbf{0}) = \mathbf{0}$). 이러한 성질로 인해 선형변환은 행렬(matrix)을 이용한 곱셈 연산으로 완벽하게 표현될 수 있습니다.

## 학습 체크
- 함수 $f$가 $f(\mathbf{u} + \mathbf{v}) = f(\mathbf{u}) + f(\mathbf{v})$와 $f(c\mathbf{u}) = cf(\mathbf{u})$를 모두 만족하는지 확인하였는가?
- 변환된 공간에서 격자선이 휘어지거나 원점이 이동하지 않는지 기하학적으로 이해하였는가?
- 주어진 선형변환을 행렬의 형태로 나타낼 수 있는가?

## 관련 개념
- **확률**: 확률 변수의 분포를 변환하거나, 확률 밀도 함수가 선형 결합에 대해 어떻게 변화하는지 분석할 때 선형변환의 원리가 적용됩니다.
