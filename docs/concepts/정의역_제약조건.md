### 정확한 진술

함수의 **정의역**은 함수가 정의되는 입력값 $x$의 범위를 뜻합니다. 이차함수 $f(x) = ax^2 + bx + c$는 원래 모든 실수에서 정의되지만, 문제에서 "정의역이 $[p, q]$일 때" 같은 조건이 주어지면 그 구간에서만 함수를 다루어야 합니다. 이를 **정의역 제약조건**이라 합니다.

정의역 제약은 여러 상황에서 나타납니다. 예를 들어 직사각형의 넓이를 가로 길이 $x$의 함수로 나타낼 때, $x$는 양수여야 하므로 자동으로 정의역이 $(0, \infty)$로 제한됩니다.

### 직관/기하적 의미

이차함수의 그래프는 포물선 모양입니다. 정의역에 제약이 없으면 포물선 전체를 봅니다. 그러나 정의역이 $[p, q]$로 제한되면, 실제 함수의 그래프는 그 포물선에서 구간 $p \le x \le q$에 해당하는 부분만입니다.

이는 **최댓값과 최솟값의 위치가 달라진다**는 뜻입니다. 대칭축 $x = -\frac{b}{2a}$이 정의역 안에 있으면 축에서 극값을 가지고, 축이 정의역 밖에 있으면 정의역의 끝점에서만 극값을 갖습니다.

### 한 줄 예

$f(x) = (x-2)^2 + 1$을 생각해봅시다 (대칭축: $x=2$).

- **정의역이 실수 전체**: 최솟값은 $f(2) = 1$
- **정의역이 $[3, 5]$**: 최솟값은 $f(3) = 2$ (축 $x=2$가 정의역 밖이므로 왼쪽 끝에서)
- **정의역이 $[0, 3]$**: 최솟값은 $f(2) = 1$ (축이 안에 있음), 최댓값은 $f(0) = 5$

```python
# 검산: sympy.solve((x-2)**2 + 1 - y, y) 또는 정의역별 최솟값 확인
# f(3) = (3-2)^2 + 1 = 2
```
