# 삼각함수 미분 예제

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$y=\sin x \cos x$ 미분

## 본문 (학습 시 채워짐)

### 문제

다음 함수를 미분하시오.
$$y = \sin x \cos x$$

### 풀이

**방법 1: 곱의 미분법**

$\sin x$와 $\cos x$의 곱이므로 곱의 미분법 $(uv)' = u'v + uv'$를 적용합니다. $u = \sin x$, $v = \cos x$로 놓으면 $u' = \cos x$, $v' = -\sin x$입니다.

$$y' = \cos x \cdot \cos x + \sin x \cdot (-\sin x)$$

각 항을 정리합니다.

$$y' = \cos^2 x - \sin^2 x$$

배각공식 $\cos 2x = \cos^2 x - \sin^2 x$를 이용하여 더 간단히 나타냅니다.

$$y' = \cos 2x$$

**방법 2: 항등식으로 먼저 정리**

곱셈-합 공식 $\sin x \cos x = \frac{1}{2} \sin 2x$를 이용하여 원래 함수를 먼저 단순화합니다.

$$y = \frac{1}{2} \sin 2x$$

이제 합성함수의 미분법을 적용합니다. $\sin 2x$의 미분값은 $2 \cos 2x$이므로:

$$y' = \frac{1}{2} \cdot 2 \cos 2x = \cos 2x$$

### 답

$$y' = \cos 2x$$

### 변형 및 주의

두 방법 모두 같은 답을 줍니다. 방법 1은 곱의 미분법을 연습하는 데 유용하고, 방법 2는 삼각함수 항등식과 합성함수 미분의 관계를 보여줍니다. 시험에서는 계산 실수를 줄이기 위해 **미분 전에 먼저 항등식으로 정리하는 방법 2를 권장**합니다.

**검산**: `sympy.diff(sympy.sin(sympy.symbols('x')) * sympy.cos(sympy.symbols('x')), sympy.symbols('x'))`
