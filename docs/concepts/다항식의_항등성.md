### 정확한 진술

두 다항식 $P(x)$와 $Q(x)$가 **항등적으로 같다**(또는 **항등성이 성립한다**)는 것은, 모든 실수 $x$에 대해 $P(x) = Q(x)$가 성립하는 경우를 말합니다. 기호로는 $P(x) \equiv Q(x)$로 나타내기도 합니다.

더 정확하게, 두 다항식이 항등적으로 같으려면 **각 차수의 계수가 모두 같아야** 합니다. 예를 들어, $P(x) = a_nx^n + \cdots + a_1x + a_0$과 $Q(x) = b_nx^n + \cdots + b_1x + b_0$이 항등적으로 같으면 $a_n = b_n, a_{n-1} = b_{n-1}, \ldots, a_0 = b_0$입니다.

### 직관과 의미

항등식은 **우연이 아닌 구조적 필연성**으로 성립합니다. 단순히 몇 개의 $x$ 값에서만 같은 것이 아니라, 모든 값에서 같다는 뜻입니다. 

이는 인수분해나 전개를 할 때 양변의 계수를 직접 비교할 수 있다는 의미입니다. 예를 들어 $(x+1)^2 = x^2 + 2x + 1$은 좌변을 전개했을 때 우변과 완전히 같아지므로, 별도 검증 없이 항상 참입니다. 이렇게 항등식은 **다항식의 구조를 파악하고 문제를 풀 때 강력한 도구**가 됩니다.

### 한 줄 예

$(x-2)(x+3) \equiv x^2 + x - 6$ (모든 $x$에서 항상 성립)

### 참고: 항등식과 방정식의 차이

**항등식**: 포함된 모든 값에서 참 (예: $x^2 - 1 = (x-1)(x+1)$)  
**방정식**: 특정 값에서만 참 (예: $x^2 = 4$ ⟹ $x = \pm 2$)

`sympy.expand((x-2)*(x+3)) - (x**2+x-6)` → 결과: $0$ (항등식 확인)
