### 정확한 진술

새로운 연산이란, 두 수에 대해 기존의 덧셈·곱셈과 다른 계산 규칙을 명시적으로 정의하여 만든 연산입니다. 일반적으로 기호 $\star$, $\circ$, $\ast$ 등으로 나타내며, 두 실수 $a$, $b$에 대해 $a \star b = f(a, b)$ 형태로 주어집니다. 여기서 $f(a, b)$는 $a$와 $b$의 덧셈, 곱셈, 거듭제곱 등을 포함한 어떤 식입니다.

### 직관과 의미

일상에서 접하는 덧셈($+$)과 곱셈($\times$)은 자연스럽고 이미 정해진 연산입니다. 그러나 수학에서는 **문제 상황에 맞게 새로운 연산을 만들어** 사용하기도 합니다. 새로운 연산을 배우는 이유는:

- 주어진 정의를 정확히 읽고 이해하는 능력 강화
- 그 연산이 어떤 성질을 만족하는지(교환법칙, 결합법칙 등) 탐구
- 추상적 규칙을 다루는 수학적 사고력 발달

예를 들어 $a \star b = a + b + ab$로 정의하면, 이것은 단순한 덧셈이 아니라 "두 수를 더하고, 거기에 그들의 곱을 더한" 특정한 규칙입니다.

### 구체적 예

$a \star b = 2a + b$일 때:

$$3 \star 5 = 2(3) + 5 = 6 + 5 = 11$$

(`sympy.sympify('2*3 + 5')` = 11)

### 주의: 순서가 중요

새로운 연산은 **교환법칙이 성립하지 않는** 경우가 대부분입니다. 위 예에서 $5 \star 3 = 2(5) + 3 = 13 \neq 11$이므로 $a \star b \neq b \star a$입니다. 따라서 항상 주어진 순서대로 계산해야 합니다.
