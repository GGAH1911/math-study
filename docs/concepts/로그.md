# 로그

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\log_a b$ — $a^x=b$인 $x$

## 본문 (학습 시 채워짐)

### 정확한 진술

$a > 0$, $a \neq 1$, $b > 0$일 때, 로그 $\log_a b$는 다음을 만족하는 수 $x$입니다:

$$a^x = b$$

즉, $\log_a b = x \Leftrightarrow a^x = b$ 입니다. 여기서 $a$를 **밑**(base), $b$를 **진수**(argument)라고 부릅니다.

### 직관: 지수의 역연산

로그는 **지수 방정식을 푸는 도구**입니다. 지수 함수 $a^x = b$에서 $x$를 구하려 할 때, 간단한 경우는 암산이 가능합니다($2^x = 8 \Rightarrow x = 3$). 하지만 $2^x = 5$라면? 바로 이때 로그를 사용해 $x = \log_2 5$라고 표현합니다. 로그는 지수로 **숨겨진 지수를 꺼내는** 역함수입니다.

### 기하적 의미

좌표평면에서 지수 함수 $y = a^x$의 그래프 위의 점 $(x, b)$를 생각해봅시다. 이 점의 $x$좌표가 정확히 $\log_a b$입니다. 달리 말하면, 함수 $y = \log_a x$는 $y = a^x$를 직선 $y = x$에 대해 대칭이동한 **역함수**입니다.

### 예시

$\log_2 8 = 3$ (∵ $2^3 = 8$)  
$\log_5 25 = 2$ (∵ $5^2 = 25$)  
$\log_3 1 = 0$ (∵ $3^0 = 1$)  
$\log_2 \frac{1}{4} = -2$ (∵ $2^{-2} = \frac{1}{4}$)

(Python: `from sympy import log; log(8, 2)` 결과 `3`)

### 주의: 정의역 조건

로그 $\log_a b$가 정의되려면 **밑 조건**: $a > 0$, $a \neq 1$이고, **진수 조건**: $b > 0$이어야 합니다. 음수나 0의 로그는 정의되지 않습니다.
