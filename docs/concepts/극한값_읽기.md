# 극한값 읽기

## 요약
변수 $x$가 어떤 값에 한없이 가까워질 때, 함수의 함숫값이 어떤 일정한 값에 한없이 가까워지면 그 값을 극한값이라고 합니다.

## 본문
함수 $f(x)$에서 $x$의 값이 $a$에 한없이 가까워질 때, $f(x)$의 값이 일정한 값 $\alpha$에 한없이 가까워지면 우리는 $\lim_{x \to a} f(x) = \alpha$라고 표기하며, 이때 $\alpha$를 함수 $f(x)$의 극한값이라고 정의합니다. 여기서 '한없이 가까워진다'는 것은 $x$가 $a$에 매우 가까워지더라도 $f(x)$와 $\alpha$ 사이의 거리가 임의의 양수보다 작아질 수 있음을 의미합니다. 이때 중요한 점은 $x$가 $a$에 도달할 필요는 없으며, $a$ 근처의 값들을 고려한다는 것입니다.

### 직관과 기하적 의미
그래프 상에서 $x$가 $a$를 향해 왼쪽이나 오른쪽에서 접근할 때, 함수의 그래프가 향하는 높이를 의미합니다. 즉, $x$가 $a$에 다가갈 때 그래프가 특정 높이 $\alpha$를 향해 수렴하는 양상을 보인다면 그 높이가 곧 극한값입니다.

### 기본 성질
함수 $f(x)$와 $g(x)$의 극한값이 각각 존재할 때, 두 함수의 합, 차, 곱, 그리고 분모가 $0$이 아닌 경우의 몫에 대해서도 극한값이 존재하며, 각 함수의 극한값의 사칙연산 결과는 각 극한값의 사칙연산 결과와 같습니다.

## 학습 체크
- $x$가 $a$로 갈 때 좌극한과 우극한이 서로 일치하는가?
- 극한값이 존재하기 위한 조건인 좌극한과 우극한의 일치 여부를 확인하였는가?

## 관련 개념
- **함수의 극한과 연속**: 극한값이 존재하고 그 값이 실제 함숫값과 일치할 때 함수가 연속이라고 정의합니다.
