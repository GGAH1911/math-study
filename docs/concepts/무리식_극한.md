# 무리식 극한

## 정의

극한값을 구할 때 분자·분모에 근호($\sqrt{\phantom{x}}$)가 포함되어 $\frac{0}{0}$ 꼴의 부정형이 나타나는 경우를 **무리식 극한**이라 한다. 이때 분자 또는 분모를 **유리화(rationalization)**하여 인수분해 가능한 형태로 변형한 뒤 약분하는 것이 기본 전략이다. $\sqrt{A}-\sqrt{B}$ 꼴은 켤레식 $\sqrt{A}+\sqrt{B}$를 곱해 $A-B$로 바꾼다.

## 예시

$$\lim_{x \to 3} \frac{\sqrt{x+1}-2}{x-3}$$

분자를 유리화:

$$= \lim_{x \to 3} \frac{(\sqrt{x+1}-2)(\sqrt{x+1}+2)}{(x-3)(\sqrt{x+1}+2)} = \lim_{x \to 3} \frac{x-3}{(x-3)(\sqrt{x+1}+2)} = \lim_{x \to 3} \frac{1}{\sqrt{x+1}+2} = \frac{1}{4}$$

## 관련 개념

- 함수의 극한
- 유리화
- 부정형 $\frac{0}{0}$
- 인수분해와 약분
