# 면적함수

## 정의

연속함수 $f(t)$에 대해 아래끝이 고정된 정적분으로 정의되는 함수

$$F(x) = \int_a^x f(t)\,dt$$

를 **면적함수** 또는 **누적면적함수**라 한다. 미적분의 기본정리에 의해 $F'(x) = f(x)$이므로, $F(x)$는 $f(x)$의 역도함수(부정적분)이다. $f(t) \ge 0$인 구간에서 $F(x)$는 곡선 $y=f(t)$와 $t$축 사이의 넓이를 나타낸다.

## 예시

$f(t) = 2t$, $a=0$으로 놓으면

$$F(x) = \int_0^x 2t\,dt = \left[t^2\right]_0^x = x^2$$

$F'(x) = 2x = f(x)$임을 확인할 수 있다. $x>0$일 때 $F(x) = x^2$은 원점에서 $x$까지 $y=2t$ 아래 삼각형의 넓이와 일치한다.

## 관련 개념

- 정적분
- 미적분의 기본정리
- 역도함수(부정적분)
- 넓이와 정적분
