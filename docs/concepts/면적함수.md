# 면적함수

## 요약
연속함수의 정적분을 통해 정의되는 함수로, 미적분의 기본정리에 의해 원래 함수의 역도함수 역할을 수행한다.

## 본문
연속함수 $f(t)$에 대하여 아래끝이 고정된 정적분으로 정의되는 함수 $F(x) = \int_a^x f(t)\,dt$를 면적함수 또는 누적면적함수라고 한다. 미적분의 기본정리에 따르면 $F'(x) = f(x)$이므로, $F(x)$는 $f(x)$의 역도함수(부정적분)가 된다.

### 직관과 기하적 의미
$f(t) \ge 0$인 구간에서 $F(x)$는 곡선 $y=f(t)$와 $t$축 사이의 넓이를 나타낸다. 예를 들어 $f(t) = 2t$이고 $a=0$일 때, $F(x) = \int_0^x 2t\,dt = x^2$이다. 이때 $x>0$인 범위에서 $F(x) = x^2$의 값은 원점에서 $x$까지 $y=2t$ 아래에 형성되는 삼각형의 넓이와 정확히 일치한다.

### 기본 성질
1. $F'(x) = f(x)$이므로, 면적함수를 미분하면 원래의 함수가 된다.
2. $F(a) = \int_a^a f(t)\,dt = 0$이므로, 면적함수는 아래끝인 $a$에서 항상 $0$의 값을 가진다.

## 학습 체크
- $F(x)$를 미분했을 때 원래 함수 $f(x)$가 도출되는 과정을 미적분의 기본정리와 연결하여 설명할 수 있는가?
- $f(t)$가 음수인 구간을 포함할 때, $F(x)$의 증감 상태와 기하학적 넓이 사이의 관계를 이해하고 있는가?

- 역도함수(부정적분)
- 넓이와 정적분
