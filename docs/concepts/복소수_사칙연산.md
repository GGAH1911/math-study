# 복소수 사칙연산

> **예제** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
나눗셈은 켤레 곱하기

## 본문 (학습 시 채워짐)

### 문제

다음 복소수 나눗셈을 계산하세요.
$$\frac{1+2i}{3-i}$$

### 풀이

**1단계: 분모의 켤레복소수 파악하기**  
분모 $3-i$의 켤레복소수는 $3+i$입니다. (허수부의 부호만 바꿈)

**2단계: 분자와 분모에 켤레를 곱하기**  
분자와 분모에 $3+i$를 곱합니다. 왜일까요? 분모에 곱하면 $i^2=-1$을 이용해 실수로 만들 수 있기 때문입니다.
$$\frac{1+2i}{3-i} \cdot \frac{3+i}{3+i}$$

**3단계: 분자 계산하기**  
$(1+2i)(3+i)$를 전개합니다.
$$(1+2i)(3+i) = 1 \cdot 3 + 1 \cdot i + 2i \cdot 3 + 2i \cdot i = 3 + i + 6i + 2i^2$$

$i^2 = -1$을 대입하면:
$$3 + i + 6i - 2 = 1 + 7i$$

**4단계: 분모 계산하기**  
$(3-i)(3+i)$를 계산합니다. (합차공식 또는 직접 계산)
$$(3-i)(3+i) = 9 - i^2 = 9 - (-1) = 10$$

**5단계: 정리하기**  
$$\frac{1+7i}{10} = \frac{1}{10} + \frac{7}{10}i$$

(검산: `sympy.simplify((1+2j)/(3-1j))` = $0.1 + 0.7j$)

### 답

$$\frac{1}{10} + \frac{7}{10}i$$

### 변형·주의

복소수 나눗셈의 핵심은 **분모를 켤레로 곱해서 실수로 만드는 것**입니다. 이는 분수 정리의 일반화된 방법입니다. 만약 분모가 이미 실수(허수부가 0)라면 켤레를 곱할 필요가 없으니 주의하세요. 또한 계산 실수를 피하려면 분자 전개 시 항을 하나하나 꼼꼼히 세어서, $i^2 = -1$을 놓치지 않도록 합니다.
