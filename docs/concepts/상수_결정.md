# 상수 결정

## 요약
주어진 조건이나 함수값을 이용하여 미지수로 남아 있는 계수나 상수의 값을 찾아내는 과정입니다.

## 본문
함수나 식의 형태가 미지수를 포함하고 있을 때, 특정 지점에서의 함숫값이나 도함수의 값 등 주어진 조건을 대입하여 미지수의 값을 결정하는 것을 의미합니다. 이는 함수의 식을 완전히 확정 짓기 위해 필수적인 과정이며, 주로 미분법이나 적분법을 통해 얻은 식에 특정 좌표를 대입함으로써 수행됩니다.

### 직관과 기하적 의미
함수의 그래프가 특정 점을 지난다는 것은 그 점의 좌표를 함수식에 대입했을 때 등식이 성립함을 의미합니다. 기하학적으로는 그래프가 특정 위치를 통과하도록 함수의 높낮이나 기울기를 조정하는 과정으로 이해할 수 있습니다.

### 기본 성질
상수를 결정하기 위해서는 반드시 식의 형태를 결정할 수 있는 충분한 개수의 조건이 필요합니다. 예를 들어, 이차함수와 같이 미지수가 두 개라면 두 개의 독립적인 조건이 주어져야 상수를 모두 결정할 수 있습니다.

## 학습 체크
- 함수식에 주어진 좌표를 대입했을 때 식이 성립하는가?
- 미지수의 개수와 주어진 조건의 개수가 일치하는가?
- 도함수를 이용할 경우, 특정 점에서의 접선의 기울기 조건이 올바르게 적용되었는가?

## 관련 개념
- **정적분의 활용**: 정적분 계산 과정에서 나타나는 적분상수 $C$를 함수의 초기값 조건을 통해 결정하는 과정이 포함됩니다.
