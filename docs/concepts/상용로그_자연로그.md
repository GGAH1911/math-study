# 상용로그 자연로그

> **정의** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\log_{10}, \ln$

## 본문 (학습 시 채워짐)

### 정확한 진술

**상용로그**(common logarithm)는 밑이 10인 로그로, $\log_{10} x$ 또는 간단히 $\log x$로 나타냅니다. 즉 $\log x = y$는 $10^y = x$를 의미합니다. **자연로그**(natural logarithm)는 밑이 자연상수 $e \approx 2.71828\ldots$인 로그로, $\ln x$ 또는 $\log_e x$로 나타냅니다. 다시 말해 $\ln x = y$는 $e^y = x$를 의미합니다.

### 직관과 실용성

상용로그는 **10진법을 기반**으로 하여 과학과 공학 분야에서 오랫동안 수치 계산의 도구였습니다. $\log 1000 = 3$처럼 10의 거듭제곱과의 관계가 직관적이고, 계산기가 없던 시대에 로그표로 큰 수의 곱셈을 더하기로 바꿀 수 있었기에 실용적이었습니다. 반면 자연로그는 **미적분학의 핵심 도구**로, 지수함수 $e^x$의 도함수가 자신과 같다는 기본 성질에서 나타납니다. 성장·감소 현상(방사성 붕괴, 인구증가, 복리)이나 확률, 적분 계산에서 자연스럽게 등장하므로 순수수학과 자연과학에서 필수적입니다.

### 밑 변환과 수능 학습

두 로그는 **밑 변환 공식**으로 연결됩니다:
$$\ln x = \frac{\log x}{\log e}, \quad \log x = \frac{\ln x}{\ln 10}$$

한국 수능 수학에서는 **자연로그가 훨씬 중요**합니다. 수학Ⅰ 단원에서도 상용로그를 배우지만, 미적분에서 지수·로그함수의 도함수를 다룰 때 $(\ln x)' = \dfrac{1}{x}$, $(e^x)' = e^x$가 핵심이기 때문입니다.

### 간단한 예

- $\log 100 = 2$ (∵ $10^2 = 100$)  
- $\ln e = 1$ (∵ $e^1 = e$)  
- $\log 0.01 = -2$ (∵ $10^{-2} = 0.01$)

`sympy.log(100, 10), sympy.ln(sympy.E)` → `(2, 1)`
