# 공간 두 점 거리

> **정리** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3D 거리공식

## 본문 (학습 시 채워짐)

### 진술

공간의 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 다음 식으로 주어진다:

$$\overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

### 유도 과정

평면좌표에서 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$ 사이의 거리가 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$라는 피타고라스 정리의 응용이었듯이, 공간좌표에서도 같은 원리를 적용한다. 점 $A$에서 점 $B$로 향하는 벡터를 생각하면, $x$축 방향 변화 $(x_2-x_1)$, $y$축 방향 변화 $(y_2-y_1)$, $z$축 방향 변화 $(z_2-z_1)$의 세 성분을 모두 고려해야 한다. 먼저 $xy$-평면에 정사영한 거리는 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$이고, 여기에 $z$축 방향 거리 $|z_2-z_1|$을 포함하면 피타고라스 정리에 의해 전체 거리가 구해진다.

### 의의 및 응용

이 공식은 공간도형의 기본 도구로, 두 점이 이루는 거리를 정량화할 수 있게 해준다. 정사영, 벡터의 크기 계산, 점과 평면 사이의 거리 등 더 복잡한 공간 기하 문제의 토대가 된다. 또한 벡터로 표현하면 $|\vec{AB}| = \sqrt{\vec{AB} \cdot \vec{AB}}$ 형태가 되어 벡터의 내적과도 자연스럽게 연결된다. 수능에서는 주어진 좌표로 직접 계산하는 것이 표준이므로, 공식을 정확히 암기하고 부호를 조심해서 계산하는 연습이 중요하다.

예를 들어 $A(1, 2, 3)$과 $B(4, 6, 15)$ 사이의 거리는 $\sqrt{(4-1)^2 + (6-2)^2 + (15-3)^2} = \sqrt{9+16+144} = \sqrt{169} = 13$이다. (`import sympy; sympy.sqrt((4-1)**2 + (6-2)**2 + (15-3)**2)`)
