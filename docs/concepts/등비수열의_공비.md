# 등비수열의 공비

## 요약
등비수열에서 이웃한 두 항의 비가 항상 일정할 때, 그 일정한 값을 공비라고 하며 보통 $r$로 나타낸다.

## 본문
등비수열 $\{a_n\}$에서 공비 $r$은 다음과 같이 정의된다.
$$r = \frac{a_{n+1}}{a_n} \quad (a_n \neq 0,\; n = 1, 2, 3, \ldots)$$
즉, 수열의 임의의 항을 선택하여 바로 다음 항을 해당 항으로 나누면 항상 일정한 값 $r$이 도출된다. 공비는 양수, 음수, 분수, 소수 등 다양한 형태를 가질 수 있으나, $r=0$인 경우에는 두 번째 항부터 모든 항이 $0$이 되어 등비수열의 성질을 유지할 수 없으므로 공비는 반드시 $0$이 아닌 수여야 한다.

### 직관과 기하적 의미
공비는 수열의 각 항이 이전 항에 비해 어떤 비율로 변화하는지를 나타내는 척도이다. 예를 들어 공비가 $3$이라면 각 항은 이전 항보다 $3$배씩 커지며, 공비가 $-\frac{1}{2}$이라면 각 항은 이전 항의 크기를 절반으로 줄이면서 부호가 반대로 바뀐다.

### 기본 성질
- 공비가 양수이면 모든 항의 부호가 일정하거나(첫째 항이 양수일 때), 모든 항의 부호가 모두 음수(첫째 항이 음수일 때)로 유지된다.
- 공비가 음수이면 항의 부호가 양수와 음수를 번갈아 가며 나타난다.
- 공비가 $1$이면 모든 항이 같은 값을 갖는 상수수열이 된다.

## 학습 체크
- 이웃한 두 항의 비를 계산했을 때 항상 동일한 값이 나오는가?
- 공비가 음수일 때 항의 부호가 교대로 바뀌는 현상을 이해하고 있는가?
- 공비가 $0$이 될 수 없는 이유를 수열의 정의와 연결하여 설명할 수 있는가?

## 관련 개념

- **수열**: 수열은 수를 일정한 규칙에 따라 나열한 것이다. 공비는 등비수열이라는 특정 종류의 수열을 특징짓는 핵심 값이므로, 수열의 기본 개념을 먼저 이해해야 공비를 올바르게 파악할 수 있다.
- **등비수열**: 공비는 등비수열을 정의하는 핵심 요소다. 등비수열은 첫째 항 $a_1$과 공비 $r$이 결정되면 모든 항이 $a_n = a_1 \cdot r^{n-1}$로 완전히 결정된다.
- **등차수열의 공차**: 등차수열에서 이웃한 두 항의 **차**가 일정한 것이 공차이듯, 등비수열에서는 이웃한 두 항의 **비**가 일정한 것이 공비다. 공차와 공비는 각각 덧셈 구조와 곱셈 구조에 대응하는 대칭적인 개념이다.
- **등비급수**: 공비의 절댓값이 $1$보다 작을 때($|r| < 1$), 등비수열의 무한합인 등비급수가 수렴한다. 공비의 범위가 급수의 수렴·발산을 결정하는 핵심 조건이 된다.
