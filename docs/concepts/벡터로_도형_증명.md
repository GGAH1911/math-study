# 벡터로 도형 증명

> **예제** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
삼각형 성질 증명

## 본문 (학습 시 채워짐)

### 문제

삼각형 ABC의 꼭짓점 A, B, C의 위치벡터를 각각 $\vec{a}, \vec{b}, \vec{c}$라 하자. BC의 중점을 M이라 하고, 중선 AM 위의 점 G가 A로부터 M 방향으로 2:1로 내분하는 점일 때, G의 위치벡터가 $\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$임을 벡터 계산으로 증명하시오.

### 단계별 풀이

**1단계: 중점 M의 위치벡터 구하기**  
중점의 위치벡터는 두 끝점 위치벡터의 산술평균입니다. BC의 중점 M은:
$$\vec{m} = \frac{\vec{b} + \vec{c}}{2}$$

**2단계: 내분점 공식 적용하기**  
점 G가 선분 AM을 2:1로 내분한다는 것은 AG:GM = 2:1이라는 뜻입니다. 내분점 공식에 따라:
$$\vec{g} = \frac{1 \cdot \vec{a} + 2 \cdot \vec{m}}{2 + 1} = \frac{\vec{a} + 2\vec{m}}{3}$$

**3단계: M의 위치벡터를 대입하여 정리하기**  
위 식에 $\vec{m} = \frac{\vec{b} + \vec{c}}{2}$를 대입합니다:
$$\vec{g} = \frac{\vec{a} + 2 \cdot \frac{\vec{b} + \vec{c}}{2}}{3} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$

### 답

$$\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$

점 G는 삼각형 ABC의 무게중심입니다. 무게중심의 위치벡터는 세 꼭짓점 위치벡터의 산술평균이라는 중요한 성질을 증명했습니다. 예를 들어 A(0, 0), B(2, 0), C(0, 2)인 경우, 무게중심 G의 좌표는 $\left(\frac{2}{3}, \frac{2}{3}\right)$입니다.

### 변형/주의

- **대칭성**: CA의 중점, AB의 중점을 통해 다른 중선을 그어도 같은 점 G를 지나갑니다. 이는 무게중심의 유일성을 보여줍니다.
- **수능 응용**: 좌표계에서 구체적인 점들이 주어질 때 이 공식으로 무게중심을 빠르게 구할 수 있습니다.
