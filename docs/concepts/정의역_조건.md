# 정의역 조건

## 요약
함수 식이 실수로서 수학적 의미를 갖기 위해 변수 $x$가 반드시 만족해야 하는 범위를 의미한다.

## 본문
함수가 실수 값을 가지려면 식 자체가 수학적으로 의미를 가져야 한다. 지수함수 $f(x) = a^x$는 지수 자리에 어떤 실수가 와도 값이 정해지므로 정의역이 자연스럽게 모든 실수가 된다. 그러나 로그함수 $f(x) = \log_a g(x)$는 그렇지 않다. 로그는 진수, 즉 로그 안의 식이 반드시 양수일 때만 정의된다. 진수가 음수이거나 $0$이면 로그 값 자체가 존재하지 않는다. 이처럼 함수 식이 실수로서 의미를 가지기 위해 변수 $x$가 반드시 만족해야 하는 범위를 정의역 조건이라 한다.

로그함수에서 정의역 조건을 세울 때는 두 가지를 동시에 확인해야 한다. 첫째는 밑 조건으로, 밑 $a$는 $a > 0$이고 $a \neq 1$이어야 한다. 둘째는 진수 조건으로, 로그 안의 식 $g(x)$가 반드시 $g(x) > 0$이어야 한다. 만약 밑이 상수로 주어진 경우에는 진수 조건에 해당하는 부등식만 풀어 그 해를 구하면 그것이 곧 함수의 정의역이 된다.

### 직관과 기하적 의미
함수의 그래프가 그려지기 위해서는 $x$값에 따른 $y$값이 실수로 존재해야 한다. 로그함수의 경우 진수 조건에 의해 로그 안의 값이 $0$ 이하가 되는 구간에서는 그래프가 그려지지 않으며, 이는 그래프가 특정 지점에서 끊기거나 존재하지 않는 영역이 생김을 의미한다.

### 기본 성질
- 지수함수 $f(x) = a^x$의 정의역은 모든 실수이다.
- 로그함수 $f(x) = \log_a g(x)$의 정의역은 진수 조건 $g(x) > 0$을 만족하는 $x$의 범위이다.
- 진수 자리에 이차식이 포함된 경우, 이차부등식을 풀어 해를 구해야 한다.

## 학습 체크
- 로그함수에서 진수 조건($g(x) > 0$)을 놓치지 않고 부등식으로 풀었는가?
- 밑이 상수로 주어졌을 때, 밑 조건은 이미 만족한다고 가정하고 진수 조건에만 집중했는가?
- 진수 자리에 이차식이 있을 때, 이차부등식의 해를 정확하게 구하였는가?

## 관련 개념

**지수함수와 로그함수**는 정의역 조건이 서로 대비된다. 지수함수 $a^x$는 모든 실수에서 정의되지만, 로그함수 $\log_a x$는 진수 조건이 반드시 따라붙는다. 두 함수는 서로 역함수 관계이므로, 한 함수의 치역이 곧 다른 함수의 정의역이 된다는 점도 함께 기억해 두면 좋다.

**함수와 그래프**에서 배운 정의역 개념이 여기서 직접 쓰인다. 정의역 조건을 잘못 구하면 그래프를 그릴 때 존재하지 않는 구간까지 그리게 되므로, 그래프를 그리기 전에 정의역을 먼저 확정하는 것이 순서다.

또한 두 로그식의 합이나 로그 안에 분수·이차식이 있는 경우처럼 조건이 여러 개 겹치는 상황에서는 각 조건을 따로 구한 뒤 **교집합**을 취해야 한다. 이때 인접 개념인 **부등식의 풀이**(일차·이차부등식, 절댓값 부등식)가 실질적인 계산 도구가 된다.
