# 정의역 조건

함수가 실수 값을 가지려면 식 자체가 수학적으로 의미를 가져야 한다. 지수함수 $f(x) = a^x$는 지수 자리에 어떤 실수가 와도 값이 정해지므로 정의역이 자연스럽게 모든 실수가 된다. 그러나 로그함수 $f(x) = \log_a g(x)$는 그렇지 않다. 로그는 **진수, 곧 로그 안의 식이 반드시 양수**일 때만 정의된다. 진수가 음수이거나 $0$이면 로그 값 자체가 존재하지 않는다. 이처럼 함수 식이 실수로서 의미를 가지기 위해 변수 $x$가 반드시 만족해야 하는 범위를 **정의역 조건**이라 한다.

로그함수에서 정의역 조건을 세울 때는 두 가지를 동시에 확인한다.

- **밑 조건** : $a > 0$이고 $a \neq 1$
- **진수 조건** : (로그 안의 식) $> 0$

밑이 상수로 주어진 경우에는 진수 조건만 부등식으로 풀면 되고, 그 부등식의 해가 곧 함수의 정의역이 된다.

## 예시

**예시 1.** $f(x) = \log_3(2x - 6)$의 정의역을 구한다.

진수 조건에 의해 $2x - 6 > 0$이어야 하므로 $x > 3$이다. 따라서 정의역은 $\{x \mid x > 3\}$이다.

**예시 2.** $f(x) = \log_2(x^2 - 5x + 4)$의 정의역을 구한다.

진수 조건에 의해 $x^2 - 5x + 4 > 0$이어야 한다. 이를 인수분해하면 $(x-1)(x-4) > 0$이므로 $x < 1$ 또는 $x > 4$이다. 따라서 정의역은 $\{x \mid x < 1 \text{ 또는 } x > 4\}$이다. 이처럼 진수 안에 이차식이 들어오면 이차부등식을 풀어 해를 구한다.

## 관련 개념

**지수함수와 로그함수**는 정의역 조건이 서로 대비된다. 지수함수 $a^x$는 모든 실수에서 정의되지만, 로그함수 $\log_a x$는 진수 조건이 반드시 따라붙는다. 두 함수는 서로 역함수 관계이므로, 한 함수의 치역이 곧 다른 함수의 정의역이 된다는 점도 함께 기억해 두면 좋다.

**함수와 그래프**에서 배운 정의역 개념이 여기서 직접 쓰인다. 정의역 조건을 잘못 구하면 그래프를 그릴 때 존재하지 않는 구간까지 그리게 되므로, 그래프를 그리기 전에 정의역을 먼저 확정하는 것이 순서다.

또한 두 로그식의 합이나 로그 안에 분수·이차식이 있는 경우처럼 조건이 여러 개 겹치는 상황에서는 각 조건을 따로 구한 뒤 **교집합**을 취해야 한다. 이때 인접 개념인 **부등식의 풀이**(일차·이차부등식, 절댓값 부등식)가 실질적인 계산 도구가 된다.
