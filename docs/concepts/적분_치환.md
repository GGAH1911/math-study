# 적분 치환

## 요약
함수의 합성함수 형태를 포함한 적분식을 변수 변환을 통해 단순화하여 계산하는 방법입니다.

## 본문
적분 치환은 복잡한 형태의 피적분함수를 포함하는 정적분이나 부정적분을 계산할 때, 함수 내부의 특정 부분을 새로운 변수로 치환하여 적분이 용이한 형태로 변환하는 기법입니다. 일반적으로 $x$에 대한 함수 $g(x)$가 포함된 식을 $g(x) = t$로 치환하면, 미분법의 연쇄 법칙에 의해 $dx = \frac{dt}{g'(x)}$의 관계가 성립하며, 이를 이용해 적분 변수를 $x$에서 $t$로 바꿉니다. 정적분의 경우 변수의 범위 또한 치환된 변수에 맞춰 변경해주어야 합니다.

### 직관과 기하적 의미
치환 적분은 복잡하게 뒤틀린 좌표계에서의 적분을 표준적인 좌표계로 옮겨와 계산하는 과정과 유사합니다. 함수를 치환하는 것은 적분 구간 내의 가로 길이를 늘리거나 줄이는 변환을 의미하며, 이때 미분값인 $g'(x)$는 변수 변화에 따른 구간 길이의 변화율을 보정해주는 역할을 하여 전체 넓이가 보존되도록 돕습니다.

### 기본 성질
$\int_{a}^{b} f(g(x))g'(x)dx = \int_{g(a)}^{g(b)} f(t)dt$의 관계를 가집니다. 이때 $t = g(x)$로 치환하면 $dt = g'(x)dx$가 되어 식의 구조가 단순해집니다.

## 학습 체크
- 치환할 대상 $g(x)$를 정했을 때, 미분한 형태인 $g'(x)$가 피적분함수에 곱해져 있는가?
- 정적분 계산 시 변수의 범위(적분 구간)를 새로운 변수에 맞춰 정확히 변환하였는가?

## 관련 개념
- **정적분의 활용**: 치환 적분을 통해 계산된 정적분 값은 곡선과 축 사이의 넓이, 회전체의 부피 등을 구하는 데 핵심적인 도구로 사용됩니다.
