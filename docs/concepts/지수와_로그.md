# 지수와 로그

> **단원** · 수학1 · 선수: [다항식](./다항식.md) / [실수와 그 계산](./실수와_그_계산.md) · 다음: [지수함수와 로그함수](./지수함수와_로그함수.md)

## 학습 목표
- 지수의 확장(유리수·실수 지수)을 이해한다
- 로그의 정의와 성질을 자유롭게 활용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- $a^n$ (자연수→정수→유리수→실수)
- 로그 $\log_a b$ (정의: $a^x=b$인 $x$)

**정리(theorem)**
- 지수법칙 일반화
- 로그의 성질 $\log(xy)=\log x+\log y$, $\log x^n = n\log x$
- 밑변환 공식

**예제(example)**
- 거듭제곱근 계산
- 로그의 값 구하기
- 상용로그·자연로그 표 활용
