### 정확한 진술

쌍곡선의 **점근선**(asymptote)은 쌍곡선이 무한히 접근하지만 만나지 않는 직선입니다. 표준형 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$의 점근선은 다음과 같습니다:

$$y = \pm \frac{b}{a}x$$

마찬가지로 표준형 $\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$의 점근선은:

$$y = \pm \frac{a}{b}x$$

점근선을 구하는 빠른 방법은 쌍곡선 방정식의 우변을 0으로 놓고 좌변을 인수분해하는 것입니다. 예를 들어 첫 번째 형태에서 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$은 $\left(\frac{x}{a} - \frac{y}{b}\right)\left(\frac{x}{a} + \frac{y}{b}\right) = 0$으로 인수분해되어 $y = \pm \frac{b}{a}x$를 얻습니다.

### 직관과 기하적 의미

쌍곡선의 두 가지는 원점을 중심으로 대칭이며, $x$ (또는 $y$) 값이 커질수록 쌍곡선은 점근선에 점점 더 가까워집니다. 기하학적으로 점근선은 쌍곡선의 "형태를 결정하는 골격"입니다. 두 점근선 사이의 각도가 작을수록 쌍곡선은 원점에서 멀어질수록 수평에 가까워지고, 각도가 클수록 가파릅니다.

이는 타원(점근선이 없음)과는 달리 쌍곡선만의 특징입니다. 점근선은 쌍곡선을 그릴 때 안내선 역할을 하며, 곡선의 범위와 증감을 파악하는 데 핵심적입니다.

### 한 줄 예

쌍곡선 $\frac{x^2}{4} - \frac{y^2}{9} = 1$의 점근선은 $y = \pm \frac{3}{2}x$입니다. (여기서 $a^2 = 4$, $b^2 = 9$이므로 $a = 2, b = 3$)
