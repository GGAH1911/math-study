# 극값 존재 조건

## 요약
함수 $f(x)$가 어떤 점 $a$에서 극값을 갖기 위해서는 해당 점 근처에서 함수값이 증가하다가 감소하거나, 감소하다가 증가하는 상태의 변화가 일어나야 합니다.

## 본문
함수 $f(x)$가 열린 구간을 포함하는 어떤 구간에서 연속이고, 점 $a$를 포함하는 어떤 열린 구간에서 미분가능할 때, $f'(a)=0$이면 점 $a$는 극값을 가질 후보가 됩니다. 하지만 $f'(a)=0$이라는 조건만으로는 부족하며, $a$의 좌우에서 도함수의 부호가 바뀌어야만 실제 극값을 갖습니다. 즉, $x=a$를 기준으로 $f'(x)$의 부호가 양에서 음으로 변하면 극대, 음에서 양으로 변하면 극소가 됩니다. 만약 $f'(a)=0$임에도 불구하고 좌우에서 부호 변화가 없다면 그 점은 극값이 아닙니다.

### 직관과 기하적 의미
그래프 상에서 극값은 산의 정상이나 골짜기의 바닥과 같습니다. 함수가 증가하다가 감소하는 지점에서는 접선의 기울기가 $0$이 되며, 그래프가 꺾이는 변곡점과는 달리 반드시 위아래로 방향이 바뀌는 지점이어야 합니다.

### 기본 성성
1. 함수가 $x=a$에서 극값을 가지면, $f(x)$는 $x=a$를 포함하는 구간에서 연속입니다.
2. 미분가능한 함수가 $x=a$에서 극값을 가지면, 반드시 $f'(a)=0$을 만족합니다.
3. 도함수의 부호 변화가 없는 $f'(a)=0$인 점은 극값이 아닐 수 있습니다.

## 학습 체크
- $f'(a)=0$이지만 극값이 아닌 대표적인 사례(예: $y=x^3$)를 구분할 수 있는가?
- 함수가 미분 불가능한 점(예: 뾰족한 점)에서도 극값을 가질 수 있음을 이해하고 있는가?
- 도함수의 부호 변화를 통해 극대와 극소를 판정하는 과정을 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수의 부호 변화를 통해 함수의 증가와 감소를 파악하고, 이를 바탕으로 함수의 극대와 극소를 판정하는 원리로 확장됩니다.
