# 같은 것 포함 조합

## 요약
서로 다른 $n$개 중에서 같은 것이 $k$개 포함된 $m$개의 물건을 나열하는 경우의 수는 $\frac{n!}{k!}$로 계산합니다.

## 본문
서로 다른 $n$개의 물건 중에서 같은 것이 $k$개 포함된 $m$개의 물건을 일렬로 나열하는 경우의 수는 전체 $n$개의 물건을 나열하는 경우의 수인 $n!$을 같은 물건들 사이의 순서 변화인 $k!$로 나눈 값과 같습니다. 즉, 모든 물건이 서로 다르다고 가정했을 때의 나열 방식에서, 같은 물건들끼리 자리를 바꾸더라도 구별되지 않는 중복된 경우를 제거하는 원리입니다.

### 직관과 기하적 의미
만약 $n$개의 물건 중 $k$개가 모두 같다면, 이 물건들의 위치를 서로 바꾸는 $k!$가지의 경우의 수는 실제로는 모두 동일한 하나의 상태로 관찰됩니다. 따라서 전체 순열의 수에서 중복되는 만큼 나누어 주는 과정이 필요합니다. 이는 공간상에서 대칭성을 가진 도형의 회전이나 반전 시 중복되는 상태를 하나로 간주하는 원리와 유사한 논리적 구조를 가집니다.

### 기본 성질
물건의 종류가 여러 개일 경우, 각 종류별로 같은 물건의 개수가 $k_1, k_2, \dots, k_r$이라면 전체 경우의 수는 $\frac{n!}{k_1! k_2! \dots k_r!}$이 됩니다. 이때 모든 $k$의 합은 전체 물건의 개수인 $n$과 같아야 합니다.

## 학습 체크
- 나열하려는 물건 중 어떤 것이 '같은 것'인지 명확히 구분할 수 있는가?
- 중복되는 물건의 개수를 정확히 파악하여 분모에 적용하였는가?
- 전체 물건의 개수와 중복되는 개수의 합이 일치하는지 확인하였는가?

## 관련 개념
- **경우의 수**: 같은 것이 포함된 나열은 전체 경우의 수를 구할 때 중복을 제거하는 특수한 형태의 순열 계산법입니다.
