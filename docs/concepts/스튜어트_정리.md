# 스튜어트 정리

## 정의

스튜어트 정리(Stewart's theorem)는 삼각형의 한 꼭짓점에서 대변 위의 한 점을 잇는 선분(세비안)의 길이를 삼각형의 변의 길이로 나타내는 정리이다.

삼각형 ABC에서 꼭짓점 A에서 대변 BC 위의 점 D를 잇는 선분 AD의 길이를 $d$, $BD = m$, $DC = n$, $BC = a = m+n$, $AB = c$, $AC = b$라 하면 다음이 성립한다.

$$b^2 m + c^2 n = a(d^2 + mn)$$

이 공식은 두 삼각형 ABD와 ACD에 코사인 법칙을 각각 적용한 뒤 연립하여 얻는다. 중선(median)의 길이 공식(중선 정리)은 스튜어트 정리에서 $m = n = \frac{a}{2}$로 놓은 특수한 경우이다.

## 예시

삼각형 ABC에서 $AB = 5$, $AC = 4$, $BC = 6$이고 D가 BC의 중점일 때, 중선 AD의 길이를 구한다. ($m = n = 3$)

스튜어트 정리 적용:

$$4^2 \cdot 3 + 5^2 \cdot 3 = 6(d^2 + 3 \cdot 3)$$

$$48 + 75 = 6(d^2 + 9)$$

$$123 = 6d^2 + 54 \implies 6d^2 = 69 \implies d^2 = \frac{69}{6} = \frac{23}{2}$$

$$d = \sqrt{\frac{23}{2}} = \frac{\sqrt{46}}{2}$$
