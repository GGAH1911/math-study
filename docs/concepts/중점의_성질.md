### 정확한 진술

좌표평면에서 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$가 주어질 때, 선분 $AB$의 중점 $M$의 좌표는 다음과 같이 정의됩니다:

$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$$

즉, 중점의 $x$좌표와 $y$좌표는 각각 두 끝점의 $x$좌표와 $y$좌표의 산술평균입니다.

### 직관과 기하적 의미

선분 $AB$ 위의 모든 점 중에서 $A$와 $B$로부터 정확히 같은 거리에 있는 점이 바로 중점입니다. 이 중점은 선분을 정확히 이등분하는 위치에 있습니다.

기하학에서 중점의 성질은 **중점연결정리**로 매우 유용하게 활용됩니다: **삼각형의 두 변의 중점을 잇는 선분은 나머지 한 변과 평행하며, 그 길이는 나머지 한 변의 길이의 절반입니다.** 이 성질은 도형의 닮음, 평행 관계, 길이 비 문제에서 자주 등장합니다.

### 예제

두 점 $A(2, 1)$과 $B(6, 5)$의 중점을 구하면:

$$M = \left( \frac{2+6}{2}, \frac{1+5}{2} \right) = (4, 3)$$

검증하면 $|AM| = \sqrt{(4-2)^2 + (3-1)^2} = \sqrt{8} = 2\sqrt{2}$이고, $|BM| = \sqrt{(4-6)^2 + (3-5)^2} = \sqrt{8} = 2\sqrt{2}$으로 $A$와 $B$로부터 같은 거리에 있습니다.

(검산: `from sympy.geometry import Point; Point(2,1).midpoint(Point(6,5))` → `Point(4, 3)`)
