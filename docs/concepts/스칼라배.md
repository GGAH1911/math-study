# 스칼라배

벡터 $\vec{a}$에 실수 $k$를 곱한 것을 $\vec{a}$의 **스칼라배**라 하고 $k\vec{a}$로 나타낸다.

$k\vec{a}$의 크기와 방향은 $k$의 부호에 따라 다음과 같이 결정된다.

- $k > 0$이면, $\vec{a}$와 방향이 **같고** 크기가 $k|\vec{a}|$인 벡터이다.
- $k < 0$이면, $\vec{a}$와 방향이 **반대이고** 크기가 $|k||\vec{a}|$인 벡터이다.
- $k = 0$이거나 $\vec{a} = \vec{0}$이면, $k\vec{a} = \vec{0}$이다.

$\vec{a} = (a_1,\, a_2)$를 성분으로 나타낼 때는 각 성분에 $k$를 곱하면 된다.

$$k\vec{a} = (ka_1,\, ka_2)$$

스칼라배에 대해 다음 성질이 항상 성립한다. 실수 $k$, $l$과 벡터 $\vec{a}$, $\vec{b}$에 대하여

$$k(l\vec{a}) = (kl)\vec{a}, \quad (k+l)\vec{a} = k\vec{a}+l\vec{a}, \quad k(\vec{a}+\vec{b}) = k\vec{a}+k\vec{b}, \quad 1\cdot\vec{a}=\vec{a}$$

---

## 예시

$\vec{a} = (2,\,-3)$일 때 $3\vec{a}$를 구해 보자.

$$3\vec{a} = (3\times2,\;3\times(-3)) = (6,\,-9)$$

$k=3>0$이므로 방향은 그대로이고 크기만 3배로 늘어난다.

이번엔 $-2\vec{a}$를 구하면

$$-2\vec{a} = (-2\times2,\;-2\times(-3)) = (-4,\;6)$$

$k=-2<0$이므로 방향이 반대로 뒤집히고, 크기는 원래의 2배가 된다.

---

## 관련 개념

- **평면벡터**: 스칼라배는 평면벡터의 핵심 연산 중 하나로, 벡터의 정의 바로 위에서 도입된다. 벡터가 무엇인지 명확해야 스칼라배의 방향·크기 규칙을 이해할 수 있다.
- **벡터의 덧셈**: 스칼라배와 덧셈을 함께 쓰면 뺄셈 $\vec{a}-\vec{b}=\vec{a}+(-1)\vec{b}$로 자연스럽게 정의된다. 두 연산은 항상 짝을 이뤄 등장한다.
- **벡터의 크기**: $|k\vec{a}|=|k||\vec{a}|$가 성립한다. 스칼라배가 크기를 몇 배로 바꾸는지 직접 보여 주는 관계식이다.
- **단위벡터**: $\vec{a}\neq\vec{0}$일 때 $\dfrac{1}{|\vec{a}|}\vec{a}$는 $\vec{a}$ 방향의 단위벡터이다. 스칼라배의 가장 대표적인 응용으로, 방향만 추출할 때 쓴다.
- **두 벡터의 평행 조건**: 두 벡터 $\vec{a}$, $\vec{b}$가 평행하면 $\vec{b}=k\vec{a}$를 만족하는 실수 $k$가 존재한다. 스칼라배가 곧 평행의 언어가 된다.
