# 스칼라배

## 요약
벡터에 실수를 곱하여 크기를 변화시키거나 방향을 반대로 바꾸는 연산을 스칼라배라고 한다.

## 본문
벡터 $\vec{a}$에 실수 $k$를 곱한 것을 $\vec{a}$의 **스칼라배**라 하고 $k\vec{a}$로 나타낸다. $k\vec{a}$의 크기와 방향은 $k$의 부호에 따라 결정된다. $k > 0$이면 $\vec{a}$와 방향이 같고 크기가 $k|\vec{a}|$인 벡터가 되며, $k < 0$이면 $\vec{a}$와 방향이 반대이고 크기가 $|k||\vec{a}|$인 벡터가 된다. 만약 $k = 0$이거나 $\vec{a} = \vec{0}$이면 결과는 영벡터 $\vec{0}$이 된다. 성분으로 나타낸 벡터 $\vec{a} = (a_1,\, a_2)$의 스칼라배는 각 성분에 $k$를 곱하여 $k\vec{a} = (ka_1,\, ka_2)$로 계산한다.

### 직관과 기하적 의미
스칼라배는 벡터의 '길이'를 조절하는 연산으로 이해할 수 있다. 양수를 곱하면 원래 방향을 유지하며 길이가 늘어나거나 줄어들고, 음수를 곱하면 방향이 정반대로 뒤집히면서 길이가 변한다. 예를 들어 $\vec{a} = (2,\,-3)$일 때 $3\vec{a} = (6,\,-9)$는 방향은 같고 크기가 3배인 벡터이며, $-2\vec{a} = (-4,\;6)$는 방향이 반대이고 크기가 2배인 벡터이다.

### 기본 성질
실수 $k, l$과 벡터 $\vec{a}, \vec{b}$에 대하여 다음 성질이 성립한다.
- $k(l\vec{a}) = (kl)\vec{a}$
- $(k+l)\vec{a} = k\vec{a}+l\vec{a}$
- $k(\vec{a}+\vec{b}) = k\vec{a}+k\vec{b}$
- $1\cdot\vec{a}=\vec{a}$

## 학습 체크
- $k$의 부호가 벡터의 방향에 어떤 영향을 미치는지 설명할 수 있는가?
- 성분으로 주어진 벡터에 실수를 곱할 때 각 성분에 어떻게 적용되는지 알고 있는가?
- 스칼라배의 분배법칙과 결합법칙 성질을 이해하고 있는가?

## 관련 개념

- **평면벡터**: 스칼라배는 평면벡터의 핵심 연산 중 하나로, 벡터의 정의 바로 위에서 도입된다. 벡터가 무엇인지 명확해야 스칼라배의 방향·크기 규칙을 이해할 수 있다.
- **벡터의 덧셈**: 스칼라배와 덧셈을 함께 쓰면 뺄셈 $\vec{a}-\vec{b}=\vec{a}+(-1)\vec{b}$로 자연스럽게 정의된다. 두 연산은 항상 짝을 이뤄 등장한다.
- **벡터의 크기**: $|k\vec{a}|=|k||\vec{a}|$가 성립한다. 스칼라배가 크기를 몇 배로 바꾸는지 직접 보여 주는 관계식이다.
- **단위벡터**: $\vec{a}\neq\vec{0}$일 때 $\dfrac{1}{|\vec{a}|}\vec{a}$는 $\vec{a}$ 방향의 단위벡터이다. 스칼라배의 가장 대표적인 응용으로, 방향만 추출할 때 쓴다.
- **두 벡터의 평행 조건**: 두 벡터 $\vec{a}$, $\vec{b}$가 평행하면 $\vec{b}=k\vec{a}$를 만족하는 실수 $k$가 존재한다. 스칼라배가 곧 평행의 언어가 된다.
