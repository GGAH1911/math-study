### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)이 **중근**을 가지려면 판별식 $D = b^2 - 4ac = 0$이어야 합니다. 이 조건을 만족할 때, 방정식은 중근 $x = -\frac{b}{2a}$를 정확히 하나 가집니다.

다시 말해, 판별식이 0이 되는 경우가 중근을 가지는 **필요충분조건**입니다.

### 직관/기하적 의미

이차함수 $y = ax^2 + bx + c$의 그래프는 포물선입니다. 판별식 $D > 0$이면 포물선이 x축과 서로 다른 두 점에서 만나고, $D = 0$이면 x축에 정확히 **한 점에서 접**하며, $D < 0$이면 x축과 만나지 않습니다.

중근조건 $D = 0$은 기하학적으로 포물선이 x축과 접하는 상황을 나타냅니다. 이때 중근 $x = -\frac{b}{2a}$는 접점의 x좌표이며, 동시에 포물선의 대칭축입니다.

### 한 줄 예

이차방정식 $x^2 - 4x + 4 = 0$에서 $D = (-4)^2 - 4(1)(4) = 16 - 16 = 0$이므로 중근 $x = 2$를 가집니다. (실제로 $x^2 - 4x + 4 = (x-2)^2$) 

검증: `from sympy import symbols, discriminant; x = symbols('x'); print(discriminant(x**2 - 4*x + 4, x))`  
⟹ 결과: 0
