### 정확한 진술

두 평면벡터 $\vec{a}$, $\vec{b}$의 합 $\vec{a} + \vec{b}$는 다음과 같이 정의됩니다. 점 $O$에서 출발하여 벡터 $\vec{a}$에 의해 점 $A$에 도달하고, 점 $A$에서 벡터 $\vec{b}$에 의해 점 $B$에 도달할 때, 벡터 $\overrightarrow{OB}$를 $\vec{a} + \vec{b}$로 정의합니다. 이를 **삼각형 법칙**(triangle rule)이라 부릅니다.

동치적으로, 점 $O$를 원점으로 하여 벡터 $\vec{a}$, $\vec{b}$에 대응하는 변을 갖는 평행사변형을 그렸을 때, 대각선 벡터가 $\vec{a} + \vec{b}$입니다. 이를 **평행사변형 법칙**(parallelogram rule)이라 부릅니다.

성분으로 표현하면, $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$일 때:
$$\vec{a} + \vec{b} = (a_1 + b_1, a_2 + b_2)$$

### 직관과 기하적 의미

벡터 합은 **연속된 이동의 결과**를 나타냅니다. 먼저 $\vec{a}$ 방향으로 이동한 후 $\vec{b}$ 방향으로 이동했을 때, 출발점에서 최종 도착점까지의 순 변위(net displacement)가 바로 $\vec{a} + \vec{b}$입니다.

평행사변형 법칙은 같은 시점에서 출발하는 두 벡터를 생각할 때 유용합니다. 두 방향의 합성 효과를 대각선으로 시각화하므로, 물리에서 힘의 합성이나 속도의 합성을 다룰 때 매우 직관적입니다. 벡터의 크기와 방향이 모두 고려되므로, 단순한 스칼라 더하기와는 달리 **방향에 따라 결과가 달라집니다**.

### 한 줄 예

$\vec{a} = (3, 1)$, $\vec{b} = (1, 2)$일 때, $\vec{a} + \vec{b} = (4, 3)$입니다. 기하학적으로는 $O(0,0)$에서 출발하여 $(3,1)$로 이동한 후 다시 $(1,2)$만큼 이동하면 $(4,3)$에 도달합니다.

```python
# sympy로 검산
import sympy as sp
a = sp.Matrix([3, 1])
b = sp.Matrix([1, 2])
print(a + b)  # Matrix([[4], [3]])
```
