# 적분 조건식

## 요약
미분방정식의 해를 구할 때, 미분된 함수를 다시 적분하여 원래의 함수를 찾아내기 위해 필요한 추가적인 정보를 제공하는 식입니다.

## 본문
적분 조건식은 미분방정식을 적분하여 일반해를 구할 때, 적분 상수 $C$를 결정하기 위해 주어지는 조건을 의미합니다. 미분 과정에서는 함수의 상수항이 사라지기 때문에, 미분된 식만으로는 원래 함수의 정확한 형태를 하나로 확정할 수 없습니다. 이때 특정 지점에서의 함수 값이나 미분 계수와 같은 추가적인 조건이 주어지면, 이를 적분 과정에 대입하여 유일한 특수해를 도출할 수 있습니다.

### 직관과 기하적 의미
미분방정식의 일반해는 평면 위에서 수많은 곡선들의 가족(family of curves)을 나타냅니다. 적분 조건식은 이 무수히 많은 곡선들 중 특정한 조건을 만족하는 단 하나의 곡선을 선택하도록 가이드라인을 제시하는 역할을 합니다. 즉, 기하학적으로는 곡선군 중에서 특정 점을 지나거나 특정 기울기를 갖는 하나의 곡선을 확정 짓는 과정입니다.

### 기본 성질
적분 조건식은 주로 초기 조건(initial condition)의 형태로 주어지며, 함수 $y(x)$의 특정 값 $y(x_0) = y_0$를 포함합니다. 이 조건이 주어지면 적분 상수 $C$에 대한 방정식이 형성되어 $C$의 값을 유일하게 결정할 수 있습니다. 만약 조건이 부족하면 해는 여전히 상수 $C$를 포함한 일반해의 형태로 남게 됩니다.

## 학습 체크
- 주어진 미분방정식을 적분하여 얻은 일반해에 주어진 조건을 어떻게 대입하여 $C$를 구하는가?
- 적분 조건식이 함수 값($y$)을 주는 경우와 미분 계수($y'$)를 주는 경우의 차이는 무엇인가?

## 관련 개념
- **적분**: 미분방정식의 해를 구하는 과정에서 미분된 함수를 원래의 함수로 되돌리는 연산 과정입니다.
