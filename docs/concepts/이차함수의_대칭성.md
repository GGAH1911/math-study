# 이차함수의 대칭성

## 요약
이차함수는 축의 방정식에 대하여 좌우가 대칭인 기하학적 특징을 가진다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 그래프는 축의 방정식인 $x = -\frac{b}{2a}$를 기준으로 좌우가 완벽하게 대칭을 이루는 형태를 띤다. 이는 함수식의 변수를 축의 방정식으로부터 떨어진 거리로 치환했을 때, 결과값이 동일하게 나타나는 성질에서 기인한다. 즉, 축의 방정식 $x = p$에 대하여 $f(p-t) = f(p+t)$를 만족하는 모든 실수 $t$에 대하여 함숫값이 같다. 이러한 대칭성은 이차함수의 그래프가 포물선 형태를 띠게 만드는 핵심적인 기하학적 요소이며, 함수의 최댓값 또는 최솟값이 축 위에서 발생함을 보장한다.

### 직관과 기하적 의미
그래프를 축의 방정식인 직선 $x = -\frac{b}{2a}$를 기준으로 접었을 때, 왼쪽 부분과 오른쪽 부분이 정확히 포개어진다. 이는 함수가 특정 지점을 중심으로 좌우가 거울을 본 듯한 대칭 구조를 가짐을 의미하며, 함수의 증가와 감소가 축을 기점으로 반전됨을 시각적으로 보여준다.

### 기본 성질
이차함수의 그래프에서 축에 의해 나누어진 두 지점의 $x$ 좌표의 평균값은 항상 축의 방정식과 일치한다. 또한, 함숫값이 같은 두 점의 $x$ 좌표의 산술 평균은 항상 축의 방정식인 $x = -\frac{b}{2a}$가 된다.

## 학습 체크
- 이차함수의 식에서 계수 $a, b, c$를 보고 축의 방정식을 즉각적으로 도출할 수 있는가?
- 함숫값이 같은 두 점의 $x$ 좌표를 알 때, 이를 통해 축의 방정식을 구할 수 있는가?

## 관련 개념
- **여러가지함수의 미분**: 이차함수를 미분하면 일차함수가 되며, 이 일차함수의 해가 곧 이차함수의 대칭축을 결정한다.
