### 정확한 진술

수열의 합 공식은 $a_1, a_2, \ldots, a_n$으로 주어진 유한 수열의 모든 항을 더한 값을 나타내는 방법입니다. 일반적으로 **시그마 기호** $\Sigma$(합의 기호)를 사용하여 다음과 같이 표현합니다:

$$\sum_{k=1}^{n} a_k = a_1 + a_2 + a_3 + \cdots + a_n$$

여기서 $k$는 합을 나타내는 변수(더미 변수), 1은 시작값, $n$은 끝값입니다. 특히 등차수열과 등비수열의 경우, 직접 더하지 않고도 합을 구할 수 있는 **닫힌 형태의 공식**이 존재합니다.

### 직관과 필요성

$a_1 + a_2 + \cdots + a_{100}$을 계산해야 한다면, 항이 100개나 되므로 직접 더하기는 비효율적입니다. 대신 **수열의 규칙성**(등차 또는 등비)을 이용하면 단 몇 개의 항의 값과 항의 개수만으로 전체 합을 즉시 계산할 수 있습니다. 예를 들어, 등차수열 $1, 3, 5, 7, \ldots, 99$는 첫 50개 홀수의 합인데, 공식을 사용하면 $n^2 = 50^2 = 2500$으로 바로 구합니다. 이는 시간 단축뿐 아니라 수학적 구조를 이해하는 데 핵심입니다.

### 한 줄 예

등차수열 $2, 5, 8, 11, \ldots$의 첫 10항의 합: $S_{10} = \frac{10(2 + 29)}{2} = 155$ (첫째항과 마지막 항의 합에 항의 개수의 절반을 곱함)
