### 정확한 진술

3차원 공간의 두 점 $P_1(x_1, y_1, z_1)$과 $P_2(x_2, y_2, z_2)$ 사이의 거리는 다음과 같이 정의됩니다:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

더 일반적으로, 공간에서의 거리는 두 도형(점, 직선, 평면 등) 사이의 최단 거리로 정의됩니다.

### 직관과 기하적 의미

거리는 공간에서 두 도형이 얼마나 떨어져 있는지를 나타내는 기본적인 척도입니다. 2차원에서 두 점 사이의 거리가 피타고라스 정리로 구해지듯이, 3차원에서도 세 방향(x, y, z)의 차이를 이용하여 같은 원리로 계산합니다.

**점과 평면 사이의 거리**: 평면 $ax + by + cz + d = 0$과 점 $(x_0, y_0, z_0)$ 사이의 거리는

$$\text{거리} = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$

**점과 직선 사이의 거리**: 점에서 직선에 내린 수선의 발까지의 거리입니다. 이는 벡터의 외적을 이용하여 구할 수 있습니다.

이들 거리는 기본 정의에서 출발하여 단계적으로 유도되며, 공간도형의 위치 관계를 파악하는 데 필수적입니다.

### 예

점 $A(1, 2, 3)$과 점 $B(4, 6, 15)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2 + (15-3)^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13$입니다.
