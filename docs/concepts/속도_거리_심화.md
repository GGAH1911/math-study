# 속도 거리 심화

> **예제** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
운동 모델링

## 본문 (학습 시 채워짐)

### 문제

$0 \le t \le 3$초 동안 움직이는 물체의 속도가 $v(t) = t^2 - 4t + 3$ (m/s)로 주어졌다. (1) 이 시간 동안 물체의 **변위**를 구하고, (2) 실제로 움직인 **거리**를 구하시오.

### 단계별 풀이

**1단계: 속도 함수의 부호 변화 확인**  
변위와 거리는 다를 수 있다. 그 이유는 속도가 음수가 되는 구간이 있기 때문이다. $v(t) = 0$인 시점을 찾자.
$$t^2 - 4t + 3 = (t-1)(t-3) = 0 \implies t = 1, 3$$
따라서 $0 < t < 1$에서 $v(t) > 0$ (양의 방향), $1 < t < 3$에서 $v(t) < 0$ (음의 방향)이다.

**2단계: 변위 계산**  
변위는 정적분으로 직접 계산한다. 음수 값은 반대 방향 이동을 의미한다.
$$s = \int_0^3 v(t) \, dt = \int_0^3 (t^2 - 4t + 3) \, dt = \left[\frac{t^3}{3} - 2t^2 + 3t\right]_0^3 = 9 - 18 + 9 = 0$$
물체는 출발점으로 돌아왔다. 그러나 실제로 움직인 거리는 다르다.

**3단계: 거리 계산**  
실제 거리는 속도의 절댓값을 적분한다. 절댓값은 항상 양수이므로 거리는 항상 증가한다.
$$\text{거리} = \int_0^1 v(t) \, dt - \int_1^3 v(t) \, dt = \left[\frac{t^3}{3} - 2t^2 + 3t\right]_0^1 - \left[\frac{t^3}{3} - 2t^2 + 3t\right]_1^3$$
$$= \left(\frac{1}{3} - 2 + 3\right) - \left[(0) - (0)\right] - \left[(0) - \left(\frac{1}{3} - 2 + 3\right)\right] = \frac{4}{3} + \frac{4}{3} = \frac{8}{3}$$

### 답

(1) 변위: $0$ m  
(2) 거리: $\frac{8}{3}$ m (약 2.67 m)

### 변형/주의

**변위와 거리의 물리적 의미** — 변위(displacement)는 시작점과 끝점의 위치 차이로, 방향을 고려한다. 거리(distance)는 실제로 이동한 경로의 길이로, 항상 양수이다. 이 문제처럼 왕복 운동에서는 두 값이 다르다.

**계산 팁** — $\int_a^b |f(t)| \, dt$를 계산할 때는 반드시 $f(t) = 0$인 점에서 구간을 나누고, 각 구간에서 부호를 판단한 후 절댓값을 풀어야 한다. sympy 확인: `integrate(t**2 - 4*t + 3, (t, 0, 3))` = 0; `integrate(Abs(t**2 - 4*t + 3), (t, 0, 3))` ≈ 2.667
