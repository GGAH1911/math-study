# 여러가지 함수의 극한과 연속

> **단원** · 미적분 · 선수: [함수의 극한과 연속](./함수의_극한과_연속.md) / [지수함수와 로그함수](./지수함수와_로그함수.md) / [삼각함수](./삼각함수.md)

## 학습 목표
- 지수/로그/삼각함수의 극한을 다룬다
- 연속함수 합성·곱의 연속성을 활용한다

## 다룰 정의 / 정리 / 예제 (Phase 2 spoke로 분해됨)

**정의(definition)**
- $\sin x / x$의 극한
- 자연상수 $e$의 정의

**정리(theorem)**
- $\lim_{x\to 0}\sin x/x = 1$
- $\lim_{x\to 0}(1+x)^{1/x}=e$

**예제(example)**
- 부정형 극한 처리
- $\sin$ 관련 극한
- 지수/로그 극한
