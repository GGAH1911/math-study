# 속력

## 정의

속력은 단위 시간당 이동한 거리의 크기(스칼라량)이다. 수직선 위를 움직이는 점 P의 위치가 $x(t)$일 때, 시각 $t$에서의 속도는 $v(t) = x'(t)$이고, 속력은 속도의 절댓값 $|v(t)| = |x'(t)|$이다. 속도는 방향을 포함하는 벡터량이지만, 속력은 그 크기만을 나타낸다. 수능에서는 주로 위치 함수 $x(t)$가 주어졌을 때 속력의 최솟값·최댓값 또는 속력이 특정 값이 되는 시각을 묻는 형태로 출제된다.

## 예시

위치 함수 $x(t) = t^3 - 3t^2$ ($t \ge 0$)에서 $t=1$일 때의 속력을 구한다.

$$v(t) = x'(t) = 3t^2 - 6t$$

$$v(1) = 3(1)^2 - 6(1) = 3 - 6 = -3$$

속력 $= |v(1)| = |-3| = 3$

## 관련 개념

- 속도(velocity)
- 위치 함수
- 미분과 변화율
- 평균변화율과 순간변화율
