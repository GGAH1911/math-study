# 속력

## 요약
속력은 단위 시간당 이동한 거리의 크기를 나타내는 스칼라량으로, 속도의 절댓값과 같다.

## 본문
속력은 단위 시간당 이동한 거리의 크기를 나타내는 스칼라량이다. 수직선 위를 움직이는 점 $P$의 위치가 $t$에 대한 함수 $x(t)$로 주어질 때, 시각 $t$에서의 속도는 위치 함수를 미분한 $v(t) = x'(t)$로 정의된다. 이때 속력은 속도의 크기만을 의미하므로 속도 함수에 절댓값을 취한 $|v(t)| = |x'(t)|$로 계산한다. 속도는 운동의 방향성을 포함하는 벡터량인 반면, 속력은 방향과 관계없이 물체가 움직인 빠르기만을 나타낸다는 점이 핵심적인 차이점이다. 수능과 같은 평가 환경에서는 위치 함수 $x(t)$가 주어졌을 때 속력의 최댓값이나 최솟값을 구하거나, 특정 속력에 도달하는 시각을 찾는 문제가 자주 출제된다.

### 직관과 기하적 의미
속력은 물체가 얼마나 빠르게 움직이는지를 나타내는 척도이다. 속도가 양수이면 양의 방향으로, 음수이면 음의 방향으로 움직이고 있음을 의미하지만, 속력은 이 방향성을 제거하고 오직 이동한 거리의 변화율만을 나타낸다. 기하학적으로 속력은 위치 함수 $x(t)$의 그래프에서 접선의 기울기인 속도 $v(t)$의 절댓값과 같다.

### 기본 성질
1. 속력은 항상 $0$보다 크거나 같다.
2. 속도가 $0$인 지점은 물체의 운동 방향이 바뀌거나 잠시 멈추는 지점이다.
3. 위치 함수 $x(t)$의 미분계수인 속도 $v(t)$의 부호가 바뀌는 지점에서 물체의 운동 방향이 바뀐다.

## 학습 체크
- 위치 함수 $x(t)$가 주어졌을 때, 속력 $|v(t)|$를 구하기 위해 미분과 절댓값을 정확히 적용하였는가?
- 속도 $v(t)$의 부호가 바뀌는 지점과 속력 $|v(t)|$가 $0$이 되는 지점의 관계를 이해하고 있는가?
- 특정 시각에서의 속력의 최댓값 또는 최솟값을 구하기 위해 미분법을 적절히 활용할 수 있는가?
