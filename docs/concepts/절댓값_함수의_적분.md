### 정확한 진술

절댓값 함수의 적분이란 $|f(x)|$의 형태를 $[a, b]$ 구간에서 정적분하는 것입니다. 절댓값을 포함한 함수를 직접 적분할 수 없으므로, 함수가 0이 되는 점을 기준으로 구간을 나누어 각 부분에서 절댓값을 풀어낸 후 적분합니다.

$$\int_a^b |f(x)| \, dx = \int_a^c f(x) \, dx + \int_c^d (-f(x)) \, dx + \cdots$$

여기서 $c, d, \cdots$는 $[a, b]$ 구간 안에서 $f(x) = 0$이 되는 점들입니다.

### 직관과 기하적 의미

절댓값 기호는 "부호와 무관하게 크기만 취한다"는 뜻입니다. 그래프 아래 넓이를 구할 때, $f(x) < 0$인 구간에서는 그래프가 $x$축 아래에 있지만, 절댓값을 취하면 그 부분이 $x$축 위로 "뒤집어져" 양의 넓이로 계산됩니다. 결과적으로 $\int_a^b |f(x)| \, dx$는 곡선 $y = |f(x)|$가 $x$축과 이루는 전체 넓이입니다.

### 계산 절차 및 예

$\int_0^3 |x^2 - 4x + 3| \, dx$를 구해봅시다.

먼저 $x^2 - 4x + 3 = (x-1)(x-3) = 0$의 해는 $x = 1, 3$입니다.

- $0 \leq x \leq 1$: $x^2 - 4x + 3 \geq 0$
- $1 \leq x \leq 3$: $x^2 - 4x + 3 \leq 0$

따라서:
$$\int_0^3 |x^2-4x+3| \, dx = \int_0^1 (x^2-4x+3) \, dx + \int_1^3 (-(x^2-4x+3)) \, dx$$

$$= \left[\frac{x^3}{3} - 2x^2 + 3x\right]_0^1 + \left[-\frac{x^3}{3} + 2x^2 - 3x\right]_1^3$$

$$= \left(\frac{1}{3} - 2 + 3\right) + \left(-9 + 18 - 9 + \frac{1}{3} - 2 + 3\right) = \frac{4}{3} + \frac{4}{3} = \frac{8}{3}$$
