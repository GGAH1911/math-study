# 도함수의 계산

## 요약
다항함수, 삼각함수 등 다양한 함수의 도함수를 구할 때 미분계수의 정의를 매번 사용하지 않고, 정해진 공식과 성질을 이용하여 효율적으로 계산하는 방법입니다.

## 본문
도함수의 계산은 함수의 변화율을 나타내는 미분계수를 보다 빠르고 간편하게 구하기 위해 함수의 형태에 따른 특수한 규칙을 적용하는 과정입니다. 함수 $f(x)$의 도함수 $f'(x)$를 구하기 위해서는 함수의 각 항에 대해 미분법을 적용하며, 이때 다항함수의 미분법인 $x^n$의 미분은 $nx^{n-1}$임을 기본으로 합니다. 여러 항이 더해지거나 빼진 형태의 함수는 각 항을 개별적으로 미분하여 더하거나 뺀 결과와 같으며, 함수끼리의 곱이나 합성된 형태의 함수는 곱의 미분법과 합성함수의 미분법을 사용하여 계산합니다.

### 직관과 기하적 의미
도함수를 계산한다는 것은 임의의 점 $x$에서의 접선의 기울기를 함수식으로 나타내는 것과 같습니다. 복잡한 극한 식을 매번 계산하는 대신, 계산 규칙을 통해 도함수라는 새로운 함수를 찾아내면 그래프 위의 어떤 점에서도 접선의 기울기를 즉각적으로 파악할 수 있습니다.

### 기본 성질
함수 $f(x)$와 $g(x)$에 대하여 상수 $c$를 곱하거나 더한 함수의 미분은 각각 $cf'(x)$와 $f'(x)$로 계산됩니다. 또한, 두 함수의 곱의 미분은 $f'(x)g(x) + f(x)g'(x)$이며, 합성함수의 미분은 겉함수를 미분한 뒤 속함수를 미분한 결과에 속함수의 미분값을 곱하는 연쇄 법칙을 따릅니다.

## 학습 체크
- 다항함수의 미분법을 적용할 때 지수 법칙을 정확히 활용하여 차수를 낮추고 계수를 곱하였는가?
- 두 함수의 곱이나 합성함수의 형태일 때, 어떤 미분법을 적용해야 하는지 판단할 수 있는가?

## 관련 개념
- **미분**: 함수의 특정 지점에서의 순간 변화율인 미분계수를 구하는 행위이며, 도함수의 계산은 이 미분계수를 일반화하여 함수 형태로 나타내는 과정입니다.
