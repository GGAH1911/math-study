### 정확한 진술

3차함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)에서 **극값**이란, 어떤 점 근처에서 함수값이 최대 또는 최소가 되는 값을 의미합니다. 극값을 갖는 $x$의 값을 **극값점**이라 부릅니다.

3차함수가 극값을 가지려면 도함수 $f'(x) = 3ax^2 + 2bx + c$가 **서로 다른 두 실근**을 가져야 합니다. 이 두 근을 $\alpha < \beta$라 할 때, $x = \alpha$와 $x = \beta$에서 함수는 극값을 갖습니다.

### 직관과 기하적 의미

도함수는 함수의 기울기를 나타냅니다. $f'(x) = 0$인 점에서 기울기가 0이 되므로, 함수는 증가에서 감소로 또는 감소에서 증가로 방향을 바꿉니다. 이 변곡점이 바로 극값입니다.

3차함수는 최대 **2개의 극값**을 가질 수 있습니다.
- $f'(x) = 0$이 서로 다른 두 실근을 가지면: 극대값 1개, 극소값 1개 (S자 모양)
- $f'(x) = 0$이 중근이나 허근을 가지면: 극값 없음 (계속 증가하거나 계속 감소)

**중요한 점**: 극값은 "그 근처에서의" 최댓값/최솟값이지, 전체 함수의 최댓값이 아닙니다.

### 한 줄 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 0$을 풀면 $x = -1$ 또는 $x = 1$이고, $x = -1$에서 극대값 $f(-1) = 2$, $x = 1$에서 극소값 $f(1) = -2$를 갖습니다.
