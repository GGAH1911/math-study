# 다항함수 결정

## 요약
조건으로 주어진 적분 방정식이나 미분 관계식을 이용하여 다항함수의 계수를 모두 구해내는 과정이다.

## 본문
다항함수를 결정한다는 것은 조건으로 주어진 적분 방정식이나 미분 관계식을 이용하여 함수의 계수를 모두 구해내는 것을 말한다. 정적분이 포함된 조건에서 다항함수 $f(x)$를 결정할 때에는 상황에 따라 두 가지 핵심 전략을 사용한다.

첫째, 적분 구간이 상수인 경우이다. $\int_a^b f(x)\,dx = k$ 꼴처럼 적분 결과가 하나의 상수일 때, 이 식 전체도 하나의 상수이다. 따라서 $f(x)$ 안에 이 적분이 포함되어 있다면, 그 적분 값을 미지의 상수 $c$로 놓고 문제를 푼다. 이후 실제로 $c$를 대입하여 등식이 성립하는지 검증함으로써 $c$의 값을 확정한다.

둘째, 적분 구간에 변수가 포함된 경우이다. $\int_a^x f(t)\,dt = g(x)$ 꼴일 때는 양변을 $x$에 대해 미분하여 $f(x) = g'(x)$를 얻을 수 있다. 또한 $x = a$를 대입하면 $\int_a^a f(t)\,dt = 0$이므로 $g(a) = 0$이라는 추가 조건을 얻을 수 있으며, 이는 미결정 상수를 결정하는 데 유용하게 활용된다. 이처럼 두 전략을 적절히 선택하거나 결합하여 $f(x)$의 모든 계수를 하나씩 결정해 나간다.

### 예시
**예시 1 — 상수 치환**
$f(x) = x^2 + \int_0^1 t\,f(t)\,dt$ 에서 $c = \int_0^1 t\,f(t)\,dt$ 로 놓으면 $f(x) = x^2 + c$이다. 이를 대입하면
$$c = \int_0^1 t(t^2 + c)\,dt = \int_0^1 (t^3 + ct)\,dt = \frac{1}{4} + \frac{c}{2}$$
$\tfrac{c}{2} = \tfrac{1}{4}$이므로 $c = \tfrac{1}{2}$이다. 따라서 $f(x) = x^2 + \tfrac{1}{2}$이다.

**예시 2 — 변수 구간 미분**
모든 실수 $x$에 대해 $\int_1^x f(t)\,dt = x^2 + ax + b$ 를 만족하는 다항함수 $f(x)$와 상수 $a, b$를 구하는 과정이다. 양변을 $x$로 미분하면 $f(x) = 2x + a$를 얻는다. $x = 1$을 대입하면 좌변이 $0$이므로 $0 = 1 + a + b$가 성립해야 한다. 또한 $x = 1$을 원래 식에 대입하면 $0 = 1 + a + b$이므로 $a$와 $b$의 관계를 통해 상수를 결정할 수 있다.

## 학습 체크
- 적분 구간이 상수일 때 적분 값을 미지수 $c$로 치환하여 대입하는 과정을 이해하였는가?
- 적분 구간에 변수가 포함된 식을 미분하여 함수 $f(x)$를 도출할 수 있는가?
- 적분 구간의 시작점($x=a$)을 대입하여 얻는 추가 조건을 활용할 수 있는가?

## 관련 개념

- **정적분의 활용**: 다항함수를 결정하는 과정은 정적분의 계산 능력을 전제로 한다. 정적분으로 넓이·변화량을 구하는 것과 마찬가지로, 여기서도 $\int_a^b f(x)\,dx$를 직접 계산하여 등식을 세운다.

- **미분**: "적분 구간에 변수가 포함된 경우"에서는 $\tfrac{d}{dx}\int_a^x f(t)\,dt = f(x)$라는 미적분학의 기본 정리를 사용한다. 미분을 능숙하게 다루지 못하면 이 전략을 쓸 수 없으므로, 다항함수의 미분이 선결 조건이다.

- **미정계수법**: 미지의 상수를 $c$로 놓고 조건에 대입하여 값을 확정하는 과정은 미정계수법의 직접적인 적용이다. 다항함수의 차수를 먼저 파악하고 계수를 하나씩 맞춰가는 감각이 중요하다.

- **연속함수와 적분 가능성**: $f(x)$가 다항함수이면 항상 연속이므로 적분이 잘 정의되고, 미분과 적분을 자유롭게 교환할 수 있다. 이 전제가 무너지면 위의 전략들을 그대로 적용할 수 없다.
