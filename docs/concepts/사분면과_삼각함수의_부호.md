# 사분면과 삼각함수의 부호

## 요약
좌표평면 위의 사분면 위치에 따라 삼각함수의 부호가 결정되며, 이는 각의 좌표값과 반지름의 부호에 의해 결정됩니다.

## 본문
좌표평면을 두 축이 만나는 점을 기준으로 네 개의 영역으로 나눈 것을 사분면이라 하며, 시계 반대 방향으로 제1사분면, 제2사분면, 제3사분면, 제4사분면이라 부릅니다. 각 사분면에서 삼각함수의 부호는 동경의 위치에 있는 점의 좌표 부호에 따라 결정됩니다. 제1사분면에서는 모든 삼각함수의 값이 양수이며, 제2사분면에서는 $\sin$만 양수, 제3사분면에서는 $\tan$만 양수, 제4사분면에서는 $\cos$만 양수입니다. 이는 단위원 또는 반지름이 $r$인 원 위의 점 $(x, y)$에 대하여 $\sin\theta = \tfrac{y}{r}$, $\cos\theta = \tfrac{x}{r}$, $\tan\theta = \tfrac{y}{x}$로 정의되기 때문입니다.

### 직관과 기하적 의미
삼각함수의 부호는 원 위의 점의 좌표가 어느 방향에 있는지를 나타내는 지표입니다. 예를 들어 제2사분면은 $x$값이 음수이고 $y$값이 양수인 영역이므로, $x$를 분자로 갖는 $\cos$은 음수가 되고 $y$를 분자로 갖는 $\sin$은 양수가 됩니다. $\tan$은 $y/x$의 값이므로 음수와 양수의 나눗셈이 되어 음수가 됩니다.

### 기본 성질
각 사분면에서의 부호 결정 규칙은 다음과 같습니다.
- 제1사분면: $\sin\theta > 0, \cos\theta > 0, \tan\theta > 0$
- 제2사분면: $\sin\theta > 0, \cos\theta < 0, \tan\theta < 0$
- 제3사분면: $\sin\theta < 0, \cos\theta < 0, \tan\theta > 0$
- 제4사분면: $\sin\theta < 0, \cos\theta > 0, \tan\theta < 0$

## 학습 체크
- 각 사분면에서 $\tan$의 부호가 양수인 영역은 어디인가요?
- $\sin\theta < 0$이고 $\cos\theta < 0$인 각 $\theta$는 몇 사분면에 위치하나요?

## 관련 개념
- **삼각함수**: 각의 크기에 따라 좌표값의 비율을 나타내는 함수로, 사분면의 위치에 따라 부호가 결정되는 기초가 됩니다.
