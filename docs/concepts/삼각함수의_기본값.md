# 삼각함수의 기본값

## 요약
단위원 위의 점의 좌표를 이용하여 사인, 코사인, 탄젠트의 값을 정의하며, 이는 삼각비의 개념을 모든 실수 범위로 확장한 것입니다.

## 본문
단위원(반지름의 길이가 $1$인 원) 위의 점 $P(x, y)$에 대하여, 동경 $OP$가 $x$축의 양의 방향과 이루는 각을 $\theta$라고 할 때, $\sin\theta = y$, $\cos\theta = x$, $\tan\theta = \frac{y}{x}$ ($x \neq 0$)로 정의합니다. 이는 직각삼각형에서의 삼각비 개념을 일반각으로 확장한 것으로, 각의 크기에 관계없이 좌표를 통해 함수의 값을 결정할 수 있게 합니다.

### 직관과 기하적 의미
단위원에서의 삼각함수 값은 원 위의 점의 좌표 그 자체를 의미합니다. 코사인 값은 점 $P$의 $x$좌표를, 사인 값은 점 $P$의 $y$좌표를 나타내며, 탄젠트 값은 동경의 기울기를 의미합니다. 따라서 각 $\theta$가 커짐에 따라 점 $P$가 원을 따라 회전하며 좌표값이 변화하는 과정을 통해 삼각함수의 주기성과 대칭성을 시각적으로 이해할 수 있습니다.

### 기본 성질
단위원을 이용한 정의에 의해 $\sin^2\theta + \cos^2\theta = 1$이라는 관계식이 성립합니다. 이는 원의 방정식 $x^2 + y^2 = 1$에서 유도된 결과입니다. 또한, 각 $\theta$가 $2\pi$의 정수 배만큼 변할 때마다 점 $P$의 좌표가 반복되므로, 모든 삼각함수는 주기성을 가집니다.

## 학습 체크
- 단위원 위의 점의 좌표 $(x, y)$를 보고 $\sin\theta$와 $\cos\theta$의 값을 즉각적으로 추출할 수 있는가?
- $\tan\theta$의 값이 정의되지 않는 각 $\theta$의 조건은 무엇인가?
- $\sin\theta$와 $\cos\theta$의 값이 각각 $-1$과 $1$ 사이의 값을 갖는 이유를 단위원의 반지름과 연결하여 설명할 수 있는가?

## 관련 개념
- **삼각함수**: 단위원을 통해 정의된 사인, 코사인, 탄젠트 함수를 통칭하며, 각의 크기에 따라 변하는 값을 함수로 나타낸 것입니다.
