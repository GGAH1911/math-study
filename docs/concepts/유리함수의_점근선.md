### 정확한 진술

유리함수 $f(x) = \frac{P(x)}{Q(x)}$의 **점근선**은 $x$가 특정 값에 가까워지거나 무한대로 갈 때, 함수의 그래프가 점점 다가가는 직선입니다. 

**수직 점근선**: 분모 $Q(x) = 0$이지만 분자 $P(x) \neq 0$인 점 $x = a$에서, $x \to a$일 때 $|f(x)| \to \infty$이면 직선 $x = a$는 수직 점근선입니다.

**수평 점근선**: $x \to \infty$ 또는 $x \to -\infty$일 때 $f(x) \to L$ (상수)이면 직선 $y = L$은 수평 점근선입니다. 분자의 차수가 분모의 차수보다 작을 때 $y = 0$이 수평 점근선이고, 같을 때는 최고차 계수의 비가 $L$입니다.

**사선 점근선**: 분자의 차수가 분모의 차수보다 정확히 1 크면 장제법으로 $f(x) = (ax + b) + \frac{나머지}{분모}$ 형태가 되고, 직선 $y = ax + b$는 사선 점근선입니다.

### 직관/기하적 의미

점근선은 함수의 "극단적 행동"을 나타냅니다. $x$가 극단값으로 갈 때 함수가 어떤 직선에 무한히 가까워진다는 것인데, 이는 함수의 전체 그래프 모양을 파악하는 데 필수적입니다. 수직 점근선은 함수가 정의되지 않는 "벽"이고, 수평/사선 점근선은 함수가 먼 곳에서 어떤 방향으로 움직이는지 보여줍니다.

### 한 줄 예

$f(x) = \frac{2x+1}{x-3}$에서 수직 점근선은 $x=3$ (분모가 0), 수평 점근선은 $y=2$ (최고차 계수의 비)입니다.

```
# 검증: sympy.limit(f, x, oo)와 f의 극한값 확인
from sympy import symbols, limit, oo
x = symbols('x')
f = (2*x + 1)/(x - 3)
print(limit(f, x, oo))  # 2
```
