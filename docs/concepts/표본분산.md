# 표본분산

표본분산은 표본에 속한 값들이 표본평균으로부터 얼마나 퍼져 있는지를 하나의 수로 나타낸 것이다.

크기 $n$인 표본 $x_1, x_2, \ldots, x_n$의 표본평균을 $\bar{x}$라 하면, 표본분산 $S^2$은 다음과 같이 정의된다.

$$S^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

각 값과 표본평균의 차이를 제곱한 뒤 평균을 낸 것이다. 제곱을 하는 이유는 평균보다 큰 값과 작은 값의 차이가 서로 상쇄되지 않게 하기 위해서다. 표본분산은 항상 $0$ 이상이며, 값들이 표본평균 주위에 촘촘히 모여 있을수록 작아지고 넓게 흩어질수록 커진다.

계산에 편리한 동치 공식도 있다.

$$S^2 = \frac{1}{n}\sum_{i=1}^{n}x_i^2 - \bar{x}^2$$

## 예시

표본이 $2, 4, 6, 8, 10$인 경우를 보자.

표본평균을 먼저 구한다.

$$\bar{x} = \frac{2+4+6+8+10}{5} = 6$$

표본분산을 정의대로 계산한다.

$$S^2 = \frac{1}{5}\left\{(2-6)^2+(4-6)^2+(6-6)^2+(8-6)^2+(10-6)^2\right\}$$
$$= \frac{1}{5}(16+4+0+4+16) = \frac{40}{5} = 8$$

동치 공식으로도 확인해 보자.

$$S^2 = \frac{1}{5}(4+16+36+64+100) - 6^2 = 44 - 36 = 8$$

두 방법 모두 같은 값 $8$을 준다. 직접 편차를 구하기 번거로울 때는 두 번째 공식이 더 빠르다.

## 관련 개념

**표본평균**은 표본분산 계산의 출발점이다. $\bar{x}$를 먼저 구해야 각 값과의 편차를 잡을 수 있으므로, 표본분산을 구하기 전에 반드시 표본평균을 확정해야 한다.

**모분산** $\sigma^2$은 모집단 전체를 대상으로 같은 방식으로 정의한 분산이다. 현실에서는 모집단 전부를 조사하기 어렵기 때문에 표본분산을 구해 모분산을 추정한다. 표본의 크기 $n$이 클수록 표본분산은 모분산에 가까워진다.

**표본표준편차** $S = \sqrt{S^2}$는 표본분산의 양의 제곱근이다. 분산은 원래 단위를 제곱한 단위를 가지므로 해석이 어색할 수 있는데, 표준편차는 원래 데이터와 같은 단위로 돌아와 실질적인 퍼짐 정도를 직관적으로 나타낸다.

**추정**은 표본분산이 실제로 쓰이는 맥락이다. 모분산 $\sigma^2$을 알 수 없을 때 표본분산 $S^2$을 그 추정값으로 사용하고, 이를 바탕으로 모집단의 특성에 대한 결론을 내린다.
