# 표본분산

## 요약
표본분산은 표본 데이터가 표본평균으로부터 얼마나 떨어져 있는지를 나타내는 척도로, 편차 제곱의 평균을 의미한다.

## 본문
크기가 $n$인 표본 $x_1, x_2, \ldots, x_n$의 표본평균을 $\bar{x}$라 할 때, 표본분산 $S^2$은 다음과 같이 정의된다.
$$S^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$
이는 각 데이터 값과 표본평균의 차이인 편차를 제곱하여 모두 더한 뒤, 이를 표본의 개수 $n$으로 나눈 값이다.

### 직관과 기하적 의미
데이터의 값들이 표본평균에 밀집되어 있을수록 표본분산은 $0$에 가까운 작은 값을 가지며, 데이터가 평균으로부터 멀리 넓게 퍼져 있을수록 표본분산은 큰 값을 가진다. 편차를 그대로 더하면 합이 항상 $0$이 되어 데이터의 퍼짐 정도를 알 수 없으므로, 편차를 제곱하여 모든 값을 양수로 만든 뒤 평균을 내는 방식을 사용한다.

### 기본 성질
표본분산은 항상 $0$ 이상의 값을 가지며, 계산의 편의를 위해 다음과 같은 동치 공식을 사용할 수 있다.
$$S^2 = \frac{1}{n}\sum_{i=1}^{n}x_i^2 - \bar{x}^2$$
이 공식은 각 데이터의 제곱의 평균에서 평균의 제곱을 뺀 값과 같음을 의미하며, 편차를 일일이 구하기 번거로운 경우 매우 유용하다.

## 학습 체크

- 표본의 데이터가 평균에 가까워질 때 표본분산의 값은 어떻게 변화하는가?
- 정의를 이용한 계산 방식과 동치 공식을 이용한 계산 결과가 왜 동일한가?

## 관련 개념

**표본평균**은 표본분산 계산의 출발점이다. $\bar{x}$를 먼저 구해야 각 값과의 편차를 잡을 수 있으므로, 표본분산을 구하기 전에 반드시 표본평균을 확정해야 한다.

**모분산** $\sigma^2$은 모집단 전체를 대상으로 같은 방식으로 정의한 분산이다. 현실에서는 모집단 전부를 조사하기 어렵기 때문에 표본분산을 구해 모분산을 추정한다. 표본의 크기 $n$이 클수록 표본분산은 모분산에 가까워진다.

**표본표준편차** $S = \sqrt{S^2}$는 표본분산의 양의 제곱근이다. 분산은 원래 단위를 제곱한 단위를 가지므로 해석이 어색할 수 있는데, 표준편차는 원래 데이터와 같은 단위로 돌아와 실질적인 퍼짐 정도를 직관적으로 나타낸다.

**추정**은 표본분산이 실제로 쓰이는 맥락이다. 모분산 $\sigma^2$을 알 수 없을 때 표본분산 $S^2$을 그 추정값으로 사용하고, 이를 바탕으로 모집단의 특성에 대한 결론을 내린다.
