### 정확한 진술

각(angle)은 한 점에서 출발한 두 반직선이 이루는 크기를 의미하며, 범위와 부호는 맥락에 따라 정의됩니다. 고등학교 삼각함수에서는 주로 다음을 다룹니다.

**일반각(general angle)**: 표준 위치(시초선이 $x$축의 양의 방향)에서 정의한 각 $\theta = \alpha + 360° \cdot n$ (단, $n$은 정수). 호도법으로는 $\theta = \alpha + 2\pi k$ (단, $k$는 정수).

**각의 부호**: 단위원 위에서 동경(각의 끝 변)이 위치한 **사분면**에 따라 결정됩니다.
- **제1사분면** ($0° < \theta < 90°$): $\sin \theta > 0, \cos \theta > 0, \tan \theta > 0$
- **제2사분면** ($90° < \theta < 180°$): $\sin \theta > 0, \cos \theta < 0, \tan \theta < 0$
- **제3사분면** ($180° < \theta < 270°$): $\sin \theta < 0, \cos \theta < 0, \tan \theta > 0$
- **제4사분면** ($270° < \theta < 360°$): $\sin \theta < 0, \cos \theta > 0, \tan \theta < 0$

### 직관/기하적 의미

단위원 위의 점 $P(\cos \theta, \sin \theta)$를 생각해봅시다. 각 $\theta$는 양수 $x$축(시초선)에서 점 $P$까지 **반시계 방향**으로 측정한 호의 길이(라디안)입니다. 음의 각은 시계 방향으로 측정합니다.

삼각함수의 부호는 점 $P$의 좌표에서 직접 나옵니다: $\sin \theta$는 $y$좌표이므로 제1, 2사분면에서 양수이고, $\cos \theta$는 $x$좌표이므로 제1, 4사분면에서 양수입니다. $\tan \theta = \frac{\sin \theta}{\cos \theta}$의 부호는 분자와 분모 부호의 곱입니다.

일반각 $\theta = \alpha + 360° \cdot n$의 개념은 "기준각 $\alpha$에서 출발해 몇 바퀴를 도는가"를 나타냅니다. 예를 들어 $30°, 390°(-330°)$는 모두 같은 동경을 나타냅니다.

### 한 줄 예

$\theta = 240°$는 제3사분면에 속하므로: $\sin 240° = -\frac{\sqrt{3}}{2}$, $\cos 240° = -\frac{1}{2}$, $\tan 240° = \sqrt{3}$ (음수 ÷ 음수 = 양수).
