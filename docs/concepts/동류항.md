# 동류항

> **정의** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
문자와 차수가 같은 항

## 본문 (학습 시 채워짐)

### 정의
동류항(like terms)은 **같은 문자가 같은 차수로 나타나는 항**입니다. 같은 문자로 이루어진 항들 중에서 그 문자의 지수가 모두 같으면 동류항입니다.

예를 들어, $2x$와 $5x$, $3x$와 $-7x$는 모두 동류항입니다. 두 항 모두 문자 $x$가 1제곱으로 나타나기 때문입니다. 마찬가지로 $3x^2$과 $-4x^2$, $2xy$와 $5xy$도 동류항입니다. 반면 $2x$와 $3x^2$는 동류항이 아닙니다. 문자는 같지만 차수가 다르기 때문입니다.

### 직관과 의미
동류항을 구분하는 이유는 **동류항끼리만 더하거나 뺄 수 있기 때문**입니다. $3x + 5x$는 $8x$로 한 번에 계산되지만, $3x + 2x^2$는 더 이상 정리할 수 없습니다. 복잡한 식을 간단하게 정리하려면 먼저 동류항을 찾아내 모아야 합니다. 이것은 방정식을 풀거나 식을 전개하고 인수분해할 때 가장 기본이 되는 기술입니다.

### 예시
식을 정리해보겠습니다: $2x + 3x^2 - 5x + x^2 + 7$

동류항끼리 모으면:
- $x$의 1제곱 항: $2x - 5x = -3x$
- $x$의 2제곱 항: $3x^2 + x^2 = 4x^2$
- 상수항: $7$

따라서 정리된 식은 $4x^2 - 3x + 7$입니다. 이렇게 동류항을 찾아 계산하면 복잡해 보이는 식도 간단하게 정리됩니다.
