# 절댓값

> **정의** · 중1 · 단원: [정수와 유리수](/concepts/정수와_유리수)

## 요약
수직선 위에서 원점까지의 거리

## 본문 (학습 시 채워짐)

### 정확한 진술

어떤 수 $a$의 **절댓값**은 다음과 같이 정의됩니다.

$$|a| = \begin{cases} a & \text{if } a \geq 0 \\ -a & \text{if } a < 0 \end{cases}$$

즉, 양수나 0이면 그대로 두고, 음수면 부호를 바꿔서 양수로 만드는 연산입니다.

### 직관과 기하적 의미

수직선 위에 원점(0)과 어떤 수를 나타내는 점이 있을 때, 절댓값은 **그 점에서 원점까지의 거리**를 나타냅니다. 거리는 항상 0 이상이므로 절댓값도 항상 음이 아닌 수입니다.

예를 들어, 수직선에서 3은 원점의 오른쪽으로 3칸 떨어져 있고, -3은 원점의 왼쪽으로 3칸 떨어져 있으므로 $|3| = 3$, $|-3| = 3$입니다. 두 점 모두 원점으로부터 같은 거리에 있다는 뜻입니다.

### 기본 성질

- $|0| = 0$
- 양수 $a > 0$에 대해 $|a| = a$
- 음수 $a < 0$에 대해 $|a| = -a$ (음수의 부호를 없앤 값)
- 모든 수 $a$에 대해 $|-a| = |a|$ (대칭성)

### 간단한 예

$|5| = 5$, $|-5| = 5$, $|0| = 0$, $|-\frac{1}{2}| = \frac{1}{2}$, $|-12.3| = 12.3$

이런 식으로 절댓값을 계산할 수 있습니다: `abs(-7)` → 7
