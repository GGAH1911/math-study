### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)와 x축의 교점의 개수는 **판별식** $D = b^2 - 4ac$의 부호로 완전히 결정됩니다.

- $D > 0$: 서로 다른 두 실근 → 그래프가 x축과 **두 점에서 만남**
- $D = 0$: 중근 → 그래프가 x축과 **한 점에서 접함** (중근점)
- $D < 0$: 실근이 없음 → 그래프가 x축과 **만나지 않음**

### 직관/기하적 의미

근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$에서 제곱근 안의 식이 판별식 $D = b^2 - 4ac$입니다. 이 값이 음수면 실수해가 존재하지 않으므로, 그래프는 x축과 만나지 않습니다. 반대로 양수면 두 개의 서로 다른 근이 존재하여 두 교점이 생기고, 0이면 제곱근이 0이 되어 중근이 됩니다. **판별식은 결국 이차방정식의 근의 존재성과 개수를 나타내는 지표**입니다.

### 한 줄 예

$f(x) = x^2 - 5x + 6$의 경우, $D = (-5)^2 - 4(1)(6) = 25 - 24 = 1 > 0$ → 두 실근 $x = 2, 3$ → x축과 두 점 $(2, 0)$, $(3, 0)$에서 만남.

```python
# 검산: sympy.solve(x**2 - 5*x + 6, x)  → [2, 3]
```
