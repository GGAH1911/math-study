### 정확한 진술

로그의 밑 변환 공식은 한 밑의 로그를 다른 밑의 로그로 나타내는 공식입니다.

$a > 0, a \neq 1, b > 0, c > 0, c \neq 1$일 때:
$$\log_a b = \frac{\log_c b}{\log_c a}$$

특히 상용로그(밑 10) 또는 자연로그(밑 $e$)로 나타내면:
$$\log_a b = \frac{\log b}{\log a} = \frac{\ln b}{\ln a}$$

### 직관과 기하적 의미

로그 $\log_a b = x$는 "$a$를 $x$번 곱하면 $b$가 된다"는 뜻입니다. 그런데 임의의 밑으로 로그를 직접 계산하기는 어렵습니다. 하지만 계산기나 로그표에는 상용로그나 자연로그 값이 있으므로, 이들을 이용해 다른 밑의 로그값을 구할 수 있습니다.

수식으로 보면, 밑 $a$에서의 로그값은 "밑 $c$에서 본 $b$의 값"을 "밑 $c$에서 본 $a$의 값"으로 나눈 것입니다. 이는 두 밑의 성장률을 비교하는 것과 같습니다. 어떤 "기준 밑" $c$를 정해두고 모든 로그를 그 기준으로 표현하면, 임의의 밑의 로그를 쉽게 계산할 수 있으므로, 수학 계산과 실생활 응용에서 매우 유용합니다.

### 예시

$\log_2 8$을 구하려면 밑 변환 공식으로:
$$\log_2 8 = \frac{\log 8}{\log 2} = \frac{\ln 8}{\ln 2}$$

$8 = 2^3$이므로 답은 $3$입니다. (`sympy.log(8)/sympy.log(2)` → 3.0)

또 다른 예로, $\log_3 27 = \frac{\ln 27}{\ln 3} = \frac{\ln 3^3}{\ln 3} = 3$입니다.
