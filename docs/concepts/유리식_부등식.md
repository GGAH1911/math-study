# 유리식 부등식

## 요약
유리식 부등식은 분모에 변수가 포함된 식을 포함하는 부등식으로, 분모가 $0$이 되지 않는 조건 하에 분자와 분모의 부호를 분석하여 해를 구한다.

## 본문
유리식 부등식이란 부등호 양변에 유리식(분모에 변수가 포함된 식)이 있는 부등식을 말한다. 유리식 부등식을 풀 때 가장 주의해야 할 점은 분모를 양변에 직접 곱하거나 이항할 때 분모의 부호가 변수에 따라 달라질 수 있어 부등호의 방향이 바뀔 수 있다는 것이다. 따라서 분모를 직접 이항하여 계산하기보다는 우변을 $0$으로 만든 뒤 통분하여 하나의 유리식 형태로 정리하거나, 분자와 분모의 부호를 각각 분석하는 방법을 사용한다. 이때 분모가 $0$이 되는 값은 정의되지 않으므로 반드시 해에서 제외해야 한다.

$$\frac{f(x)}{g(x)} > 0 \iff f(x)\,g(x) > 0 \quad (g(x) \neq 0)$$

### 직관과 기하적 의미
유리식의 부호는 분자와 분모의 부호가 서로 같으면 양수($+$)가 되고, 서로 다르면 음수($-$)가 된다는 원리를 이용한다. 이는 수직선 위에서 함수의 값이 $0$보다 큰 구간과 작은 구간을 찾는 과정과 같다.

### 기본 성질
$\dfrac{x-1}{x+2} > 0$과 같은 부등식을 풀기 위해서는 분자와 분모의 부호가 바뀌는 경계점인 $x=1$과 $x=-2$를 기준으로 구간을 나누어 분석한다.

| 구간 | $x-1$ | $x+2$ | 분수 |
|------|--------|--------|------|
| $x < -2$ | $-$ | $-$ | $+$ |
| $-2 < x < 1$ | $-$ | $+$ | $-$ |
| $x > 1$ | $+$ | $+$ | $+$ |

위 표를 통해 $x < -2$ 또는 $x > 1$일 때 유리식의 값이 양수가 됨을 알 수 있다. 단, 분모가 $0$이 되는 $x = -2$는 해에서 제외한다.

## 학습 체크
- 분모를 양변에 곱하여 식을 정리할 때, 분모의 부호가 변수에 따라 달라질 수 있음을 고려하였는가?
- 부등식의 해를 구할 때 분모가 $0$이 되는 값을 제외하였는가?
- 분자와 분모의 부호 변화를 기준으로 구간을 나누어 정확히 분석하였는가?
