# 평균 중앙값 최빈값

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
대푯값 3종

## 본문 (학습 시 채워짐)

### 정확한 진술

**평균(mean)**은 모든 데이터의 합을 데이터 개수로 나눈 값입니다. 데이터 $x_1, x_2, \ldots, x_n$이 주어질 때:
$$\text{평균} = \bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

**중앙값(median)**은 데이터를 크기 순서로 정렬했을 때 중앙에 위치한 값입니다. 데이터가 홀수 개면 가운데 값, 짝수 개면 가운데 두 값의 평균입니다.

**최빈값(mode)**은 데이터 중에서 가장 자주 나타나는 값(빈도가 가장 높은 값)입니다.

### 직관과 사용 상황

세 대푯값은 데이터의 '중심'을 나타내지만, 각각 다른 관점에서 봅니다.

**평균**은 모든 데이터를 균등하게 반영하므로, 극값(매우 크거나 작은 값)의 영향을 크게 받습니다. 따라서 극값이 없는 '정상적인' 분포에서 가장 유용합니다.

**중앙값**은 극값에 강합니다. 예를 들어 소득 통계에서 소수의 부자가 평균을 크게 올리더라도, 중앙값은 일반적인 소득 수준을 더 잘 나타냅니다.

**최빈값**은 카테고리 데이터(예: 선호하는 과목)나 가장 인기 있는 값을 찾을 때 유용하며, 유일하지 않을 수 있습니다.

### 한 줄 예

$(1, 2, 2, 3, 10)$에서 평균은 $\frac{18}{5} = 3.6$, 중앙값은 $2$, 최빈값은 $2$입니다. 극값 $10$ 때문에 평균이 왼쪽으로 치우친 데이터를 제대로 표현하지 못하지만, 중앙값 $2$는 대부분의 데이터를 더 잘 대표합니다.
