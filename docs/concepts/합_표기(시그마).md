# 합 표기(시그마)

수열 $\{a_n\}$의 첫째 항부터 제$n$항까지의 합을 나타낼 때, 각 항을 일일이 나열하는 대신 **시그마($\Sigma$)** 기호를 사용해 간결하게 표현한다.

$$\sum_{k=1}^{n} a_k = a_1 + a_2 + a_3 + \cdots + a_n$$

기호 아래에 쓴 $k=1$은 합산을 시작하는 첫 번째 인덱스, 기호 위에 쓴 $n$은 마지막 인덱스를 뜻한다. $k$는 합산이 진행되면서 $1, 2, 3, \ldots, n$으로 하나씩 증가하는 변수이며, 합산이 끝나면 사라지는 **더미 변수(dummy variable)**다. 즉 $k$ 자리에 어떤 문자를 써도 합의 값은 달라지지 않는다.

시그마는 다음 기본 성질을 만족한다.

$$\sum_{k=1}^{n}(a_k + b_k) = \sum_{k=1}^{n} a_k + \sum_{k=1}^{n} b_k, \qquad \sum_{k=1}^{n} c\,a_k = c\sum_{k=1}^{n} a_k$$

상수 $c$에 대해 $\displaystyle\sum_{k=1}^{n} c = cn$이 성립한다.

## 예시

**예시 1.** 자연수 $1$부터 $100$까지의 합을 시그마로 쓰면

$$\sum_{k=1}^{100} k = 1 + 2 + 3 + \cdots + 100 = \frac{100 \cdot 101}{2} = 5050$$

이다. 자연수의 합 공식 $\displaystyle\sum_{k=1}^{n} k = \dfrac{n(n+1)}{2}$을 바로 적용했다.

**예시 2.** 첫째 항이 $2$, 공비가 $3$인 등비수열의 첫째 항부터 제$5$항까지의 합은

$$\sum_{k=1}^{5} 2 \cdot 3^{k-1} = 2 + 6 + 18 + 54 + 162 = 2 \cdot \frac{3^5 - 1}{3 - 1} = 242$$

이다. 시그마 안의 식 $2 \cdot 3^{k-1}$에 $k = 1, 2, 3, 4, 5$를 차례로 대입하면 각 항이 만들어지고, 그 합이 등비수열의 합 공식과 정확히 일치함을 확인할 수 있다.

## 관련 개념

**수열**은 시그마의 토대다. 시그마는 수열의 각 항 $a_k$를 정해진 규칙대로 더하는 작업을 기호 하나로 압축한 것이므로, 수열의 일반항을 먼저 파악해야 시그마를 올바르게 쓸 수 있다.

**등차수열의 합**과 **등비수열의 합**은 각각 $\displaystyle\sum_{k=1}^{n} k$, $\displaystyle\sum_{k=1}^{n} r^{k-1}$ 꼴로 표현되며, 시그마 공식을 통해 닫힌 형태의 합 공식으로 이어진다.

$\displaystyle\sum_{k=1}^{n} k^2 = \dfrac{n(n+1)(2n+1)}{6}$, $\displaystyle\sum_{k=1}^{n} k^3 = \left\{\dfrac{n(n+1)}{2}\right\}^2$ 같은 **거듭제곱의 합 공식**도 시그마 표기 위에서 증명하고 활용한다.

나아가 수열의 **점화식**으로 정의된 수열의 합을 구할 때도 시그마를 이용해 양변을 합산하는 방식이 자주 쓰이므로, 점화식과도 밀접하게 연결된다.
