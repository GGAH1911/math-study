# 미분을 이용한 최적화

## 요약
함수의 도함수가 $0$이 되는 지점을 찾아 함수의 최댓값과 최솟값을 결정하는 과정이다.

## 본문
미분을 이용한 최적화는 주어진 함수의 값이 최대 또는 최소가 되는 지점을 찾는 수학적 방법이다. 연속인 함수 $f(x)$가 어떤 구간에서 미분 가능하다면, 함수의 극값은 도함수 $f'(x)=0$을 만족하는 임계점에서 발생할 가능성이 높다. 최적화 과정은 먼저 함수의 도함수를 구하여 $f'(x)=0$인 $x$의 값을 찾는 것에서 시작한다. 이후 해당 지점 전후에서의 도함수의 부호 변화를 확인하거나, 이계도함수 $f''(x)$의 부호를 조사하여 해당 점이 극대점인지 극소점인지 판별한다. 만약 구간이 닫힌 구간 $[a, b]$로 제한되어 있다면, 구간 내부의 극값뿐만 아니라 양 끝점에서의 함숫값도 함께 비교하여 전체 구간에서의 최댓값과 최솟값을 결정해야 한다.

### 직관과 기하적 의미
함수의 그래프에서 접선의 기울기가 $0$이 되는 지점은 그래프가 상승을 멈추고 하강으로 돌아서거나, 하강을 멈추고 상승으로 돌아서는 변곡점의 후보가 된다. 즉, 접선이 $x$축과 평행하게 놓이는 지점을 찾는 것이 최적화의 기하학적 핵심이다.

### 기본 성질
함수가 연속이고 미분 가능하다면, 극값은 반드시 도함수가 $0$인 지점에서 나타나며, 이는 함수의 증가와 감소가 바뀌는 경계가 된다.

## 학습 체크
- 도함수가 $0$이 되는 지점이 반드시 함수의 극값이라는 보장이 있는가?
- 닫힌 구간에서 최댓값과 최솟값을 찾을 때 구간의 양 끝값을 반드시 고려해야 하는가?

## 관련 개념
- **지수함수와 로그함수**: 이 함수들은 미분법을 통해 함수의 증가와 감소를 분석함으로써 복잡한 형태의 최적화 문제를 해결하는 데 사용된다.
