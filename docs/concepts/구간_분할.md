# 구간 분할

## 요약
전체 구간을 여러 개의 작은 구간으로 나누어 함수를 분석하거나 적분 값을 계산하는 방법입니다.

## 본문
구간 분할이란 주어진 구간 $[a, b]$를 여러 개의 하위 구간으로 쪼개어 각 구간의 길이를 작게 만드는 과정을 의미합니다. 일반적으로 구간 $[a, b]$를 $n$개의 부분 구간 $[x_0, x_1], [x_1, x_2], \dots, [x_{n-1}, x_n]$으로 나누는 것을 말하며, 이때 $x_0 = a$이고 $x_n = b$입니다. 각 부분 구간의 경계점들을 순서대로 나열한 것을 분할이라고 하며, 구간의 개수가 많아질수록 각 구간의 폭은 점점 작아지게 됩니다.

### 직관과 기하적 의미
기하학적으로 구간 분할은 복잡한 곡선 아래의 넓이를 구할 때, 이를 다루기 쉬운 직사각형들의 합으로 근사하기 위해 밑변을 잘게 나누는 과정과 같습니다. 구간을 더 잘게 나눌수록 직사각형들의 높이와 곡선 사이의 오차가 줄어들어 실제 넓이에 더 가까워집니다.

### 기본 성질
구간을 분할할 때 구간의 개수가 늘어날수록 각 구간의 최대 폭은 감소하며, 분할이 세분화될수록 근사값의 정밀도가 높아집니다. 또한, 하나의 구간을 다시 여러 개의 구간으로 나누는 재분할 과정은 적분의 극한값을 정의하는 기초가 됩니다.

## 학습 체크
- 구간의 개수가 무한히 많아질 때 구간의 폭이 $0$으로 수렴하는 조건은 무엇인가?
- 분할된 구간의 경계점들이 항상 순서대로 배열되어야 하는 이유는 무엇인가?

## 관련 개념
- **적분**: 구간을 무한히 잘게 나누어 각 부분의 넓이를 합산하는 극한의 과정이 적분의 핵심 원리입니다.
