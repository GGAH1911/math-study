# 괄호 풀기

> **예제** · 중1 · 단원: [문자와 식](/concepts/문자와_식)

## 요약
$3(2x-1)-2(x+4)$ 정리

## 본문 (학습 시 채워짐)

### 문제

다음 식을 정리하세요.
$$3(2x-1)-2(x+4)$$

### 단계별 풀이

**1단계: 분배법칙으로 첫 번째 괄호 풀기**

괄호 앞의 수를 괄호 안의 각 항에 곱합니다.
$$3(2x-1) = 3 \cdot 2x + 3 \cdot (-1) = 6x - 3$$

**2단계: 분배법칙으로 두 번째 괄호 풀기**

음수를 분배할 때는 괄호 안의 부호가 반대로 바뀝니다. $-2 \times x = -2x$, $-2 \times 4 = -8$입니다.
$$-2(x+4) = -2x - 8$$

**3단계: 괄호를 푼 식 정리하기**

괄호를 풀어서 얻은 모든 항을 나열합니다.
$$6x - 3 - 2x - 8$$

**4단계: 같은 항끼리 정리하기**

$x$가 있는 항끼리, 숫자인 상수항끼리 모아서 계산합니다.
- $x$ 항: $6x - 2x = 4x$
- 상수항: $-3 - 8 = -11$

### 답

$$4x - 11$$

검산: $x=1$일 때 원래 식은 $3(1) - 2(5) = 3 - 10 = -7$, 정리된 식은 $4(1) - 11 = -7$ ✓

### 변형 및 주의

부호 실수가 가장 많이 나옵니다. 특히 빼기 기호 앞의 괄호를 풀 때 주의하세요. $-2(x+4) = -2x - 8$이지 $-2x + 8$이 아닙니다. 괄호 안의 모든 항의 부호가 반대로 바뀌어야 합니다. 같은 항을 정리할 때도 부호를 포함해서 더하고 빼야 하므로 천천히 확인하며 진행하세요.
