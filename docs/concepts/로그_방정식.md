### 정확한 진술
로그 방정식은 미지수를 포함하는 로그식이 있는 방정식을 말합니다. 일반적으로 $\log_a f(x) = c$ 형태, 또는 $\log_a f(x) = \log_a g(x)$ 형태, 또는 이들이 합쳐진 형태입니다. 여기서 $a$는 밑($a > 0, a \neq 1$)이고, $f(x), g(x)$는 미지수 $x$를 포함하는 함수입니다.

### 직관과 풀이 원리
로그의 정의 $\log_a b = c \Leftrightarrow a^c = b$를 이용하면, 모든 로그 방정식을 지수 방정식으로 바꿀 수 있습니다. 예를 들어 $\log_2 x = 3$은 "2를 몇 제곱하면 $x$가 되는가"를 묻는 것이므로 $x = 2^3 = 8$입니다. 더 복잡한 경우, 로그의 성질—$\log_a(MN) = \log_a M + \log_a N$, $\log_a(M/N) = \log_a M - \log_a N$, $\log_a(M^n) = n\log_a M$—을 이용하여 식을 정리한 후 풉니다.

중요한 점은 로그의 진수가 항상 양수여야 한다는 조건입니다. 방정식을 풀고 나면 구한 해가 모든 로그 함수의 진수 조건을 만족하는지 반드시 확인해야 합니다. 조건을 만족하지 않는 해는 버립니다.

### 한 줄 예
$\log_2(x+1) = 3$에서 정의에 의해 $x + 1 = 2^3 = 8$이므로 $x = 7$이고, 진수 조건 $x + 1 > 0$을 만족합니다. (검증: $\log_2 8 = 3$ ✓)
