# 함수의조건

## 요약
집합 $X$의 모든 원소가 집합 $Y$의 원소에 오직 하나씩만 대응될 때, 이를 두 집합 사이의 함수라고 합니다.

## 본문
두 집합 $X$와 $Y$에 대하여, 집합 $X$의 각 원소 $x$에 대하여 집합 $Y$의 원소 $y$가 오직 하나씩 대응되는 관계를 함수라고 하며, 이때 $X$를 정의역, $Y$를 공역이라고 합니다. 함수가 성립하기 위해서는 정의역의 모든 원소가 반드시 대응되어야 하며, 하나의 원소가 두 개 이상의 원소에 대응되어서는 안 된다는 두 가지 핵심 조건을 충족해야 합니다.

### 직관과 기하적 의미
함수를 그래프로 나타냈을 때, $x$축의 임의의 값을 선택하여 수직선을 그었을 때 그래프와 만나는 점이 반드시 하나여야 합니다. 만약 수직선이 그래프와 만나지 않는 구간이 있다면 이는 정의역의 일부 원소가 대응되지 않음을 의미하며, 두 개 이상의 점에서 만난다면 하나의 원소가 여러 곳에 대응됨을 의미하므로 함수의 조건을 만족하지 않습니다.

### 기본 성질
함수 $f: X \to Y$에서 정의역 $X$의 모든 원소는 반드시 공역 $Y$의 원소와 연결되어야 하며, $x_1 \neq x_2$이면 $f(x_1) \neq f(x_2)$여야 한다는 성질이 있습니다. 이는 함수가 결정론적인 규칙을 가지고 있음을 의미하며, 입력값이 같으면 출력값도 반드시 같아야 함을 시사합니다.

## 학습 체크
- 정의역의 원소 중 대응되는 값이 없는 원소가 존재하는가?
- 정의역의 한 원소가 서로 다른 두 개 이상의 공역 원소에 대응되는가?

## 관련 개념
- **여러가지함수의 극한**: 함수의 대응 관계가 연속적이고 극한값이 존재할 때, 함수의 거동을 분석하는 도구로 사용됩니다.
