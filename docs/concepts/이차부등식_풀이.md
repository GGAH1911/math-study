# 이차부등식 풀이

> **예제** · 고1 · 단원: [방정식과 부등식](/concepts/방정식과_부등식)

## 요약
그래프 활용

## 본문 (학습 시 채워짐)

### 문제

다음 이차부등식을 풉니다.

$$x^2 - 5x + 6 < 0$$

### 단계별 풀이

**1단계: 이차방정식의 근 구하기**

부등식을 등식으로 바꾸어 $x^2 - 5x + 6 = 0$을 풉니다.

$$x^2 - 5x + 6 = (x-2)(x-3) = 0$$

따라서 $x = 2$ 또는 $x = 3$입니다.

**2단계: 포물선의 개형 파악**

이차함수 $y = x^2 - 5x + 6$은 최고차 계수가 $1 > 0$이므로 아래로 볼록(∪ 모양)한 포물선입니다. 이 포물선은 $x = 2, 3$에서 $x$축과 만납니다.

**3단계: 그래프로 부등식 해석**

부등식 $x^2 - 5x + 6 < 0$은 "**포물선이 $x$축 아래에 있는 $x$의 범위**"를 찾는 것입니다. 아래로 볼록한 포물선에서 $x$축 아래 구간은 두 근 사이이므로, $2 < x < 3$ 구간입니다.

**4단계: 해 확인**

$x = 2.5$를 대입하면: $(2.5)^2 - 5(2.5) + 6 = 6.25 - 12.5 + 6 = -0.25 < 0$ ✓

### 답

$$2 < x < 3$$

### 변형/주의

**부등호 종류에 따른 차이:**
- $x^2 - 5x + 6 \leq 0$ → $2 \leq x \leq 3$ (근을 포함)
- $x^2 - 5x + 6 > 0$ → $x < 2$ 또는 $x > 3$ ($x$축 위쪽)
- $x^2 - 5x + 6 \geq 0$ → $x \leq 2$ 또는 $x \geq 3$

**주의:** 최고차 계수가 음수인 $-x^2 + 5x - 6 < 0$이면 포물선이 위로 볼록하므로 해의 형태가 달라집니다. 항상 최고차 계수의 부호를 먼저 확인하세요.

**검산:** `from sympy import symbols, solve; x = symbols('x'); solve(x**2 - 5*x + 6 < 0, x)`
