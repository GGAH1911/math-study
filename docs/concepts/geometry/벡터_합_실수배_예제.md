# 벡터 합 실수배 예제

> **예제** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
성분으로 계산

## 본문 (학습 시 채워짐)

### 문제

$\vec{a} = (2, 1)$, $\vec{b} = (-1, 3)$ 일 때, $2\vec{a} - \vec{b}$를 구하고 그 크기를 구하시오.

### 단계별 풀이

**1단계: 실수배를 각 성분에 적용합니다.**

벡터에 실수를 곱할 때는 모든 성분을 그 수로 곱합니다. $2\vec{a} = 2(2, 1) = (4, 2)$입니다. 이는 성분 하나하나에 2를 곱한 것이므로 실수배의 정의를 따릅니다.

**2단계: 벡터의 차를 성분끼리 계산합니다.**

$2\vec{a} - \vec{b} = (4, 2) - (-1, 3)$입니다. 벡터의 차는 대응하는 성분끼리 뺍니다:

$$2\vec{a} - \vec{b} = (4 - (-1), 2 - 3) = (5, -1)$$

**3단계: 크기를 피타고라스 정리로 구합니다.**

벡터의 크기는 $\left|\vec{v}\right| = \sqrt{x^2 + y^2}$이므로:

$$|2\vec{a} - \vec{b}| = \sqrt{5^2 + (-1)^2} = \sqrt{25 + 1} = \sqrt{26}$$

(`(4, 2) - (-1, 3) = (5, -1); sqrt(5**2 + (-1)**2)` → `sqrt(26)`)

### 답

$2\vec{a} - \vec{b} = (5, -1)$이고, 크기는 $\sqrt{26}$입니다.

### 변형·주의

**부호 주의**: $-\vec{b} = (-(-1), -3) = (1, -3)$입니다. 벡터 앞의 마이너스 부호는 모든 성분의 부호를 바꿉니다. $(−1, 3)$을 빼는 것은 $(1, −3)$을 더하는 것과 같습니다.

**복합 계산**: 실수배와 덧셈·뺄셈이 섞여 있을 때는 먼저 실수배를 각각 처리한 후, 벡터의 합과 차를 계산합니다. 순서를 헷갈리면 성분이 틀릴 수 있습니다.
