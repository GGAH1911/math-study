# 평면의 법선벡터

> **정리** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
평면에 수직인 벡터

## 본문 (학습 시 채워짐)

### 진술: 평면의 법선벡터

점 $P_0(x_0, y_0, z_0)$을 지나고 0이 아닌 벡터 $\vec{n} = (a, b, c)$에 수직인 평면의 방정식은 다음과 같이 표현됩니다.

$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$$

이때 벡터 $\vec{n} = (a, b, c)$를 이 평면의 **법선벡터**(normal vector)라 합니다. 법선벡터는 평면에 수직이며, 평면 위의 모든 벡터와 수직(내적이 0)입니다.

### 유도: 왜 $(a, b, c)$가 법선벡터인가

평면 위의 임의의 점을 $P(x, y, z)$라 하면, 벡터 $\overrightarrow{P_0P} = (x - x_0, y - y_0, z - z_0)$는 평면 위에 있으므로 $\vec{n}$과 수직입니다. 따라서:

$$\vec{n} \cdot \overrightarrow{P_0P} = 0$$

$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$$

이를 전개하면 $ax + by + cz = d$ 형태(단, $d = ax_0 + by_0 + cz_0$)가 되는데, **이 평면의 방정식에서 $x, y, z$의 계수가 바로 법선벡터의 성분**입니다.

### 의의와 응용

평면의 법선벡터는 다음과 같이 활용됩니다:

1. **평면의 방정식 작성**: 평면 위의 한 점과 법선벡터가 주어지면 평면의 방정식을 즉시 쓸 수 있습니다.

2. **평면 간 관계 판정**: 두 평면의 법선벡터가 평행하면 두 평면도 평행합니다. 법선벡터들의 내적이 0이면 두 평면은 수직입니다.

3. **점과 평면 사이의 거리**: 점 $(x_1, y_1, z_1)$과 평면 $ax + by + cz = d$ 사이의 거리는 $\displaystyle\frac{|ax_1 + by_1 + cz_1 - d|}{\sqrt{a^2 + b^2 + c^2}}$로, 법선벡터의 크기 $|\vec{n}|$이 분모에 나타납니다.

**예**: 평면 $2x - y + 3z = 5$의 법선벡터는 $(2, -1, 3)$이며, 점 $(1, 1, 1)$을 지나고 법선벡터가 $(1, 2, -1)$인 평면의 방정식은 $1(x-1) + 2(y-1) - 1(z-1) = 0$ 즉, $x + 2y - z = 2$입니다.
