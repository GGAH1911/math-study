# 점과 직선의 거리 공식

## 본문

### 정확한 진술

좌표평면에서 점 $P(x_0, y_0)$과 직선 $ax + by + c = 0$ 사이의 거리 $d$는 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

여기서 $a^2 + b^2 \neq 0$입니다.

### 직관과 기하적 의미

점에서 직선까지의 거리는 점을 지나고 직선에 수직인 직선이 원래 직선과 만나는 교점까지의 거리입니다. 즉, 점에서 직선에 내린 수선의 길이입니다.

공식 분자 $|ax_0 + by_0 + c|$는 점의 좌표가 직선 방정식을 얼마나 "어기는지"를 나타내고, 분모 $\sqrt{a^2 + b^2}$는 직선의 방향을 정규화합니다. 분자의 절댓값은 점이 직선의 어느 쪽에 있든 거리를 양수로 만듭니다.

### 핵심 예시

직선 $3x + 4y - 5 = 0$과 점 $(1, 2)$ 사이의 거리는:

$$d = \frac{|3(1) + 4(2) - 5|}{\sqrt{3^2 + 4^2}} = \frac{|3 + 8 - 5|}{\sqrt{9 + 16}} = \frac{6}{5}$$

(검산: `sympy.sqrt((3*1 + 4*2 - 5)**2 / (3**2 + 4**2))` = 1.2)

### 공식 기억법

분자는 점 $(x_0, y_0)$을 직선 방정식 $ax + by + c = 0$에 대입한 값의 절댓값입니다. 분모는 직선의 일반형에서 계수 $a, b$의 제곱의 합에 제곱근을 씌운 것입니다. 이 구조는 거리의 기하학적 정의를 대수적으로 인코딩한 것입니다.
