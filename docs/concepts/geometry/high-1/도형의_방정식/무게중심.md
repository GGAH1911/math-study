# 무게중심

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
도형을 구성하는 점들의 좌표를 산술 평균하여 구하는 균형점입니다.

## 본문
평면 위의 점 $P_1(x_1, y_1), P_2(x_2, y_2), \cdots, P_n(x_n, y_n)$이 주어졌을 때, 이들 점의 무게중심은 각 좌표의 평균값인 $G\left(\frac{x_1 + x_2 + \cdots + x_n}{n}, \frac{y_1 + y_2 + \cdots + y_n}{n}\right)$입니다. 특히 삼각형의 세 꼭짓점이 $A(x_1, y_1), B(x_2, y_2), C(x_3, y_3)$인 경우, 무게중심 $G$의 좌표는 각 좌표의 합을 3으로 나눈 $G\left(\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3}\right)$이 됩니다.

### 직관과 기하적 의미
무게중심은 도형의 물리적 균형을 이루는 "균형점"입니다. 균일한 밀도를 가진 판을 도형 모양으로 잘라 무게중심에 받치면 판이 기울어지지 않고 수평을 유지합니다. 기하학적으로 삼각형의 무게중심은 세 중선, 즉 각 꼭짓점과 그 대변의 중점을 잇는 직선들이 한 점에서 만나는 점을 의미합니다.

### 기본 성질
삼각형의 무게중심은 각 중선을 꼭짓점으로부터 $2:1$의 비율로 내분하는 성질을 가집니다. 또한, 점의 개수가 늘어나더라도 각 좌표의 산술 평균을 구하는 방식으로 일반화하여 구할 수 있으며, 이는 물리학의 질량중심이나 통계학의 평균 위치 개념으로 확장됩니다.

## 학습 체크
- $n$개의 점이 주어졌을 때 무게중심의 좌표를 구하는 공식은 무엇인가요?
- 삼각형의 무게중심이 중선을 어떤 비율로 나누는지 설명할 수 있나요?
- 세 꼭짓점이 $A(0, 0), B(6, 0), C(0, 3)$인 삼각형의 무게중심을 직접 계산해 보세요.

## 관련 개념
- **좌표평면과 그래프**: 점의 위치를 수치화하여 나타낸 평면 위에서 무게중심의 좌표를 계산하는 기초가 됩니다.
- **중점**: 무게중심을 구하거나 중선의 성질을 이해할 때 대변의 중점을 찾는 과정이 필수적입니다.
- **내분점**: 무게중심이 중선을 $2:1$로 나누는 지점임을 이해하기 위해 필요한 개념입니다.
