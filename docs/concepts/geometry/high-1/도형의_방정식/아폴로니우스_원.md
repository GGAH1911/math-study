# 아폴로니우스 원

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 정점으로부터의 거리의 비가 일정하게 유지되는 점들의 자취는 원을 이룹니다.

## 본문
두 점 $A$, $B$와 양수 $k$ ($k \neq 1$)에 대하여, 두 점으로부터의 거리의 비가 $k$로 일정한 점 $P$의 집합을 **아폴로니우스 원**이라 합니다. 즉, $\tfrac{|PA|}{|PB|} = k$를 만족하는 점 $P$의 자취를 의미합니다.

### 직관과 기하적 의미
이 원은 두 정점 사이에서 특정한 비율을 유지하며 균형을 이루는 점들이 그리는 궤적입니다. 예를 들어 $k=2$라면, 점 $P$는 항상 점 $A$보다 점 $B$에 훨씬 가까이 있어야 합니다. 이러한 조건을 만족하며 점을 이동시키다 보면 자연스럽게 원의 형태가 나타납니다. 만약 $k=1$이라면 두 점으로부터의 거리가 같아야 하므로 자취는 원이 아닌 두 점의 수직이등분선(직선)이 됩니다.

### 기본 성질
두 점 $A(0, 0)$, $B(3, 0)$이고 $k = 2$인 경우를 예로 들어보겠습니다. 점 $P(x, y)$에 대하여 $\sqrt{x^2 + y^2} = 2\sqrt{(x-3)^2 + y^2}$이 성립해야 합니다. 양변을 제곱하여 정리하면 $x^2 + y^2 = 4(x^2 - 6x + 9 + y^2)$이 되고, 이를 전개하면 $3x^2 + 3y^2 - 24x + 36 = 0$이 됩니다. 양변을 $3$으로 나누어 표준형으로 고치면 $(x-4)^2 + y^2 = 4$가 되어, 중심이 $(4, 0)$이고 반지름이 $2$인 원이 도출됩니다. 이처럼 거리의 비 조건은 대수적으로 이차방정식을 유도하여 원의 방정식을 결정합니다.

## 학습 체크
- $k=1$일 때 자취가 원이 아닌 직선이 되는 이유를 기하학적으로 설명할 수 있는가?
- 두 점의 좌표와 거리의 비가 주어졌을 때, 원의 중심과 반지름을 구할 수 있는가?

## 관련 개념
- **평면벡터**: 벡터의 크기 비를 이용하여 점 $P$의 위치를 벡터의 선형 결합으로 표현하고 자취를 구할 수 있습니다.
