# 거리와 비율

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
좌표평면 위 두 점 사이의 거리는 피타고라스 정리를 통해 계산하며, 선분의 내분과 외분은 거리의 비를 이용한 가중 평균의 원리로 정의됩니다.

## 본문
좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음과 같이 정의됩니다.
$$AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
선분 $AB$를 $m : n$으로 내분하는 점 $P$는 선분 위의 점으로서 $AP : PB = m : n$을 만족하며, 그 좌표는 다음과 같습니다.
$$P = \left( \frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n} \right)$$
이는 거리의 비가 곧 $m : n$임을 의미하며, 선분을 선분 밖의 연장선상에서 나누는 외분점 $Q$ 또한 동일한 원리로 정의됩니다.

### 직관과 기하적 의미
좌표평면에서의 거리는 피타고라스 정리에 기반합니다. 두 점을 잇는 선분을 직각삼각형의 빗변으로 간주하면, 가로와 세로의 길이는 각각 $|x_2 - x_1|$과 $|y_2 - y_1|$이 되어 거리 공식이 유도됩니다. 비율의 관점에서 내분점은 선분 내부에 위치하며, 외분점은 선분의 연장선 위에 위치합니다. 이때 내분점 공식의 구조는 각 점의 좌표에 비율에 따른 가중치를 부여하여 계산하는 가중 평균의 원리와 같습니다.

### 기본 성질
- 두 점 사이의 거리는 두 점의 좌표 차이의 제곱 합의 제곱근으로 나타납니다.
- 내분점은 선분 내부의 점이며, 외분점은 선분의 연장선상에 있는 점입니다.
- 내분점 공식의 분모 $m + n$은 두 비율의 합을 나타냅니다.

## 학습 체크
- 두 점 사이의 거리 공식이 피타고라스 정리와 어떻게 연결되는지 설명할 수 있는가?
- 내분점과 외분점의 위치 관계를 선분 위와 연장선 위로 구분하여 설명할 수 있는가?
- 내분점 공식이 왜 가중 평균의 형태를 띠는지 이해하고 있는가?

## 관련 개념
- **함수와 그래프**: 좌표평면 위의 점들의 집합을 통해 함수의 그래프를 시각화하며, 이때 점 사이의 거리는 그래프 상의 두 점 사이의 간격을 측정하는 기준이 됩니다.
