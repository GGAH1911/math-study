# 좌표기하

## 정의

**좌표기하**는 평면 위의 점을 실수 쌍 $(x, y)$로 나타내고, 기하학적 도형을 방정식으로 표현하여 대수적 방법으로 분석하는 수학의 분야입니다. 한국 교육과정에서는 주로 **이차곡선(원, 타원, 포물선, 쌍곡선)을 좌표평면에서 다루는 단원**을 지칭합니다.

## 기하적 의미

좌표기하의 핵심은 **기하 객체와 방정식의 일대일 대응**입니다. 예를 들어 원의 중심이 $(a, b)$이고 반지름이 $r$인 원은 정확히 방정식 $$(x-a)^2 + (y-b)^2 = r^2$$을 만족하는 점들의 집합입니다. 이렇게 하면 기하 도형의 성질을 **방정식 풀이와 함수 분석**으로 다룰 수 있습니다.

특히 이차곡선들은 다음과 같이 표현됩니다:
- **타원**: $\displaystyle\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b > 0$)
- **포물선**: $y^2 = 4px$ (초점 $(p, 0)$, 준선 $x = -p$)
- **쌍곡선**: $\displaystyle\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$

이들은 **초점**이라는 특수한 점과 **준선**이라는 특수한 직선으로 정의되며, 각 곡선 위의 점들이 이 기하학적 성질을 만족합니다.

## 예

원 $x^2 + y^2 = 25$ (중심 원점, 반지름 5)와 직선 $y = x + 1$이 만나는 점을 구합니다. $y = x + 1$을 원의 방정식에 대입하면:
$$x^2 + (x+1)^2 = 25 \implies 2x^2 + 2x - 24 = 0 \implies x^2 + x - 12 = 0$$
따라서 $x = 3$ 또는 $x = -4$이고, 교점은 $(3, 4)$와 $(-4, -3)$입니다. (`sympy.solve(x**2 + x - 12, x)` → `[-4, 3]`)
