# 최대·최소

## 정확한 진술

함수 $f(x)$가 정의역에서 가질 수 있는 함수값들 중 가장 큰 값을 **최댓값(maximum)**이라 하고, 가장 작은 값을 **최솟값(minimum)**이라고 합니다. 

폐구간 $[a, b]$에서 연속인 함수 $f(x)$는 반드시 최댓값과 최솟값을 가지며, 이들은 다음 중 하나의 위치에서 나타납니다:
- 도함수가 0이 되는 점 (극값점)
- 구간의 끝점 ($x=a$ 또는 $x=b$)

## 직관과 기하적 의미

**그래프에서의 의미**: 최댓값은 정의역 내에서 함수 그래프의 가장 높은 점이고, 최솟값은 가장 낮은 점입니다. 마치 산의 꼭대기(최댓값)와 골짜기(최솟값)를 찾는 것처럼 생각할 수 있습니다.

**제약 조건이 있을 때**: 도형의 방정식으로 주어진 영역(예: 원 위, 직선 위)에서 특정 값을 최대·최소화하는 문제가 나타납니다. 예를 들어 원 $x^2 + y^2 = 1$ 위의 점에서 거리 $d = x + y$의 최댓값·최솟값을 구할 때, 원이라는 제약 조건 하에서만 탐색합니다.

**극값정리**: 폐구간에서 연속인 함수는 항상 최댓값과 최솟값을 가진다는 것이 극값정리의 핵심입니다.

## 한 줄 예

$f(x) = -x^2 + 4x + 1$을 구간 $[0, 5]$에서 구하면, 극값점은 $f'(x) = -2x + 4 = 0$에서 $x = 2$이고, $f(2) = 5$, $f(0) = 1$, $f(5) = -4$이므로 최댓값은 $5$, 최솟값은 $-4$입니다.  
(`sympy.solve(sympy.diff(-x**2 + 4*x + 1, x), x)` → $x = 2$)
