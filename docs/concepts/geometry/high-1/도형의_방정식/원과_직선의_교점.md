### 정확한 진술

원 위의 점이면서 동시에 직선 위의 점인 모든 점들을 **원과 직선의 교점**이라고 합니다. 즉, 원의 방정식과 직선의 방정식을 **동시에 만족**하는 좌표 $(x, y)$를 모두 찾는 것입니다.

원의 방정식 $(x-a)^2 + (y-b)^2 = r^2$와 직선의 방정식 $y = mx + n$ (또는 $Ax + By + C = 0$)이 주어질 때, 교점의 좌표는 두 식을 연립하여 구합니다.

### 직관과 기하적 의미

평면 위에서 원과 직선은 다양한 방식으로 만날 수 있습니다:
- **서로 다른 두 점에서 만남** (직선이 원을 관통): 교점 2개
- **한 점에서 접함** (직선이 원에 접선): 교점 1개  
- **만나지 않음** (직선이 원 밖): 교점 0개

이 개수는 판별식(또는 중심에서 직선까지의 거리)으로 판정할 수 있습니다. 거리 $d$와 반지름 $r$을 비교하면: $d < r$ (2개), $d = r$ (1개), $d > r$ (0개)입니다.

### 한 줄 예

원 $x^2 + y^2 = 5$와 직선 $y = x + 1$을 연립하면 $x^2 + (x+1)^2 = 5$ → $2x^2 + 2x - 4 = 0$ → $x^2 + x - 2 = 0$ → $(x+2)(x-1) = 0$이므로 교점은 $(-2, -1)$과 $(1, 2)$입니다.

(검증: `sympy.solve([x**2 + y**2 - 5, y - x - 1], [x, y])` → `[(-2, -1), (1, 2)]`)
