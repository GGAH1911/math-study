# 점과 직선의 거리

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 정확한 진술

평면 위의 점 $P$에서 직선 $l$까지의 거리는 점 $P$에서 직선 $l$에 내린 수선의 발을 $H$라 할 때, 선분 $PH$의 길이입니다. 직선 $l$의 방정식이 $ax + by + c = 0$ (단, $a^2 + b^2 \neq 0$)이고 점 $P$의 좌표가 $(x_0, y_0)$일 때, 거리 $d$는 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

## 직관과 기하적 의미

점에서 직선까지의 거리는 "점과 직선 위의 모든 점 사이 거리의 최솟값"입니다. 직선 위의 여러 점들까지의 거리를 재어 보면, 수선의 발 $H$일 때만 최소입니다. 이는 수학적으로 당연한데, 직각삼각형에서 빗변보다 한 변이 더 짧기 때문입니다.

분모 $\sqrt{a^2 + b^2}$는 직선의 "법선 벡터" $(a, b)$의 크기이고, 분자 $|ax_0 + by_0 + c|$는 점 $P$를 법선 방향으로 투영한 값의 크기입니다. 절댓값이 붙는 이유는 거리는 항상 양수이기 때문입니다.

## 한 줄 예

점 $P(1, 2)$에서 직선 $3x - 4y + 5 = 0$까지의 거리는 $d = \frac{|3(1) - 4(2) + 5|}{\sqrt{3^2 + (-4)^2}} = \frac{|3 - 8 + 5|}{\sqrt{25}} = \frac{0}{5} = 0$이므로, 점 $P$는 실제로 직선 위에 있습니다. (검산: `sympy.symbols('x, y'); 3*1 - 4*2 + 5`)
