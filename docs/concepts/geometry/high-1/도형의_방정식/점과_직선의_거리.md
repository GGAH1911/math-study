# 점과 직선의 거리

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
점 $P$에서 직선 $l$에 내린 수선의 발을 $H$라 할 때, 선분 $PH$의 길이가 점과 직선 사이의 거리입니다.

## 본문
평면 위의 점 $P$에서 직선 $l$까지의 거리는 점 $P$에서 직선 $l$에 내린 수선의 발을 $H$라 할 때, 선분 $PH$의 길이입니다. 직선 $l$의 방정식이 $ax + by + c = 0$ (단, $a^2 + b^2 \neq 0$)이고 점 $P$의 좌표가 $(x_0, y_0)$일 때, 거리 $d$는 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미
점에서 직선까지의 거리는 점과 직선 위의 모든 점 사이 거리의 최솟값을 의미합니다. 직선 위의 여러 점들까지의 거리를 비교해 보면, 수선의 발 $H$에 위치할 때 거리가 최소가 됩니다. 이는 직각삼각형에서 빗변보다 한 변의 길이가 더 짧다는 기하학적 원리에 근거합니다. 공식의 분모 $\sqrt{a^2 + b^2}$는 직선의 법선 벡터 $(a, b)$의 크기를 나타내며, 분자 $|ax_0 + by_0 + c|$는 점 $P$를 법선 방향으로 투영한 값의 크기를 나타냅니다. 이때 거리는 항상 양수여야 하므로 분자에 절댓값이 붙습니다.

### 기본 성질
- 점 $P(1, 2)$에서 직선 $3x - 4y + 5 = 0$까지의 거리는 $d = \tfrac{|3(1) - 4(2) + 5|}{\sqrt{3^2 + (-4)^2}} = \tfrac{0}{5} = 0$입니다.
- 거리 $d=0$인 경우, 해당 점은 직선 위에 존재합니다.

## 학습 체크
- 점과 직선 사이의 거리를 구할 때 분모에 직선의 계수들의 제곱합의 제곱근이 들어가는 이유를 기하학적으로 설명할 수 있는가?
- 점의 좌표를 직선의 방정식에 대입했을 때 결과가 $0$이 된다면, 이 점과 직선의 관계는 무엇인가?

## 관련 개념
- **도형의 방정식**: 점과 직선 사이의 거리 공식은 평면 좌표 위에서 도형의 위치 관계를 파악하고 방정식의 해를 구하는 데 필수적인 도구로 사용됩니다.
