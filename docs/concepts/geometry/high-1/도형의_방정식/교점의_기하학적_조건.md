# 교점의 기하학적 조건

## 정확한 진술

두 곡선의 **교점**은 두 곡선의 방정식을 **동시에 만족하는 점**입니다. 곡선 $f(x, y) = 0$과 $g(x, y) = 0$이 있을 때, 교점의 좌표 $(x_0, y_0)$는 다음을 만족합니다:

$$f(x_0, y_0) = 0 \quad \text{and} \quad g(x_0, y_0) = 0$$

즉, 교점을 구하는 것은 이 연립방정식을 푸는 것과 같습니다.

## 직관/기하적 의미

평면 위에서 두 곡선이 **만나는 지점**이 교점입니다. 각 곡선은 어떤 조건을 만족하는 점들의 자취인데, 교점은 **두 조건을 동시에 만족하는 점**입니다. 예를 들어 직선과 원이 만나거나, 두 원이 만나거나, 포물선과 직선이 만나는 상황에서 그 만남의 위치를 나타냅니다. 교점의 개수는 두 곡선의 형태와 위치에 따라 0개, 1개, 2개 이상이 될 수 있습니다.

## 실제 예

직선 $y = 2x + 1$과 원 $x^2 + y^2 = 5$의 교점을 구해봅시다. 직선의 방정식을 원의 방정식에 대입하면:

$$x^2 + (2x+1)^2 = 5$$
$$x^2 + 4x^2 + 4x + 1 = 5$$
$$5x^2 + 4x - 4 = 0$$

근의 공식을 적용하면 $x = \frac{-4 \pm \sqrt{16 + 80}}{10} = \frac{-4 \pm \sqrt{96}}{10} = \frac{-2 \pm 2\sqrt{6}}{5}$

각 $x$ 값을 $y = 2x + 1$에 대입하여 교점의 좌표를 구할 수 있습니다.

(`sympy.solve([x**2 + y**2 - 5, y - 2*x - 1], [x, y])`)
