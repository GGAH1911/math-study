# 두 원의 교점

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 원의 방정식을 동시에 만족하는 점들의 집합으로, 두 원이 만나는 위치를 의미합니다.

## 본문
두 원의 교점이란 두 원의 방정식을 동시에 만족하는 점들의 집합입니다. 원 $C_1: (x-a)^2 + (y-b)^2 = r_1^2$과 원 $C_2: (x-c)^2 + (y-d)^2 = r_2^2$이 주어졌을 때, 교점 $(x_0, y_0)$은 다음의 연립방정식을 모두 만족하는 점입니다:
$$\begin{cases} (x_0-a)^2 + (y_0-b)^2 = r_1^2 \\ (x_0-c)^2 + (y_0-d)^2 = r_2^2 \end{cases}$$

### 직관과 기하적 의미
두 원이 평면에서 만나는 상황을 시각화하면, 두 원의 위치 관계에 따라 교점의 개수는 0개, 1개(접하는 경우), 또는 2개가 될 수 있습니다. 교점을 구하는 일반적인 방법은 두 원의 방정식에서 이차항을 소거하기 위해 한 방정식에서 다른 방정식을 빼는 것입니다. 예를 들어 $C_1 - C_2 = 0$을 계산하면 다음과 같은 식을 얻습니다:
$$(x-a)^2 + (y-b)^2 - (x-c)^2 - (y-d)^2 = r_1^2 - r_2^2$$
이 식을 정리하면 직선의 방정식이 나타나는데, 이를 **근축**이라고 부릅니다. 이 직선은 두 원의 교점을 지나는 직선이며, 이 직선과 원의 교점을 찾는 것이 곧 두 원의 교점을 구하는 과정입니다.

### 기본 성질
- 두 원의 교점이 2개인 경우, 두 원을 뺀 식에서 얻은 직선은 두 교점을 지나는 공통현을 나타냅니다.
- 두 원이 한 점에서 만나는 경우(접하는 경우), 두 원의 방정식을 뺀 식에서 얻은 직선은 두 원의 공통접선이 됩니다.
- 원 $(x-1)^2 + (y-2)^2 = 4$와 $(x-3)^2 + (y-2)^2 = 4$의 교점을 구하기 위해 두 식을 빼면 $-4x + 8 = 0$, 즉 $x = 2$를 얻습니다. 이를 첫 번째 원에 대입하면 $(y-2)^2 = 3$이 되어, 교점은 $(2, 2+\sqrt{3})$과 $(2, 2-\sqrt{3})$이 됩니다.

## 학습 체크
- 두 원의 방정식을 뺐을 때 나타나는 직선의 방정식이 무엇을 의미하는지 설명할 수 있는가?
- 두 원의 위치 관계(교점의 개수)에 따라 교점의 개수가 어떻게 변하는지 이해하고 있는가?

## 관련 개념
- **원의 성질**: 원의 방정식과 반지름의 정의를 정확히 알아야 두 원의 위치 관계와 교점의 존재 여부를 판단할 수 있습니다.
