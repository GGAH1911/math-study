# 두 원의 교점

## 정확한 진술

두 원의 교점이란 두 원의 방정식을 동시에 만족하는 점들의 집합입니다. 원 $C_1: (x-a)^2 + (y-b)^2 = r_1^2$과 원 $C_2: (x-c)^2 + (y-d)^2 = r_2^2$이 주어졌을 때, 교점 $(x_0, y_0)$은 다음을 모두 만족합니다:

$$\begin{cases} (x_0-a)^2 + (y_0-b)^2 = r_1^2 \\ (x_0-c)^2 + (y_0-d)^2 = r_2^2 \end{cases}$$

## 직관 및 기하적 의미

두 원이 평면에서 만나는 상황을 생각해봅시다. 두 원이 만난다면 교점은 0개, 1개(접함), 또는 2개가 됩니다. 

교점을 구하려면 두 원의 방정식을 연립하되, 보통 **하나의 방정식에서 다른 방정식을 빼서** 이차항을 소거합니다. 예를 들어 $C_1 - C_2 = 0$을 계산하면:

$$(x-a)^2 + (y-b)^2 - (x-c)^2 - (y-d)^2 = r_1^2 - r_2^2$$

이를 정리하면 **직선(근축, radical axis)의 방정식**이 나옵니다. 이 직선이 원과 만나는 점이 바로 두 원의 교점입니다.

## 한 줄 예

원 $(x-1)^2 + (y-2)^2 = 4$와 $(x-3)^2 + (y-2)^2 = 4$의 교점을 구하려면, 두 식을 빼서 $-4x + 8 = 0$, 즉 $x = 2$를 얻습니다. 이를 첫 번째 원에 대입하면 $(2-1)^2 + (y-2)^2 = 4$에서 $(y-2)^2 = 3$, $y = 2 \pm \sqrt{3}$이므로 교점은 $(2, 2+\sqrt{3})$과 $(2, 2-\sqrt{3})$입니다. (`sympy.solve([(x-1)**2 + (y-2)**2 - 4, (x-3)**2 + (y-2)**2 - 4], [x, y])`)
