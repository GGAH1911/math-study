# 두 직선의 수직 조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 직선의 기울기의 곱이 $-1$이거나, 일반형 계수의 곱의 합이 $0$이면 두 직선은 서로 수직입니다.

## 본문
두 직선이 서로 수직일 필요충분조건은 두 직선의 기울기를 각각 $m_1, m_2$라고 할 때 $m_1 \cdot m_2 = -1$이 성립하는 것입니다. 다만, 이는 두 직선의 기울기가 모두 존재할 때를 전제로 하며, 한 직선이 수평선($y=c$)이고 다른 직선이 수직선($x=d$)인 특수한 경우에도 두 직선은 수직입니다. 또한 일반형 $a_1x + b_1y + c_1 = 0$과 $a_2x + b_2y + c_2 = 0$으로 주어진 두 직선의 경우에는 계수들 사이의 관계식인 $a_1a_2 + b_1b_2 = 0$이 성립할 때 두 직선은 수직입니다.

### 직관과 기하적 의미
기울기가 $\tan(\theta)$인 직선을 $90^\circ$ 회전시키면 새로운 기울기는 $\tan(\theta + 90^\circ) = -\cot(\theta) = -\frac{1}{\tan(\theta)}$가 됩니다. 따라서 두 기울기를 곱하면 $\tan(\theta) \cdot \left(-\frac{1}{\tan(\theta)}\right) = -1$이 되어 수직 조건이 도출됩니다. 벡터 관점에서는 두 직선의 방향벡터가 이루는 각이 $90^\circ$이므로, 두 방향벡터의 내적이 $0$이 되는 조건과 일치합니다.

### 기본 성질
- 기울기가 존재하는 두 직선의 경우: $m_1 \cdot m_2 = -1$
- 일반형 방정식의 계수를 이용할 경우: $a_1a_2 + b_1b_2 = 0$
- 수평선($y=c$)과 수직선($x=d$)은 서로 수직임

## 학습 체크
- 두 직선 중 하나가 $x$축 또는 $y$축에 평행하여 기울기를 정의할 수 없는 경우 어떻게 처리해야 하는가?
- 일반형 방정식에서 계수 $a, b$를 이용해 수직 조건을 구할 때 왜 내적의 원리가 적용되는가?
- 기울기의 곱이 $-1$이라는 조건이 왜 회전 변환과 연결되는가?

## 관련 개념
- **이차곡선**: 타원, 쌍곡선, 포물선과 같은 이차곡선에서 접선이나 축의 기울기를 구할 때 이 수직 조건을 활용하여 문제를 해결할 수 있습니다.
