# 평행이동

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
도형 위의 모든 점을 일정한 방향과 거리만큼 옮기는 것으로, 도형의 모양과 크기는 유지된 채 위치만 변하는 이동입니다.

## 본문
점 $(x, y)$를 $x$축 방향으로 $a$만큼, $y$축 방향으로 $b$만큼 평행이동하면 이동 후의 점은 $(x+a, y+b)$가 됩니다. 도형의 평행이동은 도형을 구성하는 모든 점을 동시에 같은 방향과 같은 거리만큼 옮기는 것을 의미합니다. 이때 도형의 방정식 $f(x, y) = 0$을 $x$축 방향으로 $a$만큼, $y$축 방향으로 $b$만큼 평행이동하면, 새로운 도형의 방정식은 $f(x-a, y-b) = 0$이 됩니다. 이는 새로운 좌표 $(x, y)$를 원래의 좌표로 되돌리기 위해 $a$와 $b$를 각각 빼주는 원리를 이용한 것입니다.

### 직관과 기하적 의미
평행이동은 도형의 크기나 모양을 전혀 바꾸지 않고, 단지 공간상에서 도형 전체를 밀어내는 것과 같습니다. 예를 들어 원을 평행이동하면 여전히 같은 크기의 원이 되고, 직선을 평행이동하면 여전히 같은 기울기를 가진 직선이 됩니다. 즉, 도형의 형태적 특징은 보존된 채 위치 정보만 변화합니다.

### 기본 성질
평행이동을 하면 도형의 모양과 크기는 변하지 않습니다. 또한, 방정식의 변수를 치환할 때 이동 방향의 반대 부호를 대입해야 한다는 점이 핵심입니다. 예를 들어 원 $x^2 + y^2 = 4$를 $x$축 방향으로 $3$, $y$축 방향으로 $2$만큼 이동하면 중심이 $(0, 0)$에서 $(3, 2)$로 이동하며, 방정식은 $(x-3)^2 + (y-2)^2 = 4$가 됩니다.

## 학습 체크
- 점의 이동과 도형의 방정식 이동 시 부호가 왜 반대로 적용되는지 설명할 수 있는가?
- 도형을 평행이동했을 때 모양과 크기가 변하지 않음을 이해하고 있는가?

## 관련 개념
- **도형의 방정식**: 평행이동을 통해 함수의 그래프나 원, 직선과 같은 도형을 좌표평면 위에서 이동시켜 새로운 방정식을 유도할 수 있습니다.
