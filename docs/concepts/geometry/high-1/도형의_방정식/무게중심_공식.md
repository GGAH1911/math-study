# 무게중심 공식

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
$n$개의 점이 주어졌을 때 각 좌표 성분의 산술평균을 구하여 구하는 대표점입니다.

## 본문
평면이나 공간에서 $n$개의 점 $P_1(x_1, y_1, \ldots)$, $P_2(x_2, y_2, \ldots)$, $\ldots$, $P_n(x_n, y_n, \ldots)$이 주어졌을 때, 이 점들의 무게중심은 다음 좌표를 갖는 점 $G$입니다.
$$G = \left( \frac{x_1 + x_2 + \cdots + x_n}{n}, \frac{y_1 + y_2 + \cdots + y_n}{n}, \cdots \right)$$
즉, 각 좌표 성분의 산술평균을 구함으로써 무게중심의 좌표를 결정할 수 있습니다.

### 직관과 기하적 의미
무게중심은 여러 점들이 한 점에 집중된 것처럼 행동하는 대표점입니다. 물리적으로는 균등하게 분포된 질량의 무게 중심을 의미하며, 기하학적으로는 도형을 가장 잘 대표하는 중심 역할을 합니다.

### 기본 성질
삼각형의 경우, 세 꼭짓점을 잇는 중선 세 개가 만나는 교점이 무게중심이며, 이 점은 각 중선을 $2:1$로 내분합니다. 사면체의 경우, 네 꼭짓점에서 대면의 무게중심을 잇는 네 개의 선분이 무게중심에서 만나며, 이 점은 각 선분을 $3:1$로 내분합니다.

## 학습 체크
- $n$개의 점이 주어졌을 때 각 좌표의 평균을 구하는 과정을 정확히 이해하고 있는가?
- 삼각형의 무게중심이 중선을 $2:1$로 내분한다는 성질을 좌표로 증명할 수 있는가?
- 차원이 확장되어 사면체가 되었을 때 내분비가 어떻게 변화하는지 파악하고 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간상의 점들의 좌표를 벡터의 합과 성분으로 표현하여 무게중심의 위치를 벡터로 나타낼 수 있습니다.
