# 무게중심 공식

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 정확한 진술

평면이나 공간에서 $n$개의 점 $P_1(x_1, y_1, \ldots)$, $P_2(x_2, y_2, \ldots)$, $\ldots$, $P_n(x_n, y_n, \ldots)$이 주어졌을 때, 이 점들의 **무게중심**(centroid, 또는 무게중심)은 다음 좌표를 갖는 점 $G$입니다.

$$G = \left( \frac{x_1 + x_2 + \cdots + x_n}{n}, \frac{y_1 + y_2 + \cdots + y_n}{n}, \cdots \right)$$

즉, 각 좌표 성분의 산술평균입니다.

## 직관/기하적 의미

무게중심은 여러 점들이 "한 점에 집중된 것처럼" 행동하는 대표점입니다. 물리적으로는 균등하게 분포된 질량의 무게 중심이고, 기하학적으로는 도형을 가장 잘 대표하는 중심입니다.

**삼각형의 경우**: 세 꼭짓점을 잇는 중선(꼭짓점과 대변의 중점을 잇는 선분) 세 개는 항상 한 점에서 만나는데, 이 교점이 바로 무게중심입니다. 무게중심은 각 중선을 $2:1$로 내분합니다.

**사면체의 경우**: 네 꼭짓점에서 대면의 무게중심을 잇는 네 개의 선분도 무게중심에서 만나며, $3:1$로 내분됩니다.

## 한 줄 예

삼각형의 꼭짓점이 $A(0, 0)$, $B(6, 0)$, $C(0, 6)$일 때, 무게중심은 $G(2, 2)$입니다. 

(검산: $\frac{0+6+0}{3} = 2$, $\frac{0+0+6}{3} = 2$ ✓)
