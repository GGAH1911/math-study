# 기울기와 각도

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
직선의 기울기 $m$은 직선이 $x$축의 양의 방향과 이루는 각 $\theta$의 탄젠트 값인 $m = \tan(\theta)$로 정의됩니다.

## 본문
직선이 $x$축의 양의 방향과 이루는 각을 $\theta$ ($0° \leq \theta < 180°$)라 할 때, 그 직선의 기울기 $m$은 $m = \tan(\theta)$를 만족합니다. 이때 각 $\theta$는 직선을 $x$축의 양의 방향에서 반시계 방향으로 회전시켜 일치시키는 각을 의미하며, 이를 기울기각 또는 경사각이라고 부릅니다.

### 직관과 기하적 의미
기울기는 직선을 따라 오른쪽으로 한 칸 이동할 때 수직 방향으로 얼마나 변화하는지를 나타내는 척도이며, 이는 기하학적으로 각도 $\theta$의 탄젠트 값과 일치합니다. 기울기의 부호에 따라 직선의 방향을 알 수 있는데, 기울기가 양수이면 $0° < \theta < 90°$ 범위에서 직선이 우상향하고, 기울기가 음수이면 $90° < \theta < 180°$ 범위에서 직선이 우하향합니다. 만약 직선이 $x$축과 평행한 수평선이라면 $\theta = 0°$이고 기울기 $m = 0$이며, $y$축과 평행한 연직선은 $\theta = 90°$가 되어 기울기를 정의할 수 없습니다.

### 기본 성질
- 기울기가 $m = 1$인 직선의 기울기각은 $\theta = 45°$입니다.
- 기울기가 $m = \sqrt{3}$인 직선의 기울기각은 $\theta = 60°$입니다.
- 기울기가 양수이면 직선은 오른쪽 위로 향하고, 음수이면 오른쪽 아래로 향합니다.

## 학습 체크
- 기울기가 음수인 직선의 기울기각 $\theta$의 범위는 어떻게 되는가?
- 기울기가 정의되지 않는 연직선의 각도는 몇 도인가?
- 기울기 $m$과 각도 $\theta$ 사이의 관계식을 쓰시오.

## 관련 개념
- **도함수의 활용 심화**: 곡선 위의 한 점에서 접선의 기울기를 알면, 그 접선이 $x$축과 이루는 각을 $\theta = \arctan(f'(x))$를 이용하여 즉시 구할 수 있습니다.
