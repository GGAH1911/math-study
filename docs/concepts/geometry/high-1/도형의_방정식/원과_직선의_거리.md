# 원과 직선의 거리

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
원의 중심에서 직선까지의 최단 거리를 이용하여 원과 직선의 위치 관계를 판정하는 개념입니다.

## 본문
원의 중심을 $C(x_0, y_0)$, 반지름을 $r$이라 할 때, 직선 $ax + by + c = 0$까지의 거리를 **원과 직선의 거리**라 정의합니다. 이 거리는 원의 중심에서 직선까지의 최단 거리이며, 다음 공식으로 구합니다:
$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미
기하학적으로 원과 직선의 거리는 원의 중심에서 직선에 내린 수선의 발까지의 거리입니다. 이 거리 $d$와 반지름 $r$을 비교하면 원과 직선의 위치 관계를 판정할 수 있습니다. $d > r$이면 직선이 원과 만나지 않으며, $d = r$이면 직선이 원에 접하여 한 점에서 만납니다. $d < r$이면 직선이 원의 내부를 지나며 두 점에서 만나게 됩니다.

### 기본 성질
원의 중심에서 직선까지의 최단 거리는 항상 수선의 길이이므로, 이 거리는 원과 직선의 위치를 결정하는 핵심적인 기준이 됩니다. 예를 들어 원 $(x-1)^2 + (y-2)^2 = 4$ (중심 $(1,2)$, 반지름 $2$)와 직선 $x + 2y - 5 = 0$ 사이의 거리를 구하면 $d = \frac{|1 + 2(2) - 5|}{\sqrt{1^2 + 2^2}} = 0$입니다. 이때 $d < r$이므로 직선은 원의 중심을 지나며 두 점에서 만납니다.

## 학습 체크
- 원의 중심 좌표와 직선의 방정식을 이용하여 점과 직선 사이의 거리 공식을 정확히 적용할 수 있는가?
- 구한 거리 $d$와 반지름 $r$의 크기를 비교하여 직선과 원의 위치 관계를 논리적으로 설명할 수 있는가?

## 관련 개념
- **점과 직선 사이의 거리**: 원의 중심이라는 한 점과 직선 사이의 거리를 구하는 원리가 동일하게 적용됩니다.
- **원의 방정식**: 원의 중심과 반지름의 정보를 통해 직선과의 위치 관계를 판정하는 기초가 됩니다.
