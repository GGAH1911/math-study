# 중점공식

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 점의 좌표를 각각 평균 내어 선분의 정확한 중간 위치를 찾는 공식입니다.

## 본문
좌표평면에서 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 잇는 선분의 중점 $M$의 좌표는 다음과 같습니다.
$$M\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$$
중점의 $x$좌표는 두 점의 $x$좌표의 평균값이며, $y$좌표는 두 점의 $y$좌표의 평균값입니다.

### 직관과 기하적 의미
중점공식은 두 점 사이의 정확한 중간 지점을 찾는 방법입니다. 점 $A$에서 점 $B$로 이동할 때 전체 거리의 절반만큼 이동한 위치가 중점이 됩니다. 기하학적으로는 선분 $AB$를 $1:1$의 비율로 내분하는 점을 의미합니다. 좌표의 각 성분을 독립적으로 평균내는 이유는 $x$축 방향과 $y$축 방향의 변화가 서로 영향을 주지 않기 때문입니다.

### 기본 성질
- 중점의 좌표는 항상 두 점 사이에 위치하는 내분점의 성질을 가집니다.
- 내분점 공식에서 비율이 $1:1$인 특수한 경우에 해당합니다.
- 3차원 공간에서도 동일한 원리가 적용되어 $z$좌표까지 평균을 내어 구합니다.

## 학습 체크
- 두 점 $A(2, 4)$와 $B(8, 10)$의 중점을 구했을 때, 각 점으로부터의 거리가 동일한지 확인해 보세요.
- 중점 공식이 내분점 공식의 특수한 형태임을 이해하고 있는지 점검해 보세요.

## 관련 개념
- **내분점**: 선분을 특정 비율로 나누는 점을 구하는 일반적인 공식이며, 중점은 그 비율이 $1:1$인 경우입니다.
- **함수와 그래프**: 좌표평면 위에서 두 점의 중간 위치를 찾는 과정은 함수의 그래프 위에서 두 점의 평균적인 위치를 파악하는 기초가 됩니다.
