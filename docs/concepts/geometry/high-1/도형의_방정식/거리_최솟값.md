# 거리 최솟값

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 정확한 진술

두 기하학적 대상(점, 직선, 원, 곡선 등) 사이의 **거리 최솟값**은 한 대상의 모든 점과 다른 대상의 모든 점 사이의 거리 중 가장 작은 값입니다. 특히 고등학교에서는 점과 직선, 점과 원, 또는 두 도형 사이의 거리 최솟값을 다룹니다.

점 $P(x_0, y_0)$에서 직선 $ax + by + c = 0$까지의 거리는 다음 공식으로 주어집니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

이것이 점과 직선 사이의 거리 최솟값입니다.

## 기하적 의미

점 $P$에서 직선에 그은 수선의 발을 $H$라 하면, $\overline{PH}$의 길이가 거리 최솟값입니다. 직선 위의 다른 모든 점과의 거리는 이보다 더 깁니다. 

원의 중심 $C$와 반지름 $r$이 주어질 때, 점 $P$에서 원까지의 거리 최솟값은:
- $P$가 원 밖이면: $\overline{CP} - r$ 
- $P$가 원 위 또는 안이면: $0$

직선이 두 도형을 구분할 때, 거리 최솟값은 수직 거리로 나타나므로 **최적화 문제**의 핵심 도구입니다.

## 예

점 $P(2, 1)$에서 직선 $3x - 4y + 5 = 0$까지의 거리:

$$d = \frac{|3(2) - 4(1) + 5|}{\sqrt{9 + 16}} = \frac{|6 - 4 + 5|}{5} = \frac{7}{5}$$
