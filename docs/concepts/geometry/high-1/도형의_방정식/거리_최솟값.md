# 거리 최솟값

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 기하학적 대상 사이의 거리 최솟값은 각 대상에 포함된 모든 점들 사이의 거리 중 가장 작은 값을 의미하며, 주로 수직 거리나 중심으로부터의 거리 차이로 계산됩니다.

## 본문
두 기하학적 대상(점, 직선, 원, 곡선 등) 사이의 거리 최솟값은 한 대상의 모든 점과 다른 대상의 모든 점 사이의 거리 중 가장 작은 값을 의미합니다. 고등학교 과정에서는 주로 점과 직선, 점과 원, 또는 두 도형 사이의 거리 최솟값을 다룹니다. 점 $P(x_0, y_0)$에서 직선 $ax + by + c = 0$까지의 거리 최솟값은 다음과 같은 공식으로 구할 수 있습니다.
$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미
점 $P$에서 직선에 내린 수선의 발을 $H$라고 할 때, 선분 $\overline{PH}$의 길이가 곧 거리의 최솟값이 됩니다. 직선 위의 다른 어떤 점을 선택하더라도 점 $P$와의 거리는 $\overline{PH}$보다 길어지게 됩니다. 원의 경우, 원의 중심 $C$와 반지름 $r$이 주어졌을 때 점 $P$가 원 밖에 있다면 중심으로부터의 거리에서 반지름을 뺀 $\overline{CP} - r$이 최솟값이 되며, 점 $P$가 원 위에 있거나 원 내부에 있다면 최솟값은 $0$이 됩니다.

### 기본 성질
거리 최솟값은 도형이 서로 만날 수 있는지를 판단하거나, 특정 조건에서 최적의 위치를 찾는 최적화 문제의 핵심적인 도구로 활용됩니다. 직선이 두 도형을 구분하는 위치에 있을 때, 두 도형 사이의 최솟값은 항상 수직 방향의 거리로 나타납니다.

예를 들어, 점 $P(2, 1)$에서 직선 $3x - 4y + 5 = 0$까지의 거리를 구하면 다음과 같습니다.
$$d = \frac{|3(2) - 4(1) + 5|}{\sqrt{3^2 + (-4)^2}} = \frac{|6 - 4 + 5|}{5} = \frac{7}{5}$$

## 학습 체크
- 점과 직선 사이의 거리 공식에서 분모의 $\sqrt{a^2 + b^2}$이 갖는 의미는 무엇인가?
- 점이 원 내부에 있을 때 원까지의 거리 최솟값이 $0$이 되는 이유는 무엇인가?
- 두 곡선 사이의 거리 최솟값을 구할 때 수직인 방향을 고려해야 하는 이유는 무엇인가?

## 관련 개념
- **도형의 방정식**: 평면 위의 점들의 집합을 방정식으로 나타냄으로써, 두 도형 사이의 거리를 대수적으로 계산할 수 있는 토대를 제공합니다.
