# 점-기울기 형식

좌표평면에서 한 점과 기울기로부터 직선의 방정식을 바로 쓰는 표준 형식입니다. 고1 도형의 방정식 단원에서 직선 식 작성의 출발점입니다.

## 정의

좌표평면 위의 점 $(x_1, y_1)$을 지나고 기울기가 $m$인 직선의 방정식은
$$y - y_1 = m(x - x_1).$$
이를 정리하면 일반형 $y = mx + b$ ($b = y_1 - m x_1$) 또는 $mx - y + (y_1 - m x_1) = 0$이 됩니다.

기울기가 정의되지 않는 수직선의 경우는 별도로 $x = x_1$로 씁니다. 두 점 $(x_1, y_1), (x_2, y_2)$가 주어지면 먼저 $m = \dfrac{y_2 - y_1}{x_2 - x_1}$를 구한 후 점-기울기 형식을 적용합니다.

## 예시

점 $(2, -1)$을 지나고 기울기가 $3$인 직선을 구해 봅니다.
$$y - (-1) = 3(x - 2) \implies y = 3x - 7.$$

또한 두 점 $\mathrm{A}(1, 2), \mathrm{B}(4, 8)$을 지나는 직선은 기울기 $m = \dfrac{8 - 2}{4 - 1} = 2$이고 점-기울기 형식으로 $y - 2 = 2(x - 1)$, 즉 $y = 2x$.
