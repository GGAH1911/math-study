# 두 직선의 관계

> **정리** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 직선의 기울기 관계를 통해 평행과 수직 조건을 판정할 수 있다.

## 본문
두 직선 $l_1: y = m_1 x + n_1$과 $l_2: y = m_2 x + n_2$가 수직선이 아닐 때, 두 직선이 평행할 조건은 기울기가 같은 $m_1 = m_2$이며, 서로 수직일 조건은 기울기의 곱이 $-1$인 $m_1 \cdot m_2 = -1$이다. 일반형 방정식 $a_1 x + b_1 y + c_1 = 0$과 $a_2 x + b_2 y + c_2 = 0$의 관점에서 평행 조건은 계수의 비 $\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} \neq \tfrac{c_1}{c_2}$로 나타낼 수 있다.

### 증명 스케치
기울기가 같으면 두 직선은 같은 방향을 유지하며 만나지 않으므로 평행하다. 수직 조건은 방향 벡터를 통해 유도할 수 있는데, 각 직선의 방향 벡터를 $(1, m_1)$과 $(1, m_2)$라고 할 때, 두 직선이 수직이면 두 벡터의 내적이 $0$이어야 하므로 $1 + m_1 m_2 = 0$, 즉 $m_1 m_2 = -1$이 성립한다. 일반형에서의 평행 조건은 두 직선의 법선 벡터 $(a_1, b_1)$과 $(a_2, b_2)$가 서로 평행하다는 성질을 계수의 비로 표현한 것이다.

### 의의와 응용
이 정리는 특정 점을 지나면서 주어진 직선과 평행하거나 수직인 직선의 방정식을 구하는 문제의 기초가 된다. 예를 들어 점 $(1, 2)$를 지나고 $2x - 3y + 5 = 0$과 평행한 직선은 계수의 비를 유지한 채 $2x - 3y + 4 = 0$과 같이 구할 수 있다. 이는 원과 직선의 위치 관계나 삼각형의 수선 구하기 등 다양한 도형 문제 해결에 필수적으로 활용된다.

## 학습 체크
- 기울기가 주어진 두 직선이 평행하거나 수직인지 판정할 수 있는가?
- 일반형 방정식의 계수 비를 이용하여 평행한 직선의 방정식을 구할 수 있는가?
- 수직인 두 직선의 기울기 곱이 $-1$임을 이용하여 미지수를 찾을 수 있는가?

## 관련 개념
- **도형의 방정식**: 직선의 방정식을 구하는 과정에서 평행과 수직 조건이 핵심적인 도구로 사용된다.
