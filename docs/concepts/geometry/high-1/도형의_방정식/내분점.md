# 내분점

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
선분 위의 한 점으로서 선분을 주어진 비로 나누는 지점을 의미합니다.

## 본문
선분 $AB$를 $m : n$으로 내분하는 점 $P$는 선분 위에 있으면서 $\overline{AP} : \overline{PB} = m : n$을 만족하는 점입니다. 점 $A(x_1, y_1)$과 $B(x_2, y_2)$일 때, 내분점 $P$의 좌표는 다음과 같습니다.
$$P = \left( \frac{mx_2 + nx_1}{m+n}, \frac{my_2 + ny_1}{m+n} \right)$$

### 직관과 기하적 의미
내분점은 선분을 일정한 비율로 분할하는 지점입니다. 비 $m : n$에서 $m$의 값이 커질수록 점 $P$는 점 $B$에 가까워지며, 반대로 $n$의 값이 커질수록 점 $P$는 점 $A$에 가까워집니다. 공식의 구조를 살펴보면 $B$의 좌표에는 $m$이, $A$의 좌표에는 $n$이 곱해지는데, 이는 반대편 구간의 길이를 가중치로 활용하여 가중평균을 구하는 원리와 같습니다. 특히 $m = n$인 경우의 내분점은 선분의 중점이 되며, 이는 두 점 좌표의 산술평균과 같습니다.

### 기본 성질
- $m : n$의 비율이 커질수록 내분점은 상대방 점에 가까워집니다.
- $m = n$일 때 내분점은 선분의 중점이 됩니다.
- 내분점은 항상 선분 $AB$ 위에 존재합니다.

## 학습 체크
- 내분점 공식에서 $m$과 $n$이 각각 어떤 좌표에 곱해지는지 혼동하지 않았나요?
- $m=n$인 특수한 경우인 중점 좌표를 구할 때 산술평균 공식을 바로 적용할 수 있나요?
- 내분점의 위치가 $A$에 가까운지 $B$에 가까운지 비율을 통해 판단할 수 있나요?

## 관련 개념
- **함수와 그래프**: 내분점의 좌표를 변수로 하는 함수를 정의하거나, 그래프 상의 두 점 사이의 특정 지점을 좌표로 나타낼 때 활용됩니다.
