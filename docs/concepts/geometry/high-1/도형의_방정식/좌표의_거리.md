# 좌표의 거리

## 정확한 진술

좌표평면에서 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음과 같이 정의됩니다:
$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

특히 원점 $O(0, 0)$에서 점 $P(x, y)$까지의 거리는:
$$d = \sqrt{x^2 + y^2}$$

## 직관과 기하적 의미

이 공식은 **피타고라스 정리**에서 직접 유도됩니다. 두 점 $A$와 $B$를 잇는 선분을 빗변으로 하는 직각삼각형을 그으면, 한 변의 길이는 $|x_2 - x_1|$ (가로 변화량), 다른 한 변의 길이는 $|y_2 - y_1|$ (세로 변화량)입니다. 피타고라스 정리를 적용하면:
$$(\text{빗변})^2 = (\text{가로})^2 + (\text{세로})^2$$

거리 공식은 도형의 크기를 측정하고, 원의 방정식, 원점으로부터의 거리 조건, 중점까지의 거리 등을 다룰 때 기본 도구가 됩니다.

## 계산 예

두 점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리를 구하면:
$$d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

(`sqrt((4-1)**2 + (6-2)**2)` 계산 결과는 $5$)

원점 $O(0, 0)$에서 점 $P(3, 4)$까지의 거리는:
$$d = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$$
