# 직선의 방정식

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
$y=mx+n$, $ax+by+c=0$

## 본문 (학습 시 채워짐)

### 정확한 진술

직선의 방정식은 좌표평면 위의 직선 위에 있는 모든 점 $(x, y)$가 만족하는 $x$와 $y$의 관계식입니다. 가장 기본적인 두 가지 형태는 다음과 같습니다.

**기울기-절편 형태(slope-intercept form):**
$$y = mx + n$$
여기서 $m$은 기울기(slope), $n$은 $y$절편(y-intercept)입니다.

**일반형(general form):**
$$ax + by + c = 0 \quad (a, b \text{는 동시에 } 0\text{이 아님})$$

두 형태는 서로 변환 가능합니다. 예를 들어 $y = 2x - 3$은 $2x - y - 3 = 0$으로 쓸 수 있습니다.

### 직관 및 기하적 의미

$y = mx + n$ 형태에서:
- **기울기 $m$**: 직선의 가파른 정도입니다. $m > 0$이면 오른쪽 위로 향하고, $m < 0$이면 오른쪽 아래로 향합니다. 기울기의 크기가 클수록 더 가팝습니다.
- **절편 $n$**: 직선이 $y$축과 만나는 점의 $y$좌표입니다. 즉, 점 $(0, n)$을 지나갑니다.

일차 방정식이 항상 직선을 나타내는 이유는 $x$와 $y$가 1제곱으로만 나타나기 때문입니다. 만약 $x^2$이나 $xy$처럼 고차항이 있으면 포물선이나 쌍곡선 같은 곡선이 됩니다.

일반형 $ax + by + c = 0$은 특정 기울기를 갖지 않는 수직선(예: $x = 2$)도 표현할 수 있으므로 더 포괄적입니다.

### 한 줄 예

기울기 2, $y$절편 $-3$인 직선의 방정식은 $y = 2x - 3$입니다. 이는 점 $(0, -3)$을 지나고, $x$가 1 증가할 때 $y$는 2만큼 증가합니다. (`sympy.solve(Eq(y, 2*x - 3), y)` ✓)
