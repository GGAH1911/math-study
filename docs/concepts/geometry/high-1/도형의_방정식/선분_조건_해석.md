# 선분 조건 해석

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
좌표평면 위의 두 점을 잇는 선분은 매개변수 $t$를 이용하여 점의 위치를 나타내며, $t$의 값에 따라 선분의 내분점 위치를 결정합니다.

## 본문
좌표평면 위의 두 점 $A(a_1, a_2)$, $B(b_1, b_2)$에 대하여 선분 $AB$는 다음과 같은 매개변수 방정식으로 정의됩니다:
$$P = A + t(B - A), \quad 0 \le t \le 1$$
이를 성분별로 나타내면 $x = a_1 + t(b_1 - a_1)$, $y = a_2 + t(b_2 - a_2)$이며, $0 \le t \le 1$인 모든 점 $P$의 집합이 곧 선분 $AB$가 됩니다.

### 직관과 기하적 의미
매개변수 $t$는 점 $A$에서 출발하여 점 $B$를 향해 나아가는 '진행도'로 해석할 수 있습니다. $t=0$이면 시작점인 $A$에 위치하고, $t=1$이면 도착점인 $B$에 위치하며, $0 < t < 1$인 구간은 $A$와 $B$ 사이의 경로를 의미합니다. 또한 기하학적으로 선분 $AB$ 위의 임의의 점 $P$는 두 끝점으로부터의 거리의 합이 전체 선분의 길이와 같다는 $|AP| + |PB| = |AB|$ 조건을 만족합니다.

### 기본 성질
매개변수 $t$의 값은 선분의 내분 비율을 결정합니다. 예를 들어 $t=0.5$이면 선분의 중점을 나타내며, 일반적인 내분점의 경우 $t = \tfrac{m}{m+n}$일 때 점 $P$는 선분 $AB$를 $m:n$으로 내분하는 점이 됩니다.

## 학습 체크
- 매개변수 $t$의 범위가 $0 \le t \le 1$을 벗어날 경우 어떤 도형이 형성되는가?
- 점 $P$가 선분을 $m:n$으로 내분할 때, 매개변수 $t$의 값은 어떻게 표현되는가?

## 관련 개념
- **도형의 성질**: 선분의 내분점과 외분점의 개념을 통해 좌표를 결정하며, 점 사이의 거리 공식을 통해 매개변수와 실제 거리 사이의 관계를 이해할 수 있습니다.
