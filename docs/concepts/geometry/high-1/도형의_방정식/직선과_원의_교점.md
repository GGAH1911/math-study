### 정확한 진술

평면 위의 원 $C$와 직선 $\ell$이 주어졌을 때, **직선과 원의 교점**은 다음 두 조건을 동시에 만족하는 점 $P$입니다:
- $P$는 직선 $\ell$ 위의 점
- $P$는 원 $C$ 위의 점

원의 방정식 $(x-a)^2 + (y-b)^2 = r^2$과 직선의 방정식을 연립하면, 교점의 좌표는 이 연립방정식의 해가 됩니다. 교점이 존재하려면 두 방정식의 연립 이차방정식이 실근을 가져야 합니다.

### 기하적 의미

원의 중심을 $O$, 반지름을 $r$이라 하고, 점 $O$에서 직선 $\ell$까지의 거리를 $d$라 합시다. 교점의 개수는 $d$와 $r$의 관계로 결정됩니다:

- **$d < r$**: 직선이 원과 두 점에서 만남 (할선) → 두 교점
- **$d = r$**: 직선이 원에 접함 → 한 교점 (접점)
- **$d > r$**: 직선과 원이 떨어져 있음 → 교점 없음

이를 대수적으로 판정하려면 직선의 방정식을 원의 방정식에 대입한 후 얻는 이차방정식의 판별식 $\Delta$를 조사합니다:
- $\Delta > 0$: 서로 다른 두 교점
- $\Delta = 0$: 한 교점 (중근)
- $\Delta < 0$: 교점 없음

### 예

원 $x^2 + y^2 = 4$와 직선 $y = x - 1$의 교점을 구합니다.

직선의 식을 원의 식에 대입하면:
$$x^2 + (x-1)^2 = 4$$
$$2x^2 - 2x - 3 = 0$$

판별식 $\Delta = 4 + 24 = 28 > 0$이므로 서로 다른 두 교점이 존재합니다.

근의 공식으로 $x = \frac{1 \pm \sqrt{7}}{2}$이고, 각각의 $y$ 값은 $y = x - 1$에서 구하면 교점은 $\left(\frac{1 + \sqrt{7}}{2}, \frac{-1 + \sqrt{7}}{2}\right)$, $\left(\frac{1 - \sqrt{7}}{2}, \frac{-1 - \sqrt{7}}{2}\right)$입니다.

`sympy.solve([x**2 + y**2 - 4, y - x + 1], [x, y])`로 검증 가능합니다.
