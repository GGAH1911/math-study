# 거리와 최적화

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 점 사이의 거리와 점과 직선 사이의 거리를 정의하고, 이를 활용하여 최단 거리를 찾는 최적화 문제를 해결합니다.

## 본문
평면 좌표계에서 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ 사이의 거리는 $d(P, Q) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$로 정의되며, 이는 벡터 $\vec{PQ}$의 크기 $|\vec{PQ}|$와 같습니다. 또한 점 $P(x_0, y_0)$에서 직선 $ax + by + c = 0$까지의 거리는 $d = \tfrac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$로 계산합니다.

### 직관과 기하적 의미
거리는 두 도형 사이의 가장 가까운 길이를 의미합니다. 점과 직선 사이의 최단 거리는 점에서 직선에 내린 수선의 발까지의 길이이며, 이 수선은 항상 직선과 수직을 이룹니다. 최적화 문제에서는 특정 조건 아래 거리를 최소 또는 최대화하는 점을 찾을 때 이 거리 공식을 활용합니다. 예를 들어, 직선 위의 한 점과 주어진 점 사이의 거리가 최소가 되는 지점을 찾는 과정은 거리 함수를 최소화하는 최적화 과정과 같습니다.

### 기본 성질
- 점이 직선 위에 있을 경우, 점과 직선 사이의 거리는 $0$이 됩니다.
- 두 점 사이의 거리는 좌표 차이의 제곱의 합에 루트를 씌운 값으로, 피타고라스 정리에 기반합니다.
- 최단 거리를 찾는 문제는 거리 함수를 최소화하는 최적화 문제로 귀결됩니다.

## 학습 체크
- 점 $(1, 2)$에서 직선 $x + y - 3 = 0$까지의 거리를 구할 때 결과가 $0$이 나오는 이유는 무엇인가?
- 직선 위의 한 점을 매개변수로 표현하여 거리의 최솟값을 구하는 과정은 어떻게 진행되는가?

## 관련 개념
- **평면벡터**: 두 점 사이의 거리는 벡터 $\vec{PQ}$의 크기와 동일한 의미를 가집니다.
