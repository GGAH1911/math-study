# 거리와 최적화

## 정확한 진술

평면 좌표계에서 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ 사이의 거리는 다음으로 정의됩니다:

$$d(P, Q) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

이는 벡터 $\vec{PQ}$의 크기 $|\vec{PQ}|$와 같습니다. 점 $P(x_0, y_0)$에서 직선 $ax + by + c = 0$까지의 거리는:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

## 직관/기하적 의미

거리는 두 도형 사이 가장 가까운 길이입니다. 점과 직선 사이의 최단 거리는 점에서 직선에 내린 수선의 발까지의 길이이며, 이 수선은 항상 직선과 수직입니다. 최적화 문제에서는 특정 조건 아래 거리를 최소 또는 최대화하는 점을 찾을 때 거리 공식을 활용합니다. 예를 들어 "직선 위의 어느 점에서 주어진 점까지의 거리가 최소인가" 하는 질문은 거리 함수를 최소화하는 최적화 문제입니다. 이렇게 거리 개념은 응용 문제에서 최선의 위치나 조건을 찾는 데 필수적입니다.

## 한 줄 예

점 $(1, 2)$에서 직선 $x + y - 3 = 0$까지의 거리: $d = \frac{|1 + 2 - 3|}{\sqrt{2}} = 0$ (점이 직선 위에 있음). 점 $(0, 0)$에서는 $d = \frac{|-3|}{\sqrt{2}} = \frac{3\sqrt{2}}{2}$ `(sympy.sqrt((0+0-3)**2 / 2))`
