### 정확한 진술

좌표평면 위의 원 $C: (x-a)^2 + (y-b)^2 = r^2$과 직선 $l: Ax + By + C = 0$의 위치 관계는 **원의 중심 $(a, b)$에서 직선 $l$까지의 거리 $d$와 원의 반지름 $r$의 대소관계**로 결정됩니다. 

원의 중심에서 직선까지의 거리는 다음 공식으로 구합니다:

$$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$$

이때 세 가지 경우가 발생합니다:
- **$d < r$**: 직선과 원이 **두 점에서 만남** (할선)
- **$d = r$**: 직선과 원이 **한 점에서 만남** (접선)  
- **$d > r$**: 직선과 원이 **만나지 않음** (외부)

### 직관/기하적 의미

원의 중심에서 출발하는 수직선의 발이 직선 위의 점입니다. 이 수직거리 $d$가 원의 "반지름"과 얼마나 가까운지에 따라 교점의 개수가 달라집니다. 

만약 직선이 원의 중심을 지나간다면 ($d=0$), 직선은 원의 지름을 따라 지나므로 반드시 두 점에서 만납니다. 직선이 원 밖으로 멀어질수록 거리 $d$가 증가하다가, $d=r$이 되는 순간 원에 **정확히 스치고** (접하고), 더 멀어지면 교점이 없어집니다.

### 한 줄 예

원 $(x-1)^2 + (y+2)^2 = 5$와 직선 $x + 2y - 1 = 0$의 관계를 판단하세요. 

중심 $(1, -2)$에서 직선까지의 거리는 $d = \frac{|1 + 2(-2) - 1|}{\sqrt{1^2 + 2^2}} = \frac{|-4|}{\sqrt{5}} = \frac{4\sqrt{5}}{5} \approx 1.79$이고, 반지름은 $r = \sqrt{5} \approx 2.24$입니다. 
$d < r$이므로 **직선과 원은 두 점에서 만납니다** (할선).
