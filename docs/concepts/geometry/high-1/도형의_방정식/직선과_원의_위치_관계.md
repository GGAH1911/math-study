# 직선과 원의 위치 관계

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
좌표평면 위에서 원의 중심과 직선 사이의 거리 $d$와 원의 반지름 $r$의 크기를 비교하여 두 도형의 위치 관계를 판별할 수 있습니다.

## 본문
좌표평면 위의 원 $C: (x-a)^2 + (y-b)^2 = r^2$과 직선 $l: Ax + By + C = 0$의 위치 관계는 원의 중심 $(a, b)$에서 직선 $l$까지의 거리 $d$와 원의 반지름 $r$의 대소관계에 의해 결정됩니다. 이때 원의 중심에서 직선까지의 거리 $d$는 다음과 같은 공식으로 계산합니다.
$$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$$
이 거리 $d$와 반지름 $r$을 비교하면 세 가지 경우로 나뉩니다. 첫째, $d < r$이면 직선과 원은 두 점에서 만나며 이를 할선이라 합니다. 둘째, $d = r$이면 직선과 원은 한 점에서 만나며 이를 접선이라 합니다. 셋째, $d > r$이면 직선과 원은 만나지 않습니다.

### 직관과 기하적 의미
원의 중심에서 직선에 내린 수직선의 발이 직선 위의 한 점이 되는데, 이 수직 거리 $d$가 원의 반지름 $r$과 비교했을 때 얼마나 가까운지가 교점의 개수를 결정합니다. 만약 직선이 원의 중심을 통과한다면 $d=0$이 되어 반지름보다 항상 작으므로 반드시 두 점에서 만나게 됩니다. 직선이 원의 중심에서 멀어지다가 $d=r$이 되는 순간 원의 가장자리를 스치듯 접하게 되고, 그보다 더 멀어지면 교점이 생기지 않습니다.

### 기본 성질
- $d < r$: 두 점에서 만남 (할선)
- $d = r$: 한 점에서 만남 (접선)
- $d > r$: 만나지 않음

## 학습 체크
- 원의 중심에서 직선까지의 거리 $d$를 구할 때 분모의 $\sqrt{A^2 + B^2}$ 계산에 주의했는가?
- $d < r$인 경우와 $d > r$인 경우의 기하학적 형태를 머릿속으로 그릴 수 있는가?
- 직선이 원의 중심을 지날 때 $d=0$이 되어 항상 두 점에서 만난다는 사실을 이해했는가?

## 관련 개념
- **도형의 방정식**: 원과 직선의 위치 관계는 좌표평면 위에서 도형을 방정식으로 나타내어 대수적으로 해결하는 대표적인 사례입니다.
