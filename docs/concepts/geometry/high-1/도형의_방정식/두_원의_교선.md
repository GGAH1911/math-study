# 두 원의 교선

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 원의 방정식을 서로 빼서 얻는 일차식으로, 두 원의 교점을 지나는 직선을 의미합니다.

## 본문
평면 위에 두 개의 원이 있을 때, 이 두 원이 교차하며 만나는 두 교점을 지나는 직선을 두 원의 공통현 또는 두 원의 교선이라 합니다. 두 원의 방정식을 각각 $C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0$, $C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0$이라 하면, 두 원의 교선의 방정식은 두 원의 방정식을 빼서 얻습니다:
$$\boxed{(D_1 - D_2)x + (E_1 - E_2)y + (F_1 - F_2) = 0}$$
이 식은 $x$와 $y$에 대한 일차식의 형태를 띠므로 항상 직선을 나타냅니다.

### 직관과 기하적 의미
두 원의 공통현은 두 원의 교점을 지나는 직선으로서, 두 원의 중심을 잇는 직선과 항상 수직으로 만납니다. 기하학적으로 두 원의 중심 사이의 거리가 $0$보다 크고 두 반지름의 합($r_1 + r_2$)보다 작을 때 두 교점이 존재하며, 이때 공통현이 유일하게 결정됩니다.

### 기본 성질
- 공통현은 두 원의 중심을 연결한 직선과 수직이다.
- 공통현 위의 임의의 점에서 두 원에 이르는 거듭제곱의 값은 서로 같다.

## 학습 체크
- 두 원의 방정식을 뺐을 때 $x^2$과 $y^2$ 항이 소거되어 일차식이 되는 원리를 이해하고 있는가?
- 공통현이 두 원의 중심을 잇는 직선과 수직이라는 성질을 이용해 교점의 좌표를 구할 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 평면에서의 공통현 개념은 공간에서 두 구의 교선인 원을 다룰 때 평면의 방정식과 직선의 방정식을 이해하는 기초가 됩니다.
