# 교점조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 도형의 방정식을 동시에 만족하는 점이 존재하는지, 그리고 그 점의 개수가 몇 개인지를 결정하는 조건입니다.

## 본문
두 도형의 교점은 두 도형을 나타내는 방정식을 동시에 만족하는 점을 의미합니다. 교점조건이란 두 도형이 만나는 점이 존재하는지 여부와 만나는 점의 개수가 어떻게 결정되는지를 나타내는 조건을 말합니다. 예를 들어 직선 $L_1: ax + by + c = 0$과 직선 $L_2: dx + ey + f = 0$의 교점은 다음 연립방정식을 풀어 구할 수 있습니다.

$$\begin{cases} ax + by + c = 0 \\ dx + ey + f = 0 \end{cases}$$

이 연립방정식의 해의 상태에 따라 교점의 개수가 결정됩니다. 연립방정식이 유일한 해를 가지면 교점이 정확히 1개이고, 부정형 해를 가지면 두 직선이 일치하여 교점이 무수히 많으며, 불능이면 두 직선이 평행하여 교점이 존재하지 않습니다.

### 직관과 기하적 의미
기하학적으로 교점조건은 두 도형이 만나는지, 만난다면 어디서 몇 번 만나는지를 판단하는 도구입니다. 직선과 원의 관계를 예로 들면, 원의 중심에서 직선까지의 거리 $d$와 원의 반지름 $r$을 비교하여 교점의 개수를 알 수 있습니다. $d < r$이면 교점이 2개이고, $d = r$이면 접하여 교점이 1개이며, $d > r$이면 교점이 없습니다. 이러한 기하적 직관은 복잡한 도형에서도 판별식이나 연립방정식의 성질을 통해 대수적으로 검증할 수 있습니다.

### 기본 성질
- 연립방정식의 해의 개수는 도형의 교점의 개수와 일치합니다.
- 두 도형이 접하는 경우, 교점은 하나이며 이는 대수적으로 중근을 갖는 것과 같습니다.
- 매개변수가 포함된 방정식의 경우, 교점조건을 통해 매개변수의 범위를 구할 수 있습니다.

## 학습 체크
- 두 도형의 방정식을 연립했을 때 나타나는 방정식의 해의 종류(유일한 해, 무수히 많은 해, 해 없음)가 각각 어떤 기하학적 상황을 의미하는가?
- 원과 직선의 위치 관계를 판별할 때, 점과 직선 사이의 거리 공식을 사용하는 방법은 무엇인가?

## 관련 개념
- **도형의 방정식**: 도형을 좌표평면 위의 방정식으로 나타냄으로써 교점의 존재 여부를 대수적인 연립방정식 문제로 변환하여 해결할 수 있게 합니다.
