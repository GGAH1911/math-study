# 기하학적 조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
좌표평면에서 점이나 도형이 만족해야 하는 기하학적 성질을 방정식이나 부등식의 형태로 나타낸 것입니다.

## 본문
기하학적 조건은 좌표평면 위에서 점이나 도형이 갖는 특정한 성질을 수식으로 변환한 것입니다. 어떤 기하학적 관계를 만족하는 점들의 집합을 구하면 그것이 곧 도형이 되며, 이를 통해 시각적인 도형의 성질을 대수적인 식으로 표현할 수 있습니다.

### 직관과 기하적 의미
기하학적 조건은 눈에 보이는 도형의 성질을 수식으로 연결하는 다리 역할을 합니다. 예를 들어 "원점으로부터 거리가 3이다"라는 기하학적 조건은 $x^2 + y^2 = 9$라는 방정식으로 변환됩니다. 이 식을 만족하는 모든 점 $(x, y)$를 모으면 반지름이 3인 원이라는 도형이 나타납니다. 즉, 기하학적 조건은 도형의 자취를 결정하는 핵심 규칙입니다.

### 기본 성질
기하학적 조건을 활용하면 다음과 같은 수학적 분석이 가능합니다.
- 도형의 방정식을 논리적으로 유도할 수 있습니다.
- 특정 점이 주어진 도형 위에 존재하는지 여부를 판정할 수 있습니다.
- 복잡한 도형의 성질을 수식을 통해 정밀하게 분석할 수 있습니다.

예를 들어, 점 $(x, y)$가 점 $(1, 2)$로부터 거리가 5인 원 위에 있다는 조건은 $(x-1)^2 + (y-2)^2 = 25$로 나타낼 수 있습니다. 실제로 점 $(4, 6)$을 대입하면 $(4-1)^2 + (6-2)^2 = 3^2 + 4^2 = 25$가 되어 조건을 만족함을 확인할 수 있습니다.

## 학습 체크
- 주어진 기하학적 조건을 만족하는 점 $(x, y)$를 식으로 세울 수 있는가?
- 도출된 방정식이 나타내는 도형의 모양을 그래프로 그릴 수 있는가?
- 특정 점의 좌표를 방정식에 대입하여 도형 위의 점인지 확인할 수 있는가?

## 관련 개념
- **이차함수**: 초점으로부터의 거리와 준선으로부터의 거리가 같다는 기하학적 조건을 식으로 나타내면 이차함수의 그래프 형태가 됩니다.
