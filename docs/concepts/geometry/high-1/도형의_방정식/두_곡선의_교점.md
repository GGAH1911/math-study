# 두 곡선의 교점

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 곡선의 교점은 두 함수의 함숫값이 같아지는 지점으로, 방정식 $f(x) = g(x)$의 해를 통해 구할 수 있습니다.

## 본문
두 곡선 $y = f(x)$와 $y = g(x)$의 교점은 두 식을 동시에 만족하는 점 $(a, f(a))$를 의미합니다. 즉, $f(a) = g(a)$를 만족하는 $x = a$에서 두 곡선이 만납니다. 이때 교점의 $x$ 좌표는 방정식 $f(x) = g(x)$의 해가 되며, $y$ 좌표는 $f(a)$ 또는 $g(a)$의 값과 같습니다.

### 직관과 기하적 의미
좌표평면 위에서 두 곡선이 서로 교차하며 만나는 지점이 바로 교점입니다. 이는 두 함수의 함숫값이 동일한 순간을 시각적으로 나타낸 것입니다. 대수적으로는 방정식 $f(x) = g(x)$를 풀어 해를 구하고, 기하적으로는 두 그래프가 평면 위에서 만나는 위치를 찾는 과정으로 이해할 수 있습니다. 교점의 개수는 상황에 따라 0개, 1개, 또는 여러 개가 될 수 있습니다.

### 기본 성질
교점을 구하는 절차는 다음과 같습니다. 먼저 두 식을 같다고 놓은 방정식 $f(x) = g(x)$를 세운 뒤, 이를 $f(x) - g(x) = 0$의 형태로 정리합니다. 그 다음 방정식을 풀어 $x$ 값을 구하고, 구한 $x$ 값을 원래의 식 중 하나에 대입하여 $y$ 좌표를 결정합니다.

**예시:** 직선 $y = 2x + 1$과 포물선 $y = x^2$의 교점을 구하면, $x^2 - 2x - 1 = 0$의 해인 $x = 1 \pm \sqrt{2}$를 통해 교점 $(1 + \sqrt{2}, 3 + 2\sqrt{2})$와 $(1 - \sqrt{2}, 3 - 2\sqrt{2})$를 얻을 수 있습니다.

## 학습 체크
- 교점의 $x$ 좌표를 구한 후, 반드시 $y$ 좌표를 구하기 위해 식에 대입하는 과정을 거쳤는가?
- 두 식을 같다고 놓은 방정식의 해가 실제 그래프의 교점 개수와 일치하는가?

## 관련 개념
- **방정식**: 교점의 $x$ 좌표를 찾기 위해 $f(x) = g(x)$라는 방정식을 푸는 과정이 필수적입니다.
- **함수**: 두 곡선은 각각 함수 $f$와 $g$의 그래프를 의미하며, 교점은 두 함수의 함숫값이 일치하는 지점입니다.
