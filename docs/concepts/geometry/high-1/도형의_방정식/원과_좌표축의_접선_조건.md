# 원과 좌표축의 접선 조건

원이 $x$축 또는 $y$축에 접한다는 조건을 중심과 반지름의 관계식으로 정리한 것입니다. 고1 도형의 방정식 단원에서 원의 위치 결정 문제의 핵심 도구입니다.

## 정의

중심이 $(a, b)$, 반지름이 $r$ ($r > 0$)인 원 $(x - a)^2 + (y - b)^2 = r^2$에 대해
- **$x$축에 접함:** 중심에서 $x$축까지의 거리 $= r$, 즉 $|b| = r$.
- **$y$축에 접함:** 중심에서 $y$축까지의 거리 $= r$, 즉 $|a| = r$.
- **두 축에 동시 접함:** $|a| = |b| = r$. 이때 중심은 사분면의 안쪽에 위치한 점 $(\pm r, \pm r)$.

이는 원의 중심과 직선 사이의 거리 공식의 특수한 경우입니다.

## 예시

제1사분면에서 두 좌표축에 모두 접하고 점 $(2, 4)$를 지나는 원을 찾아봅니다. 조건에서 중심은 $(r, r)$, 반지름은 $r$이어야 합니다. 점이 원 위에 있으므로
$$(2 - r)^2 + (4 - r)^2 = r^2.$$
전개하면 $4 - 4r + r^2 + 16 - 8r + r^2 = r^2$이므로 $r^2 - 12r + 20 = 0$, $r = 2$ 또는 $r = 10$.

따라서 두 원: 중심 $(2, 2)$, 반지름 $2$인 원과 중심 $(10, 10)$, 반지름 $10$인 원.
