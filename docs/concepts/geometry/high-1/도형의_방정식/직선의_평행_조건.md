# 직선의 평행 조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 직선이 평행하려면 기울기가 같아야 하며, 두 직선이 서로 다른 직선이 되도록 상수항 조건이 충족되어야 합니다.

## 본문
두 직선이 평행하다는 것은 같은 평면 위에서 두 직선이 만나지 않는 상태를 의미합니다. 고등학교 수학에서는 직선의 방정식을 표현하는 방식에 따라 다음과 같이 평행 조건을 판정합니다.

먼저 기울기가 주어진 형태의 직선 $l_1: y = m_1 x + n_1$과 $l_2: y = m_2 x + n_2$에 대하여, 두 직선이 평행할 조건은 $m_1 = m_2$ 이고 $n_1 \neq n_2$입니다. 이때 두 직선은 모두 $x$에 대한 일차식이어야 하며, 연직선이 아니어야 한다는 전제가 필요합니다.

일반형으로 표현된 직선 $l_1: a_1 x + b_1 y + c_1 = 0$과 $l_2: a_2 x + b_2 y + c_2 = 0$에 대하여, 두 직선이 평행할 조건은 $\displaystyle\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} \neq \tfrac{c_1}{c_2}$입니다. 단, 분모가 되는 $a_2, b_2$는 $0$이 아니어야 합니다.

### 직관과 기하적 의미
기울기는 직선이 수평선과 이루는 경사의 정도를 나타냅니다. 따라서 기울기가 같다는 것은 두 직선이 동일한 각도로 기울어져 있음을 의미하며, 이 경우 두 직선을 아무리 길게 연장하더라도 결코 만나지 않습니다. 일반형에서의 계수 비율 $\displaystyle\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2}$는 두 직선의 법선 벡터가 서로 평행함을 의미하며, 이는 곧 두 직선의 방향이 일치함을 뜻합니다. 이때 상수항의 비율 $\tfrac{c_1}{c_2}$가 달라야만 두 직선이 일치하지 않고 서로 다른 직선으로 존재하게 됩니다.

### 기본 성질
- 기울기가 같고 $y$절편이 다르면 두 직선은 평행합니다.
- 일반형에서 계수의 비율이 같으면 두 직선은 평행하거나 일치합니다.
- 두 직선이 일치할 경우에는 $\displaystyle\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} = \tfrac{c_1}{c_2}$를 만족합니다.

## 학습 체크
- 기울기 형태의 방정식에서 두 직선이 평행할 때, $y$절편이 같아지면 어떤 상태가 되는가?
- 일반형 방정식에서 $\displaystyle\tfrac{a_1}{a_2} = \tfrac{b_1}{b_2} = \tfrac{c_1}{c_2}$인 경우 두 직선의 관계는 무엇인가?
- 연직선(세로 직선)의 경우 기울기를 이용한 판정이 가능한가?

## 관련 개념
- **도형의 방정식**: 직선의 방정식은 좌표평면 위의 도형을 대수적으로 나타낸 것이며, 평행 조건은 두 방정식의 계수 사이의 관계식으로 표현됩니다.
