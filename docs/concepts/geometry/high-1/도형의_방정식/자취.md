# 자취

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
특정한 기하학적 조건을 만족하며 움직이는 점들이 그리는 도형의 궤적을 의미합니다.

## 본문
점 $P$가 좌표평면 위에서 어떤 기하학적 조건을 만족하면서 움직일 때, 점 $P$가 거치는 모든 점들의 집합을 자취라고 부릅니다. 즉, 주어진 조건을 만족하는 점들을 모두 모은 도형이 자취입니다. 보통 자취는 직선이나 원, 포물선 같은 곡선으로 나타나며, 대수적으로는 방정식으로 표현됩니다.

### 직관과 기하적 의미
자취를 구한다는 것은 "특정 조건을 만족하려면 점이 어떤 도형 위에 있어야 하는가?"라는 질문에 답하는 과정입니다. 예를 들어, "두 점 $A, B$로부터 거리가 같은 모든 점"이라는 조건이 주어지면, 그 점들은 선분 $AB$의 수직이등분선 위에 놓이게 되며 이 선분이 곧 자취가 됩니다.

### 기본 성질
자취를 구하는 과정은 일반적으로 다음과 같은 단계로 진행됩니다. 먼저 조건을 만족하는 움직이는 점을 $P(x, y)$로 설정합니다. 그다음 주어진 기하학적 조건을 $x$와 $y$에 관한 식으로 나타냅니다. 마지막으로 이 식을 정리하여 $x$와 $y$ 사이의 관계식인 방정식을 유도하면, 그 방정식이 곧 자취를 나타내는 식입니다.

예를 들어, 점 $P(x, y)$가 정점 $F(1, 0)$으로부터의 거리와 직선 $x = -1$까지의 거리가 같다면, $\sqrt{(x-1)^2 + y^2} = |x + 1|$을 정리하여 자취는 포물선 $y^2 = 4x$가 됩니다.

## 학습 체크
- 점 $P$의 좌표를 $(x, y)$로 설정한 후, 문제에서 제시한 조건을 어떻게 방정식으로 변환할 것인가?
- 유도된 방정식이 나타내는 도형이 기하학적으로 어떤 모양(직선, 원, 포물선 등)인지 파악했는가?

## 관련 개념
- **도형의 방정식**: 자취를 구하여 얻은 $x$와 $y$의 관계식은 곧 해당 도형을 나타내는 방정식이 됩니다.
