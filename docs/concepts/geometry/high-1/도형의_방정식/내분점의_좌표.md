# 내분점의 좌표

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 점을 주어진 비율로 나누는 점의 좌표를 구하는 방법으로, 각 좌표에 반대편 비율을 곱하여 합산한 뒤 비율의 총합으로 나누어 계산합니다.

## 본문
두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 잇는 선분 $\overline{AB}$를 $m : n$ ($m>0, n>0$)으로 내분하는 점 $P$의 좌표는 다음과 같습니다.
$$P = \left( \frac{nx_1 + mx_2}{m + n}, \frac{ny_1 + my_2}{m + n} \right)$$
이때 점 $P$는 점 $A$로부터 출발하여 점 $B$ 방향으로 전체 거리의 $\frac{m}{m+n}$만큼 떨어진 지점에 위치하며, 선분 $\overline{AB}$ 위에 놓이게 됩니다.

### 직관과 기하적 의미
내분점은 두 점 사이를 주어진 비율로 나누는 지점을 의미합니다. 만약 선분을 $1 : 1$로 내분한다면 이는 두 점의 한가운데인 중점이 되며, 이때의 좌표는 두 끝점 좌표의 산술평균과 같습니다. 기하학적으로 비율 $m : n$에서 $m$의 값이 커질수록 내분점은 점 $B$에 더 가까워집니다. 공식의 분자 구조를 보면 각 점의 좌표에 상대방의 비율을 곱하는 가중평균의 형태를 띠고 있는데, 이는 특정 점에 더 큰 가중치를 부여할수록 그 점에 가까운 위치에 내분점이 형성됨을 보여줍니다.

### 기본 성질
- 선분을 $1 : 1$로 내분하는 점은 두 점의 중점입니다.
- 내분점은 항상 두 점을 잇는 선분 위에 존재합니다.
- 비율 $m : n$에서 $m$이 커질수록 내분점은 점 $B$에 가까워지고, $n$이 커질수록 점 $A$에 가까워집니다.

## 학습 체크
- 내분점 공식에서 분자의 비율 $m$과 $n$이 각 좌표에 어떻게 교차하여 적용되는지 이해했는가?
- 내분점이 선분 위에 존재하기 위한 조건인 $m, n > 0$의 의미를 파악했는가?
- $1 : 1$ 내분 시 공식이 중점 공식으로 어떻게 변하는지 유도할 수 있는가?

## 관련 개념
- **중점**: 내분 비율이 $1 : 1$인 특수한 경우의 내분점입니다.
- **외분점**: 선분의 연장선 위에서 주어진 비율로 점을 나누는 점으로, 내분점과 달리 선분 외부의 점을 다룹니다.
- **벡터의 내분**: 평면 좌표를 넘어 벡터의 관점에서 선분을 분할하는 개념으로 확장됩니다.
