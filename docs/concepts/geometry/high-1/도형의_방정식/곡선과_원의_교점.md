# 곡선과 원의 교점

## 정확한 진술

곡선 $y = f(x)$와 원 $(x - a)^2 + (y - b)^2 = r^2$의 교점은 두 도형을 나타내는 방정식을 동시에 만족하는 점 $(x, y)$입니다. 곡선의 방정식에서 $y = f(x)$를 원의 방정식에 대입하면:

$$\left( x - a \right)^2 + \left( f(x) - b \right)^2 = r^2$$

이 방정식을 정리하여 얻은 $x$의 값들과 대응하는 $y = f(x)$ 값이 교점의 좌표입니다.

## 직관과 기하적 의미

곡선과 원이 만나는 지점을 찾는 것입니다. 평면에 그려진 두 도형이 겹치는 부분을 대수적으로 정확히 파악하는 방법이죠. 교점의 개수는 0개부터 여러 개까지 가능하며, 이는 곡선의 형태와 원의 위치·크기에 따라 결정됩니다.

**정적분의 활용**과 연결될 때는, 두 도형 사이의 넓이를 구할 때 교점을 경계값으로 사용합니다. 예를 들어 원과 직선이 만나는 교점의 $x$ 좌표를 적분 구간의 끝점으로 설정하게 됩니다.

## 한 줄 예

원 $x^2 + y^2 = 4$와 직선 $y = 1$의 교점을 구하려면, $x^2 + 1^2 = 4$에서 $x = \pm\sqrt{3}$이므로 교점은 $(-\sqrt{3}, 1)$과 $(\sqrt{3}, 1)$입니다.
