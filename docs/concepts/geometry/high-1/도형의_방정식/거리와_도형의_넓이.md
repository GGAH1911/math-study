# 거리와 도형의 넓이

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 정확한 진술

**거리**는 좌표평면의 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ 사이를 잇는 직선의 길이입니다. 거리 공식은 $d(P, Q) = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$이며, 이는 피타고라스 정리로부터 유도됩니다. **도형의 넓이**는 곡선 $y = f(x)$ 아래 또는 두 곡선 사이의 영역이 차지하는 면적을 의미하며, 정적분으로 계산합니다. 폐곡선으로 둘러싸인 영역의 넓이는 $S = \int_a^b |f(x)| \, dx$로 정의됩니다 (단, $a \leq x \leq b$에서).

## 직관과 기하적 의미

좌표평면에서 거리는 두 점 사이를 최단거리로 연결한 선분의 길이입니다. 이를 직각삼각형으로 생각하면, 밑변은 $x_2 - x_1$, 높이는 $y_2 - y_1$이고, 빗변이 바로 거리가 됩니다.

도형의 넓이는 곡선 아래의 "모양"을 수량화하는 방식입니다. 곡선 $y = f(x)$가 항상 양수일 때, 구간 $[a, b]$에서 곡선 아래의 영역을 작은 직사각형들로 잘게 나누어 쌓아올린다고 상상하면, 그 직사각형들의 넓이의 합이 정적분 값입니다. 정적분은 이 극한 과정(Riemann sum의 극한)을 통해 정의되며, 기하학적으로는 $x$축 위의 구간 $[a, b]$과 곡선 사이의 넓이를 계산합니다.

## 한 줄 예

점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9+16} = 5$이고, 곡선 $y = x^2$이 $x=0$부터 $x=2$까지일 때 아래의 넓이는 $S = \int_0^2 x^2 \, dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3}$입니다. (검산: `from sympy import integrate, symbols; x = symbols('x'); integrate(x**2, (x, 0, 2))`)
