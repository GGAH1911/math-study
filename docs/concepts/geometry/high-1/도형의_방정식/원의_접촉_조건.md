# 원의 접촉 조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
원과 직선이 접하거나 두 원이 만날 때, 중심 사이의 거리와 반지름 사이의 특정한 관계가 성립한다.

## 본문
원의 중심을 $C(a, b)$, 반지름을 $r$이라 하고 직선을 $\ell$이라 할 때, 원과 직선이 정확히 한 점에서 만나면 중심에서 직선까지의 거리 $d$는 $d(C, \ell) = r$을 만족한다. 직선의 방정식이 $px + qy + s = 0$ (단, $p^2 + q^2 = 1$)인 경우, $|pa + qb + s| = r$로 나타낼 수 있다. 또한 중심이 각각 $O_1, O_2$이고 반지름이 각각 $r_1, r_2$인 두 원이 접할 조건은 다음과 같다. 두 원이 서로 밖에서 접하는 외접의 경우에는 두 중심 사이의 거리 $|O_1O_2|$가 두 반지름의 합인 $r_1 + r_2$와 같아야 하며, 한 원이 다른 원의 내부에서 접하는 내접의 경우에는 두 중심 사이의 거리 $|O_1O_2|$가 두 반지름의 차인 $|r_1 - r_2|$와 같아야 한다.

### 직관과 기하적 의미
원은 중심으로부터 거리가 반지름 $r$인 점들의 집합이므로, 직선이 원과 한 점에서 만나려면 중심에서 직선까지의 거리가 반지름과 일치해야 한다. 만약 거리가 반지름보다 크면 직선은 원과 만나지 않고, 거리가 반지름보다 작으면 직선은 원을 관통하여 두 점에서 만나게 된다. 두 원의 경우에도 중심 사이의 거리가 반지름의 합이나 차와 같아지는 순간, 두 원의 경계선이 정확히 한 지점에서 만나게 된다.

### 기본 성질
- 원과 직선의 접점 확인: 중심에서 직선까지의 거리 $d$와 반지름 $r$을 비교하여 $d=r$이면 접한다.
- 두 원의 외접 조건: $|O_1O_2| = r_1 + r_2$
- 두 원의 내접 조건: $|O_1O_2| = |r_1 - r_2|$

## 학습 체크
- 원의 중심에서 직선까지의 거리를 구할 때 사용되는 공식이 반지름과 일치하는지 확인하였는가?
- 두 원이 접할 때, 두 중심 사이의 거리가 반지름의 합인지 차인지 상황에 따라 구분할 수 있는가?

## 관련 개념
- **원의 방정식**: 원의 중심과 반지름을 정의하며 접촉 조건을 계산하는 기초가 된다.
- **점과 직선 사이의 거리**: 원과 직선이 접하는지 판단하기 위해 반드시 필요한 계산 도구이다.
- **도함수의 활용 심화**: 함수의 그래프가 축에 접하는 상황을 판별할 때 접선의 방정식 개념과 연결된다.
