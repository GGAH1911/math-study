# 원의 접촉 조건

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 정확한 진술

원과 직선이 접할 조건: 원의 중심을 $C(a, b)$, 반지름을 $r$이라 하고, 직선을 $\ell$이라 할 때, 원과 직선이 정확히 한 점에서 만나면(접하면), 중심에서 직선까지의 거리 $d$는 다음을 만족합니다:

$$d(C, \ell) = r$$

직선 $px + qy + s = 0$ (단, $p^2 + q^2 = 1$)의 경우 구체적으로:
$$|pa + qb + s| = r$$

두 원이 접할 조건: 중심이 각각 $O_1, O_2$이고 반지름이 각각 $r_1, r_2$인 두 원은 다음 중 하나를 만족할 때 접합니다.
- **외접** (원이 서로 밖에서 접할 때): $|O_1O_2| = r_1 + r_2$
- **내접** (작은 원이 큰 원 안에서 접할 때): $|O_1O_2| = |r_1 - r_2|$

## 직관/기하적 의미

원은 중심으로부터 거리가 $r$인 모든 점의 집합입니다. 따라서 직선과 원이 정확히 한 점에서 만나려면, 중심에서 직선까지의 거리가 정확히 반지름과 같아야 합니다. 거리가 반지름보다 크면 교점이 없고, 작으면 두 점에서 만나기 때문입니다.

두 원의 경우, 외접할 때는 두 중심 사이 거리가 두 반지름의 합이 되어 원들이 한 점에서 만나고, 내접할 때는 거리가 반지름의 차가 되어 안쪽에서 만납니다.

## 한 줄 예

원 $(x-1)^2 + (y-2)^2 = 4$와 직선 $3x - 4y - 5 = 0$의 접촉 확인: 중심 $(1, 2)$에서 직선까지의 거리 $\frac{|3(1) - 4(2) - 5|}{\sqrt{9+16}} = \frac{10}{5} = 2 = r$이므로 접합니다. (검증: `sympy.solve([(x-1)**2 + (y-2)**2 - 4, 3*x - 4*y - 5], [x, y])` 결과 해가 1개)
