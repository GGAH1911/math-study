# 수직인 두 직선의 기울기 관계

좌표평면에서 두 직선이 수직일 때 두 기울기의 곱이 $-1$이 되는 관계입니다. 고1 도형의 방정식 단원의 핵심 공식입니다.

## 정의

기울기가 각각 $m_1, m_2$인 두 직선이 수직일 필요충분조건은
$$m_1 \cdot m_2 = -1.$$
특별한 경우로
- 수평선 $y = c$와 수직선 $x = k$는 항상 수직(한쪽 기울기가 존재하지 않음).
- 수직 직선의 기울기는 주어진 직선의 기울기의 **음의 역수**.

증명 개요: 두 직선의 방향벡터가 각각 $(1, m_1), (1, m_2)$이고, 내적 $1 + m_1 m_2$가 $0$이 되어야 수직.

## 예시

직선 $\ell: y = 3x - 2$에 수직인 직선의 기울기는 $-\dfrac{1}{3}$입니다. 점 $(0, 1)$을 지나는 수직 직선은 $y = -\dfrac{1}{3}x + 1$.

또한 두 직선 $y = ax + 1$과 $y = (2a + 1)x - 1$이 수직이도록 하는 $a$를 구해 봅니다. $a(2a + 1) = -1$이므로 $2a^2 + a + 1 = 0$. 판별식 $D = 1 - 8 < 0$이므로 실수 $a$는 존재하지 않습니다.
