# 거리함수

> **정의** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
두 대상 사이의 떨어진 정도를 수치로 나타내는 함수로, 좌표평면에서는 피타고라스 정리를 이용하여 두 점 사이의 거리를 계산합니다.

## 본문
거리함수(distance function)란 두 점, 또는 점과 도형 사이의 거리를 구하는 함수입니다. 고등학교 수학에서 가장 기본적인 경우는 좌표평면 위의 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ 사이의 거리로, 다음과 같이 정의됩니다:
$$d(P, Q) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
더 일반적으로, 점 $P$와 도형(직선, 원, 평면 등) 사이의 거리는 "점에서 도형 위의 모든 점까지의 거리 중 최솟값"으로 정의합니다. 예를 들어 점 $P(x_0, y_0)$과 직선 $ax + by + c = 0$ 사이의 거리는 다음과 같습니다:
$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미
거리함수는 두 객체가 얼마나 "떨어져 있는지"를 수량화합니다. 피타고라스 정리에 기초하여, 좌표평면의 두 점 사이 거리는 가로 거리와 세로 거리를 직각삼각형의 두 변으로 보았을 때 빗변의 길이와 같습니다. 점과 직선 사이의 거리는 점에서 직선에 내린 수선의 발까지의 거리이며, 이는 직선 위의 다른 어떤 점까지의 거리보다 항상 짧은 최솟값을 의미합니다.

### 기본 성질
- 점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$입니다.

- 점과 직선 사이의 거리가 왜 '최솟값'의 개념을 갖는지 기하학적으로 이해하고 있는가?

## 관련 개념
- **도형의 성질**: 점과 직선 사이의 거리를 이용하면 원의 반지름이나 선분의 수직 이등분선과 같은 도형의 성질을 좌표로 증명할 수 있습니다.
