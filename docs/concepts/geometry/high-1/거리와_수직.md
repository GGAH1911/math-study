### 정확한 진술

점 $P$에서 직선 $\ell$까지의 **거리**는, 점 $P$에서 직선 $\ell$에 내린 **수선의 발** $H$까지의 거리 $|PH|$입니다. 

좌표평면에서 점 $P(x_0, y_0)$과 직선 $\ell: ax + by + c = 0$ $(a^2 + b^2 \neq 0)$이 주어질 때, 거리 $d$는 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관/기하적 의미

점 $P$에서 직선까지의 모든 점들 중에서 가장 가까운 점이 바로 수선의 발 $H$입니다. 이는 $PH$가 직선 $\ell$과 **수직(직교)**이기 때문입니다. 

기하학적으로 보면, 점 $P$에서 직선 위의 다른 점 $Q$로 가는 벡터 $\vec{PQ}$는 항상 직선의 방향 벡터보다 더 길어집니다. 오직 수선을 따라 내려갔을 때만 최단거리가 됩니다. 직선의 법선 벡터(수직 벡터) $(a, b)$ 방향이 바로 거리를 측정하는 가장 효율적인 방향입니다.

### 공식의 직관적 이해

분자 $|ax_0 + by_0 + c|$는 점 $P$를 직선의 법선 벡터 방향으로 '정사영'한 부호 있는 거리이고, 분모 $\sqrt{a^2 + b^2}$는 그 방향의 단위 벡터 크기입니다. 따라서 나눗셈은 **정규화**(normalization) 역할을 합니다.

### 한 줄 예제

점 $(1, 2)$에서 직선 $3x + 4y - 11 = 0$까지의 거리는 $d = \frac{|3(1) + 4(2) - 11|}{\sqrt{9 + 16}} = \frac{|0|}{5} = 0$입니다. (점이 직선 위에 있음)

다른 예: 점 $(0, 0)$에서 직선 $x + y - 2 = 0$까지의 거리는 $d = \frac{|0 + 0 - 2|}{\sqrt{2}} = \sqrt{2}$입니다.
