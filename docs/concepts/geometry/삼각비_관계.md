# 삼각비 관계

> **정리** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
$\sin^2+\cos^2=1$ (직관)

## 본문 (학습 시 채워짐)

### 진술

임의의 각 $\theta$에 대하여 다음이 성립합니다.

$$\sin^2\theta + \cos^2\theta = 1$$

이 식을 **삼각비의 기본 항등식** 또는 **피타고라스 항등식**이라 합니다.

### 증명

직각삼각형에서 유도하면 명확합니다. 빗변의 길이를 $r$, 높이를 $y$, 밑변을 $x$라 할 때:
- $\sin\theta = \frac{y}{r}$
- $\cos\theta = \frac{x}{r}$

따라서
$$\sin^2\theta + \cos^2\theta = \frac{y^2}{r^2} + \frac{x^2}{r^2} = \frac{x^2 + y^2}{r^2}$$

피타고라스 정리에 의해 $x^2 + y^2 = r^2$이므로:
$$\sin^2\theta + \cos^2\theta = \frac{r^2}{r^2} = 1$$

이 결과는 각의 크기와 무관하게 항상 성립합니다.

### 의의와 응용

이 항등식은 삼각함수의 **가장 기본적인 관계식**으로, 한 삼각비를 알면 다른 삼각비를 구할 수 있습니다. 예를 들어 $\sin\theta = 0.6$이면 $\cos^2\theta = 1 - 0.36 = 0.64$에서 $\cos\theta = \pm 0.8$입니다 (`sympy.sqrt(1 - 0.6**2)` → 약 0.8). 부호는 $\theta$가 위치한 사분면에 따라 결정됩니다. 수능 삼각형 문제와 삼각함수 단원에서 가장 자주 활용되는 핵심 성질이며, 고등학교 삼각함수 항등식($\tan^2\theta + 1 = \sec^2\theta$ 등)의 기초가 됩니다.
