# 이차곡선 평행이동

> **예제** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
꼭짓점 이동

## 본문 (학습 시 채워짐)

### 문제

포물선 $y = x^2$을 $x$축 방향으로 3만큼, $y$축 방향으로 $-2$만큼 평행이동한 포물선의 방정식을 구하고, 꼭짓점의 좌표를 찾으세요.

### 단계별 풀이

**1단계: 평행이동의 원리 이해**

점 $(x, y)$를 $x$축 방향으로 $a$, $y$축 방향으로 $b$만큼 평행이동하면 $(x+a, y+b)$로 이동합니다. 역으로, 새 곡선 위의 점 $(x, y)$는 원래 곡선의 점 $(x-a, y-b)$에서 유래했습니다.

**2단계: 방정식 변환**

원래 곡선이 $y = x^2$이므로, 원래 점 $(X, Y)$는 $Y = X^2$를 만족합니다.

새 곡선 위의 점을 $(x, y)$라 하면:
$$X = x - 3, \quad Y = y - (-2) = y + 2$$

원래 관계식 $Y = X^2$에 대입:
$$y + 2 = (x - 3)^2$$

**3단계: 정리**

$$y = (x - 3)^2 - 2$$

전개하면: $y = x^2 - 6x + 7$

꼭짓점은 표준형에서 직접 읽을 수 있습니다.

### 답

**방정식**: $y = (x-3)^2 - 2$ (또는 전개형 $y = x^2 - 6x + 7$)

**꼭짓점**: $(3, -2)$

### 변형·주의

- **꼭짓점 형태의 활용**: $y = a(x-h)^2 + k$ 형태에서 꼭짓점은 항상 $(h, k)$입니다. 이를 암기하면 평행이동 문제에서 빠르게 풀 수 있습니다.

- **부호 실수 방지**: "$x$축 방향으로 양수 이동"은 방정식에서 $(x - \text{양수})$ 형태가 됩니다. 직관과 반대로 느껴질 수 있으니 주의하세요.

- **다른 이차곡선**: 원 $x^2 + y^2 = r^2$을 같이 평행이동하면 $(x-3)^2 + (y+2)^2 = r^2$ (중심이 $(3, -2)$로 이동)

- **검증** (sympy): `sympy.expand((x - 3)**2 - 2)` → $x^2 - 6x + 7$ ✓
