### 정확한 진술

두 도형의 **교점(intersection point)**은 두 도형을 나타내는 방정식을 동시에 만족하는 점입니다. **교점조건**이란 두 도형이 만나는 점이 존재하고, 만나는 점의 개수가 정해진 조건을 말합니다. 예를 들어 직선 $L_1: ax + by + c = 0$과 직선 $L_2: dx + ey + f = 0$의 교점은 다음 연립방정식을 풀어 구합니다:

$$\begin{cases} ax + by + c = 0 \\ dx + ey + f = 0 \end{cases}$$

이 연립방정식이 유일한 해를 가지면 교점이 정확히 1개, 부정형 해를 가지면 두 직선이 일치(무수히 많은 교점), 불능이면 평행(교점 없음)입니다.

### 직관과 기하적 의미

기하학적으로 교점조건은 "두 도형이 만나는가, 만나면 어디서 몇 번 만나는가"를 판단하는 도구입니다. 직선과 원의 경우, 원의 중심에서 직선까지의 거리 $d$와 반지름 $r$을 비교하면:
- $d < r$: 교점 2개
- $d = r$: 교점 1개(접함)
- $d > r$: 교점 없음

이런 기하적 직관을 대수적으로 검증할 수 있으며, 매개변수를 포함한 복잡한 도형에서도 판별식이나 연립방정식의 성질로 교점 개수를 판정할 수 있습니다.

### 한 줄 예

직선 $y = x + 1$과 원 $x^2 + y^2 = 5$의 교점은 $x^2 + (x+1)^2 = 5$를 풀어 $(1, 2)$와 $(-2, -1)$ 두 점입니다. (`sympy.solve(x**2 + (x+1)**2 - 5, x)`)
