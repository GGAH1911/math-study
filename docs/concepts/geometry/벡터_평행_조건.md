### 정확한 진술

두 벡터 $\vec{a}$, $\vec{b}$가 **평행**하다는 것은, 한 벡터가 다른 벡터의 0이 아닌 실수배로 표현될 때를 말합니다. 즉:

$$\vec{a} \parallel \vec{b} \Leftrightarrow \vec{a} = k\vec{b} \text{ (단, } k \neq 0 \text{인 실수)}$$

평면에서 성분으로 나타낼 때, $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$이면 평행 조건은:
$$a_1 b_2 - a_2 b_1 = 0$$

이를 성분의 비로 나타내면 (분모가 0이 아닐 때):
$$\frac{a_1}{b_1} = \frac{a_2}{b_2}$$

### 직관과 기하적 의미

두 벡터가 평행하다는 것은 기하학적으로 **같은 직선 위의 방향을 가진다**는 뜻입니다. 두 벡터를 같은 시점에서 그렸을 때 정확히 같은 직선 위에 놓인다는 의미입니다. $k > 0$이면 두 벡터의 방향이 같고, $k < 0$이면 정반대입니다. 성분식 $a_1 b_2 - a_2 b_1 = 0$은 두 벡터로 만든 평행사변형의 넓이가 0이 된다는 뜻인데, 이는 두 벡터가 실제로 완전히 일직선을 이룬다는 조건을 수식으로 표현한 것입니다. 이 식은 행렬식(determinant)으로도 나타낼 수 있습니다.

### 한 줄 예

$\vec{p} = (2, 4)$와 $\vec{q} = (-1, -2)$는 $2 \times (-2) - 4 \times (-1) = 0$을 만족하므로 평행합니다($\vec{p} = -2\vec{q}$).
