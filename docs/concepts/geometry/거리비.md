### 정확한 진술

거리비(eccentricity)는 이차곡선 위의 임의의 점에서 초점(focus)까지의 거리와 준선(directrix)까지의 거리의 비로 정의됩니다. 기호로 $e$를 사용하며, 다음과 같이 나타냅니다:

$$e = \frac{\text{초점까지의 거리}}{\text{준선까지의 거리}}$$

이 값은 이차곡선의 종류를 결정하는 핵심 성질입니다:
- $e = 1$일 때: 포물선
- $0 < e < 1$일 때: 타원
- $e > 1$일 때: 쌍곡선

### 직관 및 기하적 의미

거리비는 이차곡선이 "얼마나 길쭉한지" 또는 "초점이 얼마나 치우쳐 있는지"를 측정하는 척도입니다.

**타원에서** ($0 < e < 1$): $e$가 0에 가까울수록 원에 가까워지고, 1에 가까워질수록 납작해집니다. 예를 들어 $e = 0.6$인 타원은 $e = 0.9$인 타원보다 원에 더 가깝습니다.

**포물선에서** ($e = 1$): 초점과 준선의 거리 관계가 정확히 균형을 이루어, 한 방향으로 무한히 열린 곡선이 됩니다.

**쌍곡선에서** ($e > 1$): $e$가 1에 가까울수록 가지가 덜 벌어지고, 클수록 더 벌어집니다.

### 표준형에서의 계산

타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b$)에서: $e = \frac{\sqrt{a^2-b^2}}{a} = \frac{c}{a}$

쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$에서: $e = \frac{\sqrt{a^2+b^2}}{a} = \frac{c}{a}$

**예**: 타원 $\frac{x^2}{25} + \frac{y^2}{9} = 1$의 거리비는 $e = \frac{\sqrt{25-9}}{5} = \frac{4}{5} = 0.8$입니다.
