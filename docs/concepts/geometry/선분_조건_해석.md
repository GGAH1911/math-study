### 정확한 진술

좌표평면 위의 두 점 $A(a_1, a_2)$, $B(b_1, b_2)$에 대해, **선분 AB**는 다음 조건을 만족하는 점들의 집합입니다:

$$P = A + t(B - A), \quad 0 \le t \le 1$$

또는 성분으로 나타내면:
$$x = a_1 + t(b_1 - a_1), \quad y = a_2 + t(b_2 - a_2), \quad 0 \le t \le 1$$

### 직관과 기하적 의미

매개변수 $t$는 선분 AB를 몇 등분했을 때의 위치를 나타냅니다. $t = 0$일 때 점 A, $t = 1$일 때 점 B에 도달하고, $0 < t < 1$인 값들은 A와 B 사이의 모든 점을 나타냅니다. 

직관적으로, $t$를 "A에서 출발해 B로 향하는 진행도"로 볼 수 있습니다. 거리 조건으로도 해석할 수 있는데, 선분 AB 위의 점 P는 $|AP| + |PB| = |AB|$를 만족합니다. 즉, A에서 P까지의 거리와 P에서 B까지의 거리의 합이 전체 거리와 같다는 뜻입니다.

### 한 줄 예

$A(1, 2)$, $B(5, 6)$일 때 선분의 중점은 $t = 0.5$를 대입하면 $P(3, 4)$입니다. 일반적으로 $t$ 값이 내분점의 비율을 결정하므로, $t = \frac{m}{m+n}$이면 점 P는 선분 AB를 $m:n$으로 내분합니다.
