# 초점의 거리

### 정의

초점의 거리는 이차곡선의 두 초점 사이의 거리를 의미합니다. 표기는 보통 $2c$입니다. 여기서 $c$는 이차곡선의 매개변수로, 각 곡선의 종류에 따라 정의되는 방식이 다릅니다.

**타원** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b > 0$)에서:
$$c = \sqrt{a^2 - b^2}, \quad \text{초점의 거리} = 2c$$

**쌍곡선** $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ (단, $a > 0, b > 0$)에서:
$$c = \sqrt{a^2 + b^2}, \quad \text{초점의 거리} = 2c$$

### 기하적 의미

초점의 거리는 이차곡선의 "벌어짐 정도"를 나타냅니다. 타원의 경우, 초점의 거리가 작을수록 원에 가까워지고, 클수록 길쭉해집니다. 쌍곡선의 경우, 초점의 거리가 작을수록 두 가지(branch)가 가깝고, 클수록 멀어집니다. 이는 곡선의 이심률(eccentricity) $e = \frac{c}{a}$와도 밀접한 관련이 있습니다.

### 예제

타원 $\frac{x^2}{100} + \frac{y^2}{64} = 1$에서:
- $a^2 = 100, b^2 = 64$이므로 $c^2 = 100 - 64 = 36$
- $c = 6$
- **초점의 거리 = $2c = 12$**

초점은 $(-6, 0)$과 $(6, 0)$이며, 두 점 사이의 거리가 정확히 12입니다. ✓
