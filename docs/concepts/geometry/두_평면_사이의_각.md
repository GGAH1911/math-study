### 정확한 진술

두 평면 사이의 각은 두 평면의 법선벡터가 이루는 각으로 정의합니다. 

평면의 방정식이 $ax + by + cz = d$로 주어질 때, 법선벡터는 $\vec{n} = (a, b, c)$입니다. 두 평면의 법선벡터를 각각 $\vec{n_1}$, $\vec{n_2}$라 하면, 두 평면이 이루는 각 $\theta$ ($0 \leq \theta \leq \frac{\pi}{2}$)는 다음 식으로 구합니다:

$$\cos \theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}| \cdot |\vec{n_2}|}$$

분자에 절댓값을 붙이는 이유는 두 평면 사이의 각을 항상 예각(0°부터 90°) 범위로 정의하기 때문입니다.

### 직관/기하적 의미

평면은 법선벡터 하나로 완전히 결정됩니다. 두 평면이 만날 때 실제로 만나는 기하학적 각도는 각 평면에 수직인 방향, 즉 법선벡터들이 이루는 각으로 측정하는 것이 가장 자연스럽습니다.

예를 들어 벽과 바닥이 만나는 모서리를 생각해보면, 벽에 수직인 화살표와 바닥에 수직인 화살표가 이루는 각이 바로 벽과 바닥이 만드는 각도입니다.

### 한 줄 예

평면 $2x + y - z = 3$과 평면 $x - 2y + 2z = 1$ 사이의 각을 구할 때, 법선벡터는 각각 $(2, 1, -1)$과 $(1, -2, 2)$이므로:

$$\cos \theta = \frac{|(2)(1) + (1)(-2) + (-1)(2)|}{\sqrt{4+1+1} \cdot \sqrt{1+4+4}} = \frac{|2-2-2|}{\sqrt{6} \cdot 3} = \frac{2}{3\sqrt{6}} = \frac{\sqrt{6}}{9}$$

따라서 $\theta = \arccos \frac{\sqrt{6}}{9}$ (약 61°)입니다.

```python
import sympy as sp
n1 = sp.Matrix([2, 1, -1])
n2 = sp.Matrix([1, -2, 2])
cos_theta = abs(n1.dot(n2)) / (n1.norm() * n2.norm())
theta_deg = float(sp.acos(cos_theta) * 180 / sp.pi)
print(f"θ ≈ {theta_deg:.1f}°")  # θ ≈ 61.1°
```
