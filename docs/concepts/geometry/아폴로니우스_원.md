### 정확한 진술

두 점 $A$, $B$와 양수 $k$ ($k \neq 1$)에 대해, 다음을 만족하는 점 $P$의 집합을 **아폴로니우스 원**(Apollonius circle)이라 합니다:

$$\frac{|PA|}{|PB|} = k$$

즉, 두 정점으로부터의 거리의 비가 상수인 모든 점들이 이루는 도형입니다.

### 직관과 기하적 의미

이 원은 두 점 사이에서 '같은 비율'을 유지하는 균형점들의 자취입니다. 예를 들어 $k = 2$이면, 점 $P$는 항상 $A$보다 $B$로부터 절반 거리에 있어야 합니다. 이런 조건을 따라 움직이면 자연스럽게 원이 만들어집니다. $k = 1$일 때는 두 점의 수직이등분선(직선)이 되므로, $k \neq 1$일 때만 원입니다.

### 구체적 예시와 원의 방정식

$A(0, 0)$, $B(3, 0)$이고 $k = 2$인 경우를 봅시다.

점 $P(x, y)$에 대해:
$$\sqrt{x^2 + y^2} = 2\sqrt{(x-3)^2 + y^2}$$

양변을 제곱하면:
$$x^2 + y^2 = 4[(x-3)^2 + y^2]$$
$$x^2 + y^2 = 4x^2 - 24x + 36 + 4y^2$$
$$3x^2 + 3y^2 - 24x + 36 = 0$$
$$x^2 + y^2 - 8x + 12 = 0$$
$$(x-4)^2 + y^2 = 4$$

중심 $(4, 0)$, 반지름 $2$인 원입니다. (검증: `sympy.solve([x**2 + y**2 - 8*x + 12], x)`)

**핵심**: 거리의 비 조건은 대수적으로 이차방정식을 만들어 원을 결정합니다.
