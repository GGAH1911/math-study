### 정확한 진술

최솟값 최적화란 주어진 제약 조건 하에서 특정 량(주로 거리)을 최소화하는 점이나 경로를 찾는 것입니다. 공간에서 조건을 만족하는 모든 점 중에서 목적 함수(거리, 길이, 면적 등)의 값이 가장 작은 경우를 구하는 문제입니다. 예를 들어, 점 $P$에서 평면 $\alpha$ 위의 점들까지의 거리 중 가장 짧은 값을 구하는 것이 최솟값 최적화입니다.

### 직관과 기하적 의미

공간에서 제약 조건은 주로 평면, 직선, 곡면 같은 기하도형으로 나타납니다. 목적함수는 이 도형 위의 점과 기준점(또는 기준도형) 사이의 거리입니다. 최솟값을 달성하는 점은 항상 특별한 위치에 있는데, 점에서 평면까지의 최단거리라면 평면에 수직인 방향의 교점이 됩니다. 벡터의 관점에서 보면, 목적함수는 벡터 크기(노름)이고, 제약조건은 벡터가 만족해야 할 기하학적 성질입니다. 최솟값 문제는 "조건을 지키면서 무언가를 가장 효율적으로 하려면?" 같은 실무적 질문의 수학적 표현입니다.

### 한 줄 예

점 $P(1, 2, 3)$에서 평면 $2x + y - 2z = 1$까지의 최단거리는 $\frac{|2(1) + 2 - 2(3) - 1|}{\sqrt{4+1+4}} = \frac{|-5|}{3} = \frac{5}{3}$이며, 이는 점 $P$에서 평면의 법선벡터 $(2, 1, -2)$ 방향으로 수선을 그었을 때 교점까지의 거리입니다. ✓ `from sympy import point, plane; p = (1, 2, 3); distance = abs(2*1 + 1*2 - 2*3 - 1) / (2**2 + 1**2 + (-2)**2)**0.5`
