### 정확한 진술

초점거리(focal distance)는 이차곡선을 정의하는 두 초점 사이의 거리를 뜻합니다. 타원과 쌍곡선에서는 이 거리를 보통 $2c$로 표기하며, 여기서 $c$는 중심에서 각 초점까지의 거리입니다. 포물선의 경우 초점과 준선 사이의 거리를 초점거리의 개념으로 다루며, 이를 $2p$로 나타냅니다.

### 직관과 기하적 의미

이차곡선의 초점들은 곡선의 '형태'를 결정하는 핵심 요소입니다. 초점거리가 클수록 곡선은 더 "퍼진" 형태를 가집니다. 예를 들어 타원에서 초점거리 $2c$가 커질수록 타원은 원에서 멀어지고 납작해집니다. 반대로 쌍곡선에서 초점거리가 크면 두 가지가 더 멀리 떨어집니다.

또한 초점거리는 곡선의 **이심률(eccentricity)** $e$와 밀접한 관계가 있습니다. 타원에서는 $e = \frac{c}{a}$ (단, $a$는 장축의 반길이)이고, 쌍곡선에서도 $e = \frac{c}{a}$ (단, $a$는 꼭짓점까지의 거리)입니다. 이심률이 고정되어 있을 때 초점거리가 커지면 전체 곡선도 함께 커집니다.

### 구체적 예시

타원 $\displaystyle \frac{x^2}{25} + \frac{y^2}{9} = 1$에서 $a=5$, $b=3$이므로 $c = \sqrt{a^2 - b^2} = \sqrt{25-9} = 4$이고, 초점거리는 $2c = 8$입니다. 초점은 $(\pm 4, 0)$에 위치합니다.

쌍곡선 $\displaystyle \frac{x^2}{16} - \frac{y^2}{9} = 1$에서 $a=4$, $b=3$이므로 $c = \sqrt{a^2+b^2} = 5$이고, 초점거리는 $2c = 10$입니다.
