### 정확한 진술

두 포물선의 방정식이 각각 $y = a_1x^2 + b_1x + c_1$과 $y = a_2x^2 + b_2x + c_2$일 때, **포물선의 교점**은 두 방정식을 동시에 만족하는 점 $(x, y)$를 말합니다. 즉, $a_1x^2 + b_1x + c_1 = a_2x^2 + b_2x + c_2$를 풀어 $x$ 좌표를 구하고, 이를 원래 방정식에 대입하여 $y$ 좌표를 구합니다.

### 직관과 기하적 의미

평면 위의 두 포물선이 만나는 점이 교점입니다. 곡선 간의 상대적 위치에 따라 교점의 개수가 결정됩니다. 두 포물선의 방정식을 연립하면 이차방정식이 되므로, **판별식**에 따라:
- **판별식 > 0**: 서로 다른 2개의 교점 (두 포물선이 두 점에서 만남)
- **판별식 = 0**: 1개의 교점 (한 점에서 접함)
- **판별식 < 0**: 교점 없음 (만나지 않음)

### 한 줄 예

$y = x^2$과 $y = -x^2 + 4$의 교점을 찾으려면, $x^2 = -x^2 + 4$에서 $2x^2 = 4$, 즉 $x = \pm\sqrt{2}$이고, 두 교점은 $(\sqrt{2}, 2)$와 $(-\sqrt{2}, 2)$입니다. (`sympy.solve(x**2 - (-x**2 + 4), x)` → $x = -\sqrt{2}, \sqrt{2}$)
