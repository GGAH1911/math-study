### 정확한 진술

평면 위의 두 직선이 **평행**하다는 것은, 아무리 연장해도 교점을 갖지 않는다는 뜻입니다. 기울기가 존재하는 두 직선 $\ell_1: y = m_1x + b_1$과 $\ell_2: y = m_2x + b_2$가 평행할 필요충분조건은 다음과 같습니다:

$$m_1 = m_2 \text{ 이고 } b_1 \neq b_2$$

즉, **기울기가 같으면서 $y$절편이 다르면** 두 직선은 평행합니다.

### 직관/기하적 의미

기울기는 직선이 얼마나 가파르게 올라가거나 내려가는지를 나타냅니다. 두 직선의 기울기가 같다는 것은 두 직선이 같은 방향을 바라본다는 의미입니다. 

생각해 보세요: 만약 두 직선의 기울기가 다르다면, 아무리 멀리 연장해도 언젠가는 만나게 됩니다. 하지만 기울기가 같으면 두 직선은 항상 같은 각도를 유지하므로 영원히 만나지 않습니다. 이것이 평행의 본질입니다.

한편, 기울기가 존재하지 않는 경우도 있습니다. 수직선 $x = a$와 $x = c$ (단, $a \neq c$)도 평행합니다. 이 경우 "기울기"라는 표현 대신 "방향이 같다"고 말합니다.

### 한 줄 예

$y = 2x + 1$과 $y = 2x - 3$은 기울기가 모두 2로 같고 $y$절편이 다르므로 평행합니다.

### 판정법 (보충)

일반형 $ax + by + c = 0$과 $a'x + b'y + c' = 0$의 경우, 두 직선이 평행할 필요충분조건은:

$$\frac{a}{a'} = \frac{b}{b'} \neq \frac{c}{c'} \text{ (단, } a', b', c' \neq 0\text{)}$$

구체 예: $2x - 3y + 1 = 0$과 $4x - 6y - 5 = 0$은 $\frac{2}{4} = \frac{-3}{-6} = \frac{1}{2}$이지만 $\frac{1}{-5} \neq \frac{1}{2}$이므로 평행합니다. (`sympy: from sympy import symbols, solve; x, y = symbols('x y'); solve([2*x - 3*y + 1, 4*x - 6*y - 5], [x, y])` → 해 없음 = 평행)
