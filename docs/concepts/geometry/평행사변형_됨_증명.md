# 평행사변형 됨 증명

> **예제** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
주어진 조건으로 증명

## 본문 (학습 시 채워짐)

### 문제

사각형 ABCD의 대각선 AC와 BD가 점 O에서 만난다. 다음 조건을 만족할 때, 사각형 ABCD가 평행사변형임을 증명하시오.

**조건:** $AO = OC$이고 $BO = OD$

### 단계별 풀이

**1단계: 비교할 삼각형 선택**

삼각형 AOB와 삼각형 COD를 살펴봅니다. 대각선의 교점을 기준으로 마주보는 두 삼각형이므로 합동을 보이는 데 유리합니다.

**2단계: SAS 합동 증명**

삼각형 AOB와 삼각형 COD에서:
- $AO = OC$ (주어진 조건)
- $\angle AOB = \angle COD$ (맞꼭지각)
- $BO = OD$ (주어진 조건)

따라서 SAS 합동 조건에 의해 $\triangle AOB \equiv \triangle COD$

**3단계: 엇각 이용하여 한 쌍의 대변 평행 증명**

두 삼각형이 합동이므로 대응각이 같습니다:
$$\angle OAB = \angle OCD$$

이 두 각은 직선 AC를 가로지르는 AB와 DC의 엇각이므로:
$$AB \parallel DC$$

**4단계: 나머지 대변 평행 증명**

마찬가지로 삼각형 AOD와 삼각형 COB의 합동(SAS)에서:
$$\angle OAD = \angle OCB$$

따라서 $AD \parallel BC$

**5단계: 평행사변형 확정**

두 쌍의 대변이 각각 평행하므로 ABCD는 평행사변형입니다.

### 답

**사각형 ABCD는 평행사변형이다.** ✓

### 변형/주의

**유사 조건들:**
- 대각선이 서로를 이등분하면 평행사변형 (이 문제)
- 한 쌍의 대변이 평행하고 길이가 같으면 평행사변형
- 두 쌍의 대변의 길이가 각각 같으면 평행사변형

**주의점:**
합동 조건(SAS, ASA, SSS)을 정확히 맞춰야 합니다. 이 문제에서 맞꼭지각 $\angle AOB = \angle COD$가 "그 사이의 각"이 되려면 양쪽에 두 쌍의 변이 있어야 함을 확인하세요.
