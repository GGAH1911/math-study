### 정확한 진술

점의 자취(locus)는 특정 기하학적 조건을 만족하는 모든 점들의 집합입니다. 평면 위의 점 $P(x, y)$가 만족하는 조건을 방정식으로 나타낸 것을 점의 자취의 방정식이라 합니다. 직선은 점의 자취의 가장 기본적인 예로, 일차 방정식 $ax + by + c = 0$ (단, $a^2 + b^2 \neq 0$)으로 표현됩니다.

### 직관/기하적 의미

점의 자취를 구한다는 것은 특정 조건 아래에서 점이 그리는 도형의 방정식을 찾는 과정입니다. 예를 들어, "고정점으로부터 거리가 일정한 점들의 집합"은 원을, "두 고정점으로부터 거리의 합이 일정한 점들"은 타원을 나타냅니다. 직선은 기울기와 한 점, 또는 두 점의 좌표로 유일하게 결정됩니다. 벡터로 표현하면 직선 위의 점 $\vec{r}(t) = \vec{a} + t\vec{d}$ (방향벡터 $\vec{d}$, 매개변수 $t$)의 형태이며, 직교좌표로 변환하면 일차 방정식이 됩니다. 이렇게 대수적 조건과 기하학적 도형의 대응 관계를 이해하는 것이 평면벡터와 해석기하의 핵심입니다.

### 한 줄 예

점 $A(1, 2)$와 $B(5, 4)$를 지나는 직선의 자취: 기울기는 $m = \frac{4-2}{5-1} = \frac{1}{2}$이므로, 점-기울기 형태 $y - 2 = \frac{1}{2}(x - 1)$을 정리하면 $x - 2y + 3 = 0$입니다. (검증: `sympy.solve([1 - 2*2 + 3, 5 - 2*4 + 3])` → 두 점 모두 방정식을 만족함)
