# 삼각형의 각의 성질

## 정확한 진술

삼각형의 세 내각의 합은 항상 $180°$ 또는 $\pi$ 라디안이다. 삼각형 $\triangle ABC$에서 $\angle A + \angle B + \angle C = 180°$가 성립한다.

또한 삼각형의 **외각**(한 변을 연장했을 때 만드는 각)은 자신과 인접하지 않은 두 내각(원격 내각)의 합과 같다. 예를 들어 변 $BC$를 $C$ 너머로 연장할 때 생기는 외각은 $\angle A + \angle B$이다.

## 직관과 기하적 의미

삼각형 내각의 합이 180°라는 성질은 평면 기하의 가장 기본적인 사실이다. 이를 직관적으로 이해하려면, 한 꼭짓점에서 출발하여 삼각형의 변을 따라 한 바퀴 도는 모습을 생각해보자. 각 꼭짓점에서 방향을 $\angle A$, $\angle B$, $\angle C$만큼 꺾으면서 원래 위치로 돌아오는데, 이 세 회전각의 합이 정확히 한 바퀴(180°)가 되어야 닫힌 도형이 완성된다.

외각의 성질은 내각의 합으로부터 바로 유도된다. 한 꼭짓점에서의 내각과 외각은 일직선을 이루므로 합이 180°이고, 나머지 두 내각의 합도 180° 빼기 한 내각이므로 정확히 외각과 같다.

## 예시

삼각형의 세 내각이 $60°$, $70°$, $50°$일 때, $60° + 70° + 50° = 180°$이다. 이 삼각형에서 한 변을 연장하여 만든 외각은 $60° + 70° = 130°$ 또는 $60° + 50° = 110°$ 또는 $70° + 50° = 120°$이 되며, 각각의 경우 내각과 외각의 합은 항상 180°이다.
