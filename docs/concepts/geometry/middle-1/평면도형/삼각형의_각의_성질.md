# 삼각형의 각의 성질

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
삼각형의 세 내각의 합은 항상 $180^{\circ}$이며, 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같다.

## 본문
삼각형 $\triangle ABC$에서 세 내각의 크기의 합인 $\angle A + \angle B + \angle C$는 항상 $180^{\circ}$ 또는 $\pi$ 라디안이다. 또한 삼각형의 한 변을 연장했을 때 생기는 외각의 크기는 그와 인접하지 않은 나머지 두 내각(원격 내각)의 크기를 합한 것과 같다. 예를 들어 변 $BC$를 $C$ 방향으로 연장하여 만든 외각의 크기는 $\angle A + \angle B$와 같다.

### 직관과 기하적 의미
삼각형 내각의 합이 $180^{\circ}$라는 사실은 평면 기하의 근본적인 원리이다. 이를 직관적으로 이해하기 위해 삼각형의 변을 따라 한 바퀴를 도는 과정을 상상해 보자. 각 꼭짓점에 도달할 때마다 방향을 $\angle A, \angle B, \angle C$만큼 회전하며 이동하여 원래 위치와 방향으로 돌아오게 되는데, 이때 발생하는 회전각의 총합이 평면에서 한 바퀴를 도는 각도인 $180^{\circ}$가 되어야 도형이 닫히게 된다. 외각의 성질은 내각과 외각이 일직선상에 있어 합이 $180^{\circ}$라는 점과 내각의 합이 $180^{\circ}$라는 점을 결합하여 유도할 수 있다.

### 기본 성질
삼각형의 세 내각이 $60^{\circ}, 70^{\circ}, 50^{\circ}$인 경우, 세 각의 합은 $60^{\circ} + 70^{\circ} + 50^{\circ} = 180^{\circ}$로 성립한다. 이때 각 변을 연장하여 만든 외각은 각각 $60^{\circ} + 70^{\circ} = 130^{\circ}$, $60^{\circ} + 50^{\circ} = 110^{\circ}$, $70^{\circ} + 50^{\circ} = 120^{\circ}$가 된다. 어떤 경우에도 해당 꼭짓점의 내각과 외각의 합은 항상 $180^{\circ}$를 유지한다.

## 학습 체크
- 삼각형의 세 내각의 합이 $180^{\circ}$임을 이용하여 알지 못하는 한 각의 크기를 구할 수 있는가?
- 외각의 크기를 구할 때 이웃한 내각을 제외한 나머지 두 내각의 합을 이용할 수 있는가?

## 관련 개념
- **도형의 성질**: 삼각형의 내각과 외각의 관계는 평면도형을 구성하는 가장 기초적인 성질 중 하나이다.
