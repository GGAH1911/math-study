# 거리

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
두 점 사이의 거리는 두 점을 잇는 최단 경로의 길이를 의미하며, 좌표평면 위에서는 피타고라스 정리를 이용하여 계산합니다.

## 본문
평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음과 같이 정의됩니다.
$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
이를 두 점 사이의 거리 공식이라 하며, $|AB|$로 표기합니다. 만약 한 점이 원점 $O(0, 0)$이라면, 점 $P(x, y)$와 원점 사이의 거리는 $|OP| = \sqrt{x^2 + y^2}$이 됩니다.

### 직관과 기하적 의미
거리는 두 점을 잇는 가장 짧은 선분의 길이를 뜻합니다. 이 공식은 피타고라스 정리에서 유도됩니다. 두 점 $A$와 $B$를 빗변으로 하는 직각삼각형을 상상하면, 가로의 길이는 두 $x$좌표의 차이인 $|x_2 - x_1|$이 되고, 세로의 길이는 두 $y$좌표의 차이인 $|y_2 - y_1|$이 됩니다. 이때 빗변의 길이인 $|AB|$를 구하는 과정이 곧 거리 공식과 일치합니다.

### 기본 성질
거리는 다음과 같은 수학적 성질을 가집니다.
- 거리는 항상 0보다 크거나 같습니다 ($d(A, B) \geq 0$).
- 두 점이 같은 위치에 있을 때만 거리가 0입니다 ($d(A, B) = 0 \Leftrightarrow A = B$).
- $A$에서 $B$까지의 거리와 $B$에서 $A$까지의 거리는 같습니다 ($d(A, B) = d(B, A)$).
- 한 점을 거쳐 가는 거리보다 직접 가는 거리가 항상 짧거나 같습니다 ($d(A, C) \leq d(A, B) + d(B, C)$).

## 학습 체크
- 두 점의 좌표가 주어졌을 때, 피타고라스 정리를 이용하여 거리를 구할 수 있는가?
- 원점과 임의의 점 사이의 거리를 구할 때 공식이 어떻게 단순화되는지 이해하고 있는가?
- 삼각부등식의 의미를 기하학적인 경로의 관점에서 설명할 수 있는가?

## 관련 개념
- **평면도형**: 좌표평면 위의 점들을 연결하여 삼각형이나 사각형 같은 도형을 만들 때, 각 변의 길이를 구하는 기초가 됩니다.
