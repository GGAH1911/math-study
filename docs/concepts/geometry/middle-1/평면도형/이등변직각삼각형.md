# 이등변직각삼각형

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 정확한 진술

이등변직각삼각형은 **두 다리(직각을 이루는 두 변)의 길이가 같은 직각삼각형**입니다. 직각을 $\angle C = 90°$라 하고, 두 다리를 $CA = CB = a$라 하면, 빗변의 길이는 피타고라스 정리에 의해 $AB = a\sqrt{2}$입니다. 또한 두 예각의 크기는 모두 $45°$이므로, 이 삼각형은 **$45°$-$45°$-$90°$ 직각삼각형**으로도 불립니다.

## 직관/기하적 의미

이등변직각삼각형은 가장 대칭적인 직각삼각형입니다. 직각의 꼭짓점에서 빗변에 내린 수선은 빗변의 중점을 지나고 빗변을 이등분하므로, 두 작은 이등변직각삼각형으로 나뉩니다. 수능과 고등수학에서 각도와 변의 길이 관계가 명확하므로 **특수각 삼각형**으로 자주 등장합니다. 다리의 길이가 $a$일 때, 빗변의 길이는 항상 $a\sqrt{2}$이므로 **변의 비 $1 : 1 : \sqrt{2}$**를 외우면 여러 계산을 빠르게 할 수 있습니다.

## 한 줄 예

다리의 길이가 각각 3인 이등변직각삼각형의 빗변은 $3\sqrt{2}$입니다. 
```python
# sympy를 이용한 검산
import sympy as sp
a = 3
hypotenuse = sp.sqrt(a**2 + a**2)
print(hypotenuse)  # 3*sqrt(2)
```
