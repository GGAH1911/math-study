# 사각형의 내각의 합

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
모든 사각형의 네 내각의 크기를 모두 더하면 항상 $360^{\circ}$가 됩니다.

## 본문
모든 사각형의 내각의 합은 $360^{\circ}$입니다. 즉, 사각형 $ABCD$의 네 내각을 $\angle A, \angle B, \angle C, \angle D$라고 할 때, $\angle A + \angle B + \angle C + \angle D = 360^{\circ}$라는 식이 항상 성립합니다. 이러한 성질은 일반적인 볼록 사각형뿐만 아니라 오목한 형태의 사각형에서도 동일하게 적용되는 사각형의 기본적인 성질입니다.

### 직관과 기하적 의미
사각형을 한 대각선으로 나누면 두 개의 삼각형으로 분할할 수 있습니다. 삼각형의 내각의 합이 $180^{\circ}$이므로, 두 삼각형의 내각을 모두 더하면 $180^{\circ} + 180^{\circ} = 360^{\circ}$가 되어 사각형의 내각의 합과 일치하게 됩니다. 기하학적으로는 사각형의 한 꼭짓점에서 출발하여 모든 변을 따라 한 바퀴 돌아 제자리로 돌아올 때 발생하는 회전각의 총합이 $360^{\circ}$라는 평면의 완전한 회전 원리를 나타내기도 합니다.

### 기본 성질
정사각형의 경우 네 내각이 모두 $90^{\circ}$이므로 $90^{\circ} \times 4 = 360^{\circ}$가 되어 이 성질을 만족합니다. 또한 사다리꼴에서 세 각의 크기가 각각 $120^{\circ}, 95^{\circ}, 85^{\circ}$로 주어졌다면, 나머지 한 각은 전체 합인 $360^{\circ}$에서 세 각의 합인 $300^{\circ}$를 뺀 $60^{\circ}$가 되어야 합니다.

## 학습 체크
- 사각형을 대각선으로 나누었을 때 나타나는 삼각형의 개수와 내각의 합 사이의 관계를 이해하고 있는가?
- 오목 사각형에서도 내각의 합이 $360^{\circ}$가 되는 이유를 삼각형의 분할을 통해 설명할 수 있는가?
- 주어진 세 각의 크기를 알 때, 나머지 한 각의 크기를 구할 수 있는가?

## 관련 개념
- **원의 성질**: 원에 내접하는 사각형의 경우, 이 기본 성질을 바탕으로 이웃한 두 대각의 합이 항상 $180^{\circ}$가 된다는 특별한 성질을 가집니다.
