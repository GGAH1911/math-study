# 각도 조건

## 정확한 진술

평면의 다각형에서 **내각의 합**은 다음과 같이 결정됩니다. 변의 개수가 $n$인 다각형의 모든 내각을 더하면 $(n-2) \times 180°$입니다. 특히 삼각형($n=3$)은 $180°$, 사각형($n=4$)은 $360°$, 오각형($n=5$)은 $540°$입니다.

또한 **외각의 합**은 모든 볼록 다각형에서 항상 $360°$입니다.

## 직관과 기하적 의미

다각형의 내각 합 공식은 다음과 같이 이해할 수 있습니다. 한 꼭짓점에서 모든 대각선을 그으면 $n$각형이 $(n-2)$개의 삼각형으로 나뉩니다. 삼각형 하나의 내각 합이 $180°$이므로, 전체 합은 $(n-2) \times 180°$입니다.

외각의 합이 항상 $360°$인 이유는 다각형 둘레를 한 바퀴 따라가며 회전할 때 원점으로 돌아오기 때문입니다. 각 꼭짓점에서 돌린 각도의 총합이 정확히 한 바퀴, 즉 $360°$가 되는 원리입니다.

## 한 줄 예

육각형의 내각의 합은 $(6-2) \times 180° = 720°$이고, 정육각형이라면 각 내각은 $\frac{720°}{6} = 120°$입니다.

## 실제 계산

삼각형 세 각이 $50°, 70°, \alpha$일 때, $50 + 70 + \alpha = 180$이므로 $\alpha = 60°$입니다. 이때 삼각형의 각 꼭짓점의 외각은 순서대로 $130°, 110°, 120°$이고, 합은 $130 + 110 + 120 = 360°$입니다.
