# 사각형의 넓이

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
사각형의 넓이는 평면상의 네 꼭짓점으로 이루어진 닫힌 도형이 차지하는 면적을 의미하며, 좌표를 알 때 신발끈 공식을 통해 구할 수 있습니다.

## 본문
사각형의 넓이는 평면상의 네 개의 꼭짓점으로 이루어진 닫힌 도형이 차지하는 면적입니다. 좌표평면에서 사각형의 네 꼭짓점을 $A(x_1, y_1), B(x_2, y_2), C(x_3, y_3), D(x_4, y_4)$로 나타낼 때, 신발끈 공식을 이용하여 다음과 같이 구할 수 있습니다.

$$\text{넓이} = \frac{1}{2} |x_1(y_2 - y_4) + x_2(y_3 - y_1) + x_3(y_4 - y_2) + x_4(y_1 - y_3)|$$

특히 축에 평행한 직사각형의 경우, 가로 길이를 $a$, 세로 길이를 $b$라고 하면 넓이는 단순히 $ab$가 됩니다.

### 직관과 기하적 의미
사각형의 넓이는 해당 도형이 좌표평면상에서 얼마만큼의 면적을 점유하는지를 나타내는 척도입니다. 축에 평행한 직사각형은 가로와 세로의 곱이라는 직관적인 방식으로 계산되지만, 사다리꼴, 평행사변형, 마름모와 같은 일반적인 사각형은 더 복잡한 접근이 필요합니다. 신발끈 공식은 꼭짓점의 좌표 정보만으로도 넓이를 산출할 수 있게 해주므로, 좌표 기하학에서 도형으로 둘러싸인 영역의 넓이를 구하는 중요한 기준이 됩니다.

### 기본 성질
- 축에 평행한 직사각형의 넓이는 가로와 세로의 곱으로 간단히 계산됩니다.
- 일반적인 사각형의 경우, 네 꼭짓점의 좌표를 알면 신발끈 공식을 통해 넓이를 구할 수 있습니다.
- 예시로 꼭짓점이 $(0, 0), (4, 0), (4, 3), (0, 3)$인 직사각형의 넓이는 $4 \times 3 = 12$입니다.
- 꼭짓점이 $(1, 1), (3, 1), (3, 4), (1, 4)$인 경우, 신발끈 공식을 적용하면 $\frac{1}{2}|1(1-4) + 3(4-1) + 3(4-1) + 1(1-4)| = \frac{1}{2}|-3+9+9-3| = 6$이 됩니다.

## 학습 체크
- 축에 평행하지 않은 일반적인 사각형의 꼭짓점 좌표가 주어졌을 때, 신발끈 공식을 정확히 적용할 수 있는가?
- 직사각형의 넓이를 구할 때 가로와 세로의 길이를 구하는 과정에서 좌표의 차이를 올바르게 계산하였는가?

## 관련 개념
- **이차곡선**: 이차곡선과 직선으로 둘러싸인 영역의 넓이를 구할 때, 사각형의 넓이를 구하는 원리와 유사한 좌표 기하학적 접근이 사용됩니다.
