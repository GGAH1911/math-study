# 사다리꼴 넓이

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
사다리꼴의 넓이는 두 평행한 밑변의 길이 합에 높이를 곱한 후 $2$로 나누어 구합니다.

## 본문
사다리꼴은 한 쌍의 대변이 평행한 사각형을 말합니다. 평행한 두 변을 **밑변**이라 하고, 두 밑변 사이의 수직거리를 **높이**라고 할 때, 사다리꼴의 넓이는 두 밑변의 길이의 합에 높이를 곱한 값의 절반으로 계산합니다. 두 밑변의 길이를 $a$, $b$, 높이를 $h$라고 하면 넓이 $S$는 다음과 같은 공식으로 나타낼 수 있습니다.
$$S = \frac{1}{2}(a+b)h$$

### 직관과 기하적 의미
사다리꼴의 넓이를 구하는 원리는 여러 가지 방식으로 이해할 수 있습니다. 첫째로, 사다리꼴에 대각선을 그어 두 개의 삼각형으로 나누면 각각의 넓이는 $\frac{1}{2}ah$와 $\frac{1}{2}bh$가 되며, 이 둘을 더하면 전체 넓이 공식이 도출됩니다. 둘째로, 두 평행한 변의 평균 길이인 $\frac{a+b}{2}$를 구한 뒤, 여기에 높이 $h$를 곱한다고 생각하면 직관적으로 이해하기 쉽습니다. 만약 두 밑변의 길이가 같아지면($a=b$) 사다리꼴은 평행사변형이 되며, 이때 공식은 $\text{밑변} \times \text{높이}$로 단순화됩니다.

### 기본 성질
- 한 쌍의 대변이 평행해야 사다리꼴의 정의를 만족합니다.
- 두 밑변의 길이가 같으면 평행사변형이 됩니다.
- 높이는 두 평행한 변 사이의 수직 거리를 의미합니다.

## 학습 체크
- 사다리꼴의 넓이를 구할 때 두 밑변 중 하나만 사용하지 않도록 주의했나요?
- 높이를 구할 때 기울어진 변의 길이가 아닌, 두 밑변 사이의 수직 거리를 사용했나요?
- 계산 결과의 단위가 넓이 단위(예: $\text{cm}^2$)로 올바르게 표기되었나요?

## 관련 개념
- **좌표평면과 그래프**: 좌표평면 위에 사다리꼴의 네 꼭짓점이 주어졌을 때, 각 점의 좌표를 이용하여 밑변의 길이와 높이를 구한 뒤 넓이를 계산할 수 있습니다.
