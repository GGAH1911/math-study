# 원의 넓이

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
반지름이 $r$인 원의 넓이는 원주율 $\pi$와 반지름의 제곱을 곱한 $\pi r^2$입니다.

## 본문
반지름이 $r$인 원의 넓이는 $\pi r^2$으로 정의됩니다. 여기서 $\pi$는 원주율(약 3.14159...)을 의미하며, $r$은 원의 중심에서 원 위의 임의의 점까지의 거리인 반지름을 나타냅니다.

### 직관과 기하적 의미
원의 넓이 공식은 원을 아주 많은 가늘고 긴 삼각형으로 쪼개어 생각하면 쉽게 이해할 수 있습니다. 원의 중심을 공통 꼭짓점으로 하여 원 위의 점들을 연결하면 여러 개의 이등변삼각형을 만들 수 있는데, 이 삼각형들의 밑변을 모두 더하면 원의 둘레인 $2\pi r$이 됩니다. 각 삼각형의 높이는 반지름 $r$과 같으므로, 전체 넓이는 $\frac{1}{2} \times (2\pi r) \times r$이 되어 최종적으로 $\pi r^2$이라는 공식이 도출됩니다. 이는 원을 무한히 많은 부채꼴로 나누어 극한을 취하는 과정과도 일맥상통합니다.

### 기본 성질
반지름의 길이가 변함에 따라 원의 넓이는 반지름의 제곱에 비례하여 변화합니다. 예를 들어 반지름이 3 cm인 원의 넓이는 $\pi \times 3^2 = 9\pi$ cm²이며, 이는 약 28.27 cm²입니다. 일반적으로 반지름이 $r$인 원의 넓이를 구하려면 $r$을 제곱한 값에 $\pi$를 곱하면 됩니다.
