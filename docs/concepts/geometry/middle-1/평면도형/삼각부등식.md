# 삼각부등식

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
삼각형의 세 변의 길이는 임의의 한 변의 길이가 나머지 두 변의 길이의 합보다 작아야 한다는 원리입니다.

## 본문
삼각형의 세 변의 길이를 $a$, $b$, $c$라고 할 때, 다음의 부등식을 만족해야 합니다: $a + b > c$, $b + c > a$, $c + a > b$. 이를 더 간결하게 표현하면 한 변의 길이는 다른 두 변의 길이의 합보다 작고, 두 변의 길이의 차의 절댓값보다 커야 한다는 의미인 $|a - b| < c < a + b$로 나타낼 수 있습니다.

### 직관과 기하적 의미
삼각부등식은 세 점이 삼각형을 이루기 위한 필요충분조건입니다. 두 점 $A$와 $B$ 사이의 최단거리는 직선이므로, 제3의 점 $C$를 거쳐가는 경로($AC + BC$)는 직접 가는 경로($AB$)보다 반드시 길어야 합니다. 만약 두 변의 합이 나머지 한 변과 같다면($a + b = c$), 세 점은 한 직선 위에 놓이게 되어 삼각형을 형성할 수 없습니다. 기하학적으로는 벡터의 합과도 연결되는데, 두 벡터를 더한 결과의 크기는 각각의 크기를 더한 값보다 작거나 같습니다.

### 기본 성질
세 변의 길이가 3, 4, 6인 경우, $3+4>6$, $4+6>3$, $6+3>4$가 모두 성립하므로 삼각형을 만들 수 있습니다. 반면, 세 변의 길이가 3, 4, 7인 경우에는 $3+4=7$이 되어 삼각형을 형성할 수 없습니다.

## 학습 체크
- 세 변의 길이 중 가장 긴 변이 나머지 두 변의 합보다 작은지 확인했는가?
- 세 변의 길이의 차가 가장 긴 변보다 작은지 확인했는가?

## 관련 개념
- **삼각함수**: 삼각형의 변의 길이와 각도 사이의 관계를 다루며, 삼각부등식에서 정의된 삼각형의 성립 조건이 전제가 됩니다.
