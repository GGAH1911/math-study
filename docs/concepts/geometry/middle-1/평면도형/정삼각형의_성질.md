# 정삼각형의 성질

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
세 변의 길이가 모두 같고 세 내각이 모두 $60^\circ$인 삼각형으로, 높이와 넓이를 구하는 공식이 정해져 있는 대칭적인 도형입니다.

## 본문
세 변의 길이가 모두 같은 삼각형을 **정삼각형**이라고 합니다. 한 변의 길이를 $a$라 할 때, 정삼각형은 모든 변과 모든 각이 같은 가장 대칭적인 형태를 가집니다.

### 직관과 기하적 의미
정삼각형의 꼭짓점에서 대변에 내린 수선은 대변을 정확히 이등분합니다. 이 과정에서 정삼각형은 두 개의 직각삼각형으로 나누어지며, 이 직각삼각형에 피타고라스 정리를 적용하면 높이를 유도할 수 있습니다. 높이를 $h$라 하면 $h^2 + (\tfrac{a}{2})^2 = a^2$이 성립하며, 이를 정리하면 $h = \tfrac{\sqrt{3}}{2}a$라는 식을 얻게 됩니다. 즉, 정삼각형의 모든 기하적 성질은 이 높이 공식으로부터 유도됩니다.

### 기본 성질
- 세 내각의 크기는 모두 $60^\circ$로 같습니다.
- 높이 $h = \tfrac{\sqrt{3}}{2}a$
- 넓이 $S = \tfrac{\sqrt{3}}{4}a^2$

## 학습 체크
- 한 변의 길이가 $a$일 때, 높이를 구하기 위해 피타고라스 정리를 어떻게 활용하는지 설명할 수 있는가?
- 정삼각형의 넓이 공식이 밑변과 높이를 곱한 값의 절반임을 이해하고 있는가?

## 관련 개념
- **닮음과 피타고라스**: 정삼각형의 높이를 구할 때 피타고라스 정리를 사용하며, 정삼각형을 반으로 나누면 닮은 형태의 직각삼각형이 나타납니다.
