# 중점

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
선분 위의 두 끝점에서 같은 거리에 있는 점으로, 선분을 이등분하는 지점입니다.

## 본문
두 점 $A$와 $B$를 잇는 선분 $\overline{AB}$ 위에서, $A$와 $B$로부터 같은 거리에 있는 점을 **중점**이라 합니다. 좌표평면에서 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$의 중점 $M$의 좌표는 다음과 같습니다.

$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$$

즉, 중점의 $x$좌표는 두 점의 $x$좌표의 평균이고, $y$좌표도 두 점의 $y$좌표의 평균입니다.

### 직관과 기하적 의미
선분을 정확히 반으로 나누는 지점입니다. 중점으로부터 양쪽 끝점까지의 거리는 항상 같으므로, 저울의 균형점처럼 생각할 수 있습니다. 공간에서 중점은 대칭성을 나타내는데, 점 $A$를 중점 $M$에 대해 대칭이동하면 점 $B$에 도달하고, 그 반대도 마찬가지입니다. 이 성질 때문에 중점은 도형의 중심을 찾거나 대칭축을 구하는 기본 도구가 됩니다.

### 기본 성질
원의 지름의 중점은 원의 중심이 됩니다. 또한 삼각형의 각 변의 중점을 연결하면 원래 삼각형과 닮은 새로운 도형들이 만들어지는 중점연결정리가 성립합니다. 두 점 사이의 거리를 정확히 반으로 나누기 때문에 함수의 그래프에서 대칭점을 찾을 때도 자주 사용됩니다.

## 학습 체크
- 두 점의 좌표를 각각 더한 후 2로 나누었을 때, 결과값이 선분 위에 위치하는지 확인했는가?
- 중점이 선분을 이등분한다는 사실을 이용하여 대칭인 다른 점의 좌표를 구할 수 있는가?

## 관련 개념
- **평면도형**: 삼각형의 중점을 연결하여 새로운 도형을 만들거나, 원의 중심을 찾는 과정에서 핵심적인 역할을 합니다.
