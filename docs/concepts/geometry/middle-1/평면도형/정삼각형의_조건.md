# 정삼각형의 조건

## 정확한 진술

삼각형이 **정삼각형**이 되기 위한 조건은 다음 중 하나와 동치입니다:

- **변의 조건**: 세 변의 길이가 모두 같다. 즉, $a = b = c$
- **각의 조건**: 세 내각이 모두 같고 각각 $60°$이다. 즉, $\angle A = \angle B = \angle C = 60°$
- **코사인 법칙 조건**: 한 변 $a$에 대해 $a^2 = b^2 + c^2 - 2bc\cos 60°$를 만족할 때 $b = c$이면 정삼각형

가장 중요한 것은, **한 조건만 확인해도 나머지가 자동으로 따라온다**는 점입니다. 예를 들어 $a = b = c$를 알면, 코사인 법칙에 의해 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{a^2 + a^2 - a^2}{2a^2} = \frac{1}{2}$이므로 $A = 60°$가 자동 결정됩니다.

## 직관/기하적 의미

정삼각형은 삼각형 중에서 **가장 대칭적**인 도형입니다. 세 변의 길이가 모두 같다는 것은 어느 꼭짓점도 "특별하지 않다"는 뜻이고, 그 결과 세 내각도 자동으로 같아져서 각각 $60°$가 됩니다.

이것은 삼각함수와도 연결됩니다. $\cos 60° = \frac{1}{2}$, $\sin 60° = \frac{\sqrt{3}}{2}$라는 값들이 정삼각형의 기하학적 성질에서 비롯됩니다. 정삼각형의 높이가 $\frac{\sqrt{3}}{2}a$인 이유도 바로 $60°$의 삼각함수 값 때문입니다.

## 한 줄 예

변의 길이가 $a = b = 2$이고 $\cos C = \frac{1}{2}$일 때, $c^2 = 4 + 4 - 2 \cdot 2 \cdot 2 \cdot \frac{1}{2} = 4$이므로 $c = 2$이고 정삼각형입니다. (검산: `import sympy; sympy.solve(4 + 4 - 8*0.5 - c**2, c)` → $c = 2$)
