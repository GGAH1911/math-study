# 부채꼴 넓이 예제

> **예제** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
반지름과 중심각의 정보를 이용하여 원의 넓이 중 해당 부채꼴이 차지하는 비율만큼의 넓이를 구합니다.

## 본문
반지름이 $6\text{ cm}$이고 중심각이 $60^\circ$인 부채꼴의 넓이를 구하시오.

### 단계별 풀이
**1단계: 부채꼴 넓이 구하는 원리 이해하기**
부채꼴은 원의 일부분이므로, 원 전체의 넓이에 중심각이 전체 $360^\circ$ 중 차지하는 비율을 곱하여 계산합니다.

**2단계: 원 전체의 넓이 계산하기**
반지름 $r = 6\text{ cm}$를 이용하여 원의 넓이를 구하면 다음과 같습니다.
$$\text{원의 넓이} = \pi r^2 = \pi \times 6^2 = 36\pi \text{ cm}^2$$

**3단계: 중심각의 비율 계산하기**
전체 각도 $360^\circ$에 대한 중심각 $60^\circ$의 비율을 구합니다.
$$\frac{60^\circ}{360^\circ} = \frac{1}{6}$$

**4단계: 최종 부채꼴 넓이 산출하기**
원의 넓이에 중심각의 비율을 곱하여 최종 결과값을 얻습니다.
$$\text{부채꼴의 넓이} = \frac{1}{6} \times 36\pi = 6\pi \text{ cm}^2$$

### 답과 변형
$$6\pi \text{ cm}^2$$ (약 $18.85 \text{ cm}^2$)

- **중심각 변화에 따른 결과**: 중심각이 $90^\circ$이면 $9\pi \text{ cm}^2$, $120^\circ$이면 $12\pi \text{ cm}^2$가 됩니다.
- **호의 길이를 이용한 방법**: 호의 길이 $l$과 반지름 $r$을 알 때 $\frac{1}{2}rl$ 공식을 사용할 수 있습니다.
- **단위 주의사항**: 계산 시 중심각은 반드시 도($^\circ$) 단위인지 확인해야 합니다.

## 학습 체크
- 원의 넓이와 중심각의 비율 관계를 이해하고 있는가?
- 반지름과 중심각이 주어졌을 때 단계별로 넓이를 구할 수 있는가?
- 호의 길이가 주어졌을 때의 다른 넓이 공식도 알고 있는가?

## 관련 개념
- **평면도형**: 부채꼴은 원의 일부분을 나타내는 평면도형의 한 종류입니다.
