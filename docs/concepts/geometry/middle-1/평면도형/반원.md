# 반원

> **정의** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
원의 중심을 지나는 지름에 의해 이등분된 원의 절반 부분을 의미합니다.

## 본문
반원(semicircle)은 원의 중심을 지나는 현인 지름에 의해 원이 나누어진 두 개의 합동인 부분 중 하나입니다. 중심이 원점이고 반지름이 $r$인 원 $x^2 + y^2 = r^2$에서, 반원은 보통 지름을 $x$축 위에 놓고 $y \geq 0$인 부분을 지칭합니다. 반원 위의 점들은 $y = \sqrt{r^2 - x^2}$ ($-r \leq x \leq r$)로 표현됩니다.

### 직관과 기하적 의미
반원은 원을 가로로 정확히 이등분한 도형입니다. 원의 중심에서 보면 정확히 $180^\circ$의 중심각을 차지하며, 전체 원의 넓이의 정확히 절반입니다. 일상에서는 동전 반쪽이나 무지개의 형태 등 많은 곳에서 볼 수 있습니다. 또한 곡선으로 둘러싸인 영역의 대표적인 예시로서, 직선으로 둘러싸인 삼각형이나 사각형과 달리 곡선의 넓이를 구하기 위해 정적분이 활용됩니다.

### 기본 성질
반지름이 $r$인 반원의 넓이는 다음 정적분으로 계산됩니다:
$$\text{넓이} = \int_{-r}^{r} \sqrt{r^2 - x^2} \, dx = \frac{\pi r^2}{2}$$
이 적분은 $x = r\sin\theta$ 치환을 이용하여 계산할 수 있으며, 결과는 원의 전체 넓이 $\pi r^2$의 정확히 절반이 됩니다. 예를 들어 반지름이 2인 반원의 넓이는 다음과 같습니다:
$$\text{넓이} = \int_{-2}^{2} \sqrt{4 - x^2} \, dx = \frac{\pi \cdot 2^2}{2} = 2\pi$$

## 학습 체크
- 반원의 넓이가 왜 원 전체 넓이의 $\tfrac{1}{2}$이 되는지 정적분을 통해 증명할 수 있는가?
- 반원의 경계선인 지름을 제외한 곡선 부분의 방정식은 무엇인가?

## 관련 개념
- **정적분의 활용**: 곡선으로 둘러싸인 영역의 넓이를 구하는 대표적인 사례로, 반원의 넓이를 계산할 때 정적분이 필수적으로 사용됩니다.
