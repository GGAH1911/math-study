# 정n각형 내각

> **예제** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
정육각형의 한 내각의 크기는 $120^\circ$입니다.

## 본문
정육각형의 한 내각의 크기를 구하시오.

### 단계별 풀이
**1단계: 내각의 합 공식 적용**
정$n$각형의 모든 내각의 합은 $(n-2) \times 180^\circ$입니다. 정육각형은 $n=6$이므로 내각의 합은 다음과 같습니다.
$$\text{내각의 합} = (6-2) \times 180^\circ = 4 \times 180^\circ = 720^\circ$$

**2단계: 한 내각의 크기 계산**
정육각형은 모든 내각의 크기가 같으므로, 내각의 합을 변의 개수인 6으로 나누어 한 내각의 크기를 구할 수 있습니다.
$$\text{한 내각} = \frac{720^\circ}{6} = 120^\circ$$

또는 정$n$각형의 한 내각 공식인 $\tfrac{(n-2) \times 180^\circ}{n}$을 사용하여 $\tfrac{(6-2) \times 180^\circ}{6} = 120^\circ$임을 바로 구할 수도 있습니다.

### 답과 변형
정육각형의 한 내각은 **$120^\circ$**입니다.

**다른 정다각형의 예시**
- 정삼각형: $\tfrac{180^\circ}{3} = 60^\circ$
- 정사각형: $\tfrac{360^\circ}{4} = 90^\circ$
- 정오각형: $\tfrac{540^\circ}{5} = 108^\circ$
- 정팔각형: $\tfrac{1080^\circ}{8} = 135^\circ$

**주의사항**
정육각형의 외각은 $180^\circ - 120^\circ = 60^\circ$입니다. 모든 정$n$각형의 외각의 합은 $360^\circ$이므로, 정육각형의 외각 6개를 더하면 $6 \times 60^\circ = 360^\circ$가 되어 성립함을 확인할 수 있습니다.

- 정다각형의 한 내각과 외각의 관계를 이해하고 있는가?

## 관련 개념
- **평면도형**: 정다각형은 평면 위에 그려지는 도형의 일종으로, 내각과 외각의 성질을 통해 도형의 구조를 파악할 수 있습니다.
