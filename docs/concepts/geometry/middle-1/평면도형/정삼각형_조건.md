# 정삼각형 조건

## 정확한 진술

정삼각형(equilateral triangle)은 **세 변의 길이가 모두 같은 삼각형**입니다. 동시에 이는 **세 내각이 모두 $60°$인 삼각형**과 동치입니다. 평면 위의 세 점 $A, B, C$가 정삼각형을 이루려면 다음 조건을 만족해야 합니다:

$$|AB| = |BC| = |CA|$$

혹은 동등하게, 한 변의 길이를 $a$라 할 때:
$$|AB| = |BC| = |CA| = a$$

## 직관/기하적 의미

정삼각형은 **모든 변과 각이 대칭인 가장 완벽한 삼각형**입니다. 이등변삼각형의 특수한 경우로, 세 꼭짓점이 한 원(외접원) 위에 균등하게 배치되어 있습니다. 정삼각형의 중심에서 세 꼭짓점까지의 거리는 모두 같으므로, 중심을 중심으로 $120°$씩 회전시키면 자기 자신과 완전히 일치합니다(3중 회전 대칭).

좌표평면에서 한 변의 길이가 $a$인 정삼각형의 높이는 $\frac{\sqrt{3}}{2}a$이고, 넓이는 $\frac{\sqrt{3}}{4}a^2$입니다.

## 한 줄 예

세 점 $A(0, 0)$, $B(2, 0)$, $C(1, \sqrt{3})$은 정삼각형을 이룹니다. 왜냐하면:

$$|AB| = 2, \quad |BC| = \sqrt{(2-1)^2 + (0-\sqrt{3})^2} = 2, \quad |CA| = \sqrt{1^2 + (\sqrt{3})^2} = 2$$

세 변의 길이가 모두 2로 같으므로 정삼각형입니다. (검증: `sympy.sqrt((2-1)**2 + (0-sqrt(3))**2)` = 2)
