# 삼각형의 합동

## 정확한 진술

두 삼각형이 **합동**이라는 것은 한 삼각형을 옮기거나 회전, 뒤집어서 다른 삼각형과 정확히 겹칠 수 있다는 뜻입니다. 기호로는 $\triangle ABC \cong \triangle DEF$처럼 쓰며, 이는 대응하는 변의 길이가 모두 같고 대응하는 각의 크기도 모두 같다는 의미입니다. 즉, $\overline{AB} = \overline{DE}$, $\overline{BC} = \overline{EF}$, $\overline{CA} = \overline{FD}$이고 $\angle A = \angle D$, $\angle B = \angle E$, $\angle C = \angle F$입니다.

## 직관과 기하적 의미

합동은 기하학에서 "같다"의 개념을 정확하게 정의한 것입니다. 종이 위에 그린 두 삼각형이 합동이면, 한 삼각형을 오려내어 다른 삼각형 위에 놓았을 때 정확하게 겹칩니다. 즉, 평면상의 **이동**(평행이동, 회전, 대칭이동)으로 한 도형을 다른 도형으로 변환할 수 있다는 뜻입니다.

삼각형의 합동은 단순해 보이지만 강력합니다. 실제로는 6개 조건(변 3개, 각 3개)을 모두 확인할 필요 없고, **합동 조건** (SSS, SAS, ASA, AAS 등)을 이용하면 일부만 확인하고도 합동을 판단할 수 있습니다.

## 한 줄 예

$\triangle ABC$에서 $AB = 5$, $BC = 6$, $\angle B = 60°$이고, $\triangle PQR$에서 $PQ = 5$, $QR = 6$, $\angle Q = 60°$라면, SAS 합동 조건에 의해 $\triangle ABC \cong \triangle PQR$입니다.
