# 삼각형의 합동

> **정의** · 중1 · 단원: [작도와 합동](/concepts/작도와_합동)

## 요약
두 삼각형의 대응변의 길이와 대응각의 크기가 모두 같아, 한 삼각형을 옮기거나 회전 또는 뒤집었을 때 다른 삼각형과 완전히 겹쳐지는 상태를 의미합니다.

## 본문
두 삼각형이 **합동**이라는 것은 한 삼각형을 옮기거나 회전, 뒤집어서 다른 삼각형과 정확히 겹칠 수 있다는 뜻입니다. 기호로는 $\triangle ABC \cong \triangle DEF$처럼 쓰며, 이는 대응하는 변의 길이가 모두 같고 대응하는 각의 크기도 모두 같다는 의미입니다. 즉, $\overline{AB} = \overline{DE}$, $\overline{BC} = \overline{EF}$, $\overline{CA} = \overline{FD}$이고 $\angle A = \angle D$, $\angle B = \angle E$, $\angle C = \angle F$입니다.

### 직관과 기하적 의미
합동은 기하학에서 "같다"의 개념을 정확하게 정의한 것입니다. 종이 위에 그린 두 삼각형이 합동이면, 한 삼각형을 오려내어 다른 삼각형 위에 놓았을 때 정확하게 겹칩니다. 즉, 평면상의 **이동**(평행이동, 회전, 대칭이동)으로 한 도형을 다른 도형으로 변환할 수 있다는 뜻입니다.

### 기본 성질
삼각형의 합동은 단순해 보이지만 강력합니다. 실제로는 6개 조건(변 3개, 각 3개)을 모두 확인할 필요 없이, 특정 조건만 만족하면 합동임을 판단할 수 있는 **합동 조건**(SSS, SAS, ASA 등)이 존재합니다. 예를 들어, $\triangle ABC$에서 $AB = 5$, $BC = 6$, $\angle B = 60^\circ$이고, $\triangle PQR$에서 $PQ = 5$, $QR = 6$, $\angle Q = 60^\circ$라면, SAS 합동 조건에 의해 $\triangle ABC \cong \triangle PQR$입니다.

## 학습 체크
- 두 삼각형이 합동일 때, 대응하는 변의 길이와 대응하는 각의 크기가 모두 일치하는가?
- 삼각형의 모든 변과 각을 다 확인하지 않고도 합동을 판별할 수 있는 조건(SSS, SAS, ASA)을 알고 있는가?

## 관련 개념
- **원의 성질**: 원의 중심과 원 위의 점을 연결하여 만든 삼각형의 합동을 통해 원의 반지름과 현의 성질을 증명할 수 있습니다.
