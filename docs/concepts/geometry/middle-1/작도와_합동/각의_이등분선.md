# 각의 이등분선

> **정의** · 중1 · 단원: [작도와 합동](/concepts/작도와_합동)

## 요약
각의 이등분선은 주어진 각을 크기가 같은 두 각으로 나누는 반직선으로, 이 선 위의 임의의 점에서 두 변에 이르는 거리는 항상 같습니다.

## 본문
각의 이등분선은 주어진 각을 두 개의 합동인 각으로 나누는 반직선입니다. 예를 들어 각 $\angle AOB$에서 꼭짓점 $O$를 지나는 반직선 $\overrightarrow{OP}$가 이등분선이 되려면 $\angle AOP = \angle BOP$를 만족해야 합니다.

### 직관과 기하적 의미
각의 이등분선은 두 반직선 사이를 완벽하게 반반씩 나누는 기하학적 경로입니다. 이 개념은 평면 위에서 대칭적인 구조를 형성하며, 각의 양 끝 변으로부터 동일한 거리에 있는 점들의 집합이라는 기하학적 의미를 갖습니다.

### 기본 성질
각의 이등분선 위의 임의의 점에서 각의 두 변까지의 거리는 항상 같습니다. 이 성질은 삼각형의 세 각의 이등분선이 만나는 점인 **내심**을 정의하는 기초가 됩니다. 또한, 삼각형에서 한 꼭짓점의 각의 이등분선이 대변을 만나는 점은 $\frac{BD}{DC} = \frac{AB}{AC}$라는 **각의 이등분선 정리**를 만족합니다.

## 학습 체크
- $\angle AOB = 60^\circ$인 각의 이등분선 $\overrightarrow{OP}$가 있을 때, $\angle AOP$와 $\angle BOP$의 크기는 각각 몇 도인가?
- 각의 이등분선 위의 한 점에서 각의 두 변에 내린 수선의 길이는 서로 같은가?
- 삼각형의 세 각의 이등분선은 항상 한 점에서 만나는가?

## 관련 개념
- **도형의 성질**: 각의 이등분선은 삼각형의 **내심**을 결정하는 핵심 요소이며, 변의 길이 비와 관련된 **각의 이등분선 정리**를 통해 선분의 길이를 구하는 데 활용됩니다.
