# 정육면체

> **정의** · 중1 · 단원: [입체도형](/concepts/입체도형)

## 요약
6개의 합동인 정사각형으로 이루어진 가장 대칭적인 정다면체입니다.

## 본문
정육면체는 6개의 합동인 정사각형으로 이루어진 정다면체입니다. 모든 모서리의 길이가 같고, 모든 꼭짓점에서 3개의 모서리가 만나며, 모든 면이 서로 수직으로 만나는 입체도형입니다. 한 모서리의 길이를 $a$라 하면, 정육면체의 모든 기본 성질을 결정할 수 있습니다.

### 직관과 기하적 의미
정육면체는 가장 대칭적인 정다면체 중 하나로, 어느 방향으로 회전하든 같은 모양을 유지합니다. 정육면체를 좌표계에 놓으면 $x, y, z$축이 정육면체의 3개 모서리 방향과 평행하게 할 수 있으며, 이는 공간벡터 문제에서 자주 사용되는 표준 위치입니다. 정육면체의 대칭성 덕분에 꼭짓점, 모서리, 면의 위치 관계를 쉽게 파악할 수 있습니다. 예를 들어, 한 꼭짓점에서 가장 먼 꼭짓점까지의 거리는 체대각선의 길이인 $a\sqrt{3}$입니다.

### 기본 성질
모서리의 길이가 $a$일 때, 정육면체의 부피는 $V = a^3$이며, 전체 겉넓이는 $S = 6a^2$입니다. 모든 면은 서로 수직이며, 모든 꼭짓점에는 3개의 모서리가 동일한 각도로 모입니다.

## 학습 체크
- 정육면체의 한 모서리 길이를 알 때, 체대각선의 길이를 구하는 공식은 무엇인가요?
- 정육면체의 겉넓이와 부피를 결정하는 변수는 무엇인가요?

## 관련 개념
- **공간도형과 공간벡터**: 정육면체의 모서리를 축으로 설정하여 공간상의 점과 벡터의 위치를 정의하는 기초 모델로 활용됩니다.
