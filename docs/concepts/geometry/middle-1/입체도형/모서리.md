# 모서리

> **정의** · 중1 · 단원: [입체도형](/concepts/입체도형)

## 정확한 진술

모서리란 **입체도형을 이루는 두 개의 평면이 만나서 이루는 교선**입니다. 다시 말해, 공간도형의 표면을 구성하는 두 면(면)이 접하는 경계선을 의미합니다.

정육면체를 예로 들면, 정육면체는 6개의 정사각형 면으로 이루어져 있고, 인접한 두 면이 만나는 곳이 모서리입니다. 정육면체는 총 12개의 모서리를 갖습니다.

## 직관/기하적 의미

모서리는 입체도형의 "뼈대"를 이루는 선분들입니다. 손가락으로 정육면체의 모서리를 따라가보면, 어떤 방향으로든 직선 경로를 그리게 됩니다. 

공간도형을 시각적으로 파악할 때:
- **꼭짓점**(vertex): 모서리들이 만나는 점
- **모서리**(edge): 두 면이 만나는 선
- **면**(face): 공간도형의 표면

이 세 요소는 입체도형의 기본 구성 단위입니다. 모서리의 개수, 길이, 방향은 입체도형의 부피나 표면적을 구할 때 중요한 정보가 됩니다.

## 한 줄 예

정삼각뿔(사면체)은 4개의 정삼각형 면으로 이루어져 있으므로 **6개의 모서리**를 갖습니다. 한편, 사각뿔(밑면이 사각형)의 경우 **8개의 모서리**(밑면 4개 + 옆면과 밑면의 교선 4개)를 갖습니다.
