# 부피 동등 조건

> **정의** · 중1 · 단원: [입체도형](/concepts/입체도형)

## 요약
두 입체도형의 높이가 같고 모든 높이에서의 단면의 넓이가 같다면 두 도형의 부피는 같습니다.

## 본문
두 입체도형이 같은 높이를 가지고 있고, 밑면으로부터 같은 높이에서 자른 모든 단면의 넓이가 같다면, 두 입체도형의 부피는 같습니다. 이 원리를 카발리에리 원리 또는 부피의 카발리에리 정리라고 합니다. 수식으로 표현하면, 밑면으로부터 높이 $h$ 위치에서의 단면적을 각각 $S_1(h)$, $S_2(h)$라 할 때, 모든 $0 \leq h \leq H$에서 $S_1(h) = S_2(h)$이면, 두 입체의 부피는 $V_1 = V_2 = \int_0^H S(h) \, dh$가 성립합니다.

### 직관과 기하적 의미
입체도형을 매우 얇은 평면 조각들로 차근차근 쌓아올린다고 생각해보세요. 각 높이에서의 단면이 같은 넓이를 가진다면, 입체가 얼마나 기울거나 휜지는 중요하지 않습니다. 최종적으로 쌓인 전체 부피는 같을 수밖에 없습니다. 마치 같은 크기의 동전을 같은 개수만큼 쌓을 때, 동전을 어떻게 정렬하든 최종 높이와 부피가 변하지 않는 것처럼, 입체도형의 형태가 아니라 단면들의 합이 부피를 결정합니다.

### 기본 성질
- 두 도형의 높이가 동일해야 합니다.
- 모든 높이에서 대응하는 단면의 넓이가 일치해야 합니다.
- 도형이 기울어져 있더라도 단면의 넓이만 같다면 부피는 동일합니다.

## 학습 체크
- 두 입체도형의 높이가 서로 다를 때도 단면의 넓이가 같으면 부피가 같다고 할 수 있는가?
- 기울어진 원기둥과 곧은 원기둥의 부피가 같은 이유를 단면의 관점에서 설명할 수 있는가?

## 관련 개념
- **입체도형**: 단면의 넓이를 쌓아 올리는 대상이 되며, 형태가 변하더라도 단면의 넓이가 일정하면 부피가 유지됩니다.
