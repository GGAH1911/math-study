# 정삼각기둥

> **정의** · 중1 · 단원: [입체도형](/concepts/입체도형)

## 요약
두 밑면이 합동인 정삼각형이고 서로 평행하며, 옆면이 직사각형인 입체도형입니다.

## 본문
정삼각기둥은 두 밑면이 합동인 정삼각형이고, 이 두 밑면이 평행하며, 옆면이 직사각형인 입체도형입니다. 더 구체적으로, 정삼각형 $ABC$와 그 위쪽의 합동인 정삼각형 $A'B'C'$ 사이에 $AA' \parallel BB' \parallel CC'$이고 네 점 $ABB'A'$, $BCC'B'$, $CAA'C'$이 모두 직사각형을 이루는 도형입니다.

### 직관과 기하적 의미
정삼각기둥은 정삼각형을 수직 방향으로 일정한 거리만큼 옮긴 결과라고 생각할 수 있습니다. 밑면의 정삼각형이 가진 3중 회전 대칭이 전체 기둥에서도 유지되므로, 어느 방향에서 봐도 대칭적인 모양을 띱니다.

### 기본 성질
- 밑면의 한 변의 길이 $a$가 주어지면, 정삼각형의 넓이는 $\displaystyle \frac{\sqrt{3}}{4}a^2$입니다.
- 높이가 $h$일 때, 옆면적(3개 직사각형의 합)은 $3ah$입니다.
- 전체 표면적은 $\displaystyle \frac{\sqrt{3}}{2}a^2 + 3ah$입니다.
- 부피는 (밑넓이) $\times$ (높이)이므로 $\displaystyle \frac{\sqrt{3}}{4}a^2h$입니다.

## 학습 체크
- 밑면의 한 변의 길이가 2이고 높이가 5인 정삼각기둥의 부피를 구할 수 있는가?
- 정삼각기둥의 옆면 3개가 모두 합동인 직사각형임을 설명할 수 있는가?
- 정삼각기둥의 전체 겉넓이를 구하기 위해 필요한 구성 요소들을 모두 나열할 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 정삼각기둥의 각 꼭짓점을 좌표로 나타내어 공간에서의 위치를 벡터로 표현하거나, 면과 선 사이의 관계를 벡터의 내적으로 분석할 수 있습니다.
