# 부피 보존

## 정확한 진술

**부피 보존**은 Cavalieri의 원리(카발리에리 원리)를 기반으로 합니다. 두 개의 입체도형이 같은 높이 $h$를 가지고, **모든 높이 $z$($0 \leq z \leq h$)에서 같은 높이의 단면적이 같으면, 두 입체도형의 부피는 같다**는 원리입니다.

수식으로 표현하면, 높이 $z$에서의 단면적을 $A_1(z)$와 $A_2(z)$라 할 때:
$$A_1(z) = A_2(z) \text{ (모든 } 0 \leq z \leq h \text{에 대해)} \implies V_1 = V_2$$

## 직관과 기하적 의미

입체도형을 아주 얇은 종이를 겹겹이 쌓아서 만든다고 생각해보세요. 각 높이에서 종이의 모양(단면)이 정확히 같다면, 두 입체도형이 어떻게 생겼는지는 상관없이 **전체 두께(부피)는 반드시 같습니다**.

예를 들어, 원기둥과 기울어진 기둥은 외형은 다르지만, 같은 높이에서 같은 원형 단면을 가진다면 부피가 동일합니다. 이것이 부피 보존의 핵심입니다.

## 한 줄 예

높이가 10 cm이고 모든 높이에서 단면적이 $20\text{ cm}^2$인 직육면체와 원기둥의 부피는 모두 $20 \times 10 = 200\text{ cm}^3$로 같습니다.
