# 각도 구하기 예제

> **예제** · 중1 · 단원: [기본 도형](/concepts/기본_도형)
## 요약
평행선과 직선에서 각도 추적

## 본문

### 문제

평행선 $l \parallel m$을 직선 $t$가 자릅니다. 직선 $t$와 $l$이 만나는 점을 $A$, 직선 $t$와 $m$이 만나는 점을 $B$라 하겠습니다. 점 $A$에서 표시된 각이 $62°$일 때, 점 $B$에서 같은 위치의 각(동위각)을 구하시오.

### 단계별 풀이

**1단계: 상황 정리하기** — 평행선 두 개를 직선 하나가 자르는 상황입니다. 점 $A$에서 한쪽 각 $62°$가 주어졌고, 점 $B$에서 "같은 위치"의 각을 찾아야 합니다.

**2단계: 동위각의 성질 적용하기** — 평행선을 횡단선(두 평행선을 자르는 직선)이 자를 때, 한쪽 교점에서의 각과 다른 쪽 교점에서 같은 위치의 각을 **동위각**이라 부릅니다. 평행선에서는 **동위각이 항상 같다**는 성질이 있습니다.

**3단계: 답 구하기** — 점 $A$의 각 $62°$와 점 $B$의 동위각 위치 각이 같으므로, 점 $B$의 동위각은 $62°$입니다.

### 답

$$\angle B = 62°$$

### 변형/주의

**다른 각도로 시도해보기**: 점 $A$에서의 각이 $55°$라면, 점 $B$의 동위각도 $55°$입니다. 주어진 각의 크기와 관계없이 동위각은 항상 같다는 성질이 핵심입니다.

**엇각도 활용할 수 있습니다**: 동위각 외에 **엇각**(교차하는 위치의 각)도 평행선에서 같습니다. 같은 문제를 엇각으로 물으면 답은 여전히 $62°$이므로, 여러 방법으로 접근할 수 있다는 점을 기억하세요. 항상 먼저 직선과 각의 위치를 정확히 파악한 후 성질을 적용합니다.
