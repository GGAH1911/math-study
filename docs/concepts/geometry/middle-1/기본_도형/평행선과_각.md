# 평행선과 각

> **정의** · 중1 · 단원: [기본 도형](/concepts/기본_도형)

## 요약
두 직선이 평행하면 횡단선에 의해 생기는 동위각과 엇각의 크기가 같고, 같은 쪽 내각의 합은 $180^{\circ}$입니다.

## 본문
두 직선이 평행하다는 것은 같은 평면 위에서 아무리 길게 연장해도 서로 만나지 않는 상태를 의미하며, 기호로는 $l \parallel m$과 같이 나타냅니다. 평행한 두 직선 $l$과 $m$을 하나의 직선(횡단선 또는 할선)이 통과할 때, 이 직선과 두 평행선이 이루는 각들 사이에는 특별한 기하학적 관계가 성립합니다.

### 직관과 기하적 의미
평행선은 두 직선의 기울기가 완전히 같음을 의미합니다. 같은 방향으로 똑같이 기울어져 있기 때문에, 횡단선이 두 직선과 만날 때 동일한 각도로 교차하게 되어 같은 패턴이 반복됩니다. 동위각의 크기가 같은 이유는 이러한 일정한 기울기 때문이며, 엇각은 기하학적 대칭성에 의해 나타나는 결과입니다. 또한 평행선 위의 모든 점에서 직선이 일정하게 기울어져 있으므로, 같은 쪽 내각의 합이 $180^{\circ}$가 되어 평행 상태를 유지하게 됩니다. 이러한 성질들은 도형의 닮음이나 합동을 판정할 때 매우 중요한 도구로 활용됩니다.

### 기본 성질
- **동위각**: 같은 위치에 있는 각의 크기는 서로 같습니다.
- **엇각**: 횡단선의 반대편에서 평행선 사이에 위치한 각의 크기는 서로 같습니다.
- **같은 쪽 내각**: 횡단선의 같은 쪽에 있는 평행선 사이의 두 각의 합은 $180^{\circ}$입니다.

## 학습 체크
- 두 직선이 평행할 때, 동위각과 엇각의 크기가 같다는 사실을 이용해 미지의 각을 구할 수 있는가?
- 같은 쪽 내각의 합이 $180^{\circ}$가 아닐 때, 두 직선은 평행하지 않다는 것을 증명할 수 있는가?

## 관련 개념
- **도형의 성질**: 평행선의 성질은 삼각형의 내각의 합이나 도형의 합동 및 닮음을 판정하는 기초적인 근거가 됩니다.
