# 직각

> **정의** · 중1 · 단원: [기본 도형](/concepts/기본_도형)

## 요약
두 직선 또는 반직선이 만나는 점의 각도가 정확히 $90^{\circ}$인 상태를 의미합니다.

## 본문
두 직선 또는 반직선이 만나는 점에서 이루는 각의 크기가 정확히 $90^{\circ}$ (또는 $\tfrac{\pi}{2}$ 라디안)일 때, 이 각을 **직각**이라고 합니다. 기하학적으로는 한 직선 위의 점에서 그은 수직선이 원래 직선과 이루는 각을 의미하며, 이는 각도 측정의 기준점이 됩니다.

### 직관과 기하적 의미
직각은 "완전히 수직"인 상태를 직관적으로 나타냅니다. 책상의 모서리, 교실의 벽과 바닥이 만나는 지점, 십자 모양이 만드는 네 개의 각이 모두 직각의 대표적인 예시입니다. 또한 좌표평면에서 $x$축과 $y$축이 만나는 지점처럼 수평과 수직을 정의하는 데 핵심적인 역할을 합니다.

### 기본 성질
직각은 예각($0^{\circ} < \theta < 90^{\circ}$)이나 둔각($90^{\circ} < \theta < 180^{\circ}$)에 해당하지 않는 특별한 기준 각입니다. 두 직선이 직각을 이루며 만날 때는 $AB \perp CD$와 같이 표기하며, 도형에서는 만나는 점 근처에 작은 사각형 기호를 그려 표시합니다. 직각삼각형에서는 가장 큰 각이 직각이며, 이는 피타고라스 정리와 밀접하게 연결됩니다.

## 학습 체크
- 두 직선이 직각으로 만날 때 사용하는 기호 $\perp$의 의미를 알고 있는가?
- 직각은 예각이나 둔각의 범주에 포함되는가?
- 도형에서 직각을 나타내기 위해 사용하는 기호는 무엇인가?

## 관련 개념
- **평면도형**: 정사각형의 네 내각은 모두 직각이며, 직각삼각형은 한 각이 직각인 삼각형을 의미합니다.
