# 맞꼭지각

> **정리** · 중1 · 단원: [기본 도형](/concepts/기본_도형)

## 요약
두 직선이 한 점에서 만날 때 서로 마주보는 두 각의 크기는 항상 같습니다.

## 본문
두 직선 $l$과 $m$이 점 $O$에서 만날 때, 서로 마주보는 두 각인 $\angle AOB$와 $\angle COD$를 맞꼭지각이라고 합니다. 이때 두 맞꼭지각의 크기는 항상 같습니다. 즉, $\angle AOB = \angle COD$가 성립합니다.

### 증명 스케치
두 직선이 만나서 만들어지는 네 개의 각 중 인접한 두 각의 합은 일직선을 이루므로 항상 $180^\circ$입니다. $\angle AOB$와 $\angle BOC$가 일직선 위에 있다면 $\angle AOB + \angle BOC = 180^\circ$이고, 마찬가지로 $\angle BOC$와 $\angle COD$가 일직선 위에 있다면 $\angle BOC + \angle COD = 180^\circ$입니다. 이 두 식을 비교하면 $\angle AOB + \angle BOC = \angle BOC + \angle COD$가 되며, 양변에서 공통된 각인 $\angle BOC$를 빼면 $\angle AOB = \angle COD$라는 결론을 얻을 수 있습니다.

### 의의와 응용
맞꼭지각 정리는 기하학적 문제를 해결할 때 각의 크기를 결정하는 가장 기초적인 도구입니다. 여러 직선이 복잡하게 얽혀 있는 도형에서도 맞꼭지각의 성질을 이용해 같은 크기의 각을 찾아내면 복잡한 관계를 단순화할 수 있습니다. 이는 이후 평행선의 성질이나 삼각형의 외각 정리와 같은 심화 개념을 증명할 때도 핵심적인 근거로 활용됩니다.

## 학습 체크

- 평면 위에서 여러 직선이 교차할 때 맞꼭지각의 크기가 같음을 이용하여 미지의 각을 구할 수 있는가?

## 관련 개념
- **기본 도형**: 점, 선, 면과 같은 가장 기초적인 요소들이 모여 맞꼭지각과 같은 도형의 성질을 형성하는 토대가 됩니다.
