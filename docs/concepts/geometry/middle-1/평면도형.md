# 평면도형

> **단원** · 중1 · 선수: [작도와 합동](/concepts/작도와_합동) · 다음: [도형의 성질](/concepts/도형의_성질) / [원의 성질](/concepts/원의_성질) / [입체도형](/concepts/입체도형)

## 학습 목표
- 다각형의 내각·외각의 합을 구할 수 있다
- 원과 부채꼴의 호의 길이·넓이를 계산할 수 있다

## 다룰 정의 / 정리 / 예제

**정의**
- [다각형](/concepts/다각형) — 정다각형
- 내각·외각
- 원, 부채꼴, 활꼴

**정리**
- $n$각형의 내각의 합 $= 180(n-2)$
- 부채꼴 호 길이 $= 2\pi r \cdot \theta/360$

**예제**
- 정다각형의 한 내각
- [부채꼴 넓이 예제](/concepts/부채꼴_넓이_예제) — 비교

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
