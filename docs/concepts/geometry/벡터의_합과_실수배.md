# 벡터의 합과 실수배

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
평행사변형 법칙

## 본문 (학습 시 채워짐)

### 정확한 진술

두 벡터 $\vec{a}$, $\vec{b}$의 **합** $\vec{a} + \vec{b}$는 다음과 같이 정의합니다: $\vec{a}$의 시점을 $O$라 할 때, $\vec{a}$의 종점을 $A$, $\vec{b}$의 시점을 $A$로 옮겨 그 종점을 $B$라 하면, $\vec{a} + \vec{b} = \overrightarrow{OB}$입니다. 이를 **삼각형 법칙**이라 합니다.

벡터 $\vec{a}$와 실수 $k$에 대하여 **실수배** $k\vec{a}$는: $k > 0$일 때 $\vec{a}$와 같은 방향으로 크기가 $|k||\vec{a}|$인 벡터, $k < 0$일 때 $\vec{a}$와 반대 방향으로 크기가 $|k||\vec{a}|$인 벡터, $k = 0$일 때 영벡터 $\vec{0}$입니다.

### 직관과 기하적 의미

벡터의 합은 **평행사변형 법칙**으로도 이해할 수 있습니다: $\vec{a}$와 $\vec{b}$를 같은 시점 $O$에서 그으면, 이 두 벡터를 인접한 두 변으로 하는 평행사변형을 그렸을 때, 그 대각선이 $\vec{a} + \vec{b}$입니다. 이 그림으로 벡터 합의 교환법칙 $\vec{a} + \vec{b} = \vec{b} + \vec{a}$를 시각적으로 확인할 수 있습니다.

실수배는 벡터의 **방향은 유지하면서 크기를 조절**하는 연산입니다. 2$\vec{a}$는 $\vec{a}$의 크기를 2배로 늘인 같은 방향의 벡터이고, $-\vec{a}$는 정반대 방향으로 같은 크기의 벡터입니다. 이를 통해 서로 평행한 벡터들의 관계를 단순히 표현할 수 있습니다.

### 성질과 연산

벡터의 합과 실수배는 다음 성질을 만족합니다:
- 결합법칙: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
- 분배법칙: $k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$, $(k + m)\vec{a} = k\vec{a} + m\vec{a}$

이 성질들은 벡터를 좌표로 나타낼 때 성분별 연산으로 자동으로 확인됩니다. 예를 들어 $\vec{a} = (2, 1)$, $\vec{b} = (1, 3)$이면 $\vec{a} + \vec{b} = (3, 4)$이고, $2\vec{a} = (4, 2)$입니다.
