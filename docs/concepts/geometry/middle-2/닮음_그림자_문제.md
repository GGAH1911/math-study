# 닮음 그림자 문제

> **예제** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
실제 높이 계산

## 본문 (학습 시 채워짐)

### 문제

어떤 시간에 키 160 cm인 학생이 햇빛 아래 서 있고, 학생의 그림자 길이가 80 cm이다. 같은 시간에 학교 건물의 그림자 길이가 1200 cm일 때, 건물의 실제 높이는 몇 cm인가?

### 풀이

**1단계: 상황 파악하기**

같은 시간에 햇빛이 같은 각도로 내리므로, 학생과 건물이 만드는 두 직각삼각형이 닮음이다. 태양광이 평행하다는 물리적 사실이 닮음을 보장하는 핵심이다.

**2단계: 닮음비 구하기**

학생은 높이와 그림자로 된 직각삼각형, 건물도 마찬가지다. 두 삼각형이 닮음이므로 대응변의 비가 같다.

$$\frac{\text{학생의 높이}}{\text{학생의 그림자}} = \frac{\text{건물의 높이}}{\text{건물의 그림자}}$$

**3단계: 식 세우기**

$$\frac{160}{80} = \frac{h}{1200}$$

여기서 $h$는 건물의 높이다. 좌변을 정리하면 닮음비 2를 얻는다.

**4단계: 건물 높이 구하기**

$$2 = \frac{h}{1200}$$
$$h = 2 \times 1200 = 2400$$

따라서 건물의 높이는 **2400 cm**, 즉 **24 m**이다.

(검산: `160 * 1200 / 80 = 2400`)

### 답

2400 cm (또는 24 m)

### 주의·응용

- **그림자의 각도**: 시간이 지나면 태양의 위치가 바뀌어 같은 물체의 그림자 길이도 변한다. 문제에서 "같은 시간"이라는 조건이 중요한 이유다.
- **직각삼각형 확인**: 높이와 그림자는 항상 수직이므로 자동으로 직각삼각형을 이룬다.
- **확장**: 그림자 대신 거울상(반사)이 주어져도 같은 원리로 풀 수 있다. 두 닮음 삼각형의 대응변 비가 일정하다는 본질을 꿰뚫으면 어떤 배치에도 적용된다.
