# 도형의 닮음과 피타고라스

> **단원** · 중2 · 선수: [도형의 성질](/concepts/도형의_성질) / [식의 계산](/concepts/식의_계산) · 다음: [삼각비](/concepts/삼각비)

## 학습 목표
- 두 도형의 닮음비를 구하고 활용할 수 있다
- 피타고라스 정리로 직각삼각형의 변을 구한다

## 다룰 정의 / 정리 / 예제

**정의**
- [닮음](/concepts/닮음) — 닮음비
- 직각삼각형

**정리**
- 닮음비 = 대응변의 비
- [피타고라스 정리](/concepts/피타고라스_정리) — $a^2+b^2=c^2$
- 닮음비$^2$ = 넓이비, 닮음비$^3$ = 부피비

**예제**
- 삼각형의 중점연결정리 응용
- 피타고라스 역정리로 직각판별
- 닮음 활용 그림자·축적 문제

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
