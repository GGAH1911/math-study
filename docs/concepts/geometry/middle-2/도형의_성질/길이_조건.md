# 길이 조건

## 정확한 진술

세 선분의 길이가 각각 $a$, $b$, $c$일 때, 이들이 삼각형의 세 변을 이룰 수 있기 위한 **필요충분조건**을 **길이 조건**이라고 합니다. 세 부등식을 모두 만족해야 합니다:

$$a + b > c, \quad b + c > a, \quad c + a > b$$

또는 가장 긴 변을 $c$라 할 때, $a + b > c$만 확인하면 충분합니다.

## 직관과 기하적 의미

평면 위의 세 점 $A$, $B$, $C$를 연결하려고 합니다. 만약 가장 긴 변의 길이가 나머지 두 변의 합보다 크거나 같으면, 세 점이 일직선상에 놓이거나 평면 자체를 이루지 못합니다. 직관적으로 "가장 긴 변이 너무 길면 나머지 두 변이 그것을 잇지 못한다"는 의미입니다.

역으로 길이 조건을 만족하면, 항상 유일한 삼각형을 그릴 수 있습니다. 이 조건은 **삼각형 부등식**(triangle inequality)이라 부르며, 좌표평면에서 거리 개념의 기초가 됩니다.

## 한 줄 예

길이가 $3$, $4$, $5$인 선분들: $3+4=7>5$ ✓ 모든 조건 만족 → 삼각형 가능  
길이가 $1$, $2$, $5$인 선분들: $1+2=3 \not> 5$ ✗ → 삼각형 불가능
