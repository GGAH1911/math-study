# 각의 이등분선 성질

각의 이등분선 위의 점이 양변까지의 거리가 같다는 성질입니다. 기하 단원에서 자취·이차곡선의 광학적 성질을 다룰 때 활용됩니다.

## 정의

한 각 $\angle \mathrm{XOY}$의 내부의 점 $\mathrm{P}$가 두 변 $\mathrm{OX}, \mathrm{OY}$로부터의 거리가 같다는 것은 $\mathrm{P}$가 $\angle \mathrm{XOY}$의 **이등분선** 위에 있다는 것과 동치입니다. 즉,
$$d(\mathrm{P}, \mathrm{OX}) = d(\mathrm{P}, \mathrm{OY}) \iff \mathrm{P} \in \text{이등분선}.$$

이는 자취 문제에서 두 직선까지의 거리가 같은 점들의 집합이 각 이등분선이라는 사실로 이어집니다. 또한 타원·쌍곡선의 광학적 성질(접선이 두 초점과 이루는 각의 이등분선)과도 연관됩니다.

## 예시

두 직선 $\ell_1: y = 0$ (즉 $x$축)과 $\ell_2: y = x$ 사이의 각의 이등분선 중 하나를 구해 봅니다. 임의의 점 $(x, y)$로부터 $\ell_1$까지의 거리는 $|y|$, $\ell_2: x - y = 0$까지의 거리는 $\dfrac{|x - y|}{\sqrt{2}}$.

이 둘이 같다는 조건 $|y| = \dfrac{|x - y|}{\sqrt{2}}$를 정리하면 두 이등분선의 식을 얻습니다(예각·둔각 각각 한 개).
