# 이등변삼각형

> **정의** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
두 변의 길이가 같은 삼각형입니다.

## 본문
이등변삼각형은 두 변의 길이가 같은 삼각형을 의미합니다. 삼각형 $ABC$에서 $AB = AC$일 때, 이를 이등변삼각형이라 하며, 길이가 같은 두 변 $AB$와 $AC$를 다리라고 부르고 나머지 변 $BC$를 밑변이라고 합니다. 이때 두 다리가 만나는 점 $A$는 꼭짓점이 됩니다.

### 직관과 기하적 의미
이등변삼각형의 핵심적인 특징은 좌우 대칭 구조를 가진다는 점입니다. 꼭짓점에서 밑변에 내린 수선은 밑변을 정확히 이등분하며, 이 직선이 삼각형의 대칭축 역할을 수행합니다. 따라서 이등변삼각형은 축을 중심으로 접었을 때 완전히 포개어지는 대칭성을 가집니다.

### 기본 성질
이등변삼각형의 가장 중요한 성질은 두 다리의 길이가 같으면 그 밑각의 크기도 같다는 것입니다. 즉, $AB = AC$이면 $\angle ABC = \angle ACB$가 성립합니다. 이 성질은 역으로 두 각의 크기가 같은 삼각형도 이등변삼각형이 된다는 양방향 성질을 포함합니다. 또한, 꼭짓점에서의 각의 이등분선은 밑변에 수직이며 밑변의 중점을 지나는 성질을 가집니다.

예를 들어 세 변의 길이가 5, 5, 7인 삼각형은 이등변삼각형에 해당하며, 길이가 같은 두 변이 만나는 꼭짓점의 대각을 제외한 나머지 두 밑각의 크기는 서로 같습니다. 한편, 모든 변의 길이가 같은 정삼각형은 이등변삼각형의 특수한 형태로서 세 각이 모두 $60^{\circ}$로 같습니다.

## 학습 체크

- 꼭짓점의 각의 이등분선이 밑변을 수직이등분한다는 성질을 활용할 수 있는가?
