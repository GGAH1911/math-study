# 평행사변형의 성질

## 정확한 진술
평행사변형(parallelogram)은 두 쌍의 대변(마주보는 변)이 각각 평행한 사각형입니다. 사각형 $ABCD$에서 변 $AB \parallel CD$이고 동시에 변 $BC \parallel AD$를 만족할 때, 이를 평행사변형이라고 정의합니다.

## 직관/기하적 의미
"두 쌍의 대변이 평행하다"는 단순한 조건이 얼마나 강력한지 이해하는 것이 중요합니다. 평행사변형에서는 이 조건만으로도 다음과 같은 성질들이 자동으로 따라옵니다:

**대변의 길이 같음**: 평행한 두 변의 길이는 항상 같습니다. 즉, $AB = CD$이고 $BC = AD$입니다.

**대각 같음**: 마주보는 두 각도는 항상 같습니다. 즉, $\angle A = \angle C$이고 $\angle B = \angle D$입니다.

**대각선 이등분**: 두 대각선이 교차하는 점을 중심으로, 각 대각선이 정확히 반으로 나뉩니다.

기하학적으로 보면, 한 변을 고정하고 평행한 선 위에 대변을 배치하면 도형의 모양이 자동으로 결정되는데, 이것이 평행사변형이 '평행'이라는 조건만으로 정의될 수 있는 이유입니다.

## 한 줄 예
변의 길이가 $5\text{ cm}$과 $3\text{ cm}$이고 한 각도가 $60°$인 평행사변형에서, 마주보는 각도는 모두 $60°$ (또는 $120°$)이고 인접한 각도의 합은 항상 $180°$입니다.
