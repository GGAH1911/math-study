# 이등변삼각형 성질

> **정리** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
두 변의 길이가 같은 삼각형에서 두 밑각의 크기는 서로 같습니다.

## 본문
삼각형 $ABC$에서 $AB = AC$이면 $\angle B = \angle C$입니다. 이때 길이가 같은 두 변 $AB$와 $AC$를 등변이라 하며, 두 등변이 만나는 각 $\angle A$를 꼭짓각, 나머지 두 각 $\angle B$와 $\angle C$를 밑각이라고 합니다. 즉, 두 변의 길이가 같은 삼각형에서는 그 두 변을 잇는 꼭짓점에 마주보는 두 각의 크기가 같습니다.

### 증명 스케치
각 $A$의 이등분선이 밑변 $BC$와 만나는 점을 $D$라고 가정합니다. 이때 $AB = AC$이고, 각의 이등분선에 의해 $\angle BAD = \angle CAD$이며, 선분 $AD$는 두 삼각형이 공통으로 가지는 변입니다. 따라서 삼각형 $ABD$와 삼각형 $ACD$는 두 변의 길이와 그 사이의 각이 같으므로 SAS 합동 조건에 의해 서로 합동입니다. 합동인 두 삼각형의 대응각은 같으므로 $\angle ABD = \angle ACD$, 즉 $\angle B = \angle C$가 성립합니다.

### 의의와 응용
이 정리의 역도 성립하여, 삼각형의 두 각의 크기가 같으면 그 대변의 길이도 같습니다. 이는 도형의 대칭성을 파악하는 중요한 도구가 됩니다. 모든 변의 길이와 모든 각의 크기가 같은 정삼각형은 이등변삼각형의 특수한 형태입니다. 또한 좌표평면에서 두 점으로부터 같은 거리에 있는 점들의 자취인 수직이등분선을 구할 때나, 삼각형의 변과 각 사이의 관계를 이용해 합동을 증명할 때 유용하게 활용됩니다.
