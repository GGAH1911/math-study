# 선분의 길이

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 잇는 선분 $AB$의 길이는 다음 공식으로 정의됩니다.

$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

일반적으로 이를 **거리 공식**(distance formula)이라고 부르며, 선분의 길이는 항상 0 이상의 실수입니다.

## 직관/기하적 의미

두 점 사이의 거리는 **피타고라스 정리**에서 비롯됩니다. 두 점을 연결하되, 한 점에서 다른 점으로 수평 이동한 거리가 $|x_2 - x_1|$이고 수직 이동한 거리가 $|y_2 - y_1|$일 때, 이 둘을 직각삼각형의 두 변으로 생각하면 빗변의 길이가 바로 선분의 길이입니다. 제곱의 합에 루트를 취하는 이유는 음수를 피하고(절댓값이므로), 두 방향의 거리를 동등하게 취급하기 위함입니다.

## 한 줄 예

$A(1, 2)$, $B(4, 6)$일 때, $|AB| = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$ (sympy: `sympy.sqrt((4-1)**2 + (6-2)**2)`로 검증 가능)

## 수직선에서의 특수한 경우

한 직선 위의 두 점, 예를 들어 $A(a)$, $B(b)$일 때는 $|AB| = |b - a|$로 단순화됩니다. 이는 일반 공식에서 수직 이동이 0이 되기 때문입니다.
