# 사다리꼴의 성질

> **정의** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
한 쌍의 대변이 평행한 사각형으로, 두 다리의 중점을 연결한 선분의 길이는 두 밑변 길이의 평균과 같습니다.

## 본문
사다리꼴은 정확히 한 쌍의 대변이 평행한 사각형을 의미합니다. 이때 평행한 두 변을 밑변 또는 평행변이라 부르고, 평행하지 않은 나머지 두 변을 다리 또는 비평행변이라고 합니다. 만약 평행하지 않은 두 다리의 길이가 서로 같다면 이를 이등변사다리꼴이라고 부릅니다.

### 직관과 기하적 의미
사다리꼴의 구조를 이해하는 핵심은 평행선과 그 사이의 관계를 파악하는 것입니다. 밑변이 서로 평행하기 때문에, 각 밑변과 만나는 같은 쪽 내각의 합은 항상 $180^\circ$가 되는 동측내각의 성질을 가집니다. 또한 사다리꼴 내부의 중점연결선은 사다리꼴을 두 개의 작은 사다리꼴로 분할하는 기하학적 구조를 형성합니다.

### 기본 성질
사다리꼴에서 두 다리의 중점을 연결한 선분인 중점연결선은 두 밑변과 평행하며, 그 길이는 두 밑변 길이의 산술평균과 같습니다. 이를 수식으로 나타내면 다음과 같습니다.
$$m = \frac{a+b}{2}$$
여기서 $a$와 $b$는 두 밑변의 길이, $m$은 중점연결선의 길이입니다. 예를 들어 밑변의 길이가 각각 $4$와 $2$인 사다리꼴에서 중점연결선의 길이는 $\frac{4+2}{2} = 3$이 됩니다.

## 학습 체크
- 사다리꼴에서 평행하지 않은 두 변의 길이가 같을 때 부르는 명칭은 무엇인가요?
- 중점연결선의 길이를 구하기 위해 필요한 두 밑변의 정보는 무엇인가요?
- 사다리꼴의 한 밑변과 다른 밑변이 만날 때, 같은 쪽에 있는 두 내각의 합은 몇 도인가요?

## 관련 개념
- **일차함수**: 좌표평면 위에서 사다리꼴의 변을 직선의 방정식으로 나타낼 때 일차함수의 기울기와 절편 개념이 활용됩니다.
