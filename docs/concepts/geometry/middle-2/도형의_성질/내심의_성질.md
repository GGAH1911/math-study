# 내심의 성질

> **정의** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
내심은 삼각형의 세 내각의 이등분선의 교점이며, 세 변에 이르는 거리가 모두 같은 내접원의 중심입니다.

## 본문
내심(내접원의 중심)은 삼각형의 세 내각의 이등분선이 모두 만나는 점입니다.

### 직관과 기하적 의미
내심의 핵심 성질은 삼각형의 세 변까지의 거리가 모두 같다는 것입니다. 이 공통 거리를 $r$이라 하면, 이것이 바로 삼각형에 내접하는 원(내접원)의 반지름이 됩니다. 삼각형의 꼭짓점이 $A, B, C$이고 대변의 길이가 각각 $a=BC, b=CA, c=AB$일 때, 내심 $I$의 좌표는 세 변의 길이를 무게로 삼아 다음과 같이 표현할 수 있습니다.
$$I = \frac{aA + bB + cC}{a + b + c}$$

### 기본 성질
내접원의 반지름 $r$은 삼각형의 넓이 $S$와 반둘레 $s$를 이용하여 구할 수 있습니다. 여기서 반둘레 $s$는 $\tfrac{a+b+c}{2}$로 정의됩니다.
$$r = \frac{S}{s}$$

예를 들어, 꼭짓점이 $A(0, 0), B(4, 0), C(0, 3)$인 직각삼각형의 경우 각 변의 길이는 $a=5, b=3, c=4$입니다. 이때 내심의 좌표는 다음과 같이 계산됩니다.
$$I = \frac{5(0,0) + 3(4,0) + 4(0,3)}{5+3+4} = (1, 1)$$
삼각형의 넓이 $S=6$이고 반둘레 $s=6$이므로, 내접원의 반지름 $r=1$이 됩니다. 실제로 점 $(1, 1)$에서 각 변까지의 거리는 모두 1로 동일합니다.

## 학습 체크
- 삼각형의 세 내각의 이등분선이 한 점에서 만나는지 확인할 수 있는가?
- 내심에서 각 변에 내린 수선의 길이가 모두 같음을 이해하고 있는가?
- 삼각형의 넓이와 둘레의 길이를 이용하여 내접원의 반지름을 구할 수 있는가?

## 관련 개념
- **기본 도형**: 점, 선, 면과 같은 가장 기초적인 요소들이 모여 삼각형을 형성하며, 내심은 이러한 도형의 내부 성질을 결정합니다.
- **외심**: 삼각형의 세 변의 수직이등분선의 교점으로, 내심과는 달리 세 꼭짓점까지의 거리가 모두 같습니다.
