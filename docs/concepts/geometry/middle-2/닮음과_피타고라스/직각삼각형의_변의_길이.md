# 직각삼각형의 변의 길이

## 정확한 정의

직각삼각형에서 변의 길이를 다룰 때, 세 변을 다음과 같이 분류합니다. 직각(90°)을 이루는 두 변을 **직각변**(leg)이라 부르고, 직각의 대변을 **빗변**(hypotenuse)이라 부릅니다. 빗변의 길이를 $c$, 두 직각변의 길이를 $a$, $b$라 하면, 피타고라스 정리에 의해 다음이 항상 성립합니다.

$$a^2 + b^2 = c^2$$

## 기하적 의미

직각삼각형에서 한 각을 $\theta$라 할 때, **대변**(opposite side)은 각 $\theta$의 맞은편 직각변이고, **인접변**(adjacent side)은 각 $\theta$와 만나는 직각변입니다. 삼각비는 이들 변의 길이 비로 정의됩니다.

$$\sin\theta = \frac{\text{대변}}{c}, \quad \cos\theta = \frac{\text{인접변}}{c}, \quad \tan\theta = \frac{\text{대변}}{\text{인접변}}$$

이 관계식들을 역으로 이용하면, 각도와 한 변의 길이가 주어졌을 때 나머지 변의 길이를 구할 수 있습니다. 예를 들어 빗변 $c$와 각 $\theta$를 알면 대변 = $c\sin\theta$, 인접변 = $c\cos\theta$로 구합니다.

## 예

빗변의 길이가 10이고 한 직각변이 6인 직각삼각형을 생각해봅시다. 피타고라스 정리를 적용하면 나머지 직각변의 길이는

$$\sqrt{10^2 - 6^2} = \sqrt{64} = 8$$

입니다. 검산: `sympy.sqrt(100 - 36)` = 8 ✓
