# 닮음비

> **정의** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
두 닮은 도형에서 대응하는 변의 길이의 비를 의미합니다.

## 본문
두 도형이 닮음일 때, 대응하는 변의 길이의 비를 **닮음비**라고 합니다. 예를 들어 삼각형 $ABC$와 삼각형 $DEF$가 닮음이고 대응변의 비가 $AB : DE = BC : EF = CA : FD = 2 : 1$이면, 두 삼각형의 닮음비는 $2 : 1$입니다. 닮음인 도형의 모든 대응변의 비는 항상 일정하며, 이 비율에 의해 닮음비가 하나로 결정됩니다.

### 직관과 기하적 의미
닮음비는 한 도형을 얼마나 확대 또는 축소했는지를 나타내는 크기 비율입니다. 닮음비가 $k : 1$이면 첫 번째 도형이 두 번째 도형을 $k$배 확대한 것임을 의미합니다. 실생활에서는 지도상의 거리와 실제 거리의 비율인 축척이나, 축소 모형 자동차 등이 닮음비의 대표적인 예시입니다.

### 기본 성질
닮음비가 $k : 1$일 때, 도형의 넓이의 비는 $k^2 : 1$이 되고, 부피의 비는 $k^3 : 1$이 됩니다. 이는 도형의 길이는 $k$배로 변하지만, 넓이는 길이의 제곱에 비례하여 변하고, 부피는 길이의 세제곱에 비례하여 변한다는 중요한 성질을 나타냅니다. 예를 들어 한 변의 길이가 $8\text{ cm}$인 삼각형과 대응변이 $4\text{ cm}$인 닮은 삼각형의 닮음비는 $2 : 1$이며, 이때 두 삼각형의 넓이 비는 $4 : 1$이 됩니다.

## 학습 체크
- 대응변의 길이의 비를 통해 닮음비를 구할 수 있는가?
- 닮음비가 주어졌을 때 넓이와 부피의 변화 비율을 계산할 수 있는가?

## 관련 개념
- **닮음과 피타고라스**: 닮은 도형의 성질을 이용하여 피타고라스 정리를 증명하거나, 닮음비를 통해 피타고라스 정리와 관련된 변의 길이를 구할 수 있습니다.
