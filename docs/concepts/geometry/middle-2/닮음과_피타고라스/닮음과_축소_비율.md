# 닮음과 축소 비율

> **정의** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/도형의_닮음과_피타고라스)

## 요약
두 도형이 같은 모양을 유지하며 크기만 변하는 관계를 닮음이라 하며, 이때 대응하는 변의 길이의 비를 닮음비 또는 축소 비율이라 합니다.

## 본문
두 도형이 닮음이라는 것은 한 도형을 일정한 비율로 확대하거나 축소하고 필요에 따라 회전하거나 평행이동했을 때, 다른 도형과 정확히 겹쳐지는 관계를 의미합니다. 이때 대응하는 변의 길이의 비를 닮음비라 하며, 도형이 작아지는 비율을 구체적으로 나타낼 때 축소 비율 $k$를 사용합니다 ($0 < k \leq 1$). 만약 원래 도형의 선분 길이가 $\ell$이라면, 축소 비율 $k$를 적용하여 축소된 도형의 대응 선분의 길이는 $k\ell$이 됩니다.

### 직관과 기하적 의미
닮음과 축소 비율은 "같은 모양, 다른 크기"라는 기하학적 직관을 수학적으로 정교하게 표현한 것입니다. 이는 지도, 축도, 사진 축소 등 실생활에서 매우 흔하게 발견되는 원리입니다. 축소 비율 $k$는 $0$과 $1$ 사이의 값을 가지며, $k$의 값이 작을수록 도형은 더 많이 축소됩니다. 특히 축소 비율이 $0$에 점점 가까워지면 도형은 결국 한 점으로 수렴하게 되는데, 이는 반복적인 축소가 일어날 때 대상이 사라지는 것과 같은 수학적 의미를 갖습니다.

### 기본 성질
축소 비율 $k$가 $0$과 $1$ 사이일 때, 도형을 반복적으로 축소하면 대응하는 변의 길이는 기하급수적으로 감소합니다. 예를 들어 한 변의 길이가 $4\text{cm}$인 정사각형을 축소 비율 $k=0.5$로 계속 축소하면, 변의 길이는 $4, 2, 1, 0.5, 0.25, \ldots$와 같이 변하며 결국 $0$을 향해 나아갑니다.

## 학습 체크
- 닮음비가 $2:3$일 때, 축소 비율 $k$의 값은 얼마인가요?
- 원래 도형의 길이가 $\ell$일 때, 축소 비율 $k$를 적용한 후의 길이를 식으로 나타내 보세요.
- 축소 비율 $k$가 $1$보다 크다면 도형은 어떻게 변하나요?

## 관련 개념
- **수열의 극한**: 축소 비율 $k$가 $0$과 $1$ 사이일 때, 반복적인 축소 과정에서 변의 길이 수열 $\{k^n\}$은 $0$으로 수렴하게 됩니다.
