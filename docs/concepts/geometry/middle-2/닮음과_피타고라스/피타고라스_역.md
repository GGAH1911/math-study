# 피타고라스 역

> **정리** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
$a^2 + b^2 = c^2$을 만족하는 세 변의 길이를 가진 삼각형은 반드시 빗변의 길이가 $c$인 직각삼각형이다.

## 본문
세 실수 $a, b, c > 0$이 $a^2 + b^2 = c^2$을 만족할 때, 이 세 수를 세 변의 길이로 하는 삼각형은 반드시 직각삼각형이며, 길이 $c$인 변이 빗변이다.

### 증명 스케치
주어진 조건으로부터 직각이 존재함을 보이기 위해, 같은 성질을 가진 직각삼각형을 먼저 구성한다. 두 변의 길이가 각각 $a, b$이고 그 사이 각이 $90^\circ$인 직각삼각형을 그린다. 피타고라스 정리를 적용하면 이 삼각형의 빗변 $c'$는 $c'^2 = a^2 + b^2$을 만족한다. 이때 주어진 조건 $a^2 + b^2 = c^2$과 비교하면 $c' = c$이다. 즉, 두 삼각형의 세 변이 모두 일치하므로 SSS 합동에 의해 두 삼각형은 완전히 같은 도형이다. 따라서 원래 주어진 삼각형도 반드시 직각삼각형이며, $c$가 빗변이어야 한다.

### 의의와 응용
피타고라스 정리와 달리, 역정리는 각도를 측정하지 않고도 세 변의 길이만으로 직각 여부를 판정할 수 있게 해준다. 실생활에서 건설 현장이나 목공 작업 시 직각을 확인하는 데 활용된다.

예를 들어 변의 길이가 3, 4, 5일 때 $3^2 + 4^2 = 9 + 16 = 25 = 5^2$이므로 이는 직각삼각형이다(이집트 삼각형). 또 다른 예로 (5, 12, 13)도 $5^2 + 12^2 = 25 + 144 = 169 = 13^2$를 만족하는 직각삼각형을 이룬다. 이러한 세 자연수의 조합을 **피타고라스 수**라 부른다.
