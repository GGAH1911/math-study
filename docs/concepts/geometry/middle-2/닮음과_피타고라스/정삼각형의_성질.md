# 정삼각형의 성질

## 정확한 진술

세 변의 길이가 모두 같은 삼각형을 **정삼각형**이라고 합니다. 한 변의 길이를 $a$라 할 때, 정삼각형의 주요 성질은 다음과 같습니다:

- 세 내각이 모두 $60°$로 같음
- 높이(한 꼭짓점에서 대변까지의 수선): $h = \frac{\sqrt{3}}{2}a$
- 넓이: $S = \frac{\sqrt{3}}{4}a^2$

## 직관/기하적 의미

정삼각형은 가장 대칭적인 삼각형입니다. 한 변의 길이가 $a$인 정삼각형에서 꼭짓점에서 대변에 내린 수선은 대변을 이등분합니다. 이렇게 만들어진 직각삼각형에 피타고라스 정리를 적용하면:

$$h^2 + \left(\frac{a}{2}\right)^2 = a^2$$

$$h^2 = a^2 - \frac{a^2}{4} = \frac{3a^2}{4}$$

$$h = \frac{\sqrt{3}}{2}a$$

이 높이를 이용하면 넓이는 $S = \frac{1}{2} \times a \times h = \frac{1}{2} \times a \times \frac{\sqrt{3}}{2}a = \frac{\sqrt{3}}{4}a^2$가 됩니다. 정삼각형의 모든 기하적 성질은 이 하나의 높이 공식에서 유도됩니다.

## 한 줄 예

한 변의 길이가 $2$인 정삼각형의 높이는 $\sqrt{3}$이고, 넓이는 $\sqrt{3}$입니다. (`from sympy import sqrt, simplify; h = sqrt(3)/2 * 2; area = sqrt(3)/4 * 2**2; print(f"높이: {h}, 넓이: {area}")` → 높이: $\sqrt{3}$, 넓이: $\sqrt{3}$)
