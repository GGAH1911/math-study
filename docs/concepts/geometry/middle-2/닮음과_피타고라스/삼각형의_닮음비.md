# 삼각형의 닮음비

## 정확한 진술

두 삼각형이 닮음일 때, 한 삼각형의 대응하는 변의 길이를 다른 삼각형의 변의 길이로 나눈 비를 **닮음비**라고 합니다. 삼각형 $ABC$와 삼각형 $A'B'C'$가 닮음이고 대응하는 변의 길이가 $AB : A'B' = BC : B'C' = CA : C'A' = k : 1$이면, 두 삼각형의 닮음비는 $k : 1$입니다.

## 직관과 기하적 의미

닮음비는 두 도형의 "크기 차이"를 나타냅니다. 같은 모양의 삼각형들이 있을 때, 한 삼각형을 몇 배로 확대하거나 축소하면 다른 삼각형이 되는데, 이 확대/축소 배율이 바로 닮음비입니다.

중요한 성질들:
- **대응하는 모든 변의 비**가 같으므로, 한 쌍의 변만 비교해도 닮음비를 알 수 있습니다.
- **넓이의 비**는 닮음비의 제곱이 됩니다. 예를 들어 닮음비가 $2:1$이면 넓이 비는 $4:1$입니다.
- **둘레의 비**도 닮음비와 같습니다.

## 한 줄 예

삼각형 $ABC$의 각 변의 길이가 3, 4, 5이고, 이와 닮음인 삼각형 $A'B'C'$의 변이 6, 8, 10이면, 닮음비는 $1:2$ (또는 $2:1$이라고 쓸 수도 있음)입니다.

```python
# 검산: 대응하는 변의 비가 모두 같은지 확인
ratios = [6/3, 8/4, 10/5]  # [2.0, 2.0, 2.0] → 닮음비 2:1
```
