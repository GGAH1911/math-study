# 직각삼각형의 높이

> **정의** · 중2 · 단원: [닮음과 피타고라스](/concepts/닮음과_피타고라스)

직각삼각형의 직각인 꼭짓점에서 빗변에 내린 수선의 길이입니다. 중2 닮음과 피타고라스 단원에서 닮음을 통한 길이 관계 풀이의 핵심입니다.

## 정의

직각삼각형 $\triangle \mathrm{ABC}$에서 $\angle \mathrm{C} = 90^\circ$일 때, 꼭짓점 $\mathrm{C}$에서 빗변 $\overline{\mathrm{AB}}$에 내린 수선의 발을 $\mathrm{H}$라 하고 $\overline{\mathrm{CH}} = h$를 **높이**라 합시다. 수선의 발이 빗변을 $\overline{\mathrm{AH}} = p,\ \overline{\mathrm{HB}} = q$로 나누면 다음의 닮음 관계식이 성립합니다.
$$h^2 = pq,\quad a^2 = q(p+q),\quad b^2 = p(p+q).$$
여기서 $a = \overline{\mathrm{BC}}, b = \overline{\mathrm{AC}}, c = \overline{\mathrm{AB}} = p + q$.

또한 직각삼각형의 넓이는 두 가지 방법으로 표현되어 $\dfrac{1}{2}ab = \dfrac{1}{2}ch$이므로
$$h = \frac{ab}{c}.$$

## 예시

직각을 낀 두 변이 $6, 8$인 직각삼각형의 빗변은 $\sqrt{36 + 64} = 10$. 빗변에 내린 수선(높이)의 길이는
$$h = \frac{6 \cdot 8}{10} = \frac{48}{10} = 4.8.$$
