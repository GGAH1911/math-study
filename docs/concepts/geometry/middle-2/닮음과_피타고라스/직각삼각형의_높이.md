# 직각삼각형의 높이

> **정의** · 중2 · 단원: [닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
직각삼각형의 직각인 꼭짓점에서 빗변에 내린 수선의 길이를 의미하며, 삼각형의 넓이 공식과 닮음비를 통해 구할 수 있습니다.

## 본문
직각삼각형 $\triangle \mathrm{ABC}$에서 $\angle \mathrm{C} = 90^\circ$일 때, 꼭짓점 $\mathrm{C}$에서 빗변 $\overline{\mathrm{AB}}$에 내린 수선의 발을 $\mathrm{H}$라 하고 $\overline{\mathrm{CH}} = h$를 **높이**라고 정의합니다. 이때 수선의 발이 빗변을 $\overline{\mathrm{AH}} = p, \overline{\mathrm{HB}} = q$로 나누면, 삼각형의 닮음 성질에 의해 $h^2 = pq$라는 관계가 성립합니다. 또한 각 변의 길이를 $a = \overline{\mathrm{BC}}, b = \overline{\mathrm{AC}}, c = \overline{\mathrm{AB}} = p + q$라고 할 때, $a^2 = q(p+q)$와 $b^2 = p(p+q)$의 관계도 함께 성립합니다.

### 직관과 기하적 의미
직각삼각형의 높이는 삼각형의 넓이를 구하는 두 가지 관점을 연결하는 핵심 요소입니다. 삼각형의 넓이를 구할 때 밑변을 빗변($c$)으로 보고 높이($h$)를 사용하면 $\frac{1}{2}ch$가 되고, 직각을 낀 두 변($a, b$)을 각각 밑변과 높이로 보면 $\frac{1}{2}ab$가 됩니다. 이 두 값이 같아야 하므로 $h = \frac{ab}{c}$라는 관계식이 도출됩니다. 이는 직각삼각형 내부의 닮은 삼각형들이 서로의 변의 길이를 결정하는 기하학적 구조를 가지고 있음을 의미합니다.

### 기본 성질
1. 닮음비에 의한 관계: $h^2 = pq$, $a^2 = q(p+q)$, $b^2 = p(p+q)$
2. 넓이를 이용한 관계: $h = \frac{ab}{c}$
3. 예시: 직각을 낀 두 변이 $6, 8$인 직각삼각형의 빗변은 $10$이므로, 높이 $h$는 $\frac{6 \times 8}{10} = 4.8$입니다.

## 학습 체크
- 직각삼각형의 두 직각을 낀 변의 길이와 빗변의 길이를 알 때, 높이를 구하는 공식은 무엇인가?
- 수선의 발에 의해 나누어진 빗변의 두 선분 길이 $p, q$를 이용하여 높이 $h$를 어떻게 구할 수 있는가?
- 직각삼각형의 넓이 공식을 이용하여 높이 $h$를 구하는 과정이 왜 타당한가?
