# 피타고라스 정리

> **정리** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
직각삼각형에서 두 직각변의 길이의 제곱의 합은 빗변의 길이의 제곱과 같다.

## 본문
직각삼각형의 두 직각변의 길이를 $a$, $b$, 빗변의 길이를 $c$라 하면 $a^2 + b^2 = c^2$이 성립한다. 이를 피타고라스 정리라고 한다. 이 정리는 역으로 세 변의 길이 $a, b, c$가 $a^2 + b^2 = c^2$을 만족할 때, 해당 삼각형이 $c$를 빗변으로 하는 직각삼각형임을 판정하는 데에도 사용된다.

### 증명 스케치
직각삼각형 $ABC$에서 $\angle C = 90^\circ$이고, $C$에서 빗변 $AB$에 내린 수선의 발을 $H$라 하면 삼각형 $ABC$, $CAH$, $CBH$는 모두 닮음이다. 삼각형 $ABC$와 $CAH$의 닮음비에 의해 $AC^2 = AB \cdot AH$가 성립하고, 삼각형 $ABC$와 $CBH$의 닮음비에 의해 $BC^2 = AB \cdot BH$가 성립한다. 이때 $AH + BH = AB$이므로, 두 식을 더하면 $AC^2 + BC^2 = AB(AH + BH) = AB^2 = c^2$이 되어 정리가 성립한다.

### 의의와 응용
피타고라스 정리는 직각의 유무를 판정하고 도형의 거리를 계산하는 기초가 된다. 좌표평면에서의 두 점 사이의 거리, 공간에서의 벡터의 크기, 삼각함수의 항등식 $\sin^2\theta + \cos^2\theta = 1$ 등이 모두 이 정리에 근거한다. 예를 들어, 두 변의 길이가 $3$과 $4$인 직각삼각형의 빗변은 $\sqrt{3^2 + 4^2} = 5$이다.
