# 닮음

> **정의** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
한 도형을 일정한 비율로 확대하거나 축소했을 때 다른 도형과 완전히 일치하는 관계입니다.

## 본문
두 도형이 닮음이라는 것은 한 도형을 일정한 비율로 확대하거나 축소했을 때 다른 도형과 정확히 같아지는 관계를 말합니다. 더 정확하게는 두 도형의 대응각의 크기가 모두 같고, 대응변의 길이 비가 모두 일정할 때 두 도형은 닮음이라고 합니다. 두 도형 $A$와 $B$가 닮음일 때, 이를 기호로 $A \sim B$와 같이 나타냅니다.

### 직관과 기하적 의미
닮음은 모양은 같지만 크기가 다른 상태를 의미합니다. 사진을 확대하거나 축소할 때 사진 속 풍경의 모양이 변하지 않는 것과 같습니다. 도형을 일정한 비율 $k$인 닮음비로 확대하면, 모든 각도는 그대로 유지되면서 모든 변의 길이는 $k$배가 됩니다. 예를 들어 닮음비가 $2:1$이라면, 한 도형의 모든 변의 길이는 원래 도형의 2배가 됩니다.

### 기본 성질
닮은 두 도형은 다음과 같은 특징을 가집니다. 첫째, 대응하는 각의 크기가 모두 같습니다. 둘째, 대응하는 변의 길이의 비가 모두 일정합니다. 예를 들어 변의 길이가 $3\text{cm}, 4\text{cm}, 5\text{cm}$인 삼각형과 $6\text{cm}, 8\text{cm}, 10\text{cm}$인 삼각형이 있다면, 대응변의 비가 $1:2$로 일정하므로 두 삼각형은 닮음입니다. 실생활에서는 지도가 대표적인 예시로, 축척을 통해 실제 지형의 모양을 일정한 비율로 축소하여 나타냅니다.

## 학습 체크
- 대응각의 크기와 대응변의 길이 비가 모두 같은지 확인할 수 있는가?
- 닮음비가 주어졌을 때 대응하는 변의 길이를 계산할 수 있는가?
- 실생활 상황에서 닮음의 원리가 어떻게 적용되는지 이해하고 있는가?

## 관련 개념
- **닮음과 피타고라스**: 닮은 도형의 성질을 이용하여 피타고라스 정리를 증명하거나, 직각삼각형의 닮음을 통해 변의 길이를 구할 수 있습니다.
