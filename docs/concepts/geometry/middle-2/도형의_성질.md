# 도형의 성질

> **단원** · 중2 · 선수: [작도와 합동](/concepts/작도와_합동) / [평면도형](/concepts/평면도형) · 다음: [닮음과 피타고라스](/concepts/닮음과_피타고라스) / [원의 성질](/concepts/원의_성질)

## 학습 목표
- 이등변삼각형·직각삼각형·다각형의 성질을 증명한다
- 사각형(평행사변형·마름모·정사각형 등)의 성질을 활용한다

## 다룰 정의 / 정리 / 예제

**정의**
- [이등변삼각형](/concepts/이등변삼각형) — 직각삼각형
- [평행사변형](/concepts/평행사변형) — 마름모, 직사각형, 정사각형

**정리**
- 이등변삼각형 두 밑각은 같다
- 평행사변형의 대변·대각은 각각 같다

**예제**
- 평행사변형 됨을 증명
- 특수 사각형 성질로 길이·각 구하기

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
