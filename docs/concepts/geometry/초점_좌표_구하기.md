# 초점 좌표 구하기

> **예제** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
주어진 식에서

## 본문 (학습 시 채워짐)

### 문제

$y^2 + 8x - 4y + 12 = 0$으로 주어진 포물선의 초점의 좌표를 구하시오.

### 단계별 풀이

주어진 방정식을 포물선의 표준형 $(y - k)^2 = 4p(x - h)$로 변환합니다.

**1단계: $y$ 항 정리**

$$y^2 - 4y + 8x + 12 = 0$$

**2단계: $y$에 대해 완전제곱식 만들기**

$y^2 - 4y$를 완전제곱식으로 만들기 위해 4를 더하고 빼면:

$$(y^2 - 4y + 4) - 4 + 8x + 12 = 0$$

$$(y - 2)^2 + 8x + 8 = 0$$

$$(y - 2)^2 = -8x - 8$$

**3단계: 표준형으로 정리**

$$(y - 2)^2 = -8(x + 1)$$

이를 $(y - 2)^2 = 4p(x + 1)$과 비교하면 $4p = -8$, 즉 $p = -2$입니다.

**4단계: 초점 구하기**

포물선의 꼭짓점은 $(-1, 2)$입니다. 포물선의 초점은 꼭짓점에서 축의 방향으로 $p$만큼 떨어진 점이므로:

$$\text{초점} = (-1 + p, 2) = (-1 - 2, 2) = (-3, 2)$$

### 답

$\boxed{(-3, 2)}$

### 변형/주의

**기호 확인:** $p = -2 < 0$이므로 포물선이 $x$축의 음의 방향(왼쪽)으로 열립니다. 초점도 꼭짓점의 왼쪽에 위치합니다.

**완전제곱식 실수:** 상수항을 이동할 때 같은 값을 더한 후 빼야 합니다. $y^2 - 4y + 4 = (y-2)^2$이므로 4를 양변에서 처리합니다.

**타원·쌍곡선과의 차이:** 일반형이 주어졌을 때도 완전제곱식으로 정리해서 표준형을 찾는 과정은 동일합니다. 초점의 거리 공식(타원: $c^2 = a^2 - b^2$, 쌍곡선: $c^2 = a^2 + b^2$)도 그때마다 적용하세요.
