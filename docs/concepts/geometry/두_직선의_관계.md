# 두 직선의 관계

> **정리** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
평행/수직 판정

## 본문 (학습 시 채워짐)

### 진술 및 가정

두 직선 $l_1: y = m_1 x + n_1$과 $l_2: y = m_2 x + n_2$ (단, 두 직선 모두 수직선이 아님)에 대해:
- **평행**: $l_1 \parallel l_2 \Leftrightarrow m_1 = m_2$
- **수직**: $l_1 \perp l_2 \Leftrightarrow m_1 \cdot m_2 = -1$

일반형 $a_1 x + b_1 y + c_1 = 0$과 $a_2 x + b_2 y + c_2 = 0$의 경우, 평행 조건은 $\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$이다.

### 간단한 유도 및 증명 스케치

두 직선의 기울기가 같으면 같은 방향을 가지므로 만나지 않는다(평행). 수직 조건은 방향 벡터를 이용해 유도된다. 한 직선의 방향 벡터를 $(1, m_1)$, 다른 직선을 $(1, m_2)$라 하면, 수직일 때 내적이 0이어야 하므로:
$$1 + m_1 m_2 = 0 \Rightarrow m_1 m_2 = -1$$

일반형에서 평행은 법선 벡터 $(a_1, b_1)$과 $(a_2, b_2)$가 평행함을 의미하며, 이를 계수의 비로 표현한 것이다.

### 의의 및 응용

이 정리는 조건을 만족하는 직선의 방정식을 구할 때 기본이 된다. 예를 들어 점 $(1, 2)$를 지나고 직선 $2x - 3y + 5 = 0$과 평행한 직선은 $2x - 3y + c = 0$ 형태이고, 점을 대입하면 $2(1) - 3(2) + c = 0$에서 $c = 4$이므로 $2x - 3y + 4 = 0$이다. 수직 조건과 함께 원과 직선, 삼각형의 수선 등 다양한 도형 문제에서 필수적이다.
