# 닮음비

> **정의** · 중2 · 단원: [도형의 닮음과 피타고라스](/concepts/닮음과_피타고라스)

## 요약
대응변의 비

## 본문 (학습 시 채워짐)

### 정확한 진술

두 도형이 닮음일 때, 대응하는 변의 길이의 비를 **닮음비**라고 합니다. 삼각형 ABC와 삼각형 DEF가 닮음이고 대응변의 비가 $AB : DE = BC : EF = CA : FD = 2 : 1$이면, 두 삼각형의 닮음비는 $2 : 1$입니다. 닮음인 도형의 모든 대응변의 비는 항상 같다는 것이 닮음의 정의이며, 따라서 닮음비는 하나로 결정됩니다.

### 직관적 의미

닮음비는 한 도형을 얼마나 확대 또는 축소했는지를 나타내는 '크기 비율'입니다. 닮음비가 $k : 1$이면 첫 번째 도형이 두 번째 도형을 $k$배 확대한 것입니다. 지도에서 실제 거리와 지도상 거리의 비(축척), 축소 모형 자동차 등이 실생활의 닮음비 예입니다.

특히 중요한 성질은 닮음비가 $k : 1$일 때, **넓이의 비는 $k^2 : 1$**, **부피의 비는 $k^3 : 1$**이라는 점입니다. 길이는 $k$배 변하지만, 넓이는 $k^2$배, 부피는 $k^3$배로 변한다는 뜻입니다.

### 간단한 예

삼각형의 한 변이 8 cm이고, 이와 닮음인 다른 삼각형의 대응변이 4 cm이면 닮음비는 $8 : 4 = 2 : 1$입니다. 첫 번째 삼각형의 다른 변이 6 cm라면, 두 번째 삼각형의 대응변은 $6 \div 2 = 3$ cm입니다. 두 삼각형의 넓이 비는 $2^2 : 1 = 4 : 1$입니다.
