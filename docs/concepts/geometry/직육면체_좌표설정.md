### 정확한 진술

직육면체의 좌표설정이란 3차원 직교좌표계에서 한 꼭짓점을 원점에 놓고, 세 모서리를 $x$축, $y$축, $z$축 방향으로 배열하는 것입니다. 가로(폭) $a$, 세로(깊이) $b$, 높이 $c$인 직육면체를 설정할 때, 일반적으로 원점을 한 꼭짓점에 두고 나머지 일곱 꼭짓점을 다음과 같이 놓습니다:

$$\text{원점} = (0, 0, 0), \quad (a, 0, 0), \quad (0, b, 0), \quad (0, 0, c), \quad (a, b, 0), \quad (a, 0, c), \quad (0, b, c), \quad (a, b, c)$$

이때 원점에서 출발하는 세 모서리는 좌표축과 평행하므로 모두 서로 수직입니다.

### 직관과 기하적 의미

좌표설정을 이렇게 하는 이유는 계산의 편의성과 대칭성 때문입니다. 직육면체의 모든 모서리가 좌표축과 평행하면, 두 꼭짓점 사이의 거리는 단순히 $\sqrt{(\Delta x)^2 + (\Delta y)^2 + (\Delta z)^2}$로 구할 수 있습니다. 또한 대각선의 길이는 $\sqrt{a^2 + b^2 + c^2}$로 즉시 얻어집니다. 평면이나 직선과의 위치 관계를 판정할 때도 좌표축과의 평행성이 식을 크게 단순화합니다.

### 한 줄 예

가로 3, 세로 4, 높이 5인 직육면체의 꼭짓점은 $(0, 0, 0)$부터 $(3, 4, 5)$까지의 조합 8개이고, 대각선 길이는 $\sqrt{3^2 + 4^2 + 5^2} = \sqrt{50} = 5\sqrt{2}$입니다.
