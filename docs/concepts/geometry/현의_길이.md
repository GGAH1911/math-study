### 정확한 진술

원 위의 두 점을 잇는 선분을 **현**(弦, chord)이라 합니다. 원의 중심을 $O$, 반지름을 $r$, 중심에서 현까지의 거리를 $d$라 할 때, 현의 길이는 다음 공식으로 구합니다:

$$\text{현의 길이} = 2\sqrt{r^2 - d^2}$$

### 직관/기하적 의미

원의 중심 $O$에서 현에 내린 수선의 발을 $H$라 하면, 이 수선은 현을 정확히 이등분합니다. 따라서 직각삼각형을 만들 수 있습니다.

원 위의 한 끝점을 $A$라 하면, 삼각형 $OHA$에서 피타고라스 정리를 적용합니다:
- $OH = d$ (중심에서 현까지의 거리)
- $OA = r$ (반지름)
- $HA = \sqrt{r^2 - d^2}$ (수선의 발에서 끝점까지)

현이 중심을 기준으로 대칭이므로, 현의 길이 = $2HA = 2\sqrt{r^2 - d^2}$입니다.

**기하적 의미**: 중심에서 멀어질수록 현은 짧아집니다. 중심을 지나는 현(지름)일 때 $d=0$이므로 길이는 최대값 $2r$입니다.

### 한 줄 예

반지름이 5이고 중심에서 현까지의 거리가 3인 원에서, 현의 길이는 $2\sqrt{5^2 - 3^2} = 2\sqrt{16} = 8$입니다.

```python
import sympy
sympy.simplify(2 * sympy.sqrt(5**2 - 3**2))  # 8
```
