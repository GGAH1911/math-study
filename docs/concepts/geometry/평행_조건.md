### 정확한 진술

두 직선이 **평행**하다는 것은 같은 평면 위에서 만나지 않는 두 직선을 말합니다. 

기울기 형태로 표현된 두 직선 $l_1: y = m_1 x + n_1$과 $l_2: y = m_2 x + n_2$가 평행하기 위한 필요충분조건은
$$m_1 = m_2 \text{ 이고 } n_1 \neq n_2$$
입니다.

일반형으로 표현된 두 직선 $l_1: a_1 x + b_1 y + c_1 = 0$과 $l_2: a_2 x + b_2 y + c_2 = 0$이 평행할 필요충분조건은
$$\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$$
입니다(단, $a_2, b_2 \neq 0$).

### 직관과 기하적 의미

직선의 기울기는 그 직선이 향하는 '방향'을 나타냅니다. 기울기가 같다는 것은 두 직선이 같은 각도로 올라가거나 내려간다는 뜻이므로, 두 직선이 평행합니다. 

그런데 기울기가 같더라도 $y$절편이 같으면 두 직선이 완전히 일치합니다(중복). 따라서 평행이 되려면 **기울기는 같되 $y$절편은 달라야** 합니다.

일반형에서 계수의 비가 같다는 조건은 두 직선의 방향벡터가 평행하다는 의미입니다. 상수항의 비가 다르다는 조건이 추가되어야 두 직선이 실제로 다른 위치에 있으면서 평행입니다.

### 한 줄 예

직선 $l_1: y = 2x + 1$과 $l_2: y = 2x - 3$은 평행합니다. (기울기가 모두 $2$이고 $y$절편이 다름)

또는 일반형: 직선 $3x + 4y - 5 = 0$과 $3x + 4y + 8 = 0$은 평행합니다. 
$$\frac{3}{3} = \frac{4}{4} = 1 \text{ 이지만 } \frac{-5}{8} \neq 1$$

검산: `sympy.solve([3*x + 4*y - 5, 3*x + 4*y + 8], [x, y])` → 해가 없음 (평행 확인)
