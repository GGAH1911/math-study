### 초점의 정의

**초점(focus)**는 이차곡선을 정의하는 기준점입니다. 이차곡선 위의 모든 점이 초점(들)과 일정한 관계를 만족합니다.

- **타원**: 두 초점 $F_1$, $F_2$까지의 거리의 합이 항상 $2a$로 일정
  $$|PF_1| + |PF_2| = 2a$$

- **쌍곡선**: 두 초점 $F_1$, $F_2$까지의 거리의 차가 항상 $2a$로 일정
  $$||PF_1| - |PF_2|| = 2a$$

- **포물선**: 초점 $F$와 준선까지의 거리가 항상 같음
  $$|PF| = d(P, \text{준선})$$

### 점근선의 정의

**점근선(asymptote)**은 곡선이 무한히 가까워지지만 만나지 않는 직선입니다. 이차곡선 중에서는 **쌍곡선만** 점근선을 가집니다.

쌍곡선 $\displaystyle\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$의 점근선은
$$y = \pm \frac{b}{a}x$$

곡선이 멀어질수록 이 직선들에 점점 가까워집니다.

### 기하적 의미

초점과 점근선은 이차곡선의 **형태와 위치를 완전히 결정**합니다. 초점의 위치로부터 곡선의 폭과 늘어난 정도를 알 수 있고, 점근선은 쌍곡선의 "열림" 방향과 기울기를 나타냅니다. 특히 이심률(eccentricity) $e = \frac{c}{a}$는 초점의 거리를 통해 곡선이 얼마나 "찌그러져" 있는지 측정합니다.

### 예시

표준형 쌍곡선 $\displaystyle\frac{x^2}{9} - \frac{y^2}{4} = 1$에서:
- $a = 3$, $b = 2$이므로 $c = \sqrt{9+4} = \sqrt{13}$
- 초점: $(\pm\sqrt{13}, 0)$
- 점근선: $y = \pm\frac{2}{3}x$
