### 정확한 진술

극값(極値)은 함수가 특정 점에서 그 근처의 모든 점보다 큰 값(극대값) 또는 작은 값(극소값)을 갖는 경우를 말합니다. 일변수 함수 $f(x)$에서 $x = a$를 포함하는 어떤 구간의 모든 $x$에 대해 $f(x) \leq f(a)$이면 $f(a)$를 **극대값**, $f(x) \geq f(a)$이면 **극소값**이라 합니다.

최적화(最適化)는 주어진 조건(제약 조건) 하에서 목적함수의 최댓값 또는 최솟값을 구하는 과정입니다. 극값 구하기는 최적화 문제를 해결하는 가장 기본적인 수학적 도구입니다.

### 직관/기하적 의미

함수의 그래프 위에서 극값은 **산의 봉우리**(극대값) 또는 **골짜기의 밑바닥**(극소값)에 해당합니다. 미분가능한 함수에서는 극값을 갖는 점 $x = a$에서 접선의 기울기가 0이 됩니다: $f'(a) = 0$.

선수 개념인 평면벡터와 연결하면, 여러 조건(벡터의 크기, 방향, 스칼라곱 등)이 얽힌 상황에서도 최적 상태를 찾을 수 있습니다. 예를 들어 점에서 직선까지의 최단거리, 또는 주어진 벡터 조건 하에서 크기 최소화 같은 문제들이 극값과 최적화의 실제 응용입니다.

### 한 줄 예

함수 $f(x) = x^2 - 4x + 3$에서 도함수 $f'(x) = 2x - 4$이므로 $f'(x) = 0$일 때 $x = 2$이고, 이 점에서 극소값 $f(2) = -1$을 갖습니다. 
```
sympy.solve(2*x - 4, x)  # [2]
```
