### 정확한 진술

거리의 최솟값은 두 도형 사이에서 나타나는 가장 짧은 거리를 의미합니다. 가장 기본적인 경우는 점과 직선 사이의 거리입니다. 점 $P(x_0, y_0)$에서 직선 $ax + by + c = 0$까지의 거리는 다음 공식으로 정의됩니다:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

이 공식은 점에서 직선에 내린 수선의 길이를 정확히 계산합니다.

### 직관/기하적 의미

평면 위의 한 점에서 직선까지 그을 수 있는 모든 선분 중에서, 직선과 수직으로 만나는 선분이 가장 짧습니다. 이것이 바로 거리(최솟값)입니다. 같은 원리로, 점과 원, 또는 두 원 사이의 최솟값도 중심을 잇는 직선 위에서 나타납니다. 거리의 최솟값을 구하는 것은 대수적 계산뿐만 아니라 기하학적으로도 의미 있는 개념으로, 현실의 최적화 문제(예: 공장에서 고객까지의 최단 배송 거리)를 모델링할 때도 활용됩니다.

### 한 줄 예

점 $(2, 1)$에서 직선 $2x - y + 3 = 0$까지의 거리는 $\displaystyle d = \frac{|2(2) - 1 + 3|}{\sqrt{4 + 1}} = \frac{6}{\sqrt{5}} = \frac{6\sqrt{5}}{5}$입니다.

(검산: `from sympy import sqrt, simplify; d = abs(2*2 - 1 + 3) / sqrt(2**2 + 1); print(simplify(d))` → $\frac{6\sqrt{5}}{5}$)
