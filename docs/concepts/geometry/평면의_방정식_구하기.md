# 평면의 방정식 구하기

> **예제** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
세 점 또는 점+법선

## 본문 (학습 시 채워짐)

### 문제

세 점 $A(1, 0, 0)$, $B(0, 1, 0)$, $C(0, 0, 1)$을 지나는 평면의 방정식을 구하시오.

### 단계별 풀이

**단계 1: 방향벡터 구하기**

점 $A$를 기준점으로 두 방향벡터를 구합니다.
$$\vec{AB} = B - A = (-1, 1, 0)$$
$$\vec{AC} = C - A = (-1, 0, 1)$$

**단계 2: 법선벡터 구하기**

외적을 이용해 평면의 법선벡터를 구합니다.
$$\vec{n} = \vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & 1 & 0 \\ -1 & 0 & 1 \end{vmatrix}$$

각 성분을 계산하면:
- $\vec{i}$ 성분: $(1)(1) - (0)(0) = 1$
- $\vec{j}$ 성분: $-[(-1)(1) - (0)(-1)] = -(-1) = 1$
- $\vec{k}$ 성분: $(-1)(0) - (1)(-1) = 1$

따라서 $\vec{n} = (1, 1, 1)$입니다.

검증: `sympy.Matrix([-1,1,0]).cross(sympy.Matrix([-1,0,1]))`

**단계 3: 평면의 방정식 세우기**

점 $A(1, 0, 0)$을 지나고 법선벡터가 $(1, 1, 1)$인 평면의 방정식:
$$1(x - 1) + 1(y - 0) + 1(z - 0) = 0$$
$$x + y + z = 1$$

### 답

$$x + y + z = 1$$

### 변형/주의

**대안: 점과 법선벡터가 직접 주어진 경우**

일반적으로 점 $P(x_0, y_0, z_0)$과 법선벡터 $\vec{n} = (a, b, c)$가 주어지면, 다음 공식을 직접 적용합니다:
$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$$

세 점 문제에서는 두 방향벡터의 외적으로 법선벡터를 먼저 구해야 한다는 점이 중요합니다.

**검증 중요성**

구한 답이 올바른지 항상 확인해야 합니다. 세 점을 방정식에 대입:
- $A(1, 0, 0)$: $1 + 0 + 0 = 1$ ✓
- $B(0, 1, 0)$: $0 + 1 + 0 = 1$ ✓
- $C(0, 0, 1)$: $0 + 0 + 1 = 1$ ✓
