### 정확한 진술

벡터 분해는 주어진 벡터 $\vec{a}$를 특정 기저(basis) 벡터들의 선형결합으로 나타내는 과정입니다. 평면벡터의 경우, 영이 아닌 두 벡터 $\vec{b}$, $\vec{c}$가 평행하지 않을 때, 임의의 벡터 $\vec{a}$에 대해 

$$\vec{a} = m\vec{b} + n\vec{c}$$

를 만족하는 유일한 실수 $m$, $n$이 존재합니다. 이러한 표현을 $\vec{b}$, $\vec{c}$를 기저로 하는 $\vec{a}$의 분해라 하며, $m$, $n$을 분해계수라 합니다.

### 직관 및 기하적 의미

벡터 분해는 좌표 설정과 같은 개념입니다. 평면 위의 임의의 점(또는 벡터)을 두 개의 기준 방향으로 이동한 거리의 조합으로 표현하는 것이죠. 마치 격자 좌표에서 $x$ 축 방향과 $y$ 축 방향으로 얼마나 움직이는지로 위치를 나타내듯이, $\vec{b}$와 $\vec{c}$ 방향으로 각각 몇 배씩 더해야 하는지를 알아내는 과정입니다. 기저가 서로 평행하지 않으면 평면 전체를 빈틈없이 커버할 수 있어서 모든 벡터를 유일하게 분해할 수 있습니다.

### 한 줄 예

$\vec{a} = (3, 1)$, $\vec{b} = (1, 0)$, $\vec{c} = (0, 1)$일 때, $\vec{a} = 3\vec{b} + 1\vec{c}$로 분해됩니다. 더 일반적으로 $\vec{b} = (1, 1)$, $\vec{c} = (1, -1)$이면, $\vec{a} = 2\vec{b} + 1\vec{c}$입니다 (`sympy.solve([m + n - 3, m - n - 1], [m, n])` → $m=2, n=1$).
