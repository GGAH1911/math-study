### 정확한 진술

두 평면벡터 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$에 대해, **성분의 합**은 다음과 같이 정의됩니다.

$$\vec{a} + \vec{b} = (a_1 + b_1, a_2 + b_2)$$

즉, 같은 위치의 성분끼리 더한 벡터입니다. 이것이 벡터 덧셈의 표준 정의입니다.

### 직관과 기하적 의미

성분의 합은 벡터 덧셈의 **평행사변형 규칙(parallelogram rule)**과 일치합니다. $\vec{a}$와 $\vec{b}$를 원점에서 출발하는 두 변으로 하는 평행사변형을 그리면, 그 대각선이 바로 $\vec{a} + \vec{b}$입니다.

성분 표현으로는 각 축 방향 이동을 독립적으로 더하는 셈입니다. 예를 들어 $\vec{a}$가 오른쪽으로 3칸, 위로 2칸 이동이고, $\vec{b}$가 오른쪽으로 1칸, 위로 4칸 이동이면, 둘을 합친 이동은 오른쪽 4칸, 위 6칸이 됩니다.

**주요 성질:**
- 교환법칙: $\vec{a} + \vec{b} = \vec{b} + \vec{a}$
- 결합법칙: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
- 영벡터: $\vec{a} + \vec{0} = \vec{a}$

### 예

$\vec{a} = (3, 2)$, $\vec{b} = (1, 4)$일 때:
$$\vec{a} + \vec{b} = (3+1, 2+4) = (4, 6)$$

더 복잡한 경우를 확인하려면:
```
sympy: from sympy import Matrix; a = Matrix([3, 2]); b = Matrix([1, 4]); print(a + b)
```

세 벡터의 경우 $\vec{a} + \vec{b} + \vec{c} = (a_1 + b_1 + c_1, a_2 + b_2 + c_2)$로 확장됩니다. 성분 덧셈은 벡터의 개수와 관계없이 같은 원리가 적용되므로, 복잡한 벡터 연쇄 계산도 단순한 성분 합으로 처리할 수 있습니다.
