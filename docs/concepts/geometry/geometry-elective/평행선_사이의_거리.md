### 정확한 진술

공간에서 두 직선이 평행할 때, 이들 사이의 거리는 한 직선 위의 임의의 점에서 다른 직선까지의 거리입니다. 직선 $\ell_1$이 점 $A$를 지나고 방향벡터 $\vec{d}$를 가지며, 직선 $\ell_2$가 점 $B$를 지나고 같은 방향벡터 $\vec{d}$를 가질 때, 두 직선 사이의 거리 $d$는 다음과 같습니다:

$$d = \frac{|\vec{AB} \times \vec{d}|}{|\vec{d}|}$$

### 직관/기하적 의미

평행한 두 직선은 방향이 동일하므로, 한 직선 위의 어느 점을 택하든 다른 직선까지의 거리는 항상 같습니다. 벡터의 외적 $\vec{AB} \times \vec{d}$의 크기는 두 벡터가 만드는 평행사변형의 넓이를 나타내고, 이를 밑변 $|\vec{d}|$로 나누면 높이, 즉 두 직선 사이의 거리를 얻습니다. 이는 점과 직선 사이의 거리 개념을 평행선으로 확장한 것입니다.

### 한 줄 예

직선 $\ell_1: (x, y, z) = (1, 0, 0) + s(1, 1, 0)$과 $\ell_2: (x, y, z) = (0, 1, 0) + t(1, 1, 0)$은 모두 방향벡터 $(1, 1, 0)$을 가지므로 평행하며, 이들 사이의 거리는 $\displaystyle \frac{|(1, -1, 0) \times (1, 1, 0)|}{|(1, 1, 0)|} = \frac{2}{\sqrt{2}} = \sqrt{2}$입니다. (검산: `from sympy import Matrix; AB = Matrix([1,-1,0]); d = Matrix([1,1,0]); AB.cross(d).norm() / d.norm()` → $\sqrt{2}$)
