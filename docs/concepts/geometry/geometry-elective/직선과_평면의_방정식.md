# 직선과 평면의 방정식

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
매개변수형 / 일반형

## 본문 (학습 시 채워짐)

### 직선의 정확한 진술

3차원 공간에서 직선은 한 점과 방향벡터로 결정됩니다. 점 $P_0(x_0, y_0, z_0)$을 지나고 방향벡터가 $\vec{d} = (a, b, c)$인 직선은 다음과 같이 나타낼 수 있습니다.

**매개변수형**: $\begin{cases} x = x_0 + at \\ y = y_0 + bt \\ z = z_0 + ct \end{cases}$ (단, $t$는 실수 매개변수)

**일반형(대칭형)**: $\frac{x - x_0}{a} = \frac{y - y_0}{b} = \frac{z - z_0}{c}$ (단, $a, b, c \neq 0$)

### 평면의 정확한 진술

3차원 공간에서 평면은 한 점과 법선벡터(평면에 수직인 벡터)로 결정됩니다. 점 $P_0(x_0, y_0, z_0)$을 지나고 법선벡터가 $\vec{n} = (A, B, C)$인 평면의 방정식은:

**일반형**: $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$

정리하면: $Ax + By + Cz + D = 0$

**매개변수형**: 평면 위의 두 독립 방향벡터 $\vec{u}, \vec{v}$를 이용하여 $\vec{r} = \vec{r_0} + s\vec{u} + t\vec{v}$ (단, $s, t$는 실수 매개변수)

### 직관과 기하적 의미

직선의 매개변수형은 시간 $t$에 따라 직선 위를 움직이는 점의 궤적을 나타냅니다. $t=0$일 때 $P_0$에서 출발하여, $t$가 증가/감소하면서 방향벡터 방향으로 이동합니다.

평면의 일반형 $Ax + By + Cz + D = 0$에서 $(A, B, C)$는 평면에 수직인 법선벡터입니다. 평면 위의 모든 점 $(x, y, z)$은 이 조건을 만족합니다.

### 한 줄 예

점 $(1, 2, 3)$을 지나고 방향벡터 $(2, -1, 1)$인 직선: $\frac{x-1}{2} = \frac{y-2}{-1} = \frac{z-3}{1}$

점 $(1, 0, 2)$를 지나고 법선벡터 $(1, 2, -1)$인 평면: $1(x-1) + 2(y-0) - 1(z-2) = 0$ 즉, $x + 2y - z + 1 = 0$
