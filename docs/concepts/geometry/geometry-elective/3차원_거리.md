## 본문

### 정확한 진술

3차원 공간에서 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 다음 공식으로 정의됩니다.

$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

또는 **벡터로 표현**하면, $\overrightarrow{AB} = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$일 때,

$$|AB| = \sqrt{\overrightarrow{AB} \cdot \overrightarrow{AB}} = |\overrightarrow{AB}|$$

### 직관/기하적 의미

2차원에서 피타고라스 정리로 거리를 구하듯이, 3차원에서도 **직각삼각형을 단계적으로 그려서** 같은 원리를 적용합니다.

먼저 점 $A$에서 점 $B$로 가는 경로를 $xy$-평면 방향($x$축, $y$축 거리)과 $z$축 방향(높이)으로 분해합니다. $xy$-평면 위의 거리는 $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$이고, 이것과 높이 차이 $(z_2 - z_1)$을 빗변으로 하는 직각삼각형을 만들면 최종 거리를 얻게 됩니다. 이는 **2차원 거리 공식을 한 번 더 적용**한 것입니다.

### 한 줄 예

점 $P(1, 2, 3)$과 $Q(4, 6, 15)$ 사이의 거리:
$$|PQ| = \sqrt{(4-1)^2 + (6-2)^2 + (15-3)^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13$$

원점 $O(0, 0, 0)$으로부터 점 $(2, 3, 6)$까지의 거리는 $\sqrt{4 + 9 + 36} = \sqrt{49} = 7$입니다.
