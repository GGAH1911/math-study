# 거리 관계

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선은 평면 위의 점들이 초점이나 준선과 이루는 특정한 거리 관계에 의해 결정되는 도형입니다.

## 본문
이차곡선은 평면 위의 점들이 만족하는 거리 관계로 정의됩니다. 이차곡선 위의 임의의 점이 특정 기하학적 위치들인 초점이나 준선까지의 거리 사이에 성립하는 조건을 거리 관계라 하며, 이를 통해 타원, 쌍곡선, 포물선이 결정됩니다.

**타원**은 평면 위의 두 정점인 초점 $F_1, F_2$까지의 거리의 합이 일정한 점들의 집합입니다.
$$|PF_1| + |PF_2| = 2a \quad (a > 0)$$

**쌍곡선**은 평면 위의 두 정점인 초점 $F_1, F_2$까지의 거리의 차의 절댓값이 일정한 점들의 집합입니다.
$$\big||PF_1| - |PF_2|\big| = 2a \quad (a > 0)$$

**포물선**은 평면 위의 한 정점인 초점 $F$와 한 직선인 준선 $\ell$까지의 거리가 같은 점들의 집합입니다.
$$|PF| = d(P, \ell)$$

### 직관과 기하적 의미
거리 관계는 이차곡선이 형성되는 원리를 설명합니다. 타원은 두 초점으로부터 거리의 균형을 이루는 점들의 궤적이며, 쌍곡선은 두 초점으로부터의 거리 차이가 일정한 점들의 궤적입니다. 포물선은 초점과 준선 사이의 완벽한 대칭을 이루는 점들의 궤적입니다. 이러한 거리 관계는 단순한 정의를 넘어 꼭짓점, 중심, 점근선과 같은 이차곡선의 모든 기하학적 성질을 유도하는 근본적인 출발점이 됩니다.

### 기본 성질
- 타원의 경우 거리의 합인 $2a$가 두 초점 사이의 거리보다 커야 타원이 형성됩니다.
- 쌍곡선의 경우 거리의 차인 $2a$가 두 초점 사이의 거리보다 작아야 쌍곡선이 형성됩니다.
- 포물선은 초점과 준선 사이의 거리가 일정하게 유지되는 대칭 구조를 가집니다.

## 학습 체크
- 타원과 쌍곡선에서 거리의 합 또는 차가 초점 사이의 거리와 어떤 관계를 가져야 도형이 정의되는가?
- 포물선의 정의에서 초점과 준선 사이의 거리가 점의 위치에 따라 어떻게 변하는가?
- 주어진 초점과 거리 조건을 이용하여 이차곡선의 방정식을 유도할 수 있는가?

## 관련 개념
- **이차곡선**: 거리 관계를 통해 정의되는 타원, 쌍곡선, 포물선을 통칭하는 개념입니다.
