# 거리 관계

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 정확한 진술

이차곡선은 평면 위의 점들이 만족하는 **거리 관계**로 정의됩니다. 이차곡선 위의 임의의 점이 특정 기하학적 위치들(초점, 준선 등)까지의 거리 사이에 성립하는 조건을 거리 관계라 하며, 이를 통해 타원, 쌍곡선, 포물선이 결정됩니다.

**타원**: 평면 위의 두 정점(초점) $F_1$, $F_2$까지의 거리의 합이 일정한 점들의 집합
$$|PF_1| + |PF_2| = 2a \quad (a > 0)$$

**쌍곡선**: 평면 위의 두 정점(초점) $F_1$, $F_2$까지의 거리의 차의 절댓값이 일정한 점들의 집합
$$\big||PF_1| - |PF_2|\big| = 2a \quad (a > 0)$$

**포물선**: 평면 위의 한 정점(초점) $F$와 한 직선(준선) $\ell$까지의 거리가 같은 점들의 집합
$$|PF| = d(P, \ell)$$

## 직관/기하적 의미

거리 관계는 이차곡선이 어떻게 "생겨났는지"를 설명합니다. 타원은 두 초점으로부터 **균형**을 이루는 점들이고, 쌍곡선은 두 초점으로부터의 거리 **차이**가 일정한 점들입니다. 포물선은 초점과 준선 사이의 **완벽한 대칭**을 이루는 점들입니다. 이 거리 관계는 단순한 정의가 아니라, 이차곡선의 모든 성질(꼭짓점, 중심, 점근선 등)을 유도하는 출발점입니다.

## 한 줄 예

초점이 $F_1(-3, 0)$, $F_2(3, 0)$이고 거리의 합이 10인 타원은 $\frac{x^2}{25} + \frac{y^2}{16} = 1$입니다. (확인: $2a = 10$이므로 $a = 5$, $2c = 6$이므로 $c = 3$, $b^2 = a^2 - c^2 = 25 - 9 = 16$)
