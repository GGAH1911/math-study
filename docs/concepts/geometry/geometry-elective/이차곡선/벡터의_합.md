# 벡터의 합

## 정확한 진술

두 벡터 $\vec{a}$와 $\vec{b}$의 합은 $\vec{a} + \vec{b}$로 표기하며, 다음과 같이 정의합니다. 벡터 $\vec{a}$를 나타내는 화살표의 시작점에서 끝점까지 이동한 후, 그 끝점을 새로운 시작점으로 하여 벡터 $\vec{b}$를 나타내는 화살표를 그렸을 때, 처음 시작점에서 마지막 끝점까지의 벡터가 $\vec{a} + \vec{b}$입니다. 이를 **삼각형 법칙**(triangle law)이라 부릅니다.

좌표로 표현하면, $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$일 때:
$$\vec{a} + \vec{b} = (a_1 + b_1, a_2 + b_2)$$

## 직관과 기하적 의미

벡터의 합은 두 이동을 연달아 실행하는 것과 같습니다. 예를 들어 $\vec{a}$가 "동쪽으로 3칸"이고 $\vec{b}$가 "북쪽으로 4칸"이라면, $\vec{a} + \vec{b}$는 "먼저 동쪽으로 3칸, 그 다음 북쪽으로 4칸 이동한 결과"를 의미합니다.

또한 두 벡터의 합은 **평행사변형 법칙**으로도 나타낼 수 있습니다. 두 벡터 $\vec{a}$, $\vec{b}$를 같은 시작점에 놓고, 각각을 두 변으로 하는 평행사변형을 그리면, 그 대각선 벡터가 $\vec{a} + \vec{b}$입니다.

벡터의 합은 **교환법칙**($\vec{a} + \vec{b} = \vec{b} + \vec{a}$)과 **결합법칙**($(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$)을 만족합니다.

## 한 줄 예

$\vec{a} = (2, 3)$, $\vec{b} = (1, -2)$이면 $\vec{a} + \vec{b} = (3, 1)$입니다.
