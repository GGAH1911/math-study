# 거리비 조건

## 정확한 진술

거리비 조건은 평면 위의 점이 고정된 점(초점)과 고정된 직선(준선)으로부터의 거리 비가 항상 일정한 값을 만족하는 조건입니다.

고정된 점 $F$(초점)와 $F$를 지나지 않는 직선 $l$(준선)이 주어질 때, 점 $P$에서 $F$까지의 거리 $r$과 직선 $l$까지의 거리 $d$의 비가 항상 일정한 양수 $e$를 만족하는 점들의 집합:
$$\frac{r}{d} = e$$

여기서 $e$를 **이심률(eccentricity)**이라 하며, 이심률의 크기에 따라 곡선의 종류가 결정됩니다.

## 직관과 기하적 의미

거리비 조건은 초점과 준선의 상대적 위치 관계로 모든 이차곡선을 통일적으로 정의합니다. 

이심률의 크기에 따라:
- $0 < e < 1$: 타원 (초점에 더 가까운 쪽으로 편중)
- $e = 1$: 포물선 (초점과 준선이 균형을 이룸)
- $e > 1$: 쌍곡선 (초점에서 멀어짐)

이심률이 작을수록 곡선은 더 둥글고 초점 주변에 집중되며, 클수록 더 퍼지고 늘어난 형태를 띱니다. 특히 원은 타원의 특수한 경우로, 이심률 $e = 0$에 해당합니다.

## 한 줄 예

초점 $F(1, 0)$과 준선 $x = 4$를 가지며 이심률 $e = \frac{1}{2}$인 점들의 자취를 구하면, 조건 $(x-1)^2 + y^2 = \frac{1}{4}(x-4)^2$를 정리하여 타원을 얻습니다.
