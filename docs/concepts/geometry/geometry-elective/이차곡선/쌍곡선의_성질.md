# 쌍곡선의 성질

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
두 초점으로부터의 거리의 차가 일정한 점들의 자취로, 두 개의 분리된 가지를 가지며 점근선에 접근하는 곡선입니다.

## 본문
쌍곡선은 평면 위의 두 고정점인 초점으로부터의 거리 차의 절댓값이 항상 일정한 점들의 자취입니다. 두 초점을 $F(c, 0)$, $F'(-c, 0)$이라 하고, 거리 차의 절댓값을 $2a$ ($0 < a < c$)라고 할 때, 쌍곡선 위의 모든 점 $P$는 $\left| |PF| - |PF'| \right| = 2a$를 만족합니다. 이를 바탕으로 유도된 표준형 방정식은 $b^2 = c^2 - a^2$일 때 $\tfrac{x^2}{a^2} - \tfrac{y^2}{b^2} = 1$입니다.

### 직관과 기하적 의미
원은 중심으로부터의 거리가 일정하고, 타원은 두 초점으로부터의 거리 합이 일정한 곡선입니다. 반면 쌍곡선은 거리의 차가 일정하다는 조건 때문에 좌우로 분리된 두 개의 가지를 형성합니다. 곡선은 초점에 가까울수록 급격히 꺾이며, 멀어질수록 점근선 $y = \pm \tfrac{b}{a}x$에 한없이 가까워집니다. 이심률 $e = \tfrac{c}{a}$가 $1$보다 크기 때문에 타원보다 더 열린 형태를 띠며 무한히 뻗어나가는 특성을 보입니다.

### 기본 성질
- 표준형 방정식 $\tfrac{x^2}{a^2} - \tfrac{y^2}{b^2} = 1$에서 $a$는 주축의 길이를, $b$는 점근선의 기울기를 결정하는 요소입니다.
- 초점의 좌표는 $F(\pm c, 0)$이며, 이때 $c = \sqrt{a^2 + b^2}$의 관계가 성립합니다.
- 점근선은 쌍곡선이 무한히 커질 때 곡선이 수렴하게 되는 직선 $y = \pm \tfrac{b}{a}x$를 의미합니다.

## 학습 체크
- 두 초점으로부터의 거리의 차가 일정하다는 정의가 어떻게 두 개의 분리된 곡선 가지를 만드는가?
- 이심률 $e$의 값이 $1$보다 클 때 곡선의 형태가 왜 타원과 달리 열린 구조를 갖는가?
- 주어진 쌍곡선 방정식에서 초점의 위치와 점근선의 방정식을 정확히 도출할 수 있는가?

## 관련 개념
- **이차곡선**: 쌍곡선은 원, 타원과 함께 이차방정식으로 나타나는 대표적인 이차곡선 중 하나입니다.
