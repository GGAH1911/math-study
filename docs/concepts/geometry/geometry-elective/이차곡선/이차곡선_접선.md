# 이차곡선 접선

> **정리** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선 위의 점 $(x_0, y_0)$에서의 접선 방정식은 곡선 방정식의 $x^2$을 $xx_0$로, $y^2$을 $yy_0$로 치환하여 구할 수 있습니다.

## 본문
이차곡선 위의 점 $(x_0, y_0)$에서의 접선은 곡선의 방정식에서 $x^2$을 $xx_0$로, $y^2$을 $yy_0$로 치환하여 간단히 구할 수 있습니다. 구체적인 공식은 다음과 같습니다. 원 $x^2 + y^2 = r^2$ 위의 점 $(x_0, y_0)$에서의 접선은 $xx_0 + yy_0 = r^2$이며, 포물선 $y^2 = 4px$ 위의 점 $(x_0, y_0)$에서의 접선은 $yy_0 = 2p(x + x_0)$입니다. 타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 위의 점 $(x_0, y_0)$에서의 접선은 $\frac{xx_0}{a^2} + \frac{yy_0}{b^2} = 1$이고, 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 위의 점 $(x_0, y_0)$에서의 접선은 $\frac{xx_0}{a^2} - \frac{yy_0}{b^2} = 1$입니다. 이러한 치환 방식은 곡선의 대칭성을 활용한 매우 효율적인 방법입니다.

### 증명 스케치
곡선 위의 점 $(x_0, y_0)$에서 접선의 기울기는 매개변수 미분을 통해 $\frac{dy/dt}{dx/dt}$로 구할 수 있습니다. 원의 경우, 원점과 접점을 잇는 위치벡터 $(x_0, y_0)$와 접선의 방향벡터 $(y_0, -x_0)$가 서로 수직임을 이용합니다. 두 벡터의 내적이 $x_0 \cdot y_0 + y_0 \cdot (-x_0) = 0$이 되어 수직임이 증명되므로, 이를 통해 접선의 방정식을 유도할 수 있습니다.

### 의의와 응용
이 공식은 곡선이 표준형일 때 직접 적용할 수 있으며, 평행이동된 곡선의 경우 표준형으로 변환하여 적용해야 합니다. 원 밖의 한 점에서 그은 접선의 접점을 찾을 때는 접선 공식과 점의 좌표를 결합하여 해결할 수 있습니다. 예를 들어 원 $x^2 + y^2 = 25$ 위의 점 $(3, 4)$에서의 접선은 $3x + 4y = 25$가 됩니다.
