# 공통접원

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
두 원 이상의 모든 도형에 동시에 접하는 원을 의미합니다.

## 본문
두 원 이상의 모든 도형에 동시에 접하는 원을 **공통접원**(공통외접원)이라고 합니다. 가장 일반적인 경우는 두 원이 주어졌을 때, 이 두 원에 모두 접하는 원을 찾는 것입니다. 원 $C_1: (x-a_1)^2 + (y-b_1)^2 = r_1^2$과 원 $C_2: (x-a_2)^2 + (y-b_2)^2 = r_2^2$이 있을 때, 중심이 $(h, k)$이고 반지름이 $\rho$인 공통접원은 두 원에 외접하거나 내접하는 조건을 만족해야 합니다.

### 직관과 기하적 의미
공통접원은 크게 두 가지 경우로 구분됩니다. 첫째는 **외적 공통접원**으로, 두 원의 외부에서 두 원 모두에 외접하는 원을 말합니다. 두 원의 중심 사이의 거리를 $d = \sqrt{(a_2-a_1)^2 + (b_2-b_1)^2}$라고 할 때, 공통접원의 반지름 $\rho$는 두 원의 중심과 접원의 중심 사이의 거리 관계를 통해 결정됩니다. 둘째는 **내적 공통접원**으로, 한 원이 다른 원을 포함하면서 내접하는 경우를 의미합니다. 기하학적으로 공통접원을 찾는 과정은 **상사**(homothety) 개념과 밀접하게 연결됩니다. 공통접원의 중심은 두 원의 상사중심을 지나는 직선 위에 위치하게 됩니다.

### 기본 성질
원 $(x-0)^2 + (y-0)^2 = 1$과 원 $(x-5)^2 + (y-0)^2 = 4$에 모두 외접하는 공통접원의 경우, 접원의 중심 $(h, k)$는 $x$축 위의 특정 점이며, 반지름 $\rho$에 대하여 $\sqrt{h^2 + k^2} - 1 = \sqrt{(h-5)^2 + k^2} - 2$라는 조건을 만족해야 합니다.

## 학습 체크
- 두 원에 외접하는 공통접원을 구할 때, 중심 사이의 거리와 반지름 사이의 관계식을 어떻게 세울 것인가?
- 공통접원의 중심이 두 원의 상사중심과 어떤 기하학적 관계를 갖는지 설명할 수 있는가?

## 관련 개념
- **도형의 방정식**: 원의 방정식을 이용하여 두 원과 접하는 새로운 원의 방정식을 유도하는 기초가 됩니다.
