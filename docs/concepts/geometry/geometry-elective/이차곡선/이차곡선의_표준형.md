# 이차곡선의 표준형

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선의 표준형은 곡선의 핵심 요소인 중심, 초점, 꼭짓점 등을 한눈에 파악할 수 있도록 가장 단순한 형태로 나타낸 방정식입니다.

## 본문
이차곡선의 표준형이란 원, 타원, 쌍곡선, 포물선을 가장 간단한 형태로 나타낸 방정식을 의미합니다. 일반적으로 이차곡선은 중심이 원점에 있거나 축이 좌표축과 평행하도록 평행이동한 상태의 방정식을 표준형으로 나타내며, 이를 통해 곡선의 기하학적 성질을 즉각적으로 파악할 수 있습니다.

### 직관과 기하적 의미
일반적인 이차곡선 방정식 $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$은 계수가 복잡하여 곡선의 모양을 직관적으로 파악하기 어렵습니다. 반면 표준형으로 변환하면 몇 개의 핵심 매개변수만으로 곡선의 전체적인 형태를 완벽하게 결정할 수 있어, 이차곡선의 본질적인 특징을 드러내는 가장 효율적인 표현 방식이 됩니다.

### 기본 성질
각 곡선의 표준형에 따른 주요 성질은 다음과 같습니다.
- **원**: $x^2 + y^2 = r^2$ (반지름 $r$)
- **타원**: $\tfrac{x^2}{a^2} + \tfrac{y^2}{b^2} = 1$ (장축 길이 $2a$, 단축 길이 $2b$)
- **쌍곡선**: $\tfrac{x^2}{a^2} - \tfrac{y^2}{b^2} = 1$ (횡축 길이 $2a$)
- **포물선**: $y^2 = 4px$ (꼭짓점이 원점, 초점 $(p, 0)$)

예를 들어, $2x^2 + 3y^2 - 4x - 12y + 8 = 0$과 같은 일반형 방정식을 표준형인 $\tfrac{(x-1)^2}{3} + \tfrac{(y-2)^2}{2} = 1$로 변환하면, 중심이 $(1, 2)$인 타원임을 즉시 알 수 있습니다.

## 학습 체크
- 일반형 방정식을 표준형으로 변환할 때 완전제곱식의 형태를 정확히 유도할 수 있는가?
- 표준형의 계수들을 보고 중심, 초점, 꼭짓점, 축의 길이를 바로 찾아낼 수 있는가?
- 각 곡선(원, 타원, 쌍곡선, 포물선)의 표준형 식을 구분하여 쓸 수 있는가?

## 관련 개념
- **이차곡선**: 표준형은 이차곡선의 종류를 결정하고 그 기하학적 특징을 설명하는 가장 기초적인 도구입니다.
