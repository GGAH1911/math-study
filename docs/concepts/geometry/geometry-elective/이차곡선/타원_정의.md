# 타원 정의

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
두 초점으로부터의 거리의 합이 일정한 점들의 자취

## 본문
평면 위의 서로 다른 두 점 $F$, $F'$를 정하자. 이 두 점을 **초점**이라 부른다. 이 두 초점으로부터의 거리의 합이 일정한 점 $P$들의 자취를 **타원**이라 한다. 즉, 양의 상수 $2a$에 대하여 $|PF| + |PF'| = 2a$를 만족하는 모든 점 $P$의 집합이 타원이다. 단, $2a$는 두 초점 사이의 거리보다 커야 한다.

### 직관과 기하적 의미
타원을 가장 직관적으로 이해하는 방법은 실을 이용한 실험이다. 두 초점에 실의 끝을 고정하고, 길이가 $2a$인 실을 항상 팽팽하게 유지하면서 펜으로 그리면 타원이 그려진다. 실의 길이가 짧을수록 타원은 더 찌그러진 모양이 되고, 실의 길이가 길어질수록 원에 가까워진다. 이때 두 초점이 하나로 일치하는 특수한 경우가 바로 원이다.

### 기본 성질
두 초점 사이의 거리를 $2c$라 할 때, 타원의 **장축 길이**는 $2a$, **단축 길이**는 $2b$이며, 다음과 같은 관계식이 성립한다:
$$a^2 = b^2 + c^2$$
예를 들어, 초점이 $F(3, 0)$, $F'(-3, 0)$이고 거리의 합 $2a = 10$인 타원이 있다면, $a = 5$이고 $c = 3$이다. 이때 $b = \sqrt{25 - 9} = 4$가 되어 타원의 방정식은 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$이 된다.

## 학습 체크

- 장축, 단축, 초점 사이의 관계식 $a^2 = b^2 + c^2$을 활용하여 방정식을 구할 수 있는가?

## 관련 개념
- **이차곡선**: 타원은 이차곡선의 한 종류로, 초점의 위치와 거리의 합 조건에 의해 결정되는 곡선이다.
