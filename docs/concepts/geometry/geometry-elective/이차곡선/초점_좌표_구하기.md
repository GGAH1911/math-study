# 초점 좌표 구하기

> **예제** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선의 일반형 방정식을 완전제곱식을 이용하여 표준형으로 변환한 후, 꼭짓점과 초점의 위치 관계를 통해 초점의 좌표를 구합니다.

## 본문
$y^2 + 8x - 4y + 12 = 0$으로 주어진 포물선의 초점의 좌표를 구하시오.

### 단계별 풀이
주어진 방정식을 포물선의 표준형 $(y - k)^2 = 4p(x - h)$로 변환합니다.

**1단계: $y$ 항 정리**
$$y^2 - 4y + 8x + 12 = 0$$

**2단계: $y$에 대해 완전제곱식 만들기**
$y^2 - 4y$를 완전제곱식으로 만들기 위해 4를 더하고 빼면 다음과 같습니다.
$$(y^2 - 4y + 4) - 4 + 8x + 12 = 0$$
$$(y - 2)^2 + 8x + 8 = 0$$
$$(y - 2)^2 = -8x - 8$$

**3단계: 표준형으로 정리**
$$(y - 2)^2 = -8(x + 1)$$
이를 $(y - 2)^2 = 4p(x + 1)$과 비교하면 $4p = -8$, 즉 $p = -2$입니다.

**4단계: 초점 구하기**
포물선의 꼭짓점은 $(-1, 2)$입니다. 포물선의 초점은 꼭짓점에서 축의 방향으로 $p$만큼 떨어진 점이므로 다음과 같습니다.
$$\text{초점} = (-1 + p, 2) = (-1 - 2, 2) = (-3, 2)$$

### 답과 변형
$\boxed{(-3, 2)}$

**주의사항**
$p = -2 < 0$이므로 포물선은 $x$축의 음의 방향으로 열리며, 초점은 꼭짓점의 왼쪽에 위치합니다. 완전제곱식을 만들 때 상수항을 이동하여 더하고 빼는 과정에서 실수가 없어야 합니다. 타원이나 쌍곡선의 경우에도 일반형을 표준형으로 변환하는 과정은 동일하며, 각 곡선의 초점 거리 공식($c^2 = a^2 - b^2$ 또는 $c^2 = a^2 + b^2$)을 적용하여 해결합니다.

## 학습 체크
- 일반형 방정식을 완전제곱식을 이용하여 표준형으로 변환할 수 있는가?
- $p$의 부호에 따른 포물선의 방향과 초점의 위치를 정확히 파악했는가?

## 관련 개념
- **이차곡선**: 포물선, 타원, 쌍곡선은 모두 이차방정식의 형태로 나타나며, 표준형으로 변환하여 기하학적 특징을 파악하는 원리가 동일합니다.
