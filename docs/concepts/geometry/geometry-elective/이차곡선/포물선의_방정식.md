### 정확한 진술

포물선(parabola)은 다음과 같이 정의됩니다: **한 점(초점)과 그 점을 지나지 않는 한 직선(준선)으로부터 같은 거리에 있는 점들의 자취**입니다.

초점을 $F$, 준선을 $l$이라 하고, 평면 위의 임의의 점 $P$에 대해 다음이 성립합니다:
$$|PF| = d(P, l)$$

꼭짓점을 원점으로 하고 축이 좌표축과 평행한 표준 위치에서 포물선의 방정식은 다음과 같습니다:
- **축이 $x$축 위**: $y^2 = 4px$ (초점: $(p, 0)$, 준선: $x = -p$)
- **축이 $y$축 위**: $x^2 = 4py$ (초점: $(0, p)$, 준선: $y = -p$)

여기서 $p > 0$일 때 포물선은 각 축의 양의 방향으로 열리고, $p < 0$일 때는 음의 방향으로 열립니다.

### 직관/기하적 의미

포물선은 일상에서 매우 흔합니다. 물건을 던질 때의 궤적, 위성 안테나의 모양, 자동차 헤드라이트의 반사면 등이 모두 포물선입니다. 

초점과 준선의 거리가 같다는 조건은 **균형**을 의미합니다. 이 성질 덕분에 포물선은 독특한 **반사 성질**을 가집니다: 초점으로 들어오는 모든 광선은 포물선에 반사된 후 준선에 수직인 방향으로 나갑니다. 이것이 집중형 안테나와 손전등의 원리입니다.

### 한 줄 예

$y^2 = 4x$는 초점이 $(1, 0)$이고 준선이 $x = -1$인 포물선입니다. 포물선 위의 점 $(1, 2)$에 대해 초점까지의 거리는 $\sqrt{(1-1)^2 + (2-0)^2} = 2$이고, 준선까지의 거리도 $1 - (-1) = 2$로 정의를 만족합니다.

```python
# sympy로 검산: 점 (1, 2)가 y^2 = 4x 위에 있는지 확인
import sympy as sp
x, y = sp.symbols('x y')
print(sp.simplify(y**2 - 4*x).subs([(x, 1), (y, 2)]))  # 0
```
