# 초점과 거리의 차

## 정확한 진술

평면 위의 두 고정점 $F_1$, $F_2$ (초점)과 양수 $a$에 대하여, 다음을 만족하는 점 $P$의 자취를 **쌍곡선**이라 합니다.

$$||PF_1| - |PF_2|| = 2a$$

단, $2a < |F_1F_2|$를 만족해야 합니다. 즉, **한 점에서 두 초점까지의 거리 차의 절댓값이 일정한** 모든 점들의 집합입니다.

## 직관과 기하적 의미

쌍곡선은 타원과 대비되는 이차곡선입니다. 타원이 "두 초점까지의 거리의 합"이 일정하다면, 쌍곡선은 "거리의 차"가 일정합니다.

두 초점 사이의 거리를 $2c$ (단, $c > a$)라 할 때, 쌍곡선은 **두 개의 분리된 가지**로 나뉩니다:
- 초점 $F_1$에 더 가까운 가지: $|PF_1| - |PF_2| = -2a$
- 초점 $F_2$에 더 가까운 가지: $|PF_2| - |PF_1| = 2a$

이렇게 정의하는 이유는, 초점으로부터 거리 차에 기초한 정위치 결정 시스템(쌍곡선 항법)이나 음파 측위 같은 실제 응용이 이 성질을 만족하기 때문입니다.

## 한 줄 예

초점이 $F_1(-5, 0)$, $F_2(5, 0)$일 때, $2a = 6$으로 정의된 쌍곡선의 모든 점 $P$는 $||PF_1| - |PF_2|| = 6$을 만족합니다.
