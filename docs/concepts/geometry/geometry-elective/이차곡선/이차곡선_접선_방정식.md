# 이차곡선 접선 방정식

> **예제** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선 위의 한 점이 주어졌을 때, 그 점을 접점으로 하는 접선의 방정식을 구하는 방법입니다.

## 본문
포물선 $y^2 = 8x$ 위의 점 $P(2, 4)$에서의 접선의 방정식을 구하시오.

### 단계별 풀이
**1단계: 접점이 곡선 위에 있는지 확인**
점 $(2, 4)$를 포물선 방정식에 대입하면 $4^2 = 8 \times 2 = 16$이 되어 등식이 성립합니다. 따라서 점 $P$는 포물선 위의 점입니다.

**2단계: 접선의 기울기 구하기**
포물선 $y^2 = 8x$를 $x$에 대해 음함수 미분하면 $2y \frac{dy}{dx} = 8$이므로 $\frac{dy}{dx} = \frac{4}{y}$입니다. 점 $(2, 4)$에서의 기울기는 $\frac{4}{4} = 1$입니다.

**3단계: 접선 방정식 구하기**
기울기가 $1$이고 점 $(2, 4)$를 지나는 직선의 방정식은 $y - 4 = 1(x - 2)$이므로 $y = x + 2$입니다.

공식을 이용하면 포물선 $y^2 = 4px$의 점 $(x_0, y_0)$에서의 접선은 $y_0 y = 2p(x + x_0)$입니다. $4p = 8$이므로 $p = 2$이며, 이를 대입하면 $4y = 4(x + 2)$가 되어 결과가 같습니다.

### 답과 변형
**답:** $y = x + 2$ (또는 $x - y + 2 = 0$)

**다른 이차곡선의 접선 공식:**
- **타원** $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$의 점 $(x_0, y_0)$에서: $\dfrac{x_0 x}{a^2} + \dfrac{y_0 y}{b^2} = 1$
- **쌍곡선** $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$의 점 $(x_0, y_0)$에서: $\dfrac{x_0 x}{a^2} - \dfrac{y_0 y}{b^2} = 1$
- **원** $x^2 + y^2 = r^2$의 점 $(x_0, y_0)$에서: $x_0 x + y_0 y = r^2$

**주의사항:**
- 접점 좌표는 반드시 곡선 위의 점이어야 합니다.
- 곡선 밖의 점에서 그은 접선을 구할 때는 이 공식을 직접 사용할 수 없으며, 판별식 조건을 이용해야 합니다.
- 포물선은 도함수가 존재하는 모든 점에서 접선을 가지지만, 타원과 쌍곡선의 경우 정의역을 확인해야 합니다.

## 관련 개념
- **이차곡선**: 포물선, 타원, 쌍곡선 등 각 곡선의 방정식 형태에 따라 접선의 공식을 다르게 적용해야 합니다.
