# 접선의 조건

## 정확한 진술

곡선과 직선이 **한 점에서만 만나며 그 점에서 곡선에 붙어 있는 직선**을 곡선의 접선이라 합니다. 곡선의 방정식을 $f(x, y) = 0$, 직선을 $y = mx + n$이라 할 때, 이 직선이 곡선의 접선이 되는 조건은 다음 두 가지 중 하나입니다.

1. **직선과 곡선의 교점을 구하는 방정식이 중근을 가진다** — $f(x, mx+n) = 0$의 판별식 $D = 0$
2. **접점에서 곡선의 기울기와 직선의 기울기가 같다** — 접점 $(x_0, y_0)$에서 $\frac{dy}{dx}\bigg|_{(x_0,y_0)} = m$

이차곡선(원, 타원, 쌍곡선, 포물선)의 경우, **두 조건은 동치**입니다. 즉, 교점이 중근이면 그 점에서 기울기도 같고, 반대도 성립합니다.

## 직관/기하적 의미

직선이 곡선과 두 점에서 만나면 할선(secant line)입니다. 이 두 교점이 가까워질수록 할선의 기울기는 곡선의 접선의 기울기에 가까워집니다. 극한으로 두 교점이 일치하면, 할선이 곡선의 접선이 되며 이것이 **미분계수의 기하학적 의미**입니다.

대수적으로는 교점 방정식이 중근을 가진다는 것이 "두 교점이 겹친다"를 의미합니다. 따라서 판별식 $D = 0$ 조건은 접선의 대수적 판정법이 됩니다.

## 한 줄 예

원 $x^2 + y^2 = 4$와 직선 $y = x + c$가 접할 조건은, $x^2 + (x+c)^2 = 4$를 정리한 $2x^2 + 2cx + (c^2-4) = 0$의 판별식이 $D = 4c^2 - 8(c^2-4) = 0$이므로 $c = \pm 2\sqrt{2}$입니다. (sympy: `from sympy import symbols, solve; c = symbols('c'); solve(4*c**2 - 8*(c**2 - 4), c)` → $c = \pm 2\sqrt{2}$)
