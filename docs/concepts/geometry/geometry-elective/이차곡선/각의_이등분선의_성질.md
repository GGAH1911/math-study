# 각의 이등분선의 성질

이차곡선의 접선과 두 초점이 이루는 각을 이등분선과 관련짓는 광학적 성질입니다. 기하 이차곡선 단원의 핵심 성질입니다.

## 정의

- **타원의 광학적 성질:** 타원의 한 점 $\mathrm{P}$에서의 접선은 두 초점 $\mathrm{F}, \mathrm{F}'$로부터 그어지는 선분 $\overline{\mathrm{PF}}, \overline{\mathrm{PF}'}$이 이루는 외각을 이등분합니다. 한 초점에서 출발한 빛이 타원에 반사되면 다른 초점으로 모입니다.
- **쌍곡선의 광학적 성질:** 쌍곡선의 한 점에서의 접선은 두 초점이 이루는 내각을 이등분합니다. 한 초점에서 출발한 빛은 다른 초점에서 출발한 것처럼 반사됩니다.
- **포물선의 광학적 성질:** 포물선의 점에서의 접선은 초점으로 향하는 선분과 축에 평행한 직선이 이루는 각을 이등분합니다.

## 예시

타원 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$의 초점은 $(\pm 3, 0)$. 점 $\mathrm{P}(0, 4)$에서의 접선은 $y = 4$. 이때 $\overline{\mathrm{PF}}$와 $\overline{\mathrm{PF}'}$는 대칭이고, 접선 $y = 4$가 이 두 선분의 외각을 이등분합니다.
