# 각의 이등분선의 성질

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선의 접선이 두 초점과 접점을 연결한 선분들이 이루는 각을 이등분하는 광학적 성질을 의미합니다.

## 본문
이차곡선의 접선과 두 초점이 이루는 각을 이등분선과 관련짓는 광학적 성질은 기하 이차곡선 단원의 핵심 성질입니다.

타원의 한 점 $\mathrm{P}$에서의 접선은 두 초점 $\mathrm{F}, \mathrm{F}'$로부터 그어지는 선분 $\overline{\mathrm{PF}}, \overline{\mathrm{PF}'}$이 이루는 외각을 이등분합니다. 이로 인해 한 초점에서 출발한 빛이 타원에 반사되면 다른 초점으로 모이는 성질을 갖습니다. 쌍곡선의 한 점에서의 접선은 두 초점이 이루는 내각을 이등분하며, 한 초점에서 출발한 빛은 다른 초점에서 출발한 것처럼 반사되어 나갑니다. 포물선의 경우, 접선은 초점으로 향하는 선분과 축에 평행한 직선이 이루는 각을 이등분하는 성질을 보입니다.

예를 들어 타원 $\tfrac{x^2}{25} + \tfrac{y^2}{16} = 1$의 초점은 $(\pm 3, 0)$입니다. 점 $\mathrm{P}(0, 4)$에서의 접선은 $y = 4$이며, 이때 $\overline{\mathrm{PF}}$와 $\overline{\mathrm{PF}'}$는 서로 대칭이며 접선 $y = 4$가 이 두 선분의 외각을 이등분하게 됩니다.

### 직관과 기하적 의미
빛이 곡선에 부딪혀 반사될 때, 입사각과 반사각이 같다는 원리가 이차곡선의 기하학적 구조와 결합된 것입니다. 타원은 빛을 한 초점으로 모아주는 거울 역할을 하고, 쌍곡선은 빛을 다른 초점에서 오는 것처럼 퍼뜨리는 역할을 합니다.

### 기본 성질
- 타원: 접선이 두 초점 연결 선분의 외각을 이등분함.
- 쌍곡선: 접선이 두 초점 연결 선분의 내각을 이등분함.
- 포물선: 접선이 초점 방향 선분과 축에 평행한 직선 사이의 각을 이등분함.

## 학습 체크
- 타원의 접선이 두 초점으로부터 그은 선분의 외각을 이등분한다는 사실을 기하학적으로 증명할 수 있는가?
- 쌍곡선에서 빛이 반사될 때, 반사된 빛의 경로가 다른 초점에서 출발한 경로와 일치함을 이해하고 있는가?
- 포물선의 접선 성질이 빛을 축에 평행하게 반사시키는 원리와 어떻게 연결되는지 설명할 수 있는가?
