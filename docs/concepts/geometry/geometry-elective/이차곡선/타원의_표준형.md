# 타원의 표준형

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
중심이 원점에 있고 장축이 좌표축과 평행한 타원을 대수적으로 나타낸 방정식입니다.

## 본문
타원의 표준형은 중심이 좌표 원점에 있고 장축이 좌표축과 평행한 타원의 방정식입니다. 장축이 $x$축일 때는 $\tfrac{x^2}{a^2} + \tfrac{y^2}{b^2} = 1 \quad (a > b > 0)$이며, 장축이 $y$축일 때는 $\tfrac{x^2}{b^2} + \tfrac{y^2}{a^2} = 1 \quad (a > b > 0)$입니다. 여기서 $a$는 장축의 반길이, $b$는 단축의 반길이를 의미합니다.

### 직관과 기하적 의미
타원은 두 초점으로부터의 거리의 합이 일정한 점들의 자취로 정의되는데, 표준형은 이를 가장 단순한 좌표계에서 대수적으로 표현한 것입니다. 원의 방정식 $x^2 + y^2 = r^2$을 한 축 방향으로 균등하게 확대 또는 축소하면 타원이 되며, 표준형의 분모 $a^2$과 $b^2$이 그 비율을 결정합니다. $a > b$이면 $x$축 방향으로 더 길게 늘어나고 초점도 $x$축 위에 놓이며, 반대로 $b > a$이면 $y$축 방향으로 더 길어집니다. 이처럼 좌표축과 정렬된 형태를 표준형이라 하는 이유는 회전이나 평행이동 없이 방정식의 계수만으로 타원의 크기와 방향을 명확히 파악할 수 있기 때문입니다.

### 기본 성질
타원의 초점 좌표는 $c = \sqrt{a^2 - b^2}$를 이용하여 $(\pm c, 0)$ 또는 $(0, \pm c)$로 나타납니다. 예를 들어 $\tfrac{x^2}{25} + \tfrac{y^2}{16} = 1$의 경우, 장축의 반길이는 5, 단축의 반길이는 4이며 초점은 $(\pm 3, 0)$입니다.

## 학습 체크
- 장축과 단축의 길이를 결정하는 $a$와 $b$의 관계를 통해 타원의 방향을 판별할 수 있는가?
- 초점의 좌표를 구하기 위해 필요한 $c$의 계산 원리를 이해하고 있는가?

## 관련 개념
- **이차곡선**: 타원은 이차곡선의 한 종류로, 초점과 준선의 성질을 통해 정의되는 곡선군에 속합니다.
