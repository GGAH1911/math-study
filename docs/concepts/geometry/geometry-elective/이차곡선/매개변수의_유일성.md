# 매개변수의 유일성

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
이차곡선을 매개변수로 표현할 때, 정의역 내의 서로 다른 매개변수 값이 곡선 위의 서로 다른 점에 대응되는 성질을 의미합니다.

## 본문
이차곡선을 매개변수로 표현할 때, 정의역의 서로 다른 매개변수 값이 곡선 위의 서로 다른 점에 대응되는 성질을 매개변수의 유일성이라고 합니다. 즉, 주어진 정의역에서 매개변수 함수 $(x(t), y(t))$가 단사함수임을 의미합니다. 더 엄밀하게는, 적절히 정한 정의역(보통 $[a, b)$ 또는 $(a, b)$)에서 $t_1 \neq t_2 \Rightarrow (x(t_1), y(t_1)) \neq (x(t_2), y(t_2))$를 만족해야 합니다.

### 직관과 기하적 의미
매개변수를 시간의 흐름으로 이해하면, 이 성질은 곡선 위의 각 점을 정확히 한 번씩만 지나간다는 것을 의미합니다. 만약 같은 점을 여러 번 방문하게 되면 매개변수의 유일성이 깨지게 됩니다. 예를 들어 원 $x^2 + y^2 = 1$을 $x = \cos t, y = \sin t$로 나타낼 때, $t = 0$과 $t = 2\pi$는 모두 점 $(1, 0)$에 도달하므로, 유일성을 확보하기 위해 정의역을 $[0, 2\pi)$로 제한하여 한 바퀴만 돌도록 설정합니다.

### 기본 성질
매개변수의 유일성은 곡선 위의 특정 점을 찾거나 기하학적 성질을 분석할 때, 한 점이 여러 매개변수 값에 대응될 가능성을 제거하여 분석을 명확하게 해줍니다. 특히 곡선의 길이를 계산하거나 적분을 수행할 때, 동일한 구간이 중복 계산되는 오류를 방지하는 데 필수적인 역할을 합니다. 타원 $x = 3\cos t, y = 2\sin t$ ($0 \le t < 2\pi$)에서 $t = \tfrac{\pi}{4}$일 때 점 $\left(\tfrac{3\sqrt{2}}{2}, \sqrt{2}\right)$를 얻으며, 이 범위 내의 다른 $t$ 값으로는 같은 점에 도달하지 않습니다.

- 매개변수의 유일성이 보장되지 않을 경우 곡선의 길이를 계산할 때 어떤 문제가 발생할 수 있는가?

## 관련 개념
- **이차곡선**: 매개변수를 통해 좌표평면 위의 점들의 집합으로 표현되며, 매개변수의 유일성을 통해 곡선의 각 점을 일대일로 대응시켜 분석할 수 있습니다.
