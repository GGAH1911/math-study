# 포물선의 표준형

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
포물선의 표준형은 꼭짓점이 원점에 있고 축이 좌표축과 일치하는 경우의 방정식으로, 초점과 준선으로부터 같은 거리에 있는 점들의 집합을 나타낸다.

## 본문
포물선의 표준형은 꼭짓점이 원점에 있고 축이 좌표축과 일치할 때의 방정식이다. 축이 $x$축일 때는 $y^2 = 4px$, 축이 $y$축일 때는 $x^2 = 4py$로 나타낸다. 여기서 $p$는 초점과 꼭짓점 사이의 거리인 초점거리를 의미하며, $p > 0$이면 양의 방향으로, $p < 0$이면 음의 방향으로 포물선이 열린다.

### 직관과 기하적 의미
포물선은 한 점(초점)과 한 직선(준선)까지의 거리가 항상 같은 점들의 집합이다. 예를 들어 $y^2 = 4px$의 경우, 초점은 $F(p, 0)$이고 준선은 직선 $x = -p$이다. 포물선 위의 임의의 점 $(x, y)$에서 초점까지의 거리 $\sqrt{(x-p)^2 + y^2}$와 준선까지의 거리 $|x + p|$가 항상 같다는 성질을 이용하면 표준형 방정식이 유도된다.

### 기본 성질
- 꼭짓점 $(0, 0)$에서 포물선이 가장 좁은 형태를 띤다.
- 대칭축은 초점과 꼭짓점을 연결한 직선이며, $x$축 또는 $y$축에 대해 대칭이다.
- 초점거리 $|p|$의 값이 커질수록 포물선의 폭은 더 넓어진다.

## 학습 체크
- 초점이 $(3, 0)$이고 준선이 $x = -3$인 포물선의 방정식을 구할 수 있는가?
- $p$의 부호에 따라 포물선이 그려지는 방향이 어떻게 달라지는지 설명할 수 있는가?
- 포물선 위의 한 점과 초점 사이의 거리와 준선 사이의 거리가 같음을 증명할 수 있는가?

## 관련 개념
- **이차곡선**: 포물선은 이차곡선의 한 종류로, 초점과 준선의 관계를 통해 정의되는 곡선군에 속한다.
