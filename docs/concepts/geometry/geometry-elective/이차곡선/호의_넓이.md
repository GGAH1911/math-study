# 호의 넓이

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
극좌표로 표현된 곡선이 원점으로부터 그리는 영역의 넓이를 부채꼴의 넓이 합을 이용해 구하는 개념입니다.

## 본문
극좌표 $r = f(\theta)$ ($\alpha \leq \theta \leq \beta$)로 주어진 곡선이 원점으로부터 그리는 영역의 넓이 $A$는 다음과 같이 정의합니다.
$$A = \frac{1}{2}\int_{\alpha}^{\beta} r^2 \, d\theta = \frac{1}{2}\int_{\alpha}^{\beta} [f(\theta)]^2 \, d\theta$$
여기서 $r$은 원점으로부터의 거리인 극반지름을 의미하며, $\theta$는 각도를 나타냅니다.

### 직관과 기하적 의미
직교좌표계에서 곡선 아래의 넓이를 구할 때는 영역을 수직 직사각형으로 잘게 나누어 합산하지만, 극좌표계에서는 원점을 중심으로 하는 부채꼴(sector)을 이용하여 넓이를 계산합니다. 각도가 $d\theta$만큼 미세하게 변할 때, 반지름이 $r$인 부채꼴의 넓이는 $\tfrac{1}{2}r^2 d\theta$로 근사할 수 있습니다. 이러한 미세한 부채꼴들의 넓이를 $\alpha$부터 $\beta$까지 모두 더하는 과정이 곧 적분이며, 이를 통해 전체 영역의 넓이를 얻게 됩니다.

### 기본 성질
- 원 $r = a$ (상수)의 넓이를 구하면 $A = \tfrac{1}{2}\int_0^{2\pi} a^2 \, d\theta = \pi a^2$가 되어 우리가 아는 원의 넓이 공식과 일치합니다.
- 심장형 곡선 $r = a(1 + \cos\theta)$의 넓이는 $A = \tfrac{1}{2}\int_0^{2\pi} a^2(1+\cos\theta)^2 \, d\theta = \tfrac{3\pi a^2}{2}$로 계산됩니다.

## 학습 체크
- 적분 구간 $\alpha$와 $\beta$를 설정할 때 곡선이 한 바퀴 회전하는 범위를 정확히 파악했는가?
- $r$ 자리에 함수 $f(\theta)$를 대입하여 제곱한 후 적분 식을 올바르게 세웠는가?

## 관련 개념
- **정적분의 활용**: 미세한 부채꼴의 넓이를 합산하여 전체 넓이를 구하는 과정은 정적분의 정의를 기하학적 넓이 계산에 적용한 대표적인 사례입니다.
