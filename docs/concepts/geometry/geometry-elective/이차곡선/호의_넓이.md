# 호의 넓이

## 정확한 진술

극좌표 $r = f(\theta)$ ($\alpha \leq \theta \leq \beta$)로 주어진 곡선이 원점으로부터 그리는 영역의 넓이를 다음과 같이 정의합니다.

$$A = \frac{1}{2}\int_{\alpha}^{\beta} r^2 \, d\theta = \frac{1}{2}\int_{\alpha}^{\beta} [f(\theta)]^2 \, d\theta$$

여기서 $r$은 원점으로부터의 거리(극반지름), $\theta$는 각도입니다.

## 직관 및 기하적 의미

직교좌표에서는 곡선 아래의 영역을 수직 직사각형으로 분할하여 $\int_a^b y \, dx$로 구합니다. 극좌표에서는 원점을 중심으로 부채꼴(sector)을 이용합니다.

각도가 $d\theta$만큼 변할 때, 반지름이 $r$인 호가 그리는 부채꼴의 넓이는 $\frac{1}{2}r^2 d\theta$입니다. (반지름 $r$, 중심각 $d\theta$인 부채꼴의 넓이는 $\frac{1}{2}r^2 d\theta$) 이를 $\alpha$에서 $\beta$까지 적분하면 전체 넓이를 얻습니다.

## 한 줄 예

원 $r = a$ (상수)의 넓이: $A = \frac{1}{2}\int_0^{2\pi} a^2 \, d\theta = \pi a^2$ ✓

다른 예로, 심장형 곡선(cardioid) $r = a(1 + \cos\theta)$의 넓이는 $A = \frac{1}{2}\int_0^{2\pi} a^2(1+\cos\theta)^2 \, d\theta = \frac{3\pi a^2}{2}$입니다.
