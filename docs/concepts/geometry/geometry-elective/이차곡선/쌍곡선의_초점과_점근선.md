# 쌍곡선의 초점과 점근선

## 정확한 진술

**쌍곡선**은 두 초점(focus)으로부터의 거리 차가 일정한 점들의 자취입니다. 두 초점을 $F(c, 0)$, $F'(-c, 0)$이라 하고, 거리 차의 절댓값을 $2a$라 하면, 쌍곡선 위의 임의의 점 $P(x, y)$는 다음을 만족합니다:

$$||PF| - |PF'|| = 2a$$

이를 정리하면 표준형 방정식을 얻습니다:

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a > 0, b > 0, c^2 = a^2 + b^2)$$

**초점(focus)**은 쌍곡선을 정의하는 두 고정점이며, 초점 사이의 거리는 $2c$입니다. **점근선(asymptote)**은 쌍곡선이 무한히 접근하되 만나지 않는 직선으로, 표준형 쌍곡선의 점근선은 다음과 같습니다:

$$y = \pm \frac{b}{a}x$$

## 직관/기하적 의미

원의 정의가 "한 점으로부터 거리가 같은 점들의 자취"라면, 쌍곡선은 "**두 점으로부터 거리 차가 같은 점들의 자취**"입니다. 이는 원뿔을 평면으로 자를 때 원뿔축과 충분히 가파른 각도에서 잘라낸 곡선으로도 나타나므로 이차곡선의 핵심입니다.

쌍곡선은 두 개의 분리된 가지(branch)를 가집니다. 오른쪽 가지의 점들은 $|PF| - |PF'| = 2a$를 만족하고, 왼쪽 가지는 $|PF'| - |PF| = 2a$를 만족합니다. 점이 초점에서 멀어질수록 쌍곡선은 점근선에 가까워지는데, 이는 "초점에서 매우 멀 때 원뿔이 기울어진 평면처럼 보인다"는 기하학적 직관과 부합합니다.

## 한 줄 예

$\frac{x^2}{9} - \frac{y^2}{16} = 1$이면 $a^2 = 9$, $b^2 = 16$이므로 초점은 $(\pm 5, 0)$ (여기서 $c = \sqrt{9+16} = 5$)이고, 점근선은 $y = \pm \frac{4}{3}x$입니다. (`from sympy import symbols, sqrt; c = sqrt(9 + 16); print(f"초점: ({float(c)}, 0)")`)
