# 쌍곡선 정의

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
두 초점으로부터의 거리의 차가 일정한 점들의 자취입니다.

## 본문
쌍곡선은 평면 위의 두 초점 $F$와 $F'$으로부터의 거리의 차의 절댓값이 일정한 점들의 자취입니다. 두 초점 사이의 거리를 $2c$라 하고, 쌍곡선 위의 임의의 점을 $P$라고 할 때, 다음 식을 만족하는 점들의 집합입니다.
$$||PF| - |PF'|| = 2a \quad (0 < a < c)$$
이때 상수 $a$는 쌍곡선의 크기와 모양을 결정하는 중요한 요소입니다.

### 직관과 기하적 의미
타원이 두 초점으로부터의 거리의 합이 일정한 곡선이라면, 쌍곡선은 거리의 차가 일정하다는 점에서 차이가 있습니다. 이러한 기하적 특성 때문에 쌍곡선은 하나의 연속된 곡선이 아니라, 서로 마주 보는 두 개의 분리된 가지를 형성하게 됩니다. 한 가지는 초점 $F$에 더 가깝고, 다른 가지는 초점 $F'$에 더 가깝게 형성됩니다.

### 기본 성질
초점이 $x$축 위의 $F(c, 0)$, $F'(-c, 0)$에 위치할 때, 쌍곡선의 표준형 방정식은 다음과 같습니다.
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (b^2 = c^2 - a^2)$$
이 곡선은 $x \geq a$ 또는 $x \leq -a$ 범위에서 정의되며, $(\pm a, 0)$을 꼭짓점으로 가집니다. 또한 곡선이 무한히 뻗어나갈 때 점근선인 $y = \pm\frac{b}{a}x$에 한없이 가까워지는 성질이 있습니다. 예를 들어, 초점이 $F(5, 0)$, $F'(-5, 0)$이고 거리 차의 절댓값이 $6$이라면 $a=3, c=5$이므로 $b^2=16$이 되어 방정식은 $\frac{x^2}{9} - \frac{y^2}{16} = 1$이 됩니다.

## 관련 개념
