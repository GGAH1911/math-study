# 주축

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
주축은 이차곡선을 표준형으로 나타낼 때 기준이 되는 대칭축으로, 곡선의 기하학적 구조와 대칭성을 결정하는 핵심 축입니다.

## 본문
주축(主軸)은 이차곡선을 표준형으로 나타낼 때의 대칭축을 의미합니다. 타원과 쌍곡선의 경우에는 중심을 지나는 서로 수직인 두 개의 축을 말하며, 포물선의 경우에는 꼭짓점을 지나는 대칭축을 의미합니다.

타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b > 0$)에서 $x$축은 길이가 $2a$인 장축이 되고, $y$축은 길이가 $2b$인 단축이 됩니다. 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$에서는 $x$축을 횡축이라 부르고, $y$축을 켤레축이라 부릅니다.

### 직관과 기하적 의미
주축은 이차곡선이 가장 대칭적인 방향을 나타냅니다. 어떤 각도로 기울어진 이차곡선이라도 적절한 좌표 회전을 통해 주축을 새로운 좌표축과 일치시키면 곡선의 방정식이 가장 단순한 표준형으로 표현됩니다. 타원의 경우 장축 위의 두 끝점은 중심에서 가장 먼 점들이고, 단축 위의 두 끝점은 중심에서 가장 가까운 점들입니다. 이 두 축의 길이 차이는 타원이 얼마나 납작한지를 결정하며, 쌍곡선에서도 주축은 중심, 꼭짓점, 점근선의 방향과 같은 핵심적인 기하학적 특성을 결정합니다.

### 기본 성질
- 타원의 장축과 단축은 서로 수직이며, 두 축의 길이 차이가 곡선의 모양을 결정합니다.
- 쌍곡선의 횡축과 켤레축은 서로 수직이며, 곡선의 방향과 점근선의 위치를 결정합니다.
- 포물선의 주축은 꼭짓점을 지나며 곡선의 대칭을 이루는 유일한 축입니다.

## 학습 체크
- 타원의 장축과 단축의 길이를 통해 타원의 모양(납작한 정도)을 어떻게 파악할 수 있는가?
- 쌍곡선에서 횡축과 켤레축이 곡선의 점근선과 어떤 관계를 갖는가?
- 포물선의 주축은 타원이나 쌍곡선의 주축과 비교했을 때 어떤 차이점이 있는가?

## 관련 개념
- **이차곡선**: 주축은 타원, 쌍곡선, 포물선과 같은 이차곡선의 표준형을 결정하고 대칭성을 정의하는 기초가 됩니다.
