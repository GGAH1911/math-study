# 단축의 길이

## 정확한 진술

타원에서 **단축(minor axis)**은 중심을 지나면서 장축에 수직인 두 꼭짓점을 잇는 선분입니다. 표준형 타원 방정식 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b > 0$)에서 단축의 길이는 $2b$입니다.

쌍곡선에서는 **허축(conjugate axis)**을 단축에 해당하는 개념으로 보며, 표준형 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$에서 허축의 길이는 $2b$입니다.

## 직관과 기하적 의미

타원은 "압축된 원"으로 생각할 수 있습니다. 두 개의 수직 축이 있는데, 하나는 길고(장축, 길이 $2a$) 하나는 짧습니다(단축, 길이 $2b$). 단축의 길이는 타원이 **수직 방향으로 얼마나 퍼져 있는지**를 나타냅니다.

쌍곡선의 경우, 허축의 길이는 쌍곡선을 감싸는 직사각형의 높이를 결정합니다. 이 직사각형의 대각선 방향이 쌍곡선의 점근선이 되므로, 허축의 길이는 쌍곡선의 "퍼짐" 정도를 제어합니다.

## 예제

**타원** $\frac{x^2}{25} + \frac{y^2}{9} = 1$에서:
- $a = 5$, $b = 3$이므로 단축의 길이는 $2 \times 3 = 6$

**쌍곡선** $\frac{x^2}{16} - \frac{y^2}{4} = 1$에서:
- $a = 4$, $b = 2$이므로 허축의 길이는 $2 \times 2 = 4$

핵심: 단축의 길이는 **분모의 작은 쪽에서 제곱근을 취하고 2배**하면 됩니다.
