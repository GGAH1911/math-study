### 정확한 진술

평면 위의 두 정점(초점)으로부터의 거리 합이 일정한 점들의 집합을 **타원**(ellipse)이라고 합니다. 초점을 $F_1$, $F_2$라 하고 일정한 거리 합을 $2a$라 하면, 타원 위의 모든 점 $P$에 대해
$$\overline{PF_1} + \overline{PF_2} = 2a$$
가 성립합니다. 여기서 $a$는 장축의 반길이이고, 두 초점 사이의 거리를 $2c$ (단, $0 < c < a$)라 하면 $b = \sqrt{a^2 - c^2}$로 정의되며, $b$는 단축의 반길이입니다.

좌표계에서 두 초점이 $(\pm c, 0)$에 있을 때 타원의 표준형은
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)$$
입니다.

### 직관과 기하적 의미

타원의 정의는 원의 일반화입니다. 원은 한 점(중심)으로부터 거리가 일정한 점들의 자취이지만, 타원은 **두 점으로부터의 거리의 합**이 일정합니다. 따라서 두 초점이 가까워질수록(즉, $c \to 0$) 타원은 원에 가까워집니다.

타원의 '길쭉함'을 나타내는 지표가 **이심률**(eccentricity) $e = \frac{c}{a}$입니다. $0 < e < 1$이며, $e$가 0에 가까울수록 원 모양이고, 1에 가까울수록 길쭉해집니다.

### 한 줄 예

초점이 $F_1(-3, 0)$, $F_2(3, 0)$이고 거리 합이 10인 타원: $c = 3$, $2a = 10$ (따라서 $a = 5$)이고, $b = \sqrt{25-9} = 4$이므로 표준형은 $\frac{x^2}{25} + \frac{y^2}{16} = 1$입니다. (검산: `sympy.symbols('x y'); a, b = 5, 4; sympy.simplify(sympy.sqrt(x**2 + 9) + sympy.sqrt((x-6)**2) - 10)` 시 $x=5$일 때 $|5+3| + |5-3| = 10$ ✓)
