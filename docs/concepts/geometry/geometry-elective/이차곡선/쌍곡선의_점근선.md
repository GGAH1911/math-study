# 쌍곡선의 점근선

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
쌍곡선이 무한히 멀어질 때 곡선이 한없이 가까워지는 직선을 점근선이라 합니다.

## 본문
쌍곡선의 **점근선**(asymptote)은 쌍곡선 위의 점이 무한히 멀어질 때 곡선이 한없이 가까워지지만 결코 만나지는 않는 직선을 의미합니다. 표준형 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$의 점근선은 $y = \pm \frac{b}{a}x$이며, 표준형 $\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$의 점근선은 $y = \pm \frac{a}{b}x$입니다. 점근선을 구하는 효율적인 방법은 쌍곡선의 방정식에서 우변의 상수항을 $0$으로 치환한 후 좌변을 인수분해하는 것입니다. 예를 들어 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0$으로 식을 세우면 $\left(\frac{x}{a} - \frac{y}{b}\right)\left(\frac{x}{a} + \frac{y}{b}\right) = 0$이 되어 두 직선의 방정식을 바로 얻을 수 있습니다.

### 직관과 기하적 의미
점근선은 쌍곡선의 전체적인 모양을 결정하는 기하학적 골격 역할을 합니다. 쌍곡선의 두 점근선은 원점을 중심으로 대칭을 이루며, $x$ 또는 $y$의 값이 커질수록 쌍곡선은 이 점근선에 점점 더 밀착하게 됩니다. 두 점근선 사이의 각도가 작으면 쌍곡선은 완만하게 퍼지는 형태를 띠고, 각도가 크면 가파르게 뻗어나가는 형태를 띠게 됩니다. 이는 타원과 같은 다른 이차곡선에서는 나타나지 않는 쌍곡선만의 고유한 특징입니다.

### 기본 성질
- 점근선은 쌍곡선의 곡선이 무한히 뻗어나가는 방향을 안내하는 가이드라인 역할을 합니다.
- 쌍곡선의 방정식에서 상수항을 $0$으로 두어 얻은 직선은 항상 점근선이 됩니다.
- 점근선은 쌍곡선과 만나지 않지만, 좌표값이 커질수록 두 사이의 거리는 $0$에 수렴합니다.

## 학습 체크
- 쌍곡선의 방정식에서 우변을 $0$으로 두었을 때 얻어지는 직선이 왜 점근선이 되는지 설명할 수 있는가?
- 쌍곡선의 표준형 식에서 $a$와 $b$의 값에 따라 점근선의 기울기가 어떻게 변화하는지 이해하고 있는가?

## 관련 개념
- **이차곡선**: 쌍곡선은 이차곡선의 한 종류로, 점근선을 가진다는 점에서 타원이나 포물선과 구별되는 특징을 가집니다.
