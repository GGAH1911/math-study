# 극곡선의 미분

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
극좌표로 표현된 곡선 위의 한 점에서의 접선의 기울기를 구하기 위해 매개변수 미분법을 적용하는 과정입니다.

## 본문
극곡선의 미분이란 극좌표 $r = f(\theta)$로 표현된 곡선에서 접선의 기울기나 곡선의 변화율을 구하는 과정입니다. 극좌표 $(r, \theta)$의 관계식을 데카르트 좌표 $(x, y)$로 변환한 후 연쇄법칙을 적용하여, 극곡선 위의 한 점에서 $\frac{dy}{dx}$를 구합니다. 극곡선 위의 점은 $x = r\cos\theta$, $y = r\sin\theta$로 나타나므로, 접선의 기울기는 다음과 같습니다.

$$\frac{dy}{dx} = \frac{\frac{dr}{d\theta}\sin\theta + r\cos\theta}{\frac{dr}{d\theta}\cos\theta - r\sin\theta}$$

### 직관과 기하적 의미
극곡선의 미분은 회전하는 반지름과 거리 변화의 합성 효과를 포착합니다. 일반적인 함수 $y = f(x)$와 달리, 극곡선은 각도 $\theta$가 변할 때 동시에 반지름 $r$도 변하므로, 이 두 변화를 모두 고려해야 접선의 기울기를 정확히 구할 수 있습니다. 식의 분자인 $\frac{dr}{d\theta}\sin\theta + r\cos\theta$는 수직 방향의 변화를 나타내며, 분모인 $\frac{dr}{d\theta}\cos\theta - r\sin\theta$는 수평 방향의 변화를 나타냅니다.

### 기본 성질
원점에서 출발하는 나선 $r = \theta$ ($0 < \theta < 2\pi$)에서 $\theta = \pi$ 일 때 접선의 기울기를 구하면 다음과 같습니다.

$$\frac{dy}{dx}\bigg|_{\theta=\pi} = \frac{1 \cdot \sin\pi + \pi\cos\pi}{1 \cdot \cos\pi - \pi\sin\pi} = \frac{0 - \pi}{-1 - 0} = \pi$$

## 학습 체크
- 극좌표 식을 $x$와 $y$에 대한 매개변수 방정식으로 변환할 수 있는가?
- 연쇄법칙을 이용하여 $\frac{dy}{dx}$를 구하는 공식이 도출되는 과정을 이해하고 있는가?
- $\frac{dr}{d\theta}$의 값이 $0$인 경우와 그렇지 않은 경우의 기하학적 차이를 구분할 수 있는가?

## 관련 개념
- **여러가지함수의 미분**: 극곡선의 미분은 매개변수 $\theta$에 대한 미분을 포함하므로, 삼각함수와 같은 다양한 함수의 미분법을 기초로 합니다.
