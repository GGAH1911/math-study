# 이차곡선

> **단원** · 기하 · 선수: [도형의 방정식](/concepts/도형의_방정식)

## 학습 목표
- 포물선·타원·쌍곡선의 정의와 표준형 방정식을 이해한다
- 이차곡선의 접선·초점을 다룬다

## 다룰 정의 / 정리 / 예제

**정의**
- 포물선 (초점·준선)
- 타원 (두 초점)
- 쌍곡선 (점근선)

**정리**
- 포물선 $y^2=4px$, 타원 $x^2/a^2+y^2/b^2=1$, 쌍곡선 $x^2/a^2-y^2/b^2=1$

**예제**

- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
