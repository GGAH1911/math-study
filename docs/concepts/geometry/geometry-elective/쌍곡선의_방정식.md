### 정확한 진술

쌍곡선은 평면 위의 두 개의 고정된 점(초점, focus)으로부터 **거리의 차가 일정한** 점들의 자취입니다. 초점을 $F_1$, $F_2$라 하고, 두 초점 사이의 거리를 $2c$라 할 때, 다음을 만족하는 점 $P$의 집합입니다:

$$|PF_1| - |PF_2| = 2a \quad (0 < a < c)$$

여기서 $2a$는 상수입니다.

### 직관/기하적 의미

타원이 "거리의 합이 일정"이라면, 쌍곡선은 "거리의 **차**가 일정"입니다. 이 조건은 두 개의 분리된 곡선 부분(branch)을 만듭니다. 각 점이 항상 한쪽 초점에 더 가까우므로, 좌우로 나뉜 대칭적인 모양이 됩니다.

쌍곡선은 두 개의 가지(branch)를 가지며, 각 가지는 초점 방향으로 무한히 뻗어나갑니다. 특히 중심에서 멀어질수록 두 개의 점근선(asymptote)에 점점 가까워집니다.

### 표준형 방정식

중심이 원점이고, 초점이 $x$축 위에 있는 경우의 쌍곡선 방정식은:

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

여기서 $a > 0$, $b > 0$이고, $c^2 = a^2 + b^2$ (단, $c$는 초점까지의 거리)

초점이 $y$축 위에 있으면:

$$\frac{y^2}{a^2} - \frac{x^2}{b^2} = 1$$

### 한 줄 예

$\frac{x^2}{4} - \frac{y^2}{5} = 1$은 $a = 2$, $b = \sqrt{5}$이므로 $c = 3$, 초점은 $(\pm 3, 0)$입니다.

검산: `sympy.solve([(x**2/4 - y**2/5 - 1), (x - 3)**2 + y**2 - (x + 3)**2 - y**2 + 12], [x, y])` 으로 초점 조건 확인 가능합니다. 실제로는 초점의 정의에서 $x = 3$일 때 거리의 차가 $4 = 2a$임을 직접 확인할 수 있습니다.
