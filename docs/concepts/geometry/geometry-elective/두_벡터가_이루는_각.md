# 두 벡터가 이루는 각

### 정확한 진술

영벡터가 아닌 두 벡터 $\vec{a}$, $\vec{b}$가 이루는 각 $\theta$는 다음을 만족하는 각입니다:

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$$

이때 $\theta$의 범위는 $0 \le \theta \le \pi$ 입니다. 여기서 $\vec{a} \cdot \vec{b}$는 두 벡터의 내적, $|\vec{a}|$, $|\vec{b}|$는 각각의 크기입니다.

### 기하적 의미

두 벡터를 같은 시작점에서 그렸을 때, 두 화살표 사이의 각도가 바로 "두 벡터가 이루는 각"입니다. 내적 공식은 이 각도를 각 벡터의 성분으로부터 계산하는 방법을 제공합니다.

$\theta = 0$일 때 두 벡터는 같은 방향이고, $\theta = \frac{\pi}{2}$일 때 수직, $\theta = \pi$일 때 반대 방향입니다. 내적이 양수면 예각, 0이면 수직, 음수면 둔각입니다.

### 한 줄 예

벡터 $\vec{a} = (1, 0)$과 $\vec{b} = (1, 1)$이 이루는 각 $\theta$는 $\cos\theta = \frac{1}{\sqrt{2}}$이므로 $\theta = \frac{\pi}{4}$ (45도)입니다.

검산: `import sympy; sympy.acos(1/sympy.sqrt(2))` → $\frac{\pi}{4}$
