### 정확한 진술

두 평면벡터 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$에 대해:
$$\vec{a} = \vec{b} \iff a_1 = b_1 \text{ 그리고 } a_2 = b_2$$

즉, 두 벡터가 같으려면 **모든 성분이 각각 같아야** 합니다.

### 직관과 기하적 의미

벡터는 크기와 방향을 가진 화살표입니다. 두 벡터가 정말 "같다"는 것은 단순히 길이가 같은 것이 아니라, 방향도 완전히 같아야 한다는 뜻입니다. 

좌표평면에서 생각해보면, 벡터 $\vec{a} = (a_1, a_2)$는 원점에서 출발해 점 $(a_1, a_2)$에 도달하는 화살표입니다. 벡터 $\vec{b} = (b_1, b_2)$도 마찬가지로 점 $(b_1, b_2)$를 나타냅니다. 이 두 화살표가 정확히 같은 위치에서 끝나려면, 각 방향의 이동량이 모두 같아야 하므로 성분이 모두 같아야 하는 것입니다.

**역방향이 주의점입니다.** 벡터 $\vec{a} = (3, 2)$와 $\vec{a}' = (3, -2)$는 $x$방향은 같지만 $y$방향이 다르므로 **다른 벡터**입니다. 

### 한 줄 예

$\vec{u} = (2, 5)$와 $\vec{v} = (2, 5)$는 모든 성분이 같으므로 $\vec{u} = \vec{v}$이지만, $\vec{u} = (2, 5)$와 $\vec{w} = (5, 2)$는 성분이 다르므로 $\vec{u} \neq \vec{w}$입니다.

### 확장: 성분 이용한 조건들

벡터 조건을 확인할 때는 **성분 비교**가 기본입니다. 예를 들어 $\vec{a} = (x+1, 3)$, $\vec{b} = (4, y-1)$이고 $\vec{a} = \vec{b}$라면, $x+1 = 4$이고 $3 = y-1$이므로 $x=3$, $y=4$입니다. (검증: `sympy.solve([x+1-4, 3-(y-1)], [x, y])` → `{x: 3, y: 4}`)
