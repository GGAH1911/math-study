# 벡터의 조건

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 평면벡터가 같으려면 크기와 방향이 모두 일치해야 하며, 이는 각 성분의 값이 모두 같음을 의미합니다.

## 본문
두 평면벡터 $\vec{a} = (a_1, a_2)$와 $\vec{b} = (b_1, b_2)$에 대하여, $\vec{a} = \vec{b}$일 조건은 $a_1 = b_1$이고 $a_2 = b_2$인 것입니다. 즉, 두 벡터가 같다는 것은 모든 성분이 각각 일치해야 함을 뜻합니다.

### 직관과 기하적 의미
벡터는 크기와 방향을 가진 화살표로 이해할 수 있습니다. 두 벡터가 같다는 것은 단순히 화살표의 길이가 같은 것을 넘어, 화살표가 가리키는 방향까지 완전히 동일해야 함을 의미합니다. 좌표평면에서 벡터 $\vec{a} = (a_1, a_2)$를 원점에서 점 $(a_1, a_2)$로 향하는 화살표라고 할 때, $\vec{b} = (b_1, b_2)$와 같은 화살표가 되려면 각 방향으로 이동한 양이 모두 같아야 합니다. 따라서 성분 중 하나라도 다르면 두 벡터는 서로 다른 벡터가 됩니다. 예를 들어 $\vec{a} = (3, 2)$와 $\vec{a}' = (3, -2)$는 $x$축 방향의 이동량은 같지만 $y$축 방향의 이동량이 다르므로 서로 다른 벡터입니다.

### 기본 성질
벡터의 같음을 확인할 때는 각 성분을 서로 비교하는 성분 비교법을 사용합니다. 만약 $\vec{a} = (x+1, 3)$이고 $\vec{b} = (4, y-1)$일 때, $\vec{a} = \vec{b}$를 만족하려면 $x+1=4$와 $3=y-1$을 동시에 만족하는 $x$와 $y$의 값을 찾아야 합니다. 이를 통해 $x=3$, $y=4$임을 구할 수 있습니다.

## 학습 체크
- 두 벡터의 크기(길이)가 같다고 해서 반드시 두 벡터가 같은 벡터인가요?
- 벡터의 성분 중 하나라도 부호가 다르면 두 벡터는 같다고 할 수 있나요?

## 관련 개념
- **평면벡터**: 좌표평면 위에서 크기와 방향을 성분으로 나타내어 다루는 벡터로, 성분의 일치 여부를 통해 두 벡터의 같음을 판별합니다.
