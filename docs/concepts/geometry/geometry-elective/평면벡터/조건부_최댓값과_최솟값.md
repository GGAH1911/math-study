# 조건부 최댓값과 최솟값

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
제약 조건으로 인해 제한된 영역 내에서 함수의 최댓값과 최솟값을 찾는 과정입니다.

## 본문
조건부 최댓값과 최솟값이란 제약 조건이라 불리는 추가적인 제한을 만족하면서 함수가 가질 수 있는 최대·최솟값을 의미합니다. 더 정확히 말하면, 함수의 정의역이 실수 전체가 아니라 특정 조건을 만족하는 점들의 집합으로 제한될 때, 그 제한된 영역 내에서 함수가 나타내는 극값을 의미합니다. 예를 들어, 함수 $f(x, y)$에 대하여 조건 $g(x, y) = 0$을 만족하는 점 $(x, y)$ 중에서 $f$의 최댓값을 찾는 것이 조건부 최댓값 문제입니다. 고등학교 교육과정에서는 주로 일차함수나 이차함수가 직선, 원, 도형의 경계와 같은 조건을 만족할 때의 극값을 구하는 방식으로 다룹니다.

### 직관과 기하적 의미
조건 없이 함수를 최적화하는 것과 달리, 조건부 극값은 제약 조건이 우리가 탐색할 수 있는 영역을 좁혀주는 역할을 합니다. 기하학적으로는 원 위의 점들만 고려하거나 삼각형의 변 위에서만 탐색하는 상황과 같습니다. 예를 들어 $f(x, y) = x + y$를 원 $x^2 + y^2 = 1$ 위에서 최대화할 때, 함수의 등고선이 원과 접하는 지점에서 최댓값이 나타납니다. 이는 제약 조건의 경계에서 목적함수의 등고선과 제약곡선이 평행할 때 극값이 나타난다는 원리를 기하학적으로 보여줍니다.

### 기본 성질
- 제약 조건이 형성하는 영역의 경계에서 최댓값 또는 최솟값이 발생할 수 있습니다.
- 함수의 등고선과 제약 조건의 곡선이 접하는 지점에서 극값이 형성되는 경향이 있습니다.

## 학습 체크
- 주어진 제약 조건이 함수의 정의역을 어떻게 제한하는지 파악했는가?
- 함수의 등고선과 제약 조건의 경계가 접하는 지점을 찾을 수 있는가?
- 제한된 영역의 경계점과 내부의 극값을 구분하여 고려했는가?

## 관련 개념
- **평면벡터**: 벡터의 내적을 이용하여 두 직선이나 곡선 사이의 거리 및 함수의 최댓값을 기하학적으로 해석할 수 있습니다.
