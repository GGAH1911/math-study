# 선분의 매개변수 표현

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
선분 위의 임의의 점을 매개변수 $t$를 이용하여 위치벡터의 선형 결합으로 나타내는 방법입니다.

## 본문
평면에서 두 점 $A, B$가 주어졌을 때, 선분 $AB$ 위의 임의의 점 $P$는 다음과 같이 나타낼 수 있습니다.
$$\vec{OP} = (1-t)\vec{OA} + t\vec{OB}, \quad 0 \leq t \leq 1$$
위치벡터를 $\vec{a} = \vec{OA}, \vec{b} = \vec{OB}$라 할 때, $\vec{p} = (1-t)\vec{a} + t\vec{b}$로 표현하며, 이때 $t$를 매개변수라 하고 이 식을 선분 $AB$의 매개변수 표현이라 합니다.

### 직관과 기하적 의미
선분 위의 점은 점 $A$에서 점 $B$ 방향으로 얼마나 진행했는가에 따라 결정됩니다. 매개변수 $t$가 $0$에서 $1$로 변함에 따라 점 $P$는 $A$에서 출발하여 $B$까지 선분을 따라 이동합니다. $t=0$이면 점 $A$에 위치하고, $t=1$이면 점 $B$에 위치하며, $0 < t < 1$인 구간에서 점 $P$는 선분 $AB$ 내부의 점이 됩니다.

### 기본 성질
계수인 $(1-t)$와 $t$의 합은 항상 $1$이 되는데, 이는 이 표현을 두 점의 가중평균으로 해석할 수 있음을 의미합니다. 예를 들어 $A(1, 2), B(5, 4)$인 경우 매개변수 표현은 $\vec{OP} = (1+4t, 2+2t)$이며, $t=\frac{1}{2}$을 대입하면 선분의 중점인 $(3, 3)$을 얻을 수 있습니다.

## 학습 체크
- 매개변수 $t$의 범위가 $0 \leq t \leq 1$이 아닌 $t > 1$ 또는 $t < 0$이 될 경우, 점 $P$는 어떤 위치에 있게 되는가?
- 두 계수의 합이 항상 $1$이 되어야 하는 이유는 무엇인가?

## 관련 개념
- **평면벡터**: 선분 위의 점의 위치를 벡터의 합과 실수배를 이용한 선형 결합으로 표현하는 기초가 됩니다.
