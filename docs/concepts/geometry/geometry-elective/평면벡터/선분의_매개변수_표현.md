# 선분의 매개변수 표현

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 정확한 진술

평면에서 두 점 $A$, $B$가 주어졌을 때, 선분 $AB$ 위의 임의의 점 $P$는 다음과 같이 나타낼 수 있습니다.

$$\vec{OP} = (1-t)\vec{OA} + t\vec{OB}, \quad 0 \leq t \leq 1$$

또는 위치벡터 $\vec{a} = \vec{OA}$, $\vec{b} = \vec{OB}$로 쓸 때:

$$\vec{p} = (1-t)\vec{a} + t\vec{b}$$

여기서 $t$를 **매개변수(parameter)**라 하고, 이 식을 선분 $AB$의 **매개변수 표현**이라 합니다.

## 직관 · 기하적 의미

선분 위의 점은 $A$에서 $B$ 방향으로 얼마나 진행했는가로 결정됩니다.

- $t=0$일 때: $\vec{p} = \vec{a}$ (점 $A$)
- $t=1$일 때: $\vec{p} = \vec{b}$ (점 $B$)  
- $0 < t < 1$일 때: $P$는 선분 $AB$ 위의 점

계수 $(1-t)$와 $t$는 합이 항상 $1$이므로, 이 표현을 **가중평균**으로 해석할 수 있습니다. 매개변수 $t$가 $0$에서 $1$로 변할 때, 점 $P$는 $A$에서 출발하여 $B$까지 선분을 따라 움직입니다.

## 한 줄 예

$A(1, 2)$, $B(5, 4)$일 때 선분 $AB$의 매개변수 표현은 $\vec{OP} = (1-t)(1, 2) + t(5, 4) = (1+4t, 2+2t)$ ($0 \leq t \leq 1$). 예를 들어 $t=\frac{1}{2}$일 때 점 $(3, 3)$ (중점)을 얻습니다.

`sympy.solve([1+4*t - 3, 2+2*t - 3], [t])` → $t = 0.5$를 확인할 수 있습니다.
