# 벡터의 크기

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
벡터의 크기는 벡터가 나타내는 물리량의 강도를 나타내며, 기하학적으로는 원점에서 종점까지의 직선거리를 의미합니다.

## 본문
3차원 공간의 벡터 $\vec{a} = (a_1, a_2, a_3)$에 대하여, 벡터의 크기 또는 노름(norm)은 $|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$로 정의합니다. 2차원 벡터 $\vec{a} = (a_1, a_2)$의 경우에는 $|\vec{a}| = \sqrt{a_1^2 + a_2^2}$입니다. 벡터의 크기는 항상 음이 아닌 실수로 나타납니다.

### 직관과 기하적 의미
벡터의 크기는 기하학적으로 원점에서 점 $(a_1, a_2, a_3)$까지의 직선거리를 나타냅니다. 3차원에서 좌표축에 평행한 변의 길이가 각각 $|a_1|, |a_2|, |a_3|$인 직육면체를 그리면, 벡터의 크기는 원점에서 대각 꼭짓점까지의 대각선 길이와 같습니다. 이는 피타고라스 정리를 여러 번 적용하여 얻어지는 결과입니다. 화살표로 벡터를 표현할 때 화살표의 길이가 곧 벡터의 크기이며, 크기가 클수록 벡터가 더 멀리 뻗어 있음을 의미합니다. 영벡터 $\vec{0} = (0, 0, 0)$만이 유일하게 크기가 0인 벡터입니다.

### 기본 성질
벡터의 크기를 구하는 것은 벡터가 나타내는 물리량의 강도를 수치로 측정하는 과정과 같습니다.
