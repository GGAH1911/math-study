# 위치벡터

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
원점을 시점으로 하여 평면 위의 점의 위치를 나타내는 벡터입니다.

## 본문
좌표평면에서 원점 $O$를 기준으로 점 $P$까지의 벡터를 점 $P$의 위치벡터라고 합니다. 점 $P$의 좌표가 $(x, y)$일 때, 위치벡터는 $\overrightarrow{OP} = (x, y)$로 나타냅니다. 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$가 있을 때, 점 $A$의 위치벡터를 $\vec{a}$, 점 $B$의 위치벡터를 $\vec{b}$라고 하면 두 점을 잇는 벡터 $\overrightarrow{AB}$는 $\vec{b} - \vec{a} = (x_2 - x_1, y_2 - y_1)$로 계산할 수 있습니다.

### 직관과 기하적 의미
위치벡터는 원점을 기준으로 평면상의 위치를 나타내는 화살표입니다. 어떤 점이 평면 어디에 있는지를 벡터로 표현함으로써, 점의 좌표와 벡터를 동일한 체계 안에서 다룰 수 있게 됩니다. 이를 통해 벡터의 덧셈, 뺄셈, 스칼라배 연산을 기하학적으로 해석할 수 있으며, 선분의 내분점, 외분점, 무게중심과 같은 기하학적 성질을 벡터 계산을 통해 효율적으로 구할 수 있습니다.

### 기본 성질
두 위치벡터 $\vec{a}$와 $\vec{b}$를 이용하여 선분 $AB$의 중점 $M$의 위치벡터를 구하면 $\tfrac{\vec{a} + \vec{b}}{2}$가 됩니다. 예를 들어 점 $A(1, 2)$와 점 $B(4, 6)$이 있을 때, 각 위치벡터는 $\vec{a} = (1, 2)$, $\vec{b} = (4, 6)$이며, 이들의 합을 2로 나눈 중점의 위치벡터는 $(2.5, 4)$가 됩니다.

## 학습 체크
- 점 $P$의 좌표가 주어졌을 때 이를 위치벡터 $\overrightarrow{OP}$로 올바르게 변환할 수 있는가?
- 두 점의 위치벡터를 이용하여 두 점 사이를 잇는 벡터 $\overrightarrow{AB}$를 구할 수 있는가?
- 위치벡터를 활용하여 선분의 내분점이나 무게중심의 좌표를 계산할 수 있는가?

## 관련 개념
- **평면벡터**: 위치벡터를 통해 평면 위의 점을 벡터로 나타냄으로써 평면벡터의 연산을 좌표를 이용한 계산으로 연결할 수 있습니다.
