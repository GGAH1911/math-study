# 벡터의 자취

## 정확한 진술

벡터 $\vec{v}$가 특정 조건을 만족할 때, $\vec{v}$의 끝점이 그리는 도형을 **벡터의 자취**라고 합니다. 일반적으로 원점을 시작점으로 하는 위치벡터 $\vec{r} = (x, y)$가 어떤 조건을 충족할 때, 벡터의 끝점 좌표 $(x, y)$가 만족하는 방정식을 **자취의 방정식**이라 합니다.

## 직관/기하적 의미

벡터로 표현된 조건(크기, 수직, 평행 등)은 곧 그 벡터가 가리키는 점의 좌표가 만족해야 할 조건으로 해석됩니다. 예를 들어 "크기가 $r$인 벡터"는 끝점이 원점으로부터 거리 $r$인 모든 점, 즉 반지름 $r$인 원을 의미합니다. 이처럼 벡터 조건을 좌표로 번역하면 원, 직선, 포물선, 타원 같은 익숙한 이차곡선들이 나타납니다. 벡터 언어는 기하적 조건(예: "두 벡터가 수직")을 깔끔하게 표현하므로, 자취 문제를 푸는 강력한 도구가 됩니다.

## 한 줄 예

$\vec{r} = (x, y)$가 $|\vec{r}| = 3$을 만족하면 자취는 원 $x^2 + y^2 = 9$; $\vec{r}$이 $\vec{r} \cdot (1, 2) = 5$를 만족하면 자취는 직선 $x + 2y = 5$입니다.
