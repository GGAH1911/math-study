# 무게중심의 벡터 표현

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
삼각형의 무게중심은 세 꼭짓점의 위치벡터의 산술 평균으로 나타낼 수 있으며, 각 중선을 $2:1$로 내분하는 점입니다.

## 본문
삼각형 $\mathrm{ABC}$의 세 꼭짓점의 위치벡터를 각각 $\vec{a}, \vec{b}, \vec{c}$라고 할 때, 이 삼각형의 무게중심 $\mathrm{G}$의 위치벡터 $\vec{g}$는 다음과 같이 정의됩니다.
$$\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$
이를 좌표평면 위의 점 $\mathrm{A}(x_1, y_1), \mathrm{B}(x_2, y_2), \mathrm{C}(x_3, y_3)$에 대하여 성분별로 나타내면 무게중심 $\mathrm{G}$의 좌표는 다음과 같습니다.
$$\mathrm{G}\left(\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3}\right)$$
이 공식은 평면벡터 단원에서 도형의 특수점을 벡터로 표현하는 가장 대표적인 사례 중 하나입니다.

### 직관과 기하적 의미
무게중심은 삼각형의 질량이 각 꼭짓점에 균일하게 분포되어 있다고 가정할 때, 도형의 물리적 균형을 이루는 평형점을 의미합니다. 기하학적으로는 삼각형의 세 중선이 만나는 점이며, 각 중선은 꼭짓점에서 무게중심까지의 거리와 무게중심에서 변의 중점까지의 거리의 비가 $2:1$이 되도록 분할합니다.

### 기본 성질
삼각형의 무게중심은 세 중선의 교점이며, 모든 중선에 대해 동일하게 $2:1$의 내분점이라는 성질을 가집니다. 또한, 벡터의 관점에서 무게중심은 세 꼭짓점 벡터의 합을 꼭짓점의 개수인 $3$으로 나눈 값과 같습니다.

## 학습 체크

- 무게중심이 중선을 $2:1$로 내분한다는 성질을 이용하여 벡터 식을 유도할 수 있는가?
- 좌표평면에서 세 점의 좌표를 이용하여 무게중심의 좌표를 정확히 계산할 수 있는가?
