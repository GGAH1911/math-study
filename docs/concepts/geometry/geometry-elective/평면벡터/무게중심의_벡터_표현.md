# 무게중심의 벡터 표현

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

삼각형의 무게중심의 위치를 꼭짓점 벡터로 나타낸 식입니다. 기하 평면벡터 단원에서 도형의 특수점을 벡터로 다루는 대표 공식입니다.

## 정의

삼각형 $\mathrm{ABC}$의 세 꼭짓점의 위치벡터를 $\vec{a}, \vec{b}, \vec{c}$라 할 때, 무게중심 $\mathrm{G}$의 위치벡터는
$$\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}.$$
좌표로 풀어쓰면 $\mathrm{A}(x_1, y_1), \mathrm{B}(x_2, y_2), \mathrm{C}(x_3, y_3)$일 때
$$\mathrm{G}\!\left(\frac{x_1 + x_2 + x_3}{3},\ \frac{y_1 + y_2 + y_3}{3}\right).$$

또한 무게중심은 각 중선을 꼭짓점 쪽에서 $2 : 1$로 내분하는 점입니다.

## 예시

세 점 $\mathrm{A}(1, 2), \mathrm{B}(4, -1), \mathrm{C}(-2, 5)$를 꼭짓점으로 하는 삼각형의 무게중심 $\mathrm{G}$를 구해 봅니다.
$$\mathrm{G}\!\left(\frac{1 + 4 + (-2)}{3},\ \frac{2 + (-1) + 5}{3}\right) = \mathrm{G}(1, 2).$$
