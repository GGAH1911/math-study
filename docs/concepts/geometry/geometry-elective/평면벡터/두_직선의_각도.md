# 두 직선의 각도

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 직선의 방향벡터를 이용한 내적의 절댓값 비율을 통해 두 직선이 이루는 예각을 구하는 개념입니다.

## 본문
두 직선의 방향벡터를 각각 $\vec{u}$, $\vec{v}$라 할 때, 두 직선이 이루는 각 $\theta$ ($0 \le \theta \le \tfrac{\pi}{2}$)는 다음과 같이 정의합니다:
$$\cos \theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}| \cdot |\vec{v}|}$$
두 직선이 만날 때 발생하는 네 개의 각 중 예각(또는 직각)만을 정의하기 위해 분자에 절댓값을 사용하며, 이는 방향벡터를 어느 방향으로 선택하더라도 항상 동일한 각도를 얻게 하기 위함입니다.

### 직관과 기하적 의미
두 직선이 평면에서 교차하면 서로 마주 보는 각을 포함하여 총 네 개의 각이 생기는데, 수학적으로 '두 직선 사이의 각'은 이 중 예각을 의미합니다. 벡터의 내적 관점에서 보면, 내적의 값이 클수록 두 방향벡터가 가리키는 방향이 비슷하여 직선 사이의 각도가 작아지며, 내적이 $0$이면 두 직선은 서로 수직입니다. 또한, 기울기 $m_1, m_2$를 이용할 경우 $\tan \theta = \left|\tfrac{m_1-m_2}{1+m_1m_2}\right|$로 표현할 수 있으며, 분모가 $0$이 되는 $m_1 m_2 = -1$인 경우 두 직선은 수직입니다.

### 기본 성질
- 방향벡터의 크기와 관계없이 방향벡터의 방향만으로 각도를 결정할 수 있습니다.
- 두 직선이 평행하면 내적의 절댓값 비율이 $1$이 되어 $\theta = 0^\circ$가 됩니다.
- 두 직선이 수직이면 내적이 $0$이 되어 $\theta = 90^\circ$가 됩니다.

## 학습 체크
- 방향벡터에 절댓값을 취했을 때와 취하지 않았을 때의 결과 차이는 무엇인가요?
- 두 직선의 기울기만 알고 있을 때 각도를 구하는 공식은 무엇인가요?
- 두 직선이 평행하거나 수직일 때 벡터의 내적 값은 어떻게 나타나나요?

## 관련 개념
- **평면벡터**: 두 직선의 방향을 나타내는 벡터를 통해 직선 사이의 각도를 계산하는 도구로 사용됩니다.
