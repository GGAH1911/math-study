# 벡터의 일차결합

## 정확한 진술

평면벡터 $\vec{a}$, $\vec{b}$와 실수 $m$, $n$에 대하여 
$$m\vec{a} + n\vec{b}$$
의 형태로 나타낸 벡터를 $\vec{a}$, $\vec{b}$의 **일차결합**(linear combination)이라 합니다. 여기서 $m$, $n$을 **계수**(coefficients)라고 부릅니다.

일반적으로 벡터가 여럿일 때도, 세 벡터 $\vec{a}$, $\vec{b}$, $\vec{c}$의 일차결합은 $m\vec{a} + n\vec{b} + p\vec{c}$ (실수 $m, n, p$) 형태입니다.

## 직관적 의미

일차결합은 여러 벡터를 **스칼라배와 덧셈만으로 조합**하는 것입니다. 기하학적으로는:
- $m\vec{a}$: 벡터 $\vec{a}$를 $m$배 늘이거나 줄이거나 반대 방향으로 뒤집기
- $n\vec{b}$: 벡터 $\vec{b}$를 비슷하게 조정
- 둘을 더하기: 벡터 삼각형 법칙으로 합성

**핵심**은 평면 위의 모든 벡터를 적절한 일차결합으로 나타낼 수 있다는 점입니다. 만약 $\vec{a}$와 $\vec{b}$가 평행하지 않다면(즉, 선형독립이면), 평면의 **기저**(basis)를 이루어서 평면의 모든 벡터 $\vec{c}$를 어떤 계수 $m$, $n$에 대해 $\vec{c} = m\vec{a} + n\vec{b}$ 형태로 유일하게 표현할 수 있습니다. 이것이 좌표계의 기초가 됩니다.

## 예제

$\vec{a} = (1, 0)$, $\vec{b} = (0, 1)$일 때, $2\vec{a} + 3\vec{b} = (2, 0) + (0, 3) = (2, 3)$입니다.

더 일반적으로, $\vec{p} = (3, 5)$를 $\vec{a} = (1, 1)$과 $\vec{b} = (1, -1)$의 일차결합으로 나타내면: $m\vec{a} + n\vec{b} = (m+n, m-n) = (3, 5)$에서 $m = 4$, $n = -1$이므로 $\vec{p} = 4\vec{a} - \vec{b}$입니다. (검증: `sympy.solve([m + n - 3, m - n - 5], [m, n])` → $m = 4, n = -1$)
