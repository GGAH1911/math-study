# 벡터의 일차결합

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 개 이상의 벡터에 실수를 곱한 뒤 더하여 새로운 벡터를 만드는 것을 일차결합이라고 합니다.

## 본문
평면벡터 $\vec{a}$, $\vec{b}$와 실수 $m$, $n$에 대하여 $m\vec{a} + n\vec{b}$의 형태로 나타낸 벡터를 $\vec{a}$, $\vec{b}$의 일차결합이라 하며, 이때 실수 $m$, $n$을 계수라고 합니다. 벡터가 여러 개인 경우에도 동일한 원리가 적용되어, 세 벡터 $\vec{a}$, $\vec{b}$, $\vec{c}$의 일차결합은 $m\vec{a} + n\vec{b} + p\vec{c}$와 같은 형태로 나타낼 수 있습니다.

### 직관과 기하적 의미
일차결합은 여러 벡터를 스칼라배와 덧셈만으로 조합하는 과정입니다. 기하학적으로는 벡터 $\vec{a}$를 $m$배만큼 늘이거나 줄이고, 벡터 $\vec{b}$를 $n$배만큼 조정한 뒤, 두 벡터를 삼각형 법칙에 따라 합성하는 것과 같습니다. 만약 두 벡터 $\vec{a}$와 $\vec{b}$가 서로 평행하지 않다면, 이들은 평면의 기저를 이루어 평면 위의 임의의 벡터 $\vec{c}$를 $\vec{c} = m\vec{a} + n\vec{b}$와 같이 유일한 계수 $m, n$을 사용하여 표현할 수 있게 합니다. 이는 좌표계가 형성되는 근본적인 원리가 됩니다.

### 기본 성질
- 예제 1: $\vec{a} = (1, 0)$, $\vec{b} = (0, 1)$일 때, $2\vec{a} + 3\vec{b} = (2, 3)$입니다.
- 예제 2: $\vec{p} = (3, 5)$를 $\vec{a} = (1, 1)$과 $\vec{b} = (1, -1)$의 일차결합으로 나타내면 $\vec{p} = 4\vec{a} - \vec{b}$입니다.

## 학습 체크
- 벡터의 일차결합에서 계수는 어떤 수의 범위를 가져야 하는가?
- 두 벡터가 평행할 때, 평면 위의 모든 벡터를 일차결합으로 유일하게 나타낼 수 있는가?
- 주어진 벡터를 특정 벡터들의 일차결합으로 나타내기 위한 계수 $m, n$을 어떻게 구할 것인가?

## 관련 개념
- **평면벡터**: 평면 위의 점을 나타내거나 방향과 크기를 가진 양을 나타내며, 일차결합을 통해 평면 전체를 구성하는 기초가 됩니다.
