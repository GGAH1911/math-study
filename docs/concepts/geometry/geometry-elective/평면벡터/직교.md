# 직교

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 평면벡터의 내적이 $0$이면 두 벡터는 서로 직교합니다.

## 본문
두 평면벡터 $\vec{a}$와 $\vec{b}$가 **직교(orthogonal)**한다는 것은 두 벡터의 내적이 $0$임을 의미합니다. 즉, $\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = 0$을 만족해야 합니다. 만약 두 벡터가 모두 영벡터가 아니라면, $\cos\theta = 0$이어야 하므로 두 벡터가 이루는 각 $\theta$는 $90^\circ$가 됩니다. 이를 성분으로 나타내면 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$일 때 $a_1b_1 + a_2b_2 = 0$인 상태를 말합니다.

### 직관과 기하적 의미
기하학적으로 직교는 두 벡터가 서로 수직임을 의미합니다. 원점을 시점으로 하는 두 화살표가 정확히 $90^\circ$의 각도를 이루는 상태를 말하며, 내적의 정의에 따라 각도가 직각이면 코사인 값이 $0$이 되어 내적 값이 $0$이 됩니다. 이러한 성질은 삼각형의 높이 구하기, 원의 접선과 반지름의 수직 관계, 좌표축 사이의 관계 등을 수식으로 표현할 때 매우 유용하게 사용됩니다.

### 기본 성질
- 두 벡터가 영벡터가 아닐 때, $\vec{a} \cdot \vec{b} = 0$이면 $\vec{a} \perp \vec{b}$입니다.
- 성분으로 표현된 두 벡터의 내적 합이 $0$이면 두 벡터는 수직입니다.

## 학습 체크
- 두 벡터 중 하나가 영벡터인 경우에도 내적이 $0$이 되어 직교한다고 볼 수 있는가?
- 성분으로 주어진 두 벡터가 수직임을 확인하기 위해 어떤 계산 과정을 거쳐야 하는가?

## 관련 개념
- **평면벡터**: 벡터의 내적을 통해 두 벡터 사이의 각도와 수직 여부를 판별할 수 있습니다.
