# 계수 결정

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 벡터가 평행하지 않을 때, 임의의 벡터를 두 벡터의 선형 결합으로 나타내는 과정에서 각 벡터의 계수를 구하는 것입니다.

## 본문
두 벡터 $\vec{a}$, $\vec{b}$가 평행하지 않을 때, 즉 일차독립일 때, 평면 위의 모든 벡터 $\vec{c}$는 $\vec{c} = m\vec{a} + n\vec{b}$ 꼴로 유일하게 표현됩니다. 이때 계수 결정이란 주어진 벡터 $\vec{c}$를 이 형태로 나타냈을 때, 각 벡터 앞에 붙는 계수 $m$과 $n$의 값을 구하는 과정을 의미합니다.

### 직관과 기하적 의미
평면 위에 서로 다른 두 방향을 나타내는 벡터 $\vec{a}$, $\vec{b}$를 기준 축으로 생각하면 이해가 쉽습니다. 어떤 목표 지점 $\vec{c}$에 도달하기 위해 $\vec{a}$ 방향으로 몇 칸, $\vec{b}$ 방향으로 몇 칸을 이동해야 하는지를 찾는 것이 바로 계수 결정입니다. 즉, 기준이 되는 두 벡터를 사용하여 목표 벡터를 구성하는 '이동량'을 찾는 과정입니다.

### 기본 성질
좌표평면에서 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$, $\vec{c} = (c_1, c_2)$로 주어졌을 때, $m\vec{a} + n\vec{b} = \vec{c}$를 성분별로 분리하면 다음과 같은 연립방정식을 얻습니다.
$$\begin{cases} m a_1 + n b_1 = c_1 \\ m a_2 + n b_2 = c_2 \end{cases}$$
이 연립방정식의 해를 구하면 계수 $m$과 $n$을 결정할 수 있습니다. 예를 들어 $\vec{a} = (2, 1)$, $\vec{b} = (1, 2)$, $\vec{c} = (5, 5)$인 경우, $2m + n = 5$와 $m + 2n = 5$를 풀어 $m = 5/3$, $n = 5/3$이라는 결과를 얻습니다.

## 학습 체크
- 두 벡터 $\vec{a}$와 $\vec{b}$가 평행할 때도 계수를 유일하게 결정할 수 있는가?
- 벡터의 성분을 이용해 계수를 구할 때, 연립방정식의 해가 존재하지 않거나 무수히 많은 경우는 어떤 상황인가?

## 관련 개념
- **평면벡터**: 평면 위의 점을 나타내거나 방향과 크기를 가진 양을 나타내며, 계수 결정의 대상이 되는 벡터들이 존재하는 공간을 정의합니다.
