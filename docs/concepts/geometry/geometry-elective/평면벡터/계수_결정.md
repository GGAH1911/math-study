# 계수 결정

## 정확한 진술

두 벡터 $\vec{a}$, $\vec{b}$가 평행하지 않을 때(즉, 일차독립일 때), 평면의 모든 벡터는 $\vec{c} = m\vec{a} + n\vec{b}$ 꼴로 유일하게 표현됩니다. **계수 결정**이란 주어진 벡터 $\vec{c}$를 이 형태로 나타냈을 때, 계수 $m$과 $n$의 값을 구하는 과정입니다.

## 직관과 기하적 의미

평면 위에 서로 다른 두 방향을 나타내는 벡터 $\vec{a}$, $\vec{b}$를 기준 축으로 생각해 보세요. 어떤 목표 지점 $\vec{c}$에 도달하려면, $\vec{a}$ 방향으로 몇 칸, $\vec{b}$ 방향으로 몇 칸을 가야 할까요? 그 '몇 칸'이 바로 계수 $m$, $n$입니다. 계수 결정은 이 질문에 답하는 것입니다.

## 풀이 방법

좌표로 주어진 경우, $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$, $\vec{c} = (c_1, c_2)$라 하면:

$$m\vec{a} + n\vec{b} = \vec{c}$$

를 성분별로 풀면:

$$\begin{cases} m a_1 + n b_1 = c_1 \\ m a_2 + n b_2 = c_2 \end{cases}$$

이 연립방정식을 $m$, $n$에 대해 풀면 계수를 구할 수 있습니다.

## 한 줄 예

$\vec{a} = (1, 0)$, $\vec{b} = (0, 1)$, $\vec{c} = (3, 2)$일 때, $m = 3$, $n = 2$입니다.

일반적인 경우: $\vec{a} = (2, 1)$, $\vec{b} = (1, 2)$, $\vec{c} = (5, 5)$라 하면, $2m + n = 5$, $m + 2n = 5$를 풀어 $m = 5/3$, $n = 5/3$을 얻습니다. (`sympy.solve([2*m + n - 5, m + 2*n - 5], [m, n])` → `{m: 5/3, n: 5/3}`)
