# 점의 궤적

## 정확한 진술

점의 궤적은 **주어진 조건을 만족하는 모든 점들의 집합**입니다. 어떤 기하학적 조건(거리, 각도, 관계식 등)을 만족하는 점 $P(x, y)$의 집합을 좌표평면에 나타내면, 일반적으로 곡선이나 도형이 됩니다. 이 곡선의 방정식을 구하는 것이 "점의 궤적을 구한다"는 의미입니다.

## 직관과 기하적 의미

궤적은 **"어떤 조건이 점들을 모아 어떤 모양을 만드는가"**를 보여줍니다. 평면벡터에서 점의 위치를 위치벡터 $\vec{OP}$로 나타낼 때, 조건을 벡터 관계식으로 표현하면 자연스럽게 궤적을 찾을 수 있습니다.

예를 들어:
- 원점으로부터 거리가 3 → 반지름 3인 원
- 두 점 $A$, $B$로부터 같은 거리 → 선분 $AB$의 수직이등분선
- 초점 $F_1$, $F_2$로부터 거리의 합이 일정 → 타원

## 풀이 방법

궤적을 구하는 기본 절차:
1. 조건을 만족하는 점 $P(x, y)$를 임의로 설정
2. 주어진 조건을 $x$, $y$의 식으로 표현
3. 정리하여 방정식 획득

## 예: 두 점으로부터 등거리의 점

$A(1, 0)$, $B(-1, 0)$으로부터 같은 거리에 있는 점 $P(x, y)$의 궤적:

$$\sqrt{(x-1)^2 + y^2} = \sqrt{(x+1)^2 + y^2}$$

양변을 제곱하고 정리하면:
$$(x-1)^2 + y^2 = (x+1)^2 + y^2$$
$$-4x = 0 \Rightarrow x = 0$$

궤적은 **$y$축**(직선 $x = 0$)입니다. 이것이 선분 $AB$의 수직이등분선입니다.

(`sympy.solve([(x-1)**2 + y**2 - ((x+1)**2 + y**2)], x)` → $x=0$)
