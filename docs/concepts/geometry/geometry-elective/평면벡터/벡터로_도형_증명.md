# 벡터로 도형 증명

> **예제** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
삼각형의 무게중심의 위치벡터가 세 꼭짓점 위치벡터의 산술평균임을 벡터 연산으로 증명합니다.

## 본문
삼각형 $ABC$의 꼭짓점 $A, B, C$의 위치벡터를 각각 $\vec{a}, \vec{b}, \vec{c}$라 하자. $BC$의 중점을 $M$이라 하고, 중선 $AM$ 위의 점 $G$가 $A$로부터 $M$ 방향으로 $2:1$로 내분하는 점일 때, $G$의 위치벡터가 $\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$임을 벡터 계산으로 증명하시오.

### 단계별 풀이
**1단계: 중점 $M$의 위치벡터 구하기**
중점의 위치벡터는 두 끝점 위치벡터의 산술평균입니다. $BC$의 중점 $M$은 다음과 같습니다.
$$\vec{m} = \frac{\vec{b} + \vec{c}}{2}$$

**2단계: 내분점 공식 적용하기**
점 $G$가 선분 $AM$을 $2:1$로 내분한다는 것은 $AG:GM = 2:1$임을 의미합니다. 내분점 공식에 따라 $G$의 위치벡터는 다음과 같습니다.
$$\vec{g} = \frac{1 \cdot \vec{a} + 2 \cdot \vec{m}}{2 + 1} = \frac{\vec{a} + 2\vec{m}}{3}$$

**3단계: $M$의 위치벡터를 대입하여 정리하기**
위 식에 $\vec{m} = \frac{\vec{b} + \vec{c}}{2}$를 대입하여 정리하면 최종 결과를 얻습니다.
$$\vec{g} = \frac{\vec{a} + 2 \cdot \frac{\vec{b} + \vec{c}}{2}}{3} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$

### 답과 변형
$$\vec{g} = \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$
점 $G$는 삼각형 $ABC$의 무게중심입니다. 무게중심의 위치벡터는 세 꼭짓점 위치벡터의 산술평균이라는 성질을 가집니다. 예를 들어 $A(0, 0), B(2, 0), C(0, 2)$인 경우, 무게중심 $G$의 좌표는 $\left(\frac{2}{3}, \frac{2}{3}\right)$가 됩니다.

- **대칭성**: $CA$의 중점이나 $AB$의 중점을 통해 다른 중선을 그어도 모두 같은 점 $G$를 지나며, 이는 무게중심의 유일성을 나타냅니다.
- **수능 응용**: 좌표계에서 구체적인 점의 좌표가 주어질 때, 이 공식을 활용하면 무게중심을 매우 빠르게 구할 수 있습니다.

## 학습 체크
- 중점의 위치벡터와 내분점 공식을 정확히 적용할 수 있는가?
- 무게중심의 위치벡터가 세 꼭짓점의 평균이라는 성질을 유도할 수 있는가?
- 주어진 좌표를 바탕으로 무게중심의 좌표를 계산할 수 있는가?

## 관련 개념
- **평면벡터**: 벡터의 연산과 내분점 공식을 이용하여 도형의 기하학적 성질을 대수적으로 증명하는 기초가 됩니다.
