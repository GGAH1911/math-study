# 법선벡터

## 정확한 진술

평면의 방정식 $ax + by + cz = d$ (또는 2차원 직선 $ax + by = c$)에 대해, 벡터 $(a, b, c)$ (또는 $(a, b)$)를 그 평면(직선)의 **법선벡터(normal vector)**라고 합니다. 법선벡터는 평면 또는 곡선에 수직입로, 기울기나 방향을 정의하는 핵심 요소입니다.

## 직관과 기하적 의미

법선벡터는 평면 위의 모든 점에서 그 평면 밖으로 수직으로 "튀어나오는" 방향을 가리킵니다. 예를 들어, 종이에 그은 직선에 연필을 수직으로 세우면 그 연필의 방향이 바로 법선벡터의 방향입니다. 평면의 방정식을 $ax + by + cz = d$ 형태로 쓸 수 있는 이유도 법선벡터 $(a, b, c)$에 수직인 모든 점들의 집합이기 때문입니다.

## 관계식과 한 줄 예제

직선 $2x - 3y = 5$의 법선벡터는 $(2, -3)$입니다. 이 벡터는 직선에 수직이므로, 직선을 향해 움직이는 가장 빠른 경사 방향을 나타냅니다.

평면 $x + 2y + 3z = 10$의 법선벡터는 $(1, 2, 3)$이고, 이 벡터의 크기는 $\sqrt{1^2 + 2^2 + 3^2} = \sqrt{14}$입니다. 정규화(단위 법선벡터)하려면 각 성분을 $\sqrt{14}$로 나누면 됩니다.

## 실용적 활용

법선벡터는 점에서 평면까지의 거리를 구하거나, 두 평면이 이루는 각을 계산할 때 중요합니다. 점 $(x_0, y_0, z_0)$과 평면 $ax + by + cz = d$ 사이의 거리는 다음 공식으로 구합니다:

$$\text{거리} = \frac{|ax_0 + by_0 + cz_0 - d|}{\sqrt{a^2 + b^2 + c^2}}$$

분모가 바로 법선벡터의 크기(norm)입니다. 이는 법선 방향으로 얼마나 떨어져 있는지를 측정하는 것입니다.
