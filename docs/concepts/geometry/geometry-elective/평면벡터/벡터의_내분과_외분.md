# 벡터의 내분과 외분

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
선분을 일정 비율로 나누는 내분점과 외분점의 위치벡터를 구하는 방법입니다.

## 본문
선분 $AB$를 $m:n$ ($m, n > 0$)으로 내분하는 점 $P$는 선분 $AB$ 위에 있으면서 $\overrightarrow{AP} : \overrightarrow{PB} = m : n$을 만족하는 점이며, 위치벡터는 $\vec{OP} = \frac{n\vec{OA} + m\vec{OB}}{m+n}$입니다. 선분 $AB$를 $m:n$ ($m \neq n$)으로 외분하는 점 $Q$는 선분 $AB$의 연장선 위에 있으면서 $\overrightarrow{AQ} : \overrightarrow{QB} = m : n$을 만족하는 점이며, 위치벡터는 $\vec{OQ} = \frac{-n\vec{OA} + m\vec{OB}}{m-n}$입니다.

### 직관과 기하적 의미
내분점은 선분을 두 부분으로 분할하는 지점으로, 벡터 공식에서 계수의 합이 $m+n$인 것은 두 끝점의 위치에 가중치를 부여하기 때문입니다. 이때 비중이 큰 쪽의 점에 더 큰 가중치가 부여됩니다. 외분점은 선분을 한쪽 방향으로 연장했을 때 나타나는 지점입니다. 공식에서 계수에 음수가 포함되는 이유는 외분점이 선분의 외부(반대편)에 위치하기 때문이며, $m > n$이면 점 $B$ 너머에, $m < n$이면 점 $A$ 너머에 위치하게 됩니다.

### 기본 성질
- 내분점의 경우 $m=n$이면 선분의 중점이 됩니다.
- 외분점은 $m$과 $n$의 크기 비교에 따라 위치하는 방향이 결정됩니다.
- 내분점 공식은 분모가 양수이고, 외분점 공식은 분모가 $m-n$이므로 $m \neq n$이어야 합니다.

## 학습 체크
- 내분점 공식에서 분자의 계수 $n$과 $m$이 서로 뒤바뀌지 않았는지 확인했는가?
- 외분점의 위치가 $m > n$일 때 $B$ 쪽인지, $m < n$일 때 $A$ 쪽인지 구분할 수 있는가?

## 관련 개념
- **평면벡터**: 벡터의 연산과 위치벡터의 개념을 바탕으로 선분 위의 점을 좌표로 나타냅니다.
