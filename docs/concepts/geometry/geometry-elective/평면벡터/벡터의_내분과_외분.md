# 벡터의 내분과 외분

## 정확한 진술

선분 $AB$를 $m:n$ ($m, n > 0$)으로 **내분하는 점** $P$는 선분 $AB$ 위에 있으면서 $\overrightarrow{AP} : \overrightarrow{PB} = m : n$을 만족하는 점입니다. 이때 위치벡터로는:

$$\vec{OP} = \frac{n\vec{OA} + m\vec{OB}}{m+n}$$

선분 $AB$를 $m:n$ ($m \neq n$)으로 **외분하는 점** $Q$는 선분 $AB$의 연장선 위에 있으면서 $\overrightarrow{AQ} : \overrightarrow{QB} = m : n$을 만족하는 점입니다 (단, 두 벡터의 방향이 반대). 이때 위치벡터로는:

$$\vec{OQ} = \frac{-n\vec{OA} + m\vec{OB}}{m-n}$$

## 직관과 기하적 의미

내분점은 '선분 위의 분할 지점'입니다. 예를 들어 1:1로 내분하면 중점이 되고, 선분을 두 부분으로 나눕니다. 벡터 공식에서 계수의 합이 $m+n$인 이유는, 두 끝점의 위치에 '가중치'를 주기 때문입니다. 가까운 쪽 점에 더 큰 가중치를 줍니다.

외분점은 '선분 바깥의 연장 지점'입니다. 선분을 한쪽으로 연장했을 때, 주어진 비를 만족하는 점입니다. 공식에서 계수가 음수인 이유는, 외분점이 선분의 반대편에 있기 때문입니다. $m > n$일 때는 $B$ 너머에, $m < n$일 때는 $A$ 너머에 위치합니다.

## 한 줄 예

$A(0, 0)$, $B(3, 0)$일 때, 선분 $AB$를 $2:1$로 내분하는 점 $P$는 $P(2, 0)$이고, $2:1$로 외분하는 점 $Q$는 $Q(6, 0)$입니다.

**확인:** 내분점 $P = \frac{1 \cdot A + 2 \cdot B}{2+1} = \frac{(0,0) + (6,0)}{3} = (2,0)$ ✓  
외분점 $Q = \frac{-1 \cdot A + 2 \cdot B}{2-1} = \frac{(0,0) + (6,0)}{1} = (6,0)$ ✓
