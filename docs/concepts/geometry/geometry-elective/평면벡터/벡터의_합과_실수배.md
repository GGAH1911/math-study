# 벡터의 합과 실수배

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
벡터의 합은 삼각형 법칙과 평행사변형 법칙으로 정의되며, 실수배는 벡터의 방향은 유지한 채 크기를 조절하는 연산입니다.

## 본문
두 벡터 $\vec{a}$, $\vec{b}$의 **합** $\vec{a} + \vec{b}$는 $\vec{a}$의 시점을 $O$, 종점을 $A$라 하고 $\vec{b}$의 시점을 $A$로 옮겨 그 종점을 $B$라 할 때, $\overrightarrow{OB}$로 정의하며 이를 **삼각형 법칙**이라 합니다. 벡터 $\vec{a}$와 실수 $k$에 대한 **실수배** $k\vec{a}$는 $k > 0$이면 $\vec{a}$와 같은 방향으로 크기가 $|k||\vec{a}|$인 벡터, $k < 0$이면 $\vec{a}$와 반대 방향으로 크기가 $|k||\vec{a}|$인 벡터, $k = 0$이면 영벡터 $\vec{0}$을 의미합니다.

### 직관과 기하적 의미
벡터의 합은 두 벡터를 인접한 두 변으로 하는 평행사변형을 그렸을 때 그 대각선으로 나타내는 **평행사변형 법칙**으로 이해할 수 있습니다. 이를 통해 벡터 합의 교환법칙 $\vec{a} + \vec{b} = \vec{b} + \vec{a}$를 시각적으로 확인할 수 있습니다. 실수배는 벡터의 방향은 유지하면서 크기를 조절하는 연산입니다. 예를 들어 $2\vec{a}$는 크기를 2배로 늘린 벡터이고, $-\vec{a}$는 방향이 반대인 벡터입니다. 이를 통해 서로 평행한 벡터들의 관계를 간결하게 표현할 수 있습니다.

### 기본 성질
벡터의 합과 실수배는 다음과 같은 연산 성질을 만족합니다.
- 결합법칙: $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$
- 분배법칙: $k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$, $(k + m)\vec{a} = k\vec{a} + m\vec{a}$
이러한 성질들은 벡터를 좌표 성분으로 나타냈을 때 각 성분별 연산과 일치하여 성립합니다.

## 학습 체크
- 삼각형 법칙과 평행사변형 법칙을 이용해 벡터의 합을 기하학적으로 그릴 수 있는가?
- 실수 $k$의 부호에 따른 벡터의 방향 변화를 정확히 이해하고 있는가?
- 벡터의 연산 성질을 활용하여 복잡한 식을 단순화할 수 있는가?

## 관련 개념
- **평면벡터**: 벡터의 합과 실수배를 통해 평면 위에서 두 점을 잇는 선분이나 평행한 직선의 관계를 정의하는 기초가 됩니다.
