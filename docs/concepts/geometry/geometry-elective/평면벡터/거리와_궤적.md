### 정확한 진술

평면 위의 점 $P(x, y)$가 주어진 거리 조건을 만족할 때, 이를 충족하는 모든 점들의 집합을 **궤적(자취, locus)**이라 합니다. 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음과 같이 정의됩니다.

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

특정 거리 조건을 식으로 나타내면 궤적의 방정식을 얻으며, 이는 평면 위의 특정 도형(원, 타원, 쌍곡선 등)을 나타냅니다.

### 직관과 기하적 의미

거리 조건은 공간에서 특정 성질을 가진 점들을 "찾는" 과정입니다. 예를 들어:
- **한 점으로부터 일정 거리**: 점 $F$로부터 거리가 $r$인 모든 점들은 중심 $F$, 반지름 $r$인 **원**을 그립니다.
- **두 점으로부터 거리의 합이 일정**: 두 점 $F_1, F_2$로부터 거리의 합이 $2a$인 점들은 **타원**을 이룹니다.
- **두 점으로부터 거리의 차가 일정**: 거리의 차가 $2a$인 점들은 **쌍곡선**을 이룹니다.

이는 기하의 대수화입니다. 주어진 거리 조건(기하학적 성질) → 방정식(대수식) → 곡선(도형)의 흐름으로, 기하 문제를 체계적으로 풀 수 있게 합니다. 벡터의 크기 $|\vec{AP}|$를 이용하면 더욱 간결하게 표현 가능합니다.

### 한 줄 예

점 $A(1, 2)$로부터 거리가 $3$인 점 $P(x, y)$의 궤적은 $(x-1)^2 + (y-2)^2 = 9$ (중심 $A$, 반지름 $3$인 원)입니다.

검산: `sympy.solve((x-1)**2 + (y-2)**2 - 9, y)`로 특정 $x$값에 대한 $y$를 구할 수 있습니다.
