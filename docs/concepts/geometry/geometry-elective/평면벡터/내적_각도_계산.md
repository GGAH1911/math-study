# 내적 각도 계산

> **예제** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 벡터 사이 각

## 본문 (학습 시 채워짐)

### 문제

$\vec{a} = (1, 0)$, $\vec{b} = (1, 1)$일 때, 두 벡터 사이의 각 $\theta$를 구하시오. (단, $0 \leq \theta \leq \pi$)

### 단계별 풀이

**1단계: 내적 계산** — 벡터의 내적 정의에 따라 대응하는 성분끼리 곱한 후 더합니다.
$$\vec{a} \cdot \vec{b} = 1 \cdot 1 + 0 \cdot 1 = 1$$

**2단계: 각 벡터의 크기 구하기** — 내적 공식 $\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$를 사용하려면 분모의 크기들이 필요합니다.
$$|\vec{a}| = \sqrt{1^2 + 0^2} = 1, \quad |\vec{b}| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

**3단계: $\cos \theta$ 계산** — 내적 공식에 대입하여 코사인 값을 구합니다.
$$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \frac{1}{1 \cdot \sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

**4단계: 각도 결정** — 코사인 값이 $\frac{\sqrt{2}}{2}$인 각을 찾습니다. $0 \leq \theta \leq \pi$ 범위에서 유일합니다.
$$\theta = \frac{\pi}{4} \text{ (또는 } 45°\text{)}$$

### 답

$$\theta = \frac{\pi}{4}$$

**검증** (sympy): `a = [1, 0]; b = [1, 1]; cos_theta = 1 / (1 * sqrt(2)); acos(cos_theta) = π/4` ✓

### 변형·주의

**두 벡터가 예각인 경우:** $\vec{a} \cdot \vec{b} > 0$이면 $\cos \theta > 0$이므로 $0 < \theta < \frac{\pi}{2}$ (예각)입니다.

**둔각 판정:** 만약 $\vec{a} = (1, 0)$, $\vec{b} = (-1, 1)$이면 $\vec{a} \cdot \vec{b} = -1 < 0$이므로 $\frac{\pi}{2} < \theta < \pi$ (둔각)입니다. 내적 부호로 각의 종류를 빠르게 판단할 수 있습니다.
