# 내적 각도 계산

> **예제** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 벡터 사이의 각은 벡터의 내적과 각 벡터의 크기를 이용하여 코사인 값을 구함으로써 구할 수 있습니다.

## 본문
$\vec{a} = (1, 0)$, $\vec{b} = (1, 1)$일 때, 두 벡터 사이의 각 $\theta$를 구하시오. (단, $0 \leq \theta \leq \pi$)

### 단계별 풀이
**1단계: 내적 계산**
벡터의 내적 정의에 따라 대응하는 성분끼리 곱한 후 더합니다.
$$\vec{a} \cdot \vec{b} = 1 \cdot 1 + 0 \cdot 1 = 1$$

**2단계: 각 벡터의 크기 구하기**
내적 공식 $\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$을 사용하기 위해 각 벡터의 크기를 구합니다.
$$|\vec{a}| = \sqrt{1^2 + 0^2} = 1, \quad |\vec{b}| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

**3단계: $\cos \theta$ 계산**
내적 공식에 대입하여 코사인 값을 구합니다.
$$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \frac{1}{1 \cdot \sqrt{2}} = \frac{\sqrt{2}}{2}$$

**4단계: 각도 결정**
$0 \leq \theta \leq \pi$ 범위에서 $\cos \theta = \frac{\sqrt{2}}{2}$를 만족하는 각을 찾습니다.
$$\theta = \frac{\pi}{4}$$

### 답과 변형
**답**
$$\theta = \frac{\pi}{4}$$

**변형 및 주의사항**
두 벡터의 내적 값이 양수이면 $\cos \theta > 0$이므로 두 벡터 사이의 각은 예각($0 < \theta < \frac{\pi}{2}$)입니다. 반대로 내적 값이 음수이면 $\cos \theta < 0$이므로 두 벡터 사이의 각은 둔각($\frac{\pi}{2} < \theta < \pi$)이 됩니다. 예를 들어 $\vec{a} = (1, 0)$, $\vec{b} = (-1, 1)$인 경우 내적 값이 $-1$이므로 둔각이 형성됩니다.

## 학습 체크
- 내적의 결과값 부호를 보고 두 벡터가 이루는 각이 예각인지 둔각인지 즉각 판별할 수 있는가?
- 코사인 공식의 분모에 들어가는 각 벡터의 크기를 정확히 계산할 수 있는가?

## 관련 개념
- **평면벡터**: 벡터의 성분을 이용하여 내적을 계산하고 이를 통해 기하학적 각도를 도출하는 기초가 됩니다.
