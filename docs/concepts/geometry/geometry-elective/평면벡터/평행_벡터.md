# 평행 벡터

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
두 영벡터가 아닌 벡터 $\vec{a}$와 $\vec{b}$가 $\vec{b} = k\vec{a}$ ($k \neq 0$)를 만족할 때, 두 벡터는 평행하다고 합니다.

## 본문
두 영벡터가 아닌 벡터 $\vec{a}$와 $\vec{b}$가 평행하다는 것은, $0$이 아닌 실수 $k$가 존재하여 $\vec{b} = k\vec{a}$를 만족함을 의미하며, 이를 기호로 $\vec{a} \parallel \vec{b}$와 같이 나타냅니다. 이때 실수 $k$의 부호에 따라 방향이 결정되는데, $k > 0$이면 두 벡터는 같은 방향을 향하고 $k < 0$이면 서로 반대 방향을 향합니다.

### 직관과 기하적 의미
기하학적으로 평행 벡터는 같은 직선 위에 있거나 서로 평행한 직선 위에 놓인 방향을 의미합니다. 두 벡터의 크기는 서로 다를 수 있지만, 한 벡터가 다른 벡터의 상수배로 표현된다는 점에서 방향의 일치성 또는 반대성을 가집니다. 좌표평면 상에서 두 벡터의 성분은 항상 일정한 비율을 유지하며, 이는 두 벡터가 이루는 면적이나 외적의 값이 $0$임을 시사합니다.

### 기본 성질
두 벡터 $\vec{a} = (a_1, a_2)$와 $\vec{b} = (b_1, b_2)$가 평행하기 위한 필요충분조건은 $a_1 b_2 - a_2 b_1 = 0$입니다. 만약 두 벡터의 성분이 $0$이 아니라면 $\frac{b_1}{a_1} = \frac{b_2}{a_2}$라는 비율 관계를 통해서도 평행 여부를 판정할 수 있습니다. 예를 들어 $\vec{a} = (1, 2)$이고 $\vec{b} = (3, 6)$이면 $\vec{b} = 3\vec{a}$이므로 같은 방향의 평행 벡터이며, $\vec{c} = (-4, -6)$이면 $\vec{c} = -2\vec{a}$이므로 반대 방향의 평행 벡터입니다.

## 학습 체크
- $k$의 부호에 따라 두 벡터의 방향이 어떻게 달라지는가?
- 두 벡터의 성분 좌표를 이용하여 평행 여부를 판정하는 식은 무엇인가?
- 영벡터가 포함된 경우에도 위 정의를 그대로 적용할 수 있는가?

## 관련 개념
- **평면벡터**: 좌표평면 위에서 화살표로 나타나는 벡터로, 평행 벡터의 성분비와 기하적 성질을 다루는 기초가 됩니다.
