# 직선의 법선 벡터

> **정의** · 기하 · 단원: [평면벡터](/concepts/평면벡터)

## 요약
직선에 수직인 방향을 나타내는 벡터로, 직선의 방정식 계수를 통해 쉽게 구할 수 있습니다.

## 본문
평면 위의 직선에 대해 법선 벡터는 그 직선에 수직인 방향을 나타내는 벡터를 의미합니다. 직선의 방정식이 $ax + by + c = 0$의 형태일 때, 이 직선의 법선 벡터는 $\vec{n} = (a, b)$입니다. 법선 벡터는 유일하게 결정되지 않으며, 영벡터가 아닌 임의의 실수 $k$에 대하여 $k\vec{n}$ ($k \neq 0$) 또한 동일한 직선의 법선 벡터가 됩니다.

### 직관과 기하적 의미
직선을 하나의 장벽이라고 가정했을 때, 법선 벡터는 그 장벽을 수직으로 뚫고 나가는 방향과 같습니다. 직선 위의 임의의 점에서 법선 벡터를 그리면 항상 직선과 직교하는 방향으로 튀어나오게 됩니다. 직선의 방정식 $ax + by + c = 0$에서 계수 $a$와 $b$가 법선 벡터의 성분이 되는 이유는, 이 식이 점 $(x, y)$와 벡터 $(a, b)$의 내적이 상수값을 유지한다는 의미를 담고 있기 때문입니다. 즉, 직선 위의 모든 점은 법선 벡터와 수직 관계를 형성합니다.

### 기본 성질
- 직선 $2x - 3y + 5 = 0$의 법선 벡터는 $\vec{n} = (2, -3)$입니다. 이 벡터의 길이를 $1$로 정규화하면 $\frac{1}{\sqrt{13}}(2, -3)$이 되며, 이는 직선으로부터의 거리를 구할 때 방향 지표로 활용됩니다.
- 점 $(1, 2)$를 지나고 법선 벡터가 $(3, 4)$인 직선의 방정식은 $3(x-1) + 4(y-2) = 0$, 즉 $3x + 4y - 11 = 0$으로 나타낼 수 있습니다.

## 학습 체크
- 직선의 방정식 $ax + by + c = 0$에서 계수 $a, b$가 왜 법선 벡터의 성분이 되는지 내적의 관점에서 설명할 수 있는가?
- 주어진 법선 벡터와 한 점이 주어졌을 때, 직선의 방정식을 유도할 수 있는가?

## 관련 개념
- **도형의 방정식**: 법선 벡터를 이용하면 직선의 방정식을 벡터의 내적을 활용한 형태로 간결하게 표현할 수 있습니다.
