# 벡터 방정식

## 정확한 진술

곡선 위의 임의의 점 $P$의 위치벡터를 매개변수 $t$로 나타낸 방정식을 **벡터 방정식**이라 합니다. 

$$\vec{r}(t) = \vec{r}_0 + t\vec{d}$$

여기서 $\vec{r}_0$는 출발점, $\vec{d}$는 방향벡터, $t$는 매개변수입니다. 평면에서는 성분 표현으로

$$\vec{r}(t) = (x_0 + at, y_0 + bt)$$

또는 $x = x_0 + at$, $y = y_0 + bt$ (매개변수 방정식)로도 나타냅니다.

## 직관/기하적 의미

벡터 방정식은 **동적으로 점이 움직이는 궤적**을 기술합니다. $t$를 시간으로 생각하면, $\vec{r}(t)$의 끝점이 그리는 자취가 곡선 전체입니다. 

고정된 점 $\vec{r}_0$에서 출발해 방향벡터 $\vec{d}$ 방향으로 진행하는 물체의 경로를 나타낸다고 이해하면 직관적입니다. 직선은 가장 단순한 경우로, 벡터의 합($\vec{r}_0 + t\vec{d}$)으로 원점에서의 거리와 방향을 동시에 표현합니다.

## 한 줄 예

$\vec{r}(t) = (1, 2) + t(2, -1)$은 점 $(1, 2)$를 지나고 방향벡터가 $(2, -1)$인 직선의 벡터 방정식입니다. 

$t = 0$일 때 점 $(1, 2)$, $t = 1$일 때 점 $(3, 1)$, $t = -1$일 때 점 $(-1, 3)$을 지나갑니다. 일반 형태로는 $x - 1 = \frac{y - 2}{-1}$, 즉 $x + 2y - 5 = 0$입니다.
