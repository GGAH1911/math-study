### 정확한 진술

평면 위의 두 개의 고정된 점을 **초점**(focus)이라 하고, 이 두 초점으로부터의 거리 차의 절댓값이 일정한 점들의 자취를 **쌍곡선**(hyperbola)이라고 합니다.

두 초점을 $F_1(-c, 0)$, $F_2(c, 0)$ (단, $c > 0$)이라 하고, 초점으로부터의 거리 차의 절댓값이 $2a$ (단, $0 < a < c$)라 하면, 쌍곡선 위의 임의의 점 $P(x, y)$에 대해

$$||PF_1| - |PF_2|| = 2a$$

가 성립합니다.

### 직관과 기하적 의미

쌍곡선은 타원과 유사하게 정의되지만, 결정적인 차이가 있습니다. 타원은 두 초점으로부터의 거리의 **합**이 일정한 점들의 자취인 반면, 쌍곡선은 거리의 **차**의 절댓값이 일정합니다. 이로 인해 쌍곡선은 **두 개의 분지**(branch)로 이루어집니다.

- 한 분지: $|PF_1| - |PF_2| = 2a$ (점 $F_2$에 더 가까운 점들)
- 다른 분지: $|PF_2| - |PF_1| = 2a$ (점 $F_1$에 더 가까운 점들)

초점이 $x$축 위에 있을 때의 **표준형**은 다음과 같습니다.

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a > 0, \, b > 0, \, c^2 = a^2 + b^2)$$

이 식에서 $a$는 꼭짓점까지의 거리, $c$는 초점까지의 거리를 나타냅니다.

### 한 줄 예

두 초점이 $F_1(-5, 0)$, $F_2(5, 0)$이고 거리 차의 절댓값이 $6$인 쌍곡선의 방정식은 $\frac{x^2}{9} - \frac{y^2}{16} = 1$입니다. ($a=3$, $c=5$에서 $b^2 = c^2 - a^2 = 16$)
