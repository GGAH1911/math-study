# 3차원좌표계

## 정확한 진술

공간에 고정된 한 점을 원점 $O$라 하고, 이를 지나면서 서로 직각을 이루는 세 개의 수직선 $x$축, $y$축, $z$축을 설정한다. 이를 **3차원 좌표계**라 부르며, 공간의 임의의 점 $P$는 세 개의 실수 순서쌍 $(x, y, z)$로 유일하게 나타낼 수 있다. 여기서 $x, y, z$를 각각 $P$의 $x$ 좌표, $y$ 좌표, $z$ 좌표라 부른다.

## 직관·기하적 의미

2차원 평면좌표에서 수직인 두 축으로 점의 위치를 결정했듯이, 3차원 공간에서는 세 개의 수직 축이 필요하다. 점 $P$의 좌표 $(x, y, z)$는 다음과 같이 해석된다:
- $x$: 원점을 지나고 $yz$평면에 수직인 직선에서의 거리 및 방향
- $y$: 원점을 지나고 $xz$평면에 수직인 직선에서의 거리 및 방향  
- $z$: 원점을 지나고 $xy$평면에 수직인 직선에서의 거리 및 방향

세 좌표축은 서로 직교하므로, 이를 **직교좌표계**(오른손 좌표계)라고도 부른다.

## 한 줄 예

점 $A(2, 3, 1)$는 원점에서 $x$축 방향으로 2, $y$축 방향으로 3, $z$축 방향으로 1만큼 떨어진 점이다.

## 두 점 사이 거리

두 점 $P(x_1, y_1, z_1)$과 $Q(x_2, y_2, z_2)$ 사이의 거리는

$$\overline{PQ} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

이다. 예를 들어 $A(1, 2, 3)$과 $B(4, 6, 8)$ 사이의 거리는:

$$\overline{AB} = \sqrt{(4-1)^2 + (6-2)^2 + (8-3)^2} = \sqrt{9 + 16 + 25} = \sqrt{50} = 5\sqrt{2}$$

(검산: `from sympy import sqrt; sqrt((4-1)**2 + (6-2)**2 + (8-3)**2)`)
