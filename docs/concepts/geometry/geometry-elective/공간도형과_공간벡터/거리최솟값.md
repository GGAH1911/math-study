# 거리최솟값

## 정확한 진술

거리최솟값(minimum distance)이란, 주어진 도형(직선, 평면, 곡선, 곡면) 위의 모든 점에서 특정 점(또는 다른 도형)까지 거리 중 가장 작은 값입니다. 조건을 만족하는 점 $Q$에 대하여 다음과 같이 표현됩니다.
$$d_{\min} = \min_{Q \text{ on }도형} |PQ|$$

여기서 $P$는 기준점이고, 이 최솟값을 달성하는 $Q$를 최단거리점이라 합니다.

## 직관과 기하적 의미

공간에서 점과 도형 사이의 최단거리는 점에서 그 도형으로 내린 **수선의 길이**입니다. 직관적으로, 점에서 직선 위의 수많은 점들로 거리를 그으면, 수선을 그었을 때가 가장 짧습니다. 

이는 벡터의 수직 성질로도 설명됩니다. 최단거리를 주는 점 $Q$에서는 벡터 $\overrightarrow{PQ}$가 그 도형의 **접선(또는 법선)에 수직**이어야 합니다. 미분적으로는 거리 함수 $f(Q) = |PQ|^2$의 극값이 되는 조건이며, 이것이 라그랑주 승수법의 기본 원리입니다.

## 한 줄 예

점 $P(1, 0, 0)$에서 평면 $x + y + z = 3$까지의 거리최솟값은 평면의 법선벡터를 이용하면 $\dfrac{|1 + 0 + 0 - 3|}{\sqrt{1^2 + 1^2 + 1^2}} = \dfrac{2\sqrt{3}}{3}$입니다. 마찬가지로 점 $A(0, 1, 0)$에서 직선 위의 점 $(t, t, 1)$까지 거리의 최솟값은 $|PA|^2 = t^2 + (t-1)^2 + 1$을 $t$에 대해 미분하여 구합니다. (sympy: `sympy.diff(t**2 + (t-1)**2 + 1, t)` → $t = 1/2$일 때 최소)
