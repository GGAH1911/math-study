# 평면의 방정식 구하기

> **예제** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
세 점이 주어지면 두 방향벡터의 외적으로 법선벡터를 구하여 평면의 방정식을 결정합니다.

## 본문
세 점 $A(1, 0, 0)$, $B(0, 1, 0)$, $C(0, 0, 1)$을 지나는 평면의 방정식을 구하시오.

### 단계별 풀이
**단계 1: 방향벡터 구하기**
점 $A$를 기준점으로 두 방향벡터를 구합니다.
$$\vec{AB} = B - A = (-1, 1, 0)$$
$$\vec{AC} = C - A = (-1, 0, 1)$$

**단계 2: 법선벡터 구하기**
외적을 이용해 평면의 법선벡터를 구합니다.
$$\vec{n} = \vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -1 & 1 & 0 \\ -1 & 0 & 1 \end{vmatrix}$$

각 성분을 계산하면 다음과 같습니다.
- $\vec{i}$ 성분: $(1)(1) - (0)(0) = 1$
- $\vec{j}$ 성분: $-[(-1)(1) - (0)(-1)] = 1$
- $\vec{k}$ 성분: $(-1)(0) - (1)(-1) = 1$

따라서 법선벡터 $\vec{n} = (1, 1, 1)$입니다.

**단계 3: 평면의 방정식 세우기**
점 $A(1, 0, 0)$을 지나고 법선벡터가 $(1, 1, 1)$인 평면의 방정식은 다음과 같습니다.
$$1(x - 1) + 1(y - 0) + 1(z - 0) = 0$$
$$x + y + z = 1$$

### 답과 변형
**답**
$$x + y + z = 1$$

**변형 및 주의사항**
점 $P(x_0, y_0, z_0)$과 법선벡터 $\vec{n} = (a, b, c)$가 직접 주어지는 경우에는 $a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$ 공식을 바로 적용할 수 있습니다. 하지만 세 점이 주어지는 경우에는 두 방향벡터의 외적을 통해 법선벡터를 먼저 찾아내는 과정이 필수적입니다. 계산 후에는 반드시 세 점을 방정식에 대입하여 $1+0+0=1$과 같이 식이 성립하는지 검증해야 합니다.

## 학습 체크
- 세 점이 주어졌을 때 외적을 통해 법선벡터를 구할 수 있는가?
- 구한 법선벡터를 이용하여 평면의 방정식 표준형을 도출할 수 있는가?
- 계산 결과가 주어진 세 점을 모두 만족하는지 검증할 수 있는가?
