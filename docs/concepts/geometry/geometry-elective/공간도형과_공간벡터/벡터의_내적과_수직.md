# 벡터의 내적과 수직

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
두 벡터의 내적은 각 성분의 곱의 합 또는 두 벡터의 크기와 사이각의 코사인 값을 곱한 값으로 정의되며, 내적이 0이면 두 벡터는 수직입니다.

## 본문
두 벡터 $\vec{a} = (a_1, a_2, a_3)$와 $\vec{b} = (b_1, b_2, b_3)$의 내적은 각 성분의 곱을 모두 더한 $a_1 b_1 + a_2 b_2 + a_3 b_3$으로 정의됩니다. 이를 기하학적으로 표현하면 두 벡터가 이루는 각을 $\theta$라 할 때 $|\vec{a}| |\vec{b}| \cos\theta$와 같습니다. 특히 두 벡터가 서로 수직인 상태를 의미하는 직교(orthogonal) 조건은 $\vec{a} \cdot \vec{b} = 0$인 경우와 같습니다.

### 직관과 기하적 의미
내적은 한 벡터가 다른 벡터의 방향으로 투영된 크기가 얼마인지를 측정하는 도구입니다. 벡터 $\vec{b}$를 벡터 $\vec{a}$ 방향으로 정사영했을 때의 길이는 $|\vec{b}| \cos\theta$이며, 이 길이에 $\vec{a}$의 크기를 곱한 값이 바로 내적입니다. 만약 두 벡터가 수직이라면 $\cos\theta = 0$이 되어 정사영된 길이가 0이 되므로, 내적의 결과값도 0이 됩니다.

### 기본 성질
- 두 벡터의 내적이 0이면 두 벡터는 서로 수직입니다.
- 내적은 성분의 곱을 통해 대수적으로 계산할 수 있어 벡터의 각도를 구하는 데 유용합니다.
- 예시로 $\vec{a} = (1, 2, 0)$, $\vec{b} = (2, -1, 5)$인 경우 $\vec{a} \cdot \vec{b} = 2 - 2 + 0 = 0$이므로 두 벡터는 수직입니다.

## 학습 체크
- 두 벡터의 성분을 알 때 내적을 계산하는 대수적 방법과 각도를 이용한 기하적 방법이 일치하는가?
- 두 벡터가 수직일 때 내적의 값이 왜 0이 되는지 정사영의 개념으로 설명할 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간상의 점과 선, 면의 위치 관계를 벡터의 내적을 이용하여 수치적으로 계산하고 증명할 수 있습니다.
