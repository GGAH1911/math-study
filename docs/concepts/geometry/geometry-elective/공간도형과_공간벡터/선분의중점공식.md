# 선분의중점공식

## 정확한 진술

좌표평면 또는 좌표공간에서 두 점을 잇는 선분의 중점의 좌표는 각 좌표의 산술평균입니다.

**2차원의 경우:** 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$를 잇는 선분 $AB$의 중점 $M$의 좌표는
$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$$

**3차원의 경우:** 두 점 $A(x_1, y_1, z_1)$, $B(x_2, y_2, z_2)$를 잇는 선분 $AB$의 중점 $M$의 좌표는
$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}, \frac{z_1 + z_2}{2} \right)$$

## 직관/기하적 의미

선분의 중점은 두 끝점으로부터 같은 거리에 있는 점입니다. 각 좌표 성분을 독립적으로 생각하면, 한 축 위에서 두 값의 "정중앙"을 구하는 것은 두 값을 더한 후 반으로 나누는 것입니다. 이를 모든 좌표 축에 동시에 적용하면 선분의 중점을 찾을 수 있습니다. 다시 말해, 중점공식은 각 축 방향에서 등거리 분할을 동시에 수행하는 것입니다.

**벡터 관점:** 점 $A$를 출발점으로 할 때, 중점 $M$은 $A$에서 선분 $\overrightarrow{AB}$의 절반만큼 이동한 위치입니다. 즉, $\overrightarrow{OM} = \frac{\overrightarrow{OA} + \overrightarrow{OB}}{2}$로도 표현됩니다.

## 한 줄 예

두 점 $A(2, 3, 1)$, $B(4, 5, 7)$의 중점은 $M = \left( \frac{2+4}{2}, \frac{3+5}{2}, \frac{1+7}{2} \right) = (3, 4, 4)$입니다. (검산: `sympy.Point3D(2,3,1).midpoint(sympy.Point3D(4,5,7))`)
