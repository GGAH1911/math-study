# 구와 평면의 접촉 조건

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 정확한 진술

중심이 점 $O(x_0, y_0, z_0)$이고 반지름이 $r$인 구와 평면 $ax + by + cz + d = 0$ (단, $a^2 + b^2 + c^2 \neq 0$)을 생각합니다. 구의 중심에서 평면까지의 거리를 $D$라 할 때:

$$D = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$

**구와 평면이 한 점에서 접할 조건**은 이 거리가 반지름과 정확히 같은 경우입니다:

$$D = r \quad \Leftrightarrow \quad |ax_0 + by_0 + cz_0 + d| = r\sqrt{a^2 + b^2 + c^2}$$

## 직관/기하적 의미

구의 중심에서 평면으로 내린 수직 거리가 반지름보다 크면 구와 평면이 만나지 않습니다. 거리가 반지름보다 작으면 평면이 구를 관통하여 원 모양으로 만나게 됩니다. 거리가 정확히 반지름과 같을 때, 평면이 구의 표면에 한 점에서만 스치는 것이 바로 "접촉"입니다. 이 접점은 구의 중심에서 평면으로 내린 수선의 발이며, 이것이 유일한 공통점입니다.

## 한 줄 예

중심이 원점 $(0, 0, 0)$이고 반지름이 $3$인 구가 평면 $x + y + z = 3\sqrt{3}$과 접하는지 확인하면, 거리는 $D = \frac{|0+0+0-3\sqrt{3}|}{\sqrt{1^2+1^2+1^2}} = \frac{3\sqrt{3}}{\sqrt{3}} = 3 = r$이므로 접합니다.
