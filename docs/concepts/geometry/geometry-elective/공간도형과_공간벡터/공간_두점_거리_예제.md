# 공간 두점 거리 예제

> **예제** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
공간 좌표에서 두 점 사이의 거리는 각 좌표 성분의 차이를 제곱하여 합한 뒤 루트를 씌워 구합니다.

## 본문
$A(1, -2, 3)$과 $B(4, 2, -1)$ 사이의 거리를 구하시오.

공간에서 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 피타고라스 정리를 3차원으로 확장한 공식인 $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$을 사용하여 계산합니다.

### 단계별 풀이
**1단계: 각 좌표의 차 계산**
주어진 점의 좌표 성분별 차이를 구합니다.
- $x$ 좌표 차이: $4 - 1 = 3$
- $y$ 좌표 차이: $2 - (-2) = 4$
- $z$ 좌표 차이: $-1 - 3 = -4$

**2단계: 제곱하여 더하기**
각 차이를 제곱한 후 모두 합합니다. 음수 값이 포함되어 있어도 제곱을 통해 양수로 변환되어 거리의 합성을 나타냅니다.
$$d = \sqrt{3^2 + 4^2 + (-4)^2} = \sqrt{9 + 16 + 16} = \sqrt{41}$$

### 답과 변형
$$d = \sqrt{41} \approx 6.40$$

- **부호 무관**: $(B-A)$와 $(A-B)$ 중 어느 방향으로 계산하더라도 제곱을 거치므로 결과는 동일합니다.
- **축 방향 거리**: 만약 한 축의 좌표만 다르고 나머지 좌표가 같다면, 그 축의 차이값이 곧 두 점 사이의 거리가 됩니다.

## 학습 체크
- 공간 거리 공식의 성분을 정확히 대입하여 계산할 수 있는가?
- 좌표의 차이를 구할 때 음수 부호를 실수 없이 처리하는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간에서의 두 점 사이의 거리는 벡터의 크기를 구하는 과정과 직결되며, 이는 공간도형의 성질을 분석하는 기초가 됩니다.
