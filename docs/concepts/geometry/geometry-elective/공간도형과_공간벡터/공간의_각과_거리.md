# 공간의 각과 거리

공간의 점, 직선, 평면 사이의 각도와 거리를 좌표·벡터를 사용해 계산하는 종합 개념입니다. 기하 공간도형과 공간벡터 단원의 핵심 응용입니다.

## 정의

공간에 점 $\mathrm{P}(x_0, y_0, z_0)$와 평면 $\pi: ax + by + cz + d = 0$이 주어졌을 때, 점과 평면 사이의 거리는
$$\frac{|a x_0 + b y_0 + c z_0 + d|}{\sqrt{a^2 + b^2 + c^2}}.$$
두 점 $\mathrm{A}(x_1, y_1, z_1), \mathrm{B}(x_2, y_2, z_2)$ 사이의 거리는
$$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}.$$
또한 두 직선의 사잇각은 방향벡터의 사잇각, 직선과 평면의 각은 직선의 방향벡터와 법선벡터의 여각으로 정의됩니다.

## 예시

두 점 $\mathrm{A}(1, 2, 3)$, $\mathrm{B}(4, 6, 3)$ 사이의 거리는
$$\sqrt{9 + 16 + 0} = 5.$$

또한 점 $\mathrm{P}(1, 1, 1)$에서 평면 $x + y + z - 6 = 0$까지의 거리는
$$\frac{|1 + 1 + 1 - 6|}{\sqrt{3}} = \frac{3}{\sqrt{3}} = \sqrt{3}.$$
