# 평행선 사이의 거리

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
공간에서 방향벡터가 같은 두 평행한 직선 사이의 거리는 한 직선 위의 임의의 점에서 다른 직선까지의 수직 거리를 의미하며, 벡터의 외적을 이용하여 계산할 수 있습니다.

## 본문
공간에서 두 직선이 평행할 때, 이들 사이의 거리는 한 직선 위의 임의의 점에서 다른 직선까지의 거리입니다. 직선 $\ell_1$이 점 $A$를 지나고 방향벡터 $\vec{d}$를 가지며, 직선 $\ell_2$가 점 $B$를 지나고 같은 방향벡터 $\vec{d}$를 가질 때, 두 직선 사이의 거리 $d$는 다음과 같습니다:
$$d = \frac{|\vec{AB} \times \vec{d}|}{|\vec{d}|}$$

### 직관과 기하적 의미
평행한 두 직선은 방향이 동일하므로, 한 직선 위의 어느 점을 택하든 다른 직선까지의 거리는 항상 일정합니다. 벡터의 외적 $\vec{AB} \times \vec{d}$의 크기는 두 벡터가 만드는 평행사변형의 넓이를 나타내며, 이를 밑변의 길이인 $|\vec{d}|$로 나누면 높이에 해당하는 두 직선 사이의 거리가 산출됩니다. 이는 점과 직선 사이의 거리 개념을 평행한 두 직선 사이의 관계로 확장한 것입니다.

### 기본 성질
- 두 직선이 평행하면 한 직선 위의 어떤 점을 선택하더라도 다른 직선까지의 거리는 동일합니다.
- 두 직선 사이의 거리는 두 직선이 이루는 평행사변형의 높이와 같습니다.

## 학습 체크
- 두 직선의 방향벡터가 서로 실수배 관계인지 확인하였는가?
- 거리 계산 시 두 직선 위의 점을 잇는 벡터 $\vec{AB}$를 정확히 설정하였는가?
- 외적의 크기를 방향벡터의 크기로 나누는 과정을 이해하였는가?
