# 점과직선사이의거리

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
점과 직선 사이의 거리는 점과 직선 위의 임의의 점 사이의 거리 중 최솟값이며, 이는 점에서의 수선의 발까지의 길이와 같다.

## 본문
점 $P$와 직선 $L$ 사이의 거리는 점 $P$에서 직선 $L$ 위의 임의의 점까지의 거리 중 최솟값입니다. 직선 $L$이 점 $A$를 지나고 방향벡터가 $\vec{d}$일 때, 점 $P$에서 직선까지의 거리는 다음 공식으로 구할 수 있습니다:
$$d = \frac{|\vec{AP} \times \vec{d}|}{|\vec{d}|}$$
여기서 $\vec{AP}$는 직선 위의 점 $A$에서 점 $P$로 향하는 벡터이며, $\times$는 두 벡터의 외적을 의미합니다.

### 직관과 기하적 의미
점 $P$에서 직선 $L$에 내린 수선의 발을 $H$라고 할 때, 두 대상 사이의 거리는 선분 $PH$의 길이와 같습니다. 직선 위의 다른 임의의 점 $Q$를 선택하더라도 삼각형 $PHQ$가 직각삼각형을 형성하므로, 빗변인 $|PQ|$는 항상 높이인 $|PH|$보다 큽니다. 따라서 수선의 길이는 기하학적으로 최단거리가 됩니다. 외적을 활용하는 방식은 벡터 $\vec{AP}$를 방향벡터 $\vec{d}$에 수직인 성분으로 분해했을 때 그 크기가 곧 거리가 된다는 원리에 기반합니다.

### 기본 성질
직선 $L: \vec{r} = (1, 0, 0) + t(1, 1, 0)$과 점 $P(2, 1, 1)$ 사이의 거리를 계산하면 다음과 같습니다. 먼저 $\vec{AP} = (1, 1, 1)$입니다. 두 벡터의 외적 $\vec{AP} \times \vec{d}$는 $(-1, 1, 0)$이며, 그 크기는 $\sqrt{2}$입니다. 방향벡터의 크기 $|\vec{d}|$ 또한 $\sqrt{2}$이므로, 최종 거리는 $\tfrac{\sqrt{2}}{\sqrt{2}} = 1$이 됩니다.
