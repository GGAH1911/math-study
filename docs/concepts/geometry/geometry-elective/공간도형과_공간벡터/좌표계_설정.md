# 좌표계 설정

## 정확한 진술

공간에 한 점 $O$를 원점으로 정하고, 이 점을 지나면서 서로 수직인 세 직선을 $x$축, $y$축, $z$축으로 설정하는 것을 **좌표계 설정**이라 한다. 이 세 축 위의 단위벡터를 각각 $\vec{e}_1$, $\vec{e}_2$, $\vec{e}_3$라 할 때, 공간 위의 임의의 점 $P$는 다음과 같이 나타낼 수 있다:

$$\vec{OP} = x\vec{e}_1 + y\vec{e}_2 + z\vec{e}_3$$

여기서 $x$, $y$, $z$를 점 $P$의 좌표라 하며, $P(x, y, z)$로 표기한다.

## 직관/기하적 의미

좌표계 설정은 추상적인 공간을 '수량화'하는 과정이다. 원점을 기준으로 세 방향(앞뒤, 좌우, 상하)을 정의함으로써 공간 위의 모든 점을 세 개의 실수 쌍으로 표현할 수 있다. 이렇게 하면 기하학적 성질을 대수적 계산으로 다룰 수 있게 된다. 

예를 들어, 두 점 사이의 거리나 각도를 벡터의 크기, 내적으로 구할 수 있고, 도형의 성질을 방정식으로 기술할 수 있다. 고등학교 단계에서는 보통 세 축이 서로 직각인 **직교좌표계**(직각좌표계)를 사용하므로 계산이 단순해진다.

## 한 줄 예

점 $A(1, 2, 3)$과 $B(4, 5, 6)$이 있을 때, $\vec{AB} = (3, 3, 3)$이고, 거리는 $|\vec{AB}| = \sqrt{3^2 + 3^2 + 3^2} = 3\sqrt{3}$이다.
