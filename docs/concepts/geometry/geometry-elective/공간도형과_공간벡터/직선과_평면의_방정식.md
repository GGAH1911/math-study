# 직선과 평면의 방정식

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3차원 공간에서 직선은 한 점과 방향벡터로, 평면은 한 점과 법선벡터로 정의됩니다.

## 본문
3차원 공간에서 직선은 한 점 $P_0(x_0, y_0, z_0)$과 방향벡터 $\vec{d} = (a, b, c)$에 의해 결정됩니다. 직선의 방정식은 매개변수 $t$를 사용하여 $x = x_0 + at$, $y = y_0 + bt$, $z = z_0 + ct$로 나타내는 매개변수형과, $\tfrac{x - x_0}{a} = \tfrac{y - y_0}{b} = \tfrac{z - z_0}{c}$ (단, $a, b, c \neq 0$)로 나타내는 일반형(대칭형)이 있습니다.

3차원 공간에서 평면은 한 점 $P_0(x_0, y_0, z_0)$과 평면에 수직인 법선벡터 $\vec{n} = (A, B, C)$에 의해 결정됩니다. 평면의 방정식은 $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$ 또는 이를 정리한 $Ax + By + Cz + D = 0$의 일반형으로 나타냅니다. 또한 평면 위의 두 독립적인 방향벡터 $\vec{u}, \vec{v}$를 이용하면 $\vec{r} = \vec{r_0} + s\vec{u} + t\vec{v}$ (단, $s, t$는 실수 매개변수)와 같은 매개변수형으로도 표현할 수 있습니다.

### 직관과 기하적 의미
직선의 매개변수형은 시간 $t$의 흐름에 따라 점이 이동하는 궤적을 의미하며, $t=0$일 때의 위치에서 방향벡터의 방향을 따라 이동하는 모습을 나타냅니다. 평면의 일반형에서 계수 $(A, B, C)$는 해당 평면에 수직인 법선벡터를 의미하며, 평면 위의 모든 점은 이 벡터와의 내적이 일정하다는 성질을 가집니다.

### 기본 성질
- 직선의 방정식 예시: 점 $(1, 2, 3)$을 지나고 방향벡터가 $(2, -1, 1)$인 직선은 $\tfrac{x-1}{2} = \tfrac{y-2}{-1} = \tfrac{z-3}{1}$입니다.
- 평면의 방정식 예시: 점 $(1, 0, 2)$를 지나고 법선벡터가 $(1, 2, -1)$인 평면은 $x + 2y - z + 1 = 0$입니다.

## 학습 체크
- 직선의 방향벡터와 평면의 법선벡터를 구분하여 방정식에 올바르게 대입할 수 있는가?
- 매개변수형 방정식을 일반형(대칭형 또는 일반형)으로 변환할 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간에서의 직선과 평면은 벡터의 내적과 성분을 이용하여 기하학적 위치 관계를 해석하는 기초가 됩니다.
