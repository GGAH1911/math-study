# 구

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
구는 공간에서 한 점으로부터 일정한 거리에 있는 모든 점의 집합으로, 원의 3차원 확장 형태입니다.

## 본문
구(sphere)는 공간에서 한 점(중심)으로부터 일정한 거리(반지름)에 있는 모든 점의 집합입니다. 중심이 $O$이고 반지름이 $r$인 구 위의 점 $P$는 항상 $|OP| = r$을 만족합니다. 좌표계에서 중심이 $(a, b, c)$이고 반지름이 $r$인 구의 방정식은 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$입니다.

### 직관과 기하적 의미
구는 2차원 도형인 원의 3차원 확장입니다. 원이 2차원 평면에서 한 점으로부터 등거리에 있는 점들의 자취라면, 구는 3차원 공간에서 동일한 원리를 나타냅니다. 구의 중심을 원점으로 설정하면 방정식이 $x^2 + y^2 + z^2 = r^2$로 단순화되며, 이는 구가 원점을 중심으로 각 축에 대해 완벽한 회전 대칭성을 가짐을 의미합니다. 또한 구 위의 임의의 점은 매개변수 $\theta$와 $\phi$를 이용하여 다음과 같이 표현할 수 있습니다:
$$
\begin{cases}
x = a + r \sin\theta \cos\phi \\
y = b + r \sin\theta \sin\phi \\
z = c + r \cos\theta
\end{cases}
$$
(단, $0 \le \theta \le \pi$, $0 \le \phi < 2\pi$)

### 기본 성질
- 중심이 $(1, 2, 3)$이고 반지름이 $5$인 구의 방정식은 $(x - 1)^2 + (y - 2)^2 + (z - 3)^2 = 25$입니다.
- 특정 점이 구 위의 점인지 확인하려면 해당 좌표를 방정식에 대입하여 등식이 성립하는지 확인합니다. 예를 들어, 점 $(6, 2, 3)$은 $(6-1)^2 + (2-2)^2 + (3-3)^2 = 25$를 만족하므로 구 위의 점입니다.
- 원점을 중심으로 하는 반지름이 $2$인 구의 방정식은 $x^2 + y^2 + z^2 = 4$입니다.

## 학습 체크
- 구의 방정식에서 중심의 좌표와 반지름을 어떻게 추출할 수 있는가?
- 주어진 점이 특정 구의 표면 위에 존재하는지 판별하는 방법은 무엇인가?
- 구의 방정식을 매개변수 형태로 변환할 때 각 변수의 범위는 어떻게 설정되는가?

## 관련 개념
- **공간도형과 공간벡터**: 구는 공간도형의 대표적인 예시이며, 구 위의 점과 중심 사이의 거리를 벡터의 크기를 이용하여 수학적으로 정의할 수 있습니다.
