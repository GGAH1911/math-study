# 구

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 정확한 진술

구(sphere)는 공간에서 한 점(중심)으로부터 일정한 거리(반지름)에 있는 모든 점의 집합입니다.

중심이 $O$이고 반지름이 $r$인 구 위의 점 $P$는 항상 $|OP| = r$을 만족합니다.

좌표계에서 중심이 $(a, b, c)$이고 반지름이 $r$인 구의 방정식은

$$
(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2
$$

입니다.

## 직관 및 기하적 의미

구는 원의 3차원 확장입니다. 원이 2차원에서 한 점으로부터 등거리에 있는 점들의 자취라면, 구는 3차원 공간에서 같은 개념을 나타냅니다.

구의 중심을 원점으로 놓으면 방정식이 $x^2 + y^2 + z^2 = r^2$로 간단해집니다. 이 식은 구가 원점 중심, 각 축에 대해 완벽한 회전 대칭성을 가짐을 의미합니다.

구 위의 임의의 점은 매개변수 표현으로도 나타낼 수 있습니다:
$$
\begin{cases}
x = a + r \sin\theta \cos\phi \\
y = b + r \sin\theta \sin\phi \\
z = c + r \cos\theta
\end{cases}
$$
여기서 $0 \le \theta \le \pi$, $0 \le \phi < 2\pi$입니다.

## 예시

중심이 $(1, 2, 3)$이고 반지름이 $5$인 구의 방정식:
$$(x - 1)^2 + (y - 2)^2 + (z - 3)^2 = 25$$

점 $(6, 2, 3)$이 이 구 위에 있는지 확인하면, $(6-1)^2 + (2-2)^2 + (3-3)^2 = 25$이므로 구 위의 점입니다.

원점을 중심으로 하는 반지름 2인 구: $x^2 + y^2 + z^2 = 4$
