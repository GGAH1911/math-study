# 법선벡터

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
평면이나 직선에 수직인 방향을 나타내는 벡터로, 도형의 방정식에서 계수들의 집합으로 나타납니다.

## 본문
평면의 방정식 $ax + by + cz = d$ 또는 직선의 방정식 $ax + by = c$에서 계수들로 이루어진 벡터 $(a, b, c)$ 또는 $(a, b)$를 법선벡터라고 합니다. 법선벡터는 해당 평면이나 직선에 수직인 방향을 정의하며, 도형의 기울기와 방향을 결정하는 핵심적인 요소입니다.

### 직관과 기하적 의미
법선벡터는 평면 위의 모든 점에서 평면 밖으로 수직하게 튀어나오는 방향을 가리킵니다. 예를 들어, 종이에 그은 직선에 연필을 수직으로 세웠을 때 연필이 가리키는 방향이 바로 법선벡터의 방향과 같습니다. 평면의 방정식을 $ax + by + cz = d$의 형태로 표현할 수 있는 이유는, 법선벡터에 수직인 모든 점들의 집합이 곧 평면을 이루기 때문입니다.

### 기본 성질
법선벡터는 도형의 위치와 관계없이 수직인 방향만을 나타내므로, 벡터의 크기를 $1$로 만드는 정규화 과정을 통해 단위 법선벡터를 구할 수 있습니다. 예를 들어, 평면 $x + 2y + 3z = 10$의 법선벡터 $(1, 2, 3)$을 정규화하려면 각 성분을 크기인 $\sqrt{14}$로 나누면 됩니다. 또한, 점과 평면 사이의 거리를 구할 때 분모에 사용되는 법선벡터의 크기는 법선 방향으로의 거리를 측정하는 기준이 됩니다.

## 학습 체크
- 직선 $2x - 3y = 5$의 법선벡터를 구할 수 있는가?
- 평면 $x + 2y + 3z = 10$의 법선벡터의 크기를 계산할 수 있는가?
- 점과 평면 사이의 거리 공식에서 분모가 법선벡터의 크기와 어떤 관계인지 이해하고 있는가?

## 관련 개념
- **도형의 방정식**: 평면이나 직선의 방정식에서 계수들이 곧 법선벡터를 구성하며, 이를 통해 도형의 방향을 정의합니다.
