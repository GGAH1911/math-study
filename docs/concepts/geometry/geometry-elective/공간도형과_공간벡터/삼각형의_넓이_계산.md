# 삼각형의 넓이 계산

## 정확한 진술

삼각형의 넓이는 세 가지 주요 방식으로 계산합니다.

**1) 기저와 높이:** 한 변의 길이를 $a$, 그 변에서의 높이를 $h$라 하면
$$\text{넓이} = \frac{1}{2}ah$$

**2) 두 변과 끼인각:** 두 변의 길이가 $a, b$이고 끼인각이 $\theta$일 때
$$\text{넓이} = \frac{1}{2}ab\sin\theta$$

**3) 벡터의 외적:** 한 꼭짓점에서 출발하는 두 벡터를 $\vec{u}, \vec{v}$라 하면
$$\text{넓이} = \frac{1}{2}|\vec{u} \times \vec{v}|$$

## 직관과 기하적 의미

기저와 높이 공식은 가장 기초적입니다. 삼각형을 밑변 $a$인 직사각형의 절반으로 생각하면 높이 $h$일 때 넓이는 $\frac{1}{2}ah$가 됩니다.

두 변과 끼인각 공식은 높이를 다르게 표현한 것입니다. 변 $a$를 기저로 잡으면, 변 $b$와 각 $\theta$에 의해 높이는 $b\sin\theta$이므로 같은 결과를 얻습니다.

벡터의 외적은 3차원 공간에서 특히 유용합니다. 두 벡터가 이루는 평행사변형의 넓이가 외적의 크기이고, 삼각형은 그 절반입니다.

## 구체적 예

세 꼭짓점이 $A(0, 0, 0), B(2, 0, 0), C(0, 3, 0)$인 삼각형의 넓이를 구하면:
- $\vec{AB} = (2, 0, 0), \vec{AC} = (0, 3, 0)$
- $\vec{AB} \times \vec{AC} = (0, 0, 6)$
- 넓이 $= \frac{1}{2}|6| = 3$

기저·높이로도 확인: 밑변 2, 높이 3 → 넓이 $\frac{1}{2} \times 2 \times 3 = 3$ ✓

(`import sympy; sympy.Matrix([2,0,0]).cross(sympy.Matrix([0,3,0]))` → `Matrix([0, 0, 6])`)
