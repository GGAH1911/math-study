# 거리 최소화

## 정확한 진술

공간 내의 두 기하학적 대상(점, 직선, 평면 등) 사이의 **거리 최소화**는, 한 대상 위의 점에서 다른 대상 위의 임의의 점까지의 거리 중 가장 작은 값을 찾는 개념입니다. 점 $P$에서 도형 $S$까지의 거리는 $d(P, S) = \min\{|PQ| : Q \in S\}$로 정의됩니다.

## 직관/기하적 의미

현실에서 두 도형 사이의 가장 가까운 거리는 항상 **수직(직교)으로 만날 때** 나타납니다. 예를 들어 점에서 평면까지의 최단 경로는 평면에 수직인 직선을 따라가며, 두 스큐직선 사이의 최단거리는 두 직선 모두에 수직인 공통 수선 위에서 달성됩니다. 이 원리는 벡터의 직교성과 깊이 연결되어 있으며, 고등학교에서 다루는 거리 공식들(점과 평면 사이, 점과 직선 사이 등)의 기하학적 근거가 됩니다.

## 한 줄 예

점 $P(1, 2, 3)$에서 평면 $2x + y + 2z = 6$까지의 최단거리는

$$d = \frac{|2(1) + 1(2) + 2(3) - 6|}{\sqrt{2^2 + 1^2 + 2^2}} = \frac{|6|}{3} = 2$$

입니다. 이 거리는 점에서 평면의 법선 방향으로 내린 수선의 길이이며, 평면 위의 다른 어떤 점까지의 거리보다 작습니다.
