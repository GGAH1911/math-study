# 공간벡터

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
$\vec a=(a_1,a_2,a_3)$와 같이 세 개의 실수 성분으로 나타내어 3차원 공간에서의 방향과 크기를 표현하는 벡터입니다.

## 본문
공간벡터는 3차원 공간에서 방향과 크기를 함께 나타내는 양으로, 시점과 종점이 정해진 화살표로 정의됩니다. 성분 형태로는 세 개의 실수 순서쌍 $\vec{a} = (a_1, a_2, a_3)$로 나타내며, 이때 $a_1, a_2, a_3$는 각각 $x, y, z$ 축 방향의 성분을 의미합니다. 이는 평면벡터 $(a_1, a_2)$의 개념을 $z$ 축 방향으로 확장한 것입니다.

### 직관과 기하적 의미
공간벡터 $\vec{a} = (a_1, a_2, a_3)$는 원점 $O$에서 출발하여 점 $P(a_1, a_2, a_3)$에 도달하는 화살표로 시각화할 수 있습니다. 이 화살표의 길이는 $|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$이며, 방향은 세 성분의 비율에 의해 결정됩니다. 평면에서는 두 개의 좌표만으로 위치를 나타낼 수 있었지만, 3차원 공간에서는 높이를 포함한 세 개의 좌표가 필요하며 공간벡터는 이를 통해 점의 위치, 이동 방향, 힘의 작용 등을 정확히 표현합니다.

### 기본 성질
벡터의 크기는 각 성분의 제곱의 합에 루트를 씌운 값으로 계산됩니다. 예를 들어 $\vec{a} = (2, -3, 1)$인 경우, 그 크기는 $|\vec{a}| = \sqrt{2^2 + (-3)^2 + 1^2} = \sqrt{14}$가 됩니다.
