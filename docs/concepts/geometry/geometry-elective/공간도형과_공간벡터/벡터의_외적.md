# 벡터의 외적

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
두 평면벡터가 이루는 평행사변형의 유향 넓이를 나타내는 연산입니다.

## 본문
두 평면벡터 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$의 외적(cross product)은 다음과 같은 스칼라값으로 정의됩니다.
$$\vec{a} \times \vec{b} = a_1 b_2 - a_2 b_1$$
이를 크기와 각을 이용하여 표현하면 $\vec{a} \times \vec{b} = |\vec{a}||\vec{b}|\sin\theta$가 되며, 여기서 $\theta$는 $\vec{a}$에서 $\vec{b}$로 향하는 반시계 방향 각을 의미합니다.

### 직관과 기하적 의미
외적의 절댓값은 두 벡터 $\vec{a}$와 $\vec{b}$를 두 변으로 하는 평행사변형의 넓이와 같습니다. 부호는 회전 방향을 나타내어, 결과가 양수이면 $\vec{a}$에서 $\vec{b}$로의 회전이 반시계 방향임을, 음수이면 시계 방향임을 의미합니다. 내적이 두 벡터의 유사한 방향성을 측정한다면, 외적은 두 벡터가 이루는 면적과 수직에 가까운 정도를 부호와 함께 나타냅니다.

### 기본 성질
외적은 $2 \times 2$ 행렬의 행렬식(determinant)과 동일한 구조를 가집니다. 즉, $\vec{a}$와 $\vec{b}$를 열로 하는 행렬의 행렬식이 곧 외적의 값이 됩니다.
$$\vec{a} \times \vec{b} = \begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix}$$
두 벡터가 평행하거나 반평행하여 $\theta = 0$ 또는 $\pi$인 경우 외적값은 $0$이 되며, 두 벡터가 서로 수직일 때 외적의 절댓값이 최대가 됩니다.

## 학습 체크
- 두 벡터가 평행할 때 외적의 값이 $0$이 되는 이유를 $\sin\theta$의 값과 연결하여 설명할 수 있는가?
- 외적의 결과가 음수로 나왔을 때, 벡터의 배치 방향이 어떻게 되는지 기하학적으로 이해하고 있는가?
- 주어진 두 벡터의 성분을 이용하여 행렬식의 형태로 외적을 계산할 수 있는가?

## 관련 개념
- **평면벡터**: 외적은 평면 위의 두 벡터를 입력으로 받아 하나의 스칼라값을 산출하는 연산입니다.
