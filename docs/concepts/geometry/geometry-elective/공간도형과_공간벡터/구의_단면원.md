# 구의 단면원

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

구가 평면과 만날 때 생기는 원입니다. 기하 공간도형 단원에서 구와 평면의 위치 관계의 핵심 결과입니다.

## 정의

중심이 $\mathrm{C}$이고 반지름이 $r$인 구와 평면 $\pi$가 만나면 그 교집합은 원이며, 이 원을 **구의 단면원**이라 합니다. 중심 $\mathrm{C}$로부터 평면 $\pi$까지의 거리를 $d$라 하면 ($0 \le d < r$):
- 단면원의 중심: $\mathrm{C}$에서 평면 $\pi$에 내린 수선의 발.
- 단면원의 반지름: $r' = \sqrt{r^2 - d^2}.$
- $d = r$이면 평면이 구에 접하여 점 하나만 공유, $d > r$이면 만나지 않음.

## 예시

중심이 $\mathrm{C}(0, 0, 0)$이고 반지름이 $5$인 구 $x^2 + y^2 + z^2 = 25$와 평면 $z = 3$의 단면원을 구해 봅니다. 중심에서 평면까지의 거리는 $d = 3$이므로 단면원의 반지름은
$$r' = \sqrt{25 - 9} = 4.$$
단면원의 중심은 $(0, 0, 3)$이며, 식은 평면 $z = 3$ 위의 $x^2 + y^2 = 16$입니다.
