# 공간 두 점 거리

> **정리** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
공간좌표에 있는 두 점 사이의 거리를 피타고라스 정리를 이용하여 구하는 공식입니다.

## 본문
공간의 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$로 정의됩니다.

### 증명 스케치
평면좌표에서 두 점 사이의 거리를 구하는 원리를 공간으로 확장하여 적용합니다. 점 $A$에서 점 $B$로 향하는 변화량을 각 축의 성분인 $(x_2-x_1)$, $(y_2-y_1)$, $(z_2-z_1)$으로 분해합니다. 먼저 $xy$-평면에 정사영된 두 점 사이의 거리를 피타고라스 정리에 의해 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$로 구한 뒤, 이 결과값과 $z$축 방향의 높이 차이인 $|z_2-z_1|$을 직각삼각형의 두 변으로 하는 피타고라스 정리를 한 번 더 적용하면 전체 거리가 도출됩니다.

### 의의와 응용
이 공식은 공간도형의 거리를 정량화하는 가장 기초적인 도구입니다. 벡터의 크기를 계산하거나 점과 평면 사이의 거리를 구하는 등 복잡한 공간 기하 문제를 해결하는 토대가 됩니다. 또한 벡터의 내적을 이용한 $|\vec{AB}| = \sqrt{\vec{AB} \cdot \vec{AB}}$ 표현과도 직결됩니다. 실제 문제 풀이 시에는 좌표의 부호를 정확히 처리하여 계산 실수를 방지하는 것이 중요합니다. 예를 들어 $A(1, 2, 3)$과 $B(4, 6, 15)$ 사이의 거리는 $\sqrt{(4-1)^2 + (6-2)^2 + (15-3)^2} = \sqrt{9+16+144} = 13$입니다.

- 평면에서의 거리 공식이 공간으로 확장되는 원리를 이해하고 있는가?
- 벡터의 크기 개념과 이 공식이 어떻게 연결되는지 설명할 수 있는가?
