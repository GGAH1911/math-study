# 구의 방정식

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3차원 공간에서 한 정점으로부터 일정한 거리에 있는 점들의 집합을 구라고 하며, 이를 방정식으로 나타낸 것이 구의 방정식입니다.

## 본문
3차원 공간에서 구(sphere)는 한 점(중심)으로부터 일정한 거리에 있는 모든 점의 집합입니다. 중심이 $(a, b, c)$이고 반지름이 $r$인 구의 방정식은 $(x-a)^2 + (y-b)^2 + (z-c)^2 = r^2$입니다. 특히 중심이 원점 $(0, 0, 0)$인 경우, 방정식은 $x^2 + y^2 + z^2 = r^2$으로 간단하게 표현됩니다. 여기서 $(x, y, z)$는 구 위의 임의의 점을 나타내며, $r > 0$은 반지름을 의미합니다.

### 직관과 기하적 의미
평면에서 원이 한 점으로부터 일정한 거리에 있는 점들의 자취인 것처럼, 구는 이를 3차원 공간으로 확장한 개념입니다. 중심 $C(a, b, c)$와 구 위의 점 $P(x, y, z)$ 사이의 거리 $|CP|$가 반지름 $r$과 같다는 조건을 만족하는 점들의 집합입니다. 거리 공식 $\sqrt{(x-a)^2 + (y-b)^2 + (z-c)^2} = r$의 양변을 제곱하면 표준형 방정식을 얻을 수 있습니다. 기하적으로 구는 중심을 기준으로 모든 방향에서 동일한 거리 $r$에 있는 점들로 이루어진 완벽한 입체도형이며, 2차원의 원에 높이(z축) 차원이 추가된 형태입니다.

### 기본 성질
- 중심이 $(1, 2, 3)$이고 반지름이 $5$인 구의 방정식은 $(x-1)^2 + (y-2)^2 + (z-3)^2 = 25$입니다.
- 중심이 원점이고 반지름이 $2$인 구의 방정식은 $x^2 + y^2 + z^2 = 4$입니다.

## 학습 체크
- 구의 방정식에서 우변의 상수항이 반지름의 제곱($r^2$)임을 주의하여 계산하였는가?
- 중심의 좌표 $(a, b, c)$를 구할 때 방정식의 부호를 올바르게 해석하였는가?

## 관련 개념
- **공간도형과 공간벡터**: 구는 공간도형의 대표적인 예시이며, 구 위의 점이나 중심을 벡터로 표현하여 공간에서의 위치 관계를 분석할 수 있습니다.
