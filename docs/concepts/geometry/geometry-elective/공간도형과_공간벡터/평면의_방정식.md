# 평면의 방정식

## 정확한 진술

공간에서 한 점 $P_0(x_0, y_0, z_0)$을 지나고, 영벡터가 아닌 벡터 $\vec{n} = (a, b, c)$에 수직인 평면의 방정식은 다음과 같습니다:

$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$$

이를 전개하면 **일반형**

$$ax + by + cz + d = 0 \quad (a, b, c \text{ 중 적어도 하나는 } 0 \text{이 아님})$$

으로 나타낼 수 있습니다. 여기서 벡터 $\vec{n} = (a, b, c)$를 평면의 **법선벡터**라고 부릅니다.

## 직관과 기하적 의미

3차원 공간에서 평면은 무한히 펼쳐진 2차원 도형입니다. 한 점 $P_0$를 지나고 특정 방향 $\vec{n}$에 수직이라는 조건 두 가지가 주어지면, 그 평면은 유일하게 결정됩니다.

평면 위의 모든 점 $P(x, y, z)$에 대해 벡터 $\overrightarrow{P_0P}$는 항상 법선벡터 $\vec{n}$과 **수직**입니다. 즉, 내적이 0입니다:

$$\overrightarrow{P_0P} \cdot \vec{n} = (x - x_0, y - y_0, z - z_0) \cdot (a, b, c) = 0$$

이것이 평면의 방정식이 나오는 원리이며, 동시에 그 기하학적 의미입니다.

## 간단한 예

점 $P_0(1, 2, 3)$을 지나고 법선벡터가 $\vec{n} = (2, -1, 1)$인 평면의 방정식:

$$2(x - 1) - 1(y - 2) + 1(z - 3) = 0$$
$$2x - y + z - 3 = 0$$

검증 코드: `sympy.expand(2*(x-1) - (y-2) + (z-3))` → $2x - y + z - 3$
