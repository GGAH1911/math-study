# 평면의 방정식

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
공간에서 한 점을 지나고 특정 벡터에 수직인 평면은 법선벡터를 이용한 방정식으로 유일하게 결정됩니다.

## 본문
공간에서 한 점 $P_0(x_0, y_0, z_0)$을 지나고, 영벡터가 아닌 벡터 $\vec{n} = (a, b, c)$에 수직인 평면의 방정식은 $a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$입니다. 이를 전개하면 $ax + by + cz + d = 0$ (단, $a, b, c$ 중 적어도 하나는 $0$이 아님)이라는 일반형으로 나타낼 수 있습니다. 이때 벡터 $\vec{n} = (a, b, c)$를 평면의 법선벡터라고 부릅니다.

### 직관과 기하적 의미
3차원 공간에서 평면은 무한히 펼쳐진 2차원 도형입니다. 평면 위의 임의의 점 $P(x, y, z)$에 대하여, 평면 위의 한 점 $P_0$와 연결한 벡터 $\overrightarrow{P_0P}$는 평면의 방향을 결정하는 법선벡터 $\vec{n}$과 항상 수직입니다. 두 벡터가 수직이라는 것은 두 벡터의 내적이 $0$임을 의미하며, $\overrightarrow{P_0P} \cdot \vec{n} = 0$이라는 식을 통해 평면의 방정식이 유도됩니다. 즉, 평면의 방정식은 특정 점을 지나면서 특정 방향에 수직인 평면 위의 모든 점의 자취를 나타냅니다.

### 기본 성질
- 평면의 방정식에서 계수 $(a, b, c)$는 해당 평면에 수직인 법선벡터를 구성합니다.
- 평면의 방정식은 점의 좌표와 법선벡터의 성분을 알 때 유일하게 결정됩니다.
- 예시로 점 $P_0(1, 2, 3)$을 지나고 법선벡터가 $\vec{n} = (2, -1, 1)$인 평면은 $2x - y + z - 3 = 0$입니다.

## 학습 체크
- 평면의 방정식에서 계수 $a, b, c$가 모두 $0$이 될 수 없는 이유는 무엇인가요?
- 주어진 점과 법선벡터를 이용하여 평면의 방정식을 일반형으로 변환할 수 있나요?
- 평면 위의 임의의 점과 기준점 사이의 벡터가 왜 법선벡터와 내적이 $0$이 되는지 설명할 수 있나요?

## 관련 개념
- **공간도형과 공간벡터**: 공간에서의 도형의 위치 관계를 벡터의 내적과 수직 조건을 통해 수학적으로 정의하고 분석하는 기초가 됩니다.
