# 평면의 법선벡터

> **정리** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
평면에 수직인 벡터를 의미하며, 평면의 방정식을 결정하는 핵심 요소입니다.

## 본문
점 $P_0(x_0, y_0, z_0)$을 지나고 $0$이 아닌 벡터 $\vec{n} = (a, b, c)$에 수직인 평면의 방정식은 $a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$입니다. 이때 벡터 $\vec{n} = (a, b, c)$를 이 평면의 법선벡터라고 합니다. 법선벡터는 평면에 수직이며, 평면 위에 존재하는 모든 벡터와 내적했을 때 $0$이 되는 성질을 가집니다.

### 증명 스케치
평면 위의 임의의 점을 $P(x, y, z)$라고 할 때, 평면 위의 두 점을 연결한 벡터 $\overrightarrow{P_0P} = (x - x_0, y - y_0, z - z_0)$는 평면 내에 존재하므로 법선벡터 $\vec{n}$과 수직입니다. 따라서 두 벡터의 내적 $\vec{n} \cdot \overrightarrow{P_0P} = 0$을 계산하면 $a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$이라는 식이 유도됩니다. 이를 전개하면 $ax + by + cz = d$ 형태가 되는데, 이때 $x, y, z$의 계수가 곧 법선벡터의 성분이 됩니다.

### 의의와 응용
법선벡터는 평면의 방정식을 작성할 때 한 점과 함께 주어지면 평면을 즉시 정의할 수 있게 해줍니다. 또한 두 평면의 관계를 판정할 때 유용하여, 두 법선벡터가 평행하면 두 평면도 평행하고, 두 법선벡터의 내적이 $0$이면 두 평면은 수직입니다. 마지막으로 점과 평면 사이의 거리를 구할 때 분모에 법선벡터의 크기가 사용됩니다.

**예시**: 평면 $2x - y + 3z = 5$의 법선벡터는 $(2, -1, 3)$입니다. 점 $(1, 1, 1)$을 지나고 법선벡터가 $(1, 2, -1)$인 평면의 방정식은 $1(x-1) + 2(y-1) - 1(z-1) = 0$, 즉 $x + 2y - z = 2$입니다.

- 두 평면이 수직인지 확인하기 위해 법선벡터의 내적을 계산할 수 있는가?
- 법선벡터를 이용하여 점과 평면 사이의 거리 공식을 적용할 수 있는가?
