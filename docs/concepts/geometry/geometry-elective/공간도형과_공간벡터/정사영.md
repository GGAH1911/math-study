# 정사영

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
점이나 벡터를 특정 평면이나 직선 위로 수직하게 투영하여 얻는 그림자와 같은 상태를 의미합니다.

## 본문
점 $P$에서 평면 $\pi$에 내린 수선의 발을 $P'$이라 할 때, $P'$을 점 $P$의 평면 $\pi$ 위로의 정사영이라고 합니다. 이와 마찬가지로 직선 위의 정사영, 또는 벡터 $\vec{a}$의 벡터 $\vec{b}$ 방향으로의 정사영도 정의할 수 있습니다. 벡터 $\vec{a}$를 벡터 $\vec{b}$ 방향으로 정사영한 벡터를 $\text{proj}_{\vec{b}}\vec{a}$라 하면 다음과 같이 나타냅니다.

$$\text{proj}_{\vec{b}}\vec{a} = \frac{\vec{a} \cdot \vec{b}}{|\vec{b}|^2} \vec{b}$$

이때 정사영의 크기인 스칼라 성분은 $\text{comp}_{\vec{b}}\vec{a} = \frac{\vec{a} \cdot \vec{b}}{|\vec{b}|}$로 계산합니다.

### 직관과 기하적 의미
햇빛이 수직으로 내려올 때 지면 위에 드리워지는 그림자를 떠올리면 이해가 쉽습니다. 그림자의 경계선이 바로 정사영입니다. 벡터의 관점에서는 어떤 방향을 기준으로 했을 때 다른 벡터가 그 방향으로 얼마나 기여하는지를 나타내는 척도가 됩니다. 두 벡터가 이루는 각이 예각이면 정사영은 원래 벡터와 같은 방향을 향하고, 둔각이면 반대 방향을 향합니다. 만약 두 벡터가 수직이라면 정사영은 영벡터가 됩니다.

### 기본 성질
- 두 벡터가 이루는 각이 예각이면 정사영 벡터는 원래 벡터와 같은 방향을 가집니다.
- 두 벡터가 이루는 각이 둔각이면 정사영 벡터는 원래 벡터와 반대 방향을 가집니다.
- 두 벡터가 수직이면 정사영은 영벡터가 됩니다.
- 정사영은 공간도형에서 거리, 면적, 각도를 계산할 때 핵심적인 역할을 합니다.

## 학습 체크
- 벡터 $\vec{a}$를 $\vec{b}$ 방향으로 정사영할 때, 두 벡터가 수직이면 결과값은 무엇인가요?
- 정사영 벡터의 크기(스칼라 성분)를 구하는 공식은 무엇인가요?
- 두 벡터가 이루는 각이 둔각일 때 정사영 벡터의 방향은 어떻게 되나요?

## 관련 개념
- **공간도형과 공간벡터**: 공간도형의 면적이나 길이를 구할 때 벡터의 정사영을 이용하여 복잡한 도형의 크기를 단순화하여 계산할 수 있습니다.
