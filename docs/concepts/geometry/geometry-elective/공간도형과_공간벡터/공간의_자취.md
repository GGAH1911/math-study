# 공간의 자취

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3차원 공간에서 특정한 기하학적 조건을 만족하는 모든 점의 집합을 의미합니다.

## 본문
3차원 공간에서 특정한 기하학적 조건을 만족하는 모든 점의 집합을 **공간의 자취**라고 합니다. 조건을 $C$라고 할 때, 자취는 $\{P \mid P\text{가 조건 }C\text{를 만족}\}$와 같은 집합의 형태로 표현할 수 있습니다. 예를 들어 "두 점 $A, B$로부터 같은 거리에 있는 점들"이라는 조건이 주어지면, 해당 조건을 만족하는 모든 점의 집합인 수직이등분면이 자취가 됩니다.

### 직관과 기하적 의미
2차원 평면에서 원이나 직선이 자취의 대표적인 예였듯이, 3차원 공간에서는 조건을 만족하는 점들을 모았을 때 구, 원기둥, 원뿔과 같은 **곡면**이나 **곡선**이 나타납니다. 자취를 구하는 과정은 거리, 각도, 비와 같은 대수적 조건을 기하학적 도형으로 **시각화**하는 과정과 같습니다. 예를 들어 원점 $O$로부터 거리 $r$인 점들의 자취 $x^2 + y^2 + z^2 = r^2$은 구를 형성하며, 여기에 "$z = 0$인 평면 위에 있다"라는 조건을 추가하면 원이라는 더 제한된 도형이 나타나게 됩니다.

### 기본 성질
- 조건이 단순할수록 자취는 넓은 범위의 도형(곡면 등)을 형성하며, 조건이 추가될수록 자취는 더 제한된 형태(곡선 등)로 나타납니다.
- 점 $A(0, 0, 1)$과 점 $B(0, 0, -1)$로부터 같은 거리에 있는 점 $P(x, y, z)$의 자취를 구하면, 식 $\sqrt{x^2 + y^2 + (z-1)^2} = \sqrt{x^2 + y^2 + (z+1)^2}$을 정리하여 평면 $z = 0$을 얻을 수 있습니다.

## 학습 체크
- 주어진 기하학적 조건이 점의 좌표 $(x, y, z)$에 대해 어떤 방정식으로 표현되는지 유도할 수 있는가?
- 조건이 추가됨에 따라 자취의 차원(곡면 $\rightarrow$ 곡선 $\rightarrow$ 점)이 어떻게 변화하는지 이해하고 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간의 자취로 나타나는 구, 평면, 직선 등의 도형을 벡터의 내적이나 크기를 이용하여 대수적으로 해석하고 증명할 수 있습니다.
