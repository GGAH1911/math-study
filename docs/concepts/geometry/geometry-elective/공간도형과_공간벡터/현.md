### 정확한 진술

원 위의 서로 다른 두 점을 잇는 선분을 **현**(chord)이라고 부릅니다. 반지름이 $r$인 원의 중심을 $O$라 하고 원 위의 두 점을 $A$, $B$라 할 때, 선분 $\overline{AB}$가 현입니다. 특히 원의 중심을 지나가는 현을 **지름**(diameter)이라 하며, 이는 현 중에서 가장 긴 선분이고 길이는 $2r$입니다.

### 직관과 기하적 의미

현은 원을 두 부분으로 나누는 기본 도형입니다. 현 $\overline{AB}$가 짧을수록 작은 호가 생기고, 길어질수록 호가 커집니다. 

원의 중심 $O$에서 현 $\overline{AB}$에 수직선을 그어 현과 만나는 점을 $M$이라 하면, 이 수선은 현을 정확히 이등분합니다(즉, $\overline{AM} = \overline{MB}$). 이 성질로부터 중요한 공식을 얻을 수 있습니다. **중심에서 현까지의 거리가 $d$이고 원의 반지름이 $r$일 때, 현의 길이는**

$$\text{현의 길이} = 2\sqrt{r^2 - d^2}$$

입니다. $d$가 작을수록(중심에 가까울수록) 현이 길어지고, $d = 0$일 때 지름이 됩니다.

### 한 줄 예

반지름이 5인 원에서 중심으로부터 거리 3인 현의 길이는 $2\sqrt{5^2 - 3^2} = 2\sqrt{16} = 8$입니다.

```python
# sympy로 검산
import sympy as sp
chord_length = 2 * sp.sqrt(5**2 - 3**2); print(chord_length)  # 8
```

### 핵심 성질

현이 대하는 중심각이 크면 현도 길어집니다. 또한 같은 원에서 현의 길이가 같으면 중심으로부터의 거리도 같습니다. 이런 성질들은 원과 관련된 각의 계산, 특히 원주각과 중심각의 관계를 다룰 때 자주 활용됩니다.
