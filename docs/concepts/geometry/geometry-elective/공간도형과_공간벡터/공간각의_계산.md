# 공간각의 계산

공간에서 두 직선, 직선과 평면, 두 평면이 이루는 각을 벡터의 내적으로 계산하는 방법입니다. 기하 공간도형과 공간벡터 단원의 핵심 응용입니다.

## 정의

공간의 두 영벡터가 아닌 벡터 $\vec{u}, \vec{v}$에 대하여 사잇각 $\theta$ ($0 \le \theta \le \pi$)는
$$\cos\theta = \frac{\vec{u} \cdot \vec{v}}{|\vec{u}|\,|\vec{v}|}.$$
- **두 직선의 각:** 두 직선의 방향벡터 사이의 각 ($0 \le \theta \le \dfrac{\pi}{2}$로 잡음).
- **직선과 평면의 각:** 직선의 방향벡터와 평면의 법선벡터가 이루는 각을 $\alpha$라 하면 직선과 평면의 각은 $\dfrac{\pi}{2} - \alpha$.
- **두 평면의 각:** 두 평면의 법선벡터 사이의 각.

## 예시

세 점 $\mathrm{A}(1, 0, 0)$, $\mathrm{B}(0, 1, 0)$, $\mathrm{O}(0, 0, 0)$로부터 벡터 $\overrightarrow{\mathrm{OA}} = (1, 0, 0)$과 $\overrightarrow{\mathrm{OB}} = (0, 1, 0)$의 사잇각을 구해 봅니다.
$$\cos\theta = \frac{0}{1 \cdot 1} = 0 \implies \theta = \frac{\pi}{2}.$$
