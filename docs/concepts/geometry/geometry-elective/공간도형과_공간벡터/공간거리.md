# 공간거리

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
3차원 공간에서 두 도형 사이의 가장 짧은 거리인 최단거리를 의미합니다.

## 본문
공간거리란 3차원 공간에서 두 도형 사이의 최단거리를 의미하며, 가장 기본적인 형태는 두 점 사이의 거리입니다. 좌표계가 주어진 공간에서 두 점 $A(x_1, y_1, z_1)$과 $B(x_2, y_2, z_2)$ 사이의 거리는 거리 공식 $\overline{AB} = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$을 통해 구할 수 있습니다. 이는 벡터의 크기 $|\vec{AB}|$와 같으며, 평면에서의 거리 공식을 3차원으로 확장한 개념입니다. 더 나아가 점과 직선, 점과 평면, 두 직선, 직선과 평면, 그리고 두 평면 사이의 거리는 각 도형 위의 점들 중 거리가 가장 짧은 두 점 사이의 거리로 정의됩니다.

### 직관과 기하적 의미
거리는 두 도형이 공간상에서 얼마나 떨어져 있는지를 나타내는 척도입니다. 점과 직선 사이의 거리는 점에서 직선에 내린 수선의 발까지의 길이를 의미하며, 점과 평면 사이의 거리는 점에서 평면에 내린 수선의 발까지의 길이를 의미합니다. 평행한 두 직선이나 두 평면 사이의 거리는 한 도형 위의 임의의 점에서 다른 도형으로 내린 수선의 길이와 같습니다. 반면, 공간에서 만나지도 평행하지도 않은 꼬인 두 직선 사이의 거리는 두 직선 위의 점들 중 거리가 최소가 되는 지점을 찾는 복잡한 과정을 필요로 합니다.

### 기본 성질
- 점과 직선(또는 평면) 사이의 거리는 수선의 길이를 의미한다.
- 평행한 두 직선(또는 평면) 사이의 거리는 임의의 점에서의 수선의 길이로 일정하다.
- 두 도형 사이의 거리는 각 도형 위의 점들 사이의 거리 중 최솟값이다.

## 학습 체크
- 두 점의 좌표가 주어졌을 때 3차원 거리 공식을 정확히 적용할 수 있는가?
- 점과 평면 사이의 거리를 구할 때 수선의 발을 이용한 원리를 이해하고 있는가?
- 꼬인 위치에 있는 두 직선 사이의 거리를 구하는 원리를 파악하고 있는가?
