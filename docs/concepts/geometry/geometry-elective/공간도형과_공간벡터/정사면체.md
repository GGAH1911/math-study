# 정사면체

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 정확한 진술

정사면체(正四面體, regular tetrahedron)는 4개의 합동인 정삼각형으로만 이루어진 정다면체입니다. 같은 길이의 모서리 6개로 연결된 4개의 꼭짓점을 가지며, 각 꼭짓점에서 3개의 모서리가 만납니다. 모서리의 길이를 $a$라 하면, 마주보는 두 모서리(skew lines)는 직교합니다.

## 직관과 기하적 의미

정사면체는 입체도형 중 가장 간단한 정다면체입니다. 정육면체에서 한 꼭짓점마다 하나씩 번갈아 4개를 선택하면 정사면체가 됩니다. 높이는 한 면의 무게중심에서 그 반대편 꼭짓점까지의 거리이며, 정삼각형 한 변이 $a$일 때 높이는 $h = \sqrt{\frac{2}{3}}a$입니다. 

정사면체의 부피는 $V = \frac{a^3}{6\sqrt{2}}$이고, 표면적(4개 정삼각형의 넓이)은 $S = \sqrt{3}a^2$입니다. 정사면체의 중심(무게중심)에서 각 꼭짓점까지의 거리는 모두 같으므로, 중심을 중심으로 하는 구에 내접합니다(외접구).

정사면체는 대칭성이 높아 공간도형 문제에서 자주 등장합니다. 한 꼭짓점에서 대면의 무게중심으로 그은 직선(높이)는 4개이고, 이들은 중심에서 만나며 $3:1$로 내분됩니다.

## 한 줄 예

한 변의 길이가 2인 정사면체의 부피는 $V = \frac{2^3}{6\sqrt{2}} = \frac{8}{6\sqrt{2}} = \frac{4\sqrt{2}}{6} = \frac{2\sqrt{2}}{3}$입니다.
