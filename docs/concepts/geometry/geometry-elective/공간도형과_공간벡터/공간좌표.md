# 공간좌표

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
$(x,y,z)$

## 본문 (학습 시 채워짐)

### 정의

공간에서의 점의 위치를 나타내기 위해 원점 O를 기준으로 서로 수직인 세 수직선(x축, y축, z축)을 설정합니다. 공간의 임의의 점 P는 이 세 축과의 관계에 따라 세 개의 실수로 이루어진 순서쌍 $(x, y, z)$로 유일하게 나타낼 수 있으며, 이를 점 P의 **공간좌표**라고 합니다.

### 직관적 이해

평면좌표 $(x, y)$에서는 가로·세로 두 방향으로 위치를 결정했습니다. 공간좌표는 여기에 높이 방향을 추가한 것입니다. 각 성분이 의미하는 바는 다음과 같습니다: $x$는 원점에서 x축 방향의 거리(부호 포함), $y$는 y축 방향의 거리, $z$는 z축 방향의 거리입니다.

좌표축은 **오른손 좌표계**를 따릅니다. 오른손의 엄지, 검지, 중지를 각각 x축, y축, z축의 양의 방향으로 펼쳤을 때 일치하는 배치입니다. 이 세 축이 만드는 세 개의 좌표평면은 xy평면(z = 0), yz평면(x = 0), zx평면(y = 0)입니다.

### 예와 특수한 점들

점 $A(2, 1, 3)$은 x방향으로 2, y방향으로 1, z방향으로 3만큼 떨어진 점입니다. 원점은 $O(0, 0, 0)$이고, x축 위의 점은 $(a, 0, 0)$ 형태, xy평면 위의 점은 $(a, b, 0)$ 형태입니다. 예를 들어 점 $(3, 0, 0)$은 x축 위에, 점 $(1, 2, 0)$은 xy평면 위에 있습니다.
