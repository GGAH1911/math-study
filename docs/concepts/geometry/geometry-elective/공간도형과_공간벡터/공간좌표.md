# 공간좌표

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
공간의 임의의 점 $P$를 세 좌표축과의 관계를 나타내는 순서쌍 $(x, y, z)$로 나타낸 것입니다.

## 본문
공간에서의 점의 위치를 나타내기 위해 원점 $O$를 기준으로 서로 수직인 세 수직선인 $x$축, $y$축, $z$축을 설정합니다. 공간의 임의의 점 $P$는 이 세 축과의 관계에 따라 세 개의 실수로 이루어진 순서쌍 $(x, y, z)$로 유일하게 나타낼 수 있으며, 이를 점 $P$의 공간좌표라고 합니다.

### 직관과 기하적 의미
평면좌표 $(x, y)$에서 가로와 세로 방향에 높이 방향을 추가한 개념입니다. 각 성분 $x, y, z$는 원점에서 각 축의 양의 방향으로 떨어진 거리를 의미합니다. 좌표축은 오른손의 엄지, 검지, 중지를 각각 $x$축, $y$축, $z$축의 양의 방향으로 펼쳤을 때 일치하는 오른손 좌표계를 따릅니다. 이때 세 축이 만드는 세 개의 좌표평면은 $z=0$인 $xy$평면, $x=0$인 $yz$평면, $y=0$인 $zx$평면입니다.

### 기본 성질
점 $A(2, 1, 3)$과 같이 각 성분은 해당 축 방향으로의 이동 거리를 나타냅니다. 원점은 $(0, 0, 0)$이며, $x$축 위의 점은 $(a, 0, 0)$, $xy$평면 위의 점은 $(a, b, 0)$의 형태를 가집니다. 예를 들어 점 $(3, 0, 0)$은 $x$축 위에 있고, 점 $(1, 2, 0)$은 $xy$평면 위에 위치합니다.

## 학습 체크
- 공간의 점을 세 실수의 순서쌍으로 나타낼 때 각 성분이 의미하는 물리적 거리를 이해하고 있는가?
- 좌표축과 좌표평면의 방정식($x=0$ 등)을 보고 해당 평면이 어떤 축을 포함하는지 구분할 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간좌표를 통해 공간상의 점과 도형의 위치를 수치화하며, 이를 바탕으로 벡터의 연산과 도형의 성질을 분석합니다.
