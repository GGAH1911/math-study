# 사면체와 공간벡터

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 정확한 진술

사면체 $ABCD$에 대해, 한 꼭짓점 $A$를 기준점으로 설정하고 다른 세 꼭짓점으로의 벡터를 $\vec{a} = \overrightarrow{AB}$, $\vec{b} = \overrightarrow{AC}$, $\vec{c} = \overrightarrow{AD}$라 할 때, **사면체 내의 임의의 점 $P$는 다음과 같이 표현**된다:

$$\overrightarrow{AP} = s\vec{a} + t\vec{b} + u\vec{c}$$

여기서 $s, t, u \geq 0$이고 $s + t + u \leq 1$이다. $s + t + u = 1$일 때는 사면체의 **표면**, $s + t + u < 1$일 때는 **내부**의 점이다.

## 직관/기하적 의미

사면체는 3차원 공간에서 4개의 꼭짓점으로 결정되는 최소 단위의 입체도형입니다. 한 꼭짓점을 기준으로 세 벡터를 설정하면, 이 세 벡터가 '좌표축'처럼 작동하여 사면체 내의 모든 점을 유일하게 결정할 수 있습니다. 계수 $s, t, u$는 각각 세 면 $BCD$, $ACD$, $ABD$에서의 **무게중심 좌표**(barycentric coordinate)를 나타내며, 이들 합이 1 이하라는 조건이 바로 사면체라는 경계를 정의합니다.

## 한 줄 예

$A(0,0,0)$, $B(1,0,0)$, $C(0,1,0)$, $D(0,0,1)$일 때, 사면체의 무게중심은 $s=t=u=\frac{1}{4}$로 $\overrightarrow{AP} = \frac{1}{4}(\vec{a}+\vec{b}+\vec{c})$이고, 좌표로는 $(\frac{1}{4}, \frac{1}{4}, \frac{1}{4})$입니다. (검증: `sympy.Matrix([1,1,1,0])/4` → 무게중심)
