# 두 구의 교선

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
두 구가 적절한 거리 조건 내에서 만날 때, 그 교선은 두 구의 중심을 잇는 직선에 수직인 평면 위에 놓인 하나의 원입니다.

## 본문
중심이 $C_1(a_1, b_1, c_1)$이고 반지름이 $r_1$인 구와 중심이 $C_2(a_2, b_2, c_2)$이고 반지름이 $r_2$인 구가 주어졌을 때, 두 구의 교선은 두 구의 방정식을 동시에 만족하는 모든 점의 집합입니다. 두 구의 중심 사이 거리를 $d$라 할 때, $|r_1 - r_2| < d < r_1 + r_2$ 조건을 만족하면 교선은 반드시 존재하며, 이때의 교선은 하나의 원이 됩니다.

### 직관과 기하적 의미
공간에서 두 개의 공이 서로를 파고들며 교차할 때, 두 공이 만나는 경계면은 항상 평면곡선인 원의 형태를 띱니다. 이 원은 두 구의 중심을 연결한 직선과 수직을 이루는 평면 위에 놓이게 됩니다.

### 기본 성질
교선을 구하는 핵심 원리는 두 구의 방정식을 서로 빼는 것입니다. 두 구의 방정식을 빼면 $x^2, y^2, z^2$과 같은 모든 이차항이 소거되어 일차 방정식 형태가 나타나는데, 이것이 바로 교선을 포함하는 평면의 방정식입니다. 따라서 이 평면과 원래의 구 방정식 중 하나를 연립하면 교선인 원의 중심과 반지름을 수학적으로 도출할 수 있습니다. 예를 들어, 구 $x^2 + y^2 + z^2 = 25$와 구 $(x-3)^2 + y^2 + z^2 = 16$의 교선은 평면 $x = \frac{16}{3}$ 위에 놓인 원이 됩니다.

## 학습 체크
- 두 구의 중심 사이 거리 $d$와 반지름 $r_1, r_2$ 사이의 관계가 교선의 존재 여부에 어떤 영향을 미치는가?
- 두 구의 방정식을 뺐을 때 나타나는 일차 방정식이 기하학적으로 어떤 의미를 갖는가?

## 관련 개념
- **공간도형과 공간벡터**: 교선인 원이 놓인 평면의 법선 벡터를 구하거나, 원 위의 점을 벡터로 표현할 때 공간도형의 성질과 벡터의 내적 개념이 활용됩니다.
