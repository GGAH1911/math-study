### 정확한 진술

점 P와 평면 α 사이의 거리는 다음과 같이 정의합니다:

**점 P에서 평면 α에 내린 수선의 발을 H라 할 때, 선분 PH의 길이를 점과 평면 사이의 거리라고 합니다.**

좌표계에서 점 $P(x_0, y_0, z_0)$과 평면 $ax + by + cz + d = 0$이 주어질 때, 거리는 다음 공식으로 구합니다:

$$d = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$

### 직관/기하적 의미

점에서 평면까지의 거리는 **최단거리**입니다. 평면 위의 임의의 점을 선택하더라도, 그 점까지의 거리보다 수선의 발까지의 거리가 항상 작거나 같습니다(피타고라스 정리). 

기하적으로는 평면에 수직인 방향을 따라 재는 길이이며, 이는 평면의 법선벡터 방향과 정확히 일치합니다. 공식에서 분자 $|ax_0 + by_0 + cz_0 + d|$는 점의 좌표를 평면의 방정식에 대입한 값의 절댓값이고, 분모 $\sqrt{a^2 + b^2 + c^2}$는 법선벡터의 크기로, 이를 통해 방향과 무관한 순수한 거리를 얻습니다.

### 한 줄 예

점 $P(1, 2, 3)$에서 평면 $x + 2y + 2z - 9 = 0$까지의 거리는 다음과 같습니다:

$$d = \frac{|1 + 2(2) + 2(3) - 9|}{\sqrt{1^2 + 2^2 + 2^2}} = \frac{|1 + 4 + 6 - 9|}{\sqrt{9}} = \frac{2}{3}$$

검증: `abs(1 + 2*2 + 2*3 - 9) / sqrt(1 + 4 + 4) = 2/3` ✓
