# 교선

> **정의** · 기하 · 단원: [공간도형과 공간벡터](/concepts/공간도형과_공간벡터)

## 요약
두 개의 서로 다른 평면이 만나서 이루는 직선을 교선이라고 합니다.

## 본문
두 개의 서로 다른 평면이 만날 때, 그 교집합으로 이루어진 직선을 교선이라고 합니다. 즉, 두 평면을 동시에 만족하는 모든 점의 집합을 의미합니다. 평면 1의 방정식을 $a_1x + b_1y + c_1z = d_1$, 평면 2의 방정식을 $a_2x + b_2y + c_2z = d_2$라 하면, 교선은 이 두 방정식을 동시에 만족하는 점 $(x, y, z)$들의 궤적입니다.

### 직관과 기하적 의미
책을 펼쳤을 때 두 페이지가 책등을 따라 만나는 경계선을 떠올리면 이해가 쉽습니다. 공간에서 두 평면이 평행하지 않다면 반드시 하나의 직선에서 만나게 되는데, 이 직선이 바로 교선입니다.

### 기본 성질
교선 위의 모든 점은 두 평면 위에 동시에 존재하므로, 교선의 방향벡터는 두 평면의 법선벡터 $\vec{n}_1$과 $\vec{n}_2$ 모두에 수직입니다. 따라서 교선의 방향벡터 $\vec{d}$는 두 법선벡터의 외적으로 구할 수 있습니다:
$$\vec{d} = \vec{n}_1 \times \vec{n}_2$$
교선 위의 한 점을 알고 있다면, 이 방향벡터와 결합하여 교선의 매개변수 방정식을 완전히 결정할 수 있습니다. 예를 들어 평면 $x + y + z = 3$과 $2x - y + z = 3$의 교선은 두 식을 연립하여 얻은 $x = 2y$와 $z = 3 - 3y$를 이용하여 $(2t, t, 3-3t)$와 같이 나타낼 수 있습니다.

## 학습 체크
- 두 평면이 평행할 때 교선이 존재하지 않는 이유는 무엇인가요?
- 교선의 방향벡터를 구하기 위해 왜 두 법선벡터의 외적을 사용하나요?
