### 정확한 진술

초점까지의 거리는 이차곡선 위의 한 점 $P$에서 그 이차곡선의 초점 $F$까지의 거리 $|PF|$입니다. 각 이차곡선은 초점과의 거리 관계식으로 정의됩니다:

- **포물선**: 초점 $F$와 준선 $\ell$에 대해, $|PF| = d(P, \ell)$ (초점까지의 거리 = 준선까지의 거리)
- **타원**: 두 초점 $F_1, F_2$에 대해, $|PF_1| + |PF_2| = 2a$ (상수)
- **쌍곡선**: 두 초점 $F_1, F_2$에 대해, $||PF_1| - |PF_2|| = 2a$ (상수)

### 직관/기하적 의미

초점까지의 거리 관계식은 각 이차곡선이 어떻게 생성되는지의 본질을 드러냅니다. 포물선은 "한 점(초점)과 한 직선(준선)으로부터 같은 거리에 있는 점들의 자취"이며, 타원은 "두 초점으로부터의 거리 합이 항상 일정한 점들의 자취", 쌍곡선은 "두 초점으로부터의 거리 차가 항상 일정한 점들의 자취"입니다. 

초점의 위치와 거리 관계식이 주어지면 곡선의 모양과 크기가 완전히 결정되므로, 초점까지의 거리는 이차곡선의 가장 기본적인 기하학적 성질입니다.

### 한 줄 예

포물선 $y^2 = 4x$의 초점은 $F(1, 0)$이고, 점 $(1, 1)$에서의 초점까지의 거리는 $\sqrt{(1-1)^2 + (1-0)^2} = 1$입니다. (`sympy.sqrt((1-1)**2 + (1-0)**2)` → 1)

타원 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$에서 초점은 $F_1(-3, 0)$, $F_2(3, 0)$이고, 타원 위의 모든 점에서 두 초점까지의 거리의 합은 $|PF_1| + |PF_2| = 10$으로 일정합니다.
