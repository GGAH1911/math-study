# 원과 곡선의 교점

### 정확한 진술

원과 곡선의 교점은 원의 방정식과 다른 곡선(직선, 이차곡선 등)의 방정식을 동시에 만족하는 점입니다. 원 $x^2 + y^2 = r^2$과 곡선 $f(x, y) = 0$의 교점 $(x, y)$는 두 식을 모두 만족해야 합니다.

### 직관과 기하적 의미

교점을 찾는 일은 평면 위에서 두 곡선이 만나는 지점을 결정하는 과정입니다. 이때:
- **대수적 관점**: 두 방정식을 연립하여 풀기
- **기하학적 관점**: 곡선들의 상대적 위치에 따라 교점의 개수(0개, 1개, 2개, 3개, 4개)와 위치가 결정됨

교점의 개수는 곡선의 위치 관계를 나타냅니다. 예를 들어 원과 직선이 만나지 않으면 교점 0개, 접하면 1개(중근), 두 점에서 만나면 2개입니다.

### 계산 예시

원 $x^2 + y^2 = 5$와 직선 $y = x + 1$의 교점을 구합니다:

$$x^2 + (x+1)^2 = 5$$
$$2x^2 + 2x - 4 = 0$$
$$x^2 + x - 2 = 0 \Rightarrow (x+2)(x-1) = 0$$

따라서 $x = -2$ 또는 $x = 1$이고, 교점은 $(-2, -1)$과 $(1, 2)$입니다.

(검산: `sympy.solve([x**2 + y**2 - 5, y - x - 1], [x, y])`)

### 주의할 점

- 연립방정식에서 판별식이 음수면 실근(교점)이 없습니다.
- 중근이 나타나면 두 곡선이 그 점에서 접합니다.
- 원과 이차곡선의 교점은 최대 4개입니다(교점이 모두 실수 범위에 있을 때).
