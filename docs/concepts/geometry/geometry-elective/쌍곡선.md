### 정의

두 점 $F_1$, $F_2$(초점)에서의 거리 차의 절댓값이 일정한 점들의 자취를 **쌍곡선**이라 합니다. 즉, 평면 위의 점 $P$에 대해

$$||PF_1| - |PF_2|| = 2a$$

를 만족하는 모든 점 $P$의 집합입니다. 여기서 $a > 0$은 상수이고, 두 초점 사이의 거리는 $2c$ $(c > a)$입니다.

초점이 $x$축 위에 있고 원점 중앙일 때, 쌍곡선의 표준형은

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (b^2 = c^2 - a^2)$$

입니다. 초점이 $y$축 위에 있으면 $x$와 $y$의 역할이 바뀝니다.

### 기하학적 의미

쌍곡선은 **두 초점으로부터의 거리 차가 일정하다**는 조건으로 만들어집니다. 원(초점이 같은 점)과 타원(거리의 합이 일정)과 달리, 쌍곡선은 **두 개의 분리된 곡선**으로 나타나며, 각 가지는 한 초점에 더 가깝습니다.

표준형에서 쌍곡선의 두 가지는 $x = a$와 $x = -a$의 수직선 사이 공간에 존재하지 않습니다(꼭짓점). $|x|$가 커질수록 곡선은 점근선 $y = \pm \frac{b}{a}x$에 가까워집니다. 이는 쌍곡선이 무한히 뻗어나가면서도 일정한 기울기로 접근하는 특성을 보여줍니다.

### 예제

초점이 $(\pm 3, 0)$이고 $a = 2$인 쌍곡선의 방정식을 구하면:

$c = 3$, $a = 2$이므로 $b^2 = c^2 - a^2 = 9 - 4 = 5$

따라서 $\displaystyle \frac{x^2}{4} - \frac{y^2}{5} = 1$

(검증: 점 $(4, 0)$에서 $\frac{16}{4} - 0 = 4 - 0 = 1$ ✓)
