# 점과직선사이의거리

### 정의

점 P와 직선 L 사이의 거리는, 점 P에서 직선 L 위의 임의의 점까지의 거리 중 **최솟값**입니다. 

직선 L이 점 A를 지나고 방향벡터가 $\vec{d}$일 때, 점 P에서 직선까지의 거리는 다음 공식으로 구합니다:

$$d = \frac{|\vec{AP} \times \vec{d}|}{|\vec{d}|}$$

여기서 $\vec{AP}$는 직선 위의 점 A에서 P로의 벡터, $\times$는 외적(cross product)입니다.

### 기하적 의미

점 P에서 직선 L에 내린 **수선의 발**을 H라 할 때, 거리는 선분 PH의 길이입니다. 이것이 최단거리인 이유는 기하학적으로 자명합니다. 직선 위의 다른 어떤 점 Q를 택해도 삼각형 PHQ에서 직각(P에서의 각)이 있으므로 $|PQ| > |PH|$이기 때문입니다.

외적을 사용하는 이유는, 벡터 $\vec{AP}$를 방향벡터 $\vec{d}$에 수직인 성분으로 분해했을 때 그 크기가 바로 거리이기 때문입니다.

### 계산 예시

직선 $L: \vec{r} = (1, 0, 0) + t(1, 1, 0)$ (점 (1,0,0)을 지나고 방향벡터 (1,1,0))과 점 $P(2, 1, 1)$ 사이의 거리를 구해봅시다.

$\vec{AP} = (2,1,1) - (1,0,0) = (1, 1, 1)$

$\vec{AP} \times \vec{d} = (1,1,1) \times (1,1,0) = (-1, 1, 0)$

$|\vec{AP} \times \vec{d}| = \sqrt{1 + 1 + 0} = \sqrt{2}$, $|\vec{d}| = \sqrt{2}$

거리: $d = \frac{\sqrt{2}}{\sqrt{2}} = 1$
