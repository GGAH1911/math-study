### 정확한 진술

정다각형(정n각형)의 **내각**은 다각형의 한 꼭짓점에서 인접한 두 변이 이루는 각입니다. 정다각형의 모든 변의 길이가 같고 모든 각의 크기가 같으므로, 각 내각의 크기는 다음 공식으로 구합니다:

$$\text{한 내각의 크기} = \frac{(n-2) \times 180°}{n}$$

여기서 $n$은 다각형의 변의 개수입니다.

### 직관/기하적 의미

이 공식이 나오는 이유는 n각형을 삼각형으로 나누는 원리에서 비롯됩니다. 한 꼭짓점에서 모든 대각선을 그으면 n각형은 $(n-2)$개의 삼각형으로 나뉘고, 삼각형의 내각의 합은 $180°$이므로 전체 내각의 합은 $(n-2) \times 180°$입니다. 정다각형은 모든 각이 같으므로 이를 $n$으로 나누면 한 내각의 크기를 얻습니다.

기하학적으로, 정다각형은 원에 내접하는 완전히 대칭인 도형으로, 중심에서 본 각 꼭짓점은 균등하게 배치됩니다. 내각이 클수록 더 많은 변이 필요합니다.

### 한 줄 예

정육각형($n=6$)의 한 내각은 $\frac{(6-2) \times 180°}{6} = \frac{720°}{6} = 120°$입니다.

### 검증 계산
```python
# sympy로 확인: 정육각형, 정오각형, 정사각형
for n in [6, 5, 4, 3]:
    angle = (n-2) * 180 / n
    print(f"정{n}각형: {angle}°")
```
