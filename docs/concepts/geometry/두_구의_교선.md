# 두 구의 교선

### 정확한 진술
중심이 $C_1(a_1, b_1, c_1)$이고 반지름이 $r_1$인 구, 중심이 $C_2(a_2, b_2, c_2)$이고 반지름이 $r_2$인 구가 주어졌을 때, 두 구의 **교선**은 이 두 방정식을 동시에 만족하는 모든 점의 집합입니다. 두 구의 중심 사이 거리를 $d$라 할 때, **$|r_1 - r_2| < d < r_1 + r_2$** 조건에서 교선이 존재하며, 이 경우 교선은 **하나의 원**이 됩니다.

### 직관/기하적 의미
공간에서 두 개의 공(구)이 교차할 때, 만나는 경계는 항상 평면곡선인 **원**입니다. 이 원은 두 구의 중심을 잇는 직선에 수직인 평면 위에 놓입니다.

교선을 구하는 핵심은 **두 구의 방정식을 빼는 것**입니다:
$$(x-a_1)^2 + (y-b_1)^2 + (z-c_1)^2 - [(x-a_2)^2 + (y-b_2)^2 + (z-c_2)^2] = r_1^2 - r_2^2$$

좌변을 전개하면 모든 이차항이 소거되어 **일차 방정식(평면)**만 남습니다. 이것이 교선을 포함하는 평면의 방정식입니다. 이 평면과 원래의 구 방정식을 연립하면 교선인 원의 중심과 반지름을 구할 수 있습니다.

### 한 줄 예
구 $x^2 + y^2 + z^2 = 25$와 구 $(x-3)^2 + y^2 + z^2 = 16$의 교선은 평면 $x = \frac{16}{3}$ 위의 한 원입니다.
