### 정확한 진술

평면 위의 두 고정점 $F_1$, $F_2$ (초점이라 함)으로부터 **거리의 합이 일정한** 모든 점 $P$의 자취를 **타원**이라 합니다. 즉,
$$|PF_1| + |PF_2| = 2a \quad (a > 0, \text{ 상수})$$
를 만족하는 점 $P$들이 이루는 도형입니다.

두 초점이 $x$축 위에 $F_1(-c, 0)$, $F_2(c, 0)$으로 놓여 있을 때 ($0 < c < a$), 타원의 표준형 방정식은
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (b^2 = a^2 - c^2)$$
입니다. 여기서 $a$는 **장축의 반길이**, $b$는 **단축의 반길이**입니다.

### 직관/기하적 의미

타원은 "늘어난 원"으로 볼 수 있습니다. 두 초점이 서로 가까워져 한 점이 되면 원이 되고, 초점 사이의 거리가 멀어질수록 타원은 찌그러집니다. 

**이심률**(eccentricity) $e = \frac{c}{a}$는 이 찌그러짐의 정도를 나타냅니다. $0 < e < 1$일 때 타원, $e = 0$일 때 원, $e = 1$일 때 포물선이 됩니다. 타원의 모양은 완전히 $a$와 $b$의 비로 결정됩니다.

### 한 줄 예

$\frac{x^2}{25} + \frac{y^2}{9} = 1$은 장축의 반길이가 5, 단축의 반길이가 3인 타원입니다. ($a=5, b=3$이므로 $c=4$, 초점은 $(\pm 4, 0)$)

**검증:** `sympy.solve([5**2 - 3**2], c)` → $c = 4$ ✓
