### 정의

내심(내접원의 중심)은 삼각형의 세 내각의 이등분선이 모두 만나는 점입니다.

### 직관과 기하적 의미

내심의 핵심 성질은 삼각형의 **세 변까지의 거리가 모두 같다**는 것입니다. 이 공통 거리를 $r$이라 하면, 이것이 바로 삼각형에 내접하는 원(내접원)의 반지름입니다.

삼각형의 꼭짓점이 $A$, $B$, $C$이고 대변의 길이가 각각 $a = BC$, $b = CA$, $c = AB$일 때, 내심 $I$의 좌표는 세 변의 길이를 무게로 삼는 무게중심으로 표현됩니다:

$$I = \frac{aA + bB + cC}{a + b + c}$$

내접원의 반지름은 다음 공식으로 구합니다:

$$r = \frac{\text{넓이}}{\text{반둘레}} = \frac{S}{s}$$

여기서 $s = \frac{a+b+c}{2}$는 반둘레입니다.

### 예

꼭짓점이 $A(0, 0)$, $B(4, 0)$, $C(0, 3)$인 직각삼각형을 생각해봅시다(3-4-5 삼각형). 각 변의 길이는:
- $a = BC = 5$, $b = CA = 3$, $c = AB = 4$

내심의 좌표는:

$$I = \frac{5(0,0) + 3(4,0) + 4(0,3)}{5+3+4} = \frac{(12, 12)}{12} = (1, 1)$$

삼각형의 넓이는 $S = \frac{1}{2} \times 3 \times 4 = 6$이고, 반둘레는 $s = 6$이므로 내접원의 반지름은 $r = \frac{6}{6} = 1$입니다. 실제로 점 $(1, 1)$에서 $x$축까지의 거리는 1, $y$축까지의 거리는 1이며, 빗변 $3x + 4y = 12$까지의 거리도 $\frac{|3+4-12|}{5} = 1$로 모두 같습니다.
