# 구의 부피 계산

> **예제** · 중1 · 단원: [입체도형](/concepts/입체도형)

## 요약
반지름 주어진 부피

## 본문 (학습 시 채워짐)

### 문제

반지름이 3cm인 구의 부피를 구하시오. (단, $\pi$는 원주율)

### 단계별 풀이

구의 부피를 구하기 위해 먼저 **부피 공식을 확인**합니다. 반지름이 $r$인 구의 부피는 다음과 같습니다.

$$V = \frac{4}{3}\pi r^3$$

이 공식은 원과 회전의 성질로부터 유도되며, 중1에서는 공식으로 주어지므로 이를 사용하면 됩니다.

**주어진 반지름 값을 대입**합니다. 문제에서 반지름 $r = 3\text{cm}$이므로:

$$V = \frac{4}{3}\pi \times 3^3$$

**3의 세제곱을 계산**하고 정리합니다. $3^3 = 27$이므로:

$$V = \frac{4}{3}\pi \times 27 = \frac{4 \times 27}{3}\pi = \frac{108}{3}\pi = 36\pi \text{ cm}^3$$

**검산**: `sympy.simplify(4/3 * 3**3)` → 36. 따라서 부피는 $36\pi\text{ cm}^3$입니다.

### 답

$$V = 36\pi \text{ cm}^3$$

(근사값으로 나타내면 약 113.1cm³)

### 변형/주의

**지름이 주어진 경우**: 문제에서 "지름이 6cm"이라고 하면 먼저 **반지름 = 지름 ÷ 2**로 계산하여 $r = 3$cm를 얻은 후 공식을 적용하세요.

**단위 관리**: 부피의 단위는 **cm³**(세제곱센티미터)입니다. 반지름이 mm나 m로 주어졌다면 단위를 일치시켜 계산해야 합니다.

**$\pi$ 표기**: 수능 기출에서는 정확한 값으로 $36\pi$를 답으로 하되, 필요하면 $\pi \approx 3.14$ 또는 $\pi \approx \frac{22}{7}$로 근사합니다.
