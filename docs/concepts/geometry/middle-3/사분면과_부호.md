### 정확한 진술

좌표평면을 원점을 중심으로 $x$축과 $y$축으로 나눈 네 영역을 **사분면**이라 합니다. 제1사분면($x > 0, y > 0$), 제2사분면($x < 0, y > 0$), 제3사분면($x < 0, y < 0$), 제4사분면($x > 0, y < 0$)입니다.

일반각 $\theta$에 대해 반지름 $r > 0$인 원 위의 점 $(x, y)$에서 
$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}$$
로 정의할 때, 각 삼각비의 부호는 점 $(x, y)$가 있는 사분면에 의해 결정됩니다.

- **제1사분면**: $x > 0, y > 0$ → $\sin\theta > 0, \cos\theta > 0, \tan\theta > 0$ (모두 양)
- **제2사분면**: $x < 0, y > 0$ → $\sin\theta > 0, \cos\theta < 0, \tan\theta < 0$
- **제3사분면**: $x < 0, y < 0$ → $\sin\theta < 0, \cos\theta < 0, \tan\theta > 0$ (탄젠트만 양)
- **제4사분면**: $x > 0, y < 0$ → $\sin\theta < 0, \cos\theta > 0, \tan\theta < 0$

### 직관/기하적 의미

직각삼각형에서 배운 삼각비($0° \leq \theta \leq 90°$)를 모든 각도로 확장할 때, 각의 위치가 어느 사분면에 있느냐에 따라 좌표의 부호가 바뀝니다. 

예를 들어 $\sin\theta$는 항상 $y$좌표에 비례하므로 제1, 2사분면에서만 양수이고, $\cos\theta$는 $x$좌표에 비례하므로 제1, 4사분면에서만 양수입니다. 이를 쉽게 기억하려면 **CAST 법칙**을 사용합니다: 제1사분면에서 All(모두), 제2사분면에서 Sine, 제3사분면에서 Tangent, 제4사분면에서 Cosine이 양수입니다.

### 한 줄 예

$\theta = 120°$는 제2사분면에 있으므로 $\sin 120° = \frac{\sqrt{3}}{2} > 0$, $\cos 120° = -\frac{1}{2} < 0$, $\tan 120° = -\sqrt{3} < 0$입니다.
