### 정확한 진술

삼각형의 세 변의 길이를 $a, b, c$, 그에 마주보는 각을 각각 $A, B, C$라 할 때, 다음 두 법칙이 성립합니다.

**사인 법칙(sine rule):**
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

여기서 $R$은 삼각형의 외접원의 반지름입니다.

**코사인 법칙(cosine law):**
$$a^2 = b^2 + c^2 - 2bc \cos A$$
$$b^2 = a^2 + c^2 - 2ac \cos B$$
$$c^2 = a^2 + b^2 - 2ab \cos C$$

### 직관과 기하적 의미

사인 법칙은 **변의 길이와 대각의 정현의 비가 일정**하다는 의미입니다. 같은 호(호에 내접하는 원주각)에 대해 사인 값이 일정하므로, 외접원의 크기가 커질수록 같은 각에 대응하는 변도 커집니다.

코사인 법칙은 **직각삼각형에서의 피타고라스 정리를 일반화한 것**입니다. 각 $A$가 직각이면 $\cos A = 0$이므로 $a^2 = b^2 + c^2$가 되며, 각이 둔각이거나 예각일 때는 보정항 $-2bc \cos A$가 생깁니다.

### 한 줄 예

변의 길이가 $a = 3, b = 4, c = 5$인 직각삼각형(∠C = 90°)에서 사인 법칙 $\frac{a}{\sin A} = \frac{c}{\sin C}$에 대입하면 $\frac{3}{\sin A} = \frac{5}{1} = 5$이므로 $\sin A = 0.6$이고, 코사인 법칙 $c^2 = a^2 + b^2 - 2ab\cos C$에서 $\cos C = 0$을 확인할 수 있습니다. (`sympy.solve(3**2 + 4**2, 5**2)` → 25 = 25)
