# 원의 성질

> **단원** · 중3 · 선수: [도형의 성질](/concepts/도형의_성질) / [평면도형](/concepts/평면도형) · 다음: [도형의 방정식](/concepts/도형의_방정식)

## 학습 목표
- 원의 현·접선·원주각의 성질을 활용한다
- 내접·외접 사각형의 성질을 적용한다

## 다룰 정의 / 정리 / 예제

**정의**
- 현, 접선, 원주각, 중심각

**정리**
- 원주각은 같은 호에 대해 동일
- 원주각 = 중심각 / 2
- 접선은 접점에서 반지름과 수직

**예제**
- 원주각으로 각도 구하기
- [접선의 길이 예제](/concepts/접선의_길이_예제)
- 내접사각형의 대각의 합 $180°$

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
