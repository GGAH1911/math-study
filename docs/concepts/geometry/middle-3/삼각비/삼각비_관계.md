# 삼각비 관계

> **정리** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
$\sin^2\theta + \cos^2\theta = 1$은 삼각비 사이의 가장 기초적인 관계를 나타내는 항등식입니다.

## 본문
임의의 각 $\theta$에 대하여 $\sin^2\theta + \cos^2\theta = 1$이 성립하며, 이를 삼각비의 기본 항등식 또는 피타고라스 항등식이라고 합니다.

### 증명 스케치
직각삼각형의 빗변의 길이를 $r$, 높이를 $y$, 밑변을 $x$라고 하면 $\sin\theta = \tfrac{y}{r}$이고 $\cos\theta = \tfrac{x}{r}$입니다. 이때 $\sin^2\theta + \cos^2\theta$를 계산하면 $\tfrac{y^2}{r^2} + \tfrac{x^2}{r^2} = \tfrac{x^2 + y^2}{r^2}$이 됩니다. 피타고라스 정리에 의해 $x^2 + y^2 = r^2$이므로, 최종적으로 값은 $1$이 됩니다. 이 성질은 각의 크기와 관계없이 항상 성립합니다.

### 의의와 응용
이 식은 한 가지 삼각비의 값을 알면 나머지 삼각비의 값을 결정할 수 있게 해주는 핵심적인 도구입니다. 예를 들어 $\sin\theta = 0.6$이라면 $\cos^2\theta = 1 - 0.6^2 = 0.64$이므로 $\cos\theta = 0.8$임을 알 수 있습니다(단, 부호는 각의 위치에 따라 결정됩니다). 이는 고등학교 과정의 삼각함수 항등식인 $\tan^2\theta + 1 = \sec^2\theta$ 등을 유도하는 기초가 되며, 다양한 수학 문제 해결에 필수적으로 활용됩니다.

## 관련 개념
- **삼각비**: 직각삼각형의 변의 길이의 비율을 나타내며, 이 항등식은 삼각비 사이의 관계를 정의합니다.
