# 삼각형의 코사인 법칙

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
삼각형의 세 변의 길이와 한 각의 크기 사이의 관계를 나타내는 공식으로, 피타고라스 정리를 일반화한 개념입니다.

## 본문
삼각형 $ABC$에서 세 변의 길이를 $a, b, c$라 하고, 각 $C$를 변 $c$의 대각이라고 할 때 다음과 같은 관계가 성립합니다.
$$c^2 = a^2 + b^2 - 2ab\cos C$$
이 공식은 삼각형의 한 꼭짓점의 대변의 길이를 구하거나, 모든 변의 길이를 알 때 각을 구하는 상황에서 유용하게 사용됩니다. 대칭성에 의해 $a^2 = b^2 + c^2 - 2bc\cos A$와 $b^2 = a^2 + c^2 - 2ac\cos B$도 동일하게 성립합니다.

### 직관과 기하적 의미
코사인 법칙은 **일반화된 피타고라스 정리**로서의 의미를 갖습니다. 만약 각 $C$가 $90^\circ$라면 $\cos C = 0$이 되어 우리가 잘 아는 피타고라스 정리인 $c^2 = a^2 + b^2$가 됩니다. 기하학적으로는 두 변 $a$와 $b$ 사이의 각도 $C$가 변 $c$의 길이에 미치는 영향을 나타냅니다. 각도가 예각인지 둔각인지에 따라 변 $c$의 길이가 어떻게 변하는지를 $-2ab\cos C$라는 항이 정확하게 반영하여 계산해 줍니다.

### 기본 성질
삼각형의 세 변의 길이를 모두 알고 있다면 코사인 법칙을 변형하여 각의 크기를 구할 수 있습니다. 또한, 삼각형의 모양이 결정되는 조건 중 하나로 활용됩니다.

## 학습 체크
- 각 $C$가 $90^\circ$일 때 코사인 법칙이 피타고라스 정리로 어떻게 변하는지 설명할 수 있는가?
- 세 변의 길이를 알 때 코사인 법칙을 이용하여 특정 각의 크기를 구할 수 있는가?
- 코사인 법칙의 유도 과정에서 피타고라스 정리가 어떻게 사용되는지 이해하고 있는가?

## 관련 개념
- **피타고라스 정리**: 직각삼각형에서만 성립하는 특수한 경우로, 코사인 법칙에서 $\cos 90^\circ = 0$임을 이용해 유도할 수 있습니다.
- **삼각비**: 각의 크기에 따른 변의 길이 비율을 나타내며, 코사인 법칙은 이 삼각비의 값을 변의 길이와 연결해 줍니다.
