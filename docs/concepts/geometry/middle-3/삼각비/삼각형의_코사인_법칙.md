# 삼각형의 코사인 법칙

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 정확한 진술

삼각형 $ABC$에서 한 꼭짓점의 대변의 길이를 구하거나, 모든 변의 길이를 알 때 각을 구하는 상황에서 적용되는 공식입니다.

$$c^2 = a^2 + b^2 - 2ab\cos C$$

여기서 $a, b, c$는 삼각형의 세 변이고, $C$는 변 $c$의 대각입니다. 대칭성에 의해 다음도 성립합니다.

$$a^2 = b^2 + c^2 - 2bc\cos A$$
$$b^2 = a^2 + c^2 - 2ac\cos B$$

## 직관과 기하적 의미

코사인 법칙은 **일반화된 피타고라스 정리**입니다. $C = 90°$인 경우 $\cos C = 0$이므로 $c^2 = a^2 + b^2$가 되어 피타고라스 정리와 일치합니다.

기하학적으로는 변 $c$를 두 변 $a, b$로 표현할 때, 두 변 사이의 각 $C$가 예각이면 수직 투영을 고려해야 하고, 둔각이면 공식이 자동으로 조정됩니다. 코사인 항 $-2ab\cos C$가 이 "각도의 영향"을 정확히 반영합니다.

## 유도 스케치

점 $A$에서 변 $BC$에 수직선을 내려 발을 $H$라 하면, 직각삼각형에서 $BH = c\cos A$입니다. 피타고라스 정리를 적용하면:
$$a^2 = (c - c\cos A)^2 + h^2 = c^2 - 2bc\cos A + b^2$$

이를 정리하면 코사인 법칙을 얻습니다.
