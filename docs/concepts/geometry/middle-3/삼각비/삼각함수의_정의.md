# 삼각함수의 정의

## 정확한 진술

좌표평면에 단위원(반지름이 1인 원)을 그립니다. 원점에서 출발한 반직선이 양의 $x$축과 이루는 각을 $\theta$라 하고, 이 반직선이 단위원과 만나는 점을 $(x, y)$라 하면:

$$\cos \theta = x, \quad \sin \theta = y, \quad \tan \theta = \frac{y}{x} \quad (x \neq 0)$$

이것이 삼각함수의 기본 정의입니다. 각 $\theta$는 음수도, $360°$를 넘는 값도 가능합니다.

## 직관/기하적 의미

삼각함수는 **각도를 입력받아 원 위의 좌표를 출력**하는 함수입니다. 단위원 위를 움직이는 점의 위치를 추적하면, 각 $\theta$에 따라 $x$ 좌표 ($\cos\theta$)와 $y$ 좌표 ($\sin\theta$)가 규칙적으로 변합니다.

직각삼각형에서 배운 삼각비($\text{대변}/\text{빗변}$ 등)는 $0°$부터 $90°$까지만 정의되지만, 단위원을 이용하면 모든 각도로 자연스럽게 확장됩니다. 예를 들어 $\theta = 150°$일 때도 단위원 위의 한 점이 존재하므로 $\cos 150°$, $\sin 150°$가 정의됩니다.

## 한 줄 예

$\theta = 60°$일 때, 단위원 위의 점은 $\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$이므로 $\cos 60° = \frac{1}{2}$, $\sin 60° = \frac{\sqrt{3}}{2}$입니다.
