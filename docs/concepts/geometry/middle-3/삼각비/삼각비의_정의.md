# 삼각비의 정의

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 정확한 진술

직각삼각형에서 예각 하나를 기준으로 할 때, 다음 세 비율을 **삼각비**라고 합니다.

$$\sin A = \frac{\text{대변}}{\text{빗변}}, \quad \cos A = \frac{\text{인접변}}{\text{빗변}}, \quad \tan A = \frac{\text{대변}}{\text{인접변}}$$

여기서 예각 $A$에 대해:
- **대변(opposite)**: $A$의 맞은쪽 변
- **인접변(adjacent)**: $A$에 인접한 직각이 아닌 변  
- **빗변(hypotenuse)**: 직각의 맞은쪽 변 (가장 긴 변)

## 직관/기하적 의미

삼각비는 **삼각형의 모양**을 각도로 나타냅니다. 같은 각도라면 삼각형의 크기가 달라도 삼각비는 같습니다(닮음). 예를 들어, 30° 각도를 가진 모든 직각삼각형은 변의 길이는 다르지만 $\sin 30° = 0.5$로 동일합니다.

- $\sin A$가 크면 → 각 $A$가 크다 (대변이 빗변에 가깝다)
- $\cos A$가 크면 → 각 $A$가 작다 (인접변이 빗변에 가깝다)  
- $\tan A$가 크면 → 기울기가 가파르다

## 한 줄 예

빗변의 길이가 10, 대변의 길이가 6인 직각삼각형에서 각 $A$에 대해 $\sin A = \frac{6}{10} = 0.6$입니다.

더 나아가 피타고라스 정리로 인접변을 구하면 $\sqrt{10^2 - 6^2} = 8$이므로, $\cos A = 0.8$, $\tan A = 0.75$입니다.

```python
# sympy로 검증
import sympy as sp
# 빗변 10, 대변 6일 때 인접변
인접변 = sp.sqrt(10**2 - 6**2)  # 8
sin_A, cos_A, tan_A = 6/10, 인접변/10, 6/인접변
# sin_A = 0.6, cos_A = 0.8, tan_A = 0.75
```
