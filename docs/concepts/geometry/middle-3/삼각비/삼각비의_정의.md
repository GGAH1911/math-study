# 삼각비의 정의

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
직각삼각형에서 예각의 크기에 따라 결정되는 세 변의 길이의 비율을 의미합니다.

## 본문
직각삼각형에서 예각 하나를 기준으로 할 때, 다음 세 비율을 삼각비라고 합니다.

$$\sin A = \frac{\text{대변}}{\text{빗변}}, \quad \cos A = \frac{\text{인접변}}{\text{빗변}}, \quad \tan A = \frac{\text{대변}}{\text{인접변}}$$

여기서 예각 $A$에 대하여 각 변의 의미는 다음과 같습니다. 대변은 각 $A$의 맞은쪽 변을, 인접변은 각 $A$에 인접한 직각이 아닌 변을, 빗변은 직각의 맞은쪽 변인 가장 긴 변을 의미합니다.

### 직관과 기하적 의미
삼각비는 삼각형의 크기와 상관없이 삼각형의 모양(각도)을 나타내는 척도입니다. 닮은 직각삼각형은 각도가 같다면 변의 길이가 달라도 삼각비의 값은 항상 일정합니다. 예를 들어, $30^{\circ}$를 가진 모든 직각삼각형에서 $\sin 30^{\circ}$는 $0.5$로 동일합니다. 또한 $\sin A$의 값이 클수록 각 $A$는 커지며, $\cos A$의 값이 클수록 각 $A$는 작아집니다. $\tan A$는 삼각형의 기울기를 나타내며, 이 값이 클수록 경사가 가파름을 의미합니다.

### 기본 성질
삼각형의 세 변의 길이를 알 때 피타고라스 정리를 이용하면 나머지 변의 길이를 구할 수 있으며, 이를 통해 모든 삼각비의 값을 결정할 수 있습니다. 예를 들어 빗변이 $10$, 대변이 $6$인 경우 인접변은 $\sqrt{10^2 - 6^2} = 8$이 되며, 이에 따라 $\sin A = 0.6$, $\cos A = 0.8$, $\tan A = 0.75$가 됩니다.

## 학습 체크
- 직각삼각형에서 각 변(대변, 인접변, 빗변)의 위치를 정확히 구분할 수 있는가?
- 삼각형의 크기가 변하더라도 각도가 일정하면 삼각비가 왜 일정한지 설명할 수 있는가?
- 피타고라스 정리를 활용하여 한 변의 길이를 알 때 나머지 삼각비들을 모두 구할 수 있는가?

## 관련 개념
- **삼각비**: 직각삼각형의 각과 변 사이의 관계를 나타내는 기초 개념으로, 삼각비의 정의를 바탕으로 삼각함수로 확장됩니다.
