# 특수각

> **정의** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
$30°, 45°, 60°$의 삼각비 값을 정확히 이해하고 활용하는 것.

## 본문
특수각은 삼각비의 값을 수치로 정확히 알 수 있는 특별한 각도를 의미하며, 중학교 과정에서는 $30°, 45°, 60°$를 주요 대상으로 다룹니다. 각 각도에 따른 $\sin$, $\cos$, $\tan$의 값은 다음과 같습니다.

| 각도 | $\sin$ | $\cos$ | $\tan$ |
|------|--------|--------|--------|
| $30°$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{3}}{3}$ |
| $45°$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $1$ |
| $60°$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $\sqrt{3}$ |

### 직관과 기하적 의미
이 값들은 특정한 기하 도형의 변의 길이 비율을 통해 유도됩니다. $45°$의 삼각비는 두 직각변의 길이가 같은 직각이등변삼각형에서 나타납니다. 직각변의 길이가 $1$일 때 빗변의 길이는 $\sqrt{2}$가 되므로, $\sin 45° = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$가 됩니다. $30°$와 $60°$의 삼각비는 정삼각형을 수직 이등분했을 때 나타나는 직각삼각형에서 유도됩니다. 한 변의 길이가 $2$인 정삼각형을 높이로 나누면 밑변의 절반은 $1$, 높이는 $\sqrt{3}$이 되어 $\sin 30° = \dfrac{1}{2}$과 같은 값을 얻게 됩니다.

### 기본 성질
특수각의 삼각비는 도형의 크기와 상관없이 각도가 일정하면 항상 일정한 비율을 유지합니다. 예를 들어 $\sin 60° = \dfrac{\sqrt{3}}{2}$이므로, 빗변의 길이가 $4$인 직각삼각형에서 $60°$에 대한 높이는 $4 \times \dfrac{\sqrt{3}}{2} = 2\sqrt{3}$이 됩니다.

## 학습 체크
- $30°, 45°, 60°$의 $\sin, \cos, \tan$ 값을 표 없이도 암기할 수 있는가?
- 직각이등변삼각형과 정삼각형의 성질을 이용하여 특수각의 값을 유도할 수 있는가?
- 특수각이 포함된 직각삼각형에서 변의 길이를 삼각비를 이용해 구할 수 있는가?

## 관련 개념
- **삼각비**: 특수각의 삼각비는 삼각비의 정의를 구체적인 수치로 확장하여 계산할 수 있게 해주는 기초가 됩니다.
