# 각도 구하기

> **예제** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
삼각비의 값을 이용하여 특수각의 크기를 추정하거나 결정할 수 있습니다.

## 본문
직각삼각형 ABC에서 $\angle C = 90^\circ$이고, 빗변 $AB = 10\text{ cm}$, $BC = 5\text{ cm}$입니다. $\angle A$의 크기를 구하세요.

### 단계별 풀이
**1단계: 주어진 정보 정리**
직각삼각형에서 $\angle A$에 대한 대변은 $BC$이고, 빗변은 $AB$입니다. 문제에서 이 두 변의 길이를 알고 있으므로 사인 비를 세웁니다.

**2단계: 사인 비 계산**
$\sin A = \frac{\text{대변}}{\text{빗변}} = \frac{BC}{AB} = \frac{5}{10} = \frac{1}{2}$
사인 값이 $1/2$라는 것을 얻었으므로, 이제 "사인값이 $1/2$인 각은 몇 도인가?"를 찾으면 됩니다.

**3단계: 삼각비 표에서 각 찾기**
중3 과정에서 배우는 특수각들의 삼각비 표를 참고하면, $\sin 30^\circ = \frac{1}{2}$입니다. 따라서 $\sin A = \sin 30^\circ$이므로 $A = 30^\circ$입니다.

### 답과 변형
$\angle A = 30^\circ$

**비가 특수각이 아닐 때:**
만약 $\sin A = 0.6$처럼 깔끔한 특수각이 아니면, 계산기나 삼각함수표를 사용해 각을 추정합니다. 중3 교과서는 주로 $30^\circ, 45^\circ, 60^\circ$의 특수각 문제를 다룹니다.

**다른 삼각비 활용:**
코사인이나 탄젠트로도 같은 각을 구할 수 있습니다. 예를 들어 $\cos A = \frac{AC}{AB}$로 구하거나, 두 직각변을 아는 경우 $\tan A = \frac{BC}{AC}$를 사용합니다.

**검산:**
피타고라스 정리로 $AC$를 먼저 구하면 $AC = \sqrt{10^2 - 5^2} = 5\sqrt{3}\text{ cm}$이고, $\tan 30^\circ = \frac{1}{\sqrt{3}}$이므로 $\tan A = \frac{5}{5\sqrt{3}} = \frac{1}{\sqrt{3}}$로 확인할 수 있습니다.

## 학습 체크
- 삼각비의 정의를 이용하여 변의 길이를 구할 수 있는가?
- 특수각($30^\circ, 45^\circ, 60^\circ$)의 삼각비 값을 암기하고 있는가?
- 주어진 변의 길이를 통해 삼각비의 값을 계산할 수 있는가?

## 관련 개념
- **삼각비**: 직각삼각형에서 두 변의 길이의 비를 나타내며, 이를 통해 각의 크기를 결정할 수 있습니다.
