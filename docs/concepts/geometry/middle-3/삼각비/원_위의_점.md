### 정확한 진술

중심이 원점 $O$이고 반지름이 $1$인 **단위원**(unit circle) 위의 점을 생각합니다. 원점에서 시작하는 반직선이 양의 $x$축과 이루는 각을 $\theta$라 할 때, 이 반직선이 단위원과 만나는 점 $P$의 좌표는 다음과 같습니다:

$$P = (\cos \theta, \sin \theta)$$

이 정의는 모든 실수 각 $\theta$에 대해 성립하며, 삼각비의 개념을 일반화합니다.

### 직관과 기하적 의미

삼각비에서 배운 $\sin \theta$와 $\cos \theta$는 직각삼각형의 변의 비율이었습니다. 하지만 원 위의 점으로 정의하면, 어떤 각도에서도(예: 90°보다 큰 각에서도) 삼각함수를 자연스럽게 사용할 수 있습니다.

원 위의 점 $P(\cos \theta, \sin \theta)$에서:
- **$x$좌표** = $\cos \theta$ : 점이 얼마나 오른쪽(또는 왼쪽)에 있는지
- **$y$좌표** = $\sin \theta$ : 점이 얼마나 위(또는 아래)에 있는지

각 $\theta$가 증가하면 점은 반시계방향으로 원 위를 따라 이동합니다. 항상 $\cos^2 \theta + \sin^2 \theta = 1$이 성립하므로, 점은 정확히 단위원 위에 있습니다.

### 구체적인 예

$\theta = 60°$일 때, 점의 좌표는:
$$P = \left(\cos 60°, \sin 60°\right) = \left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$$

$\theta = 120°$일 때:
$$P = \left(\cos 120°, \sin 120°\right) = \left(-\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$$

두 점 모두 원점으로부터 거리가 $1$입니다. (검증: `sympy.sqrt((-1/2)**2 + (sympy.sqrt(3)/2)**2)` → `1`)
