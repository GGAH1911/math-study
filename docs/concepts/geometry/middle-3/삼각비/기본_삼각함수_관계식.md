# 기본 삼각함수 관계식

## 정의

기본 삼각함수 관계식(fundamental trigonometric identities)은 삼각함수들 사이에 항상 성립하는 항등식입니다. 주요 관계식은 다음과 같습니다:

**피타고라스 항등식**
$$\sin^2\theta + \cos^2\theta = 1$$

**비율 관계식**
$$\tan\theta = \frac{\sin\theta}{\cos\theta}, \quad \cot\theta = \frac{\cos\theta}{\sin\theta}$$

**역수 관계식**
$$\sec\theta = \frac{1}{\cos\theta}, \quad \csc\theta = \frac{1}{\sin\theta}$$

**확장 항등식** (피타고라스 항등식에서 유도)
$$1 + \tan^2\theta = \sec^2\theta, \quad 1 + \cot^2\theta = \csc^2\theta$$

## 직관 및 기하적 의미

단위원 위의 점을 생각해봅시다. 각 $\theta$에 대응하는 단위원 위의 점의 좌표는 정확히 $(\cos\theta, \sin\theta)$입니다. 이 점이 원점으로부터 거리 1인 단위원 위에 있다는 조건에서, 거리 공식을 적용하면:

$$\sqrt{\cos^2\theta + \sin^2\theta} = 1$$

양변을 제곱하면 피타고라스 항등식을 얻습니다. **즉, 단위원의 정의 자체가 이 항등식의 근본 원인입니다.**

다른 관계식들도 이로부터 유도됩니다. 양변을 $\cos^2\theta$로 나누면 $1 + \tan^2\theta = \sec^2\theta$를 얻고, $\sin^2\theta$로 나누면 $1 + \cot^2\theta = \csc^2\theta$를 얻습니다.

## 예: θ = π/6일 때 검증

$\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$, $\cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$이므로:
$$\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1 \checkmark$$

(`sympy.sin(sympy.pi/6)**2 + sympy.cos(sympy.pi/6)**2` → 1)
