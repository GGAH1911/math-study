# 각도 구하기

> **예제** · 중3 · 단원: [삼각비](/concepts/삼각비)

## 요약
비에서 각 추정

## 본문 (학습 시 채워짐)

### 문제

직각삼각형 ABC에서 ∠C = 90°이고, 빗변 AB = 10 cm, BC = 5 cm입니다. ∠A의 크기를 구하세요.

### 단계별 풀이

**1단계: 주어진 정보 정리**  
직각삼각형에서 ∠A에 대한 대변은 BC이고, 빗변은 AB입니다. 문제에서 이 두 변의 길이를 알고 있으므로 사인 비를 세웁니다.

**2단계: 사인 비 계산**  
$\sin A = \frac{\text{대변}}{\text{빗변}} = \frac{BC}{AB} = \frac{5}{10} = \frac{1}{2}$

사인 값이 1/2라는 것을 얻었으므로, 이제 "사인값이 1/2인 각은 몇도인가?"를 찾으면 됩니다.

**3단계: 삼각비 표에서 각 찾기**  
중3 과정에서 배우는 특수각들의 삼각비 표를 참고하면, $\sin 30° = \frac{1}{2}$입니다.

따라서 $\sin A = \sin 30°$이므로 $A = 30°$입니다.

### 답

∠A = **30°**

### 변형·주의

**비가 특수각이 아닐 때:**  
만약 $\sin A = 0.6$처럼 깔끔한 특수각이 아니면, 계산기나 삼각함수표(더 자세한 표)를 사용해 각을 추정합니다. 중3 교과서는 주로 30°, 45°, 60°의 특수각 문제를 다룹니다.

**다른 삼각비 활용:**  
코사인이나 탄젠트로도 같은 각을 구할 수 있습니다. 예를 들어 $\cos A = \frac{AC}{AB}$로 구하거나, 두 직각변을 아는 경우 $\tan A = \frac{BC}{AC}$를 사용합니다.

**검산:**  
피타고라스 정리로 AC를 먼저 구하면 $AC = \sqrt{10^2 - 5^2} = 5\sqrt{3}$ cm이고, $\tan 30° = \frac{1}{\sqrt{3}}$이므로 $\tan A = \frac{5}{5\sqrt{3}} = \frac{1}{\sqrt{3}}$로 확인할 수 있습니다.
