# 원과 직선의 위치 관계

> **정의** · 중3 · 단원: [원의 성질](/concepts/원의_성질)

## 요약
좌표평면에서 원과 직선의 위치 관계는 원의 중심에서 직선까지의 거리와 반지름의 크기를 비교하거나, 연립 이차방정식의 판별식을 통해 결정됩니다.

## 본문
좌표평면에서 원과 직선이 이루는 위치 관계는 직선이 원과 서로 다른 두 점에서 만나는 경우, 한 점에서 만나며 접하는 경우, 그리고 공통된 점이 없이 만나지 않는 경우의 세 가지 중 하나로 나타납니다.

### 직관과 기하적 의미
원의 중심을 $O(a, b)$, 반지름을 $r$이라 하고, 직선을 $Ax + By + C = 0$이라 할 때, 원의 중심에서 직선까지의 거리 $d$를 이용하여 위치 관계를 판정할 수 있습니다. 이때 거리는 $d = \tfrac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$로 계산됩니다. 중심에서 직선까지의 거리 $d$가 반지름 $r$보다 작으면($d < r$) 직선은 원을 가로지르며 두 점에서 만나고, 거리가 반지름과 같으면($d = r$) 직선은 원에 접하며 한 점에서 만나고, 거리가 반지름보다 크면($d > r$) 직선은 원과 만나지 않습니다.

### 기본 성질
원의 방정식과 직선의 방정식을 연립하여 한 변수를 소거하면 이차방정식이 만들어지며, 이 방정식의 판별식 $D$를 통해서도 위치 관계를 알 수 있습니다. 판별식 $D$가 $0$보다 크면 서로 다른 두 실근을 가져 두 점에서 만나고, $D$가 $0$이면 중근을 가져 한 점에서 접하며, $D$가 $0$보다 작으면 실근이 없어 만나지 않습니다.

## 학습 체크
- 원의 중심에서 직선에 내린 수선의 길이가 반지름보다 작을 때, 교점은 몇 개인가?
- 원의 방정식과 직선의 방정식을 연립했을 때 판별식이 $0$이 된다면 어떤 상태를 의미하는가?

## 관련 개념
- **원의 성질**: 원의 중심과 반지름의 정의를 정확히 알아야 직선과의 거리 비교를 통해 위치 관계를 판정할 수 있습니다.
