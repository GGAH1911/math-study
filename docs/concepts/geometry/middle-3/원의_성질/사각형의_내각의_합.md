### 정확한 진술

모든 사각형의 내각의 합은 $360°$입니다. 즉, 사각형 $ABCD$의 네 내각을 $\angle A, \angle B, \angle C, \angle D$라 하면 다음이 성립합니다:

$$\angle A + \angle B + \angle C + \angle D = 360°$$

이는 볼록 사각형뿐 아니라 오목한 형태의 사각형에도 성립하는 기본 성질입니다(다만 오목사각형의 경우 한 내각을 음수로 다루기도 함).

### 직관과 기하적 의미

사각형을 한 대각선으로 나누면 두 개의 삼각형이 됩니다. 삼각형의 내각의 합이 $180°$이므로, 두 삼각형의 내각의 합을 모두 더하면:

$$180° + 180° = 360°$$

기하학적으로는, 사각형의 한 꼭짓점에서 출발하여 모든 변을 따라 한 바퀴 돌아 돌아올 때 회전각의 총합이 $360°$라는 뜻입니다. 이것이 평면의 "완전한 회전"을 나타냅니다.

원의 성질과의 연결: 원에 내접하는 사각형(원에 내접하는 사각형)의 경우, 대각의 합이 $180°$씩이 되는 특별한 성질이 있는데, 이것도 이 기본 성질 위에 세워집니다.

### 한 줄 예

정사각형은 네 내각이 모두 $90°$이므로 $90° + 90° + 90° + 90° = 360°$; 사다리꼴에서 한 각이 $120°, 95°, 85°$라면 남은 각은 $360° - 300° = 60°$입니다.
