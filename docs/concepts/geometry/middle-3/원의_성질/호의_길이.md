# 호의 길이

> **정의** · 중3 · 단원: [원의 성질](/concepts/원의_성질)

## 요약
호의 길이는 원의 중심각의 크기에 비례하며, 원주에 중심각의 비율을 곱하여 구할 수 있습니다.

## 본문
원 위의 두 점을 잇는 곡선을 호라고 하며, 호의 길이는 이 호의 실제 길이를 나타내는 값입니다. 원의 반지름을 $r$, 호에 대한 중심각을 $\theta$(단위: 도)라고 할 때, 호의 길이 $l$은 다음과 같은 공식으로 정의됩니다:
$$l = \frac{\pi r \theta}{180} = 2\pi r \times \frac{\theta}{360}$$
예를 들어 중심각이 $180^{\circ}$인 경우, 호의 길이는 반원의 둘레인 $\pi r$이 됩니다.

### 직관과 기하적 의미
원의 전체 둘레인 원주는 중심각이 $360^{\circ}$일 때의 길이인 $2\pi r$입니다. 호는 원의 일부분이므로, 전체 원주에서 호가 차지하는 각도의 비율만큼의 길이를 갖게 됩니다. 즉, 호의 길이는 원주에 $\frac{\text{중심각}}{360^{\circ}}$을 곱한 값과 같습니다. 이를 통해 호의 길이는 중심각의 크기에 정확히 비례한다는 사실을 알 수 있습니다.

### 기본 성질
- 호의 길이는 중심각의 크기에 정비례합니다.
- 중심각이 커질수록 호의 길이도 길어지며, 중심각이 $0^{\circ}$에 가까워지면 호의 길이도 $0$에 수렴합니다.
- 반지름이 일정할 때, 호의 길이와 중심각의 크기는 같은 비율을 유지합니다.

## 학습 체크
- 호의 길이를 구할 때 사용하는 공식 두 가지를 서로 같은 의미임을 이용하여 설명할 수 있는가?
- 중심각이 2배, 3배로 커질 때 호의 길이도 같은 비율로 변하는지 확인할 수 있는가?
- 반지름과 중심각이 주어졌을 때, 원주와의 비율 관계를 이용하여 호의 길이를 계산할 수 있는가?

## 관련 개념
- **원의 성질**: 원의 둘레인 원주의 개념을 이해해야 호의 길이를 원주와의 비율로 계산할 수 있습니다.
