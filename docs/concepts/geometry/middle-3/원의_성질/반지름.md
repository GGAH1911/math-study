# 반지름

## 정확한 진술

원의 중심에서 원 위의 한 점까지의 거리를 **반지름**(radius)이라 합니다. 원을 정의하는 가장 기본적인 요소로, 보통 $r$로 나타냅니다. 원의 중심을 $O$, 원 위의 임의의 점을 $P$라 할 때, 반지름은 $r = |OP|$ 입니다. 원의 정의 자체가 "중심에서 거리 $r$인 모든 점의 집합"이므로, 반지름은 원의 크기를 결정하는 핵심 값입니다.

## 직관/기하적 의미

원의 모든 점은 중심으로부터 정확히 같은 거리에 있습니다. 이 거리가 바로 반지름입니다. 반지름이 커질수록 원은 더 커지고, 반지름이 작아지면 원도 작아집니다. 따라서 반지름 하나만 주어져도 원의 크기가 완전히 결정됩니다.

좌표평면에서 중심이 $(a, b)$이고 반지름이 $r$인 원의 방정식은
$$(x - a)^2 + (y - b)^2 = r^2$$
입니다. 특히 중심이 원점인 경우 $x^2 + y^2 = r^2$ 가 됩니다. 이 식은 피타고라스 정리의 직접적인 응용입니다.

또한 반지름의 두 배를 **지름** 또는 **직경**(diameter)이라 하며, $d = 2r$ 입니다.

## 한 줄 예

원의 둘레가 $8\pi$일 때, 원의 반지름은 $r = \frac{8\pi}{2\pi} = 4$ 입니다. (원의 둘레 공식: $C = 2\pi r$)
