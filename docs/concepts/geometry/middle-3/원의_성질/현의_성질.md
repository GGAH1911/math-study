# 현의 성질

> **정의** · 중3 · 단원: [원의 성질](/concepts/원의_성질)

## 요약
원의 중심에서 현에 내린 수선은 현을 이등분하며, 현의 길이와 중심에서의 거리는 반비례 관계에 있습니다.

## 본문
원 위의 서로 다른 두 점을 잇는 선분을 현이라 하며, 원의 지름 또한 현의 일종입니다. 예를 들어 반지름이 $r$인 원 $O$ 위에 두 점 $A, B$가 있을 때, 선분 $AB$는 원 $O$의 현이 됩니다.

### 직관과 기하적 의미
현은 원의 내부를 두 부분으로 나누는 기초적인 요소입니다. 원의 중심에서 현에 이르는 거리가 가까울수록 현의 길이는 길어지고, 중심에서 멀어질수록 현의 길이는 짧아지는 특징을 가집니다.

### 기본 성질
원의 중심 $O$에서 현 $AB$에 내린 수선의 발을 $H$라고 할 때, 수선은 현을 이등분하여 $AH = HB = \tfrac{1}{2}AB$가 성립합니다. 또한 중심에서 현까지의 거리를 $d$, 현의 길이를 $l$, 반지름을 $r$이라 하면 피타고라스 정리에 의해 $d^2 + \left(\tfrac{l}{2}\right)^2 = r^2$이라는 관계식이 성립합니다. 따라서 같은 원에서 현의 길이가 길수록 중심에서의 거리는 짧고, 현의 길이가 짧을수록 중심에서의 거리는 깁니다.

## 학습 체크
- 원의 중심에서 현에 내린 수선이 현을 이등분하는지 확인할 수 있는가?
- 피타고라스 정리를 이용하여 현의 길이와 중심 사이의 거리를 계산할 수 있는가?
- 현의 길이와 중심에서의 거리 사이의 상관관계를 이해하고 있는가?

## 관련 개념
- **원의 성질**: 원의 중심, 반지름, 현의 관계를 통해 원의 기하학적 구조를 이해하는 기초가 됩니다.
