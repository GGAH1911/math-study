# 접선의 길이 예제

> **예제** · 중3 · 단원: [원의 성질](/concepts/원의_성질)

## 요약
원의 외부 한 점에서 원에 그은 접선의 길이는 원의 중심과 외부 점 사이의 거리, 그리고 원의 반지름을 이용하여 피타고라스 정리로 구할 수 있습니다.

## 본문
원의 중심을 O, 반지름을 $5\text{ cm}$라고 하자. 원 밖의 점 A가 O로부터 $13\text{ cm}$ 떨어져 있을 때, A에서 원에 그은 접선이 원과 만나는 점을 P라고 하자. 접선의 길이 AP를 구하여라.

### 단계별 풀이
**1단계: 상황 파악**
A에서 원에 그은 접선이므로, 접점 P에서 반지름 OP는 접선 AP에 수직입니다. 이는 원의 중요한 성질입니다. 따라서 삼각형 OPA는 P에서 직각을 이루는 직각삼각형입니다.

**2단계: 주어진 조건 정리**
- $OP = 5\text{ cm}$ (반지름)
- $OA = 13\text{ cm}$ (중심에서 외부 점까지 거리)
- $\angle OPA = 90^\circ$ (접선의 성질)

**3단계: 피타고라스 정리 적용**
직각삼각형 OPA에서 다음 식이 성립합니다:
$$OA^2 = OP^2 + AP^2$$
$$13^2 = 5^2 + AP^2$$
$$169 = 25 + AP^2$$
$$AP^2 = 144$$
$$AP = 12\text{ cm}$$

### 답과 변형
**답: 접선의 길이는 $12\text{ cm}$입니다.**

**변형 및 주의사항**
- **변형 1:** A에서 원에 그을 수 있는 접선은 실제로 2개이며, 두 접선의 길이는 항상 같습니다.
- **변형 2:** $OA = 13, OP = 5$일 때, $\sin(\angle AOP) = \tfrac{5}{13}$을 이용하여 각의 크기를 구하는 문제로 확장할 수 있습니다.
- **주의:** 중심에서 접선에 내린 수선은 반드시 접점을 지난다는 성질을 이용해 직각삼각형을 만드는 것이 핵심입니다.
