# 접선-현 정리

> **정의** · 중3 · 단원: [원의 성질](/concepts/원의_성질)

## 요약
원 위의 한 점에서의 접선과 현이 이루는 각의 크기는 그 현에 대한 원주각의 크기와 같습니다.

## 본문
원 위의 한 점 $P$에서 그은 접선과, $P$를 포함하는 현 $PQ$가 이루는 각의 크기는 호 $PQ$에 대한 원주각의 크기와 같습니다. 즉, 원 위의 다른 점 $R$에서 호 $PQ$를 바라보는 원주각 $\angle PRQ$의 크기는 접선과 현 $PQ$가 이루는 각의 크기와 항상 일치합니다.

### 직관과 기하적 의미
접선은 원과 단 한 점에서만 만나는 특수한 직선이므로, 접선을 현의 길이가 $0$에 가까워지는 극한의 상태로 이해하면 원주각의 성질과 자연스럽게 연결됩니다. 기하학적으로 접근하면, 원의 중심 $O$에서 접점 $P$에 그은 반지름 $OP$는 접선과 항상 수직($90^\circ$)을 이룹니다. 이 직각 조건과 중심각이 원주각의 두 배라는 성질을 결합하면, 접선과 현이 이루는 각이 해당 현이 마주 보는 원주각과 같음을 논리적으로 증명할 수 있습니다.

### 기본 성질
원의 중심이 $O$이고 점 $P$에서의 접선이 현 $PQ$와 이루는 각이 $35^\circ$라면, 호 $PQ$를 바라보는 원 위의 임의의 점 $R$에서의 원주각 $\angle PRQ$ 역시 $35^\circ$가 됩니다.

## 학습 체크
- 접선과 현이 이루는 각이 주어졌을 때, 해당 현에 대한 원주각의 크기를 바로 구할 수 있는가?
- 접선과 반지름이 수직이라는 성질을 이용하여 접선-현 정리를 유도할 수 있는가?

## 관련 개념
- **원의 성질**: 원주각과 중심각의 관계를 통해 접선-현 정리를 기하학적으로 증명할 수 있는 기초가 됩니다.
