# 반원의 원주각

지름을 한 변으로 보는 원주각이 항상 직각이라는 정리입니다. 중3 원의 성질 단원의 대표 결과로, 탈레스 정리로도 알려져 있습니다.

## 정의

원 위의 한 점 $\mathrm{P}$에서 지름 $\overline{\mathrm{AB}}$를 바라보는 원주각 $\angle \mathrm{APB}$는 항상 $90^\circ$입니다. 즉,
$$\mathrm{P} \in \text{원 위},\ \overline{\mathrm{AB}}\ \text{는 지름} \implies \angle \mathrm{APB} = 90^\circ.$$

이는 일반적인 원주각 정리(원주각은 같은 호에 대한 중심각의 절반)의 특수한 경우이며, 지름에 대응하는 중심각이 평각 $180^\circ$이므로 원주각은 $90^\circ$가 됩니다.

역으로, 어떤 점이 선분 $\overline{\mathrm{AB}}$를 직각으로 바라본다면 그 점은 $\overline{\mathrm{AB}}$를 지름으로 하는 원 위에 있습니다.

## 예시

지름이 $\overline{\mathrm{AB}} = 10$인 원 위의 점 $\mathrm{P}$에 대해 $\overline{\mathrm{AP}} = 6$이면 $\angle \mathrm{APB} = 90^\circ$이므로 직각삼각형 $\triangle \mathrm{APB}$에서
$$\overline{\mathrm{BP}} = \sqrt{10^2 - 6^2} = 8.$$
