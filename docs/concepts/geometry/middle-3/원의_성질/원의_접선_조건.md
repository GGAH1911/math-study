# 원의 접선 조건

## 정확한 진술

원 $C: (x-a)^2 + (y-b)^2 = r^2$과 직선 $l$이 있을 때, **원의 중심에서 직선까지의 거리가 반지름과 같으면 그 직선은 원의 접선**입니다.

원의 중심 $(a, b)$에서 직선 $Ax + By + C = 0$까지의 거리는

$$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$$

**접선의 조건**: $d = r$

## 직관과 기하적 의미

원 위의 한 점을 지나는 직선이 원과 만나는 방식은 거리에 따라 결정됩니다. 원의 중심에서 직선까지의 거리가 작아질수록 직선이 중심에 가까워집니다.

- 거리 $< r$: 직선이 원과 **두 점**에서 만남 (할선)
- 거리 $= r$: 직선이 원과 **한 점**에서 만남 (접선)
- 거리 $> r$: 직선이 원과 **만나지 않음**

즉, **접선은 중심으로부터 거리가 정확히 반지름인 직선들**입니다. 이 조건은 접선의 정의 "원과 정확히 한 점에서 만나는 직선"을 거리로 나타낸 것입니다.

## 예시와 검증

중심 $(0, 0)$, 반지름 $5$인 원 $x^2 + y^2 = 25$에 대해 직선 $3x + 4y - 25 = 0$이 접선인지 확인합니다.

중심에서 직선까지의 거리:
$$d = \frac{|3(0) + 4(0) - 25|}{\sqrt{9+16}} = \frac{25}{5} = 5$$

거리가 반지름 $5$와 같으므로 **이 직선은 원의 접선**입니다. 접점은 $(4, 3)$입니다.

검증 코드: `from sympy import symbols, solve; x, y = symbols('x y'); solve([x**2 + y**2 - 25, 3*x + 4*y - 25], [x, y])`
