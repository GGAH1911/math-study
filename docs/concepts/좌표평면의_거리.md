# 좌표평면의 거리

## 요약
두 점 사이의 거리는 피타고라스 정리를 이용하여 좌표평면 위 두 점 사이의 직선 거리를 구하는 것입니다.

## 본문
좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$로 정의합니다. 이는 두 점을 빗변으로 하는 직각삼각형을 상상했을 때, 가로 길이인 $|x_2-x_1|$과 세로 길이인 $|y_2-y_1|$을 각각 밑변과 높이로 하여 피타고라스 정리를 적용한 결과와 같습니다.

### 직관과 기하적 의미
두 점 사이의 거리는 두 점을 잇는 가장 짧은 직선의 길이를 의미합니다. 좌표평면에서 두 점 사이의 거리를 구하는 과정은 수직인 두 축의 차이를 이용하여 대각선의 길이를 찾는 기하학적 원리를 담고 있습니다.

### 기본 성질
두 점의 좌표 순서가 바뀌어도 제곱을 통해 계산하므로 거리는 항상 양수이며, 두 점이 일치할 때만 거리는 $0$이 됩니다. 또한, 거리 공식은 평면 위에서 두 점 사이의 최단 경로를 나타내는 유클리드 거리의 개념을 수학적으로 공식화한 것입니다.

## 학습 체크
- 두 점의 좌표를 공식에 대입할 때 $x$좌표와 $y$좌표를 혼동하지 않고 정확히 매칭하였는가?
- 계산 과정에서 제곱을 통해 음수가 양수로 변하는 과정을 정확히 처리하였는가?

## 관련 개념
- **지수함수와 로그함수**: 좌표평면 위에서 지수함수나 로그함수의 그래프 위의 두 점 사이의 거리를 구할 때 이 공식을 동일하게 적용합니다.
