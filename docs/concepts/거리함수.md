### 정확한 진술

거리함수(distance function)란 두 점, 또는 점과 도형 사이의 거리를 구하는 함수입니다. 고등학교 수학에서 가장 기본적인 경우는 좌표평면 위의 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ 사이의 거리로, 다음과 같이 정의됩니다:

$$d(P, Q) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

더 일반적으로, 점 $P$와 도형(직선, 원, 평면 등) 사이의 거리는 "점에서 도형 위의 모든 점까지의 거리 중 최솟값"으로 정의합니다. 예를 들어 점 $P(x_0, y_0)$과 직선 $ax + by + c = 0$ 사이의 거리는:

$$d = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$

### 직관과 기하적 의미

거리함수는 두 객체가 얼마나 "떨어져 있는지"를 수량화합니다. 피타고라스 정리에 기초하여, 좌표평면의 두 점 사이 거리는 가로 거리와 세로 거리를 직각삼각형의 두 변으로 보면 빗변의 길이입니다. 점과 직선 사이의 거리는 점에서 직선에 내린 수선의 발까지의 거리로, 직선 위의 다른 어떤 점까지의 거리보다 항상 짧습니다.

### 한 줄 예

점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$입니다.

검산: `sympy.sqrt((4-1)**2 + (6-2)**2)` → 5
