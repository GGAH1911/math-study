# 이차방정식 근의 합

## 요약
이차방정식의 두 근의 합은 계수의 비율을 이용하여 근을 직접 구하지 않고도 구할 수 있는 값입니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)의 두 근을 $\alpha, \beta$라고 할 때, 두 근의 합 $\alpha + \beta$는 $-\frac{b}{a}$와 같습니다. 이는 근의 공식 $\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 통해 유도할 수 있는 결과로, 두 근을 더하면 루트를 포함한 항이 서로 상쇄되어 계수들의 조합으로만 표현됩니다. 따라서 방정식의 계수만 알고 있다면 복잡한 계산 과정 없이도 두 근의 합을 즉각적으로 찾아낼 수 있습니다.

### 직관과 기하적 의미
이차함수 $y = ax^2 + bx + c$의 그래프 관점에서 볼 때, 두 근의 합은 그래프의 대칭축과 밀접한 관련이 있습니다. 이차함수의 대칭축의 방정식은 $x = -\frac{b}{2a}$이며, 이는 두 근의 평균값과 같습니다. 즉, 두 근의 합은 대칭축의 위치를 두 배 한 값과 동일하며, 그래프가 $x$축과 만나는 두 지점의 중심 위치를 나타냅니다.

### 기본 성질
이 성질은 근의 판별식 $D = b^2 - 4ac$의 값과 관계없이 항상 성립합니다. 실근을 갖는 경우뿐만 아니라 허근을 갖는 경우에도 계수의 비율만으로 합을 구할 수 있다는 점이 핵심입니다. 또한, 이는 근과 계수의 관계 중 가장 기초적인 부분으로, 이후 근과 계수의 관계를 통해 두 근의 곱을 구하는 과정으로 확장됩니다.

## 학습 체크
- 이차방정식의 $x$항 계수가 $0$인 경우, 두 근의 합은 무엇이 되는가?
- 근의 공식을 이용하여 $\alpha + \beta = -\frac{b}{a}$임을 직접 유도할 수 있는가?
- 이차함수의 대칭축의 방정식과 두 근의 합 사이의 관계를 설명할 수 있는가?

## 관련 개념
- **이차방정식**: 근의 합은 이차방정식의 해를 구하는 과정 없이 계수만으로 해의 특성을 파악하게 해주는 도구입니다.
- **근과 계수의 관계**: 이차방정식의 두 근의 합과 곱을 계수들로 나타낸 일반적인 원리 중 하나입니다.
- **이차함수**: 그래프의 대칭축 위치를 결정하는 요소로서 근의 합과 연결됩니다.
