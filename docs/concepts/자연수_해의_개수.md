### 정확한 진술

$x_1 + x_2 + \cdots + x_n = k$ 형태의 **선형방정식**에서, 모든 변수가 자연수(양의 정수)인 해의 개수를 구하는 것입니다. 여기서 $k$는 양의 정수, $n$은 변수의 개수입니다.

### 직관과 조합론적 의미

이 문제는 "같은 것이 있는 순열"과 본질적으로 같습니다. $k$개의 동일한 공을 $n$명에게 나누어 주되, 각 사람이 최소 1개 이상 받아야 한다는 상황이죠. 

조합론으로 해결하려면 **변수 치환**을 사용합니다. $y_i = x_i - 1$로 놓으면 ($i = 1, 2, \ldots, n$), 각 $y_i \geq 0$이고 다음을 만족합니다:

$$y_1 + y_2 + \cdots + y_n = k - n$$

이제 음이 아닌 정수 해의 개수는 중복조합 공식으로:

$$\binom{(k-n)+n-1}{n-1} = \binom{k-1}{n-1}$$

### 구체적 예시

$x + y + z = 5$의 자연수 해의 개수를 구하세요. $k=5$, $n=3$이므로:

$$\binom{5-1}{3-1} = \binom{4}{2} = 6$$

실제 해: $(1,1,3), (1,2,2), (1,3,1), (2,1,2), (2,2,1), (3,1,1)$ — 정확히 6가지입니다. 

(`from math import comb; comb(4, 2)  # = 6`)

### 주의: 자연수 vs 음이 아닌 정수

**자연수** 해(1 이상)는 반드시 변수 치환이 필요합니다. 만약 문제가 "0 이상의 정수 해"라면 변수 치환 없이 바로 $\binom{k+n-1}{n-1}$을 사용합니다. 문제 조건을 정확히 읽어야 합니다.
