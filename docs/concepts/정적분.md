# 정적분

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
$\int_a^b f(x)dx$

## 본문 (학습 시 채워짐)

### 정확한 진술

함수 $f(x)$가 닫힌 구간 $[a, b]$에서 연속이고, $F(x)$가 $f(x)$의 부정적분(즉, $F'(x) = f(x)$)일 때, $a$부터 $b$까지의 **정적분**은 다음과 같이 정의합니다:

$$\int_a^b f(x)dx = F(b) - F(a)$$

우리는 종종 $F(b) - F(a)$를 $[F(x)]_a^b$로 표기합니다. 이것이 미적분학의 기본정리(Fundamental Theorem of Calculus)입니다.

### 직관/기하적 의미

정적분 $\int_a^b f(x)dx$는 **곡선 $y=f(x)$와 $x$축 사이의 부호가 있는 넓이**를 나타냅니다. $f(x) \geq 0$인 구간에서는 위쪽 넓이가 양수, $f(x) < 0$인 구간에서는 아래쪽 넓이가 음수로 계산됩니다.

왜 부정적분의 차이가 넓이일까요? 부정적분 $F(x)$는 $0$부터 $x$까지의 누적 넓이를 나타냅니다. 따라서 $F(b) - F(a)$는 $a$에서 $b$까지의 "추가된" 넓이 — 즉, 정적분입니다. 이것이 미적분과 기하의 가장 아름다운 연결고리입니다.

### 한 줄 예

$f(x) = 2x$일 때, $\int_1^3 2x\,dx = [x^2]_1^3 = 3^2 - 1^2 = 9 - 1 = 8$입니다. (검산: `from sympy import integrate, symbols; x = symbols('x'); integrate(2*x, (x, 1, 3))`)

이는 $x=1$에서 $x=3$ 사이, 직선 $y=2x$ 아래의 넓이가 8이라는 뜻입니다.
