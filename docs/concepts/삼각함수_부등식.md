# 삼각함수 부등식

## 요약
삼각함수 부등식은 삼각함수가 포함된 식의 부등호를 만족하는 각 $x$의 범위를 구하는 문제로, 삼각함수의 주기성을 고려하여 단위원이나 그래프를 통해 해를 구한다.

## 본문
삼각함수 부등식은 $\sin x$, $\cos x$, $\tan x$ 등을 포함한 식이 특정 값보다 크거나 작은 $x$의 범위를 구하는 문제다. 삼각함수는 주기함수이므로 부등식의 해는 하나의 구간이 아니라 무수히 많은 구간의 합집합으로 나타날 수 있다. 따라서 문제를 풀 때는 반드시 단위원 또는 그래프를 활용해 시각적으로 접근하는 것이 효과적이다.

### 직관과 기하적 의미
삼각함수의 부등식은 단위원 위에서 특정 좌표의 위치를 찾는 과정과 같다. 예를 들어 $\sin x \geq k$는 단위원에서 $y$좌표가 $k$ 이상인 지점들을 찾는 것이고, $\cos x < k$는 $x$좌표가 $k$ 미만인 지점들을 찾는 것이다. $\tan x > k$의 경우에는 단위원 위에서 기울기가 $k$보다 큰 직선과 만나는 호의 범위를 찾는 것으로 이해할 수 있다.

### 기본 성질
부등식을 해결하기 위한 기본 전략은 다음과 같다. 먼저 주어진 부등식을 $\sin x \geq k$, $\cos x < k$, $\tan x > k$ 형태로 정리한다. 그 다음 단위원 위에서 $y = k$ (또는 $x = k$, $y/x = k$) 직선과 교점을 찾아 등호가 성립하는 각도를 구한다. 부등호의 방향에 따라 조건을 만족하는 호의 범위를 읽어낸 뒤, 문제에서 요구하는 범위가 $0 \leq x < 2\pi$와 같이 한 주기로 제한되어 있다면 해당 구간 안의 해만 적고, 그렇지 않다면 주기 $2\pi$를 더한 일반해로 확장하여 나타낸다.

**예시 1.** $0 \leq x < 2\pi$일 때 $\sin x \geq \tfrac{\sqrt{3}}{2}$를 풀어라.
$\sin x = \tfrac{\sqrt{3}}{2}$가 되는 각도는 $x = \tfrac{\pi}{3}$과 $x = \tfrac{2\pi}{3}$이다. 단위원에서 $y$좌표가 $\tfrac{\sqrt{3}}{2}$ 이상인 호는 두 교점 사이의 위쪽 호이므로 $\tfrac{\pi}{3} \leq x \leq \tfrac{2\pi}{3}$이다.

**예시 2.** $0 \leq x < 2\pi$일 때 $\cos x < -\tfrac{1}{2}$를 풀어라.
$\cos x = -\tfrac{1}{2}$가 되는 각도는 $x = \tfrac{2\pi}{3}$과 $x = \tfrac{4\pi}{3}$이다. 단위원에서 $x$좌표가 $-\tfrac{1}{2}$ 미만인 호는 두 교점 사이의 왼쪽 호이므로 $\tfrac{2\pi}{3} < x < \tfrac{4\pi}{3}$이다.

## 학습 체크
- 삼각함수의 주기성 때문에 해가 여러 구간으로 나타날 수 있음을 인지하고 있는가?
- 부등식의 방향에 따라 단위원에서 어떤 좌표(x 또는 y)의 범위를 확인해야 하는지 알고 있는가?
- 문제에서 주어진 $x$의 범위가 한 주기인지, 아니면 일반해를 구해야 하는 상황인지 구분할 수 있는가?

## 관련 개념

**삼각함수** — 부등식의 뼈대를 이루는 $\sin$, $\cos$, $\tan$의 정의와 단위원 위에서의 값 분포를 알아야 교점의 각도를 정확히 읽을 수 있다.

**삼각부등식** — 삼각함수 부등식의 상위 범주로, 주기성에 따라 해가 반복되는 구조를 다룬다. 삼각함수 부등식은 삼각부등식을 삼각함수 그래프·단위원으로 구체화한 것이다.

**삼각함수의 그래프** — 해의 구간을 시각적으로 확인하는 보조 수단이다. $y = \sin x$ 그래프 위에 $y = k$ 직선을 그었을 때 그래프가 직선보다 위에 있는 구간이 $\sin x > k$의 해가 된다.

**삼각방정식** — 등호가 성립하는 특정 각도를 구하는 문제로, 부등식 풀이에서 경계값(등호 성립점)을 찾는 첫 단계가 삼각방정식의 풀이와 동일하다.

**일반각** — 한 주기 안의 해를 구한 뒤 $2n\pi$($n$은 정수)를 더해 전체 실수 범위의 해를 표현할 때 쓰는 개념이다.
