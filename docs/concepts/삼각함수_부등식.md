# 삼각함수 부등식

삼각함수 부등식은 $\sin x$, $\cos x$, $\tan x$ 등을 포함한 식이 특정 값보다 크거나 작은 $x$의 범위를 구하는 문제다.

삼각함수는 주기함수이므로 부등식의 해는 하나의 구간이 아니라 무수히 많은 구간의 합집합으로 나타난다. 이 때문에 풀이는 반드시 **단위원** 또는 **그래프**를 활용해 시각적으로 접근해야 한다.

기본 전략은 다음과 같다.

1. 주어진 부등식을 $\sin x \geq k$, $\cos x < k$, $\tan x > k$ 형태로 정리한다.
2. 단위원 위에서 $y = k$ (또는 $x = k$, $y/x = k$) 직선과 교점을 찾아 등호가 성립하는 각도를 구한다.
3. 부등호 방향에 따라 조건을 만족하는 호(arc)의 범위를 읽는다.
4. 주기 $2\pi$를 더한 일반해로 확장한다.

범위가 $0 \leq x < 2\pi$처럼 한 주기로 제한된 경우에는 그 구간 안의 해만 적는다.

## 예시

**예시 1.** $0 \leq x < 2\pi$일 때 $\sin x \geq \dfrac{\sqrt{3}}{2}$를 풀어라.

$\sin x = \dfrac{\sqrt{3}}{2}$가 되는 각도는 $x = \dfrac{\pi}{3}$과 $x = \dfrac{2\pi}{3}$이다. 단위원에서 $y$좌표가 $\dfrac{\sqrt{3}}{2}$ **이상**인 호는 두 교점 사이의 위쪽 호이므로

$$\frac{\pi}{3} \leq x \leq \frac{2\pi}{3}$$

---

**예시 2.** $0 \leq x < 2\pi$일 때 $\cos x < -\dfrac{1}{2}$를 풀어라.

$\cos x = -\dfrac{1}{2}$가 되는 각도는 $x = \dfrac{2\pi}{3}$과 $x = \dfrac{4\pi}{3}$이다. 단위원에서 $x$좌표가 $-\dfrac{1}{2}$ **미만**인 호는 두 교점 사이의 왼쪽 호이므로

$$\frac{2\pi}{3} < x < \frac{4\pi}{3}$$

## 관련 개념

**삼각함수** — 부등식의 뼈대를 이루는 $\sin$, $\cos$, $\tan$의 정의와 단위원 위에서의 값 분포를 알아야 교점의 각도를 정확히 읽을 수 있다.

**삼각부등식** — 삼각함수 부등식의 상위 범주로, 주기성에 따라 해가 반복되는 구조를 다룬다. 삼각함수 부등식은 삼각부등식을 삼각함수 그래프·단위원으로 구체화한 것이다.

**삼각함수의 그래프** — 해의 구간을 시각적으로 확인하는 보조 수단이다. $y = \sin x$ 그래프 위에 $y = k$ 직선을 그었을 때 그래프가 직선보다 위에 있는 구간이 $\sin x > k$의 해가 된다.

**삼각방정식** — 등호가 성립하는 특정 각도를 구하는 문제로, 부등식 풀이에서 경계값(등호 성립점)을 찾는 첫 단계가 삼각방정식의 풀이와 동일하다.

**일반각** — 한 주기 안의 해를 구한 뒤 $2n\pi$($n$은 정수)를 더해 전체 실수 범위의 해를 표현할 때 쓰는 개념이다.
