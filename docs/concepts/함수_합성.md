# 함수 합성

## 요약
두 함수를 결합하여 하나의 새로운 함수를 만드는 연산 과정입니다.

## 본문
두 함수 $f$와 $g$가 있을 때, $x$를 $g$에 먼저 대입하여 얻은 결과값을 다시 $f$에 대입하여 얻는 새로운 함수를 합성함수라고 하며, 이를 $f \circ g$ 또는 $(f \circ g)(x)$로 나타냅니다. 즉, $(f \circ g)(x) = f(g(x))$입니다. 이때 합성함수가 정의되기 위해서는 함수 $g$의 치역이 함수 $f$의 정의역의 부분집합이어야 한다는 조건이 필요합니다.

### 직관과 기하적 의미
합성함수는 두 개의 연산 과정을 하나의 연속된 흐름으로 연결하는 것과 같습니다. 입력값 $x$가 첫 번째 함수 $g$를 통과하여 중간 결과물인 $g(x)$를 만들어내고, 이 결과물이 다시 두 번째 함수 $f$의 입력값이 되어 최종적인 결과 $f(g(x))$를 도출합니다. 기하학적으로는 좌표평면 위에서 한 함수의 그래프를 다른 함수의 입력값 변화에 따라 변형시키거나, 두 변환을 순차적으로 적용하여 새로운 곡선을 그려내는 과정으로 이해할 수 있습니다.

### 기본 성질
합성함수는 일반적으로 교환법칙이 성립하지 않습니다. 즉, $f \circ g$와 $g \circ f$는 서로 다른 함수인 경우가 대부분입니다. 다만, 결합법칙은 성립하여 $(f \circ g) \circ h = f \circ (g \circ h)$가 항상 성립합니다. 또한, 어떤 함수 $f$를 자기 자신과 합성하여 항등함수가 되는 함수 $f^{-1}$가 존재할 때, 이를 역함수라고 합니다.

## 학습 체크
- 합성함수의 정의역을 결정할 때 $g(x)$의 치역과 $f$의 정의역 사이의 관계를 고려하였는가?
- 합성함수의 계산에서 연산 순서가 결과에 미치는 영향(교환법칙 성립 여부)을 이해하고 있는가?

## 관련 개념
- **정적분의 활용**: 합성함수의 형태를 가진 함수를 적분할 때, 치환적분법을 사용하여 복잡한 식을 단순화하여 계산할 수 있습니다.
