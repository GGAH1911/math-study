# 거듭제곱함수 미분

## 정의

**거듭제곱함수**란 $f(x) = x^r$ ($r$은 실수) 꼴의 함수이다. 이를 미분하면 거듭제곱 법칙에 의해

$$\frac{d}{dx} x^r = r x^{r-1}$$

이 성립한다. $r$이 양의 정수일 때는 다항함수의 미분, $r = \dfrac{1}{n}$일 때는 무리함수($\sqrt[n]{x}$)의 미분, $r$이 음의 정수일 때는 유리함수의 미분에 대응된다.

## 예시

$f(x) = x^{1/2} = \sqrt{x}$ ($x > 0$)를 미분하시오.

$$f'(x) = \frac{1}{2} x^{1/2 - 1} = \frac{1}{2} x^{-1/2} = \frac{1}{2\sqrt{x}}$$

또한 $g(x) = x^{-2} = \dfrac{1}{x^2}$이면

$$g'(x) = -2x^{-3} = -\frac{2}{x^3}$$

## 관련 개념

- 거듭제곱의 미분(Power Rule)
- 지수법칙
- 합성함수의 미분(Chain Rule)
- 무리함수
