### 정확한 진술

두 각 $\alpha$와 $\beta$의 동경(terminal side)이 일치할 필요충분조건은 다음과 같습니다.

$$\beta = \alpha + 360° \cdot k \quad \text{(단, } k \text{는 정수)}$$

또는 라디안 단위로는:

$$\beta = \alpha + 2\pi k \quad \text{(단, } k \text{는 정수)}$$

### 직관과 기하적 의미

좌표평면의 원점에서 각을 그릴 때, 동경은 시작선(보통 양의 $x$축)으로부터 회전한 반직선입니다. 두 각의 동경이 같은 방향을 가리킨다는 것은 회전 각도는 다르지만 '최종 위치'가 같다는 뜻입니다.

예를 들어, 시침이 12시 방향을 가리키는 상태에서:
- 360° 회전하면 다시 같은 위치
- 720° 회전해도 같은 위치  
- −360° 회전(시계방향)해도 같은 위치

즉, 처음 각 $\alpha$에서 **몇 바퀴를 더 도는지**($360° \times k$)에 관계없이, 최종적으로 같은 동경에 도달합니다.

### 한 줄 예

$30°$와 $390°$의 동경은 일치합니다. ($390° = 30° + 360° \times 1$)

또 다른 예: $\frac{\pi}{4}$와 $\frac{\pi}{4} + 2\pi$의 동경도 일치합니다.

### 응용

같은 삼각함수값을 갖는 각들을 찾을 때 핵심입니다. 예를 들어 $\sin 30° = \sin 390°$인 이유는 두 각의 동경이 일치하기 때문입니다.
