# 2차원 규칙 구조

## 요약
행과 열이라는 두 개의 인덱스를 사용하여 수열이나 규칙적 배열을 표 형태로 나타낸 구조이다.

## 본문
수열이나 규칙적 배열을 행(가로)과 열(세로) 두 방향으로 정리한 표 형태의 구조를 2차원 규칙 구조라 한다. 행 번호 $m$과 열 번호 $n$의 두 인덱스를 이용해 각 항의 값 또는 위치를 나타낸다. 수능에서는 행마다 공차나 공비가 다르거나 열마다 별도의 수열이 정의되는 이중 규칙 형태로 자주 출제되며, 특정 항을 찾거나 합을 구하는 문제에 핵심적으로 활용된다.

### 직관과 기하적 의미
2차원 규칙 구조는 평면 위의 격자점(lattice point)에 숫자를 배치하는 것과 유사한 의미를 갖는다. 1차원 수열이 직선상의 위치를 나타낸다면, 2차원 구조는 가로축과 세로축이라는 두 가지 변수를 동시에 고려하여 데이터의 위치를 좌표처럼 정의한다. 이를 통해 단순한 나열을 넘어 평면적인 패턴을 시각화할 수 있다.

### 기본 성질
일반적으로 $m$행 $n$열에 위치한 항의 값은 행과 열의 인덱스 $m, n$에 대한 함수 $f(m, n)$으로 표현된다. 예를 들어, 자연수를 순차적으로 채워 나가는 경우 $m$행 $n$열의 수는 $3(m-1) + n$과 같이 행의 크기와 현재 위치를 결합한 식으로 나타낼 수 있다. 규칙이 복잡해질수록 행의 변화량과 열의 변화량을 분리하여 분석하는 것이 중요하다.

## 학습 체크
- $m$행 $n$열의 일반항을 구하기 위해 행과 열의 변화 규칙을 어떻게 분리하여 식을 세울 것인가?
- 행의 번호가 증가함에 따라 각 행의 첫 번째 항이 어떤 수열을 이루는지 파악하였는가?
- 주어진 표에서 특정 항의 위치를 찾을 때 행과 열의 인덱스를 혼동하지 않고 적용하였는가?
