- 중복순열·중복조합·이항정리를 활용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 중복순열, 중복조합
- 이항계수

**정리(theorem)**
- 중복순열 $n^r$, 중복조합 $_{n+r-1}C_r$
- 이항정리 $(a+b)^n = \sum_k {}_nC_k a^{n-k}b^k$

**예제(example)**
- 중복 있는 줄세우기
- 구분 안 되는 공 나누기
- 이항계수 항 구하기
