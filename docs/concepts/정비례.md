# 정비례

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
$y=ax$ 관계

## 본문 (학습 시 채워짐)

### 정확한 진술

두 수 $x$와 $y$의 관계가 $y = ax$ (단, $a \neq 0$인 상수) 형태로 나타날 때, **$y$는 $x$에 정비례한다**고 말합니다. 이때 $a$를 **비례상수**라고 부릅니다.

달리 표현하면, $x$의 값이 변할 때 $y$의 값도 같은 비율로 변합니다. 예를 들어 $x$가 2배가 되면 $y$도 2배가 되고, $x$가 $\frac{1}{3}$로 줄어들면 $y$도 $\frac{1}{3}$로 줄어듭니다.

### 직관과 그래프의 의미

정비례 관계 $y = ax$는 좌표평면 위에서 **원점을 지나는 일직선**으로 나타납니다. 

- $a > 0$일 때: 그래프는 제1, 3사분면을 지나며 왼쪽 아래에서 오른쪽 위로 향합니다.
- $a < 0$일 때: 그래프는 제2, 4사분면을 지나며 왼쪽 위에서 오른쪽 아래로 향합니다.

비례상수 $a$는 이 일직선의 **기울기**를 나타냅니다. $|a|$가 클수록 그래프는 더 급해집니다.

### 구체적인 예

**상황:** 한 상품이 개당 3,000원일 때, 구입한 개수 $x$와 총 가격 $y$의 관계

이 경우 $y = 3000x$이고, 비례상수는 3,000입니다. 
- $x = 1$일 때 $y = 3000$
- $x = 2$일 때 $y = 6000$
- $x = 3$일 때 $y = 9000$

이 점들 $(1, 3000)$, $(2, 6000)$, $(3, 9000)$을 좌표평면에 나타내면 원점을 지나는 일직선 위에 모두 놓입니다.

검산 예시: `sympy.solve(3000*x - y, y)` → $y = 3000x$
