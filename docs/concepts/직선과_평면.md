### 정확한 진술

3차원 공간에서 **직선**은 한 점 $P_0 = (x_0, y_0, z_0)$을 지나고 영이 아닌 방향벡터 $\vec{d} = (a, b, c)$로 정의되는 일차원 도형입니다. 매개변수 방정식으로는 다음과 같이 나타냅니다:

$$P = P_0 + t\vec{d}, \quad t \in \mathbb{R}$$

**평면**은 한 점 $P_0 = (x_0, y_0, z_0)$을 지나고 영이 아닌 법선벡터 $\vec{n} = (A, B, C)$에 수직인 이차원 도형입니다. 평면의 방정식은:

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

### 직관과 기하적 의미

직선은 공간의 한 점에서 출발하여 일정한 방향으로 무한히 뻗어나가는 자취입니다. 방향벡터는 직선이 "어느 방향으로 움직이는지"를 나타내며, 이 벡터에 평행한 모든 벡터도 같은 직선을 나타냅니다.

평면은 무한히 펼쳐진 2차원 곡면으로, 공간을 두 개의 반공간으로 나눕니다. 법선벡터는 평면에 수직인 방향을 가리키므로, 법선벡터를 알면 평면이 공간에서 어떻게 향하고 있는지를 완전히 알 수 있습니다. 실제로 법선벡터의 방향이 바뀌면 평면의 기울기가 바뀝니다.

### 한 줄 예

점 $(1, 2, 3)$을 지나고 방향벡터 $(1, -1, 2)$인 직선: $\vec{r}(t) = (1 + t, 2 - t, 3 + 2t)$

점 $(1, 0, -1)$을 지나고 법선벡터 $(2, 1, 3)$인 평면: $2(x-1) + 1(y-0) + 3(z+1) = 0$, 즉 $2x + y + 3z = -1$
