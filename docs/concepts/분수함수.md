# 분수함수

## 요약
분수함수는 $f(x) = \frac{k}{x - p} + 3$ 꼴의 함수로, 점 $(p, q)$를 기준으로 대칭이며 $x=p$와 $y=q$를 점근선으로 갖는 쌍곡선 그래프를 그리는 함수이다.

## 본문
분수함수는 $f(x) = \frac{k}{x - p} + q$ ($k \neq 0$) 꼴로 나타내어지는 함수를 의미한다. 이 함수의 그래프는 쌍곡선의 형태를 띠며, 두 개의 점근선을 갖는 것이 가장 큰 특징이다. 이때 점근선은 $x = p$와 $y = q$이며, 그래프는 이 두 직선이 만나는 점인 $(p, q)$를 중심으로 대칭 구조를 이룬다. 함수의 정의역은 분모가 $0$이 되는 값을 제외한 실수 전체의 집합이며, 치역은 점근선인 $y = q$를 제외한 실수 전체의 집합이다.

### 직관과 기하적 의미
분수함수의 그래프는 기본형인 $y = \frac{k}{x}$의 그래프를 $x$축 방향으로 $p$만큼, $y$축 방향으로 $q$만큼 평행이동한 것과 같다. 상수 $k$의 부호에 따라 그래프가 그려지는 사분면의 위치가 결정되는데, $k > 0$인 경우에는 점근선의 교점을 기준으로 제1사분면과 제3사분면 방향에 그래프가 위치한다. 반대로 $k < 0$인 경우에는 점근선의 교점을 기준으로 제2사분면과 제4사분면 방향에 그래프가 위치하게 된다.

### 기본 성질
함수의 식에서 $k$의 값은 그래프의 곡선이 점근선으로부터 얼마나 멀리 떨어져 있는지를 결정한다. 예를 들어 $f(x) = \frac{2}{x - 1} + 3$이라는 함수가 있다면, 이 함수는 $y = \frac{2}{x}$의 그래프를 $x$축으로 $1$만큼, $y$축으로 $3$만큼 이동시킨 것이다. 이 경우 점근선은 $x = 1$과 $y = 3$이 되며, $x = 3$을 대입하면 $f(3) = \frac{2}{3 - 1} + 3 = 4$가 되어 점 $(3, 4)$를 그래프가 지나게 된다.

- 주어진 분수함수의 식을 보고 정의역과 치역을 정확히 찾아낼 수 있는가?
