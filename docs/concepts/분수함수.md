# 분수함수

## 정의

분수함수는 $f(x) = \frac{k}{x - p} + q$ ($k \neq 0$) 꼴의 함수를 말한다. 정의역은 분모가 0이 되는 $x = p$를 제외한 실수 전체이며, 점 $(p, q)$를 중심으로 $x = p$, $y = q$가 각각 점근선이 되는 쌍곡선 그래프를 가진다. $k > 0$이면 1·3사분면 쪽에, $k < 0$이면 2·4사분면 쪽에 그래프가 위치한다.

## 예시

$f(x) = \frac{2}{x - 1} + 3$의 그래프를 분석하면:

- 점근선: $x = 1$, $y = 3$
- 정의역: $\{x \mid x \neq 1\}$, 치역: $\{y \mid y \neq 3\}$
- $x = 3$이면 $f(3) = \frac{2}{2} + 3 = 4$

그래프는 점 $(1, 3)$을 기준으로 $y = \frac{2}{x}$를 평행이동한 쌍곡선이다.
