# 곡선의 초점

## 정의

이차곡선(포물선, 타원, 쌍곡선)에서 초점(焦點, focus)은 곡선의 정의에 쓰이는 고정된 점이다. 포물선 $y^2 = 4px$의 초점은 $(p, 0)$이고, 타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b > 0$)의 초점은 $(\pm c, 0)$, 단 $c = \sqrt{a^2 - b^2}$이다. 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$의 초점은 $(\pm c, 0)$, 단 $c = \sqrt{a^2 + b^2}$이다. 각 이차곡선은 초점을 이용한 거리 조건으로 정의되며, 수능에서는 초점의 좌표를 구하거나 초점과 관련된 거리 관계를 활용하는 문제가 출제된다.

## 예시

타원 $\frac{x^2}{25} + \frac{y^2}{9} = 1$의 초점을 구한다.

$a^2 = 25$, $b^2 = 9$이므로 $c = \sqrt{25 - 9} = \sqrt{16} = 4$

초점: $(\pm 4, 0)$, 즉 $F(4, 0)$과 $F'(-4, 0)$

이 타원 위의 임의의 점 $P$에 대해 $\overline{PF} + \overline{PF'} = 2a = 10$이 성립한다.
