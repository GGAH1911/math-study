# 곡선의 초점

## 요약
이차곡선(포물선, 타원, 쌍곡선)의 정의를 결정하는 고정된 점을 초점이라고 한다.

## 본문
이차곡선에서 초점(焦點, focus)은 곡선의 기하학적 정의를 구성하는 핵심적인 고정점이다. 포물선 $y^2 = 4px$의 초점은 $(p, 0)$이다. 타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b > 0$)의 초점은 $(\pm c, 0)$이며, 이때 $c = \sqrt{a^2 - b^2}$이다. 쌍곡선 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$의 초점은 $(\pm c, 0)$이며, 이때 $c = \sqrt{a^2 + b^2}$이다. 각 이차곡선은 초점과 준선, 또는 두 초점 사이의 거리 관계를 통해 정의되며, 수능 수학에서는 초점의 좌표를 직접 구하거나 초점과 곡선 위의 점 사이의 거리 관계를 활용하여 문제를 해결하는 유형이 자주 출제된다.

### 직관과 기하적 의미
초점은 곡선이 만들어지는 원리 그 자체를 담고 있는 점이다. 포물선에서는 초점에서 곡선까지의 거리와 준선까지의 거리가 같다는 성질을 통해 곡선이 그려지며, 타원과 쌍곡선에서는 두 초점으로부터의 거리의 합이나 차가 일정하다는 성질이 곡선의 모양을 결정한다.

### 기본 성질
타원 $\frac{x^2}{25} + \frac{y^2}{9} = 1$을 예로 들면, $a^2 = 25$, $b^2 = 9$이므로 $c = \sqrt{25 - 9} = 4$가 되어 초점은 $(4, 0)$과 $(-4, 0)$이 된다. 이때 타원 위의 임의의 점 $P$에 대하여 두 초점 $F, F'$까지의 거리의 합 $\overline{PF} + \overline{PF'}$은 장축의 길이인 $2a = 10$과 항상 같다.

## 학습 체크
- 포물선, 타원, 쌍곡선의 식에서 초점의 좌표를 구하기 위해 필요한 매개변수 $c$의 계산식을 각각 구분할 수 있는가?
- 타원에서 두 초점 사이의 거리와 장축의 길이 사이의 관계를 이해하고 있는가?
- 쌍곡선에서 두 초점으로부터 곡선 위의 점까지의 거리의 차가 일정함을 활용할 수 있는가?
