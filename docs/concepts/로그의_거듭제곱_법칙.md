# 로그의 거듭제곱 법칙

로그의 거듭제곱 법칙은 진수가 거듭제곱 꼴일 때 지수를 로그 앞으로 꺼낼 수 있다는 성질이다. $a > 0$, $a \neq 1$, $b > 0$이고 $n$이 실수일 때 다음이 성립한다.

$$\log_a b^n = n \log_a b$$

이 성질이 성립하는 이유는 로그의 정의에서 바로 확인할 수 있다. $\log_a b = t$로 놓으면 $b = a^t$이므로, $b^n = a^{tn}$이 된다. 따라서 $\log_a b^n = tn = n \log_a b$이다. 지수의 곱셈 법칙이 로그의 세계에서는 계수의 곱셈으로 바뀐다는 점이 핵심이다.

## 예시

**첫 번째 예.** $\log_2 8$을 거듭제곱 법칙으로 계산하면, $8 = 2^3$이므로

$$\log_2 8 = \log_2 2^3 = 3 \log_2 2 = 3 \times 1 = 3$$

**두 번째 예.** $\log_3 \sqrt{27}$을 계산해 보자. $\sqrt{27} = 27^{1/2} = (3^3)^{1/2} = 3^{3/2}$이므로

$$\log_3 \sqrt{27} = \log_3 3^{3/2} = \frac{3}{2} \log_3 3 = \frac{3}{2}$$

지수가 분수여도 그대로 앞으로 꺼낼 수 있음을 확인할 수 있다.

## 관련 개념

**지수 법칙**은 거듭제곱 법칙의 직접적인 토대다. $(a^m)^n = a^{mn}$이라는 지수의 성질이 없으면 이 증명이 성립하지 않으므로, 지수 계산에 익숙해야 한다.

**로그의 곱셈 법칙** $\log_a MN = \log_a M + \log_a N$과 함께 익혀두면 좋다. 거듭제곱 법칙은 같은 수를 $n$번 곱하는 상황에 곱셈 법칙을 반복 적용한 결과이기도 하다.

**로그의 밑 변환 공식**을 쓸 때 거듭제곱 법칙이 자주 등장한다. 밑이나 진수를 변환하는 과정에서 지수를 앞으로 꺼내 식을 단순하게 만드는 데 쓰인다.

**상용로그**에서는 $\log_{10} 10^n = n$처럼 이 법칙이 매우 자주 쓰이며, 큰 수나 작은 수를 다루는 계산의 핵심 도구가 된다.
