# 로그의 거듭제곱 법칙

## 요약
로그의 진수가 거듭제곱 형태일 때, 그 지수를 로그 앞의 계수로 내려서 곱할 수 있는 성질이다.

## 본문
로그의 거듭제곱 법칙은 $a > 0, a \neq 1, b > 0$이고 $n$이 실수일 때, $\log_a b^n = n \log_a b$가 성립한다는 성질이다. 이 법칙은 지수의 법칙이 로그의 세계에서는 계수의 곱셈으로 변환된다는 특징을 보여준다. 로그의 정의를 통해 그 이유를 살펴보면, $\log_a b = t$라고 할 때 $b = a^t$가 된다. 양변을 $n$제곱하면 $b^n = (a^t)^n = a^{tn}$이 되며, 로그의 정의에 의해 $\log_a b^n = tn = n \log_a b$가 유도된다. 따라서 복잡한 거듭제곱 형태의 진수를 가진 로그도 지수를 앞으로 꺼냄으로써 훨씬 단순한 형태로 계산할 수 있다.

### 직관과 기하적 의미
지수가 커진다는 것은 같은 수를 여러 번 곱한다는 의미이며, 로그는 그 지수 자체를 나타내는 값이다. 따라서 지수가 $n$배가 되면 로그의 값도 $n$배가 된다는 직관적 관계를 가진다.

### 기본 성질
- $\log_a b^n = n \log_a b$
- $\log_a \sqrt[m]{b} = \frac{1}{m} \log_a b$ (지수가 분수인 경우 포함)

## 학습 체크
- 로그의 진수가 거듭제곱 형태일 때 지수를 로그 앞으로 꺼낼 수 있는가?
- 지수가 분수 형태인 무리수(예: $\sqrt{x}$)인 경우에도 지수를 계수로 변환할 수 있는가?
- 로그의 밑과 진수 조건($a>0, a \neq 1, b>0$)을 만족하는지 확인하였는가?

## 관련 개념

**지수 법칙**은 거듭제곱 법칙의 직접적인 토대다. $(a^m)^n = a^{mn}$이라는 지수의 성질이 없으면 이 증명이 성립하지 않으므로, 지수 계산에 익숙해야 한다.

**로그의 곱셈 법칙** $\log_a MN = \log_a M + \log_a N$과 함께 익혀두면 좋다. 거듭제곱 법칙은 같은 수를 $n$번 곱하는 상황에 곱셈 법칙을 반복 적용한 결과이기도 하다.

**로그의 밑 변환 공식**을 쓸 때 거듭제곱 법칙이 자주 등장한다. 밑이나 진수를 변환하는 과정에서 지수를 앞으로 꺼내 식을 단순하게 만드는 데 쓰인다.

**상용로그**에서는 $\log_{10} 10^n = n$처럼 이 법칙이 매우 자주 쓰이며, 큰 수나 작은 수를 다루는 계산의 핵심 도구가 된다.
