### 정확한 진술

복소수(complex number)는 $z = a + bi$ 형태로 나타내는 수입니다. 여기서 $a, b$는 실수이고, $i$는 **허수단위**로 정의되어 $i^2 = -1$을 만족합니다. 복소수에서 $a$를 **실부**, $b$를 **허부**라 하고, 각각 $\text{Re}(z)$, $\text{Im}(z)$로 표기합니다.

복소수의 중요한 성질은 **같음의 조건**입니다. 두 복소수 $a_1 + b_1i$와 $a_2 + b_2i$가 같으려면 실부와 허부가 각각 같아야 합니다. 즉, $a_1 + b_1i = a_2 + b_2i \Leftrightarrow a_1 = a_2 \text{ and } b_1 = b_2$. 이는 복소수가 실부와 허부라는 두 개의 독립적인 성분으로 유일하게 결정된다는 뜻입니다.

### 직관/기하적 의미

실수 범위에서는 $x^2 = -1$ 같은 방정식을 풀 수 없습니다. 복소수는 이 문제를 해결하기 위해 **수를 2차원으로 확장**한 것입니다. **복소평면**에서 각 복소수 $a + bi$는 좌표 $(a, b)$의 점으로 표현되는데, 가로축(실수축)과 세로축(허수축)으로 이루어집니다. 이 기하학적 표현 덕분에 복잡한 대수 연산을 시각적으로 이해할 수 있습니다.

### 한 줄 예

$z = 2 + 3i$는 실부 2, 허부 3인 복소수로, 복소평면의 점 $(2, 3)$을 나타냅니다. 마찬가지로 $-5 = -5 + 0i$는 실수(허부가 0)이고, $4i = 0 + 4i$는 순허수(실부가 0)입니다.
