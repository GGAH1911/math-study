# 제약조건이 있는 경우의 수

## 요약
특정한 조건이나 제한 사항이 주어진 상황에서 전체 경우의 수 중 해당 조건을 만족하는 경우만을 선별하여 계산하는 방법입니다.

## 본문
제약조건이 있는 경우의 수란 전체 사건의 집합 중에서 문제에서 제시한 특정한 조건을 만족하는 부분집합의 원소 개수를 구하는 것을 의미합니다. 이러한 문제는 단순히 모든 경우를 나열하는 것이 아니라, 주어진 제약사항을 만족하기 위해 어떤 전략을 세워야 하는지를 판단하는 것이 핵심입니다. 일반적으로 제약조건이 있는 문제는 조건이 까다로운 경우를 먼저 결정하거나, 조건을 만족하지 않는 경우를 전체에서 빼는 보수적인 방법 중 어느 것이 효율적인지를 판단하여 해결합니다.

### 직관과 기하적 의미
제약조건은 우리가 탐색해야 할 전체 영역을 특정 부분으로 제한하는 역할을 합니다. 예를 들어, 수직선 상의 점들을 선택할 때 '이웃하지 않아야 한다'는 조건이 붙으면, 점들 사이에 빈 공간을 확보해야 한다는 기하학적 제약이 생깁니다. 이는 전체 가능한 조합의 공간 내에서 특정 패턴을 가진 부분 공간만을 추출하는 과정과 같습니다.

### 기본 성질
첫째, 제약조건이 복잡할수록 조건을 만족하는 경우를 직접 구하는 것보다 전체 경우의 수에서 조건을 만족하지 않는 경우를 빼는 '여사건'의 원리가 유용할 때가 많습니다. 둘째, 여러 개의 제약조건이 동시에 주어질 경우, 각 조건을 동시에 만족하는 교집합을 구하거나 단계별로 조건을 적용하여 경우를 나누어 계산해야 합니다. 셋째, 제약조건은 문제의 풀이 순서를 결정하는 결정적인 단서가 되므로, 가장 까다로운 조건을 기준으로 경우를 분류하는 것이 효율적입니다.

## 학습 체크
- 주어진 제약조건을 만족하는 경우를 직접 세는 것이 유리한가, 아니면 여사건을 이용하는 것이 유리한가?
- 제약조건이 여러 개일 때, 각 조건을 독립적인 단계로 나누어 순차적으로 적용할 수 있는가?
- 조건을 만족하는 경우를 분류할 때, 중복되거나 빠진 경우는 없는가?

## 관련 개념
- **경우의 수**: 제약조건이 있는 경우의 수는 결국 전체 경우의 수 중에서 특정 조건을 만족하는 부분집합의 크기를 구하는 과정입니다.
