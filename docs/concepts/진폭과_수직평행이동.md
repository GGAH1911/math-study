# 진폭과 수직평행이동

삼각함수 $y = a\sin x$ 또는 $y = a\cos x$에서 **진폭**은 $|a|$로 정의한다. 진폭은 그래프가 중심선으로부터 위아래로 얼마나 벌어지는지를 나타내는 값이다. 구체적으로 함수의 최댓값과 최솟값의 차이를 $2$로 나눈 것, 즉

$$\text{진폭} = \frac{\text{최댓값} - \text{최솟값}}{2}$$

이다. $a > 0$이면 최댓값은 $a$, 최솟값은 $-a$이며, $a < 0$이어도 진폭은 반드시 양수인 $|a|$로 읽는다.

**수직평행이동**은 $y = \sin x$의 그래프 전체를 $y$축 방향으로 평행하게 옮기는 변환이다. $y = \sin x + b$로 쓰면 그래프가 $y$축 방향으로 $b$만큼 이동한다. $b > 0$이면 위로, $b < 0$이면 아래로 올라가거나 내려가며, 그래프의 모양·주기·진폭은 전혀 바뀌지 않는다.

두 변환을 동시에 적용한 꼴은

$$y = a\sin x + b$$

이며, 이때 진폭은 $|a|$, 그래프의 중심선(최댓값과 최솟값의 중간)은 직선 $y = b$가 된다. 최댓값은 $b + |a|$, 최솟값은 $b - |a|$이다.

---

## 예시

**예 1.** $y = 3\sin x - 1$

- 진폭: $|3| = 3$
- 중심선: $y = -1$
- 최댓값: $-1 + 3 = 2$, 최솟값: $-1 - 3 = -4$

기본 함수 $y = \sin x$의 그래프를 위아래로 $3$배 늘린 뒤, 전체를 $y$축 방향으로 $1$만큼 아래로 내린 것이다.

**예 2.** $y = -2\cos x + 4$

- 진폭: $|-2| = 2$
- 중심선: $y = 4$
- 최댓값: $4 + 2 = 6$, 최솟값: $4 - 2 = 2$

$a = -2$이므로 그래프가 $x$축에 대해 뒤집히면서($\cos x$의 산과 골이 반전) 진폭은 $2$가 되고, 그 전체가 위로 $4$만큼 올라간다. 최솟값이 $2$로 양수이므로 그래프 전체가 $x$축 위에 위치한다.

## 관련 개념

**삼각함수** — 진폭과 수직평행이동은 $\sin x$, $\cos x$의 값 범위가 $[-1, 1]$이라는 성질 위에 세워진 개념이다. 기본 삼각함수의 정의와 값 범위를 먼저 이해해야 진폭이 왜 최댓값·최솟값을 결정하는지 파악할 수 있다.

**주기와 수평평행이동** — 수직 변환과 짝을 이루는 수평 변환이다. $y = a\sin(bx + c) + d$처럼 쓰면 $|a|$가 진폭, $d$가 수직이동, $\frac{2\pi}{|b|}$가 주기, $-\frac{c}{b}$가 수평이동(위상)을 각각 담당한다. 네 변환이 독립적으로 작용하기 때문에 하나씩 분리해 읽는 습관이 중요하다.

**최대·최솟값 문제** — 수능에서는 $y = a\sin x + b$ 형태의 최댓값 또는 최솟값을 조건으로 $a$, $b$를 구하는 문제가 자주 등장한다. 진폭과 수직이동의 관계를 연립방정식으로 세우는 풀이가 핵심이다.
