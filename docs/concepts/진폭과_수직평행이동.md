# 진폭과 수직평행이동

## 요약
삼각함수 $y = a\sin x + b$에서 $|a|$는 그래프의 높낮이 폭인 진폭을 결정하며, $b$는 그래프의 중심선을 결정하는 수직평행이동을 의미한다.

## 본문
삼각함수 $y = a\sin x$ 또는 $y = a\cos x$에서 **진폭**은 $|a|$로 정의하며, 이는 그래프가 중심선으로부터 위아래로 얼마나 벌어지는지를 나타내는 값이다. 구체적으로 함수의 최댓값과 최솟값의 차이를 $2$로 나눈 값인 $\text{진폭} = \tfrac{\text{최댓값} - \text{최솟값}}{2}$과 같다. 이때 $a > 0$이면 최댓값은 $a$, 최솟값은 $-a$가 되며, $a < 0$인 경우에도 진폭은 반드시 양수인 $|a|$로 정의한다.

**수직평행이동**은 $y = \sin x$의 그래프 전체를 $y$축 방향으로 옮기는 변환으로, $y = \sin x + b$와 같이 나타낸다. $b > 0$이면 그래프가 위로, $b < 0$이면 아래로 이동하며, 이 과정에서 그래프의 모양, 주기, 진폭은 변하지 않는다.

두 변환이 동시에 적용된 $y = a\sin x + b$ 형태에서 그래프의 중심선은 직선 $y = b$가 되며, 최댓값은 $b + |a|$, 최솟값은 $b - |a|$로 계산된다.

### 직관과 기하적 의미
진폭 $|a|$는 그래프의 수직적 크기를 결정하며, $a$의 부호는 그래프의 상하 반전 여부를 결정한다. 수직평행이동 $b$는 그래프 전체를 통째로 들어 올리거나 내리는 역할을 하여, 그래프의 중심축을 $x$축($y=0$)에서 $y=b$로 이동시킨다.

### 기본 성질
- 진폭은 $a$의 부호와 관계없이 항상 $|a|$로 일정하다.
- 수직평행이동은 그래프의 형태(주기, 진폭)를 변화시키지 않고 위치만 이동시킨다.
- $y = a\sin x + b$에서 최댓값과 최솟값의 차이는 항상 $2|a|$이다.

## 학습 체크
- $y = -3\cos x + 2$에서 진폭과 중심선, 최댓값과 최솟값을 각각 구하시오.
- $y = a\sin x + b$의 그래프가 $x$축과 접할 때, $a$와 $b$의 관계를 설명하시오.
- 수직평행이동을 했을 때 그래프의 주기와 진폭이 변하지 않는 이유를 설명하시오.

## 관련 개념

**삼각함수** — 진폭과 수직평행이동은 $\sin x$, $\cos x$의 값 범위가 $[-1, 1]$이라는 성질 위에 세워진 개념이다. 기본 삼각함수의 정의와 값 범위를 먼저 이해해야 진폭이 왜 최댓값·최솟값을 결정하는지 파악할 수 있다.

**주기와 수평평행이동** — 수직 변환과 짝을 이루는 수평 변환이다. $y = a\sin(bx + c) + d$처럼 쓰면 $|a|$가 진폭, $d$가 수직이동, $\tfrac{2\pi}{|b|}$가 주기, $-\tfrac{c}{b}$가 수평이동(위상)을 각각 담당한다. 네 변환이 독립적으로 작용하기 때문에 하나씩 분리해 읽는 습관이 중요하다.

**최대·최솟값 문제** — 수능에서는 $y = a\sin x + b$ 형태의 최댓값 또는 최솟값을 조건으로 $a$, $b$를 구하는 문제가 자주 등장한다. 진폭과 수직이동의 관계를 연립방정식으로 세우는 풀이가 핵심이다.
