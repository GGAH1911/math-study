# 판별식

> **정리** · 중3 · 단원: [이차방정식](/concepts/이차방정식)

## 요약
$D=b^2-4ac$의 부호와 근의 종류

## 본문 (학습 시 채워짐)

### 진술 + 가정

이차방정식 $ax^2+bx+c=0$ (단, $a\neq 0$)에서 **판별식** $D=b^2-4ac$의 부호에 따라 근의 종류가 완전히 결정된다.

- $D>0$일 때: 서로 다른 2개의 실근
- $D=0$일 때: 중근(같은 크기의 2개 실근)
- $D<0$일 때: 실근이 없음(복소수 범위의 2개 켤레복소수근)

### 간단한 유도/증명 스케치

근의 공식에서 유도된다. 이차방정식의 해는
$$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$

루트 안의 식 $b^2-4ac$가 판별식 $D$이다. 이 값의 부호가 제곱근 계산 가능성을 좌우한다.

- $D>0$: $\sqrt{D}$는 양의 실수 → $\pm\sqrt{D}$로 두 개의 서로 다른 실근 생성
- $D=0$: $\sqrt{D}=0$ → $\pm 0$은 같으므로 $x=-\frac{b}{2a}$ (중근)
- $D<0$: $\sqrt{D}$는 실수가 아님 → 허수 단위 $i$가 필요하지만, 실수 범위에선 근이 없음

### 의의/응용

판별식은 방정식을 풀지 않고도 근의 존재와 개수를 판정할 수 있는 도구다. 특히 고등학교 수학에서는:

- 이차함수의 그래프가 $x$축과 만나는 점의 개수 판정
- 이차부등식을 풀 때 해의 범위 결정
- 연립방정식의 해의 개수 판정
- 기하 문제에서 접선/교선 조건 설정

**검증 예시**: $2x^2-5x+3=0$에서 $D=(-5)^2-4(2)(3)=25-24=1>0$ → 서로 다른 2개 실근 (실제 근: $x=1$ 또는 $x=\frac{3}{2}$)

```python
# 근의 공식 검증
import sympy as sp
x = sp.Symbol('x')
eq = 2*x**2 - 5*x + 3
print(sp.solve(eq, x))  # [1, 3/2]
```
