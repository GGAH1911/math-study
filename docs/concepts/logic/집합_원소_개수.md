# 집합 원소 개수

> **예제** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
포함배제 원리

## 본문 (학습 시 채워짐)

### 문제

어떤 학교의 동아리 가입 현황을 조사했다. 영어 동아리에 가입한 학생이 12명, 과학 동아리에 가입한 학생이 15명이다. 두 동아리에 모두 가입한 학생이 4명일 때, 영어 동아리 또는 과학 동아리에 적어도 하나 가입한 학생의 수를 구하시오.

### 단계별 풀이

영어 동아리에 가입한 학생의 집합을 $A$, 과학 동아리에 가입한 학생의 집합을 $B$라고 하자.
- $|A| = 12$
- $|B| = 15$
- $|A \cap B| = 4$

우리가 구해야 할 것은 "적어도 하나의 동아리에 가입한 학생", 즉 $|A \cup B|$이다.

처음 생각하기에는 $|A| + |B| = 12 + 15 = 27$이라 할 수 있겠지만, 이것은 틀렸다. 왜냐하면 두 동아리에 모두 가입한 4명의 학생이 중복으로 세어지기 때문이다.

**포함배제 원리(Inclusion-Exclusion Principle)**를 사용해야 한다. 합집합의 원소 개수는 각 집합의 원소 개수를 더한 후, 교집합의 원소 개수를 빼야 한다:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

이를 이용하면:

$$|A \cup B| = 12 + 15 - 4 = 23$$

### 답

**23명**

### 변형/주의

포함배제 원리는 세 개 이상의 집합에도 적용된다. 집합 A, B, C에 대해:

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$

일반 원칙은 홀수 개의 집합의 교집합은 더하고, 짝수 개의 집합의 교집합은 뺀다는 것이다.

**주의사항**: 합집합의 원소 개수를 구할 때 교집합을 빼먹기 쉽다. "또는"으로 표현되는 합집합 문제에서는 항상 중복을 확인하고, 필요하면 교집합을 명시적으로 구해서 빼주자. 

sympy로 검증: `12 + 15 - 4`를 계산하면 23이 나온다.
