### 정확한 진술

집합의 원소 조건이란 어떤 원소가 특정 집합에 속하기 위해 만족해야 하는 성질 또는 명제를 말합니다. 이를 수식으로 나타내면 $A = \{x \mid P(x)\}$ 형태로 쓰며, 여기서 $P(x)$는 원소 $x$가 만족해야 하는 조건(명제)입니다. 어떤 원소 $a$가 집합 $A$에 속한다($a \in A$)는 것은 정확히 $P(a)$가 참일 때이고, $a \notin A$는 $P(a)$가 거짓일 때입니다.

### 직관과 의미

집합의 원소 조건은 "집합이 무엇인지"를 정의하는 핵심입니다. 모양이나 색깔로 되어 있는 주머니 같은 집합이 아니라, **어떤 조건을 만족하는 모든 대상의 모임**이라고 생각할 수 있습니다. 예를 들어 "100 이상 200 미만의 홀수"라는 조건은 그 조건을 만족하는 모든 수들의 집합을 정의합니다.

원소 조건은 명제와 깊은 관련이 있습니다. 집합 $A = \{x \mid P(x)\}$가 주어지면, 임의의 원소 $a$에 대해 "$a \in A$"와 "$P(a)$는 참"은 동치(iff)가 됩니다. 즉, 조건이 참인지 거짓인지 판단하는 것으로 집합의 경계가 결정됩니다.

### 구체적인 예

$$\{x \mid x \in \mathbb{Z}, -3 < x \le 5\} = \{-2, -1, 0, 1, 2, 3, 4, 5\}$$

여기서 조건 "$x \in \mathbb{Z}$ 이고 $-3 < x \le 5$"를 만족하는 정수를 모두 모으면 이 집합이 됩니다. 예를 들어 $x = 0$은 조건을 만족하므로 ($0$은 정수이고 $-3 < 0 \le 5$) 집합에 속하고, $x = -4$는 조건을 만족하지 않으므로 ($-4 \not> -3$) 집합에 속하지 않습니다.

**검증 (sympy):** `{x for x in range(-3, 6) if -3 < x <= 5}` → `{-2, -1, 0, 1, 2, 3, 4, 5}`
