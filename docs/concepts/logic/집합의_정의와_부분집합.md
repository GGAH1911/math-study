### 집합의 정확한 진술

집합(set)은 다음 두 조건을 만족하는 원소(element)들의 모임입니다:
1. 어떤 대상이 그 집합에 속하는지 속하지 않는지 명확하게 판단할 수 있어야 함
2. 원소는 중복되지 않으며, 순서도 상관없음

예를 들어 $A = \{1, 2, 3\}$이면 $2 \in A$(2는 A에 속함), $4 \notin A$(4는 A에 속하지 않음)입니다.

### 집합의 직관과 의미

집합은 특정 조건을 만족하는 "구별 가능한 대상들의 집합"입니다. 고등학교에서는 주로 수를 원소로 하는 집합을 다룹니다. 예를 들어 방정식 $x^2 - 5x + 6 = 0$의 해의 집합은 $\{2, 3\}$입니다. 집합은 **그림으로 벤 다이어그램**으로도 나타낼 수 있어, 집합 간의 포함 관계를 직관적으로 이해할 수 있습니다.

### 부분집합의 정확한 진술

집합 $B$의 모든 원소가 집합 $A$에 속할 때, $B$를 $A$의 **부분집합**(subset)이라 하고 $B \subseteq A$로 나타냅니다.

기호로는: $B \subseteq A \iff (x \in B \Rightarrow x \in A)$

특히 $B \subseteq A$이면서 $A$에 속하지만 $B$에는 속하지 않는 원소가 있으면 $B \subsetneq A$(진부분집합)입니다.

### 부분집합의 직관과 의미

부분집합은 "한 집합이 다른 집합 안에 완전히 포함되는" 관계입니다. 벤 다이어그램으로 보면 한 원판이 다른 원판 안에 포함되는 모습입니다. **중요한 성질**은 모든 집합 $A$에 대해 $\emptyset \subseteq A$(공집합은 모든 집합의 부분집합)이고, $A \subseteq A$(반사성)입니다.

### 예시

$A = \{1, 2, 3\}$, $B = \{1, 2\}$, $C = \{1, 2, 3\}$일 때:
- $B \subsetneq A$ (B는 A의 진부분집합)
- $C \subseteq A$ (실제로는 $C = A$)
- $A$의 모든 부분집합: $\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$ (총 $2^3 = 8$개)
