### 정확한 진술

부등식의 **해**(solution)는 주어진 부등식을 참(참)으로 만드는 미지수의 값들의 집합입니다. 예를 들어 부등식 $2x + 3 > 7$의 해는 이 식을 성립시키는 모든 $x$ 값들이고, 부등식의 **해의 집합**(solution set)이라 하면 그 모든 값들을 집합 기호로 나타낸 것입니다.

### 직관과 기하적 의미

부등식의 해는 등식의 해와 달리 보통 하나의 값이 아니라 **어떤 범위(구간)**를 이룹니다. 위의 $2x + 3 > 7$을 정리하면 $x > 2$이므로, 2보다 큰 모든 실수가 해입니다. 이를 수직선 위에 나타내면 2의 오른쪽 방향 전체가 강조되는데(2는 포함하지 않음), 이 시각적 표현이 해의 집합의 범위를 가장 직관적으로 보여줍니다.

### 간단한 예

부등식 $x^2 - 5x + 6 < 0$의 해를 구해봅시다.

좌변을 인수분해하면 $(x-2)(x-3) < 0$입니다. 이 곱이 음수가 되려면 두 인수의 부호가 반대여야 하므로, $2 < x < 3$일 때만 성립합니다.

따라서 **해의 집합은 $\{x \mid 2 < x < 3\}$ 또는 구간 표기로 $(2, 3)$**입니다.

```python
# sympy.solve(x**2 - 5*x + 6 < 0, x) 
# 결과: 2 < x ∧ x < 3
```

### 주의 사항

- **경계점 포함 여부**: $\leq$ 또는 $\geq$는 경계값을 **포함**(닫힌 구간), $<$ 또는 $>$는 **포함하지 않음**(열린 구간).
- **해가 없는 경우**: 예를 들어 $x^2 + 1 < 0$은 어떤 실수 $x$도 만족할 수 없으므로 **해의 집합은 공집합** $\emptyset$입니다.
- **모든 실수가 해인 경우**: $x^2 + 1 > 0$처럼 부등식이 항상 참이면 해의 집합은 모든 실수 $\mathbb{R}$입니다.
