### 정확한 진술

원소의 명확한 판정이란 임의의 대상 $x$에 대해 "$x \in A$인가, $x \notin A$인가"가 명확히 결정되어야 한다는 원칙입니다. 다시 말해, 주어진 집합 $A$와 대상 $x$에 대해 다음 중 정확히 하나만 참이어야 합니다:
- $x$는 $A$에 속한다 ($x \in A$)
- $x$는 $A$에 속하지 않는다 ($x \notin A$)

### 직관과 의의

집합을 정의할 때 "어떤 원소들의 모임"이라고 말하지만, 이것이 의미를 가지려면 경계가 명확해야 합니다. 예를 들어 "$\{$큰 수들의 모임$\}$"은 집합이 아닙니다. "큼"은 주관적이어서 어떤 수가 그 모임에 속하는지 속하지 않는지 명확히 판정할 수 없기 때문입니다.

반대로 "$\{x \mid x \text{는 자연수이고 } x < 10\}$"은 집합입니다. 임의의 정수 $n$을 들었을 때, "$n$이 자연수인가?", "$n < 10$인가?"를 각각 명확히 답할 수 있으므로 포함 여부가 결정되기 때문입니다. 이것이 바로 원소의 명확한 판정이 성립하는 경우입니다.

### 한 줄 예

- ✓ $\{2, 3, 5, 7, 11\}$ — 각 수가 소수인지 아닌지 명확함
- ✗ $\{$아름다운 색깔들$\}$ — "아름다움"의 기준이 명확하지 않음
- ✓ $\{x \mid x \text{는 실수이고 } x^2 = 4\}$ — 임의의 실수 $y$에 대해 $y^2 = 4$인지 명확히 확인 가능

이 원칙이 성립할 때만 집합의 성질(합집합, 교집합, 여집합 등)을 일관되게 다룰 수 있습니다.
