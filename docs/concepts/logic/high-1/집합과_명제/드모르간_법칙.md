# 드모르간 법칙

> **정리** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)
## 요약
$(A\cup B)^c=A^c\cap B^c$

## 본문

### 진술
전체집합 $U$와 $U$의 두 부분집합 $A, B$에 대하여 다음 두 등식이 성립한다:
$$\begin{align}
(A \cup B)^c &= A^c \cap B^c \\
(A \cap B)^c &= A^c \cup B^c
\end{align}$$
이를 **드모르간 법칙**(De Morgan's Law)이라 한다.

### 증명 스케치
첫 번째 식 $(A \cup B)^c = A^c \cap B^c$를 증명하자. 임의의 원소 $x$에 대하여:
$$x \in (A \cup B)^c \iff x \notin (A \cup B) \iff x \notin A \text{ 그리고 } x \notin B$$
$$\iff x \in A^c \text{ 그리고 } x \in B^c \iff x \in A^c \cap B^c$$

각 동치 관계는 여집합, 합집합, 교집합의 정의에서 따라온다. 따라서 $(A \cup B)^c = A^c \cap B^c$이다. 두 번째 식도 마찬가지 논리로, "$A$와 $B$에 동시에 속하지 않는 것"은 "$A$에 속하지 않거나 $B$에 속하지 않는 것"과 같음을 보일 수 있다.

### 의의와 활용
드모르간 법칙은 여집합이 포함된 복잡한 식을 간단히 정리하는 강력한 도구이다. 예를 들어 $(A^c \cup B^c)$처럼 표현된 집합을 $(A \cap B)^c$로 간단히 나타낼 수 있어 계산을 효율적으로 만든다. 이 법칙은 집합과 명제 단원의 여러 문제를 푸는 데 자주 사용되며, 특히 명제의 부정을 다룰 때 중요하다. "P 또는 Q의 부정은 P가 아니고 Q도 아님"이라는 논리적 원리가 바로 이 법칙에서 나오기 때문이다.
