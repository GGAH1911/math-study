### 정확한 진술

집합(set)은 서로 다른 원소들(elements)의 모임입니다. 일반적으로 대문자 $A, B, C, \ldots$로 표기하며, 집합에 속한 각 대상을 원소라 합니다. 원소 $a$가 집합 $A$에 속할 때는 $a \in A$로, 속하지 않을 때는 $a \notin A$로 나타냅니다.

집합은 원소들을 명확히 구분할 수 있어야 합니다. 즉, 어떤 대상이 그 집합에 속하는지 속하지 않는지가 확실하게 결정되어야 합니다. 예를 들어 "좋은 숫자들의 모임"은 집합이 아닙니다. "좋다"는 기준이 모호하기 때문입니다. 반면 "10 이하의 자연수"는 집합입니다.

### 직관/기하적 의미

집합을 이해하는 가장 직관적인 방법은 '상자'로 생각하는 것입니다. 상자 안에 명확한 규칙을 만족하는 물건들(원소)을 담습니다. 상자 안의 물건들은:
- **순서가 없습니다**: $\{1, 2, 3\} = \{3, 1, 2\}$
- **중복이 없습니다**: $\{1, 1, 2\} = \{1, 2\}$ (같은 원소는 한 번만 세어집니다)

집합을 표현하는 방법은 두 가지입니다.
- **원소나열법**: $A = \{1, 2, 3, 4, 5\}$ (원소를 직접 나열)
- **조건제시법**: $A = \{x \mid x \text{는 자연수이고 } x \leq 5\}$ (조건으로 표현)

### 한 줄 예

집합 $A = \{2, 4, 6, 8\}$에서 $4 \in A$이지만 $5 \notin A$입니다. 또는 조건제시법으로 $A = \{x \mid x \text{는 짝수이고 } 2 \leq x \leq 8\}$로도 같은 집합입니다.
