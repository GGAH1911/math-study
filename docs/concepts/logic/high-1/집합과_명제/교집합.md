# 교집합

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
두 집합에 공통으로 포함된 모든 원소들을 모아놓은 집합입니다.

## 본문
두 집합 $A$, $B$에 대하여 $A$에도 속하고 $B$에도 속하는 모든 원소의 집합을 $A$와 $B$의 **교집합**(intersection)이라 하며, 기호로 $A \cap B$로 나타냅니다. 이는 "$x \in A$ 그리고 $x \in B$"라는 조건을 동시에 만족하는 모든 $x$를 모은 것입니다.

$$A \cap B = \{x \mid x \in A \text{ and } x \in B\}$$

### 직관과 기하적 의미
교집합은 두 집합의 **공통 부분**을 의미합니다. 벤다이어그램을 통해 시각화하면 두 원이 겹치는 중앙 영역에 해당합니다. 실생활의 예로, 축구 동아리 학생 집합을 $S$, 수학 동아리 학생 집합을 $M$이라고 할 때, $S \cap M$은 두 동아리에 모두 가입한 학생들의 집합입니다. 만약 두 집합이 공통된 원소를 하나도 갖지 않는다면 교집합은 공집합($\emptyset$)이 됩니다.

### 기본 성질
- $A \cap B = B \cap A$ (교환법칙)
- $A \cap (B \cap C) = (A \cap B) \cap C$ (결합법칙)
- $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ (분배법칙)

## 학습 체크
- 두 집합의 원소 중 어느 하나라도 포함되지 않으면 교집합의 원소가 될 수 없음을 이해했는가?
- 두 집합이 서로소(disjoint)일 때 교집합이 공집합이 되는 원리를 설명할 수 있는가?

## 관련 개념
- **집합과 명제**: 집합의 연산 중 하나로서, 조건문에서 '그리고(and)'의 논리 연산과 밀접한 관련이 있습니다.
