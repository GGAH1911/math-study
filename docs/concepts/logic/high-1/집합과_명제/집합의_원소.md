# 집합의 원소

집합을 구성하는 각각의 대상과, 어떤 대상이 그 집합에 속하는지를 판단하는 관계를 다룹니다. 고1 집합과 명제 단원의 가장 기본 용어입니다.

## 정의

집합 $A$의 **원소**는 $A$를 구성하는 개별 대상이며, $a$가 $A$의 원소일 때 $a \in A$로, 아닐 때 $a \notin A$로 표기합니다.

집합을 표기하는 두 가지 표준 방법은
- **원소나열법:** $A = \{a_1, a_2, \ldots, a_n\}$.
- **조건제시법:** $A = \{x \mid x\text{에 관한 조건}\}$.

같은 원소는 두 번 세지 않으며, 원소들의 나열 순서는 집합의 정체성에 영향을 주지 않습니다.

## 예시

집합 $A = \{x \mid x\text{는 } 12\text{의 양의 약수}\}$를 원소나열법으로 나타내면 $A = \{1, 2, 3, 4, 6, 12\}$입니다. 따라서 $4 \in A$, $5 \notin A$.

또한 $\{1, 2, 2, 3\}$과 $\{1, 2, 3\}$은 같은 집합이며, $\{3, 1, 2\}$ 역시 같은 집합입니다.
