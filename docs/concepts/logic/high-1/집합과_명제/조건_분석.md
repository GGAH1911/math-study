# 조건 분석

## 정확한 진술

조건 분석이란 수학 문제에서 주어진 하나 이상의 조건들을 논리적으로 해석하여, 미지수가 만족해야 할 범위나 집합을 파악하는 과정입니다. 주어진 조건들을 명제의 형태로 이해하고, 이들이 결정하는 집합(해집합)을 체계적으로 구하는 것이 핵심입니다.

## 직관과 논리적 의미

**"모두 만족" vs "하나만 만족"을 구분하는 것이 중요합니다.** 

두 조건 $P$와 $Q$가 있을 때:
- $P$ **그리고** $Q$를 동시에 만족: 교집합 $P \cap Q$
- $P$ **또는** $Q$ 중 하나를 만족: 합집합 $P \cup Q$

예를 들어, "$x > 2$ **이고** $x < 5$"는 $2 < x < 5$를 의미하며(교집합), "$x < 1$ **또는** $x > 3$"은 두 영역의 합집합입니다. 

조건 분석은 문제에 숨겨진 논리 구조를 명확히 하여 중복 계산을 피하고 빠뜨린 경우가 없도록 보장합니다.

## 구체적 예시

**조건이 부등식 형태인 경우:**  
$x^2 - 5x + 6 < 0$ **이고** $x \geq 2$를 동시에 만족하는 $x$의 범위를 구합시다.
- 첫 조건: $(x-2)(x-3) < 0$ → $2 < x < 3$
- 두 조건의 교집합: $2 < x < 3$ ∩ $\{x \geq 2\}$ = $2 < x < 3$

(`sympy.solve([x**2 - 5*x + 6 < 0, x >= 2], x)` 형태로 검증 가능)

**조건이 명제 형태인 경우:**  
명제 "$x$가 짝수 → $x$는 2의 배수"는 대우가 참이므로, 모든 짝수는 반드시 2의 배수임을 확인할 수 있습니다.

조건 분석 능력은 부등식, 확률, 집합 단원에서 해집합을 구할 때와 논리 문제를 풀 때 매우 유용합니다.
