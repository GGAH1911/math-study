# 집합의 관계

두 집합 사이의 포함·상등 관계를 나타내는 개념들의 모음입니다. 고1 집합과 명제 단원의 기초입니다.

## 정의

두 집합 $A, B$에 대해 주요 관계는 다음과 같습니다.
- **부분집합:** 모든 $x \in A$에 대해 $x \in B$이면 $A \subseteq B$.
- **진부분집합:** $A \subseteq B$이고 $A \neq B$이면 $A \subsetneq B$ (또는 $A \subset B$로 표기).
- **상등:** $A \subseteq B$이고 $B \subseteq A$이면 $A = B$.
- **서로소:** $A \cap B = \varnothing$이면 두 집합은 서로소.

특히 공집합 $\varnothing$은 모든 집합의 부분집합이며, 원소가 $n$개인 유한집합의 부분집합의 개수는 $2^n$, 진부분집합의 개수는 $2^n - 1$입니다.

## 예시

$A = \{1, 2\}, B = \{1, 2, 3\}$일 때 모든 $A$의 원소가 $B$에 속하므로 $A \subseteq B$이고 $A \neq B$이므로 $A \subsetneq B$.

또한 $A = \{1, 2, 3\}$의 부분집합의 개수는 $2^3 = 8$이고 그 목록은 $\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$입니다.
