# 집합의 연산

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
집합의 연산은 두 개 이상의 집합 사이의 관계를 합집합, 교집합, 차집합, 여집합이라는 연산을 통해 정의하는 과정입니다.

## 본문
두 집합 $A, B$가 주어졌을 때, 다음과 같이 연산합니다. 합집합 $A \cup B$는 $A$ 또는 $B$에 속하는 모든 원소의 집합이며, $A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$로 나타냅니다. 교집합 $A \cap B$는 $A$와 $B$ 모두에 속하는 원소의 집합으로, $A \cap B = \{x \mid x \in A \text{ 그리고 } x \in B\}$입니다. 여집합 $A^c$는 전체집합 $U$에 속하지만 $A$에는 속하지 않는 원소의 집합이며, $A^c = \{x \mid x \in U, x \notin A\}$로 정의합니다. 차집합 $A - B$는 $A$에는 속하지만 $B$에는 속하지 않는 원소의 집합으로, $A - B = \{x \mid x \in A, x \notin B\}$입니다.

### 직관과 기하적 의미
벤다이어그램을 통해 시각화하면 이해가 쉽습니다. 합집합은 두 원판이 차지하는 전체 영역을 의미하며, 교집합은 두 원판이 겹치는 부분을 나타냅니다. 여집합은 특정 집합의 바깥 영역을, 차집합은 첫 번째 집합에서 두 번째 집합의 영역을 제외한 나머지 부분만을 의미합니다. 실생활의 예로 수학을 선택한 학생 집합을 $A$, 과학을 선택한 학생 집합을 $B$라고 할 때, 합집합은 둘 중 하나라도 선택한 학생이며 교집합은 두 과목을 모두 선택한 학생입니다.

### 기본 성질
$A = \{1, 2, 3\}$, $B = \{2, 3, 4\}$인 경우를 예로 들면, 합집합 $A \cup B = \{1, 2, 3, 4\}$, 교집합 $A \cap B = \{2, 3\}$, 차집합 $A - B = \{1\}$이 됩니다.

## 학습 체크
- 합집합과 교집합의 정의를 '또는'과 '그리고'라는 조건으로 정확히 구분할 수 있는가?
- 차집합 $A - B$를 여집합과 교집합의 연산인 $A \cap B^c$로 변환하여 표현할 수 있는가?
- 벤다이어그램을 그려서 주어진 집합 연산의 결과를 시각적으로 도출할 수 있는가?

## 관련 개념
- **집합과 명제**: 집합의 연산은 명제의 논리 연산인 '또는', '그리고', '부정'과 밀접하게 연결됩니다.
- **함수**: 집합의 원소들 사이의 대응 관계를 다루는 함수를 정의하기 위해 집합의 연산 개념이 기초가 됩니다.
