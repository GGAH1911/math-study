# 원소 조건

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
집합을 정의할 때 원소가 갖추어야 할 성질을 명시하여 집합의 범위를 결정하는 방식입니다.

## 본문
집합 $A$를 나타낼 때 원소가 만족해야 하는 조건을 명시하여 정의하는 방식을 원소 조건이라고 하며, 다음과 같이 기호로 나타냅니다.
$$A = \{x \mid P(x)\}$$
여기서 $P(x)$는 변수 $x$에 대한 명제 또는 조건을 의미하며, 이는 집합 $A$가 조건 $P(x)$를 만족하는 모든 $x$의 모임임을 나타냅니다. 이때 기호 $\mid$ 또는 $:$는 "그러한" 또는 "만족하는"이라는 의미를 담고 있습니다.

### 직관과 의미
원소 조건은 무한히 많은 원소를 가진 집합을 효율적으로 표현할 수 있게 해줍니다. 예를 들어 나열하기 어려운 실수의 집합도 하나의 조건으로 간단히 정의할 수 있습니다. 어떤 원소 $a$가 집합 $A$에 속하는지는 "$a$가 조건 $P(a)$를 만족하는가?"를 통해 판단합니다. 조건을 만족하면 $a \in A$이고, 만족하지 않으면 $a \notin A$입니다. 즉, 원소 조건은 집합의 경계를 결정하는 기준이 됩니다.

**예시**
1) 자연수 집합: $A = \{x \mid x \text{는 10 이하의 짝수}\} = \{2, 4, 6, 8, 10\}$
2) 실수 집합: $B = \{x \in \mathbb{R} \mid x^2 - 3x + 2 = 0\} = \{1, 2\}$
3) 부등식 조건: $C = \{x \mid x > 0 \text{ 그리고 } x < 5\} = (0, 5)$

## 학습 체크
- 주어진 조건 $P(x)$를 만족하는 $x$의 값을 정확히 찾아낼 수 있는가?
- 조건에 포함된 변수의 범위(예: 실수, 자연수 등)를 확인하였는가?
- 조건이 명확하여 집합의 원소가 유일하게 결정되는가?

## 관련 개념
- **집합과 명제**: 집합의 원소가 되는 조건은 명제의 형태를 띠며, 조건의 참과 거짓에 따라 집합의 원소 포함 여부가 결정됩니다.
