# 여집합

## 정확한 진술

전체집합 $U$와 $U$의 부분집합 $A$에 대해, **$A$의 여집합** $A^c$ (또는 $\complement_U A$)는 $U$에는 속하지만 $A$에는 속하지 않는 모든 원소들의 집합입니다.

$$A^c = \{x \in U \mid x \notin A\}$$

여집합은 항상 전체집합을 기준으로 정의됩니다. 만약 전체집합이 명확하지 않으면 여집합도 결정될 수 없습니다.

## 직관/기하적 의미

여집합은 주어진 집합에서 "빠진 부분"을 나타냅니다. 전체집합을 하나의 영역으로 생각하면, 집합 $A$는 그 일부를 차지하고, 여집합 $A^c$는 $A$가 차지하지 않은 나머지 부분입니다. 벤다이어그램에서 $A$의 여집합은 $A$ 바깥의 모든 영역(단, 전체집합 $U$ 내에서)으로 표현됩니다.

중요한 성질:
- $A \cup A^c = U$ (집합과 여집합의 합집합은 전체집합)
- $A \cap A^c = \emptyset$ (집합과 여집합의 교집합은 공집합)
- $(A^c)^c = A$ (여집합의 여집합은 원래 집합)

## 한 줄 예

$U = \{1, 2, 3, 4, 5\}$이고 $A = \{1, 3, 5\}$일 때, $A^c = \{2, 4\}$입니다.

더 나아가, 두 집합의 차집합도 여집합으로 표현할 수 있습니다: $A - B = A \cap B^c$. 여집합의 개념은 합집합, 교집합과 함께 드모르간의 법칙 $(A \cup B)^c = A^c \cap B^c$을 만드는 핵심 기초가 됩니다.
