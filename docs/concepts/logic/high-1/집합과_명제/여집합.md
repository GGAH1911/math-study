# 여집합

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
전체집합 $U$에 속하지만 주어진 집합 $A$에는 속하지 않는 원소들의 집합입니다.

## 본문
전체집합 $U$와 $U$의 부분집합 $A$에 대하여, $A$의 여집합 $A^c$ (또는 $\complement_U A$)는 $U$의 원소 중 $A$에 포함되지 않는 모든 원소들의 집합을 의미합니다. 이를 조건제시법으로 나타내면 $A^c = \{x \in U \mid x \notin A\}$입니다. 여집합은 반드시 전체집합 $U$가 무엇인지가 명확히 정의되어 있어야만 결정될 수 있습니다.

### 직관과 기하적 의미
여집합은 전체 영역에서 특정 집합이 차지하는 부분을 제외한 "나머지 부분"을 의미합니다. 벤다이어그램을 통해 시각화하면, 전체 영역인 $U$ 중에서 집합 $A$를 나타내는 원을 제외한 나머지 바깥 영역이 바로 $A^c$가 됩니다.

### 기본 성질
- $A \cup A^c = U$ (집합과 여집합의 합집합은 전체집합이 됩니다.)
- $A \cap A^c = \emptyset$ (집합과 여집합의 교집합은 공집합입니다.)
- $(A^c)^c = A$ (여집합의 여집합은 원래의 집합 $A$로 돌아갑니다.)

## 학습 체크
- 여집합을 구할 때 전체집합 $U$의 범위를 정확히 확인하였는가?
- 차집합 $A - B$를 $A \cap B^c$로 변환하여 계산할 수 있는가?
- 드모르간의 법칙을 적용할 때 여집합 기호가 분배되면서 연산자가 바뀌는 점을 주의하였는가?

## 관련 개념
- **집합과 명제**: 여집합은 집합의 연산을 구성하는 핵심 요소이며, 명제의 부정과 논리적 구조를 이해하는 기초가 됩니다.
- **차집합**: 두 집합의 차집합 $A - B$는 $A$와 $B$의 여집합의 교집합인 $A \cap B^c$로 표현할 수 있습니다.
- **드모르간의 법칙**: 여집합의 성질을 이용하여 합집합의 여집합을 각 집합의 여집합의 교집합으로 변환할 수 있습니다.
