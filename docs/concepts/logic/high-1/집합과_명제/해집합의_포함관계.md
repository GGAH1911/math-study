### 정확한 진술

두 방정식(또는 부등식) $P(x) = 0$과 $Q(x) = 0$에 대해, $P(x) = 0$의 해집합을 $A$, $Q(x) = 0$의 해집합을 $B$라고 하자. $A \subseteq B$일 때, "$P(x) = 0$의 해집합이 $Q(x) = 0$의 해집합에 **포함된다**"고 하고, "$A$는 $B$의 부분집합"이라고 표현한다. 특히 $A = B$일 때, 두 방정식의 **해집합이 같다**고 한다.

### 직관과 기하적 의미

수직선 위에서 해집합을 점이나 구간으로 나타낼 때, 해집합의 포함관계는 한 집합이 다른 집합에 완전히 포함되어 있는 상태를 말한다. 예를 들어 $x^2 = 4$의 해집합 $\{-2, 2\}$와 $x^2 - 4 = 0$의 해집합 $\{-2, 2\}$는 같으므로 $A = B$이다. 또한 $|x| < 1$의 해집합 $\{x \mid -1 < x < 1\}$은 $|x| < 2$의 해집합 $\{x \mid -2 < x < 2\}$에 포함되므로 $A \subseteq B$이다.

### 한 줄 예

$x^2 - 5x + 6 = 0$의 해는 $\{2, 3\}$이고, $(x-2)(x-3)(x-4) = 0$의 해는 $\{2, 3, 4\}$이므로 전자의 해집합이 후자의 해집합에 포함된다.

### 핵심 활용

두 방정식이 같은 해를 가질 조건을 판단할 때 해집합의 포함관계를 확인한다. 즉, $A = B \Leftrightarrow (A \subseteq B) \text{ and } (B \subseteq A)$를 이용하여 동치 관계를 증명하거나 확인할 수 있다. 특히 수열이나 함수 단원에서 "두 함수의 영점(零點)이 같다"는 표현도 이와 같은 맥락으로 이해할 수 있다.
