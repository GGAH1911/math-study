# 집합 원소 개수

> **예제** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
합집합의 원소 개수를 구할 때 중복되는 교집합의 원소 개수를 한 번 빼주는 원리입니다.

## 본문
어떤 학교의 동아리 가입 현황을 조사했다. 영어 동아리에 가입한 학생이 12명, 과학 동아리에 가입한 학생이 15명이다. 두 동아리에 모두 가입한 학생이 4명일 때, 영어 동아리 또는 과학 동아리에 적어도 하나 가입한 학생의 수를 구하시오.

### 단계별 풀이
영어 동아리에 가입한 학생의 집합을 $A$, 과학 동아리에 가입한 학생의 집합을 $B$라고 하자.
- $|A| = 12$
- $|B| = 15$
- $|A \cap B| = 4$

우리가 구해야 할 것은 "적어도 하나의 동아리에 가입한 학생", 즉 $|A \cup B|$이다.

처음 생각하기에는 $|A| + |B| = 12 + 15 = 27$이라 할 수 있겠지만, 이것은 틀렸다. 왜냐하면 두 동아리에 모두 가입한 4명의 학생이 중복으로 세어지기 때문이다.

포함배제 원리를 사용해야 한다. 합집합의 원소 개수는 각 집합의 원소 개수를 더한 후, 교집합의 원소 개수를 빼야 한다:
$$|A \cup B| = |A| + |B| - |A \cap B|$$
이를 이용하면:
$$|A \cup B| = 12 + 15 - 4 = 23$$

### 답과 변형
**23명**

포함배제 원리는 세 개 이상의 집합에도 적용된다. 집합 $A, B, C$에 대해 다음과 같이 확장된다:
$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$
일반 원칙은 홀수 개의 집합의 교집합은 더하고, 짝수 개의 집합의 교집합은 뺀다는 것이다. 합집합의 원소 개수를 구할 때 교집합을 빼먹지 않도록 주의해야 하며, "또는"으로 표현되는 문제에서는 항상 중복을 확인해야 한다.

## 학습 체크
- 두 집합의 합집합 원소 개수를 구할 때 교집합을 왜 빼야 하는지 설명할 수 있는가?
- 세 집합의 포함배제 원리 공식에서 부호가 왜 바뀌는지 이해했는가?
- 문제에서 "또는"이라는 표현이 나왔을 때 합집합을 떠올릴 수 있는가?

## 관련 개념
- **집합과 명제**: 집합의 연산과 원소의 개수를 다루는 기초적인 논리 구조를 제공합니다.
