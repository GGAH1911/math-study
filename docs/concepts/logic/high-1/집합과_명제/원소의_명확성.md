# 원소의 명확성

집합이 되기 위한 조건으로, 집합에 어떤 대상이 속하는지가 객관적으로 분명해야 한다는 성질입니다. 고1 집합과 명제 단원의 출발점입니다.

## 정의

어떤 대상이 모임에 속하는지 여부가 누가 보아도 같은 판단을 내릴 수 있도록 명확히 정해질 때 그 모임은 **집합**이 됩니다. 이 성질을 원소의 **명확성**이라 합니다.

수학에서 다루는 집합은 보통 다음 두 가지 표기 중 하나로 명확성을 확보합니다.
- **원소나열법:** 모든 원소를 직접 나열, 예: $\{1, 2, 3\}$.
- **조건제시법:** 원소가 만족하는 명확한 조건을 제시, 예: $\{x \mid x\text{는 } 5\text{ 이하의 자연수}\}$.

## 예시

집합 후보 두 가지를 비교해 봅니다.
- $A = \{x \mid x\text{는 } \pi\text{에 매우 가까운 수}\}$: "매우 가깝다"의 기준이 모호하므로 집합이 아닙니다.
- $B = \{x \mid x\text{는 } 0 \le x \le 10\text{인 자연수}\} = \{0, 1, \ldots, 10\}$: 조건이 명확하므로 집합입니다.
