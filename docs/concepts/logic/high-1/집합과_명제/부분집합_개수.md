# 부분집합 개수

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
원소의 개수가 $n$개인 유한집합의 부분집합의 총 개수는 $2^n$개이다.

## 본문
원소의 개수가 $n$인 유한집합 $A$의 모든 부분집합의 개수는 $2^n$개이다. 이때 $2^n$에는 공집합과 자기 자신인 집합 $A$가 모두 포함된다. 즉, 집합의 크기를 $|A|=n$이라고 할 때, 부분집합의 개수는 $2^n$으로 계산한다.

### 직관과 의미
각 원소에 대하여 해당 원소를 부분집합에 "포함할지" 또는 "포함하지 않을지"를 독립적으로 결정한다고 생각하면 이해하기 쉽다. $n$개의 원소 $a_1, a_2, \ldots, a_n$이 있을 때, 각 원소마다 선택할 수 있는 경우의 수는 포함(O) 또는 미포함(X)으로 총 2가지이다. 모든 원소에 대해 이 선택을 반복하므로, 곱의 법칙에 의해 전체 경우의 수는 $2 \times 2 \times \cdots \times 2 = 2^n$이 된다. 예를 들어 집합 $A = \{1, 2, 3\}$의 경우, 원소가 3개이므로 부분집합은 $2^3 = 8$개이며, 그 목록은 $\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$이다.

### 기본 성질
이 공식은 이항정리의 성질과도 밀접하게 연결된다. 원소 $n$개 중 $k$개를 선택하여 부분집합을 만드는 경우의 수는 조합 $\binom{n}{k}$로 나타낼 수 있으며, 모든 가능한 $k$에 대하여 이 값들을 모두 더하면 전체 부분집합의 개수인 $2^n$이 된다. 즉, $\sum_{k=0}^{n} \binom{n}{k} = 2^n$이라는 관계가 성립한다.

## 학습 체크
- 부분집합의 개수를 구할 때 공집합과 자기 자신을 포함하여 계산했는지 확인했는가?
- 원소의 개수가 늘어남에 따라 부분집합의 개수가 $2^n$의 규칙을 따르는지 이해했는가?
- 특정 원소를 반드시 포함하거나 반드시 제외해야 하는 조건이 있을 때의 계산법을 알고 있는가?

## 관련 개념
- **경우의 수**: 각 원소의 포함 여부를 결정하는 독립적인 선택의 과정이 곱의 법칙을 통해 전체 경우의 수로 연결된다.
- **조합**: 부분집합 중 원소의 개수가 $k$개인 것의 개수를 구할 때 $\binom{n}{k}$를 사용하며, 이를 모두 합하면 전체 부분집합의 개수가 된다.
