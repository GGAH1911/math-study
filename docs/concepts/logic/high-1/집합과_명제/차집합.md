# 차집합

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
한 집합에는 포함되지만 다른 집합에는 포함되지 않는 원소들만을 모아놓은 집합입니다.

## 본문
두 집합 $A, B$에 대하여 $A$에는 속하지만 $B$에는 속하지 않는 원소들의 집합을 **$A$와 $B$의 차집합**이라 하고 $A - B$ (또는 $A \setminus B$)로 표기합니다. 이를 조건제시법으로 나타내면 $A - B = \{x \mid x \in A,\ x \notin B\}$입니다.

### 직관과 기하적 의미
차집합은 집합 $A$에서 집합 $B$와 겹치는 부분을 도려내고 남은 부분만을 취하는 연산입니다. 벤 다이어그램으로 나타내면 집합 $A$의 영역 중 집합 $B$와 중복되는 영역을 제외한 나머지 부분에 해당합니다. 이때 주의할 점은 $A - B$와 $B - A$는 서로 다른 집합이 될 수 있다는 것입니다. 즉, 연산의 순서에 따라 결과가 달라지는 비대칭적인 성질을 가집니다.

### 기본 성질
차집합은 여집합을 이용하여 다음과 같이 표현할 수 있습니다.
- $A - B = A \cap B^c$ (전체집합이 정해진 경우)
- $A \cap B$와 $A - B$는 서로소이며, $A = (A \cap B) \cup (A - B)$입니다.
- 집합의 원소의 개수를 구할 때, $n(A - B) = n(A) - n(A \cap B)$가 성립합니다.

예를 들어 $A = \{1, 2, 3, 4, 5\}, B = \{3, 4, 5, 6, 7\}$일 때, $A - B = \{1, 2\}$이고 $B - A = \{6, 7\}$입니다. 또한 $n(A) = 5, n(A \cap B) = 3$이므로 $n(A - B) = 5 - 3 = 2$가 되어 계산 결과가 일치함을 확인할 수 있습니다.

## 학습 체크
- $A - B$와 $B - A$가 같아지기 위한 조건은 무엇인가?
- 차집합을 여집합을 이용한 교집합 형태로 변환할 수 있는가?
- 집합의 원소의 개수를 구할 때 중복되는 원소를 제외하는 원리를 이해하고 있는가?
