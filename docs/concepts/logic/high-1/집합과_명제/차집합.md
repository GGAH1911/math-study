# 차집합

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

한 집합에 속하지만 다른 집합에는 속하지 않는 원소들의 집합입니다. 고1 집합과 명제 단원의 기본 연산입니다.

## 정의

두 집합 $A, B$에 대하여 $A$에는 속하지만 $B$에는 속하지 않는 원소들의 집합을 **$A$와 $B$의 차집합**이라 하고 $A - B$ (또는 $A \setminus B$)로 표기합니다.
$$A - B = \{x \mid x \in A,\ x \notin B\}.$$
주요 성질:
- $A - B = A \cap B^c$ (전체집합이 정해진 경우).
- 일반적으로 $A - B \neq B - A$.
- $A \cap B$와 $A - B$는 서로소이며, $A = (A \cap B) \cup (A - B)$.
- $n(A - B) = n(A) - n(A \cap B)$.

## 예시

$A = \{1, 2, 3, 4, 5\}, B = \{3, 4, 5, 6, 7\}$일 때
$$A - B = \{1, 2\},\quad B - A = \{6, 7\}.$$

또한 $n(A) = 5, n(A \cap B) = 3$이므로 $n(A - B) = 5 - 3 = 2$로 위의 직접 계산과 일치합니다.
