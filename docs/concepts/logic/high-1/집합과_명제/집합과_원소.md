# 집합과 원소

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)
## 요약
명확히 정해진 원소들의 모임

## 본문

### 정확한 진술

**집합**(set)은 명확히 정해진 조건을 만족하는 대상들의 모임입니다. 이 모임에 속하는 각 대상을 **원소**(element)라고 부릅니다.

어떤 집합 $A$가 있을 때, 원소 $x$가 $A$에 속하면 "$x \in A$"로 표기하고, 속하지 않으면 "$x \notin A$"로 표기합니다. 집합은 보통 대문자 $A, B, C, \ldots$로, 원소는 소문자 $a, b, x, \ldots$로 나타냅니다.

**"명확히 정해진"이란 무엇인가?** 어떤 대상이 그 집합에 속하는지 속하지 않는지 판단할 수 있어야 합니다. 예를 들어 "모든 자연수의 집합"은 명확하지만, "큰 자연수의 집합"은 "큼"의 기준이 모호하므로 집합이 아닙니다.

### 직관과 의미

집합은 수학의 가장 기본적인 언어입니다. 마치 "과자 봉지"에 같은 종류의 과자들을 넣듯이, 공통된 성질을 가진 대상들을 하나의 단위로 묶어서 생각합니다. 이렇게 하면 복잡한 문제를 더 단순하고 체계적으로 다룰 수 있습니다.

원소를 쌍으로 생각하면: 원소가 "있다" 또는 "없다" 둘 중 하나만 가능합니다. 같은 원소를 여러 번 쓸 수 없고, 원소들의 순서도 상관없습니다.

### 구체적인 예

$A = \{1, 3, 5, 7, 9\}$ 일 때, $3 \in A$이고 $4 \notin A$입니다.

$B = \{x \mid x\text{는 10 이하의 소수}\} = \{2, 3, 5, 7\}$ 일 때, $5 \in B$이지만 $9 \notin B$입니다.

**핵심**: 원소와 집합의 관계는 단방향입니다. 원소는 집합 속에 "포함"되는 것이고, 집합은 여러 원소를 "포함하는" 것입니다. 이 관계를 정확히 이해하는 것이 집합 단원 전체의 출발점입니다.
