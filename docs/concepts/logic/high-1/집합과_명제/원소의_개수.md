# 원소의 개수

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
유한집합에 포함된 원소의 총 개수를 의미하며, 집합의 합집합과 교집합 사이의 관계를 나타내는 포함과 배제의 원리의 기초가 됩니다.

## 본문
유한집합 $A$의 원소의 개수를 $n(A)$로 표기합니다. 이는 집합에 속한 개별 원소들을 하나씩 세었을 때 나타나는 총합을 의미합니다. 공집합 $\varnothing$의 원소의 개수는 $0$, 즉 $n(\varnothing) = 0$입니다.

### 직관과 기하적 의미
두 집합 $A$와 $B$의 합집합에 있는 원소의 개수를 구할 때, 단순히 $n(A) + n(B)$를 하면 두 집합의 교집합인 $n(A \cap B)$ 영역이 중복되어 두 번 계산됩니다. 따라서 중복된 만큼을 한 번 빼주어야 정확한 합집합의 개수가 나옵니다. 이는 벤 다이어그램에서 두 원이 겹치는 부분을 고려하는 것과 같습니다.

### 기본 성질
두 유한집합 $A, B$에 대하여 다음의 포함과 배제의 원리가 성립합니다.
$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$
세 집합 $A, B, C$에 대해서는 다음과 같이 확장됩니다.
$$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C)$$

## 학습 체크
- $A = \{1, 2, 3, 4\}, B = \{3, 4, 5\}$일 때 $n(A \cup B)$를 구하는 과정이 포함과 배제의 원리와 일치하는가?
- 학생 $30$명 중 영어를 좋아하는 학생 $18$명, 수학을 좋아하는 학생 $15$명, 둘 다 좋아하는 학생 $8$명일 때, 적어도 하나를 좋아하는 학생의 수를 구할 수 있는가?
