# 원소의 개수

유한집합에 속한 원소의 총 개수를 가리키는 개념입니다. 고1 집합과 명제 단원에서 포함과 배제의 원리의 출발점입니다.

## 정의

유한집합 $A$의 원소의 개수를 $n(A)$로 표기합니다. 두 유한집합 $A, B$에 대해 다음의 포함과 배제의 원리가 성립합니다.
$$n(A \cup B) = n(A) + n(B) - n(A \cap B).$$

세 집합에 대해서는
$$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C).$$
공집합 $\varnothing$의 원소의 개수는 $0$, 즉 $n(\varnothing) = 0$입니다.

## 예시

$A = \{1, 2, 3, 4\}, B = \{3, 4, 5\}$일 때 $A \cap B = \{3, 4\}$이므로
$$n(A \cup B) = 4 + 3 - 2 = 5.$$
실제로 $A \cup B = \{1, 2, 3, 4, 5\}$로 일치합니다.

또한 학생 $30$명 중 영어를 좋아하는 학생이 $18$명, 수학을 좋아하는 학생이 $15$명, 둘 다 좋아하는 학생이 $8$명일 때 둘 중 적어도 하나를 좋아하는 학생의 수는
$$18 + 15 - 8 = 25.$$
