# 합집합

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
두 집합에 속하는 모든 원소를 중복 없이 한데 모은 집합입니다.

## 본문
두 집합 $A$와 $B$의 **합집합**(union)은 다음과 같이 정의합니다.
$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$
즉, $A$에 속하거나 $B$에 속하거나 둘 다에 속하는 모든 원소를 모아 만든 집합입니다. 여기서 "또는"은 수학에서 배타적 또는가 아니라 **포함적 또는**이므로, $A$와 $B$ 모두에 속하는 원소도 포함됩니다.

### 직관과 기하적 의미
벤 다이어그램으로 생각하면, 합집합은 두 집합을 나타내는 원판이 덮는 **전체 영역**을 의미합니다. 겹치는 부분과 각 집합에만 속하는 부분을 모두 포함합니다. 합집합의 원소 개수는 다음 공식으로 구할 수 있습니다.
$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$
두 집합의 원소 개수를 더할 때 겹치는 부분(교집합)이 중복 계산되기 때문에, 그만큼을 빼주어야 정확한 개수가 나옵니다.

### 기본 성질
- **결합 법칙**: $(A \cup B) \cup C = A \cup (B \cup C)$
- **교환 법칙**: $A \cup B = B \cup A$
- **항등원**: $A \cup \emptyset = A$
- **멱등성**: $A \cup A = A$

## 학습 체크
- 합집합을 구할 때 두 집합에 공통으로 들어있는 원소를 중복해서 적지는 않았나요?
- 합집합의 원소 개수를 구할 때 교집합의 개수를 왜 빼야 하는지 원리를 이해했나요?

## 관련 개념
- **집합과 명제**: 집합의 연산인 합집합은 명제의 논리 연산 중 '또는'과 대응되어 집합의 포함 관계를 다루는 기초가 됩니다.
