# 서로소

> **정의** · 고1 · 단원: [집합과 명제](/concepts/집합과_명제)

## 요약
두 사건이 동시에 일어날 수 없어 교집합이 공집합인 상태를 의미합니다.

## 본문
두 사건 $A, B$가 서로소(mutually exclusive)라는 것은 $A \cap B = \emptyset$임을 의미하며, 이는 두 사건이 동시에 일어날 수 없음을 뜻합니다. 이를 일반화하여 여러 사건 $A_1, A_2, \ldots, A_n$이 서로 배타적이라는 것은 임의의 서로 다른 두 사건을 선택하더라도 공통 원소를 가지지 않는 상태, 즉 $A_i \cap A_j = \emptyset$ (모든 $i \neq j$에 대해)를 의미합니다.

### 직관과 기하적 의미
확률 실험의 결과가 사건 $A$에 포함된다면, 그 결과는 절대로 사건 $B$에 포함될 수 없습니다. 이를 벤 다이어그램으로 시각화하면 두 사건을 나타내는 영역이 서로 겹치지 않고 완전히 떨어져 있는 모습으로 나타납니다.

### 기본 성질
두 사건이 서로소일 때, 합사건의 확률은 각 사건의 확률을 단순히 더한 값과 같습니다. 즉, $P(A \cup B) = P(A) + P(B)$가 성립합니다. 만약 두 사건이 서로소가 아니라면 교집합의 확률을 빼주는 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ 식을 사용해야 하므로, 서로소 여부를 확인하는 것은 확률 계산을 단순화하는 매우 중요한 과정입니다.

## 학습 체크
- 두 사건의 교집합이 공집합임을 나타내는 기호는 무엇인가요?
- 두 사건이 서로소일 때 합사건의 확률을 구하는 공식은 어떻게 변하나요?
- 주사위 눈이 홀수인 사건과 짝수인 사건은 서로소인가요?

## 관련 개념
- **확률**: 두 사건이 서로소이면 합사건의 확률을 구할 때 교집합의 확률을 고려할 필요 없이 각 확률의 합으로 계산할 수 있습니다.
