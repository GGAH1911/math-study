# 서로소

## 정확한 진술

두 사건 $A$, $B$가 **서로소**(mutually exclusive, 또는 배타적)라는 것은 $A \cap B = \emptyset$ (공집합)을 의미합니다. 즉, 두 사건이 동시에 일어날 수 없습니다. 더 일반적으로, 여러 사건 $A_1, A_2, \ldots, A_n$이 **서로 배타적**이라는 것은 어떤 두 사건도 공통 원소를 가지지 않음을 뜻합니다: $A_i \cap A_j = \emptyset$ (모든 $i \neq j$에 대해).

## 직관과 의미

확률 실험에서 발생한 결과가 사건 $A$에 속한다면, 동시에 사건 $B$에도 속할 수 없습니다. 벤 다이어그램으로 보면 두 사건의 영역이 전혀 겹치지 않는 모습입니다. 

이 성질이 확률론에서 중요한 이유는 **덧셈 정리**와 연결되기 때문입니다. 두 사건이 서로소일 때는 합사건의 확률을 간단하게 구할 수 있습니다:

$$P(A \cup B) = P(A) + P(B)$$

만약 서로소가 아니라면 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$로 교집합의 확률을 빼야 합니다. 따라서 서로소 여부를 판단하는 것은 확률 계산을 단순화하는 핵심입니다.

## 한 줄 예

주사위를 한 번 던질 때 $A = \{$홀수$\} = \{1, 3, 5\}$, $B = \{$짝수$\} = \{2, 4, 6\}$이면 $A \cap B = \emptyset$이므로 서로소이고, $P(A \cup B) = \frac{1}{2} + \frac{1}{2} = 1$입니다.
