# 원소 개수

## 정확한 진술

유한 집합 $A$의 **원소 개수**(또는 **크기, 기수**)는 집합에 속한 원소가 몇 개인지를 나타내는 음이 아닌 정수입니다. 이를 기호로 $|A|$ 또는 $n(A)$로 나타냅니다. 

예를 들어 집합 $A = \{1, 3, 5\}$이면 $|A| = 3$입니다. 특히 **공집합** $\emptyset$의 원소 개수는 $|\emptyset| = 0$입니다.

두 집합 $A$, $B$의 관계는 원소 개수로 다음과 같이 표현합니다:
- $A \subseteq B$이면 $|A| \le |B|$
- $A = B$이면 $|A| = |B|$

## 직관과 중요성

집합의 원소 개수는 그 집합이 얼마나 "크다"를 정량적으로 측정하는 방법입니다. 여사건이나 조합 문제를 풀 때 전체 경우의 수를 세어야 하는데, 이때 집합의 원소 개수 개념이 핵심입니다.

집합 연산과의 관계도 중요합니다. 일반적으로:
$$|A \cup B| = |A| + |B| - |A \cap B|$$

이는 두 집합을 합칠 때 겹치는 부분을 중복으로 세지 않기 위한 **포함-배제 원리**입니다. 전체 경우의 수를 구하거나 여집합을 이용한 여사건의 확률을 계산할 때 자주 사용됩니다.

## 한 줄 예

$A = \{2, 4, 6, 8\}$이고 $B = \{4, 8, 12\}$일 때, $|A| = 4$, $|B| = 3$이고, $A \cap B = \{4, 8\}$이므로 $|A \cup B| = 4 + 3 - 2 = 5$입니다.
