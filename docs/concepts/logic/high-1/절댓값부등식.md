### 정확한 진술

절댓값부등식은 절댓값 기호 $|\cdot|$를 포함한 부등식입니다. 실수 $a, b$에 대해 절댓값의 성질을 이용하면:

$$|x| < a \quad \Leftrightarrow \quad -a < x < a \quad (a > 0)$$
$$|x| > a \quad \Leftrightarrow \quad x < -a \text{ 또는 } x > a \quad (a > 0)$$

더 일반적으로, $|f(x)| < g(x)$ 꼴의 부등식은 $-g(x) < f(x) < g(x)$로 변환하여 풉니다. 단, $g(x) \geq 0$ 범위에서만 의미가 있습니다.

### 직관/기하적 의미

절댓값 $|x|$는 수직선 위에서 $x$와 0 사이의 거리를 나타냅니다. 따라서 $|x| < a$는 "0으로부터 거리가 $a$보다 작다"는 뜻이고, 이를 만족하는 $x$는 $-a$와 $a$ 사이의 열린 구간 $(-a, a)$입니다.

마찬가지로 $|x - c| < r$은 "점 $c$로부터 거리가 $r$보다 작다"는 의미이므로, 해는 구간 $(c-r, c+r)$입니다. 이 관점은 부등식을 푸는 과정에서 검산하거나 해를 직관적으로 이해할 때 유용합니다.

### 한 줄 예

$|x - 2| < 3$의 해는 $-1 < x < 5$입니다. (기하학적으로: 점 2로부터 거리 3 이내인 모든 점)

**검증**: `sympy.solve(abs(x - 2) < 3, x)` → $(-1, 5)$
