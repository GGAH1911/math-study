### 정확한 진술

집합 $A$를 나타낼 때, 원소가 만족해야 하는 **조건**을 명시하여 정의하는 방식을 사용합니다. 이를 **원소 조건**이라고 부르며, 다음과 같이 기호로 나타냅니다:

$$A = \{x \mid P(x)\}$$

여기서 $P(x)$는 변수 $x$에 대한 명제(조건)입니다. 이는 "집합 $A$는 조건 $P(x)$를 만족하는 모든 $x$의 모임"이라는 의미입니다. 기호 $\mid$ 또는 $:$는 "그러한" 또는 "만족하는"을 뜻합니다.

### 직관과 의미

원소 조건은 무한히 많은 원소를 가진 집합을 효율적으로 표현할 수 있게 해줍니다. 예를 들어 나열하기 어려운 실수의 집합도 하나의 조건으로 간단히 정의할 수 있습니다.

어떤 원소 $a$가 집합 $A$에 속하는지는 "$a$가 조건 $P(a)$를 만족하는가?"로 판단합니다. 만족하면 $a \in A$이고, 만족하지 않으면 $a \notin A$입니다. 따라서 **원소 조건은 집합의 경계를 결정하는 기준**이 됩니다.

### 예시

**1) 자연수 집합:**
$$A = \{x \mid x \text{는 10 이하의 짝수}\} = \{2, 4, 6, 8, 10\}$$
조건: "$x$는 10 이하의 짝수"

**2) 실수 집합:**
$$B = \{x \in \mathbb{R} \mid x^2 - 3x + 2 = 0\}$$
조건을 풀면 (sympy: `sympy.solve(x**2 - 3*x + 2, x)`) $x = 1$ 또는 $x = 2$이므로, $B = \{1, 2\}$입니다.

**3) 부등식 조건:**
$$C = \{x \mid x > 0 \text{ 그리고 } x < 5\} = (0, 5)$$

원소 조건을 명확히 기술하는 것이 집합을 정확히 이해하고 다루는 첫 걸음입니다.
