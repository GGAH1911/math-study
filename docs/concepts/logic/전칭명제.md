### 정확한 진술

전칭명제(universal proposition)는 주어진 집합의 **모든 원소**가 어떤 조건을 만족한다고 주장하는 명제입니다. 기호로는 $\forall x \in A, P(x)$로 표현하며, "모든 $x \in A$에 대하여 $P(x)$이다"라고 읽습니다. 여기서 $A$는 정의역(논의 영역)이고, $P(x)$는 $x$에 대한 조건이나 성질입니다.

전칭명제의 핵심은 **예외가 없다**는 것입니다. 진리값을 판단할 때, 전칭명제는 논의 영역의 **모든 원소**에 대해 조건이 성립해야만 참입니다. 단 하나의 원소라도 조건을 만족하지 않으면 그 명제는 거짓입니다. 이 반박하는 원소를 **반례(counterexample)**라고 부릅니다.

### 직관과 의미

전칭명제를 이해하려면 존재명제와 대비하면 좋습니다. "어떤 $x \in A$에 대하여 $P(x)$이다" (존재명제, $\exists x \in A, P(x)$)는 최소 하나의 원소가 조건을 만족하면 참이지만, 전칭명제는 모든 원소가 만족해야 참입니다.

전칭명제의 참/거짓을 보일 때:
- **참임을 보이려면**: 일반적인 증명(arbitrary element 선택 후 논리 전개)
- **거짓임을 보이려면**: 반례 하나만 찾으면 충분

### 예시

**예 1**: $\forall x \in \mathbb{R}, x^2 \geq 0$ 
→ 모든 실수의 제곱은 0 이상. **참**

**예 2**: $\forall x \in \mathbb{Z}, x > 0$  
→ 모든 정수가 양수라는 뜻. 반례: $x = -1$. **거짓**

**예 3**: $\forall x \in \{1, 2, 3\}, x < 5$  
→ 1, 2, 3 모두 5보다 작다. **참**

이 개념은 수학의 거의 모든 정리(theorem)가 전칭명제 형태라는 점에서 매우 중요합니다.
