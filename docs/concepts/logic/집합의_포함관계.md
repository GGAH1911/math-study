### 정확한 진술

집합 $A$의 모든 원소가 집합 $B$에 속할 때, "$A$는 $B$에 포함된다"고 하며, 이를 기호로 $A \subseteq B$ 또는 $B \supseteq A$로 나타냅니다.

$$A \subseteq B \Leftrightarrow \text{모든 } x \text{에 대해 } (x \in A \Rightarrow x \in B)$$

특히 $A \subseteq B$이면서 $A \neq B$인 경우를 **진부분집합**(proper subset)이라 하며 $A \subset B$로 표기합니다.

### 직관적·기하적 의미

포함관계는 한 집합이 다른 집합 "안에" 완전히 포함되는 상황을 나타냅니다. 벤 다이어그램으로 표현하면 $A$의 원소들이 모두 $B$의 영역 내에 있는 모습입니다.

일상적 예: "소수(素數)의 집합"은 "자연수의 집합"에 포함되므로, 모든 소수는 자연수입니다.

포함관계의 핵심 성질:
- **반사성**: $A \subseteq A$ (모든 집합은 자신에 포함)
- **추이성**: $A \subseteq B$이고 $B \subseteq C$이면 $A \subseteq C$
- **공집합의 성질**: $\emptyset \subseteq A$ (공집합은 모든 집합에 포함)
- **집합의 같음 정의**: $A = B$ $\Leftrightarrow$ $A \subseteq B \text{이고 } B \subseteq A$

### 한 줄 예

$A = \{1, 2\}$, $B = \{1, 2, 3\}$일 때, $A \subseteq B$입니다. (A는 B의 부분집합)

또한 $A = \{1, 3, 5\}$, $B = \{1, 3, 5\}$이면 $A \subseteq B$이면서 $B \subseteq A$이므로 $A = B$입니다.
