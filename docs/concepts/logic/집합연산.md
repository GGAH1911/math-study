### 정확한 진술

집합연산이란 두 개 이상의 집합으로부터 새로운 집합을 만드는 방법입니다. 고등학교 수학에서 다루는 기본 집합연산은 다음과 같습니다.

**합집합(union)** $A \cup B$: $A$에 속하거나 $B$에 속하는 모든 원소들의 집합
$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$

**교집합(intersection)** $A \cap B$: $A$에도 속하고 $B$에도 속하는 원소들의 집합
$$A \cap B = \{x \mid x \in A \text{ 그리고 } x \in B\}$$

**여집합(complement)** $A^c$ 또는 $\bar{A}$: 전체집합 $U$에 속하면서 $A$에는 속하지 않는 원소들의 집합
$$A^c = \{x \mid x \in U, x \notin A\}$$

**차집합(difference)** $A - B$ 또는 $A \setminus B$: $A$에는 속하지만 $B$에는 속하지 않는 원소들의 집합
$$A - B = \{x \mid x \in A, x \notin B\}$$

### 직관/기하적 의미

벤 다이어그램에서 합집합은 두 원의 전체 영역을, 교집합은 겹치는 중앙 부분을 나타냅니다. 여집합은 해당 집합 밖의 모든 영역이고, 차집합은 한쪽 원에만 속하는 영역입니다. 이를 통해 집합연산을 시각적으로 이해하면 교환법칙, 결합법칙, 드모르간 법칙 같은 성질들을 기하학적으로 확인할 수 있습니다.

### 한 줄 예

$A = \{1, 2, 3\}$, $B = \{2, 3, 4\}$일 때:
- $A \cup B = \{1, 2, 3, 4\}$
- $A \cap B = \{2, 3\}$  
- $A - B = \{1\}$

(검산: `set([1,2,3]) | set([2,3,4])` = {1, 2, 3, 4})
