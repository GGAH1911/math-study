### 정확한 진술

두 집합 $A$와 $B$의 **합집합**(union)은 다음과 같이 정의합니다.

$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$

즉, $A$에 속하거나 $B$에 속하거나 둘 다에 속하는 모든 원소를 모아 만든 집합입니다. "또는"은 수학에서 배타적 또는(exclusive or)이 아니라 **포함적 또는**(inclusive or)이므로, $A$와 $B$ 모두에 속하는 원소도 포함됩니다.

### 직관과 기하적 의미

벤 다이어그램으로 생각하면, 합집합은 두 집합을 나타내는 원판이 덮는 **전체 영역**입니다. 겹치는 부분도 포함하고, 한쪽에만 속하는 부분도 모두 포함합니다.

합집합의 크기는 다음 공식으로 구합니다.

$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$

두 집합의 원소 개수를 더한 후 겹치는 부분(교집합)을 빼는 이유는, 겹치는 원소를 중복 계산했기 때문입니다.

### 기본 성질

- **결합 법칙**: $(A \cup B) \cup C = A \cup (B \cup C)$
- **교환 법칙**: $A \cup B = B \cup A$
- **항등원**: $A \cup \emptyset = A$ (공집합과의 합은 자기 자신)
- **멱등성**: $A \cup A = A$

### 예시

$A = \{1, 2, 3\}$, $B = \{2, 3, 4, 5\}$일 때, $A \cup B = \{1, 2, 3, 4, 5\}$입니다. 

원소 2와 3은 두 집합에 모두 속하지만, 합집합에서는 한 번만 나타납니다. 이를 확인하면: $n(A) = 3$, $n(B) = 4$, $n(A \cap B) = 2$이므로 $n(A \cup B) = 3 + 4 - 2 = 5$ ✓
