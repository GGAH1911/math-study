### 정확한 진술

집합 $A$의 크기(cardinality) 또는 원소의 개수는 그 집합에 속한 서로 다른 원소의 총 개수를 나타냅니다. 이를 기호로 $|A|$ 또는 $n(A)$로 표기합니다. 예를 들어, 유한집합 $A = \{2, 4, 6, 8\}$이면 $|A| = 4$입니다. 공집합 $\emptyset$의 크기는 $|\emptyset| = 0$입니다.

### 직관과 의미

집합의 크기는 "얼마나 많은 원소를 포함하는가"라는 질문에 답합니다. 집합에 같은 원소가 여러 번 나타나더라도 한 번만 세어집니다. 예를 들어, 명시적 나열의 중복을 무시합니다: $\{1, 1, 2, 2, 2, 3\} = \{1, 2, 3\}$이므로 크기는 3입니다. 이는 합의 원리, 포함-배제 원리 등 조합론의 기초가 됩니다. 또한 두 집합의 크기가 같으면 일대일 대응이 존재한다는 의미로, 집합의 본질적 구조를 파악하는 데 핵심 개념입니다.

### 한 줄 예

$A = \{a, e, i, o, u\}$일 때, $|A| = 5$이며, $B = \{x \mid x \in \mathbb{Z}, -2 < x \leq 3\}$는 $B = \{-1, 0, 1, 2, 3\}$이므로 $|B| = 5$입니다.

### 확장: 여집합과의 관계

전체집합 $U$와 그 부분집합 $A$에 대해, 여집합 $A^c$의 크기는 다음을 만족합니다:
$$|A^c| = |U| - |A|$$

이 관계식은 여사건의 확률 계산($P(A^c) = 1 - P(A)$)로도 자연스럽게 확장됩니다.
