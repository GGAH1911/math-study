### 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 잇는 선분 $AB$ 위의 점 $P$가 $\overline{AP} : \overline{PB} = m : n$을 만족할 때, $P$를 선분 $AB$를 **$m : n$으로 내분하는 점**이라 합니다. 이때 $P$의 좌표는

$$P = \left( \frac{mx_2 + nx_1}{m+n}, \frac{my_2 + ny_1}{m+n} \right)$$

특히 $m = n$인 경우, 즉 선분의 중점을 $M$이라 하면

$$M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$$

### 직관과 기하적 의미

선분 $AB$ 위의 내분점 $P$는 $A$에서 출발하여 $B$ 방향으로 가되, 남은 거리와의 비율이 $m : n$으로 고정된 지점입니다. 이는 선분을 **정확한 비율로 나누는** 기하학적 작업입니다.

중점은 내분점의 가장 특별한 경우로, 선분을 **정확히 반으로** 나눕니다. 벡터로 생각하면 $\overrightarrow{AP} = \frac{m}{m+n} \overrightarrow{AB}$이므로, 내분점은 $A$에서 $B$로 향하는 벡터를 특정 비율만큼 진행한 위치입니다.

### 한 줄 예와 검산

$A(0, 0)$, $B(6, 3)$을 $2:1$로 내분하는 점은 $\left(\frac{2 \cdot 6 + 1 \cdot 0}{3}, \frac{2 \cdot 3 + 1 \cdot 0}{3}\right) = (4, 2)$입니다.

같은 두 점의 중점은 $\left(\frac{0+6}{2}, \frac{0+3}{2}\right) = (3, 1.5)$입니다.

```python
# sympy로 검산: A(0, 0), B(6, 3)을 2:1로 내분
from sympy import Point
A, B = Point(0, 0), Point(6, 3)
P = Point(A.x + (2/3)*(B.x - A.x), A.y + (2/3)*(B.y - A.y))
print(P)  # (4, 2)
```
