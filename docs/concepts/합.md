# 합

## 요약
두 개 이상의 수를 더하여 하나의 새로운 수를 얻는 연산 과정입니다.

## 본문
두 개 이상의 수나 항을 더하여 하나의 결과값을 얻는 연산을 합이라고 합니다. 수학적 기호로는 더하기 기호인 $+$를 사용하여 나타내며, 연산의 결과로 나온 값을 합 또는 결과값이라고 부릅니다. 합은 수의 크기를 결합하여 전체량을 구하는 가장 기초적인 산술 연산 중 하나입니다.

### 직관과 기하적 의미
두 물체의 길이를 이어 붙였을 때 전체 길이를 구하는 과정이나, 두 영역의 넓이를 합쳐 전체 넓이를 구하는 과정으로 이해할 수 있습니다. 수직선 위에서 한 점으로부터 특정 거리만큼 이동했을 때 도달하는 지점을 찾는 과정으로도 해석이 가능합니다.

### 기본 성질
합에는 교환법칙과 결합법칙이 성립합니다. 교환법칙에 의해 더하는 순서를 바꾸어도 결과는 동일하며, 결합법칙에 의해 세 개 이상의 수를 더할 때 어떤 두 수를 먼저 더하더라도 결과는 같습니다. 또한 어떤 수에 $0$을 더하면 자기 자신이 나오는 항등원의 성질을 가집니다.

## 학습 체크
- 더하는 수의 순서가 바뀌어도 결과가 변하지 않는 성질을 이해하고 있는가?
- 여러 개의 수를 더할 때 어떤 순서로 계산해도 결과가 같은 이유를 설명할 수 있는가?

## 관련 개념
- **수열**: 수열의 각 항을 순서대로 더하여 얻은 값을 부분합 또는 급수라고 하며, 이는 합의 개념이 확장된 형태입니다.
