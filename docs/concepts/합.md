### 정확한 진술

수열 $\{a_n\}$의 처음 $n$개 항을 모두 더한 값을 그 수열의 **합**(sum)이라고 하며, 다음과 같이 나타냅니다.

$$S_n = a_1 + a_2 + a_3 + \cdots + a_n$$

이를 **시그마 기호** $\sum$를 사용해 간결하게 표현하면:

$$S_n = \sum_{k=1}^{n} a_k$$

여기서 $S_n$을 **부분합**(partial sum)이라고 부르며, $k$는 합하는 항의 번호(인덱스)입니다.

### 직관과 의미

합은 수열의 각 항들을 차례대로 누적해 나가는 과정입니다. 예를 들어, 매달 저축액이 수열을 이루면, 그 합은 총 저축액이 됩니다. 수열 자체가 개별 데이터라면, 합은 그 데이터들을 종합한 결과값입니다.

시그마 기호는 "합을 구하라"는 명령어로, 수학에서 복잡한 덧셈을 간단하게 표기하는 약속입니다. 같은 패턴의 덧셈이 많을수록 시그마 표기의 가치가 커집니다.

### 한 줄 예

수열 $1, 2, 3, 4, 5$의 합은 $S_5 = 1+2+3+4+5 = 15$ 또는 $\sum_{k=1}^{5} k = 15$입니다.

### 실제 계산 예시

수열 $\{a_n\} = 2n$일 때, 처음 4개 항의 합:
- $a_1 = 2$, $a_2 = 4$, $a_3 = 6$, $a_4 = 8$
- $S_4 = 2 + 4 + 6 + 8 = 20$ = $\sum_{k=1}^{4} 2k$

수학1에서는 특히 **등차수열의 합**과 **등비수열의 합**에 유용한 공식들이 있으며, 이들 공식을 유도할 때 이 기본 정의가 출발점이 됩니다.
