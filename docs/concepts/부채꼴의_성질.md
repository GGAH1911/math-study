# 부채꼴의 성질

## 요약
반지름과 중심각의 크기에 따른 부채꼴의 호의 길이와 넓이를 구하며, 이를 활용해 삼각함수의 극한을 결정하는 부등식을 유도할 수 있다.

## 본문
반지름의 길이가 $r$이고 중심각의 크기가 $\theta$ (라디안)인 부채꼴에서 호의 길이 $l$은 $r\theta$이며, 넓이 $S$는 $\frac{1}{2}r^2\theta$ 또는 $\frac{1}{2}rl$로 나타낼 수 있다. 이러한 성질은 단위원($r=1$) 위에서 기하학적 넓이 비교를 통해 삼각함수의 극한을 다루는 핵심 도구가 된다.

### 직관과 기하적 의미
$0 < \theta < \dfrac{\pi}{2}$인 범위에서 단위원 위의 세 도형인 삼각형, 부채꼴, 외부 삼각형의 넓이를 비교하면 $\frac{1}{2}\sin\theta < \frac{1}{2}\theta < \frac{1}{2}\tan\theta$라는 부등식이 성립한다. 이는 중심각 $\theta$가 작아질수록 세 도형의 넓이가 서로 매우 유사해짐을 의미하며, 이를 통해 $\theta$가 $0$으로 수렴할 때의 극한값을 결정할 수 있다.

### 기본 성질
위의 부등식의 각 항을 $\frac{1}{2}\sin\theta$로 나누면 $1 < \frac{\theta}{\sin\theta} < \frac{1}{\cos\theta}$를 얻는다. $\theta \to 0$일 때 $\frac{1}{\cos\theta} \to 1$이므로, 끼인값 정리에 의해 $\lim_{\theta \to 0} \frac{\sin\theta}{\theta} = 1$임이 증명된다. 이는 수열의 극한에서도 $n \to \infty$일 때 $\frac{\sin(1/n)}{1/n} \to 1$이 되는 원리와 동일하다.

## 학습 체크
- 반지름 $r$과 중심각 $\theta$가 주어졌을 때 호의 길이와 넓이를 각각 구할 수 있는가?
- 단위원에서의 넓이 비교 부등식을 이용하여 $\frac{\sin\theta}{\theta}$의 극한값을 유도할 수 있는가?
- 부채꼴의 넓이 공식 $S = \frac{1}{2}rl$이 성립하는 이유를 기하학적으로 설명할 수 있는가?

## 관련 개념

**수열의 극한** — 부채꼴 넓이 부등식은 삼각함수가 포함된 수열의 극한을 샌드위치 정리로 처리할 때 부등식의 양 끝을 공급한다. 이 연결이 이 개념을 수열의 극한 단원에서 배우는 핵심 이유다.

**부채꼴** — $l = r\theta$, $S = \tfrac{1}{2}r^2\theta$는 부채꼴의 기본 공식이다. 중심각이 반드시 **라디안** 단위여야 성립하므로, 각도(°)를 라디안으로 변환하는 것에 주의한다.

**삼각함수의 극한** — $\displaystyle\lim_{\theta \to 0}\frac{\sin\theta}{\theta} = 1$과 $\displaystyle\lim_{\theta \to 0}\frac{\tan\theta}{\theta} = 1$은 모두 부채꼴 넓이 부등식에서 출발한다. 이 두 극한은 이후 미분의 정의에서도 반복적으로 등장한다.

**샌드위치 정리(끼인값 정리)** — 두 수열 $a_n \leq b_n \leq c_n$이고 $a_n, c_n$이 같은 극한값으로 수렴하면 $b_n$도 같은 값으로 수렴한다는 정리로, 부채꼴 부등식과 결합하여 직접 계산하기 어려운 삼각함수 극한을 처리한다.
