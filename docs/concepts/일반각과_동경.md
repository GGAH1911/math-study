# 일반각과 동경

## 정의

**동경(動徑)** 은 원점을 중심으로 시초선(양의 $x$축)에서 회전한 반직선을 말하며, 회전 방향과 크기를 나타내는 각을 **일반각** 이라 한다. 반시계 방향을 양(+), 시계 방향을 음(−)으로 정의한다. 하나의 동경이 나타내는 각도는 무수히 많으며, 시초선에서 $\alpha$만큼 회전한 동경이 나타내는 일반각은 다음과 같다.

$$\theta = \alpha + 360° \cdot n \quad (n \in \mathbb{Z})$$

라디안으로는 $\theta = \alpha + 2\pi n$으로 표현한다.

## 예시

$-30°$와 같은 위치에 있는 동경의 일반각을 구하여라.

$$\theta = -30° + 360° \cdot n \quad (n \in \mathbb{Z})$$

예를 들어 $n=1$이면 $330°$, $n=-1$이면 $-390°$가 되어 모두 같은 동경 위치이다.
