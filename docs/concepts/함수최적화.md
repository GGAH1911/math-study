### 정확한 진술

함수최적화(function optimization)는 공간도형이나 공간벡터 상황에서 특정 제약 조건 하에 거리, 부피, 표면적 같은 기하학적 양을 최솟값 또는 최댓값으로 만드는 점이나 도형의 위치를 찾는 과정입니다. 수학적으로는 목적 함수(objective function) $f(x, y, z)$를 제약 조건(constraint) $g(x, y, z) = 0$ 아래에서 최소화 또는 최대화하는 것입니다.

### 직관과 기하적 의미

기하에서의 함수최적화는 "가장 좋은 위치"를 찾는 문제입니다. 예를 들어:
- 공간의 정해진 점에서 주어진 평면까지의 거리가 최소인 지점은 그 점에서 평면에 수직인 방향입니다.
- 원뿔에 내접하는 원기둥의 부피가 최대가 되려면 어느 높이에 설정해야 할까요?
- 사면체에서 한 꼭짓점에서 대면(對面)까지의 최단 거리는 어떻게 구할까요?

이들은 모두 공간벡터의 수직 관계나 거리 공식 $d = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$ 를 활용하여 해결합니다. 기하학적 직관(수직일 때 거리 최소, 대칭성 등)을 이용하면 미적분 없이도 최적값을 찾을 수 있습니다.

### 한 줄 예

점 $P(1, 2, 4)$에서 평면 $2x + y + 2z = 9$ 위의 점까지의 최단거리는 $\frac{|2(1) + 1(2) + 2(4) - 9|}{\sqrt{4 + 1 + 4}} = \frac{|2 + 2 + 8 - 9|}{3} = 1$ 입니다. (공식 검증: `from sympy import *; print(abs(2*1 + 1*2 + 2*4 - 9) / sqrt(4 + 1 + 4))`)
