# 평균 분산 계산

> **예제** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
주어진 자료에서

## 본문 (학습 시 채워짐)

### 문제

어느 학급의 수학 시험 점수 다섯 명이 다음과 같습니다: 60, 70, 80, 90, 95

이 자료의 평균과 분산을 구하고, 이 점수들이 평균으로부터 얼마나 퍼져 있는지 설명하세요.

### 단계별 풀이

**1단계: 평균 구하기**

평균 $\bar{x}$은 모든 값의 합을 자료의 개수로 나눕니다.

$$\bar{x} = \frac{60 + 70 + 80 + 90 + 95}{5} = \frac{395}{5} = 79$$

**2단계: 각 자료와 평균의 차이 계산**

분산을 구하려면 먼저 각 값이 평균에서 얼마나 벗어났는지 봅니다.

$$60 - 79 = -19, \quad 70 - 79 = -9, \quad 80 - 79 = 1$$
$$90 - 79 = 11, \quad 95 - 79 = 16$$

**3단계: 편차를 제곱하여 합하기**

편차들을 제곱하면 음수를 없애고 큰 벗어남을 더 크게 반영합니다.

$$(-19)^2 = 361, \quad (-9)^2 = 81, \quad 1^2 = 1$$
$$11^2 = 121, \quad 16^2 = 256$$

$$\text{제곱의 합} = 361 + 81 + 1 + 121 + 256 = 820$$

**4단계: 분산 구하기**

분산 $s^2$은 제곱한 편차들의 평균입니다.

$$s^2 = \frac{820}{5} = 164$$

### 답

- 평균: $\bar{x} = 79$점
- 분산: $s^2 = 164$
- 표준편차: $s = \sqrt{164} \approx 12.8$점

점수들이 평균 79점 주변에서 표준편차 약 12.8점 범위 내에 분포하고 있습니다.

```
# sympy로 검산
import statistics
data = [60, 70, 80, 90, 95]
print(f"평균: {statistics.mean(data)}, 분산: {statistics.variance(data)}")
```

### 변형/주의

- **분산이 클수록** 자료가 평균에서 멀리 퍼져 있고, **작을수록** 평균 근처에 몰려 있습니다.
- 편차를 제곱하는 이유는 양수/음수 상관없이 벗어남의 크기를 측정하기 위함입니다.
- 중학교에서는 전체 자료에 대한 분산을 배우므로 분모를 $n$으로 나눕니다. (고등학교에서 표본분산은 $n-1$로 나눔)
