# 경우의 수 (고1)

> **단원** · 고1 · 선수: [확률 중2](./확률_중2.md) · 다음: [경우의 수](./경우의_수.md)

## 학습 목표
- 순열과 조합으로 경우의 수를 정확히 센다
- 합·곱의 법칙을 응용 문제에 적용한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 순열 $_nP_r$, 조합 $_nC_r$

**정리(theorem)**
- $_nP_r=\frac{n!}{(n-r)!}$, $_nC_r=\frac{n!}{r!(n-r)!}$
- $_nC_r={}_nC_{n-r}$

**예제(example)**
- 줄세우기 (순열)
- 뽑기 (조합)
- 같은 것이 있는 순열
- 원순열
