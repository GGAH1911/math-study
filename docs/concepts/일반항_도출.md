# 일반항 도출

## 요약
수열의 규칙성을 파악하여 임의의 항을 나타내는 식 $a_n$을 찾아내는 과정입니다.

## 본문
수열의 일반항 도출은 수열을 이루는 각 항 사이의 관계나 항의 번호 $n$과 항의 값 $a_n$ 사이의 규칙을 찾아내어, 이를 $n$에 관한 식 $a_n = f(n)$의 형태로 나타내는 것을 의미합니다. 이는 수열의 모든 항을 일일이 나열하지 않고도 원하는 위치의 항을 즉각적으로 계산할 수 있게 해주는 수학적 도구입니다.

### 직관과 기하적 의미
일반항은 수열을 하나의 함수적 관점에서 바라보게 합니다. 예를 들어, 등차수열의 일반항은 $n$에 대한 일차함수(직선)의 형태를 띠며, 등비수열의 일반항은 지수함수의 형태를 띱니다. 즉, 수열의 일반항을 구하는 것은 이산적인 점들의 나열을 관통하는 함수적 규칙을 찾는 과정과 같습니다.

### 기본 성질
가장 대표적인 두 가지 형태는 등차수열과 등비수열입니다. 첫째 항을 $a_1$, 공차를 $d$라고 할 때 등차수열의 일반항은 $a_n = a_1 + (n-1)d$로 나타나며, 이는 일차함수의 성질을 가집니다. 둘째 항을 $a_1$, 공비를 $r$이라고 할 때 등비수열의 일반항은 $a_n = a_1 \cdot r^{n-1}$로 나타나며, 이는 지수함수의 성질을 가집니다. 그 외에도 계차수열이나 점화식 형태의 복잡한 규칙도 일반항 도출의 대상이 됩니다.

## 학습 체크
- 수열의 항들이 일정한 차이로 증가하는지, 혹은 일정한 비율로 곱해지는지 확인하였는가?
- 구한 일반항에 $n=1$을 대입했을 때 실제 첫째 항의 값과 일치하는가?
- 일반항이 $n$에 대한 식일 때, $n$에 들어갈 수 있는 값의 범위가 자연수임을 고려하였는가?

## 관련 개념
- **수열**: 일반항을 통해 수열의 모든 항을 정의하며, 수열의 성질을 분석하는 기초가 됩니다.
- **등차수열**: 일반항이 $n$에 대한 일차식으로 나타나는 특수한 형태의 수열입니다.
- **등비수열**: 일반항이 $n$에 대한 지수식으로 나타나는 특수한 형태의 수열입니다.
