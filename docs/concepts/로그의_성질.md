# 로그의 성질

> **정리** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\log(xy)=\log x+\log y$ 등

## 본문 (학습 시 채워짐)

### 정리의 진술 및 가정

$a > 0, a \neq 1$일 때, $x > 0, y > 0$이면 다음이 성립한다.

1. **곱의 로그**: $\log_a(xy) = \log_a x + \log_a y$
2. **나눗셈의 로그**: $\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y$
3. **거듭제곱의 로그**: $\log_a(x^n) = n\log_a x$ (단, $n$은 실수)

이 성질들은 밑이 10인 상용로그나 밑이 $e$인 자연로그에서도 동일하게 성립한다.

### 증명 스케치

로그의 정의 $\log_a x = p \Leftrightarrow a^p = x$를 이용한다.

$\log_a x = p, \log_a y = q$라 하면, $a^p = x, a^q = y$이다. 따라서
$$xy = a^p \cdot a^q = a^{p+q}$$

양변에 로그를 취하면
$$\log_a(xy) = p + q = \log_a x + \log_a y$$

나눗셈의 성질은 지수법칙 $\frac{a^p}{a^q} = a^{p-q}$에서, 거듭제곱의 성질은 $(a^p)^n = a^{pn}$에서 같은 방식으로 유도된다.

### 의의 및 응용

로그의 성질은 곱셈을 덧셈으로, 나눗셈을 뺄셈으로 전환시킨다. 이를 통해 복잡한 지수 방정식을 풀 수 있다. 예를 들어 $3^x = 50$을 풀려면 양변에 로그를 취해
$$x\log 3 = \log 50 \implies x = \frac{\log 50}{\log 3}$$

를 얻는다. 또한 과학·공학에서 pH, 음의 크기(데시벨), 지진의 규모 등 지수적으로 변하는 현상을 다룰 때 필수적이다.

**예**: $\log 12 = \log(4 \times 3) = \log 4 + \log 3 = 2\log 2 + \log 3$ (sympy: `sympy.log(12).rewrite(sympy.log).simplify()`)
