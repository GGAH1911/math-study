# 무리함수 미분

## 정의

$f(x) = \sqrt{g(x)} = [g(x)]^{1/2}$ 꼴의 함수를 미분할 때는 **합성함수 미분법(연쇄법칙)**을 적용한다.

$$\frac{d}{dx}\sqrt{g(x)} = \frac{g'(x)}{2\sqrt{g(x)}} \quad (g(x)>0)$$

특히 $g(x)=x$이면 $\frac{d}{dx}\sqrt{x} = \frac{1}{2\sqrt{x}}$ ($x>0$)이다. $g(x)=0$인 점에서는 도함수가 정의되지 않거나 무한대로 발산할 수 있으므로 정의역에 주의해야 한다.

## 예시

$f(x) = \sqrt{x^2+3}$을 미분하면 $g(x)=x^2+3$, $g'(x)=2x$이므로

$$f'(x) = \frac{2x}{2\sqrt{x^2+3}} = \frac{x}{\sqrt{x^2+3}}$$

$x=1$에서 $f'(1) = \dfrac{1}{\sqrt{4}} = \dfrac{1}{2}$.
