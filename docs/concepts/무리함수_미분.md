# 무리함수 미분

## 요약
무리함수 $f(x) = \sqrt{g(x)}$의 미분은 합성함수 미분법을 이용하여 $\tfrac{g'(x)}{2\sqrt{g(x)}}$로 계산한다.

## 본문
$f(x) = \sqrt{g(x)} = [g(x)]^{1/2}$ 꼴의 함수를 미분할 때는 합성함수 미분법(연쇄법칙)을 적용한다. 미분 공식은 다음과 같다.
$$\frac{d}{dx}\sqrt{g(x)} = \frac{g'(x)}{2\sqrt{g(x)}} \quad (g(x)>0)$$
특히 가장 기본적인 형태인 $g(x)=x$인 경우, $\tfrac{d}{dx}\sqrt{x} = \tfrac{1}{2\sqrt{x}}$ ($x>0$)가 성립한다. 이때 주의할 점은 $g(x)=0$인 지점에서는 분모가 $0$이 되므로 도함수가 정의되지 않거나 무한대로 발산할 수 있다는 것이다. 따라서 무리함수를 미분할 때는 항상 함수의 정의역과 도함수의 정의역을 구분하여 주의 깊게 살펴야 한다.

예를 들어 $f(x) = \sqrt{x^2+3}$을 미분하는 과정을 살펴보자. 여기서 $g(x)=x^2+3$이라 하면 $g'(x)=2x$이므로, 합성함수 미분법에 의해 $f'(x) = \tfrac{2x}{2\sqrt{x^2+3}} = \tfrac{x}{\sqrt{x^2+3}}$이 된다. 만약 $x=1$에서의 미분계수를 구하고자 한다면 $f'(1) = \tfrac{1}{\sqrt{4}} = \tfrac{1}{2}$임을 알 수 있다.

### 직관과 기하적 의미
무리함수의 그래프는 특정 지점에서 접선의 기울기가 급격히 변하거나, 정의역의 경계에서 접선이 수직에 가까워지는 특성을 가질 수 있다. 이는 미분 계수가 정의되지 않는 지점과 밀접한 관련이 있다.

### 기본 성질
- $g(x)$가 미분 가능한 함수일 때, $\sqrt{g(x)}$의 미분은 $g'(x)$를 $2\sqrt{g(x)}$로 나눈 값과 같다.
- 분모가 $0$이 되지 않도록 $g(x)>0$인 범위 내에서 미분이 이루어져야 한다.
