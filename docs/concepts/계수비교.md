### 정확한 진술

두 다항식이 모든 $x$에 대해 항등적으로 같으면, 각 차수의 계수는 모두 같습니다.

예를 들어:
$$a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 = b_nx^n + b_{n-1}x^{n-1} + \cdots + b_1x + b_0$$

이면 $a_n = b_n$, $a_{n-1} = b_{n-1}$, ..., $a_0 = b_0$입니다.

### 직관 및 의미

다항식의 각 차수 항은 수학적으로 독립적입니다. 두 다항식이 모든 실수 $x$에 대해 같다는 것은 "우연히" 같은 것이 아니라 **구조적으로** 같다는 뜻입니다. 따라서 같은 차수의 항끼리만 비교하면 됩니다.

이는 특정 값을 여러 번 대입하는 방법보다 훨씬 효율적입니다. 미지수가 많을 때 한 번에 모두 구할 수 있고, 실수할 가능성도 줄입니다.

### 활용 예

**문제:** $x^2 + px + q = (x-1)^2$을 만족하는 $p$, $q$를 구하세요.

**풀이:** 우변을 전개하면:
$$(x-1)^2 = x^2 - 2x + 1$$

양변의 계수를 비교하면:
- $x^2$ 계수: $1 = 1$ (자동 만족)
- $x^1$ 계수: $p = -2$
- $x^0$ 계수: $q = 1$

**답:** $p = -2$, $q = 1$

**참고:** 계수비교는 부분분수 분해, 다항식 나눗셈의 나머지 구하기, 미정계수법 등에서 필수적으로 사용됩니다.
