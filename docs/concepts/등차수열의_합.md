# 등차수열의 합

> **정리** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
$S_n=n(a_1+a_n)/2$

## 본문 (학습 시 채워짐)

### 진술 및 가정

첫째항이 $a_1$, 공차가 $d$인 등차수열 $\{a_n\}$의 첫 $n$항까지의 합 $S_n$은 다음과 같습니다.

$$S_n = \frac{n(a_1 + a_n)}{2}$$

또는 $a_n = a_1 + (n-1)d$를 대입하면 다음 형태로도 나타낼 수 있습니다.

$$S_n = \frac{n}{2}\{2a_1 + (n-1)d\}$$

### 유도 및 증명 스케치

등차수열의 합을 두 가지 순서로 나열하여 더합니다. 첫 $n$항의 합을 $S_n = a_1 + a_2 + \cdots + a_n$이라 하면, 역순으로 쓴 것은 $S_n = a_n + a_{n-1} + \cdots + a_1$입니다. 두 식을 더하면:

$$2S_n = (a_1 + a_n) + (a_2 + a_{n-1}) + \cdots + (a_n + a_1)$$

등차수열의 성질에 의해 $a_i + a_{n+1-i} = a_1 + a_n$ (항상 같음)이므로, 우변은 $(a_1 + a_n)$이 $n$번 반복됩니다.

$$2S_n = n(a_1 + a_n)$$

따라서 $S_n = \frac{n(a_1 + a_n)}{2}$입니다.

### 의의 및 응용

이 공식은 첫째항과 마지막항의 평균에 항의 개수를 곱하는 형태로, 등차수열이 "규칙적으로 증가(또는 감소)하는 수"이기 때문에 성립합니다. 수능에서는 첫째항과 공차를 구하거나, 특정 조건 하에서 합의 최댓값·최솟값을 구하는 문제에 자주 출제됩니다.

**예**: 첫째항이 2, 공차가 3인 등차수열의 첫 10항의 합. 여기서 $a_{10} = 2 + 9 \times 3 = 29$이므로 $S_{10} = \frac{10(2+29)}{2} = 155$ (`sympy.solve`로: 합 공식 직접 계산 가능)
