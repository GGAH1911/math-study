# 함수의 곱의 연속성

## 요약
두 함수가 특정 지점에서 연속이면, 두 함수의 곱 또한 해당 지점에서 연속이다.

## 본문
두 함수 $f(x)$와 $g(x)$가 모두 $x = a$에서 연속이면, 두 함수의 곱인 $f(x)g(x)$도 $x = a$에서 연속이다. 함수가 $x = a$에서 연속이라는 것은 함숫값 $f(a)$가 정의되어 있고, 극한값 $\lim_{x \to a} f(x)$가 존재하며, 이 극한값과 함숫값이 서로 일치해야 한다는 세 가지 조건을 모두 만족함을 의미한다. 곱함수의 경우 극한의 성질에 의해 $\lim_{x \to a} f(x)g(x) = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x) = f(a) \cdot g(a)$가 성립하므로, 연속의 세 조건을 모두 충족하게 된다. 따라서 연속함수끼리의 곱은 언제나 연속성을 유지한다.

### 직관과 기하적 의미
그래프의 관점에서 볼 때, 두 함수가 $x = a$에서 끊김 없이 이어져 있다면, 두 그래프의 값을 곱하여 만든 새로운 함수 $h(x) = f(x)g(x)$ 역시 해당 지점에서 끊어지지 않고 매끄럽게 연결된 형태를 띠게 된다.

### 기본 성질
- $f(x)$와 $g(x)$가 모든 실수에서 연속이면, $h(x) = f(x)g(x)$도 모든 실수에서 연속이다.
- 다항함수와 삼각함수처럼 각각 연속인 함수들의 곱은 별도의 계산 없이도 연속임을 바로 알 수 있다.
- 예시로 $f(x) = x + 1$과 $g(x) = x^2 - 3$은 모든 실수에서 연속이므로, 그 곱인 $h(x) = x^3 + x^2 - 3x - 3$도 모든 실수에서 연속이다.

## 학습 체크
- 두 함수 중 하나라도 $x = a$에서 불연속일 때, 곱함수 $f(x)g(x)$의 연속성을 판단하려면 어떤 조건을 확인해야 하는가?
- $f(x)$가 $x = a$에서 연속이지만 $f(a) = 0$인 경우, $g(x)$가 $x = a$에서 불연속이어도 곱함수가 연속이 될 수 있는 사례가 있는가?

## 관련 개념

**함수의 극한과 연속**이 이 성질의 토대다. 곱의 연속성 증명은 결국 극한의 곱셈 법칙, 즉 $\lim_{x \to a} f(x)g(x) = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x)$에서 출발하므로, 극한의 기본 성질을 먼저 익혀 두어야 한다.

합·차의 연속성과 짝을 이루는 성질이다. 연속함수끼리 더하거나 빼도 연속이고, 곱해도 연속이다. 나눗셈의 경우에는 분모가 $0$이 되는 점을 제외하면 연속이 보장된다(몫의 연속성).

이 성질들을 합치면, 다항함수와 유리함수의 연속성을 체계적으로 설명할 수 있다. 다항함수는 상수함수와 $y = x$의 곱을 반복해 만들어지므로 모든 실수에서 연속이고, 유리함수는 분모가 $0$이 아닌 점에서 연속임을 곱·몫의 연속성으로 바로 이끌어 낼 수 있다.
