# 속력 계산

수직선 위를 움직이는 점 P의 시각 $t$에서의 위치를 $x(t)$라 하면, 점 P의 **속도**는

$$v(t) = x'(t)$$

이고, **속력**은 속도의 절댓값

$$|v(t)| = |x'(t)|$$

이다.

속도는 방향을 포함하므로 음수가 될 수 있다. 점이 수직선의 양의 방향으로 움직이면 $v(t)>0$, 음의 방향으로 움직이면 $v(t)<0$이다. 반면 속력은 빠르기만을 나타내는 양으로, 항상 $0$ 이상이다. 위치 함수가 삼각함수·지수함수·로그함수처럼 다양한 형태로 주어질 때, 각 함수에 맞는 미분법을 적용하여 속도와 속력을 구한다.

## 예시

**예시 1.** 점 P의 위치가 $x(t) = \sin 2t + \cos t$로 주어질 때, $t = \dfrac{\pi}{6}$에서의 속력을 구한다.

$$v(t) = x'(t) = 2\cos 2t - \sin t$$

$$v\!\left(\frac{\pi}{6}\right) = 2\cos\frac{\pi}{3} - \sin\frac{\pi}{6} = 2 \cdot \frac{1}{2} - \frac{1}{2} = \frac{1}{2}$$

속력은 $\left|v\!\left(\dfrac{\pi}{6}\right)\right| = \dfrac{1}{2}$이다.

**예시 2.** 점 P의 위치가 $x(t) = e^{2t} - 3t$로 주어질 때, $t = 0$에서의 속력을 구한다.

$$v(t) = x'(t) = 2e^{2t} - 3$$

$$v(0) = 2e^{0} - 3 = 2 - 3 = -1$$

$v(0) = -1 < 0$이므로 점은 음의 방향으로 움직이고 있으며, 속력은 $|v(0)| = 1$이다.

## 관련 개념

**여러 가지 함수의 미분**은 속력 계산의 핵심 도구다. 위치 함수가 삼각함수이면 $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$를, 지수함수이면 $(e^x)' = e^x$, 로그함수이면 $(\ln x)' = \dfrac{1}{x}$를 사용하여 속도 함수 $v(t)$를 구한다. 합성함수가 포함된 경우에는 연쇄법칙도 함께 적용한다.

**도함수의 활용 심화**에서는 속력을 한 번 더 미분하여 **가속도** $a(t) = v'(t) = x''(t)$를 구하거나, $v(t) = 0$이 되는 순간을 분석하여 점이 방향을 바꾸는 시각, 이동 거리의 최솟값·최댓값 등을 탐구한다. 속력 계산은 이 심화 활용으로 자연스럽게 연결된다.
