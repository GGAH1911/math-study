# 속력 계산

## 요약
속력은 위치 함수의 미분으로 구한 속도의 절댓값으로, 물체의 운동 방향과 관계없이 움직이는 빠르기만을 나타낸다.

## 본문
수직선 위를 움직이는 점 $P$의 시각 $t$에서의 위치를 $x(t)$라고 할 때, 점 $P$의 속도 $v(t)$는 위치 함수를 시간에 대해 미분한 $x'(t)$로 정의한다. 이때 속력은 속도의 크기만을 나타내는 양으로, 속도에 절댓값을 취한 $|v(t)| = |x'(t)|$로 정의한다.

### 직관과 기하적 의미
속도는 물체가 어느 방향으로 움직이는지를 포함하는 개념이다. 수직선 상에서 점이 양의 방향으로 이동하면 속도는 양수($v(t)>0$)를 나타내고, 음의 방향으로 이동하면 음수($v(t)<0$)를 나타낸다. 반면 속력은 방향에 상관없이 오직 물체가 얼마나 빠르게 움직이는가라는 '빠르기'만을 나타내므로 항상 $0$ 이상의 값을 가진다. 즉, 속도가 음수일 때도 속력은 그 절댓값만큼의 양수 값을 갖는다.

### 기본 성질
위치 함수 $x(t)$가 삼각함수, 지수함수, 로그함수 등 다양한 형태를 가질 때, 각 함수의 미분법을 적용하여 속도를 먼저 구한 뒤 절댓값을 씌워 속력을 계산한다. 속도가 $0$인 지점은 물체의 운동 방향이 바뀌거나 잠시 멈추는 순간을 의미하며, 이때 속력 또한 $0$이 된다.

## 예시

**예시 1.** 점 $P$의 위치가 $x(t) = \sin 2t + \cos t$일 때, $t = \tfrac{\pi}{6}$에서의 속력을 구하는 과정은 다음과 같다.
먼저 속도 $v(t)$를 구하면 $v(t) = x'(t) = 2\cos 2t - \sin t$이다.
$t = \tfrac{\pi}{6}$를 대입하면 $v\left(\tfrac{\pi}{6}\right) = 2\cos\tfrac{\pi}{3} - \sin\tfrac{\pi}{6} = 2 \cdot \tfrac{1}{2} - \tfrac{1}{2} = \tfrac{1}{2}$이다.
따라서 속력은 $\left|v\left(\tfrac{\pi}{6}\right)\right| = \tfrac{1}{2}$이다.

**예시 2.** 점 $P$의 위치가 $x(t) = e^{2t} - 3t$일 때, $t = 0$에서의 속력을 구하는 과정은 다음과 같다.
속도 $v(t)$는 $v(t) = x'(t) = 2e^{2t} - 3$이다.
$t = 0$을 대입하면 $v(0) = 2e^{0} - 3 = 2 - 3 = -1$이다.
이때 속도는 $-1$로 음의 방향으로 움직이고 있음을 나타내며, 속력은 $|v(0)| = 1$이다.

## 학습 체크
- 속도가 음수일 때 물체의 운동 방향과 속력의 값은 어떻게 나타나는가?
- 위치 함수가 복잡한 함수(삼각함수, 지수함수 등)로 주어졌을 때 속력을 구하는 단계는 무엇인가?

## 관련 개념

**여러 가지 함수의 미분**은 속력 계산의 핵심 도구다. 위치 함수가 삼각함수이면 $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$를, 지수함수이면 $(e^x)' = e^x$, 로그함수이면 $(\ln x)' = \tfrac{1}{x}$를 사용하여 속도 함수 $v(t)$를 구한다. 합성함수가 포함된 경우에는 연쇄법칙도 함께 적용한다.

**도함수의 활용 심화**에서는 속력을 한 번 더 미분하여 **가속도** $a(t) = v'(t) = x''(t)$를 구하거나, $v(t) = 0$이 되는 순간을 분석하여 점이 방향을 바꾸는 시각, 이동 거리의 최솟값·최댓값 등을 탐구한다. 속력 계산은 이 심화 활용으로 자연스럽게 연결된다.
