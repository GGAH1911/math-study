# 부채꼴 넓이 예제

> **예제** · 중1 · 단원: [평면도형](/concepts/평면도형)

## 요약
반지름·중심각 주어진 넓이

## 본문 (학습 시 채워짐)

### 문제

반지름이 6cm, 중심각이 60°인 부채꼴의 넓이를 구하시오.

### 단계별 풀이

**1단계: 부채꼴 넓이 공식을 어떤 기준으로 세울지 생각하기**
부채꼴은 원의 일부이므로, 원 전체의 넓이에서 중심각이 차지하는 비율을 곱하면 됩니다. 이것이 부채꼴 넓이의 핵심 원리입니다.

**2단계: 원 전체의 넓이 구하기**
반지름이 $r = 6$ cm이므로, 원 전체의 넓이는:
$$\text{원의 넓이} = \pi r^2 = \pi \times 6^2 = 36\pi \text{ cm}^2$$

**3단계: 중심각의 비율 구하기**
중심각이 60°이고 원 전체는 360°이므로, 부채꼴이 차지하는 비율은:
$$\frac{60°}{360°} = \frac{1}{6}$$

**4단계: 부채꼴의 넓이 계산하기**
부채꼴 넓이는 원의 넓이에 비율을 곱한 것입니다:
$$\text{부채꼴의 넓이} = \frac{60}{360} \times 36\pi = \frac{1}{6} \times 36\pi = 6\pi \text{ cm}^2$$

### 답

$$6\pi \text{ cm}^2$$ (약 18.85 cm²)

`sympy.pi * 6**2 * 60 / 360` → $6\pi$

### 변형/주의

- **중심각이 다른 경우**: 중심각이 90°면 $\frac{1}{4} \times 36\pi = 9\pi$ cm², 120°면 $\frac{1}{3} \times 36\pi = 12\pi$ cm²입니다.
- **호의 길이가 주어진 경우**: 호의 길이 $l$과 반지름 $r$이 주어지면 부채꼴 넓이 = $\frac{1}{2} \times l \times r$ 공식을 사용할 수도 있습니다.
- **단위 주의**: 넓이 공식에 들어가는 중심각은 반드시 도(°) 단위여야 합니다. 라디안으로 바뀌면 공식이 달라집니다.
