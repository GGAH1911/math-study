# 절댓값 함수의 미분가능 조건

## 요약
함수 $f(x)$가 $x=a$에서 미분가능하려면, $x=a$를 포함하는 구간에서 연속이어야 하며 좌미분계수와 우미분계수가 일치해야 한다.

## 본문
함수 $f(x)$가 $x=a$에서 미분가능하다는 것은 함수 $f(x)$의 도함수 $f'(a)$가 존재함을 의미한다. 이는 극한값 $\lim_{h \to 0} \tfrac{f(a+h)-f(a)}{h}$가 존재함을 뜻하며, 구체적으로는 $x=a$에서의 좌미분계수 $\lim_{h \to 0^-} \tfrac{f(a+h)-f(a)}{h}$와 우미분계수 $\lim_{h \to 0^+} \tfrac{f(a+h)-f(a)}{h}$가 서로 같아야 함을 의미한다. 절댓값 함수 $f(x) = |g(x)|$의 경우, $g(a)=0$인 지점에서 $g(x)$의 부호가 변하면 그래프가 꺾이게 되어 미분 불가능한 점이 발생할 수 있다. 따라서 $x=a$에서 $g(a)=0$일 때 $|g(x)|$가 미분가능하려면 $g'(a)=0$이어야 한다.

### 직관과 기하적 의미
함수의 그래프가 $x=a$에서 끊어지지 않고 이어져 있어야 하며(연속성), 해당 지점에서 그래프가 뾰족한 첨점(cusp)을 형성하지 않고 매끄러운 곡선 형태를 유지해야 함을 의미한다. 즉, 접선의 기울기가 좌우에서 일정하게 결정되어야 한다.

### 기본 성질
1. 함수가 $x=a$에서 미분가능하면, 함수는 $x=a$에서 반드시 연속이다.
2. 역은 성립하지 않는다. 즉, 연속이라고 해서 반드시 미분가능한 것은 아니다.
3. 절댓값 함수 $|g(x)|$는 $g(x)=0$인 지점에서 $g'(x) \neq 0$이면 미분 불가능하다.

## 학습 체크
- $f(x) = |x-a|$와 같은 형태의 함수가 $x=a$에서 왜 미분 불가능한지 좌우 미분계수를 이용하여 설명할 수 있는가?
- $f(x) = |g(x)|$에서 $g(a)=0$일 때, $g'(a)=0$이면 $f(x)$가 $x=a$에서 미분가능함을 증명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 미분가능성을 판별하는 것은 함수의 극대, 극소 및 그래프의 개형을 정확히 파악하여 함수의 증감을 분석하는 기초가 된다.
