# 일대일대응과 순열

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
일대일대응은 두 집합의 원소가 빠짐없이 하나씩 짝을 이루는 상태를 의미하며, $n$개의 원소를 일렬로 배열하는 순열의 개수는 $n$개의 원소 사이의 일대일대응의 개수와 같다.

## 본문
두 집합 $A, B$에 대하여 함수 $f: A \to B$가 일대일대응이 되기 위해서는 두 가지 조건을 동시에 만족해야 한다. 첫째는 서로 다른 원소가 서로 다른 값으로 대응되어야 한다는 단사 성질이며, 둘째는 공역의 모든 원소가 화살표를 받아야 한다는 전사 성질이다. 즉, 집합 $A$의 각 원소가 집합 $B$의 원소와 정확히 하나씩 짝을 이루어 빈틈없이 연결된 상태를 말하며, 이 경우 두 집합의 원소 개수는 $|A| = |B|$로 항상 같다.

서로 다른 $n$개의 원소 중에서 순서를 고려하여 $r$개를 선택해 배열하는 것을 순열이라 하며, 그 개수는 $\mathrm{P}(n, r)$ 또는 $_n\mathrm{P}_r$로 나타낸다. 이는 $n$부터 시작하여 하나씩 줄여가며 $r$개의 인수를 곱한 값과 같으며, 공식으로는 $\tfrac{n!}{(n-r)!}$로 계산한다. 특히 $r=n$인 경우인 $\mathrm{P}(n, n) = n!$은 $n$개의 원소를 일렬로 나열하는 모든 경우의 수이자, 집합 $A$에서 $B$로 가는 모든 일대일대응의 개수를 의미한다.

### 직관과 기하적 의미
일대일대응은 모든 학생이 빈 좌석 없이 정확히 하나의 좌석에 앉는 "완벽한 짝짓기" 상황과 같다. $n$명의 학생을 $n$개의 좌석에 배치하는 방식의 가짓수를 구하는 것이 곧 순열의 계산이다.

### 기본 성질
- 일대일대응이 존재하려면 반드시 두 집합의 원소 개수가 같아야 한다.
- $n$개의 서로 다른 원소를 일렬로 배열하는 경우의 수는 $n!$이다.

## 학습 체크
- 함수가 단사 함수이면서 동시에 전사 함수인지 확인하였는가?
- 순열에서 원소의 개수 $n$과 선택하는 개수 $r$의 관계를 이해하였는가?
- 일대일대응의 개수가 왜 $n!$으로 계산되는지 순열의 정의와 연결할 수 있는가?

## 관련 개념
- **확률**: 일대일대응의 개수를 전체 경우의 수의 분자로 사용하여 특정 배열이 나타날 확률을 구할 수 있다.
- **함수**: 일대일대응은 함수의 특수한 형태로서, 함수의 정의와 공역, 치역의 개념을 포함한다.
