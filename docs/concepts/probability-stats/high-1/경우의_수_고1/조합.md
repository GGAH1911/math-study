# 조합

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$n$개의 서로 다른 것 중에서 순서를 고려하지 않고 $r$개를 선택하는 경우의 수를 의미하며, $_nC_r = \frac{n!}{r!(n-r)!}$로 계산합니다.

## 본문
$n$개의 서로 다른 것 중에서 순서를 생각하지 않고 $r$개($0 \le r \le n$)를 선택하는 경우의 수를 조합(combination)이라 하고, $_nC_r$ 또는 $\binom{n}{r}$으로 나타냅니다.

### 직관과 기하적 의미
순열 $_nP_r$은 선택된 원소들의 배열 순서까지 구분하지만, 조합은 순서를 무시하고 선택된 구성원만을 따집니다. 예를 들어 {A, B}와 {B, A}는 순열에서는 서로 다른 경우이지만, 조합에서는 같은 경우로 간주합니다. 따라서 순열 $_nP_r$에서 중복되는 배열의 수인 $r!$만큼 나누어 주면 조합의 값이 나옵니다. 즉, $_nC_r = \frac{_nP_r}{r!}$의 관계가 성립합니다. 기하학적 관점에서 조합은 $n$개의 원소를 가진 집합에서 크기가 $r$인 부분집합을 뽑는 것과 같습니다.

### 기본 성질
조합의 계산식은 다음과 같습니다.
$$_nC_r = \binom{n}{r} = \frac{n!}{r!(n-r)!}$$
예를 들어 6명의 학생 중 위원 3명을 뽑는 경우의 수는 $_6C_3 = \frac{6!}{3! \cdot 3!} = 20$가지입니다.

## 학습 체크
- 순서가 중요한 상황(순열)과 중요하지 않은 상황(조합)을 구분할 수 있는가?
- 조합의 공식이 순열의 공식을 $r!$로 나눈 형태임을 이해하고 있는가?
- 주어진 조건에서 부분집합의 개수를 구하는 문제를 해결할 수 있는가?

## 관련 개념
- **경우의 수 (고1)**: 조합은 전체 경우의 수를 구하는 여러 방법 중 하나로, 선택의 순서가 상관없는 상황을 처리할 때 사용됩니다.
