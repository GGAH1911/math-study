# 팩토리얼

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
자연수 $n$부터 $1$까지의 모든 자연수를 곱한 값으로, 서로 다른 $n$개를 일렬로 나열하는 경우의 수를 의미합니다.

## 본문
자연수 $n$에 대하여 $n$의 팩토리얼 $n!$은 $1$부터 $n$까지의 모든 자연수를 차례대로 곱한 값을 말합니다. 이를 수식으로 나타내면 $n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1$입니다. 이때 $0!$은 $1$로 정의합니다.

### 직관과 기하적 의미
팩토리얼은 서로 다른 $n$개의 객체를 일렬로 나열하는 방법의 수를 나타냅니다. 예를 들어 $3$개의 공을 나열할 때, 첫 번째 자리에 올 수 있는 공은 $3$가지, 두 번째 자리는 남은 $2$가지, 마지막 자리는 남은 $1$가지이므로 총 $3 \times 2 \times 1 = 6$가지의 경우가 발생합니다. 이는 순열 $P(n, n)$의 값과 동일합니다. $0! = 1$인 이유는 아무것도 배열하지 않는 상태 자체가 하나의 경우의 수로 간주되기 때문이며, 이는 수학적 공식의 일관성을 유지하기 위해 약속된 정의입니다.

### 기본 성질
- $n!$은 $n$이 커질수록 매우 빠르게 증가합니다.
- $n! = n \times (n-1)!$의 관계가 성립하여 재귀적인 구조를 가집니다.
- $0! = 1$로 정의함으로써 조합이나 순열 공식에서 오류 없이 계산이 가능합니다.

## 학습 체크
- $5!$의 값을 직접 계산할 수 있는가?
- 왜 $0!$을 $1$로 정의해야 하는지 그 이유를 설명할 수 있는가?
- $n$개의 서로 다른 물건을 일렬로 세우는 방법의 수와 $n!$의 관계를 이해하고 있는가?

## 관련 개념
- **경우의 수**: 서로 다른 $n$개의 대상을 일렬로 나열하는 모든 가능한 방법을 구할 때 팩토리얼을 핵심 도구로 사용합니다.
- **순열**: $n$개 중 $r$개를 선택하여 순서를 고려해 나열하는 $P(n, r)$의 특수한 경우로, $r=n$일 때 $n!$이 됩니다.
- **조합**: $n$개 중 순서에 상관없이 $r$개를 선택하는 $C(n, r)$의 분모 부분에서 팩토리얼 개념이 사용됩니다.
