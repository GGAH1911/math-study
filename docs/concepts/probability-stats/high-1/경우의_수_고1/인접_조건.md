# 인접 조건

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
특정한 원소들이 반드시 서로 이웃하여 배열되어야 한다는 제약 조건으로, 해당 원소들을 하나의 묶음(블록)으로 간주하여 문제를 단순화하여 해결합니다.

## 본문
인접 조건은 순열이나 조합 문제에서 특정한 원소들이 반드시 이웃하여 배열되어야 한다는 제약 조건입니다. 예를 들어 "A와 B는 항상 옆자리에 앉아야 한다" 또는 "같은 색깔의 공들은 연달아 놓여야 한다"와 같은 상황이 이에 해당합니다.

### 직관과 기하적 의미
인접 조건 문제의 핵심 전략은 인접해야 하는 대상들을 하나의 단위(블록)로 묶는 것입니다. "인접해야 한다"는 복잡한 제약을 하나의 객체로 단순화하면, 전체 문제가 기본 순열 계산으로 변환됩니다. 예를 들어 5명이 일렬로 앉는데 A와 B가 반드시 옆에 앉아야 한다면, A와 B를 하나의 블록 $[AB]$로 생각합니다. 그러면 이 블록과 나머지 3명을 합쳐 총 4개의 단위를 배열하는 $4!$ 가지의 경우와, 블록 내부에서 A와 B의 순서를 정하는 $2!$ 가지를 곱하여 총 $4! \times 2! = 48$ 가지의 경우를 구할 수 있습니다.

### 기본 성질
인접 조건을 적용할 때는 두 단계의 계산 과정이 필요합니다. 첫째, 이웃해야 하는 대상들을 하나의 덩어리로 묶어 전체 개수를 줄인 뒤 배열하는 단계입니다. 둘째, 묶인 덩어리 내부에서 구성원들이 서로 자리를 바꾸는 경우의 수를 계산하여 곱하는 단계입니다. 8개의 서로 다른 책 중 수학책 3권이 반드시 나란히 있어야 한다면, 수학책 3권을 하나의 블록으로 보아 $(8 - 3 + 1)! \times 3! = 6! \times 3! = 4320$ 가지로 계산합니다.

## 학습 체크
- 이웃해야 하는 대상들을 하나의 묶음으로 처리했을 때, 전체 개수가 어떻게 변하는지 정확히 파악했는가?
- 묶음 내부의 원소들이 서로 자리를 바꿀 수 있는 경우의 수를 빠뜨리지 않고 곱해주었는가?

## 관련 개념
- **경우의 수**: 인접 조건을 만족하는 전체 사건의 개수를 구하는 과정에서 순열과 조합의 원리가 핵심적으로 사용됩니다.
