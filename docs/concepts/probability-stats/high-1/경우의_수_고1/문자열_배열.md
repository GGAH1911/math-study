# 문자열 배열

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
주어진 문자 집합에서 일부 또는 전체 문자를 순서를 고려하여 선택하고 배치하여 만드는 문자열입니다.

## 본문
문자열 배열은 주어진 문자 집합에서 일부 또는 전체 문자를 순서를 고려하여 선택하고 배치하여 만드는 문자열을 의미합니다. $n$개의 서로 다른 문자에서 $r$개를 순서대로 배열하는 경우의 수는 순열 공식 $P(n, r) = \frac{n!}{(n-r)!}$을 사용하여 계산할 수 있습니다.

### 직관과 기하적 의미
'배열'이라는 용어는 선택된 요소들의 **순서가 결과에 영향을 미친다**는 것을 의미합니다. 예를 들어 {수, 학}이라는 두 글자를 사용할 때, 순서를 고려하지 않는다면 구성 요소는 하나뿐이지만, 배열을 하면 "수학"과 "학수"라는 서로 다른 두 개의 결과가 만들어집니다. 이는 첫 번째 자리에 어떤 문자가 오느냐에 따라 전체 문자열의 정체성이 완전히 달라지는 현상을 반영합니다.

### 기본 성질
문자열을 만드는 과정은 각 자리에 올 수 있는 문자의 선택지를 단계적으로 곱하는 방식으로 이해할 수 있습니다. 예를 들어 문자 {가, 나, 다, 라}에서 2개를 배열하는 경우, 첫 번째 자리에는 4가지 중 하나를 선택할 수 있고, 두 번째 자리에는 남은 3가지 중 하나를 선택할 수 있습니다. 따라서 총 경우의 수는 $4 \times 3 = 12$가지가 됩니다.

## 학습 체크
- 배열할 대상의 개수와 선택할 개수가 다를 때, 순열 공식을 어떻게 적용하는가?
- 순서가 중요한 '배열'과 순서가 중요하지 않은 '조합'의 차이점을 명확히 구분할 수 있는가?

## 관련 개념
- **경우의 수**: 문자열 배열은 전체 경우의 수를 구하는 방법 중 하나로, 순서가 있는 선택 상황을 다룹니다.
