# 주사위 확률

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
주사위의 각 면이 나올 가능성이 모두 같을 때, 특정 사건이 일어날 확률은 전체 경우의 수에 대한 해당 사건의 경우의 수의 비율로 계산합니다.

## 본문
정상적인 주사위를 던질 때, 임의의 사건 $A$가 일어날 확률 $P(A)$는 다음과 같이 정의됩니다.
$$P(A) = \frac{\text{사건 } A \text{가 일어나는 경우의 수}}{\text{일어날 수 있는 모든 경우의 수}}$$
주사위는 6개의 면을 가지므로 전체 경우의 수는 6입니다. 예를 들어 특정 숫자 3이 나올 확률은 $P(3) = \tfrac{1}{6}$이며, 짝수가 나올 확률은 2, 4, 6 세 가지 경우를 포함하므로 $P(\text{짝수}) = \tfrac{3}{6} = \tfrac{1}{2}$이 됩니다.

### 직관과 기하적 의미
주사위는 균형 잡힌 정육면체로 만들어져 모든 면이 나올 가능성이 완전히 같습니다. 이를 **동등 가능성(equally likely)**의 가정이라 하며, 이 가정에 따라 각 면은 독립적으로 $\tfrac{1}{6}$이라는 동일한 확률을 가집니다. 따라서 특정 범위의 숫자가 나올 확률을 구할 때는 해당 조건을 만족하는 경우의 수를 모두 세어 전체 경우의 수인 6으로 나누면 됩니다. 예를 들어 "4 이상"이 나올 확률은 4, 5, 6 세 가지 경우를 포함하므로 $P(4 \text{ 이상}) = \tfrac{3}{6} = \tfrac{1}{2}$입니다.

### 기본 성질
주사위 확률 계산의 핵심은 '전체 경우의 수'와 '사건의 경우의 수'를 정확히 파악하는 것입니다. "5 이상"이 나올 확률을 구한다면, 경우의 수는 5와 6으로 2가지이며 전체는 6이므로 $P = \tfrac{2}{6} = \tfrac{1}{3}$이 됩니다.

## 학습 체크
- 주사위를 던질 때 특정 숫자가 나올 확률과 짝수가 나올 확률 중 어느 것이 더 큰가요?
- "3 미만"의 숫자가 나올 확률을 구할 때 포함되는 경우의 수는 무엇인가요?

## 관련 개념
- **확률**: 사건이 일어날 가능성을 수치로 나타낸 것으로, 주사위의 경우처럼 모든 결과의 가능성이 같을 때 경우의 수의 비율로 정의됩니다.
