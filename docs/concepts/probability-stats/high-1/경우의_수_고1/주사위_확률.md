# 주사위 확률

## 정확한 진술

정상적인 주사위를 던질 때, 임의의 사건 $A$가 일어날 확률은 다음과 같이 정의됩니다.

$$P(A) = \frac{\text{사건 } A \text{가 일어나는 경우의 수}}{\text{일어날 수 있는 모든 경우의 수}}$$

주사위는 6개의 면을 가지므로 전체 경우의 수는 6입니다. 예를 들어:
- 특정 숫자(예: 3)가 나올 확률: $P(3) = \frac{1}{6}$
- 짝수가 나올 확률: $P(\text{짝수}) = \frac{3}{6} = \frac{1}{2}$ (경우: 2, 4, 6)

## 직관과 의미

주사위는 균형 잡힌 정육면체로 만들어져, 모든 면이 나올 가능성이 완전히 같습니다. 이를 **동등 가능성(equally likely)**의 가정이라 부릅니다. 따라서 각 면은 독립적으로 같은 확률 $\frac{1}{6}$을 가집니다.

여러 면을 포함하는 사건의 확률은 조건을 만족하는 경우들을 모두 세어 전체 6으로 나누면 됩니다. 예를 들어 "4 이상"의 사건은 4, 5, 6을 포함하므로:

$$P(4 \text{ 이상}) = \frac{3}{6} = \frac{1}{2}$$

## 한 줄 예

"주사위에서 5 이상이 나올 확률은?" → $P = \frac{2}{6} = \frac{1}{3}$ (경우: 5, 6)

검증: `favorable = 2; total = 6; probability = favorable / total  # 0.333...`
