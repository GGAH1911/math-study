# 최단거리 조건

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
격자점 이동 문제에서 정해진 방향으로만 이동하여 목적지에 도달하는 최소 이동 횟수를 의미하며, 경로의 개수를 유한하게 계산할 수 있게 하는 핵심 조건입니다.

## 본문
$(0, 0)$에서 $(m, n)$으로 가는 경로를 생각할 때, 각 이동이 오른쪽(R) 또는 위쪽(U) 중 하나로 제한된다면 최단거리로 이동하기 위해서는 반드시 오른쪽으로 $m$번, 위쪽으로 $n$번 이동해야 합니다. 이때 총 이동 횟수는 $m+n$번이 되며, 이를 최단거리 조건이라고 합니다.

### 직관과 기하적 의미
격자점 이동 문제에서 최단거리 조건이 성립한다는 것은 모든 가능한 경로가 동일한 길이($m+n$)를 가진다는 것을 의미합니다. 만약 왼쪽이나 아래쪽으로 이동하는 것이 허용된다면 경로의 길이가 무한히 길어질 수 있어 경우의 수를 셀 수 없게 되지만, 최단거리 조건은 경로의 수를 유한하고 계산 가능한 상태로 만들어주는 핵심적인 가정 역할을 합니다.

### 기본 성질
최단거리 조건 하에서 경로의 개수는 전체 이동 횟수 $m+n$번 중 오른쪽으로 이동할 위치 $m$개를 선택하는 조합의 수와 같습니다. 따라서 경로의 개수는 다음과 같이 계산됩니다.
$$\binom{m+n}{m} = \binom{m+n}{n}$$
예를 들어, $(0, 0)$에서 $(2, 3)$으로 최단거리로 가는 경로의 개수는 $\binom{2+3}{2} = \binom{5}{2} = 10$입니다.

## 학습 체크
- 최단거리 조건이 성립하기 위해 이동 방향이 어떻게 제한되어야 하는가?
- 최단거리 조건이 없을 때 경로의 개수를 구할 수 없는 이유는 무엇인가?
- $(m, n)$까지 가는 최단거리 경로의 개수를 조합 기호를 사용하여 나타내면 무엇인가?

## 관련 개념
- **경우의 수**: 최단거리 조건은 전체 이동 횟수 중 특정 방향의 이동 횟수를 결정함으로써, 조합을 이용하여 경로의 개수를 유한하게 계산할 수 있게 합니다.
