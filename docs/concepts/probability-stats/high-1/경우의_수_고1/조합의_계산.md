# 조합의 계산

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
$n$개의 서로 다른 원소 중 순서를 고려하지 않고 $r$개를 선택하는 경우의 수입니다.

## 본문
$n$개의 서로 다른 원소 중에서 순서를 구별하지 않고 $r$개를 선택하는 경우의 수를 조합(combination)이라 하며, 다음과 같이 계산합니다.
$$\binom{n}{r} = \text{C}(n,r) = \frac{n!}{r!(n-r)!} \quad (0 \le r \le n)$$
여기서 $n! = n \times (n-1) \times \cdots \times 2 \times 1$이고, $0! = 1$입니다.

### 직관과 기하적 의미
조합과 순열의 핵심 차이는 순서의 중요성입니다. 순열은 (A, B)와 (B, A)를 다르게 세지만, 조합은 이 둘을 같은 것으로 봅니다. 직관적으로, $n$개 중 $r$개를 고르는 모든 순열의 개수는 $\tfrac{n!}{(n-r)!}$인데, 이들 중 같은 $r$개 원소로 이루어진 그룹은 $r!$번 반복됩니다. 따라서 서로 다른 조합의 개수는 이를 $r!$로 나누어 구합니다. 다르게 말하면, 조합 $\binom{n}{r}$은 크기가 $r$인 부분집합의 개수를 나타냅니다.

### 기본 성질
큰 수를 다룰 때는 다음 성질을 활용하면 계산이 간단해집니다.
- **대칭성**: $\binom{n}{r} = \binom{n}{n-r}$ (예: $\binom{10}{7} = \binom{10}{3}$)
- **파스칼 항등식**: $\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$

## 학습 체크
- $n$개 중 $r$개를 선택할 때, 선택된 원소들의 순서가 결과에 영향을 주는지 확인했는가?
- $\binom{n}{r}$을 계산할 때 $r$이 $n$보다 큰 경우나 $r=0$인 경우의 결과값을 알고 있는가?
- 대칭성을 이용하여 계산 과정을 단축할 수 있는 상황인지 파악했는가?

## 관련 개념
- **경우의 수**: 조합은 전체 경우의 수 중 특정 조건을 만족하는 부분집합의 개수를 구하는 핵심적인 방법입니다.
- **순열**: 순열은 순서를 고려하여 나열하는 것이고, 조합은 순열에서 중복되는 순서만큼 나누어준 개념입니다.
