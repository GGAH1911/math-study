# 원순열

> **예제** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$n$개를 원형으로 배열할 때 회전하여 같은 것을 하나로 간주하는 경우의 수는 $(n-1)!$입니다.

## 본문
A, B, C, D 4명이 둥근 테이블에 앉을 때, 시계방향으로 같은 배열은 같은 것으로 간주합니다. 이 경우의 수를 구하세요.

### 단계별 풀이
**1단계: 일렬 배열의 경우의 수 구하기**
4명을 일렬로 배열하면 순열 공식 $4! = 24$가지입니다. 이는 아직 원형의 회전 특성을 고려하지 않은 상태입니다.

**2단계: 원형 배열에서 회전의 중복 인식하기**
둥근 테이블에서는 회전으로 인해 발생하는 중복을 제거해야 합니다. 예를 들어 시계방향으로 A-B-C-D, B-C-D-A, C-D-A-B, D-A-B-C는 모두 같은 배열로 취급됩니다. 이처럼 $n$개의 배열이 회전했을 때 모두 같으므로, 일렬 배열의 수 $n!$을 $n$으로 나누어야 합니다.

**3단계: 원순열 공식 적용하기**
$n$명이 원탁에 앉는 경우의 수는 $\frac{n!}{n} = (n-1)!$입니다. 특정 한 명의 자리를 고정시키고 나머지 $(n-1)$명을 배열하는 것과 논리적으로 동일합니다. 따라서 $(4-1)! = 3! = 6$입니다.

### 답과 변형
**6가지** (또는 $(4-1)! = 3! = 6$)

- **뒤집기 포함 시**: 목걸이처럼 뒤집었을 때 모양이 같다면 $\frac{(n-1)!}{2}$를 적용합니다.
- **한 자리 고정**: 특정 인물의 위치를 고정하면 나머지 인원을 일렬로 배열하는 것과 같습니다.
- **같은 것이 있는 경우**: 같은 종류의 물체가 포함된 원형 배열은 $\frac{(n-1)!}{\text{같은 것의 개수}!}$를 적용하여 계산합니다.

## 학습 체크
- 회전하여 같은 것을 하나로 보는 원순열의 원리를 이해하고 있는가?
- 일렬 배열의 수를 회전하는 개수로 나누는 이유를 설명할 수 있는가?
- 목걸이 문제와 같이 뒤집었을 때 같은 경우를 구분할 수 있는가?

## 관련 개념
- **경우의 수 고1**: 원순열은 전체 경우의 수를 구하는 여러 방법 중 하나로, 중복되는 경우를 나누어 처리하는 원리를 배웁니다.
