# 약수의 개수

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
양의 정수 $n$의 약수의 개수는 $n$을 소인수분해했을 때 각 소인수의 지수에 1을 더한 값들을 모두 곱하여 구할 수 있습니다.

## 본문
양의 정수 $n$의 약수의 개수는 $n$을 나누는 양의 정수가 모두 몇 개인지를 나타내는 값이며, 기호로는 $\tau(n)$ 또는 $d(n)$이라 표기합니다. 예를 들어 $n = 12$일 때, $12$의 약수는 $1, 2, 3, 4, 6, 12$이므로 약수의 개수는 6입니다. 일반적으로 $n$의 소인수분해가 $n = p_1^{a_1} \times p_2^{a_2} \times \cdots \times p_k^{a_k}$와 같을 때, 약수의 개수는 각 지수에 1을 더하여 모두 곱한 $(a_1 + 1)(a_2 + 1) \cdots (a_k + 1)$로 계산합니다.

### 직관과 기하적 의미
이 공식은 경우의 수의 곱의 법칙을 통해 이해할 수 있습니다. $n$의 모든 약수는 각 소인수를 어떤 지수로 몇 번 사용할지를 결정함으로써 만들어집니다. 소인수 $p_1$의 경우 지수를 $0$부터 $a_1$까지 총 $(a_1 + 1)$가지 중에서 선택할 수 있고, 소인수 $p_2$ 역시 $0$부터 $a_2$까지 $(a_2 + 1)$가지 중에서 선택할 수 있습니다. 따라서 모든 소인수에 대해 가능한 지수의 선택지를 곱하면 전체 약수의 개수가 됩니다.

### 기본 성질
$60 = 2^2 \times 3^1 \times 5^1$을 예로 들면, 약수의 개수는 $(2+1)(1+1)(1+1) = 12$입니다. 실제 약수인 $1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60$을 나열했을 때 총 12개가 나옴을 확인할 수 있습니다.

- 약수의 개수를 구할 때 소인수가 아닌 밑(base)의 숫자를 계산에 포함시키지는 않았는가?

## 관련 개념
- **집합과 명제**: 약수의 집합을 정의할 때 원소의 개수를 구하는 과정으로 연결됩니다.
- **소인수분해**: 약수의 개수를 구하기 위한 가장 기초적이고 필수적인 전제 단계입니다.
