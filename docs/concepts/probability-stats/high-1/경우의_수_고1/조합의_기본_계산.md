# 조합의 기본 계산

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
서로 다른 $n$개에서 순서를 고려하지 않고 $r$개를 선택하는 방법의 수를 구하는 계산법입니다.

## 본문
서로 다른 $n$개에서 순서를 고려하지 않고 $r$개를 뽑는 방법의 수를 **조합**이라 하며, $_n\mathrm{C}_r$ 또는 $\binom{n}{r}$로 표기합니다. 이는 확률과 통계의 경우의 수 단원에서 매우 중요한 핵심 기법입니다. 조합의 값은 다음과 같은 공식으로 계산합니다.
$$\binom{n}{r} = \frac{n!}{r!(n-r)!} \quad (0 \le r \le n)$$
이 식은 $n$개 중 $r$개를 뽑아 일렬로 나열하는 순열의 수 $_nP_r$을, 뽑힌 $r$개가 나열되는 순서의 수인 $r!$로 나누어 준 것과 같습니다.

### 직관과 기하적 의미
조합은 '순서'가 결과에 영향을 주지 않는 상황을 다룹니다. 예를 들어, $A, B$ 두 명을 뽑는 경우와 $B, A$ 두 명을 뽑는 경우가 동일한 하나의 경우로 취급됩니다. 따라서 순열과 달리 중복되는 순서의 개수만큼 나누어 주는 과정이 포함됩니다.

### 기본 성질
조합은 다음과 같은 유용한 성질을 가집니다.
- $\binom{n}{0} = \binom{n}{n} = 1$
- 대칭성: $\binom{n}{r} = \binom{n}{n-r}$ (전체에서 $r$개를 뽑는 것은 뽑지 않을 $n-r$개를 선택하는 것과 같습니다.)
- 파스칼의 항등식: $\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$

예를 들어, 서로 다른 $5$명에서 $2$명을 뽑는 방법의 수는 $\binom{5}{2} = \frac{5 \times 4}{2 \times 1} = 10$입니다. 또한 $\binom{7}{3} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35$이며, 대칭성에 의해 $\binom{7}{4} = 35$임을 알 수 있습니다.

## 학습 체크
- $n$개 중 $r$개를 뽑을 때, $r$이 $n$의 절반보다 클 경우 대칭성을 이용하여 계산을 단순화할 수 있는가?
- 순열($_nP_r$)과 조합($\binom{n}{r}$)의 결정적인 차이점인 '순서의 고려 여부'를 문제 상황에서 구분할 수 있는가?
- 파스칼의 항등식을 이용하여 복잡한 조합의 합을 계산할 수 있는가?
