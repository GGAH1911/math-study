# 합의의 원리

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 정확한 진술

두 사건 또는 집합 $A$와 $B$가 서로소(disjoint)일 때, 즉 $A \cap B = \emptyset$일 때, $A$ 또는 $B$에 속하는 경우의 수는 다음과 같이 구한다:

$$|A \cup B| = |A| + |B|$$

일반적으로 서로 겹치지 않는 $n$개의 집합 $A_1, A_2, \ldots, A_n$에 대해:

$$\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{i=1}^{n} |A_i|$$

## 직관 및 의미

합의의 원리는 "서로 다른 경우들을 나누어서 각각 센 후, 그것들을 모두 더하면 전체 경우의 수가 된다"는 아이디어입니다. 

예를 들어, 한 상자에 빨간 공 5개와 파란 공 3개가 있다면, "빨간 공을 고르거나 파란 공을 고르는 경우"는 당연히 $5 + 3 = 8$입니다. 왜냐하면 빨간 공을 고르는 행동과 파란 공을 고르는 행동은 동시에 일어날 수 없기 때문입니다(서로소).

반대로 조건이 겹칠 수 있다면(예: "여학생이거나 3학년")—즉 $A \cap B \neq \emptyset$이면—단순히 $|A| + |B|$를 하면 겹치는 부분을 두 번 센 오류가 생깁니다. 이 경우 **포함-배제 원리**를 사용해야 합니다.

## 간단한 예

주사위를 한 번 던져서 "홀수 또는 2의 배수"가 나올 경우의 수는?
- 홀수: $\{1, 3, 5\}$ (3가지)
- 2의 배수: $\{2, 4, 6\}$ (3가지)
- 둘이 겹치지 않으므로: $3 + 3 = 6$가지

이 원리는 경우의 수 문제에서 가장 기초적인 도구이며, 복잡한 상황에서도 먼저 "겹치지 않게 나눌 수 있을까?"라고 묻는 것이 문제 해결의 첫 단계입니다.
