# 합의의 원리

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
두 사건이 서로 겹치지 않을 때, 각 사건이 일어나는 경우의 수를 더하면 전체 경우의 수가 된다는 원리입니다.

## 본문
두 사건 또는 집합 $A$와 $B$가 서로소(disjoint)일 때, 즉 $A \cap B = \emptyset$일 때, $A$ 또는 $B$에 속하는 경우의 수는 다음과 같이 구합니다:
$$|A \cup B| = |A| + |B|$$
일반적으로 서로 겹치지 않는 $n$개의 집합 $A_1, A_2, \ldots, A_n$에 대해 전체 경우의 수는 각 집합의 원소 개수의 합과 같습니다:
$$\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{i=1}^{n} |A_i|$$

### 직관과 기하적 의미
합의의 원리는 "서로 다른 경우들을 나누어서 각각 센 후, 그것들을 모두 더하면 전체 경우의 수가 된다"는 아이디어입니다. 예를 들어, 한 상자에 빨간 공 5개와 파란 공 3개가 있다면, "빨간 공을 고르거나 파란 공을 고르는 경우"는 $5 + 3 = 8$입니다. 빨간 공을 고르는 행동과 파란 공을 고르는 행동은 동시에 일어날 수 없기 때문입니다. 만약 조건이 겹친다면(예: "여학생이거나 3학년") 단순히 더할 경우 겹치는 부분을 두 번 세게 되므로 주의해야 합니다.

### 기본 성질
주사위를 한 번 던져서 "홀수 또는 2의 배수"가 나올 경우의 수를 구하는 것이 대표적인 예입니다. 홀수는 $\{1, 3, 5\}$로 3가지이고, 2의 배수는 $\{2, 4, 6\}$으로 3가지입니다. 두 집합이 서로소이므로 합의 원리에 따라 $3 + 3 = 6$가지가 됩니다. 이 원리는 복잡한 상황을 단순한 상황으로 분할하여 해결하는 문제 해결의 첫 단계가 됩니다.

## 학습 체크
- 두 사건이 서로소(겹치지 않음)인지 확인했는가?
- 사건이 겹칠 경우, 단순히 더하는 대신 포함-배제 원리를 적용해야 하는 것은 아닌가?

## 관련 개념
- **경우의 수**: 합의의 원리는 경우의 수를 구하는 가장 기초적인 도구이며, 전체 상황을 겹치지 않는 부분으로 나누어 계산하는 핵심 방법입니다.
