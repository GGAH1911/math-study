# 포함-배제 원리

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_(고1))

## 요약
여러 집합의 합집합의 크기를 구할 때, 각 집합의 크기를 더하고 교집합들을 번갈아 가며 더하거나 빼서 중복을 조정하는 원리입니다.

## 본문
두 개 이상의 집합의 합집합의 크기를 구할 때, 각 집합의 크기를 모두 더한 후 중복되는 부분을 적절히 제거하여 계산하는 원리입니다. 두 집합 $A$, $B$에 대하여 $|A \cup B| = |A| + |B| - |A \cap B|$로 나타내며, 세 집합 $A$, $B$, $C$에 대해서는 $|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$로 계산합니다. 일반적으로 $n$개의 집합에 대하여 각 집합의 크기를 모두 더한 뒤, 두 개씩 교집합을 빼고, 세 개씩 교집합을 더하는 과정을 반복하며 부호를 번갈아 적용하여 합집합의 크기를 구합니다.

### 직관과 기하적 의미
이 원리는 "포함했다가 빼기"를 반복하여 중복을 조정하는 과정입니다. 예를 들어 수학을 좋아하는 학생과 과학을 좋아하는 학생의 수를 구할 때, 두 집합을 단순히 더하면 두 과목을 모두 좋아하는 학생이 두 번 계산됩니다. 따라서 이 중복된 부분을 한 번 빼주어야 합니다. 벤 다이어그램을 통해 보면, 합집합 영역의 모든 부분을 정확히 한 번씩만 세기 위해 여러 교집합 항을 번갈아 더하고 빼며 중복을 조정하는 것과 같습니다.

### 기본 성질
- 두 집합의 경우, 합집합의 크기는 각 집합의 크기의 합에서 교집합의 크기를 뺀 것과 같습니다.
- 집합의 개수가 늘어날수록 홀수 개의 교집합은 더하고, 짝수 개의 교집합은 빼는 규칙을 따릅니다.

## 학습 체크
- 두 집합의 합집합을 구할 때 왜 교집합의 크기를 한 번 빼주어야 하는가?
- 세 집합의 경우에서 마지막에 세 집합의 교집합을 다시 더해주는 이유는 무엇인가?

## 관련 개념
- **경우의 수**: 특정 조건을 만족하는 원소의 개수를 구할 때, 중복 계산을 방지하기 위해 이 원리를 핵심적으로 사용합니다.
