# 순열 조합 관계

> **정리** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$n$개의 서로 다른 원소에서 $r$개를 선택하는 조합의 수는 $(n-r)$개를 선택하는 조합의 수와 같습니다.

## 본문
$n$개의 서로 다른 원소에서 $r$개를 선택하는 조합의 수는 $(n-r)$개를 선택하는 조합의 수와 같습니다. 즉, $_nC_r = {}_nC_{n-r}$이 성립합니다.

### 증명 스케치
조합의 정의에 따라 $_nC_r = \frac{n!}{r!(n-r)!}$입니다. 한편, $(n-r)$개를 선택하는 경우의 수는 $_nC_{n-r} = \frac{n!}{(n-r)!(n-(n-r))!} = \frac{n!}{(n-r)!r!}$로 나타낼 수 있습니다. 두 식은 분자와 분모의 구성 요소가 동일하므로 서로 같습니다.

### 의의와 응용
이 성질은 조합의 본질이 '선택할 대상'을 정하는 것뿐만 아니라 '제외할 대상'을 정하는 것과 같다는 직관을 제공합니다. 예를 들어 5명 중 2명을 뽑는 것은 남겨질 3명을 정하는 것과 같습니다. 실전 계산에서는 $r$의 값이 $n$의 절반보다 클 경우, 이 성질을 이용하여 더 작은 숫자로 변환함으로써 계산 과정을 획기적으로 단축할 수 있습니다. 예를 들어 $_{20}C_{18}$을 계산할 때 $_{20}C_2$로 바꾸어 계산하면 훨씬 간편합니다.

## 학습 체크
- $_nC_r$과 $_nC_{n-r}$이 왜 같은 값을 갖는지 조합의 정의를 이용하여 설명할 수 있는가?
- $r$이 $n$의 절반보다 큰 조합 문제를 만났을 때, 계산을 단순화하기 위해 이 성질을 즉각적으로 적용할 수 있는가?

## 관련 개념
- **경우의 수 (고1)**: 조합의 성질을 이용하여 복잡한 선택 문제를 효율적으로 해결하는 기초 원리가 됩니다.
