# 경우의 수 (고1)

> **단원** · 고1 · 선수: [확률 중2](/concepts/확률_중2) · 다음: [경우의 수](/concepts/경우의_수)

## 학습 목표
- 순열과 조합으로 경우의 수를 정확히 센다
- 합·곱의 법칙을 응용 문제에 적용한다

## 다룰 정의 / 정리 / 예제

**정의**
- [순열](/concepts/순열) — $_nP_r$, 조합 $_nC_r$

**정리**
- $_nP_r=\frac{n!}{(n-r)!}$, $_nC_r=\frac{n!}{r!(n-r)!}$
- $_nC_r={}_nC_{n-r}$

**예제**
- 줄세우기 (순열)
- 뽑기 (조합)
- 같은 것이 있는 순열
- [원순열](/concepts/원순열)

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
