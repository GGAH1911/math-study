# 순열

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$_nP_r=n!/(n-r)!$

## 본문 (학습 시 채워짐)

### 정확한 진술

**순열**이란 $n$개의 서로 다른 원소 중에서 $r$개($0 \le r \le n$)를 **순서를 고려하여** 선택해 일렬로 나열하는 것입니다. 이렇게 나열하는 경우의 수를 $_nP_r$ (또는 $P(n,r)$)이라 표기하며, 공식은 다음과 같습니다:

$$_nP_r = \frac{n!}{(n-r)!} = n(n-1)(n-2)\cdots(n-r+1)$$

여기서 $n! = n \times (n-1) \times \cdots \times 2 \times 1$은 **계승(factorial)**입니다.

### 직관: 자리를 채우는 과정

순열을 이해하는 핵심은 **곱의 법칙**입니다. 5명을 일렬로 세우는 상황을 생각해봅시다.
- 첫 번째 자리: 5명 중 아무나 선택 → 5가지
- 두 번째 자리: 남은 4명 중 선택 → 4가지  
- 세 번째 자리: 남은 3명 중 선택 → 3가지

곱의 법칙에 따라 총 경우의 수는 $5 \times 4 \times 3 = 60$입니다. 이것이 $_5P_3$입니다.

**순서가 중요**하다는 점이 핵심입니다. (A, B, C)와 (B, A, C)는 서로 다른 나열입니다.

### 공식의 의미

$_nP_r = \frac{n!}{(n-r)!}$에서 분자 $n!$은 $n$개 모두를 나열할 때의 경우의 수입니다. 분모 $(n-r)!$은 선택하지 않은 $(n-r)$개를 고정시키는 경우의 수로, 이를 나누어 실제 순열만 세게 됩니다. 또 다른 관점으로, $_nP_r = n(n-1)(n-2)\cdots(n-r+1)$은 첫 자리부터 $r$번째 자리까지 곱의 법칙을 직접 적용한 형태입니다.

### 예시

8명 중 3명을 선택해 순서대로 시상대(금, 은, 동)에 세우는 경우의 수는:
$$_8P_3 = \frac{8!}{5!} = 8 \times 7 \times 6 = 336$$

(`factorial(8)//factorial(5)`)
