### 정확한 진술

주어진 정수 집합 $S = \{a_1, a_2, \ldots, a_n\}$에 대해, $S$의 부분집합 $A$가 **합이 0인 집합**이라는 것은 $A$의 모든 원소의 합이 0이 되는 경우를 말합니다. 즉,
$$\sum_{a_i \in A} a_i = 0$$
을 만족하는 공집합이 아닌 부분집합 $A$입니다. 

### 직관과 의미

합이 0인 집합을 찾는 문제는 "주어진 수들 중에서 일부를 골라, 더했을 때 정확히 0이 되도록 할 수 있는가?"라는 질문입니다. 이는 부분집합의 합(subset sum) 문제의 특수한 경우로, 목표값이 0으로 고정된 것입니다.

예를 들어 양수와 음수가 섞여 있을 때, 양수 그룹과 음수 그룹이 절댓값으로 정확히 같으면 합이 0이 됩니다. 또는 음수만 있다 하더라도, 예를 들어 $\{-3, -2, 5\}$에서 특정 원소들의 합이 0이 될 수 있습니다.

### 구체적인 예

집합 $\{-2, -1, 3, 1\}$에서 부분집합 $\{-2, 1, 1\}$은... (단, 중복 불가면 불가능)
다시, $\{-3, 1, 2\}$에서 $\{-3, 1, 2\}$ 전체는 합이 0입니다.
더 간단히: $\{-2, 1, 1\}$이 아닌 $\{-2, 0, 2\}$라면 합이 0입니다.

실제로 자주 출제되는 형태는 "집합의 부분집합 중 원소의 합이 0이 되는 경우의 수"를 구하는 것으로, 동적계획법(DP)이나 경우의 수 세기로 해결합니다. 예: $S = \{-1, 0, 1\}$이면 합이 0인 부분집합은 $\{0\}$, $\{-1, 1\}$로 2개입니다.
