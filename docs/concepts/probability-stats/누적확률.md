### 정확한 진술

확률변수 $X$의 **누적확률**(또는 누적분포함수)은 확률변수가 어떤 값 $x$ 이하일 확률을 나타냅니다. 이를 $F(x)$로 표기하며, 다음과 같이 정의합니다.

$$F(x) = P(X \leq x)$$

**이산확률변수**인 경우, $x$ 이하인 모든 가능한 값들의 확률을 합합니다:
$$F(x) = \sum_{x_i \leq x} P(X = x_i)$$

**연속확률분포**인 경우, 확률밀도함수 $f(t)$를 $-\infty$부터 $x$까지 적분합니다:
$$F(x) = \int_{-\infty}^{x} f(t) \, dt$$

### 직관적 의미

누적확률은 "~까지의 누적된 확률"입니다. 주사위를 던졌을 때 $F(3)$은 1, 2, 3이 나올 확률의 합이므로, 이 값까지 차곡차곡 쌓인 확률이 무엇인지를 보여줍니다. 

그래프로 나타내면 이산확률은 계단 모양, 연속확률은 완만한 곡선으로 왼쪽에서 오른쪽으로 증가합니다. 누적확률함수는 항상 $0 \leq F(x) \leq 1$이고, $F(-\infty) = 0$, $F(\infty) = 1$을 만족합니다. 

중요한 성질로, 어떤 구간 $(a, b]$의 확률은 누적확률으로 쉽게 구할 수 있습니다:
$$P(a < X \leq b) = F(b) - F(a)$$

### 한 줄 예

주사위를 던질 때 나올 눈이 4 이하일 누적확률: $F(4) = \frac{1}{6} + \frac{1}{6} + \frac{1}{6} + \frac{1}{6} = \frac{2}{3}$
