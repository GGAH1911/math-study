### 정확한 진술

함수 $f$의 정의역에서 $x_1 < x_2$일 때마다 $f(x_1) \leq f(x_2)$를 만족하면, $f$를 **비감소함수**(non-decreasing function)라고 합니다. 다시 말해, $x$가 증가하면 함수값은 증가하거나 같은 수준을 유지합니다.

비감소함수는 증가함수(strictly increasing)보다 약한 조건입니다. 증가함수는 $f(x_1) < f(x_2)$를 요구하지만, 비감소함수는 등호를 허용합니다.

### 직관과 기하적 의미

그래프로 보면 비감소함수는 왼쪽에서 오른쪽으로 이동할 때 높이가 올라가거나 같은 높이에 머물렀다가 다시 올라갑니다. 평평한 구간이 있어도 절대 내려가지 않습니다. 

예를 들어 계단 함수나 절댓값 함수처럼 어떤 구간에서 상수이고 다른 구간에서 증가하는 함수들이 비감소함수의 전형적인 형태입니다. 생활에서는 누적된 판매액, 누적 강수량처럼 시간이 지날수록 같거나 증가하는 양을 나타낼 때 자주 등장합니다.

### 예시

$f(x) = \lfloor x \rfloor$ (바닥함수, 최대정수함수)는 비감소함수입니다. $x$가 증가하면 함수값은 일정하다가 정수에서 한 단계씩 증가합니다. 예를 들어 $f(1.2) = 1 \leq f(2.9) = 2$입니다.

또한 $f(x) = x^2$ (단, $x \geq 0$)도 비감소함수이며, $f(x) = |x|$는 전체 실수에서는 비감소함수가 아니지만 음수 구간에서 한정하면 비감소함수입니다.

**검산:** `sympy.solve(x**2 - 4, x)` 를 통해 $x^2 = 4$의 해가 $x = -2, 2$임을 확인할 수 있고, $x \geq 0$ 범위에서 $0 \leq 2$일 때 $f(0) = 0 \leq f(2) = 4$임이 명확합니다.
