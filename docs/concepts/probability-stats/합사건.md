### 정확한 진술

두 사건 $A$, $B$에 대하여, **합사건**은 "$A$ 또는 $B$가 일어나는 사건"을 의미하며, $A \cup B$로 표기합니다. 집합 표현으로는:

$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$

즉, $A$에 속하거나 $B$에 속하거나, 또는 둘 다에 속하는 모든 경우를 포함합니다. 일반적으로 $n$개의 사건 $A_1, A_2, \ldots, A_n$에 대해서도 $A_1 \cup A_2 \cup \cdots \cup A_n$으로 확장합니다.

### 직관과 기하적 의미

합사건은 "**적어도 하나가 일어나는 경우**"입니다. 벤 다이어그램에서 두 원이 겹치는 영역을 포함하여 둘의 경계선 안에 있는 모든 부분이 $A \cup B$입니다. 

일상적으로는 주사위를 던질 때 $A$ = "짝수가 나온다", $B$ = "4 이상이 나온다"라고 하면, $A \cup B$는 "짝수 또는 4 이상"이므로 $\{2, 4, 5, 6\}$입니다. 4와 6은 두 조건을 모두 만족하지만, 합사건에는 한 번만 포함됩니다.

합사건의 확률은 **포함-배제 원리**로 구합니다:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$P(A \cap B)$를 빼는 이유는 겹치는 부분 (교집합)이 두 번 더해지기 때문입니다. 특히 $A$와 $B$가 **배반사건**(동시에 일어날 수 없음)이면 $P(A \cap B) = 0$이므로:

$$P(A \cup B) = P(A) + P(B)$$

### 한 줄 예

주사위를 한 번 던질 때, $A$ = "3의 배수", $B$ = "4 이상"이면 $A \cup B = \{3, 4, 5, 6\}$이고, $P(A \cup B) = \frac{4}{6} = \frac{2}{3}$입니다. (검산: $P(A) = \frac{2}{6}$, $P(B) = \frac{3}{6}$, $P(A \cap B) = P(\{6\}) = \frac{1}{6}$이므로 $\frac{2}{6} + \frac{3}{6} - \frac{1}{6} = \frac{4}{6}$)
