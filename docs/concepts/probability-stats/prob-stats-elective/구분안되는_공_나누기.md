# 구분안되는 공 나누기

> **예제** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
중복조합

## 본문 (학습 시 채워짐)

### 문제

같은 종류의 사탕 8개를 3개의 서로 다른 상자 A, B, C에 나누어 넣는다. 각 상자에는 최소 0개 이상 들어가야 한다. 모든 경우의 수를 구하시오.

### 단계별 풀이

**1단계: 문제의 본질 파악**  
사탕이 모두 같으므로 어떤 사탕이 어디 가는지는 상관없습니다. 중요한 것은 각 상자에 **몇 개씩** 들어가는가입니다. 즉, $a + b + c = 8$ (A에 $a$개, B에 $b$개, C에 $c$개)을 만족하는 음이 아닌 정수해를 찾는 것입니다.

**2단계: 중복조합 공식 적용**  
서로 다른 $n=3$개(상자)에서 중복을 허용하여 $r=8$개를 선택하는 중복조합이므로:
$$H(3, 8) = C(3+8-1, 8) = C(10, 8) = C(10, 2)$$

**3단계: 계산하기**  
$$C(10, 2) = \frac{10 \times 9}{2 \times 1} = 45$$

공식의 논리: $n$개 종류 중 중복 선택 $r$개는 "○" $r$개와 "│" $(n-1)$개를 배열하는 것과 같습니다. 예를 들어 ○○○│○○│○○○는 A에 3개, B에 2개, C에 3개를 뜻합니다. 총 $r+n-1$개 자리 중 칸막이를 배치하므로 $C(r+n-1, n-1)$입니다. (sympy: `comb(10, 2)` = 45)

### 답

45가지

### 변형/주의

**변형:** 각 상자에 **최소 1개씩** 들어가야 한다면?  
먼저 각 상자에 1개씩 배치(3개 소비)한 뒤, 남은 5개를 자유롭게 배분합니다.
$$H(3, 5) = C(7, 2) = 21$$

**주의:** "구분 안 되는 공"과 "구분되는 상자"를 헷갈리지 마세요. 상자가 구분 안 되면 중복조합이 아닌 다른 분할 문제가 됩니다. 또한 중복조합은 **같은 종류의 것을 여러 번 선택할 수 있는** 상황에서만 적용됩니다.
