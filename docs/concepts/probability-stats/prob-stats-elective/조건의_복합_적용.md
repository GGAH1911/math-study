### 정확한 진술

조건의 복합 적용이란, 어떤 사건이 두 개 이상의 조건을 **동시에** 만족해야 하는 경우를 다루는 것입니다. 이때 각 조건의 관계(모두 만족, 적어도 하나 만족, 특정 조건 제외)에 따라 경우의 수를 올바르게 계산해야 합니다.

조건 $A$와 $B$가 있을 때:
- **AND** (모두 만족): $A \cap B$ 구간의 경우의 수만 센다
- **OR** (하나라도 만족): $|A \cup B| = |A| + |B| - |A \cap B|$ (포함-배제 원리)
- **NOT** (특정 조건 제외): 전체에서 제외할 조건을 뺀다

### 직관과 의미

실생활 선택은 거의 항상 여러 제약을 동시에 고려합니다. 예를 들어 "회원이면서 동시에 할인 대상"이라거나 "서울에 살면서 동시에 30대 미만"처럼 여러 조건이 겹칩니다. 이런 상황에서 조건들이 **어떻게 만나는지** 명확히 파악하지 못하면 중복 계산하거나 빠뜨리게 됩니다. 조건의 복합 적용은 이 모호함을 제거하고 각 경우를 정확히 분류하는 도구입니다.

### 구체적 예

10명의 학생(남학생 6명, 여학생 4명) 중 **남자이면서 동시에 수학을 잘하는 학생**이 3명일 때, 이 조건을 모두 만족하는 경우의 수는 3입니다. 이는 "남자" AND "수학을 잘함" 조건의 교집합을 세는 것입니다.

반대로 **"남자이거나 수학을 잘하는" 학생**의 수라면, $6 + 3 - 3 = 6$ (남자 전체에서 이미 수학 잘하는 남학생을 센 후, 수학 잘하는 여학생 추가) 같은 식으로 포함-배제 원리를 적용합니다.
