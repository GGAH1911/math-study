### 정확한 진술

두 사건 $A$, $B$에 대하여 다음이 성립합니다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

여기서 $P(A \cup B)$는 사건 $A$ 또는 $B$ (또는 둘 다)가 일어날 확률이고, $P(A \cap B)$는 두 사건이 동시에 일어날 확률입니다.

### 직관과 기하적 의미

벤다이어그램을 떠올려 보세요. 사건 $A$를 나타내는 원과 사건 $B$를 나타내는 원이 서로 겹쳐 있습니다. 합집합 $A \cup B$의 확률을 구하려면 $P(A)$에 $P(B)$를 더합니다. 하지만 겹치는 부분 $A \cap B$는 두 번 더해지므로, 올바른 확률을 얻으려면 한 번 빼야 합니다. 이것이 덧셈정리입니다.

특별한 경우로, 두 사건이 서로 **배반**(겹치지 않음)이면 $A \cap B = \emptyset$이므로 $P(A \cap B) = 0$입니다. 따라서 $P(A \cup B) = P(A) + P(B)$로 간단해집니다.

### 구체적인 예

주사위를 한 번 던질 때, "홀수가 나오거나 3의 배수가 나올 확률"을 구해 봅시다.

- $A$ = {홀수} = {1, 3, 5} → $P(A) = \dfrac{3}{6}$
- $B$ = {3의 배수} = {3, 6} → $P(B) = \dfrac{2}{6}$  
- $A \cap B = \{3\}$ → $P(A \cap B) = \dfrac{1}{6}$

따라서 $P(A \cup B) = \dfrac{3}{6} + \dfrac{2}{6} - \dfrac{1}{6} = \dfrac{4}{6} = \dfrac{2}{3}$
