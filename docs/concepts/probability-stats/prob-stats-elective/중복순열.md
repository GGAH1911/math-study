# 중복순열

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
$n^r$

## 본문 (학습 시 채워짐)

### 정확한 진술

$n$개의 서로 다른 원소 중에서 **중복을 허용**하여 $r$개를 선택해 일렬로 나열하는 경우의 수를 **중복순열**이라 하며, 다음과 같이 표기합니다.

$$\mathbf{\overline{P}(n, r) = n^r}$$

### 직관/기하적 의미

일반 순열과 달리 **같은 원소를 여러 번 선택할 수 있습니다.** 곱의 법칙으로 이해하면:

- **1번째 자리**: $n$가지 선택지
- **2번째 자리**: 여전히 $n$가지 (이미 1번째에 선택한 것도 다시 선택 가능)
- **3번째 자리**: 여전히 $n$가지
- ⋮
- **$r$번째 자리**: 여전히 $n$가지

곱의 법칙에 의해 총 경우의 수는 $n \times n \times \cdots \times n$ ($r$번 곱함) = $n^r$입니다.

### 한 줄 예

숫자 1, 2, 3, 4 중에서 중복을 허용하여 **2개를 선택해 2자리 수를 만드는** 경우의 수:

각 자리마다 4가지 선택이 가능하므로 $\overline{P}(4, 2) = 4^2 = 16$가지입니다.  
(11, 12, 13, 14, 21, 22, …, 43, 44)

*검증 코드:* `len([(i,j) for i in range(1,5) for j in range(1,5)])` → 16

### 구별 포인트

일반 **순열** $P(n, r) = \frac{n!}{(n-r)!}$에서는 한 번 선택한 원소를 다시 선택할 수 없지만, 중복순열은 **제약이 없습니다.** 따라서 $n < r$인 경우에도 정의됩니다.  
예: 2개 숫자에서 3개를 선택 → $\overline{P}(2, 3) = 2^3 = 8$ (111, 112, 121, 122, 211, 212, 221, 222)
