# 중복조합

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
$_{n+r-1}C_r$

## 본문 (학습 시 채워짐)

### 정확한 진술

$n$개의 서로 다른 원소 중에서 **중복을 허용**하여 $r$개를 택하는 경우의 수를 **중복조합**이라고 합니다. 이를 $\text{H}(n,r)$ 또는 $_nH_r$로 나타내며, 다음 공식으로 계산합니다:

$$\text{H}(n,r) = _{n+r-1}C_r = \frac{(n+r-1)!}{r!(n-1)!}$$

이는 조합 $\binom{n}{r}$처럼 **순서는 상관없지만**, 같은 원소를 여러 번 선택할 수 있다는 점이 핵심입니다.

### 직관 및 기하적 의미

중복조합은 일상에서 자주 마주칩니다:
- 같은 종류의 과자를 구별 없이 담기
- 빵 가게에서 여러 종류 중 정해진 개수 사기
- 같은 구슬을 여러 개의 상자에 넣기

**생성함수 관점**: 각 원소를 0번 이상 몇 번이든 선택할 수 있으므로, 문제를 **음이 아닌 정수해 찾기**로 변환할 수 있습니다:
$$x_1 + x_2 + \cdots + x_n = r \quad (x_i \geq 0)$$

이 방정식의 해의 개수는 중복조합 $\text{H}(n,r)$과 같으며, 중복조합 공식 $_{n+r-1}C_r$이 바로 이 해의 개수입니다.

### 계산 예

사과, 배, 포도 3가지 과일 중 중복을 허용하여 2개를 고르는 경우의 수:
$$\text{H}(3,2) = _{3+2-1}C_2 = _4C_2 = \frac{4 \times 3}{2 \times 1} = 6$$

실제 경우: (사,사), (사,배), (사,포), (배,배), (배,포), (포,포) ✓

```
import sympy as sp
# 검산: 4개 중 2개를 선택
sp.binomial(4, 2)  # 결과: 6
```
