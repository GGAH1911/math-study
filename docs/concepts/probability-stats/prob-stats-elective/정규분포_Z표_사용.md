# 정규분포 Z표 사용

> **예제** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
신뢰구간 / 표준화

## 본문 (학습 시 채워짐)

### 문제

어떤 대학 입학생의 수능 수학 점수는 평균이 100점, 표준편차가 15점인 정규분포를 따른다고 한다. 200명의 입학생을 표본으로 조사했을 때, 표본 평균이 102점이었다. 신뢰도 95%에서 모평균의 신뢰구간을 구하시오. (단, $Z_{0.025} = 1.96$)

### 단계별 풀이

**1단계: 주어진 정보 정리**

- 모표준편차: $\sigma = 15$
- 표본크기: $n = 200$  
- 표본평균: $\bar{x} = 102$
- 신뢰도: 95% → $Z_{\alpha/2} = 1.96$

**2단계: 표본평균의 표준오차 계산**

표본평균은 근사적으로 정규분포를 따르며, 표준오차(standard error)는:

$$SE = \frac{\sigma}{\sqrt{n}} = \frac{15}{\sqrt{200}} \approx 1.061$$

**3단계: 신뢰구간 공식 적용**

신뢰도 95%일 때 신뢰구간은:

$$\bar{x} \pm Z_{\alpha/2} \cdot SE = 102 \pm 1.96 \times 1.061 = 102 \pm 2.08$$

### 답

**신뢰구간: $(99.92, 104.08)$ 또는 $99.92 \le \mu \le 104.08$**

이는 모평균이 99.92점과 104.08점 사이에 있을 확률이 95%라는 의미입니다.

(검산: `import math; print(round(102 - 1.96*15/math.sqrt(200), 2), round(102 + 1.96*15/math.sqrt(200), 2))`)

### 변형/주의

**표준화의 의미:** Z표를 사용할 때는 $Z = \frac{\bar{x} - \mu}{SE}$로 표준화합니다. 신뢰도가 주어지면 Z값을 표에서 찾아 역으로 신뢰구간을 구하는 원리입니다.

**신뢰도별 Z값:**
- 90% 신뢰도: $Z_{0.05} = 1.645$
- 95% 신뢰도: $Z_{0.025} = 1.96$  
- 99% 신뢰도: $Z_{0.005} = 2.576$

신뢰도가 높을수록 Z값이 커져 신뢰구간이 넓어집니다.

**표본크기의 영향:** 표본크기가 클수록 표준오차 $SE = \frac{\sigma}{\sqrt{n}}$가 작아져서 신뢰구간이 좁아지고 추정의 정확도가 높아집니다. 예를 들어 표본이 400명이었다면 $SE \approx 0.75$로 더 정밀한 추정이 가능했을 것입니다.
