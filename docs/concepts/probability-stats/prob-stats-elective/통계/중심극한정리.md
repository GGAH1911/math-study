# 중심극한정리

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
모집단의 분포 모양과 상관없이 표본의 크기가 커질수록 표본평균의 분포는 정규분포에 가까워진다는 원리입니다.

## 본문
모집단의 평균이 $\mu$이고 표준편차가 $\sigma$일 때, 이 모집단에서 크기가 $n$인 표본을 반복적으로 추출하여 얻은 표본평균 $\bar{X}$의 분포는 $n$이 충분히 크다면 평균이 $\mu$이고 표준편차가 $\frac{\sigma}{\sqrt{n}}$인 정규분포 $N\left(\mu, \frac{\sigma^2}{n}\right)$에 가까워집니다. 이때 가장 중요한 특징은 원래 모집단의 분포가 정규분포가 아닌 다른 형태(균등분포, 왜곡된 분포 등)일지라도 표본의 크기 $n$이 커지면 표본평균의 분포는 반드시 정규분포의 형태를 띠게 된다는 점입니다.

### 직관과 기하적 의미
표본의 크기가 커질수록 우리가 관찰하는 표본평균의 값들은 모집단의 실제 평균인 $\mu$를 중심으로 종 모양의 정규분포를 그리며 모이게 됩니다. 이는 표본을 많이 뽑을수록 표본평균이 모집단의 특성을 더 정확하게 반영하게 된다는 직관을 수학적으로 뒷받침합니다.

### 기본 성질
표본의 크기 $n$이 커질수록 표본평균의 분산인 $\frac{\sigma^2}{n}$은 작아집니다. 이는 표본의 크기가 커질수록 표본평균들이 모집단의 평균 $\mu$ 근처에 더 밀집하게 되어, 추정의 정밀도가 높아짐을 의미합니다.

## 학습 체크
- 모집단의 분포가 정규분포가 아닐 때, 표본평균의 분포는 어떤 모양을 갖게 되는가?
- 표본의 크기 $n$이 커질수록 표본평균의 표준편차는 어떻게 변화하는가?

## 관련 개념
- **통계**: 표본을 통해 모집단의 특성을 추론하는 과정에서, 표본평균의 분포를 정규분포로 가정할 수 있게 해주는 핵심적인 근거가 됩니다.
