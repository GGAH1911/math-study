# 표준오차

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
표준오차는 표본통계량이 모수로부터 얼마나 떨어져 있는지를 나타내는 지표로, 표본 크기가 커질수록 추정의 정확도가 높아짐을 의미합니다.

## 본문
표준오차(standard error, SE)는 표본통계량의 표준편차를 의미하며, 표본을 통해 얻은 추정값이 실제 모수로부터 평균적으로 얼마나 벗어나 있는지를 정량화한 값입니다. 모표준편차 $\sigma$와 표본 크기 $n$을 알 때 표본평균 $\bar{X}$의 표준오차는 $SE(\bar{X}) = \tfrac{\sigma}{\sqrt{n}}$으로 계산됩니다. 만약 모표준편차를 알 수 없는 실제 상황이라면 표본표준편차 $s$를 사용하여 $SE(\bar{X}) = \tfrac{s}{\sqrt{n}}$으로 추정하여 사용합니다.

### 직관과 기하적 의미
동일한 모집단에서 표본을 반복하여 추출할 때, 각 표본의 평균값들은 서로 조금씩 다른 값을 가집니다. 이러한 표본평균들이 이루는 분포를 표본분포라고 하며, 이 분포 내에서 표본평균들이 얼마나 넓게 흩어져 있는지를 나타내는 척도가 바로 표준오차입니다. 표준오차가 작다는 것은 표본평균들이 모평균 근처에 밀집해 있다는 것을 의미하므로 추정의 신뢰도가 높음을 시사하며, 반대로 표준오차가 크다는 것은 표본평균들이 넓게 퍼져 있어 추정의 불확실성이 높음을 의미합니다.

### 기본 성질
표준오차는 표본의 크기 $n$의 제곱근에 반비례하는 성질을 가집니다. 따라서 표본의 크기가 4배로 증가하면 표준오차는 $\tfrac{1}{2}$로 감소하게 됩니다. 예를 들어 모표준편차가 20점인 모집단에서 표본 크기가 400명일 때의 표준오차는 $\tfrac{20}{\sqrt{400}} = 1$점으로 매우 작지만, 표본 크기를 100명으로 줄이면 표준오차는 $\tfrac{20}{\sqrt{100}} = 2$점이 되어 추정의 불확실성이 커집니다.

## 학습 체크
- 표본의 크기가 커질 때 표준오차는 어떻게 변화하며, 이것이 추정의 신뢰도와 어떤 관계가 있는가?
- 모표준편차를 모르는 경우 표준오차를 구하기 위해 어떤 값을 대신 사용해야 하는가?

## 관련 개념
- **통계**: 표본을 통해 모집단의 특성을 추론하는 과정에서 표준오차는 추정값의 정밀도를 측정하는 핵심적인 도구로 사용됩니다.
