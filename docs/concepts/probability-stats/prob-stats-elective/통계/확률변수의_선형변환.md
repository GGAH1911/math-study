# 확률변수의 선형변환

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
확률변수 $X$에 상수 $a, b$를 적용하여 만든 $Y = aX + b$의 기댓값은 $aE(X) + b$이며, 분산은 $a^2V(X)$가 됩니다.

## 본문
확률변수 $X$에 상수 $a, b$($a \neq 0$)를 이용하여 새로운 확률변수 $Y = aX + b$를 만드는 것을 **확률변수의 선형변환**이라 합니다. 선형변환을 거친 새로운 확률변수 $Y$ 역시 고유한 확률분포를 가지며, 이에 따른 기댓값과 분산을 새롭게 정의할 수 있습니다.

### 직관과 기하적 의미
확률변수에 상수 $b$를 더하는 것은 확률분포의 모양을 유지한 채 전체를 평행이동시키는 것과 같습니다. 따라서 데이터의 퍼짐 정도를 나타내는 분산에는 아무런 영향을 주지 않습니다. 반면, 확률변수에 $a$배를 하는 것은 데이터 사이의 간격을 $a$배만큼 확대하는 효과를 줍니다. 이때 데이터의 흩어짐을 나타내는 분산은 간격의 제곱에 비례하여 변화하므로 $a^2$배가 됩니다. 이는 길이를 2배로 늘리면 넓이가 4배가 되는 원리와 유사합니다.

### 기본 성질
선형변환된 확률변수 $Y$의 기댓값과 분산은 다음과 같은 공식으로 계산됩니다.
$$E(Y) = E(aX + b) = aE(X) + b$$
$$V(Y) = V(aX + b) = a^2V(X)$$
기댓값은 원래의 기댓값에 $a$를 곱한 후 $b$를 더한 값과 같아 선형성을 유지하지만, 분산은 계수의 제곱인 $a^2$만큼 변화한다는 점이 핵심입니다.

## 학습 체크
- $Y = aX + b$에서 상수항 $b$가 기댓값과 분산에 각각 어떤 영향을 미치는지 설명할 수 있는가?
- 확률변수 $X$의 분산이 $V(X)$일 때, $Y = -3X + 5$의 분산은 왜 $9V(X)$가 되는지 논리적으로 설명할 수 있는가?

## 관련 개념
- **통계**: 데이터의 중심 경향성과 산포도를 변환된 변수에 적용하여 새로운 데이터 집합의 특성을 파악하는 기초가 됩니다.
