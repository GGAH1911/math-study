# 표준정규분포표

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
표준정규분포 $N(0,1)$을 따르는 확률변수의 누적확률 값을 미리 계산하여 정리해 놓은 표입니다.

## 본문
표준정규분포표는 표준정규분포 $N(0,1)$을 따르는 확률변수 $Z$에 대하여, 특정 값 $z$ 이하의 확률인 $P(Z \leq z)$를 미리 계산하여 정리한 표입니다. 즉, 주어진 $z$값에 대응하는 표준정규분포의 누적분포함수 값을 나타냅니다.

### 직관과 기하적 의미
정규분포를 따르는 확률변수를 표준화하면 평균이 0이고 표준편차가 1인 표준정규분포가 됩니다. 이때 특정 구간의 확률을 구하기 위해서는 다음과 같은 적분 식을 계산해야 합니다.

$$P(Z \leq z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-t^2/2} dt$$

이 적분은 초등함수로 표현할 수 없는 복잡한 형태를 띠고 있습니다. 따라서 실무나 시험에서는 이 적분 값을 미리 계산해 둔 표를 참조하여 문제를 해결합니다. 기하학적으로 표의 값은 종 모양의 정규분포 곡선에서 왼쪽 끝부터 해당 $z$값까지의 면적, 즉 그래프 아래의 넓이를 의미합니다. 이를 통해 특정 점수 이하가 나타날 확률을 매우 빠르게 구할 수 있습니다.

### 기본 성질
- $z$값이 커질수록 누적확률 값도 커지며, $z=0$일 때 확률 값은 $0.5$입니다.
- 표준정규분포의 대칭성으로 인해 $P(Z \geq z) = 1 - P(Z \leq z)$의 관계가 성립합니다.

## 학습 체크
- 표준정규분포표의 값이 의미하는 기하학적 대상은 무엇인가요?
- 왜 확률을 구할 때 적분 식 대신 표준정규분포표를 사용하나요?
- $Z=1.96$일 때 표에서 읽은 값이 $0.975$라면, $Z$가 $1.96$보다 클 확률은 얼마인가요?

## 관련 개념
- **확률**: 표준정규분포표의 값은 연속확률변수가 특정 범위에 속할 확률을 나타냅니다.
- **표준화**: 일반적인 정규분포를 따르는 확률변수를 표준정규분포표를 이용할 수 있는 $Z$값으로 변환하는 과정입니다.
- **누적분포함수**: 확률변수가 특정 값 이하의 값을 가질 확률을 나타내는 함수로, 표준정규분포표는 이 함수의 값을 정리한 것입니다.
