# 확률변수의 변환

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
확률변수에 특정 함수를 적용하여 생성된 새로운 확률변수의 분포를 구하는 과정입니다.

## 본문
확률변수 $X$가 주어져 있고, 실수 전체의 집합에서 실수 전체의 집합으로 대응하는 함수 $g$가 있을 때, $Y = g(X)$로 정의된 $Y$ 또한 확률변수입니다. 이때 $Y$의 확률분포는 원래의 확률변수 $X$의 확률분포와 적용된 함수 $g$에 의해 완전히 결정됩니다. 구체적으로 임의의 사건 $\{Y \leq y\}$에 대하여 $P(Y \leq y) = P(g(X) \leq y) = P(X \in g^{-1}((-\infty, y]))$로 계산할 수 있으며, 이를 통해 $Y$의 누적분포함수 또는 확률밀도함수를 도출할 수 있습니다.

### 직관과 기하적 의미
어떤 무작위 상황을 나타내는 확률변수 $X$에 특정한 규칙인 함수 $g$를 적용하면 새로운 무작위 상황인 확률변수 $Y$가 만들어집니다. 예를 들어 주사위 눈금 $X$에 2를 곱하여 $Y = 2X$라는 새로운 변수를 만들면, 각 눈금에 대응하는 확률은 유지되지만 값의 범위가 달라집니다. 즉, 원래의 불확실성은 그대로 유지되지만 함수에 의해 값들의 분포 패턴이 변하게 됩니다. 이때 변환이 선형적이면 분포의 형태는 유지된 채 평균과 분산만 바뀌지만, 비선형적 변환이 적용되면 분포의 형태 자체가 완전히 변하게 됩니다.

### 기본 성질
$X \sim N(0, 1)$인 표준정규분포를 따를 때, $Y = 3X + 5$와 같은 선형변환을 수행하면 $Y \sim N(5, 9)$가 됩니다. 이는 일변량 선형변환의 성질에 따라 평균은 $E[Y] = 3 \cdot 0 + 5 = 5$가 되고, 분산은 $\text{Var}(Y) = 3^2 \cdot 1 = 9$가 됨을 의미합니다.

## 학습 체크
- 함수 $g$가 일대일 대응이 아닐 때 $Y$의 확률밀도함수를 어떻게 구할 것인가?
- 선형변환과 비선형변환이 각각 확률분포의 형태에 어떤 영향을 미치는가?

## 관련 개념
- **확률**: 확률변수가 취하는 각 값에 할당된 가능성을 의미하며, 변환된 변수의 분포를 결정하는 기초가 됩니다.
