# 유한소수

## 정확한 진술

**유한소수**란 소수점 이하의 자릿수가 유한한 실수입니다. 즉, 어느 자리부터는 0이 반복되어 정확히 표현되는 수입니다. 

분수 형태로는 다음과 같이 특징지어집니다: 기약분수 $\frac{a}{b}$가 유한소수가 되려면, 분모 $b$를 소인수분해했을 때 **2와 5의 거듭제곱으로만 이루어져야** 합니다. 즉, $b = 2^m \times 5^n$ 형태여야 합니다(단, $m, n \geq 0$).

예를 들어 $\frac{1}{8} = \frac{1}{2^3}$ 은 유한소수이지만, $\frac{1}{3}$은 분모에 3이 있어 무한소수가 됩니다.

## 직관: 10진법과의 관계

10진법은 $10 = 2 \times 5$로 이루어져 있습니다. 분모가 2나 5의 거듭제곱이면, 충분히 큰 자리 이후로 남은 분자를 10의 거듭제곱으로 나눌 수 있어 정확히 끝나게 됩니다.

예를 들어:
- $\frac{1}{4} = \frac{25}{100} = 0.25$ (분모 $4 = 2^2$ 이므로, $10^2 = 100$으로 변환 가능)
- $\frac{3}{5} = \frac{6}{10} = 0.6$ (분모 5이므로, $10^1$로 변환 가능)

반면 분모에 3이나 7 같은 소인수가 있으면, 10의 거듭제곱으로 그 부분을 만족시킬 수 없어 무한히 반복되는 순환소수가 됩니다.

## 한 줄 예

$\frac{7}{8} = 0.875$ (분모 $8 = 2^3$이므로 유한소수)
$$\text{확인: } \frac{7}{8} = \frac{7 \times 125}{8 \times 125} = \frac{875}{1000} = 0.875$$
