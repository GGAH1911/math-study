# 정규분포

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
평균 $\mu$를 중심으로 좌우대칭인 종 모양의 확률밀도함수를 가지는 연속확률분포입니다.

## 본문
확률변수 $X$가 정규분포를 따른다는 것은, $X$의 확률밀도함수가 다음과 같을 때를 의미합니다:
$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}$$
여기서 $\mu$는 평균, $\sigma^2$은 분산이며, $\sigma > 0$입니다. 이를 $X \sim N(\mu, \sigma^2)$로 표기합니다.

### 직관과 기하적 의미
정규분포의 그래프는 종 모양(bell curve)으로, 평균 $\mu$를 중심으로 좌우대칭인 형태를 띱니다. 평균에서 멀어질수록 확률이 급격히 감소하므로, 데이터가 평균 근처에 밀집되는 현상을 잘 나타냅니다. 표준편차 $\sigma$는 분포의 퍼짐 정도를 결정하며, $\sigma$가 작을수록 그래프는 중심에 높게 솟은 뾰족한 모양이 되고, $\sigma$가 클수록 완만하고 넓게 퍼진 모양이 됩니다.

### 기본 성질
정규분포는 표준편차를 기준으로 데이터가 분포하는 구간에 따라 다음과 같은 확률적 특징을 가집니다. 이를 68-95-99.7 규칙이라고 합니다.
- $P(\mu - \sigma < X < \mu + \sigma) \approx 0.683$ (약 68%)
- $P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.954$ (약 95%)
- $P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 0.997$ (약 99.7%)

예를 들어, 수능 수학 점수가 $N(100, 15^2)$를 따른다면, 100점과 115점 사이의 학생 비율은 약 34%입니다. 이는 표준정규분포 $N(0,1)$에서 $P(0 < Z < 1) \approx 0.3413$인 것과 같습니다.
