# 정규분포

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)
## 요약
$N(\mu, \sigma^2)$

## 본문

확률변수 $X$가 **정규분포**를 따른다는 것은, $X$의 확률밀도함수가 다음과 같을 때를 의미합니다:

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right), \quad x \in \mathbb{R}$$

여기서 $\mu$는 평균, $\sigma^2$은 분산이며, $\sigma > 0$입니다. 이를 $X \sim N(\mu, \sigma^2)$로 표기합니다.

### 직관과 기하적 의미

정규분포의 그래프는 **종 모양**(bell curve)으로, 평균 $\mu$를 중심으로 좌우대칭입니다. 평균에서 멀어질수록 확률이 빠르게 감소하므로, 데이터가 평균 근처에 집중되는 현상을 잘 설명합니다.

표준편차 $\sigma$는 분포의 **퍼짐 정도**를 나타냅니다. $\sigma$가 작을수록 뾰족하고, 클수록 완만합니다. 

특히 다음이 성립합니다:
- $P(\mu - \sigma < X < \mu + \sigma) \approx 0.683$ (약 68%)
- $P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.954$ (약 95%)
- $P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 0.997$ (약 99.7%)

이를 **68-95-99.7 규칙**이라 합니다.

### 한 줄 예

학생들의 수능 수학 점수가 $N(100, 15^2)$를 따를 때, 100점과 115점 사이의 학생 비율은 약 34% 정도입니다.

실제로, 표준정규분포 $N(0,1)$에서 $P(0 < Z < 1) \approx 0.3413$입니다. (계산 예: `from scipy.stats import norm; print(round(norm.cdf(1) - norm.cdf(0), 4))`)
