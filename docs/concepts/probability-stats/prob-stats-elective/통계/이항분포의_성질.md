# 이항분포의 성질

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
$n$번의 독립 시행에서 성공 확률이 $p$인 이항분포 $B(n, p)$의 평균은 $np$, 분산은 $np(1-p)$입니다.

## 본문
$n$번의 독립 시행에서 성공 확률이 $p$인 이항분포 $B(n, p)$는 성공한 횟수를 확률변수 $X$로 할 때, $X$가 가질 수 있는 값에 따른 확률 분포를 의미합니다. 이 분포에서 $X$의 평균(기댓값)은 $E[X] = np$이며, 분산은 $V[X] = np(1-p)$, 표준편차는 $\sigma(X) = \sqrt{np(1-p)}$로 계산됩니다.

### 직관과 기하적 의미
평균이 $np$인 이유는 각 시행에서 기대되는 성공 횟수가 $p$이므로, 이를 $n$번 반복하면 전체 성공 횟수의 기대값은 당연히 $n \times p$가 되기 때문입니다. 예를 들어 동전을 100번 던질 때 앞면이 나올 확률이 $0.5$라면, 평균적으로 $100 \times 0.5 = 50$번의 앞면이 나옵니다. 분산이 $np(1-p)$인 이유는 성공과 실패의 확률이 균형을 이룰수록 결과의 불확실성이 커지기 때문입니다. 성공 확률 $p$가 $0.5$에 가까울수록 분산은 최대가 되고, $0$이나 $1$에 가까워질수록 결과가 예측 가능해지므로 분산은 작아집니다. 표준편차는 실제 관측값이 평균으로부터 얼마나 떨어져 있는지를 나타내며, 이 값이 클수록 운에 따른 변동성이 크다는 것을 의미합니다.

### 기본 성질
- 평균(기댓값): $E[X] = np$
- 분산: $V[X] = np(1-p)$
- 표준편차: $\sigma(X) = \sqrt{np(1-p)}$
- 예시: 주사위를 120번 던질 때 6이 나오는 횟수를 $X$라 하면, $X \sim B(120, \tfrac{1}{6})$이고 $E[X] = 20$, $V[X] = \tfrac{100}{6} \approx 16.67$입니다.

## 학습 체크
- 이항분포에서 성공 확률 $p$가 $0.5$일 때 분산은 언제 최대가 되는가?
- 시행 횟수 $n$이 커질 때 평균과 분산은 각각 어떻게 변화하는가?

## 관련 개념
- **확률**: 각 시행에서 사건이 발생할 가능성을 나타내며, 이항분포의 매개변수 $p$를 결정하는 기초가 됩니다.
