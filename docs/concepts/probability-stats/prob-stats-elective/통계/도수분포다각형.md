# 도수분포다각형

## 정확한 진술

도수분포다각형은 도수분포표에서 각 계급의 **계급값**(계급의 중점)을 $x$축에, 대응하는 **도수**를 $y$축에 나타낸 뒤, 이 점들을 선분으로 연결한 꺾은선 그래프입니다. 양 끝점은 인접한 계급의 계급값까지 도수 0인 점으로 확장하여 그립니다.

## 직관/기하적 의미

도수분포표는 숫자의 나열일 뿐 전체 데이터의 분포 형태를 직관적으로 파악하기 어렵습니다. 도수분포다각형은 이 정보를 시각화하여 분포의 모양, 중심 위치, 퍼짐의 정도를 한눈에 볼 수 있게 합니다. 예를 들어 꺾은선이 한쪽으로 치우쳐 있으면 데이터가 비대칭 분포함을 알 수 있고, 중앙에 뚜렷한 봉우리가 있으면 중앙값 근처에 데이터가 집중되어 있음을 판단할 수 있습니다. 히스토그램(직사각형 막대)과 달리 연속적인 변화 추세를 표현하는 데 효과적이며, 여러 분포를 같은 그래프에 그려 비교할 때도 유용합니다.

## 한 줄 예

어느 학급 학생 100명의 수학 성적을 10점 단위로 분류했을 때, 50~60점(도수 8명), 60~70점(도수 23명), 70~80점(도수 42명), 80~90점(도수 22명), 90~100점(도수 5명)이면, 계급값 55, 65, 75, 85, 95에 대응하는 도수들을 점으로 찍고 선분으로 연결한 꺾은선이 도수분포다각형입니다.
