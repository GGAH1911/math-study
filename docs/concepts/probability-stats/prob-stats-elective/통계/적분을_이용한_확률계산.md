# 적분을 이용한 확률계산

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
연속확률변수가 특정 구간에 속할 확률은 확률밀도함수의 그래프 아래 면적, 즉 정적분 값과 같습니다.

## 본문
연속확률변수 $X$의 확률밀도함수를 $f(x)$라 할 때, $X$가 구간 $[a, b]$에 포함될 확률은 다음의 정적분으로 정의됩니다:
$$P(a \le X \le b) = \int_a^b f(x) \, dx$$
이때 확률밀도함수는 모든 $x$에 대하여 $f(x) \ge 0$이어야 하며, 전체 구간에 대한 적분값은 $\int_{-\infty}^{\infty} f(x) \, dx = 1$을 만족해야 합니다.

### 직관과 기하적 의미
확률밀도함수 $f(x)$의 그래프 아래에서 $x$축 위의 구간 $[a, b]$에 해당하는 영역의 넓이가 곧 해당 구간에 변수가 포함될 확률을 의미합니다. 이산확률변수에서 각 확률을 모두 더하는 것과 달리, 연속확률변수에서는 함수를 적분함으로써 확률을 계산합니다. 예를 들어, 정규분포(평균 $\mu$, 표준편차 $\sigma$)의 확률은 다음과 같은 적분식으로 나타낼 수 있습니다:
$$P(a \le X \le b) = \int_a^b \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \, dx$$
이러한 적분값은 표준정규분포표를 이용하거나 수치적분 방법을 통해 구할 수 있습니다.

### 기본 성질
- 확률밀도함수의 전체 넓이는 항상 1입니다.
- 특정 한 점에서의 확률 $P(X=c)$은 적분값의 정의에 따라 항상 0입니다.
- 확률은 항상 0과 1 사이의 값을 가집니다.

## 학습 체크
- 확률밀도함수 $f(x)$의 그래프 아래 면적이 왜 확률을 의미하는지 기하학적으로 설명할 수 있는가?
- 연속확률변수에서 특정 한 점에서의 확률이 0인 이유를 적분의 관점에서 이해하고 있는가?
- 정규분포의 확률을 구할 때 표준화 과정을 거치는 이유를 적분식의 형태와 연결할 수 있는가?

## 관련 개념
- **확률**: 연속적인 상황에서는 개별 점의 확률 대신 구간의 넓이를 통해 확률을 정의합니다.
- **정적분**: 확률밀도함수의 그래프 아래 면적을 구하기 위해 사용하는 핵심적인 수학적 도구입니다.
- **정규분포**: 확률밀도함수가 종 모양의 곡선을 그리며, 적분을 통해 구간별 확률을 계산하는 대표적인 연속확률분포입니다.
