# 적분을 이용한 확률계산

## 정확한 진술

연속확률변수 $X$의 확률밀도함수를 $f(x)$라 할 때, $X$가 구간 $[a, b]$에 포함될 확률은 다음의 정적분으로 정의됩니다:

$$P(a \le X \le b) = \int_a^b f(x) \, dx$$

여기서 $f(x) \ge 0$ (모든 $x$)이고 $\int_{-\infty}^{\infty} f(x) \, dx = 1$을 만족합니다.

## 직관과 기하적 의미

확률밀도함수 $f(x)$의 그래프 아래, $x$축 위의 구간 $[a, b]$에서 이루어진 영역의 넓이가 바로 그 확률입니다. 이산확률변수에서 여러 확률을 더하듯이, 연속확률변수에서는 확률밀도함수를 적분하여 확률을 계산합니다.

특히 고등학교에서 자주 다루는 정규분포(평균 $\mu$, 표준편차 $\sigma$)의 경우:

$$P(a \le X \le b) = \int_a^b \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \, dx$$

이 적분값을 표준정규분포표로 구하거나 수치적분으로 계산합니다.

## 예제

균등분포 $U(0, 2)$ (구간 $[0, 2]$에서 일정한 확률밀도)에서 확률변수 $X$가 $[0.5, 1.5]$에 포함될 확률을 구하세요.

확률밀도함수는 $f(x) = \dfrac{1}{2}$ (단, $0 \le x \le 2$)이므로:

$$P(0.5 \le X \le 1.5) = \int_{0.5}^{1.5} \frac{1}{2} \, dx = \frac{1}{2}[x]_{0.5}^{1.5} = \frac{1}{2}(1.5 - 0.5) = 0.5$$

따라서 확률은 **0.5** (또는 50%)입니다. 이는 기하적으로 밑변이 1, 높이가 0.5인 직사각형의 넓이와 같습니다.
