# 이항분포 확률 계산

> **예제** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
이항분포의 확률 질량 함수 공식인 ${}_nC_k p^k q^{n-k}$를 이용하여 독립 시행에서 특정 횟수의 성공 확률을 계산합니다.

## 본문
어느 학생이 선택지 4개인 객관식 문제를 무작정 찍고 있습니다. 5문제를 이런 식으로 풀 때, 정확히 2문제를 맞힐 확률을 구하세요.

### 단계별 풀이
한 문제를 맞힐 확률은 $p = \tfrac{1}{4}$이고, 틀릴 확률은 $q = 1 - p = \tfrac{3}{4}$입니다. 시행 횟수는 $n=5$이며, 성공 횟수는 $k=2$인 경우를 구합니다.

**1단계: 조합 계산**
5문제 중 어느 2문제를 맞힐지 선택하는 경우의 수는 다음과 같습니다.
$$\binom{5}{2} = \frac{5 \times 4}{2 \times 1} = 10$$

**2단계: 특정 배열의 확률**
특정 순서로 맞히고 틀리는 경우의 확률은 다음과 같습니다.
$$p^2 \times q^3 = \left(\frac{1}{4}\right)^2 \times \left(\frac{3}{4}\right)^3 = \frac{27}{1024}$$

**3단계: 이항분포 공식 적용**
조합 수와 특정 배열의 확률을 곱하여 최종 확률을 구합니다.
$$P(X=2) = \binom{5}{2} p^2 q^3 = 10 \times \frac{27}{1024} = \frac{135}{512}$$

### 답과 변형
정확히 2문제를 맞힐 확률은 $\boxed{\tfrac{135}{512}}$입니다.

**변형**: "최소 2문제를 맞힐 확률"을 구할 때는 $P(X \geq 2) = P(X=2) + P(X=3) + P(X=4) + P(X=5)$와 같이 각 확률을 모두 더해야 합니다. 계산 시 성공의 위치를 결정하는 조합 $\binom{n}{k}$를 빠뜨리지 않도록 주의해야 합니다.

## 학습 체크
- $n$번의 독립 시행에서 $k$번 성공할 확률을 구할 때 조합을 반드시 포함하는가?
- '적어도' 또는 '최소'라는 표현이 나올 때 여사건이나 합의 개념을 적절히 사용하는가?

## 관련 개념
- **통계**: 이항분포는 통계적 추정의 기초가 되며, 표본의 크기가 커질 때 정규분포로 근사하여 계산할 수 있습니다.
