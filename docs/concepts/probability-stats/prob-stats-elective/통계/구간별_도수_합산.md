### 정확한 진술

구간별 도수 합산은 도수 분포표에서 각 계급(구간)의 도수를 작은 구간부터 누적으로 더하는 과정입니다. $i$번째 구간까지의 누적도수 $F_i$는 다음과 같이 정의됩니다.

$$F_i = \sum_{j=1}^{i} f_j = f_1 + f_2 + \cdots + f_i$$

여기서 $f_j$는 $j$번째 구간의 도수(그 구간에 속하는 자료의 개수)입니다. 마지막 구간까지 누적하면 $F_n = N$ (전체 자료의 개수)이 됩니다.

### 직관과 의미

도수 합산은 "어느 값 이하의 자료가 몇 개인가?"를 빠르게 파악하는 도구입니다. 예를 들어 시험 성적 분포에서 80점 이하인 학생이 전체의 몇 퍼센트인지 알고 싶다면, 80점 구간까지의 누적도수를 보면 됩니다. 이를 통해 상대적 위치(백분위수)도 계산할 수 있으며, 데이터의 분포를 더 깊이 이해하는 데 필수적입니다. 누적도수를 그래프로 나타내면 누적도수곡선(ogive)이 되어 시각화도 가능합니다.

### 한 줄 예

학생 100명의 수학 점수를 10점 구간으로 나누었을 때, 30~40점 구간에 12명, 40~50점 구간에 18명, 50~60점 구간에 25명이 있다면, 60점 이하의 누적도수는 $F_3 = 12 + 18 + 25 = 55$명입니다.
