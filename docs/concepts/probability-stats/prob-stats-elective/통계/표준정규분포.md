# 표준정규분포

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
평균이 0이고 표준편차가 1인 정규분포로, 서로 다른 정규분포를 동일한 기준으로 비교할 수 있게 해주는 표준화된 분포입니다.

## 본문
표준정규분포는 평균이 0이고 표준편차가 1인 정규분포를 의미하며, 확률변수 $Z$가 이를 따를 때 $Z \sim N(0, 1)$로 표기합니다. 이 분포의 확률밀도함수는 다음과 같이 정의됩니다:
$$f(z) = \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}, \quad z \in \mathbb{R}$$

### 직관과 기하적 의미
임의의 정규분포 $N(\mu, \sigma^2)$를 따르는 확률변수 $X$는 표준화 변환인 $Z = \tfrac{X - \mu}{\sigma}$를 통해 표준정규분포로 변환될 수 있습니다. 이를 통해 평균과 표준편차가 서로 다른 여러 정규분포를 하나의 통일된 기준으로 비교하고 계산할 수 있습니다. 기하학적으로 그래프는 $z=0$을 중심으로 좌우 대칭인 종 모양(bell curve)을 그리며, 실제 확률 계산 시에는 누적 확률값이 정리된 표준정규분포표를 활용하여 편리하게 값을 구할 수 있습니다.

### 기본 성질
- 평균은 0이며, 표준편차는 1입니다.
- 그래프는 $z=0$을 축으로 완벽한 좌우 대칭 구조를 가집니다.
- 모든 확률의 합은 1이며, 표준화된 $Z$값에 따른 누적 확률은 표를 통해 쉽게 확인할 수 있습니다.

## 학습 체크
- 정규분포를 따르는 확률변수 $X$를 표준화하여 $Z$로 변환하는 식을 정확히 알고 있는가?
- 표준정규분포표를 사용하여 특정 범위에 속할 확률을 구할 수 있는가?
- 표준정규분포의 그래프 모양과 대칭성에 대해 이해하고 있는가?

## 관련 개념
