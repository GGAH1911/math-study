# 표준정규분포

## 정확한 진술

표준정규분포는 평균이 0, 표준편차가 1인 정규분포를 말합니다. 확률밀도함수는 다음과 같이 정의됩니다:

$$f(z) = \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}, \quad z \in \mathbb{R}$$

확률변수 $Z$가 표준정규분포를 따를 때, $Z \sim N(0, 1)$로 표기합니다.

## 직관 및 기하적 의미

임의의 정규분포 $N(\mu, \sigma^2)$를 따르는 확률변수 $X$는 **표준화 변환**으로 표준정규분포로 변환할 수 있습니다:

$$Z = \frac{X - \mu}{\sigma}$$

이를 표준화(standardization)라 하며, 평균과 표준편차가 다른 여러 정규분포를 하나의 기준으로 비교·계산하게 해줍니다.

기하학적으로 그래프는 $z=0$을 중심으로 좌우 대칭인 종 모양(bell curve)입니다. $P(Z \leq 1) \approx 0.8413$, $P(Z \leq 2) \approx 0.9772$처럼 누적분포함수 값들이 표로 정리되어 있어, 실제 계산에서는 이 **표준정규분포표**를 참조하여 확률을 빠르게 구합니다.

## 한 줄 예

어떤 학교 학생들의 키가 평균 170cm, 표준편차 5cm인 정규분포를 따를 때, 키 180cm인 학생의 표준화 값은 $Z = \frac{180-170}{5} = 2$이므로, 표준정규분포표에서 $P(Z \leq 2) \approx 0.9772$를 찾아 상위 약 2.28%임을 알 수 있습니다.
