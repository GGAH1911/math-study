# 확률밀도함수

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
연속확률변수의 확률을 계산하기 위해 도입된 함수로, 그래프 아래의 넓이가 곧 확률을 의미합니다.

## 본문
연속확률변수 $X$의 확률밀도함수(probability density function) $f(x)$는 모든 실수 $x$에 대하여 $f(x) \geq 0$이며, 전체 구간에 대한 적분 값이 $\displaystyle \int_{-\infty}^{\infty} f(x)\,dx = 1$을 만족하는 함수입니다. 임의의 실수 $a, b$ ($a \leq b$)에 대하여 확률은 $P(a \leq X \leq b) = \int_a^b f(x)\,dx$와 같이 적분을 통해 계산됩니다.

### 직관과 기하적 의미
이산확률변수와 달리 연속확률변수는 특정 한 점에서의 확률이 $0$입니다. 따라서 확률을 개별 값이 아닌 특정 구간에 속할 확률로 정의하며, 이때 확률밀도함수의 그래프 아래 면적이 곧 해당 구간의 확률이 됩니다. 전체 면적이 $1$이어야 한다는 점은 모든 사건의 확률의 합이 $1$이어야 한다는 원리를 나타냅니다. 주의할 점은 특정 지점에서의 함숫값 $f(x)$ 자체가 확률이 아니라, 그 지점에서의 확률 밀도를 의미한다는 것입니다.

### 기본 성질
- 모든 $x$에 대하여 함숫값은 $0$ 이상이어야 합니다.
- 전체 구간에 대한 함수의 적분 값은 반드시 $1$입니다.
- 특정 구간 $[a, b]$에서의 적분 값은 변수 $X$가 해당 구간에 포함될 확률과 같습니다.

## 학습 체크
- 확률밀도함수의 함숫값이 $1$보다 클 수 있는가?
- 특정 한 점에서의 확률이 $0$인 이유는 무엇인가?
- 확률밀도함수의 그래프 아래 전체 넓이가 왜 $1$이어야 하는가?

## 관련 개념
- **확률**: 연속확률변수에서는 특정 값이 아닌 구간에 대한 면적을 통해 확률을 정의합니다.
- **정규분포**: 확률밀도함수가 종 모양의 곡선 형태를 띠는 대표적인 연속확률분포의 예시입니다.
