# 이산확률변수

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
표본공간의 각 원소에 실수 값을 대응시키되, 그 값이 유한하거나 셀 수 있는 형태인 확률변수입니다.

## 본문
표본공간을 $\Omega$라 할 때, 함수 $X: \Omega \to \mathbb{R}$이 각 표본에 실수를 대응시키는 함수로서 그 함수값이 $x_1, x_2, x_3, \ldots$와 같이 유한개이거나 가산무한개로 명확히 구분될 때 이를 이산확률변수라 합니다. 이때 각 값 $x_i$에 대하여 $P(X=x_i) > 0$을 정의하는 함수를 확률질량함수라고 부릅니다.

### 직관과 기하적 의미
확률 실험의 결과인 주사위 눈, 동전의 앞뒤, 불량품 개수와 같은 추상적인 값들을 구체적인 숫자로 변환하여 수학적으로 분석할 수 있게 해주는 도구입니다. '이산'이라는 용어는 값들 사이에 간격이 존재함을 의미하며, 연속확률변수와 달리 특정 지점에서 정확한 확률값을 가질 수 있다는 특징이 있습니다.

### 기본 성질
이산확률변수에서 각 확률값의 총합은 반드시 1이 되어야 하며, 각 사건이 일어날 확률은 0 이상이어야 합니다.

## 학습 체크
- 확률변수가 가질 수 있는 값들이 왜 연속적이지 않고 떨어져 있는지 설명할 수 있는가?
- 확률질량함수에서 모든 확률의 합이 1이 됨을 확인할 수 있는가?

## 관련 개념
- **확률**: 이산확률변수가 특정한 값을 가질 가능성을 수치화하여 나타낸 것입니다.
