# 확률분포

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
확률변수가 가질 수 있는 각 값에 대응하는 확률을 나타낸 것입니다.

## 본문
확률분포(probability distribution)는 확률변수 $X$가 취할 수 있는 각 값에 대한 확률을 모두 나타낸 것입니다.

이산확률변수의 경우, 확률분포는 각 값 $x_1, x_2, \ldots, x_n$에 대해 확률 $P(X=x_1), P(X=x_2), \ldots, P(X=x_n)$을 정합니다. 이를 확률질량함수라 하며, 모든 확률의 합은 $\sum_{i=1}^{n} P(X=x_i) = 1$을 만족해야 합니다.

연속확률변수의 경우, 확률분포는 확률밀도함수 $f(x)$로 표현됩니다. 이때 특정 구간 $[a, b]$에 확률변수가 포함될 확률은 함수를 적분하여 $P(a \leq X \leq b) = \int_a^b f(x) \, dx$로 계산합니다.

### 직관과 기하적 의미
어떤 시행을 반복할 때 특정 결과가 나타나는 빈도를 정리한 것으로, "어떤 값이 얼마나 자주 일어날 것인가"를 보여줍니다. 이산확률변수는 확률분포표나 막대그래프로, 연속확률변수는 곡선으로 시각화됩니다. 이를 통해 데이터가 어디에 집중되어 있는지, 얼마나 퍼져 있는지, 극단적인 값이 나올 가능성은 얼마인지를 한눈에 파악하여 미래의 불확실한 상황을 예측할 수 있습니다.

### 기본 성질
- 이산확률변수의 모든 확률의 합은 항상 1입니다.
- 연속확률변수의 경우, 특정 한 점에서의 확률은 0이며 구간에 대한 적분값으로 확률을 정의합니다.
- 주사위를 던질 때처럼 모든 눈이 나올 확률이 $\frac{1}{6}$로 동일한 경우를 균등분포라고 합니다.

## 학습 체크
- 이산확률변수와 연속확률변수의 확률을 구하는 방식의 차이를 설명할 수 있는가?
- 주어진 확률함수가 확률분포의 조건을 만족하는지 확인할 수 있는가?
- 확률분포의 그래프 모양을 보고 데이터의 집중도와 퍼짐 정도를 해석할 수 있는가?

- **통계**: 확률분포는 수집된 데이터를 바탕으로 현상의 패턴을 파악하고 미래를 예측하는 통계적 추론의 기초가 됩니다.
