# 표준화

> **정의** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
평균이 $\mu$이고 표준편차가 $\sigma$인 확률변수 $X$를 평균이 0이고 표준편차가 1인 표준정규분포를 따르도록 변환하는 과정입니다.

## 본문
평균이 $\mu$, 표준편차가 $\sigma$인 확률변수 $X$에 대하여 $Z = \tfrac{X - \mu}{\sigma}$로 정의되는 값을 **표준화(standardization)** 또는 **표준점수(z-score)**라고 합니다.

### 직관과 기하적 의미
표준화는 데이터의 중심을 평균으로 이동시킨 후, 표준편차를 기준으로 데이터의 간격을 재조정하는 과정입니다. 이를 통해 산출된 $Z$값은 데이터가 평균으로부터 표준편차의 몇 배만큼 떨어져 있는지를 나타내는 상대적인 위치를 의미합니다.

### 기본 성질
확률변수 $X$가 정규분포 $N(\mu, \sigma^2)$를 따를 때, 표준화된 변수 $Z$는 항상 표준정규분포 $N(0, 1)$을 따릅니다. 이러한 성질 덕분에 서로 다른 평균과 표준편차를 가진 데이터들도 하나의 표준정규분포표를 이용하여 확률을 계산할 수 있으며, 서로 다른 척도를 가진 데이터들을 공정하게 비교할 수 있습니다. 예를 들어, 국어 성적이 평균 70점, 표준편차 12점일 때 82점을 받은 학생의 $Z$값은 $\tfrac{82-70}{12} = 1$이며, 이는 해당 학생의 성적이 평균보다 표준편차의 1배만큼 높다는 것을 의미합니다.

## 학습 체크
- $X$가 정규분포를 따를 때 $Z$가 표준정규분포를 따르기 위한 조건은 무엇인가요?
- 표준화된 값 $Z$가 0보다 크다면, 원래의 데이터 $X$는 평균보다 큰가요, 작은가요?
- 서로 다른 두 시험의 성적을 비교할 때 표준화가 필요한 이유는 무엇인가요?

## 관련 개념
- **확률**: 표준화된 $Z$값을 통해 특정 범위 내에 데이터가 존재할 확률을 표준정규분포표에서 구할 수 있습니다.
- **정규분포**: 표준화의 대상이 되는 기초 분포로, 데이터가 평균을 중심으로 대칭인 종 모양을 이룹니다.
- **표준정규분포**: 평균이 0이고 표준편차가 1인 특수한 형태의 정규분포로, 모든 정규분포의 확률 계산 기준이 됩니다.
