# 경우의 분류

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 정확한 진술

경우의 분류란, 어떤 사건이나 상황의 모든 가능한 경우들을 **서로 겹치지 않고(배반), 빠지지 않도록(완전)** 여러 그룹으로 나누는 것입니다. 각 그룹에 속하는 경우의 수를 구한 뒤, 전체 경우의 수는 각 그룹의 경우의 수를 더합니다. 이를 **합의 법칙**(덧셈 원리)이라 합니다.

수식으로, 사건 $A$를 $n$개의 배반 사건 $A_1, A_2, \ldots, A_n$으로 분할하면:
$$|A| = |A_1| + |A_2| + \cdots + |A_n|$$

## 직관과 필요성

복잡한 경우의 수 문제를 한 번에 풀기는 어렵습니다. 대신 **조건에 따라 자연스럽게 나뉘는 경우들**로 나누어 각각 세면, 계산이 간단해집니다. 핵심은 "어떻게 나눌 것인가"입니다. 잘 나눈 분류는 겹치는 경우가 없고 빠진 경우도 없어야 하므로, 분류할 때 조건을 명확히 정해야 합니다.

예를 들어 "주사위 두 개를 던져 눈의 합이 6 이상"인 경우를 셀 때, "합이 6인 경우", "합이 7인 경우", …, "합이 12인 경우"로 나누면 각 그룹이 겹치지 않고 모두 포함됩니다.

## 한 줄 예

주사위 한 개를 던질 때 "짝수가 나오거나 3의 배수가 나오는" 경우: 짝수 {2, 4, 6}은 3개, 3의 배수는 {3, 6}이므로 겹치는 6을 피하려면 "2, 4" (2개) + "3" (1개) + "6" (1개) = 4개로 분류하여 답은 4입니다.

(`sympy.Union(set([2,4,6]), set([3,6]))`로 확인하면 크기는 4)
