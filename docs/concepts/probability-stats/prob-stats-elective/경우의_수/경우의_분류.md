# 경우의 분류

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
사건을 서로 겹치지 않고 빠짐없이 여러 그룹으로 나누어 각각의 경우의 수를 더하는 과정입니다.

## 본문
경우의 분류란 어떤 사건이나 상황에서 발생할 수 있는 모든 가능한 경우들을 서로 겹치지 않게(배반) 하고, 빠진 부분이 없도록(완전) 여러 그룹으로 나누는 것을 의미합니다. 이렇게 분류된 각 그룹의 경우의 수를 모두 더하면 전체 사건의 경우의 수를 구할 수 있는데, 이를 합의 법칙 또는 덧셈 원리라고 합니다. 수식으로는 사건 $A$를 $n$개의 서로 겹치지 않는 사건 $A_1, A_2, \ldots, A_n$으로 분할했을 때, $|A| = |A_1| + |A_2| + \cdots + |A_n|$으로 나타냅니다.

복잡한 경우의 수 문제를 해결할 때 한 번에 모든 경우를 세는 것은 매우 어렵습니다. 따라서 조건에 따라 자연스럽게 나뉘는 상황들로 나누어 각각 계산하면 훨씬 간단하게 문제를 풀 수 있습니다. 이때 가장 중요한 핵심은 "어떻게 분류할 것인가"이며, 분류할 때 설정한 조건이 중복을 만들거나 일부 경우를 누락시키지 않도록 명확해야 합니다. 예를 들어 주사위 두 개를 던져 눈의 합이 6 이상인 경우를 구할 때, 합이 6인 경우부터 12인 경우까지로 나누면 각 그룹이 서로 겹치지 않으면서도 모든 경우를 포함하게 되어 효율적인 계산이 가능합니다.

### 직관과 기하적 의미
전체 집합을 부분 집합들로 쪼개는 과정으로 이해할 수 있습니다. 마치 하나의 큰 도형을 겹치지 않는 작은 조각들로 나누어 전체 넓이를 구하는 것과 같습니다.

### 기본 성질
분류된 각 그룹은 서로 배반 사건이어야 하며, 모든 그룹의 합집합은 전체 사건과 같아야 합니다.

## 학습 체크
- 분류를 할 때 특정 경우가 두 개 이상의 그룹에 동시에 포함되지는 않는가?
- 설정한 조건에 따라 모든 가능한 경우가 빠짐없이 포함되었는가?
- 합의 법칙을 적용하기 전, 각 그룹의 경우의 수를 독립적으로 정확히 구하였는가?

## 관련 개념
- **경우의 수**: 사건이 일어날 수 있는 모든 가짓수를 구하는 것으로, 분류를 통해 계산을 단순화할 수 있습니다.
