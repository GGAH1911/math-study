# 원탁 순열

## 정확한 진술

$n$명이 원탁에 앉는 경우의 수는 **원탁 순열**이라 하며, $(n-1)!$로 계산합니다.

일반적인 순열 $n!$에서는 1번 자리, 2번 자리, ... 처럼 구별되는 위치가 있지만, 원탁은 회전 대칭이므로 같은 배치의 $n$가지 회전을 모두 동일한 것으로 봅니다. 따라서 $n!$을 $n$으로 나누면:

$$\text{원탁 순열} = \frac{n!}{n} = (n-1)!$$

## 직관/기하적 의미

원탁에 앉힐 때, 먼저 임의로 한 사람(예: A)을 고정하세요. A의 위치를 기준점으로 삼으면, 나머지 $(n-1)$명을 A의 양옆부터 배열하는 경우의 수만 세면 됩니다. 이렇게 하면 회전을 자동으로 제거할 수 있어, 결과가 $(n-1)!$이 되는 것입니다.

반대로 생각하면: 일렬 순열은 $n!$가지인데, 원탁을 시계방향으로 회전하면 $n$가지 다른 배열이 모두 같은 상태가 됩니다. 따라서 중복을 $n$으로 나누는 것입니다.

## 한 줄 예

4명(A, B, C, D)이 원탁에 앉는 경우: $(4-1)! = 3! = 6$가지  
(A를 고정하면, 나머지 B, C, D를 배열하는 $3! = 6$가지)
