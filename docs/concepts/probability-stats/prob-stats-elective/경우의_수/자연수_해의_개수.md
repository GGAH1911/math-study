# 자연수 해의 개수

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
$x_1 + x_2 + \cdots + x_n = k$ 형태의 선형방정식에서 모든 변수가 1 이상의 자연수인 해의 개수를 구하는 문제입니다.

## 본문
$x_1 + x_2 + \cdots + x_n = k$ 형태의 선형방정식에서, 모든 변수가 자연수(양의 정수)인 해의 개수를 구하는 것입니다. 여기서 $k$는 양의 정수, $n$은 변수의 개수입니다.

### 직관과 기하적 의미
이 문제는 $k$개의 동일한 공을 $n$명에게 나누어 주되, 각 사람이 최소 1개 이상의 공을 받아야 하는 상황과 같습니다. 즉, $k$개의 물건을 $n$개의 구역으로 나누어 담는 과정에서 각 구역에 최소 1개씩의 물건이 포함되도록 배치하는 것과 본질적으로 같습니다.

### 기본 성질
자연수 해의 개수를 구하기 위해서는 변수 치환을 통해 음이 아닌 정수 해의 문제로 변환해야 합니다. 각 변수 $x_i$에 대하여 $y_i = x_i - 1$로 치환하면, 모든 $y_i$는 0 이상의 정수가 되며 방정식은 $y_1 + y_2 + \cdots + y_n = k - n$이 됩니다. 따라서 구하고자 하는 해의 개수는 중복조합을 이용하여 $\binom{(k-n)+n-1}{n-1} = \binom{k-1}{n-1}$로 계산할 수 있습니다.

예를 들어 $x + y + z = 5$의 자연수 해의 개수는 $k=5, n=3$이므로 $\binom{5-1}{3-1} = \binom{4}{2} = 6$이며, 실제 해는 $(1,1,3), (1,2,2), (1,3,1), (2,1,2), (2,2,1), (3,1,1)$입니다.

## 학습 체크
- 문제에서 요구하는 해가 '자연수(1 이상)'인지 '음이 아닌 정수(0 이상)'인지 반드시 구분해야 합니다.
- 변수 치환을 통해 $k$를 $k-n$으로 변환하여 중복조합 공식을 적용하는 과정을 이해해야 합니다.

## 관련 개념
- **경우의 수**: 이 개념은 특정 조건을 만족하는 사건이 발생하는 가짓수를 구하는 경우의 수의 대표적인 유형 중 하나입니다.
- **중복조합**: 자연수 해의 문제를 음이 아닌 정수 해의 문제로 변환하여 해결하는 핵심 도구입니다.
