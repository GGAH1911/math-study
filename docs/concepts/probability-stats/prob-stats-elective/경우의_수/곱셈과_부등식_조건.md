# 곱셈과 부등식 조건

## 정확한 진술

두 실수 $a$, $b$에 대하여 **곱 $ab$의 부호**는 $a$와 $b$의 부호에 따라 다음과 같이 결정됩니다:

- $ab > 0$ ⟺ $(a > 0 \text{ and } b > 0)$ 또는 $(a < 0 \text{ and } b < 0)$
- $ab < 0$ ⟺ $(a > 0 \text{ and } b < 0)$ 또는 $(a < 0 \text{ and } b > 0)$
- $ab = 0$ ⟺ $a = 0$ 또는 $b = 0$

즉, **곱이 양수가 되려면 두 수의 부호가 같아야 하고**, **곱이 음수가 되려면 부호가 달라야** 합니다. 경우의 수로는 음수, 양수, 0의 각 부호 조합이 정확히 3가지 결과를 만듭니다.

## 직관/기하적 의미

"양수는 오른쪽, 음수는 왼쪽"으로 생각할 때:

- **양수 × 양수**: 양의 방향과 양의 방향 → 결과는 양수
- **음수 × 음수**: 음의 방향이 두 번 뒤집혀 → 결과는 양수
- **양수 × 음수** (또는 음수 × 양수): 한쪽만 음수 → 결과는 음수

부등식에서도 이 원리가 적용됩니다. **양수를 곱하면 부등호 방향이 유지**되지만, **음수를 곱하면 부등호가 뒤집힙니다.** 예를 들어 $x < 3$에 $-2$를 곱하면 $-2x > -6$이 되는 이유입니다.

## 한 줄 예

$(-3) \times 5 = -15 < 0$ (부호가 다름), $(-2) \times (-7) = 14 > 0$ (부호가 같음), $(x-1)(x+2) < 0$ 풀이: 부호가 다를 조건 $-2 < x < 1$.
