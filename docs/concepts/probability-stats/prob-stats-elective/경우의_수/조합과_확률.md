# 조합과 확률

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수_(확통))

## 요약
$n$개의 서로 다른 원소 중 순서를 고려하지 않고 $r$개를 선택하는 경우의 수입니다.

## 본문
$n$개의 서로 다른 원소 중에서 순서를 고려하지 않고 $r$개를 선택하는 경우의 수를 **조합(combination)**이라 하며, 다음과 같이 정의합니다.
$$\binom{n}{r} = {}_nC_r = \frac{n!}{r!(n-r)!}$$
이때 $0 \le r \le n$이며, $\binom{n}{0} = \binom{n}{n} = 1$입니다.

### 직관과 기하적 의미
조합과 순열의 가장 큰 차이는 **순서**의 유무입니다. 순열 ${}_nP_r$은 선택된 원소들의 배열 순서까지 구별하지만, 조합은 순서를 무시합니다. 예를 들어 {A, B}와 {B, A}는 순열에서는 서로 다른 경우로 취급되지만, 조합에서는 동일한 하나의 경우로 간주합니다.

직관적으로 이해하자면, $n$개 중 $r$개를 선택하여 나열하는 모든 순열은, 선택된 $r$개의 원소를 재배열하는 $r!$가지의 경우마다 중복되어 나타납니다. 따라서 순열의 수를 $r!$로 나누어줌으로써 순서의 영향을 제거한 것이 조합의 원리입니다.
$$\binom{n}{r} = \frac{{}_nP_r}{r!} = \frac{n!}{r!(n-r)!}$$
조합은 팀 구성, 부분집합 선택, 상품 조합처럼 선택의 순서가 결과에 영향을 주지 않는 상황에서 유용하게 사용됩니다.

### 기본 성질
- 5명 중 2명을 선택하는 경우의 수: $\binom{5}{2} = \tfrac{5!}{2!3!} = 10$
- 파이썬 계산 결과: `math.comb(5, 2)` $\rightarrow$ 10

## 학습 체크
- 순열과 조합을 구분할 때 '순서가 의미가 있는가'를 어떻게 판단할 것인가?
- $\binom{n}{r} = \binom{n}{n-r}$ 성질이 성립하는 이유를 조합의 의미로 설명할 수 있는가?

## 관련 개념
- **확률**: 전체 경우의 수와 특정 사건의 경우의 수를 계산할 때, 순서를 고려하지 않는 조합을 사용하여 확률을 구하는 경우가 많습니다.
