# 조합과 확률

## 정확한 진술

$n$개의 서로 다른 원소 중에서 순서를 고려하지 않고 $r$개를 선택하는 경우의 수를 **조합(combination)**이라 하며, 다음과 같이 정의합니다.

$$\binom{n}{r} = {}_nC_r = \frac{n!}{r!(n-r)!}$$

여기서 $0 \le r \le n$이고, $\binom{n}{0} = \binom{n}{n} = 1$입니다.

## 직관 및 기하적 의미

조합과 순열의 가장 큰 차이는 **순서**입니다. 순열 ${}_nP_r = \frac{n!}{(n-r)!}$은 순서를 구별하지만, 조합은 순서를 무시합니다.

예를 들어 {A, B}와 {B, A}는 순열에서는 다른 경우이지만, 조합에서는 같은 것입니다.

직관적으로, $n$개 중 $r$개를 선택할 때 가능한 모든 순열은 같은 $r$개 원소의 조합에서 $r!$번씩 반복됩니다(같은 원소들의 배열 순서가 $r!$가지). 따라서:

$$\binom{n}{r} = \frac{{}_nP_r}{r!} = \frac{n!}{r!(n-r)!}$$

조합은 "팀 구성", "부분집합 선택", "상품 조합" 처럼 선택의 순서가 의미 없는 상황에서 자연스럽게 나타납니다. 확률에서 "같은 확률을 갖는 여러 경우" 중 원하는 경우를 세울 때도 자주 사용됩니다.

## 한 줄 예

5명 중 2명을 선택하는 경우의 수는 $\binom{5}{2} = \frac{5!}{2!3!} = \frac{5 \times 4}{2 \times 1} = 10$입니다.

`math.comb(5, 2)` → 10
