# 다항계수

## 정확한 진술

$n$개의 서로 다른 원소를 크기가 각각 $n_1, n_2, \ldots, n_k$인 $k$개의 구별되는 그룹으로 나누는 경우의 수를 **다항계수**(multinomial coefficient)라고 하며, 다음과 같이 표현합니다.

$$\binom{n}{n_1, n_2, \ldots, n_k} = \frac{n!}{n_1! \, n_2! \cdots n_k!}$$

여기서 $n_1 + n_2 + \cdots + n_k = n$입니다.

## 직관과 의미

다항계수는 이항계수 $\binom{n}{r}$의 일반화입니다. $n$명을 일렬로 배치하는 경우의 수는 $n!$이지만, 각 그룹 내에서의 순서는 구별하지 않으므로 각 그룹의 크기 팩토리얼로 나누어줍니다.

예를 들어, 10명을 빨강(3명), 파랑(4명), 초록(3명) 세 팀으로 나누는 상황을 생각해봅시다. 먼저 10명을 일렬로 배치하면 $10!$가지이지만, 빨강끼리, 파랑끼리, 초록끼리의 순서는 상관없으므로 각각 $3!$, $4!$, $3!$으로 나눕니다. 이것이 바로 $\frac{10!}{3! \cdot 4! \cdot 3!}$입니다.

이항계수 $\binom{n}{r} = \frac{n!}{r!(n-r)!}$는 $k=2$인 특수한 경우입니다.

## 구체적인 예

12명을 A조(4명), B조(5명), C조(3명)로 나누는 경우의 수:

$$\binom{12}{4,5,3} = \frac{12!}{4! \cdot 5! \cdot 3!} = \frac{479001600}{24 \cdot 120 \cdot 6} = 27720$$

검증: `sympy.factorial(12) // (sympy.factorial(4) * sympy.factorial(5) * sympy.factorial(3))` → `27720`
