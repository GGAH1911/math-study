# 다항계수

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
$n$개의 서로 다른 원소를 크기가 정해진 $k$개의 그룹으로 나누는 경우의 수를 나타내는 수치입니다.

## 본문
$n$개의 서로 다른 원소를 크기가 각각 $n_1, n_2, \ldots, n_k$인 $k$개의 구별되는 그룹으로 나누는 경우의 수를 다항계수라고 하며, 다음과 같이 표현합니다.
$$\binom{n}{n_1, n_2, \ldots, n_k} = \frac{n!}{n_1! \, n_2! \cdots n_k!}$$
이때 각 그룹의 크기의 합은 전체 원소의 개수와 같아야 합니다($n_1 + n_2 + \cdots + n_k = n$).

### 직관과 기하적 의미
다항계수는 이항계수 $\binom{n}{r}$의 일반화된 형태입니다. $n$명을 일렬로 배치하는 전체 경우의 수인 $n!$에서, 각 그룹 내의 원소들은 순서가 구별되지 않으므로 각 그룹의 크기에 해당하는 팩토리얼 값들로 나누어 중복을 제거하는 원리입니다. 예를 들어, 10명을 빨강(3명), 파랑(4명), 초록(3명) 세 팀으로 나눈다면, 전체 배치 $10!$을 각 팀의 내부 순서인 $3!$, $4!$, $3!$로 나누어 $\frac{10!}{3! \cdot 4! \cdot 3!}$로 계산합니다. 만약 그룹이 두 개($k=2$)라면 이항계수 공식 $\frac{n!}{r!(n-r)!}$과 동일해집니다.

### 기본 성질
12명을 A조(4명), B조(5명), C조(3명)로 나누는 경우의 수는 다음과 같이 계산됩니다.
$$\binom{12}{4,5,3} = \frac{12!}{4! \cdot 5! \cdot 3!} = 27720$$

## 학습 체크
- $n_1 + n_2 + \cdots + n_k$의 합이 전체 원소의 개수 $n$과 일치하는지 확인했는가?
- 각 그룹의 크기가 1보다 큰 경우, 분모의 팩토리얼 계산이 정확하게 이루어졌는가?

## 관련 개념
- **경우의 수**: 다항계수는 서로 다른 대상들을 특정 조건에 따라 여러 그룹으로 분할하는 경우의 수를 구하는 핵심적인 도구입니다.
