# 구분안되는 공 나누기

> **예제** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
서로 다른 $n$개의 상자에 같은 종류의 $r$개 물건을 나누어 담는 경우의 수는 중복조합 $H(n, r)$을 이용하여 구합니다.

## 본문
같은 종류의 사탕 8개를 3개의 서로 다른 상자 A, B, C에 나누어 넣을 때, 각 상자에 최소 0개 이상 들어가는 모든 경우의 수를 구하시오.

중복조합은 서로 다른 $n$개 중에서 중복을 허용하여 $r$개를 선택하는 것을 의미하며, 이는 같은 종류의 물건을 서로 다른 상자에 배분하는 상황과 논리적으로 동일합니다. 위 문제에서 사탕이 모두 같으므로 어떤 사탕이 어느 상자에 들어가는지는 중요하지 않으며, 각 상자에 들어가는 개수의 합이 8이 되는 음이 아닌 정수해의 개수를 찾는 것이 핵심입니다. 즉, $a + b + c = 8$을 만족하는 해의 개수를 구하는 문제입니다.

### 단계별 풀이
**1단계: 문제의 본질 파악**
사탕이 모두 같으므로 각 상자에 몇 개씩 들어가는지가 중요합니다. 이는 $a + b + c = 8$을 만족하는 음이 아닌 정수해를 찾는 과정과 같습니다.

**2단계: 중복조합 공식 적용**
서로 다른 $n=3$개의 상자에서 중복을 허용하여 $r=8$개의 사탕을 선택하는 것이므로 중복조합 공식을 적용합니다.
$$H(3, 8) = C(3+8-1, 8) = C(10, 8) = C(10, 2)$$

**3단계: 계산하기**
$$C(10, 2) = \frac{10 \times 9}{2 \times 1} = 45$$
공식의 논리는 $r$개의 물건과 $n-1$개의 칸막이를 일렬로 배열하는 것과 같습니다. 총 $r+n-1$개의 자리 중 칸막이가 들어갈 $n-1$자리를 선택하는 $C(r+n-1, n-1)$과 같습니다.

### 답과 변형
**답: 45가지**

**변형: 각 상자에 최소 1개씩 들어가야 하는 경우**
먼저 각 상자에 사탕을 1개씩 미리 배분하면 총 3개의 사탕이 소모됩니다. 남은 5개의 사탕을 3개의 상자에 자유롭게 배분하면 되므로 $H(3, 5) = C(3+5-1, 5) = C(7, 5) = C(7, 2) = 21$입니다.

**주의사항**
"구분 안 되는 공"과 "구분되는 상자"를 반드시 구분해야 합니다. 만약 상자까지 구분되지 않는다면 중복조합이 아닌 분할의 개념을 적용해야 합니다. 또한 중복조합은 반드시 선택하는 대상이 같은 종류여야 합니다.

## 학습 체크
- 상자가 서로 다른지, 물건이 같은지 구분할 수 있는가?
- '최소 1개씩' 조건이 있을 때 미리 배분하는 전략을 사용할 수 있는가?
- 중복조합 공식을 칸막이 모델로 설명할 수 있는가?

## 관련 개념
- **경우의 수**: 중복조합은 전체 경우의 수를 구하는 방법 중 하나로, 선택의 조건에 따라 적용 여부가 결정됩니다.
