# 원형순열

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
$n$개의 서로 다른 원소를 원형으로 배열할 때, 회전하여 같은 모양이 되는 것을 하나로 간주하여 계산하는 배열의 방식입니다.

## 본문
$n$개의 서로 다른 원소를 원형으로 배열할 때, 회전을 같은 것으로 간주하는 배열의 개수를 원형순열이라 하며, 그 개수는 $(n-1)!$입니다.

### 직관과 기하적 의미
일렬로 배열할 때는 맨 앞과 맨 뒤라는 명확한 시작점이 존재하지만, 원형 배열에서는 회전할 경우 시작점의 개념이 사라집니다. 예를 들어 원탁에 A, B, C, D 네 사람이 앉을 때, 시계방향으로 A-B-C-D 순서로 앉는 것과 B-C-D-A 순서로 앉는 것은 원탁을 회전시키면 완전히 겹치게 되므로 같은 배치로 취급합니다. 즉, 원형 배열에서는 원소들 사이의 상대적인 위치 관계가 중요하며, 회전했을 때 나타나는 중복된 경우를 제외해야 합니다.

### 기본 성질
$n$개의 원소를 일렬로 나열하는 경우의 수는 $n!$입니다. 하지만 원형 배열에서는 각 배열마다 회전했을 때 나타나는 서로 다른 $n$가지의 경우가 모두 같은 배치로 간주됩니다. 따라서 전체 순열의 수에서 중복되는 회전 횟수인 $n$으로 나누어 주면 원형순열의 수를 구할 수 있습니다. 이를 수식으로 나타내면 $\tfrac{n!}{n} = (n-1)!$이 됩니다. 이 개념은 원탁에 사람을 앉히는 문제나 목걸이의 디자인 배치 등 회전 대칭이 발생하는 상황을 해결할 때 필수적으로 사용됩니다.

## 학습 체크
- $n$개의 원소를 원형으로 배열할 때, 왜 $n$으로 나누어 중복을 제거해야 하는가?
- 일렬로 배열하는 순열과 원형순열의 결정적인 차이점은 무엇인가?

## 관련 개념
- **경우의 수**: 원형순열은 전체 경우의 수 중에서 회전이라는 조건에 의해 중복되는 경우를 제외하여 계산하는 특수한 경우의 수의 일종입니다.
