# 중복조합

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
$n$개의 서로 다른 원소 중에서 중복을 허용하여 $r$개를 택하는 경우의 수로, $_{n+r-1}C_r$로 계산합니다.

## 본문
$n$개의 서로 다른 원소 중에서 **중복을 허용**하여 $r$개를 택하는 경우의 수를 **중복조합**이라고 하며, $\text{H}(n,r)$ 또는 $_nH_r$로 나타냅니다. 이는 조합 $\binom{n}{r}$과 달리 순서는 고려하지 않되, 같은 원소를 여러 번 선택할 수 있다는 점이 핵심입니다. 계산 공식은 다음과 같습니다.
$$\text{H}(n,r) = _{n+r-1}C_r = \frac{(n+r-1)!}{r!(n-1)!}$$

### 직관과 기하적 의미
중복조합은 같은 종류의 과자를 구별 없이 담거나, 여러 종류의 빵 중 정해진 개수를 사는 상황처럼 일상에서 자주 나타납니다. 또한 같은 구슬을 여러 개의 상자에 나누어 넣는 문제로도 해석할 수 있습니다.

수학적으로는 각 원소를 0번 이상 선택할 수 있다는 점을 이용하여, 다음과 같은 **음이 아닌 정수해 찾기** 문제로 변환하여 풀 수 있습니다.
$$x_1 + x_2 + \cdots + x_n = r \quad (x_i \geq 0)$$
이 방정식의 해의 개수는 중복조합의 공식인 $_{n+r-1}C_r$과 정확히 일치합니다.

예를 들어, 사과, 배, 포도 3가지 과일 중 중복을 허용하여 2개를 고르는 경우의 수는 $\text{H}(3,2) = _4C_2 = 6$이며, 실제 경우는 (사,사), (사,배), (사,포), (배,배), (배,포), (포,포)입니다.

### 기본 성질
- $\text{H}(n,r) = \text{H}(n+r-1, r)$의 관계를 가집니다.
- $\text{H}(n,r) = \text{H}(n+r-1, n-1)$의 관계를 가집니다.

## 학습 체크
- 중복을 허용하여 선택하는 상황을 보고 중복조합 공식으로 식을 세울 수 있는가?
- 방정식의 음이 아닌 정수해 개수를 구하는 문제를 중복조합으로 변환할 수 있는가?
- 조합($C$)과 중복조합($H$)의 차이점을 명확히 구분하여 적용할 수 있는가?

## 관련 개념
- **경우의 수**: 중복조합은 전체 경우의 수를 구하는 여러 방법 중 하나로, 선택의 조건에 따라 조합이나 순열과 구분하여 사용합니다.
