# 같은 것이 있을 때의 순열

## 정확한 진술

$n$개의 원소 중에서 같은 것이 각각 $n_1$개, $n_2$개, ..., $n_k$개씩 있을 때, 이 $n$개를 모두 사용하여 배열하는 경우의 수는 다음과 같습니다.

$$\frac{n!}{n_1! \cdot n_2! \cdot \ldots \cdot n_k!}$$

여기서 $n_1 + n_2 + \cdots + n_k = n$입니다.

## 직관과 유도

같은 원소가 없다면, $n$개를 배열하는 경우의 수는 $n!$입니다. 하지만 일부 원소가 같으면 어떻게 될까요?

예를 들어 **A, A, B** 세 글자를 배열한다고 생각해봅시다. 만약 두 A를 구별하여 $A_1, A_2, B$로 본다면 $3! = 6$가지입니다. 그런데 같은 A 두 개는 구별되지 않으므로, $A_1 A_2 B$와 $A_2 A_1 B$는 모두 "AAB"로 같은 배열입니다. 즉, 같은 2개(A의 개수)의 순열인 $2!$로 나누어야 하므로:

$$\text{경우의 수} = \frac{3!}{2!} = \frac{6}{2} = 3$$

실제로 AAB, ABA, BAA 세 가지입니다. 일반적으로 같은 원소들의 중복을 제거하기 위해 각 같은 원소의 개수의 팩토리얼로 나누어줍니다.

## 한 줄 예

**AABBC 다섯 글자를 배열하는 경우의 수**는 $\dfrac{5!}{2! \cdot 2! \cdot 1!} = \dfrac{120}{4} = 30$가지입니다.

(검증: `from math import factorial; factorial(5) // (factorial(2) * factorial(2) * factorial(1))` → 30)
