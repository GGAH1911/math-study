# 순열과 조합

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
순열은 서로 다른 $n$개 중 $r$개를 선택하여 순서를 고려해 나열하는 것이며, 조합은 순서에 상관없이 $r$개를 선택하는 것입니다.

## 본문
$n$개의 서로 다른 원소 중에서 $r$개를 선택하여 **순서를 정하여 나열한 경우의 수**를 순열이라 하며, 기호로 $_nP_r$ 또는 $P(n, r)$로 나타냅니다. 식으로는 $_nP_r = \frac{n!}{(n-r)!} = n(n-1)(n-2) \cdots (n-r+1)$로 계산하며, $n$개를 모두 나열하는 경우 $_nP_n = n!$이 됩니다. 반면 $n$개의 서로 다른 원소 중에서 $r$개를 선택하는 경우의 수를 조합이라 하며, 기호로 $_nC_r$ 또는 $\binom{n}{r}$로 나타냅니다. 조합은 **선택만 하고 순서는 구분하지 않는 것**이 특징이며, 식으로는 $_nC_r = \frac{n!}{r!(n-r)!} = \frac{_nP_r}{r!}$로 나타냅니다.

### 직관과 기하적 의미
순열은 "배열"의 관점에서 접근하여 대상의 위치가 바뀌면 다른 경우로 간주합니다. 예를 들어 A, B, C 세 명 중 2명을 뽑을 때, AB와 BA를 다르게 보는 것이 순열입니다. 반면 조합은 "선택"의 관점에서 접근하여 대상의 순서와 상관없이 구성원이 같으면 같은 경우로 간주합니다. 즉, AB와 BA를 같은 것으로 보는 것이 조합입니다.

### 기본 성질
순열과 조합 사이에는 명확한 관계가 존재합니다. 같은 $r$개를 선택했을 때, 선택된 $r$개를 배열하는 방법의 수가 $r!$가지이므로, $_nP_r = {_nC_r} \times r!$이라는 관계식이 성립합니다. 이를 통해 순열의 값을 조합의 값에 $r!$을 곱하여 구할 수도 있습니다.

## 학습 체크
- 순열에서 $r$개의 원소를 나열할 때 순서가 바뀌면 결과값이 어떻게 변하는가?
- 조합에서 $_nC_r$과 $_nC_{n-r}$의 값이 왜 같은지 원리를 설명할 수 있는가?
- 5명 중 3명을 일렬로 세우는 경우와 3명을 뽑기만 하는 경우의 차이를 수식으로 나타낼 수 있는가?

## 관련 개념
- **경우의 수**: 순열과 조합은 특정한 조건에 맞는 사건이 일어나는 가짓수를 구하는 경우의 수의 핵심적인 방법론입니다.
