# 순열과 조합

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 순열의 정의

$n$개의 서로 다른 원소 중에서 $r$개를 선택하여 **순서를 정하여 나열한 경우의 수**를 순열이라 하며, 기호로 $_nP_r$ 또는 $P(n, r)$로 나타냅니다.

$$_nP_r = \frac{n!}{(n-r)!} = n(n-1)(n-2) \cdots (n-r+1)$$

특히 $n$개를 모두 나열하는 경우 $_nP_n = n!$입니다.

## 조합의 정의

$n$개의 서로 다른 원소 중에서 $r$개를 선택하는 경우의 수를 조합이라 하며, 기호로 $_nC_r$ 또는 $\binom{n}{r}$로 나타냅니다. 조합은 **선택만 하고 순서는 구분하지 않습니다**.

$$_nC_r = \frac{n!}{r!(n-r)!} = \frac{_nP_r}{r!}$$

## 직관적 의미

**순열은 "배열"**, 조합은 "선택"입니다. 예를 들어 A, B, C 세 명 중 2명을 뽑을 때, 순열은 "누구를 먼저, 둘째에 배치할 것인가"(AB와 BA는 다름), 조합은 "누구 둘을 선택할 것인가"(AB와 BA는 같음)를 묻습니다. 

순열과 조합의 관계는 명확합니다: 같은 $r$개를 선택했을 때, 그것을 배열하는 방법이 $r!$가지이므로, $_nP_r = {_nC_r} \times r!$ 입니다.

## 한 줄 예

5명 중 3명을 일렬로 세우는 순열: $_5P_3 = 5 \times 4 \times 3 = 60$ / 5명 중 3명을 선택하는 조합: $_5C_3 = \frac{60}{3!} = 10$

`sympy.factorial(5)//sympy.factorial(2) - sympy.factorial(5)//(sympy.factorial(3)*sympy.factorial(2))`로 검산하면 순열 60, 조합 10을 확인할 수 있습니다.
