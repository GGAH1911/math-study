# 중복조합과 배열

같은 대상을 여러 번 뽑을 수 있는 조합과, 같은 것이 포함된 일렬 배열의 경우의 수를 다룹니다. 확률과 통계 경우의 수 단원의 응용 핵심입니다.

## 정의

- **중복조합:** 서로 다른 $n$가지에서 중복을 허락하여 $r$개를 뽑는 방법의 수는
$$_n\mathrm{H}_r = {}_{n + r - 1}\mathrm{C}_r = \binom{n + r - 1}{r}.$$
- **같은 것이 있는 순열:** 전체 $n$개 중 같은 것이 각각 $p, q, r, \ldots$개씩 있을 때 일렬 배열의 수는
$$\frac{n!}{p!\, q!\, r! \cdots} \quad (p + q + r + \cdots = n).$$

중복조합은 방정식 $x_1 + x_2 + \cdots + x_n = r$의 음이 아닌 정수해의 개수를 세는 문제와 동치입니다.

## 예시

세 가지 종류의 사탕에서 중복을 허락해 $5$개를 고르는 방법의 수는
$$_3\mathrm{H}_5 = \binom{7}{5} = 21.$$

또한 문자 $A, A, A, B, B$를 일렬로 배열하는 방법의 수는
$$\frac{5!}{3!\, 2!} = 10.$$
