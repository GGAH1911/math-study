# 비감소 수열

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
모든 인접한 두 항에 대해 앞항이 뒷항보다 작거나 같은 수열을 의미합니다.

## 본문
수열 $a_1, a_2, \ldots, a_n$이 **비감소 수열**이라는 것은 모든 인접한 두 항에 대해 앞항이 뒷항보다 작거나 같은 수열을 의미합니다. 즉, 다음을 만족합니다:
$$a_1 \le a_2 \le a_3 \le \cdots \le a_n$$
비감소 수열의 각 항은 이전 항과 같을 수도 있고 더 커질 수도 있지만, 값이 작아지는 구간은 절대 존재하지 않습니다.

### 직관과 기하적 의미
비감소 수열은 마치 계단을 올라가는 과정과 같습니다. 각 계단의 높이가 이전 계단보다 높거나 같아서, 전체적인 흐름이 아래로 내려가지 않고 유지되거나 위로 올라가는 형태를 띱니다. 현실 세계의 데이터 중 일일 누적 판매액, 누적 강수량, 혹은 시간에 따른 사람의 키 변화와 같이 값이 줄어들지 않고 유지되거나 증가하는 현상을 설명할 때 유용하게 사용됩니다.

### 기본 성질
수열의 항들이 모두 같아도 비감소 수열의 조건을 만족하며, 항의 값이 커지는 구간이 포함되어도 상관없습니다. 예를 들어 $2, 2, 5, 7, 7, 7, 9$는 모든 인접 항이 $a_i \le a_{i+1}$을 만족하므로 비감소 수열입니다. 반면 $3, 5, 4, 6$처럼 중간에 값이 작아지는 구간이 있다면 비감소 수열이 아닙니다.

## 학습 체크
- 수열의 항이 이전 항과 동일한 경우에도 비감소 수열로 분류되는가?
- 주어진 수열에서 인접한 두 항을 비교했을 때, 단 하나의 항이라도 앞항이 뒷항보다 크다면 비감소 수열인가?

## 관련 개념
- **경우의 수**: 중복을 허용하여 작은 것부터 큰 것 순서로 선택하는 경우의 수를 구할 때, 선택한 숫자들을 크기순으로 나열한 비감소 수열의 개수를 구하는 문제로 변환하여 해결할 수 있습니다. 이는 중복조합 $\binom{n+r-1}{r}$의 원리와 직결됩니다.
