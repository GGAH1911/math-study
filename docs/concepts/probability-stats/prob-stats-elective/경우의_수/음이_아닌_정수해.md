# 음이 아닌 정수해

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 정확한 진술

$x_1 + x_2 + \cdots + x_n = k$를 만족하는 **정수 $x_i$가 모두 0 이상**인 경우를 음이 아닌 정수해라고 합니다. 즉, $x_i \geq 0$ (단, $i = 1, 2, \ldots, n$)을 동시에 만족하면서 합이 정확히 $k$가 되는 모든 $(x_1, x_2, \ldots, x_n)$의 순서쌍입니다.

## 직관적 의미

**"$k$개의 동일한 공을 $n$개의 서로 다른 상자에 나누어 담는 방법의 개수"**로 이해할 수 있습니다. 각 상자는 0개 이상의 공을 담을 수 있으며, 모든 공을 반드시 사용해야 합니다. 이 문제는 **중복조합(stars and bars method)**으로 해결되며, 답은 $\binom{n+k-1}{k} = \binom{n+k-1}{n-1}$입니다.

예를 들어 $x_1 + x_2 + x_3 = 4$ (단, $x_i \geq 0$)의 음이 아닌 정수해는, 4개의 동일한 공을 3개의 상자에 나누는 방법과 같으므로 $\binom{3+4-1}{4} = \binom{6}{4} = 15$가지입니다.

## 한 줄 예

$x + y = 3$ (단, $x, y \geq 0$)의 음이 아닌 정수해는 $(0,3), (1,2), (2,1), (3,0)$로 4가지이며, 공식으로는 $\binom{2+3-1}{3} = \binom{4}{3} = 4$입니다.

```python
# 검증: x + y = 3의 음이 아닌 정수해 개수
from sympy import symbols, solve
x, y = symbols('x y', integer=True, nonnegative=True)
solutions = [(xi, yi) for xi in range(4) for yi in range(4) if xi + yi == 3]
print(len(solutions))  # 4
```
