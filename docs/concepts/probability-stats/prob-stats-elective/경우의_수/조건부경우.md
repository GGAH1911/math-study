# 조건부경우

## 정확한 진술

조건부 경우의 수는 전체 경우의 집합에서 **특정 조건을 만족하는 경우들만 세는 경우의 수**입니다. 전체 가능한 경우의 집합을 $S$, 조건을 $C$라 할 때, 조건을 만족하는 부분집합 $\{x \in S : x \text{가 조건 } C \text{를 만족}\}$의 원소 개수입니다.

## 직관/기하적 의미

경우의 수 문제에서는 항상 상황에 제약이 따릅니다. 예를 들어 "5명 중 2명을 뽑되 A는 반드시 포함"이라는 조건이 있다면, 전체 $\binom{5}{2}$가지 중에서 조건을 만족하는 것만 세어야 합니다.

조건부 경우의 수는 **실생활의 제한된 상황**을 수학으로 옮기는 도구입니다. 자동판매기에서 "3000원 이상 5000원 이하인 음료"를 고르는 경우의 수, 또는 "홀수인 두 자리 수"의 개수처럼, 조건을 먼저 명확히 한 후 그 조건을 만족하는 원소들만 찾아내야 합니다.

## 한 줄 예

**예1**: 1부터 20까지의 자연수 중 **4의 배수**는 $4, 8, 12, 16, 20$이므로 경우의 수는 5입니다.

**예2**: 동전 3개를 던질 때 나올 수 있는 경우는 $2^3 = 8$가지이지만, **앞면이 2개 이상**인 경우는 $(H,H,T), (H,T,H), (T,H,H), (H,H,H)$ 네 가지입니다.

**예3**: 5명이 일렬로 서는 경우는 $5! = 120$가지이지만, **특정 두 명이 인접**한 경우는 두 명을 하나로 묶어 $2! \times 4! = 48$가지입니다.

이처럼 조건 없이는 전체 경우의 수이고, 조건이 주어지면 그 조건을 만족하는 부분만 세는 것입니다.
