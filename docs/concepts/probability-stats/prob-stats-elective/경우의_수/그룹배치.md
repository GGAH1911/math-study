# 그룹배치

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
$n$개의 서로 다른 원소를 비어있지 않은 $k$개의 구별되지 않는 그룹으로 나누는 경우의 수입니다.

## 본문
$n$개의 서로 다른 원소를 $k$개의 구별되지 않는 그룹으로 나누는 경우의 수를 **그룹배치**라고 합니다. 이때 각 그룹은 반드시 원소를 하나 이상 포함해야 하며, 모든 원소는 정확히 하나의 그룹에만 속해야 합니다. 이 값은 제2종 스털링 수 $S(n, k)$로 나타내며, 그룹들 사이에 순서가 없다는 점이 핵심입니다.

### 직관과 기하적 의미
그룹배치의 핵심은 그룹 간의 순서를 고려하지 않는다는 점입니다. 예를 들어 학생 A, B, C, D를 두 팀으로 나눌 때, '1번 팀'과 '2번 팀'처럼 팀에 이름이 붙어 있다면 순서가 의미가 있겠지만, 단순히 두 그룹으로만 나눈다면 {A, B}와 {C, D}로 나누는 것과 {C, D}와 {A, B}로 나누는 것은 동일한 하나의 경우로 취급합니다.

### 기본 성질
스털링 수는 다음과 같은 점화식을 통해 구할 수 있습니다.
$$S(n, k) = k \cdot S(n-1, k) + S(n-1, k-1)$$
첫 번째 항은 $n$번째 원소가 이미 만들어진 $k$개의 그룹 중 하나에 들어가는 경우를 의미하며, 두 번째 항은 $n$번째 원소가 새로운 그룹을 형성하는 경우를 의미합니다. 기저 조건으로는 $S(n, 1) = 1$과 $S(n, n) = 1$이 성립합니다.

예를 들어 4명을 2개 조로 나누는 경우 $S(4, 2)$를 계산하면 다음과 같습니다.
- {A, B}, {C, D}
- {A, C}, {B, D}
- {A, D}, {B, C}
- {A, B, C}, {D}
- {A, B, D}, {C}
- {A, C, D}, {B}
- {B, C, D}, {A}
총 7가지이므로 $S(4, 2) = 7$입니다.

## 학습 체크
- 그룹이 구별되는 경우와 구별되지 않는 경우의 차이점을 설명할 수 있는가?
- 점화식에서 $k \cdot S(n-1, k)$ 항이 의미하는 바를 원소의 배치 관점에서 이해했는가?
- 모든 원소가 하나의 그룹에만 속해야 한다는 조건을 만족하는가?

## 관련 개념
- **경우의 수**: 그룹배치는 주어진 조건에 따라 원소들을 나누는 특정한 경우의 수를 구하는 문제입니다.
