# 조합을 이용한 확률

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수_(확통))

## 요약
같은 종류의 대상 중에서 순서를 고려하지 않고 선택할 때, 전체 경우의 수와 특정 사건이 일어날 경우의 수를 모두 조합($C$)을 이용하여 계산하는 확률입니다.

## 본문
조합을 이용한 확률은 같은 종류의 대상들 중에서 선택하는 상황에서, 전체 경우의 수와 유리한 경우의 수를 모두 조합으로 계산하여 구하는 확률입니다. 일반적으로 다음과 같이 정의합니다.

$$P(A) = \frac{\text{조건을 만족하는 경우의 수}}{\text{전체 경우의 수}} = \frac{C(n, k) \text{ 형태}}{\text{전체 조합의 수}}$$

여기서 전체 경우와 유리한 경우 모두 순서를 고려하지 않는 선택 상황이므로 조합 공식 $C(n, k) = \frac{n!}{k!(n-k)!}$을 사용합니다.

### 직관과 의미
조합을 확률 계산에 사용하는 이유는 순서가 상관없는 선택 문제이기 때문입니다. 예를 들어 52장의 카드 중 5장을 뽑을 때, 뽑는 순서가 다르더라도 구성된 카드가 같다면 같은 경우로 취급합니다. 이렇게 순서를 구별하지 않는 상황에서 전체 경우의 수와 유리한 경우의 수를 모두 조합으로 나타내면, 자동으로 같은 것끼리의 중복 계산이 소거되어 올바른 확률을 얻을 수 있습니다.

### 기본 성질
10명 중 임의로 3명을 선발할 때, 특정 1명이 포함될 확률은 $\frac{C(9,2)}{C(10,3)} = \frac{36}{120} = \frac{3}{10}$ 입니다. 이는 전체 10명 중 3명을 뽑는 조합의 수 중에서, 특정 인물을 포함한 상태로 나머지 9명 중 2명을 뽑는 조합의 수의 비율과 같습니다.

## 학습 체크
- 확률을 계산할 때 분자와 분모에 모두 조합을 적용했는가?
- 문제 상황에서 선택하는 대상의 순서가 결과에 영향을 주지 않는 '순서 없는 선택'인가?
- 특정 조건이 포함된 경우의 수를 구할 때, 이미 선택된 대상을 제외한 나머지 인원과 남은 선택 횟수를 정확히 설정했는가?

## 관련 개념
- **확률**: 조합을 통해 구한 유리한 경우의 수를 전체 경우의 수로 나누어 사건이 발생할 가능성을 수치화합니다.
