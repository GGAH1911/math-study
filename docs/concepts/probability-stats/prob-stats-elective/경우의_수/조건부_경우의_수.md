### 정확한 진술

조건부 경우의 수는 **특정 조건을 만족하는 경우들만 세는 것**입니다. 주어진 조건 $C$를 만족하는 경우의 수를 구하기 위해 다음 두 방법을 활용합니다:

- **직접 계산**: 조건을 만족하는 경우들을 처음부터 끝까지 직접 세기
- **여집합 이용**: 전체 경우의 수에서 조건을 만족하지 않는 경우를 빼기 ($N_{\text{조건}} = N_{\text{전체}} - N_{\text{조건 아님}}$)

### 직관/기하적 의미

조건이 없으면 모든 가능한 경우를 세어야 하지만, **조건이 생기는 순간 범위가 자동으로 줄어듭니다**. 예를 들어 주사위를 던질 때 "3 이상"이라는 조건이 있으면 가능한 경우가 6가지에서 4가지로 좁혀집니다. 조건부 경우의 수는 이 좁혀진 범위 안에서 정확하게 세는 능력입니다.

복잡한 상황은 여러 조건들로 분해하여 각각 계산한 뒤 적절히 합치거나 곱하면 됩니다. 이는 복잡한 문제를 단계적으로 풀 수 있게 해주며, 나중에 조건부 확률의 기초가 됩니다.

### 한 줄 예

"1부터 20까지 자연수 중 3의 배수**이면서 동시에** 짝수인 수의 개수"는, 3의 배수 중 짝수인 6의 배수(6, 12, 18)를 찾으므로 **3개**입니다.

**다른 예시**: "10명 중 남학생만으로 3명을 뽑는 경우의 수" → 전체 10명이 아니라 조건(남학생)을 만족하는 사람들로만 조합을 계산합니다. `sympy.comb(7, 3)` (남학생이 7명이라 가정하면)
