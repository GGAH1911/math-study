# 경우의 분석

## 정확한 진술

경우의 분석이란 어떤 현상이나 사건을 여러 개의 서로 배타적인(겹치지 않는) 경우들로 나누고, 각 경우에 속하는 것들을 체계적으로 세는 방법입니다. 전체를 관찰 가능한 특성(예: 조건, 형태, 결과)에 따라 분할함으로써 중복을 피하고 빠짐을 방지합니다.

## 직관적 의미

복잡한 상황에서 직접 세는 것은 실수하기 쉽습니다. 경우의 분석은 큰 집합을 작은 부분으로 쪼개어, 각 부분을 따로 세고 합치는 분할과 정복의 전략입니다. 

예를 들어 "카드 몇 장이 조건을 만족하나?"라는 문제에서, 조건을 여러 작은 조건으로 나누면 (예: 색깔별, 숫자별) 각 경우가 단순해져 센다. 중요한 원칙은:
- **빠짐없이**: 모든 가능성을 포함
- **겹치지 않게**: 한 사건이 두 경우에 속하지 않도록 분할

이렇게 하면 합의 법칙 $N(\text{전체}) = N(\text{경우 1}) + N(\text{경우 2}) + \cdots$을 사용할 수 있습니다.

## 적용 방법

경우를 나눌 때는 다음 기준을 고려합니다:
- **특정 원소의 포함 여부**: "A를 포함하는 경우" vs "A를 포함하지 않는 경우"
- **대소 관계**: "첫 번째 숫자 < 두 번째 숫자" vs "첫 번째 숫자 ≥ 두 번째 숫자"
- **범주**: "빨강, 파랑, 초록 경우로 분류"

## 예시

세 자리 수 중 백의 자리가 십의 자리보다 큰 경우를 센다면:
- **경우 1**: 백의 자리 = 2, 십의 자리 = 1 → 일의 자리는 10가지
- **경우 2**: 백의 자리 = 3, 십의 자리 ∈ {1, 2} → 각각 10가지씩
- 이런 식으로 계속 분할하면 중복 없이 정확히 셀 수 있습니다.
