# 다항정리

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수_(확통))

## 요약
다항정리는 이항정리를 일반화하여 여러 개의 항을 가진 다항식의 거듭제곱 전개식을 구하는 원리입니다.

## 본문
$n$개의 변수 $a_1, a_2, \ldots, a_k$에 대하여, 다항정리는 다음과 같이 정의됩니다.
$$\left( a_1 + a_2 + \cdots + a_k \right)^n = \sum_{n_1 + n_2 + \cdots + n_k = n} \frac{n!}{n_1! \, n_2! \, \cdots \, n_k!} \, a_1^{n_1} a_2^{n_2} \cdots a_k^{n_k}$$
이때 합은 음이 아닌 정수 $n_1, n_2, \ldots, n_k$의 모든 조합에 대해 이루어지며, 각 항의 계수인 $\tfrac{n!}{n_1! \, n_2! \, \cdots \, n_k!}$를 **다항계수**라고 부릅니다.

### 직관과 기하적 의미
다항정리는 이항정리의 일반화된 형태입니다. $(a_1 + a_2 + \cdots + a_k)^n$을 전개한다는 것은 $n$개의 괄호에서 각각 하나의 항을 선택하여 곱하는 과정과 같습니다. 이때 $a_1$을 $n_1$번, $a_2$를 $n_2$번, ..., $a_k$를 $n_k$번 선택하는 경우의 수가 바로 다항계수입니다. 이는 $n$개의 자리에 같은 종류끼리 구별하지 않고 배열하는 중복순열의 원리와 일치합니다. 예를 들어 $(x+y+z)^2$를 전개하면 $x^2 + y^2 + z^2 + 2xy + 2xz + 2yz$가 됩니다.

### 기본 성질
다항계수는 각 지수의 합이 전체 지수인 $n$과 같아야 한다는 조건을 가집니다. 즉, $n_1 + n_2 + \cdots + n_k = n$을 만족하는 정수들에 대해서만 항이 존재합니다.

## 학습 체크
- 다항계수 $\tfrac{n!}{n_1! \, n_2! \, \cdots \, n_k!}$에서 각 $n_i$의 합이 왜 반드시 $n$이어야 하는가?
- 항의 개수가 $k$개인 다항식의 $n$제곱을 전개했을 때, 나타나는 서로 다른 항의 개수는 어떻게 구하는가?

## 관련 개념
- **다항식**: 다항정리는 여러 개의 항으로 이루어진 다항식을 거듭제곱하여 전개하는 과정을 다룹니다.
- **이항정리**: 다항정리에서 항의 개수가 2개인 특수한 경우를 의미합니다.
- **중복순열**: 다항계수를 구하는 과정은 $n$개의 자리에 각 항을 배치하는 중복순열의 수와 같습니다.
