# 여사건을 이용한 포함배제

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
구하려는 경우의 수를 직접 구하기 어려울 때, 전체 경우의 수에서 조건을 만족하지 않는 여사건의 경우의 수를 빼서 계산하는 방법입니다.

## 본문
여사건을 이용한 포함배제란, 구하려는 경우의 수를 직접 세기 어려울 때 전체 경우에서 조건을 만족하지 않는 경우를 뺀다는 방법입니다. 전체 집합을 $U$, 우리가 원하는 조건을 나타내는 집합을 $A$라 하면 $|A| = |U| - |A^c|$로 나타낼 수 있습니다. 여기서 $A^c$는 $A$의 여사건으로, 조건을 만족하지 않는 모든 경우를 뜻합니다. 여러 조건이 복합적으로 얽혀 있는 경우에는 드모르간 법칙을 활용하여 식을 확장하여 해결할 수 있습니다.

### 직관과 기하적 의미
"전체에서 빼기"는 매우 직관적인 아이디어입니다. 어떤 조건을 만족하는 경우를 일일이 세는 과정이 매우 복잡하거나 번거로울 때, 반대로 그 조건을 만족하지 않는 경우를 세는 쪽이 훨씬 간단할 수 있다는 점을 이용합니다. 이는 복잡한 영역을 직접 계산하기보다 전체 영역에서 불필요한 부분을 도려내는 방식과 유사합니다.

### 기본 성질
포함배제 원리 $|A_1 \cup A_2| = |A_1| + |A_2| - |A_1 \cap A_2|$는 원하는 사건들을 모두 더한 뒤 중복된 부분을 빼는 방식입니다. 반면 여사건을 이용한 방식은 드모르간 법칙인 $(A_1 \cup A_2)^c = A_1^c \cap A_2^c$를 통해 동치적으로 표현될 수 있으며, 특히 문제에서 "~가 아닌"이라는 표현이 등장할 때 계산을 획기적으로 간결하게 만들어줍니다.

## 학습 체크
- 문제에서 "적어도 하나는 ~이다" 또는 "~가 아니다"라는 표현이 있는지 확인했는가?
- 전체 경우의 수 $|U|$를 설정할 때 조건이 없는 순수한 전체 집합을 정확히 설정했는가?
- 여사건의 경우의 수를 구할 때, 문제에서 요구하는 조건의 반대 상황을 정확히 정의했는가?

## 관련 개념
- **경우의 수**: 전체 집합의 크기와 여사건의 크기를 이용하여 특정 사건이 일어나는 경우의 수를 효율적으로 산출합니다.
- **포함배제 원리**: 여러 사건이 겹치는 경우를 처리하는 원리로, 여사건의 관점에서 드모르간 법칙과 결합하여 복잡한 집합 문제를 해결합니다.
- **드모르간 법칙**: 여러 조건이 결합된 여사건을 개별 조건의 여사건들의 교집합으로 변환하여 계산을 가능하게 합니다.
