# 여사건을 이용한 포함배제

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 정확한 진술

여사건을 이용한 포함배제란, 구하려는 경우의 수를 직접 세기 어려울 때 **전체 경우에서 조건을 만족하지 않는 경우를 뺀다**는 방법입니다. 

전체 집합을 $U$, 우리가 원하는 조건을 나타내는 집합을 $A$라 하면:
$$|A| = |U| - |A^c|$$

여기서 $A^c$는 $A$의 여사건(complement)으로, 조건을 만족하지 **않는** 모든 경우를 뜻합니다. 여러 조건이 복합되었을 때는 드모르간 법칙을 활용하여 확장됩니다.

## 직관과 의미

"전체에서 빼기"는 매우 직관적인 아이디어입니다. 예를 들어 어떤 조건을 만족하는 경우를 세는 것이 복잡하면, **그 조건을 만족하지 않는** 경우를 세는 쪽이 더 간단할 수 있습니다.

포함배제 원리와의 관계: 포함배제 원리 $|A_1 \cup A_2| = |A_1| + |A_2| - |A_1 \cap A_2|$는 "원하는 것들을 모두 세되 중복을 빼기"이지만, 여사건 관점에서 보면 $(A_1 \cup A_2)^c = A_1^c \cap A_2^c$ (드모르간 법칙)를 통해 동치적으로 표현할 수 있습니다.

## 기본 예시

**상황**: 1부터 100까지 수 중에서 3의 배수가 **아닌** 수의 개수를 구하는 경우

- 전체: $|U| = 100$
- 3의 배수(조건 불만족): $|A| = \lfloor 100/3 \rfloor = 33$
- 답: $100 - 33 = 67$

포함배제 원리와 달리 여사건 이용법은 계산이 간결하고, 특히 "~가 **아닌**" 형태의 문제에서 강력합니다.
