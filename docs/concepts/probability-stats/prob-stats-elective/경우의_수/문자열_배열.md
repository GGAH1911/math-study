# 문자열 배열

## 정확한 진술

**문자열 배열**은 주어진 문자 집합에서 일부 또는 전체 문자를 순서를 고려하여 선택·배치하여 만드는 문자열입니다. $n$개의 서로 다른 문자에서 $r$개를 순서대로 배열하는 경우의 수는 순열 공식 $P(n, r) = \frac{n!}{(n-r)!}$로 계산됩니다.

## 직관적 의미

'배열'이라는 것은 **순서가 중요**하다는 뜻입니다. 예를 들어 {수, 학} 두 글자로는 "수학"과 "학수" 두 개의 서로 다른 배열이 만들어집니다. 만약 순서를 무시한다면 (조합) 단 1가지일 테지만, 배열은 문자의 위치를 구분하므로 2가지입니다. 이는 첫 자리에 어떤 문자가 오는지가 결과를 완전히 다르게 만드는 현상을 반영합니다.

## 한 줄 예

문자 A, B, C로 만들 수 있는 3자리 배열은 $3! = 6$가지입니다: ABC, ACB, BAC, BCA, CAB, CBA.

## 계산 예시

문자 {가, 나, 다, 라}에서 2개를 순서대로 배열하는 경우의 수: $P(4, 2) = \frac{4!}{2!} = 12$가지입니다.
- 첫 자리: 4가지 선택 (가, 나, 다, 라)
- 둘째 자리: 3가지 선택 (남은 3개 중)
- 총: $4 \times 3 = 12$가지

(`P(4, 2) = 4 * 3 = 12` 또는 sympy로 `sympy.factorial(4) // sympy.factorial(2)` 검증)
