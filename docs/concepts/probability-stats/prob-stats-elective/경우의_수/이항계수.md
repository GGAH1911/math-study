# 이항계수

> **정의** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
$_nC_k$

## 본문 (학습 시 채워짐)

### 정확한 진술

$n$개 중에서 순서를 고려하지 않고 $k$개를 선택하는 경우의 수를 **이항계수**(binomial coefficient)라 하고 $_nC_k$로 나타냅니다. 계산 공식은:

$$_nC_k = \frac{n!}{k!(n-k)!}$$

단, $n \geq k \geq 0$이고 $n, k$는 음이 아닌 정수입니다.

### 직관과 의미

"조합"입니다. 순열($_nP_k$)은 순서를 구분하지만, 이항계수는 순서를 무시합니다. 예를 들어 학생 5명(A, B, C, D, E) 중 3명을 선택할 때, {A, B, C}와 {C, B, A}는 같은 선택입니다.

순열에서 $k$개를 선택한 후 그 $k$개를 배열하는 방법은 $k!$가지입니다. 이 모든 배열을 같은 것으로 취급하면 조합이 됩니다:

$$_nC_k = \frac{_nP_k}{k!} = \frac{n(n-1)(n-2)\cdots(n-k+1)}{k!} = \frac{n!}{k!(n-k)!}$$

분모의 $k!$은 "중복 제거"이고, $(n-k)!$은 "선택하지 않은 것들"을 정의에서 제외하는 역할입니다.

### 예시

6명 중 2명을 선택하면:

$$_6C_2 = \frac{6!}{2! \cdot 4!} = \frac{6 \times 5}{2 \times 1} = 15$$

`sympy.binomial(6, 2)` → 15가지
