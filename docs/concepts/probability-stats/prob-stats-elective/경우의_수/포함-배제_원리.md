# 포함-배제 원리

## 정확한 진술

두 개 이상의 집합의 합집합의 크기를 구할 때, 각 집합의 크기를 더한 후 중복을 제거하는 원리입니다. 두 집합 $A$, $B$에 대해:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

세 집합 $A$, $B$, $C$에 대해:

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$

일반적으로 $n$개 집합의 합집합의 크기는 다음과 같이 구합니다. 먼저 각 집합의 크기를 모두 더하고, 그 다음 두 개씩 교집합을 빼고, 세 개씩 교집합을 더하고, 이런 식으로 부호를 번갈아가며 반복합니다.

## 직관/기하적 의미

"포함했다가 빼기"를 반복한다는 뜻입니다. 예를 들어 학생 중 수학을 좋아하거나 과학을 좋아하는 학생 수를 세려면, 먼저 수학을 좋아하는 학생과 과학을 좋아하는 학생을 모두 더합니다. 하지만 수학과 과학을 모두 좋아하는 학생은 두 번 세어지므로 한 번을 빼야 합니다. 

벤 다이어그램으로 생각하면 더 명확합니다. 합집합의 모든 부분을 정확히 한 번씩만 세기 위해, 여러 개의 교집합 항을 번갈아 더하고 빼는 방식으로 중복을 조정하는 것입니다.

## 한 줄 예

1부터 100까지의 자연수 중 3의 배수 또는 5의 배수의 개수는 $|A \cup B| = \lfloor 100/3 \rfloor + \lfloor 100/5 \rfloor - \lfloor 100/15 \rfloor = 33 + 20 - 6 = 47$입니다. (확인: `len([n for n in range(1, 101) if n % 3 == 0 or n % 5 == 0])` 결과 47)
