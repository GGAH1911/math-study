# 중복원소 순열

## 정확한 진술

$n$개의 원소 중에서 어떤 원소들이 반복되어 나타나는 경우, 예를 들어 같은 원소가 각각 $n_1$개, $n_2$개, ..., $n_k$개씩 있을 때 ($n_1 + n_2 + \cdots + n_k = n$), 이 $n$개의 원소를 **모두 사용하여** 일렬로 배열하는 방법의 수를 **중복원소 순열** 또는 **같은 것이 있는 순열**이라 하며, 다음 공식으로 구합니다:

$$\frac{n!}{n_1! \cdot n_2! \cdot \ldots \cdot n_k!}$$

## 직관과 의미

중복 없이 $n$개 서로 다른 원소를 배열하면 $n!$가지입니다. 그런데 그 중 $n_1$개가 실제로 같은 원소라면, 이들을 서로 바꾼 배열은 구별되지 않으므로 중복으로 세어진 것입니다. 따라서 $n_1!$로 나누어 이 중복을 제거합니다. 마찬가지로 $n_2$개의 같은 원소는 $n_2!$로, $n_k$개의 같은 원소는 $n_k!$로 나눕니다. 이 방법은 **중복제거 원리**라고도 불리며, 조합론의 기본 원리입니다.

## 예시

"BOOK"이라는 4개 글자를 배열하면, 일반적으로는 $4! = 24$가지입니다. 그런데 O가 2개 같으므로:

$$\frac{4!}{2!} = \frac{24}{2} = 12\text{가지}$$

(검산: `from math import factorial; print(factorial(4) // factorial(2))` → 12)

직접 세어보면 BOOK, BOKO, BKOO, OBKO, OBOK, ... 등 정확히 12가지 서로 다른 배열이 만들어집니다.
