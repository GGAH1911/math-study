### 정확한 진술

수열 $a_0, a_1, a_2, \ldots$에 대해 **생성함수**(generating function)는 다음과 같은 형식적 멱급수(formal power series)입니다.

$$G(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3 + \cdots = \sum_{n=0}^{\infty} a_n x^n$$

여기서 계수 $a_n$은 수열의 각 항이며, $x$는 형식적 변수일 뿐 실제 값을 대입하는 것이 아닙니다.

### 직관/기하적 의미

생성함수는 **수열의 정보를 하나의 함수로 인코딩**하는 방법입니다. 각 항의 계수가 수열의 원소가 되므로, 복잡한 수열의 규칙성을 다항식 연산으로 탐구할 수 있습니다. 예를 들어, 경우의 수 문제에서 여러 조건을 만족하는 경우를 세는 상황을 생각해봅시다. 각 경우의 수를 수열로 모으면, 생성함수의 계수들이 바로 우리가 구하는 답이 됩니다. 또한 두 생성함수를 곱하면 그 결과의 계수들은 원래 수열들의 **합성곱(convolution)**을 나타내므로, 어려운 합의 계산을 대수적으로 단순화할 수 있습니다.

### 한 줄 예

수열 $1, 1, 1, 1, \ldots$의 생성함수는 $G(x) = 1 + x + x^2 + x^3 + \cdots = \frac{1}{1-x}$ (단, $|x| < 1$일 때 수렴)입니다. 여기서 $x^n$의 계수가 항상 1이므로 $n$번째 항이 1임을 나타냅니다. 실제로 경우의 수 문제에서 "동일한 물건 $n$개를 선택하는 경우의 수는 1가지"라는 상황을 생성함수로 표현할 때 자주 나타나는 형태입니다.
