# 수의 곱 조건

> **정의** · 확률과통계 · 단원: [경우의 수](/concepts/경우의_수)

## 요약
두 사건이 연속적으로 또는 동시에 일어날 때, 각 사건의 경우의 수를 곱하여 전체 경우의 수를 구하는 원리입니다.

## 본문
두 사건 $A$와 $B$가 동시에 또는 순서대로 일어날 때, 사건 $A$가 일어나는 경우의 수를 $m$, 각 경우에 대해 사건 $B$가 일어나는 경우의 수를 $n$이라 하면, 두 사건이 모두 일어나는 경우의 수는 $m \times n$입니다. 이를 곱의 법칙 또는 수의 곱 조건이라 합니다. 더 일반적으로 $k$개의 사건이 순차적으로 일어나고 각 단계에서의 경우의 수가 $n_1, n_2, \ldots, n_k$이면, 전체 경우의 수는 $n_1 \times n_2 \times \cdots \times n_k$이 됩니다.

### 직관과 기하적 의미
곱의 법칙은 단계별 선택의 과정을 다룹니다. 첫 번째 선택에서 $m$가지 방법이 있고, 각 선택 이후 항상 같은 수 $n$의 다음 선택지가 있다면, 두 선택을 함께 하는 방법은 $m \times n$가지가 됩니다. 예를 들어 옷 3가지와 신발 2가지를 조합하는 상황은, 각 옷마다 신발 2가지의 선택지가 반복되어 나타나므로 $3 \times 2 = 6$가지의 조합이 형성되는 것과 같습니다.

### 기본 성질
사건이 연달아 일어날 때 각 단계의 선택지가 독립적으로 일정하게 유지된다면 곱의 법칙을 적용할 수 있습니다. 만약 A에서 B로 가는 방법이 5가지이고, B에서 C로 가는 방법이 4가지라면, A에서 C까지 가는 전체 경로의 수는 $5 \times 4 = 20$가지가 됩니다.

## 학습 체크
- 두 사건이 동시에 일어나는 상황인지, 아니면 단계적으로 일어나는 상황인지 구분할 수 있는가?
- 각 단계의 경우의 수가 이전 단계의 결과에 따라 변하지 않고 일정하게 유지되는가?
- 합의 법칙(사건이 별개로 일어남)과 곱의 법칙(사건이 연달아 일어남)을 혼동하지 않고 적용할 수 있는가?

## 관련 개념
- **경우의 수**: 곱의 법칙은 전체 경우의 수를 계산할 때 가장 기본적으로 사용되는 연산 원리입니다.
