# 구간별조건

## 정확한 진술

구간별조건이란 구하는 대상의 범위를 겹치지 않는 여러 구간으로 분할하여, 각 구간에서 서로 다른 조건을 적용하여 경우의 수를 계산하는 방법입니다. 조건을 만족하는 전체 경우의 수는 각 구간에서 조건을 만족하는 경우의 수의 합으로 구합니다.

$$\text{(전체 경우의 수)} = \sum_{i=1}^{k} \text{(구간 }i\text{에서의 경우의 수)}$$

## 직관·기하적 의미

어떤 조건이 변수의 범위나 특성에 따라 다르게 작동할 때, 우선 그 범위를 기준으로 전체를 작은 부분들로 나누면 각 부분에서는 조건이 더 단순해집니다. 예를 들어 "일의 자리"가 조건에 영향을 준다면 일의 자리가 0인 경우, 1인 경우, …, 9인 경우로 나누어 각각 세는 방식입니다. 이는 조합론의 **분할 원리**(partition principle)에 기초하며, "겹치지 않고 빠지지 않게 모든 경우를 분류하여 센다"는 조합론의 가장 기본적인 원칙입니다.

## 한 줄 예

$1 \le n \le 100$인 정수를 $n$을 3으로 나눈 나머지에 따라 분류하면, 나머지 0 (33개), 나머지 1 (34개), 나머지 2 (33개)이고, 합은 $33 + 34 + 33 = 100$입니다.

```python
# 1~100 중 나머지별 분류
[len([n for n in range(1, 101) if n % 3 == r]) for r in range(3)]  # [33, 34, 33]
```
