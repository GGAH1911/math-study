# 중복있는 줄세우기

> **예제** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)

## 요약
서로 다른 $n$개에서 중복을 허용하여 $r$개를 뽑아 일렬로 나열하는 중복순열의 원리를 이해하고 적용한다.

## 본문
서로 다른 문자 $a, b, c$ 세 개를 사용하여 4자리 문자열을 만든다. 같은 문자를 여러 번 사용할 수 있을 때, 몇 가지 문자열을 만들 수 있는가?

### 단계별 풀이
각 자리에 $a, b, c$ 중 어느 문자든 자유롭게 올 수 있으므로, 각 자리는 독립적으로 3가지의 선택지를 가집니다. 첫 번째 자리부터 네 번째 자리까지 각 자리마다 $a, b, c$ 중 하나를 선택하는 경우의 수는 각각 3가지씩입니다. 따라서 곱의 법칙을 적용하면 $3 \times 3 \times 3 \times 3 = 3^4 = 81$이 됩니다. 이는 중복순열 공식인 $\Pi(n, r) = n^r$에서 $n=3, r=4$를 대입한 결과와 일치합니다.

### 답과 변형
**81가지**

- **제약 조건이 있는 경우**: 만약 첫 글자는 반드시 $a$여야 한다는 조건이 붙는다면, 첫 번째 자리는 1가지 경우뿐이므로 $1 \times 3 \times 3 \times 3 = 27$가지가 됩니다.
- **같은 것이 있는 순열과의 차이**: 만약 $a$가 2개, $b$가 1개, $c$가 1개로 정해진 구성 요소를 배열하는 것이라면 이는 중복순열이 아니라 같은 것이 있는 순열에 해당하며, $\frac{4!}{2! \cdot 1! \cdot 1!} = 12$가지로 계산됩니다.
- **실생활 응용**: 0부터 9까지 10개의 숫자로 만드는 4자리 비밀번호는 $10^4 = 10,000$가지이며, 3가지 색상의 신호등이 5번 신호를 보내는 경우의 수는 $3^5 = 243$가지입니다.

## 학습 체크
- 각 자리에 올 수 있는 경우의 수를 독립적으로 파악하여 곱할 수 있는가?
- 중복순열 공식 $n^r$을 문제 상황에 맞게 $n$과 $r$에 대입할 수 있는가?
- 같은 것이 있는 순열과 혼동하지 않고 중복 허용 여부를 구분할 수 있는가?

## 관련 개념
- **경우의 수**: 중복순열은 전체 경우의 수를 구하는 방법 중 하나로, 선택의 중복이 허용되는 특수한 상황을 다룹니다.
