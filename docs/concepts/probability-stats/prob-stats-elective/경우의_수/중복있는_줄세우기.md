# 중복있는 줄세우기

> **예제** · 확률과통계 · 단원: [경우의 수 (확통)](/concepts/경우의_수)
## 요약
중복순열 응용

## 본문

### 문제

서로 다른 문자 $a, b, c$ 세 개를 사용하여 4자리 문자열을 만든다. 같은 문자를 여러 번 사용할 수 있을 때, 몇 가지 문자열을 만들 수 있는가?

### 단계별 풀이

**1단계: 상황 파악**  
각 자리에 $a, b, c$ 중 어느 문자든 자유롭게 올 수 있습니다. "중복을 허용하면서 배열한다"는 것이 중복순열의 핵심입니다.

**2단계: 각 자리별 경우의 수**
- 첫 번째 자리: $a, b, c$ 중 1개 선택 → 3가지
- 두 번째 자리: 첫 자리 선택과 무관하게 다시 3가지
- 세 번째 자리: 3가지
- 네 번째 자리: 3가지

**3단계: 곱의 법칙 적용**  
각 자리는 독립적이므로:
$$3 \times 3 \times 3 \times 3 = 3^4 = 81$$

이는 중복순열 공식 $\Pi(n, r) = n^r$에서 $n=3, r=4$를 대입한 결과입니다.

### 답

**81가지**

(검증: `3**4 = 81`)

### 변형 및 주의

- **제약 조건이 있는 경우**: "첫 글자는 반드시 $a$"라면 $1 \times 3 \times 3 \times 3 = 27$가지입니다.

- **같은 것이 있는 순열과 혼동 금지**: 만약 "a 2개, b 1개, c 1개를 배열한다"면 이는 중복순열이 아니라 **같은 것이 있는 순열**로, $\displaystyle\frac{4!}{2! \cdot 1! \cdot 1!} = 12$가지입니다. 완전히 다른 개념입니다.

- **실생활 응용**: 비밀번호(0~9 십 개 숫자, 4자리) → $10^4 = 10,\!000$가지. 신호등 색상(빨강·노랑·파랑 3가지, 5번 신호) → $3^5 = 243$가지.
