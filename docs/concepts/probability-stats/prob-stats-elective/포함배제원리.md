### 정확한 진술

포함배제원리는 여러 집합의 합집합의 원소 개수를 구하는 방법입니다. 두 집합 $A$, $B$에 대해

$$|A \cup B| = |A| + |B| - |A \cap B|$$

이고, 세 집합 $A$, $B$, $C$에 대해

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$

입니다. 일반적으로 $n$개의 집합에 대해, **포함된 집합들을 모두 더한 뒤, 두 개씩 겹치는 부분을 빼고, 세 개씩 겹치는 부분을 다시 더하고, 이렇게 부호를 바꿔가며 반복**합니다.

### 직관과 기하적 의미

벤 다이어그램을 그려보면 명확해집니다. $A \cup B$의 크기를 셀 때, $|A| + |B|$로 더하면 $A \cap B$에 속한 원소들이 두 번 세어집니다. 따라서 한 번 빼줘야 합니다. 세 개 이상의 집합에서도 같은 논리가 적용됩니다. 포함과 배제를 반복하면서 각 원소가 정확히 한 번만 세어지도록 보정하는 것이 핵심입니다.

경우의 수 문제에서 "적어도 하나의 조건을 만족하는 경우"를 구할 때 자주 쓰입니다. 예를 들어 "3의 배수 또는 5의 배수"처럼 여러 조건 중 하나라도 만족하는 경우의 수를 계산할 수 있습니다.

### 한 줄 예

1부터 10까지의 수 중 2의 배수 또는 3의 배수인 경우: $|A| = 5$ (2,4,6,8,10), $|B| = 3$ (3,6,9), $|A \cap B| = 1$ (6)이므로 $|A \cup B| = 5 + 3 - 1 = 7$
