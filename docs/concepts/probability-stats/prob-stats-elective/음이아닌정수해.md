### 정확한 진술

방정식 $x_1 + x_2 + \cdots + x_k = n$을 만족하는 음이아닌 정수 $x_1, x_2, \ldots, x_k$의 순서쌍 $(x_1, x_2, \ldots, x_k)$를 **음이아닌정수해(non-negative integer solution)**라 합니다. 여기서 "음이아닌"이란 0 이상을 뜻하므로, 각 변수는 0, 1, 2, 3, ... 중 하나여야 합니다. 음수나 소수는 불가능합니다.

### 실제 의미: 분배 문제와의 연결

이 개념이 중요한 이유는 조합론의 가장 실용적인 문제인 **동일한 물건을 구별되는 상자에 나누어 담는 경우의 수**와 정확히 일치하기 때문입니다. 예를 들어:
- 10개의 동일한 사탕을 3명의 친구에게 나누어주기
- 5개의 동일한 공을 4개의 서로 다른 색상 상자에 넣기

각 상자(또는 친구)가 받은 개수가 $x_1, x_2, \ldots, x_k$에 해당하며, 이는 고등학교에서 배우는 **중복조합** $\mathrm{H}(k, n)$과 동일한 상황입니다.

### 해의 개수를 구하는 공식

음이아닌정수해 개수는:
$$\binom{n+k-1}{k-1}$$

이 공식은 "n개의 동일한 공 + (k-1)개의 칸막이"를 일렬로 배열하는 것으로 이해할 수 있습니다.

### 구체적 예

$x + y + z = 4$의 음이아닌정수해 개수:
$$\binom{4+3-1}{3-1} = \binom{6}{2} = 15$$

몇 가지 해: $(0,0,4), (0,1,3), (0,2,2), (1,1,2), (2,2,0), (4,0,0), \ldots$ (총 15개)

검증: `len([(x,y,z) for x in range(5) for y in range(5) for z in range(5) if x+y+z==4])`
