# 조건부확률

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
$P(B|A)$

## 본문 (학습 시 채워짐)

### 정확한 정의

사건 $A$가 일어났다는 조건 아래에서 사건 $B$가 일어날 확률을 **조건부확률**(conditional probability)이라 하며, 다음과 같이 정의합니다:

$$P(B|A) = \frac{P(A \cap B)}{P(A)} \quad (P(A) > 0)$$

여기서 $P(A \cap B)$는 $A$와 $B$가 동시에 일어날 확률, $P(A)$는 사건 $A$의 확률입니다.

### 직관적 의미

조건부확률은 **표본공간의 재설정**입니다. 처음에는 전체 표본공간에서 확률을 계산했다면, 이제는 "$A$가 일어났다"는 새로운 정보를 받은 후 $A$만을 새로운 전체 범위로 삼는 것입니다.

분수의 의미:
- **분자** $P(A \cap B)$: A이면서 동시에 B인 경우의 확률
- **분모** $P(A)$: A가 일어난 모든 경우의 확률(새로운 전체)

따라서 조건부확률은 "축소된 표본공간에서 B가 차지하는 상대적 비율"입니다.

### 구체적 예

주사위 한 번을 던질 때:
- $A$: "나온 수가 3 이상"  
- $B$: "나온 수가 짝수"

$P(A) = \frac{4}{6}$ (3, 4, 5, 6)이고, $A \cap B = \{4, 6\}$이므로 $P(A \cap B) = \frac{2}{6}$입니다.

$$P(B|A) = \frac{2/6}{4/6} = \frac{1}{2}$$

"주사위 눈이 3 이상이라고 알았을 때, 그것이 짝수일 확률은 50%"라는 뜻입니다. 주사위 눈이 {3, 4, 5, 6} 중 하나인데, 이 중 짝수는 {4, 6} 두 개이기 때문입니다.

**검산**: `from fractions import Fraction; P_B_given_A = Fraction(2, 4); print(P_B_given_A)` → 1/2
