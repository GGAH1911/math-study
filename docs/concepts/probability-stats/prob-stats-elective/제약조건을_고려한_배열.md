### 정확한 진술

제약조건을 고려한 배열이란, $n$개의 서로 다른 원소 중에서 $r$개를 선택하여 순서를 정할 때, **특정한 조건(제약조건)을 반드시 만족**해야 하는 배열입니다. 제약조건 없이 일반적으로 배열할 수 있는 경우의 수는 $_{n}P_{r} = \frac{n!}{(n-r)!}$이지만, 조건이 추가되면 이 수는 줄어듭니다.

제약조건의 예시:
- 특정 원소 A가 맨 앞에 와야 함
- 원소 B와 C는 인접하지 않아야 함  
- 원소들이 특정 크기 순서를 유지해야 함

### 직관·기하적 의미

제약조건은 배열의 "자유도(자유로운 정도)"를 제한합니다. 제약 없이는 모든 배열이 가능하지만, 조건을 추가하면 가능한 배열의 개수가 감소합니다. 이는 실제 상황에서 자주 나타납니다.

예를 들어:
- **책상 배치**: 특정 사람끼리는 옆에 앉을 수 없음
- **암호 설정**: 특정 숫자는 특정 위치에 올 수 없음
- **시간표 편성**: 특정 과목은 특정 요일에만 배치 가능
- **사진 촬영**: 특정 인물은 반드시 중앙에 서야 함

제약조건을 고려한 배열을 세는 것은 이러한 현실의 제약 속에서 **실제로 가능한 경우가 몇 가지인지** 파악하는 것입니다. 제약이 강할수록 가능한 배열 수는 줄어들므로, 체계적으로 경우를 나누어 계산하는 능력이 중요합니다.

### 한 줄 예

서로 다른 4명의 학생을 일렬로 세우되, **A는 맨 앞에 와야 한다**는 제약이 있으면 경우의 수는 $3! = 6$입니다. (A의 위치는 고정이므로 나머지 3명만 배열하면 됨)
