### 정의

인접 제약 조건(adjacent constraint)은 순열이나 배열 문제에서 **특정 원소들이 반드시 이웃해야 한다**는 조건입니다. 예를 들어, $n$개의 서로 다른 원소를 일렬로 배열할 때, 원소 $A$와 $B$가 항상 인접(옆에 붙어 있어야)한다는 제약을 말합니다.

수식으로 표현하면, 배열 순서에서 $A$와 $B$의 위치를 $i$, $i+1$ 또는 $i+1$, $i$로만 허용한다는 뜻입니다.

### 직관과 문제 풀이 방법

인접 제약 조건의 핵심은 **제약을 받는 원소들을 하나의 단위(block)로 묶는 것**입니다. 

예를 들어, A와 B를 반드시 인접하게 배열해야 한다면:
1. A와 B를 하나의 묶음으로 간주합니다
2. 이 묶음을 하나의 단위로 취급하여 다른 원소들과 함께 배열합니다
3. 묶음 내에서 A와 B의 순서도 고려해야 합니다

따라서 $n$개의 원소 중 특정 2개가 인접해야 할 때:
- 묶음 1개 + 나머지 $(n-2)$개 = 총 $(n-1)$개 단위를 배열: $(n-1)!$가지
- 묶음 내에서의 순서: $2!$가지
- **전체: $(n-1)! \times 2!$가지**

이 방법은 3개 이상의 원소가 인접해야 하는 경우로도 확장됩니다.

### 예제

5명을 일렬로 세울 때, A와 B가 반드시 옆에 있어야 한다면?

A와 B를 하나의 묶음으로 생각하면, 묶음(AB) + C + D + E = 4개 단위를 배열하는 것입니다.
- 4개 단위의 배열: $4! = 24$가지
- 묶음 내 A, B의 순서: $2! = 2$가지
- **답: $24 \times 2 = 48$가지**

검증: `sympy.factorial(4) * sympy.factorial(2)` = 48 ✓
