# 통계

> **단원** · 확률과통계 · 선수: [확률](/concepts/확률) / [대푯값과 산포도](/concepts/대푯값과_산포도) · 다음: 없음

## 학습 목표
- 이산·연속 확률변수와 확률분포를 다룬다
- 이항분포·정규분포를 활용한다
- 표본평균을 통한 통계적 추정을 수행한다

## 다룰 정의 / 정리 / 예제

**정의**
- [확률변수](/concepts/확률변수) — $X$, 확률분포
- 기댓값 $E(X)$, 분산 $V(X)$
- 이항분포 $B(n,p)$
- [정규분포](/concepts/정규분포) — $N(\mu,\sigma^2)$
- 표본평균 $\bar X$

**정리**
- $E(X)=\sum xP(X=x)$, $V(X)=E(X^2)-E(X)^2$
- 이항분포의 정규근사
- [표본평균의 분포](/concepts/표본평균의_분포) — ~ $N(\mu, \sigma^2/n)$

**예제**
- 확률변수 평균·분산
- [이항분포 확률 계산](/concepts/이항분포_확률_계산)
- 정규분포 $Z$-표 사용
- 신뢰구간 구하기

- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
