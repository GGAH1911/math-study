### 정확한 진술

제약 조건은 경우의 수를 세거나 조합·순열을 구할 때 선택이 **반드시 만족해야 하는 추가 규칙**입니다. 어떤 문제에서 "$\cdots$일 때만 센다", "단, $\cdots$는 제외한다" 같은 부분이 바로 제약 조건입니다.

$$\text{전체 경우의 수} \to \text{제약 조건 적용} \to \text{조건을 만족하는 경우의 수}$$

### 직관과 의미

제약 조건이 없으면 모든 선택이 자유롭습니다. 하지만 대부분의 실제 문제에는 조건이 붙어 **가능한 경우를 제한**합니다.

**예시:**
- **제약 조건 없음:** $\{1, 2, 3, 4, 5\}$에서 서로 다른 두 개를 순서대로 선택 → $5 \times 4 = 20$가지

- **제약 조건 있음:** 첫 번째는 홀수여야 함 → 첫 번째에서 $\{1, 3, 5\}$ (3가지), 두 번째에서 남은 것 중 선택 (4가지) → $3 \times 4 = 12$가지

제약 조건이 강할수록, 조건이 많을수록 **경우의 수는 더 적어집니다**. 따라서 조건을 정확히 파악하고 단계적으로 적용하는 것이 핵심입니다.

### 한 줄 예

주사위 두 개를 던질 때 "합이 7 이상" 이라는 제약 조건 아래, 가능한 경우는 $(1,6), (2,5), (2,6), \ldots$ 처럼 조건을 만족하는 것만 셉니다.

```python
# 검증: 1~5 중 두 개를 고르되 합이 정확히 6
pairs = [(a,b) for a in range(1,6) for b in range(a+1,6) if a+b==6]
# 결과: [(1, 5), (2, 4)] → 2가지
```
