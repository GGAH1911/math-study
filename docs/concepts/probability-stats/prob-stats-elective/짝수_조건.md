### 정확한 진술

$n$개의 서로 다른 원소 중에서 **짝수 개**의 원소를 선택하는 경우의 수는 $2^{n-1}$이다. 즉, $\binom{n}{0} + \binom{n}{2} + \binom{n}{4} + \cdots = 2^{n-1}$ (단, $n \geq 1$).

### 직관과 유도

이항정리로부터 두 식을 세운다:

$$\sum_{k=0}^{n} \binom{n}{k} = (1+1)^n = 2^n$$

$$\sum_{k=0}^{n} (-1)^k \binom{n}{k} = (1-1)^n = 0 \quad (n \geq 1)$$

두 식을 더하면 홀수 항은 소거되고:

$$2\left(\binom{n}{0} + \binom{n}{2} + \binom{n}{4} + \cdots\right) = 2^n$$

따라서 **짝수 개 선택의 경우의 수**는:

$$\binom{n}{0} + \binom{n}{2} + \binom{n}{4} + \cdots = 2^{n-1}$$

직관적으로, $2^n$가지 부분집합 중 정확히 절반이 짝수 개의 원소를 가진다는 의미이다.

### 예제

5개의 서로 다른 원소에서 짝수 개를 선택:

$$\binom{5}{0} + \binom{5}{2} + \binom{5}{4} = 1 + 10 + 5 = 16 = 2^{5-1}$$

(`sympy.binomial(5, 0) + sympy.binomial(5, 2) + sympy.binomial(5, 4)` 검산 결과: 16)

마찬가지로 홀수 개 선택 $\binom{5}{1} + \binom{5}{3} + \binom{5}{5} = 5 + 10 + 1 = 16$도 동일한 값이다.
