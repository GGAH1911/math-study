### 정확한 진술

수열 $a_1, a_2, \ldots, a_n$이 **비감소 수열**이라는 것은 모든 인접한 두 항에 대해 앞항이 뒷항보다 작거나 같은 수열을 의미합니다. 즉, 다음을 만족합니다:

$$a_1 \le a_2 \le a_3 \le \cdots \le a_n$$

비감소 수열의 각 항은 같을 수도 있고 커질 수도 있지만, 절대 감소하지 않습니다.

### 직관과 의미

비감소 수열은 마치 계단을 올라가는 것처럼 생각할 수 있습니다. 각 계단은 이전 계단보다 높거나 같은 높이를 유지합니다. 예를 들어 일일 누적 판매액, 누적 강수량, 혹은 시간에 따른 사람의 키 변화처럼 현실에서도 비감소 수열이 자주 나타납니다.

경우의 수와의 연결에서 특히 중요한데, "중복을 허용하여 작은 것부터 큰 것 순서로 선택하는 경우의 수"를 구할 때 비감소 수열의 개수를 세는 것으로 문제를 변환할 수 있습니다. 예를 들어, 1부터 5까지의 숫자 중에서 중복을 허용하여 3개를 선택하는 경우의 수는, 선택한 숫자들을 작은 순서대로 정렬했을 때의 비감소 수열 개수와 같습니다.

### 예제

$2, 2, 5, 7, 7, 7, 9$는 비감소 수열입니다 ($2 \le 2 \le 5 \le 7 \le 7 \le 7 \le 9$).

반면 $3, 5, 4, 6$은 비감소 수열이 아닙니다. 왜냐하면 $5 > 4$이기 때문입니다.

**비감소 수열 개수 검산**: 1부터 3까지의 숫자를 중복을 허용하여 2개 선택하는 비감소 수열은 $(1,1), (1,2), (1,3), (2,2), (2,3), (3,3)$로 6개입니다. 이는 중복조합 $\binom{3+2-1}{2} = \binom{4}{2} = 6$과 일치합니다. (`from sympy import binomial; binomial(4, 2)`)
