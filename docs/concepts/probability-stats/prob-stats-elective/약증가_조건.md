### 정확한 진술

수열 $a_1, a_2, \ldots, a_n$이 **약증가 조건**을 만족한다는 것은 다음을 의미합니다:

$$a_1 \leq a_2 \leq a_3 \leq \cdots \leq a_n$$

즉, 앞 항이 뒤 항보다 작거나 같다는 조건입니다. 등호가 포함되므로 "약(弱)"이라고 부르며, 엄격한 부등호 $<$를 사용하면 **순증가 조건**이라고 합니다.

### 직관 및 기하적 의미

약증가 조건은 경우의 수, 특히 **중복조합**과 매우 밀접합니다. 집합 $\{1, 2, \ldots, n\}$에서 중복을 허용하여 $r$개를 선택한 뒤 순서대로 정렬하면 약증가 수열이 됩니다. 예를 들어, $\{1, 2, 3\}$에서 중복을 허용하여 2개를 뽑으면:

$$(1,1), (1,2), (1,3), (2,2), (2,3), (3,3)$$

모두 약증가 형태입니다. 이렇게 **"약증가 수열의 개수" = "중복조합"**이라는 관계가 성립하므로, 중복조합 공식 $H(n, r) = \binom{n+r-1}{r}$로 즉시 계산할 수 있습니다.

### 계산 예제

1부터 5까지의 숫자 중에서 중복을 허용하여 3개를 선택하되 약증가 수열로 나열하는 경우의 수:

$$H(5, 3) = \binom{5+3-1}{3} = \binom{7}{3} = 35$$

`sympy.binomial(7, 3)` = 35

구체 예: $(1,1,1), (1,1,2), (1,1,3), \ldots, (5,5,5)$ 중 $(2,3,5)$는 약증가, $(3,2,5)$는 약증가 아님.

약증가 조건은 수능 확률과 통계, 조합론 문제에서 **자주 등장하는 핵심 개념**입니다.
