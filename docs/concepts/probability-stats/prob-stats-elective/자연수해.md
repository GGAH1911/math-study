### 정확한 진술

방정식이나 부등식의 **해 중에서 자연수인 것**을 자연수해라고 부릅니다. 자연수는 $\{1, 2, 3, \ldots\}$를 의미합니다(0 제외).

### 직관과 의미

현실 문제에서는 "개수", "금액", "시간(미래)" 같은 **양수 정수만 의미**가 있습니다.
- "몇 개의 상자에 담으면..." → 음수나 0개는 불가능
- "몇 년 후..." → 음수 시간은 해석 불가
- 경우의 수 → 항상 자연수

따라서 전체 실수 해가 아닌, **자연수 범위 내의 해만 찾는 제약**이 생깁니다. 이는 순수한 수학적 기법이 아니라 문제의 **현실적 조건**을 반영한 것입니다.

### 예시

**방정식의 경우**: 
$x^2 - 5x + 6 = 0$을 풀면 일반 해는 $x = 2$ 또는 $x = 3$이고, 둘 다 자연수이므로 자연수해는 **$2, 3$**입니다.

**부등식의 경우**: 
$x^2 - 5x + 4 < 0$의 일반 해는 $1 < x < 4$인데, 이를 만족하는 자연수해는 **$2, 3$**입니다.

**응용 예시**: 두 자연수의 합이 7이고 곱이 10일 때 두 수는? 
두 수를 $x, y$라 하면 $x + y = 7$, $xy = 10$에서 근과 계수의 관계로 $t^2 - 7t + 10 = 0$, 즉 $t = 2$ 또는 $5$이므로 자연수해는 **2와 5**입니다.

`sympy.solve(x**2 - 5*x + 6, x)` → [2, 3]
