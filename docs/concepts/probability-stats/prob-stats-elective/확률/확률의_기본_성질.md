# 확률의 기본 성질

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
확률의 기본 성질은 모든 확률이 반드시 만족해야 하는 세 가지 공리로, 모든 확률의 계산과 성질을 유도하는 기초가 됩니다.

## 본문
표본공간을 $S$, 사건을 $A, B, \ldots$라고 할 때, 확률은 다음 세 가지 조건을 만족해야 합니다. 첫째, 모든 사건 $A$에 대하여 $P(A) \geq 0$입니다. 둘째, 전체사건의 확률은 $P(S) = 1$입니다. 셋째, 서로 배타적인 사건 $A, B$ (즉 $A \cap B = \emptyset$)에 대하여 $P(A \cup B) = P(A) + P(B)$가 성립합니다. 이 세 가지 공리는 확률론의 근간을 이루며, 이를 통해 여사건의 확률 $P(A^c) = 1 - P(A)$, 불가능사건의 확률 $P(\emptyset) = 0$, 그리고 일반적인 합사건의 확률인 포함-배제 원리 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$를 유도할 수 있습니다.

### 직관과 기하적 의미
첫 번째 조건은 확률이 음수가 될 수 없다는 상식을 나타내며, 두 번째 조건은 어떤 사건이 반드시 일어날 확률은 1이라는 보장을 의미합니다. 세 번째 조건은 겹치지 않는 두 상황이 동시에 일어날 수 없을 때, 두 사건 중 하나가 일어날 확률은 각각의 확률을 합한 것과 같다는 직관을 수식화한 것입니다.

### 기본 성질
주사위를 던지는 실험에서 짝수가 나올 확률을 구할 때, 사건 $\{2\}, \{4\}, \{6\}$은 서로 배타적이므로 가법성을 적용하여 $P(\text{짝수}) = P(\{2\}) + P(\{4\}) + P(\{6\}) = \tfrac{1}{6} + \tfrac{1}{6} + \tfrac{1}{6} = \tfrac{1}{2}$로 계산할 수 있습니다.

## 학습 체크
- 모든 확률의 값이 0 이상이어야 하는 이유는 무엇인가?
- 사건 $A$와 그 여사건 $A^c$의 확률을 더하면 왜 항상 1이 되는가?
- 두 사건이 서로 배타적이지 않을 때 합사건의 확률을 구하는 공식은 무엇인가?

## 관련 개념
- **확률**: 확률의 기본 성질은 확률의 정의를 구성하는 핵심 공리로서, 모든 확률 계산의 출발점이 됩니다.
