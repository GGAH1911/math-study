### 정확한 진술

두 사건 $A$, $B$에 대해 $A$ 또는 $B$가 일어날 확률은 다음과 같습니다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

일반적으로 $n$개의 사건 $A_1, A_2, \ldots, A_n$에 대해서는 포함-배제 원리(inclusion-exclusion principle)를 적용합니다. 예를 들어 세 사건의 경우:

$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(B \cap C) - P(C \cap A) + P(A \cap B \cap C)$$

### 직관과 기하적 의미

벤 다이어그램으로 생각하면, 합집합 $A \cup B$의 확률을 구할 때 $P(A)$와 $P(B)$를 더하면 겹치는 영역 $A \cap B$가 두 번 계산됩니다. 따라서 중복을 제거하기 위해 $P(A \cap B)$를 한 번 빼야 합니다.

**특수한 경우**: 두 사건이 서로소(mutually exclusive, 동시에 일어날 수 없음)이면 $P(A \cap B) = 0$이므로:
$$P(A \cup B) = P(A) + P(B)$$

이 경우를 덧셈 정리(addition rule)라고 부르기도 합니다.

### 간단한 예

주사위를 한 번 던질 때, $A$ = "짝수", $B$ = "3의 배수"라 하면:
- $P(A) = \frac{3}{6}$ (2, 4, 6)
- $P(B) = \frac{2}{6}$ (3, 6)  
- $P(A \cap B) = \frac{1}{6}$ (6)

따라서:
$$P(A \cup B) = \frac{3}{6} + \frac{2}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$$

검산: $A \cup B$ = {2, 3, 4, 6}이므로 $P(A \cup B) = \frac{4}{6}$ ✓
