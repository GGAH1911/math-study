# 배반사건

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
두 사건이 동시에 일어날 수 없어 교집합이 공집합인 상태를 의미합니다.

## 본문
두 사건 $A$와 $B$가 배반사건이라는 것은 두 사건이 동시에 일어날 수 없음을 뜻하며, 수학적으로는 $A \cap B = \emptyset$을 만족합니다. 이를 확장하여 여러 사건 $A_1, A_2, \ldots, A_n$에 대해 임의의 두 사건을 선택했을 때 항상 $A_i \cap A_j = \emptyset$ ($i \neq j$)이면 이 사건들은 서로 배반이라고 합니다. 만약 이 사건들이 표본공간 $S$를 겹치는 부분 없이 완전히 분할한다면, 모든 사건의 합집합은 표본공간과 같고($A_1 \cup A_2 \cup \cdots \cup A_n = S$), 임의의 두 사건의 교집합은 공집합이어야 합니다.

### 직관과 기하적 의미
벤 다이어그램으로 시각화했을 때, 배반사건은 두 영역이 서로 겹치지 않고 떨어져 있는 형태를 띱니다. 실생활의 예로 동전을 한 번 던질 때 발생하는 "앞면"과 "뒷면"은 동시에 나타날 수 없으므로 배반사건입니다.

### 기본 성질
배반사건의 핵심 성질은 확률의 덧셈 법칙이 단순화된다는 점입니다. 일반적인 사건의 합집합 확률은 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$이지만, 두 사건이 배반사건이면 교집합의 확률이 $0$이 되므로 $P(A \cup B) = P(A) + P(B)$가 성립합니다.

## 학습 체크
- 두 사건의 교집합이 공집합인지 확인했는가?
- 사건의 합집합이 표본공간 전체를 포함하는지 확인했는가?
- 주사위 예시처럼 공통 원소가 존재하는지 주의했는가?

## 관련 개념
- **확률**: 배반사건일 경우 합집합의 확률을 구할 때 교집합의 확률을 뺄 필요 없이 각 사건의 확률을 단순히 더하면 됩니다.
