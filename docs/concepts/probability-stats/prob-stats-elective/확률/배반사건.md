# 배반사건

## 정확한 진술

두 사건 $A$와 $B$가 **배반사건**이라는 것은 두 사건이 동시에 일어날 수 없다는 뜻입니다. 즉, $A \cap B = \emptyset$을 만족합니다. 

더 일반적으로, 여러 사건 $A_1, A_2, \ldots, A_n$이 **서로 배반**이라 하면, 임의의 두 개를 선택했을 때 항상 $A_i \cap A_j = \emptyset$ (단, $i \neq j$)입니다. 

또한 이들이 표본공간 $S$를 **완전히 분할**하면(전체를 겹치지 않게 나눔), 다음을 만족합니다:
$$A_1 \cup A_2 \cup \cdots \cup A_n = S \text{ 이고 } A_i \cap A_j = \emptyset \text{ (단, } i \neq j\text{)}$$

## 직관과 기하적 의미

벤 다이어그램으로 보면, 배반사건은 두 영역이 겹치지 않습니다. 실생활로는 동전을 한 번 던질 때 "앞면"과 "뒷면"이 배반사건입니다. 둘 다 일어날 수는 없으니까요.

배반사건의 가장 중요한 성질은 **확률의 덧셈 법칙**입니다: 
$$P(A \cup B) = P(A) + P(B)$$

이는 배반이 아닌 일반 사건에서는 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$이므로, 겹치는 부분이 없을 때만 단순히 더할 수 있다는 뜻입니다.

## 예시

주사위를 한 번 던질 때, 사건 $A$ = "3의 배수가 나온다" = $\{3, 6\}$과 사건 $B$ = "홀수가 나온다" = $\{1, 3, 5\}$는 배반사건이 아닙니다. (3이 공통으로 있음) 

반면, 사건 $A'$ = "짝수가 나온다" = $\{2, 4, 6\}$과 사건 $B'$ = "홀수가 나온다" = $\{1, 3, 5\}$는 배반사건입니다. 따라서 $P(A' \cup B') = \frac{3}{6} + \frac{3}{6} = 1$.
