# 표본공간과 사건

## 정확한 진술

어떤 시행(실험)에서 나올 수 있는 **모든 가능한 결과들의 집합**을 **표본공간**(sample space)이라 하고, 보통 $S$로 표기합니다. 표본공간에 속하는 각 결과를 **표본점**(sample point)이라 합니다.

표본공간의 부분집합 중에서 **특정 조건을 만족하는 결과들의 모임**을 **사건**(event)이라 합니다. 예를 들어 사건 $A$는 $A \subseteq S$를 만족합니다.

특히 어느 한 개의 표본점만으로 이루어진 사건을 **근원사건**(elementary event)이라 하고, 표본공간 $S$ 전체를 **전사건**, 공집합 $\emptyset$을 **공사건**이라 합니다.

## 직관/기하적 의미

표본공간은 "일어날 수 있는 모든 경우"를 담는 그릇입니다. 주사위를 던지면 $S = \{1, 2, 3, 4, 5, 6\}$이고, 동전을 두 번 던지면 $S = \{HH, HT, TH, TT\}$입니다.

사건은 표본공간 안에서 우리가 관심 있는 부분입니다. "짝수가 나온다" 같은 조건은 사건 $A = \{2, 4, 6\}$으로 표현됩니다. 나중에 확률을 정의할 때 $P(A) = \frac{|A|}{|S|}$처럼 사건의 크기와 전체를 비교합니다.

이 기초 위에서 두 사건의 합집합 $A \cup B$ (또는 사건), 교집합 $A \cap B$ (그리고 사건), 여집합 $A^c$ (여사건) 같은 사건 간의 관계를 다루게 됩니다.

## 한 줄 예

주사위를 한 번 던지는 시행에서 표본공간 $S = \{1, 2, 3, 4, 5, 6\}$, 사건 $A = \{\text{3의 배수}\} = \{3, 6\}$, 근원사건 $\{4\}$입니다.
