# 원탁 배치

## 정확한 진술

구별되는 $n$명의 사람을 원탁에 앉히되, **회전으로 같은 배치는 같은 것으로 간주**할 때의 경우의 수를 **원탁 배치(circular arrangement)**라고 합니다. 이 경우의 수는 $**(n-1)!**$입니다.

일반적으로, 구별되는 $n$개의 원소를 원형으로 배열하는 경우의 수는 $(n-1)!$으로 계산합니다.

## 직관과 유도

일렬 배치와의 차이를 생각해봅시다. 만약 $n$명을 **일렬**로 앉히면 $n!$가지입니다. 하지만 원탁은 시작점이 정해져 있지 않으므로, 같은 상대적 순서를 가지는 배치는 회전을 통해 같아집니다.

예를 들어 A, B, C, D 네 명이 원탁에 앉아있다면:
- (A-B-C-D) → (B-C-D-A) → (C-D-A-B) → (D-A-B-C)  

이 네 가지는 모두 같은 배치입니다. 즉, 일렬 배치의 $n!$에서 $n$가지 회전 배치를 하나로 취급해야 하므로, $\dfrac{n!}{n} = (n-1)!$이 됩니다.

**기하적으로**: 원탁의 한 자리를 고정(예: A를 맨 위에 고정)하면, 나머지 $n-1$명을 배치하는 경우의 수는 $(n-1)!$입니다. 이것이 원탁 배치의 본질입니다.

## 한 줄 예

5명을 원탁에 앉히는 경우의 수: $(5-1)! = 4! = 24$가지 (검증: `sympy.factorial(4)`)
