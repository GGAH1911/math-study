### 정확한 진술

어떤 시행(실험)의 모든 가능한 결과를 모은 집합을 **표본공간** $S$라 합니다. 표본공간의 부분집합을 **사건**이라 합니다. 사건 $A$가 일어날 확률 $P(A)$는 다음과 같이 정의합니다.

$$P(A) = \frac{\text{사건 } A \text{에 속한 경우의 수}}{\text{표본공간 } S \text{의 전체 경우의 수}}$$

단, 표본공간의 각 원소(근원사건)가 일어날 가능성이 모두 같을 때(동일한 확률) 성립합니다. 이를 **고전적 확률**이라 합니다.

### 직관적 의미

확률은 "어떤 일이 일어날 가능성의 크기"를 0 이상 1 이하의 수로 나타낸 것입니다. 확률이 0에 가까울수록 일어나기 어렵고, 1에 가까울수록 일어나기 쉽습니다. 기하적으로는 **표본공간이라는 전체 영역 안에서 사건 $A$가 차지하는 영역의 비율**입니다. 

예를 들어 동전을 던질 때 표본공간 $S = \{\text{앞}, \text{뒤}\}$이고, "앞이 나올 사건" $A = \{\text{앞}\}$이면 확률은 $\frac{1}{2}$입니다. 이는 동전을 충분히 많이 던질 때 약 절반이 앞면이 나온다는 의미입니다.

### 한 줄 예

표준 주사위를 던질 때 "6이 나올 확률"은 $P(\{6\}) = \frac{1}{6}$이고, "3 이상의 눈이 나올 확률"은 $P(\{3, 4, 5, 6\}) = \frac{4}{6} = \frac{2}{3}$입니다. (`sympy.Rational(4, 6)`)
