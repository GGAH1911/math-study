# 기댓값과분산

## 정확한 진술

확률변수 $X$가 취할 수 있는 값들이 $x_1, x_2, \ldots, x_n$이고 각각의 확률이 $p_1, p_2, \ldots, p_n$일 때, **기댓값**(또는 **평균**)은 다음과 같이 정의됩니다:

$$E(X) = \sum_{i=1}^{n} x_i p_i$$

**분산**은 확률변수가 기댓값으로부터 얼마나 떨어져 있는지를 나타내며, 다음과 같이 정의됩니다:

$$V(X) = E((X - E(X))^2) = E(X^2) - (E(X))^2$$

**표준편차**는 분산의 양의 제곱근이므로 $\sigma(X) = \sqrt{V(X)}$입니다.

## 직관과 의미

기댓값은 확률을 가중치로 한 산술평균입니다. 만약 같은 확률실험을 매우 많이 반복한다면, 얻은 값들의 평균은 기댓값에 점점 가까워집니다.

분산은 데이터가 기댓값 주변에 얼마나 흩어져 있는지를 재는 척도입니다. 분산이 작으면 대부분의 값이 기댓값 근처에 모여 있고, 분산이 크면 값들이 기댓값에서 멀리 떨어진 경우가 많다는 뜻입니다.

## 간단한 예

주사위를 던질 때 나오는 눈의 수를 $X$라 하면, 각 결과가 $\frac{1}{6}$의 확률을 가지므로:

$$E(X) = \frac{1}{6}(1 + 2 + 3 + 4 + 5 + 6) = 3.5$$

$$V(X) = E(X^2) - (E(X))^2 = \frac{1}{6}(1 + 4 + 9 + 16 + 25 + 36) - 3.5^2 = 12.25 - 12.25 = \frac{35}{12}$$

검증: `sum([i**2 for i in range(1,7)])/6 - 3.5**2`는 약 2.917입니다.
