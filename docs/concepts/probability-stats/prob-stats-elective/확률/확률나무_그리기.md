# 확률나무 그리기

> **예제** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
확률나무를 이용하여 복합 사건의 확률을 시각화하고 각 단계의 확률을 곱하여 계산합니다.

## 본문
상자 A에는 빨간 공 2개, 흰 공 1개가 들어있고, 상자 B에는 빨간 공 1개, 흰 공 2개가 들어있다. 상자 A에서 공 1개를 꺼낸 후 상자 B에서 공 1개를 꺼낼 때, 꺼낸 두 공이 모두 빨간 공일 확률을 구하시오.

### 단계별 풀이
**1단계: 첫 번째 선택 (상자 A)**
상자 A의 공 3개 중에서 빨간 공이 나올 확률은 $\frac{2}{3}$, 흰 공이 나올 확률은 $\frac{1}{3}$입니다.

**2단계: 두 번째 선택 (상자 B)**
상자 B의 공 3개 중에서 빨간 공이 나올 확률은 $\frac{1}{3}$, 흰 공이 나올 확률은 $\frac{2}{3}$입니다.

**3단계: 확률나무 그리기**
```
상자 A에서의 선택
   /            \
빨강(2/3)      흰색(1/3)
  |              |
상자 B의 선택   상자 B의 선택
 /  \           /  \
빨강 흰색     빨강 흰색
1/3 2/3       1/3 2/3
```

**4단계: 모든 경로의 확률 계산**
확률나무의 각 경로는 위에서 아래로 이동하며, 경로의 확률은 각 단계의 확률을 곱하여 구합니다.
- (A 빨강, B 빨강): $\frac{2}{3} \times \frac{1}{3} = \frac{2}{9}$
- (A 빨강, B 흰색): $\frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$
- (A 흰색, B 빨강): $\frac{1}{3} \times \frac{1}{3} = \frac{1}{9}$
- (A 흰색, B 흰색): $\frac{1}{3} \times \frac{2}{3} = \frac{2}{9}$
모든 확률의 합은 $\frac{2}{9} + \frac{4}{9} + \frac{1}{9} + \frac{2}{9} = 1$이 되어 계산이 정확함을 확인할 수 있습니다.

### 답과 변형
**답**: 두 공이 모두 빨간 공일 확률은 $\dfrac{2}{9}$입니다.

**변형 및 주의사항**
- **핵심 원리**: 한 경로의 확률은 각 단계의 확률을 모두 곱한 값이며, 여러 사건이 동시에 일어나는 경우 각 경로의 확률을 더하여 구합니다.
- **응용 예시**: 만약 "최소 1개가 빨강일 확률"을 구한다면, 빨간 공이 포함된 세 가지 경로의 확률을 모두 더한 $\frac{7}{9}$가 답이 됩니다.
- **확장 적용**: 단계가 늘어나거나, 공을 다시 넣지 않는 조건처럼 단계마다 확률이 변하는 경우에도 동일한 나무 구조를 사용하여 계산할 수 있습니다.

## 학습 체크
- 각 단계의 확률을 곱하여 하나의 경로에 대한 확률을 구할 수 있는가?
- 구하고자 하는 조건에 해당하는 경로를 나무에서 정확히 찾아낼 수 있는가?
- 조건부 확률이 포함된 복합적인 상황에서도 확률나무를 그릴 수 있는가?

## 관련 개념
- **확률**: 사건이 일어날 가능성을 수치로 나타낸 것으로, 확률나무는 이 수치들을 시각적으로 연결하여 복합적인 사건의 확률을 계산하는 도구가 됩니다.
