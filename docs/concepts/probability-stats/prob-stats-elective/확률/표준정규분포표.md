# 표준정규분포표

## 정확한 진술

표준정규분포표는 표준정규분포 $N(0,1)$을 따르는 확률변수 $Z$에 대해, $P(Z \leq z)$의 값(누적확률)을 미리 계산하여 정리한 표입니다. 즉, 주어진 $z$값에 대해 표준정규분포의 누적분포함수(CDF) 값을 나타냅니다.

## 직관과 기하적 의미

정규분포를 따르는 확률변수를 표준화(standardization)하면 평균 0, 표준편차 1인 표준정규분포가 됩니다. 확률을 구하려면 다음 식을 계산해야 합니다:

$$P(Z \leq z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}} e^{-t^2/2} dt$$

이 적분은 초등함수로 표현할 수 없으므로, 실무와 시험에서는 미리 계산된 표를 참조합니다. 표에서 $z$값을 찾으면 대응하는 누적확률을 즉시 얻을 수 있어, 복잡한 확률 문제를 빠르게 해결할 수 있습니다.

표의 값은 종 모양 정규분포 곡선의 왼쪽부터 해당 $z$까지의 면적(기하적으로는 그래프 아래의 넓이)을 의미합니다. 이를 통해 "이 점수 이하일 확률은 몇 %인가?"와 같은 실제 문제를 단 몇 초에 풀 수 있습니다.

## 한 줄 예시

$Z = 1.96$일 때 표준정규분포표에서 0.975를 읽으므로, $P(Z \leq 1.96) = 0.975$입니다.
