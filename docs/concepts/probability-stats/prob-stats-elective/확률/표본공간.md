# 표본공간

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 정확한 진술

표본공간(sample space)은 어떤 확률시행(random experiment)을 시행했을 때 나타날 수 있는 **모든 결과의 집합**입니다. 보통 $S$ 또는 $\Omega$로 나타냅니다. 표본공간의 각 원소를 **표본점(sample point)**이라고 부르며, 표본점의 개수를 $n(S)$로 표기합니다.

예를 들어 주사위를 한 번 던지는 시행에서 표본공간은 $S = \{1, 2, 3, 4, 5, 6\}$이고, $n(S) = 6$입니다.

## 직관과 의미

표본공간은 확률을 정의하는 **기반**입니다. 확률시행을 할 때 "무엇이 일어날 수 있는가?"를 먼저 정확히 파악해야만 각 사건(event)이 일어날 확률을 구할 수 있습니다. 

표본공간을 명확히 하는 것은 문제를 풀기 전에 꼭 필요한 단계입니다. 예를 들어:
- **동전 2개를 던질 때**: $S = \{HH, HT, TH, TT\}$ (앞면을 H, 뒷면을 T로 표기)
- **카드 1장을 뽑을 때**: 카드의 무늬를 구분하면 $n(S) = 52$, 숫자만 보면 $n(S) = 13$

같은 상황이라도 **어떤 정보를 기록하는지**에 따라 표본공간이 달라집니다. 문제에서 "무엇을 구하는가"를 확인한 후 적절한 표본공간을 정의하는 습관이 중요합니다.

## 한 줄 예

주사위 2개를 동시에 던질 때, 표본공간은 $S = \{(1,1), (1,2), \ldots, (6,6)\}$이고 $n(S) = 36$입니다.
