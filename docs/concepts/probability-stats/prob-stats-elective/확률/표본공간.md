# 표본공간

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
표본공간은 어떤 확률시행을 했을 때 나타날 수 있는 모든 결과의 집합을 의미합니다.

## 본문
표본공간(sample space)은 어떤 확률시행(random experiment)을 시행했을 때 나타날 수 있는 모든 결과의 집합입니다. 보통 $S$ 또는 $\Omega$로 나타내며, 표본공간의 각 원소를 표본점(sample point)이라고 부릅니다. 표본점의 개수는 $n(S)$로 표기합니다. 예를 들어 주사위를 한 번 던지는 시행에서 표본공간은 $S = \{1, 2, 3, 4, 5, 6\}$이고, $n(S) = 6$입니다.

### 직관과 의미
표본공간은 확률을 정의하는 기반입니다. 확률시행을 할 때 "무엇이 일어날 수 있는가?"를 먼저 정확히 파악해야만 각 사건(event)이 일어날 확률을 구할 수 있습니다. 표본공간을 명확히 하는 것은 문제를 풀기 전에 꼭 필요한 단계입니다. 예를 들어 동전 2개를 던질 때, 앞면을 $H$, 뒷면을 $T$로 표기하면 $S = \{HH, HT, TH, TT\}$가 됩니다. 카드 1장을 뽑을 때도 카드의 무늬를 구분하면 $n(S) = 52$, 숫자만 보면 $n(S) = 13$이 됩니다. 이처럼 같은 상황이라도 어떤 정보를 기록하는지에 따라 표본공간이 달라지므로, 문제에서 구하고자 하는 바에 맞춰 적절한 표본공간을 정의하는 습관이 중요합니다.

### 기본 성질
표본공간은 시행에서 발생 가능한 모든 결과들을 빠짐없이 포함해야 합니다. 주사위 2개를 동시에 던질 때의 예시처럼, 결과가 순서에 따라 달라진다면 $S = \{(1,1), (1,2), \ldots, (6,6)\}$과 같이 모든 조합을 포함해야 하며 이때 $n(S) = 36$이 됩니다.

## 학습 체크
- 확률시행에서 발생 가능한 모든 결과를 빠짐없이 나열했는가?
- 문제의 조건에 따라 표본공간의 원소를 어떻게 정의할 것인가?

## 관련 개념
- **확률**: 표본공간 내의 특정 사건이 일어날 가능성을 수치로 나타낸 것입니다.
