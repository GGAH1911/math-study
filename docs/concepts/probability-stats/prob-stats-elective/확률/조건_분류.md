# 조건 분류

## 정확한 진술

조건이 주어졌을 때, 표본공간(전체 경우의 수)을 조건을 만족하는 경우와 만족하지 않는 경우로 나누어 분류하는 것을 **조건 분류**라고 합니다. 어떤 조건 $A$가 주어졌을 때, 전체 표본공간 $S$에서 조건 $A$를 만족하는 부분집합을 $A$, 만족하지 않는 부분집합을 $A^c$로 나누면, $S = A \cup A^c$이고 $A \cap A^c = \emptyset$입니다.

## 직관/기하적 의미

조건 분류는 주어진 조건에 따라 전체 경우의 수를 **체계적으로 구분**하는 과정입니다. 예를 들어 "두 개의 주사위를 던질 때"라는 전체 상황에서 "첫 번째 주사위가 3 이상"이라는 조건이 주어지면, 표본공간이 조건을 만족하는 경우와 만족하지 않는 경우로 자동으로 나뉩니다. 이렇게 조건에 따라 경우의 수를 구분하면, 각 조건 아래에서 구체적인 사건이 일어날 확률을 더 정확하게 계산할 수 있습니다. 또한 여러 개의 조건이 함께 주어질 때는 조건들 사이의 교집합과 합집합을 파악하여 전체 경우를 빠짐없이, 중복 없이 분류할 수 있습니다. 이는 나중에 배우는 조건부 확률의 기초를 이룹니다.

## 한 줄 예

1부터 10까지의 자연수 중에서 "3의 배수"라는 조건으로 분류하면, 조건을 만족하는 경우는 $\{3, 6, 9\}$이고 만족하지 않는 경우는 $\{1, 2, 4, 5, 7, 8, 10\}$입니다. 이 두 집합은 겹치지 않으면서 합쳐지면 원래의 표본공간이 됩니다.
