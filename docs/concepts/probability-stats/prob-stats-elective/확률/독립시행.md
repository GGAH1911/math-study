# 독립시행

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
각 시행의 결과가 다음 시행의 결과에 아무런 영향을 미치지 않고, 매 시행마다 사건이 일어날 확률이 일정하게 유지되는 시행을 의미합니다.

## 본문
같은 시행을 여러 번 반복할 때, 각 시행의 결과가 다른 시행들의 결과에 영향을 주지 않는 경우를 독립시행이라 합니다. 더 정확히 말하면, 한 번의 시행에서 어떤 사건 $A$가 일어날 확률을 $p$라 할 때, 이 시행을 $n$번 반복해도 매번 $A$가 일어날 확률은 항상 $p$로 일정하며, 어떤 회차의 결과도 다른 회차에 영향을 주지 않아야 합니다.

### 직관과 기하적 의미
주사위를 던지는 상황을 예로 들 수 있습니다. 첫 번째 던지기에서 6이 나왔다고 해서 두 번째 던지기에서 6이 나올 확률이 변하지 않으며, 매번 $\frac{1}{6}$로 일정합니다. 반면, 상자에서 공을 꺼낸 뒤 다시 넣지 않는 '비복원 추출'의 경우에는 남은 공의 개수가 변하므로 다음 시행의 확률에 영향을 주게 되어 독립시행이 성립하지 않습니다.

### 기본 성질
사건 $A$가 일어날 확률이 $p$인 독립시행을 $n$번 반복할 때, 사건 $A$가 정확히 $k$번 일어날 확률은 다음과 같은 식을 따릅니다.
$$P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$$
예를 들어, 동전을 5번 던질 때 앞면이 정확히 3번 나올 확률은 $\binom{5}{3}\left(\frac{1}{2}\right)^3\left(\frac{1}{2}\right)^2 = \frac{5}{16}$입니다.

## 학습 체크
- 각 시행의 결과가 이전 결과에 영향을 받는지 여부를 확인했는가?
- 매 시행마다 사건이 일어날 확률 $p$가 동일하게 유지되는가?
- 독립시행의 확률 공식에서 $n, k, p$의 값이 문제의 조건과 일치하는가?

## 관련 개념
- **확률**: 독립시행에서 각 시행마다 사건이 발생할 고정된 확률 $p$를 설정하는 기초가 됩니다.
- **이항분포**: 독립시행을 반복할 때 나타나는 확률 변수의 분포를 나타내며, 독립시행의 확률 공식이 이 분포의 확률 질량 함수가 됩니다.
