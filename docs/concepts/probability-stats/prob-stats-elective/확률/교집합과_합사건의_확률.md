# 교집합과 합사건의 확률

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 정확한 진술

두 사건 $A$와 $B$에 대해:

**교집합의 확률**: 사건 $A$와 $B$가 모두 일어날 확률을 $P(A \cap B)$로 나타냅니다.

**합사건의 확률**: 사건 $A$ 또는 $B$ 중 적어도 하나가 일어날 확률을 $P(A \cup B)$로 나타내며, 다음 공식을 만족합니다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

## 직관과 기하적 의미

벤 다이어그램으로 생각하면 명확합니다. 집합 $A$와 $B$를 원으로 그렸을 때, 교집합 $A \cap B$는 두 원이 겹치는 영역입니다. 합사건 $A \cup B$는 두 원이 차지하는 전체 영역입니다.

합사건의 확률을 구할 때 $P(A) + P(B)$로 단순히 더하면, 겹치는 부분(교집합)을 두 번 세게 됩니다. 따라서 중복으로 센 부분 $P(A \cap B)$를 한 번 빼주어야 합니다. 이를 **포함-배제 원리**(inclusion-exclusion principle)라고 부릅니다.

## 한 줄 예

주사위 한 번을 던질 때, $A$ = "3 이상의 수" = $\{3, 4, 5, 6\}$, $B$ = "짝수" = $\{2, 4, 6\}$이면, $A \cap B = \{4, 6\}$이므로 $P(A \cap B) = \frac{2}{6} = \frac{1}{3}$입니다. 합사건은 $P(A \cup B) = \frac{4}{6} + \frac{3}{6} - \frac{2}{6} = \frac{5}{6}$입니다. (검증: sympy로 확인하면 `len({3,4,5,6} | {2,4,6}) / 6 = 5/6`이 맞습니다.)
