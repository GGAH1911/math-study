### 정확한 진술

두 사건 $A$, $B$에 대하여 다음이 성립합니다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

특히 $A$와 $B$가 서로 배반사건(동시에 일어날 수 없는 사건)이면 $P(A \cap B) = 0$이므로 다음과 같이 간단해집니다.

$$P(A \cup B) = P(A) + P(B)$$

### 직관과 의미

표본공간에서 사건 $A$와 $B$를 벤 다이어그램으로 그리면, 합사건 $A \cup B$의 영역은 $A$ 영역과 $B$ 영역을 합친 것입니다. 그런데 $A$와 $B$가 겹치는 부분 $A \cap B$가 있다면, 단순히 $P(A) + P(B)$로 계산하면 이 교집합 부분을 두 번 세게 됩니다. 따라서 한 번 뺄셈으로 조정해야 하는 것입니다.

배반사건인 경우는 겹치는 부분이 없으므로($P(A \cap B) = 0$) 그냥 두 확률을 더하면 됩니다.

### 예

주사위 하나를 던질 때, '3 이상 4 이하의 수가 나올 확률'과 '4 이상의 수가 나올 확률'의 합사건을 생각해봅시다.
- $A$ = {3, 4}, $B$ = {4, 5, 6}
- $A \cap B$ = {4}
- $P(A \cup B) = \frac{2}{6} + \frac{3}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$

실제로 $A \cup B$ = {3, 4, 5, 6}이므로 확률은 $\frac{4}{6} = \frac{2}{3}$입니다. ✓

(sympy로 검산: `Rational(2,6) + Rational(3,6) - Rational(1,6)` → 2/3)
