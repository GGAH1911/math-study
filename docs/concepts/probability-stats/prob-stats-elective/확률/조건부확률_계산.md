# 조건부확률 계산

> **예제** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
주머니에서 공을 꺼낼 때, 첫 번째 결과가 다음 결과의 확률에 영향을 주는 비복원추출 상황에서의 조건부확률 계산법입니다.

## 본문
주머니에 흰 공 4개, 검은 공 3개가 들어있다. 공을 하나씩 꺼내어(뽑은 공은 다시 넣지 않음) 두 번 뽑는다. 첫 번째에 흰 공을 뽑았다는 조건 아래, 두 번째에 검은 공을 뽑을 확률을 구하시오.

### 단계별 풀이
**1단계: 상황 정리**
처음 상황은 흰 공 4개, 검은 공 3개로 총 7개다. 첫 번째에 흰 공을 뽑았다는 조건이 주어졌으므로, 이를 확정된 사실로 받아들인다.

**2단계: 조건 이후의 상황 파악**
첫 번째에 흰 공을 뽑은 후 주머니에 남은 공은 다음과 같다.
- 흰 공: $4 - 1 = 3$개
- 검은 공: 3개 (변하지 않음)
- 남은 총 공의 개수: $3 + 3 = 6$개

**3단계: 조건부확률 계산**
"첫 번째에 흰 공을 뽑은 상황"이 이미 일어났으므로, 두 번째 뽑기는 남은 6개의 공 중에서 일어난다. 따라서 구하고자 하는 확률은 다음과 같다.
$$P(\text{두 번째 검은 공} \mid \text{첫 번째 흰 공}) = \frac{\text{검은 공 개수}}{\text{남은 공 총 개수}} = \frac{3}{6} = \frac{1}{2}$$

### 답과 변형
$$\boxed{\frac{1}{2}}$$

**변형 예시**
첫 번째에 검은 공을 뽑았다면, 남은 공은 흰 공 4개와 검은 공 2개(총 6개)가 되어 두 번째 검은 공을 뽑을 확률은 $\tfrac{2}{6} = \tfrac{1}{3}$이 된다.

**주의 사항**
뽑은 공을 다시 넣지 않는 **비복원추출**에서는 앞선 사건이 다음 사건의 확률을 변화시키지만, 뽑은 공을 다시 넣는 **복원추출**에서는 각 사건이 독립적이므로 확률이 변하지 않는다.

## 학습 체크
- 비복원추출 상황에서 조건이 주어졌을 때 남은 표본 공간의 크기를 정확히 계산할 수 있는가?
- 조건부확률이 독립 사건과 어떻게 다른지 구분할 수 있는가?

## 관련 개념
- **확률**: 어떤 사건이 일어날 가능성을 수치로 나타낸 것으로, 조건부확률은 특정 사건이 일어났다는 전제하에 다른 사건이 일어날 확률을 다룬다.
