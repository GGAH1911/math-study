# 배수의 성질

## 정확한 진술

정수 $a, b$에 대해 **"$a$는 $b$의 배수이다"** 또는 **"$b$가 $a$를 나눈다"**는 다음을 의미합니다:

$$b = ka$$

를 만족하는 정수 $k$가 존재한다는 뜻입니다. 이를 기호로 $a \mid b$로 표기합니다.

배수 관계의 기본 성질들:
- **반사성**: 모든 자연수 $a$에 대해 $a \mid a$ (자신은 자신의 배수)
- **이행성**: $a \mid b$이고 $b \mid c$이면 $a \mid c$
- **선형성**: $a \mid b$이고 $a \mid c$이면, 모든 정수 $m, n$에 대해 $a \mid (mb + nc)$

## 직관적 의미

배수는 어떤 수를 정수 번 반복하여 더한 결과입니다. 예를 들어 3의 배수는 $3 \times 1 = 3$, $3 \times 2 = 6$, $3 \times 3 = 9$처럼 3씩 증가하는 수들입니다. 즉, 배수란 **"나누어떨어진다"**는 산술 구조를 나타냅니다.

특히 **선형성**이 핵심입니다. 어떤 수가 두 수의 배수라면, 그 두 수의 합이나 차도 배수가 됩니다. 이는 배수 판정 문제를 풀 때 원래 수들의 조합을 이용할 수 있다는 뜻으로, 나머지 계산이나 합동식(modular arithmetic) 같은 응용에서 매우 유용합니다.

## 한 줄 예

12는 3의 배수입니다. 왜냐하면 $12 = 3 \times 4$이므로 $3 \mid 12$이기 때문입니다.

확인: `[k for k in range(1, 13) if 12 % k == 0]` → [1, 2, 3, 4, 6, 12]
