### 정확한 진술

두 사건 $A$와 $B$에 대하여 다음이 성립합니다:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

특히, $A$와 $B$가 배반사건(동시에 일어날 수 없음)이면:

$$P(A \cup B) = P(A) + P(B)$$

### 직관적 의미

"$A$ 또는 $B$가 일어날 확률"을 구할 때, 단순히 $P(A) + P(B)$로 더하면 교집합 부분이 중복으로 계산됩니다. 따라서 중복 부분 $P(A \cap B)$를 한 번 빼야 정확한 값을 얻습니다. 벤 다이어그램으로 생각하면, 두 영역의 넓이 합에서 겹치는 부분을 다시 빼는 것과 같습니다.

배반사건인 경우 겹치는 부분이 없으므로($P(A \cap B) = 0$), 단순히 더하기만 하면 됩니다.

### 한 줄 예

주사위를 한 번 던질 때, "3의 배수 또는 4 이상의 수가 나올 확률"을 구하면: $A = \{3, 6\}$, $B = \{4, 5, 6\}$이므로 $A \cap B = \{6\}$입니다. 따라서 $P(A \cup B) = \frac{2}{6} + \frac{3}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$입니다.
