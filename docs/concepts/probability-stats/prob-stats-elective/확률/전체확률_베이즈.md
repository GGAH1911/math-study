# 전체확률 베이즈

> **정리** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
전체확률의 법칙과 베이즈 식

## 본문 (학습 시 채워짐)

### 진술 및 가정

표본공간 $\Omega$가 서로 배반인 사건들 $B_1, B_2, \ldots, B_n$으로 분할되어 있고, 각 $P(B_i) > 0$이라 하자. 임의의 사건 $A$에 대해 다음이 성립한다.

**전체확률의 법칙(Law of Total Probability):**
$$P(A) = \sum_{i=1}^{n} P(A \mid B_i) P(B_i)$$

**베이즈 정리(Bayes' Theorem):** $P(A) > 0$일 때,
$$P(B_j \mid A) = \frac{P(A \mid B_j) P(B_j)}{P(A)} = \frac{P(A \mid B_j) P(B_j)}{\sum_{i=1}^{n} P(A \mid B_i) P(B_i)}$$

### 유도 및 증명 스케치

조건부확률의 정의로부터 출발하자. $P(A \cap B_i) = P(A \mid B_i) P(B_i)$이고, $B_1, B_2, \ldots, B_n$이 표본공간의 완전한 분할을 이루므로:

$$A = \bigcup_{i=1}^{n} (A \cap B_i)$$

우변의 사건들은 쌍마다 배반이므로 확률의 덧셈 법칙에 의해:
$$P(A) = \sum_{i=1}^{n} P(A \cap B_i) = \sum_{i=1}^{n} P(A \mid B_i) P(B_i)$$

베이즈 정리는 조건부확률의 정의와 전체확률의 법칙을 결합하면 얻어진다:
$$P(B_j \mid A) = \frac{P(A \cap B_j)}{P(A)} = \frac{P(A \mid B_j) P(B_j)}{\sum_{i=1}^{n} P(A \mid B_i) P(B_i)}$$

### 의의 및 응용

전체확률의 법칙은 구하기 어려운 사건 $A$의 확률을 여러 경우 $B_i$로 나누어 계산하는 강력한 도구다. 실제 문제에서는 상황을 원인별로 분류하고 각 경우의 조건부확률을 안다면 전체 확률을 구할 수 있다.

베이즈 정리는 **역확률** 문제의 핵심이다. 새로운 정보 $A$를 관측했을 때, 원인 $B_j$가 실제로 일어났을 확률을 역으로 구하는 공식이다. 여기서 $P(B_j)$는 사전확률(prior), $P(A \mid B_j)$는 가능도(likelihood), $P(B_j \mid A)$는 사후확률(posterior)이라 부른다. 진단검사의 신뢰도, 스팸 필터링, 법정 증거 판단 등 실생활의 많은 분야에서 필수적으로 응용되는 강력한 확률 추론 도구다.
