# 경우의수

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
어떤 사건이나 상황에서 발생할 수 있는 모든 가능한 결과의 개수를 의미합니다.

## 본문
경우의 수는 어떤 사건이나 상황에서 일어날 수 있는 모든 가능한 경우들의 개수입니다. 예를 들어 주사위를 던질 때 나올 수 있는 결과가 $1, 2, 3, 4, 5, 6$이라면 경우의 수는 $6$이 됩니다. 수학적으로는 집합 $A$의 모든 원소의 개수를 세는 것과 같으며, $|A|$ 또는 $n(A)$로 표기합니다.

### 직관과 기하적 의미
경우의 수는 확률을 계산하기 위한 핵심적인 도구입니다. 확률은 특정 사건이 일어날 가능성을 수치화한 것으로, 다음과 같이 정의됩니다.
$$P(\text{사건}) = \frac{\text{원하는 경우의 수}}{\text{전체 경우의 수}}$$
따라서 어떤 결과가 나타날 가능성을 정확히 측정하기 위해서는 가능한 모든 경우를 빠짐없이 세는 과정이 반드시 선행되어야 합니다. 예를 들어 동전 2개를 동시에 던질 때 나올 수 있는 모든 경우는 $(\text{앞}, \text{앞}), (\text{앞}, \text{뒤}), (\text{뒤}, \text{앞}), (\text{뒤}, \text{뒤})$로 총 $4$가지입니다.

### 기본 성질
경우의 수를 구하는 데에는 두 가지 기본 원리가 적용됩니다. 첫째는 **합의 법칙**입니다. 사건 $A$의 경우의 수가 $m$이고 사건 $B$의 경우의 수가 $n$일 때, 두 사건이 동시에 일어나지 않는다면 $A$ 또는 $B$가 일어나는 경우의 수는 $m + n$입니다. 빨간 공 3개와 파란 공 2개 중 하나를 고르는 경우($3+2=5$)가 이에 해당합니다. 둘째는 **곱의 법칙**입니다. 어떤 사건이 두 단계로 연속하여 일어날 때, 첫 번째 단계의 경우의수가 $m$이고 두 번째 단계가 $n$이라면 전체 경우의 수는 $m \times n$입니다. 수를 먼저 선택하고(3가지) 문자를 선택하는(2가지) 경우($3 \times 2 = 6$)가 대표적입니다.

## 학습 체크
- 사건이 동시에 일어나는 상황인지, 아니면 별개로 일어나는 상황인지 구분할 수 있는가?
- 합의 법칙과 곱의 법칙 중 어떤 원리를 적용해야 하는지 판단할 수 있는가?

## 관련 개념
- **확률**: 경우의 수를 활용하여 특정 사건이 발생할 가능성을 수치로 나타낸 값입니다.
