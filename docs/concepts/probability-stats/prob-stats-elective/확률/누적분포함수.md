# 누적분포함수

> **정의** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
확률변수가 특정 값 $x$ 이하의 값을 가질 확률을 나타내는 함수입니다.

## 본문
확률변수 $X$에 대하여 누적분포함수(Cumulative Distribution Function, CDF)는 $F(x) = P(X \leq x)$로 정의됩니다. 이는 확률변수 $X$가 임의의 실수 $x$보다 작거나 같은 값을 가질 확률을 의미하며, 모든 실수 $x$에 대해 정의됩니다. 누적분포함수는 $F(-\infty) = 0$과 $F(\infty) = 1$이라는 성질을 반드시 만족해야 합니다.

### 직관과 기하적 의미
누적분포함수는 확률을 왼쪽에서 오른쪽으로 차례대로 더해 나가는 과정을 보여줍니다. 그래프상에서 특정 지점 $x$의 함숫값 $F(x)$는 수직선을 따라 $-\infty$부터 $x$까지 존재하는 모든 확률의 총합을 나타냅니다. 이산확률변수의 경우 확률이 특정 지점에서 점프하며 계단 모양으로 증가하는 형태를 보이고, 연속확률변수의 경우 그래프가 매끄럽게 이어지는 형태를 띱니다.

### 기본 성질
연속확률변수에서 누적분포함수 $F(x)$와 확률밀도함수 $f(x)$는 미분과 적분의 관계를 가집니다. 구체적으로 $F(x) = \int_{-\infty}^{x} f(t) \, dt$이며, 누적분포함수를 미분하면 확률밀도함수를 얻을 수 있습니다($F'(x) = f(x)$). 또한, 임의의 두 실수 $a, b$ ($a < b$)에 대하여 구간 $[a, b]$ 사이의 확률은 $P(a < X \leq b) = F(b) - F(a)$로 계산할 수 있어 구간 확률을 구하는 데 매우 유용합니다.

## 학습 체크
- 누적분포함수의 함숫값이 $1$을 초과하거나 $0$보다 작아질 수 있는가?
- 이산확률변수의 누적분포함수 그래프가 왜 계단 모양으로 나타나는가?
- 구간 확률 $P(a < X \leq b)$를 구할 때 왜 $F(a)$를 빼주는가?

## 관련 개념
- **확률**: 누적분포함수는 특정 범위 내에 확률변수가 존재할 확률을 누적하여 나타낸 함수입니다.
- **확률밀도함수**: 연속확률변수에서 누적분포함수를 미분하여 얻을 수 있는 함수입니다.
- **표준정규분포**: 누적분포함수 $\Phi(x)$를 통해 특정 범위의 확률을 표준화된 값으로 쉽게 계산할 수 있는 분포입니다.
