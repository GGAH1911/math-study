### 정확한 진술

정수 $a$와 $b$가 주어졌을 때, **$a$가 $b$를 나눈다** (또는 **$a$는 $b$의 약수**)는 것은 어떤 정수 $q$에 대해 $b = aq$가 성립함을 의미합니다. 이를 기호로 $a \mid b$로 나타내고, $a \nmid b$는 나누지 않음을 뜻합니다.

### 직관 및 의미

$a \mid b$는 "$b$를 $a$로 나누었을 때 나머지가 0이다"와 정확히 같은 뜻입니다. 예를 들어 $3 \mid 12$는 $12 = 3 \times 4$이므로 참이고, $3 \mid 13$은 거짓입니다. 이 관계는 정수론의 가장 기본이 되는 개념으로, 최대공약수, 최소공배수, 소수 판정 등 많은 중요한 성질들의 토대가 됩니다.

약수 관계는 **순서 관계**(부분 순서)를 정의합니다:
- 반사성: $a \mid a$ (모든 정수는 자기 자신을 나눔)
- 추이성: $a \mid b$이고 $b \mid c$이면 $a \mid c$
- 반대칭성: $a \mid b$이고 $b \mid a$이면 $a = \pm b$

### 한 줄 예

$2 \mid 10$이고 $10 \mid 100$이므로 $2 \mid 100$입니다. 또한 $(-3) \mid 12$도 성립합니다 (음수도 약수가 될 수 있음).

### 계산 검증

```python
# 예: a = 3, b = 12인 경우
# 12를 3으로 나누면 몫이 4, 나머지가 0
q = 12 // 3  # q = 4
remainder = 12 % 3  # remainder = 0
# 따라서 3 | 12
```
