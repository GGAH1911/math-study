### 정확한 진술

주어진 정의역과 치역, 그리고 특정 조건을 만족해야 하는 함수들의 개수를 구하는 것을 **조건부 함수의 개수**라고 합니다. 즉, 집합 $A$에서 집합 $B$로의 함수 중에서 "일대일 함수", "치역이 $B$와 같은 함수" 같은 특정 조건들을 동시에 만족하는 함수가 몇 개인지를 세는 것입니다.

### 직관과 의미

함수를 세는 문제는 단순한 "곱의 법칙"을 넘어섭니다. 정의역의 각 원소가 치역의 원소로 대응될 때, 추가 조건이 없다면 일반적인 함수의 개수는 $|B|^{|A|}$개입니다. 그러나 "서로 다른 원소는 서로 다른 상으로 대응되어야 한다" (일대일 함수), 또는 "치역의 모든 원소가 실제로 사용되어야 한다" (전사 함수) 같은 조건이 붙으면 상황이 달라집니다. 조건부 함수 개수는 이러한 **제약 조건 아래에서의 경우의 수**를 체계적으로 계산하는 방법입니다.

### 주요 경우들

**일대일 함수**: 정의역 $|A| = m$, 치역 $|B| = n$ (단, $m \leq n$)일 때, 일대일 함수의 개수는 $P(n, m) = \frac{n!}{(n-m)!}$

**전사 함수**: 정의역 $|A| = m$, 치역 $|B| = n$ (단, $m \geq n$)일 때, 전사 함수의 개수는 포함-배제 원리로 계산: $n! \cdot S(m, n)$ (여기서 $S(m, n)$은 스털링 수)

### 예시

정의역이 $\{1, 2, 3\}$, 치역이 $\{a, b, c, d\}$일 때 일대일 함수의 개수를 구하면, 첫 번째 원소는 4가지, 두 번째 원소는 3가지, 세 번째 원소는 2가지 선택 가능하므로 $4 \times 3 \times 2 = 24$개입니다.

(`from math import perm; perm(4, 3)` → 24)
