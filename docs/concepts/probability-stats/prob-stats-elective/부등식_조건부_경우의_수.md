### 정확한 진술

부등식 조건부 경우의 수는 **부등식이나 대소관계 등 특정 조건을 만족하면서 동시에 다른 제약(양의 정수, 음이 아닌 정수 등)을 충족하는 경우를 세는 것**입니다. 예를 들어 "$x + y + z = 10$이고 $x < y < z$"처럼 등식과 부등식을 함께 만족하는 순서쌍의 개수, 또는 "$a + b \leq 5$인 음이 아닌 정수 $(a, b)$의 개수"를 구하는 문제입니다.

### 직관적 의미

부등식은 경우의 수에서 **"제약 조건"**입니다. 
- 부등식 없이 "$x + y = 5$인 음이 아닌 정수해"는 중복조합으로 쉽게 세어지지만, 
- "$x < y$이면서 $x + y = 5$"라는 조건이 추가되면, 모든 경우가 아닌 일부만 세야 합니다.

기하적으로는 격자점(정수 좌표)을 세는데, 부등식은 격자점이 존재할 수 있는 영역을 한정합니다.

### 풀이 전략

**대칭성 이용**: $x < y$를 만족하는 경우와 $x > y$를 만족하는 경우가 대칭일 때, 전체에서 $x = y$인 경우를 빼서 $\frac{1}{2}(전체 - x=y경우)$로 계산할 수 있습니다.

**변수 치환**: 부등식을 등식으로 바꿉니다. 예를 들어 $a + b + c \leq 5$는 $a + b + c + d = 5$ (단, $d \geq 0$)로 변환하여 중복조합 문제로 풀 수 있습니다.

### 간단한 예

$a + b = 6$이고 $a < b$인 양의 정수 쌍 $(a, b)$: 조건 없이는 $(1,5), (2,4), (3,3), (4,2), (5,1)$ 다섯 가지이지만, $a < b$ 조건을 적용하면 $(1,5), (2,4)$ **두 가지**입니다.

(검증: `sympy.solve((a + b - 6, a - b + 1), a, b)` → $a=1, b=5$ 확인)
