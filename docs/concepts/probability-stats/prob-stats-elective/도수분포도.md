### 정확한 진술

도수분포도(도수분포표)는 데이터를 몇 개의 구간(계급)으로 나누고, 각 구간에 속하는 데이터의 개수(도수)를 표로 정리한 것입니다. 일반적으로 다음과 같은 형태입니다:

| 계급 | 도수 |
|------|------|
| $a_1 \le x < a_2$ | $f_1$ |
| $a_2 \le x < a_3$ | $f_2$ |
| $\vdots$ | $\vdots$ |

여기서 계급의 폭은 $(a_{i+1} - a_i)$이고, 도수 $f_i$는 해당 계급에 속하는 데이터의 개수입니다.

### 직관과 의미

원래 흩어진 데이터를 그룹으로 묶으면 데이터의 분포 패턴을 한눈에 파악할 수 있습니다. 예를 들어 100명의 학생 키 데이터는 보기 힘들지만, 5cm 간격으로 묶으면 "160~165cm에 가장 많다"는 사실을 쉽게 알 수 있습니다.

도수분포도의 핵심은 **데이터 손실**과 **가독성의 균형**입니다. 각 계급 내 개별 값을 모르게 되지만, 전체 분포 경향(mode, skewness 등)은 명확해집니다. 통계 분석에서 큰 데이터셋을 다룰 때 필수적인 도구입니다.

### 예시

반 학생 30명의 수학 점수를 다음과 같이 표로 정리했습니다:

| 점수 구간 | 도수 |
|----------|------|
| $70 \le x < 80$ | 5 |
| $80 \le x < 90$ | 12 |
| $90 \le x < 100$ | 8 |
| 합계 | 25 |

이 표에서 80점 이상 90점 미만 구간에 학생이 가장 많이 분포함을 알 수 있습니다. 모든 도수의 합은 표본 크기 25와 일치합니다.

이때 각 계급의 '계급값'(중앙값)은 $\frac{70+80}{2}=75$, $\frac{80+90}{2}=85$, $\frac{90+100}{2}=95$이고, 이를 이용해 평균을 근사할 수 있습니다:
$$\bar{x} \approx \frac{75 \times 5 + 85 \times 12 + 95 \times 8}{25} = 85.4$$
