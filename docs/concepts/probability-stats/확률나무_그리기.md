# 확률나무 그리기

> **예제** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
복합 사건 분석

## 본문 (학습 시 채워짐)

### 문제

상자 A에는 빨간 공 2개, 흰 공 1개가 들어있고, 상자 B에는 빨간 공 1개, 흰 공 2개가 들어있다. 상자 A에서 공 1개를 꺼낸 후 상자 B에서 공 1개를 꺼낼 때, 꺼낸 두 공이 모두 빨간 공일 확률을 구하시오.

### 단계별 풀이

**1단계: 첫 번째 선택 (상자 A)**

상자 A의 공 3개 중에서:
- 빨간 공: $\frac{2}{3}$
- 흰 공: $\frac{1}{3}$

**2단계: 두 번째 선택 (상자 B)**

상자 B의 공 3개 중에서:
- 빨간 공: $\frac{1}{3}$
- 흰 공: $\frac{2}{3}$

**3단계: 확률나무 그리기**

```
상자 A에서의 선택
   /            \
빨강(2/3)      흰색(1/3)
  |              |
상자 B의 선택   상자 B의 선택
 /  \           /  \
빨강 흰색     빨강 흰색
1/3 2/3       1/3 2/3
```

**4단계: 모든 경로의 확률 계산**

확률나무의 각 경로는 위에서 아래로 이동하며, **경로의 확률은 각 단계의 확률을 곱합니다**:

- (A 빨강, B 빨강): $\frac{2}{3} \times \frac{1}{3} = \frac{2}{9}$ ← 우리가 구하는 경우
- (A 빨강, B 흰색): $\frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$
- (A 흰색, B 빨강): $\frac{1}{3} \times \frac{1}{3} = \frac{1}{9}$
- (A 흰색, B 흰색): $\frac{1}{3} \times \frac{2}{3} = \frac{2}{9}$

검증: $\frac{2}{9} + \frac{4}{9} + \frac{1}{9} + \frac{2}{9} = 1$ ✓

### 답

두 공이 모두 빨간 공일 확률은 $\dfrac{2}{9}$이다.

### 변형/주의

**핵심**: 확률나무에서는 **한 경로의 확률 = (각 단계의 확률을 곱함)**. 여러 경로의 확률을 원하면 각 경로를 더합니다.

**주의 사항**: 만약 "최소 1개가 빨강일 확률"을 구한다면, 처음 세 경로(A 빨강 또는 B 빨강)의 확률을 모두 더해야 합니다: $\frac{2}{9} + \frac{4}{9} + \frac{1}{9} = \frac{7}{9}$.

**확장**: 세 개 이상의 단계가 있어도 같은 방법을 적용합니다. 각 분기점에서 조건이 바뀐다면(예: 복원 없이 뽑는 경우) 그에 맞게 각 단계의 확률을 수정하면 됩니다.
