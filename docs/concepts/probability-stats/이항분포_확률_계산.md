# 이항분포 확률 계산

> **예제** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
${}_nC_k p^k q^{n-k}$

## 본문 (학습 시 채워짐)

### 문제

어느 학생이 선택지 4개인 객관식 문제를 무작정 찍고 있습니다. 5문제를 이런 식으로 풀 때, 정확히 2문제를 맞힐 확률을 구하세요.

### 단계별 풀이

먼저 상황을 정리합니다. 한 문제를 맞힐 확률은 $p = \frac{1}{4}$이고, 틀릴 확률은 $q = 1 - p = \frac{3}{4}$입니다. 시행은 5번($n=5$) 반복되고, 성공(정답)을 정확히 $k=2$번 원합니다.

**1단계: 조합 계산**

5문제 중 어느 2문제를 맞힐지 선택하는 경우의 수는:
$$\binom{5}{2} = \frac{5!}{2! \cdot 3!} = \frac{5 \times 4}{2 \times 1} = 10$$

**2단계: 특정 배열의 확률**

예를 들어 "처음 2문제는 맞고 나머지 3문제는 틀리는" 경우의 확률은:
$$p^2 \times q^3 = \left(\frac{1}{4}\right)^2 \times \left(\frac{3}{4}\right)^3 = \frac{1}{16} \times \frac{27}{64} = \frac{27}{1024}$$

**3단계: 이항분포 공식 적용**

모든 가능한 배열을 더하면(조합 수 × 한 배열의 확률):
$$P(X=2) = \binom{5}{2} p^2 q^3 = 10 \times \frac{27}{1024} = \frac{270}{1024} = \frac{135}{512}$$

일반 형태: $P(X=k) = \binom{n}{k}p^k q^{n-k}$

### 답

정확히 2문제를 맞힐 확률은 $\boxed{\frac{135}{512}}$ 또는 약 **26.4%**입니다.

### 변형/주의

**변형 1**: "최소 2문제를 맞힐 확률"은 $P(X \geq 2) = P(X=2) + P(X=3) + P(X=4) + P(X=5)$로 각각 계산해 더합니다.

**주의**: 조합 $\binom{n}{k}$를 빼먹으면 안 됩니다. 이것이 "어느 위치에서 성공할지"의 경우의 수입니다. 계산 검증: `sympy.binomial(5, 2) * (1/4)**2 * (3/4)**3`
