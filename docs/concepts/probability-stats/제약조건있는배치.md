### 제약조건 있는 배치란?

제약조건 있는 배치는 $n$개의 서로 다른 원소를 배열할 때, 특정 조건(제약)을 만족해야 하는 배치의 개수를 구하는 문제입니다. 일반적인 순열 $P(n, r) = \frac{n!}{(n-r)!}$와 달리, 추가 규칙이 존재합니다. 예를 들어 "특정 원소가 특정 위치에 올 수 없다", "두 원소가 인접하면 안 된다", "원탁에 앉힐 때 A와 B가 옆에 오면 안 된다" 같은 조건들입니다.

### 직관적 이해

제약조건이 없으면 $n$개 원소의 배치는 $n!$가지입니다. 하지만 조건이 추가되면 가능한 배치의 수가 줄어듭니다. 이를 구하는 기본 전략은 두 가지입니다.

**① 포함-배제 원리**: 조건을 만족하지 않는 경우를 빼는 방법입니다. 전체 배치에서 조건을 위반하는 배치들의 개수를 차감합니다.

$$(\text{조건을 만족하는 배치}) = (\text{전체 배치}) - (\text{조건 위반 배치})$$

**② 직접 계산**: 조건에 따라 경우를 나누어 각각을 계산한 뒤 더합니다. 예를 들어 "A는 맨 앞에, B는 맨 뒤에"라면, 이 두 위치는 먼저 정하고 나머지 원소들을 배열합니다.

### 예시

5명이 일렬로 앉는데, A와 B가 인접하면 안 되는 경우를 계산해봅시다.

- 전체 배치: $5! = 120$
- A와 B가 인접한 경우: A와 B를 하나의 단위로 보면 4개 단위의 배치는 $4! = 24$가지, A와 B의 순서는 $2! = 2$가지이므로 $24 \times 2 = 48$
- **조건을 만족하는 배치**: $120 - 48 = 72$

(검증: `from math import factorial; print(factorial(5) - (factorial(4) * 2))`)
