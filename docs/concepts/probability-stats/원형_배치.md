### 정확한 진술

**원형 배치**(circular arrangement)는 $n$개의 서로 다른 원소를 원 위에 배열하는 경우의 수입니다. 회전하여 같아지는 배열은 같은 것으로 간주합니다.

$n$개의 원소를 원형으로 배치하는 방법의 수는:

$$\frac{n!}{n} = (n-1)!$$

일직선상에서의 순열 $n!$을 $n$으로 나누는 이유는 각 배치마다 $n$가지 회전이 가능하기 때문입니다.

### 직관·기하적 의미

원탁에 사람들을 앉히거나, 목걸이를 만드는 것처럼 **시작점이 없는 환형 구조**에서의 배열 문제입니다.

일직선 순열에서는 자리 1, 2, 3, …이 구별되지만, 원형 배치에서는 위치 자체가 의미가 없습니다. 대신 원소들 사이의 **상대적 순서**만 중요합니다. 

예를 들어 {A, B, C}를 일직선으로 배열하면 (A, B, C), (A, C, B), (B, A, C), (B, C, A), (C, A, B), (C, B, A)의 6가지(= $3!$)이지만, 원형으로 배열하면 (A, B, C) 순서로 배열된 것과 (B, C, A), (C, A, B)는 모두 같은 배치이므로, 실제로는 $\frac{6}{3} = 2$가지입니다.

### 한 줄 예

5명의 학생을 원탁에 앉히는 방법: $4! = 24$가지

```python
# 검증: sympy로도 확인 가능 (순열 생성 후 회전 동치류 계산)
import math
math.factorial(4)  # 24
```
