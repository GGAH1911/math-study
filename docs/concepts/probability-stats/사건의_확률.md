### 정확한 진술

표본공간을 $S$, 사건을 $A \subseteq S$라 할 때, **사건 $A$의 확률**은 다음과 같이 정의합니다:

$$P(A) = \frac{\text{사건 } A \text{가 일어나는 경우의 수}}{\text{표본공간 } S \text{의 전체 경우의 수}}$$

모든 경우가 동일한 확률로 일어난다는 가정(고전적 확률) 하에서, 이 공식으로 계산됩니다. 따라서 $0 \le P(A) \le 1$이며, 특히 $P(S) = 1$ (반드시 일어남), $P(\emptyset) = 0$ (절대 일어나지 않음)입니다.

### 직관과 의미

"사건의 확률"은 어떤 일이 일어날 **가능성의 정도**를 0과 1 사이의 수로 나타낸 것입니다. 표본공간 전체에서 우리가 관심 있는 사건이 차지하는 비중을 생각하면 직관적입니다.

예를 들어 주사위를 한 번 던질 때:
- 표본공간: $S = \{1, 2, 3, 4, 5, 6\}$ (전체 6가지)
- "짝수가 나온다"는 사건: $A = \{2, 4, 6\}$ (3가지)
- 확률: $P(A) = \frac{3}{6} = \frac{1}{2}$ 

확률이 클수록 그 사건은 일어나기 쉽고, 작을수록 일어나기 어렵습니다. 확률 1은 "반드시 일어남", 확률 0은 "절대 일어나지 않음"을 의미합니다.

### 한 줄 예

카드 한 장을 표준 덱(52장)에서 뽑을 때 "스페이드가 나올 확률"은 $P = \frac{13}{52} = \frac{1}{4}$입니다.
