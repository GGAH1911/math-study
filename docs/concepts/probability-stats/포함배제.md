### 정확한 진술

두 개 이상의 집합의 합집합에 속한 원소의 개수를 구할 때, 각 집합의 크기를 모두 더한 후 중복된 부분을 빼는 원리입니다. 두 집합 $A$, $B$에 대하여:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

세 집합 $A$, $B$, $C$의 경우:

$$|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |B \cap C| - |C \cap A| + |A \cap B \cap C|$$

### 직관/기하적 의미

$|A| + |B|$로 계산하면 $A \cap B$에 속한 원소들이 두 번 세어집니다. 따라서 한 번 빼야 정확한 합집합의 크기를 얻습니다. 세 집합 이상일 때도 같은 원리가 적용됩니다. 벤 다이어그램에서 보면, 먼저 각 영역을 더하고(덧셈), 겹치는 부분들을 보정하면서(뺄셈), 다시 너무 많이 뺀 부분을 더합니다(덧셈).

일반적으로 포함된 횟수가 홀수면 더하고, 짝수면 빼는 규칙을 따릅니다.

### 한 줄 예

1부터 30까지의 자연수 중 3의 배수 또는 5의 배수인 수의 개수를 구하면: $A$ = {3의 배수}, $B$ = {5의 배수}일 때, $|A| = 10$, $|B| = 6$, $|A \cap B| = 2$ (15의 배수)이므로 $|A \cup B| = 10 + 6 - 2 = 14$개입니다. (`sympy.Integer(10) + sympy.Integer(6) - sympy.Integer(2)`)
