### 정확한 진술

조합을 이용한 확률은 **같은 종류의 대상들 중에서 선택하는 상황에서, 전체 경우의 수와 유리한 경우의 수를 모두 조합으로 계산하여 구하는 확률**입니다. 일반적으로 다음과 같이 정의합니다.

$$P(A) = \frac{\text{조건을 만족하는 경우의 수}}{\text{전체 경우의 수}} = \frac{C(n, k) \text{ 형태}}{\text{전체 조합의 수}}$$

여기서 전체 경우와 유리한 경우 모두 "순서를 고려하지 않는" 선택 상황이므로 조합 공식 $C(n, k) = \frac{n!}{k!(n-k)!}$을 사용합니다.

### 직관과 의미

조합을 확률 계산에 사용하는 이유는 **"순서가 상관없는 선택"** 문제이기 때문입니다. 예를 들어 52장의 카드 중 5장을 뽑을 때, "♠A, ♥K, ◇Q, ♣J, ♠2"와 "♣J, ♠A, ◇Q, ♥K, ♠2"는 같은 손(hand)입니다. 이렇게 순서를 구별하지 않는 상황에서 전체 경우의 수와 유리한 경우의 수를 모두 조합으로 나타내면, 자동으로 **같은 것끼리의 중복 계산이 소거**되어 올바른 확률을 얻습니다.

### 한 줄 예

10명 중 임의로 3명을 선발할 때, 특정 1명이 포함될 확률은 $\frac{C(9,2)}{C(10,3)} = \frac{36}{120} = \frac{3}{10}$ 입니다. (검증: `from sympy import binomial; binomial(9, 2) / binomial(10, 3)`)
