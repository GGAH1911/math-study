### 정확한 진술

경우의 수란 어떤 사건이 일어날 수 있는 모든 가능한 경우를 세는 것입니다. 주어진 조건을 만족하는 모든 경우를 빠짐없이, 중복 없이 세어서 그 총 개수를 구하는 작업입니다. 기호로는 경우의 수를 $n$으로 나타내거나, 특정 집합의 원소 개수를 $|A|$ 또는 $\#A$로 표현합니다.

### 직관 및 기본 원리

경우의 수 분석의 핵심은 **곱의 법칙(multiplying principle)**과 **합의 법칙(addition principle)**입니다.

**곱의 법칙**: 어떤 사건이 연속으로 일어날 때, 각 단계에서 선택 가능한 경우의 수를 곱합니다. 예를 들어, 셔츠 3종류와 바지 2종류 중 하나씩 고르면 $3 \times 2 = 6$가지입니다.

**합의 법칙**: 서로 겹치지 않는 여러 경우가 있을 때, 각 경우의 수를 더합니다. 예를 들어, 버스로 가는 경우 4가지와 기차로 가는 경우 3가지는 총 $4 + 3 = 7$가지입니다.

경우의 수 분석은 단순히 수를 세는 것을 넘어, 복잡한 상황을 체계적으로 분해하고 구조화하는 능력을 기릅니다. 이는 확률 계산의 분모와 분자를 구하는 기초이며, 조합론의 출발점입니다.

### 구체적 예

**예 1**: 동전 2개를 던질 때 나올 수 있는 경우  
첫 번째 동전: (앞, 뒤) → 2가지  
두 번째 동전: (앞, 뒤) → 2가지  
곱의 법칙에 따라: $2 \times 2 = 4$가지 (앞앞, 앞뒤, 뒤앞, 뒤뒤)

**예 2**: 0, 1, 2를 이용해 만든 서로 다른 두 자리 수의 개수  
십의 자리: 0은 불가능 → 1, 2 중 선택 (2가지)  
일의 자리: 십의 자리에서 선택한 수를 제외한 2개 중 선택 (2가지)  
곱의 법칙: $2 \times 2 = 4$가지
