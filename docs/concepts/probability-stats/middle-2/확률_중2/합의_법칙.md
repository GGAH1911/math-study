# 합의 법칙

> **정리** · 중2 · 단원: [확률 (중학)](/concepts/확률_중2)

## 요약
두 사건이 서로 겹치지 않는 배반사건일 때, 두 사건 중 어느 하나라도 일어나는 경우의 수는 각 사건의 경우의 수를 더한 것과 같습니다.

## 본문
두 사건 $A$와 $B$가 서로 겹치지 않는 배반사건, 즉 $A \cap B = \emptyset$이면 다음 식이 성립합니다:
$$n(A \cup B) = n(A) + n(B)$$
여기서 $n(X)$는 사건 $X$에 포함된 경우의 수입니다. 이러한 성질은 여러 개의 사건이 서로 겹치지 않을 때도 확장되어 다음과 같이 적용됩니다:
$$n(A_1 \cup A_2 \cup \cdots \cup A_k) = n(A_1) + n(A_2) + \cdots + n(A_k)$$
이 법칙을 적용하기 위한 필수 가정은 모든 사건이 서로 배반이어야 한다는 점입니다. 즉, 동시에 일어날 수 있는 경우가 없어야 합니다.

### 증명 스케치
배반사건은 두 사건의 영역이 서로 겹치지 않음을 의미합니다. 따라서 사건 $A$에 속한 경우의 수와 사건 $B$에 속한 경우의 수를 더할 때, 중복되어 계산되는 부분이 전혀 없으므로 단순히 두 값을 합하는 것만으로 전체 경우의 수를 구할 수 있습니다. 예를 들어 주사위를 던져 1 또는 2가 나오는 경우($n(A)=2$)와 3 또는 4가 나오는 경우($n(B)=2$)는 서로 겹치지 않으므로, 1, 2, 3, 4 중 하나가 나오는 경우의 수는 $2+2=4$가 됩니다.

### 의의와 응용
합의 법칙은 복잡한 상황을 서로 겹치지 않는 단순한 상황들로 나누어 계산할 때 매우 유용합니다. 예를 들어 주사위 두 개의 합이 짝수인 경우를 구할 때, 합이 2, 4, 6, 8, 10, 12인 각각의 경우를 구한 뒤 모두 더하는 방식으로 접근할 수 있습니다. 다만, 사건들이 서로 겹치는 경우에는 중복 계산이 발생하므로 합의 법칙을 그대로 적용해서는 안 됩니다.

## 학습 체크
- 두 사건이 서로 배반사건인지(동시에 일어날 수 없는지) 먼저 확인하였는가?
- 사건들이 서로 겹치는 부분이 있음에도 불구하고 단순히 더하기만 하지는 않았는가?

## 관련 개념
- **확률 (중2)**: 합의 법칙을 통해 구한 경우의 수를 전체 경우의 수로 나누어 특정 사건이 일어날 확률을 계산할 수 있습니다.
