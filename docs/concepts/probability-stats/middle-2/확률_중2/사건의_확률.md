# 사건의 확률

> **정의** · 중2 · 단원: [확률 (중학)](/concepts/확률_(중학))

## 요약
사건의 확률은 어떤 일이 일어날 가능성의 정도를 전체 경우의 수에 대한 해당 사건의 경우의 수의 비율로 나타낸 값입니다.

## 본문
표본공간을 $S$, 사건을 $A \subseteq S$라 할 때, 사건 $A$의 확률은 다음과 같이 정의합니다. 모든 경우가 동일한 확률로 일어난다는 가정 하에, 사건 $A$의 확률 $P(A)$는 표본공간 $S$의 전체 경우의 수에 대한 사건 $A$가 일어나는 경우의 수의 비율인 $P(A) = \tfrac{\text{사건 } A \text{가 일어나는 경우의 수}}{\text{표본공간 } S \text{의 전체 경우의 수}}$로 계산됩니다.

### 직관과 기하적 의미
사건의 확률은 어떤 일이 일어날 가능성의 정도를 0과 1 사이의 수로 나타낸 것입니다. 표본공간 전체에서 우리가 관심 있는 사건이 차지하는 비중을 생각하면 직관적으로 이해할 수 있습니다. 예를 들어 주사위를 한 번 던질 때, 전체 경우의 수는 $S = \{1, 2, 3, 4, 5, 6\}$으로 6가지이며, "짝수가 나온다"는 사건은 $A = \{2, 4, 6\}$으로 3가지입니다. 이때 확률은 $P(A) = \tfrac{3}{6} = \tfrac{1}{2}$이 됩니다. 확률이 클수록 그 사건은 일어나기 쉽고, 작을수록 일어나기 어렵습니다.

### 기본 성질
확률은 항상 $0 \le P(A) \le 1$의 범위를 가집니다. 모든 결과가 포함된 표본공간 $S$가 일어날 확률 $P(S)$은 1이며, 이는 사건이 반드시 일어남을 의미합니다. 반대로 아무것도 일어나지 않는 공집합 $\emptyset$의 확률 $P(\emptyset)$은 0이며, 이는 사건이 절대 일어나지 않음을 의미합니다.

## 학습 체크
- 확률을 계산할 때 분모에 들어갈 '전체 경우의 수'를 빠뜨리지 않고 정확히 구하였는가?
- 구한 확률 값이 0과 1 사이의 범위에 있는지 확인하였는가?
- 사건이 일어나는 경우의 수를 구할 때 중복되거나 빠진 경우는 없는가?

## 관련 개념
- **확률**: 사건의 확률을 바탕으로 여러 사건이 동시에 또는 연속적으로 일어날 가능성을 다루는 수학적 개념입니다.
