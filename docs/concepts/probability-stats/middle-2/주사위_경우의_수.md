# 주사위 경우의 수

> **예제** · 중2 · 단원: [확률 (중학)](/concepts/확률_중2)

## 요약
두 주사위의 합

## 본문 (학습 시 채워짐)

### 문제

두 개의 정육면체 주사위를 동시에 던질 때, 나온 두 수의 합이 7이 되는 경우의 수를 구하세요.

### 단계별 풀이

첫 번째 주사위 눈의 수를 $a$, 두 번째 주사위 눈의 수를 $b$라고 하겠습니다. 우리가 찾는 것은 $a + b = 7$을 만족하는 모든 순서쌍 $(a, b)$입니다.

**단계 1: 가능한 경우 체계적으로 나열하기**

첫 번째 주사위의 값에 따라 정리하면:
- $a = 1$일 때: $b = 6$ → $(1, 6)$ ✓
- $a = 2$일 때: $b = 5$ → $(2, 5)$ ✓
- $a = 3$일 때: $b = 4$ → $(3, 4)$ ✓
- $a = 4$일 때: $b = 3$ → $(4, 3)$ ✓
- $a = 5$일 때: $b = 2$ → $(5, 2)$ ✓
- $a = 6$일 때: $b = 1$ → $(6, 1)$ ✓

**단계 2: 경우의 수 세기**

위에서 찾은 순서쌍을 모두 세면 6개입니다.

검증: `[len([(a, b) for a in range(1, 7) for b in range(1, 7) if a + b == 7])]` → 6

### 답

**6가지**

### 변형·주의

**변형 1** — 합이 7 **이상**인 경우는 몇 가지일까요?  
$a + b \geq 7$을 만족하는 순서쌍을 세면 21가지입니다. 전체 $6 \times 6 = 36$가지 중에서 합이 12 이하인 경우들을 세는 것도 좋은 연습입니다.

**변형 2** — 만약 주사위가 3개라면?  
세 수 $a, b, c$의 합이 10이 되는 경우의 수를 구하면, 체계적 나열이 더 복잡해집니다. 이런 때는 '중복조합' 개념(고등학교)으로 더 빠르게 풀 수 있습니다.

**주의** — 순서쌍 $(1, 6)$과 $(6, 1)$은 다른 경우입니다. 첫 번째 주사위와 두 번째 주사위를 구별해야 합니다!
