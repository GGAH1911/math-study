# 합의 법칙

> **정리** · 중2 · 단원: [확률 (중학)](/concepts/확률_중2)

## 요약
배반사건의 경우의 수 합

## 본문 (학습 시 채워짐)

### 진술과 가정

두 사건 $A$와 $B$가 **배반사건**이면, 즉 $A \cap B = \emptyset$이면 다음이 성립합니다:

$$n(A \cup B) = n(A) + n(B)$$

여기서 $n(X)$는 사건 $X$에 포함된 경우의 수입니다. 같은 방식으로 서로소(겹치지 않는) 사건들이 여러 개일 때도 성립합니다:

$$n(A_1 \cup A_2 \cup \cdots \cup A_k) = n(A_1) + n(A_2) + \cdots + n(A_k)$$

**가정**: 사건들이 서로 배반이어야 합니다(동시에 일어날 수 없어야 함).

### 유도와 직관

합의 법칙이 왜 성립하는지는 매우 단순합니다. 배반사건이란 겹치지 않는다는 뜻이므로, 사건 $A$에 속한 경우의 수와 사건 $B$에 속한 경우의 수를 더할 때 중복을 걱정할 필요가 없습니다.

예를 들어, 주사위를 한 번 던질 때:
- 사건 $A$: 1 또는 2가 나온다 → $n(A) = 2$
- 사건 $B$: 3 또는 4가 나온다 → $n(B) = 2$

$A$와 $B$는 겹치지 않으므로, "1, 2, 3, 4 중 하나가 나온다"는 경우의 수는 $2 + 2 = 4$입니다. 실제로 세어보면 $\{1, 2, 3, 4\}$이므로 맞습니다.

### 의의와 응용

합의 법칙은 복잡한 상황을 **서로 겹치지 않는 간단한 경우들로 분해**할 때 핵심 도구입니다.

**예시**:
- "5장 이상의 카드가 나올 확률" = "5장, 6장, 7장, ..., 13장이 나올 확률의 합"
- "주사위 두 개의 합이 짝수일 경우의 수" = "합이 2, 4, 6, 8, 10, 12인 경우들의 합"

**주의**: 배반이 아닌 경우, 즉 겹친다면 합의 법칙을 바로 적용할 수 없습니다. 예를 들어 "카드가 5 이상이거나 빨간색"일 확률은 단순히 더할 수 없습니다(5 이상이면서 빨간 카드가 중복 계산됨).

검산 코드: `len([i for i in range(1,7) if i in {1,2,3,4}])`  → 4
