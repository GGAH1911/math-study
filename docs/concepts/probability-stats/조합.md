# 조합

> **정의** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$_nC_r=n!/(r!(n-r)!)$

## 본문 (학습 시 채워짐)

### 정확한 진술

$n$개의 서로 다른 것 중에서 **순서를 생각하지 않고** $r$개($0 \le r \le n$)를 선택하는 경우의 수를 **조합(combination)**이라 하고, $_nC_r$ 또는 $\binom{n}{r}$으로 나타냅니다:

$$_nC_r = \binom{n}{r} = \frac{n!}{r!(n-r)!}$$

### 직관 및 의미

순열 $_nP_r$은 순서를 구분합니다. 예를 들어 {A, B}와 {B, A}를 서로 다른 경우로 봅니다. 하지만 조합은 순서를 무시하므로 같은 선택으로 봅니다.

따라서 조합은 순열로부터 다음과 같이 유도됩니다:
$$_nC_r = \frac{_nP_r}{r!} = \frac{n!}{r!(n-r)!}$$

선택된 $r$개 원소를 배열하는 방식이 $r!$가지이므로, 순열 $_nP_r$을 $r!$로 나누어 중복을 제거하면 조합이 됩니다.

**기하적으로**, 조합은 $n$개 원소에서 크기 $r$인 부분집합을 선택하는 것입니다. 예를 들어 {1, 2, 3} 중 2개를 선택하면 {1, 2}, {1, 3}, {2, 3}의 3가지입니다.

### 한 줄 예

6명의 학생 중에서 위원 3명을 선택하는 경우의 수는:
$$_6C_3 = \frac{6!}{3! \cdot 3!} = \frac{720}{6 \times 6} = 20 \text{가지}$$

(`sympy.factorial(6) // (sympy.factorial(3) * sympy.factorial(3))` → 20)
