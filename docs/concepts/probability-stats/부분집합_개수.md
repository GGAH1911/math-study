### 정확한 진술

원소의 개수가 $n$인 유한집합 $A$의 부분집합의 개수는 $2^n$이다.

즉, $|A| = n$이면 $A$의 모든 부분집합의 개수는 정확히 $2^n$개이다. 이는 공집합과 $A$ 자신도 포함한 개수이다.

### 직관과 의미

각 원소에 대해 "포함할지, 포함하지 않을지"를 **독립적으로** 선택할 수 있다고 생각하면 된다. 

$n$개의 원소 $a_1, a_2, \ldots, a_n$이 있을 때:
- $a_1$: 포함(O) 또는 미포함(X) → 2가지
- $a_2$: 포함(O) 또는 미포함(X) → 2가지
- $\vdots$
- $a_n$: 포함(O) 또는 미포함(X) → 2가지

**곱의 법칙**에 의해 총 경우의 수는 $2 \times 2 \times \cdots \times 2 = 2^n$이다.

### 구체적 예

집합 $A = \{1, 2, 3\}$을 보자. 부분집합은:
$$\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}$$

총 8개 = $2^3$이다.

원소 3개일 때:
- 원소 1: 포함/미포함 (2가지)
- 원소 2: 포함/미포함 (2가지)  
- 원소 3: 포함/미포함 (2가지)

따라서 $2^3 = 8$개이다.

```python
# 검산: sympy로 확인
from itertools import combinations
A = {1, 2, 3}
subsets = [set(c) for i in range(len(A)+1) for c in combinations(A, i)]
# 결과: 길이 8 ✓
```

### 응용

$n$이 작을 때: $n=2$ → $2^2=4$개, $n=4$ → $2^4=16$개, $n=5$ → $2^5=32$개

이 공식은 **이항정리**와도 연결된다. 부분집합 중 원소 $k$개를 선택하는 경우의 수는 $\binom{n}{k}$이고, 모든 $k$에 대해 합하면:
$$\sum_{k=0}^{n} \binom{n}{k} = 2^n$$

이는 경우의 수와 조합론의 기초 개념으로, 집합론의 여러 문제에서 자주 쓰인다.
