### 정확한 진술

집합 $A$의 원소가 $m$개, 집합 $B$의 원소가 $n$개일 때, $A$에서 $B$로의 함수의 개수는 $n^m$입니다. 이는 정의역 $A$의 각 원소가 치역 $B$의 원소 중 정확히 하나를 선택하도록 대응되므로, 곱의 법칙에 의해 결정됩니다.

### 직관과 의미

함수는 정의역의 각 원소에 치역의 원소를 "대응"시키는 규칙입니다. 정의역이 $m$개 원소로 이루어졌을 때, **각 원소마다 독립적으로** 치역의 $n$개 원소 중 하나를 선택할 수 있습니다. 이를 단계별로 세면:

- 첫 번째 정의역 원소: $n$가지 선택
- 두 번째 정의역 원소: $n$가지 선택
- ⋯
- $m$번째 정의역 원소: $n$가지 선택

곱의 법칙에 의해 전체 함수의 개수는 $\underbrace{n \times n \times \cdots \times n}_{m \text{개}} = n^m$이 됩니다.

이 개념은 경우의 수의 가장 기본적인 적용으로, 순서쌍을 만드는 것과 동일합니다.

### 예시

$A = \{1, 2\}$, $B = \{가, 나, 다\}$일 때, $A \to B$인 함수의 개수는 $3^2 = 9$입니다.

- $f(1) = 가, f(2) = 가$
- $f(1) = 가, f(2) = 나$
- $f(1) = 가, f(2) = 다$
- ⋯

이런 식으로 총 9가지 함수가 존재합니다. (검증: `3**2 = 9`)
