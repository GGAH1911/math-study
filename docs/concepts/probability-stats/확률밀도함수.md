### 정확한 진술

연속확률변수 $X$의 **확률밀도함수**(probability density function, PDF) $f(x)$는 다음 두 조건을 만족하는 함수입니다.

1. 모든 $x$에 대해 $f(x) \geq 0$
2. $\displaystyle \int_{-\infty}^{\infty} f(x)\,dx = 1$

이때 $a \leq b$인 임의의 실수 $a, b$에 대해
$$P(a \leq X \leq b) = \int_a^b f(x)\,dx$$
로 확률을 계산합니다.

### 직관과 기하적 의미

이산확률변수에서는 각 값의 확률을 따로 정의했다면, 연속확률변수는 특정 하나의 값일 확률이 0입니다. 대신 **구간의 확률**을 생각하며, 이를 위해 확률밀도함수를 도입합니다.

확률밀도함수의 그래프 아래 넓이가 곧 확률입니다. 예를 들어 $a$와 $b$ 사이 구간의 넓이는 $X$가 $[a, b]$에 속할 확률을 나타냅니다. 따라서 **전체 그래프 아래 넓이는 반드시 1**이어야 하고(사건의 확률의 합), 특정 점 $x_0$에서의 함숫값 $f(x_0)$는 확률이 아니라 "확률 밀도"입니다.

### 예시

신장이 정규분포 $N(170, 100)$를 따르는 어떤 모집단에서, 확률밀도함수는
$$f(x) = \frac{1}{10\sqrt{2\pi}} \exp\left(-\frac{(x-170)^2}{200}\right)$$
입니다. 신장이 165cm 이상 175cm 이하일 확률은
$$P(165 \leq X \leq 175) = \int_{165}^{175} f(x)\,dx$$
로 계산됩니다.

*sympy로 표준정규분포의 적분 확인:* `from scipy.stats import norm; print(norm.cdf(1) - norm.cdf(-1))` ≈ 0.682 (평균 ±1σ)
