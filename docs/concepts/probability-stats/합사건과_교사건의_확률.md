### 정확한 진술

표본공간 $S$에서 두 사건 $A$, $B$에 대해:

**합사건(합집합)**: $A \cup B = \{s \in S \mid s \in A \text{ 또는 } s \in B\}$  
사건 $A$ 또는 $B$ 중 적어도 하나가 일어나는 경우들의 집합입니다.

**교사건(교집합)**: $A \cap B = \{s \in S \mid s \in A \text{ 그리고 } s \in B\}$  
사건 $A$와 $B$가 동시에 일어나는 경우들의 집합입니다.

따라서:
$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

이 식은 **포함-배제 원리**라 부르며, $P(A \cap B)$를 빼는 이유는 두 사건의 공통 부분이 중복으로 계산되기 때문입니다.

### 직관/기하적 의미

**벤다이어그램**으로 생각하면:
- 합사건 $A \cup B$는 두 원이 차지하는 **전체 영역** (겹치는 부분도 포함)
- 교사건 $A \cap B$는 두 원이 **겹치는 중심 부분**

**실생활 예**: 주사위를 던질 때 $A$ = "짝수", $B$ = "3 이상"
- $A = \{2, 4, 6\}$, $B = \{3, 4, 5, 6\}$
- $A \cup B = \{2, 3, 4, 5, 6\}$ (짝수 **또는** 3 이상)
- $A \cap B = \{4, 6\}$ (짝수 **그리고** 3 이상)

### 한 줄 예

주사위 시행에서 $P(A) = 3/6$, $P(B) = 4/6$, $P(A \cap B) = 2/6$일 때, 
$$P(A \cup B) = \frac{3}{6} + \frac{4}{6} - \frac{2}{6} = \frac{5}{6}$$

(검증: `sympy.Rational(3,6) + sympy.Rational(4,6) - sympy.Rational(2,6)` → $\frac{5}{6}$)
