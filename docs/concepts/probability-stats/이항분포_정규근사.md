# 이항분포 정규근사

> **정리** · 확률과통계 · 단원: [통계](/concepts/통계)

## 요약
$n$ 크면 정규분포로 근사

## 본문 (학습 시 채워짐)

### 진술 및 가정

이항분포 $X \sim B(n, p)$에서 시행 횟수 $n$이 충분히 클 때, $X$는 근사적으로 평균 $\mu = np$, 분산 $\sigma^2 = np(1-p)$인 정규분포를 따릅니다. 즉,

$$X \sim B(n, p) \approx N(np, np(1-p)) \text{ (단, } n \text{이 충분히 클 때)}$$

표준화하면 $Z = \dfrac{X - np}{\sqrt{np(1-p)}}$는 표준정규분포 $N(0, 1)$으로 근사됩니다. 

**가정**: 실무에서는 $np \geq 5$이고 $n(1-p) \geq 5$일 때 이 근사를 신뢰할 수 있습니다.

### 증명 스케치 및 직관

이항분포는 독립적인 베르누이 시행의 합입니다. $X = X_1 + X_2 + \cdots + X_n$이고 각 $X_i$는 독립이며 같은 분포를 따르므로, **중심극한정리(Central Limit Theorem)**에 의해 $n$이 커질수록 $X$의 분포는 정규분포에 가까워집니다. 

기하학적으로 보면, 이항분포의 히스토그램은 $n$이 작을 때는 비대칭적이고 뾰족하지만, $n$이 증가하면서 점차 종 모양의 정규분포 곡선에 수렴합니다.

### 의의 및 응용

이 정리는 **이항확률을 빠르게 계산**할 수 있게 해줍니다. 원래는 $P(X = k) = \binom{n}{k}p^k(1-p)^{n-k}$를 직접 계산해야 하지만, $n$이 크면 정규분포표를 이용해 근사확률을 구할 수 있습니다.

**예**: 1000명 중 성공률 40%인 사건에서 성공 인원이 380명 이상 420명 이하일 확률을 구할 때, $\mu = 400$, $\sigma = \sqrt{1000 \times 0.4 \times 0.6} \approx 15.49$로 두고, 표준정규분포를 이용하면 간편합니다. (`from scipy.stats import norm; norm.cdf((420-400)/15.49) - norm.cdf((380-400)/15.49)`)
