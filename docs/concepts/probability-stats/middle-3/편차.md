### 정확한 진술

편차(deviation)는 어떤 데이터 한 개가 평균으로부터 얼마나 멀리 떨어져 있는지를 나타낸 값입니다. 데이터가 $x_1, x_2, \ldots, x_n$이고 평균이 $\bar{x}$일 때, $i$번째 데이터의 편차는

$$d_i = x_i - \bar{x}$$

로 정의됩니다. 편차는 음수일 수도, 양수일 수도, 0일 수도 있습니다.

### 직관/기하적 의미

평균은 데이터의 "중심"이라고 생각할 수 있습니다. 편차는 각 데이터가 이 중심으로부터 **얼마나 벗어나 있는지**를 보여주는 척도입니다. 

예를 들어, 5명 학생의 시험 점수가 70, 80, 90, 100, 60일 때 평균은 80점입니다. 이때 각 학생의 편차는:
- 70점 학생: $70 - 80 = -10$
- 80점 학생: $80 - 80 = 0$
- 90점 학생: $90 - 80 = 10$
- 100점 학생: $100 - 80 = 20$
- 60점 학생: $60 - 80 = -20$

양수 편차는 "평균보다 위", 음수 편차는 "평균보다 아래"를 의미합니다. 편차들의 합은 항상 0이 되는 성질이 있으므로, 자료의 산포도(분산, 표준편차)를 계산할 때는 편차의 제곱을 사용합니다.

### 한 줄 예

여섯 자연수 $3, 5, 7, 9, 11, 13$의 평균은 $\bar{x} = 8$이고, 11의 편차는 $11 - 8 = 3$입니다. (검산: `[3-8, 5-8, 7-8, 9-8, 11-8, 13-8] = [-5, -3, -1, 1, 3, 5]`, 합 = 0 ✓)
