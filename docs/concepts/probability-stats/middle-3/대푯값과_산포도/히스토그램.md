# 히스토그램

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
수집한 데이터를 일정한 구간인 계급으로 나누어 각 구간의 도수를 직사각형 막대로 나타낸 그래프입니다.

## 본문
히스토그램은 수집한 데이터를 일정한 폭의 계급으로 나누어, 각 계급에 속하는 데이터의 개수인 도수 또는 상대도수를 직사각형 막대로 나타낸 그래프입니다. $x$축에는 계급 구간을, $y$축에는 도수 또는 상대도수를 표시하며, 막대가 서로 인접하여 겹치지 않는 것이 특징입니다.

### 직관과 기하적 의미
히스토그램의 핵심은 연속적인 데이터의 분포를 시각화하는 데 있습니다. 예를 들어 학급 학생들의 키를 일정 구간으로 묶으면, 각 키 범위에 몇 명이 속하는지를 한눈에 파악할 수 있습니다. 막대의 높이가 높을수록 해당 구간에 데이터가 많이 몰려 있음을 의미합니다. 또한 막대가 서로 붙어 있는 형태는 데이터가 연속적임을 나타내며, 이는 막대 사이에 간격이 있는 일반적인 막대그래프와 구분되는 특징입니다.

### 기본 성질
히스토그램에서 각 막대의 넓이 또는 높이는 해당 구간의 상대도수를 나타내므로, 모든 막대 넓이의 합은 $1$ 또는 $100\%$가 됩니다. 이러한 성질은 데이터의 전체적인 분포 양상을 파악하는 데 매우 유용하며, 추후 확률분포의 개념으로 확장되는 중요한 기초가 됩니다.

## 학습 체크
- 히스토그램의 $x$축과 $y$축에는 각각 무엇을 표시해야 하는가?
- 히스토그램의 막대가 서로 붙어 있는 것은 데이터의 어떤 특성을 나타내는가?
- 모든 막대의 넓이를 합했을 때 왜 $1$이 되어야 하는가?

## 관련 개념
- **통계**: 데이터를 수집, 정리, 분석하여 의미 있는 정보를 추출하는 과정에서 히스토그램은 데이터의 분포를 시각적으로 보여주는 핵심적인 도구로 사용됩니다.
