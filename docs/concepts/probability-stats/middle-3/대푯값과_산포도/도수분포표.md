# 도수분포표

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
원시 자료를 일정한 구간으로 나누어 각 구간에 속하는 데이터의 개수를 정리한 표입니다.

## 본문
도수분포표는 수집된 자료를 일정한 간격의 구간인 계급으로 분류하여, 각 계급에 속하는 자료의 개수인 도수를 정리한 표입니다. 자료의 분포 상태를 한눈에 파악할 수 있도록 돕는 요약 도구입니다. 도수분포표는 자료를 나누는 구간인 계급, 각 구간의 중앙값인 계급값, 해당 구간의 자료 개수인 도수, 그리고 전체 자료 개수에 대한 도수의 비율인 상대도수로 구성됩니다.

### 직관과 기하적 의미
수많은 개별 데이터를 나열하는 대신 도수분포표를 사용하면 자료가 어느 구간에 집중되어 있는지 분포의 형태를 직관적으로 파악할 수 있습니다. 이는 히스토그램이나 도수분포다각형과 같은 그래프를 그리는 기초가 되며, 자료의 전체적인 흐름을 시각화하는 데 핵심적인 역할을 합니다.

### 기본 성질
도수의 총합은 항상 전체 자료의 개수 $n$과 일치해야 하며, 각 계급의 상대도수를 모두 더한 값은 항상 $1$이 되어야 합니다. 또한, 계급값은 해당 구간의 중간값인 $\tfrac{\text{하한} + \text{상한}}{2}$을 사용하여 계산합니다.

## 학습 체크
- 도수의 총합과 상대도수의 총합이 각각 $n$과 $1$이 되는지 확인하였는가?
- 계급값은 해당 구간의 양 끝값을 더해 2로 나눈 값인가?
- 상대도수를 통해 전체에서 특정 계급이 차지하는 비율을 계산할 수 있는가?

## 관련 개념
- **통계**: 자료의 특성을 수치로 요약하여 분석하는 학문으로, 도수분포표는 통계적 분석을 위한 가장 기초적인 자료 정리 방식입니다.
