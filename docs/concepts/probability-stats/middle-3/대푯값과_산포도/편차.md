# 편차

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
편차는 각 데이터가 평균으로부터 떨어진 거리를 나타내는 값으로, 데이터의 분포 상태를 파악하는 기초가 됩니다.

## 본문
어떤 데이터 한 개가 평균으로부터 얼마나 멀리 떨어져 있는지를 나타낸 값을 편차라고 합니다. 데이터가 $x_1, x_2, \ldots, x_n$이고 평균이 $\bar{x}$일 때, $i$번째 데이터의 편차는 $d_i = x_i - \bar{x}$로 정의됩니다. 편차는 데이터가 평균보다 크면 양수, 평균보다 작으면 음수, 평균과 같으면 0이 됩니다.

### 직관과 기하적 의미
평균은 데이터의 중심 역할을 합니다. 편차는 각 데이터가 이 중심으로부터 얼마나 벗어나 있는지를 보여주는 척도입니다. 예를 들어 시험 점수가 70, 80, 90, 100, 60점이고 평균이 80점이라면, 각 점수의 편차는 -10, 0, 10, 20, -20이 됩니다. 여기서 양수 편차는 평균보다 높은 위치를, 음수 편차는 평균보다 낮은 위치를 의미합니다.

### 기본 성질
모든 편차를 더하면 그 합은 항상 0이 됩니다. 이러한 성질 때문에 자료가 얼마나 퍼져 있는지 나타내는 산포도를 계산할 때는 편차를 그대로 더하는 대신, 편차를 제곱하여 합한 값을 사용합니다.

## 학습 체크
- 편차의 정의를 이용하여 특정 데이터의 편차를 계산할 수 있는가?
- 모든 편차의 합이 왜 항상 0이 되는지 이해하고 있는가?
- 편차의 부호가 데이터와 평균의 크기 관계를 어떻게 나타내는지 설명할 수 있는가?

## 관련 개념
- **대푯값과 산포도**: 편차는 대푯값인 평균을 기준으로 데이터가 흩어진 정도를 나타내는 산포도를 구하기 위한 핵심적인 중간 단계입니다.
