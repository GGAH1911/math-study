# 도수

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
어떤 자료 집단에서 특정한 값이 나타나는 횟수를 의미합니다.

## 본문
어떤 자료 집단에서 특정한 값이 나타나는 횟수를 그 값의 도수라고 합니다. 일반적으로 어떤 변수 $X$의 값 $x$에 대해 도수는 $f(x)$ 또는 단순히 $f$로 나타냅니다.

### 직관과 의미
도수는 통계에서 자료를 정리하고 분석하기 위한 가장 기본적인 도구입니다. 예를 들어 반 학생 30명의 혈액형을 조사했을 때, A형이 8명, B형이 7명, O형이 10명, AB형이 5명이라면, A형의 도수는 8이고 O형의 도수는 10입니다. 이처럼 자료를 정리하면 원래 순서대로 모든 데이터를 나열하는 것보다 훨씬 간결하며 데이터의 패턴을 파악하기 쉬워집니다. 도수가 클수록 해당 값이 자료에서 더 자주 나타났음을 의미합니다.

자료의 성격에 따라 정리 방식이 달라집니다. 혈액형이나 성별과 같은 질적 자료는 각 범주에 해당하는 도수를 세어 정리하며, 키나 몸무게와 같은 양적 자료는 도수분포표를 만들어 일정한 구간(급간)별로 도수를 정렬하여 나타냅니다.

### 기본 성질
전체 자료의 개수를 $n$이라 할 때, 모든 도수의 합은 항상 전체 자료의 개수와 같아야 합니다. 즉, $\sum f = n$입니다.

## 학습 체크
- 특정 값의 도수를 구할 때, 해당 값이 자료에 나타나는 횟수를 정확히 세었는가?
- 모든 도수를 더한 값이 전체 자료의 개수와 일치하는가?
- 자료의 종류(질적/양적)에 따라 도수를 정리하는 적절한 방법(범주별/구간별)을 선택하였는가?

## 관련 개념
- **통계**: 자료의 특성을 수치로 요약하여 나타내는 과정에서 도수는 자료의 분포를 파악하는 가장 기초적인 단위가 됩니다.
