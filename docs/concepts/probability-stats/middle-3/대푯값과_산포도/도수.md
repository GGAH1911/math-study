# 도수

## 정확한 진술

어떤 자료 집단에서 특정한 값이 나타나는 **횟수**를 그 값의 **도수**(frequency)라고 합니다. 일반적으로 어떤 변수 $X$의 값 $x$에 대해 도수를 $f(x)$ 또는 단순히 $f$로 나타냅니다. 전체 자료의 개수를 $n$이라 할 때, 도수의 합은 항상 $\sum f = n$입니다.

## 직관과 의미

도수는 통계에서 자료를 정리하고 분석하기 위한 가장 기본적인 개념입니다. 예를 들어 반 학생 30명의 혈액형을 조사했을 때, A형이 8명, B형이 7명, O형이 10명, AB형이 5명이라면, A형의 도수는 8이고 O형의 도수는 10입니다. 이렇게 자료를 정렬하면 원래 순서대로 30명의 혈액형을 모두 나열하는 것보다 훨씬 간결하고 패턴을 파악하기 쉬워집니다. 도수가 클수록 그 값이 자료에서 자주 나타났다는 의미입니다.

도수는 변량의 특성에 따라 다르게 정리됩니다. **질적 자료**(혈액형, 성별 등)는 각 범주의 도수를 세고, **양적 자료**(키, 몸무게, 시험 점수 등)는 **도수분포표**(frequency table)를 만들어 일정한 구간(급간)별로 도수를 정렬합니다.

## 한 줄 예

어느 학교의 시험 점수가 다음과 같다고 하자:
$$70, 75, 80, 75, 90, 80, 70, 85, 80, 75$$

여기서 70점의 도수는 2, 75점의 도수는 3, 80점의 도수는 3, 85점의 도수는 1, 90점의 도수는 1입니다. 도수의 합은 $2+3+3+1+1=10$으로 전체 자료의 개수와 같습니다.

```python
# sympy로 확인: [70, 75, 80, 75, 90, 80, 70, 85, 80, 75]의 도수
from collections import Counter; Counter([70, 75, 80, 75, 90, 80, 70, 85, 80, 75])
# Counter({75: 3, 80: 3, 70: 2, 90: 1, 85: 1})
```
