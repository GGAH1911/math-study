# 편차의 성질

## 정확한 진술

주어진 데이터 $x_1, x_2, \ldots, x_n$의 평균을 $\bar{x}$라 할 때, **편차**는 각 데이터값과 평균의 차이로 정의됩니다.

$$\text{편차}_i = x_i - \bar{x}$$

편차는 다음 두 가지 중요한 성질을 만족합니다.

**성질 1** — 모든 편차의 합은 0입니다.
$$\sum_{i=1}^{n} (x_i - \bar{x}) = 0$$

**성질 2** — 편차의 제곱의 합은 분산에 데이터 개수를 곱한 값과 같습니다.
$$\sum_{i=1}^{n} (x_i - \bar{x})^2 = n \cdot s^2$$
(여기서 $s^2$은 분산)

## 직관 및 기하적 의미

편차는 "각 데이터가 평균으로부터 얼마나 떨어져 있는가"를 나타냅니다. 평균보다 크면 양수, 평균보다 작으면 음수 편차를 가집니다.

**성질 1의 의미**: 평균은 데이터의 '무게 중심'이므로, 평균 위의 편차들(양수)과 평균 아래의 편차들(음수)이 정확히 상쇄됩니다. 이는 평균의 정의 자체에서 필연적으로 따르는 결과입니다.

**성질 2의 의미**: 편차를 제곱하는 이유는 부호를 없애면서 각 데이터의 '흩어짐 정도'를 정량화하기 위함입니다. 편차의 제곱의 합이 작을수록 데이터가 평균에 집중되어 있음을 의미합니다.

## 구체적 예

데이터: 2, 4, 6
평균: $\bar{x} = \frac{2+4+6}{3} = 4$

각 편차: $-2, 0, 2$

**성질 1 확인**: $(-2) + 0 + 2 = 0$ ✓

**성질 2 확인**: $(-2)^2 + 0^2 + 2^2 = 8$이고, 분산 $s^2 = \frac{8}{3}$이므로 $3 \times \frac{8}{3} = 8$ ✓

이 성질들은 분산과 표준편차를 계산할 때 필수적으로 사용되므로, 확실히 이해하고 넘어가는 것이 중요합니다.
