# 최빈값

## 정확한 진술

최빈값(mode)은 **데이터 집합에서 가장 자주 나타나는 값**입니다. 즉, 빈도(도수)가 가장 높은 값을 말합니다.

데이터 $\{x_1, x_2, \ldots, x_n\}$에서 최빈값 $M_o$는 가장 많이 나타나는 값입니다. 

$$M_o = \arg\max_x f(x)$$

여기서 $f(x)$는 값 $x$의 빈도입니다.

## 직관과 특징

최빈값은 **분포의 가장 높은 봉우리**를 나타냅니다. 도수분포표나 히스토그램에서 가장 높은 막대에 해당하는 값이 최빈값입니다.

**특이한 경우들:**
- **최빈값이 없는 경우**: 모든 값이 같은 빈도로 나타나면 최빈값이 없습니다. 예: $\{1, 2, 3, 4\}$
- **최빈값이 2개 이상인 경우**: 같은 최고 빈도를 가진 값이 여러 개면 모두 최빈값입니다. 예: $\{1, 1, 2, 2, 3\}$에서는 1과 2가 모두 최빈값 (이봉분포)

## 한 줄 예

반 학생들의 키 데이터 $\{165, 168, 168, 168, 170, 172, 175, 175\}$에서 빈도가 3으로 가장 높은 값은 **168 cm**이므로, 최빈값은 **168**입니다.

## 다른 대푯값과의 비교

최빈값은 평균(mean)과 중앙값(median)과 달리 **계산이 필요 없고** **범주형 데이터**에도 사용할 수 있습니다. 예를 들어 선호하는 색깔 조사에서 가장 많이 선택된 색을 나타낼 수 있습니다.

다만, 분포가 여러 봉우리를 가질 때 최빈값만으로는 전체 분포를 파악하기 어려울 수 있습니다.
