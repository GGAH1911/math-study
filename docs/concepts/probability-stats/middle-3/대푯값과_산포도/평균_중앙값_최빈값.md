# 평균 중앙값 최빈값

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
데이터의 중심 경향성을 나타내는 세 가지 지표인 평균, 중앙값, 최빈값의 특징을 이해합니다.

## 본문
데이터의 중심을 나타내는 대푯값에는 평균, 중앙값, 최빈값이 있습니다. **평균**은 모든 데이터의 합을 데이터의 개수로 나눈 값으로, 데이터 $x_1, x_2, \ldots, x_n$이 주어질 때 $\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$으로 계산합니다. **중앙값**은 데이터를 크기 순서대로 나열했을 때 가장 가운데에 위치한 값입니다. 데이터의 개수가 홀수이면 가운데 값이 되고, 짝수이면 가운데 있는 두 값의 평균이 됩니다. **최빈값**은 데이터 중에서 가장 빈번하게 나타나는, 즉 빈도가 가장 높은 값을 의미합니다.

### 직관과 기하적 의미
세 대푯값은 데이터의 중심을 서로 다른 관점에서 바라봅니다. 평균은 모든 데이터의 값을 산술적으로 반영하므로 데이터 전체의 균형점을 찾는 데 유용하지만, 매우 크거나 작은 극값이 존재할 경우 그 값에 크게 휘둘리는 특성이 있습니다. 반면 중앙값은 데이터의 순서에 기반하므로 극값의 영향을 거의 받지 않아, 소수의 극값이 전체 분포를 왜곡하는 상황에서 데이터의 일반적인 수준을 더 잘 보여줍니다. 최빈값은 데이터의 분포에서 가장 밀집된 구간을 찾는 데 유용하며, 수치 데이터뿐만 아니라 범주형 데이터에서도 사용할 수 있는 직관적인 지표입니다.

### 기본 성질
데이터 $(1, 2, 2, 3, 10)$을 예로 들면, 평균은 $3.6$, 중앙값은 $2$, 최빈값은 $2$입니다. 여기서 $10$이라는 극값 때문에 평균은 데이터의 일반적인 흐름보다 큰 값을 나타내지만, 중앙값은 대부분의 데이터가 모여 있는 위치를 더 정확하게 대변합니다. 또한 최빈값은 데이터의 특성에 따라 하나가 아닐 수도 있습니다.

## 학습 체크
- 극값이 포함된 데이터 집합에서 평균과 중앙값의 차이가 발생하는 이유를 설명할 수 있는가?
- 주어진 데이터 세트에서 평균, 중앙값, 최빈값을 각각 계산할 수 있는가?
- 데이터의 분포 형태에 따라 어떤 대푯값을 사용하는 것이 가장 적절한지 판단할 수 있는가?

## 관련 개념
- **대푯값과 산포도**: 대푯값은 데이터의 중심 위치를 나타내며, 산포도는 데이터가 이 중심으로부터 얼마나 퍼져 있는지를 나타내는 개념입니다.
