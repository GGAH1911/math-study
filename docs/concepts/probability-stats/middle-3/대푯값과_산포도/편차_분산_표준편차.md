# 편차 분산 표준편차

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
데이터가 평균으로부터 얼마나 떨어져 있는지 나타내는 척도로, 편차의 제곱의 평균인 분산과 그 양의 제곱근인 표준편차를 통해 데이터의 퍼짐 정도를 측정합니다.

## 본문
데이터 $x_i$와 평균 $\bar{x}$가 있을 때, 각 데이터 값이 평균에서 떨어진 정도를 나타내는 **편차**는 $x_i - \bar{x}$로 정의됩니다. 이때 모든 편차의 합은 항상 $0$이 되는 성질이 있습니다. **분산** $s^2$은 이러한 편차들을 각각 제곱하여 모두 더한 후 데이터의 개수 $n$으로 나눈 값으로, $s^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$입니다. **표준편차** $s$는 분산에 양의 제곱근을 취한 값으로, $s = \sqrt{s^2}$입니다.

### 직관과 기하적 의미
평균만으로는 데이터가 얼마나 넓게 퍼져 있는지 알 수 없습니다. 편차의 합이 $0$이 되기 때문에 편차의 크기를 반영하기 위해 제곱을 사용하며, 분산은 원래 데이터 단위의 제곱이 되므로 이를 다시 원래 단위로 맞추기 위해 제곱근을 취합니다. 표준편차가 작을수록 데이터는 평균 근처에 밀집해 있고, 클수록 평균에서 멀리 퍼져 있음을 의미합니다.

### 기본 성질
데이터 $2, 4, 6, 8$의 경우 평균은 $5$이며, 각 편차는 $-3, -1, 1, 3$입니다. 분산은 $\frac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4} = 5$이며, 표준편차는 $\sqrt{5} \approx 2.236$이 됩니다.

- 표준편차의 크기에 따라 데이터의 분포 상태를 해석할 수 있는가?

## 관련 개념
- **대푯값과 산포도**: 평균과 같은 대푯값으로 데이터의 중심을 찾고, 편차·분산·표준편차와 같은 산포도로 데이터의 흩어짐을 분석합니다.
