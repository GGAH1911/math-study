# 편차 분산 표준편차

## 본문

### 편차·분산·표준편차의 정의

**편차(deviation)**는 각 데이터 값이 평균에서 얼마나 멀어져 있는지를 나타냅니다. 데이터 $x_i$와 평균 $\bar{x}$가 있을 때, 편차는 $x_i - \bar{x}$입니다.

**분산(variance)**는 편차의 제곱을 모두 평균한 값입니다. $n$개의 데이터 $x_1, x_2, \ldots, x_n$이 있고 평균이 $\bar{x}$일 때, 분산 $s^2$는 다음과 같이 정의됩니다:

$$s^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

**표준편차(standard deviation)**는 분산의 양의 제곱근입니다:

$$s = \sqrt{s^2} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}$$

### 직관: 왜 편차를 제곱하고 제곱근을 취할까?

평균만으로는 데이터의 특징을 완전히 알 수 없습니다. 평균이 같은 두 데이터 집합도 퍼져 있는 정도가 다를 수 있기 때문입니다. 편차의 합은 항상 0이 되므로, 각 편차의 크기를 반영하기 위해 제곱합니다. 분산의 단위는 원래 데이터의 단위의 제곱이 되므로, 이를 원래 단위로 돌리기 위해 제곱근을 취한 것이 표준편차입니다. **표준편차가 작을수록 데이터가 평균 근처에 모여 있고, 클수록 퍼져 있습니다.**

### 계산 예시

데이터 $2, 4, 6, 8$의 편차·분산·표준편차를 구합시다.

- 평균: $\bar{x} = \frac{2+4+6+8}{4} = 5$
- 편차: $2-5=-3$, $4-5=-1$, $6-5=1$, $8-5=3$
- 분산: $s^2 = \frac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4} = \frac{20}{4} = 5$
- 표준편차: $s = \sqrt{5} \approx 2.236$

(검산: `from sympy import sqrt; sqrt(5)` → $\sqrt{5}$)

이 데이터는 비교적 퍼져 있으므로 표준편차가 상대적으로 큽니다.
