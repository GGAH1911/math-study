# 두 집단 비교

> **예제** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
평균이 같을 때 표준편차가 작을수록 데이터가 평균에 밀집되어 있어 성적이 더 안정적입니다.

## 본문
두 반의 수학 시험 성적이 다음과 같습니다.

**A반**: 60, 65, 70, 75, 80, 85, 90 (7명)  
**B반**: 72, 73, 74, 75, 76, 77, 78 (7명)

두 반의 성적 분포를 비교하고, 어느 반의 성적이 더 안정적인지 판단하세요.

### 단계별 풀이
**1단계: 두 반의 평균 계산하기**

평균은 두 집단의 중심을 나타내므로, 먼저 각 반의 대푯값을 구합니다.

$$\text{A반 평균} = \frac{60+65+70+75+80+85+90}{7} = \frac{525}{7} = 75$$

$$\text{B반 평균} = \frac{72+73+74+75+76+77+78}{7} = \frac{525}{7} = 75$$

두 반 모두 평균이 75점으로 같습니다. 단순히 평균만 보면 두 반의 성적이 동등해 보입니다.

**2단계: 두 반의 표준편차 계산하기**

평균이 같으므로, 표준편차로 데이터가 얼마나 흩어져 있는지 비교합니다.

$$\text{A반 분산} = \frac{(60-75)^2+(65-75)^2+\cdots+(90-75)^2}{7} = \frac{700}{7} = 100$$

$$\text{A반 표준편차} = \sqrt{100} = 10$$

$$\text{B반 분산} = \frac{(72-75)^2+(73-75)^2+\cdots+(78-75)^2}{7} = \frac{28}{7} = 4$$

$$\text{B반 표준편차} = \sqrt{4} = 2$$

**3단계: 결과 해석하기**

A반의 표준편차가 10으로 B반의 2보다 훨씬 크다는 것은, A반 학생들의 성적이 평균을 중심으로 더 넓게 퍼져 있다는 의미입니다. 반면 B반은 성적이 75점 근처에 몰려 있어 일관되고 안정적입니다.

### 답과 변형
- **평균**: 두 반 모두 75점 (동등)
- **표준편차**: A반 10점, B반 2점
- **결론**: B반의 성적이 더 안정적이고 균형 잡혀 있습니다.

만약 두 반의 평균이 다르다면 평균과 표준편차를 함께 고려해야 합니다. 예를 들어 A반 평균이 80점이고 표준편차가 5이며, B반 평균이 70점이고 표준편차가 3이라면, A반이 평균은 더 높지만 성적의 변동성은 더 크다고 해석해야 합니다.

## 학습 체크
- 평균이 동일할 때 표준편차의 크기에 따른 데이터의 분포 특징을 설명할 수 있는가?
- 평균과 표준편차가 모두 다를 때 두 집단의 성적 특성을 종합적으로 비교할 수 있는가?

## 관련 개념
- **대푯값과 산포도**: 평균은 자료의 중심 위치를 나타내며, 표준편차는 자료가 평균으로부터 얼마나 떨어져 있는지를 나타내는 산포도의 척도입니다.
