# 도수분포

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 정확한 진술

도수분포란 자료를 일정한 크기의 구간(계급)으로 나누어, 각 구간에 속하는 자료의 개수(도수)를 나타낸 것입니다. 일반적으로 도수분포표(frequency distribution table) 또는 히스토그램으로 표현합니다. 

각 계급은 다음과 같이 구성됩니다:
- **계급(class)**: 자료를 분류하기 위한 구간 (예: $160 \leq h < 170$)
- **도수(frequency)**: 각 계급에 속하는 자료의 개수 (예: 15명)
- **계급값(class mark)**: 각 계급의 중앙값 (예: $165 = \frac{160 + 170}{2}$)

## 직관/기하적 의미

도수분포는 **크기가 큰 자료 집합의 분포 패턴을 한눈에 파악**하기 위한 도구입니다. 예를 들어 1000명의 키 데이터를 개별적으로 나열하면 의미를 찾기 어렵지만, 10cm 간격의 계급으로 묶으면 "160~170cm에 가장 많은 학생이 분포"하는 식으로 즉각적으로 이해할 수 있습니다.

히스토그램은 각 계급을 가로축, 도수를 세로축으로 하는 막대 그래프이며, 도수분포곡선(frequency polygon)은 각 계급값을 꼭짓점으로 하는 꺾인선 그래프입니다. 이를 통해 데이터의 중심, 퍼짐, 기울어짐 등을 시각적으로 분석합니다.

## 한 줄 예

어느 반 40명의 수학 시험 성적을 10점 단위로 분류했을 때, "60점 이상 70점 미만" 구간에 8명이 속한다면, 이 구간의 **도수는 8**입니다.

| 계급 | 도수 |
|------|------|
| 60~70 | 8 |
| 70~80 | 12 |
| 80~90 | 15 |
| 90~100 | 5 |
