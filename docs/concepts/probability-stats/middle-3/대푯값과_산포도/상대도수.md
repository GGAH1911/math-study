# 상대도수

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
상대도수는 전체 도수에 대한 각 계급 도수의 비율로, 서로 다른 크기를 가진 자료 집단을 공정하게 비교할 수 있게 해주는 지표입니다.

## 본문
상대도수는 특정 계급의 도수를 전체 도수의 합으로 나눈 값입니다. 어떤 자료에서 $i$번째 계급의 도수를 $f_i$, 전체 도수의 합을 $n$이라 할 때, $i$번째 계급의 상대도수는 $\tfrac{f_i}{n}$으로 계산합니다.

### 직관과 기하적 의미
도수는 단순히 "얼마나 많은가"라는 절대적인 수치를 보여주지만, 표본의 크기가 서로 다른 두 자료를 비교할 때는 한계가 있습니다. 예를 들어, A 학급에서 성적 A를 받은 학생이 10명이고 B 학급에서 12명일 때, 단순히 도수만 비교하면 B 학급이 많아 보입니다. 하지만 A 학급 인원이 25명이고 B 학급 인원이 48명이라면, 실제 비율은 A 학급이 더 높습니다. 이때 상대도수를 사용하면 표본 크기의 영향을 제거하고 각 계급이 전체에서 차지하는 순수한 비중과 상대적 위치를 파악할 수 있어 서로 다른 자료를 공정하게 비교할 수 있습니다.

### 기본 성질
상대도수는 항상 0 이상 1 이하의 값을 가집니다. 모든 계급의 상대도수를 모두 더하면 항상 1이 되어야 합니다. 만약 상대도수를 백분율(%)로 나타내고자 한다면, 계산된 상대도수에 100을 곱하여 표현합니다.

## 학습 체크
- 상대도수의 모든 계급의 합이 1이 되는지 확인하였는가?
- 도수만으로 비교할 때 발생할 수 있는 오류를 상대도수가 어떻게 해결하는지 이해하였는가?
- 상대도수를 백분율로 변환할 때 곱해야 하는 상수는 무엇인가?

## 관련 개념
- **통계**: 자료의 특성을 수치로 요약하여 나타내는 과정에서, 상대도수는 자료의 분포를 비율로 나타내는 핵심적인 도구로 사용됩니다.
