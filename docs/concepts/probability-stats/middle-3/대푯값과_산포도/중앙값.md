# 중앙값

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
자료를 크기 순으로 나열했을 때 가운데 위치하는 값으로, 극단적인 값의 영향을 받지 않고 자료의 중심 경계를 나타냅니다.

## 본문
자료를 크기 순서로 정렬했을 때 가운데에 위치하는 값을 중앙값이라고 합니다. 중앙값은 평균, 최빈값과 함께 자료의 특징을 하나의 수로 나타내는 대푯값 중 하나입니다. 자료의 개수가 $n$개일 때, $n$이 홀수라면 $\tfrac{n+1}{2}$번째 값이 중앙값이 되며, $n$이 짝수라면 가운데 위치한 두 값 $\tfrac{n}{2}$번째 값과 $\left(\tfrac{n}{2}+1\right)$번째 값의 평균이 중앙값이 됩니다.

### 직관과 기하적 의미
중앙값은 자료를 정확히 반으로 나누는 경계값의 의미를 갖습니다. 전체 자료의 $50\%$는 중앙값보다 작거나 같고, 나머지 $50\%$는 중앙값보다 크거나 같게 분포하여 자료의 중심 위치를 직관적으로 보여줍니다.

### 기본 성질
중앙값은 평균과 달리 극단적인 값(이상치)에 영향을 거의 받지 않는다는 강력한 특징이 있습니다. 예를 들어, 대부분의 값이 특정 범위에 모여 있고 단 하나의 값만 매우 크거나 작은 경우, 평균은 그 극단적인 값에 의해 왜곡되어 자료 전체를 대표하기 어려울 수 있습니다. 하지만 중앙값은 자료의 순위만을 기준으로 하므로, 이러한 이상치가 포함되어도 자료의 전형적인 모습을 안정적으로 나타냅니다.

## 학습 체크
- 자료의 개수가 짝수일 때 중앙값을 구하는 방법은 무엇인가요?
- 평균과 비교했을 때 중앙값이 가지는 가장 큰 장점은 무엇인가요?

## 관련 개념
- **대푯값과 산포도**: 중앙값은 자료를 대표하는 **대푯값**의 일종이며, 자료가 중앙값으로부터 얼마나 퍼져 있는지를 나타내는 **산포도**와 함께 자료의 분포 상태를 파악하는 데 사용됩니다.
