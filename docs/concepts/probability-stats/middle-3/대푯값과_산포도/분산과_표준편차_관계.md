# 분산과 표준편차 관계

> **정리** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
표준편차는 분산에 제곱근을 취한 값으로, 자료의 산포도를 원래 자료와 같은 단위로 나타낸 지표입니다.

## 본문
표준편차는 분산의 양의 제곱근입니다. 자료의 분산을 $V$라고 할 때, 표준편차 $\sigma$는 $\sigma = \sqrt{V}$의 관계를 만족합니다. 분산 $V$는 각 자료값과 평균의 차이인 편차를 제곱하여 평균낸 값으로, 자료가 평균으로부터 얼마나 떨어져 있는지를 나타내는 산포도를 측정합니다.

### 증명 스케치
평균이 $\bar{x}$인 자료 $x_1, x_2, \ldots, x_n$에 대하여 분산 $V$는 다음과 같이 정의됩니다.
$$V = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$
분산은 편차를 제곱하여 계산하므로 결과값이 원래 자료의 단위와 다르게 제곱된 형태로 나타납니다. 따라서 원래 자료의 단위로 되돌리기 위해 분산에 제곱근을 취하면 표준편차가 됩니다.
$$\sigma = \sqrt{V} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}$$
예를 들어 자료가 1, 3, 5, 7, 9일 때, 평균은 5이며 분산은 $\frac{(1-5)^2+(3-5)^2+(5-5)^2+(7-5)^2+(9-5)^2}{5} = 8$입니다. 이때 표준편차는 $\sqrt{8} = 2\sqrt{2}$가 됩니다.

### 의의와 응용
분산은 계산 과정에서 값을 제곱하기 때문에 원래 자료의 단위와 일치하지 않는다는 단점이 있습니다. 반면 표준편차는 제곱근을 취함으로써 원래 자료와 동일한 단위를 갖게 되어, 자료의 흩어진 정도를 직관적으로 해석할 수 있게 해줍니다. 예를 들어 키의 분산이 $25\text{ cm}^2$라면 표준편차는 $5\text{ cm}$가 되며, 이는 자료들이 평균으로부터 평균적으로 $5\text{ cm}$ 정도 떨어져 있음을 의미합니다. 이러한 직관성 덕분에 실제 통계 분석이나 수능 등에서는 산포도를 비교할 때 표준편차를 주로 사용합니다.

## 학습 체크
- 분산의 값에 제곱근을 취했을 때 표준편차가 도출되는 과정을 설명할 수 있는가?
- 분산과 표준편차의 단위 차이가 데이터 해석에 어떤 영향을 미치는지 이해하고 있는가?
- 주어진 자료의 분산을 구한 뒤 이를 이용해 표준편차를 정확히 계산할 수 있는가?

## 관련 개념
- **대푯값과 산포도**: 자료의 중심 위치를 나타내는 대푯값과 자료가 퍼진 정도를 나타내는 산포도 중, 산포도를 나타내는 핵심 지표로 표준편차가 활용됩니다.
