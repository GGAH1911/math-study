# 누적도수

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
어떤 계급 이하의 모든 도수를 합한 값으로, 데이터가 특정 값 이하에 얼마나 분포하는지 파악하는 데 사용됩니다.

## 본문
어떤 계급 이하의 모든 도수를 합한 값을 **누적도수**(cumulative frequency)라고 합니다. $i$번째 계급까지의 누적도수는 $F_i = f_1 + f_2 + \cdots + f_i$로 정의되며, 여기서 $f_j$는 $j$번째 계급의 도수입니다.

### 직관과 기하적 의미
누적도수는 "특정 값 이하인 데이터가 몇 개나 되는가?"라는 질문에 대한 해답을 제공합니다. 도수분포표의 위에서부터 아래로 도수를 차례대로 더해나가면 구할 수 있으며, 마지막 계급의 누적도수는 항상 전체 표본의 크기 $n$과 일치하게 됩니다. 이를 히스토그램 위에 그래프로 나타내면 오른쪽 위로 올라가는 단조증가 곡선인 누적도수 그래프(오자이브)가 됩니다. 이 그래프를 통해 데이터가 어느 범위에 집중되어 있는지 시각적으로 확인할 수 있으며, 전체의 50%에 해당하는 중앙값이나 특정 백분위수를 찾는 데 유용하게 활용됩니다.

### 기본 성질
도수분포표를 예로 들어 시험 점수를 분류했을 때, 각 계급의 도수가 $5, 8, 12, 5$라면 누적도수는 $5, 13, 25, 30$이 됩니다. 즉, 80점 이하인 학생은 13명임을 바로 알 수 있습니다. 또한, 계급별 상대도수를 누적하여 계산한 **누적상대도수** $\tfrac{F_i}{n}$는 0부터 1(또는 0%에서 100%)까지 증가하는 성질을 가집니다. 위 예제에서 80점 이하인 학생의 누적상대도수는 $\tfrac{13}{30} \approx 0.433$, 즉 약 43.3%가 됩니다.

## 학습 체크
- 마지막 계급의 누적도수는 왜 항상 전체 도수의 합과 같아야 할까요?
- 누적도수 그래프가 오른쪽 위로만 올라가는 형태를 띠는 이유는 무엇인가요?
- 누적상대도수에서 마지막 계급의 값은 항상 얼마가 되어야 하나요?

## 관련 개념
- **통계**: 자료의 분포 상태를 요약하여 나타내는 과정에서 누적도수는 데이터의 누적된 분포 양상을 보여주는 중요한 지표로 활용됩니다.
