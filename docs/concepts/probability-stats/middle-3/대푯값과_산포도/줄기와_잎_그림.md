# 줄기와 잎 그림

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
데이터를 큰 자리수와 작은 자리수로 나누어 줄기와 잎으로 나타냄으로써, 개별 자료값을 보존하면서도 전체적인 분포를 한눈에 파악할 수 있게 하는 자료 정리 방법입니다.

## 본문
줄기와 잎 그림은 주어진 데이터를 두 부분으로 나누어 표시하는 자료 정리 방법입니다. 각 자료의 값을 줄기와 잎으로 분해하여, 줄기는 수직으로 나열하고 잎은 줄기의 오른쪽에 가로로 배열합니다. 예를 들어 데이터가 $23, 24, 27, 31, 35$라면, 줄기는 $2$와 $3$이 되고, 줄기 $2$에 붙는 잎은 $3, 4, 7$이 되며, 줄기 $3$에 붙는 잎은 $1, 5$가 됩니다.

### 직관과 기하적 의미
줄기와 잎 그림은 히스토그램처럼 도수 분포를 시각화하여 자료가 어느 범위에 집중되어 있는지 명확하게 보여줍니다. 줄기는 자료의 큰 자리수를, 잎은 작은 자리수를 나타내어 자료의 전체적인 분포 양상을 직관적으로 파악하게 합니다.

### 기본 성질
이 방법은 원래 자료값을 모두 보존하면서도 분포를 한눈에 파악할 수 있다는 특징이 있습니다. 히스토그램과 달리 개별 데이터값이 손실되지 않으므로, 잎을 크기 순서대로 정렬하여 배치하면 중앙값이나 사분위수와 같은 통계량을 매우 쉽게 구할 수 있습니다.

## 학습 체크
- 줄기와 잎 그림에서 잎을 정렬하여 배열했을 때, 전체 자료의 개수를 통해 중앙값을 어떻게 찾을 수 있는가?
- 히스토그램과 비교했을 때 줄기와 잎 그림만이 가지는 데이터 보존 측면의 장점은 무엇인가?

## 관련 개념
- **통계**: 자료를 수집하고 정리하여 의미 있는 정보를 추출하는 과정에서 줄기와 잎 그림은 데이터를 시각화하는 기초적인 도구로 활용됩니다.
