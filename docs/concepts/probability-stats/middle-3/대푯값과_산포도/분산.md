# 분산

## 요약
분산은 데이터가 평균으로부터 얼마나 떨어져 있는지를 나타내는 척도로, 편차 제곱의 평균을 의미합니다.

## 본문
주어진 데이터 $x_1, x_2, \ldots, x_n$의 평균을 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$라 할 때, **분산**(variance)은 다음과 같이 정의됩니다.

$$\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

이는 각 데이터가 평균으로부터 떨어진 거리(편차)의 제곱을 모두 더한 후 데이터의 개수로 나눈 값입니다. 다만, 표본 분산을 구할 때는 분모를 $n-1$로 나누어 계산하기도 합니다.

### 직관과 기하적 의미
분산은 데이터가 평균 주위에 얼마나 밀집해 있는지 또는 흩어져 있는지를 보여주는 지표입니다. 데이터들이 평균에 가깝게 모여 있을수록 분산은 작아지고, 평균에서 멀리 떨어져 있을수록 분산은 커집니다. 편차를 제곱하여 합산하는 이유는 음수가 발생하는 것을 방지하고, 평균에서 멀리 떨어진 값에 더 큰 가중치를 부여하기 위함입니다. 만약 모든 데이터가 평균과 동일하다면 분산은 $0$이 됩니다.

### 기본 성질
데이터의 편차의 합은 항상 $0$이 되므로, 분산을 구하기 위해서는 반드시 편차를 제곱하는 과정이 필요합니다. 분산은 항상 $0$ 이상의 값을 가지며, 데이터의 산포도를 나타내는 대표적인 통계량입니다.

## 학습 체크
- 분산의 정의에서 왜 편차를 그대로 더하지 않고 제곱하여 더하는지 설명할 수 있는가?
- 데이터의 값이 평균에서 멀어질 때 분산의 크기는 어떻게 변화하는가?
- 데이터 $\{2, 4, 6\}$의 분산을 직접 계산하여 $\frac{8}{3}$이 나오는지 확인할 수 있는가?
