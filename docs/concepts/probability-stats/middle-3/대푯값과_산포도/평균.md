# 평균

## 정확한 진술

평균(또는 산술평균)은 주어진 자료의 모든 값을 더한 후 자료의 개수로 나눈 값입니다. $n$개의 자료값이 $x_1, x_2, \ldots, x_n$일 때, 평균 $\bar{x}$는 다음과 같이 정의합니다:

$$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

이때 $\sum$ 기호는 "모두 더한다"는 의미입니다.

## 직관/기하적 의미

평균은 자료 전체를 가장 잘 대표하는 하나의 값입니다. 수직선 위에 각 자료값을 점으로 나타내면, 평균은 이 점들을 모두 같은 무게로 매달았을 때 균형을 이루는 점—즉 "무게 중심"—처럼 작동합니다. 

실생활로 생각해보면, 5명이 받은 총상금이 500원이라면 각자 똑같이 나눠주는 금액은 평균인 100원입니다. 비슷하게 한 반 학생들의 키의 평균은 "이 반 학생들의 '전형적인' 키가 몇 cm인가"를 보여줍니다. 평균은 대푯값 중에서 가장 널리 사용되는데, 모든 자료값을 고르게 반영하고 계산이 간단하기 때문입니다.

## 한 줄 예

시험 점수가 60, 70, 80, 90, 100점인 5명 학생의 평균 점수는 $\bar{x} = \frac{60+70+80+90+100}{5} = \frac{400}{5} = 80$점입니다.
