# 평균

> **정의** · 중3 · 단원: [대푯값과 산포도](/concepts/대푯값과_산포도)

## 요약
평균은 모든 자료의 값을 더한 후 자료의 개수로 나눈 값으로, 자료 전체를 대표하는 하나의 수치입니다.

## 본문
평균(또는 산술평균)은 주어진 자료의 모든 값을 더한 후 자료의 개수로 나눈 값입니다. $n$개의 자료값이 $x_1, x_2, \ldots, x_n$일 때, 평균 $\bar{x}$는 다음과 같이 정의합니다:

$$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

이때 $\sum$ 기호는 모든 자료값을 더한다는 의미를 나타냅니다.

### 직관과 기하적 의미
평균은 자료 전체를 가장 잘 대표하는 하나의 값입니다. 수직선 위에 각 자료값을 점으로 나타내면, 평균은 이 점들을 모두 같은 무게로 매달았을 때 균형을 이루는 점, 즉 "무게 중심"과 같은 역할을 합니다. 실생활의 예로 5명이 받은 총상금이 500원일 때 각자 똑같이 나누어 갖는 금액인 100원이 평균에 해당합니다. 또한 한 반 학생들의 키의 평균은 그 반 학생들의 "전형적인" 키가 얼마인지를 보여줍니다. 평균은 모든 자료값을 고르게 반영하고 계산이 간단하여 대푯값 중에서 가장 널리 사용됩니다.

### 기본 성질
시험 점수가 60, 70, 80, 90, 100점인 5명 학생의 평균 점수는 다음과 같이 계산할 수 있습니다.
$$\bar{x} = \frac{60+70+80+90+100}{5} = \frac{400}{5} = 80\text{점}$$

## 학습 체크
- 자료의 개수가 변할 때 평균값은 어떻게 변하는가?
- 평균이 자료의 전체적인 특징을 대표하기 위해 갖추어야 할 조건은 무엇인가?

## 관련 개념
- **대푯값과 산포도**: 평균은 자료의 중심 경향을 나타내는 대표적인 **대푯값**이며, 자료가 평균으로부터 얼마나 퍼져 있는지를 나타내는 **산포도**와 함께 자료의 특성을 분석하는 데 사용됩니다.
