### 정확한 진술

확률변수 $X$에 대해 누적분포함수(누적분포함수, CDF)는 다음과 같이 정의됩니다.

$$F(x) = P(X \leq x)$$

즉, 확률변수 $X$가 $x$ 이하의 값을 가질 확률입니다. 모든 $x$에 대해 정의되며, $F(\infty) = 1$, $F(-\infty) = 0$을 만족합니다.

### 직관과 성질

누적분포함수는 확률을 **누적**하여 보여줍니다. 그래프에서 특정 점 $x$의 함숫값 $F(x)$는, 수직선을 따라 왼쪽(음의 방향)에 있는 모든 확률을 합친 값입니다.

**이산확률변수**인 경우, $F(x)$는 계단 모양으로 증가합니다. **연속확률변수**인 경우, 확률밀도함수 $f(x)$와의 관계는

$$F(x) = \int_{-\infty}^{x} f(t) \, dt$$

입니다. 즉, 누적분포함수를 미분하면 확률밀도함수를 얻습니다: $F'(x) = f(x)$.

또한 임의의 $a < b$에 대해

$$P(a < X \leq b) = F(b) - F(a)$$

가 성립하므로, 누적분포함수로부터 구간 확률을 쉽게 구할 수 있습니다.

### 예시

표준정규분포 $N(0, 1)$의 누적분포함수를 $\Phi(x)$라 하면, 시험 점수가 표준정규분포를 따를 때 "점수가 0 이하일 확률"은 $\Phi(0) = 0.5$입니다. 마찬가지로 "점수가 1.96 이하일 확률"은 $\Phi(1.96) \approx 0.975$입니다.

(검증: 표준정규분포 누적분포함수 값 계산은 통계 소프트웨어나 표를 이용하여 확인 가능)
