# 원순열

> **예제** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$(n-1)!$

## 본문 (학습 시 채워짐)

### 문제

A, B, C, D 4명이 둥근 테이블에 앉을 때, 시계방향으로 같은 배열은 같은 것으로 간주합니다. 이 경우의 수를 구하세요.

### 단계별 풀이

**1단계: 일렬 배열의 경우의 수 구하기**
4명을 일렬로 배열하면 순열 공식 $4! = 24$가지입니다. — 아직 원형 특성을 고려하지 않은 상태

**2단계: 원형 배열에서 회전의 중복 인식하기**
둥근 테이블에서는 회전으로 같은 배열을 구분하지 않습니다. 예를 들어 시계방향으로 A-B-C-D, B-C-D-A, C-D-A-B, D-A-B-C는 모두 같은 배열입니다. 이렇게 4가지가 같으므로 일렬 배열 24가지를 4로 나누어야 합니다.

**3단계: 원순열 공식 적용하기**
n명이 원탁에 앉는 경우의 수는 $(n-1)! = \frac{n!}{n}$입니다. 여기서 A의 자리를 고정시키고 나머지를 배열하는 것과 같으므로 $(4-1)! = 3! = 6$

### 답

**6가지** (또는 $(4-1)! = 3! = 6$)

```python
import math
math.factorial(3)  # = 6 ✓
```

### 변형/주의

- **뒤집기 포함 시**: 테이블 뒷면에서도 같다면(목걸이처럼 뒤집기 대칭) $(n-1)!/2$로 더 줄어듭니다.
- **한 자리 고정**: "A는 맨 위에 항상 앉음"이라 정하면, 나머지 3명을 배열하는 $3! = 6$과 같습니다.
- **같은 것이 있는 경우**: 빨간 구슬 2개, 파란 구슬 2개를 원형 배열하면 $\frac{(n-1)!}{\text{같은 것의 개수}!}$를 적용합니다.
