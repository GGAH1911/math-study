# 두 곡선 넓이 예제

> **예제** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
$y=x, y=x^2$

## 본문 (학습 시 채워짐)

### 문제

$y=x$와 $y=x^2$으로 둘러싸인 영역의 넓이를 구하시오.

### 단계별 풀이

**1단계: 두 곡선의 교점 구하기**  
두 곡선이 만나는 점에서 $y$ 좌표가 같으므로 $x = x^2$를 풉니다. $x^2 - x = 0$에서 $x(x-1) = 0$이므로 $x=0$ 또는 $x=1$입니다. 이것이 적분 구간의 경계입니다.

**2단계: 어느 곡선이 위에 있는지 확인**  
$0 < x < 1$ 구간에서 한 점, 예를 들어 $x=0.5$를 대입해봅시다. $y=x$일 때 $y=0.5$이고, $y=x^2$일 때 $y=0.25$입니다. 따라서 $y=x$이 $y=x^2$보다 위에 있습니다.

**3단계: 정적분 세우기**  
두 곡선 사이의 넓이는 (위의 함수) − (아래의 함수)를 적분합니다:
$$S = \int_0^1 (x - x^2) \, dx$$

**4단계: 적분 계산**  
부정적분을 구하면:
$$\int (x - x^2) \, dx = \frac{x^2}{2} - \frac{x^3}{3} + C$$

정적분을 계산합니다:
$$S = \left[ \frac{x^2}{2} - \frac{x^3}{3} \right]_0^1 = \left( \frac{1}{2} - \frac{1}{3} \right) - 0 = \frac{3}{6} - \frac{2}{6} = \frac{1}{6}$$

검산: `sympy.integrate(x - x**2, (x, 0, 1))`

### 답

$$\frac{1}{6}$$

### 변형·주의

- **부호 확인**: 항상 (위의 함수) − (아래의 함수) 순서로 빼야 넓이는 양수가 됩니다.
- **교점 놓치기**: 교점을 정확히 찾지 못하면 적분 구간을 잘못 설정합니다. 대수적으로 정확히 풀어야 합니다.
- **확장**: 3개 이상의 곡선이 얽혀 있을 땐 구간을 나누어 계산합니다. 예를 들어 $y=x$, $y=x^2$, $y=2-x$가 모두 만날 때는 교점마다 적분 구간을 새로 나눕니다.
