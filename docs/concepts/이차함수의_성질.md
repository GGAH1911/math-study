### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 성질은 다음과 같습니다:

- **꼭짓점**: $x = -\dfrac{b}{2a}$에서 최댓값 또는 최솟값을 가지며, 꼭짓점은 $\left(-\dfrac{b}{2a}, -\dfrac{\Delta}{4a}\right)$입니다. 여기서 $\Delta = b^2 - 4ac$는 판별식입니다.
- **대칭축**: 직선 $x = -\dfrac{b}{2a}$에 대해 대칭입니다.
- **최댓값/최솟값**: $a > 0$일 때는 최솟값 $-\dfrac{\Delta}{4a}$를, $a < 0$일 때는 최댓값 $-\dfrac{\Delta}{4a}$를 갖습니다.
- **근과 판별식의 관계**: $\Delta = b^2 - 4ac > 0$이면 서로 다른 두 실근, $\Delta = 0$이면 중근, $\Delta < 0$이면 실근이 없습니다.

### 기하적 의미

이차함수의 그래프는 **포물선**입니다. $a$의 부호에 따라 포물선이 위(아래)로 볼록한 모양이 결정되며, 꼭짓점이 최솟값(최댓값) 위치가 됩니다. 대칭축을 기준으로 양쪽이 완전히 같은 모양이므로, 함수의 증감을 판단할 때 꼭짓점이 핵심입니다. 또한 $\Delta$의 부호는 포물선이 $x$축과 만나는지를 결정합니다.

### 예

$f(x) = x^2 - 4x + 3$에서: 꼭짓점은 $x = 2$, 최솟값은 $f(2) = -1$입니다. 대칭축은 $x = 2$이고, $\Delta = 16 - 12 = 4 > 0$이므로 두 실근 $x = 1, 3$을 가집니다.

```
# sympy로 검증
from sympy import symbols, solve
x = symbols('x')
f = x**2 - 4*x + 3
solve(f, x)  # [1, 3]
```
