### 정확한 진술

삼각함수 부등식이란 $\sin\theta$, $\cos\theta$, $\tan\theta$ 등의 삼각함수에 대한 부등식으로, 해는 일반각 $\theta$ (또는 $x$)의 범위입니다. 가장 기본적인 형태는 $\sin\theta > a$, $\cos\theta \leq b$, $\tan\theta < c$ 등이며, 여기서 $a, b, c$는 정상수입니다. 삼각함수의 주기성 때문에 한 주기 $[0, 2\pi)$ (또는 $[0°, 360°)$) 내의 해를 먼저 구한 뒤, 주기를 더하여 일반해를 나타냅니다.

### 직관 및 기하적 의미

단위원 상에서 생각하면 직관적입니다. $\sin\theta > \frac{1}{2}$는 "단위원 위의 점 $(\cos\theta, \sin\theta)$의 $y$좌표가 $\frac{1}{2}$보다 크다"는 뜻입니다. $[0, 2\pi)$에서는 $\theta \in (\frac{\pi}{6}, \frac{5\pi}{6})$이 되고, 일반해는 $2\pi n$의 주기를 더해 $\theta = 2\pi n + \frac{\pi}{6} < \theta < 2\pi n + \frac{5\pi}{6}$ (단, $n$은 정수)입니다. 

마찬가지로 $\cos\theta \leq -\frac{1}{2}$는 $x$좌표가 $-\frac{1}{2}$ 이하인 영역으로, $[0, 2\pi)$에서 $\theta \in [\frac{2\pi}{3}, \frac{4\pi}{3}]$입니다.

### 한 줄 예

$\sin x > \frac{\sqrt{3}}{2}$를 $[0, 2\pi)$에서 풀면, $x \in (\frac{\pi}{3}, \frac{2\pi}{3})$ 이고, 일반해는 $2\pi n + \frac{\pi}{3} < x < 2\pi n + \frac{2\pi}{3}$ (정수 $n$)입니다. 코드 검증: `sympy.solve(sympy.sin(x) - sympy.sqrt(3)/2 > 0, x, domain=sympy.S.Reals)` 로 수치 확인 가능합니다.
