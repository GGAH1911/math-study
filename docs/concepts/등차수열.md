# 등차수열

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
연속한 두 항의 차가 일정

## 본문 (학습 시 채워짐)

### 정확한 진술

등차수열은 **연속한 두 항의 차가 항상 같은 상수인 수열**입니다. 즉, 수열 $\{a_n\}$에서 $a_{n+1} - a_n = d$ (단, $d$는 상수)를 만족할 때, 이 수열을 공차가 $d$인 등차수열이라 합니다. 첫째항을 $a$, 공차를 $d$라 하면, 등차수열의 **일반항**은 다음과 같습니다:

$$a_n = a + (n-1)d$$

### 직관과 의미

등차수열은 매 단계마다 일정량씩 규칙적으로 증가하거나 감소하는 수열입니다. 예를 들어 월급이 매달 일정액씩 오른다면, 각 달의 월급은 등차수열을 이룹니다. 좌표평면에서 등차수열의 항들 $(n, a_n)$을 점으로 나타내면 **일직선 위에 놓입니다**. 이는 등차수열이 선형 관계를 가진다는 의미입니다.

### 단계별 이해

첫째항 $a = 3$, 공차 $d = 2$인 등차수열을 생각해봅시다. 항을 나열하면 $3, 5, 7, 9, 11, \ldots$입니다. 다섯째항은 $a_5 = 3 + (5-1) \times 2 = 11$입니다. 

일반항 공식 $a_n = a + (n-1)d$를 외우는 것보다, 첫 몇 항을 직접 써보며 규칙을 찾는 것이 이해에 도움됩니다. 또한 **세 항 이상이 주어졌을 때 등차수열인지 판별**하려면 인접한 항들의 차가 모두 같은지 확인하면 됩니다.

(`sympy.symbols('n'); a_n = 3 + (n-1)*2; [a_n.subs(n, i) for i in range(1, 6)]` → `[3, 5, 7, 9, 11]`)
