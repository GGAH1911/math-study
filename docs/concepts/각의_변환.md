# 각의 변환

## 요약
삼각함수에서 $90^\circ \times n \pm \theta$ 꼴의 각을 $\theta$에 관한 식으로 변환할 때, $n$의 홀짝 여부에 따라 함수를 결정하고 사분면의 부호를 적용하는 공식 체계이다.

## 본문
삼각함수에서 **각의 변환**이란 $90^\circ \times n \pm \theta$ (또는 $\tfrac{\pi}{2} \cdot n \pm \theta$) 꼴의 각에 대한 삼각함수 값을 $\theta$의 삼각함수로 바꾸는 공식 체계이다. 이 변환의 핵심 규칙은 두 가지이다. 첫째, $n$이 짝수이면 함수 이름은 그대로 유지되지만, $n$이 홀수이면 $\sin \leftrightarrow \cos$, $\tan \leftrightarrow \cot$와 같이 여함수(co-function) 형태로 바뀐다. 둘째, 변환된 함수의 부호는 원래의 각도가 위치한 사분면에서 해당 삼각함수가 가지는 부호와 동일하게 결정한다.

### 직관과 기하적 의미
각의 변환은 단위원 위에서 각의 위치 변화에 따른 삼각함수의 좌표 변화를 나타낸다. $90^\circ$의 배수를 기준으로 각을 분해하면, 회전된 각이 어느 사분면에 위치하는지를 파악하여 함수의 부호를 결정할 수 있다. 이는 복잡한 각을 특수각인 $\theta$로 환원하여 계산을 단순화하는 데 목적이 있다.

### 기본 성질
주요 공식의 예시는 다음과 같다.
- $\sin(90^\circ - \theta) = \cos\theta$, $\cos(90^\circ - \theta) = \sin\theta$
- $\sin(180^\circ - \theta) = \sin\theta$, $\cos(180^\circ - \theta) = -\cos\theta$
- $\sin(90^\circ + \theta) = \cos\theta$, $\cos(90^\circ + \theta) = -\sin\theta$
