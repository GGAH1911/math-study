# 각의 변환

## 정의

삼각함수에서 **각의 변환**이란 $90° \times n \pm \theta$ (또는 $\dfrac{\pi}{2} \cdot n \pm \theta$) 꼴의 각에 대한 삼각함수 값을 $\theta$의 삼각함수로 바꾸는 공식 체계이다. $n$이 짝수이면 함수 이름은 그대로 유지되고, $n$이 홀수이면 sin↔cos, tan↔cot처럼 여함수(co-)로 바뀐다. 부호는 원래 각도가 속하는 사분면에서 해당 삼각함수의 부호를 따른다.

주요 공식 예시:
- $\sin(90° - \theta) = \cos\theta$, $\cos(90° - \theta) = \sin\theta$
- $\sin(180° - \theta) = \sin\theta$, $\cos(180° - \theta) = -\cos\theta$
- $\sin(90° + \theta) = \cos\theta$, $\cos(90° + \theta) = -\sin\theta$

## 예시

$\cos 120°$의 값을 구하시오.

$$\cos 120° = \cos(180° - 60°) = -\cos 60° = -\frac{1}{2}$$
