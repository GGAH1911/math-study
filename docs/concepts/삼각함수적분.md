### 정확한 진술

삼각함수의 적분이란 $\sin x$, $\cos x$, $\tan x$ 등 삼각함수를 피적분함수로 하는 정적분을 계산하는 것입니다. 기본 부정적분 공식은 다음과 같습니다:

$$\int \sin x \, dx = -\cos x + C$$

$$\int \cos x \, dx = \sin x + C$$

$$\int \tan x \, dx = -\ln|\cos x| + C$$

정적분으로는 구간 $[a, b]$에서 미적분학의 기본정리를 적용합니다:

$$\int_a^b \sin x \, dx = [-\cos x]_a^b = -\cos b + \cos a$$

### 직관/기하적 의미

$\sin x$의 그래프는 파동 형태이며, 정적분 $\int_a^b \sin x \, dx$는 그 곡선 아래의 넓이를 의미합니다. 다만 $x$축 아래 부분은 음수로 계산되므로, 실제로는 위쪽 넓이에서 아래쪽 넓이를 뺀 값입니다. 한 주기($0$부터 $2\pi$까지)에서 양수 부분과 음수 부분의 넓이가 정확히 상쇄되어 정적분값은 0이 됩니다. 이는 삼각함수의 주기성과 대칭성이 적분에 반영되는 현상입니다. 또한 부정적분에서 $\cos x$의 도함수가 $-\sin x$이므로, 역으로 $\sin x$를 적분하면 $-\cos x$가 되는데, 이는 미분과 적분이 역연산임을 보여줍니다.

### 한 줄 예

$$\int_0^{\pi} \sin x \, dx = [-\cos x]_0^{\pi} = -\cos \pi + \cos 0 = 1 + 1 = 2$$

(검산: `from sympy import *; integrate(sin(x), (x, 0, pi))`)
