### 정확한 진술

미정상수(undetermined constant)란 함수식에 포함된 미지의 상수(보통 $a, b, c$ 등으로 표기)를 말합니다. **미정상수의 결정**이란 함수가 특정 조건—주로 연속성, 미분가능성, 극값 조건 등—을 만족하도록 하는 상수의 값을 구하는 과정입니다. 

수식으로 표현하면, 함수

$$f(x) = \begin{cases} x^2 + a & \text{if } x \leq 1 \\ 2x + b & \text{if } x > 1 \end{cases}$$

가 $x = 1$에서 연속이 되는 $a, b$ 값을 찾는 것입니다.

### 직관적 의미

함수가 어떤 점에서 끊어지지 않으려면, 좌극한과 우극한이 같아야 하고, 함수값도 그와 같아야 합니다. 이 조건이 바로 연속성 정의입니다. 미정상수가 포함된 구간별 함수의 경우, **경계점에서 좌극한 = 우극한 = 함수값**이 되도록 상수를 조정합니다. 기하학적으로는 그래프가 끊어지거나 튀지 않도록, 매끄럽게 이어지게 하는 상수 값을 찾는 것입니다.

### 기본 예

함수 $f(x) = \begin{cases} x + 2 & \text{if } x < 1 \\ a & \text{if } x = 1 \\ 2x & \text{if } x > 1 \end{cases}$가 $x=1$에서 연속이려면, $\lim_{x \to 1^-} f(x) = 1 + 2 = 3$이고 $\lim_{x \to 1^+} f(x) = 2 \cdot 1 = 2$이므로 좌극한과 우극한이 다릅니다. 따라서 이 함수는 $a$의 어떤 값으로도 연속이 될 수 없습니다.

### 실제 예: 연속 함수 찾기

함수 $g(x) = \begin{cases} 3x + 1 & \text{if } x < 2 \\ a & \text{if } x = 2 \\ x^2 & \text{if } x > 2 \end{cases}$가 $x=2$에서 연속이 되는 $a$를 구합시다.

- $\lim_{x \to 2^-} g(x) = 3(2) + 1 = 7$
- $\lim_{x \to 2^+} g(x) = 2^2 = 4$

좌극한 ≠ 우극한이므로 불연속입니다. 만약 $g(x) = \begin{cases} 2x + 1 & \text{if } x < 2 \\ a & \text{if } x = 2 \\ x^2 & \text{if } x > 2 \end{cases}$이면, 좌극한 = $2(2)+1=5$, 우극한 = $4$로 여전히 불연속입니다.

올바른 문제: $h(x) = \begin{cases} 2x & \text{if } x < 2 \\ a & \text{if } x = 2 \\ x^2 - 4 & \text{if } x > 2 \end{cases}$에서 좌극한 = $2 \cdot 2 = 4$, 우극한 = $4 - 4 = 0$이므로 역시 불연속입니다. 

연속되는 경우: $f(x) = \begin{cases} x + 1 & \text{if } x < 1 \\ a & \text{if } x = 1 \\ 2x & \text{if } x > 1 \end{cases}$에서 좌극한 = $1+1=2$, 우극한 = $2 \cdot 1 = 2$이므로 $a = 2$일 때 연속입니다. ✓
