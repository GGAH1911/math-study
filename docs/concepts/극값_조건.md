### 정확한 진술

함수 $f(x)$가 $x=a$를 포함하는 구간에서 미분가능할 때, $x=a$에서 극값을 가지기 위한 필요충분조건은 다음 중 하나입니다.

**1차 도함수 판정법**: $f'(a) = 0$이고, $x=a$의 좌우에서 $f'(x)$의 부호가 바뀐다. 즉, $x<a$일 때와 $x>a$일 때 $f'(x)$의 부호가 다르면 극값을 가진다.
- $f'(x)$가 음에서 양으로 바뀌면: $x=a$에서 극소
- $f'(x)$가 양에서 음으로 바뀌면: $x=a$에서 극대

**2차 도함수 판정법**: $f'(a) = 0$이고 $f''(a) \neq 0$일 때,
- $f''(a) < 0$이면 $x=a$에서 극대
- $f''(a) > 0$이면 $x=a$에서 극소

### 직관과 기하적 의미

극값이란 함수가 어떤 점에서 국소적으로 최댓값(극대)이나 최솟값(극소)을 갖는 경우입니다. **1차 도함수 판정법**은 "기울기가 0이 되는 점에서, 양쪽으로 기울기 방향이 반대면 산봉우리나 계곡이다"는 직관입니다. **2차 도함수 판정법**은 더 빠른 판정으로, 2차 도함수가 음수면 그래프가 아래로 볼록(극대), 양수면 위로 볼록(극소)인 상황을 의미합니다. 

다만 2차 도함수 판정법은 $f''(a) = 0$인 변곡점에서는 사용할 수 없으므로, 1차 판정법이 더 일반적입니다.

### 예시

$f(x) = x^3 - 3x$에서 극값을 찾아봅시다.
- $f'(x) = 3x^2 - 3 = 3(x^2-1)$이므로 $f'(x)=0$일 때 $x=-1$ 또는 $x=1$
- $x=-1$에서: $f'(x)$가 양 → 음으로 바뀌므로 **극대** ($f(-1)=2$)
- $x=1$에서: $f'(x)$가 음 → 양으로 바뀌므로 **극소** ($f(1)=-2$)

검증: `sympy.solve(3*x**2 - 3, x)` → `[-1, 1]`
