# 함수의 극한과 연속

> **단원** · 수학2 · 선수: [함수와 그래프](./함수와_그래프.md) · 다음: [극한](./극한.md) / [미분](./미분.md)

## 학습 목표
- $\lim_{x\to a}f(x)$의 의미를 이해한다
- 극한의 사칙연산을 활용한다
- 함수의 연속성을 정의에 따라 판별한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 극한 $\lim_{x\to a}f(x)=L$
- 연속함수

**정리(theorem)**
- 극한의 사칙연산
- $\frac{0}{0}, \frac{\infty}{\infty}$ 부정형 처리
- 연속의 정의: $\lim_{x\to a}f(x)=f(a)$

**예제(example)**
- 인수분해·유리화로 부정형 해소
- 극한값 계산
- 연속 여부 판별
