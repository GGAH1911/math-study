# 함수방정식

## 요약
함수방정식이란 미지 함수 $f(x)$를 구하기 위해 함수에 대한 방정식 형태를 갖는 식을 의미합니다.

## 본문
함수방정식은 변수 $x$뿐만 아니라 함수 $f$ 자체를 미지수로 포함하는 방정식이다. 일반적인 방정식이 특정 수치를 찾는 과정이라면, 함수방정식은 주어진 조건을 만족하는 함수의 규칙이나 형태를 찾아내는 것이 목적이다. 따라서 해가 단 하나로 결정될 수도 있고, 특정 조건을 만족하는 함수들의 집합으로 나타날 수도 있다. 함수방정식을 해결하기 위해서는 대입법, 치환법, 대칭성 이용, 미분법 활용 등 다양한 전략이 필요하다.

### 직관과 기하적 의미
함수방정식은 함수가 그래프상에서 어떤 대칭성을 갖는지, 혹은 특정 점에 대해 어떤 성질을 갖는지를 설명하는 도구로 쓰인다. 예를 들어 $f(x) = f(-x)$라는 식은 함수가 $y$축에 대해 대칭인 우함수임을 나타내며, $f(x) = f(a-x)$는 $x = a/2$라는 직선에 대해 대칭임을 의미한다. 즉, 방정식의 형태는 함수의 기하학적 구조를 결정짓는 제약 조건으로 작용한다.

### 기본 성질
함수방정식의 해를 구할 때는 대입을 통해 특수한 값에서의 함수값을 먼저 찾아내는 것이 일반적이다. 또한, $f(x+y) = f(x) + f(y)$와 같은 코시 함수방정식은 함수의 선형성을 나타내는 대표적인 형태이다. 만약 함수가 연속이라는 조건이 추가된다면, 위 식의 해는 $f(x) = cx$ 형태의 일차함수로 유일하게 결정된다.

## 학습 체크
- 주어진 식에 $x=0$ 또는 $x=1$과 같은 특정한 값을 대입했을 때 얻을 수 있는 정보는 무엇인가?
- 함수가 연속함수라는 조건이 주어졌을 때, 해의 형태가 어떻게 제한되는가?
- 방정식의 좌변과 우변의 변수 구조를 비교하여 대칭성이나 주기성을 찾아낼 수 있는가?

## 관련 개념
- **여러가지 적분법**: 함수방정식의 해로 구한 함수를 적분하여 넓이나 부피를 구할 때 사용된다.
