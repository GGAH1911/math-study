# 역함수 구하기

> **예제** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
$y$를 $x$로 푼 뒤 변수 교환

## 본문 (학습 시 채워짐)

### 문제

$f(x) = 2x + 1$의 역함수를 구하시오.

### 단계별 풀이

**1단계: 함수를 $y = f(x)$ 형태로 나타내기**  
주어진 함수를 $y = 2x + 1$로 쓴다. 이렇게 하면 입력 $x$와 출력 $y$의 관계가 명확해진다.

**2단계: $x$를 $y$로 나타내기**  
역함수에서는 입력과 출력이 바뀌므로, 원래 식에서 $x$를 $y$의 식으로 표현한다.
$$y = 2x + 1$$
$$y - 1 = 2x$$
$$x = \frac{y - 1}{2}$$

**3단계: 변수 교환하기**  
역함수도 함수이므로 $x$를 입력, $y$를 출력으로 표기해야 한다. 위 식에서 $x$와 $y$의 역할을 바꾼다.
$$y = \frac{x - 1}{2}$$

### 답

$$f^{-1}(x) = \frac{x - 1}{2}$$

**검증**: $f(f^{-1}(x)) = 2 \cdot \frac{x-1}{2} + 1 = x$ ✓  
(sympy: `solve(y - (2*x + 1), x)` → $\frac{y-1}{2}$)

### 변형·주의

**정의역과 치역 확인**: 원래 함수의 정의역이 제한되면 역함수의 정의역도 바뀐다. 예를 들어 $f: [0, \infty) \to [1, \infty)$일 때, 역함수의 정의역은 $[1, \infty)$이다.

**일대일 대응 필수**: 역함수가 존재하려면 원래 함수가 일대일 함수여야 한다. 일차함수는 항상 일대일이지만, 이차함수나 상수함수는 정의역을 적절히 제한해야 역함수가 존재한다.

**그래프의 대칭성**: $f(x)$의 그래프와 $f^{-1}(x)$의 그래프는 직선 $y = x$에 대해 대칭이다.
