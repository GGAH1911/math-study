# 수열의합

## 요약
수열의 각 항을 순서대로 더하여 얻은 값을 의미하며, 합의 기호 $\sum$을 사용하여 간결하게 나타냅니다.

## 본문
수열 $\{a_n\}$의 첫째항부터 제$n$항까지의 합을 $S_n$이라고 하며, 이는 $S_n = a_1 + a_2 + \dots + a_n$으로 정의됩니다. 수열의 합을 다룰 때는 항의 개수와 각 항의 규칙성을 파악하는 것이 가장 중요합니다. 특히 합의 기호 $\sum_{k=1}^{n} a_k$를 사용하면 복잡한 합의 형태를 수학적으로 간결하게 표현할 수 있습니다.

### 직관과 기하적 의미
수열의 합은 이산적인 값들의 누적된 총합을 의미합니다. 만약 수열의 항이 함수의 함숫값과 같다면, 수열의 합은 정해진 구간에서 함수 그래프 아래의 면적을 계단 모양으로 근사하는 과정과 유사한 의미를 갖습니다. 즉, 연속적인 적분의 개념을 이산적인 영역으로 확장한 형태라고 이해할 수 있습니다.

### 기본 성질
합의 기호 $\sum$은 선형성을 가지므로, 각 항에 상수가 곱해져 있다면 상수를 합 기호 밖으로 뺄 수 있고, 두 수열의 합은 각각의 합을 더한 것과 같습니다. 또한, 합의 범위가 $k=1$부터 시작하지 않는 경우, 전체 합에서 앞부분의 합을 빼는 방식으로 계산할 수 있습니다.

## 학습 체크
- 합의 기호 $\sum$을 사용하여 주어진 수열의 합을 간결한 식으로 나타낼 수 있는가?
- 수열의 합 $S_n$이 주어졌을 때, 일반항 $a_n$을 $S_n - S_{n-1}$을 이용하여 구할 수 있는가?

## 관련 개념
- **수열**: 수열의 각 항을 차례대로 더한 결과물이 바로 수열의 합이므로, 수열의 규칙성을 이해하는 것이 선행되어야 합니다.
- **등차수열의 합**: 등차수열의 항들은 일정한 차이를 가지므로, 첫째항과 마지막 항의 평균을 이용한 공식으로 합을 구할 수 있습니다.
- **등비수열의 합**: 등비수열의 항들은 일정한 비율로 증가하거나 감소하므로, 공비를 이용한 특수한 합의 공식을 적용합니다.
