### 정확한 진술

평면에서 두 벡터 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$가 주어질 때, 이 두 벡터가 만드는 **평행사변형의 넓이**는 다음의 절댓값으로 정의합니다:

$$\text{넓이} = |a_1 b_2 - a_2 b_1|$$

이 값을 외적(cross product)이나 외부곱(outer product)의 크기라 부르며, 부호를 포함한 값 $a_1 b_2 - a_2 b_1$을 **부호있는 넓이(signed area)**라고 합니다.

### 직관과 기하적 의미

두 벡터 $\vec{a}$, $\vec{b}$를 같은 시작점에서 그리면 평행사변형을 이룹니다. 이 평행사변형의 밑변이 $\vec{a}$이고 높이가 $\vec{b}$의 수직 성분이므로, 넓이는 밑변 × 높이로 계산됩니다.

부호있는 넓이는 두 벡터의 상대적 방향을 기록합니다. $\vec{a}$에서 $\vec{b}$로 회전하는 각도가 **반시계방향**이면 양수, **시계방향**이면 음수입니다. 이는 3차원에서 벡터의 외적이 수직인 축 방향을 결정하는 것과 같은 원리입니다.

### 한 줄 예

$\vec{a} = (2, 0)$, $\vec{b} = (0, 3)$이면 부호있는 넓이는 $2 \times 3 - 0 \times 0 = 6$이고, 절댓값 넓이는 $|6| = 6$입니다.

### 계산 검산
```python
# sympy.Matrix로 검증
from sympy import Matrix
a, b = Matrix([2, 0]), Matrix([0, 3])
signed_area = a[0]*b[1] - a[1]*b[0]  # 6
abs_area = abs(signed_area)  # 6
```
