# 모평균과 모분산

## 요약
모평균과 모분산은 모집단 전체를 대상으로 확률변수가 가지는 기댓값과 데이터의 흩어짐 정도를 나타내는 지표이다.

## 본문
확률변수 $X$가 취할 수 있는 값 전체의 집합인 모집단 전체를 대상으로 구한 평균을 모평균 $\mu$, 분산을 모분산 $\sigma^2$이라 한다. 이산확률변수 $X$가 값 $x_1, x_2, \ldots, x_n$을 각각 확률 $p_1, p_2, \ldots, p_n$으로 가질 때, 모평균 $\mu$는 다음과 같이 정의한다.
$$\mu = E(X) = \sum_{i=1}^{n} x_i p_i$$
모평균은 확률변수가 장기적으로 어떤 값에 집중하는지를 나타내는 기댓값의 의미를 갖는다. 모분산 $\sigma^2$은 각 값이 모평균으로부터 얼마나 떨어져 있는지를 확률로 가중평균한 값으로, 다음과 같이 정의한다.
$$\sigma^2 = V(X) = E\bigl((X - \mu)^2\bigr) = \sum_{i=1}^{n} (x_i - \mu)^2 p_i$$
또한 계산의 편의를 위해 분산은 제곱의 평균에서 평균의 제곱을 뺀 값으로도 구할 수 있다.
$$\sigma^2 = E(X^2) - \mu^2$$
모분산의 양의 제곱근인 $\sigma = \sqrt{\sigma^2}$은 모표준편차라고 하며, 분산과 동일한 단위를 사용하여 데이터의 산포도를 직관적으로 파악할 수 있게 한다.

### 직관과 기하적 의미
모평균은 데이터의 무게중심 역할을 하며, 확률변수가 나타낼 것으로 기대되는 중심적인 위치를 의미한다. 모분산은 데이터가 이 중심으로부터 얼마나 넓게 퍼져 있는지를 나타내는 척도이다. 분산 값이 클수록 데이터는 평균에서 멀리 떨어져 넓게 분포하며, 분산 값이 작을수록 데이터는 평균 근처에 밀집되어 있음을 의미한다.

### 기본 성질
모분산은 편차의 제곱에 확률을 곱하여 구하므로 항상 $0$보다 크거나 같다. 또한 모표준편차는 분산에 루트를 씌운 값으로, 분산과 동일한 물리적 단위를 공유하여 데이터의 변동성을 해석하기에 용이하다.

## 학습 체크

- 모분산을 계산할 때 '제곱의 평균'에서 '평균의 제곱'을 빼는 공식을 활용하여 계산 실수를 줄일 수 있는가?
- 모표준편차가 모분산과 비교하여 데이터의 단위(unit) 측면에서 어떤 이점을 갖는지 이해하고 있는가?

## 관련 개념

**확률(선수):** 모평균·모분산의 정의 자체가 각 값에 확률을 가중치로 곱하는 구조다. 확률의 기본 성질 $\sum p_i = 1$이 성립해야 $E(X)$가 비로소 의미 있는 평균이 된다.

**통계(선수):** 모집단 전체를 알 수 없을 때 표본을 뽑아 **표본평균** $\bar{X}$와 **표본분산** $S^2$으로 모수를 추정한다. 모평균과 모분산은 그 추정의 목표값, 즉 참값에 해당한다.

**기댓값:** 모평균은 기댓값 $E(X)$와 같은 개념이다. 기댓값의 선형성 $E(aX + b) = aE(X) + b$, 그리고 분산의 변환 공식 $V(aX + b) = a^2 V(X)$는 모평균·모분산을 다룰 때 핵심적으로 활용된다.

**이항분포·정규분포:** 이항분포 $B(n, p)$를 따르는 확률변수는 모평균 $\mu = np$, 모분산 $\sigma^2 = np(1-p)$임이 알려져 있다. 정규분포 $N(\mu, \sigma^2)$에서 $\mu$와 $\sigma^2$는 그 이름 그대로 모평균과 모분산이며, 분포의 중심과 퍼짐을 결정한다.
