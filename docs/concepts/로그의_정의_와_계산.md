# 로그의 정의 와 계산

## 요약
지수를 구하는 과정을 역으로 나타낸 것이 로그이며, 로그의 성질을 이용해 복잡한 계산을 단순화할 수 있습니다.

## 본문
지수 $a^x = N$에서 지수 $x$를 구하는 것을 로그의 관점에서 표현하면 $x = \log_a N$이 됩니다. 이때 밑 $a$는 $a > 0$이고 $a \neq 1$이어야 하며, 진수 $N$은 $N > 0$이어야 한다는 조건이 반드시 필요합니다. 로그는 큰 수의 곱셈을 덧셈으로, 나눗셈을 뺄셈으로 변환하여 계산을 용이하게 만드는 도구로 활용됩니다.

### 직관과 기하적 의미
로그는 '밑을 몇 번 곱해야 원하는 수가 되는가?'라는 질문에 대한 답입니다. 예를 들어 $\log_2 8 = 3$이라는 것은 2를 3번 곱하면 8이 된다는 의미입니다. 기하학적으로 로그 함수 $y = \log_a x$는 지수 함수 $y = a^x$의 역함수이며, 그래프 상에서 직선 $y = x$에 대하여 대칭인 형태를 가집니다.

### 기본 성질
로그의 계산을 위한 핵심 성질은 다음과 같습니다. 첫째, 로그의 합은 진수의 곱과 같고($\log_a M + \log_a N = \log_a MN$), 로그의 차는 진수의 몫과 같습니다($\log_a M - \log_a N = \log_a \tfrac{M}{N}$). 둘째, 로그의 지수는 앞으로 내려올 수 있습니다($\log_a M^k = k \log_a M$). 셋째, 밑의 변환 공식($\log_a b = \tfrac{\log_c b}{\log_c a}$)을 통해 어떤 밑으로든 로그를 표현할 수 있습니다.

## 학습 체크
- 로그의 정의를 사용할 때 밑과 진수의 조건($a>0, a \neq 1, N>0$)을 항상 확인하고 있는가?
- 로그의 성질을 이용하여 복잡한 수의 곱셈과 나눗셈을 덧셈과 뺄셈으로 변환할 수 있는가?
- 로그의 밑 변환 공식을 사용하여 서로 다른 밑을 가진 로그들을 통일할 수 있는가?

## 관련 개념
- **지수와 로그**: 지수가 거듭제곱의 결과값을 찾는 과정이라면, 로그는 그 결과값으로부터 지수를 찾아내는 역연산 관계입니다.
