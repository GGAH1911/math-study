# 부호가 바뀌는 함수의 적분

## 요약
적분 구간 내에서 함수의 부호가 변하는 경우, 정적분 값은 함수가 $x$축 위쪽에 위치한 넓이와 아래쪽에 위치한 넓이의 차이로 계산됩니다.

## 본문
함수 $f(x)$의 정적분 $\int_{a}^{b} f(x) \, dx$를 계산할 때, 구간 $[a, b]$ 내에서 $f(x)$의 부호가 바뀌는 지점이 존재한다면 단순히 넓이를 구하는 것과는 다른 결과가 나타납니다. 정적분은 함수 그래프와 $x$축 사이의 '대수적인 넓이'를 의미하므로, $f(x) \ge 0$인 구간에서의 넓이는 양수로, $f(x) < 0$인 구간에서의 넓이는 음수로 계산되어 합산됩니다. 따라서 곡선과 $x$축으로 둘러싸인 실제 넓이를 구하고자 할 때는 함수가 $x$축과 만나는 점을 기준으로 구간을 나누어, 각 구간의 정적분 값에 절댓값을 씌운 뒤 모두 더해야 합니다.

### 직관과 기하적 의미
정적분은 함수 그래프 아래의 면적을 계산하는 과정에서 $x$축보다 아래에 있는 부분의 면적을 음수로 취급합니다. 예를 들어, 어떤 구간에서 함수가 $x$축 위쪽 면적을 $5$만큼, 아래쪽 면적을 $3$만큼 가지고 있다면, 이 구간의 정적분 값은 $5 - 3 = 2$가 됩니다. 반면, 실제 기하학적 넓이는 두 면적의 합인 $5 + 3 = 8$이 됩니다. 즉, 정적분은 '부호가 포함된 넓이의 합'이며, 실제 넓이는 '부호가 제거된 넓이의 합'이라는 차이가 있습니다.

### 기본 성질
구간 $[a, b]$에서 함수 $f(x)$가 $x=c$를 기준으로 부호가 바뀐다고 가정할 때, 곡선과 $x$축 사이의 넓이 $S$는 다음과 같이 계산됩니다.
$$S = \int_{a}^{c} |f(x)| \, dx = \int_{a}^{c} f(x) \, dx + \int_{c}^{b} -f(x) \, dx \quad (\text{단, } a < c < b \text{ 이고 } f(x) \ge 0 \text{ on } [a, c])$$

## 학습 체크
- 함수 $f(x)$가 $x$축과 만나는 지점(실근)을 정확히 찾아 구간을 나누었는가?
- 각 구간에서 함수가 $x$축보다 위(양수)에 있는지 아래(음수)에 있는지 확인하였는가?
- 정적분 값을 구한 후, 넓이를 구할 때 절댓값을 적용하여 음수 값을 양수로 변환하였는가?

## 관련 개념
- **정적분의 활용**: 정적분을 이용하여 곡선과 $x$축 사이의 넓이를 구하는 구체적인 방법론으로, 부호가 바뀌는 구간을 분할하여 계산하는 원리가 적용됩니다.
