# 조건부확률 계산

> **예제** · 확률과통계 · 단원: [확률](/concepts/확률)

## 요약
주머니에서 뽑기

## 본문 (학습 시 채워짐)

### 문제

주머니에 흰 공 4개, 검은 공 3개가 들어있다. 공을 하나씩 꺼내어(뽑은 공은 다시 넣지 않음) 두 번 뽑는다. 첫 번째에 흰 공을 뽑았다는 조건 아래, 두 번째에 검은 공을 뽑을 확률을 구하시오.

### 단계별 풀이

**1단계: 상황 정리**

처음 상황은 흰 공 4개, 검은 공 3개로 총 7개다. 첫 번째에 흰 공을 뽑았다는 조건이 주어졌으므로, 이를 확정된 사실로 받아들인다.

**2단계: 조건 이후의 상황 파악**

첫 번째에 흰 공을 뽑은 후 주머니에 남은 공은:
- 흰 공: $4 - 1 = 3$개
- 검은 공: 3개 (변하지 않음)
- 남은 총 공의 개수: $3 + 3 = 6$개

**3단계: 조건부확률 계산**

"첫 번째에 흰 공을 뽑은 상황"이라는 조건이 이미 일어났으므로, 우리가 구하는 것은 이 상황에서의 상대확률이다. 두 번째 뽑기는 남은 6개 공 중에서 일어난다.

$$P(\text{두 번째 검은 공} \mid \text{첫 번째 흰 공}) = \frac{\text{검은 공 개수}}{\text{남은 공 총 개수}} = \frac{3}{6} = \frac{1}{2}$$

### 답

$$\boxed{\frac{1}{2}}$$

### 변형/주의

**변형 1**: 첫 번째에 검은 공을 뽑았다면?
- 남은 공: 흰 공 4개, 검은 공 2개 (총 6개)
- 두 번째 검은 공의 조건부확률: $\frac{2}{6} = \frac{1}{3}$

**핵심 구분**: **비복원추출**(뽑은 것을 넣지 않음)에서 조건부확률이 나타난다. 만약 **복원추출**(뽑은 것을 다시 넣음)이라면, 두 번째 확률은 조건과 무관하게 항상 $\frac{3}{7}$로 일정해진다. 비복원은 확률이 변하고, 복원은 확률이 독립이다.

**검산** (sympy: `from fractions import Fraction; Fraction(3, 6)` → 1/2)
