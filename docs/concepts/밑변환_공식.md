# 밑변환 공식

> **정리** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\log_a b=\log_c b / \log_c a$

## 본문 (학습 시 채워짐)

### 정리의 진술

임의의 양수 $a, b, c$ (단, $a \neq 1, c \neq 1$)에 대해 다음이 성립한다:

$$\log_a b = \frac{\log_c b}{\log_c a}$$

이를 **밑변환 공식**이라 한다. 좌변은 밑이 $a$인 로그이고, 우변은 밑이 $c$인 로그의 비로 나타내어진다. 특히 $c = 10$ (상용로그)이나 $c = e$ (자연로그)를 선택하면 계산기나 로그표로 구할 수 있는 값으로 변환하게 된다.

### 유도 및 증명 스케치

$\log_a b = x$라 하면, 로그의 정의에 의해 $a^x = b$이다. 양변에 밑 $c$인 로그를 취하면:

$$\log_c(a^x) = \log_c b$$

로그의 성질 $\log_c(a^x) = x \log_c a$를 적용하면:

$$x \log_c a = \log_c b$$

따라서 $x = \dfrac{\log_c b}{\log_c a}$ (단, $\log_c a \neq 0$, 즉 $a \neq 1$)이고, $x = \log_a b$이므로 공식이 증명된다.

### 의의 및 활용

계산기나 교과서에는 보통 밑 10(상용로그)이나 밑 $e$(자연로그)의 로그만 제시되어 있다. 임의의 밑을 가진 로그를 구해야 할 때, 밑변환 공식을 이용하면 이들 표준 로그로 변환할 수 있다. 예를 들어, $\log_2 8 = \frac{\log_{10} 8}{\log_{10} 2}$로 계산할 수 있다. 실제로는 $\log_2 8 = 3$이므로 (∵ $2^3 = 8$), 이는 검증 수단이 된다. 또한 로그 방정식과 부등식을 풀 때, 서로 다른 밑의 로그를 통일해야 할 필요가 있을 때 필수적인 도구이다.
