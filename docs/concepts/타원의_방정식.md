### 정확한 진술

평면 위의 두 점 $F_1$, $F_2$(초점이라 함)으로부터의 거리의 합이 일정한 점들의 자취를 **타원**이라고 합니다. 즉, 두 초점을 $F_1(-c, 0)$, $F_2(c, 0)$이라 하고 거리의 합을 $2a$ ($a > c > 0$)라 하면, 타원 위의 모든 점 $P(x, y)$는 다음을 만족합니다.

$$|PF_1| + |PF_2| = 2a$$

이를 정리하면 타원의 표준방정식을 얻습니다. $b^2 = a^2 - c^2$으로 정의할 때:

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)$$

### 직관과 기하적 의미

타원을 손가락 두 개를 초점으로 하는 실로 묶인 자의 궤적으로 상상할 수 있습니다. 실의 총 길이가 $2a$로 고정되어 있으므로, 펜 끝이 그리는 곡선이 타원입니다.

**주요 요소:**
- **장축**: $x$축 위의 긴 지름, 길이 $2a$
- **단축**: $y$축 위의 짧은 지름, 길이 $2b$
- **중심**: 원점 $(0, 0)$
- **이심률**: $e = \frac{c}{a}$ ($0 < e < 1$) — 타원이 얼마나 찌그러졌는지 나타냄

$e$가 0에 가까울수록 원에 가까우며, 1에 가까울수록 길쭉합니다.

### 한 줄 예

$\frac{x^2}{25} + \frac{y^2}{9} = 1$은 장축의 길이가 10, 단축의 길이가 6인 타원입니다. (`sympy.solve((x**2/25 + y**2/9 - 1).subs(y, 0), x)` → $x = ±5$)
