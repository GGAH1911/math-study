# 이등변삼각형

> **정의** · 중2 · 단원: [도형의 성질](/concepts/도형의_성질)

## 요약
두 변의 길이가 같음

## 본문 (학습 시 채워짐)

### 정의

이등변삼각형은 **두 변의 길이가 같은 삼각형**입니다. 

삼각형 $ABC$에서 $AB = AC$일 때, 이를 이등변삼각형이라 하고, 길이가 같은 두 변 $AB$, $AC$를 **다리(leg)**라 부르며, 나머지 변 $BC$를 **밑변(base)**이라 합니다. 점 $A$는 두 다리가 만나는 **꼭짓점(apex)**입니다.

### 기하적 의미

이등변삼각형의 핵심은 **좌우 대칭**입니다. 꼭짓점에서 밑변에 내린 수선은 밑변을 정확히 이등분하며, 이 직선이 대칭축이 됩니다.

가장 중요한 성질은 **"다리가 같으면 밑각이 같다"**는 것입니다. 즉, $AB = AC$이면 $\angle ABC = \angle ACB$입니다. 반대로 두 각이 같은 삼각형은 반드시 이등변삼각형이므로, 이 성질은 양방향으로 성립합니다.

또한 꼭짓점에서의 각의 이등분선은 밑변에 수직이며 밑변의 중점을 지나갑니다.

### 예

세 변의 길이가 5, 5, 7인 삼각형은 이등변삼각형입니다. 여기서 길이 5인 다리가 만나는 꼭짓점의 각을 $\angle A$라 하면, 밑변의 양쪽 끝 각 $\angle B = \angle C$가 성립합니다.

**특수한 경우**: 정삼각형(모든 변의 길이가 같음)은 이등변삼각형의 특수한 경우이며, 세 각이 모두 $60°$로 같습니다.
