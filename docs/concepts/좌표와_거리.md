# 좌표와 거리

## 요약
수직선과 평면 위에서 점의 위치를 나타내는 좌표를 이해하고, 두 점 사이의 거리를 구하는 원리를 학습합니다.

## 본문
수직선 위에서 원점으로부터 오른쪽 방향을 양의 방향으로 하여 어떤 점 $P$까지의 거리를 $x$라고 할 때, 점 $P$의 좌표를 $x$라고 정의합니다. 평면에서는 두 개의 수직선(축)을 사용하여 점의 위치를 나타내며, 이를 좌표라 합니다. 두 점 사이의 거리는 두 점 사이의 최단 길이를 의미하며, 수직선에서는 두 좌표의 차의 절댓값으로 나타내고 평면에서는 피타고라스 정리를 이용하여 계산합니다.

### 직관과 기하적 의미
좌표는 무한한 공간 속에서 특정 위치를 숫자로 고정하는 약속입니다. 수직선에서의 거리는 한 점이 다른 점으로부터 얼마나 떨어져 있는지를 나타내는 크기이며, 평면에서의 거리는 두 점을 잇는 선분의 길이를 의미합니다. 이는 공간의 크기를 측정 가능한 수치로 변환하는 기초가 됩니다.

### 기본 성질
수직선 위의 두 점 $A(a)$, $B(b)$ 사이의 거리는 $|a-b|$로 계산됩니다. 평면 위의 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$ 사이의 거리는 $\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$로 나타냅니다. 이때 거리는 항상 $0$보다 크거나 같으며, 두 점이 일치할 때만 $0$이 됩니다.

## 학습 체크
- 수직선 위에서 음수의 좌표를 가진 두 점 사이의 거리를 구할 때 절댓값을 사용하는 이유는 무엇인가?
- 평면 좌표에서 두 점 사이의 거리 공식이 피타고라스 정리와 어떤 연관이 있는지 설명할 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 좌표평면 위에서 함수의 그래프를 그릴 때, $x$축과 $y$축의 좌표 개념이 필수적으로 사용됩니다.
