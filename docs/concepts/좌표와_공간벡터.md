### 정확한 진술

3차원 공간에서 한 점 $P$의 위치를 나타내기 위해 원점 $O$를 기준으로 $x$축, $y$축, $z$축의 세 개의 수직인 축을 설정합니다. 이를 **직교좌표계**라 하고, 점 $P$를 세 개의 실수 $(x, y, z)$로 나타내며 이를 $P$의 **좌표**라 합니다.

**공간벡터**는 3차원 공간에서 크기와 방향을 가진 양입니다. 한 점 $A$에서 점 $B$로의 공간벡터는 $\overrightarrow{AB}$로 표기하고, 좌표로는 $\overrightarrow{AB} = (x_B - x_A, y_B - y_A, z_B - z_A)$로 나타냅니다. 특히 원점 $O$에서 점 $P(x, y, z)$로의 벡터 $\overrightarrow{OP}$를 **위치벡터**라 하며, 이는 단순히 $(x, y, z)$로 표현됩니다.

### 직관/기하적 의미

평면도형에서 2차원 좌표계를 사용했듯이, 3차원 공간의 도형을 다루기 위해서는 3차원 좌표가 필수입니다. 공간벡터는 화살표처럼 방향과 거리를 동시에 나타내므로, 평면벡터보다 더 풍부한 기하학적 관계(예: 두 직선의 위치 관계, 점에서 평면까지의 거리)를 식으로 계산할 수 있게 해줍니다. 좌표와 벡터가 결합되면, 공간의 어떤 도형이든 방정식으로 표현할 수 있습니다.

### 한 줄 예

점 $A(1, 2, 3)$과 점 $B(4, 5, 6)$이 있을 때, 공간벡터 $\overrightarrow{AB} = (3, 3, 3)$이고, 이 벡터의 크기는 $|\overrightarrow{AB}| = \sqrt{3^2 + 3^2 + 3^2} = 3\sqrt{3}$입니다.

```python
from sympy import sqrt, simplify
simplify(sqrt((4-1)**2 + (5-2)**2 + (6-3)**2))
```
