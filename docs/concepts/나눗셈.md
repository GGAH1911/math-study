# 나눗셈

### 정의

두 다항식 $f(x)$와 $g(x)$ ($g(x) \neq 0$, $\deg g \leq \deg f$)에 대해, 다음을 만족하는 다항식 $q(x)$ (몫)와 $r(x)$ (나머지)가 유일하게 존재합니다:
$$f(x) = g(x) \cdot q(x) + r(x)$$
여기서 나머지는 $\deg r < \deg g$ 또는 $r(x) = 0$을 만족합니다. 이를 **다항식의 나눗셈**이라 합니다.

### 직관과 의미

정수 나눗셈($12 = 5 \times 2 + 2$)처럼, 다항식도 나누어떨어지는 개념이 있습니다. $f(x)$를 $g(x)$로 나누면 몫 $q(x)$와 나머지 $r(x)$를 얻으며, 나머지의 차수는 항상 제수의 차수보다 작아야 합니다(더 이상 나눌 수 없다는 뜻). 특히 나머지가 0이면 $f(x)$가 $g(x)$로 **나누어떨어진다**고 하며, 이는 인수분해와 밀접한 관계가 있습니다. 조립제법 같은 계산 방법도 이 원리에 기반합니다.

### 예: 간단한 경우

$f(x) = x^3 + 2x^2 - 5x + 3$을 $g(x) = x - 1$로 나누면:
$$x^3 + 2x^2 - 5x + 3 = (x - 1)(x^2 + 3x - 2) + 1$$

몫은 $q(x) = x^2 + 3x - 2$, 나머지는 $r(x) = 1$입니다. 나머지의 차수가 1 < 2이므로 조건을 만족합니다.

`sympy.div(x**3 + 2*x**2 - 5*x + 3, x - 1)`
