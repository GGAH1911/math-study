### 정확한 진술

두 다항식을 더하거나 뺄 때는 **같은 차수의 항들끼리만** 계수를 더하거나 뺍니다. 

예를 들어, $P(x) = a_nx^n + \cdots + a_1x + a_0$과 $Q(x) = b_nx^n + \cdots + b_1x + b_0$이 주어질 때,
$$P(x) + Q(x) = (a_n+b_n)x^n + \cdots + (a_1+b_1)x + (a_0+b_0)$$
$$P(x) - Q(x) = (a_n-b_n)x^n + \cdots + (a_1-b_1)x + (a_0-b_0)$$

이 규칙이 항등식이 되어야 하므로, 차수가 없거나 계수가 0인 항은 생략합니다.

### 직관 및 의미

다항식을 더하고 빼는 이유는 **같은 차수 항의 역할이 다르기 때문**입니다. $x^2$ 항은 $x$ 항과 성질이 완전히 다르므로, 서로 섞을 수 없습니다. 예를 들어 "사과 3개 + 귤 2개"를 "과일 5개"라고 쓸 수 없듯이, $3x^2 + 2x$를 $5x^2$ 또는 $5x$로 합칠 수 없습니다.

실생활로는 서로 다른 단위의 량을 모을 때와 같습니다. 덧셈은 분배법칙을 이용해 괄호를 풀고 정리하는 방식이고, 뺄셈은 빼는 다항식의 모든 항의 부호를 바꾼 후 덧셈으로 계산해도 됩니다.

### 예제

$(2x^2 + 3x - 1) + (x^2 - 2x + 5)$를 계산하면:
$$x^2 \text{ 항: } 2x^2 + x^2 = 3x^2$$
$$x \text{ 항: } 3x + (-2x) = x$$
$$\text{상수항: } (-1) + 5 = 4$$
$$\therefore (2x^2 + 3x - 1) + (x^2 - 2x + 5) = 3x^2 + x + 4$$

뺄셈 $(3x^2 - 2x + 4) - (x^2 + x - 2)$는 다음과 같이:
$$(3x^2 - 2x + 4) + (-(x^2 + x - 2)) = (3x^2 - 2x + 4) + (-x^2 - x + 2) = 2x^2 - 3x + 6$$
