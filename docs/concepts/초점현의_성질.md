### 정확한 진술

초점현(焦點弦)은 이차곡선의 초점을 지나는 현입니다. 타원 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (단, $a > b > 0$)에서 초점 $F(c, 0)$ (단, $c = \sqrt{a^2 - b^2}$)을 지나는 현의 양 끝점을 $P$, $Q$라 하면, 다음 **조화평균 성질**이 성립합니다.

$$\frac{1}{|FP|} + \frac{1}{|FQ|} = \frac{2a}{b^2}$$

### 직관 및 기하적 의미

초점은 타원의 정의(두 초점으로부터의 거리 합이 $2a$)를 만족하는 특수한 점입니다. 초점을 지나는 현은 이 특별한 위치로 인해 길이 관계가 단순한 합이 아닌 **역수의 합**으로 표현됩니다. 

이는 초점에 가까워질수록 현의 한쪽은 짧아지고 다른 쪽은 길어지는 균형을 수식화한 것입니다. 조화평균 공식은 초점 주변의 기하학적 "밀도"를 반영하며, 타원의 곡률 변화와도 연결됩니다.

### 예제

타원 $\frac{x^2}{25} + \frac{y^2}{9} = 1$에서 초점 $F(4, 0)$ ($c = \sqrt{25-9} = 4$)을 지나는 현 $PQ$를 생각합니다. $|FP| = 5$일 때, 조화평균 성질을 적용하면:

$$\frac{1}{5} + \frac{1}{|FQ|} = \frac{2 \cdot 5}{9} = \frac{10}{9}$$

$$\frac{1}{|FQ|} = \frac{10}{9} - \frac{1}{5} = \frac{50 - 9}{45} = \frac{41}{45}$$

$$|FQ| = \frac{45}{41}$$

따라서 $|PQ| = 5 + \frac{45}{41} = \frac{245}{41}$ 입니다.

(**검증**: `from fractions import Fraction; 1/Fraction(5,1) + 1/Fraction(45,41) == Fraction(10,9)`)
