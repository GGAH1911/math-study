### 정확한 진술

함수 $f(x)$의 정의역이 폐구간 $[a, b]$로 제한되어 있을 때, **극값(극대값 또는 극소값)은 다음 후보 중에서만 나타난다:**

1. 정의역 내부 $(a, b)$에서 $f'(x) = 0$인 점(임계점)
2. 정의역의 끝점 $x = a, x = b$

극댓값은 이들 후보 중 함수값이 가장 큰 점에서 나타나고, 극솟값은 함수값이 가장 작은 점에서 나타난다.

### 직관 및 기하적 의미

정의역이 제한되지 않았다면, 극값은 도함수가 0이 되는 점에서만 찾으면 된다. 하지만 폐구간으로 제한되면 상황이 달라진다. 끝점 $x = a$나 $x = b$에서 함수가 급격히 올라가거나 내려갈 수 있기 때문에, 끝점의 함수값도 비교 대상에 포함해야 한다.

예를 들어 $f(x) = x$는 도함수가 항상 1이어서 임계점이 없지만, 구간 $[1, 3]$에서는 끝점 $x = 3$에서 극댓값 3을, 끝점 $x = 1$에서 극솟값 1을 가진다. **끝점도 극값 후보가 되는 이유는 정의역 경계에서 함수가 '지역적 최대·최소'를 이룰 수 있기 때문이다.**

### 한 줄 예

$f(x) = -x^2 + 4x$ (단, $1 \le x \le 3$): $f'(x) = -2x + 4 = 0$에서 $x = 2$ (임계점), 끝점 $f(1) = 3, f(2) = 4, f(3) = 3$을 비교하면 극댓값은 $f(2) = 4$, 극솟값은 $f(1) = f(3) = 3$이다.

```python
# sympy.solve(-2*x + 4, x) → [2]
# f(1)=3, f(2)=4, f(3)=3 확인
```
