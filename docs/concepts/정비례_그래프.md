# 정비례 그래프

> **정리** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
원점을 지나는 직선

## 본문 (학습 시 채워짐)

### 진술 (정비례 관계식과 그래프)

$y = ax$ (단, $a \neq 0$)로 나타나는 정비례 관계식의 그래프는 **원점을 지나는 직선**입니다. 여기서 $a$를 **정비례상수**라고 하며, 이 직선의 기울기(가파른 정도)를 결정합니다.

**가정:** 좌표평면에서 $x$와 $y$가 정비례 관계 $y = ax$를 만족합니다.

### 유도와 증명 스케프

관계식 $y = ax$에 $x = 0$을 대입하면 $y = a \cdot 0 = 0$이므로, 점 $(0, 0)$(원점)은 항상 그래프 위에 있습니다.

또한 임의의 $x$ 값에 대해 정확히 하나의 $y$ 값이 결정되므로, 그래프는 **직선 모양**이 됩니다. 예를 들어 $y = 2x$인 경우, 점 $(1, 2)$, $(2, 4)$, $(-1, -2)$ 등이 모두 한 직선 위에 놓입니다.

기울기 $a$의 의미: $x$가 1만큼 증가할 때 $y$는 $a$만큼 증가합니다. 따라서 $a > 0$이면 직선이 오른쪽 위로 향하고, $a < 0$이면 오른쪽 아래로 향합니다.

$$y = 2x \text{의 그래프: } (0, 0), (1, 2), (2, 4) \text{ 등을 지나는 직선}$$
$$y = -\frac{1}{2}x \text{의 그래프: } (0, 0), (2, -1), (4, -2) \text{ 등을 지나는 직선}$$

### 의의와 응용

정비례 그래프는 **속력×시간 = 거리**, **단가×수량 = 가격** 같은 실생활 상황을 모델링합니다. 기울기를 보면 정비례상수의 크기와 부호를 한눈에 파악할 수 있어, 두 정비례 관계를 비교할 때 유용합니다. 또한 중2에서 배우는 일차함수 $y = ax + b$의 기초가 되므로 중요합니다.
