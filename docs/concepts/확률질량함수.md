# 확률질량함수

> **정의** · 확률과통계

## 요약
이산확률변수가 취할 수 있는 각 값에 대응하는 확률을 나타내는 함수입니다.

## 본문
이산확률변수 $X$가 취할 수 있는 값이 $x_1, x_2, x_3, \ldots$처럼 셀 수 있을 때, 각 값에 확률을 대응시키는 함수를 **확률질량함수**라 한다. $X$가 특정 값 $x_i$를 가질 확률을 $P(X = x_i) = p_i$로 나타낼 때, 확률질량함수 $f(x)$는 다음과 같이 정의된다.
$$f(x_i) = P(X = x_i) = p_i$$
이 함수는 주사위를 던질 때처럼 결과가 딱딱 정해진 경우에 각 결과가 나올 가능성을 수학적으로 표현한 것입니다.

### 직관과 기하적 의미
확률질량함수는 확률변수가 가질 수 있는 값들에 대해 '얼마나 큰 확률을 가지고 있는가'를 보여주는 지도와 같습니다. 예를 들어 동전을 두 번 던질 때 앞면이 나오는 횟수 $X$의 경우, $X$는 $0, 1, 2$ 중 하나의 값을 가지며 각 확률은 $P(X=0) = \frac{1}{4}$, $P(X=1) = \frac{1}{2}$, $P(X=2) = \frac{1}{4}$가 됩니다. 이처럼 각 값에 할당된 확률을 통해 전체적인 확률 분포의 형태를 파악할 수 있습니다.

### 기본 성질
함수 $f(x)$가 적법한 확률질량함수이기 위해서는 다음 두 가지 조건을 반드시 만족해야 합니다.
1. 모든 $i$에 대하여 $p_i \geq 0$이다. (각 확률은 음수가 될 수 없다.)
2. $\sum_{i} p_i = 1$이다. (모든 경우의 확률을 더하면 반드시 1이 된다.)

예를 들어 확률질량함수가 $f(x) = \dfrac{x}{k}$ $(x = 1, 2, 3, 4)$로 주어졌다면, 모든 확률의 합이 1이어야 하므로 $\frac{1}{k} + \frac{2}{k} + \frac{3}{k} + \frac{4}{k} = 1$을 만족하는 $k=10$을 구할 수 있습니다.

## 학습 체크
- 확률질량함수의 모든 확률값의 합이 1이 되는지 확인하였는가?
- 확률변수가 가질 수 있는 모든 값에 대해 확률이 0 이상으로 정의되었는가?
- 주어진 함수식에서 미지수가 포함된 경우, 확률의 총합 조건을 이용하여 미지수를 구할 수 있는가?

## 관련 개념

**이산확률변수**는 확률질량함수가 정의되는 대상이다. 확률변수가 이산적인지 연속적인지에 따라 확률을 기술하는 도구가 달라지므로, 이산확률변수의 뜻을 먼저 이해하는 것이 핵심 선수지식이다.

**확률분포**는 확률질량함수를 표나 그래프로 나타낸 것 전체를 가리킨다. 확률질량함수가 각 값에서의 "높이"를 알려준다면, 확률분포는 그 전체 모양을 한눈에 보여 준다.

**기댓값(평균)** $E(X) = \sum x_i \cdot p_i$는 확률질량함수의 값 $p_i$를 가중치로 삼아 계산한다. 확률질량함수를 모르면 기댓값도 구할 수 없다.

**이항분포** $B(n, p)$는 확률질량함수가 $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$로 주어지는 대표적인 이산확률분포로, 확률질량함수의 구체적인 적용 사례이다.

**연속확률변수의 확률밀도함수**는 확률질량함수의 연속 버전에 해당한다. 이산의 경우 $\sum p_i = 1$이라면, 연속의 경우 $\int f(x)\,dx = 1$이 대응 조건이 된다.
