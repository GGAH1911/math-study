### 정확한 진술

수열 $\{a_n\}$의 **부분합** $S_n$은 처음 $n$개 항의 합입니다.
$$S_n = a_1 + a_2 + a_3 + \cdots + a_n = \sum_{k=1}^{n} a_k$$

부분합은 수열의 각 항을 누적해서 더한 값으로, 수열의 처음부터 $n$번째까지의 누적 합을 나타냅니다.

### 직관과 의미

부분합은 **누적의 개념**입니다. 예를 들어 매달 저축하는 금액이 수열 $\{a_n\}$이라면, 부분합 $S_n$은 $n$개월까지 모은 총액입니다. 

$$S_1 = a_1, \quad S_2 = a_1 + a_2, \quad S_3 = a_1 + a_2 + a_3, \ldots$$

중요한 성질은 일반항을 부분합으로부터 구할 수 있다는 점입니다:
- $n = 1$일 때: $a_1 = S_1$
- $n \geq 2$일 때: $a_n = S_n - S_{n-1}$

이는 **$n$번째 항이 $n-1$개월까지의 누적합과 $n$개월까지의 누적합의 차이**라는 의미입니다.

### 예제

수열 $a_n = 2n$의 부분합 $S_n$을 구하면:

$$S_n = 2 \cdot 1 + 2 \cdot 2 + 2 \cdot 3 + \cdots + 2 \cdot n = 2(1 + 2 + \cdots + n) = 2 \cdot \frac{n(n+1)}{2} = n(n+1)$$

예를 들어 $S_3 = 2 + 4 + 6 = 12 = 3 \times 4$ ✓

**검증 코드**: `sum([2*n for n in range(1, 4)])  # 12`
