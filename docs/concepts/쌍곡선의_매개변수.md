# 쌍곡선의 매개변수

## 요약
쌍곡선 위의 점의 좌표를 하나의 변수 $\theta$를 이용하여 나타내는 것을 매개변수 표현이라 한다.

## 본문
쌍곡선 $\tfrac{x^2}{a^2} - \tfrac{y^2}{b^2} = 1$ 위의 점 $(x, y)$를 하나의 변수 $\theta$만으로 동시에 나타낼 수 있다. 이를 **매개변수 표현**이라 하고, $\theta$를 매개변수라 부른다. 쌍곡선의 매개변수 표현식은 다음과 같다.
$$x = \frac{a}{\cos\theta}, \quad y = b\tan\theta$$
이 식에 대입하여 삼각 항등식 $\sec^2\theta - \tan^2\theta = 1$이 성립함을 확인하면, 모든 $\theta$ 값에 대하여 해당 점이 쌍곡선 방정식 위를 만족함을 알 수 있다. 매개변수 표현의 핵심은 점의 위치를 $x$와 $y$ 두 좌표 대신 하나의 변수로 깔끔하게 포착한다는 데 있다.

### 직관과 기하적 의미
매개변수 $\theta$의 변화에 따라 점 $(x, y)$가 쌍곡선 위를 움직이게 된다. 예를 들어 $\theta = 0$일 때 $x = a, y = 0$이 되어 쌍곡선의 꼭짓점 위치를 나타낸다. 즉, 복잡한 좌표 관계를 하나의 변수의 움직임으로 단순화하여 곡선 위의 점의 궤적을 직관적으로 파악할 수 있게 해준다.

### 기본 성질
쌍곡선의 방정식 형태에 따라 매개변수 식의 계수가 결정된다.
- **예 1.** 쌍곡선 $\tfrac{x^2}{4} - \tfrac{y^2}{9} = 1$은 $a = 2, b = 3$이므로 매개변수 표현은 $x = \tfrac{2}{\cos\theta}, y = 3\tan\theta$이다.
- **예 2.** 쌍곡선 $x^2 - \tfrac{y^2}{4} = 1$은 $a = 1, b = 2$이므로 매개변수 표현은 $x = \tfrac{1}{\cos\theta}, y = 2\tan\theta$이다. $\theta = \tfrac{\pi}{4}$를 대입하면 $x = \sqrt{2}, y = 2$가 되며, 이는 실제 쌍곡선 방정식 $2 - 1 = 1$을 만족한다.

## 학습 체크
- 쌍곡선의 방정식에서 $a$와 $b$의 값을 확인하여 매개변수 식을 정확히 유도할 수 있는가?
- 삼각 항등식을 이용하여 매개변수로 표현된 점이 실제 쌍곡선 방정식의 해가 됨을 증명할 수 있는가?

## 관련 개념

**이차곡선** — 포물선·타원·쌍곡선 모두 이차곡선의 일종이다. 쌍곡선의 매개변수 표현은 이차곡선 전반을 하나의 틀 안에서 이해하는 데 도움이 된다.

**타원의 매개변수 표현** — 타원 $\tfrac{x^2}{a^2} + \tfrac{y^2}{b^2} = 1$은 $x = a\cos\theta$, $y = b\sin\theta$로 나타낸다. 쌍곡선의 표현과 부호 하나만 다르며, 배경에 깔린 항등식도 $\sin^2\theta + \cos^2\theta = 1$ 대 $\sec^2\theta - \tan^2\theta = 1$로 대응된다.

**삼각함수 항등식** — $\sec^2\theta - \tan^2\theta = 1$이 매개변수 표현 전체를 성립시키는 열쇠다. 이 항등식이 없으면 쌍곡선의 매개변수 표현은 정당화되지 않는다.

**쌍곡선의 점근선** — 매개변수 $\theta$가 $\tfrac{\pi}{2}$에 가까워질수록 $x, y$가 함께 커지면서 점근선 $y = \pm\tfrac{b}{a}x$ 방향으로 뻗어 나가는 거동을 매개변수를 통해 직관적으로 관찰할 수 있다.
