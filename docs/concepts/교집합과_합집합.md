# 교집합과 합집합

## 요약
두 사건이 동시에 일어나는 경우를 교집합, 적어도 하나가 일어나는 경우를 합집합이라 하며, 합집합의 확률은 각 사건의 확률의 합에서 교집합의 확률을 뺀 값으로 구한다.

## 본문
표본공간 $S$ 위에서 두 사건 $A$, $B$가 주어졌을 때, 두 사건이 동시에 일어나는 경우 전체를 교집합 $A \cap B$라 하고, 두 사건 중 적어도 하나가 일어나는 경우 전체를 합집합 $A \cup B$라 한다. 확률의 관점에서 합집합의 확률을 구하는 과정은 매우 중요한데, 이는 두 사건의 확률을 단순히 더할 경우 중복되는 부분을 고려해야 하기 때문이다.

### 직관과 기하적 의미
두 사건의 확률을 각각 $P(A)$와 $P(B)$라고 할 때, 이 둘을 단순히 더하면 두 사건이 동시에 일어나는 영역인 $P(A \cap B)$가 두 번 계산되는 결과가 나타난다. 따라서 정확한 합집합의 확률을 구하기 위해서는 중복된 부분만큼을 한 번 빼 주어야 한다. 이를 수식으로 나타낸 것이 확률의 덧셈정리인 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$이다.

### 기본 성질
만약 두 사건이 동시에 일어날 수 없는 관계라면, 즉 $A \cap B = \varnothing$인 경우를 배반사건이라고 한다. 배반사건일 때는 $P(A \cap B) = 0$이 되므로, 합집합의 확률은 단순히 각 사건의 확률을 더한 $P(A \cup B) = P(A) + P(B)$로 계산할 수 있다.

예를 들어, 주사위를 던질 때 짝수가 나오는 사건 $A=\{2, 4, 6\}$과 3의 배수가 나오는 사건 $B=\{3, 6\}$이 있다면, 두 사건의 교집합은 $\{6\}$이다. 이때 $P(A \cup B)$는 $P(A) + P(B) - P(A \cap B) = \frac{3}{6} + \frac{2}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$이 된다.

## 학습 체크
- 두 사건이 동시에 일어날 수 없는 '배반사건'일 때 합집합의 확률 공식은 어떻게 변하는가?
- 합집합의 확률을 구할 때 교집합의 확률을 빼 주는 이유는 무엇인가?
- 주어진 확률 값들을 이용해 두 사건이 동시에 일어날 확률을 역으로 구할 수 있는가?

## 관련 개념

**확률**은 이 절의 토대다. 교집합과 합집합은 사건(집합)의 언어로 쓰이지만, 그 값을 구하는 순간 확률의 덧셈정리로 넘어오기 때문에, 확률의 정의와 기본 성질을 먼저 익혀야 덧셈정리가 자연스럽게 받아들여진다.

**집합과 명제**는 $\cap$과 $\cup$ 기호 자체의 출발점이다. 집합에서 배운 벤 다이어그램·여집합·부분집합 개념이 확률 공간에서도 그대로 작동하므로, 그림을 그려 가며 사건의 포함 관계를 확인하는 습관이 덧셈정리 실수를 크게 줄여 준다.

인접 개념으로는 **여사건의 확률** $P(A^c) = 1 - P(A)$가 있다. "적어도 하나" 조건은 여사건("하나도 없다")으로 바꿔 계산하는 편이 훨씬 빠른 경우가 많으므로, 합집합과 여사건을 함께 다루는 연습이 중요하다. 나아가 **조건부 확률**과 **독립사건**을 배우면, $P(A \cap B)$를 $P(A)P(B \mid A)$나 $P(A)P(B)$로 바꿔 쓸 수 있게 되어 교집합 확률을 직접 세지 않고도 구하는 방법이 열린다.
