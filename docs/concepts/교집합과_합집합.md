# 교집합과 합집합

표본공간 $S$ 위에서 두 사건 $A$, $B$가 주어졌을 때, 두 사건이 **동시에** 일어나는 경우 전체를 **교집합** $A \cap B$라 하고, 두 사건 중 **적어도 하나**가 일어나는 경우 전체를 **합집합** $A \cup B$라 한다.

확률에서 이 두 집합 연산이 특히 중요한 이유는, 합집합의 확률을 구하는 덧셈정리 때문이다.

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$A$와 $B$를 단순히 더하면 $A \cap B$에 해당하는 부분이 두 번 계산되므로, 한 번 빼 주어야 정확한 값이 나온다. 두 사건이 동시에 일어날 수 없는 경우, 즉 $A \cap B = \varnothing$이면 $P(A \cap B) = 0$이므로 식은 $P(A \cup B) = P(A) + P(B)$로 단순해진다. 이를 **배반사건**의 덧셈이라 한다.

---

## 예시

**예시 1.** 주사위를 한 번 던질 때, 짝수가 나오는 사건을 $A = \{2, 4, 6\}$, 3의 배수가 나오는 사건을 $B = \{3, 6\}$이라 하자.

$$A \cap B = \{6\}, \quad A \cup B = \{2, 3, 4, 6\}$$

$$P(A) = \frac{3}{6}, \quad P(B) = \frac{2}{6}, \quad P(A \cap B) = \frac{1}{6}$$

덧셈정리를 적용하면

$$P(A \cup B) = \frac{3}{6} + \frac{2}{6} - \frac{1}{6} = \frac{4}{6} = \frac{2}{3}$$

직접 세어 보면 $A \cup B$의 원소가 4개이므로 $\dfrac{4}{6} = \dfrac{2}{3}$으로 일치한다.

**예시 2.** 어느 반 학생 중 수학을 좋아하는 학생의 비율이 $\dfrac{2}{5}$, 영어를 좋아하는 학생의 비율이 $\dfrac{1}{3}$, 둘 다 좋아하는 학생의 비율이 $\dfrac{1}{10}$일 때, 적어도 하나를 좋아하는 학생의 비율은

$$\frac{2}{5} + \frac{1}{3} - \frac{1}{10} = \frac{12}{30} + \frac{10}{30} - \frac{3}{30} = \frac{19}{30}$$

## 관련 개념

**확률**은 이 절의 토대다. 교집합과 합집합은 사건(집합)의 언어로 쓰이지만, 그 값을 구하는 순간 확률의 덧셈정리로 넘어오기 때문에, 확률의 정의와 기본 성질을 먼저 익혀야 덧셈정리가 자연스럽게 받아들여진다.

**집합과 명제**는 $\cap$과 $\cup$ 기호 자체의 출발점이다. 집합에서 배운 벤 다이어그램·여집합·부분집합 개념이 확률 공간에서도 그대로 작동하므로, 그림을 그려 가며 사건의 포함 관계를 확인하는 습관이 덧셈정리 실수를 크게 줄여 준다.

인접 개념으로는 **여사건의 확률** $P(A^c) = 1 - P(A)$가 있다. "적어도 하나" 조건은 여사건("하나도 없다")으로 바꿔 계산하는 편이 훨씬 빠른 경우가 많으므로, 합집합과 여사건을 함께 다루는 연습이 중요하다. 나아가 **조건부 확률**과 **독립사건**을 배우면, $P(A \cap B)$를 $P(A)P(B \mid A)$나 $P(A)P(B)$로 바꿔 쓸 수 있게 되어 교집합 확률을 직접 세지 않고도 구하는 방법이 열린다.
