# 절대값

## 요약
절대값은 수직선 위에서 원점으로부터 어떤 수까지의 거리를 의미하며, 항상 0 이상의 값을 갖는 수입니다.

## 본문
실수 $x$의 절대값 $|x|$는 수직선 위에서 원점까지의 거리를 나타내며, 다음과 같이 정의한다.
$$|x| = \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}$$

### 직관과 기하적 의미
절대값은 수의 크기만을 나타내며, 방향성을 배제한 '거리'의 개념이다. 수직선 위에서 어떤 점이 원점으로부터 얼마나 떨어져 있는지를 나타내므로, 음수라 할지라도 거리를 나타낼 때는 부호를 떼어낸 양수 값으로 표현한다. 예를 들어 $-3$의 절대값은 원점으로부터 $3$만큼 떨어져 있으므로 $3$이 된다.

### 기본 성질
절대값은 다음과 같은 주요 성질을 가진다.
1. $|x| \geq 0$ (절대값은 항상 0보다 크거나 같다.)
2. $|xy| = |x||y|$ (두 수의 곱의 절대값은 각 절대값의 곱과 같다.)
3. $|x+y| \leq |x|+|y|$ (삼각부등식: 두 수의 합의 절대값은 각 절대값의 합보다 작거나 같다.)

또한 부등식의 해를 구할 때, $|x| < a$ ($a>0$)이면 $-a < x < a$이고, $|x| > a$이면 $x < -a$ 또는 $x > a$이다.

예를 들어 $|2x-3| \leq 5$를 풀면 다음과 같다.
$$-5 \leq 2x-3 \leq 5$$
$$-2 \leq 2x \leq 8$$
$$-1 \leq x \leq 4$$

## 학습 체크
- $x$가 음수일 때 $|x| = -x$로 정의되는 이유는 무엇인가?
- $|x+y| \leq |x|+|y|$에서 등호가 성립하는 조건은 무엇인가?
- $|x| < a$와 $|x| > a$의 해가 각각 다른 형태를 갖는 이유를 기하학적으로 설명할 수 있는가?
