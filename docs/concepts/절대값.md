# 절대값

## 정의

실수 $x$의 **절대값** $|x|$는 수직선 위에서 원점까지의 거리를 나타내며 다음과 같이 정의한다.

$$|x| = \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}$$

절대값의 주요 성질: $|x| \geq 0$, $|xy| = |x||y|$, $|x+y| \leq |x|+|y|$ (삼각부등식). 부등식 $|x| < a$ ($a>0$)의 해는 $-a < x < a$이고, $|x| > a$의 해는 $x < -a$ 또는 $x > a$이다.

## 예시

$|2x-3| \leq 5$ 풀기.

$$-5 \leq 2x-3 \leq 5$$
$$-2 \leq 2x \leq 8$$
$$-1 \leq x \leq 4$$

## 관련 개념

- 절대값 함수 ($y=|f(x)|$의 그래프)
- 이차부등식
- 실수의 대소 관계
- 부등식의 풀이
