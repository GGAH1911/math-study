# 합성함수의 미분 (연쇄법칙)

> **단원** · 미적분 · 선수: [여러가지함수의 미분](/concepts/여러가지함수의_미분)

## 학습 목표
- 연쇄법칙으로 합성함수를 미분한다
- 매개변수·역함수·음함수 미분을 다룬다

## 다룰 정의 / 정리 / 예제 (Phase 2 spoke로 분해됨)

**정의(definition)**
- 합성함수, 연쇄법칙
- 매개변수 함수
- 역함수 미분
- [음함수 미분](/concepts/음함수_미분)

**정리(theorem)**
- 연쇄법칙 $\{f(g(x))\}'=f'(g(x))\cdot g'(x)$
- 매개변수 미분 $dy/dx = (dy/dt)/(dx/dt)$

**예제(example)**
- $\sin(2x)$, $e^{x^2}$ 같은 합성함수 미분
- 매개변수 함수 접선
- 음함수 $x^2+y^2=1$ 미분
