### 정의: 함수값의 비교

정의역에 속하는 서로 다른 두 원소 $a, b$에 대하여, $f(a)$와 $f(b)$의 대소관계를 판정하는 것을 함수값의 비교라고 합니다. 특히 함수의 증감성(증가 또는 감소하는 성질)을 알고 있을 때, $a$와 $b$의 대소관계로부터 함수값의 대소관계를 체계적으로 구할 수 있습니다.

함수 $f$가 구간 $I$에서 증가함수이면, $a, b \in I$일 때 $a < b \Leftrightarrow f(a) < f(b)$입니다. 반대로 감소함수이면, $a < b \Leftrightarrow f(a) > f(b)$입니다.

### 직관적 의미: 그래프로 읽기

함수 $f(a)$는 점 $(a, f(a))$의 $y$-좌표, 즉 그래프 위의 높이입니다. 따라서 두 함수값의 비교는 그래프 위의 두 점 중 어느 점이 더 높은지를 묻는 것과 같습니다.

- **증가함수 구간**: 그래프가 좌에서 우로 올라가므로, $x$-좌표가 크면 높이도 깁니다.
- **감소함수 구간**: 그래프가 좌에서 우로 내려가므로, $x$-좌표가 크면 높이는 작아집니다.
- **극값을 갖는 함수**: 극대점과 극소점 근처에서는 함수값의 대소가 복잡할 수 있으므로 주의해야 합니다.

### 실제 예

함수 $f(x) = x^2 - 2x$가 $[0, 3]$에서 정의되어 있습니다. 

먼저 도함수를 구하면 $f'(x) = 2x - 2$이므로, $f'(x) = 0$일 때 $x = 1$입니다. 
- $0 \leq x < 1$에서 $f'(x) < 0$ → 감소함수
- $1 < x \leq 3$에서 $f'(x) > 0$ → 증가함수

따라서 $f(0.5)$와 $f(2)$를 비교할 때: $0.5 < 1$이고 $2 > 1$이므로, 두 점 모두 극소점 $x=1$을 기준으로 반대편에 있습니다. 계산하면 $f(0.5) = -0.75$, $f(2) = 0$이므로 $f(0.5) < f(2)$입니다.

(검증: `from sympy import symbols, diff; x = symbols('x'); f = x**2 - 2*x; print(f.subs(x, 0.5), f.subs(x, 2))`)
