### 정확한 진술

방정식이나 부등식을 **만족하는 미지수의 값이 정수일 때**, 그 값을 **정수 해**(integer solution)라고 합니다. 

예를 들어 방정식 $x^2 - 5x + 6 = 0$의 해는 $x = 2, 3$인데, 둘 다 정수이므로 이 방정식은 "정수 해를 갖는다" 또는 "정수 해 $x = 2, 3$을 갖는다"고 표현합니다. 반대로 $x^2 - 2 = 0$의 해 $x = \pm\sqrt{2}$는 정수가 아니므로 정수 해가 존재하지 않습니다.

부등식도 마찬가지입니다. 부등식 $x^2 - 5x + 6 < 0$을 풀면 $2 < x < 3$인데, 이를 만족하는 정수 해는 **존재하지 않습니다** (개구간이므로 경계값 2, 3 포함 안 함). 하지만 $2 \le x \le 3$이면 정수 해는 $x = 2, 3$입니다.

### 직관/기하적 의미

실생활 문제에서 대부분의 답은 정수입니다. "학생 몇 명인가?", "상자 몇 개?" 같은 질문에 $3.7$명이나 $2.4$개라는 답은 의미가 없죠. 따라서 어떤 방정식을 풀었을 때 모든 해 중에서 **실제로 의미 있는 것은 정수 해뿐인 경우**가 많습니다.

또한 수능과 교육과정에서 "정수 해의 개수를 구하라"는 문제는 **정수만 세어야** 한다는 뜻입니다. 이는 부등식의 정수 해를 구하는 기초 능력으로 자주 출제됩니다.

### 한 줄 예

부등식 $x^2 - 4x + 3 \le 0$을 풀면 $(x-1)(x-3) \le 0$이므로 $1 \le x \le 3$인데, 이를 만족하는 정수 해는 **$x = 1, 2, 3$** (3개)입니다.
(`sympy.solve(x**2 - 4*x + 3 <= 0, x)` 또는 $1 \le 3$인 정수 확인으로 검증)
