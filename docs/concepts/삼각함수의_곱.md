### 정의

두 삼각함수의 곱을 삼각함수의 합 또는 차로 표현하는 공식을 **곱-합 공식**(product-to-sum formula)이라 합니다. 구체적으로는 다음 세 가지입니다.

$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

$$\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$$

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$

이 세 식은 모두 **곱 형태의 우변을 합/차 형태의 우변으로 바꾸는 항등식**입니다. 고등학교 교과서에서 합-차 공식의 역방향으로 유도되며, 삼각함수 적분이나 파동 현상을 다룰 때 필수적입니다.

### 직관 및 활용

삼각함수의 곱은 계산이 복잡하지만, 합/차로 바꾸면 덧셈 정리나 다른 공식과 결합하기 쉬워집니다. 특히 **정적분**을 계산할 때, 예를 들어 $\int \sin(2x) \sin(3x) \, dx$ 같은 식이 주어지면, 곱-합 공식으로 먼저 변환한 후 각각 적분하면 훨씬 간단해집니다. 

물리학에서 **간섭 현상**(두 파동의 만남)을 분석할 때도 이 공식이 중요합니다. 두 진동파 $\sin(\omega_1 t) \sin(\omega_2 t)$의 곱은 서로 다른 주파수를 가진 성분으로 분해되는데, 곱-합 공식이 이를 명확히 보여줍니다.

### 예시

$$\sin 30° \cos 20° = \frac{1}{2}[\sin(30°+20°) + \sin(30°-20°)] = \frac{1}{2}[\sin 50° + \sin 10°]$$

검증: `from sympy import sin, cos, rad, simplify; simplify(sin(rad(30))*cos(rad(20)) - 0.5*(sin(rad(50)) + sin(rad(10))))`로 확인 가능합니다.
