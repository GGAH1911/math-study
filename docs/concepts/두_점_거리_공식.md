# 두 점 거리 공식

> **정리** · 고1 · 단원: [도형의 방정식](/concepts/도형의_방정식)

## 요약
$d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$

## 본문 (학습 시 채워짐)

### 진술

평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리를 $d$라 하면:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

### 증명 스케치

두 점을 지나 $x$축, $y$축에 평행한 직선들을 그으면 직각삼각형을 만든다. 이 직각삼각형의 두 다리 길이는 $|x_2 - x_1|$과 $|y_2 - y_1|$이고, 빗변이 선분 $AB$이다. 피타고라스 정리를 적용하면:

$$d^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$$

양변에 제곱근을 취하면 공식을 얻는다. 제곱 때문에 절댓값 기호는 불필요하다.

### 기하학적 의미와 활용

이 공식은 도형의 방정식 단원의 모든 기초이다. 예를 들어 중심이 $(a, b)$이고 반지름이 $r$인 원 위의 점 $(x, y)$는 중심과의 거리가 정확히 $r$이므로:

$$\sqrt{(x-a)^2 + (y-b)^2} = r$$

이것이 원의 방정식이다. 또한 두 점을 지나는 직선, 점과 직선 사이의 거리, 원과 직선의 위치 관계 판정, 대칭점 구하기 등 거의 모든 도형 문제에서 핵심적으로 사용된다.

### 계산 예

$P(1, 2)$와 $Q(4, 6)$ 사이의 거리를 구하면:

$$d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

(`sympy.sqrt((4-1)**2 + (6-2)**2)` → `5`)
