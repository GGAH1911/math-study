# 다항식의미분

## 요약
다항식의 각 항을 미분법 공식에 따라 개별적으로 미분하여 새로운 다항식을 얻는 과정입니다.

## 본문
다항식의 미분은 다항식을 구성하는 각 항에 대하여 미분법을 적용하는 것을 의미합니다. 임의의 다항식 $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$에 대하여, 각 항의 지수를 앞으로 내려 곱하고 지수에서 1을 뺀 값으로 차수를 낮추어 계산합니다. 즉, $f'(x) = n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + \dots + a_1$이 됩니다. 이때 상수항은 미분하면 0이 됩니다.

### 직관과 기하적 의미
다항식의 미분은 함수 그래프 위의 임의의 점에서의 접선의 기울기를 구하는 과정입니다. 다항식의 차수가 낮아질수록 그래프의 곡률이 변하며, 미분된 식을 통해 함수가 증가하는 구간과 감소하는 구간을 파악할 수 있습니다.

### 기본 성질
첫째, 다항식의 합과 차의 미분은 각 항을 각각 미분하여 더하거나 뺀 것과 같습니다. 둘째, 상수배가 되어 있는 항은 미분 시 상수와 함수를 분리하여 계산할 수 있습니다. 셋째, 상수항을 미분하면 항상 0이 됩니다.

## 학습 체크
- 다항식의 차수가 미분 후 어떻게 변화하는지 설명할 수 있는가?
- 상수항이 포함된 다항식을 미분할 때 결과값이 어떻게 변하는지 이해하고 있는가?
- 여러 개의 항으로 이루어진 다항식을 각 항별로 나누어 미분할 수 있는가?

## 관련 개념
- **미분**: 다항식의 미분은 미분의 정의를 다항식이라는 특수한 함수 형태에 적용하여 계산을 단순화한 것입니다.
