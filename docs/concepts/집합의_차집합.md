# 집합의 차집합

## 요약
두 집합의 원소 중 한쪽 집합에만 속하는 원소들로 이루어진 집합을 의미합니다.

## 본문
두 집합 $A$와 $B$가 있을 때, 집합 $A$의 원소 중에서 집합 $B$에 속하지 않는 원소들로만 이루어진 집합을 $A$와 $B$의 차집합이라고 하며, 기호로는 $A-B$ 또는 $A \setminus B$와 같이 나타냅니다. 즉, $A-B = \{x \mid x \in A \text{ 이고 } x \notin B\}$로 정의됩니다. 이는 집합 $A$에서 집합 $B$와 겹치는 부분인 교집합 $A \cap B$를 제외한 나머지 부분을 추출하는 과정과 같습니다.

### 직관과 기하적 의미
벤 다이어그램을 통해 시각화하면, 두 원이 겹쳐져 있는 그림에서 $A$라는 원의 영역 중 $B$와 겹치는 초승달 모양의 영역만을 남기는 것과 같습니다. 즉, $A$라는 전체 영역에서 $B$라는 영역을 도려낸다고 생각하면 직관적으로 이해하기 쉽습니다.

### 기본 성질
차집합은 교환법칙이 성립하지 않으므로 $A-B$와 $B-A$는 일반적으로 같지 않습니다. 또한, 차집합은 다음과 같은 집합 연산의 성질을 가집니다.
1. $A-B = A-(A \cap B)$
2. $A-B = A \cup B - (A \cap B)$ (대칭차집합의 일부)
3. $A-B = (A-B) \cap B^c$ (여집합과의 관계)

## 학습 체크
- $A-B$를 구할 때 $B$의 원소가 $A$에 포함되지 않는 경우를 어떻게 처리해야 하는가?
- $A-B$와 $B-A$가 같아지기 위한 조건은 무엇인가?

## 관련 개념
- **집합과 명제**: 집합의 연산인 차집합은 조건제시법과 같은 명제의 논리 구조를 바탕으로 정의되며, 집합의 포함 관계를 판별하는 기초가 됩니다.
