### 정확한 진술

함수 $f(x)$가 구간 $(a, b)$에서 미분가능할 때, 도함수 $f'(x)$의 부호로 함수의 증감을 다음과 같이 판정합니다.

- **$f'(x) > 0$이면 $f(x)$는 $(a, b)$에서 증가함수**
- **$f'(x) < 0$이면 $f(x)$는 $(a, b)$에서 감소함수**
- **$f'(x) = 0$인 점은 함수의 극값 후보점(임계점)**

도함수의 부호가 바뀌는 점에서 극값이 발생합니다. 예를 들어 $f'(x)$가 양에서 음으로 바뀌면 극대, 음에서 양으로 바뀌면 극소입니다.

### 직관과 기하적 의미

도함수 $f'(x)$는 각 점에서의 **순간 기울기**를 나타냅니다. 기울기가 양수이면 그래프가 오른쪽으로 올라가고, 음수이면 내려갑니다. 이것이 증감의 본질입니다.

기하적으로, 곡선 $y = f(x)$를 왼쪽에서 오른쪽으로 따라가며 도함수의 부호를 확인하면:
- 도함수가 양수인 구간에서는 곡선이 **상승**
- 도함수가 음수인 구간에서는 곡선이 **하강**
- $f'(x) = 0$인 점을 지나며 부호가 바뀌는 곳이 **봉우리** 또는 **계곡**

### 한 줄 예와 검증

$f(x) = x^3 - 3x^2$일 때, $f'(x) = 3x^2 - 6x = 3x(x-2)$입니다.

$f'(x) > 0 \Leftrightarrow x < 0$ 또는 $x > 2$ (증가)
$f'(x) < 0 \Leftrightarrow 0 < x < 2$ (감소)

따라서 $x=0$에서 극대, $x=2$에서 극소입니다. `sympy.solve(3*x**2 - 6*x, x)` → $[0, 2]$
