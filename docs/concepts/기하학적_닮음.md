# 기하학적 닮음

## 정의

두 도형이 닮음(相似)이면, 대응하는 변의 길이의 비(닮음비)가 일정하고 대응하는 각의 크기가 같다. 삼각형의 닮음 조건은 SSS(세 변의 비가 같음), SAS(두 변의 비와 끼인각이 같음), AA(두 각이 같음) 세 가지이다. 닮음비가 $m : n$이면 넓이의 비는 $m^2 : n^2$이고, 부피의 비는 $m^3 : n^3$이다. 수능에서는 두 삼각형이 닮음임을 보이고 변의 길이나 넓이를 구하는 문제에 자주 활용된다.

## 예시

삼각형 $ABC$와 삼각형 $DEF$에서 $\angle A = \angle D = 60°$, $\angle B = \angle E = 45°$이면, AA 닮음에 의해 $\triangle ABC \sim \triangle DEF$이다.

$\overline{AB} = 4$, $\overline{DE} = 6$이면 닮음비는 $4:6 = 2:3$이므로,

$\overline{BC} : \overline{EF} = 2:3$이고, 넓이의 비는 $4:9$이다.
