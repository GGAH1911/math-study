### 정확한 진술

연립일차방정식의 **해**는 주어진 모든 방정식을 동시에 만족하는 미지수의 값(들)입니다. 예를 들어 두 개의 방정식으로 이루어진 연립일차방정식이 있을 때, 해는 첫 번째 방정식도 참으로 만들고 동시에 두 번째 방정식도 참으로 만드는 미지수 조합입니다. 

미지수가 $x, y, \ldots$일 때, 해는 순서쌍 (또는 순서조) 형태로 나타냅니다. 예컨대 $x + y = 5$와 $2x - y = 1$을 동시에 만족하는 해는 $(x, y) = (2, 3)$입니다.

### 직관과 기하적 의미

방정식 하나는 좌표평면에서 직선을 나타냅니다. 두 방정식을 함께 보면, 그 해는 두 직선의 **교점의 좌표**에 해당합니다. 마찬가지로 세 개 이상의 방정식이 있으면, 해는 여러 직선(또는 더 높은 차원에서는 초평면)이 모두 만나는 지점입니다.

이 기하학적 관점은 해의 개수를 직관적으로 이해하는 데 도움이 됩니다:
- 두 직선이 한 점에서 만나면 → **유일한 해**가 존재
- 두 직선이 평행하면 → **해가 없음** (모순)
- 두 직선이 일치하면 → **무수히 많은 해** (부정)

### 한 줄 예

$x + y = 3$과 $x - y = 1$의 연립일차방정식에서 해는 $(x, y) = (2, 1)$입니다. 검증: $2 + 1 = 3$ ✓, $2 - 1 = 1$ ✓

```python
# sympy로 검증
from sympy import symbols, solve, Eq
x, y = symbols('x y')
sol = solve([Eq(x + y, 3), Eq(x - y, 1)], [x, y])
# sol = {x: 2, y: 1}
```
