### 정확한 진술

두 함수 $u(x)$, $v(x)$가 미분가능하고 $v(x) \neq 0$일 때, 몫 $\frac{u(x)}{v(x)}$의 도함수는 다음과 같습니다.

$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$

이를 **몫의 미분법(quotient rule)**이라고 부릅니다. 곱의 미분법과 달리 순서가 중요하므로 분자에서 먼저 곱해지는 항($u'v$)과 나중에 곱해지는 항($uv'$)의 위치를 정확히 구분해야 합니다.

### 직관과 기하적 의미

몫의 미분법은 곱의 미분법에서 유도됩니다. $y = \frac{u}{v}$이면 $yv = u$이므로, 양변을 $x$에 대해 미분하면:

$$y'v + yv' = u'$$

따라서 $y' = \frac{u' - yv'}{v} = \frac{u'v - uv'}{v^2}$

기하학적으로, 두 함수의 비율이 변할 때의 순간변화율을 구하는 것입니다. 분자 $u$가 증가하면 비율이 증가하지만, 분모 $v$가 증가하면 비율이 감소합니다. 분모의 제곱 $v^2$이 나타나는 이유는 비율의 크기 변화를 정확히 반영하기 위함입니다.

### 한 줄 예

$f(x) = \frac{x^2}{x+1}$에서 $u = x^2$, $v = x+1$이므로 $u' = 2x$, $v' = 1$입니다. 따라서:

$$f'(x) = \frac{2x(x+1) - x^2 \cdot 1}{(x+1)^2} = \frac{2x^2 + 2x - x^2}{(x+1)^2} = \frac{x^2 + 2x}{(x+1)^2}$$

`sympy.diff(x**2 / (x + 1), x)` 검산: $\frac{x^2 + 2x}{(x+1)^2}$ ✓
