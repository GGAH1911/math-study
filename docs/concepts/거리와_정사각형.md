# 거리와 정사각형

## 정의

좌표평면 위의 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$ 사이의 거리는 $\overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$이다. 이 거리 공식을 이용하면, 네 꼭짓점의 좌표가 주어진 사각형이 정사각형인지 판별할 수 있다. 정사각형은 네 변의 길이가 모두 같고, 두 대각선의 길이도 서로 같으므로, 이 두 조건을 좌표로 확인한다. 즉, 인접한 두 변의 길이가 같고 두 대각선의 길이가 같으면 정사각형이다.

## 예시

네 점 $A(0,0)$, $B(2,0)$, $C(2,2)$, $D(0,2)$가 정사각형인지 확인한다.

변의 길이: $\overline{AB} = \overline{BC} = \overline{CD} = \overline{DA} = 2$

대각선의 길이: $\overline{AC} = \overline{BD} = \sqrt{4+4} = 2\sqrt{2}$

네 변이 같고 두 대각선이 같으므로 정사각형이다.
