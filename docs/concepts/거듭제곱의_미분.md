# 거듭제곱의 미분

## 정의

자연수 $n$에 대해 $x^n$을 $x$에 관해 미분하면 다음이 성립한다:

$$\frac{d}{dx} x^n = n x^{n-1}$$

이를 **거듭제곱 법칙(Power Rule)**이라 한다. 이 공식은 정수·유리수·실수 지수로도 확장된다. 수능 수학(미적분)에서 다항함수·유리함수·무리함수의 미분에 가장 빈번하게 사용된다.

## 예시

$f(x) = x^5$을 미분하시오.

$$f'(x) = 5x^{5-1} = 5x^4$$

또한 $g(x) = 3x^3 - 2x + 1$이면

$$g'(x) = 9x^2 - 2$$

## 관련 개념

- 미분의 정의(극한)
- 다항함수의 미분
- 합·차의 미분법
- 곱의 미분법
