# 거듭제곱의 미분

## 요약
자연수 지수를 가진 항을 미분할 때 지수를 앞으로 내리고 지수에서 1을 뺀 값으로 바꾸는 규칙을 의미한다.

## 본문
자연수 $n$에 대하여 $x^n$을 $x$에 관해 미분하면 지수 $n$이 계수로 내려오고 지수는 $n-1$이 되는 $\frac{d}{dx} x^n = n x^{n-1}$이 성립한다. 이를 거듭제곱 법칙이라 하며, 이 원리는 정수, 유리수, 실수의 지수로도 확장되어 적용될 수 있다. 이 법칙은 다항함수뿐만 아니라 유리함수와 무리함수의 미분을 계산할 때 가장 기본이 되는 핵심적인 도구이다.

예를 들어 $f(x) = x^5$을 미분하면 지수인 5가 앞으로 내려오고 지수는 4가 되어 $f'(x) = 5x^4$이 된다. 또한 여러 항이 더해진 식 $g(x) = 3x^3 - 2x + 1$의 경우, 각 항을 개별적으로 미분하여 $g'(x) = 9x^2 - 2$라는 결과를 얻을 수 있다.

### 직관과 기하적 의미
함수 $y=x^n$의 그래프 위의 한 점에서의 접선의 기울기를 구하는 과정이 바로 거듭제곱의 미분이다. 지수가 커질수록 그래프의 곡률이 급격히 변하며, 미분 계수는 그 변화율을 나타낸다.

### 기본 성질
- 지수가 1인 항 $x$를 미분하면 상수 1이 된다.
- 상수항을 미분하면 0이 된다.
- 계수가 있는 항은 미분 결과에 계수를 곱하여 계산한다.

## 학습 체크
- 지수가 유리수나 실수인 경우에도 거듭제곱 법칙을 동일하게 적용할 수 있는가?
- 다항식 형태의 함수를 미분할 때 각 항의 계수와 지수를 정확히 처리하였는가?
