### 정확한 진술

두 함수 $y = f(x)$와 $y = g(x)$의 교점은 방정식 $f(x) = g(x)$의 해에 대응됩니다. 특히 직선 $y = c$ (상수)와 곡선 $y = f(x)$의 교점 개수를 구하는 것을 **교점 개수 함수**라 하며, 이는 매개변수 $c$의 값에 따라 교점의 개수가 어떻게 변하는지를 나타내는 함수입니다. 즉, $N(c) = $ "$y = f(x)$와 $y = c$가 만나는 점의 개수"로 정의합니다.

### 직관과 기하적 의미

$y = f(x)$의 그래프를 수평선 $y = c$가 지나갈 때, 그래프와 직선이 만나는 횟수가 교점 개수입니다. $c$를 서서히 증가시키면, 특정 값에서 극값(극대·극소)을 만나거든 교점 개수가 급격히 변합니다. 예를 들어 극댓값이 $M$일 때, $c > M$이면 교점이 0개, $c = M$이면 1개(접함), $c < M$이면 2개가 될 수 있습니다. 이렇게 함수의 극값이 **교점 개수의 경계값**이 됩니다.

### 한 줄 예

$f(x) = x^3 - 3x$이고 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 극댓값은 $f(-1) = 2$, 극솟값은 $f(1) = -2$입니다. 따라서 $c > 2$ 또는 $c < -2$일 때 $N(c) = 1$, $-2 < c < 2$일 때 $N(c) = 3$, $c = \pm 2$일 때 $N(c) = 2$입니다.

(검증: `sympy.solveset(x**3 - 3*x - 0, x)` → 교점을 구체적으로 계산 가능)
