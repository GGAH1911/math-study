# 곱의 미분법

## 요약
두 함수의 곱으로 이루어진 함수를 미분할 때, 앞의 함수와 뒤의 함수의 미분값을 교차하여 곱한 뒤 각각의 함수를 미분한 값을 더하는 방식입니다.

## 본문
두 연속함수 $f(x)$와 $g(x)$에 대하여 함수 $h(x) = f(x)g(x)$의 미분계수는 $h'(x) = f'(x)g(x) + f(x)g'(x)$로 계산됩니다. 즉, 첫 번째 함수를 미분하고 두 번째 함수는 그대로 곱한 항과, 첫 번째 함수는 그대로 두고 두 번째 함수를 미분하여 곱한 항의 합으로 나타납니다.

### 직관과 기하적 의미
기하학적으로 두 함수의 곱은 직사각형의 넓이 변화로 해석할 수 있습니다. 가로의 길이가 $f(x)$이고 세로의 길이가 $g(x)$인 직사각형이 있을 때, $x$가 미세하게 변화함에 따라 넓이가 변하는 정도는 가로가 변하며 생기는 넓이 변화량($f'(x)g(x)$)과 세로가 변하며 생기는 넓이 변화량($f(x)g'(x)$)의 합과 같습니다.

### 기본 성질
곱의 미분법은 함수가 복잡한 다항식이나 삼각함수의 결합으로 이루어져 있을 때 이를 개별적인 성분으로 분리하여 미분할 수 있게 해줍니다. 특히 $f(x)=x$와 같이 단순한 함수가 포함된 경우 계산을 매우 효율적으로 만들어줍니다.

## 학습 체크
- 두 함수가 곱해진 형태를 보고 미분할 때, 두 함수를 각각 미분한 값의 곱($f'(x)g'(x)$)으로 실수하지 않았는가?
- 미분법을 적용하기 전, 함수가 미분 가능한 연속함수인지 확인하였는가?

## 관련 개념
- **여러가지함수의 미분**: 삼각함수나 지수함수, 로그함수 등이 포함된 복잡한 형태의 함수를 미분할 때 곱의 미분법을 필수적으로 결합하여 사용합니다.
