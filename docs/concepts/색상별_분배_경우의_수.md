# 색상별 분배 경우의 수

## 요약
서로 다른 색상을 가진 물건들을 특정 조건에 따라 나누어 배치할 때, 색상별로 구분되는 모든 가능한 조합의 수를 구하는 방법입니다.

## 본문
색상별 분배 경우의 수란 서로 다른 색상을 가진 물건들을 주어진 조건에 따라 여러 그룹으로 나누거나 배치할 때, 색상의 종류와 개수에 따라 나타날 수 있는 모든 가능한 경우를 계산하는 것을 의미합니다. 이 개념을 적용할 때는 먼저 분배할 대상이 서로 같은지 다른지를 구분해야 하며, 나누어지는 칸이나 그룹이 구별되는지 여부를 판단하는 것이 핵심입니다. 만약 색상이 서로 다르다면 각 색상이 차지하는 위치나 순서가 결과에 영향을 미치게 되며, 이때는 순열의 원리를 활용하여 계산합니다. 반면 색상이 같거나 구별되지 않는 조건이라면 조합의 원리를 사용하여 중복을 제외한 경우를 찾아내야 합니다.

### 직관과 기하적 의미
색상을 시각적인 구분자로 생각하면 이해가 쉽습니다. 예를 들어 빨간 공 3개와 파란 공 2개를 나열하는 상황은, 색상이라는 속성이 배열의 순서에 결정적인 역할을 하는 것과 같습니다. 이는 공간상에서 물체가 배치될 때 색상이라는 레이어가 겹쳐지며 나타나는 패턴의 가짓수를 찾는 과정과 유사합니다.

### 기본 성질
첫째, 분배할 대상의 총 개수와 색상별 개수의 합이 일치해야 합니다. 둘째, 색상 간의 구별 여부에 따라 계산 방식이 순열($P$) 또는 조합($C$)으로 결정됩니다. 셋째, 조건에 따라 특정 색상이 반드시 특정 위치에 있어야 한다는 제약 조건이 붙을 경우, 해당 조건을 먼저 고정시킨 후 나머지 경우를 계산하는 것이 효율적입니다.

## 학습 체크
- 분배되는 물건의 색상이 서로 다를 때와 같을 때의 계산 방식 차이를 설명할 수 있는가?
- 특정 색상의 물건이 반드시 포함되어야 한다는 조건이 있을 때, 전체 경우에서 제외해야 할 경우는 무엇인가?
- 나누어지는 칸이 구별되지 않는 경우, 중복되는 경우를 어떻게 처리해야 하는가?

## 관련 개념
- **경우의 수**: 색상별로 나누어지는 모든 가능한 상황을 빠짐없이, 중복 없이 세는 근본적인 원리입니다.
