# 외분점

## 요약
선분 $AB$를 $m:n$으로 외분하는 점은 선분 $AB$의 연장선 위에 있으며, 점 $A$로부터의 거리와 점 $B$로부터의 거리의 비가 $m:n$인 점을 의미합니다.

## 본문
수직선 위의 두 점 $A(x_1)$와 $B(x_2)$에 대하여 선분 $AB$를 $m:n$ ($m, n > 0$)으로 외분하는 점 $P(x)$는 선분 $AB$의 연장선 위에 존재하며, 점 $A$로부터의 거리와 점 $B$로부터의 거리가 $m:n$의 비율을 만족하는 점을 말한다. 이를 좌표로 나타내면 $x = \frac{mx_2 - nx_1}{m-n}$이다. 이때 $m=n$인 경우는 외분점이 존재하지 않으며, $m>n$이면 점 $P$는 점 $B$의 오른쪽에, $m<n$이면 점 $P$는 점 $A$의 왼쪽에 위치한다.

### 직관과 기하적 의미
외분점은 선분의 바깥쪽에서 두 점으로부터의 거리 비율을 결정하는 점이다. 내분점이 선분 내부에서 두 점 사이를 나누는 지점이라면, 외분점은 선분을 따라 길게 뻗어 나간 직선 위에서 특정 비율을 유지하며 위치한다. 예를 들어 $m>n$일 때 외분점은 $B$를 지나 $A$의 반대 방향이 아닌 $B$의 바깥쪽으로 나아간 곳에 위치하게 된다.

### 기본 성질
외분점의 좌표 공식은 내분점 공식에서 $n$의 부호를 $-n$으로 바꾸어 계산하는 것과 동일한 구조를 가진다. 또한, 외분점은 항상 두 점 $A, B$를 포함하는 직선 위에 존재하며, $m$과 $n$의 크기 차이에 따라 점의 위치가 결정된다.

## 학습 체크
- 외분점의 좌표를 구할 때 분모가 $0$이 되는 경우($m=n$)는 어떤 의미를 갖는가?
- $m < n$인 경우 외분점이 점 $A$의 왼쪽에 위치하는 이유를 좌표의 대소 관계로 설명할 수 있는가?

## 관련 개념
- **내분점**: 선분 내부에서 두 점을 $m:n$의 비율로 나누는 점으로, 외분점과 공식의 구조가 유사하다.
- **두 점 사이의 거리**: 외분점의 위치를 결정하기 위해 두 점 사이의 거리와 외분점까지의 거리 사이의 비를 계산할 때 사용된다.
