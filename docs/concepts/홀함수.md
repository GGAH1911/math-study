# 홀함수

## 요약
함수 $f(x)$가 모든 정의역의 $x$에 대하여 $f(-x) = -f(x)$를 만족할 때 이를 홀함수(기함수)라고 하며, 그래프는 원점에 대하여 대칭인 성질을 갖는다.

## 본문
함수 $f(x)$가 정의역의 모든 $x$에 대하여 $f(-x) = -f(x)$를 만족할 때, $f$를 홀함수(기함수)라 한다. 이는 함수에 음수를 대입했을 때 함숫값의 부호가 반대로 바뀌는 성질을 의미한다. 예를 들어 $f(x) = x^3 - 2x$와 같은 함수는 $f(-x) = (-x)^3 - 2(-x) = -x^3 + 2x = -(x^3 - 2x) = -f(x)$를 만족하므로 홀함수에 해당한다. 이러한 성질은 정적분 계산에서 매우 유용하게 활용되는데, 홀함수를 구간 $[-a, a]$에 대해 적분하면 그 결과는 항상 $0$이 된다. 즉, $\int_{-a}^{a} f(x)\,dx = 0$이다.

### 직관과 기하적 의미
홀함수의 그래프는 원점을 중심으로 $180^{\circ}$ 회전했을 때 원래의 그래프와 완전히 겹쳐지는 원점 대칭의 형태를 띤다. 따라서 그래프 상의 한 점 $(a, b)$가 그래프 위에 있다면, 반드시 그 점의 원점 대칭점인 $(-a, -b)$도 그래프 위에 존재해야 한다.

### 기본 성질
첫째, 함수 $f(x)$의 정의역이 $0$을 포함한다면, $f(0) = -f(0)$이 성립해야 하므로 반드시 $f(0) = 0$이어야 한다. 둘째, 정적분에서 홀함수의 대칭성을 이용하면 $\int_{-a}^{a} f(x)\,dx = 0$임을 이용하여 복잡한 계산을 단순화할 수 있다.

## 학습 체크

- 정적분 구간이 $[-a, a]$와 같이 대칭일 때, 함수가 홀함수라면 적분값이 $0$이 되는가?
