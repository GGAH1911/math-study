# 홀함수

## 정의

함수 $f(x)$가 정의역의 모든 $x$에 대해 $f(-x) = -f(x)$를 만족할 때, $f$를 **홀함수(기함수)**라 한다. 홀함수의 그래프는 원점에 대해 대칭이며, 항상 $f(0) = 0$이 성립한다(단, $0$이 정의역에 속할 때). 수능에서는 적분과 결합하여 $\int_{-a}^{a} f(x)\,dx = 0$ (홀함수)임을 활용하는 문제가 자주 출제된다.

## 예시

$f(x) = x^3 - 2x$로 놓으면 $f(-x) = (-x)^3 - 2(-x) = -x^3 + 2x = -(x^3 - 2x) = -f(x)$이므로 홀함수이다.

따라서 $\displaystyle\int_{-2}^{2}(x^3 - 2x)\,dx = 0$.

## 관련 개념

- 우함수(짝함수)
- 원점 대칭
- 정적분의 성질
- 대칭성을 이용한 적분
