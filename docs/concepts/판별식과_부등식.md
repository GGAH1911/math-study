# 판별식과 부등식

## 요약
이차방정식의 판별식 $D$의 부호에 따라 이차함수 그래프와 $x$축의 교점 개수를 결정하여 부등식의 해를 판별할 수 있습니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)에서 판별식 $D = b^2 - 4ac$는 방정식의 실근의 개수를 결정하는 핵심 지표입니다. 판별식 $D > 0$이면 서로 다른 두 실근을 가지며, $D = 0$이면 중근을 갖고, $D < 0$이면 실근을 갖지 않습니다. 이러한 성질은 이차부등식 $ax^2 + bx + c > 0$ 또는 $ax^2 + bx + c < 0$의 해를 구하는 데 결정적인 역할을 합니다. 부등식의 해가 모든 실수이거나 존재하지 않는 경우를 판별할 때 판별식의 부호를 확인하는 과정이 필수적입니다.

### 직관과 기하적 의미
이차부등식의 해는 이차함수 $y = ax^2 + bx + c$의 그래프가 $x$축($y=0$)과 만나는 위치와 관련이 있습니다. 판별식 $D$는 그래프가 $x$축과 만나는 점의 개수를 의미하므로, $D$의 부호에 따라 그래프가 $x$축 위로 떠 있는지, $x$축에 접하는지, 혹은 $x$축을 관통하는지를 시각적으로 파악할 수 있습니다.

### 기본 성질
이차부등식 $ax^2 + bx + c > 0$이 모든 실수 $x$에 대하여 성립하기 위해서는 이차항의 계수 $a > 0$이어야 하며, 그래프가 $x$축보다 항상 위에 있어야 하므로 판별식 $D < 0$이어야 합니다. 반대로 $ax^2 + bx + c < 0$이 항상 성립하려면 $a < 0$이고 $D < 0$이어야 합니다.

## 학습 체크
- 이차부등식의 해가 '모든 실수'일 때, 이차항의 계수 $a$의 부호와 판별식 $D$의 부호를 각각 어떻게 설정해야 하는가?
- 판별식 $D=0$인 경우, 부등식의 해가 '없음'이 되는 조건과 '모든 실수'가 되는 조건의 차이는 무엇인가?

## 관련 개념
- **이차함수**: 이차부등식의 해를 그래프의 위치 관계를 통해 시각적으로 해석할 수 있게 해주는 기초가 됩니다.
- **이차방정식**: 판별식을 통해 실근의 존재 여부를 판단하는 원리가 동일하게 적용됩니다.
