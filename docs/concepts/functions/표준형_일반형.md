# 표준형 일반형

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
$y=a(x-p)^2+q$ ↔ $y=ax^2+bx+c$

## 본문 (학습 시 채워짐)

### 정확한 진술

이차함수는 다음 두 가지 형태로 표현합니다.

**표준형**(꼭짓점 형): $y = a(x-p)^2 + q$ (단, $a \neq 0$)

**일반형**: $y = ax^2 + bx + c$ (단, $a \neq 0$)

이 두 형태는 동일한 이차함수를 다르게 표현한 것입니다. 표준형의 $p$와 $q$는 꼭짓점의 좌표이고, 일반형의 $a, b, c$는 전개된 형태의 계수입니다.

### 직관과 기하적 의미

**표준형의 강점**: 꼭짓점 $(p, q)$를 한눈에 읽을 수 있습니다. 또한 대칭축이 직선 $x = p$임을 바로 알 수 있고, 포물선이 기본 함수 $y = ax^2$를 가로로 $p$만큼, 세로로 $q$만큼 이동한 것임을 이해하기 좋습니다.

**일반형의 강점**: 이차함수가 주어진 그대로이며, 계수들의 관계를 통해 여러 성질(예: 판별식)을 다룰 때 편합니다.

### 형식 변환

**일반형 → 표준형** (평방완성): $y = ax^2 + bx + c$를 $a$로 인수분해한 뒤, $x$의 일차항을 완성합니다.

$$y = a\left(x^2 + \frac{b}{a}x\right) + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a}$$

따라서 $p = -\frac{b}{2a}$, $q = \frac{4ac - b^2}{4a}$입니다.

**표준형 → 일반형**: $(x-p)^2$을 전개합니다. $y = a(x^2 - 2px + p^2) + q = ax^2 - 2apx + (ap^2 + q)$

### 한 줄 예

$y = 2x^2 - 8x + 5$를 표준형으로: $y = 2(x-2)^2 - 3$ (꼭짓점: $(2, -3)$)

`sympy.factor(2*x**2 - 8*x + 5 - 2*(x-2)**2)`로 검증하면 $-3$이 나옵니다.
