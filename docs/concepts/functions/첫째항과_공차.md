### 정확한 진술

등차수열은 **첫째항** $a_1$과 **공차** $d$로 완전히 결정됩니다. 첫째항 $a_1$은 수열의 첫 번째 항이고, 공차 $d$는 연속된 두 항의 차이입니다. 즉, 모든 $n \geq 1$에 대해

$$a_{n+1} - a_n = d$$

를 만족합니다. 이 두 수(첫째항과 공차)만 알면, 등차수열의 모든 항을 구할 수 있습니다.

### 직관/기하적 의미

첫째항 $a_1$은 **출발점**이고, 공차 $d$는 **매 단계마다 얼마나 증가(또는 감소)하는가**를 나타냅니다. 예를 들어 $a_1 = 5$, $d = 3$이면, 수열은 5에서 시작해서 매번 3씩 커집니다: 5, 8, 11, 14, ...

공차가 양수면 수열은 증가하고, 음수면 감소하며, 0이면 모든 항이 같습니다. 수직선 위에 수열의 항들을 표시하면, 첫째항의 위치에서 시작하여 공차 크기만큼 규칙적으로 떨어진 점들이 배열됩니다. 첫째항과 공차는 이 규칙을 완전히 결정하는 **최소한의 정보**입니다.

### 한 줄 예

첫째항이 2, 공차가 4인 등차수열의 처음 다섯 항: $2, 6, 10, 14, 18$
```
# 검증: sympy.solve([2 + (1-1)*4, 2 + (2-1)*4, 2 + (3-1)*4, 2 + (4-1)*4, 2 + (5-1)*4], [])
# 또는 간단히: [2 + (n-1)*4 for n in range(1, 6)] → [2, 6, 10, 14, 18]
```
