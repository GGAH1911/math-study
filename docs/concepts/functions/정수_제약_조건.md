### 정확한 진술

정수 제약 조건(integer constraint)은 함수 최적화 문제에서 **변수 또는 함수값이 정수여야 한다**는 추가 조건입니다. 도함수의 활용으로 찾은 실수 범위의 최댓값이나 최솟값이 정수가 아닐 때, 정수 범위에서 다시 탐색해야 합니다.

수식으로는 다음과 같이 표현됩니다. 함수 $f(x)$가 실수 $a \leq x \leq b$ 범위에서 $x = x_0$에 도달하는 최댓값 $M = f(x_0)$을 가질 때, $M$이 정수가 아니면 정수 제약 조건 하의 최댓값은:

$$f(\lfloor x_0 \rfloor) \text{ 또는 } f(\lceil x_0 \rceil) \text{ 중 큰 값}$$

(또는 정의역 자체가 정수만 가능한 경우, 정의역의 정수점들만에서 함수값을 비교)

### 직관과 실제 상황

도함수를 이용해 함수의 임계점을 찾으면 **실수 범위에서의 최적값**을 얻습니다. 하지만 실생활 문제나 조합론 문제에서는 개수, 시간, 거리 등이 정수여야 하는 경우가 많습니다. 예를 들어 "판매량 $x$개에 따른 이익 $f(x)$의 최댓값"을 구할 때, $x$는 정수여야 하므로 미분으로 찾은 최적점 근처의 정수값들을 직접 대입하여 비교해야 합니다.

### 한 줄 예

$f(x) = -x^2 + 5x + 2$가 $0 \leq x \leq 5$ 범위에서 $x = 2.5$일 때 실수 최댓값 $8.25$를 갖지만, $x$가 정수여야 하면 $f(2) = 8$ 또는 $f(3) = 8$이 정수 최댓값입니다. (`sympy.solve(diff(-x**2 + 5*x + 2, x), x)` → `[2.5]`, `f(2)=8, f(3)=8`)
