# 매개변수 미분

> **정의** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
$dy/dx=(dy/dt)/(dx/dt)$

## 본문 (학습 시 채워짐)

### 정확한 진술

곡선이 매개변수 $t$로 다음과 같이 표현될 때:
$$x = f(t), \quad y = g(t)$$

이때 $\frac{dy}{dx}$는 다음 공식으로 구한다:
$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)} \quad (f'(t) \neq 0)$$

이를 **매개변수 미분**이라 하며, $y$를 $x$의 함수로 직접 나타낼 수 없을 때 유용하다.

### 직관/기하적 의미

매개변수 방정식에서 $x$와 $y$는 모두 중간 변수 $t$(예: 시간)에 의존한다. 따라서 $\frac{dy}{dx}$를 구하려면 연쇄법칙을 적용해야 한다.

$$\frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx} = \frac{dy/dt}{dx/dt}$$

물리적으로는 $\frac{dx}{dt}$와 $\frac{dy}{dt}$가 각각 $t$ 시점에서 $x$와 $y$의 순간변화율이므로, 그 비율이 곡선 위의 점에서 접선의 기울기가 된다.

### 예시

원을 나타내는 매개변수 방정식 $x = \cos t$, $y = \sin t$ $(t \in [0, \pi])$를 생각하자.

$$\frac{dx}{dt} = -\sin t, \quad \frac{dy}{dt} = \cos t$$

따라서:
$$\frac{dy}{dx} = \frac{\cos t}{-\sin t} = -\cot t$$

$t = \frac{\pi}{4}$일 때 접선의 기울기는 $-1$이다.

(`sympy.diff(sympy.sin(t), t) / sympy.diff(sympy.cos(t), t)` → $-\cot t$)
