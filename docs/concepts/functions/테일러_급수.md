### 정확한 진술

함수 $f(x)$가 $x=a$ 주변에서 무한번 미분가능할 때, $f(x)$를 다음과 같은 **무한급수**로 나타낼 수 있습니다.

$$f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \frac{f'''(a)}{3!}(x-a)^3 + \cdots$$

이를 **$x=a$에서의 테일러 급수**라고 부릅니다. 특히 $a=0$인 경우를 **매클로린 급수**라고 합니다.

### 직관적 의미

테일러 급수는 "함수를 다항식으로 정확하게 표현하는 방법"입니다. 핵심은 다음과 같습니다:

어떤 점 $x=a$에서 함수값 $f(a)$와 모든 차수의 도함수값들 $f'(a), f''(a), f'''(a), \ldots$을 알면, $a$ 주변의 **모든 점에서** 함수값을 계산할 수 있다는 뜻입니다.

기하학적으로는 $a$ 근처에서 일직선(1차 근사)으로 시작해 곡선(2차 근사)을 거쳐, 점점 더 높은 차수의 다항식이 원래 함수에 가까워지다가 무한 개의 항을 모두 더하면 정확히 일치합니다. 이는 제한된 정보(도함수들)로부터 전체 함수를 "재구성"하는 강력한 도구입니다.

### 한 줄 예

$e^x$의 매클로린 급수: $e^x = 1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \dfrac{x^4}{4!} + \cdots$

이 급수는 모든 실수 $x$에서 수렴하며, $x=1$을 대입하면 $e \approx 2.71828$을 얻습니다. (sympy: `sum(1/factorial(n) for n in range(20))` ≈ 2.71828)
