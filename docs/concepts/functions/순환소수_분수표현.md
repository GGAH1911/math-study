# 순환소수 분수표현

> **예제** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
등비급수 활용

## 본문 (학습 시 채워짐)

### 문제

다음 순환소수를 분수로 나타내시오.

(1) $0.\overline{5}$ (즉, $0.555\ldots$)

(2) $0.1\overline{3}$ (즉, $0.1333\ldots$)

### 단계별 풀이

**(1번 풀이)**

순환부분을 무한급수로 쓴다. $0.555\ldots = \frac{5}{10} + \frac{5}{100} + \frac{5}{1000} + \cdots$ (왜: 순환하는 부분 "5"를 소수 자리마다 분해)

공통인수로 묶으면 $= \frac{5}{10} \left(1 + \frac{1}{10} + \frac{1}{100} + \cdots \right)$ (왜: 등비급수 공식을 쓰기 위해)

괄호 안은 첫째항 $a=1$, 공비 $r=\frac{1}{10}$인 무한등비급수이므로 합은 $\frac{1}{1-\frac{1}{10}} = \frac{10}{9}$ (왜: 등비급수 공식 $S = \frac{a}{1-r}$ 적용)

따라서 $0.\overline{5} = \frac{5}{10} \cdot \frac{10}{9} = \frac{5}{9}$

**(2번 풀이)**

순환하지 않는 부분과 순환하는 부분을 분리한다. $0.1\overline{3} = 0.1 + 0.0\overline{3}$ (왜: 순환 시작점이 소수 둘째 자리이므로)

$0.0\overline{3} = \frac{3}{100} + \frac{3}{1000} + \cdots = \frac{3}{100}(1 + \frac{1}{10} + \frac{1}{100} + \cdots) = \frac{3}{100} \cdot \frac{10}{9} = \frac{1}{30}$

따라서 $0.1\overline{3} = \frac{1}{10} + \frac{1}{30} = \frac{3}{30} + \frac{1}{30} = \frac{4}{30} = \frac{2}{15}$

### 답

(1) $\boxed{\frac{5}{9}}$

(2) $\boxed{\frac{2}{15}}$

검증: `sympy.Rational(5, 9).evalf()` → 0.555..., `sympy.Rational(2, 15).evalf()` → 0.1333...

### 변형/주의

**순환마디의 길이가 긴 경우**: $0.\overline{142857}$처럼 순환마디가 6자리면 $\frac{1}{1-\frac{1}{10^6}}$을 적용하여 $\frac{142857}{999999} = \frac{1}{7}$을 얻는다.

**실수하기 쉬운 점**: 순환하지 않는 부분($0.1$)과 순환하는 부분($0.\overline{3}$)을 명확히 구분하지 않으면 공비와 첫째항을 잘못 설정한다. 순환 시작 위치를 10의 거듭제곱으로 정확히 파악하는 것이 핵심이다.
