### 정확한 진술

삼각함수 방정식(trigonometric equation)이란 미지수가 삼각함수의 인수로 나타나는 방정식입니다. 가장 기본적인 형태는 $\sin x = a$, $\cos x = b$, $\tan x = c$ 같은 꼴이며, 더 복잡하게는 $2\sin^2 x + 3\cos x = 1$ 또는 $\tan 2x = \sin x$ 같이 여러 삼각함수가 섞여 있을 수 있습니다. 주어진 상수에 대해 조건을 만족하는 모든 $x$를 찾는 것이 목표입니다.

### 직관·기하적 의미

삼각함수는 주기 함수이므로 방정식의 해도 무한히 많은 경우가 대부분입니다. 예를 들어 $\sin x = 0.5$의 해는 한 주기 $[0, 2\pi)$ 내에서는 $x = \dfrac{\pi}{6}, \dfrac{5\pi}{6}$ 두 개이지만, 전체 실수에서는 이들에 $2\pi$의 정수배를 더한 무수히 많은 값들입니다. 그래프적으로는 $y = \sin x$ 곡선과 $y = 0.5$ 직선이 만나는 점들의 $x$ 좌표를 모두 구하는 것이며, 주기성 때문에 같은 패턴이 반복됩니다. 따라서 보통 한 주기 내의 기본해(기본각)를 먼저 구한 뒤, 주기를 더하여 일반해를 표현합니다.

### 한 줄 예

$\cos x = \dfrac{1}{2}$를 $[0, 2\pi)$에서 풀면 $x = \dfrac{\pi}{3}, \dfrac{5\pi}{3}$이고, 일반해는 $x = \pm\dfrac{\pi}{3} + 2\pi n$ (단, $n$은 정수)입니다.
