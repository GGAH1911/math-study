### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음이 성립합니다.

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha \beta = \frac{c}{a}$$

이를 **근과 계수의 관계** 또는 **비에타의 정리**(Vieta's formulas)라고 부르며, 두 근의 합과 곱을 이차방정식의 계수로 직접 표현하는 관계식입니다.

### 직관/기하적 의미

이차방정식을 두 근 $\alpha, \beta$로 인수분해하면:

$$a(x - \alpha)(x - \beta) = 0$$

이를 전개하면:

$$ax^2 - a(\alpha + \beta)x + a\alpha\beta = 0$$

원래 형태 $ax^2 + bx + c = 0$과 계수를 비교하면:
- $-a(\alpha + \beta) = b$ ⟹ $\alpha + \beta = -\frac{b}{a}$
- $a\alpha\beta = c$ ⟹ $\alpha\beta = \frac{c}{a}$

핵심은 **근의 공식으로 실제 근을 구하지 않아도**, 계수만으로 두 근의 합과 곱을 알 수 있다는 것입니다. 이는 근의 개별 값보다 근들의 관계식이 필요할 때 계산을 크게 단순화합니다.

### 한 줄 예

$x^2 - 5x + 6 = 0$의 두 근은 $\alpha = 2, \beta = 3$이고, $2 + 3 = 5 = -\frac{-5}{1}$, $2 \times 3 = 6 = \frac{6}{1}$을 확인할 수 있습니다.

(`sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)
