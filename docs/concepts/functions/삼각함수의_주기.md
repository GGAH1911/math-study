### 정확한 진술

함수 $f(x)$가 주기 $T$를 가진다는 것은, 모든 $x$에 대해 다음을 만족하는 양수 $T$가 존재한다는 뜻입니다:

$$f(x + T) = f(x)$$

이때 조건을 만족하는 **가장 작은 양수 $T$**를 함수의 **기본주기(또는 최소주기)**라고 부릅니다. 삼각함수에서는:
- $\sin(x)$, $\cos(x)$의 기본주기: $2\pi$
- $\tan(x)$, $\cot(x)$의 기본주기: $\pi$

일반적으로 $f(x) = \sin(Bx + C) + D$ 형태일 때, 주기는 $\dfrac{2\pi}{|B|}$입니다. $\tan$ 함수라면 $\dfrac{\pi}{|B|}$입니다.

### 직관/기하적 의미

단위원을 이용한 삼각함수의 정의에서, 각도 $x$를 $2\pi$만큼 증가시키면 같은 위치로 돌아옵니다. 따라서 사인값과 코사인값도 완전히 같아집니다. 

**그래프**로 보면, 한 주기만큼 이동한 곡선은 원래 곡선과 완벽하게 겹칩니다. 이것이 "주기적"이라 부르는 이유입니다. 실생활에서는 파동, 진동, 계절 변화 등 반복되는 현상을 수학적으로 표현할 때 주기함수를 사용합니다.

$\tan(x)$가 $\pi$를 주기로 갖는 이유는 $\tan(x) = \dfrac{\sin(x)}{\cos(x)}$인데, 분자와 분모가 모두 부호가 바뀌어 결과적으로 $\pi$마다 값이 반복되기 때문입니다.

### 한 줄 예

$\sin(x) = \sin(x + 2\pi)$이므로 사인함수의 주기는 $2\pi$입니다. 또한 $\cos\left(3x\right)$의 주기는 $\dfrac{2\pi}{3}$인데, 이는 $x$ 값이 $\dfrac{2\pi}{3}$씩 증가할 때마다 함수값이 같아진다는 뜻입니다.

**검산:**
```python
import sympy as sp
x = sp.Symbol('x')
# sin(x)의 주기 확인: sin(x + 2π) = sin(x)
sp.simplify(sp.sin(x + 2*sp.pi) - sp.sin(x))  # 0
```
