### 정확한 진술

일차함수는 다음 형태로 나타낼 수 있는 함수입니다:

$$f(x) = ax + b$$

여기서 $a$와 $b$는 상수이고, **$a \neq 0$**입니다. 상수항 $b$의 조건은 없으므로, $b = 0$이어도 일차함수입니다. 예를 들어 $f(x) = 3x$도 일차함수입니다.

### 직관과 기하적 의미

일차함수의 그래프는 **직선**입니다. 상수 $a$를 **기울기**(또는 변화율)라고 부르며, 이 값이 클수록 그래프의 기울기가 가파릅니다. $a > 0$이면 오른쪽으로 올라가는 직선, $a < 0$이면 오른쪽으로 내려가는 직선입니다.

상수 $b$는 **y절편**이라 하며, 그래프가 y축과 만나는 점의 y좌표입니다. 즉, $f(0) = b$입니다. 이를 통해 일차함수의 직선이 y축의 어느 위치에서 시작하는지 알 수 있습니다.

### 핵심 특성

일차함수의 중요한 성질 중 하나는 **일정한 변화율**을 갖는다는 것입니다. x가 1만큼 증가할 때, y는 항상 $a$만큼 변합니다. 예를 들어 $f(x) = 2x + 3$에서 x가 1 증가하면 y는 2 증가합니다.

$$f(x+1) - f(x) = a(x+1) + b - (ax + b) = a$$

### 실제 예시

$f(x) = 2x + 3$을 생각해봅시다. 이 함수의 기울기는 $a = 2$, y절편은 $b = 3$입니다. $f(0) = 3$, $f(1) = 5$, $f(2) = 7$이므로, 그래프는 점 $(0, 3)$에서 시작해 오른쪽 위로 가파르게 올라가는 직선입니다.
