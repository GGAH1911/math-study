### 정확한 진술

함수의 방정식이란, 주어진 조건들(예: 도함수, 특정 점에서의 함수값, 기하학적 성질)로부터 함수 $f(x)$를 유일하게 결정하는 관계식을 말합니다. 보통 다음과 같은 형태입니다:

$$f'(x) = g(x) \text{와} \quad f(a) = b \quad (\text{초기조건})$$

이 두 정보가 주어질 때, 함수 $f(x)$를 구하는 것을 "함수의 방정식을 푼다"고 합니다.

### 직관과 의미

도함수 $f'(x)$는 함수의 "변화율"을 나타냅니다. 만약 $f'(x)$를 알면 함수가 어떻게 증가하거나 감소하는지 알 수 있지만, 함수 자체는 아직 결정되지 않습니다. 왜냐하면 모든 역도함수는 상수 $C$만큼 다를 수 있기 때문입니다:

$$f(x) = \int f'(x) \, dx = F(x) + C$$

여기서 $C$는 임의의 상수입니다. 이 상수를 유일하게 결정하기 위해 **초기조건** $f(a) = b$를 사용합니다. 이는 "함수 위의 한 점"의 좌표를 알려주는 것으로, 함수의 그래프를 정확하게 고정시킵니다.

### 기본 예제

**조건:** $f'(x) = 3x^2 + 2$이고, $f(0) = 1$일 때 $f(x)$를 구하세요.

**풀이:**
1. $f'(x)$를 적분합니다:
$$f(x) = \int (3x^2 + 2) \, dx = x^3 + 2x + C$$

2. 초기조건 $f(0) = 1$을 이용하여 $C$를 구합니다:
$$f(0) = 0^3 + 2(0) + C = 1 \Rightarrow C = 1$$

3. 따라서 $f(x) = x^3 + 2x + 1$

**검증:** `sympy.integrate(3*x**2 + 2, x)` → $x^3 + 2x + C$

이처럼 도함수와 한 점의 함수값이 주어지면, 부정적분(역도함수)과 초기조건을 이용해 함수를 완전히 결정할 수 있습니다.
