# 반비례

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
$y=a/x$ 관계

## 본문 (학습 시 채워짐)

### 정확한 진술

두 변수 $x$, $y$ 사이의 관계식이 $y = \frac{a}{x}$ (단, $a$는 $0$이 아닌 상수)로 나타날 때, $y$는 $x$에 대하여 **반비례**한다고 합니다. 여기서 $a$를 **비례상수**라고 부릅니다.

### 직관/기하적 의미

$x$와 $y$를 곱한 값이 항상 일정하다는 뜻입니다. 즉, $x \cdot y = a$ (상수)입니다. 한 변수가 증가하면 다른 변수는 감소하고, 한 변수가 감소하면 다른 변수는 증가하는 **역의 관계**를 나타냅니다.

반비례 함수의 그래프는 **쌍곡선** 모양입니다. 좌표평면에 두 개의 곡선 부분으로 나타나는데, $a > 0$일 때는 제1사분면과 제3사분면에, $a < 0$일 때는 제2사분면과 제4사분면에 위치합니다. 그래프는 $x$축이나 $y$축과 만나지 않습니다. (축과 만나려면 $x = 0$ 또는 $y = 0$이어야 하는데, 이는 불가능하기 때문)

### 예제

**문제**: $y = \frac{6}{x}$에서 $x = 2$일 때 $y$의 값을 구하시오.

$x = 2$를 대입하면 $y = \frac{6}{2} = 3$입니다. 점 $(2, 3)$이 이 함수 그래프 위의 한 점입니다. 마찬가지로 $x = 3$일 때 $y = 2$, $x = 6$일 때 $y = 1$이므로, $x$가 증가하면서 $y$는 감소함을 확인할 수 있습니다.

(검증: `sympy.solve(y - 6/2, y)` → 3, `sympy.solve(3*2, )` → 6)
