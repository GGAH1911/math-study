### 정확한 진술

**반복 구조의 극한**은 점화식이나 재귀 관계로 정의된 수열이 수렴할 때 그 극한값을 의미합니다. 수열 $\{a_n\}$이 점화식 $a_{n+1} = f(a_n)$을 만족하고 $\lim_{n \to \infty} a_n = L$이 존재한다면, 양변에 극한을 취하여 $L = f(L)$이 성립합니다. 이 $L$이 반복 구조의 극한값입니다.

더 일반적으로, 반복 구조에서 각 단계의 결과가 이전 단계에만 의존하는 구조(함수의 반복합성 $f \circ f \circ \cdots \circ f$)에서 수렴하는 값을 뜻합니다.

### 직관과 기하적 의미

반복 구조의 극한은 "무한히 반복해도 변하지 않는 고정점"입니다. 예를 들어 계산기에서 한 수에 특정 함수를 계속 적용하면, 어느 순간부터는 화면에 같은 숫자가 나타나게 되는 현상이 바로 이것입니다.

그래프로 보면, $y = f(x)$와 $y = x$ 직선의 교점이 반복 구조의 극한값입니다. 점 $(a_n, a_n)$에서 출발하여 수직선으로 곡선에 닿고, 수평선으로 대각선에 닿는 과정을 반복하면(거미집 도형), 점들이 교점으로 수렴합니다.

### 한 줄 예

점화식 $a_{n+1} = \sqrt{2 + a_n}$에서 $a_1 = 0$이면, 수열은 $L = \sqrt{2 + L}$의 해인 $L = 2$로 수렴합니다.

$a_n = \left(1 + \frac{1}{n}\right)^n$은 상수함수가 아니지만 반복 구조 극한의 개념으로 오일러 수 $e$를 정의하기도 합니다. (`sympy로 확인: limit((1 + 1/n)**n, n, oo)` → $e \approx 2.71828$)
