# 미분계수 (Derivative at a point)

> **concept_type**: definition · **mastery**: 🟧 learning
> **선수**: [극한](/concepts/극한)
> **사용처**: [도함수](/concepts/도함수)

## 정의

함수 $y = f(x)$의 $x = a$에서의 **미분계수** $f'(a)$는 다음 극한으로 정의된다(이 극한이 존재할 때).

$$f'(a) \;=\; \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

동치 형태:

$$f'(a) \;=\; \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

기호는 $f'(a)$ 외에도 $\left. \dfrac{dy}{dx} \right|_{x=a}$, $\dot{f}(a)$ 등을 쓴다.

## 기하적 의미

곡선 $y = f(x)$ 위의 두 점 $\bigl(a, f(a)\bigr)$, $\bigl(a + h,\, f(a+h)\bigr)$를 지나는 **할선(secant line)** 의 기울기는

$$m_{\text{secant}}(h) = \frac{f(a+h) - f(a)}{h}$$

$h \to 0$일 때 할선은 점 $\bigl(a, f(a)\bigr)$에서의 **접선(tangent line)** 으로 수렴하고, 그 기울기가 바로 미분계수 $f'(a)$이다.

![h가 0으로 가까워질수록 f(x)=x² 위의 할선이 점 (1,1)에서의 접선 y=2x-1로 수렴하는 모습](../assets/미분계수/tangent_secant.svg)

## 표준 예제

**예제 1.** $f(x) = x^2$일 때 $f'(1)$을 구하라.

풀이.
$$f'(1) = \lim_{h \to 0} \frac{(1+h)^2 - 1^2}{h} = \lim_{h \to 0} \frac{2h + h^2}{h} = \lim_{h \to 0} (2 + h) = 2$$

(sympy 검산 통과 — `docs/assets/미분계수/tangent_secant.py` 참조.)

**예제 2.** $f(x) = \sqrt{x}$일 때 $f'(4)$를 구하라.

풀이. 유리화로 부정형 $\tfrac{0}{0}$을 해소한다.
$$f'(4) = \lim_{h \to 0} \frac{\sqrt{4+h} - 2}{h} = \lim_{h \to 0} \frac{(\sqrt{4+h} - 2)(\sqrt{4+h} + 2)}{h(\sqrt{4+h}+2)} = \lim_{h \to 0} \frac{h}{h(\sqrt{4+h}+2)} = \frac{1}{4}$$

## 미분 가능성

$f'(a)$가 존재하면 $f$는 $x = a$에서 **미분 가능**하다고 한다. 미분 가능 ⇒ 연속이지만 역은 성립하지 않는다 (예: $f(x) = |x|$는 $x = 0$에서 연속이지만 미분 불가능).

## 본문

### 정의

함수 $f(x)$가 $x = a$를 포함하는 구간에서 정의될 때, 다음 극한값이 존재하면 그 값을 **미분계수**라 하고 $f'(a)$로 나타냅니다.

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

또는 변수를 바꾸면:

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

### 기하적 의미

미분계수 $f'(a)$는 곡선 $y = f(x)$ 위의 점 $(a, f(a))$에서의 **접선의 기울기**입니다. 분자는 높이의 변화량, 분모는 가로의 변화량이므로, $h$를 0에 점점 가깝게 좁혀가며 할선(두 점을 잇는 직선)이 접선으로 수렴하는 극한입니다. 따라서 미분계수는 그 점에서의 **순간변화율**을 나타냅니다.

### 예

$f(x) = x^2$일 때, $x = 2$에서의 미분계수를 구하면:

$$f'(2) = \lim_{h \to 0} \frac{(2+h)^2 - 4}{h} = \lim_{h \to 0} \frac{4 + 4h + h^2 - 4}{h} = \lim_{h \to 0} (4 + h) = 4$$

곡선 $y = x^2$은 점 $(2, 4)$에서 기울기 4인 접선을 갖습니다. (검산: `sympy.diff(x**2, x).subs(x, 2)` = 4)
