### 정확한 진술

함수 $f(x)$가 특정 구간에서 미분가능할 때, 도함수 $f'(x)$의 부호를 이용하여 함수의 증감을 판정하고, 이를 통해 특정 점에서의 함수값(최솟값 또는 최댓값)과 다른 식의 대소관계를 증명하는 방법입니다.

**기본 원리:**
- $f'(x) > 0$ (구간에서) ⟹ $f(x)$ 증가
- $f'(x) < 0$ (구간에서) ⟹ $f(x)$ 감소
- $f'(x) = 0$ 인 점에서 극값을 가짐

특정 점 $x = a$에서 $f(x)$의 최솟값이 $f(a) = m$이면, 모든 $x$에 대해 $f(x) \geq m$이 성립합니다. 이를 역으로 이용하여 부등식을 증명합니다.

### 직관/기하적 의미

도함수는 함수의 "순간 변화율"이므로, 도함수의 부호는 함수가 올라가는지(양수) 내려가는지(음수)를 보여줍니다. 

구간 내에서 함수의 최솟값을 찾으면, 그 점에서의 함수값이 구간 전체의 "하한"이 됩니다. 예를 들어, 어떤 함수가 $x = 1$에서 최솟값 0을 가지면, 그 구간의 모든 $x$에 대해 $f(x) \geq 0$입니다. 이 성질로 모양이 복잡한 부등식도 우아하게 증명할 수 있습니다.

기하학적으로는 함수의 그래프를 그렸을 때, 그 그래프의 최솟점(또는 최댓점)을 찾는 것입니다.

### 한 줄 예

$f(x) = x - \ln x$ ($x > 0$)에서 $f'(x) = 1 - \frac{1}{x}$이고, $x = 1$일 때 최솟값 $f(1) = 1$을 가지므로, 모든 $x > 0$에 대해 $x - \ln x \geq 1$, 즉 $x \geq \ln x + 1$이 성립합니다.
```python
# 검증: f(x) = x - ln(x)의 최솟값이 1임을 확인
from sympy import symbols, ln, diff, solve
x = symbols('x', positive=True)
f = x - ln(x)
f_prime = diff(f, x)
critical_points = solve(f_prime, x)  # [1]
print(f"최솟값: f(1) = {f.subs(x, 1)}")  # 1
```
