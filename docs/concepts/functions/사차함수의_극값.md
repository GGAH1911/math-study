### 정확한 진술

사차함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$ (단, $a \neq 0$)의 **극값**은 다음과 같이 정의됩니다:

어떤 점 $x = p$에서 $f'(p) = 0$이고, $x = p$를 기준으로 $f'(x)$의 부호가 바뀔 때, $f(p)$를 극값이라 부릅니다. 구체적으로:
- $f'(x)$가 **양에서 음**으로 바뀌면: $f(p)$는 **극댓값**
- $f'(x)$가 **음에서 양**으로 바뀌면: $f(p)$는 **극솟값**

### 직관 및 기하적 의미

사차함수의 도함수 $f'(x)$는 삼차함수이므로 최대 3개의 실근을 가집니다. 따라서 사차함수는 **최대 3개의 극값**을 가질 수 있습니다. 

그래프 위에서 극값은 "봉우리"(극댓값) 또는 "계곡"(극솟값)처럼 나타납니다. 이들은 함수가 증가에서 감소로 (또는 감소에서 증가로) 방향을 바꾸는 지점입니다. $f'(x) = 0$이지만 부호가 바뀌지 않는 점에서는 극값이 **아님**을 주의해야 합니다 (변곡점).

### 예시

$f(x) = x^4 - 8x^2 + 7$일 때, $f'(x) = 4x^3 - 16x = 4x(x^2 - 4)$이므로 $f'(x) = 0$의 근은 $x = -2, 0, 2$입니다.

부호 변화를 조사하면:
- $x < -2$: $f'(x) < 0$ (감소)
- $-2 < x < 0$: $f'(x) > 0$ (증가)
- $0 < x < 2$: $f'(x) < 0$ (감소)
- $x > 2$: $f'(x) > 0$ (증가)

따라서 $x = -2$에서 극솟값 $f(-2) = -9$, $x = 0$에서 극댓값 $f(0) = 7$, $x = 2$에서 극솟값 $f(2) = -9$를 갖습니다.
