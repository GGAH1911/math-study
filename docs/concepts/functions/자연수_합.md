### 정의

처음 $n$개의 자연수를 모두 더한 합을 다음과 같이 정의합니다.

$$S_n = 1 + 2 + 3 + \cdots + n = \sum_{k=1}^{n} k$$

이 합의 값은 공식으로 다음과 같이 계산됩니다.

$$S_n = \frac{n(n+1)}{2}$$

### 직관과 기하적 의미

이 공식이 왜 성립하는지 **가우스의 방법**으로 살펴봅시다. 같은 합을 두 가지 방식으로 나열합니다.

$$\begin{align}
S_n &= 1 + 2 + 3 + \cdots + n \\
S_n &= n + (n-1) + (n-2) + \cdots + 1
\end{align}$$

두 식을 항별로 더하면 각 열의 합이 항상 $n+1$이 되고, 총 $n$개 열이 있으므로

$$2S_n = n(n+1) \quad \Rightarrow \quad S_n = \frac{n(n+1)}{2}$$

**기하적으로** 보면, 밑변 $k$, 높이 1인 직사각형들을 계단 모양으로 쌓은 것입니다. 이 계단 모양 영역의 넓이는 밑변 $n$, 높이 $(n+1)$인 직사각형 넓이의 정확히 절반이 됩니다.

### 예시

첫 100개 자연수의 합:

$$S_{100} = \frac{100 \times 101}{2} = 5050$$

더 간단한 예로, 첫 5개 자연수의 합은 $S_5 = \frac{5 \times 6}{2} = 15$ (검산: $1+2+3+4+5=15$)

일반적으로 이 공식은 수열, 급수, 수학적 귀납법 증명 등 고등학교 수학 전체에서 자주 나타나는 핵심 결과입니다.
