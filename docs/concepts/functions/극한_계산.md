### 정확한 진술

극한 계산(limit calculation)은 $\lim_{x \to a} f(x)$를 구하기 위해 직접 대입 또는 대수적 조작을 통해 수렴값을 구하는 과정입니다. $x = a$를 직접 대입했을 때 $\frac{0}{0}$, $\frac{\infty}{\infty}$, $\infty - \infty$ 등의 **부정형**이 발생하면, 인수분해, 유리화, 표준 극한 공식 등을 활용하여 형태를 변형한 후 극한값을 결정합니다.

### 직관과 기하적 의미

극한은 "$x$가 $a$에 한없이 가까워질 때 $f(x)$는 어떤 값 $L$에 한없이 가까워지는가"라는 질문입니다. 그래프 위에서 점 $(a, f(a))$ 자체의 존재나 함수값과 무관하게, $x = a$ 근처에서 함수의 행동이 어디로 수렴하는지를 찾는 것입니다. 예를 들어 $f(x) = \frac{x^2 - 1}{x - 1}$은 $x = 1$에서 정의되지 않지만, $x$가 1에 가까워질수록 함수값은 2에 접근합니다.

### 계산 절차와 예

**직접 대입**
$$\lim_{x \to 2} (x^2 + 1) = 5$$
부정형이 나타나지 않으면 바로 답입니다.

**부정형 해소: 인수분해**
$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x-2} = \lim_{x \to 2} (x+2) = 4$$
(`sympy.limit((x**2 - 4)/(x - 2), x, 2)`)

**표준 극한 활용**
$$\lim_{x \to 0} \frac{\sin x}{x} = 1, \quad \lim_{x \to 0} \frac{e^x - 1}{x} = 1$$

이들은 고교 과정에서 자주 등장하는 표준값으로, 복합 극한식을 축약할 때 핵심입니다.

### 한 줄 정리

극한 계산은 "직접 대입 → 부정형 판정 → 변형(인수분해/유리화/표준극한) → 극한값" 순서의 체계적 절차입니다.
