### 정확한 진술

함수 $f(x)$가 정의역의 모든 $x$에 대하여 $f(x+p) = f(x)$를 만족하는 양수 $p$가 존재할 때, 이 함수를 **주기함수**라고 부릅니다. 이때 $p$를 주기(period)라고 합니다. 주기함수가 가지는 주기 중에서 가장 작은 양수를 **기본주기**(또는 최소주기)라고 하며, 보통 $T$로 나타냅니다.

### 직관 및 기하적 의미

주기함수는 일정한 간격으로 함숫값이 반복되는 함수입니다. 그래프로 보면 $x$축 방향으로 주기 $p$만큼 이동해도 모양이 정확히 같습니다. 마치 벽지의 무늬가 일정하게 반복되거나, 시계 바늘이 12시간마다 같은 위치로 돌아오는 것처럼, 주기함수도 특정 길이 구간의 패턴이 양쪽으로 무한히 반복됩니다. 따라서 주기함수를 완전히 파악하려면 기본주기 구간 내의 함숫값만 알면 됩니다.

### 예시

삼각함수 $\sin x$와 $\cos x$는 기본주기 $T = 2\pi$인 주기함수입니다. 즉, 모든 $x$에 대해 $\sin(x + 2\pi) = \sin x$, $\cos(x + 2\pi) = \cos x$를 만족합니다. 또한 $\tan x$는 기본주기 $T = \pi$인 주기함수입니다. 

보다 간단한 예로, 상수함수 $f(x) = 3$은 모든 양수 $p$에 대해 $f(x+p) = f(x) = 3$이므로 주기함수이지만, 기본주기가 존재하지 않습니다. 반면 $f(x) = \sin(2x)$는 기본주기 $T = \pi$를 갖습니다.

### 참고: 주기함수의 판정

함수가 주기함수인지 판정할 때는, 정의역 내의 **모든** $x$에 대해 주기 조건이 성립해야 함에 주의합니다. 예를 들어 $f(x) = x + \sin x$는 $f(x + 2\pi) = x + 2\pi + \sin x \ne x + \sin x$이므로 주기함수가 아닙니다.
