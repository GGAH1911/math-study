# 극댓값 극솟값

> **예제** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
극값 후보 + 부호 변화

## 본문 (학습 시 채워짐)

### 문제

함수 $f(x) = x^3 - 3x^2 - 9x + 5$의 극댓값과 극솟값을 구하시오.

### 단계별 풀이

**1단계: 도함수 구하기**

극값은 도함수가 0이 되는 점에서 나타나므로 먼저 도함수를 계산합니다.

$$f'(x) = 3x^2 - 6x - 9$$

**2단계: 극값 후보 찾기 (임계점)**

$f'(x) = 0$을 풀어서 도함수가 0이 되는 $x$ 값을 구합니다. 이것이 극값의 후보입니다.

$$3x^2 - 6x - 9 = 0 \Rightarrow x^2 - 2x - 3 = 0$$
$$(x - 3)(x + 1) = 0 \Rightarrow x = -1 \text{ 또는 } x = 3$$

**3단계: 도함수의 부호 변화로 극값 판정**

임계점을 기준으로 도함수의 부호가 어떻게 변하는지 확인합니다. 부호가 양에서 음으로 바뀌면 극댓값, 음에서 양으로 바뀌면 극솟값입니다.

| 구간 | $x < -1$ | $-1 < x < 3$ | $x > 3$ |
|------|----------|-------------|--------|
| $f'(x)$의 부호 | + | − | + |
| $f(x)$의 증감 | ↗ | ↘ | ↗ |

- $x = -1$: 부호가 +에서 −로 변함 → **극댓값**
- $x = 3$: 부호가 −에서 +로 변함 → **극솟값**

**4단계: 극값의 y좌표 계산**

극댓값: $f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) + 5 = -1 - 3 + 9 + 5 = 10$

극솟값: $f(3) = 27 - 27 - 27 + 5 = -22$

### 답

극댓값은 $\mathbf{10}$ (at $x=-1$), 극솟값은 $\mathbf{-22}$ (at $x=3$)

### 변형/주의

**부호 변화가 반드시 일어나야 극값입니다.** 도함수가 0이 되더라도 부호가 변하지 않으면 극값이 아니라 변곡점입니다.

**2계 도함수로도 판정 가능합니다.** $f''(x) = 6x - 6$에서 $f''(-1) = -12 < 0$ (극대), $f''(3) = 12 > 0$ (극소)로 판정할 수 있습니다. 다만 부호 변화표가 더 직관적이고 확실합니다.

(검증: `sympy.solve(3*x**2 - 6*x - 9, x)` → $[-1, 3]$)
