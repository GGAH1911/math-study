# 도함수의 활용

> **단원** · 수학Ⅱ · 선수: [도함수](/concepts/도함수) / [미분](/concepts/미분) · 다음: 적분의 활용

## 학습 목표
- 도함수의 부호로 함수의 증가·감소 구간을 결정할 수 있다
- 극값의 정의와 1차·2차 도함수를 이용한 극값 판정법을 적용해 극대·극소를 구분할 수 있다
- 접선의 방정식을 도함수와 한 점의 좌표를 이용해 세울 수 있다
- 함수의 그래프 개형 (증감, 극값, 변곡점, 점근선)을 도함수 분석으로 그릴 수 있다
- 속도·가속도 등 변화율 문제에 도함수를 응용할 수 있다

## 다룰 정의 / 정리 / 예제

- 극값의 정의와 1차 도함수 판정 (부호 변화)
- 2차 도함수를 이용한 극값 판정 / 변곡점 정의
- 접선의 기울기 = 그 점에서의 도함수 값
- 접선의 방정식 (한 점·기울기·법선 등)
- 증가함수 / 감소함수의 판정
- 함수의 그래프 그리기 (증감표 + 극값 + 변곡점)
- 속도 = 위치의 도함수, 가속도 = 속도의 도함수
