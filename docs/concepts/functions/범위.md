### 정확한 진술

함수 $f: A \to B$의 **범위(range)**는 함수가 실제로 취할 수 있는 모든 함수값들의 집합입니다. 즉, $f$의 범위는 $\{f(x) \mid x \in A\}$로 정의되며, 보통 $\text{Range}(f)$ 또는 $f(A)$로 표기합니다.

정의역이 $A$, 치역이 $B$일 때 범위는 항상 치역의 부분집합입니다. 범위 $\subseteq$ 치역이며, 범위 = 치역인 경우 함수를 **전사함수(onto)**라고 부릅니다.

### 직관/기하적 의미

그래프 위에서 범위는 **함수가 그려내는 모든 $y$ 값들의 범위**입니다. 이차함수 $f(x) = ax^2 + bx + c$ ($a > 0$)의 경우, 포물선이 아래로 볼록하므로 최솟값을 가지며, 범위는 $[f(\text{꼭짓점}), \infty)$가 됩니다.

좌표평면에서 함수의 그래프는 $y = f(x)$인 점들의 집합인데, 이 점들의 $y$ 좌표를 모두 모으면 범위입니다. 이는 그래프를 $y$축에 정사영했을 때 나타나는 부분입니다.

### 한 줄 예

이차함수 $f(x) = x^2 - 4x + 5$의 범위는 $[1, \infty)$입니다. (꼭짓점에서 $y = 1$이므로)

```python
# 검산: sympy를 이용한 확인
from sympy import symbols, solve, Min
x = symbols('x', real=True)
f = x**2 - 4*x + 5
vertex_x = -(-4)/(2*1)  # 꼭짓점 x 좌표
min_value = f.subs(x, vertex_x)  # y = 1
```

### 주의점

- **범위와 치역의 구분**: 정의역과 치역이 모두 주어진 경우, 범위는 치역보다 작거나 같습니다.
- **폐구간과 개구간**: 범위가 최솟값을 가지면 폐구간 $[a, \infty)$, 최솟값이 없으면 개구간 $(a, \infty)$로 표기합니다.
