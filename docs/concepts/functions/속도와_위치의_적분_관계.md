### 정확한 진술

위치 함수 $s(t)$의 도함수가 속도 $v(t) = s'(t)$일 때, 속도를 시간에 대해 적분하면 위치의 변화량을 구할 수 있습니다:

$$s(t) - s(t_0) = \int_{t_0}^{t} v(u) \, du$$

또는 $s(t_0) = s_0$ (초기 위치)일 때:

$$s(t) = s_0 + \int_{t_0}^{t} v(u) \, du$$

미분과 적분의 역관계에 의해, 속도의 정적분은 위치의 변화량이고, 거꾸로 위치를 미분하면 속도를 얻습니다.

### 직관과 기하적 의미

속도 $v(t)$는 시간에 따른 위치 변화의 **순간 변화율**입니다. 미세한 시간 구간 $dt$에서 위치 변화는 $v(t) \cdot dt$이고, 이를 모두 더하면(적분하면) 전체 위치 변화가 됩니다.

속도-시간 그래프에서 $v(t)$를 그렸을 때, **그래프 아래 넓이**가 곧 위치의 변화량입니다(시간 구간 $[t_0, t]$ 사이). 넓이가 양수면 정방향 이동, 음수면 역방향 이동을 의미합니다.

이는 가속도 $a(t) = v'(t)$에서 속도를 구하는 관계 $v(t) = v_0 + \int_{t_0}^{t} a(u) \, du$와 완전히 같은 논리입니다.

### 한 줄 예

등속 운동 $v(t) = 3$ (m/s)에서 $t=0$부터 $t=5$까지의 위치 변화:

$$\Delta s = \int_{0}^{5} 3 \, dt = 3 \times 5 = 15 \text{ m}$$

더 일반적으로, $v(t) = 2t + 1$ (m/s)이고 초기 위치 $s(0) = 0$일 때:

$$s(t) = \int_{0}^{t} (2u + 1) \, du = t^2 + t$$

`sympy.integrate(2*u + 1, (u, 0, 5))` 로 $u=0$부터 $5$까지의 변위 15를 확인할 수 있습니다.
