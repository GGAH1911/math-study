# 지수로그 미분 예제

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$y=e^x\ln x$ 미분

## 본문 (학습 시 채워짐)

### 문제

$y=e^x \ln x$를 $x$에 대해 미분하시오.

### 단계별 풀이

이 함수는 지수함수 $e^x$와 로그함수 $\ln x$의 곱 형태입니다. **곱의 미분법**을 사용합니다.

곱의 미분법: $(uv)'=u'v+uv'$

$u=e^x$, $v=\ln x$로 놓으면:
- $u' = e^x$ (지수함수의 미분)
- $v' = \dfrac{1}{x}$ (로그함수의 미분)

공식에 대입합니다:

$$y' = (e^x)' \cdot \ln x + e^x \cdot (\ln x)'$$

$$y' = e^x \ln x + e^x \cdot \frac{1}{x}$$

공통인수 $e^x$로 인수분해하면:

$$y' = e^x\left(\ln x + \frac{1}{x}\right)$$

### 답

$$y' = e^x\left(\ln x + \frac{1}{x}\right)$$

또는 전개 형태: $y' = e^x \ln x + \dfrac{e^x}{x}$

**검산** (sympy): `diff(exp(x)*log(x), x)` → $e^x \log(x) + \dfrac{e^x}{x}$ ✓

### 변형/주의

**1단계에서 자주 하는 실수:**
- $(\ln x)' = \dfrac{1}{x}$를 정확히 기억해야 함 (다른 로그 함수와 혼동 주의)
- 곱의 미분법에서 순서 바꾸기: $(uv)' \neq u'v'$ (합성 규칙 아님)

**정의역 확인:**
$\ln x$는 $x > 0$에서만 정의되므로, 도함수도 $x > 0$에서만 의미를 가집니다.

**심화 활동:**
- $x=1$에서의 미분값 계산: $y'(1) = e^1(0 + 1) = e$
- 접선의 방정식: $x=1$일 때 $y=e \ln 1 = 0$이므로, 접선은 $y = e(x-1)$
