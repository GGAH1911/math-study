### 정확한 진술

두 수 $a$, $b$에 대하여 **최솟값함수** $\min(a, b)$는 다음과 같이 정의됩니다:

$$\min(a, b) = \begin{cases} a & \text{if } a \leq b \\ b & \text{if } a > b \end{cases}$$

더 일반적으로, $n$개의 수 $x_1, x_2, \ldots, x_n$에 대해 $\min(x_1, x_2, \ldots, x_n)$은 이들 중 가장 작은 값입니다. 두 함수 $f(x)$, $g(x)$에 대해서도 **점별(pointwise)** 최솟값함수 $\min(f(x), g(x))$를 정의할 수 있으며, 이는 각 $x$마다 $f(x)$와 $g(x)$ 중 작은 값을 함숫값으로 가집니다.

### 직관 및 기하적 의미

최솟값함수는 **두 개 이상의 값 중에서 항상 가장 작은 것을 선택**하는 연산입니다. 

두 함수 $y = f(x)$와 $y = g(x)$의 그래프를 그려놓았을 때, $y = \min(f(x), g(x))$의 그래프는 **두 곡선 중 아래에 있는 부분만 남기고 위에 있는 부분을 버린 형태**입니다. 이를 통해 최솟값함수는 실생활에서 제한 조건(제약) 문제를 모델링할 때 매우 유용합니다. 예를 들어, 버스와 택시 요금이 거리에 따라 다를 때, 각 거리에서 더 싼 교통수단을 선택하는 상황은 최솟값함수로 표현됩니다.

### 한 줄 예

$\min(3, 7) = 3$이고, $\min(-2, -5) = -5$입니다. 

함수 예: $f(x) = x^2$, $g(x) = 2x + 1$일 때, $\min(f(x), g(x))$는 $x \leq -1$ 또는 $x \geq 1$에서는 $2x + 1$의 값을, $-1 < x < 1$에서는 $x^2$의 값을 가집니다. (`min(-2**2, 2*(-2)+1)` = -3)

최솟값함수는 불연속점을 가질 수 있으므로, 선수 개념인 연속성과의 관계를 파악하는 것이 중요합니다.
