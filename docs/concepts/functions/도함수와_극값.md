### 극값의 정확한 정의

함수 $f(x)$가 $x = a$를 포함하는 어떤 열린 구간에서 정의될 때, 그 구간의 모든 $x$에 대해 $f(x) \leq f(a)$이면 $f(a)$를 **극댓값(local maximum)**, $f(x) \geq f(a)$이면 $f(a)$를 **극솟값(local minimum)**이라고 합니다. 극댓값과 극솟값을 통틀어 **극값**이라고 부릅니다.

### 도함수와 극값의 관계

극값과 도함수는 깊은 연관이 있습니다. 함수 $f(x)$가 $x = a$에서 극값을 가지면, $f'(a) = 0$이거나 $f'(a)$가 존재하지 않습니다(필요조건). 

더 실용적으로, **1차 도함수 판정법**을 사용합니다: $f'(a) = 0$일 때,
- $x < a$에서 $f'(x) > 0$, $x > a$에서 $f'(x) < 0$이면 $f(a)$는 **극댓값**
- $x < a$에서 $f'(x) < 0$, $x > a$에서 $f'(x) > 0$이면 $f(a)$는 **극솟값**

도함수의 부호가 바뀌지 않으면 극값이 아닙니다.

### 직관과 기하적 의미

그래프 관점에서 극값은 함수가 "봉우리"나 "계곡"을 이루는 지점입니다. 도함수 $f'(x)$는 그 점에서의 접선 기울기인데, 극값을 지나면서 기울기의 부호가 양에서 음으로(극대), 또는 음에서 양으로(극소) 바뀝니다.

### 한 줄 예

$f(x) = x^3 - 3x$를 생각해봅시다. $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 $f'(x) = 0$일 때 $x = -1$ 또는 $x = 1$입니다.

$x < -1$에서 $f'(x) > 0$, $-1 < x < 1$에서 $f'(x) < 0$이므로 $x = -1$에서 극댓값 $f(-1) = 2$를 가집니다.

$-1 < x < 1$에서 $f'(x) < 0$, $x > 1$에서 $f'(x) > 0$이므로 $x = 1$에서 극솟값 $f(1) = -2$를 가집니다.

`sympy.solve(3*x**2 - 3, x)` → $[-1, 1]$
