### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 **x축 교점**은 그래프가 x축과 만나는 점입니다. 즉, $f(x) = 0$을 만족하는 x값들에 해당합니다. 좌표로 표현하면 $(x_1, 0)$, $(x_2, 0)$ 등의 형태입니다.

### 직관 및 기하적 의미

그래프를 그렸을 때, x축 교점은 포물선이 수평선(x축)과 만나는 지점입니다. 이 점들이 존재하는지, 몇 개인지는 **판별식** $D = b^2 - 4ac$로 판단합니다:
- $D > 0$: x축과 두 점에서 만남 (서로 다른 두 실근)
- $D = 0$: x축과 한 점에서 접함 (중근)
- $D < 0$: x축과 만나지 않음 (실근 없음)

예를 들어, $f(x) = x^2 - 5x + 6$의 그래프는 x축과 $x = 2, 3$인 두 점에서 만나므로, x축 교점은 $(2, 0)$과 $(3, 0)$입니다.

### 구하는 방법

x축 교점을 구하려면 방정식 $ax^2 + bx + c = 0$을 풀면 됩니다. 근의 공식을 사용하면:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

위 예제에서 $x^2 - 5x + 6 = 0$을 인수분해하면 $(x-2)(x-3) = 0$이므로 $x = 2, 3$입니다. (검산: `sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)

### 한 줄 요약

x축 교점 = 이차함수가 0이 되는 x값 = 방정식 $f(x) = 0$의 해.
