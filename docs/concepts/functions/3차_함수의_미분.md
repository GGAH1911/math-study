### 정확한 진술

3차 함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)의 도함수는 거듭제곱 법칙을 적용하여 다음과 같이 구합니다.

$$f'(x) = 3ax^2 + 2bx + c$$

도함수 $f'(x)$는 2차 함수(이차함수)이며, $a$의 부호에 따라 포물선의 방향이 결정됩니다. 이 2차 도함수가 3차 함수의 극값과 증감을 완전히 결정합니다.

### 직관/기하적 의미

**순간 변화율**: 도함수 $f'(x)$ 값은 $x$에서 곡선에 그은 접선의 기울기이며, 함수가 그 점에서 얼마나 빠르게 증가 또는 감소하는지를 나타냅니다.

**극값의 판정**: $f'(x) = 0$의 판별식 $D = 4b^2 - 12ac$에 따라 3차 함수의 극값 개수가 결정됩니다.
- $D > 0$: 서로 다른 두 실근 → 극댓값과 극솟값이 각각 하나씩 존재
- $D = 0$: 중근 → 극값이 없음 (변곡점)
- $D < 0$: 실근 없음 → 극값이 없음 (계속 증가 또는 계속 감소)

**그래프의 모양**: 3차 함수 그래프는 $S$ 자 모양 또는 단조증가/단조감소 곡선이며, 도함수가 2차 함수인 것이 이러한 특성을 만듭니다.

### 한 줄 예

$f(x) = x^3 - 3x^2 + 2$일 때 $f'(x) = 3x^2 - 6x = 3x(x-2)$이므로 $x=0$과 $x=2$에서 극값을 가집니다.

```python
# sympy.diff(x**3 - 3*x**2 + 2, x) → 3x² - 6x
# sympy.solve(3*x**2 - 6*x, x) → [0, 2]
```
