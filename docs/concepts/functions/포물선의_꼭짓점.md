### 정확한 진술

이차함수 $y = a(x - p)^2 + q$ (단, $a \neq 0$)의 그래프인 포물선에서 **꼭짓점**은 점 $(p, q)$입니다. 이 점은 포물선이 방향을 바꾸는 가장 위쪽(또는 아래쪽) 위치입니다. 

표준형이 아닌 $y = ax^2 + bx + c$ 형태일 때는 꼭짓점의 $x$좌표를 $x = -\frac{b}{2a}$로 구한 뒤, 이를 함수식에 대입하여 $y$좌표를 구합니다.

### 직관 및 기하적 의미

포물선은 좌우 대칭인 곡선입니다. 꼭짓점은 **대칭축**이 포물선과 만나는 점이자, 함수의 최댓값 또는 최솟값을 가지는 위치입니다. 
- $a > 0$일 때: 꼭짓점이 최솟값(포물선이 아래로 볼록)
- $a < 0$일 때: 꼭짓점이 최댓값(포물선이 위로 볼록)

꼭짓점 $(p, q)$를 알면 포물선 전체의 모양과 위치를 즉시 파악할 수 있습니다.

### 예제

$y = 2(x - 3)^2 - 5$의 꼭짓점은 $(3, -5)$입니다.

$y = x^2 - 4x + 7$을 표준형으로 변환하면:
$$y = (x - 2)^2 + 3$$
따라서 꼭짓점은 $(2, 3)$입니다. (꼭짓점 공식: $x = -\frac{-4}{2 \cdot 1} = 2$, $y = 2^2 - 4(2) + 7 = 3$)

```python
# 검산: sympy.solve를 이용한 꼭짓점 확인
# y = x^2 - 4x + 7에서 x=2일 때 y값
y_val = 2**2 - 4*2 + 7  # = 3
```
