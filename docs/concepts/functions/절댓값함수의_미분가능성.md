### 정확한 진술

절댓값을 포함한 함수의 미분가능성은 절댓값 내부가 0이 되는 점에서 결정됩니다. 가장 기본적인 경우, $f(x) = |x|$는 $x = 0$에서 **미분불가능**합니다. 이는 좌미분계수와 우미분계수가 다르기 때문입니다:

$$\lim_{h \to 0^-} \frac{|h|}{h} = \lim_{h \to 0^-} \frac{-h}{h} = -1$$

$$\lim_{h \to 0^+} \frac{|h|}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1$$

일반적으로, 함수 $g(x)$에 대해 $f(x) = |g(x)|$가 $x = a$에서 미분가능하려면:
- $g(a) \neq 0$인 점에서는 항상 미분가능
- $g(a) = 0$인 점에서는 $g(x)$가 $x = a$에서 부호를 바꾸지 않을 때만 미분가능

### 직관과 기하적 의미

절댓값 함수는 음수 부분을 $x$축에 대해 대칭시킵니다. $f(x) = |x|$의 그래프를 보면 $x = 0$에서 **꺾이는 점(첨점)**이 생깁니다. 이 점에서 좌측과 우측의 기울기가 다르므로, 한 점에서의 순간변화율(도함수)이 존재하지 않습니다.

대조적으로 $f(x) = |x^2 - 1|$의 경우, $x = \pm 1$에서 $x^2 - 1 = 0$이지만, 이 점들 근처에서 $x^2 - 1$이 음수에서 양수로 바뀝니다. 따라서 $x = \pm 1$에서 미분불가능합니다.

### 예제

$f(x) = |2x - 3|$을 생각해봅시다. 이 함수는 $2x - 3 = 0$, 즉 $x = \frac{3}{2}$에서 절댓값 내부가 0이 됩니다.

- $x < \frac{3}{2}$일 때: $f(x) = -(2x - 3) = -2x + 3$이므로 $f'(x) = -2$
- $x > \frac{3}{2}$일 때: $f(x) = 2x - 3$이므로 $f'(x) = 2$

좌미분계수 $-2$와 우미분계수 $2$가 다르므로 $x = \frac{3}{2}$에서 **미분불가능**합니다.

(검증: `from sympy import *; x = symbols('x'); f = Abs(2*x - 3); diff(f, x)` → $x \neq \frac{3}{2}$에서만 미분가능)
