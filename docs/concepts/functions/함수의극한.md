### 정확한 진술

함수 $f(x)$에서 $x$가 어떤 값 $a$에 가까워질 때, $f(x)$가 일정한 값 $L$에 가까워지는 현상을 나타냅니다. 이를 "$x \to a$일 때 $f(x)$의 극한값은 $L$이다"라고 하고, 다음과 같이 기호로 나타냅니다:

$$\lim_{x \to a} f(x) = L$$

**엄밀한 정의(ε-δ 정의)**: 임의의 양수 $\varepsilon$에 대하여, 어떤 양수 $\delta$가 존재하여
$$0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon$$
이면 극한값이 $L$이라고 정의합니다.

### 직관/기하적 의미

극한의 핵심은 **$x = a$일 때의 함숫값 $f(a)$와 무관하게**, $x$가 $a$에 충분히 가까워질 때 $f(x)$가 어떤 값에 수렴하는지를 본다는 것입니다.

예를 들어, $f(x) = \frac{x^2 - 1}{x - 1}$에서 $x = 1$일 때는 정의되지 않지만, $x$를 1에 가깝게 한다면 $f(x)$는 2에 가까워집니다. 그래프로 보면, $x = 1$ 근처에서 점 $(1, 2)$로 향하는 모양입니다. 이것이 바로 $\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = 2$입니다.

**중요**: 극한값의 존재는 함숫값과 무관합니다. $x = a$에서 함수가 정의되지 않거나, 정의되더라도 극한값과 다를 수 있습니다.

### 한 줄 예

$\lim_{x \to 2} (3x + 1) = 7$ — $x$를 2에 가깝게 할수록 $3x + 1$은 7에 가까워집니다.

**검증**: `sympy.limit(3*x + 1, x, 2)` → 7
