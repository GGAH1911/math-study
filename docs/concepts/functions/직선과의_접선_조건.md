### 정확한 진술

곡선(주로 이차함수)과 직선이 정확히 한 점에서만 만날 조건을 '직선과의 접선 조건'이라고 합니다. 이차함수 $y = ax^2 + bx + c$와 직선 $y = mx + n$이 접할 필요충분조건은, 두 식을 연립하여 얻은 이차방정식이 **중근을 가지는 것**입니다.

즉, $ax^2 + bx + c = mx + n$을 정리한 $ax^2 + (b-m)x + (c-n) = 0$의 판별식이 0이 되어야 합니다:

$$\Delta = (b-m)^2 - 4a(c-n) = 0$$

### 직관/기하적 의미

직선과 곡선의 교점 개수는 판별식의 부호로 결정됩니다. 판별식이 양수면 교점이 2개(두 번 만남), 0이면 1개(접함), 음수면 0개(만나지 않음)입니다. 직선이 곡선에 **접한다**는 것은 그 점에서 직선이 곡선의 접선과 일치한다는 기하학적 의미를 갖습니다. 접점 부근에서 곡선과 직선이 같은 방향으로 향합니다.

### 한 줄 예

이차함수 $y = x^2$과 직선 $y = 2x + k$가 접할 때 $k$를 구하면, $x^2 = 2x + k$에서 $x^2 - 2x - k = 0$의 판별식 $4 + 4k = 0$이므로 $k = -1$입니다. 검산: `sympy.solve(x**2 - 2*x + 1, x)` → $x = 1$ (중근)으로, 접점은 $(1, 1)$입니다.
