# 증감 구간

> **예제** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
$f'(x)$ 부호로 판정

## 본문 (학습 시 채워짐)

### 문제

함수 $f(x) = x^3 - 3x^2 + 2$의 증가 구간과 감소 구간을 구하시오.

### 단계별 풀이

**1단계: 도함수 구하기**

$f'(x) = 3x^2 - 6x = 3x(x - 2)$

**2단계: 도함수가 0이 되는 점 찾기**

$f'(x) = 0$일 때: $3x(x - 2) = 0$ ⟹ $x = 0$ 또는 $x = 2$

이 점들을 **임계점**이라고 합니다.

**3단계: 각 구간에서 도함수의 부호 판정**

임계점으로 수직선을 나누면 세 구간이 생깁니다.

| 구간 | $x < 0$ | $0 < x < 2$ | $x > 2$ |
|------|---------|-----------|---------|
| $f'(x)$의 부호 | $+$ | $-$ | $+$ |
| 함수의 증감 | ↗ (증가) | ↘ (감소) | ↗ (증가) |

**4단계: 부호 판정 방법** (각 구간에서 대푯값 대입)
- $x = -1$일 때: $f'(-1) = 3(1)(−3) = -9$ ⟹ 음수 (실제로는 양수, 재계산)

다시: $f'(-1) = 3(-1)(-1-2) = 3(-1)(-3) = 9 > 0$ ✓

- $x = 1$일 때: $f'(1) = 3(1)(1-2) = 3(-1) = -3 < 0$ ✓
- $x = 3$일 때: $f'(3) = 3(3)(3-2) = 9 > 0$ ✓

### 답

**증가 구간:** $(-\infty, 0]$, $[2, \infty)$

**감소 구간:** $[0, 2]$

### 변형/주의

**⚠️ 자주 하는 실수:**
- 구간 끝점(임계점)을 포함할지 말지 헷갈림: 수능에서는 보통 닫힌 구간 표기 $[a, b]$ 사용
- $f'(x) = 0$인 점을 빠뜨리면 구간을 잘못 나눔
- 양/음 판정할 때 각 인수의 부호를 개별적으로 확인하면 실수 줄임: $3x(x-2)$에서 $3 > 0$, $x$의 부호, $(x-2)$의 부호를 따로 봄

**검산 (sympy):**
```python
from sympy import *
x = symbols('x')
f = x**3 - 3*x**2 + 2
f_prime = diff(f, x)
solve(f_prime, x)  # [0, 2]
```
