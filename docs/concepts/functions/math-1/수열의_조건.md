### 정확한 진술

수열 $\{a_n\}$은 다음 중 하나로 완전히 결정됩니다:
- **초기항 + 점화식**: 첫째항 (또는 처음 몇 항)과 인접한 항들의 관계식 $a_{n+1} = f(a_n)$
- **일반항 공식**: $a_n = f(n)$ 형태의 명시적 식

이 둘 중 하나가 주어지면, 모든 항을 유일하게 결정할 수 있습니다.

### 직관/기하적 의미

수열은 자연수 위치에 배치된 수들의 나열입니다. 수열을 "완전히 정의"하려면 모든 항의 값을 알아야 하는데, 무한 개를 일일이 나열할 수 없으므로 **법칙 또는 규칙**을 제시해야 합니다.

- **점화식**: "다음 항은 이전 항에 이 규칙을 적용하면 얻어진다"는 뜻. 초기값에서 시작하면 차근차근 모든 항을 계산할 수 있습니다.
- **일반항 공식**: "위치 $n$이 주어지면, $n$번째 항은 이 식으로 계산된다"는 뜻. 직접 계산하므로 더 빠릅니다.

### 한 줄 예

등차수열 $a_n = 2n - 1$ (조건: 초항 1, 공차 2) 또는 $a_1 = 1, a_{n+1} = a_n + 2$ (조건: 초기값 + 점화식)은 모두 같은 수열 $1, 3, 5, 7, \ldots$를 결정합니다.

### 예제: 조건의 충분성 확인

정수수열 $\{a_n\}$이 $a_1 = 3$, $a_{n+1} = 2a_n + 1$ ($n \geq 1$)을 만족하면, $a_2 = 2(3) + 1 = 7$, $a_3 = 2(7) + 1 = 15$, $\ldots$로 모든 항이 유일하게 결정됩니다. ([sympy](https://docs.sympy.org): 일반항을 구하려면 `sympy.solve(a_n - (2*a_{n-1} + 1), a_n)`의 형태로 점화식을 풀 수 있음)

이러한 **결정 조건**은 수열 문제에서 주어진 정보가 충분한지 판단하는 기준이 됩니다.
