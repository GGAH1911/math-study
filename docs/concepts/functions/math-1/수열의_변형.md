### 정확한 진술

주어진 수열 $\{a_n\}$과 $\{b_n\}$에 대해, 이들을 이용해 새로운 수열을 만드는 모든 과정을 **수열의 변형**이라 합니다. 예를 들어, 각 항에 상수를 곱하기($c \cdot a_n$), 두 수열을 더하기($a_n + b_n$), 차이를 구하기($a_n - a_{n-1}$), 일반항을 대수적으로 조작하기 등이 모두 변형에 해당합니다. 변형된 수열 $\{c_n\}$의 일반항은 원래 수열들의 일반항으로 명확히 표현되어야 합니다.

### 직관과 의미

수열의 변형은 주어진 정보로부터 새로운 성질을 끌어내는 핵심 도구입니다. 예를 들어, 공차를 모르는 등차수열 $\{a_n\}$이 있을 때, 인접한 두 항의 차 $\{a_{n+1} - a_n\}$을 계산하면 공차를 상수 수열로 만들 수 있습니다. 또는 복잡한 수열의 합을 구할 때, 원래 수열을 더 간단한 두 수열의 합으로 분해(부분분수 분해 같은)하여 계산합니다. 변형은 문제 풀이의 모든 단계에서 필수적입니다.

### 계산 예

$a_n = 2n + 1$, $b_n = 3n$일 때, 세 가지 변형을 시도해봅시다.
- 덧셈: $c_n = a_n + b_n = (2n+1) + 3n = 5n + 1$
- 상수배: $d_n = 2a_n = 2(2n+1) = 4n + 2$  
- 차분: $e_n = a_n - a_{n-1} = (2n+1) - (2(n-1)+1) = 2$

(`sympy.sympify("5*n + 1").subs(n, 5)` → 26)

마지막 변형은 원래 등차수열의 공차 2를 상수 수열로 추출한 것입니다. 이렇게 변형하면 수열의 숨은 구조가 드러납니다.
