### 정확한 진술

기본 삼각항등식(fundamental trigonometric identity)은 삼각함수들 사이에서 항상 성립하는 대수적 관계식입니다. 가장 중요한 것은 **피타고라스 항등식**입니다.

$$\sin^2\theta + \cos^2\theta = 1$$

이를 양변을 특정 제곱항으로 나누면 다음과 같은 형태도 얻을 수 있습니다.

$$1 + \tan^2\theta = \sec^2\theta$$
$$1 + \cot^2\theta = \csc^2\theta$$

이들 관계식은 $\theta$의 어떤 값에 대해서도 항상 참입니다.

### 직관 및 기하적 의미

단위원(반지름 1인 원) 위의 임의의 점을 $(\cos\theta, \sin\theta)$로 나타낼 수 있습니다. 이 점은 정의상 항상 원점으로부터 거리가 1이므로, 거리 공식을 적용하면:

$$\sqrt{\cos^2\theta + \sin^2\theta} = 1$$

양변을 제곱하면 바로 $\sin^2\theta + \cos^2\theta = 1$이 나옵니다. 따라서 기본 삼각항등식은 **단위원의 기하학적 정의에서 직접 비롯된** 사실입니다. 다른 모든 삼각항등식도 이것을 변형하여 유도됩니다.

### 한 줄 예

$\theta = \frac{\pi}{6}$일 때, $\sin\frac{\pi}{6} = \frac{1}{2}$, $\cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$이므로:

$$\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1$$

(`sympy.simplify(Rational(1,2)**2 + (sqrt(3)/2)**2)`)
