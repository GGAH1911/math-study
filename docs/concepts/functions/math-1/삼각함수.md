# 삼각함수

> **단원** · 수학1 · 선수: [삼각비](/concepts/삼각비) / [함수와 그래프](/concepts/함수와_그래프) · 다음: 없음

## 학습 목표
- 호도법으로 각을 표현하고 단위원에서 정의된 삼각함수를 이해한다
- 삼각함수의 그래프·주기·대칭을 다룬다
- 삼각함수의 덧셈정리·합성 등을 활용한다

## 다룰 정의 / 정리 / 예제

**정의**
- [호도법](/concepts/호도법) — (라디안)
- 단위원에서의 $\sin, \cos, \tan$
- 주기, 진폭, 위상

**정리**
- $\sin^2\theta+\cos^2\theta=1$
- 주기 $\sin, \cos$은 $2\pi$, $\tan$은 $\pi$
- 사인·코사인 법칙

**예제**
- [삼각함수 그래프 그리기](/concepts/삼각함수_그래프_그리기)
- 주기·진폭·위상 변형
- [삼각방정식 풀이](/concepts/삼각방정식_풀이)

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
