# 지수함수와 로그함수

> **단원** · 수학1 · 선수: [지수와 로그](/concepts/지수와_로그) / [함수와 그래프](/concepts/함수와_그래프) · 다음: 없음

## 학습 목표
- 지수함수와 로그함수의 그래프·성질을 이해한다
- 지수·로그 방정식과 부등식을 푼다

## 다룰 정의 / 정리 / 예제

**정의**
- [지수함수](/concepts/지수함수) — $y=a^x$ ($a>0, a\neq 1$)
- [로그함수](/concepts/로그함수) — $y=\log_a x$

**정리**
- 지수함수와 로그함수는 서로 역함수 (=$y=x$ 대칭)
- 단조증가/감소의 부호 조건

**예제**
- 지수·로그 방정식 풀이
- 지수·로그 부등식
- 실생활 응용 (반감기·복리)
