### 정확한 진술

조건식 정리는 두 각의 합 또는 차의 삼각함수값을 각각의 삼각함수값으로 나타내는 항등식입니다. 특히 덧셈정리라고도 부르며, 다음이 성립합니다.

$$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$
$$\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$$
$$\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$$
$$\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$$
$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}, \quad \tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$

### 직관과 기하적 의미

복잡한 각도를 두 개의 알려진 각으로 분해하면, 이미 알고 있는 특수각($30°, 45°, 60°$ 등)의 삼각함수값만으로 새로운 각의 값을 구할 수 있습니다. 예를 들어 $\sin 75°$를 직접 계산하기는 어렵지만, $75° = 45° + 30°$로 나누면 구할 수 있습니다.

좌표평면에서 단위원 위의 두 점을 더할 때, 각각의 $x$좌표(코사인)와 $y$좌표(사인)가 어떻게 합성되는지를 정확하게 나타냅니다. 이는 복소수의 극형식 곱셈에서 각도가 덧셈되는 원리와도 같습니다.

### 한 줄 예

$\sin 75° = \sin(45° + 30°) = \sin 45° \cos 30° + \cos 45° \sin 30° = \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2} = \frac{\sqrt{6}+\sqrt{2}}{4}$
