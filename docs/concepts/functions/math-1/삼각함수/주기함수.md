# 주기함수

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
함수 $f(x)$가 일정한 간격 $p$마다 함숫값이 반복되는 성질을 가질 때 이를 주기함수라고 합니다.

## 본문
함수 $f(x)$가 정의역의 모든 $x$에 대하여 $f(x+p) = f(x)$를 만족하는 양수 $p$가 존재할 때, 이 함수를 **주기함수**라고 부릅니다. 이때 $p$를 주기(period)라고 합니다. 주기함수가 가지는 주기 중에서 가장 작은 양수를 **기본주기**(또는 최소주기)라고 하며, 보통 $T$로 나타냅니다.

### 직관과 기하적 의미
주기함수는 일정한 간격으로 함숫값이 반복되는 함수입니다. 그래프로 보면 $x$축 방향으로 주기 $p$만큼 이동해도 모양이 정확히 같습니다. 마치 벽지의 무늬가 일정하게 반복되거나, 시계 바늘이 12시간마다 같은 위치로 돌아오는 것처럼, 주기함수도 특정 길이 구간의 패턴이 양쪽으로 무한히 반복됩니다. 따라서 주기함수를 완전히 파악하려면 기본주기 구간 내의 함숫값만 알면 됩니다.

### 기본 성질
삼각함수 $\sin x$와 $\cos x$는 기본주기 $T = 2\pi$인 주기함수입니다. 즉, 모든 $x$에 대해 $\sin(x + 2\pi) = \sin x$, $\cos(x + 2\pi) = \cos x$를 만족합니다. 또한 $\tan x$는 기본주기 $T = \pi$인 주기함수입니다. 보다 간단한 예로, 상수함수 $f(x) = 3$은 모든 양수 $p$에 대해 $f(x+p) = f(x) = 3$이므로 주기함수이지만, 기본주기가 존재하지 않습니다. 반면 $f(x) = \sin(2x)$는 기본주기 $T = \pi$를 갖습니다. 함수가 주기함수인지 판정할 때는 정의역 내의 모든 $x$에 대해 주기 조건이 성립해야 함에 주의해야 합니다. 예를 들어 $f(x) = x + \sin x$는 $f(x + 2\pi) = x + 2\pi + \sin x \ne f(x)$이므로 주기함수가 아닙니다.

## 학습 체크
- 함수 $f(x)$가 주기함수일 때, $f(x+p)=f(x)$를 만족하는 $p$가 반드시 유일한가?
- 상수함수가 주기함수의 정의를 만족함에도 불구하고 기본주기를 갖지 않는 이유는 무엇인가?
- 함수 $f(x) = \sin(2x)$의 기본주기를 구하는 과정은 어떻게 되는가?

## 관련 개념
- **함수와 그래프**: 주기함수의 그래프는 특정 구간의 모양이 일정 간격으로 반복되는 기하학적 특징을 보입니다.
