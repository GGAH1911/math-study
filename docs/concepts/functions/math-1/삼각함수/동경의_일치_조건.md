# 동경의 일치 조건

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
두 각의 동경이 일치하려면 한 각에 $360^{\circ}$ 또는 $2\pi$의 정수 배를 더하거나 뺀 값이 다른 각과 같아야 합니다.

## 본문
두 각 $\alpha$와 $\beta$의 동경이 일치할 필요충분조건은 다음과 같습니다.
$$\beta = \alpha + 360^{\circ} \cdot k \quad \text{(단, } k \text{는 정수)}$$
또는 라디안 단위로는 다음과 같습니다.
$$\beta = \alpha + 2\pi k \quad \text{(단, } k \text{는 정수)}$$

### 직관과 기하적 의미
좌표평면의 원점에서 각을 그릴 때, 동경은 시작선인 양의 $x$축으로부터 회전한 반직선을 의미합니다. 두 각의 동경이 일치한다는 것은 회전한 각도는 서로 다를지라도 최종적으로 가리키는 방향이 같다는 것을 뜻합니다. 예를 들어 시계 바늘이 12시를 가리킬 때, 한 바퀴($360^{\circ}$)를 돌거나 두 바퀴($720^{\circ}$)를 돌거나, 혹은 시계 방향으로 한 바퀴($-360^{\circ}$)를 돌아도 결국 다시 12시 방향을 가리키게 되는 것과 같은 원리입니다. 즉, 처음 각 $\alpha$에서 몇 바퀴를 더 돌거나 덜 도는지($360^{\circ} \times k$)에 관계없이 최종 위치가 같으면 동경이 일치한다고 합니다.

### 기본 성질
- $30^{\circ}$와 $390^{\circ}$는 $390^{\circ} = 30^{\circ} + 360^{\circ} \times 1$이므로 동경이 일치합니다.
- $\frac{\pi}{4}$와 $\frac{\pi}{4} + 2\pi$는 라디안 단위에서 동경이 일치하는 예시입니다.
- 동경이 일치하는 두 각은 삼각함수값이 항상 같습니다.

## 학습 체크
- $k$가 음수인 경우(시계 방향 회전)에도 동경의 일치 조건이 성립하는가?
- $30^{\circ}$와 $-330^{\circ}$의 동경은 일치하는가?
- 라디안 단위에서 $\frac{\pi}{3}$와 $\frac{7\pi}{3}$의 동경은 일치하는가?

## 관련 개념
- **삼각함수**: 동경이 일치하는 두 각은 사인, 코사인, 탄젠트 등 모든 삼각함수값이 동일하므로 함수의 주기성을 이해하는 기초가 됩니다.
