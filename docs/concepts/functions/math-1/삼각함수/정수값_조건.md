# 정수값 조건

## 정확한 진술

삼각함수의 함숫값이 정수가 되는 각도나 조건을 찾는 것입니다. 특히 치역이 $[-1, 1]$로 제한된 $\sin\theta$와 $\cos\theta$의 경우, 정수값은 매우 제한적입니다.

**$\sin\theta$, $\cos\theta$의 정수값 조건:**
- $\sin\theta = n$ (정수)이려면 $n \in \{-1, 0, 1\}$이어야 합니다.
- $\cos\theta = m$ (정수)이려면 $m \in \{-1, 0, 1\}$이어야 합니다.

**$\tan\theta$의 정수값 조건:**
- $\tan\theta = k$ (정수)인 경우, $\theta = \arctan(k) + n\pi$ (단, $n$은 정수)로 표현됩니다.

## 직관/기하적 의미

단위원 위의 점 $(\cos\theta, \sin\theta)$에서 **두 좌표가 동시에 정수**가 되는 경우를 생각하면, 단위원과 격자점의 교점을 찾는 것과 같습니다. 반지름 1인 단위원 위에서 좌표가 모두 정수인 점은 $(1, 0)$, $(-1, 0)$, $(0, 1)$, $(0, -1)$ 단 **4개뿐**입니다.

따라서 하나의 삼각함수만 정수값을 갖는 조건은 비교적 흔하지만, 여러 개가 동시에 정수값을 가져야 한다면 선택지가 극히 제한됩니다.

## 한 줄 예

$\sin\theta = 1$이 되려면 $\theta = \dfrac{\pi}{2} + 2n\pi$ (단, $n$은 정수)이고, 이때 $\cos\theta = 0$입니다.

**혼합 조건 예시:**  
$\sin\theta + \cos\theta = 1$을 풀 때는 양변을 제곱하여 $1 + 2\sin\theta\cos\theta = 1$에서 $\sin\theta\cos\theta = 0$을 얻으므로, 한 함수는 0이고 다른 하나는 1입니다. 해는 $\theta = 0, \dfrac{\pi}{2} + 2n\pi$입니다.

```python
# 검산 예시
import sympy as sp
theta = sp.symbols('theta', real=True)
# sin(0) + cos(0) = 1, sin(π/2) + cos(π/2) = 1 확인
print(sp.sin(0) + sp.cos(0), sp.sin(sp.pi/2) + sp.cos(sp.pi/2))
```
