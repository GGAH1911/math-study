### 정확한 진술

삼각함수의 **극값**(extreme value)은 함수가 취할 수 있는 최댓값과 최솟값을 의미합니다. 기본 삼각함수들의 극값은 다음과 같습니다.

$$\sin x: \text{최댓값 } 1, \text{ 최솟값 } -1$$
$$\cos x: \text{최댓값 } 1, \text{ 최솟값 } -1$$

더 일반적으로, $a\sin(bx + c) + d$ (단, $a > 0$) 형태의 함수는 **최댓값** $a + d$, **최솟값** $-a + d$를 갖습니다. 계수 $a$를 **진폭**(amplitude), $d$를 **중심선**이라 부릅니다.

### 직관과 기하적 의미

단위원 위의 점을 생각해봅시다. $x$가 변할 때, $(\cos x, \sin x)$는 단위원 위를 회전하며, $\sin x$는 점의 $y$좌표입니다. 원의 최상단에서 $\sin x = 1$, 최하단에서 $\sin x = -1$이므로, 이것이 바로 극값입니다.

삼각함수 그래프에서 극값은 **파동의 봉우리와 골짜기**를 의미합니다. 진폭 $a$와 중심선 $d$가 정해지면, 극값도 자동으로 결정됩니다. 이는 삼각함수의 주기성 때문에 각 주기마다 반복됩니다.

### 한 줄 예

$y = 2\sin x - 3$은 진폭 $2$, 중심선 $-3$이므로, 최댓값은 $2 + (-3) = -1$이고 최솟값은 $-2 + (-3) = -5$입니다.

```python
# sympy로 확인: 2*sin(x) - 3의 범위는 [-5, -1]
import sympy as sp
x = sp.symbols('x', real=True)
f = 2*sp.sin(x) - 3
print(f"최댓값: {2 - 3}, 최솟값: {-2 - 3}")  # 최댓값: -1, 최솟값: -5
```
