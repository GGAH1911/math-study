# 삼각형의 변과 각의 관계

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각형의 세 변의 길이와 그에 대응하는 각 사이의 관계를 사인 법칙과 코사인 법칙을 통해 설명합니다.

## 본문
삼각형의 세 변의 길이를 $a, b, c$, 그에 마주보는 각을 각각 $A, B, C$라 할 때, 다음 두 법칙이 성립합니다.

**사인 법칙(sine rule):**
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$
여기서 $R$은 삼각형의 외접원의 반지름입니다.

**코사인 법칙(cosine law):**
$$a^2 = b^2 + c^2 - 2bc \cos A$$
$$b^2 = a^2 + c^2 - 2ac \cos B$$
$$c^2 = a^2 + b^2 - 2ab \cos C$$

### 직관과 기하적 의미
사인 법칙은 변의 길이와 대각의 정현의 비가 일정하다는 의미를 담고 있습니다. 같은 호에 내접하는 원주각에 대해 사인 값이 일정하므로, 외접원의 크기가 커질수록 같은 각에 대응하는 변의 길이도 함께 커지게 됩니다.

코사인 법칙은 직각삼각형에서의 피타고라스 정리를 일반화한 형태입니다. 만약 각 $A$가 직각이라면 $\cos A = 0$이 되어 $a^2 = b^2 + c^2$이라는 피타고라스 정리가 성립하며, 각이 예각이나 둔각일 경우에는 $-2bc \cos A$라는 보정항이 추가되어 변의 길이를 결정합니다.

### 기본 성질
- 사인 법칙은 삼각형의 외접원의 반지름 $R$을 알 때 유용하며, 한 변과 그 대각, 그리고 다른 변과 그 대각의 관계를 구할 때 사용합니다.
- 코사인 법칙은 두 변의 길이와 그 사이의 끼인각을 알 때 나머지 한 변의 길이를 구하거나, 세 변의 길이를 알 때 각의 크기를 구할 때 유용합니다.

## 학습 체크
- 사인 법칙을 사용하여 외접원의 반지름 $R$을 구할 수 있는가?
- 코사인 법칙을 피타고라스 정리의 관점에서 이해하고 있는가?
- 주어진 변의 길이와 각의 정보를 바탕으로 적절한 법칙을 선택할 수 있는가?

## 관련 개념
- **삼각비**: 삼각형의 변과 각 사이의 관계를 나타내는 기초적인 도구로, 코사인 법칙에서 각의 코사인 값을 결정하는 데 사용됩니다.
