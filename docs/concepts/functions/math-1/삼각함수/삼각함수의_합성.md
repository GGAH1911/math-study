# 삼각함수의 합성

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
두 개의 서로 다른 삼각함수 항을 하나의 삼각함수로 통합하여 진폭과 위상을 한눈에 파악할 수 있도록 변환하는 기술입니다.

## 본문
$a\sin\theta + b\cos\theta$ (단, $a, b$는 상수) 형태의 삼각함수의 합을 하나의 삼각함수로 나타내는 것을 삼각함수의 합성이라고 합니다. 적절한 각 $\alpha$와 양수 $R$을 사용하여 $a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$ 또는 $a\sin\theta + b\cos\theta = R\cos(\theta - \beta)$의 형태로 변환할 수 있습니다. 이때 새로운 진폭 $R$은 $\sqrt{a^2 + b^2}$로 결정되며, 각 $\alpha$와 $\beta$는 상수 $a$와 $b$의 크기 및 부호에 따라 결정됩니다.

### 직관과 기하적 의미
삼각함수의 덧셈공식을 역으로 활용하여 두 개의 서로 다른 삼각함수 항을 하나로 통합하는 과정입니다. 기하학적으로는 서로 다른 위상을 가진 두 개의 진동(사인파와 코사인파)을 합쳤을 때, 진폭이 $\sqrt{a^2 + b^2}$로 커지면서 위상이 이동된 단일 진동파로 표현된다는 것을 의미합니다.

### 기본 성질
- 합성된 함수의 진폭 $R$은 항상 $\sqrt{a^2 + b^2}$이다.
- $a$와 $b$의 부호에 따라 합성된 함수의 위상 $\alpha$가 결정된다.
- 삼각함수의 덧셈정리를 역으로 이용하여 유도된다.

## 학습 체크
- 합성된 함수의 진폭 $R$을 구할 때 $a$와 $b$의 제곱의 합에 루트를 씌우는 원리를 이해하고 있는가?
- $a$와 $b$의 부호에 따라 $\alpha$의 사분면 위치가 어떻게 달라지는지 파악했는가?

## 관련 개념
- **삼각함수**: 삼각함수의 합성은 삼각함수의 덧셈정리를 기초로 하며, 삼각함수의 그래프를 해석하는 데 필수적인 도구입니다.
