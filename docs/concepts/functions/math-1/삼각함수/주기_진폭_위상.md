# 주기 진폭 위상

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각함수 그래프의 형태와 위치를 결정하는 세 가지 핵심 매개변수입니다.

## 본문
일반적인 삼각함수 $y = A\sin(Bx + C) + D$ (또는 코사인)에서 그래프의 특징을 결정하는 요소는 진폭, 주기, 위상입니다. **진폭(Amplitude)**은 $|A|$로 정의하며, 함수의 최댓값과 최솟값의 중간인 중심선으로부터 떨어진 거리를 의미합니다. **주기(Period)**는 $\frac{2\pi}{|B|}$로 정의하며, 함수가 동일한 값을 반복하기 시작할 때까지의 $x$축 방향의 길이를 나타냅니다. **위상(Phase)**은 $-\frac{C}{B}$로 정의하며, 그래프가 기본 형태에서 수평 방향으로 이동한 거리를 의미합니다.

### 직관과 기하적 의미
삼각함수의 그래프는 파동의 형태를 띠는데, 세 매개변수는 이 파동의 모양을 결정합니다. 진폭은 파도의 높낮이를 조절하여, 값이 커질수록 파도가 위아래로 더 크게 움직입니다. 주기는 파도 하나가 완성되는 거리를 결정하며, $B$의 절댓값이 커질수록 주기는 짧아져 그래프가 더 촘촘하게 나타납니다. 위상은 그래프 전체를 좌우로 평행이동시킵니다. 예를 들어 $y = \sin(x - \frac{\pi}{3})$는 그래프를 오른쪽으로 $\frac{\pi}{3}$만큼 이동시키고, $y = \sin(x + \frac{\pi}{6})$는 왼쪽으로 $\frac{\pi}{6}$만큼 이동시킵니다.

### 기본 성질
함수 $y = 3\sin(2x - \frac{\pi}{3}) + 1$을 예로 들면, 진폭은 3이고 주기는 $\pi$이며, 위상은 $\frac{\pi}{6}$만큼 오른쪽으로 이동한 상태입니다. 이때 $D=1$은 그래프의 중심선 높이를 결정합니다.

## 학습 체크
- $A$와 $B$의 절댓값이 변할 때 그래프의 높낮이와 반복되는 간격이 어떻게 변하는지 설명할 수 있는가?
- 식에 포함된 $C$의 부호에 따라 그래프가 어느 방향으로 이동하는지 구분할 수 있는가?
- 주어진 삼각함수 식에서 진폭, 주기, 위상, 중심선을 모두 찾아낼 수 있는가?

## 관련 개념
- **삼각함수**: 주기, 진폭, 위상이라는 매개변수를 통해 그래프의 모양과 위치를 수학적으로 표현하는 대상입니다.
