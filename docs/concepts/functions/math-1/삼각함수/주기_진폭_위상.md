# 주기 진폭 위상

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각함수 그래프의 매개변수

## 본문 (학습 시 채워짐)

### 정확한 진술

일반적인 삼각함수 $y = A\sin(Bx + C) + D$ (또는 코사인)에서:

- **진폭(Amplitude)**: $|A|$ — 최댓값과 중심선 사이의 거리
- **주기(Period)**: $\frac{2\pi}{|B|}$ — 함수값이 한 번 반복되는 $x$의 길이
- **위상(Phase)**: $-\frac{C}{B}$ — 그래프가 기본 형태에서 수평으로 이동한 거리

### 직관과 기하적 의미

삼각함수의 그래프는 파도 모양인데, 세 매개변수가 파도의 형태를 결정합니다. 

**진폭**은 파도의 높낮이를 조절합니다. $y = \sin x$의 진폭이 1이면, $y = 2\sin x$의 진폭은 2로, 파도가 위아래로 더 크게 움직입니다.

**주기**는 파도 하나가 완성되는 "거리"입니다. 기본 사인함수 $\sin x$의 주기가 $2\pi$라면, $\sin(2x)$는 주기가 $\pi$로 반으로 줄어들어 더 촘촘해집니다.

**위상**은 그래프 전체가 좌우로 평행이동한 정도입니다. 예를 들어 $y = \sin(x - \frac{\pi}{3})$는 기본 사인파를 오른쪽으로 $\frac{\pi}{3}$만큼 미는 것이고, $y = \sin(x + \frac{\pi}{6})$는 왼쪽으로 $\frac{\pi}{6}$만큼 미는 것입니다. 음수 위상은 오른쪽 이동, 양수 위상은 왼쪽 이동을 의미합니다.

### 한 줄 예

$y = 3\sin(2x - \frac{\pi}{3}) + 1$에서 진폭은 3, 주기는 $\pi$, 위상은 $\frac{\pi}{6}$(오른쪽으로 $\frac{\pi}{6}$이동), 중심선의 높이는 1입니다.

**검증**: `sympy.pi/2; 2*sympy.pi / 2` → 주기 $\pi$ ✓
