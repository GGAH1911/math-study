# 탄젠트 함수의 그래프

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
탄젠트 함수는 $\tan x = \frac{\sin x}{\cos x}$로 정의되며, 주기 $\pi$를 가지며 원점 대칭인 기함수로서 수직 점근선을 갖는 그래프를 그립니다.

## 본문
탄젠트 함수는 $\tan x = \frac{\sin x}{\cos x}$로 정의되는 삼각함수입니다. $\cos x \neq 0$인 모든 실수 $x$에서 정의되므로, 정의역은 $x \neq \frac{\pi}{2} + n\pi$ ($n$은 정수)인 모든 실수입니다. $\cos x = 0$이 되는 지점에서는 함수가 정의되지 않으며, 이 지점들은 그래프에서 수직 점근선이 됩니다.

### 직관과 기하적 의미
단위원 위의 각 $x$에 대한 점 $(\cos x, \sin x)$에서, 해당 점을 지나 $x$축에 수직인 직선이 $x = 1$인 수직선과 만나는 점의 $y$좌표가 바로 $\tan x$입니다. 이는 직각삼각형에서 대변의 길이를 인접변의 길이로 나눈 값과 기하학적으로 일치합니다. 그래프를 그릴 때는 수직 점근선 $x = \pm\frac{\pi}{2}, \pm\frac{3\pi}{2}, \ldots$를 먼저 표시한 후, 각 구간에서 원점을 지나며 $-\infty$에서 $+\infty$로 증가하는 부드러운 곡선을 그립니다.

### 기본 성질
탄젠트 함수는 $\tan(-x) = -\tan x$를 만족하는 기함수이므로 그래프는 원점에 대하여 대칭입니다. 또한 $\tan(x + \pi) = \tan x$를 만족하여 주기 $\pi$를 갖는 주기함수입니다. 주요 함숫값으로는 $\tan 0 = 0$, $\tan \frac{\pi}{6} = \frac{\sqrt{3}}{3}$, $\tan \frac{\pi}{4} = 1$, $\tan \frac{\pi}{3} = \sqrt{3}$이 있습니다.

## 학습 체크
- 탄젠트 함수의 정의역에서 함숫값이 정의되지 않는 지점의 특징은 무엇인가?
- 탄젠트 함수의 주기가 $\pi$인 이유와 그래프의 대칭성을 설명할 수 있는가?
- $\tan x = 1$을 만족하는 $x$의 값을 구간 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ 내에서 찾을 수 있는가?

## 관련 개념
- **삼각함수**: 탄젠트 함수는 사인 함수와 코사인 함수의 비율로 정의되는 삼각함수의 일종입니다.
- **점근선**: 탄젠트 함수는 $\cos x = 0$인 지점에서 함숫값이 정의되지 않으며, 그래프가 이 직선에 무한히 가까워지는 수직 점근선을 가집니다.
