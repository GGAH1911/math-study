### 탄젠트 함수의 정의

탄젠트 함수는 $\tan x = \frac{\sin x}{\cos x}$로 정의되는 삼각함수입니다. $\cos x \neq 0$인 모든 실수 $x$에서 정의되므로, 정의역은 $x \neq \frac{\pi}{2} + n\pi$ (단, $n \in \mathbb{Z}$)입니다. 이 점들에서 함수는 정의되지 않습니다.

### 그래프의 기하적 의미

$y = \tan x$의 그래프는 구간 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$에서 원점을 지나 $-\infty$에서 $+\infty$로 단조증가하는 곡선입니다. $x = \pm\frac{\pi}{2}$에서는 수직 점근선이 나타나고, 주기 $\pi$마다 동일한 패턴이 반복됩니다.

탄젠트의 기하학적 의미는 다음과 같습니다: 단위원 위의 각 $x$에 대한 점 $(\cos x, \sin x)$에서, 점을 지나 $x$축에 수직인 직선이 $x = 1$인 수직선과 만나는 점의 $y$좌표가 바로 $\tan x$입니다. 이는 직각삼각형에서 "대변/인접변"의 의미와 일치합니다.

탄젠트는 **기함수**입니다: $\tan(-x) = -\tan x$이므로 그래프는 원점 대칭입니다. 또한 주기함수이므로 $\tan(x + \pi) = \tan x$입니다.

### 주요 함숫값과 예시

다음은 주요 각도에서의 탄젠트 값입니다:
$$\tan 0 = 0, \quad \tan \frac{\pi}{6} = \frac{\sqrt{3}}{3}, \quad \tan \frac{\pi}{4} = 1, \quad \tan \frac{\pi}{3} = \sqrt{3}$$

구간 $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$에서 $\tan x = 1$의 해는 $x = \frac{\pi}{4}$입니다. (검증: `sympy.atan(1)`)

그래프를 그릴 때는 수직 점근선 $x = \pm\frac{\pi}{2}, \pm\frac{3\pi}{2}, \ldots$를 먼저 표시한 후, 각 구간에서 원점 근처의 점들을 기준으로 부드러운 곡선을 그으면 됩니다.
