### 정확한 진술

주어진 범위(일반적으로 $[0, 2\pi)$ 또는 $[0, \pi)$)에서 삼각방정식 $\sin x = a$, $\cos x = a$, $\tan x = a$ 등의 **모든 해를 찾은 후, 그 해들을 모두 더한 값**을 일반해의 합이라고 합니다.

### 직관과 대칭성

삼각함수는 단위원 위의 대칭성을 가지므로, 한 범위 내의 해들은 특정 점을 중심으로 대칭을 이룹니다. 예를 들어 $\sin x = \sin \alpha$를 만족하는 두 해 $x = \alpha$와 $x = \pi - \alpha$는 직선 $x = \frac{\pi}{2}$에 대해 대칭이며, 따라서 항상 **합이 $\pi$**입니다. 이런 대칭성을 이용하면 일일이 계산하지 않아도 해의 합을 빠르게 구할 수 있습니다.

### 범위별 규칙

**정현 방정식:** $\sin x = a$ (단, $|a| < 1$)에서 $[0, 2\pi)$ 범위의 두 해의 합은 항상 $\pi$입니다.

**코사인 방정식:** $\cos x = a$ (단, $|a| < 1$)에서 $[0, 2\pi)$ 범위의 두 해의 합은 항상 $2\pi$입니다.

**탄젠트 방정식:** $\tan x = a$에서 $[0, \pi)$ 범위에선 해가 1개, $[0, 2\pi)$ 범위에선 두 해의 합이 $\pi$입니다.

### 구체적 예시

$\sin x = \frac{1}{2}$, $0 \le x < 2\pi$ 범위에서:
- 해: $x = \frac{\pi}{6}, \frac{5\pi}{6}$
- 합: $\frac{\pi}{6} + \frac{5\pi}{6} = \pi$ ✓

$\cos x = -\frac{\sqrt{2}}{2}$, $0 \le x < 2\pi$ 범위에서:
- 해: $x = \frac{3\pi}{4}, \frac{5\pi}{4}$
- 합: $\frac{3\pi}{4} + \frac{5\pi}{4} = 2\pi$ ✓

이 대칭성 규칙을 알면 객관식 문제에서 계산 시간을 크게 단축할 수 있습니다.
