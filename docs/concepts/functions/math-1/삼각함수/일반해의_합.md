# 일반해의 합

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
주어진 범위 내에서 삼각방정식을 만족하는 모든 해를 찾아 그 값들을 모두 더한 것을 의미하며, 삼각함수의 대칭성을 이용하면 빠르게 구할 수 있습니다.

## 본문
주어진 범위(일반적으로 $[0, 2\pi)$ 또는 $[0, \pi)$)에서 삼각방정식 $\sin x = a$, $\cos x = a$, $\tan x = a$ 등의 모든 해를 찾은 후, 그 해들을 모두 더한 값을 일반해의 합이라고 합니다.

### 직관과 기하적 의미
삼각함수는 단위원 위에서 나타나는 대칭성을 가집니다. 따라서 특정 범위 내에서 방정식의 해들은 특정 직선을 기준으로 대칭을 이루는 경향이 있습니다. 예를 들어 $\sin x = \sin \alpha$를 만족하는 두 해 $x = \alpha$와 $x = \pi - \alpha$는 직선 $x = \frac{\pi}{2}$에 대해 대칭이며, 이로 인해 두 해의 합은 항상 $\pi$가 됩니다. 이러한 기하학적 대칭성을 이해하면 복잡한 계산 없이도 해의 합을 직관적으로 파악할 수 있습니다.

### 기본 성질
각 삼각함수의 방정식에 따른 범위별 해의 합 규칙은 다음과 같습니다.
- **정현 방정식**: $\sin x = a$ (단, $|a| < 1$)에서 $[0, 2\pi)$ 범위의 두 해의 합은 항상 $\pi$입니다.
- **코사인 방정식**: $\cos x = a$ (단, $|a| < 1$)에서 $[0, 2\pi)$ 범위의 두 해의 합은 항상 $2\pi$입니다.
- **탄젠트 방정식**: $\tan x = a$에서 $[0, \pi)$ 범위에는 해가 $1$개 존재하며, $[0, 2\pi)$ 범위에서의 두 해의 합은 $\pi$입니다.

예를 들어 $\sin x = \frac{1}{2}$ ($0 \le x < 2\pi$)의 해는 $\frac{\pi}{6}, \frac{5\pi}{6}$이며 합은 $\pi$입니다. 또한 $\cos x = -\frac{\sqrt{2}}{2}$ ($0 \le x < 2\pi$)의 해는 $\frac{3\pi}{4}, \frac{5\pi}{4}$이며 합은 $2\pi$가 됩니다.

## 학습 체크
- 주어진 범위가 $[0, 2\pi)$일 때, $\sin x$와 $\cos x$의 해의 합이 각각 왜 $\pi$와 $2\pi$가 되는지 단위원의 대칭성을 이용하여 설명할 수 있는가?
- $\tan x = a$의 경우 왜 $[0, \pi)$ 범위에서는 해가 하나만 존재하는가?

## 관련 개념
- **삼각함수**: 삼각함수의 그래프와 단위원에서의 좌표를 통해 방정식의 해와 그 대칭성을 결정짓는 기초가 됩니다.
