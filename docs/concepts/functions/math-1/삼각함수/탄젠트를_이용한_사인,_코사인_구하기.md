# 탄젠트를 이용한 사인, 코사인 구하기

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
주어진 $\tan \theta$ 값을 삼각함수의 항등식에 대입하여 $\sin \theta$와 $\cos \theta$의 값을 결정할 수 있습니다.

## 본문
주어진 각 $\theta$에 대해 $\tan \theta = t$라 할 때, 삼각함수의 기본 항등식인 $\sin^2 \theta + \cos^2 \theta = 1$과 $\tan \theta = \frac{\sin \theta}{\cos \theta}$를 이용하면 $\sin \theta$와 $\cos \theta$를 구할 수 있습니다. 먼저 $\cos^2 \theta$는 $\frac{1}{1 + \tan^2 \theta}$이므로 $\cos \theta = \pm \frac{1}{\sqrt{1 + t^2}}$가 됩니다. 또한 $\sin^2 \theta$는 $\frac{\tan^2 \theta}{1 + \tan^2 \theta}$이므로 $\sin \theta = \pm \frac{t}{\sqrt{1 + t^2}}$가 됩니다. 이때 부호($\pm$)는 $\theta$가 속한 사분면의 위치에 따라 결정됩니다.

### 직관과 기이적 의미
직각삼각형에서 탄젠트는 높이를 밑변으로 나눈 값입니다. $\tan \theta = t$라는 정보는 직각삼각형의 밑변과 높이의 비율을 고정시키며, 피타고라스 정리에 의해 빗변의 길이는 $\sqrt{1 + t^2}$가 됩니다. 따라서 코사인(밑변/빗변)과 사인(높이/빗변)의 값을 모두 복원할 수 있으며, 이는 하나의 삼각함수 값만으로 다른 값을 유도하는 유용한 도구가 됩니다.

### 기본 성질
- $\tan \theta$의 값이 양수이면 $\sin \theta$와 $\cos \theta$의 부호는 같습니다.
- $\tan \theta$의 값이 음수이면 $\sin \theta$와 $\cos \theta$의 부호는 서로 다릅니다.
- $\tan \theta = 2$인 경우, 제1사분면을 가정하면 $\cos \theta = \frac{1}{\sqrt{5}}$, $\sin \theta = \frac{2}{\sqrt{5}}$입니다.

## 학습 체크
- $\tan \theta$의 값이 주어졌을 때, $\theta$의 사분면에 따른 $\sin \theta$와 $\cos \theta$의 부호를 정확히 판별할 수 있는가?
- $\sin^2 \theta + \cos^2 \theta = 1$ 항등식을 이용하여 $\tan \theta$로부터 $\cos^2 \theta$를 유도하는 과정을 설명할 수 있는가?

## 관련 개념
- **삼각함수**: $\sin, \cos, \tan$ 사이의 유기적인 관계를 나타내며, 탄젠트의 값을 통해 다른 두 함수의 값을 결정하는 기초가 됩니다.
