# 탄젠트를 이용한 사인, 코사인 구하기

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

주어진 각 $\theta$에 대해 $\tan \theta$ 값을 알 때, 다음 관계식을 이용하여 $\sin \theta$와 $\cos \theta$를 구할 수 있습니다.

$\tan \theta = t$라 하면, 항등식 $\sin^2 \theta + \cos^2 \theta = 1$과 $\tan \theta = \frac{\sin \theta}{\cos \theta}$로부터:

$$\cos^2 \theta = \frac{1}{1 + \tan^2 \theta} = \frac{1}{1 + t^2}$$

$$\sin^2 \theta = \frac{\tan^2 \theta}{1 + \tan^2 \theta} = \frac{t^2}{1 + t^2}$$

따라서:
$$\cos \theta = \pm \frac{1}{\sqrt{1 + t^2}}, \quad \sin \theta = \pm \frac{t}{\sqrt{1 + t^2}}$$

(부호는 $\theta$가 놓인 사분면에 따라 결정)

## 직관 및 기하적 의미

직각삼각형에서 탄젠트는 **높이를 밑변으로 나눈 값**입니다. $\tan \theta = t$라는 정보만으로도 그 직각삼각형의 밑변과 높이의 비율이 정해집니다. 빗변의 길이는 피타고라스 정리로 $\sqrt{1 + t^2}$가 되고, 이를 이용하면 코사인(밑변/빗변)과 사인(높이/빗변)을 모두 복원할 수 있습니다. 이는 **한 가지 삼각함수 값이 주어졌을 때 다른 값을 구하는 강력한 도구**입니다.

## 한 줄 예

$\tan \theta = 2$일 때, $\cos \theta = \frac{1}{\sqrt{5}}$ (제1사분면), $\sin \theta = \frac{2}{\sqrt{5}}$입니다.

(`sympy.sqrt(1 + 2**2)` → $\sqrt{5}$ 확인)
