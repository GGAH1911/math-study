# 실수의 n제곱근 존재 조건

## 정확한 진술

실수 $a$와 양의 정수 $n$에 대하여, 방정식 $x^n = a$를 만족하는 실수 $x$가 존재할 조건은 다음과 같습니다:

**$n$이 홀수인 경우:** 모든 실수 $a$에 대해 정확히 하나의 실수 $\sqrt[n]{a}$가 존재합니다.

**$n$이 짝수인 경우:** $a \geq 0$일 때만 음이 아닌 실근 $\sqrt[n]{a}$가 존재하며, $a < 0$일 때는 실수 범위에서의 n제곱근이 존재하지 않습니다.

## 직관/기하적 의미

함수 $y = x^n$의 그래프로 이해하면 명확합니다. $x^n = a$의 해는 곡선 $y = x^n$과 수평선 $y = a$의 교점의 x좌표입니다.

$n$이 홀수일 때, $y = x^n$은 모든 사분면을 지나는 증가함수입니다. 따라서 음수 $a$에 대해서도 음의 해가 정확히 하나 존재합니다. 예를 들어 $\sqrt[3]{-8} = -2$입니다.

$n$이 짝수일 때, $y = x^n$은 아래로 볼록한 포물선 모양으로 $y$축에 대해 대칭입니다. 이 곡선의 최솟값은 $y = 0$이므로, $a < 0$인 수평선과는 만날 수 없습니다. $a > 0$이면 두 교점이 생기지만, 양의 근 $\sqrt[n]{a}$만을 주 n제곱근으로 정의합니다.

## 한 줄 예

$\sqrt[3]{-8} = -2$는 실수이지만, $\sqrt[4]{-16}$은 실수 범위에서 정의되지 않습니다.

(검증: `sympy.solve(x**3 + 8, x)` → $[-2]$; `sympy.sqrt(-16, 4)` → 복소수 범위로 확장 필요)
