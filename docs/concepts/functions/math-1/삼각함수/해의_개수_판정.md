# 해의 개수 판정

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

삼각방정식 $\sin x = a$, $\cos x = a$, $\tan x = a$ 따위의 해의 개수를 주어진 범위(보통 $[0, 2\pi)$ 또는 $[0^\circ, 360^\circ)$)에서 판정하는 것을 **해의 개수 판정**이라 합니다. 일반적으로는 $y = \sin x$, $y = \cos x$, $y = \tan x$의 그래프와 수평선 $y = a$의 교점 개수를 세어서 해의 개수를 결정합니다.

## 직관과 기하적 의미

$[0, 2\pi)$ 범위에서 $\sin x = a$를 풀 때, 이는 정현곡선과 수평선 $y = a$가 만나는 점의 개수를 묻는 것입니다. 정현함수는 한 주기에서 $[−1, 1]$ 범위에서 진동하므로:

- $|a| > 1$이면 교점이 **0개** (해 없음)
- $a = 1$이면 $x = \frac{\pi}{2}$에서만 만나므로 **1개**
- $-1 < a < 1$ (단, $a \neq 0$)이면 상승과 하강 구간에서 각각 만나므로 **2개**
- $a = 0$이면 $x = 0, \pi$에서 만나므로 **2개**
- $a = -1$이면 $x = \frac{3\pi}{2}$에서만 만나므로 **1개**

코사인의 경우 대칭성에 의해 비슷한 패턴을 따르고, 탄젠트는 주기가 $\pi$이고 수직 점근선이 있어 상황이 달라집니다.

## 한 줄 예

$[0, 2\pi)$에서 $\sin x = \frac{1}{2}$의 해는 $x = \frac{\pi}{6}, \frac{5\pi}{6}$로 **2개**입니다. (단위원에서 높이 $\frac{1}{2}$인 수평선이 원과 만나는 두 점에 해당)
