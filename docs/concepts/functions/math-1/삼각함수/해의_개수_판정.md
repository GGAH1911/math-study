# 해의 개수 판정

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각방정식의 해의 개수는 삼각함수의 그래프와 상수함수 $y=a$의 교점 개수를 통해 판정할 수 있습니다.

## 본문
삼각방정식 $\sin x = a$, $\cos x = a$, $\tan x = a$의 해의 개수를 주어진 범위(보통 $[0, 2\pi)$ 또는 $[0^\circ, 360^\circ)$) 내에서 결정하는 것을 해의 개수 판정이라 합니다. 이는 일반적으로 $y = \sin x$, $y = \cos x$, $y = \tan x$의 그래프와 수평선 $y = a$가 만나는 교점의 개수를 찾는 과정과 같습니다.

### 직관과 기하적 의미
$[0, 2\pi)$ 범위에서 $\sin x = a$의 해를 구하는 것은 정현곡선과 수평선 $y = a$가 만나는 점의 개수를 찾는 것과 같습니다. 정현함수는 한 주기 동안 $[-1, 1]$ 범위에서 진동하므로 $a$의 값에 따라 교점의 개수가 달라집니다.

### 기본 성질
- $|a| > 1$이면 교점이 $0$개입니다.
- $a = 1$이면 $x = \tfrac{\pi}{2}$에서만 만나므로 $1$개입니다.
- $-1 < a < 1$ (단, $a \neq 0$)이면 상승과 하강 구간에서 각각 만나므로 $2$개입니다.
- $a = 0$이면 $x = 0, \pi$에서 만나므로 $2$개입니다.
- $a = -1$이면 $x = \tfrac{3\pi}{2}$에서만 만나므로 $1$개입니다.

코사인의 경우 대칭성에 의해 이와 유사한 패턴을 보이며, 탄젠트는 주기가 $\pi$이고 수직 점근선이 존재하므로 상황이 달라집니다. 예를 들어 $[0, 2\pi)$에서 $\sin x = \tfrac{1}{2}$의 해는 $x = \tfrac{\pi}{6}, \tfrac{5\pi}{6}$로 $2$개이며, 이는 단위원에서 높이가 $\tfrac{1}{2}$인 수평선과 원이 만나는 두 점에 해당합니다.

## 학습 체크
- 주어진 범위가 한 주기($2\pi$)인지, 혹은 그보다 넓거나 좁은 범위인지 확인했는가?
- $a$의 값이 삼각함수의 치역 범위($[-1, 1]$) 안에 포함되는가?
- 탄젠트 함수의 경우 점근선이 주어진 범위 내에 포함되어 해의 개수에 영향을 주지는 않는가?

## 관련 개념
- **삼각함수**: 해의 개수를 판정하기 위해 그래프의 주기성, 대칭성, 치역에 대한 이해가 필수적으로 요구됩니다.
