# 삼각함수의 그래프

## 정확한 진술

삼각함수의 그래프는 각도를 $x$축에, 삼각함수값을 $y$축에 나타낸 평면곡선입니다. 주요 삼각함수는 다음과 같습니다.

- $y = \sin x$: 정의역은 모든 실수, 치역은 $[-1, 1]$
- $y = \cos x$: 정의역은 모든 실수, 치역은 $[-1, 1]$  
- $y = \tan x$: 정의역은 $x \neq \frac{\pi}{2} + n\pi$ (단, $n$은 정수), 치역은 모든 실수

각 함수는 주기함수입니다. $\sin x$와 $\cos x$의 주기는 $2\pi$이고, $\tan x$의 주기는 $\pi$입니다.

## 직관/기하적 의미

단위원 위를 각도만큼 회전하는 점의 좌표 변화를 평면에 펼쳐놓은 것이 삼각함수의 그래프입니다. 반시계 방향으로 회전할 때 점의 $y$좌표 변화가 $y = \sin x$이고, $x$좌표 변화가 $y = \cos x$입니다.

$\sin x$는 $x = \frac{\pi}{2} + 2n\pi$에서 최댓값 1, $x = -\frac{\pi}{2} + 2n\pi$에서 최솟값 -1을 가집니다. $\cos x$는 $\sin x$를 $\frac{\pi}{2}$만큼 왼쪽으로 평행이동한 형태입니다. $\tan x$는 원점을 지나며 $x = \frac{\pi}{2} + n\pi$마다 수직 점근선을 가져, 불연속이 됩니다.

## 한 줄 예

$y = \sin x$에서 $x = 0, \frac{\pi}{6}, \frac{\pi}{2}, \pi, 2\pi$일 때 함수값은 각각 $0, \frac{1}{2}, 1, 0, 0$입니다.
