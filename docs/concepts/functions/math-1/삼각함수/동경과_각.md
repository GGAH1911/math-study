# 동경과 각

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

동경(終邊, terminal side)은 각을 나타내기 위해 한 점에서 출발한 반직선을 뜻합니다. 좌표평면의 원점 O를 중심으로, 양의 x축을 시초변(始邊, initial side)으로 하고 이를 기준으로 회전하는 반직선을 **동경**이라 부릅니다. 

각 $\theta$는 시초변에서 동경까지의 회전량으로 정의됩니다. 반시계 방향 회전을 양수, 시계 방향 회전을 음수로 약속합니다. 따라서 같은 동경을 나타내는 각은 무한히 많습니다. 예를 들어 $\theta, \theta + 360^\circ, \theta + 720^\circ, \ldots$는 모두 같은 동경을 결정합니다.

## 직관/기하적 의미

동경의 위치를 파악하는 것은 삼각함수를 이해하는 핵심입니다. 원점에서 거리 $r$만큼 떨어진 동경 위의 점을 P$(x, y)$라 하면, 삼각함수는 이 점의 좌표를 이용해 정의됩니다:

$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}$$

동경이 제1, 2, 3, 4사분면 중 어디에 위치하는지에 따라 삼각함수의 부호가 결정됩니다(ASTC 법칙). 또한 한 바퀴 회전($360^\circ = 2\pi$) 후 동경이 같은 위치로 돌아오므로, 삼각함수는 주기가 $2\pi$인 주기함수가 됩니다.

## 한 줄 예

동경이 양의 y축을 가리킬 때 $\theta = 90^\circ$ (또는 $\frac{\pi}{2}$)이고, 이 경우 $\sin 90^\circ = 1, \cos 90^\circ = 0$입니다.
