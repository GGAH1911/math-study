# 호도법

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
각의 크기를 호의 길이를 반지름으로 나눈 값으로 나타내는 측정 방식입니다.

## 본문
호도법은 각의 크기를 호의 길이를 반지름으로 나눈 값으로 나타내는 각도 측정 방식입니다. 반지름이 $r$인 원에서 중심각이 만드는 호의 길이가 $l$일 때, 그 중심각의 크기 $\theta$는 $\theta = \frac{l}{r}$ (라디안)로 정의됩니다. 이때 라디안은 단위 기호로 $\text{rad}$를 쓰거나 생략하여 표현합니다.

### 직관과 기하적 의미
호도법을 이해하는 핵심은 반지름과 호의 길이의 관계에 있습니다. 반지름이 $1$인 단위원에서는 라디안 값이 호의 길이와 정확히 일치합니다. 즉, 중심각이 $\theta$ 라디안이면 호의 길이 또한 $\theta$가 됩니다. 이는 원의 기하적 성질을 이용한 측정법으로, 원 전체의 호의 길이인 $2\pi r$을 반지름 $r$로 나누면 $2\pi$가 되므로 $2\pi$ 라디안은 $360^\circ$와 같습니다.

### 기본 성질
호도법을 사용하면 삼각함수의 미분 공식이 간결해지며, 복소수나 벡터를 다루는 고급 수학 분야에서 표준적인 측정법으로 사용됩니다. 예를 들어 반지름이 $3$인 원에서 호의 길이가 $6$이라면, 중심각은 $\theta = \frac{6}{3} = 2$ 라디안이 됩니다.

## 관련 개념
