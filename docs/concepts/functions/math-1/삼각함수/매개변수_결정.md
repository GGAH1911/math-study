# 매개변수 결정

## 정확한 진술

곡선을 나타내는 **매개변수 방정식** $x = f(t)$, $y = g(t)$가 주어졌을 때, 곡선 위의 특정 점의 좌표를 만족하는 **매개변수 값을 구하는 과정**을 **매개변수 결정**이라 합니다. 이는 주어진 점이 곡선 위에서 "언제(어느 매개변수에서) 지나가는가"를 역으로 계산하는 것입니다.

예: 원의 방정식 $x = \cos\theta$, $y = \sin\theta$ ($0 \le \theta < 2\pi$)에서 점 $\left(\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$이 주어졌을 때, 이를 만족하는 $\theta = \frac{\pi}{6}$을 찾는 것이 매개변수 결정입니다.

## 직관 및 기하적 의미

매개변수 방정식은 곡선을 **동적으로** 표현합니다. 마치 영화의 프레임처럼, 각 $t$ 값에서의 점 $(x(t), y(t))$가 곡선 위에서 시간순으로 나열됩니다. 

"$x = 2$, $y = 3$인 점은 이 곡선 위에 있나?"라는 질문에 답하려면, 두 식을 동시에 만족하는 $t$가 존재하는지 확인해야 합니다. 특히 **삼각함수 매개변수**의 경우, 주기성 때문에 여러 개의 $t$ 값이 같은 점을 나타낼 수 있으므로, 정의역 범위를 고려하여 올바른 매개변수를 선택해야 합니다.

## 한 줄 예

원 $x = 2\cos\theta$, $y = 2\sin\theta$ ($0 \le \theta < 2\pi$)에서 점 $(0, -2)$에 대응하는 $\theta$는 $\frac{3\pi}{2}$입니다.  
검증: `cos(3*pi/2), sin(3*pi/2)` → $(0, -1)$이므로 $2 \times (0, -1) = (0, -2)$ ✓
