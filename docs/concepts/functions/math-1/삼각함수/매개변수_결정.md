# 매개변수 결정

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
곡선을 나타내는 매개변수 방정식에서 주어진 특정 점의 좌표를 만족하는 매개변수 값을 역으로 찾아내는 과정입니다.

## 본문
곡선을 나타내는 매개변수 방정식 $x = f(t)$, $y = g(t)$가 주어졌을 때, 곡선 위의 특정 점의 좌표를 만족하는 매개변수 값을 구하는 과정을 매개변수 결정이라 합니다. 이는 주어진 점이 곡선 위에서 어느 시점(어느 매개변수 값)에 위치하는지를 계산하는 과정입니다. 예를 들어, 원의 방정식 $x = \cos\theta$, $y = \sin\theta$ ($0 \le \theta < 2\pi$)에서 점 $\left(\tfrac{\sqrt{3}}{2}, \tfrac{1}{2}\right)$이 주어졌을 때, 이를 만족하는 $\theta = \tfrac{\pi}{6}$을 찾는 것이 매개변수 결정의 대표적인 사례입니다.

### 직관과 기하적 의미
매개변수 방정식은 곡선을 동적으로 표현합니다. 마치 영화의 프레임처럼, 각 $t$ 값에 따른 점 $(x(t), y(t))$가 곡선 위를 따라 시간순으로 움직이는 것으로 이해할 수 있습니다. 특정 점이 곡선 위에 있는지 확인하려면 두 식을 동시에 만족하는 $t$가 존재하는지 검토해야 합니다. 특히 삼각함수를 이용한 매개변수 표현에서는 함수의 주기성으로 인해 하나의 점에 여러 매개변수 값이 대응될 수 있으므로, 주어진 정의역 범위를 반드시 고려하여 적절한 값을 선택해야 합니다.

### 기본 성질
- 주어진 점 $(x_0, y_0)$가 곡선 위의 점이라면, $x_0 = f(t)$와 $y_0 = g(t)$를 동시에 만족하는 $t$가 존재해야 합니다.
- 매개변수의 범위가 제한되어 있는 경우, 계산된 $t$ 값이 해당 범위 내에 있는지 확인해야 합니다.

## 학습 체크
- 주어진 점의 좌표를 매개변수 방정식의 각 식에 대입하여 동일한 매개변수 값을 얻을 수 있는가?
- 삼각함수가 포함된 매개변수 방정식에서 매개변수의 범위(정의역) 내에 있는 해를 찾았는가?

## 관련 개념
- **삼각함수**: 매개변수 방정식에서 삼각함수를 사용할 경우, 함수의 주기성과 단위 원의 성질을 이용하여 매개변수 값을 결정해야 합니다.
