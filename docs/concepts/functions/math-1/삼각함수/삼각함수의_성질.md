# 삼각함수의 성질

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

삼각함수의 기본 성질은 다음과 같습니다.

**기본 항등식**: 모든 실수 $\theta$에 대해 $\sin^2\theta + \cos^2\theta = 1$

**주기성**: $\sin(\theta + 2\pi) = \sin\theta$, $\cos(\theta + 2\pi) = \cos\theta$, $\tan(\theta + \pi) = \tan\theta$

**대칭성**: $\sin(-\theta) = -\sin\theta$ (기함수), $\cos(-\theta) = \cos\theta$ (우함수)

**여각 공식**: $\sin(\frac{\pi}{2} - \theta) = \cos\theta$, $\cos(\frac{\pi}{2} - \theta) = \sin\theta$

## 직관/기하적 의미

단위원 위의 점 $(\cos\theta, \sin\theta)$를 생각해봅시다. 기본 항등식 $\sin^2\theta + \cos^2\theta = 1$은 이 점이 원점으로부터 거리 1에 있다는 뜻입니다.

주기성은 각도를 $2\pi$만큼 증가시키면 단위원을 한 바퀴 돌아 같은 위치로 돌아오기 때문입니다. 반각 함수(탄젠트)는 원이 특수한 대칭성을 가지므로 주기가 $\pi$입니다.

대칭성은 원점 대칭이나 축 대칭의 기하학적 성질에서 나옵니다. 음수 각에서의 함숫값은 원의 반사 대칭으로 설명됩니다.

## 한 줄 예

$\sin\frac{\pi}{6} = \frac{1}{2}$이면, $\sin(\frac{\pi}{6} + 2\pi) = \frac{1}{2}$, $\sin(-\frac{\pi}{6}) = -\frac{1}{2}$, $\cos(\frac{\pi}{2} - \frac{\pi}{6}) = \cos\frac{\pi}{3} = \frac{1}{2}$가 모두 성립합니다.
