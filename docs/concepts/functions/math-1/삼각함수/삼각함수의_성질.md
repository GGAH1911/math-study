# 삼각함수의 성질

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각함수는 단위원을 기반으로 하는 주기성과 대칭성을 가지며, 피타고라스 정리와 연관된 항등식을 만족하는 함수입니다.

## 본문
삼각함수의 성질은 단위원을 통해 정의되는 함수의 기하학적 특성을 나타냅니다. 모든 실수 $\theta$에 대하여 $\sin^2\theta + \cos^2\theta = 1$이라는 기본 항등식이 성립하며, 이는 삼각함수의 값이 단위원 위의 점의 좌표와 직결됨을 의미합니다. 또한 삼각함수는 일정한 간격마다 값이 반복되는 주기성을 가지는데, $\sin$과 $\cos$은 $2\pi$를 주기로 하고 $\tan$은 $\pi$를 주기로 합니다. 각의 부호에 따른 대칭성으로는 $\sin$은 원점 대칭인 기함수($\sin(-\theta) = -\sin\theta$)의 성질을, $\cos$은 축 대칭인 우함수($\cos(-\theta) = \cos\theta$)의 성질을 가집니다. 마지막으로 $\frac{\pi}{2}$를 기준으로 각의 보수 관계를 나타내는 여각 공식 $\sin(\frac{\pi}{2} - \theta) = \cos\theta$와 $\cos(\frac{\pi}{2} - \theta) = \sin\theta$가 성립합니다.

### 직관과 기하적 의미
단위원 위의 점 $(\cos\theta, \sin\theta)$를 생각할 때, 기본 항등식은 이 점이 원점으로부터 거리 1에 있다는 피타고라스 정리의 결과입니다. 주기성은 각도를 $2\pi$만큼 증가시키면 단위원을 한 바퀴 돌아 제자리로 돌아오는 회전 운동의 특성을 반영하며, 탄젠트는 원의 대칭적 구조로 인해 $\pi$를 주기로 가집니다. 음수 각에 대한 대칭성은 원점이나 축을 기준으로 한 반사 대칭의 기하학적 성질로 이해할 수 있습니다.

### 기본 성질
- 기본 항등식: $\sin^2\theta + \cos^2\theta = 1$
- 주기성: $\sin(\theta + 2\pi) = \sin\theta$, $\cos(\theta + 2\pi) = \cos\theta$, $\tan(\theta + \pi) = \tan\theta$
- 대칭성: $\sin(-\theta) = -\sin\theta$, $\cos(-\theta) = \cos\theta$
- 여각 공식: $\sin(\frac{\pi}{2} - \theta) = \cos\theta$, $\cos(\frac{\pi}{2} - \theta) = \sin\theta$

## 학습 체크
- $\sin^2\theta + \cos^2\theta = 1$을 이용하여 $\sin\theta$의 값을 알 때 $\cos\theta$의 값을 구할 수 있는가?
- 주어진 각의 부호와 크기에 따라 $\sin$, $\cos$, $\tan$의 함숫값이 어떻게 변하는지 주기성과 대칭성을 이용하여 설명할 수 있는가?
- 여각 공식을 활용하여 서로 다른 각의 삼각함수 값을 변환할 수 있는가?

## 관련 개념
- **삼각함수**: 단위원을 통해 정의되며, 본 개념의 성질을 바탕으로 그래프의 형태와 주기성을 결정합니다.
