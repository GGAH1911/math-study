# 삼각함수의 기본성질

$\sin, \cos, \tan$ 함수가 일반각에 대해 가지는 부호·주기·대칭의 핵심 성질들입니다. 수학1 삼각함수 단원의 기반입니다.

## 정의

단위원 정의에 의해 임의의 실수 $\theta$에 대하여 다음이 성립합니다.
- **정의 관계:** $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$ ($\cos\theta \neq 0$).
- **피타고라스 항등식:** $\sin^2\theta + \cos^2\theta = 1.$
- **주기:** $\sin(\theta + 2\pi) = \sin\theta,\ \cos(\theta + 2\pi) = \cos\theta,\ \tan(\theta + \pi) = \tan\theta.$
- **부호:** 각 사분면에서 $\sin, \cos, \tan$의 부호는 ASTC 규칙(All, Sin, Tan, Cos가 양수)로 결정됩니다.
- **치역:** $-1 \le \sin\theta \le 1$, $-1 \le \cos\theta \le 1$, $\tan\theta \in \mathbb{R}$.

## 예시

각 $\theta = \dfrac{7\pi}{6}$에 대해 $\sin\theta, \cos\theta$를 구해 봅니다. 이 각은 제3사분면이며 기준각은 $\dfrac{\pi}{6}$. 제3사분면에서 $\sin, \cos$는 모두 음수이므로
$$\sin\frac{7\pi}{6} = -\sin\frac{\pi}{6} = -\frac{1}{2}, \quad \cos\frac{7\pi}{6} = -\cos\frac{\pi}{6} = -\frac{\sqrt{3}}{2}.$$
