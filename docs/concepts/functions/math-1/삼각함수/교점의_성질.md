### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 그래프의 **교점**은 두 곡선이 만나는 점입니다. 교점이 존재하려면 $f(x) = g(x)$를 만족하는 $x$값이 존재해야 합니다. 이러한 $x$값을 **교점의 x좌표**라 하고, 이때의 $y$값은 $y = f(x) = g(x)$입니다. 따라서 **교점의 개수 = 방정식 $f(x) = g(x)$의 실근의 개수**입니다.

### 직관/기하적 의미

그래프의 교점은 두 곡선이 일치하는 지점을 의미합니다. 예를 들어, $y = \sin x$와 $y = \frac{1}{2}$의 교점은 $\sin x = \frac{1}{2}$를 만족하는 모든 점입니다. 삼각함수 그래프는 주기성을 가지므로, 한 주기 내에서 찾은 해를 이용하여 모든 교점을 표현할 수 있습니다. 특히 삼각방정식의 경우, 구간 내 교점의 개수를 파악하는 것이 문제 해결의 핵심입니다.

### 한 줄 예

방정식 $\sin x = \frac{1}{2}$에서 $[0, 2\pi]$ 구간 내 교점은 $x = \frac{\pi}{6}, \frac{5\pi}{6}$로 2개입니다. (일반해: $x = \frac{\pi}{6} + 2n\pi$ 또는 $x = \frac{5\pi}{6} + 2n\pi$, 단 $n$은 정수)

*검산: 

```python
import sympy as sp
x = sp.Symbol('x', real=True)
# [0, 2π] 내에서 sin(x) = 1/2의 해
solutions = sp.solve(sp.sin(x) - sp.Rational(1,2), x)
# 일반해 중 주기 내 해 필터링
```*
