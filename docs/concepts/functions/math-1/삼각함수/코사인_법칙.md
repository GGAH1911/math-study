# 코사인 법칙

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각형의 두 변의 길이와 그 사이 각을 알 때 나머지 한 변의 길이를 구할 수 있게 해주는 피타고라스 정리의 일반화된 형태입니다.

## 본문
삼각형 $ABC$에서 한 변의 길이의 제곱은 다른 두 변의 길이의 제곱의 합에서 그 두 변과 그 사이 각의 코사인을 곱한 값의 2배를 뺀 것과 같습니다. 이를 수식으로 나타내면 다음과 같습니다.

$$a^2 = b^2 + c^2 - 2bc\cos A$$
$$b^2 = a^2 + c^2 - 2ac\cos B$$
$$c^2 = a^2 + b^2 - 2ab\cos C$$

여기서 $a, b, c$는 각각 꼭짓점 $A, B, C$의 대변의 길이이고, $A, B, C$는 해당 꼭짓점에서의 각을 의미합니다.

### 직관과 기하적 의미
코사인 법칙은 두 변의 길이와 그 사이 각을 알 때 나머지 한 변을 구하는 강력한 도구입니다. 특히 각 $A = 90^\circ$인 직각삼각형의 경우 $\cos A = 0$이 되어 식이 $a^2 = b^2 + c^2$으로 변하는데, 이는 우리가 잘 아는 피타고라스 정리와 일치합니다. 따라서 코사인 법칙은 피타고라스 정리를 모든 삼각형으로 확장하여 일반화한 개념으로 이해할 수 있습니다. 기하학적으로는 좌표평면 위에 삼각형을 배치한 후, 점 $A$의 좌표를 삼각함수로 표현하여 두 점 사이의 거리 공식에 대입함으로써 유도할 수 있습니다.

### 기본 성질
- 각 $A$가 $90^\circ$보다 작으면 $\cos A > 0$이므로 $a^2 < b^2 + c^2$이 성립합니다.
- 각 $A$가 $90^\circ$보다 크면 $\cos A < 0$이므로 $a^2 > b^2 + c^2$이 성립합니다.
- 세 변의 길이를 모두 알 때, 코사인 법칙을 변형하여 각의 크기를 구할 수 있습니다.

## 학습 체크
- 세 변의 길이 $a, b, c$가 주어졌을 때, 코사인 법칙을 이용하여 각 $A$의 코사인 값을 구할 수 있는가?
- 코사인 법칙이 피타고라스 정리와 어떤 관계를 가지며, 어떤 조건에서 두 식이 같아지는지 설명할 수 있는가?

## 관련 개념
- **삼각비**: 삼각형의 각과 변 사이의 관계를 나타내는 기초 개념으로, 코사인 법칙의 핵심 구성 요소입니다.
- **피타고라스 정리**: 직각삼각형에서 성립하는 정리로, 코사인 법칙에서 각이 $90^\circ$인 특수한 경우에 해당합니다.
