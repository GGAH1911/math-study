### 정확한 진술

삼각함수의 기본 항등식(fundamental trigonometric identity)은 임의의 각 $\theta$에 대해 항상 성립하는 관계식입니다. 가장 중요한 것은 **피타고라스 항등식**입니다:

$$\sin^2\theta + \cos^2\theta = 1$$

이로부터 다음이 유도됩니다:
- $1 + \tan^2\theta = \sec^2\theta$ (양변을 $\cos^2\theta$로 나눔)
- $1 + \cot^2\theta = \csc^2\theta$ (양변을 $\sin^2\theta$로 나눔)

또한 기본 정의로부터:
$$\tan\theta = \frac{\sin\theta}{\cos\theta}, \quad \cot\theta = \frac{\cos\theta}{\sin\theta}$$

### 직관/기하적 의미

단위원 위의 점 $(\cos\theta, \sin\theta)$를 생각해봅시다. 원의 방정식이 $x^2 + y^2 = 1$이므로, 이 점의 좌표는 자동으로 $\sin^2\theta + \cos^2\theta = 1$을 만족합니다. 즉, 피타고라스 항등식은 **단위원의 기하학적 성질이 그대로 대수식으로 표현된 것**입니다. 다른 항등식들도 이 기본식에서 출발하여, 삼각함수들 사이의 불변적인 관계를 나타냅니다.

### 한 줄 예

$\theta = \frac{\pi}{6}$일 때, $\sin^2\frac{\pi}{6} + \cos^2\frac{\pi}{6} = \left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1$ ✓

또는 $\theta = \frac{\pi}{4}$일 때: $1 + \tan^2\frac{\pi}{4} = 1 + 1^2 = 2 = \sec^2\frac{\pi}{4}$ (∵ $\sec\frac{\pi}{4} = \sqrt{2}$) ✓

삼각함수 값이 주어졌을 때 다른 함수값을 구하거나, 복잡한 삼각식을 간단히 정리할 때 이 항등식들을 반복 적용합니다.
