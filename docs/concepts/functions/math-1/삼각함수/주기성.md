# 주기성

> **정리** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
$\sin, \cos$ → $2\pi$, $\tan$ → $\pi$

## 본문 (학습 시 채워짐)

### 진술 및 가정

**주기함수(periodic function)**: 정의역에 속하는 모든 $x$에 대해 $f(x + p) = f(x)$를 만족하는 양수 $p$가 존재할 때, $f$를 주기함수라 하며 이러한 $p$ 중 가장 작은 양수를 **기본주기(fundamental period)** 라 합니다.

**삼각함수의 주기**:
- $\sin(x + 2\pi) = \sin x$, $\cos(x + 2\pi) = \cos x$ → 기본주기: $2\pi$
- $\tan(x + \pi) = \tan x$ → 기본주기: $\pi$

### 직관 및 기하적 의미

단위원에서 생각해봅시다. 각도 $\theta$만큼 회전한 점의 좌표가 $(\cos \theta, \sin \theta)$입니다. 다시 $2\pi$만큼 회전하면 한 바퀴를 돌아 처음 위치로 돌아오므로, $(\cos(\theta + 2\pi), \sin(\theta + 2\pi)) = (\cos \theta, \sin \theta)$입니다.

탄젠트는 $\tan \theta = \frac{\sin \theta}{\cos \theta}$이므로, $\theta$에서 $\pi$를 더하면 분자와 분모가 동시에 부호가 바뀌어 $\tan(\theta + \pi) = \frac{-\sin \theta}{-\cos \theta} = \tan \theta$가 됩니다.

### 간단한 유도

삼각함수의 정의에 따라:
$$\sin(\theta + 2\pi) = \sin \theta \cos 2\pi + \cos \theta \sin 2\pi = \sin \theta \cdot 1 + \cos \theta \cdot 0 = \sin \theta$$

탄젠트의 경우:
$$\tan(\theta + \pi) = \frac{\sin(\theta + \pi)}{\cos(\theta + \pi)} = \frac{-\sin \theta}{-\cos \theta} = \tan \theta$$

### 의의 및 응용

주기성은 삼각함수의 **가장 본질적인 성질**입니다. 이를 이용하면:

1. **각도 정규화**: $\sin 750° = \sin(750° - 720°) = \sin 30° = \frac{1}{2}$ (두 바퀴를 뺀 후 계산)
2. **그래프 스케치**: 한 주기만 정확히 그리면 전체 함수를 파악할 수 있음
3. **방정식 풀이**: $\sin x = \frac{1}{2}$의 일반해는 $x = \frac{\pi}{6} + 2n\pi$ 또는 $x = \frac{5\pi}{6} + 2n\pi$ (단, $n$은 정수)

주기성 때문에 삼각함수는 **주기함수의 대표적 예시**이며, 파동·진동·천체 운동 등 반복되는 현상을 수학적으로 모델링할 수 있게 합니다.
