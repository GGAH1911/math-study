# 삼각방정식 풀이

> **예제** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
$\sin x = \tfrac{1}{2}$을 만족하는 $0 \le x < 2\pi$ 범위의 해를 구하는 과정입니다.

## 본문
$0 \le x < 2\pi$ 범위에서 다음 방정식을 풀어라.
$$\sin x = \frac{1}{2}$$

### 단계별 풀이
**1단계: 기준각 찾기**
$\sin x = \tfrac{1}{2}$를 만족하는 기준각을 찾는다. 삼각함수 특수각 중 $\sin \tfrac{\pi}{6} = \tfrac{1}{2}$이므로 기준각 $\alpha = \tfrac{\pi}{6}$를 구할 수 있다.

**2단계: 단위원에서 해의 위치 파악**
사인 값은 단위원 위 점의 $y$좌표와 같으므로, $y$좌표가 양수인 제1사분면과 제2사분면에서 해가 존재한다.
- 제1사분면의 해: 기준각과 동일한 $x = \tfrac{\pi}{6}$
- 제2사분면의 해: $\pi$에서 기준각을 뺀 $x = \pi - \tfrac{\pi}{6} = \tfrac{5\pi}{6}$

**3단계: 범위 내 해 확인**
구한 두 각 $\tfrac{\pi}{6}$와 $\tfrac{5\pi}{6}$는 모두 주어진 범위 $0 \le x < 2\pi$ 안에 포함된다. 제3사분면과 제4사분면에서는 $\sin x < 0$이므로 추가적인 해는 존재하지 않는다.

### 답과 변형
$$x = \frac{\pi}{6} \text{ 또는 } x = \frac{5\pi}{6}$$
일반해로 나타내면 $x = \tfrac{\pi}{6} + 2n\pi$ 또는 $x = \tfrac{5\pi}{6} + 2n\pi$ (단, $n$은 정수)이다.

범위가 $[0, 4\pi)$로 확장되면 주기성에 의해 $\tfrac{\pi}{6}, \tfrac{5\pi}{6}, \tfrac{13\pi}{6}, \tfrac{17\pi}{6}$의 네 개 해를 갖는다. 해를 구할 때는 사분면별 삼각함수의 부호를 먼저 확인하고, 제2사분면의 해는 $\pi - (\text{기준각})$임을 이용하면 체계적인 풀이가 가능하다.

- 단위원의 좌표를 이용하여 사분면별 해의 위치를 찾을 수 있는가?
- 주어진 범위에 따라 해의 개수가 달라짐을 이해하고 있는가?

## 관련 개념
- **삼각함수**: 각의 크기에 따른 삼각비의 값을 나타내며, 삼각방정식의 근이 되는 함수이다.
- **단위원**: 반지름이 1인 원 위에서 삼각함수의 값을 $x$좌표와 $y$좌표로 시각화하여 방정식을 풀 수 있게 한다.
