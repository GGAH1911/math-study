# 초월방정식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

초월방정식이란 $x$의 거듭제곱과 사칙연산만으로 나타낼 수 없는 방정식을 말합니다. 즉, 지수함수, 로그함수, 삼각함수, 역삼각함수 등 **초월함수**를 포함하는 방정식입니다. 일반적으로 $f(x) = 0$ 형태에서 $f(x)$가 초월함수를 포함하면 초월방정식입니다.

## 직관/기하적 의미

대수방정식(예: $x^3 - 2x + 1 = 0$)과 달리, 초월방정식은 **폐쇄형 해를 일반적으로 구할 수 없습니다**. 예를 들어 $\sin x = x/2$의 해는 계산 공식이 없으므로 그래프나 수치해석으로만 찾을 수 있습니다. 기하학적으로는 두 곡선 $y = \sin x$와 $y = x/2$의 교점의 $x$ 좌표가 해가 됩니다.

중근삼각함수 방정식 $\tan x = x$ (단, $x \neq \frac{\pi}{2} + n\pi$), 지수로그 방정식 $2^x = x + 3$ 등이 초월방정식입니다. 수능에서는 주로 삼각함수와 지수/로그가 섞인 형태가 출제됩니다.

## 한 줄 예

$\sin x = \frac{1}{2}$는 초등적으로 풀 수 있는 초월방정식이고 ($x = \frac{\pi}{6} + 2n\pi$ 또는 $x = \frac{5\pi}{6} + 2n\pi$), $\sin x = x - 1$처럼 두 초월함수가 결합되면 보통 수치적 방법으로만 근삿값을 구합니다. (sympy: `from sympy import *; nsolve(sin(x) - (x - 1), 1)`)
