# 초월방정식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
초월함수를 포함하여 일반적인 대수적 연산만으로는 해를 구할 수 없는 방정식을 의미합니다.

## 본문
초월방정식이란 $x$의 거듭제곱과 사칙연산만으로 나타낼 수 없는 방정식을 말합니다. 즉, 지수함수, 로그함수, 삼각함수, 역삼각함수 등 초월함수를 포함하는 방정식입니다. 일반적으로 $f(x) = 0$ 형태에서 $f(x)$가 초월함수를 포함하면 초월방정식으로 분류합니다.

### 직관과 기하적 의미
대수방정식(예: $x^3 - 2x + 1 = 0$)과 달리, 초월방정식은 폐쇄형 해를 일반적으로 구할 수 없습니다. 예를 들어 $\sin x = x/2$의 해는 계산 공식이 없으므로 그래프나 수치해석으로만 찾을 수 있습니다. 기하학적으로는 두 곡선 $y = \sin x$와 $y = x/2$의 교점의 $x$ 좌표가 해가 됩니다.

### 기본 성질
중근삼각함수 방정식인 $\tan x = x$ (단, $x \neq \tfrac{\pi}{2} + n\pi$)나 지수로그 방정식인 $2^x = x + 3$ 등이 대표적인 초월방정식입니다. 수능 수학에서는 주로 삼각함수와 지수 또는 로그함수가 결합된 형태가 자주 출제됩니다. $\sin x = \tfrac{1}{2}$처럼 특수각을 이용해 초등적으로 풀 수 있는 경우도 있지만, $\sin x = x - 1$처럼 서로 다른 초월함수가 결합되면 보통 수치적 방법을 통해 근삿값을 구해야 합니다.

## 학습 체크
- 방정식에 포함된 함수가 지수, 로그, 삼각함수 중 하나라도 포함되어 있는가?
- 주어진 방정식의 해를 대수적인 공식(근의 공식 등)만으로 구할 수 있는가?
- 그래프를 그렸을 때 두 함수의 교점이 방정식의 해와 일치하는가?

## 관련 개념
- **삼각함수**: 삼각함수를 포함하는 방정식은 대표적인 초월방정식의 한 종류입니다.
- **지수함수**: 지수함수와 다항함수가 결합된 형태는 대수적으로 해를 구하기 어려운 초월방정식이 됩니다.
- **로그함수**: 로그함수가 포함된 방정식 역시 초월함수의 성질을 가지므로 초월방정식에 해당합니다.
