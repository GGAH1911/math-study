# 삼각함수의 활용

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

삼각함수의 활용은 **기본 삼각함수($\sin x$, $\cos x$, $\tan x$)와 삼각함수 공식을 이용하여 실제 기하학적·물리적 문제를 해결하는 방법**입니다. 주요 활용 도구는:

- **삼각함수의 합성**: $a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \phi)$ (단, $\cos \phi = \frac{a}{\sqrt{a^2+b^2}}$)
- **각의 합과 차 공식**: $\sin(A \pm B)$, $\cos(A \pm B)$ 등
- **정현·코사인 법칙**: 삼각형의 변과 각의 관계
- **삼각형의 넓이**: $\text{넓이} = \frac{1}{2}ab\sin C$

## 직관과 기하적 의미

삼각함수는 **주기적이고 진동하는 현상을 수식으로 표현**합니다. 합성 공식을 사용하면 복잡한 파동을 진폭과 위상이 명확한 단일 정현파로 변환할 수 있으므로, 최댓값·최솟값·주기를 한눈에 파악할 수 있습니다. 정현·코사인 법칙은 삼각형의 한 꼭짓점에서 변의 길이나 대각을 모르는 상황에서 미지의 변이나 각을 구할 때 필수 도구입니다.

## 한 줄 예

$2\sin x + \sqrt{3}\cos x$를 합성하면 $\sqrt{7}\sin(x + \phi)$ 형태가 되어 진폭이 $\sqrt{7}$임을 바로 알 수 있습니다. (검증: `sqrt((2**2 + (√3)**2))` = $\sqrt{7}$)
