# 삼각함수의 활용

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
기본 삼각함수와 공식을 활용하여 삼각형의 변과 각 사이의 관계를 파악하고, 복잡한 파동을 단순화하여 기하학적·물리적 문제를 해결하는 방법입니다.

## 본문
삼각함수의 활용은 기본 삼각함수인 $\sin x$, $\cos x$, $\tan x$와 관련 공식들을 도구로 삼아 실제 기하학적 상황이나 물리적 현상을 수학적으로 해결하는 과정입니다. 이는 단순히 삼각비의 값을 구하는 것을 넘어, 삼각형의 구성 요소들 사이의 복잡한 관계를 수식화하는 데 목적이 있습니다. 주요 도구로는 두 삼각함수의 합을 하나의 삼각함수로 통합하는 삼각함수의 합성, 각의 합과 차를 다루는 각의 합과 차 공식, 그리고 삼각형의 변과 각 사이의 관계를 정의하는 정현·코사인 법칙이 있습니다. 또한 삼각형의 두 변과 그 사이각을 알 때 넓이를 구할 수 있는 공식도 포함됩니다.

### 직관과 기하적 의미
삼각함수는 주기성을 가지며 진동하는 현상을 수식으로 나타내는 강력한 도구입니다. 특히 삼각함수의 합성을 활용하면 여러 개의 파동이 섞인 복잡한 형태를 진폭과 위상이 명확한 하나의 정현파로 변환할 수 있습니다. 이를 통해 파동의 최댓값, 최솟값, 주기를 직관적으로 파악할 수 있습니다. 또한 정현·코사인 법칙은 삼각형의 모든 정보가 주어지지 않은 상황에서도 미지의 변이나 각을 찾아낼 수 있게 해주는 기하학적 열쇠 역할을 합니다.

### 기본 성질
- **삼각함수의 합성**: $a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \phi)$ (단, $\cos \phi = \tfrac{a}{\sqrt{a^2+b^2}}$)
- **각의 합과 차 공식**: $\sin(A \pm B)$, $\cos(A \pm B)$ 등의 관계식
- **정현·코사인 법칙**: 삼각형의 변의 길이와 각 사이의 관계를 규정
- **삼각형의 넓이**: $\text{넓이} = \tfrac{1}{2}ab\sin C$

## 학습 체크
- 삼각함수의 합성을 통해 얻은 결과식에서 진폭과 위상을 어떻게 추출할 수 있는가?
- 주어진 삼각형의 정보(변 또는 각)에 따라 정현법칙과 코사인법칙 중 어떤 것을 적용하는 것이 효율적인가?
- 두 각의 합과 차 공식을 이용하여 특수각이 아닌 각의 삼각함수 값을 구할 수 있는가?

## 관련 개념
- **이차곡선**: 삼각함수의 활용을 통해 좌표평면 위에서 이차곡선의 매개변수 표현이나 기하학적 성질을 분석할 때 유용하게 연결됩니다.
