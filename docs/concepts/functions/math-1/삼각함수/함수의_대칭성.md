# 함수의 대칭성

## 정확한 진술

함수 $f(x)$가 다음 두 조건 중 하나를 만족할 때 **대칭성**을 갖는다고 합니다.

**짝함수(even function)**: 정의역의 모든 $x$에 대해 $f(-x) = f(x)$

**홀함수(odd function)**: 정의역의 모든 $x$에 대해 $f(-x) = -f(x)$

이 조건들은 함수의 입력을 음수로 바꿨을 때 출력값이 어떻게 변하는지를 엄밀히 정의합니다.

## 직관과 기하적 의미

**짝함수의 그래프**: $y$축을 중심으로 **좌우 대칭**입니다. 점 $(a, f(a))$가 그래프에 있으면 점 $(-a, f(a))$도 있으므로, $y$축의 왼쪽과 오른쪽이 정확히 같은 모양입니다.

**홀함수의 그래프**: **원점을 중심으로 점대칭**입니다. 원점 주위로 180도 회전했을 때 같은 모양이 됩니다. 점 $(a, f(a))$가 있으면 점 $(-a, -f(a))$도 있으며, 이는 $(a, f(a))$를 원점을 통해 정반대로 이동한 위치입니다.

## 주요 예시

**짝함수들**:
- $f(x) = x^2$: $f(-x) = (-x)^2 = x^2 = f(x)$ ✓
- $f(x) = \cos x$: $\cos(-x) = \cos x$ ✓
- $f(x) = |x|$: $|-x| = |x|$ ✓

**홀함수들**:
- $f(x) = x^3$: $f(-x) = (-x)^3 = -x^3 = -f(x)$ ✓
- $f(x) = \sin x$: $\sin(-x) = -\sin x$ ✓
- $f(x) = x$: $f(-x) = -x = -f(x)$ ✓

**주의**: 모든 함수가 짝함수나 홀함수는 아닙니다. $f(x) = x^2 + x$는 $f(-x) = x^2 - x \neq f(x)$이고 $\neq -f(x)$이므로 대칭성이 없습니다.
