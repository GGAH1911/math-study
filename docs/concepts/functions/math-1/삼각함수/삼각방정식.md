### 정확한 진술

삼각방정식이란 **미지수에 대해 삼각함수가 포함된 방정식**입니다. 예를 들어 $\sin x = \frac{1}{2}$, $\cos 2x + 1 = 0$, $\tan x = \sqrt{3}$ 같은 형태입니다. 일반적으로 $\sin x = a$, $\cos x = b$, $\tan x = c$ (단, $|a|, |b| \leq 1$) 또는 이들의 조합으로 나타납니다.

### 직관/기하적 의미

삼각방정식을 푼다는 것은 **특정 삼각함수값을 갖는 모든 각도를 찾는 것**입니다. 단위원 위에서 생각하면:
- $\sin x = a$를 푼다 = y좌표가 $a$인 점들의 각도를 모두 찾기
- $\cos x = b$를 푼다 = x좌표가 $b$인 점들의 각도를 모두 찾기

**핵심**: 삼각함수는 주기함수이므로, 삼각방정식의 해는 **무수히 많습니다**. 따라서 일반적으로:
1. 먼저 한 주기($0 \leq x < 2\pi$ 또는 $-\pi < x \leq \pi$) 내의 모든 해를 찾고
2. 주기성 $\sin(x + 2\pi) = \sin x$ 등을 이용해 **일반해**를 표현합니다.

### 한 줄 예

$\sin x = \frac{1}{2}$를 풀면, 한 주기 $[0, 2\pi)$ 내에서 $x = \frac{\pi}{6}$ 또는 $x = \frac{5\pi}{6}$이고, **일반해**는 $x = \frac{\pi}{6} + 2n\pi$ 또는 $x = \frac{5\pi}{6} + 2n\pi$ (단, $n \in \mathbb{Z}$)입니다.
