# 삼각방정식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각방정식이란 미지수에 삼각함수가 포함된 방정식으로, 삼각함수의 주기성을 고려하여 특정 함숫값을 갖는 모든 각도를 찾는 과정입니다.

## 본문
삼각방정식이란 미지수에 대해 삼각함수가 포함된 방정식을 의미합니다. 대표적인 형태로는 $\sin x = a$, $\cos x = b$, $\tan x = c$와 같이 단일 삼각함수가 포함된 형태나, $\cos 2x + 1 = 0$처럼 여러 삼각함수가 조합된 형태가 있습니다. 이때 $\sin x = a$ 또는 $\cos x = b$의 경우, 해가 존재하기 위한 조건으로 $|a| \leq 1$, $|b| \leq 1$을 만족해야 합니다.

### 직관과 기하적 의미
삼각방정식을 푸는 과정은 단위원 위에서 특정 좌표를 갖는 점의 각도를 찾는 것과 같습니다. $\sin x = a$를 푸는 것은 단위원 위에서 $y$좌표가 $a$인 점들의 각도를 찾는 것이며, $\cos x = b$를 푸는 것은 $x$좌표가 $b$인 점들의 각도를 찾는 것과 같습니다.

### 기본 성질
삼각함수는 주기함수이기 때문에 삼각방정식의 해는 일반적으로 무수히 많습니다. 따라서 문제를 풀 때는 먼저 주어진 범위(예: $0 \leq x < 2\pi$) 내에서 모든 해를 구한 뒤, 삼각함수의 주기성을 이용하여 모든 해를 포괄할 수 있는 일반해의 형태로 표현해야 합니다.

## 학습 체크
- 주어진 범위 내에서 삼각함수의 값이 특정 상수가 되는 각도가 몇 개 존재하는지 확인했는가?
- 삼각함수의 주기성을 이용하여 무수히 많은 해를 일반해의 형태로 올바르게 표현했는가?
- $\sin x$나 $\cos x$의 값이 $-1$과 $1$ 사이의 범위에 있는지 확인했는가?

## 관련 개념
- **삼각함수**: 삼각방정식의 미지수가 포함된 함수로서, 방정식의 해를 결정하는 핵심적인 역할을 합니다.
- **단위원**: 삼각함수의 값을 좌표로 시각화하여 방정식의 해를 기하학적으로 찾는 도구가 됩니다.
- **주기성**: 삼각방정식의 해가 무수히 많음을 설명하며, 일반해를 도출하는 근거가 됩니다.
