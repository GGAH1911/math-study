# 교점과 기울기

## 교점과 기울기의 정의

두 직선 또는 곡선이 만나는 점을 **교점**이라 하며, 한 직선이 $x$축과 이루는 각을 $\theta$라 할 때, 그 직선의 **기울기**는 $m = \tan\theta$로 정의됩니다. 두 점 $(x_1, y_1)$과 $(x_2, y_2)$를 지나는 직선의 기울기는 $m = \frac{y_2 - y_1}{x_2 - x_1}$입니다.

## 기하적 의미

기울기는 직선의 "경사 정도"를 수치화한 것입니다. 기울기가 양수면 오른쪽 위로 올라가고, 음수면 오른쪽 아래로 내려갑니다. 삼각함수 관점에서 기울기 $m = \tan\theta$는 각 $\theta$의 탄젠트값이므로, **기울기는 곧 직선의 각도**를 나타냅니다.

교점은 두 직선의 방정식을 동시에 만족하는 좌표입니다. 기하학적으로, 교점에서 두 직선이 만나며, 그 점에서 각 직선의 기울기는 서로 다릅니다(일반적으로). 두 직선이 수직일 때는 기울기의 곱이 $m_1 \cdot m_2 = -1$을 만족합니다.

## 기본 예제

직선 $y = 2x + 1$과 $y = -x + 4$의 교점을 구하면:
$$2x + 1 = -x + 4$$
$$3x = 3, \quad x = 1$$
$$y = 2(1) + 1 = 3$$

따라서 교점은 $(1, 3)$입니다. 첫 번째 직선의 기울기는 $2$, 두 번째 직선의 기울기는 $-1$이므로, 두 기울기의 곱은 $2 \times (-1) = -2 \neq -1$이므로 두 직선은 수직이 아닙니다.
