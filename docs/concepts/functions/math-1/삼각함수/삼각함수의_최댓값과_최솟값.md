# 삼각함수의 최댓값과 최솟값

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 정확한 진술

삼각함수 $f(x) = a\sin(bx + c) + d$ (단, $a \neq 0$, $b > 0$) 의 **최댓값**은 $|a| + d$ 이고 **최솟값**은 $-|a| + d$ 이다. 코사인 함수 $g(x) = a\cos(bx + c) + d$ 도 동일한 규칙을 따른다.

## 직관/기하적 의미

$\sin x$ 와 $\cos x$ 는 $-1$ 부터 $1$ 사이의 값만을 가진다는 것이 핵심이다. 따라서:
- 진폭(amplitude) $|a|$ 를 곱하면 함숫값의 범위는 $[-|a|, |a|]$ 로 $|a|$ 배 확대된다.
- 수직 이동 $d$ 를 더하면 전체 범위가 $[-|a| + d, |a| + d]$ 로 위아래로 이동한다.
- 수평 이동 $c$ 와 각주파수 $b$ 는 **최댓값과 최솟값의 크기를 바꾸지 않는다**—이들은 최댓값이 나타나는 위치만 바꿀 뿐이다.

그래프 관점에서, 삼각함수는 주기적으로 진동하므로, 한 주기 동안 반드시 최댓값과 최솟값에 도달한다. 예를 들어 $y = 2\sin x + 3$ 의 그래프는 $y = 3$ 을 중심으로 위아래로 $2$ 만큼 진동한다.

## 한 줄 예

$y = 2\sin(3x - \frac{\pi}{4}) - 1$ 의 최댓값은 $2 + (-1) = 1$ 이고 최솟값은 $-2 + (-1) = -3$ 이다. (검증: `from sympy import sin, symbols, diff; x = symbols('x'); f = 2*sin(3*x - 3.14159/4) - 1`)
