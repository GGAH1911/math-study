# 삼각함수의 최댓값과 최솟값

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각함수 $f(x) = a\sin(bx + c) + d$의 최댓값은 $|a| + d$이고 최솟값은 $-|a| + d$이다.

## 본문
삼각함수 $f(x) = a\sin(bx + c) + d$ (단, $a \neq 0$, $b > 0$)의 최댓값은 $|a| + d$이며, 최솟값은 $-|a| + d$이다. 코사인 함수 $g(x) = a\cos(bx + c) + d$ 역시 동일한 규칙을 적용하여 최댓값과 최솟값을 구할 수 있다.

### 직관과 기하적 의미
$\sin x$와 $\cos x$의 치역이 $[-1, 1]$이라는 점이 핵심이다. 계수 $a$의 절댓값인 진폭 $|a|$를 곱하면 함숫값의 범위가 $[-|a|, |a|]$로 확대되며, 여기에 수직 이동량 $d$를 더하면 전체 범위가 $[-|a| + d, |a| + d]$로 위아래로 이동한다. 이때 수평 이동을 결정하는 $c$와 주기를 결정하는 $b$는 함수의 최댓값과 최솟값의 크기에는 영향을 주지 않으며, 오직 최댓값과 최솟값이 나타나는 $x$의 위치만 변화시킨다. 그래프 관점에서 삼각함수는 주기적으로 진동하므로, 한 주기 내에서 반드시 최댓값과 최솟값에 도달하게 된다.

### 기본 성질
- 진폭 $|a|$는 그래프의 높낮이 변화 폭을 결정한다.
- 수직 이동 $d$는 그래프의 중심축을 결정한다.
- $b$와 $c$는 최댓값과 최솟값의 크기에 영향을 주지 않는다.

## 학습 체크
- $a$의 부호가 양수일 때와 음수일 때 최댓값과 최솟값 공식이 어떻게 적용되는지 이해했는가?
- 수평 이동과 주기 변화가 함수의 최댓값/최솟값 값 자체를 변화시키지 않는 이유를 설명할 수 있는가?
- 주어진 삼각함수 식에서 $a$와 $d$를 찾아 최댓값과 최솟값을 정확히 계산할 수 있는가?

## 관련 개념
- **삼각함수**: 삼각함수의 기본 치역인 $[-1, 1]$을 바탕으로 함수의 변형과 최댓값, 최솟값이 결정된다.
