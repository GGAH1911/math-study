# 근의 최댓값과 최솟값

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
주어진 범위 내에서 삼각방정식의 해 중 가장 큰 값을 근의 최댓값, 가장 작은 값을 근의 최솟값이라 합니다.

## 본문
삼각방정식 또는 삼각부등식을 주어진 범위 내에서 풀 때, 모든 해 중에서 가장 큰 값을 근의 최댓값, 가장 작은 값을 근의 최솟값이라 합니다. 예를 들어 $\sin x = \frac{1}{2}$를 $0 \le x < 2\pi$ 범위에서 풀면 $x = \frac{\pi}{6}$ 또는 $x = \frac{5\pi}{6}$이므로, 근의 최솟값은 $\frac{\pi}{6}$, 최댓값은 $\frac{5\pi}{6}$이 됩니다.

### 직관과 기하적 의미
삼각함수는 주기성을 가지므로 범위를 정하지 않으면 해가 무수히 많아져 최댓값과 최솟값을 정의할 수 없습니다. 따라서 문제에서 제시된 범위가 최댓값과 최솟값을 결정하는 핵심 조건이 됩니다. 좌표평면에서 보면, 삼각함수 그래프와 수평선이 만나는 교점 중 지정된 구간에 속하는 점들의 $x$좌표가 근이며, 그중 구간 내에서 가장 오른쪽에 있는 값이 최댓값, 가장 왼쪽에 있는 값이 최솟값이 됩니다. 수능에서는 이 값들의 합, 차, 곱을 구하거나 주어진 범위 내 근의 개수를 파악하는 문제로 자주 출제됩니다.

### 기본 성질
- 범위가 제한되지 않은 삼각방정식은 일반적으로 근의 최댓값과 최솟값을 정의할 수 없습니다.
- 근의 최댓값과 최솟값은 문제에서 주어진 구간의 경계값과 일치할 수도 있고, 구간 내부의 해가 될 수도 있습니다.

## 학습 체크
- 삼각방정식을 풀 때 문제에서 제시한 구간($0 \le x < 2\pi$ 등)을 반드시 확인하였는가?
- 구한 해들 중에서 구간에 포함되지 않는 값이 있지는 않은가?
- 최댓값과 최솟값을 구한 후, 문제에서 요구하는 연산(합, 차, 곱 등)을 정확히 수행하였는가?

## 관련 개념
- **삼각함수**: 함수의 주기성과 대칭성을 이해해야 주어진 범위 내에서 모든 해를 빠짐없이 찾을 수 있습니다.
- **삼각방정식**: 근의 최댓값과 최솟값을 구하기 위한 기초 단계로, 방정식의 해를 구하는 과정이 선행되어야 합니다.
