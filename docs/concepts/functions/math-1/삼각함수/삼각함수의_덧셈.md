# 삼각함수의 덧셈

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
두 각의 합에 대한 삼각함수 값을 각각의 삼각함수 값들의 조합으로 나타내는 공식입니다.

## 본문
두 각 $A, B$에 대하여 다음의 삼각함수 덧셈 정리가 성립합니다.
$$\sin(A+B) = \sin A \cos B + \cos A \sin B$$
$$\cos(A+B) = \cos A \cos B - \sin A \sin B$$
$$\tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$$

또한, 뺄셈 공식은 위 공식에서 $B$ 대신 $-B$를 대입하여 다음과 같이 유도됩니다.
$$\sin(A-B) = \sin A \cos B - \cos A \sin B$$
$$\cos(A-B) = \cos A \cos B + \sin A \sin B$$
$$\tan(A-B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$$

### 직관과 기하적 의미
이 공식은 두 각의 합인 $A+B$에 해당하는 삼각함수 값을 각각의 삼각함수 값으로 분해하여 표현한 것입니다. 단위원 위에서 각도 $A$만큼 회전한 점과 각도 $B$만큼 회전한 점을 결합했을 때 나타나는 새로운 위치를 대수적으로 나타낸 것이라 이해할 수 있습니다. 즉, 덧셈 공식은 각도 합성이라는 기하학적 회전 구조를 수식으로 옮긴 결과물입니다. 또한 직각삼각형의 변의 길이 관계를 통해 $\sin(A+B)$가 각 성분의 기여도를 합친 것임을 확인할 수 있습니다.

### 기본 성질
- $\sin$의 덧셈 공식은 두 항의 부호가 같고, $\cos$의 덧셈 공식은 두 항의 부호가 반대입니다.
- $\tan$의 덧셈 공식은 분자에는 각의 합이, 분모에는 각의 차가 나타나는 구조를 가집니다.
- $\sin 75^\circ$를 구할 때처럼 특수각의 합으로 각을 분해하여 복잡한 각의 삼각함수 값을 계산할 때 유용하게 사용됩니다.

## 학습 체크
- $\sin(A+B)$와 $\cos(A+B)$ 공식에서 부호가 서로 다르게 나타나는 이유를 기하학적으로 설명할 수 있는가?
- $\tan(A+B)$ 공식의 분모가 $0$이 되는 경우, 즉 $\tan A \tan B = 1$인 상황에서 어떤 일이 발생하는가?

## 관련 개념
- **삼각함수**: 각의 크기에 따라 변하는 삼각비의 성질을 다루며, 덧셈 공식은 이 함수들의 연산을 가능하게 하는 핵심 도구입니다.
- **단위원**: 좌표평면 위에서 반지름이 $1$인 원을 통해 삼각함수의 값을 정의하며, 덧셈 공식의 기하학적 원리를 제공합니다.
