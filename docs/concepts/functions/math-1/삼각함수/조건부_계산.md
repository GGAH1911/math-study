# 조건부 계산

## 정확한 진술

삼각함수의 **조건부 계산**은 주어진 조건(범위, 특정 값, 관계식 등)을 만족하는 상황에서 다른 삼각함수의 값을 유일하게 결정하고 구하는 과정입니다. 예를 들어 $\sin\theta$의 값과 $\theta$의 범위가 주어질 때, $\cos\theta$와 $\tan\theta$를 구하는 것이 조건부 계산입니다.

## 직관 및 중요성

삼각함수는 하나의 값(예: $\sin\theta$)만으로는 결정되지 않습니다. 같은 사인값을 가지는 각도는 무수히 많기 때문입니다. 하지만 **범위 조건**(예: $0 < \theta < \pi$)을 추가하면 유일하게 결정됩니다. 

기하학적으로는 단위원 위의 점에서 $y$좌표만 알면 여러 위치가 가능하지만, "$\theta$가 제1사분면"이라는 조건이 추가되면 정확히 하나의 위치가 정해집니다. 이렇게 조건들을 조합하여 삼각함수값들을 체계적으로 구하는 것이 조건부 계산의 핵심입니다.

## 대표 예시

$\sin\theta = \frac{3}{5}$이고 $\frac{\pi}{2} < \theta < \pi$ (제2사분면)일 때, $\cos\theta$를 구해봅시다.

피타고라스 항등식 $\sin^2\theta + \cos^2\theta = 1$에서:
$$\cos^2\theta = 1 - \sin^2\theta = 1 - \frac{9}{25} = \frac{16}{25}$$

따라서 $\cos\theta = \pm\frac{4}{5}$입니다. 그런데 $\theta$가 제2사분면에 있으므로 $\cos\theta < 0$입니다. 

**조건에 의해** $\cos\theta = -\frac{4}{5}$로 유일하게 결정됩니다.

이때 $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{3/5}{-4/5} = -\frac{3}{4}$도 함께 구할 수 있습니다.

## 주의

조건이 없으면 무수한 답이 존재하고, 조건이 모순이면 해가 없습니다. 항상 **주어진 조건이 충분한지, 일관성이 있는지 먼저 확인**하세요.
