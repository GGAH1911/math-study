# 조건부 계산

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
주어진 조건(범위, 특정 값, 관계식 등)을 바탕으로 삼각함수의 값을 유일하게 결정하여 구하는 과정입니다.

## 본문
삼각함수의 조건부 계산은 주어진 조건인 범위, 특정 값, 또는 관계식 등을 만족하는 상황에서 다른 삼각함수의 값을 유일하게 결정하고 구하는 과정입니다. 예를 들어 $\sin\theta$의 값과 $\theta$의 범위가 주어졌을 때, 이를 바탕으로 $\cos\theta$와 $\tan\theta$를 구하는 것이 대표적인 조건부 계산의 사례입니다.

### 직관과 기하적 의미
삼각함수는 하나의 값만으로는 결과가 결정되지 않습니다. 같은 사인값을 가지는 각도는 무수히 많기 때문입니다. 기하학적으로 단위원 위에서 $y$좌표만 알면 점의 위치가 여러 곳이 될 수 있지만, "$\theta$가 제1사분면"과 같은 범위 조건이 추가되면 점의 위치가 정확히 하나로 정해집니다. 즉, 조건들을 조합하여 삼각함수값들을 체계적으로 찾아내는 것이 이 계산의 핵심입니다.

### 기본 성질
삼각함수 사이의 관계식인 피타고라스 항등식 $\sin^2\theta + \cos^2\theta = 1$ 등을 활용하여 값을 도출합니다. 이때 계산 결과로 나오는 값 중 하나를 선택할 때, 반드시 주어진 사분면의 위치에 따른 삼각함수의 부호를 고려해야 합니다. 만약 조건이 없다면 무수한 답이 존재할 수 있고, 조건 자체가 모순된다면 해가 존재하지 않을 수 있으므로 주어진 조건의 충분성과 일관성을 먼저 확인하는 것이 중요합니다.

## 학습 체크
- 주어진 각 $\theta$가 속한 사분면을 확인하여 삼각함수의 부호를 결정하였는가?
- 피타고라스 항등식을 사용하여 구하고자 하는 삼각함수의 제곱값을 정확히 계산하였는가?
- 계산된 값 중 조건에 부합하는 유일한 값을 선택하였는가?

## 관련 개념
- **삼각함수**: 각의 크기와 변의 길이 사이의 관계를 나타내며, 조건부 계산을 통해 구하고자 하는 대상이 됩니다.
- **사분면**: 각의 범위를 나타내며, 삼각함수의 부호를 결정하여 계산 결과의 유일성을 보장하는 역할을 합니다.
- **피타고라스 항등식**: $\sin^2\theta + \cos^2\theta = 1$과 같이 서로 다른 삼각함수 사이의 관계를 연결하여 값을 계산할 때 사용됩니다.
