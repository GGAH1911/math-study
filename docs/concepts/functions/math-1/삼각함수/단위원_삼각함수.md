# 단위원 삼각함수

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
각 $\theta$에 대하여 단위원 위의 점 $P$의 좌표를 $(\cos\theta, \sin\theta)$로 정의한다.

## 본문
원점을 중심으로 하고 반지름이 $1$인 원을 단위원이라 합니다. 양의 $x$축 방향에서 반시계 방향으로 각도 $\theta$만큼 회전한 위치에 있는 단위원 위의 점 $P$의 좌표를 $(\cos\theta, \sin\theta)$로 정의합니다. 즉, 각 $\theta$에 대응하는 점 $P = (\cos\theta, \sin\theta)$입니다.

### 직관과 기하적 의미
이 정의를 통해 삼각함수는 각도를 좌표로 변환하는 함수가 됩니다. 각 $\theta$를 단위원 위의 회전으로 이해하면, 수평 거리인 $x$좌표는 $\cos\theta$가 되고 수직 거리인 $y$좌표는 $\sin\theta$가 됩니다. 이러한 정의는 직각삼각형을 이용한 정의와 달리 음의 각도나 $360^\circ$를 초과하는 각에 대해서도 삼각함수를 일관되게 확장할 수 있게 해줍니다.

### 기본 성질
단위원 위의 점 $P$는 항상 반지름이 $1$인 원의 방정식 위에 존재하므로, $\cos^2\theta + \sin^2\theta = 1$이라는 항등식이 성립합니다. 이는 삼각함수의 가장 기초적인 성질이며 기하학적으로 원의 방정식에서 유도됩니다. 예를 들어 $\theta = 60^\circ$일 때, 점 $P$의 좌표는 $\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$이며, 두 좌표의 제곱의 합은 $1$이 됩니다.

## 학습 체크
- 단위원 위의 점의 좌표를 $\cos\theta$와 $\sin\theta$를 사용하여 표현할 수 있는가?
- $\cos^2\theta + \sin^2\theta = 1$이 성립함을 단위원의 방정식과 연결하여 설명할 수 있는가?
- 음의 각이나 $360^\circ$를 넘는 각에 대해서도 삼각함수의 값을 구할 수 있는가?

## 관련 개념
- **삼각함수**: 단위원의 좌표를 통해 각도에 따른 함숫값을 정의하며, 이를 통해 삼각함수의 범위를 실수 전체로 확장합니다.
