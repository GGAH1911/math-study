# 각의 조건

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
두 각의 삼각함수 값이 같을 때, 각 사이의 관계를 나타내는 조건입니다.

## 본문
두 각이 같은 삼각함수 값을 가질 조건을 **각의 조건**이라 합니다. $\alpha$와 $\beta$에 대해 다음과 같은 관계가 성립합니다.

$$\sin\alpha = \sin\beta \iff \alpha = \beta + 360°k \text{ 또는 } \alpha = 180° - \beta + 360°k \quad (k \in \mathbb{Z})$$

$$\cos\alpha = \cos\beta \iff \alpha = \pm\beta + 360°k \quad (k \in \mathbb{Z})$$

$$\tan\alpha = \tan\beta \iff \alpha = \beta + 180°k \quad (k \in \mathbb{Z})$$

### 직관과 기하적 의미
단위원 위에서 생각하면 각의 조건의 의미가 명확합니다. 사인이 같다는 것은 두 점의 $y$좌표가 같다는 뜻이므로, 한 점은 각 $\beta$에서, 다른 한 점은 각 $\beta$의 $x$축 대칭인 위치에 있거나 여러 바퀴 돌아간 위치에 있다는 뜻입니다. 코사인이 같으면 $x$좌표가 같으므로 각 $\beta$나 각 $-\beta$에서만 같은 값을 가집니다. 탄젠트는 원점을 지나는 직선의 기울기이므로, 정반대 방향인 각 $\beta + 180°$에서도 같은 값을 가집니다.

### 기본 성질
$\sin 30° = \sin 150°$인 이유는 $150° = 180° - 30°$이기 때문이며, 일반적으로 모든 정수 $k$에 대해 $\sin(30° + 360°k) = \sin(150° + 360°k) = 0.5$가 성립합니다.

## 학습 체크
- 사인 값이 같을 때, 두 각이 $x$축 대칭 관계에 있는지 확인했는가?
- 코사인 값이 같을 때, 각의 부호($\pm$)를 고려하여 일반해를 구했는가?
- 탄젠트 값이 같을 때, 주기가 $180°$임을 이용하여 정반대 방향의 각을 고려했는가?

## 관련 개념
- **삼각비**: 각의 크기에 따라 결정되는 삼각함수 값의 기초가 되며, 각의 조건은 이 삼각비가 반복되는 원리를 설명합니다.
