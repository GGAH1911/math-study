# 기본 삼각함수 항등식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
모든 각 $\theta$에 대하여 성립하는 삼각함수 사이의 관계식으로, 복잡한 식을 단순화하는 데 필수적입니다.

## 본문
기본 삼각함수 항등식은 모든 각 $\theta$에 대해 항상 성립하는 항등식입니다. 대표적인 세 가지 식은 다음과 같습니다.
$$\sin^2\theta + \cos^2\theta = 1$$
$$1 + \tan^2\theta = \sec^2\theta$$
$$1 + \cot^2\theta = \csc^2\theta$$

### 직관과 기하적 의미
첫 번째 항등식은 단위원의 기하학적 성질에서 비롯됩니다. 반지름이 1인 단위원 위의 한 점을 각 $\theta$만큼 회전한 위치로 나타내면, 그 점의 좌표는 $(\cos\theta, \sin\theta)$가 됩니다. 이 점은 항상 원점으로부터 거리가 1이므로, 피타고라스 정리에 의해 $\cos^2\theta + \sin^2\theta = 1^2 = 1$이 성립하게 됩니다.

두 번째와 세 번째 항등식은 첫 번째 항등식으로부터 유도됩니다. 예를 들어 $\sin^2\theta + \cos^2\theta = 1$의 양변을 $\cos^2\theta$로 나누면 $\tan^2\theta + 1 = \sec^2\theta$를 얻을 수 있으며, 마찬가지로 $\sin^2\theta + \cos^2\theta = 1$의 양변을 $\sin^2\theta$로 나누면 $1 + \cot^2\theta = \csc^2\theta$를 얻을 수 있습니다.

### 기본 성질
이 항등식들은 삼각함수 간의 유기적인 관계를 나타내며, 복잡한 삼각함수 식을 간단히 변형하거나 특정 삼각함수의 값을 구할 때 핵심적인 도구로 사용됩니다. 예를 들어 $\theta = 60^\circ$일 때 $\sin 60^\circ = \frac{\sqrt{3}}{2}$이고 $\cos 60^\circ = \frac{1}{2}$이므로, $(\frac{\sqrt{3}}{2})^2 + (\frac{1}{2})^2 = \frac{3}{4} + \frac{1}{4} = 1$이 되어 항등식이 성립함을 확인할 수 있습니다.

## 학습 체크
- $\sin^2\theta + \cos^2\theta = 1$ 식을 이용하여 $\cos\theta$의 값을 알 때 $\sin\theta$의 값을 구할 수 있는가?
- $\tan^2\theta$와 $\sec^2\theta$ 사이의 관계식을 유도할 수 있는가?

## 관련 개념
- **삼각함수**: 각도에 따른 삼각비의 값을 나타내는 함수로, 기본 항등식은 이 함수들 사이의 관계를 정의합니다.
