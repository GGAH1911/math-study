# 삼각함수의 부호

## 정의

각 $\theta$를 나타내는 반직선이 단위원과 만나는 점의 좌표가 $(\cos\theta, \sin\theta)$일 때, 이 점이 속한 사분면에 따라 삼각함수 값의 부호가 결정됩니다.

**사분면별 부호:**
- **제1사분면** ($0° < \theta < 90°$): $\sin\theta > 0$, $\cos\theta > 0$, $\tan\theta > 0$
- **제2사분면** ($90° < \theta < 180°$): $\sin\theta > 0$, $\cos\theta < 0$, $\tan\theta < 0$
- **제3사분면** ($180° < \theta < 270°$): $\sin\theta < 0$, $\cos\theta < 0$, $\tan\theta > 0$
- **제4사분면** ($270° < \theta < 360°$): $\sin\theta < 0$, $\cos\theta > 0$, $\tan\theta < 0$

## 기하적 의미

단위원 위의 점 $(\cos\theta, \sin\theta)$의 부호는 좌표축의 어느 쪽에 있는지로 결정됩니다.

- 점의 **y좌표**가 $\sin\theta$: y축 위쪽(제1, 2사분면)에서 양수, 아래쪽(제3, 4사분면)에서 음수
- 점의 **x좌표**가 $\cos\theta$: x축 오른쪽(제1, 4사분면)에서 양수, 왼쪽(제2, 3사분면)에서 음수  
- $\tan\theta = \frac{\sin\theta}{\cos\theta}$: 분자와 분모가 **같은 부호**(제1, 3사분면)일 때 양수, **다른 부호**(제2, 4사분면)일 때 음수

## 예

$\theta = 150°$(제2사분면)일 때 부호를 판단하세요.

**풀이:** $150°$는 y축 왼쪽 위에 있으므로:
$$\sin 150° = \sin(180° - 30°) = \sin 30° = \frac{1}{2} > 0 \checkmark$$
$$\cos 150° = \cos(180° - 30°) = -\cos 30° = -\frac{\sqrt{3}}{2} < 0 \checkmark$$
$$\tan 150° = \frac{\sin 150°}{\cos 150°} = \frac{1/2}{-\sqrt{3}/2} = -\frac{1}{\sqrt{3}} < 0 \checkmark$$

**핵심:** 삼각함수의 부호는 각의 정확한 크기가 아니라 **사분면**으로만 결정됩니다.
