# 삼각함수의 곱

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
두 삼각함수의 곱을 삼각함수의 합 또는 차의 형태로 변환하여 식을 단순화하는 공식입니다.

## 본문
두 삼각함수의 곱을 삼각함수의 합 또는 차로 표현하는 공식을 **곱-합 공식**이라 합니다. 이 공식은 곱 형태의 식을 합과 차의 형태로 바꾸어 주는 항등식으로, 다음과 같은 세 가지 핵심 식을 포함합니다.

$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$
$$\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$$
$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$

이 공식들은 고등학교 과정에서 배우는 삼각함수의 덧셈 정리로부터 유도되며, 복잡한 곱셈 형태를 다루기 쉬운 합과 차의 형태로 변환해 줍니다.

### 직관과 기하적 의미
삼각함수의 곱은 그 자체로 계산이 복잡할 수 있지만, 합과 차의 형태로 변환하면 덧셈 정리와 결합하거나 다른 삼각함수 공식과 연계하기가 매우 용이해집니다. 특히 물리학에서 두 파동이 만나는 간섭 현상을 분석할 때, 서로 다른 주파수를 가진 두 진동파의 곱을 각각의 성분으로 분해하여 분석하는 데 필수적인 도구가 됩니다.

### 기본 성질
이 공식은 정적분 계산에서 매우 강력한 위력을 발휘합니다. 예를 들어 $\int \sin(2x) \sin(3x) \, dx$와 같이 곱해진 형태의 함수를 적분해야 할 때, 곱-합 공식을 사용하여 합 또는 차의 형태로 먼저 변환하면 각각의 항을 매우 간단하게 적분할 수 있습니다.

## 학습 체크
- 곱-합 공식을 유도하기 위해 필요한 삼각함수의 덧셈 정리를 알고 있는가?
- 주어진 곱셈 형태의 식을 합 또는 차의 형태로 정확히 변환할 수 있는가?
- 정적분 문제에서 곱-합 공식이 어떻게 계산 과정을 단순화하는지 이해하고 있는가?

## 관련 개념
- **삼각함수**: 곱-합 공식은 삼각함수의 덧셈 정리로부터 유도되는 항등식이며, 삼각함수의 성질을 확장하여 다루는 개념입니다.
- **삼각함수의 덧셈 정리**: 곱-합 공식의 근간이 되는 원리로, 두 각의 합과 차에 대한 삼각함수 값을 구하는 공식입니다.
- **정적분**: 곱-합 공식을 통해 복잡한 삼각함수의 곱을 적분 가능한 합과 차의 형태로 변환하여 문제를 해결할 수 있습니다.
