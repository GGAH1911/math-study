# 매개변수 최적화

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
제약 조건이 있는 함수의 극값을 구하기 위해 변수들을 매개변수로 치환하여 단일 변수의 함수로 변환한 뒤 미분하는 최적화 기법입니다.

## 본문
매개변수 최적화는 제약 조건이 있는 함수의 최댓값 또는 최솟값을 구할 때, 변수들을 매개변수로 표현하여 함수를 단일 변수의 함수로 축약한 뒤 미분으로 극값을 찾는 기법입니다. 특히 삼각함수를 매개변수로 사용하면 원, 타원 같은 폐곡선 위의 점이나 각도 제약이 있는 도형에서 거리, 넓이, 길이의 극값을 효율적으로 구할 수 있습니다.

### 직관과 기하적 의미
원 위의 점 $(x, y)$를 $x = r\cos\theta$, $y = r\sin\theta$로 나타낼 수 있듯이, 제약 조건을 만족하는 점들의 좌표를 삼각함수로 표현하면 자유도가 줄어듭니다. 예를 들어 $x^2 + y^2 = 1$이라는 제약이 있으면 원 위의 모든 점을 하나의 매개변수 $\theta$ 하나로 표현할 수 있고, 원 위에서 어떤 식의 최댓값을 구하는 문제는 $f(\cos\theta, \sin\theta)$의 극값을 $\theta$에 대해 찾는 1변수 문제로 바뀝니다. 이는 라그랑주 승수법보다 계산이 간단하고, 기하학적으로는 제약 곡선 위를 움직일 때 목적함수가 최대 또는 최소가 되는 위치를 직관적으로 파악하게 해줍니다.

### 기본 성질
원 $x^2 + y^2 = 1$ 위의 점에서 직선 $2x + y$의 최댓값을 구하는 경우를 예로 들면, $x = \cos\theta$, $y = \sin\theta$로 치환하여 $f(\theta) = 2\cos\theta + \sin\theta$라는 단일 변수 함수를 만듭니다. 이를 삼각함수의 합성을 이용해 $f(\theta) = \sqrt{5}\sin(\theta + \alpha)$ (단, $\tan\alpha = 2$) 형태로 정리하면 최댓값이 $\sqrt{5}$임을 쉽게 알 수 있습니다.

## 학습 체크
- 제약 조건이 원이나 타원의 방정식 형태일 때 어떤 매개변수를 사용하는 것이 가장 효율적인가?
- 다변수 함수를 단일 변수 함수로 변환했을 때, 변환된 함수의 미분 가능성을 어떻게 확인하는가?
- 삼각함수의 합성을 통해 도출된 결과가 원래의 기하학적 상황과 일치하는가?

## 관련 개념
- **삼각함수**: 매개변수 $\theta$를 통해 좌표를 표현하거나 삼각함수의 합성을 이용하여 식을 단순화할 때 핵심적인 도구로 사용됩니다.
- **미분**: 매개변수로 축약된 단일 변수 함수의 극값을 찾기 위해 도함수를 구하고 $0$이 되는 지점을 찾는 과정에서 필수적입니다.
- **제약 조건**: 변수가 가질 수 있는 범위를 제한하여 최적화 문제를 정의하는 수학적 배경이 됩니다.
