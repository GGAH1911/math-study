# 매개변수 최적화

## 정확한 진술

**매개변수 최적화**는 제약 조건이 있는 함수의 최댓값 또는 최솟값을 구할 때, 변수들을 매개변수로 표현하여 함수를 단일 변수의 함수로 축약한 뒤 미분으로 극값을 찾는 기법입니다. 특히 삼각함수를 매개변수로 사용하면 원, 타원 같은 폐곡선 위의 점이나 각도 제약이 있는 도형에서 거리, 넓이, 길이의 극값을 효율적으로 구할 수 있습니다.

## 직관과 기하적 의미

원 위의 점 $(x, y)$는 $x = r\cos\theta$, $y = r\sin\theta$로 나타낼 수 있듯이, 제약 조건을 만족하는 점들의 좌표를 삼각함수로 표현하면 자유도가 줄어듭니다. 예를 들어 $x^2 + y^2 = 1$이라는 제약이 있으면 원 위의 모든 점을 하나의 매개변수 $\theta$ 하나로 표현할 수 있고, 원 위에서 어떤 식의 최댓값을 구하는 문제는 $f(\cos\theta, \sin\theta)$의 극값을 $\theta$에 대해 찾는 1변수 문제로 바뀝니다. 이는 라그랑주 승수법보다 계산이 간단하고, 기하학적으로는 "제약 곡선 위를 움직일 때 목적함수가 최대/최소가 되는 위치"를 직관적으로 파악하게 해줍니다.

## 한 줄 예

원 $x^2 + y^2 = 1$ 위의 점에서 직선 $2x + y$의 최댓값을 구하려면, $x = \cos\theta$, $y = \sin\theta$로 놓아 $f(\theta) = 2\cos\theta + \sin\theta$의 최댓값을 구합니다. 합성삼각함수 형태로 정리하면 $f(\theta) = \sqrt{5}\sin(\theta + \alpha)$ (단, $\tan\alpha = 2$)이므로 최댓값은 $\sqrt{5}$입니다.
