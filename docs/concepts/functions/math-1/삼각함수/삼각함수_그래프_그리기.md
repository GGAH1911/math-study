# 삼각함수 그래프 그리기

> **예제** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
함수의 계수를 분석하여 진폭과 주기를 파악한 뒤, 주요 점을 연결하여 그래프를 그립니다.

## 본문
$y = 2\sin\left(\tfrac{x}{2}\right)$ 의 그래프를 그리시오. 주기, 진폭, 그리고 주요 점들을 구하여 스케치하시오.

### 단계별 풀이
**단계 1: 기본 함수와의 비교**
주어진 함수를 $y = a\sin(bx)$ 형태로 보면 $a = 2$, $b = \tfrac{1}{2}$ 입니다. 표준형인 $y = \sin(x)$ 와 비교하여 그래프의 변환 상태를 파악합니다.

**단계 2: 진폭 구하기**
진폭은 $|a| = 2$ 이므로, 그래프는 $y$ 축 방향으로 2배 늘어난 형태이며 최댓값은 2, 최솟값은 -2를 갖습니다.

**단계 3: 주기 구하기**
삼각함수 $y = \sin(bx)$ 의 주기는 $\tfrac{2\pi}{|b|}$ 입니다. 여기서 $b = \tfrac{1}{2}$ 이므로 주기는 $\tfrac{2\pi}{1/2} = 4\pi$ 가 됩니다. 즉, 그래프는 $x = 0$ 부터 $x = 4\pi$ 까지 한 번의 완전한 주기를 완성합니다.

**단계 4: 주요 점 구하기**
$y = \sin(x)$ 의 주요 점을 이용하여 $\tfrac{x}{2}$ 가 $0, \tfrac{\pi}{2}, \pi, \tfrac{3\pi}{2}, 2\pi$ 일 때의 $x$와 $y$ 값을 계산합니다.
- $x=0$ 일 때 $y=0$
- $x=\pi$ 일 때 $y=2$
- $x=2\pi$ 일 때 $y=0$
- $x=3\pi$ 일 때 $y=-2$
- $x=4\pi$ 일 때 $y=0$

**단계 5: 그래프 스케치**
$x$ 축 위에 위에서 구한 주요 점들을 표시한 후, 부드러운 곡선으로 연결합니다. $(0, 0) \to (\pi, 2) \to (2\pi, 0) \to (3\pi, -2) \to (4\pi, 0)$ 순서로 이어지며, 이 패턴이 양쪽으로 대칭적으로 반복됩니다.

### 답과 변형
그래프는 진폭 2, 주기 $4\pi$ 인 정현 곡선입니다. 원점을 지나며, $x = \pi$ 에서 최댓값 2, $x = 3\pi$ 에서 최솟값 -2를 갖습니다.

**변형 및 주의사항**
- **위상 이동**: $y = 2\sin\left(\tfrac{x-\pi}{2}\right)$ 와 같이 식의 변형이 있으면 그래프가 $x$ 축 방향으로 이동합니다.
- **연직 이동**: $y = 2\sin\left(\tfrac{x}{2}\right) + 1$ 와 같이 식의 변형이 있으면 그래프가 위아래로 이동합니다.
- **주의할 점**: 주기를 구할 때 $b$의 역수를 취하는 과정을 놓쳐 주기를 $2\pi$로 잘못 계산하지 않도록 주의해야 합니다.

## 학습 체크
- $a$와 $b$의 값을 보고 진폭과 주기를 즉각적으로 구할 수 있는가?
- 주요 점의 좌표를 정확히 계산하여 그래프의 개형을 그릴 수 있는가?

## 관련 개념
- **삼각함수**: 삼각함수의 기본형을 바탕으로 계수의 변화에 따른 그래프의 이동과 확대, 축소를 이해하는 기초가 됩니다.
