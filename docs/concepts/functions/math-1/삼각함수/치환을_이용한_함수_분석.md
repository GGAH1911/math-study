# 치환을 이용한 함수 분석

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
복잡한 합성함수를 내부 함수와 외부 함수로 분리하여, 치환된 변수의 범위를 먼저 파악한 뒤 단계적으로 분석하는 기법입니다.

## 본문
함수 $y = f(g(x))$가 주어졌을 때, $u = g(x)$로 놓아 $y = f(u)$로 단순화한 후, $u$의 변화 범위와 함수 $f(u)$의 성질을 먼저 분석한 뒤, 다시 $x$의 함수로 해석하는 방법을 치환을 이용한 함수 분석이라 합니다. 이것은 합성함수의 구조를 내부 함수와 외부 함수로 분리하여 각각을 독립적으로 살피는 기법입니다.

### 직관과 기하적 의미
복잡한 합성함수를 그대로 분석하는 것은 어렵습니다. 하지만 $u = g(x)$로 놓으면, 먼저 $x$가 정의역을 움직일 때 $u$는 어떤 범위에서 움직이는가를 파악한 후, $u$에 대한 함수 $f(u)$는 그 범위에서 어떤 성질을 가지는가를 차례대로 분석할 수 있습니다. 예를 들어, 삼각함수를 포함한 함수 $y = (2\sin x - 1)^2$를 분석할 때, $u = 2\sin x - 1$로 놓으면 $-3 \le u \le 1$이 되고, 이제 $y = u^2$의 범위를 이 구간에서 구하면 됩니다. 이렇게 단계적으로 축소하여 분석하면 정의역, 치역, 극값, 대칭성 등을 체계적으로 파악할 수 있습니다.

### 기본 성질
치환을 통해 함수를 분석할 때는 반드시 치환된 변수 $u$의 범위를 정확히 설정해야 합니다. $y = \sin(2x + \tfrac{\pi}{3})$의 최댓값과 최솟값을 구할 때, $u = 2x + \tfrac{\pi}{3}$로 놓으면 $u$의 범위는 모든 실수이며, 이때 $y = \sin u$의 최댓값은 $1$, 최솟값은 $-1$입니다. 따라서 원래 함수도 최댓값 $1$, 최솟값 $-1$을 가집니다.

## 학습 체크
- 치환된 변수 $u$의 범위가 원래 변수 $x$의 범위와 어떻게 대응되는가?
- 외부 함수 $f(u)$의 극값이나 대칭성이 치환된 변수의 범위 내에 포함되는가?

## 관련 개념
- **삼각함수**: 합성함수의 내부 함수로 삼각함수가 포함될 경우, 치환된 변수의 범위를 결정하는 핵심 요소가 됩니다.
