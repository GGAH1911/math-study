# 삼각함수의 주기성

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
함수 $f(x)$가 모든 $x$에 대해 $f(x+T) = f(x)$를 만족하는 양수 $T$를 가질 때 이를 주기함수라 하며, 삼각함수는 특정한 주기를 가지고 그래프가 반복되는 성질을 갖습니다.

## 본문
함수 $f(x)$가 모든 $x$에 대해 $f(x+T) = f(x)$를 만족하는 양수 $T$가 존재할 때, 이 함수를 주기함수라고 합니다. 이때 조건을 만족하는 가장 작은 양수 $T$를 함수의 기본 주기라고 정의합니다. 삼각함수는 이러한 주기성을 가진 대표적인 함수로, 각도가 한 바퀴 회전하거나 특정 각도만큼 변할 때마다 함숫값이 반복됩니다.

### 직관과 기하적 의미
삼각함수의 그래프는 단위원 위를 움직이는 점의 회전 운동을 나타냅니다. 단위원 위의 점이 각도 $x$에서 시작하여 $2\pi$만큼 더 회전하면 다시 원래의 위치로 돌아오기 때문에 $\sin(x + 2\pi) = \sin x$와 같은 관계가 성립합니다. 기하학적으로 이는 그래프를 수평 방향으로 주기만큼 평행이동했을 때 원래의 그래프와 완전히 겹쳐짐을 의미합니다. $\tan x$의 경우, 기울기를 나타내는 접선 함수의 특성상 반바퀴($\pi$)만 회전해도 동일한 기울기를 갖게 되므로 주기가 $\pi$가 됩니다.

### 기본 성질
삼각함수의 종류에 따른 기본 주기는 다음과 같습니다.
- $\sin x$와 $\cos x$의 기본 주기는 $2\pi$입니다.
- $\tan x$와 $\cot x$의 기본 주기는 $\pi$입니다.

일반적으로 $f(x) = \sin(bx + c)$ 또는 $f(x) = \cos(bx + c)$와 같이 변수 $x$의 계수가 $b$인 경우, 함수의 기본 주기는 $\tfrac{2\pi}{|b|}$가 됩니다. 이는 함수의 그래프가 좌우로 압축되거나 늘어남에 따라 반복되는 간격이 변함을 나타냅니다.

## 학습 체크
- 함수 $f(x) = \sin(3x)$의 기본 주기는 얼마인가?
- $\tan x$의 주기가 $\pi$임을 삼각함수의 성질을 이용하여 설명할 수 있는가?
- $f(x+T) = f(x)$를 만족하는 $T$가 여러 개일 때, 가장 작은 양수 $T$를 무엇이라 부르는가?

## 관련 개념
- **도함수의 활용 심화**: 주기함수를 미분하여 얻은 도함수 역시 주기함수가 된다는 성질을 이용하여 함수의 극값과 그래프의 개형을 분석할 수 있습니다.
