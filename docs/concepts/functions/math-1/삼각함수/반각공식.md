# 반각공식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
주어진 각 $\theta$의 삼각함수 값을 이용하여 그 절반인 $\theta/2$의 삼각함수 값을 구하는 공식입니다.

## 본문
반각공식은 주어진 각 $\theta$에 대해, 그 절반인 $\theta/2$의 삼각함수값을 $\theta$의 삼각함수값으로 표현하는 공식입니다. 주요 공식은 다음과 같습니다.

$$\sin^2\left(\frac{\theta}{2}\right) = \frac{1-\cos\theta}{2}$$
$$\cos^2\left(\frac{\theta}{2}\right) = \frac{1+\cos\theta}{2}$$
$$\tan\left(\frac{\theta}{2}\right) = \frac{\sin\theta}{1+\cos\theta} = \frac{1-\cos\theta}{\sin\theta}$$

위 식에서 부호를 고려하여 제곱근을 취하면 $\sin(\theta/2) = \pm\sqrt{\tfrac{1-\cos\theta}{2}}$와 같은 형태를 얻을 수 있습니다.

### 직관과 기하적 의미
반각공식은 배각공식의 역방향 적용으로, 큰 각 $\theta$의 코사인값을 알면 그 절반 각의 사인과 코사인을 구할 수 있다는 의미를 갖습니다. 이는 복잡한 삼각함수 식을 단순화하거나, 적분 계산(특히 $\int\sin^2 x\,dx$와 같은 식)을 수행할 때 차수를 낮추는 용도로 매우 유용하게 사용됩니다. 핵심은 각을 반으로 나누는 대신, 이미 알고 있는 더 큰 각의 값으로 표현할 수 있다는 점에 있습니다.

### 기본 성질
$\theta = 60^\circ$일 때 $\cos 60^\circ = 1/2$이므로, 반각공식을 사용하면 $\cos 30^\circ = \sqrt{\tfrac{1+\tfrac{1}{2}}{2}} = \sqrt{\tfrac{3}{4}} = \tfrac{\sqrt{3}}{2}$를 얻을 수 있습니다.

## 학습 체크
- $\sin(\theta/2)$의 값을 구할 때 $\pm$ 부호를 결정하기 위해 확인해야 할 요소는 무엇인가요?
- 반각공식을 사용하여 $\sin^2 x$를 $\cos 2x$에 관한 식으로 변환할 수 있나요?

## 관련 개념
- **삼각함수**: 반각공식은 삼각함수의 성질을 이용하여 각의 크기를 변화시키며 값을 계산하는 도구입니다.
- **배각공식**: 반각공식은 배각공식에서 유도된 공식으로, 두 공식은 서로 역의 관계에 있습니다.
