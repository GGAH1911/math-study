# sinθ에 대한 이차방정식

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
$\sin \theta$를 미지수 $t$로 치환하여 이차방정식의 형태로 변환하여 해결하는 삼각방정식의 풀이법입니다.

## 본문
$\sin \theta$에 대한 이차방정식은 $a\sin^2 \theta + b\sin \theta + c = 0$ ($a \neq 0$)의 형태로 나타나는 삼각방정식을 의미합니다. 이 방정식을 해결하기 위해서는 $\sin \theta = t$로 치환하여 일반적인 이차방정식 $at^2 + bt + c = 0$의 형태로 변환하는 과정이 필요합니다. 치환된 이차방정식을 근의 공식 등을 이용하여 $t$의 값을 구한 뒤, 다시 원래의 변수인 $\sin \theta = t$를 만족하는 $\theta$의 값을 찾는 방식으로 문제를 해결합니다.

### 직관과 기하적 의미
$\sin \theta$를 $t$로 치환하는 것은 복잡한 삼각함수 문제를 익숙한 대수적 문제로 변환하는 과정입니다. 기하학적으로는 함수 $y = \sin \theta$의 그래프와 상수 함수 $y = t$의 교점이 존재하는지를 확인하는 것과 같습니다. 이때 $\sin \theta$의 치역인 $-1 \leq \sin \theta \leq 1$ 범위 내에 있는 $t$값만이 실제 방정식의 해로서 의미를 가집니다.

### 기본 성질
- $\sin \theta$의 값은 항상 $-1$ 이상 $1$ 이하의 범위를 가져야 합니다.
- 이차방정식의 두 근이 모두 $-1 \leq t \leq 1$ 범위를 벗어난다면, 해당 삼각방정식의 해는 존재하지 않습니다.
- 치환된 방정식의 해 중 범위 내에 있는 해의 개수가 실제 $\theta$의 해의 개수를 결정합니다.

## 학습 체크
- 이차방정식을 치환하여 구한 $t$의 값이 $-1 \leq t \leq 1$ 범위를 만족하는지 확인하였는가?
- 구한 $\theta$의 값이 문제에서 요구하는 범위(예: $0 \leq \theta < 2\pi$) 내에 있는 값인지 확인하였는가?

## 관련 개념
- **삼각함수**: $\sin \theta$의 치역이 $[-1, 1]$이라는 성질이 이차방정식의 해를 판별하는 결정적인 기준이 됩니다.
- **이차방정식**: 삼각방정식을 대수적으로 풀기 위해 반드시 거쳐야 하는 변환 대상이며, 근의 공식과 인수분해를 활용합니다.
- **치환**: 복잡한 형태의 삼각함수 식을 단순한 다항식 형태로 바꾸어 계산을 용이하게 만드는 핵심 도구입니다.
