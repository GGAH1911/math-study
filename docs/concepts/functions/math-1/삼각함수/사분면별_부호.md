# 사분면별 부호

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
각 $\theta$에 대한 삼각함수 $\sin\theta$, $\cos\theta$, $\tan\theta$의 부호는 동경이 위치한 사분면의 좌표 부호에 따라 결정됩니다.

## 본문
각 $\theta$에 대한 삼각함수값 $\sin\theta$, $\cos\theta$, $\tan\theta$의 부호는 $\theta$의 동경이 위치한 사분면에 따라 결정됩니다. 제1사분면($0^\circ < \theta < 90^\circ$)에서는 $\sin\theta$, $\cos\theta$, $\tan\theta$가 모두 양수입니다. 제2사분면($90^\circ < \theta < 180^\circ$)에서는 $\sin\theta$만 양수이고 $\cos\theta$와 $\tan\theta$는 음수입니다. 제3사분면($180^\circ < \theta < 270^\circ$)에서는 $\tan\theta$만 양수이고 $\sin\theta$와 $\cos\theta$는 음수입니다. 제4사분면($270^\circ < \theta < 360^\circ$)에서는 $\cos\theta$만 양수이고 $\sin\theta$와 $\tan\theta$는 음수입니다.

### 직관과 기하적 의미
단위원 위의 점 $(\cos\theta, \sin\theta)$로 생각하면 부호가 명확해집니다. 제1사분면의 점은 $x > 0, y > 0$이므로 $\cos\theta > 0, \sin\theta > 0$입니다. 제2사분면은 $x < 0, y > 0$이므로 $\cos\theta < 0, \sin\theta > 0$입니다. 제3사분면은 $x < 0, y < 0$이므로 $\cos\theta < 0, \sin\theta < 0$이며, 제4사분면은 $x > 0, y < 0$이므로 $\cos\theta > 0, \sin\theta < 0$입니다. $\tan\theta = \tfrac{\sin\theta}{\cos\theta}$이므로 같은 부호끼리 곱하면 양수, 다른 부호끼리 곱하면 음수가 됩니다. 이를 기억하기 위해 제1사분면은 **A**ll, 제2사분면은 **S**ine, 제3사분면은 **T**angent, 제4사분면은 **C**osine에서만 양수라는 **ASTC** 법칙을 활용할 수 있습니다.

### 기본 성질
- $\theta = 120^\circ$일 때, 제2사분면에 해당하므로 $\sin 120^\circ = \tfrac{\sqrt{3}}{2} > 0$, $\cos 120^\circ = -\tfrac{1}{2} < 0$, $\tan 120^\circ = -\sqrt{3} < 0$입니다.

## 학습 체크
- 동경이 제3사분면에 있을 때 $\tan\theta$가 양수인 이유를 단위원의 좌표 부호와 관련지어 설명할 수 있는가?
- $\sin\theta$와 $\cos\theta$의 부호가 같을 때, $\theta$가 위치할 수 있는 사분면은 어디인가?

## 관련 개념
- **삼각비**: 직각삼각형에서의 삼각비 개념이 단위원 위에서의 좌표로 확장되어 사분면별 부호를 결정하는 기초가 됩니다.
