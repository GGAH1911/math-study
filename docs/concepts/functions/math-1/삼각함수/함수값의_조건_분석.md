# 함수값의 조건 분석

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
삼각함수의 등식이나 부등식 조건이 주어졌을 때, 지정된 범위 내에서 해당 조건을 만족하는 각 $\theta$의 값이나 범위를 찾는 과정입니다.

## 본문
삼각함수 $f(\theta) = \sin\theta$, $\cos\theta$, $\tan\theta$ 등에 대하여 등식이나 부등식 형태의 조건이 주어졌을 때, 그 조건을 만족하는 각 $\theta$의 값이나 범위를 구하고 분석하는 것을 함수값의 조건 분석이라고 합니다. 예를 들어 $\sin\theta = \tfrac{1}{2}$와 같은 방정식이나 $\cos\theta > \tfrac{\sqrt{3}}{2}$와 같은 부등식 조건에서 적절한 $\theta$를 찾아내는 과정이 이에 해당합니다. 이 분석을 수행할 때는 반드시 주어진 범위(예를 들어 $0 \le \theta < 2\pi$ 또는 특정 구간)를 명시해야 하며, 해당 범위 내에서 조건을 만족하는 모든 각도를 빠짐없이 찾아내는 것이 중요합니다.

### 직관과 기하적 의미
삼각함수의 그래프를 활용하면 시각적으로 직관적인 이해가 가능합니다. $y = \sin\theta$ 그래프를 그렸을 때, 조건 $\sin\theta = \tfrac{1}{2}$은 수평선 $y = \tfrac{1}{2}$과 그래프가 만나는 교점의 $\theta$-좌표를 찾는 것과 같습니다. 또한 단위원 위에서의 관점으로 접근하면 더욱 명확합니다. $\sin\theta = \tfrac{1}{2}$이라는 조건은 단위원 위에서 $y$-좌표가 $\tfrac{1}{2}$인 점을 찾는 것과 같으며, 한 주기 내에서 이를 만족하는 점은 $\theta = \tfrac{\pi}{6}$ 또는 $\theta = \tfrac{5\pi}{6}$가 됩니다.

### 기본 성질
- 주어진 범위 내에서 모든 해를 누락 없이 찾는 것이 핵심입니다.
- 삼각함수의 주기성을 고려하여 해의 개수와 위치를 파악해야 합니다.
- 부등식 조건의 경우, 그래프의 높낮이를 통해 해의 범위를 결정합니다.

## 학습 체크
- 문제에서 제시된 각 $\theta$의 범위가 어디까지인지 확인하였는가?
- 삼각함수의 그래프나 단위원의 좌표를 이용하여 해를 시각적으로 검증하였는가?
- 방정식의 경우, 주기성을 고려하여 한 주기 내의 모든 해를 모두 구하였는가?

## 관련 개념
- **삼각함수**: 함수의 정의에 따라 각에 따른 함숫값을 결정하며, 조건 분석의 대상이 되는 핵심 대상입니다.
