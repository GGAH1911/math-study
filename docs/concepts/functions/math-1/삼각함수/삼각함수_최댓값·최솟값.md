### 정확한 진술

삼각함수 $f(x) = a\sin(bx + c) + d$ (또는 $\cos$) 형태에서:
- **최댓값**: $|a| + d$
- **최솟값**: $-|a| + d$

일반적으로 $\sin x$와 $\cos x$의 치역(range)이 $[-1, 1]$이므로, 진폭(amplitude) $a$만큼 확대되고 수직으로 $d$만큼 이동할 때 극값은 위처럼 결정됩니다. 정의역(周期, 위상)에 따라 최댓값·최솟값을 **실제로 달성하는 $x$ 값은 달라**지지만, 함수의 절댓값 최댓값과 최솟값 자체는 이 식으로 구합니다.

### 직관/기하적 의미

삼각함수 그래프는 기본적으로 $-1$과 $+1$ 사이를 진동합니다. 진폭 $a$는 이 진동의 '높이'를 조절하고, 상수항 $d$는 진동의 '중심선'을 수직으로 이동시킵니다. 따라서 중심선 $y = d$를 기준으로 위아래로 $|a|$씩 떨어진 곳이 최댓값과 최솟값이 됩니다. 주기나 위상 이동($c$ 값)은 **언제** 최대/최소가 되는지는 결정하지만, **얼마나** 크거나 작은지는 결정하지 않습니다.

### 한 줄 예

$y = 2\sin x + 3$이면 최댓값은 $2+3=5$ (when $\sin x = 1$), 최솟값은 $-2+3=1$ (when $\sin x = -1$). 

**검증**: `[2*sin(x) + 3 for sin_x in [-1, 1]]` → $[1, 5]$ ✓
