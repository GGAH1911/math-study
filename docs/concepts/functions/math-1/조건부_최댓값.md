### 정확한 진술

수열 $\{a_n\}$이 주어졌을 때, 특정 조건 $P(n)$을 만족하는 모든 $n$에 대하여 $a_n$의 최댓값을 **조건부 최댓값**이라 합니다. 기호로는

$$\max\{a_n : P(n)\text{이 참}\}$$

로 나타냅니다. 여기서 조건 $P(n)$은 $n$의 범위(예: $1 \leq n \leq 100$), 부등식, 또는 특정 성질을 뜻합니다.

### 직관과 의미

조건부 최댓값은 수열의 모든 항이 아닌, **조건을 만족하는 항들만 필터링하여** 그 중 가장 큰 값을 찾는 개념입니다. 마치 기온 기록에서 "봄철의 최고 기온"을 찾을 때 3월~5월 데이터만 모아서 비교하는 것처럼, 조건으로 범위를 좁힌 후 그 안에서 극값을 구합니다. 이는 제약이 있는 최적화 문제나 함수의 국소 극값을 다룰 때 매우 중요합니다.

### 한 줄 예

$a_n = -n^2 + 10n - 9$일 때, 양수인 항들만 고려하면 $a_n > 0$를 만족하는 $n$은 $1 \leq n \leq 9$이며, 이 범위에서의 조건부 최댓값은 $a_5 = 16$입니다.

(검산: `sympy.solve(-n**2 + 10*n - 9, n)` → 근이 $n=1, 9$이므로 $1 < n < 9$에서 양수, $a_5 = -25 + 50 - 9 = 16$)
