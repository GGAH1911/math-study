### 정확한 진술

기본 삼각함수 항등식은 **모든 각 $\theta$에 대해 항상 성립하는 항등식**입니다. 대표적인 세 가지는 다음과 같습니다.

$$\sin^2\theta + \cos^2\theta = 1$$

$$1 + \tan^2\theta = \sec^2\theta$$

$$1 + \cot^2\theta = \csc^2\theta$$

### 직관과 기하적 의미

첫 번째 항등식의 의미를 생각해봅시다. 단위원(반지름이 1인 원) 위의 한 점을 각 $\theta$만큼 회전한 위치로 나타내면, 그 점의 좌표는 $(\cos\theta, \sin\theta)$입니다. 이 점은 항상 원점으로부터 거리가 1이므로, 피타고라스 정리에 의해 $\cos^2\theta + \sin^2\theta = 1^2 = 1$이 성립합니다.

두 번째와 세 번째 항등식은 첫 번째 항등식에서 유도됩니다. 예를 들어 $\sin^2\theta + \cos^2\theta = 1$의 양변을 $\cos^2\theta$로 나누면:

$$\tan^2\theta + 1 = \sec^2\theta$$

이 세 항등식들은 **삼각함수 간의 관계를 나타내고, 복잡한 삼각함수 식을 간단히 할 때 필수**입니다.

### 구체적 예

$\theta = 60°$일 때를 확인하면:
- $\sin 60° = \frac{\sqrt{3}}{2}$, $\cos 60° = \frac{1}{2}$
- $(\frac{\sqrt{3}}{2})^2 + (\frac{1}{2})^2 = \frac{3}{4} + \frac{1}{4} = 1$ ✓

검산: `sympy.simplify(sin(pi/3)**2 + cos(pi/3)**2)` → `1`
