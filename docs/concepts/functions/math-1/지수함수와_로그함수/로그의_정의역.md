# 로그의 정의역

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
로그함수 $y = \log_a x$의 정의역은 모든 양의 실수인 $(0, \infty)$입니다.

## 본문
로그함수 $y = \log_a x$ (단, $a > 0, a \neq 1$)의 정의역은 모든 양의 실수입니다. 즉, 로그의 진수 $x$는 반드시 $0$보다 커야 하며, 이를 집합으로 나타내면 $(0, \infty)$가 됩니다.

### 직관과 기하적 의미
로그는 지수함수의 역함수라는 점을 통해 그 정의역을 명확히 이해할 수 있습니다. 지수함수 $y = a^x$는 모든 실수 $x$에 대하여 항상 양수값만을 출력합니다. 예를 들어 음수 지수 $a^{-2} = \frac{1}{a^2}$은 항상 양수이며, $x$가 음의 무한대로 갈 때도 $y$는 $0$에 가까워질 뿐 $0$보다 작아지지는 않습니다. 따라서 지수함수의 치역인 $(0, \infty)$가 역함수인 로그함수의 정의역이 됩니다.

기하학적으로 보면, $y = a^x$의 그래프는 $x$축과 만나지 않고 항상 $x$축 위쪽에 위치합니다. 이 그래프를 $y = x$ 직선에 대칭시킨 로그함수의 그래프는 $y$축의 양수 부분만을 $x$축으로 가지게 되므로, 정의역이 양수 범위로 제한됩니다. 만약 $\log_2 (-1)$과 같이 진수가 음수인 경우를 생각한다면, 이는 $2^? = -1$을 만족하는 실수를 찾는 것과 같은데, 어떤 실수를 거듭제곱해도 음수가 될 수 없으므로 로그값은 정의되지 않습니다.

### 기본 성질
| 식 | 정의 여부 | 이유 |
|---|---|---|
| $\log_2 8$ | ✓ 정의됨 | $x = 8 > 0$이므로 정의역 내 |
| $\log_5 \frac{1}{25}$ | ✓ 정의됨 | $x = \frac{1}{25} > 0$이므로 정의역 내 |
| $\log_3 (-9)$ | ✗ 정의 안 됨 | $x = -9 < 0$이므로 정의역 밖 |
| $\log_7 0$ | ✗ 정의 안 됨 | $x = 0$이므로 정의역 밖 |

## 학습 체크
- 로그의 진수 조건인 $x > 0$을 만족하는지 확인했는가?
- 지수함수의 치역과 로그함수의 정의역 사이의 역함수 관계를 이해하고 있는가?
- 로그의 진수가 $0$이거나 음수인 경우 왜 정의될 수 없는지 설명할 수 있는가?

## 관련 개념
- **지수와 로그**: 로그는 지수 방정식의 해를 구하는 과정에서 탄생하였으며, 지수함수의 치역이 로그함수의 정의역이 되는 역함수 관계를 가집니다.
