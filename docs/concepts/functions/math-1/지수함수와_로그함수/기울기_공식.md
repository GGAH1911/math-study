# 기울기 공식

## 정확한 진술

좌표평면 위의 두 점 $P_1(x_1, y_1)$과 $P_2(x_2, y_2)$ (단, $x_1 \neq x_2$)를 지나는 직선의 **기울기**(slope)는 다음 공식으로 정의됩니다:

$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x}$$

여기서 $\Delta y = y_2 - y_1$은 $y$의 변화량, $\Delta x = x_2 - x_1$은 $x$의 변화량입니다.

## 직관/기하적 의미

기울기는 직선이 수평면에 대해 얼마나 가파른지를 나타내는 실수값입니다. **$x$가 1만큼 증가할 때 $y$가 얼마나 변하는가**를 보여주는 '변화의 비율'입니다.

- $m > 0$일 때: 직선이 왼쪽 아래에서 오른쪽 위로 향함
- $m < 0$일 때: 직선이 왼쪽 위에서 오른쪽 아래로 향함  
- $m = 0$일 때: 수평선 (직선이 $x$축과 평행)
- $|m|$이 클수록: 직선이 더욱 가파름

기울기 공식은 직선뿐만 아니라 곡선(지수함수, 로그함수 등) 위의 두 점 사이의 **평균 변화율**(average rate of change)을 계산할 때도 사용됩니다. 이는 나중에 미분으로 배우는 순간 변화율의 기초가 됩니다.

## 한 줄 예

점 $A(2, 5)$와 점 $B(6, 13)$을 지나는 직선의 기울기는 $m = \frac{13-5}{6-2} = \frac{8}{4} = 2$입니다. (`sympy.solve(2*1 - (13-5)/(6-2), x)` → 검산 완료)
