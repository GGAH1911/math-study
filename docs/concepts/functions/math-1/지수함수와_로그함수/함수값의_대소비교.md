# 함수값의 대소비교

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
함수의 정의역에서 입력값의 크기 관계에 따른 함수값의 대소 관계를 함수의 증감 성질을 이용하여 판단하는 것입니다.

## 본문
함수 $f$에서 서로 다른 두 입력값 $a, b$에 대하여 함수값 $f(a)$와 $f(b)$의 크기 관계를 판단하는 것을 함수값의 대소비교라고 합니다. 즉, $f(a) > f(b)$, $f(a) = f(b)$, $f(a) < f(b)$ 중 어느 것이 성립하는지를 결정하는 과정입니다.

### 직관과 기하적 의미
함수의 그래프 위에서 두 점 $(a, f(a))$와 $(b, f(b))$의 $y$좌표를 비교하는 것과 같습니다. 기하학적으로는 그래프 상의 두 점 중 어느 점이 더 높은 위치에 있는지를 판단하는 과정으로 이해할 수 있습니다.

### 기본 성질
함수의 증감 성질을 파악하면 대소비교를 신속하게 수행할 수 있습니다.
- **지수함수 $f(x) = a^x$ ($a > 0, a \neq 1$):** 밑 $a > 1$이면 증가함수이므로 $x$값이 클수록 함수값도 크고, $0 < a < 1$이면 감소함수이므로 $x$값이 클수록 함수값은 작습니다.
- **로그함수 $f(x) = \log_a x$ ($a > 0, a \neq 1, x > 0$):** 지수함수와 마찬가지로 밑 $a > 1$이면 증가함수, $0 < a < 1$이면 감소함수입니다.

## 학습 체크
- 함수의 밑($a$)의 범위에 따라 함수가 증가하는지 감소하는지 먼저 확인하였는가?
- 입력값($x$)의 크기 관계와 함수의 증감 방향이 일치하는지, 혹은 반대인지 판단하였는가?

## 관련 개념
- **지수함수와 로그함수**: 함수의 밑의 조건에 따라 증가 또는 감소하는 성질을 가지므로, 함수값의 대소비교를 결정하는 핵심 근거가 됩니다.
