# 역함수 관계

## 역함수의 정확한 정의

두 함수 $f: X \to Y$와 $g: Y \to X$가 **역함수 관계**라는 것은 다음을 만족함을 의미합니다:

$$f(g(y)) = y \quad (모든 \, y \in Y)$$
$$g(f(x)) = x \quad (모든 \, x \in X)$$

이때 $g$를 $f$의 역함수라 하고 $g = f^{-1}$으로 표기합니다. 역함수가 존재하려면 $f$는 **일대일 대응**(단사이자 전사)이어야 합니다.

## 그래프와 기하적 의미

역함수 관계의 핵심 성질은 **두 함수의 그래프가 직선 $y = x$에 대해 대칭**이라는 것입니다. 만약 점 $(a, b)$가 $f$의 그래프 위에 있다면, 점 $(b, a)$는 $f^{-1}$의 그래프 위에 있습니다.

이는 다음과 같이 이해할 수 있습니다: $f$에서 입력값 $x$와 출력값 $y$의 역할을 완전히 뒤집는 것이 역함수이므로, 좌표축도 대칭적으로 바뀌게 되는 것입니다.

## 지수함수와 로그함수의 역함수 관계

특히 중요한 예로, **지수함수 $f(x) = a^x$와 로그함수 $g(x) = \log_a x$ (단, $a > 0, a \neq 1$)는 서로 역함수 관계**입니다.

이는 정의에 의해 검증됩니다:
$$a^{\log_a x} = x \quad (x > 0)$$
$$\log_a(a^x) = x \quad (모든 \, x)$$

따라서 지수함수의 정의역 $\mathbb{R}$이 로그함수의 치역이 되고, 지수함수의 치역 $(0, \infty)$가 로그함수의 정의역이 됩니다.

## 구체적 예

$f(x) = 2^x$의 역함수는 $f^{-1}(x) = \log_2 x$입니다. 검증: $f(3) = 8$이면 $f^{-1}(8) = 3$ ✓

(`sympy.solve(2**x - 8, x)` 결과: $x = 3$)
