# 역함수 관계

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
두 함수가 입력과 출력의 역할을 서로 바꾸어 원래의 값을 되돌려주는 관계를 역함수 관계라고 합니다.

## 본문
두 함수 $f: X \to Y$와 $g: Y \to X$가 역함수 관계라는 것은 모든 $x \in X$에 대하여 $g(f(x)) = x$이고, 모든 $y \in Y$에 대하여 $f(g(y)) = y$임을 의미합니다. 이때 $g$를 $f$의 역함수라 하며 $g = f^{-1}$로 표기합니다. 역함수가 존재하기 위해서는 함수 $f$가 반드시 일대일 대응이어야 합니다.

### 직관과 기하적 의미
역함수는 $f$에서 입력값 $x$와 출력값 $y$의 역할을 완전히 뒤집는 과정입니다. 따라서 좌표평면 위에서 두 함수의 그래프는 직선 $y = x$에 대하여 대칭인 형태를 띱니다. 만약 점 $(a, b)$가 $f$의 그래프 위에 있다면, 그 역함수의 그래프에는 점 $(b, a)$가 반드시 포함됩니다.

### 기본 성질
지수함수 $f(x) = a^x$와 로그함수 $g(x) = \log_a x$ ($a > 0, a \neq 1$)는 대표적인 역함수 관계입니다. $a^{\log_a x} = x$와 $\log_a(a^x) = x$가 성립하기 때문입니다. 이 관계에 의해 지수함수의 정의역은 로그함수의 치역이 되고, 지수함수의 치역 $(0, \infty)$는 로그함수의 정의역이 됩니다. 예를 들어 $f(x) = 2^x$의 역함수는 $f^{-1}(x) = \log_2 x$이며, $f(3)=8$일 때 $f^{-1}(8)=3$이 성립합니다.

## 학습 체크
- 함수 $f$가 일대일 대응이 아닐 때 역함수가 존재할 수 없는 이유를 설명할 수 있는가?
- 두 함수의 그래프가 $y=x$에 대해 대칭임을 이용하여 역함수의 함숫값을 구할 수 있는가?
- 지수함수와 로그함수의 정의역과 치역이 서로 어떻게 대응되는지 이해하고 있는가?

## 관련 개념
- **지수함수와 로그함수**: 두 함수는 서로 역함수 관계에 있으며, 지수함수의 정의역과 치역이 로그함수의 치역과 정의역으로 서로 뒤바뀝니다.
