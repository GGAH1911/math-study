# 로그함수의 단조성

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 정확한 진술

로그함수의 단조성(monotonicity)이란 로그함수가 정의역 전체에서 순증가 또는 순감소 함수임을 나타냅니다. 밑이 $a > 1$인 로그함수 $f(x) = \log_a x$는 **순증가함수**이고, $0 < a < 1$인 경우는 **순감소함수**입니다. 즉, $x_1 < x_2$일 때:
- $a > 1$이면 $\log_a x_1 < \log_a x_2$
- $0 < a < 1$이면 $\log_a x_1 > \log_a x_2$

이는 모든 양수 $x_1, x_2$에 대해 성립하며, 로그함수가 극값을 갖지 않고 한 방향으로만 변함을 의미합니다.

## 직관과 기하적 의미

로그함수는 지수함수의 역함수이므로, 지수함수의 성질을 그대로 물려받습니다. 밑 $a > 1$인 지수함수 $y = a^x$가 순증가함수이므로, 그 역함수인 $y = \log_a x$도 순증가함수입니다. 반대로 $0 < a < 1$일 때 지수함수가 순감소이면 로그함수도 순감소입니다.

그래프상으로는 밑이 클수록(예: $a = 10$) 로그값이 천천히 증가하고, 밑이 1에 가까울수록(예: $a = 1.01$) 급하게 증가합니다. 이 성질은 부등식 풀이, 함수의 최대·최솟값, 함수 비교 문제에서 핵심 도구가 됩니다.

## 한 줄 예

$\log_2 8 = 3 < 4 = \log_2 16$이므로 $\log_2 x$는 증가함수이고, $\log_{0.5} 8 = -3 > -4 = \log_{0.5} 16$이므로 $\log_{0.5} x$는 감소함수입니다.
