# 정의역 분석

## 정확한 진술

함수 $f$의 **정의역(domain)**은 $f(x)$가 실수 값으로 정의되는 모든 $x$의 집합입니다. 이를 $D_f$로 표기합니다.

## 직관/기하적 의미

정의역은 함수 그래프가 존재할 수 있는 $x$축의 범위입니다. 실함수를 다룰 때 정의역이 제한되는 주요 이유는 다음과 같습니다:

**로그함수** $\log_a x$ (단, $a > 0, a \neq 1$)는 양수에서만 정의됩니다. 이는 $\log_a x = y$ ⟺ $a^y = x$에서 지수 $a^y$는 항상 양수이기 때문입니다.

**지수함수** $a^x$ (단, $a > 0, a \neq 1$)는 모든 실수 $x$에서 정의되어 정의역이 $\mathbb{R}$입니다.

**짝수 제곱근** $\sqrt[2n]{x}$ (단, $n \in \mathbb{N}$)은 $x \geq 0$일 때만 정의됩니다.

특히 지수함수와 로그함수는 역함수 관계이므로, 지수함수의 치역 $(0, \infty)$이 로그함수의 정의역이 됩니다.

## 한 줄 예

$f(x) = \log_2(x^2 - 4)$의 정의역을 구합시다.

로그의 진수가 양수여야 하므로:
$$x^2 - 4 > 0 \Rightarrow (x-2)(x+2) > 0 \Rightarrow x < -2 \text{ 또는 } x > 2$$

따라서 정의역은 $(-\infty, -2) \cup (2, \infty)$입니다.
