# 함수의 최댓값과 최솟값

## 정확한 진술

함수 $f(x)$의 **최댓값(maximum)**은 정의역에 속하는 모든 $x$에 대해 $f(x) \leq M$을 만족하는 최대의 실수 $M$입니다. 이때 $f(a) = M$을 만족하는 점 $x = a$를 **최댓값을 주는 점**이라 부릅니다. 마찬가지로 **최솟값(minimum)**은 정의역의 모든 $x$에 대해 $f(x) \geq m$을 만족하는 최소의 실수 $m$이며, $f(c) = m$인 점 $x = c$를 **최솟값을 주는 점**이라 합니다.

## 직관/기하적 의미

함수의 그래프에서 최댓값은 함수가 도달하는 가장 높은 $y$ 좌표이고, 최솟값은 가장 낮은 $y$ 좌표입니다. 지수함수 $f(x) = a^x$ (단, $a > 1$)는 정의역이 전체 실수일 때 최솟값도 최댓값도 존재하지 않습니다. 그러나 정의역을 폐구간 $[p, q]$로 제한하면, 지수함수는 증가함수이므로 $x = p$에서 최솟값 $a^p$를, $x = q$에서 최댓값 $a^q$를 가집니다. 로그함수 $f(x) = \log_a x$ (단, $a > 1$)도 정의역 $(0, \infty)$에서는 최댓값·최솟값이 없으나, 정의역 $[p, q]$로 제한하면 $x = p$에서 최솟값 $\log_a p$를, $x = q$에서 최댓값 $\log_a q$를 가집니다.

## 한 줄 예

$f(x) = 2^x$를 구간 $[1, 3]$에서 생각하면, 최솟값은 $f(1) = 2$이고 최댓값은 $f(3) = 8$입니다.
