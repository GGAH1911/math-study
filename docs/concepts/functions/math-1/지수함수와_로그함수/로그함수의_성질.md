# 로그함수의 성질

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
로그함수의 성질은 곱셈 연산을 덧셈 연산으로 변환하여 복잡한 계산을 단순화하는 성질을 핵심으로 합니다.

## 본문
로그함수 $f(x) = \log_a x$ (단, $a > 0, a \neq 1, x > 0$)는 지수함수의 역함수로서 다음과 같은 독특한 연산 규칙을 가집니다. 로그의 가장 근본적인 역할은 곱셈을 덧셈으로 바꾸어 계산의 복잡도를 낮추는 데 있습니다. 지수법칙 $a^x \cdot a^y = a^{x+y}$에 로그를 취하면 $\log_a(xy) = x + y = \log_a x + \log_a y$가 되는 원리가 모든 성질의 바탕이 됩니다. 이러한 성질 덕분에 과거 로그표는 거대한 숫자의 곱셈을 단순한 덧셈으로 바꾸어주는 강력한 계산 도구로 사용되었습니다. 또한 나눗셈은 뺄셈으로, 거듭제곱은 상수를 곱하는 형태로 축소되며, 밑의 변환 공식은 서로 다른 밑을 가진 로그 사이를 연결하는 다리 역할을 수행합니다.

### 직관과 기하적 의미
로그함수는 수의 크기를 '배수'가 아닌 '지수'의 관점에서 바라보게 합니다. 곱셈 연산이 덧셈으로 변환되는 것은 수의 규모가 커질 때 그 변화량을 선형적인 덧셈으로 표현할 수 있음을 의미합니다. 이는 기하급수적으로 증가하는 현상을 선형적인 눈금으로 읽어내는 것과 같습니다.

### 기본 성질
- $\log_a 1 = 0$
- $\log_a a = 1$
- $\log_a (xy) = \log_a x + \log_a y$
- $\log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y$
- $\log_a (x^n) = n \log_a x$
- $\log_a x = \frac{\log_b x}{\log_b a}$

## 학습 체크
- 로그의 밑 조건($a > 0, a \neq 1$)과 진수 조건($x > 0$)을 만족하는지 확인하였는가?
- 로그의 성질을 이용하여 복잡한 곱셈과 나눗셈을 덧셈과 뺄셈으로 변환할 수 있는가?
- 밑의 변환 공식을 사용하여 계산하기 편한 밑으로 로그를 바꿀 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 로그함수는 지수함수의 역함수 관계에 있으며, 지수법칙의 성질이 로그의 성질로 그대로 전이됩니다.
