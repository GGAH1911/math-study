# 로그함수의 성질

## 정확한 진술

로그함수 $f(x) = \log_a x$ (단, $a > 0, a \neq 1, x > 0$)의 성질은 다음과 같습니다.

**기본 성질:**
- $\log_a 1 = 0$
- $\log_a a = 1$
- $\log_a (xy) = \log_a x + \log_a y$ (곱셈 공식)
- $\log_a \left(\frac{x}{y}\right) = \log_a x - \log_a y$ (나눗셈 공식)
- $\log_a (x^n) = n \log_a x$ (거듭제곱 공식, $n$은 실수)
- $\log_a x = \frac{\log_b x}{\log_b a}$ (밑의 변환 공식)

## 직관·기하적 의미

이 성질들은 로그함수가 **곱셈을 덧셈으로 변환**한다는 근본적 역할에서 비롯합니다. 

지수함수 $a^x \cdot a^y = a^{x+y}$에서 밑 $a$로 로그를 취하면 $\log_a(xy) = x + y = \log_a x + \log_a y$가 됩니다. 곱셈이 덧셈으로 바뀌는 것이지요. 이것이 과학 계산에서 로그표와 계산자가 귀했던 이유입니다.

나눗셈($x/y = x \cdot y^{-1}$)과 거듭제곱($x^n = \underbrace{x \cdot x \cdots x}_{n\text{개}}$)도 같은 원리로 덧셈과 뺄셈, 상수배로 축소됩니다. 

밑의 변환은 다양한 밑의 로그를 자유롭게 비교·계산할 수 있도록 하는 다리 역할을 합니다.

## 한 줄 예

$\log_2 8 + \log_2 4 = \log_2(8 \times 4) = \log_2 32 = 5$ (확인: `sympy.log(32, 2)`)
