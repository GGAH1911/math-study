# 실생활 지수응용

> **예제** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
복리 계산과 방사성 물질의 반감기는 지수함수의 원리를 이용한 대표적인 실생활 응용 사례입니다.

## 본문
은행에 100만 원을 연 5% 복리로 정기예금에 넣었습니다. 5년 후 원리금 합계는 얼마입니까? (단, $1.05^5 \approx 1.276$)

### 단계별 풀이
**1단계: 복리 모델 수립**
매년 말의 잔액이 전년도의 1.05배가 되므로, $n$년 후 잔액을 $A_n$이라 하면 $A_n = A_0(1 + r)^n$입니다. 여기서 $A_0 = 100$ (만 원), $r = 0.05$ (연 5%), $n = 5$ (년)입니다.

**2단계: 지수식에 값 대입**
정의에 맞춰 대입하면 $A_5 = 100 \times (1.05)^5$이며, 주어진 근삿값을 사용하여 계산합니다.

**3단계: 계산 수행**
$A_5 = 100 \times 1.276 = 127.6$ (만 원)입니다. 따라서 원리금 합계는 127만 6000원입니다.

**4단계: 의미 확인**
초기금 100만 원에서 5년 동안 이자 27만 6000원을 얻었으며, 이는 단리 이자인 25만 원보다 큼을 알 수 있습니다.

### 답과 변형
**127만 6000원**

**반감기 응용**: 방사성 물질의 잔량도 같은 구조를 가집니다. 반감기가 $T$일 때 $t$일 후 잔량은 $A(t) = A_0 \left(\frac{1}{2}\right)^{t/T}$입니다. 예를 들어 반감기가 8일인 물질 64g은 16일 후 $64 \times 0.5^{16/8} = 16\text{g}$으로 감소합니다.

**주의사항**: 복리 계산 시 이자 지급 주기를 확인해야 합니다. 월 복리라면 $A = A_0(1 + r/12)^{12n}$과 같이 밑과 지수를 조정해야 합니다.

## 학습 체크
- 복리 계산 시 이자율과 기간을 지수식의 밑과 지수에 올바르게 대입할 수 있는가?
- 반감기 모델에서 시간의 흐름에 따른 물질의 감소량을 지수함수로 표현할 수 있는가?
- 이자 지급 주기가 변할 때 지수식의 구조가 어떻게 변화하는지 이해하고 있는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수의 증가 모델을 통해 복리 계산을 수행하며, 로그를 이용하면 특정 금액에 도달하는 시간을 구할 수 있습니다.
