# 방정식의 근과 합

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음 관계를 **근과 계수의 관계**(또는 비에타 공식)라 부릅니다:

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha \beta = \frac{c}{a}$$

이 관계는 근의 공식 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$에서 두 근을 더하거나 곱하면 바로 유도됩니다. 더 일반적으로, $n$차 다항식의 근들과 계수 사이의 대칭 관계를 **비에타 공식**이라 합니다.

## 직관과 활용

근과 계수의 관계의 핵심은 "근의 공식을 명시적으로 계산하지 않고도 근의 합이나 곱을 알 수 있다"는 점입니다. 예를 들어, 두 근의 합과 곱만 알면 원래 방정식을 복원할 수 있습니다. 근의 합을 $s = \alpha + \beta$, 근의 곱을 $p = \alpha\beta$라 하면, 두 근은 방정식 $t^2 - st + p = 0$의 근이 됩니다.

이 성질은 근의 구체적인 값을 구하지 않고 합이나 곱 같은 특정 정보가 필요할 때 매우 유용합니다. 또한 지수방정식이나 로그방정식을 치환해 이차방정식으로 만들 때도 이 관계가 유용하게 쓰입니다.

## 구체적 예

방정식 $2x^2 - 5x + 3 = 0$에서 $a = 2, b = -5, c = 3$이므로:
- 근의 합: $\alpha + \beta = \frac{5}{2}$
- 근의 곱: $\alpha\beta = \frac{3}{2}$

실제로 이 방정식의 근은 $x = 1$ 또는 $x = \frac{3}{2}$이며, 검증하면 $1 + \frac{3}{2} = \frac{5}{2}$, $1 \cdot \frac{3}{2} = \frac{3}{2}$ ✓

(`sympy.vieta(x**2 - Rational(5,2)*x + Rational(3,2), x)` 또는 근의 공식으로 검산 가능)
