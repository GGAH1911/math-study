### 정확한 진술

함수 $f$의 **정의역**(domain)은 $f(x)$가 의미 있게 정의되는 모든 $x$값들의 집합입니다. 함수를 순서쌍 $(x, f(x))$의 모임으로 생각할 때, 정의역은 입력값으로 가능한 모든 $x$입니다.

일반적으로 별다른 명시가 없으면 '최대 정의역'을 사용합니다. 즉, 식이 수학적으로 정의되는 가장 큰 범위를 정의역으로 잡습니다.

### 직관과 기하적 의미

정의역은 함수의 "입력 도메인"으로, 함수 기계에 넣을 수 있는 재료의 범위입니다. 예를 들어 $f(x) = \sqrt{x}$는 음수를 제곱근할 수 없으므로 정의역이 $x \geq 0$으로 제한됩니다.

그래프 관점에서, 정의역은 함수 그래프가 그려지는 $x$축 구간입니다. 선수 개념인 지수함수 $f(x) = a^x$ ($a > 0, a \neq 1$)는 모든 실수에서 정의되므로 정의역이 $\mathbb{R}$ 전체이지만, 로그함수 $f(x) = \log_a x$는 오직 양수 $x > 0$에서만 정의되므로 정의역이 $(0, \infty)$입니다.

### 한 줄 예

- $f(x) = \frac{1}{x-2}$: 분모가 0이 되면 안 되므로 정의역은 $\{x \mid x \neq 2\}$ 또는 $\mathbb{R} \setminus \{2\}$
- $g(x) = \log(2x - 5)$: 로그의 진수가 양수여야 하므로 정의역은 $\left\{x \mid x > \frac{5}{2}\right\}$
- $h(x) = \sqrt{x^2 - 4}$: 루트 안이 0 이상이어야 하므로 정의역은 $\{x \mid |x| \geq 2\}$

문제를 풀 때는 함수식을 보면서 분모가 0이 되거나, 짝수 제곱근 안이 음수가 되거나, 로그의 진수가 양수가 아닌 경우를 찾아 제외하면 됩니다.
