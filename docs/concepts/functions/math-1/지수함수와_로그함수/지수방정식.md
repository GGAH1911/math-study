# 지수방정식

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
미지수가 지수 부분에 포함되어 있는 방정식을 의미하며, 지수함수의 그래프와 특정 함숫값이 만나는 지점의 지수를 찾는 과정입니다.

## 본문
지수방정식(exponential equation)은 미지수가 지수에 포함된 방정식을 말합니다. 가장 기본적인 형태는 $a^x = b$ (단, $a > 0, a \neq 1, b > 0$)이며, 더 일반적으로는 $a^{f(x)} = a^{g(x)}$ 또는 $a^{f(x)} = c$와 같은 형태를 포함합니다. 여기서 밑(base)이라 불리는 $a$는 양수여야 하며 1이 아니어야 합니다.

### 직관과 기하적 의미
지수방정식을 푼다는 것은 지수함수가 특정 값을 갖게 하는 입력값, 즉 지수를 찾는 과정입니다. 예를 들어 $2^x = 8$이라는 식은 "2를 몇 번 곱해야 8이 되는가?"라는 질문과 같습니다. 이를 좌표평면에서 해석하면, 지수함수 $y = 2^x$의 그래프와 수평선 $y = 8$이 만나는 점의 $x$ 좌표를 찾는 것과 같습니다.

### 기본 성질
$a^x = b$ 형태의 방정식은 양변에 로그를 취하여 해결할 수 있습니다. $\log_a(a^x) = \log_a b$를 이용하면 $x = \log_a b$라는 해를 얻을 수 있으며, 상용로그를 사용한다면 $x \log a = \log b$이므로 $x = \tfrac{\log b}{\log a}$로 계산할 수 있습니다.

## 학습 체크
- 밑을 같게 만들었을 때 지수 부분이 서로 같다는 성질을 정확히 적용할 수 있는가?
- 지수방정식을 풀 때 밑 조건($a > 0, a \neq 1$)과 진수 조건($b > 0$)을 만족하는지 확인할 수 있는가?
- 지수함수의 그래프를 이용하여 방정식의 해를 기하학적으로 설명할 수 있는가?

## 관련 개념
- **지수와 로그**: 지수방정식의 해를 구하는 과정은 로그의 정의를 이용해 지수를 내리는 과정과 직결됩니다.
- **지수함수**: 지수방정식의 해는 지수함수의 그래프와 수평선이 만나는 교점의 $x$ 좌표와 같습니다.
