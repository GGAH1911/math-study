# 로그 함수

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
로그함수는 지수함수의 역함수로, 밑 $a$를 몇 제곱해야 $x$가 되는지를 나타내는 함수입니다.

## 본문
밑 $a$ ($a > 0, a \neq 1$)에 대한 로그함수는 지수방정식 $a^y = x$를 $y$에 대해 푼 것으로, 다음과 같이 정의합니다:
$$y = \log_a x \quad (x > 0)$$
여기서 $y = \log_a x$는 $a$를 몇 제곱하면 $x$가 되는가에 대한 답을 의미하며, $a^y = x$와 $y = \log_a x$는 동일한 관계를 서로 다른 형태로 나타낸 것입니다. 특히 밑이 자연상수 $e$인 경우를 자연로그 $\ln x = \log_e x$라고 하며, 밑이 $10$인 경우를 상용로그 $\log x = \log_{10} x$라고 부릅니다.

### 직관과 기하적 의미
로그함수는 지수함수의 역함수로서, 지수함수 $y = a^x$의 그래프와 직선 $y = x$에 대해 대칭인 형태를 가집니다. 지수함수가 밑을 통해 결과값을 구하는 과정이라면, 로그함수는 결과값을 통해 지수를 찾아내는 과정입니다. 이로 인해 로그함수의 정의역은 $(0, \infty)$이며 치역은 실수 전체의 집합 $\mathbb{R}$이 됩니다. 또한 모든 로그함수는 $a^0 = 1$이라는 성질에 의해 항상 점 $(1, 0)$을 지납니다.

### 기본 성질
로그함수의 증감은 밑의 범위에 따라 결정됩니다. 밑 $a > 1$일 때는 그래프가 오른쪽 위로 올라가는 증가함수의 형태를 띠며, $0 < a < 1$일 때는 오른쪽 아래로 내려가는 감소함수의 형태를 띱니다.

## 학습 체크
- 로그의 밑 조건인 $a > 0, a \neq 1$과 진수 조건인 $x > 0$을 항상 확인하였는가?
- 주어진 로그값이 지수 관계를 통해 성립하는지 검산할 수 있는가? (예: $\log_2 8 = 3 \iff 2^3 = 8$)

## 관련 개념
- **지수함수**: 로그함수는 지수함수의 역함수 관계에 있으므로, 두 함수의 그래프는 $y=x$에 대해 대칭입니다.
- **여러가지함수의 극한**: 로그함수의 그래프가 $x$가 $0$으로 갈 때의 거동이나 $x$가 무한대로 갈 때의 극한값을 다룰 때 필수적으로 사용됩니다.
