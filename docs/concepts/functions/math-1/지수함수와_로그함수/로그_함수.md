# 로그 함수

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 정확한 진술

밑 $a$ ($a > 0, a \neq 1$)에 대한 **로그함수**는 지수방정식 $a^y = x$를 $y$에 대해 푼 것으로, 다음과 같이 정의합니다:

$$y = \log_a x \quad (x > 0)$$

여기서 $y = \log_a x$는 "$a$를 몇 제곱하면 $x$가 되는가"의 답입니다. 즉, $a^y = x$와 $y = \log_a x$는 같은 관계를 다른 형태로 나타낸 것입니다. 특히 $a = e$ (자연상수)일 때를 **자연로그** $\ln x = \log_e x$, $a = 10$일 때를 **상용로그** $\log x = \log_{10} x$라고 부릅니다.

## 직관 및 기하적 의미

로그함수는 **지수함수의 역함수**입니다. 지수함수 $y = a^x$와 로그함수 $y = \log_a x$의 그래프는 직선 $y = x$에 대해 대칭입니다. 

- 지수함수는 "밑을 주면 결과를 구한다" ($a^3 = 8$)
- 로그함수는 "결과를 주면 지수를 구한다" ($\log_2 8 = 3$)

따라서 정의역이 $(0, \infty)$이고 치역이 $\mathbb{R}$ 전체입니다. $a > 1$일 때 로그함수는 증가함수이고, $0 < a < 1$일 때는 감소함수입니다. 모든 로그함수는 점 $(1, 0)$을 지나갑니다. ($\log_a 1 = 0$, 왜냐하면 $a^0 = 1$)

## 한 줄 예

$\log_2 8 = 3$인 이유는 $2^3 = 8$이기 때문이고, $\log_{10} 1000 = 3$은 $10^3 = 1000$을 의미합니다.

**검산:** `sympy.log(8, 2), sympy.ln(2.718281828)`로 로그값을 확인할 수 있습니다.
