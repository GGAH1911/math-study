# 함수의 활용

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
실제 현상을 지수함수와 로그함수로 모델링하여 현상의 변화를 분석하고 미래의 값을 예측하는 과정입니다.

## 본문
함수의 활용이란 실제 상황이나 문제에서 나타나는 현상을 함수로 모델링하고, 그 함수의 성질인 정의역, 치역, 증감, 극값 등을 이용하여 문제를 해결하는 과정입니다. 수학1 과정에서는 지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)와 로그함수 $f(x) = \log_a x$의 활용이 핵심적인 비중을 차지합니다.

### 직관과 기하적 의미
세상의 많은 현상은 함수 관계를 따릅니다. 세균의 증식, 방사능 감소, 소리의 크기, 지진의 강도와 같은 실제 상황들이 지수나 로그의 형태로 표현됩니다. 함수의 활용은 추상적인 수식이 구체적인 현상과 어떻게 연결되는지를 파악하는 과정이며, 함수의 그래프나 방정식을 통해 미래의 값을 예측하거나 최적의 조건을 찾는 것을 의미합니다. 예를 들어, 초기값이 $N_0$이고 매년 2배씩 증가하는 상황을 $N(t) = N_0 \cdot 2^t$로 나타낼 수 있으며, 이때 로그를 이용하면 특정 값에 도달하는 시점인 $t = \log_2 \tfrac{N}{N_0}$를 구할 수 있습니다.

### 기본 성질
지수함수 모델링은 양이 일정 비율로 급격히 증가하거나 감소하는 상황에 적합하며, 로그함수 모델링은 큰 수의 변화를 다루거나 역의 관계를 통해 특정 시점을 찾을 때 유용합니다. 예를 들어, 어떤 물질의 질량이 20년마다 절반으로 감소할 때, 질량 $m(t) = m_0 \cdot \left(\tfrac{1}{2}\right)^{t/20}$이라는 식을 세워 50년 후의 남은 질량을 정확히 계산할 수 있습니다.

- 모델링된 함수 식을 바탕으로 특정 시점의 값을 계산하거나, 목표 값에 도달하는 시간을 구할 수 있는가?

## 관련 개념
- **지수와 로그**: 함수의 밑이 되는 수의 성질을 결정하며, 지수함수와 로그함수의 역함수 관계를 형성하여 모델링의 기초가 됩니다.
