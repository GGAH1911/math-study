# 지수함수의 평행이동

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
지수함수 $f(x) = a^x$를 $x$축 방향으로 $p$만큼, $y$축 방향으로 $q$만큼 평행이동하면 $g(x) = a^{x-p} + q$가 됩니다.

## 본문
지수함수 $f(x) = a^x$ ($a > 0, a \neq 1$)를 평행이동하면 함수의 형태가 변하지만, 그래프의 모양은 유지된 채 좌표평면 위에서 위치만 이동하게 됩니다. 수평 평행이동은 $x$ 대신 $x-p$를 대입하는 방식으로 이루어지며, 오른쪽으로 $p$만큼 이동하면 $g(x) = a^{x-p}$, 왼쪽으로 $p$만큼 이동하면 $g(x) = a^{x+p}$가 됩니다. 수직 평행이동은 함수 전체에 $q$를 더하는 방식으로 이루어지며, 위로 $q$만큼 이동하면 $g(x) = a^x + q$, 아래로 $q$만큼 이동하면 $g(x) = a^x - q$가 됩니다. 따라서 오른쪽으로 $p$만큼, 위로 $q$만큼 평행이동한 일반적인 형태는 $g(x) = a^{x-p} + q$로 나타낼 수 있습니다.

### 직관과 기하적 의미
지수함수의 평행이동은 그래프 전체를 통째로 밀어서 옮기는 것과 같습니다. 수평 평행이동의 경우, $x$ 자리에 $x-p$를 대입하면 원래의 함숫값이 나타나는 $x$ 값이 $p$만큼 커지게 되므로 그래프가 오른쪽으로 이동하게 됩니다. 예를 들어 $a^2$의 값이 원래 $x=2$에서 나타났다면, $a^{x-3}$에서는 $x=5$에서 동일한 값이 나타납니다. 수직 평행이동은 모든 점의 $y$좌표를 일괄적으로 변화시키는 과정입니다. 평행이동을 하더라도 함수의 증가 또는 감소 추세는 변하지 않지만, 함수의 치역(범위)과 점근선의 위치가 달라진다는 특징이 있습니다.

### 기본 성질
- **점근선**: $g(x) = a^{x-p} + q$의 점근선은 직선 $y = q$입니다.
- **증감 상태**: 밑 $a$의 값에 따른 함수의 증가 또는 감소 성질은 평행이동 후에도 그대로 유지됩니다.
- **대응 관계**: $f(x)$ 위의 점 $(x, y)$가 평행이동 후에는 $(x+p, y+q)$로 이동합니다.

## 학습 체크
- 평행이동된 함수 $g(x) = a^{x-p} + q$에서 점근선이 $y=q$임을 이용하여 $q$의 값을 구할 수 있는가?
- $f(x) = 2^x$를 오른쪽으로 1, 위로 3만큼 이동했을 때, 원래 함수 위의 점 $(1, 2)$가 이동한 좌표를 정확히 계산할 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수와 로그함수는 서로 역함수 관계에 있으며, $y=x$ 대칭인 그래프를 가집니다. 따라서 지수함수의 평행이동은 로그함수의 그래프 형태와 점근선 위치에 직접적인 영향을 미칩니다.
