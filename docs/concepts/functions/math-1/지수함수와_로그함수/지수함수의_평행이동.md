# 지수함수의 평행이동

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 정확한 진술

지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)를 평행이동한 함수는 다음과 같이 나타냅니다.

- **수평 평행이동**: 오른쪽으로 $p$만큼 이동하면 $g(x) = a^{x-p}$, 왼쪽으로 $p$만큼 이동하면 $g(x) = a^{x+p}$
- **수직 평행이동**: 위로 $q$만큼 이동하면 $g(x) = a^x + q$, 아래로 $q$만큼 이동하면 $g(x) = a^x - q$
- **일반형**: 오른쪽으로 $p$, 위로 $q$만큼 이동하면 $g(x) = a^{x-p} + q$

## 직관/기하적 의미

지수함수의 평행이동은 좌표평면에서 그래프 전체를 움직이는 것입니다. 수평 평행이동에서 $x$를 $(x-p)$로 바꾸면, 원래 함숫값이 $p$만큼 뒤에서 나타나므로 그래프가 오른쪽으로 이동합니다. 예를 들어 $a^2$의 값이 원래 $x=2$에서 나타났다면, $a^{x-3}$에서는 $x=5$에서 나타나게 됩니다.

수직 평행이동은 모든 점의 $y$좌표를 일괄적으로 증가 또는 감소시킵니다. 평행이동 후에도 **증가 추세**는 유지되지만, 함수값의 범위와 점근선이 달라집니다. 특히 $g(x) = a^{x-p} + q$의 점근선은 직선 $y = q$입니다.

## 한 줄 예

$f(x) = 2^x$를 오른쪽으로 1, 위로 3 평행이동하면 $g(x) = 2^{x-1} + 3$이고, 점 $(2, 7)$은 원래 함수의 점 $(1, 4)$에서 이동한 것입니다. (검증: $2^{2-1} + 3 = 2 + 3 = 5$ ✗ → 정정: $2^{2-1} + 3 = 2 + 3 = 5$, 원래 $f(1) = 2^1 = 2$이므로 $(1,2) \to (2, 5)$)
