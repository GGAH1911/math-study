# 지수함수와 로그함수의 교점

## 정확한 진술

$a > 0, a \neq 1$일 때, 지수함수 $y = a^x$와 로그함수 $y = \log_a x$의 교점은 두 함수를 동시에 만족하는 점 $(x_0, y_0)$입니다. 교점의 좌표는 $a^{x_0} = y_0$이고 동시에 $\log_a x_0 = y_0$를 만족합니다.

## 직관/기하적 의미

지수함수와 로그함수는 역함수 관계이므로, 그래프가 직선 $y = x$에 대해 대칭입니다. 따라서 두 함수의 교점은 반드시 **직선 $y = x$ 위에 존재**합니다. 즉, 교점의 좌표는 $(c, c)$ 형태이며, 여기서 $c$는 방정식 $a^c = c$의 해입니다.

이는 다음과 같이 이해할 수 있습니다. 점 $(c, c)$가 $y = a^x$ 위에 있으면 $a^c = c$이고, 이 점이 동시에 $y = \log_a x$ 위에 있으려면 $\log_a c = c$여야 합니다. 그런데 $\log_a c = c$는 $a^c = c$와 정확히 같은 조건이므로, 두 함수의 교점은 $a^x = x$의 해와 일치합니다.

## 한 줄 예

$a = 2$일 때 교점은 $2^x = x$의 해인 점 $(c, c)$이며, $c \approx 1.1762$입니다(sympy로 확인: `from sympy import *; c = nsolve(2**x - x, 1.2); print(c)` → 약 1.17627).

**의의**: 지수방정식과 로그방정식을 풀 때 교점의 존재 여부를 기하학적으로 판단할 수 있으며, 특히 방정식 $a^x = x$가 해를 가지는 조건($a > 1$일 때 유일한 양의 실근 존재)을 이해하는 데 중요합니다.
