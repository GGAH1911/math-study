# 로그함수의 평행이동

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
로그함수 $f(x) = \log_a x$를 $x$축 방향으로 $p$만큼, $y$축 방향으로 $q$만큼 평행이동하면 $g(x) = \log_a(x - p) + q$가 됩니다.

## 본문
로그함수 $f(x) = \log_a x$ ($a > 0, a \neq 1$)를 $x$축 방향으로 $p$만큼, $y$축 방향으로 $q$만큼 평행이동한 함수는 $g(x) = \log_a(x - p) + q$로 나타냅니다. 이때 $p$의 부호에 따라 오른쪽($p > 0$) 또는 왼쪽($p < 0$)으로 이동하며, $q$의 부호에 따라 위($q > 0$) 또는 아래($q < 0$)로 이동합니다.

### 직관과 기하적 의미
원래 로그함수 $\log_a x$는 점 $(1, 0)$을 지나며 $x$축을 점근선으로 가집니다. 함수를 오른쪽으로 이동시키면 동일한 함숫값에 도달하기 위해 더 큰 $x$값이 필요하므로 $x$ 대신 $x-p$를 대입하게 됩니다. 또한 함수 전체를 위아래로 움직이기 위해 상수항 $q$를 더합니다. 평행이동 후의 점근선은 $x = p$로 변하며, 그래프는 반드시 점 $(p+1, q)$를 통과하게 됩니다.

### 기본 성질
평행이동을 하더라도 밑 $a$의 조건에 따른 함수의 증가 또는 감소 성질은 변하지 않습니다. 즉, $a > 1$이면 증가함수, $0 < a < 1$이면 감소함수의 형태를 그대로 유지합니다.

## 학습 체크
- 평행이동된 함수 $g(x) = \log_a(x - p) + q$에서 새로운 점근선의 방정식은 무엇인가?
- 함수 $g(x) = \log_a(x - p) + q$가 반드시 지나는 한 점의 좌표를 구하시오.

## 관련 개념
- **지수함수와 로그함수**: 로그함수는 지수함수의 역함수이므로, 지수함수의 평행이동은 로그함수의 점근선과 그래프 형태에 대칭적인 변화를 일으킵니다.
