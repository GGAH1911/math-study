# 지수 로그 역함수 관계

> **정리** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
지수함수 $f(x) = a^x$와 로그함수 $g(x) = \log_a x$는 서로 역함수 관계이며, 두 함수의 그래프는 직선 $y = x$에 대하여 대칭입니다.

## 본문
밑 $a$ ($a > 0, a \neq 1$)에 대하여 지수함수 $f(x) = a^x$와 로그함수 $g(x) = \log_a x$는 서로 역함수입니다. 즉, $f^{-1} = g$이고 $g^{-1} = f$입니다. 따라서 두 함수의 그래프는 직선 $y = x$에 대해 선대칭인 형태를 띱니다.

### 증명 스케치
역함수의 정의에 따라 $y = a^x$일 때 $x = \log_a y$가 성립합니다. 이를 다시 쓰면 $y = a^x \Leftrightarrow x = \log_a y$입니다. 역함수를 구하기 위해 $x$와 $y$의 위치를 바꾸면 $x = a^y \Leftrightarrow y = \log_a x$가 됩니다. 따라서 $y = a^x$의 역함수는 $y = \log_a x$임이 증명됩니다.

그래프의 대칭성은 역함수의 성질에서 기인합니다. 원함수의 그래프 위의 점 $(p, q)$에 대하여 역함수의 그래프 위에는 반드시 $(q, p)$가 존재합니다. 점 $(p, q)$와 $(q, p)$는 직선 $y = x$에 대해 대칭이므로, 두 함수의 그래프 전체가 $y = x$에 대해 대칭을 이룹니다.

### 의의와 응용
지수함수와 로그함수의 역함수 관계는 다음과 같은 수학적 도구를 제공합니다.

- **정의역과 치역의 교환**: $a^x$의 정의역인 실수 전체의 집합은 $\log_a x$의 치역이 되고, $a^x$의 치역인 양의 실수 전체의 집합은 $\log_a x$의 정의역이 됩니다.
- **방정식 풀이 및 동치 변환**: $a^x = b$ 형태의 방정식은 $x = \log_a b$로 변환하여 풀 수 있으며, 반대로 $\log_a x = c$는 $x = a^c$로 변환할 수 있습니다. 이를 통해 복잡한 지수 또는 로그 방정식을 상대방의 형태로 바꾸어 문제를 단순화할 수 있습니다.

예를 들어, $2^x = 8$이라는 방정식은 $x = \log_2 8 = 3$으로 간단히 해결할 수 있습니다.
