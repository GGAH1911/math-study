# 함수 그래프의 교점

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
두 함수의 그래프가 좌표평면 위에서 만나는 점을 교점이라 하며, 이는 방정식 $f(x) = g(x)$의 실근과 대응한다.

## 본문
두 함수 $f(x)$와 $g(x)$의 그래프의 교점은 두 함수를 동시에 만족하는 점 $(a, b)$를 의미한다. 즉, $x$값이 $a$일 때 두 함수의 함숫값이 $b$로 같아야 하므로 $f(a) = g(a) = b$를 만족해야 한다. 이때 교점의 $x$좌표는 방정식 $f(x) = g(x)$의 해가 되며, $y$좌표는 해당 해를 함수식에 대입하여 얻는다.

### 직관과 기하적 의미
좌표평면에 두 함수의 그래프를 그렸을 때 선들이 서로 맞닿는 지점이 바로 교점이다. 따라서 두 그래프의 교점의 개수는 방정식 $f(x) = g(x)$가 가지는 서로 다른 실근의 개수와 일치한다. 예를 들어 지수함수 $y = a^x$와 직선 $y = mx + n$의 교점을 찾기 위해서는 $a^x = mx + n$이라는 방정식을 풀어야 한다.

### 기본 성질
어떤 함수와 그 역함수의 교점은 항상 직선 $y = x$ 위에 존재한다. 이는 역함수의 그래프가 원래 함수의 그래프를 직선 $y = x$에 대하여 대칭이동시킨 것이기 때문이다.

## 학습 체크
- 교점의 $x$좌표를 구하기 위해 세워야 하는 방정식의 형태는 무엇인가?
- 두 함수의 그래프가 만나는 점의 개수와 방정식의 실근 사이에는 어떤 관계가 있는가?
- 함수와 그 역함수의 교점이 $y = x$ 위에 존재하는 이유는 무엇인가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수와 로그함수는 서로 역함수 관계에 있으므로, 두 함수의 교점은 직선 $y = x$ 위에서 나타난다.
