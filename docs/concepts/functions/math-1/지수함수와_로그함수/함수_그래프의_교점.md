# 함수 그래프의 교점

## 정확한 진술

두 함수 $f(x)$와 $g(x)$의 그래프의 **교점**이란, 같은 점 $(a, b)$를 두 그래프 위에서 동시에 만족하는 점입니다. 즉, $a$에서 두 함수값이 같을 때, 곧 $f(a) = g(a) = b$를 만족하는 점입니다. 

좌표로 표현하면, 교점의 $x$좌표는 **방정식** $f(x) = g(x)$의 해이고, 대응하는 $y$좌표는 이 해를 함수에 대입해서 구합니다.

## 직관/기하적 의미

두 그래프를 좌표평면에 그렸을 때, 만나는 지점이 바로 교점입니다. 교점의 개수는 방정식 $f(x) = g(x)$가 가지는 **서로 다른 실근의 개수**와 정확히 같습니다. 예를 들어 지수함수 $y = a^x$와 직선 $y = mx + n$의 교점을 찾으려면, $a^x = mx + n$을 풀어야 합니다.

특히 어떤 함수와 그 **역함수**의 교점은 직선 $y = x$ 위에만 존재합니다. 이는 역함수의 그래프가 원함수의 그래프를 직선 $y = x$에 대해 대칭이기 때문입니다.

## 한 줄 예

$y = 2^x$와 $y = x + 1$의 교점을 구하려면 방정식 $2^x = x + 1$을 풀면 됩니다.

**검산**: $x = 0$일 때 $2^0 = 1$, $0 + 1 = 1$ (교점: $(0, 1)$); $x = 2$일 때 $2^2 = 4$, $2 + 1 = 3$ (교점 아님). `sympy.solve(2**x - (x + 1), x)`로 모든 교점을 구할 수 있습니다. 이 경우 $x = 0$과 $x = 2$에서 교점을 가집니다(근사값 확인 필요).
