# 지수방정식 풀이

> **예제** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
지수방정식은 지수에 미지수가 포함된 방정식으로, 양변의 밑을 같게 만들어 지수끼리 비교하여 해를 구합니다.

## 본문
$$2^x = 8$$

### 단계별 풀이
지수방정식은 지수가 변수인 방정식입니다. 풀이의 핵심은 양변을 같은 밑으로 표현하는 것입니다.

**1단계: 우변을 밑 2로 표현하기**
$8$을 2의 거듭제곱으로 나타내면 $8 = 2^3$입니다. 따라서 원래 식은 $2^x = 2^3$이 됩니다.

**2단계: 지수 비교**
$a > 0, a \neq 1$일 때, $a^m = a^n$이면 $m = n$입니다. 양변의 밑이 같은 2이므로, 지수끼리 같아야 합니다. 즉, $x = 3$입니다.

**3단계: 검증**
$x=3$을 원래 식에 대입하면 $2^3 = 8$이 되어 식이 성립함을 확인할 수 있습니다.

### 답과 변형
**답**
$$x = 3$$

**변형 및 주의점**
예제 2) $3^{2x-1} = 27$
$27 = 3^3$이므로 $3^{2x-1} = 3^3$입니다. 지수를 비교하면 $2x - 1 = 3$이 되어 $x = 2$를 얻습니다.

밑을 통일할 수 없는 경우: $2^x = 5$와 같이 양변을 같은 밑으로 만들 수 없는 방정식은 로그를 이용해 $x = \log_2 5$ 또는 $x = \tfrac{\ln 5}{\ln 2}$와 같이 풀어야 합니다.

주의사항: 밑은 항상 양수이고 1이 아니어야 합니다. $a^x = b$ 형태에서 $a > 0, a \neq 1, b > 0$ 조건을 만족하지 않으면 실수해가 존재하지 않을 수 있습니다.

## 학습 체크
- 양변의 밑을 동일하게 맞출 수 있는가?
- 지수끼리의 비교를 통해 미지수의 값을 정확히 도출했는가?
- 밑의 조건($a > 0, a \neq 1$)과 결과값($b > 0$)을 확인했는가?

## 관련 개념
- **지수함수와 로그함수**: 지수방정식의 해를 구하는 과정에서 로그의 정의가 핵심적인 역할을 하며, 밑을 통일할 수 없는 경우 로그를 통해 해를 표현합니다.
