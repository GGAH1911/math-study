# 지수방정식 풀이

> **예제** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)
## 요약
$2^x=8$ 같은

## 본문

### 문제

다음 지수방정식을 풀어보겠습니다.

$$2^x = 8$$

### 단계별 풀이

지수방정식은 **지수가 변수인 방정식**입니다. 풀이의 핵심은 양변을 같은 밑으로 표현하는 것입니다.

**1단계: 우변을 밑 2로 표현하기**

$8$을 2의 거듭제곱으로 나타냅니다:
$$8 = 2^3$$

따라서 원래 식은:
$$2^x = 2^3$$

**2단계: 지수 비교**

$a > 0, a \neq 1$일 때, $a^m = a^n$이면 $m = n$입니다.

양변의 밑이 같은 2이므로, 지수끼리 같아야 합니다:
$$x = 3$$

**3단계: 검증**

$x=3$을 원래 식에 대입하면:
$$2^3 = 8 \,\checkmark$$

### 답

$$x = 3$$

### 변형/주의점

**예제 2**: $3^{2x-1} = 27$

$27 = 3^3$이므로:
$$3^{2x-1} = 3^3$$
$$2x - 1 = 3$$
$$x = 2$$

**밑을 통일할 수 없는 경우**: $2^x = 5$ 같은 방정식은 양변을 같은 밑으로 만들 수 없습니다. 이 경우 **로그**를 이용해 풀어야 합니다:
$$x = \log_2 5$$

또는 상용로그나 자연로그로:
$$x = \frac{\ln 5}{\ln 2} \approx 2.32$$

**주의**: 밑은 항상 양수이고 1이 아니어야 하므로, $a^x = b$ 형태에서 $a > 0, a \neq 1, b > 0$이어야 실수해 없습니다.
