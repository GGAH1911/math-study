# 로그방정식

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
미지수가 로그의 밑이나 진수에 포함된 방정식을 로그방정식이라 하며, 로그의 성질을 이용하여 진수 또는 지수 형태로 변환하여 해결합니다.

## 본문
로그방정식이란 미지수가 로그의 밑이나 진수에 포함되어 있는 방정식을 말합니다. 일반적인 형태는 $\log_a f(x) = b$ 또는 $\log_a f(x) = \log_a g(x)$와 같습니다. 이때 밑의 조건인 $a > 0, a \neq 1$을 만족해야 하며, 로그의 정의에 따라 진수 조건인 $f(x) > 0$ 및 $g(x) > 0$이 반드시 성립해야 합니다.

### 직관과 기하적 의미
로그방정식을 푸는 과정은 본질적으로 지수방정식을 푸는 것과 같습니다. 로그는 지수의 역함수 관계에 있기 때문입니다. 예를 들어 $2^x = 8$을 푸는 것과 $\log_2 8 = x$를 푸는 것은 수학적으로 동일한 의미를 갖습니다. 실생활에서는 인구 증가, 방사능 붕괴, 복리 계산과 같은 지수적 현상에서 특정 시간이나 조건을 역으로 추적할 때 로그방정식이 유용하게 사용됩니다.

### 기본 성질
로그방정식을 해결하는 주요 전략은 두 가지입니다. 첫째, 양변이 같은 밑을 가진 로그 형태라면 로그의 성질을 이용하여 진수끼리 같다고 놓는 방법입니다($\log_a f(x) = \log_a g(x) \Rightarrow f(x) = g(x)$). 둘째, 로그의 정의를 이용하여 로그식을 지수 형태로 변환하는 방법입니다($\log_a f(x) = b \Rightarrow f(x) = a^b$).

## 학습 체크
- 방정식을 푼 후, 구한 해가 로그의 진수 조건($f(x) > 0$)을 만족하는지 반드시 확인했는가?
- 로그의 성질을 사용하여 식을 정리할 때, 진수가 음수가 되지 않도록 주의하였는가?

## 관련 개념
- **지수와 로그**: 로그는 지수의 역함수 관계에 있으므로, 로그방정식의 해법은 지수방정식의 원리와 직결됩니다.
