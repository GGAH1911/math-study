# 로그방정식

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 정확한 진술

로그방정식이란 미지수가 로그의 밑이나 진수에 포함되어 있는 방정식입니다. 일반적인 형태는 다음과 같습니다:

$$\log_a f(x) = b \quad \text{또는} \quad \log_a f(x) = \log_a g(x)$$

여기서 $a$는 밑 ($a > 0, a \neq 1$), $f(x)$와 $g(x)$는 $x$에 대한 식이며, $f(x) > 0, g(x) > 0$이어야 합니다.

## 직관 및 의미

로그방정식을 푼다는 것은 지수방정식을 푸는 것과 본질적으로 같은 작업입니다. 로그는 지수의 역함수이기 때문입니다. 예를 들어 "$2^x = 8$을 푼다"와 "$\log_2 8 = x$를 푼다"는 같은 문제입니다. 로그방정식은 실생활의 지수적 현상(인구 증가, 방사능 감소, 복리 계산 등)에서 역으로 특정 시간이나 조건을 구할 때 나타납니다. 정의역 조건($f(x) > 0$)을 항상 확인해야 한다는 점이 중요합니다.

## 기본 풀이 전략

**방법 1:** 양변이 같은 밑의 로그일 때, 진수끼리 같다고 놓습니다.
$$\log_a f(x) = \log_a g(x) \Rightarrow f(x) = g(x)$$

**방법 2:** 로그를 지수 형태로 변환합니다.
$$\log_a f(x) = b \Rightarrow f(x) = a^b$$

## 간단한 예

$\log_3(x+1) = 2$를 풀어봅시다.

지수 형태로 변환하면: $x + 1 = 3^2 = 9$

따라서 $x = 8$입니다. 정의역 확인: $x + 1 = 9 > 0$ ✓

또 다른 예: $\log_2 x + \log_2(x-2) = 3$

로그의 성질 $\log_a m + \log_a n = \log_a(mn)$를 이용하면:
$$\log_2[x(x-2)] = 3$$
$$x(x-2) = 2^3 = 8$$
$$x^2 - 2x - 8 = 0$$
$$(x-4)(x+2) = 0$$

정의역: $x > 0$이고 $x - 2 > 0$이므로 $x > 2$. 따라서 $x = 4$만 해입니다.
