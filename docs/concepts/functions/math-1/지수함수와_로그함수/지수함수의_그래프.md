# 지수함수의 그래프

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
밑 $a$의 범위에 따라 증가 또는 감소하는 곡선 형태를 띠며, $y$축 대칭 관계를 가질 수 있는 함수입니다.

## 본문
지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)는 밑 $a$의 값에 따라 그래프의 개형이 결정되는 함수입니다. $a > 1$인 경우에는 $x$값이 증가함에 따라 함수값이 급격히 증가하는 형태를 보이며, $0 < a < 1$인 경우에는 $x$값이 증가함에 따라 함수값이 감소하는 형태를 보입니다. 모든 지수함수의 그래프는 $x$축을 점근선으로 가지며, $y$축과 $(0, 1)$에서 만나는 매끄러운 곡선입니다.

### 직관과 기하적 의미
지수함수의 그래프는 밑 $a$의 크기에 따라 서로 다른 형태를 띱니다. $a > 1$인 경우, 그래프는 왼쪽에서 오른쪽으로 올라가는 곡선입니다. $x$가 음수일 때는 $0$에 가까워지고, $x$가 양수일 때는 값이 빠르게 증가합니다. 예를 들어 $f(x) = 2^x$는 $x$가 $1$씩 증가할 때마다 함수값이 $2$배씩 늘어납니다. 반대로 $0 < a < 1$인 경우, 그래프는 왼쪽에서 오른쪽으로 내려가는 곡선입니다. $x$가 음수일 때 값이 빠르게 증가하고, $x$가 양수일 때는 $0$에 가까워집니다. 이때 $f(x) = \left(\frac{1}{2}\right)^x$는 $a > 1$인 경우의 그래프를 $y$축에 대하여 대칭시킨 모양과 같습니다.

### 기본 성질
- 정의역: 모든 실수
- 치역: 양수 전체 $(0, \infty)$
- $y$절편: $(0, 1)$
- 점근선: $x$축 ($y = 0$)
- 함수의 증감: $a > 1$일 때 증가, $0 < a < 1$일 때 감소

## 학습 체크
- 밑 $a$의 조건이 왜 $a > 0$이며 $a \neq 1$이어야 하는가?
- 지수함수의 그래프가 $x$축과 만나지 않는 이유는 무엇인가?
- $f(x) = a^x$와 $g(x) = (1/a)^x$의 그래프는 어떤 관계를 갖는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수 $y = a^x$의 역함수는 로그함수 $y = \log_a x$이며, 두 함수의 그래프는 직선 $y = x$에 대하여 대칭입니다.
