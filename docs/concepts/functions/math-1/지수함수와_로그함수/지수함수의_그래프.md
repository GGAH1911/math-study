# 지수함수의 그래프

## 정확한 진술

지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)의 그래프는 다음 성질을 만족합니다:

- **정의역**: 모든 실수
- **치역**: 양수 전체 $(0, \infty)$
- **y절편**: $(0, 1)$
- **점근선**: x축 (y = 0)
- **함수값**: $a > 1$일 때 지속 증가, $0 < a < 1$일 때 지속 감소

## 직관 및 기하적 의미

지수함수의 그래프는 밑 $a$의 크기에 따라 서로 다른 형태를 띱니다.

**$a > 1$인 경우**: 그래프는 왼쪽에서 오른쪽으로 올라가는 곡선입니다. $x$가 음수일 때는 0에 가까워지고, $x$가 양수일 때는 빠르게 증가합니다. 예를 들어 $f(x) = 2^x$는 $x$가 1씩 증가할 때마다 함수값이 2배씩 늘어나죠.

**$0 < a < 1$인 경우**: 그래프는 반대로 왼쪽에서 오른쪽으로 내려가는 곡선입니다. $x$가 음수일 때 빠르게 증가하고, $x$가 양수일 때는 0에 가까워집니다. $f(x) = \left(\frac{1}{2}\right)^x$는 $a > 1$인 경우의 그래프를 y축 대칭시킨 모양입니다.

모든 경우 그래프는 $(0, 1)$을 지나고, x축을 결코 만나지 않으며, 매끄러운 곡선을 이룹니다.

## 한 줄 예제

$f(x) = 2^x$와 $g(x) = \left(\frac{1}{2}\right)^x = 2^{-x}$는 y축 대칭이며, 각각 $(0, 1)$을 통과하는 증가/감소 곡선입니다.
