# 지수함수

> **정의** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)
## 요약
$y=a^x$ ($a>0, a\ne 1$)

## 본문

$a > 0$이고 $a \ne 1$인 상수 $a$에 대해, 모든 실수 $x$를 정의역으로 하는 함수 $y = a^x$를 **지수함수**라고 합니다. 여기서 $a$를 **밑**(base)이라 부르며, $x$를 **지수**라고 합니다. 조건 $a > 0$은 $a^x$가 모든 실수 $x$에 대해 정의되도록 보장하며, $a \ne 1$ 조건은 상수함수를 제외하기 위한 것입니다.

### 직관과 기하적 의미

지수함수 $y = a^x$는 언제나 양수이므로 치역은 $(0, \infty)$입니다. 따라서 그래프는 $x$축 위쪽에만 존재합니다.

**$a > 1$인 경우** $x$가 증가하면 함수값이 기하급수적으로 증가하는 **지수적 성장**을 나타냅니다. 예를 들어 $y = 2^x$는 $x = -\infty$에 가까워질수록 0에 수렴하고, $x$가 양수로 커질수록 급격히 상승합니다.

**$0 < a < 1$인 경우** $x$가 증가하면 함수값이 감소하는 **지수적 감소** 현상을 보입니다. 예를 들어 $y = \left(\frac{1}{2}\right)^x$의 그래프는 $y = 2^x$를 $y$축 기준으로 대칭 이동한 형태입니다.

모든 지수함수는 점 $(0, 1)$을 지나갑니다. 모든 $a > 0$에 대해 $a^0 = 1$이기 때문입니다.

### 한 줄 예

$y = 3^x$는 밑이 3인 지수함수로, $x = 0$일 때 $y = 1$, $x = 1$일 때 $y = 3$, $x = 2$일 때 $y = 9$입니다.

```python
# 검증
[3**x for x in [0, 1, 2]]  # [1, 3, 9]
```
