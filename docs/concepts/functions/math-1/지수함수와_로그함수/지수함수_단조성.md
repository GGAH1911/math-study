# 지수함수 단조성

> **정리** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)
## 요약
$a>1$이면 증가, $0<a<1$이면 감소

## 본문

### 진술 및 가정

지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)에 대해 다음이 성립합니다:
- **$a > 1$일 때**: $f(x) = a^x$는 $\mathbb{R}$ 위에서 **증가함수**
- **$0 < a < 1$일 때**: $f(x) = a^x$는 $\mathbb{R}$ 위에서 **감소함수**

즉, $x_1 < x_2$일 때 $a > 1$이면 $a^{x_1} < a^{x_2}$이고, $0 < a < 1$이면 $a^{x_1} > a^{x_2}$입니다.

### 증명 스케치

$x_1 < x_2$인 임의의 두 실수를 택하고 $\Delta x = x_2 - x_1 > 0$으로 놓겠습니다.

**경우 1: $a > 1$일 때**

$$\frac{a^{x_2}}{a^{x_1}} = a^{x_2 - x_1} = a^{\Delta x}$$

$\Delta x > 0$이고 $a > 1$이므로, 밑이 1보다 크면 지수가 양수일 때 그 값은 1보다 큽니다. 즉 $a^{\Delta x} > 1$이므로 $a^{x_2} > a^{x_1}$입니다.

**경우 2: $0 < a < 1$일 때**

같은 식에서 밑이 1보다 작으면 양수 지수일 때 그 값은 1보다 작습니다. 따라서 $a^{\Delta x} < 1$이므로 $a^{x_2} < a^{x_1}$입니다.

### 의의 및 응용

이 단조성은 지수방정식·부등식을 풀 때 핵심입니다:

- $2^x = 2^3 \Rightarrow x = 3$ (밑 2는 증가함수이므로 지수만 비교)
- $2^x > 2^3 \Rightarrow x > 3$ (부등호 방향 유지)
- $\left(\frac{1}{2}\right)^x < \left(\frac{1}{2}\right)^3 \Rightarrow x > 3$ (부등호 방향 **역전**!)

또한 이 성질로부터 **지수함수는 일대일 대응**임을 알 수 있으므로 역함수(로그함수)의 존재를 보장합니다. 예를 들어 $a > 1$일 때 $\log_a$는 증가함수, $0 < a < 1$일 때 $\log_a$는 감소함수가 되는 것입니다.
