# 지수함수 단조성

> **정리** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
밑 $a$가 $1$보다 크면 증가하고, $0$과 $1$ 사이이면 감소한다.

## 본문
지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)에 대하여, 밑 $a$의 값에 따라 함수의 증감이 결정됩니다. $a > 1$이면 $f(x)$는 실수 전체의 집합 $\mathbb{R}$에서 증가함수이며, $0 < a < 1$이면 $f(x)$는 실수 전체의 집합 $\mathbb{R}$에서 감소함수입니다. 이를 수식으로 나타내면 $x_1 < x_2$일 때 $a > 1$이면 $a^{x_1} < a^{x_2}$이고, $0 < a < 1$이면 $a^{x_1} > a^{x_2}$가 성립합니다.

### 증명 스케치
$x_1 < x_2$인 임의의 두 실수를 택하고 $\Delta x = x_2 - x_1 > 0$으로 설정합니다. 이때 $\tfrac{a^{x_2}}{a^{x_1}} = a^{x_2 - x_1} = a^{\Delta x}$입니다.

**경우 1: $a > 1$일 때**
$\Delta x > 0$이고 $a > 1$이므로 $a^{\Delta x} > 1$입니다. 따라서 $a^{x_2} > a^{x_1}$이 성립하여 함수는 증가합니다.

**경우 2: $0 < a < 1$일 때**
$\Delta x > 0$이지만 $a < 1$이므로 $a^{\Delta x} < 1$입니다. 따라서 $a^{x_2} < a^{x_1}$이 성립하여 함수는 감소합니다.

### 의의와 응용
이 성질은 지수방정식과 부등식을 해결하는 핵심 도구입니다. 밑이 $1$보다 크면 지수의 대소 관계와 부등호의 방향이 일치하지만, 밑이 $0$과 $1$ 사이이면 부등호의 방향이 반대로 바뀝니다. 또한 지수함수가 일대일 대응임을 보장하여 역함수인 로그함수의 존재를 가능하게 합니다. 이에 따라 $a > 1$일 때 로그함수는 증가함수가 되고, $0 < a < 1$일 때 로그함수는 감소함수가 됩니다.

## 학습 체크
- 밑의 범위에 따라 지수 부등식의 부등호 방향이 어떻게 변하는가?
- 지수함수의 단조성이 로그함수의 증가/감소 성질과 어떻게 연결되는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수의 단조성은 로그함수가 일대일 대응임을 증명하며, 밑의 조건에 따른 로그함수의 증감 성질을 결정합니다.
