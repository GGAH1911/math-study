### 정확한 진술

두 각 $\alpha$, $\beta$에 대해 다음이 성립합니다.

$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha \tan\beta}$$

$$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha \tan\beta}$$

(단, $\tan\alpha$, $\tan\beta$, $\tan(\alpha \pm \beta)$가 모두 정의되어야 하고, 분모가 0이 아니어야 합니다.)

### 유도 및 의미

삼각함수의 기본 항등식에서 시작합니다.

$$\tan(\alpha + \beta) = \frac{\sin(\alpha + \beta)}{\cos(\alpha + \beta)} = \frac{\sin\alpha\cos\beta + \cos\alpha\sin\beta}{\cos\alpha\cos\beta - \sin\alpha\sin\beta}$$

분자와 분모를 모두 $\cos\alpha\cos\beta$로 나누면:

$$\tan(\alpha + \beta) = \frac{\frac{\sin\alpha}{\cos\alpha} + \frac{\sin\beta}{\cos\beta}}{1 - \frac{\sin\alpha}{\cos\alpha} \cdot \frac{\sin\beta}{\cos\beta}} = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

이 공식은 **기울기의 합과 관련**됩니다. 직선의 기울기를 탄젠트로 표현할 때, 두 직선이 이루는 각의 탄젠트 값을 구하려면 이 공식을 씁니다. 특히 $\tan\alpha\tan\beta = 1$에 가까워질수록 분모가 0에 접근하므로, 두 직선이 거의 수직이 됨을 나타냅니다.

### 구체적 예

$\tan 15° = \tan(45° - 30°)$를 구하면:

$$\tan 15° = \frac{\tan 45° - \tan 30°}{1 + \tan 45° \tan 30°} = \frac{1 - \frac{1}{\sqrt{3}}}{1 + \frac{1}{\sqrt{3}}} = \frac{\sqrt{3} - 1}{\sqrt{3} + 1} = 2 - \sqrt{3}$$

검증: `sympy.simplify((sympy.sqrt(3) - 1)/(sympy.sqrt(3) + 1))`는 $2 - \sqrt{3}$를 반환합니다.
