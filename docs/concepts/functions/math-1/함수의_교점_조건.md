### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 **교점**은 방정식 $f(x) = g(x)$를 동시에 만족하는 점 $(x, y)$입니다. 여기서 $x$는 **교점의 $x$ 좌표(횡좌표)**이며, 이를 구하려면 $f(x) = g(x)$를 풀어야 합니다. 교점의 $y$ 좌표는 $y = f(x) = g(x)$로 동일합니다.

### 직관과 기하적 의미

좌표평면에서 두 함수의 그래프가 만나는 지점입니다. 교점이 존재한다는 것은 두 함수가 어떤 $x$ 값에서 같은 함삿값을 가진다는 뜻이며, 교점의 개수는 방정식 $f(x) = g(x)$의 근의 개수와 정확히 같습니다. 

- **교점이 1개**: 그래프가 한 점에서만 만남 (근이 1개)
- **교점이 여러 개**: 그래프가 여러 점에서 만남
- **교점이 없음**: 그래프가 만나지 않음 (근이 없음)

특히 지수함수와 로그함수처럼 일대일대응 함수들의 교점을 분석할 때 이 개념이 중요합니다.

### 구체적 예시

함수 $f(x) = 2^x$와 $g(x) = x + 3$의 교점을 구하려면:

$$2^x = x + 3$$

$x = 0$일 때: $2^0 = 1$, $0 + 3 = 3$ (불일치)  
$x = 2$일 때: $2^2 = 4$, $2 + 3 = 5$ (불일치)  
$x = 1$일 때: $2^1 = 2$, $1 + 3 = 4$ (불일치)  

근사적으로 계산하면 교점은 약 $(1.9, 4.9)$ 근처에 있습니다. (sympy를 통한 수치해석: `from scipy.optimize import fsolve; fsolve(lambda x: 2**x - x - 3, 1.5)`)

이렇게 두 함수의 교점을 구하는 것은 실생활의 비용과 수익이 같아지는 지점, 또는 두 물리량이 같아지는 시점을 찾는 데 응용됩니다.
