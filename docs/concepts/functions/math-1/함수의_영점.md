### 정확한 진술

함수 $f(x)$의 **영점**(零點, zero)은 $f(x) = 0$을 만족하는 $x$의 값입니다. 즉, 방정식 $f(x) = 0$의 모든 해가 함수 $f$의 영점입니다. 함수가 여러 개의 영점을 가질 수 있으며, 영점이 없을 수도 있습니다.

### 기하적 의미

함수의 그래프를 생각할 때, 영점은 **그래프가 $x$축과 만나는 점의 $x$좌표**입니다. 예를 들어 이차함수 $f(x) = x^2 - 5x + 6$의 그래프는 두 개의 점 $(2, 0)$과 $(3, 0)$에서 $x$축과 만나므로, 이 함수의 영점은 $x = 2$와 $x = 3$입니다. 

함수의 영점은 방정식을 푸는 것과 같습니다. "함수의 영점을 구하세요"라는 문제는 "방정식을 풀어 $x$값을 구하세요"라는 뜻입니다. 수학1에서는 다항함수, 지수함수, 삼각함수 등 여러 종류의 함수에서 영점을 찾는 문제가 자주 나타납니다.

### 예: 삼각함수의 영점

삼각함수 $f(x) = \sin x$의 영점을 구합니다. $\sin x = 0$을 만족하는 $x$는 $x = n\pi$ (단, $n$은 정수)이므로, $\sin x$의 영점은 모든 정수배의 $\pi$입니다.

범위를 제한하면 더 명확합니다. $0 \le x < 2\pi$ 범위에서 $\sin x = 0$의 해는 $x = 0, \pi, 2\pi$입니다. 따라서 이 범위에서의 영점은 $x = 0$, $x = \pi$입니다.

더 구체적으로, $\sin x = \cos x$의 영점을 구하면:
$$\sin x - \cos x = 0$$
$$\sin x = \cos x$$
$$\tan x = 1$$

따라서 $x = \frac{\pi}{4} + n\pi$가 해입니다. 이 방정식의 모든 해가 함수 $f(x) = \sin x - \cos x$의 영점입니다.
