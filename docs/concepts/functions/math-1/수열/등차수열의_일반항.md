# 등차수열의 일반항

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 정확한 진술

첫째항이 $a_1$이고 공차가 $d$인 등차수열의 $n$번째 항은 다음 공식으로 구한다:

$$a_n = a_1 + (n-1)d \quad (n \geq 1)$$

이 식을 등차수열의 **일반항 공식** 또는 **일반항**이라 한다.

## 직관: 첫 항에서 공차를 몇 번 더하는가?

등차수열은 정의상 이웃한 두 항의 차가 항상 공차 $d$로 일정하다. 따라서 첫째항 $a_1$에서 출발할 때:

- $a_1$ = 첫째항
- $a_2 = a_1 + d$ (공차를 1번 더함)
- $a_3 = a_1 + 2d$ (공차를 2번 더함)
- $a_4 = a_1 + 3d$ (공차를 3번 더함)
- ⋮
- $a_n = a_1 + (n-1)d$ (공차를 $(n-1)$번 더함)

$n$번째 항에 도달하려면 첫째항에서 출발해 공차를 정확히 $(n-1)$번 더해야 한다는 뜻이다. 이것이 일반항 공식의 본질이며, 수열을 한눈에 이해하는 핵심이다.

## 한 줄 예

첫째항이 2이고 공차가 3인 등차수열 $2, 5, 8, 11, \ldots$에서 다섯 번째 항은 $a_5 = 2 + (5-1) \times 3 = 14$이다. (또는 `sympy.symbols('n'); a1=2; d=3; a_n=a1+(n-1)*d; a_n.subs(n, 5)` → 14)
