# 초기값 결정

## 정확한 진술

수열 $\{a_n\}$을 점화식(재귀 관계식)으로 정의할 때, 수열의 모든 항을 유일하게 결정하기 위해 필요한 첫 몇 항의 값을 **초기값**이라고 합니다. 예를 들어 $a_{n+1} = 2a_n + 1$ 형태의 점화식이 주어졌을 때, $a_1$의 값을 정하지 않으면 $a_2, a_3, \ldots$을 구할 수 없으므로, $a_1 = 3$ 같은 초기값이 반드시 필요합니다.

## 직관과 의미

점화식은 인접한 항들의 관계만 나타낼 뿐, 수열이 어디에서 시작하는지는 알려주지 않습니다. **초기값은 수열의 "출발점"을 정하는 조건**으로, 이를 정함으로써 무수히 많은 수열 중 정확히 하나의 수열을 결정할 수 있습니다. 점화식의 계수나 상수항이 같더라도 초기값이 다르면 완전히 다른 수열이 됩니다.

또한 일반항 공식 $a_n = f(n)$을 구할 때, 점화식을 풀어서 나온 일반 해(general solution)에 포함된 상수를 결정하는 데 초기값이 사용됩니다.

## 한 줄 예

$a_{n+1} = a_n + 2$이고 $a_1 = 1$이면 수열은 $1, 3, 5, 7, \ldots$로 유일하게 결정되며, 일반항은 $a_n = 2n - 1$입니다. (검산: `sympy.solve(a_1 + 2*(n-1) - (2*n - 1), n)`는 항등식)

## 계수가 여러 개인 경우

2계 점화식 $a_{n+2} = a_{n+1} + a_n$ (예: 피보나치 수열)에는 초기값이 두 개 필요합니다. 보통 $a_1$과 $a_2$를 정하면, $a_3, a_4, \ldots$는 점화식으로부터 모두 유일하게 결정됩니다.
