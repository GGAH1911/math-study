# 공비 결정

## 정확한 진술

등비수열 $\{a_n\}$에서 **공비**(common ratio)는 인접한 두 항의 비로, 기호 $r$로 나타냅니다. 즉,

$$r = \frac{a_{n+1}}{a_n}$$

(단, $a_n \neq 0$)

공비 $r$은 모든 $n$에 대해 일정한 값이며, 이를 결정하기 위해서는 수열에서 연속된 두 항을 알면 충분합니다. 첫째항이 $a$이고 공비가 $r$인 등비수열의 일반항은 $a_n = ar^{n-1}$입니다.

## 직관과 의미

공비는 등비수열의 '증가/감소 속도'를 결정하는 핵심 계수입니다. $|r| > 1$이면 항이 빠르게 커지고, $0 < |r| < 1$이면 항이 0에 가까워집니다. $r < 0$인 경우 항의 부호가 번갈아 바뀝니다. 따라서 공비 하나를 알면 수열의 전체 패턴을 파악할 수 있습니다. 특히 합 공식 $S_n = \frac{a(1-r^n)}{1-r}$ (단, $r \neq 1$)을 적용할 때 반드시 필요합니다.

## 한 줄 예

수열 $2, 6, 18, 54, \ldots$에서 공비는 $r = \frac{6}{2} = 3$입니다. (`sympy.simplify(6/2)` → 3)

## 공비 결정의 실제 방법

주어진 정보에서 공비를 구하는 경우:
- **인접한 두 항이 주어질 때**: $r = \frac{a_{n+1}}{a_n}$을 직접 계산합니다.
- **첫째항과 특정항이 주어질 때**: $a_n = a_1 \cdot r^{n-1}$에서 $r^{n-1} = \frac{a_n}{a_1}$을 풀어 $r$을 구합니다.
- **두 항의 값만 주어질 때**: $a_i \cdot r^{j-i} = a_j$의 관계식을 세워 공비의 거듭제곱을 먼저 구한 뒤, 근을 추출합니다.

공비가 음수이거나 분수인 경우도 같은 방법으로 결정됩니다.
