# 시그마 합기호

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
여러 개의 항을 더하는 과정을 간결하게 나타내는 합기호입니다.

## 본문
시그마($\sum$)는 수열의 여러 항을 한 번에 더하는 것을 나타내는 기호입니다. 표기법 $\sum_{k=1}^n a_k$는 첫 번째 항부터 $n$번째 항까지의 합인 $a_1 + a_2 + a_3 + \cdots + a_n$을 의미합니다. 만약 시작하는 항의 번호가 1이 아니라면 $\sum_{k=m}^n a_k = a_m + a_{m+1} + \cdots + a_n$과 같이 아래 첨자에 시작값 $m$을 적어 표현합니다. 여기서 $k$는 합을 구하는 변수이며, 아래 첨수는 시작하는 $k$의 값, 위 첨수는 끝나는 $k$의 값, $a_k$는 $k$번째 항을 나타냅니다.

### 직관과 기하적 의미
시그마는 수열의 항들을 일일이 나열하여 더할 때 발생하는 번거로움을 줄이기 위한 수학적 약속입니다. 예를 들어 $1$부터 $100$까지의 합을 $1 + 2 + 3 + \cdots + 100$이라고 길게 쓰는 대신 $\sum_{k=1}^{100} k$라고 쓰면 매우 간결해집니다. $k$가 아래 첨수에서 시작하여 위 첨수까지 1씩 증가하며 $a_k$의 값을 차례대로 계산하여 모두 더하는 과정으로 이해하면 쉽습니다.

구체적인 예로 $\sum_{k=1}^5 k$는 $1+2+3+4+5=15$가 되고, $\sum_{k=1}^4 (2k-1)$은 홀수 네 개의 합인 $1+3+5+7=16$이 됩니다. 시작값이 다른 경우인 $\sum_{k=3}^6 k^2$은 $3^2+4^2+5^2+6^2=86$과 같이 계산합니다.

### 기본 성질
- $\sum_{k=1}^n c = nc$ (단, $c$는 상수)
- $\sum_{k=1}^n c a_k = c \sum_{k=1}^n a_k$ (단, $c$는 상수)
- $\sum_{k=1}^n (a_k \pm b_k) = \sum_{k=1}^n a_k \pm \sum_{k=1}^n b_k$

## 학습 체크
- $\sum$ 기호의 아래 첨자와 위 첨자가 의미하는 시작과 끝의 범위를 정확히 파악할 수 있는가?
- 주어진 수열의 일반항을 보고 시그마 기호를 사용하여 합의 형태로 변환할 수 있는가?
- 시작값이 1이 아닌 경우의 합 계산 과정을 실수 없이 수행할 수 있는가?

## 관련 개념
- **수열**: 시그마는 수열의 각 항을 더하는 도구이므로, 수열의 일반항을 정확히 구하는 능력이 필수적입니다.
