# 시그마 합기호

> **정의** · 수학1 · 단원: [수열](/concepts/수열)
## 요약
$\sum_{k=1}^n a_k$

## 본문

**시그마(시그마)**는 여러 항을 한 번에 더하는 것을 나타내는 합기호입니다. 표기법 $\sum_{k=1}^n a_k$는 다음을 의미합니다:

$$\sum_{k=1}^n a_k = a_1 + a_2 + a_3 + \cdots + a_n$$

일반적으로 시작값이 1이 아닐 때는 $\sum_{k=m}^n a_k = a_m + a_{m+1} + \cdots + a_n$으로 나타냅니다.

여기서:
- $k$: 합을 구하는 첨수(index) 또는 더하기 변수
- $m$ (아래 첨수): 시작하는 $k$의 값
- $n$ (위 첨수): 끝나는 $k$의 값  
- $a_k$: $k$번째 항

### 직관과 의미

시그마는 수열의 여러 항을 더할 때, 긴 식을 간단하게 쓰기 위한 약속입니다. 예를 들어 $1 + 2 + 3 + \cdots + 100$을 쓰는 대신 $\sum_{k=1}^{100} k$로 표현하면 훨씬 간결합니다. 

$k$가 아래 첨수에서 시작하여 위 첨수까지 1씩 증가하면서, 매번 $a_k$를 계산해 모두 더한다고 생각하면 됩니다.

### 구체적 예

$\sum_{k=1}^5 k = 1 + 2 + 3 + 4 + 5 = 15$

$\sum_{k=1}^4 (2k-1) = 1 + 3 + 5 + 7 = 16$ (처음 4개의 홀수의 합)

시작값이 다른 예: $\sum_{k=3}^6 k^2 = 3^2 + 4^2 + 5^2 + 6^2 = 9 + 16 + 25 + 36 = 86$

(`sympy`: `sum(k for k in range(1, 6))` = 15, `sum(2*k-1 for k in range(1, 5))` = 16)
