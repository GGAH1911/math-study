# 항의 값 계산

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열의 일반항이나 점화식에 특정 자연수를 대입하여 원하는 위치의 항의 값을 구하는 과정입니다.

## 본문
수열 $\{a_n\}$의 일반항 또는 점화식이 주어졌을 때, 특정 자연수 $n$에 해당하는 항 $a_n$의 값을 구하는 것을 항의 값 계산이라 합니다. 예를 들어 일반항이 $a_n = 3n^2 - 2n + 1$로 주어지면, $n = 5$를 대입하여 $a_5 = 3(5)^2 - 2(5) + 1 = 66$과 같이 계산합니다. 점화식으로 정의된 경우(예: $a_1 = 1$, $a_{n+1} = 2a_n + 1$)에는 초기항부터 차례대로 항을 구해 나가거나, 일반항 공식을 먼저 유도한 후 대입하는 방식을 사용합니다.

### 직관과 기하적 의미
수열은 규칙을 따르는 수들의 순서 있는 나열입니다. 그 규칙을 명확한 식으로 나타낸 것이 일반항이며, 일반항을 알면 수열 전체를 일일이 나열할 필요 없이 원하는 위치의 항을 즉시 계산할 수 있습니다. 수열을 $n$에 대한 함수로 본다면, 항의 값 계산은 함수값 계산과 본질적으로 같습니다. 이 능력은 부분합, 급수, 점화식 풀이, 나아가 극한과 수렴성 개념으로 나아가기 위한 필수적인 기초가 됩니다.

### 기본 성질
**등차수열** (첫째항 $a$, 공차 $d$):
$$a_n = a + (n-1)d$$

**등비수열** (첫째항 $a$, 공비 $r$):
$$a_n = a \cdot r^{n-1}$$

예를 들어 등차수열에서 $a_1 = 2$, 공차 $d = 3$일 때, 일반항은 $a_n = 3n - 1$이므로 $a_{10} = 29$가 됩니다.

## 학습 체크
- 주어진 식이 일반항인지 점화식인지 구분하여 계산 방식을 결정할 수 있는가?
- $n$에 특정 자연수를 대입할 때 연산 실수 없이 정확한 값을 도출할 수 있는가?
- 점화식이 주어졌을 때 초기항부터 차례대로 대입하여 다음 항을 구할 수 있는가?

## 관련 개념
- **수열**: 규칙을 가진 수의 나열이며, 항의 값 계산을 통해 수열의 구체적인 구성 요소를 파악할 수 있습니다.
- **일반항**: 수열의 규칙을 $n$에 관한 식으로 나타낸 것으로, 항의 값을 직접 계산할 수 있게 해주는 도구입니다.
- **점화식**: 항 사이의 관계를 나타낸 식으로, 이전 항의 값을 이용하여 다음 항의 값을 계산하는 방식을 제공합니다.
