# 공비

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
등비수열에서 인접한 두 항 사이의 일정한 비율을 의미하며, 수열의 증감과 부호 변화를 결정하는 핵심 요소입니다.

## 본문
등비수열에서 **공비**는 연속한 두 항의 비를 의미합니다. 수열 $\{a_n\}$의 공비를 $r$이라 하면, 모든 자연수 $n$에 대하여 다음을 만족합니다:

$$r = \frac{a_{n+1}}{a_n}$$

또는 동치적으로 다음과 같이 표현할 수 있습니다:

$$a_{n+1} = a_n \cdot r$$

첫째항을 $a_1$이라 할 때, 이 수열의 일반항은 $a_n = a_1 \cdot r^{n-1}$이 됩니다.

### 직관과 기하적 의미
공비는 등비수열이 변화하는 속도를 나타내는 척도입니다. 공비가 $1$보다 크면 수열은 지수적으로 증가하고, $0$과 $1$ 사이이면 감소합니다. 만약 공비가 음수라면 항의 부호가 양수와 음수를 번갈아 가며 나타나게 됩니다. 기하학적으로 공비는 일정한 배율을 의미하며, 매 단계마다 이전 항에 공비를 곱하여 다음 항을 얻는 등비수열의 본질적인 특징을 나타냅니다. 이는 복리 계산이나 바이러스 전파와 같은 기하급수적 변화를 모델링할 때 필수적인 개념입니다.

### 기본 성질
예를 들어 수열 $2, 6, 18, 54, \ldots$에서 공비를 구하면 다음과 같습니다.

$$r = \frac{6}{2} = 3$$

이때 공비는 $3$이며, 일반항은 $a_n = 2 \cdot 3^{n-1}$이 됩니다.

- 공비의 크기($r > 1, 0 < r < 1, r < 0$)에 따라 수열의 수렴과 발산 양상을 예측할 수 있는가?

## 관련 개념
- **수열**: 공비가 일정한 비율로 항이 커지거나 작아지는 특수한 형태의 수열을 등비수열이라고 합니다.
