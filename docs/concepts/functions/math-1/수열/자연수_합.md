# 자연수 합

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
처음 $n$개의 자연수를 모두 더한 합은 $\frac{n(n+1)}{2}$이라는 공식으로 계산할 수 있습니다.

## 본문
처음 $n$개의 자연수를 모두 더한 합을 다음과 같이 정의합니다.
$$S_n = 1 + 2 + 3 + \cdots + n = \sum_{k=1}^{n} k$$
이 합의 값은 공식으로 다음과 같이 계산됩니다.
$$S_n = \frac{n(n+1)}{2}$$

### 직관과 기하적 의미
이 공식이 왜 성립하는지 가우스의 방법을 통해 확인할 수 있습니다. 합을 두 가지 방식으로 나열하여 항별로 더하면 다음과 같습니다.
$$\begin{align}
S_n &= 1 + 2 + 3 + \cdots + n \\
S_n &= n + (n-1) + (n-2) + \cdots + 1
\end{align}$$
두 식을 더하면 각 열의 합이 항상 $n+1$이 되고, 총 $n$개의 열이 존재하므로 $2S_n = n(n+1)$이 되어 공식이 유도됩니다. 기하적으로는 밑변의 길이가 $k$이고 높이가 1인 직사각형들을 계단 모양으로 쌓은 형태를 의미하며, 이 전체 영역의 넓이는 밑변이 $n$이고 높이가 $n+1$인 직사각형 넓이의 절반과 같습니다.

### 기본 성질
이 공식은 수열, 급수, 수학적 귀납법 증명 등 고등학교 수학 전반에서 매우 중요하게 다뤄지는 핵심 결과입니다. 예를 들어 첫 100개 자연수의 합은 $S_{100} = \frac{100 \times 101}{2} = 5050$이며, 첫 5개 자연수의 합은 $S_5 = \frac{5 \times 6}{2} = 15$로 계산됩니다.

## 학습 체크
- 가우스의 방법을 이용하여 합의 공식이 유도되는 과정을 설명할 수 있는가?
- 계단 모양의 기하학적 구조가 왜 직사각형 넓이의 절반이 되는지 이해하였는가?
- 주어진 $n$의 값에 대해 공식과 직접 더한 값이 일치하는지 검산할 수 있는가?

## 관련 개념
- **함수와 그래프**: $n$을 변수로 볼 때, 이 공식은 $n$에 대한 이차함수 그래프의 형태를 나타냅니다.
- **수열**: 자연수의 합은 등차수열의 합을 구하는 가장 기초적인 사례입니다.
- **급수**: 무한히 많은 항을 더하는 급수의 개념을 학습할 때 부분합의 기초가 됩니다.
