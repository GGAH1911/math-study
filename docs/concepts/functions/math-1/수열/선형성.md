### 정확한 진술

어떤 함수나 연산이 **선형성(linearity)**을 만족한다는 것은 다음 두 가지 성질을 동시에 가짐을 의미합니다.

- **덧셈 성질**: $f(x + y) = f(x) + f(y)$
- **스칼라 곱셈 성질**: $f(cx) = cf(x)$ (모든 상수 $c$에 대해)

이 두 조건을 합치면 임의의 상수 $a, b$와 입력 $x, y$에 대해
$$f(ax + by) = af(x) + bf(y)$$
가 성립합니다. 이를 선형성의 **동차성(homogeneity)**과 **가법성(additivity)**이라 부릅니다.

### 직관과 기하적 의미

선형성은 **완전한 비례 관계**를 의미합니다. 입력을 2배로 늘리면 출력도 정확히 2배가 되며, 여러 입력의 합에 대한 결과는 각각의 결과를 합한 것과 같습니다. 이 성질 덕분에 복잡한 문제를 간단한 부분으로 분해하여 해결할 수 있습니다.

고등학교 수학에서 미분, 적분, 행렬 곱셈 같은 많은 연산이 선형성을 가집니다. 예를 들어 미분 연산은 선형이므로 $(af + bg)' = af' + bg'$가 성립하고, 이 덕분에 복잡한 함수도 항별로 미분한 후 합칠 수 있습니다.

### 구체적 예시

**선형 함수**: $f(x) = 3x$는 선형입니다.
$$f(2x + 3y) = 3(2x + 3y) = 6x + 9y = 2 \cdot 3x + 3 \cdot 3y = 2f(x) + 3f(y)$$ ✓

**미분의 선형성**: $(5x^3 - 2\cos x)' = 15x^2 + 2\sin x$ (각 항을 따로 미분하여 합침)

**비선형 함수**: $g(x) = x^2$는 선형이 아닙니다.
$$g(2x) = 4x^2 \neq 2x^2 = 2g(x)$$ ✗
