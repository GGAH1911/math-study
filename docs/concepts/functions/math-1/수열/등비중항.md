# 등비중항

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
세 수 $a, b, c$가 등비수열을 이룰 때, 중간 항 $b$를 양 끝 항 $a$와 $c$의 등비중항이라고 합니다.

## 본문
세 수 $a, b, c$ ($a, c \neq 0$)에 대하여 $b^2 = ac$를 만족할 때, $b$를 **등비중항**이라고 정의합니다. 이는 $a, b, c$가 이 순서대로 등비수열을 이룬다는 조건과 동치입니다.

### 직관과 기하적 의미
산술중항이 덧셈을 기준으로 한 평균이라면, 등비중항은 곱셈을 기준으로 정의되는 평균입니다. 로그 스케일 관점에서 보면, 양수 범위에서 $\log b$는 $\log a$와 $\log c$의 산술평균인 $\tfrac{\log a + \log c}{2}$가 됩니다. 즉, 등비중항은 로그를 취했을 때 산술평균처럼 작동하는 성질을 가집니다.

### 기본 성질
등비중항은 $a$와 $c$의 부호에 따라 결정됩니다. $a$와 $c$의 부호가 같다면 $b$는 양수와 음수 두 개가 존재할 수 있으며, $a$와 $c$의 부호가 다르면 실수 범위에서 등비중항이 존재하지 않습니다. 예를 들어 $2$와 $8$의 등비중항은 $b^2 = 16$을 만족하는 $4$와 $-4$입니다.

## 학습 체크
- $a$와 $c$의 부호가 다를 때 등비중항이 존재하지 않는 이유를 곱셈의 성질과 연결하여 설명할 수 있는가?
- $b^2 = ac$라는 식을 이용하여 세 항이 등비수열을 이루는지 어떻게 판별하는가?

## 관련 개념
- **수열**: 세 항이 등비수열을 이룰 때, 그 중간 항이 바로 등비중항이 됩니다.
