# 등비중항

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 정확한 진술

세 수 $a, b, c$ ($a, c \neq 0$)에 대해 다음 조건을 만족할 때, $b$를 **등비중항**(geometric mean)이라고 합니다:
$$b^2 = ac$$

동치적으로, $a, b, c$가 이 순서대로 등비수열을 이루면 $b$가 $a$와 $c$의 등비중항입니다.

## 직관 및 기하적 의미

산술중항(예: 1, 3, 5에서 3)이 덧셈을 중심으로 "평균"을 정의한다면, 등비중항은 곱셈을 중심으로 정의됩니다. 세 수가 등비수열을 이루기 위한 필요충분조건이 바로 중간 항이 양 끝 항의 등비중항이 되는 것입니다.

**로그 스케일 해석**: 양수 범위에서, $\log b$는 $\log a$와 $\log c$의 산술평균입니다:
$$\log b = \frac{\log a + \log c}{2}$$

이는 지수 함수와 로그 함수의 관계에서 비롯됩니다. 즉, 등비중항은 로그 스케일에서 산술평균처럼 작동합니다.

## 예

**예 1**: $2$와 $8$의 등비중항을 구하세요.

$b^2 = 2 \times 8 = 16$이므로 $b = 4$ 또는 $b = -4$입니다.
- $2, 4, 8$은 공비 $2$인 등비수열 ✓
- $2, -4, 8$은 공비 $-2$인 등비수열 ✓

일반적으로 양수 값인 $4$를 주 답으로 삼습니다.

(`sympy.solve(b**2 - 16, b)` → `[-4, 4]`)

**주의**: 등비중항은 0이 아닌 한 개 또는 두 개입니다. $a$와 $c$의 부호가 같으면 양수와 음수 두 개, $a \cdot c < 0$이면 실수 등비중항이 없습니다.
