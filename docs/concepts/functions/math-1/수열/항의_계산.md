# 항의 계산

"항의_계산"의 정확한 의미를 확인하고 싶습니다. 몇 가지 가능성을 제시할게요:

1. **등차수열/등비수열의 n번째 항 구하기** — 일반항 공식을 이용해 특정 항의 값을 계산하는 방법
2. **수열의 합 계산** — $\sum$ 기호를 이용한 합의 계산
3. **특정 항의 계산 기법** — 수열에서 주어진 조건으로부터 특정 항을 역으로 구하는 방법
4. **점화식을 통한 항의 계산** — 이전 항들로부터 다음 항을 재귀적으로 구하는 방법

이 중 **어느 개념**을 정의하길 원하시나요? 

또한 페이지 요약(1줄)도 비어있는데, 이를 채우면 더 명확한 방향 설정이 될 것 같습니다. 예를 들어:
- "등차수열과 등비수열에서 n번째 항을 일반항 공식으로 구하는 방법"
- "주어진 조건으로부터 수열의 특정 항을 찾는 계산 기법"
