# 수열의 일반항

> **예제** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
주어진 조건에서 망원급수 기법을 이용하여 수열의 일반항 $a_n$을 구합니다.

## 본문
첫째항 $a_1 = 2$이고 점화식 $a_{n+1} = a_n + 3n$을 만족하는 수열 $\{a_n\}$의 일반항 $a_n$을 구하세요.

### 단계별 풀이
**1단계: 점화식 변형**
점화식을 $a_{n+1} - a_n = 3n$으로 다시 정리합니다. 연속된 항들의 차가 규칙을 갖는 경우 망원급수 기법을 사용하여 일반항을 구할 수 있습니다.

**2단계: 망원급수 전개**
$n \geq 2$일 때, 첫째항부터 제$n$항까지의 차를 모두 더하면 다음과 같습니다.
$$a_n - a_1 = (a_2 - a_1) + (a_3 - a_2) + \cdots + (a_n - a_{n-1})$$
여기에 점화식을 대입하면 다음과 같습니다.
$$a_n - a_1 = 3 \cdot 1 + 3 \cdot 2 + \cdots + 3(n-1) = 3(1 + 2 + \cdots + (n-1))$$

**3단계: 등차수열의 합 적용 및 정리**
자연수의 합 공식을 적용하면 $1 + 2 + \cdots + (n-1) = \frac{(n-1)n}{2}$입니다.
따라서 $a_n - 2 = 3 \cdot \frac{n(n-1)}{2}$이며, 이를 정리하면 다음과 같습니다.
$$a_n = 2 + \frac{3n^2 - 3n}{2} = \frac{3n^2 - 3n + 4}{2}$$

### 답과 변형
**답**
$$a_n = \frac{3n^2 - 3n + 4}{2}$$

**검증 및 주의사항**
- $n=1$일 때 $a_1 = \frac{3-3+4}{2} = 2$로 성립하며, $n=2$일 때 $a_2 = 2+3(1)=5$이고 공식으로도 $\frac{12-6+4}{2}=5$로 일치합니다.
- 점화식이 $a_{n+1} - a_n = f(n)$ 형태일 때 망원급수를 활용하며, 합의 범위가 $n-1$까지임을 주의해야 합니다.

## 학습 체크
- $a_{n+1} - a_n = f(n)$ 형태의 점화식을 망원급수로 변환할 수 있는가?
- 등차수열의 합 공식을 사용하여 일반항을 최종 정리할 수 있는가?
- 구한 일반항이 첫째항($n=1$)과 일치하는지 검증할 수 있는가?

## 관련 개념
- **수열**: 항들 사이의 관계를 나타내는 점화식을 통해 수열의 규칙성을 파악하고 일반항을 도출하는 기초가 됩니다.
