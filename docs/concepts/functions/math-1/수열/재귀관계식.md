# 재귀관계식

## 정확한 진술

수열 $\{a_n\}$에서 일반항 $a_n$을 직접 구하지 않고, 수열의 여러 항들 사이의 관계를 나타내는 식을 **재귀관계식**(또는 **점화식**)이라 합니다. 일반적으로 $a_{n+1} = f(a_n, a_{n-1}, \ldots)$ 형태이며, 초기 조건(예: $a_1$의 값)과 함께 주어집니다.

## 직관과 기하적 의미

재귀관계식은 "다음 항을 이전 항들로 표현하는 규칙"입니다. 즉, 수열의 처음 몇 항만 알면 나머지 모든 항을 하나씩 계산할 수 있습니다. 예를 들어 **등차수열** $a_{n+1} = a_n + d$와 **등비수열** $a_{n+1} = r \cdot a_n$도 가장 기본적인 재귀관계식입니다. 

재귀관계식을 푼다는 것은 이 관계식과 초기 조건을 만족하는 **일반항 공식**을 찾는 과정입니다. 예를 들어 $a_1 = 1, a_{n+1} = 2a_n$이면, 계산을 반복하면 $a_n = 2^{n-1}$임을 알 수 있습니다.

## 기본 예

$$a_1 = 3, \quad a_{n+1} = a_n + 2$$

이 재귀관계식은 초항이 3이고 공차가 2인 등차수열을 정의합니다. 몇 항을 계산하면:
- $a_1 = 3$
- $a_2 = 3 + 2 = 5$
- $a_3 = 5 + 2 = 7$
- $a_4 = 7 + 2 = 9$

패턴에서 일반항은 $a_n = 2n + 1$입니다. (검산: `sympy.symbols('n'); a_n = 2*n + 1; [a_n.subs(n, i) for i in range(1, 5)]` → $[3, 5, 7, 9]$)

## 주의

재귀관계식만으로는 수열이 결정되지 않습니다. **초기 조건(초항들)**이 반드시 필요합니다. 같은 관계식 $a_{n+1} = 2a_n$이라도 $a_1 = 1$이면 $a_n = 2^{n-1}$, $a_1 = 5$이면 $a_n = 5 \cdot 2^{n-1}$로 달라집니다.
