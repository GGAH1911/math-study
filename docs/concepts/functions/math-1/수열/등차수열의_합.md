# 등차수열의 합

> **정리** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
등차수열의 합은 첫째항과 마지막 항의 평균에 항의 개수를 곱하여 구할 수 있습니다.

## 본문
첫째항이 $a_1$, 공차가 $d$인 등차수열 $\{a_n\}$의 첫 $n$항까지의 합 $S_n$은 다음과 같습니다.
$$S_n = \frac{n(a_1 + a_n)}{2}$$
또한 일반항 $a_n = a_1 + (n-1)d$를 대입하면 다음과 같이 공차를 포함한 형태로도 나타낼 수 있습니다.
$$S_n = \frac{n}{2}\{2a_1 + (n-1)d\}$$

### 증명 스케치
등차수열의 합을 구하기 위해 첫째항부터 $n$번째 항까지 나열한 식 $S_n = a_1 + a_2 + \cdots + a_n$과, 이를 역순으로 나열한 식 $S_n = a_n + a_{n-1} + \cdots + a_1$을 준비합니다. 두 식을 세로로 더하면 각 항의 합이 $a_1 + a_n$으로 일정함을 알 수 있습니다. 등차수열의 성질에 의해 $a_i + a_{n+1-i} = a_1 + a_n$이 성립하므로, 우변은 $(a_1 + a_n)$이 총 $n$번 반복됩니다. 따라서 $2S_n = n(a_1 + a_n)$이 되며, 양변을 2로 나누면 공식이 유도됩니다.

### 의의와 응용
이 공식은 수열의 항들이 일정한 간격으로 증가하거나 감소할 때, 전체 합이 평균값에 항의 개수를 곱한 것과 같다는 직관적인 의미를 담고 있습니다. 수능 및 모의고사에서는 주어진 합의 값을 통해 첫째항과 공차를 추론하거나, 합의 식이 이차함수 형태임을 이용하여 합의 최댓값 또는 최솟값을 찾는 문제로 자주 응용됩니다.

예를 들어, 첫째항이 2이고 공차가 3인 등차수열의 첫 10항까지의 합은 $a_{10} = 2 + 9 \times 3 = 29$이므로, $S_{10} = \frac{10(2+29)}{2} = 155$로 계산할 수 있습니다.

## 학습 체크
- 첫째항과 마지막 항을 알 때와 첫째항과 공차를 알 때의 두 가지 공식 형태를 구분하여 사용할 수 있는가?
- 등차수열의 합 $S_n$이 $n$에 관한 이차식으로 나타날 때, 이를 통해 일반항을 유도할 수 있는가?

## 관련 개념
- **수열**: 등차수열의 합은 수열의 일종인 등차수열의 부분합을 구하는 과정입니다.
