# 부분합

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열의 첫째항부터 제$n$항까지의 항들을 차례대로 더한 누적 합을 의미합니다.

## 본문
수열 $\{a_n\}$의 부분합 $S_n$은 처음 $n$개 항의 합을 나타내며, 다음과 같이 정의됩니다.
$$S_n = a_1 + a_2 + a_3 + \cdots + a_n = \sum_{k=1}^{n} a_k$$
부분합은 수열의 각 항을 누적해서 더한 값으로, 수열의 처음부터 $n$번째 항까지의 누적된 총합을 의미합니다.

### 직관과 기하적 의미
부분합은 **누적의 개념**입니다. 예를 들어 매달 저축하는 금액이 수열 $\{a_n\}$이라면, 부분합 $S_n$은 $n$개월 동안 모은 총액과 같습니다. $S_1 = a_1$, $S_2 = a_1 + a_2$, $S_3 = a_1 + a_2 + a_3$와 같이 항이 늘어남에 따라 합계가 누적되는 구조를 가집니다.

### 기본 성질
부분합과 일반항 사이에는 다음과 같은 중요한 관계가 성립합니다. 이는 $n$번째 항이 $n$개월까지의 누적합에서 $n-1$개월까지의 누적합을 뺀 차이와 같다는 원리입니다.
- $n = 1$일 때: $a_1 = S_1$
- $n \geq 2$일 때: $a_n = S_n - S_{n-1}$

예를 들어 수열 $a_n = 2n$의 부분합 $S_n$을 구하면 다음과 같습니다.
$$S_n = 2 \cdot 1 + 2 \cdot 2 + \cdots + 2 \cdot n = 2 \cdot \frac{n(n+1)}{2} = n(n+1)$$
실제로 $S_3 = 2 + 4 + 6 = 12$이며, 이는 $3 \times 4$와 일치합니다.

## 학습 체크
- $n=1$일 때와 $n \geq 2$일 때를 나누어 일반항을 구해야 하는 이유는 무엇인가요?
- 부분합 $S_n$이 주어졌을 때, 이를 이용하여 일반항 $a_n$을 찾는 과정은 어떻게 되나요?

## 관련 개념
- **수열**: 부분합은 수열의 각 항을 순차적으로 더해나가는 과정을 통해 정의되는 개념입니다.
