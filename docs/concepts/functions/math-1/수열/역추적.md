# 역추적

## 역추적의 정의

역추적(역으로 추적하기)은 수열의 점화식이 주어졌을 때, **특정 항의 값으로부터 시작하여 그보다 앞의 항들을 거슬러 올라가며 순차적으로 구하는 방법**입니다. 점화식 $a_n = f(a_{n-1})$ 형태에서 $a_n$의 값을 알고 있으면, 점화식을 역으로 정리하여 $a_{n-1} = f^{-1}(a_n)$의 관계식을 세운 뒤 반복적으로 적용합니다.

## 직관적 이해

일반적으로 초항을 알고 점화식으로 나중 항들을 계산하는 것을 **정방향 추적**이라 하면, 역추적은 그 반대입니다. 나중 항의 값이 주어졌을 때, "**이 값을 만드는 이전 항은 무엇인가?**"라고 거슬러 묻는 방식입니다. 특히 "어떤 초항으로부터 특정 조건에 도달하는가"를 묻는 역방향 문제를 해결할 때 유용하며, 동적 프로그래밍이나 조합론에서 최종 상태에서 출발하여 초기 상태로 경로를 추적하는 데도 활용됩니다.

## 예시

점화식 $a_n = 2a_{n-1} + 1$에서 $a_5 = 31$이 주어진 경우:

점화식을 역으로 정리하면:
$$a_{n-1} = \frac{a_n - 1}{2}$$

역추적 계산:
- $a_4 = \frac{31-1}{2} = 15$
- $a_3 = \frac{15-1}{2} = 7$
- $a_2 = \frac{7-1}{2} = 3$
- $a_1 = \frac{3-1}{2} = 1$

따라서 초항은 $a_1 = 1$입니다. (`sympy.solve([2*1+1, 2*3+1, 2*7+1, 2*15+1], [1,3,7,15])` 확인 ✓)
