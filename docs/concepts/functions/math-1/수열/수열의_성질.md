### 정확한 진술

수열의 성질은 수열이 만족하는 기본적인 특징들을 나타냅니다. 가장 중요한 세 가지 성질은 다음과 같습니다:

1. **유계성(boundedness)**: 수열 $\{a_n\}$이 유계라는 것은 모든 항이 어떤 범위 안에 들어가는 것을 의미합니다. 즉, 실수 $M, m$이 존재하여 모든 자연수 $n$에 대해 $m \le a_n \le M$을 만족합니다.

2. **단조성(monotonicity)**: 수열이 계속 증가하거나 계속 감소하는 성질입니다. $a_n \le a_{n+1}$ (단조증가) 또는 $a_n \ge a_{n+1}$ (단조감소)을 만족합니다.

3. **수렴성(convergence)**: 수열의 항들이 어떤 값 $L$으로 점점 가까워지는 성질입니다. 임의의 $\epsilon > 0$에 대해, 충분히 큰 $N$이 존재하여 $n > N$일 때 $|a_n - L| < \epsilon$을 만족합니다.

### 직관과 기하적 의미

**유계성**은 수열이 "폭발"하지 않고 어떤 구간 안에 머물러 있다는 뜻입니다. 예를 들어 $a_n = 1 - \frac{1}{n}$은 항상 1 이하이고 0 이상이므로 유계입니다.

**단조성**은 수열의 "방향성"을 나타냅니다. 계단처럼 올라가거나 내려가거나, 또는 진동할 수 있습니다.

**수렴성**은 수열이 어떤 목표점(극한값)을 향해 가까워지는 모습입니다. 예를 들어 $\lim_{n \to \infty} \frac{1}{n} = 0$입니다.

### 한 줄 예

- 유계: $a_n = \sin n$은 유계 ($-1 \le a_n \le 1$)
- 단조증가: $a_n = n$은 단조증가
- 수렴: $a_n = \frac{1}{n}$은 0으로 수렴

### 성질들 사이의 관계

**중요 정리**: 수렴하는 수열은 반드시 유계입니다. 그러나 역은 성립하지 않습니다. $a_n = (-1)^n$은 유계이지만 수렴하지 않습니다.

**단조수렴정리**: 수열이 단조이면서 동시에 유계이면, 반드시 수렴합니다. 이는 극한값의 존재를 증명하는 강력한 도구입니다.

```python
import sympy as sp
n = sp.Symbol('n', positive=True, integer=True)
# 예: a_n = 1 - 1/n 은 유계이고 단조증가하며 1로 수렴
a_n = 1 - 1/n
print(f"극한: {sp.limit(a_n, n, sp.oo)}")  # 1
```

### 주의할 점

수열의 성질은 자연수만을 정의역으로 하기 때문에 함수의 연속성 같은 개념이 적용되지 않습니다. 대신 수렴성이 핵심입니다. 또한 유계성과 단조성은 서로 독립적이므로, 수렴을 보장하려면 두 조건을 **동시에** 만족해야 합니다.
