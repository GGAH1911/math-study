# 일의 자리 주기성

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
정수 $a$의 거듭제곱 $a^n$에서 일의 자리 숫자가 일정한 간격으로 반복되는 현상을 의미합니다.

## 본문
정수 $a$의 거듭제곱 $a^n$ ($n = 1, 2, 3, \ldots$)을 생각할 때, 일의 자리 숫자들이 어떤 주기로 반복되는 현상을 일의 자리 주기성이라고 합니다. 즉, 양의 정수 $k$가 존재하여 모든 자연수 $n$에서 $a^n \equiv a^{n+k} \pmod{10}$을 만족하며, 이때 $k$를 주기라고 부릅니다.

### 직관과 기하적 의미
$a^n$의 일의 자리는 오직 $a$의 일의 자리 숫자에만 의존합니다. 예를 들어 $2^5$와 $12^5$는 일의 자리가 같습니다. 일의 자리는 $\{0, 1, 2, \ldots, 9\}$라는 유한한 집합 내의 값만 가질 수 있으므로, 거듭제곱이 커짐에 따라 언젠가는 반드시 이전에 나타났던 일의 자리 숫자가 다시 나타나게 됩니다. 이는 함수 $f(n) = a^n \bmod 10$이 주기함수임을 의미하며, 마치 시계판이 12시간마다 반복되는 것과 같은 원리입니다.

### 기본 성질
거듭제곱의 일의 자리는 밑수 $a$의 일의 자리 숫자에 의해 결정됩니다. 구체적인 예로 $2^n$의 일의 자리는 $2, 4, 8, 6$이 반복되는 주기 4를 가지며, $3^n$과 $7^n$ 역시 각각 $3, 9, 7, 1$과 $7, 9, 3, 1$의 패턴으로 주기 4를 가집니다. 이러한 주기성을 활용하면 큰 지수를 가진 거듭제곱의 일의 자리도 쉽게 구할 수 있습니다. 예를 들어 $2^{2024}$의 일의 자리는 지수 $2024$가 주기 $4$로 나누어떨어지므로, $2^4$의 일의 자리인 $6$과 같습니다.

## 학습 체크

- 지수가 매우 클 때, 주기성을 이용하여 일의 자리를 구하는 방법은 무엇인가요?

## 관련 개념
- **함수와 그래프**: 일의 자리 숫자의 변화를 $n$에 따른 함숫값으로 나타내면 일정한 패턴이 반복되는 주기함수의 형태를 띱니다.
