# 일의 자리 주기성

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 정확한 진술

정수 $a$의 거듭제곱 $a^n$ ($n = 1, 2, 3, \ldots$)을 생각할 때, 일의 자리 숫자들이 어떤 주기로 반복되는 현상을 **일의 자리 주기성**이라고 합니다. 즉, 양의 정수 $k$가 존재하여 모든 자연수 $n$에서 
$$a^n \equiv a^{n+k} \pmod{10}$$
을 만족합니다. 여기서 $k$를 주기라고 부릅니다.

## 직관과 기하적 의미

$a^n$의 일의 자리는 오직 $a$의 일의 자리 숫자에만 의존합니다. 예를 들어 $2^5$와 $12^5$는 일의 자리가 같습니다. 따라서 일의 자리는 유한한 집합 $\{0, 1, 2, \ldots, 9\}$에서만 값을 가지므로, 거듭제곱이 증가할수록 언젠가는 반드시 같은 일의 자리가 다시 나타나게 됩니다. 이는 함수 $f(n) = a^n \bmod 10$이 **주기함수**라는 뜻입니다. 마치 시계판이 12시간마다 반복되듯이, 일의 자리도 일정한 주기마다 같은 패턴을 되풀이합니다.

## 구체적인 예

- $2^1, 2^2, 2^3, 2^4, \ldots$의 일의 자리: $2, 4, 8, 6, 2, 4, 8, 6, \ldots$ (주기 4)
- $3^1, 3^2, 3^3, 3^4, \ldots$의 일의 자리: $3, 9, 7, 1, 3, 9, 7, 1, \ldots$ (주기 4)  
- $7^1, 7^2, 7^3, 7^4, \ldots$의 일의 자리: $7, 9, 3, 1, 7, 9, 3, 1, \ldots$ (주기 4)

이 주기성을 이용하면 $2^{2024}$의 일의 자리를 빠르게 구할 수 있습니다. $2024 = 506 \times 4 + 0$이므로, $2^{2024}$의 일의 자리는 $2^4$의 일의 자리인 **6**입니다. 검산: `2024 % 4 == 0` → $2^{2024} \equiv 2^{4} \equiv 6 \pmod{10}$
