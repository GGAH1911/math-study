# 초기조건 분석

## 정확한 진술

수열 $\{a_n\}$의 **초기조건**이란 수열의 처음 몇 항의 값들, 특히 $a_1$ (또는 경우에 따라 $a_0, a_2$ 등)을 말합니다. 점화식(recurrence relation)이 주어져 있을 때, 초기조건은 이 점화식으로부터 모든 항을 유일하게 결정하기 위해 반드시 필요한 정보입니다.

예를 들어, 1차 점화식 $a_{n+1} = a_n + d$는 초기값 $a_1$이 없으면 수열 전체가 결정되지 않습니다. 같은 점화식을 만족하더라도 $a_1 = 1$이면 등차수열 $1, 1+d, 1+2d, \ldots$이고, $a_1 = 5$면 $5, 5+d, 5+2d, \ldots$로 완전히 다른 수열입니다.

## 직관/기하적 의미

**초기조건**은 "출발점"입니다. 점화식 자체는 "한 항에서 다음 항으로 가는 규칙"일 뿐, 어디서부터 시작하는지는 나타내지 않습니다. 마치 탄도탄이 발사 위치와 각도에 따라 궤적이 결정되듯이, 수열도 초기값이 정해져야 모양이 정해집니다.

**초기조건 분석**은 이러한 초기값들이 수열의 일반항, 극한, 성질에 어떻게 영향을 미치는지를 살펴보는 과정입니다. 특히 복잡한 점화식에서 초기조건이 조금 달라져도 결과가 크게 달라질 수 있으므로, 이를 분석하는 것은 매우 중요합니다.

## 한 줄 예

점화식 $a_{n+1} = 2a_n$에서 초기조건 $a_1 = 3$이면 수열은 $3, 6, 12, 24, \ldots$ (일반항 $a_n = 3 \cdot 2^{n-1}$)이 되고, 초기조건을 $a_1 = 1$로 바꾸면 $1, 2, 4, 8, \ldots$ (일반항 $a_n = 2^{n-1}$)가 되어 전혀 다른 수열입니다. (`sympy.solve(a_n - 2*a_n1, a_n)` 형태로 점화식을 풀 때 상수항이 초기조건에 의존함을 확인 가능)
