# 합의공식

## 정확한 진술

**합의공식**은 수열의 처음 $n$개 항의 합 $S_n = a_1 + a_2 + \cdots + a_n$을 직접 계산하지 않고, 수열의 성질을 이용하여 공식으로 구하는 방법입니다. 수학1에서는 주로 등차수열과 등비수열의 합의공식을 다룹니다.

**등차수열의 합의공식**: 첫째항이 $a_1$, 공차가 $d$인 등차수열에서
$$S_n = \frac{n(a_1 + a_n)}{2} = \frac{n}{2}(2a_1 + (n-1)d)$$

**등비수열의 합의공식**: 첫째항이 $a$, 공비가 $r$인 등비수열에서 ($r \neq 1$일 때)
$$S_n = \frac{a(1-r^n)}{1-r}$$

## 직관/기하적 의미

등차수열의 합은 **역순 더하기 원리**로 유도됩니다. 수열을 앞에서부터, 뒤에서부터 두 번 더한 후 2로 나누면, 각 위치에서 $(a_1 + a_n)$이 $n$번 나타나므로 $S_n = \frac{n(a_1 + a_n)}{2}$입니다.

등비수열의 합은 **무한등비급수의 유한 버전**이므로, 기하급수의 구조를 반영합니다. $S_n$에 공비 $r$을 곱한 후 원래의 $S_n$에서 빼면, 대부분의 항이 소거되어 $a(1-r^n)$만 남습니다.

## 한 줄 예

첫째항 2, 공차 3인 등차수열에서 처음 10개 항의 합은 $S_{10} = \frac{10(2 + 29)}{2} = 155$이고, 첫째항 2, 공비 2인 등비수열에서 처음 5개 항의 합은 $S_5 = \frac{2(1-2^5)}{1-2} = 62$입니다. (검증: `sum([2*2**i for i in range(5)])` → 62)
