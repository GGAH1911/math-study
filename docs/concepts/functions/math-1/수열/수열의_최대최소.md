# 수열의 최대최소

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열의 최댓값과 최솟값은 모든 항 중에서 가장 큰 값과 가장 작은 값을 의미하며, 유한 수열은 항상 존재하지만 무한 수열은 존재하지 않을 수도 있습니다.

## 본문
수열 $\{a_n\}$에서 **최댓값**은 모든 항보다 크거나 같은 값으로, 어떤 $n_0$에 대해 모든 $n$에 대하여 $a_n \leq a_{n_0}$을 만족하는 값입니다. 마찬가지로 **최솟값**은 모든 항보다 작거나 같은 값으로, 어떤 $n_1$에 대해 모든 $n$에 대하여 $a_n \geq a_{n_1}$을 만족하는 값입니다. 유한한 항을 가진 유한 수열은 항상 최댓값과 최솟값을 가집니다. 반면 무한 수열의 경우에는 항이 무한히 커지거나 작아질 수 있으므로 최댓값이나 최솟값이 존재하지 않을 수도 있습니다. 예를 들어 $a_n = n$과 같은 수열은 항이 계속 커지므로 최댓값이 없고, $a_n = -n$과 같은 수열은 항이 계속 작아지므로 최솟값이 없습니다.

### 직관과 기하적 의미
수열을 좌표평면에 나타낼 때 각 항 $a_n$은 점 $(n, a_n)$으로 표시됩니다. 이때 최댓값은 이 점들 중 $y$좌표가 가장 큰 점의 $y$값이며, 최솟값은 $y$좌표가 가장 작은 점의 $y$값입니다. 특히 $a_n = an^2 + bn + c$와 같은 이차식 형태의 수열에서는 이차함수의 꼭짓점 위치를 통해 최댓값이나 최솟값이 나타나는 $n$의 위치를 파악할 수 있습니다. 만약 수열이 증가수열이라면 첫 항이 최솟값이 되고 마지막 항이 최댓값이 되며, 감소수열이라면 그 반대의 양상을 보입니다.

### 기본 성질
- 유한 수열은 반드시 최댓값과 최솟값을 가집니다.
- 무한 수열은 수열의 발산 여부에 따라 최댓값이나 최솟값이 없을 수 있습니다.
- 이차 수열의 경우 함수의 꼭짓점 위치와 수열의 항 번호($n$)를 비교하여 최댓값/최솟값을 결정합니다.

## 학습 체크
- 수열이 무한할 때 최댓값이나 최솟값이 존재하지 않는 구체적인 사례를 들 수 있는가?
- 이차식 형태의 수열에서 꼭짓점의 $n$값이 정수가 아닐 때 최댓값은 어떻게 결정되는가?

## 관련 개념
- **수열**: 수열의 각 항의 값들을 비교하여 그중 가장 큰 값과 작은 값을 찾는 과정입니다.
