# 첫째항

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열 $\{a_n\}$에서 $n=1$일 때의 항인 $a_1$은 수열의 시작을 알리는 출발점이자 전체 항을 결정하는 기초가 된다.

## 본문
수열 $\{a_n\}$에서 $n=1$일 때의 항을 **첫째항**(first term)이라 하며, 기호로 $a_1$로 나타낸다. 수열의 각 항은 일반적으로 $a_1, a_2, a_3, \ldots, a_n, \ldots$로 표기된다.

### 직관과 기하적 의미
수열은 일정한 규칙에 따라 나열된 수들의 집합이다. 첫째항은 이 수열의 **출발점**으로서, 수열 전체의 흐름을 결정하는 기준점이 된다. 특히 등차수열이나 등비수열과 같이 규칙성이 명확한 수열에서는 첫째항이 무엇인지에 따라 수열이 나아가는 방향과 위치가 완전히 달라진다.

### 기본 성질
규칙성이 있는 수열에서는 첫째항과 공차 또는 공비만 알아도 모든 항을 유일하게 결정할 수 있다. 예를 들어, 등차수열의 일반항은 $a_n = a_1 + (n-1)d$이므로 $a_1$이 정해져야 나머지 항들이 결정된다. 등비수열 또한 $a_n = a_1 \cdot r^{n-1}$의 형태를 가지므로 $a_1$의 값이 수열의 본질적인 구성 요소가 된다. 예시로 수열 $3, 7, 11, 15, 19, \ldots$에서 첫째항 $a_1 = 3$이고 공차 $d=4$일 때, $a_n = 3 + (n-1)4$를 통해 모든 항을 구할 수 있다.

## 학습 체크
- 수열의 첫째항 $a_1$이 변할 때, 수열의 전체적인 값의 크기나 변화 양상이 어떻게 달라지는가?
- 일반항 $a_n$이 주어졌을 때, $n=1$을 대입하여 첫째항을 정확히 찾아낼 수 있는가?

## 관련 개념
- **수열**: 첫째항을 포함하여 일정한 규칙에 따라 차례대로 나열된 수의 열을 의미한다.
