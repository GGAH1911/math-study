# 등차수열

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
연속한 두 항의 차가 일정한 수열입니다.

## 본문
등차수열은 연속한 두 항의 차가 항상 같은 상수인 수열을 의미합니다. 수열 $\{a_n\}$에서 $a_{n+1} - a_n = d$ (단, $d$는 상수)를 만족할 때, 이 수열을 공차가 $d$인 등차수열이라 합니다. 첫째항을 $a$, 공차를 $d$라 하면, 등차수열의 일반항은 다음과 같습니다.
$$a_n = a + (n-1)d$$

### 직관과 기하적 의미
등차수열은 매 단계마다 일정량씩 규칙적으로 증가하거나 감소하는 수열입니다. 예를 들어 매달 월급이 일정액씩 오른다면, 각 달의 월급은 등차수열을 이룹니다. 좌표평면에서 등차수열의 항들을 점 $(n, a_n)$으로 나타내면 모든 점이 일직선 위에 놓이게 되는데, 이는 등차수열이 선형 관계를 가진다는 것을 의미합니다.

### 기본 성질
첫째항 $a = 3$, 공차 $d = 2$인 등차수열을 예로 들면 항은 $3, 5, 7, 9, 11, \ldots$과 같이 나열됩니다. 이때 다섯째항은 $a_5 = 3 + (5-1) \times 2 = 11$로 구할 수 있습니다. 등차수열 여부를 판별하려면 인접한 항들의 차이가 모두 같은지 확인하면 됩니다. 일반항 공식을 암기하기에 앞서 첫 몇 개의 항을 직접 나열하며 규칙을 찾아보는 것이 이해에 효과적입니다.

## 학습 체크
- 연속한 두 항의 차가 일정한지 확인하여 등차수열임을 판별할 수 있는가?
- 첫째항과 공차를 이용하여 임의의 $n$번째 항을 구할 수 있는가?

## 관련 개념
- **수열**: 항들이 나열된 수의 집합이며, 등차수열은 이 중 가장 기본적인 형태의 수열입니다.
