# 귀납법 증명 예제

> **예제** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수학적 귀납법을 사용하여 자연수의 합 공식인 $1+2+\cdots+n=\frac{n(n+1)}{2}$을 증명합니다.

## 본문
수학적 귀납법을 이용하여 모든 양의 정수 $n$에 대해 다음이 성립함을 증명하시오:
$$1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}$$

### 단계별 풀이
**단계 1: 기저 단계($n=1$) 확인**
$n=1$일 때 좌변은 $1$이고 우변은 $\frac{1 \cdot 2}{2} = 1$이므로 등식이 성립합니다. 귀납법은 가장 작은 경우부터 시작하여 논리의 신뢰성을 확보합니다.

**단계 2: 귀납 가정 설정**
$n=k$일 때 등식이 참이라고 가정합니다:
$$1 + 2 + \cdots + k = \frac{k(k+1)}{2}$$
이 가정은 $n=k+1$일 때의 성립 여부를 확인하기 위한 발판이 됩니다.

**단계 3: 귀납 단계 증명($n=k+1$일 때)**
$n=k+1$일 때의 좌변을 구하기 위해 귀납 가정을 이용하여 $k$항까지의 합을 공식으로 대체합니다:
$$1 + 2 + \cdots + k + (k+1) = \frac{k(k+1)}{2} + (k+1)$$
우변을 공통인수 $(k+1)$로 묶고 통분하여 정리하면 다음과 같습니다:
$$\frac{k(k+1)}{2} + (k+1) = (k+1)\left(\frac{k}{2} + 1\right) = (k+1) \cdot \frac{k+2}{2} = \frac{(k+1)(k+2)}{2}$$
이는 $n=k+1$을 공식에 대입한 결과와 일치하므로, $n=k$가 참이면 $n=k+1$도 참임이 증명됩니다.

### 답과 변형
기저 단계와 귀납 단계가 모두 성립하므로, 수학적 귀납법에 의해 모든 양의 정수 $n$에 대해 $1+2+\cdots+n=\frac{n(n+1)}{2}$가 성립합니다.

이 공식은 첫째항과 마지막항이 같은 등차수열의 합 공식인 $S=\frac{n(\text{첫째항}+\text{마지막항})}{2}$의 특수한 경우입니다. 귀납법은 일반항이 복잡한 수열의 합이나 부등식 증명에 매우 강력한 도구이므로, 단순 암기보다는 증명 논리 자체를 이해하는 것이 중요합니다.

## 학습 체크
- $n=1$인 경우를 확인하는 기저 단계의 의미를 이해하고 있는가?
- $n=k$일 때의 가정을 $n=k+1$일 때의 식에 어떻게 적용하는지 알고 있는가?
- 증명 과정에서 공통인수로 묶어 식을 정리하는 대수적 과정을 수행할 수 있는가?

## 관련 개념
- **수열**: 수열의 합을 구하는 과정에서 수학적 귀납법은 일반항을 이용한 계산 외에 논리적인 증명 도구로 사용됩니다.
