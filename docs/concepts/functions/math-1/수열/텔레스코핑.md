# 텔레스코핑

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열의 일반항을 인접한 두 항의 차이 형태로 변형하여, 합을 계산할 때 중간 항들을 모두 소거하고 양 끝의 항만 남기는 계산 기법입니다.

## 본문
텔레스코핑(telescoping)은 수열의 일반항을 부분 차이 형태로 나타낼 수 있을 때 활용하는 합 계산 기법입니다. 즉, $a_n = b_n - b_{n-1}$ 형태로 표현 가능한 수열의 부분합을 구할 때, 인접한 항들이 소거되는 성질을 이용합니다. 이 경우 부분합은 다음과 같이 극단적으로 단순화됩니다:
$$\sum_{k=1}^{n} a_k = \sum_{k=1}^{n} (b_k - b_{k-1}) = b_n - b_0$$

### 직관과 기하적 의미
전개식을 따라가면 이해가 쉽습니다:
$$(b_1 - b_0) + (b_2 - b_1) + (b_3 - b_2) + \cdots + (b_n - b_{n-1})$$
이 합에서 $b_1, b_2, \ldots, b_{n-1}$은 각각 양수항과 음수항으로 동시에 나타나므로 모두 소거됩니다. 망원경의 관을 줄이듯 연쇄적으로 항이 사라진다는 뜻에서 "텔레스코핑"이라 부릅니다. 이 기법은 일반항이 겉으로는 복잡하지만 부분분수 분해나 적절한 변형으로 차이 형태를 만들 수 있는 수열을 다룰 때 매우 유용합니다.

### 기본 성질
대표적인 예로 $\tfrac{1}{k(k+1)} = \tfrac{1}{k} - \tfrac{1}{k+1}$과 같은 형태를 들 수 있습니다. 이를 통해 다음과 같은 계산이 가능합니다:
$$\sum_{k=1}^{n} \frac{1}{k(k+1)} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1 - \frac{1}{n+1} = \frac{n}{n+1}$$
예를 들어 $n=5$일 때의 값은 $\tfrac{5}{6}$이 됩니다.

## 학습 체크
- 일반항을 $b_n - b_{n-1}$ 꼴로 변형할 수 있는가?
- 합을 전개했을 때 소거되지 않고 남는 첫 항과 마지막 항을 정확히 찾았는가?
- 부분분수 분해와 같이 일반항을 변형하는 기술을 숙지하고 있는가?

## 관련 개념
- **수열**: 텔레스코핑은 수열의 합을 구하는 핵심적인 방법론 중 하나로, 수열의 항들이 서로 상쇄되는 구조를 가질 때 적용됩니다.
