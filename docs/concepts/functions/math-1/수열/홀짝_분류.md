# 홀짝 분류

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 정확한 진술

수열 $\{a_n\}$에서 첫 번째, 세 번째, 다섯 번째... 항을 모아 만든 부분수열을 **홀수 항 수열**이라 하고, 두 번째, 네 번째, 여섯 번째... 항을 모아 만든 부분수열을 **짝수 항 수열**이라 합니다.

$$\text{홀수 항: } a_1, a_3, a_5, \ldots, a_{2k-1}, \ldots$$

$$\text{짝수 항: } a_2, a_4, a_6, \ldots, a_{2k}, \ldots$$

특히 홀수 항 수열을 $\{a_{2k-1}\}$ 또는 $\{a_{2n-1}\}$로, 짝수 항 수열을 $\{a_{2k}\}$ 또는 $\{a_{2n}\}$로 표기합니다.

## 직관/기하적 의미

홀짝 분류는 수열을 두 개의 "길"로 나누어 각각의 규칙을 분석하는 기법입니다. 복잡한 수열이 실은 홀수 위치와 짝수 위치에서 서로 다른 등비 또는 등차 패턴을 따를 때가 많기 때문입니다. 예를 들어, 점화식 $a_n = 2a_{n-2} + 3$처럼 두 칸 뛰어 점프하는 식을 풀 때는 홀수 항과 짝수 항을 따로 취급하면 훨씬 단순한 등차 또는 등비수열 문제로 축소됩니다.

## 한 줄 예

수열 $a_1 = 1, a_2 = 2, a_3 = 3, a_4 = 4, a_5 = 5, a_6 = 6, \ldots$에서 홀수 항 수열은 $\{1, 3, 5, \ldots\}$이고 짝수 항 수열은 $\{2, 4, 6, \ldots\}$입니다.

**검산**: 주어진 수열에서 홀수 항은 $a_{2k-1} = 2k-1$, 짝수 항은 $a_{2k} = 2k$입니다.
