# 홀짝 분류

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
수열의 항을 인덱스의 홀수와 짝수 여부에 따라 두 개의 부분수열로 나누어 분석하는 방법입니다.

## 본문
수열 $\{a_n\}$에서 첫 번째, 세 번째, 다섯 번째 항을 모아 만든 부분수열을 **홀수 항 수열**이라 하고, 두 번째, 네 번째, 여섯 번째 항을 모아 만든 부분수열을 **짝수 항 수열**이라 합니다. 이를 수식으로 나타내면 다음과 같습니다.

$$\text{홀수 항: } a_1, a_3, a_5, \ldots, a_{2k-1}, \ldots$$
$$\text{짝수 항: } a_2, a_4, a_6, \ldots, a_{2k}, \ldots$$

일반적으로 홀수 항 수열은 $\{a_{2k-1}\}$ 또는 $\{a_{2n-1}\}$로 표기하며, 짝수 항 수열은 $\{a_{2k}\}$ 또는 $\{a_{2n}\}$으로 표기합니다.

### 직관과 기하적 의미
홀짝 분류는 수열을 두 개의 서로 다른 "길"로 나누어 각각의 규칙을 독립적으로 분석하는 기법입니다. 복잡한 수열이 실은 홀수 위치와 짝수 위치에서 서로 다른 등차 또는 등비 패턴을 따르는 경우가 많기 때문입니다. 예를 들어, $a_n = 2a_{n-2} + 3$과 같이 두 칸씩 건너뛰며 정의된 점화식의 경우, 홀수 항과 짝수 항을 분리하여 생각하면 각각 단순한 등차 또는 등비수열 문제로 축소되어 훨씬 쉽게 해결할 수 있습니다.

### 기본 성질
- 홀수 항 수열의 일반항은 $n$에 대한 식 $a_{2n-1}$로 표현됩니다.
- 짝수 항 수열의 일반항은 $n$에 대한 식 $a_{2n}$으로 표현됩니다.
- 수열의 항이 홀수와 짝수로 명확히 구분되므로, 전체 수열의 성질을 파악할 때 두 부분수열의 규칙을 각각 구한 뒤 결합하는 방식으로 접근할 수 있습니다.

## 학습 체크
- 주어진 수열의 일반항이 $n$에 대한 식일 때, 홀수 항과 짝수 항의 일반항을 각각 $k$에 관한 식으로 정확히 유도할 수 있는가?
- 두 칸씩 건너뛰는 형태의 점화식이 주어졌을 때, 이를 홀수 항과 짝수 항의 관점으로 분리하여 해석할 수 있는가?

## 관련 개념
- **수열**: 홀짝 분류는 수열의 항들을 특정 규칙에 따라 부분수열로 나누어 분석하는 하위 기법입니다.
