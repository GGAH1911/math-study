# 공차

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
등차수열에서 이웃한 두 항의 차이가 항상 일정하게 유지되는 값을 의미합니다.

## 본문
등차수열 $\{a_n\}$에서 임의의 항과 그 앞 항의 차를 **공차**(common difference)라고 하며, 보통 문자 $d$로 나타냅니다. 공차는 다음과 같이 정의됩니다:
$$d = a_{n+1} - a_n \quad (n \geq 1)$$
등차수열의 특징은 모든 연속된 두 항의 차가 항상 같은 상수값이라는 점입니다.

### 직관과 기하적 의미
공차는 수열이 일정하게 증가하거나 감소하는 정도를 나타내는 척도입니다. 수열을 시간에 따른 변화로 이해한다면, 공차는 매 단위 시간마다 발생하는 일정한 변화의 크기와 같습니다. 공차의 부호에 따라 수열의 흐름이 결정됩니다.
- $d > 0$이면 수열은 일정하게 증가합니다.
- $d < 0$이면 수열은 일정하게 감소합니다.
- $d = 0$이면 모든 항이 동일한 상수 수열이 됩니다.

### 기본 성질
공차를 알면 첫째항 $a_1$과 결합하여 수열의 모든 항을 결정할 수 있습니다. 일반항은 첫째항에서 공차를 $(n-1)$번 더한 형태인 $a_n = a_1 + (n-1)d$로 표현됩니다. 예를 들어, 수열 $2, 5, 8, 11, \ldots$에서 공차 $d$는 $5 - 2 = 3$입니다. 이때 일반항은 $a_n = 2 + (n-1) \times 3 = 3n - 1$이 되며, 이를 통해 $a_{10} = 29$임을 쉽게 구할 수 있습니다.

## 학습 체크
- 공차의 부호에 따라 수열이 증가수열인지 감소수열인지 구분할 수 있는가?
- 주어진 수열의 항들 사이의 관계를 통해 공차 $d$를 정확히 계산할 수 있는가?
- 공차와 첫째항을 이용하여 일반항 $a_n$을 도출할 수 있는가?

## 관련 개념
- **수열**: 공차는 등차수열을 정의하는 핵심 요소로, 수열의 항들이 일정한 규칙을 가지고 나열되도록 만드는 기준이 됩니다.
