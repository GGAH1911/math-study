# 거듭제곱의 합

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 요약
자연수의 거듭제곱을 차례대로 더한 합을 의미하며, 차수에 따라 특정한 다항식 공식으로 나타낼 수 있습니다.

## 본문
거듭제곱의 합이란 자연수 $1, 2, 3, \ldots, n$의 $k$제곱을 모두 더한 것을 뜻하며, 일반적으로 다음과 같이 나타냅니다.
$$\sum_{i=1}^{n} i^k = 1^k + 2^k + 3^k + \cdots + n^k$$
여기서 $k$는 양의 정수입니다. 가장 대표적으로 다루는 경우는 $k=1, 2, 3$인 경우로, 각각의 공식은 다음과 같습니다.
$k=1$일 때: $\sum_{i=1}^{n} i = \tfrac{n(n+1)}{2}$
$k=2$일 때: $\sum_{i=1}^{n} i^2 = \tfrac{n(n+1)(2n+1)}{6}$
$k=3$일 때: $\sum_{i=1}^{n} i^3 = \left[\tfrac{n(n+1)}{2}\right]^2$

### 직관과 기하적 의미
1차 합은 등차수열의 합으로서 사다리꼴 모양의 개수를 세는 것과 같고, 제곱의 합은 정사각형 타일들을 쌓아 올릴 때 필요한 개수와 관련이 있어 피라미드 모양의 부피를 계산하는 것과 유사한 의미를 갖습니다. 세제곱의 합은 1차 합의 제곱과 같다는 흥미로운 항등식을 만족합니다.

### 기본 성질
$k=1$인 경우의 합은 연속된 자연수의 합 공식과 일치하며, $k=3$인 경우의 합은 $k=1$일 때 구한 결과값을 제곱한 것과 정확히 일치하는 성질을 보입니다.

## 학습 체크
- $k=2$인 경우의 공식에서 분모가 $6$인 이유를 기하학적 구조를 통해 설명할 수 있는가?
- 세제곱의 합 공식이 일차항의 합의 제곱과 왜 같은 결과가 나오는지 증명할 수 있는가?
- 주어진 $n$의 값에 대해 공식이 실제 계산 결과와 일치하는지 검산할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 거듭제곱의 합 공식을 이용하여 미지수 $n$에 대한 고차 방정식의 해를 구하거나, 합의 범위를 결정하는 부등식 문제를 해결할 수 있습니다.
