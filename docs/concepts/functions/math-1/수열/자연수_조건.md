# 자연수 조건

## 정확한 진술

수열 $\{a_n\}$에서 **자연수 조건**이란 인덱스 $n$이 자연수(양의 정수) 집합 $\mathbb{N} = \{1, 2, 3, \ldots\}$에만 속해야 한다는 조건입니다. 보통 "단, $n$은 자연수", "$n \in \mathbb{N}$", 또는 "$n = 1, 2, 3, \ldots$"로 명시합니다. 이 조건이 있어야 수열의 항이 정확히 어디서부터 시작되고 어떤 범위에서 정의되는지 명확합니다.

## 직관/기하적 의미

수열은 **자연수를 입력받아 수를 출력하는 함수**이기 때문에, 정의역이 자연수로 제한됩니다. 자연수 조건을 명시하지 않으면 $a_0$ (0번째 항), $a_{-1}$ (음수 인덱스), $a_{1.5}$ (분수 인덱스) 같은 이상한 항들이 나타날 수 있으므로, 이를 방지합니다. 자연수 조건은 **수열이 첫 번째 항부터 시작하여 순서대로 정의된다**는 의미입니다. 따라서 수열과 함수를 구별할 때, 수열의 특수성(순서, 시작점)을 보장합니다.

## 한 줄 예

일반항 $a_n = 2n - 1$ (단, $n$은 자연수)로 정의하면, $a_1 = 1, a_2 = 3, a_3 = 5, \ldots$가 명확하게 정의됩니다.
