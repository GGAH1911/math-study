# 점화식

> **정의** · 수학1 · 단원: [수열](/concepts/수열)

## 정확한 진술

점화식은 수열의 어떤 항이 그 앞의 항들로 표현되는 관계식입니다. 일반적으로 $a_n = f(a_{n-1}, a_{n-2}, \ldots)$ 형태이며, 초기값(초항)과 함께 주어집니다. 예를 들어 $a_n = a_{n-1} + d$ (공차가 $d$인 등차수열)나 $a_n = a_{n-1} \cdot r$ (공비가 $r$인 등비수열)이 점화식입니다.

## 직관과 실용성

점화식의 핵심은 **한 항을 알면 다음 항을 계산할 수 있다**는 뜻입니다. 마치 도미노 패턴처럼 첫 번째 항(또는 처음 몇 항)만 정해지면, 나머지는 규칙에 따라 자동으로 결정됩니다. 

수학의 여러 분야에서 자연스럽게 나타납니다. 은행의 복리 계산($a_n = a_{n-1} \cdot (1 + r)$), 바이러스 감염 모델, 피보나치 수열($a_n = a_{n-1} + a_{n-2}$) 등이 모두 점화식으로 표현됩니다. 닫힌 형태(일반항)로 표현하기 어려울 때 점화식은 수열의 패턴을 간단하게 기술하는 강력한 도구입니다.

## 기본 예제

**예 1: 등차수열**
$$a_n = a_{n-1} + 2, \quad a_1 = 3$$
이면 $a_1 = 3$, $a_2 = 5$, $a_3 = 7$, ... 입니다.

**예 2: 기하수열**
$$a_n = 3a_{n-1}, \quad a_1 = 2$$
이면 $a_1 = 2$, $a_2 = 6$, $a_3 = 18$, ... 입니다.

**검산:**
```python
# 예 1: a_n = a_{n-1} + 2, a_1 = 3
a = [0, 3]  # a[1] = 3
for i in range(2, 5):
    a.append(a[i-1] + 2)
# a = [0, 3, 5, 7, 9]
```

점화식은 수열의 구체적 계산($a_1$에서 $a_{100}$까지)과 이론적 분석(수렴성, 합)의 다리 역할을 하므로 수능 수열 단원의 핵심 개념입니다.
