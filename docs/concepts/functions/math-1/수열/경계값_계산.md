# 경계값 계산

## 정확한 진술

수열 $\{a_n\}$이 어떤 실수 $L$로 **수렴한다**는 것은, $n$이 커질수록 $a_n$이 $L$에 임의로 가까워진다는 뜻입니다. 이 수렴하는 값 $L$을 수열의 **극한값(limit value)** 또는 **경계값**이라 하고, 기호로 $\lim_{n \to \infty} a_n = L$로 나타냅니다.

더 엄밀하게는, 임의의 양수 $\epsilon > 0$에 대해 어떤 자연수 $N$이 존재하여 $n > N$일 때 항상 $|a_n - L| < \epsilon$이 성립하면 $\lim_{n \to \infty} a_n = L$입니다.

## 직관과 기하적 의미

수열의 항들을 수직선 위에 표시하면, 경계값은 수열이 "수렴해 들어가는" 그 점입니다. $n$이 충분히 크면, 수열의 항들은 경계값 주변의 아무리 좁은 구간 안에도 몰려 있게 됩니다.

경계값 계산은 다음과 같은 상황에서 필수입니다:
- 함수의 미분(도함수의 정의: $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$)
- 정적분(리만 합의 극한)
- 급수의 수렴성 판정

따라서 극한값을 효율적으로 구하는 기술은 미분과 적분 학습의 토대가 됩니다.

## 한 줄 예

수열 $a_n = \frac{2n + 1}{n}$의 경우, $\lim_{n \to \infty} \frac{2n + 1}{n} = \lim_{n \to \infty} \left(2 + \frac{1}{n}\right) = 2$이므로 경계값은 $2$입니다. (`sympy.limit(n + 1/2, n, oo)` → 2)
