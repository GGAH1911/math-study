### 정확한 진술

시그마 기호 $\sum$는 수열의 여러 항을 더할 때 사용하는 표기법입니다. 일반적으로 다음과 같이 나타냅니다:

$$\sum_{k=m}^{n} a_k = a_m + a_{m+1} + a_{m+2} + \cdots + a_n$$

여기서:
- $k$는 **합변수** (또는 첨수)로, $m$부터 $n$까지 변합니다
- $m$은 시작 값(하한, lower bound)
- $n$은 끝 값(상한, upper bound)  
- $a_k$는 $k$번째 항(일반항)

### 직관 및 의미

시그마는 "차례대로 더해서 합을 구하라"는 의미를 간단히 표현한 것입니다. 예를 들어 "첫 100개의 자연수를 모두 더하라"를 일일이 쓰면 $1 + 2 + 3 + \cdots + 100$이 되어 매우 복잡하지만, 시그마를 쓰면 $\sum_{k=1}^{100} k$로 간단히 나타낼 수 있습니다. 이 표기법은 긴 합을 압축할 뿐 아니라, 합의 규칙을 분석하거나 일반적인 패턴을 찾을 때도 매우 유용합니다.

### 한 줄 예시

$$\sum_{k=1}^{4} k = 1 + 2 + 3 + 4 = 10$$

좀 더 복잡한 예: $\sum_{k=1}^{5} k^2 = 1 + 4 + 9 + 16 + 25 = 55$

(검산: `sum(k**2 for k in range(1, 6))` → 55)
