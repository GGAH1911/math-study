### 정확한 진술

삼각함수의 관계식은 같은 각 또는 관련된 각에 대해 삼각함수 값들 사이에 항상 성립하는 항등식입니다. 기본 관계식은 다음과 같습니다:

**피타고라스 항등식**
$$\sin^2\theta + \cos^2\theta = 1$$

**몫의 관계식**
$$\tan\theta = \frac{\sin\theta}{\cos\theta}$$

이들은 각의 크기 $\theta$에 관계없이 항상 참입니다.

### 직관과 기하적 의미

단위원 위의 점 $P(\cos\theta, \sin\theta)$를 생각해봅시다. 이 점은 반지름이 1인 원 위에 있으므로, 거리 공식에 의해:
$$(\cos\theta)^2 + (\sin\theta)^2 = 1^2$$

즉, 피타고라스 정리 자체가 피타고라스 항등식의 기하학적 근거입니다. 직각삼각형의 빗변이 1이고, 밑변이 $\cos\theta$, 높이가 $\sin\theta$이므로 자동으로 성립하는 것이죠.

$\tan\theta$는 기울기로 해석되므로, $\frac{\sin\theta}{\cos\theta}$ (높이 ÷ 밑변)로 정의되는 것이 자연스럽습니다.

### 한 줄 예

$\theta = 30°$일 때: $\sin^2 30° + \cos^2 30° = \left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1$ ✓

(검증: `sympy.simplify(sin(pi/6)**2 + cos(pi/6)**2)` → 1)
