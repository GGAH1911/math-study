### 정확한 진술

두 곡선의 **교점의 좌표**는 두 곡선의 방정식을 동시에 만족하는 점 $(x, y)$의 좌표입니다. 곡선 $f(x) = 0$과 $g(x) = 0$의 교점을 구하려면, $f(x) = g(x)$를 풀어 $x$ 값(들)을 찾고, 이를 원래 식에 대입하여 $y$ 값을 구합니다.

### 직관과 기하적 의미

좌표평면에서 두 그래프가 만나는 지점이 교점입니다. 예를 들어 직선 $y = 2x + 1$과 포물선 $y = x^2$의 교점은 두 식이 동시에 성립하는 위치에서 발생합니다. 이를 찾기 위해 $2x + 1 = x^2$로 정리하고 풉니다. 삼각함수의 경우, $\sin x = \cos x$ 같은 방정식은 사인 함수와 코사인 함수 그래프의 교점의 $x$ 좌표들을 나타냅니다.

### 단계별 풀이 예

**예:** 직선 $y = x + 1$과 원 $x^2 + y^2 = 5$의 교점을 구하세요.

원의 방정식에 $y = x + 1$을 대입합니다:
$$x^2 + (x + 1)^2 = 5$$
$$x^2 + x^2 + 2x + 1 = 5$$
$$2x^2 + 2x - 4 = 0$$
$$x^2 + x - 2 = 0$$
$$(x + 2)(x - 1) = 0$$

따라서 $x = -2$ 또는 $x = 1$입니다.

- $x = -2$일 때: $y = -2 + 1 = -1$ → 교점 $(-2, -1)$
- $x = 1$일 때: $y = 1 + 1 = 2$ → 교점 $(1, 2)$

(검산: `sympy.solve([x**2 + y**2 - 5, y - x - 1], [x, y])` → $[(-2, -1), (1, 2)]$)

### 주의사항

- 교점이 없을 수도 있습니다 (판별식이 음수이거나 교집합이 공집합).
- 접하는 경우 중근이 나타나므로, 교점의 개수를 확인하세요.
- 삼각함수 방정식에서는 주기성을 고려하여 모든 해를 기술해야 합니다.
