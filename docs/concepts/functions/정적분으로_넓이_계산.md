### 정확한 진술

곡선 $y = f(x)$ ($a \le x \le b$에서 $f(x) \ge 0$)과 $x$축 사이의 넓이는 정적분으로 다음과 같이 나타낼 수 있습니다.

$$\text{넓이} = \int_a^b f(x) \, dx$$

더 일반적으로, $f(x)$가 음수 구간을 포함하면 넓이는 다음과 같습니다.

$$\text{넓이} = \int_a^b |f(x)| \, dx$$

두 곡선 $y = f(x)$와 $y = g(x)$ ($f(x) \ge g(x)$)로 둘러싸인 영역의 넓이는 다음과 같습니다.

$$\text{넓이} = \int_a^b [f(x) - g(x)] \, dx$$

### 직관적 이해

정적분이 넓이가 되는 이유는 리만 합의 극한에서 비롯됩니다. 구간 $[a, b]$를 $n$개의 작은 구간으로 나누고, 각 구간의 폭을 $\Delta x$, 높이를 $f(x_i)$로 하는 직사각형들의 넓이를 더하면 근사 넓이를 얻습니다. $n \to \infty$일 때 이 합이 수렴하는 값이 바로 정적분입니다. 즉, 정적분은 "무한히 많은 무한히 작은 직사각형의 합"이므로 정확한 넓이를 나타냅니다.

기하적으로, $x$축 아래의 영역은 음의 넓이로 취급되므로, 절댓값이 필요한 경우가 있습니다.

### 한 줄 예

$y = x^2$ ($0 \le x \le 2$)과 $x$축 사이의 넓이는 $\int_0^2 x^2 \, dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3}$입니다.

(검산: `from sympy import symbols, integrate; x = symbols('x'); integrate(x**2, (x, 0, 2))` → $\frac{8}{3}$)
