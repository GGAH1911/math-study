# 치환적분 예제

> **예제** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
$\int 2x\cos(x^2)dx$

## 본문 (학습 시 채워짐)

### 문제

다음 부정적분을 구하시오.
$$\int 2x\cos(x^2)\,dx$$

### 단계별 풀이

**1단계: 피적분함수 분석**

$2x\cos(x^2)$를 보면, $x^2$이라는 합성함수가 안에 있고, $2x$는 그 미분입니다. 이것이 바로 치환적분을 사용해야 할 신호입니다.

**2단계: 치환 설정**

$u = x^2$로 놓으면:
$$\frac{du}{dx} = 2x \quad \Rightarrow \quad du = 2x\,dx$$

**3단계: 적분식 변환**

원래의 적분에서 $2x\,dx$를 $du$로 바꾸면:
$$\int 2x\cos(x^2)\,dx = \int \cos(u)\,du$$

**4단계: 기본 적분 공식 적용**

$$\int \cos(u)\,du = \sin(u) + C$$

**5단계: 역치환**

$u = x^2$를 다시 대입합니다:
$$\sin(u) + C = \sin(x^2) + C$$

검증: $\frac{d}{dx}[\sin(x^2)] = \cos(x^2) \cdot 2x = 2x\cos(x^2)$ ✓

### 답

$$\int 2x\cos(x^2)\,dx = \sin(x^2) + C$$

### 변형/주의

**변형 1:** $\int 2x\sin(x^2)\,dx$는 같은 방법으로 $u = x^2$로 치환하면 $-\cos(x^2) + C$입니다.

**변형 2:** $\int 3x^2 e^{x^3}\,dx$도 $u = x^3$로 치환하면 $e^{x^3} + C$가 됩니다.

**주의:** 치환을 선택할 때는 "$du$가 이미 적분식에 있는가?"를 확인하세요. 여기서는 $du = 2x\,dx$가 정확히 피적분함수에 포함되어 있어서 추가 상수 조정이 불필요했습니다.
