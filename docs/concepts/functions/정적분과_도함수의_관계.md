### 정확한 진술

연속함수 $f(x)$가 주어졌을 때, **정적분과 도함수의 관계**는 다음 두 명제로 이루어집니다.

**[미적분학 기본정리 1부]** 함수 $F(x) = \int_a^x f(t)\,dt$로 정의하면, $F'(x) = f(x)$입니다.

**[미적분학 기본정리 2부]** $F'(x) = f(x)$인 부정적분 $F(x)$가 존재할 때, $$\int_a^b f(x)\,dx = F(b) - F(a)$$

### 직관/기하적 의미

첫 번째 명제는 **정적분과 미분이 역연산**임을 보여줍니다. $x$를 조금 증가시킬 때 누적 넓이 $F(x)$의 변화량은 그 순간의 함수값 $f(x)$에 비례합니다. 

$$\frac{dF}{dx} = \lim_{\Delta x \to 0} \frac{\int_a^{x+\Delta x} f(t)\,dt - \int_a^x f(t)\,dt}{\Delta x} = \lim_{\Delta x \to 0} \frac{\int_x^{x+\Delta x} f(t)\,dt}{\Delta x} \approx f(x)$$

두 번째 명제는 정적분을 **실제로 계산하는 방법**을 제시합니다. $a$부터 $b$까지의 누적 변화량은 구간 양 끝점에서의 부정적분 값의 차이와 같습니다.

### 한 줄 예

$f(x) = 2x$일 때, $F(x) = x^2$은 $F'(x) = 2x = f(x)$를 만족하며, $\int_1^3 2x\,dx = 3^2 - 1^2 = 8$입니다. (검증: `sympy.integrate(2*x, (x, 1, 3))` → 8)
