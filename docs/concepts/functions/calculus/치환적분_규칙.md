# 치환적분 규칙

> **정리** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
변수 치환으로 단순화

## 본문 (학습 시 채워짐)

### 진술 및 가정

$u = g(x)$로 놓을 때, $\int f(g(x)) g'(x) dx = \int f(u) du$

이것이 **치환적분(integration by substitution)의 핵심 규칙**입니다. 가정은 $f$와 $g$가 연속이고 $g$가 미분가능해야 한다는 것입니다. 또한 $u = g(x)$로 치환할 때 역함수가 존재하거나, 적어도 적분 구간에서 일대일 대응이어야 합니다.

### 증명 스케칙 및 직관

미적분학의 기본정리와 **연쇄 법칙의 역**으로부터 유도됩니다. $F'(u) = f(u)$라 하면, 연쇄 법칙에 의해
$$\frac{d}{dx}[F(g(x))] = F'(g(x)) \cdot g'(x) = f(g(x)) \cdot g'(x)$$

양변을 $x$에 대해 적분하면
$$\int f(g(x)) g'(x) dx = F(g(x)) + C$$

한편 $\int f(u) du = F(u) + C$이므로, 두 식은 본질적으로 같습니다. **복잡한 합성함수를 더 단순한 형태로 변환하는 것**이 핵심 아이디어입니다.

### 의의와 응용

치환적분은 직접 계산하기 어려운 적분을 다루기 쉬운 형태로 만드는 강력한 도구입니다. 예를 들어, $\int 2x \sin(x^2) dx$에서 $u = x^2$로 놓으면 $du = 2x dx$이므로 $\int \sin(u) du = -\cos(u) + C = -\cos(x^2) + C$가 됩니다.

**선택 기준**: $g'(x)$가 피적분함수에 명시적으로 포함되어 있거나, 합성함수 구조가 명확할 때 효과적입니다. 지수함수, 로그함수, 삼각함수가 포함된 합성함수 적분에서 특히 자주 사용됩니다.

검산: `sympy.integrate(2*x*sp.sin(x**2), x)` → $-\cos(x^2) + C$ ✓
