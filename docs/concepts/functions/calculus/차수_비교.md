### 정확한 진술

두 함수 $f(x)$, $g(x)$에 대해, $x \to \infty$일 때 비율의 극한
$$\lim_{x \to \infty} \frac{f(x)}{g(x)}$$
을 조사하여 **극한값이 무한대이면** $f(x)$가 $g(x)$보다 **고차(高次)**, **0이면** $f(x)$가 $g(x)$보다 **저차(低次)**, **0이 아닌 유한값이면** **같은 차수**라고 합니다.

### 직관적 의미

$x$가 충분히 크거나 작을 때, 어느 함수가 더 빠르게 변하는지를 판단합니다. 예를 들어 $x^3$과 $x^2$을 비교하면, $x$가 커질수록 $x^3$이 훨씬 더 빠르게 커지므로 고차입니다. 극한값을 계산할 때 $\displaystyle \frac{\infty}{\infty}$ 꼴을 마주칠 때, 분자와 분모의 **차수를 비교**하면 극한값이 무한대인지 0인지 유한인지가 결정됩니다. 분자가 분모보다 고차이면 극한은 $\infty$, 분모가 고차이면 극한은 $0$입니다.

### 예

$$\lim_{x \to \infty} \frac{x^3 + x}{x^2 + 1} = \infty \quad \text{(분자가 고차)}$$

$$\lim_{x \to \infty} \frac{2x}{x^3 + 5} = 0 \quad \text{(분모가 고차)}$$

$$\lim_{x \to \infty} \frac{3x^2}{x^2 + 1} = 3 \quad \text{(같은 차수)}$$

검증: `from sympy import *; x = symbols('x'); limit(x**3 / x**2, x, oo)` → ∞, `limit(x / x**2, x, oo)` → 0
