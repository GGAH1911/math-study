### 정확한 진술

등비수열 $\{a_n\}$의 첫째항을 $a_1$, 공비를 $r$이라 할 때, $a_n = a_1 \cdot r^{n-1}$입니다. 이 수열이 **수렴한다**는 것은 다음과 같이 정의됩니다.

$$\begin{align}
|r| < 1 &\Rightarrow \lim_{n \to \infty} a_n = 0 \\
r = 1 &\Rightarrow \lim_{n \to \infty} a_n = a_1 \\
r = -1 \text{ 또는 } |r| > 1 &\Rightarrow \text{발산}
\end{align}$$

### 직관/기하적 의미

공비 $r$의 절댓값이 1보다 작으면 항이 계속 곱해질 때마다 크기가 줄어듭니다. $r$이 0에 가까울수록 더 빠르게 0으로 수렴하고, $r$이 음수면 부호가 번갈아 바뀌며 진동하면서 0에 접근합니다. 예를 들어 $r = 0.5$일 때는 단조 감소하고, $r = -0.5$일 때는 0 주변에서 진동합니다.

반면 $|r| = 1$이면 수열의 크기가 변하지 않아 수렴할 수 있지만($r = 1$일 때만), $|r| > 1$이면 항들이 기하급수적으로 커져서 발산합니다. 특히 $r = -1$이면 $a_1, -a_1, a_1, -a_1, \ldots$로 진동합니다.

### 한 줄 예

첫째항이 8이고 공비가 $\frac{1}{2}$인 등비수열 $8, 4, 2, 1, \frac{1}{2}, \ldots$은 0으로 수렴합니다. (검산: `sympy.limit(8 * (0.5)**(n-1), n, sympy.oo)` = 0)
