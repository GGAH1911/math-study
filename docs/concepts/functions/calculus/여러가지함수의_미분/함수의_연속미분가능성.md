# 함수의 연속미분가능성

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지_함수의_미분)

## 정확한 진술

함수 $f(x)$가 폐구간 $[a, b]$에서 **연속미분가능(continuously differentiable)**하다는 것은 다음 두 조건을 모두 만족한다는 뜻입니다:

1. $f(x)$가 $[a, b]$에서 미분가능하다
2. 도함수 $f'(x)$가 $[a, b]$에서 연속이다

이런 함수를 $C^1([a, b])$ 또는 $C^{(1)}$로 표기하기도 합니다.

## 직관/기하적 의미

"미분가능하면 연속이다"라는 정리를 배웠을 것입니다. 그러면 역은 어떨까요? **미분가능한 함수의 도함수가 항상 연속인 것은 아닙니다.** 

예를 들어, 
$$f(x) = \begin{cases} x^2 \sin(1/x) & x \neq 0 \\ 0 & x = 0 \end{cases}$$
는 모든 점에서 미분가능하지만, 도함수 $f'(x)$는 $x = 0$에서 불연속입니다. 미분은 가능하지만 접선의 기울기가 "뜬금없이" 변하는 것입니다.

연속미분가능성은 이보다 훨씬 강한 조건입니다. 함수가 연속미분가능하면 그래프가 "매끄럽게" 이어져 있을 뿐만 아니라, **접선의 기울기도 부드럽게 변합니다**. 기하학적으로는 꺾이거나 뾰족한 부분 없이 완벽하게 부드러운 곡선입니다.

$$\text{연속미분가능} \Rightarrow \text{미분가능} \Rightarrow \text{연속}$$

## 한 줄 예

- $f(x) = x^2$는 연속미분가능입니다. $f'(x) = 2x$는 모든 점에서 연속이기 때문입니다.
- $f(x) = |x|$는 $x = 0$에서 미분가능하지 않으므로, 연속미분가능하지 않습니다.
- 다항함수나 삼각함수, 지수함수 같은 기본 초등함수들은 정의역에서 모두 연속미분가능합니다.
