# 미분의 계산

## 정확한 진술

함수 $f(x)$가 $x=a$에서 미분가능하다는 것은 다음 극한이 존재한다는 뜻입니다.

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

이 극한값을 **$x=a$에서의 미분계수** 또는 **도함수값**이라 합니다. 구간 $I$ 내 모든 점에서 미분가능한 함수의 도함수는 $f'(x)$ 또는 $\frac{df}{dx}$로 기록됩니다.

## 직관/기하적 의미

미분 계산은 함수 곡선 위 한 점에서의 **접선의 기울기**를 구하는 과정입니다. 분자 $f(a+h) - f(a)$는 높이의 변화, 분모 $h$는 가로의 변화이므로, $h \to 0$일 때 할선의 기울기가 접선의 기울기로 수렴합니다. 이는 함수의 **순간변화율**을 의미하며, 함수가 어떤 지점에서 얼마나 빠르게 변하는지를 나타냅니다.

## 실제 계산 절차

$f(x) = x^2$일 때 $f'(1)$을 구하면:

$$f'(1) = \lim_{h \to 0} \frac{(1+h)^2 - 1^2}{h} = \lim_{h \to 0} \frac{2h + h^2}{h} = \lim_{h \to 0} (2 + h) = 2$$

일반적으로는 도함수 공식들(멱함수, 삼각함수, 지수로그함수의 미분 공식)과 미분법 정리(곱의 미분, 합성함수의 미분)를 조합하여 복잡한 함수의 도함수를 효율적으로 구합니다.

`sympy.limit((x+h)**2 - x**2, h, 0) / h`를 계산하면 $2x$를 얻습니다.
