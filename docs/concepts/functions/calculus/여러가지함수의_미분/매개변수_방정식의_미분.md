### 정확한 진술

곡선이 매개변수 $t$로 표현될 때,
$$x = f(t), \quad y = g(t)$$
곡선 위의 한 점에서 접선의 기울기는 다음 공식으로 구합니다:

$$\frac{dy}{dx} = \frac{\frac{dy}{dt}}{\frac{dx}{dt}} = \frac{g'(t)}{f'(t)} \quad \left(\text{단, } \frac{dx}{dt} \neq 0\right)$$

이것을 **매개변수 방정식의 미분**이라 합니다.

### 직관과 기하적 의미

매개변수 $t$를 시간으로 생각하면 점 $(x(t), y(t))$는 평면을 움직이는 입자의 궤적입니다. $t$가 조금 변할 때:
- $x$의 변화율: $\frac{dx}{dt}$ (수평 속도)
- $y$의 변화율: $\frac{dy}{dt}$ (연직 속도)

곡선의 기울기는 "수평 변화 대비 연직 변화"이므로, 두 속도의 비 $\frac{dy/dt}{dx/dt}$를 구합니다. 이는 연쇄법칙의 구체적 표현입니다: $\frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx}$의 역수 관계입니다.

### 간단한 예

**단위원의 매개변수 표현:** $x = \cos t$, $y = \sin t$

$$\frac{dy}{dx} = \frac{\frac{d}{dt}(\sin t)}{\frac{d}{dt}(\cos t)} = \frac{\cos t}{-\sin t} = -\cot t$$

$t = \frac{\pi}{4}$일 때: $\frac{dy}{dx} = -\cot\frac{\pi}{4} = -1$

따라서 점 $\left(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right)$에서 접선의 기울기는 $-1$입니다.

(검산: `sp.diff(sp.sin(t), t) / sp.diff(sp.cos(t), t).subs(t, sp.pi/4)` → $-1$)
