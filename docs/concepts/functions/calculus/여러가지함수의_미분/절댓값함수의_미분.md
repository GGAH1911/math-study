# 절댓값함수의 미분

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지_함수의_미분)

## 요약
절댓값 함수는 내부 식이 $0$이 되는 지점에서 그래프가 꺾일 수 있으므로, 구간을 나누어 미분하거나 좌미분계수와 우미분계수를 비교하여 미분 가능성을 판정해야 합니다.

## 본문
함수 $f(x) = |g(x)|$의 미분은 절댓값 내부 식인 $g(x)$의 부호에 따라 구간을 나누어 정의합니다. $g(x) \neq 0$인 지점에서는 $g(x)$가 양수이면 $g'(x)$를, 음수이면 $-g'(x)$를 미분계수로 가집니다. 이를 하나의 식으로 간결하게 표현하면 $g(x) \neq 0$일 때 $\tfrac{d}{dx}|g(x)| = \tfrac{g(x)}{|g(x)|} \cdot g'(x)$가 성립합니다. 반면, $g(x) = 0$인 지점에서는 함수의 그래프가 꺾이는 현상이 발생할 수 있으므로, 해당 지점에서 좌미분계수와 우미분계수가 일치하는지 반드시 확인하여 미분 가능 여부를 판정해야 합니다.

### 직관과 기하적 의미
절댓값 함수의 그래프는 내부 식이 $0$이 되는 영점에서 기울기가 급격히 변하는 특징이 있습니다. 양수 구간에서는 원래 함수 $g(x)$의 모양을 따르지만, 음수 구간에서는 부호가 반전된 $-g(x)$의 모양을 따르기 때문입니다. 이로 인해 영점에서 그래프가 V자 형태로 뾰족하게 꺾이는 '첨점'이 형성될 수 있으며, 이 지점에서는 좌우 미분계수의 부호가 다르거나 크기가 달라 미분이 불가능할 수 있습니다.

### 기본 성질
$f(x) = |2x - 4|$의 경우를 예로 들면, $x > 2$인 구간에서는 $f'(x) = 2$이고 $x < 2$인 구간에서는 $f'(x) = -2$입니다. $x = 2$를 기준으로 좌미분계수와 우미분계수가 서로 다르므로, 이 함수는 $x = 2$에서 미분 불가능합니다.

## 학습 체크
- $g(x) = 0$인 지점에서 $g'(x) = 0$인 경우, 절댓값 함수 $|g(x)|$는 미분 가능한가?
- 절댓값 함수가 특정 지점에서 미분 가능하기 위한 좌미분계수와 우미분계수의 조건은 무엇인가?

## 관련 개념
- **도함수의 활용 심화**: 절댓값 함수가 포함된 함수의 극값이나 그래프의 개형을 파악할 때, 꺾이는 지점에서의 미분 가능성을 판단하는 것이 필수적입니다.
