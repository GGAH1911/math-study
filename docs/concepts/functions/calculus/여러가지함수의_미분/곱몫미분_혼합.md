# 곱몫미분 혼합

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
분수 형태의 식을 미분할 때 분자에 곱의 미분법이 포함된 경우처럼 여러 미분법을 동시에 적용하여 해결합니다.

## 본문
다음 함수를 미분하시오.

$$f(x) = \frac{(x^2+1)(2x-1)}{x+3}$$

### 단계별 풀이
**1단계: 어떤 공식을 사용할지 판단하기**
분자가 두 함수의 곱이고 전체 식이 분수이므로, 몫의 미분법을 사용합니다. 분자를 $u = (x^2+1)(2x-1)$, 분모를 $v = x+3$로 놓겠습니다.

**2단계: 분자의 도함수 구하기 (곱의 미분법)**
$u(x) = (x^2+1)(2x-1)$에 곱의 미분법 $(fg)' = f'g + fg'$를 적용하면 다음과 같습니다.
$$u'(x) = (2x)(2x-1) + (x^2+1)(2) = 4x^2 - 2x + 2x^2 + 2 = 6x^2 - 2x + 2$$

**3단계: 분모의 도함수 구하기**
$v'(x) = 1$입니다.

**4단계: 몫의 미분법 적용**
$$f'(x) = \frac{u'v - uv'}{v^2} = \frac{(6x^2-2x+2)(x+3) - (x^2+1)(2x-1)}{(x+3)^2}$$

**5단계: 분자 전개 및 정리**
- $(6x^2-2x+2)(x+3) = 6x^3 + 16x^2 - 4x + 6$
- $(x^2+1)(2x-1) = 2x^3 - x^2 + 2x - 1$
- 빼기: $6x^3 + 16x^2 - 4x + 6 - 2x^3 + x^2 - 2x + 1 = 4x^3 + 17x^2 - 6x + 7$

### 답과 변형
$$f'(x) = \frac{4x^3 + 17x^2 - 6x + 7}{(x+3)^2}$$

**변형 및 주의사항**
분자를 먼저 전개하여 $f(x) = \frac{2x^3 - x^2 + 2x - 1}{x+3}$ 형태로 만든 후 몫의 미분법을 적용할 수도 있으며, 상황에 따라 이 방법이 더 효율적일 수 있습니다. 또한 분자에 거듭제곱 형태가 포함되어 연쇄법칙이 함께 쓰이는 경우도 있으므로 곱의 미분법, 몫의 미분법, 연쇄법칙을 유기적으로 조합하는 연습이 필요합니다.

## 학습 체크
- 분자의 곱 형태를 미분할 때 곱의 미분법을 정확히 적용할 수 있는가?
- 몫의 미분법을 적용한 후 분자 전개 과정에서 부호 실수를 하지 않는가?
- 복합적인 미분법이 결합된 형태를 보고 어떤 공식을 먼저 적용할지 판단할 수 있는가?

## 관련 개념
- **여러가지 함수의 미분**: 몫의 미분법과 곱의 미분법을 포함하여 다양한 형태의 함수를 미분하는 원리를 다룹니다.
