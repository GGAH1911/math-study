# 삼각함수의 도함수

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지_함수의_미분)

## 요약
삼각함수의 도함수는 미분의 정의인 극한을 통해 도출되며, 사인 함수를 미분하면 코사인 함수가 되는 등 삼각함수 간의 변화율 관계를 나타냅니다.

## 본문
삼각함수의 도함수는 다음과 같이 정의됩니다:
$$\frac{d}{dx}\sin x = \cos x, \quad \frac{d}{dx}\cos x = -\sin x, \quad \frac{d}{dx}\tan x = \sec^2 x$$
여기서 $x$는 라디안 단위의 각도이며, 이 공식들은 미분의 정의인 극한 $\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$를 통해 도출됩니다. 특히 $\sin x$의 도함수가 $\cos x$라는 사실은 삼각함수 미분을 학습하는 데 있어 가장 기초가 되는 핵심 원리입니다.

### 직관과 기하적 의미
단위원 위의 점 $P = (\cos x, \sin x)$를 떠올려봅시다. 각도 $x$가 증가함에 따라 점 $P$는 원 위를 반시계 방향으로 이동합니다. 이때 $y$ 좌표인 $\sin x$가 순간적으로 얼마나 빠르게 변하는지를 나타내는 것이 바로 $(\sin x)' = \cos x$입니다. 기하학적으로 $x = 0$일 때 사인 함수는 가파르게 올라가므로 도함수값이 최대($\cos 0 = 1$)이고, $x = \frac{\pi}{2}$일 때 최댓값에 도달하므로 도함수는 $0$($\cos \frac{\pi}{2} = 0$)이 되며, $x = \pi$일 때는 가파르게 내려가므로 도함수가 음수($\cos \pi = -1$)가 됩니다. 이러한 변화 양상은 코사인 함수의 그래프와 정확히 일치합니다.

### 기본 성질
삼각함수의 미분은 단순한 공식 암기를 넘어 함수 간의 관계를 보여줍니다. 예를 들어 $f(x) = \sin 2x$와 같이 합성된 형태의 함수를 미분할 때는 연쇄법칙을 적용해야 합니다. $f'(x) = 2\cos 2x$가 되며, 특정 지점 $x = \frac{\pi}{12}$에서의 미분계수는 $f'(\frac{\pi}{12}) = 2\cos \frac{\pi}{6} = 2 \cdot \frac{\sqrt{3}}{2} = \sqrt{3}$으로 계산됩니다.

## 학습 체크
- $\sin x$의 도함수가 $\cos x$가 되는 과정을 미분의 정의인 극한 식을 사용하여 증명할 수 있는가?
- 단위원 위에서 점의 움직임과 삼각함수 도함수의 부호 및 크기를 연결하여 설명할 수 있는가?
- 합성된 삼각함수의 미분 시 연쇄법칙을 정확히 적용하여 미분계수를 구할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 삼각함수의 도함수를 통해 함수의 극대, 극소 및 변곡점을 파악하여 복잡한 삼각함수 그래프의 개형을 정밀하게 그릴 수 있습니다.
