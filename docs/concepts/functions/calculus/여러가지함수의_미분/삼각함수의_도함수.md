# 삼각함수의 도함수

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지_함수의_미분)

## 정확한 진술

삼각함수의 도함수는 다음과 같이 정의됩니다:

$$\frac{d}{dx}\sin x = \cos x, \quad \frac{d}{dx}\cos x = -\sin x, \quad \frac{d}{dx}\tan x = \sec^2 x$$

여기서 $x$는 라디안 단위의 각도이며, 이 공식들은 미분의 정의인 극한 $\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$를 통해 도출됩니다. 특히 $\sin x$의 도함수가 $\cos x$라는 것은 삼각함수 미분의 기초가 됩니다.

## 직관과 기하적 의미

단위원 위의 점 $P = (\cos x, \sin x)$를 떠올려봅시다. 각도 $x$가 증가하면서 점 $P$는 반시계방향으로 원 위를 이동합니다. 이때 $y$ 좌표인 $\sin x$가 순간적으로 얼마나 빠르게 변하는지를 나타내는 것이 바로 $(\sin x)' = \cos x$입니다.

기하학적으로, $x = 0$일 때 사인 함수는 가파르게 올라가므로 도함수값은 최대이고($\cos 0 = 1$), $x = \frac{\pi}{2}$일 때 최댓값에 도달하므로 도함수는 0($\cos \frac{\pi}{2} = 0$), $x = \pi$일 때 가파르게 내려가므로 도함수는 음수가 됩니다($\cos \pi = -1$). 이러한 변화가 정확히 코사인 함수의 그래프와 일치합니다.

## 한 줄 예

$f(x) = \sin 2x$의 도함수는 연쇄법칙을 적용하여 $f'(x) = 2\cos 2x$이고, $x = \frac{\pi}{12}$에서의 값은 $f'(\frac{\pi}{12}) = 2\cos \frac{\pi}{6} = 2 \cdot \frac{\sqrt{3}}{2} = \sqrt{3}$입니다.
