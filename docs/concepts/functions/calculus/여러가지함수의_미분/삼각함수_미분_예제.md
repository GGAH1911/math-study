# 삼각함수 미분 예제

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$y=\sin x \cos x$를 미분하여 $\cos 2x$를 도출하는 과정을 학습합니다.

## 본문
다음 함수를 미분하시오.
$$y = \sin x \cos x$$

### 단계별 풀이
**방법 1: 곱의 미분법 적용**
$\sin x$와 $\cos x$의 곱 형태이므로 곱의 미분법 $(uv)' = u'v + uv'$를 사용합니다. $u = \sin x$, $v = \cos x$라 하면 $u' = \cos x$, $v' = -\sin x$이므로 다음과 같이 계산합니다.
$$y' = \cos x \cdot \cos x + \sin x \cdot (-\sin x) = \cos^2 x - \sin^2 x$$
이때 삼각함수의 배각공식 $\cos 2x = \cos^2 x - \sin^2 x$를 적용하면 최종 결과는 $\cos 2x$가 됩니다.

**방법 2: 항등식을 이용한 단순화 후 미분**
삼각함수의 곱을 합으로 바꾸는 공식 $\sin x \cos x = \tfrac{1}{2} \sin 2x$를 사용하여 식을 먼저 정리합니다.
$$y = \frac{1}{2} \sin 2x$$
이제 합성함수의 미분법을 적용합니다. $\sin 2x$를 미분하면 $2\cos 2x$가 되므로 다음과 같습니다.
$$y' = \frac{1}{2} \cdot 2 \cos 2x = \cos 2x$$

### 답과 변형
$$y' = \cos 2x$$
두 방법 모두 동일한 결과를 얻을 수 있습니다. 곱의 미분법은 미분법의 기본 원리를 연습하기에 좋고, 항등식을 이용한 방법은 계산 과정을 단축할 수 있어 실전 시험에서 실수를 줄이는 데 매우 효율적입니다.

## 학습 체크
