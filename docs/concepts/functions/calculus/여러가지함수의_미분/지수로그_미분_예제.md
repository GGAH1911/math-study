# 지수로그 미분 예제

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
지수함수와 로그함수의 곱으로 이루어진 함수의 미분법을 학습합니다.

## 본문
$y=e^x \ln x$를 $x$에 대해 미분하시오.

### 단계별 풀이
이 함수는 지수함수 $e^x$와 로그함수 $\ln x$의 곱 형태이므로 곱의 미분법 $(uv)'=u'v+uv'$을 적용합니다.

먼저 각 성분을 미분하면 다음과 같습니다.
$u=e^x$일 때 $u'=e^x$이며, $v=\ln x$일 때 $v'=\dfrac{1}{x}$입니다.

이를 곱의 미분법 공식에 대입하면 다음과 같습니다.
$$y' = (e^x)' \cdot \ln x + e^x \cdot (\ln x)'$$
$$y' = e^x \ln x + e^x \cdot \frac{1}{x}$$

마지막으로 공통인수인 $e^x$로 묶어 정리하면 최종 도함수를 구할 수 있습니다.
$$y' = e^x\left(\ln x + \frac{1}{x}\right)$$

### 답과 변형
$$y' = e^x\left(\ln x + \frac{1}{x}\right) \quad \text{또는} \quad y' = e^x \ln x + \dfrac{e^x}{x}$$

미분 시 $\ln x$의 미분 결과가 $\dfrac{1}{x}$임을 정확히 인지해야 하며, 곱의 미분법을 적용할 때 각 항을 각각 미분하여 더하는 과정을 주의해야 합니다. 또한 로그함수의 정의에 따라 $x>0$인 범위에서만 미분이 유효합니다.

## 학습 체크
- 곱의 미분법을 사용하여 두 함수의 곱 형태를 정확히 미분할 수 있는가?
- 지수함수와 로그함수의 개별 미분 공식을 혼동 없이 적용할 수 있는가?
- 도함수의 정의역이 원래 함수의 정의역과 일치함을 이해하고 있는가?

## 관련 개념
- **여러가지함수의 미분**: 지수함수, 로그함수, 삼각함수 등 다양한 함수의 미분법을 다루며, 이 예제는 그중 지수와 로그의 곱을 다룹니다.
