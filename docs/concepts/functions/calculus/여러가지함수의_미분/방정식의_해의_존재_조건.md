# 방정식의 해의 존재 조건

## 정확한 진술

연속함수 $f(x)$가 닫힌 구간 $[a, b]$에서 정의되고, $f(a)$와 $f(b)$의 부호가 반대면(즉, $f(a) \cdot f(b) < 0$), 방정식 $f(x) = 0$은 개구간 $(a, b)$ 내에 최소한 하나의 해를 가집니다. 일반적으로 방정식 $f(x) = g(x)$는 $h(x) = f(x) - g(x)$로 변환하여 동일한 조건을 적용할 수 있습니다.

## 직관과 기하적 의미

함수의 그래프를 생각해봅시다. $f(a) > 0$이고 $f(b) < 0$이면, 연속함수는 $x$축을 반드시 지나야 합니다. 이것은 그래프가 끊어지지 않고 한 점에서 다른 점으로 연결되기 때문입니다. 이 원리를 **중간값 정리**라고 부르며, 미분 가능한 함수의 경우 도함수 $f'(x)$의 성질을 조사하면 추가 정보를 얻을 수 있습니다. 예를 들어 $f'(x) > 0$이 항상 성립하면 $f$는 증가함수이므로, 해가 유일함을 알 수 있습니다.

## 예시와 검증

방정식 $x^3 - 5x + 2 = 0$을 생각해봅시다. $f(x) = x^3 - 5x + 2$라 하면, $f(0) = 2 > 0$이고 $f(1) = 1 - 5 + 2 = -2 < 0$입니다. 따라서 $(0, 1)$ 구간에서 해가 존재합니다. 

더 나아가 $f'(x) = 3x^2 - 5$를 분석하면, $f'(x) = 0$일 때 $x = \pm\sqrt{5/3}$이므로, 함수의 극값을 찾아 해의 개수를 판단할 수도 있습니다. (검산: `sympy.solve(x**3 - 5*x + 2, x)`로 모든 해를 확인 가능)

이 방법은 방정식의 정확한 해를 구하기 어려울 때도 **해의 존재성과 개수**를 확인하는 강력한 도구입니다.
