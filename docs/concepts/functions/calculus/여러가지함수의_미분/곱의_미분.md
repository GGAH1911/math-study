# 곱의 미분

> **정리** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
두 함수의 곱의 미분은 각 함수를 번갈아 미분하여 더한 값과 같다. $(fg)' = f'g + fg'$

## 본문
두 함수 $f(x)$와 $g(x)$가 어떤 구간에서 미분가능할 때, 두 함수의 곱 $f(x)g(x)$의 도함수는 $\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$이다. 이 공식은 복잡하게 결합된 함수의 미분을 수행할 때 각 구성 요소를 개별적으로 미분하여 조합하는 방식을 제공한다.

### 증명 스케치
도함수의 정의에 따라 $\lim_{h \to 0} \tfrac{f(x+h)g(x+h) - f(x)g(x)}{h}$를 계산한다. 분자에 $f(x+h)g(x)$를 더하고 빼는 조작을 통해 식을 분리하면 $\tfrac{f(x+h)\{g(x+h) - g(x)\}}{h} + \tfrac{g(x)\{f(x+h) - f(x)\}}{h}$가 된다. 이때 $h \to 0$일 때 $f(x+h)$는 $f(x)$로 수렴하므로, 결과적으로 $f(x)g'(x) + g(x)f'(x)$가 도출된다.

### 의의와 응용
곱의 미분법은 다항함수, 삼각함수, 지수함수 등이 결합된 복잡한 형태의 함수를 미분할 때 필수적인 도구이다. 예를 들어 $y = x^2 \sin x$를 미분하면 $y' = 2x \sin x + x^2 \cos x$가 된다. 이는 몫의 미분법이나 연쇄법칙과 결합되어 함수의 접선의 기울기, 극값 등을 구하는 모든 미분 과정의 기초가 된다.

## 학습 체크

- 두 함수가 곱해진 형태의 식을 보고 각 함수를 각각 미분하여 합하는 과정을 정확히 수행할 수 있는가?

## 관련 개념
- **여러가지함수의 미분**: 곱의 미분법은 삼각함수나 지수함수 등 다양한 함수의 곱으로 이루어진 복잡한 형태를 미분할 때 핵심적인 계산 원리로 작용한다.
