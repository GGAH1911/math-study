# 절댓값과 경우 분석

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지_함수의_미분)

## 정확한 진술

절댓값 함수 $|f(x)|$는 정의역 내 절댓값이 0이 되는 점을 기준으로 **경우를 나누어** 분석합니다. 가장 기본적인 경우는 다음과 같습니다.

$$|x| = \begin{cases} x & (x \geq 0) \\ -x & (x < 0) \end{cases}$$

일반적으로 $|f(x)|$의 도함수를 구할 때, $f(x) = 0$이 되는 점을 경계로 하여 각 구간에서 별도로 미분합니다.

$$|f(x)| = \begin{cases} f(x) & (f(x) \geq 0) \\ -f(x) & (f(x) < 0) \end{cases}$$

따라서 $f(x) \neq 0$인 점에서:
- $f(x) > 0$인 구간에서는 $\frac{d}{dx}|f(x)| = f'(x)$
- $f(x) < 0$인 구간에서는 $\frac{d}{dx}|f(x)| = -f'(x)$

## 직관과 기하적 의미

절댓값을 포함한 함수의 그래프는 일반적으로 **꺾이는 점**(절댓값이 0이 되는 곳)을 가집니다. 이 점에서 좌미분과 우미분이 다를 수 있으므로, 미분 가능성을 조사할 때 경우를 나누어 확인해야 합니다. 기하학적으로는 절댓값이 $x$축 아래의 그래프를 위로 "반사"시키는 효과를 만들어냅니다.

## 한 줄 예

$y = |x - 2|$에서 경우를 나누면, $x \geq 2$일 때 $y = x - 2$이고 $x < 2$일 때 $y = -(x-2) = -x + 2$이므로, 도함수는 $x = 2$를 제외하고 각 구간에서 $1$ 또는 $-1$입니다. 절댓값 함수의 경우 분석은 **구간별로 부호를 판정하는 것**이 핵심입니다.
