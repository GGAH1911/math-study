# 지수함수 미분

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
$(e^x)'=e^x$

## 본문
자연상수 $e$를 밑으로 하는 지수함수 $f(x) = e^x$의 도함수는 자기 자신과 같으며, 모든 실수 $x$에 대해 $\tfrac{d}{dx}e^x = e^x$가 성립합니다. 더 일반적으로 $a > 0$이고 $a \neq 1$인 상수 $a$에 대하여 지수함수 $f(x) = a^x$의 도함수는 $\tfrac{d}{dx}a^x = a^x \ln a$입니다.

### 직관과 기하적 의미
지수함수 $e^x$는 미분했을 때 자기 자신이 나오는 유일한 함수입니다. 이는 $e = \lim_{n \to \infty} \left(1 + \tfrac{1}{n}\right)^n \approx 2.71828\ldots$라는 특별한 값 덕분입니다. 기하학적으로 곡선 $y = e^x$ 위의 임의의 점 $(x, e^x)$에서 접선의 기울기는 해당 점의 함숫값 $e^x$와 정확히 일치합니다. 즉, 순간변화율이 현재의 값과 동일하다는 성질을 가지며, 이는 박테리아 증식이나 방사능 붕괴와 같은 자연계의 지수적 성장 모델을 설명하는 핵심 원리가 됩니다.

### 기본 성질
미분의 정의를 이용하면 $\tfrac{d}{dx}e^x = \lim_{h \to 0} \tfrac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \tfrac{e^h - 1}{h}$로 나타낼 수 있습니다. 이때 자연상수 $e$의 정의에 의해 $\lim_{h \to 0} \tfrac{e^h - 1}{h} = 1$이 되므로 $(e^x)' = e^x$라는 결과가 도출됩니다.

## 학습 체크
- $e^x$를 미분했을 때 왜 자기 자신이 나오는지 극한의 정의를 통해 설명할 수 있는가?
- 밑이 $e$가 아닌 일반적인 지수함수 $a^x$를 미분할 때 $\ln a$가 붙는 이유를 이해하고 있는가?
- 지수함수와 다항함수가 결합된 형태의 미분 계산을 정확히 수행할 수 있는가?

## 관련 개념
- **여러가지 함수의 미분**: 지수함수와 로그함수를 포함하여 다양한 형태의 함수를 미분하는 법을 다루는 단원입니다.
