# 지수함수 미분

> **정의** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)
## 요약
$(e^x)'=e^x$

## 본문

자연상수 $e$를 밑으로 하는 지수함수 $f(x) = e^x$의 도함수는 자기 자신과 같습니다. 즉,
$$\frac{d}{dx}e^x = e^x$$

이는 모든 실수 $x$에 대해 성립합니다. 더 일반적으로, $a > 0$이고 $a \neq 1$일 때 $f(x) = a^x$의 도함수는
$$\frac{d}{dx}a^x = a^x \ln a$$
입니다.

### 직관과 기하적 의미

지수함수 $e^x$는 미분하면 자기 자신이 나오는 유일한 함수입니다. 이는 $e$가 특별한 수이기 때문인데, $e$는 다음 극한으로 정의됩니다:
$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n \approx 2.71828\ldots$$

기하학적으로, 곡선 $y = e^x$ 위의 임의의 점 $(x, e^x)$에서 접선의 기울기는 정확히 그 점의 함수값 $e^x$와 같습니다. 다시 말해 **순간변화율이 현재값과 동일**하다는 뜻으로, 자연 현상의 지수적 성장(박테리아 증식, 방사능 붕괴 등)을 설명하는 이유입니다.

### 증명 스케치

미분의 정의에서:
$$\frac{d}{dx}e^x = \lim_{h \to 0} \frac{e^{x+h} - e^x}{h} = e^x \lim_{h \to 0} \frac{e^h - 1}{h}$$

자연상수 $e$의 정의에 의해 $\displaystyle \lim_{h \to 0} \frac{e^h - 1}{h} = 1$이 성립하므로, 결과적으로 $(e^x)' = e^x$입니다.

### 한 줄 예

$f(x) = 3e^x - 2x^2$일 때, $f'(x) = 3e^x - 4x$입니다.
