### 정확한 진술

함수 부등식의 응용이란 도함수를 활용하여 함수의 극값을 찾거나 두 함수 사이의 대소 관계를 판정하는 기법입니다. 일반적으로 $f'(x) = 0$이 되는 점에서 함수의 증감이 바뀌므로, 도함수의 부호를 조사하면 함수의 극값을 정확히 결정할 수 있습니다. 또한 $f(x) \geq g(x)$를 증명하고 싶을 때, $h(x) = f(x) - g(x)$라 놓고 $h(x)$의 최솟값이 0 이상임을 보이는 방식으로 활용합니다.

### 직관 및 기하적 의미

도함수는 함수의 기울기를 나타내므로, $f'(x)$의 부호 변화를 추적하면 함수가 언제 올라가고 내려가는지 알 수 있습니다. 도함수가 양에서 음으로 바뀌는 점은 극댓값, 음에서 양으로 바뀌는 점은 극솟값입니다. 이를 통해 함수의 그래프를 그리고 최댓값·최솟값을 구간별로 구할 수 있으며, 나아가 두 곡선이 항상 특정한 대소 관계를 유지함을 엄밀하게 증명할 수 있습니다.

### 전형적인 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x-1)(x+1)$입니다. $f'(x) = 0$일 때 $x = -1$ 또는 $x = 1$이고, 부호 조사에 의해 $x = -1$에서 극댓값 $f(-1) = 2$, $x = 1$에서 극솟값 $f(1) = -2$를 얻습니다. 검증: `from sympy import symbols, diff, solve; x = symbols('x'); f = x**3 - 3*x; fp = diff(f, x); print(solve(fp, x))`

### 응용의 핵심 기법

부등식 증명에서는 $f(x) - g(x) \geq 0$을 직접 전개하기 어려울 때, 양변의 차에 대한 도함수를 구해 극솟값이 0 이상임을 보입니다. 예를 들어 $e^x \geq 1 + x$를 증명할 때, $h(x) = e^x - 1 - x$로 놓으면 $h'(x) = e^x - 1$이고, $x = 0$에서 $h'(0) = 0$이며 $x > 0$일 때 $h'(x) > 0$, $x < 0$일 때 $h'(x) < 0$이므로 $h(x)$의 최솟값은 $h(0) = 0$입니다. 따라서 $h(x) \geq 0$이 성립합니다.
