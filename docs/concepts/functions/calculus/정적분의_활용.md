# 정적분의 활용

> **단원** · 미적분 · 선수: [여러가지 적분법](/concepts/여러가지_적분법)

## 학습 목표
- 넓이·부피·곡선의 길이·운동을 정적분으로 다룬다
- 회전체의 부피·표면적을 구한다

## 다룰 정의 / 정리 / 예제

**정의**
- 회전체
- [곡선의 길이](/concepts/곡선의_길이)

**정리**
- 두 곡선 사이 넓이
- [회전체 부피 공식](/concepts/회전체_부피_공식) — $V=\pi\int [f(x)]^2 dx$
- 속도→거리 적분, 가속도→속도 적분

**예제**
- 두 곡선 사이 넓이
- $y=x^2$의 회전체 부피
- 운동 거리 계산
