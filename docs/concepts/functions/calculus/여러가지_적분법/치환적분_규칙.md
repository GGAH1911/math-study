# 치환적분 규칙

> **정리** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
변수 치환을 통해 복잡한 합성함수 형태의 적분을 단순한 형태로 변환하여 계산합니다.

## 본문
$u = g(x)$로 놓을 때, $\int f(g(x)) g'(x) dx = \int f(u) du$가 성립합니다. 이것이 치환적분의 핵심 규칙입니다. 이 규칙이 성립하기 위해서는 함수 $f$와 $g$가 연속이어야 하며, $g$는 미분가능해야 합니다. 또한 $u = g(x)$로 치환할 때 역함수가 존재하거나 적어도 적분 구간 내에서 일대일 대응이어야 합니다.

### 증명 스케치
미적분학의 기본정리와 연쇄 법칙의 역관계를 통해 유도할 수 있습니다. $F'(u) = f(u)$라고 가정하면, 연쇄 법칙에 의해 $\tfrac{d}{dx}[F(g(x))] = F'(g(x)) \cdot g'(x) = f(g(x)) \cdot g'(x)$가 됩니다. 이 식의 양변을 $x$에 대해 적분하면 $\int f(g(x)) g'(x) dx = F(g(x)) + C$가 됩니다. 한편 $\int f(u) du = F(u) + C$이므로, 두 식은 본질적으로 동일한 결과를 나타냅니다. 즉, 복잡한 합성함수 구조를 단순한 변수 형태로 변환하는 것이 이 증명의 핵심 아이디어입니다.

### 의의와 응용
치환적분은 직접 계산하기 까다로운 적분식을 다루기 쉬운 형태로 바꾸어주는 강력한 도구입니다. 예를 들어 $\int 2x \sin(x^2) dx$를 계산할 때, $u = x^2$으로 치환하면 $du = 2x dx$가 되어 $\int \sin(u) du = -\cos(u) + C = -\cos(x^2) + C$라는 간단한 결과를 얻을 수 있습니다. 주로 피적분함수 안에 어떤 함수의 미분 형태인 $g'(x)$가 포함되어 있거나, 합성함수의 구조가 명확할 때 사용하며 지수함수, 로그함수, 삼각함수가 포함된 경우에 매우 효과적입니다.

## 학습 체크
- $u = g(x)$로 치환할 때 $dx$를 $du$에 관한 식으로 올바르게 변환할 수 있는가?
- 피적분함수 내에서 치환할 대상($g(x)$)과 그 미분 형태($g'(x)$)를 정확히 찾아낼 수 있는가?

## 관련 개념
- **여러가지 적분법**: 치환적분을 포함하여 부분적분 등 다양한 적분 기술을 다루는 상위 범주입니다.
