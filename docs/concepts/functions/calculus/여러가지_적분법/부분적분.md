# 부분적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)
## 요약
$\int u dv=uv-\int v du$

## 본문

### 정확한 진술

두 함수 $u(x)$와 $v'(x)$의 곱 형태 적분을 다른 형태로 변환하는 방법입니다. **부분적분 공식**은 다음과 같습니다:

$$\int u \, dv = uv - \int v \, du$$

또는 함수 표기로 쓰면:

$$\int u(x) v'(x) \, dx = u(x)v(x) - \int u'(x) v(x) \, dx$$

여기서 $du = u'(x)dx$, $dv = v'(x)dx$이고, $u$와 $v$는 미분가능한 함수입니다.

### 직관과 유도

부분적분은 곱의 미분법(곱의 법칙) $\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x)$에서 출발합니다. 양변을 적분하면:

$$\int \frac{d}{dx}[u(x)v(x)] \, dx = \int u'(x)v(x) \, dx + \int u(x)v'(x) \, dx$$

좌변을 정리하면 $u(x)v(x) = \int u'(x)v(x) \, dx + \int u(x)v'(x) \, dx$이므로:

$$\int u(x)v'(x) \, dx = u(x)v(x) - \int u'(x)v(x) \, dx$$

즉, **곱셈으로 주어진 복잡한 적분을 더 간단한 형태로 옮기는 역함수의 관계**입니다. 핵심은 $u$와 $dv$를 적절히 선택하여 $\int v \, du$가 원래 적분보다 계산하기 쉬운 형태가 되도록 하는 것입니다.

### 기본 예

$\int x e^x \, dx$를 계산합니다. $u = x$, $dv = e^x dx$로 놓으면 $du = dx$, $v = e^x$이므로:

$$\int x e^x \, dx = xe^x - \int e^x \, dx = xe^x - e^x + C$$

검증: `sympy.integrate(x*sp.exp(x), x)` → $e^x(x-1) + C$ ✓
