# 부분적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
두 함수의 곱으로 이루어진 적분을 미분법의 역과정을 이용하여 더 단순한 형태의 적분으로 변환하는 방법입니다.

## 본문
두 미분 가능한 함수 $u(x)$와 $v'(x)$의 곱 형태 적분을 다른 형태로 변환하는 방법입니다. **부분적분 공식**은 다음과 같습니다:
$$\int u \, dv = uv - \int v \, du$$
또는 함수 표기로 쓰면 다음과 같습니다:
$$\int u(x) v'(x) \, dx = u(x)v(x) - \int u'(x) v(x) \, dx$$
여기서 $du = u'(x)dx$, $dv = v'(x)dx$입니다. 이 방법은 곱의 미분법 $\tfrac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x)$의 양변을 적분하여 유도됩니다. 양변을 적분하면 $u(x)v(x) = \int u'(x)v(x) \, dx + \int u(x)v'(x) \, dx$가 되며, 이를 정리하면 부분적분 공식이 도출됩니다. 즉, 복잡한 곱셈 형태의 적분을 더 계산하기 쉬운 형태의 적분으로 옮기는 과정입니다. 이때 핵심은 $u$와 $dv$를 적절히 선택하여 $\int v \, du$가 원래의 적분보다 계산하기 쉬운 형태가 되도록 만드는 것입니다.

### 직관과 기하적 의미
부분적분은 곱의 미분법을 역으로 적용하는 과정입니다. 두 함수의 곱이 변화하는 양상을 미분법을 통해 분해한 뒤, 이를 다시 적분하여 원래 함수의 곱을 찾아내는 원리를 가집니다.

### 기본 성질
$\int x e^x \, dx$를 계산할 때 $u = x$, $dv = e^x dx$로 설정하면 $du = dx$, $v = e^x$가 됩니다. 이를 공식에 대입하면 $xe^x - \int e^x \, dx = xe^x - e^x + C$라는 결과를 얻을 수 있습니다.

## 학습 체크

- 부분적분 공식을 유도하는 미분법과의 관계를 설명할 수 있는가?

## 관련 개념
- **여러가지 적분법**: 부분적분은 치환적분과 함께 복잡한 형태의 함수를 적분하기 위해 사용하는 핵심적인 기법 중 하나입니다.
