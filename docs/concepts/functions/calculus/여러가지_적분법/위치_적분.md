# 위치 적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
함수 $f(x)$의 부정적분은 미분의 역연산으로서, 미분했을 때 $f(x)$가 되는 원시함수 $F(x)$와 임의의 상수 $C$를 포함하는 함수를 의미한다.

## 본문
함수 $f(x)$의 부정적분(또는 원시함수)은 $F'(x) = f(x)$를 만족하는 함수 $F(x)$를 말하며, 다음과 같이 표기한다:
$$\int f(x)\,dx = F(x) + C$$
여기서 $\int$는 적분 기호, $f(x)$는 피적분함수, $dx$는 적분변수를 나타내며, $C$는 임의의 상수인 적분상수를 의미한다.

### 직관과 기하적 의미
부정적분은 미분의 역연산이다. 즉, 도함수 $f(x)$가 주어졌을 때 이를 미분하여 원래의 함수 $F(x)$를 찾아내는 과정이다. 이때 상수의 도함수는 $0$이므로, $F'(x) = f(x)$를 만족하는 함수가 $F(x)$라면 $F(x) + C$ 역시 동일한 조건을 만족하게 된다. 따라서 부정적분은 유일하지 않으며, 적분상수 $C$의 값에 따라 무수히 많은 해를 갖는다. 기하학적으로 이는 같은 도함수를 갖는 곡선들이 서로 수직 방향으로 평행이동한 관계에 있음을 의미한다.

### 기본 성질
- 멱함수의 적분: $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$ (단, $n \neq -1$)
- 삼각함수의 적분: $\int \sin x\,dx = -\cos x + C$, $\int \cos x\,dx = \sin x + C$
- 지수함수의 적분: $\int e^x\,dx = e^x + C$
- 예시: $\int 3x^2\,dx = x^3 + C$ 이며, 이를 미분하면 $3x^2$이 된다.

## 학습 체크
- $F'(x) = f(x)$를 만족하는 함수를 찾을 때 왜 적분상수 $C$를 반드시 포함해야 하는가?
- 멱함수의 적분 공식에서 지수 $n$이 $-1$인 경우는 왜 별도로 구분하여 생각해야 하는가?
- 부정적분 결과로 얻은 함수를 다시 미분했을 때 원래의 피적분함수가 나오는지 확인하는 방법은 무엇인가?

## 관련 개념
- **도함수의 활용 심화**: 부정적분은 정적분을 계산하기 위한 기초가 되며, 이를 통해 곡선 아래의 넓이, 입체의 부피, 물리적 변화량 등을 계산하는 데 필수적으로 사용된다.
