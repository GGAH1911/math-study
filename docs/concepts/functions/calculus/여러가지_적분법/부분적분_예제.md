# 부분적분 예제

> **예제** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)
## 요약
$\int xe^x dx$

## 본문

### 문제

다음을 계산하시오.
$$\int xe^x \, dx$$

### 단계별 풀이

**1단계: 부분적분 대상 선택**  
$x$와 $e^x$의 곱이므로 부분적분을 적용합니다. 다항식 $x$를 $u$로, 지수함수 $e^x$를 $dv$로 설정하는 것이 표준입니다. (다항식 미분이 단순해지므로)

**2단계: $du$, $v$ 구하기**  
$u = x$일 때 $du = dx$  
$dv = e^x dx$일 때 $v = e^x$

**3단계: 부분적분 공식 적용**  
$$\int u \, dv = uv - \int v \, du$$
를 사용하면:
$$\int xe^x \, dx = x \cdot e^x - \int e^x \, dx$$

**4단계: 남은 적분 계산**  
$\int e^x \, dx = e^x + C$ 이므로:
$$\int xe^x \, dx = xe^x - e^x + C$$

**5단계: 인수분해로 정리**  
$$\int xe^x \, dx = (x-1)e^x + C$$

### 답

$$(x-1)e^x + C$$

(검증: $(d/dx)[(x-1)e^x] = e^x + (x-1)e^x = xe^x$ ✓)

### 변형 및 주의

**미분으로 검증:**  곱의 미분법으로 $(x-1)e^x + C$를 미분하면 $xe^x$가 나오는지 확인하는 것이 좋은 습관입니다.

**$u$, $dv$ 선택의 중요성:**  만약 반대로 $u = e^x$, $dv = x dx$로 잘못 설정하면 $\int v du = \int \frac{x^2}{2} e^x dx$가 되어 더 복잡해집니다. **LIATE 규칙**(Logarithm, Inverse, Algebraic, Trigonometric, Exponential 순서로 $u$ 선택)을 따르면 실수를 줄일 수 있습니다.

**적분상수:**  부정적분이므로 반드시 $+ C$를 붙여야 합니다.
