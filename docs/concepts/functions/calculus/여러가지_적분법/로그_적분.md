# 로그 적분

> **예제** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
부분적분법을 이용하여 로그함수의 적분 $\int \ln x \, dx$를 계산할 수 있습니다.

## 본문
다음 적분을 계산하시오.
$$\int \ln x \, dx$$

### 단계별 풀이
**1단계: 부분적분 공식 적용할 함수 선택**
$\ln x$를 직접 적분하기 어려우므로 부분적분 $\int u \, dv = uv - \int v \, du$를 사용합니다. 로그함수는 다항함수보다 미분이 간단하므로 $u = \ln x$로 설정합니다.

**2단계: $u$, $dv$ 설정 및 미분·적분**
$u = \ln x$이면 $du = \frac{1}{x} dx$이고, $dv = dx$이면 $v = x$입니다. 이렇게 하면 적분 항 $\int v \, du$가 더 간단해집니다.

**3단계: 부분적분 공식 대입**
$$\int \ln x \, dx = x \ln x - \int x \cdot \frac{1}{x} \, dx = x \ln x - \int 1 \, dx$$
우변의 적분이 다항함수가 되어 계산 가능해졌습니다.

**4단계: 남은 적분 계산**
$$\int 1 \, dx = x$$
이므로 최종 결과를 얻습니다.

### 답과 변형
$$\int \ln x \, dx = x \ln x - x + C \quad \text{(단, } x > 0\text{)}$$
또는 $x(\ln x - 1) + C$로 쓸 수도 있습니다.

**검증**: 미분으로 확인하면 $\frac{d}{dx}[x \ln x - x] = \ln x + x \cdot \frac{1}{x} - 1 = \ln x$로 결과가 일치합니다.
**주의사항**: $\ln x$의 정의역에 따라 $x > 0$인 범위에서만 유효합니다.
**유사 문제**: $\int x \ln x \, dx$는 $u = \ln x$, $dv = x \, dx$로 설정하여 $\frac{x^2}{2} \ln x - \frac{x^2}{4} + C$를 얻습니다.

## 학습 체크
- 부분적분법을 적용할 때 어떤 함수를 $u$로 두어야 적분이 쉬워지는지 이해했는가?
- 적분 결과의 정의역이 원래 함수의 정의역과 일치하는지 확인했는가?

## 관련 개념
- **여러가지 적분법**: 부분적분법을 활용하여 로그함수와 같이 직접적인 부정적분이 어려운 함수를 적분하는 방법을 배웁니다.
