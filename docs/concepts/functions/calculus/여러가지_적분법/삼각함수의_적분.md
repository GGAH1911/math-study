# 삼각함수의 적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
삼각함수의 적분은 삼각함수 함수의 미분의 역연산으로, 주기적인 변화를 가진 함수의 누적된 넓이를 구하는 과정입니다.

## 본문
삼각함수의 적분은 기본 삼각함수들의 부정적분, 즉 미분의 역연산을 수행하여 원래의 함수를 찾아내는 과정입니다. 고등학교 미적분 과정에서 다루는 주요 공식은 다음과 같습니다.

$$\int \sin x \, dx = -\cos x + C$$
$$\int \cos x \, dx = \sin x + C$$
$$\int \tan x \, dx = -\ln|\cos x| + C$$
$$\int \cot x \, dx = \ln|\sin x| + C$$

이 공식들은 미분법을 통해 검증할 수 있습니다. 예를 들어 $\tfrac{d}{dx}(-\cos x) = \sin x$이므로 첫 번째 공식이 성립함을 알 수 있습니다. 특히 $\tan x$와 $\cot x$의 적분은 치환적분법을 활용합니다. $\tan x = \tfrac{\sin x}{\cos x}$를 $\cos x = u$로 치환하면 $\int \tfrac{-du}{u} = -\ln|u| + C = -\ln|\cos x| + C$라는 결과를 얻게 됩니다.

### 직관과 기하적 의미
삼각함수의 적분은 주기적으로 진동하는 파동의 변화량을 누적한 결과를 나타냅니다. 기하학적으로는 함수 $y = \sin x$와 같은 곡선 아래의 부호가 있는 넓이를 구하는 것과 같습니다. 이러한 성질 때문에 삼각함수의 적분은 물리학의 진동 운동, 교류 전류의 흐름, 그리고 다양한 파동 현상을 수식화할 때 필수적인 도구로 사용됩니다.

### 기본 성질
- 미분의 역연산 성질을 가지므로, 적분 결과에 미분을 수행하면 원래의 피적분 함수가 되어야 합니다.
- 적분 상수 $C$가 포함되어 함수 그래프의 수직 이동을 나타냅니다.
- 선형성을 가져, 함수의 합이나 상수의 곱에 대해 각각 적분할 수 있습니다.

## 학습 체크
- $\tan x$를 적분할 때 왜 $\ln$ 형태의 결과가 나오는지 치환적분 과정을 통해 설명할 수 있는가?
- $\sin x$를 적분했을 때 부호가 $-\cos x$로 바뀌는 이유를 미분과 연결하여 이해하고 있는가?

## 관련 개념
- **적분**: 삼각함수의 적분은 미분의 역과정을 수행한다는 점에서 적분의 기본 원리를 그대로 따릅니다.
