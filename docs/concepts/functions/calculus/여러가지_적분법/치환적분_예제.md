# 치환적분 예제

> **예제** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
피적분함수 내의 합성함수와 그 미분 형태가 함께 포함된 경우, 변수를 치환하여 적분하기 쉬운 형태로 변환하여 계산합니다.

## 본문
$$\int 2x\cos(x^2)\,dx$$

### 단계별 풀이
**1단계: 피적분함수 분석**
$2x\cos(x^2)$를 보면, $x^2$이라는 합성함수가 안에 있고, $2x$는 그 미분입니다. 이것이 바로 치환적분을 사용해야 할 신호입니다.

**2단계: 치환 설정**
$u = x^2$로 놓으면:
$$\frac{du}{dx} = 2x \quad \Rightarrow \quad du = 2x\,dx$$

**3단계: 적분식 변환**
원래의 적분에서 $2x\,dx$를 $du$로 바꾸면:
$$\int 2x\cos(x^2)\,dx = \int \cos(u)\,du$$

**4단계: 기본 적분 공식 적용**
$$\int \cos(u)\,du = \sin(u) + C$$

**5단계: 역치환**
$u = x^2$를 다시 대입합니다:
$$\sin(u) + C = \sin(x^2) + C$$

검증: $\frac{d}{dx}[\sin(x^2)] = \cos(x^2) \cdot 2x = 2x\cos(x^2)$ ✓

### 답과 변형
**답**
$$\int 2x\cos(x^2)\,dx = \sin(x^2) + C$$

**변형 및 주의사항**
- $\int 2x\sin(x^2)\,dx$는 같은 방법으로 $u = x^2$로 치환하면 $-\cos(x^2) + C$가 됩니다.
- $\int 3x^2 e^{x^3}\,dx$도 $u = x^3$로 치환하면 $e^{x^3} + C$가 됩니다.
- 치환을 선택할 때는 $du$가 이미 적분식에 있는가?를 확인하세요. 여기서는 $du = 2x\,dx$가 정확히 피적분함수에 포함되어 있어서 추가 상수 조정이 불필요했습니다.

## 학습 체크
- 합성함수의 미분 형태가 피적분함수 안에 포함되어 있는지 식을 분해하여 확인할 수 있는가?
- 치환한 변수 $u$에 따른 $du$의 관계를 정확히 도출하여 적분식을 변환할 수 있는가?
- 적분 계산 후 다시 원래의 변수 $x$로 되돌리는 역치환 과정을 수행할 수 있는가?

## 관련 개념
- **여러가지 적분법**: 치환적분은 부분적분과 함께 복잡한 형태의 함수를 적분하기 위해 사용하는 핵심적인 방법입니다.
