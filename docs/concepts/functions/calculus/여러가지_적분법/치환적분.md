# 치환적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)
## 요약
$\int f(g(x))g'(x)dx=\int f(u)du$

## 본문

### 정확한 진술

$u = g(x)$로 놓으면, $du = g'(x)dx$이고,

$$\int f(g(x))g'(x)\,dx = \int f(u)\,du$$

입니다. 즉, 합성함수를 적분할 때 안쪽 함수를 새로운 변수 $u$로 치환하면, 복잡한 적분을 더 간단한 형태로 바꿀 수 있습니다.

### 직관 및 의미

치환적분은 **연쇄법칙(chain rule)의 역과정**입니다. 미분에서 $\frac{d}{dx}[F(g(x))] = F'(g(x)) \cdot g'(x)$라면, 적분에서는 이를 역으로 이용합니다. 

변수를 바꾼다는 것은 함수의 "입력값"을 새로운 변수로 보는 것입니다. 예를 들어 $\int (2x+1)^5 dx$에서 $2x+1$을 하나의 단위로 보면 $(u)^5$ 형태가 되어, 간단한 거듭제곱 적분 공식을 적용할 수 있습니다.

**적분 기호의 의미**: $dx$와 $du$는 단순한 기호가 아니라, 변수 변환 시 미분 관계식 $du = g'(x)dx$를 정확히 반영합니다. 이것이 치환적분이 성립하는 핵심입니다.

### 간단한 예

$\int (2x+1)^5 dx$를 계산하면:
- $u = 2x+1$로 놓으면 $du = 2dx$, 즉 $dx = \frac{1}{2}du$
- $\int u^5 \cdot \frac{1}{2}du = \frac{1}{2} \cdot \frac{u^6}{6} + C = \frac{(2x+1)^6}{12} + C$

(검증: `from sympy import *; x = symbols('x'); integrate((2*x+1)**5, x)`)
