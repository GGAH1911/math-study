# 치환적분

> **정의** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
합성함수의 적분을 수행할 때 안쪽 함수를 새로운 변수로 치환하여 적분하기 쉬운 형태로 변환하는 방법입니다.

## 본문
$u = g(x)$로 놓으면 $du = g'(x)dx$가 성립하며, 이를 이용하면 $\int f(g(x))g'(x)dx = \int f(u)du$로 나타낼 수 있습니다. 즉, 복잡한 합성함수 형태의 피적분 함수를 단순한 형태의 함수로 바꾸어 적분을 수행하는 기법입니다.

### 직관과 기하적 의미
치환적분은 미분의 연쇄법칙을 역으로 적용한 과정입니다. 미분에서 $\tfrac{d}{dx}[F(g(x))] = F'(g(x)) \cdot g'(x)$가 성립하므로, 이를 적분 관점에서 바라보면 합성함수의 미분 구조를 그대로 거꾸로 따라가는 것과 같습니다. 변수를 바꾼다는 것은 함수의 입력값을 새로운 관점에서 바라보는 것을 의미하며, 예를 들어 $\int (2x+1)^5 dx$와 같은 식에서 $2x+1$을 하나의 단위로 묶어 $u$로 치환하면 단순한 거듭제곱 함수의 적분 문제로 변환되어 계산이 매우 간편해집니다. 이때 적분 기호 옆의 $dx$와 $du$는 단순한 문자가 아니라 변수 변환에 따른 미분 관계를 나타내는 핵심적인 요소입니다.

### 기본 성질
$\int (2x+1)^5 dx$를 계산하는 과정을 통해 성질을 이해할 수 있습니다. 먼저 $u = 2x+1$로 치환하면 $du = 2dx$이므로 $dx = \tfrac{1}{2}du$가 됩니다. 이를 원래 식에 대입하면 $\int u^5 \cdot \tfrac{1}{2}du$가 되며, 계산 결과는 $\tfrac{1}{2} \cdot \tfrac{u^6}{6} + C = \tfrac{(2x+1)^6}{12} + C$가 됩니다.

## 학습 체크
- $u$로 치환했을 때 $dx$를 $du$에 관한 식으로 올바르게 변환할 수 있는가?
- 피적분 함수 내에 $g(x)$와 그 미분 형태인 $g'(x)$가 모두 포함되어 있는지 식별할 수 있는가?

## 관련 개념
- **여러가지 적분법**: 치환적분은 부분적분법과 함께 복잡한 형태의 함수를 적분하기 위해 사용하는 핵심적인 도구입니다.
