# 리만합

## 정확한 진술

폐구간 $[a, b]$에서 연속인 함수 $f(x)$에 대해, 구간을 $n$개의 소구간으로 분할하여 각 소구간의 폭을 $\Delta x_i = x_i - x_{i-1}$이라 하고, 각 소구간에서 임의로 선택한 점을 $c_i$라 하면 **리만합**은 다음과 같이 정의됩니다.

$$\sum_{i=1}^{n} f(c_i) \Delta x_i$$

여기서 분할의 최대 소구간 폭 $\|P\| = \max(\Delta x_i) \to 0$일 때 이 합의 극한값이 정적분 $\int_a^b f(x) \, dx$입니다.

## 직관과 기하적 의미

리만합은 곡선 $y = f(x)$ 아래 영역의 넓이를 **직사각형들의 합**으로 근사하는 방법입니다. 각 소구간 $[x_{i-1}, x_i]$에서 높이 $f(c_i)$, 밑변 $\Delta x_i$인 직사각형을 그리면, 이들 직사각형의 넓이 합이 리만합입니다. 소구간을 점점 더 많이 나눌수록(즉, $n \to \infty$) 이 근사는 실제 곡선 아래 넓이에 수렴합니다.

$c_i$를 어떻게 선택하느냐에 따라 좌끝점 리만합, 우끝점 리만합, 중점 리만합 등 다양한 형태가 생기지만, 분할을 충분히 세밀하게 하면 모두 같은 값으로 수렴합니다.

## 간단한 예

$f(x) = x$를 $[0, 1]$에서 2등분하고 우끝점을 택하면: $f(\tfrac{1}{2}) \cdot \tfrac{1}{2} + f(1) \cdot \tfrac{1}{2} = \tfrac{1}{2} \cdot \tfrac{1}{2} + 1 \cdot \tfrac{1}{2} = \tfrac{3}{4}$. 실제 정적분값 $\int_0^1 x \, dx = \tfrac{1}{2}$에 아직 정확하지는 않지만, 분할을 더 세밀하게 하면 $\tfrac{1}{2}$로 수렴합니다.
