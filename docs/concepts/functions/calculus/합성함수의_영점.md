### 정확한 진술

함수 $f$와 $g$에 대해 합성함수 $(f \circ g)(x) = f(g(x))$의 **영점(zero point)**은 $f(g(x)) = 0$을 만족하는 $x$의 값입니다. 

다시 말해, $g(x) = a$일 때 $f(a) = 0$이면, 그 $x$ 값이 합성함수의 영점입니다.

### 직관/기하적 의미

합성함수의 영점을 찾는 과정은 두 단계로 나뉩니다:

1. **외함수의 영점 찾기**: 먼저 $f(\alpha) = 0, f(\beta) = 0, \ldots$를 만족하는 $f$의 모든 영점 $\alpha, \beta, \ldots$를 파악합니다.

2. **역으로 추적하기**: 각 영점에 대해 $g(x) = \alpha$, $g(x) = \beta$, ... 를 풀어서 $x$값을 구합니다.

기하학적으로 생각하면, 곡선 $y = g(x)$와 수평선들 $y = \alpha, y = \beta, \ldots$ (여기서 $f(\alpha) = 0$ 등)이 만나는 점들의 $x$좌표가 합성함수의 영점입니다. 즉, $g$의 치역이 $f$의 영점 집합과 만나는 부분을 찾는 것입니다.

### 한 줄 예

$f(x) = x - 1$, $g(x) = x^2$일 때, $f(g(x)) = x^2 - 1 = 0$의 영점은 $x = 1$ 또는 $x = -1$입니다. ($g(1) = g(-1) = 1$이고 $f(1) = 0$이므로) 확인: `sympy.solve(x**2 - 1, x)` → $[-1, 1]$
