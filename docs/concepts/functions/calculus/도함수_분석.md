### 정확한 진술

도함수 분석이란 도함수 $f'(x)$의 부호와 값으로부터 원함수 $f(x)$의 증감, 극값, 그래프의 개형을 파악하는 과정입니다. 즉, $f'(x) > 0$인 구간에서 $f(x)$는 증가하고, $f'(x) < 0$인 구간에서 감소하며, $f'(x) = 0$인 점은 극값 또는 변곡점의 후보가 됩니다.

### 직관/기하적 의미

기하적으로 도함수는 각 점에서의 접선 기울기입니다. 접선이 오른쪽 위로 향하면($f'(x) > 0$) 함수는 올라가고, 오른쪽 아래로 향하면($f'(x) < 0$) 함수는 내려갑니다. $f'(x) = 0$인 점은 접선이 수평인 곳으로, 함수가 극대 또는 극소를 가지거나 정체할 가능성이 있습니다. 도함수 분석은 이 기울기 정보를 체계적으로 정리하여 함수의 전체 모양을 그려내는 작업입니다.

### 한 줄 예

$f(x) = x^3 - 3x$의 도함수 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$를 분석하면, $x < -1$과 $x > 1$에서 증가하고 $-1 < x < 1$에서 감소하므로, $x = -1$에서 극대값 2, $x = 1$에서 극소값 -2를 가집니다. (`sympy.solve(3*x**2 - 3, x)` → $\{-1, 1\}$)
