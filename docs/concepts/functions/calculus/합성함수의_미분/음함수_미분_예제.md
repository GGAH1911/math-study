# 음함수 미분 예제

> **예제** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
$x^2+y^2=1$의 접선

## 본문 (학습 시 채워짐)

### 문제

원 $x^2+y^2=1$ 위의 점 $(a, b)$에서의 접선의 방정식을 구하시오. (단, $a^2+b^2=1$이고 $b \neq 0$)

### 단계별 풀이

**1단계: 음함수 미분**

주어진 원의 방정식 $x^2+y^2=1$의 양변을 $x$에 대해 미분합니다. $y$는 $x$의 함수이므로 연쇄법칙을 적용합니다:

$$2x + 2y\frac{dy}{dx} = 0$$

**2단계: 도함수 정리**

위 식을 정리하면:

$$\frac{dy}{dx} = -\frac{x}{y}$$

**3단계: 점에서의 기울기**

점 $(a, b)$에서의 접선의 기울기는:

$$m = -\frac{a}{b}$$

**4단계: 접선의 방정식**

점-기울기 형태로 접선의 방정식을 세웁니다:

$$y - b = -\frac{a}{b}(x-a)$$

양변에 $b$를 곱하고 정리하면:

$$by - b^2 = -ax + a^2$$
$$ax + by = a^2 + b^2$$

$a^2 + b^2 = 1$이므로:

$$ax + by = 1$$

### 답

점 $(a, b)$에서의 접선의 방정식은 $\boxed{ax + by = 1}$입니다.

### 변형/주의

**구체적 예**: 점 $\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$에서의 접선은 $\frac{1}{2}x + \frac{\sqrt{3}}{2}y = 1$이며, 정리하면 $x + \sqrt{3}y = 2$입니다. 검증: `sp.simplify((sp.Rational(1,2))**2 + (sp.sqrt(3)/2)**2)` → 1 ✓

**일반화**: 원 $x^2+y^2=r^2$ 위의 점 $(a, b)$에서의 접선은 $ax + by = r^2$입니다.

**기하학적 의미**: 접선의 법선벡터는 $(a, b)$인데, 이는 원의 중심에서 점 $(a, b)$로의 반지름 방향과 같습니다. 따라서 **접선은 항상 반지름에 수직**입니다.
