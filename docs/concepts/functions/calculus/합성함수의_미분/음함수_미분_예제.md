# 음함수 미분 예제

> **예제** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
원 $x^2+y^2=1$ 위의 점 $(a, b)$에서의 접선의 방정식을 음함수 미분법을 이용하여 구합니다.

## 본문
원 $x^2+y^2=1$ 위의 점 $(a, b)$에서의 접선의 방정식을 구하시오. (단, $a^2+b^2=1$이고 $b \neq 0$)

### 단계별 풀이
**1단계: 음함수 미분**
주어진 원의 방정식 $x^2+y^2=1$의 양변을 $x$에 대해 미분합니다. 이때 $y$를 $x$에 대한 함수로 보고 연쇄법칙을 적용하면 다음과 같습니다.
$$2x + 2y\frac{dy}{dx} = 0$$

**2단계: 도함수 정리**
위 식을 $\frac{dy}{dx}$에 관하여 정리하면 접선의 기울기를 구할 수 있습니다.
$$\frac{dy}{dx} = -\frac{x}{y}$$

**3단계: 점에서의 기울기**
구한 도함수에 점 $(a, b)$를 대 substituted 하면 접선의 기울기 $m$을 얻습니다.
$$m = -\frac{a}{b}$$

**4단계: 접선의 방정식**
기울기가 $-\frac{a}{b}$이고 점 $(a, b)$를 지나는 직선의 방정식은 다음과 같습니다.
$$y - b = -\frac{a}{b}(x-a)$$
양변에 $b$를 곱하여 정리하면 $by - b^2 = -ax + a^2$이 되며, 이를 이항하면 $ax + by = a^2 + b^2$이 됩니다. 문제의 조건에서 $a^2 + b^2 = 1$이므로 최종 식은 다음과 같습니다.
$$ax + by = 1$$

### 답과 변형
**답**: $\boxed{ax + by = 1}$

**변형 및 일반화**
- **구체적 예시**: 점 $\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$에서의 접선은 $\frac{1}{2}x + \frac{\sqrt{3}}{2}y = 1$이며, 이를 정리하면 $x + \sqrt{3}y = 2$가 됩니다.
- **일반화**: 반지름이 $r$인 원 $x^2+y^2=r^2$ 위의 점 $(a, b)$에서의 접선은 $ax + by = r^2$입니다.
- **기하학적 의미**: 접선의 법선벡터는 $(a, b)$로, 이는 원의 중심에서 점 $(a, b)$를 향하는 반지름 방향과 일치합니다. 즉, 접선은 항상 반지름과 수직을 이룹니다.

## 학습 체크
- 음함수 미분 시 $y$를 $x$의 함수로 간주하여 연쇄법칙을 정확히 적용할 수 있는가?
- 구한 도함수를 이용하여 접선의 기울기를 구하고 직선의 방정식으로 나타낼 수 있는가?
- 원의 방정식 일반형에서 접선의 방정식을 유도할 수 있는가?

## 관련 개념
- **합성함수의 미분**: 음함수 미분은 $y$를 $x$에 대한 함수로 보고 연쇄법칙을 적용하는 과정이므로 합성함수의 미분 원리가 핵심적으로 사용됩니다.
