# 매개변수곡선

> **정의** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분_(연쇄법칙))

## 요약
실수 변수 $t$를 매개변수로 사용하여 평면 위의 점 $(x, y)$를 나타내는 곡선입니다.

## 본문
매개변수곡선(parametric curve)은 실수 변수 $t$(매개변수, parameter)를 이용하여 다음과 같이 표현되는 곡선입니다:
$$x = f(t), \quad y = g(t) \quad (a \leq t \leq b)$$
여기서 $f(t)$와 $g(t)$는 폐구간 $[a, b]$에서 정의된 함수이며, 각 $t$ 값에 대해 평면 위의 한 점 $(x, y)$가 결정됩니다. 이를 곡선 $C$ 위의 점이라 합니다.

### 직관과 기하적 의미
일반적으로 우리는 곡선을 $y = f(x)$ 형태로 표현하지만, 매개변수곡선은 시간을 나타내는 변수 $t$를 도입하여 곡선을 그려나갑니다. 마치 물체가 시간에 따라 움직이는 궤적을 기록하는 것과 같습니다. 이 방식은 원이나 타원 같은 폐곡선을 표현할 때 매우 유용하며, 한 $x$ 값에 여러 $y$ 값이 대응되는 곡선도 하나의 식으로 나타낼 수 있습니다. 또한 곡선의 방향성을 명확히 보여주며, 속도나 가속도 같은 물리량을 미분으로 계산하기에 매우 적합합니다. 예를 들어 원 $x^2 + y^2 = 1$은 $y = \pm\sqrt{1-x^2}$처럼 함수를 나누어 써야 하지만, 매개변수를 이용하면 $x = \cos t, y = \sin t$ ($0 \leq t \leq 2\pi$)로 간단히 표현됩니다.

### 기본 성질
- 한 $x$ 값에 대해 여러 개의 $y$ 값이 대응될 수 있어 함수가 아닌 곡선도 표현 가능합니다.
- 매개변수 $t$의 변화에 따라 곡선이 그려지는 방향(orientation)을 정의할 수 있습니다.
- $x = 2\cos t, y = 3\sin t$ ($0 \leq t \leq 2\pi$)와 같이 타원의 방정식 등을 효율적으로 나타냅니다.

## 학습 체크
- 매개변수 $t$의 범위가 곡선의 모양과 길이에 어떤 영향을 미치는지 이해하고 있는가?
- 주어진 매개변수 방정식을 이용하여 $x$와 $y$의 관계식을 유도할 수 있는가?

## 관련 개념
- **여러가지함수의 미분**: 매개변수곡선의 접선의 기울기를 구하기 위해 연쇄법칙을 활용하여 $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$를 계산하는 과정이 연결됩니다.
