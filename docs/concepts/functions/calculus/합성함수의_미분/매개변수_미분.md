# 매개변수 미분

> **정의** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
매개변수 $t$로 표현된 곡선에서 $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$ 공식을 이용하여 도함수를 구하는 방법입니다.

## 본문
곡선이 매개변수 $t$에 대하여 $x = f(t)$, $y = g(t)$와 같이 주어졌을 때, $y$를 $x$에 대한 함수로 직접 나타내기 어려운 경우 매개변수 미분을 사용하여 $\frac{dy}{dx}$를 구할 수 있습니다. 이때 도함수는 $\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)}$ (단, $f'(t) \neq 0$)로 계산합니다. 예를 들어, 원을 나타내는 매개변수 방정식 $x = \cos t$, $y = \sin t$에서 $\frac{dx}{dt} = -\sin t$, $\frac{dy}{dt} = \cos t$이므로, $\frac{dy}{dx} = \frac{\cos t}{-\sin t} = -\cot t$가 됩니다. 따라서 $t = \frac{\pi}{4}$일 때 접선의 기울기는 $-1$임을 알 수 있습니다.

### 직관과 기하적 의미
매개변수 방정식에서 $x$와 $y$는 모두 매개변수 $t$에 의존하며, 이때 $\frac{dy}{dx}$를 구하는 과정은 연쇄법칙을 적용하는 것과 같습니다. 물리적으로 $\frac{dx}{dt}$와 $\frac{dy}{dt}$는 각각 $t$ 시점에서 $x$와 $y$의 순간변화율을 의미하며, 이 두 변화율의 비율이 곡선 위의 한 점에서의 접선의 기울기가 됩니다.

### 기본 성질
매개변수 미분은 $y$를 $x$에 대한 함수로 명시적으로 나타낼 수 없는 복잡한 곡선에서도 미분계수를 쉽게 구할 수 있게 해줍니다. 다만, 분모인 $\frac{dx}{dt}$가 $0$이 되지 않아야 미분계수가 정의됩니다.

## 학습 체크
- 매개변수 방정식이 주어졌을 때 각 변수를 $t$로 미분하여 비율로 나타낼 수 있는가?
- 분모가 $0$이 되는 지점에서 미분계수가 정의되지 않음을 이해하고 있는가?
- 매개변수 미분법을 활용하여 특정 지점에서의 접선의 기울기를 구할 수 있는가?

## 관련 개념
- **합성함수의 미분**: 매개변수 미분은 $x$와 $y$가 공통된 변수 $t$를 매개로 연결되어 있다는 점에서 연쇄법칙을 통한 합성함수의 미분 원리를 기반으로 합니다.
