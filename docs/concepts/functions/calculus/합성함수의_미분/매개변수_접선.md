# 매개변수 접선

> **예제** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
매개변수 방정식으로 주어진 곡선 위의 한 점에서의 접선의 방정식은 각 매개변수를 매개변수에 대해 미분한 값의 비율을 이용하여 기울기를 구함으로써 구할 수 있습니다.

## 본문
매개변수 방정식 $x = \cos t, y = \sin t$로 나타낸 곡선(단위원) 위의 점 $t = \tfrac{\pi}{4}$에서의 접선의 방정식을 구하시오.

### 단계별 풀이
**1단계: 주어진 점의 좌표를 구한다**
$t = \tfrac{\pi}{4}$를 대입하여 곡선 위의 점을 찾습니다.
$$x = \cos \frac{\pi}{4} = \frac{\sqrt{2}}{2}, \quad y = \sin \frac{\pi}{4} = \frac{\sqrt{2}}{2}$$
따라서 점은 $\left(\tfrac{\sqrt{2}}{2}, \tfrac{\sqrt{2}}{2}\right)$입니다.

**2단계: 각 매개변수를 $t$에 대해 미분한다**
연쇄법칙을 적용하기 위해 $\tfrac{dx}{dt}$와 $\tfrac{dy}{dt}$를 구합니다.
$$\frac{dx}{dt} = -\sin t, \quad \frac{dy}{dt} = \cos t$$

**3단계: $t = \tfrac{\pi}{4}$에서의 미분값을 계산한다**
구한 도함수에 $t = \tfrac{\pi}{4}$를 대입합니다.
$$\frac{dx}{dt}\bigg|_{t=\pi/4} = -\sin \frac{\pi}{4} = -\frac{\sqrt{2}}{2}, \quad \frac{dy}{dt}\bigg|_{t=\pi/4} = \cos \frac{\pi}{4} = \frac{\sqrt{2}}{2}$$

**4단계: 접선의 기울기를 구한다**
매개변수 미분법 $\tfrac{dy}{dx} = \tfrac{dy/dt}{dx/dt}$ (단, $\tfrac{dx}{dt} \neq 0$)를 이용합니다.
$$\frac{dy}{dx}\bigg|_{t=\pi/4} = \frac{\sqrt{2}/2}{-\sqrt{2}/2} = -1$$

**5단계: 접선의 방정식을 구한다**
점 $\left(\tfrac{\sqrt{2}}{2}, \tfrac{\sqrt{2}}{2}\right)$를 지나고 기울기가 $-1$인 직선의 방정식을 세웁니다.
$$y - \frac{\sqrt{2}}{2} = -1 \cdot \left(x - \frac{\sqrt{2}}{2}\right) \implies y = -x + \sqrt{2}$$

### 답과 변형
**답:** $y = -x + \sqrt{2}$ (또는 $x + y = \sqrt{2}$)

**변형:** $t = \tfrac{\pi}{3}$와 같이 다른 매개변수 값을 대입하더라도 동일한 과정을 거쳐 접선을 구할 수 있습니다.

**주의:** $\tfrac{dy}{dx} = \tfrac{dy/dt}{dx/dt}$ 공식은 $\tfrac{dx}{dt} \neq 0$인 경우에만 유효합니다.

## 학습 체크
- 매개변수 미분 시 분모인 $\tfrac{dx}{dt}$가 $0$이 되는 지점에서는 어떤 현상이 발생하는가?
- 접점의 좌표를 구할 때 $t$의 값을 $x$와 $y$에 각각 대입하는 과정을 정확히 수행하였는가?

## 관련 개념
- **합성함수의 미분**: 매개변수 미분은 변수 $x$와 $y$가 제3의 변수 $t$로 연결된 합성함수의 구조를 가지므로 연쇄법칙을 통해 도함수를 구합니다.
