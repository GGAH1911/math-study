# 여러가지 함수의 미분

> **단원** · 미적분 · 선수: [미분](/concepts/미분) / [여러가지함수의 극한](/concepts/여러가지함수의_극한)

## 학습 목표
- 지수·로그·삼각함수의 도함수를 구한다
- 몫의 미분법을 활용한다

## 다룰 정의 / 정리 / 예제

**정의**
- $e^x$의 도함수
- $\ln x$의 도함수
- 삼각함수의 도함수

**정리**
- $(e^x)'=e^x$, $(\ln x)'=1/x$
- $(\sin x)'=\cos x$, $(\cos x)'=-\sin x$
- [몫의 미분](/concepts/몫의_미분) — $(f/g)'=(f'g-fg')/g^2$

**예제**
- 지수·로그함수 미분
- [삼각함수 미분 예제](/concepts/삼각함수_미분_예제)
- 곱·몫 미분 계산
