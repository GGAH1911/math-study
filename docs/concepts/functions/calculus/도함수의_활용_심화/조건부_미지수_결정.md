# 조건부 미지수 결정

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
함수가 만족해야 하는 기하학적 조건들을 도함수와 함숫값에 관한 방정식으로 변환하여 미지수를 찾아내는 과정입니다.

## 본문
조건부 미지수 결정이란 함수나 곡선이 만족해야 하는 조건들(극값, 변곡점, 지나는 점, 기울기 조건 등)로부터 그 함수에 포함된 미지수(상수)들을 구하는 과정입니다. 예를 들어 $f(x) = ax^3 + bx^2 + cx + d$ 형태의 함수에서 "$x=2$에서 극댓값을 가진다" 또는 "$f(1)=3$이고 $f'(2)=0$"과 같은 조건들을 이용해 $a, b, c, d$를 결정하는 것을 의미합니다.

### 직관과 기하적 의미
함수의 도형적 특징인 극값의 위치, 증감 변화, 변곡점 등은 그 함수의 도함수를 통해 드러납니다. 극값 조건 $f'(x_0) = 0$, 극값의 부호 변화, 변곡점 조건 $f''(x_0) = 0$과 같은 도함수 정보를 식으로 세우면 미지수에 대한 연립방정식이 만들어집니다. 즉, 주어진 기하학적 조건들은 대수적 제약으로 변환되어 함수를 유일하게 결정할 수 있게 해줍니다.

### 기본 성질
조건부 미지수 결정의 핵심은 문제의 조건을 식으로 변환하는 것입니다. 먼저 극값, 변곡점, 곡선이 지나는 점 등 문제 조건을 해석하여 $f'(x) = 0$, $f(x_0) = k$, $f''(x_0) = 0$과 같은 식을 구성해야 합니다. 이후 미지수의 개수만큼 독립적인 식이 확보되면 연립방정식을 풀어 미지수를 결정합니다.

예를 들어 $f(x) = x^3 + ax^2 + bx$에서 "$x=1$에서 극솟값 $-1$을 가진다"는 조건이 주어지면, $f'(1) = 3 + 2a + b = 0$과 $f(1) = 1 + a + b = -1$이라는 두 식을 세워 $a = 3, b = -9$를 구할 수 있습니다.

## 학습 체크
- 주어진 조건이 함숫값($f(x)$)에 관한 것인지, 미분계수($f'(x)$)에 관한 것인지 구분하여 식을 세웠는가?
- 미지수의 개수와 도출된 독립적인 방정식의 개수가 일치하는가?
- 극값 조건에서 도함수가 $0$이 되는 것뿐만 아니라, 전후 부호 변화(증감 변화)를 고려해야 하는 상황은 없는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 그래프 개형을 추론하거나 극값, 변곡점의 위치를 파악할 때 미지수를 결정하는 기초가 됩니다.
