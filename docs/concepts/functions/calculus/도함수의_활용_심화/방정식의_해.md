# 방정식의 해

## 정확한 진술

방정식 $f(x) = 0$의 **해** (또는 **근**)는 이 등식을 성립하게 하는 모든 $x$값입니다. 예를 들어 $x^2 - 5x + 6 = 0$의 해는 $x = 2, 3$입니다. 일반적으로 방정식이 몇 개의 해를 가지는지, 그리고 그 위치가 어디인지는 함수의 성질과 밀접한 관계가 있습니다.

## 직관적 의미

함수 $y = f(x)$의 그래프가 **$x$축과 만나는 점의 $x$좌표**가 곧 방정식 $f(x) = 0$의 해입니다. 도함수를 활용하면 함수의 극값(극대·극소)과 증감 구간을 파악하여 방정식이 실근을 몇 개 가지는지, 어느 구간에 있는지 **미리 예측**할 수 있습니다. 예를 들어, $f'(x) = 0$인 점에서 함수가 극값을 가지므로, 극댓값과 극솟값의 부호를 조사하면 그 사이에 해가 있는지 판단할 수 있습니다.

## 구체적 예

방정식 $f(x) = x^3 - 3x + 1 = 0$을 생각해봅시다.

먼저 도함수를 구하면:
$$f'(x) = 3x^2 - 3 = 3(x^2 - 1)$$

$f'(x) = 0$일 때 $x = -1$ 또는 $x = 1$입니다. 극값을 계산하면:
- $f(-1) = -1 + 3 + 1 = 3 > 0$ (극댓값)
- $f(1) = 1 - 3 + 1 = -1 < 0$ (극솟값)

극댓값이 양수, 극솟값이 음수이므로 함수는 $x < -1$, $-1 < x < 1$, $x > 1$의 세 구간에서 각각 한 번씩 $x$축을 지나갑니다. 따라서 이 방정식은 **3개의 실근**을 가집니다.

```
(sympy.solve(x**3 - 3*x + 1, x) 결과: 세 실근이 약 -1.879, 0.347, 1.532)
```

## 주의

- **중근**: 해가 중복되면 서로 다른 해로 세지 않습니다. 예: $(x-1)^2 = 0$은 해가 $x = 1$ (중근)입니다.
- **허근**: 실계수 방정식도 복소수 범위에서는 허근을 가질 수 있습니다. 고등학교 과정에서는 보통 실근만 다룹니다.
