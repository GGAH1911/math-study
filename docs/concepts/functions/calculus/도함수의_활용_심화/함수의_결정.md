# 함수의 결정

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
주어진 도함수와 초기 조건을 이용하여 원함수를 유일하게 찾아내는 과정입니다.

## 본문
함수의 결정이란 주어진 도함수 $f'(x)$와 함수의 한 점에서의 함숫값과 같은 초기 조건으로부터 원함수 $f(x)$를 유일하게 결정하는 과정을 의미합니다. 이를 수식으로 나타내면 다음과 같습니다.
$$\begin{cases} f'(x) = g(x) \\ f(a) = b \end{cases}$$
위 조건이 주어졌을 때, 부정적분을 통해 얻은 일반해 $f(x) = F(x) + C$에서 초기 조건 $f(a) = b$를 만족하는 상수 $C$를 찾아냄으로써 단 하나의 함수를 확정할 수 있습니다.

### 직관과 기하적 의미
도함수 $f'(x)$는 함수 $f(x)$의 각 점에서의 기울기 정보를 담고 있습니다. 즉, 도함수는 함수의 전체적인 형태를 결정하는 역할을 합니다. 하지만 도함수만으로는 함수가 좌표평면 상에서 수직 방향으로 얼마나 이동해 있는지 알 수 없으므로, 함수를 유일하게 확정하기 위해서는 함수가 지나는 특정 점의 위치를 알려주는 초기 조건이 반드시 필요합니다. 기하학적으로 보면 도함수는 함수의 모양을, 초기 조건은 함수의 위치를 결정합니다.

### 기본 성질
초기 조건이 주어지지 않을 경우, 원함수는 상수 $C$의 값에 따라 무수히 많은 함수족을 형성하며 유일하게 결정되지 않습니다. 따라서 함수를 하나로 확정하기 위해서는 반드시 하나의 점에서의 함숫값과 같은 추가적인 정보가 필요합니다.

## 학습 체크
- 도함수 $f'(x)$만 주어졌을 때 원함수가 유일하게 결정되지 않는 이유는 무엇인가요?
- 초기 조건 $f(a)=b$가 주어졌을 때, 부정적분으로 구한 식에서 상수 $C$를 어떻게 결정하나요?

## 관련 개념
- **도함수의 활용 심화**: 도함수를 통해 함수의 증가와 감소, 극값을 파악하여 함수의 전체적인 개형을 추론하는 과정에서 함수의 결정 원리가 기초가 됩니다.
