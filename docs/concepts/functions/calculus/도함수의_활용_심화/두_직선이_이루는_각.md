# 두 직선이 이루는 각

## 정확한 진술

두 직선이 이루는 각이란, 두 직선을 교점에서 만났을 때 형성되는 네 개의 각 중에서 **0°보다 크고 90°보다 작거나 같은 각**을 의미합니다. 기호로는 $\theta$라고 나타내며, $0 < \theta \le 90°$ (또는 $0 < \theta \le \frac{\pi}{2}$)의 범위에 있습니다.

두 직선의 **기울기**가 각각 $m_1$, $m_2$일 때, 이루는 각 $\theta$는 다음 공식으로 구합니다:

$$\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right|$$

또는 두 직선의 **방향벡터**가 각각 $\vec{v_1} = (a_1, b_1)$, $\vec{v_2} = (a_2, b_2)$일 때:

$$\cos\theta = \frac{|\vec{v_1} \cdot \vec{v_2}|}{|\vec{v_1}| \cdot |\vec{v_2}|}$$

## 직관과 기하적 의미

두 직선이 평면에서 만날 때 형성되는 네 개의 각은 대각의 관계로 같은 크기를 가집니다. 따라서 "두 직선이 이루는 각"은 **가장 작은 양의 각**을 선택한 것으로, 항상 **예각 또는 직각**에 해당합니다. 이렇게 정의하는 이유는 두 직선의 상대적 위치를 유일하게 나타내기 위함입니다.

만약 두 직선이 수직이면 $\theta = 90°$이고, 이때 $m_1 \cdot m_2 = -1$입니다.

## 한 줄 예

직선 $y = 2x + 1$과 $y = -\frac{1}{2}x + 3$이 이루는 각은 $\tan\theta = \left|\frac{2-(-\frac{1}{2})}{1 + 2 \cdot (-\frac{1}{2})}\right| = \left|\frac{\frac{5}{2}}{0}\right|$ → 분모가 0이므로 $\theta = 90°$ (수직)

`import math; m1, m2 = 2, -1/2; tan_theta = abs((m1-m2)/(1+m1*m2)) if 1+m1*m2 != 0 else float('inf'); theta_deg = math.degrees(math.atan(tan_theta)) if tan_theta != float('inf') else 90; print(theta_deg)` → 90.0
