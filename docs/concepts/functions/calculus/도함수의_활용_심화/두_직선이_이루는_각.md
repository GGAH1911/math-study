# 두 직선이 이루는 각

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
두 직선이 교차할 때 형성되는 네 개의 각 중 $0 < \theta \le 90^\circ$ 범위를 만족하는 각을 의미합니다.

## 본문
두 직선이 교점에서 만날 때 형성되는 네 개의 각 중에서 $0^\circ$보다 크고 $90^\circ$보다 작거나 같은 각을 두 직선이 이루는 각이라고 하며, 기호로는 $\theta$로 나타냅니다. 이때 각의 범위는 $0 < \theta \le 90^\circ$ (또는 $0 < \theta \le \frac{\pi}{2}$)입니다. 두 직선의 기울기가 각각 $m_1, m_2$일 때, 이루는 각 $\theta$는 $\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right|$ 공식을 통해 구할 수 있습니다. 만약 두 직선의 방향벡터가 각각 $\vec{v_1} = (a_1, b_1), \vec{v_2} = (a_2, b_2)$라면, $\cos\theta = \frac{|\vec{v_1} \cdot \vec{v_2}|}{|\vec{v_1}| \cdot |\vec{v_2}|}$를 이용하여 구할 수도 있습니다.

### 직관과 기하적 의미
두 직선이 평면에서 만날 때 발생하는 네 개의 각은 대각의 관계에 의해 서로 크기가 같습니다. 이 중 가장 작은 양의 각을 선택하여 정의함으로써, 두 직선의 상대적 위치를 예각 또는 직각의 형태로 유일하게 나타낼 수 있습니다.

### 기본 성질
두 직선이 서로 수직인 경우 이루는 각 $\theta = 90^\circ$이며, 이때 두 기울기의 곱 $m_1 \cdot m_2 = -1$이 성립합니다.

## 학습 체크
- 두 직선의 기울기 곱이 $-1$일 때, 왜 $\tan\theta$의 분모가 $0$이 되는지 기하학적으로 설명할 수 있는가?
- 방향벡터를 이용하여 $\cos\theta$를 구할 때, 왜 절댓값 기호를 사용하여 각을 $90^\circ$ 이하로 제한하는가?

## 관련 개념
- **도함수의 활용 심화**: 곡선 위의 한 점에서의 접선과 다른 접선이 이루는 각을 구할 때, 각 접선의 기울기를 이용하여 두 직선이 이루는 각의 원리를 적용합니다.
