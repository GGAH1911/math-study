# 매개변수 곡선의 접선

## 정확한 진술

매개변수 곡선 $x = x(t)$, $y = y(t)$ (단, $a \le t \le b$)가 있을 때, 점 $(x(t_0), y(t_0))$에서의 **접선의 기울기**는 다음과 같습니다.

$$\frac{dy}{dx}\bigg|_{t=t_0} = \frac{\frac{dy}{dt}\bigg|_{t=t_0}}{\frac{dx}{dt}\bigg|_{t=t_0}}$$

(단, $\frac{dx}{dt}\bigg|_{t=t_0} \neq 0$)

이 기울기를 이용하면 점 $(x(t_0), y(t_0))$에서의 **접선의 방정식**은 다음과 같습니다.

$$y - y(t_0) = \frac{dy/dt|_{t=t_0}}{dx/dt|_{t=t_0}} \left( x - x(t_0) \right)$$

## 직관/기하적 의미

매개변수 곡선에서 $t$는 시간처럼 생각할 수 있습니다. $t$가 증가하면서 점 $(x(t), y(t))$는 평면 위의 궤적을 따라갑니다. 이때 $\frac{dx}{dt}$는 $x$ 방향 속도, $\frac{dy}{dt}$는 $y$ 방향 속도입니다. 따라서 두 속도의 비 $\frac{dy/dt}{dx/dt}$는 곡선의 **순간적인 기울기**를 나타냅니다.

접선은 그 점에서 곡선이 진행하는 방향을 나타냅니다. 매개변수로 표현된 곡선은 일반적인 함수 $y = f(x)$ 형태가 아닐 수 있으므로(예: 원, 사이클로이드), 매개변수 미분을 이용해 기울기를 구하는 것이 필수입니다.

## 한 줄 예

곡선 $x = t^2$, $y = t^3$ (단, $-1 \le t \le 1$)에서 $t = 1$일 때의 접선: $\frac{dx}{dt} = 2t|_{t=1} = 2$, $\frac{dy}{dt} = 3t^2|_{t=1} = 3$이므로 기울기는 $\frac{3}{2}$이고, 점 $(1, 1)$을 지나므로 **$y - 1 = \frac{3}{2}(x - 1)$** 즉 **$y = \frac{3}{2}x - \frac{1}{2}$**입니다. (검산: `sympy.diff(t**3, t) / sympy.diff(t**2, t)` at $t=1$ = $\frac{3}{2}$)
