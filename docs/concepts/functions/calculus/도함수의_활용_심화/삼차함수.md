# 삼차함수

## 정확한 진술
삼차함수는 최고차항이 3차인 다항함수입니다. 일반형은 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)입니다. 여기서 $a$는 최고차 계수이고, $b, c, d$는 각각 2차, 1차, 상수항의 계수이며 모두 실수입니다.

## 직관/기하적 의미
삼차함수의 그래프 형태는 도함수의 근의 개수에 따라 결정됩니다. 도함수 $f'(x) = 3ax^2 + 2bx + c$가 서로 다른 두 실근을 가지면 극값이 2개 존재하여 전형적인 S자 곡선을 이루고, 중근을 가지거나 실근이 없으면 극값이 없어 단조증가 또는 단조감소합니다. 

중요한 특성은 삼차함수가 항상 변곡점을 정확히 1개 가진다는 점입니다. 변곡점은 $f''(x) = 6ax + 2b = 0$을 만족하는 $x = -\frac{b}{3a}$이며, 그래프의 볼록성이 아래로 볼록에서 위로 볼록(또는 그 반대)으로 바뀌는 지점입니다. 이 점을 중심으로 삼차함수의 그래프는 점대칭입니다.

## 한 줄 예
$f(x) = x^3 - 3x + 1$은 삼차함수이며, $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 $x = \pm 1$에서 극값을 가집니다. (검증: `sympy.diff(x**3 - 3*x + 1, x)`)
