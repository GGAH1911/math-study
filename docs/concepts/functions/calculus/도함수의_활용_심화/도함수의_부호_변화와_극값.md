### 정확한 진술

함수 $f(x)$가 구간 $(a, b)$에서 미분가능하고, $x = c \in (a, b)$에서 $f'(c) = 0$일 때, $x = c$를 기준으로 $f'(x)$의 부호가 바뀌면 $x = c$에서 **극값**을 갖습니다.

- $f'(x)$가 양수에서 음수로 바뀌면 $x = c$에서 **극대값** $f(c)$를 가짐
- $f'(x)$가 음수에서 양수로 바뀌면 $x = c$에서 **극소값** $f(c)$를 가짐

이를 **극값 판정법**(또는 First Derivative Test)이라고 합니다.

### 직관/기하적 의미

도함수 $f'(x)$는 함수의 순간변화율이므로, $f'(x) > 0$이면 함수는 증가하고, $f'(x) < 0$이면 함수는 감소합니다. 따라서 $f'(x)$의 부호가 양에서 음으로 바뀐다는 것은 함수가 증가하다가 감소로 전환되는 지점, 즉 **봉우리(극대)**입니다. 반대로 음에서 양으로 바뀌면 **계곡(극소)**입니다.

**중요한 주의:** $f'(c) = 0$이라도 $f'(x)$의 부호가 바뀌지 않으면 극값이 아닙니다. 예를 들어, $f(x) = x^3$에서 $f'(0) = 0$이지만, $x = 0$ 좌우에서 $f'(x) > 0$이므로 극값이 아닙니다.

### 한 줄 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로, $x = -1$에서 극대값 $f(-1) = 2$, $x = 1$에서 극소값 $f(1) = -2$를 갖습니다. (`from sympy import symbols, diff; x = symbols('x'); diff(x**3 - 3*x, x)`)
