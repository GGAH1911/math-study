# 도함수의 물리적 의미

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
도함수는 시간의 흐름에 따른 물리량의 변화를 특정 순간의 변화율, 즉 순간속도나 가속도와 같은 물리적 변화량으로 나타낸 것입니다.

## 본문
함수 $f(t)$가 시간 $t$에 따른 위치, 온도, 농도와 같은 물리량을 나타낼 때, 도함수 $f'(t) = \lim_{h \to 0} \tfrac{f(t+h) - f(t)}{h}$는 시각 $t$에서 해당 물리량이 변화하는 정도인 순간변화율을 의미합니다. 이는 물리적 현상에서 매우 중요한 의미를 갖는데, 만약 $f(t)$가 물체의 위치를 나타낸다면 그 도함수인 $f'(t)$는 물체의 속도가 되며, 속도의 도함수인 $f''(t)$는 가속도가 됩니다.

### 직관과 기하적 의미
시간이 $t$에서 $t+\Delta t$로 아주 미세하게 변할 때, 물리량의 변화량인 $f(t+\Delta t) - f(t)$를 시간 변화량 $\Delta t$로 나눈 값은 평균변화율을 나타냅니다. 여기서 시간 변화량을 $0$에 가깝게 극한을 보내는 것은, 마치 자동차의 속도계가 특정 찰나의 속도를 가리키는 것처럼 "그 순간에 얼마나 빠르게 변하는가"를 포착하는 과정입니다. 예를 들어 자동차의 이동 거리 $s(t) = 5t^2$에 대하여 $s'(t) = 10t$를 구하면, $t=3$일 때의 순간속도는 $30$ m/s가 되어 그 순간의 정확한 이동 속도를 알 수 있습니다.

### 기본 성질
물리량의 변화를 다룰 때 도함수는 변화의 흐름을 연속적인 함수로 변환해 줍니다. 높이 $h(t) = 20t - 5t^2$인 물체의 경우, $h'(t) = 20 - 10t$는 시각 $t$에서의 수직 속도를 나타내며, 이를 한 번 더 미분한 $h''(t) = -10$은 물체에 작용하는 일정한 중력 가속도를 의미합니다.

## 학습 체크
- $f(t)$가 위치일 때 $f'(t)$와 $f''(t)$가 각각 무엇을 의미하는지 설명할 수 있는가?
- 평균변화율에서 시간 변화량 $\Delta t$를 $0$으로 보낼 때 도함수가 갖는 물리적 의미는 무엇인가?
- 주어진 위치 함수를 미분하여 특정 시점에서의 순간속도를 구할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수를 통해 변화율을 구하는 것을 넘어, 변화율이 $0$이 되는 지점을 찾아 물리량의 최댓값이나 최솟값을 찾는 최적화 문제로 확장됩니다.
