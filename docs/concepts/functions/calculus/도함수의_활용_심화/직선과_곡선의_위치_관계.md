### 정확한 진술

곡선 $y = f(x)$와 직선 $y = ax + b$의 위치 관계는 방정식 $f(x) = ax + b$, 즉 $f(x) - ax - b = 0$의 실근의 개수와 중복도에 의해 결정됩니다. 

- **서로 다른 두 실근**: 곡선과 직선이 서로 다른 두 점에서 만남
- **중근** (또는 중근을 포함): 곡선과 직선이 한 점에서 접함  
- **실근이 없음**: 곡선과 직선이 만나지 않음

### 직관/기하적 의미

곡선 위의 점 $(c, f(c))$에서의 접선을 생각해봅시다. 접선의 기울기는 도함수값 $f'(c)$이고, 접선의 방정식은 다음과 같습니다:
$$y - f(c) = f'(c)(x - c)$$

어떤 직선 $y = ax + b$가 점 $x = c$에서 곡선에 **접하는** 조건은 두 가지를 동시에 만족해야 합니다:

$$f(c) = ac + b \quad \text{(교점 조건)}$$
$$f'(c) = a \quad \text{(기울기 일치 조건)}$$

첫 번째는 점이 직선 위에 있다는 뜻이고, 두 번째는 곡선의 기울기와 직선의 기울기가 같다는 의미입니다. 이 둘이 모두 성립해야만 "접한다"고 합니다.

### 한 줄 예

곡선 $y = x^2$과 직선 $y = 2x - 1$의 교점: $x^2 - 2x + 1 = 0$ → $(x-1)^2 = 0$이므로 $x = 1$ (중근)에서 접합니다. (`sympy.solve(x**2 - 2*x + 1, x)`)
