# 극값의 합 조건

## 정확한 진술

함수 $f(x)$가 극값을 가질 조건과 그 극값들의 합이 만족하는 성질을 **극값의 합 조건**이라 합니다. 특히 삼차함수 $f(x) = ax^3 + bx^2 + cx + d$에서, 도함수 $f'(x) = 3ax^2 + 2bx + c = 0$이 서로 다른 두 실근 $\alpha, \beta$ ($\alpha < \beta$)를 가질 때, 극댓값 $M = f(\alpha)$와 극솟값 $m = f(\beta)$의 합 $M + m$은 함수의 기본 매개변수들과 일정한 관계를 갖습니다.

## 직관과 기하적 의미

삼차함수는 정확히 하나의 변곡점을 가지며, 이 점의 $x$좌표는 극값을 주는 두 근의 산술평균과 같습니다($\frac{\alpha+\beta}{2} = -\frac{b}{3a}$). 기하학적으로, 변곡점에서의 함수값을 $c$라 하면, 그 점을 지나고 수평인 직선이 삼차함수의 "중심"을 이루어, 극값의 합은 변곡점 함수값의 2배가 됩니다. 이는 삼차함수의 점대칭 성질에서 비롯되는 핵심입니다.

## 한 줄 예

$f(x) = x^3 - 3x + 1$에서 $f'(x) = 3x^2 - 3 = 0$ ⟹ $x = \pm1$이고, 극댓값은 $f(-1) = 3$, 극솟값은 $f(1) = -1$입니다. 극값의 합 $3 + (-1) = 2$이고, 변곡점 $x = 0$에서 $f(0) = 1$이므로 극값의 합 $= 2 \times f(0)$ 성립합니다. (검산: `sympy.solve(3*x**2-3, x)` ⟹ $[-1, 1]$ ✓)
