# 속도

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
속도는 위치 함수를 시간으로 미분한 값으로, 방향을 포함하는 벡터량입니다.

## 본문
점의 위치가 시각 $t$의 함수 $s(t)$로 나타날 때, 속도 $v(t)$는 위치 함수를 시간 $t$에 대하여 미분한 값인 $v(t) = s'(t) = \frac{ds}{dt}$로 정의됩니다. 속도는 방향성을 가지는 벡터량이므로 음수 값을 가질 수 있으며, 이때의 음수 부호는 물체가 음의 방향으로 이동하고 있음을 의미합니다. 속도의 크기인 절댓값 $|v(t)|$는 속력이라고 하며, 이는 항상 $0$보다 크거나 같은 값을 가집니다.

### 직관과 기하적 의미
위치-시간 그래프에서 속도는 그래프 곡선의 기울기로 해석됩니다. 특정 시각 $t = a$에서의 속도 $v(a)$는 위치 함수 그래프 위의 점 $(a, s(a))$에서 그은 접선의 기울기와 동일합니다. 따라서 기울기가 가파를수록 물체는 빠르게 움직이고, 기울기가 완만할수록 천천히 움직입니다. 만약 접선의 기울기가 $0$이라면 그 순간 물체는 정지 상태에 있으며, 기울기가 음수라면 물체는 음의 방향으로 이동하고 있음을 나타냅니다.

### 기본 성질
속도는 방향을 포함하는 개념이므로 속력과는 엄격히 구분되어야 합니다. 예를 들어 속도가 $-5 \text{ m/s}$라면 이는 음의 방향으로 초당 $5\text{m}$를 이동한다는 의미이지만, 이때의 속력은 방향을 제외한 크기인 $5 \text{ m/s}$가 됩니다.

- 위치-시간 그래프의 접선의 기울기와 속도 사이의 관계를 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 미분을 통해 변화율을 구하는 원리를 확장하여, 위치의 변화율인 속도와 속도의 변화율인 가속도를 다룹니다.
