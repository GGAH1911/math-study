# 속도

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 정확한 진술

점의 위치가 시각 $t$의 함수 $s(t)$로 나타날 때, **속도**는 다음과 같이 정의됩니다.

$$v(t) = s'(t) = \frac{ds}{dt}$$

즉, 위치 함수를 시간으로 미분한 값입니다. 속도는 벡터이므로 음수 값을 가질 수 있으며, 음수는 음의 방향 이동을 의미합니다. 속도의 절댓값 $|v(t)|$를 **속력**이라고 부르며, 이는 항상 음이 아닙니다.

## 직관 및 기하적 의미

위치-시간 그래프에서 속도는 곡선의 기울기입니다. 시각 $t = a$에서 속도 $v(a)$는 점 $(a, s(a))$에서의 접선의 기울기와 같습니다. 기울기가 크면 빠르게 움직이고, 기울기가 작으면 천천히 움직입니다. $v(a) = 0$이면 그 순간 정지 상태이고, $v(a) < 0$이면 음의 방향으로 이동합니다.

## 계산 예시

위치가 $s(t) = 3t^2 + 2t + 1$ (단위: m)로 주어지면:

$$v(t) = s'(t) = 6t + 2 \text{ (단위: m/s)}$$

$t = 1$초일 때 속도는 $v(1) = 6(1) + 2 = 8$ m/s입니다.

**검산:** `sympy.diff(3*t**2 + 2*t + 1, t)` → $6t + 2$

## 주의사항

속도와 속력을 구분하세요. 속도는 **방향을 포함한 크기**(음수 가능)이고, 속력은 **항상 음이 아닌 크기**입니다. 예를 들어 $v(t) = -5$ m/s이면 음의 방향으로 초당 5m 이동하는데, 속력은 5 m/s입니다.
