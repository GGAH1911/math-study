# 함수의 교점 분석

## 정확한 진술

두 함수 $f(x)$와 $g(x)$의 **교점**(intersection point)은 방정식 $f(x) = g(x)$를 만족하는 $x$값과 그에 대응하는 점 $(a, f(a))$입니다. 즉, 교점을 찾는 것은 방정식 $h(x) = f(x) - g(x) = 0$의 모든 실근을 구하는 것과 같습니다.

## 직관/기하적 의미

$xy$-평면에서 두 함수의 그래프가 만나는 지점이 교점입니다. 도함수를 활용하면 교점의 **성질**을 분석할 수 있습니다. 특히 곡선 $y = f(x)$가 직선 $y = g(x)$와 점 $x = a$에서 **접한다면**(tangent), 다음 두 조건을 동시에 만족합니다:

- $f(a) = g(a)$ (점을 공유)  
- $f'(a) = g'(a)$ (그 점에서 같은 기울기)

이 경우 방정식 $h(x) = 0$은 $x = a$에서 **중근**(double root)을 가집니다. 반면 한 번만 만나는 교점(횡단)은 $h'(a) \neq 0$입니다. 이렇게 도함수는 교점이 단순히 만나는지, 접하는지, 혹은 더 높은 차수로 접하는지를 구별하는 강력한 도구입니다.

## 한 줄 예

포물선 $y = x^2$과 직선 $y = 2x - 1$의 교점을 구하면 $x^2 = 2x - 1 \Rightarrow x^2 - 2x + 1 = 0 \Rightarrow (x-1)^2 = 0$이므로 $x = 1$ (중근, 접점)이고, 교점은 $(1, 1)$입니다. (`sympy.solve(x**2 - 2*x + 1, x)` → `[1]`)
