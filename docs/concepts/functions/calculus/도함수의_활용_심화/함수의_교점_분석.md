# 함수의 교점 분석

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
두 함수의 교점은 방정식 $f(x) = g(x)$의 실근을 통해 찾으며, 도함수를 통해 교점에서 그래프가 만나는지 또는 접하는지를 판별할 수 있습니다.

## 본문
두 함수 $f(x)$와 $g(x)$의 교점은 방정식 $f(x) = g(x)$를 만족하는 $x$값과 그에 대응하는 점 $(a, f(a))$를 의미합니다. 따라서 교점을 찾는 과정은 새로운 함수 $h(x) = f(x) - g(x)$를 설정했을 때, 방정식 $h(x) = 0$의 모든 실근을 구하는 과정과 동일합니다.

### 직관과 기하적 의미
$xy$-평면 위에서 두 함수의 그래프가 서로 만나는 지점이 바로 교점입니다. 이때 도함수를 활용하면 교점의 기하학적 성질을 정밀하게 분석할 수 있습니다. 만약 곡선 $y = f(x)$가 직선 $y = g(x)$와 점 $x = a$에서 접한다면, 두 함수는 해당 지점에서 함숫값이 같을 뿐만 아니라 접선의 기울기까지 동일해야 합니다. 즉, $f(a) = g(a)$와 $f'(a) = g'(a)$를 동시에 만족해야 하며, 이는 그래프가 단순히 교차하는 것이 아니라 부드럽게 맞닿아 있음을 의미합니다.

### 기본 성질
- **접점의 조건**: $x = a$에서 두 함수가 접한다면, 방정식 $h(x) = f(x) - g(x) = 0$은 $x = a$에서 중근을 가집니다.
- **횡단의 조건**: 두 함수가 $x = a$에서 단순히 교차하며 지나간다면, $h'(a) \neq 0$의 성질을 가집니다.
- **도함수의 역할**: 도함수는 교점이 단순히 만나는 지점인지, 아니면 접하는 지점인지, 혹은 더 높은 차수의 접점을 갖는지를 구별하는 결정적인 도구로 사용됩니다.

## 학습 체크
- 방정식 $f(x) - g(x) = 0$의 근의 개수와 그래프의 교점 개수는 항상 일치하는가?
- 두 함수의 미분계수가 같을 때, 반드시 두 그래프는 접한다고 할 수 있는가?
- $h(x) = 0$이 중근을 가질 때, 그래프의 형태는 어떻게 나타나는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수를 통해 함수의 증감과 극값을 파악함으로써, 두 함수의 그래프가 교차하는 지점의 개수를 논리적으로 추론할 수 있습니다.
