# 도함수 방정식의 해

## 정확한 진술

함수 $f(x)$의 도함수를 $f'(x)$라 할 때, 도함수에 대한 방정식—예를 들어 $f'(x) = k$ (여기서 $k$는 상수)를 풀어 얻는 $x$의 값을 **도함수 방정식의 해**라고 합니다. 가장 자주 다루어지는 경우는 $k=0$인 경우로, $f'(x) = 0$의 해는 함수의 극값(극댓값 또는 극솟값)을 갖는 점의 $x$좌표입니다. 더 일반적으로, $f'(x) = m$의 해는 함수의 그래프에서 기울기가 정확히 $m$인 접선을 그을 수 있는 모든 점의 $x$좌표를 나타냅니다.

## 직관/기하적 의미

도함수 방정식의 해를 찾는 것은 함수의 그래프에서 특정 기울기를 가진 위치를 찾는 과정입니다. 특히 $f'(x) = 0$의 해에서는 접선이 수평이 되며, 이 점을 경계로 함수의 증감 성질이 변합니다. 예를 들어 $f'(x)$가 양에서 음으로 바뀌면 극댓값을, 음에서 양으로 바뀌면 극솟값을 갖습니다. 이렇게 도함수 방정식의 해를 분석하면 함수의 형태를 완전히 파악할 수 있고, 최적값 문제를 해결할 때도 필수적입니다.

## 한 줄 예

$f(x) = x^3 - 3x$일 때, $f'(x) = 3x^2 - 3 = 0$을 풀면 $x = \pm 1$이 도함수 방정식의 해이며, 이 두 점에서 함수가 극값을 갖습니다.
