# 거리와 적분

## 정확한 진술

시간 구간 $[a, b]$에서 물체의 속도함수를 $v(t)$라 할 때, **거리(distance)**는 다음 정적분으로 정의됩니다.

$$\text{거리} = \int_a^b |v(t)| \, dt$$

속도가 항상 양수인 경우 절댓값을 생략할 수 있습니다. 절댓값을 제외한 $\int_a^b v(t) \, dt$는 **변위(displacement)**로, 방향을 고려한 순 이동거리를 나타냅니다.

## 직관·기하적 의미

$v(t)$를 $t$축 위의 곡선으로 그렸을 때, 정적분 $\int_a^b v(t) \, dt$는 곡선 아래의 넓이(부호 포함)입니다. $v(t) > 0$이면 정방향 운동, $v(t) < 0$이면 역방향 운동을 나타내므로:

- **변위**: 시작점과 끝점 사이의 순 이동거리. 양수와 음수 부분이 상쇄됩니다.
- **거리**: 실제로 움직인 총 거리. 음수 부분을 절댓값으로 변환하여 더합니다.

예를 들어 물체가 앞으로 5m 이동한 후 뒤로 3m 이동하면:
- 거리 = $5 + 3 = 8\text{m}$
- 변위 = $5 - 3 = 2\text{m}$

## 한 줄 예

속도함수 $v(t) = 3t - 6$ (단위: m/s)에서 $t = 0$부터 $t = 4$까지의 거리와 변위를 구할 때, $v(t) = 0$인 점이 $t = 2$이므로:

$$\text{변위} = \int_0^4 (3t-6) \, dt = [1.5t^2 - 6t]_0^4 = 24 - 24 = 0\text{m}$$

$$\text{거리} = \int_0^2 |3t-6| \, dt + \int_2^4 |3t-6| \, dt = 6 + 6 = 12\text{m}$$

(검증: `from sympy import symbols, integrate, Abs; t = symbols('t'); integrate(Abs(3*t-6), (t, 0, 4))`)
