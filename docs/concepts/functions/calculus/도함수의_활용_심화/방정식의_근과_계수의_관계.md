### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음 관계가 성립합니다:
$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

삼차방정식 $ax^3 + bx^2 + cx + d = 0$ (단, $a \neq 0$)의 세 근을 $\alpha, \beta, \gamma$라 할 때:
$$\alpha + \beta + \gamma = -\frac{b}{a}$$
$$\alpha\beta + \beta\gamma + \gamma\alpha = \frac{c}{a}$$
$$\alpha\beta\gamma = -\frac{d}{a}$$

이를 **근과 계수의 관계**(또는 비에타 공식)라고 부릅니다.

### 유도 원리와 기하적 의미

방정식을 인수분해 형태로 쓰면 이 관계가 명확해집니다. 이차방정식의 경우:
$$ax^2 + bx + c = a(x - \alpha)(x - \beta)$$

우변을 전개하면:
$$a(x - \alpha)(x - \beta) = a\left\{x^2 - (\alpha+\beta)x + \alpha\beta\right\}$$

계수를 비교하면 주어진 공식을 얻습니다. 삼차 이상도 동일한 방식으로 유도됩니다.

**기하적 의미**: 근의 값을 일일이 구하지 않아도 계수만으로 근들의 합, 곱, 대칭식 등을 계산할 수 있다는 장점이 있습니다. 이는 복잡한 계산을 피하고 문제 해결을 효율화합니다.

### 예시

방정식 $2x^2 - 5x + 3 = 0$의 두 근 $\alpha, \beta$에 대해:
$$\alpha + \beta = \frac{5}{2}, \quad \alpha\beta = \frac{3}{2}$$

$\alpha^2 + \beta^2$을 구하면:
$$\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = \left(\frac{5}{2}\right)^2 - 2 \cdot \frac{3}{2} = \frac{25}{4} - 3 = \frac{13}{4}$$

(검산: `sympy.solve(2*x**2 - 5*x + 3, x)` → $[1, \frac{3}{2}]$, $1^2 + (\frac{3}{2})^2 = \frac{13}{4}$ ✓)
