# 롤의 정리

> **정리** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)

## 요약
평균값 정리의 특수한 경우로, 양 끝점의 함숫값이 같을 때 미분계수가 $0$인 지점이 존재함을 나타내는 정리입니다.

## 본문
함수 $f$가 폐구간 $[a, b]$에서 연속이고 개구간 $(a, b)$에서 미분가능하며, $f(a) = f(b)$를 만족하면, 어떤 점 $c \in (a, b)$에 대하여 $f'(c) = 0$인 $c$가 존재합니다. 이 정리가 성립하기 위해서는 제시된 세 가지 조건이 모두 충족되어야 합니다. 만약 양 끝점의 함숫값이 다르거나 구간 내에 미분 불가능한 점이 있다면, 도함수가 $0$이 되는 지점이 반드시 존재한다는 결론을 보장할 수 없습니다.

기하학적으로는 함수 그래프의 양 끝점 높이가 같을 때, 그 사이 구간에서 접선의 기울기가 $0$인 수평 접선을 갖는 지점이 반드시 존재함을 의미합니다. 이는 그래프가 산이나 계곡의 형태를 띠며 올라갔다 내려오는 과정에서 반드시 기울기가 $0$이 되는 순간을 맞이한다는 직관적인 성질을 보여줍니다.

### 증명 스케치
최댓값과 최솟값 정리에 의해 함수 $f$는 폐구간 $[a, b]$에서 최댓값 $M$과 최솟값 $m$을 갖습니다. 만약 $M = m$이라면 $f$는 상수함수이므로 모든 점 $c$에서 $f'(c) = 0$이 되어 정리가 자명하게 성립합니다. 만약 $M > f(a)$이거나 $m < f(a)$라면, 최댓값 또는 최솟값을 갖는 점 $c$는 구간의 끝점이 아닌 개구간 $(a, b)$ 내에 존재하게 됩니다. 이때 $f(c)$는 극값을 가지며, $f$가 미분가능하므로 $f'(c) = 0$이 성립합니다.

### 의의와 응용
롤의 정리는 평균값 정리의 특수한 형태로, 방정식 $f'(x) = 0$의 해의 존재 여부나 개수를 추론하는 데 매우 유용합니다. 특히 함수의 개형을 파악하거나 방정식 $f(x) = k$의 실근의 개수를 판별할 때 핵심적인 도구로 사용됩니다. 예를 들어 $f(x) = x^3 - 3x$의 경우, $f(-1) = f(1) = -2$이므로 $(-1, 1)$ 사이에서 $f'(c) = 0$인 점이 반드시 존재하며, 실제로 $f'(x) = 3x^2 - 3 = 0$을 만족하는 $x=0$이 존재함을 확인할 수 있습니다.

## 학습 체크
- 함수가 연속이고 미분가능한 조건과 양 끝점의 함숫값이 같다는 조건을 모두 확인하였는가?
- 롤의 정리를 이용하여 도함수의 해의 개수를 추론하는 과정을 이해하였는가?
- 평균값 정리와 롤의 정리 사이의 관계를 설명할 수 있는가?

## 관련 개념
- **평균값 정리**: 롤의 정리를 일반화한 개념으로, 두 점 사이의 평균변화율과 같은 미분계수를 갖는 점이 존재함을 설명합니다.
- **도함수의 활용**: 롤의 정리를 통해 함수의 증가와 감소, 극값의 존재 등을 판단하는 기초 원리로 사용됩니다.
