# 롤의 정리

> **정리** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)
## 요약
평균값 정리의 특수 경우

## 본문

### 진술 및 가정

함수 $f$가 다음을 만족할 때, 롤의 정리가 성립합니다.

**롤의 정리:** 함수 $f$가 폐구간 $[a, b]$에서 연속이고 개구간 $(a, b)$에서 미분가능하며, $f(a) = f(b)$를 만족하면, 어떤 점 $c \in (a, b)$에 대하여 $f'(c) = 0$이 존재한다.

세 조건 모두 필수입니다. 하나라도 빠지면 결론이 성립하지 않을 수 있습니다. 예를 들어 $f(a) \neq f(b)$이거나 미분불가능한 점이 있으면 도함수가 0인 점이 존재하지 않을 수 있습니다.

### 기하학적 의미

함수값이 양 끝점에서 같다면, 그 사이에 반드시 "수평 접선"을 갖는 지점이 있다는 뜻입니다. 높이가 같은 두 지점 사이에 산을 지나거나 계곡을 지나는 그래프는 언젠가 기울기가 0인 순간을 맞이한다는 직관입니다. 이는 연속성과 미분가능성이 보장하는 자연스러운 성질입니다.

### 증명 스케치

최댓값과 최솟값 정리에 의해 $f$는 $[a, b]$에서 최댓값 $M$과 최솟값 $m$을 갖습니다. $f(a) = f(b)$이므로, $M > f(a)$ 또는 $m < f(a)$입니다(둘 다 같으면 $f$가 상수함수이므로 $f'(c) = 0$이 자명).

최댓값에 도달하는 점을 $c$라 하면, $c \in (a, b)$입니다(끝점이 아닌 이유는 위에서 설명). 그러면 $f(c)$가 극댓값이고, 미분가능성으로부터 $f'(c) = 0$입니다.

### 의의와 활용

롤의 정리는 **평균값 정리의 특수한 경우**이며, 방정식 $f'(x) = 0$의 해의 개수를 추론할 때 강력한 도구입니다. 예를 들어, $f'(x) = 0$이 정확히 몇 개의 해를 갖는지 판단하거나, 방정식 $f(x) = k$의 해의 개수를 결정할 때 활용됩니다. 수능 문제에서 함수의 개형을 결정하거나 방정식의 근의 개수를 세는 상황에서 자주 등장합니다.

**예:** $f(x) = x^3 - 3x$에서 $f(-1) = f(1) = -2$이므로, 롤의 정리에 의해 $(-1, 1)$에서 $f'(c) = 0$인 점이 존재합니다. 실제로 $f'(x) = 3x^2 - 3 = 0$에서 $x = 0 \in (-1, 1)$입니다. (검증: `sympy.solve(3*x**2 - 3, x)`)
