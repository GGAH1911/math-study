### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 교점 개수는 방정식 $f(x) = g(x)$, 즉 $h(x) = f(x) - g(x) = 0$의 실근 개수와 같습니다. **교점 개수 판정**이란 $h(x) = 0$의 근의 개수를 도함수 $h'(x)$를 이용해 분석하고, $h(x)$의 부호 변화로 결정하는 과정입니다.

### 직관 및 기하적 의미

함수 $h(x) = f(x) - g(x)$의 그래프가 x축과 만나는 점의 개수가 두 곡선의 교점 개수입니다. $h'(x)$를 구하면 $h(x)$의 증감을 파악할 수 있고, 극값의 부호와 위치를 확인하면 다음과 같이 판정합니다:

- $h(x)$가 극값을 가질 때, 극댓값과 극솟값의 부호를 조사
- 극댓값 > 0, 극솟값 < 0이면 $h(x) = 0$은 세 개의 서로 다른 실근을 가짐
- 극댓값 = 0 또는 극솟값 = 0이면 중근이 존재
- 극댓값 < 0 또는 극솟값 > 0이면 한 개의 실근만 존재

### 핵심 예시

$f(x) = x^3$과 $g(x) = 3x$의 교점 개수를 판정하면, $h(x) = x^3 - 3x = x(x^2 - 3)$이고, $h'(x) = 3x^2 - 3 = 3(x^2 - 1)$입니다. 

극값은 $x = \pm 1$에서 발생하며, $h(1) = -2 < 0$, $h(-1) = 2 > 0$이므로 세 개의 서로 다른 실근을 가집니다.

(`sympy.solve(x**3 - 3*x, x)` → $[0, -\sqrt{3}, \sqrt{3}]$, 확인됨)
