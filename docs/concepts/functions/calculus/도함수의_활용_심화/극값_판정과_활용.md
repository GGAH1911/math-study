### 정확한 진술

함수 $f(x)$가 $x=a$를 포함하는 어떤 구간에서 정의될 때, $f(a)$가 그 구간 내의 모든 $x$에 대해 $f(a) \geq f(x)$를 만족하면 $f(a)$를 **극댓값**(local maximum), $f(a) \leq f(x)$를 만족하면 **극솟값**(local minimum)이라고 합니다. 극댓값과 극솟값을 합쳐 **극값**이라 하며, 이를 갖는 점 $x=a$를 극값을 갖는 점이라 합니다.

### 직관과 기하적 의미

극값은 함수의 그래프에서 "산꼭대기"나 "골짜기" 모양의 지점입니다. 미분 가능한 함수의 경우, 극값을 판정하는 방법은 도함수의 부호 변화를 관찰하는 것입니다.

**1차 도함수 판정법**: $f'(a) = 0$이고 $x=a$ 전후로 $f'(x)$의 부호가 바뀌면 극값입니다. 양(+)에서 음(−)으로 바뀌면 극댓값, 음(−)에서 양(+)으로 바뀌면 극솟값입니다.

**2차 도함수 판정법**: $f'(a) = 0$일 때, $f''(a) < 0$이면 극댓값, $f''(a) > 0$이면 극솟값입니다.

### 예시와 검산

$f(x) = -x^2 + 4x$를 살펴봅시다.

$f'(x) = -2x + 4 = 0$에서 $x = 2$

$x < 2$일 때 $f'(x) > 0$ (증가), $x > 2$일 때 $f'(x) < 0$ (감소)이므로 $x=2$에서 극댓값을 갖습니다.

극댓값: $f(2) = -4 + 8 = 4$

또는 2차 도함수로: $f''(x) = -2 < 0$ 이므로 $x=2$에서 극댓값 ✓

(검산: `sympy.solve(-2*x + 4, x)` → $[2]$, `f(2)` → $4$)

극값은 최댓값/최솟값과 다릅니다. 극값은 '근처'에서의 최댓값일 뿐, 함수 전체 범위에서의 최댓값이 아닐 수 있습니다. 이 구분이 극값 판정의 핵심입니다.
