# 변곡점

> **정의** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)

## 요약
이계도함수 $f''(x)$의 부호가 바뀌는 지점

## 본문
점 $(x_0, f(x_0))$를 지나갈 때 $f''(x)$가 양에서 음으로 또는 음에서 양으로 부호를 바꾸면, 이 점을 **변곡점**이라 한다.

### 직관과 기하적 의미
변곡점은 그래프가 굽어지는 방향을 바꾸는 점이다. $f''(x) > 0$이면 그래프는 아래로 볼록($\cup$)한 모양을 띠고, $f''(x) < 0$이면 위로 볼록($\cap$)한 모양을 띤다. 변곡점은 이 곡선의 볼록한 방향이 전환되는 지점으로, 매끄럽게 흐르는 곡선의 성질이 변하는 순간을 의미한다. 이는 함수의 높낮이가 변하는 극값과는 구분되는 개념으로, 곡선의 휘어짐 자체가 변하는 지점이다.

### 기본 성질
변곡점이 되기 위해서는 우선 $f''(x_0) = 0$이거나 $x_0$에서 $f''(x)$가 존재하지 않아야 한다. 하지만 단순히 $f''(x_0) = 0$이라는 조건만으로는 부족하며, 반드시 $x_0$의 좌우에서 $f''(x)$의 부호가 실제로 바뀌어야 한다. 예를 들어 $f(x) = x^4$의 경우 $f''(x) = 12x^2$이며, $x=0$에서 $f''(0)=0$이지만 $x=0$ 전후로 부호가 바뀌지 않으므로 변곡점이 아니다. 반면 $f(x) = x^3$은 $f''(x) = 6x$이므로 $x=0$ 전후에서 부호가 바뀌어 $(0, 0)$이 변곡점이 된다.

## 학습 체크
- $f''(x)$의 부호 변화 여부를 확인하여 변곡점을 판정할 수 있는가?
- $f''(x_0)=0$인 점이 반드시 변곡점은 아님을 이해하고 있는가?
- 그래프의 볼록성 변화를 보고 변곡점의 위치를 추론할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 이계도함수를 통해 함수의 오목과 볼록을 판정하며, 이를 통해 함수의 그래프 개형을 정밀하게 그리는 데 사용된다.
