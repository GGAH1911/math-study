# 도함수 계산

## 정확한 진술

함수 $f(x)$의 **도함수**는 $f'(x)$ 또는 $\frac{df}{dx}$로 나타내며, 다음과 같이 정의됩니다:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

이 극한값이 존재할 때 $f$는 $x$에서 **미분가능**하다고 하며, $f'(x)$를 **미분 계수**라 부릅니다.

## 직관 · 기하적 의미

도함수는 한 점에서의 **순간변화율**을 나타냅니다. 기울기 관점으로 보면, $\frac{f(x+h) - f(x)}{h}$는 $(x, f(x))$와 $(x+h, f(x+h))$를 잇는 할선(secant line)의 기울기입니다. $h$가 0에 가까워질수록 할선이 접선(tangent line)에 가까워지므로, $f'(x)$는 **곡선 $y=f(x)$ 위의 점 $(x, f(x))$에서의 접선의 기울기**입니다.

이는 물리학에서 위치 함수의 도함수가 속도를 의미하는 것과도 맥락을 같이합니다.

## 계산 공식 (기본)

다항식, 삼각함수, 지수함수 등의 도함수는 다음 공식으로 직접 계산합니다:

- $\frac{d}{dx}(x^n) = nx^{n-1}$
- $\frac{d}{dx}(\sin x) = \cos x$, $\frac{d}{dx}(\cos x) = -\sin x$
- $\frac{d}{dx}(e^x) = e^x$, $\frac{d}{dx}(\ln x) = \frac{1}{x}$ (단, $x > 0$)

**합·차의 미분**: $\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$  
**곱의 미분**: $\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$  
**연쇄 법칙**: $\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$

## 한 줄 예

$f(x) = x^3 - 2x + 1$일 때, $f'(x) = 3x^2 - 2$ (합·차 법칙과 거듭제곱 공식 적용)

검산: `sympy: diff(x**3 - 2*x + 1, x)` → $3x^2 - 2$ ✓
