# 운동과 거리

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 정확한 진술

시간 $t$에서의 물체의 위치를 나타내는 함수를 $s(t)$라 할 때, **속도**는 $v(t) = s'(t)$입니다. 시간 구간 $[a, b]$에서:

- **변위(displacement)**: 위치의 순변화량 = $s(b) - s(a) = \int_a^b v(t) \, dt$
- **이동거리(distance traveled)**: 실제 이동한 거리의 합 = $\int_a^b |v(t)| \, dt$

## 직관과 기하적 의미

도함수로서의 속도는 방향을 포함합니다. 예를 들어 직선 위를 오가는 물체라면, 양수 속도는 우측 이동, 음수 속도는 좌측 이동을 의미합니다. 

변위 $\int_a^b v(t) \, dt$는 최종 위치에서 초기 위치를 뺀 값이므로, 왕복하는 운동에서 서로 상쇄됩니다. 반면 이동거리는 모든 움직임의 크기를 더해야 하므로, **속력 $|v(t)|$** 를 적분합니다. 그래프 관점에서, $v(t)$ 곡선과 $t$축 사이의 부호 있는 면적이 변위, 절댓값의 면적 합이 이동거리입니다.

## 한 줄 예

$s(t) = t^2 - 4t$ ($0 \le t \le 3$)일 때, $v(t) = 2t - 4$입니다. $t=2$에서 속도가 0이 되어 방향이 바뀌므로:
- 변위: $\int_0^3 (2t-4) \, dt = [t^2 - 4t]_0^3 = -3$
- 이동거리: $\int_0^2 |2t-4| \, dt + \int_2^3 (2t-4) \, dt = 4 + 1 = 5$  
  (`sympy.integrate(abs(2*t-4), (t, 0, 2)) + sympy.integrate(2*t-4, (t, 2, 3))`)
