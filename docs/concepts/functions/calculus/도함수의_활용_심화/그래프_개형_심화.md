# 그래프 개형 심화

> **예제** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)
## 요약
점근선·볼록 분석

## 본문

### 문제

다음 함수의 그래프 개형을 그리기 위해 점근선과 볼록성을 분석하세요.

$$f(x) = x + 1 + \frac{2}{x-1}$$

### 단계별 풀이

**1단계: 정의역과 수직 점근선**  
분모가 0이 되는 점은 $x = 1$이므로, 정의역은 $x \neq 1$입니다. 따라서 수직 점근선은 $x = 1$입니다.

**2단계: 사선 점근선**  
$x \to \pm\infty$일 때 $\frac{2}{x-1} \to 0$이므로, 사선 점근선은 $y = x + 1$입니다. (함수는 $x < 1$에서는 이 직선의 아래, $x > 1$에서는 위에 위치)

**3단계: 증감 구간**  
$$f'(x) = 1 - \frac{2}{(x-1)^2}$$

$f'(x) = 0$일 때: $(x-1)^2 = 2$ → $x = 1 \pm \sqrt{2}$  
따라서 $x < 1-\sqrt{2}$, $1+\sqrt{2} < x$에서 $f'(x) > 0$ (증가), $1-\sqrt{2} < x < 1$과 $1 < x < 1+\sqrt{2}$에서 $f'(x) < 0$ (감소)

**4단계: 변곡점과 볼록성**  
$$f''(x) = \frac{4}{(x-1)^3}$$

$f''(x) = 0$인 점이 없으므로 변곡점은 없습니다. 다만:
- $x < 1$에서 $f''(x) < 0$ (위로 볼록)
- $x > 1$에서 $f''(x) > 0$ (아래로 볼록)

### 답

그래프는 두 개의 분리된 곡선으로 이루어집니다. 좌측 $(x < 1)$: $x = 1-\sqrt{2}$에서 극대값 $2-2\sqrt{2}$, 우측 $(x > 1)$: $x = 1+\sqrt{2}$에서 극소값 $2+2\sqrt{2}$. 두 곡선 모두 사선 점근선 $y = x+1$에 수렴하며, 좌측은 아래에서 접근하고 우측은 위에서 접근합니다. (검산: `sympy.solve(x - 1 - sp.sqrt(2), x)` → $x = 1 + \sqrt{2}$)

### 변형·주의

점근선의 위치 관계(함수가 어느 쪽에 있는지)는 극한값의 부호나 $f''(x)$의 부호와 일치해야 합니다. 또한 정의역이 끊어진 경우, 각 구간에서 독립적으로 증감·볼록성을 판정하고, 수직 점근선 근처에서의 극한 거동도 함께 고려해야 정확한 개형을 얻을 수 있습니다.
