# 그래프 개형 심화

> **예제** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)

## 요약
함수의 점근선과 이계도함수를 이용한 볼록성을 분석하여 그래프의 전체적인 개형을 파악합니다.

## 본문
다음 함수의 그래프 개형을 그리기 위해 점근선과 볼록성을 분석하세요.

$$f(x) = x + 1 + \frac{2}{x-1}$$

### 단계별 풀이
**1단계: 정의역과 수직 점근선**  
분모가 $0$이 되는 점은 $x = 1$이므로, 정의역은 $x \neq 1$입니다. 따라서 수직 점근선은 $x = 1$입니다.

**2단계: 사선 점근선**  
$x \to \pm\infty$일 때 $\tfrac{2}{x-1} \to 0$이므로, 사선 점근선은 $y = x + 1$입니다. 함수는 $x < 1$ 구간에서는 이 직선의 아래에, $x > 1$ 구간에서는 이 직선의 위에 위치합니다.

**3단계: 증감 구간**  
$f'(x) = 1 - \tfrac{2}{(x-1)^2}$입니다.  
$f'(x) = 0$인 지점은 $(x-1)^2 = 2$를 만족하는 $x = 1 \pm \sqrt{2}$입니다.  
- $x < 1-\sqrt{2}$ 또는 $x > 1+\sqrt{2}$에서 $f'(x) > 0$이므로 함수는 증가합니다.  
- $1-\sqrt{2} < x < 1$ 또는 $1 < x < 1+\sqrt{2}$에서 $f'(x) < 0$이므로 함수는 감소합니다.

**4단계: 변곡점과 볼록성**  
$f''(x) = \tfrac{4}{(x-1)^3}$입니다.  
$f''(x) = 0$인 점이 없으므로 변곡점은 존재하지 않습니다.  
- $x < 1$에서 $f''(x) < 0$이므로 위로 볼록합니다.  
- $x > 1$에서 $f''(x) > 0$이므로 아래로 볼록합니다.

### 답과 변형
그래프는 두 개의 분리된 곡선으로 나타납니다. $x < 1$ 영역에서는 $x = 1-\sqrt{2}$에서 극댓값 $2-2\sqrt{2}$를 갖고 사선 점근선 $y = x+1$의 아래쪽에서 접근합니다. $x > 1$ 영역에서는 $x = 1+\sqrt{2}$에서 극솟값 $2+2\sqrt{2}$를 갖고 사선 점근선의 위쪽에서 접근합니다.

점근선의 위치 관계를 파악할 때는 극한값의 부호와 이계도함수의 부호를 함께 고려해야 하며, 정의역이 끊어진 경우 각 구간을 독립적으로 분석하여 수직 점근선에서의 거동을 반드시 확인해야 합니다.
