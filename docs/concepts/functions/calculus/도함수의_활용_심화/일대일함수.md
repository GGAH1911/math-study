# 일대일함수

## 정확한 진술

함수 $f: A \to B$가 **일대일함수**(단사함수, injective function)라는 것은 정의역의 서로 다른 원소가 서로 다른 치역값으로 대응된다는 뜻입니다. 다시 말해, 임의의 $x_1, x_2 \in A$에 대하여

$$x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$$

가 성립하거나, 대우를 이용하면

$$f(x_1) = f(x_2) \implies x_1 = x_2$$

가 성립할 때 $f$를 일대일함수라고 합니다.

## 직관/기하적 의미

그래프로 생각하면, **수평선 검사**(horizontal line test)를 사용합니다. 치역의 모든 수평선 $y = c$가 함수의 그래프와 최대 한 점에서만 만날 때 일대일함수입니다. 이는 각 $y$값이 정확히 하나의 $x$값으로부터만 나온다는 의미입니다.

미분가능한 함수의 경우, **일대일함수의 충분조건**은 도함수가 항상 양수거나 항상 음수인 것입니다. 즉, $f'(x) > 0$ (또는 $f'(x) < 0$)이 정의역 전체에서 성립하면 $f$는 일대일함수입니다. 왜냐하면 이 경우 함수가 순증가(또는 순감소)하기 때문에 같은 함수값이 나올 수 없기 때문입니다. 반대로 $f'(x) = 0$이 되는 구간이 있다면 그 구간에서 함수가 상수이므로 일대일함수가 아닙니다.

## 한 줄 예

$f(x) = 2x + 3$은 $f'(x) = 2 > 0$이므로 일대일함수이고, $g(x) = x^2$은 $x < 0$과 $x > 0$에서 같은 함수값을 가지므로(예: $g(-1) = g(1) = 1$) 일대일함수가 아닙니다. 하지만 정의역을 $[0, \infty)$로 제한하면 $g$는 일대일함수가 됩니다.
