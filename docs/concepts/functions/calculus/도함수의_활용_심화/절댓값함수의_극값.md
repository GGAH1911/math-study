# 절댓값함수의 극값

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
절댓값 함수 $f(x) = |g(x)|$의 극값은 $g(x) > 0$인 구간에서 $f'(x) = 0$인 점과 $g(x) = 0$인 점을 모두 후보로 하여 판정한다.

## 본문
절댓값 함수 $f(x) = |g(x)|$의 극값을 구하기 위해서는 먼저 함수의 형태가 바뀌는 지점을 파악해야 한다. 우선 $g(x) > 0$인 구간에서는 $f(x) = g(x)$이므로, 일반적인 함수의 극값 구하기와 동일하게 $f'(x) = 0$인 점을 후보로 조사한다. 다음으로 $g(x) = 0$인 점은 함수가 $x$축과 만나는 지점으로, 이 지점에서 함수는 미분 불가능할 수 있으나 그래프가 꺾이는 지점이므로 반드시 극값의 후보로 포함하여 검토해야 한다. 각 후보점에서 함숫값을 계산한 뒤, 주변 함숫값과의 크기를 비교하거나 좌미분계수와 우미분계수의 부호 변화를 확인하여 극댓값과 극솟값을 최종적으로 판정한다.

### 직관과 기하적 의미
절댓값 함수 $y = |g(x)|$의 그래프는 원래 함수 $y = g(x)$의 그래프에서 $y < 0$인 부분을 $x$축을 기준으로 상하 대칭시킨 형태를 띤다. 이 과정에서 $g(x) = 0$인 지점은 그래프가 $x$축과 만나며 뾰족하게 꺾이는 형태(첨점)를 만들게 되어 미분이 불가능해진다. 따라서 기존 함수에서는 극값이 아닐 수 있었던 지점들이 절댓값을 씌움으로써 극솟값이 될 수 있으므로, 미분 불가능한 점을 반드시 확인해야 한다.

### 기본 성질
$f(x) = |x^2 - 4x + 3|$의 경우, $x=1$과 $x=3$에서 $g(x)=0$이 되어 미분 불가능한 점이 발생한다. 한편 $1 < x < 3$ 구간에서는 $f(x) = -x^2 + 4x - 3$이 되며, 이 구간 내에서 $f'(x) = -2x + 4 = 0$을 만족하는 $x=2$에서 극댓값 $f(2) = 1$을 갖는다.

## 학습 체크
- $g(x)=0$인 지점에서 함수가 꺾일 때, 그 점이 극솟값이 되기 위한 조건은 무엇인가?
- $g(x)>0$인 구간에서 $f'(x)=0$인 점을 찾았을 때, 그 점이 반드시 극값임을 보장하는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증감과 극대·극소를 판정할 때 미분 불가능한 점을 포함하여 분석하는 능력이 요구된다.
