# 기하와 미분의 응용

## 정확한 진술

함수 $f(x)$의 도함수 $f'(x)$는 곡선 $y = f(x)$ 위의 점 $(x, f(x))$에서 **접선의 기울기**를 나타냅니다. 이 기울기 정보를 이용하여 곡선의 극대·극소, 변곡점, 오목·볼록성 등 **기하학적 성질을 분석하고 파악하는 방법**을 기하와 미분의 응용이라 합니다.

## 직관/기하적 의미

도함수 $f'(x)$의 부호와 크기는 곡선의 모양을 결정합니다:

- $f'(x) > 0$인 구간: 곡선이 **상승** (함수값이 증가)
- $f'(x) < 0$인 구간: 곡선이 **하강** (함수값이 감소)  
- $f'(x) = 0$인 점: 곡선의 **극값** 후보 (극대, 극소, 또는 안장점)
- $f''(x) > 0$: 곡선이 **아래로 볼록** (오목)
- $f''(x) < 0$: 곡선이 **위로 볼록** (볼록)

이 정보들을 종합하면 곡선을 정확하게 그릴 수 있고, 최댓값·최솟값이나 넓이 같은 실용적 문제를 해결할 수 있습니다.

## 한 줄 예

$f(x) = x^3 - 3x^2$에서 $f'(x) = 3x^2 - 6x = 3x(x-2)$이므로, $x=0$과 $x=2$에서 극값을 가집니다. (`sympy.solve(3*x**2 - 6*x, x)` → $[0, 2]$)
