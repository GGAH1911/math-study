# 함수의 증감

## 정확한 진술

구간 $I$에서 미분가능한 함수 $f(x)$에 대하여 다음이 성립합니다.

**증감의 판정 정리**
- $I$의 모든 점에서 $f'(x) > 0$이면 $f(x)$는 $I$에서 **증가함수**
- $I$의 모든 점에서 $f'(x) < 0$이면 $f(x)$는 $I$에서 **감소함수**  
- $I$의 모든 점에서 $f'(x) = 0$이면 $f(x)$는 $I$에서 **상수함수**

## 직관/기하적 의미

도함수 $f'(x)$는 각 점에서 함수 그래프의 접선 기울기를 나타냅니다. 기울기가 양수면 그래프가 오른쪽으로 갈수록 위로 상승하고(증가), 음수면 내려갑니다(감소). 이 성질을 이용하면 함수 전체를 그리지 않고도 도함수의 부호만으로 증감을 판정할 수 있습니다. 특히 고차 함수나 복잡한 함수일수록 도함수의 부호 변화를 추적하여 **증감표**를 만드는 것이 함수의 최댓값, 최솟값, 극값을 찾는 표준 방법입니다.

## 한 줄 예

$f(x) = x^3 - 3x^2 + 1$에서 $f'(x) = 3x^2 - 6x = 3x(x-2)$이므로, $x < 0$ 또는 $x > 2$에서 증가, $0 < x < 2$에서 감소합니다.

(`sympy.solve(3*x*(x-2), x)` → $x = 0, 2$)
