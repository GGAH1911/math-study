# 도함수의 부호와 증감

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
도함수의 부호는 함수의 증가와 감소를 결정하며, 도함수의 부호가 변하는 지점을 통해 함수의 극값을 찾을 수 있다.

## 본문
폐구간 $[a, b]$에서 미분 가능한 함수 $f(x)$에 대하여, 도함수 $f'(x)$의 부호에 따라 함수의 증감이 결정된다. $f'(x) > 0$인 구간에서 함수 $f(x)$는 증가하며, $f'(x) < 0$인 구간에서 함수 $f(x)$는 감소한다. 만약 구간 내에서 $f'(x) \geq 0$이면 함수는 증가하고, $f'(x) \leq 0$이면 함수는 감소한다. 이때 $f'(x) = 0$을 만족하는 점은 함수의 극댓값 또는 극솟값을 갖는 후보가 된다. 구체적으로 도함수의 부호가 양에서 음으로 바뀌는 지점에서는 극댓값을, 음에서 양으로 바뀌는 지점에서는 극솟값을 갖는다.

### 직관과 기하적 의미
도함수 $f'(x)$는 함수 $f(x)$의 그래프 위의 임의의 점에서의 접선의 기울기를 의미한다. 접선의 기울기가 양수이면 그래프가 오른쪽 위로 향하므로 함수값이 증가하는 상태이며, 기울기가 음수이면 오른쪽 아래로 향하므로 함수값이 감소하는 상태이다. 기울기가 $0$이 되는 지점은 접선이 수평이 되는 순간으로, 함수가 증가에서 감소로 또는 감소에서 증가로 방향을 전환할 수 있는 변곡점의 후보가 된다. 이러한 성질을 이용하면 복잡한 함수의 그래프 개형을 논리적으로 예측할 수 있다.

### 기본 성질
$f(x) = x^3 - 3x$를 예로 들면, 도함수는 $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이다. $f'(x) > 0$인 구간인 $x < -1$ 또는 $x > 1$에서 함수는 증가하고, $f'(x) < 0$인 구간인 $-1 < x < 1$에서 함수는 감소한다. 따라서 $x = -1$에서 극댓값 $2$를, $x = 1$에서 극솟값 $-2$를 갖는다.

## 관련 개념
- **도함수의 활용 심화**: 도함수의 부호와 증감을 바탕으로 함수의 극값, 최대·최소, 그리고 그래프의 개형을 완벽하게 파악하는 단계로 확장된다.
