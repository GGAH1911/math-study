### 정확한 진술

함수 $f(x)$에 대하여 **도함수의 근**(critical point)은 도함수가 0이 되는 $x$값입니다. 즉, $f'(x) = 0$을 만족하는 모든 $x$를 도함수의 근이라 합니다.

정의역 내에서 도함수가 존재하고 미분가능한 함수에서만 의미가 있으며, 도함수의 근이 존재하지 않을 수도 있습니다.

### 직관 및 기하적 의미

함수의 그래프 위의 한 점에서 그은 접선의 기울기는 도함수값입니다. 도함수의 근에서는 **접선의 기울기가 정확히 0**이므로, 접선이 $x$축에 평행합니다. 

기하학적으로 이 지점들은 함수의 그래프가 **"수평"**이 되는 순간입니다. 극값(극대값, 극소값)은 도함수의 근에서 발생할 가능성이 높으므로, 함수의 최댓값·최솟값을 구할 때 반드시 확인해야 합니다.

다만 도함수의 근이 항상 극값을 의미하는 것은 아닙니다. 예를 들어 $f(x) = x^3$에서 $f'(x) = 3x^2$이므로 $x=0$은 도함수의 근이지만, 이 점은 변곡점이지 극값이 아닙니다.

### 예제

$f(x) = x^3 - 3x^2 + 1$일 때, 도함수는 $f'(x) = 3x^2 - 6x = 3x(x-2)$입니다. 

도함수의 근은 $f'(x) = 0$에서 $x = 0$ 또는 $x = 2$입니다.

이 두 점에서 함수의 그래프 위의 접선 기울기가 0이므로, 극값의 후보가 됩니다. 실제로 부호 판정이나 이계 도함수를 이용하면 $x=0$에서 극대, $x=2$에서 극소임을 알 수 있습니다.

```python
from sympy import symbols, diff, solve
x = symbols('x')
f = x**3 - 3*x**2 + 1
f_prime = diff(f, x)
critical_points = solve(f_prime, x)  # [0, 2]
```
