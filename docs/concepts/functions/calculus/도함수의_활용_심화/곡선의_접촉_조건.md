# 곡선의 접촉 조건

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
두 곡선이 특정 점에서 함숫값과 도함수 값이 모두 같을 때, 두 곡선은 그 점에서 접한다고 합니다.

## 본문
두 곡선 $y = f(x)$와 $y = g(x)$가 점 $(a, f(a))$에서 **접한다**(osculate)는 것은 $f(a) = g(a)$와 $f'(a) = g'(a)$라는 두 조건을 동시에 만족함을 의미합니다. 더 나아가 두 곡선이 점 $a$에서 **$n$차 접촉**(contact of order $n$)을 가진다는 것은 $f(a) = g(a)$부터 $f^{(n)}(a) = g^{(n)}(a)$까지의 모든 고계도함수 값이 서로 같음을 의미합니다.

### 직관과 기하적 의미
함숫값이 같다는 것은 두 곡선이 단순히 한 점에서 만나는 '교점'을 형성함을 의미하지만, 접촉은 그 교점에서 두 곡선이 같은 방향으로 나아감을 의미합니다. 도함수가 같다는 것은 해당 점에서의 접선의 기울기가 동일하다는 뜻이므로, 두 곡선이 마치 하나의 곡선처럼 부드럽게 이어지는 형태를 띱니다. 고등학교 교육과정에서는 주로 함숫값과 도함수가 같은 '1차 접촉'을 다루며, 이는 곡선 위의 한 점에 접선을 그을 때의 조건과 일치합니다.

### 기본 성질
- 두 곡선이 점 $a$에서 접하면, $x=a$는 두 함수의 차 $f(x) - g(x) = 0$의 중근을 갖습니다.
- $n$차 접촉을 만족하는 두 함수 $f(x)$와 $g(x)$의 차는 $(x-a)^{n+1}$을 인수로 가집니다.

## 학습 체크
- 두 곡선이 한 점에서 만날 때, 접한다고 말하기 위해 추가로 확인해야 할 조건은 무엇인가요?
- $n$차 접촉의 정의를 이용하여 $f(x)$와 $g(x)$의 고계도함수 관계를 설명할 수 있나요?
- 함수 $f(x) = x^2$과 직선 $g(x) = 2x - 1$이 점 $(1, 1)$에서 접함을 미분 계수를 통해 증명할 수 있나요?

## 관련 개념
- **도함수의 활용 심화**: 접선의 방정식이나 곡선의 오목과 볼록을 다룰 때, 접촉의 차수를 통해 곡선의 근사적 형태를 파악하는 데 활용됩니다.
