# 절댓값 함수의 극값

## 정확한 진술

절댓값 함수의 극값은 $f(x) = |g(x)|$ 형태의 함수에서 최댓값 또는 최솟값을 갖는 점입니다. 절댓값 함수는 $g(x) = 0$이 되는 점에서 **꺾이는 성질**을 가지므로, 도함수가 정의되지 않을 수 있으며, 이 점에서 극값이 나타날 수 있습니다.

## 직관·기하적 의미

절댓값 함수 $f(x) = |g(x)|$는 원함수 $g(x)$의 그래프 중 x축 아래 부분을 위로 접어올린 형태입니다. 따라서 극값은 다음 세 가지 경우에서 발생합니다:

1. **$g(x) = 0$인 점**: 절댓값이 꺾이는 점으로, 양쪽 미분계수의 부호가 바뀔 수 있습니다.
2. **$g'(x) = 0$이면서 $g(x) \neq 0$인 점**: 원함수의 극값이 그대로 상속됩니다.
3. **양/음 구간에서 도함수의 부호 변화**: $g(x) > 0$일 때 $\displaystyle\frac{d}{dx}|g(x)| = g'(x)$이고, $g(x) < 0$일 때 $\displaystyle\frac{d}{dx}|g(x)| = -g'(x)$입니다.

## 구체적 예

$f(x) = |x^2 - 4|$의 극값을 구하면:

$g(x) = x^2 - 4$는 $x = -2, 2$에서 영점을 가집니다. 또한 $g'(x) = 2x$이므로 $x = 0$에서 극값을 가집니다.

- $x = 0$: $f(0) = |-4| = 4$ (극댓값)
- $x = -2, 2$: $f(\pm 2) = 0$ (극솟값)

따라서 $f(x)$는 $x = 0$에서 극댓값 4, $x = \pm 2$에서 극솟값 0을 가집니다.

**검증**: `sympy.solve((x**2 - 4).diff(x), x)` → $[0]$; `sympy.solve(x**2 - 4, x)` → $[-2, 2]$
