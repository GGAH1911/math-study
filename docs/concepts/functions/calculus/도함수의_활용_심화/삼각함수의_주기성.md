### 정확한 진술

함수 $f(x)$가 **주기함수**라는 것은, 모든 $x$에 대해 $f(x+T) = f(x)$를 만족하는 양수 $T$가 존재한다는 의미입니다. 이러한 $T$를 $f$의 **주기(period)**라고 하고, 조건을 만족하는 가장 작은 양수를 **기본 주기(fundamental period)**라고 합니다.

삼각함수의 기본 주기는 다음과 같습니다:
- $\sin x$, $\cos x$: 주기 $2\pi$
- $\tan x$: 주기 $\pi$
- $\cot x$: 주기 $\pi$

일반적으로 $f(x) = \sin(bx + c)$, $f(x) = \cos(bx + c)$ 형태의 함수는 기본 주기가 $\frac{2\pi}{|b|}$입니다.

### 직관/기하적 의미

삼각함수의 그래프는 원의 회전 운동에서 비롯됩니다. 단위원 위의 점이 각도 $x$에서 시작하여 $2\pi$ 만큼 추가로 회전하면 같은 위치에 돌아오므로, $\sin(x + 2\pi) = \sin x$입니다. 기하학적으로는 그래프가 수평으로 주기 길이만큼 평행이동해도 완전히 같은 모양이 반복된다는 의미입니다.

$\tan x$는 주기가 $\pi$인 이유는 접선 함수가 반바퀴 회전으로 같은 기울기를 갖기 때문입니다.

### 주기성 확인 예제

$\sin(x + 2\pi) = \sin x$임을 삼각함수의 덧셈공식으로 확인할 수 있습니다:
$$\sin(x + 2\pi) = \sin x \cos 2\pi + \cos x \sin 2\pi = \sin x \cdot 1 + \cos x \cdot 0 = \sin x$$

마찬가지로 $\cos(x + 2\pi) = \cos x$도 성립합니다. $\tan x$의 경우 $\tan(x + \pi) = \tan x$입니다 (`sympy.simplify(tan(x + pi) - tan(x))` 검증 가능).
