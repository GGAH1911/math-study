# 최적화 문제

> **예제** · 미적분 · 단원: [도함수의 활용 (심화)](/concepts/도함수의_활용_심화)
## 요약
제약 조건의 최대/최소

## 본문

### 문제

둘레가 40인 직사각형의 넓이를 최대로 하려면 가로와 세로의 길이는 얼마여야 하는가?

### 단계별 풀이

가로의 길이를 $x$, 세로의 길이를 $y$라고 하겠습니다.

**제약 조건 정리**

둘레 조건: $2x + 2y = 40$에서 $y = 20 - x$

**변수 소거**

넓이를 한 변수로 표현하면:
$$S(x) = xy = x(20-x) = 20x - x^2$$

**정의역 결정**

$x > 0$, $y > 0$이므로 $0 < x < 20$

**도함수 계산**

$$S'(x) = 20 - 2x$$

극값을 구하면: $S'(x) = 0 \Rightarrow x = 10$

**2차 미분으로 극값의 성질 확인**

$$S''(x) = -2 < 0$$

$S''(10) < 0$이므로 $x = 10$에서 최댓값을 가집니다.

**함숫값 계산**

- $x = 10$일 때, $y = 20 - 10 = 10$
- 최대 넓이: $S_{\max} = 10 \times 10 = 100$

### 답

가로와 세로의 길이가 모두 **10**일 때(즉, 정사각형), 넓이의 최댓값은 **100**입니다.

검산: `sympy.symbols('x'); sympy.solve(20 - 2*x, x)` → `[10]`

### 변형/주의

**제약 조건의 역할** — 제약 조건이 없으면 최적화 문제가 정의되지 않습니다. "$y = 20 - x$"라는 조건이 있기에 비로소 한 변수 함수가 되어 도함수로 극값을 찾을 수 있습니다.

**경계값 검토** — $x \to 0^+$ 또는 $x \to 20^-$일 때 $S(x) \to 0$입니다. 개구간 $(0, 20)$의 극값 $x=10$이 유일하고, 2차 미분이 음수이므로 이는 전체 최댓값입니다.

**일반 원리** — 둘레가 일정한 모든 도형 중 정사각형(또는 원)이 최대 넓이를 가집니다. 이는 등주 부등식(isoperimetric inequality)의 특수한 경우입니다.
