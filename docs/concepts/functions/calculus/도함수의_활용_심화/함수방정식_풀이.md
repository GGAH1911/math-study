# 함수방정식 풀이

## 정의
함수방정식이란 미지수가 함수인 방정식입니다. 즉, 구하려는 함수 $f(x)$가 만족해야 할 조건들이 주어진 형태입니다. 예를 들어 $f(x+y) = f(x) + f(y)$는 함수 $f$를 찾기 위한 함수방정식입니다.

## 직관과 의미
함수방정식은 함수의 본질적인 성질을 나타냅니다. 예를 들어 $f(x+y) = f(x) + f(y)$를 만족하면서 연속인 함수는 반드시 $f(x) = cx$ 형태(일차함수)입니다. 미적분에서는 주로 도함수의 성질, 함수값 사이의 관계, 또는 함수의 합성 조건으로 주어진 함수방정식을 풀게 됩니다.

## 기본 풀이 방법
미적분 범위에서 함수방정식을 푸는 주요 전략은:

**양변 미분**: 함수방정식의 양변을 $x$ 또는 $y$에 대해 미분하여 미분방정식을 만들고, 초기조건과 함께 적분하여 $f(x)$의 구체적 형태를 결정합니다.

**특수값 대입**: $x = 0$, $y = 0$ 같은 특정 값을 함수방정식에 대입하여 함수의 기본 성질을 파악합니다.

**함수의 형태 추정**: 주어진 조건에서 $f(x)$가 어느 형태(일차, 이차, 지수, 로그 등)인지 추측한 후 계수를 결정합니다.

## 간단한 예
$f'(x) = 2f(x)$이고 $f(0) = 1$을 만족하는 함수를 구하면, 양변을 정리하여 $\frac{f'(x)}{f(x)} = 2$에서 $\ln|f(x)| = 2x + C$를 얻고, 초기조건 $f(0) = 1$을 적용하면 $f(x) = e^{2x}$입니다. ✓
