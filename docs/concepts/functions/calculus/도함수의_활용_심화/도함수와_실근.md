# 도함수와 실근

## 정확한 진술

함수 $f(x)$의 도함수 $f'(x)$를 분석하면, 방정식 $f(x) = 0$의 실근의 개수와 위치를 판별할 수 있습니다. 구체적으로, $f'(x) = 0$인 점에서의 극값들과 함수의 끝값들의 부호를 비교하여, $f(x)$의 그래프가 x축과 만나는 횟수를 결정할 수 있습니다.

## 직관과 기하적 의미

도함수는 함수의 순간변화율을 나타내므로, $f'(x)$의 부호에 따라 $f(x)$의 증감이 결정됩니다. 이를 이용하면 함수의 극댓값과 극솟값을 찾을 수 있고, 이 극값들이 0보다 크거나 작은지에 따라 그래프가 x축과 만나는 점의 개수가 결정됩니다. 예를 들어, 극값이 두 개인 3차 함수가 극댓값 $M$과 극솟값 $m$을 가질 때:
- $M > 0$이고 $m > 0$이면 실근은 1개
- $M > 0$이고 $m < 0$이면 실근은 3개
- $M < 0$이고 $m < 0$이면 실근은 1개

## 계산 예제

$f(x) = x^3 - 3x + 1$에서 $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로, $f'(x) = 0$일 때 $x = -1$ 또는 $x = 1$입니다.

극댓값: $f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3 > 0$  
극솟값: $f(1) = 1 - 3 + 1 = -1 < 0$

극댓값과 극솟값의 부호가 다르므로, 이 함수는 실근을 3개 가집니다. `sympy.solve(x**3 - 3*x + 1, x)`로 확인하면 약 $x \approx -1.88, 0.35, 1.53$입니다.
