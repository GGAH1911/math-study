# 극소

## 정확한 진술

함수 $f(x)$가 $x = a$를 포함하는 어떤 열린 구간에서 정의되어 있을 때, 그 구간의 모든 $x$에 대해 $f(x) \geq f(a)$이면 $f(a)$를 **극소값**, $x = a$를 **극소점**이라 합니다. 즉, $a$ 근처에서 $f(a)$가 가장 작은 값입니다.

도함수를 이용한 판정법은 다음과 같습니다:
- $f'(a) = 0$이고
- $x = a$의 좌측에서 $f'(x) < 0$ (함수가 감소)
- $x = a$의 우측에서 $f'(x) > 0$ (함수가 증가)

이 두 조건을 만족하면 $x = a$에서 극소입니다.

## 직관/기하적 의미

극소점은 그래프에서 "골짜기의 바닥"입니다. 극소점에 가까워질수록 함수값이 감소하다가 극소점을 지나면서 증가로 바뀝니다. 도함수의 부호가 음($-$)에서 양($+$)으로 변하는 지점이 바로 극소점입니다.

극소값은 **국소적 최솟값**입니다. 전체 함수의 최솟값(최솟값)과는 다를 수 있습니다. 예를 들어 여러 개의 극소점이 있을 수 있고, 그중 어느 하나가 최솟값일 수도, 아닐 수도 있습니다.

## 한 줄 예

$f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로, $f'(x)$는 $x = -1$에서 음에서 양으로 바뀌어 $x = -1$에서 극소값 $f(-1) = 2$를 가집니다. (검증: `sympy.solve(3*x**2 - 3, x)` → $[-1, 1]$)
