# 함수의 실근

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
함수의 실근은 방정식 $f(x)=0$을 만족하는 실수 $x$값으로, 함수의 그래프가 $x$축과 만나는 점의 $x$좌표를 의미합니다.

## 본문
함수 $f(x)$의 실근이란 방정식 $f(x) = 0$을 만족하는 실수 $x$값을 의미합니다. 즉, $f(\alpha) = 0$을 성립하게 하는 모든 실수 $\alpha$를 함수 $f$의 실근이라 합니다. 실근의 개수는 $0$개 이상이며, 함수의 종류와 성질에 따라 결정됩니다.

### 직관과 기하적 의미
함수의 실근은 함수의 그래프가 $x$축과 만나는 점들의 $x$좌표로 이해할 수 있습니다. 그래프가 $x$축을 통과하거나 접하는 지점이 곧 실근이 되는 지점입니다.

### 기본 성질
도함수의 활용 관점에서 실근의 개수를 판정할 때는 함수의 극값(극댓값, 극솟값)과 극값에서의 함수값을 활용하는 것이 매우 중요합니다. 예를 들어, 삼차함수의 경우 극값을 가질 때 극댓값과 극솟값의 부호를 비교함으로써 실근의 개수를 정확히 파악할 수 있습니다. $f(x) = x^3 - 3x$의 사례를 보면, 도함수 $f'(x) = 3x^2 - 3$을 통해 극값의 위치를 $x = -1, 1$로 찾을 수 있습니다. 이때 극댓값 $f(-1) = 2$와 극솟값 $f(1) = -2$의 부호가 서로 반대이므로, 이 함수는 서로 다른 $3$개의 실근을 가집니다.

## 학습 체크
- 방정식 $f(x)=0$의 해가 모두 실수인지, 아니면 허수를 포함하는지 어떻게 구분하는가?
- 함수의 극값의 부호가 실근의 개수 판정에 어떤 영향을 미치는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증가와 감소, 극값의 위치를 파악하여 실근의 개수를 판정하는 핵심 도구로 사용됩니다.
