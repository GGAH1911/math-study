# 함수의 최솟값

## 정확한 진술

함수 $f$의 정의역을 $D$라 할 때, 어떤 $c \in D$에 대해

$$\text{모든 } x \in D \text{에서 } f(x) \geq f(c)$$

가 성립하면 $f$는 $x=c$에서 **최솟값** $f(c)$를 가진다고 합니다. 이를 **절댓값 최솟값(절대 최솟값)** 또는 **전역 최솟값**이라 합니다.

한편, $c$를 포함하는 어떤 열린 구간 $(c-\delta, c+\delta)$ 내에서 위 부등식이 성립하면, $f$는 $x=c$에서 **극솟값**을 가진다고 합니다. 극솟값은 국소적인 최솟값입니다.

## 직관/기하적 의미

함수의 그래프 위에서 최솟값은 가장 낮은 점의 $y$좌표입니다. 정의역이 폐구간 $[a, b]$이고 $f$가 연속함수이면, **최솟값은 항상 존재**하며 다음 세 곳 중 하나에서 발생합니다:

1. 극솟값을 가지는 내부 점 (도함수가 0이 되는 점)
2. 도함수가 존재하지 않는 점
3. 구간의 끝점 $a$ 또는 $b$

따라서 최솟값을 찾으려면 이 세 종류의 후보값들을 모두 계산한 후 가장 작은 값을 선택합니다.

## 한 줄 예

$f(x) = x^2 - 4x + 3 = (x-2)^2 - 1$은 $x=2$에서 최솟값 $-1$을 가집니다. (검증: `sympy.solve(sympy.diff(x**2 - 4*x + 3, x), x)` → $[2]$)
