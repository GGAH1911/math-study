# 도함수를 이용한 극값 판정

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
함수의 도함수가 $0$이 되는 지점 주변에서 도함수의 부호 변화나 이계도함수의 부호를 확인하여 극대와 극소를 판정합니다.

## 본문
함수 $f$가 $x = a$를 포함하는 구간에서 미분가능하고 $f'(a) = 0$일 때, 다음 조건으로 극값을 판정합니다.

**1차 도함수 판정법**
- $x = a$ 좌측에서 $f'(x) > 0$, 우측에서 $f'(x) < 0$이면 $f(a)$는 **극대**입니다.
- $x = a$ 좌측에서 $f'(x) < 0$, 우측에서 $f'(x) > 0$이면 $f(a)$는 **극소**입니다.
- $x = a$ 전후로 $f'(x)$의 부호가 변하지 않으면 극값이 아닙니다.

**2차 도함수 판정법**
$f'(a) = 0$일 때, $f''(a) \neq 0$이면 다음을 따릅니다.
- $f''(a) < 0$이면 $f(a)$는 **극대**입니다.
- $f''(a) > 0$이면 $f(a)$는 **극소**입니다.

예를 들어 $f(x) = x^3 - 3x$에서 $f'(x) = 3(x-1)(x+1) = 0$일 때, $x = -1$에서는 좌우 부호가 양에서 음으로 변하므로 극대값 $f(-1) = 2$를 갖고, $x = 1$에서는 좌우 부호가 음에서 양으로 변하므로 극소값 $f(1) = -2$를 갖습니다.

### 직관과 기하적 의미
극값 판정은 함수가 증가 또는 감소의 방향을 바꾸는 지점을 찾는 과정입니다. 1차 판정법은 도함수의 부호 변화를 추적합니다. 기울기가 양에서 음으로 바뀐다는 것은 함수가 올라가다가 내려가기 시작한다는 의미이므로 그 지점이 최고봉인 극대가 됩니다. 2차 판정법은 함수의 굽음 방향을 이용합니다. $f''(a) < 0$은 그래프가 위로 볼록한 모양임을 의미하여 극대가 되고, $f''(a) > 0$은 아래로 볼록한 모양임을 의미하여 극소가 됩니다.

### 기본 성질
- 극값은 반드시 $f'(x) = 0$인 지점에서 발생할 수 있으나, $f'(x) = 0$인 모든 지점이 극값인 것은 아닙니다.
- 2차 판정법은 $f''(a) = 0$인 경우에는 판정할 수 없으므로, 이럴 때는 1차 판정법을 사용해야 합니다.

## 학습 체크
- $f'(a) = 0$이지만 극값이 아닌 경우(예: $f(x) = x^3$의 $x=0$)를 구분할 수 있는가?
- 2차 판정법을 사용할 때 $f''(a)$의 부호가 의미하는 기하학적 모양을 이해하고 있는가?

## 관련 개념
- **도함수의 활용 심화**: 극값 판정법을 통해 함수의 그래프 개형을 그리고, 이를 바탕으로 함수의 최댓값과 최솟값을 찾는 문제로 확장됩니다.
