# 함수의 극값 조건

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
함수가 극값을 갖기 위해서는 도함수의 부호 변화가 필수적이며, 이는 삼차함수와 같은 다항함수에서 판별식을 통해 매개변수의 범위를 결정하는 핵심 조건이 됩니다.

## 본문
미분가능한 함수 $f(x)$가 극값을 갖는다는 것은 도함수 $f'(x)=0$을 만족하는 실근의 좌우에서 $f'(x)$의 부호가 변화함을 의미합니다. 즉, 함수가 극값을 가질 조건은 도함수가 부호를 바꾸는 실근을 갖는 것과 동치이며, 반대로 함수가 극값을 갖지 않으려면 도함수가 부호를 바꾸지 않아야 합니다. 이는 도함수의 그래프가 축을 통과하지 않고 접하거나 축 위에 머무는 상태를 의미합니다.

삼차함수 $f(x) = ax^3 + bx^2 + cx + d$ ($a \neq 0$)의 경우, 도함수는 이차함수 $f'(x) = 3ax^2 + 2bx + c$가 됩니다. 이때 삼차함수의 극값 존재 여부는 이차방정식 $f'(x)=0$의 판별식 $D = 4b^2 - 12ac$에 의해 결정됩니다. 판별식 $D > 0$이면 도함수가 서로 다른 두 실근을 가져 부호 변화가 발생하므로 극값을 두 개 갖게 되고, $D \le 0$이면 도함수가 부호를 바꾸지 않으므로 극값을 갖지 않는 단조 증가 또는 단조 감소 함수가 됩니다.

### 직관과 기하적 의미
함수의 그래프가 극값을 갖는다는 것은 그래프의 높낮이가 변하며 꺾이는 지점이 존재함을 의미합니다. 기하학적으로는 도함수의 그래프가 $x$축을 뚫고 지나가야 함을 뜻하며, 만약 도함수가 $x$축에 접하기만 한다면 함수는 계속 증가하거나 감소하는 형태를 유지하게 됩니다.

### 기본 성질
- $f$가 극값을 가짐 $\iff$ $f'(x) = 0$이 부호가 바뀌는 실근을 가짐.
- $f$가 극값을 갖지 않음 $\iff$ $f'(x)$가 부호를 바꾸지 않음.
- 삼차함수에서 극값이 두 개 존재하려면 도함수의 판별식이 양수여야 함.

## 학습 체크
- 도함수의 실근이 존재하더라도 왜 반드시 극값이 되는 것은 아닌가요?
- 삼차함수가 극값을 갖지 않기 위한 조건이 왜 판별식 $D \le 0$인가요?
- $f'(x)=0$의 중근을 가질 때 함수의 그래프는 어떤 형태를 띠게 되나요?
