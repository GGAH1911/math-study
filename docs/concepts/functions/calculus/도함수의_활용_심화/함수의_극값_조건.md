# 함수의 극값 조건

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

함수가 지정된 개수의 극값을 가지거나 특정 점에서 극값을 갖도록 매개변수를 정하는 문제에서 사용하는 조건입니다. 미적분 도함수 활용에서 매개변수 결정의 핵심 도구입니다.

## 정의

미분가능한 함수 $f(x)$의 극값은 $f'(x) = 0$의 실근 중 그 좌우에서 $f'$의 부호가 바뀌는 점에서 나타납니다. 따라서 다음과 같은 동치 조건이 성립합니다.
- $f$가 극값을 가짐 $\iff$ $f'(x) = 0$이 부호가 바뀌는 실근을 가짐.
- $f$가 극값을 갖지 않음 $\iff$ $f'(x)$가 부호를 바꾸지 않음(예: 항상 같은 부호 또는 중근).

삼차함수 $f(x) = ax^3 + bx^2 + cx + d$ ($a \neq 0$)의 경우, $f'(x) = 3ax^2 + 2bx + c$의 판별식 $D = 4b^2 - 12ac$에 대해
- $D > 0$: 극값 두 개,
- $D \le 0$: 극값을 갖지 않음(단조).

## 예시

$f(x) = x^3 + ax^2 + 3x$가 극값을 갖지 않도록 하는 $a$의 범위를 구해 봅니다. $f'(x) = 3x^2 + 2ax + 3$의 판별식이 $0$ 이하이면 됩니다. $D/4 = a^2 - 9 \le 0$이므로 $-3 \le a \le 3$.
