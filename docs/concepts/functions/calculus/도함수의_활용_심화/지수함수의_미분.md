# 지수함수의 미분

## 정확한 진술

지수함수 $f(x) = a^x$ (단, $a > 0, a \neq 1$)의 도함수는 다음과 같이 정의됩니다.
$$f'(x) = a^x \ln a$$

여기서 $\ln a$는 $a$의 자연로그(밑이 $e$인 로그)입니다. 특히 중요한 특수한 경우는 자연지수함수입니다.
$$f(x) = e^x \implies f'(x) = e^x$$

이 경우 $\ln e = 1$이므로 도함수가 원래 함수와 정확히 같습니다.

## 직관/기하적 의미

지수함수의 미분 공식은 "함수의 기울기가 함숫값에 비례한다"는 놀라운 특성을 나타냅니다. 곡선의 어느 점에서든 접선의 기울기는 그 점의 함숫값에 상수 $\ln a$를 곱한 값입니다. 밑이 클수록 $\ln a$가 커져 함수가 더 가파르게 상승합니다. 자연지수함수는 비례상수가 정확히 1이 되어 "자신의 속도로 증가하는" 가장 자연스러운 지수 성장을 표현합니다. 이것이 실제 인구 증가, 방사능 붕괴, 금융 복리 등 자연현상에 자주 나타나는 이유입니다.

## 한 줄 예

$f(x) = 3^x$이면 $f'(x) = 3^x \ln 3$이므로, $x=1$에서 접선의 기울기는 $3 \ln 3 \approx 3.296$입니다. (검산: `3 * ln(3)` ≈ 3.296)
