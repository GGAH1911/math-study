# 구간별 최솟값 함수

## 정확한 진술

구간별 최솟값 함수는 다음과 같이 정의됩니다. 주어진 함수 $f(x)$와 매개변수 $t$에 대해, 폐구간 $[t, t+a]$ (단, $a > 0$는 고정된 상수)에서 $f(x)$의 최솟값을 $m(t)$라 하면,

$$m(t) = \min_{t \le x \le t+a} f(x)$$

를 구간별 최솟값 함수라 합니다. 여기서 $t$는 구간의 왼쪽 끝점이며, 구간의 위치가 변함에 따라 최솟값도 매개변수 $t$의 함수로 표현됩니다.

## 직관과 기하적 의미

$m(t)$는 길이 $a$인 "슬라이딩 윈도우"를 함수 그래프 위에서 오른쪽으로 밀어 옮길 때, 각 위치에서 포착하는 최솟값들을 모은 함수입니다. 도함수를 활용하면, 각 구간 내에서 최솟값이 구간의 끝점(경계)에서 달성되는지, 아니면 내부의 극값점에서 달성되는지 판단할 수 있습니다. 이는 구간 위치에 따라 최솟값을 결정하는 "우승자"가 바뀌는 지점을 찾는 데 핵심입니다.

## 한 줄 예

$f(x) = x^2 - 4x + 5$에서 길이 2인 구간 $[t, t+2]$의 최솟값 함수를 구하면: $f'(x) = 2(x-2) = 0$이므로 극솟값은 $x=2$입니다. $t \le 2 \le t+2$ (즉, $0 \le t \le 2$)이면 $m(t) = f(2) = 1$이고, $t > 2$이면 $m(t) = f(t) = t^2 - 4t + 5$입니다.
