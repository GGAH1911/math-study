# 구간별 최솟값 함수

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 요약
주어진 함수에서 고정된 길이의 구간을 이동시키며 각 위치에서의 최솟값을 추적하여 나타낸 함수입니다.

## 본문
주어진 함수 $f(x)$와 고정된 양수 상수 $a$에 대하여, 폐구간 $[t, t+a]$에서 $f(x)$의 최솟값을 $m(t)$라고 정의할 때, $m(t) = \min_{t \le x \le t+a} f(x)$를 구간별 최솟값 함수라 합니다. 여기서 매개변수 $t$는 구간의 왼쪽 끝점을 의미하며, 구간이 오른쪽으로 이동함에 따라 구간 내에서 함수가 갖는 최솟값의 변화를 $t$에 대한 함수로 나타낸 것입니다.

### 직관과 기하적 의미
$m(t)$는 길이 $a$인 "슬라이딩 윈도우"를 함수 그래프 위에서 오른쪽으로 밀어 옮길 때, 각 위치에서 포착하는 최솟값들을 모은 함수입니다. 도함수를 활용하면, 각 구간 내에서 최솟값이 구간의 경계(끝점)에서 발생하는지, 혹은 구간 내부의 극값점에서 발생하는지를 판단할 수 있습니다. 이는 구간의 위치에 따라 최솟값을 결정하는 지점이 바뀌는 변곡점을 찾는 과정과 같습니다.

### 기본 성질
함수 $f(x) = x^2 - 4x + 5$를 예로 들면, 극솟값은 $x=2$에서 $1$을 갖습니다. 길이 $a=2$인 구간 $[t, t+2]$를 고려할 때, 구간 내에 극점 $x=2$가 포함되는 $0 \le t \le 2$ 범위에서는 $m(t) = 1$이 됩니다. 반면, 구간이 극점을 벗어나는 $t > 2$ 범위에서는 구간의 왼쪽 끝점인 $f(t)$가 최솟값이 되어 $m(t) = t^2 - 4t + 5$가 됩니다.

## 학습 체크
- 구간의 길이 $a$가 변할 때 최솟값 함수의 연속성과 미분 가능성은 어떻게 변하는가?
- 구간 내에서 최솟값을 결정하는 지점이 구간의 끝점일 때와 내부의 극값점일 때의 조건은 무엇인가?

## 관련 개념
- **도함수의 활용 심화**: 구간 내 최솟값이 발생하는 지점이 구간의 경계인지 내부의 극점인지를 판별하여 함수의 미분 가능성을 분석하는 데 활용됩니다.
