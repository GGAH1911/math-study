# 원점을 지나는 접선

> **정의** · 미적분 · 단원: [도함수의 활용 심화](/concepts/도함수의_활용_심화)

## 정확한 진술

함수 $y = f(x)$의 그래프 위의 한 점 $(a, f(a))$에서의 접선이 **원점을 지나는 접선**입니다. 이는 도함수를 이용해 다음과 같이 표현됩니다:

점 $(a, f(a))$에서의 접선의 방정식은 $y - f(a) = f'(a)(x - a)$입니다. 이 접선이 원점 $(0, 0)$을 지나면:

$$0 - f(a) = f'(a)(0 - a)$$

정리하면:

$$f(a) = a \cdot f'(a)$$

이 식을 만족하는 $a$를 찾으면, 점 $(a, f(a))$에서의 접선이 원점을 지나갑니다.

## 직관과 기하적 의미

기하학적으로 원점을 지나는 접선은 **원점에서 곡선을 "스치고 지나가는" 직선**입니다. 이는 다음을 의미합니다:
- 접선은 곡선의 특정 점에서 곡선과 맞닿아 있고 (접함)
- 동시에 원점을 통과합니다

이 조건은 $f(a) = a \cdot f'(a)$라는 하나의 방정식으로 축약되므로, 일반적으로 유한 개의 점에서만 이런 접선이 존재합니다. 이는 함수의 형태를 파악하고, 최댓값·최솟값 문제나 기울기 분석 문제에서 자주 활용됩니다.

## 한 줄 예

$f(x) = x^2 - 2x + 2$일 때, 점 $(1, 1)$에서의 접선은 $y = 0 \cdot x + 1$... (계산: $f'(1) = 2(1) - 2 = 0$이므로 수평선) — 원점을 지나지 않습니다.

대신 $f(x) = x^2 + 2x$인 경우, 점 $(1, 3)$에서 $f(1) = 3$, $f'(1) = 4$이고, 조건 확인: $3 = 1 \times 4$? (거짓) — 계산으로 정확한 점을 찾으면 조건 $f(a) = a \cdot f'(a)$를 푸는 것이 핵심입니다. (sympy: `solve(a**2 + 2*a - a*(2*a + 2), a)`)
