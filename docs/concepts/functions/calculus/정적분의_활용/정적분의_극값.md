# 정적분의 극값

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
적분함수 $F(x) = \int_a^x f(t) \, dt$의 극값은 피적분함수 $f(x)$의 부호가 바뀌는 지점에서 발생하며, 이는 누적 넓이의 증감이 전환되는 순간을 의미합니다.

## 본문
적분함수 $F(x) = \int_a^x f(t) \, dt$가 점 $x = c$에서 극값을 갖는다는 것은 미적분학의 기본정리에 의해 $F'(c) = f(c) = 0$을 만족하며, 동시에 $x = c$를 기준으로 $f(x)$의 부호가 변화해야 함을 의미합니다. 즉, 적분함수의 극값 판정은 피적분함수의 부호 변화를 조사함으로써 결정됩니다.

### 직관과 기하적 의미
적분값 $F(x)$는 $a$부터 $x$까지 곡선 아래의 부호가 있는 넓이를 나타냅니다. $f(t) > 0$인 구간에서는 넓이가 계속 더해지므로 $F(x)$는 증가하고, $f(t) < 0$인 구간에서는 넓이가 차감되므로 $F(x)$는 감소합니다. 따라서 $F(x)$의 극댓값은 양수 영역에서 음수 영역으로 부호가 바뀌는 지점에서 나타나며, 극솟값은 음수 영역에서 양수 영역으로 부호가 바뀌는 지점에서 나타납니다. 이는 누적된 넓이의 증가와 감소가 교차하는 지점을 찾는 것과 같습니다.

### 기본 성질
- $f(c) = 0$이지만 $f(x)$의 부호가 변하지 않으면 $F(x)$는 극값을 갖지 않습니다.
- $F(x)$의 극값 위치는 $f(x)$의 $x$축 통과 지점(부호 변화 지점)과 일치합니다.

## 학습 체크
- $f(c) = 0$일 때, $F(x)$가 극값을 갖기 위해 반드시 확인해야 할 조건은 무엇인가요?
- $f(x)$의 부호가 양수에서 음수로 변할 때, $F(x)$는 극대인가요, 극소인가요?
- 적분함수의 그래프에서 극값이 나타나는 지점의 기하학적 의미는 무엇인가요?

## 관련 개념
- **정적분의 활용**: 정적분을 통해 구한 넓이 함수의 변화율을 분석하여 함수의 증가와 감소를 파악하고 극값을 찾는 데 사용됩니다.
