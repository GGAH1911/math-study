# 두 곡선 넓이 예제

> **예제** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
두 곡선 $y=x$와 $y=x^2$으로 둘러싸인 영역의 넓이를 구하는 과정입니다.

## 본문
$y=x$와 $y=x^2$으로 둘러싸인 영역의 넓이를 구하시오.

### 단계별 풀이
**1단계: 두 곡선의 교점 구하기**  
두 곡선이 만나는 점을 찾기 위해 $x = x^2$ 방정식을 풉니다. $x^2 - x = 0$에서 $x(x-1) = 0$이므로 $x=0$ 또는 $x=1$입니다. 이 값들이 적분 구간의 경계가 됩니다.

**2단계: 어느 곡선이 위에 있는지 확인**  
$0 < x < 1$ 구간에서 $x=0.5$를 대입하면 $y=x$는 $0.5$, $y=x^2$은 $0.25$입니다. 따라서 $y=x$가 $y=x^2$보다 위쪽에 위치합니다.

**3단계: 정적분 세우기**  
두 곡선 사이의 넓이는 위에 있는 함수에서 아래에 있는 함수를 뺀 식을 적분하여 구합니다.
$$S = \int_0^1 (x - x^2) \, dx$$

**4단계: 적분 계산**  
부정적분은 $\frac{x^2}{2} - \frac{x^3}{3}$이며, 정적분 값을 계산하면 다음과 같습니다.
$$S = \left[ \frac{x^2}{2} - \frac{x^3}{3} \right]_0^1 = \left( \frac{1}{2} - \frac{1}{3} \right) - 0 = \frac{1}{6}$$

### 답과 변형
$$\frac{1}{6}$$

- **부호 주의**: 넓이는 항상 양수여야 하므로 반드시 (위의 함수) $-$ (아래의 함수) 순서로 계산해야 합니다.
- **교점 확인**: 적분 구간을 결정하는 교점을 정확히 찾는 것이 문제 해결의 핵심입니다.
- **구간 분할**: 세 개 이상의 곡선이 만날 때는 교점을 기준으로 적분 구간을 나누어 각각 계산해야 합니다.

## 학습 체크
- 두 곡선의 교점을 이용해 적분 구간을 정확히 설정할 수 있는가?
- 구간 내에서 어떤 함수가 상단에 위치하는지 판단할 수 있는가?
- 곡선이 여러 개일 때 구간을 나누어 넓이를 합산할 수 있는가?

## 관련 개념
- **정적분의 활용**: 정적분을 이용하여 곡선과 축, 또는 두 곡선 사이의 넓이를 구하는 원리를 배웁니다.
