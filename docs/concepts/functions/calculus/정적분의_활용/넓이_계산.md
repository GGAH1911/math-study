# 넓이 계산

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
좌표평면에서 곡선과 축 또는 곡선 사이의 넓이는 정적분의 절댓값을 이용하여 계산합니다.

## 본문
좌표평면에서 곡선으로 둘러싸인 도형의 넓이는 정적분을 통해 계산할 수 있습니다. 곡선 $y = f(x)$와 $x$축, 그리고 두 수직선 $x = a$, $x = b$로 둘러싸인 영역의 넓이는 $S = \int_a^b |f(x)| \, dx$로 정의됩니다. 만약 두 곡선 $y = f(x)$와 $y = g(x)$가 구간 $[a, b]$에서 $f(x) \geq g(x)$를 만족하며 둘러싸인 영역의 넓이를 구하고자 한다면, $S = \int_a^b (f(x) - g(x)) \, dx$를 이용합니다. 이처럼 절댓값이나 두 함수의 차를 사용하는 이유는 넓이가 항상 양수의 값을 가져야 하기 때문입니다.

### 직관과 기하적 의미
이 정의는 구간 $[a, b]$를 매우 좁은 직사각형 띠로 나누어 그 넓이들을 합한 뒤, 너비가 $0$으로 수렴하도록 만드는 리만 합의 극한으로 이해할 수 있습니다. 곡선이 $x$축의 위와 아래를 번갈아 지나가는 경우에는 구간을 나누어 위쪽 곡선에서 아래쪽 곡선을 빼는 방식으로 계산하거나, 함수에 절댓값을 씌워 모든 영역을 양수로 변환하여 합산함으로써 기하학적으로 의미 있는 넓이를 얻습니다.

### 기본 성질
- 곡선이 $x$축 아래에 있는 구간에서는 함수값에 마이너스를 붙여 양수로 만듭니다.
- 두 곡선 사이의 넓이를 구할 때는 항상 위쪽에 있는 함수에서 아래쪽에 있는 함수를 뺍니다.

## 학습 체크
- 곡선이 $x$축을 통과하여 위아래로 나뉘는 경우, 적분 구간을 어떻게 나누어 계산해야 하는가?
- 두 곡선 사이의 넓이를 구할 때, 어떤 함수가 더 위에 있는지 판단하는 방법은 무엇인가?

## 관련 개념
- **좌표평면과 그래프**: 곡선이 그려지는 공간적 배경이 되며, 함수의 높낮이를 통해 넓이 계산의 기준을 제공합니다.
- **정적분**: 구간 내의 함수값의 누적된 합을 구하는 도구로, 넓이를 계산하는 핵심적인 수학적 수단입니다.
