# 거리와 적분

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
물체의 속도함수 $v(t)$에 대하여 변위는 속도함수의 정적분으로, 거리는 속도함수의 절댓값의 정적분으로 정의됩니다.

## 본문
시간 구간 $[a, b]$에서 물체의 속도함수를 $v(t)$라 할 때, 물체가 실제로 움직인 총 거리(distance)는 다음 정적분으로 정의됩니다.
$$\text{거리} = \int_a^b |v(t)| \, dt$$
만약 속도가 구간 내에서 항상 양수라면 절댓값을 생략할 수 있습니다. 이때 절댓값을 제외한 $\int_a^b v(t) \, dt$는 변위(displacement)라고 하며, 이는 방향을 고려하여 시작점과 끝점 사이의 순 이동거리를 나타냅니다.

### 직관과 기하적 의미
$v(t)$를 $t$축 위의 곡선으로 나타냈을 때, 정적분 $\int_a^b v(t) \, dt$는 곡선과 $t$축 사이의 넓이를 부호를 포함하여 계산한 값입니다. $v(t) > 0$인 구간은 정방향 운동을, $v(t) < 0$인 구간은 역방향 운동을 의미합니다.
- **변위**: 양의 방향 이동과 음의 방향 이동이 서로 상쇄된 결과로, 처음 위치와 나중 위치의 차이를 나타냅니다.
- **거리**: 방향에 상관없이 움직인 궤적의 총합으로, 음수 영역의 넓이를 절댓값으로 변환하여 모두 더한 값입니다.

예를 들어 물체가 앞으로 5m 이동한 후 뒤로 3m 이동했다면, 변위는 $5 - 3 = 2\text{m}$이고 거리는 $5 + 3 = 8\text{m}$가 됩니다.

### 기본 성질
속도함수 $v(t) = 3t - 6$일 때, $t=0$부터 $t=4$까지의 변화를 살펴보면 다음과 같습니다.
- **변위**: $\int_0^4 (3t-6) \, dt = [1.5t^2 - 6t]_0^4 = 0\text{m}$
- **거리**: $v(t)=0$인 지점인 $t=2$를 기준으로 구간을 나누어 계산합니다.
$$\int_0^2 |3t-6| \, dt + \int_2^4 |3t-6| \, dt = 6 + 6 = 12\text{m}$$

- 속도함수가 항상 0보다 크거나 같다면 변위와 거리는 어떤 관계를 갖나요?

## 관련 개념
- **도함수의 활용 심화**: 위치함수를 미분하면 속도함수가 되고, 속도함수를 적분하면 위치의 변화량인 변위를 구할 수 있다는 미분과 적분의 관계를 다룹니다.
