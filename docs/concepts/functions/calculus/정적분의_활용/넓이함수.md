# 넓이함수

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
함수 $f(x)$가 구간 $[a, b]$에서 연속일 때, 하한 $a$를 기준으로 상한을 $x$로 하여 정의된 정적분 $F(x) = \int_a^x f(t) \, dt$를 넓이함수라고 합니다.

## 본문
함수 $f(x)$가 구간 $[a, b]$에서 연속일 때, 고정된 점 $a$를 하한으로 하여 상한을 변수 $x$로 하는 정적분 $F(x) = \int_a^x f(t) \, dt \quad (a \le x \le b)$를 함수 $f$의 넓이함수 또는 적분함수라고 합니다.

### 직관과 기하적 의미
$x$축 위의 점이 $a$에서 시작하여 오른쪽으로 이동할 때, 곡선 $y = f(t)$ 아래의 넓이(부호를 포함한)가 어떻게 변하는지를 나타내는 함수입니다. $x$가 $\Delta x$ 만큼 증가하면 넓이는 약 $f(x) \cdot \Delta x$ 만큼 변하므로, 넓이함수의 도함수는 원래 함수 $f(x)$가 됩니다. 즉, $F'(x) = f(x)$이며, 이것이 미적분학의 기본정리의 첫 번째 부분입니다.

### 기본 성질
$f(x) = 2x$이고 $a = 0$일 때, 넓이함수는 $F(x) = \int_0^x 2t \, dt = x^2$입니다. 실제로 $F'(x) = 2x = f(x)$를 확인할 수 있어 정의가 일관성 있게 작동함을 알 수 있습니다. 예를 들어 $x = 3$일 때 $F(3) = 9$는 $0$에서 $3$ 사이의 삼각형 넓이를 의미합니다.

## 학습 체크
- $F(x)$의 도함수가 원래 함수 $f(x)$와 같아지는 원리를 미분계수의 정의를 이용하여 설명할 수 있는가?
- 적분 구간의 상한이 변수 $x$로 주어졌을 때, $F(a)$의 값은 항상 $0$이 되는가?

## 관련 개념
- **도함수의 활용 심화**: 넓이함수의 도함수가 원래 함수가 된다는 성질을 이용하여, 복잡한 형태의 함수를 미분하거나 적분하는 과정을 연결할 수 있습니다.
