# 거리와 변위

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 정확한 진술

시각 $t = a$에서 $t = b$까지 물체가 직선 위에서 움직일 때, 속도가 $v(t)$라고 하면:

**변위(displacement)**는 $\displaystyle s = \int_a^b v(t) \, dt$

**거리(distance)**는 $\displaystyle d = \int_a^b |v(t)| \, dt$

변위는 초기 위치에서 최종 위치까지의 순 이동을 나타내고, 거리는 이동 경로의 길이를 모두 더한 값입니다.

## 직관/기하적 의미

**변위**는 $v(t)$의 그래프 아래 넓이를 **부호를 포함해** 계산합니다. $v(t) > 0$일 때는 양의 넓이, $v(t) < 0$일 때는 음의 넓이로 취급되어, 최종적으로 순 이동만 남습니다. 예를 들어 오른쪽으로 100m 갔다가 왼쪽으로 80m 돌아오면 변위는 +20m입니다.

**거리**는 $|v(t)|$의 그래프 아래 넓이를 계산하므로, 속도의 방향과 관계없이 **항상 양수**입니다. 위 예에서 거리는 100m + 80m = 180m입니다.

## 한 줄 예

물체의 속도가 $v(t) = t - 2$ (초, 시간 $t=0$부터 $t=5$까지)일 때:

- 변위: $\displaystyle \int_0^5 (t-2) \, dt = \left[\frac{t^2}{2} - 2t\right]_0^5 = \frac{25}{2} - 10 = \frac{5}{2}$ (m)
- 거리: $v(t) = 0$인 점은 $t=2$이므로
  $$\int_0^2 |t-2| \, dt + \int_2^5 |t-2| \, dt = \int_0^2 (2-t) \, dt + \int_2^5 (t-2) \, dt = 2 + \frac{9}{2} = \frac{13}{2} \text{ (m)}$$

변위는 최종 위치만 고려하지만, 거리는 돌아온 경로까지 모두 계산됩니다. `sympy.integrate(abs(t-2), (t, 0, 5))` 로 검산 가능합니다.
