# 거리와 변위

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
변위는 위치의 변화량을 나타내는 정적분 값이며, 거리는 이동한 경로의 총 길이를 나타내는 속력의 정적분 값입니다.

## 본문
시각 $t = a$에서 $t = b$까지 물체가 직선 위에서 움직일 때, 속도가 $v(t)$라고 하면 변위(displacement)는 $\displaystyle s = \int_a^b v(t) \, dt$로 정의하며, 거리(distance)는 $\displaystyle d = \int_a^b |v(t)| \, dt$로 정의합니다. 변위는 물체의 초기 위치와 최종 위치 사이의 순수한 위치 변화를 나타내는 반면, 거리는 물체가 움직인 경로의 전체 길이를 모두 합산한 값입니다.

### 직관과 기하적 의미
변위는 속도 함수 $v(t)$의 그래프 아래 면적을 계산할 때 부호를 포함하여 계산합니다. 즉, $v(t) > 0$인 구간은 양의 넓이로, $v(t) < 0$인 구간은 음의 넓이로 취급하여 모두 더합니다. 따라서 물체가 앞으로 갔다가 뒤로 돌아온 경우, 서로 반대 방향의 움직임이 상쇄되어 최종적인 위치 변화량만 남게 됩니다. 반면 거리는 속력 $|v(t)|$의 그래프 아래 면적을 계산하므로, 운동 방향에 관계없이 항상 양수의 값을 가지며 이동한 모든 경로를 누적하여 나타냅니다.

### 기본 성질
- 변위는 운동 방향이 바뀌어도 최종 위치에 따라 값이 결정되지만, 거리는 방향 전환과 상관없이 항상 증가하는 성질을 갖습니다.
- 속도 $v(t)$가 $0$이 되는 지점을 기준으로 구간을 나누어 적분하면 거리를 구할 수 있습니다.
- 물체가 한 방향으로만 움직인다면 변위의 절댓값과 거리는 동일합니다.

## 학습 체크
- 속도 함수 $v(t)$의 부호가 바뀌는 지점을 정확히 찾아 구간을 나누어 적분하였는가?
- 변위의 결과값이 음수로 나왔을 때, 이것이 운동 방향의 반대를 의미함을 이해하고 있는가?

## 관련 개념
- **정적분의 활용**: 정적분을 이용하여 속도 함수로부터 위치의 변화량이나 이동 거리를 계산하는 구체적인 방법론을 다룹니다.
