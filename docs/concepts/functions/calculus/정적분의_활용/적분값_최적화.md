# 적분값 최적화

## 정확한 진술

적분값 최적화는 정적분으로 표현된 함수의 값을 최대 또는 최소화하는 문제를 말합니다. 일반적으로 정적분 $\int_a^b f(t) \, dt$ 형태의 값이 변수(예: 상한, 하한, 함수의 계수)에 따라 어떻게 변하는지 분석하고, 그 극값을 구하는 과정입니다.

더 정확히는, 적분 구간, 피적분함수, 또는 이들과 연관된 매개변수가 변할 때, 적분값 자체를 최대/최소화하는 조건을 찾는 것입니다.

## 직관과 기하적 의미

도함수의 성질을 활용하면, 적분값의 극값을 찾을 수 있습니다. 정적분 $I(x) = \int_a^x f(t) \, dt$를 $x$에 대해 미분하면 $\frac{dI}{dx} = f(x)$이므로, 임계점은 $f(x) = 0$인 점입니다.

기하학적으로 생각하면:
- 곡선 $y = f(x)$와 $x$축 사이의 **넓이**를 최대/최소화하려 할 때
- 또는 구간이 이동하면서 변하는 넓이의 극값을 구할 때

적분값이 극값을 가지려면, 적분값을 어떤 변수로 미분했을 때 0이 되어야 합니다.

## 예시

곡선 $y = x(4-x)$와 $x$축으로 둘러싼 영역에서, 구간 $[0, t]$ ($0 < t < 4$)에 대한 적분값 $I(t) = \int_0^t x(4-x) \, dx$의 최댓값을 구하세요.

먼저 $I(t) = \int_0^t (4x - x^2) \, dx = \left[2x^2 - \frac{x^3}{3}\right]_0^t = 2t^2 - \frac{t^3}{3}$

극값을 구하려면: $\frac{dI}{dt} = 4t - t^2 = t(4-t) = 0$

$0 < t < 4$ 범위에서 $t = 4$는 경계이므로, 극대값은 사실 $t = 4$일 때 전체 넓이입니다. 하지만 $t \in (0,4)$에서 극값을 원한다면, $\frac{d^2I}{dt^2} = 4 - 2t$를 확인하여 최적점을 판별합니다.

*sympy 검산: `sympy.diff(2*t**2 - t**3/3, t)` → $4t - t^2$*
