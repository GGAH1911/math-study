# 교점의 활용

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 정확한 진술

두 곡선 $y = f(x)$와 $y = g(x)$의 **교점**은 방정식 $f(x) = g(x)$의 해입니다. 정적분의 활용에서 교점은 넓이를 계산하는 **구간을 결정하는 핵심**이 됩니다. 두 곡선 사이의 넓이 $\int_a^b |f(x) - g(x)| dx$를 구할 때, 교점의 $x$좌표들이 적분 상한과 하한이 되기 때문입니다.

## 직관/기하적 의미

좌표평면에서 두 곡선이 만나는 점이 교점입니다. 교점을 찾는 것은 두 함수값이 정확히 같아지는 순간을 찾는 것이고, 이것이 "넓이가 바뀌는 경계"가 됩니다. 예를 들어 포물선 $y = x^2$과 직선 $y = 2x$가 만나는 순간, 어느 곡선이 위에 있는지가 바뀌므로, 교점을 기준으로 적분을 나누어야 합니다. 교점을 놓치면 음수 넓이를 더하거나 뺄 수 있으므로 정확한 답을 얻을 수 없습니다.

## 한 줄 예

$y = x^2$과 $y = 2x$의 교점은 $x^2 = 2x$에서 $x = 0, 2$이고, 이 구간에서 두 곡선이 이루는 넓이는 $\int_0^2 (2x - x^2) dx = \left[ x^2 - \frac{x^3}{3} \right]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}$입니다.
