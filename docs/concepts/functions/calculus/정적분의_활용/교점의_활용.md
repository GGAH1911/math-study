# 교점의 활용

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
두 곡선의 교점은 방정식의 해로서, 정적분을 이용해 두 곡선 사이의 넓이를 구할 때 적분 구간을 결정하는 경계 역할을 합니다.

## 본문
두 곡선 $y = f(x)$와 $y = g(x)$의 교점은 방정식 $f(x) = g(x)$의 해로 정의됩니다. 정적분의 활용 측면에서 교점은 두 곡선 사이의 넓이를 계산하기 위한 적분 구간을 결정하는 핵심적인 요소입니다. 두 곡선 사이의 넓이 $\int_a^b |f(x) - g(x)| dx$를 구할 때, 교점의 $x$좌표들이 적분 상한과 하한이 되기 때문입니다.

### 직관과 기하적 의미
좌표평면에서 두 곡선이 만나는 점이 교점입니다. 교점을 찾는 과정은 두 함수의 값이 정확히 일치하는 순간을 찾는 것이며, 이는 기하학적으로 "넓이의 계산 방식이 바뀌는 경계"를 의미합니다. 예를 들어 포물선 $y = x^2$과 직선 $y = 2x$가 만나는 지점에서는 어느 곡선이 위쪽에 위치하는지가 결정됩니다. 만약 교점을 정확히 찾아 구간을 나누지 않으면, 넓이가 아닌 음수 값이 포함된 잘못된 계산 결과가 나올 수 있습니다.

### 기본 성질
- 두 곡선의 교점의 $x$좌표는 방정식 $f(x) = g(x)$의 실근과 일치한다.
- 두 곡선 사이의 넓이를 구할 때, 교점은 적분 구간을 나누는 기준점이 된다.
- 교점을 기준으로 함수 간의 대소 관계($f(x) \ge g(x)$ 또는 $f(x) \le g(x)$)가 변할 수 있다.

## 학습 체크
- 두 곡선이 만나는 지점의 $x$좌표를 구하기 위해 어떤 방정식을 세워야 하는가?
- 교점이 여러 개일 경우, 적분 구간을 어떻게 나누어 계산해야 하는가?
- 교점을 찾지 못했을 때 발생할 수 있는 계산상의 오류는 무엇인가?

## 관련 개념
- **정적분의 활용**: 교점의 $x$좌표를 적분 구간으로 설정하여 두 곡선 사이의 넓이를 구하는 데 사용됩니다.
