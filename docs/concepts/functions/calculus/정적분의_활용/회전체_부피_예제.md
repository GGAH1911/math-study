# 회전체 부피 예제

> **예제** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
$y=\sqrt x$를 $x$축 중심으로 회전시킨 회전체의 부피를 구하는 과정입니다.

## 본문
$y = \sqrt{x}$ ($0 \le x \le 4$)의 그래프를 $x$축 중심으로 회전시킨 회전체의 부피를 구하세요.

### 단계별 풀이
**1단계: 공식 확인**
$x$축 중심으로 회전시킨 회전체의 부피는 다음 공식을 사용합니다:
$$V = \pi \int_a^b [f(x)]^2 \, dx$$

**2단계: 반지름 함수 결정**
$x$축 위의 한 점 $x$에서 곡선 $y = \sqrt{x}$까지의 거리인 $r(x) = \sqrt{x}$가 회전체의 반지름이 됩니다.

**3단계: 적분 설정**
$$V = \pi \int_0^4 (\sqrt{x})^2 \, dx = \pi \int_0^4 x \, dx$$

**4단계: 계산**
$$\int_0^4 x \, dx = \left[ \frac{x^2}{2} \right]_0^4 = 8$$
따라서 $V = 8\pi$입니다.

### 답과 변형
$$V = 8\pi$$
수치로는 약 $25.13$입니다.

**변형 및 주의사항**
- **$y$축 중심 회전**: 원통각법을 사용하거나, $x = y^2$으로 역함수를 이용해 $V = \pi \int_0^2 (4 - y^4) \, dy$로 계산할 수 있습니다.
- **구간 변화**: 적분 구간이 $0 \le x \le 1$로 바뀌면 부피는 $\tfrac{\pi}{2}$가 됩니다.
- **주의점**: 반지름은 함수값 자체이며, 반드시 제곱 후 적분해야 합니다.

## 관련 개념
- **정적분의 활용**: 정적분을 이용하여 곡선과 축 사이의 넓이뿐만 아니라 회전체의 부피를 계산하는 데 활용됩니다.
