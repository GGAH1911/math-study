### 정확한 진술
시간 $t$에 따른 속도함수 $v(t)$가 구간 $[a, b]$에서 주어질 때, 물체가 이동한 거리는 정적분으로 정의됩니다:
$$s = \int_a^b |v(t)| \, dt$$

여기서 $|v(t)|$는 속도의 절댓값입니다. 구간 전체에서 $v(t) \geq 0$이면 절댓값을 생략할 수 있습니다:
$$s = \int_a^b v(t) \, dt$$

### 직관/기하적 의미
속도-시간 그래프에서 곡선과 시간축 사이의 넓이가 이동 거리를 나타냅니다. 미적분학 기본정리에 의해 거리를 시간으로 미분하면 속도이므로, 역으로 속도를 시간에 대해 적분하면 거리를 얻습니다. 미소시간 $dt$ 동안의 미소거리는 $ds = v(t) dt$이고, 이를 모든 구간에서 합산하는 과정이 정적분입니다. 속도가 음수인 구간(역방향 이동)이 있을 때는 절댓값을 사용하여 실제 이동한 거리를 정확히 계산합니다.

### 한 줄 예
속도가 $v(t) = 2t$ m/s일 때, $t = 0$부터 $t = 3$까지 이동한 거리는 $\int_0^3 2t \, dt = 9$ m입니다. (검증: `from sympy import symbols, integrate; t = symbols('t'); integrate(2*t, (t, 0, 3))`)
