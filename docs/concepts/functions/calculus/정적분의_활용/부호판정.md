### 정확한 진술

함수 $f(x)$가 구간 $(a, b)$에서 미분가능할 때, 도함수 $f'(x)$의 부호를 조사하여 함수의 증감을 판정하는 것을 **부호판정**이라 합니다. 구체적으로:

- $f'(x) > 0$인 구간에서 $f(x)$는 증가함수
- $f'(x) < 0$인 구간에서 $f(x)$는 감소함수  
- $f'(x) = 0$이 되는 점을 **임계점(critical point)**이라 하며, 극값의 후보가 됩니다.

### 직관과 기하적 의미

도함수 $f'(x)$는 각 점에서 함수 $f(x)$의 그래프에 그은 접선의 기울기입니다. 기울기가 양수면 그래프가 오른쪽으로 갈수록 올라가고 있고, 음수면 내려가고 있습니다. 부호판정은 이 기울기 정보를 체계적으로 추적하여 함수 전체의 개형을 알아내는 과정입니다. 특히 임계점 앞뒤로 $f'(x)$의 부호가 어떻게 바뀌는지 살피면, 극댓값과 극솟값이 어디에 위치하는지 정확히 파악할 수 있습니다.

### 한 줄 예

$f(x) = x^3 - 3x^2$에서 $f'(x) = 3x^2 - 6x = 3x(x - 2)$이므로, $x < 0$일 때 증가, $0 < x < 2$일 때 감소, $x > 2$일 때 증가합니다.

`from sympy import symbols, diff, solve, factor; x = symbols('x'); f = x**3 - 3*x**2; f_prime = diff(f, x); print(factor(f_prime)); print(solve(f_prime, x))`
