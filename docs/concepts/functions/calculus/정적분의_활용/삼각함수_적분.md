### 정확한 진술

삼각함수의 적분이란 피적분함수가 사인, 코사인, 탄젠트 등 삼각함수인 정적분 또는 부정적분을 말합니다. 기본 삼각함수의 부정적분은 다음과 같습니다:

$$\int \sin x \, dx = -\cos x + C$$
$$\int \cos x \, dx = \sin x + C$$
$$\int \tan x \, dx = -\ln|\cos x| + C$$
$$\int \sec^2 x \, dx = \tan x + C$$

정적분의 경우 구간 $[a, b]$에서 $\int_a^b \sin x \, dx = [-\cos x]_a^b = -\cos b + \cos a$와 같이 계산합니다.

### 직관·기하적 의미

삼각함수는 주기함수이므로 그 적분값은 함수의 부호와 크기가 한 주기(또는 부분 구간)에서 어떻게 변하는지를 나타냅니다. 예를 들어 $\sin x$를 $0$에서 $\pi$까지 적분하면 양수(사인 곡선 아래 넓이)가 되고, $\pi$에서 $2\pi$까지 적분하면 음수(곡선이 $x$축 아래)가 됩니다. 따라서 삼각함수의 정적분은 진동하는 현상(파동, 음파, 교류 전류 등)의 누적 효과를 계산할 때 매우 유용합니다.

또한 $\sin^2 x$, $\cos^2 x$ 같은 제곱 형태는 반각공식($\cos 2x = 1 - 2\sin^2 x$ 등)을 이용해 적분합니다.

### 한 줄 예

$\int_0^{\pi} \sin x \, dx = [-\cos x]_0^{\pi} = -(-1) - (-1) = 2$ 

(`sympy.integrate(sp.sin(x), (x, 0, sp.pi))` 로 검증 가능)
