### 정확한 진술

두 넓이의 비가 일정한 값으로 주어지는 조건입니다. 곡선 $y = f(x)$와 $x$축 사이의 영역, 또는 두 곡선 $y = f(x)$와 $y = g(x)$ 사이의 영역 중 선택된 구간의 넓이들이 특정 비율을 만족해야 한다는 뜻입니다.

형식으로는 두 영역의 넓이를 $S_1, S_2$라 할 때,
$$\frac{S_1}{S_2} = k \quad \text{또는} \quad S_1 : S_2 = m : n$$
같은 형태의 조건을 말합니다.

### 직관과 기하적 의미

넓이 비율 조건은 그래프의 개형이나 미지의 상수를 결정하는 강력한 도구입니다. 1:1 비율이면 두 영역의 넓이가 같고, 1:2 비율이면 한쪽이 다른 쪽의 2배라는 기하학적 의미를 갖습니다.

정적분으로 표현하면
$$\int_a^b f(x)\,dx : \int_b^c f(x)\,dx = m : n$$
같은 형태가 되며, 이 등식으로부터 미지의 적분 상수, 곡선이 지나는 점, 또는 구간의 끝점을 구할 수 있습니다. 특히 수능에서는 이 조건과 함수의 성질(미분 가능성, 연속성 등)을 함께 사용하여 함수를 완전히 결정하는 문제로 출제됩니다.

### 한 줄 예

$f(x) = x^2$에 대해 $\int_0^1 x^2\,dx = \frac{1}{3}$, $\int_1^2 x^2\,dx = \frac{7}{3}$이므로 넓이 비율은 $S_1 : S_2 = 1 : 7$입니다.  
(`from sympy import *; x = symbols('x'); integrate(x**2, (x, 0, 1)), integrate(x**2, (x, 1, 2))` → $(1/3, 7/3)$)
