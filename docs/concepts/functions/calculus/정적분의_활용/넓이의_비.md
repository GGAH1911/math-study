# 넓이의 비

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
두 평면 도형의 넓이를 정적분으로 계산한 후, 그 값들의 상대적인 크기 비율을 구하는 개념이다.

## 본문
두 평면 도형의 넓이를 각각 $S_1$, $S_2$라 할 때, 넓이의 비는 $\displaystyle \frac{S_1}{S_2}$로 정의된다. 곡선과 직선으로 둘러싸인 영역의 넓이를 정적분으로 계산한 후, 두 영역의 넓이를 나누어 상대적 크기의 비율을 구하는 개념이다.

### 직관과 기하적 의미
넓이의 비는 두 도형의 크기를 정량적으로 비교하는 도구이다. 예를 들어 비가 $3:2$이면 첫 번째 영역이 두 번째 영역의 $1.5$배 크다는 것을 의미한다. 곡선으로 둘러싸인 영역은 형태가 매우 복잡할 수 있지만, 정적분을 이용하면 기하학적 직관에 의존하지 않고도 정확한 비교가 가능하다. 이는 도형의 형태가 어떠하든 적분을 통해 넓이라는 단일한 수치로 축약할 수 있으며, 그 수치들의 비를 구함으로써 복잡한 형상을 단순한 비율 관계로 변환할 수 있음을 뜻한다.

### 기본 성질
두 곡선 $y = x^2$과 $y = x$ 사이의 넓이를 $0 \le x \le 1$과 $1 \le x \le 2$ 구간에서 각각 구하면, 전자는 $\int_0^1 (x - x^2) dx = \frac{1}{6}$, 후자는 $\int_1^2 (x^2 - x) dx = \frac{5}{6}$이므로 넓이의 비는 $1:5$가 된다.

## 학습 체크
- 정적분을 통해 구한 두 영역의 넓이가 음수가 나오지 않도록 함수식의 상하 관계를 올바르게 설정하였는가?
- 두 영역의 넓이를 구한 후, 비를 나타낼 때 분자와 분모의 순서가 문제에서 요구하는 순서와 일치하는가?

## 관련 개념
- **정적분의 활용**: 복잡한 곡선으로 둘러싸인 영역의 넓이를 정적분을 통해 수치화함으로써 넓이의 비를 계산할 수 있는 근거를 제공한다.
