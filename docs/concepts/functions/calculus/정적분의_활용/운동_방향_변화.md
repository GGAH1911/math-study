# 운동 방향 변화

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
속도 $v(t)$의 부호가 양수에서 음수로 또는 음수에서 양수로 바뀌는 순간에 물체의 운동 방향이 변합니다.

## 본문
시각 $t$에서 운동하는 점의 위치를 $s(t)$라 할 때, 속도는 $v(t) = s'(t)$입니다. 운동 방향이 변한다는 것은 $v(t) = 0$이 되면서 그 전후로 $v(t)$의 부호가 바뀌는 순간을 의미합니다. 즉, 속도가 양수에서 음수로 또는 음수에서 양수로 변할 때 물체는 이동 방향을 완전히 반대로 바꾸게 됩니다.

### 직관과 기하적 의미
수직선 위를 움직이는 물체를 가정할 때, 속도가 양수이면 오른쪽으로, 음수이면 왼쪽으로 이동합니다. 속도가 $0$이 되는 순간은 물체가 일시적으로 멈추는 순간이지만, 이것만으로는 방향 변화가 일어나지 않습니다. 방향이 실제로 변하려면 그 지점을 기준으로 속도의 부호가 반드시 바뀌어야 합니다. 위치-시간 그래프의 관점에서 보면, 운동 방향의 변화는 위치 함수의 극값(극대 또는 극소)에서 발생합니다. 예를 들어 극대점에 도달하기 직전에는 위치가 증가하다가($v > 0$), 극대점을 지나면 위치가 감소하기($v < 0$) 때문입니다.

### 기본 성질
- $v(t) = 0$인 지점이라 하더라도 $v(t)$의 부호가 변하지 않는다면 운동 방향은 변하지 않습니다.
- 위치 함수 $s(t)$의 그래프에서 운동 방향이 변하는 지점은 그래프의 굴곡이 생기는 극점과 일치합니다.
- 예시로 $s(t) = t^2 - 4t + 3$인 경우, $v(t) = 2t - 4$이므로 $v(t) = 0$인 $t = 2$를 기준으로 $t < 2$에서는 음수, $t > 2$에서는 양수 값을 가집니다. 따라서 $t = 2$에서 운동 방향이 변합니다.

## 학습 체크
- $v(t) = 0$인 지점에서 반드시 운동 방향이 변하는가?
- 위치-시간 그래프에서 운동 방향이 변하는 지점은 어떤 형태를 띠는가?

## 관련 개념
- **정적분의 활용**: 위치 함수를 적분하여 속도를 구하거나, 속도를 적분하여 위치의 변화량을 구하는 과정에서 운동 방향의 변화를 고려하여 구간별로 계산해야 합니다.
