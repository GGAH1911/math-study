# 운동 방향 변화

## 정확한 진술

시각 $t$에서 운동하는 점의 위치를 $s(t)$라 할 때, 속도는 $v(t) = s'(t)$입니다. **운동 방향이 변한다**는 것은 $v(t) = 0$이 되면서 그 전후로 $v(t)$의 부호가 바뀌는 순간을 말합니다. 즉, 속도가 양수에서 음수로(또는 음수에서 양수로) 변할 때 물체가 이동 방향을 완전히 반대로 바꾸게 됩니다.

## 직관과 기하적 의미

수직선 위를 움직이는 물체를 떠올려 봅시다. 속도가 양수이면 오른쪽으로, 음수이면 왼쪽으로 이동합니다. 속도가 0이 되는 순간은 물체가 일시적으로 멈추는 순간이지만, 그것만으로는 "방향 변화"가 아닙니다. 방향이 실제로 변하려면 그 점을 기준으로 속도의 부호가 바뀌어야 합니다.

위치-시간 그래프에서는 운동 방향의 변화가 위치 함수의 극값(극대 또는 극소)에서 발생합니다. 예를 들어 극대점에 도달하기 직전에는 위치가 증가하다가($v > 0$), 극대점을 지나서는 위치가 감소합니다($v < 0$). 이것이 바로 운동 방향의 변화입니다.

## 한 줄 예

$s(t) = t^2 - 4t + 3$인 경우, $v(t) = 2t - 4$이므로 $v(t) = 0$일 때 $t = 2$입니다. $t < 2$에서 $v(t) < 0$(왼쪽으로 이동), $t > 2$에서 $v(t) > 0$(오른쪽으로 이동)이므로, $t = 2$에서 운동 방향이 변합니다.

**검산**: `sympy.solve(2*t - 4, t)` → $[2]$
