# 정적분과 넓이

## 정확한 진술

연속함수 $f(x)$가 폐구간 $[a, b]$에서 $f(x) \geq 0$을 만족할 때, 곡선 $y = f(x)$, $x$축, 그리고 두 직선 $x = a$, $x = b$로 둘러싸인 영역의 넓이는 다음 정적분으로 정의된다.

$$S = \int_a^b f(x) \, dx$$

## 직관과 기하적 의미

정적분이 넓이를 나타낸다는 것은 리만 합의 극한 과정에서 비롯됩니다. 구간 $[a, b]$를 $n$개의 작은 구간으로 등분할 때, 각 소구간 폭을 $\Delta x = \frac{b-a}{n}$이라 하고, 각 구간에서 높이 $f(c_i)$ (단, $c_i$는 소구간 내 임의의 점)인 직사각형들의 넓이를 모두 더하면

$$\text{리만 합} = \sum_{i=1}^{n} f(c_i) \Delta x$$

$n \to \infty$일 때 이 합이 정적분으로 수렴하며, 이것이 정확한 영역의 넓이입니다. 직관적으로 $n$이 커질수록 작은 직사각형들이 곡선 아래 영역을 더욱 촘촘히 채우게 됩니다.

## 한 줄 예제

$f(x) = 2x$일 때 구간 $[1, 3]$에서 곡선과 $x$축 사이의 넓이: $\displaystyle \int_1^3 2x \, dx = \left[ x^2 \right]_1^3 = 9 - 1 = 8$

(sympy로 검증: `from sympy import symbols, integrate; x = symbols('x'); integrate(2*x, (x, 1, 3))`)

**주의**: $f(x)$가 구간의 일부에서 음수이면, 그 부분의 넓이는 절댓값 $|f(x)|$로 계산하거나 구간을 나누어야 합니다.
