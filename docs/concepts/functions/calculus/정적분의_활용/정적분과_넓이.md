# 정적분과 넓이

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
연속함수 $f(x)$가 양수일 때, 곡선과 $x$축, 두 직선 $x=a, x=b$로 둘러싸인 영역의 넓이는 정적분 $\int_a^b f(x) \, dx$로 계산한다.

## 본문
연속함수 $f(x)$가 폐구간 $[a, b]$에서 $f(x) \geq 0$을 만족할 때, 곡선 $y = f(x)$, $x$축, 그리고 두 직선 $x = a$, $x = b$로 둘러싸인 영역의 넓이는 다음 정적분으로 정의된다.
$$S = \int_a^b f(x) \, dx$$

### 직관과 기하적 의미
정적분이 넓이를 나타낸다는 것은 리만 합의 극한 과정에서 비롯됩니다. 구간 $[a, b]$를 $n$개의 작은 구간으로 등분할 때, 각 소구간 폭을 $\Delta x = \frac{b-a}{n}$이라 하고, 각 구간에서 높이 $f(c_i)$ (단, $c_i$는 소구간 내 임의의 점)인 직사각형들의 넓이를 모두 더하면
$$\text{리만 합} = \sum_{i=1}^{n} f(c_i) \Delta x$$
$n \to \infty$일 때 이 합이 정적분으로 수렴하며, 이것이 정확한 영역의 넓이입니다. 직관적으로 $n$이 커질수록 작은 직사각형들이 곡선 아래 영역을 더욱 촘촘히 채우게 됩니다.

### 기본 성질
함수 $f(x)$가 구간의 일부에서 음수 값을 가지는 경우에는 정적분 값이 넓이와 다를 수 있습니다. 이때 실제 넓이를 구하기 위해서는 $f(x)$의 부호가 바뀌는 지점을 기준으로 구간을 나누어 각 구간의 정적분에 절댓값을 취한 후 모두 더해야 합니다. 즉, 넓이 $S$는 $\int_a^b |f(x)| \, dx$로 계산됩니다.

## 학습 체크
- 함수 $f(x)$가 음수인 구간을 포함할 때, 정적분 값과 넓이의 차이는 무엇인가요?
- 구간을 나누어 넓이를 구할 때, $f(x)=0$이 되는 지점을 찾는 것이 왜 중요한가요?

## 관련 개념
- **정적분의 활용**: 정적분을 이용하여 곡선과 $x$축 사이의 넓이뿐만 아니라, 회전체의 부피나 곡선의 길이 등을 구할 수 있습니다.
