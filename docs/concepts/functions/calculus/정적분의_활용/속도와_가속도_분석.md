# 속도와 가속도 분석

> **정의** · 미적분 · 단원: [정적분의 활용](/concepts/정적분의_활용)

## 요약
위치, 속도, 가속도는 미분과 적분의 관계를 통해 서로 연결되며, 각각 위치 함수의 도함수와 그 적분으로 정의됩니다.

## 본문
물체가 일직선상에서 움직일 때, 시간 $t$에 대한 위치를 $x(t)$라고 하면 속도 $v(t)$는 위치 함수를 시간으로 미분한 $\frac{dx}{dt}$로 정의되며, 가속도 $a(t)$는 속도를 시간으로 미분한 $\frac{dv}{dt}$ 또는 위치 함수를 두 번 미분한 $\frac{d^2x}{dt^2}$로 정의됩니다. 즉, 속도는 위치 함수의 1차 도함수이고 가속도는 위치 함수의 2차 도함수입니다.

### 직관과 기하적 의미
속도는 특정 순간에 물체가 움직이는 빠르기를 의미하며, 위치-시간 그래프에서 그래프의 접선의 기울기로 나타납니다. 속도의 부호는 운동 방향을 나타내어, 양수이면 양의 방향으로, 음수이면 음의 방향으로 움직임을 뜻합니다. 가속도는 속도의 변화율을 의미하며, 속도-시간 그래프에서의 접선의 기울기와 같습니다. 가속도가 양수이면 속도가 증가하는 상태를, 음수이면 속도가 감소하는 상태를 나타냅니다.

### 기본 성질
가속도 함수 $a(t)$를 알고 있을 때, 정적분을 이용하면 속도와 위치를 역산할 수 있습니다. 초기 속도를 $v_0$, 초기 위치를 $x_0$라고 할 때, 속도는 $v(t) = v_0 + \int_0^t a(s) \, ds$로, 위치는 $x(t) = x_0 + \int_0^t v(s) \, ds$로 구할 수 있습니다. 예를 들어 자동차의 위치가 $x(t) = 3t^2 - 2t$라면, 속도는 $v(t) = 6t - 2$이고 가속도는 $a(t) = 6$이 됩니다.

- 속도-시간 그래프에서 접선의 기울기가 음수일 때 물체의 운동 상태는 어떠한가?
- 가속도 함수로부터 초기 속도와 위치를 포함한 위치 함수를 구하는 과정은 무엇인가?

## 관련 개념
- **정적분의 활용**: 가속도나 속도 함수를 정적분하여 물체의 위치 변화량이나 이동 거리를 계산하는 데 사용됩니다.
