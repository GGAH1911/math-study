# 속도와 가속도 분석

## 정확한 진술

물체가 일직선상에서 움직일 때, 시간 $t$에 대한 위치를 $x(t)$라고 하면:
- **속도**는 $v(t) = \frac{dx}{dt}$ (위치를 시간으로 미분)
- **가속도**는 $a(t) = \frac{dv}{dt} = \frac{d^2x}{dt^2}$ (속도를 시간으로 미분)

속도는 위치 함수의 1차 도함수, 가속도는 2차 도함수입니다.

## 직관과 기하적 의미

**속도**는 "지금 이 순간 얼마나 빠르게 움직이는가"를 나타냅니다. 위치-시간 그래프에서 속도는 각 점에서의 접선의 기울기입니다. 속도가 양수면 양의 방향으로, 음수면 음의 방향으로 움직이고 있다는 뜻입니다.

**가속도**는 "속도가 얼마나 빠르게 변하는가"를 의미합니다. 가속도가 양수면 속도가 증가 중(물체가 빨라지거나 음의 방향 운동이 약해짐)이고, 음수면 속도가 감소 중입니다. 속도-시간 그래프에서 가속도는 그 접선의 기울기입니다.

## 역과정: 적분을 통한 역산

선수 개념과의 연계로, 가속도 함수 $a(t)$를 알면 **정적분**으로 속도와 위치를 구할 수 있습니다:
$$v(t) = v_0 + \int_0^t a(s) \, ds$$
$$x(t) = x_0 + \int_0^t v(s) \, ds$$

여기서 $v_0, x_0$는 초기 속도와 초기 위치입니다.

## 간단한 예

자동차가 $x(t) = 3t^2 - 2t$ (미터)로 움직일 때:
- 속도: $v(t) = 6t - 2$ (m/s)
- 가속도: $a(t) = 6$ (m/s²)

$t=1$초일 때 속도는 $4$ m/s, 가속도는 일정하게 $6$ m/s²입니다.
