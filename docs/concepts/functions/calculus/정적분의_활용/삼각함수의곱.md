# 삼각함수의곱

## 정확한 진술

두 삼각함수의 곱을 합 또는 차로 변환하는 공식을 **삼각함수의 곱 공식**이라 합니다. 가장 기본적인 세 가지는 다음과 같습니다.

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$

$$\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$$

$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

## 직관 및 의미

정적분을 계산할 때, $\sin x \cos x$ 같은 곱 형태가 피적분함수로 나타나면 직접 적분하기 까다롭습니다. 하지만 합차 공식으로 변환하면 각 항이 단일 삼각함수가 되어 기본 적분 공식을 바로 적용할 수 있습니다.

기하학적으로는 두 파동이 만날 때의 간섭 현상을 분석할 때도 이 공식이 유용합니다. 여러 주파수의 신호가 섞여 있을 때 각 성분을 분리하는 데 사용됩니다.

## 한 줄 예

$\int \sin 2x \cos 3x \, dx$를 계산할 때:

$$\sin 2x \cos 3x = \frac{1}{2}[\sin 5x + \sin(-x)] = \frac{1}{2}[\sin 5x - \sin x]$$

이제 각 항을 쉽게 적분할 수 있습니다:

$$\int \sin 2x \cos 3x \, dx = \frac{1}{2}\left[-\frac{1}{5}\cos 5x + \cos x\right] + C$$

검산: `sympy.integrate(sympy.sin(2*x)*sympy.cos(3*x), x)`
