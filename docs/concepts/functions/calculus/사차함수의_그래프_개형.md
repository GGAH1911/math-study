### 정확한 진술

사차함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$ (단, $a \neq 0$)의 그래프 개형은 도함수 $f'(x) = 4ax^3 + 3bx^2 + 2cx + d$가 서로 다른 실근을 몇 개 가지는가에 따라 결정된다. 구체적으로:

- **극값 3개 타입**: $f'(x) = 0$이 서로 다른 3개의 실근을 가지는 경우. $a > 0$이면 W자형(극소-극대-극소), $a < 0$이면 M자형(극대-극소-극대).
- **극값 1개 타입**: $f'(x) = 0$이 중근을 포함하여 극값을 1개만 가지는 경우. 단조성이 한 번만 바뀐다.
- **극값 0개 타입**: $f'(x) = 0$이 실근을 가지지 않거나 모두 중근인 경우. 단조증가(또는 단조감소)하며 변곡점만 존재한다.

### 직관/기하적 의미

사차함수의 그래프 개형을 파악하는 것은 함수의 전체적 '모양'을 빠르게 이해하는 것과 같다. 극값의 위치와 개수는 $f'(x) = 0$의 해를 분석함으로써 알 수 있으며, 각 극값에서의 함숫값을 비교하면 방정식 $f(x) = 0$의 실근 개수가 0개, 1개, 2개, 3개, 또는 4개인지 판단할 수 있다. 수능에서는 이 개형 분석을 토대로 근의 개수, 최댓값·최솟값, 적분 구간에서의 부호, 접선의 개수 등을 묻는 문제가 자주 출제된다.

### 한 줄 예

$f(x) = x^4 - 2x^2$인 경우 $f'(x) = 4x^3 - 4x = 4x(x^2-1)$이므로 $x = -1, 0, 1$에서 극값을 가지는 전형적인 W자형 그래프이다. (`sympy.solve(4*x**3 - 4*x, x)` → $\{-1, 0, 1\}$)
