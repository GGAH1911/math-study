# 매개변수 극한

> **정의** · 미적분 · 단원: [여러가지 함수의 극한과 연속](/concepts/여러가지_함수의_극한과_연속)

## 요약
매개변수 $t$의 변화에 따른 각 성분의 극한값이 존재할 때, 매개변수 곡선 위의 점이 향하는 목표 지점을 결정하는 개념입니다.

## 본문
매개변수 곡선 $x = f(t), y = g(t)$에서 매개변수 $t$가 어떤 값 $a$로 접근할 때, 점 $(x(t), y(t))$가 나타내는 곡선 위의 점의 극한을 매개변수 극한이라 합니다. 즉, $t \to a$일 때 다음과 같이 각 성분의 극한값으로 정의됩니다.
$$\lim_{t \to a} (f(t), g(t)) = \left( \lim_{t \to a} f(t), \lim_{t \to a} g(t) \right) = (L_1, L_2)$$
이때 양쪽 극한이 모두 존재하면, 곡선이 점 $(L_1, L_2)$로 수렴한다고 합니다.

### 직관과 기하적 의미
매개변수 극한은 곡선의 끝점을 찾는 과정입니다. 예를 들어 시간 $t$에 따라 움직이는 질점의 궤적이 $x(t), y(t)$로 주어질 때, $t$가 어떤 순간에 가까워질수록 그 점이 어디로 향하는지를 나타냅니다. $t$가 정의역의 끝(예: $t \to \infty$)에 가까워질 때 곡선의 무한원 방향의 거동을 파악할 수 있으며, $t$가 특정 구간의 경계에 가까워질 때 곡선이 그리는 도형의 시작점과 끝점을 결정합니다. 각 성분의 극한이 모두 존재해야 전체 극한이 존재하며, 한 성분이라도 발산하거나 극한이 없으면 곡선 전체의 극한은 존재하지 않습니다.

### 기본 성질
매개변수 극한은 곡선의 국소적 거동을 분석하는 데 사용됩니다. 예를 들어 $x = e^{-t}, y = 1 - t^2$일 때, $t \to \infty$이면 $\lim_{t \to \infty} (e^{-t}, 1 - t^2) = (0, -\infty)$가 되어 곡선이 $x$축에 가까워지면서 동시에 아래로 무한히 뻗어나가는 거동을 보입니다.

## 학습 체크
- 매개변수 $t$의 극한값이 존재하더라도 곡선의 극한값이 존재하지 않는 경우는 언제인가?
- $t$가 무한대로 갈 때 곡선의 거동을 성분별 극한을 통해 어떻게 해석할 수 있는가?

## 관련 개념
- **정적분의 활용**: 곡선의 길이 또는 면적을 구할 때 적분 구간의 경계값을 결정하는 데 필수적으로 사용됩니다.
