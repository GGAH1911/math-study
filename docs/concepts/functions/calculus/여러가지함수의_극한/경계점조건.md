# 경계점조건

> **정의** · 미적분 · 단원: [여러가지 함수의 극한과 연속](/concepts/여러가지_함수의_극한과_연속)

## 요약
함수나 미분방정식이 정의역의 특정 경계점 또는 초기 시점에서 만족해야 하는 값을 지정하여, 무수히 많은 일반해 중 유일한 특수해를 결정하는 조건입니다.

## 본문
경계점조건은 함수나 미분방정식이 정의역의 특정 점, 즉 구간의 끝점이나 초기 시점에서 반드시 가져야 하는 값의 조건을 의미합니다. 예를 들어 미분방정식 $\tfrac{dy}{dx} = f(x)$의 일반해가 상수 $C$를 포함하는 형태일 때, 경계점조건 $y(a) = b$를 부여하면 상수 $C$의 값을 결정할 수 있으며 이를 통해 유일한 특수해를 구할 수 있습니다. 수능 수학 범위에서는 주로 초기조건의 형태로 나타나며, 특정 지점에서의 함숫값 $y(x_0) = y_0$이나 미분계수 $f'(x_0) = m$과 같이 특정 점에서의 상태를 지정하는 방식으로 활용됩니다.

### 직관과 기하적 의미
미분방정식의 일반해는 동일한 미분 규칙을 따르면서 수직으로 평행이동된 무수히 많은 곡선들의 집합인 곡선족을 형성합니다. 이때 경계점조건은 이 무수한 곡선들 중에서 어떤 곡선을 선택할 것인지를 결정하는 결정적인 정보 역할을 합니다. 기하학적으로 해석하면, 평면 위의 한 점 $(x_0, y_0)$을 통과하는 곡선은 유일하므로, 경계점조건을 통해 해당 점을 지나는 단 하나의 해를 확정 지을 수 있습니다.

### 기본 성질
- 일반해에 포함된 임의의 상수를 결정하여 특수해를 도출하는 근거가 됩니다.
- 주어진 조건이 함수의 특정 지점에서의 함숫값이나 변화율(미분값)을 지정하는 형태로 나타납니다.
- 조건이 주어짐으로써 무수히 많은 해의 집합을 하나의 유일한 함수로 좁혀주는 역할을 합니다.

## 학습 체크
- 일반해에서 상수 $C$를 결정하기 위해 필요한 조건이 무엇인지 설명할 수 있는가?
- 주어진 경계점조건을 만족하는 특수해를 직접 계산하여 도출할 수 있는가?
- 기하학적으로 경계점조건이 곡선족의 위치를 어떻게 결정하는지 이해하고 있는가?

## 관련 개념
- **함수의 극한과 연속**: 경계점조건이 특정 점에서의 함숫값을 지정하므로, 해당 점에서의 극한값과 함숫값이 일치하는지 확인하는 연속성의 개념과 밀접하게 연결됩니다.
