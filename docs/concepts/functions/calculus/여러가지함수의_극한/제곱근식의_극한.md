# 제곱근식의 극한

## 정확한 진술

$f(x) \geq 0$인 함수에 대하여, $x$가 특정 값에 다가갈 때 $\sqrt{f(x)}$의 극한을 **제곱근식의 극한**이라 합니다. 즉,

$$\lim_{x \to a} \sqrt{f(x)} = \sqrt{\lim_{x \to a} f(x)}$$

단, $\lim_{x \to a} f(x) \geq 0$이어야 합니다. 이는 연속함수의 극한 성질에 의해 성립합니다.

## 직관 및 성질

제곱근 함수 $y = \sqrt{x}$는 $x \geq 0$에서 연속이고 증가함수입니다. 따라서 $f(x)$가 어떤 음이 아닌 값 $L$으로 수렴하면, $\sqrt{f(x)}$는 자동으로 $\sqrt{L}$로 수렴합니다. 

**핵심**: 극한값의 제곱근을 먼저 구하나, 제곱근의 극한을 먼저 구하나 결과가 같다는 의미입니다. 이를 이용하면 복잡한 제곱근식도 먼저 제곱근 안의 식의 극한을 구한 후 제곱근을 취하면 됩니다.

**주의**: $\lim_{x \to a} f(x) < 0$이면 $\lim_{x \to a} \sqrt{f(x)}$는 실수에서 정의되지 않습니다.

## 기본 예

$$\lim_{x \to 4} \sqrt{3x - 2} = \sqrt{\lim_{x \to 4}(3x - 2)} = \sqrt{12 - 2} = \sqrt{10}$$

더 복잡한 형태, 예를 들어 

$$\lim_{x \to 0} \frac{\sqrt{x+1} - 1}{x}$$

같은 부정형은 **유리화** 기법(분자·분모에 $\sqrt{x+1} + 1$을 곱함)으로 해결합니다:

$$\frac{\sqrt{x+1} - 1}{x} \cdot \frac{\sqrt{x+1} + 1}{\sqrt{x+1} + 1} = \frac{x}{x(\sqrt{x+1} + 1)} = \frac{1}{\sqrt{x+1} + 1} \to \frac{1}{2}$$
