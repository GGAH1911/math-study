### 정확한 진술

초월방정식은 지수함수, 로그함수, 삼각함수 등의 초월함수를 포함하면서, 다항식 계수의 대수방정식으로 나타낼 수 없는 방정식입니다. 일반적으로 $f(x) = g(x)$ 형태로 나타내며, 적어도 한쪽이 초월함수입니다. 예를 들어:

$$\sin x = x, \quad e^x = 2x + 1, \quad \log x = 3 - x$$

이들은 모두 초월방정식입니다.

### 직관과 기하적 의미

초월방정식의 해는 두 함수 그래프가 만나는 점의 $x$좌표입니다. 예를 들어 $\sin x = x$의 해는 $y = \sin x$와 $y = x$ 그래프의 교점이 바로 근입니다. 

대수방정식(2차, 3차)과 달리 초월방정식은 **대수적 공식으로 정확한 근을 구할 수 없다**는 결정적 특징이 있습니다. 대신 다음을 활용합니다:
- **중간값 정리**: 연속함수가 서로 다른 부호의 함수값을 가지면 사이에 근이 존재
- **그래프를 통한 근의 개수 판정**: 미분을 이용해 극값을 찾고 함수의 개형을 파악해 교점 개수 결정
- **수치해석**: 뉴턴 방법, 이분 탐색 등으로 근의 근사값 계산

수능과 대학 입시에서는 주로 **근의 개수를 판정**하거나 **근의 위치**를 묻는 문제가 출제됩니다.

### 한 줄 예

$e^x = x + 2$의 실근 개수를 판정하려면, $y = e^x$와 $y = x + 2$의 교점을 그래프로 분석하여 정확히 하나의 실근이 존재함을 확인합니다.
