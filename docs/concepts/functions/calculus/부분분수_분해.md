### 정확한 진술

유리함수 $\dfrac{P(x)}{Q(x)}$에서 분자의 차수가 분모의 차수보다 작을 때, 이를 더 간단한 유리식들의 합으로 나타내는 것을 **부분분수 분해**라고 합니다.

분모 $Q(x)$를 일차 인수들의 곱으로 인수분해할 수 있다면:

$$\frac{P(x)}{Q(x)} = \frac{A_1}{x - a_1} + \frac{A_2}{x - a_2} + \cdots + \frac{A_n}{x - a_n}$$

분모에 중근이나 이차식이 포함되면 분해 형태가 달라집니다. 예를 들어 $(x-a)^2$가 인수면 $\dfrac{A}{x-a} + \dfrac{B}{(x-a)^2}$ 형태로, $x^2 + px + q$ (중근 없음)가 인수면 $\dfrac{Cx + D}{x^2 + px + q}$ 형태로 나타냅니다.

### 직관과 의의

복잡한 유리함수를 여러 개의 단순한 분수로 쪼개면, 적분이나 수열의 극한 계산이 훨씬 수월해집니다. 예를 들어 $\dfrac{1}{x(x+1)}$을 직접 적분하기는 어렵지만, $\dfrac{1}{x} - \dfrac{1}{x+1}$로 분해한 후에는 각각 $\ln|x|$, $\ln|x+1|$로 바로 계산됩니다.

기하학적으로는 복잡한 함수를 기본 단위인 일차식 분수들로 재구성하는 과정이며, 이는 고등학교에서 수열의 극한(망원급수)을 다룰 때 필수적입니다.

### 구체적 예

$$\frac{5x + 1}{(x+1)(x-2)} = \frac{2}{x+1} + \frac{3}{x-2}$$

검증: `sympy.apart((5*x+1)/((x+1)*(x-2)), x)`는 `2/(x+1) + 3/(x-2)`를 반환합니다.
