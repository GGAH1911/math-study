### 정확한 진술

주어진 조건들(함수값, 도함수값, 극값, 극한값 등)과 함수의 차수나 형태를 이용하여 **미정계수를 결정하고 함수 자체를 유일하게 결정하는 문제**입니다. 보통 다항함수 $f(x) = ax^n + bx^{n-1} + \cdots + c$에서 계수 $a, b, c, \ldots$를 조건에 맞춰 찾는 형태입니다.

### 직관과 의미

함수 결정 문제는 "역문제"의 핵심입니다. 보통 우리는 함수가 주어졌을 때 도함수를 구하지만(순방향), 여기서는 도함수나 그래프의 성질로부터 원래 함수를 복원해야 합니다. 

조건의 개수와 미정계수의 개수를 맞춰야 합니다. 예를 들어:
- $n$차 다항함수는 $(n+1)$개의 계수를 가지므로, 독립적인 $(n+1)$개 조건이 필요합니다.
- 조건은 점 $(a, f(a))$를 지나간다, $f'(b) = 0$ (극값), $f''(c) = 0$ (변곡점) 등으로 주어집니다.

기하학적으로는 주어진 조건들을 **모두 만족하는 곡선을 찾는 것**이므로, 조건이 충분하고 일관성 있으면 유일한 함수가 결정됩니다.

### 한 줄 예

$f'(1) = 0$, $f(1) = 2$, $f(0) = 3$을 만족하는 2차함수 $f(x) = ax^2 + bx + c$를 찾는 것이 함수 결정 문제입니다.

### 풀이 전략

1. 함수 형태를 미정계수로 표현
2. 주어진 조건을 식으로 변환
3. 연립방정식을 세우고 풀기
4. 얻은 계수를 대입하여 함수 확정

예: 위 예시에서 $f'(x) = 2ax + b$이므로, $f'(1) = 2a + b = 0$, $f(1) = a + b + c = 2$, $f(0) = c = 3$으로부터 $a = -1, b = 2, c = 3$이므로 $f(x) = -x^2 + 2x + 3$입니다.
