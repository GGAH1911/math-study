# 실근의 개수 조건

## 정확한 진술

방정식 $f(x) = 0$이 실근을 가지는 개수를 판정하는 조건들입니다. 특히 **판별식**(discriminant) $D$를 이용하거나, 함수의 그래프 성질(극값, 연속성, 부호)을 이용하여 근의 개수를 결정합니다.

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 경우:
- $D = b^2 - 4ac > 0$ ⟹ 서로 다른 두 실근
- $D = 0$ ⟹ 중근(중복도 2)
- $D < 0$ ⟹ 실근 없음 (복소수 근만 존재)

일반 방정식 $f(x) = g(x)$의 실근 개수는 $h(x) = f(x) - g(x)$의 영점 개수와 같습니다.

## 직관과 기하적 의미

실근의 개수 조건은 **함수 그래프의 $x$축과의 교점 개수**를 센 것입니다. $y = f(x)$ 곡선이 $x$축과 만나는 점의 개수 = 방정식 $f(x) = 0$의 실근 개수입니다.

두 곡선의 교점 $f(x) = g(x)$를 찾을 때도 마찬가지로, 차이 함수 $h(x) = f(x) - g(x)$의 그래프가 $x$축과 만나는 점들을 세면 됩니다. 극값과 부호 변화를 조사하면, 미분 없이도 근의 개수를 알 수 있습니다.

## 한 줄 예

방정식 $x^2 - 5x + 6 = 0$에서 $D = 25 - 24 = 1 > 0$이므로 서로 다른 두 실근을 가집니다. 실제로 $x = 2, 3$입니다. (`sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$)

더 복잡한 방정식에서는 함수 $f(x)$의 극값들을 구해, $f$의 최댓값과 최솟값의 부호를 확인함으로써 근의 개수를 판정합니다. 예를 들어 $f(x)$의 극솟값이 양수이면, 방정식 $f(x) = 0$은 실근을 가지지 않습니다.
