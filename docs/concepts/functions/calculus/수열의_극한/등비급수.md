# 등비급수

## 정확한 진술

첫째항이 $a$이고 공비가 $r$인 등비수열 $\{a \cdot r^{n-1}\}$의 무한급수를 **등비급수**라 합니다.

$$\sum_{n=1}^{\infty} a \cdot r^{n-1} = a + ar + ar^2 + ar^3 + \cdots$$

이 급수는 $|r| < 1$일 때만 수렴하며, 수렴값은 다음과 같습니다.

$$\sum_{n=1}^{\infty} a \cdot r^{n-1} = \frac{a}{1-r} \quad (|r| < 1)$$

$|r| \geq 1$이면 급수는 발산합니다.

## 직관과 기하적 의미

등비급수를 부분합으로 생각해봅시다. 첫 $n$항까지의 합 $S_n$은:

$$S_n = a + ar + ar^2 + \cdots + ar^{n-1} = a \cdot \frac{1-r^n}{1-r} \quad (r \neq 1)$$

$|r| < 1$이면 $n \to \infty$일 때 $r^n \to 0$이므로, $S_n \to \frac{a}{1-r}$입니다. 즉, 공비의 절댓값이 1보다 작으면 항이 점점 작아져서 합이 특정 값에 가까워집니다.

반면 $|r| > 1$이면 $|r^n|$이 계속 커지므로 합이 무한대로 발산하고, $r = 1$이면 모든 항이 $a$로 같아서 수렴하지 않습니다.

## 기본 예제

첫째항이 $2$, 공비가 $\frac{1}{3}$인 등비급수:

$$2 + \frac{2}{3} + \frac{2}{9} + \frac{2}{27} + \cdots = \frac{2}{1-\frac{1}{3}} = \frac{2}{\frac{2}{3}} = 3$$

부분합이 $2, \frac{8}{3}, \frac{26}{9}, \frac{80}{27}, \ldots$로 계속 $3$에 가까워집니다.

(검증: `from sympy import Sum, oo, Rational; Sum(2 * (Rational(1,3))**(n-1), (n, 1, oo)).doit()` → 3)
