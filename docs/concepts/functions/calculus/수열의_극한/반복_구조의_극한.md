# 반복 구조의 극한

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
점화식이나 함수의 반복 합성을 통해 생성되는 수열이 수렴할 때 도달하는 고정된 값을 의미합니다.

## 본문
반복 구조의 극한은 점화식이나 재귀 관계로 정의된 수열이 수렴할 때 그 극한값을 의미합니다. 수열 $\{a_n\}$이 점화식 $a_{n+1} = f(a_n)$을 만족하고 $\lim_{n \to \infty} a_n = L$이 존재한다면, 양변에 극한을 취하여 $L = f(L)$이 성립하며, 이때의 $L$을 반복 구조의 극한값이라고 합니다. 더 일반적으로는 각 단계의 결과가 이전 단계에만 의존하는 함수의 반복 합성 $f \circ f \circ \cdots \circ f$ 과정에서 수렴하는 값을 뜻합니다.

### 직관과 기하적 의미
반복 구조의 극한은 "무한히 반복해도 변하지 않는 고정점"으로 이해할 수 있습니다. 계산기에서 특정 함수를 계속 적용할 때 어느 순간부터 같은 숫자가 나타나는 현상이 대표적인 예시입니다. 기하학적으로는 함수 $y = f(x)$의 그래프와 직선 $y = x$의 교점으로 나타납니다. 점 $(a_n, a_n)$에서 출발하여 곡선에 수직으로 닿고 다시 대각선에 수평으로 닿는 과정을 반복하는 '거미집 도형'을 그리면, 점들이 교점을 향해 수렴하게 됩니다.

### 기본 성질
수열이 수렴한다는 전제하에, 극한값 $L$은 반드시 함수 $f(x)$의 고정점인 $f(L) = L$을 만족해야 합니다. 예를 들어 점화식 $a_{n+1} = \sqrt{2 + a_n}$에서 $a_1 = 0$일 때, 수열은 $L = \sqrt{2 + L}$을 만족하는 $L = 2$로 수렴합니다. 또한, $a_n = \left(1 + \tfrac{1}{n}\right)^n$과 같이 구조적 반복을 통해 오일러 수 $e$를 정의하는 경우도 존재합니다.

## 학습 체크
- 수열이 수렴할 때 극한값이 $L = f(L)$을 만족하는 이유를 극한의 성질을 이용하여 설명할 수 있는가?
- 함수 $y = f(x)$와 $y = x$의 교점을 이용하여 수열의 수렴 여부를 시각적으로 판별할 수 있는가?

## 관련 개념
- **수열의 극한**: 반복 구조를 통해 생성된 수열이 특정 값으로 다가가는 상태를 다루는 기초 개념입니다.
