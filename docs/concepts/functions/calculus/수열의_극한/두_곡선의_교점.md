# 두 곡선의 교점

## 정확한 진술

두 곡선 $y = f(x)$와 $y = g(x)$의 **교점**은, 두 식을 동시에 만족하는 점 $(a, f(a))$입니다. 즉, $f(a) = g(a)$를 만족하는 $x = a$에서 두 곡선이 만나는 점입니다. 교점의 $x$ 좌표는 방정식 $f(x) = g(x)$의 해이고, $y$ 좌표는 $f(a)$ (또는 $g(a)$)입니다.

## 직관/기하적 의미

좌표평면에서 한 곡선은 함수 $f$의 그래프이고, 다른 곡선은 함수 $g$의 그래프입니다. 두 곡선이 만나는 지점이 교점인데, 이는 두 함수의 함숫값이 같은 순간을 나타냅니다. 교점을 구하려면 **대수적으로는** $f(x) = g(x)$를 풀고, **기하적으로는** 두 그래프의 교차 위치를 찾습니다. 교점은 0개, 1개, 또는 여러 개 존재할 수 있습니다.

## 해를 구하는 과정

교점을 찾는 절차는:
1. 방정식 $f(x) = g(x)$를 세우기
2. 이를 $f(x) - g(x) = 0$ 형태로 정리하기
3. 방정식을 풀어 $x$ 값(들) 구하기
4. 각 $x$ 값을 $f(x)$ 또는 $g(x)$에 대입하여 $y$ 좌표 구하기

## 한 줄 예

직선 $y = 2x + 1$과 포물선 $y = x^2$의 교점을 구하세요.

**풀이:** $2x + 1 = x^2$를 정리하면 $x^2 - 2x - 1 = 0$입니다. 근의 공식을 적용하면 $x = \frac{2 \pm \sqrt{4 + 4}}{2} = 1 \pm \sqrt{2}$이므로, 교점은 $(1 + \sqrt{2}, 3 + 2\sqrt{2})$와 $(1 - \sqrt{2}, 3 - 2\sqrt{2})$ 두 개입니다. (검증: `sympy.solve(x**2 - 2*x - 1, x)` → $[1 - \sqrt{2}, 1 + \sqrt{2}]$)
