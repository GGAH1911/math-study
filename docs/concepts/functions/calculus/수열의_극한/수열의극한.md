### 정확한 진술

수열 $\{a_n\}$이 실수 $L$에 **수렴한다**고 하고, 이를 $\lim_{n \to \infty} a_n = L$로 나타냅니다. 이는 다음을 의미합니다:

$$\text{모든 } \varepsilon > 0 \text{에 대해, 어떤 자연수 } N \text{이 존재하여} \quad n > N \Rightarrow |a_n - L| < \varepsilon$$

즉, 아무리 작은 오차 범위 $\varepsilon$를 정해도, $n$이 충분히 크면(어떤 $N$을 넘으면) 그 이후의 모든 항 $a_n$이 $L$에서 오차 범위 이내에 있다는 뜻입니다.

수렴하지 않는 수열은 **발산**한다고 합니다.

### 직관 및 기하적 의미

$n$이 커질수록 수열의 항들이 어떤 값 $L$ 주변에 점점 더 모여든다는 개념입니다. 

수직선 위에서 생각하면, $L$ 중심의 아무리 좁은 구간 $(L - \varepsilon, L + \varepsilon)$을 그려도, 어느 항부터는 그 구간 내에만 항들이 존재하게 된다는 의미입니다. 처음 몇 항은 구간 밖에 있을 수 있지만, 충분히 뒤쪽의 항들은 모두 구간 안에 갇혀있습니다.

### 기본 예제

**예 1.** $a_n = \frac{1}{n}$일 때, $\lim_{n \to \infty} a_n = 0$입니다.

$\varepsilon > 0$이 주어질 때, $N = \lceil \frac{1}{\varepsilon} \rceil$로 정하면, $n > N$일 때:
$$|a_n - 0| = \frac{1}{n} < \frac{1}{N} \leq \varepsilon$$

따라서 조건을 만족합니다.

**예 2.** $a_n = 2 + \frac{(-1)^n}{n}$일 때, $\lim_{n \to \infty} a_n = 2$입니다. 항들이 $2$ 주위에서 진동하지만 점점 $2$에 가까워집니다: $2.5, 1.5, 2.25, 1.75, \ldots \to 2$.

(sympy 검증: `limit(2 + (-1)**n/n, n, oo)`)

이 정의는 수렴 여부를 엄밀하게 판정할 수 있게 하며, 이후 급수, 함수의 극한, 연속성 등 고등 개념의 기초가 됩니다.
