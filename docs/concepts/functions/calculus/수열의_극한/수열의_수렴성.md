### 정확한 진술

수열 $\{a_n\}$이 실수 $L$로 **수렴한다**는 것은, 임의의 양수 $\varepsilon$에 대하여 다음을 만족하는 자연수 $N$이 존재한다는 뜻입니다:

$$n > N \implies |a_n - L| < \varepsilon$$

이를 기호로 $\lim_{n \to \infty} a_n = L$ 또는 $a_n \to L$ ($n \to \infty$)로 나타냅니다. 이 조건을 만족하지 않으면 수열은 **발산**한다고 합니다.

### 직관 및 기하적 의미

정의의 조건은 다음을 의미합니다:
- 아무리 작은 오차 범위 $\varepsilon$을 정해도, 어느 지점 $N$ 이후의 모든 항은 $L$ 주변 거리 $\varepsilon$ 이내에 들어간다
- 즉, $n$이 충분히 크면 $a_n$과 $L$의 차이가 우리가 원하는 만큼 작아진다

수직선 위에서 보면, 수열의 항들이 극한값 $L$의 양쪽으로 조밀하게 모여드는 모습입니다. **수렴성**은 이러한 "몰려드는" 성질 자체를 의미합니다.

### 구체적 예

$a_n = \frac{1}{n}$은 극한값 $L = 0$으로 수렴합니다. 

예를 들어 $\varepsilon = 0.01$을 잡으면, $N = 100$으로 두었을 때 $n > 100$인 모든 $n$에 대해 $|a_n - 0| = \frac{1}{n} < 0.01$이 성립합니다. 더 작은 $\varepsilon$이 주어지면 더 큰 $N$을 택하면 되므로, 조건이 충족됩니다.

**검증**: `sympy.limit(1/n, n, oo)` → 0

### 주의

- 수렴하는 수열은 **유일한** 극한값을 가집니다 (극한의 유일성)
- 수렴성은 수열의 **처음 유한 개 항**과는 무관하며, 오직 "충분히 뒤의" 항들의 행동만 중요합니다
- 수열이 유계(bounded)라고 해서 반드시 수렴하지는 않습니다 (예: $(-1)^n$)
