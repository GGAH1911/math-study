# 순환소수 분수표현

> **예제** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
등비급수의 합 공식을 활용하여 순환소수를 분수로 변환할 수 있습니다.

## 본문
다음 순환소수를 분수로 나타내시오.

(1) $0.\overline{5}$ (즉, $0.555\ldots$)

(2) $0.1\overline{3}$ (즉, $0.1333\ldots$)

### 단계별 풀이
**(1번 풀이)**
순환하는 부분인 $5$를 소수 자리마다 분해하여 무한급수로 나타내면 $0.555\ldots = \tfrac{5}{10} + \tfrac{5}{100} + \tfrac{5}{1000} + \cdots$입니다. 등비급수 공식을 적용하기 위해 공통인수인 $\tfrac{5}{10}$으로 묶으면 $\tfrac{5}{10} \left(1 + \tfrac{1}{10} + \tfrac{1}{100} + \cdots \right)$이 됩니다. 괄호 안의 식은 첫째항 $a=1$, 공비 $r=\tfrac{1}{10}$인 무한등비급수이므로 그 합은 $\tfrac{1}{1-\tfrac{1}{10}} = \tfrac{10}{9}$입니다. 따라서 $0.\overline{5} = \tfrac{5}{10} \cdot \tfrac{10}{9} = \tfrac{5}{9}$입니다.

**(2번 풀이)**
순환하지 않는 부분과 순환하는 부분을 분리하면 $0.1\overline{3} = 0.1 + 0.0\overline{3}$입니다. 여기서 $0.0\overline{3} = \tfrac{3}{100} + \tfrac{3}{1000} + \cdots$이므로 $\tfrac{3}{100}(1 + \tfrac{1}{10} + \tfrac{1}{100} + \cdots)$으로 쓸 수 있습니다. 괄호 안의 합은 $\tfrac{3}{100} \cdot \tfrac{10}{9} = \tfrac{1}{30}$입니다. 따라서 $0.1\overline{3} = \tfrac{1}{10} + \tfrac{1}{30} = \tfrac{3}{30} + \tfrac{1}{30} = \tfrac{4}{30} = \tfrac{2}{15}$입니다.

### 답과 변형
(1) $\boxed{\tfrac{5}{9}}$
(2) $\boxed{\tfrac{2}{15}}$

**변형 및 주의사항**
순환마디의 길이가 긴 경우에도 동일한 원리가 적용됩니다. 예를 들어 $0.\overline{142857}$은 $\tfrac{142857}{1-1/10^6} = \tfrac{142857}{999999} = \tfrac{1}{7}$로 계산할 수 있습니다. 이때 주의할 점은 순환하지 않는 부분과 순환하는 부분을 명확히 구분하여 공비와 첫째항을 설정하는 것이며, 순환이 시작되는 위치를 $10$의 거듭제곱으로 정확히 파악해야 합니다.

## 학습 체크
- 순환마디의 길이에 따른 분모의 형태를 예측할 수 있는가?
- 순환하지 않는 소수점 아래 자릿수를 고려하여 첫째항을 올바르게 설정하였는가?

## 관련 개념
- **수열의 극한**: 순환소수를 무한급수로 표현하는 과정은 항의 개수가 무한히 많아질 때의 합을 구하는 극한의 개념을 포함합니다.
