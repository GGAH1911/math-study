# 부분분수 분해

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
유리함수를 더 간단한 형태의 분수들의 합으로 나누어 표현하는 방법입니다.

## 본문
유리함수 $\dfrac{P(x)}{Q(x)}$에서 분자의 차수가 분모의 차수보다 작을 때, 이를 더 간단한 유리식들의 합으로 나타내는 것을 **부분분수 분해**라고 합니다. 분모 $Q(x)$를 일차 인수들의 곱으로 인수분해할 수 있다면, 다음과 같이 분해할 수 있습니다.
$$\frac{P(x)}{Q(x)} = \frac{A_1}{x - a_1} + \frac{A_2}{x - a_2} + \cdots + \frac{A_n}{x - a_n}$$
만약 분모에 중근이 포함되어 $(x-a)^2$ 형태의 인수가 있다면 $\dfrac{A}{x-a} + \dfrac{B}{(x-a)^2}$와 같이 나타내며, 중근이 없는 이차식 $x^2 + px + q$가 인수라면 $\dfrac{Cx + D}{x^2 + px + q}$의 형태로 분해합니다.

### 직관과 기하적 의미
복잡한 형태의 유리함수를 기본 단위인 일차식 분수들로 재구성하는 과정입니다. 이는 복잡한 함수를 단순한 구성 요소로 분해하여 분석하는 과정과 같으며, 수열의 극한에서 망원급수를 다룰 때 핵심적인 역할을 합니다.

### 기본 성질
복잡한 유리함수를 여러 개의 단순한 분수로 쪼개면 적분이나 수열의 극한 계산이 훨씬 수월해집니다. 예를 들어 $\dfrac{1}{x(x+1)}$을 직접 적분하는 것은 까다롭지만, 이를 $\dfrac{1}{x} - \dfrac{1}{x+1}$로 분해하면 각각 $\ln|x|$와 $\ln|x+1|$를 이용하여 쉽게 계산할 수 있습니다. 구체적인 예로 $\frac{5x + 1}{(x+1)(x-2)}$는 $\frac{2}{x+1} + \frac{3}{x-2}$로 분해됩니다.

## 학습 체크
- 분자의 차수가 분모의 차수보다 크거나 같을 때는 어떻게 처리해야 하는가?
- 분모에 중근이 있는 경우와 일반적인 이차식이 있는 경우의 분해 형태 차이를 알고 있는가?

## 관련 개념
- **수열의 극한**: 망원급수 형태의 수열의 합을 계산할 때 부분분수 분해를 통해 항들이 서로 소거되는 구조를 파악할 수 있습니다.
