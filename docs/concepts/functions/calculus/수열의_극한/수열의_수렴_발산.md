# 수열의 수렴 발산

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
수열 $\{a_n\}$이 일정한 실수 $L$에 한없이 가까워지면 수렴, 그렇지 않으면 발산이라고 합니다.

## 본문
수열 $\{a_n\}$이 수렴한다는 것은 어떤 실수 $L$이 존재하여, $n$이 충분히 크면 $a_n$이 $L$에 임의로 가까워진다는 것을 의미합니다. 이를 엄밀하게 정의하면, 임의의 양수 $\epsilon$에 대하여 $n > N$일 때 항상 $|a_n - L| < \epsilon$을 만족하는 자연수 $N$이 존재하면 수열 $\{a_n\}$은 $L$로 수렴하며, 이때 $L$을 극한값이라 하고 $\lim_{n\to\infty} a_n = L$로 나타냅니다. 만약 이러한 극한값 $L$이 존재하지 않으면 수열은 발산한다고 합니다.

### 직관과 기하적 의미
이 정의의 핵심은 아무리 작은 오차 범위 $\epsilon$을 설정하더라도, 수열의 항이 충분히 뒤로 가면 모든 항이 그 범위 안에 들어오게 된다는 점입니다. 즉, 수열의 항들이 특정 값 주변으로 점점 더 밀집하며 모여드는 상태를 의미합니다. 반면 발산은 세 가지로 분류되는데, 양의 무한대로 커지는 경우, 음의 무한대로 작아지는 경우, 그리고 $a_n = (-1)^n$처럼 일정한 값으로 모이지 않고 진동하는 경우가 있습니다.

### 기본 성질
수열이 수렴할 때 극한값은 유일하며, 수렴하는 수열의 각 항은 극한값에 한없이 가까워지는 성질을 가집니다. 예를 들어 $a_n = \frac{1}{n}$은 $0$으로 수렴하고, $a_n = n$은 양의 무한대로 발산하며, $a_n = (-1)^n$은 진동 발산합니다.
