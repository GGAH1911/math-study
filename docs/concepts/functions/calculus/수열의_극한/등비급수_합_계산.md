# 등비급수 합 계산

> **예제** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
첫째항이 $a$이고 공비가 $r$인 등비급수는 $|r| < 1$일 때 $\tfrac{a}{1-r}$의 값으로 수렴합니다.

## 본문
다음 무한급수의 합을 구하세요.
$$\sum_{n=1}^{\infty} \left(\frac{1}{2}\right)^n$$

### 단계별 풀이
**단계 1: 급수를 전개하여 형태 파악**  
주어진 식을 처음 몇 항으로 전개하면 $\tfrac{1}{2} + \tfrac{1}{4} + \tfrac{1}{8} + \tfrac{1}{16} + \cdots$가 됩니다. 이를 통해 급수가 일정한 비율로 곱해지는 규칙을 가지고 있음을 알 수 있습니다.

**단계 2: 등비급수임을 확인하고 공비와 첫째항 찾기**  
각 항을 이전 항으로 나누면 $\tfrac{1}{2}$이 되므로, 이는 첫째항 $a = \tfrac{1}{2}$, 공비 $r = \tfrac{1}{2}$인 등비급수입니다. 공비가 $\tfrac{1}{2}$이므로 수렴 조건인 $|r| < 1$을 만족합니다.

**단계 3: 등비급수 합 공식 적용**  
첫째항이 $a$, 공비가 $r$ ($|r| < 1$)인 등비급수의 합 공식 $\tfrac{a}{1-r}$에 대입합니다. 주어진 식은 $\sum_{n=1}^{\infty} \tfrac{1}{2} \cdot \left(\tfrac{1}{2}\right)^{n-1}$로 변형할 수 있으므로, 계산 결과는 다음과 같습니다.
$$S = \frac{\frac{1}{2}}{1 - \frac{1}{2}} = \frac{\frac{1}{2}}{\frac{1}{2}} = 1$$

### 답과 변형
$$\boxed{1}$$

**주의사항**
- **인덱싱의 차이**: 만약 시작 항이 $n=0$이라면 첫째항이 $1$이 되어 합은 $2$가 됩니다.
- **수렴 조건**: 공비의 절댓값이 $1$ 이상이면 급수는 발산하여 합을 구할 수 없습니다.
- **부분합을 통한 검증**: 부분합 $S_N = 1 - \left(\tfrac{1}{2}\right)^N$에서 $N$을 무한대로 보내면 $1$에 수렴함을 확인할 수 있습니다.

## 학습 체크
- 급수의 시작 항($n$의 범위)에 따라 첫째항이 어떻게 변하는지 구분할 수 있는가?
- 공비의 절댓값이 $1$보다 작아야 한다는 수렴 조건을 이해하고 있는가?

## 관련 개념
- **수열의 극한**: 급수의 합은 부분합의 극한값으로 정의되므로 수열의 극한 개념을 기초로 합니다.
