# 극한의 성질

## 정확한 진술

수열 $\{a_n\}$과 $\{b_n\}$이 각각 $a$, $b$로 수렴할 때, 다음이 성립합니다.

(1) **합의 성질**: $\lim_{n \to \infty}(a_n + b_n) = a + b$

(2) **차의 성질**: $\lim_{n \to \infty}(a_n - b_n) = a - b$

(3) **곱의 성질**: $\lim_{n \to \infty}(a_n \cdot b_n) = a \cdot b$

(4) **상수배 성질**: $\lim_{n \to \infty}(c \cdot a_n) = c \cdot a$ (단, $c$는 상수)

(5) **몫의 성질**: $b \neq 0$일 때, $\lim_{n \to \infty}\frac{a_n}{b_n} = \frac{a}{b}$

(6) **대소관계 보존**: $a_n \leq b_n$이면 $a \leq b$

(7) **조임정리**: $a_n \leq c_n \leq b_n$이고 $\lim_{n \to \infty} a_n = \lim_{n \to \infty} b_n = L$이면 $\lim_{n \to \infty} c_n = L$

## 직관/기하적 의미

극한의 성질들은 수열이 어떤 값으로 수렴하는 행동을 **더하기, 빼기, 곱하기, 나누기** 같은 연산으로 조작해도 보존된다는 뜻입니다. 즉, 각 수열이 충분히 큰 $n$에서 극한값에 가까워지면, 이들을 조합한 새로운 수열도 예상한 극한값으로 수렴합니다.

조임정리는 직관적으로 "샌드위치처럼 위아래에서 같은 값으로 압박되면 가운데 수열도 그 값으로 압박된다"는 의미입니다. 이는 수렴을 증명할 때 매우 강력한 도구가 됩니다.

## 한 줄 예

$a_n = \frac{1}{n}$, $b_n = \frac{2}{n}$이면 $\lim_{n \to \infty}(a_n + b_n) = 0 + 0 = 0$이고, $\lim_{n \to \infty}(3a_n) = 3 \cdot 0 = 0$입니다.
