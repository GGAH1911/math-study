# 분자분모 최고차항 비교

## 정확한 진술

분자와 분모의 최고차항을 비교하는 것은 유리식(또는 유리함수)의 극한을 구할 때 사용하는 기본 기법입니다. 

$\lim_{n \to \infty} \frac{a_m n^m + a_{m-1}n^{m-1} + \cdots + a_0}{b_k n^k + b_{k-1}n^{k-1} + \cdots + b_0}$ 형태의 극한에서, 최고차항이 지배적이므로 다음과 같이 판정합니다:

- **$m > k$일 때**: 극한은 $\pm \infty$ (분자가 더 빠르게 증가)
- **$m = k$일 때**: 극한은 $\dfrac{a_m}{b_k}$ (최고차항의 계수 비)
- **$m < k$일 때**: 극한은 $0$ (분모가 더 빠르게 증가)

## 직관 및 활용

충분히 큰 $n$에 대해, 낮은 차수의 항들은 최고차항과 비교하면 상대적으로 무시할 수 있을 정도로 작습니다. 예를 들어 $n = 10000$일 때, $n^2$ 항에 비해 $n$ 항이나 상수항은 거의 영향을 주지 않습니다. 따라서 전체 식의 극한 동작은 **최고차항의 차수와 계수 비율**에 의해 완전히 결정됩니다.

이 기법은 단순히 극한값을 빠르게 구하는 것을 넘어, 수열과 함수의 **점근 거동(asymptotic behavior)**을 이해하는 핵심입니다. 또한 적분의 수렴성, 함수의 무한대에서의 성질을 판정할 때도 필수적입니다.

## 구체적 예

$$\lim_{n \to \infty} \frac{3n^2 + 5n + 2}{2n^2 - n + 1}$$

분자의 최고차항: $3n^2$, 분모의 최고차항: $2n^2$. 차수가 같으므로 극한은 계수 비율 $\dfrac{3}{2}$.

검증 (sympy): `sympy.limit((3*n**2 + 5*n + 2)/(2*n**2 - n + 1), n, sympy.oo)` → $\dfrac{3}{2}$
