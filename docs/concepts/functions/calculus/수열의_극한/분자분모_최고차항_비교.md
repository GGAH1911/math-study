# 분자분모 최고차항 비교

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
유리식의 극한을 구할 때 분자와 분모의 최고차항 차수를 비교하여 극한값의 발산 또는 수렴 여부를 판정하는 방법입니다.

## 본문
$\lim_{n \to \infty} \tfrac{a_m n^m + a_{m-1}n^{m-1} + \cdots + a_0}{b_k n^k + b_{k-1}n^{k-1} + \cdots + b_0}$ 형태의 유리식에서 극한값은 분자와 분모의 최고차항이 지배적인 역할을 수행하므로, 최고차항의 차수($m, k$)를 비교하여 결정합니다. 분자의 차수가 분모보다 크면($m > k$) 극한은 $\pm \infty$로 발산하며, 차수가 같으면($m = k$) 두 최고차항의 계수 비율인 $\tfrac{a_m}{b_k}$로 수렴합니다. 반대로 분모의 차수가 더 크면($m < k$) 극한은 $0$으로 수렴합니다.

### 직관과 기하적 의미
충분히 큰 $n$에 대하여 낮은 차수의 항들은 최고차항의 크기에 비해 상대적으로 매우 작아져 전체 식의 값에 거의 영향을 주지 못합니다. 예를 들어 $n$이 매우 커지면 $n^2$ 항에 비해 $n$이나 상수항은 무시할 수 있는 수준이 되므로, 식 전체의 거동은 오직 최고차항의 차수와 계수 비율에 의해서만 결정됩니다. 이는 함수의 점근 거동을 파악하는 핵심적인 원리입니다.

### 기본 성질
- 분자의 차수가 높으면 무한대로 발산한다.
- 분모의 차수가 높으면 $0$으로 수렴한다.
- 차수가 같으면 계수의 비가 극한값이 된다.

## 학습 체크
- 분자와 분모의 차수가 같을 때, 왜 나머지 항들을 무시하고 계수만 비교해도 결과가 동일한가?
- 극한값이 $\pm \infty$로 발산할 때, 부호를 결정하기 위해 추가로 확인해야 할 요소는 무엇인가?

## 관련 개념
- **수열의 극한**: 수열의 일반항이 유리식 형태일 때, 이 기법을 사용하여 수열의 수렴과 발산을 판정할 수 있습니다.
- **함수의 극한**: 함수의 무한대에서의 성질을 파악하거나 점근선을 구할 때 이 원리가 필수적으로 사용됩니다.
- **적분의 수렴성**: 이상적분의 수렴 여부를 판정할 때 피적분 함수의 무한대에서의 거동을 파악하는 도구로 활용됩니다.
