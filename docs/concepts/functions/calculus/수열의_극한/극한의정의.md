### 정확한 진술

함수 $f(x)$가 $x = a$ 근처에서 정의되어 있을 때, **$x$가 $a$에 가까워질수록 $f(x)$가 어떤 값 $L$에 가까워지면, "$x \to a$일 때 $f(x)$의 극한은 $L$"이라고** 하고 다음과 같이 나타냅니다:

$$\lim_{x \to a} f(x) = L$$

더 엄밀하게는: 임의의 양수 $\varepsilon$에 대해, 어떤 양수 $\delta$가 존재하여 $0 < |x - a| < \delta$이면 $|f(x) - L| < \varepsilon$일 때를 말합니다. 

**중요**: 극한의 존재 여부는 $f(a)$의 값과 무관합니다. $x$가 $a$에 가까워지는 과정에서의 $f(x)$의 행동만 고려합니다.

### 직관/기하적 의미

그래프 관점에서, $x$를 $a$로 점점 더 가깝게 움직일 때 대응하는 함수값들이 하나의 값 $L$로 모여드는 모습을 상상하면 됩니다. 마치 수열의 극한처럼, 함수도 특정 점 근처에서 "어느 한 값으로 수렴"하는 경향을 보입니다.

수열의 극한과의 차이점: 수열은 정의역이 자연수뿐이지만, 함수는 연속적인 정의역을 가지므로, 한쪽 방향(좌극한, 우극한)에서만 접근할 수도 있습니다. 양쪽에서 같은 값으로 수렴할 때만 극한이 존재합니다.

### 한 줄 예

$\lim_{x \to 2} (3x - 1) = 5$ (직관: $x$가 2에 가까워질수록 $3x-1$은 5에 가까워진다)

검증: `sympy.limit(3*x - 1, x, 2)` → `5`
