# 망원급수

## 정확한 진술

망원급수는 수열 $\{a_n\}$으로 만든 급수 $\sum_{n=1}^{\infty} a_n$에서 부분합 $S_N = \sum_{n=1}^{N} a_n$을 전개했을 때 대부분의 항이 소거되어 소수의 항만 남는 급수입니다. 일반적으로 $a_n = b_n - b_{n+1}$ 형태(또는 더 일반적으로 $a_n = f(n) - f(n+k)$ 형태)일 때 발생합니다.

## 직관과 기하적 의미

망원(telescope)은 앞뒤로 겹쳐진 원통이 축약되는 모습을 의미합니다. 마찬가지로 이 급수에서도 연속된 항들이 서로 상쇄됩니다.

부분합을 구체적으로 펼쳐보면:
$$S_N = (b_1 - b_2) + (b_2 - b_3) + (b_3 - b_4) + \cdots + (b_N - b_{N+1})$$

중간의 모든 항($-b_2 + b_2$, $-b_3 + b_3$ 등)이 소거되어:
$$S_N = b_1 - b_{N+1}$$

따라서 급수가 수렴하려면 $\lim_{N \to \infty} b_{N+1}$이 존재해야 하고, 수렴값은:
$$\sum_{n=1}^{\infty} a_n = b_1 - \lim_{N \to \infty} b_{N+1}$$

이 성질을 이용하면 복잡해 보이는 급수도 첫 항과 극한값 계산만으로 빠르게 답을 구할 수 있습니다.

## 예제: 부분분수 분해를 통한 망원급수

$\sum_{n=1}^{\infty} \frac{1}{n(n+1)}$를 계산하세요.

**풀이:**  
$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$로 부분분수 분해됩니다.

부분합은:
$$S_N = \sum_{n=1}^{N} \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1 - \frac{1}{N+1}$$

극한을 취하면:
$$\sum_{n=1}^{\infty} \frac{1}{n(n+1)} = \lim_{N \to \infty} \left(1 - \frac{1}{N+1}\right) = 1$$

(검증: `from sympy import symbols, apart, summation; summation(1/(n*(n+1)), (n, 1, float('inf')))`)
