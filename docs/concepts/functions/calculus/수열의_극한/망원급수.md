# 망원급수

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
연속된 항들이 서로 상쇄되어 중간 항들이 사라지고 첫 항과 마지막 항의 극한값만 남는 급수입니다.

## 본문
망원급수는 수열 $\{a_n\}$으로 만든 급수 $\sum_{n=1}^{\infty} a_n$에서 부분합 $S_N = \sum_{n=1}^{N} a_n$을 전개했을 때 대부분의 항이 소거되어 소수의 항만 남는 급수입니다. 일반적으로 $a_n = b_n - b_{n+1}$ 또는 더 일반적으로 $a_n = f(n) - f(n+k)$ 형태일 때 발생합니다.

### 직관과 기하적 의미
망원(telescope)은 앞뒤로 겹쳐진 원통이 축약되는 모습을 의미합니다. 이 급수에서도 연속된 항들이 서로 상쇄되어 마치 망원경을 접었을 때 길이가 줄어드는 것처럼 급수의 합이 단순화됩니다.

### 기본 성질
부분합을 구체적으로 펼쳐보면 $S_N = (b_1 - b_2) + (b_2 - b_3) + (b_3 - b_4) + \cdots + (b_N - b_{N+1})$이 됩니다. 이때 중간의 모든 항($-b_2 + b_2$, $-b_3 + b_3$ 등)이 소거되어 $S_N = b_1 - b_{N+1}$이라는 단순한 형태가 됩니다. 따라서 급수가 수렴하려면 $\lim_{N \to \infty} b_{N+1}$이 존재해야 하며, 이때의 수렴값은 $\sum_{n=1}^{\infty} a_n = b_1 - \lim_{N \to \infty} b_{N+1}$입니다. 이 성질을 이용하면 복잡한 급수도 첫 항과 극한값 계산만으로 빠르게 구할 수 있습니다.

예를 들어 $\sum_{n=1}^{\infty} \tfrac{1}{n(n+1)}$의 경우, $\tfrac{1}{n(n+1)} = \tfrac{1}{n} - \tfrac{1}{n+1}$로 부분분수 분해가 가능합니다. 부분합 $S_N = 1 - \tfrac{1}{N+1}$에 극한을 취하면 결과값은 $1$이 됩니다.

## 학습 체크
- 일반항 $a_n$이 $b_n - b_{n+1}$ 꼴으로 나타날 때, 부분합 $S_N$에서 소거되지 않고 남는 항은 무엇인가?
- 망원급수가 수렴하기 위해 반드시 전제되어야 하는 조건은 무엇인가?

## 관련 개념
- **수열의 극한**: 망원급수의 수렴값을 결정하기 위해 부분합의 극한값을 계산하는 과정에서 필수적으로 사용됩니다.
