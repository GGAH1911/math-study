# 극한의 유리화

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
무리식이 포함된 극한식에서 분자나 분모에 켤레식을 곱하여 근호를 제거함으로써 부정형을 해결하는 계산 기법입니다.

## 본문
극한의 유리화란 무리식(근호를 포함한 식)이 있는 극한식을 계산할 때, 분자나 분모에 켤레식을 곱하여 무리식을 제거하거나 식을 단순화하는 기법입니다. 일반적으로 $\sqrt{A} - \sqrt{B}$ 형태의 식에는 $\sqrt{A} + \sqrt{B}$를, $\sqrt{A} - B$ 형태에는 $\sqrt{A} + B$를 분자와 분모에 각각 곱하여 계산합니다.

$$\lim_{x \to a} \frac{\sqrt{f(x)} - \sqrt{f(a)}}{x - a} = \lim_{x \to a} \frac{(\sqrt{f(x)} - \sqrt{f(a)})(\sqrt{f(x)} + \sqrt{f(a)})}{(x-a)(\sqrt{f(x)} + \sqrt{f(a)})} = \lim_{x \to a} \frac{f(x) - f(a)}{(x-a)(\sqrt{f(x)} + \sqrt{f(a)})}$$

무리식이 포함된 극한 문제는 값을 직접 대입했을 때 대개 $\frac{0}{0}$ 꼴의 부정형이 되어 값을 바로 구할 수 없습니다. 이때 유리화를 통해 제곱의 차 공식 $(A-B)(A+B) = A^2 - B^2$을 적용하면 근호를 제거할 수 있으며, 이후 약분이나 인수분해를 통해 극한값을 도출할 수 있습니다. 이 기법은 도함수의 정의를 이용한 미분 계수 계산이나 수열의 극한 문제를 풀 때 매우 중요한 대수적 도구로 사용됩니다.

### 직관과 기하적 의미
무리식이 포함된 식은 변화율을 직접적으로 파악하기 어렵게 만들지만, 유리화를 통해 식을 다항식의 형태로 변환하면 극한의 수렴 여부를 명확하게 확인할 수 있습니다.

### 기본 성질
- $\sqrt{A} - \sqrt{B}$에 $\sqrt{A} + \sqrt{B}$를 곱하면 $A - B$가 되어 근호가 사라집니다.
- 유리화 과정에서 분모나 분자에 곱해진 켤레식은 극한값 계산 시 분모를 0이 아닌 값으로 만들어 계산을 가능하게 합니다.

## 학습 체크
- 분자 또는 분모 중 어느 쪽에 유리화를 적용해야 식의 형태가 단순해지는지 판단할 수 있는가?
- 유리화 과정에서 곱해준 켤레식이 분모를 0으로 만들지는 않는지 확인하였는가?
- 유리화 이후 나타나는 공통 인수를 정확히 찾아 약분하였는가?

## 관련 개념
- **수열의 극한**: 수열의 극한에서도 무리식이 포함된 일반항의 극한을 구할 때 유리화 기법이 동일하게 적용됩니다.
- **미분계수**: 미분계수의 정의를 이용해 미분 가능한 함수의 도함수를 구할 때, 무리함수의 미분 계수를 구하는 과정에서 필수적으로 사용됩니다.
