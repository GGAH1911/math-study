# 극한의 유리화

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 정확한 진술

극한의 유리화란 무리식(근호를 포함한 식)이 있는 극한식을 계산할 때, 분자나 분모에 켤레식을 곱하여 무리식을 제거하거나 간단히 하는 기법입니다. 보통 $\sqrt{A} - \sqrt{B}$ 형태의 식에는 $\sqrt{A} + \sqrt{B}$를, $\sqrt{A} - B$ 형태에는 $\sqrt{A} + B$를 분자와 분모에 곱합니다.

$$\lim_{x \to a} \frac{\sqrt{f(x)} - \sqrt{f(a)}}{x - a} = \lim_{x \to a} \frac{(\sqrt{f(x)} - \sqrt{f(a)})(\sqrt{f(x)} + \sqrt{f(a)})}{(x-a)(\sqrt{f(x)} + \sqrt{f(a)})} = \lim_{x \to a} \frac{f(x) - f(a)}{(x-a)(\sqrt{f(x)} + \sqrt{f(a)})}$$

## 직관과 의의

무리식이 있는 극한 문제는 직접 대입하면 대개 $\frac{0}{0}$ 꼴의 부정형이 되어 계산할 수 없습니다. 유리화를 하면 제곱의 차 공식 $(A-B)(A+B) = A^2 - B^2$를 이용해 근호를 제거할 수 있고, 그 결과 약분이나 인수분해를 통해 극한값을 구할 수 있게 됩니다. 이는 도함수의 정의나 수열의 극한에서 자주 나타나는 중요한 대수적 기법입니다.

## 한 줄 예

$\displaystyle \lim_{x \to 0} \frac{\sqrt{x+1} - 1}{x}$를 구할 때 분자를 유리화합니다:

$$\lim_{x \to 0} \frac{(\sqrt{x+1} - 1)(\sqrt{x+1} + 1)}{x(\sqrt{x+1} + 1)} = \lim_{x \to 0} \frac{x}{x(\sqrt{x+1} + 1)} = \lim_{x \to 0} \frac{1}{\sqrt{x+1} + 1} = \frac{1}{2}$$

검산: `sympy.limit((sqrt(x+1) - 1)/x, x, 0)` 결과 $\frac{1}{2}$
