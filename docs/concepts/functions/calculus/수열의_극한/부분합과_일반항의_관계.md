# 부분합과 일반항의 관계

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
수열의 일반항은 부분합의 첫 번째 항은 $S_1$과 같고, $n$번째 항부터는 $S_n$과 $S_{n-1}$의 차이로 구할 수 있습니다.

## 본문
수열 $\{a_n\}$의 첫 번째 항부터 $n$번째 항까지의 합을 부분합이라 하며, 기호 $S_n$으로 나타냅니다: $S_n = a_1 + a_2 + a_3 + \cdots + a_n$. 이때 수열의 일반항 $a_n$과 부분합 $S_n$ 사이에는 다음과 같은 관계가 성립합니다. 첫 번째 항은 $a_1 = S_1$이며, $n \geq 2$인 모든 자연수에 대하여 $a_n = S_n - S_{n-1}$입니다.

### 직관과 기하적 의미
부분합은 수열의 항들을 차례대로 더하여 쌓아 올린 누적값입니다. $S_{n-1}$에서 $S_n$으로 넘어갈 때 증가한 양이 바로 새로운 항인 $a_n$이 됩니다. 이는 통장 잔액의 변화를 통해 월별 입금액을 계산하는 것과 같습니다. 즉, 누적된 총액의 차이를 구하면 그 시점에 더해진 개별 값을 알 수 있다는 원리입니다. 다만, 첫 번째 항은 이전 단계의 합($S_0$)이 존재하지 않으므로 $a_1 = S_1$이라는 특수한 형태를 가집니다.

### 기본 성질
예를 들어 $S_n = n^2$인 경우를 살펴보면 다음과 같습니다. 먼저 $a_1 = S_1 = 1^2 = 1$입니다. $n \geq 2$일 때 $a_n = S_n - S_{n-1} = n^2 - (n-1)^2 = 2n - 1$입니다. 이때 $a_1 = 1$과 $2(1)-1 = 1$이 일치하므로, 모든 자연수 $n$에 대하여 일반항은 $a_n = 2n - 1$로 정의됩니다.

## 학습 체크
- $n \geq 2$일 때 구한 일반항이 $n=1$일 때의 값($a_1 = S_1$)과 일치하는지 반드시 확인해야 합니다.
- 부분합 $S_n$이 주어졌을 때, $n=1$인 경우를 따로 분리하여 계산해야 하는 상황을 주의해야 합니다.

## 관련 개념
- **수열의 극한**: 부분합 $S_n$의 극한값이 존재하면 수열 $\{a_n\}$은 0으로 수렴하며, 이는 급수의 수렴 여부를 판단하는 기초가 됩니다.
