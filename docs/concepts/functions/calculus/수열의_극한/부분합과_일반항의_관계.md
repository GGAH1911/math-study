# 부분합과 일반항의 관계

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 정확한 진술

수열 $\{a_n\}$의 첫 번째부터 $n$번째 항까지의 합을 부분합이라 하고, 기호 $S_n$으로 나타냅니다:
$$S_n = a_1 + a_2 + a_3 + \cdots + a_n$$

일반항과 부분합의 관계식은:
- $a_1 = S_1$
- $a_n = S_n - S_{n-1} \quad (n \geq 2)$

## 직관 및 의미

부분합은 수열을 차례로 더해나가며 쌓아올린 누적값입니다. $S_{n-1}$에서 $S_n$으로 넘어갈 때 증가한 양이 바로 $a_n$입니다. 이는 마치 통장 잔액으로부터 월별 입금액을 구하는 것과 같습니다—부분합의 "차이" = 일반항이라는 원리입니다. 첫 번째 항은 특수한 경우로, 부분합이 한 단계도 없으므로 $a_1 = S_1$이 됩니다.

## 구체적 예

$S_n = n^2$일 때:
- $a_1 = S_1 = 1^2 = 1$
- $n \geq 2$일 때: $a_n = n^2 - (n-1)^2 = 2n - 1$

$a_1 = 1 = 2(1) - 1$이므로 일반항은 모든 $n \geq 1$에 대해 $a_n = 2n - 1$입니다.

검증: `sympy.expand(n**2 - (n-1)**2)` = $2n - 1$ ✓
