# 수열의 극한

> **단원** · 미적분 · 선수: [수열](/concepts/수열) / [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 학습 목표
- 수열 $\{a_n\}$의 극한 $\lim_{n\to\infty} a_n$ 정의를 이해한다
- 등비수열·등비급수의 수렴 조건을 활용한다
- 급수의 합을 구할 수 있다

## 다룰 정의 / 정리 / 예제

**정의**
- 수열의 극한
- 수렴, 발산
- [급수](/concepts/급수) — 부분합
- 등비급수

**정리**
- 극한의 사칙연산
- 급수 수렴 판정
- 등비급수 합 $\frac{a}{1-r}$ ($|r|<1$)

**예제**
- 수렴/발산 판별
- 급수의 합 계산
- 순환소수를 분수로
