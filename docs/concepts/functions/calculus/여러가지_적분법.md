# 여러가지 적분법

> **단원** · 미적분 · 선수: [적분](/concepts/적분) / [합성함수의 미분](/concepts/합성함수의_미분)

## 학습 목표
- 치환적분과 부분적분을 활용한다
- 지수·로그·삼각함수의 적분을 수행한다

## 다룰 정의 / 정리 / 예제

**정의**
- [치환적분](/concepts/치환적분)
- [부분적분](/concepts/부분적분)

**정리**
- 치환적분 $\int f(g(x))g'(x)dx$
- 부분적분 $\int u dv = uv - \int v du$

**예제**
- $\int \sin(2x)dx$
- $\int x e^x dx$
- $\int \ln x dx$
