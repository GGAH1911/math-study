# 무리함수 그래프

> **예제** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
$y=\sqrt{x-a}+b$

## 본문 (학습 시 채워짐)

### 문제

다음 함수의 그래프를 그리고, 점 $(5, y)$에서의 함숫값을 구하시오.
$$y = \sqrt{x-1} + 2$$

### 단계별 풀이

**1단계: 정의역 확인**  
루트 안이 0 이상이어야 하므로 $x - 1 \geq 0$, 즉 $x \geq 1$입니다. 무리함수는 정의역에서만 그래프를 그릴 수 있으므로 정의역 확인이 필수입니다.

**2단계: 기준점 찾기**  
함수 $y = \sqrt{x-a} + b$는 $y = \sqrt{x}$를 오른쪽으로 $a$, 위로 $b$만큼 평행이동한 것입니다. 따라서 $x = 1$일 때 $y = \sqrt{1-1} + 2 = 0 + 2 = 2$이므로, 그래프의 시작점은 $(1, 2)$입니다. 이 점에서부터 함수가 정의되기 시작합니다.

**3단계: 구간별 함숫값 구하기**  
그래프의 모양을 파악하기 위해 몇 가지 점을 더 계산합니다.
- $x = 2$일 때: $y = \sqrt{2-1} + 2 = 1 + 2 = 3$
- $x = 5$일 때: $y = \sqrt{5-1} + 2 = \sqrt{4} + 2 = 2 + 2 = 4$  
($\text{sympy.sqrt(5-1) + 2}$ 검산: 4)

**4단계: 그래프 그리기**  
점 $(1, 2) \to (2, 3) \to (5, 4)$를 지나며, $x$가 증가할수록 천천히 증가하는 완만한 곡선입니다. 무리함수는 이차함수보다 천천히 증가하는 특징이 있습니다.

### 답

점 $(5, y)$에서 함숫값은 **$y = 4$**입니다.

- 정의역: $x \geq 1$
- 치역: $y \geq 2$

### 변형/주의

- **근호 안의 조건**: $\sqrt{x-1}$은 $x \geq 1$에서만 정의되므로, 정의역이 $x > 1$이 아니라 $x \geq 1$임을 유의하세요.
- **치역 구하는 법**: 무리함수 $y = \sqrt{x-a} + b$의 최솟값은 $x = a$일 때 $y = b$이므로, 치역은 항상 $y \geq b$입니다.
- **음수 버전 주의**: $y = -\sqrt{x-a} + b$ 형태면 치역이 $y \leq b$가 되므로 방향을 확인하세요.
