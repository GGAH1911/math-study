### 정확한 진술

함수 $f : X \to Y$를 나타내는 방법은 다음과 같습니다.

1. **식 (공식)**: $f(x) = 2x + 1$ 처럼 대수식으로 나타내기
2. **표 (대응표)**: $x$값과 $f(x)$값을 행/열로 정리하기
3. **그래프**: 좌표평면에 점 $(x, f(x))$를 표시하기
4. **말 (기술)**: "각 수를 제곱하는 함수"처럼 문장으로 설명하기

이 네 가지 방식은 모두 동일한 함수를 다른 관점에서 보여줍니다.

### 직관과 기하적 의미

각 표현 방식은 함수를 이해하는 서로 다른 렌즈입니다:

- **식**은 임의의 $x$값에 대해 정확한 함숫값을 계산하기에 효율적입니다.
- **표**는 구체적인 대응 관계를 한눈에 볼 수 있어 패턴 인식이 쉽습니다.
- **그래프**는 함수의 전체 형태, 증감 구간, 극값 등을 시각적으로 파악하는 데 탁월합니다.
- **말**은 현실의 상황을 함수로 이해하는 가장 자연스러운 시작점입니다.

예를 들어, $y = 2x$는 원점을 지나는 직선의 모습이지만, 같은 함수를 표로 쓰면 $(1, 2), (2, 4), (3, 6), \ldots$이고, 문장으로는 "입력의 2배를 출력한다"라고 설명됩니다.

### 한 줄 예

함수 $f(x) = x^2$을 식으로는 $f(x) = x^2$, 표로는 $\{(-1, 1), (0, 0), (1, 1), (2, 4)\}$, 그래프로는 원점 꼭짓점의 아래로 볼록한 포물선, 문장으로는 "입력을 제곱하는 함수"로 나타냅니다.
