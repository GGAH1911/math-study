# 역함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
$f^{-1}\circ f=I$

## 본문 (학습 시 채워짐)

### 정확한 진술

함수 $f: A \to B$가 **전단사**(일대일 대응)일 때, $f$의 **역함수** $f^{-1}: B \to A$는 다음을 만족하는 함수입니다:

$$f^{-1}(b) = a \iff f(a) = b$$

즉, $f$가 $a$를 $b$로 옮기면, $f^{-1}$은 $b$를 다시 $a$로 돌려보냅니다. 역함수는 원래 함수가 **전단사**일 때만 존재합니다.

### 직관과 기하적 의미

역함수는 함수의 대응 관계를 **역으로 뒤집은 것**입니다. 함수 $f$가 입력 $x$에서 출력 $y$로의 화살표라면, 역함수 $f^{-1}$은 그 화살표를 반대 방향으로 되돌립니다.

**기하적으로**, $y = f(x)$의 그래프 위의 점 $(a, b)$에 대해, $y = f^{-1}(x)$의 그래프는 **$y = x$ 직선을 기준으로 대칭**입니다. 따라서 점 $(b, a)$를 지나갑니다. 이는 $x$와 $y$ 좌표를 바꾸는 것과 같습니다.

### 합성함수의 성질

역함수의 정의에서 자동으로 따라오는 중요한 성질이 있습니다:

$$(f^{-1} \circ f)(x) = f^{-1}(f(x)) = x, \quad (f \circ f^{-1})(y) = f(f^{-1}(y)) = y$$

즉, 함수와 역함수를 합성하면 항등함수 $I$가 됩니다. 이것이 페이지 요약 $f^{-1} \circ f = I$의 의미입니다.

### 예제

$f(x) = 2x + 1$ (정의역 $\mathbb{R}$, 치역 $\mathbb{R}$)의 역함수를 구하면:
$$y = 2x + 1 \Rightarrow x = \frac{y-1}{2}$$
따라서 $f^{-1}(x) = \frac{x-1}{2}$입니다. 검증: $f(f^{-1}(3)) = f(1) = 3$ ✓
(`sympy.solve(2*x + 1 - y, x)` → `[(y - 1)/2]`)
