# 거리 계산

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 **거리(distance)**는 다음 공식으로 구합니다:

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

거리는 항상 0 이상인 실수이며, 두 점이 일치하면 거리는 0, 서로 다르면 거리는 양수입니다.

## 직관/기하적 의미

이 공식은 **피타고라스 정리**에서 유도됩니다. 두 점 $A$와 $B$를 꼭짓점으로 하는 직각삼각형을 좌표평면에 그리면, 가로 변의 길이는 $|x_2 - x_1|$이고 세로 변의 길이는 $|y_2 - y_1|$입니다. 두 점을 잇는 선분이 빗변이므로, 피타고라스 정리에 의해 그 길이가 위 공식이 됩니다.

기하학적으로 보면, 거리는 좌표평면 위 두 점을 연결하는 선분의 실제 길이입니다. 이 개념은 함수의 그래프 위 두 점 사이 거리 계산, 원의 방정식, 점과 직선 사이의 거리 구하기 등 고등학교 수학 전반에서 자주 사용되는 기초 도구입니다.

## 한 줄 예

점 $A(1, 2)$와 점 $B(4, 6)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$입니다.

(검산: `math.sqrt((4-1)**2 + (6-2)**2)` → 5.0)
