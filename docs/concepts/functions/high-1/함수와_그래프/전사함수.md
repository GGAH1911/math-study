# 전사함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
공역의 모든 원소가 정의역의 원소로부터 화살표를 받아 치역과 공역이 일치하는 함수입니다.

## 본문
함수 $f: A \to B$가 전사함수(onto function)라는 것은 임의의 $b \in B$에 대해 $f(a) = b$를 만족하는 $a \in A$가 반드시 존재함을 의미합니다. 이를 다른 관점에서 표현하면 함수의 치역과 공역이 서로 같음, 즉 $\{f(a) \mid a \in A\} = B$를 만족하는 함수라고 할 수 있습니다.

### 직관과 기하적 의미
전사함수는 정의역의 원소들이 공역의 모든 원소를 빠짐없이 커버하는 상태를 말합니다. 예를 들어, 여러 명의 사람이 다양한 직업에 배치될 때, 공역에 있는 모든 직업이 최소 한 명 이상의 사람에게 할당되어 있다면 이는 전사함수입니다. 만약 공역 중 단 하나의 원소라도 화살표를 받지 못해 선택되지 않는다면 그 함수는 전사함수가 될 수 없습니다. 화살표 다이어그램을 그렸을 때 공역의 모든 원소에 화살표가 도착해야 한다는 점이 핵심입니다.

### 기본 성질
- 예시 1: $f: \{1, 2, 3\} \to \{a, b\}$에서 $f(1)=a, f(2)=b, f(3)=b$이면 공역의 모든 원소가 화살표를 받으므로 전사함수입니다.
- 예시 2: $f: \mathbb{R} \to \mathbb{R}$에서 $f(x) = x^2$이면 치역이 $[0, \infty)$이므로 공역인 실수 전체와 일치하지 않아 전사함수가 아닙니다.
- 예시 3: $f: \mathbb{Z} \to \mathbb{Z}$에서 $f(n) = 2n$이면 치역이 짝수 집합이므로 공역인 정수 집합과 일치하지 않아 전사함수가 아닙니다.
- 예시 4: $f: \mathbb{R} \to \mathbb{R}$에서 $f(x) = 2x + 1$이면 모든 실수 $y$에 대응하는 $x$가 존재하므로 전사함수입니다.

## 학습 체크
- 함수의 치역이 공역의 부분집합이라는 점을 고려할 때, 언제 치역과 공역이 같아지는지 설명할 수 있는가?
- $f(x) = x^2$과 같은 함수가 공역을 어떻게 설정하느냐에 따라 전사함수가 될 수도, 되지 않을 수도 있음을 이해하는가?

## 관련 개념
- **함수**: 정의역의 각 원소가 공역의 원소에 하나씩 대응되는 기본 구조를 제공합니다.
- **치역**: 함수에 의해 실제로 화살표를 받은 공역의 원소 집합으로, 전사함수 여부를 결정하는 핵심 요소입니다.
- **공역**: 함수가 대응될 수 있는 전체 대상 집합으로, 전사함수에서는 치역과 반드시 일치해야 합니다.
