# 상수함수

## 정확한 진술

함수 $f: X \to \mathbb{R}$가 **상수함수**라 함은, 정의역의 모든 원소 $x \in X$에 대하여 $f(x) = c$ (단, $c$는 상수)로 같은 값을 대응시키는 경우를 말합니다. 즉, 정의역이 어떻게 변하든 함숫값은 항상 일정합니다.

## 직관과 기하적 의미

상수함수의 그래프를 좌표평면에 나타내면 수평선 형태가 됩니다. 예를 들어 $f(x) = 3$이면, $x$축 위의 모든 점에서 높이가 3으로 일정하므로 $y = 3$인 직선입니다. 이는 함수가 입력값의 변화에 전혀 반응하지 않음을 시각적으로 보여줍니다.

상수함수는 변화가 없다는 특징이 있습니다. 따라서 도함수를 구하면 $f'(x) = 0$이 되며, 정적분을 계산할 때도 $\int_a^b c \, dx = c(b-a)$처럼 단순한 형태입니다.

## 간단한 예시

**예1:** $f(x) = 2$는 모든 $x$ 값에 대해 함숫값이 2인 상수함수입니다.
- $f(-5) = 2$, $f(0) = 2$, $f(100) = 2$

**예2:** 실생활 예시로, 일정한 속도로 움직이지 않고 정지해 있는 물체의 속도 함수 $v(t) = 0$ (모든 시간 $t$에서 속도가 0)도 상수함수입니다.

**예3:** 함수 $g(x) = -7$의 그래프는 $y = -7$인 수평선입니다.

## 핵심 성질

상수함수 $f(x) = c$는:
- 기울기가 0인 일차함수로도 볼 수 있습니다 ($f(x) = 0 \cdot x + c$).
- 최댓값과 최솟값이 모두 $c$로 같습니다.
- 일대일 대응이 아니므로 역함수를 갖지 않습니다.

상수함수는 단순해 보이지만, 미분·적분이나 함수의 극한 개념을 배울 때 비교 대상으로 자주 나타나는 중요한 기본 함수입니다.
