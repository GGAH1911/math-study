# 상수함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역의 모든 원소에 대해 함숫값이 하나의 상수로 일정한 함수입니다.

## 본문
함수 $f: X \to \mathbb{R}$가 상수함수라 함은, 정의역의 모든 원소 $x \in X$에 대하여 $f(x) = c$ (단, $c$는 상수)로 같은 값을 대응시키는 경우를 말합니다. 즉, 정의역이 어떻게 변하든 함숫값은 항상 일정합니다. 예를 들어 $f(x) = 2$는 모든 $x$ 값에 대해 함숫값이 2이며, $g(x) = -7$의 그래프는 $y = -7$인 수평선이 됩니다. 실생활에서는 정지해 있는 물체의 속도 함수 $v(t) = 0$과 같이 모든 시간에서 값이 변하지 않는 상태를 나타낼 때 사용됩니다.

### 직관과 기하적 의미
상수함수의 그래프를 좌표평면에 나타내면 수평선 형태가 됩니다. 예를 들어 $f(x) = 3$이면, $x$축 위의 모든 점에서 높이가 3으로 일정하므로 $y = 3$인 직선이 됩니다. 이는 함수가 입력값의 변화에 전혀 반응하지 않음을 시각적으로 보여줍니다. 또한 변화가 없다는 특징 때문에 미분하면 도함수가 $0$이 되며, 정적분 계산 시 $\int_a^b c \, dx = c(b-a)$와 같이 단순한 형태를 띱니다.

### 기본 성질
- 기울기가 0인 일차함수의 특수한 형태로 볼 수 있습니다 ($f(x) = 0 \cdot x + c$).
- 함숫값이 항상 일정하므로 최댓값과 최솟값이 모두 $c$로 같습니다.
- 모든 함숫값이 같으므로 일대일 대응이 아니며, 따라서 역함수를 갖지 않습니다.

## 학습 체크
- 상수함수의 그래프가 $x$축과 평행한 수평선임을 이해하고 있는가?
- 상수함수의 미분값이 왜 $0$이 되는지 기하학적 기울기와 연결하여 설명할 수 있는가?
- 상수함수가 역함수를 가질 수 없는 이유를 일대일 대응 조건과 관련지어 말할 수 있는가?

## 관련 개념
- **함수와 그래프**: 상수함수는 함숫값이 변하지 않는 특수한 형태의 함수이며, 이를 좌표평면에 나타내면 기울기가 0인 수평선 그래프가 됩니다.
