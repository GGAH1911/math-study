# 구간별 함수의 비교

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역을 여러 구간으로 나누어 각 구간마다 다른 규칙을 적용하는 함수를 구간별 함수라 하며, 두 함수의 대소 관계를 파악하기 위해 각 구간별로 부등식을 풀어 해결합니다.

## 본문
구간별 함수(또는 절대값 함수)는 정의역을 몇 개의 구간으로 나누어, 각 구간에서 서로 다른 규칙으로 함숫값을 정하는 함수입니다. 예를 들어 $f(x) = \begin{cases} -2x + 1 & \text{if } x < 1 \\ x^2 - 1 & \text{if } x \geq 1 \end{cases}$와 같이 표현됩니다. 구간별 함수의 비교란 주어진 $x$ 값에서 여러 함수를 동시에 고려할 때, 어느 함수가 더 큰 값인지 판정하는 과정입니다. 이를 위해서는 일차부등식 $f(x) > g(x)$ 또는 $f(x) = g(x)$를 각 구간의 범위에 맞춰 나누어 푼 뒤, 그 결과를 종합하여 전체적인 관계를 파악해야 합니다.

### 직관과 기하적 의미
구간별 함수는 그래프 위에서 구간에 따라 서로 다른 모양의 곡선으로 나타납니다. 두 함수를 비교한다는 것은 두 그래프가 만나는 교점을 찾는 과정이자, 어느 그래프가 상대적으로 위쪽에 위치하는지를 파악하는 것과 같습니다. 예를 들어 $f(x) = |x|$는 원점에서 꺾이는 V자 모양을 그리는데, $x < 0$일 때는 $f(x) = -x$로 우상향하고 $x \geq 0$일 때는 $f(x) = x$로 우상향하며 $x = 0$에서 두 규칙이 만나 연결된 형태를 보입니다.

### 기본 성질
구간별 함수는 구간의 경계점에서 함수가 끊어지지 않고 연결될 수도 있고, 끊어질 수도 있습니다. 비교 시에는 각 구간의 경계값이 포함되는지 여부를 주의 깊게 살펴야 하며, 구간별로 정의된 식을 각각의 범위 내에서 독립적으로 계산한 후 합쳐야 정확한 해를 얻을 수 있습니다.

## 학습 체크
- 구간별 함수를 비교할 때, 각 구간의 경계값(경계가 되는 $x$값)이 해당 구간에 포함되는지 확인하였는가?
- 함수를 비교하기 위해 각 구간의 범위에 맞춰 부등식을 나누어 풀었는가?
- 그래프를 그렸을 때 두 함수의 교점이 실제 계산한 해와 일치하는지 확인하였는가?

## 관련 개념
- **일차부등식**: 구간별 함수를 비교하는 과정에서 각 구간 내의 함숫값 대소를 판정하기 위해 필수적으로 사용되는 도구입니다.
