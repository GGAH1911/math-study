# 함수의 대칭성

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f(x)$가 $f(-x) = f(x)$를 만족하면 $y$축 대칭인 짝함수, $f(-x) = -f(x)$를 만족하면 원점 대칭인 홀함수라고 합니다.

## 본문
함수 $f(x)$가 정의역의 모든 $x$에 대하여 $f(-x) = f(x)$를 만족하면 이를 짝함수(even function)라고 하며, $f(-x) = -f(x)$를 만족하면 홀함수(odd function)라고 합니다. 이러한 조건은 함수의 입력값에 음수를 대입했을 때 출력값이 원래 값과 같거나 혹은 부호만 반대인지를 엄밀하게 규정합니다.

### 직관과 기하적 의미
짝함수의 그래프는 $y$축을 기준으로 좌우가 완벽하게 일치하는 좌우 대칭의 형태를 띱니다. 즉, 점 $(a, f(a))$가 그래프 위에 존재한다면 점 $(-a, f(a))$도 반드시 그래프 위에 존재합니다. 반면 홀함수의 그래프는 원점을 중심으로 하는 점대칭의 형태를 띱니다. 이는 그래프를 원점을 중심으로 $180$도 회전시켰을 때 처음과 같은 모양이 됨을 의미하며, 점 $(a, f(a))$가 존재하면 그 반대편인 $(-a, -f(a))$도 그래프 위에 존재해야 합니다.

### 기본 성질
함수의 대칭성은 모든 함수에서 나타나는 성질이 아닙니다. 예를 들어 $f(x) = x^2 + x$와 같이 짝함수와 홀함수의 성질을 동시에 갖지 않는 함수는 대칭성이 없다고 판단합니다. 대표적인 예시로 $f(x) = x^2$, $f(x) = \cos x$, $f(x) = |x|$는 짝함수에 해당하며, $f(x) = x^3$, $f(x) = \sin x$, $f(x) = x$는 홀함수에 해당합니다.

## 학습 체크
- $f(-x) = f(x)$와 $f(-x) = -f(x)$를 각각 만족하는 함수를 구분할 수 있는가?
- 주어진 함수의 그래프를 보고 $y$축 대칭인지 원점 대칭인지 판별할 수 있는가?
- 어떤 함수가 짝함수도 홀함수도 아닌 경우를 찾을 수 있는가?

## 관련 개념
- **삼각함수**: $\cos x$는 짝함수로서 $y$축 대칭이며, $\sin x$는 홀함수로서 원점 대칭인 성질을 가집니다.
