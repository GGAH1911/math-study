# 함수 그래프와 직선의 교점

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 그래프와 직선의 교점은 두 식을 같다고 놓은 방정식의 해와 일치하며, 기하학적으로는 두 그래프가 만나는 점을 의미합니다.

## 본문
함수 $y = f(x)$의 그래프와 직선 $y = g(x)$의 교점은 두 그래프가 만나는 점 $(a, b)$를 의미합니다. 이는 $f(a) = g(a) = b$를 만족하는 점으로, 방정식 $f(x) = g(x)$의 해 $x = a$에 대응합니다.

### 직관과 기하적 의미
평면 위에 함수의 그래프와 직선을 그렸을 때 만나는 점의 $x$좌표는 방정식 $f(x) = g(x)$를 풀어 구할 수 있습니다. 교점이 $n$개 존재한다는 것은 해당 방정식이 $n$개의 서로 다른 실근을 가진다는 것과 같습니다. 교점의 개수는 두 그래프의 모양에 따라 결정되며, 함수가 연속일 경우 중간값 정리를 활용하여 특정 구간 내에 교점이 존재하는지 확인할 수 있습니다. 예를 들어 $f(x) = x^2$과 $g(x) = 2x - 1$이 구간 $[0, 2]$에서 연속이고 구간 양 끝점의 함숫값 차이의 부호가 다르다면, 중간값 정리에 의해 해당 구간 사이에 적어도 하나의 교점이 반드시 존재합니다.

### 기본 성질
- 교점의 $x$좌표는 방정식 $f(x) = g(x)$의 실근과 일치합니다.
- 교점의 $y$좌표는 해당 $x$좌표를 함수나 직선의 식에 대입하여 얻은 값입니다.
- 두 그래프가 접하는 경우, 교점은 중근을 갖는 형태로 나타납니다.

## 학습 체크
- 방정식 $f(x) = g(x)$의 실근의 개수와 그래프의 교점 개수가 왜 일치하는지 설명할 수 있는가?
- 연속함수에서 중간값 정리를 이용하여 교점의 존재 여부를 논리적으로 증명할 수 있는가?

## 관련 개념
- **함수의 극한과 연속**: 함수가 연속이어야만 중간값 정리를 적용하여 교점의 존재를 보장할 수 있습니다.
