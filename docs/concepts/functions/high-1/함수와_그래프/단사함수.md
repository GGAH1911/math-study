# 단사함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역의 서로 다른 두 원소가 서로 다른 함숫값을 갖는 함수를 의미합니다.

## 본문
함수 $f: X \to Y$가 **단사함수**(일대일함수, injective function)라는 것은, 정의역 $X$의 서로 다른 두 원소가 항상 서로 다른 함숫값을 갖는 함수입니다. 즉, $x_1 \ne x_2$이면 $f(x_1) \ne f(x_2)$를 만족해야 합니다. 이 조건의 대우를 이용하면 $f(x_1) = f(x_2)$일 때 반드시 $x_1 = x_2$임이 성립해야 한다는 것으로도 표현할 수 있습니다.

### 직관과 기하적 의미
단사함수의 본질은 공역의 원소 중 어떤 것도 정의역의 두 개 이상의 원소로부터 화살표를 받지 않는다는 것입니다. 실함수의 그래프를 이용할 경우, $x$축에 평행한 임의의 수평선을 그었을 때 그래프와 만나는 점이 최대 한 점이어야 합니다. 예를 들어 일차함수 $f(x) = 2x + 1$은 수평선과 한 점에서만 만나므로 단사함수이지만, 이차함수 $g(x) = x^2$은 수평선과 두 점에서 만나므로 전체 실수 범위에서는 단사함수가 아닙니다. 다만 정의역을 $[0, \infty)$로 제한하면 단사함수가 될 수 있습니다.

### 기본 성질
함수의 식을 통해 단사성을 검증할 때는 $f(a) = f(b)$라고 가정했을 때 $a = b$가 유도되는지 확인합니다. 예를 들어 $f(x) = 3x - 5$의 경우, $3a - 5 = 3b - 5$에서 $3a = 3b$가 되어 $a = b$가 성립하므로 단사함수입니다.

## 학습 체크
- $f(x_1) = f(x_2)$라는 조건으로부터 $x_1 = x_2$를 이끌어낼 수 있는가?
- 함수의 그래프가 수평선 판정법을 만족하는지 시각적으로 확인할 수 있는가?
- 정의역의 범위 변화에 따라 함수의 단사성 여부가 달라질 수 있음을 이해하고 있는가?

## 관련 개념
- **함수**: 단사함수는 함수의 특수한 형태 중 하나로, 대응 관계의 성질을 규정합니다.
- **역함수**: 함수가 단사함수이면서 공역과 치역이 같을 때에만 역함수가 존재할 수 있습니다.
