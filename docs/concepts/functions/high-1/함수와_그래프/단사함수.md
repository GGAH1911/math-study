# 단사함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 정확한 진술

함수 $f: X \to Y$가 **단사함수**(일대일함수, injective function)라는 것은, 정의역 $X$의 서로 다른 두 원소가 항상 서로 다른 함숫값을 갖는 함수입니다.

$$x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2)$$

동치적으로, 대우를 이용한 정의:

$$f(x_1) = f(x_2) \Rightarrow x_1 = x_2$$

## 직관과 그래프 판정법

단사함수의 본질은 **"어떤 치역의 원소도 정의역의 두 개 이상의 원소에서 나올 수 없다"**는 의미입니다.

실함수의 경우, 시각적으로 판정하는 방법이 있습니다. $x$축에 평행한 임의의 수평선이 함수의 그래프와 **최대 한 점에서만 만난다면**, 그 함수는 단사함수입니다(수평선 판정법).

예를 들어:
- $f(x) = 2x + 1$: 일차함수이므로 단사함수입니다. 수평선이 그래프와 정확히 한 점에서 만납니다.
- $g(x) = x^2$ (정의역 = 전체 실수): $g(-2) = g(2) = 4$이므로 단사함수가 아닙니다. 수평선 $y=4$가 그래프와 두 점에서 만납니다.
- $h(x) = x^2$ (정의역 = $[0, \infty)$): 정의역을 양수로 제한하면 단사함수가 됩니다.

## 예시

$f(x) = 3x - 5$는 단사함수입니다.

검증: $f(a) = f(b)$이면 $3a - 5 = 3b - 5$ ⟹ $3a = 3b$ ⟹ $a = b$ ✓
