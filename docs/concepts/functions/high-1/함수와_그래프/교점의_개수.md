# 교점의 개수

## 정확한 진술

두 함수 $f(x)$와 $g(x)$에 대해, 방정식 $f(x) = g(x)$의 **실근의 개수**를 그 두 함수의 **교점의 개수**라고 합니다. 다시 말해, 방정식 $f(x) - g(x) = 0$의 서로 다른 실근이 $n$개이면, 두 그래프는 정확히 $n$개의 점에서 만납니다.

## 직관과 기하적 의미

함수의 그래프는 $xy$-좌표평면 위의 점들의 집합입니다. 두 함수의 그래프가 어떤 점 $(a, b)$에서 만난다는 것은 다음 두 조건을 동시에 만족한다는 뜻입니다.

- 점 $(a, b)$가 $y = f(x)$의 그래프 위에 있음 → $b = f(a)$
- 점 $(a, b)$가 $y = g(x)$의 그래프 위에 있음 → $b = g(a)$

따라서 $f(a) = g(a)$, 즉 $a$는 방정식의 해입니다. **교점의 존재와 위치는 방정식의 근으로 완전히 결정되므로**, 교점의 개수를 구하는 것은 방정식의 실근 개수를 구하는 것과 동일합니다.

## 한 줄 예

$f(x) = x^2$과 $g(x) = 2x$의 교점 개수는 $x^2 = 2x$, 즉 $x^2 - 2x = 0$의 실근 개수입니다. 이를 풀면 $x(x - 2) = 0$이므로 $x = 0$ 또는 $x = 2$이고, 교점은 $(0, 0)$과 $(2, 4)$ 두 개입니다.

(`sympy.solve(x**2 - 2*x, x)` → `[0, 2]`)
