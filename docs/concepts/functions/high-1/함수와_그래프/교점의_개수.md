# 교점의 개수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
두 함수의 그래프가 만나는 점의 개수는 방정식 $f(x) = g(x)$의 서로 다른 실근의 개수와 같다.

## 본문
두 함수 $f(x)$와 $g(x)$에 대하여, 방정식 $f(x) = g(x)$의 실근의 개수를 두 함수의 교점의 개수라고 정의한다. 이는 방정식 $f(x) - g(x) = 0$의 서로 다른 실근이 $n$개일 때, 두 함수의 그래프가 좌표평면 위에서 정확히 $n$개의 점에서 만남을 의미한다.

### 직관과 기하적 의미
함수의 그래프는 좌표평면 위의 점들의 집합이다. 두 함수의 그래프가 점 $(a, b)$에서 만난다는 것은 해당 점이 두 함수의 그래프 위에 동시에 존재함을 뜻하며, 이는 $b = f(a)$와 $b = g(a)$를 동시에 만족해야 함을 의미한다. 결과적으로 $f(a) = g(a)$가 성립해야 하므로, 교점의 존재 여부와 위치는 방정식의 해와 완전히 일치한다. 따라서 그래프의 기하학적 관계를 파악하는 것은 대수적인 방정식의 해를 구하는 과정과 동일한 맥락을 가진다.

### 기본 성질
- 교점의 개수는 방정식 $f(x) - g(x) = 0$의 서로 다른 실근의 개수와 일치한다.
- 두 함수의 그래프가 만나지 않는다면, 방정식 $f(x) = g(x)$은 실근을 갖지 않는다.
- 교점의 $x$좌표는 방정식의 해이며, 교점의 $y$좌표는 해당 $x$값을 함수에 대입하여 얻은 값이다.

## 학습 체크
- 방정식 $f(x) = g(x)$의 실근이 중근을 가질 때, 그래프 상에서 교점은 어떤 형태로 나타나는가?
- 두 함수의 그래프가 교점 없이 떨어져 있다면, 방정식 $f(x) - g(x) = 0$의 근의 개수는 몇 개인가?
- 교점의 개수를 구하기 위해 $f(x) - g(x) = 0$으로 변형하여 푸는 과정이 왜 타당한가?

## 관련 개념
- **함수의 극한과 연속**: 함수의 연속성을 통해 그래프의 끊김 없는 연결을 확인하면, 극한값과 함숫값의 관계를 통해 교점의 존재 가능성을 예측할 수 있다.
- **방정식과 부등식**: 교점의 개수는 방정식의 실근 개수와 직결되며, 이는 두 함수의 그래프의 높낮이를 비교하는 부등식의 해의 범위와 밀접하게 연관된다.
