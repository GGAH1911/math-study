# 함수의 역상

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f: A \to B$에서 공역의 부분집합 $Y$에 대하여, $f(x)$의 값이 $Y$에 포함되도록 하는 정의역의 모든 원소들을 모아놓은 집합을 의미합니다.

## 본문
함수 $f: A \to B$와 $B$의 부분집합 $Y$에 대하여, $Y$의 역상(preimage)은 $f^{-1}(Y) = \{x \in A : f(x) \in Y\}$로 정의됩니다. 이는 $Y$에 속하는 원소들로 대응되는 정의역의 모든 원소들을 모두 포함하는 집합입니다. 여기서 주의할 점은 역상이 역함수와는 다른 개념이라는 것입니다. 역함수는 함수가 일대일 대응일 때만 존재하지만, 역상은 함수가 일대일 대응이 아니더라도 공역의 어떤 부분집합에 대해서도 항상 정의될 수 있습니다.

### 직관과 기하적 의미
역상은 "역방향 추적"의 관점에서 이해할 수 있습니다. 공역의 특정 원소들이나 부분집합 $Y$를 정했을 때, "이 값들이 정의역의 어느 원소들로부터 출발하여 도달했는가?"를 찾는 과정입니다. 예를 들어 $f(x) = x^2$인 함수에서 $Y$가 $\{4\}$라면, $4$를 결과값으로 갖는 정의역의 원소는 $-2$와 $2$이므로 $f^{-1}(\{4\}) = \{-2, 2\}$가 됩니다. 이처럼 함수가 다대일 대응인 경우, 역상은 여러 개의 원소를 포함하는 집합이 될 수 있습니다.

### 기본 성질
- $Y$가 공집합이면 역상 또한 공집합입니다.
- $Y$가 공역 $B$ 전체이면 역상은 정의역 $A$ 전체가 됩니다.
- $Y$가 한 원소 $\{b\}$인 경우, 이는 $b$로 대응되는 모든 정의역 원소들의 모임을 의미합니다.

## 학습 체크
- 함수가 일대일 대응이 아닐 때 역상이 여러 원소를 가질 수 있음을 이해하고 있는가?
- $f^{-1}(Y)$를 구할 때, 결과값이 $Y$에 포함되는 $x$값을 모두 찾아내는 과정을 수행할 수 있는가?

## 관련 개념
- **역함수**: 함수가 일대일 대응일 때만 존재하며, 역상 중에서도 공역의 원소 하나에 대응되는 정의역의 원소 하나를 찾는 특수한 경우로 볼 수 있습니다.
- **공역과 치역**: 역상은 공역의 부분집합을 대상으로 정의되며, 치역은 역상 중에서도 공역 전체를 대상으로 했을 때의 결과와 밀접한 관련이 있습니다.
