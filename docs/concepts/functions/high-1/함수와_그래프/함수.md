# 함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
두 집합 사이의 원소들이 하나씩 빠짐없이 대응되는 규칙을 의미합니다.

## 본문
두 집합 $X$, $Y$가 있을 때, $X$의 각 원소 $x$에 대해 $Y$의 원소 $y$가 **정확히 하나** 대응되는 규칙을 $X$에서 $Y$로의 함수라고 합니다. 이를 $f : X \to Y$로 나타내고, $x$에 대응되는 $y$를 $f(x)$로 표기합니다. 여기서 $X$를 정의역, $Y$를 공역이라 부릅니다. 함수가 성립하기 위한 핵심 조건은 정의역의 모든 원소가 빠짐없이 대응되어야 하며, 하나의 $x$가 여러 개의 $y$로 대응될 수 없다는 점입니다.

### 직관과 기하적 의미
함수는 입력값에 따른 출력값의 관계를 나타냅니다. 입력 $x$를 넣었을 때 반드시 하나의 결과값 $f(x)$가 나오는 기계와 같습니다. 좌표평면 위에서 함수의 그래프는 점 $(x, f(x))$들의 모임으로 나타나며, 임의의 수직선이 그래프와 최대 한 번만 만나는지 확인하는 연직선 검사법을 통해 함수의 여부를 시각적으로 확인할 수 있습니다.

### 기본 성질
함수 $f(x) = 2x + 1$과 같이 입력값에 대해 유일한 결과값이 결정되는 성질을 가집니다. 예를 들어 $x = 3$을 대입하면 $f(3) = 7$이라는 단 하나의 값이 도출됩니다.

## 학습 체크
- 정의역의 모든 원소가 빠짐없이 대응되고 있는가?
- 하나의 $x$값이 두 개 이상의 $y$값에 대응되고 있지는 않은가?
- 그래프를 그렸을 때 수직선이 그래프와 두 번 이상 만나지는 않는가?

## 관련 개념
- **방정식과 부등식**: 함수의 그래프와 $x$축의 교점 또는 위치 관계를 통해 방정식의 해나 부등식의 범위를 시각적으로 파악할 수 있습니다.
