# 함수방정식 풀이

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
미지수가 함수인 방정식을 해결하기 위해 특수값 대입, 미분, 함수 형태 추정 등의 전략을 사용하여 조건을 만족하는 함수 $f(x)$를 찾아내는 과정입니다.

## 본문
함수방정식이란 방정식의 미지수가 변수가 아닌 함수 $f(x)$인 방정식을 의미합니다. 즉, 주어진 조건을 만족하는 함수 $f(x)$의 구체적인 형태를 찾아내는 것이 목표입니다. 예를 들어 $f(x+y) = f(x) + f(y)$와 같은 식은 함수 $f$가 가져야 할 성질을 규정하며, 이를 통해 $f(x)$를 결정할 수 있습니다.

### 직관과 기하적 의미
함수방정식은 함수의 본질적인 성질을 나타냅니다. 예를 들어 $f(x+y) = f(x) + f(y)$를 만족하면서 연속인 함수는 반드시 $f(x) = cx$ 형태인 일차함수가 됩니다. 미적분 단계에서는 도함수의 성질, 함수값 사이의 관계, 또는 함수의 합성 조건 등을 통해 함수의 그래프가 어떤 특성을 갖는지 파악하는 데 활용됩니다.

### 기본 성질
함수방정식을 해결하기 위한 주요 전략은 다음과 같습니다. 첫째, **양변 미분**입니다. 방정식의 양변을 $x$ 또는 $y$에 대해 미분하여 미분방정식의 형태로 변환한 뒤, 초기조건과 함께 적분하여 $f(x)$를 결정합니다. 둘째, **특수값 대입**입니다. $x=0$ 또는 $y=0$과 같은 특정 값을 대입하여 함수의 기본 성질을 파악합니다. 셋째, **함수의 형태 추정**입니다. 주어진 조건에 따라 $f(x)$가 일차, 이차, 지수, 로그 함수 중 어떤 형태인지 추측한 후 계수를 결정합니다.

예를 들어 $f'(x) = 2f(x)$이고 $f(0) = 1$인 경우, 양변을 정리하면 $\frac{f'(x)}{f(x)} = 2$가 되고, 이를 적분하면 $\ln|f(x)| = 2x + C$를 얻습니다. 이때 초기조건 $f(0) = 1$을 적용하면 최종적으로 $f(x) = e^{2x}$라는 결과를 얻을 수 있습니다.

## 학습 체크
- 함수방정식에 특정 값을 대입할 때 어떤 값을 대입하는 것이 가장 효율적인가?
- 양변 미분을 통해 미분방정식으로 변환할 때 주의해야 할 점은 무엇인가?
- 주어진 조건이 함수를 일차함수, 지수함수, 로그함수 중 어떤 형태로 유도하는가?

## 관련 개념
- **도함수의 활용 심화**: 미분법을 이용하여 함수방정식을 미분방정식으로 변환하고, 이를 통해 함수의 구체적인 식을 도출하는 과정과 연결됩니다.
