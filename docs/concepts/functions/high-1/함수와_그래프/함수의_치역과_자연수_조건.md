# 함수의 치역과 자연수 조건

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역이 자연수로 제한된 함수의 치역은 함수가 취하는 모든 함숫값들을 모아놓은 집합입니다.

## 본문
함수 $f: \mathbb{N} \to \mathbb{R}$의 치역은 함수가 취하는 모든 함숫값의 집합을 의미하며, 수학적으로는 $\text{치역} = \{f(n) \mid n \in \mathbb{N}\}$으로 나타냅니다. 정의역이 실수 전체가 아닌 자연수($1, 2, 3, \ldots$)로 제한될 경우, 함수는 연속적인 곡선을 그리는 것이 아니라 특정 지점에서만 값을 가지게 됩니다. 따라서 이 함수의 치역은 일반적인 연속 함수의 치역과 달리 띄엄띄엄 떨어진 점들의 모임으로 나타나며, 유한 집합이거나 조밀하지 않은 형태를 띠게 됩니다.

### 직관과 기하적 의미
정의역이 자연수로 제한되면 함수는 연속적인 흐름을 갖지 못하고 특정 점들에서만 정의됩니다. 예를 들어 $\sin(n)$ ($n \in \mathbb{N}$)의 경우, 실수 전체를 정의역으로 하는 일반적인 사인함수가 $[-1, 1]$ 사이의 모든 값을 연속적으로 취하는 것과 달리, $\sin(1), \sin(2), \sin(3), \ldots$와 같이 불연속적인 값들만 취하게 됩니다. 즉, 그래프 상에서는 연속된 선이 아닌 점들이 찍히는 형태가 되며, 이 점들의 집합이 곧 치역이 됩니다.

### 기본 성질
함수 $f(n) = 2\sin\left(\tfrac{n\pi}{6}\right)$ ($n \in \mathbb{N}$)를 예로 들면, 함숫값은 $f(1)=1, f(2)=\sqrt{3}, f(3)=2, f(4)=\sqrt{3}, f(5)=1, f(6)=0$ 등으로 계산됩니다. 이처럼 정의역이 자연수일 때는 함숫값이 반복되거나 특정 값들로 제한될 수 있으며, 위 예시에서 이 함수의 치역은 $\{0, 1, \sqrt{3}, 2, -1, -\sqrt{3}\}$과 같이 이산적인 집합의 형태를 보입니다.

## 학습 체크
- 정의역이 자연수일 때 함수의 그래프가 연속적인 곡선이 아닌 점들로 나타나는 이유를 설명할 수 있는가?
- 주어진 함수식에 자연수를 대입하여 나타나는 함숫값들의 집합(치역)을 정확히 구할 수 있는가?

## 관련 개념
- **삼각함수**: 정의역이 실수일 때는 연속적인 값을 가지지만, 정의역이 자연수로 제한되면 삼각함수의 함숫값은 불연속적인 점들의 집합으로 나타납니다.
