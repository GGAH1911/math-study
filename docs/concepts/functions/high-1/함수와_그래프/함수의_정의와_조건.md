# 함수의 정의와 조건

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
집합 $X$의 모든 원소가 집합 $Y$의 원소에 단 하나씩만 대응될 때 이를 함수라고 합니다.

## 본문
두 집합 $X, Y$에서 $X$의 각 원소에 $Y$의 원소 하나를 정확히 대응시키는 규칙을 $X$에서 $Y$로의 **함수**(function)라고 하며, $f: X \to Y$로 나타냅니다. 여기서 $X$는 **정의역**(domain), $Y$는 **공역**(codomain)입니다. $X$의 원소 $x$에 대응되는 $Y$의 원소를 $f(x)$로 나타내고 이를 **함수값**이라고 합니다. 함수가 성립하기 위한 핵심 조건은 $X$의 모든 원소 $x$에 대하여 $f(x)$가 정확히 하나만 존재해야 한다는 점입니다.

### 직관과 기하적 의미
함수의 핵심은 입력값에 따른 출력값의 유일성입니다. 예를 들어 이차함수 $y = 2x^2 + 1$은 어떤 $x$ 값을 대입하더라도 $y$ 값이 항상 하나로 결정되므로 함수입니다. 반면 원의 방정식 $x^2 + y^2 = 1$의 경우 $x = 0$일 때 $y = 1$ 또는 $y = -1$로 두 개의 값이 대응되므로 함수가 아닙니다. 이를 좌표평면에서 확인하는 방법으로 **연직선 판정법**이 있습니다. 그래프에 임의의 수직선을 그었을 때 그래프와 최대 한 점에서만 만나면 함수이고, 두 점 이상에서 만나면 함수가 아닙니다.

### 기본 성질
함수에서는 서로 다른 입력값이 같은 출력값을 가져도 상관없습니다. 예를 들어 $f(x) = x^2 - 3x + 2$에서 $f(1) = 0$이고 $f(2) = 0$인 것처럼, 입력값 $1$과 $2$가 서로 다르더라도 결과값이 $0$으로 같을 수 있습니다. 중요한 것은 각 입력값마다 대응되는 출력이 반드시 하나여야 한다는 조건입니다.

## 학습 체크
- $X$의 모든 원소가 $Y$의 원소에 빠짐없이 대응되고 있는가?
- 하나의 $x$ 값에 대해 두 개 이상의 $y$ 값이 대응되는 경우는 없는가?

## 관련 개념
- **이차함수**: 변수 $x$의 값이 결정되면 $y$ 값이 유일하게 결정되는 함수의 대표적인 사례입니다.
- **원의 방정식**: $x$ 값 하나에 $y$ 값이 두 개 대응될 수 있어 함수가 아닌 도형의 방정식입니다.
