# 도형의넓이

## 정확한 진술

함수 $f(x)$가 구간 $[a, b]$에서 연속이고 $f(x) \geq 0$일 때, 곡선 $y = f(x)$와 $x$축, 그리고 직선 $x = a$, $x = b$로 둘러싸인 도형의 넓이는 정적분 $\displaystyle \int_a^b f(x) \, dx$로 정의됩니다.

더 일반적으로, 두 함수 $f(x)$, $g(x)$가 $[a, b]$에서 연속이고 $f(x) \geq g(x)$일 때, 두 곡선 사이의 넓이는 $\displaystyle \int_a^b |f(x) - g(x)| \, dx$입니다.

## 직관/기하적 의미

정적분이 넓이를 나타내는 이유는 구간 $[a, b]$를 매우 작은 폭 $\Delta x$로 나누었을 때, 각 부분에서 곡선 아래의 넓이를 직사각형으로 근사할 수 있기 때문입니다. $\Delta x$를 무한히 작게 하면 이 근사가 정확해지며, 이것이 리만 합의 극한(정적분의 정의)입니다.

곡선이 음수 값을 가질 때는 절댓값을 취하거나 구간을 나누어 계산하므로, 넓이는 항상 음이 아닌 값이 됩니다. 이는 "도형이 차지하는 공간의 크기"라는 넓이의 기본 의미와 일치합니다.

## 한 줄 예

$y = x^2$, $y = 0$, $x = 0$, $x = 2$로 둘러싸인 도형의 넓이는 $\displaystyle \int_0^2 x^2 \, dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3}$입니다.

(검증: `sympy.integrate(x**2, (x, 0, 2))` → $\frac{8}{3}$)
