# 치역의 조건

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
치역은 정의역의 모든 원소를 함수에 대입했을 때 나타나는 함숫값들의 집합입니다.

## 본문
함수 $f: X \to Y$에서 치역(range)은 정의역의 모든 원소를 함수에 대입했을 때 나오는 $y$ 값들의 집합입니다. 수학적으로는 $\text{치역} = \{f(x) \mid x \in \text{정의역}\}$으로 표현하며, 치역은 항상 공역 $Y$의 부분집합이 됩니다.

### 직관과 기하적 의미
그래프를 통해 이해하면 더욱 명확합니다. 함수 $f(x) = x^2$의 정의역이 $[0, 3]$일 때, 그래프 상의 모든 점들이 가지는 $y$ 좌표를 모으면 치역인 $[0, 9]$를 얻을 수 있습니다. 이처럼 정의역의 범위가 결정되면 그에 따라 함수가 도달하는 결과값의 범위인 치역도 함께 결정됩니다. 예를 들어 $f(x) = \sin x$의 정의역이 실수 전체일 때 치역은 $[-1, 1]$이지만, 정의역을 $[0, \pi/2]$로 제한하면 치역은 $[0, 1]$로 줄어들게 됩니다.

### 기본 성질
정의역의 각 $x$ 값을 함수에 넣어서 나오는 결과들만 모으면 되므로, 정의역이 제한되면 치역도 함께 제한됩니다. 또한, 함수가 정의되기 위해서는 치역이 반드시 공역의 부분집합이어야 한다는 성질을 가집니다.

## 학습 체크
- 정의역의 범위가 변할 때 치역의 범위는 어떻게 변하는가?
- 공역과 치역의 차이점은 무엇인가?
- 주어진 함수식과 정의역이 주어졌을 때 치역을 집합 기호로 나타낼 수 있는가?

## 관련 개념
- **정의역**: 함수에 대입할 수 있는 입력값들의 집합으로, 치역을 결정하는 기초가 됩니다.
- **공역**: 함수가 가질 수 있는 전체 결과값의 후보 집합으로, 치역은 항상 이 집합의 부분집합입니다.
- **함숫값**: 정의역의 특정 원소 $x$를 함수에 대입하여 얻어지는 결과값 $f(x)$이며, 이 값들을 모두 모으면 치역이 됩니다.
