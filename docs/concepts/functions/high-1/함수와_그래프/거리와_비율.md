### 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 **거리**는 다음과 같이 정의됩니다.

$$AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

선분 $AB$를 $m : n$으로 **내분하는 점** $P$의 좌표는 거리를 이용하여 표현할 수 있습니다. 점 $P$가 선분 위에서 $AP : PB = m : n$을 만족할 때:

$$P = \left( \frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n} \right)$$

이는 거리의 비가 곧 $m : n$임을 의미합니다. 마찬가지로 선분을 **외분하는 점** $Q$도 같은 원리로 정의됩니다.

### 직관·기하적 의미

좌표평면에서 거리는 **피타고라스 정리**에서 비롯됩니다. 두 점을 연결한 직선을 직각삼각형의 빗변으로 보면, 가로 변의 길이는 $|x_2 - x_1|$, 세로 변의 길이는 $|y_2 - y_1|$이 되어 위 공식을 유도할 수 있습니다. 

**비율**은 선분을 어떤 기준점을 중심으로 어떻게 나누는지를 나타냅니다. 내분점은 선분 위에 있고, 외분점은 선분의 연장선 위에 있습니다. 내분점 공식의 분모 $m + n$과 분자의 가중치는, 가까운 점일수록 더 큰 가중치를 갖는 **가중 평균**의 개념으로 이해할 수 있습니다.

### 한 줄 예

$A(1, 2)$와 $B(5, 8)$의 거리는 $AB = \sqrt{(5-1)^2 + (8-2)^2} = \sqrt{16 + 36} = \sqrt{52} = 2\sqrt{13}$이고, 선분 $AB$를 $1:1$로 내분하는 중점 $M$은 $M = (3, 5)$입니다. (검증: `import sympy; sympy.sqrt((5-1)**2 + (8-2)**2)`)
