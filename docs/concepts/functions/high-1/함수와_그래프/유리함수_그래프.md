# 유리함수 그래프

> **예제** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
유리함수 $y=\tfrac{k}{x-a}+b$의 그래프는 점 $(a, b)$를 대칭 중심으로 하며, $x=a$와 $y=b$를 점근선으로 가집니다.

## 본문
다음 함수의 그래프를 그리고, 점근선을 구하세요.
$$y = \frac{2}{x-1} + 3$$

### 단계별 풀이
**1단계: 점근선 찾기**
유리함수 $y=\tfrac{k}{x-a}+b$ 형태에서 분모가 $0$이 되는 $x=1$이 수직 점근선이 되며, $x$가 무한히 커지거나 작아질 때 $y$가 수렴하는 $y=3$이 수평 점근선이 됩니다.

**2단계: 주요 점 구하기**
기본 함수 $y = \tfrac{2}{x}$의 그래프를 $x$축 방향으로 $1$만큼, $y$축 방향으로 $3$만큼 평행이동합니다.
- $x > 1$ 구간: $x=2$일 때 $y=5$, $x=3$일 때 $y=4$, $x=5$일 때 $y=3.5$
- $x < 1$ 구간: $x=0$일 때 $y=1$, $x=-1$일 때 $y=2$, $x=-3$일 때 $y=2.5$

**3단계: 대칭성 확인**
기본 함수 $y = \tfrac{2}{x}$가 원점 대칭이므로, 평행이동된 함수 $y = \tfrac{2}{x-1}+3$은 점근선의 교점인 $(1, 3)$에 대해 점대칭입니다. 예를 들어 $(2, 5)$는 $(1, 3)$을 기준으로 $(0, 1)$과 대칭 관계에 있습니다.

**4단계: 그래프 개형**
$k=2$로 양수이므로, $x>1$ 구간과 $x<1$ 구간 모두에서 그래프가 감소하는 형태를 띠며, 점근선 $x=1$과 $y=3$에 점차 가까워집니다.

### 답과 변형
- **수직 점근선**: $x = 1$
- **수평 점근선**: $y = 3$
- **대칭 중심**: $(1, 3)$

**변형 및 주의사항**
- **$k$의 부호**: $k>0$이면 점근선을 기준으로 양옆에서 감소하고, $k<0$이면 양옆에서 증가합니다.
- **$b$의 역할**: $b$의 값은 수평 점근선의 위치와 대칭 중심의 $y$좌표를 결정합니다.
- **주의할 점**: 점근선 $x=1$은 정의역에 포함되지 않으므로 해당 직선 위의 점에서는 함수값이 정의되지 않습니다.

## 학습 체크
- 점근선의 교점이 그래프의 대칭 중심임을 이해하고 있는가?
- $k$의 부호에 따른 그래프의 증가/감소 방향을 구분할 수 있는가?
- 평행이동을 이용하여 기본형 $y=\tfrac{k}{x}$의 그래프를 그릴 수 있는가?

## 관련 개념
- **함수와 그래프**: 유리함수는 함수를 시각적으로 나타내는 중요한 사례이며, 점근선과 대칭성을 통해 그래프의 개형을 결정합니다.
