# 유리함수 그래프

> **예제** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)
## 요약
$y=\frac{k}{x-a}+b$

## 본문

### 문제

다음 함수의 그래프를 그리고, 점근선을 구하세요.
$$y = \frac{2}{x-1} + 3$$

### 단계별 풀이

**1단계: 점근선 찾기**

유리함수 $y=\frac{k}{x-a}+b$ 형태에서:
- **수직 점근선**: 분모가 0이 되는 $x = 1$
- **수평 점근선**: $x \to \pm\infty$일 때 $\frac{2}{x-1} \to 0$이므로 $y = 3$

**2단계: 주요 점 구하기**

기본 함수 $y = \frac{2}{x}$의 점들을 $(x-1)$만큼 오른쪽, 3만큼 위로 평행이동합니다.

| $x$ | 2 | 3 | 5 |
|-----|---|---|---|
| $y$ | $2+3=5$ | $1+3=4$ | $\frac{2}{4}+3=3.5$ |

$x < 1$ 구간에서:

| $x$ | 0 | -1 | -3 |
|-----|---|----|----|
| $y$ | $-2+3=1$ | $-1+3=2$ | $-\frac{2}{4}+3=2.5$ |

**3단계: 대칭성 확인**

$y = \frac{2}{x}$는 원점 대칭이므로, $y = \frac{2}{x-1}+3$은 점 $(1, 3)$ (점근선의 교점)에 대해 점대칭입니다.

예를 들어 $(2, 5)$는 $(1, 3)$ 기준으로 $(0, 1)$과 대칭입니다. ✓

**4단계: 그래프 개형**

- $x > 1$: 오른쪽에서 수평 점근선 $y=3$에 접근하며 감소
- $x < 1$: 왼쪽에서 수평 점근선 $y=3$에 접근하며 감소
- 점 $(1, 3)$을 중심으로 점대칭

### 답

- **수직 점근선**: $x = 1$
- **수평 점근선**: $y = 3$
- **대칭 중심**: $(1, 3)$

```python
# sympy로 검증
from sympy import *
x = symbols('x')
f = 2/(x-1) + 3
print(f"x=2일 때: {f.subs(x, 2)}")  # 5
print(f"x=3일 때: {f.subs(x, 3)}")  # 4
```

### 변형/주의

**$k$의 부호에 따른 변화**:
- $k > 0$일 때: $x > a$에서 감소, $x < a$에서 감소 (이 예제)
- $k < 0$일 때: $x > a$에서 증가, $x < a$에서 증가

**$b$ 이동**: $b$가 변하면 수평 점근선만 $y = b$로 이동. 대칭 중심도 $(a, b)$로 이동합니다.

**흔한 실수**: 점근선을 "지나갈 수 없는 선"이라고만 생각하고, 점근선 위의 점에서 함수값을 구하려 하는 경우가 있습니다. 여기서 $x=1$은 정의역에 포함되지 않으므로 함수값이 존재하지 않습니다.
