# 좌표와 거리 계산

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음 공식으로 구합니다:

$$|AB| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

특히 원점 $O(0, 0)$과 점 $P(x, y)$ 사이의 거리는:

$$|OP| = \sqrt{x^2 + y^2}$$

## 직관·기하적 의미

이 공식은 피타고라스 정리에서 나옵니다. 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$를 생각해보세요. 

점 $A$에서 수평으로 $|x_2 - x_1|$만큼, 수직으로 $|y_2 - y_1|$만큼 움직이면 점 $B$에 도달합니다. 이 두 변과 선분 $AB$가 만드는 직각삼각형에 피타고라스 정리를 적용하면:

$$|AB|^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$$

따라서 제곱근을 취하면 거리 공식을 얻습니다. 좌표계는 기하 도형의 길이를 계산 가능한 식으로 변환해주는 강력한 도구입니다.

## 한 줄 예

두 점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리는 $|AB| = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$입니다. (검증: `sympy.sqrt((4-1)**2 + (6-2)**2)`)

## 더 알아보기

거리 공식은 원의 방정식, 두 점 사이 중점 좌표, 삼각형의 넓이 등 이후 여러 개념의 기초가 됩니다. 항상 "밑변과 높이의 제곱 합"이라는 기하적 의미를 염두에 두고 계산하면 실수를 줄일 수 있습니다.
