# 함수의 변환

## 정확한 진술

함수 $f(x)$를 새로운 함수로 만드는 여러 변환 방법들을 말합니다. 주요 변환은 다음과 같습니다:

- **평행이동**: $y = f(x-a) + b$ (가로로 $a$, 세로로 $b$만큼 이동)
- **대칭이동**: $y = -f(x)$ (x축 대칭), $y = f(-x)$ (y축 대칭), $y = -f(-x)$ (원점 대칭)
- **축소·확대**: $y = cf(x)$ (세로 $|c|$배), $y = f(dx)$ (가로 $\frac{1}{|d|}$배)

## 직관·기하적 의미

함수의 변환은 그래프를 평면 위에서 움직이거나 뒤집는 것입니다. 예를 들어 $y = f(x)$의 그래프가 주어졌을 때:

- $y = f(x-2)$는 **오른쪽으로 2칸 이동**한 그래프입니다
- $y = f(x) + 3$은 **위로 3칸 이동**한 그래프입니다
- $y = -f(x)$는 **x축을 기준으로 뒤집은** 그래프입니다
- $y = f(-x)$는 **y축을 기준으로 뒤집은** 그래프입니다

이는 원래 함수의 **모양은 그대로** 유지하되, 위치나 방향만 바꾼다는 의미입니다. 따라서 함수의 변환을 이해하면 복잡한 함수의 그래프를 쉽게 그릴 수 있습니다.

## 한 줄 예

$f(x) = x^2$일 때, $g(x) = (x-1)^2 + 2$는 $f(x)$를 오른쪽으로 1칸, 위로 2칸 평행이동한 것입니다.

**참고**: 삼각함수의 변환 $y = a\sin(bx + c) + d$ (진폭, 주기, 위상, 수직 이동)도 이 원리를 따릅니다. 변환의 순서가 중요하므로, 안쪽부터 차례대로 적용해야 합니다.
