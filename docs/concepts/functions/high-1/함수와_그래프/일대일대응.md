# 일대일대응

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
단사함수이면서 동시에 전사함수인 함수입니다.

## 본문
함수 $f: X \to Y$가 **일대일대응**(또는 전단사 함수)이라는 것은 다음 두 조건을 동시에 만족한다는 것을 의미합니다. 첫째, 단사성(단사함수)을 만족하여 $f(a) = f(b)$이면 $a = b$여야 합니다. 즉, 정의역의 서로 다른 원소가 치역의 같은 원소로 대응되지 않습니다. 둘째, 전사성(전사함수)을 만족하여 치역 $Y$의 모든 원소 $y$에 대해 $f(x) = y$를 만족하는 정의역의 원소 $x$가 반드시 존재해야 합니다. 결과적으로 일대일대응은 정의역의 모든 원소가 치역의 모든 원소와 정확히 하나씩 짝을 이루는 상태를 말합니다.

### 직관과 기하적 의미
화살표 그림으로 이해하면, 단사는 치역의 원소가 두 개 이상의 화살표를 받지 않는 상태(중복 없음)를 의미하고, 전사는 치역의 모든 원소가 적어도 하나의 화살표를 받는 상태(빈틈 없음)를 의미합니다. 이 두 조건이 결합되면 정의역 $X$의 원소 개수와 공역 $Y$의 원소 개수가 일치하며, 모든 원소가 완벽하게 일대일로 매칭됩니다.

### 기본 성질
일대일대응은 역함수 $f^{-1}: Y \to X$가 존재하기 위한 필요충분조건입니다. 즉, 어떤 함수가 역함수를 갖기 위해서는 반드시 일대일대응이어야 합니다.

## 학습 체크
- $f(a) = f(b)$일 때 $a = b$임을 이용하여 단사성을 확인할 수 있는가?
- 공역과 치역이 일치하는지 확인하여 전사성을 판단할 수 있는가?
- 주어진 함수가 역함수를 갖기 위한 조건으로 일대일대응을 떠올릴 수 있는가?

## 관련 개념
- **함수와 그래프**: 일대일대응은 함수 관계의 특수한 형태로, 그래프상에서 가로선 판정법을 통해 일대일대응 여부를 확인할 수 있습니다.
