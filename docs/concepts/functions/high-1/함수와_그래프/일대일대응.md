# 일대일대응

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)
## 요약
단사이면서 전사

## 본문

함수 $f: X \to Y$가 **일대일대응**(또는 전단사 함수)이다는 것은 다음 두 조건을 동시에 만족한다는 뜻입니다:

1. **단사성(단사함수)**: $f(a) = f(b)$이면 $a = b$이다. 즉, 정의역의 서로 다른 원소는 치역의 서로 다른 원소로 대응된다.
2. **전사성(전사함수)**: 치역 $Y$의 모든 원소 $y$에 대해 $f(x) = y$를 만족하는 정의역의 원소 $x$가 존재한다.

다시 말해, 일대일대응은 정의역의 모든 원소가 치역의 모든 원소와 정확히 하나씩 짝을 이루는 함수입니다.

### 직관적 의미

일대일대응을 화살표 그림으로 생각하면:
- **단사**: 치역의 어떤 원소도 두 개 이상의 화살표를 받지 않는다. (중복 대응 없음)
- **전사**: 치역의 모든 원소가 적어도 하나의 화살표를 받는다. (빠진 원소 없음)

두 조건을 합치면, 정의역 $X$의 원소 개수와 치역 $Y$의 원소 개수가 같고, 각각이 완벽하게 일대일로 대응됩니다. 이 경우 **역함수 $f^{-1}: Y \to X$가 존재**합니다.

### 예시

$f: \{1, 2, 3\} \to \{a, b, c\}$에서 $f(1) = a, f(2) = b, f(3) = c$인 함수는 일대일대응입니다. 반면 $g: \{1, 2, 3\} \to \{a, b, c, d\}$는 치역이 넓어서 전사가 아니고, $h(1) = a, h(2) = a, h(3) = b$는 단사가 아닙니다.

일대일대응은 고등학교 수학에서 **역함수 존재**의 필요충분조건이므로, 함수와 그 역함수 사이의 관계를 이해할 때 매우 중요합니다.
