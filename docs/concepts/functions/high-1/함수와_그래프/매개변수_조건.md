# 매개변수 조건

## 정확한 진술

**매개변수 조건**은 함수나 방정식이 주어진 기하적, 대수적 요구 사항을 만족하기 위해, 포함된 매개변수(parameter)가 충족해야 하는 조건을 의미합니다.

예를 들어 직선 $y = mx + 1$이 원 $x^2 + y^2 = 4$와 만나려면 $m$이 만족해야 할 부등식이 매개변수 조건입니다.

## 직관/기하적 의미

그래프를 그려보면 직관이 명확해집니다. 직선의 기울기 $m$을 변화시키면서, 그 직선이 원과 교점을 가지는 순간을 찾는 것이죠. 기울기가 너무 가팔거나 완만하면 만나지 않지만, 적절한 범위에 있으면 만납니다.

일반적으로 매개변수 조건은:
- **함수의 극값 존재**: 도함수가 부호를 바꿀 조건 (예: $f'(x) = 0$이 실근을 가져야 함)
- **특정 점을 지남**: 좌표를 대입했을 때 식이 성립하는 조건
- **두 도형의 위치 관계**: 판별식이나 거리 조건으로 표현
- **함수의 단조성**: 도함수의 부호 조건

## 한 줄 예

이차함수 $f(x) = x^2 + 2ax + 3$이 모든 $x$에 대해 항상 양수이려면, 판별식 $D = 4a^2 - 12 < 0$에서 **$-\sqrt{3} < a < \sqrt{3}$**이 매개변수 조건입니다. (검증: `sympy.solve(4*a**2 - 12 < 0, a)` → $-\sqrt{3} < a < \sqrt{3}$)
