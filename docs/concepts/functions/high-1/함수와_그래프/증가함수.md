# 증가함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 정확한 진술

구간 $I$에서 정의된 함수 $f$가 **증가함수**일 필요충분조건은: $I$의 임의의 두 점 $x_1, x_2$에 대해 $x_1 < x_2$이면 $f(x_1) < f(x_2)$를 만족하는 것입니다. 

더 정확히는, $x_1$보다 $x_2$가 오른쪽에 있을 때, 함수값도 함께 증가하는 성질을 뜻합니다.

## 직관과 기하적 의미

증가함수는 그래프가 **왼쪽에서 오른쪽으로 갈수록 계속 올라가는 모양**입니다. 

미분가능한 함수의 경우, 이는 **도함수가 항상 양수**일 때와 같습니다. 즉, 구간 $I$의 모든 점에서 $f'(x) > 0$이면 그 구간에서 $f$는 증가함수입니다. 이는 그래프 위의 모든 점에서 접선의 기울기가 양수라는 뜻이며, 따라서 함수가 계속 상승한다고 이해할 수 있습니다.

반대로 $f'(x) < 0$이면 감소함수, $f'(x) = 0$인 점은 극값(최댓값 또는 최솟값)의 후보가 됩니다.

## 한 줄 예

$f(x) = 2x + 1$은 전체 실수에서 증가함수입니다. 왜냐하면 $f'(x) = 2 > 0$이기 때문입니다.

또는 $f(x) = x^3$도 전체에서 증가함수인데, $f'(x) = 3x^2 \geq 0$이고 $x=0$을 제외하고 항상 양수이므로 엄격한 증가를 만족합니다.

반면 $f(x) = x^2$는 $(-\infty, 0]$에서는 감소, $[0, \infty)$에서는 증가하므로, 전체 실수에서는 증가함수가 아닙니다. 하지만 $x > 0$인 구간에서만 보면 증가함수입니다.

검산: `sympy.diff(lambda x: 2*x + 1, x)` → $2 > 0$ ✓
