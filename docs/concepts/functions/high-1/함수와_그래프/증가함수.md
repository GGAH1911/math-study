# 증가함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
구간 내의 $x$값이 커질 때 함수값 $f(x)$도 함께 커지는 함수를 말합니다.

## 본문
구간 $I$에서 정의된 함수 $f$가 증가함수일 필요충분조건은 $I$의 임의의 두 점 $x_1, x_2$에 대하여 $x_1 < x_2$이면 $f(x_1) < f(x_2)$를 만족하는 것입니다. 즉, $x$의 값이 오른쪽으로 이동함에 따라 함수값도 함께 증가하는 성질을 의미합니다.

### 직관과 기하적 의미
그래프 상에서 증가함수는 왼쪽에서 오른쪽으로 진행할 때 계속해서 위로 올라가는 모양을 띱니다. 미분 가능한 함수의 경우, 구간 $I$의 모든 점에서 도함수의 값이 양수($f'(x) > 0$)이면 해당 구간에서 함수는 증가합니다. 이는 그래프 위의 모든 점에서의 접선 기울기가 양수임을 의미하며, 함수가 지속적으로 상승하고 있음을 시각적으로 보여줍니다.

### 기본 성질
함수의 증감은 도함수의 부호와 밀접한 관련이 있습니다. 도함수가 양수이면 증가함수이고, 반대로 도함수가 음수($f'(x) < 0$)이면 감소함수가 됩니다. 도함수가 $0$이 되는 지점은 함수의 증가 또는 감소가 바뀌는 극값의 후보가 될 수 있습니다. 예를 들어 $f(x) = 2x + 1$은 모든 구간에서 $f'(x) = 2 > 0$이므로 증가함수이며, $f(x) = x^3$은 $f'(x) = 3x^2 \geq 0$이고 $x=0$을 제외하고 항상 양수이므로 증가함수입니다. 반면 $f(x) = x^2$은 구간에 따라 증가와 감소가 나뉘므로 전체 실수 범위에서는 증가함수가 아닙니다.

## 학습 체크
- $x_1 < x_2$일 때 $f(x_1) < f(x_2)$를 만족하는지 확인했는가?
- 도함수의 부호가 양수($>0$)인지, 혹은 $0$을 포함하여 증가하는 형태인지 구분할 수 있는가?
- 특정 구간에서 함수가 증가하는지 감소하는지 그래프의 기울기를 통해 판단할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수의 부호를 통해 함수의 증가와 감소를 판정하고, 이를 바탕으로 함수의 극값과 그래프의 개형을 파악하는 데 사용됩니다.
