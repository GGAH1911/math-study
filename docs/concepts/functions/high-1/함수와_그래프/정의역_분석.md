# 정의역 분석

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f(x)$가 실수 값으로 정의될 수 있도록 하는 모든 $x$의 집합을 찾는 과정입니다.

## 본문
함수 $f$의 정의역(domain)은 $f(x)$가 실수 값으로 정의되는 모든 $x$의 집합이며, 이를 $D_f$로 표기합니다. 함수가 그래프로 나타날 때 정의역은 그래프가 $x$축 상에서 존재할 수 있는 범위를 의미합니다. 실함수를 다룰 때 정의역이 특정 범위로 제한되는 이유는 함수의 형태에 따라 정의되지 않는 구간이 존재하기 때문입니다.

### 직관과 기하적 의미
정의역은 함수 그래프가 그려질 수 있는 $x$축의 영역을 결정합니다. 예를 들어, 로그함수 $\log_a x$ ($a > 0, a \neq 1$)는 지수함수의 성질에 의해 항상 양수 범위에서만 정의됩니다. 반면 지수함수 $a^x$는 모든 실수 $x$에 대해 정의되어 정의역이 실수 전체($\mathbb{R}$)가 됩니다. 또한 짝수 제곱근 $\sqrt[2n]{x}$ ($n \in \mathbb{N}$)은 루트 안의 값이 음수가 될 수 없으므로 $x \geq 0$인 구간에서만 그래프가 존재합니다.

### 기본 성질
함수의 종류에 따라 정의역을 결정하는 주요 조건은 다음과 같습니다.
- 로그함수: 로그의 진수가 반드시 양수여야 합니다.
- 지수함수: 모든 실수 범위에서 정의됩니다.
- 무리함수: 짝수 제곱근 내부의 값이 0 이상이어야 합니다.
- 분수 형태의 함수: 분모가 0이 되지 않는 $x$의 범위를 찾아야 합니다.

## 학습 체크
- 로그함수 $f(x) = \log_a(g(x))$에서 정의역을 구하기 위해 $g(x) > 0$ 조건을 적용할 수 있는가?
- 무리함수 $\sqrt{g(x)}$의 정의역을 구할 때 $g(x) \geq 0$ 조건을 정확히 적용하는가?
- 지수함수와 로그함수의 역함수 관계를 통해 정의역과 치역의 관계를 이해하고 있는가?

## 관련 개념
- **지수함수와 로그함수**: 두 함수는 역함수 관계에 있으므로, 지수함수의 치역인 $(0, \infty)$가 로그함수의 정의역이 됩니다.
