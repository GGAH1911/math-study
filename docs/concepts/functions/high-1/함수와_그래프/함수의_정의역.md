# 함수의 정의역

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f : X \to Y$에서 입력값으로 허용되는 모든 $x$의 집합을 의미합니다.

## 본문
함수 $f : X \to Y$에서 **정의역**(domain)은 함수에 입력될 수 있는 모든 $x$값들의 집합 $X$를 말하며, 즉 $f(x)$를 계산할 수 있는 모든 $x$의 범위를 뜻합니다. 특히 치역이 실수인 실함수의 경우, 정의역에 속한 모든 원소에 대해 함숫값이 실수로 정의되어야 하므로 다음과 같은 조건들이 정의역을 결정하는 기준이 됩니다. 분모가 $0$이 되는 값은 제외되어야 하며, 음수의 짝수 제곱근은 정의될 수 없고, 로그의 진수는 반드시 양수여야 합니다. 반면 지수함수의 밑 조건인 $a > 0, a \neq 1$을 만족하는 경우 지수 부분인 $x$는 모든 실수에서 정의될 수 있습니다.

### 직관과 기하적 의미
정의역은 함수 그래프가 존재하는 $x$축 영역을 의미합니다. 예를 들어 $y = \sqrt{x}$의 그래프는 $x \geq 0$인 오른쪽 반평면에만 그려지는데, 이때의 정의역은 $[0, \infty)$입니다. 정의역을 명시하는 것은 해당 함수가 유효하게 존재하는 범위를 선언하는 것과 같으며, 같은 식을 가지더라도 정의역이 다르면 서로 다른 함수로 취급됩니다.

### 기본 성질
- 분수 형태의 식에서는 분모가 $0$이 되지 않는 범위가 정의역이 됩니다.
- 무리함수 형태의 식에서는 근호 안의 값이 $0$ 이상인 범위가 정의역이 됩니다.
- 로그 형태의 식에서는 진수 조건에 따라 진수가 $0$보다 큰 범위가 정의역이 됩니다.

## 학습 체크
- 주어진 식에서 분모가 $0$이 되는 지점이나 로그의 진수 조건 등을 고려하여 제외해야 할 값이 있는지 확인했는가?
- 함수의 식과 함께 제시된 정의역이 그래프의 $x$축 범위와 일치하는지 확인했는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수는 밑이 양수일 때 모든 실수를 정의역으로 갖지만, 로그함수는 진수 조건에 의해 정의역이 특정 구간으로 제한됩니다.
