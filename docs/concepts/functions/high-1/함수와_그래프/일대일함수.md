# 일대일함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역의 서로 다른 원소가 서로 다른 공역의 원소에 대응되는 함수를 의미합니다.

## 본문
함수 $f: A \to B$가 일대일함수(단사함수)라는 것은 정의역의 서로 다른 원소가 서로 다른 치역값으로 대응된다는 것을 의미합니다. 즉, 임의의 $x_1, x_2 \in A$에 대하여 $x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$가 성립해야 합니다. 논리적으로는 대우 명제인 $f(x_1) = f(x_2) \implies x_1 = x_2$가 성립하는 것과 같습니다.

### 직관과 기하적 의미
그래프를 통해 확인할 때는 수평선 검사를 활용합니다. 그래프에 평행한 임의의 수평선 $y = c$를 그었을 때, 이 선이 함수의 그래프와 최대 한 점에서만 만난다면 그 함수는 일대일함수입니다. 이는 하나의 $y$값이 오직 하나의 $x$값에 의해서만 결정됨을 시각적으로 보여줍니다.

### 기본 성질
미분 가능한 함수의 경우, 도함수의 부호가 함수 전체 구간에서 일정하면 일대일함수가 됩니다. 즉, $f'(x) > 0$ 또는 $f'(x) < 0$이 정의역 전체에서 성립하면 함수가 계속 증가하거나 계속 감소하므로 일대일함수가 됩니다. 만약 $f'(x) = 0$인 구간이 존재하여 함수가 상수값을 갖게 되면, 서로 다른 $x$값이 같은 $y$값을 갖게 되어 일대일함수의 조건을 만족하지 못합니다.

## 학습 체크
- $f(x_1) = f(x_2)$일 때 $x_1 = x_2$임을 이용하여 일대일함수임을 증명할 수 있는가?
- 함수의 그래프가 수평선과 만나는 점의 개수를 통해 일대일함수 여부를 판단할 수 있는가?
- 도함수의 부호가 일정할 때 함수가 일대일함수가 되는 이유를 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증가와 감소를 판단하여 일대일함수 여부를 판별하거나, 함수의 역함수 존재 여부를 확인하는 데 사용됩니다.
