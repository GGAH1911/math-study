# 구간에서의 함수 분석

## 정확한 진술

주어진 함수 $f(x)$가 폐구간 $[a, b]$에서 어떤 성질을 가지는지 조사하는 것을 **구간에서의 함수 분석**이라고 합니다. 여기서 분석 대상은 증감(단조성), 극값, 변곡점, 함수값의 범위(치역) 등입니다. 특히 도함수 $f'(x)$의 부호를 통해 함수의 증감을 판정하고, 이를 바탕으로 극값을 찾습니다.

## 직관과 기하적 의미

함수의 그래프를 왼쪽에서 오른쪽으로 따라가며 관찰할 때, 그 모양이 어떻게 변하는지 알려주는 도구입니다. 도함수 $f'(x) > 0$인 구간에서는 함수가 증가하고, $f'(x) < 0$인 구간에서는 감소합니다. 이를 통해 함수가 언제 "올라가고" 언제 "내려가는지" 파악할 수 있으며, 극값(가장 높은 지점이나 가장 낮은 지점)도 찾을 수 있습니다. 

구간 분석은 실생활 문제에서도 중요합니다. 예를 들어 물건의 생산량에 따른 이윤함수에서, 이윤이 최대가 되는 생산량을 찾거나, 물체의 속도가 가장 빠를 때를 결정할 때 사용됩니다.

## 기본 절차

구간 $[a, b]$에서 함수 $f(x)$를 분석하려면:

1. **도함수 구하기**: $f'(x)$ 계산
2. **증감 판정**: $f'(x) = 0$인 점들을 찾아 각 부분구간에서 $f'(x)$의 부호 결정
3. **극값 찾기**: $f'(x)$의 부호가 바뀌는 점에서 극값 존재 여부 확인
4. **범위 결정**: 극값과 끝점에서의 함수값을 비교하여 최댓값과 최솟값 결정

## 한 줄 예

$f(x) = -x^2 + 4x + 1$을 구간 $[0, 5]$에서 분석하면, $f'(x) = -2x + 4$이므로 $x = 2$에서 극댓값 $f(2) = 5$를 가지고, 끝점 비교 시 $[0, 5]$에서의 최댓값은 5, 최솟값은 $f(5) = -4$입니다. (검증: `f = lambda x: -x**2 + 4*x + 1; print(f(0), f(2), f(5))` → `1, 5, -4`)
