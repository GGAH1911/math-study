# 고정점

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 정의

함수 $f$의 **고정점(fixed point)**은 다음 조건을 만족하는 점 $x$입니다:

$$f(x) = x$$

즉, 함수에 의해 자기 자신으로 대응되는 점을 의미합니다.

## 직관과 그래프적 의미

고정점을 시각적으로 이해하면, 함수 $y = f(x)$의 그래프와 직선 $y = x$가 만나는 교점의 $x$좌표입니다. 이 교점에서는 입력값과 출력값이 일치하므로, 함수를 반복 적용해도 그 점에서는 움직이지 않습니다.

예를 들어, 반복 계산 $x_{n+1} = f(x_n)$에서 수렴하는 수열의 극한값은 고정점입니다. 또한 고정점은 동역학계(dynamical system)와 수열의 수렴성을 분석하는 데 중요한 역할을 합니다.

## 예시

**예 1:** $f(x) = \frac{x+2}{2}$의 고정점을 구하면

$$x = \frac{x+2}{2} \Rightarrow 2x = x+2 \Rightarrow x = 2$$

검증: $f(2) = \frac{2+2}{2} = 2$ ✓

**예 2:** $g(x) = x^2 - 2$의 고정점을 구하려면 $x = x^2 - 2$에서 $x^2 - x - 2 = 0$이므로

$$(x-2)(x+1) = 0 \Rightarrow x = 2 \text{ 또는 } x = -1$$

(sympy.solve(x\*\*2 - x - 2, x) → [−1, 2])
