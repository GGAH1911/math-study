# 비전사

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f: X \to Y$에서 치역이 공역과 일치하지 않아, 공역의 원소 중 화살표를 받지 못하는 원소가 존재하는 경우를 말합니다.

## 본문
함수 $f: X \to Y$가 비전사(non-surjective)라는 것은 치역(함수값의 집합)이 공역과 같지 않은 경우를 의미합니다. 즉, $\text{Im}(f) \neq Y$인 상황을 말하며, 이를 논리 기호로 나타내면 공역 $Y$의 원소 중 $f(x) = y$를 만족하는 $x \in X$가 존재하지 않는 $y$가 최소 하나 이상 존재한다는 뜻입니다.

### 직관과 기하적 의미
함수를 두 집합 사이의 화살표 대응으로 이해할 때, 비전사 함수는 공역의 일부 원소들이 화살표를 받지 못하고 남겨진 상태를 나타냅니다. 전사 함수가 공역의 모든 원소가 빠짐없이 대응됨을 보장하는 것과 대조적입니다. 그래프의 관점에서 보면, 함수의 치역 범위가 공역으로 설정된 전체 범위보다 좁을 때 발생합니다. 예를 들어, 공역을 실수 전체로 잡은 이차함수 $f(x) = x^2$은 음수 값을 가질 수 없으므로 비전사 함수가 되지만, 공역을 $0$ 이상의 실수로 제한하면 전사 함수가 됩니다.

### 기본 성질
- 공역의 원소 중 정의역의 어떤 원소와도 대응되지 않는 원소가 존재한다.
- 함수의 치역이 공역의 부분집합이지만, 두 집합이 서로 같지는 않다.

## 학습 체크
- 주어진 함수의 치역을 구했을 때, 그 집합이 공역과 일치하는지 확인하였는가?
- 공역의 원소 중 함숫값으로 나타나지 않는 원소가 존재하는지 파악하였는가?

## 관련 개념
- **전사 함수**: 공역의 모든 원소가 정의역의 원소와 대응되어 치역과 공역이 일치하는 함수입니다.
- **치역**: 정의역의 원소들이 대응되어 나타나는 함숫값들의 집합입니다.
- **공역**: 함수가 가질 수 있는 전체 결과값의 범위를 의미합니다.
