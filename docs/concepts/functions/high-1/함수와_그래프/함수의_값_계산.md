# 함수의 값 계산

## 정확한 진술

함수 $f : X \to Y$에서 정의역 $X$에 속하는 어떤 값 $a$에 대해, 주어진 대응 관계에 따라 $b = f(a)$를 구하는 것을 **함수의 값을 계산한다**고 합니다. 이때 $f(a)$를 점 $a$에서의 **함숫값** 또는 **함수값**이라 부르며, $a$는 **정의역의 원소**여야 합니다.

예를 들어 $f(x) = 2x^2 - 3$이 주어졌을 때, $x = 5$를 함수에 대입하면
$$f(5) = 2(5)^2 - 3 = 50 - 3 = 47$$
이므로 함숫값은 47입니다.

## 직관과 기하적 의미

함수의 그래프를 생각해 보세요. 정의역의 어떤 점 $a$를 선택한 후, 그 점에서 수직으로 그래프 위로 올라가 그래프와 만나는 점의 **수직 좌표(y좌표)**가 바로 $f(a)$입니다. 함수는 정의역의 각 원소마다 **정확히 하나의 함숫값**을 대응시키므로, 한 번에 하나씩만 값이 결정됩니다. 이것이 함수와 대응이 아닌 일반적인 관계를 구분하는 핵심입니다.

## 단계별 계산 예

$g(x) = -x^2 + 4x + 1$일 때 $g(-2)$를 구하세요.

정의역의 값 $x = -2$를 식에 대입합니다:
$$g(-2) = -(-2)^2 + 4(-2) + 1 = -4 - 8 + 1 = -11$$

따라서 $g(-2) = -11$입니다. (검증: `sympy.symbols('x'); g = -x**2 + 4*x + 1; g.subs(x, -2)` → `-11`)

## 주의할 점

정의역에 속하지 않는 값을 대입할 수는 없습니다. 예를 들어 정의역이 $\{1, 2, 3\}$인 함수 $f$에 대해 $f(5)$는 정의되지 않습니다. 또한 다항함수나 유리함수를 계산할 때는 **괄호를 정확히** 다루고 순서대로 계산해야 실수를 줄일 수 있습니다.
