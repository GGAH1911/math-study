# 집합과 함수

함수의 정의역·공역·치역을 집합 언어로 다루는 기본 개념입니다. 수학2 함수의 극한과 연속 단원의 사전 준비로 쓰입니다.

## 정의

함수 $f : X \to Y$는 정의역 $X$의 각 원소 $x$에 공역 $Y$의 단 하나의 원소 $f(x)$를 대응시키는 규칙입니다.
- **정의역** $X$: 함수가 정의되는 입력 집합.
- **공역** $Y$: 출력이 속할 수 있는 집합.
- **치역** $f(X) = \{f(x) \mid x \in X\}$: 실제 함숫값들의 집합. $f(X) \subseteq Y$가 항상 성립.

부분집합 $A \subseteq X$에 대한 상 $f(A) = \{f(x) \mid x \in A\}$, 부분집합 $B \subseteq Y$에 대한 역상 $f^{-1}(B) = \{x \in X \mid f(x) \in B\}$로 확장됩니다.

## 예시

$f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2$에 대해 정의역은 $\mathbb{R}$, 공역은 $\mathbb{R}$, 치역은 $[0, \infty)$입니다.

부분집합 $A = [-1, 2]$의 상은 $f(A) = [0, 4]$이고, $B = [1, 4]$의 역상은 $f^{-1}(B) = [-2, -1] \cup [1, 2]$입니다.
