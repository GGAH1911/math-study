# 집합과 함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
집합 $X$의 각 원소에 집합 $Y$의 원소를 하나씩 대응시키는 규칙을 함수라 하며, 정의역, 공역, 치역의 관계를 통해 함수의 구조를 파악합니다.

## 본문
함수 $f : X \to Y$는 정의역 $X$의 각 원소 $x$에 대하여 공역 $Y$의 단 하나의 원소 $f(x)$를 대응시키는 규칙입니다. 이때 정의역 $X$는 함수가 정의되는 입력 집합을 의미하며, 공역 $Y$는 출력이 속할 수 있는 전체 집합을 의미합니다. 치역 $f(X) = \{f(x) \mid x \in X\}$는 정의역의 원소들이 대응되어 실제로 나타나는 함숫값들의 집합으로, 항상 공역의 부분집합($f(X) \subseteq Y$)이 됩니다. 이러한 함수 개념은 집합의 언어를 통해 엄밀하게 정의되며, 이후 수학2의 함수의 극한과 연속을 학습하기 위한 필수적인 기초가 됩니다.

### 직관과 기하적 의미
함수는 입력값에 따라 결과값이 결정되는 대응 관계를 나타냅니다. 예를 들어 $f(x) = x^2$과 같은 함수에서 입력값 $x$가 $-1$이면 결과값은 $1$이 됩니다. 이를 집합의 관점에서 확장하면, 정의역의 부분집합 $A \subseteq X$에 대하여 함숫값들의 집합인 상 $f(A) = \{f(x) \mid x \in A\}$를 정의할 수 있습니다. 반대로 공역의 부분집합 $B \subseteq Y$에 대하여 함숫값이 $B$에 포함되게 하는 정의역 원소들의 집합인 역상 $f^{-1}(B) = \{x \in X \mid f(x) \in B\}$를 정의할 수 있습니다.

### 기본 성질
함수에서 정의역의 모든 원소는 반드시 공역의 원소와 대응되어야 하며, 하나의 원소가 두 개 이상의 결과값에 대응될 수 없습니다. 또한, 치역은 공역의 부분집합으로서 함수의 성질을 결정하는 중요한 요소가 됩니다.

## 학습 체크
- 정의역 $X$의 모든 원소가 공역 $Y$의 원소와 하나씩 대응되는지 확인하였는가?
- 치역이 공역의 부분집합임을 이해하고, 실제 함숫값의 범위를 구할 수 있는가?
- 주어진 부분집합에 대하여 상과 역상을 집합의 정의에 따라 정확히 계산할 수 있는가?
