# 단조성

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수의 함숫값이 정의역의 변화에 따라 일관되게 증가하거나 감소하며 한 방향으로만 움직이는 성질입니다.

## 본문
함수 $f$의 정의역에 속하는 두 수 $x_1, x_2$에 대해, $x_1 < x_2$일 때 $f(x_1) < f(x_2)$를 만족하면 단조증가(strictly increasing)라고 하며, $f(x_1) > f(x_2)$를 만족하면 단조감소(strictly decreasing)라고 합니다. 이처럼 단조증가 또는 단조감소 중 하나를 만족하는 함수를 단조함수(monotonic function)라고 정의합니다. 이때 함숫값이 같을 수도 있는 경우를 포함하여 '비감소' 또는 '비증가'라고 부르기도 합니다.

### 직관과 기하적 의미
함수의 단조성은 그래프가 끊임없이 위로 올라가거나 아래로 내려가는 등 한 방향으로만 움직이는 성질을 의미합니다. 단조증가 함수는 그래프가 왼쪽에서 오른쪽으로 갈수록 계속 상승하는 형태를 보이며, 단조감소 함수는 계속 하강하는 형태를 보입니다. 이를 통해 함수의 전체적인 행동 패턴을 직관적으로 파악할 수 있습니다. 고등학교 미적분 과정에서는 도함수를 활용하여 $f'(x) > 0$인 구간에서 단조증가하고, $f'(x) < 0$인 구간에서 단조감소함을 판정합니다.

### 기본 성질
함수의 단조성은 함수의 변화 추세를 결정짓는 중요한 요소입니다. 예를 들어 $f(x) = 2x + 3$은 모든 실수에서 단조증가하며, $g(x) = -x^2$는 $x > 0$인 구간에서 $g(1) = -1 > g(2) = -4$와 같이 함숫값이 계속 작아지므로 단조감소합니다.

## 학습 체크
- $x_1 < x_2$일 때 $f(x_1) \le f(x_2)$를 만족하는 함수는 단조증가 함수인가요, 아니면 비감소 함수인가요?
- 도함수의 부호가 양수일 때 함수는 어떤 단조성을 갖나요?

## 관련 개념
- **함수와 그래프**: 함수의 단조성은 그래프의 기울기와 방향성을 결정하여 함수의 전체적인 모양을 결정합니다.
