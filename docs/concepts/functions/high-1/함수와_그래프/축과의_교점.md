# 축과의 교점

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 정확한 진술

함수 $y = f(x)$의 그래프와 좌표축이 만나는 점을 **축과의 교점**이라 합니다. 구체적으로:
- **x축과의 교점**: $y = 0$을 만족하는 점, 즉 $f(x) = 0$의 해 $(x_0, 0)$
- **y축과의 교점**: $x = 0$을 만족하는 점, 즉 $(0, f(0))$

일반적으로 "축과의 교점"은 **x축과의 교점**을 의미하며, 이는 함수의 영점(零點) 또는 근(根)과 같습니다.

## 직관/기하적 의미

함수의 그래프를 그릴 때 축과의 교점은 함수의 특징을 파악하는 중요한 포인트입니다. x축과의 교점을 찾는 것은 $f(x) = 0$의 모든 해를 구하는 것과 같으므로, 함수가 언제 양수에서 음수로 바뀌는지를 결정합니다. 특히 도함수 활용 단원에서는 극값, 변곡점, 부호 변화를 분석할 때 축과의 교점이 함수의 개형을 그리는 데 필수적입니다.

y축과의 교점은 보통 하나만 존재하며($x=0$에서의 함수값이므로), x축과의 교점은 여러 개 존재할 수 있습니다.

## 한 줄 예

$f(x) = x^2 - 5x + 6 = (x-2)(x-3)$일 때, x축과의 교점은 $(2, 0)$, $(3, 0)$이고, y축과의 교점은 $(0, 6)$입니다. 

(검산: `sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`; $f(0) = 6$ ✓)
