# 함수의 정의

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역의 각 원소에 공역의 한 원소가 대응

## 본문 (학습 시 채워짐)

### 정확한 진술

두 집합 $X$, $Y$가 주어졌을 때, 집합 $X$의 각 원소에 집합 $Y$의 원소가 **유일하게** 하나씩 대응되는 규칙을 **함수**라고 합니다. 함수 $f$를 기호로 나타낼 때:

$$f : X \to Y, \quad x \mapsto f(x)$$

여기서:
- **정의역**(domain): $X$ — 함수에 입력하는 값들의 집합
- **공역**(codomain): $Y$ — 함수의 출력이 속할 수 있는 집합
- **함숫값**: $f(x)$ — 정의역의 원소 $x$에 대응되는 공역의 원소
- **치역**(range): 정의역의 모든 원소를 함수에 대입했을 때 나오는 함숫값들의 집합 (공역의 부분집합)

**핵심**: 정의역의 각 원소는 정확히 **하나의** 공역 원소에 대응되어야 합니다. 하나도 빠지지 않고, 하나 이상으로 분산되지 않아야 합니다.

### 직관/기하적 의미

함수를 화살표 다이어그램으로 나타내면, 정의역의 각 점에서 공역의 어떤 점으로 정확히 하나의 화살표가 나갑니다. 일대일 대응이 아닐 수도 있으므로, 공역의 원소 중 일부는 화살표가 도착하지 않을 수 있습니다.

좌표평면에서는 함수 $f : X \to Y$의 그래프가 **연직선 판정법**을 만족합니다: 모든 수직선이 그래프와 최대 한 점에서만 만납니다. 이는 함수의 정의 — "각 $x$에 대해 $f(x)$는 하나뿐" — 을 기하학적으로 표현한 것입니다.

### 한 줄 예

함수 $f : \{1, 2, 3\} \to \{a, b, c, d\}$를 $f(1) = a$, $f(2) = c$, $f(3) = a$로 정의하면, 정의역의 모든 원소가 공역으로 대응되므로 함수입니다. 이 경우 치역은 $\{a, c\}$입니다.
