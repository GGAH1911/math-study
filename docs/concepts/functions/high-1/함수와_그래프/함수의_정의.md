# 함수의 정의

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
정의역의 각 원소에 공역의 원소가 유일하게 하나씩 대응되는 관계입니다.

## 본문
두 집합 $X$, $Y$가 주어졌을 때, 집합 $X$의 각 원소에 집합 $Y$의 원소가 **유일하게** 하나씩 대응되는 규칙을 **함수**라고 합니다. 함수 $f$를 기호로 나타내면 $f : X \to Y, \quad x \mapsto f(x)$와 같이 표현합니다. 여기서 $X$는 함수에 입력하는 값들의 집합인 **정의역**이며, $Y$는 함수의 출력이 속할 수 있는 집합인 **공역**입니다. 정의역의 원소 $x$에 대응되는 공역의 원소를 **함숫값** $f(x)$라고 하며, 정의역의 모든 원소를 대입했을 때 나오는 함숫값들의 집합을 **치역**이라고 합니다. 이때 치역은 공역의 부분집합이 됩니다. 함수의 핵심은 정의역의 모든 원소가 빠짐없이 대응되어야 하며, 동시에 하나의 원소가 두 개 이상의 원소에 대응되는 일이 없어야 한다는 점입니다.

### 직관과 기하적 의미
함수를 화살표 다이어그램으로 나타내면, 정의역의 각 점에서 공역의 어떤 점으로 정확히 하나의 화살표가 나갑니다. 이때 공역의 일부 원소는 화살표를 받지 못할 수도 있습니다. 좌표평면 위에서 함수의 그래프는 모든 수직선과 최대 한 점에서만 만나는 **연직선 판정법**을 만족하는데, 이는 $x$값 하나에 대응되는 $y$값이 오직 하나뿐이라는 함수의 정의를 기하학적으로 나타낸 것입니다.

### 기본 성질
함수 $f : \{1, 2, 3\} \to \{a, b, c, d\}$에서 $f(1) = a$, $f(2) = c$, $f(3) = a$와 같이 정의된다면, 정의역의 모든 원소가 공역의 원소에 대응되므로 함수가 됩니다. 이 경우 함숫값들의 집합인 치역은 $\{a, c\}$가 됩니다.

## 학습 체크
- 정의역의 모든 원소가 공역의 원소에 빠짐없이 대응되는가?
- 정의역의 한 원소가 공역의 두 개 이상의 원소에 대응되지는 않는가?
- 주어진 대응 관계에서 치역과 공역의 차이를 구분할 수 있는가?

## 관련 개념
- **함수와 그래프**: 함수의 정의를 좌표평면 위에 점의 집합으로 나타낸 것이 그래프입니다.
