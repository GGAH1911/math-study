# 함수의 합

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
두 함수의 함숫값을 각 점마다 더하여 새로운 함수를 만드는 연산입니다.

## 본문
두 함수 $f(x)$와 $g(x)$가 주어질 때, 함수의 합 $(f+g)(x)$는 $(f+g)(x) = f(x) + g(x)$로 정의합니다. 이때 함수의 합이 정의되기 위한 정의역은 $f$의 정의역과 $g$의 정의역의 교집합입니다. 즉, 모든 $x$에 대하여 $f(x)$와 $g(x)$의 값이 각각 존재해야만 합의 함숫값도 정의될 수 있습니다.

### 직관과 기하적 의미
함수의 합은 그래프 상에서 각 $x$ 좌표에 대응하는 두 함수의 $y$ 좌표(높이)를 더하는 과정입니다. 예를 들어 $f(x) = 2x$와 $g(x) = x^2$이 있을 때, $x=3$에서의 함숫값은 $f(3)=6$과 $g(3)=9$를 더한 $15$가 됩니다. 시각적으로는 두 곡선의 높이를 합쳐 새로운 형태의 곡선을 그려나가는 것과 같습니다.

### 기본 성질
함수의 합은 결합법칙과 교환법칙이 성립하여 계산이 자유롭습니다. 다만, 함수의 합을 구할 때는 반드시 각 함수의 정의역을 확인하여 합함수의 정의역이 제한되는지 검토해야 합니다. 예를 들어 $f(x) = \tfrac{1}{x}$와 $g(x) = \sqrt{x}$의 합은 두 함수의 공통 범위인 $x > 0$에서만 정의됩니다.

## 학습 체크
- 함수의 합 $(f+g)(x)$의 정의역을 구할 때 두 함수의 정의역의 교집합을 고려하였는가?
- 분수함수나 무리함수가 포함된 경우, 함숫값이 정의되지 않는 구간이 있는지 확인하였는가?

## 관련 개념
- **수열**: 수열은 정의역이 자연수 집합인 함수로 볼 수 있으므로, 두 수열의 합은 각 항의 값을 더하는 방식으로 정의됩니다.
