# 함수값

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f$에 정의역의 원소 $a$를 대입하여 얻는 결과값 $f(a)$를 의미합니다.

## 본문
함수 $f$와 정의역에 속하는 원소 $a$에 대하여, $f(a)$를 **함수값**이라고 합니다. 즉, 입력값 $a$를 함수 $f$에 대입했을 때 나오는 출력값이 함수값입니다. 기호로 표현하면 $f: X \to Y$일 때, $a \in X$에 대하여 $f(a) \in Y$인 상태를 말합니다.

### 직관과 기하적 의미
함수를 입출력 기계로 이해하면, 함수값은 특정 입력을 넣었을 때 기계가 계산하여 내놓는 결과물입니다. 예를 들어 $f(x) = 2x + 1$이라는 기계에 $x = 3$을 넣으면 $7$이 나오는데, 이때 $7$이 함수값입니다.

그래프의 관점에서 함수값은 매우 중요한 의미를 갖습니다. 좌표평면 위에서 함수 $y = f(x)$의 그래프는 모든 점 $(a, f(a))$를 모아놓은 집합입니다. 따라서 함수값 $f(a)$는 $x = a$일 때 그래프 위의 점이 가지는 $y$좌표와 같습니다. 즉, 직선 $x = a$와 그래프가 만나는 교점에서 $y$축까지의 거리를 부호를 포함하여 나타낸 값입니다.

### 기본 성질
함수의 형태에 따라 함수값의 양상은 달라집니다. $f(x) = x^2 - 2x + 3$일 때 $f(2) = 3$이므로 $3$이 함수값이 되며, $g(x) = \frac{1}{x}$에서는 $g(2) = \frac{1}{2}$이 함수값이 됩니다. 반면 상수함수 $h(x) = 5$와 같은 경우에는 입력값 $x$가 무엇이든 상관없이 함수값이 항상 $5$로 일정하게 유지됩니다.

## 학습 체크
- 입력값 $a$를 함수에 대입했을 때 나오는 결과가 함수값임을 이해하고 있는가?
- 그래프 상에서 특정 $x$값에 대한 함수값을 $y$좌표의 관점에서 찾을 수 있는가?

## 관련 개념
- **함수와 그래프**: 함수의 함수값은 좌표평면 위 그래프의 $y$좌표로 나타나며, 그래프는 이러한 함수값들을 점으로 연결하여 시각화한 것입니다.
