# 순증가함수

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
입력값이 커짐에 따라 출력값도 항상 커지는 함수를 의미합니다.

## 본문
함수 $f(x)$가 어떤 구간에서 **순증가함수**라는 것은, 그 구간에 속하는 모든 $x_1, x_2$에 대해 $x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$를 만족할 때를 말합니다. 즉, 함수의 입력값이 증가하면 출력값도 항상 증가하는 상태를 의미합니다. 만약 함수가 미분가능하다면, 어떤 구간에서 도함수가 $f'(x) > 0$이면 그 구간에서 $f$는 순증가함수입니다.

### 직관과 기하적 의미
순증가함수의 그래프는 왼쪽에서 오른쪽으로 진행할수록 항상 위로 올라가는 형태를 띱니다. 이는 시간이 지날수록 통장 잔액이 계속 늘어나거나 아이의 키가 계속 커지는 상황처럼, 나중의 시점일수록 항상 더 많은 값을 가지는 상태를 시각화한 것입니다.

### 기본 성질
순증가함수는 일반적인 증가함수와 달리 엄격한 부등호($<$)를 사용하므로, 같은 함수값이 반복되지 않습니다. 따라서 $f(x) = c$와 같은 상수함수는 순증가함수에 해당하지 않습니다.

## 학습 체크
- $x_1 < x_2$일 때 $f(x_1) \le f(x_2)$를 만족하는 증가함수와 $f(x_1) < f(x_2)$를 만족하는 순증가함수의 차이점은 무엇인가요?
- 도함수의 부호가 $f'(x) > 0$인 구간에서 함수가 순증가함수임을 설명할 수 있나요?

## 관련 개념
- **함수의 극한과 연속**: 함수가 특정 구간에서 순증가하면, 해당 구간에서 함수가 연속일 때 극한값과 함숫값이 일관된 방향성을 가집니다.
- **미분가능성**: 함수가 미분가능할 때 도함수의 양수 조건($f'(x) > 0$)은 해당 구간에서 함수가 순증가함을 판별하는 강력한 도구가 됩니다.
