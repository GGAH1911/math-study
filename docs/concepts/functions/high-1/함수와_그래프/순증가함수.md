# 순증가함수

## 정확한 진술

함수 $f(x)$가 어떤 구간에서 **순증가함수**라는 것은, 그 구간에 속하는 모든 $x_1, x_2$에 대해
$$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$$
를 만족할 때를 말합니다. 즉, 함수의 입력값이 증가하면 출력값도 항상 증가합니다.

미분가능한 함수의 경우, 어떤 구간에서 도함수가 $f'(x) > 0$이면 그 구간에서 $f$는 순증가함수입니다.

## 직관 및 기하적 의미

순증가함수의 그래프는 왼쪽에서 오른쪽으로 갈수록 항상 올라갑니다. 현실에서는 시간이 지날수록 통장 잔액이 계속 증가하거나 아이의 키가 계속 커지는 상황입니다. 더 나중의 시점일수록 항상 더 많거나 더 크다는 뜻입니다.

주의할 점은, "증가함수"와 다르다는 것입니다. 엄격한 부등호를 요구하므로($<$ 기호), 같은 함수값이 반복되지 않습니다. 예를 들어 $f(x) = c$ (상수함수)는 순증가함수가 아닙니다.

## 예제

$f(x) = 2x + 1$은 모든 실수에서 순증가함수입니다. 도함수 $f'(x) = 2 > 0$이 항상 양수이기 때문입니다. 구체적으로 $x_1 = 0$, $x_2 = 2$일 때, $f(0) = 1 < f(2) = 5$이므로 정의를 만족합니다.
