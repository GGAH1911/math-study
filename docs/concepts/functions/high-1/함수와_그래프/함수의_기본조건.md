# 함수의 기본조건

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 정확한 진술

함수 $f : X \to Y$는 집합 $X$(정의역)의 **각 원소 $x$에 대해** 집합 $Y$(치역)의 **정확히 하나의 원소** $f(x)$를 대응시키는 규칙입니다. 여기서 "정확히 하나"는 함수가 함수이기 위한 필수조건입니다. $f(x)$가 때로 여러 값을 가지거나, 어떤 $x$에서 정의되지 않으면 함수가 아닙니다.

또한 함수는 정의역의 **모든 원소**에 대해 정의되어야 합니다. 일부 원소만 대응되고 나머지는 대응이 없으면 함수가 아닙니다.

## 직관/기하적 의미

정의역을 입력, 치역을 출력으로 생각하면, 함수는 "각 입력에 대해 정확히 하나의 출력을 주는 기계"입니다. 예를 들어 $f(x) = 2x$는 함수입니다. 어떤 $x$ 값을 입력해도 정확히 하나의 출력값 $2x$가 결정됩니다. 반면 $y^2 = x$ (즉, $y = \pm\sqrt{x}$)는 함수가 아닙니다. 예를 들어 $x = 4$일 때 $y = 2$ 또는 $y = -2$ 두 개가 나오므로, "정확히 하나"라는 조건을 위반합니다.

그래프로는 **수직선 판정법(vertical line test)**으로 확인합니다. 정의역의 각 점에서 그은 수직선이 그래프와 최대 한 번만 만나면 함수입니다.
