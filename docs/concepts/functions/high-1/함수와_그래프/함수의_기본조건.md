# 함수의 기본조건

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f : X \to Y$는 정의역 $X$의 모든 원소 $x$가 공역 $Y$의 원소 중 단 하나와 대응되어야 하는 규칙입니다.

## 본문
함수 $f : X \to Y$는 집합 $X$(정의역)의 각 원소 $x$에 대하여 집합 $Y$(치역)의 정확히 하나의 원소 $f(x)$를 대응시키는 규칙입니다. 여기서 "정확히 하나"라는 조건은 함수가 성립하기 위한 필수적인 조건입니다. 만약 어떤 $x$에 대해 대응되는 $f(x)$가 여러 개이거나, 혹은 어떤 $x$에 대해 대응되는 값이 존재하지 않는다면 그것은 함수라고 할 수 없습니다. 또한 함수는 정의역 $X$에 속하는 모든 원소에 대해 빠짐없이 대응이 이루어져야 합니다. 일부 원소에 대응이 정의되지 않는다면 함수로서의 조건을 충족하지 못합니다.

### 직관과 기하적 의미
함수를 입력에 따른 출력을 내놓는 기계로 생각하면 이해가 쉽습니다. 어떤 값을 입력했을 때 결과값이 유일하게 결정되어야 합니다. 예를 들어 $f(x) = 2x$는 어떤 $x$를 넣어도 하나의 결과가 나오므로 함수입니다. 반면 $y^2 = x$와 같은 관계는 $x=4$일 때 $y=2$ 또는 $y=-2$라는 두 개의 결과가 나올 수 있으므로 함수가 아닙니다. 이를 그래프로 확인할 때는 수직선 판정법을 사용합니다. 그래프 위의 임의의 점을 지나는 수직선을 그었을 때, 그래프와 만나는 점이 최대 한 번이라면 함수입니다.

### 기본 성질
함수가 성립하기 위해서는 '모든 원소의 대응'과 '유일한 대응'이라는 두 가지 핵심 원칙을 반드시 만족해야 합니다.

## 학습 체크
- 정의역의 모든 원소가 빠짐없이 대응되고 있는가?
- 하나의 입력값에 대해 두 개 이상의 출력값이 대응되지는 않는가?
- 수직선 판정법을 통해 그래프가 함수인지 확인할 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 지수함수와 로그함수는 각각의 정의역에 대해 단 하나의 함숫값을 가지므로 함수의 기본 조건을 만족하는 대표적인 함수입니다.
