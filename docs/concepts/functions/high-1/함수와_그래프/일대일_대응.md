### 정확한 진술

함수 $f: X \to Y$가 **일대일 대응**(또는 **전단사 함수**)이라는 것은 다음 두 조건을 동시에 만족하는 것입니다.

**1) 일대일성(단사성)**: 서로 다른 $x_1, x_2 \in X$에 대해, $x_1 \neq x_2$이면 $f(x_1) \neq f(x_2)$  
**2) 대응성(전사성)**: 모든 $y \in Y$에 대해, $f(x) = y$인 $x \in X$가 적어도 하나 존재

이 두 조건이 모두 성립하면, $X$의 각 원소는 $Y$의 원소와 정확히 하나씩 짝을 이룹니다.

### 직관과 기하적 의미

일대일 대응은 두 집합이 "크기가 같다"는 의미를 나타냅니다. 정의역의 모든 원소가 치역으로 빠짐없이(전사) 가고, 서로 다른 원소들이 다른 곳으로 간다(단사)는 뜻입니다.

**그래프로 이해하기**: $y = f(x)$ 그래프를 생각할 때, 치역의 어떤 수평선 $y = c$를 그어도 그래프와 정확히 한 점에서만 만나면 일대일 대응입니다(수평선 판정법).

### 예시

- $f(x) = 2x$ (실수 $\to$ 실수): 일대일 대응입니다. 임의의 $y$에 대해 $x = \frac{y}{2}$로 유일하게 결정됩니다.

- $f(x) = x^2$ (실수 $\to$ 실수): 일대일 대응이 아닙니다. $f(2) = f(-2) = 4$이므로 단사가 아닙니다.

- $f(x) = x^2$ ($x \geq 0 \to y \geq 0$): 이제는 일대일 대응입니다. 정의역을 제한하면 조건을 만족합니다.

```
# 검산 예: x² = 4를 [0,∞)에서 풀면 x=2만 가능
from sympy import solve; solve(2*x - 8, x)  # 역함수 f⁻¹(8) = 4
```
