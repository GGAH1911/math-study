# 함수의 영점

> **정의** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
함수 $f(x)$의 영점은 방정식 $f(x) = 0$을 만족하는 $x$의 값으로, 함수의 그래프가 $x$축과 만나는 점의 $x$좌표를 의미합니다.

## 본문
함수 $f(x)$의 영점(zero)은 $f(x) = 0$을 만족하는 $x$의 값입니다. 즉, 방정식 $f(x) = 0$의 모든 해가 함수 $f$의 영점이 됩니다. 함수는 상황에 따라 여러 개의 영점을 가질 수도 있고, 영점이 하나도 없을 수도 있습니다.

### 직관과 기하적 의미
함수의 그래프를 통해 영점을 시각적으로 이해할 수 있습니다. 영점은 함수의 그래프가 $x$축과 만나는 점의 $x$좌표와 같습니다. 예를 들어 이차함수 $f(x) = x^2 - 5x + 6$의 그래프는 점 $(2, 0)$과 $(3, 0)$에서 $x$축과 만나므로, 이 함수의 영점은 $x = 2$와 $x = 3$입니다. 따라서 "함수의 영점을 구하라"는 문제는 "방정식을 풀어 $x$값을 구하라"는 문제와 동일한 의미를 갖습니다.

### 기본 성질
영점을 찾는 과정은 함수의 종류에 따라 다양한 방식으로 전개됩니다. 삼각함수 $f(x) = \sin x$를 예로 들면, $\sin x = 0$을 만족하는 $x$는 $x = n\pi$ (단, $n$은 정수)이므로 모든 정수배의 $\pi$가 영점이 됩니다. 만약 범위를 $0 \le x < 2\pi$로 제한한다면, 영점은 $x = 0$과 $x = \pi$가 됩니다. 또한 두 함수가 만나는 지점을 찾기 위해 $f(x) = g(x)$를 $f(x) - g(x) = 0$의 형태로 변형하여 영점을 구할 수도 있습니다. 예를 들어 $\sin x = \cos x$의 영점을 구하기 위해 $f(x) = \sin x - \cos x$라는 새로운 함수를 만들면, $\tan x = 1$을 만족하는 $x = \frac{\pi}{4} + n\pi$가 이 함수의 영점이 됩니다.

## 학습 체크
- 함수 $f(x)$의 영점을 구하는 것이 방정식 $f(x) = 0$의 해를 구하는 것과 왜 같은지 설명할 수 있는가?
- 함수의 그래프가 $x$축과 만나는 점의 좌표를 보고 영점을 정확히 찾아낼 수 있는가?
- 주어진 범위 내에서 삼각함수의 영점을 구할 때, 일반해와 범위 내의 해를 구분할 수 있는가?

## 관련 개념
- **삼각함수**: $\sin x$나 $\cos x$와 같은 삼각함수의 영점을 찾는 과정은 삼각방정식을 푸는 과정과 직결됩니다.
