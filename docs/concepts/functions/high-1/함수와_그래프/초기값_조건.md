# 초기값 조건

## 정확한 진술

초기값 조건(initial condition)은 미분방정식이나 함수의 변화를 나타내는 문제에서 **특정 점에서의 함수값을 지정하는 조건**입니다. 예를 들어, 미분방정식 $\frac{dy}{dx} = f(x, y)$의 해를 구할 때 $y(x_0) = y_0$이라고 주어진 조건이 초기값 조건입니다. 이 조건은 무수히 많은 일반해 중에서 **특정한 하나의 해를 결정**하는 역할을 합니다.

## 직관과 기하적 의미

미분방정식을 풀면 보통 임의의 상수 $C$를 포함한 일반해가 나옵니다. 이는 같은 법칙을 따르면서도 **서로 다른 궤적**을 그리는 수많은 함수들이 존재함을 의미합니다. 초기값 조건은 "이 모든 곡선 중에서 점 $(x_0, y_0)$을 지나가는 곡선이 우리가 원하는 것"이라고 지정해주는 것입니다. 기하학적으로는 **곡선 한 개를 선택**하는 작업이며, 실제 현상을 설명할 때는 "시간 $t=0$일 때의 상태"처럼 **초기 상황을 나타냅니다**.

## 예

미분방정식 $\frac{dy}{dx} = 2x$의 일반해는 $y = x^2 + C$입니다. 초기값 조건 $y(1) = 5$가 주어지면, $5 = 1 + C$이므로 $C = 4$이고, **특수해는 $y = x^2 + 4$로 유일하게 결정됩니다**. (검산: sympy로 $y'(1) = 2$, $y(1) = 1 + 4 = 5$ 확인)
