### 정확한 진술

함수 $f: X \to Y$에서 정의역 $X$의 한 원소 $x$에 대해, 함수의 규칙에 따라 대응되는 치역 $Y$의 원소를 **함수의 값**이라고 합니다. 이를 기호 $f(x)$로 나타냅니다. 정의역의 각 원소 $x$에는 정확히 하나의 함수값 $f(x)$가 대응됩니다.

### 직관적 의미와 기하학적 해석

함수는 입력(정의역)을 받아서 규칙에 따라 출력(함수값)을 결정하는 대응입니다. **함수의 값**은 이 규칙을 통해 결정되는 구체적인 출력값입니다.

좌표평면에서 함수 $y = f(x)$의 그래프를 그렸을 때, 함수의 값은 기하학적으로 다음을 의미합니다:
- $x$축 위의 점 $x$에서 수직으로 올라가 그래프와 만나는 점의 **$y$좌표**가 바로 $f(x)$입니다.
- 함수의 값을 구하는 것 = 그래프에서 특정 $x$의 높이를 읽는 것

### 구체적 예

함수 $f(x) = x^2 - 3x + 2$에서:

$$f(1) = 1^2 - 3(1) + 2 = 0$$
$$f(3) = 3^2 - 3(3) + 2 = 2$$
$$f(0) = 0 - 0 + 2 = 2$$

각각의 경우에 정의역의 원소를 대입하면 유일한 함수값이 결정됩니다. 같은 함수값 2가 $f(0)$과 $f(3)$에서 나올 수 있으며, 이는 함수의 정의에 전혀 어긋나지 않습니다. 함수값 구하기에는 다항식의 계산이나 그래프 읽기 모두 가능합니다.
