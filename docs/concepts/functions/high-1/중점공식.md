### 정확한 진술

좌표평면에서 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 잇는 선분의 중점 $M$의 좌표는 다음 공식으로 구합니다.

$$M\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$$

각 성분을 따로 보면, 중점의 x좌표는 두 점의 x좌표의 평균이고, 중점의 y좌표는 두 점의 y좌표의 평균입니다.

### 직관과 기하적 의미

중점공식은 "두 점의 정확히 중간 위치"를 찾는 방법입니다. 좌표평면 위에서 점 $A$에서 점 $B$로 이동할 때, 절반만큼 이동한 위치가 중점이 되는 셈입니다. 

기하학적으로는 선분 $AB$를 $1:1$로 내분(分割)하는 점이 중점입니다. 좌표의 각 성분을 독립적으로 평균내는 이유는 x축 방향과 y축 방향의 변화가 서로 영향을 주지 않기 때문입니다.

### 실제 예제

두 점 $A(2, 4)$와 $B(8, 10)$의 중점을 구하면:

$$M\left(\frac{2+8}{2}, \frac{4+10}{2}\right) = M(5, 7)$$

확인: $(5-2, 7-4) = (3, 3)$과 $(8-5, 10-7) = (3, 3)$이므로 중점이 선분을 정확히 이등분합니다.

### 주의할 점

- 중점의 좌표는 항상 두 점 사이에 위치합니다(내분점).
- 3차원 공간에서도 같은 원리로 $M\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}, \frac{z_1+z_2}{2}\right)$입니다.
- 내분점 공식에서 비율이 $1:1$인 특수한 경우가 중점공식입니다.

검산: `from sympy import Point; Point(2,4).midpoint(Point(8,10))` → `Point(5, 7)`
