### 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$, $B(x_2, y_2)$가 주어졌을 때, **좌표의 계산**은 이들 점 사이의 거리, 중점, 내분점 등을 구하는 공식과 절차를 의미합니다.

**거리 공식**: 
$$\overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

**중점의 좌표**: 
$$M = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$$

**내분점의 좌표** (선분 $AB$를 $m:n$으로 내분하는 점 $P$):
$$P = \left(\frac{nx_1 + mx_2}{m+n}, \frac{ny_1 + my_2}{m+n}\right)$$

### 직관/기하적 의미

좌표계는 기하학적 대상을 수로 표현하는 방법입니다. 거리 공식은 피타고라스 정리에서 비롯되었으며, 두 점 사이의 직선거리를 대수적으로 계산할 수 있게 해줍니다. 중점과 내분점은 선분 위의 특수한 점들의 위치를 정확히 결정하므로, 도형의 성질(예: 삼각형의 무게중심, 평행사변형의 대각선의 교점)을 분석할 때 핵심 도구가 됩니다.

### 한 줄 예

$A(1, 2)$와 $B(7, 10)$에 대해, 거리는 $\sqrt{(7-1)^2 + (10-2)^2} = \sqrt{36 + 64} = 10$이고 중점은 $(4, 6)$입니다. (`sympy.sqrt((7-1)**2 + (10-2)**2)` → `10`)
