### 정확한 진술

함수 $f(x)$의 **도함수**는 다음 극한이 존재할 때 정의됩니다:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

또는 $a$에서의 도함수는:

$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

이 극한값이 존재하면 $f(x)$는 $x = a$에서 **미분가능**하다고 하고, 각 점에서 정의된 $f'(x)$를 도함수라 합니다.

### 직관과 기하적 의미

도함수는 **함수의 순간변화율**을 나타냅니다. 기하학적으로는 곡선 위의 점에서 그은 **접선의 기울기**입니다.

$h$가 0에 가까워질 때, $\frac{f(x+h) - f(x)}{h}$는 두 점 $(x, f(x))$와 $(x+h, f(x+h))$를 잇는 할선(secant line)의 기울기입니다. 이 할선이 한 점으로 수렴할 때의 기울기가 접선의 기울기, 즉 도함수입니다. 따라서 $f'(a) > 0$이면 $x=a$ 근처에서 함수가 증가하고, $f'(a) < 0$이면 감소합니다.

### 예시

$f(x) = x^2$에 대해 $x=2$에서의 도함수를 구하면:

$$f'(2) = \lim_{h \to 0} \frac{(2+h)^2 - 4}{h} = \lim_{h \to 0} \frac{4h + h^2}{h} = \lim_{h \to 0} (4 + h) = 4$$

일반적으로 $f(x) = x^2$의 도함수는 $f'(x) = 2x$이므로 $f'(2) = 4$입니다.

검증: `sympy.diff(x**2, x).subs(x, 2)` → 4
