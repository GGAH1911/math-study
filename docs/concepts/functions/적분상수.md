### 정확한 진술

함수 $f(x)$의 **부정적분**(정의되지 않은 적분)은 $F(x) + C$ 형태로 나타내집니다. 여기서 $F'(x) = f(x)$를 만족하는 함수 $F(x)$는 **원시함수(부정적분)**이고, $C$는 **적분상수**입니다. 같은 함수 $f(x)$에 대해 원시함수는 무수히 많지만, 모두 상수항만 다르므로 일반해를 $\int f(x) \, dx = F(x) + C$로 표기합니다.

$$\frac{d}{dx}[F(x) + C] = F'(x) = f(x)$$

### 직관과 기하적 의미

미분의 역과정인 적분에서 적분상수가 필요한 이유는, **상수함수의 도함수가 0**이기 때문입니다. $F(x)$와 $F(x) + C$를 미분하면 같은 결과 $f(x)$가 나오므로, 역으로 $f(x)$를 적분하면 어느 상수가 더해졌는지 알 수 없습니다. 기하적으로는, $y = F(x)$의 그래프를 수직으로 평행이동한 모든 곡선들이 같은 기울기(도함수)를 가지므로, 서로 다른 원시함수들은 연직 방향으로만 다릅니다.

### 예시

$\int 2x \, dx$를 계산하면:
- 도함수가 $2x$인 함수 중 하나는 $x^2$ (∵ $(x^2)' = 2x$)
- 다른 원시함수: $x^2 + 1$, $x^2 - 5$, $x^2 + \pi$ 등 모두 도함수가 $2x$

따라서 일반해는:
$$\int 2x \, dx = x^2 + C$$

검산: 양변을 $x$로 미분하면 $2x = 2x$ ✓

**주의**: 정적분 $\int_a^b f(x) \, dx$에서는 적분상수가 계산 과정에서 소거되므로 명시하지 않습니다. 적분상수는 부정적분(일반해)에만 붙습니다.
