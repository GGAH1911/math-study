### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 **판별식**은 다음과 같이 정의합니다:

$$D = b^2 - 4ac$$

판별식의 값에 따라 방정식의 근이 갖는 성질이 결정됩니다:
- $D > 0$: 서로 다른 두 개의 **실근** 존재
- $D = 0$: **중근**(중복도 2인 실근) 존재  
- $D < 0$: **실근 없음** (복소수 범위에서 켤레복소수 근 존재)

### 직관·기하적 의미

이차방정식의 해는 근의 공식으로 구할 수 있습니다:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \frac{-b \pm \sqrt{D}}{2a}$$

판별식 $D$는 루트 안의 값이므로, 이 제곱근이 실수인지 아닌지를 결정합니다. **기하적으로**, 이차함수 $y = ax^2 + bx + c$의 그래프가 $x$축과 만나는 점의 개수를 판단합니다:
- $D > 0$: 포물선이 $x$축을 **두 점에서 교차**
- $D = 0$: 포물선이 $x$축에 **한 점에서 접함**
- $D < 0$: 포물선이 $x$축과 **만나지 않음**

### 한 줄 예

방정식 $2x^2 - 5x + 3 = 0$에서 $D = (-5)^2 - 4(2)(3) = 25 - 24 = 1 > 0$이므로 서로 다른 두 실근 $x = \frac{5 \pm 1}{4}$, 즉 $x = \frac{3}{2}$ 또는 $x = 1$을 가집니다. `sympy.solve(2*x**2 - 5*x + 3, x)` → $[1, \frac{3}{2}]$
