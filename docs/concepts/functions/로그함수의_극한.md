### 정확한 진술

로그함수 $f(x) = \log_a x$ (단, $a > 0$, $a \neq 1$)의 극한은 다음과 같이 정의됩니다.

$a > 1$일 때:
- $\displaystyle \lim_{x \to a} \log_a x = \log_a a = 1$ (로그함수는 정의역의 모든 점에서 연속)
- $\displaystyle \lim_{x \to 0^+} \log_a x = -\infty$ (0에 가까워질수록 음의 무한대로)
- $\displaystyle \lim_{x \to \infty} \log_a x = \infty$ (무한히 커짐)

$0 < a < 1$일 때는 극한값의 부호가 반대입니다. 또한 자연로그 $\ln x$에 대해서는 다음이 성립합니다:

$$\lim_{x \to 0^+} x \ln x = 0 \quad \text{(중요한 극한)}$$

이는 지수함수와 로그함수의 역함수 관계, 그리고 지수함수의 증가율이 로그함수의 증가율보다 빠른 사실로부터 유도됩니다.

### 직관/기하적 의미

로그함수의 그래프는 $a > 1$일 때 오른쪽 위로 천천히 증가합니다. $x$가 0에 가까워지면 함수값은 $-\infty$로 떨어지고, $x$가 커질수록 $+\infty$에 향합니다. 이는 로그의 정의 자체—"밑 $a$를 몇 제곱해야 $x$가 나오는가?"—에서 비롯됩니다. $0 < x < 1$일 때는 음의 지수가 필요하므로 음수, $x > 1$일 때는 양의 지수가 필요하므로 양수입니다.

극한 $\lim_{x \to 0^+} x \ln x = 0$의 의미는, 로그함수의 감소 속도가 $x$의 감소 속도보다 느리다는 뜻입니다. 따라서 $x$가 작아지는 것이 로그의 음수 값을 상쇄하고도 남습니다.

### 한 줄 예

$\displaystyle \lim_{x \to 10} \log_{10} x = \log_{10} 10 = 1$이고, $\displaystyle \lim_{x \to 0^+} x^2 \ln x = 0$입니다 (sympy로 검증: `sympy.limit(x**2 * sympy.ln(x), x, 0, '+')` → 0).
