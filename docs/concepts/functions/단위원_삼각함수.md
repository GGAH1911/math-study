# 단위원 삼각함수

> **정의** · 수학1 · 단원: [삼각함수](/concepts/삼각함수)

## 요약
$(\cos\theta, \sin\theta)$

## 본문 (학습 시 채워짐)

### 정의

원점을 중심으로 하고 반지름이 1인 원을 **단위원**(unit circle)이라 합니다. 각 $\theta$에 대해 단위원 위의 한 점을 다음과 같이 대응시킵니다. 양의 $x$축 방향에서 반시계방향으로 각도 $\theta$만큼 회전한 위치에 있는 단위원 위의 점 $P$의 좌표를 $(\cos\theta, \sin\theta)$로 정의합니다.

$$\text{각 } \theta \text{에 대응하는 점} \quad P = (\cos\theta, \sin\theta)$$

### 기하적 의미

이 정의를 통해 삼각함수는 "각도에서 좌표로 가는 함수"가 됩니다. 각 $\theta$를 단위원 위의 회전으로 생각하면, 수평거리(x좌표)가 $\cos\theta$, 수직거리(y좌표)가 $\sin\theta$입니다. 반지름이 1이므로 항상 다음이 성립합니다.

$$\cos^2\theta + \sin^2\theta = 1$$

이는 삼각함수의 가장 기본이 되는 항등식이며, 기하학적으로 원의 방정식에서 자연스럽게 나옵니다. 또한 이 정의를 사용하면 직각삼각형으로는 정의할 수 없는 음의 각이나 $360°$를 넘는 각까지 일관되게 확장할 수 있다는 장점이 있습니다.

### 예시

$\theta = 60°$일 때, 단위원 위의 점은 $(\cos 60°, \sin 60°) = \left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$입니다.

확인: $\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{1}{4} + \frac{3}{4} = 1$ ✓
