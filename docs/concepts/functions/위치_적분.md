### 정확한 진술

함수 $f(x)$의 **부정적분**(또는 원시함수)은 $F'(x) = f(x)$를 만족하는 함수 $F(x)$를 말하며, 다음과 같이 표기한다:

$$\int f(x)\,dx = F(x) + C$$

여기서 $C$는 임의의 상수(적분상수), $\int$는 적분 기호, $f(x)$는 피적분함수, $dx$는 적분변수를 나타낸다.

### 직관과 기하적 의미

부정적분은 **미분의 역연산**이다. 도함수 $f(x)$가 주어졌을 때, 이를 미분해서 얻은 원래 함수 $F(x)$를 찾는 과정이다.

$F'(x) = f(x)$를 만족하면, $F(x) + C$도 같은 조건을 만족한다. 상수의 도함수는 0이기 때문이다. 따라서 부정적분은 유일하지 않으며, 적분상수 $C$만큼 무수히 많은 해를 갖는다. 기하학적으로 같은 도함수를 갖는 모든 곡선은 수직 평행이동으로만 다르다는 의미다.

### 기본 공식과 예제

**멱함수의 적분**: $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$ (단, $n \neq -1$)

**예 1** | $\int 3x^2\,dx = x^3 + C$  
검증: $(x^3 + C)' = 3x^2$ ✓

**삼각함수의 적분**: $\int \sin x\,dx = -\cos x + C$, $\int \cos x\,dx = \sin x + C$

**지수함수의 적분**: $\int e^x\,dx = e^x + C$

**예 2** | $\int (2x + 3)\,dx = x^2 + 3x + C$  
검증: $(x^2 + 3x + C)' = 2x + 3$ ✓

부정적분은 정적분을 계산하기 위한 기초이며, 넓이·부피·물리량 계산 등에 필수적이다.
