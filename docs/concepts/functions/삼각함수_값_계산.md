### 정확한 진술

삼각함수 값 계산이란 주어진 각에 대해 $\sin\theta$, $\cos\theta$, $\tan\theta$ 등의 함숫값을 구하는 것입니다. 특히 고등학교 수능에서는 **특수각**(0°, 30°, 45°, 60°, 90° 등)과 이들의 덧셈, 배각, 반각 관계를 이용해 여러 각도의 삼각함수 값을 체계적으로 계산합니다.

### 직관/기하적 의미

단위원(반지름이 1인 원) 위의 점 $P(\cos\theta, \sin\theta)$를 생각해 봅시다. 원점에서 점 $P$까지 이루는 각이 $\theta$일 때, $\cos\theta$는 점 $P$의 $x$좌표, $\sin\theta$는 $y$좌표입니다. 따라서 삼각함수 값 계산은 **각도에 따른 단위원 위의 점의 좌표를 찾는 것**입니다.

가장 기본이 되는 특수각들은 암기할 가치가 있습니다:
$$\sin 30° = \frac{1}{2}, \quad \cos 30° = \frac{\sqrt{3}}{2}, \quad \tan 30° = \frac{1}{\sqrt{3}}$$
$$\sin 45° = \frac{\sqrt{2}}{2}, \quad \cos 45° = \frac{\sqrt{2}}{2}, \quad \tan 45° = 1$$
$$\sin 60° = \frac{\sqrt{3}}{2}, \quad \cos 60° = \frac{1}{2}, \quad \tan 60° = \sqrt{3}$$

더 복잡한 각의 값은 덧셈 공식, 배각 공식, 반각 공식 등을 활용해 계산합니다. 예를 들어:
$$\sin(A+B) = \sin A \cos B + \cos A \sin B$$

이를 이용하면 $\sin 75° = \sin(45° + 30°)$ 처럼 특수각 조합으로 새로운 각의 값을 구할 수 있습니다.

### 한 줄 예

$\sin 75°$를 계산하면, 덧셈 공식을 이용해 $\sin 75° = \sin(45° + 30°) = \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2} = \frac{\sqrt{6} + \sqrt{2}}{4}$입니다.

```python
import sympy as sp
# sin(75°) 계산 확인
result = sp.sin(sp.rad(75))
sp.simplify(result)  # (sqrt(6) + sqrt(2))/4
```
