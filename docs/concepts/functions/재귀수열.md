### 정확한 진술

재귀수열이란 수열의 각 항이 그 이전의 항들로 표현되는 수열입니다. 즉, $n$번째 항 $a_n$을 $a_1, a_2, \ldots, a_{n-1}$의 식으로 나타낼 수 있는 수열을 말합니다. 

이를 엄밀히 정의하면: 초기값(또는 초기 조건) $a_1, a_2, \ldots, a_k$와 $n > k$일 때 $a_n$을 결정하는 **점화식(recurrence relation)** $a_n = f(a_{n-1}, a_{n-2}, \ldots, a_{n-k})$가 주어졌을 때, 이 점화식과 초기값으로 정의된 수열을 재귀수열이라 합니다.

가장 흔한 경우는 **1계 점화식** $a_n = f(a_{n-1})$ (초기값 $a_1$)이나 **2계 점화식** $a_n = f(a_{n-1}, a_{n-2})$ (초기값 $a_1, a_2$) 입니다.

### 직관 및 의미

재귀수열은 "이전 값을 알면 다음 값을 계산할 수 있다"는 발상입니다. 초기값 하나(또는 몇 개)만 알면, 점화식을 반복 적용해 모든 항을 차례대로 구할 수 있습니다. 

예를 들어 저축 계좌의 잔액은 재귀수열입니다: 다음 달 잔액 = 이번 달 잔액 + 이자 + 입금액. 감염병 확산 모델도 마찬가지입니다: 다음 날 확진자 수 = 오늘의 확진자와 접촉자 수에 따른 함수.

고등학교 교육과정에서는 주로 **일계 선형 점화식** $a_n = pa_{n-1} + q$ 또는 **이계 선형 점화식** $a_n = pa_{n-1} + qa_{n-2}$ (피보나치 수열 같은) 을 다룹니다. 이들은 특성방정식을 이용해 일반항 공식을 유도할 수 있어 시험 문제로 자주 출제됩니다.

### 간단한 예

$a_1 = 2$, $a_n = a_{n-1} + 3$ (단, $n \geq 2$)  
→ $a_1 = 2, a_2 = 5, a_3 = 8, a_4 = 11, \ldots$ (공차가 3인 등차수열)

더 복잡한 예: $a_1 = 1, a_2 = 1$, $a_n = a_{n-1} + a_{n-2}$ (피보나치 수열, $1, 1, 2, 3, 5, 8, 13, \ldots$)

(`sympy`로 확인: `f = [1, 1]; [f.append(f[-1] + f[-2]) for _ in range(5)]; print(f)` → `[1, 1, 2, 3, 5, 8, 13]`)
