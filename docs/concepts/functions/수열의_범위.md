### 정확한 진술

수열 $\{a_n\}$의 범위(또는 치역)는 그 수열의 모든 항들이 취할 수 있는 값들의 집합입니다. 수열을 일반항 $a_n = f(n)$으로 나타낼 때 (단, $n$은 자연수), 범위는 다음과 같이 정의됩니다:

$$\text{범위} = \{a_n \mid n \in \mathbb{N}\}$$

즉, $a_1, a_2, a_3, \ldots$을 모두 나열했을 때 나타나는 서로 다른 모든 값들의 집합입니다.

### 직관/기하적 의미

"수열의 범위를 구한다"는 것은 "이 수열이 정말로 어떤 값들에 도달할 수 있는가?"를 묻는 것입니다. 예를 들어, 수열의 항들이 항상 양수인지, 음수를 포함하는지, 어느 구간 안에 갇혀 있는지를 파악할 수 있습니다. 수열은 함수의 정의역이 자연수로 제한된 특수한 함수이므로, 함수의 치역(range) 개념이 정확히 적용됩니다. 범위를 알면 수열의 행동을 깊이 있게 이해할 수 있습니다.

### 한 줄 예

수열 $a_n = n^2$ (단, $n = 1, 2, 3, \ldots$)의 범위는 $\{1, 4, 9, 16, 25, \ldots\}$, 즉 완전제곱수의 집합입니다.

```python
# 검증: 처음 10개 항의 범위
values = [n**2 for n in range(1, 11)]
# [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```
