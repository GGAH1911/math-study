### 정확한 진술

이차함수의 **표준형**은 다음과 같이 나타낸 형태입니다:

$$f(x) = a(x-p)^2 + q$$

여기서 $a \neq 0$은 이차항의 계수이고, $p$와 $q$는 실수입니다. 이를 **꼭짓점 형태**라고도 부릅니다.

### 직관과 기하적 의미

표준형은 이차함수의 **그래프 형태와 위치를 한눈에 파악할 수 있는 장점**이 있습니다.

- **꼭짓점**: 점 $(p, q)$가 포물선의 꼭짓점입니다. 이곳이 함수의 최솟값(또는 최댓값)입니다.
- **축의 방정식**: 직선 $x = p$가 포물선의 대칭축입니다.
- **개형**: $a > 0$이면 아래로 볼록(∪ 모양), $a < 0$이면 위로 볼록(∩ 모양)입니다.
- **|a|의 크기**: $|a|$가 클수록 포물선이 더 가파르고, 작을수록 완만합니다.

일반형 $f(x) = ax^2 + bx + c$에서 표준형으로 바꾸려면 **완전제곱식**을 이용하면 됩니다:
$$a\left(x^2 + \frac{b}{a}x\right) + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c$$

따라서 $p = -\frac{b}{2a}$, $q = c - \frac{b^2}{4a}$입니다.

### 한 줄 예

$f(x) = 2(x-3)^2 + 5$는 꼭짓점이 $(3, 5)$이고 최솟값이 $5$인 포물선입니다. (검산: `sympy.sympify('2*(x-3)**2 + 5').subs(x, 3)` → $5$)
