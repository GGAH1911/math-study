# 이차함수

> **단원** · 중3 · 선수: [이차방정식](/concepts/이차방정식) / [일차함수](/concepts/일차함수) · 다음: [도형의 방정식](/concepts/도형의_방정식) / [함수와 그래프](/concepts/함수와_그래프)

## 학습 목표
- $y=ax^2+bx+c$의 그래프와 꼭짓점을 구한다
- 이차함수의 최댓값/최솟값을 활용한다
- 이차함수의 그래프와 $x$축의 교점을 이차방정식으로 구한다

## 다룰 정의 / 정리 / 예제

**정의**
- 이차함수 표준형 $y=a(x-p)^2+q$
- 꼭짓점, 축

**정리**
- $a>0$이면 아래로 볼록, $a<0$이면 위로 볼록
- 꼭짓점에서 최댓값/최솟값

**예제**
- 일반형 ↔ 표준형 변환
- [꼭짓점 좌표 구하기](/concepts/꼭짓점_좌표_구하기)
- $x$축과의 교점 구하기

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
