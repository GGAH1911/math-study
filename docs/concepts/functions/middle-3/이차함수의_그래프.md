### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 **그래프**는 좌표평면에서 순서쌍 $(x, f(x))$의 집합, 즉 $\{(x, ax^2 + bx + c) : x \in \mathbb{R}\}$을 그린 곡선입니다. 이는 방정식 $y = ax^2 + bx + c$을 만족하는 모든 점들의 자취를 의미합니다.

### 직관 및 기하적 의미

이차함수의 그래프는 **포물선**(parabola)이라 부르는 U자형 또는 역U자형의 대칭곡선입니다. 포물선의 모양은 최고차 계수 $a$의 부호에 따라 결정됩니다.

- $a > 0$일 때: 아래로 볼록한 포물선(∪ 모양) → 최솟값 존재
- $a > 0$일 때: 위로 볼록한 포물선(∩ 모양) → 최댓값 존재

포물선은 **꼭짓점**(정점, vertex)을 중심으로 좌우 대칭이며, 꼭짓점의 $x$좌표는 $x = -\frac{b}{2a}$입니다. 또한 계수 $a$의 절댓값이 클수록 포물선이 더 가파르게 열립니다.

### 구체적 예시

$f(x) = x^2 - 4x + 3$의 그래프를 살펴봅시다. 이를 완전제곱식으로 나타내면 $f(x) = (x-2)^2 - 1$이므로, 꼭짓점은 $(2, -1)$이고 $a = 1 > 0$이므로 아래로 볼록한 포물선입니다. $x$축과의 교점은 $x^2 - 4x + 3 = 0$을 풀어 $x = 1, 3$을 얻고, $y$축과의 교점은 $f(0) = 3$입니다.

```python
# 검산: sympy.solve(x**2 - 4*x + 3, x) 결과 [1, 3]
```

이 포물선은 $(1, 0)$과 $(3, 0)$을 지나며, 직선 $x = 2$를 대칭축으로 하고, 최솟값 $-1$을 꼭짓점에서 갖습니다.
