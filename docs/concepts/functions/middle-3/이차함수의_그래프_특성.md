### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 그래프는 다음의 특성을 갖는 포물선입니다.

**꼭짓점**: $x = -\frac{b}{2a}$에서 극값을 가지며, 좌표는 $\left(-\frac{b}{2a}, c - \frac{b^2}{4a}\right)$입니다.

**대칭축**: 꼭짓점을 지나가는 수직선 $x = -\frac{b}{2a}$입니다.

**개형**: $a > 0$이면 아래로 볼록(∪자 모양), $a < 0$이면 위로 볼록(∩자 모양)입니다.

**$y$절편**: $y$축과의 교점은 $(0, c)$입니다.

**영점의 개수**: 판별식 $D = b^2 - 4ac$에 따라 결정됩니다. $D > 0$이면 $x$축과 2개 교점, $D = 0$이면 1개(접함), $D < 0$이면 0개입니다.

### 직관·기하적 의미

포물선은 한 점(초점)과 한 직선(준선)으로부터의 거리가 항상 같은 점들의 자취입니다. 계수 $a$의 절댓값이 클수록 포물선이 수직으로 좁아지고, 작을수록 완만해집니다. 대칭축은 포물선을 좌우로 정확히 나누는 중심축이며, 꼭짓점은 포물선의 최댓값(위로 볼록) 또는 최솟값(아래로 볼록)을 나타냅니다.

### 한 줄 예

$f(x) = -2x^2 + 4x + 1$의 경우 꼭짓점은 $(1, 3)$이고 대칭축은 $x = 1$입니다.
