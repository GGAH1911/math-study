### 정확한 진술

이차함수의 계수 결정(determining coefficients of a quadratic function)이란 주어진 조건들을 이용하여 이차함수 $y = ax^2 + bx + c$의 세 계수 $a, b, c$를 유일하게 구하는 과정입니다. 이차함수는 정확히 3개의 미지수($a, b, c$)로 표현되므로, 유일한 해를 갖기 위해서는 일반적으로 3개의 독립적인 조건이 필요합니다. 조건의 형태는 다양할 수 있습니다: 포물선이 지나가는 세 점의 좌표, 꼭짓점의 좌표와 추가 한 점, 대칭축과 두 점의 좌표 등이 그 예입니다.

### 직관/기하적 의미

포물선의 모양과 위치는 세 계수 $a, b, c$에 의해 완전히 결정됩니다. 계수 $a$는 포물선의 열림 방향(위 또는 아래)과 좁고 넓은 정도를, 그리고 $b, c$는 포물선의 수평 및 수직 위치(꼭짓점의 위치)를 결정합니다. 따라서 포물선이 지나가는 점들, 꼭짓점의 위치, 대칭축 등의 기하학적 조건이 주어지면, 이를 만족하는 유일한 이차함수를 찾을 수 있으며, 이는 곧 좌표평면에서 유일한 포물선을 결정하는 것과 같습니다.

### 한 줄 예

세 점 $(0, 1), (1, 3), (2, 9)$를 지나는 이차함수를 구하려면 각 점을 $y = ax^2 + bx + c$에 대입하여 연립방정식 $c = 1$, $a + b + c = 3$, $4a + 2b + c = 9$를 얻고, 이를 풀면 $a = 2, b = 0, c = 1$이므로 $y = 2x^2 + 1$입니다. (검증: `sympy.solve([c - 1, a + b + c - 3, 4*a + 2*b + c - 9], [a, b, c])`)
