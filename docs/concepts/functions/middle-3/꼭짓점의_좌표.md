### 정확한 진술

이차함수의 꼭짓점(vertex)은 포물선이 최고점 또는 최저점에 도달하는 점입니다. 표준형 $f(x) = a(x-p)^2 + q$ (단, $a \neq 0$)로 나타낸 이차함수의 꼭짓점 좌표는 $(p, q)$입니다.

일반형 $f(x) = ax^2 + bx + c$로 주어진 경우, 완전제곱식으로 변환하면 꼭짓점의 좌표는 다음과 같습니다:
$$\left(-\frac{b}{2a}, \frac{4ac - b^2}{4a}\right)$$

직선 $x = -\frac{b}{2a}$는 포물선의 대칭축(축of symmetry)이며, 꼭짓점은 항상 이 축 위에 위치합니다.

### 직관과 기하적 의미

포물선의 모양을 결정하는 계수 $a$의 부호에 따라 꼭짓점의 성질이 달라집니다. $a > 0$이면 포물선이 아래로 볼록(∪ 모양)하므로 꼭짓점에서 함수의 최솟값을 가집니다. $a < 0$이면 포물선이 위로 볼록(∩ 모양)하므로 꼭짓점에서 함수의 최댓값을 가집니다. 최댓값·최솟값 문제를 풀 때는 반드시 꼭짓점의 좌표를 구해야 하므로, 이 개념이 수능에서 매우 자주 출제됩니다.

### 한 줄 예

$f(x) = 2x^2 - 8x + 5$의 경우 $a = 2, b = -8, c = 5$이므로 꼭짓점은 $\left(\frac{8}{4}, \frac{40-64}{8}\right) = (2, -3)$입니다. 실제로 $f(2) = 2(4) - 8(2) + 5 = -3$으로 확인됩니다.
