# 그래프

## 정확한 진술

함수 $f: X \to Y$의 **그래프**(graph)는 정의역 $X$의 각 원소 $x$에 대해 순서쌍 $(x, f(x))$로 이루어진 집합입니다. 즉,
$$\text{그래프} = \{(x, f(x)) \mid x \in X\}$$

## 직관·기하적 의미

그래프는 함수의 전체 행동을 한눈에 볼 수 있게 해주는 도구입니다. 실함수 $f: \mathbb{R} \to \mathbb{R}$의 경우, 각 점 $(x, f(x))$는 좌표평면 위의 한 점이고, 이 모든 점들을 연결한 것이 그래프의 **곡선**(또는 도형)이 됩니다.

예를 들어 이차함수 $f(x) = x^2$의 경우, $x = -2$일 때 점 $(-2, 4)$, $x = 0$일 때 점 $(0, 0)$, $x = 1$일 때 점 $(1, 1)$ 등이 모두 그래프 위에 있고, 이들을 모두 모으면 위로 볼록한 포물선 모양이 됩니다.

그래프를 그리면 다음을 한눈에 파악할 수 있습니다:
- **치역**: 그래프가 차지하는 $y$좌표 범위
- **최댓값/최솟값**: 함수가 도달하는 가장 큰/작은 $y$값
- **증감**: $x$가 증가할 때 $y$가 올라가는지 내려가는지
- **대칭성**: 함수의 대칭축이나 대칭점

## 한 줄 예

이차함수 $f(x) = (x - 1)^2 + 2$의 그래프는 꼭짓점이 $(1, 2)$인 위로 볼록한 포물선입니다.

**검산:**
```python
# sympy.solve를 이용해 $f(x) = 3$인 $x$값 구하기
# (x-1)^2 + 2 = 3 ⟹ (x-1)^2 = 1 ⟹ x = 0 또는 2
import sympy as sp
x = sp.Symbol('x')
sp.solve((x - 1)**2 + 2 - 3, x)  # [0, 2]
```
