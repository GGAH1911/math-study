# 이차함수의 대칭성

## 정확한 진술

이차함수 $f(x) = a(x-p)^2 + q$ (단, $a \neq 0$)는 직선 $x = p$에 대해 대칭입니다. 즉, 대칭축 $x = p$에서 같은 거리에 있는 두 점에서의 함숫값이 항상 같습니다. 수식으로 나타내면, 임의의 실수 $t$에 대해 $f(p-t) = f(p+t)$가 성립합니다. 일반형 $f(x) = ax^2 + bx + c$에서 대칭축은 $x = -\frac{b}{2a}$입니다.

## 직관/기하적 의미

이차함수의 그래프인 포물선은 가장 특징적인 성질이 **좌우 대칭**입니다. 포물선의 꼭짓점을 지나고 축과 평행한 직선(대칭축)을 중심으로 왼쪽과 오른쪽이 거울처럼 완벽하게 대칭입니다.

이 성질은 이차함수의 계수 $a$의 부호에 관계없이 항상 성립합니다. $a > 0$일 때 포물선이 아래로 볼록하고, $a < 0$일 때 위로 볼록하지만, 어떤 경우든 대칭축을 중심으로 한 대칭성은 변하지 않습니다. 이것이 이차함수가 일차함수나 삼차 이상의 함수와 구별되는 기하학적 특성이며, 방정식을 풀거나 최댓값·최솟값을 구할 때도 대칭성을 활용하면 계산이 훨씬 간편해집니다.

## 한 줄 예

$f(x) = (x-2)^2 + 1$은 $x=2$에 대해 대칭이므로 $f(0) = f(4) = 5$입니다. (`(0-2)**2 + 1`, `(4-2)**2 + 1` → 5)
