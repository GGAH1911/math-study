# 꼭짓점 좌표 구하기

> **예제** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
두 가지 방법

## 본문 (학습 시 채워짐)

### 문제

다음 이차함수의 꼭짓점 좌표를 구하시오.
$$y = x^2 - 4x + 5$$

### 풀이 — 방법 1: 완전제곱식으로 변환

$x$에 관한 항을 완전제곱식으로 만듭니다. $(x - 2)^2 = x^2 - 4x + 4$이므로:
$$y = (x^2 - 4x + 4) - 4 + 5 = (x - 2)^2 + 1$$

표준형 $y = a(x - p)^2 + q$에서 꼭짓점은 점 $(p, q)$이므로, 꼭짓점은 $(2, 1)$입니다. 이 방법은 포물선의 모양과 최솟값을 직관적으로 보여줍니다.

### 풀이 — 방법 2: 꼭짓점 공식 이용

일반형 $y = ax^2 + bx + c$에서 꼭짓점의 $x$ 좌표는 $x = -\frac{b}{2a}$입니다.

주어진 식에서 $a = 1, b = -4$이므로:
$$x = -\frac{-4}{2(1)} = 2$$

이제 $x = 2$를 원래 식에 대입하여 $y$ 좌표를 구합니다:
$$y = 2^2 - 4(2) + 5 = 4 - 8 + 5 = 1$$

따라서 꼭짓점은 $(2, 1)$입니다. 이 방법은 계산이 간결하고 정답을 빠르게 얻을 수 있습니다.

### 답

$(2, 1)$

### 확인 및 주의점

두 방법 모두 같은 답을 줍니다. **완전제곱식**은 포물선의 개형과 최솟값의 의미를 깊게 이해하는 데 좋고, **공식**은 시간이 제한된 시험 상황에서 빠릅니다. 최고차 계수 $a > 0$이면 꼭짓점이 최솟값, $a < 0$이면 최댓값이 됩니다. 이 문제에서는 $a = 1 > 0$이므로 $(2, 1)$이 함수의 최솟값입니다.

검산: `y = x**2 - 4*x + 5; y.subs(x, 2)` → `1` ✓
