# 이차함수의 판별식

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

이차함수의 그래프와 $x$축의 위치 관계 및 이차방정식의 근의 종류를 결정하는 값입니다. 중3 이차함수 단원의 중심 도구입니다.

## 정의

이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)와 그에 대응하는 이차방정식 $ax^2 + bx + c = 0$의 **판별식**은
$$D = b^2 - 4ac.$$
판별식의 부호로 다음이 결정됩니다.
- $D > 0$: 방정식이 서로 다른 두 실근, 그래프는 $x$축과 두 점에서 만남.
- $D = 0$: 중근, 그래프는 $x$축에 접함.
- $D < 0$: 서로 다른 두 허근, 그래프는 $x$축과 만나지 않음.

또한 짝수 공식으로 $b = 2b'$이면 $\dfrac{D}{4} = b'^2 - ac$를 사용할 수 있습니다.

## 예시

$f(x) = x^2 - 4x + 3$의 판별식은 $D = 16 - 12 = 4 > 0$이므로 그래프는 $x$축과 두 점에서 만납니다. 실제로 $f(x) = (x-1)(x-3)$.

또한 $g(x) = x^2 - 6x + 9 = (x-3)^2$은 $D = 36 - 36 = 0$이므로 $x = 3$에서 $x$축에 접합니다.
