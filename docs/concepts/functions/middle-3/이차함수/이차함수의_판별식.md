# 이차함수의 판별식

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 그래프와 $x$축의 위치 관계를 이차방정식의 판별식 $D = b^2 - 4ac$의 부호에 따라 결정하는 도구입니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)와 그에 대응하는 이차방정식 $ax^2 + bx + c = 0$의 판별식은 $D = b^2 - 4ac$로 정의됩니다. 이 값의 부호는 이차방정식의 근의 종류를 결정할 뿐만 아니라, 이차함수 그래프가 $x$축과 어떤 위치 관계를 갖는지 결정하는 핵심적인 역할을 합니다. 만약 $D > 0$이면 이차방정식은 서로 다른 두 실근을 가지며, 그래프는 $x$축과 두 점에서 만납니다. $D = 0$이면 방정식은 중근을 가지며, 그래프는 $x$축에 접합니다. 마지막으로 $D < 0$이면 방정식은 서로 다른 두 허근을 가지며, 그래프는 $x$축과 만나지 않습니다. 이때 일차항의 계수가 짝수일 경우 $b = 2b'$라 할 때 $\dfrac{D}{4} = b'^2 - ac$라는 짝수 판별식을 사용하여 계산을 간편하게 할 수 있습니다.

### 직관과 기하적 의미
판별식은 이차함수 그래프가 $x$축(즉, $y=0$인 직선)과 만나는 지점의 개수를 시각적으로 보여줍니다. $D$의 값이 양수라는 것은 그래프가 $x$축을 뚫고 지나가는 두 지점이 존재함을 의미하고, $D$가 0이라는 것은 그래프의 꼭짓점이 $x$축 위에 놓여 있음을 의미하며, $D$가 음수라는 것은 그래프가 $x$축 위나 아래에 떠 있는 상태임을 의미합니다.

### 기본 성질
- $D > 0$: 서로 다른 두 실근, $x$축과 두 점에서 만남
- $D = 0$: 중근, $x$축에 접함
- $D < 0$: 서로 다른 두 허근, $x$축과 만나지 않음
- 예시: $f(x) = x^2 - 4x + 3$은 $D = 4 > 0$이므로 $x$축과 두 점에서 만나며, $g(x) = x^2 - 6x + 9$은 $D = 0$이므로 $x$축에 접합니다.

## 학습 체크
- 이차함수의 계수가 주어졌을 때 판별식 $D$를 통해 그래프와 $x$축의 교점 개수를 구할 수 있는가?
- $D < 0$인 경우 그래프가 $x$축과 만나지 않는다는 사실을 기하학적으로 이해하고 있는가?
- 일차항의 계수가 짝수일 때 짝수 판별식을 사용하여 계산 실수를 줄일 수 있는가?
