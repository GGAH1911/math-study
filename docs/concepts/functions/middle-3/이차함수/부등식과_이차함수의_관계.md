# 부등식과 이차함수의 관계

이차부등식의 해를 이차함수 그래프와 $x$축의 위치 관계로 해석하는 관점입니다. 중3 이차함수 단원에서 시각적 풀이의 핵심입니다.

## 정의

이차함수 $y = ax^2 + bx + c$ ($a > 0$)에 대하여 부등식의 해는 그래프와 $x$축의 위치 관계로 결정됩니다.
- $ax^2 + bx + c > 0$: $y$가 양수인 구간, 즉 그래프가 $x$축보다 **위**에 있는 $x$의 집합.
- $ax^2 + bx + c < 0$: 그래프가 $x$축보다 **아래**에 있는 $x$의 집합.

판별식 $D = b^2 - 4ac$에 따라
- $D > 0$: 그래프는 $x$축과 두 점에서 만나고, 두 근 $\alpha < \beta$의 바깥에서 양, 사이에서 음.
- $D = 0$: $x$축에 접하며 함숫값은 한 점을 제외하면 양.
- $D < 0$: $x$축과 만나지 않으며 함숫값은 항상 양.

## 예시

$f(x) = x^2 - 3x + 2$의 그래프는 위로 열린 포물선이고 $f(x) = (x-1)(x-2)$. $x$축과 $x = 1, 2$에서 만납니다.

따라서 $f(x) > 0$의 해는 $x < 1$ 또는 $x > 2$이고, $f(x) < 0$의 해는 $1 < x < 2$입니다.
