# 부등식과 이차함수의 관계

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차부등식의 해는 이차함수 그래프가 $x$축보다 위 또는 아래에 위치하는 $x$의 범위를 찾는 과정으로 해석할 수 있습니다.

## 본문
이차부등식의 해를 구하는 과정은 이차함수 $y = ax^2 + bx + c$ ($a > 0$)의 그래프와 $x$축의 위치 관계를 파악하는 것과 같습니다. 부등식의 결과값인 $y$가 양수($>0$)인 구간은 그래프가 $x$축보다 위에 있는 $x$의 범위를 의미하며, $y$가 음수($<0$)인 구간은 그래프가 $x$축보다 아래에 있는 $x$의 범위를 의미합니다.

### 직관과 기하적 의미
그래프의 모양과 $x$축의 만남을 통해 부등식의 해를 시각적으로 이해할 수 있습니다. 판별식 $D = b^2 - 4ac$의 값에 따라 그래프의 위치가 결정됩니다. $D > 0$이면 그래프가 $x$축과 두 점에서 만나며, 두 근 $\alpha < \beta$를 기준으로 바깥쪽에서는 양수 값을 갖고 사이 구간에서는 음수 값을 갖습니다. $D = 0$이면 그래프가 $x$축에 접하며, 접점을 제외한 모든 구간에서 양수 값을 갖습니다. $D < 0$이면 그래프가 $x$축과 만나지 않고 전체적으로 $x$축 위에 떠 있는 형태가 되어 모든 실수 $x$에 대해 항상 양수 값을 갖습니다.

### 기본 성질
예를 들어 $f(x) = x^2 - 3x + 2$라는 함수를 생각할 때, 이 식은 $(x-1)(x-2)$로 인수분해되어 $x=1$과 $x=2$에서 $x$축과 만납니다. 이때 $f(x) > 0$을 만족하는 $x$의 범위는 그래프가 $x$축보다 높은 구간인 $x < 1$ 또는 $x > 2$가 됩니다. 반대로 $f(x) < 0$을 만족하는 $x$의 범위는 그래프가 $x$축보다 낮은 구간인 $1 < x < 2$가 됩니다.

## 학습 체크
- 이차함수 그래프가 $x$축과 만나지 않을 때, 부등식의 해가 항상 모든 실수 또는 해가 없는 경우 중 어느 쪽인지 판별식과 연결하여 설명할 수 있는가?
- 이차부등식의 해를 구할 때 그래프의 볼록한 방향(위로 볼록 또는 아래로 볼록)이 해의 범위에 어떤 영향을 미치는지 이해하고 있는가?
