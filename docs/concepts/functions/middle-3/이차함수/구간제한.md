# 구간 제한

함수의 정의역을 어떤 구간으로 한정하는 조건입니다. 중3 이차함수 단원에서 최댓값·최솟값 문제를 다룰 때 핵심이 됩니다.

## 정의

원래 정의역이 $\mathbb{R}$인 함수 $f(x)$의 정의역을 부분집합 $D \subseteq \mathbb{R}$로 한정하는 것을 **구간 제한**이라 합니다. 흔히 $D = [\alpha, \beta]$ (폐구간), $(\alpha, \beta)$ (개구간), $[\alpha, \beta)$ 등의 형태입니다.

구간 제한된 함수의 치역, 최댓값·최솟값은 원래 함수의 그래프와 다를 수 있으며, 특히 폐구간 위 연속함수에서는 최댓값·최솟값이 반드시 존재합니다(최대·최소 정리).

## 예시

$f(x) = x^2$의 정의역을 $\mathbb{R}$ 전체로 두면 치역은 $[0, \infty)$이고 최댓값은 없습니다.

같은 함수의 정의역을 $[-1, 2]$로 제한하면 최솟값은 $f(0) = 0$, 최댓값은 $f(2) = 4$, 치역은 $[0, 4]$입니다.
