# 좌표평면 위의 도형의 넓이

## 정확한 진술

좌표평면 위에서 곡선 $y=f(x)$와 $x$축, 그리고 $x=a$, $x=b$ ($a<b$)인 수직선으로 둘러싸인 도형의 넓이는 정적분으로 정의됩니다. $f(x) \geq 0$일 때:

$$\text{넓이} = \int_a^b f(x) \, dx$$

$f(x)$가 음수인 구간이 있으면 절댓값을 취하거나, 구간을 나누어 각각 계산합니다.

## 직관/기하적 의미

폭이 매우 작은 직사각형 띠 $f(x) \cdot dx$를 $x=a$부터 $x=b$까지 모두 더하면 도형의 넓이가 됩니다. 이것이 바로 리만 합(Riemann sum)의 극한이고, 정적분의 기하학적 의미입니다. 

곡선이 $x$축 위에 있을 때는 직관적으로 이해하기 쉽습니다. 예를 들어 이차함수 $y = -x^2 + 4$ (아래로 볼록한 포물선)와 $x$축 사이의 넓이를 구할 때, 포물선 아래 영역을 무한히 많은 얇은 직사각형으로 분할하여 더하면, 극한에서 정적분값이 됩니다.

## 한 줄 예

이차함수 $y = -x^2 + 4$와 $x$축 사이의 넓이 ($-2 \leq x \leq 2$):

$$\text{넓이} = \int_{-2}^{2} (-x^2+4) \, dx = \left[-\frac{x^3}{3}+4x\right]_{-2}^{2} = \left(\frac{-8}{3}+8\right) - \left(\frac{8}{3}-8\right) = \frac{32}{3}$$

(검산: `from sympy import symbols, integrate; x = symbols('x'); integrate(-x**2 + 4, (x, -2, 2))`)
