# 이차함수의 그래프

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 그래프는 좌표평면 위에서 포물선 모양을 그리는 곡선입니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 그래프는 좌표평면에서 순서쌍 $(x, f(x))$의 집합, 즉 $\{(x, ax^2 + bx + c) : x \in \mathbb{R}\}$을 그린 곡선입니다. 이는 방정식 $y = ax^2 + bx + c$을 만족하는 모든 점들의 자취를 의미합니다.

### 직관과 기하적 의미
이차함수의 그래프는 **포물선**(parabola)이라 부르는 U자형 또는 역U자형의 대칭곡선입니다. 포물선의 모양은 최고차항의 계수인 $a$의 부호에 따라 결정됩니다. $a > 0$일 때는 아래로 볼록한 모양(∪)을 그리며 최솟값을 갖고, $a < 0$일 때는 위로 볼록한 모양(∩)을 그리며 최댓값을 갖습니다. 또한 계수 $a$의 절댓값이 커질수록 포물선의 폭은 좁아지며 가파르게 그려집니다.

### 기본 성질
포물선은 **꼭짓점**(vertex)을 중심으로 좌우가 대칭인 구조를 가집니다. 꼭짓점의 $x$좌표는 $x = -\tfrac{b}{2a}$이며, 이 점을 지나는 직선 $x = -\tfrac{b}{2a}$를 대칭축이라고 합니다. 예를 들어 $f(x) = x^2 - 4x + 3$의 경우, 완전제곱식으로 변형하면 $f(x) = (x-2)^2 - 1$이 되어 꼭짓점은 $(2, -1)$이 됩니다. 이 그래프는 $x$축과 $(1, 0), (3, 0)$에서 만나고 $y$축과 $(0, 3)$에서 만납니다.

## 학습 체크
- 최고차항의 계수 $a$의 부호에 따른 그래프의 볼록 방향과 최댓값/최솟값의 존재 여부를 구분할 수 있는가?
- 이차함수 식을 완전제곱식 형태로 변형하여 꼭짓점의 좌표와 대칭축의 방정식을 구할 수 있는가?
- 그래프가 $x$축 및 $y$축과 만나는 점(절편)을 이차방정식과 함숫값 계산을 통해 찾을 수 있는가?

## 관련 개념
- **이차함수**: 그래프의 형태와 성질을 결정하는 근간이 되는 함수식입니다.
