# 좌표평면과 거리

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음과 같이 정의됩니다.

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

이를 **두 점 사이의 거리 공식**이라 부릅니다. 거리는 항상 0 이상의 실수이며, 두 점이 같으면 0입니다.

## 직관과 기하적 의미

두 점 $A$, $B$와 x축에 평행한 직선, y축에 평행한 직선으로 직각삼각형을 그리면, 가로 변의 길이는 $|x_2 - x_1|$이고 세로 변의 길이는 $|y_2 - y_1|$입니다. 거리 공식은 **피타고라스 정리**를 좌표에 적용한 것입니다:

$$d^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$$

따라서 거리는 좌표평면에서 두 점을 잇는 선분의 길이를 나타냅니다. 거리 공식은 대칭성이 있어서 $d(A, B) = d(B, A)$를 만족합니다.

## 한 줄 예

점 $A(1, 2)$와 점 $B(4, 6)$ 사이의 거리는 $d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$입니다. (`sympy.sqrt((4-1)**2 + (6-2)**2)` → 5)
