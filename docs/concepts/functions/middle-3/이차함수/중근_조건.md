# 중근 조건

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)이 **중근**을 가진다는 것은 두 근이 같은 하나의 값으로 일치하는 경우를 말합니다. 이는 판별식 $D = b^2 - 4ac = 0$일 때 성립하며, 이 경우 근의 공식에서
$$x = -\frac{b}{2a}$$
(중복도 2인 근)를 가집니다.

## 직관/기하적 의미

이차함수 $y = ax^2 + bx + c$의 그래프를 생각해봅시다. 일반적으로 포물선은 x축과 서로 다른 두 점에서 만나거나, 만나지 않습니다. 그런데 특수한 경우 포물선이 x축에 정확히 한 점에서 **접합니다**—이것이 중근입니다. 

기하학적으로는 포물선의 꼭짓점이 x축 위에 있다는 의미이며, 이 점이 함수의 최솟값(또는 최댓값)입니다. 대수적으로 보면, 식이 완전제곱 형태
$$ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2$$
로 나타나 항상 같은 부호를 유지합니다(0 이상 또는 0 이하).

## 한 줄 예

이차방정식 $x^2 - 6x + 9 = 0$에서 판별식은 $D = 36 - 36 = 0$이므로 중근 $x = 3$을 가지며, 실제로 $(x-3)^2 = 0$으로 인수분해됩니다. (`sympy.solve(x**2 - 6*x + 9, x)` → `[3]`)
