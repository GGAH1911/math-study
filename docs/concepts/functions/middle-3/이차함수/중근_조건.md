# 중근 조건

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차방정식이 중근을 갖는다는 것은 판별식 $D = b^2 - 4ac = 0$을 만족하여 두 근이 하나로 일치하는 상태를 의미합니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)이 중근을 가진다는 것은 두 근이 같은 하나의 값으로 일치하는 경우를 말합니다. 이는 판별식 $D = b^2 - 4ac = 0$일 때 성립하며, 이 경우 근의 공식에 의해 $x = -\tfrac{b}{2a}$라는 하나의 값을 갖게 됩니다. 이때의 근은 중복도가 2인 근으로 간주됩니다.

### 직관과 기하적 의미
이차함수 $y = ax^2 + bx + c$의 그래프 관점에서 중근은 포물선이 $x$축과 서로 다른 두 점에서 만나지 않고, $x$축에 정확히 한 점에서 접하는 특수한 상태를 의미합니다. 기하학적으로 이는 포물선의 꼭짓점이 $x$축 위에 놓여 있음을 뜻하며, 이 점이 함수의 최솟값 또는 최댓값이 됩니다. 대수적으로는 식이 $ax^2 + bx + c = a\left(x + \tfrac{b}{2a}\right)^2$와 같이 완전제곱 형태로 나타나며, 식의 값이 항상 $0$ 이상 또는 $0$ 이하의 부호를 유지하게 됩니다.

### 기본 성질
- 판별식 $D = b^2 - 4ac$의 값이 $0$이어야 합니다.
- 이차방정식이 완전제곱식의 형태로 인수분해됩니다.
- 그래프의 꼭짓점 좌표의 $y$값이 $0$입니다.

## 학습 체크
- 판별식 $D$의 값이 $0$일 때, 왜 근이 하나라고 하지 않고 중근이라고 표현하는가?
- 이차방정식의 계수 $a, b, c$ 중 하나가 변할 때, 그래프가 $x$축에 접하기 위한 조건은 무엇인가?
- 완전제곱식으로 나타나는 이차방정식의 그래프 특징을 설명할 수 있는가?

## 관련 개념
- **이차함수**: 이차함수의 그래프가 $x$축과 만나는 지점이 바로 이차방정식의 해이며, 중근을 가질 때 그래프는 $x$축에 접합니다.
- **판별식**: 이차방정식의 근의 종류를 판별하는 도구로, $D=0$이면 중근을 가짐을 결정합니다.
- **인수분해**: 중근을 갖는 이차방정식은 항상 $(x-k)^2=0$ 꼴의 완전제곱식으로 인수분해됩니다.
