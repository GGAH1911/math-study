# 이차함수의 근

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수의 근은 함수 $f(x) = ax^2 + bx + c$의 값이 $0$이 되게 하는 $x$값으로, 그래프가 $x$축과 만나는 지점의 $x$좌표를 의미합니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)의 근이란 $f(x) = 0$을 만족하는 $x$값입니다. 이는 곧 이차방정식 $ax^2 + bx + c = 0$의 해와 동일한 개념입니다. 이차방정식은 판별식 $D = b^2 - 4ac$의 값에 따라 근의 개수가 결정되는데, $D > 0$이면 서로 다른 두 실근을, $D = 0$이면 중근을, $D < 0$이면 실근을 갖지 않습니다(복소수 범위에서는 두 개의 허근을 가집니다). 모든 이차방정식의 근은 근의 공식 $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$를 통해 구할 수 있습니다.

### 직관과 기하적 의미
좌표평면에서 이차함수 $y = f(x)$의 그래프인 포물선이 $x$축과 만나는 점의 $x$좌표가 바로 근입니다. 포물선이 $x$축과 두 점에서 만나면 서로 다른 두 실근을 갖고, $x$축에 접하면 중근을 가지며, $x$축과 만나지 않고 떠 있으면 실근이 존재하지 않습니다.

### 기본 성질
이차함수의 근은 함수의 영점(zero)으로서 함수의 부호를 판정하거나 최댓값과 최솟값을 다룰 때 핵심적인 역할을 합니다. 예를 들어 $f(x) = x^2 - 5x + 6 = 0$의 경우, 인수분해를 통해 $(x-2)(x-3) = 0$으로 나타낼 수 있으며, 이때 근은 $x=2$ 또는 $x=3$이 됩니다.

## 학습 체크
- 판별식 $D$의 부호에 따라 그래프와 $x$축의 위치 관계가 어떻게 변하는지 설명할 수 있는가?
- 주어진 이차함수의 식을 보고 근의 공식을 사용하여 직접 근을 구할 수 있는가?
- 이차함수의 근이 이차부등식의 해를 구하는 과정에서 어떻게 활용되는지 이해하고 있는가?

## 관련 개념
- **이차함수**: 이차함수의 그래프가 $x$축과 만나는 지점을 결정하는 핵심 요소입니다.
- **이차방정식**: 이차함수의 함숫값이 $0$이 되는 지점을 찾는 과정은 곧 이차방정식의 해를 구하는 것과 같습니다.
- **이차부등식**: 이차함수의 근을 기준으로 함수의 부호가 양수인지 음수인지가 결정되므로 부등식의 해를 구하는 데 필수적입니다.
