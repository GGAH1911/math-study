# 정의역 제한

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
함수의 정의역을 원래의 집합의 부분집합으로 줄여서 새로운 함수를 만드는 것을 의미합니다.

## 본문
함수 $f: D \to \mathbb{R}$가 정의역 $D$에서 정의되어 있을 때, $D$의 부분집합 $D' \subseteq D$를 새로운 정의역으로 지정하여 함수 $f|_{D'}: D' \to \mathbb{R}$를 만드는 것을 **정의역 제한**이라고 합니다. 이때 $D'$를 **제한된 정의역**, 원래의 함수 $f|_{D'}$를 **제한된 함수**라고 부릅니다.

### 직관과 기하적 의미
함수는 정의역의 원소를 치역의 원소로 연결하는 대응 관계입니다. 정의역을 제한한다는 것은 이 대응 관계 중 일부 구간만을 선택하여 관찰하는 것과 같습니다. 예를 들어 포물선 $y = x^2$의 그래프 전체를 그리는 대신, $0 \le x \le 3$ 구간에 해당하는 부분 곡선만을 그리는 것이 정의역 제한의 기하적 표현입니다.

### 기본 성질
정의역을 제한하면 함수의 성질이 변할 수 있습니다.
- **최댓값과 최솟값**: 정의역의 범위가 바뀌면 함수의 최댓값이나 최솟값이 달라질 수 있습니다.
- **일대일 대응 여부**: 원래 함수가 일대일 대응이 아니더라도, 정의역을 적절히 제한하면 일대일 대응 함수로 만들 수 있습니다. 예를 들어 $f(x) = x^2$은 전체 구간에서 일대일 대응이 아니지만, $x \ge 0$으로 정의역을 제한하면 일대일 대응이 됩니다.

## 학습 체크
- 함수 $f(x) = x^2$의 정의역을 $[0, 2]$로 제한했을 때, 이 함수의 최댓값과 최솟값은 각각 얼마인가요?
- 원래 함수가 일대일 대응이 아닐 때, 정의역을 어떻게 제한해야 일대일 대응 함수로 만들 수 있을까요?

## 관련 개념
- **이차함수**: 이차함수의 정의역을 특정 구간으로 제한하면, 해당 구간 내에서 함수의 최댓값이나 최솟값을 결정하는 문제를 풀 수 있습니다.
