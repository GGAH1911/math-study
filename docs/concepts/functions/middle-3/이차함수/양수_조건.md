# 양수 조건

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수 $f(x) = ax^2 + bx + c$가 모든 실수 $x$에 대해 항상 양수($f(x) > 0$)가 되려면, $a > 0$이고 판별식 $D < 0$이어야 합니다.

## 본문
이차함수 $f(x) = ax^2 + bx + c$ ($a \neq 0$)가 모든 실수 $x$에 대하여 $f(x) > 0$을 만족하기 위한 필요충분조건은 $a > 0$과 $D = b^2 - 4ac < 0$을 동시에 만족하는 것입니다.

### 직관과 기하적 의미
이차함수의 그래프인 포물선이 모든 $x$에 대해 양수라는 것은, 그래프가 $x$축과 만나지 않으면서 동시에 $x$축보다 위쪽에 위치해야 함을 의미합니다. 이를 위해 포물선의 모양을 결정하는 $a$는 반드시 $0$보다 커서 그래프가 위로 볼록한 형태(입 모양이 위를 향함)를 가져야 합니다. 또한, 그래프가 $x$축과 교점을 갖지 않아야 하므로 판별식 $D$는 $0$보다 작아야 합니다. 만약 $a < 0$이면서 $D < 0$이라면, 그래프는 $x$축 아래에 떠 있는 형태가 되어 항상 음수가 됩니다.

### 기본 성질
- $a > 0$이고 $D < 0$이면 모든 실수 $x$에 대해 $f(x) > 0$입니다.
- $a < 0$이고 $D < 0$이면 모든 실수 $x$에 대해 $f(x) < 0$입니다.
- $D = 0$인 경우, 그래프가 $x$축에 접하므로 $f(x)=0$인 지점이 존재하여 양수 조건을 만족할 수 없습니다.

## 학습 체크
- 이차함수가 항상 양수일 때, $a$의 부호와 판별식 $D$의 부호를 각각 결정할 수 있는가?
- $f(x) = x^2 + 2x + 1$처럼 $D=0$인 경우가 왜 모든 실수에서 양수라는 조건을 만족하지 못하는지 그래프를 통해 설명할 수 있는가?

## 관련 개념
- **이차방정식**: 이차함수의 $y$값이 $0$이 되는 지점은 이차방정식의 실근과 관련이 있으며, $D < 0$이면 이차방정식은 실근을 갖지 않습니다.
