# 이차함수 그래프

> **정리** · 중3 · 단원: [이차함수](/concepts/이차함수)
## 요약
$a$의 부호로 볼록 방향 결정

## 본문

### 진술 및 가정

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)의 그래프는 포물선이며, 그 모양과 위치는 다음과 같이 결정된다.

- **$a > 0$일 때**: 포물선은 아래로 볼록(∪ 모양)
- **$a < 0$일 때**: 포물선은 위로 볼록(∩ 모양)

꼭짓점의 좌표는 $\displaystyle \left( -\frac{b}{2a}, -\frac{b^2 - 4ac}{4a} \right)$이고, 대칭축은 직선 $\displaystyle x = -\frac{b}{2a}$이다.

### 간단한 유도

가장 간단한 경우 $y = ax^2$를 생각해보자. 이를 완전제곱식으로 변형하면:
$$y = a\left(x^2\right)$$

$a > 0$이면 $x$의 제곱은 항상 음이 아니므로 $y \geq 0$이다. 따라서 원점이 최솟값이고, 그래프는 아래로 볼록한 모양이다. 반대로 $a < 0$이면 $y \leq 0$이 되어 위로 볼록하다.

일반형 $y = ax^2 + bx + c$는 완전제곱식으로:
$$y = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$$

이 식에서도 $a$의 부호가 포물선의 볼록 방향을 결정하며, 꼭짓점은 $\displaystyle \left(-\frac{b}{2a}, c - \frac{b^2}{4a}\right)$이다.

**예**: $y = 2x^2 - 4x + 1$의 꼭짓점은 $\displaystyle x = -\frac{-4}{2(2)} = 1$에서 $y = 2(1)^2 - 4(1) + 1 = -1$이므로 $(1, -1)$이다.

### 의의 및 응용

이차함수 문제에서 $a$의 부호는 최댓값/최솟값 판정의 핵심이다. $a > 0$이면 최솟값이 존재하고(경제학의 최소 비용 문제), $a < 0$이면 최댓값이 존재한다(최대 이익, 최대 높이). 꼭짓점과 대칭축은 그래프 개형을 빠르게 파악하고 방정식 문제를 풀 때 필수 정보이다.
