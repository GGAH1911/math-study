### 정확한 진술

함수 $f(x)$의 **x축 교점**은 함수의 그래프가 x축과 만나는 점을 말합니다. 이는 $f(x) = 0$을 만족하는 $x$ 값에서 나타나며, 점의 좌표로는 $(x, 0)$입니다. 이때 조건을 만족하는 $x$ 값을 함수의 **근** 또는 **영점**(zero)이라고 부릅니다.

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 x축 교점을 찾는 것은 이차방정식 $ax^2 + bx + c = 0$을 푸는 것과 정확히 같습니다.

### 직관/기하적 의미

그래프 위에서 y좌표가 정확히 0이 되는 위치, 즉 수평선인 x축 위에 있는 점이 x축 교점입니다.

이차함수는 포물선이므로 x축과의 교점 개수는 판별식에 따라 결정됩니다:
- $D = b^2 - 4ac > 0$: 서로 다른 두 개의 x축 교점
- $D = 0$: 한 개의 x축 교점(포물선이 x축에 접함, **중근**)
- $D < 0$: x축 교점이 없음(실근이 없음)

함수값의 부호가 음에서 양으로(또는 그 반대로) 바뀌는 지점이 x축 교점입니다. 따라서 x축 교점은 "함수의 부호 변화 지점"으로도 이해할 수 있습니다.

### 한 줄 예

$f(x) = x^2 - 5x + 6 = (x-2)(x-3)$의 x축 교점은 $x=2$와 $x=3$이고, 점으로 표현하면 $(2, 0)$과 $(3, 0)$입니다. (`sympy.solve(x**2 - 5*x + 6, x)` → [2, 3])
