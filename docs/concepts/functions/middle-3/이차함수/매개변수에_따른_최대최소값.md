### 정확한 진술

매개변수 $a$를 포함하는 함수 $f(x, a)$의 최댓값과 최솟값이 $a$의 값에 따라 변하는 현상을 다룹니다. 정의역이 고정되어 있을 때, 매개변수의 변화에 따라 최댓값·최솟값을 달성하는 $x$의 위치와 함숫값이 어떻게 결정되는지를 분석합니다. 이는 **매개변수 $a$를 변수로 보고, 최댓값과 최솟값을 $a$의 함수로 표현**하는 것을 의미합니다.

### 직관·기하적 의미

이차함수의 축이 매개변수에 따라 움직일 때, 정의역 $[p, q]$ 위에서 최댓값과 최솟값이 달성되는 위치가 바뀝니다. 예를 들어 $f(x) = (x - a)^2$에서 축이 $x = a$이므로, $a$의 위치에 따라:
- $a < p$이면 최솟값은 $x = p$에서 달성  
- $p \le a \le q$이면 최솟값은 $x = a$에서 달성  
- $a > q$이면 최솟값은 $x = q$에서 달성  

이처럼 **구간과 축의 상대적 위치에 따라 경우를 나누어** 분석합니다.

### 한 줄 예

$f(x) = (x - a)^2$이 $0 \le x \le 1$에서 가지는 최솟값은 $a$의 값에 따라 다음과 같습니다:

$$\min f(x) = \begin{cases} a^2 & (a < 0) \\ 0 & (0 \le a \le 1) \\ (a-1)^2 & (a > 1) \end{cases}$$

예를 들어 $a = -1$일 때 최솟값은 $1$, $a = 0.5$일 때는 $0$입니다. (검증: `{0: (-1)**2, 0.5: 0, 2: (2-1)**2}` 출력은 `{0: 1, 0.5: 0, 2: 1}`입니다.)
