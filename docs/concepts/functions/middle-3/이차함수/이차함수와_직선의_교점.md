# 이차함수와 직선의 교점

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 정확한 진술

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)와 직선 $y = mx + n$의 교점의 $x$좌표는 두 함수를 같다고 놓은 방정식
$$ax^2 + bx + c = mx + n$$
을 풀어서 구합니다. 이를 정리하면
$$ax^2 + (b-m)x + (c-n) = 0$$
이라는 이차방정식이 되고, 이 방정식의 해가 교점의 $x$좌표입니다.

## 직관/기하적 의미

포물선과 직선이 만나는 지점을 찾는 것입니다. 이차방정식의 판별식 $D = (b-m)^2 - 4a(c-n)$의 부호에 따라 교점의 개수가 결정됩니다:

- $D > 0$일 때: 두 점에서 만남 (서로 다른 두 실근)
- $D = 0$일 때: 한 점에서 접함 (중근)
- $D < 0$일 때: 만나지 않음 (실근이 없음)

기하학적으로는 포물선의 위치와 직선의 기울기에 따라 만나는 형태가 달라집니다. 같은 직선이 다른 포물선과 만나면 교점의 개수도 달라집니다.

## 한 줄 예

이차함수 $y = x^2 - 2x + 1$과 직선 $y = 2x - 1$의 교점을 구하면, $x^2 - 2x + 1 = 2x - 1$에서 $x^2 - 4x + 2 = 0$이 되고, 판별식은 $D = 16 - 8 = 8 > 0$이므로 두 점에서 만나며 교점의 $x$좌표는 $x = 2 \pm \sqrt{2}$입니다.

```python
# 검산: sympy.solve(x**2 - 4*x + 2, x)
# [2 - sqrt(2), 2 + sqrt(2)]
```
