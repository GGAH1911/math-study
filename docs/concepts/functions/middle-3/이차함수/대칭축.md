# 대칭축

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수 그래프의 좌우 대칭을 이루는 기준이 되는 수직선입니다.

## 본문
이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)의 그래프인 포물선을 따라 대칭을 이루는 수직선을 **대칭축**이라고 합니다. 대칭축의 방정식은 $x = -\tfrac{b}{2a}$이며, 이는 포물선의 꼭짓점의 $x$좌표와 일치합니다. 즉, 꼭짓점을 $(p, q)$라 할 때 대칭축은 $x = p$로 나타낼 수 있습니다.

### 직관과 기하적 의미
포물선을 대칭축을 중심으로 접으면 두 부분이 완전히 겹쳐지며, 이는 대칭축이 포물선의 기하학적 중앙 역할을 함을 의미합니다. 대칭축 위의 점에서 같은 거리에 있는 포물선 위의 두 점은 항상 같은 $y$값을 가집니다. 예를 들어, 대칭축이 $x = 2$라면 $x = 1$과 $x = 3$에서의 함수값은 서로 같습니다. 이러한 대칭성은 함수의 개형을 파악하고 그래프를 그릴 때 매우 중요한 기준이 됩니다.

### 기본 성질
이차함수의 최댓값 또는 최솟값은 항상 대칭축 위에서 나타납니다. 따라서 대칭축의 위치를 알면 함수의 극점 위치를 즉각적으로 파악할 수 있으며, 이는 이차함수의 전체적인 형태를 결정짓는 핵심 요소가 됩니다.

## 학습 체크
- 이차함수의 일반형 $y = ax^2 + bx + c$에서 대칭축의 방정식을 구하는 공식은 무엇인가요?
- 대칭축의 $x$좌표와 이차함수의 꼭짓점의 $x$좌표 사이에는 어떤 관계가 있나요?
- 대칭축을 기준으로 좌우로 같은 거리만큼 떨어진 두 점의 $y$값은 서로 같은가요?

## 관련 개념
- **이차함수**: 이차함수의 그래프인 포물선은 대칭축을 중심으로 좌우가 완벽하게 대칭을 이루는 구조를 가집니다.
