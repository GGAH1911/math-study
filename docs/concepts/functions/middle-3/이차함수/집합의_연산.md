# 집합의 연산

## 정확한 진술

두 집합 $A$, $B$가 주어졌을 때, 다음과 같이 연산합니다.

**합집합** $A \cup B$: $A$ 또는 $B$에 속하는 모든 원소의 집합
$$A \cup B = \{x \mid x \in A \text{ 또는 } x \in B\}$$

**교집합** $A \cap B$: $A$와 $B$ 모두에 속하는 원소의 집합
$$A \cap B = \{x \mid x \in A \text{ 그리고 } x \in B\}$$

**여집합** $A^c$: 전체집합 $U$에 속하지만 $A$에는 속하지 않는 원소의 집합
$$A^c = \{x \mid x \in U, x \notin A\}$$

**차집합** $A - B$: $A$에는 속하지만 $B$에는 속하지 않는 원소의 집합
$$A - B = \{x \mid x \in A, x \notin B\}$$

## 직관/기하적 의미

벤다이어그램으로 시각화하면 직관적입니다. 합집합은 두 원판이 겹치는 전체 영역, 교집합은 겹치는 부분입니다. 여집합은 $A$ 바깥의 모든 영역, 차집합은 $A$에만 있는 부분입니다.

실생활로는: 반 학생을 $A$(수학 선택), $B$(과학 선택)라 하면, $A \cup B$는 둘 중 하나라도 선택한 학생, $A \cap B$는 둘 다 선택한 학생입니다.

## 한 줄 예

$A = \{1, 2, 3\}$, $B = \{2, 3, 4\}$일 때, $A \cup B = \{1, 2, 3, 4\}$, $A \cap B = \{2, 3\}$, $A - B = \{1\}$입니다.
