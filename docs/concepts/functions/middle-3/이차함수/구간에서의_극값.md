# 구간에서의 극값

이차함수의 정의역을 어떤 구간으로 제한했을 때 그 구간에서 함수가 갖는 최댓값과 최솟값을 의미합니다. 중3 이차함수 단원의 활용 핵심입니다.

## 정의

이차함수 $f(x) = a(x - p)^2 + q$의 꼭짓점은 $(p, q)$, 축은 $x = p$입니다. 정의역을 닫힌 구간 $[\alpha, \beta]$로 제한할 때 최댓값·최솟값은 다음 점들의 함숫값을 비교해 정해집니다.
- 구간 내부에 축이 포함되어 있으면 꼭짓점 $x = p$.
- 구간의 양 끝 $x = \alpha,\ x = \beta$.

$a > 0$이면 꼭짓점은 최솟값, $a < 0$이면 꼭짓점은 최댓값을 줍니다. 축이 구간 밖에 있을 때는 구간 양 끝의 값만 비교합니다.

## 예시

$f(x) = x^2 - 4x + 5$의 구간 $[0, 3]$에서의 최댓값과 최솟값을 구해 봅니다. 표준형으로 정리하면 $f(x) = (x-2)^2 + 1$이며 꼭짓점은 $(2, 1)$. 구간 $[0, 3]$에는 축 $x = 2$가 포함됩니다.

끝점 값: $f(0) = 5$, $f(3) = 2$. 꼭짓점 값: $f(2) = 1$. 따라서 최댓값은 $f(0) = 5$, 최솟값은 $f(2) = 1$입니다.
