# 일반형 표준형 변환

> **예제** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수의 일반형을 완전제곱식을 이용하여 표준형으로 변환함으로써 꼭짓점의 좌표를 찾는 과정입니다.

## 본문
다음 이차함수를 표준형으로 나타내고, 꼭짓점의 좌표를 구하세요.
$$y = x^2 - 4x + 3$$

### 단계별 풀이
**1단계: $x$에 대한 항만 묶기**
상수항을 따로 분리하여 식을 정리합니다.
$$y = (x^2 - 4x) + 3$$

**2단계: $x^2 - 4x$를 완전제곱식으로 변형하기**
$x$의 계수인 $-4$의 절반인 $-2$를 제곱한 값인 $4$를 더하고 빼서 완전제곱식을 만듭니다.
$$x^2 - 4x = (x-2)^2 - 4$$

**3단계: 원래 식에 대입**
변형된 식을 원래의 식에 대입하여 최종 형태를 도출합니다.
$$y = (x-2)^2 - 4 + 3 = (x-2)^2 - 1$$

### 답과 변형
**정답**
표준형: $y = (x-2)^2 - 1$
꼭짓점의 좌표: $(2, -1)$

**이차항 계수가 1이 아닌 경우의 주의점**
이차항의 계수가 $a$인 경우, $a$로 먼저 묶어낸 뒤 괄호 안에서 완전제곱식을 만들어야 합니다.
예시: $y = 2x^2 + 8x + 5$
1. $y = 2(x^2 + 4x) + 5$
2. $y = 2[(x+2)^2 - 4] + 5$
3. $y = 2(x+2)^2 - 8 + 5 = 2(x+2)^2 - 3$
이때 꼭짓점은 $(-2, -3)$이 됩니다. 괄호 안에서 더해준 값을 밖으로 뺄 때는 반드시 앞의 계수를 곱해야 함을 주의해야 합니다.

## 학습 체크
- 이차항의 계수가 1이 아닐 때 괄호 밖으로 상수를 뺄 때 계수를 곱했는가?
- 표준형 $y = a(x-p)^2 + q$에서 꼭짓점의 좌표 $(p, q)$를 정확히 읽어냈는가?

## 관련 개념
- **이차함수**: 일반형 $y = ax^2 + bx + c$를 표준형으로 변환하면 함수의 그래프 모양과 꼭짓점의 위치를 쉽게 파악할 수 있습니다.
