# 이차함수 최댓값 최솟값

> **정리** · 중3 · 단원: [이차함수](/concepts/이차함수)
## 요약
꼭짓점에서 발생

## 본문

### 진술 및 가정

이차함수 $y = a(x-p)^2 + q$ (단, $a \neq 0$)에서:
- $a > 0$이면 $x = p$에서 **최솟값** $q$를 가짐
- $a < 0$이면 $x = p$에서 **최댓값** $q$를 가짐

여기서 점 $(p, q)$는 포물선의 꼭짓점입니다.

### 유도 및 증명 스케치

꼭짓점 형태 $y = a(x-p)^2 + q$에서 핵심은 $(x-p)^2$ 항의 성질입니다.

모든 실수 $x$에 대해 $(x-p)^2 \geq 0$이므로:
- $a > 0$일 때: $a(x-p)^2 \geq 0$ → $y = a(x-p)^2 + q \geq q$
  - 등호는 $x-p = 0$, 즉 $x = p$일 때 성립 (최솟값)
- $a < 0$일 때: $a(x-p)^2 \leq 0$ → $y = a(x-p)^2 + q \leq q$
  - 등호는 $x = p$일 때 성립 (최댓값)

일반형 $y = ax^2 + bx + c$인 경우, 완전제곱식으로 변형하면:
$$y = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$$

따라서 꼭짓점은 $\left(-\frac{b}{2a}, c - \frac{b^2}{4a}\right)$이고, 최댓값/최솟값은 이 점에서 발생합니다.

### 의의 및 응용

**최적화 문제**: 실생활에서 이차함수로 표현되는 상황(비용 최소화, 넓이 최대화 등)의 답을 꼭짓점에서 즉시 찾을 수 있습니다.

**정의역 제한 시 주의**: 정의역이 $p$를 포함하지 않거나, 정의역이 폐구간 $[m, n]$으로 제한되면, 최댓값/최솟값은 꼭짓점이 아닌 **정의역의 끝점**에서 발생할 수 있습니다.

**검증 예**: $y = (x-2)^2 + 3$에서 최솟값은 $x=2$일 때 $3$
```python
# sympy: var('x'); y = (x-2)**2 + 3; y.subs(x, 2)  → 3
```
