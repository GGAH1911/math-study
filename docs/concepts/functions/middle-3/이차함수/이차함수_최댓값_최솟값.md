# 이차함수 최댓값 최솟값

> **정리** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수의 최댓값과 최솟값은 포물선의 꼭짓점에서 발생합니다.

## 본문
이차함수 $y = a(x-p)^2 + q$ (단, $a \neq 0$)에서 계수 $a$의 부호에 따라 최댓값과 최솟값이 결정됩니다. $a > 0$이면 $x = p$에서 최솟값 $q$를 가지며, $a < 0$이면 $x = p$에서 최댓값 $q$를 가집니다. 이때 점 $(p, q)$는 포물선의 꼭짓점입니다. 일반형인 $y = ax^2 + bx + c$를 완전제곱식으로 변형하면 $y = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$가 되므로, 꼭짓점의 좌표는 $\left(-\frac{b}{2a}, c - \frac{b^2}{4a}\right)$가 됩니다.

### 증명 스케치
모든 실수 $x$에 대하여 $(x-p)^2$은 항상 $0$보다 크거나 같습니다. 따라서 $a > 0$인 경우 $a(x-p)^2$은 $0$ 이상이므로 $y$의 값은 $q$보다 크거나 같으며, $x=p$일 때 $y=q$로 최소가 됩니다. 반대로 $a < 0$인 경우 $a(x-p)^2$은 $0$ 이하이므로 $y$의 값은 $q$보다 작거나 같으며, $x=p$일 때 $y=q$로 최대가 됩니다.

### 의의와 응용
이 개념은 실생활의 최적화 문제, 즉 비용의 최소화나 넓이의 최대화 문제를 해결할 때 핵심적인 도구가 됩니다. 다만, 정의역이 제한된 경우에는 주의가 필요합니다. 정의역이 꼭짓점의 $x$좌표를 포함하지 않거나 폐구간으로 주어질 경우, 최댓값이나 최솟값은 꼭짓점이 아닌 구간의 끝점에서 발생할 수 있습니다.

## 학습 체크
- 이차함수의 계수 $a$의 부호에 따라 그래프가 위로 볼록인지 아래로 볼록인지 구분할 수 있는가?
- 주어진 이차함수 식을 완전제곱식으로 변형하여 꼭짓점의 좌표를 정확히 구할 수 있는가?
- 정의역이 제한된 조건에서 최댓값과 최솟값이 꼭짓점이 아닌 구간의 끝점에서 나타날 수 있음을 이해하는가?
