# 표준형 꼭짓점

## 정확한 진술

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)를 다음과 같이 변형한 형태를 **표준형(꼭짓점 형태)**이라고 합니다:

$$y = a(x - p)^2 + q$$

이 식에서 $(p, q)$가 이차함수의 꼭짓점 좌표입니다. 이 형태로 변환하려면 완전제곱식을 이용하여 일반형을 정리하면 됩니다.

예를 들어 $y = 2x^2 - 8x + 5$를 표준형으로 변환하면:
$$y = 2(x^2 - 4x) + 5 = 2(x^2 - 4x + 4) - 8 + 5 = 2(x - 2)^2 - 3$$

## 직관/기하적 의미

표준형의 가장 중요한 특징은 **꼭짓점과 대칭축을 바로 읽을 수 있다**는 것입니다.

$$y = a(x - p)^2 + q$$ 형태에서:
- 꼭짓점: $(p, q)$
- 대칭축: $x = p$  
- 최댓값 또는 최솟값: $q$ (단, $a > 0$이면 최솟값, $a < 0$이면 최댓값)

$a$의 절댓값이 크면 포물선이 더 좁아지고, 작으면 더 넓어집니다. 표준형은 최값 구하기, 함수의 증감 구간 결정, 실생활 최적화 문제 해결에 매우 유용합니다.

## 한 줄 예

$y = 2x^2 - 8x + 5$의 표준형은 $y = 2(x - 2)^2 - 3$이므로, 꼭짓점은 $(2, -3)$이고 최솟값은 $-3$입니다. (검증: `sympy.expand(2*(x-2)**2 - 3)` → $2x^2 - 8x + 5$)
