# 최솟값

## 정확한 진술

함수 $f(x)$의 **최솟값**은 정의역에 속하는 모든 $x$에 대해 $f(a) \le f(x)$를 만족하는 값 $f(a)$를 의미합니다. 즉, 함수가 취할 수 있는 모든 함숯값 중에서 가장 작은 값입니다. 이때 $f(a)$를 최솟값이라 하고, 최솟값을 갖게 하는 $x$의 값 $a$를 **최솟값을 주는 점** 또는 **최솟값을 취하는 점**이라 합니다.

## 직관/기하적 의미

좌표평면에서 함수 $y = f(x)$의 그래프를 그렸을 때, 최솟값은 그래프 위의 점들 중에서 가장 낮은 지점의 $y$좌표입니다. 예를 들어 아래로 볼록한 포물선은 꼭짓점에서 최솟값을 가지며, 그 점에서의 $y$좌표가 최솟값이 됩니다. 만약 함수의 정의역이 제한되어 있다면, 그 범위 내에서 가장 작은 함숫값을 찾아야 합니다.

## 한 줄 예

함수 $f(x) = (x - 2)^2 + 3$의 경우 $x = 2$에서 최솟값 $3$을 갖습니다.
