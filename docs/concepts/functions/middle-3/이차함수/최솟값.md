# 최솟값

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
함수 $f(x)$가 취할 수 있는 함숫값 중 가장 작은 값을 의미하며, 그래프 상에서는 가장 낮은 지점의 $y$좌표에 해당합니다.

## 본문
함수 $f(x)$의 **최솟값**은 정의역에 속하는 모든 $x$에 대하여 $f(a) \le f(x)$를 만족하는 값 $f(a)$를 의미합니다. 즉, 함수가 가질 수 있는 모든 함숫값 중에서 가장 작은 값을 말합니다. 이때 최솟값을 갖게 하는 $x$의 값 $a$를 **최솟값을 주는 점** 또는 **최솟값을 취하는 점**이라고 부릅니다.

### 직관과 기하적 의미
좌표평면에서 함수 $y = f(x)$의 그래프를 그렸을 때, 최솟값은 그래프 위의 점들 중에서 가장 낮은 지점의 $y$좌표를 의미합니다. 예를 들어 아래로 볼록한 포물선 형태의 이차함수는 꼭짓점에서 최솟값을 가지며, 그 꼭짓점의 $y$좌표가 곧 최솟값이 됩니다. 만약 함수의 정의역이 특정 범위로 제한되어 있다면, 그 범위 내에서 가장 낮은 위치에 있는 함숫값을 찾아야 합니다.

### 기본 성질
함수 $f(x) = (x - 2)^2 + 3$의 경우, $x = 2$일 때 함숫값이 $3$이 되므로 $x = 2$에서 최솟값 $3$을 갖습니다. 이는 미분을 통해 $f'(x) = 0$인 지점을 찾는 방식과도 연결됩니다.

## 학습 체크
- 최솟값을 갖게 하는 $x$의 값과 실제 최솟값인 $y$의 값을 구분할 수 있는가?
- 함수의 정의역이 제한되어 있을 때, 그래프의 양 끝값과 꼭짓점의 높이를 비교하여 최솟값을 찾을 수 있는가?

## 관련 개념
- **일차부등식**: 함수의 함숫값이 특정 값보다 크거나 작다는 조건은 일차부등식의 형태로 나타나며, 이는 최솟값의 범위를 결정하는 조건이 될 수 있습니다.
