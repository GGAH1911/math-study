# 이차함수 x축 교점

> **정리** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차함수 $y=ax^2+bx+c$의 $x$축 교점의 $x$좌표는 이차방정식 $ax^2+bx+c=0$의 해와 같다.

## 본문
이차함수 $y = ax^2 + bx + c$ ($a \neq 0$)의 $x$축과의 교점의 $x$좌표는 이차방정식 $ax^2 + bx + c = 0$의 해이다. 반대로 이 방정식의 해가 존재하면 그것이 바로 교점의 $x$좌표가 된다. 이차함수가 $x$축과 만난다는 것은 함수값이 $0$이 되는 $x$값이 존재한다는 의미이므로, $y=0$을 대입하여 얻은 방정식의 해를 구함으로써 교점의 위치를 찾을 수 있다.

예를 들어 $y = x^2 - 5x + 6$이 $x$축과 만나는 점을 찾기 위해 $x^2 - 5x + 6 = 0$을 풀면, $(x-2)(x-3)=0$이 되어 $x=2$ 또는 $x=3$을 얻는다. 따라서 교점은 $(2, 0)$과 $(3, 0)$이 된다.

이때 교점의 개수는 이차방정식의 판별식 $D = b^2 - 4ac$에 의해 결정된다. $D > 0$이면 서로 다른 두 실근을 가져 $x$축과 두 점에서 만나고, $D = 0$이면 중근을 가져 $x$축에 접하며 한 점에서 만나고, $D < 0$이면 실근이 없어 $x$축과 만나지 않는다.

### 증명 스케치
$x$축 위의 모든 점은 $y$좌표가 $0$이다. 따라서 함수 $y=f(x)$가 $x$축과 만나는 점의 $x$좌표를 구하기 위해서는 $f(x)=0$을 만족하는 $x$값을 찾는 것과 같으며, 이는 곧 이차방정식의 해를 구하는 과정과 일치한다.

### 의의와 응용
이 개념은 이차방정식의 근의 공식과 인수분해를 통해 교점을 직접 계산하는 기초가 된다. 또한 이차함수의 그래프를 그릴 때 $x$절편 정보를 제공하여 포물선의 개형을 완성하며, 함수의 최댓값과 최솟값을 구하는 과정에서도 중요한 단서가 된다. 이는 향후 고등학교 과정의 부등식과 방정식의 해의 개수 문제로 확장된다.

## 학습 체크
- 이차방정식의 판별식 결과에 따라 그래프가 $x$축과 만나는 형태가 어떻게 변하는지 설명할 수 있는가?
- 주어진 이차함수 식을 보고 $x$축과의 교점의 좌표를 직접 구할 수 있는가?

## 관련 개념
- **이차함수**: $x$축과의 교점은 함수의 그래프가 $x$축과 만나는 지점인 $x$절편을 의미한다.
- **이차방정식**: 이차함수의 $y$값이 $0$이 되는 지점을 찾는 과정이 곧 이차방정식의 해를 구하는 과정이다.
- **판별식**: 이차방정식의 해의 종류를 통해 이차함수 그래프와 $x$축의 위치 관계를 판단할 수 있다.
