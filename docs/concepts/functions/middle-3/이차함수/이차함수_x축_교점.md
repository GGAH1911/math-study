# 이차함수 x축 교점

> **정리** · 중3 · 단원: [이차함수](/concepts/이차함수)
## 요약
이차방정식 $y=0$의 해

## 본문

### 진술과 가정

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)의 x축과의 교점의 x좌표는 이차방정식 $ax^2 + bx + c = 0$의 해이다. 반대로 이 방정식의 해가 존재하면 그것이 바로 교점의 x좌표이다.

### 핵심 아이디어

이차함수가 x축과 만난다는 것은 함수값이 0이 되는 x값이 존재한다는 뜻입니다. 즉:
$$y = 0 \Leftrightarrow ax^2 + bx + c = 0$$

이 방정식을 풀면 교점의 x좌표를 구할 수 있습니다. 

**예를 들어** $y = x^2 - 5x + 6$이 x축과 만나는 점을 찾으려면:
$$x^2 - 5x + 6 = 0$$
$$(x-2)(x-3) = 0$$
$$x = 2 \text{ 또는 } x = 3$$

따라서 교점은 $(2, 0)$과 $(3, 0)$입니다. (검산: `sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)

### 교점의 개수와 판별식

이차방정식의 해가 몇 개이냐에 따라 교점의 개수가 결정됩니다:

- **서로 다른 두 실근**: 포물선이 x축과 두 점에서 만남
- **중근(중복도 2)**: 포물선이 x축에 접함 (한 점에서 만남)  
- **실근이 없음**: 포물선이 x축과 만나지 않음

판별식 $D = b^2 - 4ac$를 이용하면 이를 미리 판단할 수 있습니다. $D > 0$이면 두 교점, $D = 0$이면 한 교점(접점), $D < 0$이면 교점 없음입니다.

### 의의와 활용

이 정리는 다음 학습으로 자연스럽게 연결됩니다:

- **근의 공식**: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$로 교점의 x좌표를 직접 계산
- **인수분해**: 정수해를 가질 때 빠르게 교점 찾기
- **이차함수의 그래프 그리기**: 꼭짓점과 x절편을 알면 포물선의 개형 파악 완성
- **최댓값·최솟값**: 주어진 범위에서 함숫값의 극값을 구할 때 교점 정보 활용

이 개념은 고등학교에서 부등식, 방정식의 해의 개수 문제 등으로 확장됩니다.
