# 근과 계수

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 두 근을 $\alpha, \beta$라 할 때, 다음 관계가 성립합니다:

$$\alpha + \beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}$$

이를 **근과 계수의 관계** 또는 **비에타 공식(Vieta's formula)**이라 합니다. 두 근의 합은 일차항 계수를 최고차 계수로 나누고 부호를 바꾼 값이고, 두 근의 곱은 상수항을 최고차 계수로 나눈 값입니다.

## 직관 및 유도

이차방정식의 근의 공식에서 $\alpha = \frac{-b + \sqrt{b^2 - 4ac}}{2a}$, $\beta = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$이므로:

$$\alpha + \beta = \frac{-b + \sqrt{b^2 - 4ac}}{2a} + \frac{-b - \sqrt{b^2 - 4ac}}{2a} = \frac{-2b}{2a} = -\frac{b}{a}$$

$$\alpha\beta = \frac{(-b)^2 - (b^2 - 4ac)}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}$$

다르게 보면, $\alpha, \beta$가 이차방정식의 근이므로, 인수분해 형태로:
$$a(x - \alpha)(x - \beta) = a[x^2 - (\alpha + \beta)x + \alpha\beta] = ax^2 + bx + c$$

계수를 비교하면 위 관계식이 자동으로 도출됩니다.

## 한 줄 예

방정식 $x^2 - 5x + 6 = 0$의 근은 $x = 2, 3$이고, 근의 합 $2 + 3 = 5 = -\frac{-5}{1}$ ✓, 근의 곱 $2 \times 3 = 6 = \frac{6}{1}$ ✓

(`sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)

## 의의

근의 공식을 사용하지 않고도 두 근의 합과 곱을 빠르게 구할 수 있으며, 주어진 두 근으로부터 이차방정식을 역으로 구성하거나, 근의 성질(예: 근의 부호 판정, 근의 범위)을 판단하는 데 필수적입니다.
