### 정확한 진술

함수 $f(x)$의 **근(root)**은 방정식 $f(x) = 0$을 만족하는 $x$의 값입니다. **절편(intercept)**은 그래프가 좌표축과 만나는 점의 좌표입니다. 특히 이차함수에서 자주 다루는 것은:
- **x절편(x-intercept)**: 함수의 근과 같으며, $y = 0$일 때의 $x$ 값
- **y절편(y-intercept)**: 그래프가 y축과 만나는 점으로, $x = 0$일 때의 함수값 $f(0)$

### 직관과 기하적 의미

이차함수 $f(x) = ax^2 + bx + c$의 그래프는 포물선입니다. **근**은 이 포물선이 x축과 만나는 점의 x좌표이며, 이차방정식을 풀어서 구합니다. **y절편**은 항상 단 하나이며, $x = 0$을 대입하면 곧바로 $f(0) = c$로 구할 수 있습니다.

포물선이 x축과 만나는 횟수는 판별식 $D = b^2 - 4ac$로 판단합니다:
- $D > 0$: 근이 2개 (x축과 두 점에서 만남)
- $D = 0$: 근이 1개 (중근, x축과 한 점에서 접함)
- $D < 0$: 실근이 없음 (x축과 만나지 않음)

### 한 줄 예

이차함수 $f(x) = x^2 - 5x + 6$에서 근은 $x = 2, 3$이고 ($(x-2)(x-3) = 0$으로 확인), y절편은 $f(0) = 6$입니다.

`sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$
