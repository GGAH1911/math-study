# 꼭짓점 축

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)
## 요약
포물선의 꼭짓점과 대칭축

## 본문

### 정확한 진술

이차함수 $y = a(x - p)^2 + q$ (단, $a \neq 0$)의 **꼭짓점**은 점 $(p, q)$이고, **대칭축**은 직선 $x = p$입니다. 일반형 $y = ax^2 + bx + c$에서는 대칭축이 $x = -\frac{b}{2a}$이며, 이 값을 함수에 대입하면 꼭짓점의 $y$좌표를 구할 수 있습니다.

### 직관과 기하적 의미

포물선은 대칭축을 중심으로 좌우 모양이 완벽하게 같습니다. 꼭짓점은 이 포물선의 가장 높은 점(최댓값, $a < 0$일 때) 또는 가장 낮은 점(최솟값, $a > 0$일 때)이므로, 함수의 극값을 찾는 데 핵심 역할을 합니다. 대칭축의 양쪽으로 같은 거리에 있는 두 점은 항상 같은 $y$값을 가지며, 대칭축 위의 모든 점에서 함수는 최대 또는 최소입니다.

### 표준형으로 변환하기

일반형을 표준형으로 정리하면 꼭짓점과 대칭축을 쉽게 구할 수 있습니다. 예를 들어 $y = 2x^2 - 8x + 5$를 완전제곱식으로 정리하면:

$$y = 2(x^2 - 4x) + 5 = 2(x^2 - 4x + 4) - 8 + 5 = 2(x - 2)^2 - 3$$

따라서 꼭짓점은 $(2, -3)$, 대칭축은 $x = 2$입니다. `sympy.solve(sympy.diff(2*x**2 - 8*x + 5, x), x)` → $x = 2$
