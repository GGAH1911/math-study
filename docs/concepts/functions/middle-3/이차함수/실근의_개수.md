# 실근의 개수

## 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 **실근의 개수**는 판별식 $D = b^2 - 4ac$의 부호로 결정됩니다.

- **$D > 0$일 때**: 서로 다른 두 실근
- **$D = 0$일 때**: 중근 (같은 두 실근)
- **$D < 0$일 때**: 실근 없음

## 직관과 기하적 의미

이차함수 $y = ax^2 + bx + c$의 그래프는 포물선이고, 이 포물선이 $x$축과 만나는 점의 개수가 곧 방정식의 실근 개수입니다.

- 포물선이 $x$축과 **두 점**에서 만나면 $D > 0$ (실근 2개)
- 포물선이 $x$축과 **한 점**에서 접하면 $D = 0$ (실근 1개)
- 포물선이 $x$축과 **만나지 않으면** $D < 0$ (실근 0개)

$a > 0$이면 아래로 볼록한 모양, $a < 0$이면 위로 볼록한 모양입니다. 판별식은 이 기하적 상황을 대수적으로 판단하는 수단입니다.

## 한 줄 예

$x^2 - 5x + 6 = 0$에서 $D = 25 - 24 = 1 > 0$이므로 서로 다른 두 실근 $x = 2, 3$을 가집니다.

(`sympy.solve(x**2 - 5*x + 6, x)` → `[2, 3]`)
