# 실근의 개수

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 요약
이차방정식의 실근의 개수는 판별식 $D = b^2 - 4ac$의 부호에 따라 결정되며, 이는 이차함수 그래프와 $x$축의 교점 개수와 일치합니다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 실근의 개수는 판별식 $D = b^2 - 4ac$의 부호에 의해 결정됩니다. 판별식의 값이 $0$보다 크면($D > 0$) 서로 다른 두 실근을 가지며, $0$과 같으면($D = 0$) 중근(같은 두 실근)을 가집니다. 만약 판별식의 값이 $0$보다 작으면($D < 0$) 실근을 갖지 않습니다.

### 직관과 기하적 의미
이차방정식의 실근은 이차함수 $y = ax^2 + bx + c$의 그래프인 포물선이 $x$축과 만나는 점의 $x$좌표와 같습니다. 따라서 포물선이 $x$축과 두 점에서 만나면 실근은 2개($D > 0$), $x$축에 접하며 한 점에서 만나면 실근은 1개($D = 0$), $x$축과 만나지 않고 떠 있거나 아래에 있으면 실근은 0개($D < 0$)가 됩니다. 이때 $a$의 부호에 따라 그래프는 아래로 볼록하거나 위로 볼록한 모양을 띠게 됩니다.

### 기본 성질
- $D > 0$: 서로 다른 두 실근을 가짐
- $D = 0$: 중근을 가짐
- $D < 0$: 실근이 없음
- 예시: $x^2 - 5x + 6 = 0$에서 $D = (-5)^2 - 4(1)(6) = 1 > 0$이므로 서로 다른 두 실근 $x = 2, 3$을 가집니다.

## 학습 체크
- 판별식의 부호가 결정되었을 때, 이를 그래프의 위치 관계와 어떻게 연결하여 설명할 수 있는가?
- 중근이 발생하는 경우, 그래프의 모양과 $x$축과의 관계는 어떠한가?

## 관련 개념
- **이차함수**: 이차방정식의 실근은 이차함수 그래프가 $x$축과 만나는 지점의 $x$좌표와 동일한 의미를 가집니다.
