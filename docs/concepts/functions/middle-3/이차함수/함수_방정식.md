# 함수 방정식

## 정확한 진술

함수 $f(x)$가 주어졌을 때, 등식 $f(x) = 0$을 만족하는 $x$의 값을 찾는 문제를 **함수의 방정식**이라고 합니다. 이렇게 구한 $x$값을 함수 $f(x)$의 **영점(零点)** 또는 **근(根)**이라 부릅니다.

## 직관/기하적 의미

$y = f(x)$의 그래프를 그렸을 때, 이 곡선이 $x$축과 만나는 점들의 $x$좌표가 정확히 방정식 $f(x) = 0$의 해입니다. 다시 말해, 함수의 영점을 찾는 것은 그래프와 $x$축의 교점을 찾는 것과 같습니다.

이차함수 $f(x) = a(x - p)^2 + q$ (단, $a \neq 0$)의 경우:
- $q > 0$이고 $a > 0$이면, 그래프가 $x$축 위에 있어서 교점이 없습니다 (실근 없음).
- 그래프가 $x$축과 한 점에서 만나면 중근(중복도 2인 근) 하나를 갖습니다.
- 그래프가 $x$축과 두 점에서 만나면 서로 다른 두 실근을 갖습니다.

## 단계적 예시

**문제**: 함수 $f(x) = x^2 - 5x + 6$의 방정식을 풀어봅시다.

$f(x) = 0$에서 $x^2 - 5x + 6 = 0$

인수분해하면: $(x - 2)(x - 3) = 0$

따라서 $x = 2$ 또는 $x = 3$

(검증: `sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$)

이는 포물선 $y = x^2 - 5x + 6$이 점 $(2, 0)$과 $(3, 0)$에서 $x$축과 만난다는 뜻입니다.
