# 이차함수 그래프 그리기

> **예제** · 중3 · 단원: [이차함수](/concepts/이차함수)
## 요약
$y=2x^2-4x+1$

## 본문

### 문제

$y=2x^2-4x+1$의 그래프를 그려라.

### 단계별 풀이

**1단계: 표준형으로 변환**

꼭짓점을 찾기 위해 $y=a(x-p)^2+q$ 형태로 변환합니다.

$$y=2x^2-4x+1=2(x^2-2x)+1$$

완전제곱식을 만들기 위해 괄호 안에서 $(x-1)^2=x^2-2x+1$임을 이용합니다:

$$y=2(x^2-2x+1-1)+1=2(x-1)^2-2+1=2(x-1)^2-1$$

**2단계: 꼭짓점과 대칭축 파악**

표준형 $y=2(x-1)^2-1$에서:
- 꼭짓점: $(1, -1)$
- 대칭축: $x=1$
- 최솟값: $-1$ (아래로 볼록, $a=2>0$)

**3단계: 주요 점 찾기**

$y$절편 ($x=0$): $y=2(0)^2-4(0)+1=1$ → $(0, 1)$

대칭축 $x=1$을 이용하면 $(0, 1)$의 대칭점은 $(2, 1)$입니다.

$x=-1$일 때: $y=2-4(-1)+1=7$ → $(-1, 7)$  
$x=3$일 때: $y=18-12+1=7$ → $(3, 7)$

(검증: `sympy.solve(2*x**2-4*x+1, x)` → 근은 $x=1±\frac{\sqrt{2}}{2}$)

### 답

꼭짓점 $(1, -1)$을 중심으로 대칭축 $x=1$에 대해 대칭인 **아래로 볼록한 포물선**입니다. 점 $(0, 1)$, $(2, 1)$, $(-1, 7)$, $(3, 7)$을 지나며 최솟값은 $-1$입니다.

### 변형/주의

**계수와 그래프의 관계:**  
$a=2$는 표준 포물선 $y=x^2$보다 2배 좁게 (위아래로 더 가파르게) 그려집니다. $a$의 절댓값이 크면 포물선이 좁아집니다.

**대칭의 활용:**  
한 점만 계산해도 대칭축으로 대칭인 점을 바로 얻을 수 있으므로, 계산량을 줄일 수 있습니다. 꼭짓점은 항상 그래프의 중요한 기준점이 됩니다.

**다른 형태 인식:**  
$y=ax^2+bx+c$ 형태에서 꼭짓점은 $x=-\frac{b}{2a}$로도 구할 수 있습니다. 여기서 $x=-\frac{-4}{2(2)}=1$ ✓
