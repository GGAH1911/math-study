# 이차함수의 치역

> **정의** · 중3 · 단원: [이차함수](/concepts/이차함수)

## 정확한 진술

이차함수 $y = ax^2 + bx + c$ (단, $a \neq 0$)의 **치역(range)**이란, 모든 실수 $x$에 대해 함수값 $y$가 가질 수 있는 모든 실수값들의 집합입니다. 정의역이 실수 전체일 때 이차함수의 치역은 **구간**으로 표현됩니다.

## 직관/기하적 의미

이차함수의 그래프는 포물선이므로, 꼭짓점이 함수의 극값을 결정합니다. **$a > 0$일 때** 포물선이 아래로 볼록하여 꼭짓점에서 최솟값을 가지고, 이 최솟값을 $m$이라 하면 치역은 $[m, \infty)$입니다. **$a < 0$일 때** 포물선이 위로 볼록하여 꼭짓점에서 최댓값을 가지고, 최댓값을 $M$이라 하면 치역은 $(-\infty, M]$입니다.

표준형 $y = a(x - p)^2 + q$에서 꼭짓점은 $(p, q)$이므로:
- $a > 0$ ⟹ 치역: $[q, \infty)$
- $a < 0$ ⟹ 치역: $(-\infty, q]$

일반형 $y = ax^2 + bx + c$의 꼭짓점 $y$좌표는 $\displaystyle q = c - \frac{b^2}{4a}$로도 구할 수 있습니다.

## 한 줄 예

$y = 2x^2 - 4x + 1$을 완전제곱식으로 정리하면 $y = 2(x-1)^2 - 1$이므로, 꼭짓점이 $(1, -1)$이고 $a = 2 > 0$이므로 치역은 $[-1, \infty)$입니다. (검증: `sympy.expand(2*(x-1)**2 - 1)` → $2x^2 - 4x + 1$)
