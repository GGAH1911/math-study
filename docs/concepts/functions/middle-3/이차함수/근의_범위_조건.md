### 정확한 진술

이차함수 $f(x) = ax^2 + bx + c$ (단, $a \neq 0$)의 방정식 $f(x) = 0$의 두 근을 $\alpha, \beta$라 하자. 두 근이 주어진 범위 $p < x < q$ 안에 모두 포함될 필요충분조건은:

$$\begin{cases}
\text{판별식 } D = b^2 - 4ac \geq 0 \\
p < \frac{-b}{2a} < q \quad \text{(축의 위치)} \\
(a > 0 \text{이면)} \; f(p) > 0, \, f(q) > 0
\end{cases}$$

또는 $a < 0$일 때는 $f(p) < 0, \, f(q) < 0$입니다.

### 직관 및 기하적 의미

포물선이 $x$축과 만나는 두 점이 $(p, q)$ 구간 안에 있으려면, 먼저 **실제로 $x$축과 만나야** 하므로 판별식이 0 이상이어야 합니다. 그 다음, 포물선의 꼭짓점(축)이 그 구간 안에 있어야 두 근이 양쪽에 퍼져있지 않습니다. 마지막으로 **구간의 양 끝점에서 함수값의 부호가 같아야** 합니다. $a > 0$(아래로 볼록)이면, 양 끝에서 양수여야 포물선이 그 사이에서만 $x$축과 만날 수 있습니다.

### 한 줄 예

$f(x) = x^2 - 5x + 4$의 근이 $(1, 4)$ 안에 있는지 확인: $D = 25 - 16 = 9 > 0$ ✓, 축: $\frac{5}{2} = 2.5 \in (1, 4)$ ✓, $f(1) = 0, f(4) = 0$ (경계). 실제로 근은 $x = 1, 4$이므로 열린 구간 $(1, 4)$에는 속하지 않으나, $[1, 4]$에는 속합니다. `sympy.solve(x**2 - 5*x + 4, x)` → `[1, 4]`
