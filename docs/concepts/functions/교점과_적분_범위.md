### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 교점은 $f(x) = g(x)$를 만족하는 $x$값들입니다. 이 교점의 $x$좌표들은 두 곡선이 둘러싼 영역의 넓이를 정적분으로 계산할 때, 적분 구간의 경계점(시작점, 끝점)이 되거나 구간을 나누는 기준점이 됩니다.

### 직관과 기하적 의미

좌표평면에 두 함수의 그래프를 그리면, 교점은 두 곡선이 만나는 점입니다. 교점의 $x$좌표는 "이 구간에서의 넓이 계산"이 시작되고 끝나는 위치를 자연스럽게 결정합니다. 

특히 넓이를 구할 때는 각 구간에서 **어느 함수의 그래프가 위에 있는지**를 파악해야 합니다. 예를 들어 $[a, c]$ 구간이 교점 $x=b$로 두 부분으로 나뉜다면, $[a,b]$에서는 한 함수가 위에 있고 $[b,c]$에서는 다른 함수가 위에 있을 수 있습니다. 이런 상황에서 교점의 위치를 정확히 알아야 각 구간에서 올바른 적분식을 세울 수 있습니다:

$$\text{넓이} = \int_a^b |f(x) - g(x)| \, dx + \int_b^c |g(x) - f(x)| \, dx$$

### 한 줄 예

$y = x$와 $y = x^2$의 교점은 $x = 0, 1$이고 ($x^2 = x \Rightarrow x(x-1) = 0$), 이 두 점이 정적분의 적분 구간 경계가 됩니다.
$$\text{넓이} = \int_0^1 (x - x^2) \, dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{6}$$
검산: `sympy.integrate(x - x**2, (x, 0, 1))`
