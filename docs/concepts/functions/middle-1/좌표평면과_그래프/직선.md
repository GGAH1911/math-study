# 직선

## 정확한 진술

좌표평면에서 **직선**은 두 점을 지나며 일정한 기울기를 갖는 자취입니다. 두 점 $P(x_1, y_1)$과 $Q(x_2, y_2)$ (단, $x_1 \neq x_2$)를 지날 때, 이 두 점을 지나는 직선은 유일하게 결정되며, 기울기는 $m = \frac{y_2 - y_1}{x_2 - x_1}$으로 정의됩니다. 직선의 방정식은 **기울기-절편 형태** $y = mx + b$, **점-기울기 형태** $y - y_1 = m(x - x_1)$, 또는 **일반형** $ax + by + c = 0$으로 나타낼 수 있습니다.

## 직관과 기하적 의미

직선은 평면에서 가장 기본적인 도형으로, 곡률이 0인 일직선입니다. 기울기 $m$은 직선이 수평선으로부터 얼마나 기울었는지를 나타내며, $m > 0$이면 우상향, $m < 0$이면 우하향, $m = 0$이면 수평선입니다. $y$절편 $b$는 직선이 $y$축과 만나는 점 $(0, b)$의 위치를 나타냅니다. 직선의 핵심 성질은 정해진 두 점이 있으면 그것을 지나는 직선이 항상 유일하다는 것입니다. 또한 직선 위의 어떤 두 점을 선택해도 기울기는 항상 같습니다.

## 한 줄 예

점 $(1, 3)$과 $(3, 7)$을 지나는 직선의 기울기는 $m = \frac{7-3}{3-1} = 2$이고, 점-기울기 형태로 $y - 3 = 2(x - 1)$이며, 이를 정리하면 $y = 2x + 1$입니다. (검증: `sympy.solve([3 - (2*1 + 1), 7 - (2*3 + 1)], [])` → 양쪽 모두 0)
