# 두 점 사이의 거리

## 정확한 진술

좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 다음 공식으로 정의됩니다.

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

이 거리를 $|AB|$로도 표기합니다.

## 직관과 기하적 의미

이 공식은 피타고라스 정리에서 나옵니다. 두 점을 꼭짓점으로 하는 직각삼각형을 그려 봅시다. 가로 변의 길이는 $|x_2 - x_1|$이고 세로 변의 길이는 $|y_2 - y_1|$입니다. 빗변이 바로 두 점 사이의 거리이므로, 피타고라스 정리를 적용하면 위 공식을 얻습니다.

거리의 기본 성질:
- $d(A, B) \geq 0$ (항상 0 이상)
- $d(A, B) = 0$ ⟺ $A = B$ (같은 점일 때만 0)
- $d(A, B) = d(B, A)$ (순서는 무관)

특히 원점 $O(0, 0)$에서 점 $P(x, y)$까지의 거리는 $|OP| = \sqrt{x^2 + y^2}$로 간단해집니다.

## 간단한 예

점 $A(1, 2)$와 $B(4, 6)$ 사이의 거리를 구하면:

$$|AB| = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

검산 (sympy): `sympy.sqrt((4-1)**2 + (6-2)**2)` → $5$
