# 정비례함수

## 정확한 진술

두 변수 $x$, $y$의 관계가 $y = ax$ (단, $a \neq 0$인 상수) 꼴로 나타날 때, $y$를 $x$에 대한 **정비례함수**라고 합니다. 여기서 상수 $a$를 **비례상수**라 부릅니다. 정의역은 실수 전체이고 치역도 실수 전체입니다.

## 직관과 기하적 의미

정비례함수의 그래프는 항상 **원점** $(0, 0)$을 지나는 직선입니다. 비례상수 $a$의 크기와 부호에 따라 기울기가 결정됩니다:

- $a > 0$일 때: 오른쪽 위로 향하는 직선
- $a < 0$일 때: 오른쪽 아래로 향하는 직선  
- $|a|$가 클수록 수평선에서 더 멀게 기울어집니다

정비례함수의 핵심은 **입력값이 $k$배 변하면 출력값도 정확히 $k$배 변한다**는 선형성입니다. 예를 들어 $x$가 2배가 되면 $y$도 2배가 됩니다. 이것이 "비례"라는 이름의 이유입니다.

## 구체적인 예

**$y = 2x$**: 비례상수가 2인 정비례함수
- $x = 1$일 때 $y = 2$
- $x = 3$일 때 $y = 6$  
- $x = -1$일 때 $y = -2$

**$y = -\frac{1}{2}x$**: 비례상수가 $-\frac{1}{2}$인 정비례함수
- $x = 2$일 때 $y = -1$  
- $x = -4$일 때 $y = 2$

## 주의

정비례함수는 일차함수 $y = ax + b$의 특수한 경우로, **$b = 0$일 때**만 정비례함수입니다. 따라서 $y = 3x + 1$은 정비례함수가 아닙니다.

**검산**: `sympy.sympify('2*x').subs('x', 3)` → 6
