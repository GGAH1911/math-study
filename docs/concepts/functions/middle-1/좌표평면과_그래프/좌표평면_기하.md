# 좌표평면 기하

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
두 수직인 축이 만나는 평면 위에 점의 위치를 순서쌍으로 나타내어 기하적 대상을 대수적으로 다루는 체계입니다.

## 본문
좌표평면이란 두 개의 수직인 수직선인 $x$축과 $y$축이 원점에서 만나는 평면을 의미합니다. 평면 위의 모든 점 $P$는 $x$축으로부터의 거리 $y$와 $y$축으로부터의 거리 $x$를 통해 유일하게 결정되며, 이를 순서쌍 $(x, y)$로 나타냅니다. 이때 $x$를 횡좌표, $y$를 종좌표라고 부릅니다.

### 직관과 기하적 의미
좌표평면의 핵심적인 역할은 기하학적 도형을 대수적인 식으로 변환하여 표현하는 것입니다. 예를 들어, 이차함수 $y = ax^2 + bx + c$의 그래프는 좌표평면 위에서 해당 식을 만족하는 모든 점 $(x, y)$가 그리는 자취입니다. 이를 통해 복잡한 도형의 성질을 수식 계산만으로 해결할 수 있게 되었습니다.

### 기본 성질
좌표평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 피타고라스 정리를 이용하여 다음과 같이 계산합니다.
$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
이러한 체계가 없다면 기하학적 문제를 해결하기 위해 매번 직접적인 측정과 복잡한 작도가 필요했을 것입니다.

## 학습 체크
- 점의 위치를 나타내는 순서쌍 $(x, y)$에서 $x$와 $y$의 역할은 무엇인가요?
- 두 점 사이의 거리를 구할 때 피타고라스 정리가 어떻게 적용되는지 설명할 수 있나요?

## 관련 개념
- **이차함수**: 좌표평면 위의 점들이 특정한 규칙을 가지고 모여 형성된 곡선의 자취로 나타납니다.
