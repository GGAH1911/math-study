# 정비례 식 구하기

> **예제** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)
## 요약
한 점으로부터 $y=ax$ 식

## 본문

### 문제

점 $(2, 6)$을 지나는 정비례 식을 구하시오.

### 단계별 풀이

정비례는 $y = ax$ 형태입니다. 여기서 $a$는 정비례 상수(기울기)인데, 이 값을 구해야 합니다.

**1단계: 주어진 점의 좌표를 식에 대입**

점 $(2, 6)$이 정비례 식을 지난다는 것은 $x=2$일 때 $y=6$이라는 뜻입니다. 이를 $y = ax$에 대입합니다.

$$6 = a \cdot 2$$

**2단계: 정비례 상수 $a$ 구하기**

위 식을 $a$에 대해 정리하면:

$$a = \frac{6}{2} = 3$$

**3단계: 정비례 식 완성**

따라서 구하는 식은:

$$y = 3x$$

### 답

$$y = 3x$$

### 변형 및 주의

**검증:** 구한 식이 맞는지 확인해봅시다. $x=2$를 대입하면 $y = 3 \times 2 = 6$ ✓

**다른 점들도 이 식을 만족하는가?** 
점 $(1, 3)$: $y = 3 \times 1 = 3$ ✓  
점 $(3, 9)$: $y = 3 \times 3 = 9$ ✓

**음수 기울기의 경우**  
만약 점 $(2, -6)$을 지난다면, $-6 = 2a$ → $a = -3$ → $y = -3x$

**기울기의 의미**  
$a = 3$은 "$x$가 1 증가할 때마다 $y$는 3씩 증가한다"는 뜻입니다. 이는 직선의 가파른 정도를 나타냅니다.

```python
# sympy로 검증: 점 (2, 6)을 지나고 y=ax 형태를 만족하는 a 구하기
from sympy import symbols, Eq, solve
a = symbols('a')
eq = Eq(6, a * 2)
solution = solve(eq, a)  # [3]
```
