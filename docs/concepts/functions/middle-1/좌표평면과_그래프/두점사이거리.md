# 두 점 사이의 거리

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
좌표평면 위의 두 점 사이의 거리는 피타고라스 정리를 이용하여 두 점의 좌표 차이를 이용해 구하는 직선거리입니다.

## 본문
좌표평면 위의 두 점 $\mathrm{A}(x_1, y_1)$과 $\mathrm{B}(x_2, y_2)$ 사이의 거리는 $\overline{\mathrm{AB}} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$로 정의됩니다. 이는 좌표평면 위에서 두 점을 잇는 가장 짧은 직선거리를 좌표로 표현한 공식입니다.

### 직관과 기하적 의미
이 공식은 직각삼각형의 빗변의 길이를 구하는 피타고라스 정리를 좌표평면에 적용한 결과입니다. 두 점 사이의 $x$좌표 차이와 $y$좌표 차이를 각각 직각삼각형의 밑변과 높이로 생각하면, 두 점 사이의 거리는 그 삼각형의 빗변의 길이와 같습니다. 만약 한 점이 수직선 위에 있다면 공식은 두 좌표의 차이인 $|x_2 - x_1|$로 단순화됩니다. 이 개념은 도형의 방정식과 벡터를 다루는 수학의 기초적인 도구로 활용됩니다.

### 기본 성질
두 점 $\mathrm{A}(1, 2)$와 $\mathrm{B}(4, 6)$ 사이의 거리를 계산하면 $\sqrt{(4-1)^2 + (6-2)^2} = \sqrt{3^2 + 4^2} = 5$가 됩니다. 또한 원점 $\mathrm{O}(0, 0)$과 점 $\mathrm{P}(3, 4)$ 사이의 거리는 $\sqrt{(3-0)^2 + (4-0)^2} = 5$로 계산할 수 있습니다.
