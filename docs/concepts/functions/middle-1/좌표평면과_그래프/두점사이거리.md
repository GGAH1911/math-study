# 두 점 사이의 거리

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

좌표평면 위 두 점 사이의 직선거리를 좌표로 표현한 공식입니다. 좌표평면의 기본 도구로, 도형의 방정식과 벡터의 출발점이 됩니다.

## 정의

좌표평면 위의 두 점 $\mathrm{A}(x_1, y_1)$과 $\mathrm{B}(x_2, y_2)$ 사이의 거리는
$$\overline{\mathrm{AB}} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.$$
이는 피타고라스 정리를 직각삼각형 $\triangle$에 적용한 결과입니다. 수직선 위의 점에 대해서는 $|x_2 - x_1|$로 환원됩니다.

## 예시

두 점 $\mathrm{A}(1, 2)$, $\mathrm{B}(4, 6)$ 사이의 거리를 구해 봅니다.
$$\overline{\mathrm{AB}} = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5.$$

또한 원점 $\mathrm{O}(0, 0)$과 점 $\mathrm{P}(3, 4)$ 사이의 거리는 $\sqrt{9 + 16} = 5$입니다.
