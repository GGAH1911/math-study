# 축 대칭

좌표평면의 점이나 도형을 좌표축에 대해 거울처럼 반사시키는 변환입니다. 좌표평면 단원의 기본 대칭이동입니다.

## 정의

점 $\mathrm{P}(x, y)$에 대해 다음과 같이 정의합니다.
- **$x$축 대칭이동:** $\mathrm{P}'(x,\ -y).$ $y$좌표의 부호만 바뀝니다.
- **$y$축 대칭이동:** $\mathrm{P}'(-x,\ y).$ $x$좌표의 부호만 바뀝니다.

함수 $y = f(x)$의 그래프를 $x$축에 대해 대칭이동한 도형의 식은 $y = -f(x)$이고, $y$축에 대해 대칭이동한 도형의 식은 $y = f(-x)$입니다.

## 예시

점 $\mathrm{P}(3, 5)$의 $x$축 대칭이동은 $(3, -5)$이고 $y$축 대칭이동은 $(-3, 5)$입니다.

또한 직선 $y = 2x + 1$의 $x$축 대칭이동 결과는 $-y = 2x + 1$, 즉 $y = -2x - 1$입니다. $y$축 대칭이동 결과는 $y = 2(-x) + 1 = -2x + 1$입니다.
