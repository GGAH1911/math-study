# 좌표계산

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
좌표계산이란 좌표평면 위의 두 점 사이의 거리, 중점, 기울기 등을 수식으로 산출하여 기하학적 성질을 대수적으로 해결하는 과정입니다.

## 본문
좌표계산이란 수평선과 수직선으로 이루어진 좌표계 위의 두 점 사이의 거리, 중점, 기울기 등을 수식으로 구하는 계산입니다. 평면 위의 점 $P$는 실수 쌍 $(x, y)$로 나타낼 수 있으며, 이 실수 쌍을 점의 좌표라고 부릅니다. 여기서 $x$는 가로축인 $x$축으로부터의 거리, $y$는 세로축인 $y$축으로부터의 거리입니다.

### 직관과 기하적 의미
기하학의 도형은 본래 눈으로 보고 그려서 다루었으나, 좌표를 도입하면 도형의 성질을 숫자와 식으로 표현할 수 있습니다. 예를 들어, "두 점이 얼마나 떨어져 있는가"라는 질문을 거리 공식 $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$를 통해 계산하면 정확한 수치를 얻을 수 있습니다. 이처럼 기하 문제를 대수 계산으로 변환하면 문제를 더욱 일반적이고 체계적으로 해결할 수 있다는 장점이 있습니다.

### 기본 성질
좌표계산의 핵심적인 요소로는 두 점의 가운데 위치를 나타내는 중점 좌표 $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$와 직선이 기울어진 정도를 나타내는 기울기 $m = \frac{y_2-y_1}{x_2-x_1}$ 등이 있습니다. 이러한 개념들은 모두 좌표계 위에서의 계산을 통해 도출됩니다.

## 학습 체크
- 두 점의 좌표가 주어졌을 때 거리 공식을 사용하여 정확한 값을 구할 수 있는가?
- 중점 좌표와 기울기 공식의 분자와 분모에 들어가는 성분의 의미를 이해하고 있는가?

## 관련 개념
- **평면도형**: 좌표계 위에서 도형의 성질을 수치화하여 대수적으로 분석할 수 있게 합니다.
