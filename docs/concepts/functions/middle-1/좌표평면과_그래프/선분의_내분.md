# 선분의 내분

> **정의** · 중1 · 단원: [좌표평면과 그래프](/concepts/좌표평면과_그래프)

## 요약
선분을 주어진 비율로 안쪽에서 나누는 점의 좌표를 구하는 개념으로, 좌표평면에서 도형의 위치를 결정하는 기초적인 도구입니다.

## 본문
좌표평면 위의 두 점 $\mathrm{A}(x_1, y_1)$, $\mathrm{B}(x_2, y_2)$를 잇는 선분을 $m : n$ ($m, n > 0$)의 비율로 내분하는 점 $\mathrm{P}$의 좌표는 $\mathrm{P}\left(\frac{n x_1 + m x_2}{m + n},\ \frac{n y_1 + m y_2}{m + n}\right)$입니다. 이는 선분 위의 한 점이 양 끝점으로부터 떨어진 거리의 비가 주어진 비율과 같음을 의미하며, 좌표의 계산 과정에서 비율의 역수($n$과 $m$)를 각 좌표에 곱하여 합산하는 방식을 취합니다.

### 직관과 기하적 의미
내분점은 선분 $\mathrm{AB}$의 내부에 위치하며, $m$과 $n$의 값이 커지거나 작아짐에 따라 점 $\mathrm{P}$의 위치가 $\mathrm{A}$ 또는 $\mathrm{B}$ 쪽으로 치우치게 됩니다. 특히 $m=n=1$인 경우는 선분을 정확히 이등분하는 지점인 중점을 의미하며, 이때의 좌표는 두 점의 좌표를 각각 더해 $2$로 나눈 값과 같습니다.

### 기본 성질
내분점의 좌표를 구할 때는 분모가 항상 비율의 합인 $m+n$이 된다는 점에 유의해야 합니다. 또한, 두 점의 좌표가 모두 양수일 때 내분점의 좌표 역시 항상 두 점 사이의 범위 내에 존재하게 됩니다.

## 학습 체크
- 내분점의 좌표를 구할 때 $m$과 $n$의 위치를 바꾸어 계산하지 않았는지 확인했는가?
- 중점의 좌표를 구할 때 $m=n=1$인 특수한 경우를 활용하여 더 빠르게 계산할 수 있는가?
- 주어진 점의 좌표가 $x$축과 $y$축 상의 값일 때, 내분점의 좌표가 선분 사이에 위치하는지 검토하였는가?
