### 정확한 진술

구간별 함수는 정의역을 두 개 이상의 부분으로 나누어, 각 부분에서 서로 다른 식으로 정의된 함수입니다. 형식적으로는 정의역의 분할 $D = D_1 \cup D_2 \cup \cdots \cup D_n$ ($D_i$ 는 서로소)에 대해 각 $x \in D_i$ 에서 정의역 $D_i$ 에 맞는 식 $f_i(x)$ 를 대응하는 함수를 의미합니다:

$$f(x) = \begin{cases}
f_1(x) & \text{if } x \in D_1 \\
f_2(x) & \text{if } x \in D_2 \\
\vdots \\
f_n(x) & \text{if } x \in D_n
\end{cases}$$

### 직관과 기하적 의미

구간별 함수는 실제로 "하나의 함수"입니다. 정의역의 다른 부분에서 다른 규칙이 적용될 뿐이지, 함수의 정의(입력 하나에 출력 하나)는 여전히 성립합니다. 그래프 위에서는 구간마다 다른 모양이 나타나므로, 각 구간의 경계점에서 불연속이거나 뾰족한 꺾임이 발생할 수 있습니다. 예를 들어 절댓값 함수 $|x|$ 는 $x=0$ 을 중심으로 구간을 나누어 정의한 구간별 함수의 대표 사례입니다.

### 한 줄 예

$$f(x) = \begin{cases}
x^2 & \text{if } x \leq 1 \\
3x - 2 & \text{if } x > 1
\end{cases}$$

에서 $f(0) = 0$ (첫 번째 식), $f(2) = 4$ (두 번째 식)입니다.
```
# sympy로 값 확인
from sympy import symbols, Piecewise
x = symbols('x')
f = Piecewise((x**2, x <= 1), (3*x - 2, x > 1))
print(f.subs(x, 0), f.subs(x, 2))  # 0, 4
```
