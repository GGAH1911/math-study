# 지수 로그 역함수 관계

> **정리** · 수학1 · 단원: [지수함수와 로그함수](/concepts/지수함수와_로그함수)

## 요약
서로 역함수 (y=x 대칭)

## 본문 (학습 시 채워짐)

### 진술 및 조건

밑 $a$ ($a > 0, a \neq 1$)에 대하여 지수함수 $f(x) = a^x$와 로그함수 $g(x) = \log_a x$는 **서로 역함수**입니다. 즉, $f^{-1} = g$이고 $g^{-1} = f$입니다. 따라서 두 함수의 그래프는 직선 $y = x$에 대해 **선대칭**입니다.

### 증명 스케치

역함수의 정의에서, $y = a^x$일 때 $x = \log_a y$가 성립합니다. 이를 다시 쓰면:
$$y = a^x \Leftrightarrow x = \log_a y$$

역함수를 구하려면 $x$와 $y$를 맞바꾸면:
$$x = a^y \Leftrightarrow y = \log_a x$$

따라서 $y = a^x$의 역함수는 $y = \log_a x$입니다.

그래프의 대칭성은 역함수의 기본 성질에서 나옵니다. 원함수의 그래프 위의 점 $(p, q)$가 있으면, 역함수의 그래프 위에는 $(q, p)$가 있습니다. 점 $(p, q)$와 $(q, p)$는 직선 $y = x$에 대해 대칭이므로, 두 함수의 그래프 전체가 $y = x$에 대해 대칭입니다.

### 의의와 응용

지수함수와 로그함수의 역함수 관계는 다음을 함축합니다:

- **정의역과 치역의 교환**: $a^x$의 정의역(실수)이 $\log_a x$의 치역이 되고, $a^x$의 치역(양수)이 $\log_a x$의 정의역이 됩니다.
- **방정식 풀이**: $a^x = b$ 형태의 방정식은 $x = \log_a b$로 풀 수 있고, 반대로 $\log_a x = c$는 $x = a^c$로 풀 수 있습니다.
- **지수·로그 방정식 동치 변환**: 복잡한 지수 또는 로그 방정식을 상대편으로 변환하여 문제를 단순화할 수 있습니다.

예를 들어, $2^x = 8$을 풀려면 $x = \log_2 8 = 3$입니다. (`sympy.solve(2**x - 8, x)` 또는 직접 $\log_2 8 = \log_2 2^3 = 3$)
