### 정확한 진술

함수 $y = f(x)$의 그래프를 연직 방향(위아래)으로 $c$ 단위만큼 움직인 함수는 $y = f(x) + c$이다. 여기서 $c > 0$이면 그래프가 위로 $c$ 단위 이동하고, $c < 0$이면 아래로 $|c|$ 단위 이동한다.

### 직관과 기하적 의미

함수 $y = f(x)$의 각 점 $(x, y)$에서 $y$값에 상수 $c$를 더하면, 모든 점이 수직선을 따라 동일하게 위아래로 움직인다. 이때 **$x$좌표는 변하지 않고 $y$좌표만 $c$만큼 평행이동**한다. 따라서 그래프의 모양은 정확히 같지만 위치만 바뀐다.

삼각함수에 적용하면, $y = \sin x + 1$은 $y = \sin x$의 그래프를 **위로 1칸 옮긴 것**이고, 함숫값의 범위(치역)도 $[-1, 1]$에서 $[0, 2]$로 변한다. 진동 범위는 같지만 중심값(평형점)이 $y = 1$로 올라간다.

### 예시

$y = \cos x$의 그래프를 **아래로 2칸 이동**하면 $y = \cos x - 2$이다. 원래 최댓값은 1, 최솟값은 −1이지만, 이동 후에는 최댓값이 −1, 최솟값이 −3이 된다. 주기와 대칭성은 변하지 않는다.

**검증 (sympy):**
```python
# x=π/2일 때: cos(π/2) - 2 = 0 - 2 = -2
from sympy import *
x = symbols('x')
f = cos(x) - 2
print(f.subs(x, pi/2))  # -2
```
