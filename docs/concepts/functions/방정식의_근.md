### 정확한 진술

방정식의 **근(根, root)**은 그 방정식을 참으로 만드는 미지수의 값입니다. 예를 들어 방정식 $x^2 - 5x + 6 = 0$에서 $x = 2$와 $x = 3$을 대입하면 등식이 성립하므로, 2와 3이 이 방정식의 근입니다.

일반적으로 방정식 $f(x) = 0$의 근은 $f(\alpha) = 0$을 만족하는 수 $\alpha$를 의미합니다.

### 직관과 기하적 의미

**함수의 영점(zero)과 같습니다.** 좌표평면에서 이차함수 $y = ax^2 + bx + c$를 그려보면, 그 그래프가 x축과 만나는 점들의 x좌표가 바로 방정식 $ax^2 + bx + c = 0$의 근입니다. 

- 포물선이 x축과 두 점에서 만나면 → 서로 다른 두 개의 근
- 포물선이 x축에 접하면 → 중근(같은 근 2개)
- 포물선이 x축과 만나지 않으면 → 실근이 없음(복소수 근 존재)

이 때문에 방정식을 푼다는 것은 "함수의 그래프가 x축과 만나는 위치를 찾는 것"과 같습니다.

### 한 줄 예

$x^2 - 3x + 2 = 0$에서 $x = 1$과 $x = 2$가 근입니다. (`sympy.solve(x**2 - 3*x + 2, x)` → `[1, 2]`)

근의 개수는 **판별식** $D = b^2 - 4ac$로 판단합니다: $D > 0$이면 서로 다른 두 실근, $D = 0$이면 중근, $D < 0$이면 실근 없음.
