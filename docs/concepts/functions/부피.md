### 정확한 진술

함수 $y = f(x)$ (단, $f(x) \geq 0$)와 $x$축, 직선 $x=a$, $x=b$로 둘러싸인 도형을 $x$축 중심으로 회전시킨 회전체의 부피 $V$는 다음과 같이 정적분으로 정의됩니다:

$$V = \pi \int_{a}^{b} [f(x)]^2 \, dx$$

더 일반적으로, 구간 $[a, b]$에서 횡단면의 넓이가 $A(x)$인 입체도형의 부피는:

$$V = \int_{a}^{b} A(x) \, dx$$

### 직관과 기하적 의미

부피는 3차원 도형이 차지하는 공간의 크기입니다. 정적분을 이용한 부피 계산은 **무한히 많은 얇은 원판(또는 횡단면)을 쌓는 것**으로 생각할 수 있습니다. 회전체의 경우, $x$축에서 거리 $f(x)$인 점을 회전시키면 반지름 $f(x)$인 원판이 만들어지고, 이 원판의 넓이는 $\pi[f(x)]^2$입니다. 이를 $a$에서 $b$까지 쌓아올리면 전체 부피가 됩니다.

### 한 줄 예

$y = \sqrt{x}$를 $x = 0$부터 $x = 4$까지 $x$축 중심으로 회전시킨 회전체의 부피는 $V = \pi \int_{0}^{4} x \, dx = \pi \left[\frac{x^2}{2}\right]_{0}^{4} = 8\pi$입니다.

```python
import sympy as sp
x = sp.Symbol('x')
V = sp.pi * sp.integrate(x, (x, 0, 4))
print(V)  # 8*pi
```
