### 정확한 진술

함수 $f(x)$의 **우극한**(right-hand limit)은 $x$가 $a$보다 크면서 $a$에 가까워질 때 $f(x)$가 접근하는 값입니다. 기호로는 $\lim_{x \to a^+} f(x) = L$로 나타냅니다.

**정의**: $x > a$인 범위에서 $x$를 $a$에 한없이 가깝게 하면, $f(x)$가 $L$에 한없이 가까워질 때, "우극한값이 $L$이다"라고 하고 $\lim_{x \to a^+} f(x) = L$로 쓴다.

### 직관과 기하적 의미

우극한은 **오른쪽 방향**에서만 접근하는 극한입니다. 수직선 위에서 점 $a$의 오른쪽 부분($a$보다 큼)에 있는 점들을 따라가며, 점이 $a$에 가까워질 때 함수값이 어디로 수렴하는지 봅니다.

구체적으로:
- 점 $a$의 **바로 오른쪽**에서만 함수값을 관찰
- 좌극한 $\lim_{x \to a^-} f(x)$(왼쪽에서의 극한)과는 다를 수 있음
- 불연속점이나 정의역 경계에서 중요함

**예시**: 함수 $f(x) = \lfloor x \rfloor$(바닥함수)에서 $\lim_{x \to 2^+} \lfloor x \rfloor = 2$입니다. $x$가 2의 오른쪽에서 접근할 때(예: $x = 2.1, 2.01, 2.001, \ldots$), 함수값은 항상 2입니다.

### 기본 성질

극한의 성질(사칙연산, 대소관계)은 우극한에도 동일하게 적용됩니다. 또한 함수가 $x=a$에서 연속이면 $\lim_{x \to a^+} f(x) = f(a)$입니다.
