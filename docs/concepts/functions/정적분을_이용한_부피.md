### 정확한 진술

곡선 $y = f(x)$ (단, $f(x) \geq 0$)을 $x$축 중심으로 $x = a$에서 $x = b$까지 회전시킨 회전체의 부피는 다음과 같이 정적분으로 정의됩니다.

$$V = \pi \int_a^b [f(x)]^2 \, dx$$

더 일반적으로, 위치 $x$에서의 단면이 $A(x)$인 입체도형의 부피는 다음과 같습니다.

$$V = \int_a^b A(x) \, dx$$

회전체의 경우 단면이 반지름 $f(x)$인 원이므로 $A(x) = \pi[f(x)]^2$가 됩니다.

### 직관과 기하적 의미

회전체의 부피를 구하는 핵심 아이디어는 **원판의 합(disk method)**입니다. 곡선을 $x$축 중심으로 회전시킬 때, 위치 $x$에서 $x + dx$ 사이의 얇은 조각은 두께가 $dx$이고 반지름이 $f(x)$인 원판 모양이 됩니다. 이 원판의 부피는 $dV = \pi[f(x)]^2 dx$입니다. 이러한 무수히 많은 원판들을 $a$에서 $b$까지 누적하면 회전체의 전체 부피를 얻게 되는 것입니다.

단면 공식 $V = \int_a^b A(x) \, dx$는 더욱 광범위하게 적용되어, 단면이 원이 아닌 다양한 입체도형(예: 정사각형, 삼각형 단면)의 부피도 계산할 수 있습니다.

### 한 줄 예

$y = \sqrt{x}$ ($0 \leq x \leq 4$)를 $x$축 중심으로 회전한 회전체의 부피는 $V = \pi \int_0^4 x \, dx = \pi \cdot 8 = 8\pi$입니다. (`from sympy import pi, integrate, symbols; x = symbols('x'); V = pi * integrate(x, (x, 0, 4)); print(V)`)
