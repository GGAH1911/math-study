### 정확한 진술

좌표평면이란 두 개의 수직인 수직선(x축, y축)이 원점에서 만나는 평면입니다. 평면의 모든 점 P는 x축으로부터의 거리 $y$와 y축으로부터의 거리 $x$로 유일하게 결정되며, 이를 순서쌍 $(x, y)$로 나타냅니다. 여기서 $x$를 횡좌표, $y$를 종좌표라 합니다.

### 직관/기하적 의미

좌표평면의 역할은 **기하학적 도형을 대수적으로 표현**하는 것입니다. 선수 개념인 이차함수 $y = ax^2 + bx + c$의 그래프는 좌표평면 위의 점들의 집합, 즉 조건을 만족하는 모든 $(x, y)$의 자취(자취)입니다. 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리는 피타고라스 정리로부터

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

로 계산됩니다. 좌표평면 없이는 기하 문제를 직접 측정하고 계산해야 했을 것입니다.

### 한 줄 예

점 $(2, 5)$는 x축에서 오른쪽으로 2, y축에서 위로 5만큼 떨어진 점이고, 원점 $(0, 0)$과의 거리는 $\sqrt{2^2 + 5^2} = \sqrt{29}$입니다. (검증: `sympy.sqrt(2**2 + 5**2)`)
