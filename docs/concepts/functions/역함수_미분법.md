# 역함수 미분법

> **정리** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
$(f^{-1})'=1/f'(f^{-1})$

## 본문 (학습 시 채워짐)

### 진술 및 가정

함수 $f$가 어떤 구간에서 미분가능하고 $f'(x) \neq 0$일 때, 역함수 $f^{-1}$도 미분가능하며 다음이 성립한다:

$$\left(f^{-1}\right)'(x) = \frac{1}{f'\left(f^{-1}(x)\right)}$$

또는 $y = f^{-1}(x)$로 놓으면:

$$\frac{dy}{dx} = \frac{1}{\frac{dx}{dy}}$$

이 식은 "$x$를 $y$에 대해 미분한 값의 역수"라는 직관적 의미를 담고 있습니다.

### 증명 스케치

역함수의 정의에서 모든 $x$에 대해 $f\left(f^{-1}(x)\right) = x$가 성립합니다. 양변을 $x$에 대해 미분하면, 좌변에는 연쇄법칙을 적용하고:

$$f'\left(f^{-1}(x)\right) \cdot \left(f^{-1}\right)'(x) = 1$$

양변을 정리하면:

$$\left(f^{-1}\right)'(x) = \frac{1}{f'\left(f^{-1}(x)\right)}$$

### 의의 및 활용

이 정리는 역함수를 직접 구하기 어려울 때 그 도함수를 구하는 강력한 도구입니다. 예를 들어 $f(x) = x^3 + x$의 역함수 도함수는 $f'(x) = 3x^2 + 1$을 이용해 곧바로 구할 수 있습니다. 삼각함수의 역함수(아크사인, 아크탄젠트 등) 도함수 공식도 이 원리로 유도되므로, 수능 미적분에서 자주 출제되는 중요한 기초입니다.

**예**: $f(x) = 2x + 1$이면 $f^{-1}(x) = \frac{x-1}{2}$이고, $f'(x) = 2$이므로 $\left(f^{-1}\right)'(x) = \frac{1}{2}$ ✓
