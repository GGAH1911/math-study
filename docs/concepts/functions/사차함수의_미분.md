### 정확한 진술

사차함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$ (단, $a \neq 0$)를 미분하면 삼차함수를 얻습니다.

$$f'(x) = 4ax^3 + 3bx^2 + 2cx + d$$

각 항을 거듭제곱의 미분법 $\frac{d}{dx}x^n = nx^{n-1}$으로 미분하고 합치면 이 공식을 얻습니다.

### 직관 및 기하적 의미

사차함수의 도함수가 삼차함수라는 것은 사차함수 그래프 위의 모든 점에서 순간변화율(접선의 기울기)이 삼차함수로 표현된다는 뜻입니다. 이를 통해 다음을 분석할 수 있습니다:

**극값의 개수**: $f'(x) = 0$이 3개의 서로 다른 실근을 가지면 사차함수는 최대 3개의 극값(극댓값 2개, 극솟값 1개 또는 극댓값 1개, 극솟값 2개)을 가질 수 있습니다.

**함수의 증감**: $f'(x)$의 부호가 양수인 구간에서 $f(x)$는 증가하고, 음수인 구간에서는 감소합니다.

**변곡점**: $f''(x) = 12ax^2 + 6bx + 2c$는 이차함수이므로, 최대 2개의 변곡점이 존재할 수 있습니다.

### 한 줄 예

$f(x) = x^4 - 2x^2 + 1$을 미분하면 $f'(x) = 4x^3 - 4x = 4x(x^2 - 1)$이므로, 극값은 $x = -1, 0, 1$에서 발생합니다. (`sympy.diff(x**4 - 2*x**2 + 1, x)`로 검증 가능)
