### 정확한 진술

함수 $f(x)$가 점 $x=a$에서 **최솟값**을 가지기 위한 조건은 다음과 같습니다.

**필요조건 (내부 극값):** $x=a$가 정의역 내부에 있고 최솟값이면, $f'(a) = 0$ 또는 $f'(a)$가 존재하지 않습니다.

**충분조건 (2계 미분 판정법):** $f'(a) = 0$이고 $f''(a) > 0$이면, $x=a$에서 극솟값을 가집니다.

**부호 변화 판정:** $f'(x)$가 $x=a$에서 **음에서 양으로 변**할 때, $x=a$에서 극솟값을 가집니다.

### 직관과 기하적 의미

그래프 위에서 최솟값은 "계곡"처럼 보입니다. 도함수 $f'(x)$는 함수의 기울기를 나타내므로:

- $x=a$ 왼쪽에서 $f'(x) < 0$ (기울기 음수, 내려감)
- $x=a$ 오른쪽에서 $f'(x) > 0$ (기울기 양수, 올라감)

이때 $x=a$가 최솟값의 위치입니다. 이계 도함수 $f''(a) > 0$은 이 점에서 곡선이 **아래로 볼록**(위로 오목, convex)한다는 뜻이므로, 최솟값 조건을 더욱 확실하게 보장합니다.

### 한 줄 예

$f(x) = x^2 - 4x + 5$일 때, $f'(x) = 2x - 4$이므로 $f'(2) = 0$이고, $f''(x) = 2 > 0$이므로 $x=2$에서 최솟값 $f(2)=1$을 가집니다.

```python
# sympy.solve(2*x - 4, x)  # x = 2, f(2) = 2**2 - 4*2 + 5 = 1
```
