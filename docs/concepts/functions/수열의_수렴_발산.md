# 수열의 수렴 발산

> **정의** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
$\lim_{n\to\infty}a_n$의 존재

## 본문 (학습 시 채워짐)

### 정확한 진술
수열 $\{a_n\}$이 수렴한다는 것은 어떤 실수 $L$이 존재하여, $n$이 충분히 크면 $a_n$이 $L$에 임의로 가까워진다는 뜻입니다. 이때 $L$을 극한값이라 하고 $\lim_{n\to\infty} a_n = L$로 나타냅니다.

더 정확하게는: **임의의 양수 $\epsilon$에 대하여**, $n > N$일 때 항상 $|a_n - L| < \epsilon$을 만족하는 자연수 $N$이 존재하면, 수열 $\{a_n\}$은 $L$로 수렴한다고 합니다. 이러한 $L$이 존재하지 않으면 발산이라 합니다.

### 직관/기하적 의미
이 정의의 핵심은 "아무리 작은 오차 범위 $\epsilon$을 정해도, 충분히 뒤로 가면 수열의 모든 항이 그 범위 안에 들어온다"는 뜻입니다. 수렴하는 수열은 극한값 주변에 점점 더 가까이 모인다고 생각하면 됩니다.

발산은 세 가지로 분류합니다. 첫째는 $a_n = n$처럼 양의 무한대로 발산하고, 둘째는 $a_n = -n$처럼 음의 무한대로 발산하며, 셋째는 $a_n = (-1)^n$처럼 진동하면서 어떤 극한값도 갖지 않는 진동 발산입니다.

### 한 줄 예
$a_n = \frac{1}{n}$이면 수렴 ($\lim_{n\to\infty} a_n = 0$), $a_n = n$이면 양의 무한대 발산, $a_n = (-1)^n$이면 진동 발산입니다. 수렴 확인: `sympy.limit(1/n, n, oo)` → 0
