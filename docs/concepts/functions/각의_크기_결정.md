### 정확한 진술

삼각함수값이나 좌표가 주어졌을 때, 이를 만족하는 각의 크기를 찾는 것을 **각의 크기 결정**이라 합니다. $\sin\theta = a$ 또는 $\cos\theta = b$ 같은 방정식의 해를 구하되, 주로 정의역을 $[0, 2\pi)$ 또는 $(-\pi, \pi]$ 범위로 제한하여 유일한 답을 얻습니다.

### 직관/기하적 의미

삼각함수는 주기함수이므로, 같은 함수값을 갖는 각이 무수히 많습니다. 예를 들어 $\sin 30° = \sin 150° = \frac{1}{2}$이고, 이에 $360°$의 배수를 더해도 함수값은 같습니다. 따라서 "어느 각의 삼각함수값이 $a$인가?"라는 물음에 답하려면:

1. **사분면 조건 확인**: 주어진 함수값의 부호로부터 각이 속한 사분면을 판정합니다 (ASTC 법칙).
2. **기준각 구하기**: 절댓값에 해당하는 예각 $\alpha$를 역삼각함수 $\arcsin, \arccos, \arctan$ 등으로 구합니다.
3. **해 결정**: 사분면과 기준각으로부터 주어진 범위 내의 각을 유일하게 결정합니다.

예를 들어 $\cos\theta = -\frac{\sqrt{3}}{2}$이고 $\theta \in [0, 2\pi)$이면:
- $\cos$가 음수 → 2사분면 또는 3사분면
- 기준각: $\arccos\frac{\sqrt{3}}{2} = \frac{\pi}{6}$
- 2사분면 해: $\theta = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$
- 3사분면 해: $\theta = \pi + \frac{\pi}{6} = \frac{7\pi}{6}$

### 한 줄 예

$\sin\theta = \frac{1}{2}$, $\theta \in [0, 2\pi)$일 때, $\theta = \frac{\pi}{6}$ 또는 $\frac{5\pi}{6}$입니다.
