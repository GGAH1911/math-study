### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 **교점의 개수**는 방정식 $f(x) = g(x)$의 실근의 개수를 구하는 것과 같습니다. 이를 분석하기 위해 새로운 함수 $h(x) = f(x) - g(x)$를 정의하면, 교점의 개수는 곡선 $y = h(x)$가 $x$축과 만나는 점의 개수, 즉 $h(x) = 0$의 실근의 개수가 됩니다.

### 직관적 의미

좌표평면에서 두 그래프의 교점은 두 함수의 함수값이 정확히 같은 점입니다. 이를 **차 함수** $h(x) = f(x) - g(x)$로 변환하면, 문제는 "$h(x)$의 그래프가 $x$축과 몇 번 만나는가?"로 단순화됩니다. 

차 함수의 극값(최댓값과 최솟값), 단조성, 연속성을 분석하면 부호 변화를 파악할 수 있습니다. 특히 **중간값 정리**를 적용하면, $h(x)$가 부호를 바꾸는 구간마다 정확히 하나의 근이 존재함을 알 수 있습니다.

### 구체적인 분석 방법

교점의 개수를 구하려면:

1. $h(x) = f(x) - g(x)$의 도함수 $h'(x)$를 구한다.
2. $h'(x) = 0$의 해를 찾아 극값을 계산한다.
3. 각 구간에서 $h(x)$의 부호 변화를 조사한다.

예를 들어 $f(x) = x^2$, $g(x) = x + 2$일 때, $h(x) = x^2 - x - 2 = (x-2)(x+1)$이므로 교점은 $x = -1$, $x = 2$에서 2개입니다.
