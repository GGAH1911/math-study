### 정확한 진술

두 함수 $f(x)$와 $g(x)$의 **대소관계**는 특정 $x$ 값이나 구간에서 $f(x) > g(x)$, $f(x) < g(x)$, 또는 $f(x) = g(x)$ 중 어느 것이 성립하는지를 나타냅니다. 즉, 같은 $x$에 입력했을 때 어느 함수의 출력값이 더 큰지를 비교하는 것입니다.

### 직관: 그래프로 이해하기

함수의 대소관계는 **그래프의 상대적 위치**로 가장 직관적으로 이해할 수 있습니다. 두 이차함수의 그래프를 같은 좌표평면에 그렸을 때:
- $f(x)$의 그래프가 $g(x)$의 그래프보다 **위에 있는 구간**에서는 $f(x) > g(x)$
- $f(x)$의 그래프가 $g(x)$의 그래프보다 **아래에 있는 구간**에서는 $f(x) < g(x)$
- 두 그래프가 **만나는 점**에서는 $f(x) = g(x)$

대수적으로는 **차 함수** $h(x) = f(x) - g(x)$를 만들어서 $h(x)$의 부호를 조사합니다. 이차함수의 경우 판별식 $D$를 이용하면 더 편합니다:
- $D > 0$: 두 함수가 서로 다른 두 점에서 만남 → 만나는 점 사이에서 대소관계가 바뀜
- $D = 0$: 두 함수가 한 점에서만 만남 (접함) → 그 점을 제외하고는 한쪽이 항상 큼
- $D < 0$: 두 함수가 만나지 않음 → 어느 한쪽이 항상 큼

### 예제

$f(x) = x^2 + 2x$와 $g(x) = 3x$에서 언제 $f(x) > g(x)$인가?

$h(x) = f(x) - g(x) = x^2 + 2x - 3x = x^2 - x = x(x-1)$

$x(x-1) > 0$이려면 $x < 0$ 또는 $x > 1$일 때입니다. 따라서 두 함수가 $x=0$과 $x=1$에서 만나며, $x < 0$ 또는 $x > 1$에서 $f(x) > g(x)$, $0 < x < 1$에서 $f(x) < g(x)$입니다.
