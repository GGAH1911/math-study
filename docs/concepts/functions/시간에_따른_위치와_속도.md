### 정확한 진술

시간 $t$에 따른 물체의 위치를 위치함수 $s(t)$로 나타낼 때, **속도**는 위치를 시간에 대해 미분한 도함수입니다:

$$v(t) = \frac{ds}{dt}$$

마찬가지로 **가속도**는 속도를 시간에 대해 미분한 것으로, 위치함수의 이계도함수입니다:

$$a(t) = \frac{dv}{dt} = \frac{d^2s}{dt^2}$$

이 세 함수—위치 $s(t)$, 속도 $v(t)$, 가속도 $a(t)$—는 미분을 통해 연결되며, 역으로 부정적분(역도함수)을 이용해 서로 복원할 수 있습니다.

### 직관과 물리적 의미

속도는 물체가 단위 시간당 얼마나 빨리 위치를 바꾸는지를 나타냅니다. 그래프로 보면, 위치-시간 그래프의 각 점에서의 **접선의 기울기**가 바로 그 순간의 속도입니다. 

예를 들어 $v(t) > 0$이면 위치가 증가하는 중(물체가 앞으로 나아감), $v(t) < 0$이면 위치가 감소합니다(뒤로 움직임). $v(t) = 0$인 순간은 물체가 일시적으로 멈춘 순간입니다.

가속도는 속도가 얼마나 빨리 변하는지를 보여줍니다. $a(t) > 0$이면 빨라지고 있고, $a(t) < 0$이면 느려지고 있습니다.

### 간단한 예

물체가 $s(t) = t^2 - 3t + 2$ (단위: 미터, $t$: 초)에 따라 움직인다면:

- 속도: $v(t) = 2t - 3$
- 가속도: $a(t) = 2$

$t = 2$초일 때, 위치 $s(2) = 0$m, 속도 $v(2) = 1$m/s, 가속도 $a(2) = 2$m/s²입니다. 

(`sympy.diff(t**2 - 3*t + 2, t)` → $2t - 3$)
