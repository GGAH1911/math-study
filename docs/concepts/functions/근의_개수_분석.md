### 정확한 진술

방정식 $f(x) = 0$의 실근의 개수를 판정하기 위해 함수의 도함수를 이용하여 **함수의 극값과 그래프의 개형을 분석하는 방법**을 근의 개수 분석이라고 합니다. 주어진 함수 $f(x)$에 대해 도함수 $f'(x) = 0$의 해를 구하고, 각 구간에서의 함수의 증감을 조사하여 극댓값과 극솟값을 찾은 후, 이들 극값의 부호와 함수의 연속성을 종합하여 근의 개수를 결정합니다.

### 직관적 의미

함수의 그래프를 그렸을 때, 그래프가 x축과 만나는 횟수가 근의 개수입니다. 도함수의 부호 변화를 추적하면 함수가 증가하는 구간과 감소하는 구간을 파악할 수 있고, 이로부터 극댓값과 극솟값의 위치와 크기를 알 수 있습니다. **극값의 부호가 바뀌거나 극값이 0이면 근의 개수가 변합니다.** 예를 들어, 극댓값이 양수이고 극솟값이 음수이면 그래프는 반드시 x축과 세 번 만나므로 방정식은 서로 다른 세 개의 실근을 가집니다.

### 한 줄 예

$f(x) = x^3 - 3x$인 경우, $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$이므로 $x = -1$에서 극댓값 $f(-1) = 2 > 0$, $x = 1$에서 극솟값 $f(1) = -2 < 0$을 가지므로, 방정식 $x^3 - 3x = 0$은 서로 다른 세 개의 실근을 갖습니다. (검증: `sympy.solve(x**3 - 3*x, x)` → $[-\sqrt{3}, 0, \sqrt{3}]$)

### 활용 원칙

근의 개수를 판정할 때는 다음 순서를 따릅니다: (1) $f'(x) = 0$을 풀어 극값을 가질 후보 점을 찾고, (2) 각 후보 점에서 극댓값 또는 극솟값을 계산하고, (3) 극값들의 부호를 비교하여 그래프가 x축과 만나는 횟수를 판정합니다. **매개변수를 포함하는 경우**, 극값이 0이 되는 조건을 찾으면 근의 개수가 바뀌는 경계값을 결정할 수 있습니다.
