# 적분

> **단원** · 수학2 · 선수: [미분](/concepts/미분) · 다음: 없음

## 학습 목표
- 부정적분과 정적분의 정의를 이해한다
- 다항함수의 적분으로 넓이·길이·속도를 구한다

## 다룰 정의 / 정리 / 예제

**정의**
- [부정적분](/concepts/부정적분) — $\int f(x)dx$
- [정적분](/concepts/정적분) — $\int_a^b f(x)dx$

**정리**
- [미적분의 기본정리](/concepts/미적분의_기본정리) — $\frac{d}{dx}\int_a^x f(t)dt = f(x)$
- $\int x^n dx = \frac{x^{n+1}}{n+1}+C$ ($n\neq -1$)

**예제**
- [넓이 구하기](/concepts/넓이_구하기)
- 두 곡선 사이의 넓이
- 속도→거리 적분

## 평가 기준
- 4점 문항 2회 무오답 통과 시 숙달(마스터)로 인정
- 같은 단원에서 비슷한 유형의 오답이 반복되면 기초 개념 보강을 안내
