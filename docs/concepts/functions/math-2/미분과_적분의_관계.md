### 정확한 진술

함수 $f(x)$가 구간 $[a, b]$에서 연속이고, $F(x)$가 $f(x)$의 부정적분(즉, $F'(x) = f(x)$)이면, 다음이 성립합니다:

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

이것이 **미적분학의 기본정리(Fundamental Theorem of Calculus)**입니다. 이 정리는 미분과 적분이 역연산 관계임을 나타냅니다.

### 직관적 의미

미분은 함수의 "순간 변화율"을 구하는 연산이고, 적분은 "누적된 변화"를 합하는 연산입니다. 이 둘은 정반대 방향으로 작동합니다.

예를 들어, 자동차의 속도 함수 $v(t)$가 주어졌을 때:
- **미분**: 속도 함수를 미분하면 가속도(속도의 변화율)를 얻습니다.
- **적분**: 속도 함수를 $0$부터 $T$까지 적분하면 총 이동 거리를 얻습니다.

$\int_0^T v(t)\, dt$는 $T$시간 동안 움직인 총 거리이고, 이를 다시 미분하면 순간 속도 $v(t)$로 돌아옵니다.

### 기하적 의미

- $\int_a^b f(x)\, dx$는 곡선 $y=f(x)$와 $x$축 사이의 넓이입니다.
- 부정적분 $F(x)$는 높이가 $f(x)$인 수직선으로 이루어진 "면적 누적 함수"입니다.
- 정적분의 값 $F(b) - F(a)$는 $x=a$에서 $x=b$까지 누적된 넓이의 증가량입니다.

### 예제

$f(x) = 2x$의 정적분 $\int_1^3 2x\, dx$를 계산하세요.

$F(x) = x^2$이므로 (왜냐하면 $F'(x) = 2x$):

$$\int_1^3 2x\, dx = F(3) - F(1) = 9 - 1 = 8$$

```python
# sympy로 검증
from sympy import symbols, integrate
x = symbols('x')
result = integrate(2*x, (x, 1, 3))
print(result)  # 8
```
