### 정확한 진술

함수 $F(x)$의 도함수가 $f(x)$일 때, 즉 $F'(x) = f(x)$일 때, $F(x)$를 $f(x)$의 **원함수**(또는 부정적분)라고 합니다. 주어진 함수 $f(x)$에 대해 $F'(x) = f(x)$를 만족하는 함수 $F(x)$를 찾는 과정을 **원함수를 복원한다**고 표현합니다.

### 직관과 의미

미분은 함수를 받아서 그 변화율(도함수)을 구하는 과정입니다. 원함수 복원은 이 미분의 역과정으로, 변화율 정보만 주어졌을 때 원래 함수가 무엇이었는지 추적하는 것입니다. 

예를 들어 물체의 속도 함수가 주어졌을 때, 원래 위치 함수를 복원하는 것이 원함수 복원입니다. 또한 도함수 $f(x)$에 대해 원함수 $F(x)$는 유일하지 않습니다. $F(x) + C$ (단, $C$는 임의의 상수)도 같은 도함수를 가지므로, 원함수를 찾을 때는 항상 상수항을 포함해야 합니다.

### 구체적 예

$f(x) = 2x$의 원함수를 찾으면, $F(x) = x^2 + C$ (단, $C$는 상수)입니다. 왜냐하면 $\frac{d}{dx}(x^2 + C) = 2x$이기 때문입니다.

또 다른 예: $f(x) = \cos x$의 원함수는 $F(x) = \sin x + C$입니다. 이는 $\frac{d}{dx}(\sin x + C) = \cos x$를 확인하면 알 수 있습니다.

일반적으로 $f(x) = x^n$ (단, $n \neq -1$)의 원함수는 $F(x) = \frac{x^{n+1}}{n+1} + C$입니다.

```python
# sympy로 검증: f(x) = 2x의 원함수가 x^2 + C인지 확인
import sympy as sp
x, C = sp.symbols('x C')
F = x**2 + C
print(sp.diff(F, x))  # 2*x
```

원함수를 복원하는 것은 부정적분의 핵심이며, 이를 통해 정적분을 계산할 수 있습니다.
