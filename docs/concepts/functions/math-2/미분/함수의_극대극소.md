# 함수의 극대극소

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수 $f(x)$가 어떤 열린 구간에서 주변 값보다 크거나 작은 값을 갖는 상태를 말하며, 도함수의 부호 변화를 통해 극점의 존재를 확인할 수 있습니다.

## 본문
함수 $f(x)$가 $x=a$에서 정의되고, $a$를 포함하는 어떤 열린 구간에서 $f(a) \geq f(x)$이면 $f(x)$는 $x=a$에서 극댓값을 갖고, $f(a) \leq f(x)$이면 $x=a$에서 극솟값을 가집니다. 이때 극댓값과 극솟값을 통칭하여 극값이라 하며, 극값을 갖는 점을 극점이라 합니다. 더 엄밀하게는 $a$를 포함하는 열린 구간 $(a-\delta, a+\delta)$의 모든 $x$에 대해 $f(a) > f(x)$일 때 $x=a$에서 극댓값을 갖는다고 정의합니다.

### 직관과 기하적 의미
극댓값은 함수 그래프에서 산의 정상과 같은 봉우리 모양을 나타내며, 극솟값은 골짜기와 같은 계곡 모양을 나타냅니다. 중요한 점은 극값이 함수의 전체적인 최댓값이나 최솟값이 아닌, 특정 지점 주변에서의 상태를 나타내는 국소적 성질이라는 것입니다.

### 기본 성질
미분 가능한 함수에서 극점 $x=a$를 기준으로 도함수 $f'(x)$의 부호가 바뀝니다. 극댓값을 갖는 점의 경우 좌측에서는 $f'(x) > 0$으로 증가하다가 우측에서는 $f'(x) < 0$으로 감소하며, 극솟값은 그 반대의 양상을 보입니다. 따라서 $f'(a)=0$인 점은 극점이 될 수 있는 후보가 되지만, 실제 극점인지 확인하기 위해서는 반드시 도함수의 부호 변화를 검토해야 합니다.

## 학습 체크
- $f'(a)=0$이지만 극점이 아닌 경우(예: $f(x)=x^3$의 $x=0$)를 구분할 수 있는가?
- 극값이 함수의 전체 최댓값 또는 최솟값과 항상 일치하는가?
- 주어진 함수의 도함수를 구한 뒤, 부호 변화를 통해 극점의 위치를 찾을 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 증가와 감소, 극대와 극소를 판정하여 함수의 그래프 개형을 정밀하게 그리는 데 사용됩니다.
