# 미분의 사칙연산

> **정리** · 수학2 · 단원: [미분](/concepts/미분)
## 요약
합·차·상수배의 미분

## 본문

### 정리의 진술

$f(x)$와 $g(x)$가 미분가능한 함수이고 $c$가 상수일 때, 다음이 성립합니다.

$$\frac{d}{dx}[f(x) + g(x)] = f'(x) + g'(x)$$

$$\frac{d}{dx}[f(x) - g(x)] = f'(x) - g'(x)$$

$$\frac{d}{dx}[cf(x)] = cf'(x)$$

### 왜 이것이 성립할까?

미분의 정의부터 출발합니다. 합의 미분법을 예로 들면, 극한의 정의에 의해:

$$\frac{d}{dx}[f(x) + g(x)] = \lim_{h \to 0} \frac{[f(x+h) + g(x+h)] - [f(x) + g(x)]}{h}$$

분자를 분리하고 극한의 합 규칙을 적용하면:

$$= \lim_{h \to 0} \left[\frac{f(x+h) - f(x)}{h} + \frac{g(x+h) - g(x)}{h}\right] = f'(x) + g'(x)$$

차의 미분법도 동일한 논리입니다. 상수배의 경우, 상수 $c$는 극한 기호 밖으로 나와서 $c \cdot f'(x)$가 됩니다.

### 실제로 어떻게 쓸까?

이 정리가 없으면 $y = 3x^2 + 5x - 2$ 같은 함수를 미분할 때마다 극한을 직접 계산해야 합니다. 하지만 이 정리를 사용하면 각 항을 따로 미분하고 더할 수 있습니다:

$$y' = 3 \cdot \frac{d}{dx}[x^2] + 5 \cdot \frac{d}{dx}[x] - \frac{d}{dx}[2] = 6x + 5$$

다항식뿐 아니라 삼각함수, 지수함수, 로그함수 등 모든 함수의 미분에 필수적입니다. (검증: `sympy.diff(3*x**2 + 5*x - 2, x)` → `6*x + 5`)
