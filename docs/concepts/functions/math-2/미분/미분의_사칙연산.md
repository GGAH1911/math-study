# 미분의 사칙연산

> **정리** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수의 합, 차, 상수배에 대한 미분은 각각의 미분 결과의 합, 차, 상수배와 같다.

## 본문
$f(x)$와 $g(x)$가 미분가능한 함수이고 $c$가 상수일 때, 다음의 미분 법칙이 성립합니다.
$$\frac{d}{dx}[f(x) + g(x)] = f'(x) + g'(x)$$
$$\frac{d}{dx}[f(x) - g(x)] = f'(x) - g'(x)$$
$$\frac{d}{dx}[cf(x)] = cf'(x)$$

### 증명 스케치
미분의 정의인 극한을 이용하여 증명할 수 있습니다. 합의 미분을 예로 들면, $\lim_{h \to 0} \frac{[f(x+h) + g(x+h)] - [f(x) + g(x)]}{h}$로 시작합니다. 분자를 $f(x)$와 $g(x)$에 관한 항으로 각각 분리한 뒤, 극한의 성질을 적용하면 각 함수의 미분 정의에 따라 $f'(x) + g'(x)$가 도출됩니다. 차의 미분법도 이와 동일한 논리로 증명되며, 상수배의 경우 상수 $c$가 극한 기호 밖으로 나갈 수 있어 $c \cdot f'(x)$가 됩니다.

### 의의와 응용
이 정리는 복잡한 다항식이나 다양한 함수를 미분할 때 계산 과정을 획기적으로 단축해 줍니다. 예를 들어 $y = 3x^2 + 5x - 2$를 미분할 때, 매번 극한을 계산하는 대신 각 항을 개별적으로 미분하여 더함으로써 $y' = 6x + 5$라는 결과를 쉽고 빠르게 얻을 수 있습니다. 이는 다항함수뿐만 아니라 삼각함수, 지수함수 등 모든 미분 가능한 함수를 다루는 데 있어 가장 기초적이고 필수적인 도구가 됩니다.

## 학습 체크

- 상수배가 포함된 식을 미분할 때 상수를 미분 결과에 어떻게 처리하는지 이해하고 있는가?
- 복잡한 다항식을 여러 개의 항으로 분리하여 미분할 수 있는가?

## 관련 개념
- **미분**: 함수의 변화율을 구하는 과정으로, 사칙연산 법칙은 미분을 수행하는 가장 기본적인 규칙입니다.
