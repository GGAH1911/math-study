# 미분의 계산

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수 $f(x)$의 특정 지점에서의 미분계수는 그 지점에서의 접선의 기울기이자 함수의 순간변화율을 의미합니다.

## 본문
함수 $f(x)$가 $x=a$에서 미분가능하다는 것은 다음 극한값이 존재한다는 것을 의미합니다.
$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$
이 극한값을 $x=a$에서의 미분계수 또는 도함수값이라고 부릅니다. 만약 함수가 어떤 구간 $I$ 내의 모든 점에서 미분가능하다면, 그 함수의 도함수는 $f'(x)$ 또는 $\tfrac{df}{dx}$로 나타냅니다.

### 직관과 기하적 의미
미분 계산은 함수 곡선 위의 한 점에서의 접선의 기울기를 구하는 과정입니다. 식의 분자인 $f(a+h) - f(a)$는 함숫값의 변화량을, 분모인 $h$는 독립변수의 변화량을 나타냅니다. 따라서 $h$가 $0$에 한없이 가까워질 때, 두 점을 잇는 할선의 기울기는 접선의 기울기로 수렴하게 됩니다. 이는 함수가 특정 지점에서 얼마나 빠르게 변화하는지를 나타내는 순간변화율의 의미를 갖습니다.

### 기본 성질
실제 계산 시에는 미분계수의 정의를 직접 이용하기도 하지만, 일반적으로는 도함수 공식과 미분법 정리를 활용하여 효율적으로 계산합니다. 예를 들어 $f(x) = x^2$일 때 $f'(1)$을 구하면 다음과 같습니다.
$$f'(1) = \lim_{h \to 0} \frac{(1+h)^2 - 1^2}{h} = \lim_{h \to 0} \frac{2h + h^2}{h} = \lim_{h \to 0} (2 + h) = 2$$
이처럼 멱함수, 삼각함수, 지수로그함수의 미분 공식과 곱의 미분, 합성함수의 미분법 등을 조합하여 복잡한 형태의 도함수도 구할 수 있습니다.

## 학습 체크

- 미분계수가 기하학적으로 접선의 기울기와 어떤 관계가 있는지 설명할 수 있는가?
- 미분계수의 정의를 이용하여 주어진 함수의 특정 지점에서의 미분계수를 직접 계산할 수 있는가?

## 관련 개념
