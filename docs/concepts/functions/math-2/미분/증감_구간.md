# 증감 구간

> **예제** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수 $f'(x)$의 부호가 양수이면 함수는 증가하고, 음수이면 감소합니다.

## 본문
함수 $f(x) = x^3 - 3x^2 + 2$의 증가 구간과 감소 구간을 구하시오.

### 단계별 풀이
**1단계: 도함수 구하기**
$f'(x) = 3x^2 - 6x = 3x(x - 2)$

**2단계: 도함수가 0이 되는 점 찾기**
$f'(x) = 0$일 때 $3x(x - 2) = 0$이므로 $x = 0$ 또는 $x = 2$입니다. 이 점들을 임계점이라고 합니다.

**3단계: 각 구간에서 도함수의 부호 판정**
임계점을 기준으로 수직선을 나누어 각 구간의 $f'(x)$ 부호를 확인합니다.
- $x < 0$ 구간: $f'(-1) = 3(-1)(-3) = 9 > 0$ (증가)
- $0 < x < 2$ 구간: $f'(1) = 3(1)(-1) = -3 < 0$ (감소)
- $x > 2$ 구간: $f'(3) = 3(3)(1) = 9 > 0$ (증가)

### 답과 변형
**답**
증가 구간: $(-\infty, 0]$, $[2, \infty)$
감소 구간: $[0, 2]$

**변형 및 주의사항**
- 구간의 끝점 포함 여부: 연속함수의 경우 일반적으로 닫힌 구간 $[a, b]$를 사용하여 표기합니다.
- 임계점 누락 주의: $f'(x) = 0$인 지점을 정확히 찾아야 구간을 올바르게 나눌 수 있습니다.
- 부호 판정 팁: 식 전체에 대푯값을 대입하기보다 각 인수의 부호를 개별적으로 확인하면 실수를 줄일 수 있습니다.

## 학습 체크
- 도함수의 부호가 함수의 증가와 감소에 어떻게 대응되는지 설명할 수 있는가?
- 임계점을 기준으로 구간을 나누고 각 구간의 부호를 정확히 판정할 수 있는가?
- 문제에서 요구하는 구간 표기법(개구간 또는 폐구간)을 정확히 적용할 수 있는가?

## 관련 개념
- **미분**: 함수의 변화율을 나타내는 도함수를 구하여 함수의 증감을 판단하는 도구로 사용됩니다.
