# 속도와 가속도

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
속도는 위치의 시간 변화율이며, 가속도는 속도의 시간 변화율로서 위치 함수의 이계 도함수이다.

## 본문
시간에 따라 변하는 물체의 위치를 시간 $t$의 함수 $s(t)$로 나타낼 때, **속도**(velocity)는 위치의 순간변화율인 도함수 $v(t) = s'(t) = \frac{ds}{dt}$로 정의됩니다. **가속도**(acceleration)는 속도의 순간변화율인 속도 함수의 도함수이자 위치 함수의 이계 도함수인 $a(t) = v'(t) = s''(t) = \frac{d^2s}{dt^2}$로 정의됩니다.

### 직관과 기하적 의미
속도는 물체가 얼마나 빠르게 위치를 이동하는지를 나타내는 척도입니다. 위치-시간 그래프 $s(t)$에서 속도는 그래프의 접선의 기울기와 같으므로, 기울기가 가파를수록 속도의 크기가 큽니다. 가속도는 속도가 시간에 따라 얼마나 빠르게 변하는지를 나타내며, 속도-시간 그래프 $v(t)$에서의 접선의 기울기와 같습니다. 또한 가속도는 위치 함수 $s(t)$ 그래프의 오목성(concavity)을 결정하는 요소입니다. 가속도가 양수이면 속도가 증가하는 방향으로 움직임이 변하고, 음수이면 속도가 감소하는 방향으로 움직임이 변합니다.

### 기본 성질
물체의 위치가 $s(t) = t^2 - 4t + 5$인 경우를 예로 들면, 속도는 $v(t) = 2t - 4$이며, 가속도는 $a(t) = 2$입니다. $t=1$일 때 가속도는 $2 \text{ m/s}^2$입니다. 또한 $t=0$일 때 위치 $s(0)=5$, 속도 $v(0)=-4$, 가속도 $a(0)=2$이므로, 초기에는 위치가 감소하는 방향으로 움직이고 있으나 가속도가 양수이므로 속도는 점점 증가하는 상태임을 알 수 있습니다.

## 학습 체크
- 위치 함수 $s(t)$의 이계 도함수가 양수일 때, $s(t)$ 그래프의 모양과 속도의 변화 방향은 어떠한가?
- 속도가 $0$인 지점과 가속도가 $0$인 지점이 다를 때, 물체의 운동 상태는 어떻게 변화하는가?

## 관련 개념
- **미분**: 위치 함수를 한 번 미분하면 속도가 되고, 속도 함수를 한 번 더 미분하면 가속도가 되는 관계를 갖습니다.
