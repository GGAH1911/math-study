# 실근의 개수 조건

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
방정식의 실근 개수는 함수의 그래프가 $x$축과 만나는 교점의 개수와 같으며, 이차방정식은 판별식을 통해, 일반 함수는 극값과 부호 변화를 통해 판정합니다.

## 본문
방정식 $f(x) = 0$이 실근을 가지는 개수를 판정하는 것은 함수의 그래프가 $x$축과 몇 개의 점에서 만나는지를 찾는 과정과 같습니다. 이차방정식 $ax^2 + bx + 0 = 0$ ($a \neq 0$)의 경우에는 판별식 $D = b^2 - 4ac$를 사용하여 $D > 0$이면 서로 다른 두 실근을, $D = 0$이면 중근을, $D < 0$이면 실근을 갖지 않음을 알 수 있습니다. 일반적인 방정식 $f(x) = g(x)$의 실근 개수를 구할 때는 두 함수의 차를 나타내는 $h(x) = f(x) - g(x)$를 정의한 후, 이 함수 $h(x)$의 영점 개수를 구하는 방식으로 접근합니다.

### 직관과 기하적 의미
실근의 개수는 기하학적으로 $y = f(x)$ 곡선과 $x$축 사이의 교점 개수로 해석됩니다. 두 곡선 $y = f(x)$와 $y = g(x)$의 교점 개수를 찾는 문제 역시, 두 식을 이항하여 만든 $h(x) = f(x) - g(x)$의 그래프가 $x$축과 만나는 점의 개수를 찾는 것과 동일한 의미를 가집니다.

### 기본 성질
함수의 연속성과 미분 가능성을 활용하면 복잡한 방정식의 근의 개수를 효율적으로 판정할 수 있습니다. 함수의 극값과 부호 변화를 조사하는 것이 핵심이며, 예를 들어 함수의 최솟값이 양수라면 해당 함수는 $x$축과 만나지 않으므로 방정식의 실근은 존재하지 않습니다.

## 학습 체크
- 이차방정식에서 판별식의 부호에 따른 실근의 종류를 정확히 구분할 수 있는가?
- 두 함수의 교점 개수를 구하기 위해 차이 함수를 설정하고 $x$축과의 교점을 찾는 원리를 이해하고 있는가?
- 함수의 극값과 부호 변화를 이용하여 실근의 존재 여부를 판정할 수 있는가?

## 관련 개념
- **이차방정식**: 판별식을 통해 실근의 개수를 결정하는 가장 기초적인 사례입니다.
- **함수의 극값**: 함수의 증감과 극값의 부호를 통해 방정식의 실근 개수를 판정하는 핵심 도구입니다.
- **사잇값 정리**: 함수의 연속성을 바탕으로 특정 구간에서 실근이 존재함을 증명하는 데 사용됩니다.
