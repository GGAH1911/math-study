# 절댓값함수의 미분가능성

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
절댓값을 포함한 함수 $f(x) = |g(x)|$는 절댓값 내부 함수 $g(x)$가 $0$이 되는 지점에서 $g(x)$의 부호 변화 여부에 따라 미분가능성이 결정됩니다.

## 본문
절댓값을 포함한 함수의 미분가능성은 절댓값 내부가 $0$이 되는 지점에서 결정됩니다. 가장 기본적인 예시인 $f(x) = |x|$는 $x = 0$에서 미분불가능합니다. 이는 $x=0$에서의 좌미분계수와 우미분계수가 서로 다르기 때문입니다. 구체적으로 $\lim_{h \to 0^-} \frac{|h|}{h} = -1$이고 $\lim_{h \to 0^+} \frac{|h|}{h} = 1$이므로, $x=0$에서 미분계수가 존재하지 않습니다.

일반적으로 함수 $g(x)$에 대하여 $f(x) = |g(x)|$가 $x = a$에서 미분가능하기 위한 조건은 다음과 같습니다. 우선 $g(a) \neq 0$인 지점에서는 항상 미분가능합니다. 만약 $g(a) = 0$이라면, $g(x)$가 $x = a$를 지나면서 부호를 바꾸지 않을 때(즉, $x=a$에서 접하는 경우)에만 $f(x)$가 미분가능합니다.

### 직관과 기하적 의미
절댓값 함수는 음수 영역을 $x$축에 대해 대칭시킨 형태를 가집니다. $f(x) = |x|$의 그래프를 보면 $x = 0$에서 그래프가 꺾이는 점(첨점)이 나타납니다. 이 지점에서는 좌측과 우측의 기울기가 서로 다르기 때문에 한 점에서의 순간변화율인 도함수가 정의되지 않습니다. 예를 들어 $f(x) = |x^2 - 1|$의 경우, $x = \pm 1$에서 내부 식이 $0$이 되지만 부호가 바뀌며 그래프가 꺾이므로 해당 지점들에서 미분불가능합니다.

### 기본 성질
함수 $f(x) = |2x - 3|$을 예로 들면, 내부 식이 $0$이 되는 $x = \frac{3}{2}$를 기준으로 구간을 나누어 생각할 수 있습니다. $x < \frac{3}{2}$일 때 $f(x) = -2x + 3$이므로 미분계수는 $-2$이고, $x > \frac{3}{2}$일 때 $f(x) = 2x - 3$이므로 미분계수는 $2$입니다. 좌우 미분계수가 다르므로 $x = \frac{3}{2}$에서 미분불가능합니다.

## 학습 체크

- 그래프 상에서 '꺾인 점'이 나타나는 지점과 미분불가능한 지점의 관계를 설명할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 함수의 극값이나 그래프의 개형을 파악할 때 절댓값 함수의 미분가능성을 판단하는 것이 필수적입니다.
