# 평균변화율

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수 $f(x)$에서 $x$의 값이 $a$에서 $b$로 변할 때, 두 점 사이의 함숫값 변화량을 $x$의 변화량으로 나눈 값입니다.

## 본문
함수 $f(x)$에서 $x$가 $a$에서 $b$로 변할 때, **평균변화율**은 다음과 같이 정의합니다:
$$\text{평균변화율} = \frac{f(b) - f(a)}{b - a} \quad (a \neq b)$$
일반적으로 $h \neq 0$인 작은 수에 대해 $\tfrac{f(a+h) - f(a)}{h}$로도 표현할 수 있습니다.

### 직관과 기하적 의미
평균변화율은 함수 그래프 위의 두 점 $(a, f(a))$와 $(b, f(b))$를 잇는 **할선(secant line)의 기울기**를 의미합니다. 이는 구간 $[a, b]$에서 함수가 평균적으로 얼마나 빠르게 변하는지를 나타내는 척도입니다. 예를 들어, 자동차가 2시간 동안 100km를 이동했다면 평균 시속은 50km/h가 되는데, 이는 이동 과정 중 속도가 변했을지라도 전체적으로 시간당 50km씩 변했다는 것을 의미합니다.

### 기본 성질
평균변화율은 구간 내에서의 평균적인 변화량을 측정하며, 이는 미분 개념으로 나아가기 위한 필수적인 단계입니다. $h$가 $0$에 한없이 가까워질 때 평균변화율의 극한값은 곧 **순간변화율(도함수)**이 됩니다.

## 학습 체크
- $a=b$인 경우 분모가 $0$이 되어 평균변화율을 정의할 수 없음을 이해하고 있는가?
- 함수 그래프에서 두 점을 잇는 직선의 기울기가 왜 평균변화율과 같은지 설명할 수 있는가?
- $f(x) = x^2$에서 $x=1$부터 $x=3$까지의 평균변화율을 계산할 수 있는가?

## 관련 개념
- **미분**: 평균변화율에서 $x$의 변화량인 $h$가 $0$에 가까워질 때의 극한값으로, 특정 지점에서의 순간적인 변화를 나타냅니다.
