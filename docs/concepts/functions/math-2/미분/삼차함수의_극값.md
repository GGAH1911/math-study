# 삼차함수의 극값

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
삼차함수의 극값은 도함수의 부호가 변하는 지점에서 발생하는 함수의 최댓값 또는 최솟값입니다.

## 본문
삼차함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)에서, $f'(x) = 0$인 점 $x = x_0$을 지나면서 도함수 $f'(x)$의 부호가 바뀌는 경우, 그 점을 **극값을 갖는 점**이라 하고, $f(x_0)$을 **극값**(극댓값 또는 극솟값)이라고 정의합니다. 더 정확히, $x_0$ 좌측에서 $f'(x) > 0$이고 우측에서 $f'(x) < 0$이면 **극댓값**, 반대면 **극솟값**입니다.

### 직관과 기하적 의미
도함수 $f'(x)$는 함수의 기울기를 나타냅니다. 삼차함수의 도함수는 이차함수이므로, 최대 2개의 영점을 가질 수 있습니다. 기하학적으로 극값은 그래프에서 "봉우리"(극댓값) 또는 "계곡"(극솟값)에 해당하며, 이는 주어진 구간에서 함숫값의 상대적 최댓값이나 최솟값을 찾을 때 필수적인 요소입니다.

### 기본 성질
- **극값이 2개 존재**: 도함수가 서로 다른 2개의 실근을 가지면, 한 점에서 극댓값, 다른 점에서 극솟값을 가집니다.
- **극값이 없음**: 도함수가 중근을 가지거나 실근이 없으면, 극값이 없고 함수는 항상 증가 또는 항상 감소합니다.
- **예시**: $f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 $x = -1, 1$에서 극값을 가지며, 극댓값은 $f(-1) = 2$, 극솟값은 $f(1) = -2$입니다.

## 학습 체크
- 도함수의 부호가 바뀌지 않고 $f'(x)=0$인 지점이 존재할 때, 이를 극값이라고 할 수 있는가?
- 삼차함수의 최고차항 계수의 부호에 따라 극댓값과 극솟값의 위치 관계가 어떻게 변하는가?

## 관련 개념
- **도함수의 활용 심화**: 극값을 기준으로 함수의 증가와 감소 구간을 나누어 함수의 그래프 개형을 정확하게 그리는 과정으로 연결됩니다.
