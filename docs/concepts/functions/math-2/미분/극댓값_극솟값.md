# 극댓값 극솟값

> **예제** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수의 부호가 양에서 음으로 변하면 극댓값, 음에서 양으로 변하면 극솟값을 가집니다.

## 본문
함수 $f(x) = x^3 - 3x^2 - 9x + 5$의 극댓값과 극솟값을 구하시오.

### 단계별 풀이
**1단계: 도함수 구하기**
극값은 도함수가 $0$이 되는 점에서 나타나므로 먼저 도함수를 계산합니다.
$$f'(x) = 3x^2 - 6x - 9$$

**2단계: 극값 후보 찾기**
$f'(x) = 0$을 풀어서 도함수가 $0$이 되는 $x$ 값을 구합니다.
$$3x^2 - 6x - 9 = 0 \Rightarrow x^2 - 2x - 3 = 0$$
$$(x - 3)(x + 1) = 0 \Rightarrow x = -1 \text{ 또는 } x = 3$$

**3단계: 도함수의 부호 변화로 극값 판정**
임계점을 기준으로 도함수의 부호가 어떻게 변하는지 확인합니다.
| 구간 | $x < -1$ | $-1 < x < 3$ | $x > 3$ |
|------|----------|-------------|--------|
| $f'(x)$의 부호 | + | − | + |
| $f(x)$의 증감 | ↗ | ↘ | ↗ |

- $x = -1$: 부호가 $+$에서 $-$로 변하므로 **극댓값**을 가집니다.
- $x = 3$: 부호가 $-$에서 $+$로 변하므로 **극솟값**을 가집니다.

**4단계: 극값의 $y$좌표 계산**
- 극댓값: $f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) + 5 = 10$
- 극솟값: $f(3) = (3)^3 - 3(3)^2 - 9(3) + 5 = -22$

### 답과 변형
극댓값은 $\mathbf{10}$ ($x=-1$에서), 극솟값은 $\mathbf{-22}$ ($x=3$에서)입니다.

**주의사항**
도함수의 값이 $0$이 되더라도 부호 변화가 없다면 극값이 아닌 변곡점이 될 수 있으므로 반드시 부호 변화를 확인해야 합니다. 또한 이계도함수 $f''(x) = 6x - 6$를 이용하여 $f''(-1) < 0$이면 극대, $f''(3) > 0$이면 극소임을 판정할 수도 있습니다.

## 학습 체크
- 도함수의 부호가 바뀌지 않는 지점은 왜 극값이 될 수 없는가?
- 이계도함수를 이용한 판정법과 부호 변화표를 이용한 판정법의 차이는 무엇인가?

## 관련 개념
- **미분**: 함수의 변화율을 나타내는 도함수를 구하여 극값의 후보를 찾는 핵심 도구로 사용됩니다.
