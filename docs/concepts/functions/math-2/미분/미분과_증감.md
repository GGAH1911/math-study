# 미분과 증감

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수 $f'(x)$의 부호를 통해 함수 $f(x)$가 증가하는 구간과 감소하는 구간을 판정할 수 있습니다.

## 본문
함수 $f(x)$가 구간 $(a, b)$에서 미분가능할 때, $f'(x) > 0$이면 $f$는 $(a, b)$에서 증가함수이고, $f'(x) < 0$이면 $f$는 $(a, b)$에서 감소함수이며, $f'(x) = 0$이면 $f$는 $(a, b)$에서 상수함수입니다.

### 직관과 기하적 의미
도함수 $f'(x)$는 점 $(x, f(x))$에서 그래프에 그은 접선의 기울기를 의미합니다. 접선의 기울기가 양수이면 그래프가 오른쪽 위로 향하며 올라가고, 기울기가 음수이면 오른쪽 아래로 내려가는 형태를 띱니다. 즉, 어떤 지점에서의 순간 변화율이 양수라는 것은 그 근처에서 함수의 값이 커지고 있음을 직관적으로 나타냅니다. 따라서 도함수의 부호를 조사하는 것은 함수의 증감 상태를 파악하는 핵심적인 방법입니다.

### 기본 성질
함수의 증감을 판정할 때는 $f'(x) = 0$인 지점을 기준으로 좌우 부호 변화를 확인해야 합니다. 주의할 점은 $f'(x) = 0$인 점이 존재하더라도 그 지점 전후에서 부호가 바뀌지 않는다면 증감이 변하지 않는다는 것입니다. 예를 들어 $f(x) = x^3$의 경우 $x = 0$에서 $f'(0) = 0$이지만, $x=0$ 전후로 도함수의 부호가 모두 양수이므로 전체 구간에서 증가함수입니다.

## 학습 체크
- $f'(x) > 0$인 구간과 $f'(x) < 0$인 구간을 나누어 함수의 증감을 설명할 수 있는가?
- $f'(x) = 0$인 지점에서 함수의 증감이 반드시 변하는지, 아니면 그대로 유지될 수 있는지 구분할 수 있는가?

## 관련 개념
- **지수함수와 로그함수**: 이 함수들은 미분했을 때 항상 도함수의 부호가 일정하므로, 전 구간에서 증가하거나 감소하는 단조 함수로서의 성질을 가집니다.
