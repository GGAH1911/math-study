# 3차 함수의 미분

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
3차 함수의 도함수는 2차 함수이며, 이 도함수의 부호와 실근의 개수에 따라 3차 함수의 극값과 그래프의 개형이 결정됩니다.

## 본문
3차 함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)의 도함수는 거듭제곱 법칙을 적용하여 $f'(x) = 3ax^2 + 2bx + c$로 구할 수 있습니다. 이때 도함수 $f'(x)$는 2차 함수이며, 최고차항의 계수인 $a$의 부호에 따라 포물선의 방향이 결정됩니다. 이 2차 도함수의 값은 원래 함수인 3차 함수의 증감과 극값을 결정하는 핵심적인 역할을 합니다.

### 직관과 기하적 의미
도함수 $f'(x)$의 값은 특정 지점 $x$에서 곡선에 그은 접선의 기울기를 의미하며, 이는 함수가 해당 지점에서 얼마나 빠르게 증가하거나 감소하는지를 나타내는 순간 변화율입니다. 또한, $f'(x) = 0$을 만족하는 지점은 함수의 기울기가 0이 되는 지점으로, 3차 함수의 극값을 찾는 기준이 됩니다. 3차 함수의 그래프 모양은 도함수인 2차 함수의 형태에 따라 $S$자 모양의 굴곡을 갖거나, 혹은 단조 증가 또는 단조 감소하는 곡선의 형태를 띠게 됩니다.

### 기본 성질
도함수 $f'(x) = 3ax^2 + 2bx + c$의 판별식 $D = 4b^2 - 12ac$에 따라 3차 함수의 극값 존재 여부가 결정됩니다.
- $D > 0$: 서로 다른 두 실근을 가지므로, 극댓값과 극솟값이 각각 하나씩 존재합니다.
- $D = 0$: 중근을 가지므로, 극값이 존재하지 않고 변곡점 형태를 보입니다.
- $D < 0$: 실근이 없으므로, 극값이 존재하지 않으며 함수는 계속 증가하거나 계속 감소합니다.

## 학습 체크
- 3차 함수의 도함수가 2차 함수임을 이용하여 함수의 증가와 감소 구간을 어떻게 구할 수 있는가?
- 도함수의 판별식 $D$의 부호에 따라 3차 함수의 그래프 개형이 어떻게 달라지는가?

## 관련 개념
- **도함수의 활용 심화**: 3차 함수의 극값과 그래프의 개형을 이용하여 함수의 최대값과 최소값을 구하거나 방정식과 부등식의 해의 개수를 판별하는 데 활용됩니다.
