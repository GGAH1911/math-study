# 3차함수의 극값

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
3차함수가 극값을 갖기 위해서는 도함수가 서로 다른 두 실근을 가져야 하며, 이때 함수는 증가와 감소의 방향을 바꾸며 극대값과 극소값을 갖습니다.

## 본문
3차함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)에서 **극값**이란 어떤 점 근처에서 함수값이 최대 또는 최소가 되는 값을 의미하며, 극값을 갖는 $x$의 값을 **극값점**이라 합니다. 3차함수가 극값을 가지려면 도함수 $f'(x) = 3ax^2 + 2bx + c$가 **서로 다른 두 실근**을 가져야 합니다. 이 두 근을 $\alpha < \beta$라 할 때, $x = \alpha$와 $x = \beta$에서 함수는 극값을 갖습니다.

### 직관과 기하적 의미
도함수는 함수의 기울기를 나타냅니다. $f'(x) = 0$인 지점에서는 접선의 기울기가 $0$이 되므로, 함수는 증가에서 감소로 또는 감소에서 증가로 방향을 전환하게 됩니다. 3차함수는 그래프의 모양에 따라 최대 2개의 극값을 가질 수 있습니다. 만약 $f'(x) = 0$이 서로 다른 두 실근을 가지면 S자 모양을 그리며 극대값 1개와 극소값 1개를 갖지만, 중근이나 허근을 가지면 방향 전환 없이 계속 증가하거나 감소하여 극값이 존재하지 않습니다. 이때 주의할 점은 극값이 함수의 전체 최댓값이나 최솟값을 의미하는 것은 아니라는 점입니다.

### 기본 성질
- $f'(x) = 0$의 판별식 $D > 0$이면 극대값과 극소값을 모두 가집니다.
- $f'(x) = 0$의 판별식 $D \leq 0$이면 극값을 갖지 않습니다.
- 예시: $f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 0$을 만족하는 $x = -1$에서 극대값 $2$를, $x = 1$에서 극소값 $-2$를 갖습니다.

## 학습 체크
- 도함수의 판별식이 $0$보다 커야만 3차함수가 극값을 가질 수 있음을 이해했는가?
- 극값이 함수의 전체 범위에서의 최댓값/최솟값과 어떻게 다른지 구분할 수 있는가?

## 관련 개념
- **방정식과 부등식**: 도함수가 $0$이 되는 지점을 찾기 위해 이차방정식을 풀어야 하며, 극값의 존재 여부는 부등식의 성질과 밀접하게 연관됩니다.
