# 극값 최적화

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수의 그래프에서 국소적인 최댓값과 최솟값을 찾는 과정으로, 미분을 통해 최적의 상태를 결정하는 수학적 도구입니다.

## 본문
극값(極値)은 함수가 특정 점에서 그 근처의 모든 점보다 큰 값(극대값) 또는 작은 값(극소값)을 갖는 경우를 의미합니다. 일변수 함수 $f(x)$에서 $x = a$를 포함하는 어떤 구간의 모든 $x$에 대해 $f(x) \leq f(a)$이면 $f(a)$를 **극대값**, $f(x) \geq f(a)$이면 $f(a)$를 **극소값**이라고 정의합니다. 이러한 극값을 찾는 과정은 주어진 제약 조건 하에서 목적함수의 최댓값 또는 최솟값을 구하는 최적화(最適化) 문제를 해결하는 가장 핵심적인 수학적 방법론입니다.

### 직관과 기하적 의미
함수의 그래프 상에서 극값은 산의 봉우리(극대값) 또는 골짜기의 밑바닥(극소값)에 해당합니다. 미분이 가능한 매끄러운 함수라면 극값을 갖는 지점에서 접선의 기울기가 $0$이 되는 $f'(a) = 0$의 상태를 보입니다.

### 기본 성질
함수가 미분가능할 때, 극값을 갖는 점에서는 도함수의 값이 $0$이 됩니다. 이는 최적화 문제를 풀 때 후보 지점을 압축하는 중요한 기준이 됩니다. 예를 들어 $f(x) = x^2 - 4x + 3$의 경우, 도함수 $f'(x) = 2x - 4$를 통해 $x = 2$에서 극소값 $f(2) = -1$을 가짐을 알 수 있습니다.
