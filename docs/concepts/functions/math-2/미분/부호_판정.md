# 부호 판정

도함수 $f'(x)$의 부호를 통해 함수의 증감과 극값을 결정하는 절차입니다. 수학2 미분 단원에서 그래프 개형 분석의 핵심입니다.

## 정의

미분가능한 함수 $f(x)$에 대하여 다음이 성립합니다.
- $f'(x) > 0$인 구간에서 $f$는 **증가**.
- $f'(x) < 0$인 구간에서 $f$는 **감소**.
- $f'(a) = 0$이고 좌우에서 $f'$의 부호가 양→음이면 $x = a$에서 극대, 음→양이면 극소.

부호 판정은 $f'(x) = 0$의 근들을 기준으로 수직선을 나눠 각 구간에서 $f'$의 부호를 점검하거나, 인수분해된 $f'(x)$의 부호 변화 표(증감표)를 작성해 진행합니다.

## 예시

$f(x) = x^3 - 6x^2 + 9x$의 증감을 살펴봅니다. $f'(x) = 3x^2 - 12x + 9 = 3(x-1)(x-3)$. $f'(x) = 0$의 해는 $x = 1, 3$이고 부호는
- $x < 1$: $(+)(+) > 0$ → 증가,
- $1 < x < 3$: $(+)(-) < 0$ → 감소,
- $x > 3$: $(+)(+) > 0$ → 증가.

따라서 $x = 1$에서 극댓값 $f(1) = 4$, $x = 3$에서 극솟값 $f(3) = 0$을 가집니다.
