# 도함수의 기하학적 의미

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 정확한 진술

함수 $f(x)$의 도함수 $f'(a)$는 점 $(a, f(a))$에서의 접선의 기울기입니다. 더 정확하게는, $f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$로 정의되며, 이 극한값이 점 $(a, f(a))$를 지나는 **접선의 기울기**를 나타냅니다.

## 직관과 기하학적 의미

도함수를 기하학적으로 이해하려면 할선(secant line)에서 접선(tangent line)으로 변해가는 과정을 생각해보세요. $x = a$에서 $x = a+h$까지의 할선의 기울기는 $\frac{f(a+h) - f(a)}{h}$입니다. $h$를 0에 가까워질수록 두 점이 한 점으로 수렴하고, 극한에서 할선이 **접선**이 되는 순간 그 기울기가 $f'(a)$입니다.

기하학적으로 보면:
- $f'(a) > 0$: 점 $(a, f(a))$에서 그래프가 **오른쪽 위로** 향함
- $f'(a) < 0$: 점 $(a, f(a))$에서 그래프가 **오른쪽 아래로** 향함  
- $f'(a) = 0$: 점 $(a, f(a))$에서 그래프의 접선이 **수평**

점 $(a, f(a))$에서의 접선의 방정식은 $$y - f(a) = f'(a)(x - a)$$ 또는 $$y = f'(a)(x - a) + f(a)$$입니다.

## 한 줄 예

$f(x) = x^2$일 때, $f'(2) = 4$이므로 점 $(2, 4)$에서의 접선은 기울기가 4인 직선 $y = 4(x-2) + 4 = 4x - 4$입니다. (검산: `sympy.diff(x**2, x).subs(x, 2)` → 4)
