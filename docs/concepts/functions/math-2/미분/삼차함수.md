# 삼차함수

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
최고차항의 계수가 $0$이 아닌 3차 다항식으로, 변곡점을 중심으로 점대칭인 형태를 가지며 도함수의 실근 개수에 따라 극값의 존재 여부가 결정됩니다.

## 본문
삼차함수는 최고차항이 3차인 다항함수로, 일반형은 $f(x) = ax^3 + bx^2 + cx + d$ ($a \neq 0$)로 나타냅니다. 여기서 $a$는 최고차항의 계수이며, $b, c, d$는 각각 2차, 1차, 상수항의 계수로서 모두 실수입니다.

### 직관과 기하적 의미
삼차함수의 그래프 개형은 도함수 $f'(x) = 3ax^2 + 2bx + c$의 실근 상태에 따라 결정됩니다. 도함수가 서로 다른 두 실근을 가지면 그래프는 극댓값과 극솟값을 모두 갖는 전형적인 S자 곡선을 그리며, 도함수가 중근을 갖거나 실근이 없는 경우에는 극값 없이 단조 증가하거나 단조 감소하는 형태를 보입니다.

### 기본 성질
삼차함수는 그래프의 볼록성이 변하는 지점인 변곡점을 반드시 하나 가집니다. 변곡점은 이계도함수 $f''(x) = 6ax + 2b = 0$을 만족하는 $x = -\frac{b}{3a}$ 지점이며, 삼차함수의 그래프는 이 변곡점을 기준으로 완벽한 점대칭 구조를 이룹니다.

## 학습 체크
- 도함수의 판별식을 통해 극값이 2개 존재하는 조건과 그렇지 않은 조건을 구분할 수 있는가?
- 변곡점의 좌표를 구하고, 해당 점을 기준으로 그래프가 점대칭임을 확인할 수 있는가?

## 관련 개념
- **도함수의 활용 심화**: 삼차함수의 극값과 변곡점의 성질을 이용하여 함수의 그래프 개형을 추론하고 방정식의 실근 개수를 판별하는 데 활용됩니다.
