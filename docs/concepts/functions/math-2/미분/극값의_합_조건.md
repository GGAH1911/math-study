# 극값의 합 조건

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
삼차함수의 변곡점이 점대칭 중심이 되어, 두 극값의 합은 변곡점에서의 함수값의 2배와 같다.

## 본문
함수 $f(x)$가 극값을 가질 조건과 그 극값들의 합이 만족하는 성질을 극값의 합 조건이라 합니다. 특히 삼차함수 $f(x) = ax^3 + bx^2 + cx + d$에서, 도함수 $f'(x) = 3ax^2 + 2bx + c = 0$이 서로 다른 두 실근 $\alpha, \beta$ ($\alpha < \beta$)를 가질 때, 극댓값 $M = f(\alpha)$와 극솟값 $m = f(\beta)$의 합 $M + m$은 함수의 기본 매개변수들과 일정한 관계를 갖습니다.

### 직관과 기하적 의미
삼차함수는 정확히 하나의 변곡점을 가지며, 이 점의 $x$좌표는 극값을 주는 두 근의 산술평균인 $\frac{\alpha+\beta}{2} = -\frac{b}{3a}$와 같습니다. 기하학적으로, 변곡점에서의 함수값을 $c$라 하면, 그 점을 지나고 수평인 직선이 삼차함수의 중심을 이루어 극값의 합은 변곡점 함수값의 2배가 됩니다. 이는 삼차함수가 변곡점에 대해 점대칭이라는 성질에서 비롯되는 핵심적인 특징입니다.

### 기본 성질
삼차함수 $f(x) = x^3 - 3x + 1$을 예로 들면, 도함수 $f'(x) = 3x^2 - 3 = 0$을 통해 극값의 위치 $x = \pm1$을 구할 수 있습니다. 이때 극댓값은 $f(-1) = 3$, 극솟값은 $f(1) = -1$이 되어 극값의 합은 $2$가 됩니다. 한편, 변곡점의 $x$좌표인 $0$에서의 함수값 $f(0) = 1$에 $2$를 곱하면 극값의 합과 일치함을 확인할 수 있습니다.

## 학습 체크
- 삼차함수의 도함수가 서로 다른 두 실근을 갖지 않을 때(중근을 갖거나 허근을 가질 때)도 극값의 합 성질을 논할 수 있는가?
- 변곡점의 좌표를 이용하여 극값의 합을 구하는 과정이 삼차함수의 점대칭 성질과 어떻게 연결되는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수의 극점과 삼차함수의 변곡점 사이의 관계를 이해함으로써 함수의 그래프 개형을 더욱 정밀하게 추론할 수 있습니다.
