# 도함수의 성질

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수는 함수의 합과 실수배에 대해 선형성을 가지며, 곱의 미분법과 합성함수의 미분법을 통해 복잡한 함수의 변화율을 계산할 수 있습니다.

## 본문
미분가능한 함수 $f(x)$, $g(x)$와 상수 $c$에 대하여 도함수는 다음과 같은 성질을 만족합니다. 우선 선형성에 의해 $[cf(x)]' = cf'(x)$이고 $[f(x) + g(x)]' = f'(x) + g'(x)$입니다. 또한 두 함수의 곱에 대해서는 $[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$라는 곱의 미분법이 성립하며, 합성함수에 대해서는 $\{f(g(x))\}' = f'(g(x)) \cdot g'(x)$라는 연쇄 법칙이 적용됩니다.

### 직관과 기하적 의미
선형성은 도함수가 선형 연산자임을 나타냅니다. 이는 함수를 더한 후 미분하는 것이 각각을 미분하여 더하는 것과 같음을 의미하며, 연산의 순서가 바뀌어도 결과가 동일함을 보여줍니다. 곱의 미분법은 두 함수의 변화가 서로 겹쳐지는 효과를 나타냅니다. 즉, 첫 번째 함수가 변할 때의 영향과 두 번째 함수가 변할 때의 영향이 합쳐진 결과입니다. 합성함수의 미분은 변화가 단계적으로 전파되는 과정을 설명합니다. 안쪽 함수의 변화율에 바깥쪽 함수의 변화율을 곱함으로써 각 단계의 민감도를 모두 반영합니다.

### 기본 성질
- 선형성: $[cf(x)]' = cf'(x)$, $[f(x) + g(x)]' = f'(x) + g'(x)$
- 곱의 미분법: $[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$
- 합성함수의 미분: $\{f(g(x))\}' = f'(g(x)) \cdot g'(x)$

## 학습 체크
- 함수가 여러 항의 합으로 이루어져 있을 때, 각 항을 개별적으로 미분하여 더해도 결과가 같은가?
- 두 함수의 곱을 미분할 때, 단순히 각각의 도함수를 곱하는 것이 아니라 곱의 미분법 공식을 정확히 적용했는가?
- 합성함수를 미분할 때, 안쪽 함수의 미분값을 빠뜨리지 않고 바깥쪽 함수의 미분값과 곱해주었는가?

## 관련 개념
- **정적분의 활용**: 도함수의 성질을 통해 구한 도함수를 다시 적분함으로써 함수의 변화량과 넓이를 계산할 수 있습니다.
