# 3차함수

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
최고 차수 항의 계수가 $0$이 아닌 $3$차 다항식으로, 변곡점을 하나 가지며 도함수의 판별식에 따라 극값의 개수가 결정되는 함수입니다.

## 본문
3차함수는 최고 차수 항이 $3$인 다항함수를 의미하며, 일반형은 $f(x) = ax^3 + bx^2 + cx + d \quad (a \neq 0)$로 나타냅니다. 여기서 $a, b, c, d$는 실수이며, 반드시 $a \neq 0$이어야만 3차함수의 정의를 만족합니다. 만약 $a=0$이 되면 차수가 낮아져 2차 이하의 함수가 되기 때문입니다.

### 직관과 기하적 의미
3차함수의 그래프는 곡선의 오목한 방향이 바뀌는 지점인 변곡점을 항상 정확히 하나 가집니다. 또한 도함수 $f'(x) = 3ax^2 + 2bx + c$가 2차함수라는 점을 이용하면 극값의 존재 여부를 판별할 수 있습니다. 도함수의 판별식 $D = 4b^2 - 12ac$의 값에 따라 그래프의 개형이 달라집니다. $D > 0$이면 극댓값과 극솟값을 각각 하나씩 가져 총 2개의 극값을 가집니다. $D = 0$이면 변곡점에서 접선의 기울기가 $0$이 되지만 극값은 존재하지 않습니다. $D < 0$이면 함수는 항상 증가하거나 항상 감소하는 형태를 띠며 극값을 갖지 않습니다.

### 기본 성질
- 극값과 변곡점의 위치를 파악하기 위해서는 도함수의 부호 변화를 조사하는 것이 필수적입니다.
- 예시 함수 $f(x) = x^3 - 3x^2 + 2x + 1$의 경우, 도함수 $f'(x) = 3x^2 - 6x + 2$의 판별식이 $12$로 양수이므로 극값이 2개 존재하며, 그 $x$ 좌표는 $1 \pm \frac{\sqrt{3}}{3}$입니다.

## 학습 체크
- 최고 차수 항의 계수가 $0$이 아님을 확인했는가?
- 도함수의 판별식 $D$의 부호에 따른 그래프의 개형을 구분할 수 있는가?
- 변곡점의 정의와 3차함수 그래프에서의 위치를 이해하고 있는가?

## 관련 개념
- **도함수의 활용 심화**: 3차함수의 극값과 변곡점의 성질을 이용하여 함수의 증가와 감소, 극대와 극소를 판정하고 그래프의 개형을 추론하는 데 활용됩니다.
