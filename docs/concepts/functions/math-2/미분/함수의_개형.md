# 함수의 개형

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수의 정의역, 치역, 증감, 극값 등을 종합하여 함수의 전체적인 모양을 파악하는 것입니다.

## 본문
함수 $f(x)$의 개형이란 함수의 정의역, 치역, 극한 거동, 극값, 증감 구간, 변곡점, 불연속점 등의 특성을 종합적으로 파악하여 나타낸 그래프의 전체적인 모양을 의미합니다. 수학2 과정에서는 주로 미분 가능한 함수에 대하여 도함수의 부호를 분석함으로써 함수의 개형을 결정합니다. 도함수 $f'(x)$의 값이 $0$보다 크면 함수는 증가하고, $0$보다 작으면 함수는 감소하며, $f'(x)=0$인 지점은 극값이나 변곡점이 될 수 있는 중요한 후보 지점이 됩니다.

### 직관과 기하적 의미
함수의 개형을 파악한다는 것은 함수의 전체적인 생김새를 이해하는 과정입니다. 도함수를 통해 함수가 어느 구간에서 올라가고 내려가는지, 그리고 어디서 최고점이나 최저점을 갖는지 파악함으로써 함수의 움직임을 시각적으로 재구성할 수 있습니다. 예를 들어 $f(x) = x^3 - 3x$의 경우, 도함수 $f'(x) = 3(x^2 - 1)$을 통해 $x = -1$과 $x = 1$에서 극값을 가짐을 알 수 있습니다. 이를 통해 $x < -1$ 구간에서는 증가, $-1 < x < 1$ 구간에서는 감소, $x > 1$ 구간에서는 다시 증가하는 패턴을 확인하여 그래프의 모양을 머릿속으로 그릴 수 있습니다.

### 기본 성질
- $f'(x) > 0$인 구간에서 함수는 증가합니다.
- $f'(x) < 0$인 구간에서 함수는 감소합니다.
- $f'(x) = 0$인 점은 극대, 극소 또는 변곡점의 후보가 됩니다.

## 학습 체크
- 도함수의 부호가 변하는 지점에서 함수의 극값이 발생하는가?
- 함수의 증감과 극값의 위치를 통해 그래프의 전체적인 흐름을 설명할 수 있는가?

## 관련 개념
- **함수의 극한과 연속**: 함수의 극한과 연속성은 그래프가 끊기지 않고 이어져 있는지 또는 특정 지점에서 어떻게 접근하는지를 결정하여 개형의 기초가 됩니다.
