# 극값 판정

> **정리** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
$f'(a)=0$일 때 $f''(a)$의 부호에 따라 $x=a$에서의 극대와 극소를 판정할 수 있습니다.

## 본문
함수 $f$가 $x=a$를 포함한 열린구간에서 미분가능하고 $f'(a)=0$일 때, $f''(a) > 0$이면 $f$는 $x=a$에서 극솟값을 갖고 $f''(a) < 0$이면 $f$는 $x=a$에서 극댓값을 갖습니다. 이를 2차 도함수 판정법이라 합니다.

### 증명 스케치
$f''(a) > 0$이면 $x=a$ 근처에서 $f'$이 증가함을 의미합니다. $f'(a)=0$이므로 $a$의 왼쪽에서는 $f'(x) < 0$이고 오른쪽에서는 $f'(x) > 0$이 되어 함수가 감소하다 증가하므로 극솟값을 갖습니다. 이를 테일러 근사로 보면 $f(a+h) \approx f(a) + \frac{1}{2}f''(a)h^2$이 되는데, $f''(a) > 0$이면 $h^2$ 항에 의해 $f(a+h) > f(a)$가 성립하여 극솟값이 됩니다.

### 의의와 응용
1차 도함수의 부호 변화를 일일이 조사하지 않고 $f''(a)$의 부호만으로 극값을 빠르게 판정할 수 있어 계산이 효율적입니다. 다만 $f''(a)=0$인 경우에는 이 방법을 사용할 수 없으므로 1차 도함수 판정법을 사용해야 합니다. 예를 들어 $f(x) = x^3 - 3x$에서 $f'(x)=0$인 $x=1$에 대해 $f''(1)=6 > 0$이므로 극솟값을, $x=-1$에 대해 $f''(-1)=-6 < 0$이므로 극댓값을 가집니다.

## 학습 체크
- $f''(a)=0$인 경우 왜 이 판정법을 사용할 수 없는지 설명할 수 있는가?
- 주어진 함수에 대해 1차 도함수와 2차 도함수를 구하여 극값을 판정할 수 있는가?

## 관련 개념
- **미분**: 함수의 변화율을 나타내며, 1차 도함수의 값이 0인 지점을 찾는 기초가 됩니다.
