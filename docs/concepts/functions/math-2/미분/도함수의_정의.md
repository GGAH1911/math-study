# 도함수의 정의

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수는 함수의 특정 지점에서의 순간변화율을 나타내며, 극한을 통해 정의되는 접선의 기울기입니다.

## 본문
함수 $f(x)$의 도함수는 다음 극한이 존재할 때 정의됩니다:
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
또는 $a$에서의 도함수는 다음과 같이 나타낼 수 있습니다:
$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$
이 극한값이 존재하면 함수 $f(x)$는 $x = a$에서 미분가능하다고 하며, 각 점에서 정의된 $f'(x)$를 도함수라고 합니다.

### 직관과 기하적 의미
도함수는 함수의 순간변화율을 의미하며, 기하학적으로는 곡선 위의 한 점에서의 접선의 기울기를 나타냅니다. $h$가 $0$에 가까워질 때, $\frac{f(x+h) - f(x)}{h}$는 두 점 $(x, f(x))$와 $(x+h, f(x+h))$를 잇는 할선의 기울기입니다. 이 할선의 기울기가 한 점으로 수렴할 때의 값이 바로 도함수입니다. 따라서 $f'(a) > 0$이면 $x=a$ 근처에서 함수가 증가하고, $f'(a) < 0$이면 함수가 감소하는 경향을 보입니다.

### 기본 성질
함수 $f(x) = x^2$의 경우, $x=2$에서의 도함수를 구하는 과정은 다음과 같습니다.
$$f'(2) = \lim_{h \to 0} \frac{(2+h)^2 - 4}{h} = \lim_{h \to 0} \frac{4h + h^2}{h} = \lim_{h \to 0} (4 + h) = 4$$
일반적으로 $f(x) = x^2$의 도함수는 $f'(x) = 2x$이므로 $f'(2) = 4$가 됨을 확인할 수 있습니다.

## 학습 체크
- 극한값이 존재하지 않을 때, 해당 지점에서 함수는 미분가능한가?
- 할선의 기울기가 접선의 기울기로 변하는 과정의 기하학적 의미는 무엇인가?
- 도함수의 부호가 함수의 증가와 감소에 어떤 영향을 주는가?

## 관련 개념
- **미분**: 도함수를 구하는 과정 그 자체를 의미하며, 함수의 변화 양상을 수학적으로 분석하는 도구입니다.
