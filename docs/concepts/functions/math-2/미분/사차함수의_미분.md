# 사차함수의 미분

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
사차함수를 미분하면 삼차함수가 되며, 이를 통해 함수의 극값, 증감, 변곡점 등 그래프의 개형을 분석할 수 있습니다.

## 본문
사차함수 $f(x) = ax^4 + bx^3 + cx^2 + dx + e$ (단, $a \neq 0$)를 미분하면 삼차함수인 $f'(x) = 4ax^3 + 3bx^2 + 2cx + d$를 얻습니다. 이는 각 항에 대해 거듭제곱의 미분법 $\tfrac{d}{dx}x^n = nx^{n-1}$을 적용하여 합한 결과입니다.

### 직관과 기하적 의미
사차함수의 도함수가 삼차함수라는 것은 사차함수 그래프 위의 모든 점에서 접선의 기울기가 삼차함수의 값으로 나타남을 의미합니다. 이를 통해 함수의 그래프가 어떻게 변화하는지 시각적으로 파악할 수 있습니다.

### 기본 성질
- **극값의 개수**: 도함수 $f'(x) = 0$이 서로 다른 세 실근을 가지면, 사차함수는 최대 3개의 극값(극댓값 2개와 극솟값 1개, 또는 극댓값 1개와 극솟값 2개)을 가질 수 있습니다.
- **함수의 증감**: $f'(x)$의 부호가 양수인 구간에서는 함수가 증가하고, 음수인 구간에서는 함수가 감소합니다.
- **변곡점**: 이계도함수 $f''(x) = 12ax^2 + 6bx + 2c$는 이차함수이므로, 그래프의 곡률이 변하는 변곡점은 최대 2개까지 존재할 수 있습니다.

예를 들어, $f(x) = x^4 - 2x^2 + 1$을 미분하면 $f'(x) = 4x^3 - 4x = 4x(x^2 - 1)$이 되며, 이때 $x = -1, 0, 1$에서 극값이 발생함을 알 수 있습니다.

## 학습 체크
- 사차함수의 도함수가 삼차함수일 때, 극값이 최대 몇 개까지 존재할 수 있는가?
- $f'(x)$의 부호 변화가 사차함수의 그래프 개형에 어떤 영향을 주는가?
- 이계도함수 $f''(x)$의 실근의 개수와 변곡점의 개수 사이의 관계는 무엇인가?

## 관련 개념
- **도함수의 활용 심화**: 사차함수의 극값과 변곡점의 위치를 이용하여 함수의 그래프를 정밀하게 그리고, 함수의 최대·최소 문제를 해결하는 데 활용됩니다.
