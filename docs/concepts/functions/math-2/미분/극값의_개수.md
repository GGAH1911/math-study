# 극값의 개수

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 정확한 진술

함수 $f(x)$가 정의역의 한 점 $x=a$에서 극값을 가지려면, 그 점에서 도함수 $f'(x)$가 부호를 바꾸어야 합니다. **극값의 개수**란 이러한 극값(극대값 또는 극소값)이 몇 개나 되는지를 나타내는 수입니다. 극대값과 극소값의 개수를 함께 센 총 개수를 의미합니다.

## 직관과 기하적 의미

함수의 그래프를 그려보면, 극값이 있는 점은 함수가 증가에서 감소로 바뀌거나(극대) 감소에서 증가로 바뀌는(극소) 지점입니다. 이 점들은 그래프가 "산봉우리"를 이루거나 "골짜기"를 이루는 곳이죠. 극값의 개수가 많을수록 함수의 그래프가 더 복잡하고 울퉁불퉁한 모양이 됩니다.

도함수 $f'(x)$의 영점(근)에서 부호가 바뀌는 경우만 극값이 됩니다. 즉, $f'(a) = 0$이면서 $a$의 양쪽에서 $f'(x)$의 부호가 다르면 극값입니다. 같은 부호라면 변곡점이지 극값이 아닙니다.

## 예시와 활용

**$n$차 함수의 도함수는 $(n-1)$차 함수**이므로, 최대 $(n-1)$개의 근을 가집니다. 따라서 3차 함수 $f(x) = ax^3 + bx^2 + cx + d$는 최대 2개의 극값을 가집니다:

$$f'(x) = 3ax^2 + 2bx + c$$

이 2차식이 서로 다른 두 실근을 가지면 극대 1개, 극소 1개를 가지고, 중근을 가지면 극값이 0개, 실근이 없으면 극값이 0개입니다.

예를 들어 $f(x) = x^3 - 3x$일 때, $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 $x = \pm 1$에서 극값을 가집니다. 따라서 극값의 개수는 **2개**입니다.

```python
# sympy.solve(3*x**2 - 3, x) → [-1, 1]
```
