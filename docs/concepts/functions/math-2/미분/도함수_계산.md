# 도함수 계산

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수 $f(x)$의 도함수는 각 점에서의 순간변화율이자 접선의 기울기를 나타내는 함수입니다.

## 본문
함수 $f(x)$의 **도함수**는 $f'(x)$ 또는 $\frac{df}{dx}$로 나타내며, 다음과 같이 정의됩니다:
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
이 극한값이 존재할 때 함수 $f$는 $x$에서 **미분가능**하다고 하며, 이때의 극한값을 **미분 계수**라고 합니다.

### 직관과 기하적 의미
도함수는 한 점에서의 **순간변화율**을 의미합니다. 기하학적으로 $\frac{f(x+h) - f(x)}{h}$는 두 점 $(x, f(x))$와 $(x+h, f(x+h))$를 잇는 할선의 기울기를 나타냅니다. 여기서 $h$가 $0$에 한없이 가까워지면 할선은 점 $(x, f(x))$에서의 **접선**에 수렴하게 되므로, 도함수 $f'(x)$는 곡선 $y=f(x)$ 위의 점 $(x, f(x))$에서의 **접선의 기울기**가 됩니다. 이는 물리학에서 위치 함수의 변화율이 속도가 되는 원리와 같습니다.

### 기본 성질
도함수를 계산하는 주요 공식과 성질은 다음과 같습니다.
- **거듭제곱의 미분**: $\frac{d}{dx}(x^n) = nx^{n-1}$
- **삼각함수 및 지수·로그함수**: $\frac{d}{dx}(\sin x) = \cos x$, $\frac{d}{dx}(\cos x) = -\sin x$, $\frac{d}{dx}(e^x) = e^x$, $\frac{d}{dx}(\ln x) = \frac{1}{x}$
- **합과 차의 미분**: $\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$
- **곱의 미분**: $\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$
- **연쇄 법칙**: $\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)$

예를 들어 $f(x) = x^3 - 2x + 1$이면, 각 항을 미분하여 $f'(x) = 3x^2 - 2$를 얻습니다.

## 학습 체크
- 극한값 $\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$이 존재하지 않을 때, 해당 지점에서 함수는 미분가능한가?
- 도함수의 값이 $0$이 되는 지점은 그래프의 접선 기울기와 어떤 관계가 있는가?
- 두 함수의 곱을 미분할 때 단순히 각각의 미분값을 곱하는 것이 아니라 왜 곱의 미분법을 사용해야 하는가?

## 관련 개념
- **도함수의 활용 심화**: 도함수를 통해 함수의 증가와 감소를 판별하고, 극대·극소 및 변곡점을 찾아 그래프의 개형을 정밀하게 그릴 수 있습니다.
