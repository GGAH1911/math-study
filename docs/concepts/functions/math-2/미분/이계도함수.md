# 이계도함수

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수를 한 번 더 미분한 함수로, 함수의 변화율이 변하는 정도와 그래프의 곡률을 나타냅니다.

## 본문
함수 $f(x)$의 도함수 $f'(x)$가 다시 미분가능할 때, $f'(x)$를 $x$에 대해 미분한 함수를 **이계도함수**라 하며, $f''(x)$, $\tfrac{d^2f}{dx^2}$, $\tfrac{d^2y}{dx^2}$ 등으로 나타냅니다. 즉, $f''(x) = \tfrac{d}{dx}\left(f'(x)\right)$ 입니다.

### 직관과 기하적 의미
1차 도함수 $f'(x)$가 함수의 변화율을 나타낸다면, 이계도함수 $f''(x)$는 그 변화율이 얼마나 빠르게 변하는지를 보여줍니다. 기하학적으로는 그래프의 곡률(휜 정도)을 나타내며, $f''(x) > 0$이면 그래프는 아래로 오목(위로 볼록)한 형태를 띠고, $f''(x) < 0$이면 그래프는 위로 볼록(아래로 오목)한 형태를 띱니다. $f''(x) = 0$인 지점은 곡률이 변하는 변곡점의 후보가 됩니다. 물리적으로 위치 $f(t)$에 대하여 $f'(t)$가 속도라면, $f''(t)$는 가속도를 의미합니다.

### 기본 성질
$f(x) = x^3 - 3x^2 + 2x + 1$인 경우, $f'(x) = 3x^2 - 6x + 2$이며, 이를 다시 미분한 $f''(x) = 6x - 6$이 이계도함수가 됩니다.

## 학습 체크
- 도함수 $f'(x)$가 미분가능하지 않다면 이계도함수를 정의할 수 있는가?
- $f''(x)$의 부호에 따라 그래프의 오목과 볼록을 어떻게 판별하는가?
- 변곡점의 조건과 이계도함수의 값 사이에는 어떤 관계가 있는가?

## 관련 개념
- **미분**: 함수의 변화율을 구하는 과정이며, 이계도함수는 이 미분 과정을 한 번 더 반복하여 얻는 개념입니다.
