# 이계도함수

## 정확한 진술

함수 $f(x)$의 도함수 $f'(x)$가 다시 미분가능할 때, $f'(x)$를 $x$에 대해 미분한 함수를 **이계도함수**라 하며, $f''(x)$, $\frac{d^2f}{dx^2}$, $\frac{d^2y}{dx^2}$ 등으로 나타냅니다. 즉, $f''(x) = \frac{d}{dx}\left(f'(x)\right)$ 입니다.

## 직관/기하적 의미

1차 도함수 $f'(x)$는 함수의 **변화율**을 나타내는데, 이계도함수 $f''(x)$는 그 변화율이 **얼마나 빠르게 변하는지**를 보여줍니다. 기하학적으로는 그래프의 **곡률(휜 정도)**을 나타내며:

- $f''(x) > 0$: 그래프가 위로 볼록 (아래로 오목), 1차 도함수가 증가 중
- $f''(x) < 0$: 그래프가 아래로 볼록 (위로 오목), 1차 도함수가 감소 중
- $f''(x) = 0$: 변곡점의 후보 (곡률이 바뀌는 지점)

물리적으로는 $f(t)$가 위치라면, $f'(t)$는 속도, $f''(t)$는 **가속도**입니다.

## 한 줄 예

$f(x) = x^3 - 3x^2 + 2x + 1$일 때, $f'(x) = 3x^2 - 6x + 2$이고, $f''(x) = 6x - 6$입니다.

(검산: `sympy.diff(x**3 - 3*x**2 + 2*x + 1, x, 2)`를 계산하면 $6x - 6$)
