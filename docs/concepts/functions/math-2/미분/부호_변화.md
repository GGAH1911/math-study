# 부호 변화

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
도함수의 부호가 $x=c$를 기준으로 양에서 음으로, 또는 음에서 양으로 바뀌는 현상을 의미하며, 이는 함수의 극값이 결정되는 핵심 조건입니다.

## 본문
도함수 $f'(x)$의 부호 변화란, $x = c$를 기준으로 $f'(x)$의 부호가 양(+)에서 음(-)으로, 또는 음(-)에서 양(+)으로 바뀌는 현상을 말합니다. 즉, $f'(c) = 0$인 점 $x = c$의 좌우에서 $f'(x)$의 부호가 서로 다를 때 부호 변화가 일어난다고 합니다.

### 직관과 기하적 의미
함수의 그래프에서 부호 변화는 함수의 증감이 바뀌는 지점을 정확하게 나타냅니다. 도함수(기울기)가 양수에서 음수로 바뀌면, 함수는 증가에서 감소로 전환되어 그 지점이 봉우리 모양의 극대점이 됩니다. 반대로 음수에서 양수로 바뀌면, 함수는 감소에서 증가로 전환되어 골짜기 모양의 극소점이 됩니다.

### 기본 성질
중요한 점은 $f'(c) = 0$이더라도 부호 변화가 없으면 극값이 아니라는 것입니다. 예를 들어 $f'(x) = (x-a)^2$와 같은 경우, $x = a$에서 $f'(a) = 0$이지만 좌우 모두 $f'(x) \geq 0$이므로 부호 변화가 없으며, 따라서 $x = a$는 극값이 아닙니다.

예를 들어 $f(x) = x^3 - 3x^2$에서 $f'(x) = 3x(x-2)$일 때, $x = 0$ 좌측에서 $f'(x) > 0$, 우측에서 $f'(x) < 0$이므로 부호가 양에서 음으로 변하여 $x=0$에서 극대를 갖습니다. $x = 2$에서는 좌측 $f'(x) < 0$, 우측 $f'(x) > 0$이므로 부호가 음에서 양으로 변하여 $x=2$에서 극소를 갖습니다.

## 학습 체크
- $f'(c) = 0$인 점이 반드시 극점인가요? 부호 변화 여부를 확인해야 합니다.
- 도함수의 부호가 양수에서 음수로 변할 때, 원래 함수 $f(x)$의 그래프 모양은 어떻게 변하나요?
- $f'(x)$의 부호가 변하지 않는 지점은 그래프에서 어떤 형태를 띠나요?

## 관련 개념
- **도함수의 활용 심화**: 도함수의 부호 변화를 통해 함수의 증가와 감소를 판정하고, 이를 바탕으로 함수의 극값과 그래프의 개형을 정밀하게 추론할 수 있습니다.
