# 삼차함수의 계수 결정

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
주어진 조건들을 활용하여 삼차함수의 네 가지 계수를 결정하기 위해 네 개의 독립적인 방정식을 세워 해결하는 과정입니다.

## 본문
삼차함수의 계수 결정이란, 주어진 조건들로부터 삼차함수 $f(x) = ax^3 + bx^2 + cx + d$ (단, $a \neq 0$)의 네 계수 $a, b, c, d$를 구하는 과정을 의미합니다. 삼차함수는 네 개의 미지수를 포함하므로, 이를 유일하게 결정하려면 네 개의 독립적인 조건이 필요합니다.

주요 조건의 형태는 다음과 같습니다.
- 함수값: 점 $(p, q)$를 지난다는 조건은 $f(p) = q$를 의미합니다.
- 극값: 극값이 $x=\alpha$에서 최댓값 $M$을 가진다는 조건은 $f'(\alpha) = 0$과 $f(\alpha) = M$을 동시에 만족해야 함을 의미합니다.
- 미분값: 점 $x=p$에서의 접선의 기울기가 $m$이라는 조건은 $f'(p) = m$을 의미합니다.
- 변곡점: 변곡점이 $(p, q)$라는 조건은 $f''(p) = 0$과 $f(p) = q$를 의미합니다.

### 직관과 기하적 의미
삼차함수는 일반적인 형태이므로 4개의 독립변수가 존재하며, 따라서 4개의 방정식이 세워져야 유일한 해가 존재합니다. 기하학적으로는 곡선이 특정 점들을 지나고, 특정 점에서 특정 기울기를 가지며, 특정 점에서 극값이나 변곡점을 가진다는 조건들이 그래프의 전체적인 형태를 단계적으로 결정해 나가는 과정과 같습니다. 예를 들어 원점을 지나고, $x=1$에서 극값 2를 가지며, 변곡점이 $x=2$인 삼차함수는 이러한 조건들을 모두 만족하는 유일한 그래프로 결정됩니다.

### 기본 성질
- 삼차함수의 계수를 결정하기 위해서는 반드시 네 개의 독립적인 식이 도출되어야 합니다.
- 조건이 부족할 경우 계수들 사이의 관계식만 구할 수 있으며, 조건이 중복될 경우 해가 무수히 많아질 수 있습니다.

## 학습 체크
- 주어진 조건이 $f(x)$에 대한 식인지, $f'(x)$에 대한 식인지 구분하여 정확한 방정식을 세웠는가?
- 극값 조건이 주어졌을 때 미분계수가 $0$이라는 조건을 빠뜨리지 않고 활용하였는가?
- 도출된 네 개의 방정식이 서로 독립적인지, 혹은 중복된 조건은 없는지 확인하였는가?

## 관련 개념
- **함수의 극한과 연속**: 함수의 연속성을 통해 특정 지점에서의 함숫값과 극한값이 같음을 이용하여 계수를 결정할 수 있습니다.
- **도함수**: 삼차함수의 극값이나 접선의 기울기를 구하기 위해 미분을 통해 도함수를 활용합니다.
- **연립방정식**: 도출된 네 개의 식을 통해 미지수 $a, b, c, d$를 구하는 수학적 도구로 사용됩니다.
