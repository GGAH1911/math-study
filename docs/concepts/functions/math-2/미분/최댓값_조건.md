# 최댓값 조건

> **정의** · 수학2 · 단원: [미분](/concepts/미분)

## 요약
함수 $f(x)$가 폐구간에서 연속이면 최댓값이 반드시 존재하며, 이는 구간 내부의 극값점 또는 경계점에서 발생합니다.

## 본문
함수 $f(x)$가 폐구간 $[a, b]$에서 연속이면, 해당 구간에서 함수는 반드시 최댓값을 가집니다. 이때 최댓값은 구간 내부의 극값점 또는 구간의 양 끝점인 경계점에서만 달성됩니다. 구간 내부의 점 $c$에서 최댓값을 갖기 위한 필요조건은 $f'(c) = 0$인 것이며, 충분조건은 $f'(c) = 0$이면서 해당 점의 좌우에서 함수의 부호가 양수에서 음수로 변하는 경우입니다.

### 직관과 기하적 의미
제약 조건이 주어진 도형 위에서 함수의 최댓값을 찾는 상황을 기하학적으로 해석할 수 있습니다. 예를 들어 원 $x^2 + y^2 = r^2$ 위에서 $ax + by$의 최댓값을 찾는 문제는, 직선 $ax + by = k$가 원과 접하는 순간의 $k$값을 찾는 것과 같습니다. 이때 접점은 원의 중심에서 직선에 수직인 방향으로 반지름만큼 떨어진 지점에 위치합니다. 일반적인 상황에서 도형 위의 최댓값은 해당 점에서의 도형의 접선과 목적함수의 등위선이 서로 평행할 때 달성됩니다.

### 기본 성질
- 폐구간에서 연속인 함수는 반드시 최댓값과 최솟값을 가집니다.
- 구간 내부에서 최댓값을 갖는 점은 반드시 미분 가능할 경우 도함수가 $0$이어야 합니다.
- 최댓값은 구간의 양 끝점(경계점)에서도 나타날 수 있습니다.

## 학습 체크
- 함수가 폐구간에서 연속이지만 구간의 양 끝점에서 최댓값을 갖는 경우는 어떤 경우인가?
- 구간 내부의 점 $c$에서 $f'(c) = 0$임에도 불구하고 최댓값이 아닌 극소값을 갖는 조건은 무엇인가?

## 관련 개념
- **도형의 방정식**: 최댓값을 구해야 하는 대상이 되는 제약 조건을 나타내며, 기하학적 접점의 위치를 결정하는 역할을 합니다.
