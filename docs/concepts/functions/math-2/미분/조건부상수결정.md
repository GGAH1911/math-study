# 조건부상수결정

## 정확한 진술

함수 $f(x)$의 부정적분은 $F(x) + C$ (단, $C$는 임의의 상수)로 나타나며, 적분상수 $C$는 무수히 많은 값을 가질 수 있습니다. **조건부상수결정**은 초기 조건이나 경계 조건을 이용하여 적분상수 $C$의 값을 유일하게 결정하는 과정입니다.

주어진 미분방정식 $\frac{dy}{dx} = f(x)$의 일반해 $y = F(x) + C$에서, 특정 점 $(x_0, y_0)$을 지날 조건 $y(x_0) = y_0$을 사용하면 $y_0 = F(x_0) + C$로부터 $C = y_0 - F(x_0)$로 결정됩니다. 이렇게 구한 해를 **특수해**라 합니다.

## 직관/기하적 의미

미분은 함수의 변화율만을 나타내므로, 원래 함수의 절댓값(수직 위치) 정보가 소실됩니다. 부정적분으로 되돌릴 때 $F(x) + C$ 형태로 무한히 많은 가능한 함수가 생기는데, 이는 곡선 $y = F(x)$를 연직 방향으로 평행이동한 것들입니다. **초기 조건은 이 무한히 많은 곡선 중 정확히 어느 곡선을 선택할지 지정하는 역할**을 합니다.

예를 들어 $\frac{dy}{dx} = 2x$인 모든 곡선은 $y = x^2 + C$ 형태이지만, "점 $(1, 3)$을 지난다"는 조건이 주어지면 유일한 곡선 $y = x^2 + 2$로 결정됩니다.

## 한 줄 예

$\frac{dy}{dx} = 3x^2$이고 $y(1) = 5$일 때, 일반해는 $y = x^3 + C$이므로 $5 = 1 + C$에서 $C = 4$, 따라서 특수해는 $y = x^3 + 4$입니다.
```python
# sympy.solve(Eq(1**3 + C, 5), C) → C = 4
```
