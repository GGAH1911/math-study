### 정확한 진술

함수 $f(x)$가 $x = a$를 포함하는 어떤 개구간에서 정의되어 있을 때, $x$가 $a$와 다르면서 $a$에 가까워질수록 $f(x)$가 하나의 값 $L$에 한없이 가까워지면, "$x \to a$일 때 $f(x)$의 극한값은 $L$이다"라고 하고 다음과 같이 표기합니다:

$$\lim_{x \to a} f(x) = L$$

이는 임의의 양수 $\epsilon$에 대하여, 적당한 양수 $\delta$가 존재하여 $0 < |x - a| < \delta$이면 $|f(x) - L| < \epsilon$이 성립함을 의미합니다(엡실론-델타 정의).

### 직관/기하적 의미

극한값은 함수가 어떤 점에서 "실제로 어떤 값을 가져야 하는가"가 아니라, "그 점 근처에서 어떤 값으로 수렴하는가"를 나타냅니다. 즉, $f(a)$가 정의되지 않거나 $f(a) \neq L$이어도 극한값은 존재할 수 있습니다. 좌표평면 위에서 보면, 점 $x = a$ 바로 근처에서 함수의 그래프가 점 $(a, L)$ 주변으로 집중되는 현상입니다. 극한값의 핵심은 "극한 과정($x \to a$)"에 있으며, $x = a$에서의 함수값 자체는 상관없습니다.

### 한 줄 예

$f(x) = \frac{x^2 - 1}{x - 1}$는 $x = 1$에서 정의되지 않지만, $\lim_{x \to 1} f(x) = \lim_{x \to 1} (x + 1) = 2$입니다. (sympy 검증: `from sympy import limit, Symbol; x = Symbol('x'); limit((x**2 - 1)/(x - 1), x, 1)`)
