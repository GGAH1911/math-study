# 함수의 극한과 연속성

> **단원** · 수학Ⅱ · 선수: [함수와 그래프](/concepts/함수와_그래프) / [함수](/concepts/함수) · 다음: [미분](/concepts/미분)

## 학습 목표
- 함수의 극한 정의를 이해하고 좌·우 극한으로 극한값 존재 조건을 판정할 수 있다
- 극한값의 사칙·합성 성질을 활용해 다항·유리·무리·합성함수의 극한을 계산할 수 있다
- 함수의 연속과 불연속을 정의하고 한 점/구간에서의 연속성을 판정할 수 있다
- 중간값 정리, 최대·최소 정리를 닫힌구간 연속함수에 적용해 근의 존재성과 극값 위치를 보일 수 있다

## 다룰 정의 / 정리 / 예제

- 함수의 극한 정의 (좌극한·우극한·양쪽 극한)
- 극한값의 사칙 / 곱·몫 / 합성 성질
- 극한값의 존재 조건 (좌·우 극한 일치)
- 연속의 정의 (한 점에서의 연속, 구간에서의 연속)
- 불연속점 분류 (제거가능·점프·무한 불연속)
- 중간값 정리 (Intermediate Value Theorem)
- 닫힌구간 위 연속함수의 최대·최소 정리
