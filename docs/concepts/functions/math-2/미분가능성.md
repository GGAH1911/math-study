### 정확한 진술

함수 $f(x)$가 $x=a$에서 **미분가능하다**는 것은, 다음의 극한값이 존재하고 유한할 때를 말합니다.

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

이 극한값이 존재하면 그것을 점 $x=a$에서의 **도함수값**(미분계수)이라 부릅니다. 함수가 어떤 구간의 모든 점에서 미분가능하면, 그 구간에서 **미분가능**하다고 합니다.

### 직관 및 기하적 의미

미분가능성은 함수의 그래프가 그 점에서 **매끄럽고 뾰족한 부분이 없으며, 수직 접선도 없다**는 의미입니다. 기하학적으로는 평균변화율 $\frac{f(a+h) - f(a)}{h}$가 $h \to 0$일 때 하나의 값으로 수렴해야 하는데, 이는 곡선의 순간 기울기가 유일하게 결정된다는 뜻입니다.

**미분가능 ⟹ 연속**이지만, 역은 성립하지 않습니다. 예를 들어 $f(x) = |x|$는 $x=0$에서 연속이지만 미분불가능입니다. (좌미분계수 = $-1$, 우미분계수 = $1$로 다름)

### 한 줄 예

$f(x) = x^2$는 모든 점에서 미분가능하며, $f'(a) = 2a$입니다. 반면 $f(x) = |x|$는 $x=0$에서 좌극한과 우극한이 다르므로 미분불가능합니다.

```python
# 검증: sympy로 미분가능성 확인
from sympy import symbols, diff, limit, Abs
x, a, h = symbols('x a h')
f_smooth = x**2
f_corner = Abs(x)
# f_smooth는 모든 점에서 미분가능 / f_corner는 x=0에서 미분불가능
```
