# 두 곡선 사이 넓이

> **예제** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
두 곡선 사이의 넓이는 위쪽에 위치한 함수에서 아래쪽에 위치한 함수를 뺀 식을 정적분하여 구합니다.

## 본문
두 곡선 $y = x^2$과 $y = 2x$로 둘러싸인 도형의 넓이를 구하시오.

### 단계별 풀이
**교점 찾기**
두 곡선이 만나는 점을 찾기 위해 $x^2 = 2x$ 방정식을 풉니다.
$x^2 - 2x = 0$
$x(x-2) = 0$
따라서 교점의 $x$ 좌표는 $0$과 $2$이며, 교점은 $(0, 0)$과 $(2, 4)$입니다.

**위/아래 함수 확인**
구간 $0 < x < 2$에서 $x=1$을 대입하면 $y=x^2$은 $1$, $y=2x$는 $2$가 됩니다. 따라서 이 구간에서는 $2x \ge x^2$이 성립하여 직선이 포물선보다 위쪽에 위치합니다.

**넓이 계산**
두 곡선 사이의 넓이는 위쪽 함수에서 아래쪽 함수를 뺀 식을 $0$부터 $2$까지 정적분하여 구합니다.
$$\int_0^2 (2x - x^2) \, dx = \left[ x^2 - \frac{x^3}{3} \right]_0^2 = \left(4 - \frac{8}{3}\right) - 0 = \frac{4}{3}$$

### 답과 변형
$$\frac{4}{3}$$
- **교점의 개수**: 곡선이 여러 점에서 만나면 구간을 나누어 각각의 넓이를 구한 뒤 합산해야 합니다.
- **위/아래 판단**: 그래프를 생략할 경우 구간 내 임의의 값을 대입하여 반드시 위/아래를 확인해야 합니다.
- **절댓값 활용**: 항상 (위의 식 - 아래의 식)을 계산하면 결과가 음수가 나오지 않습니다.

## 학습 체크

- 여러 개의 교점이 생길 경우 구간을 나누어 계산할 수 있는가?
