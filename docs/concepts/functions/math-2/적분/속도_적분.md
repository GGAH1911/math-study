# 속도 적분

## 정확한 진술

속도 함수 $v(t)$를 시간에 대해 적분한 것입니다. 시간 구간 $[a, b]$에서:

$$\text{변위} = \int_a^b v(t) \, dt, \quad \text{거리} = \int_a^b |v(t)| \, dt$$

**변위**는 위치의 순변화량이고, **거리**는 실제로 이동한 총 길이입니다.

## 직관과 기하적 의미

속도-시간 그래프 아래의 넓이가 바로 이동 거리입니다. 이는 미적분학의 기본정리에서 비롯됩니다. 위치함수 $s(t)$를 미분하면 속도 $v(t) = s'(t)$가 되므로, 역으로 속도를 적분하면 위치 변화를 얻습니다:

$$s(b) - s(a) = \int_a^b v(t) \, dt$$

**거리와 변위의 차이:**
- 변위는 시작점과 끝점의 위치 차이만 고려 (음수 가능)
- 거리는 절댓값으로 방향 무시, 실제 이동 거리 계산 (항상 음이 아님)

예: 앞으로 5m 갔다가 뒤로 2m 돌아오면, 변위는 3m이지만 거리는 7m입니다.

## 기본 예

**정속도의 경우:** $v(t) = 3$ m/s일 때, 2초간 이동한 거리는
$$\int_0^2 3 \, dt = 3 \times 2 = 6 \text{ m}$$

**가변속도의 경우:** $v(t) = t$ m/s에서 $t \in [0, 3]$일 때 변위는
$$\int_0^3 t \, dt = \left[\frac{t^2}{2}\right]_0^3 = \frac{9}{2} = 4.5 \text{ m}$$

(검증: `sympy.integrate(t, (t, 0, 3))` → 4.5)
