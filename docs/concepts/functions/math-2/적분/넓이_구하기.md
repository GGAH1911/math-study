# 넓이 구하기

> **예제** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
곡선 $y=f(x)$와 $x$축 사이의 넓이는 함수가 $x$축 위에 있으면 정적분 값 그대로를, $x$축 아래에 있으면 정적분 값에 절댓값을 취하여 구합니다.

## 본문
$f(x) = -x^2 + 4$일 때, 곡선 $y = f(x)$와 $x$축 사이의 넓이를 구하시오.

### 단계별 풀이
**1단계: 곡선과 $x$축의 교점 찾기**
곡선이 $x$축과 만나는 점을 구하기 위해 $f(x) = 0$을 풉니다. 이는 적분 구간의 끝점이 되므로 필수입니다.
$$-x^2 + 4 = 0 \Rightarrow x = \pm 2$$

**2단계: 주어진 구간에서 함수의 부호 확인**
$-2 \leq x \leq 2$ 범위에서 함수가 양수인지 음수인지 판단합니다. $x=0$을 대입하면 $f(0) = 4 > 0$이므로 이 구간에서 곡선은 $x$축 위에 있습니다.

**3단계: 정적분으로 넓이 표현**
함수가 $x$축 위에 있으므로 넓이는 다음과 같습니다.
$$A = \int_{-2}^{2} (-x^2 + 4) \, dx$$

**4단계: 부정적분 구하기 후 계산**
$$\int (-x^2 + 4) \, dx = -\frac{x^3}{3} + 4x + C$$
정적분 계산을 수행하면 다음과 같습니다.
$$A = \left[-\frac{x^3}{3} + 4x\right]_{-2}^{2} = \left(-\frac{8}{3} + 8\right) - \left(\frac{8}{3} - 8\right) = \frac{32}{3}$$

### 답과 변형
**답**
$$\frac{32}{3}$$

**변형 및 주의사항**
- **대칭성 활용**: 이 함수는 $y$축에 대해 대칭이므로 계산량을 줄이기 위해 $\displaystyle A = 2\int_0^2 (-x^2+4) \, dx = \tfrac{32}{3}$와 같이 계산할 수 있습니다.
- **함수가 음수인 경우**: 만약 곡선 일부가 $x$축 아래에 있다면, 그 부분의 적분값은 음수가 되므로 넓이를 구할 때는 절댓값을 취해야 합니다. 구간을 나누어 각 부분의 적분값에 절댓값을 씌워 더하는 방식으로 계산합니다.

## 학습 체크
- 곡선과 $x$축의 교점을 찾아 적분 구간을 정확히 설정하였는가?
- 함수가 $x$축 위 또는 아래에 있는지 확인하여 절댓값 처리를 적절히 하였는가?
- 함수의 대칭성을 이용하여 계산 과정을 효율적으로 단축할 수 있는가?

## 관련 개념
- **적분**: 함수의 변화량을 누적하여 넓이나 부피를 구하는 도구로, 곡선과 축 사이의 넓이를 계산하는 핵심 원리가 됩니다.
