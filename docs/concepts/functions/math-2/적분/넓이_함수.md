# 넓이 함수

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
닫힌 구간 $[a, b]$에서 연속인 함수 $f(x)$에 대하여, 구간 $[a, x]$에서의 누적 넓이를 나타내는 함수를 넓이 함수라고 합니다.

## 본문
닫힌 구간 $[a, b]$에서 정의된 연속함수 $f(x)$에 대해, 다음과 같이 정의된 함수를 **넓이 함수**라고 합니다:
$$F(x) = \int_a^x f(t) \, dt, \quad (a \le x \le b)$$
여기서 $F(x)$는 $x$가 변함에 따라 곡선 $y = f(t)$와 $t$축 사이의 넓이(부호를 포함)가 어떻게 변화하는지를 나타냅니다.

### 직관과 기하적 의미
넓이 함수 $F(x)$는 왼쪽 끝점 $a$는 고정되어 있고, 오른쪽 끝점 $x$가 움직임에 따라 쌓이는 누적 넓이를 의미합니다. $x = a$일 때 $F(a) = 0$이 되어 넓이가 존재하지 않으며, $x$가 증가함에 따라 곡선 아래의 넓이가 계속해서 누적됩니다.

### 기본 성질
넓이 함수는 원래 함수의 부호에 따라 증가와 감소가 결정됩니다. $f(x) > 0$인 구간에서는 $F(x)$가 증가하고, $f(x) < 0$인 구간에서는 $F(x)$가 감소합니다. 가장 중요한 성질은 $F'(x) = f(x)$라는 점으로, 넓이 함수를 미분하면 원래의 함수가 도출됩니다. 이는 미적분학의 기본정리를 보여주는 핵심적인 원리입니다.

예를 들어 $f(x) = 2x$이고 $a = 0$일 때, $F(x) = \int_0^x 2t \, dt = x^2$이 됩니다. 이때 $F'(x) = 2x$이므로 원래 함수와 일치하며, $F(3) = 9$를 통해 밑변이 3이고 높이가 6인 삼각형의 넓이와 같음을 확인할 수 있습니다.

## 학습 체크
- $x=a$일 때 넓이 함수 $F(a)$의 값은 왜 $0$이 되는가?
- $f(x)$의 부호가 바뀔 때 $F(x)$의 그래프 개형은 어떻게 변하는가?
- 넓이 함수 $F(x)$를 미분했을 때 원래 함수 $f(x)$가 나오는 원리를 이해했는가?

## 관련 개념
- **정적분의 활용**: 넓이 함수를 통해 정적분의 값을 구하거나, 곡선과 축 사이의 넓이를 계산하는 데 직접적으로 사용됩니다.
