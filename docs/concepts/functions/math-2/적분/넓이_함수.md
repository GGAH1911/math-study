# 넓이 함수

## 정확한 진술

닫힌 구간 $[a, b]$에서 정의된 연속함수 $f(x)$에 대해, 다음과 같이 정의된 함수를 **넓이 함수**라고 합니다:

$$F(x) = \int_a^x f(t) \, dt, \quad (a \le x \le b)$$

여기서 $F(x)$는 $x$가 변할 때, 곡선 $y = f(t)$와 $t$축 사이의 넓이(부호를 포함)를 나타냅니다.

## 직관과 기하적 의미

넓이 함수 $F(x)$는 **왼쪽 끝점이 고정되고 오른쪽 끝점이 $x$로 움직일 때의 누적 넓이**입니다.

- $x = a$일 때: $F(a) = \int_a^a f(t) \, dt = 0$ (넓이가 없음)
- $x$가 증가하면: $F(x)$도 증가 (곡선 아래 넓이가 누적)
- $f(x) > 0$인 구간에서는 $F(x)$가 증가, $f(x) < 0$인 구간에서는 $F(x)$가 감소

**핵심 정리**: $F'(x) = f(x)$입니다. 즉, 넓이 함수를 미분하면 원래 함수가 나옵니다. 이것이 **미적분학의 기본정리**입니다.

## 한 줄 예

$f(x) = 2x$이고 $a = 0$일 때, $F(x) = \int_0^x 2t \, dt = x^2$이므로 넓이 함수는 포물선 형태입니다. 확인: `F(3) = 9` (밑변 3, 높이 6인 삼각형 넓이)

실제로는 $F(x) = \int_0^x 2t \, dt = [t^2]_0^x = x^2$로 계산되며, 이는 $F'(x) = 2x = f(x)$를 만족합니다.
