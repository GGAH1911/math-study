# 속도 거리 적분

> **예제** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
가속도를 적분하면 속도가 되고, 속도를 적분하면 이동 거리가 됩니다.

## 본문
어떤 물체가 일정한 가속도 $a(t) = 2$ m/s²로 가속합니다. 초기 조건은 $t=0$일 때 속도 $v(0) = 0$ m/s, 위치 $s(0) = 0$ m입니다. $t=3$초 후의 속도와 이동 거리를 구하세요.

가속도, 속도, 위치 사이의 관계는 미분과 적분을 통해 연결됩니다. 가속도를 시간 $t$에 대해 적분하면 속도 $v(t)$를 얻을 수 있으며, 이때 적분 상수는 초기 속도 조건을 통해 결정됩니다. 또한 속도를 시간 $t$에 대해 적분하면 물체의 위치 변화량인 이동 거리를 구할 수 있습니다. 즉, $a(t) \rightarrow v(t) \rightarrow s(t)$의 흐름을 가집니다.

### 단계별 풀이
**1단계: 속도 구하기**
가속도의 정의에 따라 $a(t) = \tfrac{dv}{dt}$이므로, 속도는 가속도를 시간으로 적분하여 구합니다.
$$v(t) = \int a(t) \, dt = \int 2 \, dt = 2t + C$$
초기 조건 $v(0) = 0$을 대입하면 $C = 0$이므로 $v(t) = 2t$입니다. 따라서 $t=3$일 때 $v(3) = 6$ m/s입니다.

**2단계: 거리 구하기**
속도의 정의에 따라 $v(t) = \tfrac{ds}{dt}$이므로, 거리는 속도를 시간으로 정적분하여 구합니다.
$$s(3) = \int_0^3 v(t) \, dt = \int_0^3 2t \, dt = [t^2]_0^3 = 9 \text{ m}$$

### 답과 변형
$t=3$초일 때: 속도 = **6 m/s**, 이동 거리 = **9 m**

가속도가 상수가 아닌 경우에도 동일한 적분 과정을 거칩니다. 예를 들어 $a(t) = 3t$이면 $v(t) = \tfrac{3t^2}{2} + C$가 됩니다. 주의할 점은 속도가 음수인 구간이 있을 때입니다. 단순히 위치의 변화를 나타내는 변위를 구할 때는 $\int v(t) \, dt$를 사용하지만, 실제 움직인 총 거리인 이동 거리를 구할 때는 속도의 절댓값을 적분한 $\int |v(t)| \, dt$를 사용해야 합니다.

- **적분**: 미분의 역연산으로서 가속도에서 속도를, 속도에서 거리를 도출하는 도구로 사용됩니다.
