# 속도 거리 적분

> **예제** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
가속도→속도→거리

## 본문 (학습 시 채워짐)

### 문제
어떤 물체가 일정한 가속도 $a(t) = 2$ m/s²로 가속합니다. 초기 조건은 $t=0$일 때 속도 $v(0) = 0$ m/s, 위치 $s(0) = 0$ m입니다. $t=3$초 후의 속도와 이동 거리를 구하세요.

### 단계별 풀이
**1단계: 속도 구하기** — 가속도의 정의에 따라 $a(t) = \frac{dv}{dt}$입니다. 따라서 속도는 가속도를 시간으로 적분하여 구합니다.
$$v(t) = \int a(t) \, dt = \int 2 \, dt = 2t + C$$
초기조건 $v(0) = 0$을 대입하면 $C = 0$이므로 $v(t) = 2t$입니다. 따라서 $t=3$일 때 $v(3) = 6$ m/s입니다.

**2단계: 거리 구하기** — 속도의 정의에 따라 $v(t) = \frac{ds}{dt}$입니다. 따라서 거리는 속도를 시간으로 정적분하여 구합니다.
$$s(3) = \int_0^3 v(t) \, dt = \int_0^3 2t \, dt = [t^2]_0^3 = 9 \text{ m}$$

### 답
$t=3$초일 때: 속도 = **6 m/s**, 이동 거리 = **9 m** (검산: `sympy.integrate(2*t, (t, 0, 3))` = 9)

### 변형/주의
가속도가 상수가 아닌 경우에도 같은 방법을 적용합니다. 예를 들어 $a(t) = 3t$ m/s²이면 $v(t) = \int 3t \, dt = \frac{3t^2}{2} + C$입니다. 또한 속도가 음수인 구간이 존재하면 이동 거리와 변위를 구분해야 합니다. 거리는 $\int |v(t)| \, dt$이고 변위는 $\int v(t) \, dt$입니다. 이 예제의 핵심은 미분 관계 $a = \frac{dv}{dt}$, $v = \frac{ds}{dt}$를 적분을 통해 역으로 활용하는 것입니다.
