# 초기조건

## 정확한 진술

**초기조건**(initial condition)은 부정적분의 일반해에서 적분상수 $C$를 결정하는 조건입니다. 함수 $f(x)$의 부정적분이 $\int f(x)dx = F(x) + C$ 형태일 때, 특정 점에서의 함수값을 알면 상수 $C$를 구할 수 있습니다. 예를 들어 "$x = a$일 때 $y = b$"라는 조건이 주어지면, $b = F(a) + C$를 풀어서 특정한 하나의 원시함수를 찾을 수 있습니다.

## 직관 및 기하적 의미

부정적분 $F(x) + C$는 무수히 많은 함수들의 모임입니다. 이들은 모두 같은 기울기(도함수)를 가지지만, 수직으로 위아래로 평행이동되어 있습니다. 초기조건은 이 평행하는 곡선들 중 **정확히 어느 곡선을 지날 것인지**를 결정하는 정보입니다. 마치 미분방정식을 풀 때 "$(a, b)$를 지나는 해를 구하세요"라고 하는 것처럼, 초기조건은 무한한 선택지 중 **유일한 해**를 고르는 열쇠입니다.

## 예시

$\frac{dy}{dx} = 2x$이고 $x=1$일 때 $y=3$이라는 초기조건이 있다면:

$$y = \int 2x\, dx = x^2 + C$$

초기조건 $y(1) = 3$을 대입하면 $3 = 1^2 + C$이므로 $C = 2$입니다. 따라서 특수해는 $y = x^2 + 2$입니다.

(검증: `sympy.solve(1**2 + C - 3, C)` → `C = 2`)
