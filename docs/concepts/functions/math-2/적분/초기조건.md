# 초기조건

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
초기조건은 부정적분의 일반해에 포함된 적분상수를 결정하여 무수히 많은 함수 중 유일한 원시함수를 찾아내는 조건입니다.

## 본문
초기조건(initial condition)은 부정적분의 일반해에서 적분상수 $C$를 결정하는 조건입니다. 함수 $f(x)$의 부정적분이 $\int f(x)dx = F(x) + C$ 형태일 때, 특정 점에서의 함수값을 알면 상수 $C$를 구할 수 있습니다. 예를 들어 "$x = a$일 때 $y = b$"라는 조건이 주어지면, $b = F(a) + C$를 만족하는 $C$를 구함으로써 특정한 하나의 원시함수를 결정할 수 있습니다.

### 직관과 기하적 의미
부정적분 $F(x) + C$는 도함수가 같은 무수히 많은 함수들의 모임입니다. 이 함수들은 모두 같은 기울기를 가지지만, 수직 방향으로 평행이동되어 있는 관계입니다. 초기조건은 이 평행한 곡선들 중 정확히 어느 곡선을 지날 것인지를 결정하는 정보입니다. 마치 미분방정식에서 특정 점을 지나는 해를 구하는 것과 같이, 초기조건은 무한한 선택지 중에서 유일한 해를 고르는 열쇠 역할을 합니다.

### 기본 성질
$\frac{dy}{dx} = 2x$이고 $x=1$일 때 $y=3$이라는 초기조건이 있다면, 부정적분을 통해 $y = x^2 + C$라는 일반해를 얻습니다. 이때 초기조건 $y(1) = 3$을 대입하면 $3 = 1^2 + C$이므로 $C = 2$가 됩니다. 따라서 최종적인 특수해는 $y = x^2 + 2$가 됩니다.

## 학습 체크
- 주어진 초기조건을 부정적분의 일반해에 대입하여 적분상수 $C$를 정확히 구할 수 있는가?
- 초기조건이 주어졌을 때, 일반해에서 특수해로 넘어가는 과정의 기하적 의미를 이해하고 있는가?

## 관련 개념
- **적분**: 부정적분을 통해 얻은 일반해에 초기조건을 적용함으로써, 하나의 특정한 함수를 결정하는 과정과 밀접하게 연결됩니다.
