# 기본정리

## 정확한 진술

**미적분의 기본정리**(또는 정적분의 기본정리)는 미분과 적분이 역연산임을 명시합니다. 연속함수 $f(x)$에 대해 다음이 성립합니다.

**제1부**: 구간 $[a, b]$에서 $F(x) = \int_a^x f(t)\,dt$로 정의하면, $F'(x) = f(x)$입니다.

**제2부**: $f(x)$가 $[a, b]$에서 연속이고 $F'(x) = f(x)$인 부정적분 $F(x)$가 존재하면,
$$\int_a^b f(x)\,dx = F(b) - F(a)$$

## 직관과 의미

부정적분 $F(x)$는 **누적된 변화량**을 추적합니다. 속도함수 $v(t)$를 시간에 따라 적분하면 이동 거리가 되는데, 이는 위치함수의 변화량입니다. 마찬가지로 정적분 $\int_a^b f(x)\,dx$는 기하적으로 곡선 아래 넓이이지만, 본질적으로는 $f$의 "누적 기여도"이며, 이를 계산하려면 $f$의 부정적분 $F$를 이용해 $F(b) - F(a)$를 구하면 됩니다.

## 실제 예

$\int_1^3 2x\,dx$를 계산하면:
- 부정적분: $F(x) = x^2$
- 정적분값: $F(3) - F(1) = 9 - 1 = 8$

`sympy.integrate(2*x, (x, 1, 3))` → `8`

이 정리가 없다면 정적분은 리만 합으로만 계산해야 하므로 번거롭지만, 기본정리 덕분에 부정적분만 찾으면 정적분을 쉽게 구할 수 있습니다.
