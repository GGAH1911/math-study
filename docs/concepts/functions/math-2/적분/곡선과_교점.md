# 곡선과 교점

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
두 곡선의 방정식 $y = f(x)$와 $y = g(x)$를 동시에 만족하는 점 $(x_0, y_0)$를 교점이라 하며, 이는 방정식 $f(x) = g(x)$의 해를 통해 구할 수 있습니다.

## 본문
두 곡선 $y = f(x)$와 $y = g(x)$의 교점은 두 곡선의 방정식을 동시에 만족하는 점 $(x_0, y_0)$입니다. 즉, $f(x_0) = g(x_0) = y_0$을 만족하며, 이는 방정식 $f(x) = g(x)$를 풀어 얻을 수 있습니다. 만약 한 곡선이 $x$축인 경우, 즉 $g(x) = 0$인 상황이라면 교점은 $f(x) = 0$의 근을 통해 구하며 이를 곡선과 $x$축의 교점이라고 합니다.

### 직관과 기하적 의미
좌표평면에서 두 곡선의 교점은 두 그래프가 실제로 만나는 위치를 시각적으로 나타냅니다. 특히 적분과의 연결고리가 매우 중요한데, 두 곡선 사이의 넓이를 구할 때 적분 구간의 경계가 되는 $x$좌표가 바로 두 곡선의 교점입니다. 예를 들어, $a < b$인 두 점 $(a, f(a)) = (a, g(a))$와 $(b, f(b)) = (b, g(b))$에서 만나는 두 곡선 사이의 넓이는 $\displaystyle \int_a^b |f(x) - g(x)| dx$로 계산됩니다. 따라서 교점을 정확히 찾는 것은 적분 문제를 해결하는 핵심적인 단계입니다.

### 기본 성질
- 두 곡선이 만나는 점의 $x$좌표는 방정식 $f(x) = g(x)$의 실근과 일치합니다.
- 교점의 $y$좌표는 구한 $x$좌표를 원래의 함수식 중 어느 하나에 대입하여 구할 수 있습니다.
- 포물선 $y = x^2$과 직선 $y = 2x$의 경우, $x^2 = 2x$를 풀면 $x=0$ 또는 $x=2$를 얻으며 교점은 $(0, 0)$과 $(2, 4)$가 됩니다.

## 학습 체크
- 두 곡선의 방정식을 하나로 합친 $f(x) = g(x)$의 해가 교점의 $x$좌표임을 이해하고 있는가?
- 두 곡선 사이의 넓이를 구할 때 교점의 $x$좌표를 적분 구간으로 설정할 수 있는가?

## 관련 개념
- **적분**: 두 곡선 사이의 넓이를 구할 때 적분 구간의 경계를 결정하는 결정적인 역할을 합니다.
