# 급수와 적분의 관계

## 정확한 진술

함수 $f(x)$가 폐구간 $[a, b]$에서 연속일 때, **정적분** $\int_a^b f(x)\,dx$는 다음과 같이 정의됩니다:

$$\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i^*) \Delta x$$

여기서 $\Delta x = \frac{b-a}{n}$은 각 소구간의 너비이고, $x_i^*$는 $i$번째 소구간 $[x_{i-1}, x_i]$에 속한 임의의 점입니다. 이 합 $\sum_{i=1}^{n} f(x_i^*) \Delta x$를 **리만 합**(Riemann sum)이라 부르며, 구간을 무한히 잘게 나눌 때 이 급수의 극한값이 정적분을 정의합니다.

## 직관/기하적 의미

폐구간 $[a, b]$를 $n$개의 같은 너비인 소구간으로 나눕니다. 각 소구간에서 점 $x_i^*$를 선택하여 높이 $f(x_i^*)$, 밑변 $\Delta x$인 직사각형을 그립니다. 이 직사각형들의 넓이를 모두 더하는 것이 리만 합인데, 이는 곡선 아래 영역의 근삿값입니다. $n$이 커질수록 직사각형이 작아져 곡선을 더 정확히 따르므로, 무한히 세밀해질 때의 극한이 곡선 아래의 정확한 넓이, 즉 정적분이 됩니다.

## 한 줄 예

$f(x) = x$일 때, $\int_0^1 x\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} \frac{i}{n} \cdot \frac{1}{n} = \frac{1}{2}$
(검증: `sympy.integrate(sympy.Symbol('x'), (sympy.Symbol('x'), 0, 1))`)
