# 도형의 넓이

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
정적분을 이용하여 곡선과 $x$축 또는 두 곡선 사이로 둘러싸인 도형의 넓이를 계산할 수 있습니다.

## 본문
곡선 $y = f(x)$ ($f(x) \geq 0$)와 $x$축, 그리고 두 직선 $x = a, x = b$로 둘러싸인 도형의 넓이는 $\int_a^b f(x) \, dx$로 정의됩니다. 만약 두 곡선 $y = f(x)$와 $y = g(x)$ ($f(x) \geq g(x)$) 사이의 넓이를 구하고자 한다면, 위쪽 곡선에서 아래쪽 곡선을 뺀 식을 적분하여 $\int_a^b \{f(x) - g(x)\} \, dx$로 계산합니다.

### 직관과 기하적 의미
도형을 밑변의 길이가 $\Delta x$이고 높이가 $f(x)$인 매우 좁은 직사각형 띠들로 잘게 나누어 생각할 수 있습니다. 이 직사각형들의 넓이인 $f(x) \cdot \Delta x$를 모두 더한 후, 구간을 무한히 잘게 나누는 극한 과정을 거치면 실제 도형의 넓이에 도달하게 됩니다. 즉, 정적분은 곡선 아래의 면적을 구하는 도구이며, 함수가 $x$축 아래에 위치할 경우 정적분 값은 음수가 나올 수 있으므로 실제 넓이를 구할 때는 반드시 절댓값을 취해야 합니다.

### 기본 성질
- $f(x) \geq 0$일 때, $\int_a^b f(x) \, dx$는 구간 $[a, b]$에서 곡선 아래의 넓이를 의미합니다.
- $f(x) \leq 0$일 때, 실제 넓이는 $\int_a^b |f(x)| \, dx$로 계산해야 합니다.
- 두 곡선 사이의 넓이는 항상 위쪽 함수에서 아래쪽 함수를 뺀 값을 적분하여 구합니다.

## 학습 체크
- 함수가 $x$축 위와 아래에 걸쳐 있을 때, 전체 넓이를 구하기 위해 구간을 어떻게 나누어야 하는가?
- 두 곡선이 만나는 점을 찾았을 때, 어떤 함수를 위쪽 함수로 설정하여 적분해야 하는가?

## 관련 개념
- **이차함수**: 이차함수와 $x$축으로 둘러싸인 도형의 넓이를 구할 때 정적분을 직접적으로 활용합니다.
- **정적분**: 도형의 넓이를 정의하고 계산하는 수학적 근간이 되는 연산입니다.
