# 조건부상수결정

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
초기 조건이나 경계 조건을 활용하여 부정적분에서 발생하는 무수히 많은 적분상수 $C$의 값을 유일하게 결정하는 과정입니다.

## 본문
함수 $f(x)$의 부정적분은 $F(x) + C$ (단, $C$는 임의의 상수)로 나타나며, 이때 적분상수 $C$는 무수히 많은 값을 가질 수 있습니다. **조건부상수결정**은 이처럼 불확정적인 적분상수 $C$의 값을 특정 초기 조건이나 경계 조건을 이용하여 유일하게 결정하는 과정을 의미합니다.

주어진 미분방정식 $\tfrac{dy}{dx} = f(x)$의 일반해는 $y = F(x) + C$의 형태를 띠는데, 만약 이 함수가 특정 점 $(x_0, y_0)$을 지난다는 조건 $y(x_0) = y_0$이 주어지면 $y_0 = F(x_0) + C$라는 식을 얻을 수 있습니다. 이 식을 통해 $C = y_0 - F(x_0)$로 상수의 값을 확정할 수 있으며, 이렇게 결정된 해를 **특수해**라고 부릅니다.

### 직관과 기하적 의미
미분은 함수의 변화율만을 나타내기 때문에, 원래 함수가 가진 수직 위치 정보가 소실됩니다. 따라서 부정적분을 통해 함수를 복원할 때 $F(x) + C$와 같이 연직 방향으로 평행이동한 무한히 많은 곡선들이 후보로 존재하게 됩니다. 이때 **초기 조건은 무한히 많은 가능한 곡선들 중 단 하나의 곡선을 선택하도록 지정하는 역할**을 합니다. 예를 들어 $\tfrac{dy}{dx} = 2x$를 만족하는 모든 곡선은 $y = x^2 + C$ 형태이지만, "점 $(1, 3)$을 지난다"는 조건이 더해지면 오직 $y = x^2 + 2$라는 하나의 곡선으로 결정됩니다.

### 기본 성질
- 일반해는 적분상수 $C$를 포함하여 무수히 많은 해의 집합을 나타냅니다.
- 특정 조건이 주어지면 일반해는 단 하나의 해인 특수해로 변환됩니다.
- 조건부상수결정은 미분방정식의 해를 구하는 핵심적인 절차입니다.

## 학습 체크
- 일반해 $y = F(x) + C$에서 적분상수 $C$가 왜 발생하는지 설명할 수 있는가?
- 주어진 조건 $y(x_0) = y_0$을 이용하여 $C$의 값을 구하는 계산 과정을 이해하고 있는가?
- 일반해와 특수해의 차이점을 기하학적 관점에서 설명할 수 있는가?

## 관련 개념
- **미분**: 함수의 변화율을 구하는 연산으로, 부정적분 과정에서 수직 위치 정보가 소실되는 원인이 됩니다.
- **부정적분**: 미분의 역연산으로, 상수항 $C$를 포함하는 일반해의 형태를 생성합니다.
- **미분방정식**: 도함수를 포함하는 방정식으로, 조건부상수결정을 통해 유일한 해를 찾는 대상이 됩니다.
