# 리만합

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
구간을 잘게 나누어 만든 직사각형들의 넓이 합으로, 곡선 아래의 넓이를 근사하기 위해 사용되는 개념입니다.

## 본문
폐구간 $[a, b]$에서 연속인 함수 $f(x)$에 대하여, 구간을 $n$개의 소구간으로 분할하여 각 소구간의 폭을 $\Delta x_i = x_i - x_{i-1}$이라 하고, 각 소구간에서 임의로 선택한 점을 $c_i$라고 할 때, 리만합은 $\sum_{i=1}^{n} f(c_i) \Delta x_i$로 정의됩니다. 이때 분할의 최대 소구간 폭인 $\|P\| = \max(\Delta x_i)$가 $0$으로 수렴할 때, 이 리만합의 극한값은 정적분 $\int_a^b f(x) \, dx$의 값과 일치하게 됩니다.

### 직관과 기하적 의미
리만합은 곡선 $y = f(x)$ 아래의 영역을 여러 개의 직사각형으로 나누어 그 넓이를 근사하는 과정입니다. 각 소구간 $[x_{i-1}, x_i]$에서 높이를 $f(c_i)$, 밑변을 $\Delta x_i$로 하는 직사각형을 그리면, 이 직사각형들의 넓이 합이 곧 리만합이 됩니다. 구간을 더 잘게 나눌수록 직사각형들은 실제 곡선의 모양에 점점 더 가까워지며, 분할이 무한히 세밀해지면 그 합은 실제 곡선 아래의 넓이로 수렴합니다. 이때 $c_i$를 구간의 왼쪽 끝점으로 잡으면 좌끝점 리만합, 오른쪽 끝점으로 잡으면 우끝점 리만합이 됩니다.

### 기본 성질
함수 $f(x)$가 연속이면 분할의 방식(좌끝점, 우끝점, 중점 등)에 관계없이 분할의 폭이 $0$으로 갈 때 리만합은 항상 동일한 값인 정적분 값으로 수렴합니다.

## 학습 체크
- 소구간의 개수 $n$이 커질 때 리만합의 값이 실제 정적분 값에 어떻게 가까워지는가?
- $c_i$를 선택하는 방식에 따라 리만합의 값이 달라질 수 있는 이유는 무엇인가?

## 관련 개념
- **정적분**: 리만합의 극한값이 존재할 때 그 극한값을 의미하며, 곡선 아래의 실제 넓이를 나타냅니다.
- **여러가지 적분법**: 리만합의 원리를 이용하여 복잡한 함수를 계산하거나 다른 방식으로 넓이를 구하는 다양한 방법들을 포함합니다.
