# 정적분

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
함수 $f(x)$의 부정적분 $F(x)$를 이용하여 구간 $[a, b]$에서의 넓이를 계산하는 연산입니다.

## 본문
함수 $f(x)$가 닫힌 구간 $[a, b]$에서 연속이고, $F(x)$가 $f(x)$의 부정적분(즉, $F'(x) = f(x)$)일 때, $a$부터 $b$까지의 정적분은 $\int_a^b f(x)dx = F(b) - F(a)$로 정의합니다. 이때 $F(b) - F(a)$를 $[F(x)]_a^b$로 표기하며, 이는 미적분학의 기본정리에 해당합니다.

### 직관과 기하적 의미
정적분 $\int_a^b f(x)dx$는 곡선 $y=f(x)$와 $x$축 사이의 부호가 있는 넓이를 의미합니다. $f(x) \geq 0$인 구간에서는 위쪽 넓이가 양수로, $f(x) < 0$인 구간에서는 아래쪽 넓이가 음수로 계산됩니다. 부정적분 $F(x)$가 $0$부터 $x$까지의 누적 넓이를 나타낸다는 관점에서 볼 때, $F(b) - F(a)$는 $a$에서 $b$까지 추가된 넓이를 의미하며, 이는 미적분과 기하학을 연결하는 핵심적인 원리입니다.

### 기본 성질
- $f(x) = 2x$일 때, $\int_1^3 2x\,dx = [x^2]_1^3 = 3^2 - 1^2 = 8$입니다. 이는 $x=1$부터 $x=3$까지 직선 $y=2x$ 아래의 넓이가 8임을 나타냅니다.
