### 정확한 진술

삼각함수의 적분은 기본 삼각함수들의 부정적분(역미분)을 구하는 연산입니다. 고등학교 적분에서 자주 다루는 기본 공식들은 다음과 같습니다:

$$\int \sin x \, dx = -\cos x + C$$

$$\int \cos x \, dx = \sin x + C$$

$$\int \tan x \, dx = -\ln|\cos x| + C$$

$$\int \cot x \, dx = \ln|\sin x| + C$$

이들은 미분의 역연산이므로, 예를 들어 $\frac{d}{dx}(-\cos x) = \sin x$를 확인하면 첫 번째 공식이 맞음을 알 수 있습니다. 특별히 $\tan x$와 $\cot x$의 경우 치환을 이용해야 하는데, $\tan x = \frac{\sin x}{\cos x}$를 $u = \cos x$로 치환하면 $\int \frac{-du}{u} = -\ln|u| + C = -\ln|\cos x| + C$가 됩니다.

### 직관/기하적 의미

삼각함수의 적분은 **주기적 변화**를 누적한 결과를 나타냅니다. $\sin x$는 위아래로 진동하는 파동인데, 그것을 적분하면 코사인 함수(역시 파동이지만 위상이 다름)가 됩니다. 기하학적으로는 $y = \sin x$ 곡선 아래의 부호 있는 넓이를 구하는 것입니다. 삼각함수 적분은 **물리학의 진동 운동**, **교류 전류**, **파동 현상** 등을 수식화할 때 필수입니다.

### 한 줄 예

$\int (2\sin x + 3\cos x) \, dx = -2\cos x + 3\sin x + C$ 
(`sympy.integrate(2*sin(x) + 3*cos(x), x)`)
