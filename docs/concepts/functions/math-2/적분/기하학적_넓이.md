# 기하학적 넓이

> **정의** · 수학2 · 단원: [적분](/concepts/적분)

## 요약
정적분을 이용하여 좌표평면 위에서 곡선과 곡선 또는 곡선과 직선 사이의 영역의 크기를 수치로 계산하는 것입니다.

## 본문
기하학적 넓이는 좌표평면에서 곡선 또는 도형으로 둘러싸인 영역의 크기를 의미합니다. 고등학교 과정에서는 주로 이차곡선이나 직선과 곡선 사이의 영역의 넓이를 정적분을 이용하여 구합니다. 일반적으로 두 곡선 $y = f(x)$와 $y = g(x)$가 있고 $a \leq x \leq b$ 범위에서 $f(x) \geq g(x)$를 만족할 때, 두 곡선 사이의 넓이 $S$는 다음과 같이 정의됩니다.
$$S = \int_{a}^{b} [f(x) - g(x)] \, dx$$

### 직관과 기하적 의미
좌표평면 위에서 곡선이 만드는 영역의 크기를 수치로 나타내는 것이 핵심 목표입니다. 예를 들어 포물선 $y = x^2$과 $x$축 사이의 넓이를 구할 때, 곡선 아래쪽 영역의 크기를 구하는 과정과 같습니다. 이는 아주 얇은 직사각형들의 넓이를 모두 더한 뒤, 그 직사각형의 폭을 극한으로 줄여나가는 정적분의 원리를 이용합니다. 곡선의 형태가 아무리 복잡하더라도 적분 계산을 통해 정확한 넓이를 구할 수 있다는 점이 정적분의 강력한 도구적 가치이며, 이는 나아가 부피나 물리량 계산의 기초가 됩니다.

### 기본 성질
- 두 곡선 사이의 넓이를 구할 때는 반드시 위쪽 곡선에서 아래쪽 곡선을 뺀 값을 적분해야 합니다.
- 구간 내에서 두 곡선의 위치 관계가 바뀌어 $f(x) - g(x)$의 부호가 변하는 경우에는 구간을 나누어 각각의 넓이를 구한 뒤 합산해야 합니다.
- 넓이는 항상 양수($S > 0$)의 값을 가집니다.

## 학습 체크
- 두 곡선 사이의 넓이를 구할 때, 어떤 함수가 위쪽에 있는지 판단하는 방법은 무엇인가요?
- 적분 구간 내에서 두 함수의 대소 관계가 바뀌는 경우, 넓이를 어떻게 나누어 계산해야 하나요?

## 관련 개념
- **이차곡선**: 포물선, 타원, 쌍곡선과 같은 곡선과 직선 사이의 영역의 넓이를 구할 때 적분의 대상이 됩니다.
- **정적분**: 곡선으로 둘러싸인 영역의 넓이를 계산하기 위해 사용하는 핵심적인 수학적 도구입니다.
