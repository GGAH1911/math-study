# 함수의 조건 분석

## 정확한 진술

함수의 조건 분석이란 주어진 함수가 만족하는 여러 조건들을 종합적으로 해석하여 함수의 구체적 형태를 결정하는 과정입니다. 고등학교에서는 주로 다항함수에 대해 다음과 같은 조건들이 제시됩니다:

- **함수값 조건**: $f(a) = b$ (특정 점에서의 함수값)
- **극값 조건**: $f'(a) = 0$ (극값을 갖는 점에서의 도함수 값)
- **연속성 조건**: 특정 점에서 좌극한, 우극한, 함수값이 모두 같음
- **미분가능성 조건**: 특정 점에서 연속이면서 좌미분계수 = 우미분계수

이들 조건으로부터 연립방정식을 세우고 풀어 미지의 계수를 결정합니다.

## 직관과 기하적 의미

수능 문제에서는 함수의 식을 처음부터 완전히 주지 않고, 대신 함수의 몇몇 특징(극값의 위치, 어떤 점을 지남, 특정 점에서의 기울기 등)을 조건으로 제시합니다. 학생은 이 조건들을 수식으로 번역하고 역으로 함수를 구성해야 합니다. 이 과정을 통해 함수의 기하적 성질(그래프 모양)과 해석적 성질(도함수, 극값)을 연결하는 능력을 기릅니다. 조건이 충분하면 함수가 유일하게 결정되며, 부족하면 여러 개의 함수가 가능합니다.

## 한 줄 예

$f(0) = 1$, $f'(2) = 0$, $f(2) = 5$라는 세 조건에서 이차함수 $f(x) = x^2 - 4x + 1$의 계수를 유일하게 결정할 수 있습니다.
