# 중간값정리

## 정확한 진술

함수 $f(x)$가 닫힌 구간 $[a, b]$에서 연속이고, $k$가 $f(a)$와 $f(b)$ 사이의 값일 때(즉, $f(a) < k < f(b)$ 또는 $f(b) < k < f(a)$), 다음을 만족하는 점 $c \in (a, b)$가 **반드시 존재**한다:

$$f(c) = k$$

달리 말하면, 연속함수는 두 함숫값 사이의 **모든 중간값을 한 번 이상** 달성한다.

## 직관 및 기하적 의미

종이에서 펜을 떼지 않고 그린 곡선이 $y = f(a)$에서 시작해 $y = f(b)$에서 끝난다면, 그 곡선은 $f(a)$와 $f(b)$ 사이의 **모든 높이**를 지나가야 한다. 곡선이 연속이므로 "점프"할 수 없기 때문입니다.

이 정리는 **방정식의 해의 존재성을 보장**하는 데 핵심적입니다. 예를 들어, $f(a)$와 $f(b)$의 부호가 반대면, $f(0)$인 점이 구간 내에 반드시 존재합니다. 실제로 근과 계수의 관계나 함수의 극값 문제에서 "해가 존재하는가?"를 판단할 때 자주 사용됩니다.

## 간단한 예

$f(x) = x^2 - 3$이 $[0, 2]$에서 연속이고, $f(0) = -3 < 0 < 4 = f(2)$이므로, 중간값정리에 의해 $f(c) = 0$인 $c \in (0, 2)$가 존재합니다. 실제로 $c = \sqrt{3} \approx 1.732$에서 달성됩니다. (검산: `sympy.solve(x**2 - 3, x)` → $x = \pm\sqrt{3}$)
