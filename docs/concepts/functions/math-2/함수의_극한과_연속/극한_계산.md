# 극한 계산

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
극한 계산은 함수의 극한값이 부정형일 때, 대수적 조작을 통해 수렴하는 값을 찾아내는 체계적인 과정입니다.

## 본문
극한 계산(limit calculation)은 $\lim_{x \to a} f(x)$를 구하기 위해 직접 대입 또는 대수적 조작을 통해 수렴값을 구하는 과정입니다. $x = a$를 직접 대입했을 때 $\frac{0}{0}$, $\frac{\infty}{\infty}$, $\infty - \infty$ 등의 부정형이 발생하면, 인수분해, 유리화, 표준 극한 공식 등을 활용하여 형태를 변형한 후 극한값을 결정합니다.

### 직관과 기하적 의미
극한은 $x$가 $a$에 한없이 가까워질 때 $f(x)$가 어떤 값 $L$에 한없이 가까워지는지를 묻는 것입니다. 그래프 상에서 점 $(a, f(a))$의 존재 여부나 함수값 자체와는 무관하게, $x = a$ 근처에서 함수의 거동이 어디를 향하는지를 찾는 것이 핵심입니다. 예를 들어 $f(x) = \frac{x^2 - 1}{x - 1}$은 $x = 1$에서 정의되지 않지만, $x$가 1에 가까워질수록 함수값은 2에 접근합니다.

### 기본 성질
극한 계산은 다음과 같은 단계와 성질을 바탕으로 수행됩니다.
1. 직접 대입: 부정형이 나타나지 않으면 대입한 값이 곧 극한값입니다. $\lim_{x \to 2} (x^2 + 1) = 5$
2. 부정형 해소: $\frac{0}{0}$ 꼴의 경우 인수분해나 유리화를 통해 식을 변형합니다. $\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x+2) = 4$
3. 표준 극한 활용: 고교 과정의 핵심 공식인 $\lim_{x \to 0} \frac{\sin x}{x} = 1$ 또는 $\lim_{x \to 0} \frac{e^x - 1}{x} = 1$과 같은 표준값을 활용하여 복잡한 식을 축약합니다.

## 학습 체크
- 직접 대입을 했을 때 어떤 형태가 나오는지 확인하였는가?
- 부정형이 발생했을 때 인수분해나 유리화 중 어떤 방법이 적절한가?
- 주어진 식이 표준 극한 공식의 형태로 변형 가능한가?

## 관련 개념
- **함수의 극한과 연속**: 극한 계산을 통해 구한 극한값이 함수의 함숫값과 일치하는지 확인하여 함수의 연속성을 판단합니다.
