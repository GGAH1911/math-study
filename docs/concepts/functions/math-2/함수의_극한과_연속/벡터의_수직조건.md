# 벡터의 수직조건

## 정확한 진술

두 벡터 $\vec{a}$, $\vec{b}$에 대해 다음이 동치입니다:
- $\vec{a}$와 $\vec{b}$가 **수직(perpendicular)**이다
- $\vec{a} \cdot \vec{b} = 0$ (두 벡터의 내적이 0)

평면에서 $\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$이면, 수직 조건은 다음과 같이 표현됩니다:
$$a_1 b_1 + a_2 b_2 = 0$$

공간에서 $\vec{a} = (a_1, a_2, a_3)$, $\vec{b} = (b_1, b_2, b_3)$이면:
$$a_1 b_1 + a_2 b_2 + a_3 b_3 = 0$$

## 직관 및 기하적 의미

내적의 정의식 $\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos\theta$에서, $\vec{a}$와 $\vec{b}$ 사이의 각을 $\theta$라 하면:

$$\vec{a} \cdot \vec{b} = 0 \Rightarrow \cos\theta = 0 \Rightarrow \theta = 90°$$

즉, **두 벡터의 내적이 0이면 그들이 이루는 각이 정확히 90도**라는 의미입니다. 영벡터와의 관계에서 영벡터는 모든 벡터와 수직으로 간주됩니다(관례적 정의).

이 조건은 기하학적으로 직선의 수직성, 평면의 법벡터, 거리 최소화 문제 등 다양한 기하학적 문제를 대수적으로 해결하게 해줍니다.

## 한 줄 예

$\vec{a} = (2, 1)$, $\vec{b} = (1, -2)$일 때, $\vec{a} \cdot \vec{b} = 2(1) + 1(-2) = 0$이므로 두 벡터는 수직입니다. (`sympy`로 확인: `(2*1 + 1*(-2)) == 0`)
