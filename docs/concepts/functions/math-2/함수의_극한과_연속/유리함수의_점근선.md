# 유리함수의 점근선

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
유리함수의 그래프가 $x$가 특정 값에 가까워지거나 무한대로 갈 때 무한히 다가가는 직선을 의미합니다.

## 본문
유리함수 $f(x) = \tfrac{P(x)}{Q(x)}$의 점근선은 $x$가 특정 값에 가까워지거나 무한대로 갈 때, 함수의 그래프가 점점 다가가는 직선을 말합니다. 점근선은 크게 세 가지 유형으로 구분됩니다.

첫째, 수직 점근선은 분모 $Q(x) = 0$이지만 분자 $P(x) \neq 0$인 지점 $x = a$에서 발생합니다. 이때 $x \to a$일 때 $|f(x)| \to \infty$이면 직선 $x = a$가 수직 점근선이 됩니다. 둘째, 수평 점근선은 $x \to \infty$ 또는 $x \to -\infty$일 때 $f(x)$가 상수 $L$로 수렴하면 직선 $y = L$이 됩니다. 분자의 차수가 분모의 차수보다 작으면 $y = 0$이 되고, 두 차수가 같으면 최고차항 계수의 비가 $L$이 됩니다. 셋째, 사선 점근선은 분자의 차수가 분모의 차수보다 정확히 1 클 때 나타납니다. 이때 식을 나누어 $f(x) = (ax + b) + \tfrac{r(x)}{Q(x)}$ 형태로 변형하면, 직선 $y = ax + b$가 사선 점근선이 됩니다.

### 직관과 기하적 의미
점근선은 함수의 극단적인 행동을 나타냅니다. $x$가 극단적인 값으로 이동할 때 함수가 어떤 직선에 무한히 가까워지는지를 보여주며, 이는 전체적인 그래프의 개형을 파악하는 데 필수적입니다. 수직 점근선은 함수가 정의되지 않는 경계인 '벽'의 역할을 하며, 수평 및 사선 점근선은 함수가 먼 곳에서 나아가는 방향을 제시합니다.

### 기본 성질
- 분모가 $0$이 되는 지점은 수직 점근선의 후보가 됩니다.
- 분자와 분모의 차수에 따라 수평 또는 사선 점근선의 존재 여부가 결정됩니다.
- $f(x) = \tfrac{2x+1}{x-3}$의 경우, 분모가 $0$이 되는 $x=3$이 수직 점근선이며, 최고차항 계수의 비인 $y=2$가 수평 점근선입니다.

## 학습 체크
- 분모를 $0$으로 만드는 $x$값이 수직 점근선이 되기 위한 조건은 무엇인가?
- 분자의 차수와 분모의 차수 관계에 따른 점근선의 종류를 구분할 수 있는가?
- 분자의 차수가 분모보다 $1$ 클 때, 사선 점근선을 구하는 방법은 무엇인가?

## 관련 개념
- **여러가지함수의 극한**: 유리함수의 점근선을 구하는 과정은 변수가 무한대로 가거나 특정 값으로 갈 때의 극한값을 찾는 과정과 직결됩니다.
