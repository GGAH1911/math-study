# 분할함수

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
정의역을 여러 구간으로 나누어 각 구간마다 서로 다른 함수식을 적용하여 정의하는 함수입니다.

## 본문
분할함수(또는 구간별함수)란 정의역을 두 개 이상의 겹치지 않는 구간으로 나누어, 각 구간에서 서로 다른 함수식으로 정의되는 함수를 의미합니다. 일반적으로 다음과 같이 표기합니다.

$$f(x) = \begin{cases}
f_1(x) & \text{if } x \in D_1 \\
f_2(x) & \text{if } x \in D_2 \\
\vdots & \vdots \\
f_n(x) & \text{if } x \in D_n
\end{cases}$$

이때 $D_1, D_2, \ldots, D_n$은 서로 겹치지 않는 구간들이어야 하며, 이 구간들의 합집합이 함수의 전체 정의역을 이루어야 합니다.

### 직관과 기하적 의미
분할함수는 상황에 따라 규칙이 변하는 현상을 수학적으로 모델링한 것입니다. 실생활의 예로 거리 구간에 따라 요금이 변하는 버스 요금 체계나 소득 구간에 따라 세율이 달라지는 소득세율을 들 수 있습니다. 그래프로 나타내면 서로 다른 곡선 조각들이 결합된 형태가 되며, 각 구간이 나뉘는 경계점에서 그래프가 끊어지지 않고 이어질 수도 있고 끊어져 있을 수도 있습니다.

### 기본 성질
분할함수의 극한과 연속성을 판별할 때는 구간이 나뉘는 경계점에서 좌극한과 우극한을 각각 계산하여 비교하는 것이 가장 중요합니다. 예를 들어 $f(x) = \begin{cases} x + 1 & \text{if } x < 0 \\ x^2 & \text{if } x \geq 0 \end{cases}$와 같은 함수는 $x=0$에서 좌극한은 $1$이지만 함숫값은 $0$이므로 불연속입니다.

## 학습 체크
- 구간이 나뉘는 경계점에서 좌극한, 우극한, 함숫값이 모두 일치하는지 확인하였는가?
- 각 구간의 정의된 범위가 서로 겹치거나 빠진 부분 없이 전체 정의역을 채우고 있는가?

## 관련 개념
- **함수의 극한과 연속**: 분할함수의 경계점에서 극한값이 존재하고 함숫값과 일치하는지를 확인하여 함수의 연속성을 판단하게 됩니다.
