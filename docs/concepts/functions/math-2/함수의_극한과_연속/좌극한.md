# 좌극한

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
변수 $x$가 $a$보다 작은 값들을 통해 $a$에 점점 가까워질 때, 함수값 $f(x)$가 특정 값 $L$에 한없이 가까워지는 상태를 의미합니다.

## 본문
함수 $f(x)$에서 변수 $x$가 $a$보다 작은 값들을 통해 $a$에 점점 가까워질 때, 즉 좌측에서 접근할 때 $f(x)$가 특정 값 $L$로 수렴하면, $x$가 $a$로 접근할 때 $f$의 좌극한값은 $L$이라고 합니다. 이를 기호로는 $\displaystyle \lim_{x \to a^-} f(x) = L$ 또는 $\displaystyle \lim_{x \to a-0} f(x) = L$로 나타냅니다. 엄밀하게 정의하자면, 임의의 양수 $\varepsilon$에 대하여 어떤 양수 $\delta$가 존재하여 $a - \delta < x < a$를 만족하는 모든 $x$에 대해 $|f(x) - L| < \varepsilon$이면, 좌극한값이 $L$입니다.

### 직관과 기하적 의미
수직선 위에서 $a$의 왼쪽(더 작은 값들)에서 $a$로 한 발씩 다가갈 때, 함수값 $f(x)$가 어떤 값 $L$로 점점 더 가까워진다는 의미입니다. 그래프 관점에서는 $y = f(x)$의 그래프에서 $x < a$인 영역을 따라 $x$를 $a$의 왼쪽으로 이동시킬 때, 점 $(x, f(x))$의 $y$좌표가 $L$에 수렴하는 것을 말합니다. 이때 $x = a$에서의 함숫값 $f(a)$는 존재하지 않을 수도 있고, 존재하더라도 $L$과 다를 수 있습니다. 일상적으로는 기차가 역에 접근할 때 역 근처의 상태가 실제 역에 도착했을 때의 상태와 다를 수 있는 것과 유사합니다.

### 기본 성질
- $x$가 $a$의 왼쪽에서 접근할 때 $f(x)$가 $L$로 수렴하면, $x$가 $a$의 오른쪽에서 접근할 때의 극한값(우극한)과 동일할 경우 극한값이 존재한다고 합니다.
- 좌극한값은 $x=a$에서의 함숫값 $f(a)$의 값과 반드시 일치할 필요는 없습니다.

## 학습 체크
- $x$가 $a$보다 작은 값에서 접근한다는 조건($x < a$)이 왜 중요한가요?
- 좌극한값과 우극한값이 서로 다를 때, 극한값 $\displaystyle \lim_{x \to a} f(x)$은 어떻게 정의되나요?
- 좌극한값이 존재하더라도 함수가 해당 지점에서 불연속일 수 있는 이유는 무엇인가요?

## 관련 개념
- **함수의 극한과 연속**: 함수의 극한이 존재하기 위해서는 좌극한과 우극한이 모두 존재하고 그 값이 같아야 하며, 이 극한값이 함숫값과 같을 때 함수는 연속입니다.
