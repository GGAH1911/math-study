# 좌극한

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 정확한 진술

함수 $f(x)$에서 변수 $x$가 $a$보다 작은 값들을 통해 $a$에 점점 가까워질 때 (즉, 좌측에서 접근할 때), $f(x)$가 특정 값 $L$로 수렴하면, "$x$가 $a$로 접근할 때 $f$의 좌극한값은 $L$"이라고 합니다. 기호로는 $\displaystyle \lim_{x \to a^-} f(x) = L$ 또는 $\displaystyle \lim_{x \to a-0} f(x) = L$로 나타냅니다.

**엄밀한 정의**: 임의의 양수 $\varepsilon$에 대해, 어떤 양수 $\delta$가 존재하여 $a - \delta < x < a$를 만족하는 모든 $x$에 대해 $|f(x) - L| < \varepsilon$이면, 좌극한값이 $L$입니다.

## 직관/기하적 의미

수직선 위에서 수를 생각해 보세요. $a$의 왼쪽에서(더 작은 값들에서) $a$로 한 발씩 다가갈 때, 함수값 $f(x)$가 어떤 값 $L$로 점점 더 가까워진다는 뜻입니다.

**그래프 관점**: $y = f(x)$의 그래프를 그렸을 때, $x < a$인 영역에서 $x$를 $a$의 왼쪽 가까이로 이동시키면, 대응하는 점 $(x, f(x))$의 $y$좌표가 $L$에 수렴한다는 의미입니다. 이때 $x = a$에서의 함수값 $f(a)$는 존재하지 않을 수도, 존재하더라도 $L$과 다를 수 있습니다.

**일상적 비유**: 철길 기차역에 왼쪽에서 역에 접근하는 열차를 생각하면, 역 근처에 갈수록 속도가 목표값으로 수렴하지만, 실제로 역에 도착할 때의 상태와는 다를 수 있다는 뜻입니다.

## 한 줄 예

$$f(x) = \begin{cases} x + 1 & \text{if } x < 2 \\ 5 & \text{if } x \geq 2 \end{cases}$$

일 때, $\displaystyle \lim_{x \to 2^-} f(x) = 3$입니다. ($x < 2$인 쪽에서 $x \to 2$이면 $f(x) = x + 1 \to 3$이므로) 한편 $f(2) = 5$이므로, 좌극한과 함숫값이 같지 않습니다.
