### 정확한 진술

조각함수(piecewise function)는 정의역을 겹치지 않는 여러 구간으로 나누어, 각 구간에서 서로 다른 식으로 정의되는 함수입니다. 가장 일반적인 형태는 다음과 같습니다:

$$f(x) = \begin{cases} f_1(x) & \text{if } x \in D_1 \\ f_2(x) & \text{if } x \in D_2 \\ \vdots \\ f_n(x) & \text{if } x \in D_n \end{cases}$$

여기서 $D_1, D_2, \ldots, D_n$은 정의역의 분할이고, 각 구간에서 $f_1, f_2, \ldots, f_n$은 서로 다른 규칙(일차함수, 이차함수, 상수함수 등)입니다.

### 직관과 기하적 의미

조각함수는 현실에서 "상황에 따라 달라지는" 현상을 수학으로 나타냅니다. 예를 들어 택시 요금은 거리 구간에 따라 다르게 계산되고, 누진세는 소득 구간에 따라 세율이 달라집니다. 

그래프 관점에서 조각함수는 여러 곡선이나 직선을 구간별로 이어붙인 모양입니다. 특히 구간의 경계점 $x = a$에서 연속일지 불연속일지, 미분가능할지 아닐지가 중요한 분석 대상이 됩니다. 연속이려면 $\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = f(a)$를 모두 만족해야 합니다.

### 한 줄 예

$$f(x) = \begin{cases} x+1 & \text{if } x < 0 \\ x^2 & \text{if } x \geq 0 \end{cases}$$

는 $x = 0$에서 좌극한이 1, 우극한과 함깓값이 0이므로 불연속입니다.
