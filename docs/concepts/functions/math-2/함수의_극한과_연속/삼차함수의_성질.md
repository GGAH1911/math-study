# 삼차함수의 성질

## 정확한 진술

삼차함수는 최고차항이 3차인 다항함수입니다. 일반형으로 다음과 같이 나타냅니다:

$$f(x) = ax^3 + bx^2 + cx + d \quad (a \neq 0)$$

여기서 $a, b, c, d$는 실수 상수이고, $a \neq 0$이어야 삼차함수가 됩니다. 도함수는 이차함수가 되므로 $f'(x) = 3ax^2 + 2bx + c$입니다.

## 직관/기하적 의미

삼차함수의 가장 큰 특징은 **극값의 개수**에 있습니다. 판별식 $D = 4b^2 - 12ac$의 부호에 따라:
- $D > 0$이면 극대값과 극소값이 각각 하나씩 존재 (극값 2개)
- $D \leq 0$이면 극값이 없음 (순증가 또는 순감소)

모든 삼차함수는 **변곡점을 정확히 하나** 가지며, 이는 $f''(x) = 6ax + 2b = 0$에서 $x = -\frac{b}{3a}$입니다. 변곡점은 극값이 있는지와 관계없이 항상 그래프의 중심이 되어, 점대칭의 중심 역할을 합니다.

또한 최고차 계수 $a$의 부호에 따라 **극한 거동**이 결정됩니다:
- $a > 0$: $x \to -\infty$일 때 $f(x) \to -\infty$, $x \to \infty$일 때 $f(x) \to \infty$
- $a < 0$: $x \to -\infty$일 때 $f(x) \to \infty$, $x \to \infty$일 때 $f(x) \to -\infty$

## 한 줄 예

$f(x) = x^3 - 3x$는 $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 $x = -1$에서 극대값 2, $x = 1$에서 극소값 -2를 가집니다. (`sympy.solve(3*x**2 - 3, x)` → $[-1, 1]$)
