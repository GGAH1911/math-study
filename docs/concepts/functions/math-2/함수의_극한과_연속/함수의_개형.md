# 함수의 개형

## 정확한 진술

함수 $f(x)$의 **개형**(graph form)이란, 함수의 정의역, 치역, 극한 거동, 극값, 증감 구간, 변곡점, 불연속점 등의 특성을 종합적으로 파악하여 나타낸 그래프의 **전체적인 모양**을 의미합니다.

수학2에서는 특히 미분 가능한 함수에 대해 도함수를 이용하여 개형을 분석합니다:
- $f'(x) > 0$인 구간에서 함수는 **증가**
- $f'(x) < 0$인 구간에서 함수는 **감소**
- $f'(x) = 0$인 점은 극값(극대·극소) 또는 변곡점의 후보

## 직관과 기하적 의미

함수의 개형을 파악한다는 것은 **"함수의 전체 생김새를 이해한다"**는 뜻입니다. 도함수를 통해 함수가 어느 구간에서 올라가고, 내려가고, 어디서 최고점·최저점을 갖는지 파악함으로써 정확한 그래프를 그릴 수 있습니다.

예를 들어 $f(x) = x^3 - 3x$에서 $f'(x) = 3x^2 - 3 = 3(x^2 - 1)$이므로 $x = -1, 1$에서 극값을 가집니다. $x < -1$일 때 증가, $-1 < x < 1$일 때 감소, $x > 1$일 때 증가하는 패턴을 보면, 전체 그래프의 모양을 머릿속으로 그릴 수 있습니다.

## 한 줄 예

$f(x) = x^3 - 3x^2 + 1$의 개형을 그리려면 $f'(x) = 3x^2 - 6x = 3x(x-2)$에서 극값 위치 $x=0, 2$를 찾고 각 구간의 증감을 판단하여 그래프를 완성합니다.
