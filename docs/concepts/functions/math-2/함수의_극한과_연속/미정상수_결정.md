# 미정상수 결정

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
함수가 특정 조건(연속성, 미분가능성 등)을 만족하도록 함수식에 포함된 미지의 상수 값을 찾아내는 과정입니다.

## 본문
미정상수란 함수식에 포함된 $a, b, c$와 같은 미지의 상수를 의미합니다. 미정상수의 결정이란 함수가 주어진 특정 조건, 즉 함수의 연속성, 미분가능성, 또는 극값 조건 등을 만족하도록 하는 상수의 값을 구하는 과정을 말합니다. 예를 들어, 함수 $f(x) = \begin{cases} x^2 + a & \text{if } x \leq 1 \\ 2x + b & \text{if } x > 1 \end{cases}$가 $x = 1$에서 연속이 되도록 하는 $a, b$의 값을 찾는 것이 대표적인 예입니다.

### 직관과 기하적 의미
기하학적으로 미정상수를 결정한다는 것은 그래프가 끊어지거나 튀지 않고 매끄럽게 이어지도록 만드는 값을 찾는 것입니다. 구간별로 정의된 함수가 경계점에서 끊어지지 않으려면, 해당 점에서의 좌극한과 우극한이 일치해야 하며, 그 값이 함수의 함숫값과도 같아야 합니다. 즉, 경계점에서 그래프가 하나로 연결되도록 상수를 조정하는 작업입니다.

### 기본 성질
함수가 특정 점에서 연속이기 위해서는 다음의 세 가지 조건을 모두 만족해야 합니다.
1. 함수의 극한값 $\lim_{x \to c} f(x)$이 존재해야 한다 (좌극한과 우극한이 같아야 함).
2. 함숫값 $f(c)$가 정의되어 있어야 한다.
3. 극한값과 함숫값이 일치해야 한다 ($\lim_{x \to c} f(x) = f(c)$).

## 학습 체크
- 구간별로 정의된 함수가 경계점에서 연속일 때, 좌극한과 우극한을 각각 구하여 일치하는지 확인했는가?
- 연속성뿐만 아니라 미분가능성 조건이 주어졌을 때, 좌미분계수와 우미분계수가 같음을 이용했는가?

## 관련 개념
- **함수의 극한과 연속**: 미정상수를 결정하는 가장 기본적인 조건으로, 극한값과 함숫값이 일치해야 한다는 연속성의 정의를 활용합니다.
