# 극한의정의

> **정의** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
$x$가 $a$에 한없이 가까워질 때 함수값 $f(x)$가 특정한 값 $L$에 한없이 가까워지면, $x \to a$일 때 $f(x)$의 극한은 $L$이라고 합니다.

## 본문
함수 $f(x)$가 $x = a$ 근처에서 정의되어 있을 때, $x$가 $a$에 가까워질수록 $f(x)$가 어떤 값 $L$에 가까워지면 이를 $\lim_{x \to a} f(x) = L$로 나타냅니다. 이를 엄밀하게 정의하면, 임의의 양수 $\varepsilon$에 대하여 어떤 양수 $\delta$가 존재하여 $0 < |x - a| < \delta$이면 $|f(x) - L| < \varepsilon$을 만족하는 상태를 의미합니다. 여기서 가장 중요한 점은 극한의 존재 여부가 $f(a)$의 값과는 무관하다는 것입니다. 극한은 $x$가 $a$에 도달하는 과정에서의 함수값의 거동만을 고려하며, $x=a$에서의 함숫값은 고려 대상이 아닙니다.

### 직관과 기하적 의미
그래프 상에서 $x$를 $a$를 향해 점점 더 가깝게 이동시킬 때, 그에 대응하는 $y$값이 하나의 목표 지점인 $L$을 향해 모여드는 모습으로 이해할 수 있습니다. 수열의 극한이 이산적인 점들의 움직임을 다룬다면, 함수의 극한은 연속적인 정의역 위에서 특정 점 근처의 수렴 경향을 다룹니다. 특히 함수는 양방향에서 접근이 가능하므로, 좌극한과 우극한이 모두 존재하고 그 값이 일치할 때만 극한이 존재한다고 판단합니다.

### 기본 성질
극한이 존재하는 경우, 함수의 합, 차, 실수배, 그리고 분모가 $0$이 아닌 경우의 나눗셈에 대해서도 극한의 연산이 성립합니다.

## 학습 체크
- $x$가 $a$로 갈 때의 극한값과 $x=a$에서의 함숫값이 서로 다른 경우를 구분할 수 있는가?
- 좌극한과 우극한이 각각 무엇을 의미하며, 왜 두 값이 같아야 극한이 존재한다고 하는가?

## 관련 개념
- **수열의 극한**: 정의역이 자연수로 제한된 경우로, 함수의 극한은 이를 연속적인 실수 범위로 확장한 개념입니다.
