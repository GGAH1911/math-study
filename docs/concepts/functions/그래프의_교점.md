### 정확한 진술

두 함수 $y=f(x)$와 $y=g(x)$의 그래프의 **교점**은 두 그래프가 만나는 점입니다. 교점의 $x$좌표는 방정식 $f(x)=g(x)$의 해이며, 교점의 좌표는 $(x, f(x))$ 또는 $(x, g(x))$ (두 값이 같음)입니다.

### 직관·기하적 의미

두 그래프의 교점은 두 함수가 **같은 높이의 같은 $x$값을 가지는 순간**을 나타냅니다. 좌표평면에서 시각적으로는 두 곡선(또는 직선)이 실제로 만나는 점입니다. 

예를 들어, 직선 $y = x + 1$과 포물선 $y = x^2$이 교차한다면, 그 교점에서는 $x^2 = x + 1$이 성립합니다. 교점의 개수는 이 방정식의 실근 개수와 같습니다.

### 한 줄 예

직선 $y = 2x$와 직선 $y = x + 3$의 교점은 $2x = x + 3$에서 $x = 3$이므로 점 $(3, 6)$입니다.

### 교점 찾기의 절차

교점의 좌표를 구하려면: ① $f(x) = g(x)$ 방정식을 세우고 ② $x$값(들)을 구한 후 ③ 그 $x$값을 $f(x)$ 또는 $g(x)$에 대입하여 $y$좌표를 구합니다.

```python
# 예: y = x^2 과 y = 2x의 교점
# x^2 = 2x → x^2 - 2x = 0 → x(x - 2) = 0
# 따라서 x = 0 또는 x = 2
# 교점: (0, 0), (2, 4)
```

두 그래프가 교점을 갖지 않으면 방정식 $f(x)=g(x)$가 실근을 가지지 않으며, 한 점에서만 접하면 중근을 가집니다.
