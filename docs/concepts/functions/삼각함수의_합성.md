### 정확한 진술

삼각함수의 합성은 $a\sin\theta + b\cos\theta$ (단, $a, b$는 상수) 형태의 삼각함수의 합을 하나의 삼각함수로 나타내는 것입니다. 구체적으로, 적절한 각 $\alpha$와 양수 $R$에 대하여

$$a\sin\theta + b\cos\theta = R\sin(\theta + \alpha)$$

또는

$$a\sin\theta + b\cos\theta = R\cos(\theta - \beta)$$

로 변환할 수 있습니다. 여기서 $R = \sqrt{a^2 + b^2}$이며, $\alpha$와 $\beta$는 $a, b$의 크기와 부호에 따라 결정됩니다.

### 직관과 기하적 의미

삼각함수의 덧셈공식 $\sin(\theta + \alpha) = \sin\theta\cos\alpha + \cos\theta\sin\alpha$를 역으로 활용하면, 두 개의 서로 다른 삼각함수 항을 하나로 통합할 수 있습니다. 기하학적으로는 두 개의 진동(사인파와 코사인파)을 합쳤을 때, 그것이 위상이 이동된 단일 진동파로 표현된다는 의미입니다. 진폭이 $\sqrt{a^2 + b^2}$로 커지고, 위상(각)이 $\alpha$만큼 이동합니다.

### 한 줄 예

$\sin\theta + \sqrt{3}\cos\theta$는 $a=1, b=\sqrt{3}$이므로 $R = \sqrt{1+3} = 2$이고, 적절한 $\alpha$를 구하면 $2\sin(\theta + 60°)$로 합성됩니다.
