### 정확한 진술

수열 $\{a_n\}$이 **양의 무한대로 발산**한다는 것은: 어떤 큰 양수 $M$을 정해도, 그보다 뒤의 모든 항이 $M$보다 크다는 뜻입니다.

$$\lim_{n \to \infty} a_n = +\infty \quad \Leftrightarrow \quad \forall M > 0, \exists N \in \mathbb{N} \text{ s.t. } n > N \Rightarrow a_n > M$$

마찬가지로 $\lim_{n \to \infty} a_n = -\infty$는 항들이 어떤 음수보다도 계속 작아진다는 뜻입니다.

$$\lim_{n \to \infty} a_n = -\infty \quad \Leftrightarrow \quad \forall M < 0, \exists N \in \mathbb{N} \text{ s.t. } n > N \Rightarrow a_n < M$$

### 직관/기하적 의미

수열의 극한이 무한대라는 것은 **극한값이 실수가 아니다**는 뜻입니다. 대신 항들이 한 방향으로 계속 커지거나 작아지는 경향을 나타냅니다.

수열을 수직선 위의 점들로 생각하면, 항들이 점점 오른쪽(또는 왼쪽)으로 멀어져 가는 것이죠. 유한한 값으로 수렴하지 않고, 끝없이 증가하거나 감소합니다.

극한값이 특정 수 $L$일 때와 달리, 무한대로 발산하는 수열은 **어느 구간에도 갇혀 있지 않습니다**.

### 한 줄 예

$a_n = 2n + 1$이면 $\lim_{n \to \infty} a_n = +\infty$ (항: $3, 5, 7, 9, \ldots$)

$a_n = -n^2$이면 $\lim_{n \to \infty} a_n = -\infty$ (항: $-1, -4, -9, -16, \ldots$)
