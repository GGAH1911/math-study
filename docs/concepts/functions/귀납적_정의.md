### 정확한 진술

귀납적 정의(귀납정의)는 수열의 첫 항 또는 처음 몇 항의 값(초기값)과 일반항을 이전 항들로 나타내는 관계식(점화식)으로 수열 전체를 정의하는 방법입니다.

**형태:**
- **초기값**: $a_1 = c_1$, $a_2 = c_2$, ... (한 개 이상)
- **점화식**: $a_n = f(a_{n-1}, a_{n-2}, \ldots)$ (충분히 큰 $n$에 대해)

이 두 가지로 수열 전체가 유일하게 결정됩니다.

### 직관과 의미

모든 항을 명시적 수식으로 나타내기 어려운 경우가 많습니다. 하지만 "첫 항이 무엇이고", "다음 항이 이전 항들로부터 어떻게 만들어지는가"를 알면 충분히 수열을 파악할 수 있습니다. 귀납적 정의는 이 발상에서 출발합니다. 한 항씩 규칙에 따라 계산해 나가므로, 프로그래밍의 반복문이나 동적계획법과도 자연스럽게 연결됩니다.

### 기본 예제

**등차수열**: $a_1 = 2$, $a_{n+1} = a_n + 3$
- 수열: 2, 5, 8, 11, 14, ...
- 명시식: $a_n = 3n - 1$

**등비수열**: $a_1 = 1$, $a_{n+1} = 2a_n$
- 수열: 1, 2, 4, 8, 16, ...
- 명시식: $a_n = 2^{n-1}$

**피보나치 수열**: $a_1 = 1$, $a_2 = 1$, $a_{n+2} = a_n + a_{n+1}$
- 수열: 1, 1, 2, 3, 5, 8, 13, 21, ...
- (일반항은 비네 공식으로 표현되지만 귀납식이 훨씬 간단합니다)

귀납적 정의는 고등학교 수열 단원에서 가장 자주 마주치는 형태이며, 점화식을 풀어 명시식을 구하는 것이 중요한 학습 목표입니다.
