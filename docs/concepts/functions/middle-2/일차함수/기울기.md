# 기울기

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
$x$의 변화량에 대한 $y$의 변화량의 비율입니다.

## 본문
일차함수 $y = ax + b$에서 기울기는 $a$를 의미합니다. 임의의 두 점 $(x_1, y_1)$과 $(x_2, y_2)$를 지나는 직선의 기울기는 $\dfrac{y_2 - y_1}{x_2 - x_1}$로 계산하며, 이때 분자는 $y$의 변화량, 분모는 $x$의 변화량을 나타냅니다.

### 직관과 기하적 의미
기울기는 직선이 얼마나 가파른지를 나타내는 척도입니다. 계단을 올라갈 때 가로 거리에 대한 세로 높이의 비율과 같은 개념으로 이해할 수 있습니다. 직선이 오른쪽으로 갈 때 위로 올라가면 기울기는 양수이고, 아래로 내려가면 음수입니다. 기울기의 절댓값이 클수록 직선은 더 가파르게 나타나며, 절댓값이 작을수록 더 완만하게 나타납니다. 예를 들어 기울기가 3이라면 오른쪽으로 한 칸 이동할 때마다 위로 3칸 올라간다는 것을 의미합니다.

### 기본 성질
기울기가 양수이면 $x$가 증가할 때 $y$도 증가하며, 기울기가 음수이면 $x$가 증가할 때 $y$는 감소합니다. 점 $(0, 1)$과 $(2, 5)$를 지나는 직선의 경우, 기울기는 $\dfrac{5-1}{2-0} = 2$가 됩니다. 이는 $x$가 1씩 증가할 때마다 $y$가 2씩 증가함을 의미하며, 이 직선의 일차함수 식은 $y = 2x + 1$입니다.

## 학습 체크

- 기울기의 절댓값 크기에 따른 직선의 기울어진 정도를 시각적으로 파악할 수 있는가?

## 관련 개념
- **일차함수**: 일차함수 식 $y = ax + b$에서 $x$의 계수인 $a$가 바로 기울기를 나타냅니다.
