# 기울기

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)
## 요약
$x$ 변화량 대비 $y$ 변화량

## 본문

일차함수 $y = ax + b$에서 기울기는 $a$입니다. 임의의 두 점 $(x_1, y_1)$과 $(x_2, y_2)$를 지나는 직선의 기울기는 다음과 같이 계산합니다:

$$\text{기울기} = \frac{y_2 - y_1}{x_2 - x_1}$$

분자는 $y$의 변화량, 분모는 $x$의 변화량입니다.

### 직관/기하적 의미
기울기는 직선이 얼마나 가파른지를 나타냅니다. 오른쪽으로 갈 때 직선이 올라가면 기울기는 양수, 내려가면 음수입니다. 예를 들어 기울기가 3이라면 오른쪽으로 한 칸 이동할 때마다 위로 3칸 올라간다는 뜻입니다. 기울기의 절댓값이 크면 직선이 더 가파르고, 작으면 더 완만합니다. 계단을 올라갈 때 가로 거리에 대한 세로 높이의 비율과 같은 개념입니다.

### 한 줄 예
점 $(0, 1)$과 $(2, 5)$를 지나는 직선의 기울기는 $\dfrac{5-1}{2-0} = \dfrac{4}{2} = 2$입니다. 일차함수로는 $y = 2x + 1$이며, $x$가 1씩 증가할 때마다 $y$는 2씩 증가합니다.
