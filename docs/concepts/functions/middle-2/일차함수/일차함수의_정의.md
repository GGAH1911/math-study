# 일차함수의 정의

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
일차함수는 $f(x) = ax + b$ ($a \neq 0$) 꼴로 나타내어지는 함수로, 그래프가 직선의 형태를 띠며 일정한 변화율을 갖는 함수입니다.

## 본문
일차함수는 다음과 같은 형태의 식으로 나타낼 수 있는 함수를 말합니다:
$$f(x) = ax + b$$
이때 $a$와 $b$는 상수이며, 반드시 $a \neq 0$이어야 합니다. 상수항 $b$에 대해서는 특별한 제한 조건이 없으므로 $b=0$인 경우도 포함됩니다. 예를 들어 $f(x) = 3x$와 같은 식도 일차함수에 해당합니다.

### 직관과 기하적 의미
일차함수의 그래프는 평면 위에 **직선**의 형태로 나타납니다. 이때 상수 $a$는 그래프의 기울기를 결정하며, $a$의 절댓값이 클수록 직선은 더 가파르게 그려집니다. $a > 0$이면 오른쪽 위로 향하는 직선이 되고, $a < 0$이면 오른쪽 아래로 내려가는 직선이 됩니다. 상수 $b$는 **y절편**이라고 하며, 그래프가 y축과 만나는 점의 y좌표를 의미합니다. 즉, $f(0) = b$가 성립하여 직선이 y축의 어느 지점을 통과하는지 알려줍니다.

### 기본 성질
일차함수의 가장 중요한 특징은 **일정한 변화율**을 가진다는 점입니다. $x$의 값이 1만큼 증가할 때마다 $y$의 값은 항상 $a$만큼 일정하게 변화합니다. 이를 수식으로 나타내면 $f(x+1) - f(x) = a$가 됩니다. 예를 들어 $f(x) = 2x + 3$이라는 함수가 있다면, $x$가 1 증가할 때마다 $y$는 2씩 증가하며, 그래프는 점 $(0, 3)$을 지나는 직선이 됩니다.

## 학습 체크
- $a$의 값이 0이 되면 왜 일차함수가 아닌지 설명할 수 있는가?
- 기울기 $a$와 y절편 $b$를 보고 그래프의 모양과 위치를 예측할 수 있는가?
- $x$의 변화량에 따른 $y$의 변화량을 보고 기울기를 구할 수 있는가?

## 관련 개념
- **일차함수**: 일차함수의 그래프는 직선이며, 기울기와 y절편을 통해 식을 결정할 수 있습니다.
- **변화율**: 일차함수에서 $x$의 변화량에 대한 $y$의 변화량의 비율은 항상 일정하며, 이는 기울기와 같습니다.
