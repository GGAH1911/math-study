# 기울기 공식

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
기울기는 $x$의 변화량에 대한 $y$의 변화량의 비율로, 직선이 기울어진 정도를 나타내는 값입니다.

## 본문
좌표평면 위의 두 점 $P_1(x_1, y_1)$과 $P_2(x_2, y_2)$ (단, $x_1 \neq x_2$)를 지나는 직선의 기울기는 다음과 같은 공식으로 정의됩니다.
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x}$$
여기서 $\Delta y = y_2 - y_1$은 $y$의 변화량이며, $\Delta x = x_2 - x_1$은 $x$의 변화량입니다.

### 직관과 기하적 의미
기울기는 직선이 수평면에 대해 얼마나 가파른지를 나타내는 실수값입니다. 이는 $x$가 1만큼 증가할 때 $y$가 얼마나 변하는가를 보여주는 변화의 비율을 의미합니다.

### 기본 성질
- $m > 0$이면 직선은 오른쪽 위로 향하며, $m < 0$이면 오른쪽 아래로 향합니다.
- $m = 0$이면 직선은 $x$축과 평행한 수평선이 됩니다.
- 기울기의 절댓값 $|m|$이 클수록 직선은 더욱 가파르게 나타납니다.
- 점 $A(2, 5)$와 점 $B(6, 13)$을 지나는 직선의 기울기는 $\frac{13-5}{6-2} = 2$입니다.

## 학습 체크
- 두 점의 좌표가 주어졌을 때 $x$의 변화량이 0이 되지 않도록 주의하여 계산하였는가?
- 기울기의 부호에 따라 직선이 나타내는 방향(증가 또는 감소)을 올바르게 해석하였는가?

## 관련 개념
- **지수함수와 로그함수**: 곡선 위의 두 점 사이의 기울기를 구하면 평균 변화율을 구할 수 있으며, 이는 나중에 배울 미분의 기초가 됩니다.
