# 두 점에서 식 구하기

> **예제** · 중2 · 단원: [일차함수](/concepts/일차함수)
## 요약
$(1,3), (3,7)$ 지나는 직선

## 본문

### 문제

두 점 $(1, 3)$과 $(3, 7)$을 지나는 직선의 방정식을 구하세요.

### 단계별 풀이

**1단계: 기울기 구하기**  
직선의 기울기는 두 점의 좌표 변화로 구합니다. 기울기 $a$는 다음과 같이 계산됩니다.

$$a = \frac{y_2 - y_1}{x_2 - x_1} = \frac{7 - 3}{3 - 1} = \frac{4}{2} = 2$$

두 점 사이의 수직 변화를 수평 변화로 나누어 직선의 기울기를 얻는 것이 핵심입니다.

**2단계: 일차함수의 형태 설정**  
기울기를 알았으므로, 구하는 직선은 $y = 2x + b$ 형태입니다. 이제 절편 $b$를 구해야 합니다.

**3단계: 한 점을 대입하여 절편 구하기**  
직선이 점 $(1, 3)$을 지나므로, $x = 1$, $y = 3$을 대입합니다.

$$3 = 2 \cdot 1 + b$$
$$3 = 2 + b$$
$$b = 1$$

다른 점 $(3, 7)$을 대입해도 같은 결과를 얻으므로 검증됩니다 ($7 = 2 \cdot 3 + 1 = 7$ ✓).

### 답

$$y = 2x + 1$$

### 변형/주의

- **다른 표현**: 일반형으로는 $2x - y + 1 = 0$ 또는 $2x - y = -1$로도 나타낼 수 있습니다.
- **계산 순서**: 기울기를 먼저 구하고 절편을 구하는 것이 효율적입니다.
- **검증 습관**: 구한 식에 두 점을 모두 대입해 확인하면 실수를 줄일 수 있습니다.

*sympy 검증: `sympy.solve([3 - 2*1 - b, 7 - 2*3 - b], [b])` → $b = 1$*
