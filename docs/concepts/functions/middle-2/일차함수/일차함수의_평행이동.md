# 일차함수의 평행이동

## 정확한 진술

일차함수 $y = ax + b$를 **수평 방향으로 $p$만큼, 수직 방향으로 $q$만큼** 평행이동하면, 새로운 함수는 다음과 같습니다:

$$y = a(x - p) + b + q$$

이는 좌표 변환으로도 표현됩니다: 원래 점 $(x, y)$가 $(x + p, y + q)$로 이동합니다. 오른쪽으로 이동할 때는 $p > 0$, 왼쪽으로 이동할 때는 $p < 0$입니다. 위로 이동할 때는 $q > 0$, 아래로 이동할 때는 $q < 0$입니다.

## 직관과 기하적 의미

일차함수의 그래프는 직선이므로, 평행이동은 **직선 전체를 그대로의 기울기를 유지하면서 평행하게 밀어내는** 것입니다. 기울기 $a$는 변하지 않고, $y$절편만 변합니다.

수식으로 보면 왜 $(x - p)$일까요? 점 $(x, y)$가 오른쪽으로 $p$만큼 이동하면 새 점의 좌표는 $(x + p, y')$입니다. 반대로 생각하면, 이동 후 점의 $x$좌표에서 $p$를 빼면 원래 점의 $x$좌표가 됩니다. 따라서 $y' = a(x - p) + b + q$가 됩니다.

## 한 줄 예

$y = 2x + 1$을 오른쪽으로 3, 위로 2만큼 평행이동하면 $y = 2(x - 3) + 1 + 2 = 2x - 3$입니다. 기울기는 여전히 2이고, $y$절편은 1에서 −3으로 변합니다. (검산: `sympy.expand(2*(x - 3) + 1 + 2)` → $2x - 3$)
