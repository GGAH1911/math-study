# 직선의 교점

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 정확한 진술

두 직선 $y = m_1x + b_1$과 $y = m_2x + b_2$의 **교점**은 두 식을 동시에 만족하는 점 $(x_0, y_0)$입니다. 즉, $y_0 = m_1x_0 + b_1 = m_2x_0 + b_2$를 모두 만족하는 순서쌍입니다. 더 일반적으로는 두 직선이 동시에 지나가는 모든 점의 집합입니다.

## 직관과 기하적 의미

좌표평면 위에서 두 직선은 세 가지 위치 관계를 가질 수 있습니다:

1. **한 점에서 만나는 경우** (일반적): 기울기가 다르면 ($m_1 \neq m_2$) 두 직선은 정확히 한 점에서 만납니다. 이것이 교점입니다.

2. **평행한 경우**: 기울기가 같고 y절편이 다르면 ($m_1 = m_2$, $b_1 \neq b_2$) 두 직선은 절대 만나지 않으므로 교점이 존재하지 않습니다.

3. **일치하는 경우**: 두 식이 정확히 같으면 ($m_1 = m_2$, $b_1 = b_2$) 무수히 많은 교점을 가집니다.

교점을 구하려면 두 일차식을 같다고 놓고 방정식을 풀면 됩니다:
$$m_1x + b_1 = m_2x + b_2 \Rightarrow (m_1 - m_2)x = b_2 - b_1$$

$m_1 \neq m_2$일 때, $x = \dfrac{b_2 - b_1}{m_1 - m_2}$를 얻고, 이를 원래 식에 대입하여 $y_0$를 구합니다.

## 한 줄 예

직선 $y = 2x + 1$과 $y = -x + 4$의 교점: $2x + 1 = -x + 4$에서 $x = 1$, $y = 3$이므로 교점은 $(1, 3)$입니다. (sympy.solve([y - 2*x - 1, y + x - 4], [x, y])로 확인 가능)
