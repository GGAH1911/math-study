# 직선의 교점

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
두 직선의 방정식을 동시에 만족하는 점을 의미하며, 두 직선의 기울기에 따라 교점의 개수가 결정됩니다.

## 본문
두 직선 $y = m_1x + b_1$과 $y = m_2x + b_2$의 교점은 두 식을 동시에 만족하는 점 $(x_0, y_0)$입니다. 즉, $y_0 = m_1x_0 + b_1 = m_2x_0 + b_2$를 모두 만족하는 순서쌍이며, 기하학적으로는 두 직선이 동시에 지나는 모든 점의 집합을 의미합니다.

### 직관과 기하적 의미
좌표평면 위에서 두 직선은 기울기에 따라 세 가지 위치 관계를 가집니다. 첫째, 기울기가 서로 다르면($m_1 \neq m_2$) 두 직선은 정확히 한 점에서 만나며 이때의 점이 교점이 됩니다. 둘째, 기울기는 같지만 $y$절편이 다르면($m_1 = m_2, b_1 \neq b_2$) 두 직선은 평행하여 만나지 않으므로 교점이 존재하지 않습니다. 셋째, 기울기와 $y$절편이 모두 같으면($m_1 = m_2, b_1 = b_2$) 두 직선은 일치하며 무수히 많은 교점을 가집니다.

### 기본 성질
교점의 좌표를 구하기 위해서는 두 일차식을 같다고 놓은 방정식 $m_1x + b_1 = m_2x + b_2$를 풀어 $x$값을 구한 뒤, 이를 원래 식에 대입하여 $y$값을 찾습니다. 식을 정리하면 $(m_1 - m_2)x = b_2 - b_1$이 되며, 기울기가 다를 때 $x = \dfrac{b_2 - b_1}{m_1 - m_2}$로 계산할 수 있습니다. 예를 들어 $y = 2x + 1$과 $y = -x + 4$의 교점은 $2x + 1 = -x + 4$를 통해 $x=1$을 얻고, 이를 대입해 $y=3$을 구하여 $(1, 3)$이 됩니다.

## 학습 체크
- 두 직선의 기울기가 같을 때 교점이 생기지 않는 조건은 무엇인가요?
- 두 직선의 식이 완전히 일치할 때 교점의 개수는 몇 개인가요?
- 두 일차함수 식을 연립하여 교점의 좌표를 구하는 과정은 무엇인가요?

## 관련 개념
- **이차함수**: 일차함수와 이차함수가 만나는 경우, 이차방정식의 해를 통해 교점의 $x$좌표를 구할 수 있습니다.
