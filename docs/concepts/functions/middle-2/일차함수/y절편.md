# y절편

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 정확한 진술

함수의 그래프가 **y축과 만나는 점의 y좌표**를 **y절편**이라고 합니다. y축 위의 모든 점은 x좌표가 0이므로, 함수 $f(x)$의 y절편은 $f(0)$의 값입니다.

## 직관과 기하적 의미

좌표평면에서 y축은 $x = 0$인 수직선입니다. 따라서 어떤 곡선이든 y축과 만나는 지점을 찾으려면, 단순히 **함수에 $x = 0$을 대입**하면 됩니다. 예를 들어, 직선 $y = 2x + 3$은 $x = 0$일 때 $y = 3$이므로, 점 $(0, 3)$에서 y축과 만나고, y절편은 3입니다.

y절편은 그래프의 **시작점** 같은 역할을 합니다. 직선의 방정식 $y = mx + b$ 형태에서 $b$가 바로 y절편이고, 이는 직선이 y축을 "어디서 자르는가"를 알려줍니다.

## 한 줄 예

- 직선 $y = 2x + 3$의 y절편: $f(0) = 3$
- 포물선 $y = x^2 - 4x + 5$의 y절편: $f(0) = 5$
- 함수 $y = \log x$의 y절편: 존재하지 않음 ($x = 0$에서 정의되지 않음)

## 구하는 방법

y절편을 구하는 것은 매우 간단합니다:

$$x = 0\text{을 함수에 대입} \rightarrow y\text{의 값이 y절편}$$

예를 들어 $f(x) = 3x^2 + 2x - 7$의 y절편을 구하면:
$$f(0) = 3(0)^2 + 2(0) - 7 = -7$$

따라서 y절편은 **−7**입니다. (검증: `sympy.sympify("3*x**2 + 2*x - 7").subs("x", 0)` → -7)

## 주의할 점

- 모든 함수가 y절편을 가지는 것은 아닙니다. $y = \log x$나 $y = \frac{1}{x}$처럼 $x = 0$에서 정의되지 않는 함수는 y절편이 없습니다.
- y절편은 **하나**만 존재합니다. 함수는 각 x값에 대해 최대 하나의 y값만 가지기 때문입니다.
- x절편(0이 되는 x값)과 혼동하지 마세요. 이들은 서로 다른 개념입니다.
