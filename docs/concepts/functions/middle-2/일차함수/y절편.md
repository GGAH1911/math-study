# y절편

> **정의** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
함수의 그래프가 $y$축과 만나는 점의 $y$좌표를 의미합니다.

## 본문
함수의 그래프가 $y$축과 만나는 점의 $y$좌표를 **y절편**이라고 합니다. $y$축 위에 있는 모든 점은 $x$좌표가 $0$이라는 특징이 있으므로, 함수 $f(x)$의 $y$절편은 $x$에 $0$을 대입했을 때 나오는 값인 $f(0)$과 같습니다.

### 직관과 기하적 의미
좌표평면에서 $y$축은 $x=0$인 지점들을 모아놓은 수직선입니다. 따라서 어떤 그래프가 $y$축의 어느 지점을 통과하는지 알고 싶다면, 단순히 함수식에 $x=0$을 대입하면 됩니다. 예를 들어, 직선 $y=2x+3$은 $x=0$일 때 $y=3$이 되므로, 점 $(0, 3)$에서 $y$축과 만나며 이때의 $y$절편은 $3$이 됩니다. 일차함수 $y=mx+b$의 형태에서 $b$가 바로 $y$절편이며, 이는 직선이 $y$축을 어느 높이에서 끊어 지나가는지를 보여주는 중요한 지표가 됩니다.

### 기본 성질
- $y$절편을 구하는 방법은 함수식에 $x=0$을 대입하여 $y$값을 찾는 것입니다. 예를 들어 $f(x)=3x^2+2x-7$의 $y$절편은 $f(0)=-7$입니다.
- 모든 함수가 $y$절편을 갖는 것은 아닙니다. $y=\log x$나 $y=\frac{1}{x}$처럼 $x=0$에서 함수가 정의되지 않는 경우에는 $y$절편이 존재하지 않습니다.
- 함수는 하나의 $x$값에 대해 하나의 $y$값만 대응하므로, $y$절편은 오직 하나만 존재합니다.
- $y$값이 $0$이 되는 $x$값을 찾는 **x절편**과는 서로 다른 개념이므로 주의해야 합니다.

## 학습 체크
- 함수식에 $x=0$을 대입하여 $y$값을 구할 수 있는가?
- $x=0$에서 함수가 정의되지 않는 경우 $y$절편이 없음을 이해하고 있는가?
- $y$절편과 $x$절편의 차이점을 구분할 수 있는가?

## 관련 개념
- **도형의 방정식**: $y$절편은 좌표평면 위에 그려지는 직선이나 곡선과 같은 도형의 위치를 결정하는 중요한 요소입니다.
