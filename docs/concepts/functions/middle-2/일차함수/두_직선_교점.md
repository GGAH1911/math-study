# 두 직선 교점

> **예제** · 중2 · 단원: [일차함수](/concepts/일차함수)
## 요약
연립방정식으로 교점

## 본문

### 문제

두 직선 $y = 2x - 1$과 $y = -x + 5$의 교점을 구하세요.

### 단계별 풀이

**1단계: 두 식을 같다고 놓기**

교점에서는 두 직선이 만나므로, 같은 $x$ 값에서 같은 $y$ 값을 가집니다. 따라서 두 식의 우변을 같다고 놓으면:
$$2x - 1 = -x + 5$$

**2단계: 연립방정식 풀기**

$x$에 대해 정리합니다. 왼쪽에 $x$ 항을, 오른쪽에 상수항을 모으면:
$$2x + x = 5 + 1$$
$$3x = 6$$
$$x = 2$$

**3단계: 교점의 $y$ 좌표 구하기**

$x = 2$를 원래 식 중 하나(보통 계산이 쉬운 식)에 대입합니다. 여기서는 첫 번째 식을 사용:
$$y = 2(2) - 1 = 4 - 1 = 3$$

다른 식으로 확인하면 $y = -(2) + 5 = 3$ ✓ 같은 값이므로 맞습니다.

### 답

두 직선의 교점은 $(2, 3)$입니다.

### 변형/주의

- **식을 어느 것부터 대입해도 같은 답이 나옵니다.** 계산 실수를 피하려면 한 식으로 구한 $y$값을 다른 식에 대입해 검증하세요.
- **분수가 나오는 경우도 있습니다.** 예를 들어 $y = \frac{1}{2}x + 1$과 $y = -\frac{2}{3}x + 4$의 교점을 구하면 $x = \frac{18}{7}$처럼 분수 좌표가 됩니다. 통분하거나 분수 계산에 유의하세요.
- **실제로 만나지 않는 경우:** 두 직선이 평행하면 교점이 없습니다. 계산 중 $0 = 5$ 같은 모순이 나오면 교점이 없다는 뜻입니다.

검산 (sympy): `sympy.solve([Eq(y, 2*x - 1), Eq(y, -x + 5)], [x, y])`
