# 두 직선 교점

> **예제** · 중2 · 단원: [일차함수](/concepts/일차함수)

## 요약
두 직선의 교점은 두 식을 연립방정식으로 풀어 구할 수 있습니다.

## 본문
두 직선 $y = 2x - 1$과 $y = -x + 5$의 교점을 구하세요.

### 단계별 풀이
**1단계: 두 식을 같다고 놓기**
교점에서는 두 직선이 만나므로, 같은 $x$ 값에서 같은 $y$ 값을 가집니다. 따라서 두 식의 우변을 같다고 놓으면 다음과 같습니다.
$$2x - 1 = -x + 5$$

**2단계: 연립방정식 풀기**
$x$에 대해 정리하기 위해 $x$ 항은 왼쪽으로, 상수항은 오른쪽으로 모읍니다.
$$2x + x = 5 + 1$$
$$3x = 6$$
$$x = 2$$

**3단계: 교점의 $y$ 좌표 구하기**
$x = 2$를 원래 식 중 하나에 대입합니다. 첫 번째 식을 사용하면 다음과 같습니다.
$$y = 2(2) - 1 = 4 - 1 = 3$$
다른 식에 대입해도 $y = -(2) + 5 = 3$으로 동일한 값이 나옵니다.

### 답과 변형
두 직선의 교점은 $(2, 3)$입니다.

**주의사항**
- 어떤 식에 대입해도 결과는 같으므로, 계산 후 다른 식에 대입하여 검산하는 습관이 중요합니다.
- 계산 결과가 분수로 나올 수 있으므로 통분과 분수 연산에 주의해야 합니다.
- 두 직선이 평행하여 만나지 않는 경우에는 $0 = 5$와 같은 모순된 식이 나타납니다.

## 학습 체크
- 두 식의 우변을 같다고 놓아 $x$ 값을 구할 수 있는가?
- 구한 $x$ 값을 다시 식에 대입하여 $y$ 값을 정확히 계산할 수 있는가?
- 평행한 두 직선의 경우 교점이 존재하지 않음을 이해하고 있는가?

## 관련 개념
- **일차함수**: 일차함수 그래프의 교점은 두 함수가 같은 $x$ 값에 대해 같은 $y$ 값을 갖는 지점을 의미합니다.
