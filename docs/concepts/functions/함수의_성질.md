### 정확한 진술

함수 $f: X \to Y$를 다음과 같이 정의할 때 중요한 성질들을 구분합니다.

**기본 용어:**
- **정의역** $X$: 함수에 입력되는 값의 범위
- **치역**: 함수값 $f(x)$로 실제로 나타나는 값들의 집합
- **공역** $Y$: 함수가 대응되도록 정하는 범위 (항상 치역 ⊆ 공역)

**함수의 성질:**
- **일대일함수(단사)**: 다른 입력이 같은 출력을 주지 않음 → $f(x_1) = f(x_2) \Rightarrow x_1 = x_2$
- **전사함수**: 공역의 모든 원소가 함수값으로 나타남 → 치역 = 공역
- **일대일대응(전단사)**: 일대일함수이면서 동시에 전사함수 → 역함수 $f^{-1}$가 존재

### 직관/기하적 의미

그래프에서 이 성질들을 시각적으로 판정할 수 있습니다. **일대일함수**는 수평선 $y = c$가 그래프와 최대 한 점에서만 만나는 함수들입니다. 예를 들어 $y = x^3$이나 $y = 2^x$는 일대일함수입니다. **전사함수**는 공역의 모든 값이 실제로 그래프 위에 존재한다는 뜻으로, $f: \mathbb{R} \to \mathbb{R}$에서 $f(x) = x^3$이 전사함수의 예입니다. **일대일대응**이면 함수가 "완벽하게 짝을 이루어" 역함수를 정의할 수 있게 됩니다.

### 한 줄 예

$f(x) = x^2$는 정의역이 $\mathbb{R}$ 전체일 때 일대일함수가 아니지만 ($f(-1) = f(1) = 1$), 정의역을 $[0, \infty)$로 제한하면 일대일대응이 되어 역함수 $f^{-1}(x) = \sqrt{x}$가 존재합니다.
