### 정확한 진술

두 함수 $f(x)$와 $g(x)$가 주어질 때, **함수의 합** $(f+g)(x)$를 다음과 같이 정의합니다.

$$(f+g)(x) = f(x) + g(x)$$

여기서 정의역은 $f$와 $g$의 정의역이 모두 포함하는 집합(공통 정의역)입니다. 즉, 모든 $x$에 대해 $f(x)$와 $g(x)$ 모두를 계산할 수 있어야 합니다.

### 직관/기하적 의미

함수의 합은 두 함수의 함숫값을 각 점에서 더하는 연산입니다. 그래프로 생각하면, 점 $x$에서 $(f+g)(x)$는 $f(x)$의 높이와 $g(x)$의 높이를 더한 값입니다.

예를 들어 $f(x) = 2x$와 $g(x) = x^2$이 주어졌을 때, $x=3$에서 $f(3) = 6$, $g(3) = 9$이므로 $(f+g)(3) = 15$입니다. 그래프상에서는 각 점의 $y$좌표를 더해서 새로운 곡선을 만드는 것으로 시각화됩니다.

### 한 줄 예

$f(x) = 3x-1$, $g(x) = x^2+2$일 때, $(f+g)(x) = x^2 + 3x + 1$ (검산: `sympy.symbols('x'); f = 3*x - 1; g = x**2 + 2; (f + g).expand()`)

### 주의할 점

함수의 합을 정의할 때는 **정의역에 주의**해야 합니다. 분수함수나 무리함수가 포함되면 정의역이 제한될 수 있습니다. 예를 들어 $f(x) = \frac{1}{x}$와 $g(x) = \sqrt{x}$의 합은 $x > 0$인 범위에서만 정의됩니다.
