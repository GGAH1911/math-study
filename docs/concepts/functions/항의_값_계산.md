### 정확한 진술

수열 $\{a_n\}$의 **일반항** 또는 **점화식**이 주어질 때, 특정 자연수 $n$에 해당하는 항 $a_n$의 값을 구하는 것을 항의 값 계산이라 합니다. 예를 들어 일반항이 $a_n = 3n^2 - 2n + 1$로 주어지면, $n = 5$를 대입하여 $a_5 = 3(5)^2 - 2(5) + 1 = 66$으로 계산합니다. 점화식으로 정의된 경우(예: $a_1 = 1$, $a_{n+1} = 2a_n + 1$)에는 초기항부터 차례대로 계산하거나, 일반항 공식을 먼저 유도한 후 대입하는 방식을 사용합니다.

### 직관과 의미

수열은 규칙을 따르는 수들의 순서 있는 나열입니다. 그 규칙을 명확한 식으로 나타낸 것이 **일반항**이며, 일반항을 알면 수열 전체를 일일이 나열할 필요 없이 원하는 위치의 항을 즉시 계산할 수 있습니다. 이는 수열의 개념을 실제로 활용하는 가장 기본 과정입니다. 수열을 $n$에 대한 함수로 보면, 항의 값 계산은 함수값 계산과 본질적으로 같습니다. 이 능력은 부분합, 급수, 점화식 풀이, 나아가 극한과 수렴성 개념으로 나아가기 위한 필수 기초가 됩니다.

### 주요 공식

**등차수열** (첫째항 $a$, 공차 $d$):
$$a_n = a + (n-1)d$$

**등비수열** (첫째항 $a$, 공비 $r$):
$$a_n = a \cdot r^{n-1}$$

### 간단한 예

등차수열에서 $a_1 = 2$, 공차 $d = 3$일 때, 일반항은 $a_n = 2 + (n-1) \times 3 = 3n - 1$입니다. 따라서 $a_{10} = 3 \times 10 - 1 = 29$입니다.

(검산: `sympy.symbols('n'); a_n = 3*n - 1; print(a_n.subs(n, 10))` → 29)
