# 등차수열 일반항

## 본문

### 정확한 진술

등차수열 $\{a_n\}$의 첫 항이 $a_1$이고 공차가 $d$일 때, $n$번째 항(일반항)은 다음과 같이 나타냅니다.

$$a_n = a_1 + (n-1)d$$

여기서 $n$은 항의 순서를 나타내는 자연수입니다.

### 직관과 기하적 의미

등차수열은 일정한 크기 $d$만큼 계속 더해가면서 만들어집니다. 첫 항 $a_1$에서 시작해 공차 $d$를 한 번, 두 번, 세 번... 더하면 각 항을 얻습니다.

$$a_1, \quad a_1 + d, \quad a_1 + 2d, \quad a_1 + 3d, \cdots$$

$n$번째 항에 도달하려면 첫 항부터 공차를 몇 번 더했을까요? $(n-1)$번입니다. 왜냐하면 첫 항은 그 자체로 이미 있고, 그 다음부터 더해나가기 때문입니다. 수직선 위에서 일정한 간격으로 점들이 늘어서 있는 모습을 상상하면, 일반항 공식은 이 규칙적인 배치를 수식으로 표현한 것입니다.

### 한 줄 예

첫 항이 3, 공차가 5인 등차수열에서 $a_7 = 3 + (7-1) \times 5 = 3 + 30 = 33$입니다.
(검산: `sympy.symbols('n'); 3 + (7-1)*5` → 33)

### 공식 변형

첫 항을 $a_1$ 대신 특정 항 $a_m$으로부터 표현하려면:

$$a_n = a_m + (n-m)d$$

이 공식은 임의의 두 항 사이의 관계를 나타낼 때 유용합니다.
