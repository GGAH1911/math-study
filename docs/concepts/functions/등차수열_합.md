### 정확한 진술

첫째항이 $a$이고 공차가 $d$인 등차수열의 첫째항부터 $n$번째 항까지의 합을 $S_n$이라 하면:

$$S_n = \frac{n}{2}(2a + (n-1)d)$$

또는 첫째항 $a_1$과 마지막항 $a_n$을 이용하면:

$$S_n = \frac{n}{2}(a_1 + a_n)$$

### 직관·기하적 의미

등차수열의 합을 구하는 방법은 **대칭성**에서 비롯됩니다. 첫째항부터 $n$번째 항까지를 두 가지 순서로 나열해 보세요:

$$S_n = a + (a+d) + (a+2d) + \cdots + (a+(n-1)d)$$
$$S_n = (a+(n-1)d) + (a+(n-2)d) + \cdots + (a+d) + a$$

두 식을 더하면:
$$2S_n = (2a + (n-1)d) + (2a + (n-1)d) + \cdots + (2a + (n-1)d)$$

즉, $2a + (n-1)d$이 $n$번 더해집니다. 따라서:
$$S_n = \frac{n}{2}(2a + (n-1)d)$$

이는 **등차수열의 모든 항들이 일정하게 증가하기 때문에, 첫항과 마지막항의 평균에 항의 개수를 곱하면 합이 된다**는 의미입니다.

### 한 줄 예

첫째항이 2, 공차가 3인 등차수열에서 10항까지의 합은 $S_{10} = \frac{10}{2}(2 \cdot 2 + 9 \cdot 3) = 5 \cdot 31 = 155$입니다.

(검산: `sum([2 + i*3 for i in range(10)])` = 155)
