# 합성함수 미분 예제

> **예제** · 미적분 · 단원: [합성함수의 미분 (연쇄법칙)](/concepts/합성함수의_미분)

## 요약
$y=\sin(2x), e^{x^2}$

## 본문 (학습 시 채워짐)

### 문제

다음 함수들의 도함수를 연쇄법칙을 이용하여 구하시오.
1. $y = \sin(2x)$
2. $y = e^{x^2}$

### 단계별 풀이

**예제 1: $y = \sin(2x)$**

연쇄법칙을 적용하기 위해 합성을 안쪽에서 바깥쪽으로 인식합니다.
- 안쪽 함수: $u = 2x$ → $\frac{du}{dx} = 2$
- 바깥쪽 함수: $y = \sin(u)$ → $\frac{dy}{du} = \cos(u)$

연쇄법칙을 적용하면:
$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = \cos(u) \cdot 2 = 2\cos(2x)$$

**예제 2: $y = e^{x^2}$**

마찬가지로 합성을 분해합니다.
- 안쪽 함수: $u = x^2$ → $\frac{du}{dx} = 2x$
- 바깥쪽 함수: $y = e^u$ → $\frac{dy}{du} = e^u$

연쇄법칙을 적용하면:
$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = e^u \cdot 2x = 2x e^{x^2}$$

### 답

1. $\frac{dy}{dx} = 2\cos(2x)$
2. $\frac{dy}{dx} = 2x e^{x^2}$

(검증: `sympy.diff(sympy.sin(2*x), x)` → $2\cos(2x)$ ✓ / `sympy.diff(sympy.exp(x**2), x)` → $2x e^{x^2}$ ✓)

### 변형/주의

- **핵심**: 연쇄법칙은 "바깥쪽 미분 × 안쪽 미분"을 외우는 것이 중요합니다. 헷갈릴 때는 항상 안쪽부터 시작하세요.
- **변형 1**: $y = \sin(3x)$이면? $\frac{dy}{dx} = 3\cos(3x)$ (상수배만 달라집니다)
- **변형 2**: $y = e^{-x^2}$이면? $\frac{dy}{dx} = -2x e^{-x^2}$ (안쪽 미분이 $-2x$가 됩니다)
- **주의**: 합성함수를 단순히 "각각 미분해서 곱하기"로 착각하는 실수를 피하세요. 반드시 연쇄법칙의 순서를 지켜야 합니다.
