# 유리화 부정형

> **예제** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
$\lim_{x\to 0}(\sqrt{x+1}-1)/x$

## 본문 (학습 시 채워짐)

### 문제

다음 극한값을 구하시오.
$$\lim_{x\to 0}\frac{\sqrt{x+1}-1}{x}$$

### 단계별 풀이

**1단계: 부정형 확인**

$x\to 0$일 때, 분자는 $\sqrt{0+1}-1 = 0$, 분모도 $0$입니다.

따라서 $\frac{0}{0}$ 꼴의 부정형이므로 직접 대입은 불가능합니다. 식을 정리해야 합니다.

**2단계: 켤레식을 이용한 유리화**

분자의 무리식을 없애기 위해 켤레식 $\sqrt{x+1}+1$을 분자와 분모에 곱합니다:

$$\lim_{x\to 0}\frac{\sqrt{x+1}-1}{x} \cdot \frac{\sqrt{x+1}+1}{\sqrt{x+1}+1} = \lim_{x\to 0}\frac{(\sqrt{x+1})^2 - 1^2}{x(\sqrt{x+1}+1)}$$

분자에 합차공식 $(a-b)(a+b)=a^2-b^2$를 적용하면:

$$= \lim_{x\to 0}\frac{(x+1)-1}{x(\sqrt{x+1}+1)} = \lim_{x\to 0}\frac{x}{x(\sqrt{x+1}+1)}$$

**3단계: 약분과 극한값 계산**

$x\neq 0$일 때 $x$를 약분하면:

$$= \lim_{x\to 0}\frac{1}{\sqrt{x+1}+1}$$

이제 부정형이 해소되었으므로 직접 대입하면:

$$= \frac{1}{\sqrt{0+1}+1} = \frac{1}{2}$$

### 답

$$\boxed{\frac{1}{2}}$$

(`sympy.limit((sqrt(x+1)-1)/x, x, 0)`으로 검증 가능)

### 변형/주의

**변형: 다른 무리식 부정형**

$\lim_{x\to 4}\frac{\sqrt{x}-2}{x-4}$도 같은 원리로 $\sqrt{x}+2$를 곱해 해결합니다. 답은 $\frac{1}{4}$입니다.

**주의점**

- 부정형임을 반드시 확인하세요. 부정형이 아니면 직접 대입하면 됩니다.
- 유리화 후에도 $\frac{0}{0}$ 꼴이 남으면 인수분해나 로피탈 정리 같은 다른 방법을 시도합니다.
- 극한값을 대입할 때는 분모가 0이 아님을 확인하는 습관이 중요합니다.
