# 로그 적분

> **예제** · 미적분 · 단원: [여러가지 적분법](/concepts/여러가지_적분법)

## 요약
$\int \ln x dx$

## 본문 (학습 시 채워짐)

### 문제

다음 적분을 계산하시오.
$$\int \ln x \, dx$$

### 단계별 풀이

**1단계: 부분적분 공식 적용할 함수 선택**  
$\ln x$를 직접 적분하기 어려우므로 부분적분 $\int u \, dv = uv - \int v \, du$를 사용합니다. 로그함수는 다항함수보다 미분이 간단하므로 $u = \ln x$로 설정합니다.

**2단계: $u$, $dv$ 설정 및 미분·적분**  
$u = \ln x$이면 $du = \frac{1}{x} dx$이고, $dv = dx$이면 $v = x$입니다. 이렇게 하면 적분 항 $\int v \, du$가 더 간단해집니다.

**3단계: 부분적분 공식 대입**  
$$\int \ln x \, dx = x \ln x - \int x \cdot \frac{1}{x} \, dx = x \ln x - \int 1 \, dx$$
우변의 적분이 다항함수가 되어 계산 가능해졌습니다.

**4단계: 남은 적분 계산**  
$$\int 1 \, dx = x$$
이므로 최종 결과를 얻습니다.

### 답

$$\int \ln x \, dx = x \ln x - x + C \quad \text{(단, } x > 0\text{)}$$

또는 $x(\ln x - 1) + C$로 쓸 수도 있습니다.

### 변형/주의

**검증**: 미분으로 확인하면 $\frac{d}{dx}[x \ln x - x] = \ln x + x \cdot \frac{1}{x} - 1 = \ln x$ ✓

**정의역**: $\ln x$는 $x > 0$에서만 정의되므로 적분 결과도 $x > 0$에서만 유효합니다.

**유사 문제**: $\int x \ln x \, dx$는 같은 방식으로 $u = \ln x$, $dv = x \, dx$로 설정하여 $\frac{x^2}{2} \ln x - \frac{x^2}{4} + C$를 얻습니다.
