### 정확한 진술

함수의 **범위**(또는 치역, range)는 정의역과 함수 자체의 성질에 의해 결정되는 함숫값 전체의 집합입니다. 함수가 정의되거나 함수값의 범위를 나타내기 위해서는 정의역, 함수의 형태(예: 이차함수면 개구방향과 꼭짓점), 대칭축 등 여러 조건들이 함께 작용합니다.

### 직관과 기하적 의미

이차함수 $f(x) = ax^2 + bx + c$를 예로 들어봅시다. 포물선의 **개구방향**(a의 부호)과 **꼭짓점의 위치**가 함수가 가질 수 있는 최댓값이나 최솟값을 결정합니다:

- $a > 0$이면 포물선이 아래로 볼록하므로, 꼭짓점에서 **최솟값**을 가집니다.  
- $a < 0$이면 포물선이 위로 볼록하므로, 꼭짓점에서 **최댓값**을 가집니다.

또한 정의역이 제한되면 범위도 달라집니다. 예를 들어, 전체 실수가 아닌 특정 구간에서만 함수를 생각하면, 꼭짓점이 그 구간 안에 있는지 밖에 있는지에 따라 최댓값과 최솟값이 바뀝니다.

### 한 줄 예

$f(x) = x^2 - 4x + 5$ (정의역: 모든 실수)에서 꼭짓점은 $(2, 1)$이고 $a = 1 > 0$이므로 범위는 $f(x) \geq 1$입니다.

```python
# 꼭짓점과 범위 확인
# f(x) = x^2 - 4x + 5에서 f(2) = 4 - 8 + 5 = 1
```

또 다른 경우, 같은 함수를 $0 \leq x \leq 3$에서만 정의하면, $f(0) = 5$, $f(2) = 1$, $f(3) = 2$이므로 범위는 $1 \leq f(x) \leq 5$가 됩니다. **정의역의 범위가 제한되면 범위 조건도 함께 변한다**는 점을 기억하세요.
