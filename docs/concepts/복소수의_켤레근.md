### 정확한 진술

복소수 $z = a + bi$ (단, $a, b \in \mathbb{R}$, $i^2 = -1$)에 대해, $z$의 **켤레복소수(conjugate)**는 $\bar{z} = a - bi$입니다.

이차방정식 $ax^2 + bx + c = 0$ (단, $a, b, c \in \mathbb{R}$, $a \neq 0$)이 실근을 갖지 않을 때, 두 복소근을 $\alpha$와 $\bar{\alpha}$라 하면 이들을 **켤레근**이라고 부릅니다.

예를 들어 근의 공식에서:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

판별식 $\Delta = b^2 - 4ac < 0$이면 $\sqrt{\Delta} = i\sqrt{|\Delta|}$가 되어, 두 근은
$$x_1 = \frac{-b + i\sqrt{|\Delta|}}{2a}, \quad x_2 = \frac{-b - i\sqrt{|\Delta|}}{2a}$$

이므로 서로 켤레복소수입니다.

### 직관과 의미

실계수 이차방정식의 **복소근은 항상 켤레쌍으로 나타난다**는 것이 핵심입니다. 이는 실수 계수 다항식의 깊은 성질로, 비에타의 정리와도 연결됩니다.

기하적으로는 복소평면에서 켤레근 $\alpha$와 $\bar{\alpha}$는 실수축(가로축)에 대해 **대칭**입니다. 만약 $\alpha = 1 + 2i$라면 $\bar{\alpha} = 1 - 2i$이므로, 두 점은 실수축을 경계로 위아래 대칭입니다.

또한 켤레근의 합과 곱은 항상 실수입니다:
- 합: $\alpha + \bar{\alpha} = 2\text{Re}(\alpha)$ (실수)
- 곱: $\alpha \cdot \bar{\alpha} = |\alpha|^2$ (양의 실수)

따라서 비에타의 정리에서 $\alpha + \bar{\alpha} = -\frac{b}{a}$, $\alpha \cdot \bar{\alpha} = \frac{c}{a}$이고, 우변이 모두 실수 조건을 만족합니다.

### 한 줄 예

$x^2 - 2x + 5 = 0$의 근은 $x = 1 \pm 2i$이므로, 두 근은 켤레근입니다. (검증: `sympy.solve(x**2 - 2*x + 5, x)`)
