# 평면도형

> **단원** · 중1 · 선수: [작도와 합동](./작도와_합동.md) · 다음: [도형의 성질](./도형의_성질.md) / [원의 성질](./원의_성질.md) / [입체도형](./입체도형.md)

## 학습 목표
- 다각형의 내각·외각의 합을 구할 수 있다
- 원과 부채꼴의 호의 길이·넓이를 계산할 수 있다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 다각형, 정다각형
- 내각·외각
- 원, 부채꼴, 활꼴

**정리(theorem)**
- $n$각형의 내각의 합 $= 180(n-2)$
- 부채꼴 호 길이 $= 2\pi r \cdot \theta/360$

**예제(example)**
- 정다각형의 한 내각
- 부채꼴 넓이 비교
