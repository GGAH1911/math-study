# 전개식

## 요약
다항식의 곱셈을 괄호가 없는 덧셈과 뺄셈의 형태로 나타낸 식입니다.

## 본문
다항식의 곱셈을 계산하여 괄호를 풀고, 동류항끼리 정리하여 덧셈과 뺄셈의 형태로 나타낸 식을 전개식이라고 합니다. 전개식은 곱셈의 분배법칙을 이용하여 각 항을 하나씩 곱한 후, 차수가 같은 항들을 모아서 단순화하는 과정을 거쳐 얻어집니다.

### 직관과 기하적 의미
전개식은 넓이의 개념으로 이해할 수 있습니다. 예를 들어, 가로의 길이가 $(x + a)$이고 세로의 길이가 $(x + b)$인 직사각형의 넓이를 구할 때, 전체 넓이를 구하는 과정이 곧 전개식입니다. 이 직사각형을 네 개의 작은 직사각형으로 나누어 각 부분의 넓이를 합산하면 $(x + a)(x + b) = x^2 + (a+b)x + ab$라는 전개식을 시각적으로 확인할 수 있습니다.

### 기본 성질
전개식은 곱셈의 교환법칙과 결합법칙이 성립하므로, 항의 순서를 바꾸거나 결합하는 방식에 관계없이 결과가 동일합니다. 또한, 분배법칙을 적용할 때 괄호 안의 모든 항에 대해 빠짐없이 곱해져야 하며, 전개 후에는 반드시 동류항을 정리하여 가장 간결한 형태로 나타내어야 합니다.

## 학습 체크
- 다항식의 곱셈을 할 때 분배법칙을 모든 항에 빠짐없이 적용하였는가?
- 전개 후 동류항을 모두 찾아 적절하게 계산하여 정리하였는가?
- 부호 계산 과정에서 마이너스($-$) 기호가 포함된 항을 실수 없이 처리하였는가?

## 관련 개념
- **다항식**: 전개식은 결국 다항식의 곱셈을 수행하여 얻어지는 결과물이며, 전개된 형태 또한 다항식의 일종입니다.
