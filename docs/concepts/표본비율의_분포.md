# 표본비율의 분포

## 요약
모비율 $p$인 모집단에서 추출한 표본비율 $\hat{p}$는 표본의 크기 $n$이 충분히 클 때 평균이 $p$이고 분산이 $\tfrac{p(1-p)}{n}$인 정규분포를 따른다.

## 본문
모비율이 $p$인 모집단에서 크기 $n$인 표본을 추출할 때, 표본에서 특정 속성을 가진 개체 수를 $n$으로 나눈 값을 표본비율 $\hat{p}$라고 한다. 표본의 크기 $n$이 충분히 커서 $np \geq 5$와 $n(1-p) \geq 5$를 만족하는 경우, 표본비율 $\hat{p}$는 근사적으로 정규분포 $N\left(p, \tfrac{p(1-p)}{n}\right)$를 따른다. 이는 표본비율이 모비율을 가장 잘 추정하는 통계량임을 의미하며, 표본의 크기가 커질수록 표본비율의 분포는 모비율을 중심으로 더욱 좁게 집중된다.

### 직관과 기하적 의미
표본비율은 표본을 뽑을 때마다 값이 달라지지만, 표본의 크기가 커질수록 그 값들은 모비율 $p$에 매우 가까워진다. 이를 기하학적으로 보면 표본비율의 확률밀도함수가 $p$를 중심으로 하는 종 모양의 곡선 형태를 띠며, $n$이 증가할수록 곡선의 폭이 좁아지고 높이가 높아지는 양상을 보인다.

### 기본 성질
표본비율 $\hat{p}$의 평균은 모비율 $p$와 같아 $E(\hat{p}) = p$이며, 분산은 $V(\hat{p}) = \tfrac{p(1-p)}{n}$이다. 따라서 표준편차는 $\sigma(\hat{p}) = \sqrt{\tfrac{p(1-p)}{n}}$이 된다. 이를 표준화하면 $Z = \tfrac{\hat{p} - p}{\sqrt{p(1-p)/n}}$이며, 이 값은 표준정규분포 $N(0, 1)$을 따른다.

## 학습 체크
- 표본의 크기 $n$이 커질 때 표본비율의 분산은 어떻게 변화하는가?
- 표본비율 $\hat{p}$가 정규분포를 따르기 위한 조건은 무엇인가?
- 표준화된 변수 $Z$를 이용하여 특정 범위 내의 표본비율 확률을 어떻게 구하는가?
