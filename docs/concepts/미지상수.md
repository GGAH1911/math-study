### 정확한 진술

**미지상수**(unknown constant)는 그 값이 정해져 있지만 아직 알려지지 않은 상수를 뜻합니다. 보통 문자 $a, b, c$ 같은 알파벳 뒤쪽 글자나 $\alpha, \beta$ 같은 그리스 문자로 나타내며, 주어진 조건(방정식이나 함수의 성질)을 만족하도록 그 값을 구해야 하는 경우가 많습니다.

예를 들어, 이차함수 $f(x) = ax^2 + bx + c$의 계수 $a, b, c$는 서로 다른 함수마다 서로 다른 값을 가지므로 미지상수입니다.

### 직관과 역할

미지상수는 **미지수**(unknown variable, $x, y, z$)와 구별됩니다:
- **미지수**: 문제 내에서 변하는 량을 나타내며, 보통 우리가 구하려는 값입니다. 예: 방정식 $x^2 - 5x + 6 = 0$에서 $x$
- **미지상수**: 문제의 조건이나 구조를 정의하는 상수이며, 다른 조건에 따라 달라집니다. 예: "$x$에 관계없이 항상 $ax^2 + bx + c > 0$이려면 $a, b, c$의 관계는?"

미지상수는 **매개변수**(parameter)라고도 부르며, 함수의 형태나 방정식의 특성을 조정하는 역할을 합니다.

### 한 줄 예

직선 $y = mx + n$에서 $m$(기울기)과 $n$(절편)은 직선마다 다른 미지상수이며, "직선이 점 $(1, 2)$와 $(2, 5)$를 지날 때 $m, n$을 구하라"는 미지상수를 구하는 문제입니다.
(`sympy.solve([2 - m - n, 5 - 2*m - n], [m, n])` → $m=3, n=-1$)
