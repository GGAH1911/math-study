# 곱몫미분 혼합

> **예제** · 미적분 · 단원: [여러가지 함수의 미분](/concepts/여러가지함수의_미분)

## 요약
복합 함수

## 본문 (학습 시 채워짐)

### 문제

다음 함수를 미분하시오.

$$f(x) = \frac{(x^2+1)(2x-1)}{x+3}$$

### 단계별 풀이

**1단계: 어떤 공식을 사용할지 판단하기**  
분자가 두 함수의 곱이고 전체 식이 분수이므로, 몫의 미분법을 사용합니다. 분자를 $u = (x^2+1)(2x-1)$, 분모를 $v = x+3$로 놓겠습니다.

**2단계: 분자의 도함수 구하기 (곱의 미분법)**  
$u(x) = (x^2+1)(2x-1)$에 곱의 미분법 $(fg)' = f'g + fg'$를 적용하면:
$$u'(x) = (2x)(2x-1) + (x^2+1)(2) = 4x^2 - 2x + 2x^2 + 2 = 6x^2 - 2x + 2$$

**3단계: 분모의 도함수 구하기**  
$v'(x) = 1$이므로 계산이 간단합니다.

**4단계: 몫의 미분법 적용**  
$$f'(x) = \frac{u'v - uv'}{v^2} = \frac{(6x^2-2x+2)(x+3) - (x^2+1)(2x-1)}{(x+3)^2}$$

**5단계: 분자 전개 및 정리**  
- $(6x^2-2x+2)(x+3) = 6x^3 + 16x^2 - 4x + 6$
- $(x^2+1)(2x-1) = 2x^3 - x^2 + 2x - 1$  
- 빼기: $6x^3 + 16x^2 - 4x + 6 - 2x^3 + x^2 - 2x + 1 = 4x^3 + 17x^2 - 6x + 7$

### 답

$$f'(x) = \frac{4x^3 + 17x^2 - 6x + 7}{(x+3)^2}$$

(검산: `sympy.diff(((x**2+1)*(2*x-1))/(x+3), x)` 결과 일치)

### 변형/주의

**분자를 먼저 전개하는 방법도 있습니다:**  
$f(x) = \frac{2x^3 - x^2 + 2x - 1}{x+3}$로 전개한 후, 몫의 미분법을 적용해도 됩니다. 상황에 따라 더 간단할 수 있습니다.

**합성함수 미분이 포함된 경우:**  
분자가 $(x^2+1)^2$ 같은 거듭제곱 형태라면 연쇄법칙 $[u^n]' = nu^{n-1}u'$도 함께 써야 합니다. 곱의 미분법, 몫의 미분법, 연쇄법칙을 모두 조합하는 경우가 수능에 자주 출제되므로 각 공식을 정확히 기억하세요.
