# 등비급수 합 계산

> **예제** · 미적분 · 단원: [수열의 극한](/concepts/수열의_극한)

## 요약
$\sum (1/2)^n$

## 본문 (학습 시 채워짐)

### 문제

다음 무한급수의 합을 구하세요.
$$\sum_{n=1}^{\infty} \left(\frac{1}{2}\right)^n$$

### 단계별 풀이

**단계 1: 급수를 전개하여 형태 파악**  
주어진 식을 처음 몇 항으로 전개합니다. 급수가 어떤 규칙을 따르는지 직관적으로 이해하기 위함입니다.
$$\sum_{n=1}^{\infty} \left(\frac{1}{2}\right)^n = \frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \cdots$$

**단계 2: 등비급수임을 확인하고 공비와 첫째항 찾기**  
각 항을 이전 항으로 나누면 $\frac{1}{2}$가 되므로, 이는 첫째항 $a = \frac{1}{2}$, 공비 $r = \frac{1}{2}$인 등비급수입니다. 공비가 $\frac{1}{2}$이므로 수렴 조건 $|r| < 1$을 만족합니다.

**단계 3: 등비급수 합 공식 적용**  
첫째항이 $a$, 공비가 $r$ ($|r| < 1$)인 등비급수의 합은:
$$\sum_{n=1}^{\infty} ar^{n-1} = \frac{a}{1-r}$$

우리 문제에서는 $\sum_{n=1}^{\infty} \left(\frac{1}{2}\right)^n = \sum_{n=1}^{\infty} \frac{1}{2} \cdot \left(\frac{1}{2}\right)^{n-1}$로 쓸 수 있으므로:
$$S = \frac{\frac{1}{2}}{1 - \frac{1}{2}} = \frac{\frac{1}{2}}{\frac{1}{2}} = 1$$

### 답

$$\boxed{1}$$

### 변형 및 주의사항

**인덱싱이 다른 경우**: 만약 $\sum_{n=0}^{\infty} \left(\frac{1}{2}\right)^n$이면 첫째항이 $1$이 되어 합은 $\frac{1}{1-\frac{1}{2}} = 2$입니다.

**공비의 크기 조건**: $|r| \geq 1$이면 급수는 발산합니다. 예를 들어 공비가 $2$인 급수는 무한히 커지므로 합이 정의되지 않습니다.

**부분합으로 검증**: 부분합 $S_N = \sum_{n=1}^{N} \left(\frac{1}{2}\right)^n$을 계산하면 $S_N = 1 - \left(\frac{1}{2}\right)^N$이므로, $N \to \infty$일 때 $S_N \to 1$입니다. (`sympy.limit(1 - Rational(1,2)**n, n, oo) → 1`)
