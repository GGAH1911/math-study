### 정확한 진술

연립방정식의 풀이란 두 개 이상의 방정식을 **동시에** 만족하는 미지수의 값들을 모두 찾는 과정입니다. 예를 들어 미지수 $x, y$에 대한 두 방정식
$$\begin{cases} f(x, y) = 0 \\ g(x, y) = 0 \end{cases}$$
이 주어졌을 때, 두 식을 모두 참이 되게 하는 순서쌍 $(x, y)$를 구하는 것이 연립방정식의 풀이입니다. 이러한 순서쌍들의 집합을 **해(solution)** 또는 **해집합**이라 부르며, 해가 존재하지 않으면 **부정합(inconsistent)**, 정확히 하나의 해를 가지면 **정합(consistent)**, 무수히 많은 해를 가지면 **부정정합(dependent)**이라 분류합니다.

### 직관/기하적 의미

일차연립방정식의 경우, 각 식은 평면 위의 **직선**을 나타냅니다. 예를 들어 $2x + y = 5$와 $x - y = 1$이라는 두 직선은 평면 위의 특정 점에서 만납니다. 연립방정식의 풀이는 바로 이 **교점의 좌표를 찾는 것**입니다. 

- 두 직선이 한 점에서 만나면 → 유일한 해 1개
- 두 직선이 겹치면 → 무수히 많은 해 (같은 직선 위의 모든 점)
- 두 직선이 평행하면 → 해가 없음

이는 공간에서 여러 평면의 교집합으로도 확장되므로, 연립방정식의 풀이는 **기하학적으로 여러 도형의 교점을 찾는 문제**입니다.

### 한 줄 예

$\begin{cases} x + y = 3 \\ 2x - y = 0 \end{cases}$의 해는 $(x, y) = (1, 2)$입니다. (검증: $1 + 2 = 3$ ✓, $2 \cdot 1 - 2 = 0$ ✓)
