### 정확한 진술

삼각함수 $\sin x$와 $\cos x$의 최댓값은 각각 1입니다. 즉, 모든 실수 $x$에 대해 $\sin x \le 1$이고 $\cos x \le 1$이며, 이 최댓값은 실제로 달성됩니다. $\sin x = 1$은 $x = \dfrac{\pi}{2} + 2\pi n$ (단, $n$은 정수)일 때 성립하고, $\cos x = 1$은 $x = 2\pi n$일 때 성립합니다. 더 일반적으로, $f(x) = A\sin(Bx + C) + D$ 형태의 삼각함수는 최댓값 $|A| + D$를 가집니다.

### 직관과 기하적 의미

단위원 위의 점을 생각해 봅시다. $\cos x$는 그 점의 $x$ 좌표이고, $\sin x$는 $y$ 좌표입니다. 단위원의 반지름이 1이므로, 모든 점의 좌표는 $-1$과 $1$ 사이에 있습니다. $\sin x = 1$은 단위원 위의 점이 정상단(맨 위)인 $(0, 1)$에 있을 때, 즉 회전각이 $\dfrac{\pi}{2}$일 때입니다. 진폭 $A$를 곱하면 최댓값이 $|A|$배 커지고, 수직 이동 $D$를 더하면 전체 최댓값이 $|A| + D$가 됩니다.

### 예제

$f(x) = 3\sin x + 2$의 최댓값을 구하세요. $\sin x$의 최댓값이 1이므로, 
$$f(x)_{\max} = 3 \times 1 + 2 = 5$$
이 값은 $x = \dfrac{\pi}{2} + 2\pi n$일 때 달성됩니다.
