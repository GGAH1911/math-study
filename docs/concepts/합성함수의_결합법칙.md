# 합성함수의 결합법칙

> **정리** · 고1 · 단원: [함수와 그래프](/concepts/함수와_그래프)

## 요약
$(f\circ g)\circ h=f\circ(g\circ h)$

## 본문 (학습 시 채워짐)

### 진술과 가정

세 함수 $f$, $g$, $h$가 합성가능할 때, 합성함수의 결합법칙은 다음을 만족합니다:
$$\left(f\circ g\right)\circ h = f\circ\left(g\circ h\right)$$

즉, 세 함수를 합성할 때 어떤 방식으로 괄호를 묶든 최종 결과가 같다는 뜻입니다.

### 증명 스케치

임의의 입력값 $x$에 대해 양변을 계산해봅시다.

**좌변**: $(f\circ g)\circ h$를 $x$에 적용하면
$$\left[\left(f\circ g\right)\circ h\right](x) = (f\circ g)(h(x)) = f(g(h(x)))$$

**우변**: $f\circ(g\circ h)$를 $x$에 적용하면
$$\left[f\circ\left(g\circ h\right)\right](x) = f((g\circ h)(x)) = f(g(h(x)))$$

모든 정의역의 원소 $x$에 대해 양변이 동일하므로 두 함수는 같습니다.

### 의의와 응용

결합법칙은 세 개 이상의 함수를 합성할 때 괄호를 신경 쓰지 않아도 된다는 의미입니다. 따라서 $f\circ g\circ h$로 간단히 표기할 수 있으며, 복잡한 합성함수의 계산을 단순화합니다.

예를 들어, $f(x)=x+2$, $g(x)=3x$, $h(x)=x^2$일 때, $(f\circ g)(h(x)) = f(g(x^2)) = f(3x^2) = 3x^2+2$이고, $f((g\circ h)(x)) = f(g(x^2)) = 3x^2+2$로 동일합니다.

다만 주의할 점은 **합성함수는 교환법칙을 만족하지 않는다**는 것입니다. 일반적으로 $f\circ g \neq g\circ f$이므로 함수를 적용하는 순서가 매우 중요합니다.
