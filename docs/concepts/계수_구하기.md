# 계수 구하기

## 요약
다항식의 전개식에서 특정 항의 계수는 식을 완전히 전개하여 읽거나 이항정리의 일반항을 이용하여 효율적으로 구할 수 있습니다.

## 본문
다항식에서 특정 항의 계수를 구하는 방법은 크게 두 가지로 나뉩니다. 첫째는 다항식을 모두 전개하고 동류항끼리 정리한 후 해당 항의 계수를 직접 읽어내는 방법입니다. 둘째는 이항정리 $(a+b)^n$의 일반항 성질을 이용하여 필요한 항의 계수만을 골라내는 방법입니다. 이항정리를 활용할 경우, 전개식에서 $a^r b^{n-r}$의 계수는 $\binom{n}{r}a_0^r b_0^{n-r}$의 형태로 결정됩니다. 특히 특정 차수의 계수만을 빠르게 구해야 하는 경우에는 전체 식을 전개하기보다 해당 차수가 나타나기 위한 변수의 지수 조건을 먼저 설정하여 조합을 계산하는 것이 훨씬 효율적입니다.

### 직관과 기하적 의미
계수는 다항식이라는 수식의 구조 내에서 특정 차수의 항이 가지는 크기를 나타내는 상수입니다. 이는 다항함수의 그래프를 그릴 때 해당 차수의 항이 전체 함수의 모양과 기울기에 미치는 영향력을 결정하는 요소가 됩니다.

### 기본 성질
계수는 다항식의 모든 항을 동류항끼리 묶어 정리했을 때 결정됩니다. 또한 이항정리를 적용할 때 각 항의 지수의 합은 항상 전체 지수인 $n$과 같아야 한다는 성질을 가집니다.

## 학습 체크
- 이항정리를 사용하여 특정 항의 계수를 구할 때, 지수의 합이 $n$이 되는 조합 조건을 정확히 설정하였는가?
- 다항식을 전개할 때 계수 계산 과정에서 조합($\binom{n}{r}$)과 상수의 거듭제곱을 혼동하지 않고 정확히 곱하였는가?
