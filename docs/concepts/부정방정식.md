# 부정방정식

## 정의

미지수의 개수가 방정식의 수보다 많아 해가 무한히 많거나, 조건을 충족하는 해가 특정되지 않는 방정식을 **부정방정식**이라 한다. 수능에서는 주로 "자연수 해", "정수 해", "양의 정수 해" 등 해의 범위를 추가 조건으로 주어 해를 특정하는 문제로 출제된다. 예를 들어 $ax + by = c$ 형태에서 $x, y$가 자연수임을 조건으로 하면 해의 개수가 유한해진다.

## 예시

방정식 $2x + 3y = 12$의 자연수 해를 구하시오.

$x = \frac{12 - 3y}{2}$이므로 $x$가 자연수가 되려면 $12 - 3y$가 양의 짝수여야 한다.

- $y = 2$: $x = 3$ → $(3, 2)$ ✓
- $y = 4$ 이상이면 $x \leq 0$이라 불가

따라서 자연수 해는 $(x, y) = (3, 2)$ 뿐이다.
