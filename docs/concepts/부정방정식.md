# 부정방정식

## 요약
미지수의 개수가 방정식의 수보다 많아 해가 무한히 많거나 특정되지 않는 방정식을 의미하며, 추가 조건을 통해 해를 제한하여 해결한다.

## 본문
미지수의 개수가 방정식의 수보다 많아 해가 무한히 많거나, 조건을 충족하는 해가 특정되지 않는 방정식을 부정방정식이라 한다. 수능을 포함한 수학 시험에서는 주로 자연수 해, 정수 해, 양의 정수 해 등 해의 범위를 추가 조건으로 제시하여 해를 하나로 특정하는 문제 유형으로 자주 출제된다. 예를 들어 $ax + by = c$ 형태의 방정식에서 $x, y$가 자연수라는 조건이 붙으면, 무한했던 해의 개수가 유한한 범위로 제한되어 특정 값을 찾을 수 있게 된다.

### 직관과 기하적 의미
평면 좌표계에서 두 변수를 가진 일차방정식은 직선을 나타낸다. 방정식의 개수가 하나뿐이라면 직선 위의 모든 점이 해가 되어 무한히 많은 해를 갖게 되지만, 해의 범위를 정수나 자연수로 제한하면 직선 위의 점들 중 격자점(정수 좌표)만을 찾는 문제로 변하게 된다.

### 기본 성질
부정방정식의 해를 구하는 핵심은 주어진 추가 조건(자연수, 정수 등)을 활용하여 미지수의 범위를 제한하는 것이다. 한 문자에 대해 식을 정리했을 때, 다른 문수가 특정 조건(예: 자연수)을 만족하도록 만드는 값을 찾는 방식으로 접근한다.

**예시: 방정식 $2x + 3y = 12$의 자연수 해 구하기**
$x = \frac{12 - 3y}{2}$이므로, $x$가 자연수가 되기 위해서는 분자인 $12 - 3y$가 양의 짝수여야 한다.
- $y = 2$일 때: $x = \frac{12 - 6}{2} = 3 \rightarrow (3, 2)$
- $y = 4$ 이상일 때: $x \leq 0$이 되어 자연수 조건에 어긋남
따라서 자연수 해는 $(x, y) = (3, 2)$뿐이다.

## 학습 체크

- 해의 범위(자연수, 정수 등)가 주어졌을 때 이를 이용해 해를 특정하는 과정을 설명할 수 있는가?
- 부정방정식의 해를 구할 때 한 문자에 대해 정리하여 조건에 맞는 값을 찾는 과정을 수행할 수 있는가?
