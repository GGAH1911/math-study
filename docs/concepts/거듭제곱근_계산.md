# 거듭제곱근 계산

> **예제** · 수학1 · 단원: [지수와 로그](/concepts/지수와_로그)

## 요약
$\sqrt[3]{8}, 8^{1/3}$

## 본문 (학습 시 채워짐)

### 문제

다음을 계산하고, 지수 형태로 나타내시오.
$$\sqrt[3]{8}$$

### 단계별 풀이

**1단계: 거듭제곱근의 정의 확인**  
$\sqrt[3]{8}$은 "8의 세제곱근"이라 읽으며, 세제곱했을 때 8이 되는 양수를 찾는 것입니다. 즉, $x^3 = 8$을 만족하는 $x$를 구하는 것이죠.

**2단계: 어떤 수의 세제곱이 8인지 생각하기**  
$2^3 = 2 \times 2 \times 2 = 8$이므로, $\sqrt[3]{8} = 2$입니다.

**3단계: 지수 형태로 표현하기**  
거듭제곱근과 지수의 관계 $\sqrt[n]{a} = a^{1/n}$를 이용하면:
$$\sqrt[3]{8} = 8^{1/3} = (2^3)^{1/3} = 2^{3 \times 1/3} = 2^1 = 2$$

**4단계: 검산**  
$2^3 = 8$이므로 답이 맞습니다. (sympy: `2**3 == 8`)

### 답

$$\sqrt[3]{8} = 2, \quad 8^{1/3} = 2$$

### 변형/주의

**다른 거듭제곱근들:**  
- $\sqrt[2]{16} = \sqrt{16} = 4$ (제곱근은 보통 $\sqrt[2]$를 $\sqrt{}$로 씀)
- $\sqrt[4]{16} = 2$ ($2^4 = 16$)
- $\sqrt[5]{32} = 2$ ($2^5 = 32$)

**주의할 점:**  
짝수 제곱근(예: $\sqrt[2]{a}, \sqrt[4]{a}$)은 음수를 포함하지 않습니다. 고등학교 과정에서 $\sqrt[n]{a}$는 항상 음이 아닌 실근을 의미합니다. 홀수 제곱근은 음수도 정의되지만, 실무 계산에서는 주 값(principal root)인 양수를 사용합니다.
