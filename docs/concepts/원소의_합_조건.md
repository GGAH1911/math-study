### 정확한 진술

주어진 집합이나 수열에서 **선택된 원소들의 합이 특정 값이 되어야 한다는 제약 조건**을 의미합니다. 예를 들어, 집합 $\{a_1, a_2, \ldots, a_n\}$에서 일부 원소를 선택했을 때, 그 합이 정확히 $S$가 되는 경우를 다룹니다. 이러한 조건을 만족하는 **부분집합의 개수, 선택 방법의 경우의 수, 또는 순서쌍의 개수**를 구하는 것이 핵심입니다.

### 직관과 의미

"합 조건"은 단순히 개수만 세는 경우의 수 문제에서 **합계라는 추가 제약**을 더한 것입니다. 일상적으로는 "예산이 정해진 상황에서 물품을 선택하기" 또는 "점수 합계가 일정해야 하는 팀 구성"처럼 합이 고정되어야 하는 모든 상황입니다. 수학적으로는 부분집합의 합(subset sum) 문제의 기초가 되며, 조합론과 동적 프로그래밍의 중요한 응용 분야입니다.

### 한 줄 예

집합 $\{1, 2, 3, 4\}$에서 원소를 선택하여 **합이 5가 되도록** 하는 경우: $\{1,4\}$, $\{2,3\}$ → **2가지**

**확장 예시**: 세 양의 정수 $x, y, z$의 합이 6이 되는 순서쌍 $(x, y, z)$의 개수는 **중복조합** 공식 $\binom{n+r-1}{r-1}$을 이용하여 $\binom{6-1}{3-1} = \binom{5}{2} = 10$가지입니다.

```
# 검산 예: {1,2,3,4}에서 합이 5인 부분집합
from itertools import combinations
s = {1, 2, 3, 4}
result = [list(combo) for r in range(len(s)+1) for combo in combinations(s, r) if sum(combo) == 5]
# 결과: [[1, 4], [2, 3]] → 2가지
```
