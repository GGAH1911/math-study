# AM-GM 부등식

## 요약
양의 실수들의 산술평균은 기하평균보다 크거나 같으며, 등호는 모든 수가 같을 때 성립한다.

## 본문
양의 실수 $a, b$에 대하여 산술평균(Arithmetic Mean)은 기하평균(Geometric Mean)보다 크거나 같다는 부등식 $\frac{a + b}{2} \geq \sqrt{ab}$를 의미한다. 이 식에서 등호는 $a = b$인 경우에만 성립한다. 이를 $n$개의 양의 실수 $a_1, a_2, \ldots, a_n$으로 확장하면 $\dfrac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \cdots a_n}$이 되며, 이때 등호는 모든 $a_i$의 값이 동일할 때 성립한다. 이 부등식은 변수들의 합이 일정할 때 곱의 최댓값을 찾거나, 곱이 일정할 때 합의 최솟값을 구하는 문제에서 매우 유용하게 활용된다.

### 직관과 기하적 의미
기하학적으로 두 양수 $a, b$를 두 변으로 하는 직사각형의 넓이를 생각할 때, 이 직사각형의 넓이($ab$)와 넓이가 같은 정사각형의 한 변의 길이($\sqrt{ab}$) 사이의 관계를 보여준다. 산술평균은 두 수의 중간값을 의미하며, 기하평균은 곱의 균형을 의미한다. 두 수의 차이가 커질수록 산술평균과 기하평균 사이의 간격은 넓어진다.

### 기본 성질
1. 모든 변수가 양수일 때만 정의되며, 부등식의 방향은 항상 산술평균이 기하평균보다 크거나 같다.
2. 등호 성립 조건은 모든 변수가 같을 때($a_1 = a_2 = \cdots = a_n$)이다.
3. 합이 일정할 때 곱은 변수들이 모두 같을 때 최대가 되고, 곱이 일정할 때 합은 변수들이 모두 같을 때 최소가 된다.

## 학습 체크

- 합이나 곱이 일정하다는 조건이 문제에 주어져 있는가?
