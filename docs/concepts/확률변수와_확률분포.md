# 확률변수와 확률분포

## 요약
확률변수란 어떤 시행의 결과에 따라 특정한 값을 대응시키는 함수이며, 확률분포는 이 확률변수가 취하는 값과 그 값이 나타날 확률 사이의 관계를 나타낸 것이다.

## 본문
확률변수란 어떤 시행에서 나타날 수 있는 모든 결과에 대하여 하나의 실수 값을 대응시키는 함수를 의미한다. 확률변수가 취하는 값의 형태에 따라 셀 수 있는 값을 갖는 이산확률변수와 연속적인 값을 갖는 연속확률변수로 구분한다. 확률분포란 확률변수가 특정한 값을 가질 확률을 나타낸 것으로, 확률변수의 값과 그에 대응하는 확률 사이의 대응 관계를 말한다. 이산확률변수의 경우 각 값에 대응하는 확률의 합은 항상 $1$이 되어야 하며, 이를 확률질량함수라고 한다. 반면 연속확률변수의 경우 특정 구간에 속할 확률을 확률밀도함수를 통해 나타내며, 함수 아래의 면적이 확률이 된다.

### 직관과 기하적 의미
주사위를 던지는 시행에서 눈의 수를 확률변수 $X$라고 하면, $X$가 $1, 2, 3, 4, 5, 6$이라는 값을 가질 때 각각의 확률이 배정되는 구조를 상상할 수 있다. 연속적인 상황에서는 키나 몸무게처럼 값이 끊기지 않고 이어지는데, 이때는 특정 지점의 확률이 아닌 특정 구간의 넓이(면적)로 확률을 이해해야 한다.

### 기본 성질
확률변수가 가질 수 있는 모든 값에 대한 확률의 총합은 반드시 $1$이어야 한다. 또한 확률값은 항상 $0$ 이상 $1$ 이하의 범위를 가지며, 확률밀도함수의 경우 함수값이 음수가 될 수 없다.

## 학습 체크
- 이 확률변수가 이산형인지 연속형인지 구분할 수 있는가?
- 주어진 확률함수가 확률의 총합이 $1$이 되는 조건을 만족하는가?
- 연속확률변수에서 특정 구간의 확률을 적분을 통해 구할 수 있는가?

## 관련 개념
- **확률**: 확률변수가 어떤 값을 가질 확률을 결정하는 근본적인 척도이다.
- **기댓값**: 확률변수가 취하는 값들의 평균적인 크기를 나타내는 수치이다.
- **표준편차**: 확률변수의 값들이 기댓값으로부터 얼마나 떨어져 있는지를 나타내는 척도이다.
