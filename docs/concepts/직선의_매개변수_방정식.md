# 직선의 매개변수 방정식

## 요약
직선 위의 임의의 점을 매개변수 $t$를 이용하여 좌표 성분별로 나타낸 식입니다.

## 본문
직선의 매개변수 방정식은 공간 또는 평면 위의 한 점 $A(a, b, c)$를 지나고 방향벡터가 $\vec{u} = (l, m, n)$인 직선 위의 임의의 점 $P(x, y, z)$를 매개변수 $t$를 사용하여 나타낸 식입니다. 점 $P$에 대하여 벡터 $\vec{AP}$는 $\vec{u}$의 실수배이므로 $\vec{AP} = t\vec{u}$가 성립하며, 이를 성분으로 나타내면 $x = a + lt$, $y = b + mt$, $z = c + nt$가 됩니다. 여기서 $t$는 실수 전체의 집합을 값으로 가지며, $t$의 값에 따라 직선 위의 점들의 위치가 결정됩니다.

### 직관과 기하적 의미
직선의 매개변수 방정식은 직선을 '시간'의 흐름에 따른 '위치'의 변화로 해석할 수 있게 해줍니다. 매개변수 $t$를 시간이라고 생각하면, 점 $A$를 출발점으로 하여 방향벡터 $\vec{u}$의 방향으로 일정한 속도로 움직이는 물체의 궤적을 나타내는 것과 같습니다. $t$가 증가함에 따라 점은 방향벡터가 가리키는 방향으로 이동하며, $t=0$일 때 점은 기준점 $A$에 위치합니다.

### 기본 성질
매개변수 방정식은 직선의 방정식을 성분별로 분리하여 표현하므로, 특정 점이 직선 위에 있는지 확인하거나 두 직선의 교점을 구할 때 매우 유용합니다. 또한, 방향벡터의 성분이 $0$인 경우에도 매개변수 식을 통해 직선의 형태를 오류 없이 표현할 수 있다는 장점이 있습니다.

## 학습 체크
- 매개변수 $t$의 값에 따라 직선 위의 점이 어떻게 이동하는지 방향벡터와 연관 지어 설명할 수 있는가?
- 주어진 점과 방향벡터를 이용하여 직선의 매개변수 방정식을 정확히 세울 수 있는가?

## 관련 개념
- **공간도형과 공간벡터**: 공간에서의 직선의 위치 관계나 두 직선의 교점을 구할 때 매개변수 방정식을 활용하여 벡터의 연산으로 문제를 해결할 수 있습니다.
