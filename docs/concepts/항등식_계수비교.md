# 항등식 계수비교

> **예제** · 고1 · 단원: [다항식](/concepts/다항식)

## 요약
계수비교 방법

## 본문 (학습 시 채워짐)

### 문제

다음 항등식을 만족하는 상수 $a$, $b$를 구하시오.

$$(x+2)^2 + a(x+1) + b \equiv x^2 + 5x + 7$$

### 단계별 풀이

**1단계: 좌변을 정리한다**

좌변을 전개합니다.
$$(x+2)^2 + a(x+1) + b = x^2 + 4x + 4 + ax + a + b$$

동류항끼리 모으면:
$$x^2 + (4+a)x + (4+a+b)$$

**2단계: 양변의 계수를 비교한다**

항등식이 성립하려면 양변의 모든 계수가 같아야 합니다. 우변 $x^2 + 5x + 7$과 비교하면:

| 차수 | 좌변 계수 | 우변 계수 | 방정식 |
|------|---------|---------|--------|
| $x^2$ | 1 | 1 | $1 = 1$ ✓ |
| $x^1$ | $4+a$ | 5 | $4+a = 5$ |
| $x^0$ | $4+a+b$ | 7 | $4+a+b = 7$ |

**3단계: 연립방정식을 풀이한다**

$x$ 계수에서: $4 + a = 5$ → $a = 1$

상수항에 $a = 1$을 대입하면:
$$4 + 1 + b = 7 \quad \Rightarrow \quad b = 2$$

*검증 (sympy): `sympy.solve([4 + a - 5, 4 + a + b - 7], [a, b])`*

### 답

$$a = 1, \quad b = 2$$

### 변형 및 주의

**다른 접근: 특수값 대입**

항등식이 성립하면 모든 $x$ 값에서 성립하므로, 편리한 값을 대입할 수 있습니다.
- $x = -1$: $(1)^2 + a(0) + b = 1 - 5 + 7$ → $1 + b = 3$ → $b = 2$
- $x = 0$: $(2)^2 + a(1) + b = 7$ → $4 + a + 2 = 7$ → $a = 1$

**주의사항**
- 항등식의 정의: 모든 $x$에 대해 성립하는 식입니다. 방정식($x$의 특정값)과 혼동하지 않기.
- 계수비교는 같은 차수끼리만 비교합니다. 고차부터 낮은 차수 순으로 정리하면 실수가 줄어듭니다.
