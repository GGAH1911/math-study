# 이차방정식 실근 조건

## 요약
이차방정식의 판별식 $D$의 부호에 따라 실근의 개수가 결정된다.

## 본문
이차방정식 $ax^2 + bx + c = 0$ ($a \neq 0$)에서 계수 $a, b, c$가 실수일 때, 방정식의 근의 상태는 판별식 $D = b^2 - 4ac$의 값에 의해 결정된다. 판별식 $D$가 $0$보다 크면 서로 다른 두 실근을 갖고, $D$가 $0$이면 중근(서로 같은 두 실근)을 가지며, $D$가 $0$보다 작으면 실근을 갖지 않는다. 즉, 이차방정식이 실근을 갖기 위한 조건은 $D \ge 0$이다.

### 직관과 기하적 의미
이차방정식의 해는 이차함수 $y = ax^2 + bx + c$의 그래프가 $x$축과 만나는 점의 $x$좌표와 같다. 판별식 $D > 0$인 경우 그래프가 $x$축을 두 점에서 통과하며, $D = 0$인 경우 그래프의 꼭짓점이 $x$축에 접하며, $D < 0$인 경우 그래프가 $x$축 위나 아래에 떠 있어 만나지 않음을 의미한다.

### 기본 성질
판별식은 근의 공식 $x = \tfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$에서 근호 안의 식으로부터 유도된다. 근호 안의 값이 양수이면 서로 다른 두 실수가 나오고, $0$이면 근호가 사라져 하나의 값이 나오며, 음수이면 실수 범위에서 근을 정의할 수 없다.

## 학습 체크
- 판별식 $D$를 구할 때 계수가 실수라는 조건이 왜 필수적인가?
- $D=0$일 때 '중근'이라는 표현과 '서로 같은 두 실근'이라는 표현의 의미 차이는 무엇인가?

## 관련 개념
- **이차방정식**: 판별식은 이차방정식의 근의 형태를 결정하는 핵심적인 도구이다.
- **이차함수**: 이차방정식의 실근 존재 여부는 이차함수 그래프와 $x$축의 교점 개수와 직결된다.
