### 정의

어떤 변수를 다른 변수(보통 새로운 문자)로 바꾸어 식을 다시 나타내는 과정을 **치환**이라고 합니다. 예를 들어, 주어진 식이나 방정식에서 $x$ 또는 $x^2$ 같은 부분을 $t$로 놓으면, 원래 식이 $t$에 대한 더 간단한 형태로 변환됩니다.

형식적으로는, 어떤 변수 $u = f(x)$로 정의할 때, 원래 식의 모든 $f(x)$를 $u$로 대체하는 것입니다.

### 직관과 의미

치환은 문제를 "다른 관점"에서 보는 전략입니다. 복잡하거나 고차(高次)인 방정식을 저차(低次)의 친숙한 형태로 변환하여 풀기 쉽게 만듭니다.

예를 들어, $x^4 - 5x^2 + 6 = 0$은 4차 방정식이라 어렵지만, $x^2 = t$로 놓으면 $t^2 - 5t + 6 = 0$이 되어 2차 방정식으로 축소됩니다. 근의 공식을 사용해 $t$ 값을 구한 후, 다시 $x$의 값을 역산하여 원래 문제를 완성합니다.

치환은 또한 복잡한 함수나 부등식을 표준적인 형태로 정규화하여, 계산을 체계적으로 만들고 실수를 줄이는 도구입니다.

### 예시

$4x^2 + 4x + 1 = 9$를 풀 때, $2x + 1 = t$로 치환하면 $t^2 = 9$가 되어 $t = \pm 3$입니다. 이를 역으로 풀면 $x = 1$ 또는 $x = -2$를 얻습니다.

```
sympy.solve(4*x**2 + 4*x + 1 - 9, x)  # 결과: [-2, 1]
```
