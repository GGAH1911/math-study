# 타원 정의

> **정의** · 기하 · 단원: [이차곡선](/concepts/이차곡선)

## 요약
두 초점에서 거리 합이 일정

## 본문 (학습 시 채워짐)

### 정확한 진술

평면 위의 서로 다른 두 점 $F$, $F'$를 정하자. 이 두 점을 **초점(focus)**이라 부른다. 이 두 초점으로부터의 거리의 합이 일정한 점 $P$들의 자취를 **타원**이라 한다.

즉, 양의 상수 $2a$에 대하여
$$|PF| + |PF'| = 2a$$
를 만족하는 모든 점 $P$의 집합이 타원이다. (단, $2a >$ 두 초점 사이의 거리)

### 직관과 기하적 의미

타원을 가장 직관적으로 이해하는 방법은 **실(實) 또는 밧줄** 실험이다. 두 초점에 실의 끝을 고정하고, 길이가 $2a$인 실을 항상 팽팽하게 유지하면서 펜으로 그으면 타원이 그려진다. 실의 길이가 짧을수록 더 찌그러진 모양이 되고, 길수록 원에 가까워진다.

원은 타원의 특수한 경우다. 두 초점이 일치할 때($F = F'$), 거리 합은 반지름의 2배가 되어 원이 된다.

두 초점 사이의 거리를 $2c$라 할 때, 타원의 **장축 길이**는 $2a$, **단축 길이**는 $2b$이며, 다음의 중요한 관계식이 성립한다:
$$a^2 = b^2 + c^2$$

### 한 줄 예

초점이 $F(3, 0)$, $F'(-3, 0)$이고 $2a = 10$인 타원 위의 임의의 점은 항상 두 초점으로부터의 거리 합이 10이다. 이 경우 $a = 5$, $c = 3$이므로 $b = \sqrt{25 - 9} = 4$이고, 타원의 표준형은 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$이다.
