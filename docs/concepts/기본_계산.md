### 정확한 진술

**순열**(permutation)과 **조합**(combination)은 경우의 수를 세는 두 가지 기본 방법입니다.

- **순열** $nPr$: $n$개 중 순서를 정해서 $r$개를 선택하는 경우의 수
$$nPr = \frac{n!}{(n-r)!} = n(n-1)(n-2)\cdots(n-r+1)$$

- **조합** $nCr$: $n$개 중 순서를 무시하고 $r$개를 선택하는 경우의 수  
$$nCr = \frac{n!}{r!(n-r)!}$$

순열과 조합의 관계: $nCr = \frac{nPr}{r!}$ (같은 $r$개를 배열하는 $r!$가지 중복을 제거)

### 직관과 의미

선택 문제에서 **"순서가 중요하면"** 순열, **"순서가 상관없으면"** 조합을 씁니다.

예를 들어 3명 중 2명을 뽑아 1등과 2등을 결정하면 순서가 정해지므로 순열입니다. 반면 3명 중 대표 2명을 선택하면 순서가 없으므로 조합입니다.

계산 원리: 순열은 첫 번째 자리에 $n$가지, 두 번째에 $(n-1)$가지, …를 곱합니다(곱의 법칙). 조합은 이렇게 센 순열에서 같은 것들의 중복 $r!$가지로 나눕니다.

### 계산 예

$5P2 = 5 \times 4 = 20$ (5명 중 2명을 순서있게 선택)  
$5C2 = \frac{5 \times 4}{2 \times 1} = 10$ (5명 중 2명을 순서없게 선택)

- 검산: `sympy.binomial(5, 2)` → 10, `sympy.factorial(5)//sympy.factorial(3)` → 120 (=5P2+...)

두 공식을 구별하는 핵심은 **순서의 유무**입니다. 문제를 읽을 때 "배열하다, 나열하다"는 순열, "선택하다, 조를 이루다"는 조합을 암시합니다.
