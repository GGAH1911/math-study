# 지수의 성질

## 요약
지수법칙은 밑이 양수인 수의 거듭제곱에서 지수들 사이의 연산 규칙을 나타내는 성질입니다.

## 본문
지수의 성질은 밑이 양수인 실수 $a$에 대하여, 지수법칙을 통해 거듭제곱의 곱셈과 나눗셈을 지수의 덧셈과 뺄셈으로 변환하여 계산할 수 있는 성질을 의미합니다. 지수법칙이 성립하기 위해서는 밑 $a$가 $0$이 아니어야 하며, 지수가 자연수일 때부터 시작하여 정수와 유리수 범위로 확장됩니다.

### 직관과 기하적 의미
거듭제곱은 동일한 수를 반복해서 곱하는 과정을 나타냅니다. 예를 들어 $a^2$은 $a$를 두 번 곱한 것이고, $a^3$은 $a$를 세 번 곱한 것입니다. 따라서 $a^2 \times a^3$은 $a$를 총 다섯 번 곱한 것과 같으므로 $a^{2+3} = a^5$이 됩니다. 즉, 지수의 덧셈은 곱셈 횟수의 누적을 의미하며, 지수의 뺄셈은 곱셈 횟수의 감소를 의미합니다.

### 기본 성질
지수법칙의 핵심적인 성질은 다음과 같습니다.
1. 곱셈 법칙: $a^m \times a^n = a^{m+n}$
2. 나눗셈 법칙: $a^m \div a^n = a^{m-n}$ (단, $a \neq 0$)
3. 거듭제곱의 거듭제곱: $(a^m)^n = a^{mn}$
4. 곱의 거듭제곱: $(ab)^n = a^n b^n$
5. 몫의 거듭제곱: $\left(\tfrac{a}{b}\right)^n = \tfrac{a^n}{b^n}$

## 학습 체크
- 밑이 음수인 경우 지수법칙을 적용할 때 어떤 조건이 필요한가?
- 지수가 $0$ 또는 음수일 때 지수법칙이 성립하기 위한 밑의 조건은 무엇인가?
- $(a^m)^n$과 $a^{mn}$의 차이점은 무엇인가?

## 관련 개념
- **지수와 로그**: 지수가 밑을 몇 번 곱하는지를 나타낸다면, 로그는 결과값이 나오기 위해 밑을 몇 번 곱해야 하는지를 나타내는 역연산 관계입니다.
