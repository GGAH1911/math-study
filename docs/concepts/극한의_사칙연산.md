# 극한의 사칙연산

> **정리** · 수학2 · 단원: [함수의 극한과 연속](/concepts/함수의_극한과_연속)

## 요약
합·곱·몫의 극한

## 본문 (학습 시 채워짐)

### 극한의 사칙연산 정리

$\lim_{x \to a} f(x) = \alpha$, $\lim_{x \to a} g(x) = \beta$일 때, 다음이 성립한다:

$$\lim_{x \to a} \{f(x) + g(x)\} = \alpha + \beta$$
$$\lim_{x \to a} \{f(x) - g(x)\} = \alpha - \beta$$
$$\lim_{x \to a} f(x) \cdot g(x) = \alpha \cdot \beta$$
$$\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\alpha}{\beta} \quad (\beta \neq 0)$$

단, 우극한과 좌극한에서도 동일하게 적용되며, **각 극한이 수렴해야만** 이 정리를 사용할 수 있다.

### 증명의 개요

극한의 정의($\varepsilon$-$\delta$ 정의)로부터 각 규칙이 따라온다. 합의 극한을 예로 들면:

$\lim_{x \to a} f(x) = \alpha$이므로, 임의의 $\varepsilon > 0$에 대해 충분히 작은 $\delta_1 > 0$이 존재하여 $0 < |x - a| < \delta_1$일 때 $|f(x) - \alpha| < \varepsilon/2$이다. 마찬가지로 $g(x)$에 대해서도 $\delta_2 > 0$이 존재한다. $\delta = \min(\delta_1, \delta_2)$로 놓으면:

$$|f(x) + g(x) - (\alpha + \beta)| \le |f(x) - \alpha| + |g(x) - \beta| < \varepsilon$$

곱과 몫의 경우는 더 정교한 계산을 요하지만, 수렴하는 함수들의 유계성과 부등식을 활용하여 같은 방식으로 증명된다.

### 실제 활용과 주의점

이 정리는 극한값 계산의 핵심 도구다. $\lim_{x \to 1} (x^2 + 3x) = 1 + 3 = 4$ 처럼 다항식의 극한을 순서대로 계산할 수 있다. 함수의 연속성과도 밀접하게 연결되어, "연속함수인지 판단"하는 문제로 자주 출제된다.

**주의할 점**: 몫의 극한에서 $\beta = 0$이거나 $\frac{0}{0}$ 꼴의 부정형이 나타나면 이 정리를 바로 적용할 수 **없다**. 분자·분모를 인수분해하거나 유리화하여 먼저 약분한 후 극한을 구해야 한다. 예를 들어 $\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x + 2) = 4$처럼 식을 정리한 후 정리를 적용한다.

검증: `sympy.limit(x**2 + 3*x, x, 1)` → 4
