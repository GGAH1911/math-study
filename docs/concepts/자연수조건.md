### 정확한 진술

로그 $\log_a b$가 정의되기 위해 밑 $a$와 진수 $b$가 반드시 만족해야 할 조건은 다음과 같습니다:
- 밑: $a > 0$ 이고 $a \neq 1$
- 진수: $b > 0$

이 세 가지를 **로그의 정의 조건** 또는 **자연수 조건**이라고 부릅니다.

### 직관: 왜 이 조건이 필요한가?

로그의 정의 $\log_a b = c$ ⟺ $a^c = b$로부터 유래합니다.

**밑이 양수여야 하는 이유**: $a^c$를 실수 범위에서 계산할 때, 밑이 음수면 지수가 분수일 경우 복소수가 됩니다. 예를 들어 $(-2)^{1/2} = \sqrt{-2}$는 실수가 아니므로, 실수 범위의 로그를 정의할 수 없습니다.

**밑이 1이 아닌 이유**: $1^c = 1$ (모든 $c$에 대해)이므로, $\log_1 b$의 값이 유일하게 결정될 수 없습니다.

**진수가 양수여야 하는 이유**: $a > 0, a \neq 1$일 때, $a^c$의 치역은 항상 양수입니다. 따라서 $\log_a b$에서 $b \leq 0$이면 해가 존재하지 않습니다.

### 한 줄 예

$\log_2 8 = 3$은 정의되지만 ($a=2, b=8$ 모두 조건 만족), $\log_{-2} 8$이나 $\log_1 8$, $\log_2(-8)$은 정의되지 않습니다.

### 검산

```python
import sympy as sp
# log_2(8) = 3 확인
sp.log(8, 2)  # 3
```
