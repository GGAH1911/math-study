# 방정식과 부등식

> **단원** · 고1 · 선수: [이차방정식](./이차방정식.md) / [일차부등식](./일차부등식.md) / [다항식](./다항식.md) · 다음: 없음 (말단 노드 / Phase 1에서 미정의)

## 학습 목표

- 이차방정식의 판별식·근과 계수의 관계를 자유롭게 활용한다
- 고차·연립·절댓값·이차부등식을 풀 수 있다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 복소수 $a+bi$, 켤레복소수

**정리(theorem)**
- 이차방정식 판별식 $D$의 부호와 근의 분류 (실근/허근)
- 근과 계수의 관계
- 이차부등식 해의 분류

**예제(example)**
- 복소수 사칙연산
- 근과 계수의 관계로 식의 값
- 이차부등식 그래프 활용
