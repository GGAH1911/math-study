# 순환소수

> **정의** · 중2 · 단원: [유리수와 순환소수](/concepts/유리수와_순환소수)

## 요약
소수점 아래 일정 부분이 반복

## 본문 (학습 시 채워짐)

### 정확한 진술

순환소수란 소수점 아래의 어떤 자리부터 일정한 숫자들의 블록이 끝없이 반복되는 소수입니다. 반복되는 부분을 **순환마디**라 하며, 순환마디 위에 점을 표기합니다. 예를 들어 $0.\overline{3} = 0.3333\ldots$는 3이 계속 반복되고, $0.1\overline{6} = 0.1666\ldots$는 소수점 아래 두 번째 자리부터 6이 반복됩니다.

### 직관/기하적 의미

모든 유리수를 나눗셈으로 소수로 나타내면 순환소수 또는 유한소수가 됩니다. 순환소수가 나타나는 이유는 나눗셈 과정에서 나머지가 반복되기 때문입니다. 예를 들어 $1 \div 3$을 계속하면 나머지가 항상 1로 같으므로, 몫의 숫자 3이 계속 반복됩니다. 

일반적으로 나눗셈에서 가능한 나머지는 0부터 제수(나누는 수)에서 1을 뺀 값까지 유한개입니다. 따라서 언젠가는 같은 나머지가 다시 나타나 패턴이 반복되거나 나머지가 0이 되어 나눗셈이 끝납니다. 이것이 바로 **모든 유리수는 순환소수 또는 유한소수로 표현된다**는 의미입니다.

### 예시

- $\frac{1}{3} = 0.\overline{3}$ (순환마디: 3)
- $\frac{5}{6} = 0.8\overline{3}$ (순환마디: 3, 비순환 부분: 8)
- $\frac{1}{7} = 0.\overline{142857}$ (순환마디: 142857)

검산: `1/3`을 계산기로 나누면 $0.333\ldots$이고, `5/6 = 0.833\ldots$, `1/7 ≈ 0.142857142857$로 확인됩니다.
