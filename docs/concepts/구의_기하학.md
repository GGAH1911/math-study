### 정확한 진술

공간상의 한 점을 중심으로 하여 일정한 거리에 있는 모든 점들의 집합을 **구(sphere)**라고 합니다. 중심을 $O$, 반지름을 $r$이라 할 때, 구 위의 임의의 점 $P$에 대해 $|OP| = r$이 성립합니다.

좌표계에서 중심이 $(a, b, c)$이고 반지름이 $r$인 구의 방정식은 다음과 같습니다:
$$\left(x-a\right)^2 + \left(y-b\right)^2 + \left(z-c\right)^2 = r^2$$

### 직관과 기하적 의미

구는 2차원 평면에서의 '원'을 3차원 공간으로 확장한 개념입니다. 원이 평면상 한 중심에서 등거리에 있는 점들의 집합이듯이, 구는 공간의 중심에서 등거리에 있는 모든 점들의 집합입니다. 축구공, 지구, 농구공처럼 우리 주변에서 쉽게 관찰할 수 있는 3차원 도형이죠.

구는 다음과 같은 기하학적 특성을 갖습니다:

- **어떤 평면으로 자르든 단면은 원입니다**: 기울어진 방향이든, 수평이든 구를 자르면 항상 원의 모양이 나타납니다.
- **대원(great circle)**: 중심을 지나는 평면으로 자른 단면원이 가장 크며, 이를 대원이라 부릅니다. 지구의 적도가 대원의 예입니다.
- **곡면의 성질**: 구의 표면은 곡면이므로 원의 둘레처럼 평면에 전개도를 만들 수 없습니다.

### 한 줄 예

중심이 원점 $(0, 0, 0)$이고 반지름이 $3$인 구의 방정식은 $x^2 + y^2 + z^2 = 9$입니다. 이 구 위의 점 $(3, 0, 0)$과 $(0, 2, \sqrt{5})$를 확인하면 $3^2 + 0^2 + 0^2 = 9$ ✓, $0^2 + 2^2 + (\sqrt{5})^2 = 9$ ✓로 모두 방정식을 만족합니다.
