### 정확한 진술

이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)의 판별식을 $D = b^2 - 4ac$라 할 때:
- **중근(重根)**: $D = 0$일 때, 방정식이 하나의 실근을 중근도 2로 갖는 경우. 이 경우 근의 공식에서 $x = \dfrac{-b}{2a}$ (중근도 2)
- **단순근(單純根)**: $D > 0$일 때, 방정식이 서로 다른 두 개의 실근을 갖는 경우. 근의 공식에서 $x = \dfrac{-b \pm \sqrt{D}}{2a}$ (각각 중근도 1)

### 직관/기하적 의미

포물선 $y = ax^2 + bx + c$의 그래프와 $x$축의 교점 개수로 생각할 수 있습니다.

**중근의 경우**: 포물선이 $x$축에 정확히 한 점에서 **접합니다**. 즉, 교점이 있지만 관통하지 않고 스스로 반대 방향으로 꺾입니다. 이를 "중근"이라 부르는 이유는 근의 공식에서 같은 값이 중복(두 번) 나타나기 때문입니다.

**단순근의 경우**: 포물선이 $x$축과 서로 다른 두 점에서 **만나며 관통합니다**. 각 근은 서로 다르고, 중근도가 각각 1입니다.

### 한 줄 예

- 중근: $x^2 - 4x + 4 = (x-2)^2 = 0$ → 중근 $x=2$ (중근도 2)
  - 검산: `sympy.factor(x**2 - 4*x + 4)` → $(x-2)^2$
- 단순근: $x^2 - 5x + 6 = 0$ → 근: $x=2, 3$ (각각 단순근)
  - 검산: `sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$
