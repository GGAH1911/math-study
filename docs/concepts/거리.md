### 정확한 진술

평면 위의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 **거리**는 다음과 같이 정의됩니다.

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

이를 두 점 사이의 거리 공식(distance formula)이라 부르며, $|AB|$로도 표기합니다. 특히 한 점이 원점 $O(0, 0)$일 때, 점 $P(x, y)$와 원점 사이의 거리는 $|OP| = \sqrt{x^2 + y^2}$입니다.

### 직관과 기하적 의미

거리는 두 점을 잇는 **최단 경로의 길이**입니다. 거리 공식은 피타고라스 정리로부터 유도됩니다. 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$를 꼭짓점으로 하는 직각삼각형을 그리면, 가로 변의 길이는 $|x_2 - x_1|$, 세로 변의 길이는 $|y_2 - y_1|$입니다. 빗변 $AB$의 길이가 바로 두 점 사이의 거리이므로, 피타고라스 정리에 의해 위 공식을 얻습니다.

거리는 다음 성질을 만족합니다:
- $d(A, B) \geq 0$ (항상 0 이상)
- $d(A, B) = 0 \Leftrightarrow A = B$
- $d(A, B) = d(B, A)$ (대칭성)
- $d(A, C) \leq d(A, B) + d(B, C)$ (삼각부등식)

### 예시

점 $A(1, 2)$와 점 $B(4, 6)$ 사이의 거리는:

$$|AB| = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

(`sympy.sqrt((4-1)**2 + (6-2)**2)` → `5`)
