### 정확한 진술

정사각형은 네 변의 길이가 모두 같고, 네 개의 내각이 모두 $90°$인 사각형입니다. 즉, 모든 변이 합동이고 모든 각이 직각인 특별한 직사각형입니다. 한 변의 길이를 $a$라 하면, 정사각형의 둘레는 $4a$이고 넓이는 $a^2$입니다.

### 직관과 기하적 의미

정사각형은 평행사변형, 마름모, 직사각형의 성질을 모두 가집니다. 대각선은 길이가 같고($a\sqrt{2}$), 서로를 이등분하며, 수직으로 만납니다. 이러한 대칭성 때문에 정사각형은 가장 규칙적인 사각형이며, 좌표평면에서 기울기 관계를 분석할 때도 자주 등장합니다.

정사각형의 꼭짓점을 좌표로 나타낼 때, 인접한 두 변의 기울기의 곱은 $-1$입니다 (수직 관계). 예를 들어 한 꼭짓점이 원점에 있고 한 변이 $x$축과 평행하면, 다음 변은 $y$축과 평행해야 정사각형을 이루죠.

### 한 줄 예

한 변의 길이가 5인 정사각형의 넓이는 $5^2 = 25$이고, 대각선의 길이는 $5\sqrt{2}$입니다. 대각선이 직각이등분선이므로, 정사각형의 중심에서 각 꼭짓점까지의 거리는 모두 $\frac{5\sqrt{2}}{2}$로 같습니다.

**검산:** 대각선 길이 $d = a\sqrt{2}$일 때, 중심에서 꼭짓점까지 거리 $= \frac{d}{2}$ (한 변의 길이가 5)

```python
# sympy: 대각선 길이 확인
import sympy as sp
a = 5
diagonal = a * sp.sqrt(2)
print(diagonal)  # 5*sqrt(2)
```
