# 혼합수

혼합수란 정수 부분과 진분수 부분이 합쳐진 형태로 나타낸 분수를 말한다. 즉, 자연수와 진분수를 나란히 붙여 쓴 수이며, 이때 자연수와 진분수 사이에는 덧셈이 숨어 있다.

예를 들어 $2\dfrac{3}{5}$라고 쓰면, 이는 $2 + \dfrac{3}{5}$를 뜻한다. 혼합수에서 앞에 오는 자연수 부분을 **정수 부분**, 뒤에 오는 분수 부분을 **분수 부분**이라고 한다.

혼합수는 반드시 분수 부분이 진분수(분자가 분모보다 작은 분수)여야 한다. 분수 부분이 가분수(분자가 분모보다 크거나 같은 분수)인 경우에는 혼합수가 아니라, 먼저 정리하여 다시 혼합수나 정수로 고쳐야 한다.

## 예시

**혼합수를 가분수로 고치기**

$$3\dfrac{2}{7} = 3 + \dfrac{2}{7} = \dfrac{21}{7} + \dfrac{2}{7} = \dfrac{23}{7}$$

정수 부분 $3$을 분모 $7$을 이용해 $\dfrac{21}{7}$로 바꾼 다음, 분수 부분 $\dfrac{2}{7}$와 더하면 된다. 공식으로 정리하면 $a\dfrac{b}{c} = \dfrac{a \times c + b}{c}$ 이다.

**가분수를 혼합수로 고치기**

$$\dfrac{17}{4} = 4 + \dfrac{1}{4} = 4\dfrac{1}{4}$$

$17 \div 4 = 4 \cdots 1$이므로, 몫 $4$가 정수 부분, 나머지 $1$이 분자가 되어 $4\dfrac{1}{4}$로 나타낸다.

## 관련 개념

**정수와 유리수** — 혼합수는 유리수의 한 표현 방법이다. 같은 수를 혼합수, 가분수, 소수 등 여러 형태로 나타낼 수 있으며, 어떤 형태로 써도 수의 크기는 같다.

**진분수와 가분수** — 혼합수의 분수 부분은 반드시 진분수여야 하므로, 진분수와 가분수의 구분을 정확히 알아야 혼합수를 올바르게 다룰 수 있다. 또한 혼합수와 가분수는 서로 자유롭게 변환할 수 있어, 분수의 사칙연산을 할 때 상황에 따라 편리한 형태를 선택해 사용한다.

**분수의 덧셈과 뺄셈** — 혼합수끼리 덧셈이나 뺄셈을 할 때는 혼합수를 가분수로 바꾼 뒤 계산하거나, 정수 부분과 분수 부분을 따로 계산하는 두 가지 방법을 쓴다. 특히 뺄셈에서 분수 부분이 부족하면 정수 부분에서 $1$을 받아 내려야 하므로 주의가 필요하다.
