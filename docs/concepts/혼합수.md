# 혼합수

## 요약
혼합수는 자연수와 진분수를 나란히 붙여 쓴 수로, 정수 부분과 분수 부분의 합으로 이루어져 있습니다.

## 본문
혼합수란 정수 부분과 진분수 부분이 합쳐진 형태로 나타낸 분수를 말합니다. 즉, 자연수와 진분수를 나란히 붙여 쓴 수이며, 이때 자연수와 진분수 사이에는 덧셈이 숨어 있습니다. 예를 들어 $2\dfrac{3}{5}$라고 쓰면, 이는 $2 + \dfrac{3}{5}$를 뜻합니다. 혼합수에서 앞에 오는 자연수 부분을 **정수 부분**, 뒤에 오는 분수 부분을 **분수 부분**이라고 합니다.

혼합수는 반드시 분수 부분이 진분수(분자가 분모보다 작은 분수)여야 합니다. 만약 분수 부분이 가분수(분자가 분모보다 크거나 같은 분수)인 경우에는 혼합수가 아니므로, 먼저 정리하여 다시 혼합수나 정수로 고쳐야 합니다.

### 직관과 기하적 의미
혼합수는 전체를 나타내는 자연수 단위와 그보다 작은 조각인 분수 단위를 동시에 보여줍니다. 예를 들어 사과 3개와 사과 4분의 1개가 있다면, 이를 $3\dfrac{1}{4}$로 나타내어 전체 양을 직관적으로 파악할 수 있습니다.

### 기본 성질
혼합수와 가분수 사이의 변환은 다음과 같은 규칙을 따릅니다.

**혼합수를 가분수로 고치기**
정수 부분을 분모와 곱한 뒤 분수 부분의 분자를 더하여 새로운 분자를 만듭니다.
$$a\dfrac{b}{c} = \dfrac{a \times c + b}{c}$$
예시: $3\dfrac{2}{7} = 3 + \dfrac{2}{7} = \dfrac{21}{7} + \dfrac{2}{7} = \dfrac{23}{7}$

**가분수를 혼합수로 고치기**
가분수의 분자를 분모로 나눈 몫을 정수 부분으로, 나머지를 분수 부분의 분자로 정합니다.
예시: $\dfrac{17}{4} = 4 \cdots 1$ 이므로, $4\dfrac{1}{4}$

## 학습 체크
- 혼합수의 분수 부분이 가분수라면 어떻게 처리해야 할까요?
- $a\dfrac{b}{c}$를 가분수로 바꿀 때 정수 부분 $a$에 무엇을 곱해야 하나요?
- 가분수를 혼합수로 바꿀 때 몫과 나머지는 각각 무엇을 의미하나요?

## 관련 개념

**정수와 유리수** — 혼합수는 유리수의 한 표현 방법이다. 같은 수를 혼합수, 가분수, 소수 등 여러 형태로 나타낼 수 있으며, 어떤 형태로 써도 수의 크기는 같다.

**진분수와 가분수** — 혼합수의 분수 부분은 반드시 진분수여야 하므로, 진분수와 가분수의 구분을 정확히 알아야 혼합수를 올바르게 다룰 수 있다. 또한 혼합수와 가분수는 서로 자유롭게 변환할 수 있어, 분수의 사칙연산을 할 때 상황에 따라 편리한 형태를 선택해 사용한다.

**분수의 덧셈과 뺄셈** — 혼합수끼리 덧셈이나 뺄셈을 할 때는 혼합수를 가분수로 바꾼 뒤 계산하거나, 정수 부분과 분수 부분을 따로 계산하는 두 가지 방법을 쓴다. 특히 뺄셈에서 분수 부분이 부족하면 정수 부분에서 $1$을 받아 내려야 하므로 주의가 필요하다.
