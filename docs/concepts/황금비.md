# 황금비

## 요약
선분의 길이 비가 $\overline{AB} : \overline{AC} = \overline{AC} : \overline{CB}$를 만족할 때의 비율을 의미하며, 그 값은 $\tfrac{1+\sqrt{5}}{2}$이다.

## 본문
선분 $\overline{AB}$를 점 $C$가 $\overline{AB} : \overline{AC} = \overline{AC} : \overline{CB}$를 만족하도록 내분할 때, 이 비율을 **황금비**라 한다. 황금비의 값 $\varphi$는 방정식 $\varphi^2 = \varphi + 1$의 양의 실수 해로 $\varphi = \tfrac{1+\sqrt{5}}{2} \approx 1.618$이다.

### 직관과 기하적 의미
황금비는 시각적으로 매우 안정적이고 아름다운 비율로 알려져 있으며, 기하학적으로는 정오각형의 대각선과 한 변의 길이의 비에서도 나타나는 중요한 상수이다. 선분을 황금비로 내분한다는 것은 전체와 부분의 비율이, 부분과 나머지 부분의 비율과 같아지는 상태를 의미한다.

### 기본 성질
$\overline{AC} = 1$, $\overline{CB} = x$로 놓으면 황금비 조건에 의해 다음과 같은 이차방정식이 도출된다.
$$\frac{1+x}{1} = \frac{1}{x} \implies x^2 + x - 1 = 0 \implies x = \frac{-1+\sqrt{5}}{2}$$
따라서 전체와 부분의 비인 $\overline{AB} : \overline{AC}$는 다음과 같이 계산된다.
$$\overline{AB} : \overline{AC} = \dfrac{1 + x}{1} = \dfrac{1+\sqrt{5}}{2} = \varphi$$

## 학습 체크
- 선분 $\overline{AB}$를 황금비로 내분하는 점 $C$에 대하여, $\overline{AB} : \overline{AC}$의 값과 $\overline{AC} : \overline{CB}$의 값이 같음을 증명할 수 있는가?
- 정오각형의 대각선 길이를 한 변의 길이로 나누었을 때 나타나는 비율이 황금비임을 이해하고 있는가?
