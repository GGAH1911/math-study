# 황금비

## 정의

선분 $\overline{AB}$를 점 $C$가 $\overline{AB} : \overline{AC} = \overline{AC} : \overline{CB}$를 만족하도록 내분할 때, 이 비율을 **황금비**라 한다. 황금비의 값 $\varphi$는 방정식 $\varphi^2 = \varphi + 1$의 양의 실수 해로 $\varphi = \dfrac{1+\sqrt{5}}{2} \approx 1.618$이다. 황금비는 정오각형의 대각선과 한 변의 비에서도 나타난다.

## 예시

$\overline{AC} = 1$, $\overline{CB} = x$로 놓으면 황금비 조건에 의해

$$\frac{1+x}{1} = \frac{1}{x} \implies x^2 + x - 1 = 0 \implies x = \frac{-1+\sqrt{5}}{2}$$

따라서 $\overline{AB} : \overline{AC} = \dfrac{1 + x}{1} = \dfrac{1+\sqrt{5}}{2} = \varphi$.
