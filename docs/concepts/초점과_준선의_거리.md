# 초점과 준선의 거리

포물선 위의 점은 초점과 준선으로부터 항상 같은 거리에 있다. 이것이 포물선의 근본 정의이며, "초점과 준선의 거리"란 포물선 위의 한 점에서 초점까지의 거리와 그 점에서 준선까지의 거리(점에서 준선에 내린 수선의 길이)가 서로 같다는 성질을 가리킨다.

포물선 $y^2 = 4px$ ($p > 0$)에서 초점은 $F(p,\, 0)$이고 준선은 $x = -p$이다. 포물선 위의 점 $P(x,\, y)$에 대해 초점까지의 거리와 준선까지의 거리를 각각 구하면 둘 다 $x + p$로 같다. 즉,

$$\overline{PF} = x + p$$

이 등거리 관계가 포물선을 포물선이게 하는 핵심이다. 한편 초점 $F(p, 0)$에서 준선 $x = -p$까지의 직선 거리는 $2p$이며, 이 값은 포물선의 크기와 모양을 결정짓는 기준값이다.

## 예시

**예시 1.** 포물선 $y^2 = 8x$에서 $p = 2$이므로 초점은 $F(2,\, 0)$, 준선은 $x = -2$이다. 이 포물선 위의 점 $P(2,\, 4)$를 확인해 보자.

$$\overline{PF} = \sqrt{(2-2)^2 + (4-0)^2} = 4$$

준선 $x = -2$까지의 거리는 $2 - (-2) = 4$. 두 값이 일치한다.

**예시 2.** 포물선 $x^2 = -12y$ ($p = -3$, 아래로 열린 포물선)에서 초점은 $F(0,\, -3)$, 준선은 $y = 3$이다. 위의 점 $P(6,\, -3)$에 대해

$$\overline{PF} = \sqrt{(6-0)^2 + (-3+3)^2} = 6$$

준선 $y = 3$까지의 거리는 $|-3 - 3| = 6$. 역시 같다.

## 관련 개념

- **이차곡선**: 포물선·타원·쌍곡선을 아우르는 개념으로, 초점과 준선의 거리 관계는 이 중 특히 포물선을 정의하는 핵심 성질이다.
- **초점과 준선**: 이 개념의 직접적인 선수 개념. 초점(고정점)과 준선(고정 직선)의 위치를 알아야 거리 관계를 논할 수 있다.
- **초점거리**: 타원과 쌍곡선에서는 한 점과 두 초점까지의 거리의 합(또는 차)이 일정하다는 성질이 중심이다. 포물선의 초점·준선 등거리 성질과 대비하면 이차곡선 전체를 통일된 시각으로 이해하는 데 도움이 된다.
- **이심률**: 초점까지의 거리와 준선까지의 거리의 비 $e = \frac{\overline{PF}}{\overline{Pl}}$ 가 포물선에서는 $e = 1$이고, 타원에서는 $e < 1$, 쌍곡선에서는 $e > 1$이다. 이심률은 초점·준선 관계를 세 이차곡선에 걸쳐 하나의 언어로 기술해 주는 개념이다.
