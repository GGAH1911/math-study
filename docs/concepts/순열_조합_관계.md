# 순열 조합 관계

> **정리** · 고1 · 단원: [경우의 수 (고1)](/concepts/경우의_수_고1)

## 요약
$_nC_r={}_nC_{n-r}$

## 본문 (학습 시 채워짐)

### 진술

$n$개의 서로 다른 원소에서 $r$개를 선택하는 조합의 수는 $(n-r)$개를 선택하는 조합의 수와 같습니다.

$$_nC_r = {}_nC_{n-r}$$

### 대수적 증명

조합의 정의에 따라 

$$_nC_r = \frac{n!}{r!(n-r)!}$$

한편, $(n-r)$개를 선택하는 경우는

$$_nC_{n-r} = \frac{n!}{(n-r)!(n-(n-r))!} = \frac{n!}{(n-r)!r!}$$

분자가 같고 분모의 두 인수만 위치가 바뀌었으므로 두 식은 완전히 일치합니다.

### 직관적 의미

학생 5명 중에서 **선발할 2명**을 고르는 경우의 수를 세는 방식을 두 가지로 생각해봅시다. 첫째는 선발 명단을 직접 구성하는 것 ($_5C_2$), 둘째는 선발하지 않을 2명을 정하는 것 ($_5C_3$)입니다. 놀랍게도 두 방식은 같은 결과를 줍니다. 왜냐하면 각 선발 집합에는 정확히 하나의 미선발 집합이 대응되기 때문입니다. 이것은 조합이 본질적으로 "어떤 것을 포함할지"와 "어떤 것을 제외할지"가 같은 정보임을 의미합니다.

### 실용적 응용

계산을 간편히 하는 데 유용합니다. $_nC_r$에서 $r$이 $n/2$보다 크면, $_nC_{n-r}$로 바꿔서 더 작은 수를 곱하면 됩니다. 예를 들어 

$$_{20}C_{18} = {}_20C_2 = \frac{20 \times 19}{2 \times 1} = 190$$

훨씬 간단한 계산이 되었습니다. (`binomial(20, 18)` = `binomial(20, 2)` = 190)
