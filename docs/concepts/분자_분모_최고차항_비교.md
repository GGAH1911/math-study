### 정확한 진술

분자와 분모가 모두 다항식 또는 다항식으로 표현되는 식에서 극한값을 구할 때, **분자와 분모의 최고차항(가장 높은 차수를 가진 항)만 비교하면 극한값을 빠르게 판별할 수 있다**는 원리입니다.

$$\lim_{x \to \infty} \frac{a_n x^n + a_{n-1}x^{n-1} + \cdots + a_0}{b_m x^m + b_{m-1}x^{m-1} + \cdots + b_0} = \begin{cases} 0 & \text{if } n < m \\ \frac{a_n}{b_m} & \text{if } n = m \\ \pm\infty & \text{if } n > m \end{cases}$$

여기서 $n$과 $m$은 각각 분자와 분모의 최고차수, $a_n$과 $b_m$은 최고차항의 계수입니다.

### 직관과 의미

$x$가 매우 클 때(또는 작을 때), 다항식에서는 **최고차항이 전체 값을 지배**합니다. 예를 들어, $100x^3 + 2x + 1$에서 $x = 1000$일 때, $100x^3$ 부분이 나머지를 완전히 압도합니다. 따라서 낮은 차수의 항들은 극한값 판별에 영향을 주지 않습니다.

이 원리를 사용하면 복잡한 계산 없이도:
- **분자와 분모의 차수를 비교**하여 극한이 0인지, 유한값인지, 무한대인지 판별할 수 있습니다.
- 수열의 수렴/발산 판정 문제를 신속하게 풉니다.

### 구체적 예

$$\lim_{n \to \infty} \frac{3n^2 + n + 5}{2n^2 - 10}$$

최고차항: 분자 $3n^2$, 분모 $2n^2$
차수가 같으므로 극한값 = $\frac{3}{2}$ ✓

(`sympy.limit((3*n**2 + n + 5)/(2*n**2 - 10), n, oo)`)

### 주의점

이 기법은 $x \to \infty$ 또는 $x \to -\infty$일 때만 적용됩니다. $x \to 0$ 같은 유한한 점에서의 극한이나 분모가 0이 되는 불꼴의 경우는 **인수분해나 로피탈 정리** 같은 다른 방법을 써야 합니다.
