### 정확한 진술

일어날 가능성이 모두 같은 기본 사건이 $n$개 있고, 이 중 사건 $A$에 속하는 기본 사건이 $m$개일 때, 사건 $A$의 **확률** $P(A)$를 다음과 같이 정의합니다.

$$P(A) = \frac{m}{n} = \frac{\text{사건 } A \text{의 경우의 수}}{\text{전체 경우의 수}}$$

**주의:** 이 정의는 모든 기본 사건이 **동등하게 일어날 가능성**을 가질 때만 적용됩니다. 예를 들어 불공정한 주사위는 이 공식을 쓸 수 없습니다.

### 직관과 기본 성질

확률은 어떤 일이 일어날 **가능성의 정도**를 나타냅니다. 기본 사건들이 대칭적일 때, 원하는 결과가 전체 중 얼마나 많은 부분을 차지하는지 측정하는 것입니다.

확률의 기본 성질:
- $0 \le P(A) \le 1$ (모든 사건의 확률은 0 이상 1 이하)
- $P(\Omega) = 1$ (전체 사건이 일어날 확률은 1)
- 서로 배반인 사건 $A$, $B$에 대해 $P(A \cup B) = P(A) + P(B)$

### 예: 주사위

공정한 주사위를 한 번 던져 홀수가 나올 확률을 구하세요.

**풀이:**  
전체 기본 사건: 1, 2, 3, 4, 5, 6 → $n=6$  
홀수인 기본 사건: 1, 3, 5 → $m=3$

$$P(\text{홀수}) = \frac{3}{6} = \frac{1}{2}$$

**검산:** `sympy.Rational(3, 6)`를 계산하면 `1/2`

**주의:** '가능성이 같다'는 조건이 중요합니다. 불규칙한 주사위나 특정 목표를 선호하는 상황에서는 고전적 확률을 쓸 수 없습니다.
