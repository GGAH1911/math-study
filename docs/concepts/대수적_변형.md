### 정의

대수적 변형이란, 주어진 식을 **등가(같은 값을 갖는) 다른 형태로 바꾸는 과정**입니다. 식의 본질적 값을 바꾸지 않으면서 인수분해, 전개, 약분, 또는 항등식 대입 등을 통해 표현을 단순화하거나 원하는 형태로 만드는 것입니다. 삼각함수 단원에서는 삼각함수 항등식(예: $\sin^2 x + \cos^2 x = 1$, 덧셈공식 등)을 이용해 복잡한 삼각식을 더 간단하거나 계산하기 좋은 형태로 변형합니다.

### 직관적 의미

수학에서는 같은 대상을 여러 각도에서 바라볼 수 있습니다. 예를 들어, $\sin^2 x + \cos^2 x = 1$이므로 $\sin^2 x$를 $1 - \cos^2 x$로 바꿀 수 있습니다. 문제에 따라 어떤 형태가 더 유용한지가 결정되므로, 상황에 맞춰 식을 변형하는 기술이 핵심입니다. 정적분을 계산할 때 적분이 불가능해 보이는 식도 대수적 변형으로 적분 가능한 형태로 만들 수 있고, 방정식을 풀 때도 특정 형태로 변형해야 해가 보이는 경우가 많습니다.

### 기본 예

$\sin^2 x + 2\sin x \cos x + \cos^2 x$를 변형하면:

$$(\sin^2 x + \cos^2 x) + 2\sin x \cos x = 1 + 2\sin x \cos x = 1 + \sin 2x$$

첫 번째 식은 복잡해 보이지만, 항등식 $\sin^2 x + \cos^2 x = 1$과 덧셈공식 $2\sin x \cos x = \sin 2x$를 적용하면 한눈에 정리됩니다. 이것이 대수적 변형의 목표입니다.
