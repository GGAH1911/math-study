### 정확한 진술

**각도**는 한 점(꼭짓점)에서 출발하는 두 반직선이 만드는 도형입니다. 기호로는 $\angle AOB$처럼 나타내며, $O$는 꼭짓점, $A$와 $B$는 반직선 위의 점입니다. 각도의 크기는 두 반직선 사이의 **회전량**을 나타내는 수로, 도(°) 또는 라디안(rad)으로 측정합니다.

### 직관과 기하적 의미

각도는 "한 반직선이 다른 반직선으로부터 얼마나 벌어져 있는가"를 재는 척도입니다. 예를 들어 시계 바늘을 생각해보면, 시침과 분침 사이의 벌어짐 정도가 바로 각도입니다. 도 단위에서는 한 바퀴를 360°로 나누며, 라디안에서는 한 바퀴를 $2\pi$로 나눕니다.

각도의 분류:
- **직각**: $90°$ 또는 $\frac{\pi}{2}$ rad
- **예각**: $0° < \theta < 90°$
- **둔각**: $90° < \theta < 180°$
- **평각**: $180°$ 또는 $\pi$ rad
- **우각**: $180° < \theta < 360°$

각도는 기하 도형의 기본 성질을 결정합니다. 삼각형의 내각의 합이 180°인 것도, 직사각형의 모든 각이 직각인 것도 모두 각도 개념에서 비롯됩니다.

### 한 줄 예

시각 3시를 나타낼 때 시침과 분침이 이루는 각도는 직각 $\angle = 90°$입니다.

**도를 라디안으로 변환**: $90° = 90 \times \frac{\pi}{180} = \frac{\pi}{2}$ rad
(검증: `sympy.pi * 90 / 180` → $\pi/2$)
