# 지수의 덧셈

## 요약
지수법칙에 따라 밑이 같은 두 거듭제곱의 곱은 지수들의 합으로 나타낼 수 있습니다.

## 본문
밑이 같은 두 수의 거듭제곱을 곱하면 결과값의 지수는 원래 두 지수의 합과 같습니다. 즉, $a^m \times a^n = a^{m+n}$ (단, $a \neq 0$)의 관계가 성립합니다. 이는 동일한 수를 $m$번 곱한 후 다시 $n$번 더 곱하는 과정이 결국 총 $m+n$번을 곱하는 것과 같다는 원리에 기반합니다.

### 직관과 기하적 의미
지수는 동일한 수의 반복된 곱셈 횟수를 의미합니다. 예를 들어 $2^3$은 $2$를 세 번 곱한 것이고, $2^2$은 $2$를 두 번 곱한 것입니다. 이 둘을 곱하면 $2$가 총 $3+2=5$번 곱해진 $2^5$이 됩니다. 이는 수직선 상에서 배수의 확장이 연속적으로 일어나는 과정으로 이해할 수 있습니다.

### 기본 성질
지수의 덧셈이 성립하기 위해서는 반드시 두 수의 밑이 동일해야 합니다. 만약 밑이 서로 다르다면 지수의 합을 바로 적용할 수 없으며, 지수가 $0$인 경우($a^0=1$)나 음수인 경우에도 이 법칙은 유효하게 적용됩니다.

## 학습 체크
- 곱셈 연산 시 두 수의 밑이 서로 같은지 반드시 확인하였는가?
- 지수가 분수나 음수인 경우에도 지수의 덧셈 법칙이 동일하게 적용됨을 이해하고 있는가?

## 관련 개념
- **지수와 로그**: 지수가 밑을 몇 번 곱했는지를 나타내는 수라면, 로그는 결과값이 나오기 위해 밑을 몇 번 곱해야 하는지를 나타내는 역연산 관계입니다.
