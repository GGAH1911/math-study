# 내분점 조건

수직선 위에서 점 $B$가 두 점 $A$와 $C$ 사이를 $m:n$으로 내분할 조건은

$$B = \frac{nA + mC}{m+n}$$

이다. 세 양수 $a,\, b,\, c$에 대해 이 내분 조건을 로그에 적용하면 다음과 같이 쓸 수 있다.

$$\log b = \frac{n \log a + m \log c}{m+n}$$

양변에 $m+n$을 곱하면 $(m+n)\log b = n\log a + m\log c$, 즉

$$b^{\,m+n} = a^{\,n} \cdot c^{\,m}$$

이 된다. 이것이 지수·로그 맥락에서 내분점 조건의 핵심 변환이다.

특히 $m = n$, 즉 **$\log b$가 $\log a$와 $\log c$의 중점(1:1 내분)**일 때는

$$b^2 = ac$$

가 되어, $b$는 $a$와 $c$의 기하평균(등비중항)이다.

---

## 예시

**예시 1.** $\log_2 b$가 $\log_2 3$과 $\log_2 12$를 $1:2$로 내분할 때 $b$의 값을 구하시오.

내분점 공식을 적용하면

$$\log_2 b = \frac{2 \cdot \log_2 3 + 1 \cdot \log_2 12}{1+2} = \frac{\log_2 9 + \log_2 12}{3} = \frac{\log_2 108}{3} = \log_2 108^{\,\frac{1}{3}}$$

따라서 $b = \sqrt[3]{108}$이다.

핵심 공식으로 검산하면 $b^{\,1+2} = 3^{\,2} \cdot 12^{\,1}$, 즉 $b^3 = 108$ 이므로 일치한다.

**예시 2.** 양수 $a,\, b,\, c$에 대해 $\log a,\, \log b,\, \log c$가 이 순서대로 등차수열을 이루면, 등차중항 조건 $2\log b = \log a + \log c$에 의해

$$\log b^2 = \log ac \implies b^2 = ac$$

이므로 $b$는 $a$와 $c$의 기하평균이다. 예를 들어 $a = 2,\, c = 8$이면 $b^2 = 16$이므로 $b = 4$.

## 관련 개념

**도형의 방정식 — 내분점 공식** 이 개념의 뿌리다. 수직선 위의 내분 공식 $\frac{nA+mC}{m+n}$을 로그값에 그대로 대입한 것이 내분점 조건의 전부다.

**로그의 성질** $\log b^k = k\log b$, $\log ac = \log a + \log c$ 변환이 핵심 도구다. 이 두 성질 없이는 $b^{m+n} = a^n c^m$ 꼴로 정리할 수 없다.

**등비수열·등비중항** 1:1 내분 경우 $b^2 = ac$는 등비수열의 인접 세 항이 만족하는 조건과 완전히 같다. 내분점 조건이 $m=n$으로 특수화되면 등비중항 문제가 된다.

**지수함수·로그함수의 그래프** 곡선 위 세 점이 내분 관계에 놓일 때, $x$좌표와 $y$좌표 각각에 내분 조건을 적용하는 문제로 확장된다. 특히 $y = \log_a x$ 위의 점들에 적용할 때 위 조건이 직접 등장한다.
