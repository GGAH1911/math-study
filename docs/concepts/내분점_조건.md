# 내분점 조건

## 요약
수직선 위의 내분점 공식은 로그의 성질과 결합하여 지수와 로그 사이의 관계를 설명하는 핵심 도구가 된다.

## 본문
수직선 위에서 점 $B$가 두 점 $A$와 $C$ 사이를 $m:n$으로 내분할 조건은 $B = \tfrac{nA + mC}{m+n}$이다. 이 내분점 조건을 로그 함수에 적용하면 세 양수 $a, b, c$에 대하여 $\log b = \tfrac{n \log a + m \log c}{m+n}$이라는 식을 얻을 수 있다. 양변에 $m+n$을 곱하여 정리하면 $(m+n)\log b = n\log a + m\log c$가 되며, 로그의 성질을 이용해 지수로 변환하면 $b^{m+n} = a^n \cdot c^m$이라는 관계식이 도출된다. 이는 로그의 세계에서의 내분 관계가 지수의 세계에서는 거듭제곱과 곱셈의 관계로 변환됨을 의미한다.

### 직관과 기하적 의미
내분 비율이 $m=n$인 경우, 즉 $\log b$가 $\log a$와 $\log c$의 중점(1:1 내분)인 상황을 생각해보자. 이때 식은 $\log b = \tfrac{\log a + \log c}{2}$가 되며, 이는 $2\log b = \log a + \log c$로 쓸 수 있다. 이를 지수로 변환하면 $b^2 = ac$가 되는데, 이는 $b$가 $a$와 $c$의 기하평균(등비중항)임을 의미한다. 즉, 로그 값들이 산술적으로 등차수열을 이루면, 원래의 값들은 기하적으로 등비수열을 이루게 된다.

### 기본 성질
- 로그의 내분점 공식은 지수 법칙을 통해 $b^{m+n} = a^n \cdot c^m$의 형태로 변환 가능하다.
- $\log a, \log b, \log c$가 등차수열을 이루면 $a, b, c$는 등비수열을 이룬다.
- 내분 비율이 $1:1$일 때, 로그의 산술평균은 원래 값들의 기하평균의 로그와 같다.

## 학습 체크
- $\log_2 b$가 $\log_2 3$과 $\log_2 12$를 $1:2$로 내분할 때, $b$를 구하기 위해 $b^3 = 3^2 \cdot 12$를 이용할 수 있는가?
- $\log a, \log b, \log c$가 등차수열을 이룰 때, 왜 $b^2 = ac$라는 관계식이 성립하는지 로그의 성질을 이용하여 설명할 수 있는가?

## 관련 개념

**도형의 방정식 — 내분점 공식** 이 개념의 뿌리다. 수직선 위의 내분 공식 $\tfrac{nA+mC}{m+n}$을 로그값에 그대로 대입한 것이 내분점 조건의 전부다.

**로그의 성질** $\log b^k = k\log b$, $\log ac = \log a + \log c$ 변환이 핵심 도구다. 이 두 성질 없이는 $b^{m+n} = a^n c^m$ 꼴로 정리할 수 없다.

**등비수열·등비중항** 1:1 내분 경우 $b^2 = ac$는 등비수열의 인접 세 항이 만족하는 조건과 완전히 같다. 내분점 조건이 $m=n$으로 특수화되면 등비중항 문제가 된다.

**지수함수·로그함수의 그래프** 곡선 위 세 점이 내분 관계에 놓일 때, $x$좌표와 $y$좌표 각각에 내분 조건을 적용하는 문제로 확장된다. 특히 $y = \log_a x$ 위의 점들에 적용할 때 위 조건이 직접 등장한다.
