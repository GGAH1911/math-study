### 정확한 진술

허근이란 **실수가 아닌 복소수 근**을 의미합니다. 즉, $a, b, c$가 실수이고 $a \neq 0$일 때, 이차방정식 $ax^2 + bx + c = 0$의 판별식 $D = b^2 - 4ac < 0$이면 근의 공식에 의해 두 근은
$$x = \frac{-b \pm \sqrt{D}}{2a} = \frac{-b \pm \sqrt{-|D|}i}{2a} = \frac{-b}{2a} \pm \frac{\sqrt{|D|}}{2a}i$$
의 형태가 되며, 이러한 근들을 **허근**이라 부릅니다. 이 두 근은 항상 켤레복소수 관계입니다. 예를 들어 $D = -8$이면 근에 $\sqrt{8}i = 2\sqrt{2}i$의 허수 부분이 포함됩니다.

### 직관/기하적 의미

이차함수 $y = ax^2 + bx + c$ ($a \neq 0$)의 그래프를 생각해봅시다. 실근은 **그래프가 $x$축과 만나는 점**입니다. 판별식 $D < 0$이면 포물선이 $x$축과 만나지 않으므로 실근이 존재하지 않습니다. 이때 방정식의 근은 **실수 범위를 벗어나** 복소평면에 존재하게 되는데, 이것이 허근입니다. 복소평면에서 두 허근은 실수축(수평선)에 대해 대칭인 위치에 있습니다.

### 한 줄 예

$x^2 - 2x + 5 = 0$의 경우 $D = 4 - 20 = -16 < 0$이므로 근의 공식에 의해 $x = 1 \pm 2i$가 두 허근입니다. (검증: `sympy.solve(x**2 - 2*x + 5, x)` → $[1 - 2i, 1 + 2i]$)
