### 정확한 진술

제약조건이란 경우의 수를 세기 위해 반드시 만족해야 하는 **조건들의 모음**입니다. 문제에서 명시적으로 제시된 조건(예: "3의 배수", "5자리 수")뿐만 아니라, 상황에 내포된 조건(예: "중복 없음", "양의 정수")도 포함합니다. 경우의 수 문제의 정확한 풀이는 모든 제약조건을 정확히 파악하고, 이들을 모두 동시에 만족하는 경우들만 세는 것에서 비롯됩니다.

### 직관과 의미

제약조건은 전체 가능한 경우에서 **허용되지 않는 것들을 걸러내는 필터 역할**입니다. 예를 들어 "1부터 10까지의 자연수 중 짝수"라고 하면, 짝수 조건이 없었을 때는 10가지 선택지가 있지만, 이 조건이 생기면 2, 4, 6, 8, 10의 5가지만 남습니다. 복합적인 문제에서는 여러 제약조건이 동시에 작용하기 때문에, 각 조건을 명확히 식별하고 중복이나 빠짐 없이 체계적으로 처리하는 능력이 필수적입니다.

### 예시

**예**: 1부터 100까지의 자연수 중에서 3의 배수이면서 동시에 5의 배수인 수의 개수를 구하세요.

제약조건: ① 3의 배수 ② 5의 배수

두 조건을 모두 만족하려면 15의 배수여야 합니다. $\lfloor 100/15 \rfloor = 6$이므로 답은 **6개**입니다. (15, 30, 45, 60, 75, 90)

`len([n for n in range(1, 101) if n % 3 == 0 and n % 5 == 0])`
