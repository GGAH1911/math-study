# 표준편차

## 요약
데이터가 평균으로부터 얼마나 떨어져 있는지를 나타내는 산포도의 척도입니다.

## 본문
표준편차는 데이터의 분포가 평균을 중심으로 얼마나 밀집해 있는지 또는 넓게 퍼져 있는지를 나타내는 수치입니다. 각 데이터 값에서 평균을 뺀 편차를 제곱하여 모두 더한 값인 편차 제곱합을 데이터의 개수로 나눈 것을 분산이라 하며, 표준편차는 이 분산에 양의 제곱근을 취한 값입니다. 즉, 표준편차는 데이터의 변동성을 나타내는 대표적인 지표로 사용됩니다.

### 직관과 기하적 의미
데이터의 값이 평균에 밀집해 있을수록 표준편차는 작아지며, 데이터가 평균에서 멀리 떨어져 넓게 분포할수록 표준편차는 커집니다. 기하학적으로는 데이터 분포의 '퍼짐 정도'를 나타내는 척도로 이해할 수 있으며, 표준편차가 작을수록 데이터는 평균 근처에 모여 있는 안정적인 형태를 띠고 표준편차가 클수록 데이터는 넓게 흩어진 불안정한 형태를 띱니다.

### 기본 성질
표준편차는 항상 $0$ 이상의 값을 가지며, 모든 데이터가 평균과 같다면 표준편차는 $0$이 됩니다. 데이터의 모든 값에 일정한 상수 $a$를 더하거나 빼도 표준편차는 변하지 않지만, 모든 데이터에 $a$를 곱하면 표준편차는 $|a|$배만큼 변하게 됩니다.

## 학습 체크
- 편차의 합이 항상 $0$이 되는 이유와 이것이 표준편차 계산에 미치는 영향은 무엇인가?
- 분산과 비교했을 때 표준편차를 사용하는 실질적인 이유는 무엇인가?

## 관련 개념
- **통계**: 데이터의 중심 경향성을 나타내는 평균과 함께 데이터의 퍼짐 정도를 설명하는 핵심적인 산포도 지표로 활용됩니다.
