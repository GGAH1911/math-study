# 제곱근 계산

> **예제** · 중3 · 단원: [실수와 그 계산](/concepts/실수와_그_계산)

## 요약
$\sqrt 2+\sqrt 8$ 정리

## 본문 (학습 시 채워짐)

### 문제

다음 식을 정리하세요.
$$\sqrt{2} + \sqrt{8}$$

### 단계별 풀이

**1단계: 제곱근 안의 수를 소인수분해**

먼저 각 제곱근을 살펴봅시다. $\sqrt{2}$는 이미 가장 간단한 형태이지만, $\sqrt{8}$은 더 정리할 수 있습니다.

$$8 = 4 \times 2 = 2^2 \times 2$$

**2단계: 제곱인수를 제곱근 밖으로 꺼내기**

$\sqrt{8}$에서 완전제곱수인 4를 찾았습니다. 제곱근의 성질 $\sqrt{a^2 \cdot b} = a\sqrt{b}$ (단, $a \geq 0$)를 이용하면:

$$\sqrt{8} = \sqrt{4 \times 2} = \sqrt{4} \times \sqrt{2} = 2\sqrt{2}$$

**3단계: 같은 제곱근끼리 모으기**

이제 두 항이 모두 $\sqrt{2}$를 인수로 가집니다:

$$\sqrt{2} + \sqrt{8} = \sqrt{2} + 2\sqrt{2} = (1 + 2)\sqrt{2} = 3\sqrt{2}$$

마치 문자항처럼 $\sqrt{2}$의 계수끼리 더하면 됩니다.

### 답

$$3\sqrt{2}$$

검산 (sympy): `sympy.simplify(sympy.sqrt(2) + sympy.sqrt(8))`

### 변형/주의

**비슷한 예제 시도해보기:**
- $\sqrt{3} + \sqrt{12}$ → $\sqrt{12} = 2\sqrt{3}$이므로 답은 $3\sqrt{3}$
- $\sqrt{5} + \sqrt{20}$ → $\sqrt{20} = 2\sqrt{5}$이므로 답은 $3\sqrt{5}$

**주의점:**
- $\sqrt{2} + \sqrt{8} \neq \sqrt{10}$ (제곱근끼리 더할 때 제곱근 안의 수를 더하는 실수를 하지 마세요!)
- 반드시 제곱근 안을 먼저 정리한 후, 같은 종류의 제곱근끼리 모아야 합니다.
- 뺄셈도 같은 방식입니다: $\sqrt{18} - \sqrt{2} = 3\sqrt{2} - \sqrt{2} = 2\sqrt{2}$
