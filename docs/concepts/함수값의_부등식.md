# 함수값의 부등식

## 요약
함수 $f(x)$의 정의역 내에서 $x$의 값에 따른 함숫값의 대소 관계를 통해 부등식의 범위를 결정하는 원리입니다.

## 본문
함수 $f(x)$에 대하여 $x$의 값이 어떤 범위에 있을 때 $f(x_1) < f(x_2)$ 또는 $f(x_1) > f(x_2)$를 만족하는지를 판단하는 것을 함수값의 부등식이라고 합니다. 이는 함수의 증가와 감소 상태를 파악하는 핵심적인 과정이며, 주어진 부등식을 만족하는 $x$의 범위를 구하는 것이 주된 목적입니다. 함수의 그래프가 $x$가 증가함에 따라 위로 올라가면 증가함수이고, 아래로 내려가면 감소함수입니다. 따라서 부등식의 해를 구할 때는 반드시 함수의 단조성(증가 또는 감소 여부)을 먼저 확인해야 합니다.

### 직관과 기하적 의미
그래프 상에서 $f(x_1) < f(x_2)$라는 것은 $x_1$일 때의 점의 높이가 $x_2$일 때의 점의 높이보다 낮음을 의미합니다. 즉, 그래프가 오른쪽으로 갈수록 위로 올라가는 모양이면 $x$값이 커질 때 함숫값도 커지며, 반대로 오른쪽으로 갈수록 내려가는 모양이면 $x$값이 커질 때 함숫값은 작아집니다.

### 기본 성질
1. 함수 $f(x)$가 증가함수이면 $x_1 < x_2$일 때 $f(x_1) < f(x_2)$이다.
2. 함수 $f(x)$가 감소함수이면 $x_1 < x_2$일 때 $f(x_1) > f(x_2)$이다.
3. 부등식의 양변에 함수를 적용할 때는 해당 구간에서 함수가 증가하는지 감소하는지를 반드시 고려해야 한다.

## 학습 체크
- 주어진 함수가 해당 구간에서 증가함수인지 감소함수인지 확인하였는가?
- 부등식의 부호를 결정할 때 $x$의 대소 관계와 함숫값의 대소 관계가 일치하는가, 아니면 반대인가?

## 관련 개념
- **지수함수와 로그함수**: 밑의 조건($a>1$ 또는 $0<a<1$)에 따라 함수의 증가와 감소가 결정되므로, 부등식을 풀 때 밑의 크기에 따른 함수의 성질을 반드시 적용해야 합니다.
