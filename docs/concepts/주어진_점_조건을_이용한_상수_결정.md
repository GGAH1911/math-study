### 정확한 진술

삼각함수 식에서 **주어진 점의 좌표를 조건으로** 미지 상수를 결정하는 방법입니다.

일반적으로 $f(x) = a\sin(bx + c) + d$ 형태의 삼각함수가 특정 점 $(x_0, y_0)$을 지날 때, 이 점을 식에 대입하면:
$$y_0 = a\sin(bx_0 + c) + d$$

이는 미지수 $a, b, c, d$ 사이의 **하나의 관계식**을 제공합니다. 충분한 개수의 점 조건(보통 4개 이상)을 주면 이들을 연립하여 각 상수를 유일하게 결정할 수 있습니다.

### 직관/기하적 의미

삼각함수의 그래프는 **진폭, 주기, 위상, 수직 이동** 네 가지 요소로 완전히 결정됩니다. 그래프가 지나는 점의 좌표들은 이 요소들에 직접적인 **제약 조건**을 제공합니다.

구체적으로:
- 최댓값과 최솟값을 지나는 두 점 → 진폭과 중심선(수직 이동) 결정
- 영점(x축과의 교점) → 위상과 주기의 관계식  
- 임의의 한 점 → 네 상수 전체에 영향을 주는 조건

여러 점이 함께 주어질 때, 이들은 **미지수보다 많은 방정식**을 만들어 유일한 해를 갖도록 보장합니다(실제 삼각함수가 존재하는 경우).

### 한 줄 예

그래프가 점 $(0, 1)$과 $(\pi/2, 3)$을 지나고, 최댓값이 3, 최솟값이 $-1$인 함수 $y = a\sin(x) + b$는: 중심선 $b = 1$, 진폭 $a = 2$이므로 $y = 2\sin(x) + 1$.
