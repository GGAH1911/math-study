# 좌표평면과 각도

## 정의

좌표평면에서 **각도** 는 시초선(양의 $x$축)으로부터 동경이 회전한 크기를 나타내며, 일반각 $\theta$로 표현된다. 좌표평면을 $x$축과 $y$축으로 나눈 네 영역을 **사분면** 이라 하고, 각 사분면에서 삼각함수의 부호가 결정된다. 점 $P(x, y)$와 원점 사이의 거리를 $r = \sqrt{x^2+y^2}$이라 할 때,

$$\sin\theta = \frac{y}{r},\quad \cos\theta = \frac{x}{r},\quad \tan\theta = \frac{y}{x}$$

이 관계로 좌표와 각도를 연결한다.

## 예시

점 $P(-1, \sqrt{3})$이 나타내는 각도와 삼각함수 값을 구하여라.

$$r = \sqrt{(-1)^2 + (\sqrt{3})^2} = 2$$
$$\sin\theta = \frac{\sqrt{3}}{2},\quad \cos\theta = -\frac{1}{2},\quad \tan\theta = -\sqrt{3}$$

따라서 $\theta = 120°$ (제2사분면).
