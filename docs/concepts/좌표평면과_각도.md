# 좌표평면과 각도

## 요약
좌표평면 위에서 각도는 시초선으로부터 동경이 회전한 크기로 정의되며, 삼각함수는 원점과 점 사이의 거리와 좌표의 비율을 통해 결정된다.

## 본문
좌표평면에서 각도는 양의 $x$축을 시초선으로 하여 동경이 회전한 크기를 나타내며, 이를 일반각 $\theta$로 표현한다. 좌표평면은 $x$축과 $y$축에 의해 네 개의 영역인 사분면으로 나뉘며, 각 사분면의 위치에 따라 삼각함수의 부호가 결정된다. 원점과 점 $P(x, y)$ 사이의 거리를 $r = \sqrt{x^2+y^2}$이라 할 때, 삼각함수 $\sin\theta$, $\cos\theta$, $\tan\theta$는 좌표와 다음과 같은 관계를 가진다.

$$\sin\theta = \frac{y}{r},\quad \cos\theta = \frac{x}{r},\quad \tan\theta = \frac{y}{x}$$

이 식을 통해 평면 위의 점의 좌표와 회전한 각도 사이의 유기적인 연결을 이해할 수 있다.

### 직관과 기하적 의미
각도는 단순히 평면 위의 선분이 벌어진 정도를 넘어, 원운동을 통한 회전의 양을 의미한다. 점 $P$가 원점을 중심으로 회전할 때, $r$은 반지름의 역할을 하며 $x$와 $y$ 좌표는 원 위의 점의 위치를 나타낸다. 이때 삼각함수 값은 반지름에 대한 각 성분의 투영된 길이나 기울기로 해석될 수 있다.

### 기본 성질
점 $P(-1, \sqrt{3})$을 예로 들면, 원점으로부터의 거리 $r$은 $\sqrt{(-1)^2 + (\sqrt{3})^2} = 2$이다. 이를 삼각함수 정의에 대입하면 $\sin\theta = \frac{\sqrt{3}}{2}$, $\cos\theta = -\frac{1}{2}$, $\tan\theta = -\sqrt{3}$이 된다. 이때 점 $P$는 $x$가 음수이고 $y$가 양수인 제2사분면에 위치하므로, $\theta = 120^\circ$임을 알 수 있다.

## 학습 체크
- 점 $P(x, y)$의 좌표가 주어졌을 때, $r$을 구하고 각 사분면별 삼각함수의 부호를 정확히 판별할 수 있는가?
- 삼각함수의 정의를 이용하여 좌표값으로부터 $\sin\theta$, $\cos\theta$, $\tan\theta$의 값을 계산할 수 있는가?
