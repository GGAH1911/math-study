# 카디널리티

## 정의

집합의 **카디널리티(cardinality)**란 그 집합의 원소 개수를 나타내는 척도이다. 유한집합 $A$에 대해서는 원소의 개수 $n(A)$로 나타낸다. 수능 수학 범위에서는 주로 유한집합의 카디널리티를 다루며, $n(A \cup B) = n(A) + n(B) - n(A \cap B)$ (포함-배제 원리)가 핵심 공식이다. 두 유한집합 $A$, $B$에 대해 $A = B$이면 $n(A) = n(B)$이다.

## 예시

$A = \{1, 2, 3, 4\}$, $B = \{3, 4, 5, 6, 7\}$일 때,

$$n(A) = 4, \quad n(B) = 5, \quad n(A \cap B) = 2$$

$$n(A \cup B) = 4 + 5 - 2 = 7$$

실제로 $A \cup B = \{1,2,3,4,5,6,7\}$이므로 원소 수는 7개로 일치한다.
