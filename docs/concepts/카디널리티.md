# 카디널리티

## 요약
집합의 카디널리티는 집합에 포함된 원소의 개수를 나타내는 척도이다.

## 본문
집합의 카디널리티(cardinality)란 해당 집합이 얼마나 많은 원소를 포함하고 있는지를 나타내는 크기를 의미한다. 유한집합 $A$의 경우, 원소의 개수를 $n(A)$로 표기하여 그 크기를 정의한다. 수능 수학의 범위 내에서는 주로 원소의 개수가 유한한 집합을 대상으로 하며, 두 집합의 합집합과 교집합 사이의 관계를 설명하는 포함-배제 원리가 매우 중요하다. 즉, 두 유한집합 $A$와 $B$에 대하여 $n(A \cup B) = n(A) + n(B) - n(A \cap B)$라는 관계식이 성립한다. 또한, 두 집합 $A$와 $B$가 서로 같을 조건($A = B$)은 두 집합의 카디널리티가 같을 조건($n(A) = n(B)$)을 포함하는 필수적인 성질이다.

### 직관과 기하적 의미
집합을 점들의 모임으로 생각할 때, 카디널리티는 그 점들이 얼마나 많이 모여 있는지를 나타내는 수치이다. 예를 들어, 수직선 위의 구간을 생각할 때 원소의 개수를 세는 것은 불가능하지만, 유한한 개수의 점들로 이루어진 집합에서는 점의 개수를 세는 것이 곧 집합의 크기를 측정하는 직관적인 방법이 된다.

### 기본 성질
- 두 유한집합 $A, B$에 대하여 $A = B \implies n(A) = n(B)$이다.
- 포함-배제 원리에 의해 $n(A \cup B) = n(A) + n(B) - n(A \cap B)$가 성립한다.
- 집합의 부분집합의 원소 개수는 원래 집합의 원소 개수보다 작거나 같다.

## 학습 체크
- 두 집합의 합집합의 원소 개수를 구할 때 교집합의 원소 개수를 왜 빼주어야 하는가?
- $n(A) = n(B)$라는 사실만으로 두 집합 $A$와 $B$가 항상 같다고 말할 수 있는가?
- 포함-배제 원리를 이용하여 세 집합의 합집합 원소 개수를 구하는 식은 어떻게 확장되는가?
