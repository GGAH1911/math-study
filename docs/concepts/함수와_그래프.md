# 함수와 그래프

> **단원** · 고1 · 선수: [이차함수](./이차함수.md) / [집합과 명제](./집합과_명제.md) · 다음: [삼각함수](./삼각함수.md) / [수열](./수열.md) / [지수함수와 로그함수](./지수함수와_로그함수.md) / [함수의 극한과 연속](./함수의_극한과_연속.md)

## 학습 목표
- 함수의 정의·합성·역함수를 다룬다
- 유리함수·무리함수의 그래프를 그린다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 함수, 정의역·공역·치역
- 일대일대응
- 합성함수, 역함수
- 유리함수 $y=\frac{k}{x-a}+b$
- 무리함수 $y=\sqrt{x-a}+b$

**정리(theorem)**
- 합성함수의 결합법칙
- 역함수의 그래프 = $y=x$ 대칭

**예제(example)**
- 역함수 구하기
- 유리/무리함수 그래프 평행이동
- 치역 구하기
