### 정확한 진술

방정식의 **실근 개수**란 주어진 방정식을 만족하는 실수 해의 개수를 의미합니다. 이차방정식 $ax^2 + bx + c = 0$ (단, $a \neq 0$)에서 실근 개수는 판별식 $D = b^2 - 4ac$의 부호로 결정됩니다:

- $D > 0$일 때: **서로 다른 두 개의 실근**
- $D = 0$일 때: **중근**(중복도 2인 실근 1개)
- $D < 0$일 때: **실근 없음**(허근만 존재)

### 직관 / 기하적 의미

이차방정식 $ax^2 + bx + c = 0$의 실근 개수는 이차함수 $y = ax^2 + bx + c$의 그래프와 $x$축의 교점 개수와 정확히 같습니다. 

포물선이 $x$축과 두 점에서 만나면 서로 다른 두 실근을 가지고, 한 점에서 접하면 중근을 가지며, 만나지 않으면 실근이 없습니다. 따라서 판별식은 포물선의 꼭짓점과 $x$축의 상대적 위치를 수치화한 것입니다.

### 구체적 예

방정식 $x^2 - 5x + 6 = 0$에서 $D = 25 - 24 = 1 > 0$이므로 **서로 다른 두 실근**을 가집니다. 실제로 $(x-2)(x-3) = 0$에서 $x = 2, 3$입니다.

`sympy.solve(x**2 - 5*x + 6, x)` → $[2, 3]$ ✓

방정식 $x^2 - 4x + 4 = 0$에서 $D = 16 - 16 = 0$이므로 **중근** $x = 2$를 가집니다. 방정식 $x^2 + 1 = 0$에서 $D = -4 < 0$이므로 **실근이 없습니다**.
