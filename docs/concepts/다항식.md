## 학습 목표

- 복잡한 다항식을 효율적으로 인수분해한다

## 다룰 정의 / 정리 / 예제 (Phase 2에서 spoke로 분해)

**정의(definition)**
- 다항식, 항등식
- 나머지정리, 인수정리

**정리(theorem)**
- $f(x)$를 $x-a$로 나눈 나머지 $= f(a)$
- $f(a)=0$이면 $(x-a)$가 $f(x)$의 인수

**예제(example)**

- 항등식의 계수 비교
- 고차 다항식 인수분해
