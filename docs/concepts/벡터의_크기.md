### 정확한 진술

3차원 공간의 벡터 $\vec{a} = (a_1, a_2, a_3)$에 대하여, 벡터의 **크기** 또는 **노름(norm)** 을 다음과 같이 정의합니다.

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

2차원 벡터 $\vec{a} = (a_1, a_2)$의 경우에는 $|\vec{a}| = \sqrt{a_1^2 + a_2^2}$입니다. 벡터의 크기는 항상 음이 아닌 실수입니다.

### 직관과 기하적 의미

벡터의 크기는 기하학적으로 **원점에서 점 $(a_1, a_2, a_3)$까지의 직선거리**를 나타냅니다. 3차원에서 좌표축에 평행한 변의 길이가 각각 $|a_1|, |a_2|, |a_3|$인 직육면체를 그리면, 벡터의 크기는 원점에서 대각 꼭짓점까지의 대각선 길이와 같습니다. 이는 피타고라스 정리를 여러 번 적용해서 얻어지는 결과입니다.

벡터를 화살표로 나타낼 때, 화살표의 길이가 바로 벡터의 크기입니다. 따라서 크기가 크면 벡터가 멀리 뻗어 있다는 의미이며, 영벡터 $\vec{0} = (0, 0, 0)$만이 유일하게 크기가 0인 벡터입니다. 벡터의 크기를 구하는 것은 벡터가 나타내는 물리량의 "강도"를 수치로 측정하는 과정입니다.

### 한 줄 예

벡터 $\vec{a} = (3, 4)$의 크기는 $|\vec{a}| = \sqrt{3^2 + 4^2} = 5$입니다.
