# Figure Triage 시스템 — 설계 블루프린트 & 체크리스트

작성: 2026-06-24. 기출 문제 이미지(도형/그래프/3D)를 변형문제용으로 **재활용/재생성** 분류하고, 재생성 건은 타입별 파이프라인으로 라우팅하는 시스템.

## 0. 핵심 결정 (논의로 확정됨)

**의사결정 트리:**
```
figure 추출 → [트리아지]
  ⓪ 애초에 유효한 도형인가?
     · 아님(추출오류 — 본문 텍스트/잡음을 통째로 크롭. find_region region-bleed) → "삭제" : 제거 대상
  ① 이미지에 숫자/수식 박혀 있나? (변형 시 바뀌는 값)
     · 없음(글자라벨·추상도형만) → "재활용" : 원본 이미지 그대로. 안 그림.
     · 있음 → 재생성 필요 → ② 타입 분류
        · 2D 일반도형/그래프 → "2D 재생성" : 채점 루프(결정적 렌더 + 원본대비 적대적 검증)
        · 3D 그래픽         → "3D" : 사용자 확정 절차
```
- ★**삭제**는 *마킹만* 한다(안전). 실제 제거(frontmatter figures에서 빼고 PNG 삭제)는 삭제목록 검토 후 일괄 정리 단계로 분리 → solution-loss류 풋건·오삭제 방지. 근본은 extract_figures region-bleed 수정(별도).
- ★글자 라벨(A,B,M…)은 숫자/수식 아님. 디짓·`=`·√·첨자만 "있음"으로 판정.
- 예: #19(정사면체, A~Q 라벨만) = **재활용**. #28(y=√2x 등 박힘) = **2D 재생성 + 3D**.

**3D 파이프라인 (확정됨):**
1. 3D 씬 빌드(결정적, 수식→메시).
2. **채점 루프 = 3D *모델 자체*가 맞게 만들어졌나 QA** (각도 평가가 아님). 원본 대비:
   - 좌우반전/손지기(★핸드니스 버그), 점 위치(중점·비율), 곡선/영역의 사분면, 토폴로지(가시/은선), 라벨 정합.
   - 기준각도(교과서 맞춤)에서 1샷 렌더 ↔ 원본 비전 비교. 적대적 검증(기본=의심).
   - 통과 못 하면 모델 수정 후 재채점. → 사람한테 "모델 검증됨" 근거 제공.
3. **사람(어드민)이 표시 각도를 디폴트로 확정** (라벨 위치도). = 어드민 확정 각.
4. **확정 각 = 학생이 문제 열 때 보는 디폴트**로 락. 단 학생은 회전 가능(+"원래각도로" 버튼). 2D PNG 따로 안 굽고 **라이브 3D 임베드**.
5. 부산물: 락된 각에서 **결정적 정적 1샷** 자동(인쇄/PDF/WebGL없는기기/썸네일 폴백, 사람 손 0).

**각도 락 정책:** 학생 뷰 디폴트 = **어드민 확정 각**(학생 측 아님). 회전 허용 + 리셋.

**결정론 원칙:** 런타임에 LLM 0. 수식→메시→GPU 깊이버퍼(HLR)→렌더. 같은 입력=같은 그림. (이번 세션 #28에서 검증)

## 1. 데이터 모델

**트리아지 상태 = 별도 JSON 인덱스** `web/src/data/figure-triage.json` (프론트매터 아님 — 재인제스트가 덮어쓰는 풋건 회피). concept-figures.json 패턴.
```jsonc
{
  "schemaVersion": 1,
  "figures": {
    "<image_path>": {                  // 키 = /problem-images/XXXX_fig0.png
      "problem_slug": "2019_고3_10월모의고사_가형_19",
      "figure_index": 0,
      "status": "untriaged",           // untriaged | reuse | redraw-2d | redraw-3d | delete(추출오류)
      "suggested": "reuse",            // 자동제안(텍스트레이어/비전)
      "suggest_reason": "이미지에 숫자/수식 없음",
      "triaged_by": null,              // admin email
      "triaged_at": null,
      "notes": null,
      "render3d": null                 // 3D일 때: { template, camera{proj,world,aspect}, labels[], locked:true }
    }
  }
}
```
