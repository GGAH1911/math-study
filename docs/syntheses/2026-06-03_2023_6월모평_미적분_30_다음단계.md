## **STEP 2️⃣: 극값점과 변곡점에서 일어나는 현상**

좋습니다! 이제 **극값점과 변곡점에서 $g(t)$가 어떻게 불연속이 되는지** 설명하겠습니다.

---

### **🔍 극값점에서: 점프 불연속**

극값점은 **도함수가 0인 점** 즉, $f'(t) = 0$인 점입니다.

**극값점의 특징:**
- 그 점에서의 **접선이 수평** (기울기 = 0)
- 수평 접선은 곡선과 **한 번 이상 만남**

**그래프로 보기:** (임시로 $a=2$ 가정)

```plot
{
  "fns": [
    {"fn": "(x*x - 2*x)*exp(-x)", "label": "$f(x)$"},
    {"fn": "0.541 - 0*(x - 0.586)", "label": "극값점에서의 접선 ($t \\approx 0.59$)"}
  ],
  "range": [-0.5, 5],
  "title": "극값점: 접선이 곡선과 여러 번 만남"
}
```

**무슨 일이 일어나나:**
- $t$가 극값점 **왼쪽**에서 접근하면: 접선과 곡선의 교점 개수가 **1개** ($g(t) = 1$)
- $t$가 극값점 **정확히**에서: 접선과 곡선의 교점 개수가 **2개** ($g(t) = 2$) — 접점 자신이 중근!
- $t$가 극값점 **오른쪽**에서: 접선과 곡선의 교점 개수가 **2개 이상** ($g(t) \geq 2$)

**결과:** $\lim_{t \to \text{극값점}^-} g(t) \neq \lim_{t \to \text{극값점}^+} g(t)$  
→ **점프 불연속**이 생깁니다!

---

### **🔄 변곡점에서: 제거가능 불연속**

변곡점은 **2차 도함수가 0인 점** 즉, $f''(t) = 0$인 점입니다.

**변곡점의 특징:**
- 그 점에서 접선이 곡선을 **관통** (위에서 아래로, 또는 아래에서 위로 통과)
- 접점이 **삼중근**(triple root)이 됨

```plot
{
  "fns": [
    {"fn": "(x*x - 2*x)*exp(-x)", "label": "$f(x)$"},
    {"fn": "-0.108 + 0.355*(x - 1.268)", "label": "변곡점에서의 접선 ($t \\approx 1.27$)"}
  ],
  "range": [-0.5, 5],
  "title": "변곡점: 접선이 곡선을 관통"
}
```

**무슨 일이 일어나나:**
- $t$가 변곡점 근처에서 움직여도: 접선과 곡선의 교점 개수가 **변하지 않음**
- 변곡점에서만 잠깐 **교점이 1개 줄었다가 바로 회복**

**결과:** $\lim_{t \to \text{변곡점}^-} g(t) = \lim_{t \to \text{변곡점}^+} g(t)$  
→ **좌극한과 우극한이 같음** (제거가능 불연속)

---

### **📊 핵심 정리**

| 점의 종류 | 접선의 모양 | $g(t)$의 변화 | 불연속 종류 |
|---------|----------|-----------|----------|
| **극값점** | 수평 (기울기=0) | $1 \to 2$ 또는 $2 \to 3$ 점프 | **점프 불연속** |
| **변곡점** | 곡선 관통 | 좌극한 = 우극한 | **제거가능 불연속** |
| **그 외의 점** | 일반적인 접선 | $g(t)$ 연속 | 불연속 없음 |
