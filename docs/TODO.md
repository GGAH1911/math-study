**실측** (2026 고3 5월, 20페이지·46문항):

| 문항 | 페이지 | 디코드 |

페이지 번호에 정비례한다. 한 회차면 46회 × 평균 10페이지 ≈ **460페이지분을 파싱**하는데
실제로는 20페이지면 된다 — **23배 낭비**.

**왜 이제 드러났나**: `decode_problem` 은 **문항 단위 API** 다. 인제스트 본류는 문항을
하나씩 처리하니 자연스러운 설계였고 비용이 안 보였다. `decode_snapshot.py`(전수 재디코드)
라는 새 용법에서만 드러났다 — 전수 스냅샷 1회에 **40분**이 걸린다.

**고치는 법**: `(pdf_path, page_num) → (chars, bars)` 페이지 캐시. 20~30배 개선 예상
(40분 → 2분). 주의점 둘:
- 캐시는 메모리를 먹는다(페이지당 수천 개 pdfminer 객체) → **전수 스캔에선 회차마다 비운다**
- 캐시 키에 파일 mtime 을 넣어야 재크롭·재인제스트로 PDF 가 바뀐 경우를 잡는다

**언제 값어치가 나오나**: 파서를 고칠 때마다 스냅샷을 2회(전·후) 떠야 한다. 다음 파서
작업(밑수 분해·첨자 소실) 때 바로 회수된다.

⚠️ **파서 수정과 같은 커밋에 넣지 마라.** 스냅샷 전후를 다른 코드로 뜨면 diff 가 무의미해진다.

## 배점 불일치 103건 — 원인 미조사 (2026-08-14 등록)

**무엇**: frontmatter `source.score` 와 본문 `[N점]` 이 다르다. **103 / 4,210 (2.4%)**.
예) `2026_고3_7월모의고사_공통_09` 는 `score: 3` 인데 본문은 `[4점]`.

**어떻게 찾았나**: 난이도 미할당 조사 중 부수적으로 발견. 아직 **원인은 안 봤다.**

| 회차 | 건수 |
|---|---|
| 2019/고3_3월모의고사 | 11 |
| 2026/고3_7월모의고사 | 10 |
| 2019/고3_10월모의고사 | 10 |
| 2019/고3_4월모의고사 | 9 |
| 2020/고3_10월모의고사 | 8 |

2019~2020 교육청 회차에 몰려 있다 — **PDF 배점 파싱 쪽**을 먼저 의심할 만하다.
본문 `[N점]` 은 원본 그대로라 신뢰도가 높고, `score` 가 틀렸을 가능성이 크다.

**왜 방치하면 안 되나**: `score` 는 `exam-build.ts` 의 난이도 조합과 채점에 쓰인다.
틀린 배점으로 조합한 모의시험은 난이도가 어긋나고, 채점 총점도 틀린다.

**재현**:
```bash
python3 - <<'EOF'
import re, pathlib
for p in pathlib.Path("docs/problems").rglob("*.md"):
    t = p.read_text(encoding="utf-8")
    sc, pts = re.search(r"^  score: (\d+)$", t, re.M), re.search(r"\[(\d)점\]", t)
    if sc and pts and sc.group(1) != pts.group(1): print(p)
EOF
```

⚠️ **일괄 치환 금지.** 본문 `[N점]` 이 항상 옳다는 보장을 아직 못 세웠다(재구성 텍스트에
배점이 섞여 들어간 사례가 있을 수 있다). 표본을 원본 PDF와 대조해 **어느 쪽이 정본인지
먼저 판정**하고 나서 고친다. `docs/ops/SHUTDOWN.md` 의 "파일을 고치는 코드는 쓰기 전에
검사한다" 사고 이력 참조.

**평시는 소넷이다.** 구독이라 **한계비용 0** 이고, 실측 통과율도 나쁘지 않다(4/4 표본).

  **유도**하게 바꿔 결합을 끊었다. 유도한 보기가 원문제 보기와 같음을 assert 로 고정.
- **공통_22** — 원의 반지름이 자유 파라미터였는데 설계 불변식이 **R² = sx² + sy²** 라
  sx·sy 만 흔들면 교점이 사라지고 `solve` 가 **조용히 None** 을 돌려줬다. 반지름을
  유도값으로 묶고, 해가 없으면 예외를 던지게 했다. 자연수 조건 때문에 파라미터가 서로
  묶여 한 개씩은 못 흔드는 문제라 `VARIANTS` 로 성립하는 조합 5개를 제시한다(답 53·14·31·8·9).
