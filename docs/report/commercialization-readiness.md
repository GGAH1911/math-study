## 4. 주요 리스크 (기출 저작권 중심)

### 기출 저작권 — 가장 근본적이고 회피가 어려운 리스크
- **법적 근거가 명확하다.** 수능/모평은 공공누리 제4유형(출처표시+**상업이용금지+변경금지**)이며, 저작권법 §24조의2 4호 단서로 평가원이 권리 행사 가능. 학평(전체 71%)은 더 엄격해 "허락 없는 복제·배포·출판 일체 금지"를 공식 명시.
- **판례·집행 이력이 실재한다.** 대법원 2024(한국문학예술저작권협회 v. 평가원, 사용료 1,000만원 확정)는 **공익·비영리라도 시험목적 범위를 넘는 장기 무료 공개를 침해**로 봤다. EBS는 교재 무단사용 강사 벌금 300만원·무단인용 2.18억 배상 등 적극 소송 전례.
- **현재 코드가 침해를 키운다.** `middleware.ts:58`이 `/problem-images/`를 인증 우회 → 로그인 없이 URL만으로 원본 PNG 5,895개 취득 가능. "개인 학습용 비공개" 항변을 코드가 스스로 무력화.
- **수익화 형태와 무관하다.** 광고·구독·앱스토어 어떤 수익화도 "상업적 이용"으로 재분류되어 제4유형·학평 금지조항 위반. **비즈니스 모델 선택지 자체가 IP에 의해 원천 제약됨.**
- **파생물도 막힌다.** LLM 풀이·변형문제·전사 텍스트 = 2차적저작물 → "변경금지"에 저촉. 솔루션 캐시 2,584건·재구성 전부 해당.

**회피책(현실적 순서):**
1. **즉시(법적 노출 축소):** `/problem-images/` 게이팅 복원, robots.txt+noindex, 모든 문제에 출처표시 강제 → "비공개 개인 학습 도구"로 포지션을 코드로 뒷받침.
2. **콘텐츠 전략 전환:** 상용 트랙은 자체 자산(개념노트 1,216·도식 908·위젯 80)을 핵심으로. 기출은 (a)자작 변형문항 대체 또는 (b)EBSi/교육청 공식 링크 외부연결(임베드 금지).
3. **라이선스 타진:** 평가원·EBS·대표 교육청에 이용허락 가능성·조건 공식 문의. **허락 불가 영역(특히 학평)은 사업계획에서 선제 제외 결정.**
4. **수익화 분리:** 기출 과금이 아니라 "자체 개념·튜터·필기평가" 부가가치 과금으로 설계 → 상업이용 판정 리스크를 기출에서 떼어냄.

### 기타 주요 리스크
- **SPOF가 노트북 한 대:** 웹·DB·LLM·크론 전부 동일 머신. 절전·재부팅·네트워크 단절 = 전 서비스 중단. DB 백업 부재 → 볼륨 손상 시 계정·진도·대화 전량 영구 소실.
- **개인 구독 토큰 만료/한도:** credentials.json accessToken 만료·리프레시 실패 시 튜터·크론 전부 조용히 401 사망. 헬스체크·알림 없음.
- **빌드 미검증:** dist 50커밋 stale → 막상 `astro build` 시 membership 스키마·remark·3D 의존성에서 회귀 잠복 가능.

## 7. 비용 모델 주의 (★ 착시 경고)

**현재 "무료"는 착시다.** LLM이 토큰당 과금이 아니라 **개인 구독 한도(5시간/주간)를 소모**하는 구조라 비용이 0으로 보일 뿐, API 전환 시 실제 달러 비용이 발생한다.

| 항목 | 현재(구독) | API 전환 후 |
|---|---|---|
| 튜터 호출 | 구독 한도 소모(무료 착시) | input/output/cache 토큰 실과금 |
| 위젯 크론 | Opus 최대 80건/일 ×3재시도 = ~240콜/일 "무료" | **Opus 토큰비가 일일 운영비 주요 항목** |
| 캐싱 효과 | rate-limit 한도 절약 | cache_control을 prefix에 명시해야 입력비 절감 |

**주의사항:**
- **단위경제를 먼저 검증하라.** 사용자당 월 토큰 소비를 실측 → 가격(예 9,900~18,500원) 대비 마진 시뮬. 무한 사용량 막을 일/월 메시지 쿼터를 chat.ts에 도입.
- **모델 티어 과금 게이팅:** haiku 기본 무료·opus는 유료/admin 등급만. 현재 서버는 opus 허용(POST로 우회 가능) → 권한 교차검증 필수.
- **Opus 위젯 크론 재검토:** API 전환 후 일일 Opus 비용 실측, Batch API(50% 할인)·sonnet 다운그레이드 분리.
- **캐싱 재구현:** CLI 내장 base 캐싱에 의존 말고 system prompt prefix에 `cache_control:ephemeral` 직접 박아야 문서 추정만큼 절감됨.

---

**결론:** 콘텐츠와 인증은 자산이다. 그러나 **저작권(IP)이 사업 모델 자체를 막는 1순위 차단요소**이고, 그 다음이 LLM 자가호스팅 구조다. 이 둘을 풀기 전 인프라·결제에 투자하는 것은 순서가 틀리다. 권장 경로는 **① 저작권 법무 검토로 콘텐츠 전략을 먼저 확정 → ② 확정 후에만 API 전환·인프라·결제 착수 → ③ 결제 없는 클로즈드 베타로 단위경제·리텐션 검증 → ④ 유료화**다.
