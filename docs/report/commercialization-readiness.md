## 1. 한 줄 평결

**조건부 가능 — 출시 경로는 열려 있고, 남은 건 전부 엔지니어링이다.**
~~기출 저작권~~은 차단요소에서 **제외**한다(§4): 평가원·교육청 기출의 상업적 재현은 한국 시장에서 자이스토리·마더텅·EBS 등으로 이미 보편화돼 있고 분쟁 전례가 사실상 없다(원 보고서가 인용한 대법원 2024 판례는 *시험에 인용된 제3자 저작물* 건이지 *기출 자체 재출판*이 아니므로 오적용). 따라서 **남은 차단요소는 모두 buildable**: (1) LLM 튜터가 개인 Claude 구독을 매 요청 spawn하는 자가호스팅 → API 직결, (2) 프로덕션 인프라·결제·보안 마감 전무. 법적 벽이 없어 방향은 명확하고, 출시 가부는 *이 엔지니어링을 얼마나 빨리 끝내느냐*의 문제다.

## 4. 주요 리스크

### 기출 저작권 — 차단요소에서 제외 (사장님 판단 / 시장 관행)
평가원·교육청 **기출의 상업적 재현은 한국 시장에서 이미 보편화**돼 있다(자이스토리·마더텅·EBS 등 다수 상업 출판물). 법적 분쟁으로 비화한 전례가 사실상 없고, 원 조사가 인용한 대법원 2024(평가원 사용료) 판례는 *시험에 인용된 제3자 저작물*에 대한 것이지 *기출 문항 자체의 재출판*이 아니므로 본 건에 오적용이었다. → **출시 차단요소에서 제외.**

남는 것은 '차단'이 아니라 위생 수준의 두 가지:
- **콘텐츠 출처 한정**: 상용 트랙은 *공식 기출(평가원·교육청)* 만 사용. EBS 교재·사설 모의고사처럼 **명백한 사권(私權) 콘텐츠는 배제**(EBS는 교재 무단사용에 적극 소송 전례 — 기출과는 별개 사안).
- **PNG 게이팅 = 저작권이 아니라 유료화·자산보호**: `/problem-images/`가 무인증 공개라 비로그인 URL 취득이 가능(middleware.ts:58). 콘텐츠를 유료화하려면 어차피 로그인 뒤로 게이팅해야 하는 사안.

### 기타 주요 리스크
- **SPOF가 노트북 한 대:** 웹·DB·LLM·크론 전부 동일 머신. 절전·재부팅·네트워크 단절 = 전 서비스 중단. DB 백업 부재 → 볼륨 손상 시 계정·진도·대화 전량 영구 소실.
- **개인 구독 토큰 만료/한도:** credentials.json accessToken 만료·리프레시 실패 시 튜터·크론 전부 조용히 401 사망. 헬스체크·알림 없음.
- **빌드 미검증:** dist 50커밋 stale → 막상 `astro build` 시 membership 스키마·remark·3D 의존성에서 회귀 잠복 가능.

## 7. 비용 모델 주의 (★ 착시 경고)

**현재 "무료"는 착시다.** LLM이 토큰당 과금이 아니라 **개인 구독 한도(5시간/주간)를 소모**하는 구조라 비용이 0으로 보일 뿐, API 전환 시 실제 달러 비용이 발생한다.

| 항목 | 현재(구독) | API 전환 후 |
|---|---|---|
| 튜터 호출 | 구독 한도 소모(무료 착시) | input/output/cache 토큰 실과금 |
| 위젯 크론 | Opus 최대 80건/일 ×3재시도 = ~240콜/일 "무료" | **Opus 토큰비가 일일 운영비 주요 항목** |
| 캐싱 효과 | rate-limit 한도 절약 | cache_control을 prefix에 명시해야 입력비 절감 |

**주의사항:**
- **단위경제를 먼저 검증하라.** 사용자당 월 토큰 소비를 실측 → 가격(예 9,900~18,500원) 대비 마진 시뮬. 무한 사용량 막을 일/월 메시지 쿼터를 chat.ts에 도입.
- **모델 티어 과금 게이팅:** haiku 기본 무료·opus는 유료/admin 등급만. 현재 서버는 opus 허용(POST로 우회 가능) → 권한 교차검증 필수.
- **Opus 위젯 크론 재검토:** API 전환 후 일일 Opus 비용 실측, Batch API(50% 할인)·sonnet 다운그레이드 분리.
- **캐싱 재구현:** CLI 내장 base 캐싱에 의존 말고 system prompt prefix에 `cache_control:ephemeral` 직접 박아야 문서 추정만큼 절감됨.

---

**결론(저작권 제외 후 갱신):** 콘텐츠와 인증은 자산이고, 법적 벽이 없으므로 경로는 명확하다. 1순위 차단은 **LLM 튜터 자가호스팅(개인 구독 → API 직결)**, 그 다음이 프로덕션 인프라·결제다. 권장 경로는 **① LLM API 전환 + per-user 쿼터/메터링 → ② 프로덕션 호스팅·결제·보안 마감 → ③ 결제 없는 클로즈드 베타로 단위경제·리텐션 검증 → ④ 유료화**다. 단위경제(사용자당 월 LLM 토큰 vs 가격)가 사실상 유일한 사업적 미지수다.
