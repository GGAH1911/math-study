## 🔬 실사용 테스트 필요 (★중요 — 아이패드+애플펜슬로 확인)

저는 헤드리스 환경이라 **펜 입력을 직접 못 테스트**합니다(타입체크·마운트 렌더만 가능). 아래는 **코드는 맞는데 실기기 확인이 필요한** 것들이며, 위험도 순입니다.

### ★★ 최우선 — A3 갈무리(올가미 선택) — *완전히 새 인터랙션, 미검증*
`⬚ 선택` 도구를 켜고:
1. **올가미**: 획 몇 개 주변을 둘러 그리기 → 점선 박스로 선택되나? (과반이 올가미 안에 든 획이 선택됨)
2. **이동**: 선택 박스 *안*을 드래그 → 선택한 획이 따라 움직이나?
3. **복제**: `복제` → 살짝 옆에 복사본 + 그게 선택되나?
4. **색**: 색 고르고 `🎨 색` → 선택한 펜 획 색이 바뀌나?
5. **레이어 이동**: 레이어 2개 이상일 때 `레이어→` 드롭다운 → 선택이 다른 레이어로 가나?
6. **삭제 / 해제**: 동작 확인
7. **undo(↶)**: 위 각 동작이 되돌려지나? (이동·복제·색·삭제·레이어이동 전부)
- 잘 안 되는 항목이 있으면 **어떤 동작이 어떻게 틀린지** 적어주세요.

### ★ 지우개 영역 표시 + 크기 (이번에 추가)
- `지우개` 선택 → 펜 대면 **점선 원(지울 영역)** 이 펜 따라 표시되나?
- `소/중/대`(○ 3버튼) → 원 크기 + 실제 지워지는 범위가 같이 바뀌나?
- 애플펜슬 **호버**(화면 안 닿고 가까이) 시 원이 미리 보이나? (M2+ iPad만 호버 지원 — 안 되면 정상)

### 이미 실기기 확인됨(되는 것)
- 기본 펜 그리기, 빠른 연속 획(짝수 획 누락 해결), 콜아웃 안 뜸, 레이어 — 모두 2026-06-27 "작동한다" 확인.
