### ★★ 최우선 — A3 갈무리(올가미 선택) — *완전히 새 인터랙션, 미검증*
`⬚ 선택` 도구를 켜고:
1. **올가미**: 획 몇 개 주변을 둘러 그리기 → 점선 박스로 선택되나? (과반이 올가미 안에 든 획이 선택됨)
2. **이동**: 선택 박스 *안*을 드래그 → 선택한 획이 따라 움직이나?
3. **복제**: `복제` → 살짝 옆에 복사본 + 그게 선택되나?
4. **색**: 색 고르고 `🎨 색` → 선택한 펜 획 색이 바뀌나?
5. **레이어 이동**: 레이어 2개 이상일 때 `레이어→` 드롭다운 → 선택이 다른 레이어로 가나?
6. **삭제 / 해제**: 동작 확인
7. **undo(↶)**: 위 각 동작이 되돌려지나? (이동·복제·색·삭제·레이어이동 전부)
- 잘 안 되는 항목이 있으면 **어떤 동작이 어떻게 틀린지** 적어주세요.
