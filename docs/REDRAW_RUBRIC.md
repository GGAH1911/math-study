# Redraw 그래픽 채점기준 (rubric)

기출 redraw-2d 도형을 function-plot(`web/src/components/RedrawPlot.tsx`)으로 재현할 때의 **측정·채점 기준**.
측정 서브에이전트와 검증 서브에이전트는 이 문서를 ground truth 로 따른다.

## ★대원칙: 본문이 ground truth (이미지는 레이아웃만)

도형은 **이미지를 따라 그리는 게 아니라 문제 본문(`searchable_text`)의 식·조건·값을 ground truth 로** 그린다.

- 본문에 곡선식(`y=log₂4x` 등)·조건(교점·길이·기울기·평행이동)·값이 주어지면 **그대로 사용** — 이미지에서 모양만 보고 추정하지 마라.
- 이미지는 **레이아웃·배치·어느 곡선이 어느 것인지·정성적 모양(증가/감소·볼록)·음영영역**만 참조. 이미지는 양식화·부정확할 수 있다.
- 본문과 이미지가 충돌하면 **본문 우선**. (이미지 곡선이 `x²`처럼 보여도 본문이 `x³`이면 `x³` 을 그린다.)
- 점 좌표는 이미지에서 픽셀로 찍지 말고 **본문 조건으로 유도**한다(교점=식 연립, 길이/기울기=계산). 이미지 픽셀은 검산·레이아웃 확인용.

## 측정(measure) 절차

1. **본문 추출**: 곡선식·조건·주어진 값·점의 정의를 본문에서 뽑는다(= 수학적 ground truth).
2. **이미지 레이아웃**: 원점·축 방향·정의역(곡선이 그려진 x 범위)·곡선 배치·음영영역·라벨 위치를 이미지에서 본다.
3. **점 좌표 유도**: 본문 조건으로 계산(교점은 두 식 연립, 평행이동/대칭 등 변환 적용). 이미지로 검산.
4. **RedrawPlot spec 산출**: `curves`=본문 식, `points`=유도 좌표, `regions`=음영(곡선변은 식으로 점샘플), `lines`(직선/세로선/연장선), `texts`(곡선식·축 라벨).

## 채점 항목 (각 0~5, **원본 이미지 + 본문** 대비)

| # | 항목 | 기준 |
|---|---|---|
| ① | **본문 정합성** (최우선) | 곡선식·조건·값·점 정의가 본문과 일치하는가. 본문 식과 다른 곡선/임의 곡선/이미지만 보고 추정한 식 = **중대 결함** |
| ② | 도형 종류 | 함수그래프/기하 유형 일치 |
| ③ | 구조·구성 | 곡선·점·축·선·음영의 구성이 원본과 같은가 |
| ④ | 점 위치 | 본문 조건으로 유도된 점이 정확한가(이미지 눈대중 아님) |
| ⑤ | 곡선·직선 형태 | 곡선 방향·폭·정의역, 직선/세로선/연장선 |
| ⑥ | 음영 | 음영영역 위치·경계(곡선변 포함)·맞는 영역인가 |
| ⑦ | 라벨 | 점·곡선식·축 라벨 텍스트·위치 |
| ⑧ | 표기 청결도 | 축 화살표·필요한 눈금만·군더더기(불필요 눈금/박스) 없음 |

**verdict 규칙**: 본문 정합성(①)이 3 미만이면 다른 점수와 무관하게 **fix**(식이 틀리면 그림 자체가 무의미). 검증관은 본문(searchable_text)을 받아 ①을 반드시 확인한다 — 이미지끼리만 비교하지 마라.
