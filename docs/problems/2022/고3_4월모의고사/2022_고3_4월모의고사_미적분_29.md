    - "**$\\overline{AB}$ 계산.** $AB = p\\sqrt{1+m_1^2} = 12$ … (1)"
    - "**C(=$l_2 \\cap l_3$) 계산.** $l_2$: $y = m_2 x + m_2 p + b$. 연립하면 $x_C = \\dfrac{p(m_1-m_2)}{m_1+m_2}$, $y_C = \\dfrac{2m_1 m_2 p}{m_1+m_2}+b$. 따라서 $AC = \\dfrac{2m_1 p}{m_1+m_2}\\sqrt{1+m_2^2} = 9$ … (2)"
    - "**외접원 반지름.** $\\angle A$는 $l_1, l_2$ 사이 각: $\\sin A = \\dfrac{m_2-m_1}{\\sqrt{(1+m_1^2)(1+m_2^2)}}$. 사인 법칙 $R = \\dfrac{BC}{2\\sin A}$와 $BC = \\dfrac{p(m_2-m_1)}{m_1+m_2}\\sqrt{1+m_1^2}$를 대입하면 $R = \\dfrac{p(1+m_1^2)\\sqrt{1+m_2^2}}{2(m_1+m_2)} = \\dfrac{15}{2}$ … (3)"

(3') ÷ (2'): $\\dfrac{1+m_1^2}{m_1} = \\dfrac{10}{3}$ → $3m_1^2 - 10m_1 + 3 = 0$ → $(3m_1-1)(m_1-3)=0$. $0<m_1<1$이므로 $m_1 = \\dfrac{1}{3}$."
