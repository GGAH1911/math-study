  solution_steps:
  - 등차수열이므로 $S_n=\dfrac{n(a_1+a_n)}{2}$ 입니다.
  - $n=2k-1$ 일 때 $b_{2k-1}=2\left\{\dfrac{(2k-1)(a_1+a_{2k-1})}{2}-(2k-1)a_{2k-1}\right\}=(2k-1)(a_1-a_{2k-1})$ 이므로 (가) 는 $2k-1$ 입니다.
  - $n=2k$ 일 때 $b_{2k}=(2k-1)a_{2k}$ 입니다.
  - 둘을 더하면 $(2k-1)\{a_1-a_{2k-1}+a_{2k}\}=(2k-1)(a_1+d)=(2k-1)a_2$ 이고, $b_2=a_2=2$ 이므로 (나) 는 $4k-2$ 입니다.
  - $\sum_{n=1}^{20}b_n=\sum_{k=1}^{10}(4k-2)=4\times 55-20=200$ 이므로 (다) 는 $200$ 입니다.
  - $f(2)+g(3)+p=3+10+200=213$ 입니다.
