  다음 조건을 만족시키는 경우의 수는? (단, 같은 색 공끼리는 서로 구별하지 않고, 공이 들어 있지 않은 상자가 있을 수 있다.) [4점]

  - 검은 공의 분배 $(b_1,\dots,b_4)$ 는 합이 $4$, 흰 공 $(w_1,\dots,w_4)$ 는 합이 $6$ 인 음이 아닌 정수해입니다.

  - 조건 (나) 는 $b_i\ge 1$ 인 상자마다 $w_i\le 1$ 이라는 뜻입니다.
