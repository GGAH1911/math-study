  - 두 수의 차가 $2$ 의 배수라는 것은 두 수의 홀짝이 같다는 뜻입니다.
  - 홀수는 $1,3,5,7$ 의 $4$ 개, 짝수는 $2,4,6$ 의 $3$ 개입니다.
  - 경우의 수는 $\binom42+\binom32=6+3=9$ 입니다.
  - 전체는 $\binom72=21$ 이므로 확률은 $\dfrac{9}{21}=\dfrac37$ (보기 ①) 입니다.
