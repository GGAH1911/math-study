    - "$|f(-2)|=|f(2)|=a$이고 $f$가 일차함수이므로, $f(x)=\\frac{a}{2}x$ 또는 $f(x)=-\\frac{a}{2}x$ ($q=0$ 도출). 두 경우 모두 $|f(x)|=\\frac{a}{2}|x|$로 동일."
    - "$g'(x)=\\frac{a}{2}(x^2-4)(|x|-2)$. $x>0$이면 $\\frac{a}{2}(x-2)^2(x+2)\\ge0$, $x<0$이면 $-\\frac{a}{2}(x-2)(x+2)^2\\ge0$ → $g'\\ge0$ 항상 성립. 극값 없음 확인."
    - "조건 (나): $g(2)=\\int_0^2 (t^2-4)\\cdot\\frac{a}{2}(t-2)\\,dt = \\frac{a}{2}\\int_0^2(t-2)^2(t+2)\\,dt$. $u=t-2$ 치환 후 $\\int_{-2}^0 u^2(u+4)\\,du=\\frac{20}{3}$. 따라서 $g(2)=\\frac{a}{2}\\cdot\\frac{20}{3}=\\frac{10a}{3}=5$ $\\Rightarrow a=\\frac{3}{2}$."
    - "$g(0)=0$. $g(-4)=\\int_0^{-4}(t^2-4)\\{|f(t)|-a\\}\\,dt=-\\int_{-4}^0(t^2-4)\\cdot(-\\tfrac{3}{4})(t+2)\\,dt=\\frac{3}{4}\\int_{-4}^0(t-2)(t+2)^2\\,dt$."
    - "$u=t+2$ 치환: $\\int_{-2}^{2}(u-4)u^2\\,du=\\int_{-2}^2(u^3-4u^2)\\,du=0-4\\cdot\\frac{16}{3}=-\\frac{64}{3}$."
