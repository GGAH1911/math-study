# [2025 수능 확률과통계 29번] 4점

> 출처: 평가원 2025학년도 수능 11월 본수능 수학영역 · 단원: 통계
> Tier: killer · cognitive: 추론 · 예상 시간 600초
> **정규분포의 대칭성 조건과 확률변수 관계식으로부터 모수를 역으로 구하고 표를 활용해 계산**

## 문제

정규분포 $N(m_1,\, \sigma_1^2)$을 따르는 확률변수 $X$와 정규분포 $N(m_2,\, \sigma_2^2)$을 따르는 확률변수 $Y$가 다음 조건을 만족시킨다.

모든 실수 $z$에 대하여

$$P(X \le z) = P(X \ge 40 - z) \text{ 이고,}$$

$$P(Y \le z) = P(X \ge z + 10) \text{ 이다.}$$

$P(15 \le X \le 20) + P(15 \le Y \le 20)$의 값을 오른쪽 표준정규분포표를 이용하여 구한 것이 $0.4772$일 때, $m_1 + \sigma_2$의 값을 구하시오.  
(단, $\sigma_1$과 $\sigma_2$는 양수이다.) [4점]

| $z$ | $P(0 \le Z \le z)$ |
|-----|-------------------|
| 0.5 | 0.1915 |
| 1.0 | 0.3413 |
| 1.5 | 0.4332 |
| 2.0 | 0.4772 |
