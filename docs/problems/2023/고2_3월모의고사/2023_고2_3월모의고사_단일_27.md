    - "4종류 인형(A, B, C, D)이 각 2개씩. 각 종류에서 선택하는 수를 $a_i$ ($i=1,2,3,4$)라 하면 $0 \\le a_i \\le 2$, $a_1+a_2+a_3+a_4=5$인 경우의 수를 구한다."

    - "합계: $12 + 4 = \\boxed{16}$"
