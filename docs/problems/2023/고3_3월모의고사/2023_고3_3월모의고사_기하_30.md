    - "$A=(c,\\,b^2/a)$, $B=(-c,\\,b^2/a)$, $F=(c,0)$으로 설정. 쌍곡선(초점 $A,B$)이 $x=c$에서 $F$ 이외로 만나는 점 $P=(c,\\,2b^2/a)$ (A에 대해 F와 대칭)."
    - "조건 (가): $BF=FP$ (정삼각형) $\\Rightarrow 4c^2=3b^4/a^2$. $c^2=a^2-b^2$, $t=b^2/a^2$ 대입 $\\Rightarrow 3t^2+4t-4=0 \\Rightarrow t=2/3$. 따라서 $b^2=2a^2/3$, $c=a/\\sqrt{3}$."
    - "$a=3$ 정규화: 쌍곡선 $x^2-(y-2)^2/2=1$. 직선 $BF$, $BP$와의 교점(음수 $x$)을 연립 풀이: $Q=(-3\\sqrt{3}/5,\\,8/5)$, $R=(-3\\sqrt{3}/5,\\,12/5)$."
    - "삼각형 $BQR$: $BQ=BR=QR=4/5$ (정삼각형). 일반 $a$ 스케일로 복원하면 둘레 $=4a/5$."
    - "조건 (나): $2a - 4a/5 = 3 \\Rightarrow 6a/5=3 \\Rightarrow a=5/2$."
    - "$AF = b^2/a = 2a/3 = 5/3$. $\\therefore 60\\times AF = 60\\times\\frac{5}{3} = 100$."
