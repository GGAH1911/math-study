        ## 문제

        두 양수 $a\ (1 \le a \le 2)$, $b$에 대하여 함수

$$f(x) = \sin(ax + b\sin x)$$

가 다음을 만족시킨다.

> (가) $f(0) = 0$, $\ f(2\pi) = 2\pi a + b$
>
> (나) $f'(0) = f'(t)$인 양수 $t$의 최솟값은 $4\pi$이다.

함수 $f(x)$가 $x = \alpha$에서 극댓값을 갖는 모든 $\alpha$의 값들로 이루어진 집합을 $A$라 하자. 집합 $A$의 원소 중 열린 구간 $(0,\, 4\pi)$에 속하는 것들의 집합을 $A$라 할 때, 집합 $A$의 원소의 개수를 $n$, 집합 $A$의 원소 중 가장 작은 값을 $\alpha_1$이라 하면,

$$n\alpha_1 - ab = \frac{p}{q}$$

이다. $p + q$의 값을 구하시오.

$($단, $p$와 $q$는 서로소인 자연수이다.$)$
