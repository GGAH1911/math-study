    - "전구 $k$는 시행 $i$에서 주사위 눈 $x_i \\geq k$일 때 눌림. $f(k) = |\\{i : x_i \\geq k\\}|$를 정의하면, 전구 $k$가 켜지려면 $f(k)$가 홀수여야 함."
    - "$f(1) = 5$ (주사위는 항상 $\\geq 1$) → 자동으로 홀수 ✓. 따라서 $f(2), f(3), f(4), f(5), f(6)$ 모두 홀수 조건 필요."
    - "$n_k = |\\{i : x_i = k\\}|$로 놓으면 $f(k) - f(k+1) = n_k$. $f(6) = n_6$이 홀수 → $n_6$ **홀수**. $n_5 = f(5)-f(6) = \\text{홀수}-\\text{홀수}$ → $n_5$ **짝수**. 같은 방식으로 $n_4, n_3, n_2, n_1$ 모두 **짝수**."
    - "조건 정리: $n_1+\\cdots+n_6=5$, $n_1,\\ldots,n_5$ 짝수, $n_6$ 홀수 ($n_6 \\in \\{1,3,5\\}$)."
    - "**$n_6=5$**: $(0,0,0,0,0,5)$만 가능. 순서쌍 수 $\\frac{5!}{5!}=1$."
    - "**$n_6=3$**: $n_1+\\cdots+n_5=2$ (모두 짝수) → 정확히 하나의 $n_j=2$, 나머지 0. 5가지 선택, 각 $\\frac{5!}{2!\\cdot 3!}=10$개 → $5 \\times 10 = 50$."
