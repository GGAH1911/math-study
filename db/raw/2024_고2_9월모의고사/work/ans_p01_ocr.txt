\[2^{-1} \times 8^{\frac{5}{3}} = 2^{-1} \times (2^{3})^{\frac{5}{3}} = 2^{-1} \times 2^{5} = 2^{4} = 16\]


2. [출제의도] 함수의 극한 계산하기 


\[\begin{align*}
\lim_{x \to \infty} \frac{(2x+1)^2}{x^2 + 4x + 5} &= \lim_{x \to \infty} \frac{4x^2 + 4x + 1}{x^2 + 4x + 5} \\
&= \lim_{x \to \infty} \frac{4 + \frac{4}{x} + \frac{1}{x^2}}{1 + \frac{4}{x} + \frac{5}{x^2}} = 4
\end{align*}\]


3. [출제의도] 등차수열 계산하기 


등차수열 {a_n}의 공차를 d라 하면 


\[a_7 - a_5 = (a_1 + 6d) - (a_1 + 4d) = 2d = 6, d = 3\]


\[a_4 = a_1 + 3d = a_1 + 9 = 10\]


따라서 a₁ = 1

5. [출제의도] 함수의 극한 이해하기 


\[\lim_{x \to -1^-} f(x) = -1, \quad \lim_{x \to -1^+} f(x) = -1 \text{이므로}\]


\[\lim_{x \to -1^-} f(x) = -1\]


\[\lim_{x \to -1^+} f(x) = 2\]


\[\lim_{x \to -1^-} f(x) + \lim_{x \to -1^+} f(x) = -1 + 2 = 1\]


6. [출제의도] 로그 계산하기 


\[\log_2 5 \times \log_3 3 + \log_2 \frac{16}{3}\]


\[= \log_2 5 \times \frac{\log_2 3}{\log_2 5} + \log_2 \frac{16}{3} = \log_2 3 + \log_2 \frac{16}{3}\]


\[= \log_2 \left(3 \times \frac{16}{3}\right) = \log_2 16 = \log_2 2^4 = 4\]


7. [출제의도] 일반과로도법 이해하기 


부채의 반지름의 길이를 r, 


중심각의 크기를 θ 라 하자. 


\[\theta = \frac{\pi}{4} \text{이므로 부채의 길이는}\]


\[\frac{1}{2} r^2 \theta = \frac{1}{2} r^2 \times \frac{\pi}{4} = 18\pi, r = 12\]


따라서 부채의의 초의 길이는 


\[r\theta = 12 \times \frac{\pi}{4} = 3\pi\]


8. [출제의도] 삼각함수가 포함된 방정식 이해하기 


\[\sin^2 x + \cos^2 x = 1 \text{이므로}\]


\[\cos^2 x - 1 = 2 \sin x \text{에서}\]


\[(1 - \sin^2 x) - 1 = 2 \sin x\]


\[\sin^2 x + 2 \sin x = 0, \sin x (\sin x + 2) = 0\]


\[-1 \leq \sin x \leq 1 \text{이므로} \sin x = 0\]


\[0 < x \leq 2\pi \text{에서} x = \pi \text{또는} x = 2\pi\]


따라서 모든 해의 합은 3π

10. [출제의도] 동비수열의 합 이해하기 


동비수열 {a_n}의 첫째항을 a, 


공비를 r (r > 0) 이라 하자. 


(i) r = 1 인 경우 


\[a_2 = a_1 r = a_1\]


\[S_6 = 6a = 12\]


\[S_3 = 3a = 6\]


\[S_6 \neq 9S_3\]


(ii) r ≠ 1 인 경우 


\[S_6 = 9S_3, \frac{a(r^6 - 1)}{r - 1} = 9 \times \frac{a(r^3 - 1)}{r - 1}\]


\[(r^3 + 1)(r^3 - 1) = 9(r^3 - 1)\]


\[r^3 + 1 = 9, r^3 = 8, r = 2\]


따라서 a_4 = a_2 × r^2 = 2 × 2^2 = 8

12. [출제의도] 삼각함수를 활용하여 문제 해결하기 


 


점 A(3, -2)는 함수 f(x) = a tan(\(\frac{\pi}{4}\)x)의 그래프 위의 점이므로 


\[f(3) = a \tan \frac{3}{4} \pi = -a = -2, a = 2\]


점 A(3, -2)를 x축의 방향으로 6 만큼, y축의 방향으로 b 만큼 평행이동한 


\[\text{점 A'(9, -2 + b)는 함수 } f(x) = 2 \tan \frac{\pi}{4} x \text{의 그래프 위의 점이므로}\]


\[f(9) = 2 \tan \frac{9}{4} \pi = 2 \tan \left(2\pi + \frac{\pi}{4}\right)\]

따라서 a + b = 2 + 4 = 6 


13. [출제의도] 동비수열 이해하기 


동비수열 {a_n}의 첫째항을 a (a < 0), 


공비를 r (r ≠ 0) 이라 하자. 


\[a_3 = 8a_6 \text{에서} ar^2 × ar^4 = 8ar^7\]


\[a = 8r < 0, r < 0\]


모든 자연수 n에 대하여 


\[a_n = 8r \times r^{n-1} = 8r^n\]


\[a_2 = 8r^2 > 0, a_3 = 8r^3 < 0 \text{이므로}\]


\[a_1 + |a_2| + |2a_3| = a_1 + a_2 - 2a_3\]


\[= 8r + 8r^2 - 16r^3 = 0\]


\[2r^2 - r - 1 = 0, (2r + 1)(r - 1) = 0\]


\[r = -\frac{1}{2} \text{또는} r = 1\]


\[r < 0 \text{이므로} r = -\frac{1}{2}\]


\[따라서 a_2 = 8r^2 = 8 \times \left(-\frac{1}{2}\right)^2 = 2\]
