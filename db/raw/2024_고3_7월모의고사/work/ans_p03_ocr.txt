18. [출제의도] 여러 가지 수열의 합 이해하기 


\[ \sum_{k=1}^{15} (3a_k + 2) = 3 \sum_{k=1}^{15} a_k + \sum_{k=1}^{15} 2 \]


\[ = 3 \sum_{k=1}^{15} a_k + 30 = 45 \]


\[ 3 \sum_{k=1}^{15} a_k = 15, \sum_{k=1}^{15} a_k = 5 \]


\[ 2 \sum_{k=1}^{15} a_k = 42 + \sum_{k=1}^{14} a_k \]


\[ 10 = 42 + \sum_{k=1}^{14} a_k, \sum_{k=1}^{14} a_k = -32 \]


따라서 \(a_{15} = \sum_{k=1}^{15} a_k - \sum_{k=1}^{14} a_k = 5 - (-32) = 37\)


19. [출제의도] 삼각함수의 그래프 이해하기 


삼각함수 \(y = a \sin \pi x\)의 주기는 \(\frac{2\pi}{\pi} = 2\), 


최댓값은 \(a\), 최솟값은 \(-a\)이다. 


삼각함수 \(y = a \cos \pi x\)의 주기는 \(\frac{2\pi}{\pi} = 2\), 


최댓값은 \(a\), 최솟값은 \(-a\)이다. 


곡선 \(y = f(x)\)와 곡선 \(y = g(x)\)가 만나는 점의 \(x\) 좌표는 방정식 \(f(x) = g(x)\)의 실근이므로 


\[ a \sin \pi x = a \cos \pi x, \tan \pi x = 1 \]


\[ \pi x = \frac{\pi}{4}, \frac{5\pi}{4}, \frac{9\pi}{4} \quad (0 \le \pi x \le 3\pi) \]


\[ x = \frac{1}{4}, \frac{5}{4}, \frac{9}{4} \]


곡선 \(y = f(x)\)와 곡선 \(y = g(x)\)가 만나는 서로 


다른 세 점을 \(A(\frac{1}{4}, \frac{\sqrt{2}}{2}a)\), \(B(\frac{5}{4}, -\frac{\sqrt{2}}{2}a)\), 


\(C(\frac{9}{4}, \frac{\sqrt{2}}{2}a)\)라 하고, 점 B에서 선분 AC에
내린 수선의 발을 D라 하자. 


 


\[ \overline{AC} = \frac{9}{4} - \frac{1}{4} = 2 \]


\[ \overline{BD} = \frac{\sqrt{2}}{2} a - \left(-\frac{\sqrt{2}}{2} a\right) = \sqrt{2} a \]


삼각형 ABC의 넓이는 


\[ \frac{1}{2} \times \overline{AC} \times \overline{BD} = \frac{1}{2} \times 2 \times \sqrt{2} a = 2 \]


\[ a = \sqrt{2} \]


따라서 \(a^2 = 2\)

\[ y = g(x) = a(x-2) + 2 \text{에서 } a < 0 \quad \text{③} \]

함수 \(f(x)\)는 \(x = -2\)에 극댓값을 갖고 


\(x = -2\)에서 함수 \(f(x)\)의 합산값은 함수 


\(g(x)\)의 합산값보다 크다. 


\[ f(-2) > g(-2) \]


\[ 16 > -4a + 2 \]


\[ a > -\frac{7}{2} \quad \text{②} \]


\[ \text{①, ②에 의하여 } -\frac{7}{2} < a < 0 \]


\[ m = -\frac{7}{2}, M = 0 \]

\[ f(0) = |10 - 10| = 0 \]


\[ t > 0 \text{일 때,} \]


방정식 \(510g_2(4-x)-10=t\)의 실근을 \(x_1\),


방정식 \(510g_2x-10=t\)의 실근을 \(x_2\)라 하자.

\[ 4-x_1 = x_2, x_1+x_2 = 4 \]

\[ g(t) = 4 \text{이므로 조건을 만족시키지 않는다.} \]

\(x < 0\)에서 곡선 \(y = f(x)\)가 \(x\)축과 만나는
점의 \(x\) 좌표를 \(\alpha\)라 하면 


\[ f(x) = \begin{cases} 510g_2(4-x) + m & (x \le \alpha) \\ -510g_2(4-x) - m & (\alpha < x \le 0) \\ 510g_2x + m & (x > 0) \end{cases} \]

\[ g(t) \text{의 값은 일정하지 않다.} \]


② \(t = -10-m\)일 때, 


방정식 \(510g_2(4-x)+m=t\)의 실근을 \(x_1\),
