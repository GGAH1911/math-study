23. [출제의도] 벡터의 합과 크기 계산하기 


\[
\vec{a} = (4, 1), \quad \vec{b} = (-2, 0)
\]


\[
\vec{a} + \vec{b} = (4 - 2, 1 + 0) = (2, 1)
\]


\[
\vec{a} + \vec{b} = \sqrt{2^2 + 1^2} = \sqrt{5}
\]


24. [출제의도] 타원의 접선의 방정식 이해하기
타원 위의 점 (2, a)에서의 접선의 방정식은 


\[
\frac{2x}{8} + \frac{ay}{2a^2} = 1
\]


\[
\frac{x}{4} + \frac{y}{2a} = 1
\]


\[
y = -\frac{a}{2}x + 2a
\]


접선의 기울기가 -3 이므로 


\[
-\frac{a}{2} = -3
\]


따라서 a = 6 


25. [출제의도] 벡터를 이용한 직선의 방정식
이해하기 


\[
OP = (x, y) \text{라 하면}
\]


\[
(OP - OA) \cdot OA = 0
\]


\[
(x - 4, y - 2) \cdot (4, 2) = 0
\]


\[
4x + 2y - 20 = 0
\]


\[
y = -2x + 10
\]


\[
B(5, 0), C(0, 10)
\]


따라서 삼각형 OBC 의 넓이는 


\[
\frac{1}{2} \times OB \times OC = \frac{1}{2} \times 5 \times 10 = 25
\]


26. [출제의도] 포물선의 성질 이해하기 


 


두 점 F, A 에서 준선 l 에 내린 수선의 발을
각각 Q, M 이라 하자. 


\[
HA : AF = 3 : 1
\]


\[
AF = k (k > 0) \text{이라 하면}
\]


\[
HA = 3k, HF = 4k, AM = AF = k
\]


두 삼각형 HMA, HQF 가 서로 닮음이고 


닮음비가 3 : 4 이므로 


\[
FQ = \frac{4}{3}k
\]


\[
FQ = 4, k = 3
\]


\[
HF = 4k = 12
\]


점 P 에서 선분 HF 에 내린 수선의 발을 R 이라
하자. 


\[
PH = PF \text{ 이므로 } HR = RF = 2k = 6
\]


\[
\angle FHQ = \angle HPR, \angle FQH = \angle HRP = \frac{\pi}{2}
\]


두 삼각형 HQF, PRH 는 서로 닮음이다. 


\[
FQ : HR = 2 : 3
\]


따라서 \(PH = \frac{3}{2} HF = \frac{3}{2} \times 12 = 18\)


[다른 풀이] 


 


두 점 F, A 에서 준선 l 에 내린 수선의 발을
각각 Q, M 이라 하자. 


\[
HA : AF = 3 : 1
\]


\[
AF = k (k > 0) \text{이라 하면}
\]


\[
HA = 3k, HF = 4k, AM = AF = k
\]


두 삼각형 HMA, HQF 가 서로 닮음이고
닮음비가 3 : 4 이므로 


\[
FQ = \frac{4}{3}k
\]


\[
FQ = 4, k = 3
\]


\[
HF = 4k = 12
\]


점 F 에서 선분 PH 에 내린 수선의 발을 R 이라
하자. 


삼각형 HQF 에서 


\[
HQ = \sqrt{12^2 - 4^2} = 8\sqrt{2}, HQ = RF = 8\sqrt{2}
\]


\[
PH = PF = x \text{ 라 하면}
\]


\[
PR = PH - RH = x - 4
\]


\[
직각삼각형 PRF 에서
(x - 4)^2 + (8\sqrt{2})^2 = x^2
\]


\[
x = 18
\]


따라서 \(PH = 18\) 


27. [출제의도] 삼수선의 정리 이해하기 


\[
BP' = 6 \text{이므로 선분 } BP' \text{은 점 } P' \text{을 포함하는}
\]


일면의 지름이다. 


선분 BP' 의 중점을 O' , 직선 OO' 에 수직이고
점 O' 을 포함하는 평면을 α 라 하면, 


 


\[
OO' \perp \alpha, \quad OH \perp AB \text{이므로}
\]


삼수선의 정리에 의하여 \(OH \perp AB\)


\[
OH = \sqrt{OH^2 - OO'^2} = \sqrt{13 - 9} = 2
\]


\[
BH = \sqrt{BO'^2 - OH^2} = \sqrt{9 - 4} = \sqrt{5}
\]


점 A 가 선분 BP' 을 지름으로 하는 


원 위의 점이므로 \(PA \perp AB\) 


두 삼각형 BHO', BAP' 은 서로 닮음이고 


닮음비가 1 : 2 이므로


\[
PA = 2O'H = 4
\]


\[
PA = \sqrt{PA^2 + PP'^2} = \sqrt{16 + 9} = 5
\]


\[
AH = BH = \sqrt{5}
\]


\[
PP' \perp \alpha, \quad PA \perp AB \text{이므로}
\]


삼수선의 정리에 의하여 \(PA \perp AB\)


따라서 삼각형 PAH 의 닮이는


\[
\frac{1}{2} \times PA \times AH = \frac{1}{2} \times 5 \times \sqrt{5} = \frac{5\sqrt{5}}{2}
\]


28. [출제의도] 쌍곡선의 성질을 활용하여
문제 해결하기 


 


\[
PF = t \text{ 라 하자.}
\]


쌍곡선의 정리에 의하여 \(PF' - PF = 2a\)


\[
PF' = t + 2a
\]


\[
AF = AF', \quad AR = AS,
\]


\[
\angle ARF = \angle ASF' = \frac{\pi}{2} \text{이므로}
\]


두 삼각형 ARF, ASF' 은 서로 합동이고


\[
RF = SF'
\]


\[
AR = AS = k \text{ 라 하면}
\]


\[
RF = t + k, \quad SF' = PF' - PS = t + 2a - k
\]


\[
t + k = t + 2a - k
\]


\[
k = a
\]


\[
PQ = \frac{a}{3} \text{이므로 } QS = \frac{2a}{3}
\]


두 삼각형 QSA, QPF 는 서로 닮음이고


닮음비가 2 : 1 이므로


\[
PF = \frac{1}{2} AS = \frac{a}{2}
\]
