#### 3. [출제의도] 삼각함수의 성질 이해하기 


\[ \tan \theta = \frac{\sin \theta}{\cos \theta} = -2 \]


\[ \cos \theta = -\frac{1}{2} \sin \theta \]


\[ \sin^2 \theta + \cos^2 \theta = 1 \text{이므로} \]


\[ \sin^2 \theta + \left(-\frac{1}{2} \sin \theta\right)^2 = \frac{5}{4} \sin^2 \theta = 1 \]


\[ \sin \theta = \frac{2 \sqrt{5}}{5} \text{또는} \sin \theta = -\frac{2 \sqrt{5}}{5} \]


\[ \frac{\pi}{2} < \theta < \pi \text{이므로} \sin \theta > 0 \]


\[ \sin \theta = \frac{2 \sqrt{5}}{5} \]


따라서 \(\sin(\pi + \theta) = -\sin \theta = -\frac{2 \sqrt{5}}{5}\)


#### 4. [출제의도] 함수의 극한 이해하기 


\[ \lim_{x \to 0} f(x) = 2, \quad \lim_{x \to 1} f(x) = 3 \]


따라서 \(\lim_{x \to 0^-} f(x) + \lim_{x \to 1^+} f(x) = 2 + 3 = 5\)


#### 5. [출제의도] 정적분의 정의 이해하기 


함수 \(f(x)\)는 \(f'(x)\)의 부정적분이므로 


\[ \int_{1}^{2} f'(x) dx = [f(x)]_{1}^{2} = f(2) - f(1) \]


모든 실수 \(x\)에 대하여 


\[ f(x) - f(1) = x^3 + 4x^2 - 5x \]


\(x = 2\)일 때, 


\[ f(2) - f(1) = 2^3 + 4 \times 2^2 - 5 \times 2 = 14 \]


따라서 \(\int_{1}^{2} f'(x) dx = 14\)


#### 6. [출제의도] 등비수열의 일반항 이해하기 


등비수열 \(\{a_n\}\)의 첫째항을 \(a(a > 0)\), 공비를 \(r(r > 0)\)이라 하자. 


\[ a_n = ar^{n-1} \quad (\text{단, } n \text{은 자연수}) \]


\[ a_1 + a_2 = a + ar \]


\[ a_3 + a_4 = ar^2 + ar^3 = r^2(a + ar) \]


\[ \frac{a_3 + a_4}{a_1 + a_2} = \frac{r^2(a + ar)}{a + ar} = r^2 = 4, \quad r = 2 \quad (r > 0) \]


\[ a_2a_4 = a^2r^4 = 16a^2 = 1, \quad a = \frac{1}{4} \quad (a > 0) \]


\[ a_n = \frac{1}{4} \times 2^{n-1}, \quad a_6 = 8, \quad a_7 = 16 \]


따라서 \(a_6 + a_7 = 24\)

#### 8. [출제의도] 부정적분의 성질 이해하기 


모든 실수 \(x\)에 대하여 


\[ xf'(x) = 6x^3 - x + f(0) + 1 \]


\[ x = 0 \text{일 때, } 0 = f(0) + 1 \]


\[ f(0) = -1 \]


\[ xf'(x) = 6x^3 - x + (-1) + 1 = x(6x^2 - 1) \]

따라서 \(f(-1) = -2 + 1 - 1 = -2\)


#### 9. [출제의도] 지수와 로그의 성질 이해하기 


삼각형 ABC의 무계층의 좌표는 


\[ \left( \begin{array}{c} 0 + 2a + (-1 \log_2 9) \\ 3 \end{array} \right) - \left( \begin{array}{c} -1 \log_2 9 \end{array} \right) + \log_2 7 + a \]


\[ 0 + 2a + (-1 \log_2 9) = b, \quad 2a - \log_2 9 = 3b \]


\[ b = \frac{2}{3}a - \frac{1}{3}\log_2 9 \quad \dots \quad \text{③} \]


\[ (-1 \log_2 9) + \log_2 7 + a = \log_2 7 = \frac{1}{3}\log_2 7 \]


\[ -1 \log_2 9 + \log_2 7 + a = \log_2 7 \]


\[ a = \log_2 9 \quad \dots \quad \text{⑤} \]


두 식 ③, ⑤을 연립하면 


\[ b = \frac{2}{3}\log_2 9 - \frac{1}{3}\log_2 9 = \frac{1}{3}\log_2 9 \]


\[ a + 3b = \log_2 9 + \log_2 9 = \log_2 81 \]


\[ 2^{a+3b} = 2^{\log_2 81} \]


\[ 2^{\log_2 81} = k \text{라 하면} \]


\[ \log_2 k = \log_2 81, \quad k = 81 \]


따라서 \(2^{a+3b} = 81\)
