22. [출제의도] 점선의 방정식과 그래프의 개형을 활용하여 문제 해결하기

\[g(t) = 0\]


\[x \neq t \text{일 때 } f(x) - x - f(t) + t = 0 \text{에서}\]


\[\frac{f(x) - f(t)}{x - t} = 1 \text{이다.}\]

임의의 실수 \(s\)에 대하여 \(h(s) \geq 1\)이다. 


(i) \(h(s) = 1\)인 경우 


 


\[\lim_{t \to s} h(t) = 2 \text{이므로} \lim_{s \to t} \{h(t) - h(s)\} = 1\]


(ii) \(h(s) = 2\)인 경우 


 


\[\lim_{t \to s} h(t) = 2 \text{이므로} \lim_{s \to t} \{h(t) - h(s)\} = 0\]


 


\[\lim_{t \to s} \{h(t) - h(s)\} = 0 \lim_{t \to s} \{h(t) - h(s)\} = 2\]


(iii) \(h(s) \geq 3\)인 경우 


\(\lim_{t \to s} h(t) = 4\)이거나 극한값이 존재하지 


않는다. 


(i), (ii), (iii)에 의하여 


곡선 \(y = f(x)\)와 직선 \(l\)이 


두 점 \((-1, f(-1))\), \((1, f(1))\)에서 접할 때

만족시킨다. 


 


함수 \(f(x)\)의 최고차항의 개수를 \(a\), 직선 \(l\)의 방정식을 \(y = x + b\)라 하자. 


(단, \(a, b\)는 상수) 


\[f(x) - (x + b) = a(x - 1)^2(x + 1)^2\]


\[f(x) = a(x - 1)^2(x + 1)^2 + x + b\]


조건 (나)에서 \(\int_0^a \{f(x) - |f(x)|\} dx = 0\)을 


만족시키는 실수 \(\alpha\)의 최솟값이 \(-1\)이므로 


\[-1 \leq x \leq 0 \text{에서 } f(x) \geq 0, f(-1) \geq 0\]

\[\text{나이므로 } f(-1) = 0\]


\[f(-1) = -1 + b = 0, b = 1\]


\[f(x) = a(x - 1)^2(x + 1)^2 + x + 1\]

\[\frac{d}{dx} \int_0^x \{f(u) - ku\} du = f(x) - kx \geq 0\]
