#### 5. [출제의도] 함수의 미분가능성 이해하기 


함수 \(f(x)\)가 \(x=1\)에서 미분가능하므로
\(x=1\)에서 연속이다. 


\[\lim_{x \to 1-} f(x) = \lim_{x \to 1+} f(x) = f(1)\]


\[\lim_{x \to 1-} f(x) = \lim_{x \to 1+} (3x+a) = a+3\]


\[\lim_{x \to 1+} f(x) = \lim_{x \to 1+} (2x^3+bx+1) = b+3\]


\(f(1) = a+3\)


\(a+3 = b+3, a = b\)


함수 \(f(x)\)가 \(x=1\)에서 미분가능하므로


\[\lim_{x \to 1-} \frac{f(x) - f(1)}{x-1} = \lim_{x \to 1+} \frac{f(x) - f(1)}{x-1}\]


\[\lim_{x \to 1-} \frac{f(x) - f(1)}{x-1} = \lim_{x \to 1+} \frac{3x+a-(a+3)}{x-1} = 3\]


\[\lim_{x \to 1+} \frac{f(x) - f(1)}{x-1} = \lim_{x \to 1+} \frac{3x+a-(a+3)}{x-1}\]


\[= \lim_{x \to 1+} \frac{(2x^3+ax+1)-(a+3)}{x-1}\]


\[= \lim_{x \to 1+} \frac{(x-1)(2x^2+2x+a+2)}{x-1} = a+6\]


\(3 = a+6, a = -3, b = -3\)


따라서 \(a+b=-6\)

\[a_n = ar^{n-1} \quad (\text{단, } n \text{은 자연수})\]

또는 항이 양수이므로 \(r = 2\)


따라서 \(a_5 = r^5 = 32\)

#### 8. [출제의도] 정적분을 활용하여 속도와 거리
문제 해결하기 


점 P가 운동 방향을 바꾼 때 \(v(t)=0\) 


\(v(t) = t^2 - 4t + 3 = (t-1)(t-3) = 0\)


점 P가 \(t=1, t=3\)에서 운동 방향을 


바꾸므로 \(a=3\)


점 P가 시간 \(t=0\)에서 \(t=3\)까지 


움직인 거리는


\[\int_{0}^{3} |v(t)| dt\]


\[= \int_{0}^{1} v(t) dt + \int_{1}^{3} (-v(t)) dt\]


\[= \int_{0}^{1} (t^2 - 4t + 3) dt + \int_{1}^{3} (-t^2 + 4t - 3) dt\]


\[= \left[\frac{1}{3} t^3 - 2t^2 + 3t\right]_0^1 + \left[-\frac{1}{3} t^3 + 2t^2 - 3t\right]_1^3\]


\[= \frac{4}{3} + \frac{4}{3} = \frac{8}{3}\]
