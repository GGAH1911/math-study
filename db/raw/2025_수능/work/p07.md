# 영역: 공통

## 18번 [3점]

수열 $\{a_n\}$이 모든 자연수 $n$에 대하여

$$a_n + a_{n+3} = 12$$

를 만족시킬 때, $\displaystyle\sum_{n=1}^{9} a_n$의 값을 구하시오.

## 19번 [3점]

양수 $a$에 대하여 함수 $f(x)$를

$$f(x) = 2x^3 - 3ax^2 - 12a^2x$$

라 하자. 함수 $f(x)$의 극댓값이 $\dfrac{7}{27}$일 때, $f(3)$의 값을 구하시오.

## 20번 [4점]

곡선 $y = \left(\dfrac{1}{5}\right)^{x-3}$과 직선 $y = x$가 만나는 점의 $x$좌표를 $k$라 하자. 실수 전체의 집합에서 정의된 함수 $f(x)$가 다음 조건을 만족시킨다.

$$\boxed{x > k\text{인 모든 정수 }x\text{에 대하여}\quad f(x)=\left(\frac{1}{5}\right)^{x-3}\text{이고, }f(f(x))=3x\text{이다.}}$$

$f\!\left(\dfrac{1}{k^2 \times 5^{10}}\right)$의 값을 구하시오.
