Stage B — vision_meta.py VISION_SYSTEM prompt 강화

주요 추가 룰 (5개)

1. LaTeX 정확성 강제 
모든 수식을 LaTeX $...$ 로 정확히 옮긴다.
⋄, □, ?, 'placeholder' 같은 기호 절대 금지.
글리프 안 보이면 인접 문맥으로 추정해 작성.
\dfrac, x^{n+1}, \int_a^b, \sum_{k=1}^n 등 KaTeX 호환.
2. 도형 묘사 강제 — [그림] placeholder 금지 
has_figure=true 면 [그림: ...] 형식으로 텍스트 묘사:
- 좌표 (A(2,3), 원점 O, 점 P가 곡선 위에)
- 각도/길이 (∠OAB=θ, AB=5)
- 도형 종류 (삼각형/원/부채꼴/포물선/접선/보조선)
- 보조선·교점·음영
- 그래프 함수식 + 교점·점근선
- 좌표축 라벨, 단위
이 텍스트만으로 도형을 재구성 가능해야 함.
3. 잘림/흐림 대응 
이미지 일부 잘리거나 흐려도 보이는 범위 옮기고,
불확실한 부분은 명시 ([하단 일부 잘림: 선택지 ⑤ 식 불확실])
4. 인접 문제 cross-contamination 방지 
현재 문제 번호 "N."로 시작하는 본문 + 그 보기까지만.
다음 문제 본문이 같은 영역에 들어와도 무시.
5. 본문 길이 가드 
50-1200자 정도.
너무 짧으면 OCR 누락 의심.
너무 길면 cross-contamination 의심.

제거된 패턴

그림은 [그림] 표시  ← 이게 도형 정보 0인 placeholder 의 원인

예상 효과

결함률 ~57% → ~25% (추정) 도형 묘사 0% → 70%+ 글리프 placeholder 제거

이번 audit 결과 기반 patterns:

  • 1번 OCR 깨짐 → LaTeX 강제로 완화

  • 도형 placeholder → 좌표·각도·라벨 묘사
  • cross-contamination → 번호 가드
